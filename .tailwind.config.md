Tailwind CSS configuration for the OpenFrame OSS frontend, extending the shared `@flamingo-stack/openframe-frontend-core` design system preset with animation support.

## Key Components

- **`openframeCorePreset`** — Imported from the core UI kit package; provides all OpenDesign System (ODS) colors, theme tokens, and base Tailwind configuration
- **`tailwindcssAnimate`** — Plugin enabling CSS animation utilities
- **`content`** — Scans local `src/` files and pre-built core package dist files for class purging
- **`presets`** — Applies the core design system as a Tailwind preset, ensuring consistent theming across the stack

## Usage Example

No direct usage required — Tailwind automatically picks up this config at build time. To extend with additional theme values or plugins, modify the `config` object:

```typescript
const config: Config = {
  content: [...],
  plugins: [tailwindcssAnimate, myPlugin],
  presets: [openframeCorePreset],
  theme: {
    extend: {
      spacing: {
        '128': '32rem',
      },
    },
  },
};
```

> **Note:** Avoid overriding `theme.colors` directly — ODS colors are provided by `openframeCorePreset`. Use `theme.extend` to add values without losing the design system tokens.
