Serves as the primary application shell and layout orchestrator for the OpenFrame frontend, wiring together navigation, auth, onboarding, notifications, Mingo AI chat, and subscription gating into a single cohesive client-side layout.

## Key Components

- **`AppShell`** — Inner shell component that composes the full authenticated app layout. Manages state for:
  - Mingo AI chat drawer (open/close, deferred identity resolution, native back support)
  - Onboarding chrome (top bars, progress hydration, coach marks)
  - Unread notification counts
  - Subscription lock gating
  - Navigation sidebar config (with onboarding badge/tab visibility)
- **`CoreAppLayout`** — Layout primitive from `openframe-frontend-core` wrapping the shell
- **`AppLayoutDrawer` / `AppLayoutDrawerContent`** — Slide-in drawer panels (used for Mingo chat)
- **`ChatIdentityProvider`** — Deferred identity resolution; only activates on first chat open (avoids unnecessary API calls)
- **`SubscriptionGuard` / `SubscriptionLockContent`** — Prevents access to locked features when subscription is inactive
- **`OnboardingProgressHydrator` / `OnboardingCoachMark` / `OnboardingTourBar` / `InitialSetupBar`** — Tenant and user onboarding chrome, gated on the resolved session and loaded progress

## Usage Example

```typescript
// Used as the root layout wrapper for authenticated app routes
// (typically in app/(app)/layout.tsx)
import AppLayout from '@/app/components/layout/app-layout';

export default function Layout({ children }: { children: React.ReactNode }) {
  return <AppLayout>{children}</AppLayout>;
}
```

## Notes

- Chat identity fetch is **lazily deferred** until the drawer first opens — suppressed entirely in native shell environments due to proxy origin restrictions
- Navigation panels auto-close on route change via `pathname` effect (panels are non-modal)
- The Mingo sidebar is suppressed on the `/mingo` legacy route to prevent two chat surfaces sharing the same message store simultaneously
- The `mingoSidebar` feature flag controls availability of the chat chrome
