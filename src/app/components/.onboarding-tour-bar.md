A full-width accent-yellow announcement banner that prompts users to begin or continue the guided onboarding tour, rendered in the app layout's `topBar` slot.

## Key Components

### `OnboardingTourBar` (exported function component)

| Prop | Type | Default | Description |
|---|---|---|---|
| `onStart` | `() => void` | — | Callback fired when the CTA button or content row is tapped |
| `started` | `boolean` | `false` | Switches CTA label from `"Take the Tour"` to `"Continue Onboarding"` |
| `showAction` | `boolean` | `true` | When `false`, hides the CTA and disables the tap target (used on `/onboarding` itself) |

**Behavior notes:**
- Below `md` breakpoint: the entire content row becomes the tap target (`onContentClick → onStart`); the CTA button is CSS-hidden
- Above `md`: CTA renders as an `outline / small` `Button` with a leading `RouteIcon`
- When `showAction` is `false`, the bar collapses to content height and is fully inert

## Usage Example

```typescript
// Shown on all pages except /onboarding
<OnboardingTourBar
  onStart={() => router.push('/onboarding')}
  started={hasCompletedFirstStep}
  showAction={pathname !== '/onboarding'}
/>

// On /onboarding itself — inert banner, no CTA
<OnboardingTourBar
  onStart={() => {}}
  showAction={false}
/>
```
