Renders a pixel-accurate skeleton of the full application shell (sidebar, header, and content area) used as a loading placeholder during session checks, initialization, and Suspense fallbacks.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AppShellSkeleton` | Component | Root skeleton mirroring the full `AppShell` structure including sidebar, header, and route content |
| `APP_MAIN_CLASS_NAME` | Constant | Default bottom padding class for `<main>` elements (`pb-14`) |
| `getMainClassNameOverride` | Function | Returns per-route `<main>` padding overrides keyed by pathname prefix |
| `NavigationSidebarSkeleton` | Component (internal) | Responsive sidebar skeleton tracking minimized/expanded and tablet states |
| `HeaderButtonCellSkeleton` | Component (internal) | Individual header action button cell skeleton |
| `useOnboardingTopBarPlaceholder` | Hook (internal) | Replays cached onboarding banner to prevent layout shift on first paint |

## Usage Example

Used automatically as the Next.js `loading.tsx` fallback and Suspense boundary placeholder — not typically instantiated directly:

```typescript
// Root layout Suspense fallback
import { AppShellSkeleton } from './app-shell-skeleton';

export default function Loading() {
  return <AppShellSkeleton />;
}

// Per-route padding override (consumed by both live layout and skeleton)
import { getMainClassNameOverride, APP_MAIN_CLASS_NAME } from './app-shell-skeleton';

const mainClassName = getMainClassNameOverride(pathname) ?? APP_MAIN_CLASS_NAME;
// '/tickets' → 'pb-0 md:pb-0'
// '/mingo'   → 'p-0 md:p-0'
// other      → 'pb-14'
```

## Notes

- **Hydration-safe**: sidebar content is deferred until media queries resolve to prevent SSR/client mismatch
- **CSS var sync**: updates `--sidebar-width` on mount so the skeleton matches the real sidebar's persisted minimized state without a flash
- **Feature-flag gated**: header action cells and the onboarding top bar are conditionally rendered using the same flags as the live `AppHeader`, ensuring pixel-identical handoff
- **`getMainClassNameOverride` and `APP_MAIN_CLASS_NAME` must be kept in sync** with the live layout — divergence causes visible resize on skeleton-to-page transition for full-height routes
