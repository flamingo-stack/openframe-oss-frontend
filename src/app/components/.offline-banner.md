Renders a non-intrusive floating pill banner that monitors network connectivity and displays when the user goes offline.

## Key Components

- **`OfflineBanner`** — Client component that listens to `window` `online`/`offline` events and `navigator.onLine`, rendering a fixed pill banner centered at the top of the viewport when connectivity is lost.

## Usage Example

```typescript
// Drop into your root layout — it self-manages visibility
import { OfflineBanner } from '@/components/offline-banner';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <OfflineBanner />
        {children}
      </body>
    </html>
  );
}
```

## Behaviour Notes

- **SSR-safe**: initialises `offline` state as `false` to avoid a false-positive flash during server-side render or static export (where `navigator` is undefined).
- **Native shell aware**: positions relative to `--native-safe-top` CSS variable, accommodating device safe areas in native wrappers.
- **Accessibility**: wraps output in `role="status"` with `aria-live="polite"` so screen readers announce the connectivity change without interrupting the user.
- **Limitation**: `navigator.onLine` only confirms whether a network interface exists, not true reachability. Treat this as a UX hint; actual error handling belongs in request-level retry/refresh logic.
- **Cleanup**: removes event listeners on unmount to prevent memory leaks.
