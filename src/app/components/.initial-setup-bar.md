A full-width announcement banner rendered in the app layout's `topBar` slot to prompt tenants to complete their initial OpenFrame setup.

## Key Components

**`InitialSetupBar`** — Named export functional component that wraps `AnnouncementBarView` with setup-specific styling and behavior.

| Prop | Type | Default | Description |
|---|---|---|---|
| `onStart` | `() => void` | required | Called when the CTA button or content row is tapped |
| `started` | `boolean` | `false` | Toggles label between `"Start Setup"` and `"Continue Setup"` |
| `showAction` | `boolean` | `true` | When `false`, hides the CTA and disables the tap-target (used on the dashboard page that already hosts the setup card) |

## Key Components

- **`AnnouncementBarView`** — Shared layout primitive providing responsive one/two-row behavior (collapses CTA below `md`)
- **`ListCheckIcon`** — Leading adornment icon at `--icon-size-icon-size`
- **`Button`** — CTA rendered with `variant="outline" size="small"` matching Figma's dark card surface + Azeret Mono label

## Usage Example

```typescript
// In app layout — hide bar on the dashboard page that hosts the setup card
<InitialSetupBar
  onStart={() => router.push('/setup')}
  started={setupProgress.stepsCompleted > 0}
  showAction={pathname !== '/dashboard'}
/>

// Inert variant — bar is visible but non-interactive (dashboard page)
<InitialSetupBar
  onStart={() => router.push('/setup')}
  showAction={false}
/>
```

## Notes

- Styled with ODS tokens: `bg-ods-accent` / `text-ods-text-on-accent` (accent-yellow surface, dark text)
- Below `md`, the entire content row becomes the tap target; the `Button` is CSS-hidden at that breakpoint
- Caller is responsible for conditional rendering — the bar does not manage its own visibility
