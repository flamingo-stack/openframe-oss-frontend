Fullscreen unlock gate rendered during cold-start when biometric authentication is enabled but the Keychain read was canceled or failed, leaving the token store in a `'locked'` state. Presents retry and escape-hatch actions without navigating away until the caller resolves.

## Key Components

### `BiometricUnlockGate` (exported component)

| Prop | Type | Description |
|------|------|-------------|
| `onUnlocked` | `() => void` | Called after a successful `retryTokenHydration()` to re-drive the auth check |
| `onUseAnotherLogin` | `() => Promise<void> \| void` | Async escape hatch; buttons stay disabled until the caller completes the hand-off |

**Internal state:**

- `label` — resolved biometry label (e.g. `"Face ID"`, `"Touch ID"`) via `isBiometricAvailable()`
- `isUnlocking` — locks both buttons during the Keychain retry prompt
- `isLeaving` — locks both buttons while the caller handles the sign-in redirect

**Accessibility:** On mount, focus is programmatically moved to the `<h1>` heading via `headingRef` so assistive technology announces the lock context correctly.

## Usage Example

```typescript
import { BiometricUnlockGate } from './biometric-unlock-gate';

function AppShell() {
  const checkAuth = useAuthCheck();

  if (lockState === 'locked') {
    return (
      <BiometricUnlockGate
        onUnlocked={() => checkAuth()}
        onUseAnotherLogin={async () => {
          await router.replace('/sign-in');
        }}
      />
    );
  }

  return <AuthenticatedApp />;
}
```

> **Native-shell only.** The `'locked'` token-store state is only set inside the native shell; web builds never reach this gate.
