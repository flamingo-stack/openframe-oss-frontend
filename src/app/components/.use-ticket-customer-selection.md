Manages the linked ticket and customer selection state for time-tracking UI components, enforcing bidirectional selection rules between tickets and their associated customer organizations.

## Key Components

### `TicketCustomerSeed`
Initialization interface for pre-populating or constraining the selection state:
- `ticketId` / `customerId` — pre-selected values
- `lockCustomer` — disables the customer field when derived from a ticket selection
- `fixedCustomer` — pins the customer permanently (e.g. on a customer-scoped page); never auto-cleared

### `withSeed<T>`
Internal utility that injects a previously selected option back into the options list when it no longer appears in the current search page, preventing it from disappearing from the UI.

### `useTicketCustomerSelection()`
Primary hook that owns the full selection state and exposes:

| Returned Value | Type | Description |
|---|---|---|
| `ticketId` / `customerId` | `string \| null` | Current selections |
| `customerLocked` | `boolean` | Customer field is disabled (derived from ticket) |
| `ticketOptions` / `customerOptions` | `T[]` | Filtered + seeded option lists |
| `ticketsLoading` / `customersLoading` | `boolean` | Async loading states |
| `setTicketSearch` / `setCustomerSearch` | `setter` | Search input handlers |
| `selectTicket` / `selectCustomer` | `fn` | Selection handlers with cascade logic |
| `reset` | `fn` | Reinitializes all state from an optional `TicketCustomerSeed` |

## Selection Rules

- **Customer first** → tickets are scoped to that customer; changing customer clears a mismatched ticket
- **Ticket first** → customer is auto-pinned from the ticket's organization and locked; clearing the ticket releases the derived customer unless `fixedCustomer` is set

## Usage Example

```typescript
const {
  ticketId,
  customerId,
  customerLocked,
  ticketOptions,
  customerOptions,
  selectTicket,
  selectCustomer,
  reset,
} = useTicketCustomerSelection();

// Pre-populate from a customer-scoped page
reset({
  customerId: 'org_123',
  customerLabel: 'Acme Corp',
  fixedCustomer: true,
});

// Selecting a ticket auto-locks the customer
selectTicket('ticket_456');
// customerLocked === true, customerId derived from ticket's organizationId
```
