A floating contextual coach-mark tooltip component that renders on destination pages when a user arrives via an onboarding step. It reads query parameters to display context-aware guidance and provides a CTA to return to either the per-user onboarding flow or the tenant initial setup flow.

## Key Components

### `OnboardingCoachMark`
The sole export — a client-side React component mounted app-wide in the app shell. Renders `null` on normal page visits; only activates when the `SETUP_HINT_PARAM` query parameter is present and resolves to a known onboarding hint key.

**Behaviour:**
- Reads `SETUP_HINT_PARAM` from the URL to look up coach-mark content (`title` + `body`) from `ONBOARDING_COACH_MARKS`
- Reads `SETUP_RETURN_PARAM` to determine where the CTA navigates back to (defaults to `/onboarding`)
- Adapts the CTA label and icon based on whether the return path is the user onboarding flow (`/onboarding`) or the tenant initial setup flow

## Usage Example

```typescript
// Mounted once in the app shell (e.g. layout.tsx)
import { OnboardingCoachMark } from '@/components/onboarding-coach-mark';

export default function AppLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <OnboardingCoachMark />
    </>
  );
}
```

```typescript
// Triggering the coach mark from an onboarding step link
const href = `/settings/integrations?${SETUP_HINT_PARAM}=connectIntegration&${SETUP_RETURN_PARAM}=/onboarding`;
router.push(href);
```

## Notes

- Renders as a fixed overlay (`bottom-right`, `z-[60]`) with a max width of `360px`
- Styled with ODS accent tokens (`ods-accent`, `ods-open-yellow-secondary`)
- Depends on [`onboarding-coach-marks`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/onboarding/onboarding-coach-marks.ts) for hint key validation and content definitions
