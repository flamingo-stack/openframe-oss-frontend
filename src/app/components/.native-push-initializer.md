Mounts once inside an authenticated layout to bootstrap native push notifications. It checks for a native shell context, requests notification permission, registers the FCM token, and wires deep-link navigation through the Next.js client router. Renders nothing.

## Key Components

| Export | Type | Description |
|---|---|---|
| `NativePushInitializer` | React component | Headless initializer; invokes `initNativePush` with a router-backed navigation callback |

**Dependencies:**

- [`initNativePush`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/lib/native-push.ts) — handles permission requests, FCM token registration, and notification tap routing
- [`isNativeShell`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/lib/native-shell.ts) — guards execution to native app contexts only

## Usage Example

Drop it once inside the authenticated app layout. It is a no-op in plain browser environments.

```typescript
// app/(app)/layout.tsx
import { NativePushInitializer } from '@/components/native-push-initializer';

export default function AppLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <NativePushInitializer />
      {children}
    </>
  );
}
```

## Behaviour Notes

- **Guard** — `isNativeShell()` short-circuits the effect in web-only contexts; safe to include unconditionally.
- **Router stability** — `router` is listed as an effect dependency; Next.js guarantees a stable reference so the effect runs exactly once after mount.
- **No UI** — returns `null`; has zero impact on layout or rendering.
- **`'use client'`** — required because it calls `useRouter` and `useEffect`; never renders on the server.
