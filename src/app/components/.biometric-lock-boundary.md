Root-level React boundary that manages the native-shell biometric cold-start lock, gating the entire app tree behind a biometric unlock prompt when running in the native shell.

## Key Components

- **`BiometricLockBoundary`** — Client component wrapper that subscribes to `BiometricLockState` from the token store and conditionally renders one of three states:
  - `children` — normal pass-through (web/desktop, or after successful unlock)
  - `<BiometricUnlockGate>` — shown when lock is `'locked'` or a "use another login" hand-off is in flight
  - `<AppShellSkeleton>` — neutral hold screen during an `'invalidated'` sign-out redirect

## Render Logic

| Lock State | `leavingToLogin` | Renders |
|---|---|---|
| `null` / unlocked | `false` | `children` |
| `'locked'` | any | `BiometricUnlockGate` |
| any | `true` | `BiometricUnlockGate` |
| `'invalidated'` (pre-redirect) | — | `AppShellSkeleton` |
| `'invalidated'` (on `/auth`) | — | `children` |

## Usage Example

```typescript
// Wrap above all auth session consumers (FeatureFlagsGate, AppLayout, etc.)
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <BiometricLockBoundary>
      <AppLayout>{children}</AppLayout>
    </BiometricLockBoundary>
  );
}
```

## Side Effects

- **`'locked'`** → renders `BiometricUnlockGate`; on success calls `invalidateAuthSession` to re-drive the auth session check
- **`'invalidated'`** → triggers `signOutToLogin`, wiping stale tokens and routing to the sign-in flow; holds with `AppShellSkeleton` until `/auth` is current to prevent flashing the signed-out app
- **`handleUseAnotherLogin`** → dismisses the lock, runs `signOutToLogin`, holds the gate until the router lands on `/auth`
