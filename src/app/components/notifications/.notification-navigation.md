Resolves navigation actions and routes for notifications, mapping notification context types to their corresponding UI destinations (ticket dialogs, Mingo chat drawers, or page routes).

## Key Components

### Constants
- **`CONTEXT_TYPENAME_BY_TYPE`** — Maps backend `NotificationContext.type` strings to GraphQL `__typename` values; used by the NATS live path to reconstruct typed context records.
- **`TICKET_CONTEXT_TYPES`** — Set of context types whose entity is a ticket (navigate via `ticketId`).
- **`TICKET_CHAT_CONTEXT_TYPES`** — Subset of ticket contexts that deep-link to the Chat tab.

### Types
- **`NotificationAction`** — `{ label, route, mingoDialogId? }`. Every action carries a `route` (the only thing an out-of-React transport can act on); a Mingo dialog additionally carries `mingoDialogId`, a *preference* for the in-layout drawer that `mingoDrawerDialogId` confirms at click time.

### Functions

| Function | Description |
|---|---|
| `resolveNotificationAction(notification)` | Returns the primary `NotificationAction` for a store-shaped notification, or `null` if no navigable entity exists. |
| `resolveNatsNotificationRoute(payload)` | Resolves a route from a raw NATS wire payload (used on OS-toast click before the notification is shaped into a store record). |
| `resolveNotificationRoute(notification)` | Convenience wrapper — extracts the `route` string (`null` only when the notification points at nothing openable). |
| `mingoDrawerDialogId(action)` | The dialog to open in the in-layout drawer, or `null` to follow `action.route`. Asks the shell (`mingo-launcher-store.canOpen`) whether a drawer is mounted — do NOT branch on `mingoDialogId` directly. |
| `notificationTargetsDialog(notification, activeDialogs)` | Returns `true` when the notification's `dialogId` is in the currently active drawer view set. |
| `notificationTargetsLocation(notification, pathname, searchParams)` | Returns `true` when the current URL matches the notification's target route (pathname + query params); drives auto-read behavior. |

## Usage Example

```typescript
import {
  mingoDrawerDialogId,
  resolveNotificationAction,
  notificationTargetsLocation,
  notificationTargetsDialog,
} from '@/lib/notification-navigation';

// Resolve a navigation action to render a button
const action = resolveNotificationAction(notification);
if (action) {
  // Never branch on `action.mingoDialogId` itself — it is set whenever the
  // notification names a dialog, including where no drawer is mounted (flag off,
  // subscription lock). Opening into that would set store state nothing renders
  // while the caller marked the notification read.
  const drawerDialogId = mingoDrawerDialogId(action);
  if (drawerDialogId) {
    openMingoDialogInDrawer(drawerDialogId);
  } else {
    router.push(action.route);
  }
}

// Auto-mark read when the user is already on the target page
const isOnTarget = notificationTargetsLocation(
  notification,
  window.location.pathname,
  new URLSearchParams(window.location.search),
);

// Auto-mark read when the target dialog is open in the drawer
const isDialogOpen = notificationTargetsDialog(notification, activeDialogViews);
```
