Maps notification category strings to their corresponding navigation icons for use in notification rendering.

## Key Components

**`iconByCategory`** — Internal lookup table mapping backend `NotificationCategory` string keys (e.g., `DASHBOARD`, `TICKETS`, `MINGO`) to 16px React icon nodes. Icons use `currentColor` for theming, except `MingoIcon` which retains its canonical cyan brand colors.

**`getNotificationCategoryIcon(category)`** — Resolves a category string (case-insensitive) to its icon node. Returns `undefined` for `null`, `undefined`, or unrecognized categories.

**`withCategoryIcon(notification)`** — Enriches a `Notification` object with its category icon for tile rendering. Explicit `icon` or `imageUrl` fields always take precedence; the category icon is only injected when neither is present.

## Usage Example

```typescript
import {
  getNotificationCategoryIcon,
  withCategoryIcon,
} from './notification-category-icons';

// Resolve an icon directly
const icon = getNotificationCategoryIcon('tickets'); // <TagIcon size={16} />
const missing = getNotificationCategoryIcon(null);   // undefined

// Enrich a notification for tile rendering
const notification = { id: '1', category: 'DEVICES', title: 'Disk alert' };
const enriched = withCategoryIcon(notification);
// enriched.icon === <MonitorIcon size={16} />

// Explicit icon is never overwritten
const withCustomIcon = withCategoryIcon({ ...notification, icon: <MyIcon /> });
// withCustomIcon.icon === <MyIcon /> (unchanged)
```

## Supported Categories

| Key | Icon |
|---|---|
| `DASHBOARD` | `ChartDonutIcon` |
| `CUSTOMERS` | `IdCardIcon` |
| `DEVICES` | `MonitorIcon` |
| `SCRIPTS` | `BracketCurlyIcon` |
| `MONITORING` | `RadarIcon` |
| `SOFTWARE` | `PackageIcon` |
| `LOGS` | `ClipboardListIcon` |
| `TICKETS` | `TagIcon` |
| `MINGO` | `MingoIcon` (cyan brand colors) |

> Category matching is case-insensitive. Unknown or generic categories resolve to `undefined`.
