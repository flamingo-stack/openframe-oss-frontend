Opens a Mingo dialog in the in-layout chat drawer by coordinating the launcher and messages stores without requiring a React context.

## Key Components

- **`openMingoDialogInDrawer(dialogId: string): void`** — Sets the active dialog, clears its unread badge, and opens the chat drawer launcher. Reads Zustand stores via `getState()`, making it safe to call from event handlers, notification callbacks, and other non-React module code.

## Usage Example

```typescript
import { openMingoDialogInDrawer } from './open-mingo-dialog';

// From a desktop notification click handler
self.addEventListener('notificationclick', (event) => {
  const dialogId = event.notification.data?.dialogId;
  if (dialogId) {
    openMingoDialogInDrawer(dialogId);
  }
});

// From a regular event handler
button.addEventListener('click', () => {
  openMingoDialogInDrawer('dialog-abc-123');
});
```

## Notes

- Calls `.getState()` directly on both `useMingoMessagesStore` and `useMingoLauncherStore`, bypassing the React hook requirement so it can be invoked outside component render cycles.
- Both stores are module-level singletons shared between the drawer surface and the legacy `/mingo` standalone page.
