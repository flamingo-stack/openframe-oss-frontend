Provides a client-side React data provider that bridges NATS real-time notifications with Relay's GraphQL store, handling notification rendering, navigation, approval workflows, and popup display for the OpenFrame frontend.

## Key Components

### Constants & Configuration
- `DRAWER_PAGE_SIZE` — Paginated load size (30 notifications per fetch)
- `SHOW_POPUPS_STORAGE_KEY` / `SHOW_DESKTOP_POPUPS_STORAGE_KEY` — LocalStorage keys for popup preferences
- `DRAWER_FILTER_PAIRS` / `NATS_CONTEXT_TYPENAME` — Relay connection and context type configuration

### Pure Utility Functions
- **`parseApprovalContext`** — Extracts and validates `ApprovalNotificationMeta` from a raw NATS payload context; returns `null` for non-approval types
- **`setJsonScalar`** — Writes JSON object fields to Relay `RecordProxy` instances using the unsafe setter (bypasses scalar type restriction)
- **`upsertContextRecord`** — Gets or creates a typed `RecordProxy` in the Relay store, stamping `__typename`
- **`writeToolCallRecord`** — Serializes a single `ApprovalToolCall` into the Relay store
- **`writeNotificationContext`** — Dispatches NATS payload context to the correct Relay record type (approval, typed context, or generic fallback)
- **`prependNotificationEdge`** — Inserts a new notification edge at the head of a Relay connection, deduplicating by ID

### Interfaces
- **`NatsNotificationPayload`** — Typed shape of incoming real-time NATS notification messages
- **`PaginationState`** — Tracks drawer pagination (`hasMore`, `isLoadingMore`, `loadMore`)
- **`TileHelpers`** — Callbacks passed to tile renderers (`onComplete`, `onSettle`, `liveDurationMs`)
- **`NavigationTileWrapperProps`** — Props for the navigation wrapper component

### Component: `NavigationTileWrapper`
Wraps a notification tile so clicking its body navigates to the target entity (route or Mingo dialog). Inner `<button>` elements retain their own click handlers. Handles keyboard accessibility (`Enter`/`Space`).

## Usage Example

```typescript
// NavigationTileWrapper usage within a tile renderer
<NavigationTileWrapper
  notification={notification}
  helpers={{ onComplete, onSettle, liveDurationMs: 5000 }}
>
  <NotificationTile notification={notification} />
</NavigationTileWrapper>
```
