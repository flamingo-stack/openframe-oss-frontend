Provides a React hook for approving or rejecting Mingo AI tool-approval requests, surfacing toast notifications for both success and failure outcomes.

## Key Components

- **`useApproveRequest`** — Custom hook that returns a memoized async callback. Calls `POST /chat/api/v1/approval-requests/{id}/approve` via `apiClient` and displays a destructive or success toast based on the response.

## Usage Example

```typescript
import { useApproveRequest } from './use-approve-request';

function ApprovalActions({ requestId }: { requestId: string }) {
  const approveRequest = useApproveRequest();

  const handleApprove = async () => {
    const success = await approveRequest(requestId, true);
    if (success) {
      // e.g. mark notification as read, update local state
    }
  };

  const handleReject = async () => {
    await approveRequest(requestId, false);
  };

  return (
    <>
      <button onClick={handleApprove}>Approve</button>
      <button onClick={handleReject}>Reject</button>
    </>
  );
}
```

## Behavior Notes

| Scenario | Toast Variant | Return Value |
|---|---|---|
| Approval succeeds | `success` — "Approved" | `true` |
| Rejection succeeds | `success` — "Rejected" | `true` |
| API error | `destructive` — "Error" | `false` |

The hook delegates all follow-up logic (marking read, flipping UI state) to the caller via the boolean return, keeping the hook itself side-effect-free beyond toasting.
