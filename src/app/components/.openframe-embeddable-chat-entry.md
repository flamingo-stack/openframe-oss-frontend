Renders the Mingo AI chat panel inside OpenFrame's `AppLayoutDrawer`, wiring shared Zustand/React Query state, realtime subscriptions, context memory, and quick actions into the `EmbeddableChat` component without its built-in shell.

## Key Components

| Export / Import | Purpose |
|---|---|
| `OpenframeEmbeddableChatEntry` | Main component — mounts `EmbeddableChat` (shell-less) + `DialogSubscription` inside the host drawer |
| `useMingoUnifiedChatState` | Provides `state`, `subscription`, dialog management, and `sendInNewDialog` from the shared store/query cache |
| `DialogSubscription` | Rendered realtime tail — writes JetStream chunks into the shared store, replays on resubscribe |
| `useMingoLauncherStore` | Drains queued launcher prompts (e.g. onboarding "Meet Mingo" chips) into a fresh dialog on mount |
| `useMingoContextMemory` | Supplies the navigation-history strip shown above the composer |
| `useMingoQuickActions` | Maps admin-configured quick actions to `MingoQuickAction` chips for the empty state |

## Props

```typescript
interface OpenframeEmbeddableChatEntryProps {
  open: boolean;             // Controlled by AppLayoutDrawer
  onOpenChange: (open: boolean) => void; // Shared close handler
}
```

## Usage Example

```typescript
// Inside AppLayoutDrawer (host)
import { OpenframeEmbeddableChatEntry } from './openframe-embeddable-chat-entry';

function AppLayoutDrawer() {
  const [chatOpen, setChatOpen] = useState(false);

  return (
    <Drawer open={chatOpen} onOpenChange={setChatOpen}>
      <OpenframeEmbeddableChatEntry
        open={chatOpen}
        onOpenChange={setChatOpen}
      />
    </Drawer>
  );
}
```

## Key Behaviors

- **Shell-less rendering** — `shell="none"` delegates all chrome (positioning, close button) to the host drawer; `open`/`onOpenChange` stay in lockstep
- **State survives unmount** — Zustand + React Query live outside the component; drawer close/reopen rehydrates instantly without refetching
- **Mingo-only transport** — `modes={{}}` explicitly disables the lib's Guide (SSE) fallback; the built-in NATS adapter stays idle while `mingoState` drives everything
- **Context picker** — gated behind `featureFlags.mingoSidebarContext`; passing `undefined` disables `+`/`@` mentions and chips entirely
- **Launcher prompt drain** — `consumePendingPrompt` is idempotent; header opens and React StrictMode double-invokes are both safe no-ops
