Generates footer-button props for `EmptyState` components that link to section-specific onboarding guides in the in-app Help Center.

## Key Components

### `OnboardingGuideSource`
Union type enumerating all sections that may display an onboarding guide button: `'queries'`, `'customers'`, `'policies'`, `'scripts'`, `'script-schedules'`, `'logs'`, `'devices'`, `'tickets'`.

### `ONBOARDING_GUIDES`
Internal mapping from each `OnboardingGuideSource` to its `{ subject, slug }` — the section noun spliced into the label, and the Product Hub slug the Help Center route resolves by. Sections without an entry silently suppress the button; some sections intentionally share a guide (queries/policies, scripts/script-schedules).

### `onboardingGuideButton(source)`
Returns a `Pick<EmptyStateProps, 'buttonLabel' | 'buttonIcon' | 'buttonProps' | 'onButtonClick'>` object ready to spread into an `EmptyState`. Returns `{}` when the section has no guide configured.

| Parameter | Type | Description |
|-----------|------|-------------|
| `source` | `OnboardingGuideSource` | Section identifier |

## Usage Example

```typescript
import { onboardingGuideButton } from './onboarding-guide-button';

// Spread into EmptyState props
<EmptyState
  title="No customers yet"
  description="Add your first customer organization to get started."
  {...onboardingGuideButton('customers')}
/>

// Returns {} for a section with no guide — no button rendered
const noButton = onboardingGuideButton('worktime' as OnboardingGuideSource);
```

## Notes

- The label is always `Learn more about <subject>`, built from the map rather than passed in, so the wording stays identical across sections.
- The button icon is always `BookOpenIcon` with `text-ods-text-secondary` styling.
- The `href` is resolved via `routes.helpCenter.onboardingGuide(slug)`, keeping routing centralized.
- Adding a new section requires only a new entry in `ONBOARDING_GUIDES`.
