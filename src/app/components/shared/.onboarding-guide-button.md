Generates footer-button props for `EmptyState` components that link to section-specific onboarding guides in the in-app Help Center.

## Key Components

### `OnboardingGuideSource`
Union type enumerating all sections that may display an onboarding guide button: `'queries'`, `'customers'`, `'policies'`, `'scripts'`, `'script-schedules'`, `'logs'`, `'devices'`, `'tickets'`.

### `ONBOARDING_GUIDE_SLUGS`
Internal mapping from each `OnboardingGuideSource` to its Help Center article slug. Sections without a configured slug silently suppress the button.

### `onboardingGuideButton(source, label)`
Returns a `Pick<EmptyStateProps, 'buttonLabel' | 'buttonIcon' | 'buttonProps'>` object ready to spread into an `EmptyState`. Returns `{}` when the section has no slug configured.

| Parameter | Type | Description |
|-----------|------|-------------|
| `source` | `OnboardingGuideSource` | Section identifier |
| `label` | `string` | Button display text |

## Usage Example

```typescript
import { onboardingGuideButton } from './onboarding-guide-button';

// Spread into EmptyState props
<EmptyState
  title="No customers yet"
  description="Add your first customer organization to get started."
  {...onboardingGuideButton('customers', 'Learn more about Customers')}
/>

// Returns {} for unknown slugs — no button rendered
const noButton = onboardingGuideButton('tickets', 'Learn about Tickets');
// { buttonLabel, buttonIcon, buttonProps } if slug exists, {} otherwise
```

## Notes

- The button icon is always `BookOpenIcon` with `text-ods-text-secondary` styling.
- The `href` is resolved via `routes.helpCenter.onboardingGuide(slug)`, keeping routing centralized.
- Adding a new section requires only a new entry in `ONBOARDING_GUIDE_SLUGS`.
