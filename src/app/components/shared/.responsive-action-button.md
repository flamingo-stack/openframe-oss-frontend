Renders a responsive action button that displays an icon + label on desktop (`md+`) and collapses to an icon-only button on mobile, using CSS toggling to avoid SSR/hydration flicker.

## Key Components

### `ResponsiveActionButton`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | — | Desktop label text; doubles as `aria-label` on mobile |
| `icon` | `ReactNode` | — | Leading icon rendered at both breakpoints |
| `onClick` | `ButtonProps['onClick']` | — | Click handler |
| `variant` | `ButtonProps['variant']` | `'outline'` | Button style variant |
| `disabled` | `boolean` | — | Disables both buttons |
| `className` | `string` | — | Extra classes applied to both buttons |

## Usage Example

```typescript
import { ResponsiveActionButton } from './responsive-action-button';
import { PlusIcon } from 'lucide-react';

export function ToolbarActions() {
  return (
    <ResponsiveActionButton
      label="Add Device"
      icon={<PlusIcon className="size-4" />}
      variant="outline"
      onClick={() => console.log('clicked')}
    />
  );
}
```

## Notes

- Implemented as **two separate buttons** toggled via Tailwind's `md:` prefix (`hidden md:inline-flex` / `md:hidden`) — no JavaScript breakpoint detection, no hydration mismatch.
- The mobile button uses `size="icon"` and receives `aria-label={label}` for accessibility.
- Mirrors the icon-only pattern used in `PageActions` from `@flamingo-stack/openframe-frontend-core`.
