A slide-over drawer component for displaying log entry details, including a status tag, timestamp, structured info fields, and an optional pinned device card.

## Key Components

### `LogDrawer` (exported)

The primary drawer component. Renders an `AppLayoutDrawer` panel anchored to the right side of the screen with the following sections:

- **Header** — displays a fixed "Log Details" title, a `description`, and an optional `statusTag` + `timestamp` row
- **Body** — renders a vertical list of `infoFields` (value-on-top, label-below layout) and optionally pins a `DrawerDeviceCard` to the bottom

### `DrawerDeviceCard` (internal)

Fetches device details via `useDeviceDetails` and renders a `DeviceCard` with OS info, status, and a `DeviceDetailsButton`. Shows a `DeviceInfoSectionSkeleton` while loading.

### `LogDrawerInfoField` (exported interface)

```typescript
interface LogDrawerInfoField {
  label: string;
  value: string | React.ReactNode;
}
```

## Usage Example

```typescript
import { LogDrawer, type LogDrawerInfoField } from './log-drawer';

const fields: LogDrawerInfoField[] = [
  { label: 'Event Type', value: 'Authentication' },
  { label: 'Source IP', value: '192.168.1.10' },
];

<LogDrawer
  isOpen={drawerOpen}
  onClose={() => setDrawerOpen(false)}
  description="User login failed"
  statusTag={{ label: 'Error', variant: 'error' }}
  timestamp="2025-01-15 14:32:01"
  infoFields={fields}
  deviceId="device-abc-123"
/>
```

## Props

| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls drawer visibility |
| `onClose` | `() => void` | Called when the drawer is dismissed |
| `description` | `string` | Log event summary shown in the header |
| `statusTag` | `{ label, variant? }` | Optional status badge |
| `timestamp` | `string` | Optional formatted timestamp |
| `infoFields` | `LogDrawerInfoField[]` | Structured key-value fields rendered in the body |
| `deviceId` | `string` | If provided, pins a `DeviceCard` at the bottom of the drawer |
