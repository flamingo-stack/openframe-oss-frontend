Renders an icon component for a given device type string, mapping device categories to their corresponding icons from the `icons-v2` set.

## Key Components

### `renderDeviceTypeIcon(type?, className?)`

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `type` | `string` (optional) | — | Device type string (`'desktop'`, `'laptop'`, `'server'`, `'mobile'`, `'tablet'`) |
| `className` | `string` (optional) | `'w-6 h-6 text-ods-text-secondary'` | Tailwind CSS classes applied to the icon |

**Returns:** `React.ReactNode` — the matching icon component, or `undefined` for unknown/missing types (allowing callers to skip rendering gracefully).

Matching is case-insensitive via `.toLowerCase()`.

## Usage Example

```typescript
import { renderDeviceTypeIcon } from '@/components/device-type-icon';

// Basic usage — renders a MonitorIcon
const icon = renderDeviceTypeIcon('Desktop');

// Custom sizing
const largeIcon = renderDeviceTypeIcon('laptop', 'w-8 h-8 text-blue-500');

// Safe rendering — skip if type is unknown
const maybeIcon = renderDeviceTypeIcon(device.type);
if (maybeIcon) {
  return <span>{maybeIcon}</span>;
}
```
