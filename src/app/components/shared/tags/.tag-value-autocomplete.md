A multi-select autocomplete component for tag values that fetches suggestions based on a given tag key and supports free-form entry.

## Key Components

- **`TagValueAutocomplete`** — Main exported component that wraps the shared `Autocomplete` UI component with tag-value-specific behavior
- **`TagValueAutocompleteProps`** — Interface defining required `tagKey` and `values`/`onChange` controlled input props, plus optional `error`, `label`, and `className`
- **`useTagValueSuggestions`** — Custom hook (imported) that drives server-side option fetching, input debouncing, and input reset

## Usage Example

```typescript
import { TagValueAutocomplete } from './tag-value-autocomplete';

function TagFilter() {
  const [selectedValues, setSelectedValues] = useState<string[]>([]);

  return (
    <TagValueAutocomplete
      tagKey="environment"
      values={selectedValues}
      onChange={setSelectedValues}
      label="Environment Values"
      error={selectedValues.length === 0 ? 'Required' : undefined}
    />
  );
}
```

## Behavior Notes

- **`disableClientFilter`** — Delegates filtering to the server via `useTagValueSuggestions`, preventing the component from filtering already-fetched options locally
- **`creatable` + `freeSolo`** — Allows users to enter arbitrary values not present in suggestions
- **`resetInput`** — Called on every `onChange` to clear the search query after a value is selected
- **Placeholder** adapts dynamically: shows `"Add More..."` when values exist, otherwise `"Enter value..."`
