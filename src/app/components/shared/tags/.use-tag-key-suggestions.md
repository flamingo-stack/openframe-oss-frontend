Provides autocomplete suggestions for tag keys by fetching and debouncing search results via a refetchable Relay fragment.

## Key Components

- **`useTagKeySuggestions(currentKey, keySuggestionsRef)`** — Main hook that manages search input, debounced refetching, and autocomplete option construction for tag key fields.
- **`SUGGESTIONS_LIMIT`** — Caps returned suggestions at 20 results per query.
- **`DEBOUNCE_MS`** — 300ms debounce delay applied to search input before triggering a network refetch.

### Returned Values

| Property | Type | Description |
|---|---|---|
| `options` | `AutocompleteOption[]` | Merged list of fetched suggestions; prepends `currentKey` if not already present and input is empty |
| `isRefetching` | `boolean` | Deferred loading state to avoid UI flicker during rapid refetches |
| `handleInputChange` | `(value: string) => void` | Updates the controlled search input |
| `resetInput` | `() => void` | Clears the search input (e.g., on selection or dismiss) |

## Usage Example

```typescript
import { useTagKeySuggestions } from './use-tag-key-suggestions';

function TagKeyAutocomplete({ currentKey, keySuggestionsRef }) {
  const { options, isRefetching, handleInputChange, resetInput } =
    useTagKeySuggestions(currentKey, keySuggestionsRef);

  return (
    <Autocomplete
      options={options}
      loading={isRefetching}
      onInputChange={handleInputChange}
      onSelect={() => resetInput()}
    />
  );
}
```

> The hook uses React's `useTransition` alongside `useDeferredLoading` to prevent loading flicker, and `store-and-network` fetch policy to serve cached data immediately while refreshing in the background.
