Defines core TypeScript types and interfaces for the tagging system used across devices, tickets, and knowledge articles.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TagEntityType` | Union type | Constrains tags to supported entity contexts: `'DEVICE'`, `'TICKET'`, or `'KNOWLEDGE_ARTICLE'` |
| `TagEntry` | Interface | Minimal tag payload with a key and array of values |
| `TagEntryWithId` | Interface | Extends `TagEntry` with a unique identifier, used for persisted tag entries |
| `Tag` | Interface | Full tag record returned from the API, including optional metadata |

## Usage Example

```typescript
import type { Tag, TagEntry, TagEntryWithId, TagEntityType } from './types';

// Creating a new tag entry (pre-persist)
const newEntry: TagEntry = {
  key: 'environment',
  values: ['production', 'us-east'],
};

// Tag entry with server-assigned ID (post-persist)
const savedEntry: TagEntryWithId = {
  id: 'entry_abc123',
  key: 'environment',
  values: ['production'],
};

// Full tag record from API
const tag: Tag = {
  id: 'tag_xyz789',
  key: 'environment',
  description: 'Deployment environment label',
  color: '#FF5733',
  entityType: 'DEVICE' satisfies TagEntityType,
  createdAt: '2024-01-15T10:30:00Z',
};
```

## Notes

- `TagEntry` / `TagEntryWithId` represent input payloads (e.g., form submissions or batch operations), while `Tag` represents the full server-side record.
- All fields on `Tag` beyond `id` and `key` are optional, allowing partial responses or lightweight tag references.
