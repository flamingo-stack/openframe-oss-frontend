A form row component for editing a single tag entry (key + values), including validation logic and autocomplete suggestions for both tag keys and values.

## Key Components

### Exported Constants & Utilities

- **`TAG_REGEX`** — Regex pattern validating tag keys/values: alphanumeric, underscores, hyphens, starting with a letter or digit
- **`TAG_MAX_LENGTH`** — Maximum character length for tag keys/values (`64`)
- **`isValidTag(value)`** — Returns `true` if a string passes both length and regex checks
- **`validateTagKey(key)`** — Returns an error message string or `undefined` for a tag key
- **`validateTagValues(values)`** — Returns an error message string or `undefined` for an array of tag values

### `TagRow` Component

A client component rendering a responsive row with:
- **Key autocomplete** — Fetches server-side suggestions via `useTagKeySuggestions`, supports free-text entry
- **Value autocomplete** — Renders `TagValueAutocomplete` wrapped in `<Suspense>` (disabled while no key is selected)
- **Delete button** — Triggers `onDelete` with a trash icon
- **Duplicate key detection** — Inline error shown when the same key appears more than once
- **Label visibility** — Labels hidden on mobile for non-first rows via `labelClassName`

## Usage Example

```typescript
<TagRow
  tag={{ id: 'row-1', key: 'environment', values: ['production'] }}
  onChange={(updated) => updateTag('row-1', updated)}
  onDelete={() => removeTag('row-1')}
  existingKeys={['environment', 'region']}
  keySuggestionsRef={keySuggestionsFragmentRef}
  isFirst={true}
/>
```

> **Note:** `keySuggestionsRef` is a Relay fragment key of type `tagsEditor_keySuggestions$key`, sourced from a parent GraphQL query.
