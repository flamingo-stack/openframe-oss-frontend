Defines the shared view-model types used by the `PoliciesTable` component, normalizing divergent policy data sources (fleet-wide policies, per-device host policies, etc.) into a single table-consumable shape.

## Key Components

- **`PolicyTableAction`** — Re-exported type alias for a single ellipsis-menu item, derived from the core `MoreActionsMenu` component's `items` prop.
- **`PolicyStatusVariant`** — Union of allowed status badge color variants: `'success' | 'error' | 'warning' | 'critical' | 'grey'`.
- **`PolicyTableStatus`** — Status cell shape, including a display `label`, a `variant` for badge styling, and an optional `note` (secondary line, e.g. `"3 devices"`) with an error/warning tone.
- **`PolicyTableRow`** — Primary view-model interface. Callers map their own domain model into this shape so column rendering logic stays centralized.

| Field | Description |
|---|---|
| `id` | Stable row key |
| `name` / `description` | Display text |
| `critical` | Drives sort order and default severity label |
| `severityLabel` | Pre-formatted string for the Severity column |
| `status` | `PolicyTableStatus` for the Status column |
| `platforms` | Optional OS list, shown only when the Platform column is visible |
| `actions` | Optional ellipsis-menu items per row |
| `href` | Target for the open-in-new-tab button and optional row link |

## Usage Example

```typescript
import type { PolicyTableRow } from './policy-table-row';

const row: PolicyTableRow = {
  id: 'policy-42',
  name: 'Disk Encryption Required',
  critical: true,
  severityLabel: 'Critical',
  status: {
    variant: 'error',
    label: 'Failing',
    note: { text: '3 devices', tone: 'error' },
  },
  platforms: ['macOS', 'Windows'],
  href: '/policies/42',
};
```
