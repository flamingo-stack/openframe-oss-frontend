Renders a "Device Info" section displaying a device card with status, OS, and action buttons, supporting both prop-supplied and fetched device data.

## Key Components

- **`DeviceInfoSection`** — Main export. Accepts optional `deviceId`, `userId`, and `device` (partial device data). Prioritizes prop-supplied device data over fetched data; falls back to `useDeviceDetails` when only a `deviceId` is provided.
- **`DeviceInfoSectionProps`** — Interface defining the component's inputs; all fields are optional to support varied call sites (e.g., log panels, dialogs).
- **`DeviceCard`** — Renders the visual card with device name, organization, last-seen timestamp, OS icon, and status tag.
- **`DeviceDetailsButton`** — Injected as the card's details action button, linking to the full device detail view.
- **`DeviceInfoSectionSkeleton`** — Displayed during data fetch when no prop-supplied device is available.

## Usage Example

```typescript
// With a device ID only — fetches device details automatically
<DeviceInfoSection deviceId="device-abc123" />

// With pre-fetched/partial device data — skips network fetch
<DeviceInfoSection
  device={{
    id: 'device-abc123',
    displayName: 'MacBook Pro',
    status: 'online',
    osType: 'darwin',
    lastSeen: '2024-01-15T10:00:00Z',
  }}
/>

// Inside a log panel where both IDs and partial data may be present
<DeviceInfoSection
  deviceId="device-abc123"
  userId="user-xyz"
  device={logEntry.deviceSnapshot}
/>
```

## Behavior Notes

- Returns `null` when neither a `device` prop nor a `deviceId` is provided.
- Polling is explicitly disabled (`polling: false`) — data is fetched once on mount.
- The more/overflow button is hidden; only the details navigation button is shown.
