Renders a vertically centered empty state that dynamically fills the remaining height of the nearest `<main>` scroll container, with a `60vh` minimum floor.

## Key Components

### `EmptyState`

A wrapper around the core `NoData` component that measures available vertical space using a `ResizeObserver` and adjusts its `minHeight` so the empty state always fills down to the bottom of the scroll container. Falls back to `60vh` when the measured space is smaller.

**Props:** Re-exports `NoDataProps` from `@flamingo-stack/openframe-frontend-core` — pass all `NoData` props directly.

**Height resolution strategy:**

1. Locates the nearest `<main>` ancestor as the scroll container
2. Walks up the DOM to find the direct child of `<main>` as the `pageRoot`
3. Computes free space as `(scrollerBottom - scrollerPaddingBottom) - pageRootBottom`
4. Sets `minHeight: max(60vh, measuredHeight)` and recomputes on resize/layout changes

## Usage Example

```typescript
import { EmptyState } from '@/components/empty-state';

// Basic usage
<EmptyState
  title="No results found"
  description="Try adjusting your filters."
/>

// With action
<EmptyState
  title="No devices"
  description="Connect your first device to get started."
  action={{ label: 'Add device', onClick: handleAdd }}
/>
```

## Notes

- Uses `ResizeObserver` on both the scroller and `pageRoot` to stay current after dynamic layout changes
- Debounces updates with a `±1px` tolerance to avoid unnecessary re-renders
- Gracefully falls back to `window.innerHeight` when no `<main>` ancestor exists (e.g. outside the app shell)
