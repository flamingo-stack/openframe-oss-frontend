Defines the shared view-model types used by the `QueriesTable` component, normalizing disparate query models into a single display contract.

## Key Components

- **`QueryTableAction`** — Type alias for a single action item accepted by the core `MoreActionsMenu` ellipsis menu, derived via `ComponentProps` for type safety.
- **`QueryTableRow`** — Interface representing a normalized table row. Callers map their own query models into this shape so table column definitions remain centralized.

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Stable row identifier |
| `name` | `string` | Row display name |
| `description` | `string?` | Optional row description |
| `frequencyLabel` | `string` | Pre-formatted frequency text (e.g. `"Every 1h"`) |
| `actions` | `QueryTableAction[]?` | Optional ellipsis-menu action items |
| `href` | `string?` | URL for the open-in-new-tab button and optional row link |

## Usage Example

```typescript
import type { QueryTableRow } from './query-table-row';

const row: QueryTableRow = {
  id: 'query-123',
  name: 'CPU Usage Check',
  description: 'Monitors CPU utilization across all endpoints',
  frequencyLabel: 'Every 1h',
  href: '/queries/query-123',
  actions: [
    { label: 'Edit', onSelect: () => openEditor('query-123') },
    { label: 'Delete', onSelect: () => deleteQuery('query-123') },
  ],
};
```

Callers implementing a new query table only need to map their domain model to `QueryTableRow`; the shared table handles all rendering and column layout automatically.
