Reusable data table component for displaying OSQuery monitoring queries, shared between the fleet-wide monitoring page and per-device Queries tab.

## Key Components

### `formatQueryInterval(seconds: number): string`
Converts a schedule interval in seconds to a human-readable label (e.g. `0` → `"Manual"`, `3600` → `"Every 1h"`).

### `QueriesTable`
The primary table component. Renders a `QueryTableRow[]` with a fixed column layout:

| Column | Description |
|---|---|
| **Name** | Query name with optional truncated description |
| **Frequency** | Human-readable interval label, hidden on `md` breakpoint |
| **Actions** | `MoreActionsMenu` dropdown, rendered only when rows carry actions |
| **Open** | External link button (opens `href` in new tab), hidden on `md` breakpoint |

### `QueriesTableProps`
| Prop | Type | Description |
|---|---|---|
| `rows` | `QueryTableRow[]` | Normalized row data |
| `isLoading` | `boolean` | Shows skeleton rows |
| `emptyState` | `NoDataProps` | Rich empty state, overrides `emptyMessage` |
| `rowAsLink` | `boolean` | Makes each row navigate to its `href` |
| `hasMore` / `onLoadMore` | `boolean` / `() => void` | Enables infinite scroll footer |

## Usage Example

```typescript
import { QueriesTable, formatQueryInterval } from './queries-table';

const rows = [
  {
    id: 'q1',
    name: 'Running Processes',
    description: 'Lists all active processes',
    frequencyLabel: formatQueryInterval(300),
    href: '/queries/q1',
    actions: [{ label: 'Edit', onClick: () => {} }],
  },
];

<QueriesTable
  rows={rows}
  isLoading={false}
  rowAsLink
  stickyHeader
  emptyState={{ icon: SearchIcon, title: 'No queries', description: 'Add a query to get started' }}
  hasMore={hasNextPage}
  onLoadMore={fetchNextPage}
/>
```

> **Note:** The actions column is reserved during loading to prevent column-count jitter when transitioning from skeleton to loaded state.
