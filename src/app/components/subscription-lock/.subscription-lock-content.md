Renders the subscription management UI as a full-page overlay when a tenant is locked out of the application (e.g., trial expired or subscription canceled).

## Key Components

- **`SubscriptionLockContent`** — Client component that wraps `SubscriptionSettingsView` in a `Suspense` boundary, using `SubscriptionSettingsSkeleton` as the loading fallback. The underlying view adapts its header and CTA via context to display lock-state-specific messaging (e.g., "trial has ended" banner).

## Usage Example

```typescript
// Rendered by the lock-gate layout when tenant access is restricted
import { SubscriptionLockContent } from './subscription-lock-content';

export default function LockedLayout() {
  return (
    <main>
      <SubscriptionLockContent />
    </main>
  );
}
```

## Notes

- Reuses `SubscriptionSettingsView` directly — no duplicate data fetching or card components. Lock-specific UI differences (banner, CTA label) are handled inside `SubscriptionSettingsView` via subscription lock context.
- The `Suspense` boundary ensures async data loading within `SubscriptionSettingsView` (e.g., billing plan fetches) shows a skeleton rather than a blank screen.
