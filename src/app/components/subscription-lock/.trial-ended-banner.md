Renders a banner UI component displayed when a user's trial period has ended, showing a title and description sourced from subscription lock copy.

## Key Components

- **`TrialEndedBanner`** — Client component that displays a styled heading and description using `SubscriptionLockCopy` data.
- **`TrialEndedBannerProps`** — Interface accepting a `lockCopy` prop of type `SubscriptionLockCopy`.

## Usage Example

```typescript
import { TrialEndedBanner } from './trial-ended-banner';

const lockCopy = {
  title: 'Your trial has ended',
  description: 'Upgrade your plan to continue using OpenFrame.',
};

<TrialEndedBanner lockCopy={lockCopy} />
```

## Notes

- Marked as a Next.js Client Component (`'use client'`).
- Relies on `SubscriptionLockCopy` type from [`subscription-status`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/subscription-status.ts) for its copy data.
- Styled with ODS (OpenFrame Design System) utility classes (`text-ods-text-primary`, `text-ods-text-secondary`).
