Provides a React context for managing subscription lock state, exposing lock status and copy to any component in the tree without prop drilling.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SubscriptionLockProvider` | Component | Wraps a subtree with subscription lock state derived from a `SubscriptionStatus` value |
| `useSubscriptionLock` | Hook | Consumes the lock context; returns a safe default (`ACTIVE`, unlocked) when used outside a provider |
| `SubscriptionLockState` | Interface | Internal shape: `status`, `lockCopy`, and `isLocked` boolean |

## Usage Example

```typescript
// Wrap your layout or page with the provider
import { SubscriptionLockProvider } from './subscription-lock-context';

export default function Layout({ children }: { children: React.ReactNode }) {
  const status = useCurrentSubscriptionStatus(); // your own data fetch
  return (
    <SubscriptionLockProvider status={status}>
      {children}
    </SubscriptionLockProvider>
  );
}

// Consume in any child component
import { useSubscriptionLock } from './subscription-lock-context';

export function FeatureGate({ children }: { children: React.ReactNode }) {
  const { isLocked, lockCopy } = useSubscriptionLock();

  if (isLocked) {
    return <LockedBanner message={lockCopy?.heading} />;
  }
  return <>{children}</>;
}
```

## Notes

- `getLockCopy` drives the `isLocked` flag — a `null` return means the subscription is active and unlocked.
- The context value is memoized on `status`, so re-renders are minimised.
- `useSubscriptionLock` never throws; components outside the provider receive a safe `ACTIVE` default, making the hook safe to use in shared/library components.
