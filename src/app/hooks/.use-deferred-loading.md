A React hook that prevents loading state flicker by delaying loader appearance and enforcing a minimum visible duration.

## Key Components

### `useDeferredLoading(isLoading, options?): boolean`

Main export. Accepts a boolean loading state and optional configuration, returns a derived boolean that controls whether a loader should actually render.

**Options (`UseDeferredLoadingOptions`):**

| Option | Default | Description |
|---|---|---|
| `delayMs` | `150` | Suppress loader if loading completes before this threshold |
| `minDurationMs` | `300` | Keep loader visible for at least this long once shown |

**Behavior by case:**

1. **Fast response** (`< delayMs`): Loader never appears
2. **Medium response** (`delayMs` to `delayMs + minDurationMs`): Loader stays until minimum duration elapses
3. **Slow response** (`> delayMs + minDurationMs`): Loader hides immediately when loading ends

## Usage Example

```typescript
import { useDeferredLoading } from './use-deferred-loading';

function DataTable({ isLoading }: { isLoading: boolean }) {
  const showLoader = useDeferredLoading(isLoading, {
    delayMs: 200,       // Only show loader if fetch takes > 200ms
    minDurationMs: 400, // Keep loader visible for at least 400ms
  });

  if (showLoader) return <Spinner />;
  return <Table />;
}
```

## Notes

- Timers are properly cleaned up on unmount via a dedicated effect
- Re-entrant safe: if a new load starts while a loader is already visible, the show timer is not rescheduled
- Uses `useRef` for timer handles and shown-state tracking to avoid stale closure issues
