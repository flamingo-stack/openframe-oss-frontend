Bridges a controlled search input to a URL/query parameter, preventing race conditions that would erase characters typed while a fetch is in flight.

## Key Components

### `useSearchParam(paramValue, onDebouncedChange, delay?)`

Main hook that manages bidirectional sync between a local input state and an external URL/query param.

| Parameter | Type | Description |
|---|---|---|
| `paramValue` | `string` | Current value of the URL/query param |
| `onDebouncedChange` | `(value: string) => void` | Callback to write the debounced value back to the param |
| `delay` | `number` | Debounce delay in ms (default: `300`) |

### `UseSearchParamResult`

| Field | Type | Description |
|---|---|---|
| `search` | `string` | Controlled value for the search input — updates instantly |
| `setSearch` | `(value: string) => void` | Updates the input immediately |
| `debouncedSearch` | `string` | Debounced value to pass to queries |

**Sync direction logic:**

- **UP** — debounced input changes push to the param via `onDebouncedChange`; skips writes when the value hasn't changed to avoid clobbering unrelated params during navigation
- **DOWN** — external param changes (browser back/forward) sync back into the input; own echoes are ignored via `lastSyncedRef`

## Usage Example

```typescript
import { useSearchParam } from './use-search-param';
import { useApiParams } from '@/hooks/use-api-params';

function DeviceSearch() {
  const [params, setParam] = useApiParams();

  const { search, setSearch, debouncedSearch } = useSearchParam(
    params.search ?? '',
    (value) => setParam('search', value),
  );

  // Pass debouncedSearch to your query, search/setSearch to the input
  const { data } = useDevicesQuery({ search: debouncedSearch });

  return (
    <input
      value={search}
      onChange={(e) => setSearch(e.target.value)}
      placeholder="Search devices..."
    />
  );
}
```
