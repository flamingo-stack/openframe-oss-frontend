Provides safe browser back-navigation utilities for Next.js, using the Navigation API (`window.navigation.canGoBack`) to avoid no-ops or cross-origin escapes when calling `router.back()`.

## Key Components

| Export | Type | Description |
|---|---|---|
| `navCanGoBack()` | Function | Probes `window.navigation.canGoBack` defensively; returns `false` in SSR, unsupported browsers, or when no safe back entry exists |
| `useSafeBack(fallback)` | React Hook | Returns a memoized handler that calls `router.back()` when safe, otherwise `router.push(fallback)` |
| `safeBackOrReplace(router, fallback)` | Function | Imperative variant for post-save flows; uses `router.replace(fallback)` so the form is excluded from history |

## Usage Example

```typescript
// Hook usage — e.g. a Cancel button in an edit form
'use client';
import { useSafeBack } from '@/hooks/use-safe-back';

export function EditForm() {
  const handleCancel = useSafeBack('/dashboard');
  return <button onClick={handleCancel}>Cancel</button>;
}
```

```typescript
// Imperative usage — e.g. after a successful form submit
import { safeBackOrReplace } from '@/hooks/use-safe-back';
import { useRouter } from 'next/navigation';

export function SaveButton() {
  const router = useRouter();
  const handleSave = async () => {
    await submitForm();
    safeBackOrReplace(router, '/dashboard');
  };
  return <button onClick={handleSave}>Save</button>;
}
```

## Behavior Matrix

| Scenario | `useSafeBack` | `safeBackOrReplace` |
|---|---|---|
| Same-origin history entry exists | `router.back()` | `router.back()` |
| Fresh tab / direct URL paste | `router.push(fallback)` | `router.replace(fallback)` |
| Unsupported browser / SSR | `router.push(fallback)` | `router.replace(fallback)` |

> **Why `replace` in `safeBackOrReplace`?** After a form submit, `replace` removes the form from the history stack so pressing back from the destination returns the user to the page *before* the form, not back into it.
