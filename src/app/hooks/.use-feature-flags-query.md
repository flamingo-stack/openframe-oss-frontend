A React Query hook that fetches frontend feature flags from the GraphQL API and synchronizes the results into the global feature flags Zustand store.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `featureFlagsQueryKey` | `const` | Stable query key `['featureFlags']` for cache identification and manual invalidation |
| `useFeatureFlagsQuery` | `function` | Hook that fetches, caches, and syncs feature flags to the global store |
| `FeFeatureFlagsResponse` | `interface` | Internal type describing the GraphQL response shape |

**Behavior details:**

- **Cache**: 30-minute `staleTime`, no refetch on window focus, single retry on failure
- **Store sync**: On success, calls `setFlags()` to populate the Zustand store; on error, calls `setLoaded()` to unblock dependent UI with default flag values
- **Trial detection**: Passes GraphQL errors through `detectTrialExpiredFromGraphqlErrors` before throwing, enabling subscription-lock side effects

## Usage Example

```typescript
// Typically called once near the app root after authentication is confirmed
function AppBootstrap({ isAuthenticated }: { isAuthenticated: boolean }) {
  const { isLoading } = useFeatureFlagsQuery({ enabled: isAuthenticated });

  if (isLoading) return <Spinner />;
  return <App />;
}

// Consuming flags elsewhere via the store directly
import { useFeatureFlagsStore } from '@/stores/feature-flags-store';

function MyComponent() {
  const flags = useFeatureFlagsStore(s => s.flags);
  const isEnabled = flags['my-feature']?.enabled ?? false;
  return isEnabled ? <NewFeature /> : <LegacyFeature />;
}
```
