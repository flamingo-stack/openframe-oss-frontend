Renders a "Full Information" section displaying structured log entry details in a card layout, with graceful handling for missing data.

## Key Components

- **`FullInformationSectionProps`** — accepts an optional `logDetails` prop of type `LogEntry | null`
- **`LogEntry`** — interface representing a log event with fields: `toolEventId`, `eventType`, `ingestDay`, `toolType`, `severity`, `timestamp`, and optional `userId`, `deviceId`, `message`, `details`
- **`FullInformationSection`** — main exported component; maps log fields to `InfoCardData` items and renders them via `InfoCard`; conditionally includes `userId` and `deviceId` only when present; displays a `ToolIcon` alongside the tool type label

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section';

const logEntry = {
  toolEventId: 'evt-001',
  eventType: 'alert',
  ingestDay: '2024-01-15',
  toolType: 'connectwise',
  severity: 'high',
  userId: 'user-42',
  timestamp: '2024-01-15T10:30:00Z',
};

<FullInformationSection logDetails={logEntry} />

// Empty state
<FullInformationSection logDetails={null} />
```

## Notes

- Uses `toToolLabel` and `normalizeToolTypeWithFallback` from `openframe-frontend-core/utils` for display-safe tool type rendering
- Timestamp formatting delegates to `formatDateTime` with a raw-string fallback on parse error
- Optional fields (`userId`, `deviceId`) are conditionally spread into the items array to avoid empty rows in the card
