React hook for fetching and managing a single log entry's details via GraphQL, with loading state, error handling, and toast notifications.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useLogDetails` | Hook | Manages log detail fetching state and exposes fetch/clear actions |
| `fetchLogDetailsById` | `async (logId, ingestDay, toolType, eventType, timestamp) => LogEntry` | Fetches a specific log entry using `GET_LOG_DETAILS_QUERY` |
| `clearLogDetails` | `() => void` | Resets `logDetails` and `error` state to `null` |

**State returned:**

| Field | Type | Description |
|-------|------|-------------|
| `logDetails` | `LogEntry \| null` | The fetched log entry |
| `isLoading` | `boolean` | True while the GraphQL request is in-flight |
| `error` | `string \| null` | Error message if the last fetch failed |

## Usage Example

```typescript
import { useLogDetails } from './use-log-details';

function LogDetailPanel({ logId }: { logId: string }) {
  const { logDetails, isLoading, error, fetchLogDetailsById, clearLogDetails } =
    useLogDetails();

  useEffect(() => {
    fetchLogDetailsById(
      logId,
      '2024-01-15',
      'connectwise',
      'ticket.created',
      '2024-01-15T10:30:00Z'
    );

    return () => clearLogDetails();
  }, [logId]);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;
  return <pre>{JSON.stringify(logDetails, null, 2)}</pre>;
}
```

> On error, the hook both sets the `error` string and fires a destructive toast, so callers do not need to handle notifications manually.
