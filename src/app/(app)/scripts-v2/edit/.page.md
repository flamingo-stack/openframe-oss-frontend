Wrapper page component for the Script V2 edit route that extracts and validates the required `id` URL parameter before rendering the edit UI.

## Key Components

- **`EditScriptV2PageWrapper`** — Default export; a client-side page component that resolves the script ID from the URL and conditionally renders the edit view.
- **`useRequiredIdParam`** — Hook that reads the `id` route param, redirecting to the new-script route (`routes.scriptsV2.new`) if the param is absent or invalid.
- **`EditScriptPage`** — The underlying edit form/UI, rendered only when a valid `scriptId` is available.

## Usage Example

This component is mounted automatically by Next.js at the `/scripts-v2/[id]/edit` route. No manual instantiation is needed, but the underlying building blocks can be composed as follows:

```typescript
// Equivalent manual composition (for reference)
import { useRequiredIdParam } from '@/app/hooks/use-required-id-param';
import { routes } from '@/lib/routes';
import { EditScriptPage } from '../../scripts/v2/components/edit-script-page';

function MyEditWrapper() {
  const id = useRequiredIdParam('/scripts-v2', routes.scriptsV2.new);
  if (!id) return null;           // redirects handled inside the hook
  return <EditScriptPage scriptId={id} />;
}
```

**Redirect behaviour:** if the `id` param is missing, `useRequiredIdParam` navigates the user to `routes.scriptsV2.new`, preventing the edit page from rendering with an undefined script ID.
