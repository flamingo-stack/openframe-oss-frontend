A Next.js client-side page component that renders the V2 schedule details view, extracting the schedule ID from the URL's query parameters.

## Key Components

- **`ScheduleDetailsV2Page`** — Default export; a client component that reads the `id` query parameter and passes it to the detail view.
- **`ScheduleDetailsView`** — Imported from the V2 scripts components; handles all rendering logic for a given `scheduleId`.

## Usage Example

```typescript
// Navigating to this page with a schedule ID:
// /scripts/v2/schedule-details?id=abc123

// The component extracts "abc123" and renders:
<ScheduleDetailsV2Page />
// Internally resolves to:
<ScheduleDetailsView scheduleId="abc123" />
```

## Notes

- Uses `'use client'` directive — rendered on the client side only.
- If the `id` query parameter is absent, `scheduleId` defaults to an empty string (`''`).
- Page routing and query param parsing are handled via Next.js's `useSearchParams` hook.
