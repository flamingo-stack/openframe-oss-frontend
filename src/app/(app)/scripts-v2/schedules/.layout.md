A Next.js layout component that guards all `/scripts-v2/schedules/*` routes behind the `script-schedules` feature flag, redirecting unauthorized users to the Scripts list.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ScriptSchedulesLayout` | Default export | Route-level feature flag gate for script schedules routes |

**Dependencies:**

- `useFeatureFlagsStore` — subscribes to the resolved `script-schedules` flag from the Zustand store
- `featureFlags.scriptSchedules.enabled()` — env-var fallback when the server value is unavailable
- `routes.scriptsV2.list` — redirect target when the flag is disabled

## Usage Example

```typescript
// app/scripts-v2/schedules/layout.tsx (this file)
// Wraps all child routes under /scripts-v2/schedules/*
export default function ScriptSchedulesLayout({ children }: { children: React.ReactNode }) {
  // Reads server-resolved flag; falls back to env-var default
  const serverValue = useFeatureFlagsStore(s => (s.isLoaded ? s.flags['script-schedules'] : undefined));
  const enabled = serverValue ?? featureFlags.scriptSchedules.enabled();

  // Redirect and render nothing when flag is off
  useEffect(() => {
    if (!enabled) router.replace(routes.scriptsV2.list);
  }, [enabled, router]);

  if (!enabled) return null;
  return <>{children}</>;
}
```

## Behavior Notes

- **No flash:** Feature flags are guaranteed resolved before children render via `FeatureFlagsGate`, so the gate evaluates synchronously on mount
- **Nested gate:** Acts as a sub-gate inside the parent `scripts-v2` layout gate (`../layout.tsx`)
- **Reactivity:** Subscribes to the store so the gate re-evaluates if flag values change at runtime
- **UI parity:** The "Scripts Schedules" tab is hidden via the same flag in `scripts-v2-tabs.tsx`, keeping navigation consistent
