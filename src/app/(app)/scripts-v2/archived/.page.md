A Next.js client-side page component that renders the archived scripts view using the `ScriptsTable` component.

## Key Components

- **`ArchivedScriptsV2Page`** — Default export page component that displays a filtered list of archived scripts by passing the `archived` prop to `ScriptsTable`.

## Usage Example

```typescript
// Rendered automatically by Next.js routing.
// Equivalent to navigating to the archived scripts route.
import ArchivedScriptsV2Page from './page';

// The page renders:
<ScriptsTable archived />
```

## Notes

- Uses the `'use client'` directive, marking this as a React Client Component.
- Delegates all rendering logic to [`ScriptsTable`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/scripts/v2/components/scripts-table.tsx) — the `archived` boolean prop toggles the archived filter within that component.
