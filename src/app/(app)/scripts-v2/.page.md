Renders the Scripts V2 list page, composing the tab navigation and scripts table into a full-page layout.

## Key Components

- **`ScriptsV2Page`** — Default export; client-side page component that assembles the Scripts V2 view with the `"list"` tab active
- **`ScriptsV2TabNavigation`** — Tab bar rendered at the top of the page with `activeTab` set to `"list"`
- **`ScriptsTable`** — Main content area displaying the paginated/filterable scripts data table

## Usage Example

This is a Next.js App Router page component — it is automatically served at the route corresponding to its location in the `app/` directory. No manual instantiation is needed.

```typescript
// Rendered automatically by Next.js at the /scripts/v2 route.
// The component itself requires no props:
<ScriptsV2Page />
```

To navigate to this page programmatically:

```typescript
import { useRouter } from 'next/navigation';

const router = useRouter();
router.push('/scripts/v2');
```

## Notes

- Marked `'use client'` — runs in the browser; any data fetching should be handled inside `ScriptsTable` or via client-side hooks
- `activeTab="list"` highlights the list tab in `ScriptsV2TabNavigation`; other tab values (e.g. `"create"`, `"history"`) would point to sibling pages
