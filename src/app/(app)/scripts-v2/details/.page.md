A Next.js client-side page component that renders the v2 script details view, extracting the script ID from the URL's search parameters.

## Key Components

- **`ScriptDetailsV2Page`** — Default export page component that reads the `id` query parameter and passes it to the details view

## Usage Example

```typescript
// Accessed via URL: /scripts/v2/details?id=<scriptId>
// Renders: <ScriptDetailsView scriptId="<scriptId>" />
```

## Notes

- Uses `'use client'` directive — requires client-side rendering for `useSearchParams`
- Falls back to an empty string (`''`) if no `id` param is present
- Delegates all rendering logic to [`ScriptDetailsView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/scripts/v2/components/script-details-view.tsx)
