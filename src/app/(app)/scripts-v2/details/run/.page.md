A Next.js client-side page component that renders the script execution interface for a specific script, extracting the script ID from the URL's query parameters.

## Key Components

- **`RunScriptV2Page`** – Default export; a client component that reads the `id` query parameter and passes it to the script runner view.

## Usage Example

```typescript
// Accessed via URL: /path/to/run-script-v2?id=<scriptId>
// The component reads `id` from search params and delegates rendering to RunScriptView.

import RunScriptV2Page from './page';

// Rendered automatically by Next.js App Router at the matching route.
// No props required — the script ID is sourced from the URL query string.
<RunScriptV2Page />
```

## Notes

- Marked as `'use client'` — runs in the browser only.
- If the `id` query parameter is absent, it defaults to an empty string (`''`).
- Delegates all rendering and logic to [`RunScriptView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/scripts/v2/components/run-script-view.tsx), keeping this page thin and focused solely on routing concerns.
