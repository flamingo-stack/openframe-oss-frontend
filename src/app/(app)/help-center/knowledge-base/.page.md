Root page component for the knowledge base documentation hub, rendering the docs view at the root path (`docPath = ""`).

## Key Components

- **`KnowledgeBasePage`** — Default export; a Next.js page component that mounts `KnowledgeBaseDocsView` at the root of the knowledge base route with an empty `docPath`.

## Usage Example

```typescript
// Automatically rendered by Next.js at the /knowledge-base route.
// Deep links to individual docs are handled by the sibling [...path] route:
// e.g. /knowledge-base/getting-started → docPath = "getting-started"

import KnowledgeBasePage from './page';

// No props required — used directly as a Next.js page
<KnowledgeBasePage />
```

## Notes

- Delegates all rendering to [`KnowledgeBaseDocsView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/knowledge-base/knowledge-base-docs-view.tsx) with `docPath=""`.
- The sibling `[...path]` dynamic route handles deep links into individual docs, passing the resolved path segments as `docPath`.
