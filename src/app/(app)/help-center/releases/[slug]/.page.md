Defines the Next.js static route for individual release detail pages, prerendering a single placeholder shell to satisfy `output: 'export'` requirements while delegating actual rendering to the client component.

## Key Components

- **`generateStaticParams`** — Returns a single `{ slug: 'index' }` placeholder to satisfy Next.js static export constraints; real release slugs are resolved at runtime via the SPA fallback
- **`ReleaseDetailRoute`** — Default page export that renders [`ReleaseDetailClient`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/releases/[slug]/release-detail-client.tsx)

## Usage Example

```typescript
// Next.js automatically calls generateStaticParams at build time
// Real slug routing is handled by the SPA fallback at runtime
export function generateStaticParams(): { slug: string }[] {
  return [{ slug: 'index' }]; // placeholder shell only
}
```

> **Note:** Release slugs are runtime/CMS content and cannot be enumerated at build time. See [`docs/static-export-migration.md`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/docs/static-export-migration.md) for the full rationale behind this pattern.
