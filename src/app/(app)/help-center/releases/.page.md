Mounts the product releases list page within the Help Center section by rendering the shared `<ProductReleasesListPage>` component from the core library.

## Key Components

- **`ReleasesRoute`** — Default export; a thin route component that wires the library's `ProductReleasesListPage` to the app's endpoint config and navigation paths.

## Props Passed to `ProductReleasesListPage`

| Prop | Value | Purpose |
|---|---|---|
| `shell` | `false` | Disables the library's own shell/layout wrapper |
| `releasesEndpoint` | `EP.productReleases` | API endpoint for fetching release data |
| `basePath` | `HELP_CENTER_BASE + /releases` | Fallback URL prefix for card → detail navigation |
| `backButton` | `{ label, href }` | Breadcrumb link back to the Help Center root |

## Usage Example

```typescript
// Rendered automatically by Next.js at:
// /help-center/releases

// Card navigation resolves to:
// /help-center/releases/<slug>  (via composeContentUrl for hosted product_release type)

// To override the back destination:
<ProductReleasesListPage
  shell={false}
  releasesEndpoint={EP.productReleases}
  basePath={`${HELP_CENTER_BASE}/releases`}
  backButton={{ label: 'Back to Help Center', href: HELP_CENTER_BASE }}
/>
```
