Provides a nested `ChatRuntime` override for the `/help-center` subtree, switching navigation to `'host'` mode and scoping content URLs and endpoints to the help center section while preserving parent chat configuration.

## Key Components

- **`HelpCenterRuntimeProvider`** — Client component that wraps the `/help-center` route subtree. Reads the parent `ChatRuntimeContext`, composes a new `ChatRuntime` with `navigation.mode: 'host'` and `composeOpenframeContentUrl`, then re-provides it alongside `HELP_CENTER_ENDPOINTS`.
- **`composeOpenframeContentUrl`** — Imported content URL factory (from `help-center-content-href.ts`) that maps content card types to relative `/help-center/...` hrefs for hosted surfaces and falls back to the Flamingo content hub for others.
- **`HELP_CENTER_ENDPOINTS`** — Stable module constant injected into `EndpointsRuntimeContext` so the `<ContactForm>` component can call `useRequiredEndpointsRuntime()` without throwing.
- **Feature flag gate** — Calls `featureFlags.helpCenter.enabled()` before rendering; invokes `notFound()` to close the entire subtree if the flag is off.

## Usage Example

Mount as a layout wrapper for the `/help-center` route segment:

```typescript
// app/help-center/layout.tsx
import { HelpCenterRuntimeProvider } from './help-center-runtime-provider';

export default function HelpCenterLayout({ children }: { children: React.ReactNode }) {
  return (
    <HelpCenterRuntimeProvider>
      {children}
    </HelpCenterRuntimeProvider>
  );
}
```

> **Note:** The parent `OpenframeChatRuntimeProvider` must be present higher in the tree. `HelpCenterRuntimeProvider` spreads the parent runtime via `useContext(ChatRuntimeContext)`, overriding only `navigation` and `composeContentUrl` — chat endpoints, auth, and image proxy are inherited unchanged.
