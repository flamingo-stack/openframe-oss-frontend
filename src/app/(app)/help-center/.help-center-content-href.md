Defines the single source of truth for routing content entity cards in OpenFrame, mapping content types to either in-app `/help-center` routes or external Flamingo content hub URLs across both the help center page subtree and the chat drawer.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `composeOpenframeContentUrl` | `ComposeContentUrl` | Primary URL composer returning relative in-app hrefs for hosted types (`onboarding_guide`, `product_release`) and absolute hub URLs for all others |
| `composeOpenframeChatContentUrl` | `ComposeContentUrl` | Chat-specific wrapper that keeps `/help-center/*` hrefs relative (to avoid cross-origin new-tab misfires) and absolutizes all other hub content to `flamingo.run` |
| `isInAppHelpCenterHref` | `function` | Predicate returning `true` if an href resolves under `/help-center` |

**Internal helpers:**

- `isAbsoluteHref` — detects `https://` or `//` prefixed URLs
- `toHubOriginHref` — forces relative RAG-returned `externalUrl`s onto the content hub origin
- `helpCenterTicketHref` — builds deep-link hrefs for all HubSpot ticket card variants (`hubspot_ticket`, `hubspot_ticket_anon`, `hubspot_ticket_self`)

**Hosted in-app types** (detail routes under `/help-center`): `onboarding_guide`, `product_release`

**List-filter overrides** (no detail route, uses `?search=<id>`): `roadmap_item`, `delivery_item`

**Special overrides**: `hubspot_ticket*` → tickets list drawer; `faq` → FAQ anchor hash

## Usage Example

```typescript
// In the help-center page subtree (host mode) — returns relative href
const result = composeOpenframeContentUrl({
  type: 'product_release',
  slug: 'v2-launch',
  id: '123',
});
// → { href: '/help-center/releases/detail?slug=v2-launch', targetPlatform: null }

// In the chat drawer (embed mode) — non-hosted types get absolutized
const chatResult = composeOpenframeChatContentUrl({
  type: 'blog_post',
  slug: 'my-post',
  id: '456',
  externalUrl: 'blog/my-post',
});
// → { href: 'https://www.flamingo.run/blog/my-post', targetPlatform: null }

// Guard used by chat nav to decide soft-nav vs external open
isInAppHelpCenterHref('/help-center/roadmap?search=item-1'); // true
isInAppHelpCenterHref('https://www.flamingo.run/blog/post'); // false
```

> **Why two composers?** The help-center page subtree and the app-wide chat drawer share the same type→route mapping but differ in how they handle non-hosted content. Encoding the split here means adding a newly in-app-hosted content type automatically updates routing in both contexts with a single edit.
