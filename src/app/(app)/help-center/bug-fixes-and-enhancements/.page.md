Mounts the **Bug-fixes & Enhancements** delivery page by rendering the shared `<DeliveryPage>` component from the core library, wiring it to the local API endpoints for completed and in-progress delivery items.

## Key Components

| Export | Type | Description |
|---|---|---|
| `BugFixesAndEnhancementsRoute` | `default` React component | Page entry point for the Bug-fixes & Enhancements route |

**Dependencies:**

- `DeliveryPage` — pre-built page component from `@flamingo-stack/openframe-frontend-core` that handles chrome, search/task-type filtering, and dual self-fetching tables (completed + active)
- `EP` — local endpoint constants supplying `deliveryCompleted` and `deliveryInProgress` API routes
- `HELP_CENTER_BASE` — base path used for the back-navigation button

## Usage Example

```typescript
// Typical Next.js App Router usage — drop this file at:
// app/help-center/bug-fixes-and-enhancements/page.tsx

import { EP, HELP_CENTER_BASE } from '../endpoints';
import { DeliveryPage } from '@flamingo-stack/openframe-frontend-core/components/help-center-pages';

export default function BugFixesAndEnhancementsRoute() {
  return (
    <DeliveryPage
      shell={false}
      completedEndpoint={EP.deliveryCompleted}
      inProgressEndpoint={EP.deliveryInProgress}
      backButton={{ label: 'Back to Help Center', href: HELP_CENTER_BASE }}
    />
  );
}
```

## Notes

- `shell={false}` delegates layout/chrome ownership to the parent route shell, avoiding double-wrapping.
- All data-fetching logic lives inside `<DeliveryPage>`; this file is intentionally thin — its only responsibility is supplying the two endpoint URLs and back-button config.
- See [`endpoints.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/help-center/endpoints.ts) for the `EP` and `HELP_CENTER_BASE` definitions.
