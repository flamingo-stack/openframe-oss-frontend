Renders the onboarding guide detail route page, delegating UI to the client component while providing a static placeholder for Next.js static export compatibility.

## Key Components

- **`generateStaticParams`** — Returns a single `{ slug: 'index' }` placeholder to satisfy Next.js `output: 'export'` requirements. Real guide slugs are resolved at runtime via the native shell's SPA fallback rather than being pre-enumerated at build time.
- **`OnboardingGuideDetailRoute`** — Default page export that renders [`OnboardingGuideDetailClient`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/onboarding-guide/[slug]/onboarding-guide-detail-client.tsx).

## Usage Example

This file is a Next.js App Router page at `app/onboarding-guide/[slug]/page.tsx`. It is consumed automatically by the Next.js router — no direct imports are needed.

```typescript
// Next.js resolves this route when navigating to /onboarding-guide/:slug
// Real slugs (e.g. /onboarding-guide/getting-started) are handled by the
// SPA fallback; only 'index' is pre-rendered at build time.

// The static params stub:
export function generateStaticParams(): { slug: string }[] {
  return [{ slug: 'index' }]; // Satisfies output: 'export'; real slugs served dynamically
}
```

> **Note:** For more context on the static export strategy and why slug enumeration is not possible at build time, see `docs/static-export-migration.md`.
