Loading skeleton components for the Help Center section, providing shimmer placeholders during route-level page transitions.

## Key Components

| Export | Description |
|---|---|
| `HelpCenterPageSkeleton` | Index-page skeleton that renders the real `HelpCenterMenu` (no shimmer needed — no async data backs the index) |
| `HelpCenterDocSkeleton` | Document-page skeleton with a shimmered `h1` title, subtitle bar, back button, and four content block skeletons |
| `DOC_BLOCK_KEYS` | Internal constant (`['a', 'b', 'c', 'd']`) driving the four `Skeleton` content blocks |

## Usage Example

These are consumed automatically by Next.js via co-located `loading.tsx` files, but can also be rendered directly:

```typescript
// loading.tsx — Help Center index route
import { HelpCenterPageSkeleton } from './help-center-page-skeleton';
export default HelpCenterPageSkeleton;

// loading.tsx — individual Help Center document route
import { HelpCenterDocSkeleton } from './help-center-page-skeleton';
export default HelpCenterDocSkeleton;
```

## Design Notes

- **Index skeleton** renders the real `HelpCenterMenu` rather than a shimmer to avoid layout shift on mount, since the menu has no async dependency.
- **Doc skeleton** uses a truthy space (`" "`) as the `subtitle` prop so `TitleBlock` renders the subtitle skeleton bar — matching the layout of every document page that carries a real subtitle.
- **Back button** calls `router.push(routes.helpCenter.root)` via `onClick` to match the chrome of document pages, preventing header height shifts during load.
