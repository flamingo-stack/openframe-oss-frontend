The root page component for the Help Center route, rendering the full Help Center landing page within the application's standard page layout.

## Key Components

- **`HelpCenterPage`** *(default export)* — Client-side page component that composes `PageLayout` and `HelpCenterMenu` to produce the Help Center landing view. Intentionally kept host-local (not extracted to the shared lib) since its navigation links and icons are app-owned.

## Usage Example

```typescript
// Rendered automatically by Next.js at the /help-center route.
// No manual instantiation needed; consumed via the file-system router.
import HelpCenterPage from '@/app/help-center/page';
```

## Notes

- Uses `'use client'` directive — the page runs in the browser.
- Layout spacing is driven by CSS custom properties (`--spacing-system-l`) for consistency with the design system.
- The grid markup is intentionally delegated to [`HelpCenterMenu`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/help-center/components/help-center-menu.tsx) so any loading-state skeleton can reuse the same structure without duplicating markup in this file.
