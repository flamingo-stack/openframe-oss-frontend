Unified type definitions serving as the single source of truth for device-related data structures across the OpenFrame frontend, covering hardware inventory, MDM state, software/vulnerability tracking, and device filtering.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `Device` | `interface` | Root device entity with all fields flat at root level — hardware, OS, network, MDM, software, tags, and tool connections |
| `Software` | `interface` | Installed software entry supporting apps, Chrome extensions, VS Code extensions, Homebrew, and Python packages |
| `Vulnerability` | `interface` | CVE record with optional Fleet Premium severity fields (`cvss_score`, `epss_probability`, `cisa_known_exploit`) |
| `DevicePolicy` | `interface` | Compliance policy result (pass/fail/empty) evaluated per device via Fleet MDM |
| `MdmInfo` | `interface` | MDM enrollment status, DEP profile errors, connected-to-Fleet flag, and profile count |
| `ToolConnection` | `interface` | Agent connection record for `MESHCENTRAL` or `FLEET_MDM` tool types |
| `DeviceFilters` / `DeviceFilterInput` | `interface` | Filter facets (status, OS type, org, tags) and filter input shape for device list queries |
| `DeviceGraphQlNode` | `type` | The single-device (detail page) GraphQL response shape. List rows come from Relay via `MachineLike` in `utils/device-transform.ts`. |
| `GraphQlResponse<T>` | `interface` | Generic GraphQL envelope with `data` and `errors` fields |
| `ToolType` | `type` | Union literal — `'MESHCENTRAL' \| 'FLEET_MDM'` |

## Usage Example

```typescript
import type {
  Device,
  Software,
  Vulnerability,
  DeviceFilterInput,
  GraphQlResponse,
} from '@/types/device.types';

// Narrow a device's critical vulnerabilities
function getCriticalCves(device: Device): Vulnerability[] {
  return (device.software ?? [])
    .flatMap((s: Software) => s.vulnerabilities)
    .filter((v: Vulnerability) => (v.cvss_score ?? 0) >= 9.0);
}

// Build a filter payload for the devices query
const filterInput: DeviceFilterInput = {
  statuses: ['online'],
  osTypes: ['darwin', 'windows'],
  tagKeys: ['env:production'],
};
```
