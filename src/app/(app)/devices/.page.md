Renders the main Devices page, displaying a panel of connected devices or an onboarding empty state when no devices exist.

## Key Components

- **`Devices`** — Default export; top-level page component that composes `DevicesPanel` with organization-aware loading/empty state logic
- **`useHasOrganizations`** — Hook providing `hasOrganizations` and `isLoading` to gate empty-state rendering until the org check resolves, preventing UI flash
- **`DevicesPanel`** — Shared panel rendering the device list, archive link, and disabled "Add Device" button while org status is loading
- **`EmptyState`** — Onboarding prompt shown when no devices are connected, with action hints and a link to the devices guide

## Usage Example

```typescript
// Rendered automatically by Next.js at the /devices route.
// No props required — state is resolved internally via the hook.

import Devices from '@/app/devices/page';

// In layout or router:
<Devices />
```

The empty state defers rendering `noOrganizations={true}` until `isLoading` resolves, so the "Add a customer" banner never flashes during initial load. The `isCheckingOrganizations` prop keeps the "Add Device" action disabled in the interim.

```typescript
// Archive link is sourced from the shared routes map:
import { routes } from '@/lib/routes';

routes.devices.archive; // e.g. '/devices/archive'
```
