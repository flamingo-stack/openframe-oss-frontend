A modal dialog component for configuring remote desktop session settings, including display quality, frame rate, scaling, and input device preferences for MeshCentral-based remote connections.

## Key Components

### `RemoteSettingsModal`
The primary exported component that renders a `SimpleModal` with controls for:
- **Quality** — Select display quality level via `QUALITY_OPTIONS`
- **Scaling** — Select display scaling percentage via `SCALING_OPTIONS`
- **Frame Rate** — Select target frame rate via `FRAME_RATE_OPTIONS`
- **Invert Scroll Direction** — Toggle checkbox
- **Swap Mouse Buttons** — Toggle checkbox
- **Use Remote Keyboard Map** — Toggle checkbox

### `RemoteSettingsModalProps`
| Prop | Type | Description |
|---|---|---|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Modal open/close callback |
| `currentSettings` | `RemoteSettingsConfig` | Active settings passed in as initial state |
| `desktopRef` | `MutableRefObject<MeshDesktop \| null>` | Ref to the MeshDesktop instance |
| `tunnelRef` | `MutableRefObject<MeshTunnel \| null>` | Ref to the active MeshCentral tunnel |
| `connectionState` | `number` | Must equal `3` (connected) to apply settings |
| `onSettingsChange` | `(settings: RemoteSettingsConfig) => void` | Optional callback fired on successful save |

## Usage Example

```typescript
import { RemoteSettingsModal } from './remote-settings-modal';

<RemoteSettingsModal
  open={showSettings}
  onOpenChange={setShowSettings}
  currentSettings={remoteSettings}
  desktopRef={desktopRef}
  tunnelRef={tunnelRef}
  connectionState={connectionState}
  onSettingsChange={(updated) => setRemoteSettings(updated)}
/>
```

> **Note:** Settings are only applied when `connectionState === 3` (fully connected). Attempting to save while disconnected shows a destructive toast and aborts. On success, estimated bandwidth usage is displayed in the confirmation toast via `RemoteDesktopSettings.estimateBandwidth()`.
