Remote desktop page component for connecting to and interacting with a device via MeshCentral's remote desktop protocol. Handles tunnel lifecycle, display management, clipboard sync, fullscreen mode, and settings.

## Key Components

- **`RemoteDesktopPage`** — Default export; full-page React component managing the MeshCentral remote desktop session
- **`LegacyDeviceData`** — Interface for backward-compatible device data passed via query params
- **`MeshDesktop`** / **`MeshTunnel`** / **`MeshControlClient`** — Core MeshCentral primitives wired together for rendering, tunneling, and session control
- **`RemoteDesktopSettings`** — Applied once the tunnel reaches state `3` (connected) to push quality/encoding settings
- **`RemoteSettingsModal`** — UI modal for adjusting remote session settings at runtime
- **`ActionsMenuDropdown`** — Dropdown action menu built from `createActionsMenuGroups()` for display switching, clipboard, input toggle, etc.

## Key Behaviors

| Concern | Detail |
|---|---|
| Device resolution | Prefers `deviceData` query param (legacy), falls back to `useDeviceDetails` fetch |
| Tunnel lifecycle | Initialized once `meshcentralAgentId` is available; auto-reconnect with toast notifications |
| Clipboard sync | Intercepts paste/copy via `navigator.clipboard` ↔ `MeshControlClient.setClipboard/getClipboard` |
| Fullscreen | Toggles `document.fullscreenElement`; auto-focuses canvas on enter |
| Display list | Updated via `onDisplayListChange`; primary display auto-selected on first detection |

## Usage Example

```typescript
// Navigate to the page with a device ID
import { routes } from '@/lib/routes';

// Modern: pass device ID only
router.push(`${routes.remoteDesktop}?id=${deviceId}`);

// Legacy: pass serialized device data
const deviceData = JSON.stringify({
  id: device.id,
  meshcentralAgentId: device.agentId,
  hostname: device.hostname,
  organization: device.orgName,
});
router.push(`${routes.remoteDesktop}?id=${deviceId}&deviceData=${encodeURIComponent(deviceData)}`);
```
