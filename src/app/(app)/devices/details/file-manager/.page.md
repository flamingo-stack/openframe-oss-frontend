The File Manager page component for device details, handling loading, error, and missing-agent states before rendering the full file manager interface.

## Key Components

- **`FileManagerPage`** — Default export; retrieves device ID from search params, fetches device details, resolves the MeshCentral agent ID, and tracks the device as the active Mingo "open view." Renders appropriate UI for each state.
- **`FileManagerPageSkeleton`** — Internal skeleton component displayed during data loading, wrapping `FileManagerSkeleton` inside a `PageLayout`.

**State Handling:**

| State | Rendered UI |
|---|---|
| Loading | `FileManagerPageSkeleton` with back button |
| Error | Error message + "Return to Device Details" button |
| Missing MeshCentral Agent | Warning message explaining agent requirement |
| Ready | `FileManagerContainer` with resolved `meshcentralAgentId` |

## Usage Example

```typescript
// Rendered automatically by Next.js routing at:
// /devices/details/file-manager?id=<deviceId>

// The page reads deviceId from search params:
const deviceId = useSearchParams().get('id') ?? '';

// Resolves agent ID from device details:
const meshcentralAgentId = getMeshCentralAgentId(deviceDetails);

// Passes resolved data to the file manager container:
<FileManagerContainer
  deviceId={deviceId}
  meshcentralAgentId={meshcentralAgentId}
  hostname={hostname}
  className={PAGE_PADDING}
/>
```

## Dependencies

- [`useDeviceDetails`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/devices/hooks/use-device-details.ts) — Fetches device data (polling disabled on this surface)
- [`getMeshCentralAgentId`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/devices/utils/device-action-utils.ts) — Extracts MeshCentral agent ID from device details
- [`useTrackOpenView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/mingo/context/use-track-open-view.ts) — Keeps device registered as the active Mingo context view, called unconditionally above early returns to preserve hook order
