A modal dialog component for creating new folders, providing a controlled input form within a `SimpleModal` wrapper with keyboard and button submission support.

## Key Components

### `NewFolderModal`

**Props (`NewFolderModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `folderName` | `string` | Current controlled input value |
| `submitting` | `boolean` | Disables inputs and buttons during async submission |
| `onChange` | `(value: string) => void` | Callback fired on input change |
| `onSubmit` | `() => void` | Callback fired on form submission |
| `onClose` | `() => void` | Callback fired on cancel or modal close |

**Behaviors:**
- Auto-focuses the name input when opened
- Listens for `Enter` keypress to submit — guarded by `submitting` state and non-empty `folderName`
- Cleans up the `keydown` listener on unmount or when `isOpen` changes

## Usage Example

```typescript
const [isOpen, setIsOpen] = useState(false);
const [folderName, setFolderName] = useState('');
const [submitting, setSubmitting] = useState(false);

const handleSubmit = async () => {
  setSubmitting(true);
  await createFolder(folderName);
  setSubmitting(false);
  setIsOpen(false);
  setFolderName('');
};

<NewFolderModal
  isOpen={isOpen}
  folderName={folderName}
  submitting={submitting}
  onChange={setFolderName}
  onSubmit={handleSubmit}
  onClose={() => setIsOpen(false)}
/>
```
