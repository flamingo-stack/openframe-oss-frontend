A Next.js client-side page component that extracts a `deviceId` from the URL query string and renders the device details view.

## Key Components

- **`DeviceDetailsPage`** — Default export; reads the `id` query parameter and passes it to `DeviceDetailsView`

## Usage Example

```typescript
// Accessed via URL: /device-details?id=abc123
// DeviceDetailsPage automatically extracts "abc123" and passes it to DeviceDetailsView

import DeviceDetailsPage from './page';

// Rendered by Next.js router automatically — no manual props required
<DeviceDetailsPage />
```

## Notes

- Marked `'use client'` — runs in the browser, enabling access to `useSearchParams()`
- Falls back to an empty string (`''`) if the `id` query param is absent, so `DeviceDetailsView` must handle empty IDs gracefully
