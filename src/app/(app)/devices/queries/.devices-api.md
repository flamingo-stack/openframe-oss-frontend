The **imperative** half of the device data layer — device reads for callers that run outside React's render.

Most device reads are Relay hooks (`hooks/use-devices.ts`, `use-device-list.ts`, `use-device-filters.ts`). These functions exist for the cases a hook can't serve: a react-query `queryFn`, a singleton service, or a cursor walk. Callers get `Device` objects or plain counts and never see a GraphQL envelope.

## Key Components

| Export | Transport | Purpose |
|---|---|---|
| `fetchDevicesPage(vars?)` | Relay `fetchQuery` | One page of devices → `{ devices, pageInfo, filteredCount }` |
| `fetchAllDevices(vars?)` | Relay `fetchQuery`, looped | Every device matching a filter, following the cursor to exhaustion |
| `fetchDeviceCounts(filter?)` | raw POST | Counters only → `{ filteredCount, byStatus, byOrganization }` as `Map`s |
| `fetchDeviceNode(machineId)` | raw POST | The raw GraphQL node for one device, including `installedAgents` |

## Notes

- **`fetchDevicesPage` and `fetchAllDevices` run the same `devicesPageRelayQuery` the suspending pickers use**, so rows land in the Relay store as normalized `Machine` records however they were fetched — an imperative read and a hook read cannot disagree about a device.
- **Ordering lives in the document**, not per call site: every device list is `status DESC` (online first).
- **`fetchAllDevices` stops when the cursor can't advance**, even if the server still claims `hasNextPage` — a null `endCursor` would otherwise refetch page one forever.
- `fetchDeviceCounts` returns `Map`s rather than raw facet arrays, because every caller was doing the same array → lookup conversion.
- The two raw-POST functions are the remaining non-Relay device reads. `fetchDeviceNode` backs the detail page, whose hook merges it with Fleet and MeshCentral and polls on a data-derived interval; the counter functions back the dashboard and customer tables. Migrating them is a separate step from the list migration.

## Usage Example

```typescript
import { fetchAllDevices, fetchDeviceCounts } from './devices-api';

// The whole fleet, as a registry to look devices up in
const registry = await fetchAllDevices({ filter: { statuses: ['ONLINE', 'OFFLINE', 'ARCHIVED'] } });

// Per-organization device counts
const { byOrganization } = await fetchDeviceCounts({ organizationIds: ['org-1', 'org-2'] });
const acmeDevices = byOrganization.get('org-1') ?? 0;
```
