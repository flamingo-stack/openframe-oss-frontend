A React hook that provides archive, unarchive, and delete actions for devices, handling API calls, loading states, toast notifications, and React Query cache invalidation.

## Key Components

### `useDeviceActions(options?)`

Main export. Accepts an optional `UseDeviceActionsOptions` object with an `onSuccess` callback fired after any successful mutation.

**Returns:**

| Property | Type | Description |
|---|---|---|
| `archiveDevice` | `(id, name?) => Promise<boolean>` | Sets device status to `ARCHIVED` |
| `unarchiveDevice` | `(id, name?) => Promise<boolean>` | Restores device to `OFFLINE` status |
| `deleteDevice` | `(id, name?) => Promise<boolean>` | Sets device status to `DELETED` |
| `isArchiving` | `boolean` | Archive operation in progress |
| `isUnarchiving` | `boolean` | Unarchive operation in progress |
| `isDeleting` | `boolean` | Delete operation in progress |
| `isProcessing` | `boolean` | Any operation in progress |

### `invalidateDeviceQueries` (internal)

After any successful mutation, calls `invalidateDeviceQueries(queryClient)` — which bumps the Relay device epoch (refetching the list, facets and pickers) and invalidates the react-query device roots plus the dashboard customers-overview key. Keeps every device surface in sync without per-view refetch wiring.

> **Note:** Unarchive restores to `OFFLINE` (not `PENDING`). The agent heartbeat promotes the device to `ONLINE` on its next check-in.

## Usage Example

```typescript
import { useDeviceActions } from '@/features/devices/hooks/use-device-actions';

function DeviceActionsMenu({ deviceId, deviceName }: Props) {
  const { archiveDevice, deleteDevice, isProcessing } = useDeviceActions({
    onSuccess: () => router.push('/devices'),
  });

  return (
    <div>
      <button
        disabled={isProcessing}
        onClick={() => archiveDevice(deviceId, deviceName)}
      >
        Archive
      </button>
      <button
        disabled={isProcessing}
        onClick={() => deleteDevice(deviceId, deviceName)}
      >
        Delete
      </button>
    </div>
  );
}
```
