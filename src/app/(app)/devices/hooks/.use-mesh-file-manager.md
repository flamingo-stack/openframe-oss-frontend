React hook that manages MeshCentral file manager state and operations, handling WebSocket connection lifecycle, file system navigation, transfers, clipboard, and search for a remote device agent.

## Key Components

### Hook: `useMeshFileManager`

Accepts `UseMeshFileManagerOptions`:

| Option | Type | Description |
|---|---|---|
| `meshcentralAgentId` | `string` | Target device node ID |
| `isRemote` | `boolean` | Remote vs. server-side file access (default: `true`) |
| `onError` | `(error: Error) => void` | Optional error callback |

### Internal Utilities

- **`activeFileManagers`** — Module-level `Map` preventing duplicate connections under React Strict Mode
- **`getDirectoryFromFileIds`** — Extracts parent directory path from an array of file ID strings
- **`MeshCentralFileManager`** / **`MeshControlClient`** — Underlying WebSocket connection and protocol clients

### Returned State & Actions (`UseMeshFileManagerReturn`)

| Category | Members |
|---|---|
| State | `files`, `currentPath`, `selectedFiles`, `connectionState`, `loading`, `isSearching`, `uploadProgress`, `downloadProgress`, `clipboard` |
| Navigation | `navigateToPath`, `navigateUp`, `navigateInto` |
| File ops | `createFolder`, `deleteItems`, `renameItem`, `uploadFile`, `downloadFile`, `copyFiles`, `moveFiles` |
| Transfer control | `cancelUpload`, `cancelDownload` |
| Search | `searchFiles`, `cancelSearch`, `isSearchActive` |
| Clipboard | `copyToClipboard`, `cutFiles`, `pasteFiles`, `clearClipboard` |
| Selection | `selectFile`, `selectAll`, `handleFileAction` |

## Usage Example

```typescript
import { useMeshFileManager } from '@/hooks/use-mesh-file-manager';

function DeviceFileExplorer({ agentId }: { agentId: string }) {
  const {
    files,
    currentPath,
    connectionState,
    loading,
    navigateInto,
    navigateUp,
    uploadFile,
    downloadFile,
    handleFileAction,
  } = useMeshFileManager({
    meshcentralAgentId: agentId,
    isRemote: true,
    onError: (err) => console.error('File manager error:', err),
  });

  if (connectionState !== 'connected_end_to_end') {
    return <div>Connecting... ({connectionState})</div>;
  }

  return (
    <FileManagerUI
      files={files}
      currentPath={currentPath}
      loading={loading}
      onNavigateInto={navigateInto}
      onNavigateUp={navigateUp}
      onUpload={uploadFile}
      onDownload={downloadFile}
      onAction={handleFileAction}
    />
  );
}
```

## Notes

- The hook guards against React Strict Mode double-invocation via `activeFileManagers` and `initTokenRef` cancellation tokens — connections are torn down cleanly on unmount.
- Toast notifications are surfaced for connection state changes, transfer cancellations, and errors without requiring callers to wire up UI alerts manually.
