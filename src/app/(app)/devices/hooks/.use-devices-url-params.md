Manages URL search parameters for the devices list, synchronising filter state (search, statuses, OS types, organisations, tags, view mode) between the URL and the device query API.

## Key Components

### `useDevicesUrlParams(options?)`

Main hook that reads and writes all device filter state via URL params.

**Options**

| Option | Type | Description |
|---|---|---|
| `defaultStatuses` | `string[]` | Statuses applied when none are explicitly selected. Defaults to `DEFAULT_DEVICES_LIST_STATUSES` (ONLINE/OFFLINE). Pass `[]` to disable defaults (e.g. the archive page). |

**Returns**

| Property | Description |
|---|---|
| `params` | Normalised URL param values (statuses collapsed when equal to defaults) |
| `filters` | `DeviceFilterInput` shaped for the API query |
| `tableFilters` | Column-filter shape expected by the table component |
| `tagOptions` | `TagSearchOption[]` derived from raw tag params |
| `localSearch` / `debouncedSearch` | Responsive local value + 500 ms debounced URL value |
| `handleFilterChange` | Updates status/OS/org filters and scrolls table to top |
| `handleTagSubmit` | Adds a new tag chip and clears the search field |
| `handleTagRemove` | Removes a single tag chip |
| `handleClearAll` | Resets search and all tags |
| `setParam` / `setParams` | Low-level param setters (statuses auto-normalised) |

**Status normalisation** — selecting exactly the default status set is treated as "no selection" so the URL stays clean and the filter UI shows nothing checked in the default state.

## Usage Example

```typescript
// Main devices page (defaults: ONLINE + OFFLINE)
const { filters, tableFilters, localSearch, setLocalSearch, handleFilterChange } =
  useDevicesUrlParams();

// Archive page (no default statuses; caller locks in ARCHIVED via lockedFilters)
const { filters } = useDevicesUrlParams({ defaultStatuses: [] });
```
