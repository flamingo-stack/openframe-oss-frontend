A React hook that enables infinite scroll behavior for grid layouts using the IntersectionObserver API, triggering paginated data fetches when a sentinel element enters the viewport.

## Key Components

- **`useGridInfiniteScroll`** — Custom hook that attaches an `IntersectionObserver` to a sentinel `div` ref, automatically calling `fetchNextPage` when the sentinel scrolls into view (with a 200px root margin lookahead)
- **`UseGridInfiniteScrollParams`** — Configuration interface controlling when fetching is active (`enabled`, `hasNextPage`, `isFetchingNextPage`) and the fetch trigger (`fetchNextPage`)
- **`sentinelRef`** — A `RefObject<HTMLDivElement>` returned by the hook; must be attached to a placeholder element at the bottom of the grid

## Usage Example

```typescript
import { useGridInfiniteScroll } from './use-grid-infinite-scroll';

function FileGrid() {
  const { data, hasNextPage, isFetchingNextPage, fetchNextPage } =
    useInfiniteQuery({ /* ... */ });

  const sentinelRef = useGridInfiniteScroll({
    enabled: true,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
  });

  return (
    <>
      <div className="grid grid-cols-3 gap-4">
        {data.pages.flatMap(page => page.items).map(item => (
          <FileCard key={item.id} item={item} />
        ))}
      </div>
      {/* Sentinel must be rendered at the bottom of the scroll container */}
      <div ref={sentinelRef} />
    </>
  );
}
```

The observer is automatically disconnected on cleanup, and skips re-registration when `enabled` is false, `hasNextPage` is false, or a fetch is already in progress.
