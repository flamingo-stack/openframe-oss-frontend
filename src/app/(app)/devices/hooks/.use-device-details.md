Fetches and assembles a unified `Device` object by combining data from three sources: GraphQL (core device record), Fleet MDM (hardware/software/policy details), and MeshCentral (remote management status).

## Key Components

### Functions

- **`fetchDeviceDetails(machineId)`** — Async orchestrator that queries GraphQL, Fleet MDM, and MeshCentral in parallel, then calls `createDevice` to merge results into a single `Device` object.
- **`createDevice(node, fleetData, meshCentralStatus, meshCentralLastSeen)`** — Pure mapping function that transforms raw API responses into the unified `Device` type. Handles software, batteries, policies, users, MDM info, IP deduplication, and tool connection enrichment.
- **`collectEndUserEmails(fleetData)`** — Extracts unique end-user emails from Fleet's `end_users` array (including `other_emails`).

### Hook

- **`useDeviceDetails(machineId)`** — React Query hook that drives `fetchDeviceDetails`, with error toast notifications and stale-time caching via `deviceQueryKeys`.

## Usage Example

```typescript
import { useDeviceDetails } from '@/features/devices/hooks/use-device-details';

function DevicePanel({ machineId }: { machineId: string }) {
  const { data: device, isLoading, isError } = useDeviceDetails(machineId);

  if (isLoading) return <Spinner />;
  if (isError || !device) return <ErrorState />;

  return (
    <div>
      <h1>{device.displayName}</h1>
      <p>OS: {device.osVersion}</p>
      <p>IP: {device.ip}</p>
      <p>Status: {device.status}</p>
    </div>
  );
}
```

## Data Sources

| Source | Data Provided |
|---|---|
| GraphQL (`GET_DEVICE_QUERY`) | Core identity, org, tags, tool connections |
| Fleet MDM (`fleetApiClient`) | Hardware specs, software, policies, MDM info |
| MeshCentral (`getMeshCentralDeviceInfo`) | Remote management status, last seen |
