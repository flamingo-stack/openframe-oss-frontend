Provides a React Query hook for fetching query reports associated with a specific Fleet host, wrapping the `GET /fleet/hosts/{id}/queries` endpoint.

## Key Components

- **`hostQueriesKeys`** — Query key factory scoped to `['fleet', 'hosts', hostId, 'queries']`, used for cache management and invalidation.
- **`fetchHostQueries(hostId)`** — Async fetcher that calls `fleetApiClient.getHostQueries(hostId)` and throws on non-OK responses.
- **`useHostQueries(hostId)`** — Primary exported hook; disables fetching when `hostId` is `undefined` and returns a referentially stable empty array (`EMPTY_REPORTS`) to prevent infinite render loops in memoized dependents.

## Usage Example

```typescript
import { useHostQueries } from '@/app/(app)/monitoring/hooks/use-host-queries';

function HostQueriesPanel({ fleetHostId }: { fleetHostId: number | undefined }) {
  const { data, isLoading, isError } = useHostQueries(fleetHostId);

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorMessage />;

  return (
    <ul>
      {data.map((report) => (
        <li key={report.report_id}>
          {report.report_id} — last fetched: {report.last_fetched}
        </li>
      ))}
    </ul>
  );
}
```

## Notes

- **`enabled: !!hostId`** — Queries are skipped entirely when no Fleet host is linked to the device; safe to call unconditionally.
- **Frequency (`interval`) is not included** in host query reports. Join against the global `/fleet/queries` list by `report_id` to retrieve query interval.
- The module-level `EMPTY_REPORTS` constant is intentionally shared to preserve referential stability across renders.
