React Query hook for fetching device filter options via GraphQL, used to populate filter dropdowns/selectors in device management views.

## Key Components

### `deviceFiltersQueryKeys`

Query key factory for cache management:

| Key | Description |
|-----|-------------|
| `all` | Base key `['deviceFilters']` for all filter queries |
| `byFilter(filters)` | Scoped key `['deviceFilters', filters]` per filter input |

### `useDeviceFilters(filters?)`

TanStack Query hook that posts to `/api/graphql` with `GET_DEVICE_FILTERS_QUERY`, returning available `DeviceFilters` options. Accepts an optional `DeviceFilterInput` object (defaults to `{}`).

**Behavior:**
- Returns `null` on empty GraphQL response
- Throws on HTTP errors or GraphQL-level errors
- `keepPreviousData` prevents UI flicker during filter transitions
- `staleTime: 30s` reduces redundant refetches for relatively stable filter metadata

## Usage Example

```typescript
import { useDeviceFilters } from '@/features/devices/hooks/use-device-filters';

function DeviceFilterPanel() {
  const activeFilters: DeviceFilterInput = { siteId: 'site-123' };
  const { data, isLoading, isError } = useDeviceFilters(activeFilters);

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorMessage />;

  return (
    <FilterSelect
      options={data?.statuses}
      placeholder="Filter by status"
    />
  );
}
```
