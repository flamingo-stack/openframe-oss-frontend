React Query infinite scroll hook for paginated device data, fetching devices via GraphQL with support for filtering, searching, and cursor-based pagination.

## Key Components

### `devicesQueryKeys`
Derived query key factory linked to the canonical `deviceQueryKeys` registry, ensuring cache invalidation stays coordinated by reference.

- `all` — root key for all device queries
- `list(filters, search)` — scoped key for a specific filter + search combination

### `useDevices(filters?, search?)`
Primary hook exposing paginated device data. Wraps `useInfiniteQuery` with a 30-second stale time, auto-displays a destructive toast on error, and flattens paginated results into a single `devices` array.

**Parameters:**

| Name | Type | Default | Description |
|---|---|---|---|
| `filters` | `DeviceFilterInput` | `{}` | GraphQL filter object |
| `search` | `string` | `''` | Free-text search string |

**Returns:**

| Field | Type | Description |
|---|---|---|
| `devices` | `Device[]` | Flattened list across all loaded pages |
| `isLoading` | `boolean` | True on initial load |
| `isFetchingNextPage` | `boolean` | True while loading the next page |
| `hasNextPage` | `boolean` | Whether more pages are available |
| `fetchNextPage` | `function` | Trigger next page load |
| `filteredCount` | `number` | Total matching records from the server |
| `error` | `string \| null` | Error message if the query failed |
| `refetch` | `function` | Manually re-trigger the query |

## Usage Example

```typescript
import { useDevices } from './use-devices';

function DeviceList() {
  const { devices, isLoading, hasNextPage, fetchNextPage, filteredCount } =
    useDevices({ status: 'online' }, 'acme-laptop');

  if (isLoading) return <Spinner />;

  return (
    <>
      <p>{filteredCount} devices found</p>
      {devices.map(device => (
        <DeviceRow key={device.id} device={device} />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>Load more</button>
      )}
    </>
  );
}
```

> **Page size** is fixed at `20` per request (`DEVICES_PAGE_SIZE`). Results are sorted server-side by `status DESC`.
