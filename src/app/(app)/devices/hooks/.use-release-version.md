React Query hook that fetches and caches the current release version from the `/api/release-version` endpoint, with built-in error toasting and stale-time caching.

## Key Components

- **`releaseVersionQueryKeys`** — Structured query key factory for use with React Query cache invalidation.
- **`fetchReleaseVersion`** — Async fetcher that calls `/api/release-version` and returns the trimmed version string, falling back to `'latest'`.
- **`useReleaseVersion(options)`** — Primary hook that wraps `useQuery` with a 5-minute stale time, 10-minute GC time, and automatic destructive toast on error.

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version';

function AppHeader() {
  const { releaseVersion, isLoading, error } = useReleaseVersion();

  if (isLoading) return <span>Loading...</span>;

  return <span>Version: {releaseVersion}</span>;
}
```

**Conditionally enabled:**

```typescript
const { releaseVersion, refetch } = useReleaseVersion({ enabled: false });

// Trigger fetch manually
refetch();
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `releaseVersion` | `string` | Version string or `'latest'` fallback |
| `isLoading` | `boolean` | True during initial fetch |
| `isFetching` | `boolean` | True during any background refetch |
| `isSuccess` | `boolean` | True when data is available |
| `error` | `string \| null` | Error message if fetch failed |
| `refetch` | `function` | Manually re-trigger the query |
| `query` | `UseQueryResult` | Full React Query result object |

> **Cache behavior:** Data is considered fresh for 5 minutes (`staleTime`) and retained in memory for 10 minutes (`gcTime`). Failed requests are retried twice with a 1-second delay.
