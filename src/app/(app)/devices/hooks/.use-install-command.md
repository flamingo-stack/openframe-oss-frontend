Generates a platform-specific device installation command string by composing the server URL, registration secret, release version, organization ID, and optional tag arguments.

## Key Components

### `useInstallCommand(options)`
Primary hook that assembles and memoizes the full install command.

**Options:**
| Parameter | Type | Description |
|---|---|---|
| `organizationId` | `string` | Target org ID passed to the install command |
| `platform` | `OSPlatformId` | Target OS (`windows`, `linux`, `macos`, etc.) |
| `tags` | `TagEntry[]` | Optional key/value tags appended as `--tag` args |

**Returns:** `{ command: string, initialKey: string }`

### `buildTagArgs(tags, platform)`
Internal helper that converts `TagEntry[]` into `--tag key=value` argument strings, using platform-appropriate quoting (`"` on Windows, `'` elsewhere).

### Dependencies
- [`useRegistrationSecret`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/hooks/use-registration-secret.ts) — provides the `initialKey` for device registration
- [`useReleaseVersion`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/hooks/use-release-version.ts) — provides the agent `releaseVersion`
- [`buildInstallCommand`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/utils/device-command-utils.ts) — constructs the final command string

The `serverUrl` is derived from `window.location.hostname` at render time; local hostnames (`localhost`, `127.0.0.1`) automatically append `--localMode`.

## Usage Example

```typescript
import { useInstallCommand } from './use-install-command';

function InstallInstructions({ orgId }: { orgId: string }) {
  const { command } = useInstallCommand({
    organizationId: orgId,
    platform: 'linux',
    tags: [{ key: 'env', values: ['production'] }],
  });

  return <pre>{command}</pre>;
}
```
