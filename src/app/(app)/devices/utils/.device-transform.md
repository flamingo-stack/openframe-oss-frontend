Transforms a GraphQL `DevicesGraphQlNode` into a normalized `Device` object optimized for list view rendering, explicitly omitting fields that require additional API calls.

## Key Components

### `createDeviceListItem(node: DevicesGraphQlNode): Device`

Maps a raw GraphQL node to a flat `Device` model suitable for list/table views. Fields unavailable at the list level (CPU, memory, storage, MDM, software arrays) are explicitly set to `undefined` to signal their absence rather than leaving them uninitialized.

**Field mapping highlights:**

| Category | Source Fields | Notes |
|---|---|---|
| Identifiers | `id`, `machineId`, `hostname` | `displayName` falls back to `hostname` |
| Hardware | `serialNumber`, `manufacturer`, `model` | CPU/memory set to `undefined` |
| Network | `ip`, `macAddress` | `local_ips` built as single-item array if IP exists |
| OS | `osType`, `osVersion`, `osBuild` | Mapped to both camelCase and snake_case aliases |
| Organization | `organization.organizationId`, `name`, `image` | Null-safe with `||` fallbacks |
| Unavailable | CPU, memory, storage, MDM, software, batteries | Explicitly `undefined` |

## Usage Example

```typescript
import { createDeviceListItem } from './device-transform';
import { DevicesGraphQlNode } from '../types/device.types';

const graphqlNode: DevicesGraphQlNode = {
  id: 'device-123',
  hostname: 'MACBOOK-PRO-01',
  ip: '192.168.1.10',
  status: 'online',
  osType: 'darwin',
  osVersion: '14.2.1',
  // ...other fields
};

const deviceListItem = createDeviceListItem(graphqlNode);
// Use in list table - lightweight, no additional API calls needed
console.log(deviceListItem.displayName); // 'MACBOOK-PRO-01'
console.log(deviceListItem.cpu_brand);   // undefined (fetch detail view for full data)
```
