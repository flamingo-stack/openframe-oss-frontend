Provides device status configuration utilities for consistent status mapping across table and grid views, and OS type resolution for device display components.

## Key Components

### Types

- **`DeviceStatusVariant`** — Union type for badge/chip display variants: `'success' | 'error' | 'warning' | 'grey' | 'critical'`
- **`DeviceCardStatus`** — Union type for card-level status states: `'active' | 'inactive' | 'offline' | 'warning' | 'error'`
- **`DeviceStatusConfig`** — Interface containing `label`, `variant`, and `cardStatus` for a given device status string

### Functions

- **`getDeviceStatusConfig(status)`** — Maps a raw device status string (case-insensitive) to a `DeviceStatusConfig` object. Handles `ONLINE`, `PENDING`, `ACTIVE`, `OFFLINE`, `DECOMMISSIONED`, `IDLE`, `INACTIVE`, `MAINTENANCE`, `ARCHIVED`, `DELETED`, and falls back to `grey/inactive` for unknown values.
- **`getDeviceOperatingSystem(osType?)`** — Wraps `getOSPlatformId` from `@flamingo-stack/openframe-frontend-core` to return a normalized `OSPlatformId` (`'darwin' | 'windows' | 'linux' | undefined`).

## Usage Example

```typescript
import { getDeviceStatusConfig, getDeviceOperatingSystem } from './device-status';

// Resolve display config for a device status badge
const config = getDeviceStatusConfig('ONLINE');
// { label: 'ONLINE', variant: 'success', cardStatus: 'active' }

// Resolve OS platform for DeviceCard icon
const os = getDeviceOperatingSystem('macOS');
// 'darwin'

// Use in a component
<DeviceCard
  status={config.cardStatus}
  badgeVariant={config.variant}
  os={os}
/>
```

## Status Mapping Reference

| Input Status | Label | Variant | Card Status |
|---|---|---|---|
| `ONLINE` | ONLINE | `success` | `active` |
| `PENDING` / `ACTIVE` | PENDING | `warning` | `warning` |
| `OFFLINE` | OFFLINE | `error` | `offline` |
| `DECOMMISSIONED` / `DELETED` | — | `error` | `offline` |
| `IDLE` / `INACTIVE` / `ARCHIVED` | — | `grey` | `inactive` |
| `MAINTENANCE` | MAINTENANCE | `warning` | `warning` |
| unknown | raw value | `grey` | `inactive` |
