Defines structured, hierarchical query key factories for device-related React Query cache entries.

## Key Components

- **`deviceQueryKeys.all`** – Base key `['devices']` shared by all device queries
- **`deviceQueryKeys.lists()`** – Key for device list queries: `['devices', 'list']`
- **`deviceQueryKeys.detail(machineId)`** – Key for a single device query: `['devices', 'detail', <machineId>]`

## Usage Example

```typescript
import { deviceQueryKeys } from './query-keys';

// Invalidate all device queries
queryClient.invalidateQueries({ queryKey: deviceQueryKeys.all });

// Invalidate only list queries
queryClient.invalidateQueries({ queryKey: deviceQueryKeys.lists() });

// Fetch or invalidate a specific device
const key = deviceQueryKeys.detail('machine-abc-123');
const data = queryClient.getQueryData(key);
```

The hierarchical structure allows React Query's cache invalidation to cascade — invalidating `deviceQueryKeys.all` will also invalidate lists and detail entries, while invalidating `deviceQueryKeys.lists()` leaves detail caches untouched.
