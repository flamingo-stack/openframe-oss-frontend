Resolves a device's canonical display name from a GraphQL device object, using `displayName` with `hostname` as the only permitted fallback.

## Key Components

### `getDeviceName(device?)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `device` | `{ displayName?: string \| null; hostname?: string \| null } \| null \| undefined` | Partial GraphQL device object |

**Returns:** `string` — `displayName` if present, `hostname` if not, or `''` if both are absent.

> **Policy:** Only `displayName` → `hostname` is allowed. Do **not** add fallbacks such as `description`, `machineId`, `deviceId`, or Fleet `display_name` — those diverge across screens.

## Usage Example

```typescript
import { getDeviceName } from '@/utils/device-name';

// Preferred: displayName wins
getDeviceName({ displayName: 'Marketing Laptop', hostname: 'DESKTOP-ABC' });
// → 'Marketing Laptop'

// Fallback: hostname when displayName is absent
getDeviceName({ hostname: 'DESKTOP-ABC' });
// → 'DESKTOP-ABC'

// Safe empty state
getDeviceName(null);
// → ''
```
