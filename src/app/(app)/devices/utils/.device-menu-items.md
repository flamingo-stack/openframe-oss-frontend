Builds and exports a factory function for device action menu items, providing a single source of truth for each action's label, icon, href, and disabled state across different views (device tables, ticket panels, etc.).

## Key Components

### Interfaces

- **`DeviceMenuItemContext`** — Configuration object passed by the calling view; controls `deviceId`, `availability`, icon sizing, Windows shell branching, and new-tab behavior.
- **`DeviceMenuItems`** — Shape of the object returned by `buildDeviceMenuItems`; contains one `ActionsMenuItem` per action: `deviceDetails`, `remoteShell`, `remoteControl`, `manageFiles`, `deviceLogs`.

### Functions

- **`buildDeviceMenuItems(ctx)`** — Main export. Constructs the full set of menu items from a `DeviceMenuItemContext`. Callers pick only the items they need.
- **`buildRemoteShellItem(ctx)`** *(internal)* — Handles the three Remote Shell variants: Windows submenu (CMD / PowerShell), explicit bash link, or plain link without a `shellType` param.
- **`maybeNewTabAction(ctx, href, label, disabled?)`** *(internal)* — Conditionally injects an `iconAction` (arrow-up-right icon) onto an item when `ctx.withNewTabAction` is `true`.

### Constants

- **`WINDOWS_SHELLS`** — Tuple of `{ id, label, icon }` entries for CMD and PowerShell submenu items.

> **Note:** `Run Script` is intentionally excluded — its `onClick` opens a React-stateful modal owned by the parent component and cannot be expressed as pure config.

## Usage Example

```typescript
import { buildDeviceMenuItems } from './device-menu-items';
import { getDeviceActionAvailability } from './device-action-utils';

// Device table row dropdown (Windows machine, with new-tab actions)
const availability = getDeviceActionAvailability(device);

const { remoteShell, remoteControl, manageFiles, deviceDetails, deviceLogs } =
  buildDeviceMenuItems({
    deviceId: device.id,
    availability,
    iconSize: 'w-6 h-6',
    isWindows: true,
    withNewTabAction: true,
  });

// Ticket panel (minimal context, no new-tab, OS unknown)
const ticketItems = buildDeviceMenuItems({
  deviceId: machine.id,
  availability: null, // device not yet loaded — remote actions stay disabled
});
```
