Utility functions for converting MeshCentral `FileEntry` objects into UI-Kit `FileItem` format, along with helpers for path manipulation, file size formatting, and path sanitization.

## Key Components

| Export | Description |
|---|---|
| `convertFileEntryToItem` | Converts a single MeshCentral `FileEntry` to a UI-Kit `FileItem`, normalizing cross-platform paths |
| `convertFileEntriesToItems` | Batch converts an array of `FileEntry` objects |
| `formatFileSize` | Formats a byte count into a human-readable string (e.g., `1.5 MB`) |
| `formatDate` | Converts a Unix timestamp to a localized date string via `formatDateTime` |
| `getFileExtension` | Extracts the lowercase file extension from a filename |
| `isDownloadable` | Returns `true` only for type `3` (regular) files |
| `sanitizePath` | Strips path traversal sequences (`..`, `.`) and normalizes slashes; handles Windows drive letters |
| `getParentPath` | Returns the parent directory of a given path |
| `joinPath` | Joins path segments, deduplicating slashes and ensuring a leading `/` |

## Usage Example

```typescript
import {
  convertFileEntriesToItems,
  formatFileSize,
  sanitizePath,
  getParentPath,
} from './file-manager-utils';

// Convert MeshCentral entries for display
const items = convertFileEntriesToItems(entries, '/Users/admin');

// Format a raw byte count
formatFileSize(1536000); // "1.46 MB"

// Sanitize user-supplied paths
sanitizePath('../../etc/passwd'); // ""
sanitizePath('C:\\Users\\admin'); // "C:\\Users\\admin"

// Navigate up one level
getParentPath('/Users/admin/docs'); // "/Users/admin"
getParentPath('/');                 // "/"
```

## Notes

- Path normalization converts all backslashes to forward slashes before building `FileItem.id` and `FileItem.path`, ensuring consistent behavior across Windows and Unix MeshCentral agents.
- `sanitizePath` preserves Windows drive letters (e.g., `C:`) while stripping traversal components.
