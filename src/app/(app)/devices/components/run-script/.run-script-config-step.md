Step 2 of the run-script modal flow — renders a configuration form for executing a script against a single machine, loading script defaults via Relay and dispatching a `batchRunScript` mutation on submit.

## Key Components

### `RunScriptConfigStep`
The primary (and only) export. A Relay-suspended form component that:
- Fetches script details via `useLazyLoadQuery` (`scriptDetailRelayQuery`)
- Seeds form fields from the script's saved defaults (`defaultArgs`, `envVars`, `defaultTimeoutSeconds`, `privilegeLevel`)
- Validates form data using `zod` schema (`runFormSchema`) via `react-hook-form`
- Dispatches `batchRunScriptMutation` on valid submit

### `runFormSchema`
Internal `zod` schema validating four fields:

| Field | Type | Constraints |
|---|---|---|
| `timeout` | `number` | 1–86400 seconds |
| `runAsUser` | `boolean` | — |
| `scriptArgs` | `scriptArgumentSchema[]` | Key/value pairs |
| `envVars` | `scriptArgumentSchema[]` | Key/value pairs |

### Props (`RunScriptConfigStepProps`)

| Prop | Type | Description |
|---|---|---|
| `scriptId` | `string` | Relay ID of the script to run |
| `machineId` | `string` | Target machine for execution |
| `onBack` | `() => void` | Navigate to previous step |
| `onRan` | `() => void` | Called on successful dispatch |

## Usage Example

```typescript
import { Suspense } from 'react';
import { RunScriptConfigStep } from './run-script-config-step';

<Suspense fallback={<Spinner />}>
  <RunScriptConfigStep
    scriptId="c2NyaXB0OjEyMw=="
    machineId="bWFjaGluZTo0NTY="
    onBack={() => setStep('select')}
    onRan={() => setStep('running')}
  />
</Suspense>
```

> **Note:** This component suspends while the script detail query loads. Always wrap it in a `<Suspense>` boundary. Empty argument/env-var rows are silently dropped before the mutation is dispatched.
