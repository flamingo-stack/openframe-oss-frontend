Post-run confirmation modal displayed after a script is dispatched to a device in the scripts-v2 flow. Wraps `SimpleModal` to inform the user that script execution is underway and provides navigation to the device logs.

## Key Components

- **`ScriptRunningModal`** — Primary export. A controlled modal that renders a "Scripts Running" confirmation with two footer actions: **Close** (dismisses the modal) and **Device Logs** (navigates to the device's Overview/logs tab and closes the flow).

### Props (`ScriptRunningModalProps`)

| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback to dismiss the modal |
| `onViewDeviceLogs` | `() => void` | Navigates to the device logs and closes the flow |

## Usage Example

```typescript
import { ScriptRunningModal } from './script-running-modal';

function ScriptFlow() {
  const [isRunning, setIsRunning] = useState(false);

  const handleViewDeviceLogs = () => {
    router.push(`/devices/${deviceId}?tab=overview`);
    setIsRunning(false);
  };

  return (
    <ScriptRunningModal
      isOpen={isRunning}
      onClose={() => setIsRunning(false)}
      onViewDeviceLogs={handleViewDeviceLogs}
    />
  );
}
```
