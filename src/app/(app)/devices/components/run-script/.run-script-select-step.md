Step 1 of the run-script modal flow — renders a searchable, tag-filtered, paginated list of active scripts for selection, using Relay for data fetching and an `IntersectionObserver`-based infinite scroll.

## Key Components

- **`RunScriptSelectStep`** *(exported)* — Top-level step component. Manages search input state, debounces the query (300ms), and coordinates the tag filter with the paginated picker list.
- **`PickerList`** *(internal)* — Fetches scripts via Relay (`useLazyLoadQuery` + `usePaginationFragment`), renders each script as a selectable button with name, description, and OS type badges, and triggers infinite scroll using `IntersectionObserver` on a sentinel `div`.

## Key Behaviors

| Behavior | Detail |
|---|---|
| Page size | 20 scripts per page (`PICKER_PAGE_SIZE`) |
| Search debounce | 300ms delay before query fires |
| Infinite scroll | Pre-fetches 200px before sentinel enters viewport |
| Fetch policy | `store-and-network` for immediate cached render + background refresh |
| Empty state | Shows "No scripts found" message when result set is empty |

## Usage Example

```typescript
import { RunScriptSelectStep } from './run-script-select-step';

// Inside a modal or multi-step flow:
function RunScriptModal() {
  const handleScriptSelect = (scriptId: string) => {
    // Advance to configuration step with selected script
    setSelectedScriptId(scriptId);
    setStep('configure');
  };

  return <RunScriptSelectStep onSelect={handleScriptSelect} />;
}
```
