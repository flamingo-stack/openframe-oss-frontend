Renders the **Network** tab for a device detail view, displaying interface identity, geolocation, and sorted IPv4/IPv6 address lists — or an empty state when no network data is available.

## Key Components

| Export/Symbol | Description |
|---|---|
| `NetworkTab` | Primary exported component; accepts a `Device` or `null` and renders all network sections |
| `NetworkTabProps` | Props interface requiring a nullable `device` of type `Device` |
| `sortIpv4` | Numeric-aware comparator for dotted IPv4/CIDR strings (not lexicographic) |
| `toItems` | Filters and normalises raw `InfoRow[]` into the shape expected by `InfoCard` |
| `Labeled` | Local layout wrapper that adds a styled section heading above any child content |
| `InfoRow` | Internal type representing a label/value pair with optional `copyable` flag |

**Rendered sections:**
- **Network** — Public IP, Primary IPv4, MAC address
- **Location** — City and country from `device.geolocation`
- **IPv4 Addresses** — All local IPv4s, numerically sorted with the Fleet primary IP pinned first
- **IPv6 Addresses** — All local IPv6s, lexicographically sorted

## Usage Example

```typescript
import { NetworkTab } from './network-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  primary_ip: '192.168.1.10',
  public_ip: '203.0.113.42',
  primary_mac: 'aa:bb:cc:dd:ee:ff',
  local_ips: ['192.168.1.10', '192.168.1.20', 'fe80::1'],
  geolocation: { city: 'Austin', country: 'United States' },
};

export default function DeviceNetworkPanel() {
  return <NetworkTab device={device} />;
}
```

Pass `device={null}` to render the built-in empty state without additional guards in the parent.
