Renders the **Agents** tab on a device detail page, combining `installedAgents` and `toolConnections` from a `Device` into a unified, deduplicated list of agent cards.

## Key Components

- **`AgentsTab`** — Primary export. Merges installed agents with their corresponding tool connections, resolves online/offline status, and renders an `InfoCard` grid. Falls back to `TabEmptyState` when no agents are present.
- **`agentTypeToToolType`** — Maps agent type strings (e.g. `'fleetmdm-agent'`) to canonical tool type keys (e.g. `'FLEET_MDM'`).
- **`AGENT_TYPES_WITH_STATUS`** — Set of tool types (`FLEET_MDM`, `MESHCENTRAL`) that display a live status badge and last-seen timestamp.
- **`getAgentDisplayStatus`** — Resolves a normalized `'online' | 'offline'` display status from raw connection status strings per tool type.
- **`formatTimestamp` / `formatRelative`** — Parse ISO date strings into absolute (`formatDateTime`) or relative (`formatRelativeTime`) display values, guarding against invalid dates.

## Usage Example

```typescript
import { AgentsTab } from './agents-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  toolConnections: [
    { toolType: 'FLEET_MDM', status: 'online', lastSeen: '2025-01-10T12:00:00Z', agentToolId: 'abc123' }
  ],
  installedAgents: [
    { agentType: 'fleetmdm-agent', version: '4.58.0', updatedAt: '2025-01-10T12:00:00Z' }
  ],
};

export default function DeviceAgentsPage() {
  return <AgentsTab device={device} />;
}
```

**Merge logic:** Installed agents are matched to connections via `agentTypeToToolType`. Tool connections without a matching installed agent are appended as connection-only entries. Results are sorted alphabetically by `agentType` with `agentToolId` as a stable tie-breaker.
