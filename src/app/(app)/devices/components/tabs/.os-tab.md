Renders the OS tab panel for a device detail view, displaying operating system identity, boot/time information, and Fleet management metadata in a responsive grid layout.

## Key Components

- **`OsTab`** — Main exported component. Accepts a nullable `Device` and renders up to three `InfoCard` sections: Operating System, Boot & Time, and Management. Shows `OsEmptyState` when no data is available.
- **`toItems`** — Filters and normalizes `InfoRow` entries, stripping rows with empty/null/undefined values before passing them to `InfoCard`.
- **`formatUptime`** — Converts a raw seconds value into a human-readable string (e.g. `2d 4h`, `30m`, `< 1m`).
- **`Section`** — Lightweight layout wrapper rendering a labeled `<section>` with an uppercase `h3` heading.
- **`OsEmptyState`** — Fallback UI using `TabEmptyState` with a `TerminalMonitorIcon` when no OS data exists.

## Usage Example

```typescript
import { OsTab } from './os-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  os_version: 'macOS 14.4',
  platform: 'darwin',
  osVersion: '14.4.0',
  build: '23E214',
  cpu_type: 'arm64',
  boot_time: 1710000000,
  timezone: 'America/New_York',
  logged_in_username: 'jdoe',
  fleetTeamName: 'Engineering',
  fleetLabels: ['macOS', 'Managed'],
};

export default function DeviceDetail() {
  return <OsTab device={device} />;
}
```
