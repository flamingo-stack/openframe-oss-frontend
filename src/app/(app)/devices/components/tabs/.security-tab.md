Renders the Security tab within the device detail view, displaying posture data (encryption, security agents, and policy compliance) organized into labeled sections and cards derived from a normalized `Device` object.

## Key Components

| Export / Internal | Purpose |
|---|---|
| `SecurityTab` | Main exported component; builds sections from device data or shows an empty state |
| `buildSections` | Pure function that constructs `SecuritySection[]` from a `Device`, omitting sections with no available data |
| `SecuritySectionBlock` | Renders a titled section containing one or more posture cards in a responsive grid |
| `SecurityStatusCard` | Card displaying a list of labeled rows with colored values and status icons |
| `StatusRow` | Single label/value row with a dotted divider and an optional trailing `CheckCircle` or `AlertTriangle` icon |
| `normalizeVersion` | Strips empty strings and `"unknown"` agent version strings to `undefined` |
| `SecurityStatus` | Union type `'success' \| 'error' \| 'warning' \| 'neutral'` driving value color and icon selection |

## Usage Example

```typescript
import { SecurityTab } from './security-tab';
import type { Device } from '../../types/device.types';

// Renders posture sections when device data is present;
// falls back to an empty state when device is null or has no parseable posture data.
function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <div className="tab-panel">
      <SecurityTab device={device} />
    </div>
  );
}
```

## Section Build Logic

`buildSections` populates up to three sections, each only emitted when data exists:

```text
Encryption      → disk_encryption_enabled
Security Agents → openframe-client / osquery / orbit / fleet-desktop versions
Posture         → failingPoliciesCount, totalIssuesCount
```

Agent versions prefer `device.installedAgents` registry entries over Fleet's own host fields (which report `"unknown"` for the Flamingo-forked Fleet MDM agent).
