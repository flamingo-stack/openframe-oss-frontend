Renders the **Queries** tab within the device detail view, displaying scheduled fleet queries associated with a specific device with search filtering and frequency data joined from the global query list.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `QueriesTab` | React Component | Main tab component rendering the queries table with search |
| `QueriesTabProps` | Interface | Accepts a nullable `Device` object |

### Internal Logic

- **`useHostQueries`** — Fetches device-specific query reports from `/fleet/hosts/{id}/queries`
- **`useQueries`** — Fetches the team-scoped global query list to recover `interval` (frequency) data not present in the host endpoint
- **`intervalById`** — Memoized `Map<id, interval>` used to join frequency onto each host query row
- **`rows`** — Memoized `QueryTableRow[]` built by filtering reports by search term and mapping to table shape
- **`useStickyToolbar`** — Manages sticky search bar positioning within the tab scroll container

### Rendering Behavior

- Returns `TabEmptyState` if `device` is `null`
- Hides the search input when the table is truly empty (no rows, no active search, not loading)
- Each row links to `routes.monitoring.query(report_id)` via both `href` and an explicit action

## Usage Example

```typescript
import { QueriesTab } from './queries-tab';

// Inside a device detail page or tab panel:
<QueriesTab device={device} />

// With no device loaded yet:
<QueriesTab device={null} />
// → Renders centered empty state with icon
```
