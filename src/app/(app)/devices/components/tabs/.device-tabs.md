Defines and exports the `DEVICE_TABS` configuration array, which declares all tab items displayed on a device detail page in the OpenFrame frontend.

## Key Components

- **`DEVICE_TABS`** — A static `TabItem[]` array that registers each tab's `id`, `label`, icon component, and content component. Currently includes 11 active tabs (Queries tab is temporarily disabled).

| Tab ID | Label | Component |
|---|---|---|
| `overview` | Overview | `OverviewTab` |
| `vulnerabilities` | Vulnerabilities | `VulnerabilitiesTab` |
| `policies` | Policies | `PoliciesTab` |
| `security` | Security | `SecurityTab` |
| `agents` | Agents | `AgentsTab` |
| `tickets` | Tickets | `TicketsTab` |
| `hardware` | Hardware | `HardwareTab` |
| `os` | OS | `OsTab` |
| `network` | Network | `NetworkTab` |
| `users` | Users | `UsersTab` |
| `software` | Software | `SoftwareTab` |

## Usage Example

Pass `DEVICE_TABS` directly to a tab rendering component that accepts `TabItem[]`:

```typescript
import { DEVICE_TABS } from './device-tabs';
import { Tabs } from '@flamingo-stack/openframe-frontend-core/components/ui';

export function DeviceDetailPage() {
  return <Tabs items={DEVICE_TABS} defaultTab="overview" />;
}
```

To add a new tab, append a new `TabItem` entry to the array:

```typescript
import { NewIcon } from '@flamingo-stack/openframe-frontend-core/components/icons-v2';
import { MyNewTab } from './my-new-tab';

// Inside DEVICE_TABS array:
{
  id: 'my-tab',
  label: 'My Tab',
  icon: NewIcon,
  component: MyNewTab,
}
```

> **Note:** The `queries` tab is temporarily disabled and commented out. Its entry (`BracketCurlyEllipsisVrIcon`, `QueriesTab`) is preserved in comments for re-enablement.
