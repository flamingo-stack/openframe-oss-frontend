Renders the Tickets tab on a device detail page, displaying all support tickets associated with a specific device via client-side filtering until a server-side device filter is available.

## Key Components

- **`TicketsTab`** — Main exported component; accepts a `Device` prop and renders a searchable, infinitely-scrollable ticket table scoped to that device
- **`ticketBelongsToDevice`** — Pure helper that matches a ticket to a device by `machineId` or `id` across multiple ticket ownership shapes (`deviceId`, `owner.machine`, `owner.machineId`)
- **`DEVICE_TICKETS_PAGE_SIZE`** — Constant (`100`) capping the fetch size for the client-side filter workaround

## Usage Example

```typescript
import { TicketsTab } from './tickets-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  id: 'abc123',
  machineId: 'machine-xyz',
  // ...other fields
};

<TicketsTab device={device} />
```

## Notes

- **Client-side filtering workaround**: The tickets API currently has no device/machine filter, so the component fetches up to 100 tickets and filters them locally via `ticketBelongsToDevice`. This should be replaced with a server-side `filter: { machineIds }` once supported.
- The `source` column is stripped from the shared ticket table columns since it's redundant in a device-scoped context.
- Column widths for `assignee` (`w-[280px]`) and `status` (`w-[160px]`) are pinned to match the `DeviceDetailsSkeleton` to prevent layout shifts between loading and loaded states.
- Shows `TicketsEmptyState` when no tickets exist; shows the inline empty state when a search yields no results.
