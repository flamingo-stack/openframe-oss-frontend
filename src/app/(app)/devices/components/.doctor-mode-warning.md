Renders a dismissible warning block prompting users to run a platform-specific OpenFrame doctor command when a device is not appearing or is stuck in a pending state.

## Key Components

- **`DoctorModeWarning`** — Client component that displays a `WarningBlock` with a copyable doctor command tailored to the current OS platform
- **`useCopyToClipboard`** — Hook providing clipboard copy functionality with success/error toast feedback
- **`OPENFRAME_DOCTOR_COMMANDS`** — Map of platform IDs to their corresponding doctor CLI commands
- **`PathsDisplay`** — Component that renders the command with a copy-to-clipboard button
- **`OSPlatformId`** — Type representing supported OS platform identifiers (e.g. `win32`, `darwin`, `linux`)

## Usage Example

```typescript
import { DoctorModeWarning } from './doctor-mode-warning';

// Rendered within a device enrollment or agent status view
<DoctorModeWarning platform="darwin" />
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `platform` | `OSPlatformId` | The OS platform used to select the correct doctor command |

## Notes

- Marked `'use client'` — must run in a browser context
- The `copyCommand` callback is memoized with `useCallback` to avoid unnecessary re-renders
- Clipboard notifications are pre-configured with descriptive success/error messages for user clarity
