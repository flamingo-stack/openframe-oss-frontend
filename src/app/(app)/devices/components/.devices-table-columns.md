Defines column definitions, filter metadata, and the `DevicesTableBody` component for rendering the devices data table with support for filtering, custom actions, and responsive visibility.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DevicesTableBody` | Component | Full table component with header, body, skeleton loading, and optional footer slot |
| `getDeviceTableColumns` | Function | Returns `ColumnDef<Device>[]` for device, status, OS, and organization columns |
| `getDeviceFilterColumns` | Function | Returns filter metadata for the external mobile filter modal (`useTagFilterModal`) |
| `getDeviceTableRowActions` | Function | Factory returning a row actions renderer (three-dot dropdown) with optional refresh callback |
| `DEVICE_OPEN_COLUMN` | Constant | Static column definition rendering an "open in new tab" button |
| `deviceRowHref` | Function | Resolves a device's navigation URL using `machineId` with fallback to `id` |

## Usage Example

```typescript
// Basic table with server-side filters and custom actions
import {
  DevicesTableBody,
  getDeviceTableRowActions,
} from './devices-table-columns';

function DevicesPage({ devices, deviceFilters, totalCount }) {
  const handleRefresh = () => refetch();

  const actionsColumn = {
    id: 'actions',
    cell: ({ row }) => getDeviceTableRowActions(handleRefresh)(row.original),
  };

  return (
    <DevicesTableBody
      devices={devices}
      deviceFilters={deviceFilters}
      totalCount={totalCount}
      actionsColumn={actionsColumn}
      hideColumns={['organization']} // scoped to single org
      disableColumnFilters={['status']} // e.g. archive page
      stickyHeaderOffset="64px"
    />
  );
}
```

## Notes

- `hideColumns` removes entire columns; `disableColumnFilters` keeps a column visible but strips its header filter dropdown.
- Filter options are derived from `DeviceFilters` and only include `DEFAULT_VISIBLE_STATUSES` (excludes `ARCHIVED` and `DELETED`).
- Organization filter options are deduplicated via `deduplicateFilterOptions` to handle duplicate entries from the API.
- `OrganizationCell` is an internal component and is not exported.
