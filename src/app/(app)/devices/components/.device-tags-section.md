Renders the "Device Tags" section on the device Overview tab, displaying a device's key:value tag pairs as badge chips. Returns `null` when the device has no tags.

## Key Components

### `DeviceTagsSection`
A client-side React component that accepts a `Device` object and flattens its `tags` array (where each tag may have multiple values) into individual `key:value` chip entries.

- **`DeviceTagsSectionProps`** — `{ device: Device }` input interface
- Flattens `tag.values[]` so each unique `key:value` pair renders as its own `Tag` chip
- Uses the `badge` variant of the `Tag` component from `@flamingo-stack/openframe-frontend-core`, which applies the ODS card-border mono-uppercase style
- The `label` prop (`"key:value"`) doubles as a native `title` tooltip on hover — no extra tooltip wrapper needed

## Usage Example

```typescript
import { DeviceTagsSection } from './device-tags-section';

// Inside a device Overview tab layout:
<DeviceTagsSection device={device} />
```

Given a device with:

```typescript
device.tags = [
  { tagId: 'env', key: 'env', values: ['prod', 'us-east'] },
  { tagId: 'tier', key: 'tier', values: ['web'] },
];
```

Renders three chips: `env:prod`, `env:us-east`, `tier:web`. If `device.tags` is empty or undefined, renders nothing.
