Renders a responsive card displaying detailed metadata for a single device, including hostname, OS type, serial number, UUID (with clipboard copy), customer link, and timestamps.

## Key Components

- **`DeviceInfoSection`** — Main export. Accepts a nullable `Device` prop and renders a styled info card with graceful empty state handling.
- **`formatDateWithTime`** — Internal helper that formats an ISO date string into a date + secondary-styled time node, returning `'Unknown'` for missing/invalid values.
- **`DeviceInfoSectionProps`** — Interface accepting `device: Device | null`.

## Usage Example

```typescript
import { DeviceInfoSection } from '@/app/components/features/devices/device-info-section';

// Inside a server or client component
<DeviceInfoSection device={device} />
```

## Layout Behavior

The component uses three responsive breakpoints to reorder cells:

| Breakpoint | Layout |
|---|---|
| `< md` (mobile) | Customer/assigned user as full-width rows |
| `md–lg` (tablet) | Customer + assigned user share one horizontal row |
| `lg+` (desktop) | 4 cells per row matching Figma 9-57016 |

## Key Details

- **UUID copy** — Uses `useCopyToClipboard`; the copy button swaps to a `CheckIcon` on success and is disabled when UUID is `'Unknown'`.
- **Customer link** — Renders a navigable `<Link>` to `routes.customers.details(organizationId)` when an organization ID is present; falls back to plain text.
- **Assigned user** — Block is intentionally hidden (`username: null`) pending backend support for returning a user entity.
- **Image URLs** — Resolved via `getFullImageUrl` supporting both direct URLs and hash-based paths.
