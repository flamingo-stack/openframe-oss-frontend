Renders a sticky horizontal filter bar above the devices grid, exposing per-column dropdown filters that mirror the table view's column-header filters.

## Key Components

### `DevicesGridFilters` (exported function component)

Accepts filterable column definitions and current filter state, rendering one `FiltersDropdown` per filterable column plus an optional results count.

**Props (`DevicesGridFiltersProps`):**

| Prop | Type | Description |
|---|---|---|
| `filterColumns` | `DeviceFilterColumn[]` | Column definitions sourced from `devices-table-columns` |
| `currentFilters` | `Record<string, string[]>` | Active filter values keyed by column ID |
| `onFilterChange` | `(filters: Record<string, string[]>) => void` | Called on apply/reset; intended to write back to URL params |
| `totalCount` | `number` (optional) | Server-side result count shown in the trailing label |

Returns `null` when no filterable columns exist and `totalCount` is undefined.

## Usage Example

```typescript
import { DevicesGridFilters } from './devices-grid-filters';
import { deviceFilterColumns } from './devices-table-columns';

export function DevicesGridView() {
  const [filters, setFilters] = useDeviceFilters(); // writes to URL params

  return (
    <>
      <DevicesGridFilters
        filterColumns={deviceFilterColumns}
        currentFilters={filters}
        onFilterChange={setFilters}
        totalCount={142}
      />
      {/* grid content */}
    </>
  );
}
```

Each dropdown uses checkbox-style multi-select with a "select all" option. Active filters are visually indicated via `text-ods-accent` on the filter icon. The bar is sticky at `top-[96px]` to remain visible during scroll.
