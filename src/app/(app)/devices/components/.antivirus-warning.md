Renders an antivirus warning block for OpenFrame installations, displaying platform-specific folder paths that users should add to their antivirus exclusion list, with clipboard copy support.

## Key Components

- **`AntivirusWarning`** — Client component that accepts a `platform` prop (`OSPlatformId`) and conditionally renders a `WarningBlock` with OS-specific paths. Returns `null` if no paths exist for the given platform.
- **`OPENFRAME_PATHS`** — Imported constant providing Windows and macOS (`darwin`) exclusion paths.
- **`PathsDisplay`** — Renders the list of paths with individual copy-to-clipboard buttons.
- **`useCopyToClipboard`** — Custom hook wiring up clipboard copy with toast-style success/error feedback.

## Usage Example

```typescript
import { AntivirusWarning } from './antivirus-warning';

// Render inside an installer flow, passing the detected OS platform
export function InstallerStep() {
  const platform = 'windows'; // or 'darwin'

  return (
    <div>
      <h2>Install OpenFrame</h2>
      <AntivirusWarning platform={platform} />
    </div>
  );
}
```

## Notes

- Only renders for `windows` and `darwin` platforms; all other `OSPlatformId` values return `null`.
- Path list is memoized via `useMemo` to avoid recomputation on unrelated re-renders.
- The copy handler is stabilized with `useCallback` to prevent unnecessary child re-renders.
