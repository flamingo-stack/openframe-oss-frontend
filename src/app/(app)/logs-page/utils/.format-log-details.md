Produces a canonical plain-text string from a `LogEntry` object, used by every "Copy Log Details" affordance to ensure a consistent copied payload regardless of where it is triggered.

## Key Components

- **`formatLogDetailsForCopy(log: LogEntry): string`** — Formats a log entry into a newline-joined string containing the log ID, severity status, timestamp, tool type, event type, message, and details. Falls back to `'No message available'` and `'No details available'` for missing optional fields.

## Usage Example

```typescript
import { formatLogDetailsForCopy } from './format-log-details';

const log: LogEntry = {
  toolEventId: 'evt_123',
  severity: 'ERROR',
  timestamp: '2024-01-15T10:30:00Z',
  toolType: 'monitoring',
  eventType: 'alert',
  message: 'Disk usage exceeded threshold',
  details: 'Partition /dev/sda1 at 95%',
};

const text = formatLogDetailsForCopy(log);
// Log ID: evt_123
// Status: ERROR
// Timestamp: 2024-01-15T10:30:00Z
// Tool Type: monitoring
// Event Type: alert
// Message: Disk usage exceeded threshold
// Details: Partition /dev/sda1 at 95%

navigator.clipboard.writeText(text);
```

## Notes

- Both the log-details page action and the logs table row "Copy" button share this function, guaranteeing the copied output is identical across surfaces.
