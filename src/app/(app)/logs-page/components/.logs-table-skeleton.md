A lightweight loading skeleton for the `LogsTable` component that renders an empty `DataTable` with matching column definitions, preserving header layout and column widths during data fetches.

## Key Components

- **`LogsTableSkeleton`** — Exported React component that renders a structural placeholder table with 10 skeleton rows and no data
- **`EMPTY_LOG_ROWS`** — Stable empty array passed as table data to avoid unnecessary re-renders
- **Column definitions** — Eight columns (`logId`, `status`, `tool`, `source`, `description`, `copy`, `quickView`, `open`) mirroring the real `LogsTable` layout, including responsive `hideAt` breakpoints and fixed widths

## Usage Example

```typescript
import { LogsTableSkeleton } from './logs-table-skeleton';

// Used as a Suspense fallback or route-level loading state
export default function LogsPage() {
  return (
    <Suspense fallback={<LogsTableSkeleton />}>
      <LogsTable />
    </Suspense>
  );
}
```

## Notes

- Intentionally isolated from `logs-table.tsx` to avoid pulling in Relay queries, generated artifacts, and drawer machinery — safe to import in device-details skeletons and route-level loading states
- The `stickyHeaderOffset` of `top-[96px]` matches the real table's header positioning for a seamless transition
- Column `meta.width` values mirror the real table exactly so the layout does not shift when data loads
