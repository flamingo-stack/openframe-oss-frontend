Renders the main logs data table with Relay-powered pagination, filtering, sorting, and date-range selection for log entries in the OpenFrame frontend.

## Key Components

### `LogsTable` (default export, `forwardRef`)
Top-level table container that owns the search, filter, and sort state. Wraps `LogsTableContent` in a `Suspense` boundary and exposes a `refresh()` handle via `LogsTableRef`.

### `LogsTableContent`
Inner Relay-connected component that:
- Fetches logs via `logsTableRelayQuery` / `logsTableRelayFragment`
- Handles cursor-based pagination (`loadNext`)
- Builds `UiLogEntry` view models from raw GraphQL nodes
- Defines all `ColumnDef<UiLogEntry>[]` including the custom calendar header

### Key Types

| Type | Purpose |
|---|---|
| `LogsTableProps` | Public props: `deviceId`, `organizationId`, `embedded`, `showHeader` |
| `LogsTableRef` | Imperative handle exposing `refresh()` |
| `UiLogEntry` | Normalized view model consumed by the data table |
| `LogSortInput` | `{ field: LogSortField; direction: SortDirection }` |

### GraphQL

- `logsTableRelayQuery` — root query (filter, pagination, `logFilters`)
- `logsTableRelayFragment` — `@refetchable` pagination fragment on `Query`

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table';
import { useRef } from 'react';

function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null);

  return (
    <>
      <button onClick={() => tableRef.current?.refresh()}>
        Refresh
      </button>

      {/* Standalone full-page view */}
      <LogsTable ref={tableRef} showHeader />

      {/* Scoped to a single device, embedded inside a tab */}
      <LogsTable
        ref={tableRef}
        deviceId="device-abc-123"
        organizationId="org-xyz"
        embedded
        showHeader={false}
      />
    </>
  );
}
```
