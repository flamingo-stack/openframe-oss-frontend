Renders an expandable approval sub-row within a notification list item, allowing users to approve or reject pending requests with optimistic UI updates.

## Key Components

### `NotificationApprovalSubRow`
Main exported component that displays command details, explanation text, and approve/reject controls for an approval-request notification.

**Props (`NotificationApprovalSubRowProps`):**
| Prop | Type | Description |
|------|------|-------------|
| `notification` | `Notification` | The notification containing approval metadata |
| `onResolved` | `(notificationId: string) => void` | Optional callback fired after a successful approve/reject action |

**Internal logic:**
- **`localStatus`** — Optimistic `ChatApprovalStatus` state set immediately on user click, rolled back if the API call fails
- **`status`** — Resolves to the backend `resolvedStatus` if it's no longer `'pending'`; otherwise falls back to `localStatus`
- **`batchData`** — Memoized conversion of approval metadata into the format expected by `ApprovalBatchMessage`
- **`decide(approve)`** — Async callback that sets optimistic state, calls `useApproveRequest`, triggers `onResolved`, and rolls back on failure

Returns `null` when no valid approval metadata or batch data is found.

## Usage Example

```typescript
<NotificationApprovalSubRow
  notification={notification}
  onResolved={(id) => markNotificationRead(id)}
/>
```
