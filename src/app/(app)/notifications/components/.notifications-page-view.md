The top-level page view component for the notifications feature, orchestrating tab navigation, shared search state, Relay query loading, and bulk mutation actions across "New Notifications" and "Notifications History" tabs.

## Key Components

| Export / Symbol | Description |
|---|---|
| `NotificationsPageView` | Main page view React component rendered under the `/notifications` route |
| `NOTIFICATIONS_TABS` | Static tab config array (`new`, `history`) passed to `TabNavigation` |
| `SEARCH_DEBOUNCE_MS` | 300 ms debounce constant applied to the shared search input |

## Usage Example

```typescript
// app/notifications/page.tsx
import { NotificationsPageView } from './notifications-page-view';

export default function NotificationsPage() {
  return <NotificationsPageView />;
}
```

## Key Behaviors

- **Shared search** — a single search string is debounced (`300 ms`) and applied to both tabs; the URL param (`?search=`) is updated lazily so typing stays responsive.
- **Tab switching** — `handleTabChange` clears the search state on user-initiated tab changes while preserving deep-link URLs like `?tab=history&search=foo`.
- **Independent Relay queries** — `newQueryRef` and `historyQueryRef` each call `notificationsSectionRelayQuery` with `read: false` / `read: true` filters respectively; both reload whenever `debouncedSearch` changes.
- **Bulk mutations** — `useNotificationMutations` provides `markAllRead` (New tab action) and `removeAllRead` (History tab action), with disabled states (`isMarkingAllRead`, `isDeletingAllRead`) fed into the `PageActionButton` configs.
- **Toast feedback** — success toasts fire via `useToast` on completion of both bulk mutations.
