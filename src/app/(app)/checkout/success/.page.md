Renders the post-checkout success page displayed after a user completes a payment, showing a confirmation message with navigation options to the dashboard or subscription settings.

## Key Components

- **`CheckoutSuccessPage`** — Default export page component that composes `CheckoutResultCard` with success-specific props (icon, colors, copy, and CTAs)

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to the checkout success route.
// No props required — all content is statically defined within the component.

import CheckoutSuccessPage from '@/app/(checkout)/success/page';

// Next.js App Router renders this as a full page:
<CheckoutSuccessPage />
```

## Notes

- Uses the `CheckCircle2` icon from `lucide-react` styled with `bg-ods-success-secondary` and `text-ods-success` design tokens
- Primary CTA navigates to `routes.dashboard`; secondary CTA navigates to `routes.settings.billingUsage`
- Marked `'use client'` — runs in the browser, enabling client-side routing via the CTA links
