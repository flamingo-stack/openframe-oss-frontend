Renders the checkout cancellation confirmation page, displayed when a user cancels the payment flow before completing a purchase.

## Key Components

- **`CheckoutCancelPage`** — Default export page component that renders a `CheckoutResultCard` with an error/cancel state, informing the user no charges were made and providing navigation back to billing plans or the dashboard.

## Usage Example

```typescript
// Rendered automatically by Next.js at the /checkout/cancel route.
// No props required — navigation targets are sourced from the routes config.

import { routes } from '@/lib/routes';

// CTA destinations used internally:
routes.settings.billingUsage // "Back to Billing"
routes.dashboard                    // "Go to Dashboard"
```

## Notes

- Uses `XCircle` from `lucide-react` as the cancel icon, styled with `bg-ods-error-secondary text-ods-error` design tokens.
- Entirely client-side (`'use client'`) with no data fetching or props.
- Part of the checkout result flow alongside a success counterpart; see [`CheckoutResultCard`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/checkout/components/checkout-result-card.tsx) for the shared card UI.
