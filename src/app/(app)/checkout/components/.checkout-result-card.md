A reusable presentational card component for displaying checkout outcomes (success, failure, etc.) with an icon, title, description, and one or two call-to-action buttons.

## Key Components

### `CheckoutResultCard`

A client-side React component that renders a centered card with:

- **Icon** — accepts any component accepting a `className` prop, wrapped in a styled circle
- **Title & Description** — supports plain strings or rich `ReactNode` for the description
- **Primary CTA** — always rendered as an accent `Button`
- **Secondary CTA** — optional outline `Button`, conditionally rendered

### `CheckoutResultCardProps`

| Prop | Type | Required | Description |
|---|---|---|---|
| `icon` | `ComponentType<{ className? }>` | ✅ | Icon component to display |
| `iconWrapperClassName` | `string` | ✅ | Background/color class for the icon circle |
| `title` | `string` | ✅ | Card heading |
| `description` | `ReactNode` | ✅ | Supporting text or rich content |
| `primaryCta` | `{ label, href }` | ✅ | Main action button |
| `secondaryCta` | `{ label, href }` | ❌ | Optional secondary action button |

## Usage Example

```typescript
import { CheckoutResultCard } from './checkout-result-card';
import { CheckCircleIcon } from 'lucide-react';

export default function CheckoutSuccessPage() {
  return (
    <CheckoutResultCard
      icon={CheckCircleIcon}
      iconWrapperClassName="bg-green-100 text-green-600"
      title="Payment Successful"
      description="Your subscription is now active."
      primaryCta={{ label: 'Go to Dashboard', href: '/dashboard' }}
      secondaryCta={{ label: 'View Invoice', href: '/billing/invoices' }}
    />
  );
}
```
