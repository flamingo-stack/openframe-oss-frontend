Ticket statuses page component that conditionally renders based on application mode, redirecting non-SaaS tenant users to the dashboard.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TicketStatusesPage` | Default export (React component) | Page-level component that guards access to ticket status management |

## Usage Example

```typescript
// Automatically rendered by Next.js routing at the ticket statuses route.
// Direct usage is handled by the Next.js App Router.

// Access guard logic (simplified):
if (!isSaasTenantMode()) {
  router.replace(routes.dashboard); // Redirect non-SaaS tenants
}

// Renders when in SaaS tenant mode:
return <TicketStatusesView />;
```

## Behavior

- **SaaS Tenant Mode** — Renders [`TicketStatusesView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/ticket-statuses/components/ticket-statuses-view.tsx) to display and manage ticket statuses.
- **Non-SaaS Mode** — Immediately redirects to the dashboard via `router.replace(routes.dashboard)` and returns `null` to prevent any flash of content.

## Dependencies

| Import | Purpose |
|--------|---------|
| `isSaasTenantMode` | Runtime check for SaaS tenant context |
| `routes.dashboard` | Typed route constant for redirect target |
| `TicketStatusesView` | UI component rendering ticket status management |
