A client-side React component that renders the tags/labels section within a ticket detail dialog, supporting tag display, selection, creation, and deletion.

## Key Components

**`TicketTagsSection`** — Main exported component accepting:
- `ticketId` — ID of the ticket being edited
- `labels` — Current labels attached to the ticket (from `Dialog['labels']`)

**Hooks used:**
- `useTicketLabels` — Fetches all available ticket labels
- `useSetTicketLabels` — Mutation to update the full label set on a ticket
- `useCreateTagMutation` — Mutation to create a new global tag
- `useTicketTagDelete` — Handles delete confirmation flow with dialog state

**UI Components:**
- `Tag` — Renders an individual removable tag chip
- `TagSelectDropdown` — Multi-select dropdown with inline create and delete support

## Usage Example

```typescript
import { TicketTagsSection } from './ticket-tags-section';

<TicketTagsSection
  ticketId="ticket-abc-123"
  labels={[
    { id: 'tag-1', key: 'bug' },
    { id: 'tag-2', key: 'urgent' },
  ]}
/>
```

## Behavior Notes

- **Tag selection** — `handleChange` replaces the full label set via mutation
- **Inline removal** — `removeTag` filters out a single ID and mutates
- **Create flow** — Creates the tag globally, refetches the list, then appends the new ID to the current selection
- **Delete flow** — `requestDelete` triggers a confirmation dialog; on confirm, the tag is removed from the ticket's selected IDs if currently applied
- Tags are limited to 25 characters on creation (`maxCreateLength={25}`)
