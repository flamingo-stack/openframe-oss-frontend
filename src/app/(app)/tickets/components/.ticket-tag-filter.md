A client-side filter bar component that combines a text search input with tag filtering for the ticket list, powered by tenant-specific ticket tags.

## Key Components

- **`TicketTagFilter`** — Main exported component that wraps `TagFilterBar` with ticket tag data
- **`useTicketTags`** — Hook that fetches tenant ticket tags (id + key) from the API
- **`TagFilterBar`** — Shared UI component receiving the mapped tags and search state

### Props (`TicketTagFilterProps`)

| Prop | Type | Description |
|------|------|-------------|
| `search` | `string` | Current search input value |
| `onSearchChange` | `(value: string) => void` | Search input change handler |
| `tagIds` | `string[]` | Currently selected tag IDs |
| `onTagIdsChange` | `(ids: string[]) => void` | Tag selection change handler |
| `filterButton` | `ReactNode` | Optional mobile filter button rendered next to the search input |

## Usage Example

```typescript
import { TicketTagFilter } from './ticket-tag-filter';

function TicketListHeader() {
  const [search, setSearch] = useState('');
  const [tagIds, setTagIds] = useState<string[]>([]);

  return (
    <TicketTagFilter
      search={search}
      onSearchChange={setSearch}
      tagIds={tagIds}
      onTagIdsChange={setTagIds}
      filterButton={<MobileFilterButton />}
    />
  );
}
```

## Notes

- Tags are memoized via `useMemo` to avoid unnecessary re-renders when the `allTags` array reference changes
- The placeholder text is hardcoded as `"Search for Ticket"`
