Renders the shared empty state UI for the Tickets page and device-details Tickets tab, displaying a tag icon, descriptive message, three feature tiles, and an onboarding guide footer button.

## Key Components

- **`TicketsEmptyState`** — Client component that composes `EmptyState` with tickets-specific copy, icons, and an onboarding guide CTA via `onboardingGuideButton('tickets', ...)`.

## Usage Example

```typescript
// Tickets page
import { TicketsEmptyState } from './tickets-empty-state';

export default function TicketsPage() {
  const hasTickets = tickets.length > 0;

  return hasTickets ? <TicketsList /> : <TicketsEmptyState />;
}
```
