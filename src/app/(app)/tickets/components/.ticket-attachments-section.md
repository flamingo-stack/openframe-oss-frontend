Renders the attachments section within a ticket detail dialog, handling file uploads, downloads, and deletion with confirmation.

## Key Components

- **`TicketAttachmentsSection`** — Main exported component that displays existing attachments and provides upload/delete controls
- **`uiAttachments`** — Transformed attachment list mapping raw data to UI-ready objects with formatted file sizes and action handlers
- **`handleFilesSelected`** — Handles native file input change events, triggering the `addAttachments` mutation
- **`confirmDelete`** — Executes the delete mutation after user confirmation, clearing pending state on success

## Props

| Prop | Type | Description |
|---|---|---|
| `ticketId` | `string` | ID of the parent ticket, passed to mutation hooks |
| `attachments` | `NonNullable<Dialog['attachments']>` | Array of attachment objects from the ticket dialog state |

## Usage Example

```typescript
import { TicketAttachmentsSection } from './ticket-attachments-section';

<TicketAttachmentsSection
  ticketId="ticket-abc-123"
  attachments={ticket.attachments ?? []}
/>
```
