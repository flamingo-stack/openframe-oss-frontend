Defines the column configuration and table body component for displaying support tickets (`Dialog` records) in a data table, including title, source device, assignee, status, and open-in-new-tab action columns.

## Key Components

### `getTicketTableColumns(options)`
Returns an array of four `ColumnDef<Dialog>` column definitions:
- **Title** – ticket title with creation timestamp
- **Source** – device/hostname and organization via `DeviceCardCompact` (hidden below `md`)
- **Assignee** – avatar + name, or em-dash when unassigned (hidden below `lg`)
- **Status** – `TicketStatusTag` with optional multi-select filter support; filter options fall back to `LEGACY_STATUS_FILTER_OPTIONS` when `statusOptions` is omitted

### `getTicketOpenColumn(getUnreadCount?)`
Returns an actions column that renders an unread-message badge when unread count is present, otherwise an "open in new tab" icon button.

### `TicketTableBody`
A self-contained `DataTable` component that composes all columns, wires up `useDataTable`, and renders header, body (with loading/empty states), and an optional footer slot.

### `ticketRowHref(ticket)`
Helper that resolves a ticket row's navigation URL via `routes.tickets.dialog`.

### `LEGACY_STATUS_FILTER_OPTIONS`
Static fallback filter options (`ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`) used when lifecycle status options are not provided.

## Usage Example

```typescript
import { TicketTableBody } from './ticket-table-columns';

function MyTicketList({ tickets, isLoading, statusOptions }) {
  return (
    <TicketTableBody
      tickets={tickets}
      isLoading={isLoading}
      statusOptions={statusOptions}
      getUnreadCount={(ticket) => ticket.unreadCount}
      emptyMessage="No tickets yet."
      stickyHeaderOffset="64px"
    />
  );
}
```- `getTicketTableColumns` accepts `isUserDeleted` (from `useUserStatusMap`); when it flags `assignedTo`, the assignee cell renders `DeletedUserAvatar` + red name. `TicketTableBody` wires it automatically.
