Utility module providing reusable avatar rendering helpers for autocomplete dropdown components in ticket forms.

## Key Components

### `renderAvatarOption(variant)`
A curried function that returns an autocomplete option renderer. Displays a `SquareAvatar` alongside a truncated label, and shows a `CheckIcon` when the option is selected.

- **`variant`** — `'round' | 'square'` — controls avatar shape

### `avatarStartAdornment(option, variant)`
Returns a `SquareAvatar` node for use as a start adornment inside an autocomplete input field. Returns `undefined` when no option is selected.

## Usage Example

```typescript
import {
  renderAvatarOption,
  avatarStartAdornment,
} from './avatar-autocomplete';

// Render each option row in an autocomplete dropdown
const renderOption = renderAvatarOption('round');

<Autocomplete
  options={technicianOptions}
  renderOption={renderOption}
  startAdornment={avatarStartAdornment(selectedOption, 'round')}
/>
```

## Notes

- Relies on [`getFullImageUrl`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/image-url.ts) to resolve relative image paths.
- Expects options to conform to `AvatarOption` (extends `AutocompleteOption` with an `imageUrl` field) from [`use-ticket-options`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/features/tickets/hooks/use-ticket-options.ts).
- Image fallback text is derived from the option `label`.
