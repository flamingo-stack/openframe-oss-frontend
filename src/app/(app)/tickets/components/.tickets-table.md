Renders a paginated, filterable tickets data table with support for search, label filtering, status filtering, and infinite scroll for both active and archived ticket views.

## Key Components

### `TicketsTable`
The primary component accepting these props:

| Prop | Type | Description |
|------|------|-------------|
| `isArchived` | `boolean` | Switches between active and archived ticket views |
| `statusFilters` | `string[]` | Active status filter IDs |
| `onStatusFilterChange` | `(status: string[]) => void` | Callback when status filters change |
| `search` | `string` | Current search string |
| `onSearchChange` | `(value: string) => void` | Callback when search input changes |
| `labelIds` | `string[]` | Active label/tag filter IDs |
| `onLabelIdsChange` | `(ids: string[]) => void` | Callback when label filters change |
| `backButton` | `{ label?: string; onClick: () => void }` | Optional back navigation |
| `selector` | `ReactNode` | Optional selector element injected into the page header |

### `CurrentTickets`
Convenience wrapper rendering `TicketsTable` with `isArchived={false}`.

### `ArchivedTickets`
Convenience wrapper rendering `TicketsTable` with `isArchived={true}`.

## Key Behaviors

- **Debounced search** — search input is debounced 300ms before triggering queries
- **Infinite scroll** — uses `DataTable.InfiniteFooter` with `fetchNextPage`
- **Mobile filters** — column filters collapse into a `FilterModal` on small screens
- **Status filters** — sourced from `useTicketStatusesQuery`; archived view hides status filters entirely
- **Empty state** — shows `TicketsEmptyState` only when no data exists and no active query/filters are applied
- **Unread highlighting** — feature-flagged off (`HIGHLIGHT_UNREAD_FROM_NOTIFICATIONS = false`); re-enable once the backend exposes unread counts on the ticket entity

## Usage Example

```typescript
<CurrentTickets
  search={searchValue}
  onSearchChange={setSearchValue}
  labelIds={selectedLabels}
  onLabelIdsChange={setSelectedLabels}
  statusFilters={selectedStatuses}
  onStatusFilterChange={setSelectedStatuses}
/>

<ArchivedTickets
  search={archiveSearch}
  onSearchChange={setArchiveSearch}
  labelIds={[]}
  onLabelIdsChange={() => {}}
/>
```
