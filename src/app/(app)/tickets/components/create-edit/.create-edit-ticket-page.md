Page component that renders the create/edit ticket form within a `PageLayout`, handling navigation, form state, and action buttons for both create and edit modes.

## Key Components

- **`CreateEditTicketPage`** — Main exported component that orchestrates the ticket form page
- **`useCreateTicketForm`** — Custom hook providing form state, submission handler, edit mode detection, and attachment management
- **`useSafeBack`** — Hook for safe back navigation, resolving to ticket detail or ticket list depending on context
- **`TicketFormFields`** — Renders the actual form field UI
- **`PageLayout`** — Shell component providing title, back button, and action bar (mobile/desktop responsive)

## Usage Example

```typescript
// Rendered via Next.js route; supports optional `?edit=<ticketId>` query param
// e.g. /tickets/new         → create mode
// e.g. /tickets/new?edit=42 → edit mode

import { CreateEditTicketPage } from './create-edit-ticket-page';

export default function Page() {
  return <CreateEditTicketPage />;
}
```

## Behaviour Notes

- **Edit mode** is detected from the `?edit` search parameter; when present, the existing ticket is loaded and the title/save label update accordingly
- **Back navigation**: edit mode navigates back to the ticket dialog; create mode navigates to the ticket list
- **Actions bar**: the `Cancel` button is marked `showOnlyMobile: true` — on desktop the header back button serves as cancellation; `Save` is always visible and is disabled while submitting or loading
