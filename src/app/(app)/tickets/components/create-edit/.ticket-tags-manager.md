Manages ticket tag selection with support for creating new tags inline, optimistic UI updates, and tag deletion via an autocomplete interface.

## Key Components

### `TicketTagsManager`

**Props (`TicketTagsManagerProps`):**

| Prop | Type | Description |
|---|---|---|
| `selectedIds` | `string[]` | Currently selected tag IDs |
| `onChange` | `(ids: string[]) => void` | Callback fired with updated tag ID list |
| `disabled` | `boolean?` | Disables the input when `true` |

**Internal hooks:**
- `useTicketLabels` — fetches available ticket tags
- `useCreateTagMutation` — creates a new tag with `entityType: 'TICKET'`
- `useTicketTagDelete` — handles delete confirmation dialog and removal

**Optimistic updates:**  
New tags typed by the user are immediately added with a `_optimistic_<uuid>` temp ID. Once the mutation resolves, the temp ID is replaced with the real server-assigned ID and the tag list is refetched.

## Usage Example

```typescript
import { TicketTagsManager } from './ticket-tags-manager';

function TicketForm() {
  const [tagIds, setTagIds] = useState<string[]>([]);

  return (
    <TicketTagsManager
      selectedIds={tagIds}
      onChange={setTagIds}
      disabled={false}
    />
  );
}
```

## Behavior Notes

- **Creatable:** Users can type a new tag name (max 25 characters) and it is immediately reflected optimistically while the API call is in-flight.
- **Deletion:** Removing a tag from the dropdown triggers a confirmation dialog before committing; the `onChange` callback is called only after confirmation.
- **Loading state:** The `Autocomplete` shows a loading indicator while a tag creation request is in-flight.
