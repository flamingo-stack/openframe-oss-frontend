A client-side React section component for displaying, adding, editing, and deleting notes on a support ticket, with inline editing support and author-scoped actions.

## Key Components

### Exported

- **`TicketNotesSection`** — Main section component rendering a list of note cards plus an "Add Note" button/editor toggle
- **`TicketNoteItem`** — Interface describing a single note's data shape (`id`, `text`, `authorName`, `authorAvatar`, `createdAt`, `isOwn`)

### Internal

- **`NoteCard`** — Renders a single note with author avatar, name, timestamp, and (for own notes) a hover-revealed actions menu with Edit/Delete options
- **`NoteEditor`** — Controlled textarea editor with Save/Cancel controls; supports `Escape` to cancel and disables input during pending state

## Usage Example

```typescript
import { TicketNotesSection, type TicketNoteItem } from './ticket-notes-section';

const notes: TicketNoteItem[] = [
  {
    id: 'note-1',
    text: 'Checked device logs, issue persists after reboot.',
    authorName: 'Alice Smith',
    authorAvatar: '/avatars/alice.png',
    createdAt: '2024-06-01T10:30:00Z',
    isOwn: true,
  },
];

<TicketNotesSection
  notes={notes}
  isAddingNote={false}
  onAddNote={(text) => createNote(text)}
  onEditNote={(id, text) => updateNote(id, text)}
  onDeleteNote={(id) => deleteNote(id)}
/>
```

## Behavior Notes

- Edit/Delete actions only appear for notes where `isOwn: true`
- The actions menu is hidden until hover (or focus-within), with an explicit visible state when the dropdown is open
- The "Add Note" editor is toggled locally; the parent controls pending state via `isAddingNote`
- `Escape` key dismisses the editor without saving
