Multi-select autocomplete filter for the tickets board's activity state, mirroring the server-side `TicketActivityFilter` enum used by the board activity indicators.

## Key Components

- **`ActivityFilter`** — Main exported component rendering a multi-select `Autocomplete` with a filter icon adornment
- **`ACTIVITY_FILTER_OPTIONS`** — Exported option list mapping enum values to labels: `ACTIVE` → "Active", `STALE` → "Stale", `AWAITING_EXTERNAL` → "Awaiting Client"
- **`ActivityFilterProps`** — Interface defining `value` (`TicketActivityFilter[]`), `onChange` callback, and optional `className`

## Usage Example

```typescript
import { ActivityFilter } from './activity-filter';

function TicketFilters() {
  const [activity, setActivity] = useState<TicketActivityFilter[]>([]);

  return <ActivityFilter value={activity} onChange={setActivity} className="w-64" />;
}
```

## Behavior Notes

- Options mirror the server's `TicketActivityFilter` enum: `ACTIVE`/`STALE` are evaluated per column against the status's `staleAfterMinutes` cutoff; `AWAITING_EXTERNAL` matches tickets waiting on a client reply
- Filter semantics: OR within the selection, AND against the other board filters
- Purely presentational — no data fetching; the `TicketActivityFilter` type comes from `../types/dialog.types`
- Placeholder "All Activity" when nothing is selected; leading `Filter02Icon` styled with `text-ods-text-secondary`
