A client-side filter bar component that combines a text search input with label-based tag filtering for the ticket list, powered by tenant-specific ticket labels.

## Key Components

- **`TicketTagFilter`** — Main exported component that wraps `TagFilterBar` with ticket label data
- **`useTicketLabels`** — Hook that fetches tenant ticket labels (id + key) from the API
- **`TagFilterBar`** — Shared UI component receiving the mapped tags and search state

### Props (`TicketTagFilterProps`)

| Prop | Type | Description |
|------|------|-------------|
| `search` | `string` | Current search input value |
| `onSearchChange` | `(value: string) => void` | Search input change handler |
| `labelIds` | `string[]` | Currently selected label IDs |
| `onLabelIdsChange` | `(ids: string[]) => void` | Label selection change handler |
| `filterButton` | `ReactNode` | Optional mobile filter button rendered next to the search input |

## Usage Example

```typescript
import { TicketTagFilter } from './ticket-label-filter';

function TicketListHeader() {
  const [search, setSearch] = useState('');
  const [labelIds, setLabelIds] = useState<string[]>([]);

  return (
    <TicketTagFilter
      search={search}
      onSearchChange={setSearch}
      labelIds={labelIds}
      onLabelIdsChange={setLabelIds}
      filterButton={<MobileFilterButton />}
    />
  );
}
```

## Notes

- Labels are memoized via `useMemo` to avoid unnecessary re-renders when the `labels` array reference changes
- The placeholder text is hardcoded as `"Search for Ticket"`
