A compact React component that renders an assignee picker for a board ticket, wiring together assignee options and mutation logic into a `AssigneeDropdown` UI element.

## Key Components

- **`BoardAssigneePicker`** — Default export component that accepts a `BoardTicket` and displays a compact dropdown for selecting/changing the ticket's assignee
- **`BoardAssigneePickerProps`** — Interface requiring a `ticket: BoardTicket` prop
- **`useAssigneeOptions`** — Hook providing available assignee `options` and `isLoading` state
- **`useAssignTicket`** — Hook returning a mutation function to assign a user to a ticket
- **`getFullImageUrl`** — Utility to resolve full avatar image URLs from relative paths

## Usage Example

```typescript
import { BoardAssigneePicker } from './board-assignee-picker';
import type { BoardTicket } from '@flamingo-stack/openframe-frontend-core/components/features';

const ticket: BoardTicket = {
  id: 'ticket-123',
  assignees: [
    {
      id: 'user-456',
      name: 'Jane Doe',
      initials: 'JD',
      avatarUrl: '/avatars/jane.png',
    },
  ],
  // ...other ticket fields
};

export function BoardColumn() {
  return <BoardAssigneePicker ticket={ticket} />;
}
```

## Behavior Notes

- Reads only the **first assignee** (`ticket.assignees?.[0]`) — single-assignee display
- Falls back to `assignee.initials` then `assignee.id` if `name` is missing
- Passes `assign.isPending` to the dropdown to reflect in-flight mutation state
- The `onAssign` callback triggers `assign.mutate({ ticketId, assigneeId })` on selection
