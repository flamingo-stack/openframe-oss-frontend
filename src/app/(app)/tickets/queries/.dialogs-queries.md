GraphQL query definitions for dialog-related data fetching: paginated message retrieval with full message type support.

## Key Components

### `getDialogMessagesQuery()`
A factory function returning a paginated GraphQL query for fetching messages within a dialog. Accepts variables:
- `$dialogId` — target dialog (required)
- `$chatType` — filter by chat type
- `$cursor` / `$limit` — cursor-based pagination
- `$sortField` / `$sortDirection` — result ordering

The query returns cursor-paginated `edges` with `pageInfo`, and supports a wide union of `messageData` types via inline fragments:

| Fragment | Description |
|---|---|
| `TextData` / `ThinkingData` / `SystemData` | Text-based messages |
| `ExecutingToolData` / `ExecutedToolData` | Tool invocation lifecycle |
| `ApprovalRequestData` / `ApprovalResultData` | Human-in-the-loop approval flow |
| `ContextCompactionStartData` / `ContextCompactionEndData` | Context window management events |
| `ErrorData` | Error payloads |

## Usage Example

```typescript
import { getDialogMessagesQuery } from './dialogs-queries';

// Fetch paginated messages
const messagesResult = await graphqlClient.query({
  query: getDialogMessagesQuery(),
  variables: {
    dialogId: 'dialog-123',
    chatType: 'AGENT',
    limit: 20,
    sortField: 'createdAt',
    sortDirection: 'DESC',
  },
});
```
