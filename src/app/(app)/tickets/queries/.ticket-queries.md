GraphQL query and mutation string constants for the ticket management domain, targeting the `openframe-saas-ai-agent` service via `/chat/graphql`.

## Key Components

### Queries
| Export | Description |
|---|---|
| `GET_TICKET_QUERY` | Fetch a single ticket by ID with full detail (owner, notes, attachments, dialog, transitions) |
| `GET_TICKETS_QUERY` | Paginated ticket list with cursor-based pagination and filtering |
| `GET_BOARD_COLUMN_TICKETS_QUERY` | Lifecycle board column tickets filtered by status, org, assignee, tags and `$hasUnreadNotifications` |
| `GET_TICKET_STATUS_TRANSITION_RULES_QUERY` | Allowed status transition rules between ticket states |
| `GET_TICKET_TAGS_QUERY` | All available ticket tags |
| `GET_TICKET_ATTACHMENT_DOWNLOAD_URL` | Pre-signed download URL for a ticket attachment |

### Mutations
| Export | Description |
|---|---|
| `CREATE_TICKET_MUTATION` | Create a new ticket with owner, device, and org context |
| `UPDATE_TICKET_MUTATION` | Update ticket fields (title, description, tags, etc.) |
| `TRANSITION_TICKET_MUTATION` | Move a ticket to a new status via a defined transition |
| `PUT_TICKET_ON_HOLD_MUTATION` / `RESOLVE_TICKET_MUTATION` / `ARCHIVE_TICKET_MUTATION` / `REOPEN_TICKET_MUTATION` | Lifecycle state changes |
| `ASSIGN_TICKET_MUTATION` / `UNASSIGN_TICKET_MUTATION` | Manage ticket assignee |
| `REORDER_TICKET_MUTATION` | Update ticket sort order within a board column |
| `ADD_TICKET_NOTE_MUTATION` / `UPDATE_TICKET_NOTE_MUTATION` / `DELETE_TICKET_NOTE_MUTATION` | Manage internal ticket notes |
| `CREATE_TEMP_ATTACHMENT_UPLOAD_URL` / `DELETE_TEMP_ATTACHMENT` / `DELETE_TICKET_ATTACHMENT` | Attachment lifecycle management |
| `UNLINK_DEVICE_FROM_TICKET_MUTATION` / `UNLINK_ORGANIZATION_FROM_TICKET_MUTATION` | Detach linked device or organization |

### Internal Fragment
- `BOARD_CARD_TICKET_LIFECYCLE_FRAGMENT` — Reusable GraphQL fragment for board card ticket fields, including `pendingApproval` tool calls used by Mingo AI.

## Usage Example

```typescript
import {
  GET_TICKET_QUERY,
  CREATE_TICKET_MUTATION,
  TRANSITION_TICKET_MUTATION,
} from '@/lib/graphql/ticket-queries';

// Fetch a single ticket
const { data } = await graphqlClient.query({
  query: GET_TICKET_QUERY,
  variables: { id: 'ticket-123' },
});

// Create a new ticket
const { data } = await graphqlClient.mutate({
  mutation: CREATE_TICKET_MUTATION,
  variables: {
    input: {
      title: 'Network connectivity issue',
      description: 'Unable to reach internal resources',
      organizationId: 'org-456',
    },
  },
});

// Transition ticket status
const { data } = await graphqlClient.mutate({
  mutation: TRANSITION_TICKET_MUTATION,
  variables: {
    input: { ticketId: 'ticket-123', statusId: 'status-resolved' },
  },
});
```
