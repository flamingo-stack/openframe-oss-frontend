React Query mutation hook that removes a customer/organization association from a support ticket via GraphQL, with toast notifications and cache invalidation on completion.

## Key Components

- **`unlinkCustomerApi(ticketId)`** — Internal async function that sends the `UNLINK_ORGANIZATION_FROM_TICKET_MUTATION` GraphQL mutation, extracts the response payload, and surfaces any `userErrors` as thrown exceptions.
- **`useUnlinkCustomer(onSuccess?)`** — Exported hook wrapping `useMutation` that handles the full unlink lifecycle: executes the API call, invalidates `tickets` and `dialogs` query caches, shows success/error toast notifications, and fires an optional callback on success.

## Usage Example

```typescript
import { useUnlinkCustomer } from './use-unlink-customer';

function TicketCustomerPanel({ ticketId }: { ticketId: string }) {
  const { mutate: unlinkCustomer, isPending } = useUnlinkCustomer(() => {
    // Optional: close modal or navigate away after unlink
    console.log('Customer unlinked, running post-action');
  });

  return (
    <button
      onClick={() => unlinkCustomer(ticketId)}
      disabled={isPending}
    >
      {isPending ? 'Unlinking...' : 'Unlink Customer'}
    </button>
  );
}
```

## Behavior Notes

- On **success**: invalidates both `ticketsQueryKeys.all` and `dialogsQueryKeys.all` to ensure UI reflects the removed association, then shows a success toast.
- On **error**: displays the server-returned `userErrors` message if present, otherwise falls back to a generic error string via a destructive toast.
- The `onSuccess` callback is optional and fires after cache invalidation and toast display.
