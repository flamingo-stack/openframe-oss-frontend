Provides an infinite-scroll React Query hook for fetching paginated ticket lists, resolving status filters from lifecycle status snapshots before querying.

## Key Components

- **`useTicketsQuery`** — Main exported hook accepting `DialogsQueryParams` and returning a paginated ticket list with infinite scroll support
- **`TICKETS_PAGE_SIZE`** — Default page size constant (`20`)
- **`NON_ARCHIVED_STATUSES`** — Legacy enum fallback (`['ACTIVE', 'TECH_REQUIRED', 'ON_HOLD', 'RESOLVED']`) used when status snapshot IDs are unavailable
- **`statusIds`** — Memoized derivation from `useTicketStatusesQuery` snapshot; resolves to the archived status ID, active filter selection, or all non-archived IDs
- **`resetToFirstPage`** — Callback that resets the React Query cache to page one for the current filter combination

## Usage Example

```typescript
const {
  dialogs,
  isLoading,
  isFetchingNextPage,
  hasNextPage,
  fetchNextPage,
  error,
  resetToFirstPage,
} = useTicketsQuery({
  archived: false,
  search: 'printer issue',
  statusFilters: ['status-uuid-123'],
  organizationIds: ['org-abc'],
  assigneeIds: ['user-xyz'],
  tagIds: [],
  pageSize: 20,
});
```

## Behavior Notes

- Query is **deferred** (`enabled: !waitingForStatusIds`) until the status snapshot resolves, preventing empty filter leaks
- Falls back to legacy enum statuses only when the snapshot fetch errors and `statusIds` is empty
- Errors surface via a **destructive toast** notification automatically
- Cache settings: `staleTime: 60s`, `gcTime: 5min`, `retry: 2` with a `1000ms` delay
