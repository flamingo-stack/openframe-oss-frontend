A React Query hook that fetches and caches a single ticket's full dialog detail by ID.

## Key Components

- **`useTicketDetail(ticketId)`** — Accepts an optional/nullable ticket ID string and returns the ticket detail state. The query is disabled when `ticketId` is falsy, using a stable placeholder query key to avoid cache collisions.

## Usage Example

```typescript
import { useTicketDetail } from '@/features/tickets/hooks/use-ticket-detail';

function TicketDetailPanel({ ticketId }: { ticketId: string | null }) {
  const { ticket, isPending, error, refetch } = useTicketDetail(ticketId);

  if (isPending) return <Spinner />;
  if (error) return <ErrorMessage error={error} onRetry={refetch} />;
  if (!ticket) return null;

  return <DialogView dialog={ticket} />;
}
```

## Return Shape

| Field | Type | Description |
|---|---|---|
| `ticket` | `Dialog \| null` | Fetched ticket dialog data, or `null` if unavailable |
| `isPending` | `boolean` | `true` while the initial fetch is in-flight |
| `error` | `Error \| null` | Query error, if any |
| `refetch` | `function` | Manually re-triggers the query |

## Behavior Notes

- Query is **disabled** when `ticketId` is `null` or `undefined` — no network request is made
- Data is considered **fresh for 30 seconds** (`staleTime: 30_000`) before a background refetch is triggered
- Uses `ticketsQueryKeys.detail(ticketId)` for consistent cache key management across the tickets feature
