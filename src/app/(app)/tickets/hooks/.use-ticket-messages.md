Fetches and paginates ticket dialog messages using React Query's infinite scroll pattern, invalidating the cache whenever the dialog ID or chat type changes.

## Key Components

- **`useTicketMessages(dialogId, chatType)`** — Custom hook returning paginated message data, loading state, and pagination controls for a given ticket dialog
- **Cache invalidation** — `useEffect` triggers `invalidateQueries` on `dialogId`/`chatType` changes to ensure fresh data on dialog switch
- **Infinite query** — Fetches 50 messages per page, sorted by `createdAt DESC`, advancing via cursor-based pagination (`endCursor`)
- **`refetch`** — Exposed explicitly to support re-fetching after a NATS JetStream reconnect, where the `CHAT_CHUNKS` stream may have a gap filled only by persisted history (deduped on merge)

## Usage Example

```typescript
import { useTicketMessages } from './use-ticket-messages';
import { ChatType } from '../constants';

function TicketChat({ dialogId }: { dialogId: string }) {
  const {
    rawPages,
    isLoading,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
    refetch,
    error,
  } = useTicketMessages(dialogId, ChatType.Support);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  const messages = rawPages?.flatMap(page => page.messages) ?? [];

  return (
    <>
      {messages.map(msg => <MessageItem key={msg.id} message={msg} />)}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```

## Return Shape

| Field | Type | Description |
|---|---|---|
| `rawPages` | `MessagePage[] \| undefined` | Raw paginated response pages |
| `isLoading` | `boolean` | Initial load in progress |
| `isFetched` | `boolean` | Query has completed at least once |
| `hasNextPage` | `boolean` | More pages available |
| `isFetchingNextPage` | `boolean` | Currently loading the next page |
| `fetchNextPage` | `function` | Triggers next page fetch |
| `refetch` | `function` | Force re-fetch all loaded pages |
| `error` | `string \| null` | Error message if query failed |
