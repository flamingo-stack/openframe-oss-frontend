Manages temporary file attachments for ticket forms, handling upload, removal, and lifecycle tracking of files before they are permanently committed to a ticket.

## Key Components

### Types

- **`TempFileStatus`** — Union type representing attachment state: `'uploading' | 'uploaded' | 'error' | 'existing'`
- **`TempFileEntry`** — Interface describing a tracked file with `id`, `fileName`, `fileSize`, `contentType`, `status`, and optional `error`

### Exported Functions

- **`createTempAttachment(file)`** — Requests a pre-signed S3 upload URL via GraphQL, then PUTs the file directly to object storage. Returns `{ id, fileName, fileSize, contentType }`.

### Hook

- **`useTempAttachments()`** — Primary hook managing the full attachment lifecycle for a ticket form

| Return Value | Description |
|---|---|
| `files` | Current list of `TempFileEntry` items |
| `uploadFile(file)` | Initiates upload; adds an optimistic placeholder entry immediately |
| `removeFile(id)` | Removes a temp file or defers deletion of existing ticket attachments |
| `initializeExisting(attachments)` | Seeds the file list with already-persisted attachments (`status: 'existing'`) |
| `getTempAttachmentIds()` | Returns IDs of successfully uploaded (non-existing) files for form submission |
| `deleteRemovedAttachments()` | Executes deferred deletes for existing attachments removed by the user |
| `hasPendingDeletes` | Boolean flag indicating uncommitted removals |
| `isUploading` | Boolean reflecting in-flight upload mutation state |
| `reset()` | Clears all file and pending-delete state |

## Usage Example

```typescript
const {
  files,
  uploadFile,
  removeFile,
  initializeExisting,
  getTempAttachmentIds,
  deleteRemovedAttachments,
  isUploading,
  reset,
} = useTempAttachments();

// Seed with existing ticket attachments when editing
initializeExisting(ticket.attachments);

// Handle file input change
const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  const file = e.target.files?.[0];
  if (file) uploadFile(file);
};

// On form submit
const handleSubmit = async () => {
  const tempAttachmentIds = getTempAttachmentIds(); // pass to mutation
  await deleteRemovedAttachments();                  // flush deferred deletes
  reset();
};
```

> **Note:** Existing attachment removals are deferred (`pendingDeleteIds`) and only sent to the API on `deleteRemovedAttachments()`, allowing users to cancel edits without orphaning server-side files. Orphaned temp files from failed uploads are cleaned up by a backend background job.
