Provides inline ticket mutation hooks for the detail view, refreshing the ticket cache in place without navigating away from the page.

## Key Components

| Export | Description |
|---|---|
| `useSetTicketLabels(ticketId)` | Replaces the ticket's full label set (add/remove tags) via GraphQL mutation |
| `useAddTicketAttachments(ticketId)` | Uploads files as temp attachments then associates them with the ticket |
| `useDeleteTicketAttachment(ticketId)` | Permanently removes a single attachment from the ticket |
| `useTicketCacheInvalidation(ticketId)` *(internal)* | Returns a callback that invalidates both the ticket detail and dialogs query caches |
| `updateTicket(input)` *(internal)* | Core GraphQL helper that calls `UPDATE_TICKET_MUTATION` and surfaces `userErrors` as thrown exceptions |

All three exported hooks follow the same pattern: run a mutation, invalidate relevant caches on success, and show a toast notification on error.

## Usage Example

```typescript
import {
  useSetTicketLabels,
  useAddTicketAttachments,
  useDeleteTicketAttachment,
} from './use-ticket-detail-mutations';

function TicketDetailPanel({ ticketId }: { ticketId: string }) {
  const setLabels     = useSetTicketLabels(ticketId);
  const addAttachments = useAddTicketAttachments(ticketId);
  const deleteAttachment = useDeleteTicketAttachment(ticketId);

  // Replace all labels on the ticket
  setLabels.mutate(['label-id-1', 'label-id-2']);

  // Upload new files and attach them
  addAttachments.mutate([file1, file2]);

  // Remove a specific attachment
  deleteAttachment.mutate('attachment-id-123');
}
```

> **Note:** These hooks are intentionally separate from `useUpdateTicket` (the edit-form flow). They are designed for inline detail-view interactions and keep the user on the current page after each operation.
