Provides page-level action buttons and dropdown menu items for the tickets list view, including "New Ticket" navigation and bulk "Archive Resolved Tickets" with confirmation dialog.

## Key Components

### `useTicketsActions(params)`
Primary hook returning ticket page actions, menu groups, and a confirmation dialog node.

**Parameters:**
| Name | Type | Description |
|------|------|-------------|
| `isLoading` | `boolean` | Disables archive action while data is loading |
| `enabled` | `boolean` | When `false`, returns empty action/menu arrays |
| `filter` | `ArchiveResolvedFilter` | Optional filter passed to the archive mutation |
| `resolvedCountOverride` | `number` | Overrides the global resolved ticket count |

**Returns:**
| Name | Description |
|------|-------------|
| `actions` | `PageActionButton[]` — "New Ticket" button |
| `menuActions` | `ActionsMenuGroup[]` — Edit Statuses, Tickets Archive, Archive Resolved |
| `dialog` | `ReactNode` — `ConfirmDialog` for the archive bulk action |
| `canArchiveResolved` | `boolean` — whether the archive action is currently available |
| `openArchiveResolvedConfirm` | `() => void` — manually trigger the confirm dialog |

### `emphasizeNewTicketAction(actions, emphasize)`
Pure helper that upgrades the "New Ticket" button to the `accent` variant (yellow) during empty states, recoloring its icon to `ods-text-on-accent`. No-op when `emphasize` is `false`.

## Usage Example

```typescript
const { actions, menuActions, dialog, canArchiveResolved } = useTicketsActions({
  isLoading,
  enabled: !isError,
  filter: { statusId: activeStatusId },
  resolvedCountOverride: filteredResolvedCount,
});

const emphasizedActions = emphasizeNewTicketAction(actions, isEmpty);

return (
  <>
    <PageHeader actions={emphasizedActions} menuActions={menuActions} />
    {dialog}
  </>
);
```
