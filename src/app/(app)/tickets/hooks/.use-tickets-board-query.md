Defines shared state types and constants for the tickets board query feature, supporting paginated column-based ticket display.

## Key Components

- **`BOARD_PAGE_SIZE`** — Constant defining the number of tickets to load per page (`20`)
- **`BoardColumnState`** — Interface representing the pagination and data state for a single board column

### `BoardColumnState` Fields

| Field | Type | Description |
|-------|------|-------------|
| `tickets` | `Dialog[]` | Loaded ticket items for the column |
| `total` | `number` | Total ticket count in the column |
| `endCursor` | `string \| null` | GraphQL cursor for the next page |
| `hasMore` | `boolean` | Whether more tickets can be fetched |
| `isLoadingMore` | `boolean` | Loading state for paginated fetches |

## Usage Example

```typescript
import { BOARD_PAGE_SIZE, type BoardColumnState } from './use-tickets-board-query';

const initialColumnState: BoardColumnState = {
  tickets: [],
  total: 0,
  endCursor: null,
  hasMore: false,
  isLoadingMore: false,
};

// Fetch first page with BOARD_PAGE_SIZE as the limit
const response = await fetchTickets({ first: BOARD_PAGE_SIZE });
```
