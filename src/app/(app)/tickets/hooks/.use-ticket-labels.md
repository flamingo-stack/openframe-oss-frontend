Fetches and caches available ticket labels via a GraphQL query, returning a list of `Tag` objects for use in ticket labeling UI.

## Key Components

- **`useTicketLabels()`** — React Query hook that posts `GET_TICKET_LABELS_QUERY` to the GraphQL endpoint, extracts `ticketLabels` from the response, and returns an empty array as a safe fallback.

## Usage Example

```typescript
import { useTicketLabels } from '@/features/tickets/hooks/use-ticket-labels';

function TicketLabelPicker() {
  const { data: labels, isLoading, isError } = useTicketLabels();

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorMessage />;

  return (
    <ul>
      {labels?.map((label) => (
        <li key={label.id}>{label.name}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Query is keyed via `ticketsQueryKeys.labels()` for consistent cache invalidation across the tickets feature.
- Returns `data.ticketLabels ?? []` — downstream consumers can safely iterate without null checks.
