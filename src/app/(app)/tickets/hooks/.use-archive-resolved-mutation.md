Bulk-archives all resolved tickets via a GraphQL mutation, with optimistic UI updates and full rollback support on error.

## Key Components

### `ArchiveResolvedFilter`
Optional filter object to scope which resolved tickets are archived:

| Field | Type | Description |
|---|---|---|
| `organizationIds` | `string[]` | Limit to specific organizations |
| `assigneeIds` | `string[]` | Limit to specific assignees |
| `labelIds` | `string[]` | Limit to specific labels |

### `useArchiveResolvedMutation()`
Primary hook returning a TanStack Query `useMutation` instance with the following lifecycle:

- **`mutationFn`** — POSTs `ARCHIVE_RESOLVED_TICKETS_MUTATION` to the GraphQL endpoint; strips empty arrays from filter variables before sending
- **`onMutate`** — Optimistically removes all `RESOLVED` dialogs from paginated list caches before the request completes
- **`onError`** — Rolls back all affected query caches to their pre-mutation snapshots and shows a destructive toast
- **`onSuccess`** — Shows a success toast with the count of archived tickets
- **`onSettled`** — Invalidates all dialog list queries and ticket statistics regardless of outcome

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation';

function ArchiveButton() {
  const { mutate, isPending } = useArchiveResolvedMutation();

  const handleArchive = () => {
    mutate({
      organizationIds: ['org_123'],
      assigneeIds: ['user_456'],
    });
  };

  return (
    <button onClick={handleArchive} disabled={isPending}>
      Archive Resolved
    </button>
  );
}
```
