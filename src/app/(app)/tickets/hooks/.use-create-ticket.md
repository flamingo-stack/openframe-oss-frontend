A React Query mutation hook for creating support tickets via GraphQL, handling success/error states with toast notifications and navigation.

## Key Components

- **`createTicketApi(input)`** — Internal async function that posts a `CREATE_TICKET_MUTATION` GraphQL request, extracts the response, and throws on `userErrors`.
- **`useCreateTicket()`** — Exported hook wrapping `useMutation` that orchestrates ticket creation, cache invalidation, toast feedback, and post-create routing.

## Usage Example

```typescript
import { useCreateTicket } from '@/features/tickets/hooks/use-create-ticket';

function NewTicketForm() {
  const { mutate: createTicket, isPending } = useCreateTicket();

  const handleSubmit = (formData: CreateTicketInput) => {
    createTicket(formData);
    // On success: invalidates tickets + dialogs cache,
    // shows a success toast, and navigates to the new ticket dialog.
    // On error: shows a destructive toast with the error message.
  };

  return (
    <button onClick={() => handleSubmit({ title: 'Printer offline' })} disabled={isPending}>
      {isPending ? 'Creating...' : 'Create Ticket'}
    </button>
  );
}
```

## Behavior

| Event | Side Effects |
|---|---|
| `onSuccess` (with `ticket.id`) | Invalidates `ticketsQueryKeys.all` + `dialogsQueryKeys.all`, success toast, navigates to `routes.tickets.dialog(id)` |
| `onSuccess` (no `ticket.id`) | Same invalidation + toast, falls back to `routes.tickets.list` |
| `onError` | Destructive toast with `err.message` or a generic fallback |
