Provides a React hook for handling ticket approval and rejection mutations using TanStack Query, abstracting the approve/reject actions into callback-friendly handlers with status reporting.

## Key Components

- **`ApprovalRequestAction`** — Type defining the mutation payload (`requestId` string and `approve` boolean flag)
- **`useApprovalRequests`** — Primary hook that wraps a single `useMutation` instance to handle both approve and reject flows
- **`handleApproveRequest`** — Async handler that calls `ticketService.approveRequest` and invokes `onSuccess` with `APPROVAL_STATUS.APPROVED`
- **`handleRejectRequest`** — Async handler that calls `ticketService.rejectRequest` and invokes `onSuccess` with `APPROVAL_STATUS.REJECTED`

## Returned Values

| Property | Type | Description |
|---|---|---|
| `handleApproveRequest` | `Function` | Approves a request by ID |
| `handleRejectRequest` | `Function` | Rejects a request by ID |
| `isLoading` | `boolean` | `true` while mutation is pending |
| `error` | `string \| null` | Error message from the last failed mutation |
| `approvalMutation` | `UseMutationResult` | Raw TanStack Query mutation object |

## Usage Example

```typescript
import { useApprovalRequests } from './use-approval-requests';

function ApprovalButtons({ requestId }: { requestId: string }) {
  const { handleApproveRequest, handleRejectRequest, isLoading } =
    useApprovalRequests();

  return (
    <>
      <button
        disabled={isLoading}
        onClick={() =>
          handleApproveRequest(requestId, {
            onSuccess: (status) => console.log('Approved:', status),
            onError: (err) => console.error('Failed:', err.message),
          })
        }
      >
        Approve
      </button>
      <button
        disabled={isLoading}
        onClick={() => handleRejectRequest(requestId)}
      >
        Reject
      </button>
    </>
  );
}
```

> Both handlers re-throw errors after calling `onError`, so callers can apply additional error handling up the call stack if needed.
