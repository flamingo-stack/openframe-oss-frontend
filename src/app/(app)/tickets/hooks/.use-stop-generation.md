Provides a React hook for stopping an in-progress AI message generation for a given dialog, managing the API call, loading state, and error feedback.

## Key Components

- **`useStopGeneration(messageDialogId)`** — Main hook that accepts a dialog ID and returns controls to cancel active generation
- **`stopGeneration()`** — Callback that triggers a `POST` to `{API_ENDPOINTS.DIALOGS}/{messageDialogId}/stop` with `CHAT_TYPE.ADMIN`; no-ops if a request is already in flight
- **`isStopping`** — Boolean derived from `mutation.isPending`, useful for disabling UI controls during the request
- **Side effects** — On success, clears the `admin` typing indicator via `useTicketDetailsStore`; on error, surfaces a destructive toast notification

## Usage Example

```typescript
import { useStopGeneration } from './use-stop-generation';

function StopButton({ dialogId }: { dialogId: string | null }) {
  const { stopGeneration, isStopping } = useStopGeneration(dialogId);

  return (
    <button onClick={stopGeneration} disabled={isStopping}>
      {isStopping ? 'Stopping...' : 'Stop Generation'}
    </button>
  );
}
```

## Notes

- Requires a valid `messageDialogId`; passing `null` will cause the mutation to throw `'No active dialog to stop'`
- Depends on `@tanstack/react-query` for mutation lifecycle management
- The toast duration is fixed at 5 seconds for error feedback
