Provides a React hook for sending admin messages within a ticket's chat dialog, handling optimistic UI updates, auto-dialog creation, and error feedback.

## Key Components

- **`useSendAdminMessage(options)`** — Main hook export. Accepts `ticketId`, `messageDialogId`, and an optional `onBeforeDialogCreated` callback.
- **Dialog auto-creation** — If no `messageDialogId` exists, creates a new AI-mode dialog via `POST` to `API_ENDPOINTS.DIALOGS` before sending.
- **Optimistic update** — Immediately appends the message to the ticket details store with a unique `optimistic-*` ID before the server round-trip completes.
- **`sendAdminMessage(message)`** — Stable callback (via `useCallback`) that guards against empty strings and in-flight mutations.
- **Error toast** — On mutation failure, displays a destructive toast with the error message via `useToast`.

## Usage Example

```typescript
import { useSendAdminMessage } from './use-send-admin-message';

function AdminChatInput({ ticketId, dialogId }) {
  const { sendAdminMessage, isSendingAdminMessage } = useSendAdminMessage({
    ticketId,
    messageDialogId: dialogId,
    onBeforeDialogCreated: () => console.log('New dialog created'),
  });

  return (
    <button
      disabled={isSendingAdminMessage}
      onClick={() => sendAdminMessage('Hello from admin')}
    >
      {isSendingAdminMessage ? 'Sending...' : 'Send'}
    </button>
  );
}
```

## Returns

| Property | Type | Description |
|---|---|---|
| `sendAdminMessage` | `(message: string) => void` | Sends the message; no-ops if empty or pending |
| `isSendingAdminMessage` | `boolean` | `true` while the mutation is in flight |
