Implements the `TicketService` class, which bridges the OpenFrame ticket GraphQL API to the internal `Dialog`-based abstraction used across the frontend, handling data fetching, normalization, and status mutations.

## Key Components

### `TicketService` (class)
Implements `TicketServiceInterface` with the following methods:

| Method | Description |
|---|---|
| `fetchDialogs(params)` | Fetches a paginated, filtered list of tickets mapped to `Dialog` objects (`unreadOnly` → `filter.hasUnreadNotifications: true`, only ever sent as `true`) |
| `fetchBoardColumnByStatusId(params)` | Fetches tickets for a specific Kanban board column by status ID (same `unreadOnly` mapping via the `$hasUnreadNotifications` variable) |
| `fetchDialog(id)` | Fetches a single ticket by ID and returns it as a `Dialog` or `null` |
| `fetchMessages(params)` | Fetches paginated chat messages for a given dialog |
| `updateStatus(ticketId, status)` | Updates ticket status, returns `true` on success |
| `mutateStatus(ticketId, status)` | Executes a status mutation and returns the new `DialogStatus` |
| `transitionTicket(ticketId, toStatusId)` | Transitions a ticket to a custom status definition ID |

### `normalizeTicketToDialog(ticket)` (internal)
Maps a raw `TicketNode` GraphQL response shape to the frontend `Dialog` type, including notes, tags, attachments, token usage, and approval data.

### Status Mappings
- `TICKET_TO_DIALOG_STATUS` / `DIALOG_TO_TICKET_STATUS` — bidirectional status string maps
- `STATUS_TO_MUTATION` — maps `DialogStatus` values to their corresponding GraphQL mutation strings and response keys

## Usage Example

```typescript
import { TicketService } from './ticket-service';

const service = new TicketService();

// Fetch paginated tickets
const page = await service.fetchDialogs({
  statuses: ['ACTIVE'],
  limit: 20,
  cursor: undefined,
});

// Fetch a single ticket
const dialog = await service.fetchDialog('ticket-id-123');

// Transition to a workflow status
await service.transitionTicket('ticket-id-123', 'status-def-id-456');

// Simple status mutation
await service.mutateStatus('ticket-id-123', 'RESOLVED');
```
