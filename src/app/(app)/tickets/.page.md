Client-side route guard for the Tickets page that restricts access to SaaS tenant mode only, redirecting other deployment modes to the dashboard.

## Key Components

- **`Tickets`** (default export) — Next.js page component that enforces SaaS tenant mode access control via `isSaasTenantMode()`, redirecting to `routes.dashboard` if the condition is not met, and rendering `TicketsView` when authorized.

## Usage Example

```typescript
// Automatically used by Next.js App Router at /tickets
// No direct import needed — rendered via file-based routing

// Access control logic references:
import { isSaasTenantMode } from '@/lib/app-mode';
import { routes } from '@/lib/routes';

// If isSaasTenantMode() returns false:
// → router.replace(routes.dashboard) is called
// → component returns null (no flash of content)

// If isSaasTenantMode() returns true:
// → <TicketsView /> is rendered
```

## Notes

- Uses a dual guard pattern: `useEffect` handles the async redirect, while the synchronous `if (!isSaasTenantMode()) return null` prevents any content flash before the redirect completes.
- `ContentPageContainer` is imported but not used in the current implementation — may be a remnant or planned wrapper.
- See [`TicketsView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/tickets/components/tickets-view.tsx) for the actual UI implementation.
