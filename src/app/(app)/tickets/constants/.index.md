Defines shared constants and TypeScript types for the OpenFrame chat/dialog system, providing a single source of truth for status enums, message types, API endpoints, and network configuration used across the frontend.

## Key Components

| Export | Type | Description |
|---|---|---|
| `DIALOG_STATUS` / `DialogStatus` | const + type | Dialog lifecycle states: `ON_HOLD`, `RESOLVED`, `ACTIVE`, `ARCHIVED` |
| `TICKET_STATUS` / `TicketStatusValue` | const + type | Ticket states mirroring backend enum, includes `TECH_REQUIRED` |
| `DIALOG_MODE` / `DialogModeValue` | const + type | Chat mode: `AI` or `DIRECT` |
| `CHAT_TYPE` / `ChatType` | const + type | Distinguishes `CLIENT_CHAT` from `ADMIN_AI_CHAT` |
| `MESSAGE_TYPE` / `MessageType` | const + type | Full message lifecycle types including tool execution and approvals |
| `OWNER_TYPE` / `OwnerType` | const + type | Message author: `CLIENT`, `ADMIN`, or `ASSISTANT` |
| `APPROVAL_STATUS` / `ApprovalStatus` | const + type | Approval workflow states: `pending`, `approved`, `rejected` |
| `ASSISTANT_CONFIG` / `AssistantType` | const + type | Named configs for `fae` and `mingo` AI assistants |
| `CREATION_SOURCE` / `CreationSource` | const + type | Ticket origin: form, dialog, or admin dashboard |
| `API_ENDPOINTS` | const | REST and GraphQL endpoint paths for the chat service |
| `NATS_TOPICS` | const + type | NATS messaging topics for real-time events |
| `STORAGE_KEYS` | const | LocalStorage key for the access token |
| `NETWORK_CONFIG` | const | Timeout, reconnect, and pagination tuning values |

## Usage Example

```typescript
import {
  DIALOG_STATUS,
  MESSAGE_TYPE,
  ASSISTANT_CONFIG,
  API_ENDPOINTS,
  NETWORK_CONFIG,
  type DialogStatus,
  type MessageType,
  type AssistantType,
} from './index';

// Type-safe status comparison
function isActive(status: DialogStatus): boolean {
  return status === DIALOG_STATUS.ACTIVE;
}

// Route a message based on type
function handleMessage(type: MessageType) {
  if (type === MESSAGE_TYPE.APPROVAL_REQUEST) {
    // prompt user for approval
  }
}

// Fetch dialogs with configured pagination limit
const response = await fetch(
  `${API_ENDPOINTS.DIALOGS}?limit=${NETWORK_CONFIG.DEFAULT_MESSAGE_LIMIT}`
);

// Reference assistant by type
const assistant: AssistantType = ASSISTANT_CONFIG.MINGO.type; // 'mingo'
```
