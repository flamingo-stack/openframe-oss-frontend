Zustand store managing per-side (client/admin) chat state for ticket detail views, including message history, real-time streaming segments, approval workflows, and tool execution tracking.

## Key Components

### Types

- **`ChatSide`** — `'client' | 'admin'` discriminator for dual-pane chat views
- **`SideState`** — Per-side state slice: messages, streaming bubble, segment accumulator, token usage, typing indicator, and stream sequence tracking
- **`ApprovalStatus`** / **`ApprovalStatusMap`** — Approval state (`'approved' | 'rejected'`) keyed by request ID
- **`TicketDetailsStore`** — Full Zustand store interface

### Core Helpers

- **`createSideState()`** — Factory returning a fresh, zeroed `SideState`
- **`produceSide(state, side, updater)`** — Immutable update helper that applies a `SideState` updater to only the targeted side, leaving the other untouched

### Store Actions

| Category | Key Actions |
|---|---|
| **Messages** | `setMessages`, `addMessage`, `updateMessage`, `removeMessage`, `prependMessages`, `prependWithBoundaryMerge` |
| **Streaming** | `setStreamingMessage`, `updateStreamingMessageSegments`, `appendSegmentsToLastAssistant` |
| **Approvals** | `updateApprovalStatusInMessages`, `setApprovalStatus`, `mergeApprovalStatuses` |
| **Tool Execution** | `updateToolExecutionInMessages` |
| **Accumulator** | `setAccumulatorCallbacks`, `resetAccumulator` |
| **Lifecycle** | `clearChatState`, `clearSide` |

## Usage Example

```typescript
import { useTicketDetailsStore } from './ticket-details-store';

// Reading messages for the admin pane
const adminMessages = useTicketDetailsStore(s => s.getMessages('admin'));

// Adding an incoming streaming message
const { setStreamingMessage, updateStreamingMessageSegments } = useTicketDetailsStore();

setStreamingMessage('client', { id: 'msg-1', role: 'assistant', content: [], timestamp: new Date() });

updateStreamingMessageSegments('client', incomingSegments, streamSeq);

// Resolving an approval
useTicketDetailsStore.getState().updateApprovalStatusInMessages(
  'client',
  'approval-request-id',
  'approved',
  'Jane Smith',
);

// Switching tickets — reset all state
useTicketDetailsStore.getState().clearChatState();
```

## Notes

- `appendSegmentsToLastAssistant` handles the edge case where no assistant bubble exists yet by creating a synthetic fallback message, preventing silent drops of post-`MESSAGE_END` tool chunks.
- `highestStreamSeq` is used by the history/realtime merge layer to deduplicate replayed synthetic messages already persisted to history.
- `prependWithBoundaryMerge` supports optimistic boundary message patching when paginating older history into the top of the message list.
