Defines the core TypeScript types and interfaces for the dialog (ticket/chat session) domain, covering dialog lifecycle, message structure, ownership models, and cursor-based pagination.

## Key Components

### Dialog Types
- **`DialogStatus`** — Union type for ticket states: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED`
- **`Dialog`** — Primary interface representing a support ticket/dialog, including lifecycle fields, V2 ticket fields, assignee info, tags, attachments, notes, and token usage
- **`DialogConnection` / `DialogEdge`** — Cursor-paginated list of dialogs

### Ownership Models
- **`DialogOwner`** / **`DialogOwnerEnum`** — Base owner with `CLIENT` or `ADMIN` type
- **`ClientDialogOwner`** — Extends `DialogOwner` with an associated `Machine`
- **`Machine`** — Device/endpoint metadata (hostname, org, display name)

### Message Types
- **`MessageDataType`** — Union covering all message variants: `TEXT`, `ERROR`, `EXECUTING_TOOL`, `EXECUTED_TOOL`, `APPROVAL_REQUEST`, `APPROVAL_RESULT`, `SYSTEM`, and context compaction markers
- **`Message`** — Core message record linking to a dialog, with typed `owner` and `messageData` discriminated unions
- **`AssistantOwner`** — Carries model ID and provider display name for AI-generated messages
- **`AdminOwner`** — Carries userId and optional user profile for technician messages
- **`ExecutingToolData` / `ExecutedToolData`** — Tool invocation lifecycle with approval status
- **`ApprovalRequestData` / `ApprovalResultData`** — Structured approval workflow payloads
- **`MessageConnection` / `MessageEdge`** — Cursor-paginated list of messages

### Supporting Types
- **`DialogRating`** — User satisfaction rating linked to a dialog
- **`ChatTypeTokenUsage`** — Per-chat-type LLM token consumption metrics
- **`CursorPageInfo`** — Relay-style pagination cursors

## Usage Example

```typescript
import type { Dialog, Message, MessageDataType } from './dialog.types';

function isToolMessage(msg: Message): boolean {
  const toolTypes: MessageDataType[] = ['EXECUTING_TOOL', 'EXECUTED_TOOL'];
  return toolTypes.includes(msg.messageData.type as MessageDataType);
}

function getDialogAssignee(dialog: Dialog): string {
  return dialog.assignedName ?? 'Unassigned';
}
```
