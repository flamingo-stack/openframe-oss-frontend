Defines the complete TypeScript type system for the ticket module, mirroring the backend GraphQL schema from the OpenFrame SaaS AI agent service.

## Key Components

### Core Types

| Type/Interface | Description |
|---|---|
| `TicketStatus` | Union type for ticket lifecycle states: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED` |
| `Ticket` | Primary ticket entity with full metadata including assignee, reporter, labels, attachments, and notes |
| `TicketOwner` | Identifies ticket ownership by `CLIENT` or `ADMIN` with optional machine/user references |

### Supporting Entities

| Interface | Description |
|---|---|
| `TicketNote` | Internal notes attached to a ticket with author info |
| `TicketAttachment` | Persisted file attachments with uploader metadata |
| `TempAttachment` | Temporary upload placeholder before finalizing to `TicketAttachment` |
| `KnowledgeBaseArticle` | Linked KB articles in `DRAFT` or `PUBLISHED` state |
| `TicketStatusRef` | Lightweight status reference with display color, used for transitions |

### GraphQL Payload Types

| Interface | Description |
|---|---|
| `TicketPayload` | Wraps a `Ticket` result with `UserError[]` for mutation responses |
| `TempAttachmentPayload` | Wraps a `TempAttachment` result for pre-upload responses |
| `TicketAttachmentUploadPayload` | Returns attachment and a presigned `uploadUrl` |
| `DeletePayload` | Generic deletion response carrying only errors |

### Mutation Input Types

| Interface | Description |
|---|---|
| `CreateTicketInput` | Fields for new ticket creation including optional labels, articles, and temp attachments |
| `UpdateTicketInput` | Partial update with nullable device/org/assignee fields |
| `AssignTicketInput` | Dedicated input for ticket assignment operations |
| `TicketIdInput` | Minimal single-ID input for lookups and deletes |

## Usage Example

```typescript
import type {
  Ticket,
  CreateTicketInput,
  TicketPayload,
  TicketStatus,
} from '@/types/ticket.types';

// Constructing a create mutation input
const newTicket: CreateTicketInput = {
  title: 'VPN client failing on Windows 11',
  description: 'User cannot connect after latest update.',
  organizationId: 'org_abc123',
  assigneeId: 'user_xyz789',
  labelIds: ['label_urgent'],
  tempAttachmentIds: ['tmp_attach_001'],
};

// Handling a mutation response
function handleTicketPayload(payload: TicketPayload): Ticket {
  if (payload.userErrors.length > 0) {
    throw new Error(payload.userErrors.map(e => e.message).join(', '));
  }
  if (!payload.ticket) {
    throw new Error('No ticket returned');
  }
  return payload.ticket;
}

// Type-narrowing on status
function isResolved(status: TicketStatus): boolean {
  return status === 'RESOLVED' || status === 'ARCHIVED';
}
```
