Defines shared types and utility functions for aggregating and deriving ticket statistics from status-based count data returned by the backend.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `TicketStatusCount` | Raw status string + count pair |
| `TicketStatusDefinitionCount` | Structured status definition (kind + optional color) + count pair |
| `TicketStatisticsCounts` | Container holding optional arrays of both count types |
| `TicketKindCounts` | Derived breakdown of tickets by lifecycle kind |

### Constants

- **`TICKET_STATUS_KIND`** — Mirrors the backend `TicketStatusKind` enum; keys: `AI_ASSISTANCE`, `TECH_REQUIRED`, `RESOLVED`, `ARCHIVED`, `CUSTOM`

### Functions

| Function | Description |
|---|---|
| `kindColorFromStatistics` | Returns the color string for the first matching status kind, if defined |
| `resolvedCountFromStatistics` | Returns total count of tickets in `RESOLVED` kind |
| `totalCountFromStatistics` | Returns total ticket count across all statuses; prefers `statusCounts`, falls back to `statusDefinitionCounts` |
| `kindCountsFromStatistics` | Returns a `TicketKindCounts` breakdown aggregated by lifecycle kind |

## Usage Example

```typescript
import {
  kindCountsFromStatistics,
  totalCountFromStatistics,
  resolvedCountFromStatistics,
  kindColorFromStatistics,
} from './ticket-statistics';

const stats = {
  statusDefinitionCounts: [
    { status: { kind: 'RESOLVED', color: '#22c55e' }, count: 12 },
    { status: { kind: 'TECH_REQUIRED' }, count: 5 },
    { status: { kind: 'AI_ASSISTANCE' }, count: 3 },
  ],
};

const total = totalCountFromStatistics(stats);       // 20
const resolved = resolvedCountFromStatistics(stats); // 12
const color = kindColorFromStatistics(stats, 'RESOLVED'); // '#22c55e'

const breakdown = kindCountsFromStatistics(stats);
// { aiAssistance: 3, techRequired: 5, resolved: 12, otherStatuses: 0 }
```
