Provides optimistic UI updates for kanban-style board ticket moves, allowing instant visual feedback before server confirmation with full rollback support.

## Key Components

### Interfaces

- **`OptimisticMoveInput`** — Describes a ticket move operation: source/target status columns, ticket ID, and neighboring ticket IDs for ordering (`afterTicketId`, `beforeTicketId`)
- **`OptimisticMoveSnapshot`** — Captures pre-move cache state for rollback: the board column
  query entries for the **source and target lanes only** (every filter variant of each), plus the
  optional ticket detail entry. Untouched lanes are deliberately excluded — each polls on its own
  timer, so restoring them would revert data that arrived after the snapshot was taken

### Functions

- **`applyOptimisticMove(queryClient, input)`** — Applies an optimistic move to the React Query cache. Removes the ticket from the source column, inserts it into the target column at the correct position, and updates the detail query if present. Returns a snapshot for rollback.
- **`rollbackOptimisticMove(queryClient, snapshot)`** — Restores the snapshotted cache entries, reverting the optimistic update on error.
- **`invalidateBoardColumns(queryClient, statusIds)`** — Invalidates every board query for the given
  lanes (all filter variants) and no others. Matches by predicate rather than key, because a mutation
  knows the statusIds but not the search/filter combination the board is rendering under.

### Internal Helpers

- **`isBoardQueryKey`** — Validates that a query key belongs to a board column (`dialogs.boardColumn.*`)
- **`findDialogInCache`** — Searches all paginated board column entries for a ticket by ID
- **`removeFromColumn`** — Immutably removes a ticket from paginated column data, decrementing `filteredCount`
- **`insertIntoColumn`** — Immutably inserts a ticket at the position defined by `afterTicketId`/`beforeTicketId`, falling back to the top of the first page

## Usage Example

```typescript
// In a React Query mutation
const mutation = useMutation({
  mutationFn: (input: OptimisticMoveInput) => moveTicketApi(input),
  onMutate: async (input) => {
    await queryClient.cancelQueries({ queryKey: dialogsQueryKeys.boardColumns() });
    const snapshot = applyOptimisticMove(queryClient, input);
    return { snapshot };
  },
  onError: (_err, _input, context) => {
    if (context?.snapshot) {
      rollbackOptimisticMove(queryClient, context.snapshot);
    }
  },
});
```

## Notes

- Handles both **same-column reorders** and **cross-column moves** in a single pass
- Ticket detail cache (`ticketsQueryKeys.detail`) is kept in sync alongside board column caches
- Position resolution prefers `afterTicketId`; falls back to `beforeTicketId`, then prepends to the first page
