Defines React Query cache key factories for dialogs (tickets/boards) and tickets, ensuring consistent cache management and granular invalidation across the application.

## Key Components

### `DialogsQueryParams`
Interface describing filter parameters for dialog list queries, including `archived`, `search`, `statusFilters`, `statusIds`, `organizationIds`, `assigneeIds`, `tagIds`, and `pageSize`.

### `dialogsQueryKeys`
Query key factory for dialog-related queries:
- `all` — base key for all dialogs queries
- `lists()` — scopes all paginated list queries
- `list(params)` — unique key per filter combination (normalizes defaults for cache stability)
- `boardColumns()` — scopes all kanban board column queries
- `boardColumn(statusId, params)` — key per column, scoped by status + filters

### `invalidateAllDialogs(queryClient)`
Utility to bulk-invalidate every dialogs cache entry via the `all` base key.

### `ticketsQueryKeys`
Query key factory for ticket-specific queries:
- `all` — base key
- `tags()`, `statistics()`, `statuses()`, `statusTransitions()`, `statusTransitionRules()` — feature-scoped keys
- `detail(id)` — caches a `Dialog` shape by ticket ID
- `editForm(id)` — **separate** from `detail`; caches the full `Ticket` shape (with `statusDefinition` and `availableTransitions`) to avoid cache collisions with dialog data

## Usage Example

```typescript
import { useInfiniteQuery, useQueryClient } from '@tanstack/react-query';
import { dialogsQueryKeys, ticketsQueryKeys, invalidateAllDialogs } from './query-keys';

// Paginated dialog list
const query = useInfiniteQuery({
  queryKey: dialogsQueryKeys.list({
    archived: false,
    search: 'network',
    assigneeIds: ['user-123'],
    pageSize: 50,
  }),
  queryFn: fetchDialogs,
});

// Board column for a specific status
const columnKey = dialogsQueryKeys.boardColumn('status-abc', {
  organizationIds: ['org-1'],
});

// Invalidate all dialogs after a mutation
const queryClient = useQueryClient();
await invalidateAllDialogs(queryClient);

// Ticket edit form (isolated from Dialog cache)
const editKey = ticketsQueryKeys.editForm('ticket-456');
```

## Notes

- All keys use `as const` for type-safe tuple inference with React Query.
- `list()` normalizes all optional params to empty defaults, preventing duplicate cache entries from `undefined` vs `[]` mismatches.
- `editForm` and `detail` are intentionally distinct to prevent the `Ticket` shape from overwriting the leaner `Dialog` cache entry.
