Resolves the single live-activity indicator (`BoardTicketActivity`) a tickets-board card shows, combining the backend's `activityState` with client-side staleness detection so cards surface exactly one signal.

## Key Components

### `DEFAULT_STALE_AFTER_MINUTES` (120)

Client-side mirror of the backend staleness default (`openframe.tickets.staleness.default-minutes`). Safety net only — the effective threshold arrives server-resolved on `TicketStatusDefinition.staleAfterMinutes`.

### `resolveBoardActivity(dialog, status, now)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `dialog` | `Dialog` | Board ticket with `activityState`, `lastActivityAt`, unread/approval/escalation flags |
| `status` | `TicketStatusDefinition` | The card's column, carrying `kind` and `staleAfterMinutes` |
| `now` | `number` | Current epoch ms (passed in for testability/shared ticks) |

**Returns:** `BoardTicketActivity | undefined` — `{ kind: 'ai-working' }`, `{ kind: 'waiting-external' }`, `{ kind: 'stale', label }`, or `undefined` (no indicator).

**Priority / display rules:**
1. `activityState === 'AI_WORKING'` → `ai-working`; `'AWAITING_EXTERNAL'` → `waiting-external` (backend states win outright).
2. Staleness is skipped for `RESOLVED`/`ARCHIVED` columns (`STALE_EXEMPT_KINDS`) — meaningless once closed out.
3. Staleness is the lowest-priority signal: suppressed when the card already shows approval (`pendingApproval`), escalation (`escalatedByUser`), or unread messages (`unreadNotificationCount > 0`).
4. Idle time = `now - (lastActivityAt ?? createdAt)`; stale when it reaches `staleAfterMinutes || DEFAULT_STALE_AFTER_MINUTES`. Matches the server's `STALE` activity-filter semantics, so the indicator and the filter can never disagree about a card.

### `formatIdleDuration(idleMs)` (private)

Human label for the stale badge: `"N min"` (min 1) under an hour, `"1 hour"`/`"N hours"` under a day, then `"1 day"`/`"N days"`.

## Usage Example

```typescript
const activity = resolveBoardActivity(dialog, columnStatus, Date.now());
// -> { kind: 'stale', label: 'No activity for 3 hours' } | undefined
```
