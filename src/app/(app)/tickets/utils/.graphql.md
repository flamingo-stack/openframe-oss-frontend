Utility module for typing and extracting data from GraphQL API responses, with error handling for both HTTP-level and GraphQL-level failures.

## Key Components

### `GraphQlResponse<T>`
A generic interface representing a standard GraphQL response envelope, containing an optional `data` payload and an optional `errors` array with message and extensions fields.

### `extractGraphQlData<T>(response)`
A generic function that unwraps a GraphQL response or throws a descriptive error. Handles three failure modes in order:
1. **HTTP failure** — throws if `response.ok` is `false`
2. **GraphQL errors** — throws if the response contains a non-empty `errors` array
3. **Missing data** — throws if `gql.data` is absent

## Usage Example

```typescript
import { extractGraphQlData, GraphQlResponse } from './graphql';

interface TicketData {
  ticket: { id: string; title: string };
}

// Simulated fetch wrapper result
const response = {
  ok: true,
  data: {
    data: { ticket: { id: '42', title: 'Printer offline' } },
  } as GraphQlResponse<TicketData>,
};

try {
  const { ticket } = extractGraphQlData<TicketData>(response);
  console.log(ticket.title); // "Printer offline"
} catch (err) {
  // Handles HTTP errors, GraphQL errors, and missing data
  console.error(err.message);
}
```

## Notes

- The function is designed to pair with a fetch wrapper that returns `{ ok, data, error, status }` — it does **not** call `fetch` directly.
- Only the first GraphQL error message is surfaced when multiple errors are returned.
