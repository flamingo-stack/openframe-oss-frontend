Renders the Tickets Archive page, gating access to SaaS tenant mode and redirecting non-SaaS environments to the dashboard.

## Key Components

- **`TicketsArchive`** — Default export page component that renders `ArchivedTickets` with search and label filtering state
- **`isSaasTenantMode`** — Guard that redirects to `routes.dashboard` if the app is not running in SaaS tenant mode
- **`useApiParams`** — Manages `search` (string) and `labelIds` (array) query parameters
- **`useSearchParam`** — Debounced (300ms) search input state synced to API params
- **`useSafeBack`** — Provides a back handler that falls back to `routes.tickets.list`

## Usage Example

```typescript
// Accessed via Next.js routing at the archived tickets route.
// No props required — all state is derived from URL params.

// Search and labelIds are reflected in the URL automatically:
// /tickets/archive?search=foo&labelIds=label1,label2
```

> **Note:** This page renders `null` and redirects to the dashboard if `isSaasTenantMode()` returns `false`. The redirect is handled in both a `useEffect` (for client-side navigation) and a conditional return (to prevent flash-of-content).
