Client-side Next.js page component that handles routing for the ticket details view, reading the ticket ID from search parameters and redirecting to the ticket list if no ID is present.

## Key Components

- **`TicketDetailsPage`** — Default export page component that extracts `id` from the URL query string and conditionally renders the ticket details view or redirects.

## Usage Example

```typescript
// Accessed via URL: /tickets/details?id=TICKET-123
// Renders: <TicketDetailsView ticketId="TICKET-123" />

// Accessed via URL: /tickets/details (no id param)
// Redirects to: routes.tickets.list
```

## Behavior

| Condition | Result |
|---|---|
| `id` present in query params | Renders `<TicketDetailsView ticketId={id} />` |
| `id` missing from query params | Redirects to `routes.tickets.list`, renders `null` |

## Notes

- Uses `useSearchParams` from `next/navigation` to read the `?id=` query parameter.
- The `useEffect` guard ensures a redirect occurs on mount if `id` is absent, preventing a blank page state.
- Relies on [`TicketDetailsView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/tickets/components/ticket-details-view.tsx) for the actual UI rendering.
