Client-side entry point for the Dashboard route. Renders the main dashboard UI by delegating to the `DashboardContent` component.

## Key Components

- **`Dashboard`** — Default export. A thin wrapper component that mounts `DashboardContent` as the page root.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to the /dashboard route.
// No direct instantiation required.

import Dashboard from './page';

// Next.js App Router usage (automatic):
// File: app/dashboard/page.tsx → route: /dashboard
<Dashboard />
```

## Notes

- Marked with `'use client'` directive, ensuring this page and its subtree run as a React Client Component.
- All dashboard logic, data fetching, and UI composition is handled inside [`DashboardContent`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/dashboard/components/dashboard-content.tsx).
