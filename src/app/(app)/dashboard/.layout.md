Root layout component for the OpenFrame Dashboard section, providing metadata configuration and a transparent wrapper for dashboard child routes.

## Key Components

- **`metadata`** — Next.js route segment metadata export setting the page title and description for all dashboard routes
- **`DashboardLayout`** — Minimal passthrough layout component that renders dashboard child routes without adding additional DOM structure

## Usage Example

```typescript
// app/dashboard/layout.tsx
// Next.js automatically applies this layout to all routes under /dashboard

// Child pages receive the layout wrapper automatically:
// app/dashboard/page.tsx → wrapped by DashboardLayout
// app/dashboard/devices/page.tsx → wrapped by DashboardLayout
```

> **Note:** This layout intentionally uses a React Fragment (`<>`) as its wrapper, meaning no additional HTML elements are injected around child content. The `metadata` export is consumed by Next.js to populate `<title>` and `<meta name="description">` tags for the dashboard segment.
