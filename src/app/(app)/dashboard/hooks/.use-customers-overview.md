Fetches and aggregates a per-organization device health overview for the dashboard customers table, combining organization metadata with online/offline device counts via parallel GraphQL queries.

## Key Components

### `OrganizationOverviewRow` (exported interface)
Flattened row shape returned to consumers, including organization identity fields (`id`, `organizationId`, `name`, `websiteUrl`, `imageUrl`, `imageHash`) and computed device metrics (`total`, `active`, `inactive`, `activePct`, `inactivePct`).

### `fetchCustomersOverview(limit)` (internal async function)
Executes three GraphQL requests:
1. `GetOrganizations` — fetches all organizations (up to 100)
2. `GetDeviceFilters` (total) — total device count per org (online + offline)
3. `GetDeviceFilters` (online) + `GetDeviceFilters` (offline) — parallel fetch for per-status breakdown

Results are merged into sorted `OrganizationOverviewRow[]` (descending by total devices). Gracefully returns empty arrays on any failure.

### `useCustomersOverview(limit?)` (exported hook)
React Query wrapper around `fetchCustomersOverview`. Only runs when the user is authenticated.

| Option | Value |
|---|---|
| `staleTime` | 3 minutes |
| `gcTime` | 10 minutes |
| `retry` | 1 attempt, 1 s delay |
| `refetchOnWindowFocus` | disabled |

## Usage Example

```typescript
import { useCustomersOverview } from './use-customers-overview';

function CustomersDashboard() {
  const { rows, loading, error, totalOrganizations, refresh } =
    useCustomersOverview(10);

  if (loading) return <Spinner />;
  if (error) return <ErrorBanner message={error} />;

  return (
    <>
      <p>{totalOrganizations} organizations</p>
      {rows.map(row => (
        <div key={row.id}>
          {row.name} — {row.active}/{row.total} active ({row.activePct}%)
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh</button>
    </>
  );
}
```
