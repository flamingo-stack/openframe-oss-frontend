Singleton service that fetches and normalizes device and ticket statistics for the dashboard, using GraphQL queries via `apiClient`.

## Key Components

### Exported Types

- **`DashboardDeviceStats`** — Normalized device counts (`total`, `active`, `inactive`, `pending`, `archived`) with pre-calculated percentages.
- **`DashboardTicketStats`** — Normalized ticket counts, resolution time, FAE rating, and lifecycle kind breakdown (`aiAssistance`, `techRequired`, `otherStatuses`).

### Class: `DashboardApiService` (Singleton)

| Method | Description |
|---|---|
| `fetchDeviceStats()` | Posts `GET_DEVICE_FILTERS_QUERY` to `/api/graphql`, maps status counts to `DashboardDeviceStats` with percentage calculations. |
| `fetchTicketStats()` | Posts `GET_TICKET_STATISTICS_QUERY`, maps `ticketStatistics` response to `DashboardTicketStats` including lifecycle kind colors. |
| `handleApiError()` *(private)* | Normalizes caught errors into descriptive `Error` instances with operation context. |

### Exported Singleton

- **`dashboardApiService`** — Pre-initialized instance for direct import.

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service';

// Fetch device stats
const deviceStats = await dashboardApiService.fetchDeviceStats();
console.log(`${deviceStats.active} online (${deviceStats.activePercentage}%)`);

// Fetch ticket stats
const ticketStats = await dashboardApiService.fetchTicketStats();
console.log(`${ticketStats.resolved} resolved, avg time: ${ticketStats.avgResolveTime}`);
console.log(`Tech required: ${ticketStats.techRequired} (${ticketStats.techRequiredColor})`);
```

> **Note:** `fetchTicketStats` targets the `ticketStatistics` GraphQL query. The legacy `dialogStatistics` query was removed when the backend split tickets from dialogs.
