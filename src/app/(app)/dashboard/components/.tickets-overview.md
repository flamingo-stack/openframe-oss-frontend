Dashboard section component that renders a 4-card grid summarizing ticket counts by status (AI Assistance, Tech Required, Resolved, and Other) with loading skeleton support.

## Key Components

- **`TicketsOverviewSection`** — Main exported component; fetches ticket overview data via `useTicketsOverview` and renders a responsive grid of `DashboardInfoCard` elements grouped by ticket status
- **`useTicketsOverview`** — Custom hook (from `../hooks/use-dashboard-stats`) providing ticket counts, loading state, and dynamic color for the `TECH_REQUIRED` status card
- **`TicketsOverviewSkeleton`** — Placeholder UI rendered while ticket data is loading
- **`DashboardInfoCard`** — Card component from `@flamingo-stack/openframe-frontend-core` displaying a status tag and numeric count, linking to the tickets list route
- **`TicketStatusTag`** — Status badge component used as the `titleSlot` for each card

## Usage Example

```typescript
// Drop into any dashboard page — no props required
import { TicketsOverviewSection } from './tickets-overview';

export default function DashboardPage() {
  return (
    <main>
      <TicketsOverviewSection />
    </main>
  );
}
```

## Grid Layout

The cards follow a responsive breakpoint strategy:

| Breakpoint | Columns |
|---|---|
| Mobile (`default`) | 1 |
| Medium (`md`) | 2 |
| Large (`lg`) | 4 |

The subtitle (total ticket count) is hidden on mobile and visible from `lg` upward via `[&_p]:hidden lg:[&_p]:block`.
