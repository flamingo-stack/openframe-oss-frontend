Renders the **Customers Overview** dashboard section, displaying a paginated list of organizations with their device health metrics (online/offline counts and percentages).

## Key Components

- **`CustomersOverviewSection`** — Primary export. Fetches up to 10 customer organizations via `useCustomersOverview` and renders each as a responsive 4-column grid row containing:
  - A branded customer card (logo, name, device count, website)
  - An "Online Devices" metric card with success progress indicator
  - An "Offline Devices" metric card with error progress indicator
- **Loading state** — Delegates to `CustomersOverviewSkeleton` on initial load to prevent layout shift
- **Empty state** — Renders an `EmptyState` prompt with `IdCardIcon` when no customers exist
- **Error state** — Displays an inline error message styled with `text-ods-error`

## Usage Example

```typescript
// Drop into any dashboard page — no props required.
import { CustomersOverviewSection } from './customers-overview';

export default function DashboardPage() {
  return (
    <main>
      <CustomersOverviewSection />
    </main>
  );
}
```

## Notes

- Each organization row links to its detail page via `routes.customers.details(org.organizationId)`
- Device filter links use query params (`?organizationIds=...&statuses=ONLINE|OFFLINE`) scoped to the organization
- The customer card icon slot is overridden with `[&>div:first-child>span]:size-full` to allow the `EntityImage` logo to fill the tile, matching the Figma spec
- The subtitle (`N Customers in Total`) is hidden on mobile (`[&_p]:hidden`) and shown on `lg+` breakpoints
