Renders the dashboard onboarding walkthrough by composing five guided setup steps with route navigation and analytics tracking.

## Key Components

- **`OnboardingSection`** — Primary export; a client component that builds and renders the `OnboardingWalkthrough` with step configs derived from live completion state.
- **`useOnboardingCompletion`** — Custom hook that supplies `completionStatus` and `isLoading`, eliminating redundant API calls shared with other dashboard hooks.
- **`onboardingSteps`** — Array of `OnboardingStepConfig` objects defining the five setup steps: Customers Setup, Device Management, Company & Team, SSO Configuration, and Knowledge Base.
- **Action handlers** — Memoized `useCallback` functions per step; device and SSO actions additionally fire `trackDashboardActivity` analytics events before routing.

## Usage Example

```typescript
// Render inside a dashboard layout — no props required
import { OnboardingSection } from './onboarding-section';

export default function DashboardPage() {
  return (
    <main>
      <OnboardingSection />
    </main>
  );
}
```

## Step Configuration Reference

| Step ID | Title | Action |
|---|---|---|
| `organizations-setup` | Customers Setup | Routes to `routes.customers.new` |
| `device-management` | Device Management | Routes to `routes.devices.new()` + analytics |
| `company-and-team` | Company & Team | Routes to `routes.settings.employees` |
| `sso-configuration` | SSO Configuration | Routes to `routes.settings.sso` + analytics |
| `knowledge-base` | Knowledge Base | Opens `flamingo.run/knowledge-base` in new tab; auto-completes on click |

The `storageKey` `"openframe-dashboard-onboarding"` persists dismissal state. Dismissing tracks `EVENT_SUBTYPE.SKIP_ONBOARDING` via `trackDashboardActivity`.
