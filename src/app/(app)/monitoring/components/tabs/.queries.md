The `Queries` component renders the fleet monitoring queries list page, handling search/filter, paginated display, empty state, and query deletion within the OpenFrame monitoring section.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Queries` | React Component | Main page component for browsing and managing fleet monitoring queries |

### Internal Logic

- **`useQueries`** — Fetches query data and exposes `deleteQuery` mutation
- **`useSearchParam`** — Syncs search input to URL params with 300ms debounce
- **`useStickyToolbar`** — Manages sticky search bar offset relative to scroll container
- **`useApiParams`** — Reads/writes URL search params for sharable state
- **`visibleCount` / `PAGE_SIZE`** — Client-side pagination via incremental load-more (20 items per page)
- **`showEmptyState`** — Guards empty state visibility; only shown when loading is complete, no active search, and zero queries exist
- **`rowActions`** — Per-row action menu: navigate to query details or open delete confirmation modal
- **`ConfirmDeleteMonitoringModal`** — Delete confirmation dialog; calls `deleteQuery` on confirm and clears selection on success

## Usage Example

```typescript
// Rendered at the /monitoring/queries route via Next.js App Router
import { Queries } from './queries';

export default function QueriesPage() {
  return <Queries />;
}
```

## Routing

| Action | Destination |
|--------|-------------|
| Row click / "Query Details" | `routes.monitoring.query(id)` |
| "Add Query" button | `routes.monitoring.queryNew` |
