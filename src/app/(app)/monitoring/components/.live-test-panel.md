Real-time panel component for displaying live query or policy test execution results, including timing, host response statistics, errors, and tabular data.

## Key Components

### `LiveTestPanel` (main export)
The primary panel component that renders a full test execution dashboard. Accepts a `LiveTestPanelProps` interface controlling:
- `mode` — `'query'` or `'policy'`, adjusts labels and empty-result messaging
- `isRunning` / `campaignStatus` — drives UI state (running, finished, pending)
- `results`, `errors`, `emptyResults`, `totals` — live data from the campaign hook
- `hostsResponded` / `hostsFailed` — device response counters
- `onTestAgain`, `onStop`, `onClose` — action callbacks

### `CollapsibleSection` (internal)
Accordion-style section with a colored chevron toggle. Used to surface errors and empty-result warnings in a compact, dismissible format. Defaults to collapsed, except for policy-mode empty results (which default open as the primary failure outcome).

### `formatDuration` (internal)
Converts milliseconds to `HH:MM:SS` string format for the live duration counter.

## Usage Example

```typescript
import { LiveTestPanel } from './live-test-panel';

<LiveTestPanel
  mode="query"
  isRunning={isRunning}
  startedAt={startedAt}
  results={results}
  errors={errors}
  emptyResults={emptyResults}
  totals={totals}
  hostsResponded={hostsResponded}
  hostsFailed={hostsFailed}
  campaignStatus={campaignStatus}
  onTestAgain={handleTestAgain}
  onStop={handleStop}
  onClose={() => setShowPanel(false)}
/>
```

The duration counter auto-updates every second via `setInterval` while `isRunning` is `true`, and freezes at the final elapsed time on completion. Policy mode displays empty results as failures (expanded by default); query mode treats them as informational warnings.
