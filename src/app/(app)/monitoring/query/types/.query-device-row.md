Defines the row model for the Query Details "Assigned Devices" table, combining Fleet host data with device registry information into a unified display structure.

## Key Components

### `QueryDeviceTag`
A key-value pair interface representing a single device tag.

| Field | Type | Description |
|-------|------|-------------|
| `key` | `string` | Tag key |
| `value` | `string` | Tag value |

### `QueryDeviceRow`
The primary row model built by merging `getQueryHosts` Fleet data with the device registry.

| Field | Type | Description |
|-------|------|-------------|
| `id` | `string` | Unique device identifier |
| `hostname` | `string` | Raw hostname |
| `displayName` | `string` | Human-readable device name |
| `deviceType` | `string \| undefined` | Device category |
| `organization` | `string \| undefined` | Owning organization name |
| `organizationImageUrl` | `string \| null \| undefined` | Organization logo URL |
| `organizationImageHash` | `string \| null \| undefined` | Organization logo hash |
| `osType` | `string \| undefined` | Operating system type |
| `status` | `string` | Connection status (e.g. `ONLINE` / `OFFLINE`) |
| `lastSeen` | `string \| undefined` | Last activity timestamp |
| `machineId` | `string \| undefined` | Machine-level identifier |
| `fleetHostId` | `number` | Numeric Fleet host ID |
| `tags` | `QueryDeviceTag[]` | Associated device tags |

## Usage Example

```typescript
import type { QueryDeviceRow, QueryDeviceTag } from './query-device-row';

const tags: QueryDeviceTag[] = [
  { key: 'env', value: 'production' },
  { key: 'region', value: 'us-east-1' },
];

const row: QueryDeviceRow = {
  id: 'device-abc123',
  hostname: 'workstation-01.local',
  displayName: 'Alice's Workstation',
  deviceType: 'desktop',
  organization: 'Acme Corp',
  organizationImageUrl: 'https://cdn.example.com/acme-logo.png',
  organizationImageHash: 'sha256:abc...',
  osType: 'macOS',
  status: 'ONLINE',
  lastSeen: '2024-01-15T10:30:00Z',
  machineId: 'machine-xyz789',
  fleetHostId: 42,
  tags,
};
```
