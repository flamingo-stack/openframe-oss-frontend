A client-side React component that renders a filterable, searchable data table of devices returned by a specific query, supporting search, tag-based filtering, and column-level filters.

## Key Components

- **`QueryDevicesTable`** — Main exported component accepting a `queryId` prop; fetches and displays associated devices in a `DataTable` with search, tag filters, and column filters.
- **`tagFilterKeys`** — Derived state grouping all device tags by key→values for use in the `FilterModal`.
- **`filteredRows`** — Client-side filtered rows based on active search term and selected tags.
- **`columns`** — Defines five columns: Device (name + last seen), Customer (org image + name), OS (badge), Status (tag), and an open-in-new-tab action button.
- **`useQueryDevicesTable`** — Custom hook that provides `rows` and `isLoading` for the given `queryId`.
- **`FilterModal`** — Slide-in modal for filtering devices by tag key/value pairs.

## Usage Example

```typescript
import { QueryDevicesTable } from '@/features/queries/components/query-devices-table';

export function QueryDetailPage({ queryId }: { queryId: number }) {
  return (
    <section>
      <h2>Matched Devices</h2>
      <QueryDevicesTable queryId={queryId} />
    </section>
  );
}
```

## Behavior Notes

- **Search** filters across `displayName`, `hostname`, and `organization` fields.
- **Tag filter** uses `key:value` string matching against each device's tag set.
- **Column filters** (Status, OS, Customer) derive their options from the full unfiltered dataset to keep choices stable.
- On mobile (`md` breakpoint), the "Device Tags" button collapses to an icon-only variant.
- Empty state messaging adapts based on whether active filters are present.
