A Next.js page component that renders the "create new query" view by delegating to the shared `EditQueryPage` component with a `null` query ID.

## Key Components

- **`NewQueryPageWrapper`** — Default export; a thin client-side page wrapper that mounts `EditQueryPage` in "new query" mode by passing `queryId={null}`.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to the new-query route.
// No props required — the page is self-contained.
import NewQueryPageWrapper from './page';

// Next.js handles routing; direct usage is uncommon outside of testing:
<NewQueryPageWrapper />
```

## Notes

- The `'use client'` directive marks this as a Client Component, enabling interactivity within the `EditQueryPage` subtree.
- The distinction between "new" and "edit" modes is controlled entirely by `queryId`: `null` = create, a valid ID = edit. See [`EditQueryPage`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/components/edit-query-page.tsx) for the shared form logic.
