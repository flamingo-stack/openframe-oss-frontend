Fetches and transforms fleet query report data using React Query, exposing flattened result rows and metadata for a given query ID.

## Key Components

- **`fetchQueryReport(queryId)`** — Async function that calls `fleetApiClient.getQueryReport` and throws on failure
- **`flattenResults(results)`** — Transforms nested report results into flat `QueryResultRow[]` objects, merging `host_name`, formatted `last_fetched`, and dynamic `columns`
- **`useQueryReport(queryId)`** — Primary exported hook that orchestrates fetching and memoized transformation

## Usage Example

```typescript
import { useQueryReport } from './use-query-report';

function QueryReportTable({ queryId }: { queryId: number | null }) {
  const { rows, reportClipped, isLoading, error, refetch } = useQueryReport(queryId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <>
      {reportClipped && <Banner>Report results are clipped</Banner>}
      <DataTable rows={rows} />
    </>
  );
}
```

## Return Shape

| Field | Type | Description |
|---|---|---|
| `rows` | `QueryResultRow[]` | Flattened report rows with host metadata and dynamic columns |
| `reportClipped` | `boolean` | Whether the report exceeded the result limit |
| `isLoading` | `boolean` | Query loading state |
| `error` | `string \| null` | Error message if fetch failed |
| `refetch` | `function` | Manually re-triggers the query |

The hook is disabled when `queryId` is `null`, and the query key is scoped under `queriesQueryKeys.detail` for proper cache invalidation alongside other query-detail hooks.
