Fetches and merges Fleet-assigned query hosts with the full device registry to produce enriched, sorted rows for the Query "Assigned Devices" table.

## Key Components

### `useQueryDevicesTable(queryId)` _(exported hook)_
The primary hook. Accepts a nullable `queryId`, fires two parallel React Query fetches, and returns merged `QueryDeviceRow[]` sorted by display name.

**Returns:**

| Field | Type | Description |
|---|---|---|
| `rows` | `QueryDeviceRow[]` | Merged, sorted device rows |
| `isLoading` | `boolean` | True while either query is in-flight |
| `error` | `string \| null` | First error message encountered |

### Internal Utilities

| Function | Description |
|---|---|
| `fetchDevicesPage(cursor)` | Fetches one page of devices via GraphQL with cursor-based pagination |
| `fetchAllDevices()` | Exhausts all pages, guarding against infinite loops on a `null` `endCursor` |
| `fetchQueryHosts(queryId)` | Fetches all Fleet hosts assigned to a query via page-based pagination |

## Usage Example

```typescript
import { useQueryDevicesTable } from './use-query-devices-table';

function AssignedDevicesTable({ queryId }: { queryId: number | null }) {
  const { rows, isLoading, error } = useQueryDevicesTable(queryId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <Table>
      {rows.map(row => (
        <Row key={row.id} name={row.displayName} status={row.status} />
      ))}
    </Table>
  );
}
```

## Notes

- Both queries are disabled when `queryId` is `null`.
- Deduplication favors the **most recently seen** device when multiple registry entries share the same Fleet host ID.
- Devices without a Fleet host ID are silently skipped during the merge step.
- Tags are flattened from `{ key, values[] }` into `{ key, value }[]` pairs.
