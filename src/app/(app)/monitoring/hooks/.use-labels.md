React Query hook for managing Fleet label (category) CRUD operations, including fetching, creating, and deleting labels with toast notifications and cache invalidation.

## Key Components

### `labelsQueryKeys`
Structured query key factory for React Query cache management:
- `labelsQueryKeys.all` — base key `['labels']`
- `labelsQueryKeys.list()` — scoped key for the labels list query

### `useLabels()`
Primary hook exposing:

| Return Value | Type | Description |
|---|---|---|
| `labels` | `FleetLabel[]` | Fetched labels list (defaults to `[]`) |
| `isLoading` | `boolean` | Labels fetch in progress |
| `error` | `string \| null` | Fetch error message |
| `createLabel` | `fn` | Create a label by name with optional callbacks |
| `isCreating` | `boolean` | Create mutation pending |
| `deleteLabel` | `fn` | Delete a label by ID with optional callbacks |
| `isDeleting` | `boolean` | Delete mutation pending |

Both `createLabel` and `deleteLabel` accept optional `onSuccess` / `onError` callbacks and automatically show toast notifications on completion.

## Usage Example

```typescript
import { useLabels } from '@/hooks/use-labels';

function LabelManager() {
  const {
    labels,
    isLoading,
    createLabel,
    isCreating,
    deleteLabel,
  } = useLabels();

  const handleCreate = () => {
    createLabel('Critical', {
      onSuccess: (label) => console.log('Created:', label),
      onError: (err) => console.error(err),
    });
  };

  const handleDelete = (id: number) => {
    deleteLabel(id, {
      onSuccess: () => console.log('Deleted'),
    });
  };

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {labels.map(label => (
        <li key={label.id}>
          {label.name}
          <button onClick={() => handleDelete(label.id)}>Remove</button>
        </li>
      ))}
      <button onClick={handleCreate} disabled={isCreating}>
        Add Label
      </button>
    </ul>
  );
}
```

## Notes

- Cache invalidation targets `labelsQueryKeys.all` on any successful mutation, ensuring both list and detail queries refresh.
- API errors are routed through [`handleApiError`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/handle-api-error.ts) for consistent error formatting before being surfaced to the optional `onError` callback.
