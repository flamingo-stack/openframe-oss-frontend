React hook managing real-time Fleet MDM live query campaigns over a SockJS-framed WebSocket connection, handling campaign lifecycle, result streaming, and error management.

## Key Components

### Types

| Type | Description |
|---|---|
| `CampaignError` | Host-level query execution error with osquery version info |
| `CampaignEmptyResult` | Host that responded with zero rows |
| `CampaignTotals` | Aggregate host counts (online/offline/missing) |
| `UseLiveCampaignReturn` | Complete hook return interface |

### Internal Utilities

- **`buildWsUrl`** — Converts HTTP base URL to WebSocket (`ws://`/`wss://`)
- **`encodeSockJsMessage`** — Serializes objects into SockJS frame format
- **`parseSockJsFrame`** — Decodes raw SockJS frames (`o`, `h`, `a`, `c` prefixes)
- **`getAllHostsLabelId`** — Fetches and caches Fleet's "All Hosts" dynamic label ID
- **`fetchFleetApiToken`** — Retrieves Fleet MDM API token via GraphQL

### Hook: `useLiveCampaign`

Core exported hook managing the full campaign lifecycle:

- Creates Fleet live query campaigns via `fleetApiClient.runLiveQuery`
- Opens a native WebSocket with SockJS framing
- Streams `totals`, `result`, `status`, and `error` messages
- Enforces a 250,000 row hard cap (`CAMPAIGN_LIMIT`) and 5-minute timeout (`CAMPAIGN_TIMEOUT_MS`)
- Supports both Bearer token and cookie auth modes
- Falls back to targeting all hosts when no `hostIds` are provided

## Usage Example

```typescript
import { useLiveCampaign } from '@/hooks/use-live-campaign';

function QueryRunner() {
  const {
    startCampaign,
    stopCampaign,
    isRunning,
    results,
    errors,
    totals,
    hostsResponded,
    connectionState,
    campaignStatus,
  } = useLiveCampaign();

  const handleRun = async () => {
    const sql = 'SELECT * FROM os_version;';
    const hostIds: number[] = []; // empty = all hosts
    const started = await startCampaign(sql, hostIds);
    if (!started) {
      console.error('Campaign failed to start');
    }
  };

  return (
    <div>
      <button onClick={handleRun} disabled={isRunning}>Run</button>
      <button onClick={stopCampaign} disabled={!isRunning}>Stop</button>
      <p>Status: {connectionState} / {campaignStatus}</p>
      <p>Responded: {hostsResponded} | Total: {totals?.count}</p>
      <p>Results: {results.length} rows | Errors: {errors.length}</p>
    </div>
  );
}
```

## Notes

- `startCampaign` returns `false` on validation or setup failure; use the return value to guard UI state
- The Fleet API token is prefetched via React Query with infinite stale time to avoid repeated fetches
- The "All Hosts" label ID is module-level cached across hook instances
