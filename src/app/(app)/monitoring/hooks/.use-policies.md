React hook for managing Fleet policy CRUD operations, providing querying, creation, updating, and deletion of policies with integrated toast notifications and cache invalidation via TanStack Query.

## Key Components

- **`policiesQueryKeys`** — Structured query key factory for consistent cache management (`all`, `list`, `detail`)
- **`usePolicies(params?)`** — Primary hook that encapsulates all policy data fetching and mutations

### Hook Return Values

| Property | Type | Description |
|---|---|---|
| `policies` | `Policy[]` | Fetched policy list (defaults to `[]`) |
| `isLoading` | `boolean` | Query loading state |
| `error` | `string \| null` | Error message if query failed |
| `refetch` | `function` | Manually re-trigger the query |
| `createPolicy` | `function` | Create a new policy |
| `isCreating` | `boolean` | Pending state for create mutation |
| `updatePolicy` | `function` | Update an existing policy by ID |
| `isUpdating` | `boolean` | Pending state for update mutation |
| `deletePolicy` | `function` | Delete a policy by ID |
| `isDeleting` | `boolean` | Pending state for delete mutation |
| `policiesQuery` | `UseQueryResult` | Raw TanStack Query object for advanced use |

## Usage Example

```typescript
import { usePolicies } from './use-policies';

function PoliciesPanel({ teamId }: { teamId: number }) {
  const {
    policies,
    isLoading,
    error,
    createPolicy,
    isCreating,
    deletePolicy,
  } = usePolicies({ team_id: teamId });

  const handleCreate = () => {
    createPolicy(
      {
        name: 'macOS Firewall Enabled',
        query: 'SELECT 1 FROM alf WHERE global_state >= 1;',
        description: 'Ensure macOS firewall is enabled',
        platform: 'darwin',
        critical: true,
      },
      {
        onSuccess: (policy) => console.log('Created:', policy.id),
        onError: (err) => console.error(err),
      },
    );
  };

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <>
      {policies.map(p => (
        <PolicyRow key={p.id} policy={p} onDelete={() => deletePolicy(p.id)} />
      ))}
      <button onClick={handleCreate} disabled={isCreating}>Add Policy</button>
    </>
  );
}
```

> All mutations automatically invalidate the `policies` query cache and display toast notifications on success or failure.
