Provides a React Query hook for fetching and deduplicating all online/offline devices for use in policy device selectors, handling paginated GraphQL requests internally.

## Key Components

- **`fetchAllDevices`** — Async function that paginates through all devices via GraphQL (100 per page), filtering for `ONLINE` and `OFFLINE` statuses, sorted by status descending.
- **`deduplicateByFleetId`** — Utility that deduplicates devices sharing the same Fleet host ID, retaining the entry with the most recent `lastSeen` timestamp.
- **`usePolicyDevices`** — Primary exported hook that composes the above utilities via `useQuery`, then partitions devices into Fleet-managed and non-Fleet groups before merging deduplicated results.

## Usage Example

```typescript
import { usePolicyDevices } from './use-policy-devices';

function PolicyDeviceSelector() {
  const { devices, isLoading } = usePolicyDevices();

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {devices.map(device => (
        <li key={device.id}>{device.hostname}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Pagination is handled automatically — all pages are fetched before the query resolves.
- Fleet devices are deduplicated by host ID before being merged with non-Fleet devices; non-Fleet devices are appended as-is.
- The query key `'policy-device-selector-devices'` can be targeted for manual cache invalidation if needed.
