Fetches and caches a single Fleet policy by ID using React Query, exposing a clean interface for loading state, error handling, and data access.

## Key Components

- **`fetchPolicy(id)`** — Internal async function that calls `fleetApiClient.getPolicy(id)` and throws on non-OK responses
- **`usePolicyDetails(policyId)`** — Primary exported hook; accepts a nullable policy ID and returns normalized query state

## Usage Example

```typescript
import { usePolicyDetails } from './use-policy-details';

function PolicyDetail({ policyId }: { policyId: number | null }) {
  const { policyDetails, isLoading, error, refetch } = usePolicyDetails(policyId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;
  if (!policyDetails) return null;

  return <div>{policyDetails.name}</div>;
}
```

## Notes

- Query is **disabled** when `policyId` is `null`, preventing unnecessary fetches
- Uses `policiesQueryKeys.detail()` from the shared `use-policies` hook for cache key consistency
- Returns `null` for both `policyDetails` and `error` (instead of `undefined`) for easier conditional rendering
