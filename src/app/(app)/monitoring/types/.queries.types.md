Defines TypeScript interfaces for Fleet query entities and their associated API request/response shapes, covering query metadata, per-host query reports, and report result payloads.

## Key Components

| Interface | Description |
|---|---|
| `Query` | Full query entity including metadata, scheduling config (`interval`, `platform`), authorship, and feature flags (`automations_enabled`, `discard_data`) |
| `QueryReportResult` | A single row result from a query report, keyed by host with dynamic `columns` |
| `HostQueryReport` | Per-host query report entry from `GET /fleet/hosts/{id}/queries`, includes result count and first result preview but **not** `interval` |
| `HostQueriesResponse` | Paginated wrapper around `HostQueryReport[]` with `count` and cursor-style `meta` |
| `QueryReportResponse` | Response shape for a full query report, including clipping status and all `results` |
| `QueryReportParams` | Optional sort parameters for querying report results |

## Usage Example

```typescript
import {
  Query,
  HostQueryReport,
  QueryReportResponse,
} from "./queries.types";

// Merge interval from global query into a per-host report
function enrichReport(
  report: HostQueryReport,
  queries: Query[]
): HostQueryReport & { interval: number } {
  const global = queries.find((q) => q.id === report.report_id);
  return { ...report, interval: global?.interval ?? 0 };
}

// Type-check a report response
const response: QueryReportResponse = {
  query_id: 42,
  report_clipped: false,
  results: [
    { host_id: 1, host_name: "mac-01", last_fetched: "2024-01-01T00:00:00Z", columns: { version: "14.0" } },
  ],
};
```

## Notes

- `HostQueryReport.interval` is intentionally absent — frequency must be joined from the matching `Query` by `report_id === Query.id`.
- `columns` on both `QueryReportResult` and `HostQueryReport.first_result` are loosely typed as `Record<string, string>` to accommodate dynamic osquery column schemas.
