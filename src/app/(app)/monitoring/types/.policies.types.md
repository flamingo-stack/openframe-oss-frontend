Defines TypeScript interfaces for the policy domain, including the full `Policy` entity shape and filter criteria used when querying policies.

## Key Components

### `Policy`
Represents a compliance or configuration policy with the following notable fields:

| Field | Type | Description |
|---|---|---|
| `id` | `number` | Unique policy identifier |
| `critical` | `boolean` | Marks high-priority policies |
| `query` | `string` | The osquery SQL query for the policy |
| `platform` | `string` | Target platform (e.g., `darwin`, `windows`) |
| `calendar_events_enabled` | `boolean` | Whether calendar event reminders are active |
| `passing_host_count` / `failing_host_count` | `number` | Compliance counters across hosts |
| `hosts_include_any` | `Array<{ id, hostname }>` | Optional scoped host targets |

### `PolicyFilters`
Lightweight filter payload for querying/listing policies:

| Field | Type | Description |
|---|---|---|
| `status` | `string[]` | Filter by policy status values |
| `source` | `string[]` | Filter by policy source/origin |

## Usage Example

```typescript
import type { Policy, PolicyFilters } from './policies.types';

const filter: PolicyFilters = {
  status: ['failing'],
  source: ['team'],
};

const policy: Policy = {
  id: 42,
  name: 'Disk Encryption Enabled',
  query: 'SELECT 1 FROM disk_encryption WHERE encrypted = 1;',
  critical: true,
  description: 'Ensures full-disk encryption is active.',
  author_id: 7,
  author_name: 'Jane Doe',
  author_email: 'jane@example.com',
  resolution: 'Enable FileVault or BitLocker.',
  platform: 'darwin',
  calendar_events_enabled: false,
  created_at: '2024-01-15T10:00:00Z',
  updated_at: '2024-06-01T08:30:00Z',
  passing_host_count: 120,
  failing_host_count: 3,
};
```
