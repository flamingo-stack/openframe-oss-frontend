Customers page entry point that renders a tabbed interface for managing customer/organization records, resetting the search state on each tab switch.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Organizations` | Default export (React component) | Root page component that orchestrates tab navigation and per-tab content rendering |

### Key Dependencies

- **`useApiParams`** — Manages URL-synced query parameters (`tab`, `search`) so navigation state is bookmarkable and shareable
- **`getTabComponent`** — Resolves the active tab string to its corresponding React component from `CUSTOMERS_TABS`
- **`CustomersTabNavigation`** — Renders the tab bar; triggers a combined tab + search reset on switch

## Usage Example

```typescript
// Rendered automatically by Next.js at the /customers route.
// Tab state is driven by URL search params, e.g.:
// /customers?tab=active
// /customers?tab=archived&search=acme

// On tab switch, search is cleared to avoid stale filters carrying over:
onTabChange={tab => setParams({ tab, search: '' })}
```

## Behavior Notes

- **Default tab:** `active` (falls back when no `tab` param is present in the URL)
- **Search ownership:** The `search` param is declared at this level—not inside the child table—so it can be cleared when switching tabs; each tab starts with an empty search
- **Graceful fallback:** If `getTabComponent` returns `null` (unknown tab value), nothing is rendered rather than crashing
