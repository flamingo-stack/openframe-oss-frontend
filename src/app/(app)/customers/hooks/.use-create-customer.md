A React hook for creating new customer organizations via the API, encapsulating the POST request logic and error handling.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `ContactPersonDto` | Represents an individual contact with name, title, phone, and email |
| `AddressDto` | Physical or mailing address with street, city, state, postal code, and country |
| `ContactInformationDto` | Aggregates contacts, physical/mailing addresses, and same-address flag |
| `CreateCustomerRequest` | Full payload for creating a customer organization |

### Hook

**`useCreateCustomer()`** — Returns `{ createOrganization }`, a memoized async function that POSTs to `/api/organizations`.

- Throws an `Error` if the response is not `ok`, using the API error message or HTTP status as the error detail
- Wrapped in `useCallback` with an empty dependency array for stable reference across renders

## Usage Example

```typescript
import { useCreateCustomer, CreateCustomerRequest } from '@/hooks/use-create-customer';

function NewCustomerForm() {
  const { createOrganization } = useCreateCustomer();

  const handleSubmit = async () => {
    const payload: CreateCustomerRequest = {
      name: 'Acme Corp',
      category: 'SMB',
      numberOfEmployees: 50,
      contactInformation: {
        contacts: [{ contactName: 'Jane Doe', title: 'CEO', phone: '555-0100', email: 'jane@acme.com' }],
        physicalAddress: { street1: '123 Main St' },
        mailingAddress: { street1: '123 Main St' },
        mailingAddressSameAsPhysical: true,
      },
    };

    const result = await createOrganization(payload);
    console.log('Created:', result);
  };
}
```
