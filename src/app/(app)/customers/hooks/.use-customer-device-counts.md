Fetches and caches device counts per organization using a GraphQL query, returning a stable `Map<string, number>` keyed by organization ID.

## Key Components

- Cache key comes from the shared `deviceQueryKeys.countsBy(filter)` registry, so a device mutation refreshes these counts along with every other device surface.
- **`useCustomerDeviceCounts(organizationIds)`** — Primary hook that accepts an array of organization IDs, fires a `GetOrganizationDeviceCounts` GraphQL request, and returns a memoized map of device counts alongside a loading state.
- **`EMPTY_DEVICE_COUNTS`** — Shared readonly empty `Map` used as a stable fallback before data loads, preventing unnecessary re-renders.

## Behavior Notes

- Organization IDs are **sorted before use** (`useMemo`) to ensure query key stability regardless of input order.
- The query is **disabled** when `organizationIds` is empty, avoiding unnecessary network requests.
- Results are cached for **30 seconds** (`staleTime: 30_000`).
- GraphQL-level errors are surfaced as thrown `Error` instances, consistent with HTTP-level failures.

## Usage Example

```typescript
import { useCustomerDeviceCounts } from '@/hooks/use-customer-device-counts';

function CustomerTable({ orgIds }: { orgIds: string[] }) {
  const { deviceCounts, isLoading } = useCustomerDeviceCounts(orgIds);

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {orgIds.map((id) => (
        <li key={id}>
          Org {id}: {deviceCounts.get(id) ?? 0} devices
        </li>
      ))}
    </ul>
  );
}
```
