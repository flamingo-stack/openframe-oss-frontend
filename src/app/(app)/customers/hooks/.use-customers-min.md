A React client hook for fetching a lightweight list of organizations (customers) via GraphQL, returning minimal fields suitable for dropdowns and search selectors.

## Key Components

### `OrganizationMin` Interface
Minimal organization shape returned by the hook:

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Internal node ID |
| `organizationId` | `string` | Business-level organization identifier |
| `name` | `string` | Display name |
| `isDefault` | `boolean` | Whether this is the default organization |
| `imageUrl` | `string?` | Optional logo/avatar URL |

### `useCustomersMin(limit?)`
Client-side hook that queries `GET_ORGANIZATIONS_MIN_QUERY` against `/api/graphql`.

**Parameters**
- `limit` — max results to fetch (default: `10`)

**Returns**

| Property | Type | Description |
|---|---|---|
| `items` | `OrganizationMin[]` | Fetched organizations |
| `isLoading` | `boolean` | Request in-flight indicator |
| `error` | `string \| null` | Error message if request failed |
| `fetch` | `(search?: string) => Promise<OrganizationMin[]>` | Trigger fetch with optional search string |

## Usage Example

```typescript
import { useCustomersMin } from '@/features/customers/hooks/use-customers-min';

export function CustomerSearch() {
  const { items, isLoading, error, fetch } = useCustomersMin(20);

  const handleSearch = async (query: string) => {
    await fetch(query);
  };

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {items.map((org) => (
        <li key={org.id}>{org.name}</li>
      ))}
    </ul>
  );
}
```

> `fetch` is memoized via `useCallback` and only re-creates when `limit` changes, making it safe to pass as a prop or effect dependency.
