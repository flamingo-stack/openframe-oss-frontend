A React hook that provides a function to update an existing customer/organization record via a `PUT` API request.

## Key Components

- **`useUpdateCustomer`** — Custom hook that exposes `updateOrganization`, a memoized async function for updating an organization by ID.
- **`updateOrganization(id, request)`** — Sends a `PUT` request to `/api/organizations/:id`. Throws an error if the response is not successful; otherwise returns the response data.
- **`CreateCustomerRequest`** — Reuses the request type from [`use-create-customer`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/use-create-customer.ts) as the update payload shape.

## Usage Example

```typescript
import { useUpdateCustomer } from './use-update-customer';

function EditCustomerForm({ customerId }: { customerId: string }) {
  const { updateOrganization } = useUpdateCustomer();

  const handleSubmit = async (formData: CreateCustomerRequest) => {
    try {
      const updated = await updateOrganization(customerId, formData);
      console.log('Updated organization:', updated);
    } catch (error) {
      console.error('Failed to update organization:', error);
    }
  };

  return (
    // form JSX
  );
}
```
