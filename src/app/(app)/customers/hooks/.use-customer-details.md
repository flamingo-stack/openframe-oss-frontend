A React Query hook for fetching and normalizing customer organization details from the GraphQL API.

## Key Components

- **`CustomerDetails`** — Interface defining the normalized customer data shape, including contact roles (primary, billing, technical), contract info, and MRR
- **`customerDetailsQueryKeys`** — Query key factory for cache management (`all` and `detail(id)`)
- **`useCustomerDetails(id?)`** — Main exported hook; returns `organization`, `isLoading`, `error`, and `refetch`
- **`fetchCustomer(id)`** — Internal async function that POSTs the GraphQL query via `apiClient`
- **`mapOrganization(org)`** — Internal mapper that normalizes raw GraphQL response to `CustomerDetails`
- **`formatAddress(addr?)`** — Internal utility that concatenates address fields into a single comma-separated string

## Usage Example

```typescript
import { useCustomerDetails } from '@/features/customers/hooks/use-customer-details';

function CustomerProfile({ organizationId }: { organizationId: string }) {
  const { organization, isLoading, error, refetch } = useCustomerDetails(organizationId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <div>
      <h1>{organization?.name}</h1>
      <p>{organization?.industry}</p>
      <p>MRR: ${organization?.mrrUsd ?? 'N/A'}</p>
      <p>Primary Contact: {organization?.primary.name}</p>
    </div>
  );
}
```

## Notes

- The hook is disabled when `id` is falsy (`enabled: !!id`), making it safe to call with optional IDs
- Contacts are mapped positionally from the API response: index `0` → primary, `1` → billing, `2` → technical
- All string fields fall back to `'-'` or `''` to prevent null rendering issues in the UI
