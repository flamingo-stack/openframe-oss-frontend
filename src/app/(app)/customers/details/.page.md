Thin Next.js client page that extracts the `id` query parameter from the URL and delegates rendering to the `CustomerDetailsView` component.

## Key Components

- **`CustomerDetailsPage`** — Default export; reads the `id` search param and passes it to `CustomerDetailsView`.

## Usage Example

```typescript
// Accessed via URL: /customers/details?id=cust_123
// The page automatically reads `id` and forwards it to the view component.
<CustomerDetailsPage />
```

## Notes

- Marked `'use client'` because it uses `useSearchParams`, which requires the client-side rendering context.
- Falls back to an empty string (`''`) if no `id` param is present; the consuming `CustomerDetailsView` should handle that gracefully.
