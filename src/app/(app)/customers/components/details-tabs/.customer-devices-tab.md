Renders a scoped devices panel for a specific customer/organization, pre-filtering the device list and locking it to the given `organizationId`.

## Key Components

- **`CustomerDevicesTab`** — React component that wraps `DevicesPanel` with organization-specific configuration
- **`lockedFilters`** — Memoized filter object that constrains device results to the current organization
- **`DevicesPanel`** — Shared panel component rendered in embedded mode with hidden organization column and filter

## Usage Example

```typescript
import { CustomerDevicesTab } from './customer-devices-tab';

<CustomerDevicesTab organizationId="org_abc123" />
```

The component hides the `organization` column and filter since they are irrelevant in a single-customer context, and pre-populates the "Add Device" link with the correct `organizationId` via [`routes.devices.new`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/lib/routes.ts).
