Read-only tab component that displays the effective AI guardrails for a specific customer organization, showing either inherited tenant defaults or the organization's own materialized policy.

## Key Components

### `CustomerGuardrailsTab`
The primary exported component accepting an `organizationId` prop. Renders three states:
- **Loading** — skeleton placeholders while fetching guardrails and templates
- **Error** — `LoadError` with retry capability if data fetch fails
- **Content** — preset label card, optional "Using Default Settings" banner, and grouped policy rules

### Key Logic
- **`useOrganizationGuardrails(organizationId)`** — fetches the organization's effective guardrails
- **`useGuardrailsTemplates()`** — resolves tenant preset display names
- **`buildPolicyGroups(rules)`** — memoized grouping of flat rules into categorized `Map` entries
- **`presetLabel`** — derived label showing one of: active tenant preset, a named source template, or `Custom Policy (based on <template>)` when overrides exist

## Usage Example

```typescript
// Inside a customer details page or tab panel
import { CustomerGuardrailsTab } from './customer-guardrails-tab';

export default function CustomerPage({ params }: { params: { orgId: string } }) {
  return (
    <CustomerGuardrailsTab organizationId={params.orgId} />
  );
}
```

## Behavior Notes

- When `inheritDefault` is `true`, a banner is shown with a shortcut to edit the tenant-wide defaults in **AI Settings → Guardrails**
- The component is **read-only**; mutations (`updateOrganizationGuardrails` / `resetOrganizationGuardrails`) are not wired here but are available for extending per-customer edit flows
- `NoData` is rendered with a shield icon when policy groups resolve to an empty `Map`
