Renders a filterable, paginated ticket list scoped to a specific customer organization within the customer detail view.

## Key Components

- **`CustomerTicketsTab`** — Main exported component; accepts an `organizationId` prop and displays all tickets belonging to that organization
- **`ticketBelongsToOrganization`** — Helper predicate that filters tickets by direct `organizationId` match or via a machine-linked owner
- **`useTicketsQuery`** — Hook that fetches paginated ticket dialogs with optional search filtering
- **`useStickyToolbar`** — Hook managing sticky positioning offsets for the search toolbar and table header
- **`getTicketTableColumns`** — Generates base column definitions; extended here with an "open in new tab" action column

## Usage Example

```typescript
import { CustomerTicketsTab } from './customer-tickets-tab';

// Inside a customer detail page or tab panel
export default function CustomerPage({ params }: { params: { orgId: string } }) {
  return (
    <CustomerTicketsTab organizationId={params.orgId} />
  );
}
```

## Notes

- Tickets are client-side filtered by `organizationId` after being fetched; the search query is debounced (300 ms) before being passed to `useTicketsQuery`
- The search toolbar is sticky (`top-0, z-20`) with negative vertical margins to extend its background without affecting layout flow; the `DataTable` header docks below it via `stickyHeaderOffset`
- Clicking a row navigates to the ticket dialog route; the trailing action button opens the same route in a new tab
- Infinite scroll is handled via `DataTable.InfiniteFooter` using `fetchNextPage` from the tickets query
