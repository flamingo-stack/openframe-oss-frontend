Customer-scoped worktime tab component that renders a work time table filtered to a single organization, with a pre-filled "Add Work Time" dialog that locks the customer field.

## Key Components

- **`CustomerWorktimeTab`** — Default export. Accepts a `CustomerDetails` organization and renders the tab layout with a header action and filtered work time table.
- **`addDefaultCustomer`** — Memoized object derived from the organization prop; pre-fills and locks the customer field in the add dialog to prevent cross-customer data entry.
- **`addOpen` state** — Controls visibility of the add work time dialog, toggled by the header button and passed to `WorkTimeTable`.

## Usage Example

```typescript
import { CustomerWorktimeTab } from './customer-worktime-tab';

<CustomerWorktimeTab
  organization={{
    id: 'global-org-123',
    organizationId: 'org-456',
    name: 'Acme Corp',
    imageUrl: '/uploads/acme.png',
    imageHash: 'abc123',
    // ...other CustomerDetails fields
  }}
/>
```

## Props

| Prop | Type | Description |
|---|---|---|
| `organization` | `CustomerDetails` | The customer whose work time entries are displayed and pre-filled on add |

## Notes

- The `Customer` column is intentionally omitted from the table (single-customer context).
- `showEmployee` is always enabled — useful for identifying which technician logged time.
- `getFullImageUrl` resolves the organization avatar shown in the pre-filled customer selector.
