Renders a structured details card for a customer organization, displaying website, physical address, and mailing address in a consistent grid layout.

## Key Components

### `InfoCell` (internal)
A flexible display cell that renders a labeled value with optional icon and hyperlink support. Falls back to an em dash (`—`) for empty or placeholder values. When an `href` is provided and the value is non-empty, wraps content in an external `<a>` tag.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `value` | `string` | Display value |
| `label` | `string` | Field label shown below the value |
| `icon` | `ReactNode` | Optional leading icon |
| `href` | `string` | Optional URL; enables link behavior |

### `CustomerDetailsTab`
The primary exported component. Accepts a `CustomerDetails` object and renders a card with three info cells: website (with external link icon), physical address, and mailing address.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `organization` | `CustomerDetails` | Customer data from `useCustomerDetails` hook |

## Usage Example

```typescript
import { CustomerDetailsTab } from './customer-details-tab';

const org = {
  website: 'flamingo.run',
  physicalAddress: '123 Main St, Austin TX',
  mailingAddress: 'PO Box 456, Austin TX',
};

<CustomerDetailsTab organization={org} />
```

## Notes

- Website URLs without a protocol prefix are automatically prepended with `https://`
- Values equal to `'-'` or empty strings are treated as missing and rendered as `—`
- Layout is responsive: address cells stack vertically on mobile and display inline on `md+` breakpoints
