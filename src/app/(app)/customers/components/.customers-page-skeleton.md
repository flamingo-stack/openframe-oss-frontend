A route-level loading skeleton for the `/customers` page, rendering placeholder UI that mirrors the structure of the fully-loaded customers list — including the tab bar, page header, search toolbar, and table columns.

## Key Components

- **`CustomersPageSkeleton`** — Primary export. A React component that delegates to `ListPageSkeleton` with customers-specific configuration.
- **`TAB_WIDTHS`** — Tuple of Tailwind width classes approximating the "Active" and "Archived" tab labels.
- **`ACTIONS`** — Disabled "Add Customer" button definition passed to the page header skeleton.
- **`COLUMNS`** — Column layout mirroring `buildCustomersColumns`: Name (flex), Devices, Last Activity, and an open/chevron column — with responsive `hideAt` breakpoints.

## Usage Example

This component is intended for use as a Next.js route segment loading UI (`loading.tsx`):

```typescript
// app/customers/loading.tsx
export { CustomersPageSkeleton as default } from './customers-page-skeleton';
```

Or composed directly in a parent suspense boundary:

```typescript
import { Suspense } from 'react';
import { CustomersPageSkeleton } from './customers-page-skeleton';
import { CustomersPageContent } from './customers-page-content';

export default function CustomersPage() {
  return (
    <Suspense fallback={<CustomersPageSkeleton />}>
      <CustomersPageContent />
    </Suspense>
  );
}
```

## Notes

- Column definitions intentionally mirror `buildCustomersColumns` — if columns are added or removed from the real table, update `COLUMNS` here to keep the skeleton visually consistent.
- The `hideAt: 'md'` flags on Devices, Last Activity, and the open column match the responsive behavior of the live table.
