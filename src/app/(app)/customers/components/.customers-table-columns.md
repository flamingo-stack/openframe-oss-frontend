Defines the column configuration, UI components, and table body for the customers data table, including customer name cells, search input, date filtering, and device count display.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `UiCustomerEntry` | Interface | Flat UI-ready customer data model with device counts and formatted activity dates |
| `CustomerNameCell` | Component | Renders customer avatar, name, and email in a single table cell |
| `transformCustomerToEntry` | Function | Maps a raw `Customer` API object + device count into a `UiCustomerEntry` |
| `buildCustomersColumns` | Function | Returns `ColumnDef[]` for the customers table; accepts optional `CustomersDateFilter` to wire sort/range popover on the Last Activity column |
| `customerRowHref` | Function | Resolves the navigation href for a customer row click |
| `CustomersSearchInput` | Component | Controlled search input with a leading `SearchIcon` |
| `CustomersTableBody` | Component | Full table composition — fetches device counts, transforms rows, builds columns, and renders via `DataTable` |
| `CustomersDateFilter` | Interface | Props contract for sort direction, date range, and apply callback wired to the Last Activity header |

## Usage Example

```typescript
import { CustomersTableBody, CustomersSearchInput } from './customers-table-columns';

function CustomersPage() {
  const [search, setSearch] = useState('');
  const [range, setRange] = useState<DateRange>();
  const [sortDirection, setSortDirection] = useState<'asc' | 'desc'>('desc');

  return (
    <>
      <CustomersSearchInput value={search} onChange={setSearch} />
      <CustomersTableBody
        customers={customers}
        isLoading={isLoading}
        stickyHeaderOffset="64px"
        dateFilter={{
          sortDirection,
          range,
          onApply: ({ sort, range }) => {
            setSortDirection(sort);
            setRange(range);
          },
        }}
      />
    </>
  );
}
```

## Notes

- Device counts are fetched lazily via `useCustomerDeviceCounts`, keyed by `organizationId`
- The Last Activity column header upgrades from a plain string to an interactive `DateFilterMenu` popover when `dateFilter` is provided
- The open-in-new-tab action cell uses `data-no-row-click` to prevent row navigation when clicking the button
- Column visibility breakpoints (`hideAt: 'md'`) collapse Devices, Last Activity, and the open button on smaller screens
