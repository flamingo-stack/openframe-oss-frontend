A modal dialog component for confirming the restoration of an archived customer back to the active workspace.

## Key Components

- **`RestoreCustomerModal`** — Thin wrapper around `ConfirmDialog` that pre-configures messaging and behavior for the customer restore action.
- **`RestoreCustomerModalProps`** — Interface defining the component's props:
  - `open` — Controls dialog visibility
  - `onOpenChange` — Callback to toggle open state
  - `onConfirm` — Callback executed on confirmation
  - `isPending` — Optional flag to show loading state during the restore operation

## Usage Example

```typescript
import { RestoreCustomerModal } from './restore-customer-modal';

function CustomerActions() {
  const [isOpen, setIsOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleRestore = async () => {
    setIsPending(true);
    await restoreCustomer(customerId);
    setIsPending(false);
    setIsOpen(false);
  };

  return (
    <RestoreCustomerModal
      open={isOpen}
      onOpenChange={setIsOpen}
      onConfirm={handleRestore}
      isPending={isPending}
    />
  );
}
```

## Notes

- Uses `variant="default"` on the underlying `ConfirmDialog`, rendering a neutral (non-destructive) confirmation style appropriate for a restore action.
- Displays "Restoring..." as the button label while `isPending` is `true`.
