Renders the "Customer AI Configuration" tab on the customer edit page, allowing per-organization overrides of AI assistant settings (appearance, provider/model, answer style, quick actions) with a toggle to inherit global defaults.

## Key Components

### `CustomerAiConfiguration`

A `forwardRef` component exposing an imperative handle for parent-driven persistence.

**Props (`CustomerAiConfigurationProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `organizationId` | `string` | Scopes all config reads/writes to this organization |

**Ref Handle (`CustomerAiConfigurationHandle`):**

| Method | Signature | Description |
|--------|-----------|-------------|
| `validate` | `() => Promise<boolean>` | Validates form fields; skips when inheriting defaults |
| `commit` | `() => Promise<void>` | Persists or resets both overrides (`ClientView` + `OrganizationClientAiConfig`) |

### Key Behaviors

- **Two-backend model:** Syncs `ClientView` (name/avatar/theme/accent) and `OrganizationClientAiConfig` (provider/model/answer style/quick actions) independently
- **Inherit toggle:** Unchecked = custom overrides; checked = resets both overrides (guarded by a confirm dialog when existing overrides are detected)
- **Seeded toggle:** Waits for both org records to load before reflecting server state, preventing silent resets on unrelated saves
- **Quick actions inheritance:** Resolves the effective inherited set from the tenant's custom list or Product Hub defaults

## Usage Example

```typescript
const saveRef = useRef<CustomerAiConfigurationHandle>(null);

const handleSave = async () => {
  const isValid = await saveRef.current?.validate();
  if (!isValid) return;
  await saveRef.current?.commit();
};

<CustomerAiConfiguration
  ref={saveRef}
  organizationId="org_abc123"
/>
```
