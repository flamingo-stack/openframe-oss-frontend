Client-side Next.js page wrapper that extracts the `id` query parameter from the URL and renders the `ArticleDetailsPage` component, triggering a 404 if no `id` is present.

## Key Components

- **`ArticleDetailsPageWrapper`** — Default export; reads `id` from search params and delegates rendering to `ArticleDetailsPage`.

## Usage Example

```typescript
// Accessed via URL: /articles?id=abc123
// Renders: <ArticleDetailsPage articleId="abc123" />

// Missing id → triggers notFound() → renders 404 page
// /articles (no ?id=) → 404
```

## Notes

- Marked `'use client'` since it uses `useSearchParams()`, which requires a browser context.
- Delegates all rendering logic to [`ArticleDetailsPage`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/articles/components/article-details-page.tsx) — this wrapper only handles routing concerns.
