A React hook that moves a knowledge base item to a different folder via a GraphQL mutation, with optimistic Relay store updates for connection management.

## Key Components

### `useMoveToFolder()`
Main exported hook that encapsulates the move-to-folder mutation logic. Returns:
- **`moveToFolder(args)`** — async function that executes the mutation and updates Relay connections
- **`isPending`** — boolean indicating if the mutation is in flight

### `MoveToFolderArgs`
```typescript
interface MoveToFolderArgs {
  id: string;                         // ID of the item to move
  parentId: string | null;            // Target folder ID (null = root)
  removeFromConnections: string[];    // Relay connection IDs to remove item from
  appendToConnections?: string[];     // Relay connection IDs to add item to
  onCompleted?: () => void;           // Optional success callback
}
```

### Relay Store Updater
After mutation success, the updater:
1. Removes the item from all specified source connections via `ConnectionHandler.deleteNode`
2. Creates a new `KnowledgeBaseItemEdge` and appends it to each target connection via `ConnectionHandler.insertEdgeAfter`

## Usage Example

```typescript
import { useMoveToFolder } from './use-move-to-folder';

function MoveButton({ itemId, targetFolderId, sourceConnectionId, targetConnectionId }) {
  const { moveToFolder, isPending } = useMoveToFolder();

  const handleMove = async () => {
    await moveToFolder({
      id: itemId,
      parentId: targetFolderId,
      removeFromConnections: [sourceConnectionId],
      appendToConnections: [targetConnectionId],
      onCompleted: () => console.log('Moved successfully'),
    });
  };

  return <button onClick={handleMove} disabled={isPending}>Move</button>;
}
```

On error, a destructive toast notification is automatically displayed with the error message.
