A React hook that manages the complete lifecycle of a knowledge base article form, handling both create and edit modes with support for draft/publish workflows, tag management, assignments, and file attachments.

## Key Components

### Types

- **`SaveStatus`** — Union type `'DRAFT' | 'PUBLISHED'` representing the target article status on save
- **`UseEditArticleFormOptions`** — Input options: `articleId` (null for create mode), `initialFolderId`, and `initialArticle` (pre-fetched Relay node)

### Hook: `useEditArticleForm`

Returns the following:

| Return Value | Type | Description |
|---|---|---|
| `form` | `UseFormReturn<ArticleFormData>` | React Hook Form instance with Zod validation |
| `isEditMode` | `boolean` | `true` when `articleId` is provided |
| `isSubmitting` | `boolean` | Submission in-progress flag |
| `handleSave` | `(status: SaveStatus) => void` | Triggers form validation and persists the article |
| `tempAttachments` | `ArticleTempAttachmentsHook` | Manages pending file uploads and deletions |

### Internal Behavior

- **Form initialization** — Resets form values from `initialArticle` and `assignedItems` once both are ready; falls back to `ARTICLE_FORM_DEFAULTS` for new articles
- **Tag diffing** — Computes added/removed tag IDs between the initial state and submitted form values, then calls `addTag`/`removeTag` in parallel
- **Status transitions** — Handles `ARCHIVED → PUBLISHED`, `PUBLISHED → DRAFT`, and `DRAFT → PUBLISHED` transitions, calling `unarchiveArticle` as a prerequisite when needed
- **Attachment linking** — After save, links any temporary attachment IDs via `linkAttachments` and refreshes the Relay store with `fetchQuery(..., { fetchPolicy: 'network-only' })`
- **Assignment sync** — Delegates to `applyAssignmentsDiff` to reconcile previous and next assignment maps

## Usage Example

```typescript
const { form, isEditMode, isSubmitting, handleSave, tempAttachments } =
  useEditArticleForm({
    articleId: params.id ?? null,        // null → create mode
    initialFolderId: searchParams.folder,
    initialArticle: queryData?.node,
  });

// Save as draft
<Button onClick={() => handleSave('DRAFT')} disabled={isSubmitting}>
  Save Draft
</Button>

// Publish
<Button onClick={() => handleSave('PUBLISHED')} disabled={isSubmitting}>
  Publish
</Button>
```
