A React hook that attaches a tag to a knowledge base item via a GraphQL mutation, with built-in error toasting.

## Key Components

- **`addTagMutation`** — Relay GraphQL mutation (`useAddTagMutation`) that calls `addTagToKnowledgeBaseItem`, returning the updated item's `id` and `tags` array (`id`, `key`, `color`).
- **`useAddTag()`** — Custom hook exposing:
  - `addTag(itemId, tagId)` — Returns a `Promise<void>` that resolves on success or rejects (and displays a destructive toast) on error.
  - `isPending` — Boolean reflecting whether the mutation is in-flight.

## Usage Example

```typescript
import { useAddTag } from '@/hooks/use-add-tag';

function TagButton({ itemId, tagId }: { itemId: string; tagId: string }) {
  const { addTag, isPending } = useAddTag();

  const handleClick = async () => {
    await addTag(itemId, tagId);
  };

  return (
    <button onClick={handleClick} disabled={isPending}>
      {isPending ? 'Adding…' : 'Add Tag'}
    </button>
  );
}
```

## Notes

- Uses `useCallback` to memoize `addTag` against `commit` and `toast` dependencies.
- Error messages fall back to `'Unable to add tag'` if the thrown value is not an `Error` instance.
- Generated types are sourced from `@/__generated__/useAddTagMutation.graphql`.
