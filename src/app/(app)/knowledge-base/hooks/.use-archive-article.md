A React hook that archives a knowledge base article via a GraphQL mutation, with Relay store updates to remove the article from specified connections and optionally prepend it to archive connections.

## Key Components

- **`archiveArticleMutation`** — GraphQL mutation returning the archived article's `id`, `status`, `parentId`, and `updatedAt`
- **`ArchiveArticleArgs`** — Interface defining mutation arguments:
  - `id` — Article ID to archive
  - `removeFromConnections` — Relay connection IDs from which to delete the node
  - `appendToConnections` — Optional Relay connection IDs to prepend the archived article to
  - `onCompleted` — Optional callback on success
- **`useArchiveArticle()`** — Main exported hook returning `{ archiveArticle, isPending }`

## Usage Example

```typescript
import { useArchiveArticle } from './use-archive-article';

function ArticleActions({ articleId, listConnectionId, archiveConnectionId }) {
  const { archiveArticle, isPending } = useArchiveArticle();

  const handleArchive = async () => {
    await archiveArticle({
      id: articleId,
      removeFromConnections: [listConnectionId],
      appendToConnections: [archiveConnectionId],
      onCompleted: () => console.log('Article archived'),
    });
  };

  return (
    <button onClick={handleArchive} disabled={isPending}>
      Archive
    </button>
  );
}
```

On error, a destructive toast notification is automatically displayed via `useToast`. The hook returns a promise, enabling `async/await` usage at the call site.
