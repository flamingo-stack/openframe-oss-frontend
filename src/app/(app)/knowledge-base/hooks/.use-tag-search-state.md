Manages URL-persisted search and tag filter state for the Knowledge Base feature, encoding selected tags as `id:key` pairs in the `tags` query parameter and debouncing the search input.

## Key Components

### `TagSearchState` interface
Describes the full shape of the returned state object:

| Member | Type | Description |
|---|---|---|
| `search` / `debouncedSearch` | `string` | Immediate and debounced search input values |
| `setSearch` | `(value: string) => void` | Updates the search input |
| `selectedTags` | `SelectedKnowledgeBaseTag[]` | Decoded tag objects from URL |
| `tagIds` | `string[]` | Plain array of selected tag IDs |
| `tagSearchOptions` | `TagSearchOption<string>[]` | Tag options shaped for the UI search component |
| `addTag` / `removeTag` / `setTags` / `clearAll` | functions | Tag mutation handlers |

### `encodeTag` / `decodeTag` (internal)
Serializes tags as `<id>:<key>` strings for URL storage. Splits on the **first** colon only, so keys containing colons are handled safely.

### `useTagSearchState()`
The primary export. Wires together:
- `useApiParams` — syncs `search` and `tags` to URL params
- `useSearchParam` — provides a 300 ms debounced search with lag-free local input state
- Memoized derivations (`selectedTags`, `tagIds`, `tagSearchOptions`) to avoid unnecessary re-renders
- Stable `useCallback` handlers for all tag mutations

## Usage Example

```typescript
import { useTagSearchState } from './use-tag-search-state';

function KnowledgeBaseFilters() {
  const {
    search,
    setSearch,
    debouncedSearch,
    selectedTags,
    addTag,
    removeTag,
    clearAll,
  } = useTagSearchState();

  return (
    <div>
      <input value={search} onChange={e => setSearch(e.target.value)} />
      {selectedTags.map(tag => (
        <button key={tag.id} onClick={() => removeTag(tag.id)}>
          {tag.key} ✕
        </button>
      ))}
      <button onClick={clearAll}>Clear all</button>
    </div>
  );
}
```

> The filter state survives page refresh and browser back/forward navigation because both `search` and `tags` are encoded in the URL.
