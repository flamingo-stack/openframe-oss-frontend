Provides a React hook for removing a tag from a knowledge base item via a GraphQL mutation, with built-in error toast notifications.

## Key Components

- **`removeTagMutation`** — GraphQL mutation (`removeTagFromKnowledgeBaseItem`) that accepts `itemId` and `tagId`, returning the updated item's tag list (`id`, `key`, `color`).
- **`useRemoveTag()`** — Custom hook exposing:
  - `removeTag(itemId, tagId)` — Returns a `Promise<void>` that commits the mutation and displays a destructive toast on failure.
  - `isPending` — Boolean reflecting Relay's in-flight mutation state.

## Usage Example

```typescript
import { useRemoveTag } from './use-remove-tag';

function TagBadge({ itemId, tagId }: { itemId: string; tagId: string }) {
  const { removeTag, isPending } = useRemoveTag();

  const handleRemove = async () => {
    await removeTag(itemId, tagId);
  };

  return (
    <button onClick={handleRemove} disabled={isPending}>
      Remove Tag
    </button>
  );
}
```

## Notes

- Uses Relay's `useMutation` with a generated type (`useRemoveTagMutation.graphql`) for full type safety.
- Error handling is self-contained — consumers receive a rejected promise and the user sees a toast automatically.
- The `removeTag` callback is memoized via `useCallback` to prevent unnecessary re-renders.
