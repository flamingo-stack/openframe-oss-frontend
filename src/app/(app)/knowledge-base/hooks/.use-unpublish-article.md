A React hook that unpublishes an article via a GraphQL mutation, providing loading state and error toast notifications on failure.

## Key Components

- **`unpublishArticleMutation`** — Relay GraphQL mutation that calls `unpublishArticle(id)` and returns the updated `id`, `status`, `publishedAt`, and `updatedAt` fields.
- **`useUnpublishArticle()`** — Custom hook exposing an `unpublishArticle(id)` function and an `isPending` boolean reflecting in-flight mutation state.

## Usage Example

```typescript
import { useUnpublishArticle } from './use-unpublish-article';

function ArticleActions({ articleId }: { articleId: string }) {
  const { unpublishArticle, isPending } = useUnpublishArticle();

  const handleUnpublish = async () => {
    try {
      await unpublishArticle(articleId);
      // Handle success (e.g. navigate away, refresh list)
    } catch {
      // Error is already surfaced via toast
    }
  };

  return (
    <button onClick={handleUnpublish} disabled={isPending}>
      {isPending ? 'Unpublishing...' : 'Unpublish'}
    </button>
  );
}
```

## Behaviour Notes

| Scenario | Behaviour |
|---|---|
| Mutation succeeds | Returned promise resolves with `void` |
| Mutation fails | Destructive toast is shown; promise rejects with the error |
| Mutation in-flight | `isPending` is `true`; can be used to disable UI controls |
