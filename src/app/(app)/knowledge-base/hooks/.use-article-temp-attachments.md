Manages temporary file attachments for knowledge base articles, handling upload, removal, and lifecycle state for both new (temp) and existing attachments via Relay GraphQL mutations.

## Key Components

### Types

- **`TempFileStatus`** — Union type: `'uploading' | 'uploaded' | 'error' | 'existing'`
- **`TempFileEntry`** — Shape of a tracked file entry (`id`, `fileName`, `fileSize`, `contentType`, `status`, optional `error`)

### GraphQL Mutations

| Mutation | Operation |
|---|---|
| `createTempAttachmentMutation` | Creates a temp attachment and returns a pre-signed S3 upload URL |
| `deleteTempAttachmentMutation` | Deletes an in-progress temp attachment |
| `deleteAttachmentMutation` | Deletes a persisted knowledge base attachment |

### `useArticleTempAttachments()` Hook

Returns:

| Return Value | Description |
|---|---|
| `files` | Array of `TempFileEntry` tracking all current attachments |
| `uploadFile(file)` | Initiates upload; adds an optimistic placeholder, replaces with real ID on success |
| `removeFile(id)` | Removes a file; defers deletion for `existing` attachments until `deleteRemovedAttachments()` |
| `initializeExisting(attachments)` | Seeds the file list with pre-existing attachments (idempotent) |
| `deleteRemovedAttachments()` | Executes deferred deletes for removed existing attachments |
| `getTempAttachmentIds()` | Returns IDs of successfully uploaded (non-pending) temp attachments for form submission |
| `isUploading` | `true` if any file is currently uploading |
| `hasPendingDeletes` | `true` if deferred deletions are queued |
| `reset()` | Clears all file and pending-delete state |

## Usage Example

```typescript
const {
  files,
  uploadFile,
  removeFile,
  initializeExisting,
  getTempAttachmentIds,
  deleteRemovedAttachments,
  isUploading,
  reset,
} = useArticleTempAttachments();

// Seed existing attachments when editing an article
useEffect(() => {
  if (article?.attachments) initializeExisting(article.attachments);
}, [article]);

// Upload on file input change
const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  for (const file of e.target.files ?? []) uploadFile(file);
};

// On form submit: flush deferred deletes then submit temp IDs
const handleSubmit = async () => {
  await deleteRemovedAttachments();
  const tempIds = getTempAttachmentIds();
  await saveArticle({ tempAttachmentIds: tempIds });
};
```
