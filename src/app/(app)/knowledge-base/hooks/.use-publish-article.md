A React hook that publishes a knowledge base article via a GraphQL mutation, with built-in loading state and error toast notifications.

## Key Components

- **`publishArticleMutation`** — Relay GraphQL mutation that calls `publishArticle(id)` and returns the updated `id`, `status`, `publishedAt`, and `updatedAt` fields.
- **`usePublishArticle()`** — Hook exposing:
  - `publishArticle(id: string): Promise<void>` — triggers the mutation and returns a promise that resolves on success or rejects (with a destructive toast) on error.
  - `isPending: boolean` — `true` while the mutation is in-flight.

## Usage Example

```typescript
import { usePublishArticle } from '@/hooks/use-publish-article';

function ArticleActions({ articleId }: { articleId: string }) {
  const { publishArticle, isPending } = usePublishArticle();

  const handlePublish = async () => {
    await publishArticle(articleId);
    // Article is now published
  };

  return (
    <button onClick={handlePublish} disabled={isPending}>
      {isPending ? 'Publishing...' : 'Publish'}
    </button>
  );
}
```

## Notes

- Errors are surfaced automatically as a `destructive` toast — consumers do not need to handle UI feedback manually, though they may still `catch` the rejection for additional logic.
- The returned promise allows callers to chain post-publish actions (e.g. navigation, cache invalidation) in a straightforward `async/await` pattern.
