A React hook that executes a GraphQL mutation to unarchive a knowledge base article, handling Relay store updates and connection management.

## Key Components

### `useUnarchiveArticleMutation` (GraphQL)
Mutation that calls `unarchiveArticle(id, parentId)` and returns the updated article's `id`, `status`, `parentId`, and `updatedAt`.

### `UnarchiveArticleArgs`
| Field | Type | Description |
|---|---|---|
| `id` | `string` | Article ID to unarchive |
| `parentId` | `string \| null` | Parent node ID |
| `removeFromConnections` | `string[]` | Relay connection IDs to remove the article from |
| `appendToConnections` | `string[]` (optional) | Relay connection IDs to append the restored article to |
| `onCompleted` | `() => void` (optional) | Callback on success |

### `useUnarchiveArticle()`
Returns `{ unarchiveArticle, isPending }` where `unarchiveArticle` is a promise-returning function and `isPending` reflects the in-flight mutation state.

## Usage Example

```typescript
const { unarchiveArticle, isPending } = useUnarchiveArticle();

await unarchiveArticle({
  id: 'article-123',
  parentId: 'folder-456',
  removeFromConnections: [archivedConnectionId],
  appendToConnections: [activeConnectionId],
  onCompleted: () => console.log('Article restored'),
});
```

## Notes

- Relay store `updater` removes the node from `removeFromConnections` via `ConnectionHandler.deleteNode`, then appends a new `KnowledgeBaseItemEdge` to each `appendToConnections` entry using `ConnectionHandler.insertEdgeAfter`.
- On error, a destructive toast notification is displayed and the promise rejects with the original error.
