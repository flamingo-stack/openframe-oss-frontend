Custom React hook that executes a GraphQL mutation to update an existing knowledge base article, with built-in loading state and error toast notifications.

## Key Components

- **`updateArticleMutation`** — Relay GraphQL mutation that updates an article's `name`, `parentId`, `content`, `summary`, and `updatedAt` fields by ID
- **`UpdateArticleArgs`** — Interface accepting an `UpdateArticleInput` payload and optional `onCompleted` callback
- **`useUpdateArticle()`** — Hook exposing:
  - `updateArticle({ input, onCompleted })` — Returns a `Promise<void>` that resolves on success or rejects with the mutation error
  - `isPending` — Boolean reflecting Relay's in-flight mutation state

## Usage Example

```typescript
import { useUpdateArticle } from '@/hooks/use-update-article';

function EditArticleForm({ articleId }: { articleId: string }) {
  const { updateArticle, isPending } = useUpdateArticle();

  const handleSubmit = async (formData: UpdateArticleInput) => {
    await updateArticle({
      input: { id: articleId, ...formData },
      onCompleted: () => console.log('Article saved'),
    });
  };

  return (
    <button onClick={() => handleSubmit({ name: 'Updated Title', content: '...' })} disabled={isPending}>
      {isPending ? 'Saving...' : 'Save'}
    </button>
  );
}
```

## Notes

- Errors surface as a destructive toast via `useToast` from `@flamingo-stack/openframe-frontend-core` — no additional error handling required at the call site
- The `updateArticle` function is memoized with `useCallback`, preventing unnecessary re-renders when passed as a prop
- Generated types are sourced from `@/__generated__/useUpdateArticleMutation.graphql`, keeping the mutation signature type-safe end-to-end
