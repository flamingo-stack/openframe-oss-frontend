Fetches a single knowledge base item by ID using a Relay lazy-load query, returning the full item record including metadata, author, tags, and attachments.

## Key Components

- **`knowledgeBaseItemQuery`** — GraphQL query fragment that retrieves a complete knowledge base item by `id`, including fields for content, status, publishing info, author profile, tags, and file attachments.
- **`KnowledgeBaseItemNode`** — Exported TypeScript type derived from the generated query response, representing a non-nullable knowledge base item node.
- **`useKnowledgeBaseItem(id)`** — React hook that executes the query via `useLazyLoadQuery` with a `store-and-network` fetch policy, returning the resolved item or `null`.

## Usage Example

```typescript
import { useKnowledgeBaseItem } from '@/hooks/use-knowledge-base-item';

function KnowledgeBaseArticle({ id }: { id: string }) {
  const item = useKnowledgeBaseItem(id);

  if (!item) return <div>Not found</div>;

  return (
    <article>
      <h1>{item.name}</h1>
      <p>{item.summary}</p>
      <div dangerouslySetInnerHTML={{ __html: item.content ?? '' }} />
      <footer>
        By {item.author?.firstName} {item.author?.lastName}
      </footer>
    </article>
  );
}
```

> **Note:** This hook uses `store-and-network`, so it renders immediately from the Relay store cache while simultaneously fetching fresh data from the network. The component must be wrapped in a Relay `<Suspense>` boundary.
