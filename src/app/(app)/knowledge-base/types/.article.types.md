Defines the Zod validation schema and TypeScript types for article form data used across the article creation and editing workflows.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `articleFormSchema` | `ZodObject` | Zod schema validating article form fields with constraints |
| `ArticleFormData` | `type` | Inferred TypeScript type from `articleFormSchema` |
| `ARTICLE_FORM_DEFAULTS` | `ArticleFormData` | Default values for initializing a blank article form |

### Schema Field Constraints

| Field | Validation |
|-------|-----------|
| `title` | Required string, 1–255 characters |
| `folderId` | Nullable string |
| `tags` | String array, max 20 items |
| `body` | String, max 50,000 characters |
| `assignments` | Delegated to `assignmentsSchema` |

## Usage Example

```typescript
import { articleFormSchema, ArticleFormData, ARTICLE_FORM_DEFAULTS } from './article.types';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';

const form = useForm<ArticleFormData>({
  resolver: zodResolver(articleFormSchema),
  defaultValues: ARTICLE_FORM_DEFAULTS,
});

// Validate manually
const result = articleFormSchema.safeParse({
  title: 'Getting Started with OpenFrame',
  folderId: 'folder-123',
  tags: ['onboarding', 'ai'],
  body: 'This guide covers...',
  assignments: [],
});
```
