A Next.js client-side page component that renders the article creation form, extracting an optional `folderId` query parameter to pre-select a folder on load.

## Key Components

- **`NewArticlePageWrapper`** — Default export; reads `folderId` from the URL search params and passes it to `ArticleFormPage` with `articleId={null}` to indicate a new (unsaved) article.

## Usage Example

```typescript
// Navigating to this page with a pre-selected folder:
// /articles/new?folderId=abc123

// The component reads the param and passes it down:
<ArticleFormPage articleId={null} initialFolderId="abc123" />

// Without a folderId param, initialFolderId is null:
// /articles/new
<ArticleFormPage articleId={null} initialFolderId={null} />
```

## Notes

- Marked `'use client'` since it uses `useSearchParams`, which requires a browser context.
- `articleId={null}` signals to `ArticleFormPage` that this is a **create** flow rather than an **edit** flow.
- `folderId` is optional — if absent from the URL, `initialFolderId` is `null`.
