Renders the archived Knowledge Base articles page, providing tag-based and text-based search filtering over a table of archived articles within a sticky toolbar layout.

## Key Components

- **`ArchivePage`** — Default export; the main page component for browsing archived Knowledge Base articles
- **`TagSearchInput`** — Search input with tag chip support for filtering archived articles
- **`KnowledgeBaseTagsRow`** — Horizontal row of selectable Knowledge Base tags, scoped to archived content (`archived` prop)
- **`ArchivedArticlesTable`** — Table component rendering archived articles, driven by debounced search and selected tag IDs
- **`useTagSearchState`** — Hook managing search text, debounced search, and tag selection state
- **`useSafeBack`** — Hook providing safe back navigation, defaulting to `routes.knowledgeBase.list`
- **`useStickyToolbar`** — Hook returning refs and styles for a sticky toolbar with offset tracking

## Usage Example

```typescript
// Rendered automatically via Next.js App Router at the archive route.
// No props required — all state is managed internally.

// The page handles three filtering concerns:
// 1. Free-text search (debounced)
// 2. Tag-based filtering via KnowledgeBaseTagsRow
// 3. Combined empty state message based on active filters

const hasFilters = search.length > 0 || tagIds.length > 0;
```

## Notes

- The toolbar (search input + tags row) is **sticky** and offset-aware via `useStickyToolbar`, preventing overlap with fixed headers
- Tag filtering uses `parentId={null}` in `KnowledgeBaseTagsRow`, scoping to top-level tags only
- Back navigation falls back to [`routes.knowledgeBase.list`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/routes.ts) if no browser history is available
