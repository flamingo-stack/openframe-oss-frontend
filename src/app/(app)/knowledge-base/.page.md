A Next.js page component that renders the root-level Knowledge Base view with no folder context.

## Key Components

- **`KnowledgeBasePage`** — Default page export that mounts `KnowledgeBaseView` at the top-level (no folder selected).

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to /knowledge-base
// No manual usage required — this is a route entry point.

// To render a folder-specific view, use KnowledgeBaseView directly:
import { KnowledgeBaseView } from './components/knowledge-base-view';

<KnowledgeBaseView folderId="folder-123" />
```

## Notes

- Marked as a Client Component via `'use client'`.
- Passes `folderId={null}` to `KnowledgeBaseView`, indicating the root folder context.
- Folder-scoped views are handled by a sibling dynamic route that passes a non-null `folderId`.
