Renders the knowledge base items list view with context-aware row actions (edit, move, archive, unarchive) and provides a dedicated `ArchivedArticlesTable` component backed by Relay pagination for browsing archived articles.

## Key Components

| Export | Type | Description |
|---|---|---|
| `KnowledgeBaseItemsListView` | Component | Unified list view supporting `standard` and `archive` modes with row-level action menus |
| `ArchivedArticlesTable` | Component | Suspense-wrapped archived articles table with Relay-driven search, tag filtering, and infinite scroll |
| `KnowledgeBaseTableSkeleton` | Component | Animated pulse skeleton shown as the Suspense fallback |
| `readKnowledgeBaseItems` | Function | Utility that maps Relay edges to `ItemNode[]` via `readInlineData` |
| `KNOWLEDGE_BASE_PAGE_SIZE` | Constant | Default page size (`20`) used for all paginated queries |
| `ItemNode` | Type | Inferred row data shape from the `knowledgeBaseTableRow_node` Relay fragment |
| `ListViewProps` | Type | Discriminated union (`standard` \| `archive`) driving connection ID and modal availability |

## Usage Example

```typescript
// Standard mode — inside a folder/article tree view
<KnowledgeBaseItemsListView
  mode="standard"
  items={items}
  filteredCount={100}
  hasNext={true}
  isLoadingNext={false}
  onLoadMore={loadMore}
  emptyMessage="No articles found."
  foldersConnectionId="client:root:knowledgeBase_folders"
  articlesConnectionId="client:root:knowledgeBase_articles"
/>

// Archive mode — standalone archived articles tab
<ArchivedArticlesTable
  search={searchQuery}
  tagIds={selectedTagIds}
  emptyMessage="No archived articles."
  stickyHeaderOffset="56px"
/>
```

## Notes

- Row actions are mode-gated: archive mode exposes only **Unarchive**; standard mode exposes **Edit**, **Move to folder**, and **Archive** for articles, and folder-specific actions via `useFolderRowActions`.
- The `data-no-row-click` attribute on the actions cell prevents row navigation from triggering when the dropdown is clicked.
- Relay fragments use `@inline` for synchronous reads and `@connection` for automatic pagination store merging.
