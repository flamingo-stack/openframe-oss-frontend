A React hook that manages folder row action menus (rename, move, delete) and their associated modals for folder-level operations in the OpenFrame file browser.

## Key Components

### `FolderActionTarget`
Interface representing the minimal folder data required for actions:
- `id` — unique folder identifier
- `name` — display name

### `useFolderRowActions(args)`
Custom hook that wires together action menu definitions and modal state.

**Args:**
- `sourceConnectionId` — the connection context for move/delete operations
- `onDeleted?` — optional callback fired after successful deletion

**Returns** `FolderRowActions`:
- `buildMenuGroups(folder)` — returns an `ActionsMenuGroup[]` with Rename, Move folder, and Delete items; each item opens the corresponding modal via local state
- `modals` — a `ReactNode` fragment containing `RenameFolderModal`, `MoveToFolderModal`, and `DeleteFolderModal` pre-wired to their open/close state

## Usage Example

```typescript
import { useFolderRowActions } from './folder-row-actions';

function FolderTable({ connectionId }: { connectionId: string }) {
  const { buildMenuGroups, modals } = useFolderRowActions({
    sourceConnectionId: connectionId,
    onDeleted: () => refetchFolders(),
  });

  return (
    <>
      {folders.map((folder) => (
        <FolderRow
          key={folder.id}
          folder={folder}
          menuGroups={buildMenuGroups(folder)}
        />
      ))}
      {/* Render all modals once at the table level */}
      {modals}
    </>
  );
}
```
