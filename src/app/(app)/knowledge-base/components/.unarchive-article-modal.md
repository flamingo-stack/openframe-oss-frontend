Modal component for restoring archived knowledge base articles to a selected folder destination.

## Key Components

- **`UnarchiveArticleModal`** — Main modal component that orchestrates the unarchive flow, managing folder selection state and triggering the unarchive mutation with connection ID updates
- **`FolderPicker`** — Internal dropdown component that renders a hierarchical folder tree using `ActionsMenuDropdown`, allowing the user to select a destination folder (including the KB root)
- **`FolderPickerSkeleton`** — Pulse-animated placeholder rendered during folder data loading via `Suspense`
- **`UnarchiveArticleTarget`** — Exported interface describing the minimal article shape (`id`, `name`) required by the modal

## Usage Example

```typescript
import { UnarchiveArticleModal } from './unarchive-article-modal';

function ArchivedArticlesPanel() {
  const [target, setTarget] = useState<UnarchiveArticleTarget | null>(null);

  return (
    <UnarchiveArticleModal
      isOpen={!!target}
      onClose={() => setTarget(null)}
      article={target}
      sourceConnectionId="conn_archived_xyz"
    />
  );
}
```

## Behavior Notes

- Resets folder selection (`selected`) whenever the modal closes via a `useEffect` on `isOpen`
- Resolves `targetConnectionId` using `getKnowledgeBaseArticlesConnectionId` when a non-root folder is selected; passes `null` for root placement
- On success, fires a `success` toast and calls `onClose`; errors are silently swallowed
- The **Unarchive** button is disabled until both `article` and `selected` are non-null, and shows a `"Restoring..."` label while `isPending`
