Modal component for creating a new folder within a storage connection, handling name input, validation, submission, and success/error feedback.

## Key Components

- **`NewFolderModal`** — Primary export; a controlled modal component wrapping `SimpleModal` with a folder name input and create/cancel actions.
- **`NewFolderModalProps`** — Interface defining required props: `isOpen`, `onClose`, `parentConnectionId`, and optional `parentFolderId`, `onCreated` callback.
- **`useCreateFolder`** — Custom hook providing the `createFolder` async function and `isPending` loading state.
- **State: `name`** — Controlled input state, reset to empty string whenever the modal closes.
- **`canSubmit`** — Derived boolean; `true` only when the trimmed name is non-empty and no request is in flight.
- **`handleKeyDown`** — Allows `Enter` key to trigger submission when `canSubmit` is `true`.

## Usage Example

```typescript
import { NewFolderModal } from './new-folder-modal';

function FileExplorer({ connectionId }: { connectionId: string }) {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsOpen(true)}>New Folder</button>
      <NewFolderModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        parentConnectionId={connectionId}
        parentFolderId="folder-abc-123"
        onCreated={(folderId) => {
          console.log('Created folder:', folderId);
        }}
      />
    </>
  );
}
```

**Behavior notes:**
- Input is auto-focused on open and cleared on close.
- Success triggers a toast notification and calls `onCreated` with the new folder's ID before closing.
- The Create button shows a loading state during the async operation.
