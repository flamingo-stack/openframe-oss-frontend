Modal component for moving knowledge base items (folders or articles) to a different folder, featuring a folder picker dropdown and optimistic connection management.

## Key Components

| Export | Type | Description |
|---|---|---|
| `MoveToFolderModal` | Component | Main modal wrapping folder selection and move confirmation |
| `MoveToFolderItem` | Interface | Shape of the item being moved (`id`, `name`, `type`) |
| `FolderPicker` | Component (internal) | Dropdown built from the folder tree, excludes the item being moved |
| `FolderPickerSkeleton` | Component (internal) | Pulse skeleton shown while folder data suspends |

## Props

### `MoveToFolderModalProps`

| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Called on cancel or successful move |
| `item` | `MoveToFolderItem \| null` | The folder or article being moved |
| `sourceConnectionId` | `string` | Connection ID to remove the item from after moving |

## Usage Example

```typescript
import { MoveToFolderModal } from './move-to-folder-modal';
import { getKnowledgeBaseArticlesConnectionId } from '../hooks/use-knowledge-base-items';

const sourceConnectionId = getKnowledgeBaseArticlesConnectionId({
  parentId: 'folder-123',
  search: null,
  tagIds: [],
});

<MoveToFolderModal
  isOpen={isModalOpen}
  onClose={() => setIsModalOpen(false)}
  item={{ id: 'article-456', name: 'My Article', type: 'article' }}
  sourceConnectionId={sourceConnectionId}
/>
```

## Behavior Notes

- **Self-exclusion:** When moving a folder, its own ID is passed as `excludeFolderId` to prevent moving a folder into itself.
- **Connection management:** On confirm, the item is appended to the target connection and removed from the source connection via `useMoveToFolder`.
- **State reset:** Selected folder is cleared whenever the modal closes.
- **Suspense boundary:** `FolderPicker` is wrapped in `<Suspense>` so async folder loading shows the skeleton instead of blocking render.
