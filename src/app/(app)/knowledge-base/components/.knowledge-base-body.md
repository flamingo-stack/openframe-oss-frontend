Main body component for the Knowledge Base page, orchestrating folder/article listing, tag-based filtering, search, pagination, and navigation within a hierarchical knowledge base structure using React Relay.

## Key Components

### Exported Component
- **`KnowledgeBaseBody`** — Root entry point accepting a `parentId` prop; resolves the current folder context, wires up navigation, and renders the `KnowledgeBaseBodyShell`.

### Internal Components
- **`KnowledgeBaseBodyShell`** — Layout wrapper rendering the `PageLayout` with page title, back button, tag search, filter modal, and folder/article content areas.
- **`FoldersAndArticlesContent`** — Fetches and renders separate paginated Relay queries for folders (`type: FOLDER`) and articles (`type: ARTICLE`) side-by-side.
- **`SubtreeArticlesContent`** — Fetches articles across an entire folder subtree when both `parentId` and `tagIds` are present (uses a dedicated Relay cache key to prevent connection leakage).

### Relay GraphQL Operations
| Operation | Purpose |
|---|---|
| `knowledgeBaseBodyFoldersRelayQuery` | Non-paginated folder fetch (capped at `FOLDERS_PAGE_SIZE = 100`) |
| `knowledgeBaseBodyArticlesRelayQuery` | Paginated article fetch with cursor support |
| `knowledgeBaseBodySubtreeRelayQuery` | Paginated subtree article fetch (tag + folder combined) |

### Key Helpers
- **`buildActions`** — Constructs page action buttons (Archive, New Folder, Add Article); accents the Add Article CTA when the list is empty.
- **`useTagSearchState`** — Manages tag filter and search state.
- **`useStickyToolbar`** — Provides sticky header offset for the list view.
- **`useFolderRowActions`** — Provides row-level folder actions (rename, delete).

## Usage Example

```typescript
// Render the root knowledge base (no parent folder)
<KnowledgeBaseBody parentId={null} />

// Render a subfolder view
<KnowledgeBaseBody parentId="folder-abc-123" />
```

The component uses Next.js `notFound()` if a non-root `parentId` resolves to no matching folder. Navigation back up the folder tree uses `useSafeBack` combined with the parent folder's `parentId`.
