Renders the route-level loading skeleton for the `/knowledge-base` page, mirroring the full page chrome (header, actions, search bar, tags row, and table) without issuing any network requests.

## Key Components

- **`KnowledgeBasePageSkeleton`** — Primary export; a static skeleton component safe to render before session confirmation, using disabled action buttons and skeleton sub-components in place of live data.
- **`ACTIONS`** — Pre-defined disabled `PageActionButton` entries for Archive, New Folder, and Add Article, matching the real page's action bar.
- **`ICON_CLASS`** — Shared Tailwind class string for consistent icon sizing and color across action buttons.

## Usage Example

```typescript
// app/knowledge-base/loading.tsx (Next.js route-level loading UI)
import { KnowledgeBasePageSkeleton } from './knowledge-base-page-skeleton';

export default function Loading() {
  return <KnowledgeBasePageSkeleton />;
}
```

## Notes

- Intentionally **does not mount any Relay queries** — safe to render in the app shell before authentication is confirmed.
- Composes [`SearchBarSkeleton`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/components/shared), [`SelectableTagsRowSkeleton`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/components/shared), and [`KnowledgeBaseTableSkeleton`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/knowledge-base/knowledge-base-table) to faithfully replicate the loaded page layout.
- Marked `'use client'` to support React icon components rendered inline within the `ACTIONS` array.
