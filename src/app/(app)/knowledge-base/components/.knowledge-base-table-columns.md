Defines column definitions and the table body component for the Knowledge Base data table, supporting both standard and archive display modes.

## Key Components

- **`KnowledgeBaseRow`** — Interface describing a row item (article or folder) with fields for id, type, name, status, summary, timestamps, and tags
- **`KnowledgeBaseTableMode`** — Union type `'standard' | 'archive'` controlling column header labels and timestamp field selection
- **`knowledgeBaseRowHref`** — Helper that resolves the correct route for a row based on its type (`ARTICLE` → detail page, otherwise → folder page)
- **`KNOWLEDGE_BASE_OPEN_COLUMN`** — Pre-built column definition rendering an "open in new tab" icon button, hidden at `md` breakpoint
- **`getKnowledgeBaseColumns`** — Returns the base column definitions (name with icon/status tag + date) based on the current mode
- **`KnowledgeBaseTableBody`** — Fully composed table component using `useDataTable` and `DataTable` from the core UI library

## Usage Example

```typescript
import {
  KnowledgeBaseTableBody,
  type KnowledgeBaseRow,
} from './knowledge-base-table-columns';

const items: KnowledgeBaseRow[] = [
  {
    id: 'article-1',
    type: 'ARTICLE',
    name: 'Getting Started',
    status: 'PUBLISHED',
    summary: 'An intro guide.',
    createdAt: '2024-01-15T10:00:00Z',
  },
  {
    id: 'folder-1',
    type: 'FOLDER',
    name: 'Onboarding',
  },
];

// Standard view
<KnowledgeBaseTableBody items={items} mode="standard" totalCount={42} />

// Archive view with custom actions column
<KnowledgeBaseTableBody
  items={items}
  mode="archive"
  actionsColumn={myActionsColumn}
  isLoading={false}
  emptyMessage="No archived articles."
/>
```
