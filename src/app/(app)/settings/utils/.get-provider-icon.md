Returns the appropriate React icon component for a given SSO provider key, supporting Microsoft, Google, and Slack.

## Key Components

### `getProviderIcon(providerKey, className?)`

A utility function that maps an SSO provider string to its corresponding icon component.

| Parameter | Type | Default | Description |
|---|---|---|---|
| `providerKey` | `string` | — | Provider identifier (case-insensitive) |
| `className` | `string` | `'h-6 w-6 shrink-0'` | Tailwind classes applied to the icon |

**Returns:** `React.ReactElement | null` — the matching icon, or `null` for unsupported providers.

**Supported providers:** `microsoft`, `google`, `slack`

## Usage Example

```typescript
import { getProviderIcon } from './get-provider-icon';

// Default size
const icon = getProviderIcon('microsoft');

// Custom size
const largeIcon = getProviderIcon('google', 'h-8 w-8 shrink-0');

// Unsupported provider returns null
const unknown = getProviderIcon('github'); // null

// Typical usage in a provider list
const providers = ['microsoft', 'google', 'slack'];

return (
  <ul>
    {providers.map((key) => (
      <li key={key}>
        {getProviderIcon(key)}
        <span>{key}</span>
      </li>
    ))}
  </ul>
);
```

## Notes

- Provider key matching is **case-insensitive** (`'Microsoft'` and `'MICROSOFT'` both resolve correctly).
- Returns `null` for unrecognised providers — callers should handle the `null` case to avoid rendering gaps.
- Icons are sourced from `@flamingo-stack/openframe-frontend-core/components/icons`.
