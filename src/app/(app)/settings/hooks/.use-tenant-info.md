React Query hooks for fetching and updating tenant (organization) information via GraphQL, with toast notifications on mutation success or failure.

## Key Components

| Export | Type | Description |
|---|---|---|
| `useTenantInfo` | Hook | Fetches tenant info (`id`, `name`, `website`, `image`) from the GraphQL API |
| `useUpdateTenantInfo` | Hook | Mutation hook to update tenant info; invalidates cache and shows a toast on completion |
| `tenantInfoQueryKeys` | Constant | Centralized React Query cache key object for tenant info queries |
| `TENANT_IMAGE_ENDPOINT` | Constant | REST endpoint for managing the tenant image (`/api/tenants/image`) |

## Usage Example

```typescript
import { useTenantInfo, useUpdateTenantInfo } from './use-tenant-info';

function OrganizationSettings() {
  const { data: tenantInfo, isLoading } = useTenantInfo();
  const { mutate: updateTenant, isPending } = useUpdateTenantInfo();

  const handleSave = () => {
    updateTenant({
      name: 'Acme Corp',
      website: 'https://acme.example.com',
    });
  };

  if (isLoading) return <Spinner />;

  return (
    <div>
      <p>{tenantInfo?.name}</p>
      <button onClick={handleSave} disabled={isPending}>Save</button>
    </div>
  );
}
```

## Notes

- Both query and mutation target `/api/graphql` (not the chat endpoint) so SaaS-only mutations are routed correctly.
- Tenant image uploads are handled separately via the `TENANT_IMAGE_ENDPOINT` REST endpoint, consistent with user avatar management.
- On a successful update, the React Query cache is updated directly via `setQueryData` rather than triggering a refetch.
