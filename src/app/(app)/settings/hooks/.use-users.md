Provides React Query hooks and types for fetching, deleting, and updating users in the OpenFrame frontend, with toast notifications and auth-store integration.

## Key Components

### Types & Enums

| Export | Description |
|---|---|
| `UserStatus` | Enum with `Active` (`ACTIVE`) and `Deleted` (`DELETED`) values |
| `UserRecord` | Full user shape including `id`, `email`, `roles`, `status`, optional `image`, and timestamps |
| `UserImage` | Image URL and blur hash pair |
| `PagedUsersResponse` | Paginated wrapper around `UserRecord[]` with metadata |

### API Functions

| Export | Description |
|---|---|
| `deleteUserApi(userId)` | Raw `DELETE /api/users/{id}` call — exported for reuse by `use-account-deletion` (account self-deletion) |

### Query Keys

`usersQueryKeys` — structured key factory for TanStack Query cache management:
- `.all` — invalidates all user queries
- `.list(page, size)` — scoped to paginated list
- `.detail(id)` — scoped to a single user

### Hooks

| Hook | Description |
|---|---|
| `useUsers(page, size)` | Fetches a paginated user list; returns data, loading/error states, pagination metadata, and `refetch` |
| `useDeleteUser()` | Returns `deleteUser(userId, options?)` with cache invalidation and error toasting |
| `useUpdateProfile()` | Mutation for the authenticated user's `firstName`/`lastName`; syncs auth store on success |

## Usage Example

```typescript
// Paginated user list
const { users, isLoading, totalPages, hasNext } = useUsers(0, 20);

// Delete a user
const { deleteUser } = useDeleteUser();
deleteUser(userId, {
  onSuccess: () => console.log('Deleted'),
  onError: (err) => console.error(err),
});

// Update the authenticated user's profile
const updateProfile = useUpdateProfile();
updateProfile.mutate({ firstName: 'Jane', lastName: 'Doe' });
```

**Source:** [`hooks/use-users.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/(app)/settings/hooks/use-users.ts)
