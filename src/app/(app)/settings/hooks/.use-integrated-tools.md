Fetches integrated tools from the GraphQL API, managing loading state, error handling, and toast notifications.

## Key Components

### Hook

**`useIntegratedTools()`** — React hook that wraps the `GetIntegratedTools` GraphQL query with stateful loading and error management.

Returns:

| Property | Type | Description |
|---|---|---|
| `tools` | `IntegratedTool[]` | Fetched tools array |
| `isLoading` | `boolean` | Request in-flight indicator |
| `error` | `string \| null` | Last error message |
| `fetchIntegratedTools` | `(filter?, search?) => Promise<IntegratedTool[]>` | Trigger function |

### Exported Types

- **`IntegratedTool`** — Core tool entity including `id`, `name`, `enabled`, `layer`, `credentials`, and `toolUrls`
- **`ToolUrl`** — URL entry with optional `port` and `type`
- **`Credentials`** — Auth credentials supporting username/password and `ApiKey`
- **`ApiKey`** — API key with `key`, `type`, and `keyName`

## Usage Example

```typescript
import { useIntegratedTools } from '@/hooks/use-integrated-tools';

function ToolList() {
  const { tools, isLoading, error, fetchIntegratedTools } = useIntegratedTools();

  useEffect(() => {
    // Fetch only enabled tools in the 'monitoring' category
    fetchIntegratedTools({ enabled: true, category: 'monitoring' }, 'grafana');
  }, [fetchIntegratedTools]);

  if (isLoading) return <Spinner />;
  if (error) return <p>{error}</p>;

  return tools.map(tool => <ToolCard key={tool.id} tool={tool} />);
}
```

> **Default filter:** `{ enabled: true, category: null }` — returns all enabled tools when called with no arguments.
