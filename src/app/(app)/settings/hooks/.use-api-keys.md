React hook for managing API key CRUD operations and state, providing methods to fetch, create, update, regenerate, and toggle API keys via the `apiClient`.

## Key Components

### `ApiKeyRecord`
Type representing an API key entity with fields:
- **Identity**: `id`, `name`, `description`
- **Status**: `enabled`, `expiresAt`, `lastUsed`
- **Timestamps**: `createdAt`, `updatedAt`
- **Usage stats**: `totalRequests`, `successfulRequests`, `failedRequests`

### `useApiKeys()`
Hook exposing the following state and actions:

| Export | Type | Description |
|---|---|---|
| `items` | `ApiKeyRecord[]` | Cached list of API keys |
| `isLoading` | `boolean` | Fetch-in-progress indicator |
| `error` | `string \| null` | Last error message |
| `fetchApiKeys` | `() => Promise<ApiKeyRecord[]>` | Load all API keys |
| `createApiKey` | `(data) => Promise<{ apiKey, fullKey }>` | Create and return new key with plaintext secret |
| `updateApiKey` | `(id, data) => Promise<ApiKeyRecord>` | Update name/description/expiry |
| `regenerateApiKey` | `(id) => Promise<{ apiKey, fullKey }>` | Rotate secret, returns new plaintext key |
| `setApiKeyEnabled` | `(id, enabled) => Promise<ApiKeyRecord>` | Toggle enable/disable |

## Usage Example

```typescript
import { useApiKeys } from '@/hooks/use-api-keys';

export function ApiKeyManager() {
  const {
    items,
    isLoading,
    error,
    fetchApiKeys,
    createApiKey,
    setApiKeyEnabled,
  } = useApiKeys();

  useEffect(() => {
    fetchApiKeys();
  }, [fetchApiKeys]);

  const handleCreate = async () => {
    const { apiKey, fullKey } = await createApiKey({
      name: 'My Integration',
      description: 'Used by CI pipeline',
      expiresAt: '2026-01-01T00:00:00Z',
    });
    // Show fullKey once — it won't be retrievable again
    console.log('Save this key:', fullKey);
  };

  const handleToggle = (id: string, enabled: boolean) =>
    setApiKeyEnabled(id, !enabled);
}
```

> **Note:** `createApiKey` and `regenerateApiKey` return a `fullKey` containing the plaintext secret. Display it immediately — it is not stored and cannot be retrieved again.
