Thin alias module that exposes a type-safe URL builder for employee detail pages, delegating to the central route registry in `@/lib/routes`.

## Key Components

| Export | Type | Description |
|---|---|---|
| `employeeDetailHref` | `(id: string) => string` | Returns the URL for a given employee's detail page |

## Usage Example

```typescript
import { employeeDetailHref } from './routes';

// In a table row link
<a href={employeeDetailHref(employee.id)}>View Employee</a>

// In a header profile menu
router.push(employeeDetailHref(currentUserId));
```

## Notes

- Intentionally a thin wrapper — all routing logic lives in [`@/lib/routes`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/routes.ts)
- Shared between the employees table (row links, open-in-new-tab) and the header profile menu to ensure both entry points stay in sync
- Update `routes.settings.employeeDetails` in the central registry to affect all consumers
