A simple Next.js page component that renders the Company and Users management tab for the Employees section.

## Key Components

- **`EmployeesPage`** — Default page export that delegates rendering to the `CompanyAndUsersTab` component.

## Usage Example

```typescript
// Rendered automatically by Next.js routing
// Access via the /employees route
import EmployeesPage from './page';

// Or navigate to it via Next.js Link
import Link from 'next/link';
<Link href="/employees">Employees</Link>
```

## Notes

- Marked as a Client Component via `'use client'` directive.
- Acts as a thin routing wrapper — all logic and UI lives in [`CompanyAndUsersTab`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/employees/components/tabs/company-and-users).
