A thin Next.js page component that renders the SSO (Single Sign-On) configuration interface by delegating entirely to the `SsoConfigurationTab` component.

## Key Components

- **`SsoConfigurationPage`** — Default-exported `'use client'` page component that mounts the SSO configuration tab.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to the SSO configuration route.
// No props required — the page is self-contained.
import SsoConfigurationPage from './page';

// Next.js resolves and renders this as the route's page:
<SsoConfigurationPage />
```

## Notes

- Marked `'use client'` to enable client-side interactivity within the Next.js App Router.
- All UI logic and state live inside [`SsoConfigurationTab`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/(authenticated)/settings/components/tabs/sso-configuration.tsx) — this file is purely a route entry point.
