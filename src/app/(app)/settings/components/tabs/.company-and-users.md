Renders the Company & Users settings tab, displaying a unified data table of active users and pending/expired invitations with inline actions for managing invitation lifecycle.

## Key Components

- **`CompanyAndUsersTab`** — Main exported component. Renders a `PageLayout` containing a `DataTable` of unified user/invitation records with role and status columns.
- **`statusToLabel`** / **`statusToVariant`** — Lookup maps converting `UnifiedUserStatus` values to display labels and `Tag` color variants.
- **`employeeRowHref`** — Row-level navigation helper; routes `User` records to their employee detail page, returns `null` for invitations.

### Column Definitions

| Column | Description |
|---|---|
| `user` | Avatar, display name, and email |
| `roles` | Comma-joined role list |
| `status` | Colored `Tag` badge (`ACTIVE`, `INVITE SENT`, `INVITE EXPIRED`, `DELETED`) |
| `actions` | `MoreActionsMenu` for invitations: **Revoke** (pending) or **Resend / Remove** (expired) |
| `open` | Icon button to open a user's employee detail page in a new tab |

### Modal State

Four controlled modals handle invitation mutations: `ConfirmRevokeInvitationModal`, `ConfirmRemoveInvitationModal`, `ConfirmResendInvitationModal`, and `AddUsersModal`.

## Usage Example

```typescript
// Render as a settings tab — no props required.
import { CompanyAndUsersTab } from './company-and-users';

export default function SettingsPage() {
  return <CompanyAndUsersTab />;
}
```

Data is fetched internally via `useUsersAndInvitations(0, 1000)`. Pagination is not yet implemented; all records are loaded in a single request.
