Renders the tab navigation bar for the Settings page, defining all available settings tabs and filtering them based on the current tenant mode.

## Key Components

| Export | Type | Description |
|---|---|---|
| `SETTINGS_TABS` | `TabItem[]` | Static array of all settings tab definitions (id, label, icon, component) |
| `getSettingsTabs` | `() => TabItem[]` | Returns filtered tabs — hides the `architecture` tab unless OSS tenant mode is active |
| `SettingsTabNavigation` | Component | Renders the `TabNavigation` bar with the filtered tab list |
| `SettingsTabNavigationProps` | Interface | Props: `activeTab: string`, `onTabChange: (tabId: string) => void` |

### Tab Registry

| ID | Label | Component |
|---|---|---|
| `architecture` | Architecture | `ArchitectureTab` *(OSS mode only)* |
| `company-and-users` | Company & Users | `CompanyAndUsersTab` |
| `api-keys` | API Keys | `ApiKeysTab` |
| `sso-configuration` | SSO Configuration | `SsoConfigurationTab` |
| `profile` | Profile | `ProfileTab` |

## Usage Example

```typescript
import { SettingsTabNavigation, getSettingsTabs } from './navigation';

// Render the navigation bar
<SettingsTabNavigation
  activeTab="profile"
  onTabChange={(tabId) => setActiveTab(tabId)}
/>

// Access filtered tabs directly (e.g. for routing)
const tabs = getSettingsTabs();
const defaultTab = tabs[0].id;
```

## Notes

- The `architecture` tab is conditionally included via [`isOssTenantMode()`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/app-mode.ts) — it only appears in self-hosted OSS deployments.
- This is a `'use client'` component; tab state must be managed by the parent.
