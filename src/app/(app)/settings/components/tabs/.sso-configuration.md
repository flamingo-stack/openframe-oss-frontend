Renders the SSO Configuration settings tab, displaying a searchable table of OAuth providers with their status, allowed domains, and configuration state, plus a shared Google & Microsoft SSO auto-provisioning card for tenant domains.

## Key Components

### `SsoConfigurationTab` (default export)
Main page component that orchestrates SSO provider management for a tenant.

**State managed:**
- `providers` — list of `UiProviderRow` objects built from available providers + their fetched configs
- `searchTerm` — filters the provider table by display name or provider key
- `modalState` — controls the `SsoConfigModal` open/close state and pre-fills edit fields
- `tenantDomain` / `isDomainLoading` — drives the shared SSO card visibility and auto-provision toggle

**Hooks consumed:**
- `useSsoConfig` — fetches available providers, per-provider config, and mutation helpers
- `useTenantDomain` — fetches tenant domain info and updates shared auto-provision flag
- `useDataTable` + column definitions — powers the sortable/filterable `DataTable`
- `useSafeBack` — back-button navigation to settings root

**Column definitions (`columns`):**
| Column | Content |
|---|---|
| `OAUTH PROVIDER` | Icon + display name + provider key |
| `STATUS` | `ACTIVE`/`INACTIVE` `Tag` |
| `ALLOWED DOMAINS` | Comma-separated list or `None` |
| `CONFIGURATION` | `Configured` / `Not configured` |
| `actions` | `Edit` button opening `SsoConfigModal` |

## Usage Example

```typescript
// Rendered as a settings tab — no props required
import { SsoConfigurationTab } from './sso-configuration';

export default function SsoSettingsPage() {
  return <SsoConfigurationTab />;
}
```

The shared SSO card renders only when `tenantDomain` is non-null and non-generic:

```typescript
// Toggling auto-provision for a verified domain
// Internally calls updateSharedAutoProvision(enabled) from useTenantDomain,
// then updates tenantDomain.autoAllow in local state and shows a toast.
<CheckboxWithDescription
  id="shared-auto-provision"
  checked={tenantDomain.autoAllow}
  onCheckedChange={handleAutoProvisionToggle}
  disabled={tenantDomain.generic || isAutoProvisionUpdating}
  title={`Auto-provision accounts from ${tenantDomain.domain}`}
/>
```
