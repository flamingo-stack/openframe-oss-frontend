Renders the content panel for the active settings tab, dynamically resolving and displaying the correct tab component or a fallback "not found" state.

## Key Components

- **`SettingsTabContent`** — Client component that accepts an `activeTab` string, looks up the matching component from `SETTINGS_TABS` via `getTabComponent`, and renders it. Displays a centered error message if the tab cannot be resolved.

## Usage Example

```typescript
import { SettingsTabContent } from './settings-tab-content';

// Render the content for whichever tab is currently active
<SettingsTabContent activeTab="general" />
```

## Notes

- Uses `getTabComponent` from `@flamingo-stack/openframe-frontend-core` to resolve the tab-to-component mapping defined in [`SETTINGS_TABS`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/settings/tabs.ts).
- Marked as a Client Component (`'use client'`) since it depends on dynamic tab resolution at runtime.
- The wrapping `div` enforces a `min-h-[400px]` to prevent layout shift when switching between tabs.
