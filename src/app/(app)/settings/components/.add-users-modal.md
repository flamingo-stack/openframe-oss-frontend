A modal component for inviting multiple users to the system by entering email addresses and assigning roles, with dynamic row management and form validation.

## Key Components

### `AddUsersModal`
The primary exported component that renders a `SimpleModal` containing a dynamic list of email/role input rows.

**Props (`AddUsersModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback when modal is dismissed |
| `onInvited` | `() => Promise<void> \| void` | Optional callback fired after successful invite |
| `invite` | `(rows: InviteRow[]) => Promise<void>` | Async function that handles the actual invite API call |

### `InviteRow`
Internal type representing a single invite entry: `{ email: string; role: string }`.

## Key Behaviors

- **Dynamic rows** — Users can add or remove email/role pairs; at least one row is always present
- **Validation** — Submit is disabled until at least one row contains a valid email; invalid emails show inline error state
- **Reset on close** — Rows and submitting state reset whenever `isOpen` becomes `false`
- **Role options** — Currently supports `ADMIN` only; role list is `useMemo`-memoized for easy extension
- **Toast feedback** — Displays success or destructive toast on invite completion or failure

## Usage Example

```typescript
import { AddUsersModal } from '@/app/components/shared/add-users-modal';

function TeamPage() {
  const [isOpen, setIsOpen] = useState(false);

  const handleInvite = async (rows) => {
    await api.inviteUsers(rows); // rows: { email: string; role: string }[]
  };

  return (
    <AddUsersModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      invite={handleInvite}
      onInvited={() => refetchTeamMembers()}
    />
  );
}
```
