A one-time-display modal component that presents a newly created API key to the user, with clipboard copy functionality and a security warning.

## Key Components

**`ApiKeyCreatedModal`** — Named export; renders a `SimpleModal` that displays the full API key immediately after creation.

| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `fullKey` | `string \| null` | The complete API key to display |
| `onClose` | `() => void` | Callback fired when the user dismisses the modal |

**Internal behaviour:**
- Uses `useCopyToClipboard` hook to handle clipboard interaction, toggling a `CheckIcon`/`Copy02Icon` to confirm success.
- Stores the key in local state (`localKey`) and clears it when the modal closes, preventing stale key exposure.
- Returns `null` if no key is available, avoiding an empty modal render.

## Usage Example

```typescript
import { ApiKeyCreatedModal } from '@/app/components/api-keys/api-key-created-modal';

function ApiKeysPage() {
  const [createdKey, setCreatedKey] = useState<string | null>(null);

  const handleCreate = async () => {
    const { fullKey } = await createApiKey();
    setCreatedKey(fullKey);
  };

  return (
    <>
      <Button onClick={handleCreate}>Create API Key</Button>
      <ApiKeyCreatedModal
        isOpen={!!createdKey}
        fullKey={createdKey}
        onClose={() => setCreatedKey(null)}
      />
    </>
  );
}
```

> **Security note:** The modal intentionally displays the key only once — the warning `Alert` reinforces that the full key is not retrievable after this modal is closed. Ensure `fullKey` is cleared from parent state on `onClose`.
