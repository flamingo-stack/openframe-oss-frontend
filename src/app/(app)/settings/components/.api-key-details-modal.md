Read-only modal component that displays detailed information and usage statistics for a single API key record.

## Key Components

**`ApiKeyDetailsModal`** — Default export React component accepting:

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback to close the modal |
| `apiKey` | `ApiKeyRecord \| null` | The API key record to display; renders `null` if not provided |

**Layout sections:**

- **Header row** — Key name, description, and an `ACTIVE`/`INACTIVE` status tag
- **Two-column grid** — Read-only fields for Key ID, Created, Expires, Total Requests, Successful Requests, and Failed Requests
- **Full-width row** — Last Used timestamp spanning both columns

All date fields are formatted via `formatDateTime`; `null`/`undefined` dates render as `—`.

## Usage Example

```typescript
import { ApiKeyDetailsModal } from './api-key-details-modal';
import { useApiKeys } from './hooks/use-api-keys';

export function ApiKeysPage() {
  const { apiKeys } = useApiKeys();
  const [selectedKey, setSelectedKey] = useState<ApiKeyRecord | null>(null);

  return (
    <>
      {apiKeys.map((key) => (
        <button key={key.id} onClick={() => setSelectedKey(key)}>
          {key.name}
        </button>
      ))}

      <ApiKeyDetailsModal
        isOpen={selectedKey !== null}
        onClose={() => setSelectedKey(null)}
        apiKey={selectedKey}
      />
    </>
  );
}
```

## Notes

- Renders `null` early if `apiKey` is not provided — safe to mount unconditionally
- All inputs are `disabled` — this is a view-only modal with no editing capability
