A reusable header component for settings sub-pages that renders a back-navigation button linking to the settings root and a page title.

## Key Components

- **`SettingsSubPageHeader`** — Client component that accepts a `title` prop and renders a back arrow `Link` (via `routes.settings.root()`) alongside an `h1` heading.
- **`SettingsSubPageHeaderProps`** — Interface requiring a single `title: string` prop.

## Usage Example

```typescript
import { SettingsSubPageHeader } from '@/components/settings-sub-page-header';

export default function NotificationsSettingsPage() {
  return (
    <div>
      <SettingsSubPageHeader title="Notifications" />
      {/* page content */}
    </div>
  );
}
```

## Notes

- Marked `'use client'` — must be used within the Next.js App Router client boundary.
- The back button navigates to `routes.settings.root()`, keeping navigation logic centralised in the routes config.
- Styling uses ODS (OpenFrame Design System) tokens (`ods-card`, `ods-border`, `ods-text-*`) for consistent theming.
