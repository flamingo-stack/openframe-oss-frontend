A React client component that renders a biometric authentication toggle (Face ID / Touch ID / Fingerprint) for native mobile shells. Returns `null` on web/desktop or when the device lacks biometric support, making it safe to mount unconditionally on settings pages.

## Key Components

- **`BiometricLoginCard`** — Default export component that manages biometric login state with an accessible toggle switch
- **State**: `available`, `label`, `enabled`, `isBusy` — initialized asynchronously from native biometric APIs
- **`handleToggle`** — Async handler with optimistic UI updates; handles three distinct error cases:
  - `BIOMETRIC_ERROR.CANCELED` — silently reverts (no toast)
  - `BIOMETRIC_ERROR.INVALIDATED` — triggers a full sign-out via `signOutToLogin` (enrollment changed, tokens unrecoverable)
  - All other errors — shows a destructive toast and reverts the switch

## Usage Example

```typescript
// Mount unconditionally on the settings page — renders nothing on web/desktop
import { BiometricLoginCard } from '@/components/biometric-login-card';

export default function SecuritySettingsPage() {
  return (
    <section>
      <h2>Security</h2>
      {/* Safe to render on all platforms */}
      <BiometricLoginCard />
    </section>
  );
}
```

## Behavior Notes

- Performs parallel async initialization (`isBiometricAvailable` + `isBiometricLoginEnabled`) on mount, guarded with an `active` flag to prevent state updates after unmount
- Calls `setBiometricLoginChoice` on toggle to satisfy the post-login enrollment offer's anti-spam policy — an explicit settings change counts as answering the offer
- The `label` string (e.g., `"Face ID"`, `"Fingerprint"`) is derived from the native `biometryType` via `biometryLabel()`
