Displays the authenticated user's profile summary card with avatar, display name, email, role tags, and a contextual action menu.

## Key Components

### `ProfileCard`

The primary export. A client-side React component that renders the user's profile at a glance with the following capabilities:

- **Avatar & identity** — shows the user's avatar (`SquareAvatar`), full name or email fallback, and role tags
- **Email verification warning** — renders an inline `AlertCircleIcon` button when `emailVerified === false`, triggering `onVerifyEmail`
- **Action menu** — a kebab (`ActionsMenuDropdown`) with:
  - **Edit Profile** — always present, calls `onEditProfile`
  - **Notifications** — shown only in native shell environments when the `notifications` feature flag is enabled
  - **Reset Onboarding** — shown only when the `new-onboarding` flag is enabled and the user has a completed or skipped tour
- **Skeleton / error states** — renders a `Skeleton` while the profile loads and a `PageError` if no user data is available

### Props

| Prop | Type | Description |
|---|---|---|
| `onEditProfile` | `() => void` | Called when "Edit Profile" is selected |
| `onVerifyEmail` | `() => void` | Called when the unverified email warning is clicked |

## Usage Example

```typescript
import { ProfileCard } from './profile-card';

function ProfilePage() {
  return (
    <ProfileCard
      onEditProfile={() => router.push('/settings/edit')}
      onVerifyEmail={() => setVerifyEmailModalOpen(true)}
    />
  );
}
```

## Notes

- Depends on `useAuthStore` for user data and loading state
- `canResetOnboarding` is derived from `useOnboardingStore` — the "Reset Onboarding" menu item only appears after onboarding progress has loaded **and** the user has a terminal state (`completed` or `skipped`)
- `showNotificationSettings` is suppressed on web/desktop via `isNativeShell()`
