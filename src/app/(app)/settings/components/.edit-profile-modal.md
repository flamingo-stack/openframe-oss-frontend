A modal dialog component for editing a user's profile, supporting first/last name updates and profile image upload/removal with immediate cache-busting applied to all avatar render sites.

## Key Components

- **`EditProfileModal`** — Main exported component rendering a `SimpleModal` with profile editing controls
- **`EditProfileModalProps`** — Interface defining `isOpen`, `onClose`, `user`, `onSave`, and `isSaving` props
- **`handleImageChange`** — Uploads a new profile image via `uploadWithAuth`, applies a `Date.now()` cache-bust hash, and syncs the result into the auth store immediately
- **`handleImageRemove`** — Deletes the profile image via `deleteWithAuth` and clears image state from the auth store
- **`handleSave`** — Calls the parent-provided `onSave` with updated name fields and closes the modal on success

## Usage Example

```typescript
import { EditProfileModal } from '@/app/components/edit-profile-modal';

function ProfilePage() {
  const [isOpen, setIsOpen] = useState(false);
  const [isSaving, setIsSaving] = useState(false);
  const { user } = useAuthStore();

  const handleSave = async (data: { firstName: string; lastName: string }) => {
    setIsSaving(true);
    await updateUserProfile(data);
    setIsSaving(false);
  };

  return (
    <EditProfileModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      user={user}
      onSave={handleSave}
      isSaving={isSaving}
    />
  );
}
```

## Notes

- Email and Role fields are read-only; only first name, last name, and profile image are editable
- Image uploads are capped at 5 MB and hit `/api/users/image`
- The auth store is updated optimistically after image changes, so all avatar instances (header, profile card, uploader) refresh without requiring a separate profile `GET`
