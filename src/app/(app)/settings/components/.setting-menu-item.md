A reusable settings navigation card component that renders an icon, title, description, and a chevron link button for navigating to a settings sub-page.

## Key Components

### `SettingMenuItem`

A client-side card component used to build settings menus with consistent styling.

**Props (`SettingMenuItemProps`):**

| Prop | Type | Description |
|---|---|---|
| `href` | `string` | Navigation target for the chevron link |
| `icon` | `ReactNode` | Icon element displayed on the left |
| `title` | `string` | Primary label rendered as `h3` text |
| `description` | `string` | Secondary descriptive text rendered as `h6` text |

## Usage Example

```typescript
import { SettingMenuItem } from './setting-menu-item';
import { Bell } from 'lucide-react';

export function SettingsPage() {
  return (
    <SettingMenuItem
      href="/settings/notifications"
      icon={<Bell className="size-5" />}
      title="Notifications"
      description="Manage your alert preferences"
    />
  );
}
```

## Notes

- Marked `'use client'` — must run in a browser context (Next.js App Router).
- Uses Next.js `<Link>` for client-side navigation; the chevron button includes an `aria-label` matching `title` for accessibility.
- Styling relies on ODS (OpenFrame Design System) CSS variables (`--spacing-system-*`, `ods-card`, `ods-border`, etc.) for consistent theming.
