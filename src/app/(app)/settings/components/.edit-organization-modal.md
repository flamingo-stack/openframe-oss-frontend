Modal component for editing organization (tenant) details including name, website, and logo. Handles image upload/removal with optimistic React Query cache updates to reflect logo changes immediately without a refetch race condition.

## Key Components

- **`EditOrganizationModal`** — Main exported component. Renders a `SimpleModal` with:
  - `ImageUploader` — Logo upload/removal with 5 MB size limit and busy state
  - `Input` fields for company name and website
  - Cancel / Update footer actions

- **`handleImageChange`** — Uploads a new logo via `uploadWithAuth`, cache-busts the image URL, and immediately patches the `tenantInfoQueryKeys.all` React Query cache entry to avoid stale avatar display.

- **`handleImageRemove`** — Deletes the logo via `deleteWithAuth` and clears the cache entry.

- **`handleSave`** — Calls the parent-provided `onSave` with `{ name, website }` and closes the modal on success.

## Usage Example

```typescript
import { EditOrganizationModal } from './edit-organization-modal';

function OrganizationSettings() {
  const [isOpen, setIsOpen] = useState(false);
  const { data: tenant } = useTenantInfo();
  const { mutateAsync: updateTenant, isPending } = useUpdateTenantInfo();

  return (
    <EditOrganizationModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      organization={{
        name: tenant.name,
        website: tenant.website,
        image: tenant.image,
      }}
      onSave={(data) => updateTenant(data)}
      isSaving={isPending}
    />
  );
}
```

## Props

| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Called on cancel or successful save |
| `organization` | `{ name, website, image? }` | Current org data to pre-fill fields |
| `onSave` | `(data: UpdateTenantInfoInput) => Promise<void>` | Save handler; modal closes only on resolution |
| `isSaving` | `boolean` | Disables inputs and shows loading state on the submit button |
