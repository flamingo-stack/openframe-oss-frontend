Manages per-organization client AI configuration by providing React Query hooks for reading and mutating AI settings (LLM provider, model, answer style, custom prompt, quick actions) through the `ai-agent` GraphQL API at `/chat/graphql`.

## Key Components

### Types

- **`OrganizationClientAiConfig`** — Shape of the effective config returned by the API; includes `inheritDefault` flag, `llmProvider`, `providerModel`, `answerStyle`, `customPrompt`, `quickActions`, `quickActionsIsDefault`, and `updatedAt`.
- **`organizationAiConfigQueryKeys`** — Stable TanStack Query key factory for cache management.

### Hooks

| Hook | Returns | Description |
|---|---|---|
| `useOrganizationClientAiConfig` | `{ config, isLoading, error, refetch }` | Fetches the effective config (tenant defaults while `inheritDefault` is `true`, org override otherwise). Accepts an `enabled` guard. |
| `useUpdateOrganizationClientAiConfig` | `{ update, isPending }` | Saves an org-specific override, breaking inheritance from the tenant default. |
| `useResetOrganizationClientAiConfig` | `{ reset, isPending }` | Deletes the org override, restoring full inheritance from the tenant default. |
| `useResetOrganizationClientAiQuickActions` | `{ resetQuickActions, isPending }` | Clears only the org's quick actions list so it follows the tenant's live list again, leaving other overrides intact. |

All mutation hooks invalidate `organizationAiConfigQueryKeys.detail(organizationId)` on success.

## Usage Example

```typescript
import {
  useOrganizationClientAiConfig,
  useUpdateOrganizationClientAiConfig,
  useResetOrganizationClientAiConfig,
  useResetOrganizationClientAiQuickActions,
} from './use-organization-ai-config';

function OrgAiSettingsPanel({ organizationId }: { organizationId: string }) {
  const { config, isLoading } = useOrganizationClientAiConfig(organizationId);
  const { update, isPending: isSaving } = useUpdateOrganizationClientAiConfig(organizationId);
  const { reset } = useResetOrganizationClientAiConfig(organizationId);
  const { resetQuickActions } = useResetOrganizationClientAiQuickActions(organizationId);

  if (isLoading) return <Spinner />;

  return (
    <>
      <p>Inheriting defaults: {String(config?.inheritDefault)}</p>
      <button
        disabled={isSaving}
        onClick={() => update({ llmProvider: 'OPENAI', providerModel: 'gpt-4o', answerStyle: 'CONCISE' })}
      >
        Save Override
      </button>
      <button onClick={() => reset()}>Reset to Tenant Default</button>
      <button onClick={() => resetQuickActions()}>Reset Quick Actions</button>
    </>
  );
}
```
