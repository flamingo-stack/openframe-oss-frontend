Fetches and adapts the OpenFrame Product Hub's default quick actions for a given AI agent, mapping hub action shapes to the local `AiQuickAction` type.

## Key Components

### `hubAgentConfigUrl(slug)`
Constructs the gateway proxy URL (`/content/api/ai-agents/<slug>`) used to fetch agent config from the Product Hub. Compatible with both local dev (Next.js rewrites) and production environments.

### `useHubDefaultQuickActions(agentSlug, options)`
React hook that retrieves hub-sourced default quick actions for the specified agent slug. Internally delegates to `useEmptyStateConfig` (which caches per URL for the session lifetime) and memoizes the mapped `AiQuickAction[]` array.

**Parameters:**
- `agentSlug` — Identifies the target agent (e.g. `"mingo"`)
- `options.enabled` — Optional flag to conditionally suppress the fetch

**Returns:**
| Field | Type | Description |
|---|---|---|
| `actions` | `AiQuickAction[]` | Mapped quick actions with icon fields preserved |
| `loading` | `boolean` | True while the request is in flight |
| `loaded` | `boolean` | True once the request has settled |

## Usage Example

```typescript
const { actions, loading, loaded } = useHubDefaultQuickActions('mingo', {
  enabled: quickActionsIsDefault,
});

if (loaded) {
  seedQuickActions(actions); // use hub defaults until tenant overrides exist
}
```

## Notes

- Only active while `quickActionsIsDefault` is `true` — the tenant backend stores only org-customized lists, never hub defaults
- Icon fields (`iconName`, `iconUrl`, `iconProps`) are preserved for chat chip rendering but ignored by the settings editor (icon persistence is not yet supported)
- Source lives at [`use-hub-default-quick-actions.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/use-hub-default-quick-actions.ts)
