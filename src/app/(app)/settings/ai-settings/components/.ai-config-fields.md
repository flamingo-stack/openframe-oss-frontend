Reusable React Hook Form field components for configuring AI settings, including LLM provider/model selection and answer style preferences.

## Key Components

### `AiProviderModelFields<T>`
A generic, side-by-side layout of two controlled `Select` fields:
- **LLM Provider** – renders available providers with icons and labels sourced from `LLM_PROVIDER_OPTIONS`/`LLM_PROVIDER_ICON`/`LLM_PROVIDER_LABEL`
- **Provider Model** – dynamically populates options based on the currently selected `llmProvider` from `modelsByProvider`

Calls `onProviderChange()` when the provider changes, allowing the parent to clear the model selection.

### `AiAnswerStyleFields<T>`
Renders an **Answer Style** `RadioGroupBlock` and, when the selected style is `'CUSTOM'`, conditionally shows a **Custom Prompt** `Textarea`.

## Props

| Prop | Component | Description |
|---|---|---|
| `control` | Both | React Hook Form `Control` object |
| `llmProvider` | `AiProviderModelFields` | Watched provider value; drives model list |
| `modelsByProvider` | `AiProviderModelFields` | Map of provider → model options |
| `onProviderChange` | `AiProviderModelFields` | Callback to reset model on provider change |
| `providerLabel` | `AiProviderModelFields` | Custom label for provider select (default: `'LLM Provider'`) |
| `answerStyle` | `AiAnswerStyleFields` | Watched style value; `'CUSTOM'` reveals textarea |

## Usage Example

```typescript
import { AiProviderModelFields, AiAnswerStyleFields } from './ai-config-fields';
import { useForm } from 'react-hook-form';

function AiSettingsForm() {
  const { control, watch, setValue } = useForm<AiLogicFormValues>();
  const llmProvider = watch('llmProvider');
  const answerStyle = watch('answerStyle');

  return (
    <form>
      <AiProviderModelFields
        control={control}
        llmProvider={llmProvider}
        modelsByProvider={modelsByProvider}
        onProviderChange={() => setValue('providerModel', '')}
        providerLabel="Mingo LLM Provider"
      />
      <AiAnswerStyleFields
        control={control}
        answerStyle={answerStyle}
      />
    </form>
  );
}
```
