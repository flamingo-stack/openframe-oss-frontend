Read-only UI components for displaying AI quick actions in the AI Settings panel, supporting both Mingo and AI Assistant (Fae) agent configurations.

## Key Components

| Export | Type | Description |
|---|---|---|
| `QuickActionsAgentConfig` | Interface | Per-agent configuration with `agentLabel` (display) and `agentSlug` (checkbox IDs) |
| `MINGO_QUICK_ACTIONS_CONFIG` | Constant | Pre-built config for the Mingo agent |
| `ASSISTANT_QUICK_ACTIONS_CONFIG` | Constant | Pre-built config for the AI Assistant (Fae) agent |
| `QuickActionsBannerCopy` | Interface | Optional override for the info banner's `value` and `label` text |
| `QuickActionsSourceBanner` | Component | Info banner indicating whether actions are OpenFrame defaults or org-custom |
| `AiSettingsQuickActionsSection` | Component | Full view-mode section: heading + source banner + read-only list |
| `AiSettingsQuickActions` | Component | Core read-only `DataTable` rendering action name and instructions per row |

## Usage Example

```typescript
import {
  AiSettingsQuickActionsSection,
  MINGO_QUICK_ACTIONS_CONFIG,
} from './ai-settings-quick-actions';

// View-mode section for Mingo using OpenFrame defaults
<AiSettingsQuickActionsSection
  title="Quick Actions"
  actions={[
    { id: '1', name: 'Restart Service', instructions: 'Restarts the target service.' },
    { id: '2', name: 'Check Disk Usage', instructions: 'Reports current disk usage.' },
  ]}
  isDefault={true}
  agentConfig={MINGO_QUICK_ACTIONS_CONFIG}
/>

// Override banner copy for a per-customer inherited-config scenario
<AiSettingsQuickActionsSection
  title="Quick Actions"
  actions={customerActions}
  isDefault={true}
  agentConfig={ASSISTANT_QUICK_ACTIONS_CONFIG}
  bannerCopy={{
    value: 'Inherited from global configuration',
    label: 'Your organization has not customized these actions yet.',
  }}
/>
```

## Notes

- All components are **view-mode only** (read-only); edit mode is handled separately.
- `isDefault: true` renders the header as `"OpenFrame {agentLabel} Quick Actions"`; `false` renders `"Organization {agentLabel} Quick Actions"`.
- The `DataTable` has sorting disabled and shows `"No quick actions configured."` when the `actions` array is empty.
