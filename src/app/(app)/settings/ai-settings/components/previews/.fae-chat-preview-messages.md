Generates a static array of pre-built `Message` objects that simulate a Fae AI assistant conversation, used to populate a read-only chat preview UI.

## Key Components

- **`buildFaeChatPreviewMessages(assistantName, avatarUrl?)`** — Factory function returning five hard-coded `Message` entries that walk through a realistic Fae support scenario: diagnosing disk performance, requesting approval to run a PowerShell cleanup command, executing it, reporting results, and escalating a suspicious process to a technician.

## Usage Example

```typescript
import { buildFaeChatPreviewMessages } from './fae-chat-preview-messages';

const messages = buildFaeChatPreviewMessages('Fae', 'https://cdn.example.com/fae-avatar.png');
// Render messages in a read-only <ChatPreview> component
```

## Notes

- All messages share a fixed timestamp of **14:47:00** so every bubble displays the same time stamp in the preview.
- Message `preview-2` uses a structured `content` array combining a `text` block with an `approval_request` block (pre-set to `approved`), demonstrating the command-approval UI pattern — the PowerShell command and its explanation are both included.
- The `assistantType` is fixed to `'fae'` and `role` to `'assistant'`; these values are baked in and not configurable.
- `avatarUrl` is optional; falls back to `null` when omitted.
