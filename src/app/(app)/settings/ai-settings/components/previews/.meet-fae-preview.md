A live-preview component that renders a scaled-down mockup of the Fae AI assistant onboarding screen, reflecting real-time changes to the assistant's name, avatar, and accent color as configured in settings.

## Key Components

### `MeetFaePreview`
The sole export. Renders a responsive card containing:
- **`SquareAvatar`** — displays the assistant's avatar with the configured accent color as background
- **Feature rows** — three static capability cards (instant fix, escalation, 24/7 availability) with dynamically injected `assistantName`
- **`MspOrganizationCard`** / **`MspOrganizationCardSkeleton`** — shows the MSP's branding sourced from `useTenantInfo()`; falls back to sample data while loading
- **"Get Started" button** — styled with the live accent color
- **Flamingo branding footer**

### Scaling strategy
Content is authored at a fixed `600×945px` canvas and scaled down via CSS `transform: scale(var(--preview-scale))` (not `zoom`, which mis-renders text in Safari). The outer wrapper reserves the post-scale footprint to keep the card centered.

### `useTenantInfo` integration
Reuses the same React Query cache as the settings page — no additional network request is made.

## Usage Example

```typescript
import { MeetFaePreview } from './meet-fae-preview';

<MeetFaePreview
  assistantName="Fae"
  avatarUrl="/uploads/fae-avatar.png"
  accentColor="#FF5E8A"
  mspName="Acme IT"
  mspWebsite="www.acmeit.com"
/>
```
