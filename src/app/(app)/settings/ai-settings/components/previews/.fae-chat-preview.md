A read-only chat UI preview component that renders a scaled-down, live-preview of the Fae AI client chat interface, used to demonstrate assistant branding (name, avatar, accent color) within MSP configuration screens.

## Key Components

### `FaeChatPreview` (exported component)

| Prop | Type | Default | Description |
|---|---|---|---|
| `assistantName` | `string` | — | Display name for the Fae assistant |
| `avatarUrl` | `string?` | — | Optional avatar image URL |
| `accentColor` | `string` | — | CSS color value mapped to `--ods-flamingo-pink-base` |
| `mspName` | `string?` | `'TechFlow Solutions'` | Fallback MSP company name |
| `providerName` | `string?` | `'google'` | AI model provider identifier |
| `modelDisplayName` | `string?` | `'Google Gemini 3.5'` | Human-readable model label in footer |

**Internal behavior:**
- Uses `useTenantInfo()` to resolve the live MSP company name, falling back to `mspName`
- Preview messages are memoized via `buildFaeChatPreviewMessages`
- Scales a `650×1112px` chat layout using CSS `transform: scale()` (not `zoom`, to avoid Safari rendering bugs) at three responsive breakpoints (`0.225` → `0.266` → `0.342`)

## Usage Example

```typescript
import { FaeChatPreview } from './fae-chat-preview';

<FaeChatPreview
  assistantName="Aria"
  avatarUrl="https://cdn.example.com/aria-avatar.png"
  accentColor="#7C3AED"
  mspName="Acme IT Solutions"
  providerName="google"
  modelDisplayName="Google Gemini 3.5"
/>
```
