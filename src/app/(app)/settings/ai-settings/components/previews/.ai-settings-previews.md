Side-by-side preview component that renders themed onboarding (`MeetFaePreview`) and chat (`FaeChatPreview`) cards for AI assistant settings, applying light/dark theme scoping per-card rather than to the container.

## Key Components

### `AiSettingsPreviews`
Main exported component that composes both preview cards in a responsive two-column grid.

**Props (`AiSettingsPreviewsProps`):**

| Prop | Type | Required | Description |
|---|---|---|---|
| `assistantName` | `string` | ✅ | Display name for the AI assistant |
| `avatarUrl` | `string` | ❌ | Custom avatar image URL; falls back to `FAE_AVATAR_DATA_URI` |
| `accentColor` | `string` | ✅ | Theme accent color applied to both previews |
| `theme` | `ApplicationTheme` | ✅ | Selected theme (`light`, `dark`, or system) |
| `providerName` | `string` | ❌ | AI provider label shown in the chat preview |
| `modelDisplayName` | `string` | ❌ | Model name shown in the chat preview |

**Internal behavior:**
- **`useResolvedTheme`** — resolves `system` theme to the actual `light`/`dark` value
- **Per-card theme scoping** — applies `.theme-light` / `.theme-dark` to each card `<div>`, not the outer wrapper, to avoid unintentionally re-theming the app background
- **Avatar fallback** — substitutes `FAE_AVATAR_DATA_URI` when no custom avatar is provided, ensuring previews never show broken images

## Usage Example

```typescript
import { AiSettingsPreviews } from './ai-settings-previews';

<AiSettingsPreviews
  assistantName="Fae"
  avatarUrl="https://cdn.example.com/my-avatar.png"
  accentColor="#6366f1"
  theme="dark"
  providerName="OpenAI"
  modelDisplayName="GPT-4o"
/>
```
