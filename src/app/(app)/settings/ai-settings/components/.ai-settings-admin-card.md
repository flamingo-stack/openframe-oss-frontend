Read-only summary card component that displays Mingo AI admin configuration fields — LLM provider (with icon), provider model, and answer style — in a responsive 3-column grid layout.

## Key Components

### `AiSettingsAdminCard`
Main exported component rendering a card with three [`InfoCell`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/components/shared/info-cell.tsx) entries:

| Column | Source |
|---|---|
| **Mingo LLM Provider** | `aiConfig.llmProvider` resolved via `LLM_PROVIDER_LABEL` + `LLM_PROVIDER_ICON` |
| **Provider Model** | `providerModelLabel` prop (preferred) → `aiConfig.providerModel` → `'—'` |
| **Answer Style** | `aiConfig.answerStyle` resolved via `ANSWER_STYLE_LABEL` → `'—'` |

### Props

| Prop | Type | Description |
|---|---|---|
| `aiConfig` | `AgentAiConfig` | AI configuration object containing provider, model, and style |
| `providerModelLabel` | `string?` | Human-readable display name for the backend model identifier |

## Usage Example

```typescript
import { AiSettingsAdminCard } from './ai-settings-admin-card';

<AiSettingsAdminCard
  aiConfig={{
    llmProvider: 'openai',
    providerModel: 'gpt-4o',
    answerStyle: 'concise',
  }}
  providerModelLabel="GPT-4o"
/>
```

> **Note:** This is a display-only card. For the client-facing counterpart that includes appearance fields, see `AiSettingsCustomerCard`.
