A React tab component for configuring the customer-facing AI assistant settings, rendering either a read-only overview or a full edit form with avatar, model selection, theme, accent color, answer style, and quick actions.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CustomerAiAssistantTab` | Component | Main tab component toggling between view and edit mode |
| `CUSTOMER_AI_ASSISTANT_FORM_ID` | Constant (re-export) | HTML form ID used for external submit button binding |
| `CustomerAiAssistantTabProps` | Interface | Props: `aiConfig`, `view`, `isEditMode`, `onSubmit` |

### Internal Sub-components Rendered

- **`AiSettingsOverview`** — read-only summary when `isEditMode` is `false`
- **`AiProviderModelFields`** — LLM provider and model dropdowns
- **`ImageUploader`** — avatar upload/remove
- **`AiSettingsPreviews`** — live theme/accent color previews (feature-flagged)
- **`AiAnswerStyleFields`** — answer style selector (feature-flagged)
- **`AiSettingsQuickActionsEditor`** — quick actions editor (feature-flagged)

## Usage Example

```typescript
import {
  CustomerAiAssistantTab,
  CUSTOMER_AI_ASSISTANT_FORM_ID,
} from './customer-ai-assistant-tab';

<CustomerAiAssistantTab
  aiConfig={agentAiConfig}
  view={clientView}
  isEditMode={true}
  onSubmit={(payload, commitAvatar) => {
    saveAiSettings(payload, commitAvatar);
  }}
/>

// External submit button referencing the form by ID:
<button form={CUSTOMER_AI_ASSISTANT_FORM_ID} type="submit">
  Save
</button>
```

## Notes

- Appearance customization (theme, accent color, previews, answer style, quick actions) is gated behind `featureFlags.customerAiAssistantSettings`.
- In view mode, quick actions fall back to Product Hub defaults (`hubDefaults`) when `aiConfig.quickActionsIsDefault` is `true`.
- Form state is managed via `react-hook-form` through the `useCustomerAiAssistantForm` hook.
