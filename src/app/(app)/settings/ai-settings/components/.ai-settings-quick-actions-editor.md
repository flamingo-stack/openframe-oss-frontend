Reusable form editor component for managing AI assistant quick actions, supporting drag-to-reorder, add/remove operations, and a "use defaults" toggle with confirmation dialog.

## Key Components

### `AiSettingsQuickActionsEditor<T>`
Generic form editor component that owns the `quickActions` field array and `quickActionsIsDefault` flag. Integrates with React Hook Form via a typed `Control<T>` prop constrained to `QuickActionsFormValues`.

**Key behaviors:**
- **Checked (default on):** Renders a dimmed, read-only preview of `defaultActions` via `AiSettingsQuickActions`
- **Unchecked:** Seeds the editable list with `defaultActions` rows and enables full CRUD
- **Re-enabling defaults:** Triggers a `ConfirmDialog` before discarding custom rows

### `QuickActionsDefaultCopy`
Interface controlling the checkbox wording, confirm-dialog body, and preview header attribution (`previewIsOpenFrame`).

### `QuickActionCard` *(internal)*
Responsive grid card for each quick action row:
- `lg+`: single row — handle | Action Name | Action Instructions | delete
- `mobile/tablet`: two rows — handle | Action Name | delete, then Instructions indented
- Uses `SortableList` drag handle attributes for reorder support

## Usage Example

```typescript
import { AiSettingsQuickActionsEditor } from './ai-settings-quick-actions-editor';

// Inside a parent form component:
<AiSettingsQuickActionsEditor
  control={form.control}
  title="Mingo Quick Actions"
  agentConfig={{ agentLabel: 'Mingo', agentSlug: 'mingo' }}
  defaultActions={openFrameDefaultActions}
  defaultActionsCopy={{
    title: 'Use tenant default actions',
    description: 'Inherit the configured tenant quick actions.',
    confirmDescription: 'This replaces your custom actions with the tenant set.',
    previewIsOpenFrame: false,
  }}
  className="mt-4"
/>
```

**Required form schema fields** (`QuickActionsFormValues`):
```typescript
{
  quickActions: { name: string; instructions: string }[];
  quickActionsIsDefault: boolean;
}
```

## Notes

- The generic `<T>` allows embedding in larger form schemas without type casting at the call site
- Drag reorder uses `move()` from `useFieldArray`; the persisted order matches the array order directly — no extra mapping needed
- `SortableList` item identity uses RHF's stable `field.id` as the sortable key; index is resolved by lookup to avoid stale closures
