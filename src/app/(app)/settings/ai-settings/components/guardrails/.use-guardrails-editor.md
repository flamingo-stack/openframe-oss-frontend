Custom React hook that manages the complete edit session state for a guardrails policy editor, coordinating template selection, rule-level permission edits, and save operations across stock and custom policies.

## Key Components

### `GuardrailsDraft` (type)
A discriminated union representing the three possible edit states:
- `template` — a stock template is selected for activation
- `existing-custom` — the tenant's custom policy is selected with pending rule edits
- `new-custom` — creating/rebasing a custom policy from a stock template with pending rule edits

### `useGuardrailsEditor(args)`
The primary export. Accepts `{ isEditMode: boolean }` and returns a `GuardrailsEditor` object containing:

| Return Value | Description |
|---|---|
| `policyGroups` | Grouped policy rules with edits applied |
| `templateOptions` | Picker options including a synthetic "new custom" row when applicable |
| `selectedTemplateId` | Currently active selection in the picker |
| `canEditRules` | `true` only when a custom/new-custom draft is active |
| `selectTemplate` | Switches draft to a template or existing-custom kind |
| `createCustomPolicyFrom` | Transitions draft to `new-custom` from a base template |
| `setPolicyPermission` | Applies a single rule's approval level edit |
| `applyCategoryPermission` | Bulk-applies an approval level to all rules in a category |
| `save` | Persists the draft; returns `true` if the caller may exit edit mode |

## Usage Example

```typescript
const editor = useGuardrailsEditor({ isEditMode });

// Render template picker
editor.templateOptions.map(opt => (
  <option key={opt.id} value={opt.id}>{opt.label}</option>
));

// Apply a rule-level change
editor.setPolicyPermission(categoryId, policyId, 'require-approval');

// Bulk apply to a category
editor.applyCategoryPermission(categoryId, 'auto-approve');

// Promote to custom and then save
editor.createCustomPolicyFrom(baseTemplateId);
const didSave = await editor.save(); // returns false on mutation error
if (didSave) exitEditMode();
```

Cancelling an edit session requires only setting `isEditMode` to `false` — the draft is discarded automatically with no snapshot rollback needed.
