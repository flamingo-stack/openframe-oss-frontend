A read-only display card that shows the active Guardrails Preset label for an AI agent or configuration context, with visual muting support for inherited tenant defaults.

## Key Components

- **`GuardrailsPresetCard`** — Client component rendering a styled card containing an `InfoCell` with the preset name
- **`GuardrailsPresetCardProps`**
  - `label` — The preset name to display
  - `muted` *(optional, default `false`)* — When `true`, renders the label in secondary text color to indicate the value is inherited from tenant defaults rather than explicitly set

## Usage Example

```typescript
// Explicitly configured preset
<GuardrailsPresetCard label="Strict Safety" />

// Inherited from tenant defaults (visually muted)
<GuardrailsPresetCard label="Default" muted />
```

## Notes

- Renders as a client component (`'use client'`)
- Uses `InfoCell` from the shared component library for consistent label/value layout
- Styled with ODS (OpenDesignSystem) tokens: `bg-ods-card`, `border-ods-border`, `text-ods-text-secondary`
- The card has a minimum height of `80px` (`min-h-20`) and horizontal padding driven by the `--spacing-system-mf` CSS variable
