React Query hooks for fetching and mutating per-organization AI guardrail policies via the `ai-agent` GraphQL API (`/chat/graphql`).

## Key Components

### Query Keys
- **`organizationGuardrailsQueryKeys.detail(organizationId)`** — Scoped cache key for a single organization's guardrails.

### Hooks

| Hook | Purpose |
|---|---|
| `useOrganizationGuardrails(organizationId, options)` | Fetches the effective guardrails for an org (inherited defaults or org-specific materialized policy) |
| `useUpdateOrganizationGuardrails(organizationId)` | Materializes org-specific guardrails from a template + per-rule overrides |
| `useResetOrganizationGuardrails(organizationId)` | Reverts the org back to inheriting tenant-default guardrails |

### Types

- **`OrganizationGuardrails`** — Effective policy shape returned by the query; `rules` are normalized to `PolicyRule` (empty strings instead of `null`)
- **`OrganizationGuardrailsInput`** — Mutation input: a base `templateId` plus `overrides[]` (`naturalKey` + `approvalLevel`)

## Usage Example

```typescript
// Fetch
const { guardrails, isLoading } = useOrganizationGuardrails(organizationId);

// Update (apply template + overrides)
const { update, isPending } = useUpdateOrganizationGuardrails(organizationId);
await update({
  templateId: 'tmpl_abc123',
  overrides: [{ naturalKey: 'shell.execute', approvalLevel: 'REQUIRE_APPROVAL' }],
});

// Reset to tenant defaults
const { reset, isPending } = useResetOrganizationGuardrails(organizationId);
await reset();
```

> **Note:** These hooks target the `saas-ai-agent` GraphQL schema via raw POST to `/chat/graphql`, which is separate from the main `schema.graphql`. Tenant-level template management lives in `use-guardrails-policies.ts`.
