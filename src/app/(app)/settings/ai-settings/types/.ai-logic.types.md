Defines shared Zod validation schema, types, and utility functions for AI logic form fields used across both the CLIENT (customer) and ADMIN (Mingo) configuration tabs.

## Key Components

| Export | Type | Description |
|---|---|---|
| `aiLogicShape` | `const` | Raw Zod shape object for composing with `.extend()` or `.refine()` in tab-specific schemas |
| `aiLogicSchema` | `ZodObject` | Compiled schema from `aiLogicShape` covering provider, model, answer style, custom prompt, and quick actions |
| `AiLogicFormValues` | `type` | Inferred TypeScript type from `aiLogicSchema` |
| `requireCustomPrompt` | `function` | Validation guard — returns `false` only when `answerStyle` is `CUSTOM` and `customPrompt` is empty |
| `getAiLogicDefaults` | `function` | Maps an `AgentAiConfig` to initial form values; empties quick actions array when defaults are active |
| `toAgentAiConfigInput` | `function` | Maps form values to the GraphQL `AgentAiConfigInput` type; strips `customPrompt` and `quickActions` when not applicable |

## Usage Example

```typescript
import {
  aiLogicShape,
  getAiLogicDefaults,
  requireCustomPrompt,
  toAgentAiConfigInput,
} from './ai-logic.types';
import { z } from 'zod';

// Extend with tab-specific fields
const adminSchema = z.object(aiLogicShape).extend({
  adminOnlyField: z.string().min(1),
}).refine(requireCustomPrompt, {
  message: 'Custom prompt is required when answer style is CUSTOM',
  path: ['customPrompt'],
});

// Populate form defaults from existing config
const defaults = getAiLogicDefaults(agentAiConfig);

// Convert form submission to GraphQL input
const input = toAgentAiConfigInput(formValues);
await updateAgentAiConfig({ variables: { input } });
```

## Notes

- `quickActions` is sent as `undefined` to the backend when `quickActionsIsDefault` is `true`, letting the Product Hub own the action list
- `customPrompt` is omitted from the GraphQL input unless `answerStyle === 'CUSTOM'`
