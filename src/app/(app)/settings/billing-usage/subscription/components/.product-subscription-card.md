A React client component that renders a subscription plan selection card for a product, allowing users to choose billing periods, package tiers, or enter a custom quantity with real-time pricing feedback.

## Key Components

### `ProductSubscriptionCard`
The main exported component. Consumes two Relay fragments to display product details and current subscription state, then orchestrates billing period toggling, package radio selection, and custom quantity input.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `productRef` | Fragment key | Relay fragment for product data |
| `subscriptionProductRef` | Fragment key \| null | Relay fragment for existing subscription state |
| `description` | `string \| ((periodLabel: string) => string)` | Static or period-aware card description |
| `allowCustom` | `boolean` | Enables custom quantity input (default: `true`) |
| `reserveBillingPeriodSpace` | `boolean` | Holds vertical space for billing toggle alignment in sibling cards |
| `onUpdatesChange` | `(updates: ProductUpdates) => void` | Fires whenever selection state changes |

### `HelpTooltip`
An internal click-triggered popover using `DropdownMenu`. Intentionally avoids `Tooltip` because help content can be interactive, scrollable, or long-form.

### Relay Fragments
- `productSubscriptionCardProductFragment` — fetches `packageOptions`, `payAsYouGoOption`, `unitSize`
- `productSubscriptionCardSubscriptionFragment` — fetches current `packageOptions`, `payAsYouGoOption`, `paygOnly`

## Usage Example

```typescript
import { ProductSubscriptionCard } from './product-subscription-card';

<ProductSubscriptionCard
  productRef={product}
  subscriptionProductRef={subscriptionProduct}
  title="Endpoint Protection"
  description={(period) => `Billed ${period} per device`}
  packageUnitLabel="devices"
  customLabel="Custom amount"
  customSubtitle="Choose your own quantity"
  helpText={<RateTiersTable tiers={tiers} />}
  allowCustom
  reserveBillingPeriodSpace
  onUpdatesChange={(updates) => handleUpdates(updates)}
/>
```
