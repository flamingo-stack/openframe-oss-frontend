Renders a two-column "Current Plan" / "New Plan" comparison UI for subscription change previews, with color-coded indicators (green = upgrade, red = downgrade) applied per row and to the total cost.

## Key Components

### Exports

- **`PlanChangeSummary`** — Main component. Accepts an array of `PlanChangeSummaryItem` objects and renders a responsive side-by-side grid comparing current and proposed plan lines.
- **`PlanChangeSummaryItem`** — Interface describing each row: a `label` string and a `PlanComparison` object containing `current` and `next` `PlanLine` values.

### Internal Helpers

| Helper | Purpose |
|---|---|
| `directionClass` | Maps `'up' \| 'down' \| 'same'` to ODS color tokens |
| `quantityDirection` | Computes upgrade/downgrade direction for quantity; handles PAYG ↔ package transitions |
| `periodDirection` | Ranks billing periods (`PAYG < Monthly < Annual`) to determine direction |
| `totalDirection` | Compares annual totals; higher cost = upgrade (green) per product spec |
| `sumAnnualTotals` | Sums non-null `annualTotal` values across all plan lines |
| `NewProductValue` | Inline component that colorizes quantity and billing period independently |

## Usage Example

```typescript
import { PlanChangeSummary } from './plan-change-summary';

const items = [
  {
    label: 'Devices',
    comparison: {
      current: { quantity: 50, billingPeriod: 'MONTHLY', payg: false, annualTotal: 600 },
      next:    { quantity: 100, billingPeriod: 'YEARLY', payg: false, annualTotal: 1000 },
    },
  },
  {
    label: 'AI Tokens',
    comparison: {
      current: { payg: true, annualTotal: null },
      next:    { quantity: 500000, billingPeriod: 'YEARLY', payg: false, annualTotal: 240 },
    },
  },
];

<PlanChangeSummary items={items} />
```
