Client-side Next.js page component that renders the subscription settings UI, gating access via a feature flag and providing a `Suspense` boundary with a skeleton fallback.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SubscriptionSettingsPage` | `default` (Page Component) | Root page component for the `/settings/subscription` route |

**Dependencies:**
- `featureFlags.subscription.enabled()` — Guards the page; returns `notFound()` if the subscription feature is disabled
- `SubscriptionSettingsView` — The primary settings UI rendered inside `Suspense`
- `SubscriptionSettingsSkeleton` — Loading placeholder shown during async resolution

## Usage Example

This component is automatically resolved by Next.js App Router. No manual instantiation is required.

```typescript
// Accessed via route: /settings/subscription
// Feature flag controls visibility:

// featureFlags config (example)
export const featureFlags = {
  subscription: {
    enabled: () => process.env.NEXT_PUBLIC_SUBSCRIPTION_ENABLED === 'true',
  },
};
```

```typescript
// The page renders this tree when the flag is active:
<Suspense fallback={<SubscriptionSettingsSkeleton />}>
  <SubscriptionSettingsView />
</Suspense>
```

> **Note:** If `featureFlags.subscription.enabled()` returns `false`, Next.js renders the built-in 404 page via `notFound()`. No subscription UI is exposed to users with the flag off.
