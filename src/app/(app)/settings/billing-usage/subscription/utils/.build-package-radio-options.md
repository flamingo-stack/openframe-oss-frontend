Builds the list of radio option objects for package/tier selection in a subscription flow, combining pay-as-you-go, fixed tiers, and an optional custom amount entry.

## Key Components

### `buildPackageRadioOptions(args)`
Main exported function that assembles three option groups into a flat array:

- **PAYG option** — conditionally prepended when `payAsYouGoOption` is non-null; uses `PAYG_OPTION_ID` as value
- **Tier options** — maps each `PriceTier` to a radio item with computed total price, compact unit label, and an optional discount `Tag` badge (shown when `discountPercent > 0`)
- **Custom option** — appended when `allowCustom` is `true`; uses `CUSTOM_OPTION_ID` as value

### Supporting Interfaces

| Interface | Purpose |
|---|---|
| `PriceTier` | Defines `from` (quantity) and `unitPrice` for a single tier |
| `PayAsYouGoOption` | Optional `name`/`description` for the PAYG entry |
| `BuildPackageRadioOptionsArgs` | Full parameter shape for the builder function |

## Usage Example

```typescript
import { buildPackageRadioOptions } from './build-package-radio-options';

const options = buildPackageRadioOptions({
  tiers: [
    { from: 10, unitPrice: 5.00 },
    { from: 50, unitPrice: 4.00 },
  ],
  baselineUnitPrice: 5.00,
  months: 12,
  periodSuffix: '/yr',
  packageUnitLabel: 'devices',
  customLabel: 'Custom amount',
  customSubtitle: 'Enter a specific quantity',
  payAsYouGoOption: { name: 'PAYG', description: 'Billed monthly per device' },
  allowCustom: true,
});
// Returns: [paygEntry, tier10Entry, tier50Entry (with -20% tag), customEntry]
```

## Notes

- Discount percentage is only rendered when `baselineUnitPrice` is non-null and the tier offers a reduction
- Set `allowCustom: false` for PAYG-only products to suppress the custom quantity option
