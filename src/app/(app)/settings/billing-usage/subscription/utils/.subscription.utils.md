Utility functions for subscription plan management, including price formatting, plan selection state initialization, plan diff calculation, and checkout payload construction for the OpenFrame billing UI.

## Key Components

| Export | Type | Description |
|---|---|---|
| `CUSTOM_OPTION_ID` | `const` | Sentinel ID (`__custom__`) for user-entered custom quantities |
| `PAYG_OPTION_ID` | `const` | Sentinel ID (`__payg__`) for pay-as-you-go selection |
| `formatMoney` | `function` | Formats a number as a USD-locale integer string |
| `formatCompact` | `function` | Compact number formatting (e.g. `100000` → `"100K"`) |
| `topmostSelectionId` | `function` | Resolves the default radio selection ID for a given billing period |
| `calculateCustomQuantityPrice` | `function` | Computes total price and discount % for a custom quantity across price tiers |
| `formatPaygSubtitle` | `function` | Builds a display subtitle string for a PAYG option |
| `buildInitialSelection` | `function` | Derives initial `ProductSelectionState` from catalog + active subscription data |
| `diffPackageUpdates` | `function` | Produces `PackageUpdateInput[]` diff (ADD/CANCEL) between current and desired plan |
| `isPlanChanged` | `function` | Returns whether a `PlanComparison` represents a real selection change |
| `buildCheckoutProduct` | `function` | Builds a `ProductCheckoutInput` for new checkout sessions (trial/canceled state) |

## Usage Example

```typescript
import {
  buildInitialSelection,
  diffPackageUpdates,
  isPlanChanged,
  buildCheckoutProduct,
  PAYG_OPTION_ID,
  CUSTOM_OPTION_ID,
} from './subscription.utils';

// Initialize selection from catalog + active subscription
const selection = buildInitialSelection(productData, subscriptionProductData);

// Compute what changed (for subscriptions already active)
const updates = diffPackageUpdates(productData, selection, subscriptionProductData);
// → [{ productName: 'Devices', packageOptionId: 'uuid', action: 'ADD', quantity: 500 }]

// Check if summary panel should be shown
const changed = isPlanChanged({ current: currentPlan, next: nextPlan });

// Build checkout payload for new subscriptions
const checkoutProduct = buildCheckoutProduct(productData, selection);
```

## Notes

- `diffPackageUpdates` never emits PAYG mutations — PAYG is self-healed server-side via `reconcilePaygInvariant`.
- `toCatalogOptionId` (internal) decodes Relay global IDs (`base64("ProductOption:<uuid>")`) to raw UUIDs expected by the backend.
- `validCustomQuantity` enforces `unitSize` granularity (e.g. AI tokens require multiples of `100,000`).
