Manages product selection state for subscription cards, handling billing period switching, package tier selection, custom quantity input, and real-time update diffing against an existing subscription.

## Key Components

**`useProductSelection(args)`** — Primary hook export accepting:
- `product` — GraphQL fragment data describing available packages, tiers, and pricing
- `subscriptionProduct` — Current subscription state (nullable) used to compute diffs
- `onUpdatesChange` — Callback fired whenever selection changes, receiving validated `ProductUpdates`

**Returned values and setters:**

| Name | Description |
|---|---|
| `selection` | Current selection state (billing period, package ID, custom quantity) |
| `billingPeriodItems` | Deduplicated list of `{ id, label }` billing period options |
| `allTiers` / `tiers` | Full tier array and sliced non-baseline tiers for the active package |
| `baselineUnitPrice` | Unit price of the first tier or PAYG fallback |
| `unitSize` | Granularity constraint for custom quantities (e.g. `1` for devices, `100_000` for AI tokens) |
| `months` / `periodSuffix` | Multiplier and display suffix derived from billing period |
| `setBillingPeriod` | Switches billing period and resets package to topmost valid option |
| `setSelectedPackage` | Selects a specific package ID; toggles PAYG and custom flags |
| `setCustomQuantity` | Parses and validates a string integer into custom quantity state |

## Usage Example

```typescript
const {
  selection,
  billingPeriodItems,
  tiers,
  baselineUnitPrice,
  unitSize,
  setBillingPeriod,
  setSelectedPackage,
  setCustomQuantity,
} = useProductSelection({
  product,
  subscriptionProduct,
  onUpdatesChange: (updates) => {
    if (updates.valid) applyUpdates(updates.packageUpdates);
  },
});
```
