Utility functions for formatting numeric values and dates into human-readable strings for display in the UI.

## Key Components

| Function | Signature | Description |
|---|---|---|
| `formatCount` | `(value: number) => string` | Formats a number with locale-aware thousands separators (e.g., `1000` → `"1,000"`) |
| `formatCurrency` | `(value: number) => string` | Formats a number as USD currency with two decimal places (e.g., `42.5` → `"$42.50"`) |
| `formatDateOrDash` | `(iso: string \| null \| undefined) => string` | Parses an ISO date string via `formatDate`; returns an em dash (`—`) for null/undefined and falls back to the raw string on parse errors |

## Usage Example

```typescript
import { formatCount, formatCurrency, formatDateOrDash } from '@/lib/format';

// Numeric count
formatCount(1234567);        // "1,234,567"

// Currency
formatCurrency(1999.9);      // "$1,999.90"
formatCurrency(0);           // "$0.00"

// Dates
formatDateOrDash('2024-03-15T10:00:00Z');  // "Mar 15, 2024" (via formatDate)
formatDateOrDash(null);                     // "—"
formatDateOrDash(undefined);               // "—"
formatDateOrDash('not-a-date');            // "not-a-date" (fallback)
```
