A modal component that notifies users their subscription has been cancelled, displaying the subscription end date and informing them of the impact on their devices and tokens.

## Key Components

### `SubscriptionCancelledModal`
The primary exported component. Renders a `SimpleModal` with a cancellation message, a formatted end date, and a close button.

**Props (`SubscriptionCancelledModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `endDate` | `string \| null` | ISO date string for when the subscription ends |
| `onClose` | `() => void` | Callback fired when the modal is dismissed |

### `formatEndDate` (internal)
Safely formats a nullable ISO date string using the shared `formatDate` utility. Returns `'—'` if `null` is provided or falls back to the raw string if parsing fails.

## Usage Example

```typescript
import { SubscriptionCancelledModal } from '@/app/components/subscription-cancelled-modal';

function SettingsPage() {
  const [showModal, setShowModal] = useState(true);

  return (
    <SubscriptionCancelledModal
      isOpen={showModal}
      endDate="2025-12-31T23:59:59Z"
      onClose={() => setShowModal(false)}
    />
  );
}
```

> **Note:** When `endDate` is `null` or unparseable, the end date renders as `—` to avoid displaying raw or broken date values.
