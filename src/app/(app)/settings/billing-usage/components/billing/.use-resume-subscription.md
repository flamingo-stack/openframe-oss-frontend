Provides a React hook for resuming a Stripe subscription that is scheduled for cancellation (`PENDING_CANCELLATION`), clearing the scheduled cancellation so the subscription auto-renews at the end of the current billing period.

## Key Components

- **`resumeSubscriptionMutation`** — GraphQL mutation (`resumeSubscription`) that clears a pending Stripe cancellation. Returns a Boolean; no Relay store auto-update occurs, so callers must manually refetch billing data.
- **`useResumeSubscription()`** — Hook that wraps the mutation with toast notifications for success and error states.
  - `mutate(options?)` — Triggers the mutation. Accepts an optional `onSuccess` callback invoked after a successful resume.
  - `isPending` — Boolean reflecting in-flight mutation state.
- **`ResumeSubscriptionOptions`** — Interface with an optional `onSuccess` callback for post-mutation side effects (e.g., refetching the billing query).

## Usage Example

```typescript
import { useResumeSubscription } from './use-resume-subscription';

function BillingActions({ refetchBilling }: { refetchBilling: () => void }) {
  const { mutate, isPending } = useResumeSubscription();

  return (
    <button
      disabled={isPending}
      onClick={() => mutate({ onSuccess: refetchBilling })}
    >
      {isPending ? 'Resuming...' : 'Resume Subscription'}
    </button>
  );
}
```

> **Note:** This hook is only valid while the subscription is still within its paid period (`PENDING_CANCELLATION` status). A fully cancelled subscription must go through the checkout flow instead.
