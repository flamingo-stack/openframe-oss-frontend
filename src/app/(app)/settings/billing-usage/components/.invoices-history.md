Client-side React component that renders a searchable, sortable data table of Stripe invoice history with status badges and direct links to hosted invoice PDFs.

## Key Components

### `InvoiceItem` (interface)
Data shape for a single invoice row, including Stripe invoice number, lifecycle status, amount (in major currency units), dates, and the hosted invoice URL.

### `invoiceAmount(invoice)`
Helper that returns `invoice.amountDue` directly — no unit conversion needed since the backend already returns major currency units (e.g., `11.92` USD).

### `statusTag(status)`
Maps Stripe lifecycle statuses (`InvoiceStatus` enum) to a `Tag` variant and display label. `OPEN` and `null` (legacy) both resolve to `warning / "Unpaid"`.

### `InvoicesHistory({ invoices })`
Main exported component. Features:
- **Client-side search** — filters by invoice number and amount (matches bare `11.92`, `$11.92`, etc.)
- **Five-column table** — Invoice, Due Date, Amount, Status (`Tag` badge), and an actions column with an external link to the Stripe-hosted invoice
- Returns `null` when the invoices list is empty

## Usage Example

```typescript
import { InvoicesHistory } from './invoices-history';

const invoices = [
  {
    id: 'inv_001',
    invoiceNumber: 'ACME-0042',
    status: 'paid',
    amountDue: 149.99,
    currency: 'usd',
    createdAt: '2024-01-15T00:00:00Z',
    dueDate: '2024-02-01T00:00:00Z',
    hostedInvoiceUrl: 'https://invoice.stripe.com/...',
  },
];

export default function BillingPage() {
  return <InvoicesHistory invoices={invoices} />;
}
```
