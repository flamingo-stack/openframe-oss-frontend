A client-side modal component for confirming subscription cancellation, collecting a cancellation reason, and displaying data-loss warnings with a live Stripe-sourced effective end date.

## Key Components

| Export / Component | Description |
|---|---|
| `CancelSubscriptionModal` | Main modal component — manages reason/comment state, lazy-loads the cancellation preview query, and renders all sub-sections |
| `CancelReason` | Union type of valid cancellation reasons: `TOO_EXPENSIVE`, `NOT_USING_ENOUGH`, `MISSING_FEATURE`, `TECHNICAL_ISSUES`, `OTHER` |
| `DataLossStats` | Interface describing counts of data at risk (devices, tickets, KB articles, scripts, policies, queries) |
| `CancellationEffectiveDate` | Internal Relay Suspense leaf that reads the preloaded `subscriptionCancellationPreview` query and renders the effective date |
| `DataLossBox` | Renders a warning box listing only non-zero data metrics; omitted entirely when all counts are zero |
| `DataLossSkeleton` | Mirrors `DataLossBox` structure during loading, preserving layout shape |
| `cancelSubscriptionModalPreviewQuery` | Relay GraphQL query fetching `subscriptionCancellationPreview` from Stripe |

## Usage Example

```typescript
import { CancelSubscriptionModal, type CancelReason, type DataLossStats } from './cancel-subscription-modal';

const stats: DataLossStats = {
  activeDevices: 42,
  tickets: 130,
  kbArticles: 8,
  scripts: 5,
  monitoringPolicies: 3,
  savedQueries: 0,
};

<CancelSubscriptionModal
  isOpen={isModalOpen}
  endDate="2025-08-31T00:00:00Z"
  stats={stats}
  isStatsLoading={false}
  isPending={isCancelling}
  onClose={() => setModalOpen(false)}
  onConfirm={(reason: CancelReason, comment: string) => {
    handleCancelSubscription(reason, comment);
  }}
/>
```

## Behavior Notes

- The `subscriptionCancellationPreview` query is loaded **lazily** on first modal open using `store-or-network`, avoiding redundant Stripe round-trips on repeated opens.
- The `DataLossBox` hides individual rows with zero counts, and is omitted entirely if no non-zero metrics exist.
- The confirm button is disabled until a `CancelReason` is selected. A comment textarea appears only when `OTHER` is chosen.
- Reason/comment state resets automatically when the modal closes.
