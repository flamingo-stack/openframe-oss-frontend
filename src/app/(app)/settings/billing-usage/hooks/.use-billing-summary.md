Transforms raw GraphQL subscription data into a structured billing summary used by billing UI components to render usage metrics, warnings, and status indicators.

## Key Components

**`useBillingSummary(subscription)`** — Main function that derives all billing display state from a `billingUsageViewQuery$data['subscription']` payload. Returns a flat, UI-ready object.


There is no usage-tier type any more: the only state the page reacts to is `device.overLimit` — a committed package with more devices under management than it covers. The 90%-of-limit "approaching" tier and every AI counterpart were removed.

## Return Shape

| Key | Description |
|---|---|
| `status` | Raw subscription status |
| `flags` | Boolean conveniences (`isTrial`, `isOverdue`, `hasPendingPlan`, etc.) |
| `device` | Devices usage metrics, overage, PAYG flag, and progress bar variant |
| `ai` | AI token usage metrics, overage, PAYG flag, and progress bar variant |
| `ui` | Warning messages array, overage block visibility, accent CSS classes |
| `billing` | Next payment, next billing date, pending invoice, trial/cancellation dates |
| `updatedPlan` | Pending downgrade quantities and start date |

## Usage Example

```typescript
import { useBillingSummary } from './use-billing-summary';

function BillingView({ subscription }) {
  const summary = useBillingSummary(subscription);

  const { device, ai, ui, flags, billing } = summary;

  // Device usage progress bar
  console.log(device.pct);            // e.g. 94
  console.log(device.overLimit);      // true when the package is exceeded
  console.log(device.progressVariant); // 'warning'

  // Warnings to surface in the UI
  console.log(billing.estimatedOverage); // Stripe's metered surplus for the period, in dollars

  // Billing dates
  console.log(billing.nextBillingDate);          // subscription.currentPeriodEnd, or null
  console.log(billing.cancellationEffectiveAt); // set only for PENDING_CANCELLATION / CANCELED
  console.log(flags.isOverdue);       // false
}
```
