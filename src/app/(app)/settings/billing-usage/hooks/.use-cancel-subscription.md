Provides a React hook that executes a GraphQL mutation to cancel a subscription and handles post-mutation Relay store invalidation.

## Key Components

- **`cancelSubscriptionMutation`** — GraphQL mutation definition targeting `cancelSubscription(input: CancelSubscriptionInput)`
- **`CancelSubscriptionOptions`** — Interface for optional mutation parameters: `reason`, `description`, and an `onSuccess` callback
- **`useCancelSubscription()`** — Primary exported hook returning `{ mutate, isPending }`

## Usage Example

```typescript
import { useCancelSubscription } from './use-cancel-subscription';

function CancelButton() {
  const { mutate, isPending } = useCancelSubscription();

  return (
    <button
      disabled={isPending}
      onClick={() =>
        mutate({
          reason: 'too_expensive',
          description: 'Monthly cost is too high',
          onSuccess: () => console.log('Subscription cancelled'),
        })
      }
    >
      {isPending ? 'Cancelling...' : 'Cancel Subscription'}
    </button>
  );
}
```

## Behavior Notes

- **Store invalidation** — Because the mutation returns a bare `Boolean` (not a typed object), Relay cannot automatically reconcile the updated `PENDING_CANCELLATION` state. On success, `commitLocalUpdate` is called to invalidate the entire Relay store, forcing all subscription-derived queries (billing view, subscription lock, etc.) to refetch on their next read.
- **Error handling** — On failure, a destructive toast notification is displayed via the `useToast` hook from `@flamingo-stack/openframe-frontend-core`.
- **`isPending`** — Reflects Relay's `isInFlight` state; useful for disabling UI during the request.
