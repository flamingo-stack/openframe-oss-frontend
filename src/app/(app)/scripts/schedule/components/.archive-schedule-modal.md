A confirmation modal for archiving a schedule, wrapping the shared `ConfirmDialog` component with archive-specific copy and destructive styling.

## Key Components

- **`ArchiveScheduleModal`** — Named export; renders a pre-configured `ConfirmDialog` that transitions a schedule's status to `ARCHIVED`. The action is non-destructive and reversible via a Restore flow.

**Props (`ArchiveScheduleModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle open state |
| `onConfirm` | `() => void` | Handler triggered on confirmation |
| `isPending` | `boolean?` | Shows "Archiving…" label during async operation |

## Usage Example

```typescript
import { ArchiveScheduleModal } from './archive-schedule-modal';

function ScheduleActions({ scheduleId }: { scheduleId: string }) {
  const [open, setOpen] = useState(false);
  const { mutate, isPending } = useArchiveSchedule();

  return (
    <>
      <button onClick={() => setOpen(true)}>Archive</button>
      <ArchiveScheduleModal
        open={open}
        onOpenChange={setOpen}
        onConfirm={() => mutate(scheduleId)}
        isPending={isPending}
      />
    </>
  );
}
```

## Notes

- Uses `variant="destructive"` on `ConfirmDialog` for visual emphasis, even though the archive action is reversible.
- The modal renders no local state — open/close control is fully delegated to the parent.
