Displays schedule metadata (date, time, repeat interval, and supported OS platforms) in a responsive info bar layout.

## Key Components

| Export | Description |
|---|---|
| `ScheduleInfoBar` | Renders a 4-column info bar from a `ScriptScheduleDetail` object, auto-formatting date/time and repeat label |
| `ScheduleInfoBarFromData` | Extended variant that also displays schedule name and an optional note row above the 4-column grid |
| `ScheduleInfoBarProps` | Props interface accepting a `ScriptScheduleDetail` schedule object |
| `ScheduleInfoBarFromDataProps` | Props interface accepting pre-formatted primitive values (`name`, `note`, `date`, `time`, `repeat`, `platforms`) |

Both components use `OSTypeBadgeGroup` from `@flamingo-stack/openframe-frontend-core` to render platform icons.

## Usage Example

```typescript
// From a ScriptScheduleDetail object
import { ScheduleInfoBar } from './schedule-info-bar';

<ScheduleInfoBar schedule={scheduleDetail} />
```

```typescript
// From pre-formatted data (e.g. in a confirmation/preview context)
import { ScheduleInfoBarFromData } from './schedule-info-bar';

<ScheduleInfoBarFromData
  name="Nightly Patch Run"
  note="Prod servers only"
  date="Jul 15, 2025"
  time="02:00 AM"
  repeat="Every day"
  platforms={['windows', 'linux']}
/>
```
