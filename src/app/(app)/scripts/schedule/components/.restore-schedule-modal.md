Confirmation modal for restoring an archived schedule back to active status, built on top of the shared `ConfirmDialog` component.

## Key Components

### `RestoreScheduleModal`
A thin wrapper around `ConfirmDialog` that pre-configures copy and behavior for the restore-schedule action.

**Props (`RestoreScheduleModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle open state |
| `onConfirm` | `() => void` | Called when the user confirms the restore action |
| `isPending` | `boolean?` | Shows loading state with "Restoring..." label |

## Usage Example

```typescript
import { RestoreScheduleModal } from './restore-schedule-modal';

function ScheduleActions({ scheduleId }: { scheduleId: string }) {
  const [open, setOpen] = useState(false);
  const { mutate, isPending } = useRestoreSchedule();

  return (
    <>
      <button onClick={() => setOpen(true)}>Restore</button>
      <RestoreScheduleModal
        open={open}
        onOpenChange={setOpen}
        onConfirm={() => mutate(scheduleId)}
        isPending={isPending}
      />
    </>
  );
}
```

## Notes

- Uses `variant="default"` (non-destructive styling), appropriate since restoring is a safe, reversible action.
- Delegates all rendering and accessibility handling to [`ConfirmDialog`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/components/shared/confirm-dialog.tsx).
