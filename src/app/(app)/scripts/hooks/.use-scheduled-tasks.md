React Query hook for fetching and managing scheduled tasks associated with a script, with stub API functions pending OpenFrame RMM backend integration.

## Key Components

### Types

- **`ScheduledTask`** — Full scheduled task model supporting `daily`, `weekly`, `monthly`, and `runonce` task types, with recurrence fields, actions, and agent assignment
- **`ScheduledTaskAction`** — Describes a script action within a task (script ID, timeout, args, env vars, user context)

### Query Keys

- **`scheduledTasksQueryKeys`** — Structured query key factory with `all` and `byScript(scriptId)` selectors for cache targeting

### API Functions *(stubs)*

- **`fetchScheduledTasksByScript`** — Always returns `[]`; no backend wired yet
- **`deleteScheduledTaskApi`** — Calls `rejectScriptsMigrationPending()` on every invocation; delete is blocked until the OpenFrame RMM API is available

### Hook

- **`useScheduledTasks(scriptId)`** — Composes a read query and a delete mutation, exposing normalized loading/error states and a `deleteTask` callback

## Usage Example

```typescript
import { useScheduledTasks } from '@/hooks/use-scheduled-tasks';

function ScriptTaskList({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
  } = useScheduledTasks(scriptId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return scheduledTasks.map(task => (
    <TaskRow
      key={task.id}
      task={task}
      onDelete={() =>
        deleteTask(String(task.id), {
          onSuccess: () => console.log('Deleted'),
          onError: (err) => console.error(err.message),
        })
      }
      isDeleting={isDeleting}
    />
  ));
}
```

> **⚠️ Migration Note:** Both read and delete operations are stubs. Reads silently return an empty array; delete calls will throw via `rejectScriptsMigrationPending()` until the OpenFrame RMM scripts API is connected. See [`scripts-migration.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/lib/scripts-migration.ts) for details.
