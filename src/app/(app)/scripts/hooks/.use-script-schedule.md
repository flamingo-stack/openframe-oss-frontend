React Query hooks for fetching script schedule data, currently returning stub/empty responses pending the OpenFrame RMM scripts API integration.

## Key Components

### Query Keys

`scriptScheduleQueryKeys` — Structured cache key factory for TanStack Query:

| Key | Description |
|-----|-------------|
| `all` | Root key for all script schedule queries |
| `list()` | All schedules list |
| `detail(id)` | Single schedule by ID |
| `agents(id)` | Agents associated with a schedule |
| `history(id, limit, offset)` | Paginated execution history |

### Hooks

| Hook | Returns | Notes |
|------|---------|-------|
| `useScriptSchedules()` | `{ schedules, isLoading, error, refetch }` | Always returns `[]` (migration stub) |
| `useScriptSchedule(id)` | `{ schedule, isLoading, error, refetch }` | Rejects with migration pending error |
| `useScriptScheduleAgents(id)` | `{ agents, isLoading, error, refetch }` | Always returns `[]` (migration stub) |
| `useScriptScheduleHistory(id, options?)` | `{ history, total, isLoading, error, refetch }` | Rejects with migration pending error; default `limit: 50, offset: 0` |

## Usage Example

```typescript
// List all schedules (returns empty array until RMM API is wired)
const { schedules, isLoading, error } = useScriptSchedules();

// Fetch a single schedule (will error with migration-pending until API is ready)
const { schedule, error } = useScriptSchedule('schedule-123');

// Fetch paginated history
const { history, total } = useScriptScheduleHistory('schedule-123', {
  limit: 25,
  offset: 0,
});
```

> **⚠️ Migration Stub:** All API functions are placeholders. List and agents reads return empty arrays; single-schedule and history reads reject via `rejectScriptsMigrationPending()` so their pages render a not-found/empty state. See [`scripts-migration.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/lib/scripts-migration.ts) for details.
