TanStack Query mutation hooks for script schedule CRUD and agent management operations, currently stubbed to surface a "migration pending" error while the OpenFrame RMM scripts API backend is wired up.

## Key Components

### API Stubs (Migration Pending)
All API functions delegate to `rejectScriptsMigrationPending()` — they intentionally reject so the UI surfaces a clear toast instead of a silent no-op.

| Function | Description |
|---|---|
| `createScriptScheduleApi` | Creates a new script schedule |
| `updateScriptScheduleApi` | Updates an existing schedule by ID |
| `deleteScriptScheduleApi` | Deletes a schedule by ID |
| `replaceScheduleAgentsApi` | Replaces the full agent list on a schedule |
| `addScheduleAgentsApi` | Adds agents to a schedule |
| `removeScheduleAgentsApi` | Removes agents from a schedule |

### Exported Hooks

| Hook | Cache Invalidation on Success |
|---|---|
| `useCreateScriptSchedule` | `scriptScheduleQueryKeys.all` |
| `useUpdateScriptSchedule` | `detail(id)` + `all` |
| `useDeleteScriptSchedule` | `all` |
| `useReplaceScheduleAgents` | `agents(id)` + `detail(id)` + `all` |
| `useAddScheduleAgents` | `agents(id)` + `detail(id)` |
| `useRemoveScheduleAgents` | `agents(id)` + `detail(id)` |

## Usage Example

```typescript
import {
  useCreateScriptSchedule,
  useUpdateScriptSchedule,
  useDeleteScriptSchedule,
  useAddScheduleAgents,
} from './use-script-schedule-mutations';

function ScheduleManager() {
  const createSchedule = useCreateScriptSchedule();
  const updateSchedule = useUpdateScriptSchedule();
  const deleteSchedule = useDeleteScriptSchedule();
  const addAgents = useAddScheduleAgents();

  // Note: all mutations currently reject with a migration-pending error
  const handleCreate = () =>
    createSchedule.mutate({ name: 'Nightly Patch', scriptId: 'script_123', cron: '0 2 * * *' });

  const handleAddAgent = () =>
    addAgents.mutate({ id: 'schedule_456', agents: ['agent_001', 'agent_002'] });
}
```
