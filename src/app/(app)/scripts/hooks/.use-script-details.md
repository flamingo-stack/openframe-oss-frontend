Provides a React Query hook for fetching individual script details, currently stubbed to reject with a migration-pending error while the OpenFrame RMM scripts API is being wired up.

## Key Components

- **`ScriptDetails`** — Interface defining the full shape of a script record, including metadata (`id`, `name`, `shell`, `category`), execution config (`args`, `default_timeout`, `run_as_user`), and content (`script_body`, `script_hash`, `env_vars`).
- **`scriptDetailsQueryKeys`** — Structured query key factory for React Query cache management; provides `all` and `detail(scriptId)` keys.
- **`fetchScriptDetails`** — Internal async function that currently delegates to `rejectScriptsMigrationPending()`, causing all detail/edit/run pages to show a not-found state until the backend API is available.
- **`useScriptDetails`** — Primary exported hook that wraps the query and exposes a simplified interface.

## Usage Example

```typescript
import { useScriptDetails } from './use-script-details';

function ScriptDetailPage({ scriptId }: { scriptId: string }) {
  const { scriptDetails, isLoading, error } = useScriptDetails(scriptId);

  if (isLoading) return <Spinner />;
  if (error) return <NotFound message={error} />;

  return <pre>{scriptDetails?.script_body}</pre>;
}
```

> **Note:** This hook is intentionally non-functional pending the OpenFrame RMM scripts API integration. All calls will reject immediately, triggering the `error` state. See [`scripts-migration.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/scripts-migration.ts) for migration context.
