Provides a React Query hook for fetching and managing the scripts list, currently returning an empty array as a placeholder until the OpenFrame RMM scripts API is integrated.

## Key Components

- **`scriptsQueryKeys`** — Centralized query key registry (`['scripts']`) for cache management and invalidation.
- **`fetchAllScripts`** — Stub async function returning an empty `ScriptEntry[]` array; temporary until the OpenFrame RMM scripts API is wired up.
- **`useScripts`** — Primary hook exposing the scripts list, loading/error states, and cache control methods.

## Usage Example

```typescript
import { useScripts } from '@/features/scripts/hooks/use-scripts';

function ScriptsList() {
  const { scripts, isLoading, error, refetch, invalidate } = useScripts();

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <>
      {scripts.length === 0 ? (
        <p>No scripts yet</p>
      ) : (
        scripts.map((script) => <div key={script.id}>{script.name}</div>)
      )}
      <button onClick={() => refetch()}>Refresh</button>
      <button onClick={() => invalidate()}>Invalidate Cache</button>
    </>
  );
}
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `scripts` | `ScriptEntry[]` | List of scripts; defaults to `[]` when undefined |
| `isLoading` | `boolean` | `true` while a fetch is in-flight |
| `error` | `string \| null` | Error message or `null` if none |
| `refetch` | `function` | Manually re-triggers the query |
| `invalidate` | `function` | Invalidates the `['scripts']` cache entry |

> **Note:** `fetchAllScripts` is a stub returning `[]`. See `scripts-migration.ts` for context on the pending RMM API integration.
