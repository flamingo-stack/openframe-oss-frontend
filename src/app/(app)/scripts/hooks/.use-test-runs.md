Manages the lifecycle of a single script test run, including elapsed-time tracking, abort control, and error handling for the script execution UI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useTestRuns` | Hook | Accepts a `getFormValues` callback and returns test run state with run/stop/clear handlers |
| `testRun` | `TestRunData \| null` | Current test run state including status, output lines, and elapsed time |
| `handleRunTest` | `(device: SelectedTestDevice) => Promise<void>` | Initiates a new test run against a target device, aborting any in-progress run first |
| `handleStopRun` | `() => void` | Aborts the active run and appends an abort message to the output |
| `clearTestRun` | `() => void` | Resets `testRun` state to `null` |

### Internal Mechanics

- **`AbortController`** (`abortControllerRef`) — cancels in-flight execution; also gates the run body via `controller.signal.aborted`.
- **Elapsed timer** (`timerRef`) — a 1-second `setInterval` that updates `elapsedSeconds` only while `status === 'running'`.
- **Migration stub** — `rejectScriptsMigrationPending()` is called in place of a real backend until the OpenFrame RMM scripts API is available. Any thrown error surfaces in the run output and triggers a destructive toast.

## Usage Example

```typescript
import { useTestRuns } from './use-test-runs';
import { useForm } from 'react-hook-form';

function ScriptEditor() {
  const { getValues } = useForm<EditScriptFormData>();
  const { testRun, handleRunTest, handleStopRun, clearTestRun } =
    useTestRuns(getValues);

  const device: SelectedTestDevice = {
    deviceName: 'DESKTOP-ABC',
    agentToolId: 'agent-42',
  };

  return (
    <>
      <button onClick={() => handleRunTest(device)}>Run Test</button>
      {testRun?.status === 'running' && (
        <button onClick={handleStopRun}>Stop</button>
      )}
      {testRun && <pre>{testRun.output.join('\n')}</pre>}
      <button onClick={clearTestRun}>Clear</button>
    </>
  );
}
```

> **Note:** Test execution currently rejects immediately via `rejectScriptsMigrationPending()`. Wire the real API call in place of that stub once the OpenFrame RMM scripts backend is available. See [`scripts-migration.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/scripts-migration.ts) for details.
