Provides filtering logic for a list of devices, supporting search by name/OS and multi-select organization filtering, with lazy organization data fetching.

## Key Components

### `useDeviceFilter(options)`

Main hook that manages device filtering state and derived data.

**Options:**

| Parameter | Type | Description |
|---|---|---|
| `devices` | `Device[]` | Full list of devices to filter |
| `enabled` | `boolean` | When `false`, skips fetching organizations (e.g. when a modal is closed). Defaults to `true` |

**Returns:**

| Property | Type | Description |
|---|---|---|
| `searchTerm` | `string` | Current text search value |
| `setSearchTerm` | `setter` | Updates the search term |
| `selectedOrgIds` | `string[]` | Currently selected organization IDs |
| `setSelectedOrgIds` | `setter` | Updates selected org IDs |
| `organizationOptions` | `{ label, value }[]` | Mapped options for org multi-select UI |
| `filteredDevices` | `Device[]` | Devices after applying all active filters |

## Usage Example

```typescript
import { useDeviceFilter } from './use-device-filter';

function DeviceList({ devices, isOpen }: { devices: Device[]; isOpen: boolean }) {
  const {
    searchTerm,
    setSearchTerm,
    selectedOrgIds,
    setSelectedOrgIds,
    organizationOptions,
    filteredDevices,
  } = useDeviceFilter({ devices, enabled: isOpen });

  return (
    <>
      <input value={searchTerm} onChange={e => setSearchTerm(e.target.value)} />
      <OrgMultiSelect
        options={organizationOptions}
        value={selectedOrgIds}
        onChange={setSelectedOrgIds}
      />
      {filteredDevices.map(d => <DeviceRow key={d.id} device={d} />)}
    </>
  );
}
```

Search matches against `displayName`, `hostname`, `osType`, and `operating_system` fields. Organization filtering is skipped when `selectedOrgIds` is empty.
