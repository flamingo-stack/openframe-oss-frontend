Manages multi-select state for a list of devices, tracking selected device IDs in a `Set` and exposing helpers to toggle, bulk-select, and clear selections.

## Key Components

| Export | Type | Description |
|---|---|---|
| `useDeviceSelection` | Hook | Returns selection state and control callbacks |
| `selectedIds` | `Set<string>` | Set of currently selected device IDs |
| `selectedCount` | `number` | Convenience count of selected items |
| `toggleSelect` | `(id: string) => void` | Adds or removes a single device ID |
| `selectAllDisplayed` | `(devices: Device[]) => void` | Selects all devices in the provided array using their primary ID |
| `clearSelection` | `() => void` | Resets selection to empty |

## Usage Example

```typescript
import { useDeviceSelection } from './use-device-selection';

function DeviceTable({ devices }: { devices: Device[] }) {
  const {
    selectedIds,
    selectedCount,
    toggleSelect,
    selectAllDisplayed,
    clearSelection,
  } = useDeviceSelection();

  return (
    <>
      <button onClick={() => selectAllDisplayed(devices)}>
        Select All ({devices.length})
      </button>
      <button onClick={clearSelection} disabled={selectedCount === 0}>
        Clear ({selectedCount})
      </button>
      {devices.map(device => (
        <DeviceRow
          key={device.id}
          device={device}
          isSelected={selectedIds.has(device.id)}
          onToggle={() => toggleSelect(device.id)}
        />
      ))}
    </>
  );
}
```

## Notes

- All callbacks are memoised with `useCallback`, preventing unnecessary re-renders in child components.
- Primary IDs are resolved via `getDevicePrimaryId` to ensure consistent keying regardless of which ID field is populated on a given `Device` object.
