Fetches and combines script details with a filtered list of compatible devices for the "run script" workflow, coordinating two async data sources into a single hook.

## Key Components

**`runScriptDataQueryKeys`**
Query key factory scoping device queries by `scriptId` to ensure correct cache isolation.

**`fetchDevicesForScript(supportedPlatforms)`**
Internal async function that maps script platforms to OS types, then queries the GraphQL `/api/graphql` endpoint for up to 100 online/offline devices. Throws on HTTP errors or GraphQL errors.

**`useRunScriptData({ scriptId })`**
Primary export. Composes [`useScriptDetails`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/features/scripts/hooks/use-script-details.ts) with a dependent `useQuery` that fetches compatible devices only after script details resolve. Returns a flat object covering both data sources.

| Return Value | Type | Description |
|---|---|---|
| `scriptDetails` | `ScriptDetails \| undefined` | Resolved script metadata |
| `isLoadingScript` | `boolean` | Script fetch in-flight |
| `scriptError` | `Error \| null` | Script fetch error |
| `devices` | `Device[]` | Compatible devices (defaults to `[]`) |
| `isLoadingDevices` | `boolean` | Devices fetch in-flight |
| `devicesError` | `string \| null` | Devices fetch error message |

## Usage Example

```typescript
import { useRunScriptData } from './use-run-script-data';

function RunScriptModal({ scriptId }: { scriptId: string }) {
  const {
    scriptDetails,
    isLoadingScript,
    devices,
    isLoadingDevices,
    devicesError,
  } = useRunScriptData({ scriptId });

  if (isLoadingScript || isLoadingDevices) return <Spinner />;
  if (devicesError) return <ErrorMessage message={devicesError} />;

  return (
    <DevicePicker
      script={scriptDetails}
      compatibleDevices={devices}
    />
  );
}
```

> **Note:** Device fetching is gated on `scriptDetails` being available (`enabled: !!scriptDetails`), so both requests are sequenced automatically. A TODO exists to restore OpenFrame-RMM-agent–based device ordering once the run-script feature lands.
