React hook managing form state, validation, and submission logic for creating and editing RMM scripts, with migration-pending stubs in place of live API calls.

## Key Components

- **`useEditScriptForm`** — Primary export. Accepts `scriptId`, `scriptDetails`, and `isEditMode` to configure the form for either create or edit workflows.
- **`createScriptApi` / `updateScriptApi`** — Stub API functions that immediately reject via `rejectScriptsMigrationPending()`, surfacing a toast until the OpenFrame RMM scripts API is wired up.
- **`form`** — `react-hook-form` instance with Zod validation via `editScriptSchema` and `EDIT_SCRIPT_DEFAULT_VALUES`.
- **`createMutation` / `updateMutation`** — TanStack Query mutations handling optimistic cache invalidation and toast feedback on success or error.
- **`onSubmit`** — Normalizes form data (filters blank args/env vars, serializes key-value pairs to `key value` and `key=value` strings) before routing to the correct mutation.
- **`handleSave`** — Stable callback that triggers `handleSubmit(onSubmit)()` for external save button binding.

## Usage Example

```typescript
import { useEditScriptForm } from './use-edit-script-form';

function EditScriptPage({ scriptId, scriptDetails, isEditMode }) {
  const { form, isSubmitting, handleSave } = useEditScriptForm({
    scriptId,
    scriptDetails,
    isEditMode,
  });

  return (
    <Form {...form}>
      {/* form fields */}
      <Button onClick={handleSave} disabled={isSubmitting}>
        {isEditMode ? 'Update Script' : 'Create Script'}
      </Button>
    </Form>
  );
}
```

> **Note:** Both create and update operations currently reject with a migration-pending error. See [`scripts-migration.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/features/scripts/lib/scripts-migration.ts) for details on the pending OpenFrame RMM API integration.
