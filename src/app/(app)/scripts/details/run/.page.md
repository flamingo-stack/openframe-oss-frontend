Thin Next.js client page that extracts a `scriptId` from the URL query string and delegates all rendering to `RunScriptView`.

## Key Components

- **`RunScriptPage`** — Default export; a client component that reads the `id` query parameter and passes it to the script execution view.

## Usage Example

```typescript
// Accessed via: /run-script?id=<scriptId>
// The page automatically reads `?id=` and forwards it to RunScriptView

// RunScriptView handles all UI and execution logic for the given script
<RunScriptPage /> // renders <RunScriptView scriptId="abc123" />
```

## Notes

- Requires `'use client'` because it uses [`useSearchParams`](https://nextjs.org/docs/app/api-reference/functions/use-search-params), which is a client-side hook.
- Falls back to an empty string (`''`) if no `id` param is present — callers should ensure the query param is always provided.
