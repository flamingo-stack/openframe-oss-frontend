A Next.js client-side page component that extracts a script ID from the URL query string and renders the script details view.

## Key Components

- **`ScriptDetailsPage`** — Default export; reads the `id` query parameter via `useSearchParams` and passes it to `ScriptDetailsView`
- **`ScriptDetailsView`** — Imported component responsible for displaying full script details for the given ID

## Usage Example

```typescript
// Accessed via URL: /scripts/details?id=abc123
// The page automatically extracts "abc123" and passes it to ScriptDetailsView

<ScriptDetailsPage />
// Internally renders: <ScriptDetailsView scriptId="abc123" />
```

## Notes

- Marked as `'use client'` since it uses the `useSearchParams` hook, which requires a browser context
- Falls back to an empty string (`''`) if the `id` param is absent, so `ScriptDetailsView` should handle the empty case gracefully
