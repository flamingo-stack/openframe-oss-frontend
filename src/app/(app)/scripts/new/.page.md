A thin Next.js route page that renders the new script creation flow by delegating to the shared `EditScriptPage` component with no existing script ID.

## Key Components

- **`NewScriptPageWrapper`** – Default page export that mounts `EditScriptPage` in "create" mode by passing `scriptId={null}`.

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to /scripts/new
// No props required — scriptId=null signals "create new" mode
<NewScriptPageWrapper />
```

> See [`EditScriptPage`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/scripts/components/script/edit-script-page.tsx) for the full create/edit implementation.
