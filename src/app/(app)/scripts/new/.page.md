A thin Next.js route page wrapper that renders the `EditScriptPage` component in "create new" mode by passing `null` as the `scriptId`.

## Key Components

- **`NewScriptV2PageWrapper`** — Default-exported client component that mounts `EditScriptPage` with no existing script ID, signaling a new script creation flow.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to the new script route.
// No props required — scriptId is hardcoded to null to trigger creation mode.
import NewScriptV2PageWrapper from './page';

// Equivalent to:
<EditScriptPage scriptId={null} />
```

## Notes

- Marked `'use client'` to ensure it runs in the browser context.
- All creation logic and UI are delegated to [`EditScriptPage`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/scripts/components/edit-script-page.tsx); this file exists solely to satisfy Next.js file-based routing.
