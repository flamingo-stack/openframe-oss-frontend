Temporary migration guard for the legacy `/scripts` UI layer, providing a standardized error and helper used to block all backend calls while the scripts feature awaits its OpenFrame RMM implementation.

## Key Components

| Export | Type | Description |
|---|---|---|
| `SCRIPTS_MIGRATION_PENDING_MESSAGE` | `string` | Canonical user-facing message displayed as a toast when any scripts action is attempted |
| `rejectScriptsMigrationPending` | `() => never` | Throws the migration error; typed `never` so it satisfies any expected return type |

## Usage Example

```typescript
import {
  rejectScriptsMigrationPending,
  SCRIPTS_MIGRATION_PENDING_MESSAGE,
} from './scripts-migration';

// In a data hook — reject writes/runs with a clear user message
async function runScript(id: string): Promise<void> {
  return rejectScriptsMigrationPending();
}

// In a list hook — return empty results silently
async function fetchScripts(): Promise<Script[]> {
  return [];
}

// In a component — check the message for toast display logic
if (error.message === SCRIPTS_MIGRATION_PENDING_MESSAGE) {
  showToast({ type: 'warning', message: error.message });
}
```
