Defines TypeScript types, Zod validation schemas, and utility functions for the script scheduling feature, covering API response shapes, form data structures, and payload transformation helpers.

## Key Components

### API Response Types
| Type | Description |
|---|---|
| `ScriptScheduleListItem` | Summary item for schedule list views |
| `ScriptScheduleDetail` | Full schedule detail including actions and assigned agents |
| `ScriptScheduleHistoryEntry` | Single execution history record with status and output |
| `ScriptScheduleAgent` | Agent assigned to a schedule |
| `AgentsModifyResponse` | Response after modifying agent assignments |

### Constants
| Export | Description |
|---|---|
| `WEEKDAYS` | Bit-indexed weekday labels (Mon=0 … Sun=6) |
| `PLATFORMS` | Supported OS platforms: `windows`, `linux`, `darwin` |
| `PLATFORM_LABELS` | Human-readable platform display names |
| `REPEAT_PERIOD_OPTIONS` | UI options for repeat period selector |

### Zod Schemas
| Schema | Description |
|---|---|
| `createScheduleFormSchema` | Full form validation schema for creating/editing a schedule |
| `scheduleActionSchema` | (internal) Validates a single script action entry |

### Utility Functions
| Function | Description |
|---|---|
| `toZuluDateString(date)` | Formats a `Date` to `"yyyy-MM-dd'T'HH:mm:ss'Z'"` treating local components as UTC |
| `parseZuluToLocalDate(iso)` | Parses a UTC ISO string into a local `Date` preserving UTC time components |
| `formatScheduleDate(iso)` | Returns locale-formatted `{ date, time }` strings pinned to UTC |
| `getRepeatLabel(schedule)` | Returns human-readable repeat label (e.g. `"3 Days"`, `"Monthly"`) |
| `buildTaskTypeFromForm(...)` | Derives `ScriptScheduleTaskType` from form repeat settings |
| `scheduleDetailToFormData(...)` | Converts an API `ScriptScheduleDetail` into `CreateScheduleFormData` for pre-filling edit forms |
| `buildCreatePayload(...)` | Transforms validated form data into a `CreateScriptSchedulePayload` for the API |

## Usage Example

```typescript
import {
  createScheduleFormSchema,
  buildCreatePayload,
  scheduleDetailToFormData,
  formatScheduleDate,
} from './script-schedule.types';

// Validate and build API payload from form submission
const parsed = createScheduleFormSchema.parse(formData);
const payload = buildCreatePayload(parsed);

// Pre-fill an edit form from an existing schedule
const formDefaults = scheduleDetailToFormData(scheduleDetail);

// Display a schedule's run time in the UI
const { date, time } = formatScheduleDate(scheduleDetail.run_time_date);
// e.g. { date: "06/15/2025", time: "02:30 AM" }
```

> **Note on date handling:** `toZuluDateString` and `parseZuluToLocalDate` intentionally treat the date picker value as UTC — no timezone shift is applied. This ensures the stored and displayed times always match what the user entered.
