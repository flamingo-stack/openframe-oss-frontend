Defines Zod validation schemas, TypeScript types, and default values for the edit script form, ensuring runtime validation of script configuration fields.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `scriptArgumentSchema` | Zod schema | Validates individual script arguments/env vars with `id`, `key`, and `value` string fields |
| `editScriptSchema` | Zod schema | Full form validation schema with constraints (e.g. timeout 1–86400s, at least one platform) |
| `EditScriptFormData` | TypeScript type | Inferred type from `editScriptSchema` for type-safe form handling |
| `CATEGORIES` | `string[]` | Predefined script category options available in the form |
| `EDIT_SCRIPT_DEFAULT_VALUES` | `EditScriptFormData` | Blank/default form state used when initializing the edit script form |

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import {
  editScriptSchema,
  EDIT_SCRIPT_DEFAULT_VALUES,
  type EditScriptFormData,
} from './edit-script.types';

const form = useForm<EditScriptFormData>({
  resolver: zodResolver(editScriptSchema),
  defaultValues: EDIT_SCRIPT_DEFAULT_VALUES,
});

// Access validated data
const onSubmit = (data: EditScriptFormData) => {
  console.log(data.tag_ids);       // string[]
  console.log(data.default_timeout); // number, validated 1–86400
};
```

> **Note:** `args` and `env_vars` both reuse `scriptArgumentSchema`, sharing the same `{ id, key, value }` shape. `tag_ids` maps to `tagIds` on the API layer.
