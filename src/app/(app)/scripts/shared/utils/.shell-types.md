Defines the shell type configuration for the Scripts v2 UI, providing a self-contained list of supported shells with their icons, labels, and lookup utilities — independent of the core library's shell definitions.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SCRIPT_SHELL_TYPES` | `ShellTypeDefinition[]` | Ordered array of shell definitions for PowerShell, CMD, and Bash with v2 icons |
| `scriptShellType` | `function` | Resolves a `ShellTypeDefinition` by lowercase shell value (e.g. `'cmd'`) |
| `scriptShellLabel` | `function` | Returns the display label for a shell value, falling back to the raw value string |

**Shell entries:**

| Shell | Label | Value |
|-------|-------|-------|
| `ScriptShell.POWERSHELL` | PowerShell | `powershell` |
| `ScriptShell.CMD` | CMD | `cmd` |
| `ScriptShell.BASH` | Bash | `bash` |

## Usage Example

```typescript
import {
  SCRIPT_SHELL_TYPES,
  scriptShellType,
  scriptShellLabel,
} from './shell-types';

// Populate a shell selector
const options = SCRIPT_SHELL_TYPES; // PowerShell, CMD, Bash

// Resolve a full definition (e.g. from a saved script record)
const definition = scriptShellType('powershell');
// → { id: ScriptShell.POWERSHELL, label: 'PowerShell', value: 'powershell', icon: PowershellLogoGreyIcon }

// Display-safe label with fallback for unknown/legacy values
const label = scriptShellLabel('bash');   // → 'Bash'
const legacy = scriptShellLabel('zsh');   // → 'zsh' (raw fallback)
```

> **Design note:** Scripts v2 intentionally owns this list rather than filtering the core `SHELL_TYPES`. This enforces the product requirement of using the `CMD` label (not "Batch"), the v2 icon set, and a grey PowerShell glyph — without leaking filter logic to call sites.
