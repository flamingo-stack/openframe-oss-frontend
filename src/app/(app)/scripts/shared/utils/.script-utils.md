Utility functions for mapping script platform identifiers to OS type filter values and display labels used across the OpenFrame frontend.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AVAILABLE_PLATFORMS` | re-export | Platform list from `@/lib/platforms` |
| `DISABLED_PLATFORMS` | re-export | Disabled platform list from `@/lib/platforms` |
| `mapPlatformsToOsTypes` | function | Maps script platform strings to device OS type filter values |
| `mapPlatformsForDisplay` | function | Maps script platform strings to human-readable display labels |

## Usage Example

```typescript
import { mapPlatformsToOsTypes, mapPlatformsForDisplay } from '@/lib/script-utils';

const scriptPlatforms = ['windows', 'darwin', 'linux'];

// For device OS type filtering
mapPlatformsToOsTypes(scriptPlatforms);
// → ['WINDOWS', 'MAC_OS']  (linux has no mapping, filtered out)

// For display in UI
mapPlatformsForDisplay(scriptPlatforms);
// → ['Windows', 'macOS', 'Linux']
```

## Notes

- `mapPlatformsToOsTypes` silently drops `linux` — there is no corresponding `LINUX` OS type in the device filter schema.
- Both functions normalize input with `.toLowerCase()`, making them case-insensitive.
- Unknown/unrecognized platform strings are filtered out via the `.filter((v): v is string => !!v)` guard.
