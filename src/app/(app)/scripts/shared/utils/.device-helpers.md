Utility functions for resolving device identifiers, normalizing operating system strings, and determining execution context from a set of `Device` objects.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `getDevicePrimaryId` | `(device: Device) => string` | Returns the best available device identifier, preferring `machineId` → `agent_id` → `id` |
| `normalizeOsOrNull` | `(os?: string) => 'windows' \| 'linux' \| 'darwin' \| null` | Maps a raw OS string to a platform ID, returning `null` for unrecognized values instead of defaulting |
| `resolveOsTypeFromDevices` | `(devices: Device[]) => 'windows' \| 'linux' \| 'darwin' \| 'all'` | Determines a shared platform across a device set, returning `'all'` for mixed or unknown OS combinations |
| `resolveShellForExecution` | `(resolvedOsType: string, scriptShell?: string) => string` | Selects `powershell`, `cmd`, or `/bin/bash` based on the resolved OS type and an optional shell preference |

## Usage Example

```typescript
import {
  getDevicePrimaryId,
  normalizeOsOrNull,
  resolveOsTypeFromDevices,
  resolveShellForExecution,
} from './device-helpers';

// Resolve the best available ID for a device
const id = getDevicePrimaryId(device); // e.g. "abc-123"

// Normalize a raw OS string — returns null for unrecognized values
const platform = normalizeOsOrNull('Ubuntu 22.04'); // 'linux'
const unknown  = normalizeOsOrNull('ChromeOS');      // null

// Determine shared OS across selected devices
const osType = resolveOsTypeFromDevices(selectedDevices);
// 'windows' | 'linux' | 'darwin' | 'all' (mixed)

// Pick the right shell for script execution
const shell = resolveShellForExecution(osType, 'powershell');
// 'powershell' (Windows + preference) | 'cmd' (Windows default) | '/bin/bash' (Unix)
```

**Key design note:** `normalizeOsOrNull` intentionally diverges from `normalizeDevicePlatform` by returning `null` rather than defaulting to `'darwin'`, allowing `resolveOsTypeFromDevices` to correctly identify mixed-platform device sets without false positives.
