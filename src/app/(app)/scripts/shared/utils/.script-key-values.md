Utility functions for converting between flat `key=value` string arrays and structured `ScriptArgument` objects used in script argument handling.

## Key Components

### `parseKeyValues(arr, separator)`
Parses an array of delimiter-separated strings into `ScriptArgument[]`. Each item is split on the first occurrence of `separator` (default `=`), producing an object with a generated `id`, `key`, and `value`. Items without the separator are treated as key-only arguments with an empty value.

### `serializeKeyValues(pairs, separator)`
Converts a `ScriptArgument[]` back into a flat string array. Pairs with empty or whitespace-only keys are filtered out. Pairs with no value are serialized as the key alone.

## Usage Example

```typescript
import { parseKeyValues, serializeKeyValues } from './script-key-values';

// Parse raw CLI-style arguments
const args = parseKeyValues(['timeout=30', 'verbose', 'mode=debug']);
// [
//   { id: 'arg-0', key: 'timeout', value: '30' },
//   { id: 'arg-1', key: 'verbose', value: '' },
//   { id: 'arg-2', key: 'mode', value: 'debug' },
// ]

// Serialize back to string array
const raw = serializeKeyValues(args);
// ['timeout=30', 'verbose', 'mode=debug']

// Custom separator
const envPairs = parseKeyValues(['HOST:localhost', 'PORT:8080'], ':');
```

## Notes

- The `id` field is positional (`arg-0`, `arg-1`, …) and reflects the original array index, not the post-filter position.
- `serializeKeyValues` uses the post-filter mapping, so keys surviving the trim check retain their original index-based `id` from parsing.
