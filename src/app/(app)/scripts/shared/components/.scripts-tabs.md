Tab navigation component for the Scripts section, rendering a route-based switcher between the **Scripts List** and **Scripts Schedules** views, gated by the `script-schedules` feature flag.

## Key Components

- **`SCRIPTS_TABS`** — Static tab definitions (`list` and `schedules`) with icons from the icon library.
- **`ScriptsTabNavigationProps`** — Props interface accepting `activeTab` (`'list' | 'schedules'`).
- **`ScriptsTabNavigation`** — Main exported component that:
  - Resolves the `script-schedules` feature flag from the store (with env-var fallback).
  - Returns `null` (hides the entire tab bar) when schedules are disabled — matching the behavior of `scripts/schedules/layout.tsx`.
  - Navigates to separate routes (`routes.scripts.schedules.list` / `routes.scripts.list`) on tab change instead of using `?tab=` query state.

## Usage Example

```typescript
// In a Scripts page layout
import { ScriptsTabNavigation } from './scripts-tabs';

export default function ScriptsListPage() {
  return (
    <>
      <ScriptsTabNavigation activeTab="list" />
      {/* page content */}
    </>
  );
}
```

## Notes

- **Route-based tabs**: Unlike the legacy `/scripts?tab=` approach, each tab maps to a distinct route. The `TabNavigation` component is rendered with `urlSync={false}` since route transitions are handled manually via `router.push`.
- **Flag synchronization**: The flag is read from the Zustand store when loaded, falling back to the compile-time env value, preventing a flash of the tab bar on the schedules routes before the server-resolved flag arrives.
