A CodeMirror 6 code editor React component with a custom dark theme (`ods-dark`) and shell/language mapping, designed for script editing within the OpenFrame platform.

Split across two files: `script-editor.tsx` is the wrapper every page imports, and `script-editor-view.tsx` holds the editor itself so CodeMirror lands in its own chunk.

## Key Components

### `ScriptEditor` (exported component, `script-editor.tsx`)
The primary export. Frames the editor, owns its height, and covers it with a placeholder until it is built.

**Props (`ScriptEditorProps`):**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | Editor content |
| `onChange` | `(value: string) => void` | — | Change handler |
| `shell` | `string` | `'bash'` | Script language/shell type |
| `readOnly` | `boolean` | `false` | Disables editing |
| `height` | `string` | `'400px'` | Editor height |
| `invalid` | `boolean` | `false` | Shows error border styling |
| `loading` | `boolean` | `false` | The `value` is still in flight — holds the placeholder up past the point the editor is built |

### `prewarmScriptEditor()` (exported, `script-editor.tsx`)
Idle-schedules the dynamic import of `script-editor-view`, so a surface that might open an editor (a collapsed card, a tab one click away) pays the chunk fetch in the background instead of inside the click. Idempotent.

### `ScriptEditorPlaceholder` (internal)
Code-shaped placeholder covering the editor's box: the editor's own background, 22px line rhythm, gutter column and lines of varying width. Rendered in ONE place for the editor's whole life and faded rather than unmounted, so nothing about it restarts — `next/dynamic` gets `loading: () => null` on purpose, since a second copy in another tree position would restart the pulse. It covers the editor instead of hiding it, so the view builds and measures at its real size. Lifted once `onReady` fires AND `loading` is false.

### `ScriptEditorView` (default export, `script-editor-view.tsx`)
Builds the `EditorView` once and reconfigures it in place through two `Compartment`s (language, read-only). A `value` pushed from outside is diffed against the doc — after normalising its line endings — before dispatching, so the parent's state round-trip never rewrites the doc under the cursor. The push is annotated so it neither enters the undo history nor echoes back through `onChange`, and the caret is carried across explicitly. Everything else the build reads comes through a ref, so a changed `onChange` identity cannot tear the editor down.

### `languageFor(shellId)`
Maps shell identifiers to CodeMirror language support: `powershell` (legacy stream mode), `python`, `sql`, `deno` → TypeScript, and everything else (`bash`, `shell`, `nushell`) → the shell stream mode. **`cmd` maps to nothing** — no bat/cmd/dos mode exists in the official packages or in `@codemirror/legacy-modes`, so Windows batch renders unhighlighted.

### `toDocText` / `fromDocText` / `eolOf`
CodeMirror documents hold LF only. These keep the bound value in the terms it arrived in: CRLF in, CRLF out, so typing one character does not silently convert a Windows-authored script (whose shebang would become `#!/bin/bash\r`). `eolOf` decides from the FIRST line break, so one stray CRLF cannot convert a mixed file, and returns `null` for a single-line value so the remembered ending is kept rather than flipped.

### `odsTheme` / `odsHighlight`
The `ods-dark` palette as an `EditorView.theme` plus a `HighlightStyle` over lezer tags — a gold/teal/green palette on a `#161616` background. The theme's geometry is load-bearing: a 46px line-number gutter, a 16px fold column and 16px line padding put the first character at 78px, on 22px rows, 12px down. `ScriptEditorPlaceholder` draws the same box, and the two have to agree or the swap slides.

## Usage Example

```typescript
import { ScriptEditor } from './script-editor';

function MyForm() {
  const [script, setScript] = useState('#!/bin/bash\necho "Hello"');

  return (
    <ScriptEditor
      value={script}
      onChange={setScript}
      shell="bash"
      height="300px"
      readOnly={false}
      invalid={false}
    />
  );
}
```

> The editor is dynamically imported with `ssr: false` — it renders only on the client. Pass `shell="powershell"` or `shell="python"` to switch syntax highlighting automatically.
