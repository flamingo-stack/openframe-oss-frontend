Displays a script's name, description, and metadata strip (shell type, platforms, timeout, author) in a card layout used on script details and run pages.

## Key Components

- **`ScriptSummaryCard`** — Main card component rendering the name/description header and a 4-column metadata strip. Conditionally shows timeout and author stats via `showTimeout` and `author` props.
- **`ScriptSummaryCardSkeleton`** — Loading skeleton that mirrors the real card's layout exactly. Both lines of each stat cell are bars, sized to the loaded card's line heights (`h-6` value / `h-5` label) so nothing shifts on load.
- **`RUN_SUMMARY_STATS`** — Exported stat set for the run page variant (`showTimeout` off, author on), intended to be passed to `ScriptSummaryCardSkeleton` at call sites.
- **`ScriptSummaryStat`** — Union of metadata-cell ids (`'shell' | 'platforms' | 'timeout' | 'author'`) the skeleton's `stats` prop accepts.
- **`MetaCell`** / **`MetaStat`** / **`MetaSpacer`** — Internal layout primitives keeping the loaded card and skeleton structurally identical. `MetaSpacer` fills remaining columns when fewer than 4 stats are present.
- **`STAT_LABELS`** — Single source of truth for metadata label strings; its keys are also the skeleton's cell ids, so the two can't disagree on the stat set.

## Usage Example

```typescript
// Details page (all 4 stats)
<ScriptSummaryCard
  name="Disk Cleanup"
  description="Removes temp files older than 30 days."
  shellId="bash"
  platforms={['linux', 'darwin']}
  timeoutSeconds={120}
  author="Jane Smith"
/>

// Run page (timeout hidden, skeleton pre-configured)
<ScriptSummaryCardSkeleton stats={RUN_SUMMARY_STATS} />

<ScriptSummaryCard
  name="Disk Cleanup"
  shellId="bash"
  platforms={['linux']}
  showTimeout={false}
  author="Jane Smith"
/>
```
