A confirmation modal displayed after a script execution has been successfully submitted, informing the user where they can track progress and results.

## Key Components

### `ExecutionStartedModal`

A presentational modal component wrapping `SimpleModal` with a fixed "Execution Started" title and a two-button footer.

**Props (`ExecutionStartedModalProps`):**

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `isOpen` | `boolean` | ✅ | — | Controls modal visibility |
| `onClose` | `() => void` | ✅ | — | Called when the Close button is clicked |
| `scriptName` | `string` | ✅ | — | Name of the submitted script, highlighted in accent color |
| `onViewResults` | `() => void` | ✅ | — | Navigates to where execution results can be tracked |
| `viewLabel` | `string` | ❌ | `'View Execution History'` | Label for the primary CTA button |
| `resultsLocation` | `string` | ❌ | `'execution history'` | Completes the body sentence describing where results appear |

## Usage Example

```typescript
import { ExecutionStartedModal } from '@/app/components/execution-started-modal';

<ExecutionStartedModal
  isOpen={showModal}
  onClose={() => setShowModal(false)}
  scriptName="deploy-patch.ps1"
  onViewResults={() => router.push('/execution-history')}
/>

// With custom CTA for a different results location (e.g. job queue)
<ExecutionStartedModal
  isOpen={showModal}
  onClose={() => setShowModal(false)}
  scriptName="run-backup.sh"
  onViewResults={() => router.push('/jobs')}
  viewLabel="View Job Queue"
  resultsLocation="job queue"
/>
```
