Renders the paginated list of script executions for a specific script, including filtering, search, and row-level actions within a Relay-backed data table.

## Key Components

### `ScriptExecutionsTab` (default export)
Top-level component accepting a `scriptId` prop. Manages the search/filter toolbar state, debounced query variables, and sticky toolbar offset, then wraps `ScriptExecutionsContent` in a `Suspense` boundary.

### `ScriptExecutionsContent`
Inner Relay-aware component (must live inside `Suspense`). Responsible for:
- Fetching executions via `useLazyLoadQuery` + `usePaginationFragment`
- Deriving filter facet options (`status`, `initiator`, `machine`) from the query response
- Building the `UiExecution[]` view model from raw Relay edges
- Rendering a `DataTable` with inline `Tag`, `SquareAvatar`, `TruncateText`, and `ActionsMenuDropdown` cells

### `UiExecution`
Flat view-model interface that normalises raw GraphQL node data for the table rows.

### Key Utilities Used
| Import | Purpose |
|---|---|
| `executionStatusLabel` / `executionStatusVariant` | Maps backend enum → display label / tag variant |
| `formatExecutionTimestamp` | Formats `dispatchedAt` for the Execution column |
| `initiatorName` / `initiatorInitials` | Derives display values from the initiator union |
| `facetToSortedOptions` | Converts GraphQL facet arrays to sorted `FilterModal` option objects |
| `decodeGlobalId` | Decodes Relay global ID to raw ID for employee-detail navigation |

## Usage Example

```typescript
// Render the executions tab for a known script
import ScriptExecutionsTab from './script-executions-tab';

export default function ScriptDetailPage({ params }: { params: { id: string } }) {
  return (
    <ScriptExecutionsTab scriptId={params.id} />
  );
}
```

The component handles all pagination (`PAGE_SIZE = 20`), search debouncing, and backend filter construction internally. The parent only needs to supply the Relay `scriptId`.
