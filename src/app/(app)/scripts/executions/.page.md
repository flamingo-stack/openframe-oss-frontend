A Next.js client-side page component that renders script execution details by extracting an execution ID from the URL's query parameters.

## Key Components

- **`ScriptExecutionDetailsPage`** — Default export; reads the `id` query parameter from the URL and passes it to the execution details view.
- **`ScriptExecutionDetailsView`** — Imported from the scripts v2 feature module; handles all rendering logic for a specific script execution.

## Usage Example

```typescript
// Accessed via URL: /scripts/execution-details?id=exec_abc123
// The page automatically reads the `id` param and renders the matching execution.

// Example navigation to this page:
import { useRouter } from 'next/navigation';

const router = useRouter();
router.push('/scripts/execution-details?id=exec_abc123');
```

## Notes

- Uses `'use client'` directive — this component runs entirely on the client side.
- Falls back to an empty string (`''`) if no `id` query param is present; downstream handling of missing IDs is delegated to `ScriptExecutionDetailsView`.
