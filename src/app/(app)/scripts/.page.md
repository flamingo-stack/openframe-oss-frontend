The main page component for the Scripts section, rendering a tabbed interface that displays different script views and resets the search state on tab navigation.

## Key Components

- **`Scripts`** — Default export; the root page component for the `/scripts` route
- **`useApiParams`** — Hook managing URL-synced query parameters (`tab`, `search`)
- **`getTabComponent`** — Resolves the correct tab component based on the active `tab` param
- **`ScriptsTabNavigation`** — Tab bar UI; triggers a tab switch and clears `search` on change
- **`SCRIPTS_TABS`** — Tab registry defining available script tabs and their components

## Usage Example

```typescript
// Rendered automatically by Next.js at the /scripts route.
// Tab state is driven by URL query params, e.g.:
// /scripts?tab=list         → renders the list tab component
// /scripts?tab=templates    → renders the templates tab component

// On tab switch, search is always reset to '' to avoid stale filters:
<ScriptsTabNavigation
  activeTab={params.tab}
  onTabChange={tab => setParams({ tab, search: '' })}
/>
```

## Behavior Notes

- `tab` defaults to `"list"` and `search` defaults to `""` if not present in the URL
- Switching tabs resets `search` to an empty string, ensuring each tab starts with a clean filter state
- If `getTabComponent` returns `null` (unrecognized tab), nothing is rendered — safe fallback with no crash
