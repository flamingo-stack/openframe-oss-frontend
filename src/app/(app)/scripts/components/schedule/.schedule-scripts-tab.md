Displays the list of scripts associated with a script schedule, rendering each action as an expandable card with script arguments, environment variables, and navigation to script details.

## Key Components

- **`ScheduleScriptsTab`** — Container component that iterates over `schedule.actions` and renders a `ScheduleScriptCard` for each entry.
- **`ScheduleScriptCard`** — Individual card showing a script action's name, timeout, arguments, and environment variables. Supports accordion-style expand/collapse via CSS grid row animation. Navigates to the script details page on button click.

## Usage Example

```typescript
import { ScheduleScriptsTab } from './schedule-scripts-tab';

// Inside a schedule detail page
<ScheduleScriptsTab schedule={scheduleDetail} />
```

## Behavior Notes

- **Argument parsing** — Each `script_args` string is split on the first space; entries with no space are treated as boolean flags (`value: 'flag'`).
- **Env var parsing** — Each `env_vars` string is split on `=`, preserving values that contain `=` (e.g. base64 strings).
- **Responsive layout** — The "Script Details" button is hidden on mobile; a full-width alternative appears inside the expanded section instead.
- **Expand animation** — Uses `grid-template-rows` transition (`0fr` → `1fr`) for a smooth, height-agnostic collapse without JavaScript measurements.
