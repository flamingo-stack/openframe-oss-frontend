Loading state skeleton component for the Schedule Details page, providing placeholder UI that mirrors the layout of the fully-loaded `ScheduleDetailView`.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ScheduleDetailSkeleton` | Named export | Full-page skeleton wrapped in `PageLayout` |
| `InfoBarSkeleton` | Internal | 4-column info bar (Date, Time, Repeat, Platform) |
| `TabsSkeleton` | Internal | 3-tab navigation row placeholder |
| `ScriptCardSkeleton` | Internal | Single script card row placeholder |

## Usage Example

```typescript
import { ScheduleDetailSkeleton } from './schedule-details-skeleton';

// Typically used in a Next.js loading.tsx or Suspense boundary
export default function Loading() {
  return <ScheduleDetailSkeleton />;
}
```

```typescript
// Or inside a Suspense boundary alongside the real view
import { Suspense } from 'react';
import { ScheduleDetailSkeleton } from './schedule-details-skeleton';
import { ScheduleDetailView } from './schedule-detail-view';

export default function Page() {
  return (
    <Suspense fallback={<ScheduleDetailSkeleton />}>
      <ScheduleDetailView />
    </Suspense>
  );
}
```

## Notes

- Marked `'use client'` — runs in the browser only.
- Sub-components (`InfoBarSkeleton`, `TabsSkeleton`, `ScriptCardSkeleton`) are unexported and composed exclusively within `ScheduleDetailSkeleton`.
- Skeleton dimensions and grid layouts are intentionally matched to the real `ScheduleDetailView`, `ScheduleInfoBar`, and `ScheduleScriptCard` components to minimise layout shift on load.
