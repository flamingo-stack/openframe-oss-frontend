Renders the "Devices" tab within a script schedule detail view, displaying the list of agents assigned to a given schedule as read-only device entries.

## Key Components

**`ScheduleDevicesTab`** – Main exported component. Fetches assigned agents via `useScriptScheduleAgents`, maps them to `Device` objects, and renders them in a read-only `DeviceSelector` table. Shows a `LoadError` on fetch failure.

**`agentToDevice`** – Internal adapter function that converts a `ScriptScheduleAgent` shape to the `Device` shape expected by `DeviceSelector`, mapping fields like `agent_id → id/machineId`, `hostname → displayName`, and `plat → osType`.

**`ScheduleDevicesTabProps`** – Interface accepting:
- `schedule` – Full `ScriptScheduleDetail` object (passed but not currently consumed)
- `scheduleId` – Used to fetch agents from the schedule API

> **Note:** `useScriptScheduleAgents` currently returns an empty list pending OpenFrame RMM schedule API integration. The tab will render no devices until that wiring is complete.

## Usage Example

```typescript
import { ScheduleDevicesTab } from './schedule-devices-tab';

// Inside a parent schedule detail page/component:
<ScheduleDevicesTab
  schedule={scheduleDetail}
  scheduleId="sched_abc123"
/>
```

The tab hides the `organization`, `status`, and `actions` columns from `DeviceSelector`, keeping the view focused on hostname and OS details.
