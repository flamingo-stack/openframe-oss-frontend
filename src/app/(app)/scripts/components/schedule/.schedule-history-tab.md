Renders a paginated execution history table for a script schedule, displaying log entries with status, device, and output details, with a slide-out drawer for full log inspection.

## Key Components

### `ScheduleHistoryTab`
Main exported component that fetches and displays script schedule execution history. Accepts:
- `schedule` — `ScriptScheduleDetail` object for the parent schedule
- `scheduleId` — string ID used to fetch history via `useScriptScheduleHistory`

### Helper Functions

| Function | Description |
|---|---|
| `getStatusVariant(status)` | Maps `'passing'`/`'failing'` to Tag color variants (`success`, `error`, `grey`) |
| `getStatusLabel(entry)` | Returns a human-readable status label (`OK`, `FAILING`, or uppercased status) |

### Internal Behavior
- **Pagination** — manual offset/limit pagination (50 entries per page) with Previous/Next controls rendered when `total > limit`
- **Row click → Drawer** — clicking a table row opens a `LogDrawer` with full entry metadata (return code, device, platform, execution time, sync status, stdout/stderr)
- **Columns** — `LOG ID` (formatted with zero-padded ID + timestamp), `STATUS` (Tag), `DEVICE` (hostname), `LOG DETAILS` (truncated stdout/stderr); `DEVICE` and `LOG DETAILS` hide at `md` breakpoint

## Usage Example

```typescript
import { ScheduleHistoryTab } from './schedule-history-tab';

<ScheduleHistoryTab
  schedule={scheduleDetail}
  scheduleId="sched-abc123"
/>
```
