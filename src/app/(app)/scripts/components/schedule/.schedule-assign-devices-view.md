A React view component for assigning devices to a script schedule, allowing users to select compatible devices and persist the assignment.

## Key Components

- **`ScheduleAssignDevicesView`** — Main exported component that renders a device selection interface for a given schedule, filtered by the schedule's supported platforms
- **`fetchDevicesByPlatforms`** — Async helper that queries the GraphQL API for online/offline devices matching specified OS types (up to 100 devices)
- **`getDeviceKey`** — Alias for `getDevicePrimaryId`, used as a stable device identity function for the selector

## Key Behaviors

- Fetches schedule metadata and compatible devices in parallel, showing a skeleton loader during load
- Filters available devices by `task_supported_platforms` mapped to OS types via `mapPlatformsToOsTypes`
- On save, calls `useReplaceScheduleAgents` mutation and navigates back to the `schedule-devices` tab on success
- Surfaces `LoadError` / `NotFoundError` states for missing or failed schedule fetches
- Pre-selection from existing agents is pending OpenFrame RMM API integration (noted with `TODO` comments)

## Usage Example

```typescript
// Used as a page-level component, receiving scheduleId from route params
import { ScheduleAssignDevicesView } from './schedule-assign-devices-view';

export default function Page({ params }: { params: { id: string } }) {
  return <ScheduleAssignDevicesView scheduleId={params.id} />;
}
```
