Loading skeleton component for the Schedule Create/Edit page, providing a placeholder UI that mirrors the exact layout of `ScheduleCreateView` while data is being fetched.

## Key Components

| Component | Description |
|---|---|
| `ScheduleCreateSkeleton` | **Main export.** Full-page skeleton matching the `ScheduleCreateView` layout |
| `NameFieldSkeleton` | Label + text input placeholder for the schedule name field |
| `DateRepeatSkeleton` | Two-item row placeholder for the date picker and repeat checkbox |
| `PlatformsSkeleton` | Label + three platform button placeholders in a horizontal row |
| `ActionCardSkeleton` | Card-style placeholder mimicking a `ScheduleActionFormCard` with header, input, and footer row |

## Usage Example

```typescript
import { ScheduleCreateSkeleton } from './schedule-create-skeleton';

// Render while schedule data is loading
export default function ScheduleCreatePage() {
  const { data, isLoading } = useSchedule();

  if (isLoading) {
    return <ScheduleCreateSkeleton />;
  }

  return <ScheduleCreateView schedule={data} />;
}
```

## Notes

- Uses `Skeleton` from `@flamingo-stack/openframe-frontend-core` for all placeholder elements
- All sub-components are **internal only** — `ScheduleCreateSkeleton` is the sole named export
- Dimensions and layout classes are intentionally matched to the live form to prevent layout shift on load
- Marked `'use client'` for Next.js client-side rendering compatibility
