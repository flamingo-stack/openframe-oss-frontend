Skeleton loading screen for the Schedule Assign Devices page, rendering placeholder UI that mirrors the layout of `ScheduleAssignDevicesView` while data is being fetched.

## Key Components

| Component | Type | Description |
|---|---|---|
| `ScheduleAssignDevicesSkeleton` | Named export | Full-page skeleton matching the complete assign-devices layout |
| `InfoBarSkeleton` | Internal | Placeholder for the schedule name/note and date/time/repeat/platform info bar |
| `SelectionModeSkeleton` | Internal | Placeholder for the two radio-option selection mode cards |
| `DeviceRowSkeleton` | Internal | Placeholder for a single device table row (icon, name, metadata, actions) |

## Usage Example

```typescript
import { ScheduleAssignDevicesSkeleton } from './schedule-assign-devices-skeleton';

// Render while schedule + device data is loading
function ScheduleAssignDevicesPage() {
  const { data, isLoading } = useScheduleAssignDevices(scheduleId);

  if (isLoading) {
    return <ScheduleAssignDevicesSkeleton />;
  }

  return <ScheduleAssignDevicesView data={data} />;
}
```

## Layout Structure

The skeleton mirrors the following page regions in order:

```text
1. Back link
2. Page title + Save button
3. InfoBar  (2-col name/note row + 4-col date/time/repeat/platform row)
4. Selection mode (2 radio option cards)
5. Sub-tabs  (Available | Selected)
6. Search input
7. Device rows × 8
```

## Notes

- Uses `Skeleton` from `@flamingo-stack/openframe-frontend-core` for consistent shimmer styling
- Marked `'use client'` — renders on the client only
- `DeviceRowSkeleton` progressively hides metadata columns on mobile via `hidden md:block`
