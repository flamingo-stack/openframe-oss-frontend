A full-page form view for creating or editing a script schedule, supporting both create and edit modes via an optional `scheduleId` prop.

## Key Components

- **`ScheduleCreateView`** — Primary exported component that renders a `PageLayout`-wrapped form for schedule creation/editing
- **Form Management** — Uses `react-hook-form` with `zodResolver` against `createScheduleFormSchema` for validation
- **`useFieldArray`** — Manages a dynamic list of script actions, each rendered as a `ScheduleActionFormCard`
- **`useCreateScriptSchedule` / `useUpdateScriptSchedule`** — Mutation hooks for persisting schedule data
- **`useScriptSchedule`** — Fetches existing schedule data in edit mode and resets the form via `scheduleDetailToFormData`

### Form Sections

| Section | Fields |
|---|---|
| Schedule Name | `name` (text input) |
| Timing | `scheduledDate`, `repeatEnabled`, `repeatInterval`, `repeatPeriod` |
| Platforms | `supportedPlatforms` (toggle buttons) |
| Actions | Dynamic array of script action cards |

## Usage Example

```typescript
// Create mode
<ScheduleCreateView />

// Edit mode — fetches existing schedule by ID
<ScheduleCreateView scheduleId="sched_abc123" />
```

## Behavior Notes

- Renders `ScheduleCreateSkeleton` while loading an existing schedule in edit mode
- Platform toggles enforce a minimum of one selected platform
- Repeat interval/period fields are conditionally rendered when `repeatEnabled` is `true`
- On success, navigates to the schedule detail page; on failure, shows a destructive toast
- Cancel button navigates back to the schedule details (edit) or the schedules list tab (create)
