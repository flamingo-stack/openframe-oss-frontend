A responsive form card component for configuring a single scheduled script action, including script selection, timeout, script arguments, and environment variables.

## Key Components

### `ScheduleActionFormCard` (default export)

The primary component rendering a bordered card with responsive layouts (mobile-first stacked, tablet+ inline grid). Integrates with `react-hook-form` via `useFormContext<CreateScheduleFormData>` and handles:

- **Script selection** — Autocomplete filtered by `supportedPlatforms`, auto-populating `name` and `timeout` on selection
- **Timeout input** — Numeric field defaulting to `90` seconds
- **Script arguments & environment variables** — Rendered via `ScriptArguments` only when a valid script is selected (`selectedScriptId > 0`)
- **Remove action** — Trash icon button, disabled when `canRemove` is `false`

### `ScriptPlatformIcons` (internal)

Renders small OS platform icons inline next to script names in the autocomplete dropdown, filtered from `OS_PLATFORMS` by the script's `supported_platforms`.

## Props

| Prop | Type | Description |
|---|---|---|
| `index` | `number` | Position in the `actions` array within the form |
| `supportedPlatforms` | `string[]` | Filters available scripts by OS compatibility |
| `onRemove` | `() => void` | Callback to remove this action card |
| `canRemove` | `boolean` | Disables remove button when `false` (e.g. minimum one action required) |

## Usage Example

```typescript
import { ScheduleActionFormCard } from './schedule-action-form-card';
import { useFormContext } from 'react-hook-form';

function ScheduleActionsField() {
  const { fields, remove, append } = useFieldArray({ name: 'actions' });

  return fields.map((field, index) => (
    <ScheduleActionFormCard
      key={field.id}
      index={index}
      supportedPlatforms={['windows', 'linux']}
      onRemove={() => remove(index)}
      canRemove={fields.length > 1}
    />
  ));
}
```

> **Note:** Must be rendered within a `react-hook-form` `FormProvider` supplying `CreateScheduleFormData`.
