Displays a real-time test run card for a device agent tool execution, showing status, duration, and scrollable log output with support for stopping, retrying, or dismissing the run.

## Key Components

### `TestRunData` (interface)
Data model for a test run, including:
- `id`, `deviceName`, `agentToolId` — run identifiers
- `status` — `'running' | 'completed' | 'error' | 'aborted'`
- `output` — array of log lines streamed during execution
- `elapsedSeconds`, `startedAt`, `startTime` — timing metadata

### `TestRunCard` (component)
Primary export. Renders a responsive card with:
- **Header row** — device name, start time, duration (responsive), and status with contextual color
- **Action buttons** — "Stop Testing" while running; "Test Again" + close when finished
- **Log panel** — scrollable 240px output area that auto-scrolls on new output; highlights lines containing `error` (red) or `success`/`passed`/`completed` (green); shows animated "Waiting for response..." pulse while running

### Helper Functions
| Function | Purpose |
|---|---|
| `formatDuration(totalSeconds)` | Formats seconds as `HH:MM:SS` |
| `getStatusLabel(status)` | Maps status to display string (e.g., `'completed'` → `'Success'`) |
| `getStatusColor(status)` | Returns ODS Tailwind color class per status |

## Usage Example

```typescript
import { TestRunCard, TestRunData } from './test-run-card';

const run: TestRunData = {
  id: 'run-001',
  deviceName: 'DESKTOP-ABC123',
  agentToolId: 'tool-ping',
  startedAt: '2:34 PM',
  startTime: Date.now(),
  status: 'running',
  output: ['Starting test...', 'Pinging 8.8.8.8...'],
  elapsedSeconds: 12,
};

<TestRunCard
  run={run}
  onStop={() => stopRun(run.id)}
  onTestAgain={() => retryRun(run.id)}
  onClose={() => removeRun(run.id)}
/>
```
