A full-page view component for running a script against selected devices, handling form validation, device selection, and execution feedback.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `RunScriptView` | React Component | Main view for configuring and submitting a script execution run |
| `RunScriptViewProps` | Interface | Accepts `scriptId: string` |
| `runFormSchema` | Zod Schema | Validates `timeout` (1–86400s), `scriptArgs`, and `envVars` |
| `RunFormData` | Type | Inferred from `runFormSchema` |

**Key behaviors:**
- Loads script details and available devices via `useRunScriptData`
- Tracks the current script as the active Mingo context view via `useTrackOpenView`
- Pre-populates form fields from `scriptDetails` on load (timeout, args, env vars)
- Blocks submission if no devices are selected; shows a destructive toast
- Calls `rejectScriptsMigrationPending()` to surface a clear "migration pending" error while the OpenFrame RMM run API is not yet wired up
- Shows `ExecutionStartedModal` on success with navigation to activity logs

## Usage Example

```typescript
// Rendered via Next.js dynamic route, e.g. /scripts/[scriptId]/run
import RunScriptView from '@/app/features/scripts/views/run-script-view';

export default function RunScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />;
}
```
