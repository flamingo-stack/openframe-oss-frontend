Modal component for selecting a target device when testing a script, filtering available devices by the script's supported platforms and showing only online devices.

## Key Components

### Exports

- **`TestScriptModal`** — Main modal component wrapping `SimpleModal` and `DeviceSelector` for single-device selection
- **`SelectedTestDevice`** — Interface representing the selected device result (`agentToolId`, `deviceName`)

### Internal

- **`fetchDevicesForTest`** — Async function that queries the GraphQL API for online devices, optionally filtered by OS type derived from `supportedPlatforms`
- **`TestScriptModalProps`** — Props interface defining `isOpen`, `onClose`, `onDeviceSelected`, and `supportedPlatforms`

## Key Behaviors

- Uses `@tanstack/react-query` to fetch devices only when the modal is open and at least one platform is provided
- Converts `supportedPlatforms` strings to OS type filter values via `mapPlatformsToOsTypes`
- Enforces single-device selection; shows a toast if the user attempts to confirm with no device selected
- Resets selection state on both confirm and cancel
- Renders a placeholder message when no supported platforms are configured

## Usage Example

```typescript
import { TestScriptModal, SelectedTestDevice } from './test-script-modal';

function ScriptRunner() {
  const [isOpen, setIsOpen] = useState(false);

  const handleDeviceSelected = (device: SelectedTestDevice) => {
    console.log('Running test on:', device.deviceName, device.agentToolId);
    setIsOpen(false);
  };

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Test Script</Button>
      <TestScriptModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        onDeviceSelected={handleDeviceSelected}
        supportedPlatforms={['windows', 'linux']}
      />
    </>
  );
}
```

> **Note:** The `agentToolId` field currently falls back to the device's primary ID pending full OpenFrame RMM test-run API integration. See `use-test-runs.ts` for context.
