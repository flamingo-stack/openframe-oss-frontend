A full-page React component for creating and editing automation scripts, supporting both "new script" and "edit script" modes based on the presence of a `scriptId` prop.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `EditScriptPage` | Component | Main page component handling script create/edit flows |
| `EditScriptPageProps` | Interface | `scriptId: string \| null` — `null` triggers create mode |

**Internal dependencies:**

- `useScriptDetails` — fetches existing script data when in edit mode
- `useEditScriptForm` — manages form state, validation, and save handler
- `useTestRuns` — manages live test run lifecycle (start, stop, clear)
- `useSafeBack` — navigation helper with safe fallback routing
- `ScriptFormFields` — renders all form inputs
- `TestRunCard` — displays live test run output and controls
- `TestScriptModal` — device selection modal before running a test

## Usage Example

```typescript
// Render in create mode (no scriptId)
<EditScriptPage scriptId={null} />

// Render in edit mode (with existing script ID)
<EditScriptPage scriptId="script_abc123" />
```

## Behavior Notes

- **Loading state**: renders `EditScriptSkeleton` while fetching script data
- **Error state**: shows an inline error card with a back button if the script fails to load in edit mode
- **Page title**: dynamically set to `"Edit Script"` or `"New Script"` based on mode and data availability
- **Actions**: two persistent header buttons — `"Test Script"` (opens device selector modal) and `"Save Script"` (submits form, disables/shows spinner while submitting)
- **Test results**: `TestRunCard` is conditionally rendered above the form only when an active test run exists
