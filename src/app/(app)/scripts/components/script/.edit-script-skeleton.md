Loading skeleton component for the Edit Script page that mirrors the exact layout of `EditScriptPage` and `ScriptFormFields` during data fetching.

## Key Components

| Component | Description |
|---|---|
| `EditScriptSkeleton` | Main exported skeleton — full-page loader matching the Edit Script page layout |
| `PlatformSkeleton` | 3 platform cards + "Run as User" checkbox in a responsive grid |
| `FormFieldsSkeleton` | 4 form fields (Name, Shell Type, Category, Timeout) in a 2→4 column grid |
| `DescriptionSkeleton` | Description textarea placeholder |
| `ArgumentsSkeleton` | Script Arguments / Environment Variables section placeholder |
| `EditorSkeleton` | Code editor placeholder (300px mobile, 600px desktop) |

## Usage Example

```typescript
import { EditScriptSkeleton } from './edit-script-skeleton';

// Use as a Suspense fallback or loading state
export default function EditScriptPage({ params }: { params: { id: string } }) {
  const { data, isLoading } = useScript(params.id);

  if (isLoading) return <EditScriptSkeleton />;

  return <ScriptFormFields data={data} />;
}
```

## Notes

- Marked `'use client'` — renders on the client side only.
- Uses `Skeleton` from `@flamingo-stack/openframe-frontend-core` for consistent shimmer styling.
- Internal sub-components (`PlatformSkeleton`, `FormFieldsSkeleton`, etc.) are not exported — they are composition helpers for `EditScriptSkeleton` only.
- Responsive breakpoints mirror the real form: 2-column mobile → 4-column `lg` for form fields; 300px → 600px editor height.
