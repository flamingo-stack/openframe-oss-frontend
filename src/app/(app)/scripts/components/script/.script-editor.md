A Monaco-based code editor React component with a custom dark theme (`ods-dark`) and shell/language mapping, designed for script editing within the OpenFrame platform.

## Key Components

### `ScriptEditor` (exported component)
The primary export. Wraps `@monaco-editor/react` with platform-specific defaults.

**Props (`ScriptEditorProps`):**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | Editor content |
| `onChange` | `(value: string) => void` | — | Change handler |
| `shell` | `string` | `'bash'` | Script language/shell type |
| `readOnly` | `boolean` | `false` | Disables editing |
| `height` | `string` | `'400px'` | Editor height |
| `invalid` | `boolean` | `false` | Shows error border styling |
| `loading` | `boolean` | `false` | The `value` is still in flight — holds the placeholder up past the point Monaco is built |

### `ScriptEditorPlaceholder` (internal)
Code-shaped placeholder covering the editor's box: the editor's own background, 22px line rhythm, gutter column and lines of varying width. Rendered in ONE place for the editor's whole life and faded rather than unmounted, so nothing about it restarts — `next/dynamic` gets `loading: () => null` and Monaco gets `loading={null}` on purpose, since a second copy in another tree position would restart the pulse. It covers the editor instead of hiding it (`display: none` makes Monaco measure 0×0 and re-lay out on reveal). Lifted once the editor is built AND `loading` is false.

### `SHELL_TO_LANGUAGE`
Maps shell identifiers (`powershell`, `cmd`, `bash`, `python`, `nushell`, `deno`, `sql`) to Monaco language IDs.

### `defineOdsTheme(monaco)`
Registers the `ods-dark` custom Monaco theme — a dark theme using a gold/teal/green palette on a `#161616` background.

### `MONACO_SERVICE_OVERRIDES`
Suppresses benign `Canceled` errors from Monaco's Safari/WebKit clipboard workaround ([upstream issue #4389](https://github.com/microsoft/monaco-editor/issues/4389)).

## Usage Example

```typescript
import { ScriptEditor } from './script-editor';

function MyForm() {
  const [script, setScript] = useState('#!/bin/bash\necho "Hello"');

  return (
    <ScriptEditor
      value={script}
      onChange={setScript}
      shell="bash"
      height="300px"
      readOnly={false}
      invalid={false}
    />
  );
}
```

> The editor is dynamically imported with `ssr: false` — it renders only on the client. Pass `shell="powershell"` or `shell="python"` to switch syntax highlighting automatically.
