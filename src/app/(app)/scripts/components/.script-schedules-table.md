A full-page table component for displaying, searching, and managing script schedules, with sticky toolbar, infinite scroll pagination, empty state handling, and per-row actions.

## Key Components

### `ScriptSchedulesTable` (exported component)
Main component rendering the schedules list inside a `PageLayout`. Handles:
- **Search**: Debounced URL-synced search via `useSearchParam` and `useApiParams`
- **Infinite scroll**: Client-side "load more" pagination (`visibleCount` window over filtered results)
- **Sticky toolbar**: Search bar sticks on scroll via `useStickyToolbar`
- **Empty state**: Shown when no schedules exist and no search is active
- **Row actions**: Edit schedule, edit devices (with new-tab support)

### `getRepeatLabelFromTaskType` (internal helper)
Maps `ScriptScheduleTaskType` values (`runonce`, `daily`, `weekly`, `monthly`, `monthlydow`) to human-readable repeat labels.

### Column definitions
Five visible columns — **Script**, **OS**, **Date & Time**, **Repeat**, **Devices** — plus **Actions** and **Open in new tab**, with responsive `hideAt` breakpoints.

## Usage Example

```typescript
// Render the schedules table on the /scripts/schedules route
import { ScriptSchedulesTable } from './script-schedules-table';

export default function ScriptSchedulesPage() {
  return <ScriptSchedulesTable />;
}
```

Row clicks navigate to the schedule detail page (`routes.scripts.schedules.details`). The **Add Schedule** button becomes accent-styled when no schedules exist, guiding onboarding. Data is sourced from `useScriptSchedules`.
