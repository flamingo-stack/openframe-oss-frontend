Renders a filterable, paginated data table for scripts with URL-persisted search, shell type, OS platform, and category filters, plus per-row actions (run, edit, details).

## Key Components

### `ScriptsTable` (default export)
The primary component. Combines data fetching, URL-synchronized filtering, and table rendering for the scripts list view.

### `UiScriptEntry` (interface)
Local view model shaping raw API script data for table consumption:

| Field | Type | Description |
|---|---|---|
| `id` | `number` | Script identifier |
| `name` / `description` | `string` | Display fields |
| `shellType` | `string` | e.g. `powershell`, `bash` |
| `supportedPlatforms` | `string[]` | OS targets |
| `category` | `string` | Script grouping |
| `timeout` | `number` | Execution timeout (seconds) |

### Key Internals

- **`useScripts`** — fetches raw script data; results are memoized into `UiScriptEntry[]`
- **`useApiParams`** — syncs `search`, `shellType`, `category`, and `supportedPlatforms` to/from URL query params
- **`useSearchParam`** — debounces (300 ms) search input writes to the URL param
- **`columns`** — `ColumnDef<UiScriptEntry>[]` with responsive `hideAt` breakpoints for shell type, OS, added-by, category, and description columns
- **`renderRowActions`** — renders an `ActionsMenuDropdown` with Run, Edit, and Details links (each optionally openable in a new tab)
- **`columnFilters` / `handleColumnFiltersChange`** — bridges TanStack Table's filter state with URL params via a stable ref pattern

## Usage Example

```typescript
// app/scripts/page.tsx
import { ScriptsTable } from './components/scripts-table';

export default function ScriptsPage() {
  return <ScriptsTable />;
}
```

Filters and search state are automatically persisted in the URL, enabling shareable links and browser back/forward navigation. Row clicks navigate to the script details page; the actions menu provides Run, Edit, and Details routes defined in [`routes`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/routes.ts).
