Renders a tabbed navigation UI for the Scripts section, providing switching between a Scripts List and Scripts Schedules view with optional URL query-param synchronization.

## Key Components

- **`SCRIPTS_TABS`** — Static array of `TabItem` config objects defining the two available tabs:
  - `list` — Scripts List, rendered via `ScriptsTable`, uses `BracketCurlyIcon`
  - `schedules` — Scripts Schedules, rendered via `ScriptSchedulesTable`, uses `CalendarIcon`

- **`ScriptsTabNavigation`** — Client component that wraps `TabNavigation` from the core library. Accepts optional `activeTab` and `onTabChange` props; falls back to updating the URL query string (`?tab=<tabId>`) via `router.replace` when no custom handler is provided.

## Usage Example

```typescript
// Uncontrolled — URL query param drives active tab
<ScriptsTabNavigation activeTab={searchParams.get('tab') ?? 'list'} />

// Controlled — custom handler overrides URL sync
<ScriptsTabNavigation
  activeTab={currentTab}
  onTabChange={(tabId) => setCurrentTab(tabId)}
/>
```

## Notes

- `urlSync={false}` is passed to `TabNavigation` to prevent the core component's built-in URL handling; URL updates are managed manually via `defaultHandleTabChange`.
- Defaults to the `'list'` tab when `activeTab` is not provided.
