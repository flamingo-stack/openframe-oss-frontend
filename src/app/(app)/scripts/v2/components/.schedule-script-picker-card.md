A card component representing a single script entry in a schedule's ordered script list, combining a server-searched autocomplete with a remove button.

## Key Components

### `ScheduleScriptPickerCard` (default export)
The primary card component that renders one row of a schedule's script list. Integrates with `react-hook-form` via `Controller` and `useFormContext` to manage the `scripts[index]` field of `EditScheduleFormData`.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `index` | `number` | Position in the scripts array |
| `supportedPlatforms` | `string[]` | Platform IDs used to filter server-side script search |
| `onRemove` | `() => void` | Callback to remove this entry |
| `canRemove` | `boolean` | Disables the remove button when `false` |
| `disabled` | `boolean` | Disables all interactive elements |
| `showErrors` | `boolean` | Gates inline validation error display post-save attempt |

### `ScriptPlatformIcons` (internal)
Renders small OS platform icons next to each script option in the autocomplete dropdown, sourced from `OS_PLATFORMS` filtered by the script's `supportedPlatforms`.

## Usage Example

```typescript
import { ScheduleScriptPickerCard } from './schedule-script-picker-card';

// Inside a react-hook-form FormProvider context
<ScheduleScriptPickerCard
  index={0}
  supportedPlatforms={['windows', 'linux']}
  onRemove={() => remove(0)}
  canRemove={fields.length > 1}
  disabled={isSubmitting}
  showErrors={hasAttemptedSave}
/>
```

> **Note:** Per-script timeout, args, and env overrides are intentionally excluded. The GraphQL schedule model stores script IDs only; scripts execute with their own defaults. See [`docs/script-schedules-v2-graphql-gaps.md`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/docs/script-schedules-v2-graphql-gaps.md) for context.
