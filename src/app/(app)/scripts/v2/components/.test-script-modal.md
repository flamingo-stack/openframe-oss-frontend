A modal component for selecting an online device to run a test script against, filtering available devices by supported platform.

## Key Components

### `TestScriptModal`
The primary exported component — renders a `ModalV2` dialog that fetches online devices filtered by `supportedPlatforms`, allows single device selection, and returns the selected device's `machineId` and name via the `onDeviceSelected` callback.

### `SelectedTestDevice` (interface)
Describes the device data passed back on confirmation:
- `machineId` — agent identifier required to dispatch the script
- `deviceName` — display-friendly name of the selected device

### `TestScriptModalProps` (interface)
| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Called on cancel or after successful selection |
| `onDeviceSelected` | `(device: SelectedTestDevice) => void` | Fires with the chosen device on confirm |
| `supportedPlatforms` | `string[]` | Filters devices to matching OS types |

### `fetchOnlineDevices` (internal)
Async function that calls the GraphQL API via `apiClient`, filtering by `DEVICE_STATUS.ONLINE` and OS types mapped from `supportedPlatforms`. Returns up to 100 transformed `Device` objects.

## Usage Example

```typescript
import { TestScriptModal } from './test-script-modal';

function ScriptActions() {
  const [isOpen, setIsOpen] = useState(false);

  const handleDeviceSelected = (device: SelectedTestDevice) => {
    console.log('Running test on', device.deviceName, device.machineId);
    // dispatch test job...
  };

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Test Script</button>
      <TestScriptModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        onDeviceSelected={handleDeviceSelected}
        supportedPlatforms={['windows', 'macos']}
      />
    </>
  );
}
```

> **Note:** The device query is only enabled when the modal is open (`isOpen`) **and** at least one platform is provided. Devices without a `machineId` (agent not connected) are rendered as disabled in the selector.
