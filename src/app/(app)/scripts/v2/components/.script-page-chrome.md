Shared page chrome wrapper for script v2 pages (details, edit, run, execution details), providing a consistent title bar, Back button, and header actions without remounting across Suspense boundaries.

## Key Components

### `ScriptPageChrome`
A layout wrapper component that composes `PageLayout` with safe-back navigation. Accepts the following props:

| Prop | Type | Description |
|---|---|---|
| `title` | `string` | Page heading |
| `subtitle` | `string?` | Secondary line (e.g. execution UUID) |
| `backFallback` | `string` | Fallback URL when history stack is unsafe |
| `actions` | `PageActionButton[]` | Primary header action buttons |
| `menuActions` | `ActionsMenuGroup[]?` | Overflow `...` menu groups |
| `actionsVariant` | `ComponentProps<PageLayout>['actionsVariant']?` | Controls action button appearance |
| `className` | `string?` | Overrides default page padding |
| `children` | `ReactNode` | Page body content |

**Key behaviors:**
- Delegates back navigation to `useSafeBack`, which provides a safe fallback when the browser history stack lacks a safe prior entry
- Memoizes the back button object to prevent unnecessary re-renders

## Usage Example

```typescript
<ScriptPageChrome
  title="My Script"
  subtitle="exec-uuid-1234"
  backFallback="/scripts"
  actions={[{ label: 'Run', onClick: handleRun }]}
  menuActions={[{ label: 'More', items: [...] }]}
>
  <ScriptDetails script={script} />
</ScriptPageChrome>
```
