Provides the full edit/create page for scripts, handling both new script creation and editing existing scripts with live data loading, test dispatch via `runCommand` mutation, and tag management.

## Key Components

### `EditScriptPage` (exported)
Top-level entry point. Renders a blank creation form when `scriptId` is `null`, or wraps the form in `ScriptDetailGate` to stream in existing script data.

### `LoadedEditScriptForm`
Bridge component between the Relay gate and the form. Maps raw `ScriptDetailData` to `EditScriptFormData` via `relayScriptToForm` and extracts initial tags. Passes `loading={true}` while the script query is still in flight — Monaco mounts once and fills in progressively.

### `EditScriptForm`
Core form component. Manages:
- **Save** — full schema validation via `useEditScriptForm`, then `handleSave`
- **Test** — validates runnable prereqs (shell, body, platform) before opening `TestScriptModal`, then dispatches `runCommandMutation` against the selected device
- **Execution feedback** — `ExecutionStartedModal` redirects to activity logs (not execution history, since test runs carry no `scriptId`)
- **Tags** — `EntityTagPicker` wrapped in `Controller` and `Suspense`

## Usage Example

```typescript
// New script
<EditScriptPage scriptId={null} />

// Edit existing script (data streamed via ScriptDetailGate)
<EditScriptPage scriptId="scr_abc123" />
```

## Notes

- The form stays **mounted** during load; `disabled={loading}` guards all controls. No skeleton/remount cycle — Monaco editor initialises exactly once.
- Test execution uses `runCommandMutation` against the **current editor body**, not the saved script. Results appear in the activity log, not the script's Execution History tab.
- Inline errors are gated behind `showErrors` (set on first Save or Test click) to avoid flashing on initial render.
