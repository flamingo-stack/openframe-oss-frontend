Renders a visual badge displaying a shell type's icon and label for Scripts v2, sourced from the `SCRIPT_V2_SHELL_TYPES` registry.

## Key Components

### `ScriptShellBadge` (exported component)

| Prop | Type | Description |
|------|------|-------------|
| `value` | `string` | Lowercase shell ID (e.g. `'cmd'`, `'powershell'`) |
| `className` | `string?` | Additional classes for the wrapper `<span>` |
| `iconClassName` | `string?` | Additional classes for the icon (size/color overrides) |

**Behavior:**
- Looks up the shell definition via `scriptV2ShellType(value)`
- Renders the shell's icon tinted with `text-ods-text-secondary` (`#888`)
- Falls back to the raw `value` string if no matching shell label is found

## Usage Example

```typescript
import { ScriptShellBadge } from './script-shell-badge';

// Basic usage in a scripts table column
<ScriptShellBadge value="powershell" />

// With custom sizing and wrapper styles
<ScriptShellBadge
  value="cmd"
  className="text-sm font-medium"
  iconClassName="w-4 h-4"
/>

// Unknown shell ID — gracefully falls back to raw value
<ScriptShellBadge value="bash" />
```

## Notes

- Intentionally mirrors the core `ShellTypeBadge` layout while using the v2 icon set, keeping the scripts table visually consistent with the editor shell selector.
- The `iconClassName` prop is applied **after** the default icon classes, giving callers full override control over size and color.
