A React error boundary that intercepts `NotFoundSignal` errors thrown by suspended data leaves and renders a full-page not-found view, while re-throwing all other errors upstream.

## Key Components

### `NotFoundSignal`
A sentinel `Error` subclass thrown by data leaves when a queried entity resolves to `null` (e.g., a missing script or resource). Used exclusively as a typed signal — not a generic network error.

### `NotFoundBoundary`
A class-based React error boundary that catches `NotFoundSignal` and renders `NotFoundError` from `@flamingo-stack/openframe-frontend-core`. Any other caught error (e.g., Relay network failures) is immediately re-thrown to the next boundary up the tree.

**Props:**

| Prop | Type | Description |
|---|---|---|
| `message` | `string` | Human-readable message passed to `NotFoundError` |
| `children` | `ReactNode` | Subtree to protect |

## Usage Example

```typescript
// In a page component where a data leaf may signal a missing entity
import { NotFoundBoundary, NotFoundSignal } from './not-found-boundary';

// Data leaf — throw the signal when entity is absent
function ScriptDetail({ data }: { data: ScriptQuery$data }) {
  if (!data.script) throw new NotFoundSignal();
  return <div>{data.script.name}</div>;
}

// Wrap page chrome + data leaf together so the entire page
// (including nav/toolbar rendered above Suspense) is replaced
export default function ScriptPage() {
  return (
    <NotFoundBoundary message="Script not found">
      <PageChrome />
      <Suspense fallback={<Spinner />}>
        <ScriptDetailLoader />
      </Suspense>
    </NotFoundBoundary>
  );
}
```

## Notes

- Must be a **class component** — React error boundaries cannot be implemented as function components.
- Intentionally placed **above** `<Suspense>` so that a missing entity replaces the full page chrome, preventing stale action buttons (Run/Edit) from rendering against a non-existent resource.
