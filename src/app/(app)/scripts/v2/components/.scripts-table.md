Renders the paginated, filterable scripts data table for the OpenFrame scripts module, handling archive/unarchive mutations, column filtering, and row actions within a Relay-powered client component.

## Key Components

| Export / Symbol | Description |
|---|---|
| `ScriptsTableContent` | Inner Relay component (must live inside `<Suspense>`) — loads scripts via `useLazyLoadQuery` + `usePaginationFragment`, renders the `DataTable`, and manages archive/unarchive confirmation modals |
| `UiScriptEntry` | Internal interface representing a normalized script row used by the table |
| `ScriptsTableContentProps` | Props interface for `ScriptsTableContent`, including backend filters, search state, pagination, mobile filter state, and `archived` mode toggle |
| `renderRowActions` | Memoized callback producing per-row `ActionsMenuDropdown` with Run, Edit, and Archive/Unarchive actions |
| `refreshFilterMeta` | Imperatively re-fetches shell/platform/author facets and tag-filter options after a mutation using `fetchQuery` |
| `transformedScripts` | Memoized mapping of Relay edge/node data to `UiScriptEntry[]`, with null-edge guards |

## Usage Example

```typescript
// Rendered inside a Suspense boundary by the parent page component
<Suspense fallback={<ScriptsTableSkeleton />}>
  <ScriptsTableContent
    backendFilters={{ status: ScriptStatus.Active }}
    debouncedSearch=""
    tableFilters={{}}
    hasTagFilter={false}
    isPending={false}
    onFilterChange={(filters) => applyFilters(filters)}
    onEmptyChange={(isEmpty) => setTableEmpty(isEmpty)}
    mobileFilterOpen={false}
    onMobileFilterClose={() => setMobileFilterOpen(false)}
    stickyHeaderOffset="64px"
    archived={false}
  />
</Suspense>
```

> **Note:** The `archived` prop toggles between the active scripts list (`archived: false`) and the archived scripts list (`archived: true`), swapping the archive/unarchive action label and mutation accordingly. The `@deleteEdge` directive removes a mutated script's edge from the current connection while a store record invalidation ensures all other cached connections refetch on next read.
