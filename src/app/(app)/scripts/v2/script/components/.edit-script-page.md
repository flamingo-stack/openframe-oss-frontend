Create + edit page for a script (v2, Relay): the page chrome and the form instance paint immediately, and only the fields that read the record suspend.

## Key Components

### `EditScriptPage` (exported)
Entry point for both routes (`/scripts-v2/new`, `/scripts-v2/edit?id=`). Renders `EditScriptForm` keyed by id, so a hop from script A to B cannot keep A's form state.

### `EditScriptForm`
The page around the fields — title, Back button, the Test / Save action bar, the form instance (`useEditScriptForm`) and both modals. It reads nothing from the server, so it renders on the first pass and is never replaced by a placeholder. Manages:
- **Save** — full schema validation via `useEditScriptForm`, then `handleSave`; flips `showErrors` so inline errors appear only after a save attempt
- **Test** — validates the runnable prereqs (shell, body, platform), captures the platforms as of that click and opens `TestScriptModal`, then dispatches `runCommandMutation` against the selected device
- **Readiness** — Test and Save stay disabled until the record has seeded the form, so neither can act on an empty one
- **Execution feedback** — `ExecutionStartedModal` points at the activity logs (test runs carry no `scriptId`, so they never appear in Execution History)

### `ScriptRecordLoader`
The page's data island, and it renders **nothing**. It reads `scriptDetailRelayQuery` and hands the mapped form values + tags up through `onResolved`; the page — the owner of `useForm` — is what writes them in. It is the only suspending component and its fallback is `null` — the form is already mounted below it, locked, which IS the loading state. Nothing remounts when the answer lands, so Monaco is built exactly once. A missing script comes back as `{ status: 'missing' }` and the page swaps the fields for `NotFoundError`, keeping the chrome and the way out.

**The write must stay in the page.** RHF subscribes fields in layout effects, which run children-first and siblings in tree order, so a `reset` fired from this island — rendered above the fields — reaches a form nothing is listening to yet and is silently dropped. It only shows when the answer is instant (Relay store warm, e.g. arriving from the details page); a slow query hides it, because the island then mounts after the fields have subscribed.

### `ScriptFields`
The v2 configuration of the shared `ScriptFormFields` (shell types, `hideCategory`, tags picker) in one place — the create page, the loaded edit page and the edit page's loading state are all this one tree, the last with `disabled` on. The tag picker keeps its own `Suspense`: the tag list is a second query and has no reason to hold up the fields around it.

## Usage Example

```typescript
// New script — no record to wait for, the fields render immediately
<EditScriptPage scriptId={null} />

// Edit — the chrome paints first, only the field column suspends
<EditScriptPage scriptId="scr_abc123" />
```

## Notes

- The form is created by the page with empty defaults and seeded by the island from a **layout effect** (see `useSeedForm`): during render it would update the `useForm` owner mid-render (React errors on it), and from a passive effect a store-warm script would still cost one frame of the empty form.
- Test platforms are captured on click instead of `watch`ed, so toggling a platform doesn't re-render the page.
- Test execution uses `runCommandMutation` against the **current editor body**, not the saved script. Results appear in the activity log, not the script's Execution History tab.
- Inline errors are gated behind `showErrors` (set on Save) to avoid painting a pristine form red.
