Renders the detail view for a single script execution, showing identity, timing, and result data with live polling for in-flight runs and a matching skeleton for Suspense fallback.

## Key Components

| Export / Symbol | Description |
|---|---|
| `ScriptExecutionDetailsView` (default export implied) | Top-level page component wrapping `ScriptExecutionDetailsContent` in a `<Suspense>` boundary with `ExecutionDetailsCardSkeleton` as the fallback |
| `ScriptExecutionDetailsContent` | Loads execution data via `useLazyLoadQuery`, polls Relay every 5 s while `status === RUNNING`, builds a "Copy Execution Details" action, and renders the two-row detail card |
| `DetailCell` | Reusable value-over-label cell; accepts any `ReactNode` as the value and a string label |
| `DetailCellSkeleton` | Skeleton variant of `DetailCell` — renders a `<Skeleton>` bar for the value, real text for the label (prevents layout jump) |
| `ExecutionDetailsCardSkeleton` | Full card-body skeleton mirroring the loaded layout, including a round-avatar placeholder for the "Executed by" cell |
| `RUNNING_POLL_INTERVAL_MS` | Constant (`5000` ms) controlling the live-polling cadence for in-flight executions |

## Usage Example

```typescript
// Render the execution detail page for a given Relay global ID
import { ScriptExecutionDetailsView } from './script-execution-details-view';

export default function ExecutionPage({ params }: { params: { id: string } }) {
  return <ScriptExecutionDetailsView executionId={params.id} />;
}
```

While the Relay query resolves, `ExecutionDetailsCardSkeleton` is shown inside `ScriptPageChrome` with placeholder text. Once loaded, the view auto-polls every **5 s** if the execution is `RUNNING`, stopping as soon as the status transitions. The "Copy Execution Details" action writes a plain-text summary of all fields to the clipboard.
- Deleted initiators (via `User.status` on the payload) render `DeletedUserAvatar` and a red underlined "Executed by" link.
- The dispatch source rides beside that name as an `ExecutionSourceBadge` — "Mingo" for `AI_ASSISTANT`, "Scheduled" for `SCHEDULED`, nothing for `MANUAL`. It sits OUTSIDE the initiator link, or clicking the chip would open the technician's employee page.
