Fetches and filters eligible devices for script execution, returning only online/offline devices that match the script's supported platforms.

## Key Components

- **`runDevicesQueryKeys`** — Query key factory scoping device queries by `scriptId` for cache isolation.
- **`fetchDevicesForScript(supportedPlatforms)`** — Async function that maps platforms to OS types, builds a GraphQL filter, and fetches up to 100 devices sorted by status descending.
- **`useRunDevices(options)`** — React Query hook exposing devices, loading state, and error message.

## Usage Example

```typescript
import { useRunDevices } from './use-run-devices';

function RunScriptDeviceSelector({ scriptId }: { scriptId: string }) {
  const { devices, isLoadingDevices, devicesError } = useRunDevices({
    scriptId,
    supportedPlatforms: ['windows', 'macos'],
    enabled: true,
  });

  if (isLoadingDevices) return <Spinner />;
  if (devicesError) return <Error message={devicesError} />;

  return <DeviceList devices={devices} />;
}
```

## Notes

- Only devices with `ONLINE` or `OFFLINE` statuses are included — explicitly excludes retired/pending states.
- When `supportedPlatforms` is empty, the `osTypes` filter is omitted and all OS types are returned.
- Results are transformed via `createDeviceListItem` before being returned, normalizing raw GraphQL nodes into the `Device` shape.
- Pass `enabled: false` to defer fetching until the run-script dialog is opened.
