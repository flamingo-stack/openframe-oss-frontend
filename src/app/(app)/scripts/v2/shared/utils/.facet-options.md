Defines the `FacetOption` interface and a utility for transforming server-side facet data into sorted filter dropdown options.

## Key Components

- **`FacetOption`** — Interface representing a single filter dropdown option with `id`, `label`, and `value` string fields.
- **`facetToSortedOptions`** — Converts a server facet array (`{ value, label }[]`) into a label-sorted `FacetOption[]`. Handles `null`/`undefined` input gracefully, and preserves the facet `value` verbatim so it round-trips through URL params correctly.

## Usage Example

```typescript
import { facetToSortedOptions } from './facet-options';

const serverFacet = [
  { value: 'user-456', label: 'Jane Smith' },
  { value: 'user-123', label: 'Alice Brown' },
];

const options = facetToSortedOptions(serverFacet);
// [
//   { id: 'user-123', label: 'Alice Brown', value: 'user-123' },
//   { id: 'user-456', label: 'Jane Smith',  value: 'user-456' },
// ]

// Safe with null/undefined
const empty = facetToSortedOptions(null); // []
```

The `value` field maps directly to filter input identifiers (e.g. a user ID for `initiatorIds`/`authorIds`, a machine ID for `machineIds`), ensuring filter state serialized to URL params is passed back to the server unchanged.
