Renders the full schedule details page view for a script schedule, composing a tabbed layout with Relay-powered data islands for schedule metadata, assigned scripts, and assigned devices.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ScheduleDetailsView` (default via `ScriptPageChrome`) | Page View | Root component rendering the full schedule details page with tabs and action buttons |
| `ScheduleHeaderSection` | Internal Component | Relay island fetching and rendering the schedule info bar (name, description, platforms) |
| `ScheduleInfoBarSkeleton` | Exported Component | Loading skeleton matching the `ScheduleInfoBarFromData` layout |
| `ScheduleScriptsTabSection` | Internal Component | Relay island listing expandable `ScheduleScriptCard` entries for each scheduled script |
| `ScheduleScriptCard` | Internal Component | Collapsible card showing script name, timeout, args, and env vars with animated expand |
| `ScheduleDevicesTabSection` | Internal Component | Lazy-loaded Relay island rendering a read-only `DeviceSelector` of assigned machines |
| `machineToDevice` | Exported Utility | Adapts a `AssignedMachine` GraphQL node to the shared `Device` shape |
| `AssignedMachine` | Exported Type | Derived type for a single entry in `scriptSchedule.assignedDevices` |

## Usage Example

```typescript
// Rendered via the schedule detail gate/route:
import { ScheduleDetailsView } from './schedule-details-view';

// Each data island wraps in <Suspense> with its own skeleton,
// so the header and tabs load independently.
<Suspense fallback={<ScheduleInfoBarSkeleton />}>
  <ScheduleHeaderSection scheduleId="sch_abc123" />
</Suspense>

// Adapter used when composing device lists elsewhere:
import { machineToDevice } from './schedule-details-view';
const devices = assignedDevices.map(machineToDevice);
// → Device[] with id, machineId, hostname, displayName, osType, status
```

> **Note:** The "Execution History" tab is intentionally absent — no schedule-run history query exists in the GraphQL schema yet. The Date/Time/Repeat fields in the info bar are placeholder dashes for the same reason.
