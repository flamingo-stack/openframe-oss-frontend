A Next.js page component that renders the archived view of script schedules by passing the `archived` prop to the shared schedules table.

## Key Components

- **`ArchivedScriptSchedulesV2Page`** — Default page export; a client component that delegates rendering to `ScriptSchedulesTable` with `archived={true}`.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to the archived schedules route.
// No manual instantiation required.

// The page passes `archived` to filter the table to archived schedules:
<ScriptSchedulesTable archived />
```

## Notes

- Marked as a Client Component via `'use client'`.
- All data-fetching, filtering, and display logic lives in [`ScriptSchedulesTable`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/scripts/components/script-schedules-table.tsx).
