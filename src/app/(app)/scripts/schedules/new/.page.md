A Next.js page component that renders the schedule creation interface.

## Key Components

- **`NewSchedulePage`** — Default page export that renders the `ScheduleCreateView` component for creating new schedules.

## Usage Example

```typescript
// Accessed via Next.js routing (e.g., /schedule/new)
// No props required — renders ScheduleCreateView directly
<NewSchedulePage />
```

## Notes

- Marked as a Client Component via `'use client'` directive.
- Delegates all UI and logic to [`ScheduleCreateView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/components/schedule/schedule-create-view.tsx).
