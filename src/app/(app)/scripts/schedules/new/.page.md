A Next.js page component that renders the schedule creation flow by delegating to the shared `EditSchedulePage` component with a null `scheduleId`, indicating a new (unsaved) schedule.

## Key Components

- **`NewScheduleV2Page`** — Default export; a client-side page component that mounts `EditSchedulePage` in "create" mode.

## Usage Example

```typescript
// Accessed via the Next.js app router route:
// /scripts/new (or equivalent route segment)

// Internally renders:
<EditSchedulePage scheduleId={null} />
```

## Notes

- Marked `'use client'` — runs in the browser, not on the server.
- The `scheduleId={null}` prop signals to `EditSchedulePage` that no existing schedule is being edited; the form should initialize empty and create a new record on save.
- Reuses [`EditSchedulePage`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/scripts/components/edit-schedule-page.tsx) — the same component handles both create and edit flows, differentiated by whether `scheduleId` is `null` or a valid ID.
