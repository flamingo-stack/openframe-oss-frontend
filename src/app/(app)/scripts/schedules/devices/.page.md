Page component that renders the schedule device assignment view, extracting the `id` query parameter from the URL to pass to the underlying view component.

## Key Components

- **`ScheduleAssignDevicesPage`** — Default export; a Next.js Client Component that reads the `id` search param and delegates rendering to `ScheduleAssignDevicesView`.

## Usage Example

```typescript
// Accessed via URL: /schedule/assign-devices?id=abc123
// The page automatically extracts the `id` param and passes it as `scheduleId`

// Internally renders:
<ScheduleAssignDevicesView scheduleId="abc123" />
```

## Notes

- Marked `'use client'` — requires browser-side rendering for `useSearchParams`.
- Falls back to an empty string (`''`) if the `id` param is missing from the URL.
