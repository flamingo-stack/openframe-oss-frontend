A Next.js client-side page component that renders the v2 Schedule Devices view, extracting the schedule ID from the URL query string.

## Key Components

- **`ScheduleDevicesV2Page`** — Default export; reads the `id` query parameter and passes it to `ScheduleDevicesView` as `scheduleId`.

## Usage Example

```typescript
// Accessed via URL: /scripts/schedule-devices?id=abc123
// The component automatically reads the `id` param and forwards it.

<ScheduleDevicesV2Page />
// Renders: <ScheduleDevicesView scheduleId="abc123" />
```

## Notes

- Uses `'use client'` directive — requires a client-side render boundary.
- Falls back to an empty string (`''`) if the `id` query parameter is absent.
- Delegates all rendering logic to [`ScheduleDevicesView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/scripts/components/schedule-devices-view.tsx).
