Renders the edit schedule page by extracting a required `id` route parameter and delegating to `ScheduleCreateView` for the schedule editing UI.

## Key Components

- **`EditSchedulePage`** — Default page export that retrieves the schedule ID from the URL and renders the create/edit schedule form.
- **`useRequiredIdParam`** — Hook that validates and extracts the `id` param, redirecting to the new schedule route if absent.
- **`ScheduleCreateView`** — Shared component used for both creating and editing schedules, driven by the optional `scheduleId` prop.

## Usage Example

```typescript
// Rendered automatically by Next.js at:
// /scripts/schedules/[id]/edit

// When `id` is present → renders <ScheduleCreateView scheduleId="abc123" />
// When `id` is missing → redirects to routes.scripts.schedules.new
```

## Notes

- Uses `'use client'` directive — this is a Client Component.
- Returns `null` during the redirect cycle when no valid ID is found, preventing a flash of unstyled content.
- Reuses `ScheduleCreateView` for both new and edit flows, with `scheduleId` acting as the discriminator.
