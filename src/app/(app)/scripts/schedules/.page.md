Thin Next.js client page that reads a `scheduleId` from the URL search params and delegates rendering to `ScheduleDetailView`.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ScheduleDetailPage` | `default` (React component) | Page entry point; extracts `id` query param and passes it to the detail view |

## Usage Example

```typescript
// Accessed via: /schedule/detail?id=abc123
// Next.js renders this page; useSearchParams pulls the id automatically

import ScheduleDetailPage from './page';

// Rendered by Next.js router — no manual props needed
<ScheduleDetailPage />
```

## Notes

- Marked `'use client'` — required because `useSearchParams` is a client-side hook
- Falls back to an empty string (`''`) if `id` is absent from the query string; downstream validation is handled by [`ScheduleDetailView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/schedule/components/schedule/schedule-details-view.tsx)
