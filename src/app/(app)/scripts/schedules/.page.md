Renders the Script Schedules page within the Scripts section, combining the tab navigation and schedules table into a single view.

## Key Components

- **`ScriptSchedulesV2Page`** — Default export; page component that composes the schedules UI
- **`ScriptsTabNavigation`** — Tab bar with `"schedules"` set as the active tab
- **`ScriptSchedulesTable`** — Table component displaying all configured script schedules

## Usage Example

```typescript
// Rendered automatically by Next.js at the /scripts/schedules route
// No manual instantiation required

// Internal composition:
<div className="flex flex-col w-full">
  <ScriptsTabNavigation activeTab="schedules" />
  <ScriptSchedulesTable />
</div>
```

## Notes

- Marked as a client component via `'use client'`
- Layout uses full-width flex column to stack navigation above the table
- Part of the Scripts feature set; see related files at [`scripts/components/`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/scripts/components/)
