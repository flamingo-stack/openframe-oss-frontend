Zustand store managing the state for scripts/automation library, including script entries, search filtering, and loading/error states.

## Key Components

### Interfaces

- **`ScriptEntry`** — Shape of a single script record, including metadata like `args`, `category`, `shell`, `syntax`, `supported_platforms`, and `favorite` flag
- **`ScriptsState`** — Combined state and action types for the store

### Store

- **`useScriptsStore`** — Zustand store created with `immer` (for mutable state updates) and `devtools` (Redux DevTools support, name: `scripts-store`)

### Actions

| Action | Description |
|---|---|
| `setScripts(scripts)` | Replaces the scripts array and clears any error |
| `setSearch(search)` | Updates the search filter string |
| `setLoading(loading)` | Sets the loading boolean |
| `setError(error)` | Sets an error message and stops loading |
| `clearScripts()` | Empties the scripts array and clears error |
| `reset()` | Resets all state to initial values |

### Selectors

Pre-defined selectors for optimized component re-renders: `selectLogs`, `selectSearch`, `selectIsLoading`, `selectError`

## Usage Example

```typescript
import { useScriptsStore, selectSearch, selectIsLoading } from './scripts-store';

function ScriptsList() {
  const scripts = useScriptsStore(state => state.scripts);
  const search   = useScriptsStore(selectSearch);
  const loading  = useScriptsStore(selectIsLoading);
  const setSearch = useScriptsStore(state => state.setSearch);

  if (loading) return <Spinner />;

  return (
    <>
      <input value={search} onChange={e => setSearch(e.target.value)} />
      {scripts.map(s => <div key={s.id}>{s.name}</div>)}
    </>
  );
}
```
