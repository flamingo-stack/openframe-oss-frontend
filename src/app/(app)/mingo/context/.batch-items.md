Provides batch-fetched, client-side searched and paginated context item sources for the Mingo chat context picker, covering legacy scripts and core users.

## Key Components

| Export | Description |
|---|---|
| `UserItems` | Fetches all users via paginated `/api/users` endpoint (up to 100 pages × 200 per page), then filters and paginates results entirely on the client. |
| `fetchAllScripts` | Internal async stub — returns `[]`. Retained until the legacy script route is retired. |
| `fetchAllUsers` | Internal async function that exhausts the paginated users API and maps rows to `ChatContextItem` shape. |

Both components share the same data-flow pattern:

1. **Fetch** — `useSuspenseQuery` loads the full batch once (5-minute `staleTime`).
2. **Filter** — `useMemo` + `matches()` applies the `query` string client-side.
3. **Page** — `useClientPaging` slices results for incremental rendering.
4. **Render** — `ContextItemsList` handles display, selection, and load-more.

## Usage Example

```typescript
// Inside a context picker that dispatches item sources by type:
import { UserItems } from './batch-items';

<UserItems
  query={searchQuery}
  selectedKeys={selectedKeys}
  onToggle={handleToggle}
  atLimit={selectedKeys.size >= MAX_CONTEXT_ITEMS}
/>
```

> **Note:** Script context resolves via `ScriptItems` in [`relay-items.tsx`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/relay-items.tsx); the legacy Tactical source has been removed.
