Presentational shell component for rendering inline mention chips (entity tags) within markdown text, with loading skeleton and error boundary states.

## Key Components

### `MentionTag`
Core chip component wrapping `Tag` (variant `badge`) as an inline `<span>` to avoid invalid HTML (`<div>` inside `<p>`). Accepts an optional `href` to render the chip as a new-tab link.

### `MentionTagSkeleton`
Loading state variant rendering a pulsing inline skeleton bar in place of the label — uses an inline `<span>` (not the library's block `Skeleton`) to remain valid inside `<p>` elements.

### `MentionErrorBoundary`
React class error boundary that catches fetch failures in per-type chips and renders a plain fallback chip instead of propagating the error and blanking the message.

### `CHIP_CLASS`
Tailwind utility string tuning the `Tag` badge skin for inline mention context: vertical centering (`align-middle`), max-width truncation, muted SVG icons, and neutral hover border.

## Usage Example

```typescript
import {
  MentionTag,
  MentionTagSkeleton,
  MentionErrorBoundary,
} from './mention-tag';

// Resolved chip with a link
<MentionTag
  icon={<TicketIcon />}
  label="TKT-1234"
  href="/tickets/1234"
/>

// Chip without a link (no pointer cursor)
<MentionTag icon={<UserIcon />} label="alice@example.com" />

// Loading state
<MentionTagSkeleton icon={<TicketIcon />} />

// With error boundary — shows plain ID chip if fetch throws
<MentionErrorBoundary fallback={<MentionTag label="#1234" />}>
  <AsyncTicketChip id="1234" />
</MentionErrorBoundary>
```

## Notes

- `as="span"` is required because chips are emitted inline inside `react-markdown` `<p>` elements — a block `<div>` root would cause an HTML violation and React hydration errors.
- The `label` prop wraps its value in a fragment (`<>{label}</>`) to suppress `Tag`'s native `title` tooltip, which appears unpolished on hover.
