Renders self-fetching mention chips for REST and AI-agent GraphQL entity types (policy, query, user, script, ticket), using TanStack `useSuspenseQuery` for async resolution with graceful degradation on fetch failure.

## Key Components

### Resolvers

| Function | Entity | Data Source | Route |
|---|---|---|---|
| `resolvePolicy` | Fleet policy | `fleetApiClient.getPolicy` | `/monitoring/policy/{id}` |
| `resolveQuery` | Fleet query | `fleetApiClient.getQuery` | `/monitoring/query/{id}` |
| `resolveUser` | User | `GET /api/users/{id}` | *(none)* |
| `resolveScript` | Legacy Tactical script | Degraded (no-op) | `/scripts/details/{id}` |
| `resolveTicket` | AI-agent ticket | `POST /chat/graphql` | `/tickets/dialog?id={id}` |

All resolvers return `{ label, href? }` and **never throw** — they fall back to `{ label: id }` on error.

### `RESOLVERS`

A `Record<string, resolver>` map keyed by marker string, enabling runtime dispatch without a switch statement.

### `RestInner` *(internal)*

Calls `useSuspenseQuery` with a 5-minute stale time. Prefers `fallbackLabel` over the raw `id` when the resolver could not find the entity.

### `RestMentionChip` *(exported)*

Public wrapper that composes `MentionErrorBoundary` + `Suspense` + `RestInner`, rendering `MentionTagSkeleton` while loading and a static `MentionTag` on error.

## Usage Example

```typescript
// Render a ticket mention chip with a known fallback label
<RestMentionChip
  marker="ticket"
  id="686a1f2e3c4d5e6f7a8b9c0d"
  fallbackLabel="Printer offline – floor 3"
  icon={<TicketIcon />}
/>

// Render a policy chip (no fallback needed)
<RestMentionChip marker="policy" id="42" />
```

> **Script dispatch note:** Numeric IDs resolve via this legacy Tactical resolver; 24-character ObjectIds are dispatched to `GraphqlMentionChip` in `render-mention.tsx`.
