Mingo AI chat page component — the standalone full-page interface for the Mingo AI assistant, handling dialog management, real-time messaging, model display, and sidebar navigation.

## Key Components

| Export/Hook | Description |
|---|---|
| `Mingo` (default export) | Root page component rendering the full Mingo chat UI |
| `useMingoChat` | Manages message sending, dialog creation, typing state, and approvals |
| `useMingoDialogs` | Fetches paginated list of chat dialogs for the sidebar |
| `useMingoDialogSelection` | Handles dialog switching, message loading, and approval actions |
| `useMingoRealtimeSubscription` | Subscribes to live message/token-usage updates via websocket |
| `useMingoMessagesStore` | Zustand store holding `activeDialogId`, unread counts, and token usage |
| `useMingoDialog` | Provides dialog reset utilities |

## Usage Example

```typescript
// Rendered automatically by Next.js at /mingo
// Direct usage is handled by the router — not instantiated manually.

// Feature flag + mode guard (inside the component):
useEffect(() => {
  if (!isSaasTenantMode() || featureFlags.mingoSidebar.enabled()) {
    router.replace(routes.dashboard); // redirect away from legacy surface
  }
}, [router]);

// Selecting a dialog programmatically via the sidebar:
handleDialogSelect('dialog-abc-123');
// → updates URL (?dialogId=...), subscribes to realtime, loads messages

// Sending a message in a draft (new) chat:
await sendMessage({ content: 'How do I reset a user password?' });
// → creates dialog if none active, streams assistant response
```

## Notes

- **Legacy surface**: When the `mingo-sidebar` feature flag is enabled, this page redirects to `/dashboard`; Mingo moves into the in-layout sidebar drawer instead.
- **Draft state**: With no `dialogId` in the URL, the page renders a "new chat" welcome screen rather than an empty state.
- **Token usage**: Resolved from the realtime store first, falling back to the dialog query result to prevent flicker on dialog switches.
- **Model row**: Displays a skeleton until the active dialog's data settles, preventing the skeleton → default model → token pop-in flash.
