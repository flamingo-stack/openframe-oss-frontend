Zustand store that tracks the Mingo agent's navigation context — the entity currently open in the UI (`openView`) and up to five recently visited entities (`recentViews`) — persisting recents to localStorage and sending both with every Mingo chat message.

## Key Components

### `useMingoContextStore`
Zustand store (with `devtools` + `persist` middleware) exposing:

| Member | Description |
|---|---|
| `openView` | The entity detail page currently mounted, or `null`. Not persisted — stale on reload. |
| `recentViews` | Last N visited entities (deduped `type:id`, most-recent-first). Persisted to localStorage. |
| `setOpenView(ref)` | Sets the current entity; rolls the previous `openView` into `recentViews` and removes the incoming entity from recents. |
| `clearOpenView(ref?)` | Nullifies `openView` and rolls it into `recentViews`. Accepts the original ref to guard against navigation-ordering races (stale unmounts can't clobber a newer page's view). |
| `removeView(ref)` | Hard-drops an entity from both `openView` and `recentViews` without promoting it — backs the composer context-memory dismiss (×) button. |
| `clearRecentViews()` | Wipes `recentViews` (dev/debug). |

### `clearMingoContext()`
Resets both in-memory state and the persisted localStorage entry. Must be called on logout to prevent one user's entity context (device names, ticket titles, customer names) leaking into the next session on a shared browser.

### `rollIntoRecents()` (internal)
Prepends a ref to the recents list, deduplicates by `type:id`, and caps length at `RECENT_VIEWS_MAX`.

## Usage Example

```typescript
// On an entity detail page — register the open view
import { useMingoContextStore } from '@/stores/mingo-context-store';

function useTrackOpenView(ref: ContextRefWithLabel) {
  const { setOpenView, clearOpenView } = useMingoContextStore();

  useEffect(() => {
    setOpenView(ref);
    return () => clearOpenView(ref); // stale-unmount safe
  }, [ref.type, ref.id]);
}

// On logout — wipe context to prevent cross-session leakage
import { clearMingoContext } from '@/stores/mingo-context-store';

async function handleLogout() {
  await authService.logout();
  clearMingoContext();
}

// In the Mingo composer — read context for outbound messages
const { openView, recentViews } = useMingoContextStore();
// → forwarded to POST /chat/api/v1/messages
```
