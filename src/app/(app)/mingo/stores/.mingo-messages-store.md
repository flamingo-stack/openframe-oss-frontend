Zustand store managing all real-time messaging state for the Mingo AI chat interface, including dialog management, message CRUD, streaming segments, approval workflows, and tool execution tracking.

## Key Components

### Store Interface: `MingoMessagesStore`

Defines the complete state shape and action signatures, organized into:

| Category | State Keys |
|---|---|
| Messages | `messagesByDialog`, `streamingMessages`, `segmentAccumulators` |
| Dialogs | `activeDialogId`, `dialogs` |
| Real-time | `typingStates`, `unreadCounts`, `tokenUsageByDialog` |
| Streaming | `highestStreamSeqByDialog` |
| UI States | `isLoadingDialog`, `isLoadingMessages`, `isCreatingDialog` |
| Pagination | `hasMoreMessages`, `messagesCursor`, `newestMessageCursor` |

### Key Actions

- **`setMessages` / `addMessage` / `updateMessage` / `removeMessage`** — Immutable CRUD operations on per-dialog message arrays
- **`prependWithBoundaryMerge`** — Prepends paginated messages while patching a boundary message (used during history load)
- **`updateApprovalStatusInMessages`** — Syncs `approved`/`rejected` status into both stored and currently-streaming messages for `approval_request` and `approval_batch` segments
- **`updateToolExecutionInMessages`** — Scans newest-first to pair `EXECUTING`/`EXECUTED` tool events by `executionRequestId` or by `(integratedToolType, toolFunction)` fallback; returns `boolean` indicating match success
- **`updateStreamingMessageSegments` / `appendSegmentsToLastAssistant`** — Handles real-time token streaming with optional JetStream `streamSeq` deduplication
- **`getOrCreateAccumulator` / `resetAccumulator`** — Manages `MessageSegmentAccumulator` instances with optional approval callbacks per dialog

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store';

// Read state
const messages = useMingoMessagesStore(state => state.getMessages(dialogId));
const isLoading = useMingoMessagesStore(state => state.isLoadingMessages);

// Add a message
useMingoMessagesStore.getState().addMessage(dialogId, newMessage);

// Stream segments in real-time
useMingoMessagesStore.getState().updateStreamingMessageSegments(
  dialogId,
  incomingSegments,
  streamSeq,
);

// Resolve an approval
useMingoMessagesStore.getState().updateApprovalStatusInMessages(
  dialogId,
  requestId,
  'approved',
  resolvedByName,
);

// Get or create a segment accumulator with approval handlers
const accumulator = useMingoMessagesStore.getState().getOrCreateAccumulator(dialogId, {
  onApprove: (id) => handleApprove(id),
  onReject: (id) => handleReject(id),
});
```
