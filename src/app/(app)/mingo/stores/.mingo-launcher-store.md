Manages the global open/closed state of the Mingo chat drawer and a one-shot `pendingPrompt` queue, lifted out of `AppShell` so any page or component can programmatically open Mingo and auto-send a prompt.

## Key Components

### `MingoLauncherStore` (interface)

| Member | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Whether the Mingo chat drawer is currently open |
| `pendingPrompt` | `string \| null` | One-shot prompt queued for auto-send; `null` once consumed |
| `setOpen` | `(open: boolean) => void` | Explicitly set drawer open state |
| `toggle` | `() => void` | Toggle drawer open/closed |
| `close` | `() => void` | Close the drawer |
| `sendToMingo` | `(prompt: string) => void` | Open drawer and queue a prompt for auto-send |
| `consumePendingPrompt` | `() => string \| null` | Atomically read and clear the pending prompt |

### `useMingoLauncherStore`

Zustand store instance with `devtools` middleware (named `mingo-launcher-store`).

## Usage Example

**Triggering Mingo from a quick-action chip (e.g. onboarding):**

```typescript
import { useMingoLauncherStore } from '@/stores/mingo-launcher-store';

function OnboardingChip() {
  const sendToMingo = useMingoLauncherStore(s => s.sendToMingo);

  return (
    <button onClick={() => sendToMingo('How do I set up my first client?')}>
      Meet Mingo
    </button>
  );
}
```

**Draining the pending prompt inside the chat embedder:**

```typescript
import { useMingoLauncherStore } from '@/stores/mingo-launcher-store';

function OpenframeEmbeddableChatEntry() {
  const consumePendingPrompt = useMingoLauncherStore(s => s.consumePendingPrompt);

  useEffect(() => {
    const prompt = consumePendingPrompt();
    if (prompt) sendInNewDialog(prompt);
  }, []);
}
```

> **Note:** `consumePendingPrompt` is safe against double-consume — it only calls `set` when the prompt is non-null, preventing redundant re-renders.
