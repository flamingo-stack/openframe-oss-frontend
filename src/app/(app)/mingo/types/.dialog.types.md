TypeScript interfaces and types modeling GraphQL dialog data structures for the Mingo AI chat/dialog system, including pagination, ownership, token usage, and streaming state.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `DialogTokenUsage` | Interface | Token consumption metrics per dialog (input, output, total, context sizes) |
| `DialogStreamState` | Type | Union literal — `'IDLE'` or `'STREAMING'` |
| `DialogNode` | Interface | Core dialog entity with owner (client/admin union), lifecycle timestamps, rating, and token usage |
| `DialogEdge` | Interface | Relay-style cursor wrapper around a `DialogNode` |
| `DialogConnection` | Interface | Paginated collection of edges with `pageInfo` for cursor-based pagination |
| `DialogsResponse` | Interface | Top-level GraphQL response shape for a dialogs list query |
| `DialogResponse` | Interface | Top-level GraphQL response shape for a single dialog query |
| `UseMingoDialogsOptions` | Interface | Options bag for the `useMingoDialogs` hook — filtering, pagination, and ownership scope |

## Usage Example

```typescript
import type {
  DialogNode,
  DialogConnection,
  UseMingoDialogsOptions,
} from './dialog.types';

// Typed hook options
const options: UseMingoDialogsOptions = {
  enabled: true,
  search: 'printer',
  limit: 20,
  scope: 'my', // only the signed-in admin's dialogs
};

// Narrowing the owner union at runtime
function getOwnerLabel(dialog: DialogNode): string {
  const { owner } = dialog;
  if (owner?.type === 'CLIENT') {
    return `Machine: ${owner.machine?.hostname ?? owner.machineId}`;
  }
  if (owner?.type === 'ADMIN') {
    const { firstName, lastName } = owner.user ?? {};
    return `Admin: ${firstName ?? ''} ${lastName ?? ''}`.trim();
  }
  return 'Unknown';
}

// Iterating a paginated connection
function firstPage(connection: DialogConnection): DialogNode[] {
  return connection.edges.map((edge) => edge.node);
}
```

> **Owner union note:** `DialogNode.owner` merges `ClientDialogOwner` (machine fields) and `AdminDialogOwner` (user fields) into a single shape. Use the `type` discriminant (`'CLIENT'` | `'ADMIN'`) to safely access the correct branch, as shown above.
