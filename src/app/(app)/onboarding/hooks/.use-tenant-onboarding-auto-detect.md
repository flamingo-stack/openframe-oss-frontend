Detects completed tenant onboarding steps by comparing live data signals against per-step criteria, then persists newly completed steps to the backend in the background.

## Key Components

### `useTenantOnboardingAutoDetect(): Set<TenantOnboardingStep>`

The sole export. Returns `completedByData` — the set of steps whose data conditions are currently satisfied — so the UI can optimistically mark steps as done before the background mutation round-trips.

**Data sources:**

| Signal | Transport | Notes |
|---|---|---|
| MSP profile, org count, device count | Relay (`store-and-network`) | Single query; no waterfall |
| Active user count | TanStack `useSuspenseQuery` → REST `api/users` | Counts `items` filtered to `ACTIVE` status; avoids `totalElements` over-reporting |

**Completion criteria:**

| Step | Condition |
|---|---|
| `MSP_SETUP` | `name` + `website` + `logo` all non-empty |
| `CUSTOMERS_SETUP` | `orgCount > 1` (default org excluded) |
| `DEVICE_MANAGEMENT` | At least one `ONLINE`/`OFFLINE` device |
| `COMPANY_TEAM` | 2+ active users (owner + one teammate) |

**Mutation serialization:** Steps are persisted one at a time via `completeTenantStepInBackground`. Each mutation updates the store, triggering the next `useEffect` run for the following step. This prevents concurrent last-write-wins clobbering when multiple steps complete simultaneously.

> ⚠️ **Temporary stopgap** — this client-side detect-and-write-back exists until the backend computes `completedSteps` authoritatively inside `tenantOnboardingProgress`. Delete this hook when that lands.

**Suspense requirement:** Both data fetches suspend. This hook must be rendered inside a `Suspense` boundary (see `InitialSetupCard`).

## Usage Example

```typescript
// Must be inside a <Suspense> boundary and only mounted while onboarding is active
function InitialSetupCard() {
  const completedByData = useTenantOnboardingAutoDetect();
  const backendCompleted = useOnboardingStore(s => s.tenant?.completedSteps ?? []);

  // Union: show step as done if either source confirms it
  const allCompleted = new Set([...backendCompleted, ...completedByData]);

  return (
    <StepList steps={TENANT_ONBOARDING_STEPS} completed={allCompleted} />
  );
}
```
