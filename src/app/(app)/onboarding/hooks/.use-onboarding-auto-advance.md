Manages guided single-open accordion state for onboarding flows, automatically expanding the first incomplete step and scrolling it into view as progress advances.

## Key Components

### Constants

- **`ANCHOR_TOP_OFFSET_PX`** (`80`) — Top offset used when anchoring a row into view; exported so page-level `navigateSamePageHash` calls use the same landing position
- **`ACCORDION_ANIMATION_MS`** (`250`) — Delay before measuring scroll position to let accordion expand/collapse animations settle

### `useOnboardingAutoAdvance<T extends string>(steps, completedSteps, options)`

Core hook returning accordion control accessors:

| Return | Description |
|---|---|
| `nextStep` | First incomplete step in display order; `null` when all done |
| `expandedOf(step)` | Returns `true` if the given step is currently open |
| `onExpandedChangeOf(step)` | Returns a change handler that opens/closes and anchors the clicked row |
| `refOf(step)` | Returns a stable ref callback for attaching a DOM node to a step row |

### Options (`AutoAdvanceOptions<T>`)

| Option | Default | Description |
|---|---|---|
| `scrollOnMount` | `false` | Scrolls to the initially open step on mount |
| `urlStep` | `null` | URL-synced open step; hook adopts external hash changes (back/forward) |
| `onOpenStepChange` | — | Callback reporting every open/close transition |

## Usage Example

```typescript
const STEPS = ['profile', 'billing', 'integration'] as const;
type Step = typeof STEPS[number];

function OnboardingPage() {
  const [urlStep, setUrlStep] = useState<Step | null>(null);
  const completed: Step[] = ['profile'];

  const { nextStep, expandedOf, onExpandedChangeOf, refOf } =
    useOnboardingAutoAdvance(STEPS, completed, {
      scrollOnMount: true,
      urlStep,
      onOpenStepChange: step => setUrlStep(step),
    });

  return (
    <>
      {STEPS.map(step => (
        <OnboardingAccordionItem
          key={step}
          ref={refOf(step)}
          expanded={expandedOf(step)}
          onExpandedChange={onExpandedChangeOf(step)}
        />
      ))}
    </>
  );
}
```
