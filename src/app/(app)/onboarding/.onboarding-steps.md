Defines the canonical step order and counting utilities for the tenant "Initial Setup" and user "Get Started" onboarding flows, serving as the single source of truth for step counts and render order.

## Key Components

**Constants**
- `TENANT_ONBOARDING_STEPS` — Ordered array of 4 `TenantOnboardingStep` values driving the dashboard "Initial Setup" card
- `USER_ONBOARDING_STEPS` — Ordered array of 8 `UserOnboardingStep` values driving the `/onboarding` "Get Started" page

**Functions**

| Function | Description |
|---|---|
| `onboardingStepAnchorId(step)` | Converts a step enum value to a DOM id / URL hash fragment (e.g. `CUSTOMERS_SETUP` → `step-customers-setup`) |
| `onboardingStepFromAnchorId(steps, anchorId)` | Reverse lookup — returns the matching step or `null` if the fragment is unknown |
| `countCompleted(steps, completedSteps)` | Returns how many steps from the ordered list appear in the completed set |
| `isStepDone(step, completedSteps)` | Returns whether a single step is in the completed set |

## Usage Example

```typescript
import {
  TENANT_ONBOARDING_STEPS,
  USER_ONBOARDING_STEPS,
  onboardingStepAnchorId,
  onboardingStepFromAnchorId,
  countCompleted,
  isStepDone,
} from '@/constants/onboarding-steps';

// Progress bar: "2 of 4 steps complete"
const tenantProgress = countCompleted(TENANT_ONBOARDING_STEPS, completedTenantSteps);

// Deep-link to an accordion block
const anchor = onboardingStepAnchorId('CUSTOMERS_SETUP');
// → "step-customers-setup"
router.push(`/onboarding#${anchor}`);

// Resolve a URL hash back to a step enum value
const step = onboardingStepFromAnchorId(USER_ONBOARDING_STEPS, 'step-tickets');
// → UserOnboardingStep.TICKETS

// Conditionally render a checkmark
if (isStepDone(UserOnboardingStep.MEET_MINGO, completedUserSteps)) {
  showCompletionBadge();
}
```
