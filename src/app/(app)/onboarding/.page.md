Route entry point for the onboarding (Get Started) experience. Unconditional — every tenant has this route.

## Key Components

| Export | Type | Description |
|---|---|---|
| `OnboardingPage` | `default` (page component) | Next.js App Router page component that renders the onboarding flow |
| `OnboardingContent` | Component | The primary onboarding UI, loaded asynchronously |
| `OnboardingSkeleton` | Component | Suspense fallback shown while `OnboardingContent` is loading |

## Usage Example

This is a Next.js route module — it is not imported directly. It is resolved automatically at the `/onboarding` path and renders with a streaming Suspense boundary:

```typescript
// Rendered output (simplified)
<Suspense fallback={<OnboardingSkeleton />}>
  <OnboardingContent />
</Suspense>
```

## Notes

- Marked `'use client'` — runs in the browser despite being a page-level component.
- Suspense boundary ensures the skeleton is shown immediately while `OnboardingContent` resolves any async data or lazy imports.
- See [`OnboardingContent`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/onboarding/components/onboarding-content.tsx) and [`OnboardingSkeleton`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/onboarding/components/onboarding-skeleton.tsx) for rendering details.
