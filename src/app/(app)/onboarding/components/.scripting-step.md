Renders the "Scripting" onboarding step — a trimmed version of the full add-script form that lets users create their first script directly from the onboarding flow.

## Key Components

- **`ScriptingStep`** — Main exported component. Renders a condensed script creation form with platform selection, shell type, timeout, name, and a code editor. On submission, calls `createScriptMutation` via Relay and redirects to the new script's detail page with a coach-mark hint.
- **`onboardingScriptSchema`** — Zod schema validating the subset of script fields exposed in onboarding (`name`, `shell`, `default_timeout`, `run_as_user`, `supported_platforms`, `script_body`).
- **`handleAddScript`** — Form submit handler that merges onboarding values with `EDIT_SCRIPT_DEFAULT_VALUES`, maps via `formToWriteInput`, and commits the Relay mutation.

## Usage Example

```typescript
import { ScriptingStep } from './scripting-step';

function OnboardingFlow() {
  const [completed, setCompleted] = useState(false);

  return (
    <ScriptingStep
      onComplete={() => setCompleted(true)}
      completed={completed}
      completing={false}
    />
  );
}
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `onComplete` | `() => void` | Called when the step is marked complete or a script is successfully created |
| `completed` | `boolean` | Whether the step has already been completed |
| `completing` | `boolean` | Whether the completion action is in progress (controls button busy state) |

## Notes

- Windows platform is pre-selected by default; timeout defaults to 90 seconds.
- On successful script creation, automatically marks the step complete and navigates to the script detail page with the `scripts` coach-mark hint via [`onboardingHintUrl`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/features/onboarding/onboarding-coach-marks.ts).
- A "Full Script Form" link opens the complete form in a new tab for advanced options.
