Renders the tenant onboarding "Initial Setup" card on the Dashboard, managing a four-step guided flow (MSP Setup, Customers, Device Management, Company & Team) with auto-advance behavior, background completion, and a matching loading skeleton.

## Key Components

### `InitialSetupCard` (exported)
Mount gate component. Renders nothing until onboarding progress has loaded and a tenant record exists. Permanently hides after `tenant.completed` is set, with a ref-latch to keep the "Setup Complete" victory view visible during the current mount.

### `InitialSetupCardContent` (internal)
The card body. Suspends via `useTenantOnboardingAutoDetect` until all step counts resolve. Merges backend-persisted `completedSteps` with live-data-derived completions. Auto-commits `completeTenantInBackground` exactly once when all steps are done. Delegates accordion expand/collapse and scroll-into-view to `useOnboardingAutoAdvance`.

### `InitialSetupSkeleton` (exported)
Pixel-identical loading placeholder driven by the same `STEP_META` array as the card. Used as the `<Suspense>` fallback on the dashboard so the loading → loaded transition has no layout shift.

### `STEP_META` (internal constant)
Single source of truth for the four steps' icons, titles, and descriptions — shared between the real card and the skeleton.

## Usage Example

```typescript
// Dashboard layout — one Suspense boundary covers both loading states
import { Suspense } from 'react';
import { InitialSetupCard, InitialSetupSkeleton } from './initial-setup-card';

export function DashboardContent() {
  return (
    <Suspense fallback={<InitialSetupSkeleton />}>
      <InitialSetupCard />
    </Suspense>
  );
}
```

The card self-hides when `tenant.completed === true`, so no conditional rendering is needed at the call site.
