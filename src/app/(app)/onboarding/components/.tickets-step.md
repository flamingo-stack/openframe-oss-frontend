Onboarding step component for the "Tickets" stage, rendering an informational walkthrough with a demo video, feature highlights, and context-aware footer actions.

## Key Components

- **`TicketsStep`** — Main exported component that renders the full tickets onboarding step. Accepts `onComplete`, `onCompleteBackground`, `completed`, and `completing` props to manage step state transitions.
- **`LabeledBlock`** — Internal helper that renders an uppercase section label with associated content below it.
- **`INSIDE_TICKET_POINTS`** — Static list of five capability bullet points describing what users can do inside an open ticket.
- **`DEMO_VIDEO_ID`** — YouTube video ID (`Ch984JTweV8`) used as a placeholder until real onboarding videos are produced.

## Behavior

The footer's right action is driven by `useTicketStatistics`:

- **No tickets yet** — Shows a passive `DotsLoaderIcon` + "Waiting for first ticket" indicator.
- **Ticket exists** — Replaces the waiting state with an accent "Go to Tickets" button that navigates to `/tickets` and silently completes the step in the background via `onCompleteBackground`.
- The ticket statistics fetch is gated behind `isSaasTenantMode()` — non-SaaS tenants remain in the waiting state permanently.

## Usage Example

```typescript
<TicketsStep
  completed={false}
  completing={false}
  onComplete={() => markStepDone('tickets')}
  onCompleteBackground={() => markStepDoneQuietly('tickets')}
/>
```
