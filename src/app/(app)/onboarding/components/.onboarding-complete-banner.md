Reusable "all steps complete" banner component rendered on onboarding surfaces once every step is finished, combining an emoji icon, title/description text, and an accent call-to-action button.

## Key Components

### `OnboardingCompleteBanner`
A client-side React component that renders a bordered banner with:
- **Emoji icon box** — 40px (mobile) / 48px (desktop), bordered, displayed in a styled box
- **Title + description** — stacked text using ODS typography tokens
- **Accent CTA button** — optional leading icon, full-width on mobile, auto-width on desktop

### `OnboardingCompleteBannerProps`

| Prop | Type | Required | Description |
|---|---|---|---|
| `emoji` | `string` | ✅ | Leading emoji (e.g. `"🎉"`) |
| `title` | `string` | ✅ | Primary heading text |
| `description` | `string` | ✅ | Secondary description text |
| `actionLabel` | `string` | ✅ | Accent CTA button label |
| `onAction` | `() => void` | ✅ | CTA click handler |
| `actionIcon` | `ReactNode` | ❌ | Optional icon for the CTA button |
| `className` | `string` | ❌ | Overrides outer background; defaults to `bg-ods-card` |

## Usage Example

```typescript
import { OnboardingCompleteBanner } from './onboarding-complete-banner';
import { CheckCircleIcon } from '@heroicons/react/24/outline';

// Initial Setup card variant (on bg-ods-bg surface)
<OnboardingCompleteBanner
  emoji="🎉"
  title="Setup Complete"
  description="You're all set to start using OpenFrame."
  actionLabel="Take the Product Tour"
  actionIcon={<CheckCircleIcon />}
  onAction={() => startProductTour()}
  className="bg-ods-bg"
/>

// Get Started page variant (raised card on bg-ods-bg surface)
<OnboardingCompleteBanner
  emoji="🎉"
  title="All Steps Done!"
  description="Your workspace is fully configured."
  actionLabel="Go to Dashboard"
  onAction={() => router.push('/dashboard')}
/>
```

## Notes

- The `className` prop controls the **outer background only** — pass `bg-ods-bg` when the banner sits on a `bg-ods-bg` surface (to appear as a bordered box), or omit it to use the default `bg-ods-card` (raised card appearance).
- Layout is responsive: emoji + text remain inline on mobile; the CTA drops to a second row, then all elements align horizontally on `md+` breakpoints.
