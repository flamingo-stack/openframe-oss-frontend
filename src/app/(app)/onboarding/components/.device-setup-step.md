Renders the "Device Management" onboarding step UI, allowing users to select a customer and OS platform, copy an OpenFrame agent install command, and mark the step as complete once a device comes online.

## Key Components

### `DeviceSetupStep` (exported component)

| Prop | Type | Description |
|------|------|-------------|
| `onComplete` | `() => void` | Called when "Mark as Complete" is clicked |
| `onCompleteBackground` | `() => void` | Called silently when navigating to Devices after connection |
| `completed` | `boolean` | Hides the "Mark as Complete" button when `true` |
| `completing` | `boolean` | Shows a loading spinner on the complete button |

**Internal hooks used:**

- `useDeviceOrganizations` — fetches tenant organizations for the customer selector
- `useInstallCommand` — derives the platform-specific install command and registration key
- `useDevicesOverview` — detects whether at least one device is already connected
- `useCopyToClipboard` — handles clipboard write with success/error feedback

**Rendering logic:**

- Displays a customer `Autocomplete` (with `OrgAvatar`) and an `OsPlatformSelector`
- Shows a clickable install-script box that copies the command to clipboard
- **No device connected:** shows a "Waiting for first device" animated indicator
- **Device connected:** shows "Mark as Complete" and "Go to Devices" actions; navigating to Devices fires `onCompleteBackground` silently

## Usage Example

```typescript
import { DeviceSetupStep } from '@/app/(app)/dashboard/onboarding/device-setup-step';

function OnboardingWizard() {
  const [completed, setCompleted] = useState(false);
  const [completing, setCompleting] = useState(false);

  const handleComplete = async () => {
    setCompleting(true);
    await markStepComplete('device-setup');
    setCompleted(true);
    setCompleting(false);
  };

  return (
    <DeviceSetupStep
      onComplete={handleComplete}
      onCompleteBackground={() => markStepComplete('device-setup')}
      completed={completed}
      completing={completing}
    />
  );
}
```

> **Note:** The step auto-detects a connected device via `useDevicesOverview` — no manual polling is required. Completion itself must be explicitly triggered by the parent via `onComplete`.
