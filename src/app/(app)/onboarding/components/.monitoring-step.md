Onboarding step component for creating a monitoring policy within the guided setup flow. Renders a trimmed policy creation form (name, SQL query, device assignment) and integrates with the full monitoring data layer to create policies and assign hosts.

## Key Components

- **`MonitoringStep`** — Main exported React component. Accepts `onComplete`, `completed`, and `completing` props to coordinate with the parent onboarding orchestrator.
- **`monitoringPolicySchema`** — Zod schema validating the policy `name` (required) and `query` fields.
- **`getDeviceKey`** — Helper that extracts a Fleet host ID from a `Device` object for use as a stable selector key.

## Usage Example

```typescript
import { MonitoringStep } from './monitoring-step';

function OnboardingFlow() {
  const [completed, setCompleted] = useState(false);

  return (
    <MonitoringStep
      completed={completed}
      completing={false}
      onComplete={() => setCompleted(true)}
    />
  );
}
```

## Behavior Notes

- On **"Add Policy"**: validates the form, calls `createPolicy`, optionally assigns selected devices via `useReplacePolicyHosts`, marks the step complete if not already done, then redirects to the new policy's detail page with the onboarding coach-mark hint appended.
- On **"Mark as Complete"**: skips policy creation and invokes `onComplete` directly.
- Device rows without a Fleet agent installed are disabled with an inline tooltip.
- A **"Full Policy Form"** external link opens the full create-policy page in a new tab.
