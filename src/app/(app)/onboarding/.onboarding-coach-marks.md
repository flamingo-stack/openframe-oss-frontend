Defines the configuration and utilities for onboarding coach-mark popups — contextual hints shown on destination pages when a user arrives from an onboarding flow.

## Key Components

| Export | Type | Description |
|---|---|---|
| `SETUP_HINT_PARAM` | `string` | URL query param key (`setupHint`) that signals an active coach-mark |
| `SETUP_RETURN_PARAM` | `string` | URL query param key (`setupReturn`) carrying the back-navigation path |
| `OnboardingHintKey` | `type` | Union of supported hint targets: `devices`, `customers`, `tickets`, `scripts`, `policies`, `logs`, `knowledge` |
| `ONBOARDING_COACH_MARKS` | `Record` | Title and body copy for each coach-mark, keyed by `OnboardingHintKey` |
| `isOnboardingHintKey()` | `function` | Type guard — validates that a raw string is a known `OnboardingHintKey` |
| `onboardingHintUrl()` | `function` | Builds a destination URL with both query params appended, safe to use when `target` already has a query string |

## Usage Example

```typescript
import {
  onboardingHintUrl,
  isOnboardingHintKey,
  SETUP_HINT_PARAM,
  SETUP_RETURN_PARAM,
} from './onboarding-coach-marks';

// Build a link that triggers the "devices" coach-mark,
// returning the user to the dashboard onboarding surface.
const url = onboardingHintUrl('/devices', 'devices', '/dashboard');
// → "/devices?setupHint=devices&setupReturn=%2Fdashboard"

// On the destination page, read and validate the param:
const hint = searchParams.get(SETUP_HINT_PARAM);
if (isOnboardingHintKey(hint)) {
  // Safe to use `hint` as OnboardingHintKey — show the popup.
  const { title, body } = ONBOARDING_COACH_MARKS[hint];
}

// Strip both params once the user dismisses the popup.
searchParams.delete(SETUP_HINT_PARAM);
searchParams.delete(SETUP_RETURN_PARAM);
```

> **Flow:** onboarding action calls `onboardingHintUrl()` → user lands on destination page → component reads `setupHint`, displays the matching popup → user dismisses → both params are removed from the URL.
