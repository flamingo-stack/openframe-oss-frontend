Static configuration file that defines the presentation metadata for all user onboarding steps in the OpenFrame "Get Started" flow, grouping steps with their icons, titles, and descriptions.

## Key Components

### Interfaces

- **`UserStepMeta`** — Metadata for a single onboarding step: its `UserOnboardingStep` enum value, icon node, title, and description.
- **`UserGroupMeta`** — A labeled group containing an array of `UserStepMeta` items.

### Constants

- **`USER_ONBOARDING_GROUPS`** — The single source of truth array of `UserGroupMeta` defining three onboarding groups:

| Group | Steps |
|---|---|
| Get set up | Customers Setup, Device Management |
| Run your operations | Tickets, Scripting, Monitoring, Logging |
| Work smarter with AI | Knowledge Management, Meet Mingo |

## Usage Example

```typescript
import {
  USER_ONBOARDING_GROUPS,
  type UserGroupMeta,
  type UserStepMeta,
} from './user-onboarding-groups';

// Render each group and its steps
USER_ONBOARDING_GROUPS.forEach((group: UserGroupMeta) => {
  console.log(group.label);

  group.items.forEach((item: UserStepMeta) => {
    console.log(`  ${item.title}: ${item.description}`);
  });
});
```

## Notes

- Contains **no runtime logic** — purely static metadata.
- Intentionally decoupled from completion status, which is fetched from the backend separately.
- Shared by both `onboarding-content` (live page) and `onboarding-skeleton` (loading state) to keep labels consistent and avoid drift.
