A minimal Next.js App Router page component that renders the Worktime feature by delegating entirely to the `WorktimeView` component.

## Key Components

- **`WorktimePage`** — Default page export that serves as the route entry point for the Worktime section. Marked as a Client Component via `'use client'`.

## Usage Example

This page is automatically rendered by Next.js when navigating to its corresponding route. No props are accepted.

```typescript
// Rendered automatically at the /worktime route (or equivalent)
// To reuse the view in another context, import WorktimeView directly:
import { WorktimeView } from './components/worktime-view';

function SomeOtherPage() {
  return <WorktimeView />;
}
```

## Notes

- All logic and UI are encapsulated in [`WorktimeView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/worktime/components/worktime-view.tsx) — refer to that component for implementation details.
- The `'use client'` directive ensures this page (and its subtree) opts into React's client-side rendering model.
