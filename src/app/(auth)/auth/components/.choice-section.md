Renders the authentication landing page's dual-purpose form, providing both "Create Organization" and "Sign In" flows with real-time validation and domain/email availability checks.

## Key Components

### `AuthChoiceSection`
Main exported component accepting:

| Prop | Type | Description |
|------|------|-------------|
| `onCreateOrganization` | `(orgName, domain, email) => void` | Callback when org creation is submitted |
| `onSignIn` | `(email) => Promise<void>` | Async callback for sign-in flow |
| `isLoading` | `boolean?` | Disables inputs during parent-controlled async ops |

### Internal Hooks & Utilities
- **`useEmailAvailability`** — Debounced real-time check; returns `'checking' | 'available' | 'taken' | 'blocked'`
- **`useDomainAvailability`** — Debounced domain check with auto-generated subdomain suggestions
- **`isSaasSharedMode`** — Toggles SaaS-specific domain input (appends `SAAS_DOMAIN_SUFFIX`) vs. self-hosted free-text domain
- **`authApiClient.checkDomainAvailability`** — Server-side domain uniqueness validation on submit; handles `TENANT_REGISTRATION_BLOCKED` (409) capacity errors

## Usage Example

```typescript
import { AuthChoiceSection } from './choice-section';

function AuthPage() {
  const handleCreateOrg = (orgName: string, domain: string, email: string) => {
    // Proceed to org setup wizard
    router.push(`/setup?org=${orgName}&domain=${domain}&email=${email}`);
  };

  const handleSignIn = async (email: string) => {
    await authService.initiateSignIn(email);
  };

  return (
    <AuthChoiceSection
      onCreateOrganization={handleCreateOrg}
      onSignIn={handleSignIn}
      isLoading={false}
    />
  );
}
```

## Validation Rules

- **Email**: RFC-style regex; blocks disposable/blocked domains via `BLOCKED_EMAIL_DOMAIN_MESSAGE`
- **Org name**: Unicode-aware regex, 2–100 chars, allows `& . , ' " ( ) -`
- **Domain (SaaS)**: Lowercased, alphanumeric + hyphens only; availability verified before `onCreateOrganization` fires

## Notes

- Submit is blocked while async availability checks are pending (`'checking'` status), preventing race conditions on Enter-key press
- Domain suggestion chips (from both real-time and submit-time checks) allow one-click selection
- `ForgotPasswordModal` is conditionally rendered via `showForgotPassword` state in the Sign In section
