A client-side React component that renders the user registration form for completing organization and account setup during the OpenFrame onboarding flow.

## Key Components

### `AuthSignupSection`

The primary exported component that handles new user registration. It supports both email/password signup and SSO provider authentication, adapting its UI and copy based on the deployment mode (SaaS shared vs. self-hosted).

**Props (`AuthSignupSectionProps`):**

| Prop | Type | Description |
|---|---|---|
| `orgName` | `string` | Pre-filled organization name (read-only) |
| `domain` | `string` | Pre-filled tenant domain (read-only) |
| `email` | `string?` | Optional pre-filled email address |
| `onSubmit` | `(data: RegisterRequest) => void` | Callback with collected registration data |
| `onSso` | `(provider: string) => void?` | Optional SSO provider callback |
| `onBack` | `() => void` | Navigation callback to previous step |
| `isLoading` | `boolean` | Disables inputs and shows loading state |

### `RegisterRequest`

Internal interface defining the registration payload submitted via `onSubmit`:

```typescript
interface RegisterRequest {
  tenantName: string;
  tenantDomain: string;
  firstName: string;
  lastName: string;
  email: string;
  password: string;
}
```

## Usage Example

```typescript
import { AuthSignupSection } from './signup-section';

function RegistrationPage() {
  const handleSubmit = (data: RegisterRequest) => {
    await registerTenant(data);
  };

  return (
    <AuthSignupSection
      orgName="Acme Corp"
      domain="acme.openframe.ai"
      email="admin@acme.com"
      onSubmit={handleSubmit}
      onSso={(provider) => initiateOAuth(provider)}
      onBack={() => router.back()}
      isLoading={false}
    />
  );
}
```

## Behavior Notes

- **Form validation** is inline: email format, password length (≥ 8 chars in SaaS shared mode), and password confirmation match are all checked before enabling the submit button.
- **SSO providers** are fetched via `useRegistrationProviders` and rendered with `AuthProvidersList` when available.
- **Button copy** adapts based on `isSaasSharedMode()`: `"Start Free Trial"` vs. `"Create Organization"`.
- **Enter key** submission is supported across all input fields.
