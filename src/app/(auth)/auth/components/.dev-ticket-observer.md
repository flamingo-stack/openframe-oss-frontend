Renders nothing to the DOM; monitors URL search parameters for a `devTicket` query parameter and triggers the ticket exchange flow when detected.

## Key Components

- **`DevTicketObserver`** — Client component that observes `searchParams` for a `devTicket` value, deduplicates repeated exchanges via a `lastTicket` ref, and delegates to `useDevTicketExchange().exchangeTicket()`.
- **`isEnabled` guard** — Disables the observer when `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` is falsy or when running inside the native shell (which handles ticket exchange via the `NativeAuth` plugin instead).

## Behavior Notes

- Returns `null` — purely a side-effect component, intended to be mounted once at the layout level.
- Deduplication: the `lastTicket` ref prevents re-triggering exchange if the same ticket appears on multiple renders.
- Native shell exclusion: mobile-app logins bypass this component entirely; the gateway 302-redirects the ticket directly to the app's custom URL scheme.

## Usage Example

Mount once in a root layout alongside a `Suspense` boundary (required because `useSearchParams` suspends):

```typescript
import { Suspense } from 'react';
import { DevTicketObserver } from '@/components/dev-ticket-observer';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <Suspense fallback={null}>
          <DevTicketObserver />
        </Suspense>
        {children}
      </body>
    </html>
  );
}
```

## Configuration

| Environment Variable | Effect |
|---|---|
| `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER=true` | Activates URL monitoring |
| *(native shell detected)* | Forces observer off regardless of env var |
