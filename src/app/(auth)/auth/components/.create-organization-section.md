Stateful wrapper component that connects the shared `CreateOrganizationForm` UI to the sign-up registration flow, handling field state, validation, email/domain availability checks, and SSO registration.

## Key Components

### `CreateOrganizationSection` (exported function component)

Owns all form state and validation logic before delegating submission upward via callbacks.

**Props (`CreateOrganizationSectionProps`):**

| Prop | Type | Description |
|---|---|---|
| `onCreateOrganization` | `(orgName, domain, email) => void` | Primary submit callback |
| `ssoProviders` | `AuthSsoProvider[]` | Optional SSO alternatives rendered below submit |
| `onSsoRegister` | `(orgName, domain, email, provider) => void` | SSO path with validated org details |
| `isLoading` | `boolean` | External loading state |

**Internal responsibilities:**
- **Email validation** — regex check + live availability via `useEmailAvailability`
- **Domain handling** — in SaaS shared mode: sanitizes input to `[a-z0-9-]`, live availability via `useDomainAvailability`, and a submit-time re-check via `authApiClient.checkDomainAvailability`
- **Capacity check** — handles `409 TENANT_REGISTRATION_BLOCKED` when no cluster capacity exists for new tenants
- **Domain suggestions** — merges real-time suggestions with submit-time fallback suggestions; renders as clickable `Button` chips
- **Shared submit path** — `runWithValidatedOrg` centralizes validation for both primary submit and SSO flows
