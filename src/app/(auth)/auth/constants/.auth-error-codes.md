Centralizes backend error code constants for authentication and registration endpoints, eliminating duplicated string literals across auth-related modules.

## Key Components

- **`AUTH_ERROR_CODE`** — Immutable constant object with two error codes:
  - `INVALID_ARGUMENT` — Returned when a request contains invalid input (e.g., malformed domain).
  - `TENANT_REGISTRATION_BLOCKED` — Returned when organization registration is not permitted.
- **`AuthErrorCode`** — Union type derived from `AUTH_ERROR_CODE` values (`'INVALID_ARGUMENT' | 'TENANT_REGISTRATION_BLOCKED'`), enabling type-safe error handling.

## Usage Example

```typescript
import { AUTH_ERROR_CODE, AuthErrorCode } from './auth-error-codes';

function handleRegistrationError(code: AuthErrorCode) {
  switch (code) {
    case AUTH_ERROR_CODE.INVALID_ARGUMENT:
      return 'Please enter a valid domain name.';
    case AUTH_ERROR_CODE.TENANT_REGISTRATION_BLOCKED:
      return 'Registration is currently unavailable for this domain.';
  }
}

// Type-safe comparison in domain availability check
if (error.code === AUTH_ERROR_CODE.TENANT_REGISTRATION_BLOCKED) {
  setDomainBlocked(true);
}
```

## Notes

- Consumed by the domain-availability check (`choice-section`) and organization registration handler (`use-auth`).
- The `as const` assertion ensures values are narrowed to string literals rather than `string`, preserving full type safety.
