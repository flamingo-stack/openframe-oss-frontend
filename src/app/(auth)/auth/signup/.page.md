Client-side route entry point for the signup page, using dynamic imports to disable SSR and show a loading fallback while the signup component loads.

## Key Components

- **`Signup`** — Default export; renders the dynamically imported `SignupPage` component.
- **`SignupPage`** — Dynamically imported from `@/app/(auth)/auth/pages/signup-page` with `ssr: false` to ensure client-only rendering.
- **`SignupLoading`** — Loading fallback component shown during the dynamic import chunk load.

## Usage Example

This file is automatically resolved by Next.js App Router at the `/auth/signup` route. No direct invocation is needed.

```typescript
// Rendered automatically when navigating to /auth/signup
// Dynamic import config:
const SignupPage = dynamic(() => import('@/app/(auth)/auth/pages/signup-page'), {
  ssr: false,                        // Disable server-side rendering
  loading: () => <SignupLoading />,  // Show skeleton/spinner while loading
});
```

> **Note:** The `ssr: false` flag prevents hydration mismatches for auth-related UI that depends on browser-only APIs (e.g., `localStorage`, `sessionStorage`).
