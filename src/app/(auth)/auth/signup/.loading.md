Provides the route-level loading UI for the `/auth/signup` path, rendering a skeleton placeholder while the signup page loads.

## Key Components

- **`SignupLoading`** (default export) — Next.js `loading.tsx` convention component that renders `AuthPageSkeleton` with the `"complete-account"` variant during signup route transitions.

## Usage Example

```typescript
// Automatically used by Next.js when navigating to /auth/signup.
// No manual import needed — Next.js picks up loading.tsx by convention.

// The skeleton variant used:
<AuthPageSkeleton variant="complete-account" />
```

## Notes

- Marked `'use client'` to allow client-side rendering of the skeleton animation.
- Delegates entirely to [`AuthPageSkeleton`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/auth/components/auth-page-skeleton.tsx) for consistent skeleton styling across auth routes.
