Re-exports from the `auth-store` module, providing a unified public API for authentication state management with aliased selector names.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AuthState` | Type | Shape of the authentication state object |
| `User` | Type | User entity type |
| `UserImage` | Type | User profile image type |
| `selectAuthError` | Selector | Authentication error state (aliased from `selectError`) |
| `selectIsAuthenticated` | Selector | Boolean authentication status selector |
| `selectAuthLoading` | Selector | Loading state selector (aliased from `selectIsLoading`) |
| `selectUser` | Selector | Current user data selector |
| `useAuthStore` | Hook/Store | Primary composable for accessing auth store |

## Usage Example

```typescript
import {
  useAuthStore,
  selectIsAuthenticated,
  selectUser,
  selectAuthError,
  selectAuthLoading,
} from '@/stores/auth';

import type { AuthState, User } from '@/stores/auth';

// Access authentication state
const isAuthenticated = useAuthStore(selectIsAuthenticated);
const currentUser = useAuthStore(selectUser);
const authError = useAuthStore(selectAuthError);
const isLoading = useAuthStore(selectAuthLoading);
```

## Notes

- Selector aliases (`selectAuthError`, `selectAuthLoading`) provide namespaced names to avoid collisions when importing from multiple stores.
- All types are re-exported as type-only to ensure tree-shaking compatibility.
