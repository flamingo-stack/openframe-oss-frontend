Root layout component for the authentication section of OpenFrame, setting page metadata and wrapping auth pages with the Reddit click ID capture component for ad attribution tracking.

## Key Components

- **`AuthLayout`** — Default export; wraps all auth route children with the `RedditClickIdCapture` tracker
- **`metadata`** — Next.js route segment metadata object setting the page `title` and `description` for all auth pages
- **`RedditClickIdCapture`** — Imported side-effect component that captures Reddit click IDs for conversion tracking

## Usage Example

This layout is automatically applied by Next.js to all routes nested under the `/auth` directory.

```typescript
// Automatically wraps pages like:
// /auth/login, /auth/register, /auth/forgot-password

// Any page in the auth segment receives this layout:
export default function LoginPage() {
  return <LoginForm />;
}
// Rendered as:
// <RedditClickIdCapture />
// <LoginForm />
```

## Notes

- Uses Next.js App Router [layout convention](https://nextjs.org/docs/app/building-your-application/routing/layouts-and-templates)
- The `RedditClickIdCapture` component is rendered outside `{children}` to ensure it fires regardless of which auth sub-page is active
- Metadata is inherited by all child routes unless overridden at the page level
