Route-level loading state for the `/auth/invite` page, rendering a skeleton UI while the Accept Invitation page loads.

## Key Components

- **`InviteLoading`** — Default export; a Next.js route-level loading component that renders `AuthPageSkeleton` configured for the "complete-account" variant without tabs.

## Usage Example

```typescript
// Automatically used by Next.js when navigating to /auth/invite
// No manual usage required — Next.js picks up loading.tsx automatically

import InviteLoading from '@/app/auth/invite/loading';

// Renders the skeleton during Suspense boundaries
<InviteLoading />
```

## Notes

- Uses the `"complete-account"` variant of [`AuthPageSkeleton`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/auth/components/auth-page-skeleton.tsx), matching the single-panel layout of the Accept Invitation flow — this page brings its own shell, so it uses the full-page skeleton rather than the card-only `AuthFormSkeleton`.
- Marked as `'use client'` to support client-side Suspense boundaries in Next.js App Router.
