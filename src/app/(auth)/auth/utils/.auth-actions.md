Provides a standalone async logout function that orchestrates the full sign-out sequence — push deregistration, server-side session teardown, local store cleanup, and post-logout navigation — without requiring the full `useAuth` hook.

## Key Components

### `performLogout()`

An exported async function that executes the complete logout flow in order:

1. **Push deregistration** — Calls `unregisterNativePush()` (best-effort) before tearing down the session, while the bearer token is still valid.
2. **Server-side logout** — Calls `authApiClient.logoutAsync(tenantId)` to invalidate the session on the backend.
3. **Store cleanup** — Calls `storeLogout()` to clear auth state and `clearMingoContext()` to prevent Mingo working context from leaking into the next session.
4. **Token clearing** — Awaits `clearTokens()` in bearer auth mode (required for native Keychain operations to complete before navigation).
5. **Navigation** — Redirects using `window.location.replace` (drops history):
   - **Native shell**: Reloads SPA root (`routes.root`) to avoid bouncing to the system browser.
   - **Shared host**: Redirects to `sharedHostUrl + routes.auth.login`.
   - **Default**: Redirects to `routes.auth.login`.

## Usage Example

```typescript
import { performLogout } from '@/lib/auth/actions/auth-actions';

// In a component that only needs logout (e.g., AppShell)
function LogoutButton() {
  return (
    <button onClick={performLogout}>
      Sign out
    </button>
  );
}
```

> **Note:** Use this function when you need logout functionality without the overhead of the full `useAuth` hook. It reads auth state directly from `useAuthStore.getState()`, making it safe to call outside of React's render cycle.
