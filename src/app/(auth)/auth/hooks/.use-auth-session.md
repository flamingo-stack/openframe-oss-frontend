Single source of truth for authentication session state, combining React Query for server-side session verification with Zustand for client-side auth store synchronization.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `authSessionQueryKey` | `const` | Stable React Query key `['auth', 'session']` for cache lookups |
| `useAuthSession` | Hook | Primary auth hook — fetches `/me`, syncs Zustand store, handles native shell cold-start |
| `invalidateAuthSession` | Function | Invalidates the session query from outside React components (e.g. post-login handlers) |
| `signOutToLogin` | Async Function | Hard sign-out for native shell paths — clears tokens, seeds query as `null`, redirects to `/auth` |
| `MeResponse` | Interface | Shape of the `/me` API response including user profile fields |

## Usage Example

```typescript
// Inside a route guard or layout component
import { useAuthSession } from '@/features/auth/hooks/use-auth-session';

function RouteGuard({ children }: { children: React.ReactNode }) {
  const { isReady, isAuthenticated, user, recheck } = useAuthSession();

  if (!isReady) return <Skeleton />;
  if (!isAuthenticated) return <Redirect to="/auth" />;

  return <>{children}</>;
}
```

```typescript
// Invalidate from outside React (e.g. login success callback)
import { invalidateAuthSession } from '@/features/auth/hooks/use-auth-session';
import { useQueryClient } from '@tanstack/react-query';

const queryClient = useQueryClient();
invalidateAuthSession(queryClient);
```

```typescript
// Native shell hard sign-out
import { signOutToLogin } from '@/features/auth/hooks/use-auth-session';

await signOutToLogin(queryClient, router);
```

## Behavior Notes

- **Native shell cold-start**: Waits for Keychain hydration via `initTokenStore()` before the first `/me` call; skips the call entirely when biometric lock is pending or no tokens exist
- **Error handling**: Transient errors (`5xx`, network) throw to preserve React Query's previous data; `401`/`403` resolve to `null` to render the sign-in page
- **Store sync**: Authenticated responses update the Zustand auth store and trigger a background `fetchFullProfile()`; confirmed `null` responses (non-error, idle) trigger `storeLogout()`
- **Polling**: Refetches on a configurable interval (`runtimeEnv.authCheckIntervalMs()`) only while authenticated; disabled for signed-out state
