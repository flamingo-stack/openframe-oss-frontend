Provides debounced React hooks for checking email address and subdomain availability during user registration, integrating with the auth API to surface real-time validation feedback.

## Key Components

### Types & Constants

- **`AvailabilityStatus`** — Union type representing check states: `'idle' | 'checking' | 'available' | 'taken' | 'blocked' | 'error'`
- **`BLOCKED_EMAIL_DOMAIN_MESSAGE`** — User-facing message for disposable/privacy email domains
- **`EMAIL_REGEX`** — Internal regex used to skip API calls for malformed email input

### Hooks

- **`useEmailAvailability(email, delay?)`** — Debounced check against the auth API for whether an email is already registered or uses a blocked domain. Validates format before firing. Returns `AvailabilityStatus`.
- **`useDomainAvailability(subdomain, orgName, enabled, delay?)`** — Debounced subdomain availability check. Returns `{ status, suggestions }` where `suggestions` contains alternative subdomains (stripped of the SaaS domain suffix) when the requested subdomain is taken.

Both hooks cancel in-flight requests on cleanup to prevent stale state updates.

## Usage Example

```typescript
import {
  useEmailAvailability,
  useDomainAvailability,
  BLOCKED_EMAIL_DOMAIN_MESSAGE,
} from './use-registration-availability';

function RegistrationForm() {
  const [email, setEmail] = useState('');
  const [subdomain, setSubdomain] = useState('');
  const [orgName, setOrgName] = useState('');

  const emailStatus = useEmailAvailability(email);
  const { status: domainStatus, suggestions } = useDomainAvailability(
    subdomain,
    orgName,
    subdomain.length > 0,
  );

  return (
    <>
      <input value={email} onChange={e => setEmail(e.target.value)} />
      {emailStatus === 'blocked' && <p>{BLOCKED_EMAIL_DOMAIN_MESSAGE}</p>}
      {emailStatus === 'taken' && <p>Email already registered.</p>}

      <input value={subdomain} onChange={e => setSubdomain(e.target.value)} />
      {domainStatus === 'taken' && (
        <p>Try: {suggestions.join(', ')}</p>
      )}
    </>
  );
}
```

## Notes

- Default debounce delay is **400 ms** for both hooks; override via the `delay` parameter.
- `useDomainAvailability` also debounces `orgName` to prevent redundant re-checks on every keystroke.
- Backends omitting `reason` on unavailable emails are treated as `'taken'` for backwards compatibility.
