React hook providing authentication actions — login, registration, logout, and tenant discovery — for both native shell and browser environments.

## Key Components

**`useAuth()`** — Primary export. Manages auth flow state via `localStorage` and exposes the following:

| Member | Type | Description |
|--------|------|-------------|
| `discoverTenants` | `async fn` | Queries tenant info for a given email address |
| `registerOrganization` | `async fn` | Creates a new tenant with email/password credentials |
| `loginWithSso` | `async fn` | Initiates SSO login; handles native shell vs. browser redirects |
| `logout` | `async fn` | Revokes tokens, clears cache, and redirects appropriately |
| `reset` | `fn` | Clears all transient auth state |
| `email`, `tenantInfo`, `availableProviders` | `state` | Persisted across page loads via `localStorage` |
| `isLoading`, `isInitialized`, `discoveryAttempted` | `state` | UI control flags |

**Interfaces exported:**
- `TenantDiscoveryResponse` — Shape of the tenant discovery API response

    isLoading,
