React hook that fetches available SSO providers and the invited email address for a given invitation ID, used to populate the invite acceptance screen.

## Key Components

### `SsoProvider` (exported interface)
Represents a single SSO provider entry:
- `provider` — provider identifier string (e.g., `"google"`, `"microsoft"`)
- `enabled` — boolean flag (always `true` for fetched providers)

### `useInviteProviders(invitationId)`
Custom hook that calls `authApiClient.getInviteProviders` when an `invitationId` is present and returns:

| Return Value | Type | Description |
|---|---|---|
| `providers` | `SsoProvider[]` | List of available SSO providers |
| `email` | `string` | Pre-filled invited email (read-only on accept screen) |
| `loading` | `boolean` | `true` while request is in-flight |
| `error` | `string \| null` | Error message if fetch fails |

Loading initializes to `true` when an `invitationId` is provided, preventing flash of empty state. Re-fetches automatically when `invitationId` changes.

## Usage Example

```typescript
import { useInviteProviders } from '@/hooks/use-invite-providers';

export function InviteAcceptPage({ invitationId }: { invitationId: string }) {
  const { providers, email, loading, error } = useInviteProviders(invitationId);

  if (loading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <>
      <p>Accepting invite for: {email}</p>
      {providers.map(({ provider }) => (
        <SsoButton key={provider} provider={provider} />
      ))}
    </>
  );
}
```
