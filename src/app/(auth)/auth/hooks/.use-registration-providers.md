React hook that fetches available SSO registration providers from the auth API and exposes their loading and error states.

## Key Components

- **`SsoProvider`** — exported interface representing a single SSO provider with `provider` (name string) and `enabled` (boolean) fields
- **`RegistrationProvidersResponse`** — internal interface for the raw API response shape (`{ providers: string[] }`)
- **`useRegistrationProviders()`** — client-side React hook that calls `authApiClient.getRegistrationProviders()` on mount and returns formatted provider state

## Usage Example

```typescript
import { useRegistrationProviders } from '@/hooks/use-registration-providers';

export function SsoLoginOptions() {
  const { providers, loading, error } = useRegistrationProviders();

  if (loading) return <Spinner />;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {providers
        .filter(p => p.enabled)
        .map(p => (
          <li key={p.provider}>{p.provider}</li>
        ))}
    </ul>
  );
}
```

## Behavior Notes

- Backed by React Query with an infinite `staleTime`, so it fetches once per page and re-reads the cache on later mounts
- On a successful response, raw provider strings are mapped to `SsoProvider` objects with `enabled: true`
- On API failure or a caught exception, `providers` is reset to `[]` and `error` is populated with the message
- `loading` is `query.isPending` — false for a query that has not started, unlike `isLoading`
