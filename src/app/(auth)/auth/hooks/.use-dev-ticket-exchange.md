Exchanges a developer ticket for authentication tokens via the auth API, then synchronizes session state and navigates to the dashboard on success.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useDevTicketExchange` | Hook | Returns `exchangeTicket` callback for performing the dev ticket exchange flow |
| `exchangeTicket` | `async (ticket: string) => Promise<{success, status, tokens}>` | Submits the ticket, stores returned tokens, invalidates auth session cache, and redirects |

## Usage Example

```typescript
import { useDevTicketExchange } from './use-dev-ticket-exchange';

function DevTicketPage({ ticket }: { ticket: string }) {
  const { exchangeTicket } = useDevTicketExchange();

  useEffect(() => {
    exchangeTicket(ticket);
  }, [ticket, exchangeTicket]);

  return <p>Signing you in...</p>;
}
```

## Behavior

1. Calls `authApiClient.devExchange(ticket)` with the provided ticket string
2. Extracts and stores `accessToken` / `refreshToken` from response headers via `useTokenStorage`
3. Invalidates the `authSessionQueryKey` React Query cache to trigger a session recheck
4. Shows a success toast and navigates to the dashboard using `router.replace` (preserving clean back-stack history)
5. On any failure, surfaces a destructive toast and returns `success: false`

## Notes

- Uses `router.replace` instead of `router.push` to prevent the auth/ticket screen from appearing in browser history after login
- Token presence check (`accessToken || refreshToken`) guards against redirecting on empty responses
- Session sync is delegated entirely to `useAuthSession` after cache invalidation — this hook does not write to the user store directly
