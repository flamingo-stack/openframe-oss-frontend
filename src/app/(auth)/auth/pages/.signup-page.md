The "Complete your Account" step in the organization registration flow, handling user profile details (name + password) collection and SSO provider shortcuts after the initial Create Organization step.

## Key Components

- **`SignupPage`** — Default export; Next.js Client Component that renders the second step of organization signup
- **`CompleteAccountForm`** — Renders the name/password fields and SSO provider buttons from `@flamingo-stack/openframe-frontend-core`
- **`AuthShell`** — Layout wrapper with a `TabSelector` toggling between Sign Up and Login views
- **`useAuth`** — Provides `registerOrganization` and `registerOrganizationSso` mutation handlers
- **`useRegistrationProviders`** — Fetches available SSO providers (Google, Microsoft) from the backend
- **`useAuthStore`** — Reads `isAuthenticated` to redirect on successful signup

## Key Behaviors

| Behavior | Detail |
|---|---|
| Guard: missing session data | Redirects to `/auth` if `sessionStorage` lacks `auth:org_name`, `auth:domain`, or `auth:email` |
| Guard: already authenticated | Replaces route to dashboard (prevents back-navigation to signup) |
| Password validation | Minimum 8 characters; confirms match before enabling submit |
| SSO filtering | Only providers returned by the backend AND in `['google', 'microsoft']` are shown |
| PR Number field | Conditionally rendered via `runtimeEnv.prNumberEnabled()`; digits-only input |
| Submit label | `"Start Free Trial"` in SaaS shared mode, `"Create Organization"` otherwise |

## Usage Example

```typescript
// Rendered automatically via Next.js file-based routing.
// Prerequisite: sessionStorage must be populated by the prior step.
sessionStorage.setItem('auth:org_name', 'Acme Corp');
sessionStorage.setItem('auth:domain', 'acme');
sessionStorage.setItem('auth:email', 'admin@acme.com');

// Then navigate to:
router.push('/auth/signup');
```
