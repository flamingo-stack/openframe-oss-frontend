Generates the `robots.txt` file for the Next.js application, instructing all web crawlers to disallow access to every route.

## Key Components

- **`dynamic`** – Exported constant set to `'force-static'`, ensuring the route is pre-rendered at build time and compatible with `output: 'export'` (static export mode).
- **`robots()`** – Default export function returning a `MetadataRoute.Robots` object that blocks all user agents from indexing any path.

## Usage Example

Next.js automatically serves the return value of this function at `/robots.txt`. No manual invocation is needed.

```typescript
// Resolved robots.txt output:
// User-agent: *
// Disallow: /
```

> **Note:** The current configuration disallows all crawlers from all routes (`/`). To allow specific paths, update the `rules` object accordingly:

```typescript
rules: {
  userAgent: '*',
  allow: '/',
  disallow: ['/admin', '/api'],
},
```
