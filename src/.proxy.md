Route access control utility for Next.js middleware that enforces path-based permissions based on the active application deployment mode (`oss-tenant`, `saas-tenant`, or `saas-shared`).

## Key Components

- **`getMode()`** — Reads `NEXT_PUBLIC_APP_MODE` from environment variables, defaulting to `'oss-tenant'` if unset.
- **`isAllowed(pathname)`** — Determines whether a given path is accessible in the current mode. Static asset paths (`/_next`, `/static`, `/favicon`, etc.) are always allowed. Mode-specific rules:
  - `saas-shared`: only `/auth` and `/` are permitted
  - `saas-tenant`: all paths except `/auth` are permitted
  - `oss-tenant`: all paths are permitted
- **`defaultRedirect()`** — Returns the fallback redirect path for blocked routes (`/auth` for `saas-shared` and `oss-tenant`, `/dashboard` for `saas-tenant`).
- **`proxy(request)`** — The main middleware handler; redirects blocked requests and passes allowed ones through.
- **`config`** — Middleware matcher that excludes static assets from processing.

## Usage Example

```typescript
// middleware.ts
import { proxy } from '@/middleware/proxy';
import { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  return proxy(request);
}

export { config } from '@/middleware/proxy';
```

```bash
# .env.local
NEXT_PUBLIC_APP_MODE=saas-tenant
```

## Deployment Modes

| Mode | Allowed Paths | Redirect |
|---|---|---|
| `oss-tenant` | All paths | `/auth` |
| `saas-tenant` | All except `/auth` | `/dashboard` |
| `saas-shared` | `/` and `/auth` only | `/auth` |
