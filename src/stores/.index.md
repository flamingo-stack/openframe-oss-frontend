Central barrel export for all Zustand stores in the OpenFrame frontend, consolidating authentication, device management, and feature flag stores into a single importable module.

## Key Components

### Re-exported Stores

| Store | Source | Description |
|---|---|---|
| `useAuthStore` | `auth-store` | Authentication state management |
| `useDevicesStore` | `devices-store` | Device listing and filtering |
| `useFeatureFlagsStore` | `feature-flags-store` | Feature flag toggling |

### Auth Selectors (`auth-store`)

- `selectIsAuthenticated` — Boolean authentication status
- `selectUser` — Current authenticated user
- `selectAuthError` — Auth error state (aliased from `selectError`)
- `selectAuthLoading` — Auth loading state (aliased from `selectIsLoading`)

### Device Selectors (`devices-store`)

- `selectDevices` — Full device list
- `selectFilteredDevices` — Devices after filter is applied
- `selectSelectedDevice` — Currently selected device
- `selectDeviceStats` — Aggregated device statistics
- `selectFilter` — Active filter config
- `selectDevicesError` / `selectDevicesLoading` — Status selectors

## Usage Example

```typescript
// Import stores and selectors from a single entry point
import {
  useAuthStore,
  selectIsAuthenticated,
  selectUser,
  useDevicesStore,
  selectFilteredDevices,
  useFeatureFlagsStore,
} from '@/stores';

function MyComponent() {
  const isAuthenticated = useAuthStore(selectIsAuthenticated);
  const user = useAuthStore(selectUser);
  const devices = useDevicesStore(selectFilteredDevices);
  const { flags } = useFeatureFlagsStore();
}
```

> **Note:** Selector-based subscriptions (e.g. `useAuthStore(selectUser)`) prevent unnecessary re-renders by only updating when the selected slice changes.
