A client-side Zustand store and utility functions for detecting and signaling subscription trial expiration from GraphQL errors.

## Key Components

- **`useSubscriptionLockSignal`** — Zustand store managing the `trialExpiredFromErrors` boolean flag, with `markTrialExpired()` and `reset()` actions
- **`hasTrialExpiredClassification(errors)`** — Pure function that checks if any GraphQL error in an array carries the `SUBSCRIPTION_TRIAL_EXPIRED` classification extension
- **`detectTrialExpiredFromGraphqlErrors(errors)`** — Side-effectful function that calls `markTrialExpired()` on the store when a trial-expired error is detected
- **`TRIAL_EXPIRED_CLASSIFICATION`** — Constant string `'SUBSCRIPTION_TRIAL_EXPIRED'` matched against `error.extensions.classification`

## Usage Example

```typescript
import {
  useSubscriptionLockSignal,
  detectTrialExpiredFromGraphqlErrors,
  hasTrialExpiredClassification,
} from './subscription-lock-signal';

// In a GraphQL response handler / Apollo error link
detectTrialExpiredFromGraphqlErrors(graphqlErrors);

// In a React component — react to lock state
function AppShell() {
  const trialExpired = useSubscriptionLockSignal(s => s.trialExpiredFromErrors);

  if (trialExpired) {
    return <SubscriptionExpiredBanner />;
  }

  return <MainLayout />;
}

// Check without triggering store (e.g. conditional logic)
if (hasTrialExpiredClassification(errors)) {
  console.warn('Trial has expired');
}

// Reset after handling (e.g. on logout)
useSubscriptionLockSignal.getState().reset();
```

## Notes

- Designed to be called from a global GraphQL error interceptor (e.g. Apollo `onError` link) so any query or mutation across the app can trigger the lock
- `detectTrialExpiredFromGraphqlErrors` uses `getState()` for imperative access outside React, keeping it safe to call in non-component contexts
