Orchestrates forced user logout by clearing tokens, resetting auth state, and optionally redirecting — with special handling for biometric lock states and SaaS tenant mode.

## Key Components

### `forceLogout(options?: ForceLogoutOptions): Promise<void>`
Main async logout handler. Sequentially:
1. Skips execution in SSR (`window === undefined`) or when biometric lock is active
2. Clears stored tokens via `clearTokens()`
3. Resets the auth store state via dynamic import
4. Clears Mingo working context (recent views + live store) to prevent session leakage
5. Redirects to the default auth path unless already on an auth page, SaaS tenant mode is active, or `shouldRedirect` is `false`

### `ForceLogoutOptions` interface
| Property | Type | Default | Description |
|---|---|---|---|
| `reason` | `string` | — | Optional log/diagnostic reason string |
| `shouldRedirect` | `boolean` | `true` | Whether to redirect after logout |
| `redirectPath` | `string` | — | Override for the redirect target |

### `hasStoredTokens(): boolean`
Synchronous check for existing tokens in storage. Delegates to `hasTokensSync()`.

### `clearStoredTokens(): void`
Fire-and-forget token clearance. Calls `clearTokens()` without awaiting.

## Usage Example

```typescript
import { forceLogout, hasStoredTokens } from '@/lib/force-logout';

// Basic forced logout with redirect
await forceLogout({ reason: 'session_expired' });

// Logout without redirect (e.g. during background token refresh failure)
await forceLogout({ shouldRedirect: false });

// Custom redirect target
await forceLogout({ redirectPath: '/auth/login?expired=true' });

// Guard before making authenticated requests
if (!hasStoredTokens()) {
  await forceLogout();
}
```

> **Biometric lock guard:** If `getBiometricLockState()` returns `'locked'`, `forceLogout` exits immediately without clearing tokens — preserving the Keychain so the biometric unlock gate can retry. Never call `clearStoredTokens()` as a workaround in this state.
