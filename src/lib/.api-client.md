Centralized HTTP client that handles authenticated API requests with automatic token refresh, cookie-based and bearer token auth support, and a single-flight 401 retry strategy.

## Key Components

### Classes & Instances

- **`ApiClient`** — Core class managing request building, auth headers, and error handling. Exported as a singleton `apiClient`.

### Methods

| Method | Description |
|---|---|
| `request<T>(path, options, isRetry)` | Core request method with 401 refresh logic |
| `get / post / put / patch / delete` | HTTP convenience wrappers |
| `external<T>(url, options)` | Requests to absolute external URLs, bypasses base URL construction |
| `me()` | Shorthand for `GET /api/me` |

### Interfaces

- **`ApiRequestOptions`** — Extends `RequestInit` with optional `headers` (typed as `Record<string, string>`) and `skipAuth` flag
- **`ApiResponse<T>`** — Normalized response shape: `{ data?, error?, status, ok }`

### Auth Behavior

- **Bearer mode**: attaches `Authorization: Bearer <token>` via `getAccessTokenSync()` when `isBearerAuthMode()` is true
- **Cookie mode**: relies on `credentials: 'include'` automatically
- **401 handling**: calls `refreshAccessToken(sentAtEpoch)` once (single-flight via `token-refresh-manager`), retries the original request on success, or calls `forceLogout()` on failure. Auth pages (`/auth/*`) short-circuit to prevent redirect loops.

## Usage Example

```typescript
import { apiClient } from './api-client';

// Typed GET request
const { data, error, ok } = await apiClient.get<User[]>('/api/users');

// POST with body
const result = await apiClient.post<CreateTicketResponse>(
  '/api/tickets',
  { title: 'Network issue', priority: 'high' }
);

// Skip auth for a public endpoint
const publicData = await apiClient.get('/api/status', { skipAuth: true });

// External API call (absolute URL, no base URL prepended)
const external = await apiClient.external('https://third-party.example.com/data');
```
