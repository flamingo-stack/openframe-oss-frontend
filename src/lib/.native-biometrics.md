Bridges the frontend to the native shell's biometric authentication plugin (iOS Face ID / Touch ID, Android Fingerprint / Face Unlock), providing safe wrappers that degrade gracefully to `false`/`unavailable` in non-native environments (web, Tauri desktop).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `BIOMETRIC_ERROR` | `const` | Canonical reject codes: `UNAVAILABLE`, `NO_TOKENS`, `CANCELED`, `INVALIDATED` |
| `isBiometricAvailable()` | `async function` | Checks hardware availability; always resolves (never throws) |
| `isBiometricLoginEnabled()` | `async function` | Returns whether the user has biometric login active |
| `enableBiometricLogin()` | `async function` | Enables biometric gating; propagates `UNAVAILABLE`, `NO_TOKENS`, `CANCELED` |
| `disableBiometricLogin()` | `async function` | Disables biometric gating; propagates `CANCELED`, `INVALIDATED` |
| `biometryLabel(type)` | `function` | Human-readable label (`"Face ID"`, `"Touch ID"`, `"Fingerprint"`, etc.) |
| `biometricsSupported()` | `function` | `true` only inside a capable native shell |
| `getBiometricLoginChoice()` | `function` | Reads persisted user enrollment decision from `localStorage` |
| `setBiometricLoginChoice(choice)` | `function` | Persists `'accepted'` or `'declined'` enrollment decision |

## Usage Example

```typescript
import {
  isBiometricAvailable,
  enableBiometricLogin,
  disableBiometricLogin,
  biometryLabel,
  BIOMETRIC_ERROR,
  getBiometricLoginChoice,
  setBiometricLoginChoice,
} from './native-biometrics';
import { nativeErrorCode } from './native-shell';

// Gate UI on hardware availability
const { available, biometryType } = await isBiometricAvailable();
if (available) {
  console.log(`Enroll with ${biometryLabel(biometryType)}`); // e.g. "Face ID"
}

// Enable with error handling
try {
  await enableBiometricLogin();
  setBiometricLoginChoice('accepted');
} catch (err) {
  const code = nativeErrorCode(err);
  if (code === BIOMETRIC_ERROR.CANCELED) {
    // User dismissed the prompt — revert toggle, no error toast needed
  } else if (code === BIOMETRIC_ERROR.NO_TOKENS) {
    // Session expired before enrollment — redirect to login
  }
}

// Suppress the enrollment offer once declined
if (getBiometricLoginChoice() === null) {
  // Show one-time enrollment prompt
  setBiometricLoginChoice('declined');
}
```

> **Platform behavior:** All async wrappers short-circuit to safe defaults (`false` / `{ available: false }`) when called outside a native shell, so no environment checks are needed at the call site.
