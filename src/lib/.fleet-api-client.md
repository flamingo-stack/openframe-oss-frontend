Typed HTTP client that wraps the base `apiClient` to proxy all requests through the FleetMDM server endpoint, exposing CRUD operations for Fleet policies, queries, hosts, and their host-assignment relationships.

## Key Components

### `FleetApiClient` class

The main class that builds Fleet-scoped URLs using `runtimeEnv.tenantHostUrl()` and delegates execution to `apiClient.request`.

**Base HTTP methods**

| Method | Description |
|---|---|
| `get` / `post` / `put` / `patch` / `delete` | Standard HTTP verbs, all returning `ApiResponse<T>` |
| `request` | Internal dispatcher that resolves the full Fleet URL and calls `apiClient` |

**Policy methods**

| Method | Description |
|---|---|
| `getPolicies(params?)` | List policies, optional `team_id` / `query` filter |
| `getPolicy(id)` | Fetch a single policy |
| `createPolicy(data)` | Create a new policy |
| `updatePolicy(id, data)` | Partial update via PATCH |
| `deletePolicy(id)` | Soft-delete via POST to `/delete` endpoint |
| `runPolicyOnHost(policyId, hostId)` | Trigger policy execution on a host |
| `getPolicyHosts` / `addHostsToPolicy` / `removeHostsFromPolicy` / `replacePolicyHosts` | Host assignment CRUD |

**Query methods**

| Method | Description |
|---|---|
| `getQueries(params?)` | Paginated query list |
| `createQuery` / `updateQuery` / `deleteQuery` | Query lifecycle |
| `runQuery` / `runLiveQuery` | Execute queries against hosts/labels/teams |
| `getQueryReport(id, params?)` | Fetch cached query report with sort options |
| `getQueryHosts` / `addHostsToQuery` / `removeHostsFromQuery` / `replaceQueryHosts` | Host assignment CRUD |

**Host methods**

| Method | Signature |
|---|---|
| `getHosts(params?)` | Paginated host list with rich filtering (`policy_id`, `policy_response`, `status`, etc.) |

### Exported interfaces

- `PolicyHost` — `{ id, hostname }`
- `FleetLabel` — label metadata including `label_type` and `label_membership_type`

## Usage Example

```typescript
import { fleetApiClient } from '@/lib/fleet-api-client';

// List policies for a team
const { data } = await fleetApiClient.getPolicies({ team_id: 1 });

// Create a query and run it live
const { data: created } = await fleetApiClient.createQuery({
  name: 'OS Version Check',
  query: 'SELECT version FROM os_version;',
  interval: 3600,
});

const { data: campaign } = await fleetApiClient.runLiveQuery({
  query: 'SELECT version FROM os_version;',
  query_id: created.id,
  selected: { hosts: [42], labels: [], teams: [] },
});
```

> **Note:** Page `0` is explicitly handled using `!== undefined` checks (not truthiness) to avoid silently dropping the first page when paginating query results.
