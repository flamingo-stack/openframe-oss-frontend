Builds the sidebar navigation item list for the OpenFrame application, dynamically including or excluding items based on app mode, feature flags, onboarding state, and unread notification counts.

## Key Components

### `OnboardingNavState` interface
Describes the optional onboarding chrome state passed to the nav builder:
- `inProgress` — whether the user's Get Started flow is active
- `remaining` — outstanding step count displayed as a badge

### `CATEGORY_BY_NAV_ID`
Internal mapping from navigation item IDs to `NotificationCategory` enum values, used to look up per-category unread counts.

### `getNavigationItems(pathname, unreadCounts?, onboarding?)`
Primary export. Returns a `NavigationSidebarItem[]` list based on:
- **App mode** — returns `[]` in `authOnly` mode; adds Tickets and Mingo only in `saasTenant` mode
- **Feature flags** — `timeTracker` adds Worktime; `helpCenter` adds Help Center
- **Onboarding state** — prepends an Onboarding item with a remaining-step badge when `inProgress` is `true`
- **Unread counts** — attaches `unreadCount` to any item whose `CATEGORY_BY_NAV_ID` category has a non-zero count

## Usage Example

```typescript
import { getNavigationItems } from '@/config/navigation-config';

const items = getNavigationItems(
  pathname,
  unreadCounts,        // UnreadCountsByCategory | undefined
  { inProgress: true, remaining: 3 }, // OnboardingNavState
);

// Pass items to the sidebar component
<NavigationSidebar items={items} />
```

## Notes

- The Scripts entry always appears with the label `"Scripts"` regardless of which route version is active — the v2 flag is intentionally not surfaced in the UI
- Unread counts are supplied by `UnreadCountsHydrator` from the `unreadCountsByCategory` query; a category absent from the map (or at zero) renders no badge
