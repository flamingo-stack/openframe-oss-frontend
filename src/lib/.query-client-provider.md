Wraps the TanStack `QueryClientProvider` to configure and expose a singleton `QueryClient` instance scoped to the React component tree.

## Key Components

- **`QueryClientProvider`** — Client component that initializes a `QueryClient` with shared default options and provides it to all descendant components via React context.

### Default Query Options

| Option | Value | Description |
|---|---|---|
| `staleTime` | `60000` ms | Data stays fresh for 60 seconds before re-fetching |
| `refetchOnWindowFocus` | `false` | Disables automatic re-fetch when the browser window regains focus |

## Usage Example

Wrap your app or layout root with this provider to enable TanStack Query throughout the component tree:

```typescript
import { QueryClientProvider } from '@/providers/query-client-provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <QueryClientProvider>
          {children}
        </QueryClientProvider>
      </body>
    </html>
  );
}
```

Child components can then consume the client via standard TanStack Query hooks:

```typescript
import { useQuery } from '@tanstack/react-query';

function MyComponent() {
  const { data } = useQuery({
    queryKey: ['example'],
    queryFn: fetchExample,
  });
}
```

## Notes

- The `QueryClient` is initialized inside `useState` to ensure a new instance is created per request in Next.js server-side rendering, preventing shared state across users.
- The `'use client'` directive is required because `useState` is used for client-side instantiation.
