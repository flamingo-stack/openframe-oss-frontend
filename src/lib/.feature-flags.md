Centralizes all feature flag definitions and resolution logic for the OpenFrame frontend, bridging server-loaded GraphQL flags with environment-variable fallbacks.

## Key Components

### `FEATURE_FLAG_NAMES`
A `const` array of all known flag names sent to the backend via the `feFeatureFlags` GraphQL query. The backend only returns flags explicitly listed here.

### `getFlagValue(flagName, envFallback)`
Internal helper that reads from the Zustand `useFeatureFlagsStore`. Returns the live server value when the store is loaded and contains the flag; otherwise falls back to the provided env-var default.

### `skeletonFlagEnabled(flagName, envFallback?)`
Specialized flag reader for **loading skeleton layouts**. Uses a three-tier resolution order — live store → last cached server response → env default — to prevent layout flicker when skeletons render before flags finish loading. Should **not** be used to gate real feature behavior.

### `featureFlags`
The primary exported object. Each entry exposes a single `enabled(): boolean` method backed by `getFlagValue`. All flags default to `false` unless explicitly overridden (e.g., `newOnboarding` falls back to `runtimeEnv.newOnboardingFlag()`).

### `FeatureFlagKey`
Utility type derived from `keyof typeof featureFlags` for type-safe flag key references.

## Usage Example

```typescript
import { featureFlags, skeletonFlagEnabled } from '@/lib/feature-flags';

// Gate real feature behavior
if (featureFlags.mingoSidebar.enabled()) {
  renderSidebar();
}

// Gate skeleton layout only (allows cache fallback)
const showSidebarSkeleton = skeletonFlagEnabled('mingo-sidebar');

// Type-safe flag key reference
function logFlag(key: FeatureFlagKey) {
  console.log(key, featureFlags[key].enabled());
}
```

## Notes

- `skeletonFlagEnabled` is strictly for placeholder UI shape — never for real behavior gating, as it trusts the browser cache.
- `testClock` and `scriptSchedules` are intentionally kept off by default; the backend controls their availability in sync with schema-level field exposure.
