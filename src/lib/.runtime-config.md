Centralizes runtime environment variable access for the Next.js application, providing typed accessors for all `NEXT_PUBLIC_*` configuration values with safe fallbacks.

## Key Components

### `getEnvVar(key)`
Private helper that resolves environment variables via `next-runtime-env`, with fallbacks to `window.process.env` and `process.env` for environments where the runtime env package throws.

### `runtimeEnv`
Exported configuration object with typed accessor methods:

| Method | Env Var | Default |
|---|---|---|
| `tenantHostUrl()` | `NEXT_PUBLIC_TENANT_HOST_URL` | Stored native tenant host or `''` |
| `sharedHostUrl()` | `NEXT_PUBLIC_SHARED_HOST_URL` | `''` |
| `appScheme()` | `NEXT_PUBLIC_MOBILE_APP_SCHEME` | `APP_SCHEME` constant |
| `gtmContainerId()` | `NEXT_PUBLIC_GTM_CONTAINER_ID` | `undefined` |
| `appMode()` | `NEXT_PUBLIC_APP_MODE` | `'oss-tenant'` |
| `appType()` | `NEXT_PUBLIC_APP_TYPE` | `'openframe-dashboard'` |
| `appUrl()` | `NEXT_PUBLIC_APP_URL` | `'https://openframe.dev'` |
| `devUrl()` | `NEXT_PUBLIC_DEV_URL` | `'http://localhost:4000'` |
| `authCheckIntervalMs()` | `NEXT_PUBLIC_AUTH_CHECK_INTERVAL` | `300000` (5 min) |
| `mobileTenantId()` | `NEXT_PUBLIC_MOBILE_TENANT_ID` | `''` |

## Usage Example

```typescript
import { runtimeEnv } from '@/lib/runtime-config';

// Resolve the active tenant API base URL
const apiBase = runtimeEnv.tenantHostUrl();

// Read auth polling interval
const interval = runtimeEnv.authCheckIntervalMs(); // e.g. 300000
```

> **Note:** `tenantHostUrl()` falls back to the persisted native shell host (`getStoredTenantHost()`), enabling a single mobile binary to serve any tenant without a rebuild.
