Typed bridge layer for accessing Capacitor native shell APIs (`window.Capacitor`) from the OpenFrame web app without a direct npm dependency on Capacitor packages.

## Key Components

### Constants & Types
- **`MOBILE_APP_SCHEME`** — Custom URL scheme (`com.openframe.app`) used for OAuth callback redirect in mobile ASWebAuthenticationSession flows
- **`BiometryType`** — Union type for supported biometric modalities (`'faceId' | 'touchId' | 'fingerprint' | 'face' | 'none'`)
- **`PushPermissionState`** — Push notification permission states forwarded from FCM/APNs

### Plugin Interfaces
- **`NativeAuthPlugin`** — Core auth bridge: OAuth login flow, dev-ticket exchange, token CRUD, biometric login, shell-owned token refresh, safe-area insets
- **`FirebaseMessagingPlugin`** — FCM push notification subset (permissions, registration token, listeners)
- **`SplashScreenPlugin`** — Splash screen show/hide
- **`StatusBarPlugin`** — Status bar style and WebView overlay control
- **`AppPlugin`** — Android back button listener and `exitApp`

### Detection & Plugin Accessors
- **`isNativeShell()`** — Returns `true` when `window.Capacitor.isNativePlatform()` is present
- **`nativePlatform()`** — Returns `'ios' | 'android' | null`
- **`nativeAuthPlugin()`**, **`firebaseMessagingPlugin()`**, **`splashScreenPlugin()`**, **`statusBarPlugin()`**, **`appPlugin()`** — Typed accessors that return `null` on web; callers no-op safely

### Tenant Host Persistence
- **`getStoredTenantHost()`** / **`storeTenantHost()`** — Persists the tenant origin in `localStorage` under `native:tenant-host-url` so shell-side networking survives restarts without a build-time env var

### Tauri Event Subscriptions
- **`onNativeTokenUpdate()`** — Listens to `native-auth:token-update` Tauri events for shell-driven token rotations
- **`onNativeNotificationClick()`** — Listens to `notification:click` Tauri events for OS-toast clicks forwarded from the Rust notification plane

### Chrome Initialization
- **`applyNativeSafeAreas()`** — Reads UIKit safe-area insets and writes them as CSS variables (`--native-safe-top/bottom/left/right`)
- **`hideSplashScreen()`** — Hides the launch splash with a 200 ms fade after token hydration settles
- **`initNativeStatusBar()`** — Sets overlay mode + `DARK` style (light text on dark chrome)
- **`initNativeChrome()`** — Orchestrates status bar + safe-area init on shell startup; rotation listener registered once

## Usage Example

```typescript
import {
  isNativeShell,
  nativePlatform,
  nativeAuthPlugin,
  onNativeTokenUpdate,
  initNativeChrome,
  hideSplashScreen,
} from '@/lib/native-shell';

// Guard native-only paths
if (isNativeShell()) {
  console.log('Running on:', nativePlatform()); // 'ios' | 'android'
}

// Perform OAuth login via the native browser context
const auth = nativeAuthPlugin();
if (auth) {
  const { callbackUrl } = await auth.start({
    url: 'https://gateway.example.com/oauth/authorize?...',
    callbackHost: 'gateway.example.com',
    callbackPath: '/oauth/callback',
    callbackScheme: 'com.openframe.app',
  });
}

// Subscribe to shell-driven token rotations (Tauri/desktop only)
onNativeTokenUpdate(({ accessToken, refreshToken }) => {
  if (!accessToken) {
    // Session ended in the shell — sign out the webview
    signOut();
  }
});

// Run once at app startup
await initNativeChrome();
await hideSplashScreen();
```

## Notes

- All plugin accessors return `null` on web — wrap calls with optional chaining (`plugin?.method()`) or an `if (isNativeShell())` guard to no-op gracefully.
- `AppPlugin.addListener` may return a sync handle rather than a `Promise` at runtime; normalize with `Promise.resolve()` before chaining `.then`/`.catch`.
- Biometric methods on `NativeAuthPlugin` are optional (absent on older shell builds); access them through [`native-biometrics.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/native-biometrics.ts) which guards for their presence.
