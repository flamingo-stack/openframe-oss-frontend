Detects the current deployment environment (cloud, self-hosted, or development) by inspecting hostname patterns at runtime. Designed for browser contexts with SSR-safe fallback.

## Key Components

| Export | Type | Description |
|---|---|---|
| `DeploymentType` | Type alias | Union: `'self-hosted' \| 'cloud' \| 'development'` |
| `DeploymentInfo` | Interface | Full detection result including all boolean flags and resolved hostname |
| `detectDeployment()` | Function | Core detection logic; matches hostname against cloud/dev pattern lists |
| `isCloud()` | Function | Quick boolean check for cloud deployment |
| `isSelfHosted()` | Function | Quick boolean check for self-hosted deployment |
| `isDevelopment()` | Function | Quick boolean check for local/dev environment |
| `getDeploymentType()` | Function | Returns the `DeploymentType` string for the current environment |

**Detection rules:**
- **Cloud** — hostname contains `openframe.ai`, `auth.openframe.ai`, or `app.openframe`
- **Development** — hostname contains `localhost`, `127.0.0.1`, `0.0.0.0`, or `.local`
- **Self-hosted** — any other custom domain (default fallback)

## Usage Example

```typescript
import {
  detectDeployment,
  isCloud,
  isSelfHosted,
  getDeploymentType,
} from '@/utils/deployment-detector';

// Full detection object
const deployment = detectDeployment();
console.log(deployment.type);      // 'cloud' | 'self-hosted' | 'development'
console.log(deployment.hostname);  // e.g. 'app.openframe.ai'

// Quick boolean helpers
if (isCloud()) {
  // Enable cloud-only features (e.g. managed auth)
}

if (isSelfHosted()) {
  // Show self-hosted setup prompts or licence keys
}

// Use in conditional rendering
const label = getDeploymentType(); // 'self-hosted'
```

> **SSR note:** `window` availability is guarded at runtime. When called server-side, `hostname` defaults to `'localhost'`, which resolves to `development`.
