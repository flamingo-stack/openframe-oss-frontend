Manages chunked file uploads to MeshCentral, supporting SHA-384 hash-based deduplication, resume-on-reconnect, and real-time progress reporting.

## Key Components

### `UploadTask` Interface
Tracks the state of a single upload operation, including byte offsets, chunk progress, status lifecycle (`pending` → `hashing` → `uploading` → `completed`/`failed`/`cancelled`), and optional hash for deduplication.

### `FileUploader` Class
Core uploader with a 64KB chunk size. Communicates over a WebSocket-style `sendMessage` callback and reports progress via `onProgress`.

| Method | Description |
|--------|-------------|
| `uploadFile(file, remotePath, checkHash?)` | Initiates an upload; hashes files ≤100MB before sending |
| `calculateFileHash(file)` | Returns SHA-384 hex digest of the file |
| `handleUploadStart(id, offset?)` | Responds to server-ready signal, begins chunk streaming |
| `handleUploadAck(id, confirmedOffset?)` | Advances progress and sends the next chunk on ACK |
| `handleHashResponse(id, exists, resumeOffset?)` | Skips upload if file exists; resumes at offset otherwise |
| `handleUploadDone(id)` | Marks task completed on server confirmation |
| `cancelUpload(id)` | Cancels and removes a task |
| `clearCompleted()` / `clearAll()` | Cleans up finished or all tasks |

## Usage Example

```typescript
import { FileUploader } from './file-uploader';

const uploader = new FileUploader(
  (data) => socket.send(data),       // sendMessage
  (progress) => console.log(progress) // onProgress
);

// Start upload (hashes file first if ≤100MB)
const uploadId = await uploader.uploadFile(file, '/remote/path/');

// Wire server responses to the uploader
socket.onmessage = ({ data }) => {
  const msg = JSON.parse(data);
  if (msg.action === 'uploadstart') uploader.handleUploadStart(msg.reqid, msg.offset);
  if (msg.action === 'uploadack')   uploader.handleUploadAck(msg.reqid, msg.offset);
  if (msg.action === 'uploadhash')  uploader.handleHashResponse(msg.reqid, msg.exists, msg.offset);
};

// Check for active uploads before closing
if (uploader.hasActiveUpload()) {
  console.log('Upload in progress, do not close');
}
```
