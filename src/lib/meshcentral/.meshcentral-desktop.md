Handles remote desktop input for MeshCentral connections, translating browser keyboard/mouse events into MeshCentral's binary KVM protocol and rendering JPEG/bitmap tile streams onto an HTML canvas.

## Key Components

### `DisplayInfo` Interface
Describes a remote display with position (`x`, `y`), dimensions (`w`, `h`), and a `primary` flag.

### `DesktopInputHandlers` Interface
Contract for attaching a canvas, managing view-only mode, and optional capabilities like Ctrl+Alt+Del, key combos, clipboard interception, and multi-display switching.

### `MeshDesktop` Class
Core implementation of `DesktopInputHandlers`. Key responsibilities:

| Member | Purpose |
|---|---|
| `attach(canvas)` | Binds mouse/keyboard event listeners and begins rendering |
| `detach()` | Removes all listeners and cleans up state |
| `setViewOnly(bool)` | Disables input forwarding |
| `sendKeyCombo(combo)` | Sends sequences like `"ctrl+alt+del"` via `comboToSequence` |
| `setClipboardInterceptor(fn)` | Hooks clipboard operations before forwarding to remote |
| `syncModifiersFromEvent(e)` | Reconciles stuck modifier keys against browser event flags |
| `flushMetaBuffer()` | Sends buffered Meta/Cmd keydown after a 50ms window |
| `releaseMetaSafely(vk, ext)` | Uses a Ctrl+Win chord to release Win key without triggering Start menu |

## Usage Example

```typescript
import { MeshDesktop } from './meshcentral-desktop';

const desktop = new MeshDesktop();

// Wire up binary sender (e.g. WebSocket)
desktop.setSender((data: Uint8Array) => ws.send(data));

// Attach to a canvas element
const canvas = document.getElementById('remote-screen') as HTMLCanvasElement;
desktop.attach(canvas);

// Feed incoming tile data from the server
ws.onmessage = (event) => {
  desktop.processData(new Uint8Array(event.data));
};

// Enable view-only mode
desktop.setViewOnly(true);

// Clean up
desktop.detach();
```

## Notes

- Meta/Cmd key is buffered for 50 ms to distinguish lone taps (which would open the Start menu) from Cmd+key chords.
- `suppressedKeys` prevents duplicate keyup events when clipboard combos are handled locally.
- Unicode-eligible keys are sent via `encodeUnicodeKey` instead of VK codes for accurate IME/international input.
