Utility class for constructing and managing MeshCentral file operation request payloads, with cross-platform path handling for both Unix (`/`) and Windows (`\`) file systems.

## Key Components

**`FileOperations` class**

- `generateRequestId()` — Produces unique request IDs using timestamp + counter
- `joinPath(base, segment)` — Cross-platform path joining with auto-detected separator
- `detectSeparator(path)` — Infers `\` or `/` from path content (private)
- `parsePath(path)` / `buildPath(segments)` — Converts between path strings and segment arrays
- `getParentPath(path)` — Resolves parent directory for both Unix and Windows paths
- `sanitizeName(name)` — Strips illegal filename characters
- `validatePath(path)` — Rejects traversal sequences (`.`, `..`)

**Request factory methods** — Each returns a typed `FileOperationRequest`:

| Method | MeshCentral Action |
|---|---|
| `createListDirectoryRequest` | `ls` |
| `createMakeDirRequest` | `mkdir` |
| `createRenameRequest` | `rename` |
| `createDeleteRequest` | `rm` |
| `createCopyRequest` / `createMoveRequest` | `copy` / `move` |
| `createZipRequest` / `createUnzipRequest` | `zip` / `unzip` |
| `createSearchRequest` / `createCancelSearchRequest` | `findfile` / `cancelfindfile` |
| `createGetFileRequest` / `createSetFileRequest` | `get` / `set` (base64 encoded) |

## Usage Example

```typescript
const ops = new FileOperations();

// List a directory
const listReq = ops.createListDirectoryRequest('C:\\Users\\admin');

// Create a subdirectory
const mkdirReq = ops.createMakeDirRequest('C:\\Users\\admin', 'reports');
// path → "C:\Users\admin\reports"

// Delete files (recursive)
const deleteReq = ops.createDeleteRequest('/var/log', ['app.log', 'error.log'], true);

// Search with wildcard auto-wrap
const searchReq = ops.createSearchRequest('/home/user', '.json');
// filter → "*. json*"

// Navigate to parent
const parent = ops.getParentPath('C:\\Users\\admin\\reports');
// → "C:\Users\admin"
```

## Notes

- `createSetFileRequest` automatically base64-encodes file content via `btoa`
- `createSearchRequest` wraps the filter in `*...*` wildcards automatically; passing an empty string defaults to `*`
- Windows drive-root paths (e.g. `C:`) are handled distinctly from UNC/relative paths
