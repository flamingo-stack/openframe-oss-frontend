Utility module for converting day-granular date filter values between UI `DateRange` objects, URL parameters, and UTC ISO instant strings for backend API requests.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `toDayParam` | Function | Serializes a `Date` to a `yyyy-MM-dd` string for use in URL params |
| `parseDayParam` | Function | Parses a `yyyy-MM-dd` URL param string back to a `Date`, returns `undefined` on invalid input |
| `dateRangeFromParams` | Function | Reconstructs a `DateRange` object from `dateFrom` / `dateTo` URL param strings |
| `dateRangeToInstantBounds` | Function | Converts a `DateRange` to inclusive UTC ISO instant bounds for backend range filtering; a single selected day (`from` only) is treated as a full-day range |

## Usage Example

```typescript
import {
  toDayParam,
  parseDayParam,
  dateRangeFromParams,
  dateRangeToInstantBounds,
} from './date-filter-params';

// Serialize a date for use in a URL query param
const param = toDayParam(new Date('2024-06-15')); // "2024-06-15"

// Reconstruct a DateRange from URL params
const range = dateRangeFromParams('2024-06-01', '2024-06-15');
// { from: Date('2024-06-01'), to: Date('2024-06-15') }

// Convert to UTC instant bounds for backend API requests
const bounds = dateRangeToInstantBounds(range);
// { from: "2024-06-01T00:00:00.000Z", to: "2024-06-15T23:59:59.999Z" }

// Single-day selection covers the full day
const singleDay = dateRangeToInstantBounds({ from: new Date('2024-06-15') });
// { from: "2024-06-15T00:00:00.000Z", to: "2024-06-15T23:59:59.999Z" }
```

## Notes

- All URL param serialization uses local time with `yyyy-MM-dd` format via `date-fns`.
- Backend bounds are always UTC ISO strings spanning full days (start-of-day → end-of-day).
- Invalid or empty param strings safely return `undefined` rather than throwing.
