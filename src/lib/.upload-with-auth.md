Provides authenticated file upload and delete utilities for multipart form submissions, supporting both cookie-based and Bearer token auth modes with a companion React hook for managing upload state.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `uploadWithAuth` | `async function` | POSTs a file via `multipart/form-data` to a given endpoint, returning the uploaded file URL |
| `deleteWithAuth` | `async function` | Sends an authenticated `DELETE` request to a given endpoint |
| `useAuthenticatedUpload` | React hook | Wraps `uploadWithAuth` with `isUploading` and `error` state management |

## URL Resolution

All three exports share the same endpoint normalization logic:

- **Absolute URLs** (`http...`) — used as-is
- **`/api` prefixed paths** — prepended with `runtimeEnv.tenantHostUrl()`
- **Relative paths** — prefixed with `runtimeEnv.tenantHostUrl() + /api`

## Response URL Extraction

`uploadWithAuth` checks multiple common response shapes for the returned file URL:

```text
data.url | data.imageUrl | data.file_url | data.data.url | data.data.imageUrl | data.image.imageUrl
```

## Usage Example

```typescript
// Standalone upload
import { uploadWithAuth, deleteWithAuth } from './upload-with-auth';

const fileUrl = await uploadWithAuth('/uploads/avatar', file, 'avatar');
await deleteWithAuth('/uploads/avatar/123');

// React hook usage
import { useAuthenticatedUpload } from './upload-with-auth';

function AvatarUploader() {
  const { upload, isUploading, error } = useAuthenticatedUpload();

  const handleChange = async (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (!file) return;
    const url = await upload('/uploads/avatar', file, 'avatar');
    if (url) console.log('Uploaded to:', url);
  };

  return (
    <>
      <input type="file" onChange={handleChange} disabled={isUploading} />
      {error && <p>{error}</p>}
    </>
  );
}
```
