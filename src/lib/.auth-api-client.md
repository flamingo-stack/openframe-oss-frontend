Dedicated HTTP client for all authentication-related API endpoints (`/me`, `/oauth/*`, `/sas/*`). Handles token injection, 401 retry logic with automatic token refresh, and supports both cookie-based and Bearer token auth modes.

## Key Components

### `AuthApiClient` Class

The primary class (exported as singleton `authApiClient`) with the following methods:

| Method | Description |
|---|---|
| `handleUnauthorized()` | Intercepts 401 responses, attempts token refresh, retries the request, or triggers force logout |
| `refresh()` | Calls `/oauth/refresh` to rotate tokens |
| `oauth()` | Generic handler for `/oauth/*` endpoints |
| `devExchange()` | Exchanges a dev ticket for session credentials |
| `discoverTenants()` | Finds tenants by email via `/sas/tenant/discover` |
| `checkDomainAvailability()` | Validates subdomain availability for SaaS org registration |
| `checkEmailAvailability()` | Checks email availability for new registrations |
| `registerOrganization()` | Registers a new SaaS organization with credentials |
| `acceptInvitation()` | Accepts a user invitation with password |
| `acceptInvitationSso()` | Accepts a user invitation via SSO redirect |
| `requestPasswordReset()` / `confirmPasswordReset()` | Password reset flow |
| `loginUrl()` | Builds the OAuth login redirect URL |
| `logout()` / `logoutAsync()` | Synchronous redirect or async fetch-based logout |

### Exported Constants & Types

| Export | Description |
|---|---|
| `SAAS_DOMAIN_SUFFIX` | Derived domain suffix used to construct full subdomains (e.g., `acme.flamingo.run`) |
| `AuthApiResponse<T>` | Standard response envelope: `{ data?, error?, status, ok }` |

### Internal Helpers

- **`buildAuthUrl(path)`** — Prepends `SHARED_HOST_URL` if set; otherwise returns the relative path
- **`request<T>()`** — Authenticated fetch with Bearer token injection and `sentAtEpoch`-aware 401 handling
- **`requestRefresh<T>()`** — Token-refresh-specific fetch; reads `Refresh-Token` from headers in Bearer mode
- **`requestPublic<T>()`** — Unauthenticated fetch for public endpoints (referenced but not shown in truncated source)

## Usage Example

```typescript
import { authApiClient } from './auth-api-client';

// Discover tenants for a given email
const { data, ok } = await authApiClient.discoverTenants('user@example.com');

// Register a new organization
const result = await authApiClient.registerOrganization({
  email: 'admin@acme.com',
  firstName: 'Alice',
  lastName: 'Smith',
  password: 'securePass123',
  tenantName: 'Acme Corp',
  tenantDomain: 'acme',
});

// Build an OAuth login URL and redirect
const loginUrl = authApiClient.loginUrl(tenantId, '/dashboard', 'google');
window.location.href = loginUrl;

// Async logout (mobile/Bearer mode)
await authApiClient.logoutAsync(tenantId);
```

> **Bearer mode:** When `isBearerAuthMode()` is true, tokens are injected via `Authorization: Bearer <token>` and `Refresh-Token` headers instead of relying on cookies.

> **Auth page guard:** `handleUnauthorized` skips refresh entirely on `/auth` routes to avoid wiping tokens immediately after a successful login.
