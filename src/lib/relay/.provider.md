Wraps the application (or a subtree) with the singleton Relay environment, enabling all descendant components to execute Relay queries, mutations, and subscriptions.

## Key Components

| Export | Type | Description |
|---|---|---|
| `RelayProvider` | React component | Client-side provider that injects the Relay environment into the React tree |
| `RelayProviderProps` | Interface | Accepts a single `children: ReactNode` prop |

## Usage Example

```typescript
// app/layout.tsx
import { RelayProvider } from '@/relay/provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <RelayProvider>
          {children}
        </RelayProvider>
      </body>
    </html>
  );
}
```

## Notes

- Marked `'use client'` — must live in the client component boundary (Next.js App Router).
- The Relay environment is retrieved via `getRelayEnvironment()` and memoized so the same singleton instance is stable across re-renders.
- Delegates to `ReactRelayProvider` from `react-relay`; all Relay hooks (`useLazyLoadQuery`, `useMutation`, etc.) in child components depend on this provider being present in the tree.
