Registers Next.js-specific implementations for the core embed shim layer, bridging Next.js routing, image, and dynamic import APIs into the framework-agnostic `@flamingo-stack/openframe-frontend-core` embed system.

## Key Components

- **`registerEmbedShims()`** — Main registration function that wires up all Next.js shims. Guarded by a `registered` flag to ensure it only runs once.
- **Navigation shim** — Maps `next/navigation` hooks (`useRouter`, `usePathname`, `useSearchParams`, `useParams`) and utilities (`redirect`, `permanentRedirect`, `notFound`) via `registerNavigation`.
- **Link shim** — Registers `NextLink` as the routing-aware anchor component via `registerLink`.
- **Image shim** — Registers `NextImage` for optimized image rendering via `registerImage`.
- **Dynamic shim** — Registers `nextDynamic` for lazy-loaded component support via `registerDynamic`.

The module auto-executes `registerEmbedShims()` on import, so simply importing the file is sufficient to activate all shims.

## Usage Example

```typescript
// Import once at the app entry point (e.g., layout.tsx or _app.tsx)
import '@/lib/register-embed-shims';

// Or call explicitly if deferred registration is needed
import { registerEmbedShims } from '@/lib/register-embed-shims';
registerEmbedShims(); // Safe to call multiple times — no-op after first call
```

> **Note:** This file is marked `'use client'` since Next.js navigation hooks are client-side only. It should be imported in client component boundaries or app entry points, not in React Server Components.
