Centralized application configuration system for the OpenFrame platform, providing typed interfaces and utility functions to manage app-level settings including navigation, layout, UI behavior, SEO, and structured data generation.

## Key Components

### Types & Interfaces
- **`AppType`** — Union type for supported app variants (`openframe-auth` | `openframe-dashboard`)
- **`AppConfig`** — Root configuration interface covering branding, SEO, layout, navigation, UI, footer, and contact
- **`NavigationMenuItem` / `NavigationSection`** — Typed structures for header, mobile, and sidebar navigation
- **`FooterConfig`** — Footer layout including sections, CTA, logo, and custom component slots

### Config Accessors
- **`getCurrentAppType()`** — Reads app type from runtime environment, defaults to `openframe-dashboard`
- **`getAppConfig(appType?)`** — Returns the `AppConfig` for the current or specified app type
- **`getAllAppConfigs()`** — Returns the full `APP_CONFIGS` record

### UI & Routing Utilities
- **`shouldShowComponent(component)`** — Checks config flags for `userMenu`, `mobileNav`, `searchBar`, `platformNav`, `adminNav`
- **`shouldShowAdminMenu(userRole?)`** — Returns true only when `showAdminMenuInHeader` is enabled and role is `super_admin`
- **`isRouteAllowed(pathname)`** — Evaluates allowed/restricted route lists with wildcard and prefix support
- **`getHeaderStyle()`** — Returns the active header style variant

### Asset & SEO Helpers
- **`getPlatformAssetPaths(appType?)`** — Constructs absolute URLs for favicon, OG image, manifest, and Apple touch icon
- **`getMetadataBaseUrl()`** — Resolves base URL from runtime env (browser-safe)
- **`generateStructuredData(config)`** — Produces Schema.org `WebSite` and `Organization` JSON-LD objects

## Usage Example

```typescript
import {
  getAppConfig,
  isRouteAllowed,
  shouldShowComponent,
  generateStructuredData,
} from './app-config';

// Retrieve active configuration
const config = getAppConfig();
console.log(config.name); // "OpenFrame"

// Guard a protected route
if (!isRouteAllowed('/admin/settings')) {
  router.push('/');
}

// Conditionally render navigation elements
const showSearch = shouldShowComponent('searchBar');

// Generate page-level structured data
const { schemaLd, organizationLd } = generateStructuredData(config);
```

> **Note:** Both `openframe-auth` and `openframe-dashboard` app types resolve to the same `openframeConfig` instance. The `APP_CONFIGS` map exists to support future divergence between auth and dashboard configurations.
