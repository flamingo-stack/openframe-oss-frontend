Constructs full image URLs by prepending the API base host and appending optional cache-busting hash parameters.

## Key Components

### `getFullImageUrl(imageUrl, hash?)`
Combines `buildFullUrl` and `appendImageHash` to produce a complete, absolute URL. Returns `undefined` if `imageUrl` is falsy.

### `appendImageHash(imageUrl, hash?)`
Appends `?v=<hash>` (or `&v=<hash>` if query params already exist) to any URL string without modifying its base. Preserves the input type `T` via generic cast — safe to call independently when the consumer handles host resolution.

### `buildFullUrl(imageUrl)` *(internal)*
Normalizes relative paths against `runtimeEnv.tenantHostUrl()`:

| Input form | Output |
|---|---|
| `https://...` / `http://...` | Returned as-is |
| `/api/...` | `{tenantHost}/api/...` |
| `/path` | `{tenantHost}/api/path` |
| `path` | `{tenantHost}/api/path` |

## Usage Example

```typescript
import { getFullImageUrl, appendImageHash } from './image-url';

// Build a full absolute URL with cache-busting
const url = getFullImageUrl('/uploads/logo.png', 'abc123');
// → "https://tenant.example.com/api/uploads/logo.png?v=abc123"

// Already absolute — host is not prepended
const external = getFullImageUrl('https://cdn.example.com/img.png', 'abc123');
// → "https://cdn.example.com/img.png?v=abc123"

// Apply hash only, let the consumer resolve the host
const hashed = appendImageHash('/api/uploads/avatar.png', 'def456');
// → "/api/uploads/avatar.png?v=def456"

// Null-safe — returns undefined
const empty = getFullImageUrl(null);
// → undefined
```
