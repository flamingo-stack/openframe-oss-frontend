Controls application mode configuration, determining whether the app runs in OSS tenant, SaaS tenant, or SaaS shared (auth-only) mode, and gating routes and UI accordingly.

## Key Components

### Type

- **`AppMode`** — Union type: `'oss-tenant' | 'saas-tenant' | 'saas-shared'`

### Mode Accessors

| Function | Returns |
|---|---|
| `getAppMode()` | Current `AppMode` from runtime env, defaults to `'oss-tenant'` |
| `isOssTenantMode()` | `true` when mode is `oss-tenant` |
| `isSaasTenantMode()` | `true` when mode is `saas-tenant` |
| `isSaasSharedMode()` | `true` when mode is `saas-shared` |

### Feature Flags

| Function | Description |
|---|---|
| `isAuthEnabled()` | Auth pages active in `oss-tenant` and `saas-shared` |
| `isAppEnabled()` | App pages active in `oss-tenant` and `saas-tenant` |
| `isAuthOnlyMode()` | Alias for `saas-shared` (backward compat) |
| `isFullAppMode()` | Alias for `oss-tenant` or `saas-tenant` |

### Routing Utilities

- **`isRouteAllowedInCurrentMode(pathname)`** — Enforces per-mode route access; blocks `/auth` in `saas-tenant` (except native shell), `/settings/architecture` outside `oss-tenant`, and all non-auth routes in `saas-shared`
- **`getDefaultRedirectPath(isAuthenticated)`** — Returns the appropriate landing path for the current mode and auth state
- **`shouldShowNavigationSidebar()`** / **`shouldShowAppPages()`** — UI visibility helpers delegating to `isAppEnabled()`

## Usage Example

```typescript
import {
  getAppMode,
  isRouteAllowedInCurrentMode,
  getDefaultRedirectPath,
} from './app-mode';

// Check current mode
console.log(getAppMode()); // 'oss-tenant'

// Middleware route guard
if (!isRouteAllowedInCurrentMode(req.nextUrl.pathname)) {
  const redirect = getDefaultRedirectPath(false);
  return NextResponse.redirect(new URL(redirect, req.url));
}
```
