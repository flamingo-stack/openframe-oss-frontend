A read-only table component that displays knowledge base articles assigned to a resource, with client-side search filtering and debounced input.

## Key Components

- **`KnowledgeBaseAssignedTable`** — Main exported component that renders a searchable, filtered list of assigned knowledge base articles
- **`KnowledgeBaseAssignedTableProps`** — Interface accepting:
  - `articles: KnowledgeBaseRow[]` — Array of knowledge base article rows to display
  - `isLoading?: boolean` — Optional loading state for skeleton display
- **`debouncedSearch`** — 300ms debounced search term to avoid excessive filtering on keystroke
- **`filtered`** — Memoized array filtered by matching `name` or `summary` fields against the search needle

## Usage Example

```typescript
import { KnowledgeBaseAssignedTable } from './knowledge-base-assigned-table';

const articles: KnowledgeBaseRow[] = [
  { id: '1', name: 'VPN Setup Guide', summary: 'How to configure VPN access' },
  { id: '2', name: 'Password Reset', summary: 'Steps to reset your password' },
];

export function TicketKnowledgePanel() {
  return (
    <KnowledgeBaseAssignedTable
      articles={articles}
      isLoading={false}
    />
  );
}
```

## Notes

- Filtering is case-insensitive and matches against both `name` and `summary` fields; `summary` defaults to an empty string if absent
- Uses `KnowledgeBaseTableBody` in `"standard"` mode with a fixed skeleton of 3 rows and a custom empty message of `"No articles assigned."`
