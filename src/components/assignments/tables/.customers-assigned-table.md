Filterable table component that displays a list of pre-assigned customers with client-side debounced search filtering by name or email.

## Key Components

### `CustomersAssignedTable`
Main exported component that renders a searchable table of assigned customers.

**Props (`CustomersAssignedTableProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `customers` | `Customer[]` | Array of pre-fetched customer records to display |
| `isLoading` | `boolean` (optional) | Shows skeleton rows while data loads |

**Internal behavior:**
- `search` / `setSearch` — controlled input state
- `useDebounce(search, 300)` — debounces the search term by 300ms to avoid excessive filtering on each keystroke
- `filtered` (memoized) — filters `customers` by `name` or `contact.email` using the debounced value

## Usage Example

```typescript
import { CustomersAssignedTable } from './customers-assigned-table';
import { useCustomers } from '@/app/(app)/customers/hooks/use-customers';

export function AssignedCustomersPanel() {
  const { customers, isLoading } = useCustomers();

  return (
    <CustomersAssignedTable
      customers={customers}
      isLoading={isLoading}
    />
  );
}
```

## Notes

- Filtering is **client-side only** — all filtering operates on the `customers` prop; no API calls are triggered on search
- Empty state renders `"No customers assigned."` when the filtered result is empty
- Skeleton rows default to `3` during loading
- Reuses shared `CustomersSearchInput` and `CustomersTableBody` from [`customers-table-columns`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/customers/components/customers-table-columns.tsx)
