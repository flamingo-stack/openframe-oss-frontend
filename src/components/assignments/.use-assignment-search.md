Provides a React hook for searching and filtering assignment targets (organizations, devices, tickets, and knowledge articles) by target type, returning debounced, paginated options via React Query.

## Key Components

- **`AssignmentSearchOption`** — exported interface representing a search result with `label` and `value` string fields
- **`useAssignmentSearch(targetType, search)`** — primary exported hook; routes to the appropriate internal strategy based on `AssignmentTargetType`
- **`useServerSearchOptions`** — internal hook handling server-side search for `ORGANIZATION`, `DEVICE`, and `TICKET` types with 300ms debounce and 30s stale time
- **`useKnowledgeArticleOptions`** — internal hook fetching the full knowledge article tree once and filtering client-side with debounced search
- **`SERVER_SEARCH_FETCHERS`** — dispatch map linking `AssignmentTargetType` values to their respective GraphQL/REST fetchers
- **Fetchers** — `fetchCustomers`, `fetchDevices`, `fetchTickets`, `fetchKnowledgeArticles` — isolated async functions for each entity type, all returning `AssignmentSearchOption[]`

## Usage Example

```typescript
import { useAssignmentSearch } from './use-assignment-search';

function AssignmentCombobox({ targetType }: { targetType: AssignmentTargetType }) {
  const [search, setSearch] = useState('');
  const { options, isLoading } = useAssignmentSearch(targetType, search);

  return (
    <Combobox
      options={options}
      loading={isLoading}
      onSearchChange={setSearch}
    />
  );
}
```

## Behavior Notes

- `KNOWLEDGE_ARTICLE` results are fetched once and filtered **client-side**; all other types trigger **server-side** queries per search term
- Results are capped at `PAGE_SIZE = 20` for server queries
- Query keys follow the pattern `['assignments', 'search', targetType, debouncedSearch]` for targeted cache invalidation
- Devices fall back through `displayName → hostname → id` for their label
