Barrel export file for the assignments feature module, consolidating and re-exporting all public APIs related to assignment management.

## Key Components

| Export | Source |
|---|---|
| `useApplyAssignmentsDiff` | `./apply-assignments-diff` — Hook for applying diffs to assignment state |
| `AssignedItemsView` | `./assigned-items-view` — Component for rendering assigned items |
| `AssignmentsField` | `./assignments-field` — Form field component for managing assignments |
| `ASSIGNMENTS_DEFAULT` | `./schema` — Default value constant for assignments |
| `assignmentsSchema` | `./schema` — Validation schema for assignments data |
| `useAssignedItems` | `./use-assigned-items` — Hook for accessing assigned items state |

## Usage Example

```typescript
import {
  AssignmentsField,
  AssignedItemsView,
  assignmentsSchema,
  ASSIGNMENTS_DEFAULT,
  useAssignedItems,
  useApplyAssignmentsDiff,
} from '@/features/assignments';

// Use in a form
<AssignmentsField value={assignments} onChange={setAssignments} />

// Display read-only assigned items
<AssignedItemsView items={assignedItems} />

// Access assigned items in a component
const items = useAssignedItems();

// Apply a diff to update assignments
const applyDiff = useApplyAssignmentsDiff();
applyDiff({ added: [newItem], removed: [oldItem] });
```
