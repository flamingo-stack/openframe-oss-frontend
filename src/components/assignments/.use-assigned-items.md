Fetches and combines assigned items (customers, devices, knowledge articles, tickets) for a given assignment item across all target types using parallel GraphQL queries.

## Key Components

### `useAssignedItems(options)` *(exported hook)*
Primary hook that fires one query per `AssignmentTargetType` in parallel via `useQueries`, then merges results into a single `AssignedItemsResult`. Accepts:
- `itemId` — the source item's ID (normalized to a Relay global ID internally)
- `itemType` — the `AssignmentItemType` of the source item
- `enabled` — optional flag to suppress fetching (default `true`)

### `AssignedItemsResult` *(exported interface)*
Merged output shape:
- `value` — `AssignmentsValue` map of target type → `AssignmentRef[]`
- `customers`, `devices`, `articles`, `tickets` — hydrated domain objects per type
- `isLoading` / `isReady` — aggregate loading state across all parallel queries

### `fetchAssignedItems(itemId, targetType)` *(internal)*
Posts the `AssignmentsAssignedItems` GraphQL query with a page size of 100. Parses edges, unaliases conflicting GraphQL field names (e.g. `machineStatus` → `status`), and maps each node to its domain type via existing transformers (`mapOrganizationNode`, `createDeviceListItem`, etc.).

### `combineAssignedItems(results)` *(internal)*
`useQueries` combiner that merges all parallel query results into one `AssignedItemsResult`, accumulating refs by target type and flattening hydrated entities.

## Usage Example

```typescript
const { value, customers, devices, isLoading, isReady } = useAssignedItems({
  itemId: 'some-item-id',
  itemType: 'TICKET',
  enabled: isModalOpen,
});

if (!isReady) return <Spinner />;

// value: { ORGANIZATION: [...refs], DEVICE: [...refs] }
// customers: Customer[]
// devices: Device[]
```

> **Note:** `itemId` is automatically normalized to a Relay global ID via `ensureGlobalId`. A TODO exists to remove this once the backend's `Ticket` type is fully Relay-compliant — see [`relay-id.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/(app)/tickets/types/dialog.types.ts).
