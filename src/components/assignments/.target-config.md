Defines the display metadata configuration for all supported assignment target types, mapping each type to its labels and icon component.

## Key Components

### `TargetMeta` (interface)
Describes the display metadata for a single target type:
- `rowLabel` — label used in assignment row context (e.g., "Assigned Devices")
- `menuLabel` — singular label used in dropdown menus (e.g., "Device")
- `tabLabel` — plural label used in tab navigation (e.g., "Devices")
- `icon` — React SVG icon component rendered alongside the target

### `TARGET_CONFIG` (constant)
A lookup map keyed by `AssignmentTargetType` with entries for:

| Key | Row Label | Tab Label | Icon |
|---|---|---|---|
| `ORGANIZATION` | Assigned Customers | Customers | `IdCardIcon` |
| `DEVICE` | Assigned Devices | Devices | `MonitorIcon` |
| `TICKET` | Assigned Tickets | Tickets | `TagIcon` |
| `KNOWLEDGE_ARTICLE` | Assigned Knowledge Articles | Knowledge Articles | `FileContentIcon` |

## Usage Example

```typescript
import { TARGET_CONFIG } from './target-config';

function TargetTab({ type }: { type: AssignmentTargetType }) {
  const { tabLabel, icon: Icon } = TARGET_CONFIG[type];

  return (
    <Tab>
      <Icon size={16} />
      {tabLabel}
    </Tab>
  );
}
```

## Notes

- All icons are sourced from `@flamingo-stack/openframe-frontend-core/components/icons-v2`
- `IconProps` extends `SVGProps<SVGSVGElement>` with `size` and `color` convenience props, excluding raw `width`/`height`
- Adding a new `AssignmentTargetType` requires a corresponding entry in `TARGET_CONFIG` to maintain exhaustive typing
