Defines Zod validation schemas for assignment references used across organizational entities (devices, tickets, knowledge articles).

## Key Components

- **`assignmentRefSchema`** — Internal schema validating a single assignment reference with `id` (string) and `label` (string) fields.
- **`assignmentsSchema`** — Exported schema validating an optional object containing arrays of assignment references keyed by entity type: `ORGANIZATION`, `DEVICE`, `TICKET`, and `KNOWLEDGE_ARTICLE`. Satisfies the `AssignmentsValue` type contract.
- **`ASSIGNMENTS_DEFAULT`** — Exported default value representing an empty assignments object.

## Usage Example

```typescript
import { assignmentsSchema, ASSIGNMENTS_DEFAULT } from './schema';

// Validate incoming assignments data
const result = assignmentsSchema.safeParse({
  DEVICE: [{ id: 'dev-123', label: 'Workstation A' }],
  TICKET: [{ id: 'tkt-456', label: 'Password Reset' }],
});

if (result.success) {
  console.log(result.data); // Typed as AssignmentsValue | undefined
}

// Use default value for initialization
const assignments = ASSIGNMENTS_DEFAULT; // {}
```
