A single-row UI component for managing assignment targets, combining a multi-select autocomplete with a remove button for a specific `AssignmentTargetType`.

## Key Components

- **`AssignmentRow`** — Default export React component that renders a labeled field row containing:
  - A multi-select `Autocomplete` for searching and selecting assignment targets
  - A trash `Button` to remove the entire assignment row
- **`mergedOptions`** — Memoized option list that deduplicates currently selected `AssignmentRef` values with live search results, ensuring selected items always appear even when not in the current search response
- **`handleChange`** — Converts selected IDs back to `AssignmentRef` objects (`{ id, label }`) using the merged options map
- **`useAssignmentSearch`** — External hook providing paginated/async search options and loading state for the given `targetType`

## Props

| Prop | Type | Description |
|---|---|---|
| `targetType` | `AssignmentTargetType` | Determines label and search behavior via `TARGET_CONFIG` |
| `value` | `AssignmentRef[]` | Currently selected assignments |
| `onChange` | `(next: AssignmentRef[]) => void` | Called with updated assignment list |
| `onRemoveRow` | `() => void` | Callback to delete this row entirely |
| `disabled` | `boolean?` | Disables all controls |

## Usage Example

```typescript
<AssignmentRow
  targetType="user"
  value={[{ id: 'u1', label: 'Alice' }]}
  onChange={(refs) => setAssignments(refs)}
  onRemoveRow={() => removeRow('user')}
  disabled={isSubmitting}
/>
```
