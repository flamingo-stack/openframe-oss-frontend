Defines a Relay GraphQL mutation for marking a specific user onboarding step as complete, returning the updated onboarding progress state.

## Key Components

- **`completeUserOnboardingStepMutation`** — A `graphql` tagged template literal defining the `completeUserOnboardingStepMutation` GraphQL operation. Accepts a `$step` variable of type `UserOnboardingStep` and returns the full onboarding status after the mutation resolves.

**Returned fields:**

| Field | Description |
|---|---|
| `completedSteps` | List of steps that have been completed |
| `completed` | Whether the entire onboarding flow is done |
| `completedAt` | Timestamp when onboarding was fully completed |
| `skipped` | Whether onboarding was skipped |
| `skippedAt` | Timestamp when onboarding was skipped |

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { completeUserOnboardingStepMutation } from './complete-user-onboarding-step-mutation';
import type { completeUserOnboardingStepMutation as MutationType } from './__generated__/completeUserOnboardingStepMutation.graphql';

const [commit, isInFlight] = useMutation<MutationType>(completeUserOnboardingStepMutation);

commit({
  variables: { step: 'PROFILE_SETUP' },
  onCompleted(data) {
    const { completed, completedSteps } = data.completeUserOnboardingStep;
    if (completed) {
      // All onboarding steps done
    }
  },
});
```
