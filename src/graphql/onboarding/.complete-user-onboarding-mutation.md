Relay GraphQL mutation for completing the user onboarding flow, returning the final onboarding status after marking it as complete.

## Key Components

- **`completeUserOnboardingMutation`** — Exported Relay `graphql` tagged template literal defining the `completeUserOnboarding` mutation. Returns the following onboarding state fields:
  - `completedSteps` — List of steps the user has finished
  - `completed` — Boolean indicating full onboarding completion
  - `completedAt` — Timestamp of completion
  - `skipped` — Boolean indicating if onboarding was skipped
  - `skippedAt` — Timestamp of when onboarding was skipped

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { completeUserOnboardingMutation } from './complete-user-onboarding-mutation';
import type { completeUserOnboardingMutation as MutationType } from './__generated__/completeUserOnboardingMutation.graphql';

function OnboardingFinishButton() {
  const [commit, isInFlight] = useMutation<MutationType>(completeUserOnboardingMutation);

  const handleComplete = () => {
    commit({
      variables: {},
      onCompleted(data) {
        const { completed, completedAt } = data.completeUserOnboarding;
        console.log('Onboarding complete:', completed, completedAt);
      },
    });
  };

  return <button onClick={handleComplete} disabled={isInFlight}>Finish Setup</button>;
}
```

## Notes

- No input variables are required — the mutation resolves the current user from the authenticated session.
- The generated Relay types will be located in `__generated__/completeUserOnboardingMutation.graphql.ts` after running the Relay compiler.
