Defines a Relay GraphQL mutation that allows users to skip the onboarding flow, returning the resulting onboarding completion state.

## Key Components

- **`skipUserOnboardingMutation`** — A `graphql` tagged template literal defining the `skipUserOnboarding` mutation. Returns the updated onboarding record with skip/completion metadata.

### Mutation Response Fields

| Field | Description |
|---|---|
| `completedSteps` | Steps marked as completed before skipping |
| `completed` | Whether onboarding is fully completed |
| `completedAt` | Timestamp of completion |
| `skipped` | Whether the user skipped onboarding |
| `skippedAt` | Timestamp when onboarding was skipped |

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { skipUserOnboardingMutation } from './skip-user-onboarding-mutation';
import type { skipUserOnboardingMutation as SkipMutationType } from './__generated__/skipUserOnboardingMutation.graphql';

function OnboardingBanner() {
  const [commitMutation, isInFlight] = useMutation<SkipMutationType>(
    skipUserOnboardingMutation
  );

  const handleSkip = () => {
    commitMutation({
      variables: {},
      onCompleted(response) {
        const { skipped, skippedAt } = response.skipUserOnboarding;
        console.log(`Onboarding skipped at ${skippedAt}`);
      },
    });
  };

  return <button onClick={handleSkip} disabled={isInFlight}>Skip Setup</button>;
}
```

## Notes

- No input variables are required; the mutation resolves the current user from the session context.
- The Relay compiler will generate types at `__generated__/skipUserOnboardingMutation.graphql.ts`.
