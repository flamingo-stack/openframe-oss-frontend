Defines a Relay GraphQL mutation for marking tenant onboarding as complete and returning the updated onboarding status.

## Key Components

- **`completeTenantOnboardingMutation`** — A `graphql` tagged template literal that issues the `completeTenantOnboarding` mutation, returning:
  - `completedSteps` — List of onboarding steps that have been completed
  - `completed` — Boolean indicating whether onboarding is fully done
  - `completedAt` — Timestamp when onboarding was completed

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { completeTenantOnboardingMutation } from './complete-tenant-onboarding-mutation';

function OnboardingFinishButton() {
  const [commit, isInFlight] = useMutation(completeTenantOnboardingMutation);

  const handleComplete = () => {
    commit({
      variables: {},
      onCompleted(response) {
        const { completed, completedAt } = response.completeTenantOnboarding;
        console.log('Onboarding complete:', completed, completedAt);
      },
      onError(error) {
        console.error('Failed to complete onboarding:', error);
      },
    });
  };

  return (
    <button onClick={handleComplete} disabled={isInFlight}>
      Finish Setup
    </button>
  );
}
```

## Notes

- This mutation takes no input variables — it operates on the currently authenticated tenant context.
- The returned `completedSteps` field can be used to update local UI state or Relay's store without a separate query refetch.
