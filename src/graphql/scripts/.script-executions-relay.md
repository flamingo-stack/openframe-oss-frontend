Defines the Relay GraphQL query and pagination fragment for fetching a script's execution history, including server-side filtering, search, and infinite-scroll pagination.

## Key Components

### `scriptExecutionsRelayQuery`
The root query that fetches both the paginated execution list (via fragment spread) and the `scriptExecutionFilters` facets in a single round-trip. Accepts:
- `$scriptId` — target script identifier
- `$filter: ScriptExecutionFilterInput` — structured filter (statuses, initiators, machines)
- `$search` — free-text search string
- `$first` / `$after` — cursor-based pagination arguments

### `scriptExecutionsRelayFragment`
A `@refetchable` Relay fragment on `Query` that drives the `scriptExecutions` cursor connection. Uses `@connection` for Relay store normalization and exposes:
- `filteredCount` — total matching rows
- **Edge nodes** — `id`, `executionId`, `status`, `dispatchedAt`, `stdout`, `stderr`, `error`, plus nested `machine` (with org) and `initiator` (with avatar) objects
- `pageInfo` — `hasNextPage` / `endCursor` for infinite scroll via `loadNext`

## Usage Example

```typescript
import { useQueryLoader, usePreloadedQuery, usePaginationFragment } from 'react-relay';
import { scriptExecutionsRelayQuery, scriptExecutionsRelayFragment } from './script-executions-relay';

// Load the query
const [queryRef, loadQuery] = useQueryLoader(scriptExecutionsRelayQuery);
loadQuery({ scriptId: 'U2NyaXB0OjE=', first: 20 });

// In the component
const data = usePreloadedQuery(scriptExecutionsRelayQuery, queryRef);
const { data: fragmentData, loadNext, hasNext } = usePaginationFragment(
  scriptExecutionsRelayFragment,
  data
);

// Access filter facets (not refetched on paginate)
const { statuses, initiators, machines } = data.scriptExecutionFilters;
```

## Notes

- Filter facets (`scriptExecutionFilters`) sit on the **root query**, not the refetchable fragment, so `loadNext` pagination calls never re-request facet options — reducing unnecessary network traffic.
- Facet exclusion semantics are server-enforced: each filter group's options remain visible while the user multi-selects within that group.
