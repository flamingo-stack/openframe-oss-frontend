Defines the Relay GraphQL query and pagination fragment for the scripts table, supporting server-side filtering, search, and cursor-based infinite scroll.

## Key Components

### `scriptsTableRelayQuery`
Root query that fetches:
- **Script rows** — via the `scriptsTableRelay_query` fragment spread (with `filter`, `search`, `first`, `after` arguments)
- **Filter facets** (`scriptFilters`) — shells, platforms, and authors with `value`/`label`/`count` fields, co-located on the root query so facets refresh atomically with row results but are **not** refetched during `loadNext` pagination

### `scriptsTableRelayFragment`
A `@refetchable` fragment on `Query` that drives the `@connection`-powered infinite scroll:
- **Key:** `scriptsTableRelay_scripts` (used by `usePaginationFragment`)
- **Auto-generated pagination query:** `scriptsTableRelayPaginationQuery`
- **Edge node fields:** `id`, `name`, `description`, `shell`, `supportedPlatforms`, `defaultTimeoutSeconds`, and a full `author` object (with avatar `imageUrl`/`hash`)
- **`filteredCount`** — total matching rows for display in the table header or result summary

## Usage Example

```typescript
import { useQueryLoader, usePaginationFragment } from 'react-relay';
import {
  scriptsTableRelayQuery,
  scriptsTableRelayFragment,
} from './scripts-table-relay';

// Load the root query
const [queryRef, loadQuery] = useQueryLoader(scriptsTableRelayQuery);

loadQuery({ first: 20, filter: { shells: ['POWERSHELL'] } });

// Inside the table component, consume the pagination fragment
const { data, loadNext, hasNext } = usePaginationFragment(
  scriptsTableRelayFragment,
  queryRef, // fragment ref from usePreloadedQuery spread
);

const scripts = data.scripts.edges.map(({ node }) => node);
```

## Filter Facet Design

Facet exclusion is handled server-side: when filtering by `shells`, the `shells` facet group returns all available options (not just the selected one), preventing options from disappearing during multi-select. `authors.value` maps to user IDs; `shells`/`platforms` values map to their respective enums in `ScriptFilterInput`.
