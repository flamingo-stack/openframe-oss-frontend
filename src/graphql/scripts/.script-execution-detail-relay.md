Defines the Relay GraphQL query for fetching a single script execution's full details via the generic `node(id)` entry point, narrowing to the `ScriptExecution` type.

## Key Components

- **`scriptExecutionDetailRelayQuery`** — Exported Relay `graphql` query that resolves a `ScriptExecution` node by ID, returning execution metadata, output streams, machine context, and initiator profile.

## Query Fields

| Group | Fields |
|---|---|
| Execution metadata | `executionId`, `scriptId`, `scriptName`, `status`, `privilegeLevel`, `dispatchedAt`, `statusChangedAt`, `finishedAt`, `executionTimeMs`, `exitCode`, `timedOut` |
| Output | `stdout`, `stderr`, `error` |
| Machine | `machineId`, `hostname`, `displayName`, organization `name` |
| Initiator | `firstName`, `lastName`, `email`, avatar `imageUrl`/`hash` |

## Usage Example

```typescript
import { loadQuery, usePreloadedQuery } from 'react-relay';
import { scriptExecutionDetailRelayQuery } from './script-execution-detail-relay';

// Preload in route loader
const queryRef = loadQuery(relayEnvironment, scriptExecutionDetailRelayQuery, {
  id: executionNodeId,
});

// Consume in component
const data = usePreloadedQuery(scriptExecutionDetailRelayQuery, queryRef);
const execution = data.node; // narrowed to ScriptExecution inline fragment
```

> **Why `node(id)`?** The schema exposes no direct `scriptExecution(id)` root field, so the query uses Relay's generic `node` entry point with an inline fragment (`... on ScriptExecution`) to type-narrow the result.
