Defines the primary Relay GraphQL query for fetching script schedule details, excluding assigned devices to avoid timeout issues on large fleets.

## Key Components

- **`scriptScheduleDetailRelayQuery`** — Exported `graphql` tagged template literal query that resolves a single `scriptSchedule` by `id`, including its metadata and the ordered list of scripts it executes.

### Query Fields

| Field | Description |
|---|---|
| `id`, `name`, `description` | Schedule identity and metadata |
| `supportedPlatforms`, `status` | Platform targeting and schedule state |
| `deviceCount` | Count of assigned machines (lightweight, no per-device resolution) |
| `scripts[]` | Ordered list of scripts with shell, platform, timeout, args, and env vars |

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { scriptScheduleDetailRelayQuery } from './script-schedule-detail-relay';
import type { scriptScheduleDetailRelayQuery as QueryType } from './__generated__/scriptScheduleDetailRelayQuery.graphql';

function ScriptScheduleDetail({ scheduleId }: { scheduleId: string }) {
  const data = useLazyLoadQuery<QueryType>(
    scriptScheduleDetailRelayQuery,
    { id: scheduleId }
  );

  return <div>{data.scriptSchedule?.name}</div>;
}
```

## Design Notes

Assigned devices are intentionally excluded from this query — per-machine resolution is expensive and can 504 on real fleets. Use [`script-schedule-devices-relay.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/script-schedule-devices-relay.ts) alongside this query only in views that need to render the device list.
