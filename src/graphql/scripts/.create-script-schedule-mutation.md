Defines the Relay GraphQL mutation for creating a new script schedule, pre-selecting all fields required by the schedule detail page to enable instant cache-warm rendering on navigation.

## Key Components

- **`createScriptScheduleMutation`** — Exported Relay `graphql` tagged template literal that wraps the `createScriptSchedule` mutation, accepting a `CreateScriptScheduleInput!` argument and returning the full schedule shape including nested `scripts` with their `envVars`.

## Selected Return Fields

| Field | Description |
|---|---|
| `id`, `name`, `description` | Core schedule identity fields |
| `supportedPlatforms`, `status` | Platform targeting and schedule state |
| `deviceCount` | Number of devices associated with the schedule |
| `scripts[*]` | Nested script list with shell, timeout, args, and env vars |

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { createScriptScheduleMutation } from './create-script-schedule-mutation';

const [commitMutation, isInFlight] = useMutation(createScriptScheduleMutation);

commitMutation({
  variables: {
    input: {
      name: 'Nightly Patch Run',
      description: 'Applies OS patches across managed devices',
      supportedPlatforms: ['WINDOWS', 'MACOS'],
      scriptIds: ['script-abc123'],
    },
  },
  onCompleted(response) {
    // Relay store is now warm; navigating to the detail page
    // renders instantly via store-and-network policy.
    router.push(`/schedules/${response.createScriptSchedule.id}`);
  },
});
```

## Notes

- The mutation intentionally mirrors the field selections of the schedule detail page query, ensuring the Relay store is populated before the router replaces the URL — eliminating a loading state on first render.
