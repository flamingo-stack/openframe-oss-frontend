Defines the Relay GraphQL mutation for replacing the complete set of devices assigned to a script schedule, using PUT semantics to back the "Edit Devices" workflow.

## Key Components

### `setScriptScheduleDevicesMutation`

A Relay `graphql` tagged template that calls the `setScriptScheduleDevices` mutation.

**Variables:**

| Variable | Type | Description |
|---|---|---|
| `scheduleId` | `ID!` | Global ID of the target schedule |
| `machineIds` | `[ID!]!` | Array of Machine **global** IDs (`Machine.id`, not `machineId` string) |

**Returned fields:**

| Field | Description |
|---|---|
| `id` | Schedule ID |
| `deviceCount` | Updated device count for list-view re-render |
| `assignedDevices` | Full replacement device set for the detail page's Assigned Devices tab |

Each `assignedDevices` entry includes `id`, `machineId`, `hostname`, `displayName`, `osType`, and `status`.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { setScriptScheduleDevicesMutation } from './set-script-schedule-devices-mutation';

const [commitMutation, isInFlight] = useMutation(setScriptScheduleDevicesMutation);

commitMutation({
  variables: {
    scheduleId: 'U2NoZWR1bGU6MTIz',
    machineIds: ['TWFjaGluZToxMDA=', 'TWFjaGluZToyMDA='],
  },
  onCompleted(response) {
    console.log('Updated device count:', response.setScriptScheduleDevices.deviceCount);
  },
});
```

> **Note:** `machineIds` must be Machine **global** IDs (base64-encoded `Machine.id`), not the human-readable `machineId` string field. Passing the wrong ID type will silently assign no devices.
