Defines a Relay GraphQL query for fetching tags assigned to scripts, used to populate list filter options based on the active/archived scope of scripts.

## Key Components

- **`scriptTagsRelayFilterQuery`** — A Relay-compiled `graphql` query that calls `scriptsTags(archived: $archived)`, returning `id` and `key` for each tag. The `$archived` boolean variable scopes results: `null`/`false` returns tags on active scripts; `true` returns tags on archived scripts.

## Usage Example

```typescript
import { scriptTagsRelayFilterQuery } from './script-tags-relay';
import { useLazyLoadQuery } from 'react-relay';
import type { scriptTagsRelayFilterQuery as ScriptTagsRelayFilterQueryType } from './__generated__/scriptTagsRelayFilterQuery.graphql';

function ScriptListFilter({ showArchived }: { showArchived: boolean }) {
  const data = useLazyLoadQuery<ScriptTagsRelayFilterQueryType>(
    scriptTagsRelayFilterQuery,
    { archived: showArchived }
  );

  return (
    <TagFilter tags={data.scriptsTags} />
  );
}
```

## Notes

- This query is intentionally scoped to **tags in use** on scripts, not the full tenant tag vocabulary.
- For the script editor's tag picker (full vocabulary), use the shared `entityTagPickerQuery` with `tagsByEntityType(entityType: SCRIPT)` instead.
