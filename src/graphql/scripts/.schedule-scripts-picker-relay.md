Defines the Relay GraphQL query for the script autocomplete picker used in the schedule create/edit form, fetching active scripts filtered by platform and name search.

## Key Components

- **`scheduleScriptsPickerRelayQuery`** — A `graphql` tagged query that fetches paginated active scripts, accepting `$search` (name filter), `$platforms` (platform constraint), and `$first` (page size) variables. Returns each script's `id`, `name`, `supportedPlatforms`, and `defaultTimeoutSeconds`.

## Usage Example

```typescript
import { fetchQuery } from 'react-relay';
import { scheduleScriptsPickerRelayQuery } from './schedule-scripts-picker-relay';

// Called imperatively per keystroke in use-schedule-scripts-autocomplete
fetchQuery(relayEnvironment, scheduleScriptsPickerRelayQuery, {
  search: 'deploy',
  platforms: ['WINDOWS'],
  first: 20,
}).subscribe({
  next: (data) => {
    const scripts = data.scripts.edges.map(({ node }) => node);
    // Populate dropdown options
  },
});
```

## Notes

- Uses `fetchQuery` (imperative fetch) rather than a suspending hook because the dropdown re-queries on every keystroke; results are still normalized into the Relay store for caching.
- The `statuses: [ACTIVE]` filter is hardcoded — only active scripts are ever surfaced in the picker.
- Platform filtering (`$platforms`) ensures users cannot schedule a script on an incompatible device type.
