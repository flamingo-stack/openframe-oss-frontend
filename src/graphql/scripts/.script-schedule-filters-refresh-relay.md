Relay GraphQL query fragment for imperatively refreshing script schedule filter facets after mutations that alter list membership (e.g., archive/unarchive).

## Key Components

- **`scriptScheduleFiltersRefreshRelayQuery`** — Named Relay `graphql` query that fetches the `scriptScheduleFilters` facet data, scoped by an optional `ScriptScheduleFilterInput`. Returns `platforms` facets with `value`, `label`, and `count` fields.

## Usage Example

```typescript
import { fetchQuery } from 'react-relay';
import { scriptScheduleFiltersRefreshRelayQuery } from './script-schedule-filters-refresh-relay';

// Imperatively refresh filter facets after a mutation (e.g., archive)
fetchQuery(relayEnvironment, scriptScheduleFiltersRefreshRelayQuery, {
  filter: { /* ScriptScheduleFilterInput */ },
}).subscribe({});
```

## Notes

- Designed to be used with `fetchQuery(...).subscribe({})` so Relay writes results directly into the store, updating any mounted query's facet records in place without a full re-fetch.
- Mirrors the pattern established in [`script-filters-refresh-relay.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/script-filters-refresh-relay.ts) for consistency across filter-refresh operations.
