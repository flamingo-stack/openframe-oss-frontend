Defines the Relay GraphQL mutation for archiving a script schedule, removing its edge from the active connection list without deleting the underlying `ScriptSchedule` record.

## Key Components

- **`archiveScriptScheduleMutation`** — A compiled Relay `graphql` mutation tag that calls `archiveScriptSchedule(id:)` and uses the `@deleteEdge(connections:)` directive to immediately remove the schedule's edge from the UI list while preserving the record in the backend.

## Usage Example

```typescript
import { archiveScriptScheduleMutation } from './archive-script-schedule-mutation';
import { useMutation } from 'react-relay';

function useArchiveScriptSchedule(connectionId: string) {
  const [commitMutation, isInFlight] = useMutation(archiveScriptScheduleMutation);

  const archive = (scheduleId: string) => {
    commitMutation({
      variables: {
        id: scheduleId,
        connections: [connectionId],
      },
    });
  };

  return { archive, isInFlight };
}
```

## Notes

- **`@deleteEdge` vs `@deleteRecord`** — The mutation removes the edge from the Relay store connection (the row disappears from the list instantly) without invalidating or deleting the `ScriptSchedule` node itself. The record remains fetchable by ID and will not re-appear in the list on subsequent fetches. See [`archive-script-mutation.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/archive-script-mutation.ts) for the rationale behind this choice.
- The `connections` variable must be passed at call time (typically obtained via `__id` from a Relay `useFragment` or `usePaginationFragment` connection field).
