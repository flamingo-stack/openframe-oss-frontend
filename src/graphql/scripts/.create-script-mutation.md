Defines a Relay GraphQL mutation for creating a new script resource, returning the created script's `id` and `name`.

## Key Components

- **`createScriptMutation`** — A tagged GraphQL mutation that accepts a `CreateScriptInput` object and returns the newly created script's `id` and `name` fields.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { createScriptMutation } from './create-script-mutation';

const [commitMutation, isInFlight] = useMutation(createScriptMutation);

commitMutation({
  variables: {
    input: {
      name: 'My Script',
      // ...other CreateScriptInput fields
    },
  },
  onCompleted(response) {
    console.log('Created script:', response.createScript.id);
  },
  onError(error) {
    console.error('Mutation failed:', error);
  },
});
```

## Notes

- Defined using `react-relay`'s `graphql` tag, which enables Relay's compile-time query analysis and type generation.
- The mutation expects a `CreateScriptInput` input type — ensure the input shape matches the backend schema.
