Defines the Relay GraphQL mutation for dispatching a saved script to multiple machines simultaneously over NATS under a single shared `executionId`.

## Key Components

- **`batchRunScriptMutation`** — Relay `graphql` tagged template literal that wraps the `batchRunScript` GraphQL mutation. Accepts a `BatchRunScriptInput!` and returns only the `executionId` shared across all targeted machines.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { batchRunScriptMutation } from './batch-run-script-mutation';
import type { batchRunScriptMutation as BatchRunScriptMutationType } from './__generated__/batchRunScriptMutation.graphql';

const [commitMutation, isInFlight] = useMutation<BatchRunScriptMutationType>(batchRunScriptMutation);

commitMutation({
  variables: {
    input: {
      scriptId: 'script-abc123',
      machineIds: ['machine-1', 'machine-2', 'machine-3'],
      // shell, envVars, and script body are resolved server-side
    },
  },
  onCompleted(response) {
    console.log('Batch execution started:', response.batchRunScript.executionId);
  },
});
```

## Notes

- **No persistence** — script body, shell, and environment variables are resolved entirely server-side; nothing is stored client-side.
- **Contrast with `runScript`** — `runScript` targets a single machine; `batchRunScript` fans out to many machines under one shared `executionId`, making it easier to correlate results across the fleet.
- The returned `executionId` can be used downstream to track or stream output from all dispatched executions.
