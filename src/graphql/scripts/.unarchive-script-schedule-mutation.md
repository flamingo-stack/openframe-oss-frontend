Defines the Relay GraphQL mutation for restoring an archived script schedule back to `ACTIVE` status, removing it from the archived list's connection without deleting the underlying record.

## Key Components

- **`unarchiveScriptScheduleMutation`** — Relay `graphql` tagged template literal that executes the `unarchiveScriptSchedule` mutation, accepting a schedule `id` and a `connections` array for declarative edge removal via `@deleteEdge`.

## Usage Example

```typescript
import { unarchiveScriptScheduleMutation } from './unarchive-script-schedule-mutation';
import { useMutation } from 'react-relay';

const [commit, isInFlight] = useMutation(unarchiveScriptScheduleMutation);

commit({
  variables: {
    id: scheduleId,
    connections: [archivedConnectionId],
  },
});
```

## Notes

- Uses `@deleteEdge(connections:)` to remove the schedule's edge from the archived list connection on the client store — the record itself is **not** deleted.
- The active Schedules page re-surfaces the restored schedule via a `store-and-network` refetch on navigation.
- For the rationale behind using `@deleteEdge` instead of `@deleteRecord`, see [`archive-script-mutation.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/archive-script-mutation.ts).
