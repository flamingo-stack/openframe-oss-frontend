Defines a Relay GraphQL query for fetching complete script details from the OpenFrame API, used by detail, edit, and run views.

## Key Components

- **`scriptDetailRelayQuery`** — Named Relay `graphql` tagged template query that fetches a single script by `id`, resolving all fields required across script-related views.

### Queried Fields

| Field | Description |
|---|---|
| `id`, `name`, `description` | Core script identity |
| `shell`, `privilegeLevel`, `scriptBody` | Execution configuration |
| `tags` | Associated tag objects (`id`, `key`) |
| `supportedPlatforms` | Target OS/platform list |
| `defaultTimeoutSeconds`, `defaultArgs` | Runtime defaults |
| `envVars` | Environment variables with `name`, `value`, `secret` flag |
| `status` | Current script lifecycle state |
| `author` | Creator info (`id`, `firstName`, `lastName`, `email`) |

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { scriptDetailRelayQuery } from './script-detail-relay';
import type { scriptDetailRelayQuery as ScriptDetailQuery } from './__generated__/scriptDetailRelayQuery.graphql';

function ScriptDetail({ scriptId }: { scriptId: string }) {
  const data = useLazyLoadQuery<ScriptDetailQuery>(
    scriptDetailRelayQuery,
    { id: scriptId }
  );

  return <div>{data.script?.name}</div>;
}
```

## Notes

- Relay requires the query be named to match the file's generated type (`scriptDetailRelayQuery`).
- The `secret` boolean on `envVars` signals masked display in the UI.
