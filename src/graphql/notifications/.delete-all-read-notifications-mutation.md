Defines a Relay GraphQL mutation for deleting all read notifications in bulk.

## Key Components

- **`deleteAllReadNotificationsMutation`** — A compiled Relay `graphql` mutation that invokes the `deleteAllReadNotifications` root mutation field, taking no variables and returning no payload beyond the operation result.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { deleteAllReadNotificationsMutation } from './delete-all-read-notifications-mutation';

function ClearNotificationsButton() {
  const [commit, isInFlight] = useMutation(deleteAllReadNotificationsMutation);

  const handleClear = () => {
    commit({
      variables: {},
      onCompleted: () => console.log('All read notifications deleted'),
      onError: (err) => console.error(err),
    });
  };

  return (
    <button onClick={handleClear} disabled={isInFlight}>
      Clear All Read
    </button>
  );
}
```

## Notes

- No input variables are required — the mutation targets all read notifications for the authenticated user implicitly.
- Pair with a Relay store updater or a `refetchQueries` call to reflect the cleared state in the notification list UI.
