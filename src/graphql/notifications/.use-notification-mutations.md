A React hook that consolidates all notification GraphQL mutations — mark read, mark all read, delete, and delete all read — with optimistic Relay store updates, unread count refresh, and toast error feedback.

## Key Components

### `useNotificationMutations(options)`

The primary export. Accepts a `UseNotificationMutationsOptions` object and returns six values:

| Return | Type | Description |
|---|---|---|
| `markRead` | `(id: string) => void` | Marks a single notification as read |
| `markAllRead` | `() => void` | Marks all notifications as read |
| `removeNotification` | `(id: string) => void` | Deletes a single notification |
| `removeAllRead` | `() => void` | Deletes all read notifications |
| `isMarkingAllRead` | `boolean` | In-flight state for mark-all-read |
| `isDeletingAllRead` | `boolean` | In-flight state for delete-all-read |

### `UseNotificationMutationsOptions`

| Option | Type | Description |
|---|---|---|
| `filterPairs` | `NotificationConnectionPair[]` | Active Relay connection pairs for store updates |
| `onError` | `(op: NotificationMutation, err: Error) => void` | Optional error callback |
| `onMarkAllReadCompleted` | `() => void` | Fires after mark-all-read succeeds |
| `onDeleteAllReadCompleted` | `() => void` | Fires after delete-all-read succeeds |

### `NotificationMutation` (type)

Union of `'markRead' | 'markAllRead' | 'delete' | 'deleteAllRead'` — identifies the operation in error callbacks.

## Usage Example

```typescript
import { useNotificationMutations } from './use-notification-mutations';

function NotificationPanel({ connectionPairs }) {
  const {
    markRead,
    markAllRead,
    removeNotification,
    removeAllRead,
    isMarkingAllRead,
    isDeletingAllRead,
  } = useNotificationMutations({
    filterPairs: connectionPairs,
    onError: (operation, err) => console.error(`[${operation}]`, err),
    onMarkAllReadCompleted: () => console.log('All marked read'),
  });

  return (
    <>
      <button onClick={markAllRead} disabled={isMarkingAllRead}>
        Mark All Read
      </button>
      <button onClick={removeAllRead} disabled={isDeletingAllRead}>
        Clear Read
      </button>
      <button onClick={() => markRead('notif-123')}>Mark Read</button>
      <button onClick={() => removeNotification('notif-123')}>Delete</button>
    </>
  );
}
```

> **Note:** `filterPairs` is stored in a `useRef` so mutations always use the latest connection pairs without requiring re-subscription — safe to pass a value that changes on re-renders.
