Utility helpers for managing notifications in the Relay store, including connection manipulation, unread count tracking, severity mapping, and notification node transformation.

## Key Components

### Constants & Types
- `NOTIFICATIONS_CONNECTION_KEY` — Relay connection key used across all notification list fragments
- `NotificationsConnectionFilters` / `NotificationConnectionPair` — filter shapes for read/unread Relay connections
- `NotificationFieldsKey` / `NotificationFieldsData` — the generated key and data types of the `notificationFields_notification` `@inline` fragment (`notification-fields.ts`), which both lists spread

### Store Updater Factories
- `makeMarkReadUpdater(id, pairs, options)` — moves a single notification from unread → read connections; optionally decrements category badge count
- `makeMarkAllReadUpdater(pairs)` — bulk-moves all unread edges to read connections and zeros all category badges
- `makeDeleteAllReadUpdater(pairs)` — clears all edges from read connections
- `makeDeleteNotificationUpdater(id, pairs)` — removes a notification from all connections; adjusts unread count if it was unread

### Unread Count Helpers
- `adjustUnreadCount(store, category, delta)` — increments/decrements a per-category unread bucket in the Relay store without a refetch
- `clearUnreadCounts(store)` — zeroes all category buckets (used after mark-all-read)

### Mapping & Parsing Utilities
- `readNotificationNode(ref)` — reads a `notificationFields_notification` spread off either list's edges via `readInlineData`
- `mapNotificationNode(node)` — transforms that READ data (not the fragment reference) into the `Notification` type consumed by UI components, so a caller needing the raw fields too reads the node once
- `severityToVariant(severity)` — maps `DANGER | WARNING | SUCCESS | INFO` to UI variant strings
- `parseSeverity(input)` — normalizes case-insensitive severity strings
- `contextTypeLabel(contextType)` — converts `SNAKE_CASE` context type discriminators to human-readable "Title Case" labels
- `parseCreatedAt(value)` — normalizes epoch seconds, epoch ms, or ISO strings to a consistent millisecond timestamp

## Usage Example

```typescript
import {
  makeMarkReadUpdater,
  makeMarkAllReadUpdater,
  UNFILTERED_NOTIFICATION_PAIR,
  mapNotificationNode,
  readNotificationNode,
  severityToVariant,
  parseSeverity,
} from './notifications-helpers';

// Move a single notification to the read connection
commitMutation(environment, {
  mutation: MarkReadMutation,
  variables: { id: notificationId },
  updater: makeMarkReadUpdater(notificationId, [UNFILTERED_NOTIFICATION_PAIR]),
});

// Bulk mark all read
commitMutation(environment, {
  mutation: MarkAllReadMutation,
  variables: {},
  updater: makeMarkAllReadUpdater([UNFILTERED_NOTIFICATION_PAIR]),
});

// Read the row off an edge, then map it to the UI Notification type
const notification = mapNotificationNode(readNotificationNode(edge.node));
const variant = severityToVariant(parseSeverity(notification.severity));
// variant => 'error' | 'warning' | 'success' | 'info' | 'default'
```
