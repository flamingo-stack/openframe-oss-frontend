Defines a Relay GraphQL mutation for deleting a single notification by ID.

## Key Components

- **`deleteNotificationMutation`** — A compiled Relay `graphql` mutation tag that calls the `deleteNotification` resolver, accepting a required `$id: ID!` variable and mapping it to the `notificationId` argument.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { deleteNotificationMutation } from './delete-notification-mutation';

const [commitMutation, isInFlight] = useMutation(deleteNotificationMutation);

commitMutation({
  variables: { id: 'notification-123' },
  onCompleted: () => console.log('Notification deleted'),
  onError: (error) => console.error(error),
});
```

## Notes

- The mutation returns a scalar (no nested selection set), so the response contains only a success/boolean value from `deleteNotification`.
- Follows Relay naming conventions — the exported constant name matches the `mutation` operation name (`deleteNotificationMutation`), which is required for Relay's compiler to generate the correct artifact.
