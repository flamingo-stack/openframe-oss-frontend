Defines a Relay GraphQL mutation for marking every notification about one entity (a ticket, a Mingo dialog) as read in a single call.

## Key Components

- **`markNotificationsReadForEntityMutation`** — A compiled Relay `graphql` mutation calling `markNotificationsReadForEntity(entityType:entityId:)`, taking a `NotificationEntityType!` (`TICKET` / `DIALOG`) plus the entity's `ID!` and returning the number of notifications it marked.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { NotificationEntityType } from '@/generated/schema-enums';
import { markNotificationsReadForEntityMutation } from './mark-notifications-read-for-entity-mutation';

const [commit] = useMutation(markNotificationsReadForEntityMutation);
commit({ variables: { entityType: NotificationEntityType.TICKET, entityId: ticketId } });
```

## Notes

- The returned count spans categories, so it cannot be subtracted from a single `unreadCountsByCategory` bucket — refetch the counts instead (`refreshUnreadCounts`). `useMarkEntityNotificationsRead` does this for you.
- Notification cards stay in the drawer list; only their read state and the counts change.
- Enum values come from `@/generated/schema-enums`, never from the Relay artifact.
