Updates user notification settings via a GraphQL mutation, toggling push notification preferences.

## Key Components

- **`updateNotificationSettingsMutation`** — A Relay GraphQL mutation that accepts a `pushEnabled` boolean and returns the updated `pushEnabled` state from the server.

## Usage Example

```typescript
import { commitMutation } from 'react-relay';
import { updateNotificationSettingsMutation } from './update-notification-settings-mutation';

commitMutation(environment, {
  mutation: updateNotificationSettingsMutation,
  variables: { pushEnabled: true },
  onCompleted: (response) => {
    console.log('Push enabled:', response.updateNotificationSettings.pushEnabled);
  },
});
```

## Notes

- Defined using `react-relay`'s `graphql` tag for Relay compiler compatibility.
- The mutation only exposes the `pushEnabled` field in its response — extend the selection set if additional fields are needed.
