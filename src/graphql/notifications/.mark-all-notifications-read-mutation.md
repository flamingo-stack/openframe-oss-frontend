Defines a Relay GraphQL mutation that marks all notifications as read for the current user.

## Key Components

- **`markAllNotificationsReadMutation`** — A compiled Relay `graphql` mutation that calls the `markAllNotificationsAsRead` server mutation, requiring no input variables.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { markAllNotificationsReadMutation } from './mark-all-notifications-read-mutation';

function NotificationsBell() {
  const [commit, isInFlight] = useMutation(markAllNotificationsReadMutation);

  const handleMarkAllRead = () => {
    commit({ variables: {} });
  };

  return <button onClick={handleMarkAllRead} disabled={isInFlight}>Mark all read</button>;
}
```

## Notes

- Takes no variables — the server resolves the current user from the authenticated session.
- Pair with a Relay store updater or a refetch to reflect the cleared state in the UI after the mutation completes.
