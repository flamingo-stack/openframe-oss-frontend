Defines the Relay GraphQL query and paginated fragment for fetching unread notifications in the notifications drawer.

## Key Components

- **`notificationsDrawerRelayQuery`** — Root GraphQL query that spreads the refetchable fragment, accepting `$first` (Int, required) and `$after` (String, optional) pagination arguments.
- **`notificationsDrawerRelayFragment`** — Refetchable fragment on `Query` using `@connection` for cursor-based pagination. Fetches the first 30 unread notifications by default, filtered by `{ read: false }`.

### Fragment Fields

Each notification node exposes:

| Field | Description |
|---|---|
| `id`, `title`, `description` | Core notification identity and content |
| `severity`, `category` | Classification metadata |
| `createdAt`, `read` | Timing and read state |
| `context` | Polymorphic union covering AI dialogs, ticket events, and approval requests |

### Context Union Types

| Type | Key Fields |
|---|---|
| `AdminAiMessageContext` | `dialogId` |
| `AdminAiTicketMessageContext` | `ticketId`, `dialogId` |
| `TicketStatusChangedContext` / `TicketAssignedContext` | `ticketId` |
| `CustomerMessagePublishedContext` / `AdminMessagePublishedContext` | `ticketId` |
| `AdminApprovalRequestContext` | `approvalRequestId`, `dialogId`, `approvalType`, `toolCalls[]` |

## Usage Example

```typescript
import {
  notificationsDrawerRelayQuery,
  notificationsDrawerRelayFragment,
} from './notifications-drawer-relay';
import { usePreloadedQuery, useRefetchableFragment } from 'react-relay';

// Load initial data
const queryRef = loadQuery(environment, notificationsDrawerRelayQuery, { first: 30 });

// Inside component
const data = usePreloadedQuery(notificationsDrawerRelayQuery, queryRef);
const [fragmentData, refetch] = useRefetchableFragment(
  notificationsDrawerRelayFragment,
  data
);

// Paginate
refetch({ first: 30, after: fragmentData.notifications.pageInfo.endCursor });
```
