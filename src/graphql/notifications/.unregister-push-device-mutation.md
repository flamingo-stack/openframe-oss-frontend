Defines a Relay GraphQL mutation for unregistering a push notification device by its token.

## Key Components

- **`unregisterPushDeviceMutation`** — A compiled Relay `graphql` mutation that calls the `unregisterPushDevice` server mutation, accepting a required `token` string argument.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { unregisterPushDeviceMutation } from './unregister-push-device-mutation';

const [commitMutation] = useMutation(unregisterPushDeviceMutation);

commitMutation({
  variables: { token: devicePushToken },
  onCompleted: () => console.log('Device unregistered'),
  onError: (error) => console.error('Unregister failed', error),
});
```

## Notes

- Typically called during logout or when a user disables push notifications.
- The mutation returns a scalar (no nested selection set), so the response payload is minimal.
