Defines a Relay GraphQL query for fetching user notification settings, specifically whether push notifications are enabled.

## Key Components

- **`notificationSettingsRelayQuery`** — A compiled Relay `graphql` query that retrieves the `notificationSettings` object containing the `pushEnabled` boolean field.

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { notificationSettingsRelayQuery } from './notification-settings-relay';
import type { notificationSettingsRelayQuery as NotificationSettingsQueryType } from './__generated__/notificationSettingsRelayQuery.graphql';

const NotificationSettings = () => {
  const data = useLazyLoadQuery<NotificationSettingsQueryType>(
    notificationSettingsRelayQuery,
    {}
  );

  return <Toggle enabled={data.notificationSettings.pushEnabled} />;
};
```

## Notes

- This query takes no variables.
- The generated type `notificationSettingsRelayQuery` will be available in the Relay compiler output under `__generated__/notificationSettingsRelayQuery.graphql.ts`.
