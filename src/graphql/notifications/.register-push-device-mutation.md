Defines a Relay GraphQL mutation for registering a device to receive push notifications, accepting a device token and platform type.

## Key Components

- **`registerPushDeviceMutation`** — A compiled Relay GraphQL mutation that calls the `registerPushDevice` server mutation with the required arguments.

### GraphQL Variables

| Variable | Type | Description |
|---|---|---|
| `$token` | `String!` | The push notification device token |
| `$platform` | `PushPlatform!` | The target platform enum (e.g. `IOS`, `ANDROID`) |

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { registerPushDeviceMutation } from './register-push-device-mutation';

function usePushRegistration() {
  const [commit] = useMutation(registerPushDeviceMutation);

  const register = (token: string, platform: 'IOS' | 'ANDROID') => {
    commit({
      variables: { token, platform },
      onCompleted: () => console.log('Push device registered'),
      onError: (err) => console.error('Registration failed', err),
    });
  };

  return { register };
}
```

## Notes

- The mutation returns a scalar/boolean — no nested selection set is required.
- Relay will auto-generate TypeScript types for this mutation at build time via the Relay compiler. Ensure the `registerPushDeviceMutation` type is imported from the generated `__generated__` directory when strict typing is needed.
