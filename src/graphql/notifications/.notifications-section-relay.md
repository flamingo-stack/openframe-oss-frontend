Defines the React Relay GraphQL query and paginated fragment for the notifications section, enabling cursor-based pagination and filtered fetching of notification data.

## Key Components

- **`notificationsSectionRelayQuery`** — Root GraphQL query accepting `$first`, `$after`, `$filter`, and `$search` variables; spreads the main fragment with forwarded arguments.
- **`notificationsSectionRelayFragment`** — Refetchable, paginated fragment on `Query` using `@connection` (key: `NotificationsList_notifications`) with `filter` and `search` as cache-busting filters. Fetches notification edges including:
  - Core fields: `id`, `severity`, `title`, `description`, `createdAt`, `read`, `category`
  - Polymorphic `context` union covering: `AdminAiMessageContext`, `AdminAiTicketMessageContext`, `TicketStatusChangedContext`, `TicketAssignedContext`, `CustomerMessagePublishedContext`, `AdminMessagePublishedContext`, and `AdminApprovalRequestContext` (with full approval metadata and `toolCalls`).
- **`notificationsSectionRelayPaginationQuery`** — Auto-generated refetch query name produced by `@refetchable`.

## Usage Example

```typescript
import {
  notificationsSectionRelayQuery,
  notificationsSectionRelayFragment,
} from './notifications-section-relay';
import { usePreloadedQuery, useFragment } from 'react-relay';

// Load the root query (e.g., via useQueryLoader or loadQuery)
const queryData = usePreloadedQuery(notificationsSectionRelayQuery, queryRef);

// Consume the paginated fragment with refetch support
const { data, loadNext, hasNext } = usePaginationFragment(
  notificationsSectionRelayFragment,
  queryData
);

// Access notifications
const notifications = data.notifications.edges.map(({ node }) => node);
```

## Notes

- Default page size is `50` (`first` defaultValue in `@argumentDefinitions`).
- The `@connection` directive enables Relay's automatic pagination cache merging.
- The `context` union uses inline fragments (`... on`) for type-safe access to context-specific fields such as `ticketId`, `dialogId`, and approval `toolCalls`.
