Utility module for the OpenFrame time-tracker feature, providing timer state mapping, instant/duration parsing, Relay store updaters, and cross-surface invalidation helpers.

## Key Components

### Constants & Interfaces
- `MY_TIME_ENTRIES_CONNECTION_KEY` — Relay connection key for the recent entries list
- `TimeEntryNodeShape` — Shape of a raw GraphQL time entry node
- `TrackerClockState` — Normalized clock state consumed by the tracker UI (`status`, `runningSince`, `accumulatedMs`)

### Instant & Duration Utilities
- `parseInstant(value)` — Normalizes ISO strings, epoch seconds, or epoch ms to milliseconds
- `calendarDayToInstant(date)` / `instantToCalendarDay(value)` — Round-trip codec anchoring calendar days at UTC midnight
- `moveInstantToCalendarDay(value, day)` — Moves an instant to a new calendar day while preserving UTC time-of-day
- `formatDurationLabel(seconds)` / `parseDurationLabel(label)` — Convert between seconds and `HH:MM:SS` strings
- `toInstantRange(from, to)` — Builds inclusive day-range filter bounds

### Timer State Mapping
- `mapTimerToTrackerState(node)` — Derives `TrackerClockState` from a raw node, handling `RUNNING`, `PAUSED`, and `COMPLETED` states
- `mapTimeEntryToLastEntry(node)` — Maps a raw node to the `TimeTrackerEntry` display contract

### ID Helpers
- `toTicketGlobalId(id)` / `toOrganizationGlobalId(id)` — Normalize raw Mongo ObjectIds to Relay global IDs
- `CLEAR_TICKET_ID` / `CLEAR_ORGANIZATION_ID` — Sentinel values for clearing FK fields in partial-update mutations

### Relay Store Updaters
- `makeSetCurrentTimerUpdater(fieldName)` — Points `currentTimer` at the node returned by start/pause/resume
- `makeStopTimerUpdater()` — Prepends the stopped entry to the recent-entries connection
- `makeCreateTimeEntryUpdater()` — Prepends a newly created manual entry to the connection
- `makeDeleteTimeEntryUpdater(id)` / `makeCancelTimerUpdater(timerId)` — Delete records from the Relay store

### Cross-Surface Invalidation
- `notifyTimeEntriesChanged(userId)` / `subscribeTimeEntriesChanged(listener)` — Pub/sub for invalidating server aggregates (e.g. `employeeTimeStats`) across surfaces when the global timer widget mutates an entry

## Usage Example

```typescript
import {
  mapTimerToTrackerState,
  makeStopTimerUpdater,
  subscribeTimeEntriesChanged,
  toInstantRange,
  parseDurationLabel,
} from './time-tracker-helpers';

// Derive clock state for the tracker UI
const clockState = mapTimerToTrackerState(currentTimerNode);
// { status: 'tracking', runningSince: 1718000000000, accumulatedMs: 0 }

// Relay mutation updater for stop
commitMutation(environment, {
  mutation: StopTimerMutation,
  updater: makeStopTimerUpdater(),
});

// Build a date-range filter for the entries list
const range = toInstantRange(new Date('2025-01-01'), new Date('2025-01-31'));
// { startedFrom: '2025-01-01T00:00:00.000Z', startedTo: '2025-01-31T23:59:59.999Z' }

// Validate manual duration input
const seconds = parseDurationLabel('01:30:00'); // 5400

// Invalidate the "My Time" page when the global widget stops a timer
const unsubscribe = subscribeTimeEntriesChanged((userId) => {
  if (userId === currentUserId) refetch();
});
```
