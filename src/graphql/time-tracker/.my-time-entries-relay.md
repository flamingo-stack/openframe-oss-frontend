Defines the Relay GraphQL query and paginated fragment for fetching the current user's time entries, supporting cursor-based pagination via the `@connection` directive.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `myTimeEntriesRelayQuery` | Root query | Entry-point query that spreads the fragment with `$first` and `$after` pagination variables |
| `myTimeEntriesRelayFragment` | Refetchable fragment | Paginated fragment on `Query` using `@refetchable`, `@argumentDefinitions`, and `@connection` for cursor-based pagination |

**Fragment details:**
- **Connection key:** `MyTimeEntries_myTimeEntries` — used by Relay's store to manage the paginated list
- **Pagination defaults:** `first: 3`, `after: String` (cursor)
- **Node fields:** Spread via `...timeEntryFields_timeEntry @relay(mask: false)`, pulling in all time entry fields inline
- **Page info:** Exposes `endCursor` and `hasNextPage` for "load more" patterns

## Usage Example

```typescript
import { myTimeEntriesRelayQuery, myTimeEntriesRelayFragment } from './my-time-entries-relay';
import { usePaginationFragment, useQueryLoader } from 'react-relay';

// Load the root query
const [queryRef, loadQuery] = useQueryLoader(myTimeEntriesRelayQuery);
loadQuery({ first: 3 });

// Inside your component, use the pagination fragment
const { data, loadNext, hasNext } = usePaginationFragment(
  myTimeEntriesRelayFragment,
  queryRef
);

const entries = data.myTimeEntries.edges.map(edge => edge.node);
```
