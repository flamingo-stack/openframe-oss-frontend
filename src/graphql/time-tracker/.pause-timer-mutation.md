Relay GraphQL mutation for pausing an active timer, returning the updated time entry fields.

## Key Components

- **`pauseTimerMutation`** — A tagged GraphQL mutation that calls the `pauseTimer` root mutation field and spreads the `timeEntryFields_timeEntry` fragment (with `@relay(mask: false)` to expose all fields inline).

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { pauseTimerMutation } from './pause-timer-mutation';

const [commitPauseTimer, isPending] = useMutation(pauseTimerMutation);

commitPauseTimer({
  variables: {},
  onCompleted(response) {
    console.log('Timer paused:', response.pauseTimer);
  },
  onError(error) {
    console.error('Failed to pause timer:', error);
  },
});
```

## Notes

- Requires the `timeEntryFields_timeEntry` fragment to be defined and available in the Relay schema.
- The `@relay(mask: false)` directive makes fragment data directly accessible on the response object without needing `readInlineData`.
- No input variables are required for this mutation.
