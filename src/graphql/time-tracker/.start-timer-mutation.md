Relay GraphQL mutation for starting a timer, querying the resulting time entry with the unmasked `timeEntryFields_timeEntry` fragment.

## Key Components

- **`startTimerMutation`** — Relay `graphql` tagged template defining the `startTimerMutation` operation, accepting a `StartTimerInput` variable and spreading the `timeEntryFields_timeEntry` fragment with `@relay(mask: false)`.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { startTimerMutation } from './start-timer-mutation';

const [commitMutation, isInFlight] = useMutation(startTimerMutation);

commitMutation({
  variables: {
    input: { taskId: 'task-123' },
  },
  onCompleted(response) {
    console.log('Timer started:', response.startTimer);
  },
  onError(error) {
    console.error('Failed to start timer:', error);
  },
});
```

## Notes

- The `@relay(mask: false)` directive exposes all fragment fields directly on the response object without requiring a separate `useFragment` call.
- Ensure the `timeEntryFields_timeEntry` fragment is defined and imported elsewhere in the Relay environment for the compiler to resolve it.
