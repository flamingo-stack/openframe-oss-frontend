Relay GraphQL query definition for fetching the currently active timer entry.

## Key Components

- **`currentTimerRelayQuery`** — Named Relay `graphql` query that retrieves the active `currentTimer` and spreads the `timeEntryFields_timeEntry` fragment with `@relay(mask: false)` to expose all fragment fields directly on the query result.

## Usage Example

```typescript
import { currentTimerRelayQuery } from './current-timer-relay';
import { useLazyLoadQuery } from 'react-relay';
import type { currentTimerRelayQuery as CurrentTimerRelayQueryType } from './__generated__/currentTimerRelayQuery.graphql';

const CurrentTimer = () => {
  const data = useLazyLoadQuery<CurrentTimerRelayQueryType>(
    currentTimerRelayQuery,
    {}
  );

  return <div>{data.currentTimer?.description}</div>;
};
```

## Notes

- The `@relay(mask: false)` directive bypasses Relay's data masking, making `timeEntryFields_timeEntry` fields accessible without explicitly importing the fragment in each consumer.
- Relay will auto-generate types into `__generated__/currentTimerRelayQuery.graphql.ts` after running the Relay compiler.
- See the full source at [`current-timer-relay.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/current-timer-relay.ts).
