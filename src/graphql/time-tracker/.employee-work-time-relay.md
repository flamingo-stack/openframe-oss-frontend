Defines Relay GraphQL query and fragment for fetching employee work time entries and aggregated time statistics with pagination support.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `employeeWorkTimeRelayQuery` | `graphql` root query | Fetches `employeeTimeStats` and spreads the pagination fragment |
| `employeeWorkTimeRelayFragment` | `graphql` refetchable fragment | Paginated `employeeTimeEntries` connection with employee and organization details |

### Query Variables

| Variable | Type | Description |
|----------|------|-------------|
| `filter` | `TimeEntryFilterInput` | Filter time entries by criteria |
| `search` | `String` | Full-text search across entries |
| `first` | `Int!` | Page size (default: `20`) |
| `after` | `String` | Cursor for forward pagination |

### `employeeTimeStats` Fields

- `todayTotalSeconds` / `todayEntryCount` — today's totals
- `periodTotalSeconds` / `periodEntryCount` — filtered period totals
- `averagePerDaySeconds` — computed daily average

## Usage Example

```typescript
import { employeeWorkTimeRelayQuery, employeeWorkTimeRelayFragment } from './employee-work-time-relay';
import { useLazyLoadQuery, usePaginationFragment } from 'react-relay';

const data = useLazyLoadQuery(employeeWorkTimeRelayQuery, {
  first: 20,
  filter: { userId: 'user-123' },
  search: '',
});

const { data: fragmentData, loadNext, hasNext } = usePaginationFragment(
  employeeWorkTimeRelayFragment,
  data,
);
```

The fragment uses the `@refetchable` directive, enabling `usePaginationFragment` to automatically generate `employeeWorkTimeRelayPaginationQuery` for cursor-based pagination. The connection key `EmployeeWorkTime_employeeTimeEntries` scopes the Relay store cache by `filter` and `search`.
