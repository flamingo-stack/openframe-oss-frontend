Defines the canonical Relay GraphQL fragment for `TimeEntry` records, ensuring all time-tracker queries and mutations normalize into the same Relay store record by `id`.

## Key Components

### `timeEntryFieldsFragment`

A shared Relay fragment (`timeEntryFields_timeEntry on TimeEntry`) containing the full set of scalar and nested fields for a time entry. Spread this fragment at query/mutation read sites using `@relay(mask: false)` to inline fields directly.

**Fields covered:**

| Category | Fields |
|---|---|
| Identity | `id`, `userId`, `ticketId`, `organizationId` |
| Ticket | `ticketNumber`, `ticketTitle`, `ticket { id, ticketNumber, title, organizationId, organizationName }` |
| Organization | `organization { id, name }` |
| Time tracking | `startedAt`, `endedAt`, `pausedAt`, `durationSeconds`, `breakSeconds` |
| Metadata | `notes`, `state`, `source`, `createdAt`, `updatedAt` |

## Usage Example

```typescript
import { graphql, useFragment } from 'react-relay';
import { timeEntryFieldsFragment } from './time-entry-fields';

// In a query or mutation, spread the fragment with mask: false
const MyQuery = graphql`
  query MyQuery($id: ID!) {
    timeEntry(id: $id) {
      ...timeEntryFields_timeEntry @relay(mask: false)
    }
  }
`;

// Or compose into a parent fragment
const MyFragment = graphql`
  fragment MyComponent_data on TimeEntry {
    ...timeEntryFields_timeEntry
  }
`;
```

## Notes

- Using a single shared fragment guarantees Relay's store deduplicates all `TimeEntry` records by `id` regardless of which query fetched them.
