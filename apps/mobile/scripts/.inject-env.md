## inject-env.mjs

A build-time script that injects runtime environment configuration into the static `www/index.html` bundle, enabling the mobile/native shell app to resolve gateway hosts without a server-side rendering step.

## Key Components

- **`env` object** — Collects runtime configuration from `process.env`, including:
  - `NEXT_PUBLIC_SHARED_HOST_URL` — the shared auth host (required; build aborts if missing)
  - `NEXT_PUBLIC_TENANT_HOST_URL` — optional single-tenant pin for dev/self-hosted builds
  - `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` — dev-only affordance, defaults to disabled
  - `NEXT_PUBLIC_APP_MODE` — defaults to `oss-tenant`
  - `NEXT_PUBLIC_MOBILE_APP_SCHEME` — OAuth callback URL scheme, must match native iOS build config
  - `NEXT_PUBLIC_MOBILE_AUTH_UI` — controls auth screen variant (`login-only` or `legacy`)
- **Fail-fast validation** — Exits with an error if `NEXT_PUBLIC_SHARED_HOST_URL` is unset, since auth calls would otherwise resolve against `capacitor://localhost` and silently fail at runtime.
- **`envScript` / `insertEnvScript`** (imported from `./ota-env.mjs`) — Generate and splice a `window.__ENV` bootstrap script into `index.html`, consumed by `next-runtime-env`'s `env()` and the frontend's `runtime-config.ts` fallback.

## Usage Example

Run as a build step after the static bundle is generated, with environment variables provided by CI or your shell:

```bash
NEXT_PUBLIC_SHARED_HOST_URL=https://auth.openframe.ai \
NEXT_PUBLIC_APP_MODE=oss-tenant \
NEXT_PUBLIC_MOBILE_APP_SCHEME=com.openframe.app.dev \
node scripts/inject-env.mjs
```

On success, the script logs the injected values:

```text
▸ injected window.__ENV: {
  NEXT_PUBLIC_SHARED_HOST_URL: 'https://auth.openframe.ai',
  NEXT_PUBLIC_TENANT_HOST_URL: '',
  NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER: 'false',
  NEXT_PUBLIC_APP_MODE: 'oss-tenant',
  NEXT_PUBLIC_MOBILE_APP_SCHEME: 'com.openframe.app.dev',
  NEXT_PUBLIC_MOBILE_AUTH_UI: 'login-only'
}
```

If `NEXT_PUBLIC_SHARED_HOST_URL` is omitted, the build fails immediately rather than shipping a broken bundle.
