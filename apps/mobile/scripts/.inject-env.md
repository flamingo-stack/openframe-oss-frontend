## inject-env.mjs

A build-time Node script that injects a `window.__ENV` bootstrap script into `www/index.html`, allowing the static mobile bundle to resolve gateway hosts and runtime configuration without a server. It reads configuration from process environment variables (set by CI or the shell) and writes them directly into the HTML so `next-runtime-env`'s `env()` and `openframe-frontend`'s `runtime-config.ts` can read them at runtime via `window.__ENV`.

## Key Components

- **`env` object** — Collects runtime configuration values from `process.env`, including:
  - `NEXT_PUBLIC_SHARED_HOST_URL` — shared auth host for tenant discovery and OAuth (required).
  - `NEXT_PUBLIC_TENANT_HOST_URL` — optional single-tenant pin for dev/self-hosted builds.
  - `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` — dev-only feature flag, disabled by default.
  - `NEXT_PUBLIC_APP_MODE` — application mode (defaults to `oss-tenant`).
  - `NEXT_PUBLIC_MOBILE_APP_SCHEME` — OAuth callback URL scheme, must match native iOS build config.
  - `NEXT_PUBLIC_MOBILE_AUTH_UI` — controls which auth screens are shown (`login-only` or `legacy`).
- **Validation guard** — Aborts the build (`process.exit(1)`) if `NEXT_PUBLIC_SHARED_HOST_URL` is missing, preventing a bundle that would silently fail all auth/discovery calls.
- **`envScript` / `insertEnvScript`** (imported from `./ota-env.mjs`) — Generate and insert the `window.__ENV` script tag into the HTML, keeping injection logic shared with the over-the-air (OTA) bundle update path.

## Usage Example

Run as part of the mobile build pipeline, after `www/index.html` is generated:

```bash
NEXT_PUBLIC_SHARED_HOST_URL="https://auth.openframe.ai" \
NEXT_PUBLIC_APP_MODE="oss-tenant" \
node scripts/inject-env.mjs
```

On success, the script prints the injected values:

```text
▸ injected window.__ENV: { NEXT_PUBLIC_SHARED_HOST_URL: 'https://auth.openframe.ai', ... }
```

If `NEXT_PUBLIC_SHARED_HOST_URL` is not set, the build fails fast with an error rather than producing a bundle where auth requests resolve against `capacitor://localhost`.
