Build-time Node script that injects a `window.__ENV` bootstrap `<script>` tag into `www/index.html`, allowing the static Capacitor bundle to resolve gateway hosts and runtime configuration without a server-side rendering step.

## Key Components

- **`env` object** — collects runtime configuration from process environment variables (with sane defaults), including:
  - `NEXT_PUBLIC_SHARED_HOST_URL` — shared auth host for tenant discovery and OAuth (required, no default)
  - `NEXT_PUBLIC_TENANT_HOST_URL` — optional single-tenant pin for dev/self-hosted builds
  - `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` — dev-only feature flag, defaults to `false`
  - `NEXT_PUBLIC_APP_MODE` — defaults to `oss-tenant`
  - `NEXT_PUBLIC_MOBILE_APP_SCHEME` — OAuth callback URL scheme, must match native iOS build setting
  - `NEXT_PUBLIC_MOBILE_AUTH_UI` — controls auth screen variant (`login-only` or `legacy`)
- **Required-var validation** — aborts the build (`process.exit(1)`) if `NEXT_PUBLIC_SHARED_HOST_URL` is missing, preventing a broken bundle that would 401 on every auth call.
- **HTML injection logic** — reads `www/index.html`, replaces an existing `window.__ENV` script tag if present, otherwise inserts a new one right after `<head>`.

## Usage Example

Run as part of the build pipeline before packaging the Capacitor WebView bundle:

```bash
NEXT_PUBLIC_SHARED_HOST_URL="https://auth.openframe.ai" \
NEXT_PUBLIC_MOBILE_APP_SCHEME="com.openframe.app" \
node scripts/inject-env.mjs
```

This produces output like:

```javascript
// Injected into www/index.html <head>:
<script>window.__ENV = {"NEXT_PUBLIC_SHARED_HOST_URL":"https://auth.openframe.ai", ...};</script>
```

The consuming frontend reads these values via `next-runtime-env`'s `env()` helper or `openframe-frontend`'s `runtime-config.ts` fallback, allowing the same static bundle to be configured per environment (dev/stage/prod) without rebuilding. See [inject-env.mjs](https://github.com/flamingo-stack/openframe-saas-mobile/blob/main/scripts/inject-env.mjs).
