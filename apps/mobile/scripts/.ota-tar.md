## Overview

Implements the OTA (over-the-air) bundle archive format: a ustar tar archive of regular files compressed as a single xz stream. This format is shared across the export pipeline and native shells (Apple's Compression framework, XZ for Java), ensuring byte-identical output across implementations. Since Node lacks a native xz codec, this module shells out to the `xz` binary.

## Key Components

- **`isSafeEntryName(name)`** — Validates that a file path is safe for shells to write as-is (printable ASCII, no spaces/backslashes, no `.`/`..` segments).
- **`writeTar(entries)`** — Builds an uncompressed ustar archive from `{name, data}` entries (mode 644, owner 0, mtime 0).
- **`packTarXz(entries)`** — Produces a tar archive compressed as one deterministic xz stream (`XZ_ENCODE` options).
- **`xzDecompress(archive)`** — Decompresses and validates that an archive is exactly one intact xz stream within decoder memory limits.
- **`readTar(tar)`** — Parses an uncompressed ustar archive back into `{name, type, data}` entries, strictly validating header format.
- **`isRegularFile(entry)`** — Predicate checking an entry's type is a regular file.
- **`XZ_ENCODE`**, **`MAX_XZ_DECODER_MEMORY`** — Exported constants controlling compression settings and shell memory constraints.

Errors are raised as `OtaError` with codes like `ENTRY_NAME`, `TAR`, or `XZ` to signal specific validation failures.

## Usage Example

```javascript
import { packTarXz, xzDecompress, readTar, isRegularFile } from './ota-tar.mjs';

// Build and compress a bundle
const entries = [
  { name: 'pages/index.html', data: Buffer.from('<html>...</html>') },
  { name: 'pages/about.html', data: Buffer.from('<html>...</html>') },
];
const bundle = packTarXz(entries);

// Later, decode the bundle
const tar = xzDecompress(bundle);
const files = readTar(tar).filter(isRegularFile);

for (const file of files) {
  console.log(file.name, file.data.length);
}
```

This module underpins reproducible OTA bundle creation (see `docs/ota.md`) and is validated against fixtures in `fixtures/bundle-cases.json` to ensure cross-platform consistency.
