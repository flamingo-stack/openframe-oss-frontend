## ota-tar.mjs

Implements the over-the-air (OTA) bundle archive format: a ustar tar of regular files compressed as a single `xz` stream. This format allows OTA update shells (iOS via Apple's Compression framework, Android via XZ for Java) to deterministically decode bundles and compare them against expected fixtures. Since Node.js has no native xz codec, this module shells out to the `xz` binary.

## Key Components

- **`isSafeEntryName(name)`** — Validates a relative file path is safe for inclusion in a bundle (printable ASCII, `/`-separated, no `.`/`..`/empty segments, length-limited).
- **`writeTar(entries)`** — Builds an uncompressed ustar archive from `{ name, data }` entries (mode 644, owner 0, mtime 0).
- **`packTarXz(entries)`** — Produces a tar archive and compresses it as a single deterministic xz stream (`XZ_ENCODE` options).
- **`xzDecompress(archive)`** — Validates (via `assertOneXzStream`) and decompresses a bundle back into its tar bytes.
- **`readTar(tar)`** — Parses an uncompressed ustar archive into an ordered list of `{ name, type, data }` entries, strictly validating header checksums, size fields, and end-of-archive markers.
- **`isRegularFile(entry)`** — Predicate checking an entry's type is a regular file (`'0'`).
- **`XZ_ENCODE`** — Shared xz CLI flags (`-6 -T1 --check=crc64`) ensuring byte-for-byte reproducible compression across xz versions.
- **`MAX_XZ_DECODER_MEMORY`** — 32 MiB cap ensuring bundles stay decodable within Android shell memory limits.

Errors are raised as `OtaError` with categories like `ENTRY_NAME`, `TAR`, and `XZ` to distinguish bundle-format problems from environment/tooling failures.

## Usage Example

```javascript
import { packTarXz, xzDecompress, readTar, isRegularFile } from './ota-tar.mjs';

const entries = [
  { name: 'app/index.js', data: Buffer.from('console.log("hi")') },
  { name: 'app/pages/home.rsc', data: Buffer.from('...') },
];

// Pack entries into a compressed OTA bundle
const bundle = packTarXz(entries);

// Later, decode and verify the bundle
const tarBuffer = xzDecompress(bundle);
const decoded = readTar(tarBuffer).filter(isRegularFile);

console.log(decoded.map(e => e.name));
// => ['app/index.js', 'app/pages/home.rsc']
```

**Requirements:** The `xz` CLI must be installed on the host (`apt install xz-utils` or `brew install xz`), since Node.js has no built-in xz support.
