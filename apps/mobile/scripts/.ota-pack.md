# ota-pack.mjs

CLI script that packages the web app's static export into a signed over-the-air (OTA) update bundle for the mobile shells, producing a `tar.xz` archive and a cryptographically signed manifest (`mobile.json`).

Part of the mobile OTA pipeline documented in `docs/ota.md`. It reads the signing key from the `MOBILE_OTA_SIGNING_KEY` environment variable (a P-256 PKCS#8 PEM) and the required bridge version from `REQUIRED_BRIDGE_LEVEL` in `apps/web/src/lib/native-shell.ts`.

## Key Components

- **`LEFT_OUT`** – Set of files (social preview images) deliberately excluded from the bundle since they're only referenced via absolute URLs, never loaded from the app itself.
- **`readBridgeLevel(path)`** – Parses `REQUIRED_BRIDGE_LEVEL` out of `native-shell.ts` so the manifest always matches the web app's expected native bridge version.
- **`listFiles(dist, prefix)`** – Recursively lists all regular files under the dist directory (throws on symlinks or other non-file entries for safety).
- **`pack(options)`** – Core packing function: validates the dist directory and signing key, builds the tar.xz archive, computes its SHA-256 and size, signs the resulting payload, self-verifies the manifest, and writes both files to `outDir`. Returns paths, payload, key ID, and file list.
- **`main()`** – CLI entry point parsing `--dist`, `--version`, `--url-base`, and `--out` arguments and invoking `pack()`.

## Usage Example

```bash
node apps/mobile/scripts/ota-pack.mjs \
  --dist apps/web/dist \
  --version 1.2.3 \
  --url-base https://github.com/flamingo-stack/openframe-oss-frontend/releases/download/1.2.3 \
  --out dist/ota
```

Programmatic usage:

```javascript
import { pack } from './ota-pack.mjs';

const result = pack({
  dist: 'apps/web/dist',
  version: '1.2.3',
  urlBase: 'https://github.com/flamingo-stack/openframe-oss-frontend/releases/download/1.2.3',
  outDir: 'dist/ota',
  privateKeyPem: process.env.MOBILE_OTA_SIGNING_KEY,
  bridgeLevel: 4,
});

console.log(result.bundlePath, result.manifestPath, result.payload);
```

The script fails fast if the dist directory lacks `index.html`, still contains runtime-injected `window.__ENV` (indicating it's a native shell's `www/` rather than a fresh static export), or if the signing key is missing or not a P-256 key.
