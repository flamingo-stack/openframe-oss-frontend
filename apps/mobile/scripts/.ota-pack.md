## ota-pack.mjs

CLI script that packages the `apps/web` static export into a signed over-the-air (OTA) update bundle for the mobile shells, producing a `tar.xz` archive and a signed `mobile.json` manifest as described in `docs/ota.md`.

## Key Components

- **`LEFT_OUT`** - Set of files (duplicate social-preview images) excluded from the bundle since phones never load them locally.
- **`readBridgeLevel(path)`** - Parses `REQUIRED_BRIDGE_LEVEL` from `apps/web/src/lib/native-shell.ts` to embed in the manifest.
- **`listFiles(dist, prefix)`** - Recursively lists all regular files under the dist directory (sorted, `/`-separated), throwing on symlinks or non-file entries.
- **`pack({ dist, version, urlBase, outDir, privateKeyPem, bridgeLevel })`** - Core packaging function: validates the dist directory (must contain `index.html` without injected `window.__ENV`), builds the tar.xz archive, computes SHA-256, signs the payload with a P-256 private key, self-verifies the manifest, and writes both files to `outDir`. Returns paths, payload, keyId, and file list.
- **`main()`** - CLI entry point parsing `--dist`, `--version`, `--url-base`, and `--out` arguments; reads the signing key from `MOBILE_OTA_SIGNING_KEY` env var and bridge level from `native-shell.ts`.

Depends on `ota-tar.mjs` (archive creation), `ota-verify.mjs` (bundle/manifest verification helpers, constants), and `ota-env.mjs` (detection of injected env markers).

## Usage Example

```bash
export MOBILE_OTA_SIGNING_KEY="$(cat signing-key.pem)"

node apps/mobile/scripts/ota-pack.mjs \
  --dist apps/web/dist \
  --version 1.2.3 \
  --url-base https://github.com/flamingo-stack/openframe-oss-frontend/releases/download/1.2.3 \
  --out dist/ota
```

```javascript
import { pack } from './ota-pack.mjs';

const result = pack({
  dist: 'apps/web/dist',
  version: '1.2.3',
  urlBase: 'https://example.com/releases/1.2.3',
  outDir: 'dist/ota',
  privateKeyPem: process.env.MOBILE_OTA_SIGNING_KEY,
  bridgeLevel: 3,
});

console.log(result.bundlePath, result.manifestPath, result.payload);
```
