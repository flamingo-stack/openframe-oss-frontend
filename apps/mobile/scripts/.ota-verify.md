# ota-verify.mjs

Verifies an over-the-air (OTA) mobile bundle using the same checks the native shells apply, as documented in `docs/ota.md`. It validates the signature of `mobile.json` against the public keys in `apps/mobile/ota/keys.json`, checks the signed payload fields, and (optionally) verifies a `tar.xz` bundle named by that payload. Every failure throws an `OtaError` with a stable code matching the shells' own error codes, exercised by `fixtures/*-cases.json`.

## Key Components

- **`loadKeys(path)`** — Loads `keys.json`, returning a `Map` of key ID → P-256 public `KeyObject`. Enforces exactly two distinct keys (`current`, `next`), rejects private keys or malformed PEM.
- **`assertP256(key, what)`** — Throws `KEYS` unless the key is EC/P-256 in the canonical 91-byte uncompressed SPKI encoding.
- **`keyIdOf(key)`** — Derives a manifest key ID as the first 16 hex digits of SHA-256 over the key's SPKI DER.
- **`parseObject(text, code, what)`** — Strict JSON-object parser used throughout for envelope/payload parsing.
- **`verifyManifest(text, keys)`** — Verifies the envelope (`keyId`, `payload`, `signature`), checks the signature, then validates payload fields (`format`, `version`, `bridgeLevel`, `size`, `sha256`, `url`). Returns the parsed payload.
- **`checkBundleContents(archive)`** — Decompresses and reads the tar, validating entry types/names, rejecting duplicates/case collisions, requiring a root `index.html`, and checking env-target markers. Returns file metadata `{path, size, sha256}`.
- **`verifyBundle(archive, payload)`** — Validates archive size and SHA-256 against the manifest payload, then calls `checkBundleContents`.
- **`bundleName(version)`** — Produces the expected bundle filename, e.g. `openframe-mobile-1.2.3.tar.xz`.
- **`KEYS_PATH`, `KEY_SLOTS`, `MANIFEST_NAME`, `FORMAT`, `VERSION`** — Shared constants/regex for key slots, manifest name, format version, and semver validation.

## Usage Example

As a CLI:

```bash
# Validate keys.json alone
node apps/mobile/scripts/ota-verify.mjs

# Validate a signed manifest
node apps/mobile/scripts/ota-verify.mjs --manifest mobile.json

# Validate manifest and bundle together
node apps/mobile/scripts/ota-verify.mjs --manifest mobile.json --bundle openframe-mobile-1.2.3.tar.xz --keys ota/keys.json
```

Programmatically:

```javascript
import { loadKeys, verifyManifest, verifyBundle } from './ota-verify.mjs';
import { readFileSync } from 'node:fs';

const keys = loadKeys('apps/mobile/ota/keys.json');
const payload = verifyManifest(readFileSync('mobile.json', 'utf8'), keys);
const files = verifyBundle(readFileSync('openframe-mobile-1.2.3.tar.xz'), payload);
console.log(`Verified ${files.length} files in bundle`);
```
