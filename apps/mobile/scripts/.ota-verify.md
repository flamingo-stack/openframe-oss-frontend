# ota-verify.mjs

Node.js CLI and library for verifying OpenFrame Mobile over-the-air (OTA) update bundles exactly as the native mobile shells do (per `docs/ota.md`). It validates the cryptographic signature of a `mobile.json` manifest against trusted keys in `apps/mobile/ota/keys.json`, checks the manifest's payload fields, and—when a bundle is supplied—verifies the `tar.xz` archive's size, checksum, and internal file structure.

## Key Components

- **`loadKeys(path)`** — Loads and validates `keys.json`, returning a `Map` of key ID → P-256 public key (both `current` and `next` slots must be distinct, valid PEM public keys).
- **`assertP256(key, what)`** — Throws an `OtaError('KEYS', ...)` unless the key is a P-256 EC key in the exact 91-byte uncompressed SPKI encoding.
- **`keyIdOf(key)`** — Computes the manifest key ID (first 16 hex chars of SHA-256 over the SPKI DER).
- **`verifyManifest(text, keys)`** — Parses and verifies a signed envelope (`{keyId, payload, signature}`), checking signature validity and payload schema (`format`, `version`, `bridgeLevel`, `size`, `sha256`, `url`). Returns the verified payload object.
- **`checkBundleContents(archive)`** — Decompresses and inspects a `tar.xz` bundle: rejects non-regular files, unsafe/duplicate entry names (case-insensitive), requires a root `index.html`, and runs environment-target checks.
- **`verifyBundle(archive, payload)`** — Validates bundle size and SHA-256 against the manifest payload, then calls `checkBundleContents`.
- **`parseObject(text, code, what)`** — Strict JSON-object parser used throughout for consistent error codes.
- **Constants**: `KEYS_PATH`, `KEY_SLOTS`, `MANIFEST_NAME`, `FORMAT`, `VERSION` (semver regex), `bundleName(version)`.

All failures throw an `OtaError` carrying the same error codes exercised by shell-side test fixtures (`fixtures/*-cases.json`).

## Usage Example

```bash
# Check keys.json alone
node apps/mobile/scripts/ota-verify.mjs

# Verify a signed manifest
node apps/mobile/scripts/ota-verify.mjs --manifest mobile.json

# Verify a manifest and its bundle
node apps/mobile/scripts/ota-verify.mjs --manifest mobile.json --bundle openframe-mobile-1.2.3.tar.xz
```

```javascript
import { readFileSync } from 'node:fs';
import { loadKeys, verifyManifest, verifyBundle } from './ota-verify.mjs';

const keys = loadKeys('apps/mobile/ota/keys.json');
const payload = verifyManifest(readFileSync('mobile.json', 'utf8'), keys);
const files = verifyBundle(readFileSync('bundle.tar.xz'), payload);
console.log(`Bundle verified: ${files.length} files`);
```
