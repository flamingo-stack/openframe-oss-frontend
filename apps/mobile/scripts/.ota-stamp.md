## ota-stamp.mjs

Stamps the staged web bundle (`www/`) with the exact release version it was built from, enabling the mobile shells' over-the-air (OTA) updater to know its "built-in version." The stamp is written as a file inside the bundle itself (not a binary build setting), ensuring that lanes which reuse `www/` (for example, `SKIP_WEB=1`) ship a stamp consistent with that bundle, preventing drift between the two.

Only an exact `x.y.z` release version is stamped. Anything else (a commit past a tag, a dirty working tree, or a placeholder version) results in no stamp — and a shell without a stamp takes no OTA updates, since it cannot determine whether an incoming release is newer or older than what it currently carries.

## Key Components

- **`STAMP_NAME`** - Constant filename (`ota-builtin.json`) for the stamp file written into the bundle directory.
- **`stampBundle(version, wwwDir)`** - Core function that validates `version` against the `VERSION` regex (from `ota-verify.mjs`). Writes a JSON stamp (`{ version }`) to `wwwDir` and returns `true` if valid; otherwise removes any existing stamp file and returns `false`.
- **`main()`** - CLI entry point that reads `version` and optional `wwwDir` from `process.argv`, calls `stampBundle`, and logs the outcome.

## Usage Example

```bash
# Stamp the default www/ directory with release 1.2.3
node apps/mobile/scripts/ota-stamp.mjs 1.2.3

# Stamp a custom bundle directory
node apps/mobile/scripts/ota-stamp.mjs 1.2.3 ./dist/www

# Non-release versions (e.g. dev builds) remove any existing stamp
node apps/mobile/scripts/ota-stamp.mjs 1.2.3-dev.1
```

```javascript
import { stampBundle, STAMP_NAME } from './ota-stamp.mjs';

// Programmatic usage
const wasStamped = stampBundle('1.2.3', './www');
if (wasStamped) {
  console.log(`Stamp written at www/${STAMP_NAME}`);
} else {
  console.log('No stamp written: not a release version');
}
```
