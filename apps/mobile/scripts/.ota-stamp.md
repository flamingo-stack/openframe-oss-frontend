# ota-stamp.mjs

Stamps the staged web bundle (`www/`) with the exact release version it was built from, enabling the mobile shell's over-the-air (OTA) updater to know its "built-in version." The stamp lives inside the bundle itself (not a binary build setting), so bundle-reuse lanes (`SKIP_WEB=1`) always ship a stamp that matches the actual bundle contents, preventing version drift.

Only an exact semantic release (`x.y.z`) is stamped. Anything else—a commit past a tag, a dirty working tree, or a placeholder version—results in no stamp being written (and any existing stamp removed), meaning the shell will not attempt OTA updates since it cannot reliably compare versions.

## Key Components

- **`STAMP_NAME`** — Exported constant, the stamp filename (`ota-builtin.json`).
- **`stampBundle(version, wwwDir)`** — Core function. Writes `ota-builtin.json` containing `{ version }` into `wwwDir` if `version` matches the release pattern (`VERSION` regex from `ota-verify.mjs`); otherwise deletes any existing stamp file. Returns `true` if stamped, `false` otherwise.
- **`main()`** — CLI entry point. Reads `version` and optional `wwwDir` from `process.argv`, calls `stampBundle`, and logs the outcome.
- Uses `runCli` from `./ota-error.mjs` for standardized CLI error handling.

## Usage Example

```bash
# Stamp the default www/ directory with an exact release version
node apps/mobile/scripts/ota-stamp.mjs 1.4.2

# Stamp a custom bundle directory
node apps/mobile/scripts/ota-stamp.mjs 1.4.2 ./dist/www

# Non-release versions clear any existing stamp (no OTA updates taken)
node apps/mobile/scripts/ota-stamp.mjs 1.4.2-dirty
```

```javascript
import { stampBundle, STAMP_NAME } from './ota-stamp.mjs';

// Programmatic usage
const stamped = stampBundle('2.0.0', './www');
console.log(stamped); // true — ota-builtin.json written

const notStamped = stampBundle('2.0.0-rc1', './www');
console.log(notStamped); // false — stamp removed, not a release
```
