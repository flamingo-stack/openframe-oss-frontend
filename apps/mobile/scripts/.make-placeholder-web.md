# make-placeholder-web.mjs

Node.js CLI script that generates a minimal placeholder HTML bundle in the `www/` directory, allowing the native mobile shell to be built and deployed to a device without requiring the full `openframe-frontend` web export. It is intended for quickly validating the native pipeline (code signing, installation, launch) before integrating the real frontend bundle.

## Key Components

- **Root/output path resolution**: Uses `fileURLToPath` and `dirname`/`join` to compute the project root (one level above `scripts/`) and the target `www/` directory.
- **`mkdirSync(www, { recursive: true })`**: Ensures the `www/` directory exists before writing files.
- **`html` template string**: A self-contained dark-themed HTML page confirming the native shell is running, displaying the injected `window.__ENV` runtime configuration (if any), and reminding developers to run the real build.
- **`writeFileSync`**: Writes the generated HTML to `www/index.html`.
- **Console log**: Confirms successful placeholder generation.

## Usage Example

Run directly via Node (it has a shebang for CLI use) or through an npm script:

```bash
node scripts/make-placeholder-web.mjs
```

Typical `package.json` wiring:

```json
{
  "scripts": {
    "build:web:placeholder": "node scripts/make-placeholder-web.mjs",
    "build:web": "cd ../openframe-frontend && npm run export"
  }
}
```

After running, open the generated file to verify:

```bash
open www/index.html
```

Once the native shell (e.g., Capacitor/Cordova project) is validated with the placeholder, replace it with the real bundle by running `npm run build:web` before shipping to production.
