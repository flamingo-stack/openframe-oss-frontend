## ota-env.mjs

Provides a single shared pattern for locating, injecting, and copying the `window.__ENV` script element in `index.html` files, used both by the build-time environment injector (`inject-env.mjs`) and the native shells that deliver over-the-air (OTA) bundles.

The module guarantees one consistent format for the env script across all three use sites—store builds, OTA bundles, and shell-copied pages—validated against fixtures in `fixtures/env-cases.json`.

## Key Components

- **`ENV_SCRIPT_START`** – Regex matching the start of a `window.__ENV` script tag, used to detect if an `index.html` already carries an env.
- **`envScript(env)`** – Builds the `<script>window.__ENV = ...;</script>` string from an env object, serialized as JSON.
- **`insertEnvScript(html, element)`** – Replaces an existing env script in `html`, or inserts `element` right after `<head>` if none exists. Throws if the page has a malformed env script (missing `</script>`) or no `<head>` tag.
- **`assertEnvTarget(stagedHtml)`** – Validates that a bundle's staged HTML is a valid target for env injection: no existing env (`HAS_ENV` error) and has a `<head>` tag (`NO_HEAD` error).
- **`copyEnvScript(builtinHtml, stagedHtml)`** – Extracts the env script from the shell's built-in HTML and copies it into the staged bundle's HTML, throwing `NO_ENV` if the built-in page lacks one.

## Usage Example

```javascript
import { envScript, insertEnvScript, copyEnvScript } from './ota-env.mjs';

// During a store build: inject-env.mjs generates and inserts the env script
const element = envScript({ API_URL: 'https://api.example.com' });
const updatedHtml = insertEnvScript(originalHtml, element);

// In a native shell: copy the built-in env into a staged OTA bundle
const bundledHtml = copyEnvScript(builtinIndexHtml, stagedBundleHtml);
```

Errors from `assertEnvTarget` and `copyEnvScript` are instances of `OtaError` with codes `HAS_ENV`, `NO_HEAD`, or `NO_ENV`, allowing callers to handle invalid bundle states distinctly from generic errors thrown by `insertEnvScript`.
