## ota-env.mjs

Shared utilities for managing the `window.__ENV` script element embedded in `index.html` files, used to inject runtime environment configuration into both standard builds and over-the-air (OTA) bundles. This module defines a single canonical pattern for detecting, inserting, and copying the env script, ensuring consistency between `inject-env.mjs` (build-time injection) and the shell's OTA bundle logic (runtime copying), as validated by `fixtures/env-cases.json`.

## Key Components

- **`ENV_SCRIPT_START`** - Regex matching the opening of a `window.__ENV` script tag; used to detect if an `index.html` already has an env.
- **`envScript(env)`** - Builds the full `<script>window.__ENV = ...;</script>` element string from an env object.
- **`insertEnvScript(html, element)`** - Replaces an existing env script element in `html`, or inserts the new `element` right after `<head>` if none exists. Throws if a malformed (unterminated) env script or missing `<head>` is found.
- **`assertEnvTarget(stagedHtml)`** - Validates that a staged bundle's `index.html` is a safe target for env injection (no existing env, has a `<head>`). Throws an `OtaError` (`HAS_ENV` or `NO_HEAD`) otherwise.
- **`copyEnvScript(builtinHtml, stagedHtml)`** - Extracts the env script element from the shell's built-in `index.html` and copies it into a staged OTA bundle's `index.html`, after validating the target via `assertEnvTarget`. Throws `OtaError('NO_ENV', ...)` if the built-in page lacks an env script.

## Usage Example

```javascript
import { envScript, insertEnvScript, copyEnvScript } from './ota-env.mjs';

// Build-time injection (inject-env.mjs)
const element = envScript({ API_URL: 'https://api.example.com' });
const updatedHtml = insertEnvScript(originalHtml, element);

// Shell copying env into an OTA bundle
const bundledHtml = copyEnvScript(builtinIndexHtml, stagedIndexHtml);
```

See also: [docs/ota.md](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/docs/ota.md) for the OTA bundle workflow.
