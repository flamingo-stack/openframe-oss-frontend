# ota-keygen.mjs

CLI script that generates an EC (prime256v1) key pair for OTA update signing, writing the private key to a file outside any git repository and recording the public key in `apps/mobile/ota/keys.json` under a named slot (`current` or `next`).

## Key Components

- **`inGitWorkTree(dir)`** — Walks up the directory tree (resolving symlinks) checking for a `.git` directory, to prevent the private key from ever being written inside a git work tree (this checkout, a parent checkout, or a nested one).
- **`main()`** — Parses CLI arguments (`slot`, `privateKeyFile`, optional `--keys`), validates the target location is safe, loads/validates the existing `keys.json`, refuses to overwrite an existing slot, generates the EC key pair, writes the private key (mode `0o600`, fails if file exists via `wx` flag), and updates `keys.json` with the new public key. If writing `keys.json` fails, the private key file is deleted to avoid an orphaned, unrecorded private key.
- Relies on shared helpers from `ota-verify.mjs` (`KEY_SLOTS`, `KEYS_PATH`, `keyIdOf`, `parseObject`) and error handling from `ota-error.mjs` (`runCli`).

## Usage Example

```bash
# Generate the "current" signing key, storing the private key outside the repo
node apps/mobile/scripts/ota-keygen.mjs current ~/.secrets/ota-current.pem

# Generate the "next" key and point to a custom keys.json location
node apps/mobile/scripts/ota-keygen.mjs next ~/.secrets/ota-next.pem --keys ./apps/mobile/ota/keys.json
```

On success, the script prints the key ID and file locations:

```text
✓ "current" key a1b2c3d4: public half in apps/mobile/ota/keys.json, private key in /home/user/.secrets/ota-current.pem
```

**Safety notes:**
- Refuses to run if the target private-key path resolves inside any git work tree.
- Refuses to overwrite an existing slot in `keys.json` or an existing private-key file.
- Rolls back the private-key file if `keys.json` cannot be updated, preventing an unregistered private key from being left on disk.

See `docs/ota.md` for the full OTA signing workflow.
