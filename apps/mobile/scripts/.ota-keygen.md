# ota-keygen.mjs

CLI script that generates an EC (prime256v1) signing key pair for OpenFrame's mobile OTA (over-the-air) update mechanism, writing the private key to a secure location outside any git repository and recording the public key in `apps/mobile/ota/keys.json`.

## Key Components

- **`inGitWorkTree(dir)`** — Walks up the directory tree (resolving symlinks) checking for a `.git` directory, to prevent accidentally writing private keys inside any git checkout (including nested or parent repos).
- **`main()`** — Core CLI logic:
  - Parses `slot` (`current` or `next`) and `privateKeyFile` positional args, plus optional `--keys <keys.json>` flag.
  - Validates the target path is outside any git work tree.
  - Refuses to overwrite an existing key for the given slot.
  - Generates an EC key pair (`prime256v1` curve) via `generateKeyPairSync`.
  - Writes the private key with `mode: 0o600` and `flag: 'wx'` (fails if file exists) in PKCS8 PEM format.
  - Updates `keys.json` with the public key (SPKI PEM format), preserving only known slots.
  - Rolls back (deletes the private key file) if writing `keys.json` fails, to avoid an orphaned private key.
- Relies on shared utilities from `ota-error.mjs` (`runCli`) and `ota-verify.mjs` (`KEY_SLOTS`, `KEYS_PATH`, `keyIdOf`, `parseObject`).

## Usage Example

```bash
# Generate the "current" OTA signing key, storing the private key
# outside the repository (e.g., in a secrets directory)
node apps/mobile/scripts/ota-keygen.mjs current ~/secrets/ota-current.pem

# Generate the "next" key rotation using a custom keys.json location
node apps/mobile/scripts/ota-keygen.mjs next ~/secrets/ota-next.pem --keys apps/mobile/ota/keys.json
```

Successful output looks like:

```text
✓ "current" key <key-id>: public half in apps/mobile/ota/keys.json, private key in /home/user/secrets/ota-current.pem
```

**Note:** The script exits with an error if the private key file path resolves inside any git work tree, or if a key already exists for the specified slot. See `docs/ota.md` for the full OTA signing workflow.
