## capacitor.config.ts

Capacitor configuration file for the OpenFrame mobile app shell, defining how the native iOS/Android wrapper loads and interacts with the bundled web frontend (openframe-frontend).

This config governs native plugin behavior (push notifications, keyboard handling, splash screen), security hardening (disabling persistent server-path overrides), and iOS-specific build options (SwiftPM package symlinking for Firebase).

## Key Components

- **`config` (CapacitorConfig)** — the default-exported configuration object consumed by the Capacitor CLI during `npx cap sync`.
- **`webDir: 'www'`** — points to the git-ignored static web bundle produced by `npm run build:web` (or the dev placeholder).
- **`ios.handleApplicationNotifications: false`** — delegates `UNUserNotificationCenter` handling to native Swift code (`NotificationActions.swift`) instead of Capacitor, enabling inline notification actions while still forwarding unhandled responses to the Firebase plugin.
- **`plugins.FirebaseMessaging`** — suppresses automatic foreground push banners on iOS to match Android/FCM behavior.
- **`plugins.Keyboard`** — disables WebView resizing (`resize: 'none'`) so keyboard insets are published via CSS custom properties (`--of-keyboard-inset`) instead of native resizing, keeping iOS/Android behavior consistent.
- **`plugins.SplashScreen`** — keeps the splash screen visible until the frontend explicitly calls `SplashScreen.hide()`, matching the app's background color to avoid flashing.
- **`cordova.preferences.DisableDeploy`** — disables the WebView plugin's persistent server-base-path feature as an XSS-hardening measure.
- **`experimental.ios.spm`** — enables SwiftPM package symlinking to resolve a known Firebase SDK package-identity conflict (requires `@capacitor/cli` 8.4.0+).
- **Commented `server` block** — optional dev-only live-reload configuration pointing at a local frontend dev server.

## Usage Example

```typescript
// Build and sync the native app using this config
// 1. Build the web bundle
// npm run build:web

// 2. Sync native projects with Capacitor
// npx cap sync ios
// npx cap sync android

// 3. (Optional) Enable live-reload during development by uncommenting:
// server: {
//   url: 'http://192.168.1.50:3000',
//   cleartext: true,
// },
// then running:
// npx cap sync ios
```
