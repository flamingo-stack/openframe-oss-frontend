Default Android instrumented test class for the Capacitor-based app, verifying that tests run correctly on a physical device or emulator and that the application context resolves to the expected package name.

## Key Components

- **`ExampleInstrumentedTest`** — Test class annotated with `@RunWith(AndroidJUnit4.class)`, enabling it to run as an Android instrumented test.
- **`useAppContext()`** — Test method that retrieves the target application `Context` via `InstrumentationRegistry` and asserts the app's package name matches `com.getcapacitor.app`.

## Usage Example

This test runs automatically as part of the Android instrumented test suite (executed on a device/emulator, not the JVM). It can be triggered via Gradle or Android Studio:

```bash
./gradlew connectedAndroidTest
```

Example of extending this pattern for additional context-based checks:

```java
@Test
public void useAppContext() throws Exception {
    Context appContext = InstrumentationRegistry.getInstrumentation().getTargetContext();
    assertEquals("com.getcapacitor.app", appContext.getPackageName());
}
```

**Note:** This is boilerplate generated by the Capacitor/Android project template. It serves as a starting point for adding real instrumented tests that validate app behavior in a live Android environment, such as UI interactions, `Context`-dependent logic, or platform API integrations. Update the expected package name if the app's `applicationId` changes in `build.gradle`.
