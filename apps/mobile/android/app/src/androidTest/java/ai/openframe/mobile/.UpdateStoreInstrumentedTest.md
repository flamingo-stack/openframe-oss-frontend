# UpdateStoreInstrumentedTest.java

Android instrumented test suite validating `UpdateStore`'s on-disk persistence and bundle management behavior for the OpenFrame mobile OTA (over-the-air) update system. Tests run against the real filesystem (app cache directory) using `AndroidJUnit4`, verifying state durability across simulated process restarts, bundle installation/replacement, environment mismatch handling, trial rollback counting, and stale bundle cleanup.

## Key Components

- **`UpdateStoreInstrumentedTest`** — the test class, running under `AndroidJUnit4` with a fresh isolated home directory created/destroyed per test (`@Before`/`@After`).
- **`createHome()` / `deleteHome()`** — set up and tear down a unique temporary directory under the app's cache dir for each test, avoiding interference with the real OTA directory.
- **`installBundle(version, envElement)`** — helper that stages a fake bundle (`index.html` + `_next/static/chunk.js`) with a given embedded environment script, then installs it via `store.install(...)`.
- **`session(store)`** — builds an `OtaSession` bound to a built-in version, a fixed environment supplier, and the given `UpdateStore`.
- **`state(active, pending, attempts, bad...)`** — shorthand for constructing `OtaState` instances used in assertions.
- **Test methods** — cover: empty initial state, write/read round-trips (including raw JSON format), corrupted/unreadable state file handling, bundle installation and index retrieval, replacing stale or environment-mismatched bundles, stale directory pruning (`removeStale`), staging area wipe (`wipeStaging`), and multi-launch trial/rollback counting logic.

## Usage Example

This file is run automatically by the Android instrumentation test runner; it is not invoked directly in application code.

```java
// Run via Gradle from the command line
// ./gradlew connectedDebugAndroidTest

@RunWith(AndroidJUnit4.class)
public class UpdateStoreInstrumentedTest {
    @Test
    public void aBundleIsOnThePhoneOnceMovedIntoPlaceWithItsIndex() throws IOException {
        installBundle("1.2.3");
        assertTrue(hasPage("1.2.3"));
        assertTrue(session(store).isUsable("1.2.3"));
    }
}
```

Each test operates in an isolated temp directory under the app's cache dir (never the real `ota` directory), ensuring tests don't interfere with each other or with production OTA state.
