# UpdateStoreInstrumentedTest.java

Instrumented Android test suite verifying `UpdateStore`'s on-disk persistence and bundle management behavior, including state serialization, bundle installation/validation, stale-file cleanup, and OTA trial/rollback semantics across simulated process restarts.

## Key Components

- **`UpdateStoreInstrumentedTest`** - JUnit4 instrumented test class (`AndroidJUnit4` runner) exercising `UpdateStore` in an isolated temp directory per test, under the app's cache directory.
- **`createHome()` / `deleteHome()`** - `@Before`/`@After` lifecycle methods that create and tear down an isolated `home` directory (with an `ota` subdirectory) for each test run.
- **`installBundle(String version[, String envElement])`** - Helper that stages a fake unpacked bundle (`index.html` with an environment script tag plus a static chunk file) and installs it via `store.install(...)`.
- **`session(UpdateStore store)`** - Builds an `OtaSession` bound to the built-in version, a fixed environment supplier, and the given store.
- **`state(active, pending, attempts, bad...)`** - Convenience factory wrapping `OtaState.of(...)`.
- **Test methods** - Cover: empty initial state, write/read round-tripping (including raw JSON format verification), corrupted/unreadable state file handling, bundle installation and index validation, replacing stale or environment-mismatched bundles, stale directory cleanup (`removeStale`), workspace wiping (`wipeStaging`), and multi-launch OTA trial counting/reversion logic.

## Usage Example

```java
@Test
public void aBundleIsOnThePhoneOnceMovedIntoPlaceWithItsIndex() throws IOException {
    assertFalse(hasPage("1.2.3"));

    installBundle("1.2.3");

    assertTrue(hasPage("1.2.3"));
    assertTrue(session(store).isUsable("1.2.3"));
    assertEquals(new File(ota, "bundles/1.2.3"), store.bundleDir("1.2.3"));
}
```

Run via Gradle instrumented tests:

```bash
./gradlew connectedDebugAndroidTest
```

This executes against a connected device/emulator since the suite depends on `InstrumentationRegistry` to obtain the app's real cache directory.
