# SharedCases.java

A shared test-case runner for the OTA (over-the-air update) subsystem, designed to execute identical fixture-driven test suites from both JVM unit tests (reading classpath resources) and on-device Android instrumentation tests (reading assets). This avoids duplicating test logic across environments while exercising the same security provider and runtime differences.

## Key Components

- **`SharedCases`** – main class that drives all test suites; constructed with a `Fixtures` abstraction (for loading fixture files) and a working directory for temp files.
- **`Fixtures` interface** – abstraction for opening fixture files by path, implemented differently per platform (resource stream vs. asset stream).
- **`manifestCases()`** – validates `Manifest.verify` against JSON fixtures covering valid payloads and expected `OtaError` codes.
- **`bundleCases()`** – validates `BundleReader` behavior for both file-based (`readVerified`) and streaming (`read`) paths, including a `Trickle` input stream that simulates slow, chunked reads.
- **`envCases()`** – validates `EnvCopy.copy` HTML merging logic against builtin/staged fixtures.
- **`decisionCases()`** – validates `Decision.decide` update-rollout logic given shell/bundle state and incoming payload metadata.
- **`keyIds()`** – validates that fixture public keys produce the expected `OtaKeys.keyId` and are correctly recognized by `OtaKeys.of`.
- **`Trickle`** – private `FilterInputStream` that caps reads per call to simulate slow I/O.
- **`HashingSink`** – private `BundleReader.Sink` implementation that hashes streamed file contents and records size/SHA-256 for comparison against expected results.

## Usage Example

```java
// JVM test
public class ManifestJvmTest {
    @Test
    public void manifest() throws Exception {
        SharedCases cases = new SharedCases(
            path -> getClass().getResourceAsStream("/fixtures/" + path),
            tempFolder.getRoot()
        );
        cases.manifestCases();
        cases.bundleCases();
        cases.envCases();
        cases.decisionCases();
        cases.keyIds();
    }
}

// Android instrumentation test
public class ManifestDeviceTest {
    @Test
    public void manifest() throws Exception {
        SharedCases cases = new SharedCases(
            path -> context.getAssets().open("fixtures/" + path),
            context.getCacheDir()
        );
        cases.manifestCases();
    }
}
```

Each case method reads a corresponding `*-cases.json` fixture file, runs the production code under test, compares actual vs. expected outcomes, and fails via JUnit assertions if any case mismatches or if no cases were loaded.
