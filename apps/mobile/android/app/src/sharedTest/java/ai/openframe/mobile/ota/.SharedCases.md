# SharedCases.java

A shared JUnit-assertion-based test runner for OTA (over-the-air update) logic, designed to execute identical fixture-driven test cases from both JVM unit tests and on-device Android instrumented tests. It abstracts fixture loading via the `Fixtures` interface so the same test logic can read resources (JVM) or assets (device) while relying on the platform's native security provider and runtime.

## Key Components

- **`SharedCases`** — Main test runner class, constructed with a `Fixtures` loader and a working directory for temp files.
- **`Fixtures`** (interface) — Abstraction for opening fixture files by path, implemented differently per platform (resources vs. assets).
- **`manifestCases()`** — Validates OTA manifest signature verification (`Manifest.verify`) against expected payloads/errors, driven by `manifest-cases.json` and `fixture-keys.json`.
- **`bundleCases()`** — Verifies bundle (tar.xz) reading and checksum validation via `BundleReader`, testing both whole-file (`downloadedOutcome`) and streaming/trickle-read (`readerOutcome`) paths.
- **`envCases()`** — Tests `EnvCopy.copy` HTML environment-merging logic against `env-cases.json`.
- **`decisionCases()`** — Validates update decision logic (`Decision.decide`) given shell/bundle/payload state combinations from `decision-cases.json`.
- **`keyIds()`** — Confirms key ID derivation (`OtaKeys.keyId`) matches fixture-declared IDs.
- **`Trickle`** (inner class) — A `FilterInputStream` that limits reads to a fixed byte count, simulating slow/chunked I/O.
- **`HashingSink`** (inner class) — Implements `BundleReader.Sink` to compute SHA-256 hashes and track byte counts per extracted file for verification.

## Usage Example

```java
// JVM test subclass
public class ManifestJvmTest {
    private final SharedCases shared = new SharedCases(
        path -> getClass().getResourceAsStream("/fixtures/" + path),
        new File(System.getProperty("java.io.tmpdir"))
    );

    @Test
    public void manifestFixtures() throws Exception {
        shared.manifestCases();
    }

    @Test
    public void bundleFixtures() throws Exception {
        shared.bundleCases();
    }
}
```

Each method loads a JSON fixture file (e.g., `manifest-cases.json`), iterates through declared test cases, computes an actual outcome, compares it to the expected outcome, and aggregates mismatches before asserting all cases passed via `assertAllPassed`.
