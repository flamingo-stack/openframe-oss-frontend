# StrictFormatTest.java

Unit test suite validating strict, RFC-compliant parsing and format enforcement across the OTA (over-the-air update) subsystem's core utilities: JSON parsing, Base64 decoding, semantic version validation, DER signature encoding, OTA error classification, and safe file path validation for bundle extraction.

## Key Components

- **`jsonKeepsItsOwnTypes()`** — Verifies `Json.parse`/`Json.parseObject` correctly preserve types (strings with escapes/unicode, numbers, booleans, null, arrays, objects).
- **`jsonRefusesEverythingRfc8259DoesNotWrite()`** — Exhaustively tests rejection of malformed JSON inputs (trailing commas, comments, non-UTF8 BOM, invalid numbers, control characters, etc.) per RFC 8259.
- **`jsonRefusesBytesThatAreNotUtf8()`** — Confirms invalid UTF-8 byte sequences (continuation bytes, overlong encodings, surrogate pairs, UTF-16) are rejected.
- **`jsonNestsToItsBoundAndNoDeeper()`** / **`aManifestOfAMillionBracketsIsRefusedAndOverflowsNoStack()`** — Tests `Json.MAX_DEPTH` enforcement and stack-safety against deeply nested/malicious input via `Manifest.verify`.
- **`aNumberIsAPositiveIntegerOnlyWhenWrittenAsOne()`** — Validates `Json.Num.positiveInteger()` strictness (rejects decimals, exponents, negatives, overflow).
- **`base64DecodesWhatAnEncoderWrites()`** / **`base64RefusesEverythingElse()`** — Tests `Base64Strict.decode` against valid encodings and malformed variants (bad padding, whitespace, non-standard alphabets).
- **`aVersionIsThreePlainNumbers()`** / **`versionsCompareAsNumbers()`** — Validates `Version.isValid` and `Version.compare` semantics for strict `major.minor.patch` numeric versioning.
- **`onlyTheOneDerEncodingOfASignatureIsTaken()`** — Tests `Manifest.isStrictDer` to ensure only canonical DER-encoded ECDSA signatures are accepted (rejecting negative integers, extra padding, long-form lengths).
- **`aKeyThatIsNotA91ByteP256SpkiIsNotHeld()`** — Confirms `OtaKeys.of` rejects keys that aren't valid 91-byte P-256 SPKI format.
- **`onlyARefusalOfTheSignedBytesMarksAReleaseBad()`** — Validates `OtaError.Code.isContentRefusal()` classification logic.
- **`aBundlePathStaysInsideItsDirectory()`** — Tests `BundleReader.isSafePath` against path traversal attacks and unsafe filenames (null bytes, backslashes, UNC paths, length limits).

## Usage Example

```java
// Run via standard JUnit test runner (Maven/Gradle)
// mvn test -Dtest=StrictFormatTest

// Example of the pattern used throughout: asserting malformed input is rejected
private static void assertMalformed(String what, byte[] json) {
    try {
        Json.parse(json);
        fail(what + " was taken as JSON");
    } catch (Json.Malformed expected) {
        // expected rejection
    }
}
```

This test class has no public API of its own; it exercises internal `ai.openframe.mobile.ota` classes (`Json`, `Base64Strict`, `Version`, `Manifest`, `OtaKeys`, `OtaError`, `BundleReader`) to guarantee strict format compliance required for secure OTA update verification.
