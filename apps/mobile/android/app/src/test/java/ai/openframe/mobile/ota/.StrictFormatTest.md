# StrictFormatTest.java

Unit test suite validating strict, RFC-compliant parsing behavior for the OTA (over-the-air update) subsystem's data formats, including JSON parsing, Base64 decoding, semantic version validation, DER signature encoding, OTA error classification, and safe bundle path resolution.

## Key Components

- **`jsonKeepsItsOwnTypes()`** — Verifies `Json.parse`/`parseObject` correctly preserve types (strings with escapes, numbers, booleans, null, nested arrays/objects).
- **`jsonRefusesEverythingRfc8259DoesNotWrite()`** — Asserts malformed JSON inputs (trailing commas, comments, non-standard literals, bad escapes, unquoted keys) are rejected via `Json.Malformed`.
- **`jsonRefusesBytesThatAreNotUtf8()`** — Confirms invalid UTF-8 byte sequences (continuation bytes, overlong encodings, encoded surrogates, UTF-16) are rejected.
- **`jsonNestsToItsBoundAndNoDeeper()`** / **`aManifestOfAMillionBracketsIsRefusedAndOverflowsNoStack()`** — Tests `Json.MAX_DEPTH` enforcement and stack-safety against pathological nesting via `Manifest.verify`.
- **`aNumberIsAPositiveIntegerOnlyWhenWrittenAsOne()`** — Validates `Json.Num.positiveInteger()` only accepts canonical positive integer literals.
- **`base64DecodesWhatAnEncoderWrites()`** / **`base64RefusesEverythingElse()`** — Round-trip and strict-rejection tests for `Base64Strict.decode`.
- **`aVersionIsThreePlainNumbers()`** / **`versionsCompareAsNumbers()`** — Validates `Version.isValid` and `Version.compare` semantics for semantic version strings.
- **`onlyTheOneDerEncodingOfASignatureIsTaken()`** — Exercises `Manifest.isStrictDer` against canonical and malformed DER-encoded ECDSA signatures.
- **`aKeyThatIsNotA91ByteP256SpkiIsNotHeld()`** — Confirms `OtaKeys.of` rejects improperly sized public keys.
- **`onlyARefusalOfTheSignedBytesMarksAReleaseBad()`** — Validates `OtaError.isContentRefusal()` classification across all `OtaError.Code` values.
- **`aBundlePathStaysInsideItsDirectory()`** — Tests `BundleReader.isSafePath` against path traversal, illegal characters, and length limits.

## Usage Example

Run via the standard JUnit test runner (e.g., Gradle/Maven):

```java
// Example: directly exercising the JSON parser under test
byte[] input = "{\"ok\":true}".getBytes(StandardCharsets.UTF_8);
Map<String, Object> result = Json.parseObject(input);
assertSame(Boolean.TRUE, result.get("ok"));

// Example: validating a malformed input is rejected
try {
    Json.parse("{\"a\":1,}".getBytes(StandardCharsets.UTF_8));
    fail("trailing comma should be rejected");
} catch (Json.Malformed expected) {
    // expected
}
```

These tests act as executable specifications for `Json`, `Base64Strict`, `Version`, `Manifest`, `OtaKeys`, `OtaError`, and `BundleReader`, ensuring the OTA update pipeline rejects any input that deviates from strict format expectations, closing off parser-differential and path-traversal attack surfaces.
