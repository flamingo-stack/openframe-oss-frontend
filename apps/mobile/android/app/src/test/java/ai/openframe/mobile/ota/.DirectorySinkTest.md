# DirectorySinkTest.java

JUnit test suite validating `DirectorySink`'s behavior as a `BundleReader` destination that unpacks OTA (over-the-air) update bundles safely to the filesystem, including protection against path traversal and malicious archive contents.

## Key Components

- **`aBundleUnpacksToTheFilesItsCaseLists()`** — Unpacks a reference bundle fixture and verifies every extracted file matches expected size and SHA-256 checksum from a JSON test case manifest, and confirms no extra files are written.
- **`theBuiltinEnvGoesIntoTheUnpackedRootPage()`** — Verifies that `EnvCopy` correctly injects a `window.__ENV` script element into the unpacked `index.html` page without altering the rest of the content.
- **`aRefusedBundleWritesNothingOutsideItsDirectory()`** — Iterates over a set of malicious bundle fixtures (path traversal, symlinks, hard links, directory/file conflicts) and asserts each is rejected via `OtaError.isContentRefusal()`, with no files written outside the target directory.
- **`aSinkClosedHalfwayThroughAFileReleasesIt()`** — Uses `/dev/fd` to confirm `DirectorySink.close()` releases the underlying file descriptor even if a write is interrupted mid-file, and that `close()` is idempotent.
- **Helper utilities** — `fixture()` loads test resources, `read()` drains an `InputStream` to bytes, `filesUnder()`/`collect()` recursively lists files in a directory for structural assertions.

## Usage Example

```java
// Typical pattern used across tests: unpack a bundle fixture into a temp directory
// and validate its output via DirectorySink + BundleReader.
File unpacked = disk.newFolder("staging", "1.2.3");
byte[] index;
try (InputStream in = fixture("bundles/typical.tar.xz");
     DirectorySink sink = new DirectorySink(unpacked)) {
    index = BundleReader.read(in, sink);
}

// Verify extracted file integrity
byte[] onDisk = read(new FileInputStream(new File(unpacked, "app.js")));
assertEquals(expectedSha256, Bytes.hex(Bytes.sha256().digest(onDisk)));
```

Relies on JUnit's `TemporaryFolder` rule for isolated filesystem state and bundled test fixtures (`.tar.xz` archives, `bundle-cases.json`) located as classpath resources.
