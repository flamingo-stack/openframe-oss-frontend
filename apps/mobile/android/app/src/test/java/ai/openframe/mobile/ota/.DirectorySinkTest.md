# DirectorySinkTest.java

JUnit test suite validating `DirectorySink`, the component responsible for safely unpacking OTA (over-the-air) update bundles to disk. Tests cover correct file extraction, path-traversal/security refusals, environment variable injection into the root page, and proper file handle lifecycle management.

## Key Components

- **`DirectorySinkTest`** — Test class using a `TemporaryFolder` JUnit rule to sandbox filesystem operations.
- **`aBundleUnpacksToTheFilesItsCaseLists()`** — Verifies a valid `.tar.xz` bundle extracts exactly the files described in a JSON test-case manifest, checking size and SHA-256 integrity, and confirms no extraneous files are written.
- **`theBuiltinEnvGoesIntoTheUnpackedRootPage()`** — Confirms `EnvCopy` correctly injects a `window.__ENV` script tag into the extracted `index.html`'s `<head>`, leaving the rest of the document unchanged.
- **`aRefusedBundleWritesNothingOutsideItsDirectory()`** — Iterates over malicious bundle fixtures (path traversal, absolute paths, symlinks, hard links, directory/file conflicts) ensuring `BundleReader` throws an `OtaError` content refusal and no files escape the target directory.
- **`aSinkClosedHalfwayThroughAFileReleasesIt()`** — Uses `/dev/fd` open file counting to confirm `DirectorySink.close()` releases file descriptors even when closed mid-write, and that `close()` is idempotent.
- **Helper utilities**: `fixture()` loads test resources, `read()` drains an `InputStream` to bytes, `filesUnder()`/`collect()` recursively list extracted files, `openFiles()` counts open file descriptors via `/dev/fd`.

## Usage Example

Run via standard JUnit execution (e.g., Gradle/Maven test task):

```bash
./gradlew test --tests "ai.openframe.mobile.ota.DirectorySinkTest"
```

Typical pattern exercised by the tests:

```java
File unpacked = new File(workDir, "1.2.3");
try (InputStream in = fixture("bundles/typical.tar.xz");
     DirectorySink sink = new DirectorySink(unpacked)) {
    byte[] index = BundleReader.read(in, sink);
    // index.html bytes and extracted files are now available in `unpacked`
}
```

Security-focused bundles (e.g., `symlink.tar.xz`, `name-parent.tar.xz`) are expected to raise `OtaError` with `isContentRefusal() == true`, ensuring malicious archives never write outside the designated directory.
