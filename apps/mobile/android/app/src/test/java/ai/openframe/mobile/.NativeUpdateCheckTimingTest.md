# NativeUpdateCheckTimingTest.java

Unit test suite validating the timing and coordination logic of `CheckSchedule`, which governs when the Android shell checks for app updates, and `UpdateChecker.manifestUrl`, which builds the update manifest URL from a configured shared host.

## Key Components

- **`checkedAt(startedAt, finishedAt)`** — Test helper that creates a `CheckSchedule`, starts a check, and finishes it at given timestamps, returning the resulting schedule.
- **Timing tests** — Verify that the first check on a fresh schedule always starts, and that subsequent checks respect a one-hour cooldown measured from the start (not end) of the previous check.
- **Page vs. shell check coordination** — Tests confirm that page-initiated checks (`ask(true, ...)`) are rate-limited to once per minute, independent of shell-initiated checks, and that a check already in-flight is "joined" rather than restarted (`Asked.JOINED`).
- **Data saver / download gating** — Tests around `mayDownload(dataSaver)` verify that under data saver mode, shell-only checks skip downloads while page-initiated checks (user actively waiting on an Update Required screen) are allowed to download, including edge cases where a page joins a check before or after the download decision is made.
- **`UpdateChecker.manifestUrl` validation** — Tests ensure the manifest URL is only derived from a bare HTTPS origin (no path, query, fragment, credentials, or backslashes) and that it correctly appends the download endpoint path/query regardless of trailing slashes or custom ports.

## Usage Example

```java
// Verifying a check started an hour ago triggers a new check
CheckSchedule schedule = checkedAt(NOW - HOUR, NOW - HOUR + 5_000);
assertEquals(Asked.STARTED, schedule.ask(false, NOW));

// Verifying manifest URL construction from a shared host
String url = UpdateChecker.manifestUrl("https://openframe.ai/");
assertEquals("https://openframe.ai/v0/api/assets/download?agent=mobile&file=mobile.json", url);
```

Run via the standard JUnit test runner as part of the mobile module's test suite:

```bash
./gradlew test --tests "ai.openframe.mobile.NativeUpdateCheckTimingTest"
```
