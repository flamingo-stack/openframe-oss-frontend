# NativeUpdateCheckTimingTest.java

Unit test suite verifying the timing and coordination logic of `CheckSchedule` and `UpdateChecker`, two components that manage update-check scheduling and manifest URL construction for the OpenFrame mobile app's native update mechanism.

The tests validate throttling behavior (checks not repeated too frequently), coalescing concurrent requests ("joining" an in-flight check), data-saver-aware download gating, and strict parsing rules for the manifest URL host.

## Key Components

- **`checkedAt(startedAt, finishedAt)`** — private helper that creates a `CheckSchedule`, starts a check, and finishes it at given timestamps, returning the resulting schedule for further assertions.
- **Timing tests** — verify that:
  - The first check always runs (`theFirstActivationOfAProcessChecks`).
  - Shell checks throttle to once per hour, measured from check start, not end (`aLaterActivationChecksOnceTheLastCheckStartedAnHourAgo`).
  - Page checks throttle to once per minute (`thePagesCheckRunsUnlessOneFinishedWithinTheLastMinute`).
  - Concurrent asks join an in-flight check instead of starting a new one (`aCheckAskedForWhileOneRunsJoinsIt`).
- **Data Saver tests** — verify `mayDownload()` behavior differs for shell-initiated vs. page-initiated checks under data saver constraints, including edge cases where downloads are "left" and later resumed by a different caller.
- **`UpdateChecker.manifestUrl(host)` tests** — validate that only well-formed `https://` bare-origin hosts (no userinfo, path, query, or fragment) produce a valid manifest URL pointing to `/v0/api/assets/download?agent=mobile&file=mobile.json`, with ports preserved and trailing slashes normalized.

## Usage Example

```java
// Run via standard JUnit 4 test runner (Gradle/Maven)
// Example: verifying throttling behavior directly
CheckSchedule schedule = new CheckSchedule();
assertEquals(Asked.STARTED, schedule.ask(false, 0L));
schedule.finish(5_000L);

// A later ask within the hour returns ANSWERED, not STARTED
assertEquals(Asked.ANSWERED, schedule.ask(false, 10_000L));
```

```java
// Verifying manifest URL construction
String url = UpdateChecker.manifestUrl("https://openframe.ai");
assertEquals(
    "https://openframe.ai/v0/api/assets/download?agent=mobile&file=mobile.json",
    url
);
```
