# BundleReaderTest.java

Unit tests for `BundleReader`, validating the OTA (over-the-air) bundle extraction logic that decodes `.tar.xz` archives while enforcing size and SHA-256 signature verification before processing any file contents.

## Key Components

- **`UNTOUCHED` sink** — a `BundleReader.Sink` stub that fails the test if any file is decoded, used to assert refusals happen before extraction begins.
- **`DISCARD` sink** — a no-op sink used when the test only cares about read success/failure, not file contents.
- **`downloaded(byte[])`** — writes test bytes to a temporary file to simulate a downloaded bundle artifact.
- **`refusalOf(...)`** — helper asserting that `BundleReader.readVerified` throws `OtaError` and returns its error code.
- **`typicalBundle()`** — loads a real `.tar.xz` test fixture from resources for use across tests.
- **Test cases** covering:
  - Sink I/O failures surface as `IOException`, not `OtaError` (disk-full scenario).
  - Underlying stream read failures propagate as `IOException`, not XZ decode refusals.
  - Truncated archives are rejected with `OtaError.Code.XZ`.
  - Size/hash mismatches are rejected with `OtaError.Code.SIZE` / `OtaError.Code.SHA256`, with size checked before hash.
  - Verified reads only decode content once size and hash match the signed values.
  - The returned root index/page is correctly sized and contains the expected env copy target.

## Usage Example

```java
// Verifying a downloaded OTA bundle before extraction
byte[] bundle = loadBundleBytes();
String sha256 = Bytes.hex(Bytes.sha256().digest(bundle));
File archive = writeToTempFile(bundle);

byte[] rootIndex = BundleReader.readVerified(archive, bundle.length, sha256, new BundleReader.Sink() {
    @Override
    public void begin(String path, long size) {
        // prepare to receive file `path`
    }

    @Override
    public void write(byte[] buffer, int offset, int length) {
        // append bytes to the current file
    }

    @Override
    public void end() {
        // finalize current file
    }
});
```

These tests ensure that integrity checks (`SIZE`, `SHA256`) always precede extraction, and that infrastructure errors (disk/stream I/O) are never misreported as archive-format refusals (`XZ`).
