# BundleReaderTest.java

Unit test suite for `BundleReader`, validating secure extraction of OTA (over-the-air) update bundles packaged as `.tar.xz` archives. Tests cover integrity verification (size/SHA-256 hash checks), error classification (I/O failures vs. format refusals), and sink-based streaming extraction semantics.

## Key Components

- **`UNTOUCHED` / `DISCARD`** — Test `BundleReader.Sink` implementations; `UNTOUCHED` fails if any file is decoded (for refusal tests), `DISCARD` silently consumes extracted content.
- **`downloaded(byte[])`** — Helper writing bytes to a temporary file via JUnit's `TemporaryFolder` rule, simulating a downloaded archive on disk.
- **`refusalOf(File, long, String)`** — Helper asserting `BundleReader.readVerified` throws `OtaError` and returning its `OtaError.Code`.
- **`typicalBundle()`** — Loads a fixture archive (`/bundles/typical.tar.xz`) from test resources into memory.
- **Test methods** covering:
  - Sink I/O failures propagate as `IOException`, not `OtaError`.
  - Truncated/corrupted input streams produce `IOException` or `OtaError.Code.XZ` depending on failure point.
  - Size and hash mismatches produce `OtaError.Code.SIZE` / `OtaError.Code.SHA256`, with size checked before hash.
  - Verified reads only decode content once size and SHA-256 match.
  - The returned index/root page byte array is validated via `EnvCopy.assertTarget`.

## Usage Example

```java
// Pattern used throughout: verify an archive and assert the refusal reason
File archive = downloaded(bundleBytes);
OtaError.Code code = refusalOf(archive, wrongSize, correctSha256);
assertEquals(OtaError.Code.SIZE, code);

// Successfully reading a verified bundle
byte[] index = BundleReader.readVerified(archive, bundle.length, sha256, new BundleReader.Sink() {
    @Override public void begin(String path, long size) { /* track entry */ }
    @Override public void write(byte[] buffer, int offset, int length) { /* consume bytes */ }
    @Override public void end() { /* finalize entry */ }
});
```

This test class relies on fixtures under `src/test/resources/bundles/typical.tar.xz` and companion classes `BundleReader`, `OtaError`, `Bytes`, and `EnvCopy`.
