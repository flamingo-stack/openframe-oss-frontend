# BundleRemovalTest.java

Unit test suite verifying the `BundleRemoval` utility's logic for safely and incrementally deleting OTA (over-the-air) update bundle directories, prioritizing removal of the root `index.html` page first to prevent serving a partially-deleted bundle.

## Key Components

- **`bundle()`** — Test helper that builds a representative bundle directory tree (`1.2.3/`) containing files like `index.html`, nested assets, and route pages (e.g., `devices/index.html`).
- **`write(File)`** — Helper that creates parent directories and writes a single-byte placeholder file.
- **`theRootPageIsDeletedBeforeAnythingElse()`** — Confirms `BundleRemoval.order()` places `index.html` first and the bundle directory itself last.
- **`everyFileAndDirectoryIsDeletedOnceAndADirectoryAfterWhatItHolds()`** — Validates the deletion order is a valid topological ordering (children removed before parents, no duplicates).
- **`aRemovalStoppedAfterItsFirstStepHasTakenTheRootPage()`** — Ensures that deleting only the first ordered file removes `index.html` immediately (making the bundle unservable) while leaving the rest intact for a later full removal via `BundleRemoval.remove()`.
- **`aBundleIsRemovedWhole()`** — Confirms `BundleRemoval.remove()` deletes an entire bundle directory without affecting sibling version directories.
- **`aDirectoryWithoutARootPageOrThatIsNotThereIsRemovedAllTheSame()`** — Verifies removal works for bundles missing an `index.html`, and that removing a non-existent directory is a no-op.

## Usage Example

```java
// Run via standard JUnit test execution
@Test
public void aBundleIsRemovedWhole() throws IOException {
    File bundle = bundle();
    BundleRemoval.remove(bundle);
    assertFalse(bundle.exists());
}
```

This test class exercises the `BundleRemoval` class's `order(File)` and `remove(File)` static methods, which are responsible for safely tearing down OTA mobile app bundles on disk, ensuring the root page is invalidated first for atomic-like rollback semantics.
