# BundleRemovalTest.java

JUnit test suite verifying the behavior of `BundleRemoval`, a utility responsible for safely deleting OTA (over-the-air) update bundle directories on disk. The tests validate the deletion ordering strategy (ensuring the root `index.html` page is removed first, interruptible across multiple steps) and the recursive, whole-bundle removal logic.

## Key Components

- **`BundleRemovalTest`** — Test class using a JUnit `TemporaryFolder` rule to create isolated file structures for each test.
- **`write(File)`** — Static helper that creates parent directories and writes a single-byte placeholder file.
- **`bundle()`** — Builds a sample bundle directory tree (`1.2.3/`) containing files/directories that sort both before and after `index.html`, used to validate ordering edge cases.
- **Test methods:**
  - `theRootPageIsDeletedBeforeAnythingElse` — Confirms `BundleRemoval.order()` places `index.html` first and the bundle directory itself last.
  - `everyFileAndDirectoryIsDeletedOnceAndADirectoryAfterWhatItHolds` — Ensures the removal order is a valid dependency order (children before parents, no duplicates).
  - `aRemovalStoppedAfterItsFirstStepHasTakenTheRootPage` — Verifies a partial/interrupted removal (deleting only the first ordered item) still leaves a resumable state, and a subsequent `BundleRemoval.remove()` completes cleanup.
  - `aBundleIsRemovedWhole` — Confirms `BundleRemoval.remove()` deletes the entire target bundle without affecting sibling directories.
  - `aDirectoryWithoutARootPageOrThatIsNotThereIsRemovedAllTheSame` — Confirms removal works for bundles lacking an `index.html` and is a no-op (no exception) for non-existent paths.

## Usage Example

```java
// Example of the API under test (BundleRemoval), as exercised by this test class
File bundleDir = new File("/data/ota/1.2.3");

// Get deletion order: index.html first, directory itself last
List<File> deletionOrder = BundleRemoval.order(bundleDir);

// Remove an entire bundle directory tree safely
BundleRemoval.remove(bundleDir);

// Safe no-op if the directory doesn't exist
BundleRemoval.remove(new File("/data/ota/does-not-exist"));
```

Run tests with standard JUnit tooling, e.g., via Gradle: `./gradlew test --tests "ai.openframe.mobile.ota.BundleRemovalTest"`.
