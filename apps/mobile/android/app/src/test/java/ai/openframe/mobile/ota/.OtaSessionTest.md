# OtaSessionTest.java

Unit test suite for `OtaSession`, covering the Over-The-Air (OTA) bundle lifecycle used by the OpenFrame mobile app to download, validate, boot, and roll back JavaScript/HTML bundles served through a WebView. Tests exercise boot sequencing, Activity recreation semantics, environment-matching validation, trial-attempt accounting, and automatic rollback of bad bundles.

## Key Components

- **`OtaSessionTest`** — JUnit 4 test class exercising `OtaSession` behavior end-to-end using an in-memory fake store.
- **`MemoryStore`** — Test double implementing `OtaSession.Store`, simulating persisted OTA state (`OtaState`) and on-disk bundle "index.html" pages, with configurable failure modes (`unreadable`, `unwritable`).
- **Helper factories**:
  - `ascii(String)` — Encodes text as US-ASCII bytes.
  - `pageWith(String envElement)` — Builds a fake HTML page embedding a `window.__ENV` script tag.
  - `session(MemoryStore)` — Constructs an `OtaSession` wired to a fixed built-in version and environment supplier.
  - `state(...)` — Builds an `OtaState` with active/pending versions, attempt count, and bad-version list.
- **Test scenarios** cover: cold boot vs. Activity recreation vs. new-process restoration, trial attempt counting and auto-revert after repeated failures, bundle/environment mismatch detection (`isUsable`), dropped/stale bundles, I/O failure resilience, and `notifyReady()` confirmation flow.

## Usage Example

```java
// Example pattern used throughout the test suite
MemoryStore store = new MemoryStore(state("1.2.3", "1.2.4", 0), "1.2.3", "1.2.4");
OtaSession process = session(store);

OtaSession.Booted booted = process.boot();
assertEquals("1.2.4", booted.version);
assertTrue(booted.trial);

// Confirm the trial bundle succeeded
assertTrue(process.notifyReady());
assertEquals(state("1.2.4", null, 0), store.stored);
```

Run via standard JUnit 4 tooling:

```bash
./gradlew test --tests "ai.openframe.mobile.ota.OtaSessionTest"
```
