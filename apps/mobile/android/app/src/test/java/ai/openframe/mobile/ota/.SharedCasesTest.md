JUnit test class that runs the shared OTA (Over-The-Air update) test suite on the JVM, using `SunEC` as the signature verifier. It serves as the JVM counterpart to `SharedCasesInstrumentedTest`, which executes identical test cases on a physical/emulated Android device using `Conscrypt`, ensuring consistent OTA verification behavior across both environments.

## Key Components

- **`SharedCasesTest`** — JUnit test class hosting shared OTA verification test cases.
- **`disk`** (`TemporaryFolder` rule) — Provides a temporary directory for test fixtures and generated files, automatically cleaned up after each test.
- **`cases`** (`SharedCases`) — Delegate instance holding the actual test logic, initialized with a resource-loader function and the temp directory.
- **`readFixturesFromResources()`** — `@Before` setup method that constructs `SharedCases`, wiring it to load fixtures from classpath resources (prefixed with `/`) and write to the temp folder.
- **Test methods** — Each delegates to a corresponding method on `SharedCases`:
  - `manifestCases()` — Validates OTA manifest parsing/handling.
  - `bundleCases()` — Validates OTA bundle processing.
  - `envCases()` — Validates environment-specific logic.
  - `decisionCases()` — Validates update decision logic (e.g., apply/skip update).
  - `keyIds()` — Validates signing key identification.

## Usage Example

```java
// Run via standard JUnit tooling, e.g.:
// ./gradlew test --tests "ai.openframe.mobile.ota.SharedCasesTest"

// The test wires fixture loading like this internally:
cases = new SharedCases(
    path -> SharedCasesTest.class.getResourceAsStream("/" + path),
    disk.getRoot()
);

// Each @Test method simply delegates to shared logic:
@Test
public void manifestCases() throws Exception {
    cases.manifestCases();
}
```

This class should be kept in sync with `SharedCasesInstrumentedTest` so that both JVM (`SunEC`) and Android (`Conscrypt`) signature providers are validated against the same fixture-driven test cases, catching provider-specific discrepancies early.
