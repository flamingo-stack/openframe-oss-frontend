JUnit test class that runs the shared OTA (over-the-air update) test suite on the JVM, using Java's built-in `SunEC` signature verifier. It loads test fixtures from classpath resources and delegates actual test logic to the shared `SharedCases` helper, ensuring consistent verification behavior between this JVM-based test and its Android counterpart (`SharedCasesInstrumentedTest`, which runs on Conscrypt).

## Key Components

- **`SharedCasesTest`** - JUnit test class that wires up `SharedCases` with a JVM-appropriate resource loader and temporary directory.
- **`disk`** (`TemporaryFolder` rule) - Provides an isolated, auto-cleaned temporary directory for each test run, used for writing/reading OTA artifacts during tests.
- **`cases`** (`SharedCases`) - Shared, platform-agnostic test case implementation reused across JVM and Android test targets.
- **`readFixturesFromResources()`** - `@Before` setup method that initializes `cases` with a resource-loading function (reading from the classpath via `getResourceAsStream`) and the temp folder's root directory.
- **Test methods** - `manifestCases()`, `bundleCases()`, `envCases()`, `decisionCases()`, `keyIds()` - each delegates to the corresponding method on `SharedCases` to validate manifest parsing, bundle handling, environment resolution, update decision logic, and key ID verification respectively.

## Usage Example

This class is run automatically by the standard JUnit test runner (e.g., via Gradle/Maven):

```java
// Run via build tool:
// ./gradlew test --tests "ai.openframe.mobile.ota.SharedCasesTest"

// Conceptually, each test follows this pattern:
public class SharedCasesTest {
    @Rule
    public final TemporaryFolder disk = new TemporaryFolder();

    private SharedCases cases;

    @Before
    public void setUp() {
        cases = new SharedCases(
            path -> SharedCasesTest.class.getResourceAsStream("/" + path),
            disk.getRoot()
        );
    }

    @Test
    public void manifestCases() throws Exception {
        cases.manifestCases(); // validates OTA manifest parsing using SunEC verifier
    }
}
```

For the Android-equivalent execution path (Conscrypt), see `SharedCasesInstrumentedTest` in the same module.
