# OtaStateTest.java

Unit test suite for `OtaState`, the core state machine governing over-the-air (OTA) bundle updates in the OpenFrame mobile app. It verifies boot resolution logic (which bundle version loads), trial/rollback semantics, bad-version tracking, stale directory cleanup, and JSON serialization of persisted OTA state.

## Key Components

- **`state(active, pending, attempts, bad...)`** — Test helper that builds an `OtaState` via `OtaState.of(...)`.
- **Boot resolution tests** — Verify `OtaState.resolveBoot` correctly selects between the built-in, active, or pending bundle version, including trial counting and reverting a bundle after `OtaState.MAX_TRIAL_ATTEMPTS` failed launches.
- **Store update tests** — Confirm bundles at or below a newer built-in version are discarded and not probed on disk (`Usable` functional interface).
- **State transition tests** — Cover `applyReady`, `applyDrop`, `applyNothing`, and `applyDownloaded`, validating how confirmations, drops, and new downloads mutate state (including identity (`assertSame`) checks for no-op transitions).
- **`markBad`** — Tests the capped history (20 most recent) of versions marked bad, with re-marking moving an entry to most recent.
- **`staleDirectories`** — Tests determining which on-disk bundle directories can be deleted, preserving active/pending/currently-booted versions.
- **Serialization tests** — Round-trip (`toJson`/`parse`) fidelity and documented JSON schema shape, plus a large set of malformed/invalid JSON inputs that must fall back to `OtaState.EMPTY`.

## Usage Example

```java
// Run via standard JUnit4 test runner
OtaState before = OtaState.of("1.2.3", "1.2.4", 0, Arrays.asList());
OtaState.Boot boot = OtaState.resolveBoot(before, "1.2.0", version -> true);

assertEquals("1.2.4", boot.version);
assertTrue(boot.trial);
```

Execute the suite with Gradle/Maven as part of the mobile module's standard test task, e.g.:

```bash
./gradlew :mobile:test --tests "ai.openframe.mobile.ota.OtaStateTest"
```
