A basic JUnit unit test class scaffolded by default in Android/Capacitor projects, used as a template for writing local unit tests that run on the JVM (development machine) rather than an Android device or emulator.

## Key Components

- **`ExampleUnitTest`** — Sample test class demonstrating standard JUnit 4 test structure.
- **`addition_isCorrect()`** — A placeholder test method that asserts basic arithmetic correctness (`2 + 2 == 4`) using `assertEquals`.

## Usage Example

This file serves as a starting point for adding your own unit tests. Replace or extend it with tests relevant to your application logic:

```java
package com.getcapacitor.myapp;

import static org.junit.Assert.*;

import org.junit.Test;

public class ExampleUnitTest {

    @Test
    public void addition_isCorrect() throws Exception {
        assertEquals(4, 2 + 2);
    }

    @Test
    public void subtraction_isCorrect() throws Exception {
        assertEquals(0, 2 - 2);
    }
}
```

Run these tests locally using Gradle:

```bash
./gradlew testDebugUnitTest
```

Since these are local unit tests (not instrumented tests), they execute quickly on the host JVM without requiring a connected device or emulator, making them ideal for validating pure logic components before integration testing.

For more details, see the [Android testing documentation](http://d.android.com/tools/testing).
