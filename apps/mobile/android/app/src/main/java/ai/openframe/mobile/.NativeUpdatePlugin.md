## NativeUpdatePlugin.java

Android Capacitor plugin that exposes native over-the-air (OTA) bundle update functionality to the web frontend. It is the Android counterpart to `ios/App/App/NativeUpdatePlugin.swift`, sharing the same `jsName` (`"NativeUpdate"`) and method signatures so the shared frontend code in `native-shell.ts` can call either platform transparently.

By design, no method accepts a path, URL, or version from JavaScript — the native shell alone decides which bundle is active and where updates come from, keeping update logic trusted and out of web-controlled input.

## Key Components

- **`NativeUpdatePlugin`** — `Plugin` subclass registered under the Capacitor plugin name `"NativeUpdate"`.
- **`update()`** — Private helper that retrieves the singleton `NativeUpdate` instance bound to the plugin's Android `Context`.
- **`notifyReady(PluginCall call)`** — Signals that the currently loaded bundle is healthy/ready; resolves with an empty object.
- **`getState(PluginCall call)`** — Returns the current update state as a `JSObject`.
- **`check(PluginCall call)`** — Triggers a check for new bundles. Always resolves (never rejects) — if nothing is found, fetched, or verified, the existing state is simply returned unchanged.
- **`applyPending(PluginCall call)`** — Applies a previously downloaded/pending bundle. Rejects with `"NO_PENDING"` if no bundle is waiting; otherwise resolves and repoints the bridge's server base path to the new bundle directory on the main thread.

## Usage Example

Frontend TypeScript (via Capacitor's plugin bridge, e.g., `native-shell.ts`):

```java
// Not called directly from Java — invoked by Capacitor's JS bridge.
// Example of how the plugin dispatches a call internally:

@PluginMethod
public void check(PluginCall call) {
    NativeUpdate update = update();
    update.check("the page asked", () -> call.resolve(update.state()));
}
```

Typical JS-side usage (conceptual, not part of this file):

```typescript
import { NativeUpdate } from '@capacitor/core';

await NativeUpdate.check();
const state = await NativeUpdate.getState();
await NativeUpdate.applyPending(); // reloads server base path if a bundle is pending
```
