Manages timing and coalescing logic for OpenFrame's native (Android) OTA update checks, deciding when a new check is due, whether concurrent requests should join an in-flight check, and whether a pending download should be deferred under Data Saver restrictions.

## Key Components

- **`CheckSchedule`** (package-private final class) — Tracks check state using `elapsedRealtime`-based timestamps; not thread-safe on its own (caller, `NativeUpdate`, must synchronize access).
- **`Asked`** (enum) — Result of an `ask()` call: `ANSWERED` (no check needed), `JOINED` (an in-flight check will serve this request), `STARTED` (a new check began).
- **`CHECK_EVERY_MS`** — Minimum interval (1 hour) between background-initiated checks.
- **`RECENT_CHECK_MS`** — Short window (60s) used to decide if a page-initiated check can reuse a just-finished result; intentionally shorter than the web client's 65s retry (`LOOK_AGAIN_MS`).
- **`ask(boolean fromPage, long now)`** — Entry point called whenever an update check is requested (from background logic or an "Update required" page); returns the appropriate `Asked` outcome and starts a check if due.
- **`mayDownload(boolean dataSaverRestricts)`** — Determines if the download phase may proceed, deferring it when Data Saver is active and no page explicitly asked.
- **`finish(long now)`** — Completes the current check; if a page joined after a deferred download, immediately restarts the check (returns `true`) so the page's download obligation is honored.

## Usage Example

```java
CheckSchedule schedule = new CheckSchedule();

long now = SystemClock.elapsedRealtime();
CheckSchedule.Asked result = schedule.ask(/* fromPage= */ false, now);

if (result == CheckSchedule.Asked.STARTED) {
    boolean canDownload = schedule.mayDownload(/* dataSaverRestricts= */ true);
    // ... perform network check, optionally skip download if canDownload is false ...

    boolean restarted = schedule.finish(SystemClock.elapsedRealtime());
    if (restarted) {
        // A page request arrived while download was deferred; a new check just began.
    }
}
```

**Note:** This class has a platform twin, `OtaCheckSchedule`, in iOS's OtaCore module. Behavioral changes made here must be mirrored there, with matching test coverage (`NativeUpdateCheckTimingTest` / `CheckScheduleTests`).
