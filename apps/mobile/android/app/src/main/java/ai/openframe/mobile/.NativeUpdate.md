## NativeUpdate.java

The Android counterpart to `ios/App/App/NativeUpdate.swift`, implementing the over-the-air (OTA) bundle update lifecycle for the OpenFrame mobile app. It decides which web bundle a process launch runs, manages the trial/rollback state for freshly applied bundles, and coordinates background checking, downloading, and cleanup of old bundle directories without ever touching the main thread.

## Key Components

- **`NativeUpdate` (final class)** — Singleton facade over the OTA subsystem, accessed via `get(Context)`.
- **`BRIDGE_LEVEL`** — Static constant bumped whenever the native bridge surface changes; bundles requiring a higher level are rejected.
- **`bootDirectory(boolean recreated)`** — Called at launch to determine which bundle directory should be loaded (or `null` for the built-in APK bundle), handling trial/rollback logic and staging cleanup.
- **`state()`** — Returns a `JSObject` snapshot (enabled, builtinVersion, bridgeLevel, bootedVersion, trial, activeVersion, pendingVersion) exposed to the Capacitor bridge/JS layer.
- **`notifyReady()`** — Marks the currently booted trial bundle as confirmed-good/active.
- **`applyPending()`** — Switches to a previously downloaded pending bundle, returning its directory, with rollback logging if the previous trial failed.
- **`installObservers()`** — Hooks `ProcessLifecycleOwner` to trigger an update check when the app returns to the foreground.
- **`check(String trigger, Runnable whenSettled)`** — Entry point for scheduling/deduplicating update checks, optionally invoked from JS with a completion callback.
- **`builtinVersion(AssetManager)`** — Reads the `public/ota-builtin.json` stamp to determine the built-in bundle's version.
- **`envElement()`** — Lazily extracts the environment marker from `public/index.html` used to validate bundle compatibility.

Internally delegates to collaborator classes: `OtaSession`, `UpdateStore`, `UpdateChecker`, `CheckSchedule`, and helpers in the `ai.openframe.mobile.ota` package (`Bytes`, `Json`, `Version`, `EnvCopy`, `OtaError`, `OtaState`).

## Usage Example

```java
// Typical usage from an Activity or Capacitor plugin
NativeUpdate update = NativeUpdate.get(context);

// At app launch
File bundleDir = update.bootDirectory(wasRecreated);
// Load bundleDir, or fall back to built-in assets if null

// Install lifecycle observers once
update.installObservers();

// Trigger a manual check from JS, with a completion callback
update.check("page requested check", () -> {
    // notify JS layer that check settled
});

// Expose state to the webview bridge
JSObject currentState = update.state();

// After the new bundle renders successfully
update.notifyReady();

// To switch to a downloaded pending bundle
File pendingDir = update.applyPending();
```
