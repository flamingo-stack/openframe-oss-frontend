## UpdateChecker

Implements the OTA (over-the-air) bundle update flow for the OpenFrame mobile app. It periodically asks the compiled-in shared gateway host for a signed manifest describing the latest web bundle version, verifies its signature against compiled public keys, and decides whether to drop a pending update, do nothing, or download and stage a new bundle for the next app launch.

## Key Components

- **`UpdateChecker`** (package-private final class) - orchestrates the full check-and-download cycle.
- **`DownloadPermit`** - interface callback allowing the caller to gate bundle downloads (e.g., respecting Android Data Saver / metered network restrictions).
- **`manifestUrl(String sharedHost)`** - static helper that strictly validates the compiled shared host is a bare `https` origin (no path, query, fragment, or credentials) before building the manifest endpoint URL.
- **`compiledKeys()`** - decodes the build-time embedded `OTA_PUBLIC_KEY_CURRENT`/`OTA_PUBLIC_KEY_NEXT` into an `OtaKeys` map used to verify manifest signatures.
- **`disabledReason()`** - returns a human-readable reason the checker is disabled (missing built-in version, invalid host, missing `window.__ENV`), or `null` if update checks are active.
- **`run(String trigger, DownloadPermit permit)`** - entry point that fetches/verifies the manifest, consults `OtaSession.decide(...)`, and dispatches to drop/no-op/download logic.
- **`fetchManifest()`** / **`fetchBundle(...)`** - perform bounded, size-capped HTTP downloads (manifest capped at 64 KiB) using dedicated `OkHttpClient` instances with no cookies and restricted redirect behavior (HTTPS-only).
- **`download(Manifest.Payload payload, DownloadPermit permit)`** - handles staging, verification (`BundleReader.readVerified`), environment injection (`EnvCopy.insert`) into `index.html`, and final install via `UpdateStore`.
- **`NoUpdate`** - internal exception representing a benign "no update available" outcome (safe to log directly).

## Usage Example

```java
UpdateChecker checker = new UpdateChecker(context, updateStore, otaSession, hasBuiltinVersion, envElementSupplier);

String reason = checker.disabledReason();
if (reason == null) {
    checker.run("periodic-check", dataSaverRestricts -> !dataSaverRestricts);
} else {
    log("Update checks disabled: " + reason);
}
```

This class is intended to be invoked from a scheduled background task or app-lifecycle trigger (e.g., on resume), not directly from UI code.
