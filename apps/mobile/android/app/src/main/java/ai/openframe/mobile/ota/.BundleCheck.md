Validates a downloaded OTA bundle against its manifest-declared size and SHA-256 checksum, incrementally, as bytes arrive during download.

## Key Components

- **`BundleCheck(long size, String sha256)`** — Constructor; stores the expected byte size and expected SHA-256 hex digest from the bundle manifest.
- **`update(byte[] bytes, int offset, int length)`** — Feeds a chunk of downloaded bytes into the running digest. Tracks cumulative `received` bytes and throws `OtaError` (code `SIZE`) immediately if the total exceeds the manifest's declared `size`, stopping the download at the first excess byte.
- **`finish()`** — Called after the download completes. Throws `OtaError` (code `SIZE`) if the final byte count doesn't exactly match `size`, or `OtaError` (code `SHA256`) if the computed digest doesn't match the manifest's `sha256` value.

The class relies on `Bytes.sha256()` to create the `MessageDigest` instance and `Bytes.hex(...)` to convert the final digest to a hex string for comparison. It is designed to be used as a single-pass, stateful validator: `update` can be called multiple times as data streams in, followed by exactly one call to `finish`.

## Usage Example

```java
BundleCheck check = new BundleCheck(manifestSize, manifestSha256);

try (InputStream in = connection.getInputStream()) {
    byte[] buffer = new byte[8192];
    int read;
    while ((read = in.read(buffer)) != -1) {
        check.update(buffer, 0, read);
        // bytes may also be written to disk here
    }
    check.finish();
} catch (OtaError e) {
    // handle size mismatch or checksum failure
    throw e;
}
```

This pattern is used by `BundleReader.readVerified`, which performs the length and SHA-256 checks on the downloaded bundle before decoding any of its contents.
