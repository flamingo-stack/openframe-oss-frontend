# OtaKeys.java

Utility class for managing OTA (over-the-air) update verification keys, providing a canonical way to identify and load P-256 public keys from their SPKI (SubjectPublicKeyInfo) DER encoding.

A key's ID is derived as the first 16 lowercase hex digits of the SHA-256 hash over its SPKI DER bytes. Only the specific 91-byte encoding of a P-256 key (named curve, uncompressed point) is accepted, ensuring that every implementation computes the same ID for the same key.

## Key Components

- **`P256_SPKI_PREFIX`** - Fixed byte prefix identifying a P-256 named-curve, uncompressed-point SPKI encoding.
- **`P256_SPKI_LENGTH`** - Expected total length (91 bytes) of a valid P-256 SPKI blob.
- **`keyId(byte[] spki)`** - Computes the canonical key ID (16 hex chars) from raw SPKI bytes via SHA-256.
- **`of(byte[]... spkis)`** - Builds an immutable `Map<String, PublicKey>` keyed by `keyId`, from one or more SPKI byte arrays.
- **`publicKey(byte[] spki)`** *(private)* - Validates the SPKI format matches the expected P-256 prefix/length and loads it into a `PublicKey` using `KeyFactory`.

## Usage Example

```java
// Register OTA signing keys by their canonical SPKI DER encodings
byte[] key1Spki = /* 91-byte P-256 SPKI DER bytes */;
byte[] key2Spki = /* 91-byte P-256 SPKI DER bytes */;

Map<String, PublicKey> trustedKeys = OtaKeys.of(key1Spki, key2Spki);

// Look up a key by its computed id (e.g. received in an OTA manifest)
String keyId = OtaKeys.keyId(key1Spki);
PublicKey key = trustedKeys.get(keyId);

if (key == null) {
    throw new IllegalStateException("Unknown OTA signing key: " + keyId);
}
```

Invalid SPKI encodings (wrong length, wrong prefix, or unloadable key material) cause `publicKey` to throw `IllegalArgumentException`, ensuring only properly formatted P-256 keys are accepted.
