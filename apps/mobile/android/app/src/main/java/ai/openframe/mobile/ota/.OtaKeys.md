Utility class for managing OTA (over-the-air) update signing keys, providing deterministic key identification and strict validation of P-256 public keys in SPKI DER format.

## Key Components

- **`OtaKeys`** — Final utility class (non-instantiable) for working with P-256 public keys used in OTA update verification.
- **`keyId(byte[] spki)`** — Computes a deterministic key ID as the first 16 lowercase hex digits of the SHA-256 hash over the SPKI DER encoding.
- **`of(byte[]... spkis)`** — Builds an immutable, ordered map (`keyId → PublicKey`) from one or more SPKI-encoded public keys.
- **`publicKey(byte[] spki)`** — Private helper that validates the SPKI byte length and prefix (must match the standard P-256 named-curve, uncompressed-point encoding) before loading it via `KeyFactory`.
- **`P256_SPKI_PREFIX` / `P256_SPKI_LENGTH`** — Constants defining the fixed 26-byte ASN.1 prefix and total 91-byte length expected for a valid P-256 SPKI encoding.

This design ensures only one canonical encoding of a P-256 key is accepted, so all implementations consistently compute the same key ID for a given key.

## Usage Example

```java
import ai.openframe.mobile.ota.OtaKeys;
import java.security.PublicKey;
import java.util.Map;

// Given one or more DER-encoded SPKI byte arrays for P-256 public keys
byte[] spki1 = /* ... load from embedded resource ... */;
byte[] spki2 = /* ... load from embedded resource ... */;

Map<String, PublicKey> trustedKeys = OtaKeys.of(spki1, spki2);

// Look up a key by its deterministic ID, e.g. received in an OTA update manifest
String incomingKeyId = "a1b2c3d4e5f60718";
PublicKey verificationKey = trustedKeys.get(incomingKeyId);

if (verificationKey == null) {
    throw new SecurityException("Unknown or untrusted OTA signing key: " + incomingKeyId);
}
```

**Notes:**
- Only P-256 keys in the named-curve, uncompressed-point SPKI format (91 bytes total) are accepted; any other encoding throws `IllegalArgumentException`.
- The returned map from `of(...)` is unmodifiable and preserves insertion order (`LinkedHashMap`), useful for deterministic key rotation/lookup ordering.
- This class depends on an internal `Bytes` helper (not shown) providing `sha256()`, `hex(byte[])`, and `indexOf(byte[], byte[], int)` utilities.
