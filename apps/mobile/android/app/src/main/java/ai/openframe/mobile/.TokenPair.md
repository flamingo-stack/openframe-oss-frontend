Immutable value type representing a session's access/refresh token pair in the Android mobile shell, acting as the Android counterpart to `TokenPair` in `ios/App/App/TokenStore.swift`. It normalizes the encoding/decoding of tokens across the Capacitor bridge, HTTP response headers, and persisted storage, and provides safe merge semantics for partial token updates (e.g., when a rotation response carries only one new token).

## Key Components

- **`ACCESS_KEY` / `REFRESH_KEY`** — Shared field names (`"accessToken"` / `"refreshToken"`) used consistently across the bridge payload (getTokens/setTokens, tokenUpdate event) and the stored JSON blob.
- **`EMPTY`** — A singleton representing an absent token pair.
- **`access` / `refresh`** — The token values; blank strings are normalized to `null` via `blankToNull`.
- **`isEmpty()`** — Returns `true` if both halves are absent.
- **`merge(TokenPair incoming)`** — Applies only the present halves of `incoming` over this pair, preserving existing values when the incoming pair omits one.
- **`encode()`** — Serializes the pair to a JSON string for storage, omitting absent halves.
- **`decode(String blob)`** — Parses a stored JSON blob back into a `TokenPair`, returning `EMPTY` on null or malformed input.
- **`fromHeaders(Response response)`** — Builds a `TokenPair` from the `Access-Token` / `Refresh-Token` HTTP response headers.
- **`toJS()`** — Converts the pair into a `JSObject` for returning across the Capacitor bridge.
- **`equals()` / `hashCode()`** — Value-based equality over `access` and `refresh`.

## Usage Example

```java
// Build from an HTTP response after a token refresh
Response response = client.newCall(request).execute();
TokenPair incoming = TokenPair.fromHeaders(response);

// Merge with the currently stored pair, preserving any untouched half
TokenPair stored = TokenPair.decode(storedBlobFromPrefs);
TokenPair updated = stored.merge(incoming);

if (!updated.isEmpty()) {
    // Persist the merged pair
    prefs.edit().putString("tokenPair", updated.encode()).apply();

    // Return to the JS bridge
    call.resolve(updated.toJS());
}
```
