## TokenPair.java

An immutable value type representing the Android shell's session token pair (access + refresh tokens). It is the Android counterpart to `TokenPair` in `ios/App/App/TokenStore.swift`, and serves as the single representation of tokens across the Capacitor bridge, the gateway's HTTP headers, and the on-device stored blob.

Either token may be absent, since a rotation response can carry just one. The `merge` method allows a partial update (e.g., a refreshed access token) to be applied without erasing the other half.

## Key Components

- **`ACCESS_KEY` / `REFRESH_KEY`** — Canonical field names (`"accessToken"` / `"refreshToken"`) used consistently in bridge payloads (`getTokens`/`setTokens`, `tokenUpdate` event) and the stored JSON blob.
- **`EMPTY`** — Shared constant representing a pair with no tokens.
- **`access` / `refresh`** — Final fields holding the token strings (blank strings normalized to `null`).
- **`isEmpty()`** — Returns `true` if both tokens are absent.
- **`merge(TokenPair incoming)`** — Overlays present values from `incoming` onto `this`, preserving existing values where `incoming` has none.
- **`encode()`** — Serializes the pair to a JSON string for storage, omitting absent halves.
- **`decode(String blob)`** — Parses a stored JSON blob back into a `TokenPair`, returning `EMPTY` on `null` or malformed input.
- **`fromHeaders(Response response)`** — Builds a pair from the `Access-Token` / `Refresh-Token` HTTP response headers returned by the gateway.
- **`toJS()`** — Converts the pair into a `JSObject` suitable for returning across the Capacitor bridge.
- **`equals` / `hashCode`** — Value-based equality over `access` and `refresh`.

## Usage Example

```java
// Parse tokens from a gateway response and persist them
TokenPair fromGateway = TokenPair.fromHeaders(response);
String storedBlob = fromGateway.encode();

// Later, restore from storage and merge in a refreshed access token only
TokenPair stored = TokenPair.decode(storedBlob);
TokenPair refreshed = new TokenPair("newAccessToken123", null);
TokenPair updated = stored.merge(refreshed);

if (!updated.isEmpty()) {
    JSObject bridgeResult = updated.toJS();
    // return bridgeResult to the Capacitor plugin call
}
```
