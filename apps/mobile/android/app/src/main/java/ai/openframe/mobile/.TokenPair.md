Represents the session's access/refresh token pair as held by the Android mobile shell, mirroring the `TokenPair` type in `ios/App/App/TokenStore.swift`. Either token may be absent, and the class provides merging, encoding/decoding, and conversion to/from bridge and HTTP response formats.

## Key Components

- **`ACCESS_KEY` / `REFRESH_KEY`** - Shared field names (`accessToken`, `refreshToken`) used consistently across the JS bridge, token update events, and the stored JSON blob, so renaming one is treated as a storage migration.
- **`EMPTY`** - A singleton representing a pair with both tokens absent.
- **`access` / `refresh`** - The token values, normalized so blank strings become `null`.
- **`isEmpty()`** - Returns `true` when both tokens are absent.
- **`merge(TokenPair incoming)`** - Applies the present halves of `incoming` over this pair, preserving any half not present in the incoming pair.
- **`encode()`** - Serializes the pair to a JSON string, omitting absent halves (never nulling them).
- **`decode(String blob)`** - Parses a stored JSON blob back into a `TokenPair`, returning `EMPTY` on `null` or invalid JSON.
- **`fromHeaders(Response response)`** - Builds a `TokenPair` from the `Access-Token` / `Refresh-Token` HTTP response headers returned by the gateway during an exchange or refresh.
- **`toJS()`** - Converts the pair into a `JSObject` suitable for returning across the Capacitor bridge.
- **`equals(Object)` / `hashCode()`** - Value-based equality over `access` and `refresh`.

## Usage Example

```java
// Decode a previously stored token blob
TokenPair stored = TokenPair.decode(storedBlob);

// Build a pair from a gateway refresh response
TokenPair fromRefresh = TokenPair.fromHeaders(response);

// Merge the refreshed values over the stored ones, keeping any
// half not present in the refresh response
TokenPair updated = stored.merge(fromRefresh);

if (!updated.isEmpty()) {
    String blobToPersist = updated.encode();
    JSObject bridgeResult = updated.toJS();
}
```
