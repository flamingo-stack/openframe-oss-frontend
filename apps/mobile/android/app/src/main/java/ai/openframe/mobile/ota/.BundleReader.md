## BundleReader.java

Streaming decoder for OpenFrame OTA (over-the-air) update bundles. It decompresses an XZ-compressed tar archive and reads it entry-by-entry without ever holding the full archive or tar contents in memory, extracting file contents through a `Sink` callback while locating and buffering `index.html` separately. It enforces strict validation ordering (xz stream faults > tar faults > entry faults > missing index) matching the OTA bundle format specification.

## Key Components

- **`BundleReader`** — Final class implementing the streaming reader; not directly instantiable (private constructor).
- **`Sink`** (nested interface) — Callback contract (`begin`, `write`, `end`) invoked per tar entry as its bytes are decoded, allowing callers to stream extracted files to disk without buffering.
- **`Source`** (nested class) — Wraps the raw input stream to distinguish I/O failures from xz-format faults.
- **`readVerified(File, long, String, Sink)`** — Public entry point: verifies archive size and SHA-256 against a `BundleCheck`, then decodes the verified bytes and returns the raw `index.html` contents.
- **`read(InputStream, Sink)`** (package-private) — Lower-level entry used internally after verification.
- **`isSafePath(String)`** — Static helper validating tar entry paths reject absolute paths, `.`/`..` segments, and unsafe characters.
- Internal tar-parsing helpers: `readTar()`, `readEndOfArchive()`, `takes(String)`, `hasUstarMagic()`, `hasValidChecksum()`, `octal(...)`, `path()`.

## Usage Example

```java
File bundleFile = new File("/path/to/update.bundle");
long expectedSize = 100_663_296L;
String expectedSha256 = "a1b2c3...";

BundleReader.Sink sink = new BundleReader.Sink() {
    private OutputStream out;

    @Override
    public void begin(String path, long size) throws IOException {
        File dest = new File(targetDir, path);
        dest.getParentFile().mkdirs();
        out = new FileOutputStream(dest);
    }

    @Override
    public void write(byte[] buffer, int offset, int length) throws IOException {
        out.write(buffer, offset, length);
    }

    @Override
    public void end() throws IOException {
        out.close();
    }
};

byte[] indexHtml = BundleReader.readVerified(
    bundleFile, expectedSize, expectedSha256, sink);
```

**Notes:**
- Bundles must be xz-compressed ustar tar archives packed with `xz -6` (decoder enforces a 64 MiB memory limit).
- Validation precedence is strict: an xz stream fault is thrown before a tar fault, which is thrown before the first unsafe/duplicate entry fault, which is thrown before a missing `index.html` error — all surfaced as `OtaError`.
- Entry paths are checked case-insensitively for collisions and path traversal before being passed to the `Sink`.
