## BundleReader.java

Streams and validates an OTA update bundle—an xz-compressed tar archive—without ever buffering the full archive or decompressed tar in memory. It enforces a strict, prioritized fault hierarchy (xz stream errors > tar structure errors > first unsafe/invalid entry > missing `index.html`) and extracts `index.html` content while streaming each regular file entry to a caller-supplied `Sink`.

## Key Components

- **`BundleReader`** — core class driving streaming decode-and-validate of the bundle; entry point via static factory methods.
- **`readVerified(File, long, String, Sink)`** — verifies archive size and SHA-256 against signed metadata (via `BundleCheck`) *before* reading any bytes, then decodes the verified file.
- **`read(InputStream, Sink)`** (package-private) — decodes an already-verified input stream; used internally by `readVerified`.
- **`Sink`** — caller callback interface (`begin`/`write`/`end`) invoked for each regular file entry extracted from the tar.
- **`Source`** — internal `InputStream` wrapper that distinguishes genuine I/O failures from bundle-format faults.
- **`isSafePath(String)`** — static helper validating tar entry paths against path traversal, absolute paths, and length limits.
- Internal tar-parsing logic: ustar header validation, checksum verification, octal field parsing, duplicate/collision detection (case-insensitive), and end-of-archive block checks.

## Usage Example

```java
File bundleFile = new File("/path/to/update.bundle");
long expectedSize = 100_663_296L;
String expectedSha256 = "a1b2c3...";

BundleReader.Sink sink = new BundleReader.Sink() {
    @Override
    public void begin(String path, long size) throws IOException {
        // prepare to write file at 'path' with 'size' bytes
    }

    @Override
    public void write(byte[] buffer, int offset, int length) throws IOException {
        // append bytes to the currently open file
    }

    @Override
    public void end() throws IOException {
        // close the currently open file
    }
};

try {
    byte[] indexHtml = BundleReader.readVerified(bundleFile, expectedSize, expectedSha256, sink);
    // indexHtml contains the bytes of index.html from the bundle root
} catch (OtaError e) {
    // bundle failed validation (xz/tar/entry/index fault) — handle per e.getCode()
} catch (IOException e) {
    // genuine I/O failure reading the archive
}
```

Notes: `readVerified` always validates checksum/size first, then streams and decodes; see `apps/mobile/docs/ota.md` for the fault precedence contract this class implements.
