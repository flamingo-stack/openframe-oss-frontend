# ExternalLinksPlugin.java

A Capacitor plugin for the Android app that intercepts outgoing web navigation and opens external links in a Chrome Custom Tab instead of the system default browser, mirroring the iOS `ExternalLinksPlugin.swift` (which uses `SFSafariViewController`).

Capacitor calls `shouldOverrideLoad` on every registered plugin before falling back to its own plain `ACTION_VIEW` intent for off-origin URLs. This plugin decides whether to let the system handle the link, hand it to an installed default app, or open it in a Custom Tab.

## Key Components

- **`ExternalLinksPlugin`** — `@CapacitorPlugin(name = "ExternalLinks")` class extending `Plugin`.
- **`SYSTEM_HOSTS`** — Static list of app-store hosts (`apps.apple.com`, `itunes.apple.com`, `play.google.com`) that are excluded from Custom Tab handling so store links render natively instead of as a web page.
- **`shouldOverrideLoad(Uri url)`** — Main override hook. Validates scheme/host, skips store and in-app URLs, attempts to delegate to a default app (Android 11+), then falls back to launching a `CustomTabsIntent`. Returns `null` to let Capacitor's default behavior take over when appropriate.
- **`isAppUrl(String scheme, String host)`** — Checks whether the URL matches the app's own origin or Capacitor's allowed navigation mask, re-implementing a check Capacitor doesn't expose as a public predicate.
- **`openInDefaultApp(Uri url)`** — On Android 11+ (`Build.VERSION_CODES.R`), attempts to open the URL via an app that is the verified default handler for that domain, using `FLAG_ACTIVITY_REQUIRE_NON_BROWSER` and `FLAG_ACTIVITY_REQUIRE_DEFAULT` to avoid triggering a disambiguation chooser.

## Usage Example

This plugin is registered automatically by Capacitor via the annotation and requires no direct instantiation in application code. It is invoked implicitly when the WebView navigates to an external URL:

```java
// Registered in MainActivity via Capacitor's plugin list
public class MainActivity extends BridgeActivity {
    @Override
    public void onCreate(Bundle savedInstanceState) {
        registerPlugin(ExternalLinksPlugin.class);
        super.onCreate(savedInstanceState);
    }
}
```

Behavior summary for an outgoing link:
1. Non-HTTP(S) schemes (`mailto:`, `tel:`, `market:`) → left to the system (`null`).
2. App store hosts or same-origin/in-app URLs → left to the system (`null`).
3. A verified default app exists (Android 11+) → opened directly in that app.
4. Otherwise → opened in a Chrome Custom Tab.
5. No browser available → falls back to Capacitor's own `ACTION_VIEW` handling.
