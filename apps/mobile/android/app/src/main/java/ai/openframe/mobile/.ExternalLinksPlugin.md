## ExternalLinksPlugin.java

A Capacitor plugin for the Android app that intercepts outgoing web navigation and opens off-origin URLs in a Chrome Custom Tab instead of handing them to the default system browser. It mirrors the iOS counterpart (`ExternalLinksPlugin.swift`, which uses `SFSafariViewController`), providing a consistent in-app browsing experience across platforms.

## Key Components

- **`ExternalLinksPlugin`** — `@CapacitorPlugin(name = "ExternalLinks")` class extending Capacitor's `Plugin`, overriding `shouldOverrideLoad`.
- **`SYSTEM_HOSTS`** — Static list of app-store hosts (`apps.apple.com`, `itunes.apple.com`, `play.google.com`) excluded from Custom Tab handling so store links render natively.
- **`shouldOverrideLoad(Uri)`** — Capacitor hook invoked before a URL leaves the WebView; decides whether to intercept (`true`), defer to another handler (`null`), or let Capacitor's default `ACTION_VIEW` fallback apply.
- **`isAppUrl(String, String)`** — Checks if a URL matches the app's own origin or Capacitor's allowed navigation mask, so in-app navigation isn't redirected.
- **`openInDefaultApp(Uri)`** — On Android 11+ (API 30+), attempts to launch the URL via its verified default-handler app (e.g., Teams, Zoom) using `FLAG_ACTIVITY_REQUIRE_DEFAULT`/`FLAG_ACTIVITY_REQUIRE_NON_BROWSER`, avoiding an app chooser dialog.

## Usage Example

This plugin is registered automatically by Capacitor's Android bridge and requires no direct invocation from app code—navigation interception happens transparently:

```java
// Registered via @CapacitorPlugin annotation; Capacitor's Bridge
// calls shouldOverrideLoad(Uri) automatically for outgoing navigations.
// No manual instantiation or JS-side calls are needed.

// Example of what happens internally when a user taps an external link:
// 1. Bridge.launchIntent checks first (app-origin URLs pass through).
// 2. ExternalLinksPlugin.shouldOverrideLoad(url) is called.
// 3. Store links and in-app URLs return null (handled elsewhere).
// 4. Android 11+ default-app links open directly (e.g., Zoom meeting links).
// 5. All other http(s) URLs open in a Chrome Custom Tab.
```

**Behavior notes:**
- Non-http(s) schemes (`mailto:`, `tel:`, `market:`) and OAuth callbacks are left untouched (returns `null`).
- Falls back to Capacitor's native `ACTION_VIEW` if no browser is installed (`ActivityNotFoundException`).
