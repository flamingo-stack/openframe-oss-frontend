## OtaSession.java

Manages the lifecycle of an Over-The-Air (OTA) bundle update session for the mobile app's web view runtime. It coordinates reading/writing persisted OTA state, deciding which bundle version to boot, and tracking trial/rollback bookkeeping—all under a single lock to keep concurrent access (main thread boot, bridge calls, background checks) serialized.

## Key Components

- **`OtaSession.Store`** - Interface for persisting `OtaState`: `read()`, `write()`, and `index(version)` for bundle metadata lookup.
- **`OtaSession.Booted`** - Immutable snapshot describing what bundle is currently booted (`version`, `trial` flag, `reverted` version if a rollback occurred).
- **`OtaSession.Applied`** - Result of applying a pending update (`version` applied, or `reverted` version if it failed).
- **`boot()`** - Cold-start entry point; resolves and commits which bundle to boot, falling back to the built-in bundle on any I/O failure.
- **`recreated()`** - Handles Activity re-creation without re-deciding, except when the current bundle became unusable.
- **`applyPending()`** - Applies a downloaded/pending bundle, counting a boot attempt or marking it bad if trials are exhausted.
- **`notifyReady()`** - Confirms a trial succeeded once the web page reports ready.
- **`decide(...)`** - Delegates to `Decision.decide(...)` to determine update actions based on bridge/payload versions.
- **`drop()`, `nothing(...)`, `downloaded(...)`, `markBad(...)`** - State mutators for rejecting, no-op, completing download, and blacklisting a bundle version.
- **`staleDirectories(...)`** - Lists bundle directories no longer needed, safe to delete.
- **`isUsable(version)`** - Checks that a bundle's embedded environment matches the current build's expected env element.

## Usage Example

```java
OtaSession.Store store = new FileBackedStore(context);
OtaSession session = new OtaSession(BuildConfig.BUNDLE_VERSION, envElementSupplier, store);

// On app/process start
OtaSession.Booted booted = session.boot();
webView.loadBundle(booted.version); // null means built-in

// On Activity recreation (e.g. rotation)
OtaSession.Booted current = session.recreated();

// When the web page signals it loaded successfully
if (session.notifyReady()) {
    log("Trial confirmed for " + session.booted().version);
}

// After a background download completes
session.downloaded("1.4.0");
OtaSession.Applied applied = session.applyPending();
```
