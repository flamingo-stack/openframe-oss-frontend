## OtaSession.java

Manages the lifecycle of Over-The-Air (OTA) bundle updates for a mobile application, coordinating state persistence between a `Store` and in-memory decisions about which bundle version should be active. It serializes all read/write access to OTA state through synchronized methods, ensuring thread-safe handling of boot decisions, trial confirmations, downloads, and rollback/bad-version marking across the main thread, bridge calls, and background checks.

## Key Components

- **`Store` interface** – Abstraction for persisting `OtaState`; supports atomic `read()`/`write()` and `index(version)` lookups for environment compatibility checks.
- **`Booted`** – Immutable snapshot describing what bundle version is currently booted, whether it's a trial, and any reverted version.
- **`Applied`** – Result of applying a pending update, exposing the newly applied version (if any) and any reverted version.
- **`OtaSession(String builtinVersion, Supplier<byte[]> envElement, Store store)`** – Constructor wiring the built-in bundle version, environment fingerprint supplier, and persistence store.
- **`boot()`** – Cold-start entry point; reads stored state, resolves which bundle to boot, and commits bookkeeping (attempt counts, reverts).
- **`recreated()`** – Handles Activity re-creation without re-running full boot logic, falling back to the built-in bundle if the current version becomes unusable.
- **`notifyReady()`** – Confirms a trial succeeded (web view loaded), clearing trial status.
- **`applyPending()`** – Applies a pending downloaded bundle, counting the attempt or marking the bundle bad if attempts are exhausted.
- **`decide(...)`** – Determines update decisions based on bridge/payload version compatibility.
- **`drop()`, `nothing(...)`, `downloaded(...)`, `markBad(...)`** – State transition methods for discarding, no-op, successful download, and bad-version marking.
- **`staleDirectories(...)`** – Lists bundle directories no longer needed, for cleanup.
- **`isUsable(version)`** – Checks environment compatibility of a given bundle version via `EnvCopy`.

## Usage Example

```java
OtaSession.Store store = new FileBackedOtaStore(context);
OtaSession session = new OtaSession("1.0.0-builtin", () -> readEnvFingerprint(), store);

// At app startup
OtaSession.Booted booted = session.boot();
loadBundle(booted.version, booted.trial);

// After WebView successfully loads
if (session.notifyReady()) {
    log("Trial confirmed for version " + session.booted().version);
}

// When a new bundle finishes downloading and verifying
session.downloaded("1.2.0");
OtaSession.Applied applied = session.applyPending();
if (applied.version != null) {
    restartWithBundle(applied.version);
}
```
