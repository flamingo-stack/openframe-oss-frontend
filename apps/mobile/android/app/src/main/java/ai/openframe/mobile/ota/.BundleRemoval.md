# BundleRemoval.java

Utility for safely deleting an OTA (over-the-air) update bundle directory, ensuring the deletion order makes partial/interrupted removals fail-safe rather than leaving a directory that could be mistaken for a complete, valid bundle.

## Key Components

- **`BundleRemoval`** — final utility class (non-instantiable) providing bundle deletion logic.
- **`remove(File directory)`** — deletes an entire bundle directory tree, removing `index.html` (the file that marks a directory as a valid bundle) *first*, before any other files or subdirectories.
- **`order(File directory)`** (package-private, testable) — computes the deletion order as a `List<File>`, placing the bundle's root `index.html` at the head of the list.
- **`collect(File file, File first, List<File> order)`** — recursively walks the directory tree post-order (children before parents), skipping the `first` file (already queued), so directories are only deleted after their contents.

## Usage Example

```java
import ai.openframe.mobile.ota.BundleRemoval;
import java.io.File;

public class OtaCleanup {
    public static void main(String[] args) {
        File bundleDir = new File("/data/app/ota/bundle-123");

        // Deletes index.html first, then recursively removes
        // all remaining files and subdirectories bottom-up.
        BundleRemoval.remove(bundleDir);
    }
}
```

**Why this matters:** if deletion is interrupted partway through (e.g., process killed, ~4,200 files to remove), removing `index.html` first guarantees the directory immediately stops being recognized as a valid bundle — preventing a half-deleted bundle from being mistaken for a complete, usable one.
