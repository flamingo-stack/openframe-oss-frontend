# Json.java

A strict, dependency-free JSON parser conforming to RFC 8259, used for parsing OTA (over-the-air update) manifests in the OpenFrame mobile app. Unlike permissive libraries such as `org.json`, it rejects comments, trailing commas, single quotes, byte order marks, and any trailing text after the value—accepting only well-formed UTF-8 JSON.

## Key Components

- **`Json.parse(byte[] utf8)`** — Static entry point that decodes strict UTF-8 bytes and parses a single JSON value, throwing `Malformed` if the input is invalid or has trailing content.
- **`Json.parseObject(byte[] utf8)`** — Convenience method that parses and casts the result to `Map<String, Object>`, failing if the top-level value isn't a JSON object.
- **`Json.NULL`** — Sentinel object representing JSON's `null`, distinct from a Java `null` (which represents a missing map key).
- **`Json.Num`** — Wraps a numeric literal's raw text; `positiveInteger()` safely extracts a `long` for pure-digit numbers (≤18 digits), returning `-1` otherwise.
- **`Json.Malformed`** — Checked exception thrown for any parsing failure, with a descriptive message including the error position.
- **`MAX_DEPTH`** — Limits nested object/array depth to 32 levels to prevent stack overflow from malicious or malformed input.

## Usage Example

```java
byte[] manifestBytes = fetchOtaManifest();

try {
    Map<String, Object> manifest = Json.parseObject(manifestBytes);

    Object versionValue = manifest.get("version");
    if (versionValue instanceof Json.Num) {
        long version = ((Json.Num) versionValue).positiveInteger();
        if (version < 0) {
            throw new IllegalStateException("version is not a positive integer");
        }
    }

    Object urlValue = manifest.get("url");
    if (urlValue == Json.NULL || urlValue == null) {
        throw new IllegalStateException("missing or null url");
    }
    String url = (String) urlValue;

} catch (Json.Malformed e) {
    log("Invalid OTA manifest: " + e.getMessage());
}
```

**Notes:**
- JSON types map to Java types: objects → `LinkedHashMap`, arrays → `ArrayList`, strings → `String`, booleans → `Boolean`, numbers → `Json.Num`, and `null` → `Json.NULL`.
- Always distinguish `Json.NULL` (JSON's `null`) from Java `null` (absent key) when reading map values.
