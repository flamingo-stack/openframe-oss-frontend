# Json.java

A strict, dependency-free RFC 8259 JSON parser for the OpenFrame mobile OTA (over-the-air update) subsystem. It deliberately rejects everything standard JSON disallows—comments, trailing commas, single quotes, BOMs, and trailing whitespace-only input—unlike permissive parsers such as `org.json`.

## Key Components

- **`Json.parse(byte[] utf8)`** — Parses raw UTF-8 bytes into a JSON value tree (`Map`, `List`, `String`, `Num`, `Boolean`, or `NULL`). Throws `Malformed` if the input is not strict, valid UTF-8 JSON.
- **`Json.parseObject(byte[] utf8)`** — Convenience wrapper that parses and casts the result to `Map<String, Object>`, throwing `Malformed` if the top-level value isn't a JSON object.
- **`Json.NULL`** — Sentinel object representing JSON's `null`, distinct from a Java `null` (which instead represents a missing map key).
- **`Json.Num`** — Wraps a JSON number as its raw decimal text (preserving exact representation). Provides `positiveInteger()` to safely extract a `long` (digits-only, up to 18 digits; returns `-1` for anything else, including `1.0` or `1e0`).
- **`Json.Malformed`** — Checked exception thrown on any parse failure, with a descriptive message including the failing offset.
- **`MAX_DEPTH`** — Caps nesting at 32 levels to prevent stack overflow from malicious/corrupt input.

## Usage Example

```java
byte[] data = "{\"version\": 42, \"name\": \"firmware-update\"}".getBytes(StandardCharsets.UTF_8);

try {
    Map<String, Object> manifest = Json.parseObject(data);

    Object versionValue = manifest.get("version");
    if (versionValue instanceof Json.Num) {
        long version = ((Json.Num) versionValue).positiveInteger();
        if (version < 0) {
            throw new IllegalStateException("version is not a plain positive integer");
        }
    }

    Object name = manifest.get("name");
    if (name == Json.NULL) {
        // explicit JSON null
    } else if (name == null) {
        // key was missing entirely
    }
} catch (Json.Malformed e) {
    // handle invalid manifest JSON
}
```

## Notes

- Strings are decoded strictly: lone or mismatched surrogate escapes (`\uXXXX`) are rejected to guarantee round-trip UTF-8 safety.
- Numbers are kept as raw text (`Num`) rather than auto-converted to `double`/`long`, avoiding precision loss; callers opt into integer extraction via `positiveInteger()`.
- Duplicate object keys retain the last value, matching `JSON.parse` semantics in JavaScript.
