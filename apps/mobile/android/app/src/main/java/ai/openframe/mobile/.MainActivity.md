## MainActivity.java

The main entry point `Activity` for the OpenFrame Android mobile application, built on the Capacitor `BridgeActivity` framework. It registers custom native plugins and determines which web bundle (built-in or over-the-air updated) the Capacitor bridge should load at startup.

## Key Components

- **`MainActivity`** - Extends `BridgeActivity`, overriding `onCreate` to configure the Capacitor bridge before it initializes.
- **Plugin Registration** - Registers four custom Capacitor plugins prior to bridge startup:
  - `NativeAuthPlugin` - native authentication bridge (mirrors iOS `NativeAuthPlugin`)
  - `NativeFilesPlugin` - native file system access
  - `ExternalLinksPlugin` - handles external link/browser interactions
  - `NativeUpdatePlugin` - manages over-the-air (OTA) app updates
- **Bundle Resolution** - Uses `NativeUpdate.get(this).bootDirectory(...)` to decide whether to serve the web content from an OTA-downloaded bundle directory or fall back to the APK's bundled assets.
- **`ServerPath` Configuration** - When an OTA bundle exists, sets `bridgeBuilder.setServerPath(...)` with `ServerPath.PathType.BASE_PATH` pointing to the bundle's directory before calling `super.onCreate(...)`.

## Usage Example

This class is not invoked directly by developers; it's declared as the launcher activity in `AndroidManifest.xml` and instantiated by the Android OS:

```java
// AndroidManifest.xml declares this as the launch activity.
// The Android system instantiates it automatically; no manual invocation needed.

// Equivalent logic, for reference:
File bundle = NativeUpdate.get(context).bootDirectory(isRecreated);
if (bundle != null) {
    bridgeBuilder.setServerPath(
        new ServerPath(ServerPath.PathType.BASE_PATH, bundle.getPath())
    );
}
```

This pattern mirrors the iOS counterpart (`MainViewController.capacitorDidLoad` / `instanceDescriptor`), ensuring both platforms consistently select between a freshly downloaded OTA bundle and the shipped app assets, while registering the same set of native plugins used across the app.
