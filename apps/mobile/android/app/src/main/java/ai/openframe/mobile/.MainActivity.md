# MainActivity.java

Android entry-point `Activity` for the OpenFrame Capacitor mobile app. Extends Capacitor's `BridgeActivity` to register native plugins and select the web bundle (over-the-air update or bundled APK assets) before the Capacitor bridge initializes.

## Key Components

- **`MainActivity`** — The main `BridgeActivity` subclass that bootstraps the Capacitor WebView bridge.
- **`onCreate(Bundle savedInstanceState)`** — Overrides the Android lifecycle method to:
  - Register custom native plugins (`NativeAuthPlugin`, `NativeFilesPlugin`, `ExternalLinksPlugin`, `NativeUpdatePlugin`) prior to bridge startup, mirroring the iOS equivalent (`MainViewController.capacitorDidLoad`).
  - Resolve which web bundle to serve via `NativeUpdate.get(this).bootDirectory(...)`, choosing between an over-the-air (OTA) update directory or the default APK assets, mirroring iOS `instanceDescriptor` logic.
  - Set a custom `ServerPath` on `bridgeBuilder` when an OTA bundle directory is found, pointing the WebView's base path to that directory.
  - Call `super.onCreate(savedInstanceState)` to let Capacitor finish bridge initialization with the configured settings.

## Usage Example

This class is wired automatically by the Android manifest as the launcher activity; it is not instantiated directly in app code.

```java
// AndroidManifest.xml declares this as the launcher activity:
// <activity android:name="ai.openframe.mobile.MainActivity" ... />

// Capacitor plugins registered here become available to the web layer via:
// import { NativeAuth } from 'native-auth-plugin';
// NativeAuth.someMethod();
```

The `savedInstanceState != null` check distinguishes an Activity re-creation (keeps the previously running bundle) from a fresh launch (re-evaluates the boot directory), ensuring consistent OTA update behavior across process restarts, such as after pressing Back.
