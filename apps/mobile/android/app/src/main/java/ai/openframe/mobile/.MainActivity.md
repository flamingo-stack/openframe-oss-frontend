Entry point Activity for the OpenFrame Android app, responsible for bootstrapping the Capacitor bridge and registering native plugins used by the hybrid WebView application.

## Key Components

- **`MainActivity`** — Extends Capacitor's `BridgeActivity`, serving as the single Android activity that hosts the Capacitor WebView bridge.
- **`onCreate(Bundle)`** — Overrides the Android lifecycle method to register app-specific native plugins (`NativeAuthPlugin`, `NativeFilesPlugin`) *before* calling `super.onCreate()`, ensuring the plugins are available to the bridge as soon as it initializes.

## Usage Example

This class is not invoked directly in code; it is wired up as the launcher activity in the Android manifest and instantiated automatically by the Android runtime:

```java
// AndroidManifest.xml declares this as the launcher activity:
// <activity android:name=".MainActivity" android:exported="true">
//     <intent-filter>
//         <action android:name="android.intent.action.MAIN" />
//         <category android:name="android.intent.category.LAUNCHER" />
//     </intent-filter>
// </activity>

// Plugin registration pattern (extend by adding more registerPlugin calls):
public class MainActivity extends BridgeActivity {
    @Override
    public void onCreate(Bundle savedInstanceState) {
        registerPlugin(NativeAuthPlugin.class);
        registerPlugin(NativeFilesPlugin.class);
        super.onCreate(savedInstanceState);
    }
}
```

**Note:** This mirrors the iOS counterpart (`MainViewController.capacitorDidLoad`), which registers the equivalent native plugins for the iOS bridge, keeping native plugin availability consistent across platforms. See the source at [`android/app/src/main/java/ai/openframe/mobile/MainActivity.java`](https://github.com/flamingo-stack/openframe-saas-mobile/blob/main/android/app/src/main/java/ai/openframe/mobile/MainActivity.java).
