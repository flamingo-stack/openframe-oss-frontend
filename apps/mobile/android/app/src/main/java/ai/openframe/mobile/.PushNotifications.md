## Overview

`PushNotifications.java` renders and manages Android tray notifications on behalf of the OpenFrame shell app, which receives data-only FCM push payloads (no system notification block). It builds notification channels, posts/updates/replaces notifications, wires up action buttons (approve/reject/reply), and handles retraction of previously shown notifications. It is the Android counterpart to iOS's `NotificationActions.swift`.

## Key Components

- **`createChannels(Context)`** — Creates the `of.push` (high importance) and `of.outcomes` (low importance) notification channels on Android O+.
- **`show(Context, String messageId, Map<String,String> data)`** — Posts a new notification from push payload data, including content intent and action buttons.
- **`markInProgress(Context, String notificationId, Map<String,String> extras, String actionId)`** — Replaces a notification with a progress spinner while an action executes.
- **`replace(...)`** — Replaces a notification with an outcome (success/failure), optionally restoring action buttons for retry, and echoing back reply text on failure.
- **`retract(Context, Map<String,String> data)`** — Cancels notifications named in the `NOTIFICATION_RETRACTED` event or `retractedIds` payload array.
- **`foregroundWork(Context)`** — Builds the foreground-service notification used by the expedited worker on API < 31.
- **`isOwnAction(String actionId)`** — Checks if an action ID belongs to this app's own approve/reject/reply actions.
- **`stringExtras(Bundle)`** — Extracts all String extras from a `Bundle` into a `Map`.
- **Constants** — Category values (`CATEGORY_APPROVAL`, `CATEGORY_REPLY`), action IDs (`ACTION_APPROVE`, `ACTION_REJECT`, `ACTION_REPLY`), data payload keys (`KEY_NOTIFICATION_ID`, `KEY_TITLE`, `KEY_BODY`, etc.), and limits (`MAX_REPLY_LENGTH`, `BODY_LIMIT`).

## Usage Example

```java
// On app startup
PushNotifications.createChannels(context);

// When an FCM data-only message arrives
Map<String, String> data = remoteMessage.getData();
PushNotifications.show(context, remoteMessage.getMessageId(), data);

// While handling an approval action from a notification button
PushNotifications.markInProgress(context, notificationId, extras, PushNotifications.ACTION_APPROVE);

// After the action completes
PushNotifications.replace(context, notificationId, extras,
    "Request Approved", "Handled successfully", false, null);

// When a retraction event arrives
PushNotifications.retract(context, data);
```

This class is package-private (`ai.openframe.mobile`) and intended for use by the FCM message receiver, notification action receiver, and background workers within the shell app.
