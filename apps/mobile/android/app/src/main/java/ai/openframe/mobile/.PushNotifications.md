## PushNotifications.java

Static helper class that renders, updates, and retracts Android tray notifications for OpenFrame's data-only FCM push payloads. It is the Android counterpart to iOS's `NotificationActions.swift`, handling notification channel creation, action buttons (approve/reject/reply), inline reply input, in-progress states, outcome replacement, and retraction of previously shown notifications.

## Key Components

- **Channel constants & `createChannels(Context)`** — Idempotently creates two notification channels: `of.push` (HIGH importance, for alerts like approval requests) and `of.outcomes` (LOW importance, for silent outcome updates).
- **Data/action key constants** — Defines the data-only payload keys (`notificationId`, `title`, `body`, `groupKey`, `pushCategory`, etc.) and custom intent actions (`of.approve`, `of.reject`, `of.reply`) used to route user interactions to `NotificationActionReceiver`.
- **`show(Context, String, Map<String, String>)`** — Posts a new tray notification from an incoming data-only FCM message, attaching a content intent (for tap-to-open deep linking) and action buttons based on category.
- **`markInProgress(Context, String, Map<String, String>, String)`** — Replaces a notification's buttons with an indeterminate progress indicator while an action is being processed.
- **`replace(...)`** — Posts the final outcome of a user action under the same notification identity, optionally restoring action buttons on failure (with echoed reply text).
- **`replaceWithStoreLink(...)`** — Replaces a notification with one that deep-links to an app store listing (used when the backend rejects an outdated client).
- **`retract(Context, Map<String, String>)`** — Cancels notifications by ID, either from an explicit retraction event or a batch of `retractedIds`.
- **`foregroundWork(Context)`** — Builds the foreground-service notification required for expedited background work on API < 31.
- **`isOwnAction(String)`** / **`stringExtras(Bundle)`** — Utility methods for identifying internally-handled actions and extracting intent extras as a string map.

## Usage Example

```java
// Called once at application startup
PushNotifications.createChannels(context);

// When a data-only FCM message arrives
Map<String, String> data = remoteMessage.getData();
PushNotifications.show(context, remoteMessage.getMessageId(), data);

// After the user taps "Approve" and the network call starts
PushNotifications.markInProgress(context, notificationId, extras, PushNotifications.ACTION_APPROVE);

// Once the approval result is known
PushNotifications.replace(context, notificationId, extras,
    "Request approved", "Done", /* retry */ false, null);

// Handling a retraction push
PushNotifications.retract(context, data);
```
