# OtaState.java

Immutable value type representing the state of an over-the-air (OTA) bundle update system for the mobile app, encoding which bundle is active, which is pending verification, and which versions have been marked bad. All state transitions are pure functions (no I/O), making each rule directly testable.

## Key Components

- **`OtaState`** — Immutable record of `active` version, `pending` version, trial `attempts` count, and the `bad` version list (oldest first, capped at `MAX_BAD`).
- **`OtaState.EMPTY`** — Default state with no active/pending bundle.
- **`OtaState.Boot`** — Result of resolving boot state: contains the new `OtaState`, the `version` to boot from (null = built-in bundle), whether it's a `trial`, and any `reverted` version.
- **`Usable`** — Callback interface used to test whether a bundle's files are still valid on disk.
- **`of(...)`** — Validated factory constructor for `OtaState`.
- **`resolveBoot(...)`** — Decides which bundle to boot, discarding bundles at/below the built-in version or that fail usability checks, and reverting a pending bundle that exceeded `MAX_TRIAL_ATTEMPTS`.
- **`applyReady(...)`** — Promotes a pending bundle to active once the app has successfully booted from it as a trial.
- **`applyDrop(...)`** — Clears active/pending state (e.g. on explicit rollback), preserving the bad list.
- **`applyNothing(...)`** — Reconciles state when the server reports no update, discarding an unconfirmed pending bundle if the environment reverted to the active version.
- **`applyDownloaded(...)`** — Records a newly downloaded bundle as pending.
- **`markBad(...)`** — Adds a version to the bad list (moves it to most-recent if already present).
- **`staleDirectories(...)`** — Computes which on-disk bundle directories are safe to delete.
- **`toJson()` / `parse(byte[])`** — Serialization to/from a minimal JSON format with schema versioning; malformed or unrecognized data resolves to `EMPTY`.

## Usage Example

```java
// Resolve what to boot at app startup
OtaState.Boot boot = OtaState.resolveBoot(storedState, builtinVersion, version ->
    new File(bundleDir, version + "/index.html").exists());

String versionToLoad = boot.version; // null means built-in bundle
OtaState newState = boot.state;

// After the web view confirms it booted successfully
if (boot.trial) {
    newState = OtaState.applyReady(newState, boot.version, true);
}

// When a new bundle finishes downloading
newState = OtaState.applyDownloaded(newState, "1.2.3");

// Persist state
byte[] json = newState.toJson();
OtaState restored = OtaState.parse(json);

// Clean up unused bundle directories
List<String> toDelete = OtaState.staleDirectories(onDiskVersions, newState, boot.version);
```
