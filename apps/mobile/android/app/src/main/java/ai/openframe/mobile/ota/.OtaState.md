Immutable value object representing the state of over-the-air (OTA) bundle updates for the mobile app, encoding which bundle is active, which is pending trial, how many boot attempts it has had, and a bounded history of bad (rejected) versions. All transitions are pure functions from one `OtaState` to the next, enabling direct unit testing without I/O side effects.

## Key Components

- **`OtaState`** – immutable record holding `active`, `pending`, `attempts`, and `bad` (list of rejected versions, oldest first, capped at `MAX_BAD`).
- **`OtaState.of(...)`** – validated factory constructor enforcing version format and attempt invariants.
- **`Boot`** – nested result type returned by `resolveBoot`, carrying the next state plus which version to boot and whether it's a trial.
- **`Usable`** – functional interface to test whether a bundle directory is still valid (e.g., has `index.html`).
- **`resolveBoot(state, builtinVersion, usable)`** – computes boot decision at app startup: discards unusable/outdated bundles, rejects a pending bundle that exhausted `MAX_TRIAL_ATTEMPTS`, and increments trial attempts otherwise.
- **`applyReady`** – promotes a pending trial bundle to active once the booted page confirms it.
- **`applyDrop`** – clears active/pending state (e.g., on fatal error), preserving the bad list.
- **`applyNothing`** – reverts to active bundle when the server reports no update, unless the currently running trial is the pending one.
- **`applyDownloaded`** – sets a newly downloaded version as pending with reset attempts.
- **`markBad(state, version)`** – adds a version to the bad list.
- **`staleDirectories(names, state, bootedVersion)`** – identifies on-disk bundle directories safe to delete.
- **`toJson()` / `parse(byte[])`** – serialization to/from a minimal hand-rolled JSON format (schema-versioned).

## Usage Example

```java
// At boot time
OtaState.Boot boot = OtaState.resolveBoot(savedState, builtinVersion, version -> hasIndexHtml(version));
loadWebView(boot.version, boot.trial);
persist(boot.state.toJson());

// When server reports no update available
OtaState next = OtaState.applyNothing(state, payloadVersion, boot.version, boot.trial);

// When the booted trial page confirms itself
OtaState confirmed = OtaState.applyReady(next, boot.version, boot.trial);

// After downloading a new bundle
OtaState withDownload = OtaState.applyDownloaded(confirmed, "2.3.0");

// Cleanup stale directories
List<String> toDelete = OtaState.staleDirectories(listVersionDirs(), withDownload, boot.version);
```
