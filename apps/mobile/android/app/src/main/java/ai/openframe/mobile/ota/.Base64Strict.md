A strict, dependency-free Base64 decoder that validates canonical formatting, used by OpenFrame's mobile OTA (over-the-air update) module to decode update payloads with confidence that the encoded text is exactly what a compliant encoder would have produced.

## Key Components

- **`Base64Strict`** — final utility class with a private constructor; cannot be instantiated.
- **`decode(String text)`** — decodes a Base64 string to a `byte[]`, returning `null` if the input is not canonical (wrong length, invalid characters, incorrect padding, or non-zero unused bits in the last significant digit).
- **`digit(char c)`** — private helper mapping a single Base64 alphabet character to its 6-bit numeric value, or `-1` if the character is not part of the standard alphabet.

## Why It Exists

Unlike `android.util.Base64` or `java.util.Base64` (API 26+, above this app's minimum SDK), this implementation enforces **strict canonical form**:
- Length must be a multiple of 4.
- Only the standard alphabet (`A-Z`, `a-z`, `0-9`, `+`, `/`) is accepted — no URL-safe variants, no whitespace.
- Padding (`=`) must appear only where required.
- Unused bits in the final encoded group must be zero, matching exactly what a standards-compliant encoder would emit.

This guarantees that decode-then-re-encode round-trips produce identical text, which is the invariant release scripts rely on when verifying OTA update integrity.

## Usage Example

```java
import ai.openframe.mobile.ota.Base64Strict;

String encoded = "SGVsbG8sIFdvcmxkIQ==";
byte[] decoded = Base64Strict.decode(encoded);

if (decoded == null) {
    // Input was not canonical Base64 — reject the OTA payload
    throw new IllegalArgumentException("Invalid or non-canonical Base64 payload");
}

String message = new String(decoded, java.nio.charset.StandardCharsets.UTF_8);
// message == "Hello, World!"
```
