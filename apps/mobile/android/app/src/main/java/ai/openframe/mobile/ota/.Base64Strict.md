A strict, dependency-free Base64 decoder that enforces canonical encoding rules, rejecting any input that doesn't exactly match what a standard encoder would produce (correct padding, zeroed unused bits, no whitespace, standard alphabet only).

## Key Components

- **`Base64Strict`** — final utility class with a private constructor (non-instantiable).
- **`decode(String text)`** — decodes a canonical Base64 string into a `byte[]`, returning `null` if the input is malformed, improperly padded, uses non-standard characters, or has non-zero unused bits in the final digit.
- **`digit(char c)`** — private helper mapping a single Base64 character to its 6-bit numeric value (`0`-`63`), or `-1` if the character is invalid.

## Usage Example

```java
import ai.openframe.mobile.ota.Base64Strict;

byte[] data = Base64Strict.decode("SGVsbG8h"); // valid canonical Base64
if (data == null) {
    // input was not canonical Base64 (bad padding, bad chars, or non-zero unused bits)
    throw new IllegalArgumentException("Invalid OTA payload encoding");
}

String decoded = new String(data, java.nio.charset.StandardCharsets.UTF_8);
```

This class is used instead of `android.util.Base64` or `java.util.Base64` to guarantee that only exact, re-encodable canonical Base64 is accepted — a property enforced by the project's release scripts when validating OTA update payloads.
