Utility class for parsing and comparing strict semantic version strings in the format `x.y.z`, used by the OTA (over-the-air update) module to validate and order version numbers.

## Key Components

- **`isValid(String text)`** — Returns `true` if the given string is a valid `x.y.z` version, where each component is either `0` or a digit `1-9` followed by up to eight more ASCII digits (no leading zeros, no sign, no Unicode digits).
- **`compare(String a, String b)`** — Compares two version strings component-by-component (major, minor, patch) and returns a negative number, zero, or a positive number, similar to `Integer.compare`. Throws `IllegalArgumentException` if either string is not a valid version.
- **`parts(String text)`** *(private)* — Core parser that extracts the three integer components from a version string, enforcing strict formatting rules (no leading zeros, exactly two dots, digits only, max 9 digits per component to safely fit an `int`). Returns `null` if the string doesn't conform.

This class is `final` with a private constructor, serving purely as a static utility holder—no instances can be created.

## Usage Example

```java
import ai.openframe.mobile.ota.Version;

// Validate version strings
boolean ok = Version.isValid("1.2.3");     // true
boolean bad = Version.isValid("1.02.3");   // false (leading zero)
boolean bad2 = Version.isValid("1.2");     // false (missing component)

// Compare versions for update checks
int result = Version.compare("1.2.3", "1.10.0");
if (result < 0) {
    System.out.println("An update is available");
} else if (result == 0) {
    System.out.println("Already up to date");
} else {
    System.out.println("Local version is newer");
}

// Invalid input throws an exception
try {
    Version.compare("abc", "1.0.0");
} catch (IllegalArgumentException e) {
    System.out.println("Not a valid version string");
}
```
