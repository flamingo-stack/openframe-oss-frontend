Utility class for parsing and comparing semantic version strings in the format `x.y.z`, used for OTA (over-the-air) update version validation and ordering in the OpenFrame mobile app.

## Key Components

- **`isValid(String text)`** — Returns `true` if the given string is a strictly-formatted `x.y.z` version (each segment is `0` or a non-zero digit followed by up to eight more ASCII digits, with no sign, suffix, or non-ASCII characters).
- **`compare(String a, String b)`** — Compares two version strings numerically, segment by segment, and returns `-1`, `0`, or `1` similar to `Comparator` semantics. Throws `IllegalArgumentException` if either input is not a valid version.
- **`parts(String text)`** *(private)* — Parses a version string into a 3-element `int[]`, enforcing strict formatting rules (no leading zeros except for a single `0`, max 9 digits per segment, exact dot-separated structure). Returns `null` if the string is malformed.

This class is `final` with a private constructor, making it a non-instantiable static utility.

## Usage Example

```java
// Validate a version string
boolean valid = Version.isValid("1.2.3"); // true
boolean invalid = Version.isValid("1.02.3"); // false (leading zero)

// Compare two versions
int result = Version.compare("1.2.3", "1.10.0"); // -1, since 2 < 10

// Guard before comparing
String incoming = fetchedVersion();
if (Version.isValid(incoming) && Version.compare(incoming, currentVersion) > 0) {
    triggerOtaUpdate();
}
```

Use `isValid` to validate untrusted version strings (e.g., from OTA update manifests) before calling `compare`, since `compare` throws on malformed input.
