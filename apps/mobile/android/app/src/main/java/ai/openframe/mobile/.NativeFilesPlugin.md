## NativeFilesPlugin.java

Capacitor plugin providing native Android file picking, upload, and download for the OpenFrame mobile app. It is the Android counterpart to the iOS `NativeFilesPlugin.swift`, exposing the same `NativeFiles` JS interface consumed by `openframe-frontend`. It works around Capacitor WebView limitations where browser-native download/upload patterns (`<a download>`, base64 blobs, CORS-restricted presigned URLs) silently fail, by performing file I/O natively via `HttpURLConnection` and `ContentResolver`.

## Key Components

- **`pickFiles(PluginCall)`** — Launches `ACTION_OPEN_DOCUMENT` to pick one or more files (including Photos), guarded against concurrent picks via `pickInFlight`. Resolves with staged file metadata (`path`, `name`, `mimeType`, `size`).
- **`handlePickResult(PluginCall, ActivityResult)`** — `@ActivityCallback` that resolves selected `content://` URIs, copies each into a local cache (`stageSelection`), and returns an empty array on cancellation.
- **`uploadFile(PluginCall)`** — Streams a previously staged file to a presigned URL via `PUT`, using `setFixedLengthStreamingMode` to avoid buffering. Validates the path was staged by this plugin (`isStaged`) before deleting it post-upload.
- **`downloadFile(PluginCall)`** — Fetches a URL via `HttpURLConnection` GET and saves the result into the public Downloads collection (via `deliver`), returning `savedToDownloads`.
- **`io`** — Single-thread `ExecutorService` used for all blocking I/O, catching broad `Exception` to avoid crashing the process from executor tasks.
- **Helper methods** — `stageSelection`, `displayName`, `prepareStagingFile`, `guessMimeType`, `safeFileName`, `deleteStagingEntry`, `copy`, `describe` support staging, MIME resolution, and cleanup.

## Usage Example

```java
// Registered automatically via @CapacitorPlugin(name = "NativeFiles")
// Frontend usage (TypeScript) calls into this plugin transparently:
//
// const { files } = await NativeFiles.pickFiles({ multiple: true });
// await NativeFiles.uploadFile({ path: files[0].path, url: presignedUrl });
// await NativeFiles.downloadFile({ url: fileUrl, fileName: "report.pdf" });

@CapacitorPlugin(name = "NativeFiles")
public class NativeFilesPlugin extends Plugin {
    @PluginMethod
    public void pickFiles(PluginCall call) {
        // opens ACTION_OPEN_DOCUMENT and resolves staged file list
    }
}
```
