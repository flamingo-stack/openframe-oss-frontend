## Bytes.java

Package-private utility class providing byte array helper methods used by the OTA (over-the-air update) module, including hex encoding, SHA-256 digest creation, bounded stream reading, and byte pattern searching.

## Key Components

- **`Bytes`** — Final utility class with a private constructor to prevent instantiation.
- **`ascii(String text)`** — Encodes a `String` into a byte array using US-ASCII charset.
- **`hex(byte[] bytes)`** — Converts a byte array into its lowercase hexadecimal `String` representation.
- **`sha256()`** — Returns a `MessageDigest` instance configured for SHA-256, wrapping the checked `NoSuchAlgorithmException` into an unchecked `IllegalStateException` since SHA-256 is guaranteed available on every Java platform.
- **`readAtMost(InputStream in, int limit)`** — Reads from an `InputStream` up to `limit` bytes, returning `null` if the stream exceeds that limit (useful for safely bounding downloads). Pass `Integer.MAX_VALUE` for no practical limit.
- **`indexOf(byte[] haystack, byte[] needle, int from)`** — Performs a naive substring search for a byte sequence within another byte array, starting at a given offset.

## Usage Example

```java
// Compute SHA-256 hex digest of some data
MessageDigest digest = Bytes.sha256();
digest.update(Bytes.ascii("firmware-payload"));
String hexDigest = Bytes.hex(digest.digest());

// Safely read a response body capped at 10 MB
byte[] body = Bytes.readAtMost(inputStream, 10 * 1024 * 1024);
if (body == null) {
    throw new IOException("Response exceeded size limit");
}

// Locate a marker sequence within a byte buffer
int index = Bytes.indexOf(body, Bytes.ascii("END_MARKER"), 0);
```

This class is intended for internal use within the `ai.openframe.mobile.ota` package to support OTA update verification and streaming logic.
