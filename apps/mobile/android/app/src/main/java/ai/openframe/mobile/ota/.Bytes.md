Utility class providing byte-level helper operations for the OTA (over-the-air update) module, including ASCII encoding, hex formatting, SHA-256 digest creation, bounded stream reading, and byte-array pattern searching.

## Key Components

- **`ascii(String text)`** - Converts a string to a byte array using US-ASCII encoding.
- **`hex(byte[] bytes)`** - Converts a byte array into its lowercase hexadecimal string representation.
- **`sha256()`** - Returns a `MessageDigest` instance configured for SHA-256, wrapping the checked exception since SHA-256 is guaranteed available on all Java platforms.
- **`readAtMost(InputStream in, int limit)`** - Reads an input stream into a byte array, returning `null` if the stream would exceed `limit` bytes, avoiding unbounded memory allocation. Serves as a substitute for `InputStream.readAllBytes()` on platforms below API 33.
- **`indexOf(byte[] haystack, byte[] needle, int from)`** - Searches for the first occurrence of a byte sequence (`needle`) within another (`haystack`), starting at a given offset.

This is a `final` utility class with a private constructor, preventing instantiation. Most methods are package-private, intended for internal use within the `ai.openframe.mobile.ota` package, except `readAtMost`, which is public.

## Usage Example

```java
import java.io.InputStream;

// Compute a SHA-256 hex digest from encoded ASCII bytes
MessageDigest digest = Bytes.sha256();
digest.update(Bytes.ascii("firmware-payload"));
String checksum = Bytes.hex(digest.digest());

// Safely read a stream, capping memory usage at 1 MB
InputStream in = getUpdateStream();
byte[] data = Bytes.readAtMost(in, 1024 * 1024);
if (data == null) {
    throw new IOException("Update payload exceeds size limit");
}

// Locate a marker sequence within binary data
int offset = Bytes.indexOf(data, Bytes.ascii("END-OF-HEADER"), 0);
```
