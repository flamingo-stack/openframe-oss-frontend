Process-level initialization entry point for the OpenFrame Android app, serving as the process-wide counterpart to iOS's `AppDelegate`. It bootstraps components that must function independently of any `Activity`, since Android can spawn a process from a push notification or tray action without ever launching `MainActivity`.

## Key Components

- **`OpenFrameApplication`** — `Application` subclass that runs once per process at startup, before any `Activity` is created.
- **`onCreate()`** — Overridden lifecycle method that wires up process-wide services:
  - `TokenLifecycle.get(this).installObservers()` — registers observers to manage the authentication/push token lifecycle independent of the Capacitor bridge.
  - `NativeUpdate.get(this).installObservers()` — sets up observers for native app update handling.
  - `PushNotifications.createChannels(this)` — creates Android notification channels required for displaying push notifications.

## Usage Example

This class is not invoked directly by developers — it's registered in `AndroidManifest.xml` as the app's `Application` class and instantiated automatically by the Android OS:

```xml
<application
    android:name=".OpenFrameApplication"
    ... >
</application>
```

Once registered, `onCreate()` runs automatically whenever Android starts a new process for this app — whether triggered by the user opening the app, a push notification arriving, or a background task — ensuring token management, update checks, and notification channels are always initialized before any other component runs.

## Notes

Unlike the Capacitor bridge (tied to `MainActivity`'s lifecycle), the observers installed here persist for the entire process lifetime, making this the correct place for any logic that must survive without a visible UI, such as handling silent push payloads or background token refresh.
