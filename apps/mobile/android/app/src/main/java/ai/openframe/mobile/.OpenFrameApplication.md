# OpenFrameApplication.java

Process-level `Application` subclass for the OpenFrame Android app, serving as the entry point for initialization that must run independently of any `Activity`. This is necessary because the Capacitor bridge only exists while `MainActivity` is alive, but background work triggered by push notifications or tray actions can start a process with no Activity present at all.

## Key Components

- **`OpenFrameApplication`** — `Application` subclass that bootstraps process-wide singletons and observers before any Activity is created.
- **`onCreate()`** — Overridden lifecycle method that wires up:
  - `TokenLifecycle.get(this).installObservers()` — registers observers responsible for managing authentication/token state across the app's process lifecycle.
  - `NativeUpdate.get(this).installObservers()` — registers observers for native update checks/handling independent of UI.
  - `PushNotifications.createChannels(this)` — creates Android notification channels required for push notifications to be delivered correctly.

## Usage Example

This class is not instantiated directly by developers; it is declared in the Android manifest and instantiated automatically by the Android OS whenever the app's process starts.

```java
// AndroidManifest.xml registration (conceptual, not Java)
// <application android:name=".OpenFrameApplication" ...>

// Example of what happens internally once the process launches:
public class OpenFrameApplication extends Application {
    @Override
    public void onCreate() {
        super.onCreate();
        TokenLifecycle.get(this).installObservers();
        NativeUpdate.get(this).installObservers();
        PushNotifications.createChannels(this);
    }
}
```

Because `onCreate()` runs for **every** process start — whether triggered by a user tapping the app icon, a push notification arriving, or a background tray action — this class guarantees that token management, update checks, and notification channels are always initialized, even when `MainActivity` and the Capacitor bridge are never created.
