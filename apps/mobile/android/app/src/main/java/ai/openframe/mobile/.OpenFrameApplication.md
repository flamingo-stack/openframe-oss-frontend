# OpenFrameApplication.java

The process-level entry point for the Android application, serving as the counterpart to iOS's `AppDelegate`. Unlike the Capacitor bridge (which only exists while `MainActivity` is alive), this class ensures core services are initialized whenever the process starts—including cases where the app is launched by a push notification or tray action with no visible Activity.

## Key Components

- **`OpenFrameApplication`** — Custom `Application` subclass that bootstraps process-wide services before any Activity is created.
- **`onCreate()`** — Overridden lifecycle method that performs two critical initializations:
  - `TokenLifecycle.get(this).installObservers()` — Sets up observers to manage authentication/push token lifecycle events (e.g., refresh, registration) independent of UI state.
  - `PushNotifications.createChannels(this)` — Registers Android notification channels required for displaying push notifications, which must exist before any notification is posted.

## Usage Example

This class is not instantiated directly in code—it's declared in the Android manifest so the OS invokes it automatically at process startup:

```java
// AndroidManifest.xml registration (conceptual reference)
// <application android:name="ai.openframe.mobile.OpenFrameApplication" ...>

// Once registered, Android automatically calls onCreate()
// before any Activity, Service, or BroadcastReceiver in this process runs.
public class OpenFrameApplication extends Application {

    @Override
    public void onCreate() {
        super.onCreate();
        // Ensures token observers and notification channels
        // are ready even if the app starts from a push/tray action
        TokenLifecycle.get(this).installObservers();
        PushNotifications.createChannels(this);
    }
}
```

This guarantees that critical background services—like token refresh handling and notification channel setup—are always available, regardless of whether the app was launched via a user tap on the app icon, a push notification, or a background service trigger.
