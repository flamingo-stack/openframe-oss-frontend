## TokenLifecycle.java

Shell-owned singleton managing the in-memory access/refresh token pair, single-flight token refresh against the gateway BFF, and propagation of token state changes to the web view. This is the Android port of `ios/App/App/TokenLifecycle.swift`, preserving the same taxonomy, tunables, and custody rules while adapting to Android's process/lifecycle model (Capacitor plugin, FCM service, broadcast receivers, and workers all sharing one process singleton).

All state reads/writes are serialized on a single-thread "store queue" executor; the actual refresh POST runs on OkHttp's threads, with only the outcome returned to the queue.

## Key Components

- **`TokenLifecycle`** — Process singleton (`get(Context)`) coordinating token custody, refresh, and lifecycle observers.
- **`Code`** — Constants for refresh rejection reasons surfaced to the web view (`UNREACHED`, `UNKNOWN`, `HELD`, `DEVICE_LOCKED`, `BIOMETRIC_LOCKED`, `NO_HOST`, `SESSION_REPLACED`).
- **`RefreshResult`** — Outcome of a refresh call for the caller: `TOKENS` (rotated/fresh pair), `SESSION_OVER` (custody dropped), or `FAILED` (unchanged, transient).
- **`GateResult`** — Result of biometric-gate operations (`GATED`, `NOTHING_HELD`, `WRITE_FAILED`).
- **`Outcome`** (private) — Internal result of a single POST to `/oauth/refresh`, distinguishing `ROTATED`/`REJECTED` from network-level `UNREACHED`/`UNKNOWN` to avoid re-presenting a possibly-consumed refresh token.
- **`Waiter`** (private) — Represents a caller blocked on an in-flight refresh, tagged with the session epoch it joined.
- **`installObservers()`** — Wires `ProcessLifecycleOwner` to start/stop polling and trigger foreground refresh logic.
- **`isForeground()` / `isGatedAndUnprimed()`** — Query helpers used by push-notification handling to decide whether a tray action can act in-process or must launch the app.
- **`store()`** — Exposes the underlying `SecureTokenStore` for biometric primitive orchestration by the plugin.

## Usage Example

```java
// Obtain the process-wide singleton (application context only)
TokenLifecycle lifecycle = TokenLifecycle.get(context);

// Wire lifecycle observers once, from Application.onCreate
lifecycle.installObservers();

// Check whether a background handler (e.g. FCM push) can act without the app
if (lifecycle.isGatedAndUnprimed()) {
    // No unlocked credential in this process — must open the app UI instead
    // of trying to read the token store directly.
}

// Access the underlying secure store (policy stays in TokenLifecycle)
SecureTokenStore store = lifecycle.store();
```

Related tunables (refresh margin, poll interval, retry delays) mirror the iOS implementation in [`TokenLifecycle.swift`](https://github.com/flamingo-stack/openframe-saas-mobile/blob/main/ios/App/App/TokenLifecycle.swift) for cross-platform consistency.
