## TokenLifecycle.java

Android counterpart to `ios/App/App/TokenLifecycle.swift` — a shell-owned, process-singleton component responsible for the in-memory access/refresh token pair, single-flight token refresh against the gateway BFF, and propagating every token-state change to the Capacitor web view. All state reads/writes are serialized on a dedicated single-thread "store queue," while the actual HTTP POST runs on OkHttp's threads, with only the outcome marshaled back onto the queue.

Unlike the Capacitor plugin (which only exists while `MainActivity` is alive), this class is reachable from components with no plugin and no web view — `FirebaseMessagingService`, `BroadcastReceiver`, `Worker` — making it a true process singleton rather than a bridge-scoped object.

## Key Components

- **`TokenLifecycle`** — the singleton class itself; accessed via `get(Context)`.
- **`Code`** — string constants for reject codes surfaced to the web view (`UNREACHED`, `UNKNOWN`, `ANSWERED_ERROR`, `HELD`, `DEVICE_LOCKED`, `BIOMETRIC_LOCKED`, `NO_HOST`, `SESSION_REPLACED`).
- **`RefreshResult`** — outcome of a refresh call for the caller: `TOKENS`, `SESSION_OVER`, or `FAILED`, with factory methods `tokens()`, `sessionOver()`, `failed()`.
- **`GateResult`** — enum returned by biometric gating (`GATED`, `NOTHING_HELD`, `WRITE_FAILED`).
- **`Outcome`** — result of a single POST to `/oauth/refresh` (`ROTATED`, `REJECTED`, `UNREACHED`, `ANSWERED_ERROR`, `UNKNOWN`), distinguishing safe-to-retry from ambiguous-in-flight failures.
- **`Waiter`** — internal record of a caller queued on an in-flight refresh, tagged with the session epoch it joined.
- Tunables: `REFRESH_MARGIN_MS`, `POLL_INTERVAL_MS`, `RETRY_DELAYS_MS`, `LOST_ROTATION_RETRY_AFTER_MS`, `LOST_ROTATION_RETRY_WITHIN_MS` govern refresh timing and retry safety windows aligned with server-side grace periods.

## Usage Example

```java
// Obtain the process singleton from any Android component
TokenLifecycle lifecycle = TokenLifecycle.get(context);

// Typical call site (e.g., from a plugin or background worker)
lifecycle.refresh(force, rejectedAccessToken, "push notification", result -> {
    switch (result.kind) {
        case TOKENS:
            // use result.pair for the refreshed access/refresh tokens
            break;
        case SESSION_OVER:
            // gateway rejected the refresh token; sign the user out
            break;
        case FAILED:
            // transient failure; result.code / result.message describe why
            break;
    }
});
```

**Note:** This class is internal (`final class`, package-private) and intended to be used only within the `ai.openframe.mobile` shell module, primarily by the Capacitor plugin layer and background notification handlers.
