## EnvCopy.java

Copies the `window.__ENV` script element from the device's built-in `index.html` into an over-the-air (OTA) bundle's staged `index.html`, operating entirely on raw bytes. This ensures an OTA bundle always inherits the environment configuration of the native binary it is deployed into, rather than carrying its own baked-in environment — the element is injected right after the `<head>` tag.

## Key Components

- **`element(byte[] builtinHtml)`** - Locates and extracts the `<script>window.__ENV...</script>` element from the built-in HTML; throws `OtaError` with code `NO_ENV` if not found.
- **`assertTarget(byte[] stagedHtml)`** - Validates the staged bundle HTML is a safe injection target: throws `OtaError` with code `HAS_ENV` if it already contains a `window.__ENV` script, or `NO_HEAD` if it lacks a `<head>` tag.
- **`insert(byte[] element, byte[] stagedHtml)`** - Inserts the extracted env element immediately after `<head>` in the staged HTML, returning the new byte array.
- **`carries(byte[] html, byte[] element)`** - Checks whether a given HTML byte array already contains the specified element.
- **`copy(byte[] builtinHtml, byte[] stagedHtml)`** - Convenience method combining `element()` and `insert()` to perform the full copy operation in one call.

## Usage Example

```java
import ai.openframe.mobile.ota.EnvCopy;
import ai.openframe.mobile.ota.OtaError;

byte[] builtinHtml = readBuiltinIndexHtml();
byte[] stagedHtml = readStagedBundleIndexHtml();

try {
    byte[] mergedHtml = EnvCopy.copy(builtinHtml, stagedHtml);
    writeStagedBundleIndexHtml(mergedHtml);
} catch (OtaError e) {
    switch (e.code) {
        case NO_ENV -> logger.error("Built-in index.html missing window.__ENV");
        case HAS_ENV -> logger.error("Bundle already contains window.__ENV");
        case NO_HEAD -> logger.error("Bundle index.html missing <head> tag");
    }
    throw e;
}
```

Validation order matches the shared test fixtures (`fixtures/env-cases.json`): `NO_ENV` is checked first (during extraction), followed by `HAS_ENV`, then `NO_HEAD` (during target validation).
