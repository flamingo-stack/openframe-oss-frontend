`EnvCopy` copies the `window.__ENV` script element from the app binary's built-in `index.html` into an over-the-air (OTA) bundle's `index.html`, ensuring a downloaded bundle always runs with the environment configuration of the binary it lands in rather than bringing its own. All operations work directly on raw bytes with literal byte-pattern matching.

## Key Components

- **`element(byte[] builtinHtml)`** — Extracts the `<script>window.__ENV...</script>` element from the built-in `index.html`. Throws `OtaError` with code `NO_ENV` if the element is not found.
- **`assertTarget(byte[] stagedHtml)`** — Validates that the staged bundle's `index.html` is a valid insertion target: it must not already contain a `window.__ENV` script (`HAS_ENV`) and must contain a `<head>` tag (`NO_HEAD`).
- **`insert(byte[] element, byte[] stagedHtml)`** — Inserts the extracted env element immediately after the opening `<head>` tag of the staged HTML, returning the new byte array.
- **`carries(byte[] html, byte[] element)`** — Checks whether a given HTML byte array already contains the specified env element.
- **`copy(byte[] builtinHtml, byte[] stagedHtml)`** — Convenience method combining `element()` and `insert()` to perform the full copy operation in one call.

## Usage Example

```java
byte[] builtinHtml = readBuiltinIndexHtml();
byte[] stagedHtml = readStagedBundleIndexHtml();

try {
    byte[] patchedHtml = EnvCopy.copy(builtinHtml, stagedHtml);
    writeStagedBundleIndexHtml(patchedHtml);
} catch (OtaError e) {
    switch (e.code()) {
        case NO_ENV -> log.error("Built-in index.html missing window.__ENV", e);
        case HAS_ENV -> log.error("Bundle already contains window.__ENV", e);
        case NO_HEAD -> log.error("Bundle index.html missing <head> tag", e);
    }
    throw e;
}
```

This is used during OTA bundle staging to guarantee the bundle inherits the correct environment configuration (API endpoints, feature flags, etc.) from the installed binary, as validated against fixtures in `fixtures/env-cases.json`.
