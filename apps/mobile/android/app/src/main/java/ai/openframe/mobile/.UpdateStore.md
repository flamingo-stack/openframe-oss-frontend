# UpdateStore.java

Implements `OtaSession.Store` to manage persistent OTA (over-the-air) update state and bundle storage on disk, using a no-backup directory so that unverified downloaded bundles are never restored from device backups.

## Key Components

- **`UpdateStore(File noBackupFilesDir)`** — Constructor that sets up the directory layout: `ota/bundles` (installed bundle versions), `ota/staging` (in-progress downloads/unpacking), and `ota/state.json` (atomic state file).
- **`read()`** — Reads and parses the persisted `OtaState` from `state.json`, treating a missing file as a first-launch empty state (`OtaState.EMPTY`).
- **`write(OtaState next)`** — Atomically persists the given `OtaState` using `AtomicFile`, ensuring the root directory exists first and rolling back on failure.
- **`index(String version)`** — Reads and returns the raw bytes of `index.html` for a given bundle version, or `null` if unreadable.
- **`bundleDir(String version)`** — Resolves the on-disk directory for a given validated version string.
- **`staging()`** — Lazily creates and returns the staging directory used for unpacking new bundles.
- **`wipeStaging()`** — Removes all contents of the staging directory via `BundleRemoval`.
- **`install(File unpacked, String version)`** — Atomically moves an unpacked bundle from staging into its final versioned directory via rename, clearing any stale directory first.
- **`removeStale(OtaSession session)`** — Deletes old bundle directories no longer needed, as determined by the active `OtaSession`, while preserving the directory currently serving the web view.

## Usage Example

```java
File noBackupDir = context.getNoBackupFilesDir();
UpdateStore store = new UpdateStore(noBackupDir);

OtaState state = store.read();

File stagingDir = store.staging();
// ... download and unpack bundle into stagingDir ...

store.install(stagingDir, "1.2.3");
store.write(state.withInstalledVersion("1.2.3"));

byte[] html = store.index("1.2.3");

OtaSession session = new OtaSession(store);
store.removeStale(session);
```

This class is intended for internal use within the `ai.openframe.mobile.ota` update pipeline and is typically wired into an `OtaSession` rather than used directly by application code.
