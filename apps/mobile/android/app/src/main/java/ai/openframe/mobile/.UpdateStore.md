## UpdateStore.java

Persists OTA (over-the-air) update state and bundle files on disk for the mobile app's self-update mechanism. It implements `OtaSession.Store` and manages a private directory structure under the app's no-backup files directory, storing downloaded update bundles, a staging area for in-progress unpacking, and atomic state persistence so an interrupted write never corrupts the update tracking data.

## Key Components

- **`UpdateStore(File noBackupFilesDir)`** — Constructor that sets up the `ota` root directory with `bundles/`, `staging/`, and an `AtomicFile`-backed `state.json`.
- **`read()` / `write(OtaState)`** — Atomically read/write the persisted `OtaState`; treats a missing file as first-launch (`OtaState.EMPTY`) and logs/rethrows on genuine I/O errors.
- **`index(String version)`** — Reads the `index.html` page for a given bundle version into a byte array, returning `null` on any failure.
- **`bundleDir(String version)`** — Resolves the directory for a specific bundle version (version strings are pre-validated, never raw paths).
- **`staging()` / `wipeStaging()`** — Lazily creates and clears the staging directory used for unpacking new bundles before install.
- **`install(File unpacked, String version)`** — Atomically moves (renames) an unpacked bundle into its final versioned directory, removing any stale pre-existing directory first.
- **`removeStale(OtaSession session)`** — Deletes old bundle directories no longer needed, as determined by the session, excluding the directory currently serving the web view.

## Usage Example

```java
UpdateStore store = new UpdateStore(context.getNoBackupFilesDir());

// Read current OTA state (first launch returns OtaState.EMPTY)
OtaState state = store.read();

// Persist updated state
store.write(state.withNewVersion("1.2.3"));

// Prepare staging area, unpack a bundle, then install it
File stagingDir = store.staging();
// ... download and unpack into stagingDir ...
store.install(stagingDir, "1.2.3");

// Serve the index page for the installed version
byte[] html = store.index("1.2.3");

// Clean up old bundle directories
store.removeStale(otaSession);
```

Instances are intended for internal use within the `ai.openframe.mobile.ota` update pipeline, typically constructed once per `OtaSession`.
