## NativeAuthPlugin.java

Capacitor plugin providing native Android authentication capabilities for the OpenFrame mobile app, mirroring the iOS `NativeAuthPlugin.swift` implementation to keep the shared frontend (`native-shell.ts`) contract identical across platforms. It handles OAuth login via Chrome Custom Tabs, dev-ticket-to-token exchange, biometric-gated token access, and safe-area inset reporting.

## Key Components

- **`NativeAuthPlugin`** — `Capacitor` plugin registered as `NativeAuth`, exposing JS-callable methods.
- **`start(PluginCall)`** — Launches OAuth login in a Chrome Custom Tab (RFC 8252 flow), tracking a single pending login call resolved via deep-link callback.
- **`handleOnNewIntent(Intent)`** — Handles the `com.openframe.app://auth` deep link, resolving the pending login call with the callback URL.
- **`handleOnResume()`** — Detects user-cancelled login (Custom Tab dismissed without a deep link) and rejects with `USER_CANCELED`.
- **`exchangeTicket(PluginCall)`** — Exchanges a dev-ticket for tokens via a validated HTTPS request to `/oauth/dev-exchange`, reading tokens from response headers.
- **`getTokens(PluginCall)`** — Retrieves stored tokens through `TokenLifecycle`/`SecureTokenStore`, gating access with a `BiometricPrompt` when biometric protection is enabled.
- **`getSafeAreaInsets(PluginCall)`** — Returns real `WindowInsets`-based safe area values (top/bottom/left/right) for CSS-safe-area parity in the WebView.
- **`emitTokenUpdate(JSObject)`** — Notifies JS listeners (`tokenUpdate` event) when the token pair changes.

## Usage Example

Frontend usage (via Capacitor bridge, TypeScript side):

```java
// Native side registration (handled automatically by @CapacitorPlugin annotation)
@CapacitorPlugin(name = "NativeAuth")
public class NativeAuthPlugin extends Plugin {
    @Override
    public void load() {
        lifecycle = TokenLifecycle.get(getContext());
        lifecycle.attach(this);
    }
}
```

Example native call flow for starting login:

```java
PluginCall call = /* incoming call with "url" param */;
plugin.start(call);
// Launches CustomTabsIntent; result resolved later in handleOnNewIntent
// once the OAuth provider redirects back to com.openframe.app://auth
```

This plugin depends on `TokenLifecycle` for token storage/refresh logic and `SecureTokenStore` for biometric-gated cryptographic operations, keeping Activity-dependent UI (biometric prompts, Custom Tabs) isolated in this class.
