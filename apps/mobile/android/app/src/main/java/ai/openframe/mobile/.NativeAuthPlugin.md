## NativeAuthPlugin.java

Android Capacitor plugin that implements native OAuth login, dev-ticket exchange, biometric-gated token storage, and safe-area inset reporting for the OpenFrame mobile app. It mirrors the iOS `NativeAuthPlugin.swift` implementation so the shared frontend (`openframe-frontend: src/lib/native-shell.ts`) can consume the same JS contract (`jsName: "NativeAuth"`) unchanged across platforms.

## Key Components

- **`start(PluginCall)`** — Launches OAuth login in a Chrome Custom Tab (Android's RFC 8252-compliant equivalent of iOS `ASWebAuthenticationSession`), since third-party identity providers reject WebView-based flows.
- **`handleOnNewIntent(Intent)`** — Handles the deep-link callback (`com.openframe.app://auth`) routed back via `MainActivity`'s `singleTask` launch mode, resolving the pending login call.
- **`handleOnResume()`** — Detects user-cancelled logins (Custom Tab dismissed without a deep link) and rejects the pending call with `USER_CANCELED`.
- **`exchangeTicket(PluginCall)`** — Exchanges a dev-ticket for access/refresh tokens via a pinned HTTPS request to `/oauth/dev-exchange`, reading tokens from response headers (no CORS involved).
- **`getTokens(PluginCall)`** — Retrieves tokens through `TokenLifecycle`, using biometric-gated decryption (`BiometricPrompt` + `Cipher`) when biometrics are enabled, with in-memory caching to avoid repeated prompts.
- **`getSafeAreaInsets(PluginCall)`** — Returns real `WindowInsets`-derived safe area values (converted to density-independent pixels) since the WebView reports `env(safe-area-inset-*)` as zero.
- **`emitTokenUpdate(JSObject)`** — Package-private bridge method used by `TokenLifecycle` to notify the web layer (`tokenUpdate` event) of token changes.
- **`load()` / `handleOnDestroy()`** — Lifecycle hooks that attach/detach this plugin instance to/from the shared `TokenLifecycle` singleton.

## Usage Example

```java
// Registered automatically via @CapacitorPlugin(name = "NativeAuth")
// Frontend (TypeScript) invokes it through the Capacitor bridge:
//
// await NativeAuth.start({ url: oauthLoginUrl });
// const { callbackUrl } = await <resolved from deep link>;
// const tokens = await NativeAuth.exchangeTicket({ url: devExchangeUrl });
// const currentTokens = await NativeAuth.getTokens();

// Internally, the plugin coordinates with TokenLifecycle:
public class ExampleIntegration {
    void onLoginButtonTapped(NativeAuthPlugin plugin, PluginCall call) {
        // plugin.start(call) opens a Chrome Custom Tab for OAuth
        // On success, handleOnNewIntent resolves the call with callbackUrl
    }
}
```
