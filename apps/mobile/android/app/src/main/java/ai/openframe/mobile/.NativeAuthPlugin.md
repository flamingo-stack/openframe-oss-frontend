## NativeAuthPlugin.java

Android Capacitor plugin that mirrors the iOS `NativeAuthPlugin.swift`, exposing identical `NativeAuth` JS bindings so the shared frontend (`native-shell.ts`) works unchanged across platforms. It drives OAuth login via Chrome Custom Tabs, exchanges a dev-ticket for tokens over native HTTP, gates token reads behind biometric prompts, and reports real safe-area insets from `WindowInsets`.

## Key Components

- **`NativeAuthPlugin`** — `@CapacitorPlugin(name = "NativeAuth")` entry point; owns the Activity-bound work (Custom Tabs, biometric prompts, deep-link handling) and delegates token storage/refresh to `TokenLifecycle`.
- **`start(PluginCall)`** — Launches the OAuth flow in a Chrome Custom Tab (RFC 8252), guarding against concurrent logins via `pendingLoginCall`.
- **`handleOnNewIntent(Intent)`** — Catches the `com.openframe.app://auth` deep-link redirect and resolves the pending login call with the callback URL.
- **`handleOnResume()`** — Detects user-cancelled logins (Custom Tab dismissed without a deep link) and rejects with `USER_CANCELED`.
- **`exchangeTicket(PluginCall)`** — Validates the target URL (HTTPS + pinned `/oauth/dev-exchange` path) and performs a native HTTP GET, extracting tokens from response headers via `TokenPair.fromHeaders`.
- **`getTokens(PluginCall)`** — Returns cached/stored tokens directly when biometrics are disabled, or gates the read behind a single `BiometricPrompt` that unwraps a combined encrypted blob when enabled.
- **`getSafeAreaInsets(PluginCall)`** — Reads `WindowInsets` (system bars + display cutout) and returns density-adjusted inset values matching iOS's point-based contract.
- **`emitTokenUpdate(JSObject)`** — Bridges `TokenLifecycle` token changes to the web view via the `tokenUpdate` event.

## Usage Example

```java
// Plugin registration happens automatically via @CapacitorPlugin.
// From the frontend (TypeScript), the JS contract looks like:

// 1. Start login
NativeAuth.start({ url: "https://gateway.example.com/oauth/authorize?..." });

// 2. Exchange the dev-ticket returned via deep link
NativeAuth.exchangeTicket({ url: "https://tenant.example.com/oauth/dev-exchange?ticket=..." });

// 3. Read tokens (may prompt biometrics if enabled)
NativeAuth.getTokens();

// 4. Listen for token updates
NativeAuth.addListener("tokenUpdate", (tokens) => {
    console.log(tokens.accessToken, tokens.refreshToken);
});
```

Internally, `TokenLifecycle` (see `TokenLifecycle.java`) owns the in-memory token pair, refresh single-flighting, and tenant host configuration; this plugin supplies only the Activity-dependent operations (Custom Tabs, biometric prompts) that `TokenLifecycle` cannot perform on its own.
