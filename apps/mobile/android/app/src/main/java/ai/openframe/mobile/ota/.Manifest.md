## Manifest.java

Verifies and parses OTA (over-the-air) update manifests for the OpenFrame mobile app. It implements the signature verification and payload validation rules described in `apps/mobile/docs/ota.md` ("The manifest" and "The rules" sections), ensuring an update manifest is cryptographically signed and structurally well-formed before its contents are trusted.

## Key Components

- **`Manifest.Payload`** - Immutable value object holding verified manifest fields: `version`, `bridgeLevel`, `url`, `size`, and `sha256`.
- **`bundleName(String version)`** - Builds the expected OTA bundle filename (`openframe-mobile-<version>.tar.xz`).
- **`verify(byte[] manifest, Map<String, PublicKey> keys)`** - Main entry point. Parses the signed envelope (`keyId`, `payload`, `signature`), looks up the matching public key, enforces strict DER signature encoding, verifies the ECDSA signature over the payload, and returns a validated `Payload`. Throws `OtaError` on any failure.
- **`isStrictDer(byte[] signature)`** - Validates that a signature is the single accepted DER encoding (SEQUENCE of two positive, shortest-form INTEGERs) to avoid provider-specific signature malleability inconsistencies.
- **`payload(byte[] bytes)`** (private) - Parses and validates the inner JSON payload fields: `format`, `version` (semver), `bridgeLevel`, `size`, `sha256` (64 lowercase hex chars), and `url` (must be HTTPS and name the expected bundle file, with no query/fragment).

## Usage Example

```java
import ai.openframe.mobile.ota.Manifest;
import ai.openframe.mobile.ota.OtaError;
import java.security.PublicKey;
import java.util.Map;

Map<String, PublicKey> trustedKeys = loadTrustedKeys();
byte[] manifestBytes = downloadManifest();

try {
    Manifest.Payload payload = Manifest.verify(manifestBytes, trustedKeys);
    System.out.println("Verified version: " + payload.version);
    System.out.println("Bundle URL: " + payload.url);
    System.out.println("Expected SHA-256: " + payload.sha256);
} catch (OtaError e) {
    System.err.println("Manifest rejected: " + e.getMessage());
}
```

Note that `Manifest` is a non-instantiable utility class (private constructor); all functionality is accessed via its static methods.
