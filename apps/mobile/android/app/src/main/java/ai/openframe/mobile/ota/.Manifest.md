## Manifest.java

Verifies the signed OTA (over-the-air) update manifest used by the OpenFrame mobile app, implementing the validation checks described in `apps/mobile/docs/ota.md`. It parses a JSON signature envelope, verifies an ECDSA/SHA-256 signature against a strict DER encoding, and validates the signed payload's fields before returning a trusted `Payload`.

## Key Components

- **`Manifest.Payload`** — Immutable value object holding verified update metadata: `version`, `bridgeLevel`, `url`, `size`, and `sha256`.
- **`bundleName(String version)`** — Builds the canonical bundle filename (`openframe-mobile-<version>.tar.xz`) used to validate the `url` field.
- **`verify(byte[] manifest, Map<String, PublicKey> keys)`** — Main entry point. Parses the envelope, decodes base64 payload/signature, resolves the signing key by `keyId`, enforces strict DER signature encoding, verifies the ECDSA signature, and validates payload fields. Throws `OtaError` on any failure.
- **`isStrictDer(byte[] signature)`** — Package-visible helper enforcing a single canonical DER encoding for ECDSA signatures (rejects negative/zero-padded integers and non-shortest-form lengths) to avoid signature-malleability discrepancies across crypto providers.
- **Private validation helpers** — `envelopeString`, `derIntegerEnd`, `verifies`, `payload`, `positiveInteger`, `isSha256`, `namesBundle` enforce strict field-level rules (format version, semantic version, positive integers, 64-char hex SHA-256, HTTPS URL matching the expected bundle name with no query/fragment).

## Usage Example

```java
import ai.openframe.mobile.ota.Manifest;
import ai.openframe.mobile.ota.OtaError;
import java.security.PublicKey;
import java.util.Map;

public class OtaUpdateChecker {
    public void checkUpdate(byte[] manifestBytes, Map<String, PublicKey> trustedKeys) {
        try {
            Manifest.Payload update = Manifest.verify(manifestBytes, trustedKeys);
            System.out.println("Verified version: " + update.version);
            System.out.println("Bundle URL: " + update.url);
            System.out.println("Expected SHA-256: " + update.sha256);
        } catch (OtaError e) {
            System.err.println("Manifest rejected (" + e.getMessage() + ")");
        }
    }
}
```

**Note:** `Manifest` is a final, non-instantiable utility class (private constructor); all functionality is accessed via static methods.
