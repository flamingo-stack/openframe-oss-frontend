## SecureTokenStore.java

Android-Keystore-backed secure storage for authentication tokens, serving as the Android counterpart to the iOS Keychain implementation in `NativeAuthPlugin.swift`. It persists the combined access/refresh token pair as a single encrypted blob in `SharedPreferences`, supporting two mutually-exclusive storage modes: **ungated** (silent AES-GCM encryption with a non-exportable AndroidKeyStore master key) and **gated** (biometric-protected hybrid envelope encryption using a per-write AES content key wrapped by a biometric-gated RSA-2048/OAEP public key).

## Key Components

- **`SecureTokenStore(Context)`** — Constructor; opens the app's private `SharedPreferences` file.
- **`write(String account, String value)` / `read(String account)` / `delete(String account)`** — Silent (ungated) AES-256-GCM encrypt/decrypt/remove operations backed by a hardware-protected AndroidKeyStore master key.
- **`writeGated(String account, String value)` / `deleteGated(String account)`** — Biometric-gated writes using envelope encryption (random AES content key wrapped by an RSA public key); writes never prompt, only reads via `CryptoObject` do.
- **`Unavailable`** — Exception type thrown when a read fails transiently (not due to corruption or key invalidation), signaling the caller to retry rather than treat the token as absent.
- **`getPlain(String key)` / `putPlain(String key, String value)`** — Plain (non-encrypted) storage for non-secret metadata like tenant/shared host and client bundle version.
- **Constants** — `COMBINED`, `LEGACY_ACCESS_TOKEN`, `LEGACY_REFRESH_TOKEN`, `TENANT_HOST`, `SHARED_HOST`, `CLIENT_BUNDLE_VERSION`, `CLIENT_BUNDLE_VERSION_BUILD`, `BIO_ENABLED_MARKER`.

## Usage Example

```java
SecureTokenStore store = new SecureTokenStore(context);

// Ungated (default) — silent read/write
store.write(SecureTokenStore.COMBINED, tokenPairJson);
String tokens = store.read(SecureTokenStore.COMBINED); // null if absent

try {
    String tokens = store.read(SecureTokenStore.COMBINED);
} catch (SecureTokenStore.Unavailable e) {
    // transient failure — retry later, do not treat as logged out
}

// Gated (biometric enabled) — write is silent, read requires BiometricPrompt/CryptoObject
store.writeGated(SecureTokenStore.COMBINED, tokenPairJson);

// Plain metadata (not encrypted)
store.putPlain(SecureTokenStore.TENANT_HOST, "tenant.openframe.ai");
String host = store.getPlain(SecureTokenStore.TENANT_HOST);
```

Note: This class is package-private (`final class`), intended for internal use within the `ai.openframe.mobile` package alongside the token lifecycle and native auth plugin components.
