## SecureTokenStore.java

Android-Keystore-backed secure storage for authentication tokens, serving as the Android counterpart to the iOS Keychain implementation in `NativeAuthPlugin.swift`. It stores the access and refresh tokens as a single combined JSON blob so a biometric-gated read requires only one `BiometricPrompt`/`CryptoObject` unwrap. It supports two mutually exclusive storage modes backed by the same `SharedPreferences` file: an ungated mode using a non-exportable AES-256-GCM key in the `AndroidKeyStore` for silent reads/writes, and a gated mode using a hybrid envelope (per-write AES content key wrapped by a biometric-protected RSA-2048/OAEP key pair) so writes stay silent while reads require biometric authentication.

## Key Components

- **`SecureTokenStore(Context)`** — Constructor opening the shared `SharedPreferences` file.
- **`write(String account, String value)` / `read(String account)`** — Silent AES-GCM encrypt/decrypt using the AndroidKeyStore master key; corrupted or invalidated entries are dropped and read as absent.
- **`delete(String account)`** — Removes an ungated entry and its IV.
- **`writeGated(String account, String value)` / `deleteGated(String account)`** — Hybrid envelope encryption using a fresh AES content key wrapped with a biometric-gated RSA public key; write never prompts.
- **`Unavailable`** — Exception signaling a transient read failure (item untouched, distinct from "absent").
- **`getPlain(String)` / `putPlain(String, String)`** — Plain (non-encrypted) storage for tenant/shared host strings.
- **`isBiometricEnabled()` / `setBiometricEnabled(boolean)`** — Tracks whether gated mode is active; never prompts.
- **Constants** — `COMBINED`, `LEGACY_ACCESS_TOKEN`, `LEGACY_REFRESH_TOKEN`, `TENANT_HOST`, `SHARED_HOST` account keys; cipher transformation and OAEP parameter constants ensuring wrap/unwrap compatibility across providers.

## Usage Example

```java
SecureTokenStore store = new SecureTokenStore(context);

// Ungated (biometric off): silent write/read
store.write(SecureTokenStore.COMBINED, tokenPairJson);
String tokens = store.read(SecureTokenStore.COMBINED); // null if absent

// Gated (biometric on): silent write, prompted read (via BiometricPrompt elsewhere)
store.setBiometricEnabled(true);
store.writeGated(SecureTokenStore.COMBINED, tokenPairJson);

// Clean up when disabling biometrics or logging out
store.deleteGated(SecureTokenStore.COMBINED);
store.delete(SecureTokenStore.COMBINED);

// Non-secret host values
store.putPlain(SecureTokenStore.TENANT_HOST, "tenant.openframe.ai");
String host = store.getPlain(SecureTokenStore.TENANT_HOST);
```

Callers must handle `SecureTokenStore.Unavailable` separately from a `null` result: `null` means the token is genuinely absent (ending a session), while `Unavailable` indicates a transient Keystore error where the stored item remains intact.
