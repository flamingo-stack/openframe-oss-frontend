Android-Keystore-backed secure storage for Flamingo's OpenFrame mobile auth tokens, serving as the Android counterpart to the iOS Keychain implementation in `NativeAuthPlugin.swift`. It stores the access and refresh tokens as a single combined JSON blob to guarantee a gated (biometric) read requires only one `BiometricPrompt`/`CryptoObject` unwrap for the whole token pair.

## Key Components

- **`SecureTokenStore(Context)`** — Constructor backed by a `SharedPreferences` file (`ai.openframe.mobile.auth`).
- **Ungated mode (biometric off)** — `write(account, value)` / `read(account)` / `delete(account)`: silent AES-256-GCM encryption using a non-exportable AndroidKeyStore master key (`KEY_ALIAS`). No authentication required for read or write.
- **Gated mode (biometric on)** — `writeGated(account, value)` / `deleteGated(account)`: hybrid envelope encryption. Each write generates a fresh AES-256-GCM content key, encrypts the blob, then wraps the content key with a biometric-gated RSA-2048/OAEP public key (`BIO_KEY_ALIAS`). Writes stay silent; only unwrapping (read, implemented elsewhere using the private key) requires a `BiometricPrompt`.
- **`Unavailable`** — `RuntimeException` subtype thrown when a read fails transiently (e.g., busy KeyMint daemon) so callers can distinguish "temporarily unavailable" from "absent."
- **Plain value storage** — `getPlain(key)` / `putPlain(key, value)` for non-secret data like `TENANT_HOST`, `SHARED_HOST`, and client bundle version markers.
- **Account constants** — `COMBINED`, `LEGACY_ACCESS_TOKEN`, `LEGACY_REFRESH_TOKEN` (for cleanup of old per-token storage), `BIO_ENABLED_MARKER`.

## Usage Example

```java
SecureTokenStore store = new SecureTokenStore(context);

// Ungated (biometric disabled): silent write/read
store.write(SecureTokenStore.COMBINED, tokenPairJson);
String storedJson = store.read(SecureTokenStore.COMBINED);
if (storedJson == null) {
    // No tokens stored, or blob was corrupt/invalidated — session ends
} 

// Gated (biometric enabled): silent write, caller handles prompted read elsewhere
store.writeGated(SecureTokenStore.COMBINED, tokenPairJson);

// Handle transient unavailability distinctly from absence
try {
    String value = store.read(SecureTokenStore.COMBINED);
} catch (SecureTokenStore.Unavailable e) {
    // Retry later; do not treat as logged out
}

// Non-secret host metadata
store.putPlain(SecureTokenStore.TENANT_HOST, "tenant.openframe.ai");
String tenantHost = store.getPlain(SecureTokenStore.TENANT_HOST);
```
