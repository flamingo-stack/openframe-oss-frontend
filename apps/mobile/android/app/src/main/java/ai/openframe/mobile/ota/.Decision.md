Defines the decision logic for OpenFrame's Over-The-Air (OTA) update mechanism, determining whether an incoming update payload should be downloaded, ignored, or dropped based on version comparison and current OTA state.

## Key Components

- **`Decision`** — Enum representing the possible outcomes of OTA update evaluation:
  - `DOWNLOAD` — The payload is a valid, newer update and should be fetched.
  - `NOTHING` — The payload should be ignored (already active, pending, known bad, or incompatible bridge level).
  - `DROP` — The payload is outdated or not newer than the currently built-in version.
- **`decide(...)`** — Static method implementing the decision rules documented in `docs/ota.md` ("The decision"). Evaluates:
  1. Whether `payloadVersion` is newer than `builtinVersion` (otherwise `DROP`).
  2. Whether `payloadVersion` matches the active/pending version or is in the known-bad list (otherwise `NOTHING`).
  3. Whether `payloadBridgeLevel` exceeds the current `bridgeLevel`, indicating incompatibility (otherwise `NOTHING`).
  4. If none of the above apply, returns `DOWNLOAD`.

## Usage Example

```java
OtaState state = new OtaState();
state.active = "1.2.0";
state.pending = null;
state.bad = Set.of("1.1.5");

Decision result = Decision.decide(
    "1.0.0",      // builtinVersion
    5,            // bridgeLevel
    state,
    "1.3.0",      // payloadVersion
    5             // payloadBridgeLevel
);

if (result == Decision.DOWNLOAD) {
    // proceed to fetch and apply the update
}
```

This logic ensures updates are only downloaded when they represent genuinely newer, compatible, and previously unseen/non-blacklisted versions. See [`docs/ota.md`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/docs/ota.md) for the full specification of "The decision" rules.
