`ShellLog.java` provides tagged logging channels for the Android shell app, mirroring the iOS counterpart (`ShellLog.swift`) to ensure consistent log stream naming across platforms for authentication, notifications, and update flows.

## Key Components

- **`ShellLog`** — final class wrapping Android's `Log` with a fixed tag, exposing `notice()` (info level) and `error()` (error level) logging methods.
- **`auth`** — static instance tagged `OpenFrameAuth`, for authentication-related log messages.
- **`notifications`** — static instance tagged `OpenFrameNotifications`, for notification-related log messages.
- **`update`** — static instance tagged `OpenFrameUpdate`, for app update-related log messages.

## Usage Example

```java
// Logging an informational message during auth flow
ShellLog.auth.notice("User login succeeded");

// Logging an error during notification handling
ShellLog.notifications.error("Failed to register push token");

// Logging an update-related notice
ShellLog.update.notice("Checking for new app version");
```

To view these logs on a connected device or emulator, filter `adb logcat` by the relevant tags:

```bash
adb logcat -s OpenFrameAuth OpenFrameNotifications OpenFrameUpdate
```

This keeps logging consistent and filterable across the authentication, notifications, and update subsystems, matching the behavior of the iOS shell implementation in this repository: [ShellLog.swift](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/ios/App/App/ShellLog.swift).
