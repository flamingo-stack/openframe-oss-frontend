## ShellLog.java

A lightweight logging utility for the Android shell app that provides two dedicated log streams (auth and notifications), mirroring the equivalent `ShellLog.swift` implementation on iOS. It wraps Android's `Log` class with named tags for easy filtering via `adb logcat`.

## Key Components

- **`ShellLog`** — Final utility class exposing two static, pre-configured instances:
  - `auth` — logs under the `OpenFrameAuth` tag, used for authentication-related events.
  - `notifications` — logs under the `OpenFrameNotifications` tag, used for push/notification-related events.
- **`notice(String message)`** — Logs an informational message (`Log.i`) under the instance's tag.
- **`error(String message)`** — Logs an error message (`Log.e`) under the instance's tag.

The constructor is private, so only the two predefined instances (`auth`, `notifications`) are available—no arbitrary tags can be created.

## Usage Example

```java
// Logging an informational auth event
ShellLog.auth.notice("User successfully authenticated");

// Logging an error during notification handling
ShellLog.notifications.error("Failed to register device token");
```

To filter these logs via ADB:

```bash
adb logcat -s OpenFrameAuth OpenFrameNotifications
```
