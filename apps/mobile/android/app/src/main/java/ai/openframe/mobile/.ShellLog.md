## ShellLog.java

A lightweight Android logging utility that defines standardized, tagged log streams for different shell subsystems (authentication, notifications, and updates) in the OpenFrame mobile app. It mirrors the equivalent iOS implementation (`ShellLog.swift`) to keep logging conventions consistent across platforms.

## Key Components

- **`ShellLog`** — Final utility class wrapping Android's `Log` with a fixed tag per instance.
- **`auth`** — Static instance tagged `OpenFrameAuth`, for authentication-related logs.
- **`notifications`** — Static instance tagged `OpenFrameNotifications`, for notification-related logs.
- **`update`** — Static instance tagged `OpenFrameUpdate`, for update-related logs.
- **`notice(String message)`** — Logs an informational message (`Log.i`) under the instance's tag.
- **`error(String message)`** — Logs an error message (`Log.e`) under the instance's tag.

## Usage Example

```java
// Logging an informational message during authentication
ShellLog.auth.notice("User login succeeded");

// Logging an error during an update check
ShellLog.update.error("Failed to fetch update manifest");

// Logging a notification delivery event
ShellLog.notifications.notice("Push notification received");
```

To filter these logs via ADB, use:

```bash
adb logcat -s OpenFrameAuth OpenFrameNotifications OpenFrameUpdate
```

This class has package-private visibility and is intended for internal use within the `ai.openframe.mobile` package only.
