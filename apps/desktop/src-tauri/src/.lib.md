## lib.rs

Tauri desktop shell entry point for the OpenFrame native app. Defines the application's window/tray lifecycle, main-window presence tracking (used to resync chat/UI state after the app returns from background), platform-specific module wiring (notifications, deep-link auth, auto-updates), and shared constants consumed across the native shell and the web frontend.

## Key Components

- **`URI_SCHEME`** — Custom `openframe-console://` scheme used for OAuth callback (`auth`), notification clicks (`notify`), and installer download hand-off (`download`); registered via `Info.plist` on macOS and `register_url_scheme` on Windows.
- **`MainPresence` / `MAIN_PRESENCE`** — State machine tracking whether the main window is visible, since when it was hidden, and the last visibility value sent to the webview; guards against redundant OS calls on rapid resize/drag events.
- **`RESUME_EVENT`** (`"shell:resumed"`) — Emitted when the main window returns to the foreground, carrying elapsed hidden duration so the frontend can resync live data (e.g., chat tail).
- **`set_main_presence`** — Updates presence state, mirrors visibility to the webview, and emits `RESUME_EVENT` with the away-duration on return.
- **`sync_activation_policy`** (macOS only) — Keeps the dock icon tied to whether *any* app window is visible, not just the main one, avoiding the app appearing quit while child windows remain open.
- **Conditional submodules** — `chat_api`, `notification_actions`, `macos_un`, `macos_wake`, `windows_activator`, `windows_toast` compiled per-platform; Linux omits all notification-backend code.
- **Constants** — `WINDOW_BG`, `WINDOW_TITLE`, `MIN_WINDOW_WIDTH/HEIGHT`, `MAX_WINDOW_TITLE_CHARS`, `LOGIN_TIMEOUT`, error codes (`USER_CANCELED_ERROR`, `LOGIN_TIMEOUT_ERROR`, `LOGIN_INCOMPLETE_ERROR`), and compile-time config (`DEFAULT_SHARED_HOST`, `GTM_CONTAINER_ID`).

## Usage Example

```rust
// Emitting the resume event after the main window becomes visible again,
// so the frontend can resync state that may be stale.
fn on_window_shown(app: &tauri::AppHandle) {
    set_main_presence(app, true);
}

// Deep link dispatch based on URI_SCHEME host, e.g.
// openframe-console://auth?devTicket=...
fn handle_deep_link(url: &str) {
    if url.starts_with(&format!("{}://{}", URI_SCHEME, "auth")) {
        // route to native OAuth token exchange
    }
}
```

This module is not consumed directly by other crates; it is the Tauri application's root, wired up through `tauri::Builder` in the app's `main.rs` to register window event handlers, tray icon behavior, and deep-link/auth flows described above.
