## lib.rs

Entry point of the OpenFrame Tauri desktop shell (macOS/Windows/Linux), wiring together window management, system tray, native authentication, notifications, and background services into a single cross-platform application.

## Key Components

- **Module declarations** — conditionally compiled submodules per platform: `autostart`, `download_link`, `installer`, `chat_api`/`notification_actions`/`windows_toast` (macOS/Windows only), `macos_un`/`macos_wake` (macOS only), `windows_activator` (Windows only), `nats`, `notifications`, `tokens`, `updater`.
- **`URI_SCHEME`** — the `openframe-console://` custom protocol used for OAuth callback (`auth`), notification clicks (`notify`), and installer download hand-off (`download`).
- **`MAIN_LABEL`** — label identifying the app's primary window.
- **`WINDOW_BG`, `WINDOW_TITLE`, `MIN_WINDOW_WIDTH`/`HEIGHT`, `MAX_WINDOW_TITLE_CHARS`** — shared window presentation constants applied to all windows.
- **`RESUME_EVENT`** — event emitted to the frontend when the main window returns to foreground, carrying elapsed absence duration so the UI (e.g. chat) can resync.
- **`MainPresence` / `MAIN_PRESENCE`** — state machine tracking whether the main window is visible, since when it was hidden, and the last visibility told to the webview; synchronized via `Mutex` since updates arrive from both window events and async notification tasks.
- **`MIRROR`** — mutex serializing the decide-call-record sequence for mirroring presence into the webview, preventing race conditions across threads.
- **`sync_activation_policy`** *(macOS)* — keeps the dock icon visible (`Regular` vs `Accessory` activation policy) based on whether any app window remains on screen.
- **`set_main_presence`** — updates presence state, mirrors it to the webview, and emits `RESUME_EVENT` with absence duration on return (skipped on first reveal after launch).
- **Timeout/error constants** — `LOGIN_TIMEOUT`, `USER_CANCELED_ERROR`, `LOGIN_TIMEOUT_ERROR`, `LOGIN_INCOMPLETE_ERROR` govern the native OAuth login flow's failure modes, matched by value in the frontend.
- **`DEFAULT_SHARED_HOST`, `GTM_CONTAINER_ID`** — compile-time-injected configuration for the auth gateway host and analytics container, overridable at runtime via `config.json`.

## Usage Example

This file is the Tauri application entry crate root and is not consumed as a library by other code; it is built directly into the desktop binary. Typical interaction is through Tauri's generated `main` function elsewhere in the crate, which calls into this module's window/tray setup:

```rust
// Conceptual usage from the app's main() (not shown in this excerpt)
tauri::Builder::default()
    .setup(|app| {
        // main window created here uses WINDOW_BG, WINDOW_TITLE,
        // MIN_WINDOW_WIDTH / MIN_WINDOW_HEIGHT
        set_main_presence(app.handle(), true);
        Ok(())
    })
    .on_window_event(|window, event| {
        if let WindowEvent::Focused(true) = event {
            set_main_presence(window.app_handle(), true);
        }
    })
    .run(tauri::generate_context!())
    .expect("error while running OpenFrame");
```

Frontend code listens for the resume signal:

```typescript
// apps/web/src/lib/native-shell.ts
listen("shell:resumed", (event) => {
  const awayMs = event.payload as number;
  resyncChatIfStale(awayMs);
});
```
