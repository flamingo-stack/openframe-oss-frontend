## Windows Toast Backend

Implements Windows toast notification delivery via WinRT, exposing two activation paths: protocol activation (`openframe-console://notify` URI) for body/"Open" clicks that must survive process restarts, and COM activator background activation for Approve/Reject/Reply buttons that need to run without foregrounding the app. The module is structured so the XML-building and argument-encoding logic compiles and is testable on non-Windows hosts, isolating only the WinRT call itself behind `#[cfg(target_os = "windows")]`.

## Key Components

- **`post`** — Entry point that builds the toast XML, computes a replacement tag (for approval requests only), and dispatches the show call on a background thread.
- **`show`** — Loads the XML into a WinRT `XmlDocument`, creates and tags the `ToastNotification`, optionally suppresses the popup for silent updates, and displays it via `ToastNotificationManager`.
- **`ensure_logo`** / **`write_logo`** — Lazily materializes the embedded app logo to disk (atomic write via temp file + rename) so the notification platform can resolve it out-of-process, even for uninstalled/exited apps.
- **`toast_tag`** — Sanitizes and truncates an arbitrary key into a valid Windows toast tag (alphanumeric/`-`/`_`, max 64 chars) used for replacing prior toasts.
- **Constants** — `REPLY_INPUT_ID`, `APPROVE_ACTION`/`REJECT_ACTION`/`REPLY_ACTION`, `TITLE_LIMIT`/`BODY_LIMIT`, `TOAST_XML_BUDGET`, `TOAST_GROUP`, `TAG_LIMIT`, and the embedded `TOAST_LOGO` bytes.

## Usage Example

```rust
// Posting a toast notification (Windows only)
#[cfg(target_os = "windows")]
{
    windows_toast::post(
        &app_handle,
        "Approval Needed".to_string(),
        "A device requires your approval.".to_string(),
        Some(click_payload),
        Some(user_id),
        ActionKind::Approval,
        Delivery::New,
    );
}
```

Cross-platform logic (e.g. tag sanitization) can be exercised directly in tests without the `windows` feature:

```rust
let tag = toast_tag("request-id-with-weird-chars-!@#-and-a-very-long-suffix");
assert!(tag.len() <= 64);
```
