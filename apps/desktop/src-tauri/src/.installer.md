## installer.rs

Implements the "Deploy on this Device" feature: installs the OpenFrame agent locally with administrator rights, confirmed by a native OS dialog, and streams installer output back to the setup wizard via events.

## Key Components

- **`EVENT_OUTPUT`** / **`EVENT_DONE`** — Tauri event names used to stream installer stdout and report completion/exit code to the frontend.
- **`InstallerState`** — Guards against concurrent installs using an `AtomicBool`; a second request while one runs is rejected with `InstallError::busy()`.
- **`InstallError`** — Structured error type (`kind` + `message`) covering `busy`, `unsupported`, `unavailable`, `io`, `cancelled`, and `failed` cases, designed so the UI can map `kind` to copy without parsing free text.
- **`is_install_arg`** — Validates values bound for the agent's command line (length, charset, no leading `-`) to prevent flag injection or shell metacharacter abuse.
- **`InstallRequest`** — Deserialized payload from the webview (`org_id`, `initial_key`, `log_key`, `user_id`); intentionally excludes the tenant host, which the shell derives itself from login state, and omits `Debug` to keep secrets out of logs.
- **`InstallOs`** — Enum selecting macOS vs. Windows command construction.
- **`install_command`** — Builds the exact shell/PowerShell command (download, extract, elevate, run) matching the copyable command shown in the wizard UI (verified via a shared fixture).
- **`confirmed_by_user`** — Shows a native async confirmation dialog naming the target tenant; required because webview content cannot draw or answer OS-native prompts, closing the privilege-escalation gap.
- **`install_target`** — Resolves the tenant origin from the shell's own stored config rather than trusting any value from the page.

## Usage Example

```rust
// Frontend invokes a Tauri command (not shown in this excerpt) that:
// 1. Deserializes an InstallRequest and calls `.validate()`
let request: InstallRequest = /* from IPC */ serde_json::from_str(payload)?;
request.validate()?;

// 2. Resolves the tenant to install against from stored config
let origin = install_target(&app_config)?;

// 3. Confirms with the user via a native dialog before elevating
if !confirmed_by_user(&window, &enrolled_host(&origin)) {
    return Err(InstallError::cancelled());
}

// 4. Builds the platform-specific install command
let cmd = install_command(InstallOs::current(), &origin, &request, &machine_id);
// ... runner script executes `cmd` elevated, tailing output to EVENT_OUTPUT/EVENT_DONE
```
