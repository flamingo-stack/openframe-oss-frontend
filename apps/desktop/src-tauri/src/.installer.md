## installer.rs

Tauri backend command implementing "Deploy on this Device": installs the OpenFrame agent locally with administrator privileges and streams installer output back to the setup wizard webview, while preventing page scripts from escalating privileges without explicit user confirmation.

## Key Components

- **`EVENT_OUTPUT` / `EVENT_DONE`** — Tauri event names used to stream installer output lines and report final completion (exit code or error) to the frontend.
- **`InstallerState`** — Shared state guarding against concurrent installs via an `AtomicBool`.
- **`InstallError`** — Structured error type (`kind` + `message`) covering `busy`, `unsupported`, `unavailable`, `io`, `cancelled`, and `failed` cases, designed for UI-friendly handling.
- **`is_install_arg`** — Validates untrusted values (org id, keys, user id) against a strict alphanumeric/`-`/`_` charset and length bound, rejecting leading `-` to prevent CLI flag injection.
- **`InstallRequest`** — Deserialized payload from the webview (`orgId`, `initialKey`, `logKey`, `userId`) with `deny_unknown_fields` and no `Debug` impl to avoid leaking secrets; includes `validate()`.
- **`InstallOs`** — Platform enum (macOS/Windows) selecting which install command/elevation mechanism to build.
- **`install_command`** — Constructs the exact shell/PowerShell command run on the target OS, mirroring the frontend's `buildInstallCommand` for fixture-based parity testing.
- **`confirmed_by_user`** — Shows a native, non-spoofable async dialog naming the target tenant; only an explicit OK proceeds to elevation.
- **`install_target`** — Resolves the tenant origin the shell authenticated against (never one named by the page).

## Usage Example

```rust
// Frontend invokes the Tauri command with only the four trusted fields:
use serde_json::json;

let request = json!({
    "orgId": "org_abc123",
    "initialKey": "key_xyz789",
    "logKey": null,
    "userId": null,
});

// Backend validates each field shape before use:
let req: InstallRequest = serde_json::from_value(request)?;
req.validate()?; // rejects malformed values without leaking them

// The shell then confirms with the user before elevating:
// confirmed_by_user(&window, &tenant_host) -> bool
```

Frontend listens for streamed events:

```typescript
import { listen } from "@tauri-apps/api/event";

await listen("agent-install:output", (event) => {
  console.log("installer output:", event.payload);
});

await listen("agent-install:done", (event) => {
  console.log("install finished:", event.payload);
});
```
