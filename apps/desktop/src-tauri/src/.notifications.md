## notifications.rs

Implements the Tauri shell's background NATS-driven notification plane. It subscribes to `user.<userId>.notification` on the shell's dedicated NATS connection, dispatches OS notifications with badge updates while the window is hidden in the tray, and handles click delivery across platforms (macOS `UNUserNotificationCenter`, Windows toast activation via custom URI scheme). It bridges native click events back to the webview through a readiness-gated stash mechanism so cold-start clicks are not lost.

## Key Components

- **`NotificationsPlane`** — Managed Tauri state holding the active NATS subscription slot, an unread counter, and a stash for click payloads awaiting webview readiness.
- **`Delivery` enum** (`New`, `Update`) — Distinguishes first-time alerts from superseding updates to avoid duplicate unread counts and redundant interruptions.
- **`init(app)`** — Registers plane state and platform-specific click/action backends (`macos_un`, `windows_activator`); must run before `crate::nats::spawn`.
- **`ensure_subscription(app, client)`** — Called on every NATS `Connected` event; reuses the existing subscriber if the signed-in user hasn't changed, otherwise tears down and resubscribes.
- **`notification_router`** — Async task consuming the NATS subscriber stream, parsing JSON payloads, and dispatching to `maybe_notify`.
- **`maybe_notify(app, envelope, user_id)`** — Core dispatch logic: records action-resolution bookkeeping, filters envelopes without a `title`, applies the "window visible" suppression gate (with a silent-update exception), increments unread badge, and posts the OS notification with click/action payload.
- **`CLICK_EVENT`** — Frontend-facing event name (`notification:click`) consumed by `onNativeNotificationClick` in `native-shell.ts`.
- **`BODY_CHARS`** — Truncation limit (140) for untrusted notification body text.
- **`CLICK_URI_PREFIX`** — Windows-only activation URI prefix (`openframe-console://notify`).

## Usage Example

```rust
// During Tauri app setup:
crate::notifications::init(&app_handle);

// On NATS reconnect/connect handler:
crate::notifications::ensure_subscription(&app_handle, nats_client).await;
```

The frontend listens for delivered clicks:

```typescript
// native-shell.ts
listen("notification:click", (event) => {
  onNativeNotificationClick(event.payload);
});
```

See related modules [`notification_actions`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src-tauri/src/notification_actions.rs), `macos_un`, and `windows_activator` for platform-specific click/action handling.
