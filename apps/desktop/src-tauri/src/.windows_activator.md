## windows_activator.rs

Implements the Windows COM activator that handles toast notification action button presses. Because buttons declaring `activationType="background"` cannot deliver input through protocol activation, Windows routes them through a registered COM class, which this module registers (HKCU-only, rewritten on every launch) and serves via an in-process `IClassFactory`/`INotificationActivationCallback` implementation.

## Key Components

- **`ACTIVATOR_CLSID`** — Fixed GUID identifying this build's activator to the notification platform; must stay stable or existing toasts in the Action Center lose their buttons.
- **`is_activation_launch(argv)`** — Detects whether the process was started by COM (via `-ToastActivated` arg) rather than by the user, used to suppress window creation on activation-only launches.
- **`init(app)`** — Entry point called during Tauri setup; stores the `AppHandle` in a `OnceLock` router, registers the CLSID/AUMID in the registry, and starts the COM server thread.
- **`register(app)`** — Writes `LocalServer32` and `AppUserModelId\CustomActivator` registry keys (plus `DisplayName`/`IconUri`) so Windows can resolve and launch the activator.
- **`serve()`** — Spawns a dedicated MTA thread, calls `CoRegisterClassObject`, and parks forever to keep the COM apartment alive.
- **`handle_activation(app, args, inputs)`** — Parses the activation arguments via `windows_toast::parse_action_args`/`press_for` and dispatches to `notification_actions::spawn` or falls back to opening the main window.
- **`Activator`** / **`ActivatorFactory`** — COM objects implementing `INotificationActivationCallback_Impl::Activate` and `IClassFactory_Impl::CreateInstance`, the actual entry points invoked by the shell.
- **`user_inputs(data, count)`** — Unsafe helper converting raw `NOTIFICATION_USER_INPUT_DATA` into a safe `Vec<(String, String)>`.

## Usage Example

```rust
// Called once during Tauri app setup, typically from notifications::init
fn setup(app: &AppHandle) {
    windows_activator::init(app);
}

// Elsewhere, checking whether this launch was COM-triggered
fn main() {
    let argv: Vec<String> = std::env::args().collect();
    if windows_activator::is_activation_launch(&argv) {
        // Skip opening a window; this run exists only to serve the activation.
        return;
    }
    // ...normal app startup
}
```

This module is Windows-specific and expected to be gated behind `#[cfg(target_os = "windows")]` at the call sites, working together with `windows_toast` (toast building/parsing) and `notification_actions` (executing the resulting action).
