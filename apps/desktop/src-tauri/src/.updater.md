## updater.rs

Implements the application self-update flow using `tauri-plugin-updater`: checking the tenant-hosted manifest for new releases, downloading/installing updates with throttled progress reporting, and reporting install telemetry over NATS. It also classifies platform-specific update failures (network, disk, permission, antivirus interference, read-only mount location) into stable error kinds the frontend can act on.

## Key Components

- **`UpdateManager`** — Holds an `apply_lock` (`tokio::sync::Mutex`) ensuring only one update apply runs at a time; concurrent calls receive `UpdateError::busy()`.
- **`UpdateAvailability`** — Serializable struct emitted to the frontend describing whether an update is available, its version, release notes, release notes URL, and whether it's `blocked` (e.g., app on a read-only volume).
- **`UpdateError`** — Normalized error type with a stable `kind` (`"busy"`, `"gone"`, `"unavailable"`, `"location"`, `"network"`, `"signature"`, `"disk"`, `"permission"`, `"security"`, `"unknown"`) plus a human-readable `message`.
- **`classify` / `classify_io`** — Map `tauri_plugin_updater::Error` and `std::io::Error` variants into the coarse `UpdateError` kinds, handling OS-specific quirks (Windows antivirus codes, macOS read-only DMG/App Translocation).
- **`in_place_blocker`** — Detects if the running executable lives on a read-only mount (translocated/mounted bundle) before attempting download, avoiding wasted downloads that would fail at install time.
- **`resolve_manifest_url`** — Builds the updater manifest URL from config override or tenant host + `GATEWAY_MANIFEST_PATH`.
- **`check_for_update`** — Async function querying the manifest endpoint for an available `Update`.
- **`apply`** — Async function that acquires the apply lock, re-checks the in-place blocker, downloads with throttled progress events, and installs the update.
- **Event constants** — `EVENT_AVAILABLE`, `EVENT_PROGRESS`, `EVENT_INSTALLING`, `EVENT_ERROR` emitted to the webview via `tauri::Emitter`.
- **`InstalledAgentReport`** — Serializable payload (`agent_type`, `version`) reported to NATS for install tracking.

## Usage Example

```rust
use crate::updater::{UpdateManager, check_for_update, apply};

// Shared state registered with Tauri's app builder
let manager = UpdateManager::default();

// Check for an update against the tenant's manifest
match check_for_update(&app_handle).await {
    Ok(Some(update)) => {
        // Emit `update:available` to the UI, then apply when user accepts
        if let Err(err) = apply(&app_handle, &manager, update).await {
            log::warn!("update apply failed: {} ({})", err.message, err.kind);
        }
    }
    Ok(None) => log::info!("no update available"),
    Err(err) => log::warn!("update check failed: {}", err.message),
}
```
