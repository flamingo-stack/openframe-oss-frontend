## chat_api.rs

Authenticated GraphQL client used by the Tauri shell to call the tenant chat service directly, without opening a webview. It powers background actions triggered from OS notifications — approving/rejecting Mingo AI tool requests and replying to Mingo messages — reusing the same mutations as the frontend's `ticketService`, but in bearer-token mode against the tenant host learned at login.

## Key Components

- **`Session`** — Represents a live signed-in session (bearer token + `user_id`).
- **`active_session(app)`** — Returns `Some(Session)` only if a valid, non-expired access token (refreshed if needed) with a `userId` claim is available; otherwise `None`.
- **`ApprovalOutcome`** — Result of resolving an approval request: `Resolved` or `AlreadyResolved` (the latter is not treated as an error).
- **`resolve_approval(app, session, request_id, approve)`** — Approves/rejects a Mingo tool-approval request via the `resolveApprovalRequest` mutation, treating `ILLEGAL_STATE` as an already-resolved outcome rather than a failure.
- **`send_message(app, session, dialog_id, content)`** — Sends a message to an admin AI chat dialog via the `sendMessage` mutation.
- **`CommandError`** — Internal error type carrying a user-facing `reason` and an optional GraphQL `userErrors[].code`.
- **`mutate(...)`** — Core HTTP/GraphQL executor: builds the request against the tenant's `/chat/graphql` endpoint, handles timeouts, 401 (session no longer valid), and non-2xx responses.
- **`command_outcome(body, field)`** — Parses a GraphQL response body, distinguishing top-level `errors` from payload-level `userErrors`.
- **`error_message` / `message_of`** — Extract and truncate a human-readable error message from a JSON body (`message` or `error` field).

## Usage Example

```rust
use tauri::AppHandle;

async fn handle_approval_notification(app: &AppHandle, request_id: &str, approve: bool) {
    let Some(session) = active_session(app).await else {
        log::warn!("no active session; cannot resolve approval");
        return;
    };

    match resolve_approval(app, &session, request_id, approve).await {
        Ok(ApprovalOutcome::Resolved) => {
            log::info!("approval request resolved");
        }
        Ok(ApprovalOutcome::AlreadyResolved) => {
            log::info!("approval request was already resolved elsewhere");
        }
        Err(reason) => {
            // Surface `reason` in a follow-up notification to the user.
            log::warn!("failed to resolve approval: {reason}");
        }
    }
}
```
