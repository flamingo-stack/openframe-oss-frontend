# macos_un.rs

macOS `UNUserNotificationCenter` backend for production (bundled) builds that handles delivering notifications and routing user interactions back into the app. Chosen over the deprecated `NSUserNotificationCenter` because it reliably captures clicks on live banners, historical Notification Center entries, and cold-start launches alike. Action buttons (Approve/Reject, Reply) let users resolve AI tool-approval requests or reply to Mingo messages without opening a window.

## Key Components

- **`init(app: &AppHandle)`** — Installs the notification delegate and registers action categories. No-ops for dev builds or processes without a bundle identifier, since the `UN` APIs require one.
- **`ensure_authorized()`** — Requests notification permission from the OS exactly once; denial is handled gracefully (user controls this in System Settings).
- **`post(title, body, click, user_id, kind)`** — Fires a notification off the main thread, embedding the click payload (`of-click-payload`) and the target user id (`of-user-id`) into `userInfo` so clicks remain actionable even after a process restart.
- **`category_for(kind: ActionKind)`** — Maps an `ActionKind` (`Default`, `Approval`, `Message`) to its registered category identifier.
- **`register_categories(center)`** — Defines the three notification categories and their actions: plain "Open", "Approve"/"Reject" for tool approvals, and "Reply"/"Open" for messages. Button visibility (buttons vs. "Options" menu) is controlled entirely by macOS notification style settings, not by this code.
- **`ROUTER` / `ACTIVE`** — Static state holding the `AppHandle` for routing clicks and a flag tracking whether the UN backend is active.

Session validation and the actual decision logic for actions live in the shared `notification_actions` module — this file only owns macOS-specific delivery, categories, and response decoding.

## Usage Example

```rust
// During Tauri setup
notifications::macos_un::init(&app_handle);
notifications::macos_un::ensure_authorized();

// Firing an approval notification
notifications::macos_un::post(
    "Tool Approval Required".to_string(),
    "Mingo wants to run a script".to_string(),
    Some(serde_json::json!({ "action": "approve_tool", "id": "123" })),
    Some("user-456".to_string()),
    ActionKind::Approval,
);
```
