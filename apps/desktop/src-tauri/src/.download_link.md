Handles the `openframe-console://download?id=<uuid>` deep link that the OpenFrame desktop shell uses to bring up the app and deliver an attribution id to the signup page, so the backend can credit a web visit (and its referral source) to the resulting account.

## Key Components

- **`DownloadLinkState`** — Tauri-managed state holding the latest pending download id behind a `Mutex`, until the frontend page retrieves it.
- **`is_download_link(url)`** — Checks whether a URL uses the app's custom scheme (`crate::URI_SCHEME`) and the `download` host (case-insensitive match).
- **`download_id_of(url)`** — Extracts the `id` query parameter and validates/normalizes it into a lowercase, hyphenated UUID string; returns `None` if missing or invalid.
- **`handle_url(app, url)`** — OS-level entry point invoked when the system delivers a URL on the app's scheme. Stores a valid id in `DownloadLinkState` and emits `EVENT_RECEIVED` (`download-link:received`) to the main window. Returns `true` if the URL was a download link (regardless of id validity), signaling the caller to focus/raise the app window. Only compiled on macOS/Windows.
- **`take_pending_download_id(state)`** — Tauri command exposed to the frontend. Pops (takes) the stored id, clearing it, so it is consumed exactly once per signup flow.

## Usage Example

```rust
// OS delivers a deep link via the platform's URL scheme handler
if handle_url(&app_handle, "openframe-console://download?id=0f8fad5b-d9cb-469f-a165-70867728950e") {
    // Link was recognized as a download link; bring the app window forward.
}
```

```typescript
// Frontend (native-shell.ts) consumes the id via the Tauri command,
// either on page load or after receiving the "download-link:received" event.
const id = await invoke<string | null>("take_pending_download_id");
if (id) {
  // store id in localStorage as attribution.downloadId until signup completes
}
```

This module performs no business logic beyond extracting and relaying the id — it exists purely to bridge an OS-level deep link into a one-time value the webview can read via a Tauri command.
