# make-placeholder-web.mjs

A Node.js build script that generates a minimal placeholder HTML bundle in the `www/` directory so the Tauri shell can compile without requiring a full `openframe-frontend` export. Tauri's `generate_context!` macro embeds `www/` at compile time, so this directory must exist even when the real frontend bundle hasn't been built yet.

## Key Components

- **Path resolution** — Computes the project `root` and `www`/`index.html` target paths relative to the script's own location using `fileURLToPath`.
- **`--if-missing` flag** — When passed, the script exits quietly (no-op) if `www/index.html` already exists, preventing accidental overwrites of a real staged bundle. Used by the `predev` hook.
- **HTML generation** — Builds a dark-themed placeholder page confirming the Tauri shell is running, displaying the injected `window.__ENV` value for debugging, and instructing developers to run `npm run build:web` for the real bundle.
- **File writer** — Uses `mkdirSync` (recursive) and `writeFileSync` to create the directory structure and write `index.html`.

## Usage Example

```bash
# Always (re)write the placeholder bundle
node make-placeholder-web.mjs

# Only write if www/index.html is missing (safe for dev hooks)
node make-placeholder-web.mjs --if-missing
```

Typical usage in `package.json`:

```json
{
  "scripts": {
    "predev": "node make-placeholder-web.mjs --if-missing",
    "build:web": "node make-placeholder-web.mjs && echo 'Replace with real export build'"
  }
}
```

This ensures `cargo tauri dev` or `cargo build` never fails due to a missing `www/` directory, while still allowing the real frontend export to take precedence once built.
