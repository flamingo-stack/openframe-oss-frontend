## Overview

A Node.js build-helper script that generates a minimal placeholder HTML bundle into the `www/` directory so the Tauri desktop shell can compile and run without requiring the full `openframe-frontend` web export. Since Tauri's `generate_context!` macro embeds `www/` at compile time, this directory must exist even before a real frontend build is staged.

## Key Components

- **`--if-missing` flag** — When passed, the script exits silently if `www/index.html` already exists, preventing accidental overwrite of a real staged bundle. Used by the `predev` hook.
- **Directory bootstrap** — Creates `www/` recursively via `mkdirSync` if it doesn't exist.
- **Placeholder HTML generation** — Writes a dark-themed, self-contained `index.html` with:
  - A status message confirming the Tauri shell is running.
  - Instructions to run `npm run build:web` for the real bundle.
  - A live-rendered dump of `window.__ENV` for debugging environment injection.

## Usage Example

Run directly via Node.js:

```bash
# Always (re)generate the placeholder bundle
node scripts/make-placeholder-web.mjs

# Only generate if www/index.html is missing (safe for dev hooks)
node scripts/make-placeholder-web.mjs --if-missing
```

Typical integration in `package.json`:

```json
{
  "scripts": {
    "predev": "node scripts/make-placeholder-web.mjs --if-missing",
    "build:web": "node scripts/build-real-frontend.mjs"
  }
}
```

This ensures `npm run dev` (which triggers `predev`) never fails due to a missing `www/` directory, while `npm run build:web` can later replace the placeholder with the actual production bundle.
