Vitest global setup file that configures the React testing environment so component tests correctly detect and report state updates outside of `act()` wrappers.

## Key Components

- **`IS_REACT_ACT_ENVIRONMENT` flag** — Sets the global flag that React's testing utilities check to enable `act()` environment behavior. Without this, React silently skips its "did you forget to wrap in `act()`" checks, causing tests to pass even when they shouldn't.
- **Typed cast pattern** — Uses `(globalThis as { IS_REACT_ACT_ENVIRONMENT?: boolean })` instead of `declare global` to avoid leaking the test-only flag into the application's TypeScript program, since this root config file is included in the app's tsconfig.

## Usage Example

This file is loaded automatically by Vitest via the `setupFiles` option and requires no direct import in test files:

```typescript
// vitest.config.ts
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    setupFiles: ['./vitest.setup.ts'],
  },
});
```

```typescript
// Any component test automatically benefits from this setup
import { render, screen } from '@testing-library/react';
import { act } from 'react-dom/test-utils';

test('reports state update outside act()', () => {
  // With IS_REACT_ACT_ENVIRONMENT set, this will correctly warn/fail
  // if state updates happen outside an act() wrapper
  render(<MyComponent />);
  // ...
});
```

No manual import or configuration is needed per test file — the flag is set once globally and inherited by every component test in the suite.
