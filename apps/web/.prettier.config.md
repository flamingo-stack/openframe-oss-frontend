Prettier configuration file that defines code formatting rules for the project by re-exporting a shared preset from the `@flamingo-stack/openframe-frontend-core` package.

## Key Components

- **Default export** — Re-exports the `shared` Prettier configuration object imported from `@flamingo-stack/openframe-frontend-core/eslint-config/prettier`.

This shared preset provides:
- Formatting rules that replicate the previous Biome formatter's output byte-for-byte (120-column line width, single quotes, trailing commas, avoided arrow function parentheses) to ensure migrating formatting engines doesn't trigger a mass restyle.
- Tailwind CSS class sorting, added on top of the Biome-equivalent baseline.

## Usage Example

Prettier automatically picks up this config when run from the project root:

```bash
# Format all files using the shared config
npx prettier --write .

# Check formatting without writing changes
npx prettier --check .
```

No local customization is needed or expected — the file intentionally stays minimal, delegating all formatting rules to the shared package so that configuration stays consistent across repositories using `@flamingo-stack/openframe-frontend-core`.

```javascript
// prettier.config.mjs
import shared from '@flamingo-stack/openframe-frontend-core/eslint-config/prettier';

export default shared;
```

If repo-specific overrides are ever needed, they should be spread alongside `shared` (e.g., `{ ...shared, printWidth: 100 }`) rather than replacing it entirely, to preserve the Tailwind sorting and formatter parity guarantees.
