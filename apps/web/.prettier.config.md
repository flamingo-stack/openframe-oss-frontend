This configuration file defines Prettier's code formatting rules for the project by re-exporting a shared preset from the internal `@flamingo-stack/openframe-frontend-core` package.

## Key Components

- **`shared` (default export)**: The Prettier configuration imported from `@flamingo-stack/openframe-frontend-core/eslint-config/prettier`, re-exported unchanged as this file's default export.

The shared preset provides:
- **Byte-for-byte compatibility** with the project's previous Biome formatter settings (120 column width, single quotes, trailing commas, arrow parentheses avoided where possible)
- **Tailwind CSS class sorting**, which is an addition on top of the Biome-equivalent baseline

## Usage Example

Prettier automatically picks up this config when run from the project root:

```bash
# Format all files using the shared config
npx prettier --write .

# Check formatting without writing changes
npx prettier --check .
```

If you need to reference the config programmatically (e.g., in tooling or editor integrations):

```javascript
import config from './prettier.config.mjs';

console.log(config);
// => outputs the resolved shared Prettier options
```

No local overrides are defined in this file by design — all formatting rules live in the shared `@flamingo-stack/openframe-frontend-core` package to keep formatting consistent across Flamingo Stack projects. If repo-specific formatting rules are ever needed, they should be merged into the `shared` object before exporting, but the current intent is to avoid that.
