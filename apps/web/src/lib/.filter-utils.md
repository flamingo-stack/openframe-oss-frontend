## filter-utils.ts

Provides shared utilities for normalizing and deduplicating filter options used across table filters in different screens (devices, logs, organizations, etc).

## Key Components

- **`FilterOption`** — Interface defining the standard shape of a filter option (`id`, `label`, `value`).
- **`deduplicateFilterOptions<T>(options)`** — Removes duplicate entries from a filter options array based on their `id`, using a `Map` for efficient uniqueness tracking. Safely handles `undefined`/`null`/non-array input by returning an empty array.
- **`transformOrganizationFilters(organizations)`** — Normalizes organization data from inconsistent backend shapes (`{ id, name }` from logs, `{ value, label, count }` from devices) into the unified `FilterOption` format, applying fallback values (`'system'`, `'Unknown'`) and deduplication automatically.

## Usage Example

```typescript
import { deduplicateFilterOptions, transformOrganizationFilters } from './filter-utils';

// Deduplicate raw filter options
const rawOptions = [
  { id: 'uuid-1', label: 'Acme', value: 'uuid-1' },
  { id: 'uuid-1', label: 'Acme', value: 'uuid-1' }, // duplicate
  { id: 'uuid-2', label: 'Other', value: 'uuid-2' },
];

const unique = deduplicateFilterOptions(rawOptions);
// [{ id: 'uuid-1', ... }, { id: 'uuid-2', ... }]

// Normalize organization data from different backend formats
const logsFormat = [{ id: 'org-1', name: 'Acme Corp' }];
const devicesFormat = [{ value: 'org-2', label: 'Other Inc', count: 5 }];

const filters = transformOrganizationFilters([...logsFormat, ...devicesFormat]);
// [
//   { id: 'org-1', label: 'Acme Corp', value: 'org-1' },
//   { id: 'org-2', label: 'Other Inc', value: 'org-2' }
// ]
```

These utilities are typically consumed by filter dropdown components to ensure consistent, duplicate-free option lists regardless of the originating API's response shape.
