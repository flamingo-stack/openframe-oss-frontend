Shared utility functions for normalizing and deduplicating table filter options across all screens (devices, logs, organizations, etc.).

## Key Components

| Export | Type | Description |
|---|---|---|
| `FilterOption` | Interface | Base structure for filter options (`id`, `label`, `value`) |
| `deduplicateFilterOptions<T>` | Function | Removes duplicate filter options by ID using a `Map` |
| `transformOrganizationFilters` | Function | Normalizes organization data from multiple backend formats into `FilterOption[]` |

## Usage Example

```typescript
import { deduplicateFilterOptions, transformOrganizationFilters } from './filter-utils';

// Deduplicate raw filter options
const raw = [
  { id: 'abc', label: 'Acme', value: 'abc' },
  { id: 'abc', label: 'Acme', value: 'abc' }, // duplicate
  { id: 'xyz', label: 'Other', value: 'xyz' },
];
const unique = deduplicateFilterOptions(raw);
// [{ id: 'abc', ... }, { id: 'xyz', ... }]

// Normalize organizations from logs format ({ id, name })
const fromLogs = transformOrganizationFilters([
  { id: 'org-1', name: 'Flamingo Corp' },
  { id: 'org-2', name: 'null' }, // mapped to 'System'
]);
// [{ id: 'org-1', label: 'Flamingo Corp', value: 'org-1' },
//  { id: 'org-2', label: 'System', value: 'org-2' }]

// Normalize organizations from devices format ({ value, label })
const fromDevices = transformOrganizationFilters([
  { value: 'org-3', label: 'Acme' },
]);
// [{ id: 'org-3', label: 'Acme', value: 'org-3' }]
```

## Notes

- `deduplicateFilterOptions` is generic — accepts any type extending `FilterOption`, preserving additional fields.
- `transformOrganizationFilters` maps the `'null'` string name (backend sentinel) to the display label `'System'`.
- Both functions return an empty array for `null`, `undefined`, or non-array input.
