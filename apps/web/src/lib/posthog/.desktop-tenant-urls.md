# desktop-tenant-urls.ts

Rewrites PostHog event URLs captured from the Tauri desktop app so they report the tenant's web origin instead of the generic `tauri://localhost` (or `http://tauri.localhost` on Windows) origin the desktop shell actually runs on. This lets analytics filter desktop sessions by tenant the same way web sessions already can, while `app_platform: desktop` still distinguishes the two.

## Key Components

- **`webOrigin()`** — Resolves the origin to move URLs to. Returns the tenant host URL (`runtimeEnv.tenantHostUrl()`) only when a user is signed in (per `useAuthStore`); otherwise falls back to the shared host URL (`runtimeEnv.sharedHostUrl()`), mirroring the web app's behavior before authentication.
- **`moveToTenantOrigin(capture: PostHogCapture): PostHogCapture`** — The exported PostHog `before_send` hook. Rewrites:
  - String properties in `capture.properties`, `$set`, and `$set_once` that are full URLs or bare hosts (matched via `BARE_HOST_KEY`) pointing at the current window origin.
  - Session recording events (`$snapshot_data`), specifically `data.href` on compressed full snapshots.
  - Heatmap data (`$heatmap_data`), which is keyed by page URL.

  All rewriting is wrapped in a `try/catch` since analytics capture must never fail the app.

- **`BARE_HOST_KEY`** — Regex matching property keys ending in `host` or `referring_domain`, including PostHog's auto-derived `$initial_` and `$session_entry_` variants.
- **`RecordingEvent`** — Type describing an rrweb event, where `data` may be a string (compressed) or an object with an optional `href`.

## Usage Example

```typescript
import posthog from 'posthog-js';
import { moveToTenantOrigin } from './desktop-tenant-urls';

posthog.init(apiKey, {
  api_host: apiHost,
  before_send: moveToTenantOrigin,
});
```

This is wired into PostHog initialization so every captured event, recording snapshot, and heatmap point is transparently remapped from the desktop app's local origin to the correct tenant (or shared) web origin before being sent.
