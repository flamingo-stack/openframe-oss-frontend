## posthog-events.ts

Signup-funnel analytics helpers that push events to the GTM `dataLayer` (not a bundled PostHog SDK) for the paid-ads journey spanning landing, auth, signup, and dashboard. GTM routes these `dataLayer` events to PostHog, GA, ads platforms, and HubSpot. Also handles cross-domain session handoff by reading the GTM-loaded `window.posthog` instance.

## Key Components

- **`FUNNEL_EVENTS`** — Constant map of dataLayer event names (`signup_started`, `signup_completed`, `identify`) that must match GTM trigger configuration.
- **`queueDesktopPostHogSetup()`** — Queues desktop-specific PostHog config (`before_send` hook, `app_platform` tag) onto `window.posthog` before GTM loads, so the SDK replays the queue correctly.
- **`pushSignupStarted()`** — Fires when the signup form is rendered or first interacted with.
- **`pushSignupCompleted(userId, email?)`** — Fires on successful signup, keyed on the OpenFrame `user.id` to align with HubSpot.
- **`pushIdentify({ userId, email })`** — Links the anonymous session to a person for PostHog/HubSpot identify resolution.
- **`markPendingSignup()` / `consumePendingSignup()`** — Session-storage marker pair ensuring `signup_completed` fires exactly once, deferred until the authenticated session with a `user.id` resolves (handles both email and SSO flows).
- **`appendPosthogHandoff(url)`** — Appends `distinct_id`/`session_id` as a URL hash fragment so cross-domain redirects (auth host → tenant dashboard) continue the same PostHog session recording.

## Usage Example

```typescript
import {
  pushSignupStarted,
  pushSignupCompleted,
  pushIdentify,
  markPendingSignup,
  consumePendingSignup,
  appendPosthogHandoff,
  queueDesktopPostHogSetup,
} from '@/lib/posthog/posthog-events';

// Before GTM loads, in the desktop shell
queueDesktopPostHogSetup();

// On signup form render
pushSignupStarted();

// On any signup submission path (email or SSO)
markPendingSignup();

// After the authenticated session resolves with user info
if (consumePendingSignup()) {
  pushSignupCompleted(user.id, user.email);
  pushIdentify({ userId: user.id, email: user.email });
}

// Redirecting from auth host to tenant dashboard host
const redirectUrl = appendPosthogHandoff('https://tenant.openframe.ai/dashboard');
window.location.href = redirectUrl;
```
