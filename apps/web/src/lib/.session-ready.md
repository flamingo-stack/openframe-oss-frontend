# session-ready.ts

A client-side gate that holds application data requests until the user session has resolved (signed in or signed out), preventing premature `401`s and pointless server-side fetches while still letting pages render immediately with their own loading states.

## Key Components

- **`markSessionReady()`** — Marks the session as resolved/signed-in. Idempotent; releases any requests waiting on the gate.
- **`resetSessionReady()`** — Marks the session as resolved/signed-out. Idempotent; releases waiting requests (does **not** re-hold future ones — a signed-out state means requests should proceed and let the API's `401` drive the refresh/force-logout flow).
- **`waitForSessionReady()`** — Returns a `Promise<void>` to await before issuing a data request, or `undefined` if the gate is already open (session resolved, fail-open triggered, or running on the server). Server renders never wait, since a pending Suspense boundary would keep the HTTP response stream open indefinitely.
- **`FAIL_OPEN_AFTER_MS`** (10s) — Safety timeout ensuring a stuck session never produces an infinite skeleton; after this window, parked requests are released and allowed to fail/retry normally.

## Usage Example

```typescript
import { waitForSessionReady, markSessionReady, resetSessionReady } from './session-ready';

// In a query/fetch wrapper used by app data hooks:
async function fetchAppData(url: string, options?: RequestInit) {
  await waitForSessionReady(); // resolves immediately once session is known, or on timeout
  return fetch(url, options);
}

// In the bootstrap `/me` query (must bypass the gate itself):
async function fetchMe() {
  const response = await fetch('/api/me', { /* ...skipSessionGate logic... */ });
  if (response.ok) {
    markSessionReady();
  } else {
    resetSessionReady();
  }
  return response;
}
```

**Important:** Bootstrap calls (`/me`, feature flags) must bypass this gate entirely, since they're what resolves the session in the first place. `AuthApiClient` (sign-in/sign-out) uses raw `fetch` and is unaffected.
