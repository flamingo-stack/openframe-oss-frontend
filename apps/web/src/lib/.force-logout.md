## force-logout.ts

Provides a centralized, defensive mechanism for forcibly signing out a user by clearing authentication tokens, resetting application state, and optionally redirecting to the login page. It is designed to be resilient to partial failures, ensuring each cleanup step runs independently even if a prior step throws.

## Key Components

- **`ForceLogoutOptions`** — Configuration interface controlling redirect behavior (`shouldRedirect`, `redirectPath`) and an optional `reason` for logging/debugging.
- **`forceLogout(options?)`** — Async function that performs a full logout sequence:
  - Bails early if a biometric cold-start lock is active (prevents wiping tokens the unlock gate still needs to recover).
  - Clears stored tokens via `clearTokens()`.
  - Settles the `['auth', 'session']` React Query cache entry to `null` (not invalidation, to avoid re-triggering a `/me` fetch that could recurse back into logout).
  - Resets the auth store (`useAuthStore`) and Mingo context store, using dynamic imports to avoid static coupling to feature modules.
  - Redirects via `window.location.replace` (not `assign`) unless already on an auth page or running in SaaS-tenant mode (where no reload occurs).
- **`hasStoredTokens()`** — Synchronous check for presence of stored auth tokens.
- **`clearStoredTokens()`** — Fire-and-forget token clearing helper.

## Usage Example

```typescript
import { forceLogout, hasStoredTokens } from './force-logout';

// Standard forced logout with redirect to default login page
await forceLogout({ reason: 'token-expired' });

// Force logout without redirecting (e.g., caller handles navigation)
await forceLogout({ shouldRedirect: false });

// Redirect to a specific path after logout
await forceLogout({ redirectPath: '/auth/session-expired' });

// Check token presence before deciding to log out
if (hasStoredTokens()) {
  await forceLogout();
}
```

**Note:** This module is intended for use in low-level API/auth infrastructure (e.g., HTTP interceptors reacting to 401 responses) rather than direct UI event handlers, since it performs hard navigation and full state resets.
