## graphql-scalars.ts

Defines TypeScript types and parsing/construction utilities for the custom GraphQL scalars declared in `schema.graphql` (`Instant`, `Date`, `Long`, `JSON`). These types are wired into Relay's generated artifacts via `customScalarTypes` in `relay.config.json`, and this module is the single source of truth for how each scalar's wire format is read and produced.

Since Relay's store only keeps the raw wire value for scalars (no runtime transformation), this file bridges the gap between the wire format and native JavaScript `Date` objects, using branded string types to prevent accidentally mixing `Instant` and `LocalDate` values.

## Key Components

- **`Instant`** — branded string type for RFC 3339 UTC instants (up to nanosecond precision, as emitted by Java's `Instant.toString()`).
- **`LocalDate`** — branded string type for calendar days (`yyyy-MM-dd`, no time/zone).
- **`Long`** — plain `number` alias; wire values beyond `2^53` lose precision in JavaScript.
- **`JsonValue`** — opaque `unknown` alias for the `JSON` scalar.
- **`parseInstant(instant)`** — parses an `Instant` string into a `Date` (millisecond precision), truncating excess fraction digits; returns `null` if invalid.
- **`toInstant(date)`** — serializes a `Date` to an `Instant`.
- **`isInstant(value)`** — type guard validating a string is a parseable `Instant`.
- **`parseLocalDate(day)`** — parses a `yyyy-MM-dd` string into a `Date` at local midnight (avoids UTC-shift bugs); returns `null` if invalid.
- **`toLocalDate(date)`** — serializes a `Date`'s local calendar day to a `LocalDate`.
- **`addLocalDays(day, days)`** — adds/subtracts whole calendar days to a `LocalDate`, safe across daylight-saving transitions.
- **`asInstant(value)`** — asserts and casts a plain string to `Instant`, throwing if it's not parseable.

## Usage Example

```typescript
import {
  parseInstant,
  toInstant,
  parseLocalDate,
  toLocalDate,
  addLocalDays,
  asInstant,
  type Instant,
  type LocalDate,
} from './graphql-scalars';

// Reading a server-provided Instant scalar
const createdAt: Instant = asInstant('2026-09-23T09:04:26.847000044Z');
const jsDate = parseInstant(createdAt); // Date | null

// Building an Instant to send back
const now: Instant = toInstant(new Date());

// Working with a LocalDate (calendar day picker)
const due: LocalDate = toLocalDate(new Date());
const nextWeek = addLocalDays(due, 7); // LocalDate | null

if (parseLocalDate(due)) {
  console.log('Valid local date:', due);
}
```
