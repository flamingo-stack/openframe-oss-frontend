# app-mode.ts

Centralizes application mode logic, controlling whether the app runs as an auth-only shared SaaS deployment, a full-featured SaaS tenant, or a self-hosted OSS tenant. It drives route gating, redirect targets, and UI feature toggles based on the `NEXT_PUBLIC_APP_MODE` environment variable and the runtime shell (web, Capacitor mobile/desktop).

## Key Components

- **`AppMode`** — union type: `'oss-tenant' | 'saas-tenant' | 'saas-shared'`
- **`getAppMode()`** — reads the current mode from `runtimeEnv`, defaults to `'oss-tenant'`
- **`isOssTenantMode()` / `isSaasTenantMode()` / `isSaasSharedMode()`** — mode predicates
- **`isAuthOnlyMode()`** — backward-compatible alias for `isSaasSharedMode()`
- **`isSharedAuthUi()`** — whether to render the SaaS shared-auth sign-up UX (subdomain field, trial copy), accounting for the native shell's bundled auth pages
- **`isMobileAuthLoginOnly()` / `isLoginOnlyMobileShell()`** — gate the login-only mobile auth flow (App Store compliance for in-app purchase rules)
- **`isFullAppMode()` / `isAuthEnabled()` / `isAppEnabled()`** — feature-area toggles for auth vs. app pages
- **`isRouteAllowedInCurrentMode(pathname)`** — determines if a route is reachable in the current mode (always allows Next.js internals, account-deletion page, blocks mobile-only download-apps page on phone, etc.)
- **`getDefaultRedirectPath(isAuthenticated)`** — computes the landing redirect based on mode/shell/auth state
- **`getLandingPath()`** — returns `/mingo` for SaaS tenants, dashboard route for OSS
- **`shouldShowNavigationSidebar()` / `shouldShowAppPages()`** — UI visibility helpers

## Usage Example

```typescript
import {
  getAppMode,
  isRouteAllowedInCurrentMode,
  getDefaultRedirectPath,
} from './app-mode';

// Check current mode
if (getAppMode() === 'saas-shared') {
  console.log('Running in auth-only shared SaaS mode');
}

// Route guard in middleware
if (!isRouteAllowedInCurrentMode(pathname)) {
  const redirectTo = getDefaultRedirectPath(isAuthenticated);
  return redirect(redirectTo);
}
```

**Important:** `isRouteAllowedInCurrentMode` intentionally avoids checks that depend on async-loaded state (e.g., billing flags). Pages depending on in-flight data must self-gate using a tri-state (`loading | on | off`) pattern instead of being blocked here.
