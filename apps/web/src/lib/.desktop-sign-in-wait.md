# desktop-sign-in-wait.ts

A module-level store that tracks the in-progress desktop browser sign-in, allowing auth screens to display a "waiting on browser" state instead of the login form. Since `nativeLogin` (the single entry point for all desktop sign-in flows) is not a component, this state is kept outside React/Vue component state so it can be published from anywhere and outlives any particular screen.

## Key Components

- **`DesktopSignInWait`** — Interface describing an in-flight sign-in: the `loginUrl` opened in the browser, an optional `email`, and a `deadline` (epoch ms) after which the shell gives up.
- **`DESKTOP_LOGIN_TIMEOUT_MS`** — Constant (5 minutes) mirroring the desktop shell's `LOGIN_TIMEOUT` in `apps/desktop/src-tauri/src/lib.rs`, used by tests and UI countdowns.
- **`beginDesktopSignInWait(wait)`** — Publishes a new wait and returns an "end" callback. The returned callback only clears state if this wait is still the current one, so a superseded wait (e.g., a new sign-in starting before the old one resolves) can't incorrectly clear the newer wait's screen.
- **`getDesktopSignInWait()`** — Synchronously reads the current wait, or `null` if none is active.
- **`subscribeDesktopSignInWait(listener)`** — Registers a listener invoked on every publish/clear; returns an unsubscribe function. Useful for syncing external stores (e.g., `useSyncExternalStore`).

## Usage Example

```typescript
import {
  beginDesktopSignInWait,
  getDesktopSignInWait,
  subscribeDesktopSignInWait,
  DESKTOP_LOGIN_TIMEOUT_MS,
} from "./desktop-sign-in-wait";

// Starting a sign-in
const endWait = beginDesktopSignInWait({
  loginUrl: "https://app.example.com/login?session=abc",
  email: "user@example.com",
  deadline: Date.now() + DESKTOP_LOGIN_TIMEOUT_MS,
});

// Later, when the browser sign-in completes or is cancelled
endWait();

// In a UI component, subscribe to changes
const unsubscribe = subscribeDesktopSignInWait(() => {
  const wait = getDesktopSignInWait();
  if (wait) {
    console.log(`Waiting on ${wait.loginUrl} until ${new Date(wait.deadline)}`);
  } else {
    console.log("No active sign-in wait");
  }
});
```
