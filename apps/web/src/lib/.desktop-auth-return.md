# desktop-auth-return.ts

Implements the browser-side landing page logic for desktop sign-in callbacks. The desktop shell launches login in the system browser; since redirecting directly to a custom scheme leaves the credential form committed as the "last page" (making it look like a failed login), the gateway instead redirects to a web page under our control, which then reads the result and hands it off to the desktop app's registered URI scheme.

The hand-off data is placed in the URL fragment (after `#`) rather than the query string, so sensitive tickets never reach server logs and aren't prematurely consumed by other fragment-unaware observers.

## Key Components

- **`DESKTOP_APP_SCHEME`** - Constant string `'openframe-console'`, the desktop shell's registered URI scheme. Hardcoded to prevent URL-controlled protocol handler hijacking.
- **`desktopAuthReturnTarget(sharedHostUrl)`** - Builds the `redirectTo` URL the desktop login requests from the gateway, ending in `/#` so appended params land in the fragment.
- **`DesktopAuthReturn`** - Discriminated union describing the parsed outcome: `signed-in`, `signup`, `error`, `incomplete`, or `none`.
- **`readDesktopAuthReturn(location)`** - Parses the current page's URL fragment and returns a `DesktopAuthReturn`, building the appropriate `openframe-console://auth?...` scheme URL.
- **`landingLocation(location, navigation)`** - Recovers the originally-loaded URL (including fragment) when the app router has already rewritten the address bar, using the Performance Navigation Timing entry as a fallback.
- **`launchDesktopApp(url)`** - Invokes `window.location.assign(url)` to hand the scheme URL to the OS without navigating away from the current page.

## Usage Example

```typescript
import {
  readDesktopAuthReturn,
  landingLocation,
  launchDesktopApp,
} from './desktop-auth-return';

// On the desktop-return landing page, after hydration:
const navEntry = performance.getEntriesByType('navigation')[0] as PerformanceEntry | undefined;
const location = landingLocation(window.location, navEntry);

const result = readDesktopAuthReturn(location);

switch (result.kind) {
  case 'signed-in':
  case 'signup':
  case 'error':
    launchDesktopApp(result.appUrl);
    break;
  case 'incomplete':
    // Gateway issued nothing - fail fast instead of waiting for the shell's timeout
    launchDesktopApp(result.appUrl);
    break;
  case 'none':
    // Stray visit with no fragment; do nothing
    break;
}
```
