Tracks which chat dialog IDs are currently visible on screen (e.g., in a Mingo page or chat drawer), enabling the notifications pipeline to suppress popups and auto-mark-read for messages the user is already watching.

## Key Components

| Export | Type | Description |
|---|---|---|
| `registerActiveDialogView` | `(dialogId: string) => () => void` | Increments the view count for a dialog and returns a cleanup function to decrement on unmount. Supports multiple concurrent mounts of the same dialog via reference counting. |
| `isDialogViewActive` | `(dialogId: string) => boolean` | Returns `true` if at least one live surface is currently displaying the given dialog. |
| `subscribeActiveDialogViews` | `(listener: () => void) => () => void` | Registers a change listener compatible with React's `useSyncExternalStore`. Returns an unsubscribe cleanup. |
| `getActiveDialogViews` | `() => ReadonlySet<string>` | Returns the current stable snapshot of all on-screen dialog IDs. |
| `getServerActiveDialogViews` | `() => ReadonlySet<string>` | Server-safe stub that always returns an empty set (for SSR compatibility). |

## Usage Example

```typescript
import {
  registerActiveDialogView,
  isDialogViewActive,
  subscribeActiveDialogViews,
  getActiveDialogViews,
} from './active-dialog-views';

// In a chat drawer component — register on mount, unregister on unmount
useEffect(() => {
  return registerActiveDialogView(dialogId);
}, [dialogId]);

// In the notifications pipeline — skip popup if user is already watching
if (isDialogViewActive(incomingMessage.dialogId)) {
  return; // suppress notification
}

// With useSyncExternalStore for reactive subscriptions
const activeViews = useSyncExternalStore(
  subscribeActiveDialogViews,
  getActiveDialogViews,
  getServerActiveDialogViews,
);
```

> **Note:** `registerActiveDialogView` is reference-counted — if the same `dialogId` is mounted in two places simultaneously, the view remains active until both call their cleanup functions.
