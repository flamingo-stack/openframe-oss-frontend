## chat-stream-thread.ts

Shape bridge between the app's legacy `Message` type (content as `string | MessageSegment[]`) and the lib's `UnifiedChatMessage` type (content as `string` with optional `segments`), used during Phase 4 of chat unification where the lib's reducer owns all message accumulation and the app keeps only a converted read-mirror.

Conversion is cached bidirectionally by object identity (via `WeakMap`), guaranteeing that an untouched reducer message always converts back to the *same* app message instance. This referential stability is essential for React memoization and history-merge reference reuse to keep working correctly.

## Key Components

- **`toUnifiedMessage(message)`** — Converts an app `ChatMessage` into a reducer `UnifiedChatMessage`, moving array content into the `segments` field. Cached both ways.
- **`fromUnifiedMessage(unified, defaults)`** *(module-private)* — Converts a reducer row back into an app `ChatMessage`, stamping assistant identity/timestamp on reducer-originated rows (turn bubbles, participant rows).
- **`computeIncompleteTailState(messages)`** — Wraps the lib's `extractIncompleteTailState` to seed the reducer's accumulator (pending approvals, executing tools, trailing segments) from a hydrated thread's incomplete tail.
- **`makeChatRowId(prefix)`** — Generates a collision-resistant id for locally-authored optimistic rows (timestamp + random suffix).
- **`adminDisplayName(user)`** — Formats an operator's display name, falling back to `'Admin'`.
- **`ReducerMirrorSnapshot`**, **`ReducerMirrorConfig<K>`**, **`BoundMirror`**, **`ReducerMirror<K>`** — Interfaces defining a factory that mirrors a `ChatDialogStore` reducer's state into app-shape snapshots, keyed by a host-defined key type `K`. Handles per-key binding (`bind`), hydration (`hydrate`), event application, eviction tracking, and cross-key sibling projections (approvals/tool execution merges).
- **`ThreadIdentityDefaults`**, **`HydrateOptions`** — Supporting config types for assistant identity defaults and hydration replay behavior.

## Usage Example

```typescript
import { toUnifiedMessage, computeIncompleteTailState, makeChatRowId } from './chat-stream-thread';

// Convert an app message before feeding it to the reducer
const unified = toUnifiedMessage(appMessage);

// Seed accumulator state from a hydrated (fetched) thread
const extras = computeIncompleteTailState(fetchedMessages);
reducer.initializeWithState(thread, extras);

// Create an optimistic local row id
const rowId = makeChatRowId('user-msg');
```

Hosts typically consume this module through a `ReducerMirror` instance (built via `ReducerMirrorConfig`), calling `mirror.bind(key)` to get a `BoundMirror` with `apply`, `hydrate`, and `mutate` methods scoped to a specific `(dialogId, side)` pair.
