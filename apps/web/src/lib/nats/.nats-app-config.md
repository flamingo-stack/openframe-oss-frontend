Provides a React context and hook for building and managing NATS WebSocket connection configuration, handling authentication state, token rotation, and URL revision tracking for the OpenFrame dashboard.

## Key Components

### `NatsAppConfig` Interface
Configuration object exposed via context:
- `getWsUrl()` — Returns the computed NATS WebSocket URL, or `null` if prerequisites are unmet
- `onBeforeReconnect()` — Async callback invoked before reconnect attempts; refreshes the session and token
- `urlRevision` — Stable string that changes whenever any URL-affecting dependency changes, used to trigger reconnects
- `isAuthenticated` — Current auth state from the auth store
- `userId` — Current user ID, or `null` if unauthenticated

### `NatsAppConfigProvider`
Wraps children with `NatsAppConfigContext`, driven by `useNatsAppConfigState`.

### `useNatsAppConfig()`
Hook to consume `NatsAppConfig` from context. Throws if used outside `<NatsAppConfigProvider>`.

### Internal: `useNatsAppConfigState()`
Core state logic:
- Resolves the API base URL once on mount (`tenantHostUrl` → `window.location.origin`)
- In **bearer auth mode**, subscribes to token changes via both `window.storage` events and a native token-store emitter to keep the cached token fresh
- Derives `urlRevision` as a pipe-delimited string encoding all connection-relevant state

## Usage Example

```typescript
// Wrap your app (typically done by NatsAppProvider)
export function AppRoot({ children }: { children: ReactNode }) {
  return (
    <NatsAppConfigProvider>
      {children}
    </NatsAppConfigProvider>
  );
}

// Consume inside any child component
function MyNatsConsumer() {
  const { getWsUrl, urlRevision, isAuthenticated } = useNatsAppConfig();

  useEffect(() => {
    const url = getWsUrl();
    if (url) {
      // establish NATS WebSocket connection
    }
  }, [urlRevision]); // re-run whenever connection params change
}
```
