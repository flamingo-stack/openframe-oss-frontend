# nats-app-config.tsx

Provides application-level configuration for NATS WebSocket connections, including dynamic WebSocket URL construction, authentication token handling, and reconnection decision logic that integrates with the app's auth and session health systems.

## Key Components

- **`decideReconnect(context)`** — Async function implementing `NatsBeforeReconnect` policy. Decides whether to continue, pause, or terminate NATS reconnection attempts based on session state (`isSessionGone`, `isPausedFor`), an `/api/me` health check, and a cooldown-guarded forced token refresh when the session is alive but the socket keeps failing.
- **`NatsAppConfig`** — Interface describing the config shape consumed by the NATS provider: `getWsUrl`, `onBeforeReconnect`, `urlRevision`, `isAuthenticated`, `userId`.
- **`NatsAppConfigProvider`** — React context provider component that computes and supplies `NatsAppConfig` to descendants.
- **`useNatsAppConfig()`** — Hook to consume the `NatsAppConfig` context; throws if used outside the provider.
- **`useNatsAppConfigState()`** (internal) — Builds the config value: resolves the API base URL, subscribes to bearer token changes via `useSyncExternalStore`, and derives a `urlRevision` string that changes whenever any input affecting the WebSocket URL changes.
- **`getApiBaseUrl()` / `getAccessToken()`** (internal helpers) — Resolve the tenant host URL or fall back to `window.location.origin`, and fetch the current access token synchronously.

## Usage Example

```typescript
import { NatsAppConfigProvider, useNatsAppConfig } from '@/path/to/nats-app-config';

function App({ children }: { children: React.ReactNode }) {
  return <NatsAppConfigProvider>{children}</NatsAppConfigProvider>;
}

function NatsConsumer() {
  const { getWsUrl, onBeforeReconnect, urlRevision, isAuthenticated } = useNatsAppConfig();

  if (!isAuthenticated) return null;

  const wsUrl = getWsUrl();
  // Use wsUrl, onBeforeReconnect, and urlRevision to configure
  // a lower-level NATS connection provider (e.g. <NatsAppProvider>).
  return <div>Connected: {String(!!wsUrl)}</div>;
}
```

This config is typically consumed internally by a NATS connection provider (e.g., `NatsAppProvider`) rather than directly by feature code — components should use the connection hooks exposed by that provider instead.
