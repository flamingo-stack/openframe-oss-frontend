Composes the NATS connection provider for the OpenFrame frontend app by wiring together configuration and the core `NatsProvider` with app-specific reconnection and client settings.

## Key Components

- **`NatsAppProvider`** — Public root component. Wraps children with `NatsAppConfigProvider` and delegates NATS wiring to the internal `NatsProviderWiring` component.
- **`NatsProviderWiring`** — Internal component that consumes `useNatsAppConfig` to extract the WebSocket URL resolver, reconnect hook, and URL revision, then passes them alongside static config to the core `NatsProvider`.
- **`RECONNECTION_BACKOFF`** — Static reconnection strategy: 3 fast retries at 200 ms intervals before falling back to standard backoff.
- **`CLIENT_CONFIG`** — Static NATS client identity (`openframe-frontend-app`, `machine` user).

## Usage Example

```typescript
// Wrap your app's root layout with NatsAppProvider
import { NatsAppProvider } from '@/providers/nats-app-provider';

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <NatsAppProvider>
      {children}
    </NatsAppProvider>
  );
}
```

> **Note:** `NatsAppProvider` must be rendered in a Client Component context (`'use client'`). It relies on `NatsAppConfigProvider` to supply the dynamic WebSocket URL and token-refresh logic — configure those via the `nats-app-config` module before using this provider.
