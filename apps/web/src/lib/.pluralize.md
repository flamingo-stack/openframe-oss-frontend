Utility module for pluralizing English nouns based on a numeric count, with support for irregular plural forms and locale-aware count formatting.

## Key Components

- **`pluralize(count, noun)`** — Returns a formatted string combining a comma-separated count with the correctly pluralized noun (e.g., `"1 day"`, `"1,234 devices"`). Uses the default `-s` suffix rule for pluralization.
- **`pluralNoun(count, singular, plural?)`** — Returns just the singular or plural form of a noun based on `count`, without the count prefix. Defaults to appending `s` to `singular` if no `plural` override is provided, allowing irregular plurals (e.g., `"policy"` / `"policies"`) to be specified explicitly.

## Usage Example

```typescript
import { pluralize, pluralNoun } from './pluralize';

// Standard pluralization with count
pluralize(1, 'device');       // "1 device"
pluralize(1234, 'device');    // "1,234 devices"

// Irregular plural forms
pluralize(3, 'policy', 'policies'); // Note: pluralize doesn't take a custom plural
pluralNoun(1, 'policy', 'policies'); // "policy"
pluralNoun(3, 'policy', 'policies'); // "policies"

// Common use case: dynamic UI labels
const count = 5;
const label = `${pluralize(count, 'alert')}`; // "5 alerts"
```

Note: `pluralize` relies on `formatCount` from `./format-number` to render the numeric portion with locale-appropriate formatting (e.g., thousands separators), while `pluralNoun` handles only the noun's grammatical form and can be used independently when the count is displayed separately from the noun.
