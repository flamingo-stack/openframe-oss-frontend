## fae-app.ts

Provides a utility for launching **Fae**, the end-user chat application installed alongside the agent on a device, via its custom URL scheme. The module determines whether launching Fae is appropriate for the current platform and dispatches the deep link accordingly.

## Key Components

- **`FAE_APP_URL`** — Constant holding the custom URL scheme (`openframe-chat://open`) used to bring the Fae chat window to the foreground. The scheme is registered by the Fae app itself (via `HKCU` on Windows or `Info.plist` on macOS).
- **`canOpenFaeApp()`** — Returns `true` if the current shell is not mobile, since Fae only runs on desktop machines where the agent is installed.
- **`openFaeApp()`** — Triggers the OS to open the Fae app link. Uses `window.open` in the desktop shell context (handled via `APP_LINK_SCHEMES`), or `window.location.assign` in a browser context, where the user may be prompted to confirm opening the external app.

## Usage Example

```typescript
import { canOpenFaeApp, openFaeApp } from './fae-app';

function handleOpenFaeClick() {
  if (!canOpenFaeApp()) {
    console.warn('Fae is not available on this platform.');
    return;
  }

  openFaeApp();
}
```

**Notes:**
- Neither `canOpenFaeApp()` nor `openFaeApp()` can detect if Fae is actually installed — if it isn't, the link silently does nothing.
- This module depends on `isDesktopShell` and `isMobileShell` from `./platform` to determine the runtime environment before attempting to open the app.
