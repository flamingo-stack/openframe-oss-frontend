Utility module for converting between day-granular date filter values, URL query parameters, and GraphQL `Instant` scalars. It provides shared logic for table-based date range filters (e.g., Logs, Customers) to encode/decode dates in URLs and compute inclusive UTC bounds for backend queries.

## Key Components

- **`toDayParam(date: Date): string`** — Formats a `Date` into a local `yyyy-MM-dd` string suitable for URL params.
- **`parseDayParam(value: string): Date | undefined`** — Parses a `yyyy-MM-dd` string back into a `Date`, returning `undefined` if invalid.
- **`dateRangeFromParams(dateFrom: string, dateTo: string): DateRange | undefined`** — Rebuilds a `DateRange` object from `dateFrom`/`dateTo` URL params, returning `undefined` if both are empty.
- **`dateRangeToInstantBounds(range: DateRange | undefined): { from?: Instant; to?: Instant }`** — Converts a local `DateRange` into inclusive UTC `Instant` bounds (start of day for `from`, end of day for `to`), falling back to `from` as the upper bound when `to` is not set (single-day selection).

## Usage Example

```typescript
import { toDayParam, parseDayParam, dateRangeFromParams, dateRangeToInstantBounds } from './date-filter-params';

// Encode a date for the URL
const param = toDayParam(new Date('2024-03-15')); // "2024-03-15"

// Decode from URL params
const range = dateRangeFromParams('2024-03-01', '2024-03-15');
// { from: Date(2024-03-01), to: Date(2024-03-15) }

// Convert to backend query bounds
const { from, to } = dateRangeToInstantBounds(range);
// from: Instant at 2024-03-01T00:00:00Z (local start of day)
// to: Instant at 2024-03-15T23:59:59.999Z (local end of day)

// Single-day selection (no `to`)
const singleDay = dateRangeFromParams('2024-03-10', '');
const bounds = dateRangeToInstantBounds(singleDay);
// to defaults to end of the same day as `from`
```
