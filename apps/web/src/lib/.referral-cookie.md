# referral-cookie.ts

Captures partner-referral codes from the `?ref=` URL parameter and persists them in a cross-subdomain cookie (`of_ref`), enabling attribution to survive the hop from the marketing site (`openframe.ai`) to the signup app (`auth.openframe.ai`). This cookie is read back at registration and sent as `attribution.ref`.

A cookie is used instead of localStorage because localStorage is origin-scoped and cannot bridge subdomains, while a cookie scoped to the registrable base domain (`.openframe.ai`) can. The policy is **last-touch wins**: a new `?ref=` overwrites the stored code and restarts the 90-day window, but visits without `?ref=` never clear it.

## Key Components

- **`REFERRAL_URL_PARAM`** — query param name (`ref`) carried by partner links.
- **`REFERRAL_COOKIE_NAME`** — cookie name (`of_ref`), shared with the marketing site.
- **`REFERRAL_COOKIE_MAX_AGE_SECONDS`** — 90-day attribution window.
- **`REFERRAL_CODE_MAX_LENGTH`** — max allowed code length (64).
- **`sanitizeReferralCode(raw)`** — validates a raw string against an allowlist pattern (`A-Za-z0-9._-`), returning a clean code or `undefined`.
- **`resolveReferralCookieDomain(hostname)`** — computes the cookie `Domain` attribute (e.g. `.openframe.ai`), or `undefined` for non-cookieable hosts (localhost, IPs, `*.vercel.app`).
- **`buildReferralCookie(code, hostname, options)`** — builds a `CookieAttributes` object (non-HttpOnly, `SameSite=Lax`, path `/`, 90-day max-age) ready to be written.
- **`readReferralCode()`** — reads and re-validates the stored referral code.
- **`captureReferralFromUrl()`** — reads `?ref=` from the current URL and writes the cookie if the code is valid and differs from what's already stored (avoiding unnecessary rewrites that would shorten Safari ITP lifetimes).

## Usage Example

```typescript
import { captureReferralFromUrl, readReferralCode } from './referral-cookie';

// Call once per page load (e.g. in app-wide attribution capture logic)
captureReferralFromUrl();

// Later, at signup time, read the stored code for the registration payload
const referralCode = readReferralCode();
if (referralCode) {
  submitRegistration({ attribution: { ref: referralCode } });
}
```

Note: `captureReferralFromUrl` is a no-op outside the browser (`typeof window === 'undefined'`), making it safe to call during SSR or in isomorphic contexts.
