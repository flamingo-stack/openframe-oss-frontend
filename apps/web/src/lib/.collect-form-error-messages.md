## collect-form-error-messages.ts

Utility for extracting all error messages from a react-hook-form `FieldErrors` tree, recursively traversing nested fields and field arrays to collect every validation message in depth-first order.

## Key Components

- **`collectFormErrorMessages<T>(errors)`** — Main exported function that walks a react-hook-form error object and returns a flat array of error message strings.
- **`SKIPPED_KEYS`** — Internal `Set` of keys (`message`, `ref`, `types`) excluded from traversal to avoid walking into DOM element references (`ref`) or duplicating data (`types`).
- **`visit(node)`** — Internal recursive helper that checks for a `message` string on the current node and then recurses into all non-skipped child keys, handling both nested objects and field-array error structures (where keys are row indices).

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { collectFormErrorMessages } from './collect-form-error-messages';

function ContactForm() {
  const {
    formState: { errors },
    handleSubmit,
  } = useForm<{ contacts: { email: string }[] }>();

  const onInvalid = () => {
    // Collects messages from nested fields and field array rows,
    // e.g. ["Email is required", "Invalid email at row 2"]
    const messages = collectFormErrorMessages(errors);
    messages.forEach((msg) => console.error(msg));
  };

  return <form onSubmit={handleSubmit(() => {}, onInvalid)}>{/* fields */}</form>;
}
```

This is especially useful for surfacing all validation errors (e.g., in a toast or summary banner) when a form has deeply nested fields or dynamic field arrays, where a shallow `Object.values(errors)` would miss errors buried in array rows.
