## feature-flags.ts

Defines the catalog of server-known feature flag names and exposes a typed accessor API (`featureFlags`) for reading flag state throughout the app, with env-var fallbacks and a client-side override for debug logging.

## Key Components

- **`FEATURE_FLAG_NAMES`** — const array of all flag names the backend recognizes; must be passed explicitly to the `feFeatureFlags` GraphQL query since the server only returns requested flags. Each entry is documented inline with its behavior and rollout status.
- **`FeatureFlagName`** — union type derived from `FEATURE_FLAG_NAMES`.
- **`FeatureFlagGate`** — tri-state type (`'loading' | 'on' | 'off'`) used to distinguish "not answered yet" from "off" in gating hooks.
- **`getFlagValue(flagName, envFallback)`** — internal helper reading from `useFeatureFlagsStore`, falling back to an env-based default if the store isn't loaded yet.
- **`DEBUG_NATS_CHUNKS_KEY`** / **`isDebugChunkLogForced()`** — localStorage-based override allowing developers to force-enable the NATS chunk debug log in their own browser, bypassing the server flag (the only flag with client-side override, since it only affects console logging, not UI).
- **`featureFlags`** — object exposing `.enabled()` methods per flag: `subscription`, `debugNatsChunks`, `cancelSubscription`, `testClock`, `remoteAccessApproval`, `remoteAccessV2`, `tenantManagement`, `tenantManagementV2`, `softwareManagement`.
- **`FeatureFlagKey`** — union type of keys in `featureFlags`.

## Usage Example

```typescript
import { featureFlags } from '@/lib/feature-flags';

// Imperative read outside React (e.g., in a resolver or utility function)
if (featureFlags.tenantManagement.enabled()) {
  // show tenant management integrations
}

// Tenant Management Phase 2 requires phase 1 enabled as well
if (featureFlags.tenantManagementV2.enabled()) {
  // render Users/Groups pages, directory tab columns, etc.
}
```

For reactive, tri-state gating inside React components (loading vs. on vs. off), prefer the dedicated hooks (e.g., `useFeatureFlagGate`, `useTenantManagementGate`) over calling `featureFlags.*.enabled()` directly, since the latter treats "not yet loaded" as `false`.
