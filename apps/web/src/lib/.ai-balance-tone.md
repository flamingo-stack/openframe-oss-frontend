# ai-balance-tone.ts

Shared logic for determining the visual "tone" (default/warning/error) of the AI token balance, used consistently across the Paid AI Tokens card, its info block, and the app-wide balance bar.

This module centralizes the state calculation so all three surfaces agree — since AI consumption draws from the free grant first and the purchased balance only afterward, the tone logic must account for whether the free grant is exhausted before evaluating the purchased balance.

## Key Components

- **`AiBalanceTone`** — Union type representing the three possible states: `'default'`, `'warning'`, `'error'`.
- **`AI_BALANCE_LOW_TOKENS`** — Constant (1,000,000) defining the threshold below which the purchased balance is considered "running low."
- **`AiBalanceInput`** — Interface describing the data needed to compute tone: `freeTokens`, `freeUsed`, and `purchasedRemaining`.
- **`aiFreeTokensExhausted(input)`** — Returns `true` once the period's free grant has been fully consumed (`freeUsed >= freeTokens`).
- **`aiBalanceTone(input)`** — Main function computing the overall tone:
  - `'default'` if the free grant isn't exhausted yet, or if it is but the purchased balance is still healthy.
  - `'error'` if the free grant is exhausted and the purchased balance is zero or negative.
  - `'warning'` if the free grant is exhausted and the purchased balance is positive but at or below `AI_BALANCE_LOW_TOKENS`.

## Usage Example

```typescript
import { aiBalanceTone, aiFreeTokensExhausted, AI_BALANCE_LOW_TOKENS } from './ai-balance-tone';

const usage = {
  freeTokens: 5_000_000,
  freeUsed: 5_000_000,
  purchasedRemaining: 500_000,
};

if (aiFreeTokensExhausted(usage)) {
  console.log('Free grant spent — now drawing from purchased balance');
}

const tone = aiBalanceTone(usage);
// tone === 'warning' since purchasedRemaining (500,000) <= AI_BALANCE_LOW_TOKENS

renderBalanceBar({ tone });
```

Use `aiBalanceTone` wherever the balance state is displayed (billing card, balance bar, info blocks) to guarantee consistent coloring and messaging across the app shell and billing page without cross-importing UI logic.
