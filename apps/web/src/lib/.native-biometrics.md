# native-biometrics.ts

Frontend wrapper around the native-shell biometric-login contract (iOS/Android `NativeAuth` plugin), gating Keychain-backed token reads behind Face ID / Touch ID / Fingerprint. All functions safely degrade to disabled/unavailable results outside the MOBILE shell, so web and desktop (Tauri) never surface biometric UI.

## Key Components

- **`BIOMETRIC_ERROR`** — Constant map of reject codes (`UNAVAILABLE`, `NO_TOKENS`, `CANCELED`, `INVALIDATED`) surfaced by the native contract.
- **`isBiometricAvailable()`** — Checks if the device supports biometric auth; resolves `{ available: false, biometryType: 'none' }` when unsupported or on error.
- **`isBiometricLoginEnabled()`** — Returns whether the user has opted into biometric login; `false` when unsupported.
- **`enableBiometricLogin()`** — Enables biometric login; throws/rejects with `BIOMETRIC_UNAVAILABLE`, `NO_TOKENS`, or `BIOMETRIC_CANCELED`.
- **`disableBiometricLogin()`** — Disables biometric login; may reject with `BIOMETRIC_CANCELED` or `BIOMETRIC_INVALIDATED` (native side resets to an ungated state in the latter case).
- **`biometryLabel(biometryType)`** — Maps a `BiometryType` to a human-readable label (e.g., `'faceId'` → `"Face ID"`).
- **`biometricsSupported()`** — `true` only inside a mobile shell whose plugin exposes biometric methods.
- **`BiometricLoginChoice`** / **`getBiometricLoginChoice()`** / **`setBiometricLoginChoice()`** — Persist the user's per-device enrollment choice (`'accepted'` | `'declined'`) in `localStorage`, driving the one-time post-login enrollment prompt.

## Usage Example

```typescript
import {
  isBiometricAvailable,
  isBiometricLoginEnabled,
  enableBiometricLogin,
  biometryLabel,
  biometricsSupported,
  getBiometricLoginChoice,
  setBiometricLoginChoice,
  BIOMETRIC_ERROR,
} from './native-biometrics';

async function renderBiometricToggle() {
  if (!biometricsSupported()) return; // hide UI entirely

  const { available, biometryType } = await isBiometricAvailable();
  if (!available) return;

  const label = biometryLabel(biometryType); // e.g. "Face ID"
  const enabled = await isBiometricLoginEnabled();

  if (!enabled && getBiometricLoginChoice() !== 'declined') {
    try {
      await enableBiometricLogin();
      setBiometricLoginChoice('accepted');
    } catch (err) {
      if ((err as Error).message === BIOMETRIC_ERROR.CANCELED) {
        setBiometricLoginChoice('declined');
      }
    }
  }
}
```
