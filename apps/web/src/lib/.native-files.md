# native-files.ts

Bridges file download and upload operations through the mobile shell's native layer, working around the fact that neither iOS nor Android WebViews support browser-style file downloads or CORS-compliant uploads from blob/File data.

This module solves two mobile-specific problems: (1) the standard `URL.createObjectURL` + anchor-click download idiom silently no-ops in Capacitor WebViews, and (2) presigned GCS upload URLs reject requests from the WebView's `capacitor://localhost` / `https://localhost` origin unless streamed from a native file path. On non-mobile platforms, all helpers transparently fall back to standard browser behavior.

## Key Components

- **`NativePickedFile`** — Metadata for a file picked via the OS picker (path, name, type, size), structurally compatible with `File` minus the bytes.
- **`hasNativeFiles()`** — Detects whether the current shell exposes the native files plugin.
- **`DownloadOutcome`** — `'browser' | 'shared' | 'saved'`, describing how a downloaded file reached the user (used to decide whether to show a confirmation).
- **`downloadFileToDevice(url, fileName)`** — Downloads a remote file, using the native plugin when available, otherwise the browser blob-download idiom.
- **`pickNativeFiles(options)`** — Opens the OS file picker natively; returns `null` off mobile.
- **`nativeFilePicker(options)`** — Adapter producing a `pickFiles` callback for core's `FileUpload` component, or `undefined` when native picking isn't available.
- **`UploadSource`** — Union of `File | NativePickedFile` representing any attachment upload origin.
- **`uploadSourceMeta(source)`** — Extracts `fileName`, `contentType`, and `fileSize` uniformly from either source type.
- **`putUploadSource(source, uploadUrl)`** — PUTs a file to a presigned URL, streaming from a native path when applicable to avoid CORS issues.

## Usage Example

```typescript
import {
  downloadFileToDevice,
  nativeFilePicker,
  putUploadSource,
  uploadSourceMeta,
  type UploadSource,
} from './native-files';

// Downloading a remote file
async function handleDownload(fileUrl: string, name: string) {
  const outcome = await downloadFileToDevice(fileUrl, name);
  if (outcome === 'saved') {
    showToast('File saved to Downloads');
  }
}

// Wiring native picking into a FileUpload component
const pickFiles = nativeFilePicker({ multiple: true });

// Uploading a picked source to a presigned URL
async function handleUpload(source: UploadSource, presignedUrl: string) {
  const { fileName, contentType, fileSize } = uploadSourceMeta(source);
  console.log(`Uploading ${fileName} (${contentType}, ${fileSize} bytes)`);
  await putUploadSource(source, presignedUrl);
}
```
