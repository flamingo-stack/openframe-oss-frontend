## auth-api-client.ts

Dedicated HTTP client for authentication-related endpoints (`/me`, `/oauth/*`, `/sas/*`), handling SaaS shared-host routing, 401/token-refresh retry logic, and auth-specific error message extraction. Complements the general-purpose API client but is scoped exclusively to auth flows (login, SSO, tenant discovery, registration attribution).

## Key Components

- **`SAAS_DOMAIN_SUFFIX`** — Resolved domain suffix derived from `runtimeEnv.sharedHostUrl()` or `window.location.hostname`, used to build tenant subdomains.
- **`AuthApiResponse<T>`** — Standard response envelope (`data`, `error`, `status`, `ok`) returned by all client methods.
- **`getAuthFailureMessage(response, fallback)`** — Extracts a user-displayable error message, prioritizing field-level validation errors, then body message, then network/5xx fallbacks.
- **`AuthErrorMessage` / `PendingSsoIdentity` / `PendingSsoJoin`** — Typed shapes for auth-error page content and pending SSO identity/join data.
- **`AuthApiClient`** — Main class exposing:
  - `handleUnauthorized()` — Central 401 handler: skips refresh on `/auth` pages, retries once via `refreshTokens()`, or triggers `forceLogout()`.
  - `devExchange(ticket)` — Exchanges a native dev ticket via `/oauth/dev-exchange`.
  - `oauth(path, body, init)` — Generic authenticated request wrapper for `/oauth/*` paths.
  - `discoverTenants(email)` — Looks up tenants for an email (public).
  - `requestDownloadLink(payload)` — Sends installer download links with attribution and honeypot protection.
  - `authErrorMessage(reference)` — Fetches a safe, server-resolved message for the `/auth/error` page via raw GraphQL POST.
  - `checkDomainAvailability(subdomain, organizationName)` — Validates tenant subdomain availability.
  - `pendingSsoIdentityByTicket(ticket)` / `completeSsoRegistrationByTicket(payload)` — Native SSO signup flow support.

## Usage Example

```typescript
import { getAuthFailureMessage } from './auth-api-client';

const client = new AuthApiClient();

// Discover tenants for an email during login
const result = await client.discoverTenants('user@example.com');
if (!result.ok) {
  console.error(getAuthFailureMessage(result, 'Unable to find tenant.'));
}

// Fetch a safe error message for /auth/error?ref=...
const errorMsg = await client.authErrorMessage(reference);
if (errorMsg.ok) {
  showErrorBanner(errorMsg.data.message);
}
```
