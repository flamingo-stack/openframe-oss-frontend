## session-health.ts

Tracks whether the tenant gateway is still willing to accept requests for the current session, replacing a previous state of amnesia where refused requests were endlessly retried and deleted tenants were polled forever. It exposes a small Zustand store with three states — `healthy`, `paused`, and `gone` — and the logic to transition between them based on gateway responses and token rotation.

## Key Components

- **`SessionHealth`** — type union: `'healthy' | 'paused' | 'gone'`.
- **`PauseReason`** — type union: `'transient' | 'rejected'`, distinguishing a dropped-link/auth-server failure from a confirmed-rejected token.
- **`useSessionHealthStore`** — Zustand store (with devtools) holding `health`, `pauseReason`, and `pausedAtEpoch`.
- **`SessionGoneError`** — thrown/used to signal a request answered locally because the tenant is deleted; never retried.
- **`getSessionHealth()` / `isSessionGone()` / `isPausedFor(reason)`** — read-only accessors.
- **`markSessionPaused(reason)`** — pauses background polling; `rejected` upgrades over `transient`, never overrides `gone`.
- **`markSessionHealthy()`** — clears a `paused` state (no-op if `gone`).
- **`resetSessionHealth()`** — full reset to initial state; the only exit from `gone` (used on sign-out/tenant change).
- **`noteGatewayResponse(response)`** — inspects a tenant-gateway `Response`; marks `gone` on an HTML 410 (deleted tenant), clears a `transient` pause on 2xx. Returns `true` if the tenant was found gone.
- **`clearPauseIfTokenRotated()`** — ends a `transient` pause once the token epoch advances past when the pause was recorded.
- A module-level `subscribeToTokenChange` listener resets session health on bearer-mode sign-out/sign-in cycles, distinguishing a true sign-out from a cold-start token hydration.

## Usage Example

```typescript
import {
  noteGatewayResponse,
  markSessionPaused,
  isSessionGone,
  isPausedFor,
  SessionGoneError,
} from './session-health';

async function pollTenantGateway(path: string) {
  if (isSessionGone()) throw new SessionGoneError();

  const response = await fetch(path);
  const tenantGone = noteGatewayResponse(response);
  if (tenantGone) throw new SessionGoneError();

  if (response.status === 401) {
    const refreshed = await tryRefreshToken();
    if (!refreshed) markSessionPaused('transient');
    else if (isPausedFor('rejected')) {
      // only a successful re-validation probe clears a 'rejected' pause
    }
  }

  return response;
}
```
