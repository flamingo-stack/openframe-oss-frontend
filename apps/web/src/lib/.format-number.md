# format-number.ts

Utility module for formatting numeric values using locale-aware `Intl.NumberFormat`, intended for displaying counts (devices, CVEs, requests, etc.) consistently throughout the UI.

## Key Components

- **`formatCount(value: number | null | undefined): string`** — Formats a number with locale-aware grouping separators (e.g., `"1,234"` or `"1 234"` depending on locale). Returns `EMPTY_VALUE` when `value` is `null` or `undefined`.
- **`formatCompactCount(value: number): string`** — Formats a number using compact notation suitable for headline/summary displays (e.g., `3200000` → `"3.2M"`), with a maximum of 1 fraction digit.

Both formatters use `Intl.NumberFormat` initialized with the viewer's default locale (`undefined` locale argument), ensuring consistent behavior with other locale-sensitive utilities like `format-date`.

## Usage Example

```typescript
import { formatCount, formatCompactCount } from './format-number';

// Standard grouped count
formatCount(1234);        // "1,234" (locale-dependent)
formatCount(null);        // EMPTY_VALUE
formatCount(undefined);   // EMPTY_VALUE

// Compact headline count
formatCompactCount(3200000); // "3.2M"
formatCompactCount(950);     // "950"

// Example in a component
const deviceCountLabel = formatCount(devices.length);
const totalRequestsLabel = formatCompactCount(totalRequests);
```

## Notes

- Locale is determined automatically by the runtime environment (browser/user locale), not hardcoded.
- `formatCompactCount` does not handle `null`/`undefined` inputs — callers should guard against missing values before invoking it, or use `formatCount` instead for nullable values.
