## format-date.ts

Date/time formatting utilities built on `Intl.DateTimeFormat`, providing locale-aware, zone-aware, and null-safe formatters for displaying dates and times consistently across the app.

## Key Components

- **`toValidDate(input)`** — Normalizes a string, number, or `Date` into a valid `Date` or `null`. Distinguishes GraphQL `Date` scalars (local day) from other date strings (instants) via `parseLocalDate`/`parseInstant`.
- **`viewerLocale()`** — Returns `navigator.language` (the browser's own preferred locale), or `undefined` off the client.
- **`formatDate(input)`** — Short localized date (e.g. `10/19/2026`).
- **`formatUtcDay(input)`** — Short date rendered on the UTC calendar, for pairing with `Date` scalars.
- **`formatTime(input)` / `formatTimeWithSeconds(input)`** — Short/medium localized time.
- **`formatDateTime(input)`** — Combined date + time string.
- **`formatDateTimeInZone(input, timeZone)`** — Date + time rendered in an arbitrary IANA time zone.
- **`formatDateTimeOnDevice(input, deviceTimeZone)`** — Date + time in a device's own time zone, labeled with the zone abbreviation (e.g. `AEDT`), falling back to the viewer's unlabeled local time if the zone is unknown.
- **`toDateTimeLocalValue(input)`** — Formats an instant for an `<input type="datetime-local">` value, using the viewer's wall-clock time.
- **`formatTimeZone(timeZone, at)`** — Produces a `(UTC+02:00) Kyiv`-style label for a time zone at a given instant, correcting IANA city renames.
- **`formatLogTime(input)`** — Fixed-width 24-hour time with milliseconds, for aligned log output.
- **`viewerTimeZone()`** — Returns the runtime's resolved IANA time zone.

All formatters return `EMPTY_VALUE` for missing or unparseable input instead of throwing, so callers don't need per-call validation.

## Usage Example

```typescript
import {
  formatDate,
  formatDateTime,
  formatDateTimeOnDevice,
  formatTimeZone,
  toDateTimeLocalValue,
} from './format-date';

formatDate('2026-10-19'); // "10/19/2026"

formatDateTime(device.lastSeenAt); // "10/19/2026 9:05 AM"

// Timestamp reported by the device itself, labeled with its own zone
formatDateTimeOnDevice(device.bootedAt, device.timeZone);
// "19/10/2026 09:05 AEDT"

formatTimeZone('Europe/Kiev', new Date()); // "(UTC+02:00) Kyiv"

// Populate a <input type="datetime-local">
const value = toDateTimeLocalValue(scheduledAt); // "2026-10-19T09:05"
```
