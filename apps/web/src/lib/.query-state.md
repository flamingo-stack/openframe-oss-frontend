## query-state.ts

Centralizes the logic for deriving a UI-ready data-loading state from react-query's raw booleans, fixing the mismatch between `isLoading`/`isPending`/`isFetching` and what a page actually needs to render (skeleton, offline, error, or empty state).

## Key Components

- **`QueryState`** — interface with `isLoading`, `isOffline`, `error`, `hasData`, and `canClaimEmpty`, the single source of truth for what a data surface should render.
- **`QueryGate`** — `'open' | 'closed'` type representing whether a disabled query is expected to eventually run (distinguishing "still resolving" from "will never run").
- **`queryState(query, gate)`** — derives a `QueryState` from a react-query-like object, correctly handling the paused/offline case that bare `isLoading`/`isPending` checks get wrong.
- **`loadErrorProps(isOffline, message, onRetry?)`** — returns the `{ message, onRetry }` pair for error UI, swapping in offline copy and dropping the Retry handler when offline (since `refetch` can't succeed without connectivity).
- **`OfflineError`** — error class thrown by Relay-based code paths (which lack react-query's `paused` status) to signal a connectivity failure rather than a server error; carries `isOfflineError` and an optional `operation` name for logging.
- **`isOfflineError(error)`** — duck-typed type guard for `OfflineError`, safe across bundle boundaries.

## Usage Example

```typescript
import { queryState, loadErrorProps, isOfflineError, OfflineError } from './query-state';
import { useQuery } from '@tanstack/react-query';

function CustomerList({ enabled }: { enabled: boolean }) {
  const query = useQuery({ queryKey: ['customers'], queryFn: fetchCustomers, enabled });
  const state = queryState(query, enabled ? 'open' : 'closed');

  if (state.isLoading) return <Skeleton />;
  if (state.isOffline || state.error) {
    const { message, onRetry } = loadErrorProps(
      state.isOffline,
      state.error ?? 'Could not load customers',
      query.refetch,
    );
    return <LoadError message={message} onRetry={onRetry} />;
  }
  if (state.canClaimEmpty && query.data.length === 0) {
    return <EmptyState text="No customers yet" />;
  }
  return <Table rows={query.data} />;
}

// Relay-side usage
try {
  await runMutation();
} catch (e) {
  if (isOfflineError(e)) showToast((e as OfflineError).message);
}
```
