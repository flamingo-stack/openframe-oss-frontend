## native-shell.ts

Typed interface layer for accessing the native shell bridges exposed by OpenFrame's mobile (`window.Capacitor.Plugins`) and desktop (`window.__OPENFRAME_SHELL__`) shells, defining the shared authentication contract and shell-specific capabilities without any Capacitor npm dependency.

## Key Components

- **`APP_SCHEME`** — Default custom URL scheme (`com.openframe.app`) the mobile shell completes OAuth login on.
- **`REQUIRED_BRIDGE_LEVEL`** — Minimum native bridge version the current bundle requires; read by the OTA release packer.
- **`DESKTOP_LOGIN_ERROR`** — Error codes (`TIMEOUT`, `INCOMPLETE`) the desktop login flow can reject with.
- **`BiometryType`** — Union of supported biometric methods (`faceId`, `touchId`, `fingerprint`, `face`, `none`).
- **`NativeTokens`** — Token pair shape (`accessToken`/`refreshToken`) exchanged between web and shell.
- **`CapacitorListenerHandle`** — Union type normalizing sync/async listener handles from the Capacitor bridge shim.
- **`nativeErrorCode(error)`** — Safely extracts the native error `code` string from a rejected plugin call.
- **`NativeAuthPlugin`** — Core interface implementing the shared and shell-specific auth bridge: login (`start`, `cancel`), token exchange (`exchangeTicket`, `exchangeApple`, `signInWithApple`), token storage (`getTokens`, `setTokens`, `clearTokens`), biometrics (`enableBiometricLogin`, `isBiometricAvailable`, etc.), refresh/session (`refreshTokens`, `revokeSession`), host configuration (`setTenantHost`), push events (`addListener`), and layout (`getSafeAreaInsets`).
- **`PushPermissionState`** — Push notification permission states.
- **`DeliveredNotification`** — Shape of a notification currently in the OS tray.
- **`FirebaseMessagingPlugin`** — Subset of `@capacitor-firebase/messaging` used for push token registration and notification events.

## Usage Example

```typescript
import { isMobileShell, isDesktopShell } from './platform';
import { nativeErrorCode, type NativeAuthPlugin } from './native-shell';

async function getNativeTokens(plugin: NativeAuthPlugin) {
  try {
    const tokens = await plugin.getTokens();
    return tokens;
  } catch (error) {
    const code = nativeErrorCode(error);
    if (code === 'BIOMETRIC_CANCELED') {
      // user dismissed the biometric prompt
      return null;
    }
    throw error;
  }
}

async function refreshIfSupported(plugin: NativeAuthPlugin, rejectedAccessToken?: string) {
  if (isDesktopShell() || isMobileShell()) {
    // Only call when the shell implements shell-owned refresh
    return plugin.refreshTokens?.({ rejectedAccessToken });
  }
}
```

Consumers should always feature-probe optional methods (`plugin.foo?.()`) rather than assume availability, since bridge capabilities vary by shell and installed binary version.
