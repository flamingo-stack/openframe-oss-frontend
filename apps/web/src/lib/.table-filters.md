Provides a type-adapted re-export of the core multi-select `filterFn` so it can be assigned to strongly-typed `ColumnDef<T>[]` arrays used by TanStack table columns throughout the app.

## Key Components

- **`multiSelectFilterFn`** — A widened version of `@flamingo-stack/openframe-frontend-core`'s `multiSelectFilterFn`, typed as `ColumnDef<any>['filterFn']`. This allows it to be used as the `filterFn` for any column definition regardless of the row's concrete `TData` type, working around `FilterFn`'s contravariance on `TData` (which would otherwise make `FilterFn<unknown>` incompatible with `FilterFn<SpecificRowType>`).

## Usage Example

```typescript
import type { ColumnDef } from '@tanstack/react-table';
import { multiSelectFilterFn } from './table-filters';

interface UiLogEntry {
  level: string;
  message: string;
}

const columns: ColumnDef<UiLogEntry>[] = [
  {
    accessorKey: 'level',
    header: 'Level',
    filterFn: multiSelectFilterFn,
  },
  // ... additional columns
];
```

## Notes

- This module exists specifically to centralize a single type cast rather than repeating it across ~15 column definitions.
- `@tanstack/react-table` is not a direct dependency of this project, so the type is accessed indirectly via `ColumnDef` imported from `@flamingo-stack/openframe-frontend-core/components/ui`, since `FilterFn` itself isn't re-exported by that package.
- The underlying predicate only reads cell values, so the type widening introduces no real runtime safety risk.
