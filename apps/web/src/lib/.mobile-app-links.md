## mobile-app-links.ts

Defines the canonical, hardcoded store URLs for the OpenFrame Console mobile app, used as a last-resort fallback when the server doesn't specify a platform-specific listing during a forced app update.

## Key Components

- **`APP_STORE_URL`** — Public Apple App Store listing URL for the OpenFrame Console iOS app.
- **`GOOGLE_PLAY_URL`** — Public Google Play Store listing URL for the OpenFrame Console Android app.

## Usage Example

```typescript
import { APP_STORE_URL, GOOGLE_PLAY_URL } from './mobile-app-links';

function resolveStoreUrl(platform: 'ios' | 'android', serverUrl?: string): string {
  if (serverUrl) return serverUrl;
  return platform === 'ios' ? APP_STORE_URL : GOOGLE_PLAY_URL;
}
```

## Notes

- These constants act as the fallback when a 426 (Upgrade Required) response doesn't name a specific store listing and no policy override exists.
- The app's download page prefers store links returned by the server over these constants.
- Native iOS and Android shells maintain their own copies of these same URLs for platform-native 426 handling (`NotificationActions.swift` on iOS, `NotificationActionWorker.java` on Android) — keep all copies in sync if these URLs ever change.
