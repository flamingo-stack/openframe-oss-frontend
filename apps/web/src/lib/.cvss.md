Utility functions for formatting and classifying CVSS (Common Vulnerability Scoring System) base scores, used to display vulnerability severity consistently throughout the application.

## Key Components

- **`formatCvssScore(score: number): string`** — Formats a numeric CVSS score to one decimal place (e.g., `7` → `"7.0"`) to align with the standard CVSS presentation format.
- **`severityFromCvssScore(score: number): SoftwareCveSeverity`** — Maps a numeric CVSS base score to its qualitative severity rating per the CVSS v3.x specification:
  - `>= 9` → `CRITICAL`
  - `>= 7` → `HIGH`
  - `>= 4` → `MEDIUM`
  - `> 0` → `LOW`
  - `0` or less → `NONE`

## Usage Example

```typescript
import { formatCvssScore, severityFromCvssScore } from '@/utils/cvss';

const score = 7.5;

console.log(formatCvssScore(score)); // "7.5"
console.log(severityFromCvssScore(score)); // SoftwareCveSeverity.HIGH

// Useful when rendering a CVE badge
const label = `${formatCvssScore(score)} (${severityFromCvssScore(score)})`;
```

These helpers are typically used together when rendering CVE/vulnerability details, ensuring scores are displayed with consistent decimal precision and matched to the correct severity badge or color coding derived from `SoftwareCveSeverity`.
