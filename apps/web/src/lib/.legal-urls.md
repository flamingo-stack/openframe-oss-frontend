## legal-urls.ts

Centralized constants for legal document URLs used across public-facing screens such as registration forms, the login card footer, and the billing page. Consolidating these links into a single module prevents inconsistency across the UI—since legal links are referenced in multiple components, having one source of truth ensures updates propagate everywhere and nothing silently goes stale.

## Key Components

- **`TERMS_URL`** — Link to the Terms of Service page.
- **`PRIVACY_POLICY_URL`** — Link to the Privacy Policy page.
- **`DEVICE_BILLING_TERMS_URL`** — Link to the Payment Terms page, anchored to the section explaining how devices are counted and billed.

## Usage Example

```typescript
import { TERMS_URL, PRIVACY_POLICY_URL, DEVICE_BILLING_TERMS_URL } from '@/constants/legal-urls';

// Registration form consent copy
function ConsentText() {
  return (
    <p>
      By signing up, you agree to our{' '}
      <a href={TERMS_URL} target="_blank" rel="noopener noreferrer">Terms of Service</a>{' '}
      and{' '}
      <a href={PRIVACY_POLICY_URL} target="_blank" rel="noopener noreferrer">Privacy Policy</a>.
    </p>
  );
}

// Billing page device charge explanation
function DeviceChargeNote() {
  return (
    <a href={DEVICE_BILLING_TERMS_URL} target="_blank" rel="noopener noreferrer">
      Learn how devices are billed
    </a>
  );
}
```

Import these constants wherever legal links are rendered instead of hardcoding URLs, so future changes to legal page locations only require updating this single file.
