Utility for detecting whether the application is running in a cloud, self-hosted, or development environment, based on pattern matching against the browser's `window.location.hostname`.

## Key Components

- **`DeploymentType`** — Union type: `'self-hosted' | 'cloud' | 'development'`.
- **`DeploymentInfo`** — Interface describing the detection result: `type`, `isCloud`, `isSelfHosted`, `isDevelopment`, and `hostname`.
- **`detectDeployment()`** — Core function that inspects `window.location.hostname` against known cloud (`openframe.ai`, `auth.openframe.ai`, `app.openframe`) and development (`localhost`, `127.0.0.1`, `0.0.0.0`, `.local`) patterns, defaulting to `'self-hosted'` for any unmatched custom domain. Returns a full `DeploymentInfo` object.
- **`isCloud()`** — Shorthand boolean check for cloud deployment.
- **`isSelfHosted()`** — Shorthand boolean check for self-hosted deployment.
- **`isDevelopment()`** — Shorthand boolean check for development environment.
- **`getDeploymentType()`** — Shorthand to retrieve just the `DeploymentType`.

## Usage Example

```typescript
import { detectDeployment, isCloud, getDeploymentType } from './deployment-detector';

// Full deployment info
const info = detectDeployment();
console.log(info.type, info.hostname);

// Conditional feature flag based on deployment
if (isCloud()) {
  enableCloudOnlyFeatures();
}

// Branch logic by deployment type
switch (getDeploymentType()) {
  case 'cloud':
    console.log('Running on OpenFrame cloud');
    break;
  case 'self-hosted':
    console.log('Running on a self-hosted instance');
    break;
  case 'development':
    console.log('Running locally for development');
    break;
}
```

**Note:** Since detection relies on `window.location.hostname`, it defaults to `'localhost'` during server-side rendering (when `window` is undefined), resulting in a `'development'` classification outside the browser.
