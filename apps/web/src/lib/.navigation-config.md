## navigation-config.tsx

Builds the application sidebar navigation data for multiple sidebar layouts (classic flat, Mingo-first grouped, and sectioned) from a single source-of-truth module table (`NAV_MODULES`), applying feature-flag gates, unread-notification badges, and Beta stamps consistently across all renderings.

## Key Components

- **`NAV_MODULES`** — Central registry of every navigable module (label, icon, path, active-match prefixes, feature gates, notification category, beta flag). The single source feeding all sidebar variants.
- **`NavModuleId`** — Union type of all valid module keys derived from `NAV_MODULES`.
- **`NavigationFlags`** — Interface describing the boolean feature flags (`insights`, `softwareManagement`, `tenantManagement`, `tenantManagementV2`) that gate module visibility.
- **`OnboardingNavState`** — Interface for onboarding progress state used to conditionally render the Onboarding tab/badge.
- **`navModuleLabel(id)`** — Returns the Mingo-first (grouped) label for a module, falling back to its default label.
- **`navModuleIcon(id)`** — Returns the icon component for a module.
- **`navModuleOf(pathname)`** — Resolves the active module for a given pathname via longest-prefix match.
- **`FLAT_LAYOUT`** — Ordered module lists (`primary`/`secondary`) for the classic sidebar.
- **`GROUPED_LAYOUT`** — Group definitions (Inventory, Service Desk, Automation, Monitor) plus top-level leaves for the Mingo-first sidebar.
- **`BETA_BADGE`** — Constant label used to stamp unflagged-but-shipped modules.

## Usage Example

```typescript
import { navModuleOf, navModuleLabel, navModuleIcon } from './navigation-config';

// Determine which module a route belongs to
const activeModule = navModuleOf('/devices/123'); // 'devices'

if (activeModule) {
  const label = navModuleLabel(activeModule); // 'Devices'
  const Icon = navModuleIcon(activeModule);
  // Render <Icon size={20} /> {label}
}
```

Feature flags are passed into the sidebar builder functions (not read internally), typically from a `useMemo` in the app shell, e.g.:

```typescript
const flags: NavigationFlags = {
  insights: useFeatureFlag('insights'),
  softwareManagement: useFeatureFlag('software-management'),
  tenantManagement: useFeatureFlag('tenant-management'),
  tenantManagementV2: useFeatureFlag('tenant-management-v2'),
};
```

This ensures sidebar items only render once flags are resolved, avoiding false negatives during loading states.
