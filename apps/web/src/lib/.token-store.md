Client-side OAuth token custody module that abstracts credential storage across platforms: web builds use localStorage (bearer mode) or rely entirely on HttpOnly cookies, while native-shell builds persist tokens in the iOS Keychain via the NativeAuth plugin, mirrored in memory for synchronous access.

## Key Components

- **`ACCESS_TOKEN_KEY` / `REFRESH_TOKEN_KEY`** — localStorage key constants for web bearer mode.
- **`getTokenEpoch()` / `markTokenRotation()`** — Monotonic counter tracking credential installs, used to detect stale 401s after token rotation and avoid redundant refresh storms.
- **`getBiometricLockState()` / `subscribeToBiometricLock()` / `retryTokenHydration()` / `dismissBiometricLock()`** — Manage the cold-start biometric-gated Keychain read lock state (`'locked'`, `'invalidated'`, or `null`) and allow retrying or bypassing it.
- **`subscribeToTokenChange()`** — Lets callers (e.g., fetch interceptors, WebSocket URL builders) react to any token write, since same-tab writes don't fire native `storage` events.
- **`adoptNativeTokens(tokens)`** — Mirrors a token pair already persisted by the native shell into the in-memory cache without re-writing the Keychain.
- **`isBearerAuthMode()` / `getBearerTokenSync()`** — Determine whether auth uses a bearer header (native shell or dev-ticket mode) versus cookies, and synchronously fetch the current bearer token.
- **`initTokenStore()`** — Hydrates the in-memory cache from the Keychain on native, handling biometric prompt failures, tenant-host re-registration, and race protection against concurrent writes.

## Usage Example

```typescript
import {
  initTokenStore,
  getBearerTokenSync,
  getTokenEpoch,
  subscribeToTokenChange,
  getBiometricLockState,
  retryTokenHydration,
} from './token-store';

// App startup: hydrate from Keychain on native shells
await initTokenStore();

// Fetch interceptor: attach bearer token when applicable
const token = getBearerTokenSync();
if (token) {
  headers.set('Authorization', `Bearer ${token}`);
}

// React to token changes (e.g., refresh WS connection URL)
const unsubscribe = subscribeToTokenChange(() => {
  reconnectWebSocket();
});

// Capture epoch before a request to detect stale 401s
const epochAtRequest = getTokenEpoch();

// Handle biometric lock screen
if (getBiometricLockState() === 'locked') {
  await retryTokenHydration();
}
```
