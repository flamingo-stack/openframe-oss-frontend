Manages OAuth token persistence across web and native-shell (iOS Keychain) environments, providing a unified synchronous/asynchronous API for reading, writing, and clearing access and refresh tokens with biometric lock support.

## Key Components

### Constants
- `ACCESS_TOKEN_KEY` / `REFRESH_TOKEN_KEY` — `localStorage` keys used in web/dev-ticket mode

### Token Epoch
- `getTokenEpoch(): number` — Monotonic counter advanced on every credential install; used by `refreshAccessToken()` to detect stale 401s and avoid redundant refresh loops
- `markTokenRotation(): void` — Manually advance the epoch for cookie-mode refreshes (no client-readable token written)

### Biometric Lock
- `BiometricLockState` — `'locked' | 'invalidated' | null`; represents cold-start Keychain read outcomes
- `getBiometricLockState(): BiometricLockState` — Current biometric lock state
- `subscribeToBiometricLock(listener): () => void` — Subscribe to lock state changes; returns unsubscribe function
- `retryTokenHydration(): Promise<void>` — Re-prompts biometric after a canceled unlock attempt
- `dismissBiometricLock(): void` — Lifts the lock gate before routing to sign-in

### Hydration & Init
- `initTokenStore(): Promise<void>` — Memoized cold-start hydration; reads Keychain on native, no-op on web. Safe to call repeatedly

### Token Accessors
- `getAccessTokenSync() / getRefreshTokenSync()` — Synchronous reads; memory cache on native, `localStorage` on web
- `getAccessToken() / getRefreshToken()` — Async variants that await hydration first

### Token Writers
- `setTokens({ accessToken?, refreshToken? }): Promise<void>` — Persists tokens to Keychain (native) or `localStorage` (web); advances epoch after write

### Token Change Events
- `subscribeToTokenChange(listener): () => void` — Subscribe to token rotations on native (where DOM `storage` events don't fire)

### Auth Mode Detection
- `isBearerAuthMode(): boolean` — `true` in native shell or dev-ticket web mode

## Usage Example

```typescript
import {
  initTokenStore,
  getAccessToken,
  setTokens,
  getTokenEpoch,
  subscribeToBiometricLock,
} from './token-store';

// App startup — hydrates Keychain on native, no-op on web
await initTokenStore();

// Fetch interceptor — capture epoch before request
const epochBeforeRequest = getTokenEpoch();
const token = await getAccessToken();

// Handle 401 — only refresh if this request was issued with the current credential
async function handle401(epochAtRequest: number) {
  if (epochAtRequest < getTokenEpoch()) {
    // Token already rotated by another request — just retry
    return retry();
  }
  await refreshAccessToken();
}

// Store new tokens after a successful refresh
await setTokens({ accessToken: newAccess, refreshToken: newRefresh });

// React to biometric lock on native cold-start
const unsub = subscribeToBiometricLock((state) => {
  if (state === 'locked') showUnlockGate();
  if (state === 'invalidated') forceLogout();
  if (state === null) hideUnlockGate();
});
```
