## registration-attribution.ts

Captures and assembles marketing-attribution data for the registration flow, bridging cookie-based, localStorage-based, and URL-based signals into a `Touchpoint` payload matching the backend DTO. Handles three different data lifetimes: ad-pixel cookies (`_fbc`, `_fbp`, `_rdt_uuid`), page-load-scoped visit/click data persisted to localStorage, and a HubSpot visitor-token handoff across domains.

## Key Components

- **`Touchpoint`, `TouchpointVisit`, `TouchpointClicks`** — Interfaces mirroring the backend Java `Touchpoint` DTO; all fields optional.
- **`hubspotUtkFromHstc(hstc)`** — Extracts and validates the HubSpot visitor token (`utk`) from a `__hstc` cookie/query value.
- **`captureAttributionFromUrl()` / `captureVisitOfPage()`** — Capture-step functions meant to run on every page load, persisting visit, click, HubSpot handoff, and referral data into `localStorage` before it's lost to navigation.
- **Storage helpers (`readStored`, `writeStored`)** — TTL-aware (90-day) localStorage read/write wrappers under the `of_attr_` key prefix, resilient to corrupted or expired entries.
- **Constants** — `HUBSPOT_HSTC_PARAM`, `HUBSPOT_HSFP_PARAM`, `FBC_PARAM`, `DOWNLOAD_ID_STORAGE_PARAM`, `ATTRIBUTION_TTL_MS`, and validation patterns (`DOWNLOAD_ID_PATTERN`, `HUBSPOT_UTK_PATTERN`).
- **`VISIT_FIELD_TO_DTO`** — Maps internal visit field names (e.g. `utm_source`) to backend DTO property names (e.g. `utmSource`).

## Usage Example

```typescript
import { hubspotUtkFromHstc } from './registration-attribution';

// Mounted app-wide on every page load to persist attribution before navigation
// captureAttributionFromUrl();

// At registration form submit, assemble the Touchpoint payload using stored
// attribution, cookies (fbc/fbp/rdt_uuid), and the HubSpot handoff token:
const utk = hubspotUtkFromHstc(document.cookie.match(/__hstc=([^;]+)/)?.[1]);

const touchpoint = {
  hutk: utk,
  // fbc, fbp, rdtUuid read from cookies at submit time
  // firstVisit/lastVisit/latestClicks read from localStorage
};
```

This module works alongside `cookies.ts`, `platform.ts`, `referral-cookie.ts`, and `visit-attribution.ts`, which own the underlying cookie reading, app-shell detection, referral-code handling, and visit/click capture logic respectively.
