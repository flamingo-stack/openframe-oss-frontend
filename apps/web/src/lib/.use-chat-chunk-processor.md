## useChatChunkProcessor

React hook that bridges incoming NATS chat chunks to a per-dialog/per-side reducer (`BoundMirror`), handling identity-stable chunk processing, approval-status syncing, and post-eviction re-seeding of in-flight turns. It centralizes glue logic shared by both chat hosts (mingo dialog and tickets), leaving message accumulation and echo-suppression to the reducer itself.

## Key Components

- **`useChatChunkProcessor(options)`** — main hook; returns a stable `(chunk: unknown) => void` callback for feeding a JetStream subscription.
- **`UseChatChunkProcessorOptions`** — input shape:
  - `boundMirror`: pre-curried `BoundMirror` handle (`mirror.bind(key)`) for the active dialog/side.
  - `messages`: hydrated thread used to re-seed the reducer after an LRU eviction.
  - `approvalStatuses`: optional map synced into the reducer for `APPROVAL_REQUEST` replay.
  - `interceptEvent`: optional host hook to claim an event before the shared `apply` path runs.
- **`ChatModelMetadata`** — re-exported type from `@/lib/chat-stream-thread`.

Internally it maintains latest-value refs (for subscription-identity stability), an approval-status sync effect, and an eviction-epoch-guarded one-shot re-seed effect for unfinished turns.

## Usage Example

```typescript
import { useChatChunkProcessor } from './use-chat-chunk-processor';

function useTicketChatSide(mirror: ReducerMirror, dialogKey: string, history: ChatMessage[]) {
  const boundMirror = mirror.bind(dialogKey);

  const processChunk = useChatChunkProcessor({
    boundMirror,
    messages: history,
    approvalStatuses: { 'req-123': 'approved' },
    interceptEvent: (event) => {
      // Claim client-authored DIRECT_MESSAGE rows so the lib reducer
      // doesn't render them as admin-authored.
      if (event.type === 'direct-message' && event.authoredByClient) {
        // handle locally...
        return true;
      }
      return false;
    },
  });

  // Hand `processChunk` to a long-lived JetStream subscription:
  useEffect(() => {
    const sub = subscribeToChat(dialogKey, processChunk);
    return () => sub.unsubscribe();
  }, [dialogKey, processChunk]);
}
```

**Note:** `processChunk`'s identity never changes across renders (via `useCallback` with an empty dependency array plus refs), making it safe to pass into long-lived subscriptions without re-subscribing on every render.
