# utils.ts

Provides a single utility for resolving the OpenFrame dashboard's reachable base URL across different deployment contexts (browser, self-hosted, Vercel preview, production).

## Key Components

- **`getAppUrl()`** — Returns the current app's deployment URL (no trailing slash) by delegating to the shared `getDeploymentUrl` helper from `@flamingo-stack/openframe-frontend-core/platform-domains`, passing the `openframe-dashboard` platform identifier and the runtime-configured app URL.

## Usage Example

```typescript
import { getAppUrl } from './utils';

// Resolve the base URL for building absolute links, redirects, or API calls
const baseUrl = getAppUrl();

const inviteLink = `${baseUrl}/invite/abc123`;
```

The resolution logic is centralized in `openframe-frontend-core`, which determines the URL based on priority:

1. The browser's current page origin (client-side).
2. The runtime `NEXT_PUBLIC_APP_URL` environment variable (self-hosted installs).
3. The Vercel preview deployment URL (if applicable).
4. The OpenFrame dashboard registry URL (production).
5. `localhost` (development fallback).

This app only needs to supply its `platform` name (`openframe-dashboard`) and its own `configuredUrl` (via `runtimeEnv.appUrl()`); all shared resolution rules live in the core package, ensuring consistent behavior across all OpenFrame apps.
