# commit-mutation.ts

A promise-based wrapper around Relay's `commitMutation`, enabling imperative GraphQL mutation calls (e.g., in services or event handlers) outside of React components without manually managing callbacks.

## Key Components

- **`commitMutationPromise<TMutation>`** — Generic function that executes a Relay mutation and returns a `Promise` resolving with the mutation's typed response.
  - **Parameters:**
    - `mutation`: A `GraphQLTaggedNode` (the compiled GraphQL mutation document).
    - `variables`: The mutation's input variables, inferred from `TMutation['variables']`.
  - **Behavior:**
    - Resolves with `TMutation['response']` on successful completion.
    - Rejects with an `Error` wrapping the first GraphQL error message if `errors` are present in the response.
    - Rejects directly with the network/runtime error via `onError`.
    - Does **not** inspect or throw on `userErrors` (business-level validation failures) — callers must check these in the resolved payload themselves.
  - Uses `getRelayEnvironment()` from `@/lib/relay` to obtain the active Relay environment.

## Usage Example

```typescript
import { commitMutationPromise } from '@/lib/graphql/commit-mutation';
import UpdateDeviceMutation, {
  type UpdateDeviceMutation as UpdateDeviceMutationType,
} from '@/__generated__/UpdateDeviceMutation.graphql';

async function updateDeviceName(deviceId: string, name: string) {
  try {
    const response = await commitMutationPromise<UpdateDeviceMutationType>(
      UpdateDeviceMutation,
      { input: { deviceId, name } },
    );

    const userErrors = response.updateDevice?.userErrors;
    if (userErrors?.length) {
      // Business-level validation failure — handle explicitly
      console.warn('Update rejected:', userErrors);
      return;
    }

    console.log('Device updated:', response.updateDevice?.device);
  } catch (err) {
    // GraphQL-level or network error
    console.error('Mutation failed:', err);
  }
}
```

**Note:** This utility is intended for use outside React's declarative mutation hooks (e.g., `useMutation`), such as in service layers, background tasks, or non-component logic where imperative control flow is preferred.
