## Overview

`environment.ts` configures a client-side Relay Runtime `Environment` used for GraphQL data fetching across the app. It wires authentication, retry/backoff logic, offline detection, session/subscription gating, timeout handling, and version-enforcement into Relay's `Network` layer, and exposes a `keepalive` beacon for last-request-on-unload scenarios.

## Key Components

- **`sendGraphqlKeepalive(request, variables)`** — Fires a fire-and-forget GraphQL request using `fetch(..., { keepalive: true })` during `pagehide`, bypassing retry/gating logic since no response can be read.
- **`getAuthHeaders()`** — Builds `Authorization` headers when bearer-token auth mode is active.
- **`getGraphqlUrl()`** — Resolves the tenant-aware GraphQL endpoint URL.
- **`executeFetch(request, variables, headers)`** — Performs a single GraphQL fetch with an `AbortController`-based timeout (`RELAY_REQUEST_TIMEOUT_MS`), converting abort-due-to-timeout into a descriptive `Error`.
- **`executeFetchWithRetry(request, variables, headers)`** — Wraps `executeFetch` with jittered exponential backoff (`RETRY_ATTEMPTS`, `RETRY_BASE_DELAY_MS`), a total time budget (`RETRY_TOTAL_BUDGET_MS`), retriable-status detection (`isRetriableStatus`), and offline-aware waiting (`waitForOnline`, `OFFLINE_GRACE_MS`), throwing `OfflineError` or `UpdateRequiredError` as appropriate.
- **`waitForOnline(timeoutMs)`** — Resolves once connectivity returns or a timeout elapses, using `subscribeConnectivity`.
- **`backoffDelayMs(attempt)` / `sleep(ms)`** — Backoff delay calculation and promise-based delay helper.

The file also integrates with several cross-cutting concerns imported from sibling modules: session health (`isSessionGone`, `markSessionPaused`, `SessionGoneError`), session readiness (`waitForSessionReady`), subscription gating (`waitForSubscriptionGate`, `markSubscriptionLocked`), trial-expiration detection, token refresh (`refreshTokens`), and update enforcement (`isUpdateRequired`, `UpdateRequiredError`).

## Usage Example

```typescript
import { sendGraphqlKeepalive } from './environment';

// Typically used in a `pagehide` handler to flush a final mutation/log
window.addEventListener('pagehide', () => {
  sendGraphqlKeepalive(
    { text: 'mutation LogExit($id: ID!) { logExit(id: $id) }' },
    { id: 'session-123' },
  );
});
```

The exported Relay `Environment` (constructed using `Network.create`, `Store`, and `RecordSource` from this module) is consumed by `RelayEnvironmentProvider` at the app root to supply GraphQL fetching to all `useLazyLoadQuery`/`useFragment` call sites, with retries, timeouts, and gating applied transparently.
