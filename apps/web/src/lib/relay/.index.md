Re-exports the public API for the Relay integration module, exposing environment management utilities and the React provider component.

## Key Components

| Export | Source | Description |
|--------|--------|-------------|
| `getRelayEnvironment` | `./environment` | Retrieves the current Relay environment instance |
| `resetRelayEnvironment` | `./environment` | Resets the Relay environment (useful for auth state changes or testing) |
| `RelayProvider` | `./provider` | React context provider that supplies the Relay environment to the component tree |

## Usage Example

```typescript
import { getRelayEnvironment, resetRelayEnvironment, RelayProvider } from '@/relay';

// Wrap your app with the Relay context provider
function App() {
  return (
    <RelayProvider>
      <YourAppComponents />
    </RelayProvider>
  );
}

// Access the environment directly (e.g., for manual queries or mutations)
const environment = getRelayEnvironment();

// Reset the environment on logout or session expiry
resetRelayEnvironment();
```

## Notes

- This barrel file serves as the single entry point for all Relay-related imports across the app.
- Prefer importing from this index rather than the individual `environment` or `provider` modules directly to maintain a stable public API.
