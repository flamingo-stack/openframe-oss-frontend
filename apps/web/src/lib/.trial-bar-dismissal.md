Provides persistent, trial-scoped dismissal state for the free-trial banner using `localStorage`, kept independent of any UI framework so it can be invoked outside React's component tree.

## Key Components

- **`STORAGE_KEY`** — Constant key (`openframe:trial-bar-dismissed-v1`) under which the dismissal token is stored.
- **`isTrialBarDismissed(token: string | null): boolean`** — Checks whether the banner for the given trial token has already been dismissed. Returns `false` safely when `token` is null, running server-side (no `window`), or `localStorage` is unavailable (e.g., private browsing mode).
- **`dismissTrialBar(token: string): void`** — Persists the given trial token as dismissed, overwriting any previous entry. No-ops silently if `localStorage` is unavailable or running server-side.

## Usage Example

```typescript
import { isTrialBarDismissed, dismissTrialBar } from './trial-bar-dismissal';

// token typically derived from the trial's subscription id + end date
const trialToken = `${subscriptionId}:${trialEndsAt}`;

if (!isTrialBarDismissed(trialToken)) {
  // render the trial banner
  showTrialBanner();
}

function onDismissClick() {
  dismissTrialBar(trialToken);
  hideTrialBanner();
}
```

**Design notes:**
- The token must uniquely identify a trial period (not just the browser), so switching tenants or starting a new trial automatically re-shows the banner.
- Storage failures (e.g., disabled `localStorage`) default to showing the banner rather than silently hiding it—an intentional fail-safe since the banner is user-dismissible.
- Only one dismissal is tracked at a time; no history of past trials is retained.
