Orchestrates the native shell OAuth login flow for both mobile and desktop environments, exchanging a gateway-issued dev-ticket for access/refresh tokens stored in the system Keychain.

## Key Components

### `NativeLoginResult`
Result interface returned after a successful login.

| Field | Type | Description |
|---|---|---|
| `tenantHostChanged` | `boolean` | Signals that the resolved tenant host differs from the boot-time host, requiring a full page navigation to re-initialize client state |

### `nativeLogin(options)`
Main async function that drives the full OAuth flow.

| Parameter | Type | Description |
|---|---|---|
| `tenantId` | `string` | Target tenant identifier passed to the gateway |
| `provider` | `string?` | Optional OAuth provider override |
| `tenantDomain` | `string?` | Optional pre-discovered tenant domain; falls back to `NEXT_PUBLIC_TENANT_HOST_URL` |

**Flow summary:**
1. Resolves the tenant host from discovery or runtime config
2. Builds a redirect target — custom scheme (`myapp://auth`) on mobile, HTTPS callback path on desktop
3. Opens the gateway BFF login URL via the native auth plugin
4. Extracts the `devTicket` from the callback URL
5. Exchanges the ticket at `/oauth/dev-exchange` for access/refresh tokens
6. Persists tokens via `setTokens` and the resolved host via `storeTenantHost` / `plugin.setTenantHost`

## Usage Example

```typescript
import { nativeLogin } from './native-login';

const result = await nativeLogin({
  tenantId: 'acme-corp',
  provider: 'google',
  tenantDomain: 'acme.openframe.ai',
});

if (result.tenantHostChanged) {
  // Full navigation required — SPA state is stale for the new host
  window.location.href = '/dashboard';
}
```

> **Note:** Requires `dev-ticket-enabled` on the gateway BFF. Not intended for production tenants. On mobile, Google blocks OAuth in embedded webviews (`403 disallowed_useragent`), so the flow uses `ASWebAuthenticationSession` with a custom URL scheme.
