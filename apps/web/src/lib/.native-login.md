# native-login.ts

Implements the native-shell OAuth login flow for mobile and desktop app shells. It launches the gateway's BFF OAuth flow in an in-app browser (ASWebAuthenticationSession on mobile, default browser on desktop), receives a one-time `devTicket` on the app's custom scheme, exchanges it natively for tokens, and persists them in the Keychain. It also handles the iOS-native "Sign in with Apple" path and surfaces structured errors for SSO/Apple registration gaps.

## Key Components

- **`nativeLogin(options)`** — Main entry point. Resolves the tenant host, builds the gateway login URL (tenant-specific or shared onboarding SSO), opens the native auth browser via `nativeAuthPlugin()`, waits for the callback, and completes the ticket exchange. Returns `NativeLoginResult` indicating if the tenant host changed.
- **`appleIdentityEmail(credential)`** — Extracts the asserted email from an Apple identity JWT for display purposes only (server re-verifies independently).
- **`SsoRegistrationRequiredError`** — Thrown when an SSO identity has no matching account; carries a `signupTicket` for completing registration.
- **`AppleRegistrationRequiredError`** — Thrown when a verified Apple identity has no account; carries the spendable `AppleCredential`.
- **`AppleRegisterError`** — Signup failure for native Apple flow; tracks whether Apple's single-use code (`credentialSpent`) was already consumed.
- **`NativeLoginError`** — Browser sign-in ended without a usable result; carries a user-facing `title` for toast display.
- **`readJwtClaim`** — Internal helper to read an unverified claim off a JWT payload (display-only use).
- **`outcomeError` / `browserSignInError`** — Internal helpers that normalize desktop/mobile callback errors and outcome codes into user-facing `Error` instances.

## Usage Example

```typescript
import { nativeLogin, SsoRegistrationRequiredError, NativeLoginError } from './native-login';

try {
  const result = await nativeLogin({
    tenantId: 'tenant-123',
    provider: 'google',
    email: 'user@example.com',
  });

  if (result.tenantHostChanged) {
    // Force a full page navigation so clients re-initialize against the new host
    window.location.href = '/dashboard';
  }
} catch (error) {
  if (error instanceof SsoRegistrationRequiredError) {
    // Route to org/signup screen with error.signupTicket
  } else if (error instanceof NativeLoginError) {
    showToast(error.title, error.message);
  } else {
    showToast('Sign-in failed', (error as Error).message);
  }
}
```
