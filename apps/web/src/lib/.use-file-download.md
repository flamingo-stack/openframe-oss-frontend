# use-file-download.ts

A React hook that downloads a file while providing user feedback throughout the process, designed for callers that must first resolve a (potentially short-lived, presigned) URL before the download can start.

This hook exists primarily to solve a UX problem: on mobile, native file downloads give little or no visual feedback. iOS only shows a share sheet once the transfer completes, and Android ≥29 writes silently to Downloads. Without an intermediate "Downloading" toast, users may think the app has frozen or that their tap didn't register.

## Key Components

- **`useFileDownload()`** — Returns a memoized async callback `(fileName, resolveUrl) => Promise<void>` that:
  1. Shows a persistent, non-dismissible "Downloading" toast immediately.
  2. Awaits `resolveUrl()` to obtain the actual download URL (e.g., a presigned attachment URL).
  3. Calls `downloadFileToDevice(url, fileName)` from `./native-files`.
  4. Shows a "Saved to Downloads" success toast only if the result is `'saved'` (silent save case) — `'shared'` and `'browser'` outcomes already have their own OS-level UI, so no extra toast is needed.
  5. On error, shows a "Download Failed" destructive toast with the error message.
  6. Always dismisses the pending toast in a `finally` block.

## Usage Example

```typescript
import { useFileDownload } from './use-file-download';

function AttachmentButton({ attachmentId, fileName }: { attachmentId: string; fileName: string }) {
  const downloadFile = useFileDownload();

  const handleClick = () => {
    downloadFile(fileName, async () => {
      // Resolve a short-lived presigned URL before downloading
      const response = await fetch(`/api/attachments/${attachmentId}/url`);
      const { url } = await response.json();
      return url;
    });
  };

  return <button onClick={handleClick}>Download</button>;
}
```

**Dependencies:**
- `useToast` from `@flamingo-stack/openframe-frontend-core/hooks` for toast notifications.
- `downloadFileToDevice` from `./native-files` for the platform-specific download implementation.
