Defines the base URL for the OpenFrame hub's public content API, used by surfaces that lack a local `/content` proxy, such as the shared-auth host whose gateway routes everything except `/auth` back to this application.

## Key Components

- **`HUB_PUBLIC_API`** — Exported constant string holding the absolute URL (`https://content-api.openframe.ai/api`) of the hub's public content API endpoint.

## Usage Example

```typescript
import { HUB_PUBLIC_API } from './hub-public-api';

// Build a request to the hub's public content API
async function fetchContent(path: string) {
  const response = await fetch(`${HUB_PUBLIC_API}${path}`);
  if (!response.ok) {
    throw new Error(`Failed to fetch content: ${response.statusText}`);
  }
  return response.json();
}

// Example call
const articles = await fetchContent('/articles');
```

This constant is typically used as a fallback base URL when the current host does not provide a local `/content` proxy (e.g., on the shared-auth domain), ensuring API calls are routed directly to the hub's public endpoint instead.
