# native-update.ts

The bundle-side counterpart to the mobile shell's native over-the-air updater. It reports boot success back to the shell, reads/triggers update state, and swaps in a pending bundle on request. On platforms without the updater (desktop, browser, pre-updater store builds), `nativeUpdatePlugin()` returns null and all functions become safe no-ops.

## Key Components

- **`confirmBundleBooted()`** — Tells the shell this bundle started successfully and can work with it. Must be called early (before the first `await`) so it fires ahead of any biometric prompt. Withholds confirmation if the shell's bridge lacks required core methods (auth, splash screen, app info), which signals a `REQUIRED_BRIDGE_LEVEL` mismatch. Never throws.
- **`readUpdateState()`** — Returns the updater's current `NativeUpdateState` (enabled flag, versions, trial status, bridge level), or `null` if no updater is present or the call failed.
- **`checkForUpdate()`** — Asks the shell to actively check for a newer bundle, resolving with the resulting state once the check completes.
- **`restartIntoPendingUpdate()`** — Requests the shell to swap the web view to a previously downloaded pending bundle. Returns `true` only if the request was accepted (the shell reloads on success, so callers rarely observe `true` directly); `false` if there's no updater or the shell refused.
- **`missingCoreSurface()`** *(internal)* — Verifies the bridge exposes all methods this bundle depends on (`NativeAuth`, `SplashScreen`, `App`), used to gate the ready confirmation.
- **`normalizeState()`** *(internal)* — Defensively coerces the raw, untyped bridge response into a well-formed `NativeUpdateState`.

## Usage Example

```typescript
import {
  confirmBundleBooted,
  readUpdateState,
  checkForUpdate,
  restartIntoPendingUpdate,
} from './native-update';

// Call as early as possible during app bootstrap
await confirmBundleBooted();

// Later, check current update status
const state = await readUpdateState();
if (state?.pendingVersion) {
  // A new bundle is already downloaded; prompt the user
  const restarted = await restartIntoPendingUpdate();
  if (!restarted) {
    console.warn('Could not restart into pending update');
  }
}

// Actively trigger a check (e.g. from a "Check for updates" button)
const checked = await checkForUpdate();
console.log('Update check result:', checked);
```
