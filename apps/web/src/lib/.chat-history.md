Utility functions for managing AI approval segments within a chat message history, including finding, folding, extracting, and stripping pending approval cards to ensure consistent UI state during streaming and interruption scenarios.

## Key Components

| Export | Signature | Purpose |
|---|---|---|
| `findLatestPendingApprovalId` | `(messages: M[]) => string \| undefined` | Scans newest-to-oldest for the latest pending `approval_request` or `approval_batch` segment; returns its request ID |
| `foldPendingApprovalsEnvelope` | `(messages: M[]) => M[]` | Merges `pending-approvals-*` envelope messages back into their preceding assistant turn |
| `extractPendingApprovals` | `(messages: M[], resolvedStatuses?) => MessageSegment[]` | Collects all unresolved pending approval segments, filtering out any already resolved via realtime status or inline history |
| `stripPendingApprovals` | `(messages: M[]) => M[]` | Removes pending approval segments from inline message content; dedupes resolved segments by request ID across bubbles and drops empty assistant turns |

## Usage Example

```typescript
import {
  findLatestPendingApprovalId,
  foldPendingApprovalsEnvelope,
  extractPendingApprovals,
  stripPendingApprovals,
} from './chat-history';

// 1. Before sending a new message, optimistically reject the active approval gate
const pendingId = findLatestPendingApprovalId(storeMessages);

// 2. Re-attach any pending-approvals-* envelopes back into their assistant turns
const folded = foldPendingApprovalsEnvelope([...storeMessages, ...realtimeMessages]);

// 3. Extract segments that should render as sticky approval cards
const resolvedStatuses: Record<string, string> = { 'req-abc': 'approved' };
const pendingCards = extractPendingApprovals(folded, resolvedStatuses);

// 4. Strip pending segments from inline bubbles (pass to the message renderer)
const displayMessages = stripPendingApprovals(folded);
```

## Notes

- All functions are generic over `M extends ChatMessage`, preserving concrete message subtypes through transformations.
- `extractPendingApprovals` guards against stale duplicate `pending` copies that can appear when history is reprocessed before a realtime resolved status arrives.
- `stripPendingApprovals` drops assistant bubbles that become entirely empty after filtering, preventing orphan UI nodes.
