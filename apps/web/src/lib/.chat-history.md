Utility functions for the approval cards in a chat thread: finding, extracting and stripping pending approval parts, so the UI stays consistent during streaming and interruption. A card is a `dynamic-tool` part; its status is `approvalStatusOf(part)`.

## Key Components

| Export | Signature | Purpose |
|---|---|---|
| `DISPLAY_APPROVAL_TYPES` | `readonly string[]` | The approval tiers an operator of this app answers; another tier's card stays off screen through the lib's `approvalDisplaysInline` |
| `findLatestPendingApprovalId` | `(messages) => string \| undefined` | Scans newest-to-oldest for the latest pending approval; returns the id it is answered by (the batch's when it has one) |
| `extractPendingApprovals` | `(messages, resolvedStatuses?) => ChatToolPart[]` | Collects the unresolved cards of one for the sticky footer, leaving out any already resolved through the status map or another copy |
| `stripPendingApprovals` | `(messages) => M[]` | Removes the footer's cards from the flow; dedupes a card by its id across bubbles (an answered copy wins, a batch stays whole in the bubble that holds it) and drops empty assistant turns |
| `isCompactingTail` | `(messages) => boolean` | Whether the thread ends on a context compaction still running, which locks the composer |

## Usage Example

```typescript
import { extractPendingApprovals, findLatestPendingApprovalId, stripPendingApprovals } from './chat-history';

// 1. Before sending a new message, optimistically reject the active approval gate
const pendingId = findLatestPendingApprovalId(messages);

// 2. Extract the cards that render as sticky approval cards
const pendingCards = extractPendingApprovals(messages, { 'req-abc': 'approved' });

// 3. Strip them from inline bubbles (pass to the message renderer)
const displayMessages = stripPendingApprovals(messages);
```

## Notes

- `extractPendingApprovals` guards against stale duplicate `pending` copies that can appear when history is reprocessed before a realtime resolved status arrives.
- `stripPendingApprovals` drops assistant bubbles that become entirely empty after filtering, preventing orphan UI nodes.
