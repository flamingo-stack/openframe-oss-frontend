# push-retraction.ts

Handles clearing OS notification banners when the server retracts a push notification (e.g., because it was read, dismissed, or resolved on another device). This logic is split from `native-push.ts` to keep pure wire-payload parsing free of Relay GraphQL dependencies, enabling straightforward unit testing.

Retraction is intentionally best-effort: a notification outbox row claimed exactly at resolution time matches neither the cancel nor retract path, so stale banners are an expected, tolerated outcome rather than a bug.

## Key Components

- **`RETRACTION_EVENT`** — Constant matching the server-side data-only push event name (`NOTIFICATION_RETRACTED`) used to signal a banner should be cleared.
- **`parseRetractedIds(data: unknown): string[]`** — Extracts notification ids to retract from a push payload. Reads both the directly-named `notificationId` (when the event is a retraction) and the rolling `retractedIds` list carried on every push, since FCM delivery isn't guaranteed and redundancy covers missed pushes.
- **`removeRetracted(plugin: FirebaseMessagingPlugin, ids: string[]): Promise<void>`** — Removes matching delivered notifications from the OS notification center. Effectively **iOS-only**: on Android, delivered notification data/ids can never match server-assigned ids, so the function short-circuits early to avoid a wasted native bridge call. Android retraction is handled separately in the native messaging service.

## Usage Example

```typescript
import { parseRetractedIds, removeRetracted } from './push-retraction';
import type { FirebaseMessagingPlugin } from './native-shell';

async function handleIncomingPush(plugin: FirebaseMessagingPlugin, data: unknown) {
  const retractedIds = parseRetractedIds(data);
  if (retractedIds.length > 0) {
    await removeRetracted(plugin, retractedIds);
  }
}
```

This is typically invoked from the push message handler whenever a new FCM message arrives, whether it is itself a retraction event or simply carries an updated `retractedIds` list as part of its standard payload.
