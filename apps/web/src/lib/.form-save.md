# form-save.ts

Client-side utilities that guard form submission against double-submits, surface validation errors as toasts (scrolling to the first invalid field), and translate API-level mutation errors into user-friendly messages—particularly for concurrent-edit conflicts on directory connections.

## Key Components

- **`useGuardedSubmit()`** — React hook returning a submit function that prevents concurrent validation runs (using a ref-based guard, since `handleSubmit` is async). On success, calls `onValid` with the parsed form values. On failure, shows a destructive toast titled by `invalidTitle` and scrolls to the first invalid field.
- **`invalidSubmitHandler()`** — Internal helper that deduplicates field error messages, toasts them (or a generic fallback), and triggers scroll-to-invalid-field.
- **`CONNECTION_MODIFIED_CONCURRENTLY`** — Error code constant representing a rejected write due to a concurrent modification (optimistic concurrency conflict, no locking).
- **`userErrorsDescription()`** — Builds a toast description from a list of API error objects (`code`/`message`), special-casing the concurrent-modification scenario with guidance to reload and retry, otherwise deduplicating and joining messages.

## Usage Example

```typescript
import { useGuardedSubmit, userErrorsDescription, CONNECTION_MODIFIED_CONCURRENTLY } from '@/lib/form-save';
import { useForm } from 'react-hook-form';

function useCustomerForm() {
  const form = useForm<CustomerValues>();
  const guardedSubmit = useGuardedSubmit();

  const onSubmit = () => {
    guardedSubmit<CustomerValues>(
      'Unable to save customer',
      (pass, fail) => form.handleSubmit(pass, fail)(),
      async values => {
        const result = await saveCustomer(values);
        if (result.errors?.length) {
          toast({
            title: 'Save failed',
            description: userErrorsDescription(result.errors),
            variant: 'destructive',
          });
        }
      },
    );
  };

  return { form, onSubmit };
}
```

Typical API error payload handled by `userErrorsDescription`:

```typescript
[{ code: CONNECTION_MODIFIED_CONCURRENTLY, message: 'Stale version' }]
// => "Someone else saved this while you were editing. Reload the page to see their changes, then try again."
```
