Configures and exports the two Google Fonts used across the application — **Azeret Mono** and **DM Sans** — via Next.js's built-in font optimization system.

## Key Components

| Export | Font | CSS Variable | Weights |
|---|---|---|---|
| `azeretMono` | Azeret Mono | `--font-azeret-mono` | 400, 500, 600, 700 |
| `dmSans` | DM Sans | `--font-dm-sans` | 400, 500, 700 |

Both fonts are configured with `subset: ['latin']` and `display: 'swap'` for optimized loading behavior.

## Usage Example

Apply the CSS variables in your root layout, then reference them in Tailwind or plain CSS:

```typescript
// app/layout.tsx
import { azeretMono, dmSans } from '@/styles/fonts';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html className={`${azeretMono.variable} ${dmSans.variable}`}>
      <body>{children}</body>
    </html>
  );
}
```

```css
/* globals.css or tailwind.config.ts */
body {
  font-family: var(--font-dm-sans), sans-serif;
}

code {
  font-family: var(--font-azeret-mono), monospace;
}
```

> **Note:** Next.js requires font loader calls to be assigned directly to a `const` — this file must not re-export fonts from a dynamic expression or function call.
