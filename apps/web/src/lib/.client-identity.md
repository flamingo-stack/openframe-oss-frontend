# client-identity.ts

Builds and provides the `X-OpenFrame-Client` header, which identifies the calling client build (web/iOS/Android/desktop shell version plus bundle version) on every request sent to the tenant gateway. This lets the backend gate GraphQL schema deprecations on real client data instead of guesswork.

## Key Components

- **`CLIENT_IDENTITY_HEADER`** — the header name constant, `'X-OpenFrame-Client'`.
- **`clientBundleVersion()`** — returns the build-time bundle version (inlined via `next.config.mjs`'s `env`), or `'-'` if invalid/missing.
- **`clientIdentityValue()`** — composes the full header value: `<kind>/<shellVersion|-> bundle/<bundleVersion>`.
- **`clientIdentityHeaders()`** — returns a ready-to-spread headers object: `{ 'X-OpenFrame-Client': value }`.
- **`primeShellVersion()`** — asynchronously resolves the native shell version once per document load (no-op on subsequent calls); requests made before resolution report `-` for shell version.
- **`VERSION_PATTERN`** — validation regex (`^[0-9A-Za-z.-]{1,32}$`) matching the backend's acceptance rule, used to reject malformed/control-character values before they reach `fetch` headers.

## Usage Example

```typescript
import { primeShellVersion, clientIdentityHeaders } from './client-identity';

// Call once early in app bootstrap (e.g. in a root layout or app init)
primeShellVersion();

// Attach to any request destined for the tenant gateway
async function callTenantGateway(url: string, init: RequestInit = {}) {
  const headers = {
    ...init.headers,
    ...clientIdentityHeaders(),
  };
  return fetch(url, { ...init, headers });
}
```

**Important:** only attach these headers to tenant-gateway requests (api-client, Relay, embedded chat, upload helpers). Do **not** add them to shared auth host calls (to avoid CORS preflight on simple requests) or to presigned storage/third-party URLs (an unsigned extra header can invalidate a signed PUT).
