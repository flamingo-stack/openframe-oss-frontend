# handle-api-error.ts

Utility functions for extracting user-facing error messages from generic JavaScript errors and Relay GraphQL mutation/query errors, and for surfacing them via toast notifications.

## Key Components

- **`getErrorMessage(error: unknown): string`** — Generic fallback extractor; handles `Error` instances, plain strings, and unknown shapes (returns a generic message).
- **`getRelayErrorMessage(error: unknown, fallback?: string): string`** — Extracts clean backend messages from Relay's verbose "no data returned, got error(s)" wrapper, preferring structured `error.source.errors`, filtering out graphql-java's non-null-field noise, and falling back to text-stripping then `getErrorMessage`.
- **`RelayGraphqlError`** — Interface `{ message: string; code: string | null }` representing one backend GraphQL error with its `extensions.code`.
- **`getRelayGraphqlErrors(error: unknown): RelayGraphqlError[]`** — Returns all structured GraphQL errors (message + code) attached to a thrown Relay error; empty array for non-Relay errors.
- **`getRelayErrorCodes(error: unknown): string[]`** — Returns just the `extensions.code` values from a Relay error's `source.errors`.
- **`handleApiError(error, toast, defaultMessage?)`** — Convenience helper for React Query `onError` callbacks; extracts a message and dispatches a destructive toast.

## Usage Example

```typescript
import { getRelayErrorMessage, getRelayGraphqlErrors, handleApiError } from './handle-api-error';

// In a React Query mutation
useMutation({
  mutationFn: createUser,
  onError: (error) => handleApiError(error, toast, 'Failed to create user'),
});

// In a Relay mutation, surfacing backend-specific messages
commitMutation(environment, {
  mutation,
  variables,
  onError: (error) => {
    setErrorMessage(getRelayErrorMessage(error, 'Unable to save changes'));

    const codes = getRelayGraphqlErrors(error).map(e => e.code);
    if (codes.includes('FORBIDDEN')) {
      redirectToLogin();
    }
  },
});
```
