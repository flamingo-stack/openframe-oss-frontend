Turns the image URLs the backend stores into URLs a picture can load: absolute on the tenant gateway's `/api`, with an optional cache-busting hash.

## Key Components

### `getFullImageUrl(imageUrl, hash?)`
The data-boundary builder: absolutizes with `buildFullUrl`, then appends `?v=<hash>` (or `&v=<hash>` when the URL already has a query). Returns `undefined` if `imageUrl` is falsy. Call it in the mapper that reads a backend image field.

### `resolveBackendImageUrl(url)`
Absolutizes only the backend's own image paths (`/images/{type}/{id}`, `/knowledge-base/images/{id}`, with or without `/api`), leaving everything else (absolute, `data:`, `blob:`, the bundle's own files) unchanged. Idempotent. Registered as the chat runtime adapter's `resolveAssetUrl`, so every core-lib picture passes its src through it: a safety net for a value that reached a picture without `getFullImageUrl`.

### `appendImageHash(imageUrl, hash?)` *(internal)*
Appends the hash without changing the URL's form.

### `buildFullUrl(imageUrl)` *(internal)*
Normalizes relative paths against `runtimeEnv.tenantHostUrl()`:

| Input form | Output |
|---|---|
| `https://...` / `http://...` | Returned as-is |
| `/api/...` | `{tenantHost}/api/...` |
| `/path` | `{tenantHost}/api/path` |
| `path` | `{tenantHost}/api/path` |

## Usage Example

```typescript
import { getFullImageUrl, resolveBackendImageUrl } from './image-url';

// A backend image field with its hash → absolute gateway URL
const url = getFullImageUrl('/images/user/u-1', 'abc123');
// → "https://tenant.example.com/api/images/user/u-1?v=abc123"

// A remote-access copy that already carries its hash
const avatar = getFullImageUrl('/images/user/u-1?v=abc123');
// → "https://tenant.example.com/api/images/user/u-1?v=abc123"

// Already absolute (a Google SSO picture) — unchanged
const external = getFullImageUrl('https://lh3.googleusercontent.com/a/x');

// Only backend image paths move
resolveBackendImageUrl('/assets/logo.svg'); // → "/assets/logo.svg"
```
