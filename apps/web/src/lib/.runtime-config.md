# runtime-config.ts

Provides a typed, runtime-resolved configuration layer for environment variables, bridging `next-runtime-env` (browser-injected env vars) with native shell storage (tenant host persistence) and sensible fallback defaults. This decouples the app from build-time-only `process.env` access, allowing a single binary/bundle to serve multiple tenants/environments.

## Key Components

- **`getEnvVar(key: string)`** — Internal helper that safely reads an environment variable via `next-runtime-env`'s `env()` function, with fallback to a `window.process.env` shim or Node's `process.env` if the primary accessor throws. Returns `undefined` for missing/empty values.

- **`runtimeEnv`** — Exported object exposing all runtime configuration as methods:
  - `tenantHostUrl()` — Resolves the active tenant's gateway host (build-time var, falling back to a host persisted from a previous native-shell login).
  - `pinnedTenantHostUrl()` — Build-time tenant pin only; use for new sign-ins to avoid leaking a stale stored tenant host.
  - `sharedHostUrl()` — Shared/multi-tenant host URL.
  - `brewCask()` — Homebrew cask name for the matching agent build (per environment).
  - `appScheme()` — OAuth callback URL scheme for native shells, with per-environment override support.
  - `gtmContainerId()` — Google Tag Manager container ID, if configured.
  - `appMode()` — Application mode, defaults to `'oss-tenant'`.
  - `appType()` — Application type identifier, defaults to `'openframe-dashboard'`.
  - `appUrl()` — This install's configured address (empty string if unset; fallback logic lives elsewhere, in `./utils`).
  - `enableDevTicketObserver()` — Boolean flag for a dev-only feature.
  - `prNumberEnabled()` — Boolean flag enabling a PR Number field on signup (dev only).
  - `authCheckIntervalMs()` — Polling interval for auth checks, defaults to `300000` ms.
  - `authLoginUrl()` — Shared host URL used for authentication login redirects.
  - `mobileTenantId()` — Tenant ID baked into mobile builds.
  - `mobileAuthUi()` — Which auth screens the mobile shell renders (`'login-only'` or `'legacy'`).

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config';

// Resolve the tenant gateway host for an already-authenticated session
const host = runtimeEnv.tenantHostUrl();

// Use the pinned (build-time only) host when starting a NEW sign-in flow
const signInHost = runtimeEnv.pinnedTenantHostUrl();

// Feature flags
if (runtimeEnv.enableDevTicketObserver()) {
  // enable dev-only ticket observer UI
}

// Auth polling
setInterval(() => {
  // check auth status
}, runtimeEnv.authCheckIntervalMs());

// Mobile shell auth UI branching
const authUi = runtimeEnv.mobileAuthUi();
if (authUi === 'login-only') {
  // render minimal login-only screens
}
```
