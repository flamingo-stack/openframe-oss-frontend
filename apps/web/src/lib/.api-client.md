# api-client.ts

Centralized HTTP client that wraps `fetch` with unified authentication (cookie- and bearer-token-based), automatic token refresh on `401`, session/subscription gating, request timeouts, and special-case handling for `426` (update required) and `410` (session gone) gateway responses.

## Key Components

- **`ApiClient`** — core class exposing `request<T>()`, the main entry point for making authenticated API calls.
- **`REQUEST_TIMEOUT_MS`** — default request timeout (30s) applied via an internal `AbortController`.
- **`AUTH_UNAVAILABLE_MESSAGE`** — error message returned when token refresh fails for transient reasons (not an invalid session).
- **`ApiRequestOptions`** — extends `RequestInit` with `skipAuth`, `skipSessionGate`, and `timeoutMs` flags.
- **`ApiResponse<T>`** — standardized response shape (`data`, `error`, `status`, `ok`).
- **`updateRequiredResponse()` / `sessionGoneResponse()`** — short-circuit helpers for `426`/`410` gateway states, answered locally after the first occurrence.
- **`isGatewayUrl()`** — distinguishes tenant-gateway requests (session-relevant) from external calls.
- Private helpers: `getAuthHeaders()` (bearer token attachment), `buildUrl()` (resolves relative paths against the tenant host), `forceLogout()` (delegates to shared logout utility).

The class coordinates with several companion modules: `token-refresh-manager` (single-flight refresh), `session-ready`/`subscription-gate` (bootstrap latches), `session-health` (gone-session tracking), and `version-check` (forced-upgrade detection).

## Usage Example

```typescript
import { ApiClient } from './api-client';

const client = new ApiClient();

// Standard authenticated request
const response = await client.request<{ id: string; name: string }>('/api/customers/123');
if (response.ok) {
  console.log(response.data);
} else {
  console.error(response.error, response.status);
}

// Bootstrap-only call that must not wait on session/subscription gates
await client.request('/me', { skipSessionGate: true });

// Custom timeout, no auth headers
await client.request('/public/health', { skipAuth: true, timeoutMs: 5000 });
```

Callers should always check the `ok` field before using `data`; `401` responses are retried once automatically after a token refresh, and persistent failures (`410`, `426`, or exhausted refresh attempts) surface as standard error responses rather than throwing.
