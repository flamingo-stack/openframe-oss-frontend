# MeshCentral Integration Library

Central barrel file that aggregates and re-exports all MeshCentral integration functionality, including WebSocket communication, file management, upload/download operations, and permission checking utilities.

## Key Components

- **`WebSocketManager`** — Core WebSocket connection handler for MeshCentral communication
- **`MeshControlClient`** — High-level client for MeshCentral control operations
- **`MeshCentralFileManager`** — Manages remote file system operations
- **`FileBinaryProtocol`** — Handles binary protocol encoding/decoding for file transfers
- **`FileDownloader`** / **`FileUploader`** — Task-based file download and upload handlers
- **`FileOperations`** — File system operation utilities (list, delete, rename, etc.)
- **`FileErrorHandler`** — Centralized error handling for file operations
- **`buildWsUrl`, `MESH_USER`, `MESH_PASS`** — Configuration constants and WebSocket URL builder
- **`canAccessFiles(userRights)`** — Checks bitmask permissions to determine if a user can access files, validating mesh-level (`SERVERFILES`, `NOFILES`) and site-level (`FILEACCESS`) rights
- **Type exports** — `DownloadTask`, `UploadTask`, `FileEntry`, `FileManagerOptions`, `FileConnectionState`, `MeshRights`, `SiteRights`, and related interfaces for strong typing across the integration

## Usage Example

```typescript
import {
  WebSocketManager,
  MeshCentralFileManager,
  canAccessFiles,
  buildWsUrl,
} from '@/lib/meshcentral';

// Build WebSocket connection URL
const wsUrl = buildWsUrl('device-node-id');

// Check if current user can access files
const allowed = canAccessFiles({ mesh: userMeshRights, site: userSiteRights });

if (allowed) {
  const fileManager = new MeshCentralFileManager({
    nodeId: 'device-node-id',
    wsUrl,
  });

  await fileManager.connect();
  const listing = await fileManager.listDirectory('/');
}
```
