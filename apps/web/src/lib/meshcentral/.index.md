Entry point for the MeshCentral integration library, re-exporting all file management, transfer, and WebSocket components along with a utility function for checking file access permissions.

## Key Components

| Export | Type | Description |
|---|---|---|
| `MeshCentralFileManager` | Class | Core file manager for MeshCentral operations |
| `WebSocketManager` | Class | Manages WebSocket connections to MeshCentral |
| `MeshControlClient` | Class | Client for MeshCentral control operations |
| `FileBinaryProtocol` | Class | Handles binary protocol encoding/decoding |
| `FileDownloader` | Class | Manages file download tasks |
| `FileUploader` | Class | Manages file upload tasks |
| `FileOperations` | Class | Common file operation helpers |
| `FileErrorHandler` | Class | Centralized file error handling |
| `canAccessFiles` | Function | Checks if a user has file access permissions |
| `buildWsUrl`, `MESH_USER`, `MESH_PASS` | Constants/Util | WebSocket URL builder and credentials config |

## Usage Example

```typescript
import {
  MeshCentralFileManager,
  WebSocketManager,
  canAccessFiles,
  buildWsUrl,
} from './index';

// Check permissions before initializing
const userRights = { mesh: 0x00000020, site: 0x00000008 };

if (canAccessFiles(userRights)) {
  const wsUrl = buildWsUrl('https://meshcentral.example.com', 'nodeId123');

  const manager = new MeshCentralFileManager({
    url: wsUrl,
    nodeId: 'nodeId123',
  });

  await manager.connect();
  const listing = await manager.listDirectory('/home/user');
}
```

## Permission Flags

`canAccessFiles` evaluates three bitfield conditions against MeshCentral's rights model:

| Flag | Hex | Requirement |
|---|---|---|
| `SERVERFILES` | `0x00000020` | Must be set on `mesh` rights |
| `NOFILES` | `0x00000400` | Must **not** be set on `mesh` rights |
| `FILEACCESS` | `0x00000008` | Must be set on `site` rights |

All three conditions must pass for the function to return `true`.
