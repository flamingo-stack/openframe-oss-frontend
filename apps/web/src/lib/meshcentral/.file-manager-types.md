Type definitions and constants for the MeshCentral File Manager module, covering connection states, file entries, transfer operations, and permission flags.

## Key Components

### Types & Enums

- **`FileConnectionState`** — Union type representing WebSocket tunnel states: `disconnected`, `connecting`, `connected_to_server`, `connected_end_to_end`, `failed`
- **`FileEntry`** — Represents a file/directory/link from a remote listing, including name, type, size, modified date, and optional metadata
- **`DirectoryListing`** — Response shape for `ls` (list directory) server actions
- **`FileOperationRequest` / `FileOperationResponse`** — Generic request/response envelopes for file operations, extensible via index signature
- **`UploadRequest`** — Payload for file uploads, supporting hash-based deduplication and append mode
- **`DownloadRequest`** — Payload for file download handshakes with sub-action state machine (`start` → `startack` → `ack` / `cancel`)
- **`FileTransferProgress`** — Progress reporting shape for active uploads or downloads
- **`BinaryHeader` / `BinaryAccumulator`** — Low-level binary protocol helpers for parsing chunked binary frames
- **`FileManagerOptions`** — Configuration and callback interface passed when instantiating the file manager

### Constants

- **`MeshRights`** — Bitmask flags for node-level permissions (`SERVERFILES`, `NOFILES`)
- **`SiteRights`** — Bitmask flags for site-level permissions (`FILEACCESS`)

## Usage Example

```typescript
import type {
  FileManagerOptions,
  FileConnectionState,
  FileEntry,
  FileTransferProgress,
} from './file-manager-types';
import { MeshRights, SiteRights } from './file-manager-types';

const options: FileManagerOptions = {
  nodeId: 'node//abc123',
  isRemote: true,
  onStateChange: (state: FileConnectionState) => {
    console.log('Connection state:', state);
  },
  onDirectoryChange: (files: FileEntry[]) => {
    const dirs = files.filter(f => f.t === 2);
    console.log('Directories:', dirs.map(d => d.n));
  },
  onTransferProgress: (progress: FileTransferProgress) => {
    console.log(`${progress.file}: ${progress.progress}%`);
  },
};

// Check permission bitmask
const userRights = 0x00000028;
const canAccessFiles = (userRights & MeshRights.SERVERFILES) !== 0; // true
const siteCanAccess = (userRights & SiteRights.FILEACCESS) !== 0;   // false
```
