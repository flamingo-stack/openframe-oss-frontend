# file-manager-types.ts

Type definitions for MeshCentral's remote File Manager feature, covering the file transfer protocol (directory listings, uploads, downloads), binary message framing, and connection lifecycle state used by the file manager client.

## Key Components

- **`FileConnectionState`** — Union type representing connection lifecycle stages, from `disconnected` through `connected_end_to_end` or `failed`.
- **`FileEntry`** — Represents a single file/directory/link entry returned by the agent, including name, type, size, modified date, and path.
- **`DirectoryListing`** — Shape of a directory listing (`ls`) response containing an array of `FileEntry`.
- **`FileOperationRequest` / `FileOperationResponse`** — Generic request/response envelopes for MeshCentral's file protocol actions, using an index signature (`unknown`) for action-specific fields.
- **`UploadRequest` / `DownloadRequest`** — Typed payloads for initiating uploads (with hash/size/skip tagging) and downloads (with sub-state handshake: `start`, `startack`, `ack`, `cancel`).
- **`FileTransferProgress`** — Progress tracking data for in-flight uploads/downloads.
- **`BinaryHeader` / `BinaryAccumulator`** — Low-level structures for parsing MeshCentral's binary message framing (command, size, buffered data).
- **`FileManagerOptions`** — Configuration object for initializing a file manager session, including node targeting, auth, and a set of lifecycle callbacks (`onStateChange`, `onDirectoryChange`, `onTransferProgress`, `onSearchResult`, etc.).
- **`MeshRights` / `SiteRights`** — Constant bitmask values for MeshCentral permission checks (e.g., `SERVERFILES`, `NOFILES`, `FILEACCESS`).
- **`RelayControlMessage`** — Shape of control-channel messages (keep-alives, close notices) distinct from file protocol data.

## Usage Example

```typescript
import type {
  FileManagerOptions,
  FileEntry,
  DirectoryListing,
} from './file-manager-types';

const options: FileManagerOptions = {
  nodeId: 'node//abc123',
  isRemote: true,
  onStateChange: (state) => console.log('State:', state),
  onDirectoryChange: (files: FileEntry[]) => {
    files.forEach((f) => console.log(f.n, f.t === 2 ? 'dir' : 'file'));
  },
  onTransferProgress: (progress) => {
    console.log(`${progress.file}: ${progress.progress}%`);
  },
};

function handleListing(msg: DirectoryListing) {
  console.log(`Listing for ${msg.path}:`, msg.dir.map((e) => e.n));
}
```
