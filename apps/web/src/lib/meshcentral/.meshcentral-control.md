Manages a persistent WebSocket connection to the MeshCentral `control.ashx` endpoint, handling authentication, tunnel creation, power actions, and clipboard operations for remote node control.

## Key Components

### `MeshControlClient` class

The primary export — wraps a `WebSocketManager` to provide a high-level API for MeshCentral control-plane operations.

| Member | Description |
|---|---|
| `constructor(credentials?, authCookie?)` | Initializes the WebSocket connection with user/pass or token auth, configuring heartbeat and reconnect behavior |
| `openSession()` | Connects the WebSocket and waits for auth cookies to be issued |
| `getAuthCookies(timeoutMs?)` | Returns cached cookies or waits for MeshCentral to issue them via the `authcookie` action |
| `sendRelayTunnel(...)` | Sends a generic relay tunnel message with protocol, relay ID, and optional domain prefix |
| `sendDesktopTunnel(...)` | Shorthand for relay tunnel with protocol `2` (desktop/RDP) |
| `sendFileTunnel(...)` | Shorthand for relay tunnel with protocol `5` (file transfer) |
| `powerAction(nodeId, action, timeoutMs?)` | Sends a `wake`, `sleep`, `reset`, or `poweroff` command and awaits confirmation |
| `setClipboard(nodeId, data, timeoutMs?)` | Pushes clipboard text to a remote node |
| `getClipboard(nodeId, timeoutMs?)` | Retrieves clipboard text from a remote node |
| `reconnect()` | Re-establishes the session and replays all active tunnels |
| `close()` | Tears down the connection and rejects all pending requests |
| `isConnected()` | Returns live connection status |
| `getCachedAuthCookie()` | Returns the cached auth cookie without triggering a network request |

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control';

const client = new MeshControlClient(
  { user: 'admin', pass: 'secret' }
);

await client.openSession();

// Open a desktop tunnel
client.sendDesktopTunnel('nodeABC', 'relay-123');

// Remote power actions
await client.powerAction('nodeABC', 'reset');

// Clipboard operations
await client.setClipboard('nodeABC', 'Hello from OpenFrame');
const text = await client.getClipboard('nodeABC');

client.close();
```

> Active tunnels are tracked internally and automatically replayed on reconnect via `resendActiveTunnels()`.
