## meshcentral-control.ts

Client for MeshCentral's `control.ashx` WebSocket endpoint, managing authentication cookies, device power actions, clipboard sync, and relay tunnel announcements for remote desktop/file sessions.

## Key Components

- **`MeshControlClient`** — main class wrapping a `WebSocketManager` connection to the MeshCentral control socket.
  - **constructor(credentials?, authCookie?)** — builds the control URL with user/pass/auth query params and optional bearer token, wires up reconnect/heartbeat/message handlers.
  - **`openSession()`** — ensures the WebSocket is connected and auth cookies have been received.
  - **`getAuthCookies(timeoutMs?)`** — resolves with `{ authCookie, relayCookie? }`, requesting them if not cached.
  - **`sendRelayTunnel(...)` / `sendDesktopTunnel(...)` / `sendFileTunnel(...)`** — announce a relay tunnel to the agent for a given node (desktop uses protocol `2`, file transfer uses protocol `5`); tracks tunnels so they can be re-announced after reconnect.
  - **`forgetTunnel(tunnelKey)`** — removes a tracked tunnel.
  - **`powerAction(nodeId, action, timeoutMs?)`** — sends `wake`/`sleep`/`reset`/`poweroff` commands and awaits the device response.
  - **`setClipboard(nodeId, data, timeoutMs?)`** — pushes clipboard content to a remote node.
  - **`sendTunnelMsg(nodeId, relayPathValue, usage?)`** — low-level helper that sends a `tunnel` message over the control socket.

Internally, it tracks `pendingRequests` (keyed by response id) for request/response correlation with timeouts, and `activeTunnels` (keyed by tunnel key) so relay announcements survive socket reconnects — each tunnel's `announced` flag resets on disconnect and is re-sent once new auth cookies arrive.

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control';

const control = new MeshControlClient();

// Ensure the control session and auth cookies are ready
await control.openSession();

// Power on a device
await control.powerAction('node//abc123hash', 'wake');

// Announce a desktop relay tunnel for a session
control.sendDesktopTunnel('session-1', 'node//abc123hash', 'relay-id-1');

// Push clipboard data
const ok = await control.setClipboard('node//abc123hash', 'copied text');

// Clean up tunnel tracking when the session ends
control.forgetTunnel('session-1');
```
