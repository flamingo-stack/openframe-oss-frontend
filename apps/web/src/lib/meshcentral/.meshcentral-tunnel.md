Manages a MeshCentral relay tunnel over WebSocket, handling the full connection lifecycle including handshake, protocol negotiation, latency monitoring, and bidirectional data transfer for terminal and desktop sessions.

## Key Components

### Types

- **`TunnelState`** — Numeric union `0 | 1 | 2 | 3` representing `stopped`, `connecting`, `open`, and `connected` states
- **`TunnelOptions`** — Optional terminal dimensions (`cols`, `rows`) and login requirements
- **`TunnelCallbacks`** — Internal callback interface for data, state, control messages, pairing requests, and reconnect hooks

### `MeshTunnel` Class

| Method | Description |
|---|---|
| `start()` | Builds the relay WebSocket URL and initiates connection via `WebSocketManager` |
| `stop()` | Sends close control message, disconnects, and resets state |
| `reconnect()` | Triggers reconnection if not already connected |
| `sendText(text)` | Sends a plain text frame |
| `sendBinary(data)` | Sends a binary (`Uint8Array`) frame |
| `sendCtrl(obj)` | Serializes and sends a JSON control channel message |
| `getState()` | Returns the current `TunnelState` |
| `isConnected()` | Returns `true` when state is `3` (fully handshaked) |
| `updateAuthCookie(cookie)` | Replaces the auth cookie used for URL construction |
| `getRelayId()` | Returns the unique relay session ID |

### Private Internals

- **`initializeHandshake()`** — Sends initial RTT ping and starts a 10-second latency timer
- **`onMessage(e)`** — Routes incoming messages: handshake tokens (`c`/`cr`), tilde-prefixed data, JSON control frames, and binary buffers

## Usage Example

```typescript
const tunnel = new MeshTunnel({
  authCookie: 'abc123',
  nodeId: 'node//abc...',
  protocol: 1,
  options: { cols: 220, rows: 50 },
  onData: (data) => terminal.write(data),
  onStateChange: (state) => console.log('Tunnel state:', state),
  onConsoleMessage: (msg) => console.log('[Console]', msg),
  onCtrlMessage: (msg) => handleCtrl(msg),
  onRequestPairing: (relayId) => controlConn.sendPairing(relayId),
});

tunnel.start();

// Later:
tunnel.sendText('ls -la\n');
tunnel.stop();
```
