Centralized error handling utility for the MeshCentral File Manager, providing error classification, message mapping, retryability detection, and error history tracking.

## Key Components

### Types & Interfaces

- **`FileErrorType`** — Union type of 15 error categories (e.g., `autherror`, `connectionerror`, `diskfull`, `uploadfailed`)
- **`FileError`** — Structured error object with `type`, `message`, `details`, `timestamp`, and `retryable` flag

### `FileErrorHandler` Class

| Method | Description |
|---|---|
| `constructor(onError?)` | Accepts optional global error callback; registers default handlers |
| `registerHandler(type, handler)` | Registers a custom handler for a specific error type |
| `handleError(error)` | Dispatches error to registered handler and global callback; appends to history |
| `parseError(message)` | Parses a raw MeshCentral message object into a `FileError` |
| `createError(errorString, details?)` | Constructs a `FileError` from a raw error string |
| `getErrorMessage(type, original?)` | Returns a human-readable message for a given error type |
| `isRetryable(type)` | Returns `true` for transient errors (`connectionerror`, `uploadfailed`, etc.) |
| `getErrorHistory()` | Returns a copy of the last 100 errors |
| `getLastError()` | Returns the most recent error |
| `getErrorCounts()` | Returns a `Map` of error type → occurrence count |
| `clearHistory()` | Resets the error history |

## Usage Example

```typescript
import { FileErrorHandler } from './file-error-handler';

const handler = new FileErrorHandler((error) => {
  if (error.retryable) {
    console.warn(`Retryable error [${error.type}]: ${error.message}`);
  } else {
    console.error(`Fatal error [${error.type}]: ${error.message}`);
  }
});

// Override the default handler for connection errors
handler.registerHandler('connectionerror', (error) => {
  triggerReconnect();
});

// Parse a raw MeshCentral server message
const error = handler.parseError({ error: 'disk full', details: '/uploads' });
if (error) handler.handleError(error);

// Directly create and dispatch an error
const manualError = handler.createError('upload failed', 'large-file.zip');
handler.handleError(manualError);

// Inspect history
console.log(handler.getErrorCounts());
// Map { 'diskfull' => 1, 'uploadfailed' => 1 }
```

## Notes

- Error history is capped at **100 entries** (FIFO eviction).
- `mapErrorType` performs **case-insensitive substring matching**, so server strings like `"No Space Left"` correctly map to `diskfull`.
