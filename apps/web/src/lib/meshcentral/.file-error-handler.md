Centralized error handling utility for MeshCentral's File Manager feature. It normalizes raw error strings into typed, user-friendly `FileError` objects, tracks error history, and supports pluggable handlers per error type.

## Key Components

- **`FileErrorType`** — Union of known file-related error categories (auth, session, connection, permissions, disk/quota, upload/download, etc.).
- **`FileError`** — Normalized error shape with `type`, user-facing `message`, optional `details`, `timestamp`, and `retryable` flag.
- **`FileErrorHandler`** — Main class that:
  - Registers default console-logging handlers per error type (`setupDefaultHandlers`).
  - Allows custom handler registration via `registerHandler`.
  - Parses raw server/API error payloads into `FileError` via `parseError`/`createError`, mapping free-text strings to `FileErrorType` (`mapErrorType`).
  - Dispatches errors to registered handlers and an optional global `onError` callback (`handleError`).
  - Maintains a bounded error history (`errorHistory`, max 100 entries) with accessors (`getErrorHistory`, `getLastError`, `getErrorCounts`, `clearHistory`).
  - Determines retryability of error types via `isRetryable`.

## Usage Example

```typescript
import { FileErrorHandler, type FileError } from './file-error-handler';

const errorHandler = new FileErrorHandler((error: FileError) => {
  // Global callback, e.g., show a toast notification
  showToast(error.message, error.retryable ? 'warning' : 'error');
});

// Register a custom handler for a specific error type
errorHandler.registerHandler('quotaexceeded', error => {
  openUpgradeModal(error.message);
});

// Parse an error received from a WebSocket message
const parsed = errorHandler.parseError({ error: 'connection lost', details: 'ws closed unexpectedly' });
if (parsed) {
  errorHandler.handleError(parsed);
}

// Or create one directly from a string
const err = errorHandler.createError('file not found', 'path: /docs/report.pdf');
errorHandler.handleError(err);

// Inspect history
console.log(errorHandler.getErrorCounts());
console.log(errorHandler.getLastError());
```
