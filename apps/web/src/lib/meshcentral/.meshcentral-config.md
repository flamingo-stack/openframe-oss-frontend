Provides MeshCentral WebSocket connection configuration, building WebSocket URLs by resolving the host/scheme from runtime environment or browser context and routing through the `/ws/tools/meshcentral-server` proxy path.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MeshUrlParts` | Type | Shape describing a parsed WebSocket URL (`baseHostPort`, `scheme`) |
| `getMeshBaseHostPort()` | Function | Resolves the MeshCentral host+port string from `runtimeEnv.tenantHostUrl()`, stripping any protocol prefix |
| `getMeshWsScheme()` | Function | Returns `'wss'` (always secure); reads `window.location.protocol` when in a browser context |
| `buildWsUrl(path)` | Function | Constructs a full WebSocket URL, falling back through: configured base → browser `window.location.host` → `localhost` |
| `MESH_USER` | Constant | MeshCentral login username, sourced from `NEXT_PUBLIC_MESH_USER` |
| `MESH_PASS` | Constant | MeshCentral login password, sourced from `NEXT_PUBLIC_MESH_PASS` |

## Usage Example

```typescript
import { buildWsUrl, getMeshWsScheme, MESH_USER, MESH_PASS } from './meshcentral-config';

// Build a WebSocket URL for a specific MeshCentral route
const wsUrl = buildWsUrl('/control.ashx');
// → "wss://your-tenant.example.com/ws/tools/meshcentral-server/control.ashx"

// Authenticate against MeshCentral WebSocket
const socket = new WebSocket(wsUrl);
socket.onopen = () => {
  socket.send(JSON.stringify({ action: 'login', user: MESH_USER, pass: MESH_PASS }));
};
```

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `NEXT_PUBLIC_MESH_USER` | `mesh@openframe.io` | MeshCentral username |
| `NEXT_PUBLIC_MESH_PASS` | `meshpass@1234` | MeshCentral password (override in production) |

> **Note:** The default credentials are development placeholders. Always override `NEXT_PUBLIC_MESH_USER` and `NEXT_PUBLIC_MESH_PASS` via environment variables in production deployments.
