Implements chunked file upload functionality for MeshCentral remote file transfer, handling hash-based deduplication/resume, chunked binary transmission over a WebSocket-like message channel, and progress tracking.

## Key Components

- **`UploadTask`** — Interface representing the state of an individual upload (bytes transferred, status, hash, offsets, errors).
- **`FileUploader`** — Core class managing one or more concurrent upload tasks:
  - `uploadFile(file, remotePath, checkHash)` — Initiates an upload; optionally hashes the file first (SHA-384) to allow the server to skip/resume duplicate transfers.
  - `calculateFileHash(file)` — Computes a SHA-384 hash of file contents for deduplication.
  - `handleUploadStart`, `handleUploadAck`, `handleHashResponse`, `handleUploadDone`, `handleUploadError` — Event handlers invoked by the transport layer in response to server messages, driving the upload state machine forward.
  - `cancelUpload`, `clearCompleted`, `clearAll` — Lifecycle/cleanup methods for managing tracked uploads.
  - `getUpload`, `getAllUploads`, `hasActiveUpload`, `getActiveUploadId` — Query helpers for inspecting upload state.
  - `setSendMessage` / `setOnProgress` — Dependency injection for the outbound message transport and progress callback.

Internally, uploads are sent in 64KB chunks (`chunkSize`), with back-pressure handling (retrying chunks if `sendMessage` returns falsy) and a binary framing scheme (`prepareChunkPayload`) that escapes chunks starting with reserved control bytes.

## Usage Example

```typescript
import { FileUploader } from './file-uploader';

const uploader = new FileUploader(
  (data) => socket.send(data), // sendMessage
  (progress) => console.log(`${progress.file}: ${progress.progress}%`), // onProgress
);

const fileInput = document.querySelector('input[type="file"]') as HTMLInputElement;
const file = fileInput.files![0];

const uploadId = await uploader.uploadFile(file, '/remote/path', true);

// When the transport receives server messages, forward them:
uploader.handleUploadStart(uploadId, 0);
uploader.handleUploadAck(uploadId, 65536);
uploader.handleUploadDone(uploadId);

// Check status later
const task = uploader.getUpload(uploadId);
console.log(task?.status);
```
