Manages WebSocket connections with automatic reconnection, token refresh, message queuing, heartbeat monitoring, and browser network/visibility event handling.

## Key Components

### `WebSocketState`
Union type representing connection lifecycle states: `'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`

### `WebSocketManagerOptions`
Configuration interface supporting:
- **Connection**: `url` (static or thunk), `protocols`, `binaryType`
- **Reconnection**: `maxReconnectAttempts`, `reconnectBackoff` (delay ladder), `shouldReconnect`, `onBeforeReconnect`
- **Auth**: `refreshTokenBeforeReconnect` — proactively rotates credentials before each reconnect attempt, guarded by `urlEpoch` to avoid burning valid tokens
- **Reliability**: `enableMessageQueue`, `heartbeatInterval`, `heartbeatMessage`, `heartbeatTimeout`
- **Callbacks**: `onStateChange`, `onMessage`, `onError`, `onOpen`, `onClose`

### `WebSocketManager`
Main class managing the full connection lifecycle:

| Method | Description |
|---|---|
| `connect()` | Opens the WebSocket; guards against duplicate connections |
| `send(data)` | Sends immediately or queues if disconnected; triggers reconnect |
| `reconnect()` | Resets state and forces a fresh connection |
| `disconnect()` | Permanently closes and cleans up |

**Internal behaviors:**
- **Backoff with jitter**: `±25%` jitter applied to each reconnect delay tier
- **Auth failure detection**: Handles close codes `1008`/`4401` and reason-string heuristics
- **Browser events**: Listens to `visibilitychange`, `online`, and `offline` to pause/resume reconnection
- **Heartbeat**: Sends periodic pings and closes stale connections on timeout

## Usage Example

```typescript
const ws = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAccessToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 4000, 8000],
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true,
  heartbeatInterval: 30_000,
  heartbeatTimeout: 10_000,
  onStateChange: (state) => console.log('WS state:', state),
  onMessage: (event) => console.log('Received:', event.data),
});

ws.connect();
ws.send(JSON.stringify({ type: 'subscribe', channel: 'alerts' }));

// Later
ws.disconnect();
```
