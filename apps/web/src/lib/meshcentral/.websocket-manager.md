# websocket-manager.ts

Provides a resilient WebSocket client wrapper (`WebSocketManager`) that handles automatic reconnection with exponential backoff, token refresh coordination, heartbeat keep-alives, message queuing, and browser online/offline/visibility awareness.

## Key Components

- **`WebSocketState`** — union type representing connection lifecycle: `'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`.
- **`WebSocketManagerOptions`** — configuration interface covering URL (static or dynamic), reconnect behavior, callbacks (`onStateChange`, `onMessage`, `onError`, `onOpen`, `onClose`), token refresh hooks, heartbeat settings, and message queue toggling.
- **`WebSocketManager`** — main class exposing:
  - `connect()` — opens the socket, binds event handlers, and guards against duplicate connection attempts.
  - `send(data)` — sends data if the socket is open; otherwise queues it (if enabled) and triggers reconnection.
  - `disconnect()` — tears down the socket and marks the manager as disposed (stops future reconnects).
  - `reconnect()` — resets disposal/attempt state and forces a fresh connection.
  - Internal reconnection logic (`scheduleReconnect`) with exponential backoff, jitter, and proactive token refresh via `refreshAccessToken`/`waitForRefresh` from `token-refresh-manager`.
  - Internal heartbeat mechanism (`startHeartbeat`/`stopHeartbeat`) to detect stale connections and trigger recovery.
  - Browser event listeners (`visibilitychange`, `online`, `offline`) to pause/resume reconnection intelligently based on tab and network state.

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager';

const manager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 8,
  heartbeatInterval: 30_000,
  heartbeatMessage: () => JSON.stringify({ type: 'ping' }),
  refreshTokenBeforeReconnect: true,
  onStateChange: (state) => console.log('WS state:', state),
  onMessage: (event) => console.log('Received:', event.data),
  onOpen: () => console.log('Connected!'),
  onClose: (event) => console.log('Closed:', event.code, event.reason),
  shouldReconnect: (event) => event.code !== 1000, // don't reconnect on normal closure
});

await manager.connect();
manager.send(JSON.stringify({ action: 'subscribe', channel: 'alerts' }));

// Later, to fully tear down:
manager.disconnect();
```

Token epoch tracking ensures reconnection only triggers a credential refresh when the token hasn't already rotated since the socket URL was built, avoiding redundant refresh calls during reconnect storms.
