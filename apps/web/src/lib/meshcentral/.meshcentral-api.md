Thin API wrapper around the MeshCentral REST endpoint that fetches device status, parses online/offline state, and extracts last-seen timestamps for display.

## Key Components

### Interface

| Name | Description |
|---|---|
| `MeshCentralDeviceInfo` | Shape of the `/api/deviceStatus` response — node ID, online flag, last connect time (Unix ms), and last connect address |

### Functions

| Name | Signature | Description |
|---|---|---|
| `getMeshCentralDeviceInfo` | `(nodeId: string) => Promise<MeshCentralDeviceInfo \| null>` | Fetches device status from the MeshCentral API; returns `null` on network errors, 4xx/5xx, or malformed responses |
| `parseMeshCentralDeviceStatus` | `(info: MeshCentralDeviceInfo \| null) => 'online' \| 'offline'` | Derives connection status from a device info object; returns `'offline'` for null/malformed input |
| `parseMeshCentralLastSeen` | `(info: MeshCentralDeviceInfo \| null) => string \| null` | Returns a formatted last-seen string for offline devices; returns `null` when online or data is unavailable |

## Usage Example

```typescript
import {
  getMeshCentralDeviceInfo,
  parseMeshCentralDeviceStatus,
  parseMeshCentralLastSeen,
} from './meshcentral-api';

const nodeId = 'node//abc123';

const info = await getMeshCentralDeviceInfo(nodeId);

const status = parseMeshCentralDeviceStatus(info);
// → 'online' | 'offline'

const lastSeen = parseMeshCentralLastSeen(info);
// → 'Jan 15, 2025 10:32 AM' (offline devices only) | null
```

> **Note:** Treat a `null` return from `getMeshCentralDeviceInfo` as offline with no last-seen data — it covers network failures, gateway errors, and unexpected response shapes.
