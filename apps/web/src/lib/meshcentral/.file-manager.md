## File Manager (`file-manager.ts`)

Implements `MeshCentralFileManager`, the core client-side orchestrator for browsing, uploading, downloading, and managing files on remote devices via MeshCentral's relay tunnel protocol. It manages the tunnel lifecycle, routes JSON/binary protocol messages, and coordinates specialized helper modules (upload, download, binary protocol, error handling) to expose a unified file operations API.

## Key Components

- **`MeshCentralFileManager`** — main class managing connection state, directory browsing, file search, and transfer coordination
  - `connect()` — establishes a remote session and starts the MeshCentral tunnel
  - `loadDirectory(path)` *(referenced)* — requests a directory listing for a given path
  - Private tunnel lifecycle handlers: `ensureRemoteSession`, `startRemoteTunnel`, `handleTunnelStateChange`
  - Message routing: `handleJsonMessage`, `handleBinaryMessage`, `handleCtrlChannelMessage`
  - Path normalization: `normalizeRequestedPath` — converts Unix-style paths (e.g. `/C:/folder`) into Windows drive-letter paths
  - Delegates to collaborator classes: `FileOperations`, `FileUploader`, `FileDownloader`, `FileBinaryProtocol`, `FileErrorHandler`
- **`RECONNECT_TIMEOUT_MS`** — constant controlling reconnect timing for the underlying tunnel
- Relies on types from `file-manager-types` (`FileConnectionState`, `FileEntry`, `DirectoryListing`, `FileOperationRequest/Response`, `RelayControlMessage`, `FileManagerOptions`)
- Integrates with `MeshControlClient` (control/auth session) and `MeshTunnel` (relay transport)

## Usage Example

```typescript
import { MeshCentralFileManager } from './file-manager';
import { MeshControlClient } from './meshcentral-control';

const controlClient = new MeshControlClient(/* ... */);

const fileManager = new MeshCentralFileManager({
  isRemote: true,
  nodeId: 'node//abc123',
  controlClient,
  onStateChange: (state) => console.log('File manager state:', state),
  onError: (err) => console.error('File manager error:', err),
  onTransferProgress: (progress) => console.log('Transfer progress:', progress),
});

await fileManager.connect();
```

Errors during connection (e.g., missing `nodeId` or `controlClient`) throw descriptive errors; transfer and state events are surfaced via the `FileManagerOptions` callbacks.
