Orchestrates the MeshCentral file manager by coordinating tunnel connections, file operations, uploads, downloads, and search functionality for remote node file system access.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MeshCentralFileManager` | Class | Main file manager coordinating all file system operations over a MeshCentral tunnel |

### Constructor Options (`FileManagerOptions`)
- `isRemote` — enables remote node file access via tunnel
- `nodeId` — target MeshCentral node identifier
- `authCookie` / `relayCookie` — authentication tokens
- `controlClient` — `MeshControlClient` instance for session management
- `onStateChange`, `onError`, `onTransferProgress`, `onServerCancelDownload` — event callbacks

### Internal Collaborators
| Class | Role |
|-------|------|
| `MeshTunnel` | WebSocket tunnel to the remote node |
| `FileOperations` | Low-level file operation primitives |
| `FileUploader` | Chunked upload state machine |
| `FileDownloader` | Chunked download state machine |
| `FileBinaryProtocol` | Encodes/decodes binary wire protocol |
| `FileErrorHandler` | Normalizes and surfaces errors |

### Connection States (`FileConnectionState`)
`disconnected` → `connecting` → `connected_to_server` → `connected_end_to_end`

### Message Routing
`handleJsonMessage` dispatches incoming JSON frames by `action` field (`ls`, `findfile`, `download`, `uploadstart`, `uploadack`, `uploadhash`, `uploaddone`, `uploaderror`, `dialogmessage`, `error`). Binary frames are forwarded to `FileDownloader`.

## Usage Example

```typescript
import { MeshCentralFileManager } from './file-manager';
import { MeshControlClient } from './meshcentral-control';

const controlClient = new MeshControlClient({ /* ... */ });

const manager = new MeshCentralFileManager({
  isRemote: true,
  nodeId: 'node123abc',
  controlClient,
  onStateChange: state => console.log('State:', state),
  onTransferProgress: (progress) => console.log(`${progress.percent}%`),
  onError: err => console.error('File manager error:', err),
});

// Connect — opens control session, negotiates tunnel, then loads root directory
await manager.connect();
```

> **Note:** `connect()` only supports remote mode (`isRemote: true`). Local/server-side file access is not implemented and will throw. Path normalization handles both Unix-style (`/C:/Users`) and Windows-style (`C:\Users`) inputs automatically.
