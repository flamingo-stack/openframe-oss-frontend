# meshcentral-keys.ts

Keyboard mapping and wire-protocol encoding utilities for the MeshCentral KVM desktop protocol. Translates browser `KeyboardEvent` objects into Windows virtual-key (VK) codes and encodes them into the binary packets expected by the MeshCentral agent, including support for extended keys, Unicode text input, and keyboard shortcut combos (e.g., Ctrl+Alt+Del).

## Key Components

- **`IS_MAC_BROWSER`** — Boolean flag detecting macOS based on `navigator.platform`/`userAgent`.
- **`keyboardEventToVk(e: KeyboardEvent): number | null`** — Converts a `KeyboardEvent` into its Windows VK code, using layout-aware character mapping for letters/digits, `code`-based mapping for function/numpad/special keys, and a legacy `keyCode` fallback.
- **`isExtendedKey(e: KeyboardEvent): boolean`** — Determines whether a key requires the extended-key flag (arrow keys, numpad Enter/Divide, Home/End/Insert/Delete, right-side modifiers, etc.).
- **`isAltGraphPressed(e: KeyboardEvent): boolean`** — Checks the `AltGraph` modifier state.
- **`encodeKeyEvent(action, vk, extended): Uint8Array`** — Builds a 6-byte `MNG_KVM_KEY` (cmd 1) packet for key down/up events, handling the extended-key wire encoding (0/1/3/4).
- **`encodeUnicodeKey(action, codepoint): Uint8Array`** — Builds a 7-byte `MNG_KVM_KEY_UNICODE` (cmd 85) packet for Unicode character input.
- **`isSecureAttentionCombo(combo: string): boolean`** — Detects whether a combo string represents Ctrl+Alt+Del (order-independent), which must be sent as a secure-attention command rather than individual key presses.
- **`comboToSequence(combo: string): ComboKeyEvent[] | null`** — Parses a combo string (e.g., `"ctrl+shift+esc"`) into an ordered sequence of key-down then reverse-order key-up `ComboKeyEvent` entries.
- **`ComboKeyEvent`** — Interface describing a single synthesized key action (`action`, `vk`, `extended`).

## Usage Example

```typescript
import {
  keyboardEventToVk,
  isExtendedKey,
  encodeKeyEvent,
  isSecureAttentionCombo,
  comboToSequence,
} from './meshcentral-keys';

function handleKeyDown(e: KeyboardEvent, send: (data: Uint8Array) => void) {
  const vk = keyboardEventToVk(e);
  if (vk == null) return;
  send(encodeKeyEvent(1, vk, isExtendedKey(e)));
}

// Sending a custom shortcut combo
const combo = 'ctrl+shift+esc';
if (isSecureAttentionCombo(combo)) {
  // trigger MNG_CTRLALTDEL instead
} else {
  const sequence = comboToSequence(combo);
  sequence?.forEach(({ action, vk, extended }) => {
    send(encodeKeyEvent(action, vk, extended));
  });
}
```
