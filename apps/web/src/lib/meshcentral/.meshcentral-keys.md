Keyboard mapping and wire-encoding utilities for the MeshCentral KVM desktop protocol, translating browser `KeyboardEvent` objects into the binary frames expected by MeshCentral agents.

## Key Components

### Constants & Lookups

- **`IS_MAC_BROWSER`** — Runtime flag indicating a macOS browser, used by callers to remap modifier keys (e.g. `Meta` → `Ctrl`)
- **`CODE_TO_VK`** — Maps `KeyboardEvent.code` values (physical keys) to Windows Virtual Key codes
- **`KEY_TO_VK`** — Maps `KeyboardEvent.key` values (logical keys) to VK codes as a fallback
- **`EXTENDED_CODES`** — Set of `code` values that require the Windows `KEYEVENTF_EXTENDEDKEY` flag

### Functions

| Function | Description |
|---|---|
| `keyboardEventToVk(e)` | Resolves a `KeyboardEvent` to its VK code; returns `null` if unmappable |
| `isExtendedKey(e)` | Returns `true` if the key requires the extended-key wire flag |
| `isAltGraphPressed(e)` | Returns `true` if AltGr is active (used to suppress duplicate key injection) |
| `encodeKeyEvent(action, vk, extended)` | Builds a 6-byte `MNG_KVM_KEY` (cmd `0x01`) frame |
| `encodeUnicodeKey(action, codepoint)` | Builds a 7-byte `MNG_KVM_KEY_UNICODE` (cmd `0x55`) frame for arbitrary Unicode input |
| `comboToSequence(combo)` | Converts a combo string (e.g. `"ctrl+shift+esc"`) into an ordered press/release `ComboKeyEvent[]` |

## Usage Example

```typescript
import {
  keyboardEventToVk,
  isExtendedKey,
  encodeKeyEvent,
  encodeUnicodeKey,
  comboToSequence,
} from './meshcentral-keys';

// Encode a real browser key event
document.addEventListener('keydown', (e) => {
  const vk = keyboardEventToVk(e);
  if (vk === null) return;
  const frame = encodeKeyEvent(1, vk, isExtendedKey(e)); // action 1 = down
  socket.send(frame);
});

// Send a Unicode character (e.g. emoji or IME output)
const down = encodeUnicodeKey(1, '😀'.codePointAt(0)!);
const up   = encodeUnicodeKey(2, '😀'.codePointAt(0)!);

// Expand a hotkey combo into a press/release sequence
const events = comboToSequence('ctrl+shift+esc');
events?.forEach(({ action, vk, extended }) => {
  socket.send(encodeKeyEvent(action, vk, extended));
});
```
