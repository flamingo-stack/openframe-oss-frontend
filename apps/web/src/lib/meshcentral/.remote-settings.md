Defines types, constants, and a class for managing MeshCentral remote desktop session settings, including quality, scaling, frame rate, and input options.

## Key Components

- **`RemoteSettingsConfig`** — Interface describing all configurable session parameters (quality, scaling, frame rate, mouse/keyboard options)
- **`QUALITY_OPTIONS`** — JPEG quality presets mapping human-readable labels to values (10–100)
- **`SCALING_OPTIONS`** — Display scaling presets using MeshCentral's internal encoding (256–2048)
- **`FRAME_RATE_OPTIONS`** — Frame rate presets mapping named values to millisecond intervals (33ms–500ms)
- **`DEFAULT_SETTINGS`** — Baseline config: 50% quality, 100% scaling, 10 FPS, no input remapping
- **`RemoteDesktopSettings`** — Class managing live session settings with WebSocket delivery

### `RemoteDesktopSettings` Methods

| Method | Description |
|--------|-------------|
| `setWebSocket(ws)` | Attaches a MeshCentral WebSocket instance |
| `applySettings(settings?)` | Serializes settings into a 10-byte binary command (`0x0005`) and sends via WebSocket |
| `getSettings()` | Returns a copy of the current settings |
| `getFrameRateMs(frameRate)` | Static helper — resolves a frame rate label to its millisecond value |
| `estimateBandwidth()` | Returns an approximate KB/s estimate based on quality, scaling, and FPS |

## Usage Example

```typescript
import { RemoteDesktopSettings, DEFAULT_SETTINGS } from './remote-settings';

const rdSettings = new RemoteDesktopSettings({
  ...DEFAULT_SETTINGS,
  quality: 60,
  frameRate: 'fast',
  scaling: 1024,
});

// Attach WebSocket once connection is established
rdSettings.setWebSocket(meshSocket);

// Push settings to the remote session
rdSettings.applySettings();

// Estimate current bandwidth usage
const kbps = rdSettings.estimateBandwidth();
console.log(`Estimated bandwidth: ${kbps} KB/s`);

// Resolve frame rate to milliseconds
const ms = RemoteDesktopSettings.getFrameRateMs('smooth'); // 33
```

> **Binary protocol note:** `applySettings` builds a big-endian 10-byte buffer — bytes 0–1 are command `0x0005`, bytes 2–3 encode total size (`0x000A`), and bytes 4–9 carry JPEG encoding type, quality, scaling factor, and frame timer. See [`remote-settings.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/remote-settings.ts) for full implementation.
