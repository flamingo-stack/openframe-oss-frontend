# remote-settings.ts

Manages MeshCentral remote desktop display settings (quality, scaling, frame rate, and input options), and encodes them into the binary protocol MeshCentral expects to apply them over an active WebSocket connection.

## Key Components

- **`RemoteSettingsConfig`** — Interface defining user-configurable remote desktop options: `quality`, `scaling`, `frameRate`, `swapMouseButtons`, `useRemoteKeyboardMap`, `invertScrollDirection`.
- **`QUALITY_OPTIONS`** — Preset JPEG quality levels (10–100%) with human-readable labels.
- **`SCALING_OPTIONS`** — Preset scaling factors mapped to MeshCentral's internal values (256–2048).
- **`FRAME_RATE_OPTIONS`** — Named frame rate presets (`smooth` to `very slow`) each mapped to a millisecond delay between frames.
- **`DEFAULT_SETTINGS`** — Default `RemoteSettingsConfig` (50% quality, 100% scaling, medium frame rate).
- **`SettingsTransport`** — Minimal structural interface requiring only `sendBinary()`, decoupling this module from the full `MeshTunnel` implementation.
- **`RemoteDesktopSettings`** — Class that holds current settings, serializes them into a 10-byte big-endian binary message (MeshCentral's `COMPRESSION` command `0x05`), and sends it over a `SettingsTransport`. Also provides bandwidth estimation.

## Usage Example

```typescript
import { RemoteDesktopSettings, DEFAULT_SETTINGS } from './remote-settings';

const settings = new RemoteDesktopSettings(DEFAULT_SETTINGS);

// Attach a transport capable of sending binary data (e.g., a MeshTunnel instance)
settings.setWebSocket(meshTunnel);

// Apply updated settings
settings.applySettings({
  ...settings.getSettings(),
  quality: 80,
  scaling: 1024,
  frameRate: 'fast',
});

// Estimate resulting bandwidth usage (KB/s)
const estimatedKbps = settings.estimateBandwidth();
```

Use `RemoteDesktopSettings.getFrameRateMs('smooth')` to look up the millisecond delay for a given frame rate preset without instantiating the class.
