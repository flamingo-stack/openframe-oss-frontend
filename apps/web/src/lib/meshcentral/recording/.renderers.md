# renderers.ts

Provides `RecordingRenderer` implementations that replay recorded session data (desktop/KVM or terminal) onto a visual surface (canvas or xterm instance), powering session playback for both remote-desktop and terminal recordings.

## Key Components

- **`DesktopRecordingRenderer`** — Replays protocol-2 (desktop/KVM) recordings onto an `HTMLCanvasElement` using the same `MeshDesktop` decoder as the live viewer. Attached in render-only mode (no input listeners, `send()` is a no-op).
  - `reset()` — Detaches and replaces the internal `MeshDesktop` instance, bumping a generation counter to invalidate any in-flight paint.
  - `paint(frame)` — Decodes all tiles of a seek frame concurrently (`createImageBitmap`), then clears and draws the canvas atomically once decoding completes, so stale frames aren't shown mid-decode.
  - `feed(data)` — Forwards binary protocol frames to the decoder.
  - `waitForIdle()` — Resolves once the decoder has processed all queued data.
  - `dispose()` — Detaches and releases the decoder.

- **`TerminalRecordingRenderer`** — Replays protocol-1 (terminal) recordings into a caller-owned `Terminal` (xterm), writing raw bytes directly.
  - `reset()` — Clears the terminal buffer.
  - `feed(data)` — Writes raw bytes to the terminal.
  - `waitForIdle()` — Resolves once xterm has flushed all buffered writes.
  - `dispose()` — No-op; terminal lifecycle is managed externally.

- **`decodeTiles(tiles)`** (internal) — Decodes JPEG tile buffers into `ImageBitmap`s with bounded concurrency (`PAINT_DECODE_CONCURRENCY = 8`), returning `null` for any tile that fails to decode.

## Usage Example

```typescript
import { DesktopRecordingRenderer, TerminalRecordingRenderer } from './renderers';

// Desktop/KVM playback
const canvas = document.querySelector('canvas')!;
const desktopRenderer = new DesktopRecordingRenderer(canvas);
desktopRenderer.reset();
await desktopRenderer.paint(seekFrame);
desktopRenderer.feed(binaryChunk);
await desktopRenderer.waitForIdle();
desktopRenderer.dispose();

// Terminal playback
const terminal = new Terminal({ disableStdin: true });
terminal.open(containerEl);
const termRenderer = new TerminalRecordingRenderer(terminal);
termRenderer.feed(new TextEncoder().encode('hello\r\n'));
await termRenderer.waitForIdle();
```
