Progressively loads a multi-file MCREC recording session, feeding a sink with the stitched result after each successfully loaded file so playback can begin before all files finish downloading.

## Key Components

- **`SegmentSink`** — Interface implemented by the consumer (typically wired to a player) with three methods:
  - `start(recording, complete)` — called once with the first successfully loaded file.
  - `extend(recording, complete)` — called for each subsequent file with the cumulative stitched recording.
  - `isCurrent()` — lets the loop detect that it has been superseded (e.g., a newer load started or the component unmounted) and stop early.
- **`loadSessionSegments(sources, sink)`** — Async function that iterates an ordered list of source-fetching functions (oldest first), parsing and stitching each one incrementally via `parseMcrec` and `stitchRecordings`. Returns `{ failed: number }` counting skipped files. Throws only if every source fails to load.

## Usage Example

```typescript
import { loadSessionSegments, type SegmentSink } from './mcrec-segment-loader';

const sink: SegmentSink = {
  async start(recording, complete) {
    player.load(recording);
    if (complete) player.markSessionComplete();
  },
  extend(recording, complete) {
    player.update(recording);
    if (complete) player.markSessionComplete();
  },
  isCurrent() {
    return player.activeLoadId === loadId;
  },
};

const sources = fileUrls.map((url) => async () => {
  const response = await fetch(url);
  return response.arrayBuffer();
});

const { failed } = await loadSessionSegments(sources, sink);
if (failed > 0) {
  console.warn(`${failed} segment(s) failed to load`);
}
```

**Notes:**
- Sources are fetched sequentially, not in parallel, to preserve chronological stitching order.
- If `sink.isCurrent()` returns `false` at any point, the loop exits early without further processing.
- If the last file fails but earlier files succeeded, the session is re-stitched and sent via `extend` with `complete: true` to ensure the sink still receives a finalized session.
