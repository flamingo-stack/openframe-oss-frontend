## mcrec-seek.ts

Reconstructs the desktop screen state at a given seek target in an MCRec recording by replaying only the binary protocol commands (screen size and tile draws) between a restart point and the target record, without decoding any JPEG pixel data. This enables fast, low-cost seeking in recorded remote-desktop sessions by determining which tiles remain visible rather than re-rendering the full frame history.

## Key Components

- **`readJpegSize(bytes)`** — Parses a JPEG byte buffer's frame header to extract `width`/`height` without full decoding; returns `null` if the bytes aren't a readable JPEG.
- **`seekFrame(recording, from, to)`** — Main entry point. Given a `ParsedRecording`, a restart point `from`, and a target record `to`, returns a `SeekFrame` (screen dimensions plus the list of still-visible tiles) or `null` if a full replay is required (e.g., the target falls mid-command).
- **`fileIndex` / `indexFile`** — Internal helpers that parse the raw agent record stream into a sequence of `Command` objects (`tile` draws and `size` changes), mirroring the parsing logic of `MeshDesktop.onBinaryFrame`. Results are cached per recording via a `WeakMap`.
- **Coverage grid algorithm** — Uses a 16px-cell grid (`CELL`) to track which screen regions are fully covered by later tiles, walking commands backward from `to` and stopping early once the whole screen is accounted for (`uncovered === 0`).
- **`TileCommand`, `ScreenSizeCommand`, `Command`, `FileIndex`** — Internal types describing the indexed command stream.

## Usage Example

```typescript
import { seekFrame, readJpegSize } from './mcrec-seek';
import type { ParsedRecording } from './mcrec-types';

function renderSeekTarget(recording: ParsedRecording, restartRecord: number, targetRecord: number) {
  const frame = seekFrame(recording, restartRecord, targetRecord);

  if (!frame) {
    // Fall back to a full replay from the restart point to targetRecord.
    return replayFromScratch(recording, restartRecord, targetRecord);
  }

  // frame.width / frame.height describe the current screen size.
  // frame.tiles is the minimal set of tiles needed to reconstruct the visible screen.
  for (const tile of frame.tiles) {
    drawJpegTile(tile.x, tile.y, tile.jpeg);
  }
}

// Inspect an individual JPEG tile's dimensions without decoding it.
const size = readJpegSize(someTileBytes);
if (size) {
  console.log(`Tile is ${size.width}x${size.height}`);
}
```

Results of `seekFrame` are cached internally per `recording.agentRecords` and restart point, so repeated seeks within the same recording segment are inexpensive after the first call.
