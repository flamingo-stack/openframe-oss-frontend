Barrel module that re-exports the public API of the `mcrec` recording toolkit, consolidating parsing, playback, segment loading, stitching, type definitions, and renderer utilities into a single entry point.

## Key Components

- **`parseMcrec` / `McrecParseError`** — Parses `.mcrec` binary recording files and surfaces parsing failures.
- **`McrecPlayer` / `McrecPlayerCallbacks`** — Playback controller for driving recording render output via callbacks.
- **`loadSessionSegments` / `SegmentSink`** — Loads recording segments for a session into a provided sink.
- **`stitchRecordings` / `StitchOptions` / `DEFAULT_MAX_SEGMENT_GAP_MS`** — Combines multiple recording segments into a continuous timeline, respecting a maximum allowed gap.
- **Type definitions** — `McrecMetadata`, `McrecRecord`, `ParsedRecording`, `RecordingPlaybackSpeed`, `RecordingPlayerState`, `RecordingRenderer`, `RecordingSpan`, plus flag/type constants `MCREC_FLAG_BINARY`, `MCREC_FLAG_FROM_BROWSER`, `MCREC_RECORD_TYPE`.
- **`DesktopRecordingRenderer` / `TerminalRecordingRenderer`** — Renderer implementations for desktop and terminal session recordings.
- **`toPlaybackMs` / `RecordingTimeline`** — Utilities for converting timeline positions into playback milliseconds.

## Usage Example

```typescript
import {
  parseMcrec,
  McrecPlayer,
  loadSessionSegments,
  stitchRecordings,
  DesktopRecordingRenderer,
} from './index';

const parsed = parseMcrec(fileBuffer);

const player = new McrecPlayer({
  onFrame: (frame) => renderer.render(frame),
  onStateChange: (state) => updateUi(state),
});

const segments = await loadSessionSegments(sessionId);
const stitched = stitchRecordings(segments, { maxSegmentGapMs: 1000 });

const renderer = new DesktopRecordingRenderer(canvasElement);
player.load(stitched);
player.play();
```

This module is intended as the single import path for consumers needing any part of the mcrec recording/playback pipeline, avoiding direct imports from internal implementation files.
