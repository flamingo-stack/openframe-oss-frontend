# mcrec-stitch.ts

Stitches multiple `.mcrec` recording segments from a single MeshCentral remote-control session into one continuous playback timeline. MeshCentral creates a new recording file each time the remote tunnel reconnects, so this module merges those files, trims excessive reconnect gaps, and tracks where each original segment lands in the combined timeline.

## Key Components

- **`DEFAULT_MAX_SEGMENT_GAP_MS`** — Default cap (3000 ms) applied to reconnect gaps between segments; longer gaps are shortened to this value.
- **`StitchOptions`** — Configuration interface with optional `maxGapMs` to override the default gap cap.
- **`stitchRecordings(segments, options?)`** — Main function that merges an array of `ParsedRecording` segments into a single `ParsedRecording`, producing:
  - `records` / `agentRecords` — concatenated, time-rebased record streams.
  - `restartIndices` — indices into `agentRecords` marking the start of each segment (safe seek points, since every file opens with a full screen redraw).
  - `spans` — per-segment metadata (`startMs`, `endMs`, `shiftMs`) mapping original server time to the stitched timeline.
  - `baseTimeMs` / `durationMs` — overall timeline bounds.

Throws `McrecParseError` if no segments are provided or if segments have mismatched protocols.

## Usage Example

```typescript
import { stitchRecordings } from './mcrec-stitch';
import { parseMcrecFile } from './mcrec-parser';

const segment1 = await parseMcrecFile('session-part1.mcrec');
const segment2 = await parseMcrecFile('session-part2.mcrec');

const combined = stitchRecordings([segment1, segment2], {
  maxGapMs: 5000, // allow up to 5s reconnect gaps before trimming
});

console.log(`Combined duration: ${combined.durationMs}ms`);
console.log(`Seekable restart points: ${combined.restartIndices.length}`);

// Map a point in the stitched timeline back to original server time using spans
for (const span of combined.spans ?? []) {
  console.log(`Segment shifted by ${span.shiftMs}ms, covers ${span.startMs}-${span.endMs}`);
}
```

Segments without any agent records (pairings that never relayed a frame) are excluded from playback unless they are the only segment available.
