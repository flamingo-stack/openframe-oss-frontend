# mcrec-parser.ts

Parses MeshCentral `.mcrec` binary recording files into a structured record stream, extracting session metadata and agent-originated KVM frames for playback.

## Key Components

- **`McrecParseError`** — Custom error class thrown for malformed or unrecognized `.mcrec` files.
- **`readInt48(view, offset)`** — Internal helper that reads a 48-bit big-endian millisecond timestamp from a `DataView` (safe within JS number precision for thousands of years).
- **`parseMcrec(buffer)`** — Main export. Parses an `ArrayBuffer` into a `ParsedRecording`, containing:
  - `metadata` — Parsed `MeshCentralRelaySession` JSON header.
  - `records` — All decoded records (header + payload) found in the file.
  - `agentRecords` — Filtered, time-sorted subset of records representing actual KVM/network frames sent from the agent (excludes browser-originated and control/JSON records on desktop protocol).
  - `baseTimeMs` / `durationMs` — Playback timing bounds derived from the agent record stream.
  - `protocol` — Detected relay protocol version (`1` or `2`).

## Behavior Notes

- **Strict head, tolerant tail**: The first record must be a valid `METADATA` record with magic `"MeshCentralRelaySession"`, or parsing throws `McrecParseError`. Truncated trailing records (e.g., from a crashed relay) are silently dropped rather than causing failure.
- **Record filtering**: Only non-browser (`MCREC_FLAG_FROM_BROWSER` unset), non-empty records qualify as `agentRecords`. On protocol 1 (desktop), only binary-flagged records are kept, since text records carry control JSON that would corrupt frame decoding.
- **Stable sort by timestamp**: Ensures monotonic playback ordering even if records appear out of order in a damaged file, preserving file order for equal timestamps (required for correct KVM tile decoding).

## Usage Example

```typescript
import { parseMcrec, McrecParseError } from './mcrec-parser';

async function loadRecording(file: File) {
  const buffer = await file.arrayBuffer();

  try {
    const recording = parseMcrec(buffer);
    console.log('Protocol:', recording.protocol);
    console.log('Duration (ms):', recording.durationMs);
    console.log('Agent frames:', recording.agentRecords.length);
    return recording;
  } catch (err) {
    if (err instanceof McrecParseError) {
      console.error('Invalid recording file:', err.message);
    }
    throw err;
  }
}
```
