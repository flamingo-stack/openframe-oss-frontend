Maps wall-clock timestamps to player positions on a stitched multi-file recording timeline, accounting for reconnect gaps between recorded file segments.

## Key Components

- **`RecordingTimeline`** - Type alias picking `baseTimeMs`, `durationMs`, and `spans` from `ParsedRecording`; the minimal shape needed to resolve wall-clock time to playback position.
- **`toPlaybackMs(timeline, wallMs)`** - Converts a wall-clock time (ms since epoch) into a playback position (ms) on the stitched timeline. Handles three cases:
  - Time falls inside a recorded span → maps directly using that span's `shiftMs` offset.
  - Time falls inside a reconnect gap → plays through the retained portion of the gap, then snaps to the next span's start once the cut portion is reached.
  - Time is before the first span or after the last → clamps to the timeline bounds (`0` to `durationMs`).
- **`lastFrameAtMs(timeline)`** - Returns the wall-clock time of the last available frame. Useful for checking whether a target time is already loaded, since spans may still be streaming in.

## Usage Example

```typescript
import { toPlaybackMs, lastFrameAtMs, type RecordingTimeline } from './mcrec-timeline';

const timeline: RecordingTimeline = {
  baseTimeMs: 1_700_000_000_000,
  durationMs: 60_000,
  spans: [
    { startMs: 1_700_000_000_000, endMs: 1_700_000_020_000, shiftMs: 0 },
    { startMs: 1_700_000_025_000, endMs: 1_700_000_060_000, shiftMs: 5_000 },
  ],
};

// Get playback position for a wall-clock timestamp
const playbackMs = toPlaybackMs(timeline, 1_700_000_022_000);

// Check if a target time is already loaded before seeking
const lastLoaded = lastFrameAtMs(timeline);
if (1_700_000_050_000 <= lastLoaded) {
  const seekTo = toPlaybackMs(timeline, 1_700_000_050_000);
}
```

This is typically used by a recording player's seek/scrub logic to translate a user-selected or event-driven wall-clock time into the correct position on the assembled video timeline, correctly skipping over trimmed reconnect gaps.
