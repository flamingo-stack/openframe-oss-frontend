## mcrec-types.ts

Type definitions for MeshCentral's `.mcrec` session-recording binary format, covering both terminal and desktop/KVM recordings. Defines the record header structure, parsed-recording model, and the renderer contract used to replay recordings in the UI.

## Key Components

- **`MCREC_RECORD_TYPE`** - Enum-like constant for record types: `METADATA`, `NETWORK_DATA`, `END`, `INDEX`.
- **`MCREC_FLAG_BINARY` / `MCREC_FLAG_FROM_BROWSER`** - Bitflags found in a record's header.
- **`McrecRecord`** - A single parsed record (type, flags, timestamp, payload view).
- **`McrecMetadata`** - Shape of the first record's JSON payload (protocol, version, etc.).
- **`ParsedRecording`** - Full parsed file/session: metadata, all records, agent-only records, timeline base/duration, protocol, and optional `restartIndices`/`spans` for stitched multi-file sessions.
- **`RecordingSpan`** - Describes one file's time range and shift within a stitched session.
- **`SeekTile` / `SeekFrame`** - Desktop-protocol seek target representation (JPEG tiles positioned on a screen).
- **`RecordingPlayerState`** - Player state machine: `empty | ready | playing | paused | seeking | waiting | ended`.
- **`RecordingPlaybackSpeed`** - Allowed playback speeds: `0.5 | 1 | 2 | 4`.
- **`RecordingRenderer`** - Interface a terminal or desktop renderer must implement to consume parsed records (`reset`, `feed`, `waitForIdle`, optional `paint`, `dispose`).

## Usage Example

```typescript
import {
  MCREC_RECORD_TYPE,
  MCREC_FLAG_BINARY,
  type ParsedRecording,
  type RecordingRenderer,
} from './mcrec-types';

function replay(recording: ParsedRecording, renderer: RecordingRenderer) {
  renderer.reset();

  for (const record of recording.agentRecords) {
    if (record.type === MCREC_RECORD_TYPE.NETWORK_DATA) {
      const isBinary = (record.flags & MCREC_FLAG_BINARY) !== 0;
      renderer.feed(record.data);
    }
  }

  return renderer.waitForIdle();
}
```

This module contains no runtime logic beyond the two numeric constants - it is the shared contract consumed by the `.mcrec` parser, the stitcher (for multi-file sessions), and terminal/desktop renderer implementations.
