Implements client-side file downloads over a MeshCentral remote-connection channel, managing the negotiation handshake, binary chunk reassembly, progress reporting, and browser-triggered file saving.

## Key Components

- **`DownloadControlMessage`** — Shape of control-channel JSON messages (`start`, `cancel`, `error` sub-types) exchanged with the MeshCentral server.
- **`DownloadTask`** — Internal state tracked per download: remote path, buffered chunks, size counters, and lifecycle `status`.
- **`FileDownloader`** — Core class that:
  - `downloadFile(remotePath, fileName?, fileSize?)` — starts a new download, sends the `start` request, and returns a generated `downloadId`.
  - `handleControlMessage(message)` — dispatches server control messages (`start`/`cancel`/`error`) to the right handler.
  - `handleBinaryChunk(data, _isFinal)` — parses the 4-byte big-endian header of each binary frame, extracts file data, tracks progress, sends ACKs, and finalizes on the last chunk.
  - `getFileBlob(downloadId)` / `saveFile(downloadId)` — assembles received chunks into a `Blob` and triggers a browser download via a temporary anchor element.
  - `cancelDownload(downloadId)` / `handleDownloadError(downloadId, error)` — cancels or fails an in-progress download and notifies the server.
  - `hasActiveDownload()` / `getActiveDownloadId()` / `resetActiveDownload()` — manage the single "active" download slot (only one download is processed for binary chunks at a time).
  - `clearAll()` — resets all download state.

## Usage Example

```typescript
import { FileDownloader } from './file-downloader';

const downloader = new FileDownloader(
  (data) => websocket.send(data), // sendMessage
  (progress) => console.log(`${progress.file}: ${progress.progress}%`), // onProgress
  (fileName, reason) => console.warn(`Server cancelled ${fileName}: ${reason}`),
);

// Start a download
const downloadId = downloader.downloadFile('/remote/path/report.pdf');

// On incoming WebSocket messages:
websocket.onmessage = (event) => {
  if (typeof event.data === 'string') {
    downloader.handleControlMessage(JSON.parse(event.data));
  } else {
    downloader.handleBinaryChunk(new Uint8Array(event.data), false);
  }
};

// Cancel if needed
downloader.cancelDownload(downloadId);
```
