Handles binary framing for the MeshCentral File Manager WebSocket protocol, accumulating raw bytes and emitting parsed payload chunks as complete frames arrive.

## Key Components

### `FileBinaryProtocol` (class)

- **`push(data, onChunk)`** — Appends incoming `ArrayBuffer` data to an internal accumulator, then drains complete frames by invoking `onChunk(payload, isFinal)` for each one.
- **`consume(onChunk)`** *(private)* — Loop that reads frames from the buffer as long as enough bytes are available to satisfy the declared frame length.
- **`readHeader(headerBytes)`** *(private)* — Decodes a 4-byte little-endian header: bits 31–1 encode the payload length; bit 0 signals whether this is the final chunk.
- **`reset()`** — Clears the internal accumulator, useful when a file transfer session ends or errors.
- **`isBinaryData(data)`** — Type guard that returns `true` for `ArrayBuffer` or `Uint8Array` values.

## Usage Example

```typescript
import { FileBinaryProtocol } from './file-binary-protocol';

const protocol = new FileBinaryProtocol();

websocket.onmessage = (event) => {
  if (protocol.isBinaryData(event.data)) {
    protocol.push(event.data as ArrayBuffer, (payload, isFinal) => {
      processChunk(payload);
      if (isFinal) {
        finalizeFileTransfer();
        protocol.reset();
      }
    });
  }
};
```

## Frame Format

```text
[ 4-byte header (LE uint32) ][ payload bytes ]
  bits 31–1 = payload length
  bit 0     = isFinal flag
```
