## meshcentral-desktop.ts

Implements the remote desktop session client for MeshCentral, handling bidirectional keyboard/mouse input encoding, remote screen tile decoding/rendering, multi-display support, and clipboard interception for a canvas-based remote control UI.

## Key Components

- **`DisplayInfo`** — Interface describing a remote display (id, position, size, primary flag).
- **`DesktopInputHandlers`** — Contract for attaching/detaching input, toggling view-only mode, sending key combos, managing display switching, and clipboard interception.
- **`MeshDesktop`** — Core class implementing `DesktopInputHandlers`:
  - `attach(canvas)` / `attachRenderOnly(canvas)` — Binds (or render-only attaches) a `HTMLCanvasElement` as the remote desktop surface.
  - `detach()` / `setViewOnly()` — Teardown and input-mode toggling.
  - `bindPointerInput()` (private) — Wires mouse move/down/up/wheel/dblclick handlers, translating local cursor coordinates to remote virtual-desktop coordinates.
  - Keyboard handling — Maps `KeyboardEvent`s to virtual key codes (`keyboardEventToVk`), handles dead keys, CapsLock, and a buffered Meta/Cmd key strategy (via `bufferedMetaKey`/`metaBufferTimer`) to avoid accidental Start-menu triggers.
  - `syncModifiersFromEvent()` (private) — Reconciles stuck modifier keys (Shift/Ctrl/Alt/Meta) against live event flags, releasing Meta safely using a Ctrl+Win chord trick.
  - `waitForIdle(timeoutMs)` — Resolves when the tile decode/draw pipeline is fully drained; used for recording playback seeks.
  - `setClipboardInterceptor()` — Hooks copy/cut/paste key combos to a custom handler instead of forwarding raw keys.
  - Tile queue/draw queue fields manage async image decoding (`ImageBitmap`) with a concurrency cap (`maxConcurrentDecodes`).
- **`WATCH_COMMANDS`** — Set of command codes permitted when in watch-only (read-only observer) mode.
- **`ALL_DISPLAYS`** — Sentinel value (`0xffff`) representing the agent's combined multi-display view.
- **`isTypingTarget()`** — Helper to skip keyboard forwarding when focus is on a text input/textarea/contenteditable element.

## Usage Example

```typescript
import { MeshDesktop } from './meshcentral-desktop';

const desktop = new MeshDesktop();
const canvas = document.querySelector('canvas')!;

desktop.attach(canvas);
desktop.setViewOnly(false);

desktop.onFirstFrame?.(() => console.log('First frame rendered'));
desktop.onDisplayListChange?.((displays, current) => {
  console.log('Available displays:', displays, 'current:', current);
});

desktop.setClipboardInterceptor((type, sendKeys) => {
  if (type === 'paste') sendKeys();
});

// Later, when the session ends:
desktop.detach();
```
