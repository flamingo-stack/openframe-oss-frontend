Client boundary wrapper that re-exports all UI components from the `@flamingo-stack/openframe-frontend-core/components/ui` barrel, preventing Server Components from directly importing hook-dependent UI components.

## Key Components

- **Re-exports**: All UI components from `@flamingo-stack/openframe-frontend-core/components/ui`
- **`'use client'` directive**: Marks this module as a client boundary, ensuring hook-based components are only rendered on the client

## Usage Example

```typescript
// Import UI components through this wrapper instead of the core barrel directly
import { Button, Input, Dialog } from '@/components/openframe-core-ui';
```

## Notes

- Use this module as the import path for any core UI components in Server Components or mixed RSC/client trees
- Direct imports from `@flamingo-stack/openframe-frontend-core/components/ui` in Server Components will fail at runtime due to hook usage — always use this wrapper instead
