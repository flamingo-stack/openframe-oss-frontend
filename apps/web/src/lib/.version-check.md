# version-check.ts

Client-side mobile force-update logic that enforces version policy published by the backend. Distinguishes two independent concerns: a dismissible "update available" nudge (based on shell version vs. `latestVersion`) and a blocking "update required" screen (based on bundle version vs. `minBundleVersion`, or any HTTP 426 from the tenant gateway). Applies only to the mobile shell — web and desktop are excluded entirely.

## Key Components

- **`useAppUpdateStore`** — Zustand store holding `policy`, `required`, and `available` state.
- **`UpdateRequiredError`** — Error class for requests the gateway permanently refuses due to an outdated bundle.
- **`isUpdateRequired()`** — Returns whether the blocking update screen should be shown.
- **`noteUpgradeRequired(response)`** — Detects a 426 response on mobile and records the required-update state, extracting `storeUrl` if present.
- **`resolveStoreUrl()`** — Resolves the best-known app store URL (426 body → policy → static fallback).
- **`pendingBundleLiftsBlock(pendingVersion, minBundleVersion)`** — Checks if an already-downloaded pending bundle would satisfy the policy, enabling a restart-instead-of-store-redirect option.
- **`openStore()`** — Navigates to the resolved store URL via `window.location.assign`.
- **`refreshVersionPolicy()`** — Fetches the version policy from the shared host (`/sas/mobile/version-policy`) and updates store state; safe to call repeatedly (deduplicated in-flight).
- **`dismissUpdateNudge()`** — Dismisses the current nudge and snoozes it for 24 hours, keyed by version.
- **`UPGRADE_REQUIRED_STATUS`** — Constant `426`.
- **`UPDATE_REQUIRED_MESSAGE`** — User-facing blocking message.

## Usage Example

```typescript
import {
  refreshVersionPolicy,
  isUpdateRequired,
  noteUpgradeRequired,
  resolveStoreUrl,
  openStore,
  dismissUpdateNudge,
  useAppUpdateStore,
} from './version-check';

// On app start / foreground resume
await refreshVersionPolicy();

// After any gateway fetch
const response = await fetch('/api/some-endpoint');
if (await noteUpgradeRequired(response)) {
  // request will never succeed; show blocking screen
}

if (isUpdateRequired()) {
  showBlockingScreen(resolveStoreUrl());
}

// React component reading the nudge state
const available = useAppUpdateStore((s) => s.available);
if (available) {
  showNudgeBanner(available, {
    onUpdate: openStore,
    onDismiss: dismissUpdateNudge,
  });
}
```
