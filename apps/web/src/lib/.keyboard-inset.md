# keyboard-inset.ts

Publishes the software keyboard's height as a CSS custom property (`--of-keyboard-inset`) on the `<html>` element, allowing overlay components (modals, dialogs) to reposition themselves above the on-screen keyboard. Behavior differs significantly by platform: iOS requires this module to compute and publish the inset itself, Android deliberately publishes nothing because its native shell already resizes the WebView around the keyboard, and mobile web/PWA falls back to the `visualViewport` API.

## Key Components

- **`initKeyboardInset()`** — Public entry point. Wires up keyboard tracking exactly once per document; safe to call on any platform (iOS, Android, web). Dispatches to the correct strategy based on `mobilePlatform()`.
- **`initNativeKeyboardEvents(onShow, onHide)`** — Internal helper that subscribes to the native `Keyboard` plugin's `keyboardWillShow`/`keyboardWillHide` events (preferred over the `Did` variants for earlier, smoother animation sync). Returns `false` if no native plugin is available, letting the caller fall back.
- **`initVisualViewportFallback()`** — Internal helper for non-native mobile web contexts. Listens to `visualViewport` resize/scroll events, guarded against desktop pinch-zoom via a coarse-pointer media query.
- **`publish(height)`** — Internal function that writes the rounded inset to the CSS variable and schedules a one-time re-assertion of `scrollIntoView` on the focused element once the modal's inset transition settles (`INSET_TRANSITION_MS`).
- **`revealTarget(focused)`** — Internal helper that walks up from the focused element to the nearest ancestor that fits within the keyboard-free viewport, avoiding bad `scrollIntoView` behavior on oversized layout boxes (e.g., absolutely-positioned textareas).

## Usage Example

```typescript
import { initKeyboardInset } from './keyboard-inset';

// Call once during app bootstrap, e.g. in your root composition/mount logic.
initKeyboardInset();
```

```vue
<!-- Consuming the published inset in an overlay component -->
<template>
  <div class="modal" :style="{ paddingBottom: 'var(--of-keyboard-inset, 0px)' }">
    <slot />
  </div>
</template>
```

Consumers of `--of-keyboard-inset` are overlay primitives in `openframe-frontend-core` (`modal-v2`, `dialog`, `alert-dialog`), which should default to `0px` when this module hasn't run (e.g., on Android by design).
