# mobile-auth-return.ts

Utilities for detecting and handling a native-app mobile auth flow from within a web auth page, enabling pages shown mid-flow (e.g., "Back to Login") to exit through the app's own return address instead of stranding the user in the native shell's web sheet.

This module encodes the handshake between the server (which embeds `authMobile`/`redirectTo` params for mobile flows), the BFF's `/oauth/join-return` endpoint (which validates the return address against an allow-list before navigating), and the native app's callback parser (which reads the `error` param to decide whether to show a toast).

## Key Components

- **`MOBILE_AUTH_ERROR_PARAM`** — the query param name (`'error'`) the native app's callback parser reads.
- **`MOBILE_AUTH_ERROR`** — known app-level error codes: `USER_CANCELED` (quiet, no toast) and `SESSION_EXPIRED`.
- **`MobileAuthError`** — union type derived from `MOBILE_AUTH_ERROR` values.
- **`appWordedMessage(code)`** — returns the app's own human-readable sentence for codes it words itself, or `undefined` if the code is an auth-server reference that needs a lookup.
- **`isAuthErrorRef(value)`** — type guard checking whether a string matches the shape of a server-issued reference code (`[A-Z0-9_]{1,64}`), distinguishing structured codes from arbitrary text.
- **`readMobileAuthReturn(params)`** — reads `authMobile`/`redirectTo` from `URLSearchParams`-like input and returns the app's return address, or `null` if this isn't a mobile flow. Performs no validation itself—that's the BFF's job.

## Usage Example

```typescript
import {
  readMobileAuthReturn,
  isAuthErrorRef,
  appWordedMessage,
  MOBILE_AUTH_ERROR,
} from './mobile-auth-return';

// On a page that can be shown mid-flow (e.g., a "Back to Login" action)
const params = new URLSearchParams(window.location.search);
const mobileReturn = readMobileAuthReturn(params);

if (mobileReturn) {
  // Hand off to the BFF, which checks the allow-list and 302s accordingly
  await authApiClient.ssoJoinReturnUrl(mobileReturn, {
    error: MOBILE_AUTH_ERROR.USER_CANCELED,
  });
} else {
  // Regular web flow: navigate to web login directly
  router.push('/login');
}

// When the native app parses its callback URL:
const errorCode = callbackParams.get('error');
if (isAuthErrorRef(errorCode)) {
  const message = appWordedMessage(errorCode) ?? lookupServerMessage(errorCode);
  if (errorCode !== MOBILE_AUTH_ERROR.USER_CANCELED) showToast(message);
}
```
