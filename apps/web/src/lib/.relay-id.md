Utilities for encoding and decoding Relay-spec global IDs, with cross-environment Base64 support (browser `window.btoa`/`window.atob` and Node.js `Buffer`).

## Key Components

| Export | Description |
|---|---|
| `DecodedGlobalId` | Interface with `typename` and `rawId` fields |
| `toGlobalId` | Encodes `typename:rawId` to unpadded Base64 |
| `decodeGlobalId` | Decodes a global ID string back to `DecodedGlobalId`, returns `null` on failure |
| `ensureGlobalIdForType` | Returns the input unchanged if already a valid global ID for the given type, otherwise encodes it |
| `notificationGlobalId` | Convenience wrapper — ensures a `Notification`-typed global ID |

**Note:** Padding (`=`) is intentionally stripped from encoded IDs to match the backend's `Base64.getEncoder().withoutPadding()` behavior, ensuring URL-safe, byte-identical IDs for store lookups and route segments.

## Usage Example

```typescript
import {
  toGlobalId,
  decodeGlobalId,
  ensureGlobalIdForType,
  notificationGlobalId,
} from '@/lib/relay-id';

// Encode a raw ID
const globalId = toGlobalId('Script', '42');
// → 'U2NyaXB0OjQy' (no trailing '=')

// Decode back to typename + rawId
const decoded = decodeGlobalId(globalId);
// → { typename: 'Script', rawId: '42' }

// Safely normalize — no double-encoding if already global
const normalized = ensureGlobalIdForType('Script', '42');
const alreadyEncoded = ensureGlobalIdForType('Script', globalId);

// Notification shorthand
const notifId = notificationGlobalId('99');
// → toGlobalId('Notification', '99')
```
