# relay-id.ts

Utility module for encoding and decoding GraphQL Relay-style global IDs (base64 strings combining a typename and raw ID), compatible with both browser and Node.js environments. Mirrors the backend's unpadded base64 encoding scheme to ensure byte-identical IDs for URL safety and lookup consistency.

## Key Components

- **`toGlobalId(typename, rawId)`** — Encodes a `typename:rawId` string into an unpadded base64 global ID, matching the backend's encoding exactly.
- **`decodeGlobalId(value)`** — Decodes a global ID back into `{ typename, rawId }`, re-padding the base64 string as needed. Returns `null` on invalid input.
- **`ensureGlobalIdForType(typename, value)`** — Returns `value` unchanged if it's already a valid global ID for `typename`, otherwise encodes it as one.
- **`rawIdOf(value)`** — Extracts the raw ID from any global ID; returns the input unchanged if it isn't one.
- **`rawIdOfType(typename, value)`** — Like `rawIdOf`, but only unwraps if the decoded typename matches, avoiding false positives on raw IDs (e.g. hex ObjectIds) that happen to be valid base64.
- **`notificationGlobalId(rawId)`** — Convenience wrapper for `ensureGlobalIdForType('Notification', rawId)`.
- **`DecodedGlobalId`** — Interface describing the decoded `{ typename, rawId }` shape.

Internal helpers `btoaUtf8`/`atobUtf8` provide isomorphic base64 encode/decode (browser `btoa`/`atob` or Node `Buffer`), with padding restoration during decode.

## Usage Example

```typescript
import { toGlobalId, decodeGlobalId, rawIdOfType, notificationGlobalId } from './relay-id';

// Encode
const id = toGlobalId('Script', '507f1f77bcf86cd799439011');
// => "U2NyaXB0OjUwN2YxZjc3YmNmODZjZDc5OTQzOTAxMQ"

// Decode
const decoded = decodeGlobalId(id);
// => { typename: 'Script', rawId: '507f1f77bcf86cd799439011' }

// Safely unwrap only if type matches (avoids mangling raw hex IDs)
const rawId = rawIdOfType('Script', id); // "507f1f77bcf86cd799439011"
const unchanged = rawIdOfType('Script', '507f1f77bcf86cd799439011'); // returned as-is

// Notification-specific helper
const notifId = notificationGlobalId('abc123');
```
