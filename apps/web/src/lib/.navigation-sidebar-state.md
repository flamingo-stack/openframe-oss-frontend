Framework-neutral module defining shared constants and utilities for the navigation sidebar's persisted collapse/width state. It enables a pre-paint "FOUC prevention" seed script (emitted from the server root layout) to restore the sidebar's width and collapse state before React hydrates, and exposes a cross-tab-aware store for shells that control the sidebar's collapse state externally.

## Key Components

- **`SIDEBAR_EXPANDED_WIDTH`, `GROUPED_SIDEBAR_EXPANDED_WIDTH`, `MANHATTAN_CHATS_EXPANDED_WIDTH`** — default expanded widths for the core, Mingo-first (grouped), and Manhattan chats sidebars.
- **`SIDEBAR_MIN_EXPANDED_WIDTH` / `SIDEBAR_MAX_EXPANDED_WIDTH`** — drag-resize bounds shared by config and the seed script.
- **`SIDEBAR_WIDTH_STORAGE_KEY`** — localStorage key prefix for the user's chosen width.
- **`SIDEBAR_RESIZE`** — ready-to-use `resizable` config object (`minWidth`, `maxWidth`, `storageKey`).
- **`readChosenSidebarWidth(fallback)`** — client-only reader for the user's dragged/stepped width, clamped to bounds.
- **`SIDEBAR_ELEMENT_SELECTOR`** — DOM selector for the sidebar's root `<aside>`, for external width-reading.
- **`SIDEBAR_LIVE_WIDTH_CSS_VAR`** — CSS var name for live-mirrored sidebar width.
- **`sidebarWidthFoucScript(grouped)`** — returns an inline `<script>` string that seeds CSS width vars before first paint, based on `localStorage`.
- **`readSidebarMinimized()` / `writeSidebarMinimized()` / `subscribeSidebarMinimized()`** — a minimal external store (read/write/subscribe) for the collapse preference, synced across tabs and sidebars via `storage` and a custom `localStorageUpdate` event.

## Usage Example

```typescript
import {
  sidebarWidthFoucScript,
  readSidebarMinimized,
  writeSidebarMinimized,
  subscribeSidebarMinimized,
  SIDEBAR_RESIZE,
} from './navigation-sidebar-state';

// In the server root layout: emit the FOUC-prevention seed script
const script = sidebarWidthFoucScript(/* grouped */ true);
// <script dangerouslySetInnerHTML={{ __html: script }} />

// In a controlled shell (e.g. Mingo-first), toggle collapse via an external store
const isMinimized = useSyncExternalStore(
  subscribeSidebarMinimized,
  readSidebarMinimized,
  () => false,
);

function toggleSidebar() {
  writeSidebarMinimized(!isMinimized);
}

// Pass shared resize bounds to the sidebar config
const config = { resizable: SIDEBAR_RESIZE };
```
