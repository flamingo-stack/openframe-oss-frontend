Shared constants and inline FOUC-prevention script for the navigation sidebar's persisted collapse state. Designed to be framework-neutral (no `'use client'`) so it can be safely imported by both server-side root layouts and client-side skeleton components.

## Key Components

| Export | Type | Description |
|---|---|---|
| `SIDEBAR_MINIMIZED_WIDTH` | `number` | Collapsed sidebar width in pixels (`56`) |
| `SIDEBAR_EXPANDED_WIDTH` | `number` | Expanded sidebar width in pixels (`224`) |
| `SIDEBAR_MINIMIZED_STORAGE_KEY` | `string` | `localStorage` key used to persist the collapse state |
| `SIDEBAR_WIDTH_CSS_VAR` | `string` | CSS variable name (`--of-sidebar-skeleton-width`) seeded before first paint |
| `sidebarWidthFoucScript` | `string` | Inline script injected into `<head>` to prevent FOUC on initial load |
| `runtimeJoin` | Tagged template fn | Blocks Turbopack/SWC constant-folding that would silently corrupt the emitted inline script |

## Usage Example

Inject `sidebarWidthFoucScript` in the root `<head>` to prevent the sidebar from flashing between expanded and minimized states on page load:

```typescript
import {
  sidebarWidthFoucScript,
  SIDEBAR_WIDTH_CSS_VAR,
} from './navigation-sidebar-state';

// In your root layout (Server Component)
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <head>
        {/* Runs synchronously before first paint */}
        <script dangerouslySetInnerHTML={{ __html: sidebarWidthFoucScript }} />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

The CSS variable (`--of-navigation-sidebar-width`) is then consumed by the core `NavigationSidebar` to render at the correct persisted width before React hydration completes.

> **Note on `runtimeJoin`:** The tagged template function is an intentional workaround for a Turbopack/SWC minifier bug that silently corrupts this specific inline script when built from a plain template literal or string concatenation. Do not refactor it to a standard template literal.
