# open-in-new-tab.ts

Provides click-handler utilities for navigating away from table/row actions where a nested `<a>` element can't be used (since the row itself already renders as a `<Link>`/`<a>`). Both handlers prevent the default event and perform navigation programmatically from a `<button>` element.

## Key Components

- **`Router`** — Minimal interface describing the subset of the Next.js router used (`push(href: string)`).
- **`openInNewTab`** — Re-exported from `@flamingo-stack/openframe-frontend-core/utils`. Returns a click handler that opens the given `href` in a new browser tab. Intended for action buttons rendered inside `DataTable` rows that are themselves `<Link>` elements.
- **`navigateTo(router, href)`** — Returns a click handler that calls `e.preventDefault()` and then `router.push(href)`, navigating in the same tab. Symmetric counterpart to `openInNewTab`.

## Usage Example

```typescript
import { useRouter } from 'next/navigation';
import { openInNewTab, navigateTo } from './open-in-new-tab';

function RowActions({ detailsHref }: { detailsHref: string }) {
  const router = useRouter();

  return (
    <>
      {/* Row itself renders as <Link>, so these must be <button> */}
      <button onClick={openInNewTab(detailsHref)}>
        Open in new tab
      </button>
      <button onClick={navigateTo(router, detailsHref)}>
        View details
      </button>
    </>
  );
}
```

Use `openInNewTab` when the action should open a new browser tab (e.g., "open in new tab" context menu-style actions), and `navigateTo` when the action should navigate within the same tab using the Next.js router, obtained via `useRouter()` from `next/navigation`.
