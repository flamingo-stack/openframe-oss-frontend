## Fleet API Client

A specialized API client that extends the base `apiClient` with Fleet (osquery/FleetDM) integration, providing typed methods for managing policies, queries, and hosts within a tenant-scoped MDM/monitoring environment.

## Key Components

- **`FleetApiClient`** — Class wrapping HTTP verbs (`get`, `post`, `put`, `patch`, `delete`) with automatic Fleet URL construction based on tenant host configuration (`runtimeEnv.tenantHostUrl()`).
- **`buildFleetUrl(path)`** — Private helper that prefixes relative paths with the tenant's Fleet server base URL (`/tools/fleetmdm-server`).
- **Policy methods** — `getPolicies`, `getPolicy`, `createPolicy`, `updatePolicy`, `deletePolicy`, `runPolicyOnHost`.
- **Policy-host assignment methods** — `getPolicyHosts`, `addHostsToPolicy`, `removeHostsFromPolicy`, `replacePolicyHosts`.
- **Query methods** — `getQueries`, `getQuery`, `createQuery`, `updateQuery`, `deleteQuery`, `runQuery`, `runLiveQuery`, `getQueryReport`.
- **Query-host assignment methods** — `getQueryHosts`, `addHostsToQuery`, `removeHostsFromQuery`, `replaceQueryHosts`.
- **Host methods** — `getHosts` (filterable by team, status, policy response, etc.).
- **Type exports** — `PolicyHost`, `FleetLabel` interfaces used across Fleet-related UI components.

## Usage Example

```typescript
import { fleetApiClient } from '@/lib/fleet-api-client';

// Fetch policies for a team
const { data } = await fleetApiClient.getPolicies({ team_id: 1 });

// Create a new osquery policy
await fleetApiClient.createPolicy({
  name: 'Disk Encryption Enabled',
  query: 'SELECT 1 FROM disk_encryption WHERE encrypted = 1;',
  description: 'Ensures disk encryption is active',
  critical: true,
});

// Run a live query against selected hosts
const result = await fleetApiClient.runLiveQuery({
  query: 'SELECT * FROM system_info;',
  selected: { hosts: [101, 102], labels: [], teams: [] },
});

// List hosts failing a specific policy
const hosts = await fleetApiClient.getHosts({
  policy_id: 42,
  policy_response: 'failing',
});
```

Note: query parameters use `!== undefined` checks (not truthiness) where `0` is a valid value, such as pagination `page` numbers, to avoid silently dropping the first page.
