# native-back.ts

Handles the Android hardware/gesture back button for the mobile shell, wiring it through `@capacitor/app`. It implements a priority system: close the topmost open overlay first, then navigate SPA history back, and finally exit the app when at the history root. iOS is unaffected since it uses native WKWebView swipe gestures instead of this event.

## Key Components

- **`pushBackDismissible(close)`** — Registers a close handler for an open overlay (LIFO stack). Returns an unregister function to call on cleanup.
- **`initNativeBack()`** — Wires the Android `backButton` listener once. No-op on web or if already initialized. Handles the quirky non-Promise return shape from the native bridge's `addListener`.
- **`useNativeBackDismissible(isOpen, onClose)`** — React hook that registers `onClose` as the active dismissible while `isOpen` is true, and automatically unregisters it on close/unmount. No-op on web.

## Usage Example

```typescript
import { useCallback, useState } from 'react';
import { initNativeBack, useNativeBackDismissible } from './native-back';

// Call once at app startup (e.g. in the shell initializer)
initNativeBack();

// In a modal/overlay component
function MyModal({ open, onRequestClose }: { open: boolean; onRequestClose: () => void }) {
  const handleClose = useCallback(() => {
    onRequestClose();
  }, [onRequestClose]);

  // Pressing Android back while `open` is true calls handleClose
  // instead of navigating the SPA history or exiting the app.
  useNativeBackDismissible(open, handleClose);

  if (!open) return null;
  return <div className="modal">...</div>;
}
```

**Notes:**
- `onClose`/`close` handlers must be stable (wrapped in `useCallback`), since the effect re-registers on every change.
- Multiple open overlays stack LIFO — the most recently opened one closes first on back press.
- All behavior is gated by `isMobileShell()`, making this safe to call unconditionally in shared web/mobile code.
