Utility module providing locale-consistent USD currency formatting helpers, ensuring prices always display in the US format regardless of the user's browser locale settings.

## Key Components

- **`formatCurrency(value: number): string`** — Formats a number as a USD currency string with exactly two decimal places (e.g., `19.5` → `"$19.50"`).
- **`formatWholeCurrency(value: number): string`** — Formats a number as a whole-dollar USD currency string with no decimal places, used for simplified displays like top-up tiles (e.g., `20` → `"$20"`).

Both functions use `toLocaleString` with the `en-US` locale explicitly set, so formatting is deterministic and independent of the end user's actual locale—important since all prices in the app are denominated in USD.

## Usage Example

```typescript
import { formatCurrency, formatWholeCurrency } from './format-currency';

formatCurrency(19.5);        // "$19.50"
formatCurrency(1000);        // "$1,000.00"

formatWholeCurrency(20);     // "$20"
formatWholeCurrency(1500);   // "$1,500"
```

```vue
<script setup lang="ts">
import { formatCurrency, formatWholeCurrency } from '@/utils/format-currency';

const price = 49.99;
const topUpAmount = 20;
</script>

<template>
  <div>
    <p>Price: {{ formatCurrency(price) }}</p>
    <p>Top-up: {{ formatWholeCurrency(topUpAmount) }}</p>
  </div>
</template>
```
