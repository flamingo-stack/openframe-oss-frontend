# upload-with-auth.ts

Provides authenticated file upload and delete utilities for communicating with the tenant API gateway, along with a React hook that wraps upload logic with loading/error state management.

This module handles cookie-based session auth plus optional bearer token authentication, resolves relative endpoints against the tenant host URL, and guards requests against stale sessions or outdated client versions before they're sent.

## Key Components

- **`uploadWithAuth(endpoint, file, fieldName?)`** - Uploads a `File` via `multipart/form-data` POST request with credentials and identity headers. Resolves the response body across several possible shapes (`url`, `imageUrl`, `file_url`, nested `data`/`image` objects) to extract the uploaded file URL.
- **`deleteWithAuth(endpoint)`** - Sends an authenticated DELETE request to remove a previously uploaded file.
- **`useAuthenticatedUpload()`** - React hook exposing `upload`, `isUploading`, and `error` for use in components needing upload UI state.

Both core functions:
- Throw `UpdateRequiredError` if a client upgrade is required (checked via `isUpdateRequired()` / `noteUpgradeRequired()`).
- Throw `SessionGoneError` if the session is invalid (checked via `isSessionGone()` / `noteGatewayResponse()`).
- Attach `clientIdentityHeaders()` and, when in bearer auth mode, an `Authorization` header from `getAccessTokenSync()`.
- Resolve relative endpoints using `runtimeEnv.tenantHostUrl()`, prefixing with `/api` unless already present.

## Usage Example

```typescript
import { uploadWithAuth, deleteWithAuth, useAuthenticatedUpload } from './upload-with-auth';

// Direct function usage
async function handleFileUpload(file: File) {
  try {
    const url = await uploadWithAuth('/api/attachments', file, 'file');
    console.log('Uploaded to:', url);
  } catch (err) {
    console.error('Upload failed:', err);
  }
}

async function handleFileDelete(fileUrl: string) {
  await deleteWithAuth(`/api/attachments?url=${encodeURIComponent(fileUrl)}`);
}

// React component usage
function AvatarUploader() {
  const { upload, isUploading, error } = useAuthenticatedUpload();

  const onChange = async (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (!file) return;
    const url = await upload('/api/avatar', file);
    if (url) console.log('Avatar URL:', url);
  };

  return (
    <div>
      <input type="file" onChange={onChange} disabled={isUploading} />
      {error && <p>{error}</p>}
    </div>
  );
}
```
