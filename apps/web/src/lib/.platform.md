## platform.ts

Provides runtime detection of which "shell" (web browser, Tauri desktop app, or Capacitor mobile app) is hosting the current page, by probing globals each native shell injects before page scripts run. This is the single source of truth for shell-identification logic used throughout the app.

## Key Components

- **`ShellKind`** — type alias: `'web' | 'mobile' | 'desktop'`.
- **`shellKind()`** — returns the memoized, detected shell kind. Safe to call during SSR (always returns `'web'`) and on the client (detects and caches once per session).
- **`isAppShell()`** — `true` for any native shell (mobile or desktop); use only when a feature applies to both.
- **`isMobileShell()`** — `true` only for the Capacitor iOS/Android shell.
- **`isDesktopShell()`** — `true` only for the Tauri desktop shell.
- **`mobilePlatform()`** — returns `'ios' | 'android' | null`; non-null only inside the mobile shell.
- **`isApplePlatform()`** — `true` for the iOS mobile shell or any browser/desktop running on an Apple device (via UA sniffing); used to gate Apple-only auth UI.

## Usage Example

```typescript
import {
  isAppShell,
  isMobileShell,
  isDesktopShell,
  mobilePlatform,
  isApplePlatform,
} from './platform';

// Gate a feature available in any native shell
if (isAppShell()) {
  useShellCustodiedTokenStorage();
}

// Gate a phone-only feature (push notifications, biometrics)
if (isMobileShell()) {
  registerForPushNotifications();
}

// Platform-specific mobile behavior
const platform = mobilePlatform(); // 'ios' | 'android' | null
if (platform === 'ios') {
  enableHapticFeedback();
}

// Show "Continue with Apple" button
if (isApplePlatform()) {
  renderAppleSignInButton();
}

// Desktop-only token rotation via Tauri events
if (isDesktopShell()) {
  listenForTauriTokenRotation();
}
```

**Important:** Prefer the most specific predicate (`isMobileShell()`/`isDesktopShell()`) over `isAppShell()` unless the feature genuinely applies to both native shells — using `isAppShell()` for a phone-only feature silently includes desktop installs.
