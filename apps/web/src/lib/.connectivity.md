# connectivity.ts

A plain, subscribable store providing a verified-before-believed connectivity signal for react-query and the offline banner. It deliberately avoids `navigator.onLine` alone — measured on iOS WKWebView, that signal lags the OS network state by seconds (sometimes up to a minute) at both drop and restore edges — and instead merges a native plugin's reachability reads with the standard web `online`/`offline` events, falling back gracefully when no native plugin is present.

This module is **not** a recovery mechanism. It only answers "is there a link" — retry/recovery logic lives in react-query and in `lib/relay/environment.ts`. A reported "down" state is actively re-verified via a lightweight gateway probe (and re-checked periodically) before being trusted, since the platform signal can itself be wrong.

## Key Components

- **`isOnline(): boolean`** — Synchronous current connectivity state for non-React callers (e.g., Relay's retry policy) that need an immediate answer. Optimistic (`true`) by default until a real source reports.
- **`subscribeConnectivity(listener): () => void`** — Subscribes to connectivity changes; invokes `listener` immediately with the current value and again on every change. Returns an unsubscribe function (required synchronously by react-query's `onlineManager`).
- **Internal mechanics** (not exported): `ensureSource`/`startSource`/`startWebSource` lazily wire either the native `networkPlugin()` (via `native-shell.ts`) or `window` `online`/`offline` events; `report`/`verifyDown`/`gatewayAnswers` implement the "down is verified, up is trusted" policy using a `HEAD` probe against the tenant gateway origin (`runtimeEnv.tenantHostUrl()`), with `PROBE_TIMEOUT_MS` (5s) and `REPROBE_INTERVAL_MS` (10s) governing timing.

## Usage Example

```typescript
import { isOnline, subscribeConnectivity } from './connectivity';

// One-shot check before attempting a request
if (!isOnline()) {
  console.warn('Skipping request: no link detected');
}

// React Query onlineManager wiring (module scope, no React context needed)
import { onlineManager } from '@tanstack/react-query';

onlineManager.setEventListener(setOnline => {
  return subscribeConnectivity(online => setOnline(online));
});
```

Note: this module is intended to be wired once at module scope (e.g., in `query-client.ts`) and mounted outside React providers (e.g., an offline banner in `app/layout.tsx`), since it is a plain store rather than a hook or context.
