Defines a GraphQL Relay query for fetching device filter facets—the dynamic counts and options (status, device type, OS type, organization, tags) used to populate the device filter UI based on currently applied filters.

## Key Components

- **`deviceFiltersRelayQuery`** — A `graphql` tagged template literal (via `react-relay`) representing the `deviceFiltersRelayQuery` GraphQL operation. It accepts a `filter` argument (`DeviceFilterInput`) and returns the `deviceFilters` field, which includes:
  - `statuses` — available device status options with `value`, `label`, and `count`
  - `deviceTypes` — available device type options with `value`, `label`, and `count`
  - `osTypes` — available OS type options with `value`, `label`, and `count`
  - `organizationIds` — available customer/organization options with `value`, `label`, and `count`
  - `tagKeys` — available tag facets with `key`, `value`, and `count`
  - `filteredCount` — total count of devices matching the currently applied filter

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { deviceFiltersRelayQuery } from './device-filters-relay';
import type { deviceFiltersRelayQuery as DeviceFiltersRelayQueryType } from './__generated__/deviceFiltersRelayQuery.graphql';

function DeviceFilterPanel({ currentFilter }: { currentFilter: DeviceFilterInput }) {
  const data = useLazyLoadQuery<DeviceFiltersRelayQueryType>(
    deviceFiltersRelayQuery,
    { filter: currentFilter }
  );

  const { statuses, deviceTypes, osTypes, organizationIds, tagKeys, filteredCount } =
    data.deviceFilters;

  return (
    <div>
      <p>{filteredCount} devices match current filters</p>
      {statuses.map((status) => (
        <label key={status.value}>
          {status.label} ({status.count})
        </label>
      ))}
    </div>
  );
}
```

**Note:** This query is re-executed whenever filter selections change, independent of the paginated device list query. For user and data-source facets, see the related `useDirectoryFacets` hook.
