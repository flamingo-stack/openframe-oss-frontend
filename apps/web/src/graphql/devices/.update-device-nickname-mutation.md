# update-device-nickname-mutation.ts

Defines a GraphQL Relay mutation for setting or clearing a device's user-defined nickname.

## Key Components

- **`updateDeviceNicknameMutation`** — A `graphql` tagged mutation that calls `updateDeviceNickname` with `machineId` (required) and `nickname` (optional/nullable). Passing `null` or an empty string clears the nickname.

The mutation's response payload includes `id`, `nickname`, `displayName`, and `hostname` — fields matching the `Machine implements Node` interface, which allows Relay to automatically merge updates into its normalized store. This ensures any list, picker, or row component referencing the device re-renders with the new name without an explicit refetch.

Note: Non-Relay surfaces (e.g., raw-POST endpoints or react-query consumers like the device detail page or fleet-wide reads) are **not** updated by Relay's normalization. These must be refreshed separately via `invalidateDeviceQueries` in the calling hook.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { updateDeviceNicknameMutation } from './update-device-nickname-mutation';

function useUpdateDeviceNickname() {
  const [commit, isInFlight] = useMutation(updateDeviceNicknameMutation);

  const updateNickname = (machineId: string, nickname: string | null) => {
    commit({
      variables: { machineId, nickname },
      onCompleted: () => {
        // Refresh non-Relay data sources (detail page, fleet-wide queries)
        invalidateDeviceQueries(machineId);
      },
      onError: (error) => {
        console.error('Failed to update nickname:', error);
      },
    });
  };

  return { updateNickname, isInFlight };
}
```
