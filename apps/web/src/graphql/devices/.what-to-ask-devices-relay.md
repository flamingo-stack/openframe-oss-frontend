Defines a Relay GraphQL query that fetches online devices to populate the "What to ask Mingo?" prompt suggestions, supplying each device's identity, display name, and OS/type metadata for `@device:<id>` mentions.

## Key Components

- **`whatToAskDevicesRelayQuery`** — A `graphql` tagged template (Relay query) named `whatToAskDevicesRelayQuery` that:
  - Accepts a required `$first: Int!` variable to limit the number of results.
  - Filters devices by `statuses: [ONLINE]`.
  - Returns a paginated edge/node structure where each `node` includes:
    - `id` — used for the `@device:<id>` mention syntax.
    - `machineId`, `hostname`, `displayName`, `nickname` — used to resolve the display name shown on the chip (preferring nickname, then displayName, then hostname).
    - `type` — the kind of device.
    - `osType` — the device's operating system.

This query is fetched on-demand (e.g., on click) rather than kept live on screen, which is why it's a plain query instead of a Relay connection/fragment pattern.

## Usage Example

```typescript
import { fetchQuery, useRelayEnvironment } from 'react-relay';
import { whatToAskDevicesRelayQuery } from './what-to-ask-devices-relay';

function useOnlineDevicesForPrompt(limit: number) {
  const environment = useRelayEnvironment();

  const loadDevices = async () => {
    const data = await fetchQuery(environment, whatToAskDevicesRelayQuery, {
      first: limit,
    }).toPromise();

    return data?.devices?.edges?.map(({ node }) => ({
      id: node.id,
      label: node.nickname ?? node.displayName ?? node.hostname,
      type: node.type,
      os: node.osType,
    }));
  };

  return { loadDevices };
}
```

Typically invoked when the user opens the "What to ask Mingo?" menu, so the device list reflects the current online devices at that moment without persisting a live connection.
