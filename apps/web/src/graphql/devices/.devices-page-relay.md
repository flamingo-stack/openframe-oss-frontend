Defines a Relay GraphQL query for fetching a single bounded page of devices, intended for "pick-one" UI surfaces (script-run device pickers, schedule assignment, ticket-form autocomplete) rather than infinite-scroll browsing.

## Key Components

- **`devicesPageRelayQuery`** — A `graphql` tagged query (via `react-relay`) that fetches `devices` with pagination arguments (`$filter`, `$search`, `$first`, `$after`), sorted by `status DESC`.
  - Deliberately **not** a `@connection` directive — callers either cap and render results directly (device pickers) or manually paginate via `pageInfo`/`$after` to build a lookup table (`fetchAllDevices`), so Relay's store-managed connection list isn't needed.
  - Reuses the `deviceFields_machine` fragment and the same sort order as the main Devices page, ensuring consistent data shape and ordering across all surfaces, with Relay normalizing results into shared `Machine` records.
  - Returns `filteredCount`, `edges.node` (spreading `deviceFields_machine`), and `pageInfo` (`hasNextPage`, `endCursor`) for manual pagination walks.

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { devicesPageRelayQuery } from './devices-page-relay';
import type { devicesPageRelayQuery as DevicesPageRelayQueryType } from './__generated__/devicesPageRelayQuery.graphql';

function DevicePickerList({ filter, search }: { filter?: object; search?: string }) {
  const data = useLazyLoadQuery<DevicesPageRelayQueryType>(devicesPageRelayQuery, {
    filter,
    search,
    first: 25,
  });

  return (
    <ul>
      {data.devices.edges.map(({ node }) => (
        <li key={node.id}>{/* render device via deviceFields_machine */}</li>
      ))}
    </ul>
  );
}
```

For full-fleet lookups, repeatedly execute the query passing `pageInfo.endCursor` as `$after` until `pageInfo.hasNextPage` is `false`, accumulating results into a lookup table.
