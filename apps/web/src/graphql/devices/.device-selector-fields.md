# device-selector-fields.ts

Defines a GraphQL inline fragment that extends the base device row fields with hardware identifiers and organization contact information, used specifically for fleet-wide device selection UIs.

## Key Components

- **`deviceSelectorFieldsFragment`** — A Relay `@inline` GraphQL fragment named `deviceSelectorFields_machine` defined on the `Machine` type. It:
  - Spreads in `deviceRowFields_machine` (the base row-level fields)
  - Adds hardware identifiers: `manufacturer`, `model`, `serialNumber`
  - Adds a second, independent selection on `organization.contactInformation.contacts.email` for retrieving the customer's contact email

This fragment represents "step 2" of a layered device field composition pattern, building on top of the row fields fragment without duplicating the `organization` fields already selected there (name/logo), since Relay allows multiple independent selections on the same field.

## Usage Example

```typescript
import { useFragment } from 'react-relay';
import { deviceSelectorFieldsFragment } from './device-selector-fields';

function DeviceSelectorItem({ machineRef }) {
  const machine = useFragment(deviceSelectorFieldsFragment, machineRef);

  return (
    <div>
      <span>{machine.manufacturer} {machine.model}</span>
      <span>SN: {machine.serialNumber}</span>
      <span>Contact: {machine.organization?.contactInformation?.contacts?.[0]?.email}</span>
    </div>
  );
}
```

This fragment is consumed by the schedule's device picker (see `schedule-device-picker-relay.ts`), which needs contact information to display fleet-wide device selection options, unlike the simpler per-schedule assignment row view that relies solely on `deviceRowFields_machine`.
