# devices-list-relay-v1.ts

GraphQL Relay definitions powering the paginated device list used by the Devices page, the customer devices tab, and the archive page. This file is part of the legacy (`tenant-management-v2`-off) code path and will be removed once that flag is fully rolled out.

Its purpose is to provide a `@refetchable`, `@connection`-backed fragment so Relay manages cursor-based pagination and page merging natively, replacing the previous manual `useInfiniteQuery` approach.

## Key Components

- **`devicesListRelayV1Query`** — Root GraphQL query that accepts `filter`, `search`, `first`, and `after` arguments and spreads the paginated fragment.
- **`devicesListRelayV1Fragment`** — `@refetchable` fragment (generates `devicesListRelayV1PaginationQuery`) defining the `devices` connection:
  - Uses `@connection(key: "devicesListRelayV1_devices", filters: ["filter", "search"])` so each distinct filter/search combination gets its own isolated connection record (critical to avoid cross-contaminating paginated results).
  - Fixes sort order to `status DESC` (online devices first) so all consuming screens stay consistent.
  - Selects `unreadNotificationCount` outside the shared `deviceFields_machine` fragment, since only this list renders it, keeping other consumers of that fragment lightweight.
  - Exposes `filteredCount`, `edges.node`, and `pageInfo` (`hasNextPage`, `endCursor`) for pagination controls.

## Usage Example

```typescript
import { useLazyLoadQuery, usePaginationFragment } from 'react-relay';
import { devicesListRelayV1Query, devicesListRelayV1Fragment } from './devices-list-relay-v1';

function DevicesList({ filter, search }: { filter?: DeviceFilterInput; search?: string }) {
  const queryData = useLazyLoadQuery(devicesListRelayV1Query, {
    filter,
    search,
    first: 20,
  });

  const { data, loadNext, hasNext, isLoadingNext } = usePaginationFragment(
    devicesListRelayV1Fragment,
    queryData
  );

  return (
    <>
      {data.devices.edges.map(({ node }) => (
        <DeviceRow key={node.id} device={node} unread={node.unreadNotificationCount} />
      ))}
      {hasNext && (
        <button onClick={() => loadNext(20)} disabled={isLoadingNext}>
          Load more
        </button>
      )}
    </>
  );
}
```
