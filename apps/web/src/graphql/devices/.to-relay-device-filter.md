Narrows the app's string-based `DeviceFilterInput` to the enum-typed one relay-compiler generates from the schema.

`DeviceFilterInput.statuses` and `.deviceTypes` are `DeviceStatus` / `DeviceType` **enums** server-side, but the app's filter values arrive from URL query params — arbitrary user input. This is a real validation boundary, not a cast: an unrecognised value is dropped here rather than sent, where it would fail the whole query on a GraphQL enum coercion error and blank the list.

The enum members come from `@/generated/schema-enums`, per the project rule that enum types are generated from `schema.graphql` and never hand-written or imported from a Relay artifact.

## Usage

Every Relay device query variable set goes through it:

```typescript
useLazyLoadQuery(devicesPageRelayQuery, { filter: toRelayDeviceFilter(filter), search, first });
```
