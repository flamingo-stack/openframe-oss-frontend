# device-facets-fields.ts

Defines a shared Relay inline fragment for reading scoped `DeviceFilters` facet data (used by schedules' and bundles' `availableDeviceFilters` / `assignedDeviceFilters` fields), along with a helper to normalize that data into the `DeviceFilters` shape consumed by device picker UI components.

## Key Components

- **`deviceFacetsFieldsFragment`** — A GraphQL `@inline` fragment (`deviceFacetsFields_filters`) on `DeviceFilters` selecting `statuses`, `deviceTypes`, `osTypes`, `organizationIds`, `tagKeys`, and `filteredCount`. Centralizes this selection so multiple owners (schedules, bundles) don't duplicate identical field sets.

- **`EMPTY_DEVICE_FILTERS`** — A constant `DeviceFilters` object representing a facet-less result (all empty arrays, `filteredCount: 0`), used as a fallback when no fragment reference is available.

- **`toDeviceFilters(ref, fleetTagKeys)`** — Converts a fragment reference into a mutable `DeviceFilters` object:
  - Returns `EMPTY_DEVICE_FILTERS` (merged with `fleetTagKeys`) if `ref` is nullish.
  - Otherwise reads the inline fragment data and spreads each readonly array into a new mutable array (since Relay returns readonly arrays but consumers mutate them).
  - Falls back to `fleetTagKeys` for `tagKeys` whenever the scoped field's `tagKeys` is empty, since scoped facets currently never populate tags.

## Usage Example

```typescript
import { useFragment } from 'react-relay';
import { toDeviceFilters } from './device-facets-fields';
import type { fleetTagKeys_query$key } from '@/__generated__/fleetTagKeys_query.graphql';

function useScopedDeviceFilters(
  scheduleRef: deviceFacetsFields_filters$key | null,
  fleetTagKeys: TagFilterOption[],
) {
  // scheduleRef typically comes from a parent query's
  // availableDeviceFilters / assignedDeviceFilters field
  const deviceFilters = toDeviceFilters(scheduleRef, fleetTagKeys);

  // deviceFilters.statuses, .deviceTypes, etc. are mutable arrays
  // ready for consumption by device picker/table components
  return deviceFilters;
}
```

**Note:** Always spread the shared fragment in parent queries rather than redefining the same selection set, to keep schedule and bundle facet shapes in sync.
