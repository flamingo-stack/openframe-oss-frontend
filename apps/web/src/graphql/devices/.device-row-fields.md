# device-row-fields.ts

Defines the narrowest GraphQL fragment in the device field ladder — the minimal set of `Machine` fields needed to render a single row in `DevicesTableBody`: device name/icon, customer, status, last-seen, and tags.

This fragment is the base step that `deviceSelectorFields_machine` and `deviceFields_machine` build on by spreading it and adding more fields. It is intentionally kept lean for low-budget consumers like the schedule's Assigned Devices tab (`script-schedule-devices-relay.ts`), where per-machine resolution (`assignedDevices`) has previously timed out under heavier queries.

## Key Components

- **`deviceRowFieldsFragment`** — An `@inline` GraphQL fragment (`deviceRowFields_machine`) on `Machine`, consumed by the plain transform function `machineRowToDevice` (not a component) to flatten a relay row into the shared `Device` shape.
  - Identity: `id`, `machineId`
  - Name resolution inputs: `hostname`, `displayName`, `nickname` (resolved via `getDeviceName` as nickname → displayName → hostname)
  - Row display: `osType` (icon), `status`, `lastSeen`, `type`
  - Customer: `organization { id, organizationId, name, image { imageUrl, hash } }`
  - Tags: `tagAssignments { id, values, taggedAt, tag { id, key, description, color } }` — used for the client-side "Device Tags" filter; selected whole (not split across ladder steps) to avoid having to zip fragments back together by index

## Usage Example

```typescript
import { readInlineData } from 'react-relay';
import { deviceRowFieldsFragment } from './device-row-fields';

function machineRowToDevice(machineRef: any) {
  const data = readInlineData(deviceRowFieldsFragment, machineRef);

  return {
    id: data.id,
    name: data.nickname || data.displayName || data.hostname,
    status: data.status,
    lastSeen: data.lastSeen,
    organization: data.organization,
    tags: data.tagAssignments.map((ta) => ta.tag),
  };
}
```

Heavier consumers (e.g. the full devices table) should use `deviceFields_machine` or `deviceSelectorFields_machine`, which spread this fragment rather than duplicating its field list.
