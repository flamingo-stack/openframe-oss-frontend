# devices-list-relay.ts

Defines the GraphQL query and refetchable paginated fragment that power the scrollable device list used across the Devices page, customer devices tab, and archive page. It replaces manual cursor/page handling (previously done via `useInfiniteQuery`) with Relay's native `@connection` pagination.

## Key Components

- **`devicesListRelayQuery`** — The root `graphql` query used by `loadQuery`/`usePreloadedQuery`. Accepts `filter`, `search`, `first`, and `after` variables and spreads the paginated fragment.
- **`devicesListRelayFragment`** — A `@refetchable` fragment (generates `devicesListRelayPaginationQuery`) exposing a `devices` connection annotated with `@connection(key: "devicesListRelay_devices", filters: ["filter", "search"])`. Key details:
  - `filters: ["filter", "search"]` ensures each filter/search combination gets its own isolated connection record, mirroring the old react-query cache key `[filter, search]`.
  - Sort order is hardcoded to `status DESC` so all consumers render devices in a consistent order (online-first).
  - Each edge node spreads `deviceFields_machine` (shared) and `deviceDirectoryFields_machine` (only valid under the `tenant-management-v2` schema/feature flag), plus selects `unreadNotificationCount` directly since only this list renders it.

## Usage Example

```typescript
import { useLazyLoadQuery, usePaginationFragment } from 'react-relay';
import { devicesListRelayQuery, devicesListRelayFragment } from './devices-list-relay';

function DevicesList({ filter, search }: { filter?: DeviceFilterInput; search?: string }) {
  const queryData = useLazyLoadQuery(devicesListRelayQuery, {
    filter,
    search,
    first: 20,
  });

  const { data, loadNext, hasNext, isLoadingNext } = usePaginationFragment(
    devicesListRelayFragment,
    queryData
  );

  return (
    <>
      {data.devices.edges.map(({ node }) => (
        <DeviceRow key={node.id} device={node} />
      ))}
      {hasNext && (
        <button disabled={isLoadingNext} onClick={() => loadNext(20)}>
          Load more
        </button>
      )}
    </>
  );
}
```

**Note:** When `tenant-management-v2` is disabled, use `devicesListRelayV1_query` instead, which omits `deviceDirectoryFields_machine`.
