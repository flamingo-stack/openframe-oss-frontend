Defines the GraphQL mutation for stopping an active timer, returning the updated time entry fragment.

## Key Components

- **`stopTimerMutation`** — A Relay GraphQL mutation that calls `stopTimer` with a `StopTimerInput` and spreads the `timeEntryFields_timeEntry` fragment (unmasked) on the response.

## Usage Example

```typescript
import { stopTimerMutation } from './stop-timer-mutation';
import { useMutation } from 'react-relay';

const [commitMutation, isInFlight] = useMutation(stopTimerMutation);

commitMutation({
  variables: {
    input: { id: 'timer-id-123' },
  },
  onCompleted: (response) => {
    console.log('Timer stopped', response);
  },
});
```

## Notes

- Uses `@relay(mask: false)` to inline all fields from `timeEntryFields_timeEntry` directly into the mutation response, bypassing Relay's data masking.
- Pair with the corresponding `startTimer` mutation for full timer lifecycle management.
