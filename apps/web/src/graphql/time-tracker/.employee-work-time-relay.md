# employee-work-time-relay.ts

Defines GraphQL Relay query and fragment definitions for fetching and paginating employee work time tracking data, including aggregate time statistics and detailed time entries with associated user and organization information.

## Key Components

- **`employeeWorkTimeRelayQuery`** - Root GraphQL query that fetches `employeeTimeStats` (aggregated statistics such as today's total seconds, entry counts, and period averages) and spreads the `employeeWorkTimeRelay_query` fragment to retrieve paginated time entries.
- **`employeeWorkTimeRelayFragment`** - A `@refetchable` Relay fragment on `Query` that retrieves `employeeTimeEntries` via a `@connection` for cursor-based pagination. Each edge includes shared time entry fields (via the unmasked `timeEntryFields_timeEntry` fragment), along with related `user` (name, email, status, avatar) and `organization` (name, image, contact info) details.

## Usage Example

```typescript
import { useLazyLoadQuery, usePaginationFragment } from 'react-relay';
import { employeeWorkTimeRelayQuery, employeeWorkTimeRelayFragment } from './employee-work-time-relay';

function EmployeeWorkTimeView({ filter, search }: { filter: any; search: string }) {
  const data = useLazyLoadQuery(employeeWorkTimeRelayQuery, {
    filter,
    search,
    first: 20,
    after: null,
  });

  const { data: paginatedData, loadNext, hasNext } = usePaginationFragment(
    employeeWorkTimeRelayFragment,
    data
  );

  return (
    <div>
      <p>Today's total: {data.employeeTimeStats.todayTotalSeconds}s</p>
      {paginatedData.employeeTimeEntries.edges.map(({ node }) => (
        <div key={node.id}>
          {node.user.firstName} {node.user.lastName} — {node.organization.name}
        </div>
      ))}
      {hasNext && <button onClick={() => loadNext(20)}>Load More</button>}
    </div>
  );
}
```

**Note:** This fragment depends on `timeEntryFields_timeEntry` being defined elsewhere in the schema and uses `@relay(mask: false)` to flatten its fields directly into each edge node.
