# time-tracker-helpers.ts

Core helper utilities for the time-tracker feature: converts backend timer/entry data into UI-ready display state, codecs calendar days and instants for timezone-safe date handling, builds Relay global ids for mutation inputs, and provides Relay store updaters to keep timer and entry connections consistent after mutations.

## Key Components

- **`TimeEntryNodeShape`** — shape of a time entry node as read from GraphQL, used as input to the mapping helpers.
- **`TrackerClockState`** — display contract (`status`, `runningSince`, `accumulatedMs`) consumed by the tracker clock UI.
- **`calendarDayToInstant` / `instantToCalendarDay` / `moveInstantToCalendarDay`** — exact-inverse codecs between civil calendar days and UTC-anchored `Instant`s, avoiding timezone rollback bugs.
- **`mapTimerToTrackerState(node)`** — derives running/paused/ready clock state from `startedAt`, `breakSeconds`, and `pausedAt`, since the backend only finalizes `durationSeconds` on stop.
- **`formatDurationLabel` / `parseDurationLabel`** — `HH:MM:SS` formatting and parsing for manual entry forms.
- **`toInstantRange(from, to)`** — builds inclusive `[startedFrom, startedTo]` instant bounds for filtering.
- **`toTicketGlobalId` / `toOrganizationGlobalId`** — normalize raw ids to Relay global ids for mutation inputs.
- **`CLEAR_TICKET_ID` / `CLEAR_ORGANIZATION_ID`** — sentinel global-id-encoded blank values signaling "clear this field" to the backend.
- **`mapTimeEntryToLastEntry(node)`** — maps a `TimeEntryNodeShape` to the `TimeTrackerEntry` display type.
- **`makeSetCurrentTimerUpdater` / `makeStopTimerUpdater` / `makeCreateTimeEntryUpdater` / `makeDeleteTimeEntryUpdater` / `makeCancelTimerUpdater`** — Relay store updater factories for timer/entry mutations.
- **`notifyTimeEntriesChanged` / `subscribeTimeEntriesChanged`** — cross-surface pub/sub so pages like "My Time" refetch server-aggregated stats when another surface mutates entries.

## Usage Example

```typescript
import {
  mapTimerToTrackerState,
  toInstantRange,
  makeStopTimerUpdater,
  notifyTimeEntriesChanged,
} from './time-tracker-helpers';

// Derive display state from a GraphQL timer node
const clockState = mapTimerToTrackerState(currentTimerNode);

// Build a date-range filter for a report query
const range = toInstantRange(new Date('2024-01-01'), new Date('2024-01-31'));

// Use as a Relay mutation updater
commitMutation(environment, {
  mutation: StopTimerMutation,
  variables: { input },
  updater: makeStopTimerUpdater(),
  onCompleted: () => notifyTimeEntriesChanged(currentUserId),
});
```
