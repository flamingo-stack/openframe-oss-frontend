Defines a Relay GraphQL mutation for cancelling the active timer.

## Key Components

- **`cancelTimerMutation`** — A Relay-compiled `graphql` mutation that calls the `cancelTimer` root mutation field. Returns no selection set beyond the scalar result.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { cancelTimerMutation } from './cancel-timer-mutation';

function CancelTimerButton() {
  const [commit, isInFlight] = useMutation(cancelTimerMutation);

  return (
    <button disabled={isInFlight} onClick={() => commit({ variables: {} })}>
      Cancel Timer
    </button>
  );
}
```

## Notes

- No variables are required; the mutation takes no arguments.
- Part of the timer management feature within the OpenFrame OSS frontend. See related mutations in [`src`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src) for start/stop timer operations.
