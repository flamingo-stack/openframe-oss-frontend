Defines a Relay GraphQL mutation for deleting a time entry by its ID.

## Key Components

- **`deleteTimeEntryMutation`** — A compiled Relay `graphql` mutation that calls the `deleteTimeEntry` field on the GraphQL API, accepting a single required `ID` argument and returning a boolean/scalar result.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { deleteTimeEntryMutation } from './delete-time-entry-mutation';

const [commitMutation, isInFlight] = useMutation(deleteTimeEntryMutation);

commitMutation({
  variables: { id: 'time-entry-id-123' },
  onCompleted: () => console.log('Time entry deleted'),
  onError: (error) => console.error('Delete failed', error),
});
```

## Notes

- The mutation returns a scalar value (not a typed object), so no fragment spreading is required on the result.
- Relay will automatically generate a `deleteTimeEntryMutation$variables` type to enforce the `id: ID!` input at compile time.
