Defines GraphQL Relay query and fragment declarations for fetching a paginated list of the current user's time entries, supporting cursor-based pagination via Relay's connection pattern.

## Key Components

- **`myTimeEntriesRelayQuery`** — Root GraphQL query that accepts `first` (page size) and `after` (cursor) arguments and spreads the `myTimeEntriesRelay_query` fragment.
- **`myTimeEntriesRelayFragment`** — Refetchable Relay fragment (`myTimeEntriesRelayPaginationQuery`) defined on `Query`, exposing the `myTimeEntries` connection field with `@connection(key: "MyTimeEntries_myTimeEntries")` for pagination support. Each edge's node spreads `timeEntryFields_timeEntry` (unmasked via `@relay(mask: false)`), and `pageInfo` exposes `endCursor`/`hasNextPage` for infinite scroll or "load more" functionality.

## Usage Example

```typescript
import { usePaginationFragment, useLazyLoadQuery } from 'react-relay';
import { myTimeEntriesRelayQuery, myTimeEntriesRelayFragment } from './my-time-entries-relay';

function TimeEntriesList() {
  const queryData = useLazyLoadQuery(myTimeEntriesRelayQuery, {
    first: 3,
    after: null,
  });

  const { data, loadNext, hasNext } = usePaginationFragment(
    myTimeEntriesRelayFragment,
    queryData
  );

  return (
    <div>
      {data.myTimeEntries.edges.map(({ node, cursor }) => (
        <div key={cursor}>{/* render time entry fields */}</div>
      ))}
      {hasNext && (
        <button onClick={() => loadNext(3)}>Load More</button>
      )}
    </div>
  );
}
```

This pattern is typically paired with a React component that uses `usePaginationFragment` to incrementally load additional time entries as the user scrolls or clicks "load more".
