Updates an existing time entry record via a GraphQL mutation using Relay.

## Key Components

- **`updateTimeEntryMutation`** — A Relay GraphQL mutation that accepts an `UpdateTimeEntryInput` and spreads the `timeEntryFields_timeEntry` fragment (unmasked) on the response.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { updateTimeEntryMutation } from './update-time-entry-mutation';

const [commitMutation, isInFlight] = useMutation(updateTimeEntryMutation);

commitMutation({
  variables: {
    input: {
      id: 'time-entry-id',
      duration: 3600,
      notes: 'Updated notes',
    },
  },
  onCompleted: (response) => {
    console.log('Time entry updated:', response);
  },
  onError: (error) => {
    console.error('Update failed:', error);
  },
});
```

## Notes

- Uses `@relay(mask: false)` to inline all fields from the `timeEntryFields_timeEntry` fragment directly into the mutation response, rather than requiring a separate fragment container to access the data.
- The `UpdateTimeEntryInput` type is defined server-side; refer to the GraphQL schema for the full list of accepted fields.
