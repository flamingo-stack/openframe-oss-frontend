Relay GraphQL mutation for resuming a paused timer, returning the updated time entry fields.

## Key Components

- **`resumeTimerMutation`** — A tagged GraphQL mutation that calls `resumeTimer` and spreads the `timeEntryFields_timeEntry` fragment (with `@relay(mask: false)` to expose all fields inline).

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { resumeTimerMutation } from './resume-timer-mutation';

const [commit, isInFlight] = useMutation(resumeTimerMutation);

commit({
  variables: {},
  onCompleted(response) {
    console.log('Timer resumed:', response.resumeTimer);
  },
  onError(error) {
    console.error('Failed to resume timer:', error);
  },
});
```

## Notes

- Requires the `timeEntryFields_timeEntry` fragment to be defined and available in the Relay store.
- `@relay(mask: false)` means all fields from the fragment are directly accessible on the response object without needing to read through Relay's fragment masking.
