Defines a Relay GraphQL mutation for creating a new time entry, spreading the `timeEntryFields_timeEntry` fragment with masking disabled.

## Key Components

- **`createTimeEntryMutation`** — Exported Relay `graphql` tagged template literal that issues a `createTimeEntry` mutation, accepting a `CreateTimeEntryInput!` variable and returning fields via the unmasked `timeEntryFields_timeEntry` fragment.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { createTimeEntryMutation } from './create-time-entry-mutation';

function TimeEntryForm() {
  const [commit, isInFlight] = useMutation(createTimeEntryMutation);

  const handleSubmit = (input: CreateTimeEntryInput) => {
    commit({
      variables: { input },
      onCompleted: (response) => console.log('Created:', response),
      onError: (error) => console.error('Error:', error),
    });
  };
}
```

## Notes

- Uses `@relay(mask: false)` on the fragment spread, meaning all fields defined in `timeEntryFields_timeEntry` are directly accessible on the response without manual fragment data access.
- Relies on `timeEntryFields_timeEntry` being defined elsewhere; see the [fragment definition](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src) for the full field set.
