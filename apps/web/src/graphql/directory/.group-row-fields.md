Defines a reusable GraphQL fragment (via `react-relay`) that specifies the fields required to render a directory group as a row in a list, used across the customer's Groups tab and the user page's Groups tab.

## Key Components

- **`groupRowFieldsFragment`** — A Relay `@inline` GraphQL fragment named `groupRowFields_group`, defined on the `DirectoryGroup` type. It selects:
  - `id` — unique identifier of the group
  - `name` — display name of the group
  - `provider` — the identity/directory provider the group originates from
  - `memberCount` — number of members in the group
  - `feed` — associated feed data
  - `connection.name` — the name of the related connection

Since this is an `@inline` fragment, it can be read directly from a parent query/fragment result using `readInlineData`, rather than requiring a separate `useFragment` hook call tied to a component render.

## Usage Example

```typescript
import { readInlineData } from 'react-relay';
import { groupRowFieldsFragment } from './group-row-fields';

function getGroupRowData(groupRef: any) {
  const group = readInlineData(groupRowFieldsFragment, groupRef);

  return {
    id: group.id,
    name: group.name,
    provider: group.provider,
    memberCount: group.memberCount,
    connectionName: group.connection?.name,
  };
}
```

Typically, a parent query spreads this fragment on a `DirectoryGroup` field:

```graphql
query GroupsTabQuery {
  directoryGroups {
    ...groupRowFields_group
  }
}
```

The resulting data is then passed to `readInlineData` to extract the typed fields for rendering the group row in list views such as the Groups tabs on customer and user pages.
