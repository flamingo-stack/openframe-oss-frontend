Defines a shared Relay inline fragment and helper for representing a customer (organization) as a reusable option object, including its ID, name, and logo image. Used wherever a compact customer representation is needed, such as customer pickers, connection bindings, directory account ownership, and directory device associations.

## Key Components

- **`customerOptionFragment`** — GraphQL `@inline` fragment on `Organization` that selects `organizationId`, `name`, and `image { imageUrl, hash }`.
- **`CustomerOption`** — TypeScript type derived from the fragment's generated data type, with the internal `$fragmentType` field omitted.
- **`toCustomerOption(ref)`** — Reads the inline fragment data from a `customerOption_organization$key` reference and returns a normalized `CustomerOption` object, safely handling a `null` `image`.

## Usage Example

```typescript
import { toCustomerOption, type CustomerOption } from '@/path/to/customer-option';
import type { customerOption_organization$key } from '@/__generated__/customerOption_organization.graphql';

function getCustomerOption(organizationRef: customerOption_organization$key): CustomerOption {
  return toCustomerOption(organizationRef);
}

// Example usage in a component that receives an organization fragment reference
function CustomerPickerOption({ organizationRef }: { organizationRef: customerOption_organization$key }) {
  const customer = toCustomerOption(organizationRef);

  return (
    <div>
      {customer.image && <img src={customer.image.imageUrl} alt={customer.name} />}
      <span>{customer.name}</span>
    </div>
  );
}
```

This pattern is typically used in combination with parent fragments that spread `...customerOption_organization` on an `Organization` field, allowing `toCustomerOption` to convert the resulting fragment reference into a plain, serializable object for use in UI components like dropdowns, lists, or badges.
