Defines a Relay inline fragment and helper functions for presenting a customer that claims a directory account, converting GraphQL fragment data into a display-ready shape (name, logo, and claim reason).

## Key Components

- **`customerClaimFieldsFragment`** — GraphQL `@inline` fragment on `DirectoryCustomerClaim`, fetching the organization (via `customerOption_organization`), the claiming rule's `kind`, and `via` (the rule's target, e.g., a group name).
- **`ClaimingCustomer`** — Interface describing the presentation shape: `name`, optional `imageUrl`, and `claim` (a human-readable string like `"Group: Finance"`, or `null` if no rule applies).
- **`toCustomer(customerOption: CustomerOption): ClaimingCustomer`** — Converts a plain `CustomerOption` (name/image) into a `ClaimingCustomer` with `claim` set to `null`. Used for cases like a directory device's declared owner, where no claiming rule exists.
- **`toClaimingCustomer(ref: customerClaimFields_claim$key): ClaimingCustomer`** — Reads the inline fragment data from a Relay fragment reference, resolves the rule kind label via `ruleKindLabel`, and builds the `claim` string by combining the kind and `via` (e.g., `"Group: Finance"`), falling back to just the kind or `null` if no rule/via exists.

## Usage Example

```typescript
import { toClaimingCustomer, toCustomer } from './customer-claim-fields';
import { toCustomerOption } from './customer-option';

// From a Relay fragment reference (e.g., in a list of claims)
function ClaimRow({ claimRef }: { claimRef: customerClaimFields_claim$key }) {
  const customer = toClaimingCustomer(claimRef);

  return (
    <div>
      {customer.imageUrl && <img src={customer.imageUrl} alt={customer.name} />}
      <span>{customer.name}</span>
      {customer.claim && <span className="text-muted">{customer.claim}</span>}
    </div>
  );
}

// For a device's declared owner (no claim rule involved)
```
