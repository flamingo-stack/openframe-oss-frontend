## account-row-fields.ts

Converts a GraphQL `DirectoryAccount` fragment into a row-shaped object usable by the Users list UI, specifically populating the `User` and `Customer` cells for a device's Users tab or a group's members view. Unlike the main Users list (which merges multiple accounts into a single person row), this handles a single directory account as a standalone row.

## Key Components

- **`accountRowFieldsFragment`** — An inline GraphQL fragment (`accountRowFields_account`) declared on `DirectoryAccount`, selecting `id`, `displayName`, `email`, `signInName`, `source`, and nested `customers` data (via `customerClaimFields_claim`).
- **`AccountRow`** — A type representing the subset of `UserRow` fields an account can fully populate: `id`, `href`, `name`, `email`, `providers`, and `customers`, all required.
- **`toAccountRow(ref)`** — Reads the inline fragment data from a `accountRowFields_account$key` reference and maps it into an `AccountRow`, building the detail link via `routes.users.details`, formatting the email/sign-in address with `accountAddress`, deriving provider badges with `providerMarks`, and mapping each customer through `toClaimingCustomer`.

## Usage Example

```typescript
import { toAccountRow, accountRowFieldsFragment } from './account-row-fields';
import { useFragment } from 'react-relay';

function AccountRowCell({ accountRef }: { accountRef: accountRowFields_account$key }) {
  const row = toAccountRow(accountRef);

  return (
    <tr>
      <td><a href={row.href}>{row.name}</a></td>
      <td>{row.email}</td>
      <td>{row.providers.join(', ')}</td>
      <td>{row.customers.map(c => c.name).join(', ')}</td>
    </tr>
  );
}
```

This is typically used within a parent component that queries a `DirectoryAccount` and spreads the `accountRowFields_account` fragment, then passes the resulting fragment reference to `toAccountRow` to render consistent row data alongside merged-person rows elsewhere in the Users list.
