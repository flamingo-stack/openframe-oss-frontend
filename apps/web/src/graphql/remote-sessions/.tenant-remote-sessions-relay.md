# tenant-remote-sessions-relay.ts

Defines the GraphQL/Relay fragments and queries that power the tenant-wide **Remote Sessions** tab on the Devices page, including the paginated session list and a live-polling query for in-progress sessions.

## Key Components

- **`tenantRemoteSessionsRelayRowFragment`** (`tenantRemoteSessionsRelay_row`) — Inline fragment for a single `RemoteSession` row. Pulls in the session recording data (`sessionRecordingsApiService_session`) plus the device's `machineId`, `displayName`, `hostname`, and the customer logo fragment (`sessionRecordingsApiService_deviceCustomer`). Shared between the paged list and the live poll so rows render identically regardless of source.

- **`tenantRemoteSessionsRelayQuery`** (`tenantRemoteSessionsRelayQuery`) — Entry query accepting `$filter`, `$sort`, `$first`, and `$after` variables, delegating to the refetchable query fragment below.

- **`tenantRemoteSessionsRelayFragment`** (`tenantRemoteSessionsRelay_query`) — Refetchable fragment (generates `tenantRemoteSessionsRelayPaginationQuery`) exposing a `@connection`-annotated `remoteSessions` field keyed by `filter` and `sort`. Supports cursor-based pagination; changing `filter` or `sort` starts a fresh connection (no `after` reuse across variable sets). The first page surfaces running sessions first (capped at 100, newest first).

- **`tenantRemoteSessionsRelayLiveQuery`** (`tenantRemoteSessionsRelayLiveQuery`) — Lightweight query for polling only `LIVE` sessions (via `$filter.recordingState: LIVE`). No `first`/pagination since the server already bounds the active set to 100 and never paginates it.

## Usage Example

```typescript
import { useLazyLoadQuery, usePaginationFragment } from 'react-relay';
import {
  tenantRemoteSessionsRelayQuery,
  tenantRemoteSessionsRelayFragment,
  tenantRemoteSessionsRelayLiveQuery,
} from './tenant-remote-sessions-relay';

// Initial paginated load
const queryData = useLazyLoadQuery(tenantRemoteSessionsRelayQuery, {
  filter: { customerIds: ['cust-1'] },
  sort: { field: 'START_TIME', direction: 'DESC' },
  first: 20,
});

// Pagination
const { data, loadNext, hasNext } = usePaginationFragment(
  tenantRemoteSessionsRelayFragment,
  queryData
);

// Poll live sessions separately
const liveData = useLazyLoadQuery(tenantRemoteSessionsRelayLiveQuery, {
  filter: { recordingState: 'LIVE' },
});
```

**Note:** Changing `filter` or `sort` resets pagination—do not reuse an `after` cursor across different variable sets.
