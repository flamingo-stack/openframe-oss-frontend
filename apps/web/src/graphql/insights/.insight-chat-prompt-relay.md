Defines a Relay GraphQL query for fetching the AI chat prompt text associated with a specific insight, used to power the "Fix with Mingo" feature.

## Key Components

- **`insightChatPromptRelayQuery`** — A `graphql` tagged query (via `react-relay`) named `insightChatPromptRelayQuery` that accepts an `$id: ID!` variable and returns the `insightChatPrompt` field (the server-generated prompt string, including `@insight:` / `@device:` markers and a short ask) for that insight.

## Usage Example

This query is designed to be executed imperatively via `fetchQuery` at click-time (e.g., when a user clicks "Fix with Mingo"), rather than being rendered reactively from a list/row component. This ensures the fetched prompt always reflects the current stored insight id and server-side ask text.

```typescript
import { fetchQuery, useRelayEnvironment } from 'react-relay';
import { insightChatPromptRelayQuery } from './insight-chat-prompt-relay';

function useFixWithMingo(insightId: string) {
  const environment = useRelayEnvironment();

  const handleFixWithMingo = async () => {
    const data = await fetchQuery(
      environment,
      insightChatPromptRelayQuery,
      { id: insightId }
    ).toPromise();

    const prompt = data?.insightChatPrompt;
    if (prompt) {
      // Open a new chat session pre-filled with `prompt`
      openNewChat(prompt);
    }
  };

  return handleFixWithMingo;
}
```

**Note:** Fetching on-demand (instead of embedding this query in a fragment on the insight row) guarantees the prompt is never stale, since the marker and ask text are generated fresh by the server at request time.
