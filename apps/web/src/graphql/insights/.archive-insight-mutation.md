Defines a Relay GraphQL mutation for archiving an insight, transitioning its status from `resolved` to `archived`.

## Key Components

- **`archiveInsightMutation`** — A Relay `graphql` tagged template literal representing the `archiveInsight` mutation. It accepts an `InsightIdInput!` input and returns the updated insight's `id`, `status`, and `snoozedUntil` fields.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { archiveInsightMutation } from './archive-insight-mutation';

function useArchiveInsight() {
  const [commit, isInFlight] = useMutation(archiveInsightMutation);

  const archiveInsight = (insightId: string) => {
    commit({
      variables: {
        input: { id: insightId },
      },
      onCompleted: (response) => {
        console.log('Insight archived:', response.archiveInsight.status);
      },
      onError: (error) => {
        console.error('Failed to archive insight:', error);
      },
    });
  };

  return { archiveInsight, isInFlight };
}
```

## Notes

- This mutation is typically used alongside related insight-status mutations (e.g., `acknowledgeInsightMutation`) that share a similar payload shape (`id`, `status`, `snoozedUntil`).
- The `status` field in the response should reflect the transition to `archived`, allowing UI components to update optimistically or re-render based on the new state.
- Ensure the corresponding GraphQL schema defines `InsightIdInput` and the `archiveInsight` field on the mutation root before using this in production.
