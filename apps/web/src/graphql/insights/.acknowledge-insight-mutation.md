# acknowledge-insight-mutation.ts

Defines a GraphQL Relay mutation that transitions an Insight record from `new` or `snoozed` status to `acknowledged`.

## Key Components

- **`acknowledgeInsightMutation`** — A `graphql` tagged template exporting the `acknowledgeInsight` mutation. It accepts an `InsightIdInput!` and returns the updated `id`, `status`, and `snoozedUntil` fields.

The mutation relies on Relay's normalized store: because the returned fields match the existing Insight record's identity (`id`), Relay automatically merges the response into the store. Any component — list rows, detail headers — subscribed to that record re-renders in place, without requiring a manual refetch or connection updater.

Valid status transitions (e.g., which statuses can legally become `acknowledged`) are enforced client-side by `transitionsFrom` in `incidents/utils/incident-labels.ts`, which mirrors the backend's validation logic.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { acknowledgeInsightMutation } from './acknowledge-insight-mutation';

function useAcknowledgeInsight() {
  const [commit, isInFlight] = useMutation(acknowledgeInsightMutation);

  const acknowledge = (insightId: string) => {
    commit({
      variables: {
        input: { id: insightId },
      },
      onCompleted: (response) => {
        console.log('Acknowledged:', response.acknowledgeInsight.status);
      },
      onError: (error) => {
        console.error('Failed to acknowledge insight:', error);
      },
    });
  };

  return { acknowledge, isInFlight };
}
```

Typically invoked from an action button on an Insight card or detail view, guarded by a check against `transitionsFrom(currentStatus)` to ensure the transition is valid before committing.
