Defines a GraphQL mutation for updating the text content of an existing insight note, restricted to the note's original author. The mutation is declared using `react-relay`'s `graphql` tagged template so Relay's compiler can generate the corresponding typed artifacts.

## Key Components

- **`updateInsightNoteMutation`** — Exported GraphQL mutation document that sends an `UpdateInsightNoteInput` to the `updateInsightNote` field and requests the updated `id`, `content`, and `updatedAt` fields in response.
- **`UpdateInsightNoteInput`** — Server-defined input type (not declared here) expected to include the note identifier and new content.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { updateInsightNoteMutation } from './update-insight-note-mutation';

function useUpdateInsightNote() {
  const [commit, isInFlight] = useMutation(updateInsightNoteMutation);

  const updateNote = (noteId: string, content: string) => {
    commit({
      variables: {
        input: {
          id: noteId,
          content,
        },
      },
      onCompleted: (response) => {
        console.log('Updated note:', response.updateInsightNote);
      },
      onError: (error) => {
        console.error('Failed to update note:', error);
      },
    });
  };

  return { updateNote, isInFlight };
}
```

Because Relay normalizes the response using the returned `id`, any component displaying this note's `content` or `updatedAt` will automatically re-render with the latest data once the mutation completes.
