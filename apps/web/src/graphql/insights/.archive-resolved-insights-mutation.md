This file defines a GraphQL mutation for bulk-archiving all resolved incidents belonging to the current tenant, using Relay's `graphql` tagged template literal.

## Key Components

- **`archiveResolvedInsightsMutation`** — A Relay GraphQL mutation document that invokes the `archiveResolvedInsights` server-side mutation field. It takes no input variables and returns the count of insights that were archived.

## Usage Example

Since this mutation does not update any records in the Relay store automatically, the caller is responsible for refetching the affected insight lists after it completes:

```typescript
import { useMutation } from 'react-relay';
import { archiveResolvedInsightsMutation } from './archive-resolved-insights-mutation';

function useArchiveResolvedInsights() {
  const [commit, isInFlight] = useMutation(archiveResolvedInsightsMutation);

  const archiveAll = (onCompleted: (archivedCount: number) => void) => {
    commit({
      variables: {},
      onCompleted: (response) => {
        onCompleted(response.archiveResolvedInsights);
        // Refetch the insights list here, since the store
        // was not updated by this mutation.
      },
      onError: (error) => {
        console.error('Failed to archive resolved insights:', error);
      },
    });
  };

  return { archiveAll, isInFlight };
}
```

## Notes

- This mutation affects **all** resolved incidents for the tenant, not just those currently rendered in the UI.
- Because no store updates are performed (no `updater` function), consumers must manually trigger a refetch of any insight queries to reflect the archived state in the UI.
