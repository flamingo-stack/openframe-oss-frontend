Defines the GraphQL Relay query and refetchable fragment used to fetch a paginated, newest-first list of notes for a single incident, loaded separately from the incident detail query.

## Key Components

- **`incidentNotesRelayQuery`** — Root Relay query accepting `insightId`, `first`, and `after`, used to initially load the notes connection alongside the incident detail query.
- **`incidentNotesRelayFragment`** — A `@refetchable` fragment (`incidentNotesRelay_query`) on `Query` that defines the `insightNotes` connection (`@connection` key: `incidentNotesRelay_insightNotes`), generating a paginated `incidentNotesRelayPaginationQuery` for infinite scroll / "load more" UX.

Each note node exposes:
- `id`, `content`, `createdAt`
- `authorId` — the raw `User.id` the note was authored under, used to compare against the signed-in user's id to determine edit permissions
- `author` — spreads `userSummaryFields_user` for display (name, avatar, etc.), where `author.id` is the opaque Relay node handle (distinct from `authorId`)

## Usage Example

```typescript
import { useLazyLoadQuery, usePaginationFragment } from 'react-relay';
import {
  incidentNotesRelayQuery,
  incidentNotesRelayFragment,
} from './incident-notes-relay';

function IncidentNotesList({ insightId, currentUserId }: { insightId: string; currentUserId: string }) {
  const queryData = useLazyLoadQuery(incidentNotesRelayQuery, {
    insightId,
    first: 50,
  });

  const { data, loadNext, hasNext } = usePaginationFragment(
    incidentNotesRelayFragment,
    queryData,
  );

  return (
    <div>
      {data.insightNotes.edges.map(({ node }) => (
        <div key={node.id}>
          <p>{node.content}</p>
          {node.authorId === currentUserId && <button>Edit</button>}
        </div>
      ))}
      {hasNext && <button onClick={() => loadNext(50)}>Load more</button>}
    </div>
  );
}
```

See the [Relay documentation](https://relay.dev/docs/guided-tour/list-data/pagination/) for more on `@refetchable` and pagination fragments.
