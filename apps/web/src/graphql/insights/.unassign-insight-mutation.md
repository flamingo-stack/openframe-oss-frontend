Defines a GraphQL mutation for unassigning the current assignee from an insight, built using Relay's `graphql` tagged template literal.

## Key Components

- **`unassignInsightMutation`** — A Relay GraphQL mutation document that calls the `unassignInsight` server mutation, accepting an `InsightIdInput!` and returning the updated insight's `id`, `assigneeId`, and nested `assignee.id` (which will be `null` after unassignment).

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { unassignInsightMutation } from './unassign-insight-mutation';

function InsightAssigneeControl({ insightId }: { insightId: string }) {
  const [commit, isInFlight] = useMutation(unassignInsightMutation);

  const handleUnassign = () => {
    commit({
      variables: {
        input: { id: insightId },
      },
      onCompleted: (response) => {
        console.log('Unassigned:', response.unassignInsight.id);
      },
      onError: (error) => {
        console.error('Failed to unassign insight:', error);
      },
    });
  };

  return (
    <button onClick={handleUnassign} disabled={isInFlight}>
      Remove Assignee
    </button>
  );
}
```

## Notes

- This mutation pairs with `assignInsightMutation`, sharing the same response shape (`id`, `assigneeId`, `assignee`) for consistent Relay store updates.
- After the mutation resolves, `assignee` will typically be `null`, allowing the UI to reflect the unassigned state immediately via Relay's normalized cache.
- Requires the `InsightIdInput!` GraphQL input type to be defined in the schema, containing at minimum the insight's `id`.
