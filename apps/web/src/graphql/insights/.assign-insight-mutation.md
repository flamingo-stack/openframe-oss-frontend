# assign-insight-mutation.ts

Defines a GraphQL Relay mutation for assigning an incident/insight to a single technician, replacing any existing assignee regardless of the insight's current status.

## Key Components

- **`assignInsightMutation`** — A `graphql` tagged template literal (via `react-relay`) representing the `assignInsight` GraphQL mutation. It:
  - Accepts an `AssignInsightInput!` input object.
  - Returns the updated insight's `id`, `assigneeId`, and the `assignee` object.
  - Spreads the `userSummaryFields_user` fragment on `assignee` to pull in standard user summary fields (name, avatar, etc.) used elsewhere in the UI.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { assignInsightMutation } from './assign-insight-mutation';

function useAssignInsight() {
  const [commit, isInFlight] = useMutation(assignInsightMutation);

  const assignToTechnician = (insightId: string, assigneeId: string) => {
    commit({
      variables: {
        input: {
          insightId,
          assigneeId,
        },
      },
      onCompleted: (response) => {
        console.log('Assigned to:', response.assignInsight.assignee);
      },
      onError: (error) => {
        console.error('Assignment failed:', error);
      },
    });
  };

  return { assignToTechnician, isInFlight };
}
```

This mutation is typically invoked from incident/insight detail views where a user selects a technician from an assignment dropdown, immediately reflecting the new assignee in the UI via Relay's normalized store updates.
