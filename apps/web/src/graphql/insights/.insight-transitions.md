# insight-transitions.ts

Defines a GraphQL `@inline` fragment that fetches the server-authoritative status-transition table for insights, ensuring UI components (row menus, detail headers) only offer status changes the backend will actually accept.

## Key Components

- **`insightTransitionsFragment`** — An `@inline` GraphQL fragment (`insightTransitions_query`) on `Query` that retrieves `insightStatusTransitions`, a list of `{ from, to }` pairs describing valid status transitions.

This fragment is designed to be spread into existing list/detail queries that are already in flight, avoiding an extra network round trip. Because it's `@inline`, its data can be read synchronously by plain (non-component) functions such as `toTransitionTable`, rather than requiring a React Relay hook.

## Usage Example

```typescript
import { readInlineData, graphql } from 'react-relay';
import { insightTransitionsFragment } from './insight-transitions';

// Spread into a parent query
const query = graphql`
  query SomeInsightQuery {
    ...insightTransitions_query
    insightList {
      id
      status
    }
  }
`;

// Elsewhere, read the inline fragment data and build a lookup table
function toTransitionTable(queryRef: any): Map<string, string[]> {
  const data = readInlineData(
    graphql`
      fragment insightTransitions_query on Query @inline {
        insightStatusTransitions {
          from
          to
        }
      }
    `,
    queryRef
  );

  const table = new Map<string, string[]>();
  data.insightStatusTransitions.forEach(({ from, to }) => {
    if (!table.has(from)) table.set(from, []);
    table.get(from)!.push(to);
  });
  return table;
}

// Use the table to filter available actions in a status menu
const allowedNextStatuses = toTransitionTable(queryRef).get(currentStatus) ?? [];
```
