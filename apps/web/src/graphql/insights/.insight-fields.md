## insight-fields.ts

Defines a GraphQL inline fragment used to fetch the detailed representation of an `Insight` entity via Relay. It builds on top of a lighter-weight row fragment, adding fields that are only needed when rendering the full insight detail view.

## Key Components

- **`insightFieldsFragment`** — A Relay `@inline` GraphQL fragment (`insightFields_insight`) defined on the `Insight` type. It:
  - Spreads `insightRowFields_insight` (the base "row" fields used in list/summary views).
  - Adds detail-only fields: `description`, `interval`, and `queryResult` (osquery evidence) from the detecting query.
  - Includes the related `organization.image` (`imageUrl`, `hash`) for rendering the customer's logo.

This fragment represents "step 2" of an insight field ladder, extending the minimal row-level data with everything required for a detail page.

## Usage Example

```typescript
import { readInlineData } from 'react-relay';
import { insightFieldsFragment } from './insight-fields';

function toIncident(insightRef: any) {
  const insight = readInlineData(insightFieldsFragment, insightRef);

  return {
    description: insight.description,
    interval: insight.interval,
    evidence: insight.queryResult,
    organizationLogo: insight.organization?.image?.imageUrl,
    // ...spread row-level fields from insightRowFields_insight
  };
}
```

This fragment is consumed by `toIncident` in `incidents/utils/incident-transform.ts`, where the raw GraphQL data is normalized into the shape expected by the incident detail UI.
