This file defines a GraphQL mutation for transitioning an insight's status back to `new` from `resolved` or `archived`, implemented using Relay's `graphql` tagged template literal.

## Key Components

- **`reopenInsightMutation`** — A Relay GraphQL mutation document that calls the `reopenInsight` field, accepting an `InsightIdInput!` and returning the updated insight's `id`, `status`, and `snoozedUntil` fields.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { reopenInsightMutation } from './reopen-insight-mutation';
import type { reopenInsightMutation as ReopenInsightMutationType } from './__generated__/reopenInsightMutation.graphql';

function ReopenInsightButton({ insightId }: { insightId: string }) {
  const [commit, isInFlight] = useMutation<ReopenInsightMutationType>(reopenInsightMutation);

  const handleReopen = () => {
    commit({
      variables: {
        input: { id: insightId },
      },
      onCompleted: (response) => {
        console.log('Reopened insight:', response.reopenInsight);
      },
      onError: (error) => {
        console.error('Failed to reopen insight:', error);
      },
    });
  };

  return (
    <button onClick={handleReopen} disabled={isInFlight}>
      Reopen Insight
    </button>
  );
}
```

## Notes

- This mutation reverses the effect of `acknowledgeInsightMutation`, moving an insight from `resolved` or `archived` back to `new` status.
- The `snoozedUntil` field is returned alongside `status` since reopening may affect or clear any existing snooze state.
- Relay's compiler generates the corresponding TypeScript types (`reopenInsightMutation.graphql.ts`) at build time based on this GraphQL document.
