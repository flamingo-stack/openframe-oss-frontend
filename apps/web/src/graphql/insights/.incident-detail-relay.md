Defines the GraphQL query used by the incident details page to fetch a single insight and its related transition data via Relay.

## Key Components

- **`incidentDetailRelayQuery`** — A Relay-compiled GraphQL query that:
  - Accepts an `$id: ID!` variable identifying the insight/incident to fetch.
  - Queries `insight(id: $id)` and spreads the `insightFields_insight` fragment to retrieve the insight's core fields.
  - Spreads the `insightTransitions_query` fragment at the root query level to retrieve data needed for rendering available incident transitions (e.g., status changes).

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { incidentDetailRelayQuery } from './incident-detail-relay';
import type { incidentDetailRelayQuery as IncidentDetailRelayQueryType } from './__generated__/incidentDetailRelayQuery.graphql';

function IncidentDetailPage({ incidentId }: { incidentId: string }) {
  const data = useLazyLoadQuery<IncidentDetailRelayQueryType>(
    incidentDetailRelayQuery,
    { id: incidentId }
  );

  // `data.insight` is guaranteed non-null here; an unknown id throws
  // and is caught by the page's error boundary instead.
  return (
    <InsightDetails insightRef={data.insight} transitionsQueryRef={data} />
  );
}
```

**Note:** Because `insight(id:)` throws a GraphQL error for an unknown `id` rather than returning `null`, consuming components should rely on an error boundary (e.g., `ErrorBoundary` or Relay's `RelayEnvironmentProvider` error handling) to gracefully handle invalid incident IDs, rather than performing manual null checks.
