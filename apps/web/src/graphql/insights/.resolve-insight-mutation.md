Defines a GraphQL mutation for transitioning an insight from any open status to a `resolved` state, using Relay's `graphql` tagged template literal.

## Key Components

- **`resolveInsightMutation`** — A Relay GraphQL mutation document named `resolveInsightMutation` that:
  - Accepts an `InsightIdInput!` input containing the target insight's identifier.
  - Invokes the `resolveInsight` server mutation field.
  - Returns the updated insight's `id`, `status`, and `snoozedUntil` fields, allowing the Relay store to be updated in place after the mutation completes.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { resolveInsightMutation } from './resolve-insight-mutation';
import type { ResolveInsightMutation } from './__generated__/resolveInsightMutation.graphql';

function ResolveInsightButton({ insightId }: { insightId: string }) {
  const [commit, isInFlight] = useMutation<ResolveInsightMutation>(resolveInsightMutation);

  const handleResolve = () => {
    commit({
      variables: { input: { id: insightId } },
      onCompleted: (response) => {
        console.log('Resolved insight:', response.resolveInsight);
      },
      onError: (error) => {
        console.error('Failed to resolve insight:', error);
      },
    });
  };

  return (
    <button onClick={handleResolve} disabled={isInFlight}>
      Resolve
    </button>
  );
}
```

Note: this mutation works alongside `acknowledgeInsightMutation`, sharing a similar payload shape (`id`, `status`, `snoozedUntil`), but transitions the insight specifically to a `resolved` status regardless of its prior open state.
