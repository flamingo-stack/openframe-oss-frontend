Defines a Relay GraphQL mutation for adding a note to an insight, automatically prepending the newly created note to the top of a specified notes connection without requiring a manual store updater.

## Key Components

- **`addInsightNoteMutation`** — A `graphql` tagged template literal defining the `addInsightNoteMutation` GraphQL operation.
  - **Input:** `AddInsightNoteInput!` (mutation payload) and `connections: [ID!]!` (Relay connection IDs to update).
  - **Directive:** `@prependNode(connections: $connections, edgeTypeName: "InsightNoteEdge")` automatically inserts the new note at the top of the given connection(s), wrapped as an `InsightNoteEdge`, eliminating the need for a hand-written store updater function.
  - **Returned fields:** `id`, `content`, `authorId`, `author` (via the `userSummaryFields_user` fragment), and `createdAt`.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { ConnectionHandler } from 'relay-runtime';
import { addInsightNoteMutation } from './add-insight-note-mutation';

function useAddNote(insightId: string) {
  const [commit, isInFlight] = useMutation(addInsightNoteMutation);

  const addNote = (content: string) => {
    const connectionId = ConnectionHandler.getConnectionID(
      insightId,
      'InsightDetail_notes'
    );

    commit({
      variables: {
        input: { insightId, content },
        connections: [connectionId],
      },
    });
  };

  return { addNote, isInFlight };
}
```

The `connections` array must contain the Relay-generated connection ID(s) of the notes list(s) that should receive the newly prepended note. This is typically derived using `ConnectionHandler.getConnectionID` with the connection's key as defined in the corresponding fragment.
