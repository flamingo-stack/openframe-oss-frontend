Defines a Relay GraphQL mutation for deleting an author's note on an insight, using `@deleteEdge` to automatically prune the corresponding edge from the client-side Relay store.

## Key Components

- **`deleteInsightNoteMutation`** — A `graphql`-tagged Relay mutation document that:
  - Accepts an `InsightNoteIdInput!` identifying the note to delete and a `connections` array of Relay connection IDs to update.
  - Calls the `deleteInsightNote` field, which returns the deleted note's id.
  - Applies the `@deleteEdge(connections: $connections)` directive to remove the corresponding edge from the specified connection(s) without requiring a manual store update.

## Usage Example

```typescript
import { useMutation, ConnectionHandler } from 'react-relay';
import { deleteInsightNoteMutation } from './delete-insight-note-mutation';

function useDeleteNote(insightId: string) {
  const [commit, isInFlight] = useMutation(deleteInsightNoteMutation);

  const deleteNote = (noteId: string) => {
    const connectionId = ConnectionHandler.getConnectionID(
      insightId,
      'InsightNotesList_notes'
    );

    commit({
      variables: {
        input: { id: noteId },
        connections: [connectionId],
      },
    });
  };

  return { deleteNote, isInFlight };
}
```

## Notes

- This mutation only succeeds when the requesting user is the author of the note (server-enforced authorization).
- The `connections` array must match the Relay connection key(s) rendering the notes list so the UI updates automatically after deletion, without a manual `updater` function.
