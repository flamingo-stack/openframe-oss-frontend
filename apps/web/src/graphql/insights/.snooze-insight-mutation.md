Defines a Relay GraphQL mutation for snoozing an insight, transitioning its status from `new` or `acknowledged` to `snoozed` until a specified date/time.

## Key Components

- **`snoozeInsightMutation`** — A `graphql` tagged template literal (via `react-relay`) representing the `snoozeInsight` mutation. It accepts a `SnoozeInsightInput!` input object and returns the updated insight's `id`, `status`, and `snoozedUntil` fields.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { snoozeInsightMutation } from './snooze-insight-mutation';

function useSnoozeInsight() {
  const [commit, isInFlight] = useMutation(snoozeInsightMutation);

  const snoozeInsight = (insightId: string, until: string) => {
    commit({
      variables: {
        input: {
          id: insightId,
          until,
        },
      },
      onCompleted: (response) => {
        console.log('Insight snoozed:', response.snoozeInsight);
      },
      onError: (error) => {
        console.error('Failed to snooze insight:', error);
      },
    });
  };

  return { snoozeInsight, isInFlight };
}
```

## Notes

- This mutation is the counterpart to `acknowledgeInsightMutation`; both share a similar payload shape (`id`, `status`, and related timestamp fields).
- Ensure the Relay compiler has generated the corresponding TypeScript types for `SnoozeInsightInput` before using this mutation in components.
