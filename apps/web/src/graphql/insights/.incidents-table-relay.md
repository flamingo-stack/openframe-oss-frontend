# incidents-table-relay.ts

Defines the GraphQL Relay query and refetchable fragment powering the incidents table, including pagination, search, and faceted filtering over the `insights(...)` connection exposed by saas-api.

## Key Components

- **`incidentsTableRelayQuery`** — Root query that combines three concerns in a single round-trip:
  - Spreads `incidentsTableRelay_query` fragment (the paginated incident rows)
  - Fetches `insightFilters` (facet options via `insightFacets_filters` fragment) using the same `filter`/`search` arguments, so filter dropdowns stay in sync with the row results atomically
  - Spreads `insightTransitions_query` for related transition data
- **`incidentsTableRelayFragment`** — `@refetchable` fragment (`incidentsTableRelayPaginationQuery`) that defines the actual `insights` connection:
  - Uses `@connection` with key `incidentsTableRelay_insights`, keyed on `filter` and `search` arguments
  - Each edge spreads `insightRowFields_insight` plus a local `unreadNotificationCount` field (table-specific, not part of the shared row fragment)
  - Supports cursor-based pagination via `pageInfo { hasNextPage, endCursor }`

## Design Notes

- Facets (`insightFilters`) live on the **outer query**, not inside the `@refetchable` fragment, so calling `loadNext` for pagination does not re-trigger facet aggregation.
- The backend excludes each facet's own field when narrowing results, so a facet group's own options remain visible even as the user multi-selects within that same group.
- `filteredCount` (returned via the facets fragment) reflects the total count under the complete filter — used for the "N results" label in the UI.

## Usage Example

```typescript
import { useLazyLoadQuery, usePaginationFragment } from 'react-relay';
import {
  incidentsTableRelayQuery,
  incidentsTableRelayFragment,
} from './incidents-table-relay';

function IncidentsTable({ filter, search }: { filter: any; search: string }) {
  const data = useLazyLoadQuery(incidentsTableRelayQuery, {
    filter,
    search,
    first: 20,
  });

  const { data: paginated, loadNext, hasNext } = usePaginationFragment(
    incidentsTableRelayFragment,
    data
  );

  return (
    <>
      {paginated.insights.edges.map(({ node }) => (
        <IncidentRow key={node.__id} incident={node} />
      ))}
      {hasNext && <button onClick={() => loadNext(20)}>Load more</button>}
    </>
  );
}
```
