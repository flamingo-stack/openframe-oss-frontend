Defines a GraphQL mutation (via `react-relay`) that marks a user's onboarding flow as complete, returning the updated onboarding status fields.

## Key Components

- **`completeUserOnboardingMutation`** — A Relay-compiled GraphQL mutation document that invokes the `completeUserOnboarding` server mutation and requests back:
  - `completedSteps` — list of onboarding steps already completed
  - `completed` — boolean flag indicating overall completion
  - `completedAt` — timestamp when onboarding was completed
  - `skipped` — boolean flag indicating if onboarding was skipped
  - `skippedAt` — timestamp when onboarding was skipped
  - `tourDialogId` — identifier for the associated tour/dialog UI
  - `setupSeen` — boolean flag indicating whether the setup UI has been viewed

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { completeUserOnboardingMutation } from './complete-user-onboarding-mutation';

function OnboardingCompleteButton() {
  const [commit, isInFlight] = useMutation(completeUserOnboardingMutation);

  const handleComplete = () => {
    commit({
      variables: {},
      onCompleted: (response) => {
        console.log('Onboarding completed:', response.completeUserOnboarding);
      },
      onError: (error) => {
        console.error('Failed to complete onboarding:', error);
      },
    });
  };

  return (
    <button onClick={handleComplete} disabled={isInFlight}>
      Finish Onboarding
    </button>
  );
}
```

This mutation is typically triggered when a user finishes or dismisses the onboarding/tour flow, updating server-side state so the onboarding UI is not shown again on subsequent sessions.
