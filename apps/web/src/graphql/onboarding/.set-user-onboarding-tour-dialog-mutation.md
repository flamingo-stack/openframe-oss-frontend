Defines a GraphQL mutation (via `react-relay`) that marks a specific onboarding tour dialog as seen/completed for the current user, returning the updated onboarding progress state.

## Key Components

- **`setUserOnboardingTourDialogMutation`** — A Relay-compiled GraphQL mutation document generated by the `graphql` tagged template literal. It sends a `dialogId` to the `setUserOnboardingTourDialog` server mutation and requests back the resulting onboarding tour state:
  - `completedSteps` — list/count of steps completed
  - `completed` — whether the tour is fully completed
  - `completedAt` — timestamp of completion
  - `skipped` — whether the tour was skipped
  - `skippedAt` — timestamp of skip
  - `tourDialogId` — identifier of the dialog
  - `setupSeen` — whether the setup screen has been seen

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { setUserOnboardingTourDialogMutation } from './set-user-onboarding-tour-dialog-mutation';

function OnboardingDialog({ dialogId }: { dialogId: string }) {
  const [commit, isInFlight] = useMutation(setUserOnboardingTourDialogMutation);

  const handleDismiss = () => {
    commit({
      variables: { dialogId },
      onCompleted: (response) => {
        console.log('Updated onboarding state:', response.setUserOnboardingTourDialog);
      },
      onError: (err) => {
        console.error('Failed to update onboarding dialog state', err);
      },
    });
  };

  return (
    <button onClick={handleDismiss} disabled={isInFlight}>
      Dismiss
    </button>
  );
}
```

This mutation is typically triggered when a user completes, skips, or dismisses an onboarding tour step, keeping the backend in sync with the user's onboarding progress.
