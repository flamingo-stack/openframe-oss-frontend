# first-device-enrollment-relay.ts

Defines a GraphQL Relay query that fetches the most recently seen device along with its enrollment progress, used to power the setup wizard's "Deploy First Device" polling and completion check.

## Key Components

- **`firstDeviceEnrollmentRelayQuery`** — A `graphql` tagged query (via `react-relay`) that:
  - Queries `devices(first: 1, filter: $filter, sort: $sort)` to retrieve a single device.
  - Accepts `$filter` (`DeviceFilterInput`) and `$sort` (`SortInput`) variables, expected to sort by `lastSeen` descending so the newest device is returned.
  - Deliberately uses `devices` instead of `deviceFilters`, since the latter is backed by Pinot and can lag enrollment stage updates by several minutes.
  - Returns device identity fields (`id`, `machineId`, `hostname`, `displayName`, `status`) plus an `enrollment` object with `registeredAt`, `connectedAt`, `inventoryConnectedAt`, and `ready` — the exact signals the wizard polls to detect progress and the final "You are ready to go" state.

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { firstDeviceEnrollmentRelayQuery } from './first-device-enrollment-relay';

function DeployFirstDeviceStatus() {
  const data = useLazyLoadQuery(firstDeviceEnrollmentRelayQuery, {
    filter: {},
    sort: { field: 'LAST_SEEN', direction: 'DESC' },
  });

  const device = data.devices.edges[0]?.node;

  if (!device) {
    return <p>Waiting for first device to enroll…</p>;
  }

  return device.enrollment.ready ? (
    <p>You are ready to go — {device.displayName} enrolled successfully.</p>
  ) : (
    <p>Enrolling {device.hostname}: registered at {device.enrollment.registeredAt}</p>
  );
}
```

Typically used with a polling interval (e.g., `useLazyLoadQuery` combined with a refresh timer or `usePollingQuery` hook) so the UI updates as the device progresses through registration, connection, and inventory sync stages.
