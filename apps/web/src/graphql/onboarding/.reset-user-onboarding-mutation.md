Defines a Relay GraphQL mutation for resetting a user's onboarding state back to its initial values.

## Key Components

- **`resetUserOnboardingMutation`** — A tagged GraphQL mutation that calls `resetUserOnboarding` on the server and returns the updated onboarding status fields.

### Returned Fields

| Field | Description |
|---|---|
| `completedSteps` | List of onboarding steps that have been completed |
| `completed` | Whether onboarding is fully complete |
| `completedAt` | Timestamp of when onboarding was completed |
| `skipped` | Whether the user skipped onboarding |
| `skippedAt` | Timestamp of when onboarding was skipped |

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { resetUserOnboardingMutation } from './reset-user-onboarding-mutation';

function ResetOnboardingButton() {
  const [commitMutation, isInFlight] = useMutation(resetUserOnboardingMutation);

  const handleReset = () => {
    commitMutation({
      variables: {},
      onCompleted(response) {
        console.log('Onboarding reset:', response.resetUserOnboarding);
      },
      onError(error) {
        console.error('Reset failed:', error);
      },
    });
  };

  return <button onClick={handleReset} disabled={isInFlight}>Reset Onboarding</button>;
}
```
