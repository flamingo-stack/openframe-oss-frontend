Defines a GraphQL mutation using Relay to reset a user's onboarding progress, clearing completion/skip status and tour state.

## Key Components

- **`resetUserOnboardingMutation`** — A Relay `graphql` tagged mutation document that invokes the `resetUserOnboarding` server mutation and requests the updated onboarding fields in response:
  - `completedSteps` — list/count of onboarding steps completed
  - `completed` — boolean flag indicating full onboarding completion
  - `completedAt` — timestamp of completion
  - `skipped` — boolean flag indicating onboarding was skipped
  - `skippedAt` — timestamp of skip action
  - `tourDialogId` — identifier for the current/last tour dialog shown
  - `setupSeen` — boolean flag indicating whether the setup screen was viewed

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { resetUserOnboardingMutation } from './reset-user-onboarding-mutation';

function useResetOnboarding() {
  const [commit, isInFlight] = useMutation(resetUserOnboardingMutation);

  const resetOnboarding = () => {
    commit({
      variables: {},
      onCompleted: (response) => {
        console.log('Onboarding reset:', response.resetUserOnboarding);
      },
      onError: (error) => {
        console.error('Failed to reset onboarding:', error);
      },
    });
  };

  return { resetOnboarding, isInFlight };
}
```

This mutation is typically used when a user wants to restart the onboarding flow, such as from a settings or help menu, triggering the backend to clear prior onboarding state and returning the refreshed state for UI updates.
