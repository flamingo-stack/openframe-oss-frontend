Defines a Relay GraphQL mutation for marking a specific tenant onboarding step as complete and retrieving the updated onboarding progress state.

## Key Components

- **`completeTenantOnboardingStepMutation`** — A compiled Relay `graphql` mutation that calls `completeTenantOnboardingStep` with a required `TenantOnboardingStep` enum argument, returning the updated `completedSteps` array, overall `completed` flag, and `completedAt` timestamp.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { completeTenantOnboardingStepMutation } from './complete-tenant-onboarding-step-mutation';
import type { completeTenantOnboardingStepMutation as MutationType } from './__generated__/completeTenantOnboardingStepMutation.graphql';

function OnboardingStep() {
  const [commit, isInFlight] = useMutation<MutationType>(
    completeTenantOnboardingStepMutation
  );

  const handleComplete = () => {
    commit({
      variables: { step: 'CONNECT_PSA' },
      onCompleted(data) {
        const { completed, completedAt } = data.completeTenantOnboardingStep;
        console.log('Onboarding complete:', completed, completedAt);
      },
    });
  };

  return (
    <button onClick={handleComplete} disabled={isInFlight}>
      Mark Step Complete
    </button>
  );
}
```

## Notes

- The `step` variable must match a valid `TenantOnboardingStep` enum value defined in the GraphQL schema.
- The response payload includes `completedSteps` (array of completed step identifiers), `completed` (boolean), and `completedAt` (timestamp), which can be used to drive onboarding UI progress indicators.
