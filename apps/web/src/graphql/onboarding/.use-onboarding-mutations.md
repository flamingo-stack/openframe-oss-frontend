## useOnboardingMutations

Custom React hook that centralizes all GraphQL mutations for tenant and user onboarding flows in the OpenFrame frontend. It wraps each mutation with `commitMutation` (instead of the `useMutation` hook) so that completions survive component unmount and page navigation, synchronizes mutation results into the global onboarding store, and surfaces errors via toast notifications.

## Key Components

- **`useOnboardingMutations()`** — Primary hook export returning mutation callbacks and pending state.
- **`toTenant` / `toUser`** — Internal mappers that normalize GraphQL mutation payloads into `TenantOnboardingProgress` / `UserOnboardingProgress` store shapes.
- **Step completion mutations**: `completeTenantStep`, `completeUserStep` — awaited completions with loading state (`pending`) and optional `onSettled` callback; silent on success (no toast), errors toast.
- **Background ("fire-and-forget") mutations**: `completeTenantStepInBackground`, `completeUserStepInBackground`, `completeTenantInBackground`, `completeUserInBackground`, `setTourDialogInBackground`, `markSetupSeenInBackground` — do not block UI or affect the pending counter; used for navigation-triggered or passive completions.
- **`skipUser`** — Skips the user's onboarding flow, clears the Getting Started view state, and tracks pending state.
- **`pending`** — Numeric counter (via `useState`) indicating in-flight awaited mutations; exposed so callers can derive an `isMutating` boolean.
- **`onError`** — Internal factory producing a standardized error handler that decrements `pending` and shows a destructive toast.

## Usage Example

```typescript
import { useOnboardingMutations } from '@/path/to/use-onboarding-mutations';

function SetupStepButton({ step }: { step: TenantOnboardingStep }) {
  const { completeTenantStep, pending } = useOnboardingMutations();

  return (
    <button
      disabled={pending > 0}
      onClick={() => completeTenantStep(step, () => console.log('Step saved'))}
    >
      Mark Complete
    </button>
  );
}

// Fire-and-forget on navigation, no spinner needed
function GoToDevicesLink() {
  const { completeTenantStepInBackground } = useOnboardingMutations();

  return (
    <a href="/devices" onClick={() => completeTenantStepInBackground('ADD_DEVICE')}>
      Go to Devices
    </a>
  );
}
```

**Note:** This hook must be used within a Relay environment provider and requires `useAuthStore` and `useOnboardingStore` context to be available in the component tree.
