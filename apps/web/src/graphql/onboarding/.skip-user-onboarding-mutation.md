Defines a GraphQL mutation for skipping the user onboarding flow using `react-relay`, allowing the client to mark onboarding as skipped and retrieve the updated onboarding state.

## Key Components

- **`skipUserOnboardingMutation`** — A `graphql` tagged template literal that declares the `skipUserOnboarding` mutation. It requests the following fields in the response:
  - `completedSteps` — list/count of onboarding steps completed
  - `completed` — boolean flag indicating full completion
  - `completedAt` — timestamp of completion
  - `skipped` — boolean flag indicating the onboarding was skipped
  - `skippedAt` — timestamp of when it was skipped
  - `tourDialogId` — identifier for the associated tour dialog
  - `setupSeen` — boolean flag indicating whether setup has been viewed

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { skipUserOnboardingMutation } from './skip-user-onboarding-mutation';
import type { skipUserOnboardingMutation as SkipUserOnboardingMutationType } from './__generated__/skipUserOnboardingMutation.graphql';

function OnboardingSkipButton() {
  const [commit, isInFlight] = useMutation<SkipUserOnboardingMutationType>(
    skipUserOnboardingMutation
  );

  const handleSkip = () => {
    commit({
      variables: {},
      onCompleted: (response) => {
        console.log('Onboarding skipped:', response.skipUserOnboarding);
      },
      onError: (error) => {
        console.error('Failed to skip onboarding:', error);
      },
    });
  };

  return (
    <button onClick={handleSkip} disabled={isInFlight}>
      Skip Onboarding
    </button>
  );
}
```

This mutation is typically used in combination with the Relay compiler, which generates corresponding TypeScript types (for example, `skipUserOnboardingMutation.graphql.ts`) based on the GraphQL schema.
