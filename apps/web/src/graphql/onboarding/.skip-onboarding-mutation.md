Defines a Relay GraphQL mutation that allows skipping the onboarding flow, intended for development and QA environments only.

## Key Components

- **`skipOnboardingMutation`** — A `graphql` tagged template literal defining the `skipOnboarding` mutation, returning updated `tenant` and `user` onboarding state fields:
  - `tenant`: `completedSteps`, `completed`, `completedAt`
  - `user`: `completedSteps`, `completed`, `completedAt`, `skipped`, `skippedAt`, `tourDialogId`, `setupSeen`

**Important:** The `skipOnboarding` field only exists in the GraphQL schema when the `onboarding-skip` feature flag is enabled on the backend. Calling this mutation in environments where the flag is off will fail schema validation/codegen.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { skipOnboardingMutation } from './skip-onboarding-mutation';

function SkipOnboardingButton() {
  const [commit, isInFlight] = useMutation(skipOnboardingMutation);

  const handleSkip = () => {
    commit({
      variables: {},
      onCompleted: (response) => {
        console.log('Onboarding skipped:', response.skipOnboarding);
      },
      onError: (error) => {
        console.error('Failed to skip onboarding:', error);
      },
    });
  };

  return (
    <button onClick={handleSkip} disabled={isInFlight}>
      Skip Onboarding (Dev/QA only)
    </button>
  );
}
```

Ensure the `onboarding-skip` feature flag is enabled on the backend before invoking this mutation, otherwise Relay compiler codegen and runtime calls will fail.
