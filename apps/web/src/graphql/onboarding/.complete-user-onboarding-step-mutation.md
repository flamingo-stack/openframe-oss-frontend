Defines a Relay GraphQL mutation for marking a specific user onboarding step as completed, returning updated onboarding progress state.

## Key Components

- **`completeUserOnboardingStepMutation`** — A `graphql` tagged template literal (compiled by Relay) representing the `completeUserOnboardingStep` mutation. It accepts a required `step` argument of type `UserOnboardingStep` and returns the updated onboarding record, including:
  - `completedSteps` — list/count of steps completed so far
  - `completed` — whether the entire onboarding flow is complete
  - `completedAt` — timestamp of completion
  - `skipped` — whether onboarding was skipped
  - `skippedAt` — timestamp of skip, if applicable
  - `tourDialogId` — identifier for the active tour dialog
  - `setupSeen` — whether the setup UI has been viewed

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { completeUserOnboardingStepMutation } from './complete-user-onboarding-step-mutation';
import type { completeUserOnboardingStepMutation as CompleteUserOnboardingStepMutationType } from './__generated__/completeUserOnboardingStepMutation.graphql';

function useCompleteOnboardingStep() {
  const [commit, isInFlight] = useMutation<CompleteUserOnboardingStepMutationType>(
    completeUserOnboardingStepMutation
  );

  const completeStep = (step: CompleteUserOnboardingStepMutationType['variables']['step']) => {
    commit({
      variables: { step },
      onCompleted: (response) => {
        console.log('Onboarding progress:', response.completeUserOnboardingStep);
      },
      onError: (error) => {
        console.error('Failed to complete onboarding step:', error);
      },
    });
  };

  return { completeStep, isInFlight };
}
```

This mutation is typically invoked after a user finishes an interactive onboarding step (e.g., a product tour dialog) to persist progress and determine whether additional tour steps or setup prompts should be shown.
