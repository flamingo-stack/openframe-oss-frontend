# script-schedules-table-relay.ts

Defines the Relay GraphQL query and paginated fragment used to populate the Script Schedules table in the OpenFrame UI, including server-side search, filtering, and cursor-based pagination.

## Key Components

- **`scriptSchedulesTableRelayQuery`** — The root GraphQL query. Spreads the `scriptSchedulesTableRelay_query` fragment (passing `filter`, `search`, `sort`, `first`, `after` as arguments) and additionally fetches `scriptScheduleFilters` (currently only `platforms`: `value`, `label`, `count`) in the same round-trip so filter dropdown options stay in sync with the table rows.
- **`scriptSchedulesTableRelayFragment`** — A `@refetchable` fragment (`scriptSchedulesTableRelay_query`) on `Query`, generating `scriptSchedulesTableRelayPaginationQuery` for infinite-scroll pagination via `@connection(key: "scriptSchedulesTableRelay_scriptSchedules")`. Exposes `scriptSchedules` edges with fields: `id`, `name`, `description`, `supportedPlatforms`, `deviceCount`, `trigger`, `timeReference`, `startAt`, `repeat`, plus `filteredCount` and `pageInfo` (`hasNextPage`, `endCursor`).

**Design note:** `scriptScheduleFilters` lives on the outer query (not inside the refetchable fragment) so that `loadNext` pagination calls do not re-trigger a filter-facets refetch. `timeReference` tells consumers whether `startAt` is an absolute `SERVER` instant or a `DEVICE_LOCAL` time requiring per-device offset conversion.

## Usage Example

```typescript
import { usePaginationFragment, useLazyLoadQuery } from 'react-relay';
import {
  scriptSchedulesTableRelayQuery,
  scriptSchedulesTableRelayFragment,
} from './script-schedules-table-relay';

function ScriptSchedulesTable() {
  const queryData = useLazyLoadQuery(scriptSchedulesTableRelayQuery, {
    first: 20,
    search: '',
    filter: null,
    sort: null,
  });

  const { data, loadNext, hasNext } = usePaginationFragment(
    scriptSchedulesTableRelayFragment,
    queryData,
  );

  return (
    <div>
      {data.scriptSchedules.edges.map(({ node }) => (
        <div key={node.id}>{node.name}</div>
      ))}
      {hasNext && <button onClick={() => loadNext(20)}>Load more</button>}
    </div>
  );
}
```
