## unarchive-script-mutation.ts

Defines a GraphQL mutation (via Relay) that restores an archived script to `ACTIVE` status while keeping the Relay store consistent across both list and detail views.

## Key Components

- **`unarchiveScriptMutation`** — A `graphql` tagged mutation definition that:
  - Accepts an `$id` (the script to unarchive) and `$connections` (the Relay connection IDs representing the Archived list).
  - Applies `@deleteEdge(connections: $connections)` on the returned `id` field, which removes the script's edge from the Archived list connection immediately, without deleting the underlying `Script` record from the Relay store.
  - Requests the updated `status` field, which is written directly into the existing record. This ensures any mounted Details page for the script reflects the new status instantly, without requiring a refetch.

This design relies on the Active Scripts page using a `store-and-network` fetch policy, so it will pick up the newly active script on its next navigation/refetch rather than via local store updates.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { unarchiveScriptMutation } from './unarchive-script-mutation';

function useUnarchiveScript(connectionId: string) {
  const [commit, isInFlight] = useMutation(unarchiveScriptMutation);

  const unarchive = (scriptId: string) => {
    commit({
      variables: {
        id: scriptId,
        connections: [connectionId],
      },
    });
  };

  return { unarchive, isInFlight };
}
```

Related: see `archive-script-mutation.ts` for the inverse operation and the rationale for using `@deleteEdge` rather than `@deleteRecord`.
