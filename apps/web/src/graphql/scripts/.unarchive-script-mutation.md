Defines the Relay GraphQL mutation for restoring an archived script back to `ACTIVE` status, using `@deleteEdge` to remove it from the archived list's connection without deleting the underlying record.

## Key Components

- **`unarchiveScriptMutation`** — Relay `graphql` tagged template literal for the `unarchiveScript` mutation. Accepts `$id` (the script's ID) and `$connections` (the archived list's connection IDs), and applies `@deleteEdge` on the returned `id` to immediately remove the row from the archived view.

## Usage Example

```typescript
import { unarchiveScriptMutation } from './unarchive-script-mutation';
import { useMutation } from 'react-relay';

const [commitUnarchive, isInFlight] = useMutation(unarchiveScriptMutation);

commitUnarchive({
  variables: {
    id: scriptId,
    connections: [archivedConnectionId],
  },
});
```

## Behavior Notes

- **`@deleteEdge` vs `@deleteRecord`** — Only the edge is removed from the archived connection; the `Script` record itself remains in the Relay store and is fetchable by ID. The active scripts page will surface it on next navigation via `store-and-network` refetch.
- This is the inverse operation of `archive-script-mutation.ts`, which moves a script from the active list into the archived connection.
