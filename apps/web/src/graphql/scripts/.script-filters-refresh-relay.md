Defines a standalone Relay GraphQL query for imperatively refreshing script filter facets after list-membership mutations (archive/unarchive) without refetching the full script list.

## Key Components

- **`scriptFiltersRefreshRelayQuery`** – A `graphql` tagged template literal exporting a Relay query that fetches `scriptFilters(filter)` facet data for `shells`, `platforms`, and `authors` (each with `value`, `label`, and `count` fields).

## Usage Example

```typescript
import { fetchQuery, useRelayEnvironment } from 'react-relay';
import { scriptFiltersRefreshRelayQuery } from './script-filters-refresh-relay';

const environment = useRelayEnvironment();

// After an archive/unarchive mutation, refresh filter facets only
fetchQuery(environment, scriptFiltersRefreshRelayQuery, { filter }).subscribe({});
```

## Notes

This query mirrors the `scriptFilters(filter)` field shape used in `scriptsTableRelayQuery`, so `fetchQuery(...).subscribe({})` writes into the same Relay store records. This causes all mounted facet dropdown subscribers to re-render with updated options without triggering a full list refetch — which is redundant since `@deleteEdge` already handles the local list update.
