# execution-facets.ts

Defines the Relay GraphQL fragment that supplies the filter facets (status, initiator, machine) used to populate the column-level filter dropdowns in an Execution History table.

## Key Components

- **`executionFacetsFragment`** — A `@inline` GraphQL fragment named `executionFacets_filters` defined on the `ScriptExecutionFilters` type. It exposes three facet lists:
  - `statuses` — available status filter options
  - `initiators` — available initiator filter options
  - `machines` — available machine filter options

  Each facet entry includes `value`, `label`, and `count`, where `count` is the number of matching records shown next to the dropdown option.

Because both `scriptExecutionFilters` and `scheduleExecutionFilters` resolve to `ScriptExecutionFilters`, this single fragment is shared across both execution list queries, guaranteeing the dropdown option shape stays consistent. The `@inline` directive makes the fragment usable from a plain hook (e.g., `useExecutionFacetOptions`) rather than requiring a React component to spread it via `useFragment`.

## Usage Example

```typescript
import { readInlineData, graphql } from 'react-relay';
import { executionFacetsFragment } from './execution-facets';

function useExecutionFacetOptions(filtersRef: any) {
  const filters = readInlineData(
    graphql`
      fragment useExecutionFacetOptions_filters on ScriptExecutionFilters @inline {
        ...executionFacets_filters
      }
    `,
    filtersRef
  );

  return {
    statusOptions: filters.statuses.map((s) => ({
      label: `${s.label} (${s.count})`,
      value: s.value,
    })),
    initiatorOptions: filters.initiators.map((i) => ({
      label: `${i.label} (${i.count})`,
      value: i.value,
    })),
    machineOptions: filters.machines.map((m) => ({
      label: `${m.label} (${m.count})`,
      value: m.value,
    })),
  };
}
```
