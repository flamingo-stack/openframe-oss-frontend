Defines a Relay GraphQL mutation for dispatching ad-hoc commands to a device without persisting a script — used by the "Test Script" feature.

## Key Components

- **`runCommandMutation`** — A `graphql` tagged template literal defining the `runCommandMutation` Relay mutation. Accepts a `RunCommandInput!` variable and returns an `executionId` string.

## Behavior Notes

- **Fire-and-forget pattern**: Only an `executionId` is returned synchronously. Actual execution output is delivered asynchronously via Logs or Notifications — there is no inline result in the response.
- **No persistence**: Designed for testing a script body on a device without saving it first.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { runCommandMutation } from './run-command-mutation';

function TestScriptButton({ deviceId, scriptBody }: Props) {
  const [commit, isInFlight] = useMutation(runCommandMutation);

  const handleTest = () => {
    commit({
      variables: {
        input: {
          deviceId,
          scriptBody,
        },
      },
      onCompleted(response) {
        const { executionId } = response.runCommand;
        // Poll logs or await notification for execution result
        console.log('Execution started:', executionId);
      },
      onError(error) {
        console.error('Command dispatch failed:', error);
      },
    });
  };

  return <button onClick={handleTest} disabled={isInFlight}>Test Script</button>;
}
```
