## schedule-executions-relay.ts

Defines the Relay GraphQL query and paginated fragment powering a schedule's execution-history table — the schedule-scoped counterpart to the per-script execution list, keyed by `scheduleId` instead of `scriptId`.

## Key Components

- **`scheduleExecutionsRelayQuery`** — Root query that fetches a page of executions for a given schedule plus the filter facets (`scheduleExecutionFilters`) needed to drive faceted search UI. Takes `scheduleId`, `filter`, `search`, `sort`, `first`, and `after` as arguments.
- **`scheduleExecutionsRelayFragment`** (`scheduleExecutionsRelay_query`) — `@refetchable` fragment exposing the `scheduleExecutions` connection (`@connection(key: "scheduleExecutionsRelay_scheduleExecutions")`), used with `usePaginationFragment`/`loadNext` for infinite scrolling. Generates `scheduleExecutionsRelayPaginationQuery`.

## Design Notes

- Rows reuse the shared `executionFields_execution` fragment (same table/columns as the per-script execution list), but additionally select `scriptName` — since a schedule can run multiple scripts, each row needs to identify which script it executed. The per-script view omits this field since it would just repeat the page title.
- `scheduleExecutionFilters` is placed on the **outer query**, not inside the `@refetchable` fragment, so that `loadNext` pagination calls never re-trigger a facet refetch.
- Facet narrowing excludes each facet's own group server-side, so selecting options within a group doesn't cause its own sibling options to disappear.
- `sort` and date-range `filter` values originate from the Execution column's calendar control, consistent with the per-script execution pair.

## Usage Example

```typescript
import { usePaginationFragment, useLazyLoadQuery } from 'react-relay';
import {
  scheduleExecutionsRelayQuery,
  scheduleExecutionsRelayFragment,
} from './schedule-executions-relay';

function ScheduleExecutionsTable({ scheduleId }: { scheduleId: string }) {
  const queryData = useLazyLoadQuery(scheduleExecutionsRelayQuery, {
    scheduleId,
    first: 20,
  });

  const { data, loadNext, hasNext } = usePaginationFragment(
    scheduleExecutionsRelayFragment,
    queryData,
  );

  return (
    <>
      {data.scheduleExecutions.edges.map(({ node }) => (
        <ExecutionRow key={node.id} execution={node} scriptName={node.scriptName} />
      ))}
      {hasNext && <button onClick={() => loadNext(20)}>Load more</button>}
    </>
  );
}
```
