# schedule-run-detail-relay.ts

Defines a GraphQL query for fetching a single schedule run's details, used on the Schedule Run Details page. Since the schema lacks a direct `scheduleRun(id)` field, the query resolves the record via the generic `node(id)` entry point and narrows the result to the `ScheduleRun` type using an inline fragment.

## Key Components

- **`scheduleRunDetailRelayQuery`** — A `graphql` tagged template literal (Relay query) that:
  - Accepts a required `$id: ID!` variable
  - Resolves through `node(id)` and narrows via `... on ScheduleRun`
  - Returns core run metadata: `id`, `executionId`, `scheduleId`, `status`, `totalMachineCount`, `respondedMachineCount`, `dispatchedAt`, `finishedAt`
  - Includes nested `initiator` fields (user who triggered the run): `id`, `firstName`, `lastName`, `email`, `status`, and `image` (`imageUrl`, `hash`)

Notably, `scheduleId` enables the Back navigation and scopes the list of related executions, while `executionId` is the key used to filter the execution list down to this specific run—since no dedicated single-run API exists.

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { scheduleRunDetailRelayQuery } from './schedule-run-detail-relay';
import type { scheduleRunDetailRelayQuery as ScheduleRunDetailRelayQueryType } from './__generated__/scheduleRunDetailRelayQuery.graphql';

function ScheduleRunDetailPage({ runId }: { runId: string }) {
  const data = useLazyLoadQuery<ScheduleRunDetailRelayQueryType>(
    scheduleRunDetailRelayQuery,
    { id: runId }
  );

  if (data.node?.__typename !== 'ScheduleRun') {
    return null;
  }

  const run = data.node;

  return (
    <div>
      <p>Status: {run.status}</p>
      <p>
        Responded: {run.respondedMachineCount} / {run.totalMachineCount}
      </p>
      <p>Initiated by: {run.initiator?.firstName} {run.initiator?.lastName}</p>
    </div>
  );
}
```

This query is typically paired with a separate execution list query, filtered using the returned `scheduleId` and `executionId`, to display related executions for the fire.
