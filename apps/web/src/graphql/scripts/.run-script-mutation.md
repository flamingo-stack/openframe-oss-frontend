Defines a Relay GraphQL mutation for executing a script and retrieving its execution ID.

## Key Components

- **`runScriptMutation`** — A Relay `graphql` tagged template literal that wraps the `runScript` mutation, accepting a `RunScriptInput` payload and returning an `executionId` on success.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { runScriptMutation } from './run-script-mutation';
import type { runScriptMutationMutation } from './__generated__/runScriptMutationMutation.graphql';

const [commitMutation, isInFlight] = useMutation<runScriptMutationMutation>(runScriptMutation);

commitMutation({
  variables: {
    input: {
      scriptId: 'script-123',
      deviceId: 'device-456',
    },
  },
  onCompleted(response) {
    console.log('Execution ID:', response.runScript.executionId);
  },
  onError(error) {
    console.error('Script execution failed:', error);
  },
});
```

## Notes

- The returned `executionId` can be used to poll or subscribe to execution status updates elsewhere in the application.
- Relay will auto-generate TypeScript types for this mutation under `__generated__/runScriptMutationMutation.graphql.ts`.
