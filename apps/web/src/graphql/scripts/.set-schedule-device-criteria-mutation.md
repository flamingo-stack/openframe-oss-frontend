# set-schedule-device-criteria-mutation.ts

Defines a GraphQL mutation (via `react-relay`) that switches a script schedule's device targeting mode to `CRITERIA` and replaces its stored rule in a single wholesale write.

## Key Components

- **`setScheduleDeviceCriteriaMutation`** — Relay `graphql` tagged mutation. Takes a `scheduleId` and a `criteria` input (`ScheduleDeviceCriteriaInput`), and returns the updated schedule's `id`, `deviceCount`, `selectionMode`, and the resolved `deviceCriteria` (`organizationIds`, `deviceTypes`, `osTypes`).

## Behavior Notes

- This mutation is **not a delta** and **not committed per interaction** — unlike adjacent device-assignment mutations that edit lists incrementally, this one replaces the entire targeting rule in one commit, triggered by an explicit Save action in the UI.
- Applying a criteria rule re-points the schedule at a *live, dynamic* device set (e.g., "every device matching X, including future registrations").
- The response payload includes `deviceCount` so the Relay store can update the schedule detail view in place, without a refetch.
- Switching a schedule back to `SPECIFIC` targeting is handled elsewhere, via `selectionMode` on `UpdateScriptScheduleInput` (see `use-schedule-selection-mode.ts`). That switch does not clear the stored criteria or join rows, so toggling back to `CRITERIA` later restores the prior rule.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { setScheduleDeviceCriteriaMutation } from './set-schedule-device-criteria-mutation';

function useSetDeviceCriteria() {
  const [commit, isInFlight] = useMutation(setScheduleDeviceCriteriaMutation);

  const saveCriteria = (scheduleId: string, criteria: {
    organizationIds: string[];
    deviceTypes: string[];
    osTypes: string[];
  }) => {
    commit({
      variables: { scheduleId, criteria },
      onCompleted: (data) => {
        console.log('New device count:', data.setScheduleDeviceCriteria.deviceCount);
      },
    });
  };

  return { saveCriteria, isInFlight };
}
```
