Defines the Relay GraphQL mutation for archiving a script by removing its edge from the active connection without deleting the underlying store record.

## Key Components

- **`archiveScriptMutation`** — Relay `graphql` tagged template defining the `archiveScript` mutation. Takes `$id` (the script to archive) and `$connections` (the Relay connection IDs from which the edge should be removed). Uses `@deleteEdge` on the returned `id` to surgically remove the row from the active list.

## Design Notes

The mutation deliberately uses `@deleteEdge` instead of `@deleteRecord` to avoid two known issues:

| Approach | Problem |
|---|---|
| `@deleteRecord` | Leaves a dangling `null`-node edge in the connection **and** allows a subsequent `script(id:)` fetch to re-create the record, causing the archived row to reappear in the active list |
| `@deleteEdge` | Removes only the connection edge — the Script record remains in the Relay store so detail pages and sidebar chat can still resolve it by ID, but the active list never re-shows it |

The Archived page uses `store-and-network` fetch policy and picks up the record on next navigation.

## Usage Example

```typescript
import { archiveScriptMutation } from './archive-script-mutation';
import { useMutation } from 'react-relay';

function useArchiveScript() {
  const [commit, isInFlight] = useMutation(archiveScriptMutation);

  return (scriptId: string, connectionIds: string[]) => {
    commit({
      variables: {
        id: scriptId,
        connections: connectionIds,
      },
    });
  };
}
```
