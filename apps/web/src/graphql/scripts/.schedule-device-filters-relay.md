## Overview

This file defines a Relay GraphQL query that resolves filter facets scoped to a specific schedule's device picker, rather than the tenant-wide device fleet. It exists to fix a mismatch where the picker previously used fleet-wide `deviceFilters`, causing irrelevant facet options (e.g., platforms not supported by the schedule) and incorrect counts in the Selected/Available tabs.

## Key Components

- **`scheduleDeviceFiltersRelayQuery`** — A `graphql` tagged query exported for use with Relay hooks (e.g., `useLazyLoadQuery`/`usePreloadedQuery`). It accepts:
  - `scheduleId: ID!` — the schedule to scope facets to
  - `filter: DeviceFilterInput` — optional filter criteria
  - `search: String` — optional search term
  - `available: Boolean!` / `assigned: Boolean!` — controls which of `availableDeviceFilters` / `assignedDeviceFilters` are resolved via `@include(if:)`, letting callers avoid paying for unused facet resolution
  - Spreads `...deviceFacetsFields_filters` fragment on both fields for shared facet rendering logic

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { scheduleDeviceFiltersRelayQuery } from './schedule-device-filters-relay';

function DevicePicker({ scheduleId, activeTab, filter, search }: Props) {
  // Both halves are requested together to avoid suspending on tab switch
  const data = useLazyLoadQuery(scheduleDeviceFiltersRelayQuery, {
    scheduleId,
    filter,
    search,
    available: true,
    assigned: true,
  });

  const facets =
    activeTab === 'available'
      ? data.scriptSchedule?.availableDeviceFilters
      : data.scriptSchedule?.assignedDeviceFilters;

  return <DeviceFacetsPanel filtersRef={facets} />;
}
```

**Note:** `tagKeys` currently returns empty from both fields (a backend limitation, documented upstream). Tag chip options should instead be sourced from the fleet-wide facets query — see `toDeviceFilters` for how that fallback is wired.
