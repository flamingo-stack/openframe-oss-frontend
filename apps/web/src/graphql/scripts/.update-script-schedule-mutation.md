Defines the Relay GraphQL mutation for fully replacing (PUT semantics) a script schedule's configuration.

## Key Components

- **`updateScriptScheduleMutation`** — A `graphql` tagged template literal that issues an `updateScriptSchedule` mutation, accepting an `UpdateScriptScheduleInput` and returning the complete updated schedule node.

## Returned Fields

The mutation selection mirrors `scriptScheduleDetailRelayQuery` so Relay can merge the updated node into the store by `id` immediately, avoiding a separate refetch on the detail page:

| Field | Description |
|---|---|
| `id`, `name`, `description` | Schedule identity and metadata |
| `supportedPlatforms`, `status` | Platform targeting and current schedule state |
| `deviceCount` | Number of devices targeted |
| `scripts[].id/name/shell` | Associated script identity and shell type |
| `scripts[].defaultTimeoutSeconds/defaultArgs` | Script execution defaults |
| `scripts[].envVars[].name/value` | Environment variable key-value pairs |

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { updateScriptScheduleMutation } from './update-script-schedule-mutation';
import type { updateScriptScheduleMutationVariables } from './__generated__/updateScriptScheduleMutation.graphql';

const [commit, isInFlight] = useMutation(updateScriptScheduleMutation);

commit({
  variables: {
    input: {
      id: 'schedule-123',
      name: 'Nightly Patch Run',
      status: 'ACTIVE',
      supportedPlatforms: ['WINDOWS'],
      scriptIds: ['script-456'],
    },
  } satisfies updateScriptScheduleMutationVariables,
  onCompleted: (response) => console.log('Updated:', response.updateScriptSchedule),
  onError: (error) => console.error('Mutation failed:', error),
});
```

> **Keep in sync:** If `scriptScheduleDetailRelayQuery` adds or removes fields, update this mutation's selection to match so Relay's store stays consistent.
