# update-script-schedule-mutation.ts

Defines a Relay GraphQL mutation that performs a full (PUT-style) replacement of a script schedule's editable fields, returning the complete updated node so Relay can merge it into the normalized store by `id`.

## Key Components

- **`updateScriptScheduleMutation`** — A `graphql` tagged template exporting the `updateScriptSchedule` mutation. It accepts an `UpdateScriptScheduleInput!` and selects all editable fields on the returned schedule, including:
  - Core metadata: `id`, `name`, `description`, `supportedPlatforms`, `status`, `deviceCount`
  - Scheduling fields: `trigger`, `offlineBehavior`, `reconnectWindowSeconds`, `timeReference`, `startAt`, `repeat`, `nextRunAt`, `lastRunAt`
  - Targeting fields: `selectionMode`, `deviceCriteria` (with `organizationIds`, `deviceTypes`, `osTypes`)
  - Script associations: `scripts` (with shell, platform, timeout, default args/env vars) and `scriptCustomParams` (per-script overrides)

This selection intentionally mirrors `scriptScheduleDetailRelayQuery` so the detail page can re-render immediately from the mutation payload without triggering a separate refetch.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { updateScriptScheduleMutation } from './update-script-schedule-mutation';

function useUpdateSchedule() {
  const [commit, isInFlight] = useMutation(updateScriptScheduleMutation);

  const updateSchedule = (scheduleId: string) => {
    commit({
      variables: {
        input: {
          id: scheduleId,
          name: 'Nightly Patch Run',
          startAt: '2024-06-01T02:00:00Z',
          timeReference: 'SERVER',
          selectionMode: 'SPECIFIC',
          // ...other required UpdateScriptScheduleInput fields
        },
      },
      onCompleted: (response) => {
        console.log('Updated schedule:', response.updateScriptSchedule);
      },
    });
  };

  return { updateSchedule, isInFlight };
}
```

**Note:** Keep this mutation's field selection synchronized with `scriptScheduleDetailRelayQuery` whenever new editable fields are added to the schedule schema.
