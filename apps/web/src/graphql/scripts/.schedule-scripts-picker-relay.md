Defines a Relay GraphQL query that powers the script autocomplete/picker used in the schedule create/edit form.

## Key Components

- **`scheduleScriptsPickerRelayQuery`** — A `graphql` tagged query (via `react-relay`) that fetches `ACTIVE` scripts filtered by:
  - `search` — free-text server-side name search
  - `platforms` — restricts results to the schedule's supported `OsType` values
  - `first` — pagination limit
  
  Each returned script node includes `id`, `name`, `supportedPlatforms`, `defaultTimeoutSeconds`, `defaultArgs`, and `envVars` (`name`, `value`, `secret`), which are used to pre-populate the schedule card's run-parameter fields once a script is selected.

This query is designed to be executed imperatively via Relay's `fetchQuery` (typically from a companion hook like `use-schedule-scripts-autocomplete`) rather than through a suspending hook, since the dropdown needs to refresh on every keystroke. Results are still normalized into the Relay store for consistency with the rest of the app.

## Usage Example

```typescript
import { fetchQuery, useRelayEnvironment } from 'react-relay';
import { scheduleScriptsPickerRelayQuery } from './schedule-scripts-picker-relay';
import type { OsType } from './__generated__/scheduleScriptsPickerRelayQuery.graphql';

function useScheduleScriptsAutocomplete(platforms: OsType[]) {
  const environment = useRelayEnvironment();

  const search = (searchText: string) =>
    fetchQuery(environment, scheduleScriptsPickerRelayQuery, {
      search: searchText,
      platforms,
      first: 20,
    }).toPromise();

  return { search };
}
```
