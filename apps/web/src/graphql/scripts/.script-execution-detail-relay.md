# script-execution-detail-relay.ts

Defines a GraphQL Relay query for fetching full details of a single script execution, used to power the execution-details page.

## Key Components

- **`scriptExecutionDetailRelayQuery`** — A `graphql` tagged template literal (Relay query) that:
  - Resolves a `ScriptExecution` node via the generic `node(id: ID!)` Relay entry point (since the schema lacks a dedicated `scriptExecution(id)` field), using an inline fragment `... on ScriptExecution` to narrow the type.
  - Fetches core execution metadata: `id`, `executionId`, `scriptId`, `scriptName`, `status`, `source`, `privilegeLevel`, timestamps (`dispatchedAt`, `statusChangedAt`, `finishedAt`), `executionTimeMs`, `exitCode`, `timedOut`, and output fields (`stdout`, `stderr`, `error`).
  - Includes nested `machine` details (identity, hostname, timezone, and parent `organization`).
  - Includes nested `initiator` details (user identity, status, and profile `image`).

## Usage Example

```typescript
import { useLazyLoadQuery } from 'react-relay';
import { scriptExecutionDetailRelayQuery } from './script-execution-detail-relay';
import type { scriptExecutionDetailRelayQuery as ScriptExecutionDetailRelayQueryType } from './__generated__/scriptExecutionDetailRelayQuery.graphql';

function ScriptExecutionDetail({ executionId }: { executionId: string }) {
  const data = useLazyLoadQuery<ScriptExecutionDetailRelayQueryType>(
    scriptExecutionDetailRelayQuery,
    { id: executionId }
  );

  if (data.node?.__typename !== 'ScriptExecution') {
    return <div>Execution not found</div>;
  }

  const execution = data.node;

  return (
    <div>
      <h2>{execution.scriptName}</h2>
      <p>Status: {execution.status}</p>
      <p>Machine: {execution.machine?.displayName}</p>
      <p>Initiated by: {execution.initiator?.firstName} {execution.initiator?.lastName}</p>
      <pre>{execution.stdout}</pre>
    </div>
  );
}
```
