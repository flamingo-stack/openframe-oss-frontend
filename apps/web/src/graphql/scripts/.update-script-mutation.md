Defines the Relay GraphQL mutation for updating an existing script, selecting all editable fields to ensure the Relay store is fully reconciled after a write.

## Key Components

- **`updateScriptMutation`** — A `graphql`-tagged Relay mutation that calls `updateScript(input: UpdateScriptInput!)` and returns the complete updated script node, including metadata, execution settings, tags, environment variables, and status.

## Field Selection Strategy

The mutation's selection set mirrors `scriptDetailRelayQuery` so Relay can merge the returned payload directly into the store by `id`. This avoids a stale UI state on the script detail page that would otherwise require waiting on a `store-and-network` refetch to pick up un-returned fields. If the detail query's fields change, this mutation selection must be updated in sync.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { updateScriptMutation } from './update-script-mutation';

const [commitUpdate, isInFlight] = useMutation(updateScriptMutation);

commitUpdate({
  variables: {
    input: {
      id: 'script-123',
      name: 'Deploy App',
      shell: 'BASH',
      scriptBody: 'echo "Hello World"',
      privilegeLevel: 'STANDARD',
      defaultTimeoutSeconds: 60,
      defaultArgs: '',
      supportedPlatforms: ['LINUX'],
      envVars: [{ name: 'ENV', value: 'prod', secret: false }],
      tags: [{ id: 'tag-1', key: 'env' }],
    },
  },
  onCompleted: (response) => console.log('Updated:', response),
  onError: (error) => console.error('Mutation failed:', error),
});
```
