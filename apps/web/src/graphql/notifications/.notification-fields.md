## notification-fields.ts

Defines a shared, inline GraphQL fragment that specifies the canonical set of fields retrieved for a single notification row, used by both the notification header drawer and the full notifications section.

## Key Components

- **`notificationFieldsFragment`** — A `graphql` tagged `@inline` fragment (`notificationFields_notification`) selecting the core notification fields: `id`, `severity`, `title`, `description`, `createdAt`, `read`, `status`, `category`, `type`, and `attributes`.

### Design notes
- **Single source of truth**: Previously duplicated across the drawer and section queries, risking drift where a new field was added in one place but not the other. Spreading this one fragment keeps both consumers structurally in sync.
- **`type` + `attributes` contract**: Notification facts are exposed via a flat `string -> string` map (`attributes`) keyed by a `type` discriminator, rather than a typed union. Entity ids live under fixed keys, so even notification types unknown to the current release can still navigate and auto-read correctly.
- **No `context` union**: The now-retired typed `context` field is intentionally excluded — a live push that omitted it previously caused Relay to receive an explicit `null` link, which Relay's store rejects, poisoning subsequent commits until reload.
- **`@inline` fragment**: Intended for consumption by `mapNotificationNode`, a plain mapping function (not a React component), feeding shared notification UI components.

## Usage Example

```typescript
import { graphql, readInlineData } from 'react-relay';
import { notificationFieldsFragment } from './notification-fields';

// Parent query/fragment spreads it in:
const notificationListFragment = graphql`
  fragment notificationList_notifications on NotificationConnection {
    edges {
      node {
        ...notificationFields_notification
      }
    }
  }
`;

// Consumer reads the inline data and maps to a view model
function mapNotificationNode(nodeRef: any) {
  const node = readInlineData(notificationFieldsFragment, nodeRef);
  return {
    id: node.id,
    title: node.title,
    isRead: node.read,
    entityId: node.attributes['entityId'],
  };
}
```
