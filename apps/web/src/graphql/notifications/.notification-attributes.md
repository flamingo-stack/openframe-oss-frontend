# notification-attributes.ts

Defines the flat notification contract (`type` + `attributes`) emitted by the backend spec catalog, along with type guards, attribute key constants, and parsing helpers for notification data. Intentionally free of Relay/GraphQL dependencies so it can run in contexts like cold-start push taps that have no Relay runtime.

## Key Components

- **`INCIDENT_DETECTED_TYPE`, `isIncidentNotificationType`, `isIncidentDetectedType`** — Identify the incident notification family (shared `INCIDENT_` prefix), distinguishing initial detection from status transitions.
- **`NEW_PERMISSIONS_REQUIRED_TYPE`, `DIRECTORY_CUSTOMER_DEACTIVATED_TYPE`, `DIRECTORY_RULE_VALUE_REMOVED_TYPE`** — Notification type constants for directory/permissions events.
- **`RECORDING_NOTIFICATION_TYPES`, `isRecordingNotificationType`, `isRecordingStorageNotificationType`** — Remote Sessions recording notification family and guards distinguishing per-recording vs. per-tenant storage notifications.
- **`NOTIFICATION_ATTR`** — Canonical map of attribute keys (e.g., `ticketId`, `insightSeverity`, `recordingId`, `connections`) this app reads from the backend's flat attribute payload.
- **`readConnectionIds(value)`** — Extracts ordered string ids from a JSON-encoded `connections` attribute, defensively returning `[]` on malformed input.
- **`readNotificationAttributes(value)`** — Narrows an untyped `attributes` scalar into a `Record<string, string>`, dropping non-string and empty-string values.
- **`isApprovalResolved(resolution)`** — Checks whether an `ApprovalResolution` is terminal (`APPROVED`/`REJECTED`/`CANCELLED`), explicitly excluding `PENDING`.
- **`normalizeToolCall(raw)` / `parseAttributeToolCalls(raw)`** — Defensively parse approval tool-call data from either notification attributes or chat-service responses into `ApprovalToolCallMeta`.
- Re-exports `isApprovalNotificationType`, `MINGO_APPROVAL_REQUEST_TYPE`, `TICKET_APPROVAL_REQUEST_TYPE` from `@flamingo-stack/openframe-frontend-core`.

## Usage Example

```typescript
import {
  readNotificationAttributes,
  isIncidentNotificationType,
  isRecordingNotificationType,
  NOTIFICATION_ATTR,
  isApprovalResolved,
} from './notification-attributes';

function handleNotification(type: string, rawAttributes: unknown) {
  const attrs = readNotificationAttributes(rawAttributes);

  if (isIncidentNotificationType(type)) {
    const severity = attrs[NOTIFICATION_ATTR.insightSeverity];
    console.log(`Incident severity: ${severity}`);
  }

  if (isRecordingNotificationType(type)) {
    const recordingId = attrs[NOTIFICATION_ATTR.recordingId];
    openRecording(recordingId);
  }

  if (attrs[NOTIFICATION_ATTR.resolution] && isApprovalResolved(attrs[NOTIFICATION_ATTR.resolution])) {
    markApprovalSettled();
  }
}
```
