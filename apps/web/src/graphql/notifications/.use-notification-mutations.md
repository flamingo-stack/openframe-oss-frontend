# use-notification-mutations.ts

A React hook that centralizes all notification-related Relay mutations (mark as read, mark all as read, mark entity-scoped as read, delete, delete all read), wiring up optimistic updaters, cache store updates, unread-count refreshes, and error toasts.

## Key Components

- **`NotificationMutation`** — union type identifying which mutation failed, passed to the `onError` callback (`'markRead' | 'markAllRead' | 'markEntityRead' | 'delete' | 'deleteAllRead'`).
- **`UseNotificationMutationsOptions`** — hook input: `filterPairs` (connection/filter pairs to update in the Relay store), and optional completion/error callbacks.
- **`useNotificationMutations(options)`** — the hook itself, returning:
  - `markRead(id)` — marks a single notification read, shows a toast on failure.
  - `autoMarkRead(id)` — silent variant of `markRead` for background/implicit reads (no toast; only logs a warning).
  - `markAllRead()` — marks all notifications read, with optimistic + store updater, refreshes global and per-entity unread counts.
  - `markEntityRead(entity)` — marks all notifications read for a given entity scope (`NotificationEntityScope`), refreshing that entity's unread count.
  - `removeNotification(id)` — deletes a single notification, refreshing unread counts for the affected entity.
  - `removeAllRead()` — deletes all read notifications.
  - `isMarkingAllRead`, `isMarkingEntityRead`, `isDeletingAllRead` — in-flight mutation booleans from `useMutation`.

Internally, it uses a `filterPairsRef` (updated in `useEffect`, not during render, to comply with `react-hooks/refs`) so mutation callbacks always read the latest `filterPairs` without needing to be recreated on every change.

## Usage Example

```typescript
import { useNotificationMutations } from './use-notification-mutations';

function NotificationList({ filterPairs }: { filterPairs: NotificationConnectionPair[] }) {
  const {
    markRead,
    markAllRead,
    removeNotification,
    isMarkingAllRead,
  } = useNotificationMutations({
    filterPairs,
    onError: (operation, err) => console.error(`${operation} failed`, err),
    onMarkAllReadCompleted: () => console.log('All notifications marked read'),
  });

  return (
    <div>
      <button onClick={markAllRead} disabled={isMarkingAllRead}>
        Mark All Read
      </button>
      <button onClick={() => markRead('notif-123')}>Mark Read</button>
      <button onClick={() => removeNotification('notif-123')}>Delete</button>
    </div>
  );
}
```
