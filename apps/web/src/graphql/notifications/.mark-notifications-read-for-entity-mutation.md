Defines a Relay GraphQL mutation that marks all notifications associated with a specific entity (identified by its type and ID) as read.

## Key Components

- **`markNotificationsReadForEntityMutation`** — A `graphql` tagged template exported as a Relay mutation definition. It accepts two required variables:
  - `entityType: NotificationEntityType!` — the type of entity (e.g., ticket, device, alert) the notifications belong to.
  - `entityId: ID!` — the unique identifier of that entity.
  
  The mutation calls `markNotificationsReadForEntity`, returning a boolean/scalar result indicating success.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { markNotificationsReadForEntityMutation } from './mark-notifications-read-for-entity-mutation';

function useMarkEntityNotificationsRead() {
  const [commit, isInFlight] = useMutation(markNotificationsReadForEntityMutation);

  const markAsRead = (entityType: string, entityId: string) => {
    commit({
      variables: { entityType, entityId },
      onCompleted: (response) => {
        console.log('Notifications marked as read:', response.markNotificationsReadForEntity);
      },
      onError: (error) => {
        console.error('Failed to mark notifications as read:', error);
      },
    });
  };

  return { markAsRead, isInFlight };
}
```

This is typically invoked when a user views or interacts with an entity (such as opening a device detail page or a ticket) to clear its associated unread notifications in bulk.
