Defines a GraphQL mutation for registering a device's push notification token with the backend, enabling the server to send push notifications to a specific device and platform.

## Key Components

- **`registerPushDeviceMutation`** - A `graphql` tagged template literal (via `react-relay`) that defines the `registerPushDevice` GraphQL mutation. It accepts:
  - `token: String!` - the device's push notification token (required)
  - `platform: PushPlatform!` - the platform enum (e.g., iOS/Android/web) (required)
  - `appVersion: String` - the client app version (optional)

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { registerPushDeviceMutation } from './register-push-device-mutation';
import type { registerPushDeviceMutation as RegisterPushDeviceMutationType } from './__generated__/registerPushDeviceMutation.graphql';

function useRegisterPushDevice() {
  const [commit, isInFlight] = useMutation<RegisterPushDeviceMutationType>(
    registerPushDeviceMutation
  );

  const register = (token: string, platform: 'IOS' | 'ANDROID' | 'WEB', appVersion?: string) => {
    commit({
      variables: { token, platform, appVersion },
      onCompleted: (response) => {
        console.log('Push device registered:', response.registerPushDevice);
      },
      onError: (error) => {
        console.error('Failed to register push device:', error);
      },
    });
  };

  return { register, isInFlight };
}
```

This mutation is typically invoked once a push notification token is obtained from the platform's push service (e.g., FCM or APNs), associating it with the current user session on the backend.
