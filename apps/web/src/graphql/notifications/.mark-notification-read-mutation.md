Defines a Relay GraphQL mutation for marking a single notification as read by its ID.

## Key Components

- **`markNotificationReadMutation`** — A compiled Relay `graphql` mutation that calls `markNotificationAsRead` on the server, accepting a notification `ID` and returning a boolean result.

## Usage Example

```typescript
import { markNotificationReadMutation } from './mark-notification-read-mutation';
import { useMutation } from 'react-relay';

function NotificationItem({ id }: { id: string }) {
  const [commit] = useMutation(markNotificationReadMutation);

  const handleRead = () => {
    commit({
      variables: { id },
      onCompleted: () => console.log('Notification marked as read'),
    });
  };

  return <button onClick={handleRead}>Mark as Read</button>;
}
```

## Notes

- The mutation accepts a single `$id: ID!` variable mapped to the `notificationId` argument.
