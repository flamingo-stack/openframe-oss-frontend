## notifications-helpers.ts

Relay store utilities for managing notification connections, read/unread state transitions, and per-category unread count badges. These helpers power optimistic updates and real-time event reconciliation for the notifications list and drawer, ensuring list membership and unread counts stay consistent across multiple scoped connections (global, per-entity) without requiring a refetch.

## Key Components

- **`NotificationEntityScope`** — identifies a notification scope (e.g., a device or incident) by raw backend entity type/id.
- **`parseNotificationEntityScope`** — validates a URL-provided entity type/id pair against the known `NotificationEntityType` enum.
- **`notificationsConnectionFilters`** / **`NotificationConnectionPair`** — build the `read`/`search`/`entity` filter variables used to resolve Relay connections, paired as unread + read variants.
- **`UNFILTERED_NOTIFICATION_PAIR`** — default connection pair with no search or entity scope.
- **`adjustUnreadCount`** / **`clearUnreadCounts`** — mutate the in-store `unreadCountsByCategory` root field to keep sidebar badges in sync.
- **`connectionHasNode`** — checks whether a connection already contains an edge for a given node (idempotency guard).
- **`setReadStatus`** — sets both `read` (boolean) and `status` (enum) fields on a notification record together.
- **`makeMarkReadUpdater`** — returns a Relay store updater that moves a single notification from unread to read/archived, decrementing counts and repositioning it by `createdAt`.
- **`makeMarkAllReadUpdater`** — bulk "mark all read" updater that drains unread connections, promotes archived rows to read, and zeroes all unread counts.
- **`makeMarkEntityReadUpdater`** — scoped "mark all complete" updater for a single entity (e.g., one device's notifications), delegating to `makeMarkReadUpdater` per loaded node.
- **`makeDeleteAllReadUpdater`** — (truncated) clears read notifications from connections.
- Re-exports from `./notification-attributes`: `isIncidentDetectedType`, `isApprovalNotificationType`, `parseAttributeToolCalls`, `readNotificationAttributes`, and related type-detection constants.

## Usage Example

```typescript
import {
  notificationsConnectionFilters,
  makeMarkReadUpdater,
  makeMarkEntityReadUpdater,
  UNFILTERED_NOTIFICATION_PAIR,
} from './notifications-helpers';

// Build connection filters for a drawer scoped to no entity
const pair = {
  unread: notificationsConnectionFilters(false, ''),
  read: notificationsConnectionFilters(true, ''),
};

// Mark one notification as read across unread/read connection pairs
commitLocalUpdate(environment, store => {
  makeMarkReadUpdater(notificationId, [pair, UNFILTERED_NOTIFICATION_PAIR])(store);
});

// Mark all notifications for one device as read
commitLocalUpdate(environment, store => {
  makeMarkEntityReadUpdater({ type: NotificationEntityType.MACHINE, id: machineId }, [pair])(store);
});
```

All updaters are designed to be **idempotent**—safe to re-run when the same mutation and its corresponding NATS-driven event both trigger a store update.
