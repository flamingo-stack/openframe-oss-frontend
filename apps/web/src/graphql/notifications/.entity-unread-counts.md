# entity-unread-counts.ts

Keeps the `unreadNotificationCount` field on `Machine` and `Insight` records in sync with the Relay store whenever notifications are pushed, read, or deleted. Rather than recomputing counts client-side, it re-fetches the authoritative count from the server for only the entities currently loaded in the store (so unloaded rows naturally refresh when they're next viewed).

## Key Components

- **`entityUnreadCountsMachinesQuery`** / **`entityUnreadCountsInsightQuery`** — GraphQL queries that re-fetch `unreadNotificationCount` for machines and insights respectively.
- **`NotificationEntityRefs`** — Interface describing the set of device/insight ids a batch of notifications refers to.
- **`entityRefsOfAttributes(attributeMaps)`** — Extracts device/insight ids from raw notification attribute maps (e.g., from a live push payload).
- **`entityRefsOfNotifications(environment, ids)`** — Resolves entity refs from notification records already present in the Relay store, keyed by their Relay ids.
- **`entityRefsOfEntity(type, id)`** — Builds a single-entity ref set, used when marking all notifications for one entity as read.
- **`refreshEntityUnreadCounts(environment, refs)`** — Re-fetches unread counts (network-only) for every loaded device/insight in `refs`; silently ignores fetch errors (best effort).
- **`clearEntityUnreadCounts(environment)`** — Locally sets every loaded entity's unread count to 0, used after a "mark all as read" action.

## Usage Example

```typescript
import {
  entityRefsOfAttributes,
  entityRefsOfEntity,
  refreshEntityUnreadCounts,
  clearEntityUnreadCounts,
} from './entity-unread-counts';
import { NotificationEntityType } from '@/generated/schema-enums';

// After a live notification push, refresh affected entities
const refs = entityRefsOfAttributes([pushedNotification.attributes]);
refreshEntityUnreadCounts(environment, refs);

// After marking all notifications for one device as read
const deviceRefs = entityRefsOfEntity(NotificationEntityType.DEVICE, deviceId);
refreshEntityUnreadCounts(environment, deviceRefs);

// After "mark all notifications as read"
clearEntityUnreadCounts(environment);
```

Used by notification-handling flows (sidebar counts, read/delete actions, live push handlers) that need the per-entity unread badge to stay accurate without a full page reload.
