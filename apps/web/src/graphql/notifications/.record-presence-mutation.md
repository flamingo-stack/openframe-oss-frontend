Defines a GraphQL mutation that notifies the server of the current user's active presence (e.g., for heartbeat/online-status tracking) using Relay.

## Key Components

- **`recordPresenceMutation`**: A Relay `graphql` tagged template exporting the compiled GraphQL mutation document. Executes the `recordPresence` server mutation, which takes no input arguments and returns a boolean/status field indicating success.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { recordPresenceMutation } from './record-presence-mutation';
import type { recordPresenceMutation as RecordPresenceMutationType } from './__generated__/recordPresenceMutation.graphql';

function usePresenceHeartbeat() {
  const [commit] = useMutation<RecordPresenceMutationType>(recordPresenceMutation);

  const sendHeartbeat = () => {
    commit({
      variables: {},
      onCompleted: () => {
        console.log('Presence recorded');
      },
      onError: (error) => {
        console.error('Failed to record presence', error);
      },
    });
  };

  return sendHeartbeat;
}
```

Typically invoked on an interval (e.g., every 30-60 seconds) or on user activity events to keep the backend aware that the client session is still active.
