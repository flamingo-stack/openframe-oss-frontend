Defines a Relay GraphQL mutation for cancelling a pending push notification by its notification ID.

## Key Components

- **`cancelPendingPushMutation`**: A Relay-compiled GraphQL mutation document that executes the `cancelPendingPush` server mutation, accepting a single required `notificationId` (`ObjectId`) argument and returning a boolean/scalar result indicating success.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { cancelPendingPushMutation } from './cancel-pending-push-mutation';

function usePendingPushCancellation() {
  const [commitCancelPush, isInFlight] = useMutation(cancelPendingPushMutation);

  const cancelPush = (notificationId: string) => {
    commitCancelPush({
      variables: { notificationId },
      onCompleted: () => {
        console.log('Pending push cancelled successfully');
      },
      onError: (error) => {
        console.error('Failed to cancel pending push:', error);
      },
    });
  };

  return { cancelPush, isInFlight };
}
```

## Notes

- This file only declares the GraphQL mutation; it must be paired with Relay's `useMutation` hook (or `commitMutation`) at the call site to actually trigger the request.
- Relay's compiler processes this `graphql` tagged template at build time to generate the corresponding query artifacts, so the schema must define a `cancelPendingPush` mutation accepting `notificationId: ObjectId!`.
