A client-side route protection component that restricts access to pages based on the current application mode, displaying an "Access restricted" message for disallowed routes instead of rendering the page content.

## Key Components

- **`RouteGuard`** — A React functional component that wraps page content and conditionally renders it based on route permissions.
  - **Props:** `children: React.ReactNode` — the content to render if the current route is allowed.
  - **Behavior:** Uses `usePathname()` from `next/navigation` to get the current path, then checks it against `isRouteAllowedInCurrentMode` (imported from `../lib/app-mode`). If the route is disallowed, it renders a centered "Access restricted" message instead of the children.

## Usage Example

```typescript
import { RouteGuard } from './components/route-guard';

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <RouteGuard>
      {children}
    </RouteGuard>
  );
}
```

This component is typically placed near the root of a layout or page to gate access to routes that may not be valid in certain build modes (e.g., static export configurations where only a subset of routes are enabled). It relies on `isRouteAllowedInCurrentMode` to centralize the logic determining which routes are accessible in the current app mode, keeping the guard itself purely presentational.
