# assignment-row.tsx

Renders a single assignment row within a target-based assignment editor, combining a multi-select autocomplete search field with a remove-row action button. It merges currently selected assignment references with live search results to ensure selected items remain visible even when not present in the latest search response.

## Key Components

- **`AssignmentRow`** — React component that renders a labeled row containing:
  - A multi-select `Autocomplete` field for searching and selecting assignment targets (e.g., policies, groups) of a given `targetType`.
  - A trash icon `Button` to remove the entire row via `onRemoveRow`.
- **`AssignmentRowProps`** — Props interface:
  - `targetType: AssignmentTargetType` — determines labels/config via `TARGET_CONFIG`.
  - `value: AssignmentRef[]` — currently selected assignment refs.
  - `onChange: (next: AssignmentRef[]) => void` — called when selection changes.
  - `onRemoveRow: () => void` — called when the trash button is clicked.
  - `disabled?: boolean` — disables both the search field and remove button.
  - `readOnly?: boolean` — disables editing the selection set (search is skipped), but the row can still be removed via the trash button.

Internally uses `useAssignmentSearch` to fetch options based on `searchInput` and `targetType`, and merges search results with already-selected values to avoid losing labels for selected items not returned by the search.

## Usage Example

```typescript
import { AssignmentRow } from './assignment-row';
import type { AssignmentRef } from './types';

function PolicyAssignments() {
  const [assignments, setAssignments] = useState<AssignmentRef[]>([]);

  return (
    <AssignmentRow
      targetType="POLICY"
      value={assignments}
      onChange={setAssignments}
      onRemoveRow={() => setAssignments([])}
      disabled={false}
      readOnly={false}
    />
  );
}
```

Typically rendered in a list managed by a parent component that tracks multiple rows per target type, each with its own `onRemoveRow` handler to delete that specific row from the list.
