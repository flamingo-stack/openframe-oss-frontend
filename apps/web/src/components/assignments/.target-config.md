Defines display metadata for each assignment target type used throughout the assignment UI (rows, menus, tabs, and pickers), centralizing labels and icons so target-related components stay consistent.

## Key Components

- **`IconProps`** — Interface describing the shape of icon components accepted by `TargetMeta` (extends `SVGProps<SVGSVGElement>` minus `width`/`height`, plus `className`, `size`, `color`).
- **`TargetMeta`** — Interface describing the display metadata for a single assignment target type:
  - `rowLabel` — label shown in the assigned-items row/list.
  - `menuLabel` — label shown in the "Assign Item" menu.
  - `tabLabel` — label shown in picker tabs.
  - `icon` — icon component rendered alongside the target.
  - `pickable` — UX flag indicating whether the target type can be selected via the picker (distinct from server-side `ASSIGNMENT_TARGET_TYPES` validity).
- **`TARGET_CONFIG`** — A `Record<AssignmentTargetType, TargetMeta>` mapping each target type (`ORGANIZATION`, `DEVICE`, `TICKET`, `KNOWLEDGE_ARTICLE`, `INSIGHT`) to its display metadata. `INSIGHT` is marked `pickable: false` since incidents are linked implicitly rather than chosen by the user.

## Usage Example

```typescript
import { TARGET_CONFIG } from './target-config';
import type { AssignmentTargetType } from './types';

function renderAssignmentRow(type: AssignmentTargetType) {
  const { rowLabel, icon: Icon } = TARGET_CONFIG[type];

  return (
    <div>
      <Icon size={16} />
      <span>{rowLabel}</span>
    </div>
  );
}

// Filter only pickable target types for the "Assign Item" menu
const pickableTargets = Object.entries(TARGET_CONFIG)
  .filter(([, meta]) => meta.pickable)
  .map(([type, meta]) => ({ type, label: meta.menuLabel }));
```
