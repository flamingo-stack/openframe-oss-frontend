Computes and applies the diff between two assignment states by issuing parallel GraphQL mutations for added and removed assignments, then exposes the operation as a React Query mutation hook.

## Key Components

| Export | Type | Description |
|---|---|---|
| `useApplyAssignmentsDiff` | Hook | React Query `useMutation` hook that runs the diff and invalidates `['assignments', 'assigned-items']` on success |
| `applyAssignmentsDiff` | Internal async fn | Core diff logic — compares `prev` vs `next` assignment sets per target type and fires `assignItem` / `unassignItem` GraphQL mutations in parallel |
| `ASSIGN_ITEM_MUTATION` | GraphQL string | Mutation to assign an item to a target |
| `UNASSIGN_ITEM_MUTATION` | GraphQL string | Mutation to unassign an item from a target |
| `ApplyAssignmentsDiffInput` | Interface | Input shape: `itemId`, `itemType`, `prev`, `next` |

## Usage Example

```typescript
import { useApplyAssignmentsDiff } from './apply-assignments-diff';

function TicketAssignmentEditor({ ticketId }: { ticketId: string }) {
  const { mutate, isPending } = useApplyAssignmentsDiff();

  const handleSave = (prev: AssignmentsValue, next: AssignmentsValue) => {
    mutate({
      itemId: ticketId,
      itemType: 'Ticket',
      prev,
      next,
    });
  };

  return <button disabled={isPending} onClick={() => handleSave(prev, next)}>Save</button>;
}
```

## Behavior Notes

- All assign/unassign mutations run **concurrently** via `Promise.all` — order is not guaranteed.
- IDs are normalized to Relay global IDs via `ensureGlobalId` before being sent to the API.
- Iterates over all `ASSIGNMENT_TARGET_TYPES` (e.g. users, groups) in a single pass.
- On success, invalidates both `assignments` and `assigned-items` query caches to trigger a refresh.
