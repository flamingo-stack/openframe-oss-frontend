## apply-assignments-diff.ts

Computes and applies the minimal set of GraphQL assign/unassign mutations needed to reconcile an item's previous and next assignment state across all assignment target types (e.g., groups, tags, policies).

## Key Components

- **`applyAssignmentsDiff(input)`** — Internal async function that diffs `prev` and `next` `AssignmentsValue` objects per `ASSIGNMENT_TARGET_TYPES`, issuing `assignItem` mutations for newly added target IDs and `unassignItem` mutations for removed ones. All resulting GraphQL calls run concurrently via `Promise.all`.
- **`ASSIGN_ITEM_MUTATION`** / **`UNASSIGN_ITEM_MUTATION`** — GraphQL mutation documents for assigning/unassigning an item to/from a target.
- **`useApplyAssignmentsDiff()`** — React Query `useMutation` hook wrapping `applyAssignmentsDiff`. On success, invalidates the `ASSIGNED_ITEMS_QUERY_KEY` query to refresh cached assignment data. On error, surfaces a destructive toast notification so failures in this half of a save operation aren't silent.

## Usage Example

```typescript
import { useApplyAssignmentsDiff } from './apply-assignments-diff';

function AssignmentsForm({ itemId, itemType, originalAssignments }: Props) {
  const { mutateAsync: applyDiff, isPending } = useApplyAssignmentsDiff();
  const [nextAssignments, setNextAssignments] = useState(originalAssignments);

  async function handleSave() {
    await applyDiff({
      itemId,
      itemType,
      prev: originalAssignments,
      next: nextAssignments,
    });
  }

  return (
    <button onClick={handleSave} disabled={isPending}>
      Save Assignments
    </button>
  );
}
```

Note: `itemId` and target IDs are normalized via `ensureGlobalId` before being sent to the API, so callers may pass either local or global IDs.
