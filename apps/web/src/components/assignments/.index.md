Barrel file that re-exports the public API of the assignments feature module, consolidating hooks, components, and schema utilities related to managing assigned items (e.g., policies, scripts, or packages assigned to targets) into a single importable entry point.

## Key Components

- **`useApplyAssignmentsDiff`** – Hook for computing and applying the diff between current and desired assignment states.
- **`assignedTargetIds`** – Utility/selector for extracting the IDs of currently assigned targets.
- **`AssignedItemsContent`, `AssignedItemsView`** – UI components for rendering the list/view of assigned items.
- **`AssignmentsField`** – Form field component for managing assignments within a form context.
- **`ASSIGNMENTS_DEFAULT`, `assignmentsSchema`** – Default values and validation schema for assignment data.
- **`ASSIGNED_ITEMS_QUERY_KEY`, `useAssignedItems`** – Query key constant and hook for fetching assigned items via data-fetching layer.
- **`useAssignmentSearch`** – Hook for searching/filtering assignable items (e.g., targets available for assignment).

## Usage Example

```typescript
import {
  AssignmentsField,
  useAssignedItems,
  useApplyAssignmentsDiff,
  assignmentsSchema,
  ASSIGNMENTS_DEFAULT,
} from '@/features/assignments';

function PolicyAssignmentsForm({ policyId }: { policyId: string }) {
  const { data: assignedItems } = useAssignedItems(policyId);
  const applyDiff = useApplyAssignmentsDiff();

  const handleSubmit = async (values: typeof ASSIGNMENTS_DEFAULT) => {
    const parsed = assignmentsSchema.parse(values);
    await applyDiff(policyId, parsed);
  };

  return (
    <AssignmentsField
      defaultValue={ASSIGNMENTS_DEFAULT}
      currentAssignments={assignedItems}
      onSubmit={handleSubmit}
    />
  );
}
```

Importing from this index file (`./assignments`) keeps consumer code decoupled from the internal file structure of the assignments module.
