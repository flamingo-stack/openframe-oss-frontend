Defines the Zod validation schema for the `AssignmentsValue` structure, used to validate assignment references grouped by entity type (organizations, devices, tickets, etc.).

## Key Components

- **`assignmentRefSchema`** — Internal Zod schema representing a single assignment reference with `id` and `label` string fields.
- **`assignmentsSchema`** — Exported Zod schema validating an optional object whose keys (`ORGANIZATION`, `DEVICE`, `TICKET`, `KNOWLEDGE_ARTICLE`, `INSIGHT`) each map to an optional array of `assignmentRefSchema`. It is constrained via `satisfies z.ZodType<AssignmentsValue | undefined>` to ensure type alignment with the `AssignmentsValue` type.
- **`ASSIGNMENTS_DEFAULT`** — Exported default value (`{}`) typed as `AssignmentsValue`, useful for initializing forms or state.

## Usage Example

```typescript
import { assignmentsSchema, ASSIGNMENTS_DEFAULT } from './schema';

// Validate incoming data
const result = assignmentsSchema.safeParse({
  ORGANIZATION: [{ id: 'org-1', label: 'Acme Corp' }],
  DEVICE: [{ id: 'dev-42', label: 'Laptop-42' }],
});

if (result.success) {
  console.log('Valid assignments:', result.data);
} else {
  console.error('Validation errors:', result.error.format());
}

// Initialize default state
const initialAssignments = ASSIGNMENTS_DEFAULT;
```

This schema is typically used alongside form libraries or API response validators to ensure assignment data conforms to the expected shape before being consumed elsewhere in the application.
