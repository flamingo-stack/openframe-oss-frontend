# assigned-items-view.tsx

Renders a section showing items (customers, devices, knowledge base articles, tickets) assigned to a parent entity (insight, ticket, or knowledge article), displaying them in a single table or tabbed view depending on how many assignment kinds are present.

## Key Components

- **`AssignedItemsView`** — Top-level component that fetches assignment data via `useAssignedItems` for a given `itemId`/`itemType` and delegates rendering to `AssignedItemsContent`. Respects an ambient `useLoadingScope()` to defer fetching while in a loading scope.
- **`AssignedItemsContent`** — Presentational component that renders the fetched `AssignedItemsResult`. Handles three states:
  - **Pending/loading**: shows the item's "typical" assignment kind (`TYPICAL_TARGET_TYPE`) with per-table loading indicators.
  - **Empty**: renders nothing if no assignments and no load failure; renders a `SectionLoadError` if the fetch failed.
  - **Loaded**: renders a single table if only one assignment kind is active, or a `TabNavigation` with per-kind tables otherwise.
- **`AssignedItemsContentProps` / `AssignedItemsViewProps`** — Prop interfaces; `AssignedItemsViewProps` extends the content props but replaces `assigned` with `itemId` (since the view fetches it internally).
- **`TYPICAL_TARGET_TYPE`** — Maps each `AssignmentItemType` to its most common assignment target type, used as a placeholder tab during loading.

## Usage Example

```typescript
import { AssignedItemsView } from './assigned-items-view';

// Fetch-and-render usage (e.g. on a ticket details page)
function TicketDetailsSection({ ticketId }: { ticketId: string }) {
  return (
    <AssignedItemsView
      itemId={ticketId}
      itemType="TICKET"
      showTitle={false}
      className="mt-4"
    />
  );
}

// Host already has the data (e.g. shares a parent query)
import { AssignedItemsContent } from './assigned-items-view';
import { useAssignedItems } from './use-assigned-items';

function InsightSection({ insightId }: { insightId: string }) {
  const assigned = useAssignedItems({ itemId: insightId, itemType: 'INSIGHT' });
  return <AssignedItemsContent assigned={assigned} itemType="INSIGHT" />;
}
```
