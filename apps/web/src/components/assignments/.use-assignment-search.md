# use-assignment-search.ts

A React hook providing debounced, type-ahead search across different assignment target types (organizations, devices, tickets, knowledge articles) for use in assignment picker UIs. It abstracts the differences between server-side GraphQL search, ticket-service search scoped to non-archived statuses, and client-side filtering of a cached knowledge article tree.

## Key Components

- **`AssignmentSearchOption`** — Interface describing a `{ label, value }` search result option.
- **`useAssignmentSearch(targetType, search, enabled?)`** — Main exported hook. Dispatches to the knowledge-article client-filter path or the server-search path based on `targetType`. Returns `{ options, isLoading }`.
- **`useServerSearchOptions`** (internal) — Handles `ORGANIZATION`, `DEVICE`, and `TICKET` searches via `@tanstack/react-query`, debouncing input and, for tickets, waiting on non-archived status IDs resolved from `useTicketStatusesQuery`.
- **`useKnowledgeArticleOptions`** (internal) — Fetches the full knowledge base article tree once (cached), then filters client-side by debounced search text.
- **`fetchCustomers` / `fetchDevices` / `fetchTickets` / `fetchKnowledgeArticles`** — Individual fetch functions backing each search type, using `postGraphQl` or `ticketService.fetchDialogs`.
- **`SERVER_SEARCH_FETCHERS`** — Lookup map of fetchers per `AssignmentTargetType`, excluding `TICKET` which requires extra status-id resolution.

## Usage Example

```typescript
import { useAssignmentSearch } from './use-assignment-search';
import { useState } from 'react';

function AssignmentPicker({ targetType }: { targetType: 'ORGANIZATION' | 'DEVICE' | 'TICKET' | 'KNOWLEDGE_ARTICLE' }) {
  const [search, setSearch] = useState('');
  const { options, isLoading } = useAssignmentSearch(targetType, search);

  return (
    <div>
      <input value={search} onChange={e => setSearch(e.target.value)} placeholder="Search..." />
      {isLoading ? (
        <span>Loading…</span>
      ) : (
        <ul>
          {options.map(opt => (
            <li key={opt.value}>{opt.label}</li>
          ))}
        </ul>
      )}
    </div>
  );
}
```

Pass `enabled={false}` for read-only rows to suppress all network/query activity.
