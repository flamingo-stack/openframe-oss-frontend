# assignments-field.tsx

A React client component that renders a dynamic list of assignment target rows (e.g., groups, devices, users) with the ability to add new target types via a dropdown menu and remove existing ones.

## Key Components

- **`AssignmentsField`** — Main component that manages the collection of assignment rows. Accepts a map-like `AssignmentsValue` (keyed by target type) and emits changes via `onChange`. Supports restricting which target types are enabled and whether the field is disabled.
- **`AssignmentsFieldProps`** — Props interface: `value`, `onChange`, optional `enabledTypes`, `disabled`, and `className`.
- **`isPresent`** — Type-guard helper used to determine which target types already have assignment refs in `value`.

Internally, it distinguishes:
- **`activeTypes`** — target types currently present in `value` (rendered as rows).
- **`availableTypes`** — "pickable" target types (per `TARGET_CONFIG`) not yet added, shown in the "Assign Item" dropdown menu.

Row-level behavior (`AssignmentRow`) and target metadata (`TARGET_CONFIG`, `AssignmentTargetType`) are imported from sibling modules.

## Usage Example

```typescript
import { AssignmentsField } from './assignments-field';
import type { AssignmentsValue } from './types';

function PolicyAssignmentsSection() {
  const [assignments, setAssignments] = useState<AssignmentsValue>({
    group: [{ id: 'grp-1', name: 'Engineering' }],
  });

  return (
    <AssignmentsField
      value={assignments}
      onChange={setAssignments}
      enabledTypes={['group', 'device', 'user']}
      disabled={false}
      className="w-full"
    />
  );
}
```

Each row allows editing the list of `AssignmentRef` entries for its target type or removing the entire row via `onRemoveRow`. Read-only rows (non-pickable types) render without the ability to be manually added or removed from the dropdown, but can still appear if present in `value`.
