A form field component that manages multiple assignment rows, allowing users to add, update, and remove assignments grouped by target type (e.g., users, groups, roles).

## Key Components

- **`AssignmentsField`** — Main exported component that renders active assignment rows and an "Assign Item" dropdown button for adding new assignment types
- **`AssignmentsFieldProps`** — Interface defining `value`, `onChange`, `enabledTypes`, `disabled`, and `className` props
- **`isPresent`** — Type guard utility that checks whether an `AssignmentRef[]` array exists for a given target type

## Usage Example

```typescript
import { AssignmentsField } from './assignments-field';
import type { AssignmentsValue } from './types';

const [assignments, setAssignments] = useState<AssignmentsValue>({});

<AssignmentsField
  value={assignments}
  onChange={setAssignments}
  enabledTypes={['user', 'group']}
  disabled={false}
/>
```

## Behavior Notes

- **`activeTypes`** — Derived via `useMemo` from `enabledTypes` filtered to types already present in `value`
- **`availableTypes`** — Types not yet added; drives the dropdown menu items
- Adding a type via the dropdown initialises it with an empty `[]` array; removing deletes the key from `value`
- The "Assign Item" button is hidden when all enabled types have been added
