Defines TypeScript types and constants for modeling assignment relationships between items (tickets, knowledge articles, insights) and their assignment targets (organizations, devices, tickets, knowledge articles), bridging the gap between server-defined GraphQL types and client-side form rendering needs.

## Key Components

- **`ServerAssignmentTargetType`** — Union type matching the server's `AssignmentTargetType` enum (`ORGANIZATION`, `DEVICE`, `TICKET`, `KNOWLEDGE_ARTICLE`); used for querying `assignedItems` and calling `assignItem`.
- **`AssignmentTargetType`** — Extends `ServerAssignmentTargetType` with `'INSIGHT'`, a client-only target used when rendering forms. Insights are never assigned via `assignItem`; instead they link to tickets through `CreateTicketInput.insightId`.
- **`AssignmentItemType`** — Union type representing what *can own* an assignment (`TICKET`, `KNOWLEDGE_ARTICLE`, `INSIGHT`), mirroring the server's `AssignmentItemType`.
- **`AssignmentRef`** — Interface describing a lightweight reference to an assigned entity, with `id` and display `label`.
- **`AssignmentsValue`** — A partial record mapping each `AssignmentTargetType` to an array of `AssignmentRef` objects, representing the current assignment state for a form or component.
- **`ASSIGNMENT_TARGET_TYPES`** — Readonly array of the four server-recognized target types; use this when interacting with server queries/mutations.
- **`ALL_ASSIGNMENT_TARGET_TYPES`** — Readonly array including `INSIGHT`, for rendering all possible assignment rows in a UI form.

## Usage Example

```typescript
import {
  AssignmentsValue,
  ASSIGNMENT_TARGET_TYPES,
  ALL_ASSIGNMENT_TARGET_TYPES,
} from './types';

// Build assignment state for a form
const assignments: AssignmentsValue = {
  ORGANIZATION: [{ id: 'org-1', label: 'Acme Corp' }],
  DEVICE: [{ id: 'dev-42', label: 'Laptop-42' }],
};

// Iterate server-recognized targets when calling assignItem
ASSIGNMENT_TARGET_TYPES.forEach((targetType) => {
  const refs = assignments[targetType] ?? [];
  refs.forEach((ref) => assignItem(targetType, ref.id));
});

// Render all rows (including INSIGHT) in a form
ALL_ASSIGNMENT_TARGET_TYPES.forEach((targetType) => {
  renderAssignmentRow(targetType, assignments[targetType]);
});
```
