Defines TypeScript types and constants for the assignment system, modeling the relationships between assignable entities like organizations, devices, tickets, and knowledge articles.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `AssignmentTargetType` | `type` | Union of valid assignment target categories: `ORGANIZATION`, `DEVICE`, `TICKET`, `KNOWLEDGE_ARTICLE` |
| `AssignmentItemType` | `type` | Subset union for assignable item types: `TICKET` or `KNOWLEDGE_ARTICLE` |
| `AssignmentRef` | `interface` | Lightweight reference to an assignment entity with `id` and display `label` |
| `AssignmentsValue` | `type` | Partial record mapping each `AssignmentTargetType` to an array of `AssignmentRef` entries |
| `ASSIGNMENT_TARGET_TYPES` | `const` | Read-only array of all valid `AssignmentTargetType` values, useful for iteration and validation |

## Usage Example

```typescript
import type { AssignmentsValue, AssignmentRef } from './types';
import { ASSIGNMENT_TARGET_TYPES } from './types';

// Build an assignments payload
const assignments: AssignmentsValue = {
  ORGANIZATION: [{ id: 'org-123', label: 'Acme Corp' }],
  TICKET: [{ id: 'tkt-456', label: 'Cannot connect to VPN' }],
};

// Iterate over all valid target types
ASSIGNMENT_TARGET_TYPES.forEach((targetType) => {
  const refs: AssignmentRef[] = assignments[targetType] ?? [];
  console.log(`${targetType}: ${refs.length} assigned`);
});
```

## Notes

- `AssignmentsValue` uses `Partial<Record<...>>` so any combination of target types can be omitted safely.
- `AssignmentItemType` is a narrower subset of `AssignmentTargetType`, intended for contexts where only content items (not org/device) are valid assignment targets.
