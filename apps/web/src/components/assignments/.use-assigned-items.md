## use-assigned-items.ts

A React Query hook that fetches, for a given item, every object assigned to it across all assignment target kinds (organizations, devices, knowledge base articles, tickets) and normalizes the GraphQL union response into typed domain objects ready for UI rendering.

## Key Components

- **`ASSIGNED_ITEMS_QUERY`** — GraphQL query fetching `assignedItems` for an item, selecting type-specific fields via inline fragments on the `Organization`, `Machine`, `KnowledgeBaseItem`, and `Ticket` union members.
- **`ASSIGNED_ITEMS_LIMIT`** — Safety cap (100) on a single read of assigned items (not a pagination page size).
- **`ASSIGNED_ITEMS_SKELETON_ROWS`** — Default number of skeleton rows to render while an assigned list is loading.
- **`ASSIGNED_ITEMS_QUERY_KEY`** — Shared React Query cache key prefix used to invalidate all assigned-items reads after an assignment write.
- **`fetchAssignedItems(itemId, targetType)`** — Fetches and transforms assigned items of one target type into a `AssignedItemsPayload` (refs plus typed arrays: `customers`, `devices`, `articles`, or `tickets`).
- **`toMachineRowFields`, `toAssignedArticle`, `toDialog`** — Field-by-field mappers that convert the raw union target into the shapes expected by `DevicesTableBody`, `KnowledgeBaseAssignedTable`, and the ticket dialog, respectively.
- **`AssignedItemsResult`** — Combined result shape exposing `value`, per-kind `loadingTypes`/`failedTypes`, `isLoading`, `isReady`, `isOffline`, `loadFailed`, and a `retry()` to re-fetch only failed kinds.
- **`combineAssignedItems(results)`** — Merges parallel `useQueries` results (one per `ServerAssignmentTargetType`) into a single `AssignedItemsResult`.

## Usage Example

```typescript
import { useQueries } from '@tanstack/react-query';

function AssignmentsPanel({ itemId, itemType }: { itemId: string; itemType: AssignmentItemType }) {
  // Hook composes fetchAssignedItems per target type via useQueries,
  // then reduces results with combineAssignedItems.
  const { value, devices, customers, isLoading, loadFailed, retry } = useAssignedItems({
    itemId,
    itemType,
    enabled: true,
  });

  if (loadFailed) {
    return <button onClick={retry}>Retry loading assignments</button>;
  }

  if (isLoading) {
    return <SkeletonRows count={ASSIGNED_ITEMS_SKELETON_ROWS} />;
  }

  return <AssignmentsList value={value} devices={devices} customers={customers} />;
}
```

Invalidate all assigned-items caches after mutating an assignment:

```typescript
import { useQueryClient } from '@tanstack/react-query';
import { ASSIGNED_ITEMS_QUERY_KEY } from '@/app/(app)/assignments/use-assigned-items';

queryClient.invalidateQueries({ queryKey: ASSIGNED_ITEMS_QUERY_KEY });
```
