A filterable table component for displaying tickets assigned to the current user, featuring a debounced search input that filters by ticket title or organization name.

## Key Components

- **`TicketsAssignedTable`** — Main exported component that renders a search input and a filtered ticket list
- **`TicketsAssignedTableProps`** — Interface accepting a `tickets: Dialog[]` array and an optional `isLoading` boolean
- **Debounced search** — Uses `useDebounce` (300ms) to avoid filtering on every keystroke
- **`filtered` memo** — Derives a filtered subset of tickets matching the search needle against `title` or `organizationName`

## Usage Example

```typescript
import { TicketsAssignedTable } from '@/app/(app)/tickets/components/tickets-assigned-table';

const assignedTickets: Dialog[] = await fetchAssignedTickets(userId);

<TicketsAssignedTable
  tickets={assignedTickets}
  isLoading={false}
/>
```

## Filtering Behavior

| Input | Result |
|---|---|
| Empty / whitespace | Returns all tickets unfiltered |
| Text match on `title` | Includes matching tickets |
| Text match on `organizationName` | Includes matching tickets |
| No matches | Renders `"No tickets assigned."` empty state |

Search is case-insensitive. Missing `title` or `organizationName` fields are safely coerced to empty strings before comparison.
