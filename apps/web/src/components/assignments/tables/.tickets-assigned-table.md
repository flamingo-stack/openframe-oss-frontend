## tickets-assigned-table.tsx

A React client component that renders a searchable table of tickets assigned to the current user, combining a debounced search input with a shared ticket table body renderer.

## Key Components

- **`TicketsAssignedTable`** — Main exported component that accepts a list of tickets and a loading flag, providing client-side search filtering and rendering the results in a table.
- **`TicketsAssignedTableProps`** — Props interface defining `tickets` (array of `Dialog` objects) and optional `isLoading` boolean.

### Behavior

- Maintains local `search` state and debounces it (300ms) via `useDebounce` to avoid excessive re-filtering while typing.
- Filters tickets by matching the search term (case-insensitive) against both `title` and `organizationName` fields.
- Delegates actual row/column rendering to `TicketTableBody`, passing a custom empty-state message ("No tickets assigned.") and skeleton row count (`ASSIGNED_ITEMS_SKELETON_ROWS`) for loading states.

## Usage Example

```typescript
import { TicketsAssignedTable } from '@/app/(app)/tickets/components/tickets-assigned-table';

function AssignedTicketsSection() {
  const { tickets, isLoading } = useAssignedItems();

  return (
    <TicketsAssignedTable
      tickets={tickets}
      isLoading={isLoading}
    />
  );
}
```

The component is intended for use within the tickets dashboard, typically paired with the `useAssignedItems` hook to fetch and supply the `tickets` data and `isLoading` state.
