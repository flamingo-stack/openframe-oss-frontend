# customers-assigned-table.tsx

A client-side React component that renders a searchable, filterable table of customers assigned to a given entity (e.g., a license or product). It provides debounced local search over the customer `name` and `contact.email` fields and displays loading/empty states.

## Key Components

- **`CustomersAssignedTable`** — Main exported component. Accepts a list of customers and an optional loading flag, renders a search input, and displays a filtered table body.
- **`CustomersAssignedTableProps`** — Props interface: `customers: Customer[]` and `isLoading?: boolean`.
- Internally composes:
  - `CustomersSearchInput` — controlled search input (from `customers-table-columns`).
  - `CustomersTableBody` — renders the filtered rows, loading skeletons, and empty state.
  - `useDebounce` — debounces the search term (300ms) to avoid excessive re-filtering.
  - `oneLineEmptyState` — shared empty-state message renderer.
  - `ASSIGNED_ITEMS_SKELETON_ROWS` — constant controlling the number of skeleton rows shown while loading.

## Usage Example

```typescript
import { CustomersAssignedTable } from '@/app/(app)/customers/components/customers-assigned-table';
import { useCustomers } from '@/app/(app)/customers/hooks/use-customers';

function AssignedCustomersSection({ licenseId }: { licenseId: string }) {
  const { customers, isLoading } = useCustomers({ assignedTo: licenseId });

  return (
    <CustomersAssignedTable
      customers={customers}
      isLoading={isLoading}
    />
  );
}
```

## Notes

- Filtering is performed client-side via `useMemo`, recomputing only when `customers` or the debounced search term changes.
- The search is case-insensitive and matches on both customer name and contact email.
- When no `customers` match the search term (or the list is empty), a one-line empty state message ("No customers assigned.") is shown.
