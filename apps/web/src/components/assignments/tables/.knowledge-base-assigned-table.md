A read-only table of the knowledge base articles assigned to a customer or a device, with a search that narrows the
already-loaded list in place.

## Key Components

- **`KnowledgeBaseAssignedTable`** — Exported. A search `Input` (debounced 300 ms; matches `name` or `summary`) above a
  `DataTable` with the knowledge base listing's own columns (name, created, open), minus the row menu: an assignment is
  edited on the article's form. Rows link to the article's page.
- **`AssignedArticle`** — Exported type: the row, typed off the knowledge base cells' fragments (the assignments are
  read by raw POST, so there is no fragment reference).
- Props: `articles: AssignedArticle[]`, `isLoading?: boolean`.

## Usage Example

```typescript
import { KnowledgeBaseAssignedTable } from './knowledge-base-assigned-table';

<KnowledgeBaseAssignedTable articles={articles ?? NO_ITEMS} isLoading={isLoading} />;
```

## Notes

- While loading the body draws `ASSIGNED_ITEMS_SKELETON_ROWS` rows (`use-assigned-items.ts`; the assigned lists are
  read whole, not paged, so it is a typical count).
- An empty list reads "No articles assigned.".
