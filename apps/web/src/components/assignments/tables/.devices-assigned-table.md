A client-side React component that renders a filterable table of devices assigned to a specific context (e.g., a user or group), with debounced search filtering by device name or organization.

## Key Components

- **`DevicesAssignedTable`** — Main exported component accepting a `devices` array and optional `isLoading` flag
- **`DevicesAssignedTableProps`** — Interface defining `devices: Device[]` and optional `isLoading?: boolean`
- **Debounced search** — Uses `useDebounce` (300ms) to filter devices by `displayName`, `hostname`, or `organization`
- **`DevicesTableBody`** — Reused table body component from the shared devices module, rendering filtered results with skeleton loading and an empty state

## Usage Example

```typescript
import { DevicesAssignedTable } from './devices-assigned-table';
import type { Device } from '@/app/(app)/devices/types/device.types';

const assignedDevices: Device[] = [
  { displayName: 'Workstation-01', hostname: 'ws-01', organization: 'Acme Corp' },
  { displayName: 'Laptop-02', hostname: 'lp-02', organization: 'Flamingo Inc' },
];

export function UserDetailPanel() {
  return (
    <DevicesAssignedTable
      devices={assignedDevices}
      isLoading={false}
    />
  );
}
```

## Filtering Logic

| Field checked | Source property |
|---|---|
| Device name | `displayName` → `hostname` (fallback) |
| Organization | `organization` |

Search is case-insensitive and matches substrings. An empty search returns all devices unfiltered.
