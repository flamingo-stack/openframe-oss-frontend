# devices-store.ts

A Zustand store for managing device state in the OpenFrame platform, including device inventory, filtering, sorting, selection, and derived statistics. Built with `immer` middleware for ergonomic immutable updates and `devtools` for Redux DevTools integration.

## Key Components

- **`Device`** – Interface describing a managed device (id, name, type, status, metrics, OS info, tags, etc.)
- **`DeviceFilter`** – Interface for filtering devices by status, type, tags, or search query
- **`DevicesState`** – Store shape combining state (devices, selection, filter, sort, loading/error) and actions
- **`useDevicesStore`** – The main Zustand hook/store, created with `immer` + `devtools` middleware
- **Actions** – `setDevices`, `addDevice`, `updateDevice`, `removeDevice`, `selectDevice`, `setFilter`, `setSorting`, `setLoading`, `setError`, `refreshDevices`, `clearFilters`, `reset`
- **Basic selectors** – `selectDevices`, `selectSelectedDevice`, `selectFilter`, `selectIsLoading`, `selectError`
- **Computed selectors** – `selectFilteredDevices` (applies filtering + sorting), `selectDeviceStats` (aggregates counts by status)

## Usage Example

```typescript
import { useDevicesStore, selectFilteredDevices, selectDeviceStats } from './devices-store';

// In a React component
function DeviceList() {
  const devices = useDevicesStore(selectFilteredDevices);
  const stats = useDevicesStore(selectDeviceStats);
  const setFilter = useDevicesStore(state => state.setFilter);
  const setSorting = useDevicesStore(state => state.setSorting);

  const handleSearch = (query: string) => {
    setFilter({ searchQuery: query, status: ['online'] });
  };

  return (
    <div>
      <p>Online: {stats.online} / {stats.total}</p>
      <button onClick={() => setSorting('lastSeen')}>Sort by Last Seen</button>
      {devices.map(device => (
        <div key={device.id}>{device.name} - {device.status}</div>
      ))}
    </div>
  );
}

// Updating a device directly
useDevicesStore.getState().updateDevice('device-123', { status: 'offline' });
```

## Notes

- `refreshDevices` only toggles loading state; the actual data fetch must be triggered externally (e.g., via a query hook that calls `setDevices`/`setError` on completion).
- `setSorting` toggles `sortOrder` automatically when the same `sortBy` field is passed without an explicit order.
