Zustand store managing device state for the OpenFrame platform, providing CRUD operations, filtering, sorting, and computed selectors for device inventory management.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `Device` | Core device model with type, status, OS info, metrics, and optional tags |
| `DeviceFilter` | Filter criteria for status, type, tags, and free-text search |
| `DevicesState` | Full store shape combining state fields and action methods |

### Store

**`useDevicesStore`** — Zustand store with `immer` (immutable mutations) and `devtools` (Redux DevTools) middleware.

### Actions

| Action | Description |
|---|---|
| `setDevices` | Replace full device list and update `lastFetch` timestamp |
| `addDevice` | Append a new device |
| `updateDevice` | Patch a device by ID; syncs `selectedDevice` if active |
| `removeDevice` | Remove by ID; clears selection if active |
| `selectDevice` | Set or clear the active device |
| `setFilter` / `clearFilters` | Update or reset filter criteria |
| `setSorting` | Set sort field; toggles order if same field is re-selected |
| `refreshDevices` | Set loading state to trigger an external refetch |
| `reset` | Restore store to initial state |

### Selectors

| Selector | Description |
|---|---|
| `selectFilteredDevices` | Returns devices after applying all active filters and sort order |
| `selectDeviceStats` | Returns counts of total, online, offline, idle, and error devices |
| `selectFilter`, `selectIsLoading`, `selectError` | Primitive state accessors |

## Usage Example

```typescript
import { useDevicesStore, selectFilteredDevices, selectDeviceStats } from './devices-store';

function DeviceList() {
  const filteredDevices = useDevicesStore(selectFilteredDevices);
  const stats = useDevicesStore(selectDeviceStats);
  const { setFilter, setSorting, selectDevice } = useDevicesStore();

  // Filter to online laptops only
  setFilter({ status: ['online'], type: ['laptop'] });

  // Sort by last seen, descending
  setSorting('lastSeen', 'desc');

  return (
    <>
      <p>Online: {stats.online} / {stats.total}</p>
      {filteredDevices.map(device => (
        <div key={device.id} onClick={() => selectDevice(device)}>
          {device.name} — {device.status}
        </div>
      ))}
    </>
  );
}
```
