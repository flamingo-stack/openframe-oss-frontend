# feature-flags-store.ts

Zustand store holding server-loaded feature flags. It deliberately avoids any client-side persistence (no `localStorage`, no cookies) so that flags always reflect the latest value from `feFeatureFlags` on each load, preventing stale behavior in long-lived sessions such as the native shell.

The store treats `isLoaded === false` as a genuine application state—not a loading placeholder to be skipped past—since there is no safe default to assume before the server responds.

## Key Components

- **`FeatureFlag`** — Interface describing a single flag (`name`, `enabled`).
- **`FeatureFlagsState`** — Store shape containing:
  - `flags`: map of flag name to enabled state.
  - `isLoaded`: whether the server has answered (or terminally failed).
  - `setFlags(flags)`: bulk-replaces flags and marks the store as loaded.
  - `setLoaded()`: marks loaded without changing flags (e.g., terminal failure case).
  - `reset()`: clears flags and resets `isLoaded` to `false`.
- **`useFeatureFlagsStore`** — The Zustand hook/store, built with `immer` for ergonomic mutations and `devtools` for debugging.

## Usage Example

```typescript
import { useFeatureFlagsStore } from './feature-flags-store';

// After fetching flags from the server
function loadFlags(serverFlags: { name: string; enabled: boolean }[]) {
  useFeatureFlagsStore.getState().setFlags(serverFlags);
}

// Reading state in a component
function FeatureGate({ flagName, children }: { flagName: string; children: React.ReactNode }) {
  const isLoaded = useFeatureFlagsStore(state => state.isLoaded);
  const enabled = useFeatureFlagsStore(state => state.flags[flagName]);

  if (!isLoaded) {
    return null; // Explicitly handle the "not answered yet" state
  }

  return enabled ? <>{children}</> : null;
}

// Resetting on logout or session change
useFeatureFlagsStore.getState().reset();
```

**Note:** Consumers should prefer dedicated hooks like `useFeatureFlag` / `useFeatureFlagsReady` (if available elsewhere in the codebase) to correctly express the "not loaded yet" state rather than relying on environment defaults.
