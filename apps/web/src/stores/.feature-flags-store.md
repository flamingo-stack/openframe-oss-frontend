Zustand store managing feature flags with localStorage caching for skeleton layout optimization during server-flag resolution.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FeatureFlag` | Interface | Shape of a single flag: `name` and `enabled` boolean |
| `FeatureFlagsState` | Interface | Full store shape including flags map, load state, and actions |
| `useFeatureFlagsStore` | Zustand store | Primary hook for reading and mutating feature flag state |
| `readCachedFeatureFlags` | Function | Reads last-known flag values from `localStorage` for skeleton layout hints |

## Key Behaviors

- **`setFlags`** — Converts a `FeatureFlag[]` array into a `Record<string, boolean>` map, marks the store as loaded, and persists the result to `localStorage`. The cache write occurs outside the Immer recipe to avoid operating on a draft proxy.
- **`setLoaded`** — Marks flags as loaded without modifying flag values (e.g., when no flags exist server-side).
- **`reset`** — Clears all flags and reverts `isLoaded` to `false`.
- **`readCachedFeatureFlags`** — Intentionally isolated from `getFlagValue` so stale cache entries never gate real features; only used by route skeletons before the flags query resolves.

## Usage Example

```typescript
// Reading flags in a component
const { flags, isLoaded } = useFeatureFlagsStore();

if (!isLoaded) return <Skeleton />;
const showBeta = flags['beta-dashboard'] ?? false;

// Hydrating the store from a server response
const { setFlags } = useFeatureFlagsStore();
setFlags([
  { name: 'beta-dashboard', enabled: true },
]);

// Reading cached flags in a route skeleton (before store loads)
const cached = readCachedFeatureFlags();
const guessedLayout = cached?.['beta-dashboard'] ?? DEFAULT_BETA_ENABLED;
```

## Caching Strategy

The `localStorage` key `openframe:feature-flags-v1` stores the last server-resolved flags. Writes are skipped when the serialized value is unchanged (no unnecessary I/O). Invalid entries, non-boolean values, and private-mode failures are silently discarded — skeletons fall back to environment defaults on a cold first visit.
