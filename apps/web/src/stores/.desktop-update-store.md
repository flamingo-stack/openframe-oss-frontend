# desktop-update-store.ts

A Zustand store that manages desktop app update state within the Tauri shell, coordinating the update modal and sidebar reopen button across unrelated component subtrees.

This store acts as a **fallback path**: the Tauri shell normally applies updates silently at launch (user restarts into the new version transparently). This store only surfaces updates when the silent path fails or cannot proceed — e.g., offline at boot, failed download, self-update disabled, or a release published mid-session. It is only populated inside the Tauri desktop shell; on mobile/web it stays empty and all consumers render nothing.

## Key Components

- **`DesktopUpdatePhase`** — Union type: `'idle' | 'downloading' | 'installing' | 'error'`.
- **`DesktopUpdateState`** — Store shape: `available`, `version`, `releaseNotesUrl`, `isModalOpen`, `dismissedVersion`, `phase`, `downloaded`, `total`, `error`, `blocked`.
- **`useDesktopUpdateStore`** — The Zustand hook (wrapped with `devtools`) exposing state and actions:
  - `announce(availability)` — Records an update offered by the mount-time check or shell poll; ignores re-announcements of the in-flight version.
  - `openModal()` — Reopens the modal (e.g., from the sidebar button).
  - `dismiss()` — Closes the modal, remembering the dismissed version (not a boolean) so a newer release can still announce itself.
  - `startApply()` — Begins the download phase.
  - `setProgress(progress)` — Updates download progress; ignored once phase has moved past `downloading`.
  - `setInstalling()` — Transitions to the `installing` phase.
  - `fail(error)` — Handles failure, with special handling for `busy` (another apply owns it), `gone` (already installed/withdrawn), and `location` (permanently blocked) error kinds.

## Usage Example

```typescript
import { useDesktopUpdateStore } from '@/stores/desktop-update-store';

function UpdateSidebarButton() {
  const { available, openModal } = useDesktopUpdateStore();

  if (!available) return null;

  return <button onClick={openModal}>Update available</button>;
}

function UpdateModal() {
  const { isModalOpen, version, phase, downloaded, total, dismiss, startApply } =
    useDesktopUpdateStore();

  if (!isModalOpen) return null;

  return (
    <div>
      <p>Version {version} is ready to install.</p>
      {phase === 'downloading' && (
        <progress value={downloaded} max={total ?? undefined} />
      )}
      <button onClick={startApply}>Update now</button>
      <button onClick={dismiss}>Update on next launch</button>
    </div>
  );
}
```
