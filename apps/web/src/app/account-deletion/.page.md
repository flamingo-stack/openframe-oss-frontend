# page.tsx (Account Deletion)

A public, unauthenticated Next.js page providing account-deletion instructions, required as the "Data deletion" URL for Google Play Store compliance.

This page intentionally lives outside the `(app)` and `(auth)` route groups to remain reachable by users who cannot sign in (e.g., disabled accounts, forgotten passwords, former employees) while keeping the actual deletion action gated behind authentication. It serves from the shared host since tenant-specific gateway hosts aren't known until login.

## Key Components

- **`AccountDeletionPage`** (default export) — Server-rendered client component (`'use client'`) that renders:
  - `OpenframeLockup` — brand header
  - Instructions for users **who can sign in** (self-service deletion via Settings → Profile, with ownership-transfer handling for workspace owners)
  - Instructions for users **who can't sign in** (email-based request to `hello@openframe.ai`)
  - A "What happens to your data" section explaining anonymization, session revocation, and retention of organization-owned records
  - `PoweredByFlamingo` — footer branding

Uses `of-standalone-shell` for native safe-area insets (bypassing `AppLayout`/`AuthShell`), and relative routing via `routes.auth.login` so links resolve correctly against whichever tenant host served the page.

## Usage Example

This page is automatically served by Next.js App Router based on its file path and requires no manual invocation:

```typescript
// Accessed directly via route, e.g.:
// https://app.openframe.ai/account-deletion

// Referenced externally as the Google Play Console
// "Data deletion" URL — must be publicly reachable
// without app installation or authentication.
```

No props or configuration are needed; all links (`routes.auth.login`, `mailto:hello@openframe.ai`) are statically defined within the component.
