Defines page metadata and layout wrapper for the Account Deletion route in the Next.js app, setting the browser tab title using a shared route title utility.

## Key Components

- **`metadata`**: Exported `Metadata` object that sets the page title to `"Account Deletion"` via the `routeTitle` helper, ensuring consistent title formatting across the app.
- **Default export**: Re-exports the `default` export from `@/app/(app)/route-title-layout`, delegating the actual layout rendering logic (e.g., displaying the route title in the UI) to a shared layout component.

## Usage Example

This file is a Next.js route segment layout and is not imported directly elsewhere. It is automatically picked up by the Next.js App Router for any page nested under the corresponding `account-deletion` route segment.

```typescript
// Next.js automatically applies this layout and metadata
// to routes within the account-deletion segment, e.g.:
// app/(app)/account-deletion/page.tsx

// The resulting <title> tag will render as:
// routeTitle('Account Deletion') -> e.g. "Account Deletion | OpenFrame"
```

To customize the title for a similar route, follow the same pattern:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Your Page Name') };
```

This pattern keeps layout logic DRY by reusing a shared layout component while allowing each route to define its own page title through the `routeTitle` utility.
