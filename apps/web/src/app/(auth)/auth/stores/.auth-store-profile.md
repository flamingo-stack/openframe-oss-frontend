Imperatively fetches the signed-in user's profile via Relay and shapes it into a partial object for merging into the Zustand auth store, bypassing React's declarative fragment-based data flow.

## Key Components

- **`authStoreProfileQueryNode`** — GraphQL query (via `graphql` tag) that fetches a `User` node by global ID, requesting name, email, verification status, status, roles, and avatar image.
- **`fetchProfile(userId: string)`** — Async function that:
  - Converts the raw `userId` to a Relay global ID via `toGlobalId('User', userId)`.
  - Executes the query with `fetchPolicy: 'network-only'` to always hit the network.
  - Returns `null` if the node isn't found or isn't a `User`.
  - Returns a sparse object containing only fields the API actually returned (using conditional spreads), so partial responses never overwrite existing store data with `null`/`undefined`.

## Usage Example

```typescript
import { fetchProfile } from '@/lib/auth-store-profile';

async function hydrateAuthStore(userId: string) {
  const profile = await fetchProfile(userId);
  if (!profile) {
    // API doesn't recognize this user id
    return;
  }

  // Merge only the known fields into the Zustand store
  useAuthStore.setState((state) => ({
    user: { ...state.user, ...profile },
  }));
}
```

**Notes:**
- This module is intentionally separate from Relay-based component queries — it exists solely to hydrate the auth store at session start, keeping Relay out of the store's module graph for consumers that don't need it.
- Do not use this as a general-purpose data source for components; use Relay fragments instead for declarative, co-located data fetching.
