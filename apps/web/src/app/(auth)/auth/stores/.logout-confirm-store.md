Manages the open/close state of the logout confirmation modal using Zustand, allowing it to be triggered from any component in the tree regardless of subtree location.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useLogoutConfirmStore` | Zustand store hook | Primary hook for reading and mutating modal open state |
| `isOpen` | `boolean` | Whether the logout confirmation modal is currently visible |
| `open()` | `() => void` | Sets `isOpen` to `true` |
| `close()` | `() => void` | Sets `isOpen` to `false` |
| `setOpen(open)` | `(open: boolean) => void` | Directly assigns an arbitrary boolean value to `isOpen` |

## Usage Example

```typescript
// Trigger from any component (e.g., Settings page, navigation user menu)
import { useLogoutConfirmStore } from '@/stores/logout-confirm-store';

function UserMenu() {
  const open = useLogoutConfirmStore(state => state.open);

  return <button onClick={open}>Log Out</button>;
}

// Consume in the modal mounted once in AppShell
function LogoutConfirmModal() {
  const { isOpen, close } = useLogoutConfirmStore();

  return (
    <Dialog open={isOpen} onClose={close}>
      <p>Are you sure you want to log out?</p>
      <button onClick={close}>Cancel</button>
    </Dialog>
  );
}
```

## Notes

- Follows the same "open from anywhere" pattern as `mingo-launcher-store` — the modal itself is mounted once in `AppShell` while triggers may exist in unrelated subtrees.
- Devtools middleware is enabled with the name `logout-confirm-store` for inspection in the Redux DevTools browser extension.
