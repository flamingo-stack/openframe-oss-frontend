# auth-store.ts

A Zustand store that manages global user authentication state, including login/logout, profile data, tenant context, and lazy-loaded full profile fetching. Built with `immer`, `persist`, and `devtools` middleware following OpenFrame state management patterns.

## Key Components

- **`useAuthStore`** — Main Zustand store hook exposing authentication state and actions.
- **`AuthState`** — Interface defining the store's shape (state fields + actions).
- **`User` / `UserImage`** — Exported types describing the authenticated user and profile image data.
- **`login(user)`** — Sets the authenticated user, merging fields if the same user ID already exists.
- **`logout()`** — Clears auth state, tenant ID, and resets `useOnboardingStore` to prevent state leakage between users in the same tab.
- **`updateUser(partial)`** — Shallow-merges partial user updates into current state.
- **`setLoading` / `setError` / `clearError`** — Loading and error state helpers.
- **`setTenantId(tenantId)`** — Stores the active tenant ID in memory.
- **`fetchFullProfile()`** — Lazily imports and calls `fetchProfile` from `auth-store-profile`, merging the extended profile (e.g., `status`, `image`, timestamps) into the current user without overwriting unchanged image data.
- **Selectors** — `selectUser`, `selectIsAuthenticated`, `selectIsLoading`, `selectError` for optimized component subscriptions.
- **Persistence** — Only `user`, `isAuthenticated`, and `tenantId` are persisted under the `auth-storage` key.

## Usage Example

```typescript
import { useAuthStore, selectUser, selectIsAuthenticated } from '@/stores/auth-store';

function LoginButton() {
  const login = useAuthStore(state => state.login);
  const user = useAuthStore(selectUser);
  const isAuthenticated = useAuthStore(selectIsAuthenticated);

  const handleLogin = async () => {
    const response = await fetch('/api/me').then(r => r.json());
    login({ id: response.id, email: response.email });
  };

  return isAuthenticated ? <p>Welcome {user?.email}</p> : <button onClick={handleLogin}>Log in</button>;
}

// Fetching extended profile data (e.g., avatar, status) after login
function ProfileLoader() {
  const fetchFullProfile = useAuthStore(state => state.fetchFullProfile);

  useEffect(() => {
    fetchFullProfile();
  }, [fetchFullProfile]);

  return null;
}

// Logging out clears auth state and resets onboarding
function LogoutButton() {
  const logout = useAuthStore(state => state.logout);
  return <button onClick={logout}>Log out</button>;
}
```
