Zustand-based authentication store that manages user identity, session state, and tenant context for the OpenFrame frontend.

## Key Components

### State Shape (`AuthState`)

| Field | Type | Persisted | Description |
|---|---|---|---|
| `user` | `User \| null` | ✅ | Authenticated user object |
| `isAuthenticated` | `boolean` | ✅ | Session validity flag |
| `tenantId` | `string \| null` | ✅ | Active tenant context |
| `isLoading` | `boolean` | ❌ | General async loading flag |
| `isLoadingProfile` | `boolean` | ❌ | Profile fetch in-flight guard |
| `error` | `string \| null` | ❌ | Last error message |

### Actions

| Action | Description |
|---|---|
| `login(user)` | Sets user & authenticated state; merges fields if same user ID |
| `logout()` | Clears user/tenant state and resets onboarding store |
| `updateUser(partial)` | Merges partial user fields into existing user |
| `fetchFullProfile()` | Fetches enriched user data from `api/users/:id`; guards against concurrent calls |
| `setTenantId(id)` | Updates in-memory tenant ID |
| `setError / clearError` | Manages error state |

### Selectors

Pre-built selectors (`selectUser`, `selectIsAuthenticated`, `selectIsLoading`, `selectError`) for optimized component re-renders.

### Middleware Stack

`devtools` → `persist` → `immer` — state mutations use Immer draft syntax; `auth-storage` key persists only `user`, `isAuthenticated`, and `tenantId` to storage.

## Usage Example

```typescript
import { useAuthStore, selectUser, selectIsAuthenticated } from '@/stores/auth-store';

// In a component — use selectors to minimize re-renders
const user = useAuthStore(selectUser);
const isAuthenticated = useAuthStore(selectIsAuthenticated);

// Login after receiving user from /me endpoint
const { login, logout, fetchFullProfile } = useAuthStore.getState();
login({ id: '123', email: 'user@example.com', tenantId: 'tenant-abc' });

// Enrich with full profile data
await fetchFullProfile();

// Logout clears state and resets onboarding
logout();
```

## Notes

- **`login` is idempotent for the same user ID** — it merges updated fields rather than replacing the object, preventing unnecessary renders.
- **`fetchFullProfile` is concurrency-safe** — the `isLoadingProfile` guard prevents duplicate in-flight requests.
- **`logout` resets `useOnboardingStore`** to prevent stale onboarding state leaking to subsequent users in the same browser tab (relevant for native-shell and SaaS tenant force-logout flows).
