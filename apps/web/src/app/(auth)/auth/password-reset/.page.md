Handles the password reset confirmation flow, allowing users to set a new password via a tokenized URL. Validates the reset token from query params, enforces password length and match requirements, and submits the new password through the auth API client.

## Key Components

- **`PasswordResetPage`** — Default export; the main page component that orchestrates state, validation, and submission
- **`MIN_PASSWORD_LENGTH`** — Constant (`8`) defining the minimum accepted password length
- **Token guard** — `useEffect` that redirects to `/auth` if no `token` query param is present
- **`handleSubmit`** — Async handler that calls `authApiClient.confirmPasswordReset`, shows success/error toasts, and redirects after 2 seconds on success
- **`handleBack`** — Navigates back to `/auth`

## Usage Example

This page is accessed via a password reset email link containing a `token` query parameter:

```text
https://your-app.example.com/auth/password-reset?token=<reset_token>
```

Rendered form state and validation:

```typescript
// Inline validation logic used within the component
const isTooShort = !!password && password.length < MIN_PASSWORD_LENGTH;
const isMismatch = !!confirmPassword && password !== confirmPassword;
const isValid = password.length >= MIN_PASSWORD_LENGTH && password === confirmPassword;
```

The page renders [`PasswordResetForm`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src) wrapped in `AuthShell` with a `BackToLoginLink` footer. On success, the user is redirected to `/auth` after a 2-second delay. Missing or invalid tokens trigger a destructive toast and an immediate redirect to `/auth`.
