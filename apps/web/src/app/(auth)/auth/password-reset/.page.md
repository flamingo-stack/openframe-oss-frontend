# Password Reset Page

Next.js client-rendered page that handles the password reset flow by reading a reset `token` from the URL query string and submitting a new password to the auth API. It uses a loading-scope pattern to render an inert, empty form during static prerendering until `useSearchParams` resolves on the client.

## Key Components

- **`PasswordResetPage`** (default export) — Top-level route component that wraps the content in `BackToLoginShell` and wires up back-to-login navigation.
- **`PasswordResetContent`** — Wraps the reader component in `LoadingSuspense` to establish a loading scope/boundary.
- **`PasswordResetContentReader`** — Checks `useLoadingScope()` to decide whether to render the empty placeholder form (`EMPTY_RESET_FORM`) or the live, interactive form.
- **`PasswordResetContentLive`** — The real form logic: reads `token` from `useSearchParams`, manages password pair state via `usePasswordPair`, validates input, and calls `authApiClient.confirmPasswordReset` on submit.
- **`EMPTY_RESET_FORM`** — Inert placeholder props (no-op handlers, disabled submit) shown before the token is available.

## Usage Example

This page is automatically routed by Next.js App Router (e.g., at `/auth/reset-password`) and expects a `token` query parameter:

```typescript
// Example URL that triggers this page:
// /auth/reset-password?token=abc123xyz

// On mount, if no token is present:
// - Shows a destructive toast: "Invalid Reset Link"
// - Redirects to /auth

// On valid token + successful submission:
// - Calls authApiClient.confirmPasswordReset({ token, newPassword })
// - Shows success toast
// - Redirects to /auth after 2 seconds
```

Key flow handled internally:

```typescript
const handleSubmit = async () => {
  if (!token || !isValid) return;
  const response = await authApiClient.confirmPasswordReset({
    token,
    newPassword: pair.password,
  });
  // ... success/error toast + redirect handling
};
```

**Dependencies:** `usePasswordPair` (password + confirm-password validation hook), `authApiClient` (auth HTTP client), `BackToLoginShell` (shared auth layout shell), and `PasswordResetForm` (presentational form component from `@flamingo-stack/openframe-frontend-core`).
