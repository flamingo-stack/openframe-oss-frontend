# page.tsx — Invitation Acceptance Page

Next.js client page that renders the invitation acceptance flow, letting a new user complete their account registration (name + password, or SSO) after clicking an invite link.

## Key Components

- **`InvitePage`** — Default export; entry point that renders `InviteContent`.
- **`InviteContent`** — Wraps the reader in a `LoadingSuspense` boundary, since `useSearchParams` requires client-side rendering during static prerendering.
- **`InviteContentReader`** — Shows an empty/inert `InviteView` while in the loading scope, otherwise renders `InviteContentLive`.
- **`InviteContentLive`** — Core logic: reads the `id` query param, fetches SSO providers via `useInviteProviders`, manages form state (name, password pair), handles form submission and SSO sign-up, and shows a tenant-switch confirmation dialog when needed.
- **`InviteView`** — Shared shell combining `BackToLoginShell` and `CompleteAccountForm`, merged with `EMPTY_INVITE_FORM` defaults to avoid drift between loading and loaded states.
- **`EMPTY_INVITE_FORM`** — Static, inert default props for the form (used before the invitation is read).
- **`isInvalidInviteError`** — Helper detecting invitation-not-found/already-used errors to trigger the invalid-invite modal.
- **`SSO_TO_FORM`** — Maps backend SSO provider ids (`google`, `microsoft`, `apple`) to form provider ids.

## Usage Example

This file is a Next.js route segment (`page.tsx`) and is rendered automatically by the App Router for its route path—it is not imported directly. The invitation link format expected is:

```text
/auth/invite?id=<invitationId>
```

Internally, it composes reusable hooks and components:

```typescript
import { useInviteProviders } from '@/app/(auth)/auth/hooks/use-invite-providers';
import { usePasswordPair } from '@/app/(auth)/auth/hooks/use-password-pair';

const { providers, loading, error } = useInviteProviders(invitationId);
const { isValid, errors, ...pair } = usePasswordPair();
```

**Flow summary:**
1. Reads `id` from the URL query string.
2. Fetches available SSO providers for the invitation.
3. On submit, calls `authApiClient.acceptInvitation`; on `USER_IS_ACTIVE_IN_ANOTHER_TENANT`, prompts a confirm dialog before retrying with `switchTenant: true`.
4. On invalid/expired/missing invitation, renders `InviteLinkInvalidModal` instead of the form.
5. Supports SSO signup (`google`, `microsoft`, and `apple` on Apple platforms only) via `authApiClient.acceptInvitationSso`.
