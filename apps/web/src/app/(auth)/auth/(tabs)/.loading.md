Route-level loading UI for the `/auth` Sign Up email step, rendered automatically by Next.js during page transitions and data fetching.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AuthLoading` | `default` (React component) | Card-only skeleton for the Sign Up email step; the shell and tabs belong to `(tabs)/layout.tsx` |

## Usage Example

Next.js automatically renders this component as the Suspense fallback for the `/auth` route segment. No manual imports are needed.

```typescript
// next.js convention — file is auto-discovered as the route loading UI
// Manually rendering the skeleton (e.g. in tests or Storybook):
import AuthLoading from '@/app/auth/loading';

export default function PreviewPage() {
  return <AuthLoading />;
}
```

## Notes

- Delegates entirely to [`AuthFormSkeleton`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/auth/components/auth-page-skeleton.tsx) with `variant="signup"`, keeping skeleton variants co-located with the auth UI.
- The `'use client'` directive is required because `AuthFormSkeleton` uses client-side rendering.
