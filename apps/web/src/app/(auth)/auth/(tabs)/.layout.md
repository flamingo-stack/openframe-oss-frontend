# layout.tsx

Shared layout for the Sign Up and Login route segment, keeping the authentication shell (branding, benefits panel, tab selector) mounted across tab switches so only the inner card content suspends when navigating between the two routes.

## Key Components

- **`AuthTabsLayout`** (default export) — Next.js layout component wrapping the `signup`/`login` route group.
- **`TABS`** — Static tab definitions (`signup`, `login`) passed to `TabSelector`.

### Behavior

- **Active tab detection** — Derives the active tab from `pathname` against `routes.auth.login`.
- **Authenticated redirect** — If the user is already authenticated (and not in auth-only mode), replaces the current route with `getLandingPath()` to avoid leaving an auth route in the back stack.
- **Prefetching** — Prefetches both `routes.auth.root` and `routes.auth.login` so switching tabs requires no additional fetch.
- **Desktop sign-in wait** — Uses `useDesktopSignInWait()` to hide (not unmount) the form while waiting on browser-based desktop sign-in, preserving typed input; shows `DesktopSignInWaiting` instead.
- **Login-only mobile mode** — When `useLoginOnlyMobileShell()` is true, renders `CompactAuthShell` with no tabs and no benefits panel (login-only builds have no Sign Up route).
- **Standard shell** — Otherwise renders `AuthShell` with a `TabSelector` that calls `router.replace` to switch between `routes.auth.root` (signup) and `routes.auth.login`.

## Usage Example

This file is a Next.js layout and is not imported directly; it's automatically applied to routes within its route group:

```typescript
// app/(auth)/(auth-tabs)/signup/page.tsx
export default function SignUpPage() {
  return <SignUpForm />;
}

// app/(auth)/(auth-tabs)/login/page.tsx
export default function LoginPage() {
  return <LoginForm />;
}

// AuthTabsLayout automatically wraps both pages, preserving the shell
// (tabs, branding) while only the page content changes between routes.
```

Routes outside this group (`invite`, `sso-continue`, `password-reset`) are unaffected and render their own shells.
