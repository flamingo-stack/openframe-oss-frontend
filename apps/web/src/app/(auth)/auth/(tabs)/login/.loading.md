Renders the route-level loading UI for the `/auth/login` page while the login route segment is suspended.

## Key Components

- **`LoginLoading`** — Default export; returns an `AuthFormSkeleton` pre-configured with the `"login"` variant, displayed automatically by Next.js during route transitions or data fetching.

## Usage Example

Next.js automatically renders this component — no manual invocation needed. Simply co-locate the file with the login route:

```text
app/
└── auth/
    └── login/
        ├── loading.tsx   ← this file
        └── page.tsx
```

```typescript
// Next.js picks this up automatically during suspense/loading states.
// To customise the skeleton, update AuthFormSkeleton's "login" variant instead.
import { AuthFormSkeleton } from '../components/auth-page-skeleton';

<AuthFormSkeleton variant="login" />
```

## Notes

- Relies on [`AuthFormSkeleton`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/auth/components/auth-page-skeleton.tsx) for the actual skeleton markup; swap the `variant` prop there to change the appearance.
- The `'use client'` directive is required because `AuthFormSkeleton` uses client-side rendering.
