The `/auth` route page: Sign Up, or the login screen in a login-only mobile build (which has no sign-up to offer).

## Key Components

- **AuthRootPage()** - Default exported page component; renders `LoginPage` when `useLoginOnlyMobileShell()` is true, else `AuthPage`.

## Usage Example

```typescript
'use client';

import AuthPage from '@/app/(auth)/auth/pages/auth-page';
import LoginPage from '@/app/(auth)/auth/pages/login-page';
import { useLoginOnlyMobileShell } from '@/app/hooks/use-login-only-mobile-shell';

export default function AuthRootPage() {
  return useLoginOnlyMobileShell() ? <LoginPage /> : <AuthPage />;
}
```

Each screen draws its own loading state; the page has no route-level loading component.
