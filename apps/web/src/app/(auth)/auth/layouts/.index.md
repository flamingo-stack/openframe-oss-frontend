Reusable layout wrapper for OpenFrame authentication pages, providing a responsive 50/50 split between auth form content and a benefits panel.

## Key Components

- **`AuthLayout`** — Client component that wraps auth page children in a two-column layout. Left side renders the passed `children` (forms, prompts, etc.) with vertical centering; right side renders the static `AuthBenefitsSection`.
- **`AuthLayoutProps`** — Interface accepting `children: React.ReactNode`.
- **`AuthBenefitsSection`** — Imported sub-component occupying the right column.

## Layout Behavior

| Breakpoint | Behavior |
|---|---|
| Mobile (`< lg`) | Single column, stacked vertically, full-width panels |
| Desktop (`lg+`) | Two columns, 50/50 split, right/left panels each `h-screen` with `overflow-y-auto` on left |

## Usage Example

```typescript
import { AuthLayout } from '@/features/auth/layout';

export default function LoginPage() {
  return (
    <AuthLayout>
      <LoginForm />
    </AuthLayout>
  );
}
```

## Notes

- Marked `'use client'` — required for any auth pages using interactive form state.
- Left column uses `overflow-y-auto` at `lg` breakpoint to support tall form content without disrupting the fixed viewport layout.
- Background color driven by the `bg-ods-bg` design system token.
