A client-side React layout component that provides a consistent 50/50 split UI structure for all OpenFrame authentication pages (login, signup, password reset, etc.), with responsive behavior and vertical centering.

## Key Components

- **`AuthLayout`** — The main exported layout component that wraps auth page content. Accepts `children` and renders them alongside a fixed benefits panel.
- **`AuthLayoutProps`** — TypeScript interface defining the component's props, requiring a `children: React.ReactNode` prop.
- **`AuthBenefitsSection`** — Imported component rendered on the right side of the layout, displaying marketing/benefits content (defined in `../components/benefits-section`).

## Layout Behavior

- **Mobile (default):** Stacks content vertically in a single column (`flex-col`), scrollable as normal page flow.
- **Desktop (`lg` breakpoint and up):** Splits into two horizontal halves (`flex-row`), each taking 50% width (`lg:w-1/2`), with the full viewport height locked (`lg:h-screen lg:overflow-hidden`) and independent scrolling enabled on the left auth content panel (`lg:overflow-y-auto`).
- The left panel vertically centers its children using `justify-center` and applies consistent padding/gap spacing.

## Usage Example

```typescript
import { AuthLayout } from './index';

export default function LoginPage() {
  return (
    <AuthLayout>
      <h1>Sign In</h1>
      <LoginForm />
    </AuthLayout>
  );
}
```

```typescript
import { AuthLayout } from './index';

export default function SignupPage() {
  return (
    <AuthLayout>
      <h1>Create Account</h1>
      <SignupForm />
    </AuthLayout>
  );
}
```

This component is intended to be used as a shared wrapper across all auth-related routes to maintain visual consistency, found in the repository at `https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/path/to/index.tsx`.
