# Auth Error Page

Next.js client page component that renders the authentication error screen, resolving the error message server-side via a reference token rather than trusting any client-supplied query text.

This design closes a security gap in the previous implementation, which rendered an arbitrary `?error=<text>` query parameter directly as the displayed message — allowing anyone to craft a URL showing attacker-controlled text under the app's branding. Instead, only an opaque `ref` identifier is read from the URL, and the actual message is fetched from the auth server via `useAuthErrorMessage`.

## Key Components

- **`AuthErrorPage`** (default export) — Entry point rendering `AuthErrorScreen` with a dynamic description slot.
- **`AuthErrorFromUrl`** — Wraps the description in a `LoadingSuspense` boundary so only this part of the page waits on `useSearchParams` (which forces client-side rendering during static prerender), keeping the screen's title and navigation links statically rendered.
- **`AuthErrorFromUrlReader`** — Detects if currently inside a loading/fallback scope (`useLoadingScope`) and renders a loading-state `AuthErrorDescription` without reading the URL.
- **`AuthErrorFromUrlLive`** — Reads the `ref` param from `useSearchParams`, calls `useAuthErrorMessage(ref)`, and renders the resolved (or loading) description.

## Usage Example

This page is used as a route file (e.g., `app/auth-error/page.tsx`) and requires no props, since Next.js renders it automatically for the matching route:

```typescript
// Navigating to an error state, e.g.:
// /auth-error?ref=abc123

// The page will:
// 1. Render AuthErrorScreen with static title/actions immediately
// 2. Suspend only the description while resolving `ref`
// 3. Fetch the server-stored message for `abc123` via useAuthErrorMessage
// 4. Display the resolved message, a catalog sentence, or a generic fallback
```

No query parameter value is ever rendered directly — only the `ref` is read, and the displayed text always originates from the trusted auth server response.
