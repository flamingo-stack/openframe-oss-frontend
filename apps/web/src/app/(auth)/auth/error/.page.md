A Next.js client-side page that renders a user-facing authentication error screen, displaying a title and description derived from URL search params, with options to contact support or return to login.

## Key Components

- **`AuthErrorPage`** — Default export; a React component that reads the `error` query parameter from the URL and renders a branded error UI with two action buttons.
- **`DEFAULT_ERROR`** — Fallback title and description constants used when no specific error code is present in the URL.

## Usage Example

This page is rendered automatically by Next.js when navigating to the `/auth/error` route (or equivalent). To trigger a specific error message, append an `error` query parameter:

```typescript
// Redirect to this page with a custom error message
router.push('/auth/error?error=SessionExpired');

// Or with a generic error (falls back to DEFAULT_ERROR.description)
router.push('/auth/error');
```

The component resolves the displayed message as follows:

```typescript
// If ?error=SessionExpired is present:
// title       → 'Oops, Something Went Wrong'
// description → 'SessionExpired'

// If no ?error param:
// title       → 'Oops, Something Went Wrong'
// description → 'An unexpected error occurred. Please try again or contact support...'
```

**Action buttons:**

| Button | Behavior |
|---|---|
| **Contact Support** | Opens `https://www.flamingo.run/contact` in a new tab |
| **Go to Login** | Navigates to `/auth` via `router.push` |
