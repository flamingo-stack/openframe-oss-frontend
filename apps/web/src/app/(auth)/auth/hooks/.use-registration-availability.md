# use-registration-availability.ts

Client-side React hooks for debounced, real-time availability checks of email addresses and subdomains during the registration flow, used to give users immediate feedback before form submission.

## Key Components

- **`AvailabilityStatus`** — Union type representing check states: `'idle' | 'checking' | 'available' | 'taken' | 'blocked' | 'error'`.
- **`BLOCKED_EMAIL_DOMAIN_MESSAGE`** — User-facing message shown when an email domain is disposable/privacy-focused and thus blocked.
- **`useEmailAvailability(email, delay?)`** — Debounces the given email, validates its format, and queries `authApiClient.checkEmailAvailability` to determine if it's available, taken, blocked, or errored. Returns an `AvailabilityStatus`.
- **`useDomainAvailability(subdomain, orgName, enabled, delay?)`** — Debounces both subdomain and organization name inputs, then queries `authApiClient.checkDomainAvailability`. Returns `{ status, suggestions }`, where `suggestions` contains alternate subdomain names (with the SaaS domain suffix stripped) when the requested one is taken.

Both hooks update their "verdict" synchronously during render (keyed to the current debounced input) rather than in an effect, avoiding a one-frame flash of stale results when the input changes — effects are reserved strictly for the async network request.

## Usage Example

```typescript
import { useEmailAvailability, useDomainAvailability, BLOCKED_EMAIL_DOMAIN_MESSAGE } from './use-registration-availability';

function SignupStepOne() {
  const [email, setEmail] = useState('');
  const [orgName, setOrgName] = useState('');
  const [subdomain, setSubdomain] = useState('');

  const emailStatus = useEmailAvailability(email);
  const { status: domainStatus, suggestions } = useDomainAvailability(subdomain, orgName, Boolean(orgName));

  return (
    <div>
      <input value={email} onChange={e => setEmail(e.target.value)} />
      {emailStatus === 'taken' && <span>Email already registered</span>}
      {emailStatus === 'blocked' && <span>{BLOCKED_EMAIL_DOMAIN_MESSAGE}</span>}

      <input value={subdomain} onChange={e => setSubdomain(e.target.value)} />
      {domainStatus === 'taken' && (
        <ul>{suggestions.map(s => <li key={s}>{s}</li>)}</ul>
      )}
    </div>
  );
}
```
