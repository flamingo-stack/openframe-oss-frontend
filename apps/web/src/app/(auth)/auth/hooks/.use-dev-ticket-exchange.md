# use-dev-ticket-exchange.ts

A React hook that exchanges a development authentication ticket ("devTicket") for session tokens via the auth API, used in development/testing flows to bypass standard login.

## Key Components

- **`useDevTicketExchange()`** — Hook that returns an `exchangeTicket` callback for performing the devTicket exchange flow.
- **`exchangeTicket(ticket: string)`** — Async function that:
  - Calls `authApiClient.devExchange(ticket)` to exchange the ticket for tokens.
  - Stores resulting tokens via `useTokenStorage().storeTokensFromHeaders`.
  - Marks the ticket as settled with `markDevTicketSettled` (both on success and failure) so any pending session check is released.
  - Invalidates the `authSessionQueryKey` query to force `useAuthSession` to resync.
  - Shows a success/failure toast via `useToast`.
  - On successful token retrieval, redirects via `router.replace(getLandingPath())` (replacing history, not pushing) to avoid leaving the dev-ticket screen in the back stack.
  - Returns `{ success, status, tokens }` describing the outcome.

## Usage Example

```typescript
import { useDevTicketExchange } from '@/hooks/use-dev-ticket-exchange';

function DevTicketHandler({ ticket }: { ticket: string }) {
  const { exchangeTicket } = useDevTicketExchange();

  useEffect(() => {
    exchangeTicket(ticket).then((result) => {
      if (!result.success) {
        console.error('DevTicket exchange failed', result.status);
      }
    });
  }, [ticket, exchangeTicket]);

  return <div>Signing in…</div>;
}
```

## Notes

- Designed to work alongside `useAuthSession`: regardless of success or failure, the ticket is always marked settled and the auth session query is invalidated, ensuring the UI never gets stuck in a stale "pending" or "signed out" state.
- Errors from the API call are caught and surfaced via a destructive toast, returning a safe fallback result object instead of throwing.
