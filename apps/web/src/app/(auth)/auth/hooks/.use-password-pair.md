# use-password-pair.ts

A React hook that manages a password and confirmation-password field pair for invite and password-reset forms, handling validation state and user-facing error messages.

## Key Components

- **`usePasswordPair()`** — Hook returning the full state and handlers needed to drive a password + confirm-password UI:
  - `password` / `confirmPassword` — current input values
  - `onPasswordChange` / `onConfirmPasswordChange` — setters to bind to input `onChange` handlers
  - `isValid` — `true` only when the password satisfies validation rules (via `getPasswordError`) **and** matches the confirmation
  - `errors.password` — validation error message (only shown once the password field has been typed into)
  - `errors.confirmPassword` — `"Passwords do not match"` (only shown once confirmation has been typed and differs from password)

This hook depends on `getPasswordError` from `@/app/(auth)/auth/constants/registration-validation` to enforce password strength rules.

## Usage Example

```typescript
'use client';

import { usePasswordPair } from '@/app/(auth)/auth/hooks/use-password-pair';

export function SetPasswordForm() {
  const {
    password,
    confirmPassword,
    onPasswordChange,
    onConfirmPasswordChange,
    isValid,
    errors,
  } = usePasswordPair();

  return (
    <form>
      <input
        type="password"
        value={password}
        onChange={(e) => onPasswordChange(e.target.value)}
      />
      {errors.password && <span>{errors.password}</span>}

      <input
        type="password"
        value={confirmPassword}
        onChange={(e) => onConfirmPasswordChange(e.target.value)}
      />
      {errors.confirmPassword && <span>{errors.confirmPassword}</span>}

      <button type="submit" disabled={!isValid}>
        Set Password
      </button>
    </form>
  );
}
```
