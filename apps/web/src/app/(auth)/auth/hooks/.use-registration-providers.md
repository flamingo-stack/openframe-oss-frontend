## use-registration-providers.ts

A React Query hook that fetches and caches the list of SSO providers available for user registration, used to drive the Sign Up tab's provider buttons.

## Key Components

- **`SsoProvider`** — interface describing a provider entry (`provider` name and `enabled` flag).
- **`registrationProvidersQueryKey`** — exported query key array (`['auth', 'registration-providers']`) for cache access/invalidation from other modules.
- **`useRegistrationProviders()`** — hook that returns `{ providers, loading, error }`:
  - `providers`: `SsoProvider[]`, defaults to `[]` until loaded.
  - `loading`: derived from `isPending` (true only before the query has started/resolved, not during background refetches).
  - `error`: string message or `null`.

## Usage Example

```typescript
import { useRegistrationProviders } from '@/hooks/use-registration-providers';

function SignUpTab() {
  const { providers, loading, error } = useRegistrationProviders();

  if (loading) return <Spinner />;
  if (error) return <p>Could not load sign-up options</p>;

  return (
    <div>
      {providers.map(({ provider }) => (
        <SsoButton key={provider} provider={provider} />
      ))}
    </div>
  );
}
```

**Caching behavior:** The query uses `staleTime: Infinity` and `gcTime: Infinity` since the provider list is fixed for the page's lifetime. This avoids refetching every time the Sign Up tab remounts (e.g., after switching to Login and back), eliminating a visible flash where provider buttons would otherwise pop in late. `retry` is disabled—on failure, the UI simply shows no provider buttons, a state the form already handles gracefully.
