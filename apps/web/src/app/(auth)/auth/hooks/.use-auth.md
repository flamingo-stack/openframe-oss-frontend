## use-auth.ts

Client-side React hook providing authentication actions—tenant discovery, organization registration, login, and logout—for web and native (app shell) environments. It complements `useAuthSession`, which handles auth state checking, by focusing purely on mutating actions and side effects such as navigation, toasts, and token management.

## Key Components

- **`useAuth()`** — Main hook exposing auth state (`email`, `tenantInfo`, `hasDiscoveredTenants`, `availableProviders`, `isLoading`, `isInitialized`) and actions (`discoverTenants`, `registerOrganization`, and related login/logout flows).
- **`discoverTenants(userEmail)`** — Looks up whether a tenant/account exists for a given email, guarding against race conditions from out-of-order async responses via a `latestDiscovery` ref.
- **`registerOrganization(data)`** — Registers a new tenant/organization, handling both web and native (app shell) post-registration flows, including attribution collection and PostHog signup tracking.
- **`nativeLoginToLanding(options)`** — Wraps `nativeLogin`, refetching the auth session and redirecting to the landing page after a successful native sign-in.
- **`signInToContinue()`** — Redirects to the login screen with a toast explaining that registration succeeded but sign-in is still required.
- **`isUserCanceled(error)`** — Utility to detect user-cancelled native auth flows (should not trigger error toasts).
- **`landingReturnUrl()`** — Builds an encoded return URL for OAuth redirects, preserving PostHog session continuity across host transitions.
- **Types:** `TenantInfo`, `TenantDiscoveryResponse`, `SsoLoginTenant`, `RegisterRequest`.

## Usage Example

```typescript
import { useAuth } from '@/hooks/use-auth';

function SignupForm() {
  const { registerOrganization, isLoading } = useAuth();

  const handleSubmit = async () => {
    await registerOrganization({
      tenantName: 'Acme Corp',
      tenantDomain: 'acme.openframe.ai',
      firstName: 'Jane',
      lastName: 'Doe',
      email: 'jane@acme.com',
      password: 'securePassword123',
    });
  };

  return (
    <button onClick={handleSubmit} disabled={isLoading}>
      Create Organization
    </button>
  );
}
```
