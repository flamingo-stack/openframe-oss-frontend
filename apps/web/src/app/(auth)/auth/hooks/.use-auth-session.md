## use-auth-session.ts

Core authentication hook providing the single source of truth for session verification via `/me` endpoint, syncing React Query results into the Zustand auth store. Handles platform-specific bootstrap logic (native shell token hydration, dev-ticket exchange, SaaS shared mode) and implements a resilient polling/backoff strategy to distinguish "not yet resolved" from "definitively signed out."

## Key Components

- **`authSessionQueryKey`** – Shared React Query key (`['auth', 'session']`) for the session query, usable by other hooks/components to invalidate or read cached state.
- **`AuthUnavailableError`** – Custom error class thrown when `/me` fails because the underlying token refresh failed (auth service unavailable), distinguishing it from plain transient errors.
- **`shouldRetryAuthSession(failureCount, error)`** – Retry predicate: never retries `AuthUnavailableError` (already exhausted refresh attempts), retries other errors up to `AUTH_SESSION_RETRIES` times.
- **`useAuthSession()`** – Main hook:
  - Runs the `/me` query with platform-aware short-circuits (SaaS shared mode, app-shell cold start, biometric lock, dev-ticket pending).
  - Treats 401/403 as a definitive "signed out" (`null`), while 5xx/network errors throw to preserve cached data and trigger retries.
  - Uses an exponential backoff (`AUTH_RECHECK_BASE_MS` → `AUTH_RECHECK_MAX_MS`) to re-poll only when the query is in a failed/undecided state.
  - Syncs resolved session data into `useAuthStore` (login/logout, tenant ID, background full-profile fetch).
  - Exposes `recheck()` to force invalidation and `isReady`/`isAuthenticated` style flags based on `isPending` rather than `isLoading`, to correctly handle paused (offline) queries.

## Usage Example

```typescript
import { useAuthSession } from '@/hooks/use-auth-session';

function AppShell() {
  const { query, recheck, isReady, isAuthenticated } = useAuthSession();

  if (!isReady) {
    return <LoadingSkeleton />;
  }

  if (!isAuthenticated) {
    return <RedirectToSignIn />;
  }

  return (
    <div>
      <p>Welcome back!</p>
      <button onClick={recheck}>Refresh session</button>
    </div>
  );
}
```

Use `authSessionQueryKey` elsewhere to invalidate the session cache, e.g. after a manual sign-out action:

```typescript
import { useQueryClient } from '@tanstack/react-query';
import { authSessionQueryKey } from '@/hooks/use-auth-session';

const queryClient = useQueryClient();
queryClient.invalidateQueries({ queryKey: authSessionQueryKey });
```
