## use-organization-domain.ts

A React hook that manages organization subdomain input, validation, and availability checking for tenant creation flows. It centralizes shared logic used across multiple signup/registration screens (password signup, web SSO continuation, and native Apple signup) to ensure consistent subdomain validation behavior, including the special case of cluster-capacity exhaustion.

## Key Components

- **`OrganizationDomainState`** — Interface describing the hook's return shape, including the current domain value, sanitizing setter, blocking/error state, availability status message, suggestions, and the submit-time `confirmAvailability` check.
- **`useOrganizationDomain(organizationName: string)`** — Main hook function that:
  - Sanitizes and tracks the subdomain input (only in shared-auth UI mode).
  - Runs a debounced live availability check via `useDomainAvailability`.
  - Exposes a `confirmAvailability` async function for submit-time re-validation, which re-checks availability to avoid race conditions with the debounced status (critical for the native Apple flow where losing the race wastes a single-use auth code).
  - Distinguishes between a "taken" subdomain (user should pick another) and a `TENANT_REGISTRATION_BLOCKED` error (cluster has no capacity — renaming won't help), surfacing each with distinct toast messaging.
  - Builds a human-readable `statusMessage` (`checking`, `taken`, `available`) for inline UI feedback.

## Usage Example

```typescript
import { useOrganizationDomain } from '@/app/(auth)/auth/hooks/use-organization-domain';

function SignupForm({ organizationName }: { organizationName: string }) {
  const {
    domain,
    setDomain,
    isBlocked,
    formatError,
    isChecking,
    statusMessage,
    suggestions,
    confirmAvailability,
  } = useOrganizationDomain(organizationName);

  const handleSubmit = async () => {
    const fullDomain = await confirmAvailability();
    if (!fullDomain) return; // error already shown to the user via toast
    // proceed with registration using `fullDomain`
  };

  return (
    <div>
      <input value={domain} onChange={e => setDomain(e.target.value)} />
      {formatError && <span>{formatError}</span>}
      {statusMessage && <span>{statusMessage.message}</span>}
      <button disabled={isBlocked || isChecking} onClick={handleSubmit}>
        Continue
      </button>
    </div>
  );
}
```
