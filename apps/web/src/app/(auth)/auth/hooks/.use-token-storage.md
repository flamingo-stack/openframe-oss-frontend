React hook facade over the token store, providing a stable API for storing, retrieving, and clearing authentication tokens across iOS Keychain (native shell) and localStorage (web/dev-ticket mode).

## Key Components

**Exports**
- `useTokenStorage` — Primary hook returning token management callbacks
- `ACCESS_TOKEN_KEY` / `REFRESH_TOKEN_KEY` — Re-exported constants from `token-store` for existing consumers

**Hook Methods**

| Method | Description |
|---|---|
| `storeAccessToken(token)` | Persists a single access token |
| `storeRefreshToken(token)` | Persists a single refresh token |
| `storeTokensFromHeaders(headers)` | Extracts and stores both tokens from HTTP response headers (`Access-Token`, `Refresh-Token`) |
| `getAccessToken()` | Synchronous read of the current access token |
| `getRefreshToken()` | Synchronous read of the current refresh token |
| `clearTokens()` | Clears all stored tokens |

All methods are memoized with `useCallback` (empty deps) so references are stable across renders.

## Usage Example

```typescript
import { useTokenStorage } from '@/hooks/use-token-storage';

function AuthHandler() {
  const { storeTokensFromHeaders, getAccessToken, clearTokens } = useTokenStorage();

  async function handleLoginResponse(response: Response) {
    // Automatically reads 'Access-Token' and 'Refresh-Token' headers
    const { accessToken } = await storeTokensFromHeaders(response.headers);
    console.log('Stored token:', accessToken);
  }

  async function handleLogout() {
    await clearTokens();
  }

  const currentToken = getAccessToken(); // synchronous
}
```

> **Note:** This hook is a thin facade — all persistence logic lives in [`src/lib/token-store.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/token-store.ts). Prefer importing directly from `token-store` in new code; this hook exists for backward compatibility.
