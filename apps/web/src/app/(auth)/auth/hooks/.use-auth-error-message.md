# use-auth-error-message.ts

A React Query hook that resolves an opaque `ref` parameter from the `/auth/error` page into a user-facing error description, falling back to a generic message when the reference is invalid, missing, or the lookup fails.

This hook deliberately avoids trusting or displaying anything derived directly from the URL. Instead, it treats the `ref` as an opaque lookup key: if it's not a valid auth error reference (per `isAuthErrorRef`), the query is skipped entirely and the fallback copy is shown. Otherwise, it fetches the server's stored message for that reference, since errors occur server-side and the server is the sole source of truth for what the user should see.

## Key Components

- **`AUTH_ERROR_FALLBACK`** — Constant object with `title` and `description` shown when no better information is available (invalid ref, failed lookup, etc.). The description intentionally mirrors the server's own `UNEXPECTED` message.
- **`authErrorMessageQueryKey(ref)`** — Builds the React Query cache key for a given reference, exported for use in tests or cache invalidation.
- **`AuthErrorCopy`** — Interface describing the hook's return shape: `title`, `description`, and `isLoading`.
- **`useAuthErrorMessage(ref)`** — The main hook. Validates the `ref`, queries `authApiClient.authErrorMessage` when valid, and returns display-ready copy. Configured with `retry: false` (terminal page, no point retrying) and `staleTime: Infinity` (a resolved reference won't improve with time).

## Usage Example

```typescript
import { useSearchParams } from 'next/navigation';
import { useAuthErrorMessage } from '@/hooks/use-auth-error-message';

export function AuthErrorPage() {
  const searchParams = useSearchParams();
  const ref = searchParams.get('ref');
  const { title, description, isLoading } = useAuthErrorMessage(ref);

  if (isLoading) {
    return <LoadingSpinner />;
  }

  return (
    <div>
      <h1>{title}</h1>
      <p>{description}</p>
    </div>
  );
}
```
