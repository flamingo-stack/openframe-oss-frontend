# auth-error-screen.tsx

Client component that renders the generic authentication error screen shown whenever an auth flow fails. It displays a static title with a dynamically-resolved error description, plus actions to contact support or return to the login page.

## Key Components

- **`AuthErrorScreen({ description })`** — Main error screen component. Renders inside `AuthStatusFrame` with a fixed title (from `AUTH_ERROR_FALLBACK`), the provided `description` node, and two actions:
  - "Contact Support" — opens `https://www.flamingo.run/contact` in a new tab
  - "Go to Login" — navigates to `routes.auth.root` via Next.js router
- **`AuthErrorDescription({ text })`** — Renders the server-provided error description using `LoadingParagraph`. Shows a loading state while `text` is `undefined`, since the description is resolved asynchronously from the auth server's response for the URL's `ref` parameter.

## Usage Example

```typescript
import { AuthErrorScreen, AuthErrorDescription } from './auth-error-screen';

function AuthErrorPage({ errorText }: { errorText?: string }) {
  return (
    <AuthErrorScreen
      description={<AuthErrorDescription text={errorText} />}
    />
  );
}
```

The `description` prop is passed as a `ReactNode`, decoupling `AuthErrorScreen` (static layout/actions) from `AuthErrorDescription` (async content resolution). This allows callers to pass custom description content or loading states as needed, while `AuthErrorScreen` remains purely presentational.
