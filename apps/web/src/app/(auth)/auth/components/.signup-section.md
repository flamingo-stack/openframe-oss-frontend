# signup-section.tsx

Client-side React component rendering the final signup form in the authentication flow, allowing users to complete their account/organization registration with personal details, password, and optional SSO sign-up.

## Key Components

- **`AuthSignupSection`** — Main exported component that renders the signup form UI, including:
  - Read-only organization name and domain fields (pre-filled from a prior step)
  - Editable first name, last name, email, password, and confirm password fields
  - Inline validation (email format, password match, minimum password length in SaaS shared mode)
  - Optional SSO provider list (via `AuthProvidersList`) when registration providers are available
  - Back and submit action buttons

- **`RegisterRequest`** — Interface describing the payload shape (`tenantName`, `tenantDomain`, `firstName`, `lastName`, `email`, `password`) passed to `onSubmit`.

- **`AuthSignupSectionProps`** — Props interface defining required inputs (`orgName`, `domain`, `onSubmit`, `onBack`, `isLoading`) and optional inputs (`email`, `onSso`).

- Relies on `useRegistrationProviders` hook to fetch available SSO providers and `isSaasSharedMode` to toggle SaaS-specific validation/copy (e.g., "Start Free Trial" vs "Create Organization").

## Usage Example

```typescript
import { AuthSignupSection } from './signup-section';

function SignupStep() {
  const [isLoading, setIsLoading] = useState(false);

  const handleSubmit = async (data: RegisterRequest) => {
    setIsLoading(true);
    await registerTenant(data);
    setIsLoading(false);
  };

  return (
    <AuthSignupSection
      orgName="Acme Corp"
      domain="acme"
      onSubmit={handleSubmit}
      onSso={(provider) => redirectToSso(provider)}
      onBack={() => goToPreviousStep()}
      isLoading={isLoading}
    />
  );
}
```

Form submission is gated by client-side validation (`isFormValid`): first name, last name, a valid email, and matching non-empty passwords are required before `onSubmit` fires.
