# auth-announcement-bar.tsx

Client component that renders the hub's announcement bar above the shared-auth host's auth pages (sign-in, sign-up, etc.), only when the app is running in SaaS shared mode. It publishes its rendered height as a CSS custom property so auth page shells can size themselves to the remaining viewport space.

## Key Components

- **`HUB_ENDPOINTS`** — `EndpointsRuntime` config object pointing to the hub's public API endpoints (announcements, access code validation/consumption, contact form), built from `HUB_PUBLIC_API`.
- **`ANNOUNCEMENT_HEIGHT_VAR`** — Name of the CSS custom property (`--announcement-h`) published on `<body>` to communicate the bar's live height.
- **`AuthAnnouncementBar()`** — Default-exported component that:
  - Checks `isSaasSharedMode()` to decide whether to render at all (returns `null` otherwise).
  - Uses a `ResizeObserver` to track the bar's height and write it to `document.body.style` as `--announcement-h`.
  - Cleans up the observer and removes the CSS property on unmount.
  - Wraps `AnnouncementBar` (from `@flamingo-stack/openframe-frontend-core/components`) with `EndpointsRuntimeContext.Provider` so it fetches data from the hub's endpoints.

## Usage Example

```typescript
import { AuthAnnouncementBar } from '@/components/auth-announcement-bar';

export default function AuthLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <AuthAnnouncementBar />
      <main className="auth-shell">{children}</main>
    </>
  );
}
```

Consumers (e.g., `globals.css`) can read the published height to reserve space for the bar:

```css
.auth-shell {
  min-height: calc(100vh - var(--announcement-h, 0px));
}
```

The component renders nothing when `isSaasSharedMode()` is `false`, making it safe to include unconditionally in layouts.
