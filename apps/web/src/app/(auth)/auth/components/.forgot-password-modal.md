A React client component that renders a modal dialog allowing users to request a password reset link by submitting their email address.

## Key Components

- **`ForgotPasswordModal`** — Main exported component rendering an `AlertDialog` with an email input form.
- **`ForgotPasswordModalProps`** — Props interface:
  - `open: boolean` — controls modal visibility.
  - `onOpenChange: (open: boolean) => void` — callback invoked when modal visibility changes.
  - `defaultEmail?: string` — optional pre-filled email address.
- **`handleSubmit`** — Validates the email field, calls `authApiClient.requestPasswordReset`, and shows success/error toasts via `useToast`.
- **`handleOpenChange`** — Wraps `onOpenChange` to prevent closing the modal while a submission is in progress and resets the email field on close.

## Usage Example

```typescript
import { useState } from 'react';
import { ForgotPasswordModal } from '@/components/forgot-password-modal';

function LoginForm() {
  const [showForgotPassword, setShowForgotPassword] = useState(false);

  return (
    <>
      <button onClick={() => setShowForgotPassword(true)}>
        Forgot password?
      </button>

      <ForgotPasswordModal
        open={showForgotPassword}
        onOpenChange={setShowForgotPassword}
        defaultEmail="user@example.com"
      />
    </>
  );
}
```

The component depends on `authApiClient` from `@/lib/auth-api-client` to send the password reset request, and on shared UI primitives (`AlertDialog`, `Button`, `Input`, `Label`) and the `useToast` hook from `@flamingo-stack/openframe-frontend-core`.
