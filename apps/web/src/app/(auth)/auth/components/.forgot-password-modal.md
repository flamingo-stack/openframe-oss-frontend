A modal dialog component for initiating password reset flows, allowing users to submit their email address to receive a password reset link.

## Key Components

### `ForgotPasswordModal`

The primary exported component — a controlled `AlertDialog` that handles password reset email submission.

**Props (`ForgotPasswordModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open state changes |
| `defaultEmail` | `string` (optional) | Pre-fills the email input (defaults to `''`) |

**Internal state:**
- `email` — tracks the email input value
- `isSubmitting` — disables inputs and shows loading state during API call

**Key behaviors:**
- Calls `authApiClient.requestPasswordReset()` on submit
- Shows success/error toasts via `useToast`
- Blocks dismissal while a submission is in progress
- Resets email to `defaultEmail` when closed
- Supports `Enter` key to submit

## Usage Example

```typescript
import { ForgotPasswordModal } from '@/components/forgot-password-modal';
import { useState } from 'react';

export function LoginPage() {
  const [showReset, setShowReset] = useState(false);
  const [userEmail, setUserEmail] = useState('');

  return (
    <>
      <button onClick={() => setShowReset(true)}>Forgot Password?</button>
      <ForgotPasswordModal
        open={showReset}
        onOpenChange={setShowReset}
        defaultEmail={userEmail}
      />
    </>
  );
}
```
