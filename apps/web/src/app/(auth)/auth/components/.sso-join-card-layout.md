# sso-join-card-layout.tsx

A minimal, standalone layout component that centers a single card on the page background—used for auth flows that require focused, distraction-free screens without tabs or marketing panels.

## Key Components

- **`SsoJoinCardLayout`** — A layout wrapper component that accepts `children` (`ReactNode`) and renders them inside a centered, max-width card container on a full-height page background.

This component is used for:
- The "One Last Step" SSO join flow, where the shared `SsoJoinForm` (or its loading skeleton) is rendered as the card content.
- The invite-link notice screen, another standalone auth page with the same visual footprint.
- The desktop sign-in hand-off page (`/auth/desktop-return`), which reuses this layout for consistency.

Unlike multi-panel auth layouts (e.g., those with benefits sidebars or tabs), this layout is intentionally bare—appropriate for flows where the user is mid-process and no additional selling or navigation is needed.

## Usage Example

```typescript
import { SsoJoinCardLayout } from '@/components/layouts/sso-join-card-layout';
import { SsoJoinForm } from '@/components/sso-join-form';

export default function SsoJoinPage() {
  return (
    <SsoJoinCardLayout>
      <SsoJoinForm />
    </SsoJoinCardLayout>
  );
}
```

```typescript
// While identity data is loading, render a skeleton instead
import { SsoJoinCardLayout } from '@/components/layouts/sso-join-card-layout';
import { SsoJoinFormSkeleton } from '@/components/sso-join-form-skeleton';

export default function SsoJoinLoadingPage() {
  return (
    <SsoJoinCardLayout>
      <SsoJoinFormSkeleton />
    </SsoJoinCardLayout>
  );
}
```

The layout uses design-system spacing tokens (`--spacing-system-l`) and background tokens (`bg-ods-bg`) to ensure visual consistency with the rest of the application's auth screens.
