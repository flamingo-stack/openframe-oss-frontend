Provides a reusable layout wrapper for standalone authentication status pages, arranging a logo header, centered page content, and a branding footer in a full-height column.

## Key Components

- **`AuthStatusFrame`** — Client component that renders a full-viewport flex layout containing:
  - `OpenframeLockup` — logo displayed at the top
  - `children` — the page-specific content, centered between header and footer
  - `PoweredByFlamingo` — branding footer element

## Usage Example

```typescript
import { AuthStatusFrame } from '@/app/components/shared/auth-status-frame';

export default function AuthErrorPage() {
  return (
    <AuthStatusFrame>
      <div className="text-center">
        <h1 className="text-xl font-semibold">Authentication Error</h1>
        <p className="text-ods-text-secondary">
          Something went wrong while verifying your session. Please try again.
        </p>
      </div>
    </AuthStatusFrame>
  );
}
```

This component is intended for use on isolated, full-page auth flows such as `/auth/error` and `/auth/verify`, where a consistent, minimal layout (logo + content + footer) is needed without the main application chrome.
