# dev-ticket-observer.tsx

A global, invisible React component that watches the URL for a `devTicket` query parameter and automatically triggers a token exchange flow when one is detected. This supports development/testing login flows in web contexts, while explicitly excluding native app shells that handle ticket exchange through a separate native plugin.

## Key Components

- **`DevTicketObserver`** — Client component (`'use client'`) that renders no UI (`return null`). It should be mounted once near the root of the application layout.
  - Uses `useSearchParams` (Next.js) to read the current URL's `devTicket` parameter.
  - Uses `useDevTicketExchange` hook to perform the actual ticket-for-token exchange.
  - Uses a `useRef` (`lastTicket`) to prevent re-triggering the exchange for the same ticket value across re-renders.
  - Gated by `runtimeEnv.enableDevTicketObserver()` (controlled via the `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` environment variable) and `isAppShell()` (skips execution entirely inside the native mobile app shell, since mobile logins are handled via `NativeAuth` and custom URL schemes instead).

## Usage Example

```typescript
// app/layout.tsx
import { DevTicketObserver } from '@/components/dev-ticket-observer';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <DevTicketObserver />
        {children}
      </body>
    </html>
  );
}
```

When a URL such as `https://app.example.com/dashboard?devTicket=abc123` is loaded in a web browser (with the feature flag enabled), the component detects the `devTicket` parameter and calls `exchangeTicket('abc123')` exactly once, avoiding duplicate exchanges on subsequent re-renders with the same value.
