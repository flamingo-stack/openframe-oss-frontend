# login-form-section.tsx

Client component that wires the shared `LoginForm` UI to the application's login flow. It drives debounced, real-time tenant discovery from the email field and dynamically swaps between generic SSO providers and a discovered tenant's own configured login methods.

## Key Components

- **`LoginDiscoveryResult`** — Interface describing the outcome of a tenant discovery lookup for a given email (whether found, resolved tenant, OpenFrame login availability, and custom SSO providers).
- **`toLoginDiscoveryResult(response)`** — Maps a raw `TenantDiscoveryResponse` (from the discovery API) into a normalized `LoginDiscoveryResult`, handling legacy provider IDs and single-tenant dev backend quirks (for example, `localhost` domain).
- **`LoginSection(props)`** — Main component. Manages:
  - Debounced (400ms) email-based tenant discovery, with Enter-to-lookup-now and retry-on-error support.
  - A 10-second discovery timeout that treats a stalled request as a failure.
  - Race-safe answer tracking so a stale lookup response never overwrites a newer one.
  - Dynamic SSO button set: shows the tenant's own providers (and/or built-in OpenFrame login) once discovered, falling back to generic providers otherwise.
  - A mobile "login-only" variant that shows an invitation notice instead of a sign-up prompt for unknown emails (via `useLoginOnlyMobileShell`).
- **`LoginSectionProps`** — Props contract: `onDiscover`, `onSso`, `genericProviders`, `isLoading`.

## Usage Example

```typescript
import { LoginSection } from '@/app/(auth)/auth/components/login-form-section';
import { useAuth } from '@/app/(auth)/auth/hooks/use-auth';

export function LoginPage() {
  const { discoverTenant, loginWithSso, genericSsoProviders, isLoading } = useAuth();

  return (
    <LoginSection
      onDiscover={async (email) => {
        const response = await discoverTenant(email);
        return response ? toLoginDiscoveryResult(response) : null;
      }}
      onSso={(provider, tenant) => loginWithSso(provider, tenant)}
      genericProviders={genericSsoProviders}
      isLoading={isLoading}
    />
  );
}
```
