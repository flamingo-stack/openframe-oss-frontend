# download-link-section.tsx

Client component implementing the "Send me download link" form, where a visitor submits their work email to receive the OpenFrame installer links. Mirrors the copy and behavior of the marketing site's dialog it replaces.

## Key Components

- **`DOWNLOAD_LINK_COPY`** — Centralized object holding all user-facing strings (titles, labels, error messages, success/failure states) for the form.
- **`downloadLinkSchema`** — Zod schema validating a single trimmed, required email field.
- **`DownloadLinkValues`** — Inferred TypeScript type from `downloadLinkSchema`.
- **`DownloadLinkSection()`** — Default exported component rendering either the email capture form or a "check your inbox" success state, depending on mutation status.

## Behavior Notes

- Uses `react-hook-form` with `zodResolver` for client-side validation (`mode: 'onTouched'`).
- Submits via `useMutation` to `authApiClient.requestDownloadLink`, including a hidden honeypot field (`website`) for spam filtering — the backend silently drops honeypot-filled requests without signaling this back to the client.
- Because the backend always responds success regardless of filtering, `request.isSuccess` is the only driver for showing the "Check your inbox" message; genuine failures (network/API errors) show a toast and keep the form visible.
- Includes `HUBSPOT_DO_NOT_COLLECT_FORM_PROPS` spread on the `<form>` to opt out of HubSpot's automatic field tracking.
- The "Back to OpenFrame" button links to the production OpenFrame platform URL via `getPlatformUrl`.

## Usage Example

```typescript
import { DownloadLinkSection } from '@/components/download-link-section';

export default function DownloadPage() {
  return (
    <main className="flex min-h-screen items-center justify-center p-8">
      <div className="w-full max-w-md">
        <DownloadLinkSection />
      </div>
    </main>
  );
}
```

No props are required — the component is fully self-contained, managing its own form state, submission, and success/error UI.
