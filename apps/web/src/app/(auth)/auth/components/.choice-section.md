## choice-section.tsx

A client-side React component that renders the authentication landing UI, combining a "Create Organization" form (with real-time email/domain availability checks) and a "Sign In" form, plus a forgot-password modal trigger.

## Key Components

- **`AuthChoiceSection`** — Default exported component accepting `onCreateOrganization`, `onSignIn`, and `isLoading` props. Manages local form state for organization name, domain, org email, and sign-in email.
- **Validation regexes** — `orgNameRegex` and `emailRegex` validate organization name and email formats client-side before submission.
- **`useEmailAvailability` / `useDomainAvailability`** — Debounced hooks (imported from `../hooks/use-registration-availability`) that provide live `checking` / `available` / `taken` / `blocked` status for email and domain fields.
- **`handleCreateOrganization`** — Async handler that validates inputs, blocks submission while availability checks are pending/failed, and (in SaaS-shared mode) calls `authApiClient.checkDomainAvailability` to verify subdomain availability before invoking `onCreateOrganization`. Handles `409 TENANT_REGISTRATION_BLOCKED` errors with a dedicated toast message.
- **`handleSignIn`** — Async handler guarding against duplicate submissions via `isSigningIn` state, delegating to `onSignIn`.
- **`ForgotPasswordModal`** — Rendered conditionally via `showForgotPassword` state.
- **`CHECKING_AVAILABILITY`** — Shared loading-status string shown under inputs during async checks.

## Usage Example

```typescript
import { AuthChoiceSection } from './choice-section';

function AuthPage() {
  const handleCreateOrg = (orgName: string, domain: string, email: string) => {
    // kick off organization creation flow
  };

  const handleSignIn = async (email: string) => {
    // navigate to password step or send magic link
  };

  return (
    <AuthChoiceSection
      onCreateOrganization={handleCreateOrg}
      onSignIn={handleSignIn}
      isLoading={false}
    />
  );
}
```

Behavior adapts automatically based on `isSaasSharedMode()`: in SaaS-shared deployments, the domain field appends `SAAS_DOMAIN_SUFFIX` and performs server-side availability checks with suggested alternatives; in self-hosted mode, the domain field accepts free-form input without suffix or availability checks.
