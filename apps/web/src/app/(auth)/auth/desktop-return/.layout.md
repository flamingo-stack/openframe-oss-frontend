Defines page-level metadata and layout for the Desktop Sign-In route, re-exporting a shared layout component while overriding the document title.

## Key Components

- **`metadata`** — Next.js `Metadata` object that sets the browser tab title to "Desktop Sign-In" using the `routeTitle` helper for consistent title formatting across the app.
- **Default export** — Re-exported from `@/app/(app)/route-title-layout`, reusing the shared layout implementation instead of defining a new one.

## Usage Example

This file is a Next.js route segment layout and is not imported manually—Next.js automatically applies it to all pages under the same route segment:

```typescript
// app/desktop-sign-in/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Desktop Sign-In') };
```

Any page placed in the same directory (e.g., `app/desktop-sign-in/page.tsx`) will automatically inherit this layout and the "Desktop Sign-In" browser tab title, keeping metadata handling centralized and consistent with other routes that use the shared `route-title-layout` component.
