Standalone authentication action for performing a full logout flow outside the React component lifecycle, allowing callers (like `AppShell`) to trigger logout without the complete `useAuth` hook.

## Key Components

- **`performLogout()`** — Async function that executes the complete logout sequence:
  1. Reads `tenantId`/`user` from `useAuthStore` to resolve the effective tenant
  2. Unregisters the native push token on mobile shells (best-effort, before session teardown since it needs the bearer token)
  3. Calls `authApiClient.logoutAsync(tenantId)` to invalidate the server-side session
  4. Clears the local auth store via `storeLogout()`
  5. Clears the Mingo working context (`clearMingoContext()`) to prevent leakage across sessions on shared browsers
  6. Clears stored tokens if running in bearer auth mode (awaited to avoid racing navigation)
  7. Navigates to the appropriate destination depending on shell type (app shell reloads SPA root; shared-host or standard web redirects to the login route)

## Usage Example

```typescript
import { performLogout } from '@/lib/auth-actions';

// In a component that only needs logout, without the full useAuth hook
async function handleLogoutClick() {
  await performLogout();
}
```

```typescript
// Example: wiring into a button in AppShell
export function LogoutButton() {
  return (
    <button onClick={() => performLogout()}>
      Log Out
    </button>
  );
}
```

**Notes:**
- Navigation uses `window.location.replace` (not `assign`) so the logged-out state can't be reached via browser back button.
- Behavior differs by shell: app shell reloads the SPA root, shared-host environments redirect to a shared login URL, and standard web redirects to the default login route.
- Push unregistration is mobile-shell-specific and intentionally best-effort (wrapped in a silent `catch`).
