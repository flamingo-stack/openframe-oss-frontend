# registration-validation.ts

Centralized validation rules (regexes, error messages, and helper functions) for all registration and account-related forms. These constants mirror the auth server's own validation logic (`CoreUserRequest`, `TenantRegistrationRequest`, `PasswordResetDtos`, `@ValidEmail`, `@TenantDomain` from `openframe-oss-lib`), ensuring client-side and server-side validation never diverge.

## Key Components

- **`ORG_NAME_REGEX` / `ORG_NAME_ERROR`** — Validates organization names (2-100 chars, letters/digits/punctuation).
- **`EMAIL_REGEX`** — Loose email shape check for lookup-only endpoints (login discovery, availability).
- **`VALID_EMAIL_REGEX` / `INVALID_EMAIL_ERROR`** — Strict email validation matching the server's `@ValidEmail`, used for registration and password reset.
- **`PERSON_NAME_REGEX` / `PERSON_NAME_ERROR`** — Validates first/last names (letters, apostrophes, spaces, hyphens; max 50 chars), with a UI-friendly short error message.
- **`MIN_PASSWORD_LENGTH` / `PASSWORD_TOO_SHORT_ERROR`** — Minimum password length (8) and its error.
- **`PASSWORD_COMPLEXITY_REGEX` / `PASSWORD_COMPLEXITY_ERROR`** — Enforces uppercase, lowercase, digit, and special character.
- **`PASSWORDS_DO_NOT_MATCH_ERROR`** — Shared mismatch error message.
- **`TENANT_SUBDOMAIN_REGEX` / `TENANT_SUBDOMAIN_ERROR`** — Validates slugified subdomains (no leading/trailing/double hyphens).
- **`normalizePersonName(value)`** — Trims input and converts typographic apostrophes (`’`) to plain (`'`) before submission.
- **`isValidPersonName(value)`** — Validates a name after normalization.
- **`getPasswordError(password)`** — Returns the first applicable password error (length, then complexity), or `undefined` if valid.
- **`sanitizeSubdomain(value)`** — Strips invalid characters from subdomain input in real time.

## Usage Example

```typescript
import {
  isValidPersonName,
  normalizePersonName,
  getPasswordError,
  sanitizeSubdomain,
  VALID_EMAIL_REGEX,
  INVALID_EMAIL_ERROR,
  PASSWORDS_DO_NOT_MATCH_ERROR,
} from './registration-validation';

// Validate a name field
const firstName = "O’Brien";
if (!isValidPersonName(firstName)) {
  console.error('Invalid name');
}
const normalized = normalizePersonName(firstName); // "O'Brien"

// Validate email
if (!VALID_EMAIL_REGEX.test(email)) {
  showError(INVALID_EMAIL_ERROR);
}

// Validate password
const passwordError = getPasswordError(password);
if (passwordError) {
  showError(passwordError);
} else if (password !== confirmPassword) {
  showError(PASSWORDS_DO_NOT_MATCH_ERROR);
}

// Sanitize subdomain input as the user types
const cleanSubdomain = sanitizeSubdomain(userInput);
```
