The main authentication page component that handles new organization registration, rendering the sign-up form with SSO provider options and managing redirects for already-authenticated users.

## Key Components

- **`AuthPage`** — Default export; Next.js page component mounted at the `/auth` route
- **`useAuth`** — Provides `isLoading` state, `loginWithSso` and the `registerOrganization` mutation
- **`useRegistrationProviders`** — Fetches available SSO providers from the backend
- **`useAuthStore`** — Reads `isAuthenticated` to guard against re-entering the auth flow
- **`CreateOrganizationSection`** — Two-step sign-up: email, then organization and account details

## Behavior Notes

- Authenticated users are redirected to the dashboard via `router.replace` (not `push`), preventing `/auth` from remaining in the back stack
- The shell, tab selector, authenticated-user redirect and prefetching live in `(tabs)/layout.tsx`, which stays mounted across a tab switch
- Email/password sign-up is one screen; `registerOrganization` submits directly and lands on `/auth/check-email/`
- SSO registration offers `google`, `microsoft` and `apple` (Apple gated on `useIsApplePlatform`), cross-referenced against what the backend reports as available
