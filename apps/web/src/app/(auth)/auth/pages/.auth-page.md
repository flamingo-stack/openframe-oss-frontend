# auth-page.tsx

Next.js page component that renders the organization sign-up/registration screen, supporting both standard email/password registration and SSO-based signup (Google, Microsoft, Apple). It handles the takeover flow where a successful SSO identity verification without an existing organization transitions the user into a dedicated SSO signup completion form.

## Key Components

- **`AuthPage`** (default export) — The page component that orchestrates organization registration, rendering either `CreateOrganizationSection` (default view) or `NativeSsoSignupSection` (when an SSO identity has been verified but needs an organization, tracked via `signup.pending`).
- **`handleRegister`** — Maps the organization creation form payload to the `registerOrganization` call signature (tenant name/domain, user details, optional `prNumber` for preview environments).
- **`handleSsoLogin`** — Wraps `loginWithSso`, catching the "no organization yet" rejection and routing it to `signup.capture` instead of letting it propagate as an unhandled rejection.
- **`ssoProviders`** — Computed list of SSO providers to display, filtered by platform (Apple only shown on Apple devices via `useIsApplePlatform`) and by what the backend actually supports (once `useRegistrationProviders` finishes loading).

## Usage Example

This component is a Next.js route page and is rendered automatically by the framework for its route segment; it is not typically imported directly. It relies on several hooks that must be available in context:

```typescript
// Consumed implicitly via Next.js routing under app/(auth)/auth/
// Relevant hooks it depends on:
import { useAuth } from '@/app/(auth)/auth/hooks/use-auth';
import { useRegistrationProviders } from '@/app/(auth)/auth/hooks/use-registration-providers';
import { useSsoSignupTakeover } from '@/app/(auth)/auth/hooks/use-sso-signup-takeover';
import { useIsApplePlatform } from '@/app/hooks/use-apple-platform';

// useAuth exposes: isLoading, loginWithSso(provider), registerOrganization(payload)
// useRegistrationProviders exposes: providers, loading
// useSsoSignupTakeover exposes: pending, capture(error), onRegistered, onExit
```

**Key behavior:** When `loginWithSso` rejects because the verified identity has no associated organization, `signup.capture(error)` sets `signup.pending`, causing the component to switch to `NativeSsoSignupSection` so the user can complete organization details tied to their verified SSO identity.
