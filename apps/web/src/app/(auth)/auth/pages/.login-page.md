Renders the login page for the OpenFrame authentication flow, managing SSO provider discovery, redirect logic, and tab navigation between Login and Sign Up views.

## Key Components

- **`LoginPage`** — Default export; the main page component rendered at the `/auth/login` route
- **`FORM_PROVIDER_ORDER`** — Canonical display order for SSO provider buttons: `openframe → google → microsoft`
- **`handleDiscover`** — Async callback that runs debounced tenant discovery by email and maps backend providers to form-compatible values
- **`handleSso`** — Triggers an SSO redirect for the selected provider, managing a local `ssoLoading` flag to avoid form flicker from background discovery requests

## Usage Example

```typescript
// Rendered automatically by Next.js at /auth/login
// No props required — all state is derived from useAuthStore and useAuth

// Provider ID mapping example:
const backendProvider = 'openframe-sso';
const formProvider = SSO_TO_FORM[backendProvider]; // → 'openframe'

```

## Behaviors

- Authenticated users are redirected to `routes.dashboard` via `router.replace` (no back-stack entry)
- `(tabs)/layout.tsx` prefetches both tab segments on mount so tab switching is instant
- `ssoLoading` is scoped to SSO redirects only; `useAuth`'s broader `isLoading` is intentionally excluded to prevent form flicker during background discovery
