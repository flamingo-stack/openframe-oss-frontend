# page.tsx (Account Deleted Page)

A terminal, full-screen confirmation page rendered immediately after a user successfully self-deletes their account. It lives outside the `(app)` and `(auth)` route groups since the user is already signed out by the time it renders, and it handles local sign-out cleanup plus a manual "Sign in" exit path for native shells that lack browser chrome.

## Key Components

- **`AccountDeletedPage`** — Default export; the page component rendered at the post-deletion redirect target.
- **`organizationName` state** — Read from `sessionStorage` in a `useEffect` (not an initializer, to avoid SSR/client hydration mismatches on this statically exported page). Falls back to generic wording ("your organization") if missing.
- **`signOutRef`** — A `useRef` holding the in-flight sign-out promise, started on mount only if `ACCOUNT_DELETED_PENDING_STORAGE_KEY` is present (a guard against stray visits signing out a live session). Calls `forceLogout({ shouldRedirect: false })`, then clears the cached auth session query and removes the pending flag only after cleanup settles.
- **`handleSignIn`** — Awaits the pending sign-out, then routes to login: `router.replace(routes.auth.root)` inside an app shell (`isAppShell()`), or a `window.location.replace` to the shared auth host (or a relative fallback) on web.

## Usage Example

This page is not invoked directly by other components — it's reached via a `router.replace()` navigation from the account deletion mutation flow:

```typescript
// Triggered elsewhere (e.g., in a deletion mutation's onSuccess handler)
sessionStorage.setItem(DELETED_ACCOUNT_ORG_STORAGE_KEY, organization.name);
sessionStorage.setItem(ACCOUNT_DELETED_PENDING_STORAGE_KEY, '1');
router.replace('/account-deleted'); // lands on this page
```

Key design notes:
- Sign-out is deliberately deferred to **this page's mount**, not the deletion mutation itself, to avoid a flash of "Sign in required" app chrome while still on `/settings`.
- The `of-standalone-shell` class applies native safe-area insets since this page bypasses `AppLayout`/`AuthShell`.
