Defines the page metadata and layout wrapper for the "Account Deleted" route, re-exporting the shared route title layout component used across the app.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the document title to `"Account Deleted"` using the `routeTitle` helper for consistent title formatting across the app.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, avoiding duplicate layout logic for routes that only need a custom title.

## Usage Example

This file is a Next.js layout module automatically picked up by the framework's routing system—no manual import is needed. It applies to the route segment it resides in (e.g., an "account deleted" confirmation page):

```typescript
// Any page.tsx in the same route segment automatically
// inherits this layout and its generated <title> metadata.

export default function AccountDeletedPage() {
  return <p>Your account has been successfully deleted.</p>;
}
```

The pattern of re-exporting a shared layout with route-specific `metadata` is common throughout this app for pages that need unique titles but identical layout structure. See `@/lib/route-title` for the title formatting convention used across routes.
