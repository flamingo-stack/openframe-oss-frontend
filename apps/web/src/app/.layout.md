# layout.tsx

Next.js App Router root layout for the OpenFrame web application. It defines global metadata (SEO, Open Graph, Twitter cards, favicons), viewport behavior for both web and native-shell (static export) builds, and composes the full provider/guard tree that wraps every page in the app.

## Key Components

- **`metadata`** — Static `Metadata` export configuring title templates, description, keywords, Open Graph/Twitter previews, favicons, and manifest for OpenFrame.
- **`generateViewport()`** — Returns `Viewport` config; pins `maximumScale`/`userScalable` only for static-export (native WebView shell) builds to prevent WebKit auto-zoom on input focus, while keeping pinch-zoom enabled for the standard web build.
- **`RootLayout({ children })`** — Default export; the `<html>`/`<body>` shell that:
  - Conditionally renders `<PublicEnvScript />` (skipped in static-export builds, since the native shell injects `window.__ENV` itself).
  - Injects an inline script (`sidebarWidthFoucScript`) before paint to avoid a flash-of-unstyled-content for the collapsed/expanded sidebar state.
  - Mounts cross-cutting singletons: `RouteStyles`, `GoogleTagManager`, `RegistrationAttributionCapture`, `EmbedShimRegistration`, `DeploymentInitializer`, `NativeShellInitializer`, `TokenFreshnessWatcher`, `PostHogAnalyticsBridge`.
  - Nests the app's provider hierarchy: `RelayProvider` → `QueryClientProvider` → (conditional `DevTicketObserver`) → `AppUpdateGate` → `NatsAppProvider` → `BiometricLockBoundary` → `FeatureFlagsLoader` → `AppAgentIdentityProvider` → `NotificationsDataProvider` → `RouteGuard` → `DevicesViewConfig` → `children`.
  - Renders `OfflineBanner` and `Toaster` outside the update gate so they stay visible when an app update is required.

## Usage Example

This file is wired automatically by Next.js and is not imported directly. Page components are nested under it:

```typescript
// app/(dashboard)/page.tsx
export default function DashboardPage() {
  return <div>Dashboard content rendered inside RootLayout's children slot</div>;
}
```

To toggle native-shell (static export) behavior, set the build-time environment variable:

```bash
OPENFRAME_BUILD_TARGET=export next build
```
