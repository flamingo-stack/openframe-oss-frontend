A client-side React component module that renders informational rows reassuring users they'll remain signed in when applying an app update, whether that update comes from a store (App Store/Google Play) or was already downloaded via `NativeUpdate`.

## Key Components

- **`UpdateRow`** — Internal, unexported helper component rendering an icon, title, and detail text in a styled card row. Not interactive; purely informational.
- **`StoreUpdateRow`** — Exported component shown when an update is available in the platform store. Detects the platform via `mobilePlatform()` and displays the appropriate store icon (`GooglePlayIcon` or `AppStoreIcon`) with platform-specific copy.
- **`DownloadedUpdateRow`** — Exported component shown when an update has already been downloaded locally (e.g., via `NativeUpdate`'s pending bundle). Displays a `CheckCircleIcon` and messaging about restarting rather than visiting a store.

Both exported components communicate the same reassurance: session tokens persist across the update (stored in Keychain/Keystore), so users won't be signed out.

## Usage Example

```typescript
import { StoreUpdateRow, DownloadedUpdateRow } from '@/components/store-update-row';

function UpdatePrompt({ hasDownloadedUpdate }: { hasDownloadedUpdate: boolean }) {
  return (
    <div className="flex flex-col gap-4">
      {hasDownloadedUpdate ? <DownloadedUpdateRow /> : <StoreUpdateRow />}
    </div>
  );
}
```

## Notes

- Relies on `mobilePlatform()` from `@/lib/platform` to determine Android vs. iOS for icon and copy selection.
- Icons are sourced from `@flamingo-stack/openframe-frontend-core/components/icons-v2`.
- Styling uses ODS (OpenFrame Design System) CSS custom properties and utility classes (e.g., `text-ods-text-primary`, `bg-ods-card`).
- These are presentational-only components — no update logic, API calls, or state management is handled here.
