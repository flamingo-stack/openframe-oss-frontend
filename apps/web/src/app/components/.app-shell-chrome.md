## app-shell-chrome.ts

Framework-neutral shell constants and helper functions consumed by the live `AppLayout` (and the `(app)` group layout) to coordinate header loading states, `<main>` padding, and route-based chrome behavior. It intentionally avoids `'use client'` so server-adjacent modules can import it safely.

## Key Components

- **`headerLoadingCells()`** — Returns the ordered loading-cell placeholders (`'icon'`, `'icon'`) reserved by the standard header while it loads: time tracker + notifications (no avatar, no Mingo cell on OSS tenants).
- **`mingoHeaderLoadingCells(withMingo)`** — Same idea for the Mingo-first (phone top bar) shell; appends a third `'icon'` cell for the Mingo button when `withMingo` is `true`.
- **`APP_MAIN_CLASS_NAME`** — Default bottom padding class (`'pb-14'`) applied to `<main>` for standard routes.
- **`getMainClassNameOverride(pathname)`** — Returns a route-specific `<main>` padding override (e.g., `'pb-0 md:pb-0'` for file manager, tickets, settings, and Mingo chat/archive pages), or `undefined` to fall back to `APP_MAIN_CLASS_NAME`.
- **`isBareChromeRoute(pathname)`** — Identifies routes (the `/setup` wizard) that render without header, sidebar, or Mingo panel.
- **`isLandingRoute(pathname)`** — Identifies session-start pages (`/dashboard`, `/mingo`) used by onboarding redirect logic.
- **`holdsDashboard(pathname, onboardingV2, pending, locked)`** — Determines whether the landing page should stay on its loading skeleton while onboarding-v2 state is resolved, preventing a flash of full dashboard content before a redirect to `/setup`.

## Usage Example

```typescript
import {
  headerLoadingCells,
  mingoHeaderLoadingCells,
  APP_MAIN_CLASS_NAME,
  getMainClassNameOverride,
  isBareChromeRoute,
  holdsDashboard,
} from './app-shell-chrome';

const mainClass = getMainClassNameOverride(pathname) ?? APP_MAIN_CLASS_NAME;

if (isBareChromeRoute(pathname)) {
  // render setup wizard without chrome
}

const showSkeleton = holdsDashboard(pathname, onboardingV2State, pendingState, isLocked);

const cells = withMingo
  ? mingoHeaderLoadingCells(true)
  : headerLoadingCells();
```
