# sidebar-update-button.tsx

A React component that displays an "update available" button in the desktop app's sidebar navigation, prompting users to reopen the update modal when a new version is ready to install.

## Key Components

- **`SidebarUpdateButton`** — Functional component rendering a call-to-action button when a desktop update is available. Accepts a `minimized` prop to adapt its appearance for the collapsed sidebar rail versus the expanded sidebar.
- **`SidebarUpdateButtonProps`** — Interface defining the single `minimized: boolean` prop that controls layout (icon-only rail vs. full-width labeled button).

The component reads `available`, `version`, and `openModal` from `useDesktopUpdateStore` (a Zustand-style store). It renders `null` if no update is available, making it a no-op on mobile/web shells where the store is never populated.

## Usage Example

```typescript
import { SidebarUpdateButton } from '@/components/sidebar-update-button';

function CoreSidebar({ isCollapsed }: { isCollapsed: boolean }) {
  return (
    <nav>
      {/* ...other nav items... */}
      <SidebarUpdateButton minimized={isCollapsed} />
    </nav>
  );
}
```

When `minimized` is `true`, the button renders as a 48px square icon button with an `aria-label` and `title` for accessibility (since no visible text label is present). When `false`, it renders full-width with both the refresh icon and a `Update to v{version}` label. Clicking the button in either state calls `openModal()` to reopen the update dialog, ensuring users who dismiss the modal always have a way back to it via the sidebar.
