React error boundary component that isolates crash failures in the Mingo chat drawer, preventing synchronous throws from `embedAuthedFetch` from unmounting the entire app shell.

## Key Components

### `ChatDrawerErrorBoundary`
A class-based React `Component` that wraps the Mingo drawer panel. Implements the standard error boundary lifecycle:

- **`getDerivedStateFromError()`** — Sets `hasError: true` on any render-phase throw, triggering the fallback UI
- **`componentDidCatch(error)`** — Logs the caught error to the console with a `[ChatDrawerErrorBoundary]` prefix
- **`render()`** — Returns either the fallback message UI or `children` depending on error state

**Fallback UI:** A centered message — *"Mingo is unavailable right now. Close the panel and try again."* — styled with `text-ods-text-secondary` and `h-full` layout, scoped entirely within the drawer panel.

## Usage Example

```typescript
import { ChatDrawerErrorBoundary } from './chat-drawer-error-boundary';
import { MingoChat } from '@/components/mingo-chat';

export function ChatDrawer() {
  return (
    <ChatDrawerErrorBoundary>
      <MingoChat />
    </ChatDrawerErrorBoundary>
  );
}
```

## Notes

- Targets a specific failure mode: `embedAuthedFetch` in the core lib throws synchronously on `/content/*` paths resolved against a `capacitor://` origin (native shell context)
- Must be a **class component** — React does not support functional error boundaries
- Scoped degradation: only the drawer panel shows the fallback; the surrounding app shell remains mounted
