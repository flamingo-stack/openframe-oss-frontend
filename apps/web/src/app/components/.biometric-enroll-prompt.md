One-time prompt component that offers biometric login enrollment immediately after a user's first login in the native mobile shell.

## Key Components

### `BiometricEnrollPrompt` (exported component)

A client-side React component that renders a [`ConfirmDialog`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/components/shared/confirm-dialog.tsx) offering biometric authentication setup. Renders nothing outside the native shell.

**State**
- `open` — controls dialog visibility
- `label` — dynamic biometry label (e.g., `"Face ID"`, `"Fingerprint"`)
- `isPending` — tracks async enrollment in progress

**Key behaviors**

| Scenario | Result |
|---|---|
| Not in native shell | Nothing renders |
| User previously declined | Offer suppressed permanently |
| Biometrics unavailable or already enabled | Offer suppressed |
| User taps "Enable" → OS prompt canceled | Dialog stays open, no choice recorded |
| User taps "Enable" → transient error | Dialog closes, no choice recorded (may re-offer later) |
| User taps "Enable" → success | Records `'accepted'`, shows success toast |
| User taps "Not Now" or backdrop dismiss | Records `'declined'`, never re-offered |

## Usage Example

```typescript
// Mount once in the authenticated app shell, alongside NativePushInitializer
import { BiometricEnrollPrompt } from '@/app/components/biometric-enroll-prompt';

export function AuthenticatedShell({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <NativePushInitializer />
      <BiometricEnrollPrompt />
    </>
  );
}
```

> **Anti-spam policy:** Any dismissal (including backdrop tap) permanently records `'declined'` for the device. Only an OS-level cancel during the biometric prompt is treated as a non-decision, keeping the dialog open.
