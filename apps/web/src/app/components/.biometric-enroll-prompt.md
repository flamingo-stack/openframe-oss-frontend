Client-side React component that displays a one-time post-login prompt inviting the user to enable biometric login (Face ID/Touch ID) within the native mobile shell.

## Key Components

- **`BiometricEnrollPrompt`** — React functional component (no props) that:
  - Checks on mount whether it's running inside the mobile shell, biometrics are available, the user hasn't already enabled or declined biometric login, and shows a `ConfirmDialog` if all conditions are met.
  - `handleEnable` — Attempts to enable biometric login via `enableBiometricLogin()`; on success, records the `'accepted'` choice and shows a success toast. If the OS prompt is canceled (`BIOMETRIC_ERROR.CANCELED`), the dialog stays open without recording a choice. On other failures, the dialog closes without recording a choice (so it may be re-offered later) and an error toast is shown.
  - `handleOpenChange` — Treats any dismissal (backdrop click or "Not Now") as an explicit decline, persisting `'declined'` via `setBiometricLoginChoice` so the prompt never reappears on that device (users can still opt in from Settings).

## Usage Example

Mount once near the root of the authenticated app shell, alongside other one-time native initializers:

```typescript
import { BiometricEnrollPrompt } from '@/app/components/biometric-enroll-prompt';
import { NativePushInitializer } from '@/app/components/native-push-initializer';

function AuthenticatedShell({ children }: { children: React.ReactNode }) {
  return (
    <>
      <NativePushInitializer />
      <BiometricEnrollPrompt />
      {children}
    </>
  );
}
```

The component renders nothing when not running inside the native mobile shell (`isMobileShell()` returns `false`), and silently skips rendering if the user previously declined, already enabled biometrics, or biometrics are unavailable on the device.
