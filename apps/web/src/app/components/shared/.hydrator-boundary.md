Wraps "hydrator" components in a `Suspense` boundary with an empty (`null`) fallback, intended for components that perform data reads but render no UI themselves.

## Key Components

- **`HydratorBoundary`** — A client component that accepts `children: ReactNode` and wraps them in a `Suspense` boundary with `fallback={null}`. Used specifically for components that read query/subscription state (e.g., unread counts, billing status, URL-driven observers) and report it upward without rendering any visible output. Because these components draw nothing, there is no loading UI to show, so the fallback is intentionally empty rather than using `LoadingFallback`.

## Usage Example

```typescript
import { HydratorBoundary } from './hydrator-boundary';
import { UnreadCountHydrator } from './unread-count-hydrator';

function AppShell({ children }: { children: ReactNode }) {
  return (
    <>
      <HydratorBoundary>
        <UnreadCountHydrator />
      </HydratorBoundary>
      {children}
    </>
  );
}
```

Use `HydratorBoundary` only for non-rendering, read-and-report components. If a component renders visible content, prefer a `Suspense` boundary with a real fallback (e.g., `LoadingFallback`) instead, since an empty fallback would cause a jarring blank state while that content loads.
