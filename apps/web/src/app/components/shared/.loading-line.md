A client-side React component that renders a single skeleton text line (or multiple lines) as a loading placeholder, wrapped in a silent `LoadingRegion` for accessibility purposes.

## Key Components

- **`LoadingLine`** — Functional component that composes `LoadingRegion` and `TextLineSkeleton` to display a lightweight loading placeholder for a single text element (e.g., a figure, total, or short sentence).
  - `type` — Matches the `type` prop of `TextLineSkeleton`, controlling the skeleton's height/style (e.g., to match a numeric figure vs. regular text).
  - `lines` — Optional number of skeleton lines to render (defaults to 1).
  - `as` — Element type (`'div'` or `'span'`) for both the region and the skeleton; use `'span'` when nesting inside phrasing content like a button label or `<p>`.
  - `className` — CSS classes applied to the skeleton bar itself (commonly used to set width).
  - `regionClassName` — CSS classes applied to the wrapping `LoadingRegion`; pass `'contents'` to avoid an extra box in the layout.

The component sets `status={false}` on `LoadingRegion`, meaning it does not independently announce a loading state to assistive technology — it assumes a parent region already handles that announcement.

## Usage Example

```typescript
import { LoadingLine } from './loading-line';

// Basic usage: single skeleton line for a numeric total
function TotalDisplay({ isLoading, total }: { isLoading: boolean; total?: number }) {
  if (isLoading) {
    return <LoadingLine type="number" />;
  }
  return <div>{total}</div>;
}

// Multi-line skeleton inside a <p>, rendered as a <span>
function Summary({ isLoading, text }: { isLoading: boolean; text?: string }) {
  return (
    <p>
      {isLoading ? (
        <LoadingLine type="text" lines={3} as="span" className="w-48" />
      ) : (
        text
      )}
    </p>
  );
}

// Avoid adding an extra wrapper box by using `contents`
<LoadingLine type="text" regionClassName="contents" className="w-32" />
```
