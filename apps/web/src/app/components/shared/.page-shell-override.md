Defines a shared CSS custom-properties override that aligns the host-grid lib's `PageShell` padding behavior with OpenFrame's own `PageLayout` spacing conventions, for use on pages mounted with `shell={false}`.

## Key Components

- **`PAGE_SHELL_OVERRIDE`** — A `CSSProperties` constant exporting `--page-shell-*` CSS variables (`px`, `px-md`, `pt`, `pt-md`, `pb`, `pb-md`) that replace the lib's default wide-page spacing (`px-20 py-10`) with OpenFrame's standard page padding: flat horizontal spacing, zero top padding, and bottom-only vertical spacing (no responsive breakpoint bump), matching the `px-[var(--spacing-system-l)] pb-[var(--spacing-system-l)]` pattern used across `PageLayout` pages.

## Usage Example

```typescript
import { PAGE_SHELL_OVERRIDE } from './page-shell-override';

function MyLibPage() {
  return (
    <div style={PAGE_SHELL_OVERRIDE}>
      <LibPageShell shell={false}>
        {/* page content inherits OpenFrame's standard padding
            instead of the lib's default wide-page spacing */}
      </LibPageShell>
    </div>
  );
}
```

Apply the style object to any ancestor element of a `page-shell-content` wrapper to override its CSS variable defaults, ensuring consistent spacing between lib-provided pages and native OpenFrame `PageLayout` pages.
