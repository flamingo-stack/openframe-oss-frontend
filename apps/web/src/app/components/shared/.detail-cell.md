This file defines shared Tailwind CSS class constants for laying out value-over-label cells within detail/record cards (e.g., execution, script, query, or incident detail views). It centralizes the styling so all detail cards use consistent cell sizing and spacing.

## Key Components

- **`DETAIL_CELL_CLASS`** — Defines a cell's layout behavior on a wrapping row: a flex item with a minimum width of `140px` that flexes evenly (`flex-[1_0_0]`) to share available row space with sibling cells.
- **`DETAIL_CELL_GAP_CLASS`** — Defines the spacing between a cell's value and its label, using the `--spacing-system-xxs` CSS variable. Intended to be passed as the `className` for an `InfoCell` component.

## Usage Example

```typescript
import { DETAIL_CELL_CLASS, DETAIL_CELL_GAP_CLASS } from './detail-cell';

function ExecutionDetailCard() {
  return (
    <div className="flex flex-wrap">
      <div className={DETAIL_CELL_CLASS}>
        <InfoCell
          className={DETAIL_CELL_GAP_CLASS}
          label="Status"
          value="Completed"
        />
      </div>
      <div className={DETAIL_CELL_CLASS}>
        <InfoCell
          className={DETAIL_CELL_GAP_CLASS}
          label="Duration"
          value="2m 14s"
        />
      </div>
    </div>
  );
}
```

By importing these constants rather than redefining layout classes per component, all detail cards (scripts, queries, incidents, executions) stay visually consistent and easy to update from a single source.
