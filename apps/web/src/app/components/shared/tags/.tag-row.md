# tag-row.tsx

Renders a single editable tag key/value row used in tag editor UIs, handling key autocomplete suggestions, value autocomplete (lazy-loaded via Suspense), inline validation (format/length/duplicates), and row deletion.

## Key Components

- **`TAG_REGEX`** — Regex validating tag keys/values: must start with a letter/digit, followed by alphanumerics, underscores, or hyphens.
- **`TAG_MAX_LENGTH`** — Maximum allowed length (64 characters) for tag keys/values.
- **`isValidTag(value)`** — Returns `true` if a string passes both length and format checks.
- **`validateTagKey(key)`** — Returns an error message string if the key is invalid, otherwise `undefined`.
- **`validateTagValues(values)`** — Validates an array of tag values, returning an error message if any fail.
- **`TagRow`** — Main component rendering the key `Autocomplete`, values field, and delete `Button` for a single tag entry. Manages key suggestion fetching, duplicate-key detection, and change/delete callbacks.
- **`TagValues`** — Suspense-wrapped component that loads value suggestions for a given tag key.
- **`DisabledTagValues`** — Fallback disabled values field shown while suggestions load or no key is selected.

## Usage Example

```typescript
import { TagRow } from './tag-row';
import type { TagEntry } from './types';

function TagEditor({ tags, keySuggestionsRef }: {
  tags: (TagEntry & { id: string })[];
  keySuggestionsRef: any;
}) {
  const handleChange = (id: string, updated: TagEntry) => {
    // update tag state by id
  };

  const existingKeys = tags.map(t => t.key);

  return (
    <>
      {tags.map((tag, index) => (
        <TagRow
          key={tag.id}
          tag={tag}
          isFirst={index === 0}
          existingKeys={existingKeys}
          keySuggestionsRef={keySuggestionsRef}
          onChange={updated => handleChange(tag.id, updated)}
          onDelete={() => console.log('delete', tag.id)}
        />
      ))}
    </>
  );
}
```

**Notes:**
- Requires a `keySuggestionsRef` GraphQL fragment reference for key autocomplete data, provided by the parent query.
- Validation errors (duplicate key, invalid format, length) are computed via `useMemo` and passed down to the `Autocomplete` components as `error` props.
- The `isFirst` prop controls whether field labels are shown on larger viewports (`content-md` breakpoint) for the first row only.
