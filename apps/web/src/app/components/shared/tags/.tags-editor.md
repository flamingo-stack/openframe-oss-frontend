# tags-editor.tsx

A React client component that renders an editable list of key-value tag entries, allowing users to add, update, and delete tags with GraphQL-backed key autocomplete suggestions via Relay.

## Key Components

- **`TagsEditor`** — Main exported component that manages a list of `TagEntryWithId` tags, rendering a `TagRow` for each entry plus an "Add Tag" button.
- **`tagsEditorRootQuery`** — Relay GraphQL query that fetches tag key suggestions (limited by `SUGGESTIONS_LIMIT`) via `useLazyLoadQuery`.
- **`keySuggestionsFragment`** — Exported, refetchable Relay fragment (`tagsEditor_keySuggestions`) providing `tagKeySuggestions` (id, key, values); exported so `useTagKeySuggestions` hook can consume it elsewhere.
- **`TagsEditorProps`** — Props interface: `tags` (array of tag entries with ids), `onTagsChange` callback, and optional `addLabel` button text.

## Usage Example

```typescript
import { useState } from 'react';
import { TagsEditor } from '@/components/tags-editor';
import type { TagEntryWithId } from '@/components/types';

function MyForm() {
  const [tags, setTags] = useState<TagEntryWithId[]>([]);

  return (
    <TagsEditor
      tags={tags}
      onTagsChange={setTags}
      addLabel="Add Label"
    />
  );
}
```

## Behavior Notes

- Each new tag is assigned a client-generated `crypto.randomUUID()` for stable keying/updates.
- `existingKeys` (derived from current tags) is passed to each `TagRow` to prevent duplicate key suggestions.
- Uses `fetchPolicy: 'store-and-network'` to balance cache freshness with responsiveness.
- The fragment reference (`queryData`) is cast to `KeySuggestionsFragmentKey` and passed down to `TagRow` for fragment colocation with Relay.
