# use-tag-value-suggestions.ts

A React hook that provides debounced, searchable autocomplete suggestions for tag values by querying a GraphQL API via Relay, used for building tag-value picker/autocomplete UI components.

## Key Components

- **`useTagValueSuggestions(tagKey: string)`** - Main hook that fetches and manages tag value suggestions for a given tag key.
- **`valueSuggestionsRootQuery`** - Root GraphQL query that loads the initial set of suggestions via `useLazyLoadQuery`.
- **`valueSuggestionsFragment`** - Refetchable GraphQL fragment (`@refetchable`) that supports dynamic search-based refetching without re-triggering the root query.
- **Returned API:**
  - `options: AutocompleteOption[]` - Mapped `{ label, value }` pairs derived from the GraphQL response.
  - `isRefetching: boolean` - Deferred loading state (debounced via `useDeferredLoading`) to avoid UI flicker during fast refetches.
  - `handleInputChange(value: string)` - Updates the search input, which is debounced before triggering a refetch.
  - `resetInput()` - Clears the current search input.

## Usage Example

```typescript
import { useTagValueSuggestions } from './use-tag-value-suggestions';

function TagValueAutocomplete({ tagKey }: { tagKey: string }) {
  const { options, isRefetching, handleInputChange, resetInput } =
    useTagValueSuggestions(tagKey);

  return (
    <Autocomplete
      options={options}
      loading={isRefetching}
      onInputChange={(value) => handleInputChange(value)}
      onClear={resetInput}
    />
  );
}
```

**Implementation notes:**
- Input changes are debounced by 300ms (`DEBOUNCE_MS`) before triggering a GraphQL refetch.
- Refetches run inside `startTransition` to keep the UI responsive, with `useDeferredLoading` smoothing the loading indicator.
- Suggestions are capped at 20 results (`SUGGESTIONS_LIMIT`).
- Uses `fetchPolicy: 'store-and-network'` to prioritize cached data while revalidating against the network.
