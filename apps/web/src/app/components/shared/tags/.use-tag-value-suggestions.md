React hook that fetches and manages tag value autocomplete suggestions via GraphQL, with debounced search input and refetchable Relay fragments.

## Key Components

- **`useTagValueSuggestions(tagKey)`** — Primary export. Accepts a tag key string and returns autocomplete options, loading state, and input handlers.
- **`valueSuggestionsRootQuery`** — Relay GraphQL root query fetching initial suggestions scoped to a `tagKey`.
- **`valueSuggestionsFragment`** — Refetchable Relay fragment supporting `search` and `limit` arguments for live filtering.
- **`SUGGESTIONS_LIMIT`** — Caps results at 20 entries.
- **`DEBOUNCE_MS`** — 300ms debounce delay on user input before triggering a refetch.

## Return Values

| Property | Type | Description |
|---|---|---|
| `options` | `AutocompleteOption[]` | Mapped `{ label, value }` pairs from GraphQL results |
| `isRefetching` | `boolean` | Deferred loading state during refetch transitions |
| `handleInputChange` | `(value: string) => void` | Updates search input, triggering debounced refetch |
| `resetInput` | `() => void` | Clears search input back to empty string |

## Usage Example

```typescript
import { useTagValueSuggestions } from '@/hooks/use-tag-value-suggestions';

function TagValueAutocomplete({ tagKey }: { tagKey: string }) {
  const { options, isRefetching, handleInputChange, resetInput } =
    useTagValueSuggestions(tagKey);

  return (
    <Autocomplete
      options={options}
      loading={isRefetching}
      onInputChange={handleInputChange}
      onClose={resetInput}
    />
  );
}
```
