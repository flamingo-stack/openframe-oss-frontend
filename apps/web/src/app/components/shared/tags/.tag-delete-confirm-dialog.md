A client-side React component that renders a reusable confirmation dialog for deleting a tag, built on top of the shared `ConfirmDialog` component. It parameterizes the description copy by entity type so the same dialog can be reused across different tag contexts (e.g., ticket tags, article tags).

## Key Components

- **`TagDeleteConfirmDialogProps`** — Interface defining the component's props:
  - `open`: controls dialog visibility
  - `tagName`: name of the tag being deleted (shown in the confirmation message)
  - `entityLabel`: singular label for the entity the tag attaches to (e.g., `"ticket"`, `"article"`)
  - `isPending`: optional loading state for the confirm action
  - `onConfirm` / `onClose`: callbacks for user actions
- **`TagDeleteConfirmDialog`** — The exported component that wraps `ConfirmDialog` with preset destructive-action copy, wiring `onOpenChange` to call `onClose` only when the dialog closes.

## Usage Example

```typescript
import { useState } from 'react';
import { TagDeleteConfirmDialog } from '@/app/components/tags/tag-delete-confirm-dialog';

function TicketTagsPanel() {
  const [isDeleting, setIsDeleting] = useState(false);
  const [dialogOpen, setDialogOpen] = useState(false);

  const handleConfirm = async () => {
    setIsDeleting(true);
    await deleteTag();
    setIsDeleting(false);
    setDialogOpen(false);
  };

  return (
    <TagDeleteConfirmDialog
      open={dialogOpen}
      tagName="urgent"
      entityLabel="ticket"
      isPending={isDeleting}
      onConfirm={handleConfirm}
      onClose={() => setDialogOpen(false)}
    />
  );
}
```

Reuse this component anywhere a tag deletion needs confirmation—just supply the appropriate `entityLabel` ("ticket", "article", etc.) to adjust the warning message without duplicating dialog markup.
