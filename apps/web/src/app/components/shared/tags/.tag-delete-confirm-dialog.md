Reusable confirmation dialog for globally deleting a tag entity, with copy that adapts to the entity type (e.g. "ticket" or "article") via `entityLabel`.

## Key Components

### `TagDeleteConfirmDialog`

A thin wrapper around `ConfirmDialog` that renders a destructive confirmation prompt. Warns the user that deleting the tag removes it from every associated entity and cannot be undone.

**Props (`TagDeleteConfirmDialogProps`):**

| Prop | Type | Description |
|---|---|---|
| `open` | `boolean` | Controls dialog visibility |
| `tagName` | `string?` | Name of the tag being deleted |
| `entityLabel` | `string` | Singular entity type the tag attaches to (e.g. `"ticket"`, `"article"`) |
| `isPending` | `boolean?` | Shows loading state while deletion is in progress |
| `onConfirm` | `() => void` | Called when the user confirms deletion |
| `onClose` | `() => void` | Called when the dialog requests to close |

## Usage Example

```typescript
import { TagDeleteConfirmDialog } from './tag-delete-confirm-dialog';

function TicketTagManager() {
  const [open, setOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleDelete = async () => {
    setIsPending(true);
    await deleteTag('urgent');
    setIsPending(false);
    setOpen(false);
  };

  return (
    <TagDeleteConfirmDialog
      open={open}
      tagName="urgent"
      entityLabel="ticket"
      isPending={isPending}
      onConfirm={handleDelete}
      onClose={() => setOpen(false)}
    />
  );
}
```
