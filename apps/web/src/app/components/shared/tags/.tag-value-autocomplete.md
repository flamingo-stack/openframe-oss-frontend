A client-side React component that renders a multi-select autocomplete input for entering tag values, with dynamic suggestions fetched based on the associated tag key.

## Key Components

- **`TagValueAutocomplete`** — Default-style functional component that wraps the shared `Autocomplete` UI primitive, pre-configured for multi-value tag input with server-driven suggestions.
- **`TagValueAutocompleteProps`** — Props interface requiring `tagKey` (used to fetch relevant suggestions) and `values`/`onChange` for controlled multi-value state, plus optional `error`, `label`, and `className`.
- **`useTagValueSuggestions`** (external hook) — Supplies `options`, `isRefetching`, `handleInputChange`, and `resetInput` used to drive autocomplete suggestions and loading state.

## Usage Example

```typescript
import { useState } from 'react';
import { TagValueAutocomplete } from './tag-value-autocomplete';

function TagEditor() {
  const [values, setValues] = useState<string[]>([]);

  return (
    <TagValueAutocomplete
      tagKey="environment"
      values={values}
      onChange={setValues}
      label="Tag Values"
      error={values.length === 0 ? 'At least one value is required' : undefined}
    />
  );
}
```

The component resets the input text (`resetInput`) whenever values change, ensuring a clean state for the next entry. It supports free-form text entry via `creatable` and `freeSolo`, allowing users to add values not present in the suggested `options` list, while `disableClientFilter` defers filtering logic to the server-backed suggestions hook rather than filtering client-side.
