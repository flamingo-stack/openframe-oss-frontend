# entity-tag-picker.tsx

A searchable, creatable multi-select component for assigning tags to an entity (e.g. articles, scripts), backed by a GraphQL vocabulary query and tag create/delete mutations. It supports optimistic tag creation, a loading placeholder state, and optional global tag deletion with confirmation.

## Key Components

- **`entityTagPickerQuery`** — GraphQL query fetching the full tag vocabulary (`id`, `key`) for a given `TagEntityType`.
- **`EntityTagPicker`** — Public component; wraps the reader in a `LoadingSuspense` boundary.
- **`EntityTagPickerReader`** (internal) — Switches between a disabled placeholder (while in a loading scope, showing only already-selected tags) and the live `LiveEntityTagPicker`.
- **`LiveEntityTagPicker`** (internal) — Fetches the tag vocabulary via `useLazyLoadQuery` (`store-and-network` policy), merges it with initial/created/optimistic tags, and handles creation, selection, and deletion.
- **`PickerField`** (internal) — Thin wrapper around `Autocomplete` standardizing label, placeholder, search icon, and multi-select/creatable behavior.
- **`EntityTagPickerProps`** — Props: `entityType`, `selectedIds`, `onChange`, `initialTags`, `disabled`, `label`, `emptyPlaceholder`, `maxCreateLength`, `deletable`, `entityLabel`.

## Usage Example

```typescript
import { EntityTagPicker } from './entity-tag-picker';

function ArticleTagsField() {
  const [tagIds, setTagIds] = useState<string[]>([]);

  return (
    <EntityTagPicker
      entityType="ARTICLE"
      selectedIds={tagIds}
      onChange={setTagIds}
      initialTags={[{ id: 'tag-1', key: 'tutorial' }]}
      label="Article Tags"
      deletable
      entityLabel="article"
      maxCreateLength={40}
    />
  );
}
```

Typing a new tag name and confirming it creates the tag immediately (optimistic chip), then swaps in the real id once the `createTag` mutation resolves. Enabling `deletable` adds a delete affordance per option that, after confirmation via `TagDeleteConfirmDialog`, removes the tag from the tenant-wide vocabulary and from the current selection.
