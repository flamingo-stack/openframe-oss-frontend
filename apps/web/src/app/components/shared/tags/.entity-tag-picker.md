A searchable, creatable multi-select tag picker component that manages a tenant-wide tag vocabulary for a given entity type, including optimistic creation, deduplication, and optional global tag deletion.

## Key Components

### Exports

| Name | Type | Description |
|------|------|-------------|
| `EntityTagPicker` | Component | Main tag picker — suspends on vocabulary query; supports create, select, and delete |
| `EntityTagPickerFallback` | Component | Suspense fallback; pixel-identical disabled state to prevent layout shift |
| `entityTagPickerQuery` | GraphQL query | Fetches full tag vocabulary by `TagEntityType` |

### Props — `EntityTagPickerProps`

| Prop | Type | Description |
|------|------|-------------|
| `entityType` | `TagEntityType` | Drives vocabulary query and create mutation |
| `selectedIds` | `string[]` | Controlled array of selected tag IDs |
| `onChange` | `(ids: string[]) => void` | Called with updated ID array on any change |
| `initialTags` | `ReadonlyArray<EntityTag>` | Pre-assigned tags seeded into options |
| `deletable` | `boolean` | Enables per-option global delete with confirm dialog |
| `maxCreateLength` | `number` | Optional character cap for new tag names |

## Usage Example

```typescript
// Wrap in a Suspense boundary; EntityTagPicker suspends on its vocabulary query
<Suspense fallback={<EntityTagPickerFallback label="Tags" />}>
  <EntityTagPicker
    entityType="ARTICLE"
    selectedIds={form.tagIds}
    onChange={(ids) => form.setValue('tagIds', ids)}
    initialTags={article.tags}
    deletable
    entityLabel="article"
    maxCreateLength={50}
  />
</Suspense>
```

## Optimistic Creation Flow

New tag names not present in the vocabulary are assigned a `_optimistic_<uuid>` temp ID immediately, enabling multi-tag creation in a single interaction without race conditions. On mutation success, the temp ID is swapped for the persisted ID via `selectedIdsRef` (always-current ref, avoiding stale closure issues). On failure, the orphaned temp ID is removed.
