# use-tag-mutations.ts

Provides React hooks for creating, updating, and deleting tag entities via GraphQL mutations using Relay, with built-in toast notifications for error handling.

## Key Components

- **`useCreateTagMutation()`** — Hook that returns a `createTag` function and `isInFlight` status. Commits the `createTag` GraphQL mutation, invoking `onCompleted` with the new tag's `id` on success, or `onError`/toast on failure.
- **`useUpdateTagMutation()`** — Hook that returns an `updateTag` function and `isInFlight` status. Commits the `updateTag` GraphQL mutation with partial fields (`id` required, others optional), calling `onCompleted` on success or showing an error toast on failure.
- **`useDeleteTagMutation()`** — Hook that returns a `deleteTag` function and `isInFlight` status. Commits the `deleteTag` GraphQL mutation and uses a Relay store `updater` to remove the deleted tag record from the local store, ensuring Relay-driven UI (pickers/lists) update immediately without a refetch.

## Usage Example

```typescript
import { useCreateTagMutation, useUpdateTagMutation, useDeleteTagMutation } from './use-tag-mutations';

function TagManager() {
  const { createTag, isInFlight: creating } = useCreateTagMutation();
  const { updateTag } = useUpdateTagMutation();
  const { deleteTag } = useDeleteTagMutation();

  const handleCreate = () => {
    createTag(
      { key: 'priority', entityType: 'ticket', color: '#ff0000' },
      (id) => console.log('Created tag with id:', id),
      (error) => console.error('Create failed:', error),
    );
  };

  const handleUpdate = (id: string) => {
    updateTag({ id, description: 'Updated description' }, () => {
      console.log('Tag updated');
    });
  };

  const handleDelete = (id: string) => {
    deleteTag(id, () => console.log('Tag deleted'));
  };

  return (
    <button onClick={handleCreate} disabled={creating}>
      Create Tag
    </button>
  );
}
```

**Note:** Error handling is automatic via toast notifications for update and delete mutations; the create mutation additionally supports a custom `onError` callback. All hooks expose `isInFlight` to track mutation request state for UI loading indicators.
