Custom React hooks encapsulating Relay mutations for creating, updating, and deleting tags, with built-in toast error notifications.

## Key Components

| Export | Description |
|---|---|
| `useCreateTagMutation` | Hook that commits a `createTag` GraphQL mutation; returns the new tag's `id` via `onCompleted` callback |
| `useUpdateTagMutation` | Hook that commits an `updateTag` GraphQL mutation for patching `key`, `description`, or `color` fields |
| `useDeleteTagMutation` | Hook that commits a `deleteTag` GraphQL mutation and immediately removes the record from the Relay store via an `updater` |

All three hooks expose a `isInFlight` boolean for loading state and use `useToast` to surface destructive error toasts automatically.

## Usage Example

```typescript
import {
  useCreateTagMutation,
  useUpdateTagMutation,
  useDeleteTagMutation,
} from './use-tag-mutations';

function TagManager() {
  const { createTag, isInFlight: creating } = useCreateTagMutation();
  const { updateTag, isInFlight: updating } = useUpdateTagMutation();
  const { deleteTag, isInFlight: deleting } = useDeleteTagMutation();

  // Create a new tag
  createTag(
    { key: 'urgent', entityType: 'ticket', color: '#FF0000' },
    (id) => console.log('Created tag:', id),
  );

  // Update an existing tag
  updateTag(
    { id: 'tag-123', description: 'High priority items' },
    () => console.log('Tag updated'),
  );

  // Delete a tag (Relay store updated immediately)
  deleteTag('tag-123', () => console.log('Tag deleted'));
}
```

## Notes

- `useDeleteTagMutation` uses a Relay `updater` to eagerly drop the deleted record from the store, keeping Relay-driven lists in sync without a refetch. REST/react-query consumers are unaffected and handle their own cache invalidation.
- All mutations are memoized with `useCallback` to prevent unnecessary re-renders.
