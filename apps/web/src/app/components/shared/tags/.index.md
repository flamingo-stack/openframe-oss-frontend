Barrel file that re-exports the public API of the tags module, consolidating components, hooks, utilities, and types related to entity tagging functionality into a single import path.

## Key Components

- **`EntityTagPicker`** / **`entityTagPickerQuery`** — Component and query for selecting/picking tags associated with an entity.
- **`TagRow`**, **`isValidTag`**, **`validateTagKey`**, **`validateTagValues`**, **`TAG_MAX_LENGTH`**, **`TAG_REGEX`** — Row component and validation utilities for individual tag entries.
- **`TagsEditor`** — Full editor component for managing a collection of tags.
- **`TagValueAutocomplete`** — Autocomplete input for suggesting tag values.
- **`TagDeleteConfirmDialog`** — Confirmation dialog shown before deleting a tag.
- **`isOptimisticTagId`** / **`OPTIMISTIC_TAG_ID_PREFIX`** — Helpers for identifying optimistically-created tags (before server confirmation).
- **`useTagKeySuggestions`** / **`useTagValueSuggestions`** — Hooks providing autocomplete suggestions for tag keys/values.
- **`useCreateTagMutation`**, **`useUpdateTagMutation`**, **`useDeleteTagMutation`** — Mutation hooks for tag CRUD operations.
- **Types** — `Tag`, `TagEntityType`, `TagEntry`, `TagEntryWithId` for type-safe tag handling across the module.

## Usage Example

```typescript
import {
  TagsEditor,
  TagRow,
  useCreateTagMutation,
  useTagKeySuggestions,
  isValidTag,
  type Tag,
} from '@/features/tags';

function EntityTagsPanel({ entityId, entityType }: { entityId: string; entityType: TagEntityType }) {
  const { mutate: createTag } = useCreateTagMutation();
  const { data: suggestions } = useTagKeySuggestions(entityType);

  return (
    <TagsEditor
      entityId={entityId}
      entityType={entityType}
      onCreate={(tag: Tag) => createTag(tag)}
    />
  );
}
```

This barrel export pattern allows consumers to import any tag-related functionality from a single, stable path (`@/features/tags`) without needing to know the internal file structure.
