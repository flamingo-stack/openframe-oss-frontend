Barrel export file for the tags feature module, consolidating all public-facing components, hooks, utilities, and types into a single import path.

## Key Components

| Export | Source | Description |
|---|---|---|
| `EntityTagPicker`, `EntityTagPickerFallback`, `entityTagPickerQuery` | `entity-tag-picker` | Component and query for picking tags on entities |
| `TagDeleteConfirmDialog` | `tag-delete-confirm-dialog` | Confirmation dialog for tag deletion |
| `isValidTag`, `TAG_MAX_LENGTH`, `TAG_REGEX`, `TagRow`, `validateTagKey`, `validateTagValues` | `tag-row` | Tag validation constants, helpers, and row component |
| `TagValueAutocomplete` | `tag-value-autocomplete` | Autocomplete input for tag values |
| `TagsEditor` | `tags-editor` | Full tag management editor component |
| `Tag`, `TagEntityType`, `TagEntry`, `TagEntryWithId` | `types` | TypeScript type definitions |
| `useTagKeySuggestions` | `use-tag-key-suggestions` | Hook for fetching tag key suggestions |
| `useCreateTagMutation`, `useDeleteTagMutation`, `useUpdateTagMutation` | `use-tag-mutations` | CRUD mutation hooks for tags |
| `useTagValueSuggestions` | `use-tag-value-suggestions` | Hook for fetching tag value suggestions |

## Usage Example

```typescript
import {
  TagsEditor,
  EntityTagPicker,
  useCreateTagMutation,
  useDeleteTagMutation,
  isValidTag,
  TAG_MAX_LENGTH,
} from '@/features/tags';
import type { Tag, TagEntry } from '@/features/tags';

// Use the editor to manage tags on a resource
<TagsEditor entityType="device" entityId="device-123" />;

// Validate a tag before submission
if (isValidTag(key) && key.length <= TAG_MAX_LENGTH) {
  createTag({ key, value });
}
```
