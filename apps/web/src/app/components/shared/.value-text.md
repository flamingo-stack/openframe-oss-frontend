# value-text.tsx

A React client component that renders a cell/field value as styled text, automatically handling loading states and empty values. It supports both an explicit `loading` prop and an ambient loading scope (via `useLoadingScope`), displaying a skeleton placeholder while data is pending.

## Key Components

- **`ValueText`** — Main component that renders:
  - A `TextLineSkeleton` bar (sized by `skeletonWidth`) when loading is active
  - An `EmptyValue` marker (styled with `text-h4`) when the value is empty/null/undefined
  - A `TruncateText`-wrapped string representation of the value otherwise

### Props
| Prop | Type | Description |
|------|------|-------------|
| `value` | `string \| number \| null \| undefined` | The value to display |
| `loading` | `boolean` (optional) | Explicit loading flag, combined with ambient loading scope |
| `skeletonWidth` | `string` (optional, default `'w-32'`) | Tailwind width class for the skeleton placeholder |

## Usage Example

```typescript
import { ValueText } from './value-text';

// Basic usage with a string value
<ValueText value={user.email} />

// Numeric value with custom skeleton width while loading
<ValueText value={account.balance} loading={isFetching} skeletonWidth="w-24" />

// Empty/undefined value renders the muted empty marker
<ValueText value={null} />

// Works automatically within a loading scope (e.g., Suspense-like context)
// without needing to pass `loading` explicitly
<LoadingScopeProvider loading={isPending}>
  <ValueText value={record.status} />
</LoadingScopeProvider>
```

This component is typically used in table cells or detail views where a value may be loading, missing, or present, ensuring consistent typography (`h4`) and truncation behavior across the UI.
