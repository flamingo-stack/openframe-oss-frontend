# device-info-section.tsx

A client-side React component that displays a "Device Info" section showing details for a device referenced by a log or ticket, either from pre-loaded props or by fetching it via its ID.

## Key Components

- **`DeviceInfoSectionProps`** — Props interface accepting an optional `deviceId` (string) and/or `device` (a `PartialNamedDevice` object passed directly, e.g., from a log or dialog).
- **`DeviceInfoSection`** — The main exported component. It:
  - Uses `useLoadingScope()` to detect if it's rendering within a broader loading context (in which case it avoids fetching).
  - Uses `useDeviceDetails()` to fetch device data by ID only when no `device` prop is supplied and not within a loading scope, with polling disabled.
  - Prefers the `device` prop over fetched data when both are available.
  - Renders a `DeviceSummaryCard` while loading or once device data is available.
  - Falls back to an `EmptyValue` placeholder when no device data is found and loading has completed.

## Usage Example

```typescript
import { DeviceInfoSection } from './device-info-section';

// Fetch device by ID
function LogDetailsPanel({ logDeviceId }: { logDeviceId: string }) {
  return <DeviceInfoSection deviceId={logDeviceId} />;
}

// Use pre-loaded device data (e.g., embedded in a log payload)
function TicketDetailsPanel({ ticketDevice }: { ticketDevice: PartialNamedDevice }) {
  return <DeviceInfoSection device={ticketDevice} />;
}
```

This component is typically embedded within detail views (such as log or ticket pages) under the `app/(app)/devices` feature area, where device context needs to be surfaced alongside other record information.
