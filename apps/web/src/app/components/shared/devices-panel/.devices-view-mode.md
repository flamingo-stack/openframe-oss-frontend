## devices-view-mode.ts

Determines the effective display mode (table or grid) for a devices list based on a URL query parameter and the available content width, ensuring narrow viewports always fall back to a usable table layout.

## Key Components

- **`DevicesViewMode`** — Type alias representing the two supported view modes: `'table'` or `'grid'`.
- **`devicesViewMode(param, contentMdUp)`** — Pure function that resolves the effective view mode:
  - Returns `'table'` if the `param` is anything other than `'grid'`.
  - Returns `'table'` if `contentMdUp` is explicitly `false` (content area is narrower than the `content-md` breakpoint), even if the param requests `'grid'`.
  - Returns `'grid'` otherwise (including when `contentMdUp` is `undefined`, i.e., width not yet measured).

The function is intentionally **derived, not persisted**: it never writes back to the URL param, so widening the content area later restores the grid view without needing to re-select it.

## Usage Example

```typescript
import { devicesViewMode, type DevicesViewMode } from './devices-view-mode';
import { useContentMdUp } from './use-content-md-up';

function DevicesPage() {
  const searchParams = useSearchParams();
  const contentMdUp = useContentMdUp();

  const mode: DevicesViewMode = devicesViewMode(
    searchParams.get('viewMode'),
    contentMdUp
  );

  return mode === 'grid' ? <DevicesGrid /> : <DevicesTable />;
}
```

In this example, if a user selects `viewMode=grid` on a wide screen and then resizes to a narrow/tablet viewport, the view automatically falls back to `'table'`—without mutating the URL—and reverts to `'grid'` once the viewport widens again.
