Reusable panel component that renders the full devices list UI — supporting both table and grid view modes, column/filter customization, infinite scroll, and contextual empty/error states.

## Key Components

### `DevicesPanelProps`
Configuration interface with the following notable props:

| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | Page header title (default: `'Devices'`) |
| `lockedFilters` | `Partial<DeviceFilterInput>` | Filters merged on top of URL-driven filters (e.g. lock to a single org) |
| `hideColumns` | `string[]` | Column IDs to remove from the table |
| `hideFilters` | `string[]` | Filter keys to hide from all filter UIs |
| `defaultStatuses` | `string[]` | Fallback status filters when the user has selected none |
| `embedded` | `boolean` | Drops top padding when rendered inside a tab |
| `noOrganizations` | `boolean` | Surfaces an "Add Customer" CTA and disables "Add Device" |
| `emptyState` | `ReactNode` | Custom empty state for pristine (no filters/search) views |

### `DevicesPanel`
Main exported component orchestrating:
- **URL state** via `useDevicesUrlParams` (search, filters, view mode)
- **Data fetching** via `useDevices` (paginated) and `useDeviceFilters`
- **Table view** via `DataTable` with `DevicesTableBody`, column filters, and row actions
- **Grid view** via `DevicesGrid` with infinite scroll (`useGridInfiniteScroll`)
- **Filter modal** via `useTagFilterModal` for tag/group filters
- **Header actions**: Archive, Add Customer, Add Device buttons with conditional states

## Usage Example

```typescript
// Standalone devices page
<DevicesPanel
  showAddDevice
  archiveHref={routes.devices.archive}
  emptyState={<MyEmptyState />}
  noOrganizations={hasNoOrgs}
  isCheckingOrganizations={isCheckingOrgs}
/>

// Embedded inside a customer detail tab
<DevicesPanel
  title="Customer Devices"
  embedded
  lockedFilters={{ organizationId: customer.id }}
  hideColumns={['organization']}
  hideFilters={['organization']}
  showAddDevice={false}
  defaultStatuses={[]}
/>
```

## Notes

- Grid view is automatically collapsed to table on mobile (`isMdUp` guard in `useEffect`)
- The "Add Device" button is disabled while `isCheckingOrganizations` is `true` to prevent premature navigation
- Post-action refreshes are handled centrally via query invalidation — no per-row callbacks needed
