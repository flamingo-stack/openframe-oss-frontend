## devices-panel.tsx

Implements the Devices list page panel, orchestrating URL-driven filters/search, deferred (non-blocking) query transitions, infinite-scroll pagination, and switching between a grid and table view. Wraps the loading, error, and empty states around a shared `DevicesPanelView`, and gates directory (USER/SOURCES) columns and tenant-management features behind feature flags.

## Key Components

- **`DevicesPanelProps`** — Public prop contract for the panel: title, back button, add/archive actions, locked/hidden filters and columns, empty states, embedded-mode layout, and organization-existence flags.
- **`useDirectoryPanelState`** — Reads the directory gate once per panel to decide whether USER/SOURCES columns render and whether row rendering should wait on a facet count.
- **`DevicesPanelContent`** — Resolves URL params, deferred filters/search (via `useDeferredQuery`), directory facets, and device list data; wraps rendering in a `ContentErrorBoundary` so facet failures don't take down the whole panel.
- **`DevicesPanelLoaded`** — Renders the fully-loaded panel: toolbar, filters, grid/table view mode, column filters, and empty-state logic (including the `isNarrowing` guard against flashing empty states mid-transition).
- **`renderDeviceRowActions`** — Per-row overflow menu renderer using `DeviceActionsDropdown`.
- **`PENDING_ACTIONS_COLUMN`** — Shared actions-column definition reused by the pending/loading state to keep column widths stable.

## Usage Example

```typescript
import { DevicesPanel } from '@/app/(app)/devices/components/panel/devices-panel';

export default function DevicesPage() {
  return (
    <DevicesPanel
      title="Devices"
      addDeviceHref="/devices/new"
      showAddDevice
      archiveHref="/devices/archive"
      defaultStatuses={['ONLINE', 'OFFLINE']}
      emptyMessage="No devices found. Try adjusting your search or filters."
    />
  );
}
```

Embedded usage within a tenant/customer details tab, with organization scoping locked and the standalone top padding dropped:

```typescript
<DevicesPanel
  embedded
  lockedFilters={{ organizationId }}
  hideColumns={['organization']}
  hideFilters={['organization']}
  showAddDevice={false}
/>
```
