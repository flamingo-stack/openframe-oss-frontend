## devices-panel-v1.tsx

Legacy (v1) implementation of the Devices panel, rendered only while the `tenant-management-v2` feature flag is off. Mirrors the v2 panel at `apps/web/src/app/components/shared/devices-panel/devices-panel.tsx` but wires URL params, filters, and data fetching through the v1 hooks (`useDevicesUrlParamsV1`, `useDevicesV1`). Slated for deletion once the flag is removed.

## Key Components

- **`DevicesPanelPropsV1`** — Public prop contract: title, back button, add/archive links, locked/hidden filters, empty states, read-only mode, and embedded-layout toggles.
- **`DevicesPanelContent`** — Top-level component that merges URL-driven filters with `lockedFilters`, defers filter/search changes via `useDeferredQuery` to keep rows visible during transitions, and fetches devices with `useDevicesV1`. Wraps `DeviceFacets` in a `ContentErrorBoundary` so a facet-query failure degrades gracefully instead of taking down the whole panel.
- **`DevicesPanelLoaded`** — Renders the resolved panel: computes the active view mode (grid vs. table), builds column filters/actions column, wires the tag filter modal (`useTagFilterModal`), and decides whether to show the marketing empty state vs. the toolbar + list.
- **`renderDeviceRowActions`** — Per-row overflow menu renderer using `DeviceActionsDropdown`.
- **`PENDING_ACTIONS_COLUMN` / `PENDING_FILTER_COLUMNS`** — Static column definitions used to keep the loading skeleton's widths in sync with the loaded table.

## Usage Example

```typescript
import { DevicesPanelContent, type DevicesPanelPropsV1 } from './devices-panel-v1';

const props: DevicesPanelPropsV1 = {
  title: 'Devices',
  showAddDevice: true,
  addDeviceHref: '/devices/new',
  lockedFilters: { organizationIds: ['org_123'] },
  hideColumns: ['organization'],
  hideFilters: ['organization'],
  defaultStatuses: ['ONLINE', 'OFFLINE'],
};

function CustomerDevicesTab() {
  return <DevicesPanelContent {...props} embedded />;
}
```

**Note:** This component is rendered conditionally based on the `tenant-management-v2` flag; prefer importing from the canonical `devices-panel.tsx` entry point rather than this file directly unless working on flag-gated legacy behavior.
