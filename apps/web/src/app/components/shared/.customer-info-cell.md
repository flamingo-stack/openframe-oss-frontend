# customer-info-cell.tsx

A React client component that renders a customer's logo alongside a linked info cell, used across device cards, recording meta cards, and incident summary cards to display customer association consistently.

## Key Components

- **`CUSTOMER_LOGO_SIZE`** - Constant (`'size-10'`) controlling the logo's fixed size.
- **`CustomerInfoCellProps`** - Interface defining the component's props:
  - `customer` - Object with `id`, `name`, and `logoUrl` (all optional/nullable), or `null` if no customer is associated.
  - `label` - Optional label override (defaults to `'Customer ID (Site)'`).
- **`CustomerInfoCell`** - The main exported component. Renders an `EntityImage` (customer logo) next to an `InfoCell` whose value is a hyperlink to the customer's detail page when both `name` and `id` are available.

## Behavior Notes

- Uses `useLoadingScope()` to detect whether the surrounding record is still loading, enabling skeleton states for both the logo and the cell value.
- The logo is shown while loading (since most records have a customer) or once a `name` resolves; it's omitted entirely for customer-less records, shifting the value horizontally without affecting row height.
- Links to the customer's detail page via `routes.customers.details(id)` only when both `name` and `id` exist; otherwise renders plain text (or nothing, handled by `InfoCell`'s empty-state styling).

## Usage Example

```typescript
import { CustomerInfoCell } from '@/app/components/shared/customer-info-cell';

function DeviceCard({ device }: { device: Device }) {
  return (
    <CustomerInfoCell
      customer={device.customer}
      label="Customer ID (Site)"
    />
  );
}

// With no customer association
<CustomerInfoCell customer={null} />

// Custom label for an incident summary card
<CustomerInfoCell customer={incident.customer} label="Affected Customer" />
```
