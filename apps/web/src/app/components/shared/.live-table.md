# live-table.tsx

A reusable shell component for building "live" list tables that look identical whether data is loading or loaded. It wraps `DataTable` with a pending-state dim overlay, sticky header with row count, body with skeleton support, and an optional infinite-scroll footer, ensuring loading and loaded states share the exact same markup to avoid layout shift.

## Key Components

- **`LIVE_ROW_GAP_CLASS`** — Shared CSS class (`mb-1`) applied to every row's gap, including skeleton rows.
- **`PendingDim`** — Wraps children in a dimmed container while a background refetch is in flight, without unmounting existing rows.
- **`loadingPlaceholderRows<T>(count)`** — Generates placeholder row objects (`{ id: 'loading-N' }`) used to drive skeleton rendering through real cell components.
- **`LiveTableRows`** — Discriminated union requiring either `pageSize` (paged lists) or `skeletonRows` (whole-list reads) to determine skeleton row count.
- **`LiveTableProps<T>`** — Full prop shape combining shell options, row-count config, and either a pre-built `table` (loaded state) or raw `columns` (loading state).
- **`LiveTable<T>`** — Main exported component; dispatches to `LiveTableShell` (table provided) or `LoadingRowsLiveTable` (columns only, builds a placeholder-backed table).
- **`LoadingRowsLiveTable`** / **`LiveTableShell`** — Internal implementations composing `DataTable.Header`, `DataTable.Body`, and `DataTable.InfiniteFooter`.

## Usage Example

```typescript
import { LiveTable, type ColumnDef } from './live-table';

type User = { id: string; name: string; email: string };

const columns: ColumnDef<User>[] = [
  { id: 'name', header: 'Name', cell: (row) => row.name },
  { id: 'email', header: 'Email', cell: (row) => row.email },
];

function UserList({ table, isLoading, isPending }: { table?: DataTableInstance<User>; isLoading: boolean; isPending: boolean }) {
  if (isLoading) {
    return <LiveTable columns={columns} pageSize={20} itemName="user" />;
  }

  return (
    <LiveTable
      table={table!}
      pageSize={20}
      itemName="user"
      isPending={isPending}
      rowHref={(row) => `/users/${row.id}`}
      footer={{ onLoadMore: () => {}, hasNextPage: true }}
    />
  );
}
```

Pass `columns` before the first page resolves (no table yet) and `table` once data loads—both render the same layout so there's no visual jump between states.
