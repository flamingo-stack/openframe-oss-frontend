# lazy-markdown.tsx

Provides lazily-loaded, code-split versions of the markdown renderer and editor components, reducing the initial page bundle size by deferring these components' code until they're actually needed on the client.

## Key Components

- **`SimpleMarkdownRenderer`** — A dynamically imported markdown renderer (client-side only, `ssr: false`). While loading, it falls back to `MarkdownEngineSkeleton` to preserve layout and avoid content jumps.
- **`lazyMarkdownEditor(height: number)`** — A factory function that returns a dynamically imported `MarkdownEditor` component bound to a specific field height. Since the `next/dynamic` loading fallback receives no props, the height must be supplied at creation time so the skeleton (`MarkdownEditorFieldSkeleton`) matches the eventual editor's dimensions, preventing layout shift.

Both components are sourced from `@flamingo-stack/openframe-frontend-core` and its `components/ui` subpath, and are split out of the main page bundle via `next/dynamic`.

## Usage Example

```typescript
import { SimpleMarkdownRenderer, lazyMarkdownEditor } from './lazy-markdown';

// Rendering markdown content
function ArticlePreview({ content }: { content: string }) {
  return <SimpleMarkdownRenderer value={content} />;
}

// Creating a bound editor instance — call once at module level per height
const MarkdownEditorField = lazyMarkdownEditor(240);

function CommentForm() {
  return (
    <form>
      <MarkdownEditorField name="comment" placeholder="Write a comment..." />
    </form>
  );
}
```

**Note:** `lazyMarkdownEditor` should be invoked once at module scope for each distinct height needed (e.g., as a constant), not inside a component render function, to avoid recreating the dynamic component on every render.
