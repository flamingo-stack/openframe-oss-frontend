# policy-value-card.tsx

A presentational component that renders a single, read-only policy value (e.g. a guardrails preset or remote access permission) inside a styled card. It's used across tenant default views and per-customer views, delegating label/value rendering and loading states to `InfoCell`.

## Key Components

- **`POLICY_VALUE_CARD_CLASS`** – Constant Tailwind class string defining the card's responsive sizing (60px min-height on mobile, 80px from `md` breakpoint) and styling (border, background, padding).
- **`PolicyValueCardProps`** – Props interface:
  - `label: string` — field name, always shown even while loading.
  - `value?: string | null` — the policy value; `null`/`undefined` triggers the loading skeleton.
  - `muted?: boolean` — renders the value in secondary text color to indicate it's inherited from defaults.
  - `loading?: boolean` — explicitly forces the loading state.
- **`PolicyValueCard`** – The functional component that composes `InfoCell` inside the styled card wrapper, handling muted styling and loading/skeleton logic.

## Usage Example

```typescript
import { PolicyValueCard } from './policy-value-card';

// Standard resolved value
<PolicyValueCard label="Guardrails Preset" value="Strict" />

// Value inherited from tenant defaults (shown muted)
<PolicyValueCard label="Remote Access" value="Enabled" muted />

// Loading state (value not yet fetched)
<PolicyValueCard label="Guardrails Preset" loading />

// Value implicitly loading because it's null/undefined
<PolicyValueCard label="Remote Access" value={null} />
```

The component automatically enters a loading state whenever `value` is `null` or `undefined`, so explicit `loading` is only needed to force a skeleton before data resolution completes.
