# selectable-tags-row.tsx

A React client component that renders a single-line, overflow-aware row of clickable tag chips used for adding tags to a filter. Tags that don't fit on one line collapse into an overflow "…" chip that opens a dropdown menu listing the remaining tags.

## Key Components

- **`SelectableTag`** — Interface describing a tag (`id`, `key`).
- **`SelectableTagsRow`** — Main exported component. Renders available (unselected) tags as clickable chips, auto-collapsing overflow into an actions menu.
- **`formatTagLabel`** — Truncates tag labels longer than `MAX_TAG_LABEL_LENGTH` (24 chars) and appends an ellipsis; full text is shown via tooltip.
- **Loading state** — Driven by `useLoadingScope()` (ambient) or the `loading` prop; renders skeleton `Tag` placeholders via `LoadingItems`/`LoadingRegion`.
- **Overflow measurement** — Uses `useAutoLimitTags` with hidden off-screen `Tag` copies (`measureRef`) to compute how many chips (`visibleCount`) fit before falling back to the "…" badge (`badgeRef`).

## Usage Example

```typescript
import { SelectableTagsRow, type SelectableTag } from './selectable-tags-row';

const allTags: SelectableTag[] = [
  { id: '1', key: 'production' },
  { id: '2', key: 'staging' },
  { id: '3', key: 'needs-review-very-long-tag-name' },
];

function TagFilterExample() {
  const [selectedIds, setSelectedIds] = useState<string[]>([]);

  return (
    <SelectableTagsRow
      tags={allTags}
      selectedIds={selectedIds}
      onAdd={(tag) => setSelectedIds(prev => [...prev, tag.id])}
      loading={false}
    />
  );
}
```

When wrapped inside a `LoadingScope` provider (via `useLoadingScope`), the row automatically shows skeleton placeholders without needing to pass `loading` explicitly. Tags already present in `selectedIds` are excluded from the available list, and selecting a hidden tag from the overflow menu keeps the menu open (`closeOnSelect: false`) to allow adding multiple tags in sequence.
