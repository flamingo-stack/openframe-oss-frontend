Renders a single-line row of clickable tag chips for adding tags to a filter, automatically collapsing overflow items into an ellipsis dropdown menu.

## Key Components

### `SelectableTagsRow`
Primary component that displays available (non-selected) tags as clickable `Tag` chips. Uses `useAutoLimitTags` to measure container width and determine how many chips fit on one line. Overflow tags collapse into an `ActionsMenuDropdown` triggered by an ellipsis chip. Long tag labels (>24 chars) are truncated with a `FloatingTooltip` revealing the full key.

While its tags are read (`loading`, or a loading scope) the row draws its own loading state: a typical row of tag-chip skeleton boxes (`SelectableTagsRowSkeleton`, built from the lib's skeleton parts) in the row's own frame.

### `SelectableTag` (interface)
```typescript
interface SelectableTag {
  id: string;
  key: string;
}
```

### `formatTagLabel` (internal)
Truncates tag keys exceeding `MAX_TAG_LABEL_LENGTH` (24 characters) with an ellipsis character.

## Usage Example

```typescript
import {
  SelectableTagsRow,
  type SelectableTag,
} from './selectable-tags-row';

const allTags: SelectableTag[] = [
  { id: '1', key: 'production' },
  { id: '2', key: 'critical' },
  { id: '3', key: 'windows-servers' },
];

// The row draws its own loading state while the tags are read
<SelectableTagsRow
  loading={isLoading}
  tags={allTags}
  selectedIds={['1']}           // 'production' is already selected, hidden from row
  onAdd={(tag) => addFilter(tag)}
/>
```

The component internally filters out already-selected tags and renders an off-screen duplicate row (hidden via `aria-hidden`) to allow `useAutoLimitTags` to measure chip widths before committing to a visible count.
