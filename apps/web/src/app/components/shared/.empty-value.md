A small presentational component that renders the shared empty-value placeholder (`EMPTY_VALUE`) with muted styling, ensuring missing data is visually distinct from real content across the UI.

## Key Components

- **`EmptyValue`** — Functional component that renders `EMPTY_VALUE` inside a `<span>` styled with the `text-ods-text-secondary` class. It intentionally only controls color, leaving font size and layout to the surrounding context (table cell, summary field, stat block, etc.).

## Usage Example

```typescript
import { EmptyValue } from '@/components/empty-value';

function UserProfileField({ value }: { value: string | null }) {
  return (
    <div className="stat">
      {value ? value : <EmptyValue />}
    </div>
  );
}
```

```typescript
// Inside a table cell
<td>
  {row.lastLogin ?? <EmptyValue />}
</td>
```

Use `EmptyValue` anywhere `EMPTY_VALUE` is displayed to users, ensuring consistent muted styling instead of manually repeating the placeholder text and CSS class.
