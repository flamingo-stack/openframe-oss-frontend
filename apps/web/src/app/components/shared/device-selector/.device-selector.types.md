Defines TypeScript types and interfaces for the `DeviceSelector` component, including props for controlling selection state, infinite scroll behavior, display configuration, and interaction modes.

## Key Components

- **`SubTab`** — Union type for tab state: `'available'` or `'selected'`
- **`InfiniteScrollConfig`** — Configuration object for paginated loading on the available tab (pagination state, load callback, skeleton row count)
- **`DeviceSelectorProps`** — Primary props interface for the `DeviceSelector` component

### Notable `DeviceSelectorProps` Fields

| Prop | Type | Description |
|---|---|---|
| `devices` | `Device[]` | Consumer-controlled device list |
| `selectedIds` | `Set<string>` | Currently selected device keys |
| `onSelectionChange` | `(ids: Set<string>) => void` | Selection change callback |
| `readOnly` | `boolean` | Viewer mode — disables tabs, radio, and action buttons |
| `singleSelect` | `boolean` | Restricts selection to one device at a time |
| `addAllBehavior` | `'replace' \| 'merge'` | Controls "Add All" action behavior |
| `isDeviceDisabled` | `(device: Device) => string \| undefined` | Per-device disable with tooltip |
| `hideColumns` | `string[]` | Column IDs to remove from the table |
| `infiniteScroll` | `InfiniteScrollConfig` | Enables paginated loading |
| `headerContent` | `ReactNode` | Slot for content above tabs (e.g. info bars) |

## Usage Example

```typescript
import type { DeviceSelectorProps, InfiniteScrollConfig } from './device-selector.types';

const scrollConfig: InfiniteScrollConfig = {
  hasNextPage: true,
  isFetchingNextPage: false,
  onLoadMore: () => fetchNextPage(),
  skeletonRows: 5,
};

const props: DeviceSelectorProps = {
  devices: deviceList,
  loading: isLoading,
  selectedIds: new Set(['machine-123', 'machine-456']),
  onSelectionChange: (ids) => setSelected(ids),
  readOnly: false,
  singleSelect: false,
  addAllBehavior: 'merge',
  hideColumns: ['organization'],
  infiniteScroll: scrollConfig,
  isDeviceDisabled: (device) =>
    device.status === 'offline' ? 'Device is offline' : undefined,
};
```
