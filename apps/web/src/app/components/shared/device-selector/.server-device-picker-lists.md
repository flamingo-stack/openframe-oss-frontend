## ServerDevicePickerLists

A shared presentational wrapper that wires two server-paginated GraphQL connections (`available` and `selected` devices) into the `DeviceSelector` component's server mode. It powers device-assignment pickers (e.g., script schedules, software bundles) wherever an owner entity exposes an `availableDevices` / `assignedDevices` connection pair.

## Key Components

- **`PickerEdge`** — Interface for a single connection edge, carrying the device node plus an optional `assigned` flag (only meaningful on the Available half).
- **`PickerConnection`** — Interface describing a paginated connection: `filteredCount` and `edges`.
- **`PickerHalf`** — Interface bundling a connection with its pagination state (`hasNext`, `isLoadingNext`, `loadNext`).
- **`ServerDevicePickerListsProps`** — Full prop contract: both halves, active tab/search/narrowing state, add/remove callbacks, disabled-row predicate, and loading flag.
- **`ServerDevicePickerLists`** — The component itself. Reads both halves simultaneously (so tab switches are instant and the search box never unmounts), derives `selectedKeys` from the Available half's `assigned` flags, and renders a single `DeviceSelector` configured for server-driven search/pagination/selection.

## Usage Example

```typescript
import { ServerDevicePickerLists } from './server-device-picker-lists';

function SoftwareBundleDevicePicker() {
  const available = useAvailableDevicesConnection(bundleId);
  const selected = useAssignedDevicesConnection(bundleId);

  return (
    <ServerDevicePickerLists
      available={available}
      selected={selected}
      selectedCount={bundle.assignedDeviceCount}
      filterOptions={deviceFilterOptions}
      activeTab={activeTab}
      onTabChange={setActiveTab}
      search={search}
      onSearchChange={setSearch}
      narrowing={narrowing}
      onNarrowingChange={setNarrowing}
      busy={isMutating}
      onAdd={(device) => assignDevice(device.id)}
      onRemove={(device) => unassignDevice(device.id)}
      onAddAll={() => assignAll()}
      onRemoveAll={() => unassignAll()}
    />
  );
}
```

Each owner component is responsible for executing its own two GraphQL queries/connections and passing the resulting `PickerHalf` objects in; this component only handles presentation and pagination wiring.
