Manages state and filtering logic for a device selector component, providing search, tab switching, and filtered device list derivation.

## Key Components

### `useDeviceSelector(params)`

Custom hook accepting a `UseDeviceSelectorParams` object:

| Parameter | Type | Description |
|---|---|---|
| `devices` | `Device[]` | Full list of available devices |
| `selectedIds` | `Set<string>` | Set of currently selected device keys |
| `getDeviceKey` | `(device: Device) => string \| undefined` | Extracts a unique key from a device |

**Returns:**

| Value | Type | Description |
|---|---|---|
| `searchTerm` | `string` | Current search input value |
| `setSearchTerm` | `Dispatch` | Updates the search filter |
| `activeSubTab` | `SubTab` | Active tab — `'available'` or `'selected'` |
| `handleTabChange` | `(tabId: string) => void` | Switches tab and resets search |
| `filteredDevices` | `Device[]` | Devices matching the current search term |
| `displayDevices` | `Device[]` | Devices filtered by both search and active tab |

## Usage Example

```typescript
const {
  searchTerm,
  setSearchTerm,
  activeSubTab,
  handleTabChange,
  displayDevices,
} = useDeviceSelector({
  devices: allDevices,
  selectedIds: new Set(['device-1', 'device-2']),
  getDeviceKey: (device) => device.id,
});
```

Filtering matches against `displayName`, `hostname`, `osType`, and `operating_system` fields (case-insensitive). When `activeSubTab` is `'selected'`, `displayDevices` is further narrowed to only devices whose key exists in `selectedIds`. Switching tabs via `handleTabChange` resets the search term.
