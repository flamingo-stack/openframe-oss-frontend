Utility module for transforming GraphQL connection edges into typed `Device` rows, used by server-driven device picker components (e.g., dual-list selectors) that paginate machine data.

## Key Components

- **`DEVICE_PICKER_PAGE_SIZE`** — Constant defining the page size (20) used when fetching devices per side of a picker UI.
- **`MachineEdges`** — Internal type alias representing a nullable array of GraphQL connection edges, each wrapping an optional `deviceSelectorFields_machine$key` fragment reference.
- **`toDevices(edges)`** — Converts connection edges into an array of `Device` objects, safely filtering out `null`/`undefined` edges or nodes (e.g., due to Relay store eviction) and mapping valid nodes via `machineSelectorToDevice`.

## Usage Example

```typescript
import { toDevices, DEVICE_PICKER_PAGE_SIZE } from './picker-narrowing';

// Inside a component consuming a paginated GraphQL connection
const devices = toDevices(data?.machines?.edges);

// Use the page size constant when configuring pagination
const { loadNext } = usePaginationFragment(fragmentSpec, parentRef);
loadNext(DEVICE_PICKER_PAGE_SIZE);

devices.forEach(device => {
  console.log(device.id, device.name);
});
```

This pattern ensures components never crash on partially-evicted Relay store data, since `toDevices` gracefully skips malformed or missing edges while preserving strong typing for downstream consumers like device selector tables.
