## Overview

Defines the layout metadata shape for `DataTable` columns and exposes a single function, `liveColumnMeta`, that merges this shared layout with a column's own extras when building live Relay-backed column defs. It is a data-only module (no JSX, no `'use client'`, no imports) so that a table's column layout can be defined and shared without pulling in the table's Relay artifacts, mutations, or cell renderers.

The module underpins a "skeleton-as-live-table" loading pattern: the loading state is the real table rendered with zero rows, so the layout declared here (widths, breakpoints, sort icons, date filters) must exactly match what the live columns render.

## Key Components

- **`TableBreakpoint`** — union type (`'md' | 'lg' | 'xl' | '2xl'`) restating `DataTable`'s own breakpoints, kept local to avoid a type import.
- **`TableSkeletonColumn`** — layout descriptor for a column: `id`, optional `header`, required `width`, optional `hideAt`, `align`, `sortable`, and `dateFilterable`.
- **`SharedColumnMeta`** (internal) — the subset of `meta` fields considered shared layout: `width`, `hideAt`, `align`, `sortable`, `alwaysShowHeader`. Intentionally excludes any "full width header below `lg`" escape hatch — use `hideAt` instead, or pass one-off header classes through `liveColumnMeta`'s `extra`.
- **`sharedMeta()`** (internal) — converts a `TableSkeletonColumn` into `SharedColumnMeta`, deriving `alwaysShowHeader` from `dateFilterable` (date filter controls must stay visible below `lg`, same as other actionable filters).
- **`liveColumnMeta(column, extra?)`** — merges `extra` (column-specific meta like `filter`, `cellClassName`) with the shared layout, with shared fields taking precedence. Generic `const T` preserves literal types in `extra` (e.g. `placement: 'bottom-end'`) so callers don't need `as const`.

## Usage Example

```typescript
import { liveColumnMeta, type TableSkeletonColumn } from './table-column-layout';

const invoiceDateColumn: TableSkeletonColumn = {
  id: 'invoiceDate',
  header: 'Invoice Date',
  width: 'w-32',
  hideAt: 'lg',
  sortable: true,
  dateFilterable: true,
};

// When building the live column def:
const columnDef = {
  accessorKey: 'invoiceDate',
  meta: liveColumnMeta(invoiceDateColumn, {
    filter: { type: 'date', placement: 'bottom-end' },
    cellClassName: 'tabular-nums',
  }),
};
```

The same `invoiceDateColumn` object is reused to render the matching skeleton column during loading, guaranteeing layout parity between loading and loaded states.
