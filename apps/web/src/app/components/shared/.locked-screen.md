A reusable presentation component that renders a centered "locked" card in place of page content, used when a surface can't be shown (inactive workspace, role-restricted section, or a failed render in `app/error.tsx`).

## Key Components

- **`LockedScreen`** — Client component (`'use client'`) rendering a centered card with an icon, title, description, and optional actions row.
- **`LockedScreenProps`** — Props interface:
  - `icon?: ReactNode` — defaults to `LockAltIcon` (padlock) if omitted.
  - `title: string` — heading text.
  - `description: string` — supporting copy.
  - `actions?: ReactNode` — optional buttons, laid out stacked on small screens and in a row from the `sm` breakpoint up.

This component is presentation-only: it carries no status, role, or built-in copy. Because one of its callers renders in native app builds (where App Store Guideline 3.1.1 prohibits showing plans, prices, or purchase CTAs), the responsibility for keeping copy compliant lies with each caller — this component must not introduce any payment-related content itself.

## Usage Example

```typescript
import { LockedScreen } from './locked-screen';
import { Button } from '@/components/ui/button';

export function InactiveWorkspaceNotice() {
  return (
    <LockedScreen
      title="Workspace inactive"
      description="This workspace has been paused by your administrator."
      actions={
        <>
          <Button variant="secondary">Switch workspace</Button>
          <Button variant="primary">Contact admin</Button>
        </>
      }
    />
  );
}

// Minimal usage with default lock icon and no actions
export function RestrictedSection() {
  return (
    <LockedScreen
      title="Access restricted"
      description="This section is only available to admin users."
    />
  );
}
```
