Renders a formatted date alongside its calculated age in days, intended for use cases where the elapsed time since a date is the key information to display (e.g., CVE exposure duration).

## Key Components

- **`DateWithAge`** — Client component that accepts a `date` prop (accepting `string | number | Date | null | undefined`) and renders:
  - The formatted date (via `formatDate`) on the first line.
  - The age in days (via `differenceInCalendarDays` and `pluralize`) as secondary, smaller text below.
  - Falls back to `ValueText` with a `null` value if the date is invalid or missing.

## Usage Example

```typescript
import { DateWithAge } from '@/components/date-with-age';

function CveRow({ publishedAt }: { publishedAt: string }) {
  return (
    <td>
      <DateWithAge date={publishedAt} />
    </td>
  );
}

// Handles invalid/missing dates gracefully
<DateWithAge date={null} />
<DateWithAge date={undefined} />
<DateWithAge date="invalid-date-string" />
```

## Notes

- Relies on `toValidDate` from `@/lib/format-date` to validate and normalize the incoming date before rendering.
- Uses `TruncateText` from `@flamingo-stack/openframe-frontend-core` to ensure long formatted strings truncate gracefully in constrained layouts.
- The age label uses `pluralize` to correctly render "1 day" vs. "N days".
- Designed as a compact two-line cell renderer, commonly used in table/grid columns where both the exact date and its elapsed duration matter.
