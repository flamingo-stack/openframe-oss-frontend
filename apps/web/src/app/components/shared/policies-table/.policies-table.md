Reusable data table component for displaying MSP policy compliance data, supporting both fleet-wide monitoring and per-device policy views.

## Key Components

### `PoliciesTable`
Main exported component that renders a normalized `PolicyTableRow[]` with a consistent column layout.

**Columns rendered:**
- **Name** — Policy name with optional truncated description
- **Severity** — Critical/non-critical label, optionally sortable
- **Platform** *(optional)* — OS badge icons (`showPlatform` prop); empty platform list renders all OS icons
- **Status** — Tag with variant styling plus optional tone-colored note
- **Actions** *(conditional)* — `MoreActionsMenu` when row actions exist; column reserved during loading to prevent layout jitter
- **Open** — External link button via `openInNewTab`

### `PoliciesTableProps`
Full configuration interface supporting loading states, sorting, infinite scroll, sticky headers, and empty state customization.

## Usage Example

```typescript
import { PoliciesTable } from './policies-table';
import type { PolicyTableRow } from './policy-table-row';

const rows: PolicyTableRow[] = [
  {
    id: 'policy-1',
    name: 'FileVault Encryption',
    description: 'Disk encryption must be enabled',
    critical: true,
    severityLabel: 'Critical',
    platforms: ['darwin'],
    status: { label: 'Failing', variant: 'error' },
    href: 'https://console.example.com/policies/policy-1',
    actions: [{ label: 'View details', onClick: () => {} }],
  },
];

// Fleet-wide view with platform column and sorting
<PoliciesTable
  rows={rows}
  showPlatform
  sortable
  rowAsLink
  stickyHeader
  emptyState={{ icon: ShieldIcon, title: 'No policies', description: 'Add a policy to get started' }}
  hasMore={hasNextPage}
  onLoadMore={fetchNextPage}
/>

// Per-device view (no platform column)
<PoliciesTable rows={rows} isLoading={isFetching} skeletonRows={5} />
```

## Notes

- Column count is kept stable during loading by reserving the actions column while `isLoading` is true, preventing visual jitter when skeleton rows transition to real data.
- An empty `platforms` array is treated as "all platforms" and renders the full `['windows', 'darwin', 'linux']` icon set.
- The column header is hidden on empty state but shown during skeleton loading.
