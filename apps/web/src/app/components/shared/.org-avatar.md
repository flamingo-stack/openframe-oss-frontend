Renders a small circular avatar for an organization, displaying either the org's image or a two-letter initials fallback when no image is available or fails to load.

## Key Components

### `OrgAvatar`
A client component that accepts:
- `imageUrl` — optional raw image URL for the organization
- `hash` — optional cache-busting hash appended to the image URL
- `name` — organization name used to derive initials fallback

**Behavior:**
- Constructs the full image URL via `getFullImageUrl(imageUrl, hash)`
- Passes the URL through `useAuthedImageSrc` to swap in an authenticated blob URL in bearer-mode native shells (where plain `<img>` loads cannot carry an `Authorization` header)
- Tracks load errors via `failedUrl` state; falls back to initials if the resolved URL fails
- Renders a 20×20 Next.js `<Image>` when a valid URL is available, or a `<span>` showing the first two characters of `name` uppercased

## Usage Example

```typescript
import { OrgAvatar } from '@/components/org-avatar';

// With an image
<OrgAvatar
  imageUrl="/uploads/orgs/acme-logo.png"
  hash="abc123"
  name="Acme Corp"
/>

// Initials fallback (no image provided)
<OrgAvatar name="Flamingo Stack" />
```

## Notes

- The avatar is always 20×20px (`size-5`) with `rounded-full` and `overflow-hidden`
- Initials are capped at two characters; defaults to `??` if `name` is empty
- Error handling is URL-specific: if the authed URL changes (e.g. token refresh), the error state clears and the image retries automatically
