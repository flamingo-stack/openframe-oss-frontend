# org-avatar.tsx

A client-side React component that renders an organization's logo as a round avatar within a list row, falling back to initials when no image is available or the image fails to load.

## Key Components

- **`OrgAvatarProps`** — Interface defining the component's props:
  - `imageUrl?: string | null` — Optional image URL for the organization's logo
  - `hash?: string | null` — Optional hash used for cache-busting/versioning the image URL
  - `name: string` — Organization name, used for alt text and initials fallback

- **`OrgAvatar`** — Functional component that wraps the shared `SquareAvatar` component from `@flamingo-stack/openframe-frontend-core`, configured with:
  - `variant="round"` for circular rendering
  - `sizePx={IMAGE_FIXED_PX.glyph}` for consistent glyph-sized dimensions in table/list contexts
  - `src` resolved via `getFullImageUrl(imageUrl, hash)` to build the complete image URL
  - Automatic fallback to initials (styled via `initialsClassName`) when the image is missing or fails to load

Since `SquareAvatar` internally uses the authed-image hook, image loading works correctly even in bearer-token (native shell) authentication modes by resolving to an authenticated blob URL.

## Usage Example

```typescript
import { OrgAvatar } from '@/components/org-avatar';

function OrganizationRow({ org }: { org: Organization }) {
  return (
    <div className="flex items-center gap-2">
      <OrgAvatar
        imageUrl={org.logoUrl}
        hash={org.logoHash}
        name={org.name}
      />
      <span>{org.name}</span>
    </div>
  );
}
```

If `org.logoUrl` is `null` or the image fails to load, the avatar automatically displays the organization's initials derived from `org.name`.
