# openframe-lockup.tsx

A React component that renders the OpenFrame brand lockup — the logo mark paired with the wordmark — used across full-screen surfaces such as authentication pages, the inactive workspace screen, the setup wizard header, the root error screen, and account deletion pages.

## Key Components

- **`OpenframeLockup`** — Functional component that composes `OpenframeLogoIcon` and `OpenframeTextIcon` side by side using flexbox layout, with styling driven by CSS custom properties for consistent theming (colors and spacing).
  - **Props:**
    - `className` (optional `string`) — Additional CSS classes merged onto the root container via the `cn` utility.

## Usage Example

```typescript
import { OpenframeLockup } from './openframe-lockup';

export function AuthStatusPage() {
  return (
    <div className="flex flex-col items-center justify-center min-h-screen">
      <OpenframeLockup className="mb-8" />
      <p>Your session has expired. Please sign in again.</p>
    </div>
  );
}
```

```typescript
// Usage without additional styling
import { OpenframeLockup } from './openframe-lockup';

export function SetupWizardHeader() {
  return <OpenframeLockup />;
}
```

## Notes

- Relies on `@flamingo-stack/openframe-frontend-core` for shared icon components (`OpenframeLogoIcon`, `OpenframeTextIcon`) and the `cn` class-merging utility.
- Colors (`--color-accent-primary`, `--color-text-primary`) and spacing (`--spacing-system-xsf`) are sourced from the design system's CSS custom properties, ensuring the lockup automatically adapts to theme changes.
- The wordmark icon uses a fixed inline size (`144px` x `24px`) while the logo mark scales via Tailwind's `h-10 w-auto`.
