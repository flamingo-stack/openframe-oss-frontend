Purely presentational toolbar combining a tag-aware search input, a responsive "Device Tags" filter button, and a `FilterModal`. All state is owned by the parent component.

## Key Components

### `DevicesFilterToolbar`

The sole export — a stateless React component that renders two logical sections:

- **Search row** — a `TagSearchInput` displaying active tag chips alongside a free-text search field, and a responsive `Button` that opens the filter modal (label on `md+`, icon-only on smaller viewports).
- **`FilterModal`** — proxied directly from parent props; handles device tag filtering.

### `DevicesFilterToolbarProps`

| Prop | Type | Description |
|---|---|---|
| `searchValue` / `onSearchChange` | `string` / callback | Controlled search input value |
| `tags` / `onTagRemove` / `onClearAll` / `onSubmit` | `TagSearchOption[]` / callbacks | Tag chip management |
| `isMdUp` | `boolean \| undefined` | Switches button between label and icon-only mode |
| `onOpenFilterModal` | `() => void` | Triggers filter modal from parent |
| `isFilterModalOpen` / `onCloseFilterModal` | `boolean` / callback | Modal open state |
| `filterGroups`, `onFilterChange`, `currentFilters`, `tagFilterKeys`, `selectedTags`, `onTagsChange` | `FilterModalProps` fields | Passed straight through to `FilterModal` |
| `sticky` | `boolean` (default `true`) | Pins toolbar with bleed layout; set `false` inside modals/containers |

## Usage Example

```typescript
<DevicesFilterToolbar
  searchValue={search}
  onSearchChange={setSearch}
  tags={selectedTags}
  onTagRemove={(v) => removeTag(v)}
  onClearAll={clearAllTags}
  onSubmit={handleSubmit}
  isMdUp={isDesktop}
  onOpenFilterModal={() => setFilterOpen(true)}
  isFilterModalOpen={filterOpen}
  onCloseFilterModal={() => setFilterOpen(false)}
  filterGroups={groups}
  onFilterChange={handleFilterChange}
  tagFilterKeys={TAG_KEYS}
  selectedTags={activeTagFilters}
  onTagsChange={setActiveTagFilters}
  sticky={false} // e.g. inside DeviceSelector modal
/>
```
