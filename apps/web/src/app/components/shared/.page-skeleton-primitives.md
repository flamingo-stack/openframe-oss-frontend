Reusable loading-state primitives shared by all route-level page skeletons. Renders real chrome (headers, titles, column definitions, action buttons) with skeleton placeholders only for request-dependent data, ensuring zero layout shift when live data arrives.

## Key Components

| Export | Type | Description |
|---|---|---|
| `InlineSkeleton` | Component | Phrasing-valid `<span>` skeleton bar for use inside `<p>` elements, avoiding invalid `<div>`-in-`<p>` hydration errors |
| `InfoCardSkeleton` | Component | Dashboard stat card in loading state; renders real title, skeletons value/sub-value/percentage/progress ring |
| `TableSkeleton` | Component | Empty `DataTable` with real column headers and animated skeleton rows; wraps in `aria-busy` for screen reader signaling |
| `TabBarSkeleton` | Component | `h-14` tab bar placeholder matching `TabNavigation`; accepts per-cell `widths` to mirror real tab labels |
| `SearchBarSkeleton` | Component | Full-width `h-12` bar placeholder for filter/search toolbars |
| `ListPageSkeleton` | Component | Composite skeleton for list pages: optional tab bar + `PageLayout` header + search bar + table |

## Usage Example

```typescript
// Minimal list-page skeleton
<ListPageSkeleton
  title="Devices"
  actions={[{ label: 'Add Device', icon: PlusIcon, disabled: true }]}
  tabWidths={['w-28', 'w-24', 'w-32']}
  columns={[
    { id: 'name',   header: 'Name',   width: 'w-48' },
    { id: 'status', header: 'Status', width: 'w-24', hideAt: 'md' },
    { id: 'os',     header: 'OS',     width: 'w-32', align: 'right' },
  ]}
  rows={15}
/>

// Inline skeleton inside a typography element
<p className="text-h5">
  Total: <InlineSkeleton className="h-4 w-12" />
</p>

// Stat card with progress ring
<InfoCardSkeleton
  title="CPU Usage"
  showPercentage
  showProgress
  valueClassName="tabular-nums"
/>
```

## Notes

- `INFO_CARD_CLASS` mirrors `DashboardInfoCard`'s internal `baseClassName` (not exported by the library) to guarantee matching `h-16 md:h-[104px]` fixed height
- `TableSkeleton` passes a stable empty array (`EMPTY_SKELETON_ROWS`) and `getRowId={() => ''}` to satisfy `useDataTable` without query data
