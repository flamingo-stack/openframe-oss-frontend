# loading-paragraph.tsx

A client-side React component that renders a paragraph of body copy with a built-in loading skeleton state, used for content that is fetched asynchronously (e.g., error descriptions, CVE details, customer notes).

## Key Components

- **`LoadingParagraph`** — Main component. Shows a skeleton placeholder while `text` is `undefined`, `loading` is `true`, or the component is within a loading scope (via `useLoadingScope`). Once `text` resolves, renders the actual paragraph.
- **`LoadingParagraphProps`** — Props interface:
  - `text?: string` — the paragraph content; `undefined` triggers skeleton state.
  - `loading?: boolean` — explicit loading flag.
  - `label?: string` — accessible label announced while loading (wraps skeleton in a `LoadingRegion`); omit if the parent region already announces itself.
  - `type?: 'h4' | 'h6'` — typography scale (defaults to `'h4'`).
  - `tone?: 'primary' | 'secondary'` — text color tone (defaults to `'secondary'`).
  - `className?: string` — extra classes applied to the rendered paragraph.
  - `lines?: ParagraphLines` — number of skeleton lines, or a responsive `{ base, md }` pair split at the `content-md` breakpoint.
- **`ParagraphLines`** — Type alias: `number | { base: number; md: number }`.
- **`PARAGRAPH_SKELETON_LINES`** — Default skeleton line count (`2`).

## Usage Example

```typescript
import { LoadingParagraph } from './loading-paragraph';

function AuthErrorNotice({ errorDescription }: { errorDescription?: string }) {
  return (
    <LoadingParagraph
      text={errorDescription}
      label="Loading error details"
      type="h4"
      tone="secondary"
    />
  );
}

// Responsive line count example
function CveDescription({ description, isLoading }: { description?: string; isLoading: boolean }) {
  return (
    <LoadingParagraph
      text={description}
      loading={isLoading}
      lines={{ base: 3, md: 2 }}
      className="whitespace-pre-wrap"
    />
  );
}
```

Within a parent that sets a loading scope (via `useLoadingScope`'s provider), `LoadingParagraph` automatically renders its skeleton without needing an explicit `loading` prop.
