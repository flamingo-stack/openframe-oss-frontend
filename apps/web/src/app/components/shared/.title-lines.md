# title-lines.tsx

A React component that renders a record's title and an optional secondary line (subline), with built-in support for loading skeleton states. Commonly used to display paired name/detail information such as a script's name and description, a device's name and address, or a user's name and email.

## Key Components

- **`TitleLines`** — Main component rendering a title (h4, truncated) above an optional subline (h6, secondary tone). Automatically switches between skeleton bars (while loading) and real content.
- **`TitleLinesProps`** — Props interface controlling content (`title`, `subline`), loading behavior (`loading`, skeleton widths), subline rendering (`wrapSubline`, `sublineLines`, `emptySubline`), and styling (`className`, `titleClassName`, `titleAside`).

### Behavior notes
- Loading state is derived from `useLoadingScope()` OR the `loading` prop — either can trigger skeleton rendering.
- `emptySubline` controls whether an empty secondary line still reserves space:
  - `'mark'` (default): draws a muted empty mark (`EmptyValue`) when no subline exists, even while loading — use when every record in the list has this line.
  - `'none'`: draws nothing when subline is absent, and reserves no skeleton bar while loading either (since the final state is unknown).
- `wrapSubline` switches the subline from single-line truncation to a wrapping paragraph (useful for descriptions), with `sublineLines` controlling how many skeleton bars are drawn.
- `titleAside` renders supplementary content (e.g., role tags) next to the title once data has loaded.

## Usage Example

```typescript
import { TitleLines } from './title-lines';

function DeviceRow({ device, loading }: { device?: Device; loading: boolean }) {
  return (
    <TitleLines
      title={device?.name ?? ''}
      subline={device?.ipAddress}
      loading={loading}
      titleSkeletonWidth="w-40"
      sublineSkeletonWidth="w-56"
    />
  );
}

// Wrapping description example, only some records have one
function ScriptRow({ script, loading }: { script?: Script; loading: boolean }) {
  return (
    <TitleLines
      title={script?.name ?? ''}
      subline={script?.description}
      emptySubline="none"
      wrapSubline
      sublineLines={2}
      loading={loading}
      titleAside={<RoleTag role={script?.role} />}
    />
  );
}
```
