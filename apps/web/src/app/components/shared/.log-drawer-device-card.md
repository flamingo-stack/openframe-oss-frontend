# log-drawer-device-card.tsx

A client component that renders a compact device summary card inside the log drawer, linking a log entry to its associated device (when one exists).

## Key Components

- **`LogDrawerDeviceCard`** — internal component that fetches device details via `useDeviceDetails` (polling disabled) and renders a `DeviceSummaryCard`. Renders `null` if the device fails to load after loading completes.
- **`logDrawerDeviceCard(deviceId, onNavigate)`** — exported factory function serving as the `deviceCard` slot for the `LogDrawer` component. Returns `undefined` when `deviceId` is missing or the literal string `"null"` (used for system events with no associated device), otherwise returns a `LogDrawerDeviceCard` element.

## Usage Example

```typescript
import { logDrawerDeviceCard } from './log-drawer-device-card';

function LogDrawer({ log, onClose }: { log: LogEntry; onClose: () => void }) {
  return (
    <div className="log-drawer">
      {/* ...log details... */}
      {logDrawerDeviceCard(log.deviceId, onClose)}
    </div>
  );
}
```

## Notes

- The `onNavigate` callback is expected to close the drawer. This matters because the card's "Details" button links to a `?id=` query parameter on the device detail page—if the drawer is already open on that same device's page, clicking "Details" would otherwise appear to do nothing, since the URL state doesn't visibly change the screen.
- `deviceId === 'null'` is treated as a valid "no device" sentinel (distinct from `undefined`), representing system events that explicitly carry no device association.
