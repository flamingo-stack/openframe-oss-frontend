# info-card-loading.ts

Provides shared loading-state helpers for `InfoCard` components, allowing cards to render a stable skeleton (real labels, placeholder value bars) while their underlying data is still being fetched.

## Key Components

- **`EMPTY_CARD`** — An `InfoCardData` constant with an empty `items` array. Used as the fallback data passed to an `InfoCard` while its record is loading, letting the card's skeleton rendering path take over instead of displaying stale or partial content.
- **`labelsOf(rows)`** — A helper function that extracts the `label` field from a list of row objects. Used to pre-populate skeleton rows with real labels while their corresponding values are rendered as placeholder bars, improving perceived layout stability during loading.

## Usage Example

```typescript
import { EMPTY_CARD, labelsOf } from './info-card-loading';
import type { InfoCardData } from '@flamingo-stack/openframe-frontend-core';

const deviceInfoRows = [
  { label: 'Hostname', value: 'device-01' },
  { label: 'OS', value: 'Ubuntu 22.04' },
  { label: 'Status', value: 'Online' },
];

// While fetching device data, render a skeleton with real labels
const isLoading = true;
const cardData: InfoCardData = isLoading ? EMPTY_CARD : { items: deviceInfoRows };

// Use labelsOf to drive skeleton row labels before data arrives
const skeletonLabels = labelsOf(deviceInfoRows);
// => ['Hostname', 'OS', 'Status']
```

This pattern is typically used in components like device tabs or the log details' "Full Information" card, where the label structure is known ahead of time even though the values must wait for the record to load.
