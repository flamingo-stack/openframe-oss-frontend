A global logout confirmation modal component, mounted once in `AppShell`, that reads its open/closed state from a Zustand store so any UI trigger can open it without prop drilling.

## Key Components

### `LogoutConfirmModal` (exported component)
Renders a destructive `ConfirmDialog` for signing out the current user. Key behaviors:

- **State management** — subscribes to `useLogoutConfirmStore` for `isOpen`/`setOpen`, decoupling triggers (Settings page, nav user menu, etc.) from the modal itself
- **`handleConfirm`** — calls `performLogout()`, which redirects on success; the pending spinner intentionally stays visible during navigation
- **Error handling** — on failure, resets `isPending` and surfaces the error via `useToast` + `handleApiError`

### Dependencies
| Import | Role |
|---|---|
| `useLogoutConfirmStore` | Zustand store controlling open state |
| `performLogout` | Auth action; redirects browser on success |
| `ConfirmDialog` | Shared confirm/cancel dialog primitive |
| `handleApiError` | Normalizes API errors into toast messages |

## Usage Example

```typescript
// Mounted once at the app shell level — no props required
function AppShell({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <LogoutConfirmModal />
    </>
  );
}

// Any trigger opens it via the store
import { useLogoutConfirmStore } from '@/app/(auth)/auth/stores/logout-confirm-store';

function LogoutButton() {
  const setOpen = useLogoutConfirmStore(state => state.setOpen);
  return <button onClick={() => setOpen(true)}>Log Out</button>;
}
```
