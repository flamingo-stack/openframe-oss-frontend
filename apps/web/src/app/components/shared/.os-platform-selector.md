A client-side React component that renders an OS platform selection UI using a tab-based selector, mapping OS platform types to interactive tabs with icons and optional status badges.

## Key Components

### Interfaces

- **`PlatformSelectorOption`** — Defines a selectable platform entry with an `OSPlatformId`, optional `disabled` state, and an optional `badge` with text and color scheme.
- **`OsPlatformSelectorProps`** — Component props including the controlled `value`, `onValueChange` callback, optional `options` array, `disabledPlatforms` list, display `variant`, and `iconSize`.

### Component

- **`OsPlatformSelector`** — Renders a `TabSelector` populated with OS platform tabs. Automatically derives all available platforms from `OS_TYPES` if no explicit `options` are provided. Each tab includes the platform's icon (with active-state coloring for `primary` variant) and an optional `StatusBadge`.

## Usage Example

```typescript
import { OsPlatformSelector } from './os-platform-selector';
import type { OSPlatformId } from '@flamingo-stack/openframe-frontend-core/utils';

// Basic usage — all platforms auto-populated
<OsPlatformSelector
  value={selectedPlatform}
  onValueChange={(platform: OSPlatformId) => setSelectedPlatform(platform)}
/>

// Custom options with a badge and disabled platform
<OsPlatformSelector
  value={selectedPlatform}
  onValueChange={setSelectedPlatform}
  variant="secondary"
  disabledPlatforms={['linux']}
  options={[
    { platformId: 'windows' },
    { platformId: 'macos', badge: { text: 'Beta', colorScheme: 'yellow' } },
    { platformId: 'linux', disabled: true },
  ]}
  label="Target OS"
  iconSize="w-4 h-4"
/>
```
