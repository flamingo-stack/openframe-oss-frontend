A small, reusable button component that renders a trailing "open in new tab/row" (↗) affordance within a table row, while respecting any active loading scope and preventing conflicts with the row's own click handler.

## Key Components

- **`OpenRowButtonProps`** — Props interface:
  - `label`: accessible name describing what will open and where.
  - `onClick`: click handler invoked with the `MouseEvent`.
  - `disabled`: optional flag to render the button inert (no handler, disabled state) when there's nothing to open.
- **`OpenRowButton`** — Functional component that:
  - Uses `useLoadingScope()` to detect if the row is currently in a loading state.
  - Combines `loading` and `disabled` into a single `inert` flag, disabling the button and stripping its `onClick` when true.
  - Wraps the button in a `div` with `data-no-row-click` to prevent the row's own click/link behavior from firing when this button is clicked.
  - Renders an outlined icon-only `Button` with `ArrowRightUpIcon`, using a dynamic `aria-label` ("Open in new tab" while loading, otherwise the provided `label`).

## Usage Example

```typescript
import { OpenRowButton } from './open-row-button';

function DeviceTableRow({ device }: { device: Device }) {
  const handleOpen = (event: React.MouseEvent<HTMLButtonElement>) => {
    event.stopPropagation();
    router.push(`/devices/${device.id}`);
  };

  return (
    <tr>
      <td>{device.name}</td>
      <td>
        <OpenRowButton
          label={`Open ${device.name} details`}
          onClick={handleOpen}
          disabled={!device.id}
        />
      </td>
    </tr>
  );
}
```

**Notes:**
- Place this component inside table rows or list items where clicking the row navigates somewhere, but you want an explicit affordance button that doesn't double-trigger the row's own click behavior.
- The `data-no-row-click` attribute must be respected by the parent row's click handler (typically by checking `event.target.closest('[data-no-row-click]')` before navigating).
