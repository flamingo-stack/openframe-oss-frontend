# info-cell.tsx

A reusable presentational component that renders a labeled value cell (primary value + secondary label) following ODS typography tokens, commonly used in detail/info card layouts. It supports loading-state skeletons, optional icons, empty-value handling, and optional external link wrapping.

## Key Components

- **`InfoCellProps`** — Props interface defining `value`, `label`, `icon`, `iconSkeleton`, `href`, `className`, `loading`, `skeletonWidth`, `valueSkeleton`, and `labelSkeletonWidth`.
- **`InfoCell`** — Functional component that:
  - Detects loading state via `useLoadingScope()` or the `loading` prop.
  - Determines if `value` is text/number/empty (rendered via `ValueText`) or a non-text node (e.g., a self-skeletoning status tag) rendered as-is.
  - Renders an icon or an `iconSkeleton` placeholder (`MediaSkeleton.Icon`) while loading.
  - Renders the `label` normally, or as a `TextLineSkeleton` when `labelSkeletonWidth` is provided during loading.
  - Wraps the cell in an `<a>` tag when `href` is provided and not loading.

## Usage Example

```typescript
import { InfoCell } from './info-cell';

// Basic text value
<InfoCell value="workstation-23.acme.local" label="Hostname" />

// With icon and link
<InfoCell
  value="example.com"
  label="Website"
  icon={<GlobeIcon />}
  href="https://example.com"
/>

// Loading state with icon skeleton and label skeleton
<InfoCell
  value={undefined}
  label="Updated"
  loading
  iconSkeleton={{ size: 'md' }}
  labelSkeletonWidth="w-20"
/>

// Non-text value that self-manages its own skeleton (e.g., status badge)
<InfoCell
  value={<StatusTag status={status} />}
  label="Status"
  valueSkeleton={<StatusTag />}
/>
```

Callers should always render `InfoCell` directly rather than duplicating its internal layout, ensuring consistent loading and empty-state behavior across the app.
