A reusable display cell component that renders a primary value alongside a secondary label, designed for detail/info card layouts using ODS typography tokens (`text-h4`/`text-h6`).

## Key Components

### `InfoCellProps`

| Prop | Type | Description |
|---|---|---|
| `value` | `React.ReactNode` | Primary display value (string or JSX) |
| `label` | `string` | Secondary descriptive label rendered below the value |
| `icon` | `React.ReactNode` | Optional leading icon rendered inline with the value |
| `href` | `string` | When provided, wraps the entire cell in an external `<a>` link |
| `className` | `string` | Additional CSS classes applied to the root container |
| `loading` | `boolean` | Draw the value as a bar (a loading scope does the same) |
| `skeletonWidth` | `string` | The value bar's width while loading |
| `iconSkeleton` | `{ size?, className? }` | The box a plain `icon` is replaced by while loading, so callers pass only the real icon |
| `valueSkeleton` | `React.ReactNode` | A non-text value's loading form (the real component with no data) |
| `labelSkeletonWidth` | `string` | When the label is read too: its bar width while loading |

### `InfoCell`

Renders a vertically stacked cell with truncation support. If `href` is provided, the cell becomes a full external link with hover opacity. Text values (strings, numbers, missing values) are drawn by the shared `ValueText`: truncated with a tooltip, the muted empty mark when missing, and a bar while loading.

## Usage Example

```typescript
// Basic text cell
<InfoCell value="workstation-23.acme.local" label="Hostname" />

// With an icon
<InfoCell value="Laptop" label="Type" icon={<LaptopIcon />} />

// Mixed JSX value
<InfoCell
  value={<>{date} <span className="text-muted">{time}</span></>}
  label="Last Updated"
/>

// Clickable external link cell
<InfoCell
  value="example.com"
  label="Website"
  href="https://example.com"
/>
```
