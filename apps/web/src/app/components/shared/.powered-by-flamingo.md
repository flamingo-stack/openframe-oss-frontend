A client-side React component that renders the "Powered by Flamingo" branding footer shown across full-screen surfaces (setup wizard, auth status pages, error screens, account deletion flows).

## Key Components

- **`PoweredByFlamingo`** — Default-style functional component accepting an optional `className` prop. Renders the Flamingo mark (icon + "Powered by Flamingo" text) either as:
  - A plain `div` (non-interactive) when rendered inside the mobile shell (phone app), since store apps may not reliably link out to `flamingo.run`.
  - An anchor tag (`<a>`) linking to `https://flamingo.run` in a new tab, used everywhere else (web).
- Relies on `useIsMobileShell()` to detect the mobile shell context and `cn()` for conditional class merging.
- Uses `FlamingoMarkIcon` from `@flamingo-stack/openframe-frontend-core/components/icons-v2` for the brand mark.

## Usage Example

```typescript
import { PoweredByFlamingo } from '@/components/powered-by-flamingo';

export function SetupWizardFooter() {
  return (
    <footer className="flex justify-center py-4">
      <PoweredByFlamingo />
    </footer>
  );
}
```

```typescript
// With a custom className for layout adjustments
<PoweredByFlamingo className="mt-auto self-center" />
```

**Notes:**
- No conditional link rendering is needed by consumers — the component automatically determines whether to render a link or static mark based on the mobile shell context.
- Hover styling (`hover:bg-ods-bg-hover`) is suppressed in the mobile shell since there is no tappable link there.
- Designed for use only in full-screen, standalone surfaces rather than embedded within the main application layout.
