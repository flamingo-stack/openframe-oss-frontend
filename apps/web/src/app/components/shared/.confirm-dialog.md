# confirm-dialog.tsx

A shared confirmation dialog component for destructive and reversible actions, built on top of the `ModalV2*` primitives to maintain consistent responsive layout (centered on desktop, bottom-anchored on mobile) across the app.

The component supports three visual variants to communicate intent, a pending/loading state for async confirm actions, and an optional slot for extra content (e.g., a command box or picker) between the description and footer buttons. Notably, the dialog does **not** auto-close on confirm — the parent component controls the `open` state and should flip it to `false` once the confirm action settles, allowing the pending spinner to remain visible during async operations.

## Key Components

- **`ConfirmDialog`** — Main exported component rendering the confirmation modal with title, description, optional extra content, and Cancel/Confirm buttons.
- **`ConfirmDialogProps`** — Props interface defining `open`, `onOpenChange`, `title`, `description`, `variant`, `isPending`, `onConfirm`, `confirmLabel`/`cancelLabel`, and `extraContent`.
- **`CONFIRM_VARIANT`** — Internal mapping from dialog `variant` (`destructive` | `warning` | `default`) to the corresponding core `Button` variant (`destructive` | `warning` | `accent`), derived directly from `Button`'s own variant type to avoid drift.

## Usage Example

```typescript
import { useState } from 'react';
import { ConfirmDialog } from './confirm-dialog';

function DeleteUserButton({ userId }: { userId: string }) {
  const [open, setOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleConfirm = async () => {
    setIsPending(true);
    try {
      await deleteUser(userId);
    } finally {
      setIsPending(false);
      setOpen(false); // Parent controls closing after mutation settles
    }
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Delete User</button>
      <ConfirmDialog
        open={open}
        onOpenChange={setOpen}
        title="Delete this user?"
        description="This action cannot be undone."
        variant="destructive"
        confirmLabel="Delete"
        isPending={isPending}
        onConfirm={handleConfirm}
      />
    </>
  );
}
```
