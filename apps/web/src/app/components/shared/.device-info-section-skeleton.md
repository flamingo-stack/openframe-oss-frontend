Renders a loading skeleton that mirrors the layout of the `DeviceInfoSection` component's inline `DeviceCard`, providing a placeholder UI while device data is being fetched.

## Key Components

- **`DeviceInfoSectionSkeleton`** — Client component that renders animated skeleton elements matching the two-row `DeviceCard` structure:
  - **Row 1:** Icon box, OS icon + device name + org name, and a "Details" button placeholder
  - **Row 2:** Status tag and "Last Seen" text placeholders

## Usage Example

```typescript
import { DeviceInfoSectionSkeleton } from './device-info-section-skeleton';

// Use as a Suspense fallback or conditional loading placeholder
function DevicePanel({ isLoading, device }) {
  if (isLoading) {
    return <DeviceInfoSectionSkeleton />;
  }
  return <DeviceInfoSection device={device} />;
}
```

## Notes

- Marked `'use client'` — must run in a browser context.
- Layout dimensions are intentionally matched to `DeviceInfoSection` to prevent [layout shift](https://web.dev/cls/) when real content loads. The card enforces a `min-h-[130px]` to hold vertical space.
- Uses `Skeleton` from `@flamingo-stack/openframe-frontend-core` — see the [source file](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/device-info-section-skeleton.tsx) for exact sizing tokens.
