# notes-section.tsx

A React client component that renders a "Notes" section with inline add/edit/delete functionality, author attribution, and loading-state support. It is designed to be embedded in record detail views (e.g., ticket, device, or client pages) where contextual notes need to be displayed and managed.

## Key Components

- **`NoteItem`** — Interface describing a single note (`id`, `text`, `authorName`, `authorAvatar`, `createdAt`, `isOwn`).
- **`NotesSection`** — Main exported component. Renders the list of notes, an inline note editor, an "Add Note" button, and a delete confirmation dialog. Supports an external `loading` prop as well as an ambient loading scope via `useLoadingScope`.
- **`NoteEditor`** (internal) — Textarea-based editor used for both creating and editing notes, with save/cancel actions and `Escape`-to-cancel keyboard support.
- **`NoteCard`** (internal) — Displays a single note with avatar, author name, formatted timestamp, and (for owned notes) an actions dropdown menu for edit/delete.
- **`NotesSectionFrame`** (internal) — Shared layout shell rendering the "Notes" heading above the section content.
- **`AddNoteButton`** (internal) — Reusable button that toggles the add-note editor.

## Usage Example

```typescript
import { NotesSection, type NoteItem } from '@/components/notes-section';

const notes: NoteItem[] = [
  {
    id: '1',
    text: 'Customer requested a callback tomorrow.',
    authorName: 'Jane Doe',
    createdAt: '2024-05-01T10:00:00Z',
    isOwn: true,
  },
];

function TicketNotes() {
  const [isAdding, setIsAdding] = useState(false);

  return (
    <NotesSection
      notes={notes}
      isAddingNote={isAdding}
      onAddNote={(text) => {
        setIsAdding(true);
        // call API to create note, then update state
      }}
      onEditNote={(id, text) => {
        // call API to update note
      }}
      onDeleteNote={(id) => {
        // call API to delete note (confirmation already handled)
      }}
      loading={false}
    />
  );
}
```

Note deletion is confirmed internally via `ConfirmDialog` before `onDeleteNote` is invoked, so callers can perform the deletion directly without re-confirming.
