Provides a CSS class string that removes the top padding added by a frozen `TitleBlock` component, allowing page layouts embedded inside tabs to sit flush under the tab bar.

## Key Components

- **`EMBEDDED_PAGE_OFFSET`** — Exported string constant containing the Tailwind CSS class `-mt-[var(--spacing-system-l)]`

## Usage Example

```typescript
import { EMBEDDED_PAGE_OFFSET } from './embedded-page';

// Apply to PageLayout when rendering a shared page inside a tab
<PageLayout className={EMBEDDED_PAGE_OFFSET}>
  {/* Page content sits flush under the tab bar */}
</PageLayout>
```

## Notes

- Only apply when the page is embedded inside a tab component — the offset cancels the `pt-[var(--spacing-system-l)]` that `TitleBlock` adds at the top
- The `TitleBlock`'s bottom margin (`mb-l`) between the title and content is **not** affected
