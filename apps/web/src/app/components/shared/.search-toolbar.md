A sticky search toolbar component rendered above list/table pages, providing a search input with an icon and an optional slot for extra actions (e.g., filter buttons on mobile).

## Key Components

- **`SearchToolbarProps`** — Props interface:
  - `toolbarRef`: a ref callback (typically from `useStickyToolbar`) used to measure the toolbar for syncing with the table's sticky header.
  - `placeholder`: placeholder text for the search input.
  - `value` / `onChange`: controlled input state.
  - `disabled`: optional flag to lock the input while the underlying list/data isn't ready for searching.
  - `actions`: optional `ReactNode` rendered beside the input (e.g., a mobile filter button, since column filters are hidden below the `content-md` breakpoint).
- **`SearchToolbar`** — Functional component rendering a sticky container (`position: sticky`, `top-0`) with a search `Input` (prefixed by `SearchIcon`) and the optional `actions` slot.

## Usage Example

```typescript
import { useState } from 'react';
import { SearchToolbar } from './search-toolbar';
import { useStickyToolbar } from './use-sticky-toolbar';

function DevicesListPage() {
  const [search, setSearch] = useState('');
  const { toolbarRef } = useStickyToolbar();

  return (
    <>
      <SearchToolbar
        toolbarRef={toolbarRef}
        placeholder="Search devices..."
        value={search}
        onChange={setSearch}
        actions={<FilterButton />}
      />
      {/* table component uses the same sticky measurement */}
    </>
  );
}
```

Pair `toolbarRef` with the corresponding `useStickyToolbar` hook so the table's sticky header offset accounts for this toolbar's height. Set `disabled` while initial data is loading to prevent premature searches.
