# use-row-dialog.ts

A React hook for managing a single row-scoped dialog's state within a table component, keeping dialog ownership at the table level rather than tying it to individual row data that may be deleted or archived.

## Key Components

- **`RowDialog<TRow, TKind>`** — Internal interface describing the dialog state: the associated `row`, a `kind` discriminator (e.g., `"delete"`, `"edit"`), and an `isOpen` flag.
- **`useRowDialog<TRow, TKind>()`** — Generic hook that returns:
  - `dialog` — The current `RowDialog` state, or `null` if no dialog has ever been opened.
  - `open(row, kind)` — Opens a dialog for the given row and kind.
  - `close()` — Marks the dialog as closed (`isOpen: false`) without clearing `row`/`kind`, so exit animations can still render the dialog's content.

This design decouples the dialog's lifecycle from the row's lifecycle: since a row is just a reference, actions like archive/delete can remove the row from the table's data while the dialog is still animating closed, without losing the content needed for that animation.

## Usage Example

```typescript
import { useRowDialog } from './use-row-dialog';

type DialogKind = 'delete' | 'archive';

interface User {
  id: string;
  name: string;
}

function UserTable({ users }: { users: User[] }) {
  const { dialog, open, close } = useRowDialog<User, DialogKind>();

  return (
    <>
      {users.map(user => (
        <button key={user.id} onClick={() => open(user, 'delete')}>
          Delete {user.name}
        </button>
      ))}

      {dialog && (
        <ConfirmDialog
          isOpen={dialog.isOpen}
          title={`Confirm ${dialog.kind}`}
          onConfirm={async () => {
            await deleteUser(dialog.row.id);
            close();
          }}
          onClose={close}
        />
      )}
    </>
  );
}
```
