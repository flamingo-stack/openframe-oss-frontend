# tag-filter-bar.tsx

A shared React component that combines a searchable tag input with removable selected-tag chips and a one-click row of available tags below it. Used to provide consistent tag filtering UI across different consumers (e.g., scripts, tickets).

## Key Components

- **`TagFilterBar`** — Main exported component rendering a fragment of two rows: a search input (`TagSearchInput`) with selected-tag chips, and an optional `SelectableTagsRow` for quick one-click tag selection.
- **`TagFilterBarProps`** — Props interface controlling tags, search state, selection state, loading behavior, and optional slots (`filterButton`, `selectedTags`).

### Behavior highlights
- Derives selected-tag chip labels from `tags` + `selectedIds` by default, but accepts an explicit `selectedTags` override for cases where selections may reference tags outside the current `tags` list (e.g., folder-scoped sources).
- Uses `useLoadingScope()` combined with the `loading` prop to determine loading state; while loading, unresolved chip labels render as a `TextLineSkeleton` instead of a raw id.
- `showRow` toggles visibility of the `SelectableTagsRow` (useful for hiding it on mobile).
- `filterButton` renders an optional element (e.g., a mobile "open filters" trigger) next to the search input.
- Data fetching is intentionally left to the caller — this component is purely presentational/controlled.

## Usage Example

```typescript
import { TagFilterBar } from './tag-filter-bar';
import { useState } from 'react';

function ScriptsTagFilter({ tags }: { tags: SelectableTag[] }) {
  const [search, setSearch] = useState('');
  const [selectedIds, setSelectedIds] = useState<string[]>([]);

  return (
    <div className="flex flex-col gap-[var(--spacing-system-xxs)]">
      <TagFilterBar
        tags={tags}
        search={search}
        onSearchChange={setSearch}
        selectedIds={selectedIds}
        onSelectedIdsChange={setSelectedIds}
        placeholder="Filter by tag..."
        loading={false}
      />
    </div>
  );
}
```

Wrap the component in a `flex flex-col` container with `--spacing-system-xxs` gap so the search row and tag row align consistently across consumers.
