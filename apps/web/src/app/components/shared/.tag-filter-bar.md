A composite filter UI component that combines a tag-aware search input with a one-click selectable tag row, used for filtering lists (scripts, tickets, etc.) by tags across the OpenFrame frontend.

## Key Components

### `TagFilterBar`
The primary export. Renders two rows as a fragment:
1. A `TagSearchInput` that displays selected tags as removable chips alongside a text search field
2. A `SelectableTagsRow` (drawing its own loading state) showing available tags for quick selection

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `tags` | `ReadonlyArray<SelectableTag>` | Available tags for display and selection |
| `search` / `onSearchChange` | `string` / callback | Controlled text search state |
| `selectedIds` / `onSelectedIdsChange` | `string[]` / callback | Controlled selected tag IDs |
| `placeholder` | `string` | Input placeholder text |
| `selectedTags` | `TagSearchOption<string>[]` | Override chip derivation (e.g. folder-scoped sources) |
| `loading` | `boolean` | The tags are not read yet: the tag row draws its loading state and unknown selected chips are bars |
| `showRow` | `boolean` | Hides the tag row (e.g. on mobile); defaults to `true` |
| `filterButton` | `ReactNode` | Optional element alongside the search input |

## Usage Example

```typescript
<div className="flex flex-col gap-[--spacing-system-xxs]">
  <TagFilterBar
    tags={availableTags}
    search={searchQuery}
    onSearchChange={setSearchQuery}
    selectedIds={selectedTagIds}
    onSelectedIdsChange={setSelectedTagIds}
    placeholder="Search scripts..."
    loading={isLoading}
    showRow={!isMobile}
    filterButton={<MobileFilterButton onClick={openFilterSheet} />}
  />
</div>
```

> **Layout note:** Wrap in a `flex flex-col` container with `gap-[--spacing-system-xxs]` — the component returns a fragment with no outer wrapper.
