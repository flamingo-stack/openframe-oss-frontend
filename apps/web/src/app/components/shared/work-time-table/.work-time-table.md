## work-time-table.tsx

A client-side React component that renders a time-tracking table showing employee work time entries, with stat cards (today/period totals, average per day), filtering by employee/customer/date range, search, and inline edit/delete actions. It integrates with Relay for paginated GraphQL data fetching and live updates via subscriptions.

## Key Components

- **`WorkTimeStats`** — interface describing the stat figures (today/period totals, entry counts, daily average) returned by the query.
- **`STAT_CARDS`** — static config array defining the three summary cards (TODAY TOTAL, PERIOD TOTAL, AVG. PER DAY) and how to extract their values from `WorkTimeStats`.
- **`WorkTimeRow`** / **`WorkTimeFilter`** / **`QueryVars`** — typed shapes for table rows, server-side filters, and query variables (search, pagination, date range, employee/org ids).
- **`EmployeeCell`**, **`TimeCell`**, **`CustomerCell`**, **`TicketNotesCell`**, **`EntryActionsCell`** — per-column cell renderers that support skeleton/loading states via `useLoadingScope`, handle deleted-user display, and format duration/dates.
- **`employeeColumn`**, **`timeColumn`**, **`customerColumn`**, **`ticketNotesColumn`** — `ColumnDef` definitions for the `LiveTable`/data-table.
- **`buildColumns(...)`** — assembles the final column list, conditionally including employee/customer columns and attaching filter options, plus an actions column for edit/delete.
- **`mapUserName(...)`** — helper to derive a display name from a user's first/last name or fallback fields.
- **`formatDayParam` / `rangeFromParams`** — helpers to serialize/parse date-range URL search params (`yyyy-MM-dd` format).

This file is primarily a supporting module for a larger `WorkTimeTable` page/component (built on `useLazyLoadQuery`, `usePaginationFragment`, and `useMutation` from `react-relay`) that renders the full table, filters, pagination, and modals (`ManualEntryModal`, `ConfirmDialog`) for creating/editing/deleting time entries.

## Usage Example

```typescript
import { employeeWorkTimeRelayQuery } from '@/graphql/time-tracker/employee-work-time-relay';
import { useLazyLoadQuery } from 'react-relay';

function WorkTimeTablePage() {
  const data = useLazyLoadQuery<EmployeeWorkTimeRelayQueryType>(
    employeeWorkTimeRelayQuery,
    {
      filter: { employeeIds: null, organizationIds: null, startedFrom: null, startedTo: null },
      search: null,
      first: 20,
      after: null,
    },
  );

  // Pass fragment ref into a component using usePaginationFragment
  // and render columns via buildColumns(showEmployee, showCustomer, onEdit, onDelete)
  return <LiveTable data={data} /* ...props */ />;
}
```
