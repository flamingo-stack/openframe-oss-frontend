# billing-call-back.tsx

Renders the "Call Me Back" tab within the Contact Support modal, letting a signed-in user schedule a billing-related call via a specific, hard-coded HubSpot scheduling link. It resolves the correct link from the list of available scheduling links, shows a loading state while fetching, and confirms the booking with a toast before closing the modal.

## Key Components

- **`BILLING_MEETING_PATH`** — The fixed path (`/conrad-lunderstedt/openframe-support`) identifying the billing scheduling link. There is intentionally no fallback link, since booking on the wrong calendar would misroute the call.
- **`isBillingLink(link)`** — Predicate that checks whether a `SchedulingLink`'s URL path matches `BILLING_MEETING_PATH`.
- **`useBillingMeetingLink()`** — Hook built on `useSchedulingLinks` that flattens all purpose groups and returns the matching billing link plus a loading flag.
- **`BillingCallBack({ onDone })`** — Exported component that renders the `HubSpotMeetingScheduler` in `modal` layout, using `SignedInBookingForm` for contact details, and handles success/empty/loading states.

## Usage Example

```typescript
import { BillingCallBack } from '@/app/components/.../billing-call-back';

function SupportModalTabs({ closeModal }: { closeModal: () => void }) {
  return (
    <SupportTab label="Call Me Back">
      <BillingCallBack onDone={closeModal} />
    </SupportTab>
  );
}
```

**Behavior notes:**
- If no billing link is found (and loading has finished), it renders a plain message instead of the scheduler.
- While the link is resolving, `LoadingWhen` displays a loading state.
- `onBack` is wired to `onDone`, mimicking a phone call's "Cancel" button rather than a modal close (`X`).
- On successful booking, a success toast is shown with the formatted date/time (via `formatDateWithTimezone` and `VIEWER_TIMEZONE`), then `onDone()` is invoked to close the flow.
