Barrel export file that re-exports all shared UI components, types, and utilities from the OpenFrame frontend component library, providing a single unified entry point for consumers.

## Key Components

| Export | Type | Description |
|---|---|---|
| `DeviceInfoSection` | Component | Displays detailed device information |
| `DeviceSelector` | Component | Device selection with infinite scroll support |
| `DevicesFilterToolbar` | Component | Toolbar for filtering device lists |
| `DevicesPanel` | Component | Full panel view for device management |
| `EmptyState` | Component | Empty/zero-state placeholder UI |
| `LogDrawer` | Component | Drawer for viewing log entries |
| `OrgAvatar` | Component | Organization avatar display |
| `PoliciesTable` | Component | Table for displaying policy data |
| `QueriesTable` | Component | Table for displaying query data with interval formatting |
| `SelectableTagsRow` | Component | Row of selectable tag elements |
| `TagFilterBar` | Component | Filter bar based on tags |
| `*` from `./tags` | Multiple | All tag-related exports |
| Skeleton components | Components | `InfoCardSkeleton`, `ListPageSkeleton`, `SearchBarSkeleton`, `TabBarSkeleton`, `TableSkeleton` |
| `EMBEDDED_PAGE_OFFSET` | Constant | Offset value for embedded page layouts |
| `onboardingGuideButton` | Utility | Factory/helper for onboarding guide buttons |

## Usage Example

```typescript
import {
  DeviceSelector,
  DevicesPanel,
  PoliciesTable,
  QueriesTable,
  TagFilterBar,
  EmptyState,
  TableSkeleton,
  formatQueryInterval,
} from '@/components'; // or wherever this barrel is aliased

// Use components directly in your views/pages
<DevicesPanel />
<PoliciesTable rows={rows} />
<TagFilterBar />

// Use the query interval formatter
const label = formatQueryInterval(3600); // e.g. "1 hour"
```
