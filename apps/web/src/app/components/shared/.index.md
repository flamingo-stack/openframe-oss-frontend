# index.ts

Barrel export file that aggregates and re-exports shared UI components, hooks, types, and utilities used across the application's shared component library. It centralizes imports so consumers can import from a single module path rather than referencing individual files.

## Key Components

- **Error Handling**: `ContentErrorBoundary`, `useRetryKey`, `SectionLoadError`, `HydratorBoundary`
- **CVE/Security**: `CVE_SEVERITY`, `CVE_SEVERITY_BANDS`, `cveSeverityRank`, `resolveCveSeverity`, `CveSeverityTag`
- **Table/Grid Helpers**: `DateColumnHeader`, `TableDateFilter`, `liveColumnMeta`, `TableSkeletonColumn`, `QueriesTable`, `QueryTableAction`, `QueryTableRow`, `formatQueryInterval`
- **Data Display**: `CustomerInfoCell`, `DateWithAge`, `EmptyValue`, `ValueText`, `OrgAvatar`, `PolicyValueCard`
- **Layout & Loading**: `DETAIL_CELL_CLASS`, `LoadingLine`, `EMPTY_CARD`, `labelsOf`, `EmptyState`, `oneLineEmptyState`
- **Devices & Notes**: `DeviceInfoSection`, `DevicesPanel`, `NotesSection`, `NoteItem`
- **Navigation/Filtering**: `SelectableTagsRow`, `TagFilterBar`, `onboardingGuideButton`
- **Pagination**: `EMBEDDED_PAGE_OFFSET`, `NO_ITEMS`, `NO_NEXT_PAGE`, `noop`, `InfiniteScroll`
- **Query Utilities**: `QueryIsland`
- **Misc**: `TitleLines`, `tags` (wildcard export)

This barrel pattern simplifies imports throughout the codebase—consumers reference one path (e.g., `@/components/shared`) instead of deep-linking into individual component files, improving maintainability when internal file structure changes.
