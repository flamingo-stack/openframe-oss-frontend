Barrel export file that re-exports the app's shared UI components, types, and utilities, providing a single entry point (`@/app/components/shared`) for consumers. A few modules are imported by path instead (`live-table`, `device-selector`, `log-drawer-device-card`).

## Key Components

| Export | Type | Description |
|---|---|---|
| `ContentErrorBoundary` / `useRetryKey` | Component / Hook | The section error boundary, and the key a query re-reads with after a retry |
| `CveSeverityTag` / `CVE_SEVERITY` / `resolveCveSeverity` | Component / Utilities | A CVE's severity, its bands and ranking |
| `CustomerInfoCell` / `DateColumnHeader` / `DateWithAge` | Components | Shared table cells and the date column's header filter |
| `DeviceInfoSection` | Component | The device a log or ticket names, as its card; always drawn (the empty mark when there is none) |
| `DevicesPanel` | Component | The device list (Devices page, archive, customer devices tab) |
| `EmptyState` / `EmptyValue` | Components | Empty/zero-state placeholder, and the muted empty mark |
| `GatedSuspense` | Component | The one gated Suspense: the same view in a loading scope while a page gate holds the query, then the boundary (`bare` draws the scope only) |
| `LoadingLine` | Component | One line of text that draws its own bar while loading |
| `NotesSection` | Component | A record's notes list and composer |
| `OrgAvatar` | Component | Organization avatar display |
| `PolicyValueCard` | Component | A policy's value as a card |
| `QueryIsland` / `HydratorBoundary` | Components | Query and hydration boundaries |
| `QueriesTable` / `formatQueryInterval` | Component / Utility | Table for query data (`pageSize` for a paged list, `skeletonRows` for one read whole) and its interval formatter |
| `SectionLoadError` | Component | A section's load failure with retry |
| `SelectableTagsRow` / `TagFilterBar` / `*` from `./tags` | Components | Tag rows, filter bar and every tag-related export |
| `TitleLines` / `ValueText` | Components | Text that draws its own skeleton while loading |
| `liveColumnMeta` / `TableSkeletonColumn` | Utility / Type | A live table column's layout, shared by its loading form |
| `noop` / `NO_NEXT_PAGE` / `NO_ITEMS` / `InfiniteScroll` | Utilities | The one no-op callback, the infinite scroll of a list with no rows yet (and its type), and the one empty item list |
| `EMPTY_CARD` / `labelsOf` | Utilities | What an `InfoCard` is handed while its record is read, and a card's row labels drawn real in its skeleton |
| `DETAIL_CELL_CLASS` / `EMBEDDED_PAGE_OFFSET` | Constants | Shared layout classes and the embedded page offset |
| `onboardingGuideButton` | Utility | Factory/helper for onboarding guide buttons |

`live-table.tsx` (imported by path) holds `LiveTable` (every live list's table: `pageSize` for a paged list, `skeletonRows` for a list read whole), `PendingDim` (the one refetch dim) and `LIVE_ROW_GAP_CLASS` (the one row gap).

## Usage Example

```typescript
import { DevicesPanel, NO_ITEMS, QueriesTable, TagFilterBar, formatQueryInterval } from '@/app/components/shared';
import { LiveTable, LIVE_ROW_GAP_CLASS } from '@/app/components/shared/live-table';

<DevicesPanel />
<QueriesTable rows={rows} skeletonRows={QUERIES_SKELETON_ROWS} />
<TagFilterBar />

const label = formatQueryInterval(3600); // "Every 1h"
```
