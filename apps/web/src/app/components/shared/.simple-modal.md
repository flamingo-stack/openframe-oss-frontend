A slot-based modal wrapper over the `ModalV2*` primitives from `@flamingo-stack/openframe-frontend-core`, rendering header, content, and footer sections conditionally based on supplied props.

## Key Components

**`SimpleModal`** — The sole export. Accepts the following props:

| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Called when the modal requests dismissal |
| `title` | `ReactNode` | Convenience prop — wrapped in `ModalV2Header` + `ModalV2Title` |
| `header` | `ReactNode` | Custom header node — overrides `title` when provided |
| `children` | `ReactNode` | Modal body content |
| `contentClassName` | `string` | When set, wraps `children` in `ModalV2Content` for scrollable overflow |
| `footer` | `ReactNode` | Rendered inside `ModalV2Footer` (typically action buttons) |
| `className` | `string` | Passed to the outer `ModalV2` (e.g. `md:max-w-[600px]`) |

**Section rendering logic:**
- `header` takes priority over `title`; if neither is provided, no header is rendered
- `contentClassName` opts children into a scrollable `ModalV2Content` wrapper; omit it for short modals where children flow directly in the flex column
- `footer` is omitted entirely when not passed

> For confirm/destructive flows, prefer `<ConfirmDialog>`, which wraps `SimpleModal` with built-in variant button styling and pending state.

## Usage Example

```typescript
// Basic titled modal
<SimpleModal isOpen={isOpen} onClose={() => setIsOpen(false)} title="Edit Settings">
  <p>Modal body content here.</p>
</SimpleModal>

// Scrollable content with footer actions
<SimpleModal
  isOpen={isOpen}
  onClose={onClose}
  title="Large Form"
  contentClassName="p-4"
  className="md:max-w-[600px]"
  footer={
    <>
      <button onClick={onClose}>Cancel</button>
      <button onClick={handleSave}>Save</button>
    </>
  }
>
  <LargeFormContent />
</SimpleModal>

// Fully custom header
<SimpleModal
  isOpen={isOpen}
  onClose={onClose}
  header={<CustomHeaderWithIcon />}
>
  <p>Body content.</p>
</SimpleModal>
```
