Registers embed shims on the client side by invoking `registerEmbedShims()` at module load time and exporting a no-op React component for use in the component tree.

## Key Components

- **`registerEmbedShims()` call** — Side-effectful invocation at module scope that sets up embed shims immediately when this module is loaded on the client
- **`EmbedShimRegistration`** — A render-less React component (`returns null`) that serves as a mount point to guarantee this module is included in the client bundle

## Usage Example

```typescript
// app/layout.tsx
import { EmbedShimRegistration } from '@/components/embed-shim-registration';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <EmbedShimRegistration />
        {children}
      </body>
    </html>
  );
}
```

## Notes

- The `'use client'` directive ensures shim registration only runs in the browser environment, not during SSR
- The actual shim logic lives in [`@/lib/register-embed-shims`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/lib/register-embed-shims.ts)
- The component itself has no rendering output; its value is purely the side effect triggered at import time
