# manhattan-compact-bar.tsx

Renders the Manhattan v2 "compact" top bar, shown when the layout's two side rails plus the centre's fixed 800px width no longer fit the viewport. It consolidates access to chats (Mingo) and navigation into two drawer-triggering buttons flanking the OpenFrame logo, mirroring the ordering used by the mobile top bar.

## Key Components

- **`ManhattanCompactBar`** — The main component. Renders a horizontal bar (visible from `md` breakpoint only) with:
  - A `HeaderMingoButton` on the left (icon-only) that opens the chats drawer, optionally disabled behind a paywall.
  - A centered OpenFrame logo + wordmark.
  - A menu button on the right that opens the navigation drawer.
- **`ManhattanCompactBarProps`** — Props interface:
  - `onOpenChats: () => void` — callback to open the chats sidebar as an overlay.
  - `onOpenNavigation: () => void` — callback to open the navigation as an overlay.
  - `chatsDisabled?: boolean` — disables the chats entry point (navigation remains reachable).
- **`BAR_BUTTON_CLASS`** — Shared Tailwind class string for glyph-style bar buttons, matching sidebar footer button styling (hover/active/disabled/focus states).

## Usage Example

```typescript
import { ManhattanCompactBar } from './manhattan-compact-bar';
import { useState } from 'react';

function ManhattanLayout({ isPaidPlan }: { isPaidPlan: boolean }) {
  const [chatsOpen, setChatsOpen] = useState(false);
  const [navOpen, setNavOpen] = useState(false);

  return (
    <>
      <ManhattanCompactBar
        onOpenChats={() => setChatsOpen(true)}
        onOpenNavigation={() => setNavOpen(true)}
        chatsDisabled={!isPaidPlan}
      />
      {/* Drawer overlays for chats and navigation go here */}
    </>
  );
}
```

This component is intended to be used within the Manhattan v2 layout's "squeeze" logic, rendered only in the `compact` state where rails and centre content can't coexist at full width.
