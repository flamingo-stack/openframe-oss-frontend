# use-manhattan-squeeze.ts

A React hook that determines whether the "Manhattan" (v2) shell layout should render in a compact form based on the current window width, using `useSyncExternalStore` to react to resize events without unnecessary re-renders.

The layout reserves two sidebar rails (56px each) plus a minimum centre width of 800px. When the window is wide enough for the tablet breakpoint (800px) but narrower than the combined rail+centre width, the layout switches to a "compact" mode where sidebars collapse into drawers and the v2 top bar takes over. Below the tablet breakpoint, the phone shell is used instead (not handled here), and above the compact threshold, sidebars remain as the user left them, with content scrolling horizontally instead of folding.

## Key Components

- **`MANHATTAN_CENTRE_MIN_WIDTH`** — Exported constant (800) for the minimum centre column width.
- **`MANHATTAN_COMPACT_BELOW`** — Exported constant representing the width threshold (`2 * RAIL_WIDTH + MANHATTAN_CENTRE_MIN_WIDTH`) below which compact mode activates.
- **`ManhattanSqueeze`** — Interface with a single `compact: boolean` field describing the current squeeze state.
- **`squeezeOf({ windowWidth })`** — Pure function mapping a window width to a `ManhattanSqueeze` value.
- **`useManhattanSqueeze(enabled)`** — The main hook; subscribes to `window` resize events and returns the live `ManhattanSqueeze` state. When `enabled` is `false` (e.g., an OSS tenant), it always returns the non-compact state. Uses a stable server snapshot (`NOT_COMPACT`) to avoid hydration mismatches.

## Usage Example

```typescript
import { useManhattanSqueeze } from './use-manhattan-squeeze';

function ManhattanShell({ isV2Enabled }: { isV2Enabled: boolean }) {
  const { compact } = useManhattanSqueeze(isV2Enabled);

  return (
    <div>
      {compact ? (
        <CompactTopBar />
      ) : (
        <>
          <LeftSidebar />
          <CenterContent />
          <RightSidebar />
        </>
      )}
    </div>
  );
}
```

Since `squeezeOf` is a pure function, it can also be tested or used directly outside of React:

```typescript
import { squeezeOf } from './use-manhattan-squeeze';

const result = squeezeOf({ windowWidth: 1000 });
console.log(result.compact); // true, if within the compact range
```
