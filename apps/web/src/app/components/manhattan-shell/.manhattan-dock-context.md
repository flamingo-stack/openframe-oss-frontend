Provides a React context for toggling the composer dock behavior between the default Mingo-first shell and the Manhattan v2 centre layout, where chat appears inline in a column rather than as an overlay sheet.

## Key Components

- **`ManhattanDockContext`** — A React context (default `false`) indicating whether the Manhattan v2 dock layout is active.
- **`useManhattanDock()`** — Hook that reads the context value, returning `true` when the session's composer dock should render as an inline chat column (Manhattan v2) instead of the default overlay sheet.

## Usage Example

```typescript
'use client';

import { ManhattanDockContext, useManhattanDock } from './manhattan-dock-context';

// Providing the context (e.g., in a layout component)
function SessionLayout({ isManhattanV2 }: { isManhattanV2: boolean }) {
  return (
    <ManhattanDockContext.Provider value={isManhattanV2}>
      <ComposerDock />
    </ManhattanDockContext.Provider>
  );
}

// Consuming the context in a child component
function ComposerDock() {
  const isManhattanDock = useManhattanDock();

  if (isManhattanDock) {
    return <InlineChatColumn />;
  }

  return <OverlaySheetChat />;
}
```

This context allows components deep in the tree to adapt their rendering strategy based on the active shell variant without prop drilling, defaulting safely to the standard Mingo-first behavior when no provider is set.
