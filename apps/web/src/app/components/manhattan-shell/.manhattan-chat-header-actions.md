Builds the list of header action items (icon buttons) shown in the Manhattan chat column header, based on the current route, layout column mode, and whether a page dialog is open. Used to drive contextual controls like "Show side by side", "Full screen", and "Close chat" in the Mingo chat shell.

## Key Components

- **`ManhattanHeaderActionsOptions`** — Input props interface: current `route`, `columnMode`, `openDialogId`, `lastPage`, optional `compact` flag, and action callbacks (`showBesidePage`, `fullScreen`, `restoreSplit`, `closeChat`).
- **`manhattanHeaderActions(options)`** — Pure function that returns an array of action objects (`{ id, label, icon, onClick }`) or `undefined`, depending on the combination of `route` and `columnMode`:
  - On the chat's own page (`route === 'chat'`): shows "Show side by side" (if a dialog/page is open and not compact) plus "Close chat".
  - In split layout (`columnMode === 'split'`): shows "Full screen" and "Close chat".
  - In full-screen chat mode (`columnMode === 'chat'`): shows "Show side by side" (unless compact) and "Close chat".
  - Otherwise returns `undefined` (no actions, e.g. chat not yet created).

## Usage Example

```typescript
import { manhattanHeaderActions } from '@/app/components/mingo-shell/manhattan-chat-header-actions';

const actions = manhattanHeaderActions({
  route: 'chat',
  columnMode: 'split',
  openDialogId: 'dialog-123',
  lastPage: '/dashboard',
  compact: false,
  showBesidePage: () => console.log('show side by side'),
  fullScreen: () => console.log('full screen'),
  restoreSplit: () => console.log('restore split'),
  closeChat: () => console.log('closed'),
});

actions?.forEach(({ id, label, icon, onClick }) => {
  // render each action button in the header, e.g.:
  // <IconButton key={id} aria-label={label} icon={icon} onClick={onClick} />
});
```
