# manhattan-centre.tsx

Implements the Manhattan v2 centre layout: a two-column (chat + page) work area orchestrator for the Mingo AI assistant shell. It computes which columns are visible, mediates navigation between the chat and page views, and hands rendering slots (chat column, page header, composer dock) to `AppLayout` via a render-prop pattern.

## Key Components

- **`ManhattanCentreSlots`** — Interface describing what the centre provides to `AppLayout`: work area mode, shown-mode callback, page-hidden flag, chat column node, page header node, dock wrapper, and dock-floats predicate.
- **`ManhattanCentre`** — Main component. Accepts `enabled`, `compact`, `chatEnabled`, `startWorkLive`, and a `children` render function receiving `ManhattanCentreSlots | null`. Handles:
  - Determining work area mode (`workAreaModeOf`) from route, conversation state, chat view, compactness, and device size.
  - Syncing "What to ask Mingo?" transient state with navigation.
  - Collapsing to one column on compact/phone layouts and dismissing the chats drawer appropriately.
  - Auto-switching chat view (`split`/`hidden`/`full`) when navigating to page routes, including links originating from inside the chat.
  - Restoring split view when widening from compact to full layout.
  - Deferred "show chat on arrival" behavior for "Close page" actions.
  - Remembering pages for the legacy Mingo sheet store (back-navigation targets).
- **`MANHATTAN_WORK_AREA_STORAGE_KEY`** — `localStorage` key for persisting the chat/page divider position.
- **`MANHATTAN_WORK_AREA_SQUEEZE_FLOOR`** — Constant (`0.3`) defining how far the divider can squeeze a column below its minimum width before it clips with a shadow indicator.

## Usage Example

```typescript
import { ManhattanCentre } from './manhattan-centre';

function AppShell({ isSaasTenant }: { isSaasTenant: boolean }) {
  return (
    <ManhattanCentre enabled={isSaasTenant} compact={false} chatEnabled={true}>
      {(centre) =>
        centre ? (
          <AppLayout
            workAreaMode={centre.mode}
            onWorkAreaShownModeChange={centre.onShownModeChange}
            chatColumn={centre.chatColumn}
            pageHeader={centre.pageHeader}
          >
            {centre.wrapDock(<ComposerDock />)}
          </AppLayout>
        ) : (
          <LegacyLayout />
        )
      }
    </ManhattanCentre>
  );
}
```

Consumers wrap their layout in `ManhattanCentre` and read the provided `slots` to render the chat column, page header, and composer dock consistently with split/full/hidden view transitions.
