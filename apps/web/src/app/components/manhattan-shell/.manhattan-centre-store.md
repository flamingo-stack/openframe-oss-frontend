# manhattan-centre-store.ts

Zustand store managing the layout state of the "Manhattan" centre work area — the region that displays a page alongside (or instead of) the Mingo chat. It tracks chat view mode (split/full/hidden), compact/responsive behavior, and cross-component signals like dismissing chat drawers or navigating to linked pages.

## Key Components

- **`ManhattanChatView`** — Type union (`'split' | 'full' | 'hidden'`) describing how the chat column relates to the page column.
- **`useManhattanCentreStore`** — Zustand hook exposing:
  - `threadNode` / `setThreadNode` — DOM node the active chat's thread portals into.
  - `chatView` / `setChatView` — current chat layout mode, persisted to `sessionStorage` per tab.
  - `compact` / `setCompact` — whether the layout has collapsed to a single column (narrow viewport).
  - `chatsDismiss` / `dismissChats` — counter bumped to close the chats drawer in compact mode.
  - `shownMode` / `setShownMode` — the actual mode `AppLayout` renders (may differ from the requested mode if there's no room).
  - `whatToAskInColumn` / `setWhatToAskInColumn` — whether Start Work's prompt input is shown in the chat column.
  - `linkedPageRequests` / `requestLinkedPage` — counter bumped when an in-chat link should bring a page to the front.
- **`workAreaModeOf(route, hasConversation, chatView, compact?, phone?, chatEnabled?)`** — Pure function computing the requested `AppLayoutWorkAreaMode` (`'page' | 'chat' | 'split'`) from routing and layout state.
- **`effectiveModeOf(mode, shownMode)`** — Resolves the final rendered mode, falling back to `'page'` when the layout reports it couldn't fit a split.

## Usage Example

```typescript
import {
  useManhattanCentreStore,
  workAreaModeOf,
  effectiveModeOf,
} from '@/app/components/mingo-shell/manhattan-centre-store';

function CentreLayout({ route, hasConversation, isPhone }: Props) {
  const chatView = useManhattanCentreStore(s => s.chatView);
  const setChatView = useManhattanCentreStore(s => s.setChatView);
  const compact = useManhattanCentreStore(s => s.compact);
  const shownMode = useManhattanCentreStore(s => s.shownMode);

  const requestedMode = workAreaModeOf(route, hasConversation, chatView, compact, isPhone);
  const mode = effectiveModeOf(requestedMode, shownMode);

  return mode === 'split' ? <SplitLayout /> : mode === 'chat' ? <ChatFull /> : <PageOnly />;
}
```

Call `setChatView('full')` to maximize chat over the page, or `requestLinkedPage()` after navigating from a chat-embedded link to bring the target page forward.
