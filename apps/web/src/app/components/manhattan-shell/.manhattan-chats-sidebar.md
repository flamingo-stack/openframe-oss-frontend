## Manhattan Chats Sidebar

Defines the left sidebar components for the Manhattan v2 shell layout, including the "New Chat" action row, the chat history section, and the user/footer row with time tracker, notifications, and collapse controls. These are assembled from existing Mingo-first shell building blocks, repackaged for the Manhattan sidebar arrangement (Figma spec 1408:292998 / 1408:293116).

## Key Components

- **`ManhattanStartWorkRow`** — Renders the "New Chat" action row. Triggers `useMingoLauncherStore.getState().startNewChat()` on click, closes the mobile menu, and displays a "Needs you" count badge (suppressed when `disabled`, loading, or behind the paywall/lock screen).
- **`ManhattanChatsSection`** — Renders either a collapsed "Chats" icon row (when `minimized`) that expands the sidebar via `onExpand`, or the full `MingoSidebarHistory` list in compact density.
- **`ManhattanChatsFooter`** — Renders the footer user row: account avatar/popover (`MingoAccountPopover`, avatar-only, logout-only), optional `TimeTrackerHeaderButton` and `NotificationsBellButton` (only when `ownsHeaderCells` and not `inDrawer`), and a collapse/expand toggle button. Adapts layout between a horizontal row (expanded) and a centered vertical stack (minimized rail).
- **`FOOTER_BUTTON_CLASS`** — Shared Tailwind class for 32px square icon buttons in the footer.

## Usage Example

```typescript
import {
  ManhattanStartWorkRow,
  ManhattanChatsSection,
  ManhattanChatsFooter,
} from '@/app/components/mingo-shell/manhattan-chats-sidebar';

function ManhattanSidebar({ minimized, toggleMinimized }: { minimized: boolean; toggleMinimized: () => void }) {
  return (
    <aside className="flex h-full flex-col">
      <ManhattanStartWorkRow minimized={minimized} active={false} />
      <ManhattanChatsSection minimized={minimized} onExpand={() => toggleMinimized()} />
      <ManhattanChatsFooter
        minimized={minimized}
        locked={false}
        ownsHeaderCells
        inDrawer={false}
        onToggleCollapsed={toggleMinimized}
      />
    </aside>
  );
}
```
