# use-manhattan-shell.ts

A React hook module managing the collapsed/expanded state of the Manhattan shell's right navigation sidebar using an external store pattern, shared across the page's navigation and phone menu components.

## Key Components

- **`MANHATTAN_NAVIGATION_EXPANDED_WIDTH`** — Constant (`200`) defining the expanded width of the right navigation, matching the Figma design spec.
- **`MANHATTAN_NAVIGATION_FOLDS_KEY`** — Storage key constant (`'of.manhattan.navigation.folded'`) identifying where folded section state is kept.
- **`useManhattanNavCollapsed()`** — Hook returning a `[collapsed, setCollapsed]` tuple backed by `useSyncExternalStore`, letting multiple components (navigation sidebar, phone menu) share a single collapse state per page.

## Usage Example

```typescript
import { useManhattanNavCollapsed, MANHATTAN_NAVIGATION_EXPANDED_WIDTH } from './use-manhattan-shell';

function NavigationSidebar() {
  const [collapsed, setCollapsed] = useManhattanNavCollapsed();

  return (
    <aside style={{ width: collapsed ? 0 : MANHATTAN_NAVIGATION_EXPANDED_WIDTH }}>
      <button onClick={() => setCollapsed(!collapsed)}>
        {collapsed ? 'Expand' : 'Collapse'}
      </button>
    </aside>
  );
}

function PhoneMenuToggle() {
  // Reads the same shared collapse state as NavigationSidebar
  const [collapsed] = useManhattanNavCollapsed();
  return <span>{collapsed ? 'Menu hidden' : 'Menu visible'}</span>;
}
```

**Important notes:**
- State is **not persisted**—every page load resets to collapsed (`true`) to avoid crowding the center layout.
- The collapse state is a **module-level singleton** (one value per page load), intentionally shared across all consumers like `NavigationSidebarConfig.collapsed`/`onCollapsedChange`.
- Must be used within a Client Component (`'use client'` directive required).
