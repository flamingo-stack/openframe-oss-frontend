# time-tracker-host-provider.tsx

Client-side provider component that hosts the global time-tracker panel for the application shell. It wires Relay GraphQL queries/mutations (start, pause, resume, stop, cancel timer, and paginated time entries) into the shared `TimeTrackerProvider` context, while coordinating ticket/customer selection, manual time entry editing, and toast notifications.

## Key Components

- **`TimeTrackerHostProvider`** — Public entry point. Accepts an `enabled` flag and `children`; always mounts `TimeTrackerHost` to preserve a stable element identity in the tree (avoids remounting `CoreAppLayout` when `enabled` flips), gating network activity internally instead of conditionally rendering.
- **`TimeTrackerHost`** — Internal component containing all state and logic:
  - Manages timer state (`timerNode`), recent entries (`recentNodes`), notes, and modal visibility (manual entry, cancel confirmation).
  - Seeds the ticket/customer draft from an already-running timer exactly once per timer lifecycle (via the `seeded` flag), avoiding an empty-state flash.
  - Uses `useTicketCustomerSelection` for ticket/customer search, selection, and locking behavior.
  - Defines Relay mutations: `onStart`, `onPause`, `onResume`, `onCancel`/`confirmCancel`, `onSubmit` (stop timer), each with optimistic `updater` functions from `time-tracker-helpers` and error toasts via `onError`.
  - Builds `trackerData: TimeTrackerData` — the full prop surface passed into `TimeTrackerProvider` context, combining timer clock state, ticket/customer options, and all action callbacks.
  - Navigation helpers `onOpenMyTime` / `onOpenMyTimeMenu` route to the current user's employee detail page.
  - `onEntryClick` opens the `ManualEntryModal` pre-populated with an existing entry for editing.

## Usage Example

```typescript
import { TimeTrackerHostProvider } from '@/app/components/time-tracker-host-provider';

function AppLayout({ children }: { children: React.ReactNode }) {
  const sessionReady = useSessionReady(); // resolved session + unlocked workspace
  return (
    <TimeTrackerHostProvider enabled={sessionReady}>
      <CoreAppLayout>{children}</CoreAppLayout>
    </TimeTrackerHostProvider>
  );
}
```

**Important:** Always mount `TimeTrackerHostProvider` unconditionally in the app shell and toggle only the `enabled` prop. Conditionally rendering the provider itself (e.g., `enabled ? <TimeTrackerHostProvider>... : children`) will cause React to remount the entire subtree when `enabled` changes.
