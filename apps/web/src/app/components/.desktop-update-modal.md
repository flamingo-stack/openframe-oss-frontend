# desktop-update-modal.tsx

React client component that renders the desktop shell's "update ready" modal, handling update discovery, download progress, installation, and error states for the OpenFrame Console desktop app.

This modal is mounted once (typically in `AppShell`) and covers the cases the shell's silent-at-launch update mechanism can't handle itself: offline-at-boot machines, failed downloads, disabled self-update, and releases published mid-session. It subscribes to native shell update events exactly once per document load (guarded by a module-level flag) since the underlying event transport outlives React component lifecycles.

## Key Components

- **`ERROR_COPY`** — Record mapping each `DesktopUpdateErrorKind` (`network`, `signature`, `disk`, `permission`, `security`, `location`, `unavailable`, `busy`, `gone`, `unknown`) to a user-facing message and whether retry is appropriate. The exhaustive typing ensures new shell error kinds surface as compile errors rather than blank UI.
- **`DesktopUpdateModal()`** — Default export, the modal component itself:
  - Reads update state (`version`, `phase`, `downloaded`, `total`, `error`, `blocked`, etc.) from `useDesktopUpdateStore` via `useShallow`.
  - On mount, registers native shell listeners (`onDesktopUpdateAvailable`, `onDesktopUpdateProgress`, `onDesktopUpdateInstalling`, `onDesktopUpdateError`) and performs a one-time `checkDesktopUpdate()` poll to catch updates that were announced before the listeners existed.
  - `handleApply` — triggers `applyDesktopUpdate()`, transitioning store state via `startApply`/`fail`.
  - `handleClose` — blocks modal dismissal while an install is in progress (`downloading`/`installing` phases).
  - Renders progress (determinate `Progress` bar or an indeterminate pulsing bar when no byte-length is reported), error alerts with retry/dismiss actions, and an optional release notes link.

## Usage Example

```typescript
// Mounted once at the application shell level
import { DesktopUpdateModal } from '@/app/components/desktop-update-modal';

export function AppShell({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <DesktopUpdateModal />
    </>
  );
}
```

The component is self-contained: it reads all state from `useDesktopUpdateStore` and requires no props. It renders `null` when no update `version` is present in the store, and only activates its native listeners when `isDesktopShell()` returns `true`.
