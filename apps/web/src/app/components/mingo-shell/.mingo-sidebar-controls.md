Renders the Mingo-first shell's sidebar footer controls (time tracker and notifications bell) as compact buttons, mirroring what the classic header exposed at its right end, but scoped to a single mounting location to avoid duplicate popovers.

## Key Components

- **`MingoSidebarControlsProps`** — Props interface:
  - `ownsHeaderCells: boolean` — Gate controlling whether this instance should render. Only `true` on the desktop sidebar (md+ breakpoint) where the phone top bar (which normally hosts these controls) isn't rendered. Must stay `false` for the phone drawer's footer copy (`inDrawer`) to prevent duplicate popovers, since the time tracker's popover shares a single open state.
  - `disabled: boolean` — When `true` (e.g., lock screen active), controls remain visible but are inert.
- **`MingoSidebarControls`** — Function component that returns `null` unless `ownsHeaderCells` is `true`; otherwise renders a responsive flex container with:
  - `TimeTrackerHeaderButton` (compact variant, popover opens to the right)
  - `NotificationsBellButton` (compact variant)
  
  Layout stacks vertically in the narrow 56px rail and switches to a horizontal row once the sidebar container reaches 140px width (via container query `@[140px]/of-nav-sidebar`).

## Usage Example

```typescript
import { MingoSidebarControls } from './mingo-sidebar-controls';

function SidebarFooter({ isDesktop, isLocked }: { isDesktop: boolean; isLocked: boolean }) {
  return (
    <div className="footer-slot">
      <MingoSidebarControls ownsHeaderCells={isDesktop} disabled={isLocked} />
      {/* account row rendered alongside */}
    </div>
  );
}
```

Ensure only one instance in the tree sets `ownsHeaderCells` to `true` at a time (desktop sidebar), while the phone drawer's equivalent footer always passes `false`.
