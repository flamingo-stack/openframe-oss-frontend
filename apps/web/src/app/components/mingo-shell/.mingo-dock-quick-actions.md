# mingo-dock-quick-actions.tsx

Renders Mingo's quick-action chips above the docked chat composer on Mingo's home screen, reusing the same `MingoQuickActionWall` component that powers the chat's empty state.

## Key Components

- **`MingoDockQuickActionsProps`** — Interface defining the component's props, notably `onSend: (instructions: string) => void`, which immediately sends an action's instructions into a new chat.
- **`MingoDockQuickActions`** — Functional component that:
  - Fetches quick-action chips and their loading state via `useMingoQuickActionChips(onSend)`.
  - Detects an ambient loading scope via `useLoadingScope()` (e.g., the dock's own loading form) and merges it with the chips' own loading state.
  - Returns `null` when there are no chips and nothing is loading, to avoid rendering an empty shell.
  - Renders `MingoQuickActionWall` inside a padded/margined wrapper so it visually aligns with the composer card beneath it.
  - Keeps the wall's rows reserved during loading so the dock's height (and the centered greeting above it) doesn't shift once chips arrive.

## Usage Example

```typescript
import { MingoDockQuickActions } from './mingo-dock-quick-actions';

function MingoHomeDock() {
  const handleSend = (instructions: string) => {
    // Opens a new chat and sends the quick action's instructions
    startNewChat(instructions);
  };

  return (
    <div className="mingo-home">
      <MingoDockQuickActions onSend={handleSend} />
      <ChatComposer />
    </div>
  );
}
```

**Note:** This component is intended for use specifically on Mingo's home screen above the docked composer, where `showsDockQuickActions` is enabled. No caption/title is rendered over the chip wall, since that labeling is handled elsewhere (the home's button and the chat history menu).
