# mingo-new-chat-row.tsx

Renders the "New chat" action row at the top of Mingo's sidebar chat history, allowing users to start a fresh, empty chat conversation.

## Key Components

- **`MingoNewChatRow`** — A client component that renders an outline-styled action row (`NavigationSidebarActionRow`) with a plus-circle icon and "New chat" label. Accepts a `minimized` prop to control collapsed sidebar display.

### Behavior Notes
- On click, it triggers `useMingoLauncherStore.getState().startNewChat()` to reset the chat state directly (rather than relying solely on navigation), ensuring the chat page doesn't briefly render stale content before navigating home.
- It also calls `closeMobileMenu()` to explicitly close the mobile drawer, since navigating to the home/new-chat view from the home screen itself doesn't trigger the layout's automatic drawer-close-on-navigation behavior.

## Usage Example

```typescript
import { MingoNewChatRow } from './mingo-new-chat-row';

function MingoSidebarHistorySlot({ isMinimized }: { isMinimized: boolean }) {
  return (
    <div>
      <MingoNewChatRow minimized={isMinimized} />
      {/* chat history list follows below */}
    </div>
  );
}
```

This component is intended to be used specifically within Mingo's sidebar history slot, positioned above the list of previous chat sessions, giving users quick access to start a new conversation regardless of sidebar state (expanded or minimized).
