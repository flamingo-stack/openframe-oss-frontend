# use-composer-target.ts

React hook that determines which chat conversation the docked Mingo composer sends into, and where the user is navigated to when a message creates or continues a chat. It encodes the chat-targeting and navigation rules described in the module's design notes (PLAN §3.7).

## Key Components

- **`useComposerTarget(options)`** — Main hook. Wraps the chat state's send functions so that:
  - On the **home route**, entering the page (or closing the sheet there) deselects the active chat, ensuring a send creates a fresh conversation.
  - A send from any non-chat page that creates or continues a chat opens it in a sheet overlay (`openSheet`) or, on **phone** layouts, navigates directly to the chat's page (`routes.mingo.chat(id)`).
  - Sends made on the chat page itself are left alone, since chat-page selection is handled elsewhere (`use-chat-page-selection.ts`).
  - A chat that becomes active on home outside of a send (e.g. the Getting Started tour) is navigated to its own page.

- **`ComposerTargetOptions`** — Input config: current `route`, chat `state`, `sendInNewDialog`, `createIntentDialog`, `navigate`, `openSheet`, `sheetOpen`, and optional `phone` flag.

- **`ComposerTarget`** — Return value: `mingoState` (a wrapped `UnifiedChatState` for `EmbeddableChat`), plus follow-aware `sendInNewDialog` and `createIntentDialog`.

- **`openChat(dialogId, opts)`** — Internal helper that either navigates to the chat's page (phone) or raises the sheet (desktop/tablet).

- **`following(send)`** — Internal wrapper that arms a "pending follow" marker before a send, letting an effect detect and react to the new chat id once it commits, then disarms safely on success or failure.

## Usage Example

```typescript
import { useComposerTarget } from './use-composer-target';

function MingoDockComposer({ route, chatState, sheetOpen, isPhone }: Props) {
  const { mingoState, sendInNewDialog, createIntentDialog } = useComposerTarget({
    route,
    state: chatState,
    sendInNewDialog: chatState.sendInNewDialog,
    createIntentDialog: chatState.createIntentDialog,
    navigate: router.push,
    openSheet: () => mingoSheetStore.show(),
    sheetOpen,
    phone: isPhone,
  });

  return <EmbeddableChat state={mingoState} />;
}
```
