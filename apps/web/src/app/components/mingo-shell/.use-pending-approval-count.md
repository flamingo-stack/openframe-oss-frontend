# use-pending-approval-count.ts

A client-side React hook that computes the total count of pending approval requests for display in the sidebar's "Needs approval" badge, combining Mingo chat approvals and Tech Required ticket approvals.

## Key Components

- **`usePendingApprovalCount()`** — The main hook export. Returns a `number` representing the sum of pending Mingo dialog approvals and pending Tech Required ticket approvals.
- **`DIALOGS_COUNT_KEY`** — React Query cache key for the dialogs approval count, derived from `APPROVAL_DIALOGS_QUERY_KEY` with a `'count'` suffix.
- **`ticketsCountKey(laneId)`** — Factory for the React Query cache key used to count pending approval tickets in a given status lane.

## Behavior

- Gating logic (`live`): queries are only enabled when the subscription panel is open, Mingo chat is enabled, and the tenant is running in SaaS mode (`isSaasTenantMode()`).
- Two independent one-row queries poll the server at `APPROVALS_POLL_MS` intervals:
  - `dialogsCount` — fetched via `fetchApprovalDialogsCount`.
  - `ticketsCount` — fetched via `ticketService.countPendingApprovalTickets(laneId)`, where `laneId` is resolved from the "Tech Required" ticket status via `techRequiredStatusId`.
- `useApprovalRefreshSignal` invalidates both query caches whenever an approval decision is made or a new request arrives elsewhere in the app, keeping the badge count fresh without relying on the full approval list queries.

## Usage Example

```typescript
import { usePendingApprovalCount } from '@/app/components/approvals/hooks/use-pending-approval-count';

function SidebarBadge() {
  const pendingCount = usePendingApprovalCount();

  if (pendingCount === 0) return null;

  return <span className="badge">{pendingCount}</span>;
}
```

This hook is intended to be mounted once for the session (e.g., in a persistent sidebar component) rather than per-page, since it maintains its own polling and cache invalidation independent of the full approval list views.
