Manages the open/closed state of the chat-history search field in the Mingo-first sidebar using a lightweight Zustand store.

## Key Components

- **`HistorySearchStore`** — TypeScript interface defining the store shape: `open` (boolean) and `setOpen` (setter function).
- **`useHistorySearchStore`** — Zustand hook/store exposing the current `open` state and `setOpen` action for toggling visibility of the history search field.

## Usage Example

```typescript
import { useHistorySearchStore } from './history-search-store';

function SidebarShell() {
  const { open, setOpen } = useHistorySearchStore();

  // Open search on ⌘K / Ctrl+K
  useKeyboardShortcut('mod+k', () => setOpen(true));

  return open ? <HistorySearchField onClose={() => setOpen(false)} /> : null;
}

function MingoSidebarHistory() {
  const open = useHistorySearchStore(state => state.open);
  const setOpen = useHistorySearchStore(state => state.setOpen);

  return (
    <div>
      {open && (
        <input
          autoFocus
          placeholder="Search history..."
          onBlur={e => {
            if (!e.target.value) setOpen(false);
          }}
          onKeyDown={e => {
            if (e.key === 'Escape') setOpen(false);
          }}
        />
      )}
    </div>
  );
}
```

This store is intentionally minimal, decoupling the shell (which triggers opening via keyboard shortcuts) from the sidebar history component (which renders the field and manages its own closing behavior).
