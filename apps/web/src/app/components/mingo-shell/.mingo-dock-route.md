# mingo-dock-route.ts

Determines how the Mingo composer dock behaves and renders based on the current route, classifying pathnames into semantic route categories (`home`, `chat`, `full-width`, `page`) and mapping each to its visual presentation.

## Key Components

- **`ComposerRoute`** — Type union of the four route categories the dock cares about: `home` (new chat), `chat` (existing thread), `full-width` (remote desktop/shell/file manager), `page` (any other page).
- **`composerRouteOf(pathname)`** — Classifies a pathname into a `ComposerRoute`, normalizing trailing slashes first.
- **`isSheetRoute(route)`** — Returns `true` when the chat should open as an overlay sheet rather than inline (`page` and `full-width` routes).
- **`canShowSheet(route)`** — Returns `true` for all sheet-eligible routes plus `home` (since a chat collapses back to home).
- **`showsDockQuickActions(route)`** — Returns `true` only on `home`, where quick actions render above the composer.
- **`DockView`** interface — Describes visual config per route: `widthClassName`, `placeholder`, `showContextMemory`, and `floats`.
- **`dockViewOf(route)`** — Looks up the precomputed `DockView` for a given route.
- **`SHEET_WIDTH_CLASS_NAME`** — Tailwind width class for the composer sheet overlay, matching the page column's effective width minus insets.

## Usage Example

```typescript
import { composerRouteOf, dockViewOf, isSheetRoute } from '@/lib/mingo-dock-route';

const pathname = usePathname();
const route = composerRouteOf(pathname);
const view = dockViewOf(route);

return (
  <div className={view.widthClassName}>
    {isSheetRoute(route) ? (
      <MingoComposerSheet placeholder={view.placeholder} />
    ) : (
      <MingoComposerDock
        placeholder={view.placeholder}
        showContextMemory={view.showContextMemory}
        floats={view.floats}
      />
    )}
  </div>
);
```

This module is consumed by the app layout and dock components to keep routing-dependent presentation logic centralized, avoiding scattered pathname checks across the UI layer.
