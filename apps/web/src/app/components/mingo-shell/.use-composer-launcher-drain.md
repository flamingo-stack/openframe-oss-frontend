## Overview

Defines two React hooks that manage the Mingo chat "dock" — the bridge between launcher actions (Fix with Mingo, Ask Mingo, intent buttons, notifications, etc.) and the composer/chat UI. It publishes dock availability to a Zustand store and drains queued launcher requests into the appropriate chat action (send, create, prefill, open, or navigate).

## Key Components

- **`usePublishComposerDock()`** — Marks the dock as mounted in `useMingoLauncherStore` for the lifetime of the component, letting launchers know a composer is available to receive requests.

- **`ComposerLauncherDrainOptions`** — Configuration interface for `useComposerLauncherDrain`, bundling the chat handle, current route, send/create/select callbacks, sheet control, page-context flags (`whatToAskPage`, `phone`), and a `navigate` function.

- **`useComposerLauncherDrain(options)`** — Core hook that consumes the pending `dockRequest` from `useMingoLauncherStore` and routes it based on its `kind`:
  - `whatToAsk` — navigates to `routes.mingo.whatToAsk` if not already there.
  - `open` — opens an existing dialog (sheet overlay or full navigation depending on route/phone).
  - `prompt` / `intent` / `draft` / `newChat` — either handled in place (composer prefill, new chat, intent creation) or redirected home first if the current route can't host a composer.
  - Tracks a "sent home" ref to avoid duplicate navigation during pending transitions, and a "what to ask shown" ref to display suggestions once per page visit.

## Usage Example

```typescript
function MingoDockComposer() {
  const handle = useEmbeddableChatHandle(); // from chat module
  const route = useComposerRoute();
  const { sendInNewDialog, createIntentDialog } = useComposerTarget();
  const selectDialog = useUnifiedChatState(s => s.selectDialog);
  const openSheet = useMingoSheetStore(s => s.show);
  const navigate = useNavigate();

  usePublishComposerDock();

  useComposerLauncherDrain({
    handle,
    route,
    sendInNewDialog,
    createIntentDialog,
    selectDialog,
    openSheet,
    whatToAskPage: route === 'whatToAsk',
    phone: useIsPhone(),
    navigate,
  });

  return <ComposerUI handle={handle} />;
}
```
