A React error boundary component that isolates crashes within the Mingo composer dock's chat panel, preventing failures from propagating to and crashing the entire application shell.

## Key Components

- **`MingoDockErrorBoundary`** — A class component implementing React's error boundary pattern (`getDerivedStateFromError`, `componentDidCatch`) that catches errors thrown by its children (the chat lib panel or session chat state).
- **`state.failed`** — Boolean flag tracking whether a crash has occurred, controlling fallback UI rendering.
- **`retry`** — Instance method that resets `failed` to `false`, remounting the wrapped children. Since the crash unmounts the dock (the last surface referencing the chat state), the provider has already discarded the failed state, so remounting starts a clean session rather than re-triggering the same error.

## Usage Example

```typescript
import { MingoDockErrorBoundary } from './mingo-dock-error-boundary';

function MingoComposerDock() {
  return (
    <MingoDockErrorBoundary>
      <MingoChatPanel />
    </MingoDockErrorBoundary>
  );
}
```

When a child component throws (e.g., the chat lib panel crashes), the boundary renders a fallback UI with the message "Mingo is unavailable right now." and a **Try again** button, instead of unmounting the entire shell. Clicking retry clears the error state and remounts `children`, giving the chat a fresh start since the previous failed state was already dropped by the provider on unmount.

This component must be used as a client component (`'use client'`) since it relies on React lifecycle methods and local state, and should wrap any dock content that depends on potentially unstable chat session state.
