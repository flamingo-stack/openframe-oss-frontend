# use-sidebar-collapsed.ts

A React hook providing synchronized, persisted state for the desktop navigation sidebar's collapsed/expanded status, built on `useSyncExternalStore` to share state outside React's component tree.

## Key Components

- **`useSidebarCollapsed()`** — Hook returning a readonly tuple `[collapsed, setCollapsed]`, mirroring the `useState` API pattern. Intended to drive `NavigationSidebarConfig.collapsed` / `onCollapsedChange` in the shell's sidebar configuration.
- **`expandedOnServer`** — Internal helper returning `false`, used as the server snapshot for SSR hydration (sidebar defaults to expanded on the server to avoid layout mismatch).

This hook delegates all state storage and subscription logic to `@/lib/navigation-sidebar-state`:
- `readSidebarMinimized` — reads the current collapsed value from the external store.
- `subscribeSidebarMinimized` — subscribes to external store updates (e.g., triggered by keyboard shortcuts like ⌘K).
- `writeSidebarMinimized` — writes/persists the new collapsed value.

Using a shared external store (rather than local component state) ensures the sidebar's collapsed state stays consistent across components, survives navigation, and can be toggled programmatically (e.g., from a command palette) without prop drilling.

## Usage Example

```typescript
import { useSidebarCollapsed } from '@/hooks/use-sidebar-collapsed';

function AppShell() {
  const [collapsed, setCollapsed] = useSidebarCollapsed();

  return (
    <NavigationSidebar
      config={{
        collapsed,
        onCollapsedChange: setCollapsed,
      }}
    />
  );
}

// Programmatic toggle, e.g. from a command palette (⌘K)
function RevealSidebarCommand() {
  const [, setCollapsed] = useSidebarCollapsed();
  return <button onClick={() => setCollapsed(false)}>Expand sidebar</button>;
}
```

**Note:** Because state is persisted under the core sidebar's own storage key, both the pre-paint width seed script and this hook read/write the same preference, preventing layout flicker on page load.
