# mingo-sidebar-history.tsx

Renders the chat history section of the Mingo sidebar, backed by the shared session chat state (`useMingoChat`). It exposes the sidebar slot (new chat row + history/search), the history list itself, and a standalone search modal, all reading from (not duplicating) the live chat session.

## Key Components

- **`MingoSidebarHistory({ density })`** — Main component rendering `MingoChatRail` in `"section"` variant, bound to the active chat session's dialogs (list, scope My/All, search, paging, status glyphs). Handles row actions (open, rename, copy link, archive) and an extra "Reset Onboarding" menu item (gated by `onboarding-v2` feature flag). Renders its modals (`RenameChatModal`, `ArchiveChatModal`, `ResetOnboardingDialog`) via `createPortal` to `document.body` so they escape any sidebar transform/drawer context.
- **`SidebarHistoryModals`** — Internal helper component grouping the rename/archive/reset-onboarding modals for the portal.
- **`MingoSidebarHistorySlot({ minimized })`** — The sidebar's `sectionSlot`: stacks `MingoNewChatRow`, a compact-rail "Chats" action row (opens search, shown below 140px width), and the full `MingoSidebarHistory` (shown at 140px+ width). Highlights the "Chats" row when a chat page is mounted (via `useChatPageNodeStore`).
- **`MingoHistorySearch`** — Standalone `MingoChatSearchModal` instance, meant to be rendered once per page by the shell; opens via shared `useHistorySearchStore` state (triggered by ⌘K/Ctrl+K or either sidebar instance).

## Usage Example

```typescript
import {
  MingoSidebarHistorySlot,
  MingoHistorySearch,
} from './mingo-sidebar-history';

// In the navigation sidebar's section slot renderer:
function SidebarSection({ minimized }: { minimized: boolean }) {
  return <MingoSidebarHistorySlot minimized={minimized} />;
}

// Once per page (e.g. in the app shell), so ⌘K opens search from anywhere:
function AppShell() {
  return (
    <>
      {/* ...rest of layout... */}
      <MingoHistorySearch />
    </>
  );
}
```

Both components depend on `useMingoChat()` returning an active chat session; if the chat feature is disabled (`enabled === false`) or the session hasn't registered yet, the components render `null` or a loading/error state respectively.
