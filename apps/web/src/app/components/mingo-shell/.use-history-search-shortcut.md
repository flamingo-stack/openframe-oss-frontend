# use-history-search-shortcut.ts

Implements the global ⌘K / Ctrl+K keyboard shortcut that opens chat-history search, while carefully avoiding conflicts with editors, terminals, and pages that forward keystrokes to a remote machine.

## Key Components

- **`forwardsKeyboard(pathname)`** — Returns `true` if the given pathname (e.g. the remote desktop route) owns the keyboard via its own `window` listener, meaning the shortcut must not bind there.
- **`isHistorySearchShortcut(event, commandKey)`** — Pure predicate that checks whether a keyboard event matches the history-search shortcut: correct key (`k`), the right single modifier (`metaKey` on Mac, `ctrlKey` elsewhere, never both), no `alt`/`shift`, not already handled (`defaultPrevented`), and not originating inside a keyboard-owning surface (Monaco editor, xterm terminal, or `contenteditable` elements).
- **`useHistorySearchShortcut(enabled, onTrigger)`** — React hook that binds a `keydown` listener on `window` while `enabled` is `true`, calling `onTrigger` and suppressing the browser default (e.g. address bar search) when the shortcut matches. Uses `useVisitorOs` to detect whether the visitor's OS uses the Command key.
- **`KEYBOARD_OWNING_SURFACES`** — CSS selector identifying DOM elements that should block the shortcut.
- **`KEY_FORWARDING_PATHS`** — List of route prefixes (currently the remote desktop page) that forward all keystrokes elsewhere and must disable this shortcut.

## Usage Example

```typescript
import { usePathname } from 'next/navigation';
import { forwardsKeyboard, useHistorySearchShortcut } from './use-history-search-shortcut';

function AppShell() {
  const pathname = usePathname();
  const [historyOpen, setHistoryOpen] = useState(false);

  useHistorySearchShortcut(!forwardsKeyboard(pathname), () => {
    setHistoryOpen(true);
    // reveal sidebar and focus the search field
  });

  return <Sidebar historySearchOpen={historyOpen} />;
}
```

Disable the hook (`enabled = false`) on routes like `/devices/details/remote-desktop`, where the page itself owns all keyboard input.
