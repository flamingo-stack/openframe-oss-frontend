# mingo-phone-chat-list.tsx

Renders the mobile-specific chat history screen shown inside Mingo's composer sheet — the first screen of the phone drawer, equivalent to the sidebar's `MingoHistoryRail` but driven by the shared chat session state instead of its own data-fetching hook.

## Key Components

- **`MingoPhoneChatList`** — Client component (`'use client'`) that renders `MingoHistoryRail` bound to the active `useMingoChat()` session. Handles:
  - **Loading/error states**: shows an empty rail with loading/error flags when no chat session exists yet.
  - **Dialog selection**: navigates to `routes.mingo.chat(id)` when a dialog is selected.
  - **New chat**: calls `rememberNewChatPage()` (from `useMingoSheetStore`) then navigates to `routes.mingo.home`.
  - **Copy link**: delegates to `copyDialogLink` from the chat context.
  - **Pagination**: uses a "Show more" button pattern (`loadMore="button"`) with `MINGO_DIALOGS_PAGE_SIZE` per page, distinguishing initial load (`isLoadingHistory`) from subsequent pages (`isLoadingMore`).
  - **Scope/search**: wires `dialogScope`/`setDialogScope` and `searchQuery` from session state.
  - **Retry**: triggers `state.reloadDialogs` on load failure.

## Usage Example

```typescript
// Rendered inside the Mingo composer sheet shown on mobile layouts
import { MingoPhoneChatList } from './mingo-phone-chat-list';

export function MingoComposerSheet() {
  return (
    <div className="mingo-sheet">
      <MingoPhoneChatList />
    </div>
  );
}
```

This component reads state read-only from `useMingoChat()` (the same session the sidebar reads from) rather than fetching its own dialog list, ensuring consistent history state across desktop and mobile views.
