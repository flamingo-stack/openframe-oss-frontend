# use-mingo-quick-action-chips.ts

A React hook that transforms admin-configured Mingo quick actions into renderable chat chip objects, bridging quick-action data with the UI's chip format used by both the chat's empty state and the dock.

## Key Components

- **`useMingoQuickActionChips(send?)`** — Main hook that accepts an optional `send` callback and returns `{ chips, loading }`.
  - `send?: (instructions: string) => void` — Optional handler invoked with the action's `instructions` when a chip is clicked. If omitted, the returned chip's `onClick` is `undefined` (useful when the consumer, e.g. the chat itself, handles sending the `prompt` on its own).
  - `chips: MingoQuickAction[]` — Array of chip objects ready for rendering, each with `id`, `label`, `variant`, `icon`, `prompt`, and `onClick`.
  - `loading: boolean` — Indicates whether the underlying quick actions are still being fetched, allowing callers to render a placeholder/skeleton instead of an empty chip row.

Internally, it wraps `useMingoQuickActions` (data fetching) and maps each action through `renderQuickActionIcon` (icon resolution with `mingo` accent tinting) from `@flamingo-stack/openframe-frontend-core/components/chat`, memoizing the result via `useMemo`.

## Usage Example

```typescript
'use client';

import { useMingoQuickActionChips } from '@/app/(app)/mingo/hooks/use-mingo-quick-action-chips';

function MingoDock() {
  const handleSend = (instructions: string) => {
    // Forward the full instruction text to the chat/agent
    console.log('Sending prompt:', instructions);
  };

  const { chips, loading } = useMingoQuickActionChips(handleSend);

  if (loading) {
    return <div>Loading quick actions…</div>;
  }

  return (
    <div className="quick-action-row">
      {chips.map(chip => (
        <button key={chip.id} onClick={chip.onClick}>
          {chip.icon}
          {chip.label}
        </button>
      ))}
    </div>
  );
}
```

When used inside the chat's own empty state, `send` can be omitted since the chat component handles dispatching `chip.prompt` itself on click.
