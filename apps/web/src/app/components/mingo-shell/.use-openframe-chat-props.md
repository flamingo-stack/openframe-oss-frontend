# use-openframe-chat-props.ts

A React hook that assembles OpenFrame's host-specific configuration for the embeddable `EmbeddableChat` component, wiring up context picking, mentions, memory, quick actions, and user identity from OpenFrame's own stores and hooks.

## Key Components

- **`OpenframeChatProps`** — Type alias picking the subset of `EmbeddableChatProps` that OpenFrame's chat integration owns (context picker, mentions, memory strip, dialog capabilities, identity, welcome state, etc.). The composer dock layer adds further layout-specific props on top.
- **`OpenframeChatPropsOptions`** — Input shape for the hook: the active `MingoChatState` (`chat`), the `copyDialogLink` action, and an optional `compactDialog` action (present only when its feature flag is enabled).
- **`useOpenframeChatProps(options)`** — Builds a complete `OpenframeChatProps` object by combining:
  - User identity (`userDisplayName`, `userAvatarUrl`) derived from `useAuthStore`, used as a fallback when the library's server-resolved identity lacks a name.
  - `contextPicker` — memoized config for the `+`/`@` entity-context picker, built from `useMingoContextEntityTypes` and `renderMingoContextItems`.
  - `contextMemory` — navigation history strip from `useMingoContextMemory`.
  - `mingoWelcome` — admin-configured quick-action chips from `useMingoQuickActionChips`, included only when chips exist or are loading (to preserve empty-state height).
  - `mingoDialogCapabilities` — search, rename, archive, compact, and copy-link wiring for dialog management.
  - `modes: {}` — an intentionally empty object (not omitted) to keep the panel Mingo-only and prevent the library's legacy Guide-mode fallback from activating.
  - `renderMention` / `renderContextItem` — stable renderer functions for inline `@` mentions and attached context chips as self-fetching entity cards.

## Usage Example

```typescript
import { useOpenframeChatProps } from './use-openframe-chat-props';

function MingoComposerDock({ chat, copyDialogLink, compactDialog }: Props) {
  const chatProps = useOpenframeChatProps({
    chat,
    copyDialogLink,
    compactDialog,
  });

  return <EmbeddableChat {...chatProps} /* + composer-dock layout props */ />;
}
```

## Notes

- `modes` is deliberately passed as `{}` rather than omitted — omitting it causes the embeddable chat library to fall back to a legacy Guide-only mode, which must stay disabled here since Mingo mode is host-controlled via `mingoState`.
- `sourceSkeletonCount` is set to `0` because Mingo rarely cites sources, avoiding a flickering loading strip.
- `pendingApprovals` must be passed through explicitly since the dialog reducer filters PENDING approval cards out of message bubbles for dedupe purposes.
