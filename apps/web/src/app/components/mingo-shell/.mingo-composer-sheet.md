# mingo-composer-sheet.tsx

Renders Mingo's floating chat composer as an overlay sheet docked above the current page, allowing users to chat without leaving their current context. On mobile, it can instead display a full-screen chat list.

## Key Components

- **`SHEET_DEFAULT_HEIGHT`** — Default pixel height (500) for the desktop sheet before the user drags to resize it.
- **`SheetThreadOnScreen()`** — Internal helper component that marks the chat thread as visible so its notifications are suppressed while the sheet is open.
- **`escapeIsTaken()`** — Internal helper that detects whether `Esc` should be consumed by an open popover/menu or an in-progress composer draft instead of dismissing the sheet.
- **`MingoComposerSheet()`** — Main exported component. Manages:
  - Open/close state synced with route changes and the `useMingoSheetStore`.
  - Desktop vs. phone layouts (resizable floating card vs. full-screen sheet/chat list).
  - Dismissal via close button, scrim click, `Esc` key, and Android native back button.
  - Remembering the "last page" and "outside page" for restoring context when the chat collapses.
  - Portaling the chat header/thread into the sheet body via `setNode`.

## Usage Example

```typescript
import { MingoComposerSheet } from './mingo-composer-sheet';

// Typically mounted once near the root of the app layout,
// e.g. inside AppLayout's composerSheet overlay slot.
export function AppLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <MingoComposerSheet />
    </>
  );
}
```

The component reads its open/closed state and dimensions from `useMingoSheetStore`, so triggering it elsewhere in the app (e.g., sending a message from a composer widget) is done by updating that store rather than passing props directly to `MingoComposerSheet`.
