# mingo-account-popover.tsx

Renders the account row and dropdown menu at the foot of the Mingo-first sidebar (and the phone drawer), showing the user's avatar and name, with menu items for Settings, Help Center, unread support replies, and logging out.

## Key Components

- **`MingoAccountPopover`** — Client component wrapping the shared `AccountPopover` primitive with Mingo-specific menu entries and user data sourced from the auth store.
- **`MingoAccountPopoverProps`** — Prop interface controlling layout/behavior:
  - `collapsed` — whether the sidebar is rendered as the 56px collapsed rail.
  - `locked` — disables navigation items (Settings, Help Center, support replies) while the lock screen is active; Log out remains enabled.
  - `collapsedAlign` — alignment of the avatar trigger when collapsed (`'start'` or `'center'`).
  - `avatarOnly` — renders only the avatar as the trigger at any width.
  - `logoutOnly` — restricts the menu to just the Log out entry (used in Manhattan v2 where Settings/Help Center live in the nav sidebar).

## Behavior Notes

- Pulls user `firstName`, `lastName`, `email`, and profile image from `useAuthStore`, falling back to email or `"Account"` if no name is set.
- Uses `useOptionalTicketLive` to surface an unread support-reply count; when present, adds a "Support replies" item linking to the newest unread ticket via `buildTicketOpenHref`.
- Every navigational item calls `closeMobileMenu` on select so navigating to the current page still closes an open phone drawer.
- "Log out" triggers `useLogoutConfirmStore`'s `open` action, showing the same confirmation modal used on the Settings page.

## Usage Example

```typescript
import { MingoAccountPopover } from './mingo-account-popover';

// In a sidebar footer
<MingoAccountPopover collapsed={false} locked={false} />

// Collapsed rail, avatar-only trigger
<MingoAccountPopover collapsed avatarOnly collapsedAlign="start" locked={false} />

// Manhattan v2 chats footer: Log out only
<MingoAccountPopover collapsed={false} locked={false} logoutOnly />
```
