# use-page-chip.tsx

A React hook and supporting components that render the "page context chip" shown in Mingo's composer context strip — a UI element representing either the current page or a focused entity (like a specific customer or device) that Mingo's AI assistant is aware of in the conversation.

## Key Components

- **`PAGE_OVERVIEW_PROMPT`** — Exported constant string sent to Mingo when a user clicks the page chip to request an overview of the current page.
- **`usePageChip(route, onAsk)`** — Main hook that determines what chip to render based on the composer's route context (`'home'`, `'chat'`, or an entity view page). Returns a `ReactNode` or `null`.
- **`PageChip`** — Internal component rendering a simple clickable chip labeled with the current page's title and icon.
- **`pageIcon(pathname)`** — Resolves the appropriate icon for a path, checking named Mingo pages first, then falling back to the sidebar navigation module icon.
- **`ChipLabel`** — Small presentational component that truncates long labels within the chip strip.

## Usage Example

```typescript
import { usePageChip } from './use-page-chip';

function ComposerContextStrip({ route }: { route: ComposerRoute }) {
  const handleAsk = (prompt: string) => {
    // send `prompt` to Mingo as a new chat message
    startNewChat(prompt);
  };

  const pageChip = usePageChip(route, handleAsk);

  return (
    <div className="flex items-center gap-2">
      {pageChip}
      {/* other context chips */}
    </div>
  );
}
```

The hook automatically handles three scenarios: on Mingo's home/chat routes it derives the chip from the last visited page (or a new-chat page on mobile); on entity-focused pages it renders a removable chip (e.g., "Customer: Default") backed by `useMingoContextStore`; otherwise it renders a plain page chip based on the current pathname and search params.
