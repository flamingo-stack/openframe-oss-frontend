# mingo-sidebar-rows.tsx

Renders the top-level navigation rows ("Dashboard" and "Needs approval") that appear above the module tree in the Mingo-first sidebar. These rows live in the sidebar's `topSlot` rather than its standard `items` list, enabling special behaviors like a live approval count badge and rendering inside the mobile drawer.

## Key Components

- **`MingoSidebarRows`** — Client component that renders two `NavigationSidebarActionRow` entries:
  - **Dashboard** — links to `routes.dashboard`, highlighted when active.
  - **Needs approval** — links to `routes.approvals`, displays a live pending-approval count badge via `usePendingApprovalCount`.
- **`MingoSidebarRowsProps`** — Props interface:
  - `minimized: boolean` — collapses rows into the 56px icon rail (tooltips follow the rail's geometry).
  - `disabled: boolean` — disables navigation (e.g., behind a subscription lock or before session start).

## Usage Example

```typescript
import { MingoSidebarRows } from './mingo-sidebar-rows';

function SidebarTopSlot() {
  const [minimized, setMinimized] = useState(false);
  const isLocked = !useHasActiveSubscription();

  return (
    <MingoSidebarRows minimized={minimized} disabled={isLocked} />
  );
}
```

**Notes:**
- Both rows close the mobile menu on click via `closeMobileMenu`, since clicking a row that's already on the current page won't trigger the layout's automatic navigation-based close.
- Active state is determined by exact path match or path prefix match (`pathname.startsWith(`${path}/`)`), supporting nested routes under `dashboard` or `approvals`.
- The "New chat" row is handled separately by `MingoNewChatRow`, positioned above the chat history rather than here.
