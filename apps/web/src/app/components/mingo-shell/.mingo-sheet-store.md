Zustand store that manages the Mingo conversation sheet's state in the Mingo-first shell — tracking whether the floating chat sheet or phone chat list is open, its dragged height, and page-navigation bookkeeping needed to restore context (last page, outside page, new-chat page) across reloads and route changes.

## Key Components

- **`useMingoSheetStore`** — the main Zustand hook/store exposing state (`open`, `listOpen`, `height`, `node`, `lastPage`, `outsidePage`, `newChatPage`, etc.) and actions:
  - `show()` / `hide()` — open/close the sheet immediately.
  - `showList()` / `hideList()` — open/close the phone chat list.
  - `showAfterNavigation()` / `showListAfterNavigation()` — defer opening until the next route change lands, recording `askedFrom` so the sheet/list appears from the first frame of the new page.
  - `navigated(listCanShow?)` — called on route change; promotes any "after navigation" flags into actual open state and clears pending flags.
  - `setHeight(height)` / `resetHeight()` — persist/clear the user-dragged sheet height (`localStorage`).
  - `setNode(node)` — registers the sheet's DOM node for portaling the chat thread.
  - `openFull()` — transitions to the full chat page without flashing the underlying page.
  - `rememberPage(href)`, `rememberOutsidePage(href)`, `rememberNewChatPage()` — persist navigation context to `sessionStorage` for reload-safe "back" behavior.
- **`isSheetUp(state, pathname)`** — helper to determine if the sheet should render as open for a given pathname, accounting for pending "after navigation" opens.
- **`isListUp(state, pathname)`** — same logic as `isSheetUp`, but for the phone chat list.

## Usage Example

```typescript
import { useMingoSheetStore, isSheetUp } from './mingo-sheet-store';

function MingoComposerSheet({ pathname }: { pathname: string }) {
  const state = useMingoSheetStore();
  const sheetVisible = isSheetUp(state, pathname);

  return sheetVisible ? (
    <div ref={el => state.setNode(el)}>
      {/* chat thread portaled here */}
    </div>
  ) : null;
}

// Opening the sheet from a "Getting Started" chip, effective after navigation:
useMingoSheetStore.getState().showAfterNavigation();

// On route change (e.g., in a router effect):
useMingoSheetStore.getState().navigated(/* listCanShow */ true);

// Resizing the sheet:
useMingoSheetStore.getState().setHeight(420);
```
