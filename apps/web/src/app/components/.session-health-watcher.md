# session-health-watcher.tsx

A headless React component that restores session health after a paused state—resuming background polling and triggering session revalidation once the subscription gate is open.

## Key Components

- **`SessionHealthWatcher`** — Headless (renders `null`) React component that:
  - Resumes any previously paused session polls via `resumeSessionPolls(queryClient)` on mount, using React Query's `QueryClient` instance.
  - Starts session revalidation via `startSessionRevalidation()`, but only once the subscription gate is open (`useSubscriptionOpen()`), since this is treated as background traffic.
  - Must be mounted **below** `SubscriptionGuard` in the component tree, as it depends on `useSubscriptionOpen` to gate the revalidation effect.

## Usage Example

```typescript
import { SubscriptionGuard } from './subscription-lock/subscription-guard';
import { SessionHealthWatcher } from './session-health-watcher';

export function AppProviders({ children }: { children: React.ReactNode }) {
  return (
    <SubscriptionGuard>
      <SessionHealthWatcher />
      {children}
    </SubscriptionGuard>
  );
}
```

This component is intended to be mounted once near the root of the authenticated app shell. It has no props and no visual output—its sole responsibility is to synchronize side effects related to session health:

1. On mount, it immediately resumes any session polls that were paused by the session-health gate (see `session-health.ts`).
2. Whenever the subscription becomes "open," it kicks off session revalidation to confirm the session is still valid, cleaning up the revalidation process automatically when the subscription closes or the component unmounts.
