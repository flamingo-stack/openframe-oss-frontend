# approval-decisions.ts

A cross-surface, framework-agnostic store that tracks approval request decisions (`approved`/`rejected`) and synchronizes related React Query caches so all UI surfaces (tickets board, Mingo chat, Needs approval page) immediately reflect settled approvals without waiting for their own data sources to refetch.

This module is deliberately kept free of the query client in its decision-tracking store, since the mutation service (`ticketService.resolveApprovalRequest`) that calls `noteApprovalDecision` is imported widely and must stay lightweight.

## Key Components

- **`ApprovalDecision`** — Type alias: `'approved' | 'rejected'`.
- **`useApprovalDecisionsStore`** — Zustand store holding a map of approval request IDs to decisions.
- **`noteApprovalDecision(approvalRequestId, approved)`** — Records a settled decision; called by the resolve mutation after the server accepts it. Skips the update if the decision is unchanged (avoids unnecessary re-renders).
- **`useApprovalDecisions()`** — React hook returning the live map of all decisions made in the current tab.
- **`clearApprovalDecisions()`** — Test-only helper to reset the store.
- **`settleApprovalCaches(queryClient, approvalRequestId)`** — Imperatively updates React Query caches (tickets board columns and Mingo dialog lists) to remove the `pendingApproval` flag for the matching request, and invalidates affected ticket detail queries.

## Usage Example

```typescript
import { noteApprovalDecision, settleApprovalCaches, useApprovalDecisions } from './approval-decisions';
import { useQueryClient } from '@tanstack/react-query';

// After a successful resolve mutation:
function onApprovalResolved(approvalRequestId: string, approved: boolean, queryClient: QueryClient) {
  noteApprovalDecision(approvalRequestId, approved);
  settleApprovalCaches(queryClient, approvalRequestId);
}

// In a component (e.g., Needs approval page) to react to decisions:
function NeedsApprovalList() {
  const decisions = useApprovalDecisions();

  return pendingRequests.filter(req => !decisions[req.id]);
}

// In tests:
import { clearApprovalDecisions } from './approval-decisions';

afterEach(() => {
  clearApprovalDecisions();
});
```
