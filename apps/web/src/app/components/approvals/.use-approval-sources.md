## Overview

`use-approval-sources.ts` provides React hooks that aggregate and paginate all sources of pending approvals in the app — unread approval notifications, Mingo chats awaiting approval, and Tech Required tickets — exposing them as a single unified list for the "Needs approval" page and sidebar badge.

## Key Components

- **`useApprovalSources()`** — Main hook. Runs three `useInfiniteQuery` calls (notifications, dialogs, tickets), merges their loading/error/pagination state via `combined()`, and auto-refreshes via `useApprovalRefreshSignal`. Returns `ApprovalSourcesResult` with `sources`, `status`, `totals`, and `techRequiredStatusId`.
- **`useApprovalRefreshSignal(enabled, onChange)`** — Watches chat dialogs, notifications, and local decisions for changes invisible to the polling queries, and fires `onChange` when something moves (skips the initial render).
- **`SourceStatus`** — Interface describing a single paged source's loading/error/pagination state.
- **`ApprovalTotals`** — Server-reported counts per section (`requests`, `tickets`), `null` once fully paged in.
- **`ApprovalSourcesResult`** — Combined return shape: `sources`, `status`, `totals`, `techRequiredStatusId`.
- **`combined(...statuses)`** — Merges multiple `SourceStatus` objects into one (loading if any loading, error from first found, etc.).
- **Constants** — `APPROVALS_POLL_MS`, `APPROVAL_NOTIFICATIONS_QUERY_KEY`, `approvalTicketsQueryKey(laneId)`, `APPROVAL_TICKETS_PAGE_SIZE`.

## Usage Example

```typescript
import { useApprovalSources } from './use-approval-sources';

function ApprovalInboxPage() {
  const { sources, status, totals } = useApprovalSources();

  if (status.isLoading) return <ApprovalListSkeleton />;
  if (status.error) return <ErrorBanner {...status.error} />;

  return (
    <>
      <ApprovalList
        notifications={sources.notifications}
        dialogs={sources.dialogs}
        tickets={sources.tickets}
      />
      {status.hasMore && (
        <LoadMoreButton loading={status.isLoadingMore} onClick={status.loadMore} />
      )}
    </>
  );
}
```

This hook is intended for use within Next.js client components (`'use client'`) that render the approvals inbox or a badge reflecting pending approval counts.
