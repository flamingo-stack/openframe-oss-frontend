# approval-dialogs-query.ts

Defines GraphQL queries, filters, and fetch functions for retrieving Mingo chats ("dialogs") that are awaiting approval, powering the "Needs approval" page. Approval notifications are sent to all active admins, so this module queries across all admins' open chats that have a pending approval request.

## Key Components

- **`APPROVAL_DIALOGS_QUERY`** — GraphQL query fetching paginated dialogs with their `pendingApproval` data, including tool calls and policy review selections (via `POLICY_REVIEW_SELECTION`).
- **`APPROVAL_DIALOGS_COUNT_QUERY`** — Lightweight query that returns only `filteredCount`, used for badge counts (e.g., sidebar).
- **`APPROVAL_DIALOGS_FILTER`** — Shared filter constant: admin-type agents, open statuses (`ACTION_REQUIRED`, `ACTIVE`, `ON_HOLD`), scope `ALL`, and `hasPendingApproval: true`.
- **`APPROVAL_DIALOGS_QUERY_KEY`** — Cache key (`['mingo-dialogs', 'approvals']`) scoped under the `mingo-dialogs` prefix so rename/archive/create mutations invalidate it correctly, while staying distinct from the chat list's `['mingo-dialogs', 'list']` key.
- **`APPROVAL_DIALOGS_PAGE_SIZE`** — Page size constant (`20`).
- **`ApprovalDialogNode`**, **`ApprovalDialogsPage`** — Typed shapes for a single dialog node and a paginated result set.
- **`fetchApprovalDialogs(after)`** — Async function that POSTs to `/chat/graphql`, returning a page of dialogs with pagination info and total count.
- **`fetchApprovalDialogsCount()`** — Async function returning just the total number of pending-approval dialogs.

## Usage Example

```typescript
import {
  fetchApprovalDialogs,
  fetchApprovalDialogsCount,
  APPROVAL_DIALOGS_QUERY_KEY,
} from '@/app/(app)/mingo/queries/approval-dialogs-query';
import { useInfiniteQuery, useQuery } from '@tanstack/react-query';

// Paginated list of dialogs needing approval
const dialogsQuery = useInfiniteQuery({
  queryKey: APPROVAL_DIALOGS_QUERY_KEY,
  queryFn: ({ pageParam }) => fetchApprovalDialogs(pageParam),
  initialPageParam: undefined as string | undefined,
  getNextPageParam: (lastPage) =>
    lastPage.pageInfo.hasNextPage ? lastPage.pageInfo.endCursor ?? undefined : undefined,
});

// Sidebar badge count
const countQuery = useQuery({
  queryKey: [...APPROVAL_DIALOGS_QUERY_KEY, 'count'],
  queryFn: fetchApprovalDialogsCount,
});
```
