## approval-inbox.ts

Builds the unified "Needs approval" inbox by merging three server-filtered sources — unread approval notifications, pending Mingo chat approvals, and Tech Required tickets awaiting approval — into a single deduplicated, newest-first list of `ApprovalCard`s. Each card renders as the shared library's `Notification` tile, whether backed by a real notification or synthesized from a chat/ticket.

## Key Components

- **`ApprovalCard`** — Normalized card shape: `approvalRequestId`, `notification`, `notificationId`, `dialogId`, `ticketId`, `createdAt`, `pending`.
- **`ApprovalSources`** — Input bundle: `notifications`, `dialogs`, `tickets` (nullable for OSS), `decisions`, `chatTitles`.
- **`ApprovalInbox`** — Output: `cards` (newest first) and `pendingCount`.
- **`composeApprovalInbox(sources, kept?)`** — Main entry point; merges sources into one deduplicated list, preferring the real notification's copy (with guardrail `policyReview` merged in from chat/ticket twins), and preserving `kept` cards that were decided on-page.
- **`techRequiredStatusId(statuses)`** — Finds the tenant's system Tech Required status id.
- **`untitledRequestName(notification, chatTitles)`** — Resolves a better display name for backend-titled "Approval required" requests.
- **`decidedCard(card, decision, resolvedByName)`** — Produces the post-decision card variant (shows status tag + resolver name).
- Internal helpers: `notificationCard`, `dialogCard`, `ticketCard`, `builtCard`, `withPolicyReviews`, `withChatTitle`, `namedRequest`, `isTechnicianApproval`, `epochOf`, `requestSummary`, `newestFirst`.

## Usage Example

```typescript
import { composeApprovalInbox, techRequiredStatusId } from './approval-inbox';

const techStatusId = techRequiredStatusId(ticketStatuses);

const inbox = composeApprovalInbox(
  {
    notifications: unreadApprovalNotifications,
    dialogs: pendingMingoDialogs,
    tickets: techRequiredTickets, // or null in OSS builds
    decisions: settledDecisionsByRequestId,
    chatTitles: sidebarChatTitlesByDialogId,
  },
  keptDecidedCards, // cards decided on this page, kept visible
);

console.log(inbox.pendingCount);
inbox.cards.forEach(card => renderApprovalTile(card.notification));
```

Use `untitledRequestName` to improve display titles and `decidedCard` to transition a card to its resolved state after the user approves/rejects on the page itself.
