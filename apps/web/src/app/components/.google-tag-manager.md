Client-side React component that injects the Google Tag Manager (GTM) script and noscript fallback into a Next.js application.

## Key Components

- **`GoogleTagManager`** — Named export component that renders the GTM loader script using Next.js `<Script>` with `afterInteractive` strategy, plus a `<noscript>` iframe fallback for environments with JavaScript disabled.
- **`GoogleTagManagerProps`** — Interface accepting an optional `containerId` string; falls back to `runtimeEnv.gtmContainerId()` if not provided.
- **`useEffect`** — Initializes `window.dataLayer` array on mount when a valid container ID is present.

## Behavior

- Returns `null` (renders nothing) if no container ID is resolved from props or runtime config.
- Uses `dangerouslySetInnerHTML` to inject the standard GTM bootstrap snippet inline, loaded asynchronously after page hydration.

## Usage Example

```typescript
// app/layout.tsx
import { GoogleTagManager } from '@/components/google-tag-manager';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        {/* Uses GTM_CONTAINER_ID from runtime config automatically */}
        <GoogleTagManager />

        {/* Or pass an explicit container ID */}
        <GoogleTagManager containerId="GTM-XXXXXXX" />

        {children}
      </body>
    </html>
  );
}
```

> The container ID resolution order is: `containerId` prop → `runtimeEnv.gtmContainerId()`. If neither resolves to a value, the component renders nothing and no GTM scripts are injected.
