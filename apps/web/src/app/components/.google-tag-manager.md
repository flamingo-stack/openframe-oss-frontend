Client-side React component that injects Google Tag Manager (GTM) into the application, initializing the `dataLayer` queue and conditionally rendering a `<noscript>` fallback for non-JS environments.

## Key Components

- **`GoogleTagManager`** — Default-exported React component that renders the GTM bootstrap script.
  - **Props:**
    - `containerId?: string` — Optional GTM container ID; falls back to `runtimeEnv.gtmContainerId()` if not provided.
    - `noscriptFallback: boolean` — Controls whether the `<noscript>` iframe fallback is rendered. Must be disabled in static-export builds, since the container ID is injected at runtime by the shell, which would cause a client/server markup mismatch (React hydration error #418) if the `<noscript>` tag were rendered unconditionally.
  - **Behavior:**
    - Returns `null` if no container ID is resolved (GTM disabled).
    - On mount, initializes `window.dataLayer` and calls `queueDesktopPostHogSetup()` to queue PostHog setup for desktop builds.
    - Injects the GTM bootstrap snippet via `next/script` with `strategy="afterInteractive"` to avoid blocking page render.

## Usage Example

```typescript
import { GoogleTagManager } from '@/components/google-tag-manager';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        {/* Enable noscript fallback only for standard SSR builds, not static export */}
        <GoogleTagManager noscriptFallback={!isStaticExport} />
        {children}
      </body>
    </html>
  );
}
```

```typescript
// Overriding the container ID explicitly (e.g., for testing)
<GoogleTagManager containerId="GTM-XXXXXXX" noscriptFallback={true} />
```
