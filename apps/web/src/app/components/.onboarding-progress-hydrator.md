## Overview

A headless React component that keeps the onboarding progress store hydrated for its entire mount lifetime. It renders nothing and is intended to be mounted once in the app shell, after the session has resolved, so onboarding GraphQL queries only fire when the feature is active.

## Key Components

- **`OnboardingProgressHydrator`** — Function component with no props. Subscribes to `isLoaded` from `useOnboardingStore` and triggers `refreshOnboardingProgress` via the Relay environment whenever the store is not loaded. Always returns `null`.

## Behavior Notes

- **Driven by `isLoaded`, not by mount.** The effect is keyed on `isLoaded` (and the Relay `environment` singleton), so it self-heals after any store reset — including ones triggered by `auth-store.logout()`/`forceLogout` — without needing the component to unmount and remount.
- **Non-suspending and fail-safe.** The fetch happens inside `useEffect`; `refreshOnboardingProgress` is responsible for marking the store as loaded even on error or a null payload, so the app chrome never blocks indefinitely waiting on onboarding data.
- **Cannot spin.** An in-flight fetch leaves `isLoaded` false without re-triggering the effect, and every terminal outcome of `refreshOnboardingProgress` eventually sets `isLoaded` to `true`.

## Usage Example

```typescript
// Mount once in the app shell, after the session has resolved
import { OnboardingProgressHydrator } from '@/components/onboarding-progress-hydrator';

export function AppShell({ children }: { children: React.ReactNode }) {
  return (
    <>
      <OnboardingProgressHydrator />
      {children}
    </>
  );
}
```

```typescript
// The store it hydrates can then be read anywhere in the tree
import { useOnboardingStore } from '@/stores/onboarding-store';

function Sidebar() {
  const isLoaded = useOnboardingStore(state => state.isLoaded);
  const progress = useOnboardingStore(state => state.progress);

  if (!isLoaded) return <SidebarSkeleton />;
  return <OnboardingChecklist progress={progress} />;
}
```
