Headless client component that hydrates the onboarding progress store exactly once on mount by fetching data via Relay.

## Key Components

- **`OnboardingProgressHydrator`** — A render-nothing React component (`return null`) that calls `refreshOnboardingProgress` in a `useEffect` on mount, using the current Relay environment.

## Usage Example

```typescript
// Mounted in the app shell once the session has resolved
import { OnboardingProgressHydrator } from './onboarding-progress-hydrator';

function AppShell({ sessionReady }: { sessionReady: boolean }) {
  return (
    <>
      {sessionReady && <OnboardingProgressHydrator />}
      {/* rest of shell */}
    </>
  );
}
```

## Notes

- **Non-suspending** — the fetch runs inside `useEffect`, so it never blocks rendering or triggers a Suspense boundary.
- **Graceful degradation** — errors are handled inside `refreshOnboardingProgress`; this component has no error boundary requirement.
- **Session gated** — only mounted once `/me` has answered, so the onboarding queries never fire on an unresolved credential.
- **`'use client'`** — marked as a Client Component; `useRelayEnvironment` and `useEffect` require browser context.
