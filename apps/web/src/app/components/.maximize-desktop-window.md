This client component triggers the desktop shell to maximize its window on first mount, used as a mounting side-effect for full-screen onboarding flows (sign-in, registration, setup wizard).

## Key Components

- **`MaximizeDesktopWindow`** — A React functional component that renders nothing (`null`). On mount, it calls `maximizeDesktopWindow()` from `@/lib/native-shell` inside a `useEffect` hook, triggering the native desktop shell to maximize its window. On web or mobile platforms, this call is expected to be a no-op.

## Usage Example

Mount the component once at the root of a full-screen onboarding flow so the window maximizes immediately and remains maximized through subsequent steps:

```typescript
import { MaximizeDesktopWindow } from '@/components/maximize-desktop-window';

export default function OnboardingLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <MaximizeDesktopWindow />
      {children}
    </>
  );
}
```

Since the effect only runs once on mount (empty dependency array), place this component at the top-level layout of a multi-step flow (e.g., sign-in → registration → setup wizard) rather than on each individual step, to avoid redundant calls and ensure the maximize behavior triggers only at the start of the flow.
