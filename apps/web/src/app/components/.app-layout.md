## app-layout.tsx

The top-level application shell component that composes authentication state, navigation (Mingo and OSS/SaaS modes), billing status, onboarding, and session health into a single layout wrapper for the app's authenticated routes.

## Key Components

- **`CHROME_LOADING_FAIL_OPEN_MS`** — Constant (10,000ms) defining the maximum time the shell waits for async data (feature flags, session) before rendering with defaults rather than hanging indefinitely.
- **`useFailOpen(loading, afterMs)`** — Hook implementing a "fail-open" latch: returns `true` while loading, but automatically flips to `false` after a timeout so the UI never gets stuck in a permanent loading state, even if an expected resolution event never fires.
- **`BareAppShell`** — Minimal full-screen shell used for routes like `/setup` that need the native safe-area root wrapper but no navigation chrome.
- **`AppShell`** — The main shell component. Determines SaaS vs. OSS mode (`isSaasTenantMode`), selects Mingo vs. dashboard navigation, resolves auth/session state via `useAuthSession` and `useAuthStore`, wires up navigation callbacks, logout confirmation, native back-button dismissal, and notifications context integration.
- Integrates many sub-shells: `ManhattanCentre`, `ManhattanChatsSection`, `MingoComposerDock`, `SubscriptionGuard`, `SessionHealthWatcher`, `UnauthorizedOverlay`, `BillingBarsHydrator`, `OnboardingCoachMark`, and others, composing the full authenticated application frame.

## Usage Example

```typescript
import { AppShell } from '@/app/components/app-layout';

export default function AuthenticatedLayout({ children }: { children: React.ReactNode }) {
  return (
    <AppShell mainClassName="custom-main-class">
      {children}
    </AppShell>
  );
}
```

The exported shell is typically used as the root layout wrapper for routes under the `(app)` segment, automatically adapting its navigation and chrome (Mingo-first vs. dashboard-first) based on tenant mode, while gating data-fetching children on session readiness to avoid premature authenticated requests.
