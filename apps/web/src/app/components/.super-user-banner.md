# super-user-banner.tsx

Renders a persistent visual banner across the application when the authenticated user is a super user, displaying the currently viewed tenant's name and environment label. It handles loading states and query failures gracefully so the banner never disrupts the shell it's rendered over.

## Key Components

- **`SuperUserBanner`** — Public entry point component. Reads `isSuperUser` from the auth store (`/me`) and renders nothing for normal tenant users. Mounting is gated on the session having resolved, preventing a stale persisted flag from flashing the banner prematurely.
- **`SuperUserBannerBoundary`** — Error boundary class component that catches failures in the tenant name GraphQL lookup. On error, it renders the banner with an empty tenant name instead of unmounting the surrounding shell.
- **`SuperUserBannerContent`** / **`SuperUserBannerContentReader`** / **`SuperUserBannerContentLive`** — Internal composition handling Suspense-based loading (via `useLoadingScope`) and the live GraphQL fetch of `tenantInfo.name` using `useLazyLoadQuery`.
- **`hostLabel()`** — Resolves the environment label from the tenant's bound host (via `runtimeEnv.tenantHostUrl()`), falling back to the page's own hostname when no tenant host is configured.
- **`superUserBannerQuery`** — GraphQL query fetching `tenantInfo.name`, the tenant bound to the current request (distinct from the super user's own tenant).

## Usage Example

```typescript
import { SuperUserBanner } from '@/components/super-user-banner';

export function AppShell({ children }: { children: React.ReactNode }) {
  return (
    <>
      <SuperUserBanner />
      {children}
    </>
  );
}
```

The component is self-contained—no props required. It should be mounted once near the root of the authenticated app layout (including the lock screen) so it consistently overlays every page during a super user session, without requiring conditional rendering logic at the call site.
