# billing-bars.tsx

Defines the app-wide billing announcement bars (AI token balance warnings and trial-ending reminders) along with a Relay-backed hydrator component that resolves their visibility state from a single GraphQL query.

## Key Components

- **`billingBarsQuery`** — GraphQL query fetching subscription status, dates, and AI usage/token data in one request, kept separate from `subscriptionGuardQuery` so a usage-resolution failure only costs a banner, not an app lockout.
- **`AiBalanceBar`** — Non-dismissible top bar shown when AI tokens are low (`warning`) or depleted (`error`). Clicking it (or its CTA) opens the top-up dialog via `onManage`.
- **`TrialEndingBar`** — Dismissible bar shown once a free trial passes its halfway point, showing days remaining with an "Activate Subscription" CTA and a dismiss button.
- **`BillingBarsState`** — Shape describing resolved bar visibility: `ai.tone` (`AiBalanceTone`) and `trial` (`{ daysLeft, token } | null`).
- **`NO_BARS`** — Default/empty `BillingBarsState` constant (no AI warning, no trial bar).
- **`resolveTrial()`** — Pure function computing whether the trial bar should show, based on subscription status and start/end dates; returns `null` unless the trial is past its midpoint and not yet expired.
- **`BillingBarsHydrator`** — Runs `billingBarsQuery` via `useLazyLoadQuery` (must be rendered inside `Suspense`), computes AI tone and trial state, and reports the resolved `BillingBarsState` to a parent via the `onResolved` callback in a `useEffect`.

## Usage Example

```typescript
import { Suspense, useState } from 'react';
import {
  BillingBarsHydrator,
  AiBalanceBar,
  TrialEndingBar,
  NO_BARS,
  type BillingBarsState,
} from './billing-bars';

function AppShell() {
  const [bars, setBars] = useState<BillingBarsState>(NO_BARS);
  const [trialDismissed, setTrialDismissed] = useState(false);

  return (
    <>
      <Suspense fallback={null}>
        <BillingBarsHydrator onResolved={setBars} />
      </Suspense>

      {bars.ai.tone !== 'default' && (
        <AiBalanceBar tone={bars.ai.tone} onManage={() => openBillingDialog()} />
      )}

      {bars.trial && !trialDismissed && (
        <TrialEndingBar
          daysLeft={bars.trial.daysLeft}
          onActivate={() => navigateToActivation()}
          onDismiss={() => setTrialDismissed(true)}
        />
      )}
    </>
  );
}
```

Dismissal state for `TrialEndingBar` should be persisted keyed by `bars.trial.token`, ensuring a dismissal only suppresses the current trial period and not a future one.
