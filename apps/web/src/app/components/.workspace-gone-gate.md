Blocks the application UI with a full-screen "workspace deleted" message when the gateway reports the tenant no longer exists (session health status `gone`), forcing the user to sign out.

## Key Components

- **`WorkspaceGoneGate`** — Gate component that reads `health` from `useSessionHealthStore`. When the status equals `'gone'`, it replaces its `children` entirely with `WorkspaceGoneScreen`, unmounting the app shell (and any pollers/sockets beneath it), analogous to how `AppUpdateGate` handles forced updates.
- **`WorkspaceGoneScreen`** — Internal full-screen component rendering the "Workspace deleted" message and a Sign Out button. On mount, it moves keyboard focus to the heading so assistive technology announces the state change. Clicking Sign Out calls `signOutToLogin` (clearing auth tokens and navigating to the sign-in flow) and then `resetSessionHealth` to clear the stored health status.

## Usage Example

```typescript
import { WorkspaceGoneGate } from '@/app/components/shared/workspace-gone-gate';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <WorkspaceGoneGate>
      {/* Normal app shell, polling, and sockets live here */}
      {children}
    </WorkspaceGoneGate>
  );
}
```

Place `WorkspaceGoneGate` high in the component tree (e.g., near the root layout), above any providers or features that depend on a live tenant, so it can fully replace the tree instead of just overlaying it when the workspace is gone.
