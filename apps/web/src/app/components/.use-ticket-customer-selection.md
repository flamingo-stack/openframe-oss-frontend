# use-ticket-customer-selection.ts

React hook that manages the linked ticket + customer selection logic shared between the time-tracker panel and the manual time-entry modal, enforcing a bidirectional relationship: selecting a customer scopes ticket search results, while selecting a ticket derives and locks the customer.

## Key Components

- **`TicketCustomerSeed`** — interface for initializing/resetting the hook with pre-selected ticket/customer data, including `lockCustomer` (disable due to derivation) and `fixedCustomer` (permanently pin, never auto-clears) flags.
- **`withSeed`** — helper that ensures a previously selected option remains visible in the dropdown even if it falls outside the current search page/results.
- **`useTicketCustomerSelection(options)`** — the main hook, accepting an `enabled` flag to conditionally fetch options (used so hosts can mount it unconditionally without cost when inactive).
  - Returns `ticketId`, `customerId`, `customerLocked`, `ticketOptions`, `customerOptions`, loading flags, search setters, and `selectTicket` / `selectCustomer` / `reset` actions.

**Selection rules:**
- Picking a **customer** first filters ticket search to that organization; changing the customer clears any now-mismatched ticket.
- Picking a **ticket** pins and locks the customer to the ticket's organization (overriding a manually picked customer); clearing the ticket releases the derived customer, unless `fixedCustomer` is set.

## Usage Example

```typescript
import { useTicketCustomerSelection } from '@/app/(app)/tickets/hooks/use-ticket-customer-selection';

function TimeEntryForm({ isPanelOpen }: { isPanelOpen: boolean }) {
  const {
    ticketId,
    customerId,
    customerLocked,
    ticketOptions,
    customerOptions,
    ticketsLoading,
    customersLoading,
    setTicketSearch,
    setCustomerSearch,
    selectTicket,
    selectCustomer,
    reset,
  } = useTicketCustomerSelection({ enabled: isPanelOpen });

  // Seed from a pre-selected ticket (e.g. opened from a ticket detail page)
  useEffect(() => {
    reset({ ticketId: 'TCK-123', ticketLabel: 'Printer issue', lockCustomer: true });
  }, []);

  return (
    <>
      <Autocomplete
        options={customerOptions}
        value={customerId}
        disabled={customerLocked}
        loading={customersLoading}
        onInputChange={setCustomerSearch}
        onChange={selectCustomer}
      />
      <Autocomplete
        options={ticketOptions}
        value={ticketId}
        loading={ticketsLoading}
        onInputChange={setTicketSearch}
        onChange={selectTicket}
      />
    </>
  );
}
```
