# workspace-inactive-screen.tsx

A client-side React component that renders a lock screen displayed when an OpenFrame workspace is inactive and the current viewer has no purchase/billing flow available to them.

## Key Components

- **`WorkspaceInactiveScreen`** — The main exported component. Renders a three-band layout (brand lockup, central message/actions, footer) notifying the user their workspace is inactive, without exposing any purchase or billing CTA.
- **`WorkspaceInactiveScreenProps`** — Prop interface:
  - `title?: string` — Overrides the default heading.
  - `description?: string` — Overrides the default body copy.
  - `action?: ReactNode` — Optional remedy action, rendered leading the action row (e.g., a link to the web billing page).
  - `loading?: boolean` — When true, the description renders as a loading skeleton via `LoadingParagraph`.
- **`DEFAULT_DESCRIPTION`** — Subscription-agnostic fallback copy used when no custom `description` is supplied.

## Usage Example

```typescript
import { WorkspaceInactiveScreen } from './workspace-inactive-screen';

// Default usage — no billing action available (e.g., mobile build)
export function LockedWorkspaceView() {
  return <WorkspaceInactiveScreen />;
}

// Desktop build — include an action pointing to the web billing page
export function LockedWorkspaceViewWithBillingLink() {
  return (
    <WorkspaceInactiveScreen
      action={<a href="https://app.openframe.ai/billing">Open billing</a>}
    />
  );
}

// While the viewer's role/permissions are still being resolved
export function LockedWorkspaceViewLoading() {
  return <WorkspaceInactiveScreen loading />;
}
```

**Design notes:** The component intentionally omits any pricing, plan selection, or purchase CTA to comply with App Store Review Guideline 3.1.1. It offers only a status message, a re-check/sign-out action set (`InactiveScreenActions`), and a footer with `DeleteMyAccountLink` and `PoweredByFlamingo`. It uses `min-h-full` (not `min-h-screen`) since it renders inside the app shell's `<main>` with header/nav still visible but disabled.
