# unpaid-invoices-screen.tsx

A billing lock screen shown to workspaces in `PAST_DUE` or `SUSPENDED` subscription status, listing each outstanding Stripe invoice and offering a direct "Pay Invoice" CTA for the oldest payable one.

Unlike other subscription locks, this screen replaces the plan picker entirely rather than decorating it, since the remedy is paying an existing invoice, not choosing a plan. It is only reached on builds where payment UI is permitted — native builds are redirected to `WorkspaceInactiveScreen` upstream to comply with App Store Guideline 3.1.1.

## Key Components

- **`UnpaidInvoicesScreen`** — Top-level exported component. Wraps everything in an `ErrorBoundary` that falls back to `WorkspaceInactiveScreen` so a query failure never leaves the user with no way out of the lock.
- **`UnpaidInvoicesShell`** — Page frame; renders `LockScreenActions` outside the `Suspense` boundary so open support/delete-account dialogs survive query resolution.
- **`UnpaidInvoicesContent` / `UnpaidInvoicesContentReader` / `UnpaidInvoicesContentLive`** — Loading-scope-aware chain that gates on an external `loading` flag, then on Relay's `useLazyLoadQuery`, fetching `pendingInvoices` with `skipSubscriptionGate: true` (this screen *is* the gate).
- **`UnpaidInvoicesMain`** — Renders title/description copy from `DEBT_COPY`, the list of `OutstandingInvoiceRow`s (or skeletons via `LoadingItems`), and the primary "Pay Invoice" button pointing at the oldest invoice's `hostedInvoiceUrl`.
- **`DEBT_COPY`** — Per-status (`PAST_DUE` / `SUSPENDED`) title/description/"nothing outstanding" copy map.
- **`unpaidInvoicesScreenQuery`** — GraphQL query fetching `subscription.pendingInvoices`, filtered client-side via `isOutstandingInvoice` and sorted via `byOldestFirst`.

## Usage Example

```typescript
import { UnpaidInvoicesScreen } from '@/app/(app)/settings/billing-usage/components/lock-screens/unpaid-invoices-screen';
import { SubscriptionStatus } from '@/generated/schema-enums';

function SubscriptionLockContent({ status }: { status: SubscriptionStatus }) {
  if (status === SubscriptionStatus.PAST_DUE || status === SubscriptionStatus.SUSPENDED) {
    return <UnpaidInvoicesScreen status={status} />;
  }
  // ... other lock states
}
```

Note: callers must ensure native/App Store builds never render this component directly for payment-restricted platforms — route those to `WorkspaceInactiveScreen` instead, per `billing-visibility.ts`.
