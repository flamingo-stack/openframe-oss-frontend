# subscription-lock-copy.ts

Defines the plan-picker/paywall copy shown to users when their OpenFrame subscription requires action (trial expired, canceled, or ending soon). Deliberately isolated from `subscription-status.ts` to avoid pulling plan-and-purchase-specific wording into the mobile bundle's import graph, since mobile renders `WorkspaceInactiveScreen` instead.

## Key Components

- **`PaywallCopy`** — Interface describing the copy shown for a given subscription status: `title`, `description` (plain text, intentionally device-count-free), and optional `checkoutNote` (warns that checkout on an active trial ends it immediately and starts billing).
- **`getPaywallCopy(status)`** — Looks up copy for a `SubscriptionStatus` (`TRIAL_EXPIRED`, `CANCELED`, `TRIAL`), falling back to `DEFAULT_COPY` for any other status.
- **`paywallDescription(copy, deviceCount)`** — Builds the subtitle line. Returns `copy.description` when `deviceCount` is `null` (billing hasn't counted devices yet); otherwise returns a pluralized sentence naming the detected device count.
- **`PLANS_UNAVAILABLE_COPY`** — Static fallback copy shown when the plan catalog fails to load entirely.

## Usage Example

```typescript
import { getPaywallCopy, paywallDescription, PLANS_UNAVAILABLE_COPY } from '@/lib/subscription-lock-copy';
import { SubscriptionStatus } from '@/generated/schema-enums';

const copy = getPaywallCopy(SubscriptionStatus.TRIAL);

console.log(copy.title); // "Activate your subscription"
console.log(copy.checkoutNote); // Warns that checkout ends the trial today

// Rendering the subtitle, with or without a known device count
const subtitle = paywallDescription(copy, 5);
// "We've detected 5 active devices in your OpenFrame instance that require a subscription to continue management."

const subtitleNoCount = paywallDescription(copy, null);
// Falls back to copy.description: "Pick a plan now and keep everything running when the trial ends."

// Catalog failure fallback
if (!plansLoaded) {
  showMessage(PLANS_UNAVAILABLE_COPY.title, PLANS_UNAVAILABLE_COPY.description);
}
```

**Note:** This module must only be imported by lazily-loaded plan-lock content and the subscription page — never by app-wide guards/context, to keep it out of mobile bundles.
