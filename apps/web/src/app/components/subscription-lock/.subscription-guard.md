## Purpose

This file implements a React/Relay-based subscription gating system that determines whether a workspace's subscription is active, locked, or still resolving — and publishes that state both to the React tree (via context) and to the network layer (via a request gate), without ever unmounting or remounting the app shell.

## Key Components

- **`SubscriptionGuard`** — Top-level provider component. Resolves subscription status from a feature flag gate, a trial-expiry error signal, or a lazy-loaded GraphQL query, and provides the resolved state via React context. Deliberately avoids Suspense/redirects at this level to prevent double-mounting the app shell.
- **`useSubscriptionLock()`** — Hook that reads the current `SubscriptionLockState` (`status`, `isLocked`, `isResolved`). Falls back to an "active/unlocked" state when no guard is present above it (e.g., auth screens).
- **`useSubscriptionOpen()`** — Hook for background/non-user-initiated traffic (timers, polling) to check if it's safe to fire. Fails closed (returns `false`) if mounted outside `SubscriptionGuard`, logging a dev warning.
- **`SubscriptionStatusHydrator`** (internal) — Runs the actual `useLazyLoadQuery` call inside a `HydratorBoundary`/Suspense, reporting the resolved status up via callback instead of suspending the parent tree.
- **`SubscriptionLockState`** (interface) — Shape of the published state: `status`, `isLocked`, `isResolved`.

## Usage Example

```typescript
// In app-layout.tsx
import { SubscriptionGuard, useSubscriptionLock } from '@/app/subscription-guard';

function AppLayout({ children }: { children: ReactNode }) {
  return (
    <SubscriptionGuard>
      <PageContent>{children}</PageContent>
    </SubscriptionGuard>
  );
}

function PageContent({ children }: { children: ReactNode }) {
  const { isLocked, isResolved } = useSubscriptionLock();
  if (!isResolved) return <Skeleton />;
  return isLocked ? <PaywallScreen /> : <>{children}</>;
}

// In a background component mounted BELOW SubscriptionGuard
function PresenceReporter() {
  const canSendTraffic = useSubscriptionOpen();
  useEffect(() => {
    if (!canSendTraffic) return;
    const id = setInterval(recordPresence, 10000);
    return () => clearInterval(id);
  }, [canSendTraffic]);
  return null;
}
```
