## subscription-status.ts

Defines subscription-status logic used by the app-wide subscription lock guard, re-exporting the backend-generated `SubscriptionStatus` enum and providing helpers to resolve, classify, and route around locked statuses.

This module deliberately contains only status *logic* — no UI copy. Lock screen text lives separately in `subscription-lock-copy.ts` so that wording doesn't bloat the import graph of the app-wide guard/context that depends on this file.

## Key Components

- **`SubscriptionStatus`** — re-exported enum mirroring the backend's `schema.graphql` (generated via `npm run generate-enums`). Includes `TRIAL`, `TRIAL_EXPIRED`, `ACTIVE`, `CANCELED`, `PAST_DUE`, `SUSPENDED`.
- **`resolveSubscriptionStatus(rawStatus)`** — safely converts an untyped/nullable string (e.g., from an API response) into a known `SubscriptionStatus`, defaulting to `ACTIVE` if unrecognized.
- **`isLockingStatus(status)`** — returns `true` for statuses that lock the app: `TRIAL_EXPIRED`, `CANCELED`, `PAST_DUE`, `SUSPENDED`.
- **`isRouteOpenWhileLocked(pathname, status)`** — determines whether a given route should remain accessible despite a locked subscription (e.g., `/checkout/*` always, `/settings/billing-usage` only when `PAST_DUE`).

## Usage Example

```typescript
import {
  resolveSubscriptionStatus,
  isLockingStatus,
  isRouteOpenWhileLocked,
  SubscriptionStatus,
} from './subscription-status';

const status = resolveSubscriptionStatus(user.subscriptionStatus);

if (isLockingStatus(status)) {
  const pathname = usePathname();

  if (!isRouteOpenWhileLocked(pathname, status)) {
    // Redirect to the appropriate lock screen based on `status`
    // e.g., PAST_DUE/SUSPENDED -> UnpaidInvoicesScreen
    //       TRIAL_EXPIRED/CANCELED -> plan picker lock screen
  }
}
```

**Note:** The two debt statuses, `PAST_DUE` and `SUSPENDED`, represent sequential stages of one unpaid invoice. `PAST_DUE` locks the dashboard but keeps agent traffic flowing and allows billing access to resolve payment. `SUSPENDED` (after ~30 days) locks everything, including agents and billing.
