Re-exports the `SubscriptionStatus` enum and provides utilities for resolving raw status strings and retrieving UI copy for subscription lock screens.

## Key Components

- **`SubscriptionStatus`** — Re-exported backend enum with values: `ACTIVE`, `TRIAL`, `TRIAL_EXPIRED`, `CANCELED`, `PAST_DUE`, `SUSPENDED`. `TRIAL_EXPIRED` and `CANCELED` lock the app; `PAST_DUE` and `SUSPENDED` allow access with an inline billing CTA.
- **`SubscriptionLockCopy`** — Interface defining `title`, `description`, and `ctaLabel` strings for the full-screen subscribe gate.
- **`resolveSubscriptionStatus(rawStatus)`** — Safely coerces an unknown string (e.g., from an API response) to a valid `SubscriptionStatus`, falling back to `ACTIVE`.
- **`getLockCopy(status)`** — Returns `SubscriptionLockCopy` for locking statuses (`TRIAL_EXPIRED`, `CANCELED`), or `null` for all others.

## Usage Example

```typescript
import { resolveSubscriptionStatus, getLockCopy } from '@/lib/subscription-status';

const status = resolveSubscriptionStatus(org.subscriptionStatus);

const lockCopy = getLockCopy(status);
if (lockCopy) {
  // Render full-screen lock gate
  showLockScreen(lockCopy.title, lockCopy.description, lockCopy.ctaLabel);
}
```

> **Note:** `PAST_DUE` and `SUSPENDED` return `null` from `getLockCopy` — handle these inline on the billing page with a "Pay Overage" CTA rather than locking the app.
