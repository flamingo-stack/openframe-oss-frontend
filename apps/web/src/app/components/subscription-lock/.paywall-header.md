# paywall-header.tsx

Renders the header UI for the subscription paywall screen, splitting the title and device-count subtitle into separately mountable pieces so the title can render above a Suspense boundary (independent of billing data) while the subtitle renders inside it (dependent on billing data).

## Key Components

- **`PaywallDescription`** — Shared "fleet" description line used both in the full-page paywall and the activate-subscription modal. Renders a loading-aware paragraph (`LoadingParagraph`) showing the device count once billing resolves, with configurable line-count estimates for layout stability.
- **`PaywallTitle`** — The paywall's page-level heading (replaces standard page chrome). Renders the plan title plus a `LockScreenActionsMenu` ("…" menu) for support/delete-account actions. Designed to render *outside* the page's Suspense boundary since it has no billing dependency.
- **`PaywallSubtitle`** — Wraps `PaywallDescription` with layout compensation (negative margin + padding) to visually reconnect it to `PaywallTitle` despite being rendered inside the Suspense boundary.
- **`MODAL_DESCRIPTION_LINES`** / **`PAGE_DESCRIPTION_LINES`** — Internal constants estimating wrapped line counts for the description text, used to reserve space during loading and avoid layout shift.

## Usage Example

```typescript
import { PaywallTitle, PaywallSubtitle, PaywallDescription } from './paywall-header';
import { Suspense } from 'react';

function PaywallPage({ copy }: { copy: PaywallCopy }) {
  return (
    <div>
      {/* Renders immediately; no billing dependency */}
      <PaywallTitle copy={copy} />

      <Suspense fallback={<PaywallSubtitle copy={copy} loading />}>
        <BillingResolvedSubtitle copy={copy} />
      </Suspense>
    </div>
  );
}

async function BillingResolvedSubtitle({ copy }: { copy: PaywallCopy }) {
  const deviceCount = await fetchDeviceCount();
  return <PaywallSubtitle copy={copy} deviceCount={deviceCount} />;
}

// Reused in the activate-subscription modal with default (2-line) sizing
function ActivateSubscriptionModal({ copy, deviceCount }: { copy: PaywallCopy; deviceCount: number | null }) {
  return <PaywallDescription copy={copy} deviceCount={deviceCount} />;
}
```
