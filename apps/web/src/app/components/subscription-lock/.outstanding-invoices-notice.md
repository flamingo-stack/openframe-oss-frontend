# outstanding-invoices-notice.tsx

A React component that displays a paywall-level notice when a tenant has unpaid invoices from a prior subscription, allowing payment access even when the app is otherwise locked out.

## Key Components

- **`outstandingInvoicesNoticeFragment`** — GraphQL fragment defined on the root `Query` type, fetching the subscription's `pendingInvoices` so the paywall query can resolve both plan data and amounts owed in a single request.
- **`OutstandingInvoicesNotice`** — Exported component that:
  - Reads invoice data via `useFragment` from a nullable fragment key.
  - Maps raw invoices through `toInvoiceRow`, filters with `isOutstandingInvoice`, and sorts via `byOldestFirst`.
  - Renders `null` when there are no outstanding invoices (loading or fully paid states).
  - Resolves a `payUrl` from the oldest invoice that has a `hostedInvoiceUrl` (Stripe-finalized invoices only).
  - Renders a warning banner with singular/plural copy, a "Pay Invoice" button (disabled if no payable URL exists), and a list of `OutstandingInvoiceRow` items.

## Usage Example

```typescript
import { OutstandingInvoicesNotice } from './outstanding-invoices-notice';
import type { outstandingInvoicesNotice_query$key } from '@/__generated__/outstandingInvoicesNotice_query.graphql';

function BillingPaywall({ query }: { query: outstandingInvoicesNotice_query$key | null }) {
  return (
    <div>
      <OutstandingInvoicesNotice query={query} />
      {/* other paywall content */}
    </div>
  );
}
```

This component is typically rendered inside a billing/paywall page where the tenant's subscription access is restricted but outstanding invoice payment must still be reachable. It relies on `invoice-row` helpers and the sibling `OutstandingInvoiceRow` component for per-invoice rendering.
