# outstanding-invoice-row.tsx

Renders a single outstanding (unpaid) invoice row used in billing/paywall screens, along with helper functions for sorting and overdue detection.

## Key Components

- **`OutstandingInvoiceRow`** — React component rendering an invoice row with invoice number/date, due date, amount, status tag (Overdue/Unpaid), and an external link button to Stripe's hosted invoice page. Supports a loading state (skeleton placeholders) when `invoice` is `null` or a loading scope is active.
- **`isOverdue(invoice: InvoiceRow): boolean`** — Internal helper that determines whether an invoice's due date has passed. Invoices with no `dueDate` (e.g., auto-charged by Stripe) are never considered overdue.
- **`byOldestFirst(a: InvoiceRow, b: InvoiceRow): number`** — Exported comparator for sorting invoices oldest-first, preferring `dueDate` and falling back to `createdAt` when no due date exists.
- **`dateValue(iso)`** — Internal helper converting an ISO date string to a millisecond timestamp, defaulting to `Number.POSITIVE_INFINITY` for missing/invalid dates so such invoices sort last.

## Usage Example

```typescript
import { OutstandingInvoiceRow, byOldestFirst } from './outstanding-invoice-row';
import type { InvoiceRow } from '@/app/(app)/settings/billing-usage/components/shared/invoice-row';

function OutstandingInvoicesList({ invoices }: { invoices: InvoiceRow[] }) {
  const sorted = [...invoices].sort(byOldestFirst);

  return (
    <div className="flex flex-col gap-2">
      {sorted.map((invoice) => (
        <OutstandingInvoiceRow key={invoice.invoiceNumber ?? invoice.createdAt} invoice={invoice} />
      ))}
    </div>
  );
}

// Loading state usage — pass null to render skeleton placeholders
function LoadingRow() {
  return <OutstandingInvoiceRow invoice={null} />;
}
```

The component relies on `useLoadingScope` from `@flamingo-stack/openframe-frontend-core` to automatically detect ambient loading state, and uses `InfoCell` to render labeled value cells with consistent skeleton widths while data is pending.
