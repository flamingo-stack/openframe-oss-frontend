Renders an advisory modal that notifies the user a newer app version is available in the store, offering the choice to update now or dismiss the nudge for the day.

## Key Components

- **`UpdateAvailableModal`** — The main exported component. Reads the available update version from `useAppUpdateStore`, renders `null` when no update is pending, and otherwise displays a `SimpleModal` with the version info and action buttons.
- **`useNativeBackDismissible`** — Wires the native back button/gesture (on mobile) to dismiss the modal via `dismissUpdateNudge` whenever the modal is open.
- **`dismissUpdateNudge`** — Called on "Not Now" or native back dismiss; snoozes the nudge for the current version for one day (logic lives in `version-check.ts`).
- **`openStore`** — Called on "Update"; opens the platform app store listing.
- **`StoreUpdateRow`** — Child component rendered inside the modal body, presumably showing store-specific update details/actions.

## Usage Example

```typescript
import { UpdateAvailableModal } from '@/app/components/update-available-modal';

export function RootLayout() {
  return (
    <>
      {/* Rendered globally; shows itself only when an update is detected */}
      <UpdateAvailableModal />
      {/* rest of the app */}
    </>
  );
}
```

The component requires no props — it is self-contained, driven entirely by `useAppUpdateStore` state. Simply mount it once near the root of the app so it can appear whenever the version-check logic detects a newer store build.
