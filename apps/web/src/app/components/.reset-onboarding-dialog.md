Provides a confirmation dialog and helper hook for resetting a user's onboarding ("Get Started") tour progress, allowing them to replay the setup wizard from the beginning.

## Key Components

- **`useCanResetOnboarding()`** — Hook that determines whether a reset option should be shown. Returns `true` only once onboarding progress has loaded (`isLoaded`) and the user has either completed, skipped, started (has a `tourDialogId`), or reached the end of the wizard (`setupSeen`) without starting the tour.
- **`ResetOnboardingDialogProps`** — Props interface for the dialog:
  - `open` / `onOpenChange`: standard controlled dialog visibility.
  - `onReset?`: optional callback fired after a successful reset, useful for navigating the user back to the dashboard (since the tour restart flow is dashboard-driven).
- **`ResetOnboardingDialog`** — A `ConfirmDialog`-based component that, on confirmation, calls `resetUser` (from `useOnboardingMutations`) to clear onboarding state, then closes the dialog and invokes `onReset`.

## Usage Example

```typescript
import { useState } from 'react';
import { ResetOnboardingDialog, useCanResetOnboarding } from '@/app/components/onboarding/reset-onboarding-dialog';
import { useRouter } from 'next/navigation';

function SettingsMenu() {
  const [open, setOpen] = useState(false);
  const canReset = useCanResetOnboarding();
  const router = useRouter();

  if (!canReset) return null;

  return (
    <>
      <button onClick={() => setOpen(true)}>Reset Onboarding</button>
      <ResetOnboardingDialog
        open={open}
        onOpenChange={setOpen}
        onReset={() => router.push('/dashboard')}
      />
    </>
  );
}
```

This pattern is typically used in a settings page or menu where the "Reset Onboarding" action is conditionally rendered based on `useCanResetOnboarding`, and the dialog handles confirmation and the underlying mutation.
