## biometric-lock-boundary.tsx

A root-level boundary component that guards the entire app tree against a native-shell biometric cold-start lock, ensuring the unlock gate renders before any child's loading skeleton can mask it indefinitely.

This component must be mounted above any `useAuthSession` consumer that renders based on `isReady` (such as `AppLayout`), since a locked session query stays in an error state and a higher consumer would otherwise show a skeleton forever. On web/desktop, where the lock state is always `null`, children render untouched.

## Key Components

- **`BiometricLockBoundary`** — Main exported component wrapping `children`. Subscribes to the token-store's biometric lock state via `useSyncExternalStore` and renders one of three states:
  - **`locked`** (or mid sign-out hand-off): renders `BiometricUnlockGate`, letting the user retry biometric auth or switch accounts.
  - **`invalidated`** (enrollment changed, tokens unrecoverable): triggers `signOutToLogin` and renders a blank app-background placeholder until the route transitions to `/auth`.
  - **`null`** (unlocked): renders `children` normally.
- Internally re-drives the auth session query (`invalidateAuthSession`) whenever the lock transitions from `'locked'` to `null`, since the session query was left in an error state while locked.
- `handleUseAnotherLogin` — callback that dismisses the lock and performs a hard sign-out, used for the "log in another way" flow.

## Usage Example

```typescript
// app/layout.tsx (or equivalent root layout)
import { BiometricLockBoundary } from '@/components/biometric-lock-boundary';
import { AppLayout } from '@/components/app-layout';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <BiometricLockBoundary>
      <AppLayout>{children}</AppLayout>
    </BiometricLockBoundary>
  );
}
```

Ensure `BiometricLockBoundary` wraps any component relying on `useAuthSession`'s `isReady` flag, so the unlock gate can intercept rendering before a loading skeleton gets stuck.
