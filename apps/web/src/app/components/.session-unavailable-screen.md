# session-unavailable-screen.tsx

Full-screen gate component that replaces the app UI when the auth session is `paused` as `transient` in `session-health.ts` — meaning a 401 triggered a refresh, and the refresh failed for a reason unrelated to credential validity (e.g., auth server returning 502/503, dropped connections, WAF rejections) on two consecutive attempts. It gives the user a way to retry the refresh or sign out while the auth service recovers.

## Key Components

- **`settleOutcome(outcome, queryClient)`** — Async helper that reacts to a `RefreshOutcome`: on `'refreshed'`, clears the health pause and invalidates the cached auth session so `/me` is re-fetched; on `'terminal'`, force-logs-out locally and resets session health.
- **`signOutLocally()`** — Fallback sign-out path used when the gateway can't revoke the refresh token; clears local session state and redirects to the login route (app-shell aware via `isAppShell()`).
- **`SessionUnavailableScreen()`** (default export, function component) — Renders the full-screen "can't verify your session" UI with:
  - Automatic retry loop paced by `getRefreshBackoffRemainingMs()` (floored at `MIN_AUTO_RETRY_MS`), re-scheduling itself as long as outcomes stay `'transient'`.
  - A **Retry** button that calls `refreshTokens(undefined, { ignoreBackoff: true })` and shows a toast if still unavailable.
  - A **Sign Out** button that attempts `performLogout()` (gateway revocation) and falls back to `signOutLocally()` on failure.
  - Focus management moving to the heading on mount for assistive-tech announcement.

## Usage Example

```typescript
import { SessionUnavailableScreen } from '@/app/components/session-unavailable-screen';

// Rendered conditionally by a gate component, replacing the entire tree
// (similar to how WorkspaceGoneGate operates) so queries remount cleanly
// once the session recovers.
function AuthGate({ children }: { children: React.ReactNode }) {
  const sessionPaused = useSessionPausedTransient(); // app-specific hook

  if (sessionPaused) {
    return <SessionUnavailableScreen />;
  }

  return <>{children}</>;
}
```

Note: This component expects to be mounted by a gating layer (not rendered directly inside normal page content), since it fully replaces the visible UI and manages its own retry/sign-out lifecycle tied to `token-refresh-manager.ts`.
