Renders the platform-wide announcement bar in the `topBar` slot, sourcing announcement content from the hub admin via the shared `AnnouncementBar` component from `@flamingo-stack/openframe-frontend-core`.

## Key Components

- **`AnnouncementTopBar`** - Client component (`'use client'`) that wires up the shared `AnnouncementBar` with this app's content endpoints and current shell surface.
- **`EndpointsRuntimeContext.Provider`** - Supplies `CONTENT_ENDPOINTS` so the inner `AnnouncementBar` can self-fetch announcement data through the `/content` proxy.
- **`shellKind()`** - Resolves the current shell/surface identifier (from `@/lib/platform`), used to filter announcements the admin scoped to specific surfaces.

## Behavior

- The `AnnouncementBar` component fetches the active announcement, animates it into view, and persists a per-announcement dismissal state (so a dismissed announcement doesn't reappear).
- If the hub admin restricted an announcement to a different surface than the one returned by `shellKind()`, the bar stays collapsed/hidden in this bundle.
- All data fetching and endpoint resolution is delegated to the shared core package; this file only configures context and surface.

## Usage Example

```typescript
import { AnnouncementTopBar } from '@/app/(app)/_components/announcement-top-bar';

export default function AppLayout({ children }: { children: React.ReactNode }) {
  return (
    <div className="app-shell">
      <AnnouncementTopBar />
      <main>{children}</main>
    </div>
  );
}
```

This component is typically placed once near the root of a layout so the announcement bar appears consistently across pages within that shell.
