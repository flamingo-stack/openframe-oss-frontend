This component renders a modal form for manually creating or editing a time tracking entry, handling duration, date, ticket/customer association, optional employee assignment, and notes via GraphQL mutations.

## Key Components

- **`ManualEntryModal`** — Main exported component rendering the modal UI; supports both create and edit modes based on whether an `entry` prop is supplied.
- **`ManualEntryEditTarget`** — Interface describing the minimal `TimeEntry` fields needed to pre-fill the form when editing an existing entry.
- **`ManualEntryModalProps`** — Props interface controlling modal visibility, target user, customer pre-selection, and the edit target.
- **`AssignedUserField`** — Internal component rendering an autocomplete field for selecting/reassigning the employee the entry belongs to (shown only when `selectableUser` is enabled and no fixed `userId` is given).
- **`manualEntrySchema`** — Zod schema validating work time (must parse to a duration greater than zero), start date, and notes.
- **`ticketLabelFromEntry`** — Helper formatting a ticket's display label (`#number title`) from an edit target.

The form uses `react-hook-form` with `zodResolver`, Relay mutations (`createTimeEntryMutation`, `updateTimeEntryMutation`), and shared helpers from `time-tracker-helpers` for duration parsing/formatting and Relay global ID conversion.

function WorktimeToolbar() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Add Manual Entry</Button>
      <ManualEntryModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        selectableUser
        onSuccess={() => refetchTimeEntries()}
      />
    </>
  );
}
