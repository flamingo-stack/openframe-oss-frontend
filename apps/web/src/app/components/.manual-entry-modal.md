Modal component for manually creating or editing time entries, supporting duration input, date selection, customer/ticket association, and optional employee reassignment.

## Key Components

### `ManualEntryModal`
Primary exported component. Renders a `SimpleModal` with a form for time entry creation or editing. Switches between create/edit modes based on the `entry` prop.

**Props:**
| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `entry` | `ManualEntryEditTarget \| null` | When provided, switches to edit mode |
| `userId` | `string` | Fixes the target user; bypasses employee selector |
| `selectableUser` | `boolean` | Shows an Employee field for reassignment |
| `defaultCustomer` | `object` | Pre-selects and locks a customer on create |
| `onSuccess` | `() => void` | Callback after successful mutation |

### `ManualEntryEditTarget`
Exported interface describing the minimal shape of a time entry needed to pre-fill the edit form (id, duration, timestamps, linked ticket/organization/user).

### `AssignedUserField` (internal)
Avatar-based `Autocomplete` for selecting an employee. Merges the seed option (pre-selected user) into the fetched assignee list to ensure it is always present.

### `manualEntrySchema`
Zod schema validating `workTime` (non-zero `HH:MM:SS` duration), `startedAt` (date), and `notes` (string).

## Usage Example

```typescript
import { ManualEntryModal } from './manual-entry-modal';

// Create mode
<ManualEntryModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  selectableUser
  onSuccess={() => refetch()}
/>

// Edit mode
<ManualEntryModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  entry={selectedEntry}          // ManualEntryEditTarget
  selectableUser
  onSuccess={() => refetch()}
/>
```

Form validation requires either a linked ticket or non-empty notes. On submit, dispatches `createTimeEntryMutation` or `updateTimeEntryMutation` via Relay, then calls `onSuccess` and closes the modal.
