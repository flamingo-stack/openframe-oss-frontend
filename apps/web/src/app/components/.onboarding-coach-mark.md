# OnboardingCoachMark

A client-side React component that displays a floating contextual coach-mark overlay when a user navigates to a destination page from an onboarding step. It guides users back to their onboarding flow after completing an intermediate task.

## Key Components

- **`OnboardingCoachMark`** — The main exported component. Mounted once at the app-shell level, it:
  - Reads the `setupHint` query param to determine which coach-mark content to display (via `ONBOARDING_COACH_MARKS` lookup).
  - Returns `null` silently if no valid hint is present (normal page visits are unaffected).
  - Reads the `setupReturn` query param to determine the return path, defaulting to `/onboarding`.
  - Dynamically renders a CTA button whose label/icon adapts based on whether the user returns to the per-user "Onboarding" flow (`CompassIcon`, "Continue Onboarding") or the tenant "Initial Setup" flow (`ClipboardListIcon`, "Continue Initial Setup").
  - Navigates back to the return path via `router.push` when the CTA is clicked.

Depends on shared constants/helpers from `@/app/(app)/onboarding/onboarding-coach-marks`: `isOnboardingHintKey`, `ONBOARDING_COACH_MARKS`, `SETUP_HINT_PARAM`, `SETUP_RETURN_PARAM`.

## Usage Example

```typescript
// Mounted once, app-wide, typically in the root app shell layout
import { OnboardingCoachMark } from '@/components/onboarding-coach-mark';

export function AppShell({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <OnboardingCoachMark />
    </>
  );
}
```

```text
A user is redirected to a feature page with:
  /settings/integrations?setupHint=connectIntegration&setupReturn=/onboarding

The coach-mark then appears, showing the matching title/body from
ONBOARDING_COACH_MARKS['connectIntegration'] and a "Continue Onboarding"
button that navigates back to /onboarding on click.
```

No props are accepted — the component derives all state from URL search params, making it safe to mount globally without prop drilling.
