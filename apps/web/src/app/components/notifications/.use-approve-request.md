# use-approve-request.ts

A React client hook that resolves Mingo tool-approval requests (approve or reject) via the ticket service, surfacing success or error feedback through toast notifications.

## Key Components

- **`useApproveRequest()`** — Custom hook returning a memoized async callback for approving/rejecting an approval request.
  - **Callback signature:** `(approvalRequestId: string, approve: boolean) => Promise<boolean>`
  - Calls `ticketService.resolveApprovalRequest(approvalRequestId, approve)`.
  - On failure: shows a destructive toast with the error message and returns `false`.
  - On success: shows a success toast ("Approved" or "Rejected") and returns `true`.
  - Leaves follow-up actions (e.g., marking a notification read, updating local status) to the caller based on the returned boolean.

## Usage Example

```typescript
'use client';

import { useApproveRequest } from '@/app/(app)/tickets/hooks/use-approve-request';

function ApprovalActions({ approvalRequestId }: { approvalRequestId: string }) {
  const approveRequest = useApproveRequest();

  const handleApprove = async () => {
    const success = await approveRequest(approvalRequestId, true);
    if (success) {
      // e.g., refresh list, mark notification as read, etc.
    }
  };

  const handleReject = async () => {
    const success = await approveRequest(approvalRequestId, false);
    if (success) {
      // e.g., update local state
    }
  };

  return (
    <div>
      <button onClick={handleApprove}>Approve</button>
      <button onClick={handleReject}>Reject</button>
    </div>
  );
}
```

**Notes:**
- Must be used within a client component (`'use client'` directive required).
- Depends on `useToast` from `@flamingo-stack/openframe-frontend-core/hooks` for notification display.
- Depends on `ticketService` from `@/app/(app)/tickets/services` for the API call.
