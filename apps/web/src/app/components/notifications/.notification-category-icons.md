The icon a notification tile shows: its type's own icon when it has one, else its category's, else none (the tile draws its severity dot).

## Key Components

**`getNotificationIcon(notification)`** — The tile's icon. A type with an icon of its own (`ICON_BY_TYPE`, e.g. a permissions request) draws it; any other notification draws its category's icon from the lib's `notificationCategoryIcon`, the one category-to-icon table every host (this app, the hub's announcement preview) draws from. A category with none returns `undefined`.

**`withNotificationIcon(notification)`** — Attaches that icon for tile rendering. An explicit `icon` or `imageUrl` always wins.

## Usage Example

```typescript
import { withNotificationIcon } from './notification-category-icons';

const enriched = withNotificationIcon({ id: '1', category: 'DEVICES', title: 'Disk alert' });
// enriched.icon is the Devices section's icon
```
