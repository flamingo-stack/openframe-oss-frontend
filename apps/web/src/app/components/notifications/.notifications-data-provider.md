## Notifications Data Provider

Client-side provider component that wires real-time NATS notification pushes into the Relay store, manages the notifications drawer/popup UI state, and exposes notification actions (mark read, approve/reject, navigate) to the rest of the app. It bridges server-pushed events with Relay's local cache so notification lists, unread counts, and approval tiles update live without refetching.

## Key Components

- **`writeNotificationShapes`** — Writes a pushed notification's `type` and merged `attributes` onto a Relay record, preserving existing fields instead of nulling unselected ones.
- **`prependNotificationEdge`** — Inserts a new notification edge into the unread connection, deduplicating redelivered pushes.
- **`applyReadStateEvent`** — Applies `READ`/`ARCHIVED`/`DELETED` events across all mounted connections, adjusting unread counts and triggering a status refresh when the local store can't resolve the transition confidently.
- **`openNotificationTarget`** — Routes a notification tap to either an in-page Mingo dialog or standard navigation, marking the notification read as appropriate.
- **`NatsNotificationPayload`** — Shape of the real-time push payload (card data or read-state event).
- **`PaginationState` / `TileHelpers` / `NavigationTileWrapperProps`** — Supporting types for drawer pagination and tile rendering.
- Re-exports consumer-facing pieces from `@flamingo-stack/openframe-frontend-core` (`NotificationsProvider`, `useNotifications`, `NotificationTile`, `ApprovalRequestNotificationTile`, etc.).

## Usage Example

```typescript
import { NotificationsProvider, useNotifications } from '@/app/components/notifications/notifications-data-provider';

function NotificationsDrawer() {
  const { notifications, markRead, pagination } = useNotifications();

  return (
    <div>
      {notifications.map(n => (
        <div key={n.id} onClick={() => markRead(n.id)}>
          {n.title}
        </div>
      ))}
      {pagination.hasMore && (
        <button onClick={pagination.loadMore}>Load more</button>
      )}
    </div>
  );
}

export function App() {
  return (
    <NotificationsProvider>
      <NotificationsDrawer />
    </NotificationsProvider>
  );
}
```

This component is intended to be mounted once near the app root (via `NotificationsProvider`) and relies on an active NATS connection (`useOptionalNats`) plus a Relay environment to subscribe to and persist live notification updates.
