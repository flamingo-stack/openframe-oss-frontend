## notification-navigation.ts

Resolves a `Notification`'s backend `type` discriminator into a concrete, clickable `NotificationAction` (an in-app route, a Mingo dialog link, or an external URL). This module is the single source of truth for routing notification clicks across web, desktop (Tauri), and push transports, since all of them carry the same `type` string.

## Key Components

- **Notification type constants** — exported string discriminators (`ADMIN_AI_MESSAGE_TYPE`, `TICKET_STATUS_CHANGED_TYPE`, `TICKET_REOPENED_TYPE`, `AUTO_TOP_UP_PAUSED_TYPE`, `ANNOUNCEMENT_TYPE`, `INCIDENT_DETECTED_TYPE`, etc.) matching the backend `TenantNotificationType`.
- **`NotificationAction` / `NotificationRouteAction` / `NotificationLinkAction`** — discriminated union describing an in-app route (with optional Mingo dialog id and `readOnOpen` flag) vs. an external URL.
- **`isNotificationLinkAction`** — type guard distinguishing external link actions from route actions.
- **`NOTIFICATION_ACTION_FIELDS`** — the fixed list of entity-id fields (`ticketId`, `dialogId`, `insightId`, `recordingId`, `deviceId`, `link`, `connectionId`) that any shell (desktop, push) must forward alongside `type`.
- **`NotificationFacts`** — shape of the resolved entity ids (plus `connections`, a JSON list not carried by push due to size limits) used to compute an action.
- **`resolveAction`** — core routing function: given a `type`, `NotificationFacts`, and `category`, returns the appropriate `NotificationAction` or `null` if no action applies.
- **`linkAction`** — validates and builds an action for an announcement's `link`, distinguishing same-origin (in-app route) vs. external (`externalUrl`) destinations, rejecting non-`https:` protocols.
- Internal action builders: `mingoDialogAction`, `incidentAction`, `recordingAction`, `deviceRemoteSessionsAction`, `tenantAction`, `TENANT_LIST_ACTION`.

## Usage Example

```typescript
import {
  resolveAction,
  isNotificationLinkAction,
  NOTIFICATION_ACTION_FIELDS,
  type NotificationAction,
} from '@/lib/notification-navigation';

const facts = {
  ticketId: null,
  dialogId: 'dlg_123',
  insightId: null,
  recordingId: null,
  deviceId: null,
  link: null,
  connectionId: null,
  connections: null,
};

const action: NotificationAction | null = resolveAction('ADMIN_AI_MESSAGE', facts, 'MINGO');

if (action) {
  if (isNotificationLinkAction(action)) {
    window.open(action.externalUrl, '_blank');
  } else {
    router.push(action.route);
  }
}
```
