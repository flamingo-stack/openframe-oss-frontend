## MingoDialogParamBridge

A client-only, render-nothing bridge component that redirects legacy `?mingoDialog=<id>` URL parameters to the modern Mingo chat route, preserving backward compatibility with old links, bookmarks, and notifications.

## Key Components

- **`MingoDialogParamBridge`** — React component (no props, no visible output) that:
  - Reads the `mingoDialog` query parameter via `useSearchParams()` to trigger re-runs on URL changes.
  - Re-reads the live value from `window.location.search` to avoid acting on a stale/lagging value.
  - Skips entirely when not in SaaS tenant mode (OSS tenants have no Mingo chat feature).
  - If a dialog id is present, normalizes it (Relay global id → raw id) and redirects to `routes.mingo.chat(id)` via `router.replace`.
  - If the param exists but is empty (`?mingoDialog=`), strips it from the current URL using `withMingoDialog(..., null)` instead of navigating away.
  - Never validates whether the id actually resolves — the chat page itself handles the not-found state.

## Usage Example

Mount once near the root of the app layout so it can intercept the param on any route:

```typescript
import { MingoDialogParamBridge } from '@/components/mingo-dialog-param-bridge';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <MingoDialogParamBridge />
      {children}
    </>
  );
}
```

A link like `https://app.example.com/dashboard?mingoDialog=abc123` will be transparently redirected to the Mingo chat route with the normalized id, while a bare `?mingoDialog=` param is simply stripped from the current page's URL.
