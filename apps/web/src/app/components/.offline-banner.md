# offline-banner.tsx

A lightweight React client component that displays a non-intrusive "offline" status pill when network connectivity is lost, automatically hiding once connectivity returns. It works consistently across both web and native (WebView) shell environments.

## Key Components

- **`OfflineBanner`** — Default-style functional component that renders a fixed, centered pill indicator at the top of the viewport when the app detects an offline state. Renders `null` when online.

### Behavior Notes

- Uses `subscribeConnectivity` from `@/lib/connectivity` rather than `navigator.onLine` directly, since the native WKWebView `online` event can lag significantly behind actual reconnection.
- Initializes state as **online** (`offline = false`) to avoid a false-positive flash during SSR/static export, where `navigator` is unavailable.
- Connectivity here is a *hint* only ("no network interface"), not a guarantee the backend is reachable — it does not replace per-request 401/refresh/retry logic elsewhere in the app.
- Styled with `role="status"` and `aria-live="polite"` for accessibility, announcing changes to assistive technology without interrupting focus.
- Positioned using a CSS custom property (`--native-safe-top`) to respect native safe-area insets.

## Usage Example

```typescript
import { OfflineBanner } from '@/components/offline-banner';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <OfflineBanner />
        {children}
      </body>
    </html>
  );
}
```

Mount `OfflineBanner` once near the root of your layout. It requires no props and manages its own subscription lifecycle via `useEffect`, cleaning up automatically on unmount.
