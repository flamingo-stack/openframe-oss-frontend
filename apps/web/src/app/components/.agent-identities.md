Provides the AI agents' identities (Fae, Mingo) to every page of the app, mounted once in the root layout.

## Key Components

- **`AgentIdentities`** – Wraps its children in the lib's `AgentIdentityProvider`, reading the identities from the content proxy (`/content/api/ai-agents`). The lib packages no agent picture, so every agent mark is drawn from this one read.

## Usage Example

```tsx
// app/layout.tsx: once, around the routes, under the query client.
<AgentIdentities>
  <RouteGuard>{children}</RouteGuard>
</AgentIdentities>
```

## Notes

- It sits at the root because every icon named by a string (`EntityIcon`) asks the provider whether the name is an agent. The auth pages' announcement bar is outside the `(app)` layout, so a provider there left it without one.
- The read waits for a signed-in session (`useAuthSession`): sent earlier it is refused, and the refusal starts a token refresh that can end a sign-in in progress. Until then, and on the signed-out auth pages, no agent is known and every name is drawn as the library glyph it names.
