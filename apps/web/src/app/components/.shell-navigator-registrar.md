Registers the Next.js App Router's navigation function with a non-React module, enabling code outside the React tree (such as notification handlers or desktop OS toast callbacks) to trigger client-side navigation without forcing a full page reload.

## Key Components

- **`ShellNavigatorRegistrar`** — A client component that, on mount, calls `registerShellNavigator` with a callback wrapping `router.push`. It renders no UI (`null`) and is intended to be mounted exactly once at the application's `(app)` layout level.

## Usage Example

```typescript
// app/(app)/layout.tsx
import { ShellNavigatorRegistrar } from '@/components/shell-navigator-registrar';

export default function AppLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <ShellNavigatorRegistrar />
      {children}
    </>
  );
}
```

```typescript
// lib/shell-navigator.ts (consumer, outside React)
import { navigateInApp } from '@/lib/shell-navigator';

function onNotificationClick(href: string) {
  // Works even though this runs outside a React component/event handler
  navigateInApp(href);
}
```

## Notes

- This component must be mounted once per app instance (e.g., in the root `(app)` layout) to ensure the navigator registration stays in sync with the active router instance.
- The `useEffect` re-registers the navigator whenever `router` changes, keeping the external reference current across route transitions.
- Since it returns `null`, it has no visual footprint and is purely a side-effect/bridge component.
