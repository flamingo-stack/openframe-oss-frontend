Defines route-level metadata and layout re-export for the Dashboard page segment within a Next.js App Router group.

## Key Components

- **`metadata`** — A `Metadata` object exported for Next.js to statically resolve the `<title>` tag for this route, generated via the `routeTitle` helper with `'Dashboard'` as the page label.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as this segment's layout, avoiding duplicate layout logic across routes.

## Usage Example

This file is automatically picked up by Next.js as the `layout.tsx` for its route segment—no manual import is needed. The pattern can be replicated for other dashboard-style pages:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Settings') };
```

Each route segment supplies its own page label (for example, `'Settings'`, `'Users'`) to `routeTitle`, while sharing the same underlying layout component. This keeps the browser tab title in sync with the active section while centralizing layout markup (navigation, shell, etc.) in a single reusable component defined at `app/(app)/route-title-layout`.
