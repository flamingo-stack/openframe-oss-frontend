# Dashboard Page

The root dashboard route component that renders different experiences depending on the active app mode (OSS, SaaS, or Manhattan shell). It acts as a mode-aware router, delegating to the appropriate dashboard implementation.

## Key Components

- **`Dashboard`** (default export) — Client component that determines which dashboard UI to render:
  - **Manhattan shell mode**: redirects to `routes.mingo.home` via `useAppModeRedirect` and renders nothing while the redirect occurs (per plan D15, Manhattan v2 has no standalone dashboard).
  - **SaaS tenant mode**: renders `MingoDashboard` (Mingo-first home experience).
  - **OSS tenant mode**: renders `DashboardContent` (the standard OSS dashboard).

## Usage Example

This is a Next.js App Router page component and is rendered automatically for its route—no manual invocation is needed:

```typescript
// app/(app)/dashboard/page.tsx
export default function Dashboard() {
  const manhattan = useManhattanDock();
  useAppModeRedirect(manhattan ? routes.mingo.home : null);
  if (manhattan) return null;
  if (isSaasTenantMode()) return <MingoDashboard />;
  return <DashboardContent />;
}
```

**Behavior summary:**

```text
Manhattan shell active  -> redirect to Mingo home, render nothing
SaaS tenant mode        -> render MingoDashboard
OSS tenant mode         -> render DashboardContent
```

Relies on `useManhattanDock` to detect Manhattan shell context, `useAppModeRedirect` to perform conditional client-side redirects, and `isSaasTenantMode` to branch between SaaS and OSS rendering paths.
