# dashboard-api-service.ts

Client-side service module that aggregates device and ticket statistics for the dashboard view. It wraps calls to the shared device query layer and the tickets GraphQL endpoint, normalizing raw API responses into dashboard-ready stats objects with computed percentages.

## Key Components

- **`DashboardDeviceStats`** — Interface describing device counts (total, active, inactive, pending, archived) and their derived percentages.
- **`DashboardTicketStats`** — Interface describing ticket totals, resolution metrics, average Fae rating, and lifecycle (custom-status) kind breakdowns (AI assistance, tech required, other).
- **`DashboardApiService`** — Singleton class exposing:
  - `fetchDeviceStats()` — Retrieves device status counts via `fetchDeviceStatusCounts`, then computes active/inactive/pending/archived totals and percentages. Archived count merges `DELETED` and legacy `ARCHIVED` statuses.
  - `fetchTicketStats()` — Posts `GET_TICKET_STATISTICS_QUERY` to the GraphQL endpoint, validates the response, and derives resolved count, resolution percentage, average resolve time, average Fae rate, and lifecycle status kind counts/colors.
  - `handleApiError()` — Private helper that wraps thrown errors with contextual operation names.
- **`dashboardApiService`** — Exported singleton instance ready for use throughout the app.

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service';

async function loadDashboard() {
  try {
    const [deviceStats, ticketStats] = await Promise.all([
      dashboardApiService.fetchDeviceStats(),
      dashboardApiService.fetchTicketStats(),
    ]);

    console.log(`Active devices: ${deviceStats.active} (${deviceStats.activePercentage}%)`);
    console.log(`Resolved tickets: ${ticketStats.resolved}/${ticketStats.total}`);
    console.log(`Avg resolve time: ${ticketStats.avgResolveTime}`);
  } catch (error) {
    console.error('Failed to load dashboard stats:', error);
  }
}
```

Note: This service is a singleton (`DashboardApiService.getInstance()`); always import and use the exported `dashboardApiService` instance rather than instantiating the class directly, since the constructor is private.
