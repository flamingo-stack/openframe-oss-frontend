Defines a helper that builds a standardized header action button for overview sections, linking to a related list view (e.g., "View all") with a trailing chevron icon.

## Key Components

- **`sectionListAction(label, href)`** — Factory function that returns a `PageActionButton[]` array containing a single outline-style button configured with:
  - `label`: visible button text
  - `ariaLabel`: accessibility label derived as `Open ${label}`
  - `href`: navigation target for the list view
  - `variant: 'outline'`: outline button styling
  - `icon`: a `Chevron02RightIcon` indicating navigation to a sub-list

This button is designed to collapse to just its icon on smaller viewports (below `content-md`), keeping section headers compact.

## Usage Example

```typescript
import { sectionListAction } from './section-list-action';

// In an overview section's page/header configuration
const headerActions = sectionListAction('View all devices', '/devices');

// Pass to a page/section component that accepts `actions` or `pageActions`
<OverviewSection
  title="Devices"
  actions={headerActions}
/>
```

Typical use case: summarizing a count or preview of items in a dashboard overview card, with this action linking to the full, detailed list.
