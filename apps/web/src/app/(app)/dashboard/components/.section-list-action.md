Defines a helper that builds a `PageActionButton` configuration for an overview section's header action—typically a ">" link leading to the full list that the section summarizes/counts.

## Key Components

- **`sectionListAction(label, href)`** — Factory function that returns a `PageActionButton[]` array containing a single outline-style button with a trailing chevron icon. Used as a consistent pattern for "view all" / "open list" actions in section headers.
  - **Parameters:**
    - `label: string` — Visible button text (also used to build the `aria-label`).
    - `href: string` — Destination URL/route the action button links to.
  - **Returns:** `PageActionButton[]` — A single-element array ready to be passed to a page/section header component that accepts page actions.

## Usage Example

```typescript
import { sectionListAction } from './section-list-action';

function DevicesOverviewSection() {
  const actions = sectionListAction('View all devices', '/devices');

  return (
    <OverviewSection title="Devices" actions={actions}>
      {/* section content */}
    </OverviewSection>
  );
}
```

**Notes:**
- The returned button uses the `outline` variant and includes a `Chevron02RightIcon`, matching the design pattern for "open list" affordances.
- Per the component's design, when only one header action icon is present, it collapses to just the icon below the `content-md` breakpoint, keeping headers compact on smaller viewports.
- Intended for reuse across overview sections that link to a corresponding full list/detail page (e.g., devices, users, tickets).
