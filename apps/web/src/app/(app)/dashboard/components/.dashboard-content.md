## dashboard-content.tsx

Client component rendering the main tenant dashboard: an onboarding-aware intro banner or initial-setup card, followed by overview sections (Devices, Tickets, Customers). Coordinates behavior between the classic (v1) and v2 onboarding experiences via feature flags, and supports reuse of the overview sections in other contexts (e.g., Mingo's home).

## Key Components

- **`IntroBanner`** — Exported component showing the onboarding v2 welcome banner (`MingoIntroBanner`) once the `onboarding-v2` feature flag resolves to `on`; renders nothing otherwise.
- **`InitialSetupSection`** — Internal component rendering the legacy `InitialSetupCard` (with its own loading state) when onboarding v2 is off; hidden entirely when v2 is on.
- **`IntroBannerSection`** — Internal wrapper applying padding/collapse styling around `IntroBanner`.
- **`OverviewSectionsProps`** — Props interface for `OverviewSections`: `live`, `filterTicketLinks`, `incidents`, `dimDuringInitialSetup`.
- **`OverviewSections`** — Exported component rendering `Devices`, `Tickets` (SaaS mode only), optional `incidents` slot, and `Customers` sections inside a shared `PageLayout`. Dims/disables content while legacy Initial Setup is active.
- **`DashboardOverviews`** — Exported component combining `IntroBannerSection`, `InitialSetupSection`, and `OverviewSections` for the classic dashboard shell.
- **`DashboardContent`** (default export) — Top-level page component wrapping `DashboardOverviews` in `RevealTogether` for coordinated reveal animation, with `live` data fetching enabled.

## Usage Example

```typescript
import DashboardContent, { OverviewSections, IntroBanner } from '@/app/(app)/dashboard/dashboard-content';

// Used as the dashboard page's default export
export default function DashboardPage() {
  return <DashboardContent />;
}

// Reused elsewhere (e.g., Mingo's home) with custom incidents slot
function MingoHome() {
  return (
    <OverviewSections
      live
      filterTicketLinks
      incidents={<IncidentsSection />}
      dimDuringInitialSetup={false}
    />
  );
}
```
