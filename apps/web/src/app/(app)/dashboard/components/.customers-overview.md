# customers-overview.tsx

A dashboard section component that displays a paginated overview of customer organizations, each paired with online/offline device count cards. Handles loading, error, offline, and empty states, and coordinates its reveal timing with sibling dashboard sections via `RevealTogether`.

## Key Components

- **`CustomersOverviewSection`** — Top-level exported component that fetches customer data via `useCustomersOverview` and wraps `CustomersOverview` in a `LoadingWhen` gate tied to the page's reveal coordination (`useRevealPart`/`useRevealHeld`).
- **`CustomersOverview`** — Presentational component accepting an optional `customers` data object; renders the title block and the list of customer rows, handling loading skeletons, error/offline states, and an empty state.
- **`CustomerOverviewRow`** — Renders one row: a `DashboardInfoCard` for the customer (logo, name, device count, website) plus two `DeviceStatusInfoCard`s for online/offline devices.
- **`CustomerTitle`** — Renders the customer's name and pluralized device count, with skeleton placeholders while loading.
- **`DeviceCards`** — Renders the online/offline `DeviceStatusInfoCard` pair for a row, linking to filtered device routes.

## Usage Example

```typescript
import { CustomersOverviewSection } from './customers-overview';

export function DashboardPage() {
  return (
    <div className="dashboard-grid">
      <CustomersOverviewSection />
    </div>
  );
}
```

To render with externally-fetched data (e.g., shared across sections):

```typescript
import { CustomersOverview } from './customers-overview';
import { useCustomersOverview } from '../hooks/use-customers-overview';

function CustomSection() {
  const customers = useCustomersOverview(5);
  return <CustomersOverview customers={customers} />;
}
```

**Notes:**
- Rows render with `org={null}` to display skeleton placeholders during loading.
- Empty state only shows when `canClaimEmpty` is true (distinguishing "confirmed empty" from "offline/paused query").
- Error and offline states render a full-section `LoadError` since there are no partial results to preserve.
