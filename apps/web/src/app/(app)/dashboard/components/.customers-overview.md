# customers-overview.tsx

A dashboard section component that renders a customer overview with per-customer device status summaries (online/offline counts). It handles loading, error, offline, and empty states, and coordinates its reveal timing with sibling dashboard sections via a shared "reveal together" mechanism.

## Key Components

- **`CustomersOverviewSection`** — Top-level exported component that fetches customer data via `useCustomersOverview`, registers its readiness with `useRevealPart`, and defers rendering until the page-wide reveal gate (`useRevealHeld`) opens.
- **`CustomersOverview`** — Presentational component accepting optional `customers` data (from `useCustomersOverview`). Renders the section title, and resolves to one of: loading skeleton rows, a `LoadError` state (on error/offline), an `EmptyState` (no customers, tenant reachable), or the list of customer rows.
- **`CustomerOverviewRow`** — Renders a single customer's row: a `DashboardInfoCard` with logo/name/website plus two `DeviceStatusInfoCard`s (online/offline). Accepts `org: CustomerRow | null` to support loading placeholders.
- **`CustomerTitle`** — Renders the customer name and pluralized device count, with skeleton bars while loading.
- **`DeviceCards`** — Renders the two device status cards (`ONLINE`/`OFFLINE`) for a row, each linking to a filtered devices view.
- **`CUSTOMERS_OVERVIEW_LIMIT`** (imported) — Used to size the loading skeleton row count.

## Usage Example

```typescript
import { CustomersOverviewSection } from './customers-overview';

export function DashboardPage() {
  return (
    <div className="dashboard-sections">
      <CustomersOverviewSection />
    </div>
  );
}
```

For cases where data is already fetched elsewhere (e.g., shared across sections):

```typescript
import { CustomersOverview } from './customers-overview';
import { useCustomersOverview, CUSTOMERS_OVERVIEW_LIMIT } from '../hooks/use-customers-overview';

function CustomSection() {
  const customers = useCustomersOverview(CUSTOMERS_OVERVIEW_LIMIT);
  return <CustomersOverview customers={customers} />;
}
```

Row rendering degrades gracefully to a loading state by passing `org={null}`, enabling consistent skeleton UI across loading, error, and populated states.
