# devices-overview.tsx

Renders the "Devices Overview" dashboard section, displaying four status cards (Online, Offline, Pending, Archived) with device counts and percentages. Integrates with the app's reveal-together loading orchestration and gracefully degrades to unavailable-value states when stats fail to load.

## Key Components

- **`DEVICE_STATUS_CARD`** — Static mapping from each `DEVICE_STATUS` to its card title and progress bar color (success/error/warning/info).
- **`DeviceStatusInfoCard`** — Presentational component rendering a single device status card via `DashboardInfoCard`, with support for loading skeleton bars, progress display, and navigation link.
- **`DevicesOverviewSection`** — Data-connected wrapper that fetches device stats with `useDevicesOverview`, reports loading completion to the page's `RevealTogether` coordination, and renders `DevicesOverview`.
- **`DevicesOverview`** — Pure presentational section accepting pre-fetched `devices` data; builds the four status cards, handles error/offline states via `SectionLoadError`, and lays out cards in a responsive grid.

## Usage Example

```typescript
import { DevicesOverviewSection, DevicesOverview } from './devices-overview';
import { useDevicesOverview } from '../hooks/use-dashboard-stats';

// Standalone usage — fetches its own data and participates in page reveal timing
function DashboardPage() {
  return <DevicesOverviewSection />;
}

// Composed usage — pass already-fetched data (e.g., for a customer-specific view)
function CustomerDashboard() {
  const devices = useDevicesOverview({ customerId: 'abc123' });
  return <DevicesOverview devices={devices} />;
}
```

Each card links to a filtered devices list (`routes.devices.filtered`) or the archive page (`routes.devices.archive`) for archived devices. When data is unavailable, cards show `EMPTY_VALUE` (`—`) instead of fabricating a zero count.
