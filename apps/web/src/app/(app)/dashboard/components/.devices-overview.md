Renders the **Devices Overview** section on the dashboard, displaying four status-based info cards (Online, Offline, Pending, Archived) with counts, percentages, and progress indicators.

## Key Components

- **`DevicesOverviewSection`** — Main exported component. Fetches device stats via `useDevicesOverview`, maps them into four `DashboardInfoCard` instances, and shows a `DevicesOverviewSkeleton` while loading.
- **`DeviceStatusCard`** — Local type describing each card's shape: `status`, `title`, `value`, `percentage`, and a `progressVariant` union (`'success' | 'error' | 'warning' | 'info'`).
- **`useDevicesOverview`** — Custom hook (from `../hooks/use-dashboard-stats`) that supplies totals, per-status counts, and percentages.

## Routing Logic

Each card links to a filtered `/devices?statuses=<status>` URL, **except** Archived devices, which route to `routes.devices.archive` — reflecting the separate archive page.

## Usage Example

```typescript
// Drop into any dashboard layout — no props required
import { DevicesOverviewSection } from './devices-overview';

export function DashboardPage() {
  return (
    <main>
      <DevicesOverviewSection />
    </main>
  );
}
```

## Progress Variant Mapping

| Status   | `progressVariant` |
|----------|-------------------|
| Online   | `success`         |
| Offline  | `error`           |
| Pending  | `warning`         |
| Archived | `info`            |
