# mingo-intro-banner.tsx

Renders a dismissible onboarding banner introducing "Mingo" on the dashboard, combining a walkthrough video clip with a call-to-action to book an onboarding call. The banner is per-user dismissible (persisted via `localStorage`), responsive (stacked on narrow layouts, side-by-side from `content-lg`), and participates in a page-wide reveal/loading coordination system.

## Key Components

- **`MingoIntroBanner`** — Main exported component. Renders `null` while loading (video/link data), while dismissed, or when there's nothing to show (no video and no bookable call link). Otherwise renders a banner section with:
  - A dismiss button (X icon) that persists the dismissal per user/device.
  - `BookCallWalkthroughVideo` (shown if video data exists).
  - Descriptive copy about Mingo's role.
  - A "Book a Call" `Button` that opens `BookCallModal` (shown if a meeting link exists).
- **`useDismissed(key)`** — Internal hook using `useSyncExternalStore` to read a per-key dismissal flag from `localStorage`, ensuring server/client hydration consistency. Returns `[dismissed, dismiss]`.
- **`subscribeDismissed` / `readDismissed`** — Internal helpers backing the external store subscription and `localStorage` read, shared across all hook instances via a module-level `Set` of listeners.
- **`DISMISSED_KEY_PREFIX`** — Storage key prefix, combined with the current user's ID (or `'anonymous'`) to scope dismissal per user.

## Usage Example

```typescript
// Rendered directly in a dashboard page, typically within a RevealTogether
// group alongside other onboarding sections.
import { MingoIntroBanner } from '@/app/components/mingo-intro-banner';

export default function DashboardPage() {
  return (
    <div className="flex flex-col gap-4">
      <MingoIntroBanner />
      {/* other dashboard sections */}
    </div>
  );
}
```

The component requires no props—it self-coordinates loading state via `useLoadingScope`/`useRevealHeld`/`useRevealPart`, pulls the authenticated user from `useAuthStore`, and fetches its own data (`useOnboardingMeetingLink`, `useWalkthroughVideoData`).
