# tickets-overview.tsx

Renders the "Tickets Overview" dashboard section, displaying four summary cards (AI Assistance, Tech Required, Resolved, Other Statuses) with ticket counts. Supports loading states via `RevealTogether` coordination and optional status-filtered links to the Tickets list.

## Key Components

- **`TicketsOverviewSection`** — Top-level section component that fetches ticket overview data via `useTicketsOverview`, registers loading progress with `useRevealPart('tickets', ...)`, and wraps the display in `LoadingWhen` so it reveals alongside other dashboard sections.
- **`TicketsOverview`** — Presentational component accepting pre-fetched `tickets` data. Renders a `TitleBlock`, an optional `SectionLoadError` on failure/offline, and a responsive grid of `DashboardInfoCard` elements.
- **`TICKET_CARDS`** — Static configuration array defining each card's key, status kind, title renderer, and count accessor.
- **`TicketsOverviewLinks`** — Props interface exposing `filterLinks`, which toggles whether cards link to the Tickets list pre-filtered by status (`?status=`) or to the unfiltered list.

## Usage Example

```typescript
import { TicketsOverviewSection } from './tickets-overview';

export function DashboardPage() {
  return (
    <div className="dashboard-grid">
      {/* Cards link to the bare tickets list */}
      <TicketsOverviewSection />

      {/* Cards link to tickets filtered by the corresponding status kind */}
      <TicketsOverviewSection filterLinks />
    </div>
  );
}
```

For standalone rendering with already-fetched data (e.g. in tests or storybook):

```typescript
import { TicketsOverview } from './tickets-overview';
import { useTicketsOverview } from '../hooks/use-dashboard-stats';

function Example() {
  const tickets = useTicketsOverview();
  return <TicketsOverview tickets={tickets} filterLinks />;
}
```

**Notes:**
- Status ids used for filtering are resolved via `useTicketStatusesQuery`, sharing cache with the Tickets page; until statuses load, links fall back to the unfiltered list.
- Loading state is derived from `useLoadingScope()` combined with the `tickets.isLoading` flag, causing `DashboardInfoCard` values to render as loading bars.
