# use-customers-overview.ts

React hook that fetches and aggregates the "Customers" dashboard section: a list of organizations ranked by device count, combined with online/offline device breakdowns per organization.

## Key Components

- **`useCustomersOverview(limit)`** — Primary hook. Returns `rows`, `loading`, `isOffline`, `canClaimEmpty`, `error`, `totalOrganizations`, and `refresh`. Gated on `isAuthenticated` and powered by `useQuery` from TanStack Query.
- **`CUSTOMERS_OVERVIEW_LIMIT`** — Default row limit (`10`), exported so UI skeletons can match the real row count.
- **`OrganizationOverviewRow`** — Shape of each row: identity fields plus `total`, `active`, `inactive`, `activePct`, `inactivePct`.
- **`fetchCustomersOverview(limit)`** — Fires organization list and online/offline device count queries in parallel (`Promise.all`), merges and sorts results by `total` descending, then slices to `limit`.
- **`fetchOrganizations()`** — Fetches organizations via GraphQL; throws on failure so react-query marks the query as `error` (enables reconnect refetch) rather than silently returning empty data.
- **`organizationCountsForStatuses(statuses)`** — Fetches device counts per organization for given statuses; catches failures and degrades to an empty map so a counter failure doesn't blank the whole section.

## Design Notes

- Device counts are fetched without `organizationIds` filtering since the backend's organization facet ignores that argument anyway — this also saves request payload size.
- Only two count queries are made (`ONLINE`, `OFFLINE`); `total` is computed as their sum rather than issuing a third redundant `[ONLINE, OFFLINE]` query.
- `refetchOnMount: 'always'` ensures fresh data on every dashboard visit while redrawing over stale data instead of showing a skeleton.
- Uses `isLoading` (excludes paused) rather than `isPending` to avoid an infinite skeleton when offline.

## Usage Example

```typescript
import { useCustomersOverview, CUSTOMERS_OVERVIEW_LIMIT } from './use-customers-overview';

function CustomersSection() {
  const { rows, loading, isOffline, canClaimEmpty, error, totalOrganizations, refresh } =
    useCustomersOverview(CUSTOMERS_OVERVIEW_LIMIT);

  if (loading) return <SkeletonRows count={CUSTOMERS_OVERVIEW_LIMIT} />;
  if (error) return <ErrorState onRetry={refresh} />;
  if (canClaimEmpty) return <EmptyState message="No Customers added yet" />;

  return (
    <ul>
      {rows.map(row => (
        <li key={row.id}>
          {row.name} — {row.active}/{row.total} active ({row.activePct}%)
        </li>
      ))}
    </ul>
  );
}
```
