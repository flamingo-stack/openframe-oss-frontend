# use-dashboard-stats.ts

React hooks that fetch and expose dashboard overview statistics (device counts and ticket counts) using TanStack Query, with explicit handling of "unknown" versus "zero" states and SaaS/OSS mode gating.

## Key Components

- **`useDevicesOverview()`** — Fetches device statistics (total, active, inactive, pending, archived, and their percentages) via `dashboardApiService.fetchDeviceStats()`. Query is keyed under `deviceQueryKeys.stats()` so device archiving invalidations refresh these counters too. Enabled only when authenticated.
- **`useTicketsOverview()`** — Fetches ticket statistics (total, resolved, average resolve time, Fae rate, status breakdowns) via `dashboardApiService.fetchTicketStats()`. Only runs in SaaS tenant mode (`isSaasTenantMode()`) and when authenticated; in OSS mode the query gate is permanently `'closed'` so it reads as idle rather than loading.
- **`useSharedDashboardData()`** — Composes both hooks above into a single object exposing `devices`, `tickets`, `isAnyLoading`, and a combined `refetchAll()`.

All numeric fields are typed `number | null`. `null` explicitly means "unknown/not loaded" and must never be coalesced to `0` or rendered as a real value — consumers should display `—` instead to avoid showing false "all clear" states during errors or offline periods.

## Usage Example

```typescript
import { useDevicesOverview, useTicketsOverview, useSharedDashboardData } from './use-dashboard-stats';

function DashboardSummary() {
  const devices = useDevicesOverview();
  const tickets = useTicketsOverview();

  return (
    <div>
      <span>Online: {devices.active ?? '—'} ({devices.activePercentage ?? '—'}%)</span>
      <span>Tickets Resolved: {tickets.resolved ?? '—'}</span>
      {devices.isOffline && <span>Offline — showing last known data</span>}
    </div>
  );
}

function Dashboard() {
  const { devices, tickets, isAnyLoading, refetchAll } = useSharedDashboardData();

  if (isAnyLoading) return <Skeleton />;

  return (
    <button onClick={refetchAll}>
      Refresh ({devices.data.total ?? '—'} devices, {tickets.data.total ?? '—'} tickets)
    </button>
  );
}
```

**Note:** Query state (`isLoading`, `isOffline`, `error`) is derived via `queryState()` from `lib/query-state.ts`, which correctly distinguishes a disabled query, a paused one, and a closed gate — never collapsing them into a generic "loading" or "loaded" reading.
