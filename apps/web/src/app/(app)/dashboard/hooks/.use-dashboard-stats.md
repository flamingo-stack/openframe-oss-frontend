# use-dashboard-stats.ts

React Query hooks that supply dashboard summary statistics for devices and support tickets, using `null` counters to explicitly encode "unknown" state rather than defaulting to `0`.

## Key Components

- **`useDevicesOverview()`** — Fetches device counts (total, active, inactive, pending, archived) and their percentages via `deviceQueryKeys.stats()`. Enabled only when the user is authenticated. All counters default to `null` (not `0`) when data is unavailable, since `0` would falsely claim "zero devices" instead of "data not loaded yet."

- **`useTicketsOverview()`** — Fetches ticket statistics (total, resolved, average resolve time, AI assistance rate, etc.). Gated on both authentication **and** SaaS tenant mode (`isSaasTenantMode()`); in OSS mode the query stays permanently closed via `queryState(query, 'closed')` rather than reporting as "loading" forever.

- **`useSharedDashboardData()`** — Composes both hooks above into a single object exposing combined loading state (`isAnyLoading`) and a `refetchAll()` helper to refresh both datasets together.

## Usage Example

```typescript
import { useSharedDashboardData } from './use-dashboard-stats';

function DashboardOverview() {
  const { devices, tickets, isAnyLoading, refetchAll } = useSharedDashboardData();

  if (isAnyLoading) {
    return <DashboardSkeleton />;
  }

  return (
    <>
      <StatCard
        label="Online Devices"
        value={devices.data.active ?? '—'}
        percentage={devices.data.activePercentage}
      />
      <StatCard
        label="Resolved Tickets"
        value={tickets.data.resolved ?? '—'}
      />
      <button onClick={refetchAll}>Refresh</button>
    </>
  );
}
```

**Important:** Always render `null` counter values as `'—'` (unavailable), never coerce them to `0` — a `0` implies a real, confirmed empty state, while `null` means the data hasn't loaded or an error occurred silently. Never feed `null` into progress rings or percentage widgets without an explicit fallback.
