Provides React Query hooks for fetching and exposing dashboard statistics for devices and tickets, with authentication gating and SaaS mode awareness.

## Key Components

### `useDevicesOverview()`
Fetches device stats (total, active, inactive, pending, archived counts and percentages). Only runs when the user is authenticated. Data is considered fresh for 1 minute and cached for 5 minutes.

### `useTicketsOverview()`
Fetches ticket stats (totals, resolution times, AI assistance rate, Fae rate). Gated by both authentication **and** SaaS tenant mode (`isSaasTenantMode()`). Stale time is 3 minutes with a 5-minute cache.

### `useSharedDashboardData()`
Composite hook that combines both queries into a single return value. Exposes a unified `isAnyLoading` flag and a `refetchAll()` helper that triggers both queries simultaneously.

## Usage Example

```typescript
// Using individual hooks
function DeviceStatsCard() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return <div>{active} / {total} active ({activePercentage}%)</div>;
}

// Using the composite hook
function DashboardPage() {
  const { devices, tickets, isAnyLoading, refetchAll } = useSharedDashboardData();

  return (
    <>
      <DeviceStatsCard data={devices.data} />
      <TicketStatsCard data={tickets.data} />
      <button onClick={refetchAll} disabled={isAnyLoading}>Refresh</button>
    </>
  );
}
```

## Notes

- Numeric fields are `number | null`. **`null` means "unknown", not "zero"** — it is what the hooks return whenever there is no data, including the error state. Consumers must render it as unavailable (`—`) and must not pass it to a progress ring. Coalescing to `0` here is what made the dashboard report `ONLINE DEVICES 0 (0%)` and every ticket count at `0`, with no error on screen, whenever the stats request failed. String fields still fall back to `'—'`.
- Ticket stats are **silently disabled** in non-SaaS (self-hosted) deployments — components consuming `useTicketsOverview` receive `null` counters rather than errors.
- Query keys are centralized via `dashboardQueryKeys` for consistent cache invalidation.
