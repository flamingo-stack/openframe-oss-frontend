# query-keys.ts

Centralized query key factory for React Query hooks used across the dashboard. It defines a consistent, hierarchical structure for cache keys, enabling predictable caching and targeted invalidation of dashboard-related queries.

## Key Components

- **`dashboardQueryKeys`** — A frozen object exposing query key builders:
  - `all` — Root key for all dashboard queries (`['dashboard']`).
  - `ticketStats()` — Key for ticket statistics (SaaS mode only).
  - `orgStatsAll()` — Root key for all organization statistics queries (used to invalidate across all `limit` variants).
  - `orgStats(limit)` — Key scoped to a specific organization stats query, parameterized by `limit`.
  - `ssoProviders()` — Key for SSO provider count (used during onboarding).
  - `userStats()` — Key for user statistics (used during onboarding).
  - `invalidateAll()` — Returns the root `all` key, useful for invalidating every dashboard-related query at once.

All keys are built using `as const` to preserve literal tuple types, ensuring type-safe usage with React Query's `queryKey` option.

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { dashboardQueryKeys } from './query-keys';

// Fetching organization stats with a limit
function useOrgStats(limit: number) {
  return useQuery({
    queryKey: dashboardQueryKeys.orgStats(limit),
    queryFn: () => fetchOrgStats(limit),
  });
}

// Invalidate all org stats queries regardless of limit
function useInvalidateOrgStats() {
  const queryClient = useQueryClient();
  return () => queryClient.invalidateQueries({
    queryKey: dashboardQueryKeys.orgStatsAll(),
  });
}

// Invalidate the entire dashboard cache (e.g., after logout)
function useInvalidateDashboard() {
  const queryClient = useQueryClient();
  return () => queryClient.invalidateQueries({
    queryKey: dashboardQueryKeys.invalidateAll(),
  });
}
```

This pattern keeps query keys consistent across components, avoids typos in manually constructed arrays, and simplifies cache invalidation logic when data changes.
