Centralized query key factory for React Query hooks used across the dashboard feature, providing consistent and type-safe cache key generation.

## Key Components

**`dashboardQueryKeys`** — A `const` object with factory functions for each dashboard query domain:

| Key | Description |
|-----|-------------|
| `all` | Root key `['dashboard']` — parent for all dashboard queries |
| `deviceStats()` | Cache key for device statistics data |
| `ticketStats()` | Cache key for ticket statistics (SaaS mode only) |
| `orgStats(limit)` | Cache key for organization stats, scoped by `limit` parameter |
| `ssoProviders()` | Cache key for SSO provider count (used in onboarding) |
| `userStats()` | Cache key for user statistics (used in onboarding) |
| `invalidateAll()` | Returns root key to invalidate all dashboard queries at once |

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { dashboardQueryKeys } from './query-keys';

// Fetch device stats
const { data } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
});

// Fetch org stats with a limit
const { data: orgs } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
});

// Invalidate all dashboard queries
const queryClient = useQueryClient();
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll(),
});
```

## Notes

- All keys extend the root `['dashboard']` key, enabling bulk invalidation via `invalidateAll()`.
- Keys are deeply `const`-typed via `as const`, ensuring full TypeScript inference in `useQuery` and `useQueryClient` calls.
