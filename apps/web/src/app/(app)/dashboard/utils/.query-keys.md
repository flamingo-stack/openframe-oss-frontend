# query-keys.ts

Defines a centralized, type-safe query key factory for React Query hooks used across the dashboard, ensuring consistent cache key generation and simplifying targeted or broad cache invalidation.

## Key Components

- **`dashboardQueryKeys`** — A frozen object providing hierarchical query key builders:
  - `all` — Root key (`['dashboard']`) shared by all dashboard queries.
  - `ticketStats()` — Key for ticket statistics (SaaS mode only).
  - `orgStatsAll()` — Invalidation root for all organization statistics queries, regardless of limit.
  - `orgStats(limit)` — Key for organization statistics scoped to a specific `limit` value.
  - `ssoProviders()` — Key for SSO provider count data (used during onboarding).
  - `userStats()` — Key for user statistics (used during onboarding).
  - `invalidateAll()` — Returns the root key, useful for invalidating every dashboard-related query at once.

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { dashboardQueryKeys } from './query-keys';

// Fetching organization stats with a specific limit
function useOrgStats(limit: number) {
  return useQuery({
    queryKey: dashboardQueryKeys.orgStats(limit),
    queryFn: () => fetchOrgStats(limit),
  });
}

// Invalidating all org stats queries regardless of limit
function invalidateOrgStats() {
  const queryClient = useQueryClient();
  queryClient.invalidateQueries({ queryKey: dashboardQueryKeys.orgStatsAll() });
}

// Invalidating the entire dashboard cache (e.g., on logout)
function invalidateDashboard() {
  const queryClient = useQueryClient();
  queryClient.invalidateQueries({ queryKey: dashboardQueryKeys.invalidateAll() });
}
```

Using this factory avoids hardcoded key arrays scattered throughout components, preventing cache mismatches and making it easy to invalidate related queries (e.g., all `orgStats` variants) via their shared parent key.
