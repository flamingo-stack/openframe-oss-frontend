# ticket.types.ts

TypeScript type definitions for the ticketing system, mirroring the GraphQL schema exposed by the `openframe-saas-ai-agent` backend. These types model tickets, attachments, notes, statuses, and the GraphQL mutation inputs/payloads used to interact with the ticket API.

## Key Components

- **`TicketStatus`** — union type of valid ticket lifecycle states (`ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED`).
- **`Ticket`** — the core ticket entity, including status, owner, assignee, tags, attachments, notes, and linked knowledge base articles.
- **`TicketOwner`** — identifies whether a ticket was opened by a `CLIENT` (with resolved `Machine`) or `ADMIN`.
- **`TicketAttachment` / `TempAttachment`** — persisted vs. temporary (pre-upload) file attachments.
- **`TicketNote`** — internal/author notes attached to a ticket.
- **`KnowledgeBaseArticle`** — linked KB articles referenced from a ticket.
- **`TicketStatusRef`** — lightweight status reference used for `statusDefinition` and `availableTransitions`.
- **GraphQL payload types** — `TicketPayload`, `TempAttachmentPayload`, `TicketAttachmentUploadPayload`, `DeletePayload`, all wrapping results with `UserError[]`.
- **Mutation input types** — `CreateTicketInput`, `UpdateTicketInput`, `AssignTicketInput`, `TicketIdInput` for creating/updating/assigning tickets.

## Usage Example

```typescript
import type { Ticket, CreateTicketInput, TicketPayload } from './ticket.types';

function buildCreateInput(title: string, deviceId: string): CreateTicketInput {
  return {
    title,
    deviceId,
    tagIds: [],
    tempAttachmentIds: [],
  };
}

function isResolved(ticket: Ticket): boolean {
  return ticket.status === 'RESOLVED' && !!ticket.resolvedAt;
}

function handleMutationResult(payload: TicketPayload) {
  if (payload.userErrors.length > 0) {
    console.error('Ticket mutation failed:', payload.userErrors);
    return;
  }
  console.log('Ticket saved:', payload.ticket?.ticketNumber);
}
```

These types are typically consumed by GraphQL query/mutation hooks and UI components that render ticket lists, detail views, and forms for ticket creation/assignment.
