Defines the Zod validation schema and inferred TypeScript type for the create ticket form, enforcing field constraints and nullable autocomplete values.

## Key Components

- **`createTicketSchema`** — Zod object schema validating all create-ticket form fields, including character limits, nullable autocomplete-backed fields, and nested assignment data
- **`CreateTicketFormData`** — TypeScript type inferred from `createTicketSchema`, used to type form state and submission handlers

## Field Reference

| Field | Type | Constraints |
|---|---|---|
| `title` | `string` | Required, max 255 chars |
| `description` | `string` | Max 5000 chars |
| `statusId` | `string \| null` | Optional, autocomplete |
| `organizationId` | `string \| null` | Optional, autocomplete |
| `deviceId` | `string \| null` | Optional, autocomplete |
| `assignedTo` | `string \| null` | Optional, autocomplete |
| `tagIds` | `string[]` | Max 20 items |
| `type` | `string` | Pending backend support |
| `assignKnowledgeBase` | `boolean` | — |
| `assignments` | `assignmentsSchema` | Nested schema |

> **Note:** `userId` (reporter) and `type` are schema-defined but not yet consumed by the backend. Both are pending the Authentik integration milestone.

## Usage Example

```typescript
import { createTicketSchema, type CreateTicketFormData } from './create-ticket.types';

const result = createTicketSchema.safeParse({
  title: 'Printer offline in Room 204',
  description: 'The HP LaserJet stopped responding after a firmware update.',
  statusId: 'status-open',
  organizationId: 'org-abc123',
  tagIds: ['tag-hardware'],
  type: 'incident',
  assignKnowledgeBase: true,
  assignments: [],
});

if (result.success) {
  const data: CreateTicketFormData = result.data;
  // submit data to API
}
```
