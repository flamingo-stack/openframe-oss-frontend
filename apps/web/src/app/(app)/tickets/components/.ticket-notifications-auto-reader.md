## TicketNotificationsAutoReader

A headless React component that marks a ticket's notifications and client chat messages as "read" once the ticket's client chat is visibly on screen and the user session is actively attended.

## Key Components

- **`TicketNotificationsAutoReader`** — The exported component. Renders `null`; its only purpose is side-effect orchestration.
- **`TicketNotificationsAutoReaderProps`** — Props interface:
  - `ticketId: string` — the ticket whose notifications are marked read.
  - `dialogId: string | null` — the client-chat dialog id, registered as an "active dialog view" while on screen to suppress live popups.
  - `clientChatOnScreen: boolean` — whether the chat pane is actually visible (vs. the Details tab).
  - `lastClientMessageId: string | null` — newest client (END-USER) message id; re-arms the message-read mark on each new client message.

It coordinates two independent read ledgers:
1. **Entity notifications** (`useMarkEntityNotificationsRead`) — fired once per ticket per mount, feeding the bell/drawer/sidebar counts.
2. **Dialog message counter** (`useMarkDialogMessagesRead`) — fired once per new client message while attended, feeding the board card's "New Message" badge shared across technicians.

Both effects are gated on `clientChatOnScreen` and on `isSessionActive` (via `subscribeAttention`/`ATTENTION_IDLE_MS`), ensuring a backgrounded or idle tab marks nothing.

## Usage Example

```typescript
import { TicketNotificationsAutoReader } from './ticket-notifications-auto-reader';

function TicketDetailsContent({ ticket, dialogId, activeTab, lastClientMessageId }) {
  return (
    <>
      <TicketNotificationsAutoReader
        ticketId={ticket.id}
        dialogId={dialogId}
        clientChatOnScreen={activeTab === 'chat'}
        lastClientMessageId={lastClientMessageId}
      />
      {/* rest of ticket details UI */}
    </>
  );
}
```

Mount this component alongside the ticket's chat UI; it requires no props beyond the ticket/dialog state already tracked by the parent page and automatically unsubscribes its attention listener and active-dialog-view registration on unmount or prop change.
