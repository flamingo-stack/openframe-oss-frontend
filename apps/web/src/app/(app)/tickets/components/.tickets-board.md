## Overview

`tickets-board.tsx` implements the kanban-style board view for the tickets module, rendering tickets as draggable cards grouped into status-based lanes. It integrates optimistic drag-and-drop ticket moves, real-time column updates via subscriptions, take-over/reopen lifecycle modals, and a comprehensive set of filters (organization, assignee, tag, activity, status, search).

## Key Components

- **`TicketsBoard`** *(implicit default export via props interface `TicketsBoardProps`)* — the main board component orchestrating filters, column rendering, and ticket drag-and-drop.
- **`toLaneDefinition()`** — converts a `TicketStatusDefinition` into a `CachedBoardColumn` layout definition, used both for live rendering and skeleton caching.
- **`applyHeldMove()`** — pure view-transform helper that re-seats a dropped ticket at its drop position to prevent visual snap-back while a lifecycle modal (Take Over/Reopen) is open.
- **`toBoardTicket()` / `dialogToBoardTicket()`** — map a `Dialog` into a `TicketsBoardTicket` (extended `BoardTicket` with `hideAssign`), with WeakMap-based memoization (`boardTicketCache`) keyed per dialog for render stability.
- **`isAiOwnedTicket()`** — determines whether a ticket should hide the assign control (AI-handled or AI/client-resolved tickets).
- **`HELD_MOVE_SETTLE_TIMEOUT_MS`** — timeout constant bounding how long a confirmed take-over drop's optimistic placement persists before falling back to server data.
- Integrates subcomponents: `BoardColumnSubscriber`, `BoardAssigneePicker`, `TakeOverTicketModal`, `ReopenTicketModal`, `ActivityFilter`, `AssigneeFilter`, `OrganizationFilter`, `StatusFilter`, `TicketTagFilter`, `TicketsFilterModal`, `TicketsEmptyState`.

## Usage Example

```typescript
import { TicketsBoard } from './tickets-board';

function TicketsPage() {
  const [search, setSearch] = useState('');
  const [organizationIds, setOrganizationIds] = useState<string[]>([]);

  return (
    <TicketsBoard
      search={search}
      onSearchChange={setSearch}
      organizationIds={organizationIds}
      onOrganizationIdsChange={setOrganizationIds}
      onFiltersChange={filters => console.log('filters updated', filters)}
    />
  );
}
```
