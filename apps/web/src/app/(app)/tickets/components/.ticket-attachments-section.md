# ticket-attachments-section.tsx

A React component that renders the attachments panel for a ticket's detail view, supporting file upload (web and native), listing, download, and deletion with confirmation.

## Key Components

- **`TicketAttachmentsSection`** — Main exported component that displays a ticket's attachment list, an "Add Files" upload button, and a delete confirmation dialog.
- **`TicketAttachmentsSectionProps`** — Props interface requiring `ticketId` (string) and `attachments` (non-nullable attachments array derived from `Dialog['attachments']`).
- **`handleFilesSelected`** — Handles the hidden `<input type="file">` change event, converting `FileList` to an array and triggering the upload mutation.
- **`addFiles`** — Platform-aware trigger: uses `pickNativeFiles` on native platforms (to stream uploads from a file path, avoiding CORS issues with `capacitor://localhost`) or synchronously clicks the hidden file input on web (preserving the user-gesture stack required by WebKit).
- **`confirmDelete`** — Confirms and executes attachment deletion via `useDeleteTicketAttachment`.

## Usage Example

```typescript
import { TicketAttachmentsSection } from './ticket-attachments-section';

function TicketDetailPanel({ ticket }: { ticket: Dialog }) {
  return (
    <div>
      <h2>{ticket.subject}</h2>
      <TicketAttachmentsSection
        ticketId={ticket.id}
        attachments={ticket.attachments ?? []}
      />
    </div>
  );
}
```

### Notes
- Relies on `useLoadingScope` to disable uploads while the parent ticket is still loading (attachments can only be added once the ticket has been read).
- Uses `useAddTicketAttachments` and `useDeleteTicketAttachment` mutation hooks for optimistic/server-state updates tied to `ticketId`.
- The file input's `value` is reset after selection so re-selecting the same file still fires a `change` event.
- Deletion is gated behind a `ConfirmDialog` to prevent accidental data loss.
