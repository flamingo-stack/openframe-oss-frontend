Provides autocomplete UI utilities for rendering status options with color swatches in dropdown/autocomplete components.

## Key Components

### `StatusOption`
Interface extending `AutocompleteOption` with an additional `color: string` field for swatch display.

### `renderStatusOption(option, isSelected)`
Renders a full autocomplete option row showing a `ColorSwatch`, truncated label, and a check icon when the option is selected.

### `statusStartAdornment(option)`
Returns a `ColorSwatch` as a start adornment for the selected value displayed in the autocomplete input field. Returns `undefined` if no option is provided.

## Usage Example

```typescript
import {
  renderStatusOption,
  statusStartAdornment,
  type StatusOption,
} from './status-autocomplete';

const statusOptions: StatusOption[] = [
  { value: 'open', label: 'Open', color: '#22c55e' },
  { value: 'closed', label: 'Closed', color: '#ef4444' },
];

<Autocomplete
  options={statusOptions}
  renderOption={renderStatusOption}
  startAdornment={statusStartAdornment(selectedStatus)}
/>
```
