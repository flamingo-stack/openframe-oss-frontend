Renders a status-based multi-select filter control used for narrowing tickets by status, built on top of the shared `Autocomplete` component with color-coded status indicators.

## Key Components

- **`StatusOption`** — Interface extending `AutocompleteOption` with a `color` field, representing a selectable status (e.g., "Open", "Closed") with an associated color.
- **`renderStatusOption(option, isSelected)`** — Renders a single option row showing a `ColorSwatch`, truncated label, and a checkmark icon (`CheckIcon`) when selected.
- **`statusStartAdornment(option)`** — Returns a `ColorSwatch` adornment for the currently selected single option, or `undefined` if none is selected.
- **`StatusFilter`** — The main exported component; a multi-select autocomplete filter for tenant statuses, displaying a filter icon placeholder and color-coded options.

## Usage Example

```typescript
import { StatusFilter, type StatusOption } from './status-autocomplete';
import { useState } from 'react';

const statusOptions: StatusOption[] = [
  { value: 'open', label: 'Open', color: '#22c55e' },
  { value: 'closed', label: 'Closed', color: '#ef4444' },
  { value: 'pending', label: 'Pending', color: '#f59e0b' },
];

function TicketFilters() {
  const [selectedStatuses, setSelectedStatuses] = useState<string[]>([]);

  return (
    <StatusFilter
      options={statusOptions}
      value={selectedStatuses}
      onChange={setSelectedStatuses}
      className="w-64"
    />
  );
}
```

This component is typically used within a ticket filtering UI (e.g., a filter modal or board toolbar) to let users narrow results by one or more status values, syncing with a `?status=` query parameter.
