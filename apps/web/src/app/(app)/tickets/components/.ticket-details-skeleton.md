Loading skeleton component for the ticket details page, matching the loaded sidebar layout to enable seamless transitions while ticket data loads.

## Key Components

### `TicketDetailsSkeleton` (exported)
The main skeleton component rendered by Next.js route-level loading.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `onBack` | `() => void` | Back button handler passed through to `PageLayout` |

### `SidebarLayoutSkeleton` (internal)
Mirrors the loaded layout: a main chat pane with a right sidebar containing Ticket Details info, Attachments, and Tags sections. Desktop-only sidebar hidden on mobile via `lg:` breakpoint.

### Constants
- `SIDEBAR_ACTIONS` — disabled "Edit Ticket" button for the header (Archive/Unarchive are status-dependent, so they are omitted)

## Usage Example

```typescript
// app/tickets/[id]/loading.tsx
'use client';

import { useRouter } from 'next/navigation';
import { TicketDetailsSkeleton } from './ticket-details-skeleton';

export default function Loading() {
  const router = useRouter();
  return <TicketDetailsSkeleton onBack={() => router.back()} />;
}
```
