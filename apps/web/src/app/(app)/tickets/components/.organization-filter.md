A multi-select autocomplete filter component for filtering by organization/customer, featuring debounced search and avatar-rendered options.

## Key Components

- **`OrganizationFilter`** — Main exported component that renders a multi-select autocomplete with a filter icon adornment
- **`OrganizationFilterProps`** — Interface defining `value` (selected org IDs), `onChange` callback, and optional `className`
- **`renderOption`** — Square-variant avatar renderer via `renderAvatarOption('square')` for organization list items

## Usage Example

```typescript
import { OrganizationFilter } from './organization-filter';

function TicketFilters() {
  const [selectedOrgs, setSelectedOrgs] = useState<string[]>([]);

  return (
    <OrganizationFilter
      value={selectedOrgs}
      onChange={setSelectedOrgs}
      className="w-64"
    />
  );
}
```

## Behavior Notes

- Search input is debounced by **300ms** before querying `useOrganizationOptions`, reducing unnecessary API calls
- `disableClientFilter` delegates all filtering to the server/hook rather than client-side
- Displays **"Show All Customers"** as placeholder when no selection is made
- Fetches options dynamically via [`useOrganizationOptions`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/hooks/use-ticket-options.ts) using the debounced search term
