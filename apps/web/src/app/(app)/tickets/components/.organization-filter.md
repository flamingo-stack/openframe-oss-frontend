# organization-filter.tsx

A React component that provides a multi-select, searchable autocomplete filter for selecting organizations (customers), typically used in ticket filtering UIs. It debounces user input to limit API/search calls and renders results with square avatar icons.

## Key Components

- **`OrganizationFilter`** — Main exported component rendering a multi-select `Autocomplete` for organizations.
- **`OrganizationFilterProps`** — Props interface:
  - `value: string[]` — currently selected organization IDs.
  - `onChange: (value: string[]) => void` — callback fired when selection changes.
  - `maxItems?: number` — optional cap on selectable items (useful when the backing API limits list size).
  - `className?: string` — optional styling override.
- **`renderOption`** — Pre-configured option renderer (via `renderAvatarOption('square')`) used to display each organization with a square avatar.
- Uses `useOrganizationOptions` (from `use-ticket-options`) to fetch filtered organization data, and `useDebounce` to debounce the search term (300ms) before triggering the fetch.

## Usage Example

```typescript
import { useState } from 'react';
import { OrganizationFilter } from './organization-filter';

function TicketFilters() {
  const [selectedOrgs, setSelectedOrgs] = useState<string[]>([]);

  return (
    <OrganizationFilter
      value={selectedOrgs}
      onChange={setSelectedOrgs}
      maxItems={20}
      className="w-64"
    />
  );
}
```

This component is intended to be embedded within a larger filter bar or form, where `selectedOrgs` can be passed along to a ticket query or API call to narrow results by organization.
