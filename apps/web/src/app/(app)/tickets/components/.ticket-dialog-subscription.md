# ticket-dialog-subscription.tsx

A headless React component that manages a JetStream (NATS) subscription for a single ticket dialog, streaming chat message chunks to a client-side processor while deduplicating redelivered sequences and notifying the parent when the stream catches up after a gap.

## Key Components

- **`TicketDialogSubscription`** — The default export, a render-less (`return null`) component that wires up a `useJetStreamDialogSubscription` subscription scoped to a dialog's `CLIENT` topic on the `CHAT_CHUNKS` stream.
- **`TicketDialogSubscriptionProps`** — Props interface:
  - `dialogId`: the active dialog to subscribe to (`null` disables subscription).
  - `dispatchChunk`: callback invoked with each new `ChunkData` chunk.
  - `clientInitialOptStartSeq`: resume sequence for replay (`0` = replay from stream start).
  - `isInitialOptStartSeqReady`: gate to delay consumer creation until history has loaded.
  - `onCaughtUp`: optional callback fired when `caughtUpCount` advances, signaling the parent should refetch persisted history after a reconnect gap.
- **Deduplication logic** (`lastClientStreamSeqRef`): drops JetStream redeliveries whose `streamSeq` was already applied, resetting on `dialogId` change.
- **Stable refs** (`dispatchRef`, `onCaughtUpRef`, `lastNotifiedCatchUpRef`): avoid stale closures and redundant parent notifications without re-subscribing.

```typescript
  const [historyReady, setHistoryReady] = useState(false);

  const handleChunk = useCallback((chunk: ChunkData) => {
    // append chunk to local message state
  }, []);

  const handleCaughtUp = useCallback(() => {
    // refetch persisted history to fill any gap
  }, []);

  return (
    <TicketDialogSubscription
      dialogId={dialogId}
      dispatchChunk={handleChunk}
      clientInitialOptStartSeq={startSeq}
      isInitialOptStartSeqReady={historyReady}
      onCaughtUp={handleCaughtUp}
    />
  );
}
```

Mount this component alongside your ticket dialog UI; it produces no visible output but drives real-time chunk delivery via side effects.
