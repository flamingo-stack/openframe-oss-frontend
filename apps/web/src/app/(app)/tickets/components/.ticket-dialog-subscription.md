Manages dual JetStream NATS subscriptions (client and admin/technician topics) for a ticket dialog, deduplicating redelivered messages and collapsing reconnect notifications into a single parent callback.

## Key Components

### `TicketDialogSubscription`
A render-less React component (`returns null`) that wires up two `useJetStreamDialogSubscription` hooks against the `CHAT_CHUNKS` JetStream stream:

- **Client topic** — subscribes to `NATS_TOPICS.MESSAGE`, replaying from `clientInitialOptStartSeq`
- **Admin topic** — subscribes to `NATS_TOPICS.ADMIN_MESSAGE`, gated by `subscribeAdmin`, replaying from `adminInitialOptStartSeq`

### Deduplication logic
Each topic tracks the last applied `streamSeq` via refs (`lastClientStreamSeqRef`, `lastAdminStreamSeqRef`). Chunks with a sequence ≤ the last seen value are silently dropped, protecting against JetStream redeliveries on reconnect. Both refs reset when `dialogId` changes.

### Reconnect notification
Because both subscriptions share one NATS connection, their `reconnectionCount` values increment together. The component collapses these into a single `onReconnected` callback by tracking `Math.max(clientReconnectionCount, adminReconnectionCount)` against a `lastNotifiedReconnectRef`.

> **Note:** The `CHAT_CHUNKS` stream retains ~10 minutes of history. Outages longer than that leave a gap JetStream replay cannot fill — the parent component is expected to refetch persisted history when `onReconnected` fires.

## Usage Example

```typescript
<TicketDialogSubscription
  dialogId={activeDialogId}
  dispatchChunk={(chunk, messageType) => {
    // route chunk to your state reducer or side processor
    dispatch({ type: 'CHUNK_RECEIVED', chunk, messageType });
  }}
  clientInitialOptStartSeq={clientSeq}   // 0 = replay from stream start
  adminInitialOptStartSeq={adminSeq}
  isInitialOptStartSeqReady={historyLoaded}
  subscribeAdmin={isTechnicianPanelVisible}
  onReconnected={() => {
    // refetch persisted history to cover any gap > 10 min
    refetchDialogHistory(activeDialogId);
  }}
/>
```
