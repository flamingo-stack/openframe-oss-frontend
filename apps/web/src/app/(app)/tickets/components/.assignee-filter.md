A client-side React component that renders a multi-select autocomplete filter for choosing assignees (employees), with avatar rendering and server-side search support.

## Key Components

- **`AssigneeFilter`** — Main exported component rendering a multi-select `Autocomplete` control for filtering by assignee.
- **`AssigneeFilterProps`** — Props interface: `value` (array of selected assignee IDs), `onChange` (callback invoked with updated selection), and optional `className` for styling.
- **`useAssigneeOptions`** — Hook (imported) that supplies sorted assignee options, loading state, and search handling; configured here with `selfFirst: true` to prioritize the current user in the list.
- **`renderAvatarOption`** — Utility (imported) used to build a `renderOption` function that displays each assignee with a round avatar.

## Usage Example

```typescript
import { useState } from 'react';
import { AssigneeFilter } from './assignee-filter';

function TaskFilters() {
  const [assigneeIds, setAssigneeIds] = useState<string[]>([]);

  return (
    <AssigneeFilter
      value={assigneeIds}
      onChange={setAssigneeIds}
      className="w-64"
    />
  );
}
```

The component disables client-side filtering (`disableClientFilter`) since search queries are handled remotely via `onSearchChange`, which is wired to the `useAssigneeOptions` hook's search handler. This makes it suitable for large assignee lists where filtering should happen server-side rather than against a fully loaded dataset. The `Filter02Icon` is displayed as a start adornment to visually indicate the filtering purpose of the control.
