Multi-select autocomplete filter component for filtering tickets by assignee, with the current user automatically prioritized at the top of the options list.

## Key Components

- **`AssigneeFilter`** — Main exported component that renders a multi-select autocomplete for employee/assignee filtering
- **`AssigneeFilterProps`** — Interface defining `value` (selected IDs), `onChange` callback, and optional `className`
- **`renderOption`** — Round avatar renderer via `renderAvatarOption('round')` for displaying user avatars in the dropdown
- **`sortedOptions`** — Memoized options array that hoists the current authenticated user to the first position

## Usage Example

```typescript
import { AssigneeFilter } from './assignee-filter';

function TicketFilters() {
  const [selectedAssignees, setSelectedAssignees] = useState<string[]>([]);

  return (
    <AssigneeFilter
      value={selectedAssignees}
      onChange={setSelectedAssignees}
      className="w-64"
    />
  );
}
```

## Behavior Notes

- Fetches assignee options via `useAssigneeOptions` hook (handles loading state internally)
- Reads the current user's ID from `useAuthStore` to sort them to the top of the list
- Defaults to showing all employees when no selection is made (`placeholder="Show All Employees"`)
- Supports multi-select via the `multiple` prop on the underlying `Autocomplete` component
