## Take-Over Ticket Modal

App-specific wrapper around the core-lib `TakeOverTicketModal` component that wires up status/assignee option lists, default selections, and the actual take-over mutation when a user confirms ownership transfer of a ticket.

## Key Components

- **`TakeOverTicketTarget`** — interface describing the ticket subset needed by the flow (`id`, `ticketNumber`, `title`, `dialogId`, `assignedTo`, `availableTransitions`, `currentMode`) plus optional trigger-specific prefills (`initialStatusId`, `initialAssigneeId`).
- **`TakeOverTicketModalProps`** — props for the wrapper: `target` (opens modal when non-null), `onClose`, and optional `onSuccess` callback fired with the confirmed selection before close.
- **`TakeOverTicketModal`** — the main exported component. Responsibilities:
  - Retains the last non-null `target` in state (`shown`) so the modal keeps rendering ticket data during the close animation.
  - Resolves the default assignee: `initialAssigneeId` → ticket's current assignee → signed-in user.
  - Builds `statusOptions` via `useMemo`, sorting allowed transitions with custom statuses first (in board order), using data from `useTicketStatusesQuery`.
  - Fetches assignee options via `useAssigneeOptions`, with the current user listed first.
  - Executes the take-over via `useTakeOverTicket().mutate()` on confirm, tracking a `RESOLVE_TICKET` analytics event when the new status is resolved (via `isResolvedStatusId`).
  - Delegates all presentation to `CoreTakeOverTicketModal` from `@flamingo-stack/openframe-frontend-core`.

## Usage Example

```typescript
import { TakeOverTicketModal, type TakeOverTicketTarget } from './take-over-ticket-modal';
import { useState } from 'react';

function TicketBoard() {
  const [takeOverTarget, setTakeOverTarget] = useState<TakeOverTicketTarget | null>(null);

  const handleAssignClick = (dialog: Dialog, pickedAssigneeId: string) => {
    setTakeOverTarget({
      ticket: dialog,
      initialAssigneeId: pickedAssigneeId,
    });
  };

  return (
    <TakeOverTicketModal
      target={takeOverTarget}
      onClose={() => setTakeOverTarget(null)}
      onSuccess={(selection) => {
        console.log('Ticket taken over with:', selection);
      }}
    />
  );
}
```
