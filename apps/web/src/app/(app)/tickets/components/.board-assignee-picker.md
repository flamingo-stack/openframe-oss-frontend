# board-assignee-picker.tsx

A memoized client component that renders a compact assignee picker for a single board ticket card, allowing users to search for and assign a user directly from within a Kanban-style board lane.

## Key Components

- **`BoardAssigneePicker`** — Memoized React component (wrapped with `memo`) that displays the current assignee (or an unassigned state) and exposes a searchable dropdown to reassign the ticket.
- **`BoardAssigneePickerProps`** — Props interface requiring a single `ticket: BoardTicket` object.
- **`useAssigneeOptions`** (hook) — Supplies the searchable list of assignable users, loading state, and search handler.
- **`useAssignTicket`** (hook) — Provides the mutation used to persist an assignee change, including pending state.

## Usage Example

```typescript
import { BoardAssigneePicker } from './board-assignee-picker';
import type { BoardTicket } from '@flamingo-stack/openframe-frontend-core/components/features';

function BoardCard({ ticket }: { ticket: BoardTicket }) {
  return (
    <div className="board-card">
      <h4>{ticket.title}</h4>
      <BoardAssigneePicker ticket={ticket} />
    </div>
  );
}
```

## Notes

- The component is memoized because it is rendered inside every card on the board; without memoization, a single board-level update would trigger a re-render of every lane and card.
- The first entry in `ticket.assignees` is treated as the current assignee; the dropdown falls back to displaying `initials` or the raw `id` if no `name` is available.
- Assignment changes are performed by calling `assign.mutate({ ticketId, assigneeId })` from the `useAssignTicket` hook, with `isPending` passed through to disable/indicate loading state in the UI.
