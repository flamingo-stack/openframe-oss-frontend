# ticket-tags-section.tsx

Renders and manages the tags assigned to a ticket, allowing users to view, add, remove, create, and delete tags via a dropdown selector with inline chips.

## Key Components

- **`TicketTagsSection`** — React component that displays a ticket's current tags as removable `Tag` chips and provides a `TagSelectDropdown` for selecting, creating, or deleting tags.
- **`TicketTagsSectionProps`** — Props interface requiring `ticketId: string` and `tags: NonNullable<Dialog['tags']>`.

### Internal behavior

- Uses `useLoadingScope` to guard against stale writes while the ticket is still loading (tag mutations send the entire tag list, so an early write could overwrite unknown tags).
- Fetches all available tags via `useTicketTags` and builds dropdown `options` from them.
- Uses `useSetTicketTags(ticketId)` to persist the full selected tag ID list on change, removal, or creation.
- Uses `useCreateTagMutation` to create new tags scoped to `entityType: 'TICKET'`, then refetches and appends the new tag's ID to the selection.
- Uses `useTicketTagDelete` to handle tag deletion confirmation (`dialog`) and sync local selection if a deleted tag was selected.

## Usage Example

```typescript
import { TicketTagsSection } from '@/app/components/ticket-detail/components/ticket-tags-section';

function TicketDetailPanel({ ticket }: { ticket: Dialog }) {
  return (
    <TicketTagsSection
      ticketId={ticket.id}
      tags={ticket.tags ?? []}
    />
  );
}
```

The component is self-contained: pass the ticket ID and its current tags, and it handles fetching available tags, rendering chips, and wiring up the create/select/delete dropdown interactions internally.
