Renders the shared form field layout for creating and editing support tickets, wiring together React Hook Form controllers with UI components for title, customer, device, assignee, status, tags, file attachments, description, and assignments.

## Key Components

### `TicketFormFields` (default export)
The primary component accepting:
- **`form`** — `UseFormReturn<CreateTicketFormData>` from React Hook Form
- **`tempAttachments`** — attachment state/handlers from `useTempAttachments`
- **`isFaeForm`** — disables customer/device/status/description fields for client-facing (Fae) forms
- **`isEditMode`** — switches status options from full list to available transitions only
- **`ticket`** — existing ticket data used to seed device hostname and resolve current status

### Internal Logic
- **Debounced search** — `orgSearch` and `deviceSearch` are debounced 300ms before querying
- **Self-assign shortcut** — bubbles the signed-in user to the top of the assignee list
- **Device list seeding** — injects the ticket's current device (by hostname) when it falls outside the fetched page
- **Status lifecycle** — in edit mode, builds options from `availableTransitions`; in create mode, auto-selects the first status once loaded
- **File status mapping** — normalizes `'existing'` attachment status to `'uploaded'` for the `FileUpload` component

## Usage Example

```typescript
import { TicketFormFields } from './ticket-form-fields';
import { useForm } from 'react-hook-form';
import { useTempAttachments } from '../../hooks/use-temp-attachments';

function CreateTicketForm() {
  const form = useForm<CreateTicketFormData>();
  const tempAttachments = useTempAttachments();

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <TicketFormFields
        form={form}
        tempAttachments={tempAttachments}
        isFaeForm={false}
        isEditMode={false}
      />
    </form>
  );
}
```
