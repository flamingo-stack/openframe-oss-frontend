## ticket-form-fields.tsx

Renders the shared form field set for creating and editing support tickets, including title, customer/device/assignee autocompletes, status selection, markdown description editor, file attachments, and tag management. Handles complex option-pinning logic so previously-selected values (from a ticket snapshot or prefill data) remain visible in paginated autocomplete lists even if they fall outside the current search results.

## Key Components

- **`TicketFormFields`** — Main component rendering all ticket form fields, wired to a `react-hook-form` instance via `Controller`/`useWatch`.
- **`withOption`** — Utility that pins a single option (e.g., the ticket's current organization/device/assignee) into a fetched options list when it's missing from the current page of results.
- **`TicketFormFieldsProps`** — Props interface: `form`, `tempAttachments`, `isFaeForm`, `isEditMode`, `ticket`, and `prefill`.
- Internal memoized derivations: `ticketOrg`, `ticketDevice`, `ticketAssignee`, `organizationOptionsList`, `deviceOptionsList`, `assigneeOptionsList`, `statusOptions`.
- Status-locking logic via `isStatusLockedByPendingApproval` to disable transitions when a ticket's `TECH_REQUIRED` status has a pending approval.
- Lazy-loaded `MarkdownEditor` (via `lazyMarkdownEditor`) with `renderPreview` using `SimpleMarkdownRenderer`.
- `handleFilesAdded` / `managedFiles` — Bridges `useTempAttachments` state into the `FileUpload` component's expected shape.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { TicketFormFields } from './ticket-form-fields';
import { useTempAttachments } from '../../hooks/use-temp-attachments';
import type { CreateTicketFormData } from '../../types/create-ticket.types';

function CreateTicketForm({ prefill }: { prefill?: TicketPrefill }) {
  const form = useForm<CreateTicketFormData>({
    defaultValues: { title: '', organizationId: null, deviceId: null },
  });
  const tempAttachments = useTempAttachments();

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <TicketFormFields
        form={form}
        tempAttachments={tempAttachments}
        isEditMode={false}
        prefill={prefill}
      />
    </form>
  );
}
```

For edit mode, pass the existing `ticket` object instead of `prefill`, and set `isEditMode={true}` so the status field reflects available transitions and lock state based on pending approvals.
