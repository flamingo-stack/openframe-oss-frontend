## Overview

`TicketTagsManager` is a React client component that renders a creatable, multi-select autocomplete for managing tags on a ticket, with optimistic UI updates while new tags are being created on the server and support for deleting existing tags.

## Key Components

- **`TicketTagsManagerProps`** — Props interface: `selectedIds` (currently selected tag IDs), `onChange` (callback invoked with the updated ID list), and optional `disabled` flag.
- **`TicketTagsManager`** — Main component that:
  - Fetches available tags via `useTicketTags()`.
  - Creates new tags via `useCreateTagMutation()`, tracking in-flight creation state.
  - Maintains `optimisticTags` state to show placeholder chips immediately when a new tag is typed, before the server confirms creation.
  - Uses a ref (`selectedIdsRef`) to always resolve async tag-creation callbacks against the latest selection, avoiding stale-closure bugs when multiple tags are created concurrently.
  - Handles deletion of tags via `useTicketTagDelete`, removing deleted tag IDs from the selection.
  - Renders an `Autocomplete` component (from `@flamingo-stack/openframe-frontend-core`) configured for multi-select, free-text tag creation, and deletion.

## Usage Example

```typescript
import { TicketTagsManager } from './ticket-tags-manager';
import { useState } from 'react';

function TicketEditor() {
  const [tagIds, setTagIds] = useState<string[]>([]);

  return (
    <TicketTagsManager
      selectedIds={tagIds}
      onChange={setTagIds}
      disabled={false}
    />
  );
}
```

When a user types a new tag name and confirms it, the component optimistically adds a placeholder tag ID (prefixed with `OPTIMISTIC_TAG_ID_PREFIX`) to `selectedIds`, calls `createTag` to persist it, and once the server responds, swaps the placeholder ID for the real tag ID (or removes it on failure) via the `onChange` callback.
