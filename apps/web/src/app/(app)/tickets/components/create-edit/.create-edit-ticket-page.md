# create-edit-ticket-page.tsx

Page component that renders a unified create/edit interface for support tickets, switching modes based on an `edit` query parameter and handling prefill values for ticket creation.

## Key Components

- **`CreateEditTicketPage`** — Default export function component that orchestrates ticket creation/editing:
  - Reads `edit` search param to determine `ticketId` and derive edit vs. create mode.
  - Builds a one-time `prefill` object from `TICKET_PREFILL_KEYS` (only in create mode) using `useMemo`, since the form owns prefill values after mount.
  - Delegates form state and submission logic to `useCreateTicketForm`.
  - Computes navigation `backButton` via `useSafeBack`, routing to the ticket dialog (edit mode) or the ticket list (create mode).
  - Builds header/footer `actions` (Cancel, Save) with proper disabled/loading states — notably guarding against saving a blank form over an unloaded ticket using `ticketLoaded`.
  - Renders `PageLayout` with a `LoadingWhen` wrapper around `TicketFormFields` to show skeleton loading while an existing ticket is being fetched.

## Usage Example

```typescript
// Rendered by a Next.js route, e.g. app/tickets/create-edit/page.tsx
import { CreateEditTicketPage } from './create-edit-ticket-page';

export default function Page() {
  return <CreateEditTicketPage />;
}
```

Navigating to a route like `?edit=123` loads ticket `123` in edit mode, while a route with prefill query params (matching `TICKET_PREFILL_KEYS`, e.g. `?subject=...`) seeds a new ticket form in create mode. The component itself takes no props — all state is derived from the URL via `useSearchParams`.

## Notes

- `prefill` is intentionally computed once per `ticketId`/`searchParams` change and is read only on form mount; subsequent edits are owned by `useCreateTicketForm`.
- The Cancel button is mobile/tablet-only (`showOnlyMobile`), since desktop relies on the `PageLayout` back button.
- Save is disabled in edit mode until `ticketLoaded` is true, preventing accidental overwrites from a paused/no-data query state.
