# ticket-tag-filter.tsx

A client-side React component that renders a search and tag-filtering UI for tickets, wiring the shared `TagFilterBar` component to tenant-specific ticket tags fetched via a custom hook.

## Key Components

- **`TicketTagFilter`** — The main exported component. Combines a search input and tag selector for filtering tickets by text and tag IDs.
- **`TicketTagFilterProps`** — Interface defining the component's props:
  - `search` / `onSearchChange` — controlled search input state and handler
  - `tagIds` / `onTagIdsChange` — controlled selected tag IDs state and handler
  - `filterButton` (optional) — a `ReactNode` slot for a mobile filter trigger button rendered next to the search input
- Uses `useTicketTags` hook internally to fetch available tags and `isLoading` state, then maps them to the `{ id, key }` shape expected by `TagFilterBar`.

## Usage Example

```typescript
'use client';

import { useState } from 'react';
import { TicketTagFilter } from './ticket-tag-filter';

export function TicketListToolbar() {
  const [search, setSearch] = useState('');
  const [tagIds, setTagIds] = useState<string[]>([]);

  return (
    <TicketTagFilter
      search={search}
      onSearchChange={setSearch}
      tagIds={tagIds}
      onTagIdsChange={setTagIds}
      filterButton={<button className="md:hidden">Filters</button>}
    />
  );
}
```

This component is typically placed above a ticket list/table to let users filter results by free-text search and by one or more tags. The `tags` list is memoized to avoid unnecessary re-renders when `allTags` reference remains stable.
