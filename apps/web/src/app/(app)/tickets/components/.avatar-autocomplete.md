# avatar-autocomplete.tsx

Provides reusable rendering helpers for autocomplete components that display avatar-based options, such as assignee or user pickers in ticket forms. These helpers generate consistent option rows (with avatar, label, and selection checkmark) and start adornments for selected values.

## Key Components

- **`AvatarVariant`** — Type alias for avatar shape options: `'round'` or `'square'`.
- **`renderAvatarOption(variant)`** — Factory function that returns an `AvatarOptionRow` renderer for use as an `AutocompleteOption` item renderer. Displays the option's avatar (via `SquareAvatar`), a truncated label, and a `CheckIcon` when the option is selected.
- **`avatarStartAdornment(option, variant)`** — Builds a `SquareAvatar` element to use as the start adornment inside an autocomplete input, representing the currently selected option. Returns `undefined` if no option is provided.

## Usage Example

```typescript
import { Autocomplete } from '@flamingo-stack/openframe-frontend-core/components/ui';
import { renderAvatarOption, avatarStartAdornment } from './avatar-autocomplete';
import type { AvatarOption } from '../hooks/use-ticket-options';

function AssigneePicker({ options, value }: { options: AvatarOption[]; value?: AvatarOption }) {
  return (
    <Autocomplete
      options={options}
      value={value}
      renderOption={renderAvatarOption('round')}
      startAdornment={avatarStartAdornment(value, 'round')}
    />
  );
}
```

Both functions rely on `getFullImageUrl` to resolve relative `imageUrl` values into full image URLs, ensuring avatars render correctly regardless of how the backend returns image paths.
