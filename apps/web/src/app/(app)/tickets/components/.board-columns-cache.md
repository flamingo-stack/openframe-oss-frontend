# board-columns-cache.ts

Persists the last-seen set of ticket board columns to `localStorage` so the loading skeleton can render the same lanes (count, colors, labels) the board is about to show, avoiding a layout shift when real data arrives. Mirrors the sidebar-width seeding pattern used elsewhere in the app.

## Key Components

- **`CachedBoardColumn`** — Serializable shape of a board column (id, label, color, system flag, optional `statusKey`/`tooltip`) used for the cache.
- **`readCachedBoardColumns()`** — Reads and validates the cached column list from `localStorage`; returns `null` on missing/invalid/malformed data. Picks fields explicitly (no spread) to avoid leaking stale extra keys into `BoardColumnDef`.
- **`buildPlaceholderBoardColumns()`** — Returns placeholder `BoardColumnDef[]` lanes: cached columns marked `isLoading` with empty tickets, or a cold-start fallback of the three system statuses (`AI_ASSISTANCE`, `TECH_REQUIRED`, `RESOLVED`).
- **`usePlaceholderBoardColumns()`** — Hydration-safe hook for use in render. Always starts with the system fallback on first mount (server and client agree), then swaps in the cached tenant-specific columns right after mount via `useEffect`, avoiding SSR hydration mismatches.
- **`writeCachedBoardColumns(columns)`** — Writes the current column set to `localStorage`, skipping redundant writes and silently failing in private browsing/quota-exceeded scenarios.

## Usage Example

```typescript
import {
  usePlaceholderBoardColumns,
  writeCachedBoardColumns,
} from './board-columns-cache';

function TicketsBoard() {
  // Render-safe placeholder lanes while the real statuses query is in flight
  const placeholderColumns = usePlaceholderBoardColumns();

  const { data: statuses, isLoading } = useTicketStatusesQuery();

  useEffect(() => {
    if (statuses) {
      // Persist the real lane set for the next visit's skeleton
      writeCachedBoardColumns(
        statuses.map(s => ({
          id: s.id,
          statusKey: s.key,
          label: s.label,
          color: s.color,
          system: s.system,
          tooltip: s.tooltip,
        })),
      );
    }
  }, [statuses]);

  const columns = isLoading ? placeholderColumns : statuses;

  return <BoardColumns columns={columns} />;
}
```
