## ticket-table-columns.tsx

Defines the column configuration and cell renderers for the tickets `DataTable`, including title, source, assignee, status, and the trailing open/unread-count column, plus a composed `TicketTableBody` component built on `LiveTable`.

## Key Components

- **`getTicketTableColumns(options)`** — Builds the core `ColumnDef<Dialog>[]` array (title, source, assignee, status) with optional filtering (status/assignee multi-select), sort support, and archived-mode behavior.
- **`getTicketOpenColumn(getUnreadCount?)`** — Returns the trailing column that shows an unread-message badge or an "open in new tab" button.
- **`ticketRowHref(ticket)`** — Resolves the ticket detail route (`routes.tickets.dialog`).
- **`StatusFilterOption`** — Interface for status/assignee filter options (`id`, `value`, `label`).
- **`LEGACY_STATUS_FILTER_OPTIONS`** — Fallback status filter list used when the `ticket-statuses` feature flag is off.
- **`TicketTitleCell`, `TicketSourceCell`, `TicketAssigneeCell`, `TicketOpenCell`** — Internal cell renderers handling loading skeletons, deleted-user avatars, AI-handling edge cases, and unassigned ticket interactions.
- **`TicketTableBodyProps` / `TicketTableBodyOptions`** — Props shape for the ticket table body component wrapping `LiveTable` with loading, pending, empty-state, sticky header, infinite scroll, and filter/sort wiring.
- **`DEFAULT_EMPTY_STATE`** — Default empty-state copy ("No tickets found.").

## Usage Example

```typescript
import { getTicketTableColumns, getTicketOpenColumn } from './ticket-table-columns';

const columns = [
  ...getTicketTableColumns({
    isArchived: false,
    statusOptions: myStatusOptions,
    assigneeOptions: myAssigneeOptions,
    isUserDeleted: (id) => deletedUserIds.has(id ?? ''),
    sortable: true,
  }),
  getTicketOpenColumn((ticket) => unreadCounts[ticket.id]),
];

// Pass `columns` to a `DataTable` / `LiveTable` instance rendering `Dialog[]` rows.
```

Consumers typically combine these columns with `LiveTable` to render the tickets list, device tabs, or customer tabs, adjusting `isArchived`, `sortable`, and filter options based on context (e.g., the `/tickets` page enables sorting and filters, while device/customer tabs render a read-only subset).
