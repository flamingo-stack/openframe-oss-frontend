# table-assignee-cell.tsx

Renders the "ASSIGNED" table cell for tickets that have no owner yet, showing an "Unassigned" label with a ghost avatar. When interactive, it offers a searchable dropdown to perform the first assignment directly from the table row.

## Key Components

- **`UnassignedTicketCell`** — Memoized React component rendering the unassigned state for a ticket row. Accepts:
  - `ticketId: string` — the ticket to assign.
  - `interactive: boolean` — toggles whether the assign dropdown is shown. Disabled for archived rows and tickets the AI is still working on (those re-assignments happen on the ticket details page instead).
- **`UnassignedFace`** — Internal presentational component rendering the ghost avatar + "Unassigned" text, with optional hover styling when `interactive`.

## Usage Example

```typescript
import { UnassignedTicketCell } from './table-assignee-cell';

function TicketRow({ ticket }: { ticket: Ticket }) {
  const isArchived = ticket.status === 'archived';
  const aiInProgress = ticket.status === 'ai_working';

  return (
    <tr>
      <td>{ticket.subject}</td>
      <td>
        <UnassignedTicketCell
          ticketId={ticket.id}
          interactive={!isArchived && !aiInProgress}
        />
      </td>
    </tr>
  );
}
```

**Behavior notes:**
- Uses `useAssigneeOptions` to fetch/search assignable users (server-searched, cached in the Relay store after first load) and `useAssignTicket` to perform the mutation on selection.
- The clickable trigger has `data-no-row-click` to prevent the table row's navigation handler from firing when interacting with the picker.
- Non-interactive rendering skips loading assignee options entirely for performance.
