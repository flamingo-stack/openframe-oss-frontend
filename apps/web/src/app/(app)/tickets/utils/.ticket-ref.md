# ticket-ref.ts

Provides a single formatting utility that standardizes how tickets are displayed across the UI, ensuring a consistent `{number}: {title}` label format matching the Figma design specs for Take Over/Reopen modals, Mingo @-mention chips, and the ticket page's open-view context.

## Key Components

- **`formatTicketRef(ticket, fallback?)`** - Formats a ticket's number and title into a single display string. Handles missing number, missing title, or both missing (returns `fallback`). No `#` prefix is ever added to the ticket number.

## Usage Example

```typescript
import { formatTicketRef } from './ticket-ref';

// Both number and title present
formatTicketRef({ ticketNumber: 1003, title: 'Email client synchronization issues' });
// => "1003: Email client synchronization issues"

// Only number present
formatTicketRef({ ticketNumber: 1003, title: null });
// => "1003"

// Only title present
formatTicketRef({ ticketNumber: null, title: 'Email client synchronization issues' });
// => "Email client synchronization issues"

// Neither present - falls back to provided default (e.g. ticket id)
formatTicketRef({ ticketNumber: null, title: null }, 'ticket-abc123');
// => "ticket-abc123"
```

## Notes

- The ticket number is never prefixed with `#` - this is an intentional design decision reflected in the Figma specs.
- Whitespace in `title` is trimmed before formatting.
- `fallback` defaults to an empty string but is typically passed as the ticket's internal id to avoid rendering a blank label.
