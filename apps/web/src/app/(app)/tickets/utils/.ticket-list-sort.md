Utility module for managing ticket list sorting state, providing conversion between URL parameters and sort objects for the ticket number column. Since the tickets table only sorts by ticket number, this module centralizes the logic for parsing, serializing, and toggling that single sort dimension.

## Key Components

- **`TICKET_NUMBER_SORT_FIELD`** - Constant identifying the only sortable field (`'ticketNumber'`).
- **`DEFAULT_TICKET_LIST_SORT`** - Default sort state: newest tickets first (`DESC`).
- **`parseTicketListSort(sortDir)`** - Converts a `?sortDir=` URL param into a `TicketListSort` object. Any value other than `'asc'` falls back to the default (`DESC`), preventing invalid or stale URLs from producing an inconsistent UI state.
- **`ticketListSortToParams(sort)`** - Converts a `TicketListSort` object back into a URL param. Returns `''` for the default `DESC` direction so it's omitted from the URL by `useApiParams`, keeping URLs clean.
- **`toggleTicketListSort(current)`** - Flips the sort direction between `ASC` and `DESC`. Since there's no "unsorted" state for this column, toggling is a simple two-state switch.

## Usage Example

```typescript
import {
  DEFAULT_TICKET_LIST_SORT,
  parseTicketListSort,
  ticketListSortToParams,
  toggleTicketListSort,
} from './ticket-list-sort';

// Parse sort state from URL
const sort = parseTicketListSort('asc');
// => { field: 'ticketNumber', direction: 'ASC' }

// Serialize sort state back to URL params
const params = ticketListSortToParams(sort);
// => { sortDir: 'asc' }

// Handle header click to toggle direction
function onHeaderClick(current = DEFAULT_TICKET_LIST_SORT) {
  const next = toggleTicketListSort(current);
  const urlParams = ticketListSortToParams(next);
  // update URL / query state with urlParams
}
```

This module is typically consumed by components managing the tickets table header and URL-driven sort state, working alongside `useApiParams` to keep sort state synchronized with the URL without polluting it with default values.
