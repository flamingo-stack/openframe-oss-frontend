# query-keys.ts

Defines centralized React Query key factories for the dialogs/tickets feature, along with typed query parameters and a cache-invalidation helper. Structured key hierarchies ensure consistent, collision-free cache entries across list, board-column, and detail queries.

## Key Components

- **`DialogsQueryParams`** — Interface describing all filterable/sortable parameters for dialog list queries (archived state, search, status/org/device/assignee/tag filters, unread flag, sort, page size).
- **`dialogsQueryKeys`** — Key factory object for dialogs queries:
  - `all` — root key for all dialogs queries.
  - `lists()` — key for all list queries.
  - `list(params)` — normalized key for a specific filtered/sorted list (used with `useInfiniteQuery`; cursor is excluded).
  - `boardColumns()` — key for all Kanban-style board column queries.
  - `boardColumn(statusId, params)` — key for a single board column's infinite query, scoped by status and filters.
- **`invalidateAllDialogs(queryClient)`** — Utility to invalidate every cached dialogs query at once.
- **`ticketsQueryKeys`** — Key factory object for ticket-specific queries: `all`, `tags()`, `detail(id)`, `editForm(id)`, `statistics()`, `statusTransitions()`, `statusTransitionRules()`, `statuses()`.

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { dialogsQueryKeys, ticketsQueryKeys, invalidateAllDialogs } from './query-keys';

// Fetch a filtered dialogs list
const { data } = useQuery({
  queryKey: dialogsQueryKeys.list({ archived: false, search: 'network', unreadOnly: true }),
  queryFn: () => fetchDialogs({ archived: false, search: 'network' }),
});

// Fetch a board column for a given status
useQuery({
  queryKey: dialogsQueryKeys.boardColumn('status-123', { search: '', unreadOnly: false }),
  queryFn: () => fetchBoardColumn('status-123'),
});

// Fetch ticket details
useQuery({
  queryKey: ticketsQueryKeys.detail('ticket-456'),
  queryFn: () => fetchTicket('ticket-456'),
});

// Invalidate all dialogs caches after a mutation
const queryClient = useQueryClient();
invalidateAllDialogs(queryClient);
```

**Note:** `list` and `boardColumn` keys normalize optional params (defaulting arrays to `[]`, strings to `''`) so equivalent filter states always produce identical cache keys.
