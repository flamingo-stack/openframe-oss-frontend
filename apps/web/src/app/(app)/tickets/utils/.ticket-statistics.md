Utility module for aggregating and deriving ticket counts from raw status-definition statistics returned by the backend, grouping tickets by their lifecycle status kind (AI assistance, tech required, resolved, custom, archived).

## Key Components

- **`TicketStatusDefinitionCount`** — Interface pairing a status definition (kind + optional color) with its ticket count.
- **`TicketStatisticsCounts`** — Interface wrapping an array of `TicketStatusDefinitionCount` entries, representing raw statistics from the backend.
- **`TICKET_STATUS_KIND`** — Constant object mirroring the backend's `TicketStatusKind` enum (`AI_ASSISTANCE`, `TECH_REQUIRED`, `RESOLVED`, `ARCHIVED`, `CUSTOM`).
- **`kindColorFromStatistics(stats, kind)`** — Returns the color associated with the first status matching a given kind.
- **`resolvedCountFromStatistics(stats)`** — Returns the total count of tickets with `RESOLVED` kind.
- **`totalCountFromStatistics(stats)`** — Returns the sum of all ticket counts across every status, useful for checking if any tickets exist.
- **`TicketKindCounts`** — Interface summarizing counts grouped into `aiAssistance`, `techRequired`, `resolved`, and `otherStatuses` (custom statuses).
- **`kindCountsFromStatistics(stats)`** — Builds a `TicketKindCounts` object by summing counts per kind.

## Usage Example

```typescript
import {
  kindCountsFromStatistics,
  resolvedCountFromStatistics,
  totalCountFromStatistics,
  kindColorFromStatistics,
  TICKET_STATUS_KIND,
  type TicketStatisticsCounts,
} from './ticket-statistics';

const stats: TicketStatisticsCounts = {
  statusDefinitionCounts: [
    { status: { kind: 'AI_ASSISTANCE', color: '#00f' }, count: 5 },
    { status: { kind: 'RESOLVED', color: '#0f0' }, count: 12 },
    { status: { kind: 'CUSTOM', color: '#ccc' }, count: 3 },
  ],
};

const counts = kindCountsFromStatistics(stats);
// { aiAssistance: 5, techRequired: 0, resolved: 12, otherStatuses: 3 }

const total = totalCountFromStatistics(stats); // 20
const resolved = resolvedCountFromStatistics(stats); // 12
const color = kindColorFromStatistics(stats, TICKET_STATUS_KIND.RESOLVED); // '#0f0'
```
