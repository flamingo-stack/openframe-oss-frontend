# ticket-row-meta.ts

Builds the secondary metadata line (`3891 • 5 min ago`) shown beneath a ticket title in ticket table rows, per Figma spec 8002-256659.

## Key Components

- **`META_SEPARATOR`** — The literal string `' • '` used to join the ticket number and relative time.
- **`formatTicketRowMeta(ticket)`** — Formats a ticket's number and creation time into a single display string, omitting either part if unavailable.

## Behavior Notes

- The ticket number is always placed first so that if the cell truncates, the time is dropped before the number.
- If either the number or the time is missing, that half is simply omitted (no dangling separator).
- Time is computed from `createdAt` (time since creation), which differs intentionally from the board card's relative time, which uses `statusUpdatedAt ?? createdAt` (time since last lifecycle change). Both use the same underlying `formatTicketRelativeTime` formatter, but with different inputs per design.

## Usage Example

```typescript
import { formatTicketRowMeta } from './ticket-row-meta';

formatTicketRowMeta({ ticketNumber: 3891, createdAt: '2024-01-15T10:00:00Z' });
// => "3891 • 5 min ago"

formatTicketRowMeta({ ticketNumber: 3891, createdAt: null });
// => "3891"

formatTicketRowMeta({ ticketNumber: null, createdAt: '2024-01-15T10:00:00Z' });
// => "5 min ago"

formatTicketRowMeta({ ticketNumber: null, createdAt: null });
// => ""
```
