# use-ticket-detail-mutations.ts

A set of React Query mutation hooks for inline editing actions on the ticket detail view. Unlike the edit-form flow (`useUpdateTicket`), these mutations refresh the detail cache in place and keep the user on the page rather than navigating away.

## Key Components

- **`updateTicket(input)`** — Internal helper that sends the `UPDATE_TICKET_MUTATION` GraphQL request via `apiClient`, extracts the payload, and throws on user errors.
- **`useTicketCacheInvalidation(ticketId)`** — Internal hook returning a callback that invalidates the ticket detail query and dialogs query cache.
- **`useSetTicketTags(ticketId)`** — Mutation hook to replace a ticket's full tag set. Invalidates cache on success; shows a destructive toast on error.
- **`useAddTicketAttachments(ticketId)`** — Mutation hook that uploads files as temp attachments (via `createTempAttachment`) and attaches them to the ticket. Shows success/error toasts.
- **`useDeleteTicketAttachment(ticketId)`** — Mutation hook to permanently delete a ticket attachment via `DELETE_TICKET_ATTACHMENT` GraphQL mutation. Shows success/error toasts.

## Usage Example

```typescript
import {
  useSetTicketTags,
  useAddTicketAttachments,
  useDeleteTicketAttachment,
} from './use-ticket-detail-mutations';

function TicketDetailPanel({ ticketId }: { ticketId: string }) {
  const setTags = useSetTicketTags(ticketId);
  const addAttachments = useAddTicketAttachments(ticketId);
  const deleteAttachment = useDeleteTicketAttachment(ticketId);

  const handleTagsChange = (tagIds: string[]) => {
    setTags.mutate(tagIds);
  };

  const handleFileUpload = (files: UploadSource[]) => {
    addAttachments.mutate(files);
  };

  const handleRemoveAttachment = (attachmentId: string) => {
    deleteAttachment.mutate(attachmentId);
  };

  return null; // render UI using mutation states (isPending, etc.)
}
```

Each hook returns a standard `useMutation` result (`mutate`, `mutateAsync`, `isPending`, etc.) from `@tanstack/react-query`, enabling fine-grained control over loading and error states in the UI.
