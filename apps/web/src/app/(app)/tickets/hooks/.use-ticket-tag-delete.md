# useTicketTagDelete

A React hook that encapsulates the tag-deletion flow shared between the ticket detail tags section and the create/edit tags field. It manages confirm-dialog state, triggers the delete mutation, and refreshes the tag list, while delegating the removal of the tag from local selection state to the caller.

## Key Components

- **`useTicketTagDelete(onTagDeleted)`** — Main hook accepting a callback invoked with the deleted tag's ID so the caller can update its own selection state (e.g., a live ticket or a form).
- **`requestDelete`** — Setter function to initiate deletion by setting the target tag ID, which opens the confirmation dialog.
- **`isDeleting`** — Boolean flag indicating whether the delete mutation is in flight.
- **`dialog`** — A ready-to-render `TagDeleteConfirmDialog` element, pre-wired with the current tag name, open state, pending state, and close/confirm handlers.

Internally, it relies on `useTicketTags` to look up the tag's display name and `useDeleteTagMutation` to perform the actual deletion against the backend.

## Usage Example

```typescript
import { useTicketTagDelete } from './use-ticket-tag-delete';

function TicketTagsSection({ ticket, setTicket }) {
  const handleTagDeleted = (id: string) => {
    setTicket(prev => ({
      ...prev,
      tags: prev.tags.filter(tag => tag.id !== id),
    }));
  };

  const { requestDelete, isDeleting, dialog } = useTicketTagDelete(handleTagDeleted);

  return (
    <div>
      {ticket.tags.map(tag => (
        <button key={tag.id} onClick={() => requestDelete(tag.id)} disabled={isDeleting}>
          Remove {tag.key}
        </button>
      ))}
      {dialog}
    </div>
  );
}
```
