## use-tickets-query.ts

A React Query hook that drives the paginated ticket (dialog) list, combining infinite scroll pagination with status-based filtering, search, scoping, and automatic error toasts.

It coordinates with `useTicketStatusesQuery` to resolve status filters into concrete status IDs before firing the actual tickets request, preventing an empty filter from accidentally leaking archived tickets while status data is still loading.

## Key Components

- **`TICKETS_PAGE_SIZE`** — Default page size constant (20) used for pagination and table loading-state row counts.
- **`scopeOf(params)`** — Internal helper that derives a stable "scope" signature (archived flag, device IDs, organization IDs) from query params, used to decide whether placeholder data from a previous query can be reused.
- **`useTicketsQuery(params)`** — Main hook that:
  - Resolves `statusIds` from either explicit `statusFilters`, the archived status, or all non-archived statuses (via the statuses snapshot).
  - Disables the query (`waitingForStatusIds`) until status IDs are resolved, avoiding unsafe fallback behavior.
  - Uses `useInfiniteQuery` with cursor-based pagination (`pageParam`/`endCursor`) and `keepPreviousData` placeholder logic scoped by `scopeOf`.
  - Surfaces errors from both the tickets query and the statuses query via a toast notification.
  - Flattens paginated results into a single `dialogs` array and exposes `filteredCount` from server-side counts.
  - Provides `resetToFirstPage` to invalidate/reset the current query key (e.g., after a mutation).

## Usage Example

```typescript
import { useTicketsQuery } from './use-tickets-query';

function TicketList({ organizationId }: { organizationId?: string }) {
  const {
    dialogs,
    filteredCount,
    isLoading,
    isPending,
    isFetchingNextPage,
    hasNextPage,
    fetchNextPage,
    error,
    resetToFirstPage,
  } = useTicketsQuery({
    archived: false,
    search: '',
    statusFilters: [],
    organizationIds: organizationId ? [organizationId] : undefined,
    sort: 'createdAt_desc',
    enabled: Boolean(organizationId),
  });

  if (isLoading) return <div>Loading tickets…</div>;
  if (error) return <div>Error: {error}</div>;

  return (
    <div style={{ opacity: isPending ? 0.5 : 1 }}>
      <p>{filteredCount} tickets found</p>
      {dialogs.map(ticket => (
        <div key={ticket.id}>{ticket.subject}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </div>
  );
}
```
