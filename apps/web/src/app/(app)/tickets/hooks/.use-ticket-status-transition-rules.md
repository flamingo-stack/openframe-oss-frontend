Fetches and caches ticket status transition rules using React Query, providing the allowed state transitions for ticket workflows.

## Key Components

- **`useTicketStatusTransitionRules`** — React Query hook that retrieves all `TicketStatusTransitionRule` entries from the ticket service. Results are cached for 1 hour (`staleTime` and `gcTime` both set to `3600000ms`), minimizing redundant network requests for this relatively static configuration data.

## Usage Example

```typescript
import { useTicketStatusTransitionRules } from './use-ticket-status-transition-rules';

function TicketStatusSelector() {
  const { data: rules, isLoading, isError } = useTicketStatusTransitionRules();

  if (isLoading) return <p>Loading transitions...</p>;
  if (isError) return <p>Failed to load transition rules.</p>;

  return (
    <ul>
      {rules?.map((rule) => (
        <li key={rule.id}>
          {rule.fromStatus} → {rule.toStatus}
        </li>
      ))}
    </ul>
  );
}
```

## Notes

- Uses `ticketsQueryKeys.statusTransitionRules()` for consistent cache key management across the tickets feature.
- The long cache duration (1 hour) is intentional — transition rules are configuration-level data that rarely changes during a session.
