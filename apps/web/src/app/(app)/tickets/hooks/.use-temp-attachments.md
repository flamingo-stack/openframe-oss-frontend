## use-temp-attachments.ts

A React hook for managing temporary file attachments in ticket forms, handling upload, deletion, and lifecycle tracking of files before they are permanently associated with a ticket. It coordinates optimistic UI updates, deferred deletion of existing attachments, and cleanup of orphaned temp files via GraphQL mutations.

## Key Components

- **`TempFileStatus`** — Union type representing a file's lifecycle state: `'uploading' | 'uploaded' | 'error' | 'existing'`.
- **`TempFileEntry`** — Interface describing a tracked file (id, name, size, content type, status, optional error).
- **`createTempAttachment(source)`** — Standalone async function that requests an upload URL via GraphQL, uploads the file to storage, and returns attachment metadata.
- **`useTempAttachments()`** — Main hook returning:
  - `files` — current list of tracked `TempFileEntry` items.
  - `uploadFile(source)` — starts an upload, adding an optimistic placeholder entry.
  - `removeFile(id)` — removes a pending/temp file immediately, or defers deletion for already-saved ("existing") attachments.
  - `initializeExisting(attachments)` — seeds the hook state with attachments already on a ticket (e.g., when editing).
  - `isUploading` — boolean upload-in-progress flag.
  - `getTempAttachmentIds()` — returns IDs of successfully uploaded temp attachments, ready to submit with the ticket.
  - `deleteRemovedAttachments()` — executes deferred deletions for attachments removed from an existing ticket.
  - `hasPendingDeletes` — boolean indicating queued deletions exist.
  - `reset()` — clears all local state.

## Usage Example

```typescript
import { useTempAttachments } from './use-temp-attachments';

function TicketAttachmentsField({ ticket }) {
  const {
    files,
    uploadFile,
    removeFile,
    initializeExisting,
    getTempAttachmentIds,
    deleteRemovedAttachments,
    isUploading,
  } = useTempAttachments();

  useEffect(() => {
    if (ticket?.attachments) {
      initializeExisting(ticket.attachments);
    }
  }, [ticket, initializeExisting]);

  const handleSubmit = async () => {
    await deleteRemovedAttachments();
    const attachmentIds = getTempAttachmentIds();
    // submit attachmentIds along with the rest of the ticket form
  };

  return (
    <div>
      <input
        type="file"
        onChange={e => e.target.files?.[0] && uploadFile(e.target.files[0])}
        disabled={isUploading}
      />
      {files.map(f => (
        <div key={f.id}>
          {f.fileName} ({f.status})
          <button onClick={() => removeFile(f.id)}>Remove</button>
        </div>
      ))}
    </div>
  );
}
```
