# use-take-over-ticket.ts

A React hook that provides a mutation for a technician to "take over" a ticket from the AI assistant, transitioning it into a direct human-to-client chat.

## Key Components

- **`TakeOverTicketInput`** — Interface describing the mutation input: `ticketId`, `toStatusId`, and `assigneeId`.
- **`useTakeOverTicket()`** — A TanStack Query `useMutation` hook that:
  - Sends the `TAKE_OVER_TICKET_MUTATION` GraphQL mutation via `apiClient`, atomically updating ticket status, assignee, and switching the client dialog to `DIRECT` mode.
  - Throws on GraphQL `userErrors` to trigger the mutation's error path.
  - On success: tracks a `START_DIRECT_CHAT` analytics event and shows a success toast.
  - On error: shows a destructive toast with the error message.
  - On settled (success or error): invalidates the ticket detail query, the tickets list query, and all dialogs queries to keep the UI in sync.

## Usage Example

```typescript
import { useTakeOverTicket } from './hooks/use-take-over-ticket';

function TakeOverButton({ ticketId, toStatusId, assigneeId }: {
  ticketId: string;
  toStatusId: string;
  assigneeId: string;
}) {
  const { mutate: takeOverTicket, isPending } = useTakeOverTicket();

  const handleTakeOver = () => {
    takeOverTicket({ ticketId, toStatusId, assigneeId });
  };

  return (
    <button onClick={handleTakeOver} disabled={isPending}>
      {isPending ? 'Taking over...' : 'Take Over'}
    </button>
  );
}
```

This hook is typically used in ticket detail views where a technician can intervene on an AI-assisted conversation, instantly switching the ticket to direct human handling.
