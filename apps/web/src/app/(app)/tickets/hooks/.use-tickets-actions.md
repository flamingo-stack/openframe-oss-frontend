React hook that builds the page-level action buttons, overflow menu items, and confirmation dialog for the Tickets page, including "New Ticket" creation, status editing, archive navigation, and bulk archiving of resolved tickets.

## Key Components

- **`emphasizeNewTicketAction(actions, emphasize)`** — Utility function that restyles the "New Ticket" action to use the accent variant (with an on-accent icon) when `emphasize` is `true`, used to highlight the CTA during empty states. Returns the actions unchanged otherwise.
- **`useTicketsActions(params)`** — Main hook that returns:
  - `actions` — `PageActionButton[]` array containing the "New Ticket" button (with an AI-generation icon action).
  - `menuActions` — `ActionsMenuGroup[]` array with "Edit Statuses", "Tickets Archive", and conditionally "Archive Resolved Tickets" (shown only when there are resolved tickets).
  - `dialog` — A `ConfirmDialog` React node for confirming bulk archival of resolved tickets.
  - `canArchiveResolved` — Boolean indicating whether archiving is currently allowed (resolved count > 0, not pending, not loading).
  - `openArchiveResolvedConfirm` — Callback to open the archive confirmation dialog.

### Hook Parameters (`UseTicketsActionsParams`)
- `isLoading: boolean` — Disables archive action while data loads.
- `enabled?: boolean` — When `false`, suppresses all actions/menu items.
- `filter?: ArchiveResolvedFilter` — Filter passed to the archive mutation.
- `resolvedCountOverride?: number` — Overrides the globally-fetched resolved ticket count (useful for filtered views).

## Usage Example

```typescript
function TicketsPageHeader() {
  const { actions, menuActions, dialog, canArchiveResolved } = useTicketsActions({
    isLoading: false,
    enabled: true,
  });

  return (
    <>
      <PageHeader actions={actions} menuActions={menuActions} />
      {dialog}
    </>
  );
}
```

Combined with the emphasis helper for empty states:

```typescript
const { actions } = useTicketsActions({ isLoading: false });
const displayActions = emphasizeNewTicketAction(actions, tickets.length === 0);
```
