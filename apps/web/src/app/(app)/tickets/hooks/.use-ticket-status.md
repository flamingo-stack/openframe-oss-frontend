A React hook that manages ticket status transitions, providing convenience methods for common status changes with built-in loading state tracking, error handling, and automatic query cache invalidation.

## Key Components

### `useTicketStatus()`

The primary export. Returns an object with the following:

| Return Value | Type | Description |
|---|---|---|
| `updateTicketStatus` | `(ticketId, status) => Promise<DialogStatus \| null>` | Core method for any status transition |
| `putOnHold` | `(ticketId) => Promise<DialogStatus \| null>` | Sets status to `ON_HOLD` |
| `resolve` | `(ticketId) => Promise<DialogStatus \| null>` | Sets status to `RESOLVED` |
| `activate` | `(ticketId) => Promise<DialogStatus \| null>` | Sets status to `ACTIVE` |
| `archive` | `(ticketId) => Promise<DialogStatus \| null>` | Sets status to `ARCHIVED` |
| `isUpdating` | `boolean` | `true` while any status mutation is in flight |

**Behavior:**
- Debounces concurrent calls — ignores new requests while `isUpdating` is `true`
- On success, invalidates all dialog queries via `invalidateAllDialogs`
- On failure, surfaces a destructive toast notification and returns `null`

## Usage Example

```typescript
import { useTicketStatus } from './use-ticket-status';

function TicketActions({ ticketId }: { ticketId: string }) {
  const { resolve, putOnHold, activate, archive, isUpdating } = useTicketStatus();

  return (
    <div>
      <button onClick={() => resolve(ticketId)} disabled={isUpdating}>
        Resolve
      </button>
      <button onClick={() => putOnHold(ticketId)} disabled={isUpdating}>
        Put on Hold
      </button>
      <button onClick={() => activate(ticketId)} disabled={isUpdating}>
        Activate
      </button>
      <button onClick={() => archive(ticketId)} disabled={isUpdating}>
        Archive
      </button>
    </div>
  );
}
```
