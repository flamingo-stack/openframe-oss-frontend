A React Query hook that fetches and derives ticket statistics (resolved and total counts) from a GraphQL endpoint.

## Key Components

- **`useTicketStatistics`** — Main exported hook accepting an optional `enabled` flag to conditionally run the query. Returns `resolvedCount`, `totalCount`, and `isLoading`.
- **`TicketStatisticsResponse`** — Internal interface typing the GraphQL response shape containing `ticketStatistics`.
- **`resolvedCountFromStatistics` / `totalCountFromStatistics`** — Utility functions used with `useMemo` to derive computed counts from raw statistics data.

## Usage Example

```typescript
import { useTicketStatistics } from './use-ticket-statistics';

function TicketDashboard() {
  const { resolvedCount, totalCount, isLoading } = useTicketStatistics();

  if (isLoading) return <Spinner />;

  return (
    <p>
      {resolvedCount} / {totalCount} tickets resolved
    </p>
  );
}

// Conditionally fetch only when a panel is open
function TicketPanel({ isOpen }: { isOpen: boolean }) {
  const { totalCount, isLoading } = useTicketStatistics({ enabled: isOpen });
  // ...
}
```

## Notes

- Query results are cached with a **60-second stale time** (`staleTime: 60_000`) to reduce redundant network requests.
- Uses the shared `ticketsQueryKeys.statistics()` cache key for consistent invalidation across the app.
- Both derived values are memoized via `useMemo` to avoid unnecessary recomputation on unrelated re-renders.
