Provides a React mutation hook for updating tickets via GraphQL, handling assignment, device/organization linking, and field updates in a single composable operation.

## Key Components

- **`runTicketMutation<K>`** — Generic helper that posts a GraphQL mutation via `apiClient`, extracts the response payload, and throws on `userErrors`.
- **`updateTicketApi`** — Orchestrates up to four sequential GraphQL mutations based on which fields are present in `UpdateTicketInput`:
  - `null` values trigger unlink/unassign mutations (`unlinkOrganizationFromTicket`, `unlinkDeviceFromTicket`, `unassignTicket`)
  - `string` assigneeId triggers `assignTicket`
  - Remaining fields are batched into a single `updateTicket` mutation
- **`useUpdateTicket`** — Exported React hook wrapping `updateTicketApi` in a TanStack Query `useMutation`, with success/error toasts, query cache invalidation, and post-update navigation.

## Usage Example

```typescript
import { useUpdateTicket } from '@/features/tickets/hooks/use-update-ticket';

function TicketEditForm({ ticketId }: { ticketId: string }) {
  const { mutate: updateTicket, isPending } = useUpdateTicket();

  const handleSubmit = () => {
    updateTicket({
      id: ticketId,
      title: 'Updated title',
      assigneeId: 'user-123',   // assigns user
      organizationId: null,      // unlinks org
      deviceId: null,            // unlinks device
    });
  };

  return <button disabled={isPending} onClick={handleSubmit}>Save</button>;
}
```

On success, the hook invalidates both `ticketsQueryKeys.all` and `dialogsQueryKeys.all`, shows a success toast, and navigates to the ticket dialog (or ticket list if no `ticket.id` is returned).

> **Note:** Unlink/unassign mutations fire before the general `updateTicket` mutation. The hook returns the result of the last mutation executed as the final ticket state.
