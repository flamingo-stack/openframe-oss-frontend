# use-ticket-options.ts

A collection of React Query hooks that supply autocomplete option lists (customers, devices, tags, and related tickets) for ticket form fields, each sourced from its appropriate backend (GraphQL or REST) and shaped into a consistent `AutocompleteOption`/`AvatarOption` format.

## Key Components

- **`AutocompleteOption` / `AvatarOption`** — base option shapes (`label`, `value`, optional `imageUrl`) used across the ticket form's dropdowns.
- **`ticketOptionsQueryKeys`** — shared React Query cache key builders for organizations and ticket search, ensuring consistent invalidation.
- **`useOrganizationOptions(search, enabled)`** — fetches customer/organization options via `GET_ORGANIZATIONS_MIN_QUERY`, with `keepPreviousData` to avoid list-flicker while typing.
- **`useDeviceOptions(organizationId, search)`** — fetches a customer's ONLINE/OFFLINE devices using the shared `fetchDevicesPage` query layer (same data as the `/devices` page), scoped by `organizationId`.
- **`useTicketTagOptions()`** — fetches ticket tag options via `GET_TICKET_TAGS_QUERY`.
- **`useTicketSearchOptions(search, organizationId, enabled)`** — searches tickets (excluding archived ones) for linking, returning `TicketSearchOption` with embedded organization info.
- **`customerOptionFromTicket(ticket)`** — derives an `AvatarOption` for the customer field from a selected `TicketSearchOption`.

## Usage Example

```typescript
import {
  useOrganizationOptions,
  useDeviceOptions,
  useTicketTagOptions,
  useTicketSearchOptions,
  customerOptionFromTicket,
} from './use-ticket-options';

function TicketFormFields({ organizationId, search }: { organizationId?: string; search: string }) {
  const { options: customers, isLoading: loadingCustomers } = useOrganizationOptions(search);
  const { options: devices } = useDeviceOptions(organizationId, search);
  const { options: tags } = useTicketTagOptions();
  const { options: relatedTickets } = useTicketSearchOptions(search, organizationId);

  const selectedTicket = relatedTickets[0];
  const derivedCustomer = customerOptionFromTicket(selectedTicket);

  return null; // render autocomplete inputs using the above options
}
```

All hooks return `{ options, isLoading }` and use `keepPreviousData` where search input drives the query key, preventing dropdowns from emptying between keystrokes.
