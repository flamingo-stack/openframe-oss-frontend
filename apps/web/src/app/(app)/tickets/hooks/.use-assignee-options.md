# use-assignee-options.ts

A React hook that provides a searchable, paginated list of active users formatted as assignee options for autocomplete/picker UI components, with support for preserving already-selected users and prioritizing the current user.

## Key Components

- **`ASSIGNEE_OPTIONS_PAGE_SIZE`** — Page size constant (`50`) used for searchable pickers.
- **`ASSIGNEE_FILTER_PAGE_SIZE`** — Page size constant (`100`) used for non-searchable column header filters.
- **`sortSelfFirst<T>(options, currentUserId)`** — Utility that reorders an option list so the signed-in user appears first, if present.
- **`useAssigneeOptions(args?)`** — Main hook returning `{ options, isLoading, onSearchChange }`:
  - `selectedIds` — ids to always include in the result, even if outside the current page or search.
  - `enabled` — toggles whether the query/lookup runs.
  - `selfFirst` — moves the current user to the top of the list.
  - `pageSize` — overrides the default page size.

The hook fetches `ACTIVE` users via GraphQL (`useAssigneeOptionsQuery`), debounces search input (300ms), merges in missing selected users (via `useUsersById`), filters out users deleted since the page was fetched, and never suspends or throws—stale options remain visible with `isLoading` while new data loads.

## Usage Example

```typescript
import { useAssigneeOptions } from './use-assignee-options';

function AssigneePicker({ ticket }: { ticket: { assigneeId?: string } }) {
  const { options, isLoading, onSearchChange } = useAssigneeOptions({
    selectedIds: [ticket.assigneeId],
    selfFirst: true,
  });

  return (
    <Autocomplete
      options={options}
      loading={isLoading}
      onInputChange={(_, value) => onSearchChange(value)}
      value={ticket.assigneeId}
    />
  );
}
```

For a column header filter (no search box), use the larger page size and skip search wiring:

```typescript
const { options } = useAssigneeOptions({ pageSize: ASSIGNEE_FILTER_PAGE_SIZE });
```
