A React hook that manages approval/rejection actions for ticket approval requests, wrapping the mutation logic in a convenient API with success/error callbacks.

## Key Components

- **`ApprovalRequestAction`** — Type describing the payload (`requestId`, `approve`) sent to resolve an approval request.
- **`useApprovalRequests()`** — Hook that exposes:
  - `handleApproveRequest(requestId, options?)` — Approves a request and invokes `onSuccess`/`onError` callbacks.
  - `handleRejectRequest(requestId, options?)` — Rejects a request and invokes `onSuccess`/`onError` callbacks.
  - `isLoading` — Boolean reflecting the pending state of the underlying mutation.
  - `error` — Error message string (or `null`) from the last failed mutation.
  - `approvalMutation` — Raw `useMutation` object for advanced use cases.

Internally, it uses `@tanstack/react-query`'s `useMutation` to call `ticketService.resolveApprovalRequest`, and reports results using the `APPROVAL_STATUS` constants (`APPROVED` / `REJECTED`).

## Usage Example

```typescript
'use client';

import { useApprovalRequests } from './use-approval-requests';

function ApprovalActions({ requestId }: { requestId: string }) {
  const { handleApproveRequest, handleRejectRequest, isLoading, error } =
    useApprovalRequests();

  const onApprove = () =>
    handleApproveRequest(requestId, {
      onSuccess: (status) => console.log('Approved:', status),
      onError: (err) => console.error('Approval failed:', err),
    });

  const onReject = () =>
    handleRejectRequest(requestId, {
      onSuccess: (status) => console.log('Rejected:', status),
    });

  return (
    <div>
      <button disabled={isLoading} onClick={onApprove}>
        Approve
      </button>
      <button disabled={isLoading} onClick={onReject}>
        Reject
      </button>
      {error && <p role="alert">{error}</p>}
    </div>
  );
}
```
