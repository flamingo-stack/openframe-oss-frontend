# use-direct-chat.ts

A React hook that manages the "direct chat" mode for a support ticket, allowing a client to start a direct conversation with a human agent (bypassing AI-assisted mode) and send messages within that dialog. It handles both creating a new direct dialog and switching an existing dialog into direct mode, with optimistic cache updates and toast error notifications.

## Key Components

- **`useDirectChat(options)`** — Main hook accepting `ticketId`, `dialogId`, `currentMode`, and an optional `onDialogCreated` callback.
- **`isDirectMode`** — Boolean derived from `currentMode === DIALOG_MODE.DIRECT`.
- **`startDirectChat()`** — Creates a new dialog (if none exists) or switches an existing dialog to direct mode; guards against concurrent calls.
- **`sendClientMessage(message)`** — Sends a trimmed client message to the active dialog, resolving the dialog ID from the hook args or the React Query cache.
- **`isStartingDirectChat`** / **`isSendingClientMessage`** — Loading flags derived from the underlying mutations.
- Internally uses `useMutation` (TanStack Query) for `createDialog`, `updateDialogMode`, and `sendMessage` operations via `ticketService`, and `setMode` to optimistically patch the cached `Dialog` object.
- Tracks the `START_DIRECT_CHAT` analytics event on successful dialog creation/mode switch via `trackDashboardActivity`.

## Usage Example

```typescript
import { useDirectChat } from './use-direct-chat';

function TicketChatPanel({ ticketId, dialog }: { ticketId: string; dialog?: Dialog }) {
  const {
    isDirectMode,
    isStartingDirectChat,
    isSendingClientMessage,
    startDirectChat,
    sendClientMessage,
  } = useDirectChat({
    ticketId,
    dialogId: dialog?.dialogId,
    currentMode: dialog?.currentMode,
    onDialogCreated: () => console.log('Direct dialog created'),
  });

  return (
    <div>
      {!isDirectMode && (
        <button onClick={startDirectChat} disabled={isStartingDirectChat}>
          Start Direct Chat
        </button>
      )}
      <button
        onClick={() => sendClientMessage('Hello, I need help!')}
        disabled={isSendingClientMessage}
      >
        Send Message
      </button>
    </div>
  );
}
```
