Manages direct chat for a support ticket dialog: creates a direct dialog or switches an existing one to direct mode, through React Query mutations. Messages are sent by the client chat's engine (`useTicketClientChat`).

## Key Components

### `useDirectChat(options: UseDirectChatOptions)`
Main hook accepting:
- `ticketId` — ID of the associated support ticket
- `dialogId` — existing dialog ID (if any)
- `currentMode` — current dialog mode string
- `onDialogCreated?` — optional callback fired after a new dialog is created

### Internal Mutations
| Mutation | Purpose |
|---|---|
| `createDialogMutation` | POSTs a new `CLIENT`/`DIRECT` dialog when no `dialogId` exists |
| `switchModeMutation` | PATCHes an existing dialog's mode to `DIRECT` |

### `setMode` (internal)
Optimistically updates the cached `Dialog` query data via `queryClient.setQueryData` without a server round-trip.

## Usage Example

```typescript
const {
  isDirectMode,
  isStartingDirectChat,
  startDirectChat,
} = useDirectChat({
  ticketId: 'ticket-123',
  dialogId: dialog?.id,
  currentMode: dialog?.currentMode,
  onDialogCreated: () => console.log('Dialog ready'),
});

// Switch/create a direct chat session
startDirectChat();

```

## Returned Values

| Property | Type | Description |
|---|---|---|
| `isDirectMode` | `boolean` | `true` when `currentMode === DIALOG_MODE.DIRECT` |
| `isStartingDirectChat` | `boolean` | `true` while create or switch mutations are pending |
| `startDirectChat` | `() => void` | Creates a new dialog or switches mode depending on `dialogId` presence |
