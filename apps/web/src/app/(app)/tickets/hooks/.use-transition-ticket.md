A React Query mutation hook for transitioning a ticket's status, with automatic cache invalidation and toast notifications on success or failure.

## Key Components

### `TransitionTicketInput`
Interface defining the mutation payload:
- `ticketId` — ID of the ticket to transition
- `toStatusId` — ID of the target status

### `useTransitionTicket()`
Returns a `useMutation` result that calls `ticketService.transitionTicket`. On success, it invalidates the ticket detail query and all dialog queries, then shows a success toast. On error, it displays a descriptive destructive toast for 5 seconds.

## Usage Example

```typescript
import { useTransitionTicket } from './use-transition-ticket';

function TicketStatusButton({ ticketId, toStatusId }: { ticketId: string; toStatusId: string }) {
  const { mutate: transitionTicket, isPending } = useTransitionTicket();

  return (
    <button
      disabled={isPending}
      onClick={() => transitionTicket({ ticketId, toStatusId })}
    >
      {isPending ? 'Updating...' : 'Move to Next Status'}
    </button>
  );
}
```

## Cache Behavior

| Event | Side Effect |
|---|---|
| Success | Invalidates `ticketsQueryKeys.detail(ticketId)` + all dialogs |
| Error | No cache changes; error toast shown for 5 s |
