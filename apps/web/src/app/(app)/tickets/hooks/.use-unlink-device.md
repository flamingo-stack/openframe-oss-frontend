React Query mutation hook that removes a device association from a support ticket via GraphQL, with cache invalidation and toast notifications on success or failure.

## Key Components

- **`unlinkDeviceApi(ticketId)`** — Internal async function that sends the `UNLINK_DEVICE_FROM_TICKET_MUTATION` GraphQL mutation, extracts the response payload, and throws on `userErrors`.
- **`useUnlinkDevice(onSuccess?)`** — Exported hook wrapping `useMutation` that handles the full unlink flow, invalidating `ticketsQueryKeys.all` and `dialogsQueryKeys.all` caches after a successful mutation.

## Usage Example

```typescript
import { useUnlinkDevice } from './use-unlink-device';

function TicketDevicePanel({ ticketId }: { ticketId: string }) {
  const { mutate: unlinkDevice, isPending } = useUnlinkDevice(() => {
    console.log('Device unlinked, closing panel...');
  });

  return (
    <button
      disabled={isPending}
      onClick={() => unlinkDevice(ticketId)}
    >
      {isPending ? 'Unlinking...' : 'Unlink Device'}
    </button>
  );
}
```

## Behaviour

| Outcome | Effect |
|---|---|
| Success | Invalidates tickets + dialogs query cache, shows success toast, calls optional `onSuccess` callback |
| `userErrors` in response | Throws with the first error message, triggers error toast |
| Network/unexpected error | Shows `"Failed to unlink device"` fallback toast |
