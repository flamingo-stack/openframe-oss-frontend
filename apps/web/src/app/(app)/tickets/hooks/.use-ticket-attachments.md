A React hook that enables downloading ticket attachments by fetching a signed download URL via GraphQL and triggering the browser file download.

## Key Components

- **`useDownloadTicketAttachment`** — Custom hook that returns a `download` function for retrieving and saving ticket attachment files.
- **`download(attachmentId, fileName)`** — Callback that fetches a time-limited download URL for the given attachment ID and streams/saves it under the provided file name, leveraging the shared `useFileDownload` utility.
- **`DownloadUrlResponse`** — Internal interface describing the shape of the GraphQL response containing `ticketAttachmentDownloadUrl`.

## Usage Example

```typescript
'use client';

import { useDownloadTicketAttachment } from '@/features/tickets/hooks/use-ticket-attachments';

function AttachmentItem({ attachmentId, fileName }: { attachmentId: string; fileName: string }) {
  const { download } = useDownloadTicketAttachment();

  return (
    <button onClick={() => download(attachmentId, fileName)}>
      Download {fileName}
    </button>
  );
}
```

This hook relies on `apiClient` to issue a GraphQL POST request to `API_ENDPOINTS.GRAPHQL` using the `GET_TICKET_ATTACHMENT_DOWNLOAD_URL` query, then extracts the download URL via `extractGraphQlData`. The actual file-saving logic (streaming the response and triggering a browser download) is delegated to the shared `useFileDownload` hook, keeping this module focused solely on resolving the attachment's download URL.
