# use-ticket-tags.ts

A React Query hook that fetches the list of available ticket tags via a GraphQL query, enabling components to populate tag selectors or filter UIs with current tag data.

## Key Components

- **`useTicketTags()`** — Custom hook built on `useQuery` from `@tanstack/react-query`. Returns the standard React Query result object (`data`, `isLoading`, `error`, etc.) where `data` resolves to an array of `Tag` objects.
- **Query key**: `ticketsQueryKeys.tags()` — used for cache identification and invalidation.
- **GraphQL query**: `GET_TICKET_TAGS_QUERY` — sent via `apiClient.post` to the `API_ENDPOINTS.GRAPHQL` endpoint.
- **`extractGraphQlData`** — utility that unwraps the GraphQL response envelope and surfaces errors before returning the `ticketTags` payload.

## Usage Example

```typescript
import { useTicketTags } from '@/app/tickets/hooks/use-ticket-tags';

function TagFilter() {
  const { data: tags, isLoading, error } = useTicketTags();

  if (isLoading) return <span>Loading tags...</span>;
  if (error) return <span>Failed to load tags</span>;

  return (
    <ul>
      {tags?.map((tag) => (
        <li key={tag.id}>{tag.name}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Client-side only (`'use client'` directive) — intended for use within Next.js client components.
- Falls back to an empty array if `ticketTags` is `null` or `undefined`, ensuring consumers always receive an array.
- Caching behavior follows default `@tanstack/react-query` semantics keyed by `ticketsQueryKeys.tags()`, so repeated calls across components share the same cached result.
