Fetches and caches available ticket tags via a GraphQL query, returning a list of `Tag` objects for use in ticket tagging UI.

## Key Components

- **`useTicketTags()`** — React Query hook that posts `GET_TICKET_TAGS_QUERY` to the GraphQL endpoint, extracts `ticketTags` from the response, and returns an empty array as a safe fallback.

## Usage Example

```typescript
import { useTicketTags } from '@/features/tickets/hooks/use-ticket-tags';

function TicketTagPicker() {
  const { data: tags, isLoading, isError } = useTicketTags();

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorMessage />;

  return (
    <ul>
      {tags?.map((tag) => (
        <li key={tag.id}>{tag.key}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Query is keyed via `ticketsQueryKeys.tags()` for consistent cache invalidation across the tickets feature.
- Returns `data.ticketTags ?? []` — downstream consumers can safely iterate without null checks.
