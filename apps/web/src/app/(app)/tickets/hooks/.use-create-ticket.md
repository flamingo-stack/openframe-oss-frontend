A React hook for creating a new support ticket via a GraphQL mutation, handling cache invalidation and toast notifications on success or failure.

## Key Components

- **`createTicketApi(input)`** — Internal async function that sends the `CREATE_TICKET_MUTATION` GraphQL request through `apiClient`, extracts the response data, throws on `userErrors`, and returns the created `Ticket`.
- **`CreateTicketPayload`** — Local type override of `TicketPayload` where `ticket` includes a required `ticketId`, since `CreateTicket` is the only mutation that selects it.
- **`useCreateTicket()`** — React Query `useMutation` hook that wraps `createTicketApi`, invalidating the `tickets` and `dialogs` query caches on success and surfacing toast messages for both success and error states. Returns the standard mutation object (`mutate`, `mutateAsync`, `isPending`, etc.).

## Usage Example

```typescript
import { useCreateTicket } from './use-create-ticket';

function CreateTicketButton() {
  const { mutate: createTicket, isPending } = useCreateTicket();

  const handleCreate = () => {
    createTicket(
      {
        title: 'Cannot connect to VPN',
        description: 'User reports VPN connection failures since this morning.',
        priority: 'HIGH',
      },
      {
        onSuccess: (ticket) => {
          console.log('Created ticket ID:', ticket?.ticketId);
          // Navigation/assignment logic handled separately, e.g. by useCreateTicketForm
        },
      }
    );
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      {isPending ? 'Creating...' : 'Create Ticket'}
    </button>
  );
}
```

**Note:** This hook only handles ticket creation and feedback (toasts, cache invalidation). Post-creation navigation and assignment logic is intentionally left to the caller, typically `useCreateTicketForm`.
