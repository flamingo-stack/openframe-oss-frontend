# ticket-queries.ts

Defines the GraphQL query and mutation documents used to interact with the ticket system exposed by the `openframe-saas-ai-agent` service via the `/chat/graphql` endpoint. Covers ticket CRUD, attachments, notes, status transitions, tags, and the lifecycle board (Kanban-style columns with approval/escalation filtering).

## Key Components

- **`CREATE_TICKET_MUTATION`** - Creates a new ticket, returning full ticket details including owner, tags, and attachments.
- **`CREATE_TEMP_ATTACHMENT_UPLOAD_URL`** / **`DELETE_TEMP_ATTACHMENT`** / **`DELETE_TICKET_ATTACHMENT`** - Manage attachment upload/removal lifecycle.
- **`GET_TICKET_QUERY`** - Fetches a single ticket with full detail (status, transitions, approvals, dialog/token usage, notes, attachments).
- **`TICKETS_DEFAULT_SORT`** - Default board sort (`order ASC`); required by `GET_TICKETS_QUERY`'s non-optional `$sort` variable.
- **`GET_TICKETS_QUERY`** - Paginated ticket list query for the tickets table, using cursor-based pagination.
- **`BOARD_CARD_TICKET_FRAGMENT`** - Shared fragment for board card data (status, approvals, activity state, unread counts). Subject to a strict deploy-ordering constraint: backend fields must ship before frontend selects them, or `extractGraphQlData` throws and board/table/picker queries silently return empty.
- **`GET_BOARD_COLUMN_TICKETS_QUERY`** - Paginated tickets for a single board column/lane, with filters (organization, assignee, tags, unread, activity).
- **`GET_PENDING_APPROVAL_TICKETS_QUERY`** / **`GET_PENDING_APPROVAL_TICKETS_COUNT_QUERY`** - Tickets/count awaiting approval, used by the "Needs approval" view and sidebar badge.
- **`GET_ESCALATED_TICKETS_QUERY`** - Tickets escalated by the end user, used by the home "Needs you" card.
- **`GET_TICKET_STATUS_TRANSITION_RULES_QUERY`** / **`TRANSITION_TICKET_MUTATION`** - Fetch allowed status transitions and perform a transition.
- **`GET_TICKET_TAGS_QUERY`** - Lists all ticket tags.
- **`GET_TICKET_ATTACHMENT_DOWNLOAD_URL`** - Resolves a download URL for an attachment.
- **`ADD_TICKET_NOTE_MUTATION`** / **`UPDATE_TICKET_NOTE_MUTATION`** - Add or edit ticket notes.

## Usage Example

```typescript
import {
  GET_TICKETS_QUERY,
  TICKETS_DEFAULT_SORT,
  GET_BOARD_COLUMN_TICKETS_QUERY,
} from './ticket-queries';

// Fetch paginated tickets with default board ordering
const ticketsResult = await graphqlClient.request(GET_TICKETS_QUERY, {
  filter: { statusIds: ['status-123'] },
  first: 25,
  sort: TICKETS_DEFAULT_SORT,
});

// Fetch a single board column's tickets
const columnResult = await graphqlClient.request(GET_BOARD_COLUMN_TICKETS_QUERY, {
  statusId: 'status-123',
  limit: 20,
  organizationIds: ['org-1'],
});
```

**Note:** Any new field added to `BOARD_CARD_TICKET_FRAGMENT` or `GET_TICKETS_QUERY` must already exist on the deployed `openframe-saas-ai-agent` backend before being selected here, otherwise the GraphQL response errors out and dependent UI (board columns, tickets table, ticket picker) returns empty rather than a partial result.
