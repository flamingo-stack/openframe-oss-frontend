GraphQL mutation definitions for dialogs: create a dialog, change its mode, stop a generation, send a message, and
resolve an approval request. A dialog's messages are read with the core lib's one chat history document
(`MINGO_MESSAGES_QUERY`) through `fetchDialogMessagesPage` in `@/lib/dialog-messages-page`.

## Key Components

| Export | Description |
|---|---|
| `CREATE_DIALOG_MUTATION` | Creates a dialog and answers its raw `dialogId` |
| `UPDATE_DIALOG_MODE_MUTATION` | Switches a dialog between AI and direct mode |
| `STOP_DIALOG_GENERATION_MUTATION` | Stops the running answer |
| `SEND_MESSAGE_MUTATION` | Sends a message into a dialog |
| `RESOLVE_APPROVAL_REQUEST_MUTATION` | Approves or rejects an approval request |

All mutations return a `userErrors` array for field-level validation feedback.
