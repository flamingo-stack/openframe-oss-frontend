Confirmation dialog for deleting a ticket status, requiring the user to select a replacement status so existing tickets can be reassigned before deletion.

## Key Components

- **`DeleteStatusDialog`** — React component rendering a `SimpleModal` with a status reassignment selector and Cancel/Delete actions.
- **`DeleteStatusDialogProps`** — Props interface:
  - `isOpen` / `onClose` — modal visibility control.
  - `statusName` — name of the status being deleted, shown in the confirmation message.
  - `options` — array of `ReplacementOption` values used to populate the reassignment `Select`.
  - `onConfirm(replacementStatusId: string)` — callback invoked with the chosen replacement status ID.
  - `isPending` — disables actions and shows a loading state on the Delete button while the deletion request is in flight.
- **Open-transition state seeding** — internal `wasOpen` state is compared against `isOpen` during render (not in a `useEffect`) to reset `replacementId` to the first available option whenever the dialog transitions to open, avoiding a flash of stale data and preventing background data refreshes from overwriting user input while the modal is open.

## Usage Example

```typescript
import { DeleteStatusDialog } from './delete-status-dialog';
import type { ReplacementOption } from '../hooks/use-ticket-statuses-form';

function TicketStatusesPage() {
  const [isDialogOpen, setDialogOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const replacementOptions: ReplacementOption[] = [
    { id: 'status-1', name: 'Open', color: '#00ff00' },
    { id: 'status-2', name: 'Closed', color: '#ff0000' },
  ];

  const handleConfirm = async (replacementStatusId: string) => {
    setIsPending(true);
    await deleteStatus({ replacementStatusId });
    setIsPending(false);
    setDialogOpen(false);
  };

  return (
    <DeleteStatusDialog
      isOpen={isDialogOpen}
      onClose={() => setDialogOpen(false)}
      statusName="In Progress"
      options={replacementOptions}
      onConfirm={handleConfirm}
      isPending={isPending}
    />
  );
}
```
