Manages form state for the ticket statuses settings page, wiring together React Hook Form, Zod validation, server data synchronization, and mutation handlers for saving and deleting custom ticket statuses.

## Key Components

| Export | Type | Description |
|---|---|---|
| `useTicketStatusesForm` | Hook | Primary hook returning form state, field array controls, mutation refs, and submit handlers |
| `ReplacementOption` | Interface | Shape of a status option used when reassigning tickets from a deleted status |
| `collectErrorMessages` | Function (internal) | Recursively walks `FieldErrors` to flatten all error messages into a deduplicated string array |

### Returned Values

| Key | Description |
|---|---|
| `form` | React Hook Form instance with Zod resolver |
| `fieldArray` | `useFieldArray` controls for `customStatuses` |
| `saveMutation` / `deleteMutation` | TanStack Query mutations |
| `onValidSubmit` / `onInvalidSubmit` | Form submission handlers |
| `canDelete` | `true` when more than one custom status exists |
| `systemStatuses` | Read-only system statuses from server data |
| `persistedCustomIds` | `Set<string>` of already-persisted (non-system) status IDs |
| `replacementOptionsFor` | Returns transition-rule-filtered options for a given status ID |

## Usage Example

```typescript
import { useTicketStatusesForm } from './use-ticket-statuses-form';

function TicketStatusesFormPage() {
  const {
    form,
    fieldArray,
    saveMutation,
    onValidSubmit,
    onInvalidSubmit,
    canDelete,
    replacementOptionsFor,
  } = useTicketStatusesForm();

  return (
    <form onSubmit={form.handleSubmit(onValidSubmit, onInvalidSubmit)}>
      {fieldArray.fields.map((field, index) => (
        <StatusRow
          key={field._key}
          index={index}
          replacementOptions={replacementOptionsFor(field.id)}
          canDelete={canDelete}
        />
      ))}
      <button type="submit" disabled={saveMutation.isPending}>
        Save
      </button>
    </form>
  );
}
```

> **Note:** Server data is adopted into the form only while the form is pristine (`isDirty === false`). This prevents in-progress edits from being overwritten by background refetches, and avoids a visible flicker after a successful save resets dirty state before the refetch lands.
