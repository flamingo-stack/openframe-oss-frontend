# useTicketStatusesForm

A React hook that manages the form state, validation, and submission logic for editing custom ticket statuses, including safe handling of server-data synchronization and status deletion with replacement selection.

## Key Components

- **`useTicketStatusesForm()`** — Main hook that wires together `react-hook-form`, Zod validation, and TanStack Query data for the ticket statuses editor. Returns the form instance, field array helpers, mutations, submit handlers, and derived data for the UI.
- **`ReplacementOption`** — Interface describing a status option (`id`, `name`, `color`) that can be offered as a replacement when deleting a custom status.
- **`replacementOptionsFor(statusId)`** — Callback that filters valid replacement statuses based on the transition-rule matrix, ensuring tickets can only move to statuses the deleted status is allowed to transition to.
- **`onValidSubmit` / `onInvalidSubmit`** — Submit handlers for successful validation (persists changes, resets form, navigates back) and failed validation (shows a toast with aggregated error messages).
- **`collectErrorMessages(errors)`** — Internal utility that recursively walks a `FieldErrors` object to extract all unique validation messages for display.

## Usage Example

```typescript
import { useTicketStatusesForm } from './use-ticket-statuses-form';

function TicketStatusesPage() {
  const {
    form,
    fieldArray,
    saveMutation,
    deleteMutation,
    onValidSubmit,
    onInvalidSubmit,
    isLoading,
    canDelete,
    systemStatuses,
    persistedCustomIds,
    replacementOptionsFor,
  } = useTicketStatusesForm();

  if (isLoading) return <LoadingSpinner />;

  const handleSubmit = form.handleSubmit(onValidSubmit, onInvalidSubmit);

  return (
    <form onSubmit={handleSubmit}>
      {fieldArray.fields.map((field, index) => (
        <StatusRow
          key={field._key}
          index={index}
          canDelete={canDelete}
          replacementOptions={replacementOptionsFor(field.id)}
          form={form}
        />
      ))}
      <button type="submit" disabled={saveMutation.isPending}>
        Save
      </button>
    </form>
  );
}
```

**Note:** The hook avoids clobbering in-progress edits by only resyncing form state from server data when the form is pristine (`isDirty === false`), tracked via a ref to prevent redundant effect re-runs on every dirty-flag change.
