Type definitions, Zod schemas, and utility functions for managing ticket status configurations in the OpenFrame MSP platform.

## Key Components

### Interfaces

| Interface | Purpose |
|---|---|
| `TicketStatusDefinition` | Raw status record from the backend (system or custom); includes `staleAfterMinutes` — the server-resolved staleness threshold (status override, else tenant default 120 min) driving the board card's "No activity for N hours" indicator |
| `SystemTicketStatus` | Enriched system status with tooltip and tag variant metadata |
| `CustomTicketStatus` | User-defined status with color and optional preset key |
| `TicketStatusesPayload` | Shape of the save/update request body |

### Zod Schemas

- **`customTicketStatusSchema`** — Validates a single custom status: requires a non-empty name (max 50 chars), a 6-digit hex color, and a `kind` of `"custom"`.
- **`ticketStatusesSchema`** — Validates the full payload; enforces at least one custom status remains.

### Constants

- **`SYSTEM_KIND_META`** — Maps every non-`CUSTOM` `TicketStatusKind` (`AI_ASSISTANCE`, `TECH_REQUIRED`, `RESOLVED`, `ARCHIVED`) to its tooltip copy and tag variant style.

### Functions

| Function | Description |
|---|---|
| `derivePreset(color)` | Looks up a color against `TICKET_STATUS_COLOR_PRESETS` and returns its preset key if matched |
| `mapDefinitionToCustom(def)` | Converts a `TicketStatusDefinition` → `CustomTicketStatus` |
| `mapDefinitionToSystem(def)` | Converts a `TicketStatusDefinition` → `SystemTicketStatus`, injecting tooltip/variant from `SYSTEM_KIND_META` |

### Re-exports

`kindToCanonicalStatus`, `usesCanonicalStatusStyle`, and `TicketStatusKind` are re-exported to make this module the single import surface for ticket-status logic within the feature.

## Usage Example

```typescript
import {
  mapDefinitionToCustom,
  mapDefinitionToSystem,
  ticketStatusesSchema,
  derivePreset,
} from './ticket-statuses.types';

// Map a backend definition to a form-friendly custom status
const custom = mapDefinitionToCustom({
  id: 'abc123',
  name: 'In Review',
  color: '#4F46E5',
  position: '1',
  kind: 'CUSTOM',
  isSystem: false,
  staleAfterMinutes: 120,
});
// { kind: 'custom', id: 'abc123', name: 'In Review', color: '#4F46E5', preset: undefined }

// Map a system definition to a display-ready status
const system = mapDefinitionToSystem({
  id: 'sys1',
  name: 'AI Assistance',
  color: '#10B981',
  position: '0',
  kind: 'AI_ASSISTANCE',
  isSystem: true,
  staleAfterMinutes: 120,
});
// → includes tooltip and tagVariant from SYSTEM_KIND_META

// Validate a save payload
const result = ticketStatusesSchema.safeParse({
  customStatuses: [custom],
});
```
