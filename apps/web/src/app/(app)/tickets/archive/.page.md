Next.js page component that renders the archived tickets view, restricted to SaaS tenant mode, with search, tag filtering, and sorting support synchronized to URL query parameters.

## Key Components

- **`TicketsArchive`** (default export) — Client component rendering the archived tickets list page.
- **`useApiParams`** — Syncs `search`, `tagIds`, and `sortDir` state with URL query parameters.
- **`useSearchParam`** — Debounces (300ms) search input updates before writing to the URL params.
- **`useSafeBack`** — Provides a back-navigation handler that falls back to `routes.tickets.list`.
- **`isSaasTenantMode`** — Guards the route so it's only accessible in SaaS tenant mode; redirects to `routes.dashboard` otherwise.
- **`parseTicketListSort` / `ticketListSortToParams`** — Convert between the `sortDir` URL param and the `TicketListSort` object used by the table.
- **`ArchivedTickets`** — The presentational table component rendering the archived tickets list with filtering/sorting controls.

## Usage Example

```typescript
// Accessed via Next.js routing at the archived tickets route.
// No manual instantiation needed; Next.js renders this as the page component.

// Example of how sort state flows:
import { parseTicketListSort, ticketListSortToParams } from '../utils/ticket-list-sort';

const sort = parseTicketListSort('createdAt:desc');
const params = ticketListSortToParams({ field: 'createdAt', direction: 'desc' });
```

## Behavior Notes

- If the app is **not** in SaaS tenant mode, the component redirects to `routes.dashboard` via `router.replace` and renders `null` to avoid flashing content.
- Search, tag filters, and sort order are all persisted in the URL, enabling shareable/bookmarkable filtered views.
- The back button navigates to `routes.tickets.list` by default, using `useSafeBack` to preserve browser history semantics when possible.
