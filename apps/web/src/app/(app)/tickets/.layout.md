This layout file defines page metadata for the Tickets route and re-exports a shared layout component used across the application.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the document title for this route using the `routeTitle` utility, producing a formatted title string (e.g., "Tickets").
- **Default export** — Re-exported from `@/app/(app)/route-title-layout`, this component provides the common layout wrapper (likely handling route-based title display or page structure) shared by routes using this pattern.

## Usage Example

This file is automatically picked up by Next.js's App Router as the `layout.tsx` for the Tickets route segment. You typically don't import it directly; instead, Next.js applies it to all pages under the corresponding route folder.

```typescript
// app/(app)/tickets/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Tickets') };
```

To create a similar layout for another section (e.g., "Devices"), follow the same pattern:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Devices') };
```

This keeps metadata declarations consistent while reusing the shared `route-title-layout` component for rendering.
