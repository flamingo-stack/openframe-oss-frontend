## ticket-details-store.ts

Zustand store that manages per-side (client/admin) chat state for the ticket details chat dialog. It is "Phase 4" of chat unification: each side's message thread is backed by a shared library `ChatStreamReducer` instance held in a `createChatDialogStore`, wired through a `createReducerMirror`. This zustand store layers persistence/cache + identity on top (per-side `highestStreamSeq` bookkeeping, a cross-side approval-status map, and a converted read mirror of each reducer snapshot) so existing selectors continue to work unchanged.

Only one ticket dialog is open at a time, so both sides share a constant thread key (`'ticket-details'`), with `ChatSide` (`'client' | 'admin'`) as the real per-reducer key.

## Key Components

- **`ChatSide`** — Type alias for `'client' | 'admin'`, the two chat participants.
- **`ticketChatDialogStore`** — The underlying dialog store (built by the mirror) holding the two side reducers.
- **`mutateTicketSide(side, fn)`** — Runs a non-wire reducer command against one side and re-syncs the mirror.
- **`bindTicketSide`** — Pre-curried `{ apply, mutate, mergeApprovalStatuses }` bound per side.
- **`useTicketDetailsStore`** — Main zustand hook exposing:
  - `client` / `admin`: `SideState` (messages, `isTyping`, `streamingId`, `highestStreamSeq`)
  - `approvalStatuses`: shared `ApprovalStatusMap`
  - `clearChatState()`: resets both sides and drops mirror caches
  - `setMessages`, `prependMessages`, `prependWithBoundaryMerge`, `addMessage`, `pushOptimisticSend`, `updateMessage`, `removeMessage`, `getMessages`
  - `updateApprovalStatusInMessages`, `setApprovalStatus`, `upsertApprovalStatuses`
  - `setChatHandlers`, `setTypingIndicator`, `recordHighestStreamSeq`, `getHighestStreamSeq`, `clearSide`
- **`ApprovalStatus`** / **`ApprovalStatusMap`** — Types for approval resolution tracking (`'approved' | 'rejected'`).

## Usage Example

```typescript
import { useTicketDetailsStore, bindTicketSide } from '@/stores/ticket-details-store';

// Read messages for the admin side
const adminMessages = useTicketDetailsStore(state => state.admin.messages);

// Send an optimistic message on the client side
useTicketDetailsStore.getState().pushOptimisticSend('client', newChatMessage);

// Resolve an approval and propagate to the shared status map
useTicketDetailsStore.getState().updateApprovalStatusInMessages(
  'admin',
  'req-123',
  'approved',
  'Jane Doe',
);

// Reset all chat state when switching tickets
useTicketDetailsStore.getState().clearChatState();

// Wire NATS handlers for a side
const client = bindTicketSide('client');
client.apply(/* stream event */);
```
