# ticket-service.types.ts

Type definitions for the ticket/dialog service layer, covering ticket board queries, pagination, reordering, dialog/chat messaging, and AI-agent message context payloads.

## Key Components

- **`TicketsPage` / `MessagePage`** — Paginated result shapes for ticket lists and chat messages, each carrying a `CursorPageInfo`.
- **`TicketListSort` / `TicketListSortField`** — Explicit list sort by ticket number; omitting sort preserves board (`order`) position.
- **`FetchTicketsParams`** — Filters for the tickets list: status ids, search, org/device/assignee/tag ids, `unreadOnly`, sort, and cursor pagination.
- **`FetchBoardColumnByStatusIdParams`** — Filters for a single board column/lane, including `activity` (OR within the list, AND with other params).
- **`FetchPendingApprovalTicketsParams` / `FetchEscalatedTicketsParams`** — Specialized queries for pending-approval and escalated ticket lanes.
- **`ReorderTicketParams`** — Drag-and-drop reorder payload; `statusId` must always be sent to disambiguate lifecycle vs. legacy status ranking.
- **`TicketStatusTransitionRule`** — Allowed `from` → `to[]` status transitions.
- **`FetchMessagesParams` / `CreateDialogParams`** — Dialog message pagination and dialog creation (admin/client agent types, optional insight linkage, mode, intent).
- **`PageKind` / `ListModule` / `MessagePageRef` / `MessageListRef`** — Closed enums and shapes describing the page/list context the ai-agent needs when a message is sent.
- **`SendMessageContext`** — Composer context bundle: attached entities, current view, recent views, current page/list.
- **`TicketService`** — The service interface: fetch/transition/reorder tickets, fetch/send messages, manage dialogs, resolve approval requests.

## Usage Example

```typescript
import type { TicketService, FetchTicketsParams } from './ticket-service.types';

async function loadOpenTickets(service: TicketService, statusIds: string[]) {
  const params: FetchTicketsParams = {
    statusIds,
    unreadOnly: true,
    sort: { field: 'ticketNumber', direction: 'DESC' },
    limit: 25,
  };

  const { dialogs, pageInfo, filteredCount } = await service.fetchDialogs(params);
  console.log(`Loaded ${dialogs.length} of ${filteredCount} tickets`);
  return pageInfo.hasNextPage ? pageInfo.endCursor : null;
}

async function sendChatMessage(service: TicketService, dialogId: string) {
  await service.sendMessage(dialogId, 'Status update please', 'ADMIN', {
    currentView: { type: 'TICKET', id: dialogId },
  });
}
```
