Barrel export file that instantiates and re-exports the `TicketService` singleton along with its associated TypeScript types.

## Key Components

- **`ticketService`** — Pre-instantiated singleton of `TicketService`, ready for import and use across the application
- **`BoardStatus`** — Re-exported type representing the status of a board
- **`FetchMessagesParams`** — Re-exported type for message fetch request parameters
- **`FetchTicketsParams`** — Re-exported type for ticket fetch request parameters
- **`MessagePage`** — Re-exported type representing a paginated message result
- **`TicketsPage`** — Re-exported type representing a paginated ticket result

## Usage Example

```typescript
import { ticketService, FetchTicketsParams, TicketsPage } from './index';

const params: FetchTicketsParams = {
  boardId: 'board-123',
  page: 1,
  pageSize: 25,
};

const tickets: TicketsPage = await ticketService.fetchTickets(params);
```

> **Note:** Import from this barrel file rather than directly from `ticket-service` or `ticket-service.types` to ensure consistent singleton usage and a stable public API surface.
