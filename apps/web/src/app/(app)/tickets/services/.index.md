This module serves as the public entry point for the ticket service, exposing a singleton service instance along with related TypeScript types for consumers across the application.

## Key Components

- **`ticketService`** — A pre-instantiated singleton of `TicketService`, ready to use for ticket-related operations without needing manual instantiation.
- **`FetchMessagesParams`** — Type defining parameters for fetching messages.
- **`FetchTicketsParams`** — Type defining parameters for fetching tickets.
- **`MessagePage`** — Type representing a paginated page of messages.
- **`TicketsPage`** — Type representing a paginated page of tickets.

## Usage Example

```typescript
import { ticketService } from './index';
import type { FetchTicketsParams, TicketsPage } from './index';

async function loadTickets(): Promise<TicketsPage> {
  const params: FetchTicketsParams = {
    page: 1,
    pageSize: 20,
  };

  return ticketService.fetchTickets(params);
}

async function loadMessages(ticketId: string) {
  const params: FetchMessagesParams = {
    ticketId,
    page: 1,
    pageSize: 50,
  };

  return ticketService.fetchMessages(params);
}
```

By centralizing the export in `index.ts`, other modules can import both the service instance and its associated types from a single, consistent path, simplifying dependency management and improving discoverability.
