## ticket-service.ts

Implements the `TicketService` class, which serves as the primary data-access layer for tickets and their associated dialog/chat conversations. It wraps GraphQL queries/mutations (via `apiClient`) for fetching, creating, transitioning, and reordering tickets, as well as managing dialog messages, approvals, and read state. It normalizes raw GraphQL `TicketNode` responses into the app's unified `Dialog` domain model.

## Key Components

- **`TicketService`** — class implementing `TicketServiceInterface`; central service for all ticket/dialog operations.
- **`normalizeTicketToDialog(ticket)`** — converts a raw `TicketNode` GraphQL response into a `Dialog` object, mapping owner, status, tags, notes, attachments, and token usage.
- **`runCommand<P>(field, query, input)`** — generic helper that POSTs a GraphQL mutation, extracts the named payload, and throws on `userErrors`.
- **Fetch methods**: `fetchDialogs`, `fetchBoardColumnByStatusId`, `fetchPendingApprovalTickets`, `countPendingApprovalTickets`, `fetchEscalatedTickets`, `fetchDialog` — each builds filters/variables and returns paginated `TicketsPage` or `Dialog` results.
- **Internal types**: `TicketNode`, `TicketResponse`, `TicketsResponse`, `StatusMutationPayload`, `CommandPayload`, `CreateDialogPayload`, `MarkDialogMessagesReadPayload` — shape the raw GraphQL schema before normalization.
- **Note:** `id` fields passed around are raw `ticketId`/`dialogId` values (not Relay global IDs), used consistently across routes, caches, and NATS subjects.

## Usage Example

```typescript
import { TicketService } from '@/app/services/ticket-service';

const ticketService = new TicketService();

// Fetch a paginated list of tickets filtered by status
const page = await ticketService.fetchDialogs({
  statusIds: ['status-open'],
  limit: 20,
  cursor: null,
  search: '',
});

console.log(page.dialogs, page.pageInfo, page.filteredCount);

// Fetch a single ticket as a Dialog
const dialog = await ticketService.fetchDialog('ticket-123');

// Count tickets pending approval for a given status
const pendingCount = await ticketService.countPendingApprovalTickets('status-review');
```
