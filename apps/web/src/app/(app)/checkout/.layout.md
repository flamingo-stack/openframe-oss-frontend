Defines Next.js metadata and layout re-export for the Checkout route segment, setting the browser tab title dynamically using a shared title-formatting utility.

## Key Components

- **`metadata`** — A `Metadata` object (Next.js App Router convention) that sets the page title to the result of `routeTitle('Checkout')`, ensuring consistent title formatting across the app.
- **Default export** — Re-exports the default layout component from `@/app/(app)/route-title-layout`, reusing a shared layout implementation rather than defining a new one.

## Usage Example

This file follows the Next.js App Router convention where a `layout.tsx` file automatically applies to all routes within its segment (e.g., `/checkout`):

```typescript
// app/(app)/checkout/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Checkout') };
```

Next.js automatically picks up the `metadata` export to set `<title>Checkout | ...</title>` (per `routeTitle`'s formatting logic) in the document head, while the shared `route-title-layout` component handles the actual rendering/wrapping of page content—keeping layout logic centralized and reducing duplication across route segments.
