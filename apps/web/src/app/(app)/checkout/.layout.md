Defines route-level metadata and layout delegation for the Checkout page in a Next.js App Router application.

## Key Components

- **`metadata`** — A `Metadata` export that sets the browser tab title for the Checkout route using the `routeTitle` helper, ensuring consistent title formatting (e.g., appending a site name or suffix) across the app.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, allowing this route segment to reuse a common layout (likely responsible for rendering page titles/headers) without duplicating layout logic.

## Usage Example

This file is a Next.js layout module and is not imported directly; it's automatically picked up by the Next.js routing system for the corresponding route segment (e.g., `/checkout`).

```typescript
// app/(app)/checkout/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Checkout') };
```

To reuse this pattern for another route, create a similar `layout.tsx` in that route's folder, importing the shared layout and setting a page-specific title:

```typescript
export const metadata: Metadata = { title: routeTitle('Billing') };
export { default } from '@/app/(app)/route-title-layout';
```

This keeps title generation centralized via `routeTitle` while delegating visual layout rendering to a single shared component.
