A reusable client-side card component for displaying the outcome of a Stripe checkout flow (success, cancellation, or error), with an icon, title, description, and one or two call-to-action buttons for navigation.

## Key Components

- **`CheckoutResultCard`** — The main exported component that renders a centered card with an icon badge, title, description, and primary/secondary action buttons.
- **`CheckoutResultCardProps`** — Props interface defining:
  - `icon` — A component type (e.g., an icon from a library) rendered inside the badge.
  - `iconWrapperClassName` — CSS classes applied to the icon's circular wrapper (used to style success/error/pending states differently).
  - `title` / `description` — The headline and supporting text for the result.
  - `primaryCta` / `secondaryCta` — Objects with `label` and `href` used to render navigation buttons via `next/navigation`'s `useRouter`.
  - `pending` — Optional flag that disables both buttons while the page is still determining billing/gate state, without altering the already-settled message.

## Usage Example

```typescript
import { CheckCircle } from 'lucide-react';
import { CheckoutResultCard } from './checkout-result-card';

export default function CheckoutSuccessPage() {
  return (
    <CheckoutResultCard
      icon={CheckCircle}
      iconWrapperClassName="bg-ods-success/10 text-ods-success"
      title="Payment Successful"
      description="Your subscription is now active. It may take a moment to reflect across your account."
      primaryCta={{ label: 'Go to Dashboard', href: '/dashboard' }}
      secondaryCta={{ label: 'View Billing', href: '/settings/billing' }}
      pending={false}
    />
  );
}
```

This component is typically used on Stripe checkout return pages (e.g., `/checkout/success` or `/checkout/cancel`) within the OpenFrame OSS frontend, keeping result messaging consistent while the underlying billing gate resolves asynchronously.
