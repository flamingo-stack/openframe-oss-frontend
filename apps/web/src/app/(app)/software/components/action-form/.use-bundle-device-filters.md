# use-bundle-device-filters.ts

A React hook that fetches filter facets (for building search/narrowing UIs) for one half — "assigned" or "available" — of a software bundle's device sets, via a GraphQL Relay query.

## Key Components

- **`bundleDeviceFiltersQuery`** — GraphQL query fetching `availableDeviceFilters` and `assignedDeviceFilters` fragments for a `softwareBundle`, parameterized by `bundleId` and an optional `filter`.
- **`useBundleDeviceFilters(bundleId, half, scope)`** — Hook returning `DeviceFilters` facets scoped to either the `assigned` or `available` device set of a bundle, combined with tag facets from the global fleet (via `useDeviceFilters`).
  - `bundleId: string` — the software bundle's ID.
  - `half: 'assigned' | 'available'` — which device set's facets to read.
  - `scope: DeviceFilterInput` — the OS/platform scope the picker is framed by (sent to the server); user-selected narrowing is intentionally **not** sent, to avoid funnel-style filter collapse.
  - Returns `DeviceFilters` built via `toDeviceFilters`.

## Behavior Notes

- Uses `useLazyLoadQuery` with `fetchPolicy: 'store-and-network'` and a `retryKey` (from `useRetryKey`) to support manual refetch/retry.
- **Suspends** while loading — must be rendered inside a `Suspense` boundary alongside the device list it filters, and ideally under its own error boundary so a failed fetch doesn't break the device rows.
- Only tag-related facets are pulled from `useDeviceFilters` (unscoped), ensuring selecting one tag chip doesn't hide other tags from the menu.

## Usage Example

```typescript
import { Suspense } from 'react';
import { ErrorBoundary } from '@/app/components/shared';
import { useBundleDeviceFilters } from '@/app/(app)/devices/hooks/use-bundle-device-filters';

function BundleDeviceFacets({ bundleId, scope }: { bundleId: string; scope: DeviceFilterInput }) {
  const filters = useBundleDeviceFilters(bundleId, 'assigned', scope);

  return (
    <div>
      {filters.tagKeys.map((tag) => (
        <span key={tag}>{tag}</span>
      ))}
    </div>
  );
}

function BundleDevicePicker({ bundleId, scope }: { bundleId: string; scope: DeviceFilterInput }) {
  return (
    <ErrorBoundary fallback={<div>Failed to load filters</div>}>
      <Suspense fallback={<div>Loading filters...</div>}>
        <BundleDeviceFacets bundleId={bundleId} scope={scope} />
      </Suspense>
    </ErrorBoundary>
  );
}
```
