# useDraftBundle

A React hook that manages the lifecycle of a draft `SoftwareBundle` behind the Install/Update Software form, creating it lazily on mount and discarding it on unmount, tab close, or reload unless explicitly submitted.

## Key Components

- **`useDraftBundle({ enabled })`** — Main hook. Returns `{ bundleId, deviceCount, createError, retryCreate, markSubmitted }`.
- **`createMutation`** — GraphQL mutation that creates an empty draft bundle.
- **`deleteMutation`** — Idempotent GraphQL mutation that discards a draft bundle by id.
- **`bundleFragment`** — Relay fragment (`useDraftBundle_bundle`) exposing `id` and `deviceCount`, kept live by the device picker's store updaters.
- **`discard(environment, id)`** — Fire-and-forget helper that commits the delete mutation, ignoring the outcome since a stale draft is the server reaper's responsibility.
- **`ensureBundle()`** (internal) — Lazily creates the draft, deduplicating concurrent calls (e.g. React Strict Mode's double effect), and rejects if the page has already unmounted.

## Behavior Notes

- The draft is created once `enabled` becomes true, not on the first device selection, so the device picker can read its lists directly off the bundle from the start instead of remounting rows when switching from a fleet list to a bundle.
- Each device addition is written directly to the draft bundle (like editing a script schedule's assignment), so selections never need to be held in browser state.
- On unmount (in-app navigation), the draft is discarded via a normal mutation.
- On `pagehide` (tab close/reload), discard is attempted via `sendGraphqlKeepalive` since only keepalive requests can survive unload — but this is best-effort, not guaranteed.
- On `pageshow` with a restored bfcache page, the stale draft reference is cleared so a new one is created.
- Calling `markSubmitted()` prevents the draft from being discarded, since it's now part of submission history.

## Usage Example

```typescript
import { useDraftBundle } from '@/hooks/use-draft-bundle';

function InstallSoftwareForm({ open }: { open: boolean }) {
  const { bundleId, deviceCount, createError, retryCreate, markSubmitted } =
    useDraftBundle({ enabled: open });

  if (createError) {
    return (
      <button onClick={retryCreate}>
        Failed to start selection — retry
      </button>
    );
  }

  const handleSubmit = async () => {
    if (!bundleId) return;
    await submitSoftwareBundle(bundleId /* , devices, packages, action */);
    markSubmitted();
  };

  return (
    <div>
      <p>Devices selected: {deviceCount}</p>
      <button disabled={!bundleId} onClick={handleSubmit}>
        Submit
      </button>
    </div>
  );
}
```
