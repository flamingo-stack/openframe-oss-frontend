# package-search-field.tsx

A React/Relay component that provides a debounced, server-searched autocomplete field for browsing package manager catalogs (Homebrew, Chocolatey, winget). It defers queries so the input remains live and typeable while results are fetched, and defaults to listing the catalog when the search is empty.

## Key Components

- **`PackageSearchField`** — Public component. Wraps the query logic in a `LoadingSuspense` boundary with its own loading scope.
- **`PackageSearchFieldReader`** — Reads the loading scope; renders a disabled-looking (but non-disabled) `Autocomplete` placeholder while in a shared loading state, otherwise delegates to the query component.
- **`PackageSearchFieldQuery`** — Core logic: debounces user input (300ms), defers the query variables via `useDeferredValue` with an `initialValue` of `NOT_YET`, and issues a Relay query (`packageSearchFieldQuery`) with `store-only` fetch policy before the first deferred value resolves, then `store-or-network` once a real search begins.
- **`toSelectedPackage` / `toOption` / `packageKey`** — Helpers converting GraphQL edge nodes into `SelectedPackage` domain objects and `AutocompleteOption` UI items. `packageKey` combines `packageType` and `id` since Homebrew formulas/casks can share an id.
- **`packageSearchFieldQuery`** — GraphQL query using `@include(if: $list)` to skip the network fetch on the very first (pre-search) render.

## Usage Example

```typescript
import { PackageSearchField } from './package-search-field';
import { PackageManagerType } from '@/generated/schema-enums';

function InstallStep() {
  const [selectedPackage, setSelectedPackage] = useState<SelectedPackage | null>(null);

  return (
    <PackageSearchField
      packageManager={PackageManagerType.HOMEBREW}
      value={selectedPackage}
      onChange={setSelectedPackage}
    />
  );
}
```

Switching the `packageManager` prop remounts the search context (new catalog, fresh search). The currently selected package is always kept resolvable in the options list, even if a new search's results no longer include it.
