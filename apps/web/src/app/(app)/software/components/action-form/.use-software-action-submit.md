# use-software-action-submit.ts

A React hook that validates and submits a software action draft (install, uninstall, or update bundle) to the server, handling both "run now" and "schedule for later" flows, then navigates the user to the appropriate page based on the result.

## Key Components

- **`useSoftwareActionSubmit(action, options)`** — Main hook that returns a `submit` function and `isSubmitting` state for a given `SoftwareAction` (install/uninstall/update).
- **`SoftwareActionForm`** — Interface describing the form state required to submit: selected rows, bundle id, device count, run mode, schedule date/time, and optional update settings.
- **`SoftwareActionSubmitOptions`** — Callback options, notably `onSubmitted` to signal the draft is no longer a discardable draft.
- **`SoftwareActionSubmit`** — Return type exposing `submit(form)` and `isSubmitting: boolean`.
- **`submitMutation`** (GraphQL) — Submits the software bundle (`submitSoftwareBundle`), returning the run id and `executionIds`.
- **`actionQuery`** (GraphQL) — Looks up whether a `softwareAction` row exists yet for a given execution id, used to route to the run's detail page as soon as it's available.
- **Internal helpers**: `fail` (toast error), `scheduleInput` (validates/builds schedule payload), `leaveForRun` (post-submit navigation for single-package runs).

## Usage Example

```typescript
import { useSoftwareActionSubmit } from './use-software-action-submit';

function InstallSoftwarePage() {
  const { submit, isSubmitting } = useSoftwareActionSubmit('INSTALL', {
    onSubmitted: () => setDraftDirty(false),
  });

  const handleSubmit = () => {
    submit({
      rows: selectedRows,
      bundleId: draftBundleId,
      deviceCount: selectedDevices.length,
      mode: 'now',
      date: null,
      time: '',
      timeReference: 'DEVICE_LOCAL',
    });
  };

  return (
    <button onClick={handleSubmit} disabled={isSubmitting}>
      Install Now
    </button>
  );
}
```

For scheduled runs, pass `mode: 'schedule'` along with `date` and `time`; the hook validates the start time isn't in the past before submitting. On success, it toasts a confirmation and routes to the run's detail page (single package/device) or the actions list otherwise.
