# software-log-status-cell.tsx

Renders the STATUS column cell for a software execution log row, displaying an action label (e.g., "Update"/"Install"), a colored status tag, and the dispatch timestamp. Supports loading-state skeletons via a shared loading scope and reads data lazily through a GraphQL fragment (Relay).

## Key Components

- **`softwareLogStatusCellFragment`** — GraphQL fragment declaring the `status` and `dispatchedAt` fields required from `ScriptExecution`.
- **`SoftwareLogStatusCellProps`** — Props interface:
  - `execution`: Relay fragment reference (`softwareLogStatusCell_execution$key`) for the script execution.
  - `actionLabel`: The leading word of the cell (e.g., `"Update"`, `"Install"`).
- **`SoftwareLogStatusCell`** — Component that:
  - Detects loading state via `useLoadingScope()` and conditionally skips fragment reading.
  - Renders a skeleton (`TextLineSkeleton`) for the action label while loading.
  - Displays a status `Tag` (color/variant derived from `executionStatusVariant`) and label (`softwareRunStatusLabel`).
  - Shows the formatted dispatch date/time via `formatDateTime` inside a `TruncateText`.

## Usage Example

```typescript
import { SoftwareLogStatusCell } from './software-log-status-cell';

function SoftwareLogRow({ executionRef }: { executionRef: softwareLogStatusCell_execution$key }) {
  return (
    <SoftwareLogStatusCell
      execution={executionRef}
      actionLabel="Install"
    />
  );
}
```

This component is typically used as a table cell renderer within a software execution log list, where each row corresponds to a device's script execution result. It gracefully handles loading states so the table can render immediately with skeleton placeholders while Relay resolves the underlying data.
