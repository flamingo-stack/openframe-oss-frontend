# software-log-result-toggle.tsx

Renders the "Show Result" / "Hide Result" toggle control used in the result column of software log rows, handling both the connected (context-bound) cell and the presentational toggle button with responsive layouts and animated label transitions.

## Key Components

- **`SoftwareLogResultToggleCell({ id })`** — Context-connected cell component. Reads the open/closed state for a given row `id` from `ResultPhasesContext` and wires up the `toggle` callback. Disables the control while the row is in a loading scope (still being read).
- **`SoftwareLogResultToggle({ open, onToggle, disabled })`** — Presentational toggle button. Renders a split button with a label and chevron on `md+` screens, collapsing to an icon-only button below `md`. The chevron rotates 180° when `open` is true.
- **`ToggleLabel({ open })`** (internal) — Stacks both "Show Result" and "Hide Result" labels in a single grid cell, cross-fading between them via opacity so the label swap doesn't visually resize the button.

## Usage Example

```typescript
import { SoftwareLogResultToggleCell } from './software-log-result-toggle';

// Used as a cell renderer inside a table column definition,
// where each row supplies its own stable `id`.
function ResultColumnCell({ row }: { row: { id: string } }) {
  return <SoftwareLogResultToggleCell id={row.id} />;
}
```

```typescript
import { SoftwareLogResultToggle } from './software-log-result-toggle';
import { useState } from 'react';

// Standalone usage without the context, e.g. in isolated UI testing.
function StandaloneToggleExample() {
  const [open, setOpen] = useState(false);
  return (
    <SoftwareLogResultToggle open={open} onToggle={() => setOpen((v) => !v)} />
  );
}
```

**Notes:**
- Relies on `useResultPhasesContext` for per-row state, keeping the column definition itself free of changing closures.
- Uses `data-no-row-click` to prevent the toggle click from triggering the parent row's click handler.
- Responsive behavior: full split button (176px fixed width) at `content-md` breakpoint and above; icon-only button below it.
