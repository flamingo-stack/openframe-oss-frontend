Renders the section heading (e.g., "Update Logs" / "Install Logs") displayed above the log details on an action summary card, with built-in skeleton loading support.

## Key Components

- **`ActionDetailLogsHeading`** — React component that renders an `<h2>` heading for the logs section. Accepts a single prop:
  - `text: string | null` — the heading label to display. When `null`, or when an ancestor loading scope is active (via `useLoadingScope`), a skeleton placeholder is rendered instead of the text.

The component uses `useLoadingScope` to determine if it's within a loading context, and falls back to a `TextLineSkeleton` (styled as an `h2`-sized bar) while loading or when `text` is not yet available.

## Usage Example

```typescript
import { ActionDetailLogsHeading } from './action-detail-logs-heading';

function ActionSummaryCard({ action }: { action: { logType: string | null } }) {
  return (
    <section>
      <ActionDetailLogsHeading text={action.logType} />
      {/* log entries rendered below */}
    </section>
  );
}

// While data is loading, pass `null` to show the skeleton:
<ActionDetailLogsHeading text={null} />

// Once loaded:
<ActionDetailLogsHeading text="Install Logs" />
```

This component is typically used within a page or panel that wraps its content in a loading scope provider, allowing the heading to automatically reflect the parent's loading state without explicit prop drilling.
