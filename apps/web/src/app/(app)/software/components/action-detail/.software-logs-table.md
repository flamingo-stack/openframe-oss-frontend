## software-logs-table.tsx

Renders the per-device execution log table for a single software package's install/update run, mirroring the script execution history table but scoped to one run via its `executionId`. Supports status-based filtering (the only server-filterable facet), client-side search narrowing, infinite scroll pagination, and expandable per-row result panels showing command output.

## Key Components

- **`softwareLogsTableQuery`** — GraphQL query fetching the paginated fragment plus `softwareExecutionFilters` for the STATUS facet counts.
- **`softwareLogsTableFragment`** — Refetchable, paginated fragment (`@connection`) exposing `softwareExecutions` edges with device/customer/status/result data.
- **`SoftwareLogRow`** — Type alias for a single execution node in the connection.
- **`SoftwareLogsTable`** — Top-level component; loads data via `useLazyLoadQuery` and `usePaginationFragment`, wires up infinite scroll, and delegates rendering to `SoftwareLogsRows`.
- **`SoftwareLogsRows`** — Presentational table component (query-free) that builds columns (device, customer, status, result toggle), applies search/filter narrowing, handles loading placeholders, and renders expandable sub-rows via `ResultPhasesContext`.
- **`EMPTY_STATE`** — No-data placeholder copy/icon shown when a run has no device reports yet.

## Usage Example

```typescript
import { SoftwareLogsTable } from './software-logs-table';

function SoftwareUpdateDetails({ state }: { state: ExecutionsTabState }) {
  return (
    <SoftwareLogsTable
      packageManager="APT"
      packageName="openssl"
      action="UPDATE"
      executionId="exec-123"
      actionLabel="Update"
      state={state}
    />
  );
}
```

When data is already loaded by a parent (e.g., while the run query is pending), use `SoftwareLogsRows` directly with pre-fetched rows and facets:

```typescript
<SoftwareLogsRows
  allRows={rows}
  statusFacets={statusFacets}
  infiniteScroll={{ hasNextPage: false, isFetchingNextPage: false, onLoadMore: () => {} }}
  actionLabel="Install"
  state={state}
/>
```
