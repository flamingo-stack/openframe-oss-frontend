## use-result-phases.ts

A React hook and context pair that tracks the expand/collapse transition state of per-row result panels in a table, decoupling that state from TanStack Table's column definitions to avoid unnecessary cell remounts.

## Key Components

- **`ResultPhase`** — Type alias for `CollapsePhase`, representing a row's position in the open/close transition machine (e.g., opening, open, closing, or unmounted/absent).
- **`useResultPhases()`** — Hook that owns a `Map` of row IDs to their current `ResultPhase`. Returns:
  - `phases` — read-only map of row ID to phase.
  - `toggle(id)` — opens a closed row or begins closing an open one; schedules a post-paint update to finalize the "opening" → "open" transition.
  - `collapsed(id)` — called when a row's closing transition animation ends, unmounting its panel by removing it from the map.
- **`ResultPhasesBinding`** — Interface describing what result cells need (`phases` and `toggle`), exposed via context.
- **`ResultPhasesContext`** — React context carrying the `ResultPhasesBinding`, so table cell renderers can read live phase state without being recreated on every toggle.
- **`useResultPhasesContext()`** — Consumer hook that reads the context and throws if no provider is present above it in the tree.

## Usage Example

```typescript
import { useResultPhases, ResultPhasesContext, useResultPhasesContext } from '@/app/hooks/use-result-phases';

// At the table root
function ResultsTable() {
  const resultPhases = useResultPhases();

  return (
    <ResultPhasesContext.Provider value={resultPhases}>
      {/* table rendering using stable column definitions */}
    </ResultPhasesContext.Provider>
  );
}

// Inside a cell renderer (column def stays constant across toggles)
function ResultCell({ rowId }: { rowId: string }) {
  const { phases, toggle } = useResultPhasesContext();
  const phase = phases.get(rowId);

  return (
    <button onClick={() => toggle(rowId)}>
      {phase === 'open' ? 'Collapse' : 'Expand'}
    </button>
  );
}
```

This pattern ensures that toggling a row's panel updates only the context value, not the column definitions passed to `flexRender`, preserving hover state and animation continuity across all rendered cells.
