Defines the ordered set of labels used by the Action Detail Summary card, shared between the actual card component and its loading skeleton to ensure consistent layout and wording.

## Key Components

- **`ACTION_DETAIL_SUMMARY_LABELS`** — A `const`-asserted object mapping summary field keys (`software`, `packageManager`, `packageVersion`, `processed`) to their human-readable display labels. The `as const` assertion preserves literal string types and readonly property values, enabling strict type inference for consumers.

## Usage Example

```typescript
import { ACTION_DETAIL_SUMMARY_LABELS } from './action-detail-summary-labels';

// Render summary rows consistently across the card and skeleton components
Object.entries(ACTION_DETAIL_SUMMARY_LABELS).forEach(([key, label]) => {
  console.log(`${label}: ${summaryData[key as keyof typeof summaryData]}`);
});

// Example output:
// Software Name: nginx
// Package Manager: apt
// Package Version: 1.18.0
// Processed Devices: 42
```

This shared constant ensures the summary card and its skeleton placeholder render the same labels in the same order, avoiding duplication and drift between the two components.
