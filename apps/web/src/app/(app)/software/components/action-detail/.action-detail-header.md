# ActionDetailHeader

A client-side React component that renders the page header for a software action run's detail view, displaying a dynamic title based on the action type (e.g., "update" or "install") along with a back-navigation link.

## Key Components

- **`actionDetailHeaderFragment`** — GraphQL fragment (via `react-relay`) that fetches the `action` field from a `SoftwareActionRun` object.
- **`ActionDetailHeader`** — The main exported component. Accepts an `action` fragment reference, resolves it with `useFragment`, derives a human-readable title using `softwareActionCopy`, and falls back to `SOFTWARE_ACTION_DETAIL_TITLE` when no data is available. Renders the shared `DetailTitle` component with the resolved title and a back link to the software actions list.

## Usage Example

```typescript
import { ActionDetailHeader } from './action-detail-header';
import { graphql, useLazyLoadQuery } from 'react-relay';

function ActionDetailPage({ actionId }: { actionId: string }) {
  const data = useLazyLoadQuery(
    graphql`
      query ActionDetailPageQuery($id: ID!) {
        softwareActionRun(id: $id) {
          ...actionDetailHeader_action
        }
      }
    `,
    { id: actionId }
  );

  return (
    <div>
      <ActionDetailHeader action={data.softwareActionRun} />
      {/* rest of the detail page content */}
    </div>
  );
}
```

## Notes

- The component gracefully handles `null`/`undefined` action references (e.g., when a run ID has no corresponding data), displaying a generic fallback title instead of failing.
- Navigation back-link target is defined centrally in `@/lib/routes` via `routes.software.actions`.
- Title resolution logic (`softwareActionCopy`) is shared from the `@flamingo-stack/openframe-frontend-core` package, ensuring consistent copy across the app.
