Defines the static column layout configuration for the Software Update Details per-device logs table, used to render a consistent live table and its loading skeleton.

## Key Components

- **`SOFTWARE_LOG_COLUMNS`** — A typed constant object (`satisfies Record<string, TableSkeletonColumn>`) describing each column in the per-device logs table:
  - `device` — Device name/identifier column, flexible width.
  - `customer` — Customer name column, flexible width, hidden below the `md` breakpoint (`hideAt: 'md'`).
  - `status` — Update status column, flexible width.
  - `result` — Result column, fixed/shrink width (`w-12`, expanding to `176px` at the `content-md` breakpoint), right-aligned.

Each entry conforms to the `TableSkeletonColumn` type imported from `@/app/components/shared/table-column-layout`, ensuring consistent structure (`id`, `header`, `width`, `align`, `hideAt`) across the live table and its loading skeleton placeholder.

## Usage Example

```typescript
import { SOFTWARE_LOG_COLUMNS } from './software-logs-columns';

// Render table headers
Object.values(SOFTWARE_LOG_COLUMNS).map((col) => (
  <th key={col.id} className={col.width}>
    {col.header}
  </th>
));

// Use the same config to render a loading skeleton
// with matching column widths and responsive hiding
<TableSkeleton columns={SOFTWARE_LOG_COLUMNS} rows={5} />
```

This module is intentionally data-only — it contains no rendering logic, keeping the column definitions reusable between the live logs table and its skeleton loading state.
