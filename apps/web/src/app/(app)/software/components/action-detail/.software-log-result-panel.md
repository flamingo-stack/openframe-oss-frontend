A React client component that renders a collapsible panel displaying script execution output (stdout/stderr/error) within software log rows, using a smooth grid-based expand/collapse animation.

## Key Components

- **`SoftwareLogResultPanel`** — Main exported component that renders the expandable output panel for a script execution.
- **`softwareLogResultPanelFragment`** — GraphQL fragment pulling `stdout`, `stderr`, and `error` fields from the `ScriptExecution` type via Relay's `useFragment`.
- **`SoftwareLogResultPanelProps`** — Props interface requiring:
  - `execution`: the Relay fragment key (`softwareLogResultPanel_execution$key`)
  - `expanded`: boolean controlling the open/closed state
  - `onCollapsed`: callback fired once the collapse transition finishes, signaling the panel can safely unmount

The component uses `executionOutput` (from `execution-helpers`) to combine `stdout`/`stderr`/`error` into a single displayable string, falling back to "No output" when empty. The animation relies on CSS `grid-template-rows` transitioning between `0fr` and `1fr` (same idiom as `onboarding-accordion.tsx`), avoiding the need for measured heights, while the inner content scrolls independently once it exceeds 400px.

## Usage Example

```typescript
import { SoftwareLogResultPanel } from '@/app/(app)/scripts/shared/components/software-log-result-panel';
import { useState } from 'react';

function ExecutionRow({ execution }: { execution: softwareLogResultPanel_execution$key }) {
  const [expanded, setExpanded] = useState(false);
  const [mounted, setMounted] = useState(true);

  if (!mounted) return null;

  return (
    <>
      <button onClick={() => setExpanded(prev => !prev)}>Toggle Result</button>
      <SoftwareLogResultPanel
        execution={execution}
        expanded={expanded}
        onCollapsed={() => setMounted(false)}
      />
    </>
  );
}
```

**Note:** The `onCollapsed` callback only fires when the transition ends and `expanded` is `false`, enabling parent components to defer unmounting until the collapse animation completes.
