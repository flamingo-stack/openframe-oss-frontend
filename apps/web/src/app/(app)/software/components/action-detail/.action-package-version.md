Renders the latest published version of a catalog package for a given package manager, fetched via a Relay GraphQL query, with isolated loading and error states so failures degrade gracefully to an empty value.

## Key Components

- **`actionPackageVersionQuery`** — GraphQL query fetching `packageDetails.versions` for a given `packageManager` and `packageId` (package name). The Brew `packageType` is always passed as `null`, meaning formula/cask sub-types collapse and a name shared between both reads as empty.
- **`ActionPackageVersion`** — Public component. Wraps rendering in an `ErrorBoundary` that falls back to `EmptyValue` on failure, so a query error never breaks the page.
- **`ActionPackageVersionValue`** — Wraps the reader in a `LoadingSuspense` boundary (label: "Loading package version") to isolate its own loading state.
- **`ActionPackageVersionReader`** — Checks `useLoadingScope()`; if currently rendering inside a Suspense fallback, it short-circuits and shows a skeleton (`ValueText` with `value={null}`) instead of triggering a nested fetch.
- **`ActionPackageVersionQuery`** — Executes `useLazyLoadQuery` with `fetchPolicy: 'store-or-network'` and renders the first version string (`versions[0]?.version`) via `ValueText`, falling back to the skeleton width `w-20` while loading.

## Usage Example

```typescript
import { ActionPackageVersion } from '@/app/components/.../action-package-version';

function PackageRow({ packageManager, packageName }: {
  packageManager: PackageManagerType;
  packageName: string;
}) {
  return (
    <ActionPackageVersion
      packageManager={packageManager}
      packageName={packageName}
    />
  );
}
```

This component is intended for use in tables or lists displaying catalog action packages, where each row independently resolves and displays its latest version without blocking sibling rows on error or loading.
