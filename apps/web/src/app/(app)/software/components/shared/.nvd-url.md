# nvd-url.ts

Utility module for building and opening links to the National Vulnerability Database (NVD), used as the canonical fallback source for CVE details when the backend doesn't provide its own link.

## Key Components

- **`nvdUrl(cveId: string): string`** — Builds a properly encoded URL to a CVE's detail page on the NVD website (`https://nvd.nist.gov/vuln/detail/{cveId}`).
- **`openNvd(cveId: string): void`** — Opens the NVD record for a given CVE id in a new browser tab, using `noopener,noreferrer` for security.

## Usage Example

```typescript
import { nvdUrl, openNvd } from './nvd-url';

// Build a link to display or embed
const link = nvdUrl('CVE-2023-12345');
// => "https://nvd.nist.gov/vuln/detail/CVE-2023-12345"

// Open the CVE record directly, e.g. from a button click handler
function onViewDetails(cveId: string) {
  openNvd(cveId);
}
```

This is typically used in vulnerability tables or detail panels where a "View on NVD" link/button is shown when no internal link to the vulnerability is available.
