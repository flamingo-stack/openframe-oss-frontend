# software-tab-navigation.tsx

A client-side navigation component that renders a tab bar for switching between the Software section's three top-level pages (each backed by its own route, not a query-param tab state).

## Key Components

- **`SOFTWARE_TABS`** — Array of `TabItem` objects derived from `SOFTWARE_SECTIONS`, mapping each section's `id`, `label`, and `icon` for display in the tab bar.
- **`SoftwareTabNavigationProps`** — Props interface requiring `activeTab: SoftwareSectionId` to indicate the currently selected section.
- **`SoftwareTabNavigation`** — React component that renders a `TabNavigation` UI element and handles tab-click navigation by pushing to the corresponding route via `useRouter`.

## Usage Example

```typescript
import { SoftwareTabNavigation } from './software-tab-navigation';
import type { SoftwareSectionId } from './software-sections';

export default function SoftwarePage({ activeTab }: { activeTab: SoftwareSectionId }) {
  return (
    <div>
      <SoftwareTabNavigation activeTab={activeTab} />
      {/* Page-specific content rendered below based on the current route */}
    </div>
  );
}
```

The component looks up the `href` for the clicked tab using `presentationFor(SOFTWARE_SECTIONS, tabId)` and navigates there with `router.push`, only if the selected tab differs from `activeTab` and a valid `href` exists. Because `urlSync` is disabled on `TabNavigation`, the component does not attempt to sync tab state with URL query parameters—each tab is a distinct route under `SOFTWARE_SECTIONS`.
