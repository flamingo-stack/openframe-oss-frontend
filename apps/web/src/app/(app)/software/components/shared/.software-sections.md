Defines the configuration for the Software module's section switcher, mapping each page (All Software, Software Actions, Vulnerabilities) to its label, route, and icon.

## Key Components

- **`SOFTWARE_SECTIONS`** — A constant object mapping section IDs (`all`, `actions`, `vulnerabilities`) to their metadata: `label` (used as both tab text and page title), `href` (route path from `routes.software`), and `icon` (component from `@flamingo-stack/openframe-frontend-core/components/icons-v2`).
- **`SoftwareSectionId`** — A union type derived from the keys of `SOFTWARE_SECTIONS`, used to type-safely reference a specific section.

## Usage Example

```typescript
import { SOFTWARE_SECTIONS, type SoftwareSectionId } from './software-sections';

// Render tabs for a section switcher
Object.entries(SOFTWARE_SECTIONS).map(([id, section]) => (
  <Tab key={id} href={section.href} icon={section.icon}>
    {section.label}
  </Tab>
));

// Type-safe reference to an active section
const activeSection: SoftwareSectionId = 'vulnerabilities';
const current = SOFTWARE_SECTIONS[activeSection];
console.log(current.label); // "Vulnerabilities"
```

This pattern keeps the switcher's tabs and each page's title in sync with a single source of truth, and ensures navigation links reuse the centralized `routes` definitions.
