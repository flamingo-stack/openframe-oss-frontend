# detail-title.tsx

A reusable title header component for detail pages, rendering a record's title alongside a "Back" navigation button. Designed to remain functional even while the underlying record is still loading or fails to resolve.

## Key Components

- **`DetailTitleProps`** — Interface defining the component's props:
  - `title: string` — The display title (typically the record's name/identifier).
  - `backTo: string` — Fallback navigation target used when there's no browser history to go back to.
  - `loading?: boolean` — Optional flag indicating the title is still being fetched; renders as a loading bar.

- **`DetailTitle`** — The main exported component. It combines:
  - `useLoadingScope()` from `@flamingo-stack/openframe-frontend-core/components/ui` to detect ambient loading state from a parent scope.
  - `useSafeBack(backTo)` from `@/app/hooks/use-safe-back` to produce a safe back-navigation handler that works even when there's no prior history entry.
  - `TitleBlock` from `@flamingo-stack/openframe-frontend-core` to render the title bar and back button UI.

## Usage Example

```typescript
import { DetailTitle } from '@/components/detail-title';

function DeviceDetailPage({ device, isLoading }: { device?: Device; isLoading: boolean }) {
  return (
    <>
      <DetailTitle
        title={device?.name ?? 'Device'}
        backTo="/devices"
        loading={isLoading}
      />
      {/* rest of detail page content */}
    </>
  );
}
```

This pattern ensures the "Back" button always works—whether the user navigated here directly (no history) or the record failed to load—by falling back to the `backTo` route via `useSafeBack`.
