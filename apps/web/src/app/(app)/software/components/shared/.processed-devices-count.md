This file defines a small presentational React component that displays the progress of device responses during a run, formatted as `"responded/total"` (e.g., `3/10`).

## Key Components

- **`ProcessedDevicesCount`** — Functional component that renders the count of devices that have responded versus the total device count, using muted styling for the total portion.
- **`ProcessedDevicesCountProps`** — Interface defining the required props: `responded` (number) and `total` (number).
- Relies on `formatCount` from `@/lib/format-number` to format numeric values (e.g., adding thousand separators or abbreviations).

## Usage Example

```typescript
import { ProcessedDevicesCount } from '@/components/processed-devices-count';

function RunStatus() {
  return (
    <div className="flex items-center gap-2">
      <span>Devices processed:</span>
      <ProcessedDevicesCount responded={3} total={10} />
    </div>
  );
}
```

This renders output similar to:

```text
Devices processed: 3/10
```

where `/10` is styled with secondary text color (`text-ods-text-secondary`) to visually de-emphasize the total relative to the responded count. This component is typically used in dashboards or run summary views to give a quick visual indicator of progress for a batch operation across multiple devices.
