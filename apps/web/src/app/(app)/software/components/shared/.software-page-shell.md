Client-side layout shell component that provides a consistent frame for all Software section routes, combining optional tab navigation, standardized page padding, and error boundary handling.

## Key Components

- **`SoftwarePageShell`** — React component that wraps page content with:
  - Optional `SoftwareTabNavigation` (rendered only when `section` is provided, since detail pages omit the section switcher)
  - Consistent horizontal/bottom padding via CSS custom properties (`--spacing-system-l`)
  - A `ContentErrorBoundary` scoped *inside* the padded container, ensuring errors don't collapse the outer layout's spacing
- **`SoftwarePageShellProps`** — Props interface:
  - `section?: SoftwareSectionId` — active tab for the section switcher; omit on detail pages
  - `title: string` — page title reused by the error fallback UI
  - `errorMessage: string` — message shown when content throws
  - `children: ReactNode` — the page content to render

## Usage Example

```typescript
import { SoftwarePageShell } from './software-page-shell';

export default function InventoryPage() {
  return (
    <SoftwarePageShell
      section="inventory"
      title="Inventory"
      errorMessage="Unable to load inventory data."
    >
      <InventoryTable />
    </SoftwarePageShell>
  );
}

// Detail page without the section switcher
export default function DeviceDetailPage() {
  return (
    <SoftwarePageShell
      title="Device Details"
      errorMessage="Unable to load device details."
    >
      <DeviceDetailView />
    </SoftwarePageShell>
  );
}
```

This component should be used as the top-level wrapper for any page under the Software section to ensure consistent navigation, spacing, and error handling across routes.
