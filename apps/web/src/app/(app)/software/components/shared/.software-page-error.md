## software-page-error.tsx

Provides a factory function that generates a custom error-fallback renderer for Software pages, used when a page's content subtree throws and the default error boundary fallback would otherwise misalign the error card with the page title.

This file exists to work around a layout quirk in the core `ErrorState` component: it hardcodes `p-6` padding that can't be opted out of, which would otherwise push the error card 24px further right than the title rendered above it. The `-m-6` wrapper cancels that padding so the card's left edge lines up with the title, matching the spacing used elsewhere (e.g., under a table header).

## Key Components

- **`softwarePageErrorFallback(title, message)`** — Factory function that takes a page `title` and an error `message`, returning a fallback-renderer function compatible with `ContentErrorBoundary`'s `fallback` prop.
- **`SoftwarePageError(retry, state)`** — The returned renderer (intentionally a named function, not an arrow function, so `react/display-name` lint doesn't flag it as an anonymous component). It renders a `PageLayout` with the given `title`, and inside it a `LoadError` component wrapped in a `-m-6` div to correct padding, using `loadErrorProps` to compute offline/message/retry props.

## Usage Example

```typescript
import { softwarePageErrorFallback } from './software-page-error';
import { ContentErrorBoundary } from '@flamingo-stack/openframe-frontend-core/components/ui';

export function SoftwareListPage() {
  return (
    <ContentErrorBoundary
      fallback={softwarePageErrorFallback(
        'Software',
        'Failed to load software inventory.'
      )}
    >
      <SoftwareTable />
    </ContentErrorBoundary>
  );
}
```

When the subtree inside `ContentErrorBoundary` throws, the boundary calls `SoftwarePageError(retry, state)` to render a page-titled error state that visually matches the rest of the Software page layout.
