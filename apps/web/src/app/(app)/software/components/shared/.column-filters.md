Utility module that adapts TanStack Table's column-filter state to a controlled, callback-driven pattern, letting filter selections live outside the table (e.g., in the URL or parent component state) instead of inside `useDataTable`'s internal state.

## Key Components

- **`ColumnFilterState`** (internal type) — Structural re-declaration of TanStack's column filter array shape (`{ id, value }[]`), avoiding an undeclared dependency on `@tanstack/react-table`.
- **`ColumnFiltersUpdater`** (internal type) — Matches TanStack's updater signature: either a new state value or a function that reduces the previous state.
- **`singleColumnFilter(columnId, values, onChange)`** — Builds `columnFilters`/`onColumnFiltersChange` for a table with exactly one filterable column. Converts an external string array into TanStack's filter state and translates filter changes back into a simple `string[]` via `onChange`.
- **`multiColumnFilter(selections, onChange)`** — Same idea for multiple filterable columns keyed by column id. Accepts a record of per-column selections and reports the entire updated record back on any change, so callers don't need to diff which column changed.

## Usage Example

```typescript
import { singleColumnFilter, multiColumnFilter } from './column-filters';

// Single funnel: e.g. a "status" column filter driven by URL state
const [status, setStatus] = useState<string[]>([]);
const { columnFilters, onColumnFiltersChange } = singleColumnFilter(
  'status',
  status,
  setStatus,
);

// Multiple funnels: e.g. "status" and "priority" columns
const [filters, setFilters] = useState({ status: [], priority: [] });
const { columnFilters, onColumnFiltersChange } = multiColumnFilter(
  filters,
  setFilters,
);

// Pass both into useDataTable
const table = useDataTable({
  columns,
  data,
  state: { columnFilters },
  onColumnFiltersChange,
});
```
