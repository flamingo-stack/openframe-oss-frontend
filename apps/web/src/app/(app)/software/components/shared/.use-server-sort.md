# use-server-sort.ts

A React hook that manages server-side table sorting state synchronized with URL query parameters, bridging GraphQL `SortInput` with a data table's sort indicator UI.

## Key Components

- **`ServerSortInput`** — Interface for the GraphQL sort payload (`field` + `direction`).
- **`ServerSort`** — Return shape of the hook: `sort` (query input), `sortState` (UI indicator state), `onSortChange` (click handler).
- **`UseServerSortOptions`** — Hook input: current `sortBy`/`sortDir` from the URL, the list of `sortableIds` the backend accepts, and an `onChange` callback that writes both params back to the URL.
- **`useServerSort`** — The hook itself. It:
  - Validates `sortBy` against `sortableIds`, falling back to `''` to guard against stale or hand-edited URLs reaching the GraphQL query.
  - Memoizes the `sort` object so `useDeferredQuery` can detect pending refetches by reference equality.
  - Derives `sortState` live (not memoized) so the header's indicator updates immediately on click.
  - Implements a 3-state toggle on `onSortChange`: unsorted → desc → asc → unsorted, writing `''` instead of `'desc'` for the default direction so `useApiParams` can drop the param from the URL.
  - Scrolls the `main` container to top on sort change.

## Usage Example

```typescript
import { useServerSort } from '@/hooks/use-server-sort';
import { useApiParams } from '@/hooks/use-api-params';

function DeviceTable() {
  const { params, setParams } = useApiParams();

  const { sort, sortState, onSortChange } = useServerSort({
    sortBy: params.sortBy ?? '',
    sortDir: params.sortDir ?? '',
    sortableIds: ['name', 'status', 'lastSeen'],
    onChange: (sortBy, sortDir) => setParams({ sortBy, sortDir }),
  });

  const { data } = useDeferredQuery(DEVICES_QUERY, { variables: { sort } });

  return (
    <DataTable
      data={data}
      sortState={sortState}
      onSortChange={onSortChange}
    />
  );
}
```
