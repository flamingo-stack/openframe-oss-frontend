# software-list-frame.tsx

A shared layout frame that standardizes URL-synced state, search, sort, and filter behavior across all Software module lists (fleet-wide Software/Vulnerabilities pages and device-level tabs). It centralizes search debouncing, server-side sort toggling, multi-funnel filter selections, deferred query variables, sticky toolbar behavior, and the empty-state toolbar collapse, so every list using this frame behaves identically.

## Key Components

- **`SoftwareListFrame`** — The main component. Wraps child list content, manages URL params (search, sort, filters), a sticky search toolbar, deferred query values (to avoid UI jank during refetches), and a `loading` scope for when the owning module's feature flag hasn't resolved yet.
- **`SoftwareListFrameRenderProps`** — Props passed to the `children` render function, split into "live" values (drive instant UI feedback like sort indicators and filter ticks) and "deferred" values (lag during refetch, feed the actual data query).
- **`ListSelections`** — Type alias for a filter-column-keyed record of selected values.
- **`paramName`** — Helper to namespace URL param keys with an optional prefix (for tabs sharing a URL with other tabs).
- **`readString` / `readArray`** — Type-narrowing helpers for reading untyped param values.

## Usage Example

```typescript
import { SoftwareListFrame } from './software-list-frame';

function SoftwareVulnerabilitiesTab({ flagLoading }: { flagLoading: boolean }) {
  return (
    <SoftwareListFrame
      paramPrefix="cve"
      placeholder="Search vulnerabilities..."
      sortableIds={['severity', 'publishedAt']}
      filterKeys={['severity', 'status']}
      loading={flagLoading}
      banner={<SyncStatusBanner />}
    >
      {({
        debouncedSearch,
        sort,
        deferredSelections,
        sortState,
        onSortChange,
        selections,
        onSelectionsChange,
        isPending,
        onEmptyChange,
        stickyHeaderOffset,
      }) => (
        <VulnerabilitiesTable
          search={debouncedSearch}
          sort={sort}
          filters={deferredSelections}
          sortState={sortState}
          onSortChange={onSortChange}
          currentSelections={selections}
          onFilterChange={onSelectionsChange}
          isPending={isPending}
          onEmpty={onEmptyChange}
          stickyOffset={stickyHeaderOffset}
        />
      )}
    </SoftwareListFrame>
  );
}
```

Each consumer owns only its data connection and row rendering; the frame guarantees identical URL-state behavior, debounce timing, and toolbar UX across all Software module surfaces.
