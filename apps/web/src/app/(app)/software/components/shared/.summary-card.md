## summary-card.tsx

A responsive summary card component that displays a row of labelled values (e.g., metadata fields on a detail page), stacking vertically on small screens and arranging into a configurable grid from `md` breakpoint up. Integrates with `InfoCell` so loading and loaded states share the same layout.

## Key Components

- **`SummaryCard`** — Main component rendering an optional full-width `lead` block (e.g., a description) above a grid of `InfoCell` fields.
- **`SummaryCardProps`** — Props interface: `fields` (array of label/value pairs), `columns` (2, 3, or 4 column layout from `md` breakpoint), and optional `lead` (ReactNode shown above the fields, separated by a border).
- **`SummaryField`** — Shape of each field: `{ label: string; value: ReactNode }`.
- **`SummaryCardColumns`** — Type restricting `columns` to the supported values (`2 | 3 | 4`), backed by the static `GRID_COLUMNS` map so Tailwind can statically analyze class names.

## Usage Example

```typescript
import { SummaryCard, type SummaryField } from '@/app/components/shared/summary-card';

const fields: SummaryField[] = [
  { label: 'Severity', value: 'Critical' },
  { label: 'Published', value: '2024-01-15' },
  { label: 'CVSS Score', value: 9.8 },
];

function CveSummary() {
  return (
    <SummaryCard
      columns={3}
      lead={<p className="text-sm text-ods-text-secondary">CVE-2024-0001: Remote code execution vulnerability.</p>}
      fields={fields}
    />
  );
}
```

For a loading state, pass fields whose `value` is `undefined` or a loading placeholder — `InfoCell` handles rendering a skeleton bar automatically while keeping the label visible, ensuring consistent layout between loading and loaded states.
