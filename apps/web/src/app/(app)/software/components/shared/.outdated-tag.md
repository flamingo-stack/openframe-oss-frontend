Defines a reusable UI tag constant representing software that is behind its latest version, used consistently across fleet-wide and per-device views.

## Key Components

- **`OUTDATED_TAG`** — A `const` object with:
  - `label: 'Outdated'` — display text for the chip/tag
  - `variant: 'warning'` — visual style indicating a non-critical state (not an error)

The object is declared with `as const` to preserve literal types for `label` and `variant`, enabling strict type-checking when consumed by components expecting specific variant values.

## Usage Example

```typescript
import { OUTDATED_TAG } from './outdated-tag';

// Render a status chip for a device or software title
function SoftwareStatusChip({ isOutdated }: { isOutdated: boolean }) {
  if (!isOutdated) return null;

  return <Chip label={OUTDATED_TAG.label} variant={OUTDATED_TAG.variant} />;
}

// Use in a status mapping table
const STATUS_TAGS = {
  outdated: OUTDATED_TAG,
  // ...other status tags
} as const;
```

This constant ensures the "Outdated" label and its warning styling stay identical wherever software version status is surfaced, whether aggregated across a fleet or shown for an individual device.
