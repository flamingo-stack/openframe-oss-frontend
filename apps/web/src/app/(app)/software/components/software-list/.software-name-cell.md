# SoftwareNameCell

A table cell component that renders a software item's name and publisher, with built-in support for loading-skeleton states driven by a loading scope.

## Key Components

- **`SoftwareNameCell`** — React client component that displays a software's `name` as the primary line and its `publisher` as a secondary, muted subtitle beneath it. Both fields are truncated to prevent layout overflow.
- **`softwareNameCellFragment`** — GraphQL fragment (`softwareNameCell_software`) declared on the `Software` type, fetching `name` and `publisher`.
- Relies on `useLoadingScope` from `@flamingo-stack/openframe-frontend-core/components/ui` to detect whether the row is still loading. When in a loading scope, the fragment read is skipped (`null` passed to `useFragment`) and the cell renders empty placeholder bars instead of real data, allowing parent skeleton/loading UIs to take over.

## Usage Example

```typescript
import { SoftwareNameCell } from './software-name-cell';
import type { softwareNameCell_software$key } from '@/__generated__/softwareNameCell_software.graphql';

function SoftwareRow({ software }: { software: softwareNameCell_software$key }) {
  return (
    <tr>
      <td>
        <SoftwareNameCell software={software} />
      </td>
    </tr>
  );
}
```

The parent query must spread the fragment to supply the correct `software` key:

```typescript
graphql`
  query SoftwareTableQuery {
    software {
      edges {
        node {
          ...softwareNameCell_software
        }
      }
    }
  }
`;
```

When rendered inside a loading scope (e.g., via a wrapping skeleton provider), the component automatically displays placeholder bars for both the name and publisher lines instead of attempting to read fragment data.
