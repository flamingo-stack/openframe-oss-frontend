# software-list-view.tsx

Client-side React component that renders the top-level Software inventory page, displaying one aggregated row per software title across the entire fleet. It serves as the reference implementation for all `Software`-node list views, including the per-device Software tab, which reuses the same frame and table pattern over its own data connection.

## Key Components

- **`SoftwareListViewProps`** — Interface defining the component's props:
  - `title`: Page title (e.g., "All Software")
  - `emptyTitle` / `emptyDescription`: Messaging shown when the list has no results
  - `loading`: Optional flag indicating the frame should render before data is fetched
- **`SoftwareListView`** — Main exported component that composes:
  - `PageLayout` for page title and structure
  - `SoftwareListFrame` for search/filter UI and loading state
  - `SoftwareListTable` for rendering the actual software rows

## Usage Example

```typescript
import { SoftwareListView } from './software-list-view';

function AllSoftwarePage() {
  return (
    <SoftwareListView
      title="All Software"
      emptyTitle="No software found"
      emptyDescription="No software titles match your current search or filters."
      loading={false}
    />
  );
}
```

## Notes

- Page-level padding is intentionally **not** applied inside this component. It is handled by `SoftwarePageShell`, positioned around the error boundary, so that if a data query throws, the page title remains correctly indented.
- `SoftwareListFrame` uses a render-prop pattern (`children: list => ...`) to pass fetched list data down into `SoftwareListTable`, keeping data-fetching concerns separate from presentation.
- This component is marked `'use client'`, indicating it runs in the browser (React Client Component).
