# software-list-table.tsx

Client component that renders the fleet-wide software inventory table — one row per software title aggregated across all devices. It drives server-side search and infinite-scroll pagination via Relay, while delegating row rendering to the shared `SoftwareTable` component also used for per-device inventories.

## Key Components

- **`softwareListTableQuery`** — Root GraphQL query that spreads the paginated fragment with `search`, `first`, and `after` variables.
- **`softwareListTableFragment`** — Refetchable, `@connection`-backed fragment (`softwareListTable_softwares`) exposing `filteredCount`, `edges`, and `pageInfo` for infinite scroll.
- **`SoftwareListTableProps`** — Props interface: `debouncedSearch`, `isPending` (guards against flashing empty state during deferred refetches), `onEmptyChange`, `stickyHeaderOffset`, `emptyTitle`, `emptyDescription`.
- **`SoftwareListTable`** — Public entry point; wraps the reader in a `LoadingSuspense` boundary labeled "Loading software".
- **`SoftwareListTableReader`** — Checks `useLoadingScope()` to short-circuit into a skeleton `SoftwareTable` (no rows) during loading-scope windows, otherwise renders the live query component.
- **`SoftwareListTableQuery`** — Executes `useLazyLoadQuery` (with `store-or-network` policy and a retry key), then `usePaginationFragment` to extract rows and an `fetchNextPage` loader, passing everything into `SoftwareTable`.

## Usage Example

```typescript
import { SoftwareListTable } from './software-list-table';

function SoftwareInventoryPage() {
  const [search, setSearch] = useState('');
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <SoftwareListTable
      debouncedSearch={search}
      isPending={false}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
      emptyTitle="No software found"
      emptyDescription="No software matches your current search."
    />
  );
}
```

The component handles its own Suspense boundary and loading-scope fallback internally, so consumers only need to supply search state and empty-state copy.
