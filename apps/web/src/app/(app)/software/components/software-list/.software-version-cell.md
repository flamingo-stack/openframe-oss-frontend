Renders the "Current Version" table cell for a software inventory row, displaying the latest installed version across the fleet, an "Outdated" tag when applicable, and a count of older versions still in use.

## Key Components

- **`SoftwareVersionCell`** — Client component that reads the `softwareVersionCell_software` GraphQL fragment and renders:
  - `ValueText` showing `currentVersion` (handles loading/empty states automatically)
  - A `Tag` labeled "Outdated" when `versionStatus === SoftwareVersionStatus.OUTDATED`
  - A secondary `TruncateText` line showing `+N older versions` when `olderVersionsCount > 0`
- **`softwareVersionCellFragment`** — Relay GraphQL fragment declaring the required fields (`currentVersion`, `versionStatus`, `olderVersionsCount`) on the `Software` type.

## Usage Example

```typescript
import { SoftwareVersionCell } from './software-version-cell';
import { graphql, useFragment } from 'react-relay';

// Typically used as a cell renderer in a software inventory table,
// where each row provides its own fragment reference.
function SoftwareTableRow({ softwareRef }: { softwareRef: any }) {
  return (
    <td>
      <SoftwareVersionCell software={softwareRef} />
    </td>
  );
}
```

The component relies on `useLoadingScope()` from `@flamingo-stack/openframe-frontend-core/components/ui` to detect placeholder/loading rows — in that case it passes `null` to `useFragment`, and `ValueText` renders its own loading bar instead of throwing on a missing fragment key.
