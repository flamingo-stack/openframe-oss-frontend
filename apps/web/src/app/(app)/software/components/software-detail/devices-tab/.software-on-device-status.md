Defines presentation metadata and filter options for a device's per-software lifecycle status, used to render status labels and tags in the software-on-device data table.

## Key Components

- **`SoftwareOnDeviceStatusPresentation`** — interface describing how a status renders: a `label` string (shown in the filter funnel and, capitalized, on the chip) and a `tag` (chip variant plus optional `inFlight` flag, or `null` when no chip should be shown).
- **`SOFTWARE_ON_DEVICE_STATUS`** — a `Record` mapping every `SoftwareOnDeviceStatus` enum value to its presentation. `UP_TO_DATE` has no tag (healthy rows don't need a chip); `OUTDATED` reuses the shared `OUTDATED_TAG` styling; `UNINSTALLING` is the only in-flight state, shown with a neutral outline and loader glyph rather than a severity color.
- **`SOFTWARE_ON_DEVICE_STATUS_OPTIONS`** — a fixed array of `DataTableFilterOption` entries for the Status filter funnel, limited to `UP_TO_DATE` and `OUTDATED` only. This is intentionally static rather than derived from a facet query, since computing per-option counts would require an expensive additional host scan per title on the backend.

## Usage Example

```typescript
import { SOFTWARE_ON_DEVICE_STATUS, SOFTWARE_ON_DEVICE_STATUS_OPTIONS } from './software-on-device-status';
import { SoftwareOnDeviceStatus } from '@/generated/schema-enums';

// Render a status chip for a device row
const presentation = SOFTWARE_ON_DEVICE_STATUS[SoftwareOnDeviceStatus.OUTDATED];
// presentation.label === 'Outdated' (or OUTDATED_TAG.label)
// presentation.tag === { variant: 'error' }

// Populate the Status filter dropdown in a data table
<DataTableFilter options={SOFTWARE_ON_DEVICE_STATUS_OPTIONS} />
```

**Note:** When the backend adds support for reporting `SCHEDULED_UPDATE`, `UNINSTALLING`, or `SCHEDULED_UNINSTALL` as queryable facets, extend `SOFTWARE_ON_DEVICE_STATUS_OPTIONS` to include them.
