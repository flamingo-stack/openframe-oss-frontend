Defines a fallback display title used on the software detail page before the actual record name is resolved, or when no matching record exists for a given ID.

## Key Components

- `SOFTWARE_DETAIL_TITLE` — A constant string (`'Software'`) exported as the default/placeholder title for the software detail view.

## Usage Example

```typescript
import { SOFTWARE_DETAIL_TITLE } from './software-detail-title';

function getPageTitle(record?: { name: string }): string {
  return record?.name ?? SOFTWARE_DETAIL_TITLE;
}

// While loading, or if the record doesn't exist:
const title = getPageTitle(undefined); // 'Software'

// Once the record resolves:
const resolvedTitle = getPageTitle({ name: 'Adobe Photoshop' }); // 'Adobe Photoshop'
```

This pattern ensures the detail page always has a sensible title to render immediately, avoiding blank or `undefined` headings during data fetches or for invalid/missing record IDs.
