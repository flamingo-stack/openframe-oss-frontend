# software-device-cell.tsx

Renders the DEVICE column cell for a software table row, displaying the device type icon, device name with status tag, and the owning customer/organization name beneath it. Supports loading-scope skeleton rendering while GraphQL data resolves.

## Key Components

- **`softwareDeviceCellFragment`** — GraphQL fragment on `Machine` fetching `nickname`, `displayName`, `hostname`, `status`, `type`, and `organization.name`.
- **`SoftwareDeviceCell`** — Component that:
  - Uses `useLoadingScope()` to detect whether the row is still loading (in which case the fragment key is skipped and child components render skeleton bars).
  - Resolves the device's display name via `getDeviceName`.
  - Resolves a status tag config via `getDeviceStatusConfig` and renders it with `Tag`.
  - Renders the `DeviceTypeTile` icon based on device `type`.
  - Shows the organization name underneath via `TruncateText`, only when loading or a customer name exists.

## Usage Example

```typescript
import { SoftwareDeviceCell } from '@/app/components/software/software-device-cell';
import type { softwareDeviceCell_machine$key } from '@/__generated__/softwareDeviceCell_machine.graphql';

function SoftwareTableRow({ machine }: { machine: softwareDeviceCell_machine$key }) {
  return (
    <tr>
      <td>
        <SoftwareDeviceCell machine={machine} />
      </td>
      {/* other columns */}
    </tr>
  );
}
```

This component is designed to be used within a Relay-powered table where each row's `machine` prop is a fragment reference. It gracefully handles loading states using `useLoadingScope`, allowing parent list/table components to render skeleton rows without conditionally mounting this cell.
