## SoftwareDetailSummary

Renders a compact summary card displaying a software item's publisher and latest version, powered by a Relay GraphQL fragment. Designed to gracefully handle a loading state by rendering `null`-valued fields as placeholder bars in the underlying `SummaryCard`.

## Key Components

- **`softwareDetailSummaryFragment`** — GraphQL fragment (`softwareDetailSummary_software` on `Software`) selecting the `publisher` and `latestVersion` fields.
- **`SoftwareDetailSummary`** — React component that resolves the fragment via `useFragment` and passes the resulting data into a shared `SummaryCard` component, laid out in a 2-column grid.
- Relies on `SOFTWARE_DETAIL_SUMMARY_LABELS` for field labels, keeping display text centralized and consistent.

## Usage Example

```typescript
import { SoftwareDetailSummary } from './software-detail-summary';
import type { softwareDetailSummary_software$key } from '@/__generated__/softwareDetailSummary_software.graphql';

function SoftwareDetailPage({ softwareRef }: { softwareRef: softwareDetailSummary_software$key | null }) {
  return (
    <div className="software-detail">
      <SoftwareDetailSummary software={softwareRef} />
    </div>
  );
}
```

The `software` prop accepts a Relay fragment reference (`$key`) fetched from a parent query, or `null` while data is still loading. When `null`, `useFragment` returns `undefined` for `data`, causing the `SummaryCard` to render placeholder bars instead of actual values—providing a seamless loading experience without additional conditional logic.
