## Purpose

`SoftwareDevicesTab` renders the "Devices" tab within a Software detail view, listing every device that has a given software title installed along with its version and lifecycle status. It owns the tab's URL-synced state (search, status filter, sort) and composes the sticky search toolbar with the suspended device rows table.

## Key Components

- **`SoftwareDevicesTab`** — Memoized React component (default export pattern via named export), accepts `softwareId` and an optional `loading` flag.
- **URL state management** — Uses `useApiParams` to sync `deviceSearch`, `deviceStatus`, `deviceSortBy`, and `deviceSortDir` with query parameters.
- **`useSearchParam`** — Manages debounced search input bound to the `deviceSearch` param.
- **`useServerSort`** — Handles server-driven sorting constrained to `SOFTWARE_DEVICES_SORTABLE_COLUMN_IDS`.
- **`useDeferredQuery`** — Defers filter/search variables to avoid redundant refetches while a query is pending, exposing `isPending`.
- **`useStickyToolbar`** — Provides sticky positioning refs/styles for the search toolbar and table header offset.
- **Rendering** — Conditionally shows `SearchToolbar` (hidden when results are empty) and wraps `SoftwareDevicesTable` in `LoadingWhen` to gate fetching until the parent `loading` flag resolves.

## Usage Example

```typescript
import { SoftwareDevicesTab } from '@/app/components/software/devices/software-devices-tab';

function SoftwareDetailPage({ softwareId, moduleReady }: { softwareId: string; moduleReady: boolean }) {
  return (
    <div>
      {/* Other tabs/header */}
      <SoftwareDevicesTab softwareId={softwareId} loading={!moduleReady} />
    </div>
  );
}
```

The component requires no additional props beyond `softwareId`; all search, filter, and sort state is managed internally via URL query parameters, making the tab's state shareable and bookmarkable.
