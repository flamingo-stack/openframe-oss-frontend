# software-vulnerabilities-columns.ts

Defines the static column layout and pagination/sort configuration for the Software → Vulnerabilities table. This is a data-only module (no imports beyond types/constants, no JSX) consumed by the live table and its loading skeleton — see `table-column-layout.ts` for the rationale behind this pattern.

## Key Components

- **`SOFTWARE_VULNERABILITY_COLUMNS`** — Typed constant (`Record<string, TableSkeletonColumn>`) describing each column in the vulnerabilities table:
  - `cveId` — CVE identifier, flexible width.
  - `affectedVersion` — Affected software version, hidden below the `md` breakpoint.
  - `discoveredAt` — Date Fleet first matched the CVE against the title (not CVE publication date); sortable, hidden below `lg`.
  - `open` — Fixed-width action/indicator column, right-aligned.
- **`SOFTWARE_VULNERABILITIES_SORTABLE_COLUMN_IDS`** — Readonly list of backend sort field IDs this list supports (currently only `discoveredAt`). Any other sort field passed via the URL is ignored.
- **`SOFTWARE_VULNERABILITIES_PAGE_SIZE`** — Re-exported page size constant, sourced from the shared `FLEET_LIST_PAGE_SIZE`.

## Usage Example

```typescript
import {
  SOFTWARE_VULNERABILITY_COLUMNS,
  SOFTWARE_VULNERABILITIES_SORTABLE_COLUMN_IDS,
  SOFTWARE_VULNERABILITIES_PAGE_SIZE,
} from './software-vulnerabilities-columns';

// Render table skeleton / headers from shared column config
const columns = Object.values(SOFTWARE_VULNERABILITY_COLUMNS);

// Validate a sort param from the URL before querying the backend
function isSortable(field: string): boolean {
  return SOFTWARE_VULNERABILITIES_SORTABLE_COLUMN_IDS.includes(field);
}

// Fetch vulnerabilities with the shared page size
fetchVulnerabilities({ pageSize: SOFTWARE_VULNERABILITIES_PAGE_SIZE });
```
