# software-devices-columns.ts

Defines the column layout configuration and pagination settings for the Software → Devices data table, used to drive the skeleton/loading state and live table rendering consistently.

## Key Components

- **`SOFTWARE_DEVICE_COLUMNS`** — A `satisfies Record<string, TableSkeletonColumn>` object defining three columns:
  - `device` — flexible-width column showing the device name
  - `softwareVersion` — flexible-width, sortable column showing the software version (also drives the status filter chip in the UI)
  - `open` — fixed-width (`w-12`) action column, right-aligned, hidden at the `md` breakpoint
- **`SOFTWARE_DEVICES_SORTABLE_COLUMN_IDS`** — A readonly array containing the single column id (`softwareVersion`) permitted as a `SortInput.field` value; any other value from the URL falls back to default backend ordering.
- **`SOFTWARE_DEVICES_PAGE_SIZE`** — Re-exports `FLEET_LIST_PAGE_SIZE` as the page size for this list.

This module is intentionally data-only — no imports beyond types/constants and no JSX — so it can be shared between the table skeleton and the live table without pulling in rendering logic.

## Usage Example

```typescript
import {
  SOFTWARE_DEVICE_COLUMNS,
  SOFTWARE_DEVICES_SORTABLE_COLUMN_IDS,
  SOFTWARE_DEVICES_PAGE_SIZE,
} from './software-devices-columns';

// Render skeleton columns
Object.values(SOFTWARE_DEVICE_COLUMNS).forEach((col) => {
  console.log(col.id, col.header, col.width);
});

// Validate a sort field from the URL before passing to SortInput
function resolveSortField(requested: string | null): string | null {
  return requested && SOFTWARE_DEVICES_SORTABLE_COLUMN_IDS.includes(requested)
    ? requested
    : null;
}

// Use consistent page size for fetching
const pageSize = SOFTWARE_DEVICES_PAGE_SIZE;
```
