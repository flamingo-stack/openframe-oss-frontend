Defines the static label text used by the software detail summary card component, ensuring the real card and its loading skeleton render identical, consistently ordered labels.

## Key Components

- **`SOFTWARE_DETAIL_SUMMARY_LABELS`** — A `const`-asserted object mapping summary field keys (`publisher`, `latestVersion`) to their display labels (`'Publisher'`, `'Latest Version'`). The `as const` assertion makes all properties readonly and narrows their types to literal strings, enabling strict type-checked access to label keys.

## Usage Example

```typescript
import { SOFTWARE_DETAIL_SUMMARY_LABELS } from './software-detail-summary-labels';

// In the summary card component
function renderSummaryField(key: keyof typeof SOFTWARE_DETAIL_SUMMARY_LABELS, value: string) {
  return `${SOFTWARE_DETAIL_SUMMARY_LABELS[key]}: ${value}`;
}

renderSummaryField('publisher', 'Acme Corp');
// => "Publisher: Acme Corp"

// Iterating labels for consistent ordering in both the card and skeleton
Object.entries(SOFTWARE_DETAIL_SUMMARY_LABELS).forEach(([key, label]) => {
  console.log(`${key} -> ${label}`);
});
```

This centralization prevents label drift between the actual summary card and its skeleton placeholder, since both reference the same constant.
