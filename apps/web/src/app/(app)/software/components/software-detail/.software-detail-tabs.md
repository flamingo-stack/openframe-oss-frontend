Renders the tabbed interface for a software detail view, delegating content rendering to tab-specific body components based on the currently active tab.

## Key Components

- **`SoftwareDetailTabs`** — React component that renders a `TabNavigation` shell (with URL-synced tab state) and dynamically resolves/renders the body component for the active tab via `softwareTabBody`.
- **Props:**
  - `softwareId: string` — identifier passed to each tab body so it can fetch its own data.
  - `loading?: boolean` — defaults to `false`; signals to tab bodies that upstream data (e.g., a feature/module flag) hasn't resolved yet, so they should defer fetching.

## Usage Example

```typescript
import { SoftwareDetailTabs } from './software-detail-tabs';

export function SoftwareDetailPage({ softwareId }: { softwareId: string }) {
  return (
    <div>
      <h1>Software Details</h1>
      <SoftwareDetailTabs softwareId={softwareId} loading={false} />
    </div>
  );
}
```

Each tab body component receives `softwareId` and `loading` as props, and is responsible for fetching and displaying its own data (e.g., overview, versions, dependencies) once `loading` is `false`. Tab configuration, the default tab, and the mapping from tab key to body component are defined in `./software-detail-tab-items`.
