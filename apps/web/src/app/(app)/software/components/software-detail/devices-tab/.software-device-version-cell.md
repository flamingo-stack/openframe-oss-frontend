# software-device-version-cell.tsx

Renders the "SOFTWARE VERSION" table cell for a device-installed software row, displaying the version string installed on that specific device alongside a lifecycle status chip (e.g., supported, outdated, end-of-life).

## Key Components

- **`SoftwareDeviceVersionCell`** — React client component that reads a GraphQL fragment for a `SoftwareOnDevice` record and renders the version value plus its status tag.
- **`softwareDeviceVersionCellFragment`** — Relay GraphQL fragment declaring the `softwareVersion` and `status` fields needed on `SoftwareOnDevice`.

The component integrates with:
- `useLoadingScope` (from `@flamingo-stack/openframe-frontend-core`) to detect skeleton/loading rows and skip fragment reading.
- `ValueText` (shared component) to render the version text, automatically showing a loading bar when the value is `undefined`/`null`.
- `SoftwareOnDeviceStatusTag` to render the lifecycle status chip.

## Usage Example

```typescript
import { SoftwareDeviceVersionCell } from './software-device-version-cell';

function SoftwareRow({ softwareOnDevice }: { softwareOnDevice: any }) {
  return (
    <tr>
      <td>
        <SoftwareDeviceVersionCell softwareOnDevice={softwareOnDevice} />
      </td>
    </tr>
  );
}
```

The `softwareOnDevice` prop must be a Relay fragment reference (`softwareDeviceVersionCell_softwareOnDevice$key`) spread from a parent query or fragment that includes the `softwareDeviceVersionCell_softwareOnDevice` fragment on the `SoftwareOnDevice` type. When rendered inside a loading scope (e.g., a skeleton table row), the component gracefully renders placeholders via `ValueText` and `SoftwareOnDeviceStatusTag` instead of attempting to read incomplete fragment data.
