# software-vulnerabilities-tab.tsx

Client-side React component implementing the "Vulnerabilities" sub-tab for a software detail view, displaying CVEs matched to a given software title. It owns the URL-synced search/sort state for this tab and delegates row rendering/data-fetching to the underlying table component.

## Key Components

- **`SoftwareVulnerabilitiesTab`** — Memoized component accepting `softwareId` (string) and optional `loading` (boolean) props. Responsibilities:
  - Manages URL query params (`cveSearch`, `cveSortBy`, `cveSortDir`) via `useApiParams`.
  - Debounces search input via `useSearchParam` with `FLEET_SEARCH_DEBOUNCE_MS`.
  - Tracks sortable columns via `useServerSort`, restricted to `SOFTWARE_VULNERABILITIES_SORTABLE_COLUMN_IDS`.
  - Defers search/sort changes together via `useDeferredQuery` so query updates stay in lockstep, exposing a single `isPending` flag.
  - Manages sticky toolbar positioning via `useStickyToolbar`.
  - Hides the `SearchToolbar` when the result set is empty (`isEmpty` state, set by the table via `onEmptyChange`).
  - Wraps the table in `LoadingWhen` so that while the parent `loading` flag is unresolved, the table renders its own locked/loading state and does not fetch data.

## Usage Example

```typescript
import { SoftwareVulnerabilitiesTab } from '@/app/components/software/tabs/software-vulnerabilities-tab';

function SoftwareDetailPage({ softwareId }: { softwareId: string }) {
  const { data: moduleFlag, isLoading } = useSoftwareModuleFlag(softwareId);

  return (
    <SoftwareVulnerabilitiesTab
      softwareId={softwareId}
      loading={isLoading || !moduleFlag}
    />
  );
}
```

**Notes:**
- `softwareId` is required and identifies which software title's CVEs to display.
- `loading` should reflect any upstream gating (e.g., feature flags) before the tab is allowed to fetch; while `true`, the search toolbar renders disabled and the table suspends fetching.
- Actual row data and empty-state detection are handled inside `SoftwareVulnerabilitiesTable`, which this component only wires up via props (`debouncedSearch`, `sort`, `sortState`, `onSortChange`, `isPending`, `onEmptyChange`).
