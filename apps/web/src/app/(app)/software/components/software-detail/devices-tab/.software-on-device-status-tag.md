Renders a status chip next to a device's installed software version, visually indicating states like "updating" or "error" while rendering nothing for neutral states or unrecognized values.

## Key Components

- **`SoftwareOnDeviceStatusTag`** — Client component that accepts a `status` string (or `null`/`undefined`) and renders a `Tag` component with an appropriate label, variant, and optional loading icon.
- Relies on `presentationFor` (from `@/lib/exhaustive-map`) combined with the `SOFTWARE_ON_DEVICE_STATUS` map to resolve the status string into a presentation object.
- Returns `null` when there's no `tag` presentation defined — covering both "no attention needed" states and unknown/future values (e.g., Relay's `'%future added value'` for GraphQL enum forward-compatibility).

## Usage Example

```typescript
import { SoftwareOnDeviceStatusTag } from './software-on-device-status-tag';

function DeviceSoftwareRow({ software }: { software: { name: string; status: string | null } }) {
  return (
    <div className="flex items-center gap-2">
      <span>{software.name}</span>
      <SoftwareOnDeviceStatusTag status={software.status} />
    </div>
  );
}
```

In this example, if `software.status` maps to an "in-flight" state (e.g., installing or updating), the tag renders with a `DotsLoaderIcon`. If the status requires no visual callout or is an unrecognized value, the component renders nothing, keeping the row clean.
