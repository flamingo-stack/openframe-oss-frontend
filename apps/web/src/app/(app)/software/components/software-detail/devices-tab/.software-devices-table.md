## software-devices-table.tsx

Renders the "Devices" sub-table on a Software detail page, listing every device that has the given software installed, along with its per-device installed version and status (e.g. OUTDATED, SCHEDULED_UPDATE). Uses Relay pagination to fetch rows incrementally and supports search, backend filtering, sorting, and a status funnel driven by a fixed set of backend-reported states.

## Key Components

- **`SoftwareDevicesTable`** — Public entry component; wraps the data-fetching reader in a `LoadingSuspense` boundary with a "Loading devices" label.
- **`SoftwareDevicesTableReader`** — Chooses between rendering placeholder loading rows (inside a loading scope) or triggering the live Relay query.
- **`SoftwareDevicesTableQuery`** — Executes `softwareDevicesTableQuery` via `useLazyLoadQuery`, then paginates through the `softwareDevicesTable_query` fragment with `usePaginationFragment`.
- **`SoftwareDevicesTableRows`** — Presentational table renderer; builds the `useDataTable` instance, handles the status column filter, empty states, and infinite scroll footer.
- **`buildColumns()`** — Defines the three columns: Device (via `SoftwareDeviceCell`), Software Version/Status (via `SoftwareDeviceVersionCell`, filterable by status), and an Open-row action button.
- **`deviceHref(row)`** — Computes the link target for a row (device details page), or `null` for placeholder/agentless rows.
- **`getRowId(row, index)`** — Row-key workaround for duplicate device rows returned by the backend (test-env issue); combines device id with row index.
- **GraphQL definitions**: `softwareDevicesTableQuery` (root query) and `softwareDevicesTableFragment` (`@refetchable` connection fragment, `softwareDevicesTablePaginationQuery`).

## Usage Example

```typescript
import { SoftwareDevicesTable } from './software-devices-table';

function SoftwareDetailDevicesTab() {
  const [statusFilter, setStatusFilter] = useState<string[]>([]);
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <SoftwareDevicesTable
      softwareId="software-123"
      backendFilters={null}
      debouncedSearch=""
      sort={null}
      sortState={null}
      onSortChange={() => {}}
      statusFilter={statusFilter}
      onStatusFilterChange={setStatusFilter}
      isPending={false}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
    />
  );
}
```

The parent component is expected to manage search debouncing, sort state, and the status funnel values, passing them down as props while reacting to `onEmptyChange` to conditionally hide tab chrome when no devices exist.
