Renders the header/title section for a software detail page, displaying the software's name (or a fallback title) along with a back-navigation link to the software list.

## Key Components

- **`softwareDetailHeaderFragment`** — GraphQL fragment declaration that retrieves the `name` field from a `Software` record.
- **`SoftwareDetailHeader`** — React component that accepts a Relay fragment reference (`software`) and renders a `DetailTitle` component. It resolves the fragment data via `useFragment`, falling back to `SOFTWARE_DETAIL_TITLE` when the software record is `null` or `undefined` (e.g., for an unknown ID), while always rendering the back button pointing to `routes.software.list`.

## Usage Example

```typescript
import { SoftwareDetailHeader } from './software-detail-header';
import { useLazyLoadQuery, graphql } from 'react-relay';

function SoftwareDetailPage({ softwareId }: { softwareId: string }) {
  const data = useLazyLoadQuery(
    graphql`
      query SoftwareDetailPageQuery($id: ID!) {
        software(id: $id) {
          ...softwareDetailHeader_software
        }
      }
    `,
    { id: softwareId }
  );

  return (
    <div>
      <SoftwareDetailHeader software={data.software} />
      {/* rest of detail page content */}
    </div>
  );
}
```

This component is typically used at the top of a software detail page, ensuring consistent title rendering and back navigation regardless of whether the queried software record exists.
