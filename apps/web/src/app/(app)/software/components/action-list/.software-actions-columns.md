Defines the static column layout configuration for the Software Actions table, along with its default page size constant. This module is purely declarative data consumed by the live table rendering logic and shared skeleton loader.

## Key Components

- **`SOFTWARE_ACTION_COLUMNS`** — A typed constant object (`satisfies Record<string, TableSkeletonColumn>`) describing each column in the Software Actions list:
  - `software` — primary flexible column showing the software name.
  - `action` — the action type column; hidden below the `md` breakpoint.
  - `engine` — the engine column; hidden below the `lg` breakpoint.
  - `status` — status indicator column.
  - `processedDevices` — fixed-width column (responsive at `content-md`) showing device counts.
  - `open` — small, right-aligned trailing column (e.g., for a detail/expand action).
- **`SOFTWARE_ACTIONS_PAGE_SIZE`** — Exported constant (`20`) defining the default number of rows per page for this table.

## Usage Example

```typescript
import { SOFTWARE_ACTION_COLUMNS, SOFTWARE_ACTIONS_PAGE_SIZE } from './software-actions-columns';
import { TableSkeleton } from '@/app/components/shared/table-column-layout';

function SoftwareActionsTable() {
  return (
    <TableSkeleton
      columns={SOFTWARE_ACTION_COLUMNS}
      pageSize={SOFTWARE_ACTIONS_PAGE_SIZE}
    />
  );
}
```

Each column's `hideAt` property drives responsive visibility, while `width` controls sizing/flex behavior in the shared table layout component. See `table-column-layout.ts` for the `TableSkeletonColumn` type definition and rendering logic, and `softwareActionFilters` for the filters tied to the `action`, `engine`, and `status` columns.
