# use-software-action-filters.ts

A React hook that fetches and shapes the filter facets (Action, Engine, Status) for the Software Actions list, converting raw GraphQL facet data into `DataTableFilterOption` arrays ready for use in data-table filter dropdowns.

This hook relies on Relay's `useLazyLoadQuery` and therefore **suspends** — it must be rendered within the same Suspense boundary as the list component it filters, so loading/retry states stay synchronized.

## Key Components

- **`softwareActionFiltersQuery`** — GraphQL query fetching `softwareActionFilters` (actions, engines, statuses), each with `value`, `label`, and `count`. Intentionally queried without the user's active filter selections, since facet counts are list-wide totals, not narrowed-by-self counts.
- **`SoftwareActionFilterOptions`** — Interface describing the shape returned by the hook: `actions`, `engines`, and `statuses`, each an array of `DataTableFilterOption`.
- **`toOptions(facet, labelFor)`** — Internal helper that filters out zero-count facet values (never offering an option that would empty the list) and maps remaining values to `DataTableFilterOption`, preferring the app's own label and falling back to the server-provided label.
- **`useSoftwareActionFilters()`** — The exported hook. Fetches filter facets via Relay (using `useRetryKey` for retry-driven refetches) and maps each facet to display-ready options:
  - `actions` labeled via `softwareActionCopy(value)?.verb`
  - `engines` labeled via `presentationFor(PACKAGE_MANAGER_LABEL, value)`
  - `statuses` labeled via `softwareActionStatusLabel`

## Usage Example

```typescript
import { Suspense } from 'react';
import { useSoftwareActionFilters } from './use-software-action-filters';

function SoftwareActionFiltersBar() {
  const { actions, engines, statuses } = useSoftwareActionFilters();

  return (
    <div>
      <FilterDropdown label="Action" options={actions} />
      <FilterDropdown label="Engine" options={engines} />
      <FilterDropdown label="Status" options={statuses} />
    </div>
  );
}

function SoftwareActionsPage() {
  return (
    <Suspense fallback={<FiltersSkeleton />}>
      <SoftwareActionFiltersBar />
      {/* List component must share this same Suspense boundary */}
    </Suspense>
  );
}
```
