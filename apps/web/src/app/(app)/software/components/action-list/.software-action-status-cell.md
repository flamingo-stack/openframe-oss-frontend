# software-action-status-cell.tsx

A React/Relay table cell component that renders the status of a software action run, displaying a status tag and, when applicable, the scheduled execution time.

## Key Components

- **`softwareActionStatusCellFragment`** — GraphQL fragment declaring the `status` and `scheduledAt` fields required from a `SoftwareActionRun` node.
- **`SoftwareActionStatusCell`** — Component that renders the STATUS column for a software action row. It:
  - Resolves the `action` fragment reference via `useFragment`, skipping the read entirely (passing `null`) when inside a loading scope (`useLoadingScope()`), allowing the inner `SoftwareActionStatusTag` to render its own skeleton state.
  - Always renders a `SoftwareActionStatusTag` with the current status (or an empty string while loading).
  - Conditionally renders a secondary, truncated timestamp (via `formatDateTime`) when the status is `SoftwareActionStatus.SCHEDULED` and a `scheduledAt` value exists.

## Usage Example

```typescript
import { graphql, useFragment } from 'react-relay';
import { SoftwareActionStatusCell } from './software-action-status-cell';

// Within a table row component, after fetching rows via a parent query:
function SoftwareActionRow({ actionRef }: { actionRef: softwareActionStatusCell_action$key }) {
  return (
    <tr>
      <td>
        <SoftwareActionStatusCell action={actionRef} />
      </td>
    </tr>
  );
}
```

The component expects to be used within a Relay fragment container pattern, where `action` is a fragment reference spread from a parent query containing `...softwareActionStatusCell_action` on a `SoftwareActionRun` type. It integrates with `useLoadingScope` to support skeleton-loading table rows without requiring conditional fragment reads at the call site.
