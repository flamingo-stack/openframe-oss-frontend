# SoftwareActionEngineCell

Renders the **ENGINE** column in a software action table, displaying the package manager (e.g., apt, brew, choco) used to execute a given software action run.

## Key Components

- **`SoftwareActionEngineCell`** — React component that renders the engine/package manager label for a software action row.
- **`softwareActionEngineCellFragment`** — GraphQL fragment (`softwareActionEngineCell_action`) that fetches the `engine` field from a `SoftwareActionRun`.

## Behavior

- Uses `useLoadingScope()` to detect whether the row is part of a loading skeleton state. If so, the fragment is not read (`null` is passed to `useFragment`), and the cell renders an empty state suitable for a loading placeholder.
- When data is available, `packageManagerLabel(data.engine)` converts the raw `engine` value into a human-readable label.
- Wraps the output in `TruncateText` to gracefully handle overflow in constrained table cells.

## Usage Example

```typescript
import { SoftwareActionEngineCell } from './software-action-engine-cell';
import type { softwareActionEngineCell_action$key } from '@/__generated__/softwareActionEngineCell_action.graphql';

function ActionTableRow({ actionRef }: { actionRef: softwareActionEngineCell_action$key }) {
  return (
    <tr>
      <td>
        <SoftwareActionEngineCell action={actionRef} />
      </td>
    </tr>
  );
}
```

This component is typically used as a cell renderer within a Relay-powered data table that lists software action runs, relying on the parent query to spread the `softwareActionEngineCell_action` fragment onto each row's data.
