## software-action-processed-cell.tsx

Renders the "PROCESSED DEVICES" table cell for a software action run, displaying the ratio of devices that have reported back versus the total targeted devices.

## Key Components

- **`SoftwareActionProcessedCell`** — React component that reads a GraphQL fragment to show responded/total device counts for a given software action run. Displays a skeleton loader while the row is in a loading scope.
- **`softwareActionProcessedCellFragment`** — GraphQL fragment (`softwareActionProcessedCell_action`) declared on `SoftwareActionRun`, selecting `respondedMachineCount` and `totalMachineCount`.

## Usage Example

```typescript
import { SoftwareActionProcessedCell } from './software-action-processed-cell';
import type { softwareActionProcessedCell_action$key } from '@/__generated__/softwareActionProcessedCell_action.graphql';

function SoftwareActionRow({ actionRef }: { actionRef: softwareActionProcessedCell_action$key }) {
  return (
    <tr>
      <td>
        <SoftwareActionProcessedCell action={actionRef} />
      </td>
    </tr>
  );
}
```

The component relies on `useLoadingScope` to detect placeholder/loading rows (e.g., during pagination or optimistic updates), rendering a `TextLineSkeleton` instead of attempting to read an unavailable fragment. Once data resolves, it delegates formatting of the "responded / total" count to the shared `ProcessedDevicesCount` component.
