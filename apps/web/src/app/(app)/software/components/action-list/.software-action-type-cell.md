# software-action-type-cell.tsx

Renders the "ACTION" column cell in a software action runs table, displaying whether an action was an install or update operation using a human-readable verb label.

## Key Components

- **`SoftwareActionTypeCell`** — React component that accepts a GraphQL fragment reference (`action`) and renders the action type (e.g., "Install", "Update") as truncated text. It integrates with a loading scope context to render an empty/loading state while the row's data is still being fetched.
- **`softwareActionTypeCellFragment`** — GraphQL fragment (`softwareActionTypeCell_action` on `SoftwareActionRun`) that selects the `action` field needed by this cell.

## Usage Example

```typescript
import { SoftwareActionTypeCell } from './software-action-type-cell';
import type { softwareActionTypeCell_action$key } from '@/__generated__/softwareActionTypeCell_action.graphql';

function ActionRunRow({ actionRef }: { actionRef: softwareActionTypeCell_action$key }) {
  return (
    <tr>
      <td>
        <SoftwareActionTypeCell action={actionRef} />
      </td>
    </tr>
  );
}
```

The component relies on `useLoadingScope` to detect placeholder/loading rows (common in paginated or suspense-based tables) and skips calling `useFragment` on null data in that case. When real data is available, it uses `softwareActionCopy` to map the raw `action` enum value to a localized verb, falling back to the raw value if no mapping exists.
