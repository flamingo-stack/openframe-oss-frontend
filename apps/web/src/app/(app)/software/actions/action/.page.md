This file defines the Next.js page component for viewing details of a single software action/run within the Software Management section.

## Key Components

- **`SoftwareActionDetailsPage`** — Default export; a client-rendered page component that resolves the current action's ID from the route, enforces the software management access gate, and renders the action detail view inside a shared page shell.
- **`useSoftwareManagementGate`** — Hook providing the loading/access state for software management features, used to drive the detail view's loading indicator.
- **`useRequiredIdParam`** — Hook that extracts and validates a required `id` route parameter, redirecting to the provided fallback route (`routes.software.actions`) if missing.
- **`SoftwarePageShell`** — Shared layout wrapper providing a consistent title and error-boundary message for software pages.
- **`SoftwareActionDetailView`** — Renders the actual details/content for the resolved `actionId`.

## Usage Example

This component is automatically wired up by the Next.js App Router based on its file path (e.g., `app/software/actions/[id]/page.tsx`) and requires no manual invocation:

```typescript
// Navigating to an action's detail page triggers this component automatically
import { routes } from '@/lib/routes';

router.push(routes.software.actions.detail(actionId));
```

If the `id` parameter is missing or invalid, `useRequiredIdParam` automatically redirects the user back to the software actions list (`routes.software.actions`), and the component returns `null` to avoid rendering a broken view in the interim.
