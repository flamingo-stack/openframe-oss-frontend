# page.tsx (Software Actions)

Next.js client page component that renders the Software Actions section, displaying available software management actions within a gated, permission-aware shell layout.

## Key Components

- **`SoftwareActionsPage`** — Default-exported page component that composes the actions view inside the shared software page shell.
- **`useSoftwareManagementGate()`** — Hook used to determine access/loading state before rendering actions content, gating the UI until permissions resolve.
- **`SoftwarePageShell`** — Shared layout wrapper providing consistent title, section identity, and error handling across software-related pages.
- **`SoftwareActionsView`** — Renders the actual list/grid of software actions, receiving a `loading` flag tied to the gate's state.
- **`SOFTWARE_SECTIONS.actions.label`** — Centralized section metadata used to keep the page title consistent with navigation/config.

## Usage Example

```typescript
// This is a Next.js route page (e.g., app/software/actions/page.tsx)
// It is rendered automatically by the Next.js App Router when the
// corresponding route is visited; no manual invocation is required.

export default function SoftwareActionsPage() {
  const gate = useSoftwareManagementGate();

  return (
    <SoftwarePageShell
      section="actions"
      title={SOFTWARE_SECTIONS.actions.label}
      errorMessage="Couldn't load software actions."
    >
      <SoftwareActionsView loading={gate === 'loading'} />
    </SoftwarePageShell>
  );
}
```

This component relies on the `'use client'` directive to run in the browser, enabling the `useSoftwareManagementGate` hook to manage client-side loading/permission state. The `SoftwarePageShell` centralizes consistent error messaging and layout, while `SoftwareActionsView` handles the presentation logic for the actual list of software actions once gating resolves.
