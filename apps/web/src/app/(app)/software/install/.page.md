Next.js client page component that renders the software installation UI, gated behind a software management feature check.

## Key Components

- **`InstallSoftwarePage`** — Default-exported page component rendering the install software action flow.
- **`useSoftwareManagementGate`** — Hook that determines feature access/loading state for software management.
- **`SoftwareActionView`** — Shared component that renders the UI for a given `SoftwareAction` (here, `INSTALL`).
- **`SoftwareAction.INSTALL`** — Enum value from the generated schema specifying the install action type.

## Usage Example

This page is automatically routed by Next.js based on its file location (e.g., `app/.../install/page.tsx`) and requires no manual instantiation:

```typescript
// app/software-management/install/page.tsx
'use client';

import { SoftwareAction } from '@/generated/schema-enums';
import { SoftwareActionView } from '../components/action-form/software-action-view';
import { useSoftwareManagementGate } from '../components/shared/use-software-management-gate';

export default function InstallSoftwarePage() {
  const gate = useSoftwareManagementGate();
  return <SoftwareActionView action={SoftwareAction.INSTALL} loading={gate === 'loading'} />;
}
```

The `useSoftwareManagementGate` hook returns a gate status (e.g., `'loading'`, `'allowed'`, `'denied'`), which is translated into a `loading` boolean passed to `SoftwareActionView`. The `action` prop tells the shared view component which software action form/behavior to render, allowing the same component to be reused across install, uninstall, or other software management pages.
