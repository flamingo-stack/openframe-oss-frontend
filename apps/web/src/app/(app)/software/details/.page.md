Next.js client page component that renders the software detail view for a specific software package, identified by a required ID route parameter.

## Key Components

- **`SoftwareDetailsPage`** — Default-exported page component. Orchestrates:
  - `useSoftwareManagementGate()` — Checks whether the software management feature is enabled/ready, returning a gate state (e.g., `'loading'`).
  - `useRequiredIdParam(routes.software.list)` — Extracts the `id` route param; if missing or empty, redirects back to the software list route instead of treating it as a valid-but-missing entity. Returns `null` while redirecting.
  - `SoftwarePageShell` — Shared page layout wrapper providing the title and error-state messaging.
  - `SoftwareDetailView` — Renders the actual software detail content, given the resolved `softwareId` and a `loading` flag derived from the gate state.

## Usage Example

```typescript
// Accessed via a dynamic route, e.g. /software/[id]
// Next.js automatically renders this component when navigating to:
// routes.software.detail(someSoftwareId)

export default function SoftwareDetailsPage() {
  const gate = useSoftwareManagementGate();
  const softwareId = useRequiredIdParam(routes.software.list);

  if (!softwareId) return null; // short-circuits while redirecting to the list

  return (
    <SoftwarePageShell title={SOFTWARE_DETAIL_TITLE} errorMessage="Couldn't load this software.">
      <SoftwareDetailView softwareId={softwareId} loading={gate === 'loading'} />
    </SoftwarePageShell>
  );
}
```

**Note:** The guard `if (!softwareId) return null` intentionally avoids querying the backend with an empty ID (which would surface a misleading "not found" error) when a link is truncated or malformed—redirecting to the software list instead.
