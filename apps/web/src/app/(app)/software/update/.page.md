Next.js page component that renders the software update workflow, gated behind a software management access check.

## Key Components

- **`UpdateSoftwarePage`** (default export) — Client component that renders `SoftwareActionView` configured for the `SoftwareAction.UPDATE` action, displaying a loading state while the access gate resolves.
- **`useSoftwareManagementGate`** — Hook (imported) used to determine whether the current user/context has access to software management features.
- **`SoftwareActionView`** — Shared component (imported) responsible for rendering the action-specific UI (forms, status, etc.) based on the provided `action` and `loading` props.

## Usage Example

This file is a Next.js route page and is rendered automatically by the framework based on its file path (e.g., `app/.../update-software/page.tsx`). It is not typically imported manually, but conceptually functions as:

```typescript
import { SoftwareAction } from '@/generated/schema-enums';
import { SoftwareActionView } from '../components/action-form/software-action-view';
import { useSoftwareManagementGate } from '../components/shared/use-software-management-gate';

export default function UpdateSoftwarePage() {
  const gate = useSoftwareManagementGate();
  return <SoftwareActionView action={SoftwareAction.UPDATE} loading={gate === 'loading'} />;
}
```

The `gate` value controls the `loading` prop passed to `SoftwareActionView`, ensuring the UI reflects an accurate loading state while the software management permission check (`useSoftwareManagementGate`) completes before allowing interaction with the update action.
