Defines Next.js route metadata for the Software section and re-exports the shared route title layout component to maintain consistent page titling across the application.

## Key Components

- **`metadata`** – A `Metadata` object exported for Next.js App Router, setting the page `title` to `"Software"` via the `routeTitle` helper.
- **Default export** – Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, avoiding duplication of layout logic across route segments.

## Usage Example

This file is automatically picked up by Next.js as the layout for its route segment (e.g., `app/software/layout.tsx`). No manual import is needed—Next.js applies it based on file-system routing conventions.

```typescript
// Equivalent manual usage pattern (for reference only)
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';
import RouteTitleLayout from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Software') };

export default RouteTitleLayout;
```

The `routeTitle` utility ensures a consistent title format (e.g., appending a brand suffix) across all route segments, while the shared layout component standardizes how titles are rendered or synced with the browser tab/head metadata.
