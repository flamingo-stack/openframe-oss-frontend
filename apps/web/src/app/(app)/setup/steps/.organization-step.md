# organization-step.tsx

A client-side React component for the onboarding flow's "Set Up Your Organization" step, letting tenants set their name, website, and logo before continuing or skipping ahead.

This step shares its data layer with the settings "Edit Organization" form (`useTenantInfo`/`useUpdateTenantInfo`), so edits made here are reflected everywhere tenant info is displayed. The logo uploads immediately on selection via `useTenantLogoUpload`, consistent with other tenant logo editors in the app. "Continue" is only enabled once the organization has a name plus at least one branding element (logo or website) — otherwise the user must use "Skip this Step" to proceed without branding.

## Key Components

- **`OrganizationStep`** — Main exported component. Props:
  - `onSkip: () => void` — called to persist the step without saving form data.
  - `onSaved: () => void` — called after a successful save, to persist the step.
  - `persisting: boolean` — indicates the step is being persisted after the chosen action (drives loading states on both buttons).

Internally it:
- Seeds local `name`/`website` state and the logo uploader from the fetched `tenantInfo` once it arrives, using an `undefined` sentinel tracker to guard against stale remounts from cache.
- Tracks which `Action` (`'skip'` | `'continue'`) was chosen to drive per-button loading indicators.
- Computes `hasBranding` to gate the "Continue" button.

## Usage Example

```typescript
import { OrganizationStep } from './organization-step';

function OnboardingFlow() {
  const [persisting, setPersisting] = useState(false);

  const persistStep = async () => {
    setPersisting(true);
    await markStepComplete('organization');
    setPersisting(false);
    goToNextStep();
  };

  return (
    <OrganizationStep
      onSkip={persistStep}
      onSaved={persistStep}
      persisting={persisting}
    />
  );
}
```
