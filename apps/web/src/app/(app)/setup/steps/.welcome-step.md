# welcome-step.tsx

Renders the first screen of the setup wizard, prompting the user to either continue in the browser or download the desktop app (with OS/architecture-specific installer links), or simply continue if already running inside the desktop shell.

## Key Components

- **`installerUrl(downloads, os, architecture?)`** — Helper that searches a list of `AppDownload` entries for a binary installer matching the given OS and (optional) architecture, returning its URL or `null` if none is found.
- **`WelcomeStep({ onContinue })`** — The exported component. Behavior branches on environment:
  - **Desktop shell**: shows a single "Continue" button since there's nothing to download.
  - **Web**: shows a "Continue on Web" button plus a `DropdownButton` offering macOS/Windows (x64/ARM) installer downloads, falling back to the Download Apps settings page when a specific installer isn't available.
  - Uses `useIsDesktopShell` to decide what renders, `useDownloads` to fetch installer URLs from the server (skipped when already in the desktop shell), and `useSameWindowLinks` to determine whether download links should open in a new tab.

## Usage Example

```typescript
import { WelcomeStep } from './welcome-step';

function SetupWizard() {
  const [step, setStep] = useState(0);

  if (step === 0) {
    return <WelcomeStep onContinue={() => setStep(1)} />;
  }

  // ...render subsequent wizard steps
}
```

The component is self-contained and requires only an `onContinue` callback invoked when the user proceeds to the next wizard step; all download data and shell detection are resolved internally via hooks.
