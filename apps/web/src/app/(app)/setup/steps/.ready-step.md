Renders the final step of the first-device onboarding flow, confirming that the enrolled device's AI assistant (Mingo) is live and letting the admin start a chat with it.

## Key Components

- **`ReadyStep`** — React component (client-side) that displays:
  - A `SetupHeading` with confirmation copy.
  - A card showing the device name, a live/offline `Tag` status, and a bulleted list of assistant capabilities (`ASSISTANT_POINTS`).
  - A `Button` ("Start with Mingo") that triggers `onStart` and shows a loading state via `starting`.
- **`ASSISTANT_POINTS`** — Static array of strings describing what the AI assistant does, rendered as a checklist.
- **Props:**
  - `device: FirstDevice | null` — The device enrolled during the deploy step; if `null`, falls back to a cached lookup.
  - `onStart: () => void` — Callback invoked when the admin clicks "Start with Mingo".
  - `starting: boolean` — Controls the button's loading/disabled state.
- Uses `useFirstDeviceEnrollment(false)` to recover the device name/online status when navigating back to this step without a fresh `device` prop (i.e., the device was enrolled on a previous visit).

## Usage Example

```typescript
import { ReadyStep } from './ready-step';

function OnboardingWizard() {
  const [starting, setStarting] = useState(false);
  const device = useEnrolledDevice(); // e.g., from a prior deploy step

  const handleStart = () => {
    setStarting(true);
    navigateToMingoChat();
  };

  return (
    <ReadyStep
      device={device}
      onStart={handleStart}
      starting={starting}
    />
  );
}
```
