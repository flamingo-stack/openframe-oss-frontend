# customer-step.tsx

A React client component that renders the "Your First Customer" step of the Initial Setup onboarding flow, allowing users to quickly create their first customer organization or skip ahead with a test customer.

## Key Components

- **`CustomerStep`** — Main exported component rendering a form with customer name, website URL, and logo upload fields, plus two action paths (create customer or skip with test customer).
- **`emptyAddress`** — Default empty address shape used for both physical and mailing addresses when creating a customer.
- **`Action`** type — Tracks which button (`'test' | 'continue'`) triggered the current in-flight operation, used to drive per-button loading states.
- **`handleContinue`** — Async handler that builds a `CreateCustomerRequest`, calls `createOrganization`, uploads a pending logo (if any) via `uploadWithAuth`, invalidates related React Query caches, and notifies the parent via `onCreated`.
- **`handleTestCustomer`** — Synchronous handler that skips customer creation and calls `onTestCustomer`, letting the device enroll into the workspace's default organization.

## Usage Example

```typescript
import { CustomerStep } from './customer-step';

function SetupWizard() {
  const [organizationId, setOrganizationId] = useState<string | null>(null);
  const [persisting, setPersisting] = useState(false);

  return (
    <CustomerStep
      persisting={persisting}
      onCreated={(orgId) => {
        setOrganizationId(orgId);
        // advance to the device enrollment step
      }}
      onTestCustomer={() => {
        // advance to device step using the default organization
      }}
    />
  );
}
```

**Notes:**
- Relies on `useCreateCustomer` for the organization creation mutation and `usePendingLogo` for staged logo file state before an organization ID exists.
- Logo upload failures are non-blocking: the customer is still created, with a warning toast surfaced to the user.
- Cache invalidation targets both the `organizations` list and `dashboardQueryKeys.all` to keep dashboard widgets in sync after creation.
