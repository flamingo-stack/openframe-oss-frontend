# page.tsx

Next.js route component that renders the AI-first onboarding setup wizard (`onboarding-v2` feature flag), guiding a tenant through Initial Setup — organization, first customer, first device — ending with a handoff to the Mingo tour.

This route is rendered bare by the app shell (no header, sidebar, or panel), since the wizard itself owns the full-screen experience and manages its own loading state while reading onboarding progress. Users typically land here via `OnboardingV2Redirect`, which detects an in-progress onboarding session and redirects accordingly.

## Key Components

- **`SetupPage`** (default export) — Client component (`'use client'`) composing the setup route. Renders two children:
  - **`MaximizeDesktopWindow`** — Ensures the desktop shell's window is maximized for this route (it's typically already maximized after sign-in), giving the wizard and its deploy-step logs the full screen width they need.
  - **`SetupWizard`** — The actual multi-step wizard UI (imported from `./components/setup-wizard`), responsible for walking the tenant through organization, customer, and device setup.

## Usage Example

This is a Next.js app-router page component and is not invoked directly — it's resolved automatically based on its file path (e.g., `app/setup/page.tsx`).

```typescript
// Navigating to this route (e.g., from OnboardingV2Redirect)
import { useRouter } from 'next/navigation';

function OnboardingV2Redirect() {
  const router = useRouter();

  // When an onboarding-v2 session is detected, send the user here
  router.push('/setup');

  return null;
}
```

No props are accepted by `SetupPage` since it's a route entry point. All wizard state and progress tracking is encapsulated within `SetupWizard` itself.
