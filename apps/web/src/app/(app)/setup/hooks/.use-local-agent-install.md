# use-local-agent-install.ts

A React hook that manages the local (on-device) agent installation flow for the "Deploy on this Device" feature, bridging the desktop shell's native install process to page-level UI state.

This hook listens to the native shell's event bridge (`@/lib/native-shell`) for streaming install output and completion events, exposing them as reactive state so a page can render live install logs, status, and errors without owning the underlying process.

## Key Components

- **`LocalInstallStatus`** — Union type representing install lifecycle: `'idle' | 'running' | 'succeeded' | 'failed'`.
- **`LocalAgentInstall`** — Interface describing the hook's return value: `supported`, `status`, `lines`, `error`, and `start`.
- **`useLocalAgentInstall()`** — The hook itself. Determines platform support once on mount, subscribes to native shell output/completion events, and provides a `start` callback to kick off installation.

Internally, it uses `canInstallAgentLocally` to detect shell support, and subscribes via `onLocalAgentInstallOutput` / `onLocalAgentInstallDone` to receive streamed log lines (batched by the shell at ~200ms intervals) and the final success/failure outcome.

## Usage Example

```typescript
import { useLocalAgentInstall } from '@/hooks/use-local-agent-install';

function DeployOnDeviceButton({ agentRequest }: { agentRequest: AgentInstallRequest }) {
  const { supported, status, lines, error, start } = useLocalAgentInstall();

  if (!supported) {
    return <p>Local install is only available in the desktop app.</p>;
  }

  return (
    <div>
      <button disabled={status === 'running'} onClick={() => start(agentRequest)}>
        {status === 'running' ? 'Installing…' : 'Deploy on this Device'}
      </button>

      <pre>
        {lines.map((line, i) => (
          <div key={i}>{line.text}</div>
        ))}
      </pre>

      {status === 'failed' && error && <p>Install failed: {error.message}</p>}
      {status === 'succeeded' && <p>Agent installed successfully.</p>}
    </div>
  );
}
```

Each call to `start` resets `lines` and `error`, sets `status` to `'running'`, and awaits the native shell's install process. If `startLocalAgentInstall` throws synchronously, the hook captures the error and marks the status as `'failed'` directly, in addition to any asynchronous completion event.
