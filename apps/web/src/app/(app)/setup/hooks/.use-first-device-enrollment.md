# use-first-device-enrollment.ts

A React hook (and a one-shot query helper) that tracks the enrollment progress of a user's first device during the onboarding wizard, polling the Relay store until the agent is fully connected and ready for AI-driven management.

## Key Components

- **`EnrollmentStages`** — Interface describing the three enrollment checkpoints: `enrolled` (device node exists), `inventoryReceived` (Fleet confirmed the host), and `aiReady` (agent connected, Mingo can operate on it).
- **`FirstDevice`** — Interface representing the first enrolled device, including `machineId` (device detail page id), `mentionId` (used for `@device:<id>` inline mentions), `name` (display name or hostname fallback), `online` status, and `stages`.
- **`fetchFirstDevice(environment)`** — Async function that fetches the first device once from the network (`store-or-network`), useful for click handlers (e.g., tour chips navigating to the device page) rather than reactive rendering.
- **`useFirstDeviceEnrollment(polling)`** — React hook that reads the first device via `useLazyLoadQuery` (suspends on first load) and polls the server every 5 seconds (`POLL_MS`) when `polling` is `true`, refreshing the Relay store so all readers re-render automatically.

## Usage Example

```typescript
import { useFirstDeviceEnrollment, fetchFirstDevice } from '@/hooks/use-first-device-enrollment';
import { useRelayEnvironment } from 'react-relay';

function OnboardingChecklist() {
  const device = useFirstDeviceEnrollment(true); // polls while mounted

  if (!device) return <p>No device enrolled yet.</p>;

  return (
    <ul>
      <li>Enrolled: {device.stages.enrolled ? '✅' : '⏳'}</li>
      <li>Inventory received: {device.stages.inventoryReceived ? '✅' : '⏳'}</li>
      <li>AI ready: {device.stages.aiReady ? '✅' : '⏳'}</li>
      <li>{device.name} {device.online && '(LIVE)'}</li>
    </ul>
  );
}

// One-shot fetch for a click handler
function GoToDeviceButton() {
  const environment = useRelayEnvironment();

  const handleClick = async () => {
    const device = await fetchFirstDevice(environment);
    if (device?.machineId) {
      window.location.href = `/devices/${device.machineId}`;
    }
  };

  return <button onClick={handleClick}>View my device</button>;
}
```

**Note:** `useFirstDeviceEnrollment` suspends on initial load — wrap consuming components in a `Suspense` boundary within the onboarding wizard.
