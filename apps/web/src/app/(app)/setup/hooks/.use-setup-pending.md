## Overview

This file defines a React hook, `useSetupPending`, that determines whether the current user session should be routed to the onboarding setup wizard (`/setup`). It consolidates signals from a feature flag, onboarding progress state, and local tour state into a single tri-state result.

## Key Components

- **`SetupPending`** — Exported type representing the three possible states:
  - `'unknown'` — flag or progress data hasn't resolved yet; no routing decision should be made.
  - `'setup'` — the wizard should be shown (workspace setup incomplete, or user hasn't finished the final screen and has no server/local record of completion).
  - `'none'` — the wizard should not be shown (flag disabled, setup already completed and acknowledged, tour already started/finished/skipped, or no progress record exists at all).

- **`useSetupPending()`** — Hook that reads:
  - `useFeatureFlagGate('onboarding-v2')` for the feature flag state.
  - `useOnboardingStore` for `isLoaded`, `tenant`, and `user` progress data.
  - `useTourStarted()` for local tour-start state.
  
  It returns a `SetupPending` value based on the precedence rules documented in the type's JSDoc.

## Usage Example

```typescript
'use client';

import { useSetupPending } from '@/app/hooks/use-setup-pending';
import { useRouter } from 'next/navigation';
import { useEffect } from 'react';

export function OnboardingGuard() {
  const setupPending = useSetupPending();
  const router = useRouter();

  useEffect(() => {
    if (setupPending === 'setup') {
      router.replace('/setup');
    }
  }, [setupPending, router]);

  if (setupPending === 'unknown') {
    return null; // avoid flashing content while resolving
  }

  return null;
}
```

**Note:** Treat `'unknown'` as a loading state—avoid redirect or UI decisions until the hook resolves to `'setup'` or `'none'`, since premature routing could interrupt an in-progress server fetch.
