# dev-skip-onboarding-button.tsx

A developer/QA-only shortcut button rendered in the onboarding wizard's footer that lets testers bypass the onboarding flow entirely, completing the tenant's Initial Setup and the user's Get Started step before redirecting to the dashboard.

## Key Components

- **`DevSkipOnboardingButton`** — React client component that conditionally renders a "Skip onboarding (dev)" button.
  - Gated behind the `onboarding-skip` feature flag via `useFeatureFlagGate`.
  - Only renders when onboarding progress exists (`useOnboardingStore` has a `tenant`).
  - Hidden entirely while inside a loading scope (`useLoadingScope`), marked `data-loading-optional` to avoid skeleton flashes when the flag resolves to off.
  - Responsive rendering: icon-only `glyph` button on small screens (`sm:hidden`), full `outline` button with label on larger screens (`hidden sm:block`).
  - Calls `skipOnboarding` from `useOnboardingMutations`, then redirects via `router.replace(getLandingPath())` on success.

## Usage Example

```typescript
import { DevSkipOnboardingButton } from '@/components/onboarding/dev-skip-onboarding-button';

export function OnboardingWizardFooter() {
  return (
    <footer className="flex items-center justify-between gap-2">
      <HelpButton />
      <DevSkipOnboardingButton />
    </footer>
  );
}
```

**Notes:**
- This component should only be visible when the `onboarding-skip` feature flag is enabled (typically restricted to dev/QA environments), so no additional guard is needed when placing it in a layout.
- Unlike the primary "Start with Mingo" onboarding action, this button does **not** trigger the Mingo product tour — it's a pure bypass for testing purposes.
- The outline styling and "(dev)" suffix in the label are intentional to prevent end users from mistaking this for a supported product action.
