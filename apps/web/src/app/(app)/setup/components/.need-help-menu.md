Client component rendering the onboarding wizard footer's "Need Help?" menu, giving access to an intro video, an onboarding call booking, and a support contact form.

## Key Components

- **`NeedHelpMenu`** — Default-exported React component that renders a responsive help trigger: a glyph-only icon button on mobile (`sm:hidden`) and a labeled `DropdownButton` on larger screens (`hidden sm:block`).
- **`HelpSurface`** — Internal type (`'intro' | 'call' | 'support' | null`) tracking which modal is currently open.
- **Conditional menu items** — "Watch a 1-minute intro" and "Book an Onboarding Call" are only included when `useWalkthroughVideoData` or `useOnboardingMeetingLink` resolve a valid video/link respectively; "Contact Support" is always shown.
- **Modals rendered** — `IntroVideoModal`, `BookCallModal`, and `ContactSupportModal`, each controlled by the shared `open` state.

## Usage Example

```typescript
import { NeedHelpMenu } from '@/app/(app)/onboarding/components/need-help-menu';

export function WizardFooter() {
  return (
    <footer className="flex items-center justify-between">
      {/* other footer controls */}
      <NeedHelpMenu />
    </footer>
  );
}
```

### Behavior notes
- The menu opens **upwards** (`side="top"`) since it lives in a footer.
- `onCloseAutoFocus` is prevented so closing the dropdown doesn't steal focus from the modal it just opened.
- Menu items intentionally have no secondary description line, since `ActionsMenuItem` from `@flamingo-stack/openframe-frontend-core` has no description slot.
- Visibility of the intro/call items depends entirely on data returned by `useWalkthroughVideoData` and `useOnboardingMeetingLink`—no video/link means the item is omitted rather than shown disabled.
