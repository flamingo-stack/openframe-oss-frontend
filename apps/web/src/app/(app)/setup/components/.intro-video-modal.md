# intro-video-modal.tsx

Renders a modal dialog that plays the platform's "1-minute intro" walkthrough video, reusing the same video data that the app-shell's floating card displays. While the modal is open, it claims the walkthrough clip so the floating card won't simultaneously offer it.

## Key Components

- **`IntroVideoModal`** — React component accepting `open: boolean` and `onClose: () => void` props. Renders a `SimpleModal` wrapping the shared `Video` player.
  - Fetches video metadata via `useWalkthroughVideoData` (YouTube URL or direct file URL, poster, captions, title).
  - Calls `useInlineWalkthroughClaim(open && Boolean(url))` to signal that this modal currently "owns" playback of the walkthrough clip, preventing duplicate playback from the floating card.
  - Renders the `Video` component only when `open` is true and a playable `url` exists (lazy mount, no autoplay — playback starts only on explicit user interaction with the poster/play button).
  - Player kind is derived from data: `'youtube'` if `video.youtubeUrl` is set, otherwise `'file'`.

## Usage Example

```typescript
'use client';

import { useState } from 'react';
import { IntroVideoModal } from '@/app/components/intro-video-modal';

export function WelcomeBanner() {
  const [showIntro, setShowIntro] = useState(false);

  return (
    <>
      <button onClick={() => setShowIntro(true)}>
        Watch a 1-minute intro
      </button>

      <IntroVideoModal
        open={showIntro}
        onClose={() => setShowIntro(false)}
      />
    </>
  );
}
```

**Notes:**
- Designed for contexts where the modal itself acts as the "stage" for the video (unlike the floating card, which opens a separate theater over the page).
- Depends on `useWalkthroughVideoData` for video metadata and `useInlineWalkthroughClaim` for coordinating playback state with other walkthrough-playing UI elements.
- Full-screen playback is handled entirely by the underlying `Video` player component.
