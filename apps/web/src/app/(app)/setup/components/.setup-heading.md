# setup-heading.tsx

Renders the centered logo, title, and optional subtitle used atop setup wizard screens, matching the design system's responsive spacing and width constraints.

## Key Components

- **`SetupHeading`** — Functional component that composes the `OpenframeLockup` logo with a heading (`title`) and optional lead text (`subtitle`), centered and width-constrained per the wizard design spec.

### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `title` | `ReactNode` | Yes | Main heading content, rendered as `<h1>` |
| `subtitle` | `ReactNode` | No | Lead/description text rendered below the title, capped at 730px width |

## Usage Example

```typescript
import { SetupHeading } from '@/app/components/setup/setup-heading';

export function WelcomeStep() {
  return (
    <SetupHeading
      title="Welcome to OpenFrame"
      subtitle="Let's get your workspace configured in just a few steps."
    />
  );
}
```

Using only a title (no subtitle):

```typescript
<SetupHeading title="Choose your plan" />
```

## Notes

- The container caps at `990px` width, wider than step bodies (typically `600px`), to match the desktop single-line title design.
- Spacing tokens (`--spacing-system-lf`, `--spacing-system-xl`) drive the gap between logo/title and respond to breakpoints (24px on mobile, 40px from tablet up).
- Subtitle text wraps at `730px` max width even within the wider `990px` container.
