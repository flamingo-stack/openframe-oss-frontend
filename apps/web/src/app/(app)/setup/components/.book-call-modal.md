# book-call-modal.tsx

A client-side React component that renders the "Book an Onboarding Call" modal, wiring the shared `MeetingSchedulerModal` component from the core library to this app's onboarding meeting link and content proxy.

## Key Components

- **`BookCallModal`** — Named export, a functional component that accepts `open` (boolean) and `onClose` (callback) props to control modal visibility. It delegates all scheduling UI and booking confirmation behavior to `MeetingSchedulerModal`, supplying app-specific configuration:
  - `title`: static label "Book an Onboarding Call"
  - `link`: the onboarding meeting link, resolved via `useOnboardingMeetingLink`
  - `loading`: loading state while the link is being fetched
  - `apiBaseUrl`: set to `CONTENT_BASE`, the app's `/content` proxy base used by the scheduler to make API calls
  - `emptyMessage`: fallback text shown when no bookable calls are available

## Usage Example

```typescript
import { useState } from 'react';
import { BookCallModal } from '@/app/(app)/onboarding/components/book-call/book-call-modal';

export function OnboardingPage() {
  const [isBookCallOpen, setIsBookCallOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsBookCallOpen(true)}>
        Schedule Onboarding Call
      </button>

      <BookCallModal
        open={isBookCallOpen}
        onClose={() => setIsBookCallOpen(false)}
      />
    </>
  );
}
```

## Notes

This component acts as a thin binding layer: the modal shell, scheduler widget, and success toast are all implemented in `@flamingo-stack/openframe-frontend-core`. This file only supplies app-specific context (onboarding link resolution via `useOnboardingMeetingLink` and the `CONTENT_BASE` endpoint from `help-center/endpoints`).
