## install-log.tsx

Renders the live installer output during device installation as a collapsible, scrollable log box displayed under the install step's action buttons. It mirrors the Agent Logs column layout (time · level · message) but never truncates lines, instead scrolling horizontally to fit the longest one.

## Key Components

- **`InstallLog`** — Top-level component that converts raw `InstallOutputLine[]` into display rows via `toInstallLogRows` and renders nothing until the first line arrives.
- **`InstallLogBox`** — The actual log container: a bordered card with scroll-fade overlays on all four edges, auto-scroll-to-tail behavior (only while collapsed and not expanded), and a toggle button to expand/collapse.
- **`useFillWindowHeight`** — Internal hook that, when expanded, resizes the scroll container to consume the remaining vertical space in the page's `<main>` element, re-measuring on window resize or content growth (e.g., the progress list beneath it) via `ResizeObserver`.
- **`FADE_COLOR`**, **`VERTICAL_FADE_CLASS`**, **`MIN_EXPANDED_HEIGHT`** — Layout constants controlling fade overlay color/size and the minimum expanded height (matches the collapsed `max-h-40`).

## Usage Example

```typescript
import { InstallLog } from './install-log';
import type { InstallOutputLine } from '../lib/install-log-line';

function InstallStep({ outputLines }: { outputLines: InstallOutputLine[] }) {
  return (
    <div className="flex flex-col gap-4">
      {/* ...install action buttons and progress list... */}
      <InstallLog lines={outputLines} />
    </div>
  );
}
```

Behavior notes:
- Collapsed state caps at `600px` wide, `max-h-40` tall, and auto-scrolls to the newest line as `lines` grows.
- Expanding (via the corner button) widens the box to `900px` and fills available vertical space down to the window edge, disabling auto-scroll so users can review the full transcript.
- Renders `null` when `lines` produces no rows, so no empty box appears before installation output begins.
