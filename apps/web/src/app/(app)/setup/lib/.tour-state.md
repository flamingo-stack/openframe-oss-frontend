# tour-state.ts

Manages a client-side, per-user `localStorage` marker that bridges the gap between pressing "Start with Mingo" in the setup wizard and the Mingo panel creating the tour's actual conversation on the server. Since the wizard navigates away before the server-side `userOnboardingProgress.tourDialogId` is written, this marker prevents the dashboard from redirecting the user back to the wizard during that gap.

## Key Components

- **`TourState`** — Interface holding `startedAt`, an ISO timestamp recording when the tour began (used for Mingo's greeting).
- **`markTourStarted(userId)`** — Writes the marker to `localStorage` when "Start with Mingo" is pressed, if not already set.
- **`clearTourStarted(userId)`** — Removes the marker, called when onboarding progress is reset.
- **`useTourState()`** — React hook built on `useSyncExternalStore` that reads the current `TourState` for the authenticated user, re-rendering when the stored value changes (including cross-tab updates via the `storage` event).
- **`useTourStarted()`** — Convenience hook returning a boolean for whether the tour marker is currently set.

Internally, parsed JSON values are cached by raw string (`parsed` map) so that `useSyncExternalStore` sees referential stability for unchanged entries, avoiding unnecessary re-renders.

## Usage Example

```typescript
import { markTourStarted, useTourStarted, clearTourStarted } from './tour-state';
import { useAuthStore } from '@/app/(auth)/auth/stores/auth-store';

function StartMingoButton() {
  const userId = useAuthStore(state => state.user?.id);

  const handleClick = () => {
    markTourStarted(userId);
    // navigate to dashboard; Mingo panel will pick up the marker
  };

  return <button onClick={handleClick}>Start with Mingo</button>;
}

function DashboardGuard() {
  const tourStarted = useTourStarted();

  if (tourStarted) {
    // avoid redirecting back to the setup wizard
    return null;
  }
  // ...normal redirect logic
}
```

Call `clearTourStarted(userId)` alongside other "Reset Onboarding" logic to fully clear the marker.
