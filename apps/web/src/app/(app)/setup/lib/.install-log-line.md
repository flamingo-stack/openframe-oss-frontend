Parses raw installer output (a mix of Doctor check marks, agent JSON/tracing log lines, and plain shell output) into structured `InstallLogRow` entries suitable for display in the Agent Logs UI (time · level · message columns).

## Key Components

- **`InstallOutputLine`** — input shape: a raw text line plus the timestamp the shell handed it over.
- **`InstallLogRow`** — output shape: a normalized row with `time`, `level` (`DeviceLogLevel`), and `message`.
- **`toInstallLogRows(lines)`** — the main export. Converts an array of `InstallOutputLine` into `InstallLogRow[]` by detecting the line format:
  - **JSON agent log lines** (`{"timestamp", "level", "message", ...}`) parsed via internal `parseJsonLine`.
  - **Tracing lines** (e.g. `2026-10-23T10:00:00.123456Z  INFO openframe::service: started`) matched by `TRACING_LINE`, with `TRACE` normalized to `DEBUG`.
  - **Doctor check lines** (`[+] Admin privileges`, `[x] ...`, `[!] ...`, `[i] ...`) matched by `DOCTOR_LINE`, mapped to levels via `DOCTOR_LEVEL`.
  - **Continuation lines** (indented 4+ spaces) matched by `CONTINUATION`, inheriting the level of the previous row.
  - **Plain shell output**, classified as `ERROR` if it matches `FAILURE_LINE` (e.g. `curl: (22) ...`, `Error: ...`, `failed to ...`), otherwise `INFO`.
  - Blank lines are dropped.

## Usage Example

```typescript
import { toInstallLogRows, InstallOutputLine } from './install-log-line';

const lines: InstallOutputLine[] = [
  { text: '[+] Admin privileges', receivedAt: new Date('2026-10-23T10:00:00Z') },
  { text: '{"timestamp":"2026-10-23T10:00:01Z","level":"INFO","message":"starting install"}', receivedAt: new Date() },
  { text: 'curl: (22) The requested URL returned error: 404', receivedAt: new Date() },
  { text: '    see https://example.com/help for details', receivedAt: new Date() },
];

const rows = toInstallLogRows(lines);
// rows[0] => { time: <date>, level: INFO, message: 'Admin privileges' }
// rows[1] => { time: <parsed timestamp>, level: INFO, message: 'starting install' }
// rows[2] => { time: <receivedAt>, level: ERROR, message: 'curl: (22) ...' }
// rows[3] => { time: <receivedAt>, level: ERROR, message: 'see https://...' } // continuation inherits ERROR
```
