This file defines the page metadata and layout wrapper for the Setup route in the Next.js application, enabling dynamic browser tab titles via the shared route-title utility.

## Key Components

- **`metadata`** — A statically exported `Metadata` object (Next.js convention) that sets the document title to `"Setup"` formatted through the `routeTitle` helper, ensuring consistent title formatting across the app (e.g., appending a brand suffix).
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as this route's layout, avoiding duplication of layout logic across route segments.

## Usage Example

This file is a Next.js route segment convention file (`layout.tsx`) and is not imported directly. It is automatically picked up by the Next.js App Router for the `Setup` route segment:

```typescript
// Next.js automatically applies this layout and metadata
// to any page.tsx within the same route segment, e.g.:
// app/(app)/setup/layout.tsx  <-- this file
// app/(app)/setup/page.tsx    <-- uses the layout & metadata

// Equivalent conceptual usage:
import SetupLayout, { metadata } from './layout';

export default function Page() {
  return <SetupLayout>{/* page content */}</SetupLayout>;
}
```

Because it re-exports a shared layout component, any updates to `route-title-layout` automatically propagate to this and other routes using the same pattern, keeping title and layout behavior consistent throughout the app.
