A Next.js client-side page component that renders employee detail information based on a URL query parameter.

## Key Components

- **`EmployeeDetailsPage`** — Default export page component that extracts the `id` query parameter from the URL and passes it to the employee details view.

## Usage Example

```typescript
// Accessed via URL: /settings/employees?id=usr_123
// The component automatically extracts the `id` param and renders the view

<EmployeeDetailsPage />
// Internally resolves to:
<EmployeeDetailsView userId="usr_123" />
```

## Notes

- Marked as `'use client'` — runs entirely on the client side.
- Uses Next.js [`useSearchParams`](https://nextjs.org/docs/app/api-reference/functions/use-search-params) to read the `id` query string.
- Falls back to an empty string (`''`) if `id` is absent from the URL.
- Delegates all rendering logic to [`EmployeeDetailsView`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/settings/components/employee-details-view.tsx).
