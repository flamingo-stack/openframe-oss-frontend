Renders the compact OpenFrame logo and wordmark used in branded UI surfaces such as the sidebar and onboarding flow of the Fae window (openframe-chat).

## Key Components

- **`OpenFrameMark`** — A functional React component that renders:
  - `OpenframeLogoIcon` from `@flamingo-stack/openframe-frontend-core/components/icons-v2`, styled with primary text color and a secondary yellow accent color.
  - A `"OpenFrame"` text wordmark styled via the `text-wordmark` utility class.
  - A flex container (`span`) that aligns the icon and wordmark horizontally with consistent spacing using the `--spacing-system-xxs` CSS variable.

## Usage Example

```typescript
import { OpenFrameMark } from './openframe-mark';

function Sidebar() {
  return (
    <div className="sidebar-header">
      <OpenFrameMark />
    </div>
  );
}
```

```typescript
// Typical usage in an onboarding screen
import { OpenFrameMark } from './openframe-mark';

export function OnboardingHeader() {
  return (
    <header className="onboarding-header">
      <OpenFrameMark />
      <p className="onboarding-subtitle">Welcome to OpenFrame</p>
    </header>
  );
}
```

This component has no props and relies entirely on design-system CSS variables (`--color-text-primary`, `--ods-open-yellow-base`, `--spacing-system-xxs`) and utility classes (`text-ods-text-primary`, `text-wordmark`) for consistent branding across the application.
