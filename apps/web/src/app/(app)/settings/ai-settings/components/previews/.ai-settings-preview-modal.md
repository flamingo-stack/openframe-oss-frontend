# ai-settings-preview-modal.tsx

A full-screen modal that renders the Fae assistant preview (Welcome and Chat panes) at the device's true viewport width, letting admins see exactly what customers see when customizing AI assistant branding (name, avatar, accent color).

## Key Components

- **`PreviewPane`** - Type alias for the two preview tabs: `'welcome' | 'chat'`.
- **`AiSettingsPreviewModal`** - Main exported component. Renders a `ModalV2` containing:
  - A header row with a title (`ModalV2Title`) and a close button.
  - A `TabNavigation` to switch between "Welcome" and "Chat" preview panes.
  - The active preview pane (`FaeWelcomePreview` or `FaeChatPreview`), rendered at full/unscaled size using `PREVIEW_THEME_CLASS`.
- **`AiSettingsPreviewModalProps`** - Props interface controlling open state, active pane, assistant branding (`assistantName`, `avatarUrl`, `accentColor`), and callbacks (`onClose`, `onPaneChange`).

The modal is full-bleed (edge-to-edge) on mobile (`< md`) so the preview renders at the phone's actual width, and becomes a centered 1024px panel on larger screens (matching Fae's default chat window width).

## Usage Example

```typescript
import { useState } from 'react';
import { AiSettingsPreviewModal, type PreviewPane } from './ai-settings-preview-modal';

function AiSettingsPage() {
  const [isPreviewOpen, setPreviewOpen] = useState(false);
  const [activePane, setActivePane] = useState<PreviewPane>('welcome');

  return (
    <>
      <button onClick={() => setPreviewOpen(true)}>Preview Assistant</button>

      <AiSettingsPreviewModal
        isOpen={isPreviewOpen}
        onClose={() => setPreviewOpen(false)}
        activePane={activePane}
        onPaneChange={setActivePane}
        assistantName="Fae"
        avatarUrl="/assets/fae-avatar.png"
        accentColor="#6D28D9"
      />
    </>
  );
}
```

## Notes

- The "Start Chat" action in the Welcome pane automatically switches `activePane` to `'chat'` via `onPaneChange`, mirroring the real end-user flow.
- Safe-area insets (`--native-safe-top`, `--native-safe-bottom`) are applied inside the panel so the previewed theme's background—not the host app's—fills the notch/home-indicator areas on native clients.
