# quick-action-icon-select.tsx

A form-field component rendering a searchable icon-grid picker for selecting the glyph of a quick-action row, backed by `react-hook-form`'s `Controller`.

## Key Components

- **`QuickActionIconSelectProps`** — Props interface: `index` (row index in the `quickActions` field array), `control` (react-hook-form `Control`), `accent` (optional `QuickActionAccent` for tinting the preview), and `className`.
- **`captionFromKey(key: string)`** — Internal helper that converts a glyph key (e.g. `"grid-check"`) into a human-readable caption (e.g. `"Grid check"`), stripping trailing numeric suffixes.
- **`QuickActionIconSelect`** — The exported component. Renders a `Controller`-wrapped `SearchableSelect` in grid layout, populated from `ICON_OPTIONS` (the shared core-lib icon registry), with each option rendered via `renderQuickActionIcon` so the picker tile matches the resulting chat chip. Preserves and displays any out-of-registry stored value (e.g. legacy defaults like `grid-check` or `usb`) as a leading extra tile instead of discarding it.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { QuickActionIconSelect } from './quick-action-icon-select';
import type { QuickActionsFormValues } from '../types/quick-action.types';

function QuickActionRow({ index }: { index: number }) {
  const { control } = useForm<QuickActionsFormValues>();

  return (
    <QuickActionIconSelect
      index={index}
      control={control}
      accent="blue"
      className="w-full"
    />
  );
}
```

This component is intended to be used within a row of a `quickActions` field array managed by `react-hook-form`, typically alongside other fields like label or action type, forming part of a larger quick-actions configuration form.
