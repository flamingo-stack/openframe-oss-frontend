Defines TypeScript types and constants for AI-agent guardrail policy view-models, used to represent tenant and organization-level approval policies (what tools/functions require what level of approval) within the OpenFrame frontend.

## Key Components

- **`CUSTOM_POLICY_TYPE`** — Literal constant `'CUSTOM'` marking a policy as custom rather than template-based.
- **`CUSTOM_CREATION_TEMPLATE_ID`** — Sentinel radio value (`'CUSTOM_CREATION'`) representing an unsaved custom policy draft.
- **`CUSTOM_POLICY_DESCRIPTION`** — Static UI copy shown for the "Custom" option in policy pickers, since custom policies have no backend-provided description.
- **`PolicyTemplateSummary`** — Lightweight summary of a policy template/custom policy for list/picker views (id, name, description, type, active state, override count).
- **`PolicyRule`** — A single governed rule: tool, function, category, operation, command pattern, and its resolved `ApprovalLevel`, plus a `naturalKey` for override lookups.
- **`PolicyTemplateDetail`** — Full detail view of a policy including its rules, custom overrides map, source template (for custom policies), and active flag.
- **`CustomPolicyRequest`** — Payload shape for creating/updating a custom policy from a base template plus per-rule overrides.

## Usage Example

```typescript
import {
  CUSTOM_POLICY_TYPE,
  CUSTOM_CREATION_TEMPLATE_ID,
  type PolicyTemplateDetail,
  type CustomPolicyRequest,
} from './guardrails.types';

function buildCustomPolicyRequest(
  template: PolicyTemplateDetail,
  naturalKey: string,
  approvalLevel: PolicyTemplateDetail['customOverrides'][string]
): CustomPolicyRequest {
  return {
    templateId:
      template.type === CUSTOM_POLICY_TYPE
        ? (template.sourceTemplate ?? CUSTOM_CREATION_TEMPLATE_ID)
        : template.id,
    overrides: { ...template.customOverrides, [naturalKey]: approvalLevel },
  };
}
```

This type module is typically consumed by `use-guardrails-policies.ts` and `use-organization-guardrails.ts` to normalize API responses into consistent `PolicyRule`/`PolicyTemplateDetail` shapes for guardrail configuration UI.
