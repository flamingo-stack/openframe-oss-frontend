# build-policy-groups.ts

Transforms a flat list of `PolicyRule` objects into a nested structure (policy group → categories → policies) consumed by the core-lib `PolicyConfigurationPanel`. It also provides label formatting for policy-group section headers.

## Key Components

- **`policyGroupLabel(policyGroup: string): string`** — Converts a policy-group enum value (e.g. `FILE_OPERATIONS_POLICY`) into its display label. Uses a hardcoded lookup (`JOINED_GROUP_LABELS`) for groups whose label joins two subjects with "&" (e.g. `COMMUNICATION_MESSAGING_POLICY` → "Communication & Messaging Policy"), falling back to `formatUnderscoreText` for standard cases.
- **`buildPolicyGroups(rules: PolicyRule[]): Map<string, PermissionCategory[]>`** — Groups flat policy rules by `policyGroup`, then by `category`, building `PermissionCategory` objects with slugified IDs, resolved icons (via `categoryIcon`), and normalized tool names (via `normalizeToolTypeWithFallback`). Defaults missing `policyGroup` to `'General'` and missing `category` to `'Other'`. This is a pure data transform; presentation state (expansion, bulk selection) is owned by the consuming panel component.
- **`slugify(value: string)`** (internal) — Normalizes a string into a URL/ID-safe slug for use as a stable category identifier.

## Usage Example

```typescript
import { buildPolicyGroups, policyGroupLabel } from './build-policy-groups';
import type { PolicyRule } from './guardrails.types';

const rules: PolicyRule[] = [
  {
    naturalKey: 'file-download-pdf',
    policyGroup: 'FILE_OPERATIONS_POLICY',
    category: 'Downloads',
    operation: 'Download PDF',
    commandPattern: '*.pdf',
    tool: 'browser',
    approvalLevel: 'auto',
  },
  // ...more rules
];

const groups = buildPolicyGroups(rules);

for (const [policyGroup, categories] of groups) {
  console.log(policyGroupLabel(policyGroup)); // e.g. "File Operations Policy"
  categories.forEach((category) => {
    console.log(category.name, category.policies.length);
  });
}
```

This structure feeds directly into the `PolicyConfigurationPanel` from `@flamingo-stack/openframe-frontend-core`, rendering grouped, categorized policy rules with icons and approval levels.
