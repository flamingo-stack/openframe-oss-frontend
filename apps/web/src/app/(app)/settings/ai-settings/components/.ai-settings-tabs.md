Defines the tab configuration and navigation component for the AI Settings page, managing feature-flag-gated visibility of Mingo AI, Customer AI, and Guardrails tabs.

## Key Components

- **`AI_SETTINGS_TAB_IDS`** — Const tuple of valid tab IDs: `'mingo'`, `'customer'`, `'guardrails'`
- **`AiSettingsTabId`** — Union type derived from `AI_SETTINGS_TAB_IDS`
- **`AI_SETTINGS_TABS`** — Static array of `TabItem` configs with labels and icons for all three tabs
- **`TAB_FEATURE_FLAG`** — Maps tab IDs to feature-flag resolver functions; tabs without an entry are always visible (e.g. `guardrails`)
- **`getVisibleAiSettingsTabs()`** — Filters `AI_SETTINGS_TABS` based on current server-driven feature-flag state
- **`AiSettingsTabs`** — Client component wrapping `TabNavigation` with render-prop children for tab content

## Usage Example

```typescript
import { AiSettingsTabs, type AiSettingsTabId } from './ai-settings-tabs';
import { useState } from 'react';

export function AiSettingsPage() {
  const [activeTab, setActiveTab] = useState<AiSettingsTabId>('mingo');

  return (
    <AiSettingsTabs
      activeTab={activeTab}
      onTabChange={setActiveTab}
    >
      {(tab) => {
        if (tab === 'mingo') return <MingoSettings />;
        if (tab === 'customer') return <CustomerAiSettings />;
        if (tab === 'guardrails') return <GuardrailsSettings />;
      }}
    </AiSettingsTabs>
  );
}
```

## Notes

- The `customer` tab is hardcoded to always be visible even though its underlying appearance customization features remain gated at their own call sites
- Tab content is rendered via a [render prop](https://react.dev/reference/react/cloneElement#passing-data-with-a-render-prop) pattern, receiving the active `AiSettingsTabId`
