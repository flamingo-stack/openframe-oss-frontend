Defines the tab configuration and navigation wrapper for the AI Settings page, including feature-flag-gated visibility of the "Device Guardrails" tab based on the remote access approval gate.

## Key Components

- **`AI_SETTINGS_TAB_IDS` / `AiSettingsTabId`** — Const tuple and derived union type enumerating valid tab identifiers: `'mingo'`, `'customer'`, `'guardrails'`, `'device-guardrails'`.
- **`MingoTabIcon`** — Internal component rendering Mingo's agent identity mark (`AgentMark`) as the icon for the Mingo tab, colored via `currentColor` so the `TabNavigation` strip can style it per active/inactive state.
- **`AI_SETTINGS_TABS`** — Static array of `TabItem` definitions (id, label, icon) for all four possible tabs.
- **`useVisibleAiSettingsTabs()`** — Hook returning the tab set filtered by the `remote-access-approval` feature flag. Returns `null` while the flag is loading (to avoid the page picking a wrong initial tab before resolution), the full tab list when the flag is `'on'`, or the list minus `'device-guardrails'` otherwise.
- **`AiSettingsTabs`** — Presentational component wrapping `TabNavigation`, rendering tab content via a render-prop (`children`) scoped to the active `AiSettingsTabId`.

## Usage Example

```typescript
import {
  useVisibleAiSettingsTabs,
  AiSettingsTabs,
  type AiSettingsTabId,
} from './ai-settings-tabs';
import { useState } from 'react';

function AiSettingsPage() {
  const tabs = useVisibleAiSettingsTabs();
  const [activeTab, setActiveTab] = useState<AiSettingsTabId>('mingo');

  if (!tabs) return null; // waiting on feature flag

  return (
    <AiSettingsTabs tabs={tabs} activeTab={activeTab} onTabChange={setActiveTab}>
      {(tabId) => {
        switch (tabId) {
          case 'mingo':
            return <MingoChatSettings />;
          case 'customer':
            return <CustomerAiConfig />;
          case 'guardrails':
            return <CustomerGuardrails />;
          case 'device-guardrails':
            return <DeviceGuardrails />;
        }
      }}
    </AiSettingsTabs>
  );
}
```
