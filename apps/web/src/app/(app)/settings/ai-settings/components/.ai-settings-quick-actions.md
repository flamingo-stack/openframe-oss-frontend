# ai-settings-quick-actions.tsx

Renders the read-only "Quick Actions" list used in the AI settings view for both Mingo (internal technician assistant) and the customer-facing AI Assistant (Fae). Displays a source banner (OpenFrame defaults vs. organization-customized actions) followed by a single-column `DataTable` of actions, each showing an icon tile, name, and instructions, with full loading-skeleton support via `useLoadingScope`.

## Key Components

- **`QuickActionsAgentConfig`** — Config shape (`agentLabel`, `agentSlug`) driving per-agent wording and accent resolution.
- **`MINGO_QUICK_ACTIONS_CONFIG`** / **`ASSISTANT_QUICK_ACTIONS_CONFIG`** — Preset configs for the Mingo and Fae (AI Assistant) tabs.
- **`resolveQuickActionAccent(agentConfig, accent?)`** — Resolves the glyph tint: explicit `accent` wins, otherwise falls back to the agent's built-in accent color.
- **`QuickActionsBannerCopy`** — Overrides the banner's title/caption text.
- **`QuickActionsSourceBanner`** — Single-row info banner indicating whether actions are OpenFrame defaults or organization-configured, with skeleton support while loading.
- **`AiSettingsQuickActionsSection`** — Full view-mode section: heading + source banner + the quick actions list.
- **`AiSettingsQuickActions`** — The read-only `DataTable` of quick actions, used standalone (e.g., as a dimmed preview in edit mode).

## Usage Example

```typescript
import {
  AiSettingsQuickActionsSection,
  MINGO_QUICK_ACTIONS_CONFIG,
} from '@/app/components/ai-settings-quick-actions';

function MingoQuickActionsTab({ actions, isDefault }: { actions?: AiQuickAction[]; isDefault?: boolean }) {
  return (
    <AiSettingsQuickActionsSection
      title="Quick Actions"
      actions={actions}
      isDefault={isDefault}
      agentConfig={MINGO_QUICK_ACTIONS_CONFIG}
    />
  );
}
```

Standalone list usage (e.g., dimmed preview inside an edit-mode form):

```typescript
<AiSettingsQuickActions
  actions={actions}
  isDefault={isDefault}
  agentConfig={ASSISTANT_QUICK_ACTIONS_CONFIG}
  className="opacity-60 pointer-events-none"
/>
```

While `actions` or `isDefault` is `undefined`, components automatically render loading skeletons via the shared `useLoadingScope` context.
