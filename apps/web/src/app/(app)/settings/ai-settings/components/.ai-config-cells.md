# ai-config-cells.tsx

Builds a consistent array of three `InfoCell` elements (LLM Provider, Provider Model, Answer Style) used to summarize an agent's AI configuration across summary cards, with shared loading/skeleton styling.

## Key Components

- **`AI_CONFIG_CELL_CLASS`** — Shared Tailwind class defining each cell's frame (height, padding) responsive from mobile to `content-md`.
- **`AI_CONFIG_VALUE_SKELETON_WIDTH`** — Shared skeleton bar width (`w-24`) used while a cell's value is loading.
- **`AiConfigCellsOptions`** — Props interface: `aiConfig` (optional `AgentAiConfig`), `providerModelLabel` (optional display override), `loading` (boolean), and `providerLabel` (string, e.g. "LLM Provider").
- **`aiConfigCells(options)`** — Function returning an array of three `InfoCell` JSX elements:
  1. **LLM Provider** — shows label + icon (`NamedIcon` via `LLM_PROVIDER_ICON`) and localized value via `LLM_PROVIDER_LABEL`.
  2. **Provider Model** — shows `providerModelLabel`, falling back to `aiConfig.providerModel`, then `EMPTY_VALUE`.
  3. **Answer Style** — shows localized value via `ANSWER_STYLE_LABEL`, falling back to `EMPTY_VALUE`.

All cells respect the `loading` flag to render skeleton placeholders consistently.

## Usage Example

```typescript
import { aiConfigCells } from '../utils/ai-config-cells';

function AgentAiSummaryCard({ aiConfig, isLoading }: { aiConfig?: AgentAiConfig; isLoading: boolean }) {
  const cells = aiConfigCells({
    aiConfig,
    providerModelLabel: aiConfig?.providerModel ? friendlyModelName(aiConfig.providerModel) : undefined,
    loading: isLoading,
    providerLabel: 'LLM Provider',
  });

  return <div className="divide-y divide-ods-border">{cells}</div>;
}
```

Use `aiConfigCells` whenever a card needs to display the standard LLM provider/model/answer-style trio, ensuring consistent layout and loading behavior without duplicating `InfoCell` configuration.
