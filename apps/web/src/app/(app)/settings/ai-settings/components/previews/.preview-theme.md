This file defines a constant CSS class string used to apply a fixed dark theme to AI-generated preview content, independent of the host application's active theme.

## Key Components

- **`PREVIEW_THEME_CLASS`** — A exported string constant containing the CSS classes (`'ai-preview-theme theme-dark'`) applied to preview containers. It combines a scoping class (`.ai-preview-theme`, defined in `globals.css`) with the core library's `.theme-dark` class to isolate the preview's dark theme from the surrounding app theme.

## Usage Example

```typescript
import { PREVIEW_THEME_CLASS } from './preview-theme';

function PreviewContainer({ children }: { children: React.ReactNode }) {
  return (
    <div className={PREVIEW_THEME_CLASS}>
      {children}
    </div>
  );
}
```

## Notes

- This is **not a user-configurable setting**. The actual theme selection happens client-side in the Fae app; previews rendered before that selection occurs default to this dark theme.
- The scoping approach ensures that applying this class to a preview container does not leak theme styles to the rest of the page, since `.ai-preview-theme` constrains the `.theme-dark` rules to its subtree.
- When modifying preview styling, ensure corresponding rules exist in `globals.css` under the `.ai-preview-theme` scope.
