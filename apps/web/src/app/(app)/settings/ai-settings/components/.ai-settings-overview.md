Shared read-only overview component for the CLIENT AI settings tab, composing the customer card, assistant previews, and quick actions section into a single vertical layout.

## Key Components

### `AiSettingsOverview`
Main exported component that renders a stacked layout of:
- **`AiSettingsCustomerCard`** — displays AI config and client view details
- **`AiSettingsPreviews`** — assistant appearance preview (gated by `customerAiAssistantSettings` feature flag)
- **`AiSettingsQuickActionsSection`** — quick actions table (gated by `customerAiAssistantSettings` feature flag)

### `AiSettingsOverviewProps`
| Prop | Type | Description |
|---|---|---|
| `aiConfig` | `AgentAiConfig` | AI logic config for the active agent |
| `view` | `ClientView` | Client appearance config (CLIENT tab only) |
| `providerModelLabel` | `string` | Resolved display label for the LLM model |
| `quickActions` | `AiQuickAction[]` | List of quick actions to render |
| `quickActionsBanner` | `QuickActionsBannerCopy` | Override for the quick-actions source banner copy |

## Usage Example

```typescript
<AiSettingsOverview
  aiConfig={agentAiConfig}
  view={clientView}
  providerModelLabel="GPT-4o"
  quickActions={actions}
  quickActionsBanner={{
    label: 'Inherited from global config',
  }}
/>
```

## Notes

- Both previews and quick actions are conditionally rendered behind the `featureFlags.customerAiAssistantSettings` flag, marking them as unreleased AI customization features.
- The `quickActionsBanner` override exists specifically for per-customer views, where the banner wording differs from the tenant-level screen.
- This component is `'use client'` and is distinct from the ADMIN/Mingo tab, which uses `AiSettingsAdminCard` instead.
