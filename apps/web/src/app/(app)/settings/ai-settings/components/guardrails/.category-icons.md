Maps guardrail policy category names to their corresponding icon components, used to visually represent categories in the UI (e.g., settings panels for security policy templates).

## Key Components

- **`Icon`** — Internal type alias for an icon component accepting an optional `size` prop.
- **`CATEGORY_ICONS`** — A record mapping category name strings (matching policy template categories from `base-security-policy.json`) to their respective icon components. The first eleven entries correspond to Figma design spec (openframe-settings, 4365-22650).
- **`categoryIcon(category: string): ReactNode | undefined`** — Looks up the icon for a given category name and returns a rendered icon element (size 16) if found, or `undefined` if the category has no mapped icon.

## Usage Example

```typescript
import { categoryIcon } from './category-icons';

function CategoryBadge({ category }: { category: string }) {
  const icon = categoryIcon(category);

  return (
    <div className="flex items-center gap-2">
      {icon ?? <ShieldCheckIcon size={16} />}
      <span>{category}</span>
    </div>
  );
}

// Usage
<CategoryBadge category="File Downloads" /> // renders Download02Icon
<CategoryBadge category="Unknown Category" /> // icon is undefined, falls back to default
```

**Note:** When `categoryIcon` returns `undefined` for an unrecognized category, callers are expected to fall back to a default icon (e.g., a shield icon) as noted in the source documentation.
