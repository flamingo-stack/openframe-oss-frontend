Provides page-level action buttons for the AI Settings page, toggling between "Edit Settings" and "Save Settings" states based on edit mode.

## Key Components

### `useAiSettingsActions(args): PageActionButton[]`
A React hook that returns a memoized array of `PageActionButton` configs consumed by the page header action bar.

| Argument | Type | Description |
|---|---|---|
| `isEditMode` | `boolean` | Controls which action button is shown |
| `onEdit` | `() => void` | Callback to enter edit mode |
| `onSave` | `() => void` | Callback to persist settings |
| `isSaving` | `boolean?` | Shows "Saving..." label and loading state |
| `isSaveDisabled` | `boolean?` | Additional disabled condition beyond `isSaving` |

**Button states:**
- **View mode** — Renders an outlined "Edit Settings" button with a `PenEditIcon`
- **Edit mode** — Renders an accent "Save Settings" button; disabled and shows loading spinner when `isSaving` is `true` or `isSaveDisabled` is `true`

## Usage Example

```typescript
import { useAiSettingsActions } from './ai-settings-actions';

function AiSettingsPage() {
  const [isEditMode, setIsEditMode] = useState(false);
  const [isSaving, setIsSaving] = useState(false);

  const handleSave = async () => {
    setIsSaving(true);
    await saveAiSettings();
    setIsSaving(false);
    setIsEditMode(false);
  };

  const actions = useAiSettingsActions({
    isEditMode,
    onEdit: () => setIsEditMode(true),
    onSave: handleSave,
    isSaving,
    isSaveDisabled: !hasRequiredFields,
  });

  return <PageLayout actions={actions} />;
}
```
