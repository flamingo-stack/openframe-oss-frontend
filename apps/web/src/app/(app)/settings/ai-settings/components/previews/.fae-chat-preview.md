# fae-chat-preview.tsx

Renders a static, interactive preview of the Fae chat assistant window for use in AI settings configuration screens, showing a mid-conversation state with sample chats, a sidebar, and a handoff-to-technician scenario.

## Key Components

- **`FaeChatPreview`** — Main component that renders a mocked Fae chat window (`ChatViewV2`-style layout) using live assistant customization values (`assistantName`, `avatarUrl`, `accentColor`) alongside static sample data (chats, support team, tenant info).
- **`FaeChatPreviewProps`** — Props interface: `assistantName`, `avatarUrl` (optional), `accentColor`, `mspName` (default fallback), and `variant` (`'thumbnail'` scales a 1024×800 window into a card, `'full'` renders 1:1 via `ScaledPreviewFrame`).
- **`SampleChat`** — Internal type describing static sidebar chat entries (`id`, `title`, `ticketNumber`, `status`).
- **`SAMPLE_CHATS`** / **`SAMPLE_SUPPORT_TEAM`** — Hardcoded sample data for the chat list and the "awaiting team" handoff indicator.
- **`trailingMark(status)`** — Helper returning the trailing status icon (`HourglassClockIcon`, `MessageIndicatorIcon`) for a sidebar chat entry based on its status.

The component wires in real tenant data via `useTenantInfo` for the sidebar's organization footer, and responds to viewport width via `useContentMdUp` to mirror the real Fae window's sidebar collapse behavior at narrow widths.

## Usage Example

```typescript
import { FaeChatPreview } from './fae-chat-preview';

export function AiSettingsPreviews() {
  return (
    <FaeChatPreview
      assistantName="Fae"
      avatarUrl="/uploads/fae-avatar.png"
      accentColor="#7C3AED"
      mspName="Acme IT Services"
      variant="thumbnail"
    />
  );
}
```

Use `variant="full"` to render the preview at its native 1024×800 size without the scaling wrapper, typically in a dedicated full-screen preview modal.
