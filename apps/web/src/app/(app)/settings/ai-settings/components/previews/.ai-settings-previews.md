Welcome and chat previews of the Fae window for the AI settings, in Fae's default dark theme (`PREVIEW_THEME_CLASS`;
the theme is not a setting, each client picks it in the Fae app). Both inline forms are thumbnails that open the same
1:1 modal; below `md` a single button opens it instead (the split is CSS, so it follows the viewport).

## Key Components

### `AiSettingsPreviews`

| Prop | Type | Description |
|---|---|---|
| `assistantName` | `string` | The assistant's name. Unread while loading |
| `avatarUrl` | `string` | A custom image; Fae's own server identity picture otherwise |
| `accentColor` | `string` | The accent both previews take. Unread while loading |

While `assistantName` or `accentColor` is unread (or in a loading scope) it draws its loading form: the phone's button
(disabled) and each thumbnail's frame as a skeleton of the Fae window's aspect.

### Internal

- **`MobilePreviewButton`** — The phone's "Preview Assistant" button, one component for both forms (no `onClick`:
  disabled).
- **`ThumbnailTrigger`** — An `inert` preview with an overlay button on top (a `<button>` around the previews' own
  buttons would be invalid HTML).
- The modal (`AiSettingsPreviewModal`) also closes on the Android hardware back (`useNativeBackDismissible`).

## Usage Example

```typescript
<AiSettingsPreviews assistantName={view?.assistantName} avatarUrl={avatarUrl} accentColor={view?.accentColor} />
```
