Renders the MSP logo as a static `<img>` element, bypassing SVG injection so the current accent color does not tint the logo.

## Key Components

- **`ChatPreviewLogoProps`** — Interface accepting an optional `className` string for styling.
- **`ChatPreviewLogo`** — Functional component that renders `/assets/ai-settings/chat-preview-logo.svg` via an `<img>` tag with a decorative (empty) `alt` attribute.

## Usage Example

```typescript
import { ChatPreviewLogo } from './chat-preview-logo';

export function ChatPreviewHeader() {
  return (
    <div className="flex items-center gap-2">
      <ChatPreviewLogo className="h-8 w-auto" />
      <span>AI Settings Preview</span>
    </div>
  );
}
```

> **Note:** The empty `alt=""` marks this as a decorative image, which is intentional — the logo carries no informational content that screen readers need to announce.
