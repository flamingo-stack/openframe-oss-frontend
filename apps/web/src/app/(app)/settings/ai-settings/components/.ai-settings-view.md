## AI Settings View

A client-side React component that renders the AI Settings page with feature-flag-gated tabs (Customer AI Assistant, Mingo AI Chat, Guardrails, Device Guardrails), coordinating data fetching, edit-mode state, and save/sync logic across admin and client AI configurations.

## Key Components

- **`AiSettings`** — Main exported component. Manages:
  - Tab visibility (via `useVisibleAiSettingsTabs`) and deep-linking (`?tab=` / `?edit=true` query params)
  - Tab-scoped data fetching: `useClientAiConfig`/`useClientView` for the `customer` tab, `useAdminAiConfig` for the `mingo` tab — queries are gated so only the active tab fetches
  - Loading/error/offline state derivation per tab, distinguishing "no data yet" from "query paused" (offline) to avoid overwriting real tenant settings with defaults
  - Save orchestration: submits the active tab's `<form>` via `form.requestSubmit()`, using `FORM_ID_BY_TAB` to target the correct form by id
  - Syncing the active LLM provider/model to a separate chat backend (`useUpdateAiConfiguration`) whenever it changes
  - Customer submit flow: parallel saves of AI config and client view (`Promise.allSettled`), followed by avatar commit against the saved view id, with combined toast feedback and cache invalidation
  - Mingo submit flow: saves admin AI config, syncs LLM config, shows toast

- **`FORM_ID_BY_TAB`** — Maps each `AiSettingsTabId` to its form element id for programmatic submission.
- **`ALWAYS_VISIBLE_TABS`** — Tabs shown before feature flags resolve (excludes `device-guardrails`).
- **`isAiSettingsTabId`** — Type guard validating a tab id string against `AI_SETTINGS_TABS`.

## Usage Example

```typescript
// Rendered by a Next.js route/page
import { AiSettings } from './ai-settings-view';

export default function Page() {
  return <AiSettings />;
}
```

Deep-linking into a specific tab in edit mode:

```text
/settings/ai?tab=device-guardrails&edit=true
```

This opens the AI Settings page directly on the **Device Guardrails** tab with the form pre-opened for editing, once the feature-flag-dependent tab set resolves.
