Orchestrates the AI Settings page, managing tab state, data fetching, edit mode, and form submission for the Customer AI Assistant, Mingo AI Chat, and Guardrails configuration tabs.

## Key Components

- **`AiSettings`** — Top-level page component that composes the full AI settings UI, including tab routing, loading/error states, and save logic.

### Notable Behaviors

- **Deep-link support** — Reads `?tab=<id>&edit=true` from the URL to open a specific tab in edit mode on mount.
- **Feature-flag gated tabs** — Visible tabs are filtered via `getVisibleAiSettingsTabs()`; active tab falls back to the first visible one.
- **Lazy data fetching** — Queries for client AI config, client view, and admin AI config are gated by the active tab (`enabled: isCustomer / isMingo`) to avoid unnecessary requests.
- **Avatar commit sequencing** — Avatar upload is deferred until after the client view save resolves to get the persisted record ID, preventing flicker from premature refetches.
- **AI configuration sync** — On save, if the provider or model changed, mirrors the update to the chat backend via `useUpdateAiConfiguration`.
- **Edit mode reset** — Switching tabs or completing a save resets the view to read-only mode.

## Usage Example

```typescript
// Rendered as a Next.js page; no props required.
// Deep-linking to the customer tab in edit mode:
// /settings/ai?tab=customer&edit=true

import { AiSettings } from './ai-settings-view';

export default function AiSettingsPage() {
  return <AiSettings />;
}
```
