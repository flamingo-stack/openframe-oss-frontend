Generates a fixed, read-only sample conversation used to preview the Fae chat window UI, demonstrating message threading, an approved command execution, and a ticket escalation hand-off to a technician.

## Key Components

- **`SAMPLE_USER_NAME`** — Constant name used as the approver on the sample approval request, simulating an end user signing off on a command.
- **`buildFaeChatPreviewMessages(assistantName, avatarUrl?)`** — Builds and returns an array of `Message` objects representing a static, timestamped conversation between a user and the Fae assistant. The conversation demonstrates:
  - Plain text exchanges (user complaint, assistant diagnosis)
  - A composite message with `text` + `approval_request` blocks (showing an approved PowerShell cleanup command)
  - A composite message with `text` + `ticket_escalated` blocks (showing hand-off to a human technician)

All messages share the same fixed timestamp (14:47) so the preview renders consistently regardless of when it's viewed.

## Usage Example

```typescript
import { buildFaeChatPreviewMessages } from './fae-chat-preview-messages';

// Render a static preview of the Fae chat window
const previewMessages = buildFaeChatPreviewMessages('Fae', '/assets/fae-avatar.png');

// Pass to a read-only chat preview component
<ChatPreview messages={previewMessages} />
```

This is typically used in settings/onboarding screens or style guides where a realistic, non-interactive example of the Fae assistant's conversation UI (including approval and escalation states) needs to be displayed without making live backend calls.
