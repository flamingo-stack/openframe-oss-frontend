# guardrails-template-picker.tsx

A client-side React component that renders a radio-button list for selecting a security guardrails policy template, with support for converting stock templates into custom policies. It handles loading states with skeleton placeholders matching the loaded row layout and provides responsive behavior (desktop button vs. mobile actions menu).

## Key Components

- **`GuardrailsTemplateOption`** — Interface describing a template entry: `id`, `label`, optional `description`, and `isCustom` flag.
- **`GuardrailsTemplatePickerProps`** — Props interface: `options` (undefined while loading), `value`, `disabled`, `onSelect` callback, and `onCreateCustomPolicyFrom` callback.
- **`CustomPolicyButton`** — Internal helper component rendering the "Use for Custom Policy" button, reused for both active stock rows and inert loading rows.
- **`LOADING_OPTIONS`** — Precomputed array of skeleton row configs (4 rows, matching `STOCK_TEMPLATE_COUNT`) shown while templates are being fetched.
- **`GuardrailsTemplatePicker`** — Main exported component. Renders a `RadioGroupBlock` with one radio per template. Stock templates show a "Use for Custom Policy" action (button on desktop, dropdown menu on mobile); the custom template row shows an invisible placeholder to preserve column alignment.

## Usage Example

```typescript
import { GuardrailsTemplatePicker, GuardrailsTemplateOption } from './guardrails-template-picker';

const templates: GuardrailsTemplateOption[] = [
  { id: 'autonomous', label: 'Autonomous', description: 'Minimal restrictions', isCustom: false },
  { id: 'balanced', label: 'Balanced', description: 'Recommended defaults', isCustom: false },
  { id: 'custom-1', label: 'My Custom Policy', isCustom: true },
];

function PolicyTemplateField() {
  const [selected, setSelected] = useState('balanced');

  return (
    <GuardrailsTemplatePicker
      options={templates}
      value={selected}
      onSelect={setSelected}
      onCreateCustomPolicyFrom={baseId => {
        // Navigate to custom policy editor, seeded from `baseId`
        console.log('Create custom policy from', baseId);
      }}
    />
  );
}
```

Pass `options={undefined}` (or omit it) to display loading skeleton rows automatically, or rely on `useLoadingScope()` context to trigger the same skeleton state implicitly.
