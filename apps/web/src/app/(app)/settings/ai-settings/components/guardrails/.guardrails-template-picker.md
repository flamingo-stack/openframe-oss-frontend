A client-side radio-group component for selecting guardrails policy templates in edit mode. Stock (non-custom) template rows include a responsive "Use for Custom Policy" action — a visible button on desktop and a collapsed actions menu on mobile.

## Key Components

### `GuardrailsTemplateOption`
Exported interface describing a template option:
- `id` — unique identifier
- `label` — display name
- `description` — optional detail text
- `isCustom` — controls whether the "Use for Custom Policy" action is rendered

### `GuardrailsTemplatePicker`
Main exported component. Props:
- `options` — array of `GuardrailsTemplateOption`
- `value` — currently selected template ID
- `disabled` — disables all interactions
- `onSelect(templateId)` — called when a radio option changes
- `onCreateCustomPolicyFrom(baseTemplateId)` — called when the user opts to create a custom policy from a stock template

Renders a `RadioGroupBlock` (grouped variant). For each stock template (`isCustom: false`), a responsive trailing action is injected:
- **Desktop (`md:`)** — `Button` with `Filter03HrIcon`
- **Mobile** — `ActionsMenuDropdown` with the same action collapsed under an ellipsis trigger

Both actions call `e.preventDefault()` + `e.stopPropagation()` to prevent the surrounding radio label from being activated unintentionally.

## Usage Example

```typescript
<GuardrailsTemplatePicker
  options={[
    { id: 'strict', label: 'Strict', description: 'High restriction', isCustom: false },
    { id: 'custom-1', label: 'My Policy', isCustom: true },
  ]}
  value="strict"
  onSelect={(id) => setSelectedTemplate(id)}
  onCreateCustomPolicyFrom={(baseId) => openCustomPolicyDialog(baseId)}
/>
```
