# preview-accent.ts

Generates a CSS custom properties object for previewing a custom accent color, mirroring the same accent variables that the Fae chat window applies via `useApplyAiAppearance({ chatV2: true })`. This allows a preview UI to recolor accent buttons, onboarding dots/tiles, the selected chat row, tinted backgrounds, and the corner glow exactly as the live chat would.

## Key Components

- **`previewAccentStyle(accentColor)`** — The sole exported function. Takes an optional accent color string and returns a `CSSProperties` object populated with CSS custom properties (`--ods-accent`, `--color-accent-primary`, `--color-accent-hover`, etc.).
  - Returns an empty object if no `accentColor` is provided.
  - Uses `HEX_PATTERN` to detect valid 6-digit hex colors.
  - For hex colors, derives `hover`/`active` shades via `deriveHoverColor` / `deriveActiveColor`, and computes a readable text color via `getReadableTextColor` for `--color-text-on-accent`.
  - For non-hex colors (e.g., CSS color names or functions), hover/active fall back to the same accent value, and the derived text-on-accent variable is omitted.
  - `--color-accent-secondary` is always computed using `color-mix(in srgb, ...)` blended with `var(--color-bg)` so it adapts to the previewed theme's background.

## Usage Example

```typescript
import { previewAccentStyle } from './preview-accent';

function AccentPreview({ accentColor }: { accentColor?: string }) {
  return (
    <div style={previewAccentStyle(accentColor)} className="preview-root">
      <button className="accent-button">Preview Button</button>
    </div>
  );
}

// With a hex color: derives hover/active shades and readable text color
previewAccentStyle('#ff4d6d');

// With a non-hex value: base tokens are recolored, no derived shades
previewAccentStyle('rebeccapurple');

// No value: returns {}
previewAccentStyle(undefined);
```

This is typically applied to a wrapper element's inline `style` so that CSS variables cascade into child components using the standard accent tokens.
