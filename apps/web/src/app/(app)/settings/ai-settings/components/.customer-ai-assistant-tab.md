# customer-ai-assistant-tab.tsx

React component implementing the "Customer AI Assistant" settings tab, supporting both a read-only overview mode and an editable form mode for configuring a client-facing AI assistant (name, avatar, LLM provider/model, answer style, accent color, and quick actions).

## Key Components

- **`CustomerAiAssistantTab`** — Top-level exported component. Handles the loading state (when `aiConfig`/`view` are not yet available) by rendering a skeleton via `LoadingWhen`, showing either the loading editor or the read-only overview depending on `isEditMode`. Delegates to `CustomerAiAssistantTabContent` once data is ready.
- **`CustomerAiAssistantTabContent`** — Internal component that wires up the form (via `useCustomerAiAssistantForm`), fetches supported LLM models (`useSupportedModels`), and resolves default quick actions from the Product Hub (`useHubDefaultQuickActions`). Renders `AiSettingsOverview` in view mode or `CustomerAiAssistantEditor` in edit mode.
- **`CustomerAiAssistantLoadingEditor`** — Renders an unseeded form instance so the editor's fields can display their own loading states while configuration data is still being fetched.
- **`CustomerAiAssistantEditor`** — The actual form UI: assistant name input, avatar uploader, LLM provider/model fields, accent color picker, live previews (`AiSettingsPreviews`), answer style fields, and the quick actions editor.
- **`CUSTOMER_AI_ASSISTANT_FORM_ID`** — Re-exported constant used to associate the `<form>` element with an external submit button.

## Usage Example

```typescript
import { CustomerAiAssistantTab, CUSTOMER_AI_ASSISTANT_FORM_ID } from './customer-ai-assistant-tab';

function SettingsPage() {
  const [isEditMode, setIsEditMode] = useState(false);
  const { aiConfig, view } = useFetchedAiSettings(); // app-specific data hook

  return (
    <>
      <CustomerAiAssistantTab
        aiConfig={aiConfig}
        view={view}
        isEditMode={isEditMode}
        onSubmit={(payload, commitAvatar) => {
          // persist payload, then commitAvatar() to finalize avatar upload
          saveAiConfig(payload).then(commitAvatar);
        }}
      />
      {isEditMode && (
        <button type="submit" form={CUSTOMER_AI_ASSISTANT_FORM_ID}>
          Save
        </button>
      )}
    </>
  );
}
```
