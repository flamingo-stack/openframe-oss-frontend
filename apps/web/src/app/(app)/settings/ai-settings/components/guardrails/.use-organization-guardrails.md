# use-organization-guardrails.ts

React hooks for managing per-organization AI-agent guardrails (approval policies) via the ai-agent GraphQL API. Supports fetching the effective guardrail view (either inherited tenant defaults or a materialized org-specific policy), updating an organization's policy from a template with overrides, and resetting an organization back to inheriting tenant defaults.

## Key Components

- **`organizationGuardrailsQueryKeys`** — React Query key factory for organization guardrails cache entries.
- **`GUARDRAIL_RULE_FIELDS`** — Shared GraphQL fragment string for guardrail rule fields.
- **`GuardrailRuleGql`** / **`OrganizationGuardrailsGql`** — Raw GraphQL response shapes (nullable descriptive fields).
- **`OrganizationGuardrails`** — Normalized result type exposed to consumers, with `rules: PolicyRule[]`.
- **`toPolicyRule(rule)`** — Converts a raw `GuardrailRuleGql` into a `PolicyRule`, coercing `null` fields to empty strings.
- **`useOrganizationGuardrails(organizationId, options)`** — Query hook returning `{ guardrails, isLoading, error, refetch }`.
- **`OrganizationGuardrailsInput`** — Mutation input: `templateId` plus an `overrides` array of `{ naturalKey, approvalLevel }`.
- **`useUpdateOrganizationGuardrails(organizationId)`** — Mutation hook to materialize an org's guardrails from a template + overrides; returns `{ update, isPending }`.
- **`useResetOrganizationGuardrails(organizationId)`** — Mutation hook to reset an org to inherit tenant defaults; returns `{ reset, isPending }`.

Both mutations invalidate the `organizationGuardrailsQueryKeys.detail(organizationId)` cache entry on success. Error/success UI feedback is the caller's responsibility.

## Usage Example

```typescript
function OrganizationGuardrailsPanel({ organizationId }: { organizationId: string }) {
  const { guardrails, isLoading, error } = useOrganizationGuardrails(organizationId);
  const { update, isPending: isSaving } = useUpdateOrganizationGuardrails(organizationId);
  const { reset, isPending: isResetting } = useResetOrganizationGuardrails(organizationId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  const handleSave = async () => {
    await update({
      templateId: 'tpl_strict_ops',
      overrides: [{ naturalKey: 'shell.exec', approvalLevel: 'REQUIRE_APPROVAL' }],
    });
  };

  return (
    <div>
      <p>Inherits default: {guardrails?.inheritDefault ? 'Yes' : 'No'}</p>
      <button onClick={handleSave} disabled={isSaving}>Save Customer</button>
      <button onClick={() => reset()} disabled={isResetting}>Reset to Default</button>
    </div>
  );
}
```
