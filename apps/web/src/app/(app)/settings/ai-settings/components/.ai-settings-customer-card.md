# ai-settings-customer-card.tsx

A React client component that renders a read-only summary card displaying a customer's AI assistant configuration (assistant identity, LLM provider settings, and accent color) in a responsive grid layout with built-in loading-state skeletons.

## Key Components

- **`AiSettingsCustomerCard`** — Main component rendering a grid of info cells for a client's AI configuration. Accepts optional `aiConfig`, `view`, and `providerModelLabel` props; treats missing data as a loading state.
- **`AiSettingsCustomerCardProps`** — Props interface: `aiConfig` (`AgentAiConfig`), `view` (`ClientView`), `providerModelLabel` (display name override for the backend model).
- **`cellClass(idx, count)`** — Helper computing per-cell border/span classes so the last cell spans the full row in both 2-column and 4-column grid breakpoints.
- **`GRID_CLASS`** — Shared grid container styling constant.

## Usage Example

```typescript
import { AiSettingsCustomerCard } from './ai-settings-customer-card';

function ClientAiSettingsPanel({ clientView, aiConfig }: Props) {
  return (
    <AiSettingsCustomerCard
      aiConfig={aiConfig}
      view={clientView}
      providerModelLabel="GPT-4 Turbo"
    />
  );
}

// While data is loading, omit aiConfig/view to show skeleton placeholders
function LoadingState() {
  return <AiSettingsCustomerCard />;
}
```

The component composes shared `InfoCell` (label/value with skeleton loading) and `EntityImage` (avatar with fallback to Fae's default identity icon) components. It derives loading state from `useLoadingScope()` combined with missing `aiConfig`/`view` data, ensuring consistent skeleton rendering across the card until real data resolves.
