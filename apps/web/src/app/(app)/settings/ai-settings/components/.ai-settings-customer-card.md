A read-only summary card that displays an AI agent's configuration and client branding settings in a responsive grid layout.

## Key Components

### `AiSettingsCustomerCard`
The primary export — a presentational card component rendering six labeled cells:

| Cell | Data Source |
|---|---|
| Assistant avatar + name | `view.assistantAvatar`, `view.assistantName` |
| LLM Provider | `aiConfig.llmProvider` (icon + label) |
| Provider Model | `aiConfig.providerModel` / `providerModelLabel` |
| Answer Style | `aiConfig.answerStyle` |
| Application Theme | `view.applicationTheme` |
| Accent Color | `view.accentColor` |

### `AiSettingsCustomerCardProps`
| Prop | Type | Description |
|---|---|---|
| `aiConfig` | `AgentAiConfig` | AI/LLM configuration (provider, model, answer style) |
| `view` | `ClientView` | Client branding (avatar, theme, accent color) |
| `providerModelLabel` | `string?` | Human-readable label for the backend model name |

## Usage Example

```typescript
<AiSettingsCustomerCard
  aiConfig={{
    llmProvider: 'openai',
    providerModel: 'gpt-4o',
    answerStyle: 'concise',
  }}
  view={{
    assistantName: 'Fae',
    assistantAvatar: { imageUrl: '/avatars/fae.png', hash: 'abc123' },
    applicationTheme: 'light',
    accentColor: '#6366f1',
  }}
  providerModelLabel="GPT-4o"
/>
```

## Notes

- Falls back to `FAE_AVATAR_DATA_URI` when no custom avatar is configured, ensuring visual consistency with the AI settings previews.
- Grid adapts from 2 columns (mobile) → 4 columns (`lg:` breakpoint).
- Bottom borders are applied to all cells except the last two (final row) via the `cn` utility conditional.
