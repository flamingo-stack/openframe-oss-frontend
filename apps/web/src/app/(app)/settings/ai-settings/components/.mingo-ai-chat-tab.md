Configuration tab component for Mingo AI Chat settings, rendering either a read-only admin card view or an editable form for LLM provider, answer style, and quick actions.

## Key Components

- **`MingoAiChatTab`** — Main export. Conditionally renders view or edit mode based on `isEditMode` prop.
- **`MINGO_AI_CHAT_FORM_ID`** — Re-exported form ID constant for external form submission triggers.
- **`MingoAiChatTabProps`** — Interface accepting `aiConfig`, `isEditMode`, and `onSubmit` callback.

### View Mode
Renders `AiSettingsAdminCard` with the resolved provider/model label alongside `AiSettingsQuickActionsSection`, respecting whether quick actions are custom or hub defaults.

### Edit Mode
Renders a controlled `react-hook-form` form (validated via Zod) with:
- `AiProviderModelFields` — LLM provider/model selection
- `AiAnswerStyleFields` — Response style configuration
- `AiSettingsQuickActionsEditor` — Quick actions customization seeded from hub defaults

## Usage Example

```typescript
import { MingoAiChatTab, MINGO_AI_CHAT_FORM_ID } from './mingo-ai-chat-tab';

// Attach external submit button using the exported form ID
<button type="submit" form={MINGO_AI_CHAT_FORM_ID}>Save</button>

<MingoAiChatTab
  aiConfig={currentAgentConfig}
  isEditMode={isEditing}
  onSubmit={(input: AgentAiConfigInput) => {
    await saveAgentAiConfig(input);
  }}
/>
```
