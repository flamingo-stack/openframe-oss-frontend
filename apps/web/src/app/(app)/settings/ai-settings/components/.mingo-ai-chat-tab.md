# mingo-ai-chat-tab.tsx

React component implementing the "Mingo AI Chat" settings tab, supporting both a read-only overview view and an editable configuration form for the Mingo AI assistant's provider/model, answer style, and quick actions.

## Key Components

- **`MingoAiChatTab`** — Top-level exported component. Handles the loading scope: renders a skeleton (overview or editor, depending on `isEditMode`) while `aiConfig` is `null`, then delegates to `MingoAiChatTabContent` once data is available.
- **`MingoAiChatTabContent`** — Initializes the `react-hook-form` instance (seeded from `aiConfig`), fetches supported models and Product Hub default quick actions, and switches between the overview and editor based on `isEditMode`.
- **`MingoAiChatOverview`** — Read-only view combining `AiSettingsAdminCard` (provider/model summary) and `AiSettingsQuickActionsSection` (quick actions list).
- **`MingoAiChatLoadingEditor`** — Renders the editor form in an unseeded/loading state (used before configuration is fetched, if `isEditMode` is true).
- **`MingoAiChatEditor`** — The actual editable form containing provider/model fields, answer style fields, and the quick actions editor.
- **`MINGO_AI_CHAT_FORM_ID`** (re-exported) — Form ID constant used to associate external submit buttons with this form.

## Usage Example

```typescript
import { MingoAiChatTab, MINGO_AI_CHAT_FORM_ID } from './mingo-ai-chat-tab';

function AiSettingsPage() {
  const [aiConfig, setAiConfig] = useState<AgentAiConfig | null>(null);
  const [isEditMode, setIsEditMode] = useState(false);

  const handleSubmit = (input: AgentAiConfigInput) => {
    // Persist updated Mingo AI configuration
    saveAgentAiConfig(input);
  };

  return (
    <>
      <MingoAiChatTab
        aiConfig={aiConfig}
        isEditMode={isEditMode}
        onSubmit={handleSubmit}
      />
      {isEditMode && (
        <button type="submit" form={MINGO_AI_CHAT_FORM_ID}>
          Save
        </button>
      )}
    </>
  );
}
```

**Notes:**
- Pass `aiConfig={null}` to trigger the built-in loading skeleton; the component determines whether to show a loading overview or loading editor based on `isEditMode`.
- Quick actions default to Product Hub values (`hubDefaults`) when `aiConfig.quickActionsIsDefault` is `true`, otherwise custom actions from `aiConfig.quickActions` are used.
