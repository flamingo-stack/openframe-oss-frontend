# use-guardrails-editor.ts

A React hook that manages the in-memory edit session for the Guardrails policy editor, tracking draft changes to approval levels (templates, custom policy edits, or newly derived custom policies) without persisting anything until an explicit save.

## Key Components

- **`GuardrailsDraft`** — union type modeling the three edit states: `template` (stock template selected), `existing-custom` (editing the tenant's saved custom policy), `new-custom` (rebasing/creating a custom policy from a template).
- **`UseGuardrailsEditorArgs`** — hook input; `isEditMode` drives draft creation/teardown.
- **`useGuardrailsEditor(args)`** — main hook. Combines server state from `useGuardrailsTemplates`/`useGuardrailsTemplate` with local draft state to compute the displayed policy groups, available template options, and edit capability.
- **`GuardrailsEditor`** — exported return type of the hook, useful for typing consumers/props.

Returned API includes:
- **Server state**: `hasTemplates`, `activePresetLabel`, `policyGroups`, `isLoading`, `loadError`, `refetch`, `isDetailLoading`, `isTemplateSwitching`.
- **Edit session**: `templateOptions`, `selectedTemplateId`, `canEditRules`, `isSaving`, `selectTemplate`, `createCustomPolicyFrom`, `setPolicyPermission`, `applyCategoryPermission`, `save`.

Notable implementation details:
- Draft is seeded/dropped **during render** (not in effects) to avoid a flash of stale or empty UI when toggling edit mode.
- `save()` guards against double submission via a ref, diffing draft edits against `baseLevels` so only genuine changes become overrides.
- Templates are prefetched while editing so switching the selected template renders instantly from cache.

## Usage Example

```typescript
'use client';

import { useGuardrailsEditor } from './use-guardrails-editor';

function GuardrailsPanel() {
  const [isEditMode, setIsEditMode] = useState(false);
  const editor = useGuardrailsEditor({ isEditMode });

  const handleSave = async () => {
    const success = await editor.save();
    if (success) setIsEditMode(false);
  };

  return (
    <div>
      <p>Active preset: {editor.activePresetLabel}</p>
      {editor.policyGroups && /* render groups, call editor.applyCategoryPermission etc. */ null}
      {isEditMode && (
        <button onClick={handleSave} disabled={editor.isSaving}>
          Save
        </button>
      )}
    </div>
  );
}
```
