## AI Settings Quick Actions Editor

A form editor component for managing AI assistant quick actions (Fae and Mingo), supporting a "use default" toggle that switches between a read-only preview of hub-provided defaults and an editable, reorderable list of custom actions.

## Key Components

- **`AiSettingsQuickActionsEditor<T>`** — Main exported component. Manages a `quickActions` field array and `quickActionsIsDefault` boolean flag via `react-hook-form`. Renders either:
  - A dimmed, read-only preview of `defaultActions` when `quickActionsIsDefault` is `true`.
  - An editable, drag-sortable list of custom quick action cards when `false`, with add/remove/delete-all controls.
- **`QuickActionsDefaultCopy`** — Interface customizing checkbox wording, confirm-dialog text, and whether the preview header reads "OpenFrame" or "Organization" (used by the customer screen to mean "inherit tenant config").
- **`QuickActionCard`** (internal) — Renders a single quick action row (name, instructions, icon picker, drag handle/reorder buttons, delete), adapting its grid layout for desktop drag vs. touch-based up/down reordering.
- **`handleToggle`** (internal) — Seeds editable rows from `defaultActions` on uncheck (only if the array is empty); opens a `ConfirmDialog` before re-enabling defaults (which discards customizations).

## Usage Example

```typescript
import { AiSettingsQuickActionsEditor } from './ai-settings-quick-actions-editor';
import { useForm } from 'react-hook-form';
import type { QuickActionsFormValues } from '../types/quick-action.types';

function MingoSettingsForm() {
  const { control } = useForm<QuickActionsFormValues>({
    defaultValues: { quickActions: [], quickActionsIsDefault: true },
  });

  return (
    <AiSettingsQuickActionsEditor
      control={control}
      title="Assistant Quick Actions"
      agentConfig={{ agentSlug: 'mingo', agentLabel: 'Mingo' }}
      defaultActions={hubDefaultActions}
    />
  );
}
```

Pass `defaultActionsCopy` and `accent` to customize wording and glyph tint for the customer-facing (Fae) screen, where "default" means inheriting the tenant's configured quick actions rather than OpenFrame's curated set.
