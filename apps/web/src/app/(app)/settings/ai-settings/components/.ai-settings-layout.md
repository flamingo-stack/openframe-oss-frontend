Shared layout shell for AI Settings & Guardrails pages, providing a responsive header with a back button, optional action buttons, and a mobile-fixed bottom action bar.

## Key Components

- **`AiSettingsLayout`** — Primary layout wrapper that renders a header with a back navigation button, page title, optional slot for a selector element, and action buttons. Adds a fixed bottom bar on mobile when `mobileBottomActions` is `true`.
- **`ResponsiveAction`** — Internal helper that renders a full-width labeled `Button` on desktop (`md+`) and an icon-only `Button` on mobile, with the mobile variant suppressed when the bottom bar is active.

### Props — `AiSettingsLayoutProps`

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | — | Page content |
| `actions` | `PageActionButton[]` | — | Header / bottom-bar action buttons |
| `selector` | `ReactNode` | — | Optional control (e.g. dropdown) rendered beside actions |
| `mobileBottomActions` | `boolean` | `false` | Moves actions to a fixed bottom bar on mobile; accent buttons sort last |

## Usage Example

```typescript
import { AiSettingsLayout } from '@/components/ai-settings-layout';

export default function AiGuardrailsPage() {
  const [editing, setEditing] = useState(false);

  const actions = editing
    ? [
        { label: 'Cancel', variant: 'outline', onClick: () => setEditing(false) },
        { label: 'Save',   variant: 'accent',  onClick: handleSave },
      ]
    : [
        { label: 'Edit', icon: <EditIcon />, ariaLabel: 'Edit guardrails', onClick: () => setEditing(true) },
      ];

  return (
    <AiSettingsLayout actions={actions} mobileBottomActions={editing}>
      <GuardrailsForm />
    </AiSettingsLayout>
  );
}
```

> **Mobile bottom bar ordering:** When `mobileBottomActions` is `true`, actions are automatically sorted so `outline` (Cancel) renders first and `accent` (Save) renders last, matching the Figma spec regardless of the caller's array order.
