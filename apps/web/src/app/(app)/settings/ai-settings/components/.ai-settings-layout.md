## AI Settings Layout

A responsive page layout wrapper for AI Settings screens, providing a consistent header (back button, title, action buttons/selector) and optional mobile-specific bottom action bar.

## Key Components

- **`AiSettingsLayout`** — Main layout component. Renders a header with a back button (navigates via `useSafeBack` to `routes.settings.root()`), a title ("Guardrails & AI Settings"), an optional `selector` slot, and a list of `actions` (page action buttons). Supports `mobileBottomActions` to move actions into a fixed, full-width bottom bar on mobile instead of icon-only buttons in the header.
- **`AiSettingsLayoutProps`** — Props interface: `children` (page content), `actions` (`PageActionButton[]`), `selector` (optional `ReactNode`, e.g. a dropdown), and `mobileBottomActions` (boolean flag for mobile bottom-bar behavior).
- **`ResponsiveAction`** (internal) — Renders each action as a labeled button on desktop (`md:inline-flex`) and either an icon-only button or nothing on mobile, depending on `hideMobileIcon`.

## Usage Example

```typescript
import { AiSettingsLayout } from '@/components/ai-settings-layout';

function AiSettingsEditPage() {
  const [isSaving, setIsSaving] = useState(false);

  return (
    <AiSettingsLayout
      mobileBottomActions
      actions={[
        { label: 'Cancel', variant: 'outline', onClick: handleCancel },
        { label: 'Save', variant: 'accent', onClick: handleSave, loading: isSaving },
      ]}
      selector={<ModelSelector />}
    >
      <AiSettingsForm />
    </AiSettingsLayout>
  );
}
```

In view mode (single action), omit `mobileBottomActions` so the action renders as an icon-only button in the header on mobile:

```typescript
<AiSettingsLayout
  actions={[{ label: 'Edit', variant: 'accent', icon: <PencilIcon />, onClick: handleEdit }]}
>
  <AiSettingsDetails />
</AiSettingsLayout>
```
