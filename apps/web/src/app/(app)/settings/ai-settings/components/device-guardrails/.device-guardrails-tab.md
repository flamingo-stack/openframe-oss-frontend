# device-guardrails-tab.tsx

Implements the "Device Guardrails" tab within the AI Settings page, allowing tenants to view and edit their default remote access permission mode. It toggles between a read-only policy card and an editable form based on the shared AI Settings edit mode, coordinating save behavior through a shared form ID.

## Key Components

- **`DEVICE_GUARDRAILS_FORM_ID`** — Exported constant used by the parent `AiSettingsLayout` to trigger form submission externally via its Save action.
- **`DeviceGuardrailsTab`** — Main exported component. Fetches the tenant's remote access policy (`useTenantRemoteAccessPolicy`), handles loading/error states via `LoadingWhen`/`LoadError`, and renders either the form or the read-only card depending on `isEditMode`.
- **`DeviceGuardrailsPolicyCard`** — Internal read-only view rendering the current mode via `PolicyValueCard`.
- **`DeviceGuardrailsForm`** — Internal editable form using `react-hook-form` + `zod` validation. Renders a `Select` bound to `mode`, submits via `useUpdateTenantRemoteAccessPolicy`, and shows a toast on success/failure.
- **`deviceGuardrailsSchema`** — Zod schema validating that `mode` is one of `REMOTE_ACCESS_MODES`. Other policy fields (timeouts, fallback settings) are fixed backend constants not exposed in this form.

## Usage Example

```typescript
import { useState } from 'react';
import {
  DeviceGuardrailsTab,
  DEVICE_GUARDRAILS_FORM_ID,
} from '@/app/(app)/ai-settings/components/device-guardrails-tab';

function AiSettingsDeviceGuardrailsPanel() {
  const [isEditMode, setIsEditMode] = useState(false);

  return (
    <div>
      <DeviceGuardrailsTab
        isEditMode={isEditMode}
        onSaved={() => setIsEditMode(false)}
      />

      {isEditMode && (
        <button type="submit" form={DEVICE_GUARDRAILS_FORM_ID}>
          Save
        </button>
      )}
    </div>
  );
}
```

The component is designed to stay mounted across loading/edit-mode transitions (no remounting on data fetch), so loading states render as inline bars on the `Select`/`PolicyValueCard` rather than full-page spinners.
