Resolves an `ApplicationTheme` value (`'LIGHT'`, `'DARK'`, or `'SYSTEM'`) to a concrete `'light' | 'dark'` string, with live tracking of the OS-level `prefers-color-scheme` media query when the theme is set to `SYSTEM`.

## Key Components

- **`ResolvedTheme`** — Exported union type `'dark' | 'light'` representing the concrete resolved value.
- **`useResolvedTheme(theme)`** — React hook that maps an `ApplicationTheme` to a `ResolvedTheme`. Subscribes to `window.matchMedia('(prefers-color-scheme: light)')` and updates reactively on OS theme changes. Defaults to `'dark'` during SSR.

## Usage Example

```typescript
import { useResolvedTheme } from './use-resolved-theme';
import type { ApplicationTheme } from '../../types/ai-settings';

function ThemedComponent({ theme }: { theme: ApplicationTheme }) {
  const resolvedTheme = useResolvedTheme(theme);

  return (
    <div data-theme={resolvedTheme}>
      Currently using: {resolvedTheme} mode
    </div>
  );
}
```

## Behavior

| `ApplicationTheme` | Result |
|---|---|
| `'LIGHT'` | Always `'light'` |
| `'DARK'` | Always `'dark'` |
| `'SYSTEM'` | Follows OS `prefers-color-scheme`; defaults to `'dark'` on SSR |

**Notes:**
- Marked `'use client'` — Next.js client component only; safe on SSR (returns `'dark'` until hydration).
- The `matchMedia` listener is cleaned up automatically on unmount.
