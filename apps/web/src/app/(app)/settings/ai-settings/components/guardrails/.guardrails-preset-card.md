Displays a read-only summary card showing the current "Guardrails Preset" policy value, built on top of the shared `PolicyValueCard` component.

## Key Components

- **`GuardrailsPresetCardProps`** — Props interface:
  - `label?: string` — the preset name to display; left unset while the value is loading.
  - `muted?: boolean` — when `true`, renders the value in a muted style to indicate it is inherited from tenant defaults (defaults to `false`).
- **`GuardrailsPresetCard`** — Client component (`'use client'`) that renders a `PolicyValueCard` with a fixed label of `"Guardrails Preset"`, passing through the `label` as `value` and the `muted` flag.

## Usage Example

```vue
<!-- Example usage within a parent React/Next.js component -->
<script setup lang="ts">
import { GuardrailsPresetCard } from '@/app/components/shared/guardrails-preset-card';
</script>
```

```typescript
// Typical usage in a .tsx file
import { GuardrailsPresetCard } from '@/app/components/shared/guardrails-preset-card';

// While loading (no preset value yet) — renders a placeholder bar
<GuardrailsPresetCard />

// Preset inherited from tenant defaults — rendered with muted styling
<GuardrailsPresetCard label="Standard" muted />

// Preset explicitly set on this entity
<GuardrailsPresetCard label="Strict" />
```

This component is intended for summary/overview panels where policy settings are displayed in a consistent, read-only card format alongside other `PolicyValueCard`-based summaries.
