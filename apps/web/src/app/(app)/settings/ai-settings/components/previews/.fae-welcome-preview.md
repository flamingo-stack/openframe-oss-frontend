# fae-welcome-preview.tsx

Renders a live preview of the Fae AI assistant's onboarding carousel, mirroring the `OnboardingScreen` experience shown in the actual openframe-chat widget. Used in admin settings to let users preview how the onboarding flow will appear to clients with their configured assistant name, avatar, and accent color.

## Key Components

- **`FaeWelcomePreview`** — Main component that renders a four-step onboarding carousel (`meet`, `describe`, `ticket`, `anytime`) introducing the AI assistant's capabilities.
- **`FaeWelcomePreviewProps`** — Props interface:
  - `assistantName` — Display name for the assistant, used as avatar fallback and alt text.
  - `avatarUrl` — Optional avatar image source.
  - `accentColor` — Theme accent color applied via `previewAccentStyle`.
  - `onComplete` — Callback fired on the final step's "Start Chat" action (only wired in `full` variant).
  - `variant` — `'thumbnail'` (scaled-down, inert preview) or `'full'` (1:1 interactive rendering).

The component builds an array of `OnboardingCarouselStep` objects (icons from `icons-v2`, first step uses `SquareAvatar`) and passes them to `OnboardingCarousel`. Layout differs between variants: `thumbnail` wraps content in `ScaledPreviewFrame` with fixed height; `full` allows scrolling (`min-h-full`, `overflow-y-auto`) so short panes don't compress the carousel cards.

## Usage Example

```typescript
import { FaeWelcomePreview } from './fae-welcome-preview';

// Thumbnail preview (e.g., inside AiSettingsPreviews card)
<FaeWelcomePreview
  assistantName="Fae"
  avatarUrl="/avatars/fae.png"
  accentColor="#6366F1"
  variant="thumbnail"
/>

// Full interactive preview with completion handler
<FaeWelcomePreview
  assistantName="Fae"
  avatarUrl="/avatars/fae.png"
  accentColor="#6366F1"
  variant="full"
  onComplete={() => router.push('/chat')}
/>
```
