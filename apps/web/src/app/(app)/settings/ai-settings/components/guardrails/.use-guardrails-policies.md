# use-guardrails-policies.ts

React Query data layer for managing tenant-scoped guardrails policy templates via the ai-agent GraphQL API. It provides hooks to list policy templates, fetch a template's detailed rules, prefetch templates for instant switching, activate a template, and save custom policy overrides.

## Key Components

- **`guardrailsQueryKeys`** — Query key factory for templates list and individual template detail queries.
- **`useGuardrailsTemplates()`** — Fetches all policy templates (stock templates first, custom policy last), and derives `activeTemplateId` and `customTemplate`.
- **`useGuardrailsTemplate(templateId)`** — Fetches a single template's full rule set. Uses `keepPreviousData` so the UI shows stale rules during a switch (`isSwitching`) rather than flashing a skeleton.
- **`usePrefetchGuardrailsTemplates(templateIds, enabled)`** — Prefetches multiple templates' details in the background (e.g., when a picker UI is opened) for instant switching.
- **`useActivateGuardrailsTemplate()`** — Mutation to activate a policy template; invalidates both guardrails and organization-guardrails caches (since orgs inheriting defaults are affected) and shows success/error toasts.
- **`useSaveCustomGuardrailsPolicy()`** — Mutation to save custom policy overrides (natural key → approval level map); same cache invalidation and toast behavior.

**Note:** View-model `id`/`templateId` values are the raw `policyId` (not the Relay global `GuardrailPolicy.id`), since they're compared against `OrganizationGuardrails.sourceTemplate`.

## Usage Example

```typescript
function PolicyTemplatesPanel() {
  const { templates, activeTemplateId, isLoading } = useGuardrailsTemplates();
  const { activate, isPending } = useActivateGuardrailsTemplate();

  usePrefetchGuardrailsTemplates(
    templates.map(t => t.id),
    !isLoading,
  );

  const { template, isSwitching } = useGuardrailsTemplate(activeTemplateId);

  const { saveCustomPolicy } = useSaveCustomGuardrailsPolicy();

  const handleActivate = (templateId: string) => activate(templateId);

  const handleSaveOverrides = (overrides: Record<string, ApprovalLevel>) =>
    saveCustomPolicy({ templateId: activeTemplateId ?? '', overrides });

  return isLoading || isSwitching ? <Skeleton /> : <TemplateRulesList template={template} />;
}
```
