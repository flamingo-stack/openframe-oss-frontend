React Query data layer for guardrails policy templates, providing hooks to fetch, activate, and save AI guardrails policies against the `/chat/api/v1/policies` tenant-scoped API.

## Key Components

### `guardrailsQueryKeys`
Structured query key factory for cache management:
- `all` — base key for all guardrails queries
- `templates()` — key for the full template list
- `template(id)` — key for a single template by ID

### `useGuardrailsTemplates()`
Fetches all policy template summaries, sorted with stock templates first and the custom policy last. Returns `templates`, `activeTemplateId`, `customTemplate`, loading state, and error.

### `useGuardrailsTemplate(templateId)`
Fetches full detail for a single policy template by ID. Query is skipped when `templateId` is `null`.

### `useActivateGuardrailsTemplate()`
Mutation to activate a policy template via POST. Invalidates all guardrails queries on success and shows a success/error toast.

### `useSaveCustomGuardrailsPolicy()`
Mutation to upsert the tenant's custom policy via PUT. Invalidates all guardrails queries on success and shows a success/error toast.

## Usage Example

```typescript
// List templates and activate one
const { templates, activeTemplateId, isLoading } = useGuardrailsTemplates();
const { activate, isPending } = useActivateGuardrailsTemplate();

await activate(templateId);

// Save the tenant's custom policy
```
