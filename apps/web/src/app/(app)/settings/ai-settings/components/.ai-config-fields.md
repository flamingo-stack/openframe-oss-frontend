# ai-config-fields.tsx

Reusable React Hook Form field groups for configuring AI logic settings — provider/model selection and answer-style preferences. These components are designed to be composed independently within different host forms (e.g., customer-specific AI settings tabs) rather than rendered as a single monolithic block.

## Key Components

- **`AiProviderModelFields<T>`** — Renders two side-by-side `Select` controls for choosing an LLM provider and its corresponding model. The model options list is dynamically filtered based on the currently selected provider via `modelsByProvider`. Calls `onProviderChange` whenever the provider changes, typically used to reset the dependent model field.
- **`AiAnswerStyleFields<T>`** — Renders a grouped radio selection for `answerStyle` (using `ANSWER_STYLE_OPTIONS`), plus a conditionally rendered `Textarea` for a custom prompt when the style is `CUSTOM`.

Both components are generic over `T extends AiLogicFormValues & FieldValues`, allowing them to be embedded in larger host forms while internally narrowing `Control<T>` to `Control<AiLogicFormValues>` for type-safe field registration (`llmProvider`, `providerModel`, `answerStyle`, `customPrompt`).

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import {
  AiProviderModelFields,
  AiAnswerStyleFields,
} from './ai-config-fields';
import type { AiLogicFormValues } from '../types/ai-logic.types';
import { useSupportedModels } from '../hooks/use-supported-models';

function AiSettingsForm() {
  const { control, watch, resetField } = useForm<AiLogicFormValues>();
  const { modelsByProvider } = useSupportedModels();
  const llmProvider = watch('llmProvider');
  const answerStyle = watch('answerStyle');

  return (
    <form>
      <AiProviderModelFields
        control={control}
        llmProvider={llmProvider}
        modelsByProvider={modelsByProvider}
        onProviderChange={() => resetField('providerModel')}
        providerLabel="Mingo LLM Provider"
      />

      <AiAnswerStyleFields control={control} answerStyle={answerStyle} />
    </form>
  );
}
```

**Notes:**
- Requires `llmProvider` and `answerStyle` to be watched externally and passed in, since these components don't manage their own watch subscriptions.
- `modelsByProvider` may be `undefined` during loading; the component safely defaults to an empty options array.
- Depends on shared UI primitives (`Select`, `RadioGroupBlock`, `Textarea`) and icon/label maps from `ai-settings-display` utils.
