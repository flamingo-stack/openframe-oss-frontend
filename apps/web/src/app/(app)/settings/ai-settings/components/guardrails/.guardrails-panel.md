Renders the tenant-level AI guardrails panel for the AI Settings tab, displaying either a read-only preset summary or an edit-mode template picker alongside grouped policy rules.

## Key Components

- **`GuardrailsPanel`** — Main export. Orchestrates loading/error/empty states and composes child components based on `isEditMode` and editor state.
- **`GuardrailsPanelProps`** — Interface accepting an `editor` (`GuardrailsEditor`) and `isEditMode` boolean flag.

## Rendering States

| State | Output |
|---|---|
| Loading | Two `Skeleton` placeholders |
| Load error | `LoadError` with retry callback |
| No templates | `EmptyState` with shield icon |
| Ready (view) | Info banner + `GuardrailsPresetCard` + policy groups |
| Ready (edit) | Info banner + `GuardrailsTemplatePicker` + policy groups |

## Usage Example

```typescript
import { GuardrailsPanel } from './guardrails-panel';
import { useGuardrailsEditor } from './use-guardrails-editor';

export function GuardrailsTab() {
  const editor = useGuardrailsEditor();
  const [isEditMode, setIsEditMode] = useState(false);

  return (
    <GuardrailsPanel
      editor={editor}
      isEditMode={isEditMode}
    />
  );
}
```

> **Note:** For per-organization guardrails (customer details page), compose `GuardrailsPresetCard` and `GuardrailsPolicyGroups` directly over organization-scoped GraphQL data — see `customer-guardrails-tab.tsx`. This panel is scoped to tenant-level defaults only.
