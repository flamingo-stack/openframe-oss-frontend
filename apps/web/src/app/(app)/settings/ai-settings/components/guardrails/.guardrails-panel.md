# guardrails-panel.tsx

Renders the tenant-level (default/global) Guardrails panel in the AI Settings guardrails tab, showing either a read-only preset summary or an editable template picker, followed by grouped policy rules.

## Key Components

- **`GuardrailsPanel`** — Default export, a client component (`'use client'`) that orchestrates loading, error, and empty states around the guardrails editing experience.
  - **Props:**
    - `editor: GuardrailsEditor` — Editor state/actions from `use-guardrails-editor` (templates, policy groups, loading flags, mutation handlers).
    - `isEditMode: boolean` — Toggles between the read-only `GuardrailsPresetCard` and the editable `GuardrailsTemplatePicker`.
  - **Behavior:**
    - Uses `useLoadingScope()` combined with `editor.isLoading` to coordinate skeleton rendering via `LoadingWhen`.
    - Shows `LoadError` with a retry action if the template fetch fails.
    - Shows `EmptyState` if no policy templates exist.
    - Renders a fixed info banner ("Default settings for all customers").
    - Animates the swap between preset card and template picker using keyed `fade-in` transitions.
    - Nests a second `LoadingWhen` scope for policy rules (independently loading on template switch), showing `NoData` when a template has no rules, otherwise `GuardrailsPolicyGroups`.

## Usage Example

```typescript
import { GuardrailsPanel } from './guardrails-panel';
import { useGuardrailsEditor } from './use-guardrails-editor';

function AiSettingsGuardrailsTab() {
  const editor = useGuardrailsEditor();
  const [isEditMode, setIsEditMode] = useState(false);

  return (
    <GuardrailsPanel editor={editor} isEditMode={isEditMode} />
  );
}
```

**Related:** For per-organization (customer-level) guardrails, see `customer-guardrails-tab.tsx`, which composes `GuardrailsPresetCard` and `GuardrailsPolicyGroups` directly over GraphQL data instead of using this panel.
