Display constants and configuration data for AI settings UI, mapping AI providers, application themes, and answer styles to their human-readable labels, icons, and option descriptors.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `LLM_PROVIDER_LABEL` | `Record<AIProvider, string>` | Maps provider keys to display names |
| `LLM_PROVIDER_ICON` | `Record<AIProvider, IconComponent>` | Maps provider keys to SVG icon components |
| `LLM_PROVIDER_OPTIONS` | `AIProvider[]` | Ordered list of available AI providers |
| `APPLICATION_THEME_LABEL` | `Record<ApplicationTheme, string>` | Maps theme keys to display names |
| `ANSWER_STYLE_LABEL` | `Record<AnswerStyle, string>` | Maps answer style keys to display names |
| `ANSWER_STYLE_OPTIONS` | `AnswerStyleOption[]` | Full option objects with value, label, and description |
| `AnswerStyleOption` | `interface` | Shape for answer style dropdown/selector items |

## Usage Example

```typescript
import {
  LLM_PROVIDER_LABEL,
  LLM_PROVIDER_ICON,
  ANSWER_STYLE_OPTIONS,
} from './ai-settings-display';

// Render provider label and icon
const provider: AIProvider = 'ANTHROPIC';
const label = LLM_PROVIDER_LABEL[provider]; // 'Anthropic'
const Icon = LLM_PROVIDER_ICON[provider];   // ClaudeIcon component

// Render answer style options in a selector
ANSWER_STYLE_OPTIONS.map((option) => (
  <option key={option.value} value={option.value} title={option.description}>
    {option.label}
  </option>
));
```

## Notes

- `LLM_PROVIDER_OPTIONS` defines the display order for provider selectors.
- `AnswerStyleOption.description` provides tooltip/help text for each style choice.
- Icon components are cast via `as unknown as IconComponent` to normalize differing SVG prop signatures from the core icons package.
