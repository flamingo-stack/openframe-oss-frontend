This module defines display metadata (labels, icons, and descriptions) for AI provider and answer style options used in AI settings UI components.

## Key Components

- **`LLM_PROVIDER_LABEL`** — Maps `AIProvider` values (`ANTHROPIC`, `OPENAI`, `GOOGLE_GEMINI`) to human-readable display names.
- **`LLM_PROVIDER_ICON`** — Maps each `AIProvider` to its corresponding `IconRef` for rendering via `<NamedIcon>`.
- **`LLM_PROVIDER_OPTIONS`** — Ordered array of all available `AIProvider` values, useful for populating select/dropdown inputs.
- **`ANSWER_STYLE_LABEL`** — Maps `AnswerStyle` values (`SHORT`, `STANDARD`, `DETAILED`, `CUSTOM`) to display labels.
- **`AnswerStyleOption`** — Interface describing a selectable answer style option with `value`, `label`, and `description`.
- **`ANSWER_STYLE_OPTIONS`** — Array of `AnswerStyleOption` objects providing full metadata (label + descriptive text) for each answer style, suitable for rendering radio groups or selection cards.

## Usage Example

```typescript
import {
  LLM_PROVIDER_LABEL,
  LLM_PROVIDER_ICON,
  LLM_PROVIDER_OPTIONS,
  ANSWER_STYLE_OPTIONS,
} from './ai-settings-display';

// Render a provider dropdown
LLM_PROVIDER_OPTIONS.map((provider) => ({
  label: LLM_PROVIDER_LABEL[provider],
  icon: LLM_PROVIDER_ICON[provider],
}));

// Render answer style selection cards
ANSWER_STYLE_OPTIONS.map(({ value, label, description }) => (
  <AnswerStyleCard key={value} label={label} description={description} />
));
```

This file is purely declarative (no logic) and is typically imported by components that render AI provider selectors and answer style configuration panels within the AI settings feature.
