A Next.js page component that renders the AI Settings configuration view within the settings section of the application.

## Key Components

- **`AiSettingsPage`** — Default page export that mounts the `AiSettings` component, serving as the route entry point for `/settings/ai-settings`.

## Usage Example

```typescript
// Accessed automatically by Next.js App Router at:
// /settings/ai-settings

// The page delegates all rendering to the AiSettings component:
import { AiSettings } from '@/app/(app)/settings/ai-settings/components/ai-settings-view';

export default function AiSettingsPage() {
  return <AiSettings />;
}
```

## Notes

- Marked as a Client Component via `'use client'`, meaning it runs in the browser and supports React hooks/interactivity.
- Acts as a thin wrapper — all logic and UI are encapsulated in [`AiSettings`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/settings/ai-settings/components/ai-settings-view.tsx).
