React Query hooks for fetching and updating tenant-wide AI agent configuration (CLIENT/Fae and ADMIN/Mingo), including LLM provider settings, answer style, custom prompts, and quick actions.

## Key Components

- **`agentAiConfigQueryKeys`** – Query key factory for agent AI config cache entries, keyed by `AgentType`.
- **`toAgentAiConfig`** – Normalizes raw GraphQL response into the `AgentAiConfig` domain type, applying defaults (e.g., `quickActionsIsDefault` defaults to `true`).
- **`fetchAiConfig`** – Internal helper that posts a GraphQL query to `/chat/graphql` and unwraps the response, throwing on transport or GraphQL errors.
- **`useClientAiConfig(options?)`** – Hook to fetch the CLIENT (Fae) AI config; `config` is `null` if unconfigured.
- **`useAdminAiConfig(options?)`** – Hook to fetch the ADMIN (Mingo) AI config; `config` is `null` if unconfigured.
- **`useUpdateClientAiConfig()`** – Mutation hook returning `update`/`isPending` to save CLIENT AI config.
- **`useUpdateAdminAiConfig()`** – Mutation hook returning `update`/`isPending` to save ADMIN AI config.

Both query hooks support an `enabled` option so inactive tabs can skip fetching while still reporting an idle (not loading) state via `queryState`. Both update hooks invalidate the relevant query cache on success; updating the CLIENT config also invalidates all organization-scoped AI config caches, since tenant CLIENT config acts as the effective default for orgs on `inheritDefault`.

## Usage Example

```typescript
import { useAdminAiConfig, useUpdateAdminAiConfig } from './use-agent-ai-config';

function AdminAiSettingsPanel({ isActiveTab }: { isActiveTab: boolean }) {
  const { config, isLoading, isIdle } = useAdminAiConfig({ enabled: isActiveTab });
  const { update, isPending } = useUpdateAdminAiConfig();

  async function handleSave() {
    await update({
      llmProvider: 'OPENAI',
      providerModel: 'gpt-4o',
      answerStyle: 'CONCISE',
      customPrompt: 'Always include step numbers.',
    });
  }

  if (isIdle) return null;
  if (isLoading) return <p>Loading...</p>;

  return (
    <div>
      <p>Provider: {config?.llmProvider ?? 'Not configured'}</p>
      <button onClick={handleSave} disabled={isPending}>
        Save
      </button>
    </div>
  );
}
```
