# use-organization-ai-config.ts

React Query hooks for managing per-organization client AI configuration via the ai-agent GraphQL API (`/chat/graphql`). Handles reading the effective config (tenant defaults or org override), updating overrides, and resetting to inherited defaults — including independent reset of quick actions.

## Key Components

- **`organizationAiConfigQueryKeys`** — Query key factory (`all`, `detail(organizationId)`) for cache management.
- **`OrganizationClientAiConfig`** — Interface describing the effective config: provider, model, answer style, custom prompt, quick actions, and inheritance flags (`inheritDefault`, `quickActionsIsDefault`).
- **`useOrganizationClientAiConfig(organizationId, options?)`** — Fetches the effective AI config for an organization. Returns `{ config, isLoading, error, refetch }`.
- **`useUpdateOrganizationClientAiConfig(organizationId)`** — Mutation that saves an org-specific override (breaks inheritance). Returns `{ update, isPending }`.
- **`useResetOrganizationClientAiConfig(organizationId)`** — Mutation that clears the org's override, restoring tenant-default inheritance. Returns `{ reset, isPending }`.
- **`useResetOrganizationClientAiQuickActions(organizationId)`** — Mutation that clears only the org's quick actions override, re-enabling live tenant sync (`quickActionsIsDefault: true`) while preserving other override fields. Returns `{ resetQuickActions, isPending }`.

All mutations invalidate the `organizationAiConfigQueryKeys.detail(organizationId)` cache on success and delegate user-facing success/error feedback to the calling component.

## Usage Example

```typescript
import {
  useOrganizationClientAiConfig,
  useUpdateOrganizationClientAiConfig,
  useResetOrganizationClientAiConfig,
  useResetOrganizationClientAiQuickActions,
} from './use-organization-ai-config';

function CustomerAiSettings({ organizationId }: { organizationId: string }) {
  const { config, isLoading } = useOrganizationClientAiConfig(organizationId);
  const { update, isPending: isSaving } = useUpdateOrganizationClientAiConfig(organizationId);
  const { reset } = useResetOrganizationClientAiConfig(organizationId);
  const { resetQuickActions } = useResetOrganizationClientAiQuickActions(organizationId);

  const handleSave = async () => {
    await update({
      llmProvider: 'OPENAI',
      providerModel: 'gpt-4o',
      answerStyle: 'CONCISE',
      customPrompt: 'Always greet the customer by name.',
      quickActions: [],
    });
  };

  if (isLoading) return <p>Loading...</p>;

  return (
    <div>
      <p>Inherits tenant default: {config?.inheritDefault ? 'Yes' : 'No'}</p>
      <button onClick={handleSave} disabled={isSaving}>Save Customer Config</button>
      <button onClick={() => reset()}>Reset to Tenant Default</button>
      <button onClick={() => resetQuickActions()}>Use Default Quick Actions</button>
    </div>
  );
}
```
