# use-hub-default-quick-actions.ts

React hook that fetches the Product Hub's default AI quick actions for a given agent, used as a fallback when a tenant hasn't customized its own quick actions list.

It resolves a hub-backed config URL (scoped per agent via `agentSlug`) through the gateway's `/content/**` proxy and transforms the hub's response shape into the app's `AiQuickAction` format. It relies on `CONTENT_BASE` (rather than a hardcoded path) so the URL correctly absolutizes to the tenant gateway in the native (Capacitor) shell while remaining relative on web — this avoids a silent empty-defaults bug caused by `embedAuthedFetch` rejecting non-http(s) URLs.

Caching and request deduplication are handled by the underlying `useEmptyStateConfig` hook, which caches per URL for the session and factors in the current page topic when requesting actions from the hub.

## Key Components

- **`hubAgentConfigUrl(slug)`** — Builds the hub's agent config endpoint URL from `CONTENT_BASE`, keyed by `agent-<slug>`.
- **`useHubDefaultQuickActions(agentSlug, options)`** — Main hook. Fetches and maps hub quick-action config into `AiQuickAction[]`.
  - `agentSlug: string` — identifies which agent's defaults to fetch.
  - `options.enabled?: boolean` — optionally disables the fetch.
  - Returns `{ actions, loading, loaded }`.

## Usage Example

```typescript
import { useHubDefaultQuickActions } from './use-hub-default-quick-actions';

function QuickActionsPanel({ agentSlug, quickActionsIsDefault }: {
  agentSlug: string;
  quickActionsIsDefault: boolean;
}) {
  const { actions, loading, loaded } = useHubDefaultQuickActions(agentSlug, {
    enabled: quickActionsIsDefault,
  });

  if (loading) return <Spinner />;
  if (!loaded) return null;

  return (
    <ul>
      {actions.map(action => (
        <li key={action.id}>{action.name}</li>
      ))}
    </ul>
  );
}
```

Only render/seed these defaults when `quickActionsIsDefault` is `true` — the tenant backend persists only customized lists, never the hub's defaults.
