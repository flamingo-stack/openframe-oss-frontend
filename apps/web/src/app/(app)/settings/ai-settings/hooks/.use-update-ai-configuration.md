Syncs the chat backend's active AI configuration when a user selects a new provider or model in the AI settings UI. Only surfaces error feedback via toast; success state is delegated to the parent settings save flow.

## Key Components

- **`useUpdateAiConfiguration`** — Custom hook wrapping a `useMutation` call that `POST`s to `/chat/api/v1/ai-configuration` with the selected provider and model.
- **`UpdateAiConfigurationInput`** — Internal interface defining the mutation payload: `provider: AIProvider` and `modelName: string`.
- **Error handling** — On failure, displays a destructive toast notification; no success toast is emitted here.
- **No cache invalidation** — Intentionally omitted; model badge state derives from `adminAiConfig`/`organizationClientAiConfig`, which are invalidated by the broader settings save mutations.

## Usage Example

```typescript
import { useUpdateAiConfiguration } from './use-update-ai-configuration';

function AiSettingsForm() {
  const { updateAiConfiguration, isPending } = useUpdateAiConfiguration();

  const handleSave = () => {
    updateAiConfiguration({
      provider: 'openai',
      modelName: 'gpt-4o',
    });
  };

  return (
    <button onClick={handleSave} disabled={isPending}>
      Save AI Configuration
    </button>
  );
}
```

## Notes

- This hook is client-only (`'use client'`).
- `updateAiConfiguration` is the raw `mutate` function — fire-and-forget with no returned promise.
