# use-customer-ai-assistant-form.ts

React hook that manages form state, validation, and avatar handling for the global customer-facing AI assistant configuration screen. It bridges a GraphQL-backed `AgentAiConfig` with a REST-backed `ClientView` avatar, staging avatar changes locally until the parent form save resolves (since a new tenant may not yet have a persisted `ClientView` id).

## Key Components

- **`CommitAvatar`** — Type alias for an async function `(clientViewId: string) => Promise<void>` that flushes a staged avatar change once a valid `ClientView` id exists.
- **`UseCustomerAiAssistantFormOptions`** — Hook input: `aiConfig`, `view` (the `ClientView`), and an `onSubmit` callback receiving the validated payload plus a `commitAvatar` function.
- **`useCustomerAiAssistantForm`** — Main hook, returns:
  - `form` — `react-hook-form` instance (Zod-validated via `customerAiAssistantSchema`).
  - `avatarUrl` — Resolved/staged avatar image URL for preview.
  - `handleAvatarChange(file)` — Stages a new avatar file and shows an object-URL preview.
  - `handleAvatarRemove()` — Stages avatar removal (clears preview; marks for backend deletion if one exists).
  - `handleSubmit(event?)` — Validates the form, builds a `commitAvatar` closure capturing the staged file/removal state at submit time, and invokes `onSubmit`.

The hook also auto-resyncs form defaults when `aiConfig`/`view` change (e.g., after a post-save refetch), while carefully avoiding clobbering an in-flight staged avatar during a parallel config refetch.

## Usage Example

```typescript
import { useCustomerAiAssistantForm } from './use-customer-ai-assistant-form';

function CustomerAiAssistantSettings({ aiConfig, view }: Props) {
  const { form, avatarUrl, handleAvatarChange, handleAvatarRemove, handleSubmit } =
    useCustomerAiAssistantForm({
      aiConfig,
      view,
      onSubmit: async (payload, commitAvatar) => {
        const savedView = await saveAgentAiConfig(payload);
        await commitAvatar(savedView.id);
      },
    });

  return (
    <form onSubmit={handleSubmit}>
      <img src={avatarUrl} alt="Assistant avatar" />
      <input
        type="file"
        onChange={e => e.target.files?.[0] && handleAvatarChange(e.target.files[0])}
      />
      <button type="button" onClick={handleAvatarRemove}>Remove avatar</button>
      <button type="submit">Save</button>
    </form>
  );
}
```
