# use-client-view.ts

React Query hooks for managing the client-facing assistant appearance ("Client View") — a per-organization or tenant-wide configuration of assistant name, avatar, and accent color used by the Fae customer-facing app.

## Key Components

- **`clientViewQueryKeys`** — Query key factory for cache management, scoped by `organizationId`.
- **`withClientViewCreateFields(input, isNewView)`** — Helper that injects a default `applicationTheme: 'DARK'` field only when creating a new view (backend requires it on creation but not on updates).
- **`useClientView(organizationId?, options?)`** — Fetches the client view for a given organization (or the tenant-wide default when `organizationId` is `null`). Returns `{ view, ...queryState, refetch }`.
- **`useUpdateClientView(organizationId?, options?)`** — Mutation hook to create/update a client view. Returns `{ update, isPending }`. Supports opting out of automatic cache invalidation (`invalidateOnSuccess: false`) for callers that need to attach an avatar before refreshing.
- **`useResetClientView(organizationId)`** — Mutation hook to delete an organization's override, reverting it to the tenant default. Returns `{ reset, isPending }`.

All hooks communicate via a GraphQL endpoint (`/chat/graphql`) through `apiClient`, and normalize raw GraphQL responses (`ClientViewGql`) into the app's `ClientView` type via `toClientView`.

## Usage Example

```typescript
import { useClientView, useUpdateClientView, useResetClientView } from './use-client-view';

function ClientAppearanceSettings({ organizationId }: { organizationId: string | null }) {
  const { view, isLoading } = useClientView(organizationId);
  const { update, isPending } = useUpdateClientView(organizationId);
  const { reset } = useResetClientView(organizationId ?? '');

  async function handleSave() {
    const isNewView = view === null;
    await update(
      withClientViewCreateFields(
        { assistantName: 'Fae', accentColor: '#FF6B6B' },
        isNewView,
      ),
    );
  }

  if (isLoading) return null;

  return (
    <div>
      <p>{view?.assistantName ?? 'No custom view set'}</p>
      <button onClick={handleSave} disabled={isPending}>Save</button>
      <button onClick={() => reset()}>Reset to default</button>
    </div>
  );
}
```
