React Query hook and utilities for fetching and resolving AI provider model options from the chat backend's supported-models endpoint.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useSupportedModels` | Hook | Fetches available models grouped by AI provider (`ANTHROPIC`, `OPENAI`, `GOOGLE_GEMINI`) |
| `getProviderModelLabel` | Function | Resolves a model's display name given a specific provider and model name |
| `getModelLabelByName` | Function | Cross-provider model label lookup by model name alone (first match wins) |
| `supportedModelsQueryKey` | Constant | React Query cache key for supported models queries |
| `SupportedModelsByProvider` | Type | `Partial<Record<AIProvider, ProviderModelOption[]>>` |
| `ProviderModelOption` | Interface | `{ value: string; label: string }` select option shape |

## Usage Example

```typescript
import {
  useSupportedModels,
  getProviderModelLabel,
  getModelLabelByName,
} from './use-supported-models';

// In a component — fetch models for all providers
function ModelSelector() {
  const { modelsByProvider, isLoading, error } = useSupportedModels();

  if (isLoading) return <Spinner />;

  // Render options for a specific provider
  const openaiModels = modelsByProvider?.OPENAI ?? [];
  return <Select options={openaiModels} />;
}

// Resolve a stored model name to its display label (provider known)
const label = getProviderModelLabel(modelsByProvider, 'ANTHROPIC', 'claude-opus-4-5');
// → "Claude Opus 4.5" (or raw value as fallback)

// Resolve when only the model name is available (e.g. from stream metadata)
const label = getModelLabelByName(modelsByProvider, 'gpt-4o');
// → "GPT-4o" (searches all providers, first match wins)
```

## Notes

- The `/chat/api/v1/ai-configuration/supported-models` endpoint returns provider keys in lowercase (`anthropic`, `openai`, `google-gemini`); `RESPONSE_KEY_BY_PROVIDER` maps the `AIProvider` enum to those response keys.
- Both label-resolver utilities fall back to the raw `modelName` string when no match is found, making them safe for display in cases where the backend introduces new models before the cache is refreshed.
