A React hook and helpers for fetching AI model options grouped by provider via GraphQL, and resolving model names to human-readable display labels.

## Key Components

- **`useSupportedModels()`** — React Query hook that fetches supported AI models from the `/chat/graphql` endpoint, grouping them by `AIProvider` into `value`/`label` option pairs. Returns `{ modelsByProvider, isLoading, error }`.
- **`supportedModelsQueryKey`** — Exported query key (`['ai-configuration', 'supported-models']`) for cache invalidation/prefetching elsewhere.
- **`ProviderModelOption`** — Interface for a single model option (`value`, `label`).
- **`SupportedModelsByProvider`** — Type mapping each `AIProvider` to its array of `ProviderModelOption`.
- **`getProviderModelLabel(modelsByProvider, provider, modelName)`** — Resolves a model's display label given a known provider; falls back to the raw `modelName` if not found.
- **`getModelLabelByName(modelsByProvider, modelName)`** — Resolves a display label by searching across all providers (useful when only a provider display name, not the `AIProvider` enum, is available); falls back to the raw `modelName`.

## Usage Example

```typescript
import {
  useSupportedModels,
  getProviderModelLabel,
  getModelLabelByName,
} from './use-supported-models';

function ModelSelector({ provider }: { provider: AIProvider }) {
  const { modelsByProvider, isLoading, error } = useSupportedModels();

  if (isLoading) return <p>Loading models...</p>;
  if (error) return <p>Failed to load models</p>;

  const options = modelsByProvider?.[provider] ?? [];

  return (
    <select>
      {options.map(option => (
        <option key={option.value} value={option.value}>
          {option.label}
        </option>
      ))}
    </select>
  );
}

// Resolving a stored model to its label elsewhere in the UI
const label = getProviderModelLabel(modelsByProvider, 'OPENAI', 'gpt-4o');

// When only a model name is known (e.g., from a chat message's metadata)
const fallbackLabel = getModelLabelByName(modelsByProvider, 'gpt-4o');
```

This hook is typically consumed by AI settings forms and chat UI components that need to display friendly model names instead of raw model identifiers.
