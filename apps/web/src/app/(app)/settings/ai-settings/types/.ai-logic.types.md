Defines the shared Zod schema, types, and helper functions for the AI-logic form fields (LLM provider, model, answer style, custom prompt, quick actions) reused by both the CLIENT and ADMIN tabs in the agent AI configuration UI.

## Key Components

- **`aiLogicShape`** – Raw Zod shape object defining shared fields: `llmProvider`, `providerModel`, `answerStyle`, `customPrompt`, `quickActionsIsDefault`, `quickActions`. Exported as `const` so consuming schemas can `.extend()` it.
- **`aiLogicSchema`** – Zod object schema built from `aiLogicShape`.
- **`AiLogicFormValues`** – Inferred TypeScript type from `aiLogicSchema`, representing the form state shape.
- **`requireCustomPrompt(data)`** – Validation helper ensuring `customPrompt` is non-empty when `answerStyle` is `'CUSTOM'`; intended for use in `.refine()` calls.
- **`getAiLogicDefaults(config)`** – Converts an `AgentAiConfig` (API/domain model) into `AiLogicFormValues` for initializing the form. When `quickActionsIsDefault` is true, `quickActions` starts empty (hub-provided actions shown read-only until unchecked).
- **`toAgentAiConfigInput(values)`** – Maps form values back to the GraphQL `AgentAiConfigInput` mutation payload, omitting `customPrompt` unless style is `'CUSTOM'` and omitting `quickActions` when defaults are active (backend owns the list).

## Usage Example

```typescript
import { aiLogicSchema, requireCustomPrompt, getAiLogicDefaults, toAgentAiConfigInput } from './ai-logic.types';

// Extend for a specific tab (e.g., ADMIN tab)
const adminFormSchema = aiLogicSchema
  .extend({ someAdminField: z.string() })
  .refine(requireCustomPrompt, {
    message: 'Custom prompt is required',
    path: ['customPrompt'],
  });

// Initialize form defaults from fetched config
const defaults = getAiLogicDefaults(agentAiConfig);

// On submit, convert form values to GraphQL input
const mutationInput = toAgentAiConfigInput(formValues);
await updateAgentAiConfig({ variables: { input: mutationInput } });
```
