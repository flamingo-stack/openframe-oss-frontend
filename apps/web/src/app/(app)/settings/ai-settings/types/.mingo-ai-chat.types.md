Defines the Zod schema, TypeScript types, and form utilities for the Mingo AI Chat settings form, which manages the full AI logic configuration (provider, model, answer style, custom prompt, and quick actions) for the admin agent.

## Key Components

| Export | Type | Description |
|---|---|---|
| `MINGO_AI_CHAT_FORM_ID` | `string` | HTML form ID constant for the Mingo AI Chat settings form |
| `mingoAiChatSchema` | `ZodObject` | Zod schema built from `aiLogicShape`, with a refinement requiring a non-empty `customPrompt` |
| `MingoAiChatFormValues` | `type` | Inferred TypeScript type from `mingoAiChatSchema` |
| `getMingoAiChatDefaults` | `function` | Maps an `AgentAiConfig` to default form values |
| `toMingoAiChatSubmit` | `function` | Transforms form values into an `AgentAiConfigInput` for submission |

## Usage Example

```typescript
import {
  MINGO_AI_CHAT_FORM_ID,
  mingoAiChatSchema,
  getMingoAiChatDefaults,
  toMingoAiChatSubmit,
  type MingoAiChatFormValues,
} from './mingo-ai-chat.types';

// Initialize form with defaults from existing config
const defaultValues = getMingoAiChatDefaults(agentAiConfig);

// Validate form input
const result = mingoAiChatSchema.safeParse(formValues);
if (!result.success) {
  console.error(result.error); // e.g., "Custom prompt is required"
}

// Transform validated values for API submission
const input: AgentAiConfigInput = toMingoAiChatSubmit(result.data);
await updateAgentAiConfig(input);
```

## Notes

- The schema mirrors the client-facing chat tab but excludes appearance fields (admin-only scope).
- The `requireCustomPrompt` refinement enforces that `customPrompt` is always provided before submission.
- All core AI logic is delegated to shared helpers in [`ai-logic.types.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/types/ai-logic.types.ts).
