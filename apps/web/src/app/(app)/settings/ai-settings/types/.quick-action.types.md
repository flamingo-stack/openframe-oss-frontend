Defines the Zod validation schema and TypeScript types for quick action forms, shared across Customer and Mingo AI settings.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `quickActionSchema` | `z.ZodObject` | Zod schema validating a single quick action with optional `id`, required `name`, and required `instructions` |
| `QuickActionFormValue` | `type` | Inferred type from `quickActionSchema` representing a single quick action entry |
| `QuickActionsFormValues` | `interface` | Form contract for `AiSettingsQuickActionsEditor`, holding an array of quick actions and a default-state flag |

## Usage Example

```typescript
import { quickActionSchema, QuickActionFormValue, QuickActionsFormValues } from './quick-action.types';

// Validate a quick action entry
const result = quickActionSchema.safeParse({
  name: 'Restart Service',
  instructions: 'Restart the target Windows service via RMM.',
});

if (result.success) {
  const action: QuickActionFormValue = result.data;
}

// Use the form values contract in a form hook
const defaultValues: QuickActionsFormValues = {
  quickActions: [
    { id: 'qa-1', name: 'Restart Service', instructions: 'Restart via RMM.' },
  ],
  quickActionsIsDefault: false, // false = show custom editor; true = use hub defaults
};
```

## Notes

- `quickActionsIsDefault: true` hides the editor and defers to hub-level defaults, mirroring `AgentAiConfig.quickActionsIsDefault`.
- The `id` field is optional to support both new (unsaved) and existing quick actions in the same schema.
