Defines the Zod schema and TypeScript types for "Quick Action" entries used in the Customer and Mingo AI settings forms, enabling shared validation and typing across quick-action editing UI components.

## Key Components

- **`quickActionSchema`** — Zod object schema validating a quick action's shape: optional `id`, required non-empty `name`, required non-empty `instructions`, and an optional/nullable `iconName` for the selected icon glyph.
- **`QuickActionFormValue`** — Type inferred from `quickActionSchema`, representing a single validated quick action form entry.
- **`QuickActionsFormValues`** — Interface describing the minimal form-values contract consumed by `AiSettingsQuickActionsEditor`, containing an array of `quickActions` and a `quickActionsIsDefault` flag that mirrors `AgentAiConfig.quickActionsIsDefault` to indicate whether hub defaults are used (hiding the editor) instead of custom entries.

## Usage Example

```typescript
import { quickActionSchema, QuickActionFormValue, QuickActionsFormValues } from './quick-action.types';

// Validate a single quick action
const result = quickActionSchema.safeParse({
  name: 'Reset Password',
  instructions: 'Guide the user through resetting their password.',
  iconName: 'key-icon',
});

if (result.success) {
  const action: QuickActionFormValue = result.data;
}

// Example form state consumed by AiSettingsQuickActionsEditor
const formValues: QuickActionsFormValues = {
  quickActions: [
    { name: 'Open Ticket', instructions: 'Create a new support ticket.' },
  ],
  quickActionsIsDefault: false,
};
```
