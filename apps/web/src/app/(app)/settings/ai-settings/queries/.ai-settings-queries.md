GraphQL query and mutation string constants for managing AI agent configuration and client view appearance settings across tenant and per-organization scopes.

## Key Components

### Field Fragments (internal)

- **`AGENT_AI_CONFIG_FIELDS`** — Reusable field set for AI config: LLM provider, model, answer style, custom prompt, and quick actions
- **`CLIENT_VIEW_FIELDS`** — Reusable field set for client appearance: assistant name, avatar, theme, and accent color

### Exported Queries

| Constant | Operation | Description |
|---|---|---|
| `GET_CLIENT_AI_CONFIG_QUERY` | `ClientAiConfig` | Fetches the tenant-wide client agent AI config |
| `GET_ADMIN_AI_CONFIG_QUERY` | `AdminAiConfig` | Fetches the tenant-wide admin agent AI config |
| `GET_CLIENT_VIEW_QUERY` | `ClientView($organizationId)` | Fetches appearance settings, optionally scoped to an organization |

### Exported Mutations

| Constant | Operation | Description |
|---|---|---|
| `UPDATE_CLIENT_AI_CONFIG_MUTATION` | `UpdateClientAiConfig` | Updates client agent AI config (LLM, prompts, quick actions) |
| `UPDATE_ADMIN_AI_CONFIG_MUTATION` | `UpdateAdminAiConfig` | Updates admin agent AI config |
| `UPDATE_CLIENT_VIEW_MUTATION` | `UpdateClientView` | Updates appearance override for a specific organization |
| `RESET_CLIENT_VIEW_MUTATION` | `ResetClientView` | Removes a per-org appearance override, falling back to tenant default in one round-trip |

## Usage Example

```typescript
import {
  GET_CLIENT_VIEW_QUERY,
  UPDATE_CLIENT_VIEW_MUTATION,
  RESET_CLIENT_VIEW_MUTATION,
} from './ai-settings-queries';

// Fetch per-org appearance
const { data } = await gqlClient.request(GET_CLIENT_VIEW_QUERY, {
  organizationId: 'org_123',
});

// Update appearance for a specific org
await gqlClient.request(UPDATE_CLIENT_VIEW_MUTATION, {
  organizationId: 'org_123',
  input: { accentColor: '#FF5733', assistantName: 'Mingo' },
});

// Reset to tenant default
await gqlClient.request(RESET_CLIENT_VIEW_MUTATION, {
  organizationId: 'org_123',
});
```

> **Design note:** AI logic config (LLM provider, prompts, quick actions) is tenant-wide per agent type. Avatar and appearance settings live on `ClientView` and can be overridden per organization.
