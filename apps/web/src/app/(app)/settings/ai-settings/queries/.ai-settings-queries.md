# ai-settings-queries.ts

GraphQL query and mutation definitions for managing AI agent configuration (LLM provider, prompts, quick actions) and client-facing view branding (assistant name, avatar, accent color) at both tenant-wide (admin) and per-organization (client) levels.

## Key Components

- **`GET_CLIENT_AI_CONFIG_QUERY`** - Fetches the AI logic configuration for the client-facing agent (`clientAiConfig`).
- **`GET_ADMIN_AI_CONFIG_QUERY`** - Fetches the AI logic configuration for the admin-facing agent (`adminAiConfig`).
- **`GET_CLIENT_VIEW_QUERY`** - Fetches per-organization (or default) branding/appearance settings via `clientView`, accepting an optional `organizationId`.
- **`UPDATE_CLIENT_AI_CONFIG_MUTATION`** - Updates the client agent's AI config; returns updated config and `userErrors`.
- **`UPDATE_ADMIN_AI_CONFIG_MUTATION`** - Updates the admin agent's AI config; returns updated config and `userErrors`.
- **`UPDATE_CLIENT_VIEW_MUTATION`** - Updates per-organization appearance (`ClientViewInput`); returns updated view and `userErrors`.
- **`RESET_CLIENT_VIEW_MUTATION`** - Clears a per-organization appearance override, falling back to the tenant-wide default. Returns the resulting view (tenant default or `null`) and `userErrors`. Requires backend support for `resetClientView(organizationId: ID!)`.

Shared fragments (`AGENT_AI_CONFIG_FIELDS`, `CLIENT_VIEW_FIELDS`) are internal constants reused across the exported operations to keep field selections consistent.

## Usage Example

```typescript
import {
  GET_CLIENT_VIEW_QUERY,
  UPDATE_CLIENT_VIEW_MUTATION,
  RESET_CLIENT_VIEW_MUTATION,
} from './ai-settings-queries';

// Fetch appearance for a specific organization
const { data } = await graphqlClient.query({
  query: GET_CLIENT_VIEW_QUERY,
  variables: { organizationId: 'org_123' },
});

// Update assistant branding for that organization
await graphqlClient.mutate({
  mutation: UPDATE_CLIENT_VIEW_MUTATION,
  variables: {
    organizationId: 'org_123',
    input: { assistantName: 'Fae', accentColor: '#FF6B6B' },
  },
});

// Reset to tenant-wide default
await graphqlClient.mutate({
  mutation: RESET_CLIENT_VIEW_MUTATION,
  variables: { organizationId: 'org_123' },
});
```
