# troubleshooting-toolbar.tsx

Client component rendering the filter toolbar for the troubleshooting/device logs view, combining customer and device pickers, a time range selector, auto-update toggle, search input, and log level chips into a single responsive layout.

## Key Components

- **`TroubleshootingToolbar`** — Main component accepting filter state and change handlers, rendering a responsive grid of pickers/controls plus a search bar and level chips below.
- **`TroubleshootingToolbarProps`** — Props interface defining:
  - `customerFilter`: `FeatureFlagGate` controlling visibility/loading state of the customer picker
  - `customers` / `onCustomersChange`: selected organization IDs and setter
  - `devices` / `onDevicesChange`: selected machine IDs and setter
  - `filters`: `DeviceLogFilters` object (range, search, log level state)
  - `autoUpdate` / `onAutoUpdateChange`: auto-refresh toggle state

## Usage Example

```typescript
import { TroubleshootingToolbar } from './troubleshooting-toolbar';
import { useDeviceLogFilters } from '@/app/(app)/devices/hooks/use-device-log-filters';

function TroubleshootingPage() {
  const filters = useDeviceLogFilters();
  const [customers, setCustomers] = useState<string[]>([]);
  const [devices, setDevices] = useState<string[]>([]);
  const [autoUpdate, setAutoUpdate] = useState(true);

  return (
    <TroubleshootingToolbar
      customerFilter="on"
      customers={customers}
      onCustomersChange={setCustomers}
      devices={devices}
      onDevicesChange={setDevices}
      filters={filters}
      autoUpdate={autoUpdate}
      onAutoUpdateChange={setAutoUpdate}
    />
  );
}
```

## Notes

- The device picker is automatically scoped to the selected customers' devices once `customerFilter` is `'on'` and at least one customer is picked; otherwise it lists all devices in the tenant.
- `customerFilter === 'off'` hides the customer picker and adjusts the grid to 3 columns (vs. 4 when shown).
- The component lives outside the log list's `Suspense` boundary so the search input retains focus during data refetches.
- Grid and spacing use CSS custom properties (`--spacing-system-*`) for design-system consistency.
