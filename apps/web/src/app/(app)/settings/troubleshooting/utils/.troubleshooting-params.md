# troubleshooting-params.ts

Utility functions for normalizing and validating `customer`/`device` picker URL parameters used by the troubleshooting `deviceLogs` query, and for recovering gracefully when the API rejects an id that doesn't exist in the current tenant.

## Key Components

- **`TROUBLESHOOTING_PICK_LIMIT`** — Constant (`50`) capping how many device or customer ids can be sent in a single `deviceLogs` query.
- **`pickedIdsFromParams(values)`** — Trims, deduplicates, and caps raw param values. Returns `undefined` when the result is empty, signaling "whole tenant" rather than an invalid empty-list request.
- **`UnknownPickParam`** — Type alias (`'customer' | 'device'`) identifying which picker contains a rejected id.
- **`unknownPickFromErrors(errors)`** — Inspects GraphQL error codes (`ORGANIZATION_NOT_FOUND`, `DEVICE_NOT_FOUND`) to determine which picker holds an unknown id, returning the param and the API's original message, or `null` for unrelated errors.
- **`picksWithoutUnknown(values, message)`** — Given the API's error message, finds which picked id it names (by longest suffix match) and returns the remaining picks with that id removed. Returns an empty array if no id can be matched, since a filter that doesn't exclude the bad id would just fail again.

## Usage Example

```typescript
import {
  pickedIdsFromParams,
  unknownPickFromErrors,
  picksWithoutUnknown,
} from './troubleshooting-params';

const deviceIds = pickedIdsFromParams(['abc123', '  ', 'abc123', 'def456']);
// => ['abc123', 'def456']

const errors = [{ message: 'Organization not found: org-999', code: 'ORGANIZATION_NOT_FOUND' }];
const unknown = unknownPickFromErrors(errors);
// => { param: 'customer', message: 'Organization not found: org-999' }

if (unknown) {
  const remaining = picksWithoutUnknown(['org-123', 'org-999'], unknown.message);
  // => ['org-123']
}
```
