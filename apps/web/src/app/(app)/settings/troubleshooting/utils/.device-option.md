## device-option.ts

Utility module for transforming `Device` entities into UI-ready options for autocomplete/picker components, with logic to disambiguate duplicate hostnames and prioritize "live" devices in sort order.

This is relevant for scenarios where devices may be re-enrolled under different customers while sharing the same hostname — the module ensures the active record is both sorted to the top and visually distinguishable via a description line (hostname, organization, and status).

## Key Components

- **`sortDevicesLiveFirst(devices)`** — Sorts devices by liveness rank: `online` devices first, `offline` second, all other statuses (e.g., "pending deletion") last. Returns a new sorted array without mutating the input.
- **`toDeviceOption(device)`** — Converts a `Device` into an `AutocompleteOption` with:
  - `label`: device name (or `machineId` fallback)
  - `value`: the device's `machineId`
  - `description`: a `·`-joined string combining hostname (only if different from the label), organization, and a human-readable status (with relative last-seen time for non-online devices)
- Internal helpers `statusLabel`, `livenessRank`, and `statusText` support the above exports but are not exported.

## Usage Example

```typescript
import { sortDevicesLiveFirst, toDeviceOption } from './device-option';
import type { Device } from '@/app/(app)/devices/types/device.types';

function buildDevicePickerOptions(devices: Device[]) {
  const orderedDevices = sortDevicesLiveFirst(devices);
  return orderedDevices.map(toDeviceOption);
}

// Example result for a single device:
// {
//   label: 'MacBook-Pro-Jane',
//   value: 'machine-id-123',
//   description: 'acme-laptop-07 · Acme Corp · Online'
// }
```

Typical use case: populating a device-selection `Autocomplete` component where multiple devices may share a hostname (e.g., due to re-enrollment), ensuring the most recently active device appears first and is clearly labeled.
