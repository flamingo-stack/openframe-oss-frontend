A modal dialog component that prompts users to resend an email verification link when their email address has not yet been verified.

## Key Components

### `EmailVerificationModal`
A wrapper around the shared `ConfirmDialog` component, pre-configured for the email verification flow.

**Props (`EmailVerificationModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open/close state changes |
| `userEmail` | `string` | The unverified email address displayed in the dialog body |
| `onSubmit` | `() => Promise<void>` | Handler triggered when the user confirms resending |
| `isSending` | `boolean` | Disables the confirm button and shows a pending label while the request is in flight |

## Usage Example

```typescript
import { EmailVerificationModal } from './email-verification-modal';

function AccountSettings() {
  const [open, setOpen] = useState(false);
  const [isSending, setIsSending] = useState(false);

  const handleResend = async () => {
    setIsSending(true);
    await resendVerificationEmail();
    setIsSending(false);
    setOpen(false);
  };

  return (
    <EmailVerificationModal
      open={open}
      onOpenChange={setOpen}
      userEmail="user@example.com"
      onSubmit={handleResend}
      isSending={isSending}
    />
  );
}
```

The unverified email address is highlighted in `text-ods-warning` to draw user attention. The confirm button transitions to a `"Sending..."` label while `isSending` is `true`, preventing duplicate submissions.
