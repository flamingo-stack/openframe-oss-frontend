A modal dialog component for confirming the removal of an expired user invitation, built on top of the shared `ConfirmDialog` component.

## Key Components

### `ConfirmRemoveInvitationModal`
A focused confirmation dialog that presents a destructive action prompt before permanently deleting an expired invitation. Highlights the target user's email in error styling to clearly communicate the affected party.

**Props (`ConfirmRemoveInvitationModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open state changes |
| `userEmail` | `string` | Email address of the invitation being removed |
| `onConfirm` | `() => Promise<void> \| void` | Handler executed on confirmation (supports async) |

## Usage Example

```typescript
import { ConfirmRemoveInvitationModal } from './confirm-remove-invitation-modal';

function InvitationList() {
  const [open, setOpen] = useState(false);
  const [targetEmail, setTargetEmail] = useState('');

  const handleRemove = async () => {
    await deleteInvitation(targetEmail);
    setOpen(false);
  };

  return (
    <>
      <button onClick={() => { setTargetEmail('user@example.com'); setOpen(true); }}>
        Remove Expired Invitation
      </button>
      <ConfirmRemoveInvitationModal
        open={open}
        onOpenChange={setOpen}
        userEmail={targetEmail}
        onConfirm={handleRemove}
      />
    </>
  );
}
```

## Notes

- Rendered as a client component (`'use client'`)
- Delegates all dialog rendering/behavior to [`ConfirmDialog`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/components/shared/confirm-dialog.tsx)
- The `userEmail` is rendered with `text-ods-error` styling to visually emphasize the affected account
