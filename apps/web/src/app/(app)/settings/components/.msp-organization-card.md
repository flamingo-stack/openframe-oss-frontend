# msp-organization-card.tsx

A React client component that renders an organization identity row displaying the MSP's name, logo, and website, with an edit action button. It's built on top of the shared `IdentityRow` primitive and handles loading states gracefully by rendering skeleton bars instead of guessed or placeholder data.

## Key Components

- **`MspOrganizationCardProps`** — Interface defining the component's props: `name`, `website`, `logoUrl` (optional), `loading` (optional), and `onEditOrganization` (optional callback).
- **`MspOrganizationCard`** — The main exported component that composes `IdentityRow` with a square avatar variant, organization details, and a `ResponsiveActionButton` for editing.
- **`editIcon`** — A memoized `PenEditIcon` element reused across renders to avoid unnecessary re-instantiation.

### Design Notes

- The avatar uses `square` variant (via `IdentityRow`'s `avatarVariant` prop) to match a `SquareAvatar size="lg"` footprint, ensuring consistent row height (48px) regardless of loading state.
- No skeleton bar is drawn for the website subline when absent — since the website field is optional per tenant, rendering a placeholder bar would misrepresent the data.
- The Edit button is always rendered with static copy ("Edit Organization") but stays disabled until `onEditOrganization` is provided, signaling that organization data has fully loaded.

## Usage Example

```typescript
import { MspOrganizationCard } from './msp-organization-card';

function AccountSettingsSection() {
  const [org, setOrg] = useState<{ name: string; website: string; logoUrl?: string } | null>(null);

  return (
    <MspOrganizationCard
      name={org?.name ?? ''}
      website={org?.website ?? ''}
      logoUrl={org?.logoUrl}
      loading={!org}
      onEditOrganization={org ? () => openEditOrgModal(org) : undefined}
    />
  );
}
```

While `org` is `null`, the card renders in a loading state with skeleton bars for the avatar and name. Once data resolves, `onEditOrganization` is supplied, enabling the Edit button.
