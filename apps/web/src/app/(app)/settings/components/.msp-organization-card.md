Displays a compact card for an MSP organization, showing its logo, name, website, and an edit action button with loading skeleton support.

## Key Components

**`MspOrganizationCard`** — Primary exported component that renders organization identity information in a horizontal card layout.

**`MspOrganizationCardProps`**

| Prop | Type | Description |
|---|---|---|
| `name` | `string` | Organization display name; falls back to `"Your Organization"` if empty |
| `website` | `string` | Organization website URL shown as secondary text |
| `logoUrl` | `string?` | Optional logo image URL passed to `SquareAvatar` |
| `isLoading` | `boolean?` | Renders a skeleton placeholder instead of name/website text |
| `onEditOrganization` | `() => void` | Callback triggered by the edit action button |

## Usage Example

```typescript
import { MspOrganizationCard } from '@/app/components/msp-organization-card';

function SettingsPage() {
  const handleEdit = () => openEditModal();

  return (
    <MspOrganizationCard
      name="Acme IT Solutions"
      website="https://acmeit.com"
      logoUrl="https://acmeit.com/logo.png"
      isLoading={false}
      onEditOrganization={handleEdit}
    />
  );
}
```

**Loading state:**

```typescript
<MspOrganizationCard
  name=""
  website=""
  isLoading={true}
  onEditOrganization={() => {}}
/>
```

## Notes

- Falls back to `"Your Organization"` when `name` is an empty string.
- `website` is conditionally rendered — omitted entirely when falsy.
- Uses design tokens (`--spacing-system-m`, `text-h4`, `text-ods-text-primary`) for consistent styling.
