A confirmation modal for disabling the built-in OpenFrame SSO login at the tenant level, warning admins of the risks before confirming the action.

## Key Components

- **`DisableOpenframeSsoModal`** — React component rendering a destructive confirmation dialog built on top of the shared `ConfirmDialog` component.
- **`DisableOpenframeSsoModalProps`** — Props interface controlling dialog visibility (`open`/`onOpenChange`), pending state (`isPending`), and confirm action (`onConfirm`).
- Uses `ContentErrorBoundary` to safely render `ActiveUsersSsoNotice`, falling back to `GENERIC_SSO_NOTICE` if fetching the affected-user count fails.
- Displays a warning banner (via `AlertTriangleIcon`) explaining the risk of lockouts if the SSO provider fails, plus informational text about session persistence and next-login behavior.

## Usage Example

```typescript
import { useState } from 'react';
import { DisableOpenframeSsoModal } from './disable-openframe-sso-modal';

function SsoSettingsPanel() {
  const [open, setOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleConfirm = async () => {
    setIsPending(true);
    try {
      await disableOpenframeSso(); // your API call
      setOpen(false);
    } finally {
      setIsPending(false);
    }
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Disable OpenFrame SSO</button>
      <DisableOpenframeSsoModal
        open={open}
        onOpenChange={setOpen}
        isPending={isPending}
        onConfirm={handleConfirm}
      />
    </>
  );
}
```

This component is intended for admin-facing SSO configuration screens where disabling the local OpenFrame authentication method requires explicit, informed confirmation due to its tenant-wide, potentially locking-out impact.
