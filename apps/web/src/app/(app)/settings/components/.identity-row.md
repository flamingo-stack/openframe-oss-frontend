# identity-row.tsx

Renders a reusable identity row (avatar, name, secondary line, and trailing action) used across settings cards, including the profile card, profile tab, and organization card. It integrates with the app's loading-scope system to display skeleton placeholders automatically while data is being fetched.

## Key Components

- **`IdentityRow`** — Generic, presentational row component that renders a `SquareAvatar`, a `TitleLines` block (name + optional tags + subline), and a trailing action slot. Automatically switches to loading state via `useLoadingScope()` or the `loading` prop, rendering skeleton bars and an announced loading label via `LoadingRegion`.
- **`IdentityRowProps`** — Prop interface controlling frame class, loading state/label, avatar source/variant, name, optional `nameAside` (e.g., role tags), `subline`, `emptySubline` behavior (`'mark'` vs `'none'`), and the `action` node.
- **`USER_ROW_CLASS`** — Shared Tailwind class string defining the standard row layout (flex, gap, padding) used by both the profile card and organization card.
- **`UserIdentityRow`** — Specialized wrapper around `IdentityRow` for the signed-in user. Derives display name (falls back to email), resolves avatar URL via `getFullImageUrl`, renders role `Tag`s as `nameAside`, and shows the user's email as the subline (always "marked" even when empty).
- **`UserIdentityRowProps`** — Props for the specialized component: `user` (nullable `User`), `loading`, `action`, and optional `className`.

## Usage Example

```typescript
import { UserIdentityRow, USER_ROW_CLASS } from '@/app/components/shared/identity-row';
import { Button } from '@flamingo-stack/openframe-frontend-core/components/ui';

function ProfileCard({ user, isLoading }: { user: User | null; isLoading: boolean }) {
  return (
    <UserIdentityRow
      user={user}
      loading={isLoading}
      className={USER_ROW_CLASS}
      action={<Button disabled={isLoading}>Edit Profile</Button>}
    />
  );
}
```

For a custom identity row (e.g., a team member list), use `IdentityRow` directly:

```typescript
<IdentityRow
  className={USER_ROW_CLASS}
  loading={loading}
  loadingLabel="Loading team member"
  name={member.name}
  avatarSrc={member.avatarUrl}
  avatarVariant="square"
  subline={member.website}
  action={<Button variant="ghost">Remove</Button>}
/>
```
