Composite account settings container that groups the MSP organization row (`MspOrganizationCard`) and user profile row (`ProfileCard`) into a single bordered card, and manages the `EditOrganizationModal` open/close state.

## Key Components

| Export | Type | Description |
|---|---|---|
| `AccountSettingsCard` | React Component | Root container card combining org and profile rows |
| `AccountSettingsCardProps` | Interface | `onEditProfile` and `onVerifyEmail` callback props |

**Internal hooks used:**
- `useTenantInfo` — fetches tenant name, website, and logo
- `useUpdateTenantInfo` — mutation for persisting org changes

## Usage Example

```typescript
import { AccountSettingsCard } from './account-settings-card';

function SettingsPage() {
  const handleEditProfile = () => router.push('/settings/profile');
  const handleVerifyEmail = () => sendVerificationEmail();

  return (
    <AccountSettingsCard
      onEditProfile={handleEditProfile}
      onVerifyEmail={handleVerifyEmail}
    />
  );
}
```

## Layout Structure

```text
┌─────────────────────────────┐  border / rounded-md
│  MspOrganizationCard        │  border-b (transparent bg)
├─────────────────────────────┤
│  ProfileCard                │  bg-ods-card
└─────────────────────────────┘
         ↕ EditOrganizationModal (portal, controlled by isOrgModalOpen)
```

The component owns the outer border and `overflow-hidden` clipping; inner rows are borderless and separated by a single divider. Organization edits are submitted via `updateTenantInfo.mutateAsync` and the modal's `isSaving` state is wired to `updateTenantInfo.isPending`.
