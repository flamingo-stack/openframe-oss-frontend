# account-settings-card.tsx

A client-side wrapper component that combines the MSP organization info row and the user profile card into a single bordered container on the account settings page. It manages tenant data loading state and coordinates the organization edit modal.

## Key Components

- **`AccountSettingsCard`** — Main exported component. Renders:
  - `MspOrganizationCard`: displays organization name, website, and logo with an edit trigger (disabled until tenant data is loaded).
  - `ProfileCard`: displays/edits the current user's profile via the `onEditProfile` callback.
  - `EditOrganizationModal`: modal for editing organization details, backed by `useUpdateTenantInfo` mutation.
- **`AccountSettingsCardProps`** — Props interface requiring an `onEditProfile` callback.

## Usage Example

```typescript
import { AccountSettingsCard } from './account-settings-card';

export function AccountSettingsPage() {
  const handleEditProfile = () => {
    // open profile edit modal/flow
  };

  return (
    <div className="max-w-2xl mx-auto">
      <AccountSettingsCard onEditProfile={handleEditProfile} />
    </div>
  );
}
```

## Notes

- Uses `queryState(tenantQuery)` to derive `hasData` rather than relying on `isLoading`, because a **paused** query reports `isLoading: false` with no data. Using `isLoading` directly would incorrectly enable editing before real tenant data loads, risking an accidental save of empty `{ name: '', website: '' }` values over the actual organization record.
- The organization logo URL is resolved via `getFullImageUrl`, combining the image URL and hash from `tenantInfo.image`.
- Edit access for the organization row is conditionally wired (`onEditOrganization`) only once `tenantLoaded` is `true`.
