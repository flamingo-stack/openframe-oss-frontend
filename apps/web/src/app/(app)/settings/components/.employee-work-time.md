Renders a section displaying an employee's work time entries with an "Add Work Time" button that opens a modal for creating new entries.

## Key Components

- **`EmployeeWorkTime`** — Client component that accepts a `userId` prop and manages the open/closed state of the add-work-time modal via `addOpen`/`setAddOpen`

## Usage Example

```typescript
import { EmployeeWorkTime } from '@/app/components/employee/employee-work-time';

// Within an employee profile or details page
<EmployeeWorkTime userId="usr_abc123" />
```

## Notes

- Delegates rendering and data fetching to [`WorkTimeTable`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/components/shared/work-time-table) with `showCustomer` enabled, scoping entries to the given `employeeId`
- The `addOpen` state is lifted here and passed down to `WorkTimeTable` via `addWorkTimeOpen` / `onAddWorkTimeOpenChange`, keeping modal control at the section level
