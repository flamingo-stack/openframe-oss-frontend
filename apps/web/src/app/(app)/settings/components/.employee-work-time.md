# employee-work-time.tsx

A React client component that displays an employee's logged work time entries along with a button to add new work time records.

## Key Components

- **`EmployeeWorkTime`** — Main exported component that renders a section header with the title "Employee Work Time", an "Add Work Time" button, and a `WorkTimeTable` configured for a specific employee.
  - **Props:**
    - `userId: string` — The ID of the employee whose work time is being displayed; passed to `WorkTimeTable` as `employeeId`.
  - **Internal state:**
    - `addOpen: boolean` — Controls the visibility of the "Add Work Time" dialog/modal, managed via `useState` and toggled by the "Add Work Time" button.

This component relies on the shared `WorkTimeTable` component (from `@/app/components/shared/work-time-table`) to render the actual tabular data, passing `showCustomer` to display customer-related columns, and controlled props (`addWorkTimeOpen`, `onAddWorkTimeOpenChange`) to synchronize the add-entry dialog state.

## Usage Example

```typescript
import { EmployeeWorkTime } from '@/app/components/employee-work-time';

export default function EmployeeDetailPage({ params }: { params: { id: string } }) {
  return (
    <div>
      <EmployeeWorkTime userId={params.id} />
    </div>
  );
}
```

The component is intended to be embedded within an employee profile or detail page, giving managers or the employee themselves a quick view of logged hours and a way to add new entries via the "Add Work Time" button.
