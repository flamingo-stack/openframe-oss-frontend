# sso-configuration-details-modal.tsx

Renders a modal dialog that displays read-only details of an SSO (OAuth) provider configuration, with actions to enable, disable, or delete it. Includes a toggle to reveal/hide the client secret value.

## Key Components

- **`SsoConfigurationDetails`** — Interface describing the SSO config shape: provider, display name, enabled state, client ID/secret, and allowed domains.
- **`SsoConfigurationDetailsModalProps`** — Props interface controlling modal visibility, pending state, and action callbacks (`onEnable`, `onDisableRequest`, `onDeleteRequest`).
- **`DetailRow`** — Internal presentational component rendering a label/value row with a dashed leader line, matching the design mockup's key-value layout.
- **`SsoConfigurationDetailsModal`** — Main exported component. Displays provider name/status tag, a details card (provider, client ID, masked client secret with show/hide toggle, allowed domains), and footer actions (Cancel + Enable/Disable toggle button, plus a destructive Delete button).

## Usage Example

```typescript
import { useState } from 'react';
import {
  SsoConfigurationDetailsModal,
  type SsoConfigurationDetails,
} from './sso-configuration-details-modal';

function SsoAdminPanel() {
  const [isOpen, setIsOpen] = useState(true);
  const [isPending, setIsPending] = useState(false);

  const details: SsoConfigurationDetails = {
    provider: 'google',
    displayName: 'Google Workspace',
    isEnabled: true,
    clientId: 'client-id-123',
    clientSecret: 'super-secret-value',
    allowedDomains: ['example.com', 'flamingo.run'],
  };

  return (
    <SsoConfigurationDetailsModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      details={details}
      isPending={isPending}
      onEnable={() => {
        setIsPending(true);
        // call enable mutation
      }}
      onDisableRequest={() => {
        // open a confirmation dialog before disabling
      }}
      onDeleteRequest={() => {
        // open a confirmation dialog before deleting
      }}
    />
  );
}
```

**Notes:**
- The `showSecret` state resets to hidden each time the modal transitions from closed to open, implemented via render-time state comparison (`wasOpen`) rather than `useEffect`, avoiding a visible flash of the previous reveal state.
- Enabling fires `onEnable` immediately; disabling and deleting require parent-managed confirmation flows via `onDisableRequest`/`onDeleteRequest`.
