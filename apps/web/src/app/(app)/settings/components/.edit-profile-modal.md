# edit-profile-modal.tsx

A modal component that allows the signed-in user to edit their own profile — updating first name, last name, and profile avatar — while keeping the Relay store, global auth store, and UI all in sync.

## Key Components

- **`EditProfileModal`** — The main exported component. Renders a `SimpleModal` with an `ImageUploader` and editable `firstName`/`lastName` fields, plus read-only `email` and `role` fields.
- **`editProfileModalMutationNode`** — A GraphQL mutation (`updateUser`) used to persist name changes via Relay.
- **`storeImage`** — Internal helper that manually updates the Relay store's `User.image` record after a REST-based avatar upload, since the upload itself bypasses Relay.
- **`handleImageChange` / `handleImageRemove`** — Handle avatar upload/removal via `uploadWithAuth`/`deleteWithAuth`, synchronizing the result across local state, the auth store, and the Relay store simultaneously.
- **`handleSave`** — Commits the name-change mutation and updates the auth store (`useAuthStore`) on success.

Notably, form fields are seeded from the `user` prop during render (guarded by an `isOpen`/`wasOpen` comparison) rather than in a `useEffect`, avoiding a flash of stale values when the modal opens.

## Usage Example

```typescript
import { useState } from 'react';
import { EditProfileModal } from '@/app/components/profile/edit-profile-modal';
import { useAuthStore } from '@/app/(auth)/auth/stores';

function ProfileSettings() {
  const [isModalOpen, setIsModalOpen] = useState(false);
  const user = useAuthStore(state => state.user);

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>Edit Profile</button>
      <EditProfileModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        user={user}
      />
    </>
  );
}
```

**Dependencies:** Relay (`react-relay`), `@flamingo-stack/openframe-frontend-core` UI primitives, the app's `useAuthStore`, `SimpleModal`, and upload helpers (`uploadWithAuth`, `deleteWithAuth`).
