A modal dialog component for creating or editing API keys, supporting both create and edit modes with fields for name, description, and optional expiration date.

## Key Components

### `CreateApiKeyModal`
The sole export — a client-side React component wrapping `SimpleModal` with API key form logic.

**Props (`CreateApiKeyModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback to close the modal |
| `mode` | `'create' \| 'edit'` | Defaults to `'create'` |
| `create` | `(data) => Promise<...>` | Async function to create a new key |
| `onCreated` | `(params) => void` | Called after successful creation with `apiKeyId` and `fullKey` |
| `initial` | `{ id, name, description?, expiresAt? }` | Pre-populated values for edit mode |
| `update` | `(id, data) => Promise<any>` | Async function to update an existing key |
| `onUpdated` | `(updated) => void` | Called after successful update |

**Internal state:** `name`, `description`, `expiresAt`, `isSubmitting`

**Key behaviors:**
- Resets form state on close; pre-populates fields in edit mode via `useEffect`
- `canSubmit` is `true` only when `name` is non-empty
- `expiresAt` is converted to ISO 8601 before submission; an empty value is sent as `null`
- Displays success/error toasts via `useToast`

## Usage Example

```typescript
<CreateApiKeyModal
  isOpen={showModal}
  onClose={() => setShowModal(false)}
  mode="create"
  create={async (data) => {
    const result = await apiClient.createApiKey(data);
    return { apiKey: result.apiKey, fullKey: result.fullKey };
  }}
  onCreated={({ apiKeyId, fullKey }) => {
    // Store or display the full key (only shown once)
    setNewKey(fullKey);
  }}
/>

// Edit mode
<CreateApiKeyModal
  isOpen={showEditModal}
  onClose={() => setShowEditModal(false)}
  mode="edit"
  initial={{ id: 'key_123', name: 'My Key', expiresAt: '2025-12-31T00:00:00Z' }}
  update={async (id, data) => apiClient.updateApiKey(id, data)}
  onUpdated={() => refetchKeys()}
/>
```
