A modal component for creating or editing API keys, supporting both a "create" mode (returns a full key on success) and an "edit" mode (updates name/description/expiration of an existing key).

## Key Components

- **`CreateApiKeyModal`** — React component rendering a `SimpleModal` with fields for API key name, description, and optional expiration date.
- **`CreateApiKeyModalProps`** — Props interface controlling modal visibility, mode (`'create' | 'edit'`), initial values for edit mode, and async `create`/`update` handlers plus `onCreated`/`onUpdated` callbacks.
- **Form state reset logic** — Resets or seeds form fields during render when the `isOpen` prop transitions, avoiding a flash of stale data that an effect-based approach would cause.
- **`handleSubmit`** — Validates the name field, builds the payload (trimming strings, converting expiration to ISO string or `null`), invokes `create` or `update` depending on mode, shows success/error toasts via `useToast`, and closes the modal on success.

## Usage Example

```typescript
import { useState } from 'react';
import { CreateApiKeyModal } from './create-api-key-modal';
import { useApiKeys } from '../hooks/use-api-keys';

function ApiKeysPage() {
  const [isOpen, setIsOpen] = useState(false);
  const { create, update } = useApiKeys();

  return (
    <>
      <button onClick={() => setIsOpen(true)}>New API Key</button>
      <CreateApiKeyModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        create={create}
        onCreated={async ({ apiKeyId, fullKey }) => {
          console.log('Created key', apiKeyId, fullKey);
        }}
      />
    </>
  );
}

// Edit mode usage
<CreateApiKeyModal
  isOpen={isEditOpen}
  onClose={() => setIsEditOpen(false)}
  mode="edit"
  initial={{ id: 'key-123', name: 'Prod Key', description: 'Main key', expiresAt: null }}
  update={update}
  onUpdated={async ({ id }) => console.log('Updated', id)}
/>
```
