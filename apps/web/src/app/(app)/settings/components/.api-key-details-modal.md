Renders a read-only modal displaying detailed information about a given API key, including its status, metadata, and usage statistics.

## Key Components

- **`ApiKeyDetailsModal`** — React component that renders a `SimpleModal` with API key details.
- **`ApiKeyDetailsModalProps`** — Props interface:
  - `isOpen: boolean` — controls modal visibility.
  - `onClose: () => void` — callback invoked when the modal is closed.
  - `apiKey: ApiKeyRecord | null` — the API key record to display; if `null`, the component renders nothing.

The component displays:
- Key name, description, and an `ACTIVE`/`INACTIVE` status `Tag`.
- A two-column grid of read-only `Input` fields showing Key ID, Created/Expires/Last Used timestamps (formatted via `formatDateTime`), and request statistics (Total/Successful/Failed, formatted via `formatCount`).
- A footer with a single `Close` button.

## Usage Example

```typescript
import { useState } from 'react';
import { ApiKeyDetailsModal } from './api-key-details-modal';
import type { ApiKeyRecord } from '../hooks/use-api-keys';

function ApiKeysList({ apiKeys }: { apiKeys: ApiKeyRecord[] }) {
  const [selectedKey, setSelectedKey] = useState<ApiKeyRecord | null>(null);
  const [isModalOpen, setIsModalOpen] = useState(false);

  const handleViewDetails = (key: ApiKeyRecord) => {
    setSelectedKey(key);
    setIsModalOpen(true);
  };

  return (
    <>
      {/* ...render list with onClick={() => handleViewDetails(key)} ... */}

      <ApiKeyDetailsModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        apiKey={selectedKey}
      />
    </>
  );
}
```

## Notes

- Fields with no value (e.g., missing description) fall back to the shared `EMPTY_VALUE` placeholder.
- All data fields are rendered using disabled `Input` components, making this a strictly read-only view.
- Relies on `ApiKeyRecord` from the `use-api-keys` hook for its data shape.
