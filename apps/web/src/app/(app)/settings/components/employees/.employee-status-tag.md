# employee-status-tag.tsx

A React component that renders a styled status tag (chip) for employee records, mapping user account states and invitation states to consistent visual labels and color variants.

## Key Components

- **`STATUS_TAG`** — Internal lookup map pairing each `UserStatus` and `InvitationStatus` enum value with a `TagStyle` (a display `label` and a color `variant`: `success`, `grey`, `warning`, or `error`).
- **`employeeStatusLabel(status: string): string`** — Exported helper that resolves the display label for a given status string, falling back to the raw status value if unmapped. Used to keep labels consistent outside the tag component (e.g., in filters or tooltips).
- **`EmployeeStatusTag({ status }: { status: string | null })`** — The main component. Renders a `Tag` from `@flamingo-stack/openframe-frontend-core/components/ui` with the resolved label/variant. When `status` is `null` (data still loading), it renders an empty-label tag so the `Tag` component can display its own skeleton/loading state.

## Usage Example

```typescript
import { EmployeeStatusTag, employeeStatusLabel } from '@/components/employee-status-tag';
import { UserStatus } from '@/generated/schema-enums';

// Render a status tag in a table cell
function StatusCell({ status }: { status: string | null }) {
  return <EmployeeStatusTag status={status} />;
}

// Use the label resolver for non-chip contexts (e.g. CSV export, tooltip text)
const label = employeeStatusLabel(UserStatus.ACTIVE); // "ACTIVE"

// While data is loading
<EmployeeStatusTag status={null} /> // renders empty tag, triggers skeleton state
```

This component is typically used in the STATUS column of employee-related tables, handling both active/deleted user accounts and pending/expired invitations with a unified visual language.
