# invitation-roles-cell.tsx

Renders the **ROLE** column for a row in the invitations table, displaying the role(s) that will be granted to an invitee once they accept their invitation.

## Key Components

- **`InvitationRolesCell`** — React component that reads invitation role data via a GraphQL fragment and renders it as a comma-separated string. Supports a loading state by checking `useLoadingScope()`, in which case it skips reading the fragment and renders a loading placeholder via `ValueText`.
- **`invitationRolesCellFragment`** — Relay GraphQL fragment (`invitationRolesCell_invitation`) declared on the `Invitation` type, selecting the `roles` field.

## Usage Example

```typescript
import { InvitationRolesCell } from '@/app/components/invitations/invitation-roles-cell';
import type { invitationRolesCell_invitation$key } from '@/__generated__/invitationRolesCell_invitation.graphql';

function InvitationRow({ invitation }: { invitation: invitationRolesCell_invitation$key }) {
  return (
    <tr>
      <td>
        <InvitationRolesCell invitation={invitation} />
      </td>
    </tr>
  );
}
```

This component is intended to be used as a table cell within a list of invitations, typically inside a Relay fragment container or paginated list where each row is resolved individually. When the row is still loading (within a loading scope), the component renders a skeleton/placeholder state instead of attempting to read fragment data, preventing premature reads before the row's data is available.
