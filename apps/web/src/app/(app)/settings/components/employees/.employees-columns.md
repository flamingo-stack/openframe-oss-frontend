Defines the shared column layout configuration and pagination constants used by the Employees feature's Users and Invitations tables, decoupling table structure data from rendering logic.

## Key Components

- **`EMPLOYEES_COLUMNS`** — A `satisfies Record<string, TableSkeletonColumn>` object defining five columns shared across the users and invitations tables:
  - `user` — the USER column, takes up a third of the width, flexes on smaller screens
  - `roles` — the ROLE column, similarly responsive
  - `status` — the STATUS column, hidden at the `md` breakpoint
  - `actions` — a fixed-width right-aligned action column, hidden at `md`
  - `open` — a fixed-width right-aligned "open" control column, hidden at `md`
- **`USERS_PAGE_SIZE`** — Constant (`50`) defining the default page size for the users table.
- **`INVITATIONS_PAGE_SIZE`** — Constant (`20`) defining the default page size for the invitations table.

This module is intentionally data-only, with no rendering logic, so that both the users and invitations tables can share a single source of truth for column layout (see `table-column-layout.ts` for the `TableSkeletonColumn` type definition and rationale).

## Usage Example

```typescript
import { EMPLOYEES_COLUMNS, USERS_PAGE_SIZE, INVITATIONS_PAGE_SIZE } from './employees-columns';

// Render a table skeleton using the shared column definitions
<TableSkeleton
  columns={Object.values(EMPLOYEES_COLUMNS)}
  pageSize={USERS_PAGE_SIZE}
/>

// Reuse the same columns for the invitations tab
<TableSkeleton
  columns={Object.values(EMPLOYEES_COLUMNS)}
  pageSize={INVITATIONS_PAGE_SIZE}
/>
```
