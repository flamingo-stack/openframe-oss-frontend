Renders the employees/users listing table, mapping each `User` GraphQL node to a row with user, roles, status, and open-in-new-tab cells, while delegating pagination and querying to the parent component.

## Key Components

- **`usersTableFragment`** — Relay fragment (`usersTable_user`, plural) fetching the `User` fields and sub-fragments needed to render each row (`employeeUserCell_user`, `employeeRolesCell_user`, `employeeStatusCell_user`).
- **`UserRow`** — Type alias for a single row's resolved fragment data.
- **`detailHref(row)`** — Builds the employee detail page link from a row's raw id (converted from the Relay global id via `rawIdOf`).
- **`buildColumns(filterOptions)`** — Constructs the `ColumnDef[]` for user, roles, status, and an "open in new tab" action column, wiring up filter options via `liveColumnMeta`.
- **`getRowId(row)`** — Row id accessor for the data table.
- **`emptyState(search, isFiltered)`** — Produces contextual empty-state copy depending on whether a search term or filter is active.
- **`UsersTableProps`** — Props contract: fragment key (`rows`), `totalCount`, `search`, `isFiltered`, `filterOptions`, `selections`/`onSelectionsChange`, `isPending`, `stickyHeaderOffset`, and `infiniteScroll`.
- **`UsersTable`** — Main component. Resolves the fragment, builds a loading scope with placeholder rows while data loads, wires column filters to parent selections, builds the table via `useDataTable`, and renders it with `LiveTable`.

## Usage Example

```typescript
import { UsersTable } from './users-table';

function EmployeesPage({ usersRef, totalCount, filterOptions, selections, setSelections, isPending }) {
  return (
    <UsersTable
      rows={usersRef}
      totalCount={totalCount}
      search=""
      isFiltered={Object.values(selections).some(Boolean)}
      filterOptions={filterOptions}
      selections={selections}
      onSelectionsChange={setSelections}
      isPending={isPending}
      stickyHeaderOffset="64px"
      infiniteScroll={<LoadMoreTrigger />}
    />
  );
}
```

This component expects the parent to own the GraphQL query, pagination, and search/filter state, passing only the resolved fragment reference and current state down as props.
