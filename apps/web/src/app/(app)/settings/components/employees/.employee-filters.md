# employee-filters.ts

Provides shared logic for building and translating the ROLE and STATUS filters used across the Employees tables (Users and Invitations tabs). It bridges URL-persisted filter selections, GraphQL facet data (counts per filter value), and the typed GraphQL filter inputs expected by the respective list queries.

## Key Components

- **`EmployeeSelections`** — Interface representing the current filter state (`roles`, `status`) as kept in the URL query params.
- **`NO_EMPLOYEE_SELECTIONS`** — Empty/default `EmployeeSelections` constant, used when switching tabs.
- **`EmployeeFilterOptions`** — Interface describing the available filter options (with counts) for the ROLE and STATUS column headers.
- **`NO_EMPLOYEE_FILTER_OPTIONS`** — Default/loading-state constant for `EmployeeFilterOptions`.
- **`userFilterOptions(ref, selections)`** — Reads the `employeeFilters_userFilters` inline fragment and derives `EmployeeFilterOptions` for the Users table.
- **`invitationFilterOptions(ref, selections)`** — Reads the `employeeFilters_invitationFilters` inline fragment and derives `EmployeeFilterOptions` for the Invitations table.
- **`toUserFilter(selections)`** — Converts `EmployeeSelections` into a `UserFilterInput` (or `null` if nothing is selected) for the `users(filter:)` GraphQL query.
- **`toInvitationFilter(selections)`** — Converts `EmployeeSelections` into an `InvitationFilterInput` (or `null` if nothing is selected) for the `invitations(filter:)` GraphQL query.

## Usage Example

```typescript
import {
  NO_EMPLOYEE_SELECTIONS,
  userFilterOptions,
  toUserFilter,
} from './employee-filters';

// Building header filter options from a GraphQL fragment reference
const selections = { roles: ['ADMIN'], status: [] };
const options = userFilterOptions(userFiltersRef, selections);
// options.roles / options.status -> DataTableFilterOption[]

// Converting selections into a query filter input
const filter = toUserFilter(selections);
// filter -> { roles: ['ADMIN'] } or null if nothing is selected

// Resetting filters on tab switch
setSelections(NO_EMPLOYEE_SELECTIONS);
```

Facet counts remain stable while toggling a single filter by excluding the filter's own dimension from the count calculation, and previously-selected values are preserved in the options list even if their count drops to zero (e.g., after a search narrows results).
