# confirm-resend-invitation-modal.tsx

A confirmation modal component that resends an expired invitation by revoking the old one and issuing a new one via a GraphQL mutation, with automatic Relay store invalidation for affected invitation listings.

## Key Components

- **`ConfirmResendInvitationModal`** — React component rendering a `ConfirmDialog` that prompts the user to confirm resending an invitation.
- **`confirmResendInvitationModalFragment`** — Relay GraphQL fragment fetching `id` and `email` from an `Invitation` object.
- **`confirmResendInvitationModalMutationNode`** — Relay GraphQL mutation calling `resendInvitation`, which deletes the old invitation edge from the provided Relay `connections`.
- **`ConfirmResendInvitationModalProps`** — Props interface requiring:
  - `invitation`: fragment reference (`confirmResendInvitationModal_invitation$key`)
  - `isOpen`: dialog visibility state
  - `onClose`: callback to close the dialog
  - `listingIds`: Relay connection IDs for invitation listings that need to be invalidated/refetched after the mutation

## Usage Example

```typescript
import { ConfirmResendInvitationModal } from '@/app/components/invitations/confirm-resend-invitation-modal';

function InvitationRow({ invitation, listingIds }) {
  const [isModalOpen, setIsModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>Resend</button>
      <ConfirmResendInvitationModal
        invitation={invitation}
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        listingIds={listingIds}
      />
    </>
  );
}
```

On confirmation, the component commits the `resendInvitation` mutation, uses an `updater` function (`invalidateInvitationsListings`) to refresh the Relay store's invitation listings, shows a toast on error via `getRelayErrorMessage`, and closes the dialog on success.
