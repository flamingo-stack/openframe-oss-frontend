A confirmation modal for revoking a pending invitation or removing an expired one, sharing a single dialog implementation with kind-specific wording.

## Key Components

- **`ConfirmRevokeInvitationModal`** — React component rendering a `ConfirmDialog` that confirms and executes the `revokeInvitation` GraphQL mutation via Relay.
- **`confirmRevokeInvitationModal_invitation$key`** — Relay fragment reference providing `id` and `email` of the invitation to display/revoke.
- **`WORDING`** — Maps the `kind` prop (`'revoke' | 'remove'`) to the dialog's title, body text, and error message, since both actions use the same underlying mutation.
- **`listingIds`** — Store connection IDs used to remove the invitation edge and decrement/invalidate cached invitation listing counts on success.

## Usage Example

```typescript
import { ConfirmRevokeInvitationModal } from '@/app/components/invitations/confirm-revoke-invitation-modal';

function InvitationRow({ invitation, connectionIds }) {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Revoke</button>
      <ConfirmRevokeInvitationModal
        invitation={invitation}
        kind="revoke"
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        listingIds={connectionIds}
      />
    </>
  );
}
```

The component expects the parent to spread a Relay fragment reference (`invitation`) and supply the active listing connection IDs so the invitation's row can be optimistically removed from cached lists via `@deleteEdge` and the `decrementInvitationsCount`/`invalidateInvitationsListings` store updaters. On mutation success, `onClose` is called; on failure, a destructive toast is shown with a Relay-derived error message.
