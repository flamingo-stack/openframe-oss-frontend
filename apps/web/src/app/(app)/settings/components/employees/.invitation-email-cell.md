# invitation-email-cell.tsx

Renders the "user" column cell for pending invitation rows in a table, displaying the invited email address alongside a generated avatar since invited users have no name yet.

## Key Components

- **`InvitationEmailCell`** — React component accepting an `invitation` fragment reference (`invitationEmailCell_invitation$key`) and rendering an avatar + truncated email for a table row.
- **`invitationEmailCellFragment`** — GraphQL fragment on `Invitation` that selects the `email` field.

## Behavior Notes

- Uses `useLoadingScope()` to detect whether the row is in a loading/skeleton state. When true, the fragment is not read (`null` is passed to `useFragment`), allowing the underlying UI primitives (`SquareAvatar`, `TruncateText`) to render their own loading placeholders.
- `SquareAvatar` derives its fallback visual (e.g., initials/icon) from the `email` string since invited users don't yet have a display name.
- `TruncateText` ensures long email addresses don't overflow the table cell.

## Usage Example

```typescript
import { graphql, useFragment } from 'react-relay';
import { InvitationEmailCell } from './invitation-email-cell';

function InvitationsTableRow({ invitation }: { invitation: invitationEmailCell_invitation$key }) {
  return (
    <tr>
      <td>
        <InvitationEmailCell invitation={invitation} />
      </td>
      {/* other columns, e.g. role, invited date, actions */}
    </tr>
  );
}
```

This component is intended to be used within a Relay-powered table of pending invitations, typically alongside other cell components (e.g., role, status, actions) that share the same `Invitation` GraphQL type.
