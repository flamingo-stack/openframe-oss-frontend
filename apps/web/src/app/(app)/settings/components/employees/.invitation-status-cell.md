# invitation-status-cell.tsx

Renders the STATUS column cell for a row in the invitations table, displaying an invitation's status as a styled tag while gracefully handling loading states via Relay fragments.

## Key Components

- **`InvitationStatusCell`** — React component that accepts an `invitation` prop (a Relay fragment key) and renders the invitation's `status` field inside an `EmployeeStatusTag`. It detects whether the row is part of a loading scope (via `useLoadingScope`) and, if so, skips reading the fragment, allowing the tag to render its own loading/placeholder state.
- **`invitationStatusCellFragment`** — GraphQL fragment (`invitationStatusCell_invitation`) defined on the `Invitation` type, selecting only the `status` field needed by this cell.

## Usage Example

```typescript
import { InvitationStatusCell } from './invitation-status-cell';
import type { invitationStatusCell_invitation$key } from '@/__generated__/invitationStatusCell_invitation.graphql';

function InvitationsTableRow({ invitation }: { invitation: invitationStatusCell_invitation$key }) {
  return (
    <tr>
      <td>
        <InvitationStatusCell invitation={invitation} />
      </td>
    </tr>
  );
}
```

The parent query must spread the `invitationStatusCell_invitation` fragment onto the `Invitation` object passed as `invitation`. When used within a loading scope (e.g., skeleton rows while data streams in), the component automatically bypasses fragment reading and defers to `EmployeeStatusTag`'s loading presentation, avoiding Relay errors from reading fragments on placeholder data.
