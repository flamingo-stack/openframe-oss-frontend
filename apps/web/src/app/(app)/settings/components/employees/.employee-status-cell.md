# employee-status-cell.tsx

Renders the STATUS column cell for a row in the users table, displaying an employee's status as a tag while gracefully handling loading states via Relay fragments.

## Key Components

- **`EmployeeStatusCell`** — Client component that reads a user's `status` field through a GraphQL fragment and renders it using `EmployeeStatusTag`. Accepts a `user` prop typed as `employeeStatusCell_user$key`, a Relay fragment reference.
- **`employeeStatusCellFragment`** — GraphQL fragment (`employeeStatusCell_user`) defined on the `User` type, selecting only the `status` field.

## Behavior Notes

- Uses `useLoadingScope()` to detect whether the row is still being fetched. When in a loading scope, `useFragment` is called with `null` instead of the fragment reference, so the cell skips data reading and `EmployeeStatusTag` renders its own loading/skeleton form.
- The wrapping `<div>` uses `flex min-w-0 items-center` so the status chip retains its intrinsic width rather than stretching to fill the table cell.

## Usage Example

```typescript
import { EmployeeStatusCell } from './employee-status-cell';

// Typically rendered as a cell within a Relay-powered table row
function UsersTableRow({ user }: { user: employeeStatusCell_user$key }) {
  return (
    <tr>
      <td>
        <EmployeeStatusCell user={user} />
      </td>
    </tr>
  );
}
```

This component is intended to be used alongside a parent query/fragment that spreads `...employeeStatusCell_user` on the `User` type, enabling Relay to compose the data requirements across the users table.
