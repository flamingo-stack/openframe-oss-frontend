# invitations-list-table.tsx

Renders a paginated, searchable, filterable list of pending employee invitations using Relay for data fetching, infinite scroll, and automatic refetching on mutation invalidation.

## Key Components

- **`InvitationsListTable`** — Public entry component. Wraps `InvitationsListReader` in a `LoadingSuspense` boundary with the "Loading invitations" label, so query suspension is caught locally.
- **`InvitationsListReader`** — Internal dispatcher. If inside an active loading scope (fallback render), renders `InvitationsTable` with placeholder/empty state; otherwise delegates to `InvitationsListQuery` to run the live Relay query.
- **`InvitationsListQuery`** — Core data-fetching component. Uses `useLazyLoadQuery` to load the first page, `usePaginationFragment` for infinite scroll (`loadNext`, `hasNext`, `isLoadingNext`), and `useSubscribeToInvalidationState` to silently refetch the connection (without suspending) whenever a mutation (invite, resend, etc.) marks the invitations listing stale.
- **`invitationsListTableQueryNode`** — GraphQL query fetching the paginated connection fragment plus `invitationFilters` (kept outside the fragment so filter counts aren't recomputed per page).
- **`invitationsListTableFragment`** — Refetchable, `@connection`-annotated fragment (`invitationsListTable_invitations`) exposing `__id`, `filteredCount`, and invitation edges.

## Usage Example

```typescript
import { InvitationsListTable } from './invitations-list-table';

function EmployeesInvitationsSection() {
  const [search, setSearch] = useState('');
  const [selections, setSelections] = useState<EmployeeSelections>({});
  const [backendSelections, setBackendSelections] = useState<EmployeeSelections>({});

  return (
    <InvitationsListTable
      search={search}
      backendSelections={backendSelections}
      selections={selections}
      onSelectionsChange={setSelections}
      isPending={false}
      stickyHeaderOffset="64px"
    />
  );
}
```

**Notes:**
- `selections` drives instant header tick rendering; `backendSelections` lags behind and drives the actual server filter during a pending transition.
- The component relies on `invitationsListingId` / `affectedInvitationsListings` from `./invitations-listing` to scope mutation-driven invalidation to the correct connection.
- Pagination size is controlled by `INVITATIONS_PAGE_SIZE` from `./employees-columns`.
