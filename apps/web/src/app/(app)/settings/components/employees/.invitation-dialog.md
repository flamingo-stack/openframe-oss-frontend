## invitation-dialog.tsx

A dispatcher component that renders the appropriate confirmation modal (resend or revoke) for an invitation action, based on a GraphQL fragment colocated with both modal components.

## Key Components

- **`InvitationDialog`** — React component that reads invitation data via a Relay fragment and conditionally renders either `ConfirmResendInvitationModal` or `ConfirmRevokeInvitationModal` depending on the `kind` prop.
- **`invitationDialogFragment`** — GraphQL fragment on `Invitation` that composes the fragments required by both child modals (`confirmRevokeInvitationModal_invitation` and `confirmResendInvitationModal_invitation`).
- **`InvitationDialogProps`** — Props interface requiring an `invitation` fragment reference, an `InvitationAction` `kind`, dialog open/close state, and `listingIds` for Relay store updates.

## Usage Example

```typescript
import { InvitationDialog } from './invitation-dialog';
import type { InvitationAction } from './invitation-actions-cell';

function InvitationRow({ invitation, listingIds }) {
  const [action, setAction] = useState<InvitationAction | null>(null);

  return (
    <>
      <button onClick={() => setAction('resend')}>Resend</button>
      <button onClick={() => setAction('revoke')}>Revoke</button>

      {action && (
        <InvitationDialog
          invitation={invitation}
          kind={action}
          isOpen={Boolean(action)}
          onClose={() => setAction(null)}
          listingIds={listingIds}
        />
      )}
    </>
  );
}
```

This component acts as a single entry point for invitation-related confirmation dialogs, keeping the parent component (such as `invitation-actions-cell`) decoupled from the specifics of which modal to render.
