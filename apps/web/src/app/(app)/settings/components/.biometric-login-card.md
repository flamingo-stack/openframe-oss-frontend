# biometric-login-card.tsx

A client-side React component that renders a toggle switch for enabling/disabling biometric login (Face ID / Touch ID / Fingerprint) within the native mobile shell. It safely renders nothing on web/desktop or unsupported devices, making it safe to mount unconditionally on settings pages.

## Key Components

- **`BiometricLoginCard()`** — Main exported component. Checks platform and device capability on mount, displays a labeled switch (e.g., "Face ID", "Touch ID"), and handles toggle state transitions with optimistic UI updates.
- **`handleToggle(next: boolean)`** — Internal handler that enables/disables biometric login via native bridge calls, reverts state on failure, and surfaces toast notifications for success/error cases.

### Behavior highlights
- Returns `null` immediately if not running in the mobile shell (`isMobileShell()`) or if biometrics are unavailable on the device.
- Performs an **optimistic UI update**: the switch flips immediately, then reverts if the native call rejects.
- Records the user's explicit choice (`accepted`/`declined`) via `setBiometricLoginChoice`, feeding the anti-spam policy for the post-login enrollment prompt.
- Special-cases `BIOMETRIC_ERROR.CANCELED` (silently ignored — user canceled the native prompt) and `BIOMETRIC_ERROR.INVALIDATED` (triggers a hard sign-out via `signOutToLogin` since gated tokens become unrecoverable after biometric enrollment changes).

## Usage Example

```tsx
import { BiometricLoginCard } from '@/components/biometric-login-card';

function SettingsPage() {
  return (
    <div className="space-y-4">
      <h2>Security</h2>
      {/* Safe to render unconditionally — no-ops on unsupported platforms */}
      <BiometricLoginCard />
    </div>
  );
}
```

No props are required or accepted — the component is self-contained and derives all state from native platform APIs (`isBiometricAvailable`, `isBiometricLoginEnabled`) and context hooks (`useToast`, `useQueryClient`, `useRouter`).
