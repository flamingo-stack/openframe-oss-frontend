# settings-tab-content.tsx

A client-side React component that dynamically renders the appropriate content panel based on the currently active settings tab, with built-in fallback handling for invalid tab selections.

## Key Components

- **`SettingsTabContentProps`** - Interface defining the component's props, requiring an `activeTab` string.
- **`SettingsTabContent`** - Functional component that resolves and renders the correct tab's content using `getTabComponent` from `@flamingo-stack/openframe-frontend-core`, looking up the component within the `SETTINGS_TABS` configuration.

The component handles two states:
1. **Not found state** - Displays a centered error message when `activeTab` doesn't match any registered tab.
2. **Success state** - Renders the resolved `TabComponent` inside a wrapper with a minimum height for consistent layout.

## Usage Example

```typescript
import { useState } from 'react';
import { SettingsTabContent } from './settings-tab-content';

function SettingsPage() {
  const [activeTab, setActiveTab] = useState('general');

  return (
    <div>
      {/* Tab navigation would set activeTab via setActiveTab */}
      <SettingsTabContent activeTab={activeTab} />
    </div>
  );
}
```

This component is typically used alongside a tab navigation UI (e.g., tab buttons or a sidebar) that controls the `activeTab` state. It relies on `SETTINGS_TABS` (defined in `./tabs`) to map tab identifiers to their corresponding React components, enabling a scalable, data-driven approach to managing settings sections.
