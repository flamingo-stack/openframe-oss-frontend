Renders a single clickable settings card (icon, title, description, optional badge, and a trailing chevron) used in settings navigation grids, with built-in skeleton loading support via `useLoadingScope`.

## Key Components

- **`SettingMenuItem`** — Default-exported function component rendering the card UI.
- **`SettingMenuItemProps`** — Props interface:
  - `href` (`string`) — navigation target for the card's link.
  - `icon` (`ReactNode`) — glyph rendered in the icon frame.
  - `title` (`string`) — card heading; shows a skeleton when loading and empty.
  - `description` (`string`) — card subtext; shows a skeleton when loading and empty.
  - `badge` (`ReactNode`, optional) — inline stamp next to the title (e.g., a "Beta" tag).
  - `listItem` (`boolean`, optional) — marks the card as part of a read list for the loading height gate (sets `data-loading-item`).
- **Style constants** — `CARD_SHELL_CLASSES`, `ICON_FRAME_CLASSES`, `CHEVRON_FRAME_CLASSES`, `CHEVRON_CLASSES` define the fixed-height card shell so loading and loaded states render at identical dimensions.

While `useLoadingScope()` reports a loading state, the component swaps `title`/`description` text for `TextLineSkeleton` placeholders (only when those values are empty) and replaces the clickable `Link` with a static, non-interactive chevron frame—preventing navigation to cards whose destination isn't yet resolved.

## Usage Example

```typescript
import { SettingMenuItem } from './setting-menu-item';
import { SettingsIcon } from '@flamingo-stack/openframe-frontend-core/components/icons-v2';

export function SettingsGrid() {
  return (
    <div className="grid grid-cols-2 gap-4">
      <SettingMenuItem
        href="/settings/profile"
        icon={<SettingsIcon className="size-6" />}
        title="Profile"
        description="Manage your personal information"
      />
      <SettingMenuItem
        href="/settings/integrations"
        icon={<SettingsIcon className="size-6" />}
        title="Integrations"
        description="Connect third-party tools"
        badge={<span className="text-xs">Beta</span>}
        listItem
      />
    </div>
  );
}
```
