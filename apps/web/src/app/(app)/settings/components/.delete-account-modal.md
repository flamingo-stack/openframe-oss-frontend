# delete-account-modal.tsx

Confirmation modal for self-service account deletion, with an owner-specific variant that requires transferring organization ownership before the account can be deleted.

## Key Components

- **`DeleteAccountModal`** — Main exported component rendering a `SimpleModal` with "Confirm Deletion" title, dynamic body copy, and action buttons (Cancel / Delete or Transfer & Delete).
- **`transferMutation`** (GraphQL) — `transferOwnership` mutation used to hand over ownership to a selected new owner before deletion.
- **`deleteMutation`** (GraphQL) — `deleteUser` mutation used to delete the current authenticated user's account.
- **`DeleteAccountModalProps`** — Props interface: `open` (boolean) and `onOpenChange` (callback to control modal visibility).

## Behavior

- Uses `useOwnerGate()` to determine if the current user is the organization `owner`, a regular user, or still `loading`.
- **Regular user**: shows warning copy with Cancel / "Delete Account" actions.
- **Owner**: additionally shows an error banner and a mandatory `NewOwnerSelect` picker; confirm button reads "Transfer & Delete Account" and stays disabled until a successor is selected.
- The owner flow runs transfer and delete **sequentially** (not atomically) — if delete fails after a successful transfer, the caller remains signed in as an ADMIN, and the gate re-evaluates via `/me` invalidation so a retry correctly shows the non-owner delete flow.
- On successful deletion, calls `useLeaveDeletedAccount()` to trigger logout/redirect; the modal intentionally does not close itself since the underlying page is replaced.
- While `ownerGate` is `'loading'`, the confirm button is disabled rather than assuming a variant.
- Errors from either mutation are surfaced via `useToast` using `getRelayErrorMessage`.

## Usage Example

```typescript
import { useState } from 'react';
import { DeleteAccountModal } from '@/app/(account)/account/components/delete-account-modal';

function AccountSettingsPage() {
  const [isDeleteModalOpen, setIsDeleteModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsDeleteModalOpen(true)}>
        Delete Account
      </button>

      <DeleteAccountModal
        open={isDeleteModalOpen}
        onOpenChange={setIsDeleteModalOpen}
      />
    </>
  );
}
```
