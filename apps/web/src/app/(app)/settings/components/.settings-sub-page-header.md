# settings-sub-page-header.tsx

A client-side React component that renders a reusable header for settings sub-pages, featuring a back navigation link and a truncated page title.

## Key Components

- **`SettingsSubPageHeaderProps`** - Interface defining the component's props, requiring a `title: string`.
- **`SettingsSubPageHeader`** - Default-style functional component that renders:
  - A back-navigation link (`Link`) pointing to `routes.settings.root()`, styled as a square button with a left arrow icon (`Arrow01LeftIcon`).
  - An `h1` wrapping a `TruncateText` component (rendered `as="span"` to preserve valid heading semantics) that displays the truncated `title`, styled with the `h2` typography variant.

## Usage Example

```typescript
import { SettingsSubPageHeader } from '@/components/settings-sub-page-header';

export default function NotificationsSettingsPage() {
  return (
    <div>
      <SettingsSubPageHeader title="Notification Preferences" />
      {/* Rest of the sub-page content */}
    </div>
  );
}
```

This component is typically placed at the top of settings sub-pages (e.g., Notifications, Security, Billing) to provide consistent navigation back to the main settings page and a clear, truncation-safe title display for long page names.
