The main settings dashboard component that renders the unified settings hub page, including account info, navigation cards for sub-sections, and logout functionality.

## Key Components

### `SettingsHub`
The primary exported component that composes the full settings page. It manages:
- **Profile editing** — opens `EditProfileModal` and calls `PUT api/users/:id` to persist name changes
- **Email verification** — shows `EmailVerificationBanner` when unverified; triggers `authApiClient.resendVerificationEmail` via `EmailVerificationModal`
- **Navigation grid** — renders `SETTINGS_NAV_ITEMS` as clickable `SettingMenuItem` cards, filtered by feature flags and tenant mode
- **Logout** — triggers the logout confirm flow via `useLogoutConfirmStore`
- **Biometric login** — conditionally renders `BiometricLoginCard` (native shell only)

### `SETTINGS_NAV_ITEMS`
A static array of navigation card definitions (icon, title, description, href) pointing to:
- Billing & Usage, AI Settings & Guardrails, Architecture Overview, Employees, API Keys Management, SSO Configuration

Two items are conditionally filtered:
- `billingUsage` — hidden unless `featureFlags.subscription.enabled()`
- `architecture` — hidden unless `isOssTenantMode()`

## Usage Example

```typescript
// Rendered automatically via the settings route — no props required
import { SettingsHub } from './settings-hub';

export default function SettingsPage() {
  return <SettingsHub />;
}
```

## State

| State | Purpose |
|---|---|
| `isEditModalOpen` | Controls `EditProfileModal` visibility |
| `isUpdating` | Disables save button during profile update |
| `isSendingVerification` | Disables resend button during email dispatch |
| `isVerificationModalOpen` | Controls `EmailVerificationModal` visibility |
