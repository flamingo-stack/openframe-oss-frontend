# add-users-modal.tsx

A modal dialog component that allows admins to invite one or more users to the system by email, with per-row role selection, client-side email validation, and partial-failure handling via GraphQL mutation.

## Key Components

- **`AddUsersModal`** — Main exported React component rendering the modal. Props:
  - `isOpen: boolean` — controls modal visibility
  - `onClose: () => void` — close handler
  - `onInvited: () => void` — called when at least one invitation succeeds
  - `listingIds: readonly string[]` — invitation listing IDs to refetch after mutation
- **`addUsersModalMutationNode`** — GraphQL mutation (`inviteUsers`) that sends invite requests for a list of emails and returns `userErrors`.
- **`InviteRow`** — internal type representing a single form row (`email`, `role`).
- **`EMAIL_PATTERN`** — regex for lightweight client-side email format validation (server performs the authoritative check).
- **`ROLE_OPTIONS`** — static list of selectable roles (currently only `Admin`).

## Behavior Notes

- Form state resets to a single empty row when the modal transitions from open to closed, handled synchronously during render (not via `useEffect`) to avoid stale values flashing during the close animation.
- On submit, valid emails are extracted and sent via `commit`. The Relay `updater` invalidates invitation listings (`invalidateInvitationsListings`) regardless of partial failure.
- Partial failures are handled gracefully: successfully sent rows are removed from the form (via `refusedEmailIndexes`/`describeInviteRefusals`) so resubmitting only retries failed rows, preventing duplicate invites.
- Toast notifications communicate success, partial success, or failure states.

## Usage Example

```typescript
import { useState } from 'react';
import { AddUsersModal } from '@/app/components/add-users-modal';

function EmployeesPage({ listingIds }: { listingIds: string[] }) {
  const [isModalOpen, setModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Add Employees</button>
      <AddUsersModal
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
        onInvited={() => {
          // refresh employee/invitation list
        }}
        listingIds={listingIds}
      />
    </>
  );
}
```
