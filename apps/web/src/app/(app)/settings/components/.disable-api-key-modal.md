A modal dialog component for confirming the disabling/deactivation of an API key, wrapping the shared `ConfirmDialog` with destructive variant styling.

## Key Components

- **`DisableApiKeyModal`** — Client component that renders a confirmation dialog before deactivating an API key
- **`DisableApiKeyModalProps`** — Interface defining the component's props:
  - `isOpen` — Controls dialog visibility
  - `onClose` — Callback fired when the dialog is dismissed
  - `apiKeyName` — Optional display name of the key being disabled (falls back to `"this API Key"`)
  - `onConfirm` — Async callback executed upon user confirmation

## Usage Example

```typescript
import { DisableApiKeyModal } from './disable-api-key-modal';

function ApiKeySettings() {
  const [modalOpen, setModalOpen] = useState(false);

  const handleDisable = async () => {
    await disableApiKey(keyId);
    setModalOpen(false);
  };

  return (
    <DisableApiKeyModal
      isOpen={modalOpen}
      onClose={() => setModalOpen(false)}
      apiKeyName="Production Key"
      onConfirm={handleDisable}
    />
  );
}
```

## Notes

- Uses the `destructive` variant on `ConfirmDialog`, rendering the confirm button in an error/danger style
- The API key name is highlighted in `text-ods-error` (red) within the description to draw user attention
- Disabling is reversible — the dialog copy clarifies the key can be reactivated, distinguishing this action from permanent deletion
