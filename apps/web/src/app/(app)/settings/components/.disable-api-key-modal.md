A client-side confirmation modal that prompts the user to confirm disabling an API key, built as a thin wrapper around the shared `ConfirmDialog` component.

## Key Components

- **`DisableApiKeyModalProps`** — Interface defining the component's props: `isOpen`, `onClose`, `apiKeyName` (optional), and `onConfirm` (async callback).
- **`DisableApiKeyModal`** — React component that renders a `ConfirmDialog` with a destructive variant, displaying the API key name (or a fallback label) and triggering the provided `onConfirm` callback when confirmed.

## Usage Example

```typescript
import { useState } from 'react';
import { DisableApiKeyModal } from '@/app/components/api-keys/disable-api-key-modal';

function ApiKeyRow({ apiKey }: { apiKey: { id: string; name: string } }) {
  const [isModalOpen, setIsModalOpen] = useState(false);

  async function handleDisable() {
    await fetch(`/api/keys/${apiKey.id}/disable`, { method: 'POST' });
    setIsModalOpen(false);
  }

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>Disable</button>
      <DisableApiKeyModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        apiKeyName={apiKey.name}
        onConfirm={handleDisable}
      />
    </>
  );
}
```

## Notes

- Relies on the shared `ConfirmDialog` component located at `@/app/components/shared/confirm-dialog`.
- The `onConfirm` callback should handle the actual API call and any error handling; the modal itself does not manage loading or error states.
- If `apiKeyName` is not provided, the dialog falls back to the generic label `"this API Key"`.
