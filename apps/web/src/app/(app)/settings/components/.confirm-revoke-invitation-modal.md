A modal dialog component for confirming the revocation of a pending user invitation, wrapping the shared `ConfirmDialog` with invitation-specific messaging.

## Key Components

- **`ConfirmRevokeInvitationModal`** — Named export that renders a destructive confirmation dialog, highlighting the target user's email in error styling and warning that the invitation will be permanently deleted.
- **`ConfirmRevokeInvitationModalProps`** — Interface defining the component's props:
  - `open` — Controls dialog visibility
  - `onOpenChange` — Callback for open/close state changes
  - `userEmail` — Email address of the invited user, displayed in the confirmation message
  - `onConfirm` — Async or sync callback executed when the user confirms revocation

## Usage Example

```typescript
import { ConfirmRevokeInvitationModal } from './confirm-revoke-invitation-modal';

function InvitationsTable() {
  const [isOpen, setIsOpen] = useState(false);

  const handleRevoke = async () => {
    await revokeInvitation(invitationId);
    setIsOpen(false);
  };

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Revoke</Button>
      <ConfirmRevokeInvitationModal
        open={isOpen}
        onOpenChange={setIsOpen}
        userEmail="jane@example.com"
        onConfirm={handleRevoke}
      />
    </>
  );
}
```

## Notes

- Delegates all dialog rendering to the shared [`ConfirmDialog`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/components/shared/confirm-dialog.tsx) component.
- The target email is rendered with the `text-ods-error` class to visually emphasize the destructive nature of the action.
- Marked `'use client'` — must be used within a React Client Component tree.
