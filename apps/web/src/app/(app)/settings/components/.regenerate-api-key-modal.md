# regenerate-api-key-modal.tsx

A confirmation modal component that prompts the user to confirm regeneration of an API key, warning that the current key will stop working immediately once regenerated.

## Key Components

- **`RegenerateApiKeyModalProps`** — Interface defining the component props: `isOpen` (visibility flag), `onClose` (close callback), `apiKeyName` (optional display name for the key), and `onConfirm` (async handler invoked on confirmation).
- **`RegenerateApiKeyModal`** — The main exported component. Wraps the shared `ConfirmDialog` component with warning-styled copy and pending-state handling specific to API key regeneration.

### Implementation Details
- Uses a render-time comparison (`isOpen` vs. `wasOpen`) instead of a `useEffect` to reset `loading` on close, avoiding a one-frame flash of stale state during the closing animation.
- Wraps `onConfirm` in a `try/finally` block so that a rejected promise still resets `loading`, preventing the dialog from becoming stuck in a "Regenerating…" state with a dead confirm button.
- Renders a `warning` variant `ConfirmDialog` with custom `confirmLabel` ("Regenerate API Key") and `pendingLabel` ("Regenerating...").

## Usage Example

```typescript
import { useState } from 'react';
import { RegenerateApiKeyModal } from '@/app/components/.../regenerate-api-key-modal';

function ApiKeySettings() {
  const [isModalOpen, setIsModalOpen] = useState(false);

  const handleRegenerate = async () => {
    await fetch('/api/keys/regenerate', { method: 'POST' });
    // Refresh key list, show toast, etc.
  };

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>Regenerate Key</button>

      <RegenerateApiKeyModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        apiKeyName="Production API Key"
        onConfirm={handleRegenerate}
      />
    </>
  );
}
```
