A client-side modal component that prompts users to confirm regeneration of an API key, warning that the current key will stop working immediately.

## Key Components

### `RegenerateApiKeyModal`
The sole export — a wrapper around `ConfirmDialog` that manages async loading state during the regeneration operation.

**Props (`RegenerateApiKeyModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback fired when the dialog is dismissed |
| `apiKeyName` | `string?` | Display name of the key being regenerated |
| `onConfirm` | `() => Promise<void>` | Async handler that executes the regeneration |

**Behavior:**
- Tracks `loading` state during the async `onConfirm` call
- Resets `loading` to `false` whenever `isOpen` changes to `false` (handles external close without confirmation)
- Displays the key name highlighted in warning color; falls back to `"this API Key"` if no name is provided

## Usage Example

```typescript
import { RegenerateApiKeyModal } from '@/app/components/regenerate-api-key-modal';

function ApiKeySettings() {
  const [open, setOpen] = useState(false);

  const handleRegenerate = async () => {
    await apiClient.regenerateKey('my-service-key');
    setOpen(false);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Regenerate Key</button>
      <RegenerateApiKeyModal
        isOpen={open}
        onClose={() => setOpen(false)}
        apiKeyName="my-service-key"
        onConfirm={handleRegenerate}
      />
    </>
  );
}
```
