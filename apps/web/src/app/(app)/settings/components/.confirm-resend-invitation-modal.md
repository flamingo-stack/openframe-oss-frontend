A modal dialog component that prompts the user to confirm resending an invitation email to a specific user, warning that the previous invitation will be invalidated.

## Key Components

### `ConfirmResendInvitationModal`
A wrapper around the shared `ConfirmDialog` component, pre-configured with warning styling and messaging for the resend invitation flow.

**Props (`ConfirmResendInvitationModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle open state |
| `userEmail` | `string` | The recipient's email address, highlighted in the dialog body |
| `onConfirm` | `() => Promise<void> \| void` | Async or sync handler called when the user confirms the action |

## Usage Example

```typescript
import { ConfirmResendInvitationModal } from '@/app/components/shared/confirm-resend-invitation-modal';

function UserRow({ user }) {
  const [open, setOpen] = useState(false);

  async function handleResend() {
    await resendInvitation(user.id);
  }

  return (
    <>
      <button onClick={() => setOpen(true)}>Resend Invite</button>
      <ConfirmResendInvitationModal
        open={open}
        onOpenChange={setOpen}
        userEmail={user.email}
        onConfirm={handleResend}
      />
    </>
  );
}
```

## Notes

- Renders as a `"warning"` variant dialog, applying `text-ods-warning` styling to the target email address.
- The confirm action supports both synchronous and asynchronous handlers.
