# new-owner-candidates.tsx

Implements the candidate-selection step of an ownership-transfer flow: it queries the server for other ACTIVE users in the organization (excluding the current user) and renders a searchable autocomplete field for picking a new owner. If no eligible candidates exist, it displays guidance to invite a member or contact support instead of leaving a dead-end disabled control.

## Key Components

- **`NewOwnerCandidates`** — Public component that wraps the data-fetching logic in a `LoadingSuspense` boundary with a "Loading the members" label.
- **`NewOwnerCandidatesReader`** — Internal wrapper that detects whether it's rendering inside a loading scope (Suspense fallback) and short-circuits to a disabled `NewOwnerField` instead of firing a query.
- **`NewOwnerCandidatesQuery`** — Performs the actual GraphQL fetch via `useLazyLoadQuery`, builds autocomplete options from search results, and renders either the empty-state message or the populated `NewOwnerField`.
- **`newOwnerCandidatesQueryNode`** — GraphQL query fetching an `others` count (to detect sole-member workspaces) and a paginated, searchable `candidates` list.
- **`CANDIDATES_LIMIT`** (20) and **`SUPPORT_EMAIL`** (`hello@openframe.ai`) — Configuration constants used in the query and empty-state copy.

## Usage Example

```typescript
import { NewOwnerCandidates } from './new-owner-candidates';

function TransferOwnershipDialog({ currentUserId, organizationName }: Props) {
  const [search, setSearch] = useState('');
  const [picked, setPicked] = useState<AutocompleteOption | null>(null);

  return (
    <NewOwnerCandidates
      currentUserId={currentUserId}
      organizationName={organizationName}
      search={search}
      isSearching={false}
      onSearch={setSearch}
      value={picked?.value ?? ''}
      picked={picked}
      onChange={setPicked}
      disabled={false}
    />
  );
}
```

The `picked` prop ensures the previously selected user's label remains visible even after a new search invalidates the current option list, since `value` only carries the node ID needed by the `transferOwnership` mutation.
