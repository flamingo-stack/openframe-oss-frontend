# new-owner-select.tsx

A React client component that provides a searchable autocomplete picker for selecting a new account owner, used within the owner-variant delete-account modal. It manages search input debouncing and wraps the candidate-fetching logic in an error boundary for graceful failure handling.

## Key Components

- **`NewOwnerSelect`** — Main exported component that renders the new owner picker. Manages local state for the search input, debounced/deferred search term, and the currently picked option.
- **`NO_OPTIONS`** — Static empty array constant used as a fallback option list when the data fetch fails.
- **`NewOwnerSelectProps`** — Props interface requiring `currentUserId`, `organizationName`, `value` (selected user's node id), `onChange` callback, and `disabled` flag.

The component delegates data fetching/rendering to `NewOwnerCandidates` (which performs the actual user search query) and renders the visual input via `NewOwnerField`. It uses `ContentErrorBoundary` to catch failures in the candidates fetch and display a disabled fallback field with an error message.

Search input is debounced by 300ms via `useDebounce`, then passed through `useDeferredValue` to avoid blocking the UI during fast typing, with `isSearching` indicating when the committed search term differs from the raw input.

## Usage Example

```typescript
import { useState } from 'react';
import { NewOwnerSelect } from './new-owner-select';

function DeleteAccountOwnerStep() {
  const [newOwnerId, setNewOwnerId] = useState('');

  return (
    <NewOwnerSelect
      currentUserId="user_123"
      organizationName="Acme Corp"
      value={newOwnerId}
      onChange={setNewOwnerId}
      disabled={false}
    />
  );
}
```

This component is intended to be mounted only while the delete-account modal (owner variant) is open, since the underlying user search request is tied to its lifecycle via `NewOwnerCandidates`.
