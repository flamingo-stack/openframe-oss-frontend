A client-side React component that renders a labeled "New Owner" autocomplete field, used for selecting a new owner from a searchable list of candidates (e.g., when reassigning ownership of a resource).

## Key Components

- **`NewOwnerFieldProps`** — Interface defining the component's props: `options`, `value`, `onChange`, `onSearch`, and optional `loading`, `disabled`, `error` states.
- **`NewOwnerField`** — The main exported function component. Renders a `Label` paired with an `Autocomplete` control from `@flamingo-stack/openframe-frontend-core`. Server-side filtering is enforced via `disableClientFilter`, delegating search behavior to the `onSearch` callback whenever the input changes due to user typing (`reason === 'input'`).

## Usage Example

```typescript
import { useState } from 'react';
import { NewOwnerField } from './new-owner-field';
import type { AutocompleteOption } from '@flamingo-stack/openframe-frontend-core/components/ui';

function ReassignOwnerForm() {
  const [options, setOptions] = useState<AutocompleteOption[]>([]);
  const [ownerId, setOwnerId] = useState<string | null>(null);
  const [loading, setLoading] = useState(false);

  const handleSearch = async (search: string) => {
    setLoading(true);
    const results = await fetchActiveUsers(search);
    setOptions(results);
    setLoading(false);
  };

  return (
    <NewOwnerField
      options={options}
      value={ownerId}
      onChange={setOwnerId}
      onSearch={handleSearch}
      loading={loading}
      error={!ownerId ? 'Owner is required' : undefined}
    />
  );
}
```

**Notes:**
- `onSearch` fires only on user-driven input changes, not on programmatic value updates.
- `loading` reflects an in-flight search request, independent of the field's `disabled` state.
- Pass `error` to display validation feedback and automatically mark the field as invalid.
