A client-side modal component for confirming user deletion, wrapping the shared `ConfirmDialog` with user-specific messaging.

## Key Components

### `ConfirmDeleteUserModal`

A pre-configured confirmation dialog that displays a destructive warning before removing a user account.

**Props (`ConfirmDeleteUserModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open state changes |
| `userName` | `string` | Name of the user to be deleted (highlighted in error color) |
| `onConfirm` | `() => Promise<void> \| void` | Async or sync callback executed on confirmation |

## Usage Example

```typescript
import { ConfirmDeleteUserModal } from './confirm-delete-user-modal';

function UserManagement() {
  const [open, setOpen] = useState(false);

  const handleDelete = async () => {
    await deleteUser(userId);
  };

  return (
    <ConfirmDeleteUserModal
      open={open}
      onOpenChange={setOpen}
      userName="Jane Doe"
      onConfirm={handleDelete}
    />
  );
}
```

## Notes

- Renders the target `userName` in `text-ods-error` styling to visually emphasize the destructive action.
- Supports both synchronous and asynchronous `onConfirm` handlers.
- Delegates all dialog behavior (accessibility, animations, cancel/confirm buttons) to the shared [`ConfirmDialog`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/components/shared/confirm-dialog.tsx) component.
