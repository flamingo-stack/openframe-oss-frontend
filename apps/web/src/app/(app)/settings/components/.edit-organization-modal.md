# edit-organization-modal.tsx

A modal component that lets users edit an organization's name, website, and logo image, built on top of the shared `SimpleModal` wrapper with optimistic cache updates via React Query.

## Key Components

- **`EditOrganizationModal`** — Main exported component rendering a modal form with image upload, company name, and website fields.
- **`EditOrganizationModalProps`** — Props interface requiring `isOpen`, `onClose`, `organization` (name, website, optional image), `onSave` (async handler), and `isSaving` flag.
- **`handleImageChange`** — Uploads a new logo via `uploadWithAuth`, then writes the result directly into the `tenantInfoQueryKeys.all` React Query cache with a cache-busting hash to avoid stale-avatar flicker.
- **`handleImageRemove`** — Deletes the current logo via `deleteWithAuth` and clears the image from the query cache.
- **`handleSave`** — Calls `onSave` with the current form values and closes the modal only on success.
- **Open-transition state sync** — Uses a `wasOpen` comparison during render (instead of `useEffect`) to re-seed form state exactly when the modal transitions to open, avoiding flash-of-stale-data and background-refetch overwrite issues.

## Usage Example

```typescript
import { EditOrganizationModal } from './edit-organization-modal';

function OrganizationSettings() {
  const [isOpen, setIsOpen] = useState(false);
  const { data: tenantInfo, mutateAsync: updateTenantInfo, isPending } = useUpdateTenantInfo();

  return (
    <EditOrganizationModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      organization={{
        name: tenantInfo.name,
        website: tenantInfo.website,
        image: tenantInfo.image,
      }}
      onSave={async data => {
        await updateTenantInfo(data);
      }}
      isSaving={isPending}
    />
  );
}
```

## Notes

- Relies on `@flamingo-stack/openframe-frontend-core` for `Button`, `Input`, `Label`, and `ImageUploader` primitives.
- Image uploads are capped at 5MB (`maxSize={5 * 1024 * 1024}`).
- Depends on local helpers `getFullImageUrl`, `uploadWithAuth`, `deleteWithAuth`, and query keys/types from `use-tenant-info` and `tenant-info` types, found under `src/app/.../hooks` and `src/app/.../types` in the [repository](https://github.com/flamingo-stack/openframe-oss-frontend).
