# profile.tsx

Renders the Profile tab of the user account settings, displaying the user's identity information with an edit action, handling email verification prompts, and managing the edit profile and email verification modals.

## Key Components

- **`ProfileTab`** — Main exported component that composes the profile view:
  - Fetches the full user profile on mount via `fetchFullProfile` from `useAuthStore`.
  - Determines loading/error state by combining `useLoadingScope`, the auth store's `user`, and the session state from `useAuthSession` (distinguishing "still loading" from a genuine "no user data" error).
  - Renders `UserIdentityRow` with a loading-aware skeleton state and an "Edit Profile" button (disabled while loading).
  - Shows `EmailVerificationBanner` when `user.emailVerified === false`.
  - Opens `EditProfileModal` and `EmailVerificationModal` on demand.
  - Handles resending verification emails via `authApiClient.resendVerificationEmail`, with toast notifications for success/failure.

## Usage Example

```typescript
import { ProfileTab } from './profile';

export function AccountSettingsPage() {
  return (
    <div>
      {/* Rendered as one of the account settings tabs */}
      <ProfileTab />
    </div>
  );
}
```

**Notes:**
- Requires an authenticated session context (`useAuthSession`, `useAuthStore`) to be available higher in the component tree.
- The component intentionally reads session-resolution state from the session query (not the store) to correctly detect the terminal "signed-in but no user" error case, consistent with the pattern used in `ProfileCard`.
- Must be used within a client component tree (`'use client'` directive).
