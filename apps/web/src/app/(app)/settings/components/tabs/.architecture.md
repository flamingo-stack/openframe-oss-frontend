# architecture.tsx

Renders the Architecture Overview page for the settings section, displaying integrated tools grouped by architectural layer with search filtering and loading-state skeletons.

## Key Components

- **`ArchitectureTab`** — Main page component. Fetches enabled integrated tools, provides a search input to filter tools by name/description/category/layer/URL, groups filtered results by `layer`, and renders each group via `ArchitectureLayer`. Wraps content in `PageLayout` with a back button.
- **`ArchitectureLayer`** — Renders a single layer's heading and a responsive grid of `ArchitectureToolCard` components. Shows skeleton placeholders (heading bar + card grid) while loading via `useLoadingScope`.
- **`ArchitectureToolCard`** — Renders a single tool as a `ServiceCard`, listing its URLs (with optional port), username, password, and API key as copyable/revealable rows. Renders a skeleton `ServiceCard` when in a loading scope or when `tool` is `null`.
- **`ARCHITECTURE_SKELETON_LAYERS` / `ARCHITECTURE_SKELETON_TOOLS` / `ARCHITECTURE_SKELETON_ROWS` / `ARCHITECTURE_SKELETON_TAG`** — Constants controlling the shape and count of loading-state skeletons, chosen to approximate typical data volumes rather than real limits.

## Usage Example

```typescript
import { ArchitectureTab } from '@/app/settings/architecture/architecture';

export default function ArchitecturePage() {
  return <ArchitectureTab title="Architecture Overview" />;
}
```

The component is self-contained: it internally fetches data via `useIntegratedTools()` and requires no additional props besides an optional `title`. Navigation back uses `useSafeBack`, falling back to `routes.settings.root()` when no prior route is available.
