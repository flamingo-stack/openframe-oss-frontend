## SSO Configuration Tab

A client-side React component (`SsoConfigurationTab`) that manages Single Sign-On provider configuration for a tenant, including listing configured providers, enabling/disabling the built-in OpenFrame login, managing shared domain-based auto-provisioning, and editing/deleting individual SSO provider configs.

## Key Components

- **`SsoConfigurationTab`** — Main exported component rendering the SSO settings page: provider table, search, add/edit/disable/delete flows, and the OpenFrame & shared auto-provision toggles.
- **`UiProviderRow`** — Type describing a table row's shape (status, config presence, allowed domains, auto-provision flag, and original raw data).
- **`SecondaryText`** — Helper component rendering a truncated secondary text cell, showing a skeleton placeholder while in a loading scope.
- **`EditProviderButton`** — Helper component rendering the per-row edit action button, disabled and inert during loading states.
- **`SSO_SKELETON_ROWS`** — Constant defining the number of skeleton rows shown while data loads.
- Integrates with hooks `useSsoConfig` and `useTenantDomain` for data fetching/mutation, and modals `SsoConfigModal`, `SsoConfigurationDetailsModal`, and `DisableOpenframeSsoModal` for create/edit/view/disable flows.

## Usage Example

```typescript
import { SsoConfigurationTab } from './sso-configuration';

export default function SettingsPage() {
  return (
    <div className="settings-page">
      <SsoConfigurationTab />
    </div>
  );
}
```

This component is self-contained: it fetches provider data, tenant domain info, and OpenFrame SSO status on mount, and manages all modal/dialog state internally. It is typically rendered as a tab within a larger settings layout (e.g., `PageLayout`) and requires the surrounding app to provide the `useSsoConfig`, `useTenantDomain`, `useToast`, and routing context (`useSafeBack`, `routes`) used internally.
