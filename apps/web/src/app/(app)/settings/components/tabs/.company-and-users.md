# company-and-users.tsx

Settings page component for managing company employees, rendering tabbed "Users" and "Invitations" lists with shared search and tab-scoped filters (roles, status), all synced to URL query parameters.

## Key Components

- **`CompanyAndUsersTab`** — Main exported component rendering the Settings → Employees page, composed of:
  - `TabNavigation` — switches between `users` and `invitations` tabs
  - `SearchToolbar` — shared, debounced search input across both tabs
  - `UsersListTable` / `InvitationsListTable` — tab-specific data tables with server-side search/filter/pagination
  - `AddUsersModal` — modal for inviting new users
  - `ContentErrorBoundary` — isolates table-rendering failures per tab
- **`EMPLOYEES_TAB_VIEWS`** — static config mapping each `EmployeesTab` to its label, icon, and search placeholder
- **`EMPLOYEES_TABS`** — derived `TabItem[]` array consumed by `TabNavigation`
- **`isEmployeesTab`** — type guard narrowing a string param to `EmployeesTab`

## Usage Example

This component is intended to be rendered directly as a settings page/route, with no props:

```typescript
import { CompanyAndUsersTab } from '@/app/(authenticated)/settings/company-and-users';

export default function EmployeesPage() {
  return <CompanyAndUsersTab />;
}
```

Key behavioral notes for maintainers:

- **URL-synced state**: `tab`, `search`, `roles`, and `status` are managed via `useApiParams`, keeping the page state shareable/bookmarkable.
- **Search decoupling**: `useSearchParam` keeps typing responsive locally while debouncing updates to the URL.
- **Deferred queries**: `useDeferredQuery` ensures tab switches don't mix filters from one tab with the other's table, dimming the old table until the new data resolves.
- **Tab switch resets filters**: Changing tabs clears `roles`/`status` via `NO_EMPLOYEE_SELECTIONS` to avoid stale funnels bleeding across tabs.
- **Post-invite UX**: After inviting users via `AddUsersModal`, the view jumps to the `invitations` tab with filters cleared so new invitations are immediately visible.
