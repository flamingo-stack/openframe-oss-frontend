Barrel export file that aggregates and re-exports all settings tab components and navigation utilities from their respective modules.

## Key Components

| Export | Source Module | Description |
|--------|--------------|-------------|
| `ApiKeysTab` | `./api-keys` | Tab component for managing API keys |
| `ArchitectureTab` | `./architecture` | Tab component for architecture configuration |
| `CompanyAndUsersTab` | `./company-and-users` | Tab component for company and user management |
| `ProfileTab` | `./profile` | Tab component for user profile settings |
| `SsoConfigurationTab` | `./sso-configuration` | Tab component for SSO configuration |
| `getSettingsTabs` | `./navigation` | Function to retrieve available settings tabs |
| `SETTINGS_TABS` | `./navigation` | Constant defining settings tab identifiers |
| `SettingsTabNavigation` | `./navigation` | Navigation component for settings tabs |

## Usage Example

```typescript
import {
  ApiKeysTab,
  ArchitectureTab,
  CompanyAndUsersTab,
  ProfileTab,
  SsoConfigurationTab,
  SettingsTabNavigation,
  SETTINGS_TABS,
  getSettingsTabs,
} from '@/components/settings/tabs';

const tabs = getSettingsTabs();

function SettingsPage() {
  return (
    <>
      <SettingsTabNavigation tabs={tabs} />
      {activeTab === SETTINGS_TABS.PROFILE && <ProfileTab />}
      {activeTab === SETTINGS_TABS.API_KEYS && <ApiKeysTab />}
      {activeTab === SETTINGS_TABS.SSO && <SsoConfigurationTab />}
    </>
  );
}
```
