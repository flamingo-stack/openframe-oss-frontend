## API Keys Tab Component

Client-side React component rendering the API Keys management tab, providing a sortable/responsive data table of API keys with actions for viewing details, editing, regenerating, enabling, and disabling keys.

## Key Components

- **`ApiKeysTab`** — Main exported component rendering the full API Keys page, including the data table, empty state, action buttons (API Documentation, Create API Key), and all related modals (create, created, details, edit, regenerate, disable).
- **`KeyText`** — Internal helper that renders a table cell's text, swapping to a `TextLineSkeleton` when inside a loading scope (used for placeholder rows).
- **`KeyStatusTag`** — Internal helper rendering the enabled/disabled status `Tag`, with built-in loading skeleton support.
- **`API_KEYS_SKELETON_ROWS`** — Constant (10) defining the number of placeholder rows shown during initial load.
- **`renderRowActions`** — Builds the per-row `ActionsMenuDropdown` (Details, Edit, Regenerate, Enable/Disable) based on key state.
- **`columns`** — Responsive `ColumnDef[]` for the `DataTable`, progressively revealing columns (Key ID, Usage, Created, Expires) at larger breakpoints.

## Usage Example

```typescript
// Rendered as a tab within the settings page
import { ApiKeysTab } from './api-keys';

export default function SettingsApiKeysPage() {
  return <ApiKeysTab />;
}
```

The component relies on the `useApiKeys` hook for data fetching (`fetchApiKeys`, `createApiKey`, `updateApiKey`, `regenerateApiKey`, `setApiKeyEnabled`) and integrates with shared UI primitives (`DataTable`, `PageLayout`, `ActionsMenuDropdown`) from `@flamingo-stack/openframe-frontend-core`. It manages local modal visibility state for create/edit/details/regenerate/disable flows, and surfaces errors via `useToast`. Loading states use placeholder rows (`loadingPlaceholderRows`) with per-cell skeletons rather than a full-table spinner, keeping existing data visible during refetches.
