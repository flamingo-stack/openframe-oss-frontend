A React client component that renders the API Keys management tab within the Settings section, providing a data table for listing, creating, editing, regenerating, and disabling API keys.

## Key Components

- **`ApiKeysTab`** — Main exported component. Orchestrates the full API key management UI including:
  - A `DataTable` with columns for Name, Status, Key ID, Usage, Created, and Expires
  - Row-level actions: Edit, Regenerate, Enable/Disable (with confirmation modal for disable), and Details
  - Page-level actions: link to Swagger UI documentation and Create API Key button
  - Modal state management for create, edit, details, regenerate, disable, and post-create key display

## Key Hooks & State

| Hook / State | Purpose |
|---|---|
| `useApiKeys` | Fetches and mutates API key records |
| `useDataTable` | Configures the `DataTable` instance |
| `useSafeBack` | Handles back navigation to settings root |
| `selectedKey` | Tracks the active `ApiKeyRecord` across modals |
| `createdFullKey` | Temporarily holds the full key string after creation/regeneration |

## Usage Example

```typescript
// Rendered as a tab within the Settings page
import { ApiKeysTab } from './api-keys';

export default function SettingsPage() {
  return <ApiKeysTab />;
}
```

> **Note:** Disable requires confirmation via `DisableApiKeyModal`; enable is applied immediately without a confirmation step. After key creation or regeneration, the full key is shown once via `ApiKeyCreatedModal` and then cleared from state.
