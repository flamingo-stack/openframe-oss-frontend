Client component that renders a confirmation dialog for soft-deleting a user (marking them as `DELETED`), handling the GraphQL mutation, success/error toasts, and post-deletion navigation back to the employees list.

## Key Components

- **`ConfirmDeleteUserModal`** — React component that:
  - Resolves user data via `useFragment` (`confirmDeleteUserModal_user` fragment) to display the user's name in the confirmation message.
  - Executes the `deleteUser` GraphQL mutation (`confirmDeleteUserModalMutation`) through `useMutation`, which soft-deletes the user by updating their `status`.
  - On success: shows a success toast, closes the modal, and redirects to `routes.settings.employees`.
  - On error: shows a destructive toast with a message derived from `getRelayErrorMessage`.
  - Renders the shared `ConfirmDialog` component, passing a loading state (`isInFlight`) to disable actions while the mutation is pending.
- **`confirmDeleteUserModalFragment`** — GraphQL fragment pulling the user's `id` and summary fields (`userSummaryFields_user`).
- **`confirmDeleteUserModalMutationNode`** — GraphQL mutation definition for `deleteUser`.
- **`ConfirmDeleteUserModalProps`** — Props interface requiring a Relay fragment reference (`user`), `isOpen`, and `onClose`.

## Usage Example

```typescript
import { ConfirmDeleteUserModal } from '@/app/components/users/confirm-delete-user-modal';

function UserRow({ user }: { user: confirmDeleteUserModal_user$key }) {
  const [isModalOpen, setModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Delete</button>
      <ConfirmDeleteUserModal
        user={user}
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
      />
    </>
  );
}
```

Note: The `user` prop must be a Relay fragment reference spreading `confirmDeleteUserModal_user` on the parent query/component, obtained from a parent GraphQL query that includes the corresponding fragment spread.
