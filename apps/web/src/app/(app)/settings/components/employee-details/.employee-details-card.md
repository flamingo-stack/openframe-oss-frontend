This file defines reusable Tailwind CSS class constants for styling an employee details card component, supporting responsive layouts across different content breakpoints.

## Key Components

- **`CARD_CONTAINER`** — Class string for the outer card wrapper. Applies a column layout by default, switching to a row layout with centered items and system spacing at the `content-md` breakpoint. Includes border, rounded corners, and themed background styling.
- **`CARD_ROW`** — Class string for inner content rows within the card. Uses flex layout with system spacing by default, and switches to CSS `contents` display at the `content-md` breakpoint (allowing child elements to participate directly in the parent's grid/flex layout).

## Usage Example

```typescript
import { CARD_CONTAINER, CARD_ROW } from './employee-details-card';

function EmployeeDetailsCard({ employee }) {
  return (
    <div class={CARD_CONTAINER}>
      <div class={CARD_ROW}>
        <span>Name:</span>
        <span>{employee.name}</span>
      </div>
      <div class={CARD_ROW}>
        <span>Role:</span>
        <span>{employee.role}</span>
      </div>
    </div>
  );
}
```

Centralizing these class strings as constants keeps styling consistent across components that render employee card layouts and simplifies future design-token updates (e.g., spacing variables like `--spacing-system-m`).
