Defines the fallback/placeholder title displayed on an employee details page while the record is loading or when no matching user exists for the given id.

## Key Components

- **`EMPLOYEE_DETAILS_TITLE`** — A string constant (`'Employee'`) used as the default page title for employee detail views in loading or not-found states.

## Usage Example

```typescript
import { EMPLOYEE_DETAILS_TITLE } from './employee-details-title';

function getPageTitle(employee?: { name: string }): string {
  return employee?.name ?? EMPLOYEE_DETAILS_TITLE;
}

// While loading or if the employee record doesn't exist:
document.title = getPageTitle(undefined); // "Employee"

// Once the employee data has loaded:
document.title = getPageTitle({ name: 'Jane Doe' }); // "Jane Doe"
```

This constant centralizes the fallback title string so it can be reused consistently across components that render an employee details page, avoiding hardcoded string duplication.
