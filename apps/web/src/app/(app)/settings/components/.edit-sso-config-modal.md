Modal component for configuring and editing SSO (Single Sign-On) provider settings, supporting OAuth credentials, Microsoft-specific tenant configuration, and domain-based auto-provisioning.

## Key Components

### `SsoConfigModal` / `EditSsoConfigModal`
The primary exported component (also re-exported as `EditSsoConfigModal` for backwards compatibility). Renders a two-column modal layout:

- **Left column** — OAuth credentials form (redirect URL display/copy, Client ID, Client Secret with visibility toggle, Microsoft single-tenant Tenant ID)
- **Right column** — Domain allowlist configuration with optional auto-provisioning

### `SsoConfigModalProps`
Interface defining all modal props:

| Prop | Type | Description |
|---|---|---|
| `providerKey` | `string` | Lowercase provider identifier (e.g., `"microsoft"`) |
| `providerDisplayName` | `string` | Human-readable provider name for UI labels |
| `isEnabled` | `boolean` | Shows "Disable" button when `true` |
| `initialClientId/Secret/MsTenantId` | `string \| null` | Pre-populated form values |
| `initialAutoProvisionUsers` | `boolean` | Auto-provisioning toggle initial state |
| `initialAllowedDomains` | `string[]` | Pre-populated domain allowlist |
| `onSubmit` | `async fn` | Callback with collected config data |
| `onDisable` | `async fn` | Callback to disable the SSO provider |

## Usage Example

```typescript
<SsoConfigModal
  isOpen={isModalOpen}
  onClose={() => setIsModalOpen(false)}
  providerKey="microsoft"
  providerDisplayName="Microsoft"
  isEnabled={true}
  initialClientId="your-client-id"
  initialClientSecret="your-client-secret"
  initialMsTenantId="your-tenant-id"
  initialAutoProvisionUsers={true}
  initialAllowedDomains={["openframe.com"]}
  onSubmit={async (data) => {
    await updateSsoConfig(data);
  }}
  onDisable={async () => {
    await disableSsoProvider("microsoft");
  }}
/>
```

> **Note:** When `autoProvisionUsers` is enabled, at least one allowed domain must be provided before the form can be submitted. The redirect URL is auto-generated from [`runtimeEnv.sharedHostUrl()`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/lib/runtime-config.ts) using the pattern `/sas/login/oauth2/code/{providerKey}`.
