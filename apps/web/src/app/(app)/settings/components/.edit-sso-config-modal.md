## edit-sso-config-modal.tsx

A React client component (`SsoConfigModal`) that renders a modal dialog for creating or editing SSO (Single Sign-On) provider configurations, supporting OAuth client credentials, Microsoft single-tenant setup, and email-domain-based auto-provisioning.

## Key Components

- **`SsoConfigModal`** — Main exported component rendering the SSO configuration modal.
- **`SsoConfigModalProps`** — Props interface controlling modal mode (`create` | `edit`), initial values, provider options, and the `onSubmit` callback.
- **Redirect URL section** — Displays and copies the OAuth callback URL (built from `runtimeEnv.sharedHostUrl()` and the provider key) via `useCopyToClipboard`.
- **Provider picker** — `Select` dropdown enabled only in `create` mode, listing `providerOptions` (available providers without existing config).
- **Credential fields** — `Input` fields for Client ID and Client Secret, with a show/hide toggle for the secret.
- **Microsoft-specific tenant config** — Conditional `CheckboxWithDescription` and tenant ID input shown when `effectiveProviderKey` is `microsoft`.
- **Auto-provisioning & allowed domains** — Controls (not fully shown) for `autoProvisionUsers` and `allowedDomains`, validated via `validateEmailDomain`.
- **Render-time state sync** — Uses render-phase state comparisons (`wasOpen`, `lastProviderOptions`) instead of `useEffect` to seed form state on open and preselect providers, avoiding flicker or stale-value races.
- **`canSubmit`** — Memoized validation gating the submit button based on provider selection, required fields, Microsoft tenant requirements, and domain requirements.
- **`handleSubmit`** — Async handler invoking `onSubmit`, showing success/error toasts, and closing the modal on success.

## Usage Example

```typescript
import { SsoConfigModal } from './edit-sso-config-modal';

function SsoSettingsPage() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <SsoConfigModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      mode="edit"
      providerKey="google"
      providerDisplayName="Google Workspace"
      initialClientId="existing-client-id"
      initialClientSecret="existing-secret"
      initialAutoProvisionUsers={true}
      initialAllowedDomains={['example.com']}
      onSubmit={async (data) => {
        await updateSsoConfig(data);
      }}
    />
  );
}
```

To create a new configuration, pass `mode="create"` along with `providerOptions` (providers not yet configured):

```typescript
<SsoConfigModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  mode="create"
  providerOptions={[{ provider: 'microsoft', displayName: 'Microsoft Azure AD' }]}
  providerKey=""
  providerDisplayName=""
  onSubmit={handleCreate}
/>
```
