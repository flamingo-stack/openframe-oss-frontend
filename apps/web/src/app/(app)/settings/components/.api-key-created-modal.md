# api-key-created-modal.tsx

A React client component that displays a modal dialog showing a newly created API key, prompting the user to securely copy and save it since it will not be shown again.

## Key Components

- **`ApiKeyCreatedModal`** — Main component that renders a `SimpleModal` with the generated API key, a copy-to-clipboard button, and a warning alert.
- **`ApiKeyCreatedModalProps`** — Props interface:
  - `isOpen: boolean` — controls modal visibility.
  - `fullKey: string | null` — the full API key to display.
  - `onClose: () => void` — callback invoked when the modal is dismissed.

### Internal Behavior

The component keeps the API key (`localKey`) in local state so it remains visible during the modal's closing animation, even after the parent component clears `fullKey`. State reconciliation happens directly during render (comparing against `lastInputs`) rather than in a `useEffect`, avoiding a one-frame flash of empty content when `isOpen` or `fullKey` changes.

It uses the `useCopyToClipboard` hook to handle clipboard copy actions with success/error toast descriptions, and swaps the copy icon to a checkmark (`CheckIcon`) briefly after a successful copy.

## Usage Example

```typescript
import { useState } from 'react';
import { ApiKeyCreatedModal } from '@/app/components/api-keys/api-key-created-modal';

function ApiKeysPage() {
  const [createdKey, setCreatedKey] = useState<string | null>(null);
  const [isModalOpen, setIsModalOpen] = useState(false);

  async function handleCreateApiKey() {
    const response = await createApiKey();
    setCreatedKey(response.fullKey);
    setIsModalOpen(true);
  }

  return (
    <>
      <button onClick={handleCreateApiKey}>Create API Key</button>
      <ApiKeyCreatedModal
        isOpen={isModalOpen}
        fullKey={createdKey}
        onClose={() => setIsModalOpen(false)}
      />
    </>
  );
}
```
