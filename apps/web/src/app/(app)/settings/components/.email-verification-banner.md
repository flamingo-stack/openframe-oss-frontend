A React client component that displays a dismissible warning banner prompting users to verify their email address, with a callback to resend the verification email.

## Key Components

- **`EmailVerificationBanner`** — Named export; renders a warning `Alert` containing an icon, instructional text, and a resend button.
- **`EmailVerificationBannerProps`** — Interface defining the single `onResend` callback prop.

## Usage Example

```typescript
import { EmailVerificationBanner } from './email-verification-banner';

function Dashboard() {
  const handleResend = async () => {
    await sendVerificationEmail(currentUser.email);
  };

  return (
    <>
      {!currentUser.emailVerified && (
        <EmailVerificationBanner onResend={handleResend} />
      )}
      {/* rest of dashboard */}
    </>
  );
}
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `onResend` | `() => void` | Callback fired when the user clicks "Resend Verification Mail" |

## Notes

- Marked with `'use client'` — requires a Next.js App Router client boundary.
- Layout is responsive: stacks vertically on mobile, shifts to a horizontal row (`sm:flex-row`) on wider screens.
- Relies on design tokens (`--spacing-system-m`, `--spacing-system-s`) from the shared component library for consistent spacing.
