A client-side React component that renders a warning banner prompting users to verify their email address, with a call-to-action button to resend the verification email.

## Key Components

- **`EmailVerificationBanner`** — Default-style functional component that displays an `Alert` (warning variant) containing a warning icon, a message, and a "Resend Verification Mail" button.
- **`EmailVerificationBannerProps`** — Props interface requiring an `onResend` callback, invoked when the user clicks the resend button.

The component uses design-system primitives (`Alert`, `AlertTriangleIcon`) from `@flamingo-stack/openframe-frontend-core` and responsive utility classes (e.g., `content-sm:flex-row`) to adapt layout from stacked to inline at wider content breakpoints.

## Usage Example

```typescript
import { EmailVerificationBanner } from './email-verification-banner';

function AccountSettingsPage() {
  const handleResendVerification = async () => {
    await fetch('/api/auth/resend-verification', { method: 'POST' });
  };

  return (
    <div>
      <EmailVerificationBanner onResend={handleResendVerification} />
      {/* rest of page content */}
    </div>
  );
}
```

This component is typically rendered conditionally at the top of a page or layout when the current user's email address has not yet been verified, giving them a persistent, actionable reminder without blocking access to the rest of the UI.
