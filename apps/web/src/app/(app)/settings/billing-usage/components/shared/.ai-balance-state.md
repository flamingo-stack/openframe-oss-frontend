# ai-balance-state.ts

Computes the unified AI usage/balance state (free trial grant + prepaid token balance) from a GraphQL subscription fragment, ensuring the Free AI Tokens card, Paid AI Tokens card, and the alert sentence beneath them always agree on severity.

## Key Components

- **`aiBalanceStateFragment`** — Inline GraphQL fragment on `SubscriptionDetail` pulling `status` and `usage` (free tokens, free tokens used, purchased tokens remaining, and their USD value).
- **`AiAlert`** — Union type (`'trial-exhausted' | 'low' | 'empty' | null`) representing the single alert sentence the page may need to show.
- **`AiBalanceState`** — Interface describing the normalized state: trial flag, free/paid token amounts, USD value, tone for each card (`freeTone`, `paidTone`), and the overall `alert`.
- **`aiBalanceState(ref)`** — Main function that reads the inline fragment data and derives:
  - Whether the subscription is in `TRIAL` status.
  - Numeric free/paid token figures (coercing GraphQL `Long` string-or-number values).
  - A shared tone calculation via `aiBalanceTone` (from `lib/ai-balance-tone.ts`), skipped for trials since they have no spendable balance.
  - Trial exhaustion via `aiFreeTokensExhausted`.
  - A single `alert` value prioritizing `trial-exhausted` over balance-derived `empty`/`low` states.

## Usage Example

```typescript
import { aiBalanceState } from './ai-balance-state';
import { useFragment } from 'react-relay';

function AiUsageSection({ subscriptionRef }: { subscriptionRef: any }) {
  const state = aiBalanceState(subscriptionRef);

  return (
    <>
      <UsageStatCard
        label="Free AI Tokens"
        used={state.freeUsed}
        total={state.free}
        tone={state.freeTone}
      />
      <UsageStatCard
        label="Paid AI Tokens"
        value={`$${state.paidUsd}`}
        tone={state.paidTone}
      />
      {state.alert === 'trial-exhausted' && <p>Your trial's free tokens are used up.</p>}
      {state.alert === 'empty' && <p>You're out of AI tokens.</p>}
      {state.alert === 'low' && <p>Your AI token balance is running low.</p>}
    </>
  );
}
```

Consume this function wherever subscription usage data is available as an `aiBalanceState_subscription$key` fragment reference, keeping tone/alert logic centralized and consistent across all three UI surfaces.
