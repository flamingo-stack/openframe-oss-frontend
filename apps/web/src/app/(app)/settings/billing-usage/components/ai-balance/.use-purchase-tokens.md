# use-purchase-tokens.ts

A React hook that initiates an AI token purchase by invoking a GraphQL mutation and redirecting the customer to a Stripe-hosted invoice for payment. Tokens are credited asynchronously once the invoice is paid—this hook only handles invoice creation and tab navigation.

## Key Components

- **`usePurchaseTokensMutation`** — GraphQL mutation definition that accepts `amountUsd` and returns a `paymentUrl`.
- **`PurchaseTokensOptions`** — Options interface with an optional `onSuccess` callback, invoked once the invoice exists and its tab is open.
- **`usePurchaseTokens()`** — The exported hook. Returns:
  - `mutate(amountUsd, options?)` — Triggers the purchase flow for a given dollar amount.
  - `isPending` — Boolean reflecting mutation in-flight status.

## Usage Example

```typescript
import { usePurchaseTokens } from './use-purchase-tokens';

function TokenPurchaseButton() {
  const { mutate, isPending } = usePurchaseTokens();

  const handlePurchase = () => {
    mutate(25, {
      onSuccess: () => {
        // e.g., close a modal once the invoice tab has opened
        closeModal();
      },
    });
  };

  return (
    <button onClick={handlePurchase} disabled={isPending}>
      {isPending ? 'Processing...' : 'Buy $25 in Tokens'}
    </button>
  );
}
```

## Implementation Notes

- **Popup-blocker handling:** The invoice tab is opened via `openDeferredTab` *before* the mutation resolves, preserving the user gesture required to bypass popup blockers. The tab is then either navigated to the invoice URL or cancelled on failure.
- **Rejection scenarios:** The backend may refuse the purchase if the amount is below the configured minimum, or if the subscription is past due, suspended, cancelled, or has an expired trial—in all cases the tab is cancelled and an error toast is shown.
- **No local state mutation:** The token balance is not updated client-side; it updates only after payment, read on the next fetch.
- **Error handling:** Uses `getRelayErrorMessage` to surface user-friendly error messages via toast notifications.
