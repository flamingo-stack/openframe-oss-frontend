Displays the cost summary shown beside the checkout submit button, rendering different "total due today" messaging depending on whether devices are billed annually upfront or pay-as-you-go (metered and invoiced later).

## Key Components

- **`PlanTotalSummaryProps`** — Props interface defining `mode` (billing mode or `null` while loading), `total` (priced annual selection), `topUpUsd` (AI balance top-up charged today), `showAiNote` (whether to explain AI billing), `firstBillingDate` (first PAYG invoice date), `loading`, and `className`.
- **`PlanTotalSummary`** — Component that renders:
  - A loading state (two skeleton lines) while the picker mode is unresolved or catalog data is loading.
  - For `ANNUAL` mode: an optional AI billing note plus a "Total due today" line combining the annual total and top-up.
  - For pay-as-you-go mode: a "Total due today" line showing only the top-up (if any), plus a note stating when devices will actually be billed.

## Usage Example

```typescript
import { PlanTotalSummary } from './plan-total-summary';

function CheckoutFooter() {
  return (
    <PlanTotalSummary
      mode="ANNUAL"
      total={{ amount: 1200 }}
      topUpUsd={50}
      showAiNote={true}
      firstBillingDate={new Date('2024-07-01')}
      loading={false}
      className="mt-4"
    />
  );
}

// Pay-as-you-go mode example
function PaygFooter() {
  return (
    <PlanTotalSummary
      mode="PAYG"
      total={null}
      topUpUsd={25}
      showAiNote={true}
      firstBillingDate={new Date('2024-07-01')}
    />
  );
}
```

Typically rendered inside the checkout flow (see `plan-selection.tsx`) next to the submit button, using `DevicePlanMode` and `SelectionTotal` types exported from that module.
