# usage-stat-card.tsx

A composable card component for displaying a labeled usage metric (e.g., device count, AI balance) with tone-based coloring and built-in loading-skeleton support, used on billing/usage pages.

## Key Components

- **`UsageStatCard`** — Main card component rendering a title, headline value, and caption line. Automatically shows skeleton loading bars (via `useLoadingScope` or the `loading` prop) in place of the value/caption while data is unresolved. Supports a `tone` (`'default' | 'warning' | 'error'`) that recolors the entire card's border, background, and text to signal limit warnings or errors.
- **`UsageStatTone`** — Type union describing the card's state: `default`, `warning` (approaching a limit), or `error` (limit reached, something stopped).
- **`StatSuffix`** — Inline span for qualifying text trailing a value (e.g., `/10M`), muted by default but inherits the card's tone color when recolored.
- **`StatEmphasis`** — Inline span for highlighting the key fact within an otherwise muted caption (e.g., a date or dollar amount).
- **`StatLink`** — Anchor element for caption links that open in a new tab, styled with an underline and inheriting the caption's tone color.

## Usage Example

```typescript
import {
  UsageStatCard,
  StatSuffix,
  StatEmphasis,
  StatLink,
} from '@/app/components/shared/usage-stat-card';

function DeviceUsage({ used, limit, isOverLimit }: { used: number; limit: number; isOverLimit: boolean }) {
  return (
    <UsageStatCard
      title="Managed Devices"
      value={
        <>
          {used}
          <StatSuffix>/{limit}</StatSuffix>
        </>
      }
      caption={
        <>
          Trial ends <StatEmphasis>12/15/26</StatEmphasis> —{' '}
          <StatLink href="/billing/plans">upgrade plan</StatLink>
        </>
      }
      tone={isOverLimit ? 'error' : 'default'}
    />
  );
}
```

Pass `loading` explicitly to force the skeleton state, or rely on an ambient `useLoadingScope` context to drive it automatically. The `trailing` prop can pin extra UI (e.g., a help icon) to the card's top-right corner.
