## auto-top-up-status.ts

Normalizes GraphQL data for the auto top-up arrangement (automatic token purchasing when the AI token balance runs low) into a single shared shape consumed across the billing UI — the Paid AI Tokens card, Auto Top-up section, Manage AI Balance modal, and the corresponding mutation.

## Key Components

- **`autoTopUpStatusFragment`** — `@inline` GraphQL fragment on `AutoTopUpSettings` defining the fields every reader and the mutation response share.
- **`FALLBACK_MIN_TOP_UP_USD`** — Default floor (`$10`) for a one-time top-up when the backend doesn't supply `minimumAmountUsd`.
- **`AutoTopUpStatus`** — Normalized interface exposing `enabled`, `amountUsd`, `thresholdUsd`, `spendLimitUsd`, `spentUsd`, `paused`, `resumesAt`, `minimumAmountUsd`, `minimumThresholdUsd`, `switchedOff`, and `paymentMethodSetupUrl`.
- **`SwitchedOffReason`** / **`isSwitchedOffReason`** — Narrowed union of `AutoTopUpDisabledReason` values (`PAYMENT_FAILED`, `AUTHENTICATION_ABANDONED`, `NO_PAYMENT_METHOD`) that represent system-initiated (not user-initiated) disabling.
- **`SWITCHED_OFF_COPY`** — User-facing notice and checkbox copy for each `SwitchedOffReason`.
- **`toAutoTopUpStatus(ref)`** — Reads the inline fragment from a Relay fragment reference and maps it into an `AutoTopUpStatus`, applying defaults (fallback minimum amount, computed minimum threshold, pause detection via `pausedReason`).
- **`spendLimitUsage(spentUsd, limitUsd)`** — Computes a 0–100 percent and `reached` flag for the spend-limit progress bar; returns `null` when there's no limit.

## Usage Example

```typescript
import { toAutoTopUpStatus, spendLimitUsage, SWITCHED_OFF_COPY } from '@/lib/billing/auto-top-up-status';

function AutoTopUpSection({ settingsRef }: { settingsRef: autoTopUpStatus_settings$key }) {
  const status = toAutoTopUpStatus(settingsRef);

  const usage = spendLimitUsage(status.spentUsd, status.spendLimitUsd);

  if (status.switchedOff) {
    return <Notice text={SWITCHED_OFF_COPY[status.switchedOff].notice} />;
  }

  return (
    <div>
      <p>Enabled: {status.enabled ? 'Yes' : 'No'}</p>
      {status.paused && <p>Paused until {status.resumesAt}</p>}
      {usage && <ProgressBar percent={usage.percent} reached={usage.reached} />}
    </div>
  );
}
```
