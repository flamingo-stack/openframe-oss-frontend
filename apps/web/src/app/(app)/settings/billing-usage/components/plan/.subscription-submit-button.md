# subscription-submit-button.tsx

A single, context-aware call-to-action button that drives both the subscription checkout flow (new/expired/canceled subscriptions via Stripe) and the in-place subscription update flow (plan changes for active subscriptions), presenting the same "Proceed to Payment" label across both paths per product decision.

## Key Components

- **`SubscriptionSubmitButton`** — The main exported component. Branches internally on `needsCheckout` to decide which mutation to run:
  - **Checkout path** (`needsCheckout = true`): calls `useCreateCheckoutSession`, redirecting to Stripe. Validates custom quantities and AI top-up amount before submitting. Disabled when there's nothing purchasable yet or the `billing-activation` feature flag is off.
  - **Update path** (`needsCheckout = false`): calls `useUpdateSubscription`, applying plan changes in place without redirect. Disabled when there's no diff (`packageUpdates` is empty).
- **`SUBMIT_LABEL`** — Default CTA text (`"Proceed to Payment"`), overridable via the `label` prop for contexts where no charge occurs on click (e.g. billing page plan changes).
- **`SubscriptionSubmitButtonProps`** — Props controlling the active flow, validation, and UI state (`needsCheckout`, `packageUpdates`, `checkoutProducts`, `hasInvalidCustom`, `tokenAmountUsd`, `autoTopUpEnabled`, `validateTopUp`, `onUpdated`, `className`, `label`).

Validation errors (invalid custom quantity, invalid top-up amount) never disable the button — they surface via toast notifications on click so the user always gets feedback, even if the offending field is scrolled out of view.

## Usage Example

```typescript
import { SubscriptionSubmitButton } from './subscription-submit-button';

function BillingForm() {
  const needsCheckout = subscriptionStatus === 'TRIAL' || subscriptionStatus === 'CANCELED';

  return (
    <SubscriptionSubmitButton
      needsCheckout={needsCheckout}
      packageUpdates={packageUpdates}
      checkoutProducts={checkoutProducts}
      hasInvalidCustom={hasInvalidCustomQuantity}
      tokenAmountUsd={aiTopUpAmount}
      autoTopUpEnabled={autoTopUpEnabled}
      validateTopUp={() => validateAiTopUp(aiTopUpAmount)}
      onUpdated={() => router.refresh()}
      className="w-full"
    />
  );
}
```

For a non-charging plan change (e.g. billing page downgrade scheduling):

```typescript
<SubscriptionSubmitButton
  needsCheckout={false}
  packageUpdates={diff}
  checkoutProducts={[]}
  hasInvalidCustom={false}
  label="Update Plan"
  onUpdated={refetchSubscription}
/>
```
