# use-billing-page-actions.tsx

A React hook that derives the billing page header's action buttons and overflow menu from a subscription's current state, encapsulating the business logic that maps subscription status to available user actions.

## Key Components

- **`useBillingPageActionsFragment`** — GraphQL fragment pulling subscription `status`, `pendingInvoices`, and plan schedule data needed to decide which actions to render.
- **`BillingPageActions`** — Return type containing `actions` (header `PageActionButton[]`) and `menuActions` (overflow `ActionsMenuGroup[]`).
- **`BillingPageActionsArgs`** — Hook input: the subscription fragment key, a `readOnly` flag (desktop build), and callbacks for plan change, activation, AI balance management, cancellation, renewal, and downgrade-undo settlement.
- **`useBillingPageActions(args)`** — Main hook. Resolves subscription status (`TRIAL`, `PENDING_CANCELLATION`, `PAST_DUE`/`SUSPENDED`/`CANCELED`, `ACTIVE`, etc.) and determines:
  - Whether "Change Plan" belongs in the menu (`planOffered`).
  - Whether a downgrade is scheduled (`downgradeScheduled`), offering "Undo Downgrade".
  - The newest unpaid invoice URL for "Pay Overage".
  - The single accent action (`statusAction`): Renew Subscription, Undo Downgrade, Pay Overage, or Activate Subscription — whichever applies.
  - The secondary action: "Manage AI Balance", shown only if `onManageAiBalance` is provided.
  - Menu items gated by feature flags (`cancel-subscription`, `customer-portal`).

## Usage Example

```typescript
import { useBillingPageActions } from './use-billing-page-actions';

function BillingPageHeader({ subscriptionRef, isReadOnly }) {
  const { actions, menuActions } = useBillingPageActions({
    subscription: subscriptionRef,
    readOnly: isReadOnly,
    onChangePlan: () => openChangePlanModal(),
    onActivate: () => openActivateSubscriptionModal(),
    onManageAiBalance: hasAiBalance ? () => openAiBalanceModal() : null,
    onCancel: () => openCancelModal(),
    onRenewed: () => refetchSubscription(),
    onUndoDowngradeSettled: () => refetchSubscription(),
  });

  return <PageHeader actions={actions} menuActions={menuActions} />;
}
```

In read-only builds (e.g., desktop), the hook short-circuits to `READ_ONLY_BILLING_ACTIONS` with no menu, directing users to the web app instead.
