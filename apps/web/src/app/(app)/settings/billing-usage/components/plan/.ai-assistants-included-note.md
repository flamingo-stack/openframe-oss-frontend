# ai-assistants-included-note.tsx

A presentational React component that displays an informational banner clarifying that Fae and Mingo (Flamingo's AI assistants) are bundled into every paid plan, rather than being separate purchasable add-ons, typically shown alongside plan pricing.

## Key Components

- **`AiAssistantsIncludedNote`** — Default-exported function component with no props. Renders a styled card containing a `MagicWandIcon` icon and two lines of text explaining that AI assistants (Fae, Mingo) ship with the product and include a monthly free-token allowance, with additional usage drawn from a token balance.

## Usage Example

```typescript
import { AiAssistantsIncludedNote } from './ai-assistants-included-note';

function PlanPickerPage() {
  return (
    <div className="flex flex-col gap-4">
      <h2>Choose a Plan</h2>
      {/* ...plan pricing cards... */}
      <AiAssistantsIncludedNote />
    </div>
  );
}
```

## Notes

- This is a client component (`'use client'`), intended for use in Next.js app-router contexts where client-side rendering is required.
- Styling relies on design-system tokens (`--spacing-system-sf`, `ods-*` classes) from the shared Flamingo design system — ensure the consuming app has these CSS variables and utility classes available.
- The component is purely presentational: it accepts no props and manages no internal state, making it safe to drop into any plan-selection or billing-related view.
- Intended specifically for contexts involving the token-bank billing model, where paid plans grant a monthly free-token allowance for AI assistant usage.
