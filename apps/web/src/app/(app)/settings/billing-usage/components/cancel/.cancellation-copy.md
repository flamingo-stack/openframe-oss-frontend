## Description

Defines static, user-facing copy strings used in subscription cancellation dialogs, covering two distinct cancellation flows: cancelling a package subscription (deferred, end-of-term) versus a pay-as-you-go-only subscription (immediate termination).

## Key Components

- **`PACKAGE_CANCELLATION_TERMS`** — Confirmation dialog copy shown when a user initiates cancellation of a package subscription. Clarifies that pay-as-you-go usage stops immediately, while token purchases and auto top-up remain available until the paid term ends.
- **`PACKAGE_CANCELLED_OVERAGE`** — Post-cancellation copy confirming pay-as-you-go usage has been disabled.
- **`PACKAGE_CANCELLED_PURCHASES`** — Post-cancellation copy confirming token purchases and auto top-up remain available until the term ends.
- **`PAYG_CANCELLATION_TERMS`** — Confirmation dialog copy for pay-as-you-go-only cancellation, noting immediate termination, auto top-up disablement, and pending usage invoicing.
- **`PAYG_CANCELLED_TERMS`** — Post-cancellation copy confirming the subscription has ended and outstanding usage will be invoiced shortly.

These constants map to two cancellation semantics distinguished by `hasSubscriptionPackage`: package subscriptions defer to `PENDING_CANCELLATION` (end of paid term), while pay-as-you-go subscriptions terminate immediately and rely on `DeferredStripeCancellationService` to settle the final usage invoice once Stripe's meter catches up.

## Usage Example

```typescript
import {
  PACKAGE_CANCELLATION_TERMS,
  PACKAGE_CANCELLED_OVERAGE,
  PACKAGE_CANCELLED_PURCHASES,
  PAYG_CANCELLATION_TERMS,
  PAYG_CANCELLED_TERMS,
} from './cancellation-copy';

function renderCancellationDialog(hasSubscriptionPackage: boolean) {
  return hasSubscriptionPackage ? PACKAGE_CANCELLATION_TERMS : PAYG_CANCELLATION_TERMS;
}

function renderCancelledNotice(hasSubscriptionPackage: boolean) {
  if (hasSubscriptionPackage) {
    return `${PACKAGE_CANCELLED_OVERAGE} ${PACKAGE_CANCELLED_PURCHASES}`;
  }
  return PAYG_CANCELLED_TERMS;
}
```
