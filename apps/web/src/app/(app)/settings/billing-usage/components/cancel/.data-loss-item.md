Renders a single line item describing data a user is about to lose (e.g., in a destructive-action confirmation dialog), with built-in loading-skeleton support and an approximate-count helper for emphasizing large numbers.

## Key Components

- **`formatApproximateCount(value: number): string`** — Internal helper that formats large counts approximately (e.g., `1,200+` rounded down to the nearest hundred once ≥ 1000); smaller values are formatted exactly via `formatCount`.
- **`DataLossItem({ children, skeletonWidth })`** — A list item (`role="listitem"`) showing a warning dot icon followed by descriptive text. When rendered inside a loading scope (via `useLoadingScope`), it displays a `LoadingLine` skeleton instead of the actual content.
- **`DataLossStat({ value })`** — A styled inline stat for highlighting a count or label (e.g., "1,200+ records") in warning color. Numeric values are passed through `formatApproximateCount`; strings are rendered as-is.

## Usage Example

```typescript
import { DataLossItem, DataLossStat } from '@/app/components/shared/data-loss-item';

function DeleteWorkspaceWarning({ deviceCount, userCount, loading }: {
  deviceCount: number;
  userCount: number;
  loading: boolean;
}) {
  return (
    <div role="list">
      <DataLossItem skeletonWidth="w-1/2">
        <DataLossStat value={deviceCount} /> managed devices
      </DataLossItem>
      <DataLossItem>
        <DataLossStat value={userCount} /> active users
      </DataLossItem>
      <DataLossItem>
        <DataLossStat value="All" /> audit logs and history
      </DataLossItem>
    </div>
  );
}
```

`DataLossItem` relies on an ancestor providing `useLoadingScope`'s context; when active, `children` is ignored in favor of a skeleton bar sized by `skeletonWidth`.
