# billing-page-frame.tsx

Provides the static page frame (title, back navigation, and header actions) for the Billing & Usage screen, ensuring a consistent layout shell shared across loading and loaded states.

## Key Components

- **`READ_ONLY_BILLING_ACTIONS`** — A predefined `PageActionButton[]` used in the read-only (desktop) build. Renders a single "Manage Billing" action that opens billing management in the browser via `openBillingInBrowser`, since billing changes aren't supported in-app.
- **`BillingPageFrameProps`** — Props interface for the frame component:
  - `actions?: PageActionButton[]` — Header action buttons.
  - `menuActions?: ActionsMenuGroup[]` — Grouped actions rendered in a menu.
  - `loadingActions?: boolean` — When `true`, renders placeholder actions while subscription data is still loading.
  - `children: ReactNode` — Page content rendered inside the frame.
- **`BillingPageFrame`** — The main component. Wraps `PageLayout` with a fixed title ("Billing & Usage"), a back button routed to `routes.settings.root()` via `useSafeBack`, and passes through actions/menu actions/loading state.

## Usage Example

```typescript
import { BillingPageFrame, READ_ONLY_BILLING_ACTIONS } from './billing-page-frame';

function BillingUsageScreen() {
  const isLoading = useSubscriptionLoading();

  return (
    <BillingPageFrame
      actions={READ_ONLY_BILLING_ACTIONS}
      loadingActions={isLoading}
    >
      <BillingUsageView />
    </BillingPageFrame>
  );
}
```

This component is designed to be reused by both the fully loaded billing view and its dynamic-import loading fallback, preventing duplicate frame rendering during code-splitting transitions.
