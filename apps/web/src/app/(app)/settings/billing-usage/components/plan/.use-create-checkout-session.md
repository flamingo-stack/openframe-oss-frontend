# use-create-checkout-session.ts

A React hook that initiates a Stripe Checkout session via a GraphQL mutation, handling the popup-blocker-safe tab opening flow and surfacing user-friendly error toasts for known backend failure cases.

## Key Components

- **`useCreateCheckoutSession()`** — Main hook exposing `mutate(input)` and `isPending`. Calls the `createCheckoutSession` GraphQL mutation and manages the lifecycle of a deferred browser tab for Stripe Checkout.
- **`createCheckoutSessionMutation`** — The Relay GraphQL mutation definition requesting `checkoutUrl` for a given `CheckoutInput`.
- **`CheckoutInput`, `ProductCheckoutInput`** — Re-exported GraphQL-generated types describing the checkout request shape (devices, AI product, `tokenAmountUsd` top-up).
- **Error code constants** — `PREVIOUS_SUBSCRIPTION_FINALIZING` and `OVERDUE_INVOICES_EXIST` map specific backend error codes to tailored toast messages; `NOT_STARTED` is the generic fallback message for transport-level failures.

## Usage Example

```typescript
import { useCreateCheckoutSession } from './use-create-checkout-session';

function UpgradeButton() {
  const { mutate, isPending } = useCreateCheckoutSession();

  const handleUpgrade = () => {
    mutate({
      deviceCount: 10,
      aiProduct: { tokenAmountUsd: 20 },
    });
  };

  return (
    <button onClick={handleUpgrade} disabled={isPending}>
      {isPending ? 'Starting checkout...' : 'Upgrade Plan'}
    </button>
  );
}
```

**Key behavior:** The hook opens a blank tab synchronously on click (via `openDeferredTab`) to preserve the user gesture required by popup blockers. Once the mutation resolves, the tab either navigates to the returned `checkoutUrl` or is cancelled if the mutation fails or returns no URL. Specific GraphQL error codes (`OVERDUE_INVOICES_EXIST`, `PREVIOUS_SUBSCRIPTION_FINALIZING`) trigger targeted guidance toasts; all other errors fall back to the mutation's error message or the generic `NOT_STARTED` text.
