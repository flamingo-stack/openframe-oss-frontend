A React hook that initiates a Stripe (or similar) checkout session via a Relay GraphQL mutation, handles redirect on success, and surfaces toast notifications on failure.

## Key Components

- **`createCheckoutSessionMutation`** — Relay GraphQL mutation that calls `createCheckoutSession(input: CheckoutInput!)` and returns a `checkoutUrl`
- **`useCreateCheckoutSession()`** — Primary exported hook returning:
  - `mutate(input: CheckoutInput)` — triggers the mutation, redirects to `checkoutUrl` on success
  - `isPending: boolean` — reflects Relay's in-flight state for disabling UI controls
- **Re-exported types** — `CheckoutInput` and `ProductCheckoutInput` from the generated GraphQL types for consumer use

## Usage Example

```typescript
import { useCreateCheckoutSession } from './use-create-checkout-session';
import type { CheckoutInput } from './use-create-checkout-session';

function CheckoutButton({ plan }: { plan: string }) {
  const { mutate, isPending } = useCreateCheckoutSession();

  const handleCheckout = () => {
    const input: CheckoutInput = {
      products: [{ planId: plan, quantity: 1 }],
    };
    mutate(input);
  };

  return (
    <button onClick={handleCheckout} disabled={isPending}>
      {isPending ? 'Redirecting...' : 'Subscribe'}
    </button>
  );
}
```

## Behavior

| Outcome | Result |
|---|---|
| Success with URL | Toast shown → `window.location.href` redirect |
| Success without URL | Destructive toast, no redirect |
| Network / GraphQL error | Destructive toast with error message |
