# ai-token-balance-card.tsx

A presentational card used on the device paywall that displays the user's AI token balance context: the free-token grant tied to the selected device plan, the first top-up amount, and an optional auto-top-up toggle. It renders state only — it does not submit or persist any data itself.

## Key Components

- **`AiTokenBalanceCard`** — The main exported component. Renders:
  - A header with title, explanation text, and a `ModelTokenRatesPopover` for per-model rate details.
  - A "free tokens" callout box that shows a loading skeleton (`LoadingLine`) until `deviceMode` is known, then displays the computed free-token grant via `freeTokensForPlan`.
  - `AiTopUpFields` for configuring the initial top-up amount.
  - An optional `AutoTopUpCheckbox`, shown only when `canAutoTopUp` is true.
- **`AiTokenBalanceCardProps`** — Props interface controlling loading state, device plan mode, top-up state/handlers, and auto-top-up visibility/state.
- **`AI_GRANT_SENTENCE_LINES`** — Constant controlling how many skeleton lines the loading state reserves for the grant sentence, preventing layout shift.

## Usage Example

```typescript
import { AiTokenBalanceCard } from './ai-token-balance-card';

function PaywallPage() {
  const [deviceMode, setDeviceMode] = useState<DevicePlanMode | null>(null);
  const topUp = useAiTopUp();
  const [autoTopUp, setAutoTopUp] = useState(false);

  return (
    <AiTokenBalanceCard
      loading={false}
      deviceMode={deviceMode}
      topUp={topUp}
      autoTopUp={autoTopUp}
      canAutoTopUp={topUp.amount > 0}
      onAutoTopUpChange={setAutoTopUp}
    />
  );
}
```

**Notes:**
- `deviceMode` must come from the sibling plan-selection picker; the free-token grant recalculates when it changes (annual plans grant more than pay-as-you-go).
- This card writes nothing on its own — values flow into the parent form's `CheckoutInput.tokenAmountUsd` and `CheckoutInput.autoTopUpEnabled`, submitted together via the page's single "Proceed to Payment" action.
- `useLoadingScope()` is combined with the `loading` prop so the card reacts to ambient loading contexts as well as explicit state.
