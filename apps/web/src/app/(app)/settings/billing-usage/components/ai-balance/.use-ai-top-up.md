# use-ai-top-up.ts

A React hook that manages the shared state and logic for AI token top-up selection, used by both the billing page's "Manage AI Balance" modal and the paywall's "AI Token Balance" card. It centralizes the dollar-amount selection, validation, and dollar-to-token conversion so each surface only needs to handle the resulting amount differently (invoice, auto-refill, or checkout line item).

## Key Components

- **`TOP_UP_PRESETS_USD`** — Default preset tile amounts in whole dollars (`[20, 50, 100]`).
- **`CUSTOM_TOP_UP`** / **`NO_TOP_UP`** — Sentinel values representing a custom amount entry or an explicit "don't top up" choice.
- **`TopUpSelection`** — Union type of a preset number, `CUSTOM_TOP_UP`, `NO_TOP_UP`, or `null` (nothing chosen yet).
- **`AiTopUp`** — The hook's return shape: current selection state, computed `amountUsd`/`tokens`, validation `error`, and action methods (`selectPreset`, `selectNone`, `selectCustom`, `setCustomUsd`, `validate`, `reset`).
- **`useAiTopUp(options)`** — The hook itself. Takes `tokenPrice`, `initial`, `minimumUsd`, `presets`, and `allowNone` options.

## Usage Example

```typescript
import { useAiTopUp, TOP_UP_PRESETS_USD } from './use-ai-top-up';

function ManageAiBalanceModal({ tokenPrice }: { tokenPrice: number | null }) {
  const topUp = useAiTopUp({
    tokenPrice,
    minimumUsd: 10,
    allowNone: true,
  });

  const handleSubmit = () => {
    const error = topUp.validate();
    if (error) return; // error is now shown via topUp.error
    purchaseTokens({ tokenAmountUsd: topUp.amountUsd });
  };

  return (
    <div>
      {topUp.presets.map(usd => (
        <button key={usd} onClick={() => topUp.selectPreset(usd)}>
          ${usd} ({topUp.tokensForUsd(usd)} tokens)
        </button>
      ))}
      <button onClick={topUp.selectCustom}>Custom</button>
      {topUp.selection === 'custom' && (
        <input value={topUp.customUsd} onChange={e => topUp.setCustomUsd(e.target.value)} />
      )}
      {topUp.error && <p>{topUp.error}</p>}
      <button onClick={handleSubmit} disabled={!topUp.isComplete}>Confirm</button>
    </div>
  );
}
```

Validation errors only surface after `validate()` is called (typically on submit), keeping the form quiet while the user is still making a selection.
