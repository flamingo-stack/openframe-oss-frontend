# device-management-card.tsx

A checkout-flow card component that renders the "Device Management" section of the paywall, wrapping `DevicePlanPicker` with a heading and billing-specific context for pay-as-you-go devices.

## Key Components

- **`DeviceManagementCard`** — Main exported component. Renders a `Card` with a heading and the `DevicePlanPicker`, injecting a pay-as-you-go description that explains no charge occurs today and names the exact first billing date.
- **`deviceManagementCardProductFragment`** — GraphQL fragment on `Product` that spreads `devicePlanPickerProductFragment`, passed through to the picker without being read locally.
- **`deviceManagementCardSubscriptionProductFragment`** — GraphQL fragment on `SubscriptionProductDetail` that spreads `devicePlanPickerSubscriptionFragment`, similarly passed through.
- **`DeviceManagementCardProps`** — Props interface: nullable Relay fragment keys for `product`/`subscriptionProduct`, a `firstBillingDate: Date` for the PAYG billing message, and `onUpdatesChange` callback for plan updates.
- **`ADDITIONAL_DEVICES_HELPER_TEXT`** — Static footer note explaining overage billing for devices beyond the prepaid count.

## Usage Example

```typescript
import { DeviceManagementCard } from './device-management-card';

function PlanCheckout({ productKey, subscriptionProductKey, paygFirstBillingDate }) {
  const handleUpdatesChange = (updates: ProductUpdates) => {
    // persist device plan selection into checkout totals
  };

  return (
    <DeviceManagementCard
      product={productKey}
      subscriptionProduct={subscriptionProductKey}
      firstBillingDate={paygFirstBillingDate}
      onUpdatesChange={handleUpdatesChange}
    />
  );
}
```

**Notes:**
- Pass `null` for `product`/`subscriptionProduct` while Relay data is loading — the underlying `DevicePlanPicker` handles its own loading/skeleton state.
- This component is intentionally separate from the AI equivalent card since device billing uses a period-toggle-over-two-panels interaction model rather than a balance-picker model.
- The pay-as-you-go messaging (no charge today, exact next billing date) is specific to checkout context, distinguishing it from the Upgrade Plan modal, which modifies an already-running subscription.
