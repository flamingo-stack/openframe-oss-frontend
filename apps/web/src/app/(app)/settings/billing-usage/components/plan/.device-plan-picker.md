# device-plan-picker.tsx

Renders the device billing plan selection UI, letting users toggle between monthly pay-as-you-go and annual prepaid pricing. Shared between the paywall's `DeviceManagementCard` and the billing page's Upgrade Plan modal, with a built-in loading state driven entirely by a `null` product reference.

## Key Components

- **`devicePlanPickerProductFragment`** / **`devicePlanPickerSubscriptionFragment`** — GraphQL fragments that spread the underlying `useDevicePlanSelection` hook's fragments; the component itself reads no data directly.
- **`DevicePlanPickerProps`** — Props interface: `productRef`, `subscriptionProductRef` (both nullable for loading state), `onUpdatesChange` callback, optional `paygDescription` and `footerNote` for surface-specific copy.
- **`PriceValue`** — Internal helper rendering a formatted currency amount with a trailing `/period` label.
- **`DevicePlanPicker`** — Main exported component. Displays a `TabSelector` (Monthly/Annual) when both pricing options exist, a pay-as-you-go rate panel, or an annual panel with a `QuantityStepper` for device count and computed total. Delegates all pricing logic and state to `useDevicePlanSelection`.

## Usage Example

```typescript
import { DevicePlanPicker } from './device-plan-picker';

function UpgradePlanModal({ product, subscriptionProduct }) {
  const handleUpdatesChange = (updates: ProductUpdates) => {
    // persist pending plan changes (mode, quantity) for submission
    console.log(updates);
  };

  return (
    <DevicePlanPicker
      productRef={product}
      subscriptionProductRef={subscriptionProduct}
      onUpdatesChange={handleUpdatesChange}
      footerNote="Overage beyond your plan is billed at the standard monthly rate."
    />
  );
}

// Loading state: pass null refs to show skeleton placeholders
<DevicePlanPicker
  productRef={null}
  subscriptionProductRef={null}
  onUpdatesChange={() => {}}
/>
```

Consumers must wrap usage in a Relay environment providing the fragment data, and typically pair it with a loading scope provider (`useLoadingScope`) to coordinate skeleton states across the surrounding form.
