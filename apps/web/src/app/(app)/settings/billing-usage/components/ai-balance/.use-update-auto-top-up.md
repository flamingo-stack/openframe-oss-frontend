A React hook that commits a Relay mutation to update a billing account's auto top-up settings (enable/disable, threshold, and amount), handling cache updates and error toasts.

## Key Components

- **`updateAutoTopUpMutation`** — GraphQL mutation definition that sends an `AutoTopUpSettingsInput` and fetches the updated settings via the `autoTopUpStatus_settings` fragment.
- **`UpdateAutoTopUpOptions`** — Options interface accepting an `onCompleted` callback that receives the resulting `AutoTopUpStatus`.
- **`useUpdateAutoTopUp()`** — Hook returning:
  - `mutate(input, options)` — commits the mutation, manually relinks the mutation payload to the `autoTopUpSettings` root field (since `AutoTopUpSettings` has no `id`), and shows a destructive toast on failure.
  - `isPending` — boolean indicating whether the mutation is in flight.
- **`AutoTopUpSettingsInput`** — Re-exported type for the mutation's input shape.

## Usage Example

```typescript
import { useUpdateAutoTopUp } from './use-update-auto-top-up';

function AutoTopUpForm() {
  const { mutate, isPending } = useUpdateAutoTopUp();

  const handleSave = () => {
    mutate(
      { enabled: true, thresholdCents: 1000, amountCents: 5000 },
      {
        onCompleted: status => {
          if (status.requiresPaymentMethod) {
            // prompt user to add a card
          } else {
            // close modal, show confirmation
          }
        },
      }
    );
  };

  return (
    <button onClick={handleSave} disabled={isPending}>
      {isPending ? 'Saving…' : 'Save Auto Top-up'}
    </button>
  );
}
```

Errors are surfaced automatically via toast notifications; callers only need to handle the success path through `onCompleted`.
