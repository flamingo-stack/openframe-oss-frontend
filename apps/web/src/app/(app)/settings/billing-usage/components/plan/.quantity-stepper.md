# QuantityStepper

An uncontrolled numeric input with decrement/increment buttons, designed to avoid caret-jumping issues common to controlled numeric fields. The field's text is owned by the DOM, while React only pushes `value` into it when the change originates from outside typing (button clicks, external clamping, or fresh data).

## Key Components

- **`QuantityStepper`** — The main component rendering a bordered group with `−`/`+` buttons flanking a centered text input styled as a number field.
- **`QuantityStepperProps`** — Props interface:
  - `value`: committed quantity (only written into the field when changed externally)
  - `min`: floor enforced by buttons/arrow keys
  - `step`: increment granularity (default `1`)
  - `label`: accessible name for the input
  - `error`: validation message; also styles the group border red
  - `onChange`: fired with the in-progress (possibly out-of-range) quantity
  - `onCommit`: fired on blur or Enter, letting the owner clamp the final value

## Usage Example

```typescript
import { useState } from 'react';
import { QuantityStepper } from './quantity-stepper';

function ProductQuantity() {
  const [quantity, setQuantity] = useState(1);
  const [error, setError] = useState<string | undefined>();

  const commit = () => {
    if (quantity < 1) {
      setQuantity(1);
      setError('Quantity must be at least 1');
    } else {
      setError(undefined);
    }
  };

  return (
    <QuantityStepper
      value={quantity}
      min={1}
      step={1}
      label="Product quantity"
      error={error}
      onChange={setQuantity}
      onCommit={commit}
    />
  );
}
```

**Key behaviors:**
- Non-digit characters are rejected at `beforeinput`, preventing DOM rewrites and caret resets.
- An empty field is treated as an editing state, not a `0` quantity, so it won't be refilled mid-edit.
- Arrow Up/Down step the value by `step`; Enter triggers `onCommit`.
- Focusing the input selects all text for quick replacement.
