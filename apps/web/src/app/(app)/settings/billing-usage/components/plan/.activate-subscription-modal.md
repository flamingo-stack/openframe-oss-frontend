# activate-subscription-modal.tsx

A modal component that presents the subscription paywall (device plan selection, AI top-up, and checkout) to users whose trial is active or has ended, reusing the same checkout form and cards as the billing lock screen.

## Key Components

- **`ActivateSubscriptionModal`** — Top-level exported component. Renders nothing until `isOpen` is true, wraps the body in a `SimpleModal` and an `ErrorBoundary` so a catalog fetch failure stays contained to the modal instead of crashing the whole Billing & Usage page.
- **`ActivateSubscriptionContent`** — Wraps the reader in `LoadingSuspense` with a "Loading plans" label.
- **`ActivateSubscriptionReader`** — Detects whether it's rendering inside a loading-boundary scope (`useLoadingScope`) and either renders the body with no data or triggers the live query.
- **`ActivateSubscriptionLive`** — Executes `activateSubscriptionModalQuery` via `useLazyLoadQuery` with `store-and-network` fetch policy, run only once the modal opens.
- **`ActivateSubscriptionBody`** — Reads the `activateSubscriptionModal_query` fragment, derives form state via `usePlanCheckout`, and renders both `ModalV2Content` (paywall description, plan cards) and `ModalV2Footer` (total summary, checkout note, submit button) so they share the same form state.
- **`ActivateSubscriptionModalProps`** — `{ isOpen, status: SubscriptionStatus, onClose }`.

## Usage Example

```typescript
import { ActivateSubscriptionModal } from './activate-subscription-modal';
import { useState } from 'react';

function BillingPage({ subscriptionStatus }: { subscriptionStatus: SubscriptionStatus }) {
  const [isModalOpen, setModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Activate Subscription</button>
      <ActivateSubscriptionModal
        isOpen={isModalOpen}
        status={subscriptionStatus}
        onClose={() => setModalOpen(false)}
      />
    </>
  );
}
```

Note: the checkout flow opens Stripe in a new tab and does not report back to the modal; closing the modal and letting the page re-fetch is how the activated subscription becomes visible.
