## Overview

Pure helper functions that translate the plan picker's UI selection state (`ProductSelectionState`) into backend-ready mutation inputs — an `ADD`/`CANCEL` diff for `updateSubscription`, or a target-state payload for `createCheckoutSession`. Reads a catalog `Product` via an `@inline` Relay fragment and reconciles it with the subscription's currently active package.

## Key Components

- **`DevicePlanMode`** — `'PAYG' | 'ANNUAL'`, the two billing modes exposed in the UI.
- **`ProductSelectionState`** — picker's selection shape (PAYG toggle, billing period, selected package id, custom quantity).
- **`SelectionTotal`** — priced selection shape (`amount`, `period`, `prepaid`) for the checkout footer.
- **`ProductUpdates`** — aggregate result shape combining mode, diff, checkout input, validity, and total.
- **`CUSTOM_OPTION_ID`, `PAYG_OPTION_ID`** — sentinel values used by the picker to mark "Custom Amount" and "Pay As You Go" selections.
- **`diffPackageUpdates(productRef, currentSelection, subscriptionProductRef)`** — computes the `PackageUpdateInput[]` diff against the active package (returns `[]` when nothing changed, a single `ADD` for swaps, or `CANCEL` when reverting to PAYG).
- **`buildCheckoutProduct(productRef, currentSelection)`** — builds the `ProductCheckoutInput` target end-state used when there's no active paid subscription (trial/expired/canceled flows).

## Usage Example

```typescript
import { diffPackageUpdates, buildCheckoutProduct, PAYG_OPTION_ID } from './plan-selection';

const selection: ProductSelectionState = {
  payAsYouGoEnabled: false,
  billingPeriod: 'YEARLY',
  selectedPackageId: '500',
  customQuantity: null,
};

// For an existing paid subscription:
const updates = diffPackageUpdates(productFragmentRef, selection, subscriptionProductFragmentRef);
if (updates.length > 0) {
  await updateSubscription({ packageUpdates: updates });
}

// For a trial/expired subscription:
const checkoutInput = buildCheckoutProduct(productFragmentRef, selection);
await createCheckoutSession({ products: [checkoutInput] });
```

Internally, helpers like `committedOptionId`, `selectedQuantity`, and `toCatalogOptionId` normalize Relay global ids to the raw catalog uuids expected by the backend, and enforce `unitSize` granularity for custom quantities.
