# purchased-token-packs.tsx

A React client component that renders a list of still-spendable purchased token packs within a billing section, showing remaining/total tokens, expiration date, and purchase date for each pack.

## Key Components

- **`purchasedTokenPacksFragment`** — GraphQL fragment on `SubscriptionDetail` that fetches `usage.purchasedTokenPacks`, including `purchasedAt`, `tokensPurchased`, `tokensRemaining`, and `validUntil` for each pack. Packs are returned oldest-first (spend order), and expired packs are excluded by the API.
- **`PurchasedTokenPacks`** — The main component. Accepts a `subscription` prop (a Relay fragment reference) and resolves it via `useFragment`. Returns `null` if there are no active packs. Otherwise renders a `SectionBlock` titled "Purchased Tokens" containing a `BillingRow` per pack with:
  - Label: `tokensRemaining / tokensPurchased` (formatted compactly, e.g. "1.2K / 5K")
  - Value: "Valid until {date}" or an `EmptyValue` placeholder if no expiration is set
  - A secondary line showing the purchase date (UTC day)

## Usage Example

```typescript
import { PurchasedTokenPacks } from './purchased-token-packs';

function BillingDetails({ subscription }: { subscription: purchasedTokenPacks_subscription$key }) {
  return (
    <div className="billing-sections">
      <PurchasedTokenPacks subscription={subscription} />
    </div>
  );
}
```

**Note:** The displayed figures are per-pack values before any outstanding debt is settled against the account's overall token balance, so the sum of `tokensRemaining` across packs may not match the balance shown elsewhere in the billing UI — this component intentionally does not compute a total.
