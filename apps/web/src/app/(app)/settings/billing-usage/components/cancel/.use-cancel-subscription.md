# use-cancel-subscription.ts

A client-side React hook that encapsulates the GraphQL mutation for canceling a user's subscription, including optional cancellation reasoning, success/error handling, and Relay store invalidation.

## Key Components

- **`cancelSubscriptionMutation`** — GraphQL mutation definition (`graphql` tagged template) calling `cancelSubscription` with an optional `CancelSubscriptionInput`.
- **`CancelSubscriptionOptions`** — Interface for optional mutation inputs: `reason`, `description`, and an `onSuccess` callback.
- **`useCancelSubscription()`** — Hook returning:
  - `mutate(options?)` — Triggers the cancellation mutation. Builds `input` only if `reason` or `description` is provided; otherwise passes `null`.
  - `isPending` — Boolean flag (`isInFlight` from `useMutation`) indicating the mutation is in progress.

On success, since the mutation returns a bare `Boolean` (no updated subscription object), the hook manually calls `commitLocalUpdate` with `store.invalidateStore()` to force all subscription-derived queries (e.g., billing view, subscription-lock) to refetch fresh data rather than serve stale cached state. On error, it surfaces a destructive toast via `useToast`, using `getRelayErrorMessage` to extract a user-friendly message.

## Usage Example

```typescript
import { useCancelSubscription } from '@/hooks/use-cancel-subscription';

function CancelSubscriptionButton() {
  const { mutate, isPending } = useCancelSubscription();

  const handleCancel = () => {
    mutate({
      reason: 'too_expensive',
      description: 'Switching to a different plan',
      onSuccess: () => {
        console.log('Subscription canceled successfully');
      },
    });
  };

  return (
    <button onClick={handleCancel} disabled={isPending}>
      {isPending ? 'Canceling...' : 'Cancel Subscription'}
    </button>
  );
}
```
