# plan-checkout-cards.tsx

Renders the shared body of the plan checkout experience: a grid of pricing cards (Device Management and AI Token Balance) plus an optional AI assistants note. This component is reused by both the lock screen and the Activate Subscription modal, which differ only in the surrounding frame and placement of totals/actions (handled by `usePlanCheckout`).

## Key Components

- **`planCheckoutCardsFragment`** — GraphQL fragment on `Query` that spreads `billingPlan` (catalog products) and `subscription` (active products) so the component can resolve both the available device management product and its current subscription state.
- **`PlanCheckoutCardsProps`** — Props interface:
  - `query: planCheckoutCards_query$key | null` — Relay fragment key; `null` while data is loading, since child cards render their own pending states.
  - `form: PlanCheckout` — Shared checkout form state (from `use-plan-checkout`), including flags like `showAiCard`, `showDeviceCard`, `loading`, and device/AI top-up setters.
- **`PlanCheckoutCards`** — Main exported component. Resolves the device management product (catalog) and its subscription counterpart via `OpenframeProduct.MANAGED_DEVICES`, then lays out:
  - `AiAssistantsIncludedNote` (conditional)
  - A `LoadingRegion` wrapping a responsive grid (`grid-cols-1 lg:grid-cols-2`) containing `DeviceManagementCard` and `AiTokenBalanceCard`, each conditionally rendered based on `form.showDeviceCard` / `form.showAiCard`.

## Usage Example

```typescript
import { PlanCheckoutCards } from './plan-checkout-cards';
import { usePlanCheckout } from './use-plan-checkout';

function ActivateSubscriptionModal({ queryRef }: { queryRef: planCheckoutCards_query$key | null }) {
  const form = usePlanCheckout();

  return (
    <div className="modal-frame">
      <PlanCheckoutCards query={queryRef} form={form} />
      {/* Modal-specific total and submit button rendered here */}
    </div>
  );
}
```

Note: `items-stretch` (not `items-start`) is used so two cards of differing heights align as a single cohesive block rather than appearing mismatched, while each card's internal `flex-col` layout keeps content top-aligned.
