# stripe-tab-placeholder.tsx

Renders a styled loading placeholder into a newly opened browser tab (typically for Stripe Checkout/Billing Portal redirects), preventing the tab from showing a blank `about:blank` page while the external Stripe page loads.

## Key Components

- **`StripeTabPlaceholder`** *(internal)* — React component that renders a centered loading card with a status caption and skeleton placeholders (`TextLineSkeleton`, `UnifiedSkeleton`) mimicking a page layout.
- **`paintStripeTabPlaceholder(target, caption)`** *(exported)* — Injects the current page's styles, document attributes, and a React-rendered placeholder UI into a separate `Window` object (e.g., a tab opened via `window.open`), and mounts `StripeTabPlaceholder` into it.

## Usage Example

```typescript
'use client';

function handleUpgrade() {
  // Open a blank tab synchronously (required to avoid popup blockers)
  const stripeTab = window.open('', '_blank');

  if (stripeTab) {
    paintStripeTabPlaceholder(stripeTab, 'Redirecting to secure checkout…');
  }

  // Fetch the Stripe URL asynchronously, then navigate the tab
  fetchStripeCheckoutUrl().then(url => {
    if (stripeTab) {
      stripeTab.location.href = url;
    }
  });
}
```

## Notes

- Must open the tab **synchronously** on user interaction (e.g., inside a click handler) to avoid browser popup blockers, since the Stripe URL is typically fetched asynchronously afterward.
- Copies stylesheets, icons, `lang`, `class`, and `dataset` attributes from the current document so the placeholder matches the app's design tokens and theme (light/dark mode, CSS variables) despite the new tab having no app shell of its own.
- Uses `createRoot` from `react-dom/client` to mount the placeholder directly into the foreign document's body.
