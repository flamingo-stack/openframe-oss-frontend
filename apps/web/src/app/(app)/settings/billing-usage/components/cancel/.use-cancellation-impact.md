Aggregates "data you'll lose" counts across multiple backends (ai-agent GraphQL, main GraphQL, Fleet REST) for display in a cancellation confirmation modal.

## Key Components

### `CancellationImpact` (interface)
Shape of the resolved impact data:

| Field | Description |
|---|---|
| `tickets` | Total ticket count across all statuses |
| `kbArticles` | Knowledge base article count |
| `scripts` | Active (non-archived) script count |
| `monitoringPolicies` | Fleet monitoring policy count |
| `savedQueries` | Fleet saved query count |

### `useCancellationImpact({ enabled })` (hook)
Lazily fetches all five counters in parallel via `Promise.allSettled`. Each source fails independently — a broken endpoint degrades to `0` rather than rejecting the whole query. Results are cached for 60 seconds (`staleTime: 60_000`).

### Private fetch helpers
- `fetchTicketsTotal()` — POST to `/chat/graphql` (ai-agent endpoint)
- `fetchKbArticles()` — POST to `/api/graphql`
- `fetchScriptsCount()` — POST to `/api/graphql`, filters `ACTIVE` only
- Fleet counts — delegated to `fleetApiClient.getPoliciesCount()` / `getQueriesCount()`

## Usage Example

```typescript
import { useCancellationImpact } from '@/hooks/use-cancellation-impact';

function CancellationModal({ isOpen }: { isOpen: boolean }) {
  const { impact, isLoading } = useCancellationImpact({ enabled: isOpen });

  if (isLoading) return <Spinner />;

  return (
    <ul>
      <li>{impact?.tickets} tickets</li>
      <li>{impact?.kbArticles} knowledge base articles</li>
      <li>{impact?.scripts} active scripts</li>
      <li>{impact?.monitoringPolicies} monitoring policies</li>
      <li>{impact?.savedQueries} saved queries</li>
    </ul>
  );
}
```

> **Note:** The hook is fetch-gated by `enabled` — pass `false` when the modal is closed to avoid unnecessary network requests.
