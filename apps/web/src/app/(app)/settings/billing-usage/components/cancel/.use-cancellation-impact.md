# use-cancellation-impact.ts

A client-side hook that aggregates "what you'll lose" counts from external data sources (tickets, Fleet policies, and saved queries) to display impact warnings before a user cancels their subscription or account.

## Key Components

- **`ExternalCancellationImpact`** — Interface describing the counts not available from the main GraphQL schema: `tickets`, `monitoringPolicies`, and `savedQueries`.
- **`fetchTicketsTotal()`** — Internal async function that POSTs a GraphQL query to the ai-agent's dedicated `/chat/graphql` endpoint to retrieve the total ticket count via `ticketStatistics.totalCount`.
- **`useCancellationImpact()`** — React hook built on `useQuery` that fetches ticket, policy, and saved query counts in parallel using `Promise.allSettled`, so a failure in one source doesn't block the others. Returns `undefined` until all sources have resolved.

## Usage Example

```typescript
import { useCancellationImpact } from '@/hooks/use-cancellation-impact';

function CancellationWarningDialog() {
  const impact = useCancellationImpact();

  if (!impact) {
    return <p>Loading impact summary...</p>;
  }

  return (
    <div>
      <p>Cancelling will affect:</p>
      <ul>
        <li>{impact.tickets} open tickets</li>
        <li>{impact.monitoringPolicies} monitoring policies</li>
        <li>{impact.savedQueries} saved queries</li>
      </ul>
    </div>
  );
}
```

## Notes

- Tickets are fetched via raw `apiClient.post` against the ai-agent GraphQL schema (`/chat/graphql`), which is distinct from the main `/api/graphql` endpoint used elsewhere in the app.
- Policy and saved query counts come from `fleetApiClient`'s REST endpoints, not GraphQL.
- This is read-only, ancillary data intended for display purposes — failures silently degrade to `0` instead of surfacing error toasts, since the goal is a best-effort warning rather than a critical data path.
- Results are cached for 60 seconds (`staleTime: 60_000`) via React Query under the `['cancellation-impact']` query key.
