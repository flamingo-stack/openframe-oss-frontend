# auto-top-up-settings.ts

Defines types and validation logic for the auto top-up settings form, where users configure a billing threshold, top-up amount, and optional spend limit as whole-dollar text input.

## Key Components

- **`AutoTopUpSettingsValues`** — Form state interface holding `thresholdUsd`, `amountUsd`, and `spendLimitUsd` as raw text strings (empty `spendLimitUsd` means no limit).
- **`AutoTopUpSettingsField`** — Union of the keys of `AutoTopUpSettingsValues`, used for field-level error mapping.
- **`AutoTopUpMinimums`** — Backend-provided floor values (`minimumAmountUsd`, `minimumThresholdUsd`) that validation enforces.
- **`AutoTopUpSettingsInputValues`** — The parsed numeric payload sent to the backend on save; `spendLimitUsd: null` signals the limit should be removed.
- **`AutoTopUpSettingsValidation`** — Discriminated union result type: `{ ok: true, input }` or `{ ok: false, errors }`.
- **`toDollarsText(next)`** — Sanitizes free-form input into digits plus a single decimal point (e.g., `"$1,000.50"` → `"1000.50"`).
- **`validateAutoTopUpSettings(values, minimums)`** — Validates all three fields against whole-dollar formatting, minimums, threshold-vs-amount ordering, and spend-limit-vs-amount ordering; returns either parsed input or field errors.
- **`initialAutoTopUpSettingsValues(saved)`** — Converts saved numeric values (or `null`) into initial text field values for the form.

## Usage Example

```typescript
import {
  toDollarsText,
  validateAutoTopUpSettings,
  initialAutoTopUpSettingsValues,
} from './auto-top-up-settings';

// Seed the form from saved backend state
const values = initialAutoTopUpSettingsValues({
  thresholdUsd: 50,
  amountUsd: 100,
  spendLimitUsd: null,
});

// Sanitize user keystrokes in a controlled input
const sanitized = toDollarsText('$1,000.50'); // "1000.50"

// Validate before submitting
const result = validateAutoTopUpSettings(
  { thresholdUsd: '50', amountUsd: '100', spendLimitUsd: '' },
  { minimumAmountUsd: 20, minimumThresholdUsd: 10 },
);

if (result.ok) {
  // result.input: { thresholdUsd: 50, amountUsd: 100, spendLimitUsd: null }
  await updateAutoTopUp(result.input);
} else {
  // result.errors: Partial<Record<AutoTopUpSettingsField, string>>
  console.error(result.errors);
}
```
