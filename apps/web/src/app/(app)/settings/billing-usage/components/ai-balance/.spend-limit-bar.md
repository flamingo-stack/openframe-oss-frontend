A client-side React component that renders a visual progress bar representing how much of a rolling 30-day auto top-up spend limit has been consumed, switching to an error color when the limit is reached.

## Key Components

- **`SpendLimitBarProps`** — Interface defining the component's props:
  - `percent`: number from 0–100 indicating consumption of the spend limit over the trailing 30 days.
  - `reached`: boolean flag indicating whether the limit has been hit (blocking further auto top-ups until older entries age out of the window).
  - `label`: accessible text label describing what the bar measures, used for screen readers.
- **`SpendLimitBar`** — The exported functional component that renders a `Progress` bar (from `@flamingo-stack/openframe-frontend-core`) in `step` variant, applying an error-tone indicator class when `reached` is `true`.

## Usage Example

```typescript
import { SpendLimitBar } from './spend-limit-bar';

function BillingLimitRow() {
  const usedPercent = 82;
  const limitReached = usedPercent >= 100;

  return (
    <div className="flex flex-col gap-2">
      <span className="text-sm text-ods-text-secondary">
        Auto top-ups (last 30 days): {usedPercent}%
      </span>
      <SpendLimitBar
        percent={usedPercent}
        reached={limitReached}
        label="Auto top-up spend limit usage over the last 30 days"
      />
    </div>
  );
}
```

This component is typically used on the billing page beneath the spend limit row, and within the limit-editing modal beneath the limit input field, to give users immediate visual feedback on how close their recent auto top-ups are to the configured cap.
