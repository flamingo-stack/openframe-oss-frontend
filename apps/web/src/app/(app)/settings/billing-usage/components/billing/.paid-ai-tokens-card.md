# paid-ai-tokens-card.tsx

Renders a usage stat card displaying the user's prepaid AI token balance — the funds drawn from once the free grant is exhausted — including its monetary value and auto top-up status.

## Key Components

- **`PaidAiTokensCard`** — React component that renders a `UsageStatCard` showing the paid AI token count, its USD equivalent, and an optional auto top-up indicator.
- **`PaidAiTokensCardProps`** — Props interface accepting a Relay fragment key for the subscription and the current `AutoTopUpStatus`.
- **`paidAiTokensCardFragment`** — GraphQL fragment (`paidAiTokensCard_subscription`) that composes the shared `aiBalanceState_subscription` fragment to derive balance data.

## Usage Example

```typescript
import { PaidAiTokensCard } from './paid-ai-tokens-card';

function AiUsageSection({ subscriptionRef, autoTopUpStatus }) {
  return (
    <PaidAiTokensCard
      subscription={subscriptionRef}
      autoTopUp={autoTopUpStatus}
    />
  );
}
```

The component handles its own loading state via `useLoadingScope()`: while the subscription data is loading (or `subscription` is `null`), the card renders skeleton placeholders for the value and caption, while the `ModelTokenRatesPopover` trigger remains interactive. Once data resolves, it displays:

- The compact-formatted paid token count (via `formatCompactCount`)
- A `Refresh02VrIcon` badge when `autoTopUp.enabled` is `true`, signaling an active auto-refill arrangement
- The USD balance value (via `formatCurrency`), emphasized with `StatEmphasis`
- A `ModelTokenRatesPopover` showing per-model rates and auto top-up state in the trailing slot

This component is intended for use within billing/usage dashboards alongside sibling cards (e.g., free token usage cards) that share the `UsageStatCard` and `aiBalanceState` utilities.
