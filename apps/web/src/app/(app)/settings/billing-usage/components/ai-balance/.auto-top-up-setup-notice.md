# auto-top-up-setup-notice.tsx

A client-side React component that displays a warning notice when auto top-up configuration fails due to a missing payment method, prompting the user to add a card via Stripe before retrying.

## Key Components

- **`AutoTopUpSetupNotice`** — Functional component rendering a styled warning card. Accepts a `setupUrl` prop (string) pointing to the Stripe-hosted payment method setup page.
- **`setupUrl` prop** — URL returned from a prior mutation response; opened in a new tab only on direct user click (via `openExternalTab`) to avoid browser popup blockers, since automated `window.open` calls from async responses are typically blocked.

## Usage Example

```typescript
import { AutoTopUpSetupNotice } from './auto-top-up-setup-notice';

function BillingSettings({ autoTopUpSetupUrl }: { autoTopUpSetupUrl: string | null }) {
  if (autoTopUpSetupUrl) {
    return <AutoTopUpSetupNotice setupUrl={autoTopUpSetupUrl} />;
  }

  return <p>Auto top-up is configured.</p>;
}
```

**Context:** This component is shown when enabling automatic top-ups fails because no card is on file. Automatic (unattended) charges require a saved payment method, which cannot be captured without the customer actively returning from Stripe's hosted setup flow and re-saving the auto top-up preference. The `setupUrl` must originate from a mutation response rather than being opened programmatically on receipt, ensuring the resulting tab open is tied to a genuine user gesture (the button click) rather than an async callback, which browsers would otherwise block as a popup.
