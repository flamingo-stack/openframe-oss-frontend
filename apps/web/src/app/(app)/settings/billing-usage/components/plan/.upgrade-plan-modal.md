# upgrade-plan-modal.tsx

Modal component for changing a device plan on an active (LIVE) subscription, used in-place on the billing page. It wraps `DevicePlanPicker` with its own GraphQL query so the product catalog and pricing are fetched only when the modal is opened.

## Key Components

- **`UpgradePlanModal`** — Main exported component. Renders a `SimpleModal` titled "Change Plan" containing the plan picker and a `SubscriptionSubmitButton` footer. Returns `null` and skips all data fetching when `isOpen` is `false`.
- **`upgradePlanModalQuery`** — GraphQL query fetching `billingPlan.products` (catalog) and `subscription.products` (current plan), spreading fragments consumed by `DevicePlanPicker`.
- **`UpgradePlanBody`** — Wraps the data-reading component in `LoadingSuspense` to scope the loading boundary to just the picker.
- **`UpgradePlanReader`** — Checks `useLoadingScope()` to decide whether to render a placeholder (loading) version of `DevicePlanPicker` or the live, data-backed version.
- **`UpgradePlanLive`** — Runs `useLazyLoadQuery`, resolves the `MANAGED_DEVICES` product from both the catalog and the current subscription, and passes them to `DevicePlanPicker`.

## Usage Example

```typescript
import { useState } from 'react';
import { UpgradePlanModal } from './upgrade-plan-modal';

function BillingPage() {
  const [isModalOpen, setModalOpen] = useState(false);

  const handleUpdated = () => {
    // Refetch billing data since the mutation doesn't return
    // the updated `packageOptions` on products.
    refetchBillingPage();
    setModalOpen(false);
  };

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Change Plan</button>
      <UpgradePlanModal
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
        onUpdated={handleUpdated}
      />
    </>
  );
}
```

**Note:** This modal is only for *updating* an existing LIVE plan. For starting a new subscription from a trial (which requires AI top-up selection during checkout), use `ActivateSubscriptionModal` instead.
