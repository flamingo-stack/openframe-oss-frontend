# ai-balance-alert.tsx

A client-side React component that renders a warning/error banner informing users about the state of their AI token balance (low, empty, or trial exhausted), using a GraphQL fragment to pull subscription data via Relay.

## Key Components

- **`aiBalanceAlertFragment`** — GraphQL fragment pulling `currentPeriodEnd` and composing the shared `aiBalanceState_subscription` fragment from a `SubscriptionDetail`.
- **`AI_ALERT_COPY`** — Static lookup mapping each `AiAlert` state (`trial-exhausted`, `low`, `empty`) to its title and description copy, matching approved mockup text.
- **`AiBalanceAlert`** — The exported component. Accepts a `subscription` fragment reference, derives the current alert state via `aiBalanceState`, and renders `null` if there's no active alert. Otherwise renders a card with a warning icon (colored by severity) and the corresponding title/description, appending a reset date when applicable (not shown for trial-exhausted states, since activation—not time—resolves that case).

## Usage Example

```typescript
import { graphql, useFragment } from 'react-relay';
import { AiBalanceAlert } from './ai-balance-alert';

function SubscriptionPage({ subscriptionRef }: { subscriptionRef: any }) {
  return (
    <div className="flex flex-col gap-4">
      {/* Renders nothing if balance is healthy */}
      <AiBalanceAlert subscription={subscriptionRef} />
    </div>
  );
}
```

The parent query/fragment must spread `...aiBalanceAlert_subscription` on the `SubscriptionDetail` type to supply the required fragment reference:

```graphql
query SubscriptionPageQuery {
  subscriptionDetail {
    ...aiBalanceAlert_subscription
  }
}
```

**Note:** Severity coloring is icon-only—`text-ods-error` for empty, `text-ods-warning` for low/trial-exhausted—since the numeric balance itself is displayed elsewhere on the page.
