# auto-top-up-settings-fields.tsx

Renders the three editable fields (threshold, top-up amount, spend limit) for the "Manage AI Balance" modal's auto top-up configuration, including live helper text, validation error display, and a visual spend-limit usage bar.

## Key Components

- **`AutoTopUpSettingsFields`** — React component that renders a labeled form section with:
  - **Threshold** input — the balance that triggers a refill
  - **Top-up Amount** input — shows an estimated token count (`≈ X tokens per top-up`) computed from `tokenPrice`
  - **Spend Limit** input — caps total auto top-up spend over a rolling 30-day window
  - A **`SpendLimitBar`** usage indicator, shown only when `spentUsd` is known, reflecting the limit as currently typed (not yet saved)
- **`AutoTopUpSettingsFieldsProps`** — props interface accepting current `values`, an `onChange` handler, field-level `errors`, `tokenPrice`, `spentUsd`, and an optional `disabled` flag
- **`HELPER`** — static helper text constants for the threshold and spend limit fields

Internally, each field is rendered via a local `field()` helper that wraps `Input` with consistent styling, ARIA attributes (`aria-invalid`, `aria-describedby`, custom `aria-label`), a `USD` end adornment, and a persistent-height note line that displays either validation errors or helper text.

## Usage Example

```typescript
import { AutoTopUpSettingsFields } from './auto-top-up-settings-fields';
import type { AutoTopUpSettingsValues, AutoTopUpSettingsField } from './auto-top-up-settings';

function ManageBalanceModal() {
  const [values, setValues] = useState<AutoTopUpSettingsValues>({
    thresholdUsd: '10',
    amountUsd: '20',
    spendLimitUsd: '100',
  });
  const [errors, setErrors] = useState<Partial<Record<AutoTopUpSettingsField, string>>>({});

  const handleChange = (field: AutoTopUpSettingsField, next: string) => {
    setValues(prev => ({ ...prev, [field]: next }));
  };

  return (
    <AutoTopUpSettingsFields
      values={values}
      onChange={handleChange}
      errors={errors}
      tokenPrice={0.00002}
      spentUsd={42.5}
      disabled={false}
    />
  );
}
```

This component is intended to be used within a larger auto top-up settings form that owns the `values` state, performs validation, and persists changes on save.
