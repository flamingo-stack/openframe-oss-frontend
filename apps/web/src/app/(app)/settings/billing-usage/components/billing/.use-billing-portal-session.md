# use-billing-portal-session.ts

A React hook that opens Stripe's hosted Customer Billing Portal in a new browser tab by minting a short-lived portal session via a GraphQL mutation. The portal lets customers manage billing address, tax IDs, payment methods, and invoice history, but explicitly excludes subscription cancellation or plan changes, which remain handled in-app.

## Key Components

- **`createBillingPortalSessionMutation`** — GraphQL mutation (`createBillingPortalSession`) that requests a one-time Stripe portal URL.
- **`useBillingPortalSession()`** — Hook that returns:
  - `mutate()` — Triggers the mutation, opens a deferred tab synchronously on click (to avoid popup blockers), then navigates it to the returned `portalUrl` once the mutation resolves.
  - `isPending` — Boolean indicating the mutation is in flight (from `useMutation`'s `isInFlight`).

The hook relies on `openDeferredTab` to pre-open a placeholder tab before the async mutation completes, since Stripe session URLs are single-use and must be generated per click rather than linked statically.

## Usage Example

```typescript
import { useBillingPortalSession } from './use-billing-portal-session';

function BillingMenuItem() {
  const { mutate, isPending } = useBillingPortalSession();

  return (
    <button onClick={mutate} disabled={isPending}>
      {isPending ? 'Opening portal...' : 'Manage Billing'}
    </button>
  );
}
```

On success, the pre-opened tab navigates to the Stripe portal URL. On failure (GraphQL errors, missing URL, or network error), the tab is cancelled and a destructive toast notification is shown via `useToast` from `@flamingo-stack/openframe-frontend-core/hooks`.
