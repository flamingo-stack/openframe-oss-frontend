The question-mark button that opens the AI model token rates, for every card that counts in tokens (the paywall's AI
Token Balance card and the billing page's Paid AI Tokens counter). The table, its trigger and every state of it are the
shared library's (`ModelTokenRates`, `ModelTokenRatesPopover`); this file only reads the rates, inside the panel.

## Key Components

- **`ModelTokenRatesPopover`** *(exported)* — The lib's popover around two self-contained boundaries: an
  `ErrorBoundary` (a locked workspace has `aiModelRates` refused; the table then draws its error state) and a
  `LoadingSuspense` whose fallback is the same lib `ModelTokenRates` with no rates (its own loading form). Nothing the
  panel does reaches the page it is opened from. Props: `autoTopUpEnabled?` (the panel's first line on the billing
  page; left out on the paywall and while unread) and `className` (the trigger's).
- **`LoadedModelTokenRates`** — Internal. Reads `modelTokenRatesQuery` lazily on open (`store-and-network`, past the
  subscription gate) and hands the lib table the rates field by field.

## Usage Example

```typescript
import { ModelTokenRatesPopover } from './model-token-rates';

<UsageStatCard title="Paid AI Tokens" trailing={<ModelTokenRatesPopover autoTopUpEnabled={autoTopUp?.enabled} />} />
```

## Notes

- The trigger is a static control: a card drawn in a loading scope draws it for real.
