A React component that displays a table of AI model token conversion rates, fetched via Relay GraphQL, with provider icons and a local Suspense skeleton fallback.

## Key Components

- **`ModelTokenRates`** *(exported)* — Public entry point; wraps content in a self-contained `Suspense` boundary to avoid triggering the page-level skeleton when the query loads lazily (e.g., on tooltip open).
- **`ModelTokenRatesContent`** — Inner component that fires the `modelTokenRatesQuery` GraphQL query via `useLazyLoadQuery` and renders a scrollable list of model rows with provider icons and token ratios.
- **`ModelTokenRatesSkeleton`** — Loading placeholder matching the layout of the content, with 10 pre-keyed skeleton rows.
- **`formatRate(value)`** — Utility that converts a numeric rate to a human-readable ratio string (e.g., `2:1` or `1:5`); returns `—` for invalid/zero values.
- **`PROVIDER_ICON`** — Static map from provider type string (`ANTHROPIC`, `OPENAI`, `GOOGLE_GEMINI`) to its corresponding logo icon component.

## Usage Example

```typescript
// Drop into any tooltip, popover, or settings panel.
// The component self-manages its own Suspense + data fetching.
import { ModelTokenRates } from './model-token-rates';

function TokenRatesTooltip() {
  return (
    <Tooltip>
      <TooltipContent>
        <ModelTokenRates />
      </TooltipContent>
    </Tooltip>
  );
}
```

> **Note:** The `fetchPolicy: 'store-and-network'` strategy means cached data renders immediately on re-open while a background refresh keeps rates current. If `aiModelRates` returns an empty array, the component renders nothing.
