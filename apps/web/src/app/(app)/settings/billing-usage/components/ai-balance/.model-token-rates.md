# model-token-rates.tsx

A client component that renders the question-mark popover trigger displaying AI model token pricing (input/output rates per model). Used on both the paywall's AI Token Balance card and the billing page's Paid AI Tokens counter, sharing the underlying `ModelTokenRates` table component from the shared component library.

## Key Components

- **`ModelTokenRatesPopover`** — Exported entry point. Wraps the rates trigger/popover in an isolated `ErrorBoundary` + `Suspense` pair so the tooltip's own loading/error states never leak into (or are affected by) the page that hosts it. Accepts `autoTopUpEnabled` (controls whether the panel shows auto-refill messaging) and `className` (styles the trigger button).
- **`LoadedModelTokenRates`** — Internal wrapper providing a scoped `LoadingSuspense` (label: "Loading model rates") around the data-reading component.
- **`ModelTokenRatesReader`** — Checks `useLoadingScope()` to detect if it's rendering inside its own Suspense fallback; if so, renders the table with no data instead of triggering a live query (avoids redundant fetches during loading states).
- **`ModelTokenRatesLive`** — Executes the `modelTokenRatesQuery` GraphQL query via `useLazyLoadQuery`, mapping `aiModelRates` results into the shape `ModelTokenRates` expects. Uses `fetchPolicy: 'store-and-network'` and `skipSubscriptionGate: true` so it still loads on a locked/trial-expired workspace (the paywall must remain usable).

## Usage Example

```typescript
import { ModelTokenRatesPopover } from './model-token-rates';

function AiTokenBalanceCard() {
  return (
    <div className="balance-card">
      <span>AI Token Balance</span>
      <ModelTokenRatesPopover autoTopUpEnabled className="info-icon" />
    </div>
  );
}
```

**Important notes:**
- The `aiModelRates` GraphQL field is non-nullable (`[AiModelRate!]!`); if the backend rejects the request (e.g., `SUBSCRIPTION_TRIAL_EXPIRED`), Relay throws, which is caught locally by `ErrorBoundary` — rendering `ModelTokenRates` with `status="error"` instead of crashing the parent page.
- Because the component is a tooltip opened on-demand, its Suspense boundary is local, preventing a full-page skeleton flash when the popover's lazy query resolves.
