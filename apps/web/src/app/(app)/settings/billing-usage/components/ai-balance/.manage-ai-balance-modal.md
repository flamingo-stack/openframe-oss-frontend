# manage-ai-balance-modal.tsx

A modal component for managing a user's AI token balance and auto-top-up settings, fetched via GraphQL/Relay. It handles loading, error, and loaded states independently so the surrounding billing page remains unaffected by failures within the modal.

## Key Components

- **`ManageAiBalanceModal`** — Top-level exported component that wraps the modal in a `SimpleModal`, unmounting entirely when closed (`isOpen` is `false`) so each open starts fresh from saved data. Wraps content in an `ErrorBoundary` with a dedicated error fallback UI.
- **`manageAiBalanceModalQuery`** — GraphQL query fetching `autoTopUpSettings`, `billingPlan.products`, and `subscription.products`, used to compute pricing and auto-top-up state.
- **`ManageAiBalanceContent`** — Wraps the data reader in `LoadingSuspense` to show a loading state while the query resolves.
- **`ManageAiBalanceReader`** — Detects whether it's rendering inside a loading-scope fallback (via `useLoadingScope`) and renders the form with no data in that case, avoiding an unnecessary network read.
- **`ManageAiBalanceLive`** — Executes the actual `useLazyLoadQuery`, extracts the `AI_ASSISTANCE` product from both the billing catalog and subscription, and passes resolved `settings` and `tokenPrice` to `ManageAiBalanceForm`.

## Usage Example

```typescript
import { useState } from 'react';
import { ManageAiBalanceModal } from '@/app/components/billing/manage-ai-balance-modal';

function BillingPage() {
  const [isModalOpen, setIsModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>
        Manage AI Balance
      </button>

      <ManageAiBalanceModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
      />
    </>
  );
}
```

**Notes:**
- The query uses `fetchPolicy: 'store-or-network'` so it can resolve instantly from cache if the parent billing page already loaded the same data.
- `networkCacheConfig.metadata.skipSubscriptionGate` is set to `true` because this modal can remain open from the Billing & Usage page even when a `PAST_DUE` subscription gate is active elsewhere.
- Pricing is derived via the shared `aiTokenPrice` helper, combining catalog and subscription product data.
