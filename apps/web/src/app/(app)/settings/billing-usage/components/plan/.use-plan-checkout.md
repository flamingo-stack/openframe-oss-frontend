# use-plan-checkout.ts

A shared React hook that powers the unified plan checkout form used by both the subscription lock screen and the billing page's "Activate Subscription" modal. It centralizes device plan selection, AI top-up configuration, and the derived checkout/package-update payloads so each surface only needs to render the total and submit button.

## Key Components

- **`usePlanCheckout(query)`** — Main hook. Takes a Relay fragment key (or `null` while loading) and returns a `PlanCheckout` object with all form state and derived checkout inputs.
- **`PlanCheckout`** interface — Shape of the returned form state, including loading flags, device count, device/AI selections, auto top-up toggle, and computed `checkoutProducts` / `packageUpdates` for submission.
- **`usePlanCheckoutFragment`** — GraphQL fragment pulling the product catalog (`billingPlan.products`) and current device usage (`subscription.usage.activeDevices`) from the `Query` root.
- **`PREPAID_YEAR_TOP_UP_PRESETS_USD`** — Reduced top-up preset grid (`[20, 50]`) shown when the user selects an annual (prepaid) device plan, as opposed to the standard pay-as-you-go preset grid.

## Usage Example

```typescript
import { usePlanCheckout } from './use-plan-checkout';
import type { usePlanCheckout_query$key } from '@/__generated__/usePlanCheckout_query.graphql';

function ActivateSubscriptionModal({ queryRef }: { queryRef: usePlanCheckout_query$key | null }) {
  const plan = usePlanCheckout(queryRef);

  if (plan.loading) {
    return <Spinner />;
  }

  return (
    <>
      {plan.showDeviceCard && (
        <DevicePlanCard
          deviceCount={plan.deviceCount}
          onChange={plan.setDeviceUpdates}
        />
      )}
      {plan.showAiCard && (
        <AiTokenBalanceCard
          topUp={plan.topUp}
          autoTopUp={plan.autoTopUp}
          canAutoTopUp={plan.canAutoTopUp}
          onAutoTopUpChange={plan.setAutoTopUp}
        />
      )}
      <CheckoutButton
        disabled={plan.hasInvalidCustom}
        checkoutProducts={plan.checkoutProducts}
        tokenAmountUsd={plan.tokenAmountUsd}
        total={plan.selectionTotal}
      />
    </>
  );
}
```

Both the lock screen and billing modal consume this same hook to guarantee consistent pricing logic and Stripe Checkout payload construction across surfaces.
