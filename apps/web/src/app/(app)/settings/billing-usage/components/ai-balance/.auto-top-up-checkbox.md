A client-side React component rendering a labeled "Enable Auto Top-up" checkbox, used in balance management and paywall surfaces to let customers opt into automatic balance refills.

## Key Components

- **`AutoTopUpCheckbox`** — Functional component wrapping `CheckboxBlock` from `@flamingo-stack/openframe-frontend-core`, pre-configured with the "Enable Auto Top-up" label and a sensible default description.
- **`AutoTopUpCheckboxProps`** — Props interface:
  - `checked: boolean` — current checkbox state.
  - `onCheckedChange: (checked: boolean) => void` — callback fired on toggle.
  - `disabled?: boolean` — disables the checkbox (e.g., during a purchase/save in flight, or while catalog data hasn't loaded).
  - `error?: string` — error message shown when the box is unticked due to an external event (e.g., a declined charge), not a user action.
  - `description?: string` — overrides the default description text, letting the hosting surface customize the explanation (e.g., referencing the modal's refill threshold).
- **`DEFAULT_DESCRIPTION`** — Fallback copy explaining that the balance auto-refills with the selected amount once it runs out.

## Usage Example

```typescript
import { useState } from 'react';
import { AutoTopUpCheckbox } from './auto-top-up-checkbox';

function ManageAiBalanceModal() {
  const [autoTopUp, setAutoTopUp] = useState(false);
  const [saving, setSaving] = useState(false);

  return (
    <AutoTopUpCheckbox
      checked={autoTopUp}
      onCheckedChange={setAutoTopUp}
      disabled={saving}
      error={autoTopUp ? undefined : 'Your last auto top-up charge was declined.'}
      description="Once enabled, refills trigger at the threshold set above."
    />
  );
}
```

Use this component anywhere a consistent, labeled auto top-up toggle is needed—such as the Manage AI Balance modal or the paywall's AI Token Balance card—keeping label and description copy aligned across surfaces while allowing per-surface customization.
