# free-ai-tokens-card.tsx

A React client component that displays the current billing period's free AI token allowance alongside how much of that allowance has been consumed, rendered via the shared `UsageStatCard` UI pattern.

## Key Components

- **`FreeAiTokensCard`** — Exported component accepting a `subscription` prop (a Relay fragment reference of type `freeAiTokensCard_subscription$key | null`). It:
  - Resolves subscription data via `useFragment` using the colocated `freeAiTokensCardFragment` GraphQL fragment.
  - Derives AI balance info through the shared `aiBalanceState` helper, which spreads in the `aiBalanceState_subscription` fragment.
  - Uses `useLoadingScope()` to detect ambient loading state and render skeleton/placeholder bars instead of real values.
  - Formats token counts with `formatCompactCount` for compact numeric display (e.g., `1.2K`).
  - Shows a contextual caption: `"Included with trial"` for trial subscriptions, otherwise `"Updated monthly"`.

- **`freeAiTokensCardFragment`** — GraphQL fragment on `SubscriptionDetail` that composes the `aiBalanceState_subscription` fragment, keeping data requirements declarative and co-located with the component.

## Usage Example

```typescript
import { FreeAiTokensCard } from './free-ai-tokens-card';

function BillingOverview({ subscriptionRef }: { subscriptionRef: freeAiTokensCard_subscription$key | null }) {
  return (
    <div className="stats-grid">
      <FreeAiTokensCard subscription={subscriptionRef} />
    </div>
  );
}
```

The component gracefully handles a `null` subscription (e.g., before data loads) by rendering the `UsageStatCard` in its loading state until both the fragment data and loading scope resolve.
