# invoices-filter-modal.tsx

A responsive fallback for the invoices table's sort and filter controls, rendering a modal UI for viewport widths where the table header (with its sort arrows and status funnel) is hidden (`hidden content-md:flex`). It adapts TanStack Table's `ColumnFiltersState`/`SortingState` into the shape `FilterModal` expects, and translates user actions back into that same state.

## Key Components

- **`InvoicesFilterModalProps`** — Props interface accepting modal open/close handlers, status filter options, and the TanStack sorting/filtering state plus their setters.
- **`InvoicesFilterModal`** — The default export component. Wraps `FilterModal` from `@flamingo-stack/openframe-frontend-core`, providing:
  - `sortConfig`: defines the two sortable columns (`dueDate`, `amountDue`) and derives current sort state from `sorting[0]`.
  - `filterGroups`: maps `statusOptions` into a single "Status" filter group.
  - `currentFilters`: converts `columnFilters` into a `{ columnId: string[] }` record for the modal.
  - `handleFilterChange`: converts the modal's filter selections back into `ColumnFiltersState`, dropping empty selections so the table's "filtered" status stays accurate.
  - Sort changes apply immediately (not gated behind "Apply"), driven by `onSort`/`onSortClear` callbacks.

## Usage Example

```typescript
import { useState } from 'react';
import { InvoicesFilterModal } from './invoices-filter-modal';
import { useInvoicesTable } from './use-invoices-table';
import { invoiceStatusOptions } from './invoice-status-options';

function InvoicesPage() {
  const [isModalOpen, setModalOpen] = useState(false);
  const { sorting, setSorting, columnFilters, setColumnFilters } = useInvoicesTable();

  return (
    <InvoicesFilterModal
      isOpen={isModalOpen}
      onClose={() => setModalOpen(false)}
      statusOptions={invoiceStatusOptions}
      sorting={sorting}
      onSortingChange={setSorting}
      columnFilters={columnFilters}
      onColumnFiltersChange={setColumnFilters}
    />
  );
}
```

**Note:** State ownership stays entirely in `useInvoicesTable`; this component is purely a translation layer, ensuring the modal and table header controls never fall out of sync.
