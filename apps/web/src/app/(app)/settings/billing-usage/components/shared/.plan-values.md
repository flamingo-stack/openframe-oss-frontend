Renders formatted pricing and token-quota values for subscription plan displays, pairing a formatted numeric value with a styled "/ month" cadence suffix.

## Key Components

- **`MonthlyRate`** — Displays a per-device monthly price. Accepts an `amount` (number) prop, formats it via `formatCurrency`, and appends a muted `/ month` label.
- **`MonthlyTokens`** — Displays a monthly token allowance. Accepts a `tokens` (number) prop, formats it via `formatCompactCount` (e.g., `10K`, `1.2M`), and appends a muted `/ month` label.

Both components use the `text-ods-text-secondary` CSS class to visually de-emphasize the cadence text relative to the primary value.

## Usage Example

```typescript
import { MonthlyRate, MonthlyTokens } from '@/components/plan-values';

function PlanCard() {
  return (
    <div className="plan-card">
      <div className="price">
        <MonthlyRate amount={49.99} />
      </div>
      <div className="quota">
        <MonthlyTokens tokens={1000000} />
      </div>
    </div>
  );
}
```

This typically produces output like `$49.99 / month` and `1M / month`, with the `/ month` portion styled as secondary text to draw attention to the primary value.
