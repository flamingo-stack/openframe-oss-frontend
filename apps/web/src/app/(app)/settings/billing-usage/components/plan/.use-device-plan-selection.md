# use-device-plan-selection.ts

A React hook that manages device plan selection state (pay-as-you-go vs. annual commitment) for a billing/checkout flow, deriving pricing, validation, and checkout payloads from a Relay GraphQL product catalog fragment.

## Key Components

- **`useDevicePlanSelection(args)`** — Main hook. Resolves catalog pricing, tracks the user's selected mode (`PAYG`/`ANNUAL`) and device quantity, validates the selection, and reports `ProductUpdates` to a parent via `onUpdatesChange`.
- **`DevicePlanCatalog`** — Derived pricing shape: pay-as-you-go/annual unit prices, discount percentage, and minimum device floors for each billing period.
- **`DevicePlanState`** — Internal state: current `mode` and `quantity` (devices to prepay for annual).
- **`buildDevicePlanCatalog(product)`** — Extracts rates and minimums from the raw GraphQL product fragment. Devices are priced per billing period only (not tiered by quantity), so only the entry price tier is read.
- **`buildInitialDevicePlan(catalog, subscriptionProduct)`** — Seeds initial mode/quantity, defaulting to `ANNUAL` if a committed package exists, otherwise `PAYG` if available.
- **`MINIMUM_MANAGED_DEVICES`** (constant, `10`) — Product-defined floor for managed devices, since catalog price tiers start at 1.
- **Returned API**: `catalog`, `mode`, `quantity`, `unitSize`, `annualTotal`, `quantityTooSmall`, `quantityNotDivisible`, `setMode`, `setQuantity`, `commitQuantity`.

## Usage Example

```typescript
import { useDevicePlanSelection } from './use-device-plan-selection';

function DevicePlanCard({ productRef, subscriptionProductRef }) {
  const {
    catalog,
    mode,
    quantity,
    annualTotal,
    quantityTooSmall,
    setMode,
    setQuantity,
    commitQuantity,
  } = useDevicePlanSelection({
    productRef,
    subscriptionProductRef,
    onUpdatesChange: (updates) => {
      // Send updates (checkout payload, validity, total) to parent/checkout flow
      console.log(updates);
    },
  });

  return (
    <div>
      <button onClick={() => setMode('PAYG')}>Pay as you go</button>
      <button onClick={() => setMode('ANNUAL')}>Annual</button>

      {mode === 'ANNUAL' && (
        <input
          type="number"
          value={quantity}
          onChange={e => setQuantity(Number(e.target.value))}
          onBlur={commitQuantity}
        />
      )}

      {quantityTooSmall && <p>Minimum {catalog.minAnnualDevices} devices required</p>}
      {annualTotal != null && <p>Total: ${annualTotal}/year</p>}
    </div>
  );
}
```

**Note:** Requires Relay fragment refs (`productRef`, `subscriptionProductRef`) generated from the corresponding GraphQL fragments (`useDevicePlanSelection_product`, `useDevicePlanSelection_subscriptionProduct`).
