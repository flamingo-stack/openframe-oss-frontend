# current-plan-section.tsx

A React client component that renders the "Current Plan" billing summary block, displaying the tenant's billing cycle, device rate, free AI tokens, next payment amount, and relevant billing dates. It consumes GraphQL fragments via Relay to derive its values, with loading-state handling built into each row.

## Key Components

- **`CurrentPlanSectionProps`** — Props interface accepting Relay fragment references for `subscription` and `billingPlan` (both nullable while loading).
- **`CurrentPlanSection`** — Main exported component. Resolves fragment data with `useFragment`, computes derived values (device rate, billing cycle, next payment, free tokens, plan end date), and renders a `SectionBlock` containing multiple `BillingRow` entries.
- **`currentPlanSectionSubscriptionFragment`** — GraphQL fragment on `SubscriptionDetail`, fetching `nextPayment`, period/cancellation dates, AI usage, and composing `planSchedule_subscription`.
- **`currentPlanSectionBillingPlanFragment`** — GraphQL fragment on `BillingPlanDetails`, fetching product list with `catalogDeviceRate_product`.

## Design Notes

- Uses a **"one row rule"**: the same rows render in both loading and loaded states, with individual loading indicators per value rather than hiding whole rows.
- Device rate prioritizes the subscription's negotiated price over the catalog's period-specific rate, avoiding incorrect cross-period rate lookups.
- Distinguishes three date concepts (`currentPeriodEnd`, `cancellationEffectiveAt`, package `endDate` via `planSchedule`) and renders them as independent rows rather than merging them.
- Billing cycle is "Annual" only when the active package's `billingPeriod` is `YEARLY`; otherwise "Monthly".

## Usage Example

```typescript
import { CurrentPlanSection } from './current-plan-section';

function BillingPage({ subscriptionRef, billingPlanRef }) {
  return (
    <CurrentPlanSection
      subscription={subscriptionRef}
      billingPlan={billingPlanRef}
    />
  );
}
```

The component expects `subscriptionRef` and `billingPlanRef` to be Relay fragment keys obtained from a parent query (e.g., via `useLazyLoadQuery`), and is typically rendered inside a billing dashboard alongside other `SectionBlock` components like "Updated Plan" or "Payment Method".
