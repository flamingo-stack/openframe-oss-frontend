Reusable UI primitives for the billing section layout, providing a test mode banner, labeled section containers, and key-value row components.

## Key Components

| Export | Type | Description |
|---|---|---|
| `TestModeBanner` | Component | Yellow warning banner indicating test/sandbox mode with an alert icon and static copy |
| `SectionBlock` | Component | Titled card container wrapping billing content in a styled bordered card |
| `BillingRow` | Component | Dot-leader-style label/value row with optional muted or warning color states |

## Props

**`SectionBlock`**
- `title: string` — Uppercase section heading displayed above the card
- `children: React.ReactNode` — Content rendered inside the card

**`BillingRow`**
- `label: string` — Left-aligned descriptor text
- `value: React.ReactNode` — Right-aligned value (supports rich content)
- `muted?: boolean` — Renders value in secondary text color (default: `false`)
- `warning?: boolean` — Renders value in warning color, takes precedence over `muted` (default: `false`)

## Usage Example

```typescript
import { TestModeBanner, SectionBlock, BillingRow } from './billing-section';

function BillingOverview() {
  return (
    <>
      <TestModeBanner />
      <SectionBlock title="Current Plan">
        <BillingRow label="Plan" value="Pro" />
        <BillingRow label="Seats Used" value="18 / 20" muted />
        <BillingRow label="Overage" value="$12.00" warning />
      </SectionBlock>
    </>
  );
}
```
