# auto-top-up-notice.tsx

Renders a contextual warning banner explaining why a tenant's AI balance auto top-up has stopped refilling—either because it was manually switched off, or because a spend limit is currently blocking refills. Surfaces the information the tenant would otherwise only discover when their AI assistant stops responding due to an exhausted balance.

## Key Components

- **`AutoTopUpNotice`** — Component that renders one of three states based on `status`:
  - `status.switchedOff` set → warning banner with switched-off copy (sourced from `SWITCHED_OFF_COPY`) and border styled with `border-ods-warning`.
  - `status.paused` set → warning banner explaining the spend limit was reached, including an optional resume date and manage-balance hint.
  - Neither set → renders `null` (no notice shown).
- **`spendLimitReachedSentence(status)`** — Builds the "You've reached your spend limit..." sentence, formatting the limit as currency when available. Shared between the inline notice and other UI (e.g., a modal) for consistent copy.
- **`resumeSentence(status)`** — Builds the " Auto top-ups resume on..." sentence when `status.resumesAt` is present, otherwise returns an empty string.
- **`AutoTopUpNoticeProps`** — Props interface: `status: AutoTopUpStatus` and `onManage: (() => void) | null` (pass `null` when the "Manage AI Balance" action is unavailable for the current build).

## Usage Example

```typescript
import { AutoTopUpNotice } from './auto-top-up-notice';
import type { AutoTopUpStatus } from './auto-top-up-status';

function BalanceBanner({ status }: { status: AutoTopUpStatus }) {
  const openManageModal = () => {
    // open "Manage AI Balance" dialog
  };

  return (
    <AutoTopUpNotice
      status={status}
      onManage={openManageModal}
    />
  );
}

// Build variant where managing balance isn't supported:
<AutoTopUpNotice status={status} onManage={null} />
```

Use `spendLimitReachedSentence` and `resumeSentence` directly when the same copy needs to appear elsewhere, such as inside a "Manage AI Balance" modal:

```typescript
import { spendLimitReachedSentence, resumeSentence } from './auto-top-up-notice';

const message = `${spendLimitReachedSentence(status)}${resumeSentence(status)}`;
```
