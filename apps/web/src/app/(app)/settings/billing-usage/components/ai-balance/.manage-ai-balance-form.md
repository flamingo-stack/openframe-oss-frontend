# manage-ai-balance-form.tsx

A modal form component that manages a user's AI token balance, supporting three distinct user intents in a single interface: enabling/configuring auto top-up, disabling it, or making a one-time token purchase. The UI and submit action adapt based on an internal checkbox combined with the currently saved auto top-up state.

## Key Components

- **`ManageAiBalanceForm`** — Main component rendering the balance management modal. Derives an `Intent` (`'enable' | 'disable' | 'purchase'`) from the checkbox state vs. the saved `wasEnabled` flag, and swaps form fields, submit label, and mutation logic accordingly.
- **`ManageAiBalanceFormData`** (interface) — Props data shape: current `settings` (`AutoTopUpStatus`) and `tokenPrice`. Passed as `null` while data is loading, which locks the form.
- **`Intent`** (type) — Union describing which of three actions the submit button performs.
- **`SUBMIT_LABEL`** — Maps each `Intent` to its button text (`Save`, `Turn Off Auto Top-up`, `Proceed to Payment`).
- **`SpendLimitReachedAlert`** — Internal helper component showing a warning alert when auto top-ups are paused due to a reached spend limit, with an optional resume timestamp.

The component composes several hooks (`useAiTopUp`, `usePurchaseTokens`, `useUpdateAutoTopUp`) and sub-components (`AutoTopUpCheckbox`, `AutoTopUpSettingsFields`, `AiTopUpFields`, `AutoTopUpSetupNotice`) to handle validation, mutation state, and conditional notices (e.g., missing payment method).

## Usage Example

```typescript
import { ManageAiBalanceForm, type ManageAiBalanceFormData } from './manage-ai-balance-form';
import { ModalV2 } from '@flamingo-stack/openframe-frontend-core/components/ui';

function AiBalanceModal({ open, onClose }: { open: boolean; onClose: () => void }) {
  const formData: ManageAiBalanceFormData | null = useAiBalanceQuery(); // fetched elsewhere

  return (
    <ModalV2 open={open} onOpenChange={onClose}>
      <ManageAiBalanceForm data={formData} onClose={onClose} />
    </ModalV2>
  );
}
```

Pass `data={null}` while fetching to render the form in a loading/locked state; once resolved, the component automatically determines whether the user is enabling, disabling, or purchasing based on the saved `settings.enabled` value and checkbox interaction.
