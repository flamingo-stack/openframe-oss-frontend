# device-usage-card.tsx

A React component that displays device usage statistics on a billing/subscription dashboard, showing the device count relative to its plan allocation (or trial status) along with contextual billing information.

## Key Components

- **`DeviceUsageCard`** — Exported component that renders a `UsageStatCard` showing device usage. Accepts a `subscription` prop (a Relay fragment key or `null`) and handles its own loading state via `useLoadingScope`.
- **`deviceUsageCardFragment`** — GraphQL fragment pulling `trialExpirationDate` plus composed fragments from `deviceAllocation` and `planSchedule`, ensuring consistency with sibling components that share the same subscription data.
- **`caption()`** — Internal helper that builds the two-line caption `ReactNode`: trial messaging (with optional expiration date) or plan billing messaging (prepaid/pay-as-you-go with a billing terms link).
- **`deviceUsage()`** — Internal helper that derives the card's `tone` (`warning` when over limit), `value` (count with or without an allocation denominator), and `caption` from the fragment data.

## Usage Example

```typescript
import { DeviceUsageCard } from './device-usage-card';
import type { deviceUsageCard_subscription$key } from '@/__generated__/deviceUsageCard_subscription.graphql';

function BillingDashboard({ subscriptionRef }: { subscriptionRef: deviceUsageCard_subscription$key | null }) {
  return (
    <div className="grid grid-cols-3 gap-4">
      <DeviceUsageCard subscription={subscriptionRef} />
    </div>
  );
}
```

The component renders in a loading state (skeleton bars) while `subscription` is `null` or while inside a loading scope. Once data resolves, it displays either:
- **Trial**: a bare device count with a trial period message and expiration date (if provided by the server).
- **Prepaid plan**: `used/allocation` count with "Annual Prepaid" or "Monthly Prepaid" caption and a billing terms link.
- **Pay-as-you-go**: a bare device count with "Pay as you go" caption and billing terms link.

Tone switches to `warning` when usage exceeds the allocated limit.
