# useBillingProvisioningStatus

A React hook that polls the tenant's billing provisioning status until it reaches a terminal state, intended for use in a dev-only test-clock panel after operations (like a Stripe customer reset) that trigger asynchronous backend re-provisioning.

## Key Components

- **`useBillingProvisioningStatus(options)`** — Hook accepting an optional `{ enabled?: boolean }` config. Returns `{ status, restart }`.
  - `status: ProvisioningStatus | null` — latest `{ state, message }` from the server, or `null` before the first response.
  - `restart: () => void` — call after a re-provisioning action (e.g. a reset) to reset the poll loop.
- **`billingProvisioningStatusQuery`** — GraphQL query fetching `billingProvisioningStatus { state, message }`.
- **`ProvisioningStatus`** — Interface describing the polled status shape; `state` is kept as a raw string to avoid casting away Relay's `%future added value` enum member.

Polling uses `fetchQuery` (not `useLazyLoadQuery`) so it runs outside Suspense and doesn't blank the UI on each poll. It retries silently on transient errors (up to `MAX_CONSECUTIVE_ERRORS`), continues while `state === BillingProvisioningState.PENDING`, and stops once a terminal state is reached. Setting `enabled: false` prevents any network activity, useful when the panel is rendered in a loading scope.

## Usage Example

```typescript
'use client';

import { useBillingProvisioningStatus } from '@/hooks/use-billing-provisioning-status';
import { BillingProvisioningState } from '@/generated/schema-enums';

function TestClockPanel({ isLoading }: { isLoading: boolean }) {
  const { status, restart } = useBillingProvisioningStatus({ enabled: !isLoading });

  const handleReset = async () => {
    await resetStripeTestClock();
    restart(); // re-trigger polling after the tenant is torn down/rebuilt
  };

  if (!status) return <span>Loading provisioning status...</span>;

  return (
    <div>
      <p>State: {status.state}</p>
      <p>{status.message}</p>
      {status.state === BillingProvisioningState.PENDING && (
        <span>Provisioning in progress...</span>
      )}
      <button onClick={handleReset}>Reset Test Clock</button>
    </div>
  );
}
```
