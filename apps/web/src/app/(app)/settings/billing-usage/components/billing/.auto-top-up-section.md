Renders a read-only billing summary of a user's Auto Top-up configuration, showing its on/paused state, refill threshold, top-up amount, and 30-day spend limit usage.

## Key Components

- **`Trailing`** — Internal helper component that renders a secondary, muted text fragment (e.g., `" / refill when balance drops below"`) appended after a primary value in a billing row.
- **`AutoTopUpSection({ status })`** — Main exported component. Renders nothing if `status.enabled` is `false`. Otherwise displays a `SectionBlock` titled "Auto Top-up" containing:
  - **Status** row — "On", or "Paused" with an optional resume date/time.
  - **Threshold** row — the balance that triggers a refill (shown only if `status.thresholdUsd` is set).
  - **Top-up Amount** row — the charge per refill (shown only if `status.amountUsd` is set).
  - **Spend Limit** row — either "No limit" with 30-day spend total, or the spent amount (highlighted red via `text-ods-error` if the limit is reached) versus the configured limit.
  - **`SpendLimitBar`** — visual progress bar for spend limit usage, rendered only when usage data is available (i.e., a spend limit is set).

This component is purely presentational/read-only; all configuration changes happen in the "Manage AI Balance" flow elsewhere.

## Usage Example

```typescript
import { AutoTopUpSection } from './auto-top-up-section';
import type { AutoTopUpStatus } from '../ai-balance/auto-top-up-status';

const status: AutoTopUpStatus = {
  enabled: true,
  paused: false,
  thresholdUsd: 5,
  amountUsd: 20,
  spendLimitUsd: 100,
  spentUsd: 42.5,
};

function BillingPage() {
  return (
    <div>
      <AutoTopUpSection status={status} />
    </div>
  );
}
```

Dependencies include `formatCurrency` and `formatDateTime` utilities, the `spendLimitUsage` helper and `SpendLimitBar` from the AI balance module, and shared `BillingRow`/`SectionBlock` layout primitives.
