# billing-restricted-screen.tsx

A React component that displays a role-based access restriction screen in place of the Billing & Usage pages, shown to users (non-owners/admins) who lack permission to view billing information.

## Key Components

- **`BillingRestrictedScreen`** — Default-exported function component rendering a `LockedScreen` with context-aware title, description, and a "Back to Settings" action button.

### Behavior Notes

- Unlike other restricted routes which return a 404, this screen is shown specifically for *role-based* denial (section exists, but current user lacks permission) — see `use-billing-access-gate.ts` for the access gate logic that routes here.
- A fully disabled billing feature (`billings === 'off'`) still returns a 404, since the section genuinely doesn't exist for that tenant.
- Copy adapts based on `isBillingHidden()`:
  - **Hidden** (native builds, no payment surface): uses generic "Usage is restricted" wording to comply with App Store Guideline 3.1.1, avoiding any mention of subscriptions/payments.
  - **Not hidden** (web/standard builds): uses "Billing is restricted" wording that explicitly references subscription and payment management.

## Usage Example

```typescript
import { BillingRestrictedScreen } from '@/app/components/.../billing-restricted-screen';

// Rendered conditionally by a billing access gate when the current
// user is authenticated but not authorized (owner/admin) to view
// billing pages:
function BillingPage() {
  const { hasAccess } = useBillingAccessGate();

  if (!hasAccess) {
    return <BillingRestrictedScreen />;
  }

  return <ActualBillingContent />;
}
```
