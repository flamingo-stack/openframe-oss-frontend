# invoices-history.tsx

Renders the tenant's invoice history section, displaying a searchable, sortable, filterable data table of Stripe invoices with distinct states for loading, error, and empty data scenarios.

## Key Components

- **`InvoicesHistory`** — Main exported component that accepts a `subscription` Relay fragment reference (or `null` while loading) and renders the full invoices section.
- **`invoicesHistoryFragment`** — GraphQL fragment (`invoicesHistory_subscription`) that fetches `pendingInvoices` from `SubscriptionDetail`, spreading the shared `invoiceRow_invoice` fragment.
- **`INVOICES_UNAVAILABLE_MESSAGE`** — Error message shown when the subscription loads but invoices come back `null` (e.g., Stripe unreachable).

## Behavior

- **Loading state**: Determined via `useLoadingScope()` or a `null` subscription; the table renders skeleton rows (`INVOICES_SKELETON_ROWS`).
- **Error state**: If not loading and `pendingInvoices` is `null`, shows an inline error message instead of the table (distinguishes "failed to load" from "no invoices").
- **Empty state**: If not loading and the mapped `invoices` array is empty, renders a `NoData` placeholder with a billing-themed icon.
- **Populated state**: Renders a search input, a mobile-only filter trigger button (hidden at `content-md` breakpoint and above, since the table header takes over filtering), a `DataTable` with sorting/row-count controls, and an `InvoicesFilterModal` for mobile filter/sort controls.
- Invoice rows are transformed via `toInvoiceRow` and memoized to preserve referential stability for the table's row model.
- Table state (search, sorting, column filters, status options) is sourced from the `useInvoicesTable` hook.

## Usage Example

```typescript
import { InvoicesHistory } from './invoices-history';

function BillingPage({ subscriptionRef }: { subscriptionRef: invoicesHistory_subscription$key | null }) {
  return (
    <section>
      <InvoicesHistory subscription={subscriptionRef} />
    </section>
  );
}
```

Typically rendered within a billing/subscription detail page, consuming a Relay fragment reference resolved from a parent query.
