# cancel-offer-modal.tsx

A retention modal shown during the subscription cancellation flow that presents a reason-specific "last chance" offer (plan comparison, roadmap, or support contact) before letting the user confirm or abandon cancellation.

## Key Components

- **`OfferPreset`** — Interface describing the content for a retention offer: title, description, CTA copy/icon, and an optional `ctaHref` destination.
- **`OFFER_PRESETS`** — A `Record<CancelReason, OfferPreset>` mapping each cancellation reason (`TOO_EXPENSIVE`, `NOT_USING_ENOUGH`, `MISSING_FEATURE`, `TECHNICAL_ISSUES`, `OTHER`) to its tailored offer content. Presets without `ctaHref` (pricing-related reasons) expect the parent page to handle the CTA click (e.g., opening a plan picker modal); presets with `ctaHref` link to internal help center routes (roadmap or tickets) via the `routes` registry.
- **`CancelOfferModalProps`** — Props: `isOpen`, `reason` (nullable `CancelReason`), `isPending`, `onClose`, `onConfirm`, and `onCtaClick`.
- **`CancelOfferModal`** — The component itself. Renders a `SimpleModal` with a description, a clickable CTA card, and footer actions ("Keep Subscription" / "Cancel Subscription"). Its `handleCtaClick` opens `ctaHref` in a new tab (`window.open` with `noopener,noreferrer`) when present, or delegates to `onCtaClick` otherwise — preserving the in-progress cancellation modal rather than navigating away.

## Usage Example

```typescript
import { useState } from 'react';
import { CancelOfferModal } from './cancel-offer-modal';
import type { CancelReason } from './cancel-subscription-modal';

function CancellationFlow() {
  const [reason, setReason] = useState<CancelReason | null>('TOO_EXPENSIVE');
  const [isOfferOpen, setIsOfferOpen] = useState(true);
  const [isPending, setIsPending] = useState(false);

  return (
    <CancelOfferModal
      isOpen={isOfferOpen}
      reason={reason}
      isPending={isPending}
      onClose={() => setIsOfferOpen(false)}
      onConfirm={async () => {
        setIsPending(true);
        await cancelSubscription();
        setIsPending(false);
        setIsOfferOpen(false);
      }}
      onCtaClick={() => {
        // Handles presets without a ctaHref, e.g. opening the plan picker
        openPlanPickerModal();
      }}
    />
  );
}
```
