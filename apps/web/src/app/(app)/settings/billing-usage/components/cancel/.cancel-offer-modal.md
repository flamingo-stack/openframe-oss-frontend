A retention-focused modal component that presents contextual offers or alternatives to users who are about to cancel their subscription, based on their stated cancellation reason.

## Key Components

### `OFFER_PRESETS`
A `Record<CancelReason, OfferPreset>` map that defines tailored retention messaging for each cancellation reason:

| Reason | Offer |
|---|---|
| `TOO_EXPENSIVE` / `NOT_USING_ENOUGH` | Downgrades to a cheaper plan via billing settings |
| `MISSING_FEATURE` | Links to the OpenFrame public roadmap |
| `TECHNICAL_ISSUES` / `OTHER` | Directs to support via email |

### `OfferPreset`
Internal interface defining the shape of each retention offer: `title`, `description`, `ctaTitle`, `ctaDescription`, `ctaIcon`, and optional `ctaHref`.

### `CancelOfferModal`
The primary exported component. Renders a `SimpleModal` with:
- Contextual description text from the matched preset
- A styled CTA button card with icon, title, description, and a chevron indicator
- Footer actions: **Keep Subscription** (outline) and **Cancel Subscription** (destructive)

## Props

| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `reason` | `CancelReason \| null` | Drives preset selection; renders `null` if absent |
| `isPending` | `boolean` | Disables buttons and shows loading state during cancellation |
| `onClose` | `() => void` | Handles modal dismissal / keep subscription |
| `onConfirm` | `() => void` | Handles confirmed cancellation |
| `onCtaClick` | `() => void` | Optional override for CTA click; defaults to `window.open` |

## Usage Example

```typescript
<CancelOfferModal
  isOpen={showOfferModal}
  reason={selectedReason}
  isPending={isCancelling}
  onClose={() => setShowOfferModal(false)}
  onConfirm={handleConfirmCancel}
/>
```
