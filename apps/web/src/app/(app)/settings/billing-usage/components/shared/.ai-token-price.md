# ai-token-price.ts

Computes the per-token USD price for AI token purchases from GraphQL catalog/subscription data, and converts a USD amount into an estimated token quantity. Designed to prevent a pricing bug where a per-unit rate (e.g., $10 per 1,000,000 tokens) was mistakenly applied directly per token.

## Key Components

- **`aiTokenPriceProductFragment`** — `@inline` Relay fragment on `Product`, reading `unitSize`, `payAsYouGoOption`, and `packageOptions` (with `priceTiers`) from the catalog.
- **`aiTokenPriceSubscriptionProductFragment`** — `@inline` Relay fragment on `SubscriptionProductDetail`, reading the tenant's negotiated `payAsYouGoOption` and `packageOptions`, which take precedence over catalog pricing when present.
- **`unitPriceOf(product)`** — Internal helper resolving the rate-per-unit from a product: pay-as-you-go price, falling back to the `UNLIMITED` billing-period package's price, then its first price tier's `unitPrice`.
- **`aiTokenPrice(catalogRef, subscriptionRef?)`** — Exported function returning the `$`-per-token rate, dividing the resolved unit price by `unitSize`. Returns `null` if the catalog ref, rate, or a valid `unitSize` is missing — never falls back to a `unitSize` of 1.
- **`tokensForUsd(amountUsd, tokenPrice)`** — Exported function estimating how many tokens a given USD amount buys at the given per-token price, floored to a whole number. Returns `null` for invalid or non-positive inputs.

## Usage Example

```typescript
import { aiTokenPrice, tokensForUsd } from '@/path/to/ai-token-price';

function TokenPackageTile({ catalogRef, subscriptionRef }: Props) {
  const tokenPrice = aiTokenPrice(catalogRef, subscriptionRef);
  const estimatedTokens = tokensForUsd(20, tokenPrice);

  if (tokenPrice == null || estimatedTokens == null) {
    return <span>Pricing unavailable</span>;
  }

  return <span>${'{'}20{'}'} → ~{estimatedTokens.toLocaleString()} tokens</span>;
}
```

**Note:** Both functions deliberately return `null` instead of a misleading fallback (such as assuming `unitSize = 1`), ensuring callers render "no figure" rather than a wrong one when pricing data is incomplete.
