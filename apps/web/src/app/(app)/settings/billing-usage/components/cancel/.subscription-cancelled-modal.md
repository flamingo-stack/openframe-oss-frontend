# subscription-cancelled-modal.tsx

A client-side React component that displays a confirmation modal informing users their subscription has been cancelled, with messaging that varies based on whether the subscription included a package plan or was pay-as-you-go (PAYG).

## Key Components

- **`SubscriptionCancelledModal`** — Main exported component rendering a `SimpleModal` with cancellation details.
- **`SubscriptionCancelledModalProps`** — Props interface:
  - `isOpen: boolean` — Controls modal visibility.
  - `endDate: string | null` — The date access ends (relevant only when `withPackage` is `true`).
  - `withPackage: boolean` — Indicates whether the subscription had an active package; determines which copy is shown.
  - `onClose: () => void` — Callback invoked when the modal is dismissed.

The component conditionally renders one of two messages:
- **With package**: Shows overage/retention copy (`PACKAGE_CANCELLED_OVERAGE`) plus a formatted `endDate` (via `formatDate`) and purchase info (`PACKAGE_CANCELLED_PURCHASES`).
- **Without package (PAYG)**: Shows `PAYG_CANCELLED_TERMS` copy, since access has already ended.

## Usage Example

```typescript
import { useState } from 'react';
import { SubscriptionCancelledModal } from './subscription-cancelled-modal';

function BillingPage() {
  const [isModalOpen, setModalOpen] = useState(true);

  return (
    <SubscriptionCancelledModal
      isOpen={isModalOpen}
      endDate="2024-12-31T00:00:00Z"
      withPackage={true}
      onClose={() => setModalOpen(false)}
    />
  );
}
```

For a PAYG subscription (no retained access period):

```typescript
<SubscriptionCancelledModal
  isOpen={true}
  endDate={null}
  withPackage={false}
  onClose={() => setModalOpen(false)}
/>
```

Copy constants (`PACKAGE_CANCELLED_OVERAGE`, `PACKAGE_CANCELLED_PURCHASES`, `PAYG_CANCELLED_TERMS`) are defined in `./cancellation-copy` and should be updated there for messaging changes.
