Defines the hardcoded monthly free AI token allowances for tenants, distinguishing between committed device-package plans and metered pay-as-you-go billing, used wherever a plan's token grant must be previewed before the backend-computed `usage.aiTokensFree` figure is available.

## Key Components

- **`FREE_TOKENS_COMMITTED`** — Internal constant: 25,000,000 free tokens/month for tenants on a committed device package.
- **`FREE_TOKENS_PAYG`** — Internal constant: 10,000,000 free tokens/month for tenants on metered pay-as-you-go billing.
- **`freeTokensForPlan(committed: boolean): number`** — Returns the appropriate free token allowance based on whether the plan is (or will be) committed to a device package.

## Usage Example

```typescript
import { freeTokensForPlan } from './ai-free-tokens';

// Previewing a plan on the paywall before purchase
const previewTokens = freeTokensForPlan(true); // 25,000,000

// Describing the "Updated Plan" column for a scheduled change to PAYG
const updatedPlanTokens = freeTokensForPlan(false); // 10,000,000
```

**Important notes:**
- These values are hardcoded placeholders until the billing catalog exposes a real field for this figure. They are used only in contexts where the tenant is **not yet** on the plan being described (e.g., paywall previews, scheduled plan-change previews).
- For tenants already on an active plan, prefer the live `usage.aiTokensFree` value from the backend instead of this function.
- Trial plans (5M free tokens) are intentionally **not** covered here, since trials are never previewed—this function should not be called to represent trial allowances.
- When the catalog eventually provides this figure, both constants in this file should be replaced with calls to that source, and this module can likely be removed.
