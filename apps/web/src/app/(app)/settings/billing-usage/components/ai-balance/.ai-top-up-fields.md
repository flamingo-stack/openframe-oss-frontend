Renders the shared AI top-up amount selection UI used by both the billing page's "Manage AI Balance" modal and the paywall's "AI Token Balance" card, letting users choose "Don't top up," a preset USD amount, or a custom amount, each displayed with its equivalent token count sourced from the plan catalog rate.

## Key Components

- **`AI_BALANCE_EXPLANATION`** — Constant string explaining the shared AI balance concept, meant to be shown alongside the fields wherever top-up is offered.
- **`AiTopUpFieldsProps`** — Props interface: `topUp` (an `AiTopUp` state object), `label` (section heading), `disabled` (blocks all controls), `loading` (catalog not yet loaded).
- **`AiTopUpFields(props)`** — Main exported component. Renders a "Don't top up" tile (if allowed), preset amount tiles with token counts, a "Custom" tile, an input field for custom amounts, loading states via `LoadingLine`/`useLoadingScope`, and error messaging (including `RATE_UNAVAILABLE_MESSAGE` when the catalog has no AI rate).
- **`TopUpTile`** (internal) — Button-styled selectable tile showing a title, a subtitle (or loading bar when `null`), and a checkmark icon when selected.

## Usage Example

```typescript
import { AiTopUpFields } from './ai-top-up-fields';
import { useAiTopUp } from './use-ai-top-up';

function ManageAiBalanceModal() {
  const topUp = useAiTopUp({ allowNone: true });

  return (
    <AiTopUpFields
      topUp={topUp}
      label="Top up your balance"
      disabled={topUp.isSubmitting}
      loading={topUp.isCatalogLoading}
    />
  );
}
```

The component relies on the `AiTopUp` interface (from `./use-ai-top-up`) to drive selection state (`NO_TOP_UP`, `CUSTOM_TOP_UP`, or a preset USD value), custom amount input, token conversion (`tokensForUsd`), and validation errors — all UI logic for amount selection lives here, while state/data fetching is owned by the `useAiTopUp` hook.
