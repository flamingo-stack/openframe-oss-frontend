# catalog-device-rate.ts

Resolves the catalog's monthly per-device rate for a given billing period (or the pay-as-you-go/metered option when no period is specified), reading from the `MANAGED_DEVICES` product in the catalog.

This module acts as the single source of truth for device pricing lookups, used by plan selection UI to price panels consistently with how the subscription's committed options are priced (where an option's own price may be left empty and instead sourced from the catalog).

## Key Components

- **`catalogDeviceRateFragment`** — An `@inline` Relay fragment (`catalogDeviceRate_product`) that selects pricing data from a `Product`: its `packageOptions` (billing-period-based options with `price`/`priceTiers`) and its `payAsYouGoOption` (metered pricing). Marked `@inline` because it's consumed by plain function readers rather than components.
- **`catalogDeviceRate(products, period)`** — Looks up the `MANAGED_DEVICES` product among the given fragment refs and returns its rate:
  - If `period` is `null`, uses `payAsYouGoOption`.
  - Otherwise, finds the `packageOptions` entry matching `billingPeriod === period`.
  - Returns the option's flat `price`, falling back to the first `priceTiers[0].unitPrice` (since devices are priced per period, not by quantity).
  - Returns `null` if no matching product or option exists.

## Usage Example

```typescript
import { catalogDeviceRate } from '@/path/to/catalog-device-rate';
import type { catalogDeviceRate_product$key } from '@/__generated__/catalogDeviceRate_product.graphql';

function getMonthlyDeviceRate(
  productRefs: readonly catalogDeviceRate_product$key[],
  selectedPeriod: string | null,
) {
  const rate = catalogDeviceRate(productRefs, selectedPeriod);

  if (rate == null) {
    // No MANAGED_DEVICES product or no matching option in the catalog
    return 'N/A';
  }

  return `$${rate.toFixed(2)} / device / month`;
}

// Billing-period rate
getMonthlyDeviceRate(catalogProducts, 'MONTHLY');

// Pay-as-you-go / metered rate
getMonthlyDeviceRate(catalogProducts, null);
```

Typically paired with `use-device-plan-selection.ts`, which relies on the same per-period pricing semantics when computing plan totals.
