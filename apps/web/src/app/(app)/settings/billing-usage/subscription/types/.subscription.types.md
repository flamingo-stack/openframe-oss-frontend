Shared type definitions for the subscription management feature, centralising GraphQL-generated types alongside local domain types used across checkout and subscription-update flows.

## Key Components

### Re-exports

| Type | Source |
|---|---|
| `BillingPeriod` | `productSubscriptionCardProductFragment.graphql` |
| `SubscriptionProductStatus` | `productSubscriptionCardSubscriptionFragment.graphql` |
| `OpenframeProduct` | `subscriptionSettingsViewQuery.graphql` |

### Local Types

- **`UpdateAction`** — Union `'ADD' | 'CANCEL'` describing the direction of a subscription change.
- **`ProductSelectionState`** — Captures UI state for a product card: PAYG toggle, billing period, selected package ID, and optional custom quantity.
- **`PlanLine`** — Represents one side (current or next) of a product plan; holds PAYG flag, committed quantity, billing period, and annualised cost.
- **`PlanComparison`** — Pairs a `current` and `next` `PlanLine` for the "how your subscription changes" summary block. `current` is `null` when the product is not yet subscribed.
- **`ProductUpdates`** — Aggregates everything needed to execute a change: `packageUpdates` for active subscriptions, `checkout` input for trial/cancelled flows, a `valid` flag, and the `PlanComparison` for display.

## Usage Example

```typescript
import type {
  ProductSelectionState,
  ProductUpdates,
  PlanComparison,
  BillingPeriod,
} from './subscription.types';

const selection: ProductSelectionState = {
  payAsYouGoEnabled: false,
  billingPeriod: 'MONTHLY',
  selectedPackageId: 'pkg_starter',
  customQuantity: null,
};

const comparison: PlanComparison = {
  current: { payg: false, quantity: 50, billingPeriod: 'MONTHLY', annualTotal: 600 },
  next:    { payg: false, quantity: 100, billingPeriod: 'ANNUAL', annualTotal: 1080 },
};

const updates: ProductUpdates = {
  packageUpdates: [{ packageId: 'pkg_starter', action: 'CANCEL' }],
  checkout: { productId: 'prod_rmmm', packageId: 'pkg_growth' },
  valid: true,
  comparison,
};
```
