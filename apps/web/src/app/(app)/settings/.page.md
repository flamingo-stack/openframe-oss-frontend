Client-side settings page entry point that renders the main settings hub component.

## Key Components

- **`Settings`** — Default page export that wraps and renders the `SettingsHub` component.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to /settings
// No direct usage required — acts as the route entry point

import Settings from './page';

// Equivalent to:
// <SettingsHub />
```

## Notes

- Marked as a Client Component via `'use client'` directive.
- Delegates all rendering logic to [`SettingsHub`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/settings/components/settings-hub.tsx), keeping the page thin and focused on routing concerns.
