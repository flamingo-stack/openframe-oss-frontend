This file defines route-level metadata and layout re-export for the Settings page in a Next.js App Router application.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the browser tab title for the Settings route using the shared `routeTitle` helper, ensuring consistent title formatting across the app.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as the layout for this route segment, avoiding duplication of layout logic.

## Usage Example

This file is automatically picked up by Next.js as the `layout.tsx` for the Settings route segment. No manual import is required; Next.js wires it up based on file-system routing conventions.

```typescript
// Resulting behavior: any page under this route segment
// will render inside the shared route-title-layout,
// and the browser tab will display "Settings" (formatted via routeTitle).

// Example of the underlying helper for reference:
// lib/route-title.ts
export function routeTitle(title: string): string {
  return `${title} | OpenFrame`;
}
```

Because the layout component is re-exported rather than redefined, updates to `route-title-layout` automatically propagate to this route, keeping navigation chrome and title behavior consistent throughout the app.
