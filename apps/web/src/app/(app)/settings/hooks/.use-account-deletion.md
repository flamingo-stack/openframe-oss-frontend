# use-account-deletion.ts

Client-side hook that orchestrates the post-account-deletion navigation flow: revoking the server session, handing off context to the `/account-deleted` page, and ensuring the app never briefly renders a "signed-out" app chrome during the transition.

## Key Components

- **`DELETED_ACCOUNT_ORG_STORAGE_KEY`** — `sessionStorage` key used to pass the deleted account's organization name to the `/account-deleted` page, since the auth session (and thus the org name) is gone by the time that page renders.
- **`ACCOUNT_DELETED_PENDING_STORAGE_KEY`** — Hand-off flag between this hook and the `/account-deleted` page. The page performs the actual local sign-out (clearing tokens/store/query cache) on mount, rather than the hook doing it before navigating, to avoid a flash of "Sign in required" UI mid-navigation. It also guards against a direct, unauthorized visit to `/account-deleted` triggering a sign-out.
- **`useLeaveDeletedAccount()`** — Returns an async function to call after a successful account self-deletion. It:
  1. Stores org name and pending flag in `sessionStorage` (best-effort; falls back gracefully if storage is unavailable).
  2. Unregisters native push notifications on mobile shells.
  3. Revokes the gateway session server-side (with one retry) using the effective tenant ID.
  4. If `sessionStorage` wasn't available, performs an inline `forceLogout` and clears the auth session query cache immediately.
  5. Navigates via `router.replace` to `routes.accountDeleted`, keeping the deletion flow out of browser history.

## Usage Example

```typescript
import { useLeaveDeletedAccount } from '@/hooks/use-account-deletion';

function DeleteAccountButton() {
  const leaveDeletedAccount = useLeaveDeletedAccount();

  async function handleDeleteAccount() {
    await deleteAccountMutation.mutateAsync();
    // Session revoke + navigation to /account-deleted
    await leaveDeletedAccount();
  }

  return <button onClick={handleDeleteAccount}>Delete My Account</button>;
}
```

Pair this hook with the `/account-deleted` page, which must check `ACCOUNT_DELETED_PENDING_STORAGE_KEY` on mount to perform local sign-out and read `DELETED_ACCOUNT_ORG_STORAGE_KEY` to display the deleted organization's name.
