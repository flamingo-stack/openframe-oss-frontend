A React hook for fetching and updating tenant domain configuration, including auto-provisioning settings, via the API client.

## Key Components

### Types

- **`TenantDomainInfo`** — Shape of the domain config response: `domain`, `generic`, and `autoAllow` fields
- **`UpdateSharedAutoProvisionPayload`** — Payload for updating auto-provision: `{ autoAllow: boolean }`
- **`UpdateSharedAutoProvisionResponse`** — Response shape with optional `success` or structured `error` fields

### Hook: `useTenantDomain`

Returns the following:

| Property | Type | Description |
|---|---|---|
| `fetchTenantDomain` | `() => Promise<TenantDomainInfo>` | Fetches current tenant domain config from `api/config/global/domain` |
| `updateSharedAutoProvision` | `(enabled: boolean) => Promise<UpdateSharedAutoProvisionResponse>` | POSTs updated `autoAllow` value to `api/config/global/domain` |
| `isLoading` | `boolean` | `true` while `fetchTenantDomain` is in flight |
| `isUpdating` | `boolean` | `true` while `updateSharedAutoProvision` is in flight |

**Error handling notes:**
- `fetchTenantDomain` defaults `autoAllow` to `false` if the field is absent in the response
- `updateSharedAutoProvision` surfaces structured `BAD_REQUEST` errors as a typed return value rather than throwing, but re-throws unexpected errors for the caller to handle

## Usage Example

```typescript
const { fetchTenantDomain, updateSharedAutoProvision, isLoading, isUpdating } = useTenantDomain();

// Fetch current domain config
const domainInfo = await fetchTenantDomain();
console.log(domainInfo.domain, domainInfo.autoAllow);

// Toggle auto-provisioning
const result = await updateSharedAutoProvision(true);
if (result.error) {
  console.error(result.error.message);
} else {
  console.log('Auto-provisioning enabled');
}
```
