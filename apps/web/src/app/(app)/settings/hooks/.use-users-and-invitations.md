Combines `useUsers` and `useInvitations` hooks into a single unified data source, normalizing both users and pending invitations into a common `UnifiedUserRecord` shape for consistent rendering in user management UIs.

## Key Components

### `RecordType` (enum)
Discriminator enum with values `User` and `Invitation`, used to identify the origin of a `UnifiedUserRecord`.

### `UnifiedUserRecord` (type)
Common interface merging fields from both `UserRecord` and `InvitationRecord`. Includes `type` and original record references (`originalUser`, `originalInvitation`) for downstream access to source data.

### `useUsersAndInvitations(page, size)` (hook)
The primary export. Fetches and merges paginated users and invitations, exposing combined state, separate pagination counters, and all invitation mutations.

**Returns:**

| Field | Description |
|---|---|
| `records` | Memoized array of `UnifiedUserRecord` (users + invitations) |
| `isLoading` | `true` if either sub-hook is loading |
| `error` | First error from either sub-hook |
| `combinedTotalElements` | Sum of both pagination totals |
| `refetchAll` | Refetches both queries in parallel |
| `revokeInvitation`, `resendInvitation`, `inviteUsers` | Invitation mutation handlers |
| `usersHook`, `invitationsHook` | Raw hooks for advanced use cases |

## Usage Example

```typescript
import { useUsersAndInvitations, RecordType } from './use-users-and-invitations';

function UserManagementTable() {
  const { records, isLoading, error, refetchAll, inviteUsers } =
    useUsersAndInvitations(0, 20);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  return records.map((record) => (
    <Row
      key={record.id}
      isPending={record.type === RecordType.Invitation}
      email={record.email}
      roles={record.roles}
      status={record.status}
    />
  ));
}
```
