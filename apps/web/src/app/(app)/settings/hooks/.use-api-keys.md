# use-api-keys.ts

A React hook that manages API key CRUD operations, providing state management for listing, creating, updating, regenerating, and toggling API keys via the backend `api-keys` REST endpoint.

## Key Components

- **`ApiKeyRecord`** — Type describing an API key's metadata, including usage statistics (`totalRequests`, `successfulRequests`, `failedRequests`) and lifecycle timestamps (`createdAt`, `updatedAt`, `lastUsed`, `expiresAt`).
- **`useApiKeys()`** — Hook returning:
  - `items` — Current list of `ApiKeyRecord` objects.
  - `isLoading` — Boolean, `true` by default (assumes fetch on mount).
  - `error` — Error message string, or `null`.
  - `fetchApiKeys()` — Fetches all API keys and updates `items`.
  - `createApiKey(data)` — Creates a new API key; returns the created record plus the one-time `fullKey` value.
  - `updateApiKey(id, data)` — Updates name/description/expiration for an existing key.
  - `regenerateApiKey(id)` — Regenerates a key's secret; returns updated record and new `fullKey`.
  - `setApiKeyEnabled(id, enabled)` — Enables or disables a key.

All mutating functions throw an `Error` with a descriptive message on failure (non-OK response or missing data), so callers should wrap calls in `try/catch`.

## Usage Example

```typescript
'use client';

import { useEffect } from 'react';
import { useApiKeys } from '@/hooks/use-api-keys';

export function ApiKeysPanel() {
  const { items, isLoading, error, fetchApiKeys, createApiKey, setApiKeyEnabled } = useApiKeys();

  useEffect(() => {
    fetchApiKeys().catch(() => {
      // error state is already set by the hook
    });
  }, [fetchApiKeys]);

  const handleCreate = async () => {
    try {
      const { apiKey, fullKey } = await createApiKey({ name: 'CI Token' });
      console.log('New key created:', apiKey.id, fullKey);
    } catch (e) {
      console.error(e);
    }
  };

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {items.map((key) => (
        <li key={key.id}>
          {key.name} — {key.enabled ? 'Enabled' : 'Disabled'}
          <button onClick={() => setApiKeyEnabled(key.id, !key.enabled)}>
            Toggle
          </button>
        </li>
      ))}
      <button onClick={handleCreate}>Create Key</button>
    </ul>
  );
}
```
