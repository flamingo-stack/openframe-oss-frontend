React hook for managing SSO provider configuration, exposing async methods to fetch, update, and toggle SSO providers via the API client.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `AvailableProvider` | Provider name and display label returned from the available providers list |
| `ProviderConfig` | Full configuration for a single SSO provider, including credentials and domain rules |
| `UpdateSsoPayload` | Payload shape for creating or updating a provider's configuration |

### Hook — `useSsoConfig`

Returns four memoized async methods:

| Method | Signature | Description |
|--------|-----------|-------------|
| `fetchAvailableProviders` | `() => Promise<AvailableProvider[]>` | Retrieves all SSO providers supported by the backend |
| `fetchProviderConfig` | `(provider: string) => Promise<ProviderConfig \| undefined>` | Fetches config for a specific provider; returns `undefined` if none exists |
| `updateProviderConfig` | `(provider: string, payload: UpdateSsoPayload) => Promise<void>` | Creates or replaces credentials and settings for a provider |
| `toggleProviderEnabled` | `(provider: string, enabled: boolean) => Promise<void>` | Enables or disables a provider without modifying its config |

## Usage Example

```typescript
import { useSsoConfig } from '@/hooks/use-sso-config';

export function SsoSettingsPanel() {
  const {
    fetchAvailableProviders,
    fetchProviderConfig,
    updateProviderConfig,
    toggleProviderEnabled,
  } = useSsoConfig();

  async function handleSave(provider: string) {
    await updateProviderConfig(provider, {
      clientId: 'my-client-id',
      clientSecret: 'my-secret',
      msTenantId: 'tenant-123',
      autoProvisionUsers: true,
      allowedDomains: ['acme.com'],
    });

    await toggleProviderEnabled(provider, true);
  }
}
```

> **Note:** `fetchProviderConfig` returns `undefined` (rather than throwing) when no configuration exists for the requested provider, making it safe to use as an existence check before rendering a config form.
