Manages user invitation data and operations, providing a unified hook for fetching, revoking, resending, and sending invitations via TanStack Query.

## Key Components

### Types
- **`InvitationStatus`** — Enum with `Pending` and `Expired` states
- **`InvitationRecord`** — Shape of a single invitation (id, email, roles, timestamps, status)
- **`PagedInvitationsResponse`** — Paginated API response wrapper

### Query Keys
- **`invitationsQueryKeys`** — Structured cache key factory for list queries, enabling targeted invalidation

### `useInvitations(page, size)`
Primary hook returning invitation data, pagination metadata, loading/error states, and mutation handlers:

| Return | Description |
|---|---|
| `invitations` | Current page of `InvitationRecord[]` |
| `isLoading` / `error` | Fetch state |
| `page`, `size`, `totalPages`, `totalElements`, `hasNext`, `hasPrevious` | Pagination metadata |
| `revokeInvitation(id, options?)` | Deletes an invitation and invalidates cache |
| `resendInvitation(id, options?)` | Re-sends an invitation and invalidates cache |
| `inviteUsers(emails[])` | Sends invitations in parallel; throws on partial failure |
| `invitationsQuery` | Raw TanStack Query object for advanced use |

## Usage Example

```typescript
import { useInvitations } from '@/hooks/use-invitations';

function InvitationsTable() {
  const {
    invitations,
    isLoading,
    totalPages,
    hasNext,
    revokeInvitation,
    resendInvitation,
    inviteUsers,
  } = useInvitations(0, 20);

  const handleInvite = async () => {
    await inviteUsers(['alice@example.com', 'bob@example.com']);
  };

  const handleRevoke = (id: string) => {
    revokeInvitation(id, {
      onSuccess: () => console.log('Revoked'),
      onError: (err) => console.error(err),
    });
  };

  if (isLoading) return <Spinner />;

  return (
    <>
      {invitations.map(inv => (
        <Row key={inv.id} invitation={inv} onRevoke={handleRevoke} />
      ))}
    </>
  );
}
```
