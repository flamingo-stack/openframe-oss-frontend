React Query hook for fetching a single user record by ID from the API, returning the user data, loading state, and error message.

## Key Components

- **`fetchUser(userId)`** — Async function that calls `GET api/users/:userId`, returning `null` on 404 or throwing on other errors.
- **`useUser(userId)`** — Public hook wrapping `useQuery` with the shared `usersQueryKeys.detail(userId)` cache key. The query is disabled when `userId` is falsy.

## Usage Example

```typescript
import { useUser } from '@/hooks/use-user';

function UserProfile({ userId }: { userId: string }) {
  const { user, isLoading, error } = useUser(userId);

  if (isLoading) return <Spinner />;
  if (error) return <p>Error: {error}</p>;
  if (!user) return <p>User not found.</p>;

  return <p>{user.name}</p>;
}
```

## Notes

- Shares the `usersQueryKeys` namespace from [`use-users.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/hooks/use-users.ts), ensuring the detail entry is automatically invalidated alongside list queries.
- Returns `null` (not an error) for 404 responses, allowing callers to distinguish "not found" from a network/server failure.
- `enabled: !!userId` prevents the query from firing with an empty string, avoiding unnecessary API calls.
