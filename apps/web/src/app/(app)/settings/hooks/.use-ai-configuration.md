React hook for managing AI provider configuration state, including fetching the current configuration, retrieving supported models, and persisting updates via the API.

## Key Components

### Interfaces

- **`AiConfiguration`** — Represents the active AI setup: provider (`OPENAI`, `ANTHROPIC`, `GOOGLE_GEMINI`), model name, active status, and API key presence
- **`ModelInfo`** — Describes a single model with display name, provider, and context window size
- **`SupportedModels`** — Grouped map of available models keyed by provider slug
- **`UpdateAiConfigurationParams`** — Input shape for saving a new configuration (provider, model, optional API key)

### Hook: `useAiConfiguration`

| Return Value | Type | Description |
|---|---|---|
| `configuration` | `AiConfiguration \| null` | Currently active AI configuration |
| `supportedModels` | `SupportedModels` | Available models grouped by provider |
| `isLoading` | `boolean` | True while initial data is fetching |
| `isSaving` | `boolean` | True while an update is in progress |
| `fetchConfiguration` | `() => Promise` | Re-fetches the current configuration |
| `fetchSupportedModels` | `() => Promise` | Re-fetches the supported models list |
| `updateConfiguration` | `(params) => Promise` | Posts new config and refreshes state |

Both fetch functions are called automatically on mount via `useEffect`.

## Usage Example

```typescript
import { useAiConfiguration } from '@/hooks/use-ai-configuration';

function AiSettingsPanel() {
  const {
    configuration,
    supportedModels,
    isLoading,
    isSaving,
    updateConfiguration,
  } = useAiConfiguration();

  if (isLoading) return <Spinner />;

  const handleSave = async () => {
    await updateConfiguration({
      provider: 'ANTHROPIC',
      modelName: 'claude-3-5-sonnet-20241022',
      apiKey: 'sk-ant-...',
    });
  };

  return (
    <div>
      <p>Active model: {configuration?.modelName}</p>
      <button onClick={handleSave} disabled={isSaving}>
        {isSaving ? 'Saving...' : 'Save'}
      </button>
    </div>
  );
}
```
