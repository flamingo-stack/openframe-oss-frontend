A Next.js page component that renders the API Keys management interface.

## Key Components

- **`ApiKeysPage`** — Default export; a client-side page component that delegates rendering to the `ApiKeysTab` component.

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to the api-keys route.
// No direct instantiation needed — Next.js handles this via file-based routing.
import ApiKeysPage from './page';
```

## Notes

- Marked with `'use client'` directive, enabling client-side interactivity.
- Acts as a thin wrapper around [`ApiKeysTab`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/settings/components/tabs/api-keys.tsx), keeping the page file minimal and delegating all UI logic to the tab component.
