Defines TypeScript interfaces for tenant (MSP Organization) profile data, mirroring the `TenantInfo` GraphQL type and its associated mutation input.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TenantImage` | `interface` | Holds an organization's image URL and hash for cache-busting |
| `TenantInfo` | `interface` | Full tenant profile including id, name, website, and image |
| `UpdateTenantInfoInput` | `interface` | Partial input shape for the `updateTenantInfo` mutation; only non-null fields are applied by the backend |

## Usage Example

```typescript
import type { TenantInfo, UpdateTenantInfoInput } from './tenant-info';

const tenant: TenantInfo = {
  id: 'org_123',
  name: 'Acme IT Services',
  website: 'https://acme-it.com',
  image: {
    imageUrl: 'https://cdn.example.com/logo.png',
    hash: 'abc123',
  },
};

const updateInput: UpdateTenantInfoInput = {
  name: 'Acme Managed Services',
};
```

## Notes

- All fields except `TenantInfo.id` are optional/nullable to accommodate partial data from GraphQL responses.
- `UpdateTenantInfoInput` intentionally omits `id` and `image` — identity is inferred server-side, and image updates use a separate upload flow.
