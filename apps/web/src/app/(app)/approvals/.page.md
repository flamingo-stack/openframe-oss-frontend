Next.js page component that renders the Approvals screen, but only in SaaS tenant mode. In OSS tenant mode, approval requests don't exist conceptually (they're replaced by the Notifications feature), so this page automatically redirects users away.

## Key Components

- **`ApprovalsPage`** (default export) — Client component that:
  - Determines the current deployment mode via `isSaasTenantMode()`
  - Uses `useAppModeRedirect` to redirect to `routes.notifications()` when running in OSS mode
  - Renders `ApprovalsView` only when in SaaS mode; otherwise renders `null` to avoid a flash of content before redirect

## Usage Example

This file is a Next.js route entry point and is not imported directly elsewhere. It is automatically invoked by the Next.js router for its corresponding route path.

```typescript
// Conceptual behavior when the route is visited:

// SaaS tenant mode:
// -> isSaasTenantMode() returns true
// -> useAppModeRedirect(null) does nothing
// -> ApprovalsView is rendered

// OSS tenant mode:
// -> isSaasTenantMode() returns false
// -> useAppModeRedirect(routes.notifications()) triggers a redirect
// -> Page renders null while the redirect occurs
```

**Related modules:**
- `@/app/hooks/use-app-mode-redirect` — shared redirect hook for mode-gated pages
- `@/lib/app-mode` — exposes `isSaasTenantMode()` to distinguish SaaS vs. OSS deployments
- `@/lib/routes` — centralized route definitions, including `routes.notifications()`
- `./approvals-view` — the actual UI rendered for SaaS tenants
