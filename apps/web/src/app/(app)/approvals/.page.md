This file defines the Next.js page component for the Approvals route, which displays items requiring user approval in SaaS tenant mode only.

## Key Components

- **`ApprovalsPage`** (default export) — Page component that conditionally renders approval content based on the current app mode.
- **`isSaasTenantMode()`** — Utility (imported) that determines whether the app is running in SaaS tenant mode versus OSS mode.
- **`useAppModeRedirect(route)`** — Hook (imported) that redirects to a specified route when the app is not in the expected mode.
- **`ApprovalsView`** — Child component rendered when SaaS mode is active, containing the actual approvals UI.

## Behavior

Since OSS tenants don't have an approval workflow, this page acts as a gate:
- In **SaaS mode**: renders the `ApprovalsView` component showing pending approvals.
- In **OSS mode**: redirects the user to the Notifications page (`routes.notifications()`) instead, since approvals don't apply there.

## Usage Example

```typescript
// This file is automatically routed by Next.js App Router
// based on its location, e.g. app/approvals/page.tsx

// Example of the redirect pattern used elsewhere:
import { useAppModeRedirect } from '@/app/hooks/use-app-mode-redirect';
import { isSaasTenantMode } from '@/lib/app-mode';
import { routes } from '@/lib/routes';

function SaasOnlyPage() {
  const saas = isSaasTenantMode();
  useAppModeRedirect(saas ? null : routes.someOssFallback());

  if (!saas) return null;
  return <div>SaaS-only content</div>;
}
```

- Marked `'use client'` since it relies on client-side hooks for mode detection and redirection.
- Returns `null` while redirecting to avoid flashing SaaS-only content in OSS mode.
