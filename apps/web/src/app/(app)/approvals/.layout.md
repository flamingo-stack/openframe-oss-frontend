Defines page metadata for a Next.js route segment and re-exports a shared layout component, setting the browser tab title specifically for the "Needs approval" section of the application.

## Key Components

- **`metadata`**: A Next.js `Metadata` object that sets the document title using the `routeTitle` helper, producing a consistent, formatted title string (e.g., `"Needs approval"` combined with a site-wide suffix/prefix).
- **Default export**: Re-exports the default export from `@/app/(app)/route-title-layout`, reusing a shared layout component rather than defining a new one. This layout likely renders the page title in the UI alongside setting the `<head>` metadata.

## Usage Example

This file follows the Next.js App Router convention where a `layout.tsx` co-located with a route segment automatically wraps that segment's pages and contributes to metadata resolution.

```typescript
// app/(app)/needs-approval/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Needs approval') };
```

To adapt this pattern for another route, copy this file into the new route segment directory and change the string passed to `routeTitle`:

```typescript
export const metadata: Metadata = { title: routeTitle('Pending review') };
```

No additional logic is needed here since the actual layout rendering is delegated to the shared `route-title-layout` component, keeping per-route files minimal and focused solely on metadata configuration.
