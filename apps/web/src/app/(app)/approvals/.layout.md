Defines Next.js page metadata and re-exports the shared layout component for a route requiring approval status display.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the document title to `"Needs approval"` using the `routeTitle` helper, ensuring consistent title formatting across the app.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, avoiding duplication of layout logic across route segments.

## Usage Example

This file follows the Next.js App Router convention, where a `layout.tsx` file automatically applies to all routes within its directory segment:

```typescript
// Automatically picked up by Next.js for the containing route segment.
// No manual import needed — Next.js resolves `layout.tsx` by convention.

import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = {
  title: routeTitle('Needs approval'),
};
```

The `routeTitle` utility standardizes page titles (e.g., appending a site suffix like `"Needs approval | OpenFrame"`), while the re-exported layout component handles the actual rendering structure (headers, title display, etc.) shared across similarly-titled routes. This pattern keeps per-route files minimal—only metadata differs between routes that share the same layout behavior.
