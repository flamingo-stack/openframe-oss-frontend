## approvals-view.tsx

This file implements the "Needs approval" page (`/approvals`), rendering approval requests that a user can decide on, grouped into two sections: standalone requests Mingo raised and tickets handed to a technician awaiting approval. It handles infinite scroll pagination, loading states, errors, and empty states.

## Key Components

- **`ApprovalsView`** — Top-level page component. Wires together `useApprovalSources` (fetches/paginates approval data) and `useApprovalDecider` (handles approve/reject decisions and local "kept" state), composing them via `composeApprovalInbox` into a deduplicated card list, then renders `ApprovalList` inside a `PageLayout`.
- **`ApprovalList`** — Renders the two approval sections, manages infinite-scroll triggering (`useGridInfiniteScroll`), loading skeletons (`NotificationTile` with `loading`), error states (`SectionLoadError`), and the empty state (`NoData`) when no cards remain and no more pages exist.
- **`ApprovalSection`** — Renders a labeled group of cards (filtered by whether they belong to a ticket or not) with a running count derived from the server total and locally visible pending cards. Renders nothing if the section is empty.

## Usage Example

```typescript
import { ApprovalsView } from './approvals-view';

// Used as the page component for the /approvals route
export default function ApprovalsPage() {
  return <ApprovalsView />;
}
```

Internally, cards are split by `ticketId`:

```typescript
cards.filter(card => card.ticketId === null);   // standalone approval requests
cards.filter(card => card.ticketId !== null);   // ticket-linked requests awaiting a technician
```

Decisions flow through callbacks passed down to `ApprovalRequestCard`:

```typescript
async function onDecide(card: ApprovalCard, approve: boolean) {
  // delegates to useApprovalDecider's decide(), propagating to drawer/chat/board
}
```

Related modules: `approval-inbox.ts` (composition/dedupe logic), `use-approval-decider.ts` (decision handling), `use-approval-sources.ts` (data fetching/pagination).
