# approval-request-card.tsx

Client component rendering a single approval card on the "Needs approval" page, wrapping the shared `ApprovalRequestNotificationTile` with title-link navigation and completion handling.

## Key Components

- **`ApprovalRequestCard`** — Main component that renders an approval tile for a given `ApprovalCard`. It resolves the notification's navigation action, wraps the title in an `EntityTitleLink` when applicable, and wires up `onApprove`/`onReject`/`onComplete` callbacks. The completion checkmark only renders when `card.notificationId` exists, since only true unread notifications can be marked complete.
- **`EntityTitleLink`** — Internal helper component rendering the card title as a real `<Link>` (supporting new-tab/copy-link behavior) to the entity's canonical route. On a plain left-click (no modifier keys), it intercepts navigation and opens the Mingo chat dialog instead via `openMingoDialog`, if the resolved action includes a `mingoDialogId`.
- **`isPlainClick`** — Utility predicate checking that a mouse click is an unmodified left-click, used to distinguish "open in new tab" / "ctrl+click" from a normal navigation click.

## Usage Example

```typescript
import { ApprovalRequestCard } from '@/app/components/approvals/approval-request-card';
import type { ApprovalCard } from '@/app/components/approvals/approval-inbox';

function ApprovalList({ cards }: { cards: ApprovalCard[] }) {
  const handleDecide = async (card: ApprovalCard, approve: boolean) => {
    await submitApprovalDecision(card.id, approve);
  };

  const handleComplete = (card: ApprovalCard) => {
    markNotificationComplete(card.notificationId);
  };

  return (
    <div className="space-y-2">
      {cards.map((card) => (
        <ApprovalRequestCard
          key={card.id}
          card={card}
          onDecide={handleDecide}
          onComplete={handleComplete}
        />
      ))}
    </div>
  );
}
```

This component depends on `resolveNotificationAction` to determine whether a notification links to a ticket (plain navigation) or a Mingo chat (dialog-based navigation), ensuring consistent behavior with other notification tiles across the app.
