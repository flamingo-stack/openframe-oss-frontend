# approval-request-card.tsx

Renders a single approval request on the "Needs approval" page by wrapping the shared `ApprovalRequestNotificationTile` component, adding a title link to the underlying entity (ticket or Mingo chat) and wiring up approve/reject/complete actions.

## Key Components

- **`ApprovalRequestCard`** — Main component that renders an approval tile for a given `ApprovalCard`. It resolves the notification's navigation action, injects a linked title (via `EntityTitleLink`) when applicable, and passes approve/reject/complete callbacks to the underlying tile. The "complete" action is only exposed when the card has a backing `notificationId`.
- **`EntityTitleLink`** — Internal helper component rendering the notification title as a real anchor link to the entity's canonical route. On a plain left-click (no modifier keys) targeting a Mingo chat, it intercepts navigation and opens the Mingo dialog instead of following the link, while still preserving normal browser behaviors (new tab, copy link, etc.) for modified clicks.
- **`isPlainClick`** — Utility predicate determining whether a mouse event represents an unmodified left-click, used to decide whether to intercept link navigation.

## Usage Example

```typescript
import { ApprovalRequestCard } from '@/app/components/approvals/approval-request-card';
import type { ApprovalCard } from '@/app/components/approvals/approval-inbox';

function ApprovalList({ cards }: { cards: ApprovalCard[] }) {
  const handleDecide = async (card: ApprovalCard, approve: boolean) => {
    await submitApprovalDecision(card.id, approve);
  };

  const handleComplete = (card: ApprovalCard) => {
    markNotificationComplete(card.notificationId);
  };

  return (
    <>
      {cards.map((card) => (
        <ApprovalRequestCard
          key={card.id}
          card={card}
          onDecide={handleDecide}
          onComplete={handleComplete}
        />
      ))}
    </>
  );
}
```

This component relies on `resolveNotificationAction` to determine whether a notification links to a standard route or should open the Mingo dialog, keeping navigation behavior consistent with other notification tiles across the app.
