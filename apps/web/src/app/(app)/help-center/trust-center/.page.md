## Overview

A Next.js client route that renders the Trust Center page using the pre-built `TrustCenterPage` component from the shared `@flamingo-stack/openframe-frontend-core` library. It displays monitoring status, documents, subprocessors, and AI statements sourced from the hub's public Vanta Trust Center projection via the `/content` proxy.

## Key Components

- **`TrustCenterRoute`** — Default export; a thin wrapper component that mounts `<TrustCenterPage>` with route-specific configuration (no local state or logic).

### Configuration Passed to `TrustCenterPage`
- **`shell={false}`** — Disables the library's own page shell since `AppLayout` already supplies the `<main>` chrome.
- **`endpoint={EP.trustCenter}`** — Endpoint config pointing to the Trust Center data source.
- **`backButton`** — Navigation back to the Help Center, using `HELP_CENTER_BASE` as the target `href`.

Gated-document requests (e.g., downloading restricted files) are handled internally by the library's `ContactForm`, which resolves `HELP_CENTER_ENDPOINTS.contactUrl` from the Help Center subtree's `EndpointsRuntime`.

## Usage Example

This file is a route entry point (e.g., `app/trust-center/page.tsx`) and is rendered automatically by Next.js routing — it isn't imported directly elsewhere. To adapt the pattern for a similar help-center page:

```typescript
'use client';

import { TrustCenterPage } from '@flamingo-stack/openframe-frontend-core/components/help-center-pages';
import { EP, HELP_CENTER_BASE } from '../endpoints';

export default function TrustCenterRoute() {
  return (
    <TrustCenterPage
      shell={false}
      endpoint={EP.trustCenter}
      backButton={{ label: 'Back to Help Center', href: HELP_CENTER_BASE }}
    />
  );
}
```
