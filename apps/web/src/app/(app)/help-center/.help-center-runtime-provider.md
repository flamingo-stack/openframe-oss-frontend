## help-center-runtime-provider.tsx

A client-side React provider that overrides the app-wide `ChatRuntime` for the `/help-center` route subtree, enabling in-app soft-navigation for Help Center content surfaces (onboarding guides and product-release details) while preserving all other parent runtime config (chat endpoints, auth, image proxy).

## Key Components

- **`HelpCenterRuntimeProvider`** — Component that wraps `children` with two context providers:
  - `EndpointsRuntimeContext.Provider` — supplies `CONTENT_ENDPOINTS` (a stable constant), required by the authed ticket-creation `<ContactForm>` which calls `useRequiredEndpointsRuntime()` unconditionally.
  - `ChatRuntimeContext.Provider` — supplies a derived `runtime` object that:
    - Spreads the parent `ChatRuntime` (from `useContext(ChatRuntimeContext)`) to preserve chat endpoints, auth source, and image proxy config.
    - Spreads `parent.navigation` and sets `mode: 'host'`, preserving the parent's `navigate` / `decideNewTab` / `openExternal` callbacks instead of silently dropping them.
    - Overrides `composeContentUrl` with `composeOpenframeInAppContentUrl`, producing relative `/help-center/...` hrefs for hosted content types, `?search=<id>` deep links for roadmap/delivery items, and falling back to the external Flamingo content hub otherwise.

## Usage Example

```typescript
// app/help-center/layout.tsx
import { HelpCenterRuntimeProvider } from './help-center-runtime-provider';

export default function HelpCenterLayout({ children }: { children: React.ReactNode }) {
  return (
    <section className="help-center-shell">
      <HelpCenterRuntimeProvider>{children}</HelpCenterRuntimeProvider>
    </section>
  );
}
```

This ensures any chat widget, RAG search dropdown, or `<ContactForm>` rendered within `/help-center` pages resolves content links consistently — the same guide links to the same in-app route whether surfaced via a Help Center page or the chat assistant.

**Note:** This provider must be mounted above any component using `useRequiredEndpointsRuntime()` or `ChatRuntimeContext`, typically in a route-level `layout.tsx`.
