Renders the Support Tickets page within the Help Center section, delegating all layout and data-fetching logic to the shared `HelpCenterList` component.

## Key Components

| Export | Type | Description |
|---|---|---|
| `TicketsPage` | Default export (React component) | Page component that mounts `HelpCenterList` with ticket-specific props |

## Usage Example

```typescript
// Automatically rendered by Next.js at the tickets route.
// No direct instantiation needed — configured via props:

<HelpCenterList
  title="Support Tickets"
  shell={false}
  backButton={{ label: 'Back to Help Center', href: HELP_CENTER_BASE }}
/>
```

## Configuration Details

- **`shell={false}`** — Suppresses `HelpCenterList`'s own `PageShell`/`PageLayout` chrome, deferring to the parent app shell.
- **`backButton`** — Overrides the component's default back-link (`/`) to point at `HELP_CENTER_BASE` (the Help Center hub route defined in `endpoints.ts`).
- **API rewrites** — Internal hooks inside `HelpCenterList` call bare `/api/chat/agent/{find-ticket,ticket-action,list-engagements}` paths; `next.config.mjs` rewrites these to the gateway's `/content/api/chat/agent/*` namespace via `embedAuthedFetch`.

## Notes

- Customer identity is resolved automatically through the `ChatRuntime` context — no explicit customer ID prop is required.
- This is a `'use client'` component, so it participates in React's client-side rendering tree.
