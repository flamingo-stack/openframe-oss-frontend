Mounts the FAQ page for the Help Center by rendering the shared `<FaqDocumentPage>` component with route-specific configuration.

## Key Components

### `FaqsRoute` (default export)
A Next.js route component that renders the `FaqDocumentPage` from `@flamingo-stack/openframe-frontend-core`. It delegates all data fetching and layout to the library component, supplying only the page-level copy and navigation config.

**Props passed to `FaqDocumentPage`:**

| Prop | Value | Purpose |
|---|---|---|
| `shell` | `false` | Skips wrapping `<main>` — `AppLayout` already provides it |
| `subtitle` | `"Answers to the most common questions..."` | Displayed under the `h1` title |
| `apiBaseUrl` | `CONTENT_API_BASE` | Routes `/api/faqs` fetches through the `/content` proxy |
| `backButton` | `{ label, href }` | Back navigation to the Help Center index |

## Usage Example

```typescript
// This file is a Next.js page route — no manual import needed.
// Accessible at the path defined by its directory, e.g. /help-center/faqs

// To reuse the same component elsewhere:
import { FaqDocumentPage } from '@flamingo-stack/openframe-frontend-core/components/help-center-pages';
import { CONTENT_API_BASE, HELP_CENTER_BASE } from '../endpoints';

<FaqDocumentPage
  shell={false}
  subtitle="Answers to the most common questions about OpenFrame."
  apiBaseUrl={CONTENT_API_BASE}
  backButton={{ label: 'Back to Help Center', href: HELP_CENTER_BASE }}
/>
```

## Notes

- `CONTENT_API_BASE` and `HELP_CENTER_BASE` are sourced from the shared `endpoints` module — update routes there, not here.
- The component is marked `'use client'` as required by `FaqDocumentPage`.
