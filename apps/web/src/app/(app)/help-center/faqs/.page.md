# page.tsx (FAQs Route)

This Next.js page component renders the OpenFrame Help Center's FAQ page by mounting the shared `FaqDocumentPage` component from the `@flamingo-stack/openframe-frontend-core` library, with route-specific copy and navigation configured.

## Key Components

- **`FaqsRoute`** (default export) — A client-side route component (`'use client'`) that serves as a thin wrapper around the library-provided `FaqDocumentPage`.
- **`FaqDocumentPage`** (imported) — Handles all FAQ rendering logic, including self-fetching content from `CONTENT_ENDPOINTS.faqsUrl` and rendering within the unified `PageLayout` header (with `titleSize="h1"` matching other Help Center pages).
- **`HELP_CENTER_BASE`** (imported) — Shared endpoint constant used to construct the "back" navigation target.

## Usage Example

This file is a Next.js App Router page and is rendered automatically based on its file path (e.g., `app/help-center/faqs/page.tsx`). No manual invocation is required.

```typescript
// Consumers simply navigate to the route; Next.js handles mounting.
// e.g., visiting /help-center/faqs renders FaqsRoute automatically.

export default function FaqsRoute() {
  return (
    <FaqDocumentPage
      shell={false}
      subtitle="Answers to the most common questions about OpenFrame."
      backButton={{ label: 'Back to Help Center', href: HELP_CENTER_BASE }}
    />
  );
}
```

**Key configuration notes:**
- `shell={false}` disables the library's internal page shell since `AppLayout` (at a higher level in the app) already provides the `<main>` wrapper.
- `subtitle` supplies page-specific descriptive copy.
- `backButton` configures a labeled link back to the Help Center root, using the shared `HELP_CENTER_BASE` constant for consistency across routes.
