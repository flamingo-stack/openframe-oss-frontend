This file defines the Next.js route component for the FAQ page within the Help Center section, rendering a pre-built FAQ document component with page-specific configuration.

## Key Components

- **`FaqsRoute`** — Default-exported React component (client component) that serves as the Next.js page for the FAQ route.
- **`FaqDocumentPage`** — Imported from `@flamingo-stack/openframe-frontend-core`, a ready-made component that handles fetching and rendering FAQ content, including the page header (title/subtitle) via the shared `PageLayout`.
- **`HELP_CENTER_BASE`** — Imported constant providing the URL for the "back" navigation target to the Help Center index.

## Usage Example

This file is a Next.js page component and is not typically imported directly; it is resolved automatically by the Next.js file-based router. Its behavior is defined entirely through configuration passed to `FaqDocumentPage`:

```typescript
export default function FaqsRoute() {
  return (
    <FaqDocumentPage
      shell={false}
      subtitle="Answers to the most common questions about OpenFrame."
      backButton={{ label: 'Back to Help Center', href: HELP_CENTER_BASE }}
    />
  );
}
```

Key configuration details:
- `shell={false}` disables the component's own page wrapper since `AppLayout` (a parent layout) already renders the `<main>` element.
- `subtitle` supplies the descriptive text shown under the page title.
- `backButton` configures the navigation link back to the main Help Center page, using the shared `HELP_CENTER_BASE` endpoint constant.
- Title size (`h1`) and FAQ content fetching (via `CONTENT_ENDPOINTS.faqsUrl`) are handled internally by `FaqDocumentPage`.
