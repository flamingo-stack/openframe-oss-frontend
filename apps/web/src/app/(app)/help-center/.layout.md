Root layout for the `/help-center` route subtree, applying scoped CSS variable overrides for `PageShell` padding and wrapping all child routes in the `HelpCenterRuntimeProvider` client boundary.

## Key Components

- **`PAGE_SHELL_OVERRIDE`** — A `CSSProperties` object that sets `--page-shell-*` CSS custom properties on the layout wrapper, scoping flat horizontal and bottom-only vertical padding to the entire help center subtree without affecting the rest of the application.
- **`HelpCenterLayout`** — Default-exported React Server Component that wraps every `/help-center/*` route in both the CSS var scope and the `HelpCenterRuntimeProvider`.

## Usage Example

This layout is automatically applied by Next.js to all routes under `/help-center/`. No manual usage is required; child pages inherit the padding overrides and runtime context automatically.

```typescript
// Automatically wraps pages like:
// /help-center/faqs
// /help-center/tickets
// /help-center/release/:id

export default function HelpCenterLayout({ children }: { children: ReactNode }) {
  return (
    <div style={PAGE_SHELL_OVERRIDE}>
      <HelpCenterRuntimeProvider>{children}</HelpCenterRuntimeProvider>
    </div>
  );
}
```

The `PAGE_SHELL_OVERRIDE` effectively mirrors `px-[var(--spacing-system-l)] pb-[var(--spacing-system-l)]` with no responsive bump — the `*-md` variants intentionally match the base values.

## Notes

- **Server Component** — this layout has no client-side logic; only `HelpCenterRuntimeProvider` introduces a client boundary.
- CSS var scoping ensures `PageShell` padding changes are isolated to `/help-center` and do not affect other sections of the application.
