# layout.tsx

Next.js server layout component that wraps all `/help-center/*` routes with a section-specific metadata title and a nested chat runtime provider for in-app help navigation.

## Key Components

- **`metadata`** — Exports page metadata for the Help Center section, setting the document title via `routeTitle('Help Center')`.
- **`HelpCenterLayout`** — Default export; a React server component that renders its `children` wrapped in `PAGE_SHELL_OVERRIDE` styling and the `HelpCenterRuntimeProvider`.

## Usage Example

This file is automatically picked up by the Next.js App Router for any route under `app/help-center/`. No manual import is required:

```typescript
// app/help-center/faq/page.tsx
export default function FaqPage() {
  return <div>FAQ content rendered inside HelpCenterLayout</div>;
}
```

The layout ensures:
- All nested pages (`DevSectionPage`, `Legal`, `ReleaseDetail`, `FAQs`, `tickets`) inherit consistent `PageShell` host padding via CSS variables set in `PAGE_SHELL_OVERRIDE`, without needing per-page props.
- `HelpCenterRuntimeProvider` establishes a scoped `ChatRuntime` override enabling host-mode navigation and in-app content links specific to the Help Center section.
- Only the provider mounts as a client component; the layout itself remains a server component for optimal performance.

See also: `../route-title-layout.tsx` for the shared title-setting pattern used across other sections.
