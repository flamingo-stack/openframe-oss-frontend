# Help Center Layout

Next.js server layout component that wraps all `/help-center/*` routes, providing section-wide metadata and a nested chat runtime context for host-mode navigation.

## Key Components

- **`metadata`** — Static `Metadata` export setting the document title to "Help Center" via `routeTitle()`, applied to every route under this segment.
- **`HelpCenterLayout`** — Default-exported server component that wraps `children` in:
  - A `div` styled with `PAGE_SHELL_OVERRIDE`, which sets CSS variables controlling the shared `PageShell`'s host padding. This scoping means every page under `/help-center/*` (e.g., `DevSectionPage`, Legal, ReleaseDetail, FAQs, tickets) inherits the override automatically, with no per-page prop needed.
  - `HelpCenterRuntimeProvider`, which supplies the section's nested `ChatRuntime` override (host-mode navigation and in-app content hrefs). This is the only client boundary introduced by the layout — the layout itself remains a server component.

## Usage Example

This file is consumed automatically by the Next.js App Router; it is not imported directly by other code:

```typescript
// app/help-center/layout.tsx
// Automatically applied to all routes matching /help-center/*,
// e.g. /help-center/faqs, /help-center/tickets, /help-center/releases/[id]

export default function HelpCenterLayout({ children }: { children: ReactNode }) {
  return (
    <div style={PAGE_SHELL_OVERRIDE}>
      <HelpCenterRuntimeProvider>{children}</HelpCenterRuntimeProvider>
    </div>
  );
}
```

Any nested page component (server or client) placed under `app/help-center/` will automatically receive the title metadata, padding override, and chat runtime context from this layout without additional configuration.
