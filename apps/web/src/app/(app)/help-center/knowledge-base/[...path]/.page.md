Catch-all route handler for individual Knowledge Base doc deep-links under `/help-center/knowledge-base/<path>`.

## Key Components

- **`generateStaticParams`** — Satisfies Next.js `output: 'export'` requirements by pre-rendering a single `index` placeholder shell. Real doc paths are resolved at runtime via the native shell's SPA fallback.
- **`KnowledgeBaseDocPage`** — Async page component that receives catch-all route segments, normalizes them via `normalizeDocPath` (lowercases + joins segments), and passes the resolved path to `KnowledgeBaseDocsView` so hard loads and shared links land on the correct doc.

## Usage Example

```typescript
// Route: /help-center/knowledge-base/getting-started/installation
// params.path = ['getting-started', 'installation']

// normalizeDocPath(['getting-started', 'installation'])
// => 'getting-started/installation'

// Renders:
<KnowledgeBaseDocsView docPath="getting-started/installation" />
```

## Notes

- Doc paths are runtime/CMS content, not statically enumerable at build time. See [`docs/static-export-migration.md`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/docs/static-export-migration.md) for the rationale behind the placeholder shell approach.
- Path normalization ensures consistent resolution against the doc tree — the same single source of truth used by the Knowledge Base hub.
