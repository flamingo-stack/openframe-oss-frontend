# knowledge-base-docs-view.tsx

Client component that renders OpenFrame's in-app Knowledge Base documentation hub, acting as the host-side integration for the shared `DocsHubPage` library component. It wires up doc-source endpoints, supplies the required markdown renderer, and configures in-app routing so documentation navigation stays within the app instead of redirecting to the hub origin.

## Key Components

- **`markdownRenderer`** — The sole `DocumentTypeRenderers['markdown']` implementation required by `DocsHubPage`. Delegates rendering to `RichMarkdownRenderer`, converts raw `.mmd` Mermaid files into fenced ` ```mermaid ` blocks, and explicitly sets `resolveLinkEndpointUrl` to the app's `/content` proxy (since the renderer owns its own `onResolveLink` and otherwise falls back to a non-existent local `/api/docs/resolve-link` path).
- **`KnowledgeBaseDocsView({ docPath })`** — Exported component rendering `DocsHubPage` configured with:
  - `sourceId: 'openframe-docs'` (`KB_SOURCE_ID`) — must match the hub's `DOC_SOURCES` id
  - `chatSource: 'openframe'` — trusted platform id for resolve-link/search
  - Proxied endpoints (`structureEndpoint`, `contentEndpoint`, `resolveLinkEndpoint`, `searchEndpoint`) built via `EP`
  - `baseRoute: KNOWLEDGE_BASE_ROUTE` for soft-nav sidebar/internal links
  - A back button linking to `HELP_CENTER_BASE`

## Usage Example

```typescript
// app/help-center/knowledge-base/[[...path]]/page.tsx
import { KnowledgeBaseDocsView } from '@/components/knowledge-base-docs-view';

export default function Page({ params }: { params: { path?: string[] } }) {
  const docPath = params.path?.join('/') ?? '';
  return <KnowledgeBaseDocsView docPath={docPath} />;
}
```

**Notes for maintainers:**
- `KB_SOURCE_ID` must stay in sync with the hub's registered `DOC_SOURCES` id — mismatches break content fetching.
- Do not omit `resolveLinkEndpointUrl` on `RichMarkdownRenderer`; it is independent from `DocsHubPage`'s `resolveLinkEndpoint` prop and must point at the same `/content` proxy used by other doc endpoints to avoid gateway 500s on relative in-doc links.
