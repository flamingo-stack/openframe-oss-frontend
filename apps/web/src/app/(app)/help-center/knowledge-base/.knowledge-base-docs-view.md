## Overview

A client-side React component that renders OpenFrame's in-app Knowledge Base documentation hub. It wires the shared `DocsHubPage` library component (which supplies all chrome, sidebar tree, scroll-spy, and search) to host-specific concerns: content API endpoints, a markdown renderer, and in-app routing.

## Key Components

- **`KB_SOURCE_ID`** — Constant identifying the knowledge-base doc source (`'openframe-docs'`), must match the hub's `DOC_SOURCES` id.
- **`markdownRenderer`** — A `DocumentTypeRenderers['markdown']` implementation that feeds doc content into `RichMarkdownRenderer`. It auto-wraps raw `.mmd` Mermaid files in a ```` ```mermaid ```` fence so they render as diagrams, and explicitly sets `resolveLinkEndpointUrl` to the `/content` proxy endpoint (since the renderer owns its own link-resolution logic independent of `DocsHubPage`'s `resolveLinkEndpoint` prop).
- **`KnowledgeBaseDocsView`** — The exported page component. Accepts a `docPath` prop and renders `DocsHubPage`, supplying:
  - Four `/content`-proxied endpoints (structure, content, resolve-link, search)
  - The custom `markdownRenderer`
  - `baseRoute` for in-app soft-navigation under `/help-center/knowledge-base/*`
  - A back button linking to the Help Center

## Usage Example

```typescript
import { KnowledgeBaseDocsView } from './knowledge-base-docs-view';

// In a Next.js dynamic route, e.g. app/help-center/knowledge-base/[[...path]]/page.tsx
export default function Page({ params }: { params: { path?: string[] } }) {
  const docPath = params.path?.join('/') ?? '';
  return <KnowledgeBaseDocsView docPath={docPath} />;
}
```

## Notes

- Requires `EP.docsStructure`, `EP.docsContent`, `EP.docsResolveLink`, `EP.docsSearch`, `HELP_CENTER_BASE`, and `KNOWLEDGE_BASE_ROUTE` to be defined in the sibling `../endpoints` module.
- The `resolveLinkEndpointUrl` override on `RichMarkdownRenderer` is intentional and not redundant with `DocsHubPage`'s `resolveLinkEndpoint` — see inline comments for the distinction between engine-level and renderer-level link resolution.
