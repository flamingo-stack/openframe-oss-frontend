# release-detail-client.tsx

Client-side component that composes the shared `ReleaseDetailPage` from `@flamingo-stack/openframe-frontend-core` with app-specific section renderers for roadmap items, delivery tracking (bug fixes/enhancements), and video playback. It wires these sections to this app's API endpoints while delegating the core rendering logic to the shared library.

## Key Components

- **`RoadmapSection`** — Renders `RoadmapGrid` with app-specific roadmap endpoints (`EP.roadmapById`, `EP.roadmapVote`) so linked roadmap items can be voted on and refreshed consistently with the standalone roadmap page.
- **`VideoDisplaySection`** — Wraps `EntityVideoSection` to render a single video player with "Full Video / Highlights" tabs, instead of the library's default of multiple separate players.
- **`DeliverySection`** — Renders completed and in-progress `DeliveryTable` instances from delivery data. Uses `useLoadingScope()` to detect page-level loading state and shows a skeleton table accordingly. Required because `ReleaseDetailPage` only renders this section if the prop is supplied.
- **`ReleaseDetailClient`** — Main exported component; configures `ReleaseDetailPage` with `slug`, API endpoints, and the three section renderers above, plus a back-navigation button to the releases list.

## Usage Example

```typescript
import { ReleaseDetailClient } from './release-detail-client';

export default function Page({ params }: { params: { slug: string } }) {
  return <ReleaseDetailClient slug={params.slug} />;
}
```

This is typically used as the client boundary for a release detail route (e.g. `/help-center/releases/[slug]`), where `slug` identifies the specific release to fetch and display via `EP.productReleases`.
