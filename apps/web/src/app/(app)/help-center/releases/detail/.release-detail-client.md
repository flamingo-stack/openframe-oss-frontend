Client-side component that renders a single release detail page by composing the shared `ReleaseDetailPage` component from `@flamingo-stack/openframe-frontend-core` with app-specific injected sections for roadmap items, video playback, and delivery (bug-fixes/enhancements) data.

## Key Components

- **`RoadmapSection`** — Wraps `RoadmapGrid` so roadmap items linked to a release vote/refresh through the same `/content` API endpoints used by the standalone roadmap page.
- **`VideoDisplaySection`** — Wraps `EntityVideoSection` to render a single video player with "Full Video" / "Highlights" tabs, instead of the library's default of multiple separate players.
- **`DeliverySection`** — Renders completed and in-progress delivery tables (bug fixes/enhancements) fetched via `deliveryApiEndpoint`. Uses `useLoadingScope()` to detect when the page is still drawing itself and shows a skeleton table accordingly. Returns `null` if no data is available, and only renders tables for non-empty item lists.
- **`ReleaseDetailClient`** — The main exported component. Accepts a `slug` prop identifying the release and assembles `ReleaseDetailPage` with the injected sections, API endpoints, and a "Back to releases" navigation link.

## Usage Example

```typescript
import { ReleaseDetailClient } from './release-detail-client';

export default function Page({ params }: { params: { slug: string } }) {
  return <ReleaseDetailClient slug={params.slug} />;
}
```

This component is intended to be used within a Next.js route handler for a dynamic release detail page (e.g. `/releases/[slug]`), where `slug` identifies the specific release to display. It relies on API endpoints defined in `EP` (from `../../endpoints`) for fetching release, roadmap, and delivery data.
