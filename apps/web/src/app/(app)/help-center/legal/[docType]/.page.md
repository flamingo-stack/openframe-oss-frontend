# page.tsx

Server-side entry point for statically generated legal document pages (e.g., Terms of Service, Privacy Policy). This Next.js page component defines the set of routes to prerender at build time and delegates rendering to a client component.

## Key Components

- **`generateStaticParams`** - A server-only Next.js function that enumerates all legal document types from `LEGAL_DOCUMENT_TYPES` (imported from `@flamingo-stack/openframe-frontend-core/utils`) and returns them as route params. This enables `output: 'export'` to prerender a static page for each document type at build time.
- **`LegalPage`** (default export) - The page component itself. It contains no rendering logic of its own; it simply renders `LegalPageClient`, which handles the actual UI and client-side behavior for displaying the selected legal document.

## Usage Example

This file is a Next.js App Router page and is not imported directly elsewhere in the codebase. It is picked up automatically based on its file path (e.g., `app/legal/[docType]/page.tsx`), and Next.js calls `generateStaticParams` during the build to produce one static route per entry in `LEGAL_DOCUMENT_TYPES`:

```typescript
// Conceptually, Next.js generates routes like:
// /legal/terms-of-service
// /legal/privacy-policy
// ...one per entry in LEGAL_DOCUMENT_TYPES

export function generateStaticParams() {
  return LEGAL_DOCUMENT_TYPES.map(docType => ({ docType }));
}

export default function LegalPage() {
  return <LegalPageClient />;
}
```

The companion client component, `LegalPageClient`, is responsible for reading the resolved `docType` route param and rendering the appropriate legal content.
