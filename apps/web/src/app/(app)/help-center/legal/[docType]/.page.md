Server component entry point for legal pages that enables static prerendering of both "privacy" and "terms" documents via `generateStaticParams`.

## Key Components

- **`generateStaticParams`** — Exports static route params for two legal document types (`privacy`, `terms`), enabling Next.js static site generation (`output: 'export'`) to prerender both routes at build time.
- **`LegalPage`** — Default export server component that delegates all rendering to `LegalPageClient`.

## Usage Example

```typescript
// Routes prerendered at build time:
// /legal/privacy
// /legal/terms

// generateStaticParams returns the enumerable docType values:
export function generateStaticParams() {
  return [{ docType: 'privacy' }, { docType: 'terms' }];
}
```

## Notes

- The split between this server component and [`LegalPageClient`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/legal/[docType]/legal-page-client.tsx) follows the Next.js pattern of keeping `generateStaticParams` server-side while the interactive/rendering logic lives in a client component.
- Adding a new legal document only requires appending a new `docType` entry to the array returned by `generateStaticParams`.
