This file implements the Next.js dynamic route page for rendering legal documents (e.g., privacy policy, terms of service), statically generating one page per document type at build time.

## Key Components

- **`generateStaticParams`** — A server-only Next.js function that returns an array of route params (one per `docType`) based on `LEGAL_DOCUMENT_TYPES` imported from `@flamingo-stack/openframe-frontend-core/utils`. This enables static export (`output: 'export'`) to prerender every legal document page at build time.
- **`LegalPage`** (default export) — The server component for this route. It delegates all rendering logic to `LegalPageClient`, keeping this file purely responsible for static param generation.
- **`LegalPageClient`** — Imported from `./legal-page-client`; contains the actual client-side rendering logic for displaying the legal document content.

## Usage Example

This file is a Next.js App Router page and is not invoked directly—it's wired up automatically based on the file's location in the `app/` directory (typically something like `app/legal/[docType]/page.tsx`).

```typescript
// Next.js automatically calls generateStaticParams at build time
// to determine which [docType] routes to prerender, e.g.:
// /legal/privacy-policy
// /legal/terms-of-service

// The resulting params are passed through the route, and
// LegalPageClient handles fetching/rendering the specific
// document content on the client side.
```

To add a new legal document type, update `LEGAL_DOCUMENT_TYPES` in the shared core utils package — this page will automatically generate a static route for it without further changes.
