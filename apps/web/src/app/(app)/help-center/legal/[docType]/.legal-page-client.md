Client component that renders the correct legal document page (Privacy Policy or Terms of Service) based on the current route parameter, supplying document-specific copy strings to the shared `LegalDocumentPage` component.

## Key Components

### `COPY`
A static record keyed by `docType` (`"privacy"` | `"terms"`) that provides per-document UI strings:
- `title` — Page heading
- `fallbackDescription` — Shown when no API description is available
- `contactEmail` — Relevant contact address
- `errorContactPrompt` / `errorTitle` — Error state messaging
- `emptyStateMessage` — Empty state fallback text

### `LegalPageClient`
The exported client component. Reads the `docType` route param via `useParams`, looks up the matching copy (falling back to `"privacy"`), and delegates rendering to `LegalDocumentPage` from `@flamingo-stack/openframe-frontend-core`.

Key props forwarded to `LegalDocumentPage`:
| Prop | Value |
|---|---|
| `shell` | `false` (host app provides layout) |
| `docType` | From route params |
| `apiEndpoint` | `EP.legal(docType)` |
| `backButton` | Links back to the Help Center |
| `...copy` | Spread of the matched copy strings |

## Usage Example

```typescript
// app/legal/[docType]/page.tsx
import { LegalPageClient } from './legal-page-client';

export default function LegalPage() {
  // Route: /legal/privacy  → renders Privacy Policy
  // Route: /legal/terms    → renders Terms of Service
  return <LegalPageClient />;
}
```
