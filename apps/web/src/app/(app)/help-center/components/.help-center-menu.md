Renders the Help Center index as a two-column grid of navigation cards: the static help sections, then one card per legal document on the hub's list (the one read).

## Key Components

### `HelpCenterMenu`
The sole export. A client component that maps the `ITEMS` array into a responsive `grid-cols-1 md:grid-cols-2` layout using `SettingMenuItem` cards, followed by the legal documents read through `useLegalDocuments` (`EP.legalDocuments`). It switches itself (`useLoadingScope() || isLoading`): while the documents are read, or in a loading scope, it draws one skeleton card per `LEGAL_DOCUMENT_TYPES` entry inside `LoadingWhen`.

### `ITEMS` (internal constant)
An array of `Item` entries, each defining:
- `href` — resolved via the `routes.helpCenter` route helpers
- `title` / `description` — display copy
- `Icon` — an icon component from `@flamingo-stack/openframe-frontend-core/components/icons-v2`

Covered sections: Onboarding Guides, Development Roadmap, Product Releases, Bug-fixes & Enhancements, Support Tickets, FAQs, Trust Center, Knowledge Base. The legal documents (privacy policy, terms and the rest) come from the hub's list, not from `ITEMS`.

## Usage Example

```typescript
// app/help-center/page.tsx
import { HelpCenterMenu } from './components/help-center-menu';

export default function HelpCenterPage() {
  return (
    <main>
      <h1>Help Center</h1>
      <HelpCenterMenu />
    </main>
  );
}
```

> **Note:** The route's loading state renders `HelpCenterMenu` itself in a loading scope: the static cards draw real, the legal document cards draw their skeletons, and nothing shifts when the list lands.
