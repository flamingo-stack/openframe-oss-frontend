# help-center-menu.tsx

Renders the Help Center index grid, combining a static set of app-owned navigation cards (guides, roadmap, releases, FAQs, trust center, etc.) with a dynamic list of legal documents fetched from the hub API.

## Key Components

- **`Item`** — Type describing a static menu entry (`href`, `title`, `description`, `Icon`).
- **`ITEMS`** — Array of static `Item` entries rendered as the first cards in the grid (Onboarding Guides, Roadmap, Releases, Bug-fixes & Enhancements, Support Tickets, FAQs, Trust Center, Knowledge Base).
- **`HelpCenterMenu`** — Default exported component that renders the full grid:
  - Fetches legal documents via `useLegalDocuments({ apiEndpoint: EP.legalDocuments })`.
  - Filters documents to only those matching `isLegalDocumentType` and included in `shownLegalDocumentTypes` (computed from `useIsMobileShell()`).
  - Uses `useLoadingScope()` combined with the fetch's `isLoading` to determine a unified loading state.
  - Renders static `ITEMS` first, then legal document cards last (via `LoadingWhen`), showing skeleton placeholders (one per expected document type) while loading so the grid doesn't resize once data arrives.
  - Each entry is rendered using `SettingMenuItem` with an icon, title, description, and link.

## Usage Example

```typescript
import { HelpCenterMenu } from './help-center-menu';

export default function HelpCenterPage() {
  return (
    <div className="help-center-page">
      <h1>Help Center</h1>
      <HelpCenterMenu />
    </div>
  );
}
```

This component is self-contained—it manages its own data fetching and loading states, so it can be dropped into any page that needs to display the Help Center navigation grid.
