# help-center-menu.tsx

Renders the Help Center index grid, combining a static set of app-owned navigation cards (guides, roadmap, releases, support, FAQs, trust center, knowledge base) with a dynamic list of legal document cards fetched from the legal documents hub.

## Key Components

- **`Item`** — Type describing a static menu entry (`href`, `title`, `description`, `Icon`).
- **`ITEMS`** — Static array of `Item` entries rendered first in the grid; covers onboarding guides, roadmap, releases, bug-fixes/enhancements, support tickets, FAQs, trust center, and knowledge base links.
- **`HelpCenterMenu()`** — Default export component. Responsibilities:
  - Fetches legal documents via `useLegalDocuments({ apiEndpoint: EP.legalDocuments })`.
  - Determines loading state by combining `useLoadingScope()` (route-level prerender/loading) with the hook's own `isLoading`.
  - Computes `shownTypes` via `shownLegalDocumentTypes(useIsMobileShell())` to decide which legal document types this build should display.
  - Filters fetched `documents` down to valid, shown legal document types using `isLegalDocumentType`.
  - Renders one `SettingMenuItem` per static item, followed by one `SettingMenuItem` per legal document (or per shown type as a skeleton placeholder while loading, via `LoadingWhen`).

## Usage Example

```typescript
// Rendered within a Help Center route/page
import { HelpCenterMenu } from './help-center-menu';

export default function HelpCenterPage() {
  return (
    <section>
      <h1>Help Center</h1>
      <HelpCenterMenu />
    </section>
  );
}
```

**Behavior notes:**
- Legal document cards always render after static cards, so static entries never shift position as documents load or change.
- The grid shows a stable number of skeleton cards (matching `shownTypes.length`) during loading, preventing layout shifts when real data arrives.
- Document visibility (e.g., hiding billing-related docs on mobile shells) is controlled by `shownLegalDocumentTypes` combined with `useIsMobileShell()`.
