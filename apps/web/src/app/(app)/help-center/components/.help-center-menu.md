Renders the Help Center index as a static two-column grid of navigation cards, with no data fetching — each card links to a distinct help section using app routes.

## Key Components

### `HelpCenterMenu`
The sole export. A fully static React client component that maps the `ITEMS` array into a responsive `grid-cols-1 md:grid-cols-2` layout using `SettingMenuItem` cards.

### `ITEMS` (internal constant)
An array of nine `Item` entries, each defining:
- `href` — resolved via the `routes.helpCenter` route helpers
- `title` / `description` — display copy
- `Icon` — an icon component from `@flamingo-stack/openframe-frontend-core/components/icons-v2`

Covered sections: Onboarding Guides, Development Roadmap, Product Releases, Bug-fixes & Enhancements, Support Tickets, FAQs, Privacy Policy, Terms of Service, Knowledge Base.

## Usage Example

```typescript
// app/help-center/page.tsx
import { HelpCenterMenu } from './components/help-center-menu';

export default function HelpCenterPage() {
  return (
    <main>
      <h1>Help Center</h1>
      <HelpCenterMenu />
    </main>
  );
}
```

> **Note:** Because this component is entirely static (no async data), the route's loading state can render `HelpCenterMenu` directly rather than a skeleton — nothing loads and nothing shifts.
