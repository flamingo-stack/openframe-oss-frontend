Defines logic for determining which legal document types should be displayed in the Help Center, filtering out billing-related documents (like Payment Terms) when billing features are hidden, such as in store-distributed phone apps.

## Key Components

- **`shownLegalDocumentTypes(billingHidden: boolean)`** — Returns the list of `LegalDocumentType` values to display. When `billingHidden` is `true`, it excludes the `'payment'` document type from the full `LEGAL_DOCUMENT_TYPES` list; otherwise, it returns the complete list unchanged.

## Usage Example

```typescript
import { shownLegalDocumentTypes } from './legal-documents';
import { isBillingHidden } from '@flamingo-stack/openframe-frontend-core/utils';

// Determine whether billing-related content (e.g., payment terms) should be hidden
const billingHidden = isBillingHidden();

// Get the list of legal document types to render in the Help Center
const visibleDocs = shownLegalDocumentTypes(billingHidden);

visibleDocs.forEach(docType => {
  console.log(`Render card/page for: ${docType}`);
});
```

This function is typically used when building navigation or listing components in the Help Center that enumerate available legal documents (e.g., Terms of Service, Privacy Policy, Payment Terms), ensuring the Payment Terms document is omitted in contexts where billing information isn't applicable, such as app store builds.
