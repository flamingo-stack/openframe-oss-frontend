Defines logic for determining which legal document types should be displayed in the Help Center, filtering out billing-related documents when billing features are hidden (e.g., in phone app store builds).

## Key Components

- **`shownLegalDocumentTypes(billingHidden: boolean)`** — Returns the list of `LegalDocumentType` values to display. When `billingHidden` is `true`, it excludes the `'payment'` document type (Payment Terms covering plans, free trial, and pricing). Otherwise, it returns the full `LEGAL_DOCUMENT_TYPES` list unchanged.

This function is specifically scoped to the Help Center's own card and page rendering. Other surfaces that reference legal document content (such as the Knowledge Base or cross-document links) are considered separate hub content and are not affected by this filter.

## Usage Example

```typescript
import { shownLegalDocumentTypes } from './legal-documents';
import { isBillingHidden } from '@flamingo-stack/openframe-frontend-core/utils';

// Determine which legal documents to render in the Help Center
const billingHidden = isBillingHidden();
const docTypesToShow = shownLegalDocumentTypes(billingHidden);

docTypesToShow.forEach(docType => {
  // Render a card/page for each visible legal document type
  renderLegalDocumentCard(docType);
});
```

## Notes

- Depends on `LEGAL_DOCUMENT_TYPES` and the `LegalDocumentType` type from `@flamingo-stack/openframe-frontend-core/utils`.
- Typically paired with a billing-visibility check (e.g., `isBillingHidden()`) to determine the `billingHidden` argument, such as when building phone app variants where payment/billing information is not applicable.
