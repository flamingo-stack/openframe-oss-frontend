## help-center-content-href.ts

Single source of truth for resolving where an OpenFrame content entity card (release, onboarding guide, roadmap item, ticket, FAQ, etc.) should navigate to — either an in-app `/help-center` route or an absolute link to the external Flamingo content hub.

This module wraps `@flamingo-stack/openframe-frontend-core/utils`'s generic content-URL composer with OpenFrame-specific rules: which content types are hosted in-app (`hostedTypes`), which existing in-app routes certain types deep-link into (`overrides`), and how to rewrite hosted-type hrefs into this app's query-param detail routes (since slugged path segments aren't routable under static export).

It is consumed by three surfaces that must all agree: page entity cards, chat cards/source chips, and the RAG search dropdown — so any change here propagates everywhere.

## Key Components

- **`HOSTED_TYPES`** — Set of content types with their own in-app detail route (`onboarding_guide`, `product_release`, `markdown`).
- **`toDetailRoute(href)`** — Rewrites a hosted type's `/<suffix>/<slug>` path into this app's `?slug=` detail route.
- **`helpCenterTicketHref(id)`** — Builds a deep-link into the Help Center tickets list with a ticket pre-opened.
- **`composeLibContentUrl`** — The underlying lib composer configured with suffixes and `overrides` (roadmap, delivery, tickets, FAQ, trust center).
- **`composeOpenframeContentUrl`** *(exported)* — Base composer: relative hrefs for hosted/override types, hub origin or RAG `externalUrl` otherwise.
- **`isInAppHelpCenterHref(href)`** *(exported)* — Checks whether an href is an in-app `/help-center` route.
- **`toHubOriginHref(href)`** — Forces a relative hub-only href onto the absolute `https://www.flamingo.run` origin.
- **`composeOpenframeInAppContentUrl`** *(exported)* — The composer registered by both `host`-mode runtimes (`HelpCenterRuntimeProvider`, `OpenframeChatRuntimeProvider`); forces non-hosted hrefs absolute and nulls `targetPlatform` so same-tab/new-tab navigation decisions work correctly.

## Usage Example

```typescript
import { composeOpenframeInAppContentUrl, isInAppHelpCenterHref } from './help-center-content-href';

// Resolve where a content card should navigate
const { href, targetPlatform } = composeOpenframeInAppContentUrl({
  contentType: 'product_release',
  id: 'v1-2-0',
  // ...other fields the lib's ComposeContentUrl input expects
});

if (isInAppHelpCenterHref(href)) {
  // same-tab soft navigation, e.g. router.push(href)
} else {
  // external link — open in a new tab
  window.open(href, '_blank');
}
```
