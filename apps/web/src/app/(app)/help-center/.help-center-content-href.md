## help-center-content-href.ts

Single source of truth for resolving where a content entity card (blog, guide, release, ticket, FAQ, roadmap item, etc.) should navigate to within OpenFrame. It decides whether a content type is hosted in-app under `/help-center` (soft-nav, relative URL) or lives externally on the Flamingo content hub (absolute URL, new tab), and is consumed by page entity cards, chat/source cards, and the RAG search dropdown so all three surfaces stay consistent.

## Key Components

- **`HOSTED_TYPES`** — Set of content types with their own in-app detail route (`onboarding_guide`, `product_release`, `markdown`).
- **`DETAIL_ROUTE_BY_LIST_PATH`** — Maps a composed list path to this app's query-param detail-route builder.
- **`toDetailRoute(href)`** — Rewrites `/<suffix>/<slug>` hosted-type paths into this app's actual routable detail URLs (since slugged segments aren't prerenderable under static export).
- **`helpCenterTicketHref(id)`** — Builds a Help Center tickets-list href with a ticket pre-opened via `buildTicketOpenHref`.
- **`composeOpenframeContentUrl`** — Base composer: relative in-app hrefs for hosted types/overrides (roadmap, delivery, tickets, FAQ, trust center), absolute hub URLs for everything else.
- **`isInAppHelpCenterHref(href)`** — Returns `true` if an href targets the in-app `/help-center` subtree.
- **`composeOpenframeInAppContentUrl`** — The composer registered by both `host`-mode runtimes (Help Center pages and the app-wide chat drawer); forces non-hosted hrefs absolute onto the content hub origin and normalizes `targetPlatform` for correct same-tab/new-tab navigation.

## Usage Example

```typescript
import { composeOpenframeInAppContentUrl } from './help-center-content-href';

// Hosted type → relative in-app href, same-tab soft-nav
const guide = composeOpenframeInAppContentUrl({
  type: 'onboarding_guide',
  id: 'getting-started',
});
// => { href: '/help-center/onboarding-guides/detail?slug=getting-started', targetPlatform: null }

// Non-hosted type → absolute content-hub href, opens in new tab
const blogPost = composeOpenframeInAppContentUrl({
  type: 'blog',
  id: 'my-post-slug',
});
// => { href: 'https://www.flamingo.run/blog/my-post-slug', targetPlatform: null }

// Register with a runtime provider
helpCenterRuntimeProvider.registerComposer(composeOpenframeInAppContentUrl);
```
