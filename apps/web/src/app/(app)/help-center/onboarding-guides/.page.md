Thin Next.js route component that mounts the shared `<OnboardingGuidesCatalogPage>` from `openframe-frontend-core` for the onboarding guides catalog view within the Help Center.

## Key Components

| Export | Type | Description |
|---|---|---|
| `OnboardingGuidesCatalogRoute` | `default` React component | Next.js page component rendering the onboarding guides catalog |

## Props Passed to `<OnboardingGuidesCatalogPage>`

| Prop | Value | Description |
|---|---|---|
| `shell` | `false` | Disables the library's built-in chrome (uses the app's own layout) |
| `guidesEndpoint` | `EP.onboarding` | API endpoint for fetching onboarding guide cards |
| `sectionsEndpoint` | `EP.onboardingSections` | API endpoint for section filter pills |
| `basePath` | `{HELP_CENTER_BASE}/onboarding-guides` | Fallback URL prefix for card hrefs |
| `backButton` | `{ label, href }` | "Back to Help Center" navigation link |

## Usage Example

This component is a Next.js page file — it is auto-registered as a route. No direct instantiation is needed.

```typescript
// app/help-center/onboarding-guides/page.tsx
// Automatically resolved by Next.js App Router.
// Card links are resolved via `composeContentUrl` from the
// HelpCenterRuntimeProvider; `basePath` acts as the fallback.

export default function OnboardingGuidesCatalogRoute() {
  return (
    <OnboardingGuidesCatalogPage
      shell={false}
      guidesEndpoint={EP.onboarding}
      sectionsEndpoint={EP.onboardingSections}
      basePath={`${HELP_CENTER_BASE}/onboarding-guides`}
      backButton={{ label: 'Back to Help Center', href: HELP_CENTER_BASE }}
    />
  );
}
```

## Notes

- The catalog includes a built-in RAG search and section pill filters provided by the core library component.
- Card `href` resolution depends on `composeContentUrl` configured in the `HelpCenterRuntimeProvider` higher up the tree; `basePath` is the static fallback.
