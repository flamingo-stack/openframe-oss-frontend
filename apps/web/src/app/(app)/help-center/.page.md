# Help Center Page

Renders the Help Center landing page, combining a call-to-action scheduling block with a grid of help resource links.

This page is intentionally kept local to the app (not extracted into the shared component library) because its links and icons are host-specific. The reusable grid markup lives in `HelpCenterMenu` so the route's loading state can share the same structure, while `BookCallSection` is a shared component also used on the dashboard and `/onboarding` routes.

## Key Components

- **`HelpCenterPage`** (default export) — Client component (`'use client'`) that composes the Help Center route using `PageLayout`.
- **`BookCallSection`** — Shared scheduling block imported from the onboarding feature; fetches its own scheduling link and renders nothing if none is available, so the layout gracefully collapses on hubs without a bookable link.
- **`HelpCenterMenu`** — Local component rendering the grid of help resource links/icons.

## Usage Example

This file is a Next.js route entry point and is rendered automatically by the framework based on its file path:

```typescript
// app/help-center/page.tsx
export default function HelpCenterPage() {
  return (
    <PageLayout title="Help Center" className="px-[var(--spacing-system-l)] pb-[var(--spacing-system-l)]">
      <div className="flex flex-col gap-[var(--spacing-system-m)]">
        <BookCallSection />
        <HelpCenterMenu />
      </div>
    </PageLayout>
  );
}
```

No props are accepted since this is a page-level component resolved by the Next.js router. To modify the available help links, update `HelpCenterMenu` in `./components/help-center-menu` rather than this file.
