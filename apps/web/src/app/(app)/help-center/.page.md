# page.tsx (Help Center)

Next.js page component that renders the Help Center landing route, combining a call-booking prompt with a menu of help resources.

## Key Components

- **`HelpCenterPage`** (default export) — Client component rendering the Help Center page layout, composed of `BookCallSection` and `HelpCenterMenu`.

### Dependencies

- `PageLayout` — shared page shell from `@flamingo-stack/openframe-frontend-core`, providing the page title and padding.
- `BookCallSection` — shared scheduling block (also used on the dashboard and `/onboarding`); fetches its own booking link and renders nothing if none exists.
- `HelpCenterMenu` — local component containing the grid of help links/icons, kept app-specific (not shared via the core lib) since content is host-owned.

## Design Notes

This page intentionally stays local rather than being extracted into the shared frontend-core library, because its links and icons are specific to this host application. The actual menu grid markup lives inside `HelpCenterMenu` so that the route's loading state can reuse the same structure.

## Usage Example

```typescript
// Automatically rendered by Next.js App Router for the /help-center route
// No manual invocation needed — file acts as the route's page component.

import HelpCenterPage from './page';

export default function Example() {
  return <HelpCenterPage />;
}
```

Layout structure produced:

```text
PageLayout (title="Help Center")
└── div (flex column, gap spacing)
    ├── BookCallSection
    └── HelpCenterMenu
```
