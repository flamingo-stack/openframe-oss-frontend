## tenant-presentation.ts

Presentation layer for Cloud Tenant Management, mapping GraphQL schema enums (access states, providers, consent outcomes, issue kinds, rule kinds, license filters) to UI-facing labels, status tags, and copy. Uses `satisfies Record<Enum, …>` so widened enums fail type-checking until a new value is explicitly handled, and `presentationFor` to safely degrade when the runtime value isn't covered by the exhaustive map.

## Key Components

- **`isReadable(state)`** — determines whether an access state means the directory was actually read (`READ_ONLY`, `WRITE_AVAILABLE`, `WRITE_ENABLED`).
- **`isSyncPaused(connection)`** — true when a readable connection has been manually disabled.
- **`syncPausedDescription(by, at)`** — builds the "Paused by … on …" sentence for a paused sync.
- **`accessStateHint(state)`** — actionable copy for a failed connection check, falling back to the tag label for unknown states.
- **`checkResultTag(access)`** — `TenantStatusTag` shown after a "Check Connection" probe.
- **`ConsentAlert`, `ConsentAttempt`, `ConsentIssueReport`** — interfaces describing the consent alert banner and a single reportable consent issue.
- **`consentAlert(attempt, { readable, domain })`** — resolves the alert banner (warning/error) for the last consent attempt, covering `PARTIAL`, `CONNECTED`, and failed Microsoft/Google outcomes.
- **`consentIssueTag(kind, provider)`** — `TenantStatusTag` for a consent issue kind (provider error, pending, not finished).
- **`consentIssueCode(providerCode)`** — normalizes provider error codes, treating `"unknown"` as absent.
- **`providerErrorLookupUrl(code)`** — builds Microsoft's AADSTS error lookup URL when applicable.
- **`consentIssueReport(report)`** — formats a single consent issue as plain text for copy-to-clipboard support tickets.
- **`ListTablesCoverSchema`** — compile-time check tying schema enums to the core library's presentation unions.

## Usage Example

```typescript
import { accessStateHint, checkResultTag, consentAlert, isSyncPaused } from '@/lib/tenant-presentation';

const connection = { enabled: false, access: { state: 'READ_ONLY' } };

if (isSyncPaused(connection)) {
  console.log('Sync is paused');
}

const tag = checkResultTag(connection.access);
// { label: 'Connected and readable', variant: 'success' }

const hint = accessStateHint('DISCONNECTED');
// "OpenFrame can't read this directory yet. Ask the customer's admin to open the consent link, then check again."

const alert = consentAlert(
  { outcome: 'PARTIAL', deniedTiers: ['Mail.Read'], unfinishedTiers: [], hasIssues: false },
  { readable: true, domain: 'contoso.com' },
);
// { variant: 'warning', message: 'Connected with limited access. The admin declined some permissions: Mail.Read. ...' }
```
