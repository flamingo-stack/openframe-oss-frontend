## Overview

Presentation-layer mapping tables for Cloud Tenant Management that translate backend schema enums (`DirectoryAccessState`, `DirectoryProvider`, `DirectoryConsentOutcome`, etc.) into UI-ready labels, tags, and copy. Each mapping is declared with `satisfies Record<Enum, …>` so that when `generate-enums` widens an enum with a new value, this file stops type-checking until the new case is handled — and `presentationFor` provides a safe runtime fallback when an unmapped string reaches the UI from a backend ahead of the frontend's schema.

## Key Components

- **`isReadable(state)`** — Determines whether a directory access state means the connection can actually be read (`READ_ONLY`, `WRITE_AVAILABLE`, `WRITE_ENABLED`).
- **`isSyncPaused(connection)`** — Detects a readable connection that's been manually disabled (paused, not disconnected).
- **`syncPausedDescription(by, at)`** — Formats the "Paused by X on date" sentence for a paused sync.
- **`accessStateHint(state)`** — Returns actionable guidance text for a failed/unreadable access state.
- **`checkResultTag(access)`** — Produces the status tag shown after a "Check Connection" probe.
- **`ConsentAlert` / `ConsentAttempt`** — Types describing the alert banner and the consent attempt data driving it.
- **`consentAlert(attempt, context)`** — Builds the warning/error alert from the last consent attempt outcome (`PARTIAL`, `CONNECTED`, Microsoft/Google failure codes, etc.).
- **`consentIssueTag(kind, provider)`** — Tag for an individual consent issue (provider error, pending, not finished).
- **`consentIssueCode(providerCode)`** — Normalizes a provider error code, filtering out `unknown`.
- **`providerErrorLookupUrl(code)`** — Builds a Microsoft AADSTS error-lookup URL when applicable.
- **`ConsentIssueReport` / `consentIssueReport(report)`** — Formats a single consent issue into plain text for support-ticket copy/paste.
- **`ListTablesCoverSchema`** — Compile-time assertion type linking schema enums to the core library's presentation unions.

## Usage Example

```typescript
import {
  isReadable,
  accessStateHint,
  checkResultTag,
  consentAlert,
} from './tenant-presentation';

const access = { state: 'DISCONNECTED' };

if (!isReadable(access.state)) {
  console.log(accessStateHint(access.state));
  // "OpenFrame can't read this directory yet. Ask the customer's admin..."
}

const tag = checkResultTag(access);
// { label: 'Disconnected', variant: 'error' } (or similar, via accessStateTag)

const alert = consentAlert(lastConsentAttempt, {
  readable: isReadable(access.state),
  domain: 'acme.com',
});
if (alert) {
  console.log(alert.variant, alert.message);
}
```
