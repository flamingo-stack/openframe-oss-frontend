React hook powering the "New" tenant form (per Figma 2097-122192), handling provider/domain/name input and submitting a `createDirectoryConnection` GraphQL mutation that both persists the connection and mints its connect link in a single call.

## Key Components

- **`useNewTenantForm()`** — Main hook that wires up the form, mutation, and submission flow.
  - **`form`** — `react-hook-form` instance validated against `tenantFormSchema` (Zod), initialized with `TENANT_FORM_DEFAULT_VALUES`, validating `onChange` so the Generate button's enabled state stays live.
  - **`isCreating`** — Boolean loading state from the `useMutation` call, useful for disabling the submit button while the request is in flight.
  - **`generateLink()`** — Submission entry point (bound to "Generate Connection Link"). Delegates to `useSubmitWithAttribution` to guard against premature submits, then runs `onValid` on success.
- **`createMutation`** — GraphQL mutation (`useNewTenantFormCreateMutation`) that creates a `DirectoryConnection` and returns its `id` plus fragment data (`tenantFormHelpers_connection`) consumed by the next step.
- **`onValid`** — Internal handler that commits the mutation, links the new record into the Relay store under `directoryConnection`, and on success navigates via `router.replace` to `routes.cloudTenantManagement.new({ id })`. On `userErrors` or network error, shows a destructive toast with `CREATE_FAILED` title.

## Usage Example

```typescript
import { useNewTenantForm } from './use-new-tenant-form';

function NewTenantPage() {
  const { form, isCreating, generateLink } = useNewTenantForm();

  return (
    <form onSubmit={e => e.preventDefault()}>
      <input {...form.register('name')} placeholder="Connection name" />
      <input {...form.register('domain')} placeholder="Domain" />

      <button
        type="button"
        disabled={isCreating || !form.formState.isValid}
        onClick={generateLink}
      >
        Generate Connection Link
      </button>
    </form>
  );
}
```

Upon success, the hook navigates the user to the connect step, which reads the newly created connection from the Relay store rather than refetching it.
