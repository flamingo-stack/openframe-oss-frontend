## Overview

React hook powering the "New Tenant" form (Figma 2097-122192), which collects provider, domain, and name details and submits them via a single GraphQL mutation that both creates the directory connection and mints its connection link. On success it hands off navigation to the connect step using the newly created record's id.

## Key Components

- **`useNewTenantForm()`** — Main hook returning `{ form, isCreating, generateLink }` for use in the new-tenant page component.
- **`createMutation`** — GraphQL mutation (`createDirectoryConnection`) that creates the connection and returns its id plus `tenantFormHelpers_connection` fragment data.
- **`onValid`** — Internal submit handler that commits the mutation, updates the Relay store so the next page can read the new connection by id, and navigates via `router.replace` on success.
- **`generateLink`** — Exposed submit trigger (bound to the "Generate Connection Link" action) that validates the form via `useSubmitWithAttribution` before calling `onValid`.
- Error handling surfaces failures (`userErrors` or network errors) via `useToast` with a consistent `CREATE_FAILED` title.

## Usage Example

```typescript
import { useNewTenantForm } from './use-new-tenant-form';

function NewTenantPage() {
  const { form, isCreating, generateLink } = useNewTenantForm();

  return (
    <form onSubmit={e => { e.preventDefault(); generateLink(); }}>
      <input {...form.register('name')} placeholder="Tenant name" />
      <input {...form.register('domain')} placeholder="Domain" />
      <button type="submit" disabled={isCreating || !form.formState.isValid}>
        Generate Connection Link
      </button>
    </form>
  );
}
```

On success, the hook navigates to `routes.cloudTenantManagement.new({ id })`, where the connect step reads the connection from the Relay store rather than re-fetching it.
