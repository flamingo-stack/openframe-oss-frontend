# connect-tenant-form.tsx

React component implementing the "Connect" step of the tenant integration form (Figma 3562-27595 → 27507). It renders the same field layout as the create step but with the provider and domain locked, swaps the Generate button for a consent card once a link exists, and locks customer/attribution fields until the directory connection is verified as readable.

## Key Components

- **`ConnectTenantForm`** — Entry point component. Selects between `PendingConnectTenantForm` (no record yet, or inside a loading scope) and `LoadedConnectTenantForm` (record available).
- **`LoadedConnectTenantForm`** — Main implementation wired to `useConnectTenantForm`. Manages save/generate actions, domain editing state, consent minting retries, and connection checking.
- **`ConnectTenantFormView`** — Shared presentational frame rendering `TenantFormFrame`, `TenantFormFields`, `ProviderField` (locked), and slots for consent/attribution content. Used by both loaded and pending states to keep markup identical.
- **`PendingConnectTenantForm`** — Loading/placeholder state rendered before the tenant record resolves, backed by a throwaway `useForm` instance with default values.

## Usage Example

```typescript
import { ConnectTenantForm } from './connect-tenant-form';
import type { TenantFormRecord } from '../tenant-form/tenant-form-helpers';

function ConnectTenantPage({ record }: { record: TenantFormRecord | null }) {
  return (
    <div className="page-content">
      <ConnectTenantForm record={record} />
    </div>
  );
}
```

The component expects `record` to be `null` while the tenant record is loading (or rendered within a loading scope via `useLoadingScope`), and a populated `TenantFormRecord` once available. Behavior such as save handling, link generation, and consent verification is delegated to the `useConnectTenantForm` hook, which must be colocated in `use-connect-tenant-form.ts`.
