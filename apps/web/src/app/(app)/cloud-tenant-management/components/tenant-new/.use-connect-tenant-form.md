# use-connect-tenant-form.ts

A React hook powering the "Connect" step form for cloud tenant management (Figma 3562-27595 → 27507). It manages saving tenant name/attribution changes, editing and generating a fresh domain-based consent link, and tracking connection status against a tenant record already held in the store.

## Key Components

- **`useConnectTenantForm(record: TenantFormRecord)`** — Main hook, returns form state and handlers for the connect step.
- **`SAVE_FIELDS`** — Fields (`name`) submitted via the Save action.
- **`GENERATE_FIELDS`** — Fields (`name`, `domain`) submitted via the Generate link action.
- **Returned API:**
  - `form` / `attributionForm` — React Hook Form instances for tenant and attribution data.
  - `connected` — Whether the tenant is confirmed connected/readable.
  - `editingDomain` / `editDomain` — Domain edit mode toggle (`undefined` once connected, since the domain becomes immutable post-consent).
  - `generateLink()` — Saves changed domain/name fields, then mints a fresh consent link (invalidating any prior one).
  - `handleSave()` — Saves name/attribution changes; only sends attribution data once connected.
  - `isGenerating`, `isSaving`, `isMinting`, `mintFailed`, `retryMint()` — Loading/error state for async actions.
  - `check` — Connection check state from `useCheckConnection`.

## Usage Example

```typescript
import { useConnectTenantForm } from './use-connect-tenant-form';

function ConnectStep({ record }: { record: TenantFormRecord }) {
  const {
    form,
    attributionForm,
    connected,
    editingDomain,
    editDomain,
    generateLink,
    handleSave,
    isSaving,
    isGenerating,
    mintFailed,
    retryMint,
  } = useConnectTenantForm(record);

  return (
    <form onSubmit={form.handleSubmit(handleSave)}>
      {/* name, domain, attribution fields bound to `form` / `attributionForm` */}
      {editDomain && <button type="button" onClick={editDomain}>Edit Domain</button>}
      {editingDomain && (
        <button type="button" onClick={generateLink} disabled={isGenerating}>
          Generate Link
        </button>
      )}
      {mintFailed && <button type="button" onClick={retryMint}>Retry</button>}
      <button type="submit" disabled={isSaving}>Save</button>
    </form>
  );
}
```

## Notes

- A domain is only submitted to the API when it actually changed, since the backend rejects unchanged domains after consent.
- Attribution ("customers") data is withheld from submission until the tenant is `connected`.
- Changing the domain invalidates the previous consent link, since the tenant segment of the URL changes.
