# use-connect-tenant-form.ts

React hook powering the "connect" step form for a cloud tenant integration (Figma 3562-27595 → 27507). It manages saving the tenant's name, editing/regenerating the consent domain and link, and tracking connection status via a readability check against the customer directory.

## Key Components

- **`useConnectTenantForm(record: TenantFormRecord)`** — Main hook, returns form state and handlers for the connect step.
- **`SAVE_FIELDS`** — Fields (`name`) written by the Save action.
- **`GENERATE_FIELDS`** — Fields (`name`, `domain`) written when regenerating the consent link.
- Returned API:
  - `form` / `attributionForm` — react-hook-form instances for the tenant and attribution data.
  - `connected` — `true` if already connected or the latest check reports a readable directory state.
  - `editingDomain` / `editDomain` — toggles domain-edit mode; `editDomain` is `undefined` once connected (domain becomes locked to the granted value).
  - `generateLink()` — saves changed name/domain fields, then mints a fresh consent link (invalidating the prior one) and resets the connection check.
  - `handleSave()` — saves the changed name (and attribution data, once connected), shows a toast, and navigates to the tenant details page.
  - `isSaving` / `isGenerating` / `isMinting` / `mintFailed` — loading/error flags for the respective async operations.
  - `retryMint()` — re-attempts minting a consent link after failure.
  - `check` — connection-check state/controls from `useCheckConnection`.

## Usage Example

```typescript
import { useConnectTenantForm } from './use-connect-tenant-form';

function ConnectTenantStep({ record }: { record: TenantFormRecord }) {
  const {
    form,
    connected,
    editingDomain,
    editDomain,
    generateLink,
    handleSave,
    isSaving,
    isGenerating,
    mintFailed,
    retryMint,
  } = useConnectTenantForm(record);

  return (
    <form onSubmit={form.handleSubmit(handleSave)}>
      {/* name/domain fields bound to `form` */}

      {!connected && editDomain && (
        <button type="button" onClick={editDomain}>
          Edit Domain
        </button>
      )}

      {editingDomain && (
        <button type="button" onClick={generateLink} disabled={isGenerating}>
          Generate Link
        </button>
      )}

      {mintFailed && (
        <button type="button" onClick={retryMint}>
          Retry
        </button>
      )}

      <button type="submit" disabled={isSaving}>
        Save
      </button>
    </form>
  );
}
```

Depends on `TenantFormRecord` (shared store state), `useSaveIntegration`, `useStartConsent`, `useCheckConnection`, and `useSubmitWithAttribution` from the tenant-form/consent modules.
