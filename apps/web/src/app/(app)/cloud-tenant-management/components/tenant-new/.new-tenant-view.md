# new-tenant-view.tsx

React component rendering the `/cloud-tenant-management/new` view for creating a new tenant integration before a record exists. It shows a provider picker, domain/name fields, and a "Generate Connection Link" action; on success the flow transitions to `?id=` (handled by `ConnectTenantView`).

## Key Components

- **`NewTenantView`** — Main exported component. Composes `TenantFormFrame`, `TenantFormFields`, and `ProviderField` into the new tenant creation form.
- **`useNewTenantForm`** (internal hook) — Supplies the `form` instance, `isCreating` state, and `generateLink` action used to submit the form.
- **`offered` state** — Tracks the list of `DirectoryProvider` values the current deployment supports, populated asynchronously by `ProviderField` via its `onOffered` callback.
- **Auto-select effect** — When the deployment offers exactly one provider (or the currently selected provider isn't in the offered list), the form's `provider` field is auto-corrected to the first offered provider.
- **Generate button** — Disabled while the form is invalid, while providers are unknown/empty, or while a create request (`isCreating`) or ambient `loading` scope is active.

## Usage Example

```typescript
import { NewTenantView } from './new-tenant-view';

// Rendered as the page content for the "new tenant" route
export default function NewTenantPage() {
  return <NewTenantView />;
}
```

Internally, the component relies on `useLoadingScope()` to detect an ambient loading state (e.g., during navigation or data fetching) and locks form fields accordingly:

```typescript
const loading = useLoadingScope();
const { form, isCreating, generateLink } = useNewTenantForm();
const { isValid } = useFormState({ control: form.control });
```

The provider picker reports which providers are available via `onOffered`, letting the view disable "Generate Connection Link" until at least one valid provider exists:

```typescript
<ProviderField
  control={form.control}
  disabled={isCreating || loading}
  onOffered={setOffered}
/>
```
