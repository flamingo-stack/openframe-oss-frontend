## NewTenantView

React component rendering the "new tenant" form at `/cloud-tenant-management/new` before a tenant record exists. It lets an admin pick a directory provider, enter domain/name details, and generate a connection link; on success the flow transitions to `ConnectTenantView` via a `?id=` query param.

## Key Components

- **`NewTenantView`** — Default-exported function component; the sole export of this file.
- **`useNewTenantForm`** (consumed) — Supplies the `form` instance, `isCreating` flag, and `generateLink` action.
- **`useLoadingScope`** (consumed) — Signals an ambient loading state (e.g., route-level suspense) that locks form fields.
- **`ProviderField`** — Renders the provider picker and reports which providers (`DirectoryProvider[]`) the deployment offers via `onOffered`.
- **`TenantFormFields`** — Renders the shared domain/name fields plus the injected provider field.
- **`TenantFormFrame`** — Shared layout wrapper providing title and frame chrome; also exports `GENERATE_LINK_LABEL`.

## Behavior Notes

- Uses `useFormState` with the form's `control` to track `isValid` live (form mode `onChange`), keeping the "Generate Connection Link" button's enabled state in sync.
- Tracks `offered` (the provider list reported by the picker) in local state; `null` means not yet known.
- An effect auto-corrects the selected `provider` value to the first offered provider if the current selection isn't in the offered list — handling deployments that support only one provider.
- The Generate button is disabled when the form is invalid, providers are unknown, or no providers are offered; it shows a loading indicator while `isCreating` is true.
- All fields are disabled while `isCreating` or during the ambient `loading` scope.

## Usage Example

```typescript
import { NewTenantView } from './new-tenant-view';

export default function NewTenantPage() {
  return <NewTenantView />;
}
```

This component is intended to be rendered directly as the page content for the "new tenant" route; it manages its own form state and submission flow internally.
