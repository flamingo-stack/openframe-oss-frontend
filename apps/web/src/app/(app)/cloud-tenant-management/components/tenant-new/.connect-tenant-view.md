Renders the view for the "connect tenant" flow, displaying the consent hand-off UI for a cloud tenant record identified by its `id`. This is a thin client-side wrapper that delegates rendering to `ConnectTenantContent`.

## Key Components

- **`ConnectTenantView`** — Client component (`'use client'`) that accepts an `id` prop and renders `ConnectTenantContent` with that `id`. Used on the `/cloud-tenant-management/new?id=` route to display the tenant consent hand-off after a record has been generated.

## Usage Example

```typescript
import { ConnectTenantView } from './connect-tenant-view';

// Typically rendered in a Next.js page component,
// e.g. reading the `id` from search params
export default function Page({ searchParams }: { searchParams: { id: string } }) {
  return <ConnectTenantView id={searchParams.id} />;
}
```

This component is intentionally minimal — it exists to mark the client boundary and pass the tenant `id` through to `ConnectTenantContent`, which contains the actual consent hand-off logic and UI.
