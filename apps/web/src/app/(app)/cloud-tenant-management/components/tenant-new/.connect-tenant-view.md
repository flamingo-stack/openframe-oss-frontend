Renders the tenant-connection page for a newly generated cloud tenant record, delegating the consent hand-off UI to `ConnectTenantContent`. This component serves as the top-level view for the `/cloud-tenant-management/new?id=` route.

## Key Components

- **`ConnectTenantView`** — Client component that accepts a tenant `id` prop and passes it through to `ConnectTenantContent`, which handles the actual rendering of the connection/consent flow.

## Usage Example

```typescript
import { ConnectTenantView } from './connect-tenant-view';

// Typically rendered by a Next.js page component reading the `id` query param
export default function Page({ searchParams }: { searchParams: { id: string } }) {
  return <ConnectTenantView id={searchParams.id} />;
}
```

This component is intentionally a thin wrapper: it exists to decouple the route-level entry point from the implementation details of `ConnectTenantContent`, keeping the page boundary minimal and the consent/connection logic encapsulated in a single, reusable component.
