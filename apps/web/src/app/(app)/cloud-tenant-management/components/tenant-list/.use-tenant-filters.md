# use-tenant-filters.ts

A React hook that builds filter option lists (tenant/provider, customer, license, access state) for the tenants data table, deriving selectable facets and their counts from a GraphQL query while preserving previously selected values that drop to zero results.

## Key Components

- **`tenantFiltersQuery`** - GraphQL query fetching `directoryConnectionFilters` (providers, customers, access states, licenses), each as a facet row with `value`, `label`, and `count`, scoped by search text and filter input.
- **`toOptions(facet, selected, labelOf)`** - Converts raw facet rows into `DataTableFilterOption[]`, ensuring any currently selected value that no longer appears in the facet results is still included (with a zero count) via `withSelected`.
- **`enumLabel(members, name)`** - Returns a label-resolution function for enum-backed facets (provider, license, access state), falling back to the server-provided label or raw value when the enum member is unrecognized.
- **`useTenantFilters(search, filter, selections, enabled)`** - Main hook. Runs the query non-suspendingly, computes `options` for all four filter dimensions, and returns a `pending` flag indicating whether the first load is still in flight.

## Usage Example

```typescript
import { useTenantFilters } from './use-tenant-filters';

function TenantsFilterBar({ search, filter, selections }: {
  search: string;
  filter: DirectoryConnectionFilterInput | null;
  selections: TenantSelections;
}) {
  const { options, pending } = useTenantFilters(search, filter, selections, true);

  return (
    <TenantsTableFilters
      options={options}
      selections={selections}
      loading={pending}
    />
  );
}
```

The hook is designed to be called conditionally via the `enabled` flag (e.g., only when a filter panel is open), and it keeps the last known `options` on screen while a new query resolves, avoiding UI flicker during refetches.
