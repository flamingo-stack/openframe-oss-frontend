# consent-announcement-banner.tsx

Renders a dismissible, tenant-wide warning banner notifying admins/owners that a release requires permissions the connected directory tenants have not yet granted. It fetches the announcement via a GraphQL query, gates visibility to admins, and wraps rendering in loading/error boundaries so a failure only affects this strip, not the page.

## Key Components

- **`ConsentAnnouncementBanner`** — Public entry point. Gates rendering to admins/owners via `useAdminGate()`, wraps content in `ContentErrorBoundary` with a `SectionLoadError` fallback, and delegates to `AnnouncementAlert`.
- **`AnnouncementAlert`** — Wraps the query-driven reader in `LoadingSuspense` so nothing renders while the fetch is in flight.
- **`AnnouncementAlertReader`** — Returns `null` while inside a loading scope (`useLoadingScope()`), avoiding a flash of placeholder UI since most workspaces have no announcement.
- **`AnnouncementAlertQuery`** — Executes `consentAnnouncementBannerQuery` via `useLazyLoadQuery`, renders the `Alert` with the backend-provided message, and wires a dismiss button using `useDismissConsentAnnouncement`, refetching network-only after dismissal.
- **`consentAnnouncementBannerQuery`** — Relay GraphQL query fetching `directoryConsentAnnouncement.message`.
- **`OptionalMarkProps`** — Interface carrying an optional `data-loading-optional` attribute used by the parent loading gate.

## Usage Example

```typescript
import { ConsentAnnouncementBanner } from './consent-announcement-banner';

function TenantListPage() {
  return (
    <div>
      <ConsentAnnouncementBanner />
      {/* rest of tenant list UI */}
    </div>
  );
}
```

The banner self-gates on admin role and announcement presence — render it unconditionally above the content it concerns (e.g., a directory tenant list), and it will show or hide itself automatically.
