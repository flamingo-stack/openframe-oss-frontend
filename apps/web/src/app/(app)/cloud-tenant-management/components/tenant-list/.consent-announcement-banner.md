# consent-announcement-banner.tsx

Renders a tenant-wide, dismissible banner that alerts admins/owners when a release requires permissions that connected directory tenants have not yet granted. It queries `directoryConsentAnnouncement` via Relay, resolves silently when there is nothing to announce, and gracefully degrades on error without breaking the page.

## Key Components

- **`ConsentAnnouncementBanner`** — Public entry point. Gates rendering to `admin`/`owner` roles via `useAdminGate`, wraps the content in a `ContentErrorBoundary` (falls back to `SectionLoadError` on failure), and delegates to `AnnouncementAlert`.
- **`AnnouncementAlert`** — Wraps `AnnouncementAlertReader` in `LoadingSuspense` so no placeholder flashes while the query is in flight.
- **`AnnouncementAlertReader`** — Skips rendering entirely while inside a loading scope (`useLoadingScope`), avoiding an unnecessary box for workspaces that have no announcement.
- **`AnnouncementAlertQuery`** — Executes `consentAnnouncementBannerQuery` via `useLazyLoadQuery`, renders the `Alert` with the backend-provided `message`, a cloud icon, and a dismiss button wired to `useDismissConsentAnnouncement`. On dismiss, forces a `network-only` refetch to reflect the authoritative server state.
- **`consentAnnouncementBannerQuery`** — GraphQL query fetching `directoryConsentAnnouncement.message`.
- **`OptionalMarkProps`** — Interface passing through `data-loading-optional` for external loading-gate measurement.

## Usage Example

```typescript
import { ConsentAnnouncementBanner } from './consent-announcement-banner';

function TenantListPage() {
  return (
    <div>
      <ConsentAnnouncementBanner data-loading-optional />
      {/* rest of tenant list UI */}
    </div>
  );
}
```

The component requires no props beyond the optional loading marker — it self-gates on admin role, self-suspends on load, and self-hides when there is no announcement or the viewer lacks permission.
