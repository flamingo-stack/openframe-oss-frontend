# use-dismiss-consent-announcement.ts

A React hook that provides the dismiss action for the workspace-wide re-consent announcement banner, using a Relay mutation to permanently hide it for all users in the workspace.

## Key Components

- **`dismissMutation`** — GraphQL mutation (`useDismissConsentAnnouncementMutation`) that calls `dismissDirectoryConsentAnnouncement`, returning a boolean success flag.
- **`useDismissConsentAnnouncement(onDismissed)`** — Hook that wraps the mutation and exposes:
  - `dismiss()` — Triggers the mutation, guarded against duplicate submissions while in flight.
  - `isDismissing` — Boolean loading state from `useMutation`.

The hook's `updater` function directly clears `directoryConsentAnnouncement` from the Relay store root, so the UI updates optimistically without waiting for a refetch. On success, it invokes the `onDismissed` callback and shows a success toast; on failure, it surfaces an error toast using `getRelayErrorMessage`.

## Usage Example

```typescript
import { useDismissConsentAnnouncement } from './use-dismiss-consent-announcement';

function ConsentBanner() {
  const [visible, setVisible] = useState(true);
  const { dismiss, isDismissing } = useDismissConsentAnnouncement(() => {
    setVisible(false);
  });

  if (!visible) return null;

  return (
    <div className="banner">
      <p>Please review the updated directory consent terms.</p>
      <button onClick={dismiss} disabled={isDismissing}>
        {isDismissing ? 'Dismissing…' : 'Dismiss'}
      </button>
    </div>
  );
}
```

**Note:** Dismissing the announcement is a workspace-level action — it hides the banner for every user, not just the current one, so this action should typically be gated behind appropriate permissions in the calling component.
