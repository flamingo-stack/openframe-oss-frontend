# use-dismiss-consent-announcement.ts

A React hook that handles dismissing the directory re-consent announcement banner via a GraphQL mutation, hiding it workspace-wide rather than just for the current user.

## Key Components

- **`dismissMutation`** — GraphQL mutation definition (`dismissDirectoryConsentAnnouncement`) that returns a boolean; the Relay store is updated locally via an `updater` function rather than relying on the server response payload.
- **`useDismissConsentAnnouncement(onDismissed)`** — Hook accepting a callback invoked after successful dismissal. Returns:
  - `dismiss()` — Triggers the mutation, guarded against duplicate submissions while in-flight.
  - `isDismissing` — Boolean loading state from `useMutation`.

## Behavior

- Uses an inline Relay `updater` to immediately clear `directoryConsentAnnouncement` from the store (sets it to `null` on the root record), so the UI reacts instantly without waiting for a refetch.
- On success, calls `onDismissed()` and shows a success toast confirming the banner is hidden for the whole workspace.
- On failure, shows a destructive toast with an error message derived via `getRelayErrorMessage`.
- Calling `dismiss()` while `isDismissing` is `true` is a no-op, preventing duplicate mutation calls.

## Usage Example

```typescript
'use client';

import { useDismissConsentAnnouncement } from '@/hooks/use-dismiss-consent-announcement';

function ConsentBanner({ onHide }: { onHide: () => void }) {
  const { dismiss, isDismissing } = useDismissConsentAnnouncement(onHide);

  return (
    <div className="consent-banner">
      <p>Please review the updated directory consent terms.</p>
      <button onClick={dismiss} disabled={isDismissing}>
        {isDismissing ? 'Dismissing…' : 'Dismiss'}
      </button>
    </div>
  );
}
```
