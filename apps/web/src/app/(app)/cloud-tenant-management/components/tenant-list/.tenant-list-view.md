# tenant-list-view.tsx

Client-side React component rendering the Cloud Tenant Management page, including a searchable, filterable, and sortable table of tenants with a sticky toolbar and a "Connect Tenant" call-to-action.

## Key Components

- **`CONNECT_TENANT_ACTION`** — `PageActionButton` config for the split "Connect Tenant" action: clicking the label navigates in place, while the arrow icon opens the connect page in a new tab.
- **`TenantListViewProps`** — Props interface; accepts an optional `loading` flag that renders a skeleton frame without fetching data.
- **`TenantListView`** — Main exported component. Responsibilities:
  - Syncs search, filter, and sort state to URL query params via `useApiParams`.
  - Debounces local search input (`useSearchParam`) to keep typing responsive while deferring the actual query (`useDeferredQuery`) to avoid UI jank during refetches.
  - Loads filter options for tenant/customer/licenses/access via `useTenantFilters`.
  - Renders a sticky toolbar (`useStickyToolbar`) with a search `Input` and a filter/sort trigger `Button`.
  - Displays `ConsentAnnouncementBanner` when applicable and not loading.
  - Wraps the tenant table in `LoadingWhen` to manage loading state display.
  - Renders a `FilterModal` for advanced filtering (Provider, Customers, Access, Licences) and sorting, driven by `TENANT_SORT_COLUMNS` and helpers from `./tenants-filter`.

## Usage Example

```typescript
import { TenantListView } from './tenant-list-view';

// Basic usage within a page shell
export default function TenantManagementPage() {
  return <TenantListView />;
}

// While a feature flag or permission check resolves
export function TenantManagementPageWithGate({ flagReady }: { flagReady: boolean }) {
  return <TenantListView loading={!flagReady} />;
}
```

This component expects to be rendered inside a container (e.g., `TenantPageShell`) that supplies page padding and an error boundary, since `PageLayout`'s `contentClassName` intentionally omits padding.
