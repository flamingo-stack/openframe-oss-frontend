Renders a paginated, searchable/filterable table of cloud-directory tenants (Microsoft 365, Google Workspace, etc.) backed by a Relay GraphQL connection, including loading, empty, and error-retry states.

## Key Components

- **`TenantsTable`** — Public entry point. Wraps the query-driven reader in a `LoadingSuspense` boundary so the component owns its own loading UI.
- **`TenantsTableReader`** — Internal gate: when inside a global loading scope (e.g., initial app shell), renders `TenantsTableView` with no rows as a skeleton; otherwise delegates to `TenantsTableQuery`, which suspends while fetching.
- **`TenantsTableQuery`** — Core data component. Uses `useLazyLoadQuery` for the initial fetch and `usePaginationFragment` for cursor-based "load more" pagination. Maps GraphQL edges into `MultiCustomerTenantRow` objects, computes an empty-state flag, and calls `onEmptyChange` via `useLayoutEffect` before paint to avoid UI flashes.
- **`tenantsTableQuery` / `tenantsTableFragment`** — GraphQL query and `@refetchable` fragment (`tenantsTablePaginationQuery`) that fetch `directoryConnections` with search, filter, order, and pagination arguments, including per-tenant `access.state`, license summary, and bound customer data.
- **`tenantRowHref`** — Builds the detail-page link (`routes.cloudTenantManagement.details`) for a given row.
- **`TENANTS_PAGE_SIZE`** — Page size constant (20) shared by the query and skeleton row count.

## Usage Example

```typescript
import { TenantsTable } from './tenants-table';

function CloudTenantManagementPage() {
  const [search, setSearch] = useState('');
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <TenantsTable
      search={search}
      filter={null}
      orderBy={null}
      filters={{ /* current UI filter state */ }}
      isPending={false}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
    />
  );
}
```

Typically rendered within a page under `routes.cloudTenantManagement`, paired with a search/filter toolbar whose visibility is toggled based on the `onEmptyChange` callback.
