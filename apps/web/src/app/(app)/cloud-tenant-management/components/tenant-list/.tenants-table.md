# tenants-table.tsx

Renders a paginated, searchable/filterable table of connected tenants (Microsoft 365 / Google Workspace directories), fetching data via a Relay GraphQL connection with cursor-based pagination and a loading-scope-aware skeleton state.

## Key Components

- **`TenantsTable`** — Public entry point. Wraps the query-driven reader in a `LoadingSuspense` boundary so the component manages its own loading fallback.
- **`TenantsTableReader`** — Checks `useLoadingScope()`; if inside a loading scope (e.g. Suspense fallback), renders `TenantsTableView` with empty/skeleton rows instead of triggering a network suspense.
- **`TenantsTableQuery`** — Executes `tenantsTableQuery` via `useLazyLoadQuery`, then paginates through `usePaginationFragment` on `tenantsTable_query` fragment. Maps GraphQL edges into `MultiCustomerTenantRow[]`, handles the "no results" `EmptyState`, and wires up `onLoadMore` for infinite scroll.
- **`tenantsTableQuery` / `tenantsTableFragment`** — GraphQL definitions for fetching `directoryConnections` (tenant name, provider, domain, user counts, license summary, access state, bound customers) with search/filter/orderBy/pagination arguments.
- **`tenantRowHref`** — Builds the detail-page link for a tenant row using `routes.cloudTenantManagement.details`.
- **`TenantsTableProps`** — Props contract: live vs. deferred search/filter state (`search`, `filter`, `orderBy`, `filters`, `isPending`), empty-state callback (`onEmptyChange`), and `stickyHeaderOffset`.

## Usage Example

```typescript
import { TenantsTable } from './tenants-table';

function TenantsPage() {
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <TenantsTable
      search={deferredSearch}
      filter={directoryFilter}
      orderBy={directoryOrderBy}
      filters={liveFilters}
      isPending={isSearchPending}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
    />
  );
}
```

The component is self-contained: it owns its data fetching, pagination (`loadNext`/`hasNext`), and empty-state rendering. Consumers only need to supply search/filter state and react to `onEmptyChange` to toggle surrounding UI (e.g., hiding a search toolbar when there's nothing to search).
