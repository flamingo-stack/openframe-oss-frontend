## Purpose

Provides helper functions and types for converting tenant list UI filter/sort state into GraphQL query input shapes, used by the tenants table to translate funnel selections and sort column clicks into `DirectoryConnectionFilterInput` and `DirectoryConnectionOrderInput` for the `tenantsTableQuery`.

## Key Components

- **`TenantSelections`** — Type mapping each `TenantsTableFilterColumn` to its array of selected filter values (tenant provider, customer, licenses, access).
- **`toTenantFilter(selections)`** — Converts `TenantSelections` into a `DirectoryConnectionFilterInput`, or `null` if no filters are active (meaning an unfiltered list). Validates provider/license/access values against known enum values via `knownValues`.
- **`TENANT_SORT_COLUMNS`** — Static list of sortable columns (`Name`, `Users`, `Last read`) pairing `DirectoryConnectionSortField` keys with display labels.
- **`toTenantOrderBy(sortBy, direction)`** — Builds a `DirectoryConnectionOrderInput` from a sort key/direction pair, returning `null` for unrecognized sort fields (falling back to the server's default sort by name).
- **`tenantSortDirection(direction)`** — Normalizes a raw direction string into the UI's `ModalSortDirection` type (`'asc'` | `'desc'`).

## Usage Example

```typescript
import {
  toTenantFilter,
  toTenantOrderBy,
  tenantSortDirection,
  TENANT_SORT_COLUMNS,
} from './tenants-filter';

const selections = {
  tenant: ['GOOGLE'],
  customer: ['org-123'],
  licenses: [],
  access: [],
};

const filter = toTenantFilter(selections);
// => { providers: ['GOOGLE'], organizationIds: ['org-123'] }

const orderBy = toTenantOrderBy('USERS', 'desc');
// => { field: 'USERS', direction: 'DESC' }

const uiDirection = tenantSortDirection('desc'); // 'desc'

// Render sort column options in the UI
TENANT_SORT_COLUMNS.forEach(({ key, label }) => {
  console.log(`${label} -> ${key}`);
});
```
