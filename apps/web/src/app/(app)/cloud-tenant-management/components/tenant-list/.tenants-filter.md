## tenants-filter.ts

Converts UI-level tenant filter and sort selections into the GraphQL input shapes required by the tenants table query. Acts as a translation layer between the filter modal/table UI state and the `DirectoryConnectionFilterInput` / `DirectoryConnectionOrderInput` types consumed by the backend query.

## Key Components

- **`TenantSelections`** — Type mapping each `TenantsTableFilterColumn` to an array of selected string values (the "ticked" funnel values).
- **`toTenantFilter(selections)`** — Builds a `DirectoryConnectionFilterInput` from tenant provider, customer, license, and access selections, filtering out unknown/invalid enum values via `knownValues`. Returns `null` when no filters are active (unfiltered list).
- **`TENANT_SORT_COLUMNS`** — The list of sortable columns (Name, Users, Last read) paired with their `DirectoryConnectionSortField` keys and display labels.
- **`toTenantOrderBy(sortBy, direction)`** — Builds a `DirectoryConnectionOrderInput` from a sort column key and direction string, returning `null` for unrecognized sort fields (falls back to server default sort by name).
- **`tenantSortDirection(direction)`** — Normalizes an arbitrary direction string into the strict `ModalSortDirection` union (`'asc' | 'desc'`) expected by the UI sort control.

## Usage Example

```typescript
import { toTenantFilter, toTenantOrderBy, tenantSortDirection } from './tenants-filter';

const selections = {
  tenant: ['GOOGLE'],
  customer: ['org-123'],
  licenses: [],
  access: ['SUSPENDED'],
};

const filter = toTenantFilter(selections);
// => { providers: ['GOOGLE'], organizationIds: ['org-123'], accessStates: ['SUSPENDED'] }

const orderBy = toTenantOrderBy('USERS', 'desc');
// => { field: 'USERS', direction: 'DESC' }

const direction = tenantSortDirection('desc');
// => 'desc'

// Feed results into the generated query variables
const variables = {
  filter,
  orderBy,
};
```

Both `toTenantFilter` and `toTenantOrderBy` return `null` when no meaningful filtering/sorting is requested, letting the query rely on the server's defaults instead of sending empty objects.
