## end-connection-view.tsx

Renders the "Disconnect" or "Delete Connection" confirmation page for a directory connection, showing impact details (affected users, groups, devices, etc.) and customer-facing instructions before the destructive action is confirmed.

## Key Components

- **`EndConnectionView`** — Exported entry point; wraps the page in `LoadingSuspense` to handle async data loading while rendering a skeleton-ready layout.
- **`EndConnectionReader`** — Internal component that decides between rendering a loading skeleton (`EndConnectionPage` with `connection={null}`) or triggering the GraphQL query (`EndConnectionQuery`).
- **`EndConnectionQuery`** — Executes `endConnectionViewQuery` via `useLazyLoadQuery`, handling the not-found case with `NotFoundError`, and passes the resolved `connection` to `EndConnectionPage`.
- **`EndConnectionPage`** — Renders the full page frame (title, back button, action buttons, impact sections, and customer-tenant instructions), supporting a loading state via skeleton text/lines.
- **`CustomerTenantSteps`** — Displays provider-specific instructions for the customer's tenant admin, with a "Copy Instructions" button using `useCopyToClipboard`.
- **`endConnectionViewQuery`** — GraphQL query fetching connection details (`id`, `name`, `provider`) and impact counts (`users`, `groups`, `licenseAssignments`, `cloudOnlyDevices`, `agentDeviceLinks`).
- **`EndConnectionMode`** (`'disconnect' | 'delete'`) — Determines button labels/variants (`VERB`, `BUTTON` maps) and which content sections (`disconnectSections` / `deleteSections`) are shown.

## Usage Example

```typescript
import { EndConnectionView } from './end-connection-view';

// Within a route page component, e.g. app/tenants/[id]/disconnect/page.tsx
export default function DisconnectTenantPage({ params }: { params: { id: string } }) {
  return <EndConnectionView id={params.id} mode="disconnect" />;
}

// For a delete confirmation route
export default function DeleteTenantPage({ params }: { params: { id: string } }) {
  return <EndConnectionView id={params.id} mode="delete" />;
}
```

The component handles its own loading, error (not found), and submission states internally, so callers only need to supply the connection `id` and the `mode` (`'disconnect'` or `'delete'`).
