## end-connection-view.tsx

Renders the confirmation page for disconnecting or deleting a directory connection (e.g., Azure AD/Google Workspace tenant integration), showing impact details (users, groups, devices affected) and customer-side instructions before the destructive action is confirmed.

## Key Components

- **`EndConnectionView`** — Public entry point component. Wraps the data-fetching logic in `LoadingSuspense` to provide a consistent loading UX.
- **`EndConnectionReader`** — Internal router that decides whether to show the skeleton/loading state or trigger the actual GraphQL query, based on `useLoadingScope`.
- **`EndConnectionQuery`** — Executes the `endConnectionViewQuery` GraphQL query via `useLazyLoadQuery`, handles the "not found" case, and passes the resolved connection to `EndConnectionPage`.
- **`EndConnectionPage`** — Renders the page frame (title, back button, action buttons) along with impact sections (`InfoSection`) and the `CustomerTenantSteps` block. Supports a skeleton state while `connection` is `null`.
- **`CustomerTenantSteps`** — Displays instructions that must be performed by the customer's tenant admin, with a "Copy Instructions" button using `useCopyToClipboard`.
- **`endConnectionViewQuery`** — GraphQL query fetching the connection's `id`, `name`, `provider`, and `impact` counts (users, groups, license assignments, cloud-only devices, agent device links).
- **`VERB`, `BUTTON`** — Maps for mode-specific (`disconnect` | `delete`) labels and button styling.

## Usage Example

```typescript
// app/(routes)/cloud-tenant-management/[id]/disconnect/page.tsx
import { EndConnectionView } from '@/app/components/end-connection/end-connection-view';

export default function DisconnectPage({ params }: { params: { id: string } }) {
  return <EndConnectionView id={params.id} mode="disconnect" />;
}
```

```typescript
// Delete variant
<EndConnectionView id={connectionId} mode="delete" />
```

The component depends on `useEndConnection` (submission logic), `end-connection-copy` (mode-specific text/sections), and `routes.cloudTenantManagement` for navigation targets (list and details views).
