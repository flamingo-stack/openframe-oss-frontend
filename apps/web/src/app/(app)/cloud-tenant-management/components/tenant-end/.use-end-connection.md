# use-end-connection.ts

A React hook that performs the "disconnect" or "delete" action for a directory (tenant) connection, running the appropriate GraphQL mutation, surfacing success/error toasts, and navigating the user afterward.

## Key Components

- **`useEndConnection(connectionId, mode)`** — Main hook accepting a connection ID and an `EndConnectionMode` (`'disconnect' | 'delete'`). Returns:
  - `submit()` — triggers the corresponding mutation.
  - `isSubmitting` — boolean combining both mutations' in-flight states.
- **`disconnectMutation`** — GraphQL mutation (`disconnectDirectoryConnection`) that revokes tenant access while preserving previously read data.
- **`deleteMutation`** — GraphQL mutation (`deleteDirectoryConnection`) that permanently removes the connection along with its users, groups, and devices.
- **`FAILED_TITLE`** — Maps each mode to a user-facing toast title shown on failure.

Both mutations call `store.invalidateStore()` in their `updater`, since ending a connection changes access state, list rows/counts, and customer bindings across the app—ensuring no stale data is shown afterward.

## Usage Example

```typescript
import { useEndConnection } from './use-end-connection';

function DisconnectTenantButton({ connectionId }: { connectionId: string }) {
  const { submit, isSubmitting } = useEndConnection(connectionId, 'disconnect');

  return (
    <button onClick={submit} disabled={isSubmitting}>
      {isSubmitting ? 'Disconnecting…' : 'Disconnect Tenant'}
    </button>
  );
}

function DeleteConnectionButton({ connectionId }: { connectionId: string }) {
  const { submit, isSubmitting } = useEndConnection(connectionId, 'delete');

  return (
    <button onClick={submit} disabled={isSubmitting}>
      {isSubmitting ? 'Deleting…' : 'Delete Connection'}
    </button>
  );
}
```

On success, `disconnect` mode redirects to the connection's details page (`routes.cloudTenantManagement.details`), while `delete` mode redirects to the connections list (`routes.cloudTenantManagement.list`). On failure, a destructive toast displays a mode-specific title with a server-derived or fallback error description.
