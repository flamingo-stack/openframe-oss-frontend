# use-end-connection.ts

A React hook that handles the "disconnect" and "delete" actions for a directory connection in Cloud Tenant Management, running the appropriate GraphQL mutation, invalidating the Relay store, and navigating/toasting based on the outcome.

## Key Components

- **`useEndConnection(connectionId, mode)`** — Main hook. Accepts a connection ID and an `EndConnectionMode` (`'disconnect' | 'delete'`), and returns `{ submit, isSubmitting }`.
- **`disconnectMutation`** — GraphQL mutation (`disconnectDirectoryConnection`) that revokes access to a tenant connection while preserving previously read data.
- **`deleteMutation`** — GraphQL mutation (`deleteDirectoryConnection`) that permanently deletes the connection along with its users, groups, and devices.
- **`FAILED_TITLE`** — Maps each `EndConnectionMode` to a user-facing error toast title.
- **`submit`** — Triggers the relevant mutation based on `mode`, invalidates the Relay store (since the action affects tenant-wide reads: access state, list rows/counts, customer bindings), surfaces success/failure toasts, and redirects via `next/navigation`'s router.
- **`isSubmitting`** — Boolean combining the loading state of both mutations, useful for disabling UI during submission.

## Usage Example

```typescript
import { useEndConnection } from './use-end-connection';

function EndConnectionButton({ connectionId }: { connectionId: string }) {
  const { submit, isSubmitting } = useEndConnection(connectionId, 'disconnect');

  return (
    <button onClick={submit} disabled={isSubmitting}>
      {isSubmitting ? 'Disconnecting…' : 'Disconnect tenant'}
    </button>
  );
}
```

On success, `disconnect` mode redirects to `routes.cloudTenantManagement.details(connectionId)`, while `delete` mode redirects to `routes.cloudTenantManagement.list`. Both paths show a success or failure toast and invalidate the Relay store so that stale tenant data is not rendered after the action completes.
