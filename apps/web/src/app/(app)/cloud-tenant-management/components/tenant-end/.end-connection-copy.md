# end-connection-copy.ts

Provides provider-specific copy (text content) for the Disconnect and Delete pages of a directory connection, sourced verbatim from Figma design specs. It centralizes user-facing strings for Microsoft 365 and Google Workspace connection lifecycle actions, along with the structured data for rendering impact summary sections.

## Key Components

- **`EndConnectionMode`** — Type union: `'disconnect' | 'delete'`.
- **`EndConnectionRecord`** / **`EndConnectionRow`** / **`EndConnectionSection`** — Types describing the connection data and the rows/sections used to render impact summaries.
- **`CustomerTenantSteps`** — Shape for the customer admin console instructions (`intro`, `items`, optional `note`).
- **`DELETE_INTRO`** — Constant string with the intro copy for the Delete flow.
- **`endConnectionIntro(mode, provider)`** — Returns the intro paragraph for either Disconnect or Delete, based on provider.
- **`customerTenantSteps(provider)`** — Returns the structured steps object for a given provider (Microsoft 365, Google Workspace, or unknown fallback).
- **`customerTenantStepsText(provider)`** — Returns the steps formatted as a single markdown-like string (for use with "Copy Instructions").
- **`disconnectSections(impact)`** — Builds the "Stops" / "Stays, read-only" sections for the Disconnect page.
- **`deleteSections(impact, provider)`** — Builds the "Deleted" / "Stays, read-only" sections for the Delete page.

## Usage Example

```typescript
import {
  endConnectionIntro,
  customerTenantStepsText,
  disconnectSections,
  deleteSections,
} from './end-connection-copy';

const provider = connection.provider; // e.g. DirectoryProvider.MICROSOFT_365
const impact = connection.impact;

const intro = endConnectionIntro('disconnect', provider);
const instructions = customerTenantStepsText(provider);
const sections = disconnectSections(impact);

// For the Delete page:
const deleteIntro = endConnectionIntro('delete', provider);
const deleteSummary = deleteSections(impact, provider);
```

This module contains no side effects or network calls — it's a pure presentation layer mapping provider identifiers and impact data to display-ready copy, consumed by the Disconnect/Delete confirmation views.
