## end-connection-copy.ts

Provides UI copy and content-generation logic for the Disconnect and Delete connection pages, tailoring wording per directory provider (Microsoft 365, Google Workspace). Content is sourced verbatim from Figma designs and covers intro text, customer-facing admin console instructions, and impact summary sections (what stops, what's deleted, what stays read-only).

## Key Components

- **`EndConnectionMode`** - Type union: `'disconnect' | 'delete'`.
- **`EndConnectionRecord`** / **`EndConnectionRow`** / **`EndConnectionSection`** - Types describing the connection data and the row/section structure used to render impact summaries.
- **`CustomerTenantSteps`** - Type for the provider-specific admin console instructions (intro, items, optional note).
- **`DELETE_INTRO`** - Constant string with the intro copy for the Delete flow.
- **`endConnectionIntro(mode, provider)`** - Returns the intro paragraph for either mode, provider-aware for disconnect.
- **`customerTenantSteps(provider)`** - Returns structured steps for revoking OpenFrame's access in the provider's console.
- **`customerTenantStepsText(provider)`** - Returns the steps formatted as plain text (for "Copy Instructions" actions).
- **`disconnectSections(impact)`** - Builds the "Stops" / "Stays, read-only" sections for the Disconnect page.
- **`deleteSections(impact, provider)`** - Builds the "Deleted" / "Stays, read-only" sections for the Delete page.
