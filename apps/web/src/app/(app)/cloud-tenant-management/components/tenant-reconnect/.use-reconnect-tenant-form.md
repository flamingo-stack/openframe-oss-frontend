This React hook manages the "reconnect" flow for a cloud tenant integration, handling attribution form state and conditionally saving changes before navigating back to the tenant details page.

## Key Components

- **`useReconnectTenantForm(id, record, readable)`** — Main hook that orchestrates the reconnect save flow for a given tenant `id`.
  - `id: string` — Tenant identifier used for saving and routing.
  - `record: TenantFormRecord | null` — Existing tenant record data, including prior attribution values.
  - `readable: boolean` — Flag indicating whether the directory data is currently readable/accessible.
- **Returned API:**
  - `attributionForm` — The form instance from `useAttributionForm`, bound to attribution field values.
  - `handleSave()` — Submits attribution changes (if any) or simply navigates back if nothing changed.
  - `isSaving` — Boolean loading state from `useSaveIntegration`.

### Internal Behavior
- Uses `attributionChanged` to skip saving when the form is untouched or the record is unreadable/locked.
- Uses `useSubmitWithAttribution` to validate and submit the attribution form.
- On successful save, shows a success `toast` and navigates back via `safeBackOrReplace` to `routes.cloudTenantManagement.details(id)`.

## Usage Example

```typescript
import { useReconnectTenantForm } from './use-reconnect-tenant-form';

function ReconnectPage({ tenantId, tenantRecord, isReadable }) {
  const { attributionForm, handleSave, isSaving } = useReconnectTenantForm(
    tenantId,
    tenantRecord,
    isReadable
  );

  return (
    <form onSubmit={attributionForm.handleSubmit(handleSave)}>
      {/* attribution form fields */}
      <button type="submit" disabled={isSaving}>
        {isSaving ? 'Saving…' : 'Save and Continue'}
      </button>
    </form>
  );
}
```

This hook is typically used on a "reconnect tenant" page where a user confirms or updates attribution details after a directory probe has refreshed tenant data.
