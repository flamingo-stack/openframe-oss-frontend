# use-reconnect-tenant-form.ts

A custom React hook that manages the "reconnect" flow for a cloud tenant's integration, handling attribution form state and conditionally persisting customer attribution changes before navigating back to the tenant details page.

## Key Components

- **`useReconnectTenantForm(id, record, readable)`** — Main hook that orchestrates the reconnect save flow for a given tenant integration.
  - **`id: string`** — The tenant/integration identifier used for saving and routing.
  - **`record: TenantFormRecord | null`** — The current tenant form record containing attribution values, or `null` if unavailable.
  - **`readable: boolean`** — Flag indicating whether the directory data is readable/accessible.
  - Returns `{ attributionForm, handleSave, isSaving }`:
    - `attributionForm` — The underlying form instance from `useAttributionForm`.
    - `handleSave()` — Callback that either skips saving (if record is locked/untouched) or submits attribution changes and navigates back.
    - `isSaving` — Boolean loading state from `useSaveIntegration`.

### Internal Logic
- Uses `attributionChanged` to detect if the user modified attribution values compared to the original record.
- Uses `useSubmitWithAttribution` to validate and submit the form before calling `save`.
- Uses `integrationInput` to build the payload sent to `useSaveIntegration`.
- Uses `safeBackOrReplace` to navigate back to `routes.cloudTenantManagement.details(id)`, falling back to a replace navigation if there's no history to go back to.
- Displays a success toast via `useToast` upon successful save.

## Usage Example

```typescript
import { useReconnectTenantForm } from './use-reconnect-tenant-form';

function ReconnectTenantPage({ tenantId, tenantRecord, isDirectoryReadable }: {
  tenantId: string;
  tenantRecord: TenantFormRecord | null;
  isDirectoryReadable: boolean;
}) {
  const { attributionForm, handleSave, isSaving } = useReconnectTenantForm(
    tenantId,
    tenantRecord,
    isDirectoryReadable,
  );

  return (
    <form onSubmit={attributionForm.handleSubmit(handleSave)}>
      {/* attribution form fields bound to attributionForm */}
      <button type="submit" disabled={isSaving}>
        {isSaving ? 'Saving...' : 'Save & Continue'}
      </button>
    </form>
  );
}
```

## Notes

- If the record is `null`, unreadable, or attribution values are unchanged, `handleSave` skips the save call entirely and simply navigates back — the page load itself is treated as sufficient user consent.
- Part of the tenant form module; depends on shared helpers in `../tenant-form/` for attribution state, submission, and save-integration logic.
