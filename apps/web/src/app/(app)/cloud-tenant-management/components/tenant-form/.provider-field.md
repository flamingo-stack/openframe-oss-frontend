# provider-field.tsx

A React component that renders the directory provider selection radio group for the tenant creation/edit form, fetching available providers via a Relay GraphQL query and gracefully handling loading states.

## Key Components

- **`providerFieldQuery`** — GraphQL query fetching `directoryConnectionOptions.providers` for the current deployment.
- **`toProviderOption(provider)`** — Maps a `DirectoryProvider` enum value to a radio option (`value`, `label`, `description`) using `providerPresentation`.
- **`ProviderOptions`** — Internal component that loads provider data with `useLazyLoadQuery`, filters/orders them via `PROVIDER_ORDER`, reports the offered providers up through `onOffered`, and renders a `Controller`-wrapped `RadioGroupBlock`. Shows an `Alert` if no providers are enabled.
- **`ProviderField`** (exported) — Public entry point; wraps `ProviderFieldBody` in `LoadingSuspense` to show a "Loading providers" fallback.
- **`ProviderFieldBody`** — Detects whether it's in a loading scope (via `useLoadingScope`) and renders either a disabled placeholder radio group (`LOADING_OPTIONS`, covering all known providers) or the live `ProviderOptions`.
- **`ProviderFieldProps`** — Props interface: `control` (react-hook-form), `disabled`, `locked` (provider fixed once a connection exists), and `onOffered` callback.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ProviderField } from './provider-field';
import type { TenantFormData } from './tenant-form.types';

function TenantForm() {
  const { control } = useForm<TenantFormData>();

  return (
    <form>
      <ProviderField
        control={control}
        locked={false}
        onOffered={(providers) => console.log('Available providers:', providers)}
      />
    </form>
  );
}
```

The component is designed to be used inside the tenant creation form where it must coordinate between a Suspense boundary (its own or a parent page's) and real-time data fetching, ensuring a consistent disabled radio UI during loading and a functional, validated radio group once data resolves.
