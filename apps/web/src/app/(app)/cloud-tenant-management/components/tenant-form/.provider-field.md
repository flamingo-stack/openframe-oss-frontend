# provider-field.tsx

A React form field component that renders a radio group for selecting a directory provider (e.g., identity/directory service) in the tenant creation form. It fetches the list of providers enabled for the deployment via a GraphQL query and gracefully handles loading states, locked selections, and the case where no providers are configured.

## Key Components

- **`ProviderField`** — Public export. Wraps `ProviderFieldBody` in a `LoadingSuspense` boundary so the component manages its own loading fallback.
- **`ProviderFieldBody`** — Internal component that checks `useLoadingScope()` to decide whether to render a disabled placeholder radio group (using `LOADING_OPTIONS`) or the live `ProviderOptions`.
- **`ProviderOptions`** — Fetches `directoryConnectionOptions` via `useLazyLoadQuery`, filters/orders providers using `PROVIDER_ORDER`, reports the offered providers via the `onOffered` callback, and renders a `Controller`-bound `RadioGroupBlock`. Shows a warning `Alert` if no providers are enabled.
- **`toProviderOption`** — Maps a `DirectoryProvider` enum value to a radio option (`value`, `label`, `description`) using `providerPresentation`.
- **`providerFieldQuery`** — GraphQL query fetching available `directoryConnectionOptions.providers`.
- **`ProviderFieldProps`** — Props interface: `control` (react-hook-form), `disabled`, `locked` (for existing connections), `onOffered` (callback with offered providers).

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ProviderField } from './provider-field';
import type { TenantFormData } from './tenant-form.types';

function TenantForm() {
  const { control } = useForm<TenantFormData>();

  return (
    <ProviderField
      control={control}
      locked={false}
      onOffered={(providers) => {
        console.log('Providers offered for this deployment:', providers);
      }}
    />
  );
}
```

The component should be rendered within a form that uses `react-hook-form`'s `control` object, and benefits from being inside a Relay environment provider since it uses `useLazyLoadQuery`.
