# attribution-fields.tsx

A React form component that lets a tenant directory be attributed either to a single owning customer ("sole" mode) or shared across multiple customers claimed by matching rules ("shared" mode). It drives mode-switching logic, surfaces warnings for inactive/archived customers, and renders a locked placeholder state before a connection's directory data is available.

## Key Components

- **`AttributionFields`** — Main exported component. Renders a radio group to choose between `ATTRIBUTION_MODE.SOLE` and `ATTRIBUTION_MODE.SHARED`, conditionally shows either a single `CustomerSelect` or the `SharedCustomers` list, and displays an `Alert` when any selected customer is inactive/archived.
- **`PendingAttributionFields`** — Wrapper that mounts `AttributionFields` with a throwaway `useForm` instance, `locked` set, and no connection/provider — used while the directory record hasn't loaded yet.
- **`SharedCustomers`** (internal) — Renders a dynamic list of `AttributionCustomerCard` entries via `useFieldArray`, with an "Add Customer" button; excludes already-picked organization IDs from each row's options.
- **`modeOptions` / `sharedOptionDescription` / `sharedDescription` / `sharedUnavailable` / `inactiveMessage`** (internal helpers) — Build copy for the radio options and inactive-customer warning banner based on `provider` and `readable` state.
- **`switchMode`** (internal logic) — Carries the selected customer across when switching modes only if the target field is empty, and re-triggers validation appropriately.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { AttributionFields, PendingAttributionFields } from './attribution-fields';
import { ATTRIBUTION_DEFAULT_VALUES, type AttributionFormData } from './attribution.types';

function ConnectionAttributionStep({ connectionId, provider, directoryReadable, stored }) {
  const form = useForm<AttributionFormData>({ defaultValues: ATTRIBUTION_DEFAULT_VALUES });

  if (!connectionId) {
    return <PendingAttributionFields />;
  }

  return (
    <AttributionFields
      form={form}
      connectionId={connectionId}
      provider={provider}
      readable={directoryReadable}
      stored={stored}
      busy={form.formState.isSubmitting}
    />
  );
}
```

Pass `locked` while the connection is pending consent/reconnection, and `busy` while a save is in flight—both disable all inner controls without unmounting the form.
