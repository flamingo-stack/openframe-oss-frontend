# attribution-fields.tsx

A React form component that lets a tenant admin choose how a directory connection's accounts are attributed to customers — either one customer owns the whole tenant ("sole" mode), or multiple customers share it and claim accounts via rules ("shared" mode). Built for the "Customers and attribution" step of connection setup/editing (Figma 3126-14295, 3562-27470).

## Key Components

- **`AttributionFields`** — Main exported component. Renders a radio group to pick between sole/shared attribution modes, the corresponding customer picker(s), and warnings for inactive/archived customers still bound to the directory.
- **`PendingAttributionFields`** — Renders the same UI in a locked, inert state backed by a throwaway form, used while the connection record hasn't been read yet.
- **`SharedCustomers`** (internal) — Renders a dynamic list of `AttributionCustomerCard`s via `useFieldArray`, with an "Add Customer" button and per-card removal (disabled when only one remains).
- **`modeOptions`**, **`sharedDescription`**, **`sharedUnavailable`**, **`sharedOptionDescription`**, **`inactiveMessage`**, **`inProse`** — Pure helper functions that compute copy/labels based on provider capabilities and readability state.

## Usage Example

```typescript
import { AttributionFields, PendingAttributionFields } from './attribution-fields';
import { useForm } from 'react-hook-form';
import type { AttributionFormData } from './attribution.types';

function ConnectionAttributionStep({ connection, stored }: { connection: Connection; stored: StoredAttribution }) {
  const form = useForm<AttributionFormData>({ defaultValues: stored.defaults });

  if (!connection.isRead) {
    return <PendingAttributionFields />;
  }

  return (
    <AttributionFields
      form={form}
      connectionId={connection.id}
      provider={connection.provider}
      readable={connection.readable}
      stored={stored}
      busy={connection.isSaving}
    />
  );
}
```

Key behaviors to note:
- Switching modes carries the selected customer across to the other mode only if the target field is empty.
- The `locked` prop disables all controls while still rendering the full layout (used before consent or during edit flows).
- `stored.options` provides the picker's customer map, including archived/inactive customers that remain bound but are flagged via an `Alert`.
