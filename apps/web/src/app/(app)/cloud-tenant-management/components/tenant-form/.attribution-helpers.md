## Purpose

Helper functions that bridge a directory connection's customer/attribution data between the backend GraphQL shape and the attribution form's internal representation. Handles reading stored customers into form state, converting form state back into mutation input, detecting changes, and mapping API field-level errors onto form fields.

## Key Components

- **`PickerCustomer`** — a `CustomerOption` with an optional `badge` for inactive (archived/deleted) customers.
- **`BoundCustomer` / `StoredCustomer`** — plain interfaces describing a customer bound to a directory connection, including its organization data and attribution rules.
- **`StoredAttribution`** — the result of reading stored data: form values plus a lookup map of customer options.
- **`storedOption(customer)`** — builds a `PickerCustomer` from a `BoundCustomer`, falling back to `"Unknown customer"` when the organization is missing.
- **`readAttribution(customers)`** — converts stored customers into `AttributionFormData` (detecting sole-ownership via a single `ALL` rule vs. shared mode) plus an options map.
- **`valuesClaimedElsewhere(customers, customerIndex, ruleIndex, kind)`** — returns the set of value IDs already claimed by other rules of the same `kind`, used to prevent duplicate assignment.
- **`attributionToInput(values)`** — converts form data into `DirectoryConnectionCustomerInput[]` for the save mutation.
- **`attributionChanged(values, stored)`** — compares serialized mutation input to detect if the form has meaningful changes.
- **`attributionFieldPath(field, mode)`** — maps a GraphQL `userErrors[].field` string (e.g. `customers[1].rules[0].values[2]`) to a React Hook Form `FieldPath`, or `null` if unmappable.

## Usage Example

```typescript
import {
  readAttribution,
  attributionToInput,
  attributionChanged,
  attributionFieldPath,
} from './attribution-helpers';

// Load stored customers into form state
const { values, options } = readAttribution(connection.customers);
form.reset(values);

// On submit, build mutation input
const input = attributionToInput(form.getValues());
if (attributionChanged(form.getValues(), values)) {
  await saveIntegration({ variables: { input: { customers: input } } });
}

// Map a server-side user error to a form field
for (const error of result.updateDirectoryConnection.userErrors) {
  const path = attributionFieldPath(error.field, form.getValues('mode'));
  if (path) form.setError(path, { message: error.message });
}
```
