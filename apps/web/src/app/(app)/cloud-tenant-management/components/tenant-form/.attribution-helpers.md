# attribution-helpers.ts

Helper functions that bridge a directory connection's stored customer/rule data with the attribution form state used by the integration edit forms. They convert stored GraphQL data into form values, convert form values back into mutation input, detect changes, and map server-side field errors onto form field paths.

## Key Components

- **`PickerCustomer`** — A customer option for pickers, optionally carrying a `badge` when the stored customer is no longer active.
- **`BoundCustomer`** / **`StoredCustomer`** — Plain-data representations of a customer bound to a directory connection (with or without its claiming rules), decoupled from Relay types for easier testing.
- **`StoredAttribution`** — Result of reading stored data: form `values` plus an `options` map so pickers can name customers (including archived/deleted ones) before their list has loaded them.
- **`storedOption(boundCustomer)`** — Converts a bound customer into a `PickerCustomer`, applying the inactive badge and falling back to `UNKNOWN_CUSTOMER` when the organization document is missing.
- **`readAttribution(customers)`** — Builds `StoredAttribution` from stored customers. A single customer with one `ALL` rule becomes "sole" mode; otherwise "shared" mode with per-customer rules.
- **`valuesClaimedElsewhere(customers, customerIndex, ruleIndex, kind)`** — Returns the set of value IDs already claimed by other rules of the same `kind`, used to prevent duplicate claims.
- **`attributionToInput(values)`** — Converts form values back into `DirectoryConnectionCustomerInput[]` for the save mutation.
- **`attributionChanged(values, stored)`** — Compares serialized mutation input (not raw form state) to determine if a save is needed.
- **`attributionFieldPath(field, mode)`** — Maps a GraphQL `userErrors[].field` string (e.g. `customers[1].rules[0].values[2]`) to the corresponding `react-hook-form` `FieldPath`, or `null` if unmapped.

## Usage Example

```typescript
import {
  readAttribution,
  attributionToInput,
  attributionChanged,
  attributionFieldPath,
} from './attribution-helpers';

// Load stored customers into form state
const { values: defaultValues, options } = readAttribution(storedCustomers);

// On submit, build mutation input
const input = attributionToInput(formValues);

// Skip the save if nothing effectively changed
if (!attributionChanged(formValues, defaultValues)) {
  return; // no-op
}

// Map a server error to a form field for react-hook-form's setError
const userError = result.updateDirectoryConnection.userErrors[0];
const path = attributionFieldPath(userError?.field, formValues.mode);
if (path) {
  setError(path, { message: userError.message });
}
```
