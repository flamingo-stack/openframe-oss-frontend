## use-attribution-form.ts

Custom React hook powering the "Customers and attribution" form shared by the Connect, Edit, and Reconnect flows. It wraps `react-hook-form` with Zod validation, seed-based initialization, cross-field error re-validation, and server-error placement.

## Key Components

- **`SERVER_ERROR`** — Constant marking field errors set from server-side refusals, distinguishing them from client-side validation errors.
- **`shownErrorPaths(form)`** — Computes the list of field paths (organization IDs, rule kinds/values) currently displaying a non-server validation error, used to selectively re-trigger validation.
- **`useAttributionForm(initial, seed?)`** — Main hook that:
  - Initializes the form via `useForm` with `zodResolver(attributionFormSchema)` and `onChange` mode.
  - Uses `useSeedForm` to populate the form once a `seed` record arrives (for the Edit flow, which renders before data loads), returning `seeded` — the seed snapshot the form was last filled from (or `null`).
  - Watches customer field changes and re-triggers validation (via `queueMicrotask`) only on fields currently showing errors, so fixing one clash (e.g., duplicate "All accounts" rule or a value used in two rules) clears related errors elsewhere.
  - Exposes `placeUserErrors(errors)` to map server-returned `TenantUserError` objects onto their corresponding form fields using `attributionFieldPath`.

## Usage Example

```typescript
import { useAttributionForm } from './use-attribution-form';
import type { AttributionFormData } from './attribution.types';

function AttributionFormContainer({
  initialData,
  recordSeed,
}: {
  initialData: AttributionFormData;
  recordSeed: AttributionFormData | null;
}) {
  const { form, seeded, placeUserErrors } = useAttributionForm(initialData, recordSeed);

  const onSubmit = form.handleSubmit(async (values) => {
    const result = await saveAttribution(values);
    if (result.errors) {
      placeUserErrors(result.errors);
      return;
    }
    // success handling
  });

  return (
    <form onSubmit={onSubmit}>
      {/* Controller-bound fields for customers.*.organizationId, rules, etc. */}
    </form>
  );
}
```

Pass `seed` only when the record may arrive after mount (Edit); omit or pass `null` for flows where `initial` already contains the full record (Connect, Reconnect). Use `seeded` to diff against incoming data without clobbering unsaved user edits.
