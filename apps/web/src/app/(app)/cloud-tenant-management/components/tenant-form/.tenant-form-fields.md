Renders the shared form fields for a tenant (connection) record — a responsive grid containing the "Primary Domain Name" and "Connection Name" inputs, plus an optional provider selector slot above them. Used across the tenant create/edit pages so the field layout cannot drift between them.

## Key Components

- **`TenantFormFieldsProps`** — Props interface: `control` (react-hook-form `Control<TenantFormData>`), `disabled`, `domainLocked`, `hideDomain`, and `providerField` (`ReactNode` for the New page's provider picker).
- **`FIELD_GRID`** — Tailwind class constant defining the responsive grid (single column on mobile, two columns from `md`).
- **`TenantFormFields`** — Main component. Wraps `Controller`-bound `Input` fields for `domain` and `name`, with domain normalization (trim + lowercase) on blur and conditional rendering/locking based on props.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { TenantFormFields } from './tenant-form-fields';
import type { TenantFormData } from './tenant-form.types';

function TenantCreateForm() {
  const { control } = useForm<TenantFormData>({
    defaultValues: { domain: '', name: '' },
  });

  return (
    <TenantFormFields
      control={control}
      providerField={<ProviderPickerField control={control} />}
    />
  );
}

function TenantEditForm({ control }: { control: Control<TenantFormData> }) {
  return (
    <TenantFormFields
      control={control}
      hideDomain
      domainLocked
      disabled={false}
    />
  );
}
```

**Notes:**
- When `hideDomain` is `true`, the domain field is omitted and the `name` field spans both grid columns.
- `domainLocked` disables the domain input independently of the overall `disabled` state (used once a consent link has been generated).
- Field-level errors come from react-hook-form's `fieldState.error` and are rendered by the core `Input`/`FieldWrapper` components.
