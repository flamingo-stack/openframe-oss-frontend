Renders the shared form fields for a tenant (connection) record: an optional provider slot, a domain input, and a connection name input, wired to `react-hook-form` via `Controller`. Used by both the "New Tenant" and "Edit Tenant" pages so field layout and validation stay consistent between them.

## Key Components

- **`TenantFormFieldsProps`** — props interface: `control` (react-hook-form `Control<TenantFormData>`), `disabled`, `domainLocked` (locks domain once a consent link exists), `hideDomain` (edit mode shows domain elsewhere), and `providerField` (optional `ReactNode` slot rendered above the grid, used on the New page).
- **`FIELD_GRID`** — shared Tailwind class string: single column on mobile, two columns side by side from the `md` breakpoint.
- **`TenantFormFields`** — the main component. Renders:
  - `providerField` (if provided) above the field grid.
  - A **Primary Domain Name** `Input` (skipped when `hideDomain` is true), normalizing the value to lowercase/trimmed on blur to match the schema's submit-time transform, and disabled when `domainLocked` or `disabled` is set.
  - A **Connection Name** `Input`, which spans both grid columns when the domain field is hidden.
  - Both inputs bind their `value`, `onChange`, `onBlur`, and validation `error`/`invalid` state through `Controller`'s `fieldState`.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { TenantFormFields } from './tenant-form-fields';
import type { TenantFormData } from './tenant-form.types';

function NewTenantForm() {
  const { control } = useForm<TenantFormData>({
    defaultValues: { domain: '', name: '' },
  });

  return (
    <TenantFormFields
      control={control}
      providerField={<ProviderPicker />}
    />
  );
}

function EditTenantForm({ control, locked }: { control: Control<TenantFormData>; locked: boolean }) {
  return (
    <TenantFormFields
      control={control}
      hideDomain
      domainLocked={locked}
    />
  );
}
```
