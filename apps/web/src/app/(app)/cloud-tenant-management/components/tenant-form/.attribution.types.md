## attribution.types.ts

Defines the Zod schema, types, and validation logic for the "Customers and attribution" form, which configures which customers a directory serves and the rules used to automatically attribute accounts to them (by domain, group, or org unit).

## Key Components

- **`ATTRIBUTION_MODE`** — Constant object defining the two attribution modes: `SOLE` (one customer owns all accounts) and `SHARED` (multiple customers, each claiming accounts via rules).
- **`AttributionMode`** — Union type derived from `ATTRIBUTION_MODE`.
- **`attributionFormSchema`** — Zod schema for the full form, including a `superRefine` validator that:
  - Requires `soleCustomerId` when mode is `sole`.
  - Requires a valid customer and rule `kind` for each entry when mode is `shared`.
  - Prevents `DirectoryRuleKind.ALL` from being used alongside multiple customers.
  - Ensures rule values (domains/groups/org units) aren't claimed by more than one rule across customers.
- **`AttributionFormData`**, **`AttributionCustomer`**, **`AttributionRule`**, **`RuleValue`** — Inferred TypeScript types from the schema.
- **`newRule()`** — Factory function returning a fresh, empty rule object (avoids shared array references in field arrays).
- **`ATTRIBUTION_DEFAULT_VALUES`** — Default form state (`sole` mode, no customer selected, empty customers list).

## Usage Example

```typescript
import {
  attributionFormSchema,
  ATTRIBUTION_DEFAULT_VALUES,
  ATTRIBUTION_MODE,
  newRule,
  type AttributionFormData,
} from './attribution.types';

const formData: AttributionFormData = {
  mode: ATTRIBUTION_MODE.SHARED,
  soleCustomerId: '',
  customers: [
    {
      organizationId: 'org-123',
      rules: [newRule()],
    },
  ],
};

const result = attributionFormSchema.safeParse(formData);
if (!result.success) {
  console.error(result.error.issues);
}
```

This schema is typically consumed by a form hook (e.g., `react-hook-form` with `zodResolver`) to drive the directory connection's attribution step, validating customer selection and rule-value uniqueness before submission.
