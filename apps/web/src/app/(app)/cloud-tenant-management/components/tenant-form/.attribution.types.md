This file defines the Zod schema and types for the "Customers and attribution" form, which configures how a directory's accounts are claimed by one or more customer organizations — either a single owner or multiple customers partitioned by rule (domain, group, or org unit).

## Key Components

- **`ATTRIBUTION_MODE`** — Constant object defining the two attribution modes: `SOLE` (one customer owns all accounts) and `SHARED` (multiple customers split accounts via rules).
- **`AttributionMode`** — Union type derived from `ATTRIBUTION_MODE` values.
- **`attributionFormSchema`** — Zod schema for the full form, with `superRefine` validation that:
  - Requires `soleCustomerId` when mode is `sole`.
  - Requires `organizationId` for each customer when mode is `shared`.
  - Requires a `kind` to be selected for each rule.
  - Disallows `ALL` rule kind when more than one customer exists.
  - Requires at least one value for non-`ALL` rules.
  - Ensures no domain/group/org-unit value is claimed by more than one rule across customers.
- **`AttributionFormData`** — Inferred type from `attributionFormSchema`.
- **`AttributionCustomer`**, **`AttributionRule`**, **`RuleValue`** — Derived element types for customers, rules, and rule values.
- **`newRule()`** — Factory returning a fresh, empty `AttributionRule` object (avoids shared references in field arrays).
- **`ATTRIBUTION_DEFAULT_VALUES`** — Default form state (`sole` mode, no customer selected, empty customers list).

## Usage Example

```typescript
import {
  attributionFormSchema,
  ATTRIBUTION_MODE,
  ATTRIBUTION_DEFAULT_VALUES,
  newRule,
  type AttributionFormData,
} from './attribution.types';

const formValues: AttributionFormData = {
  ...ATTRIBUTION_DEFAULT_VALUES,
  mode: ATTRIBUTION_MODE.SHARED,
  customers: [
    {
      organizationId: 'org-123',
      rules: [newRule()],
    },
  ],
};

const result = attributionFormSchema.safeParse(formValues);
if (!result.success) {
  console.error(result.error.issues);
}
```

This schema is typically consumed by a form library (e.g., React Hook Form with `zodResolver`) to drive the directory attribution UI, validating rule assignments before the "Save" action persists customer-to-account mappings.
