## use-save-integration.ts

Provides hooks and helpers for saving tenant directory integration (connection) changes via a GraphQL mutation, coordinating validation across both the main tenant form and an optional attribution form before committing updates.

## Key Components

- **`saveIntegrationMutation`** – GraphQL mutation (`updateDirectoryConnection`) that writes changed connection fields and refreshes fragments used by the form, list row, details card, and attribution rules table.
- **`integrationInput(changes, attribution, stored)`** – Builds the `UpdateDirectoryConnectionInput` payload, including `customers` only when the attribution form is present and differs from the stored values.
- **`useSubmitWithAttribution()`** – Hook returning a guarded submit function that validates the primary form and, if provided, an attribution form simultaneously, surfacing a toast on validation failure via `invalidTitle`.
- **`useSaveIntegration(connectionId, failureTitle?)`** – Hook that performs the mutation commit. Returns `{ save, isSaving }`, where `save` handles no-op saves (empty input), user errors (placed on fields and toasted), and network/API errors (toasted with a friendly message).
- **`SaveCallbacks`** – Interface for `onSaved` (success callback) and optional `placeUserErrors` (maps server-side field errors back onto the attribution form).

## Usage Example

```typescript
const submitWithAttribution = useSubmitWithAttribution();
const { save, isSaving } = useSaveIntegration(connection.id);

function handleSave() {
  submitWithAttribution(
    tenantForm,
    attributionForm,
    'Please fix the highlighted fields',
    (values, attribution) => {
      const input = integrationInput(changedFields(values), attribution, storedAttribution);
      save(input, {
        onSaved: () => toast({ title: 'Integration saved' }),
        placeUserErrors: errors => attributionForm?.setFieldErrors(errors),
      });
    },
  );
}
```

Use this hook pair whenever a connection's editable fields and/or its attribution/customer mapping need to be saved together as a single mutation, with consistent validation ordering and error presentation.
