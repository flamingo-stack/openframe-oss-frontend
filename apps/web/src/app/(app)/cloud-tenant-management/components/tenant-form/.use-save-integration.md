## use-save-integration.ts

A set of React hooks and helpers for saving directory connection (integration) updates via a GraphQL mutation, coordinating validation and submission across a main tenant form and an optional attribution (customers) sub-form, with unified error handling and toast notifications.

## Key Components

- **`integrationInput(changes, attribution, stored)`** — Builds the `UpdateDirectoryConnectionInput` payload. Includes `customers` only when an attribution form is present and its values differ from what's stored, preserving the existing customer set otherwise.
- **`useSubmitWithAttribution()`** — Returns a submit function that validates a primary form and an optional attribution form together (via `useGuardedSubmit`), ensuring both sets of validation errors surface at once before invoking the `onValid` callback.
- **`useSaveIntegration(connectionId, failureTitle?)`** — Executes the `updateDirectoryConnection` GraphQL mutation. Returns:
  - `save(input, { onSaved, placeUserErrors })` — Commits the mutation; skips the network call if `input` is empty. On success calls `onSaved`; on user errors or network error, shows a destructive toast and scrolls to the first invalid field.
  - `isSaving` — Boolean mutation-in-flight state from `useMutation`.
- **`saveIntegrationMutation`** — The GraphQL mutation document, updating the connection record and refetching fragments used by the form, list row, and attribution rules table.
- **`SAVE_FAILED`** — Default toast title used when no custom `failureTitle` is supplied.

## Usage Example

```typescript
import { useSaveIntegration, useSubmitWithAttribution, integrationInput } from './use-save-integration';

function IntegrationEditForm({ connectionId, form, attributionForm, stored }) {
  const { save, isSaving } = useSaveIntegration(connectionId);
  const submitWithAttribution = useSubmitWithAttribution();

  const handleSave = () => {
    submitWithAttribution(
      form,
      attributionForm,
      'Fix the highlighted fields',
      (values, attribution) => {
        const input = integrationInput(values, attribution, stored);
        save(input, {
          onSaved: () => console.log('Saved successfully'),
          placeUserErrors: errors => attributionForm?.setFieldErrors?.(errors),
        });
      },
    );
  };

  return (
    <button onClick={handleSave} disabled={isSaving}>
      Save
    </button>
  );
}
```
