# attribution-customer-card.tsx

Renders a single customer card within a shared directory attribution form, pairing a customer picker with a dynamic list of matching rules. A user belongs to the customer when any of its rules claims them.

## Key Components

- **`RemoveButton`** — Icon-only outline button (trash icon) used to remove a rule row or customer card, disabled when no handler is provided.
- **`RuleRow`** — Renders one rule's "Match by" `Select` and its `RuleValuesField`, side by side. Watches the rule `kind` to reset `values` on change, computes `offered` kind options via `ruleKindsFor(provider)` (preserving a stored `ALL` kind if present), and excludes values already claimed by sibling rules/customers via `valuesClaimedElsewhere`.
- **`AttributionCustomerCard`** — Top-level export. Combines a `CustomerSelect` picker (bound to `customers.${index}.organizationId`) with a `useFieldArray`-managed list of `RuleRow`s, plus an "Add Rule" button that appends `newRule()`.

## Usage Example

```typescript
import { AttributionCustomerCard } from './attribution-customer-card';
import { useForm } from 'react-hook-form';
import type { AttributionFormData } from './attribution.types';

function AttributionCardList({ connectionId, provider, options }: {
  connectionId: string;
  provider: string | null;
  options: ReadonlyMap<string, PickerCustomer>;
}) {
  const form = useForm<AttributionFormData>();

  return (
    <AttributionCustomerCard
      form={form}
      index={0}
      connectionId={connectionId}
      provider={provider}
      options={options}
      exclude={[]}
      locked={false}
      disabled={false}
      onRemove={() => {/* remove this customer card */}}
    />
  );
}
```

**Notes:**
- `locked` indicates the directory hasn't loaded yet (pickers/values render empty); `disabled` covers both `locked` and in-flight writes.
- `onRemove` should be omitted for the last remaining customer card or rule row, since at least one of each is required.
