## attribution-customer-card.tsx

Renders a single customer's attribution block within a shared directory connection form: a customer picker followed by a list of "Match by" rules that define which directory users belong to that customer. Part of the attribution form used to map directory (e.g., Entra ID, Google Workspace) users/groups to specific tenant customers.

## Key Components

- **`RemoveButton`** — Small icon-only button (trash icon) used to remove a rule row or an entire customer card; disabled when no `onClick` handler is provided or the form is locked/disabled.
- **`RuleRow`** — Renders one attribution rule: a "Match by" `Select` (rule kind, e.g., group/OU/attribute) paired with a `RuleValuesField` for picking matching values, plus a remove button. Resets the `values` field whenever the rule `kind` changes, and excludes values already claimed by other rules/customers.
- **`AttributionCustomerCard`** — Top-level exported component. Combines a `CustomerSelect` (picks the tenant organization) with a dynamic list of `RuleRow`s (via `useFieldArray`), an "Add Rule" button, and an optional "Remove customer" button.

## Usage Example

```tsx
import { AttributionCustomerCard } from './attribution-customer-card';
import { useForm } from 'react-hook-form';
import type { AttributionFormData } from './attribution.types';

function AttributionList({ options }: { options: ReadonlyMap<string, PickerCustomer> }) {
  const form = useForm<AttributionFormData>();

  return (
    <AttributionCustomerCard
      form={form}
      index={0}
      connectionId="conn-123"
      provider="entra-id"
      options={options}
      exclude={[]}
      onRemove={() => console.log('remove customer')}
      locked={false}
      disabled={false}
    />
  );
}
```

Each card manages its own `customers.{index}.organizationId` and `customers.{index}.rules` fields on the shared `form` instance, enabling multiple cards to coexist for a single directory connection, each representing a distinct customer with its own attribution rules.
