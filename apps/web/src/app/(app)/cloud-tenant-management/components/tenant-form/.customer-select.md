# customer-select.tsx

A GraphQL-connected customer picker component used in the "Customers and attribution" form. It renders a searchless `Select` dropdown over the workspace's active customers, paginating results as the user scrolls the menu, while gracefully handling loading, error, and locked (pre-data) states.

## Key Components

- **`CustomerOptionLabel`** — Renders a single customer's avatar, name (truncated), and optional badge. Reused both as a picker option and in detail-card customer lists.
- **`CustomerSelect`** — Main exported component. Wraps the field in an `ContentErrorBoundary` and `LoadingSuspense`, falling back to a locked field on error, while loading, or when `enabled={false}`.
- **`CustomerSelectShell`** — Presentational shell rendering the `Select` trigger, options, and an optional footer (used for the infinite-scroll sentinel).
- **`CustomerSelectOptions`** — Fetches paginated organizations via `useLazyLoadQuery` + `usePaginationFragment`, merges in a possibly-excluded stored customer (`withBoundOrganization`), filters out already-bound customers, and triggers `loadNext` via an `IntersectionObserver` sentinel.
- **`CustomerSelectLocked`** (internal) — Disabled fallback showing only the stored customer (`includeOrganization`) or no items, used before data loads or on failure.
- **`customerSelectQuery` / `customerSelectFragment`** — Relay GraphQL query and refetchable, paginated fragment over `organizations`.

## Usage Example

```typescript
import { CustomerSelect } from './customer-select';

function AttributionRow({ organizationId, setOrganizationId, boundCustomers }: {
  organizationId: string;
  setOrganizationId: (id: string) => void;
  boundCustomers: string[];
}) {
  return (
    <CustomerSelect
      value={organizationId}
      onChange={setOrganizationId}
      label="Customer"
      exclude={boundCustomers}
      includeOrganization={null}
      invalid={false}
    />
  );
}
```

When editing an existing record, pass the stored customer so it displays immediately, and gate rendering until it's known:

```typescript
<CustomerSelect
  value={organizationId}
  onChange={setOrganizationId}
  includeOrganization={storedCustomer}
  enabled={isStoredCustomerLoaded}
/>
```
