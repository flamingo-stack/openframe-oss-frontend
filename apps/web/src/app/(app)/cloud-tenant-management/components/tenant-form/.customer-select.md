# customer-select.tsx

A customer-picker `Select` component used within the "Customers and attribution" form flow. It presents a paginated, searchable-free list of active customer organizations fetched via Relay, with infinite scroll triggered by an `IntersectionObserver` sentinel. The component gracefully degrades to a locked/disabled state while data loads, when disabled by the caller, or if fetching fails, always ensuring the currently stored customer remains visible even if excluded from the loaded page.

## Key Components

- **`CustomerSelect`** — Public entry point. Renders a locked placeholder field when `enabled={false}`, otherwise wraps the live list in a `ContentErrorBoundary` that falls back to a locked field with an error message on failure.
- **`CustomerOptionLabel`** — Renders a single customer's avatar, truncated name, and optional warning badge. Reused both in the dropdown menu and elsewhere (e.g., detail cards).
- **`CustomerSelectShell`** — Presentational `Select` wrapper rendering the trigger, label, and list of `SelectItem` options plus an optional `footer` (used for the pagination sentinel).
- **`CustomerSelectOptions`** — Data-fetching component using `useLazyLoadQuery` + `usePaginationFragment` to load organizations, merges in the stored customer via `withBoundOrganization`, filters out excluded IDs, and wires up infinite-scroll pagination.
- **`CustomerSelectList` / `CustomerSelectBody`** — Suspense and loading-scope coordination layers that show the locked field while in a loading scope.
- **`CustomerSelectLocked`** — Disabled fallback shell showing only the stored customer (if any) or a custom placeholder/error.

## Usage Example

```typescript
import { CustomerSelect } from './customer-select';

function AttributionRow({ organizationId, setOrganizationId, excludedIds, storedCustomer }) {
  return (
    <CustomerSelect
      value={organizationId}
      onChange={setOrganizationId}
      label="Customer"
      exclude={excludedIds}
      includeOrganization={storedCustomer}
      enabled={Boolean(storedCustomer) || organizationId === ''}
      invalid={!organizationId}
      error={!organizationId ? 'Select a customer' : undefined}
    />
  );
}
```

Pass `includeOrganization` whenever editing an existing record so the currently assigned customer renders immediately, even before pagination reaches it or if it has since been archived/deleted.
