This file defines the Zod validation schema and default values for the New/Edit Tenant Integration form, covering the connection's own fields (provider, domain, name). Customer-specific attribution data is handled separately in `attribution.types.ts`.

## Key Components

- **`domainSchema`** — Validates a registrable domain string (dot-joined labels, lowercase, no protocol/path/spaces), used as the tenant segment of the Microsoft 365 admin consent URL.
- **`nameSchema`** — Validates a non-empty connection name, trimmed and capped at 100 characters.
- **`tenantFormSchema`** — The main Zod object schema combining `provider` (a `DirectoryProvider` enum value), `domain`, and `name` for creating a new tenant connection.
- **`TenantFormData`** — TypeScript type inferred from `tenantFormSchema`, representing the shape of valid form data.
- **`editTenantFormSchema`** — Variant of `tenantFormSchema` for edit mode, relaxing the `domain` field validation since edits never resend the domain (the stored value may be a GUID or empty).
- **`TENANT_FORM_DEFAULT_VALUES`** — Default form state, pre-selecting `DirectoryProvider.MICROSOFT_365` as the provider.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import {
  tenantFormSchema,
  editTenantFormSchema,
  TenantFormData,
  TENANT_FORM_DEFAULT_VALUES,
} from './tenant-form.types';

// New tenant form
const form = useForm<TenantFormData>({
  resolver: zodResolver(tenantFormSchema),
  defaultValues: TENANT_FORM_DEFAULT_VALUES,
});

// Edit tenant form (domain validation relaxed)
const editForm = useForm<TenantFormData>({
  resolver: zodResolver(editTenantFormSchema),
  defaultValues: {
    ...TENANT_FORM_DEFAULT_VALUES,
    name: existingTenant.name,
    domain: existingTenant.domainOrGuid,
  },
});
```
