## tenant-form-helpers.ts

Shared helpers for the New, Connect, Edit, and Reconnect tenant forms: a GraphQL fragment for reading a `DirectoryConnection` record, record-to-form-values mapping, a changed-fields diff utility, and a customer-picker option helper that guarantees the bound customer stays in the list.

## Key Components

- **`tenantFormHelpersFragment`** — `@inline` GraphQL fragment selecting the fields every tenant form needs (`id`, `provider`, `domain`, `name`, `consentUrl`, `connectedAt`, `customers` with attribution rules). Being `@inline` lets the create mutation select it too, so the connect step can read from the store instead of refetching.
- **`StoredConnectionFields`** — Type alias for the subset of connection data (`provider`, `domain`, `name`) needed to build form values.
- **`connectionToFormValues(connection)`** — Maps a stored connection to `TenantFormData`, falling back to `DirectoryProvider.MICROSOFT_365` if the provider is unrecognized.
- **`TenantFormRecord`** — Interface describing everything a form needs: `id`, `provider`, `consentUrl` (null = no outstanding link), `connected` (true once consent has ever completed), `values`, and `attribution`.
- **`readTenantFormRecord(ref)`** — Reads the inline fragment data into a plain `TenantFormRecord`, normalizing `consentUrl`/`connectedAt` and building attribution from bound customers and their rules.
- **`EditableField`** — Union type `'name' | 'domain'`, the fields a form may edit.
- **`changedFields(values, stored, fields)`** — Diffs form values against stored values, returning only the fields that changed (used to build minimal update mutations).
- **`withBoundOrganization(organizations, bound)`** — Ensures the currently bound customer appears in a picker's option list even if pagination hasn't reached it yet, prepending it when missing.
