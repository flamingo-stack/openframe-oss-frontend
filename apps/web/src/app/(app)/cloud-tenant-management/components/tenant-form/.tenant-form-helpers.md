# tenant-form-helpers.ts

Shared helpers for the New, Connect, Edit and Reconnect tenant forms: a common GraphQL fragment selection for a `DirectoryConnection`, the mapping from that record to form values, a changed-fields diff for edit mutations, and a customer-picker option helper.

## Key Components

- **`tenantFormHelpersFragment`** — `@inline` GraphQL fragment selecting the fields every tenant form needs (`id`, `provider`, `domain`, `name`, `consentUrl`, `connectedAt`, `customers` with attribution rules). Being `@inline` lets the create mutation select it directly so the subsequent connect step can read from the store instead of refetching.
- **`StoredConnectionFields`** — Type alias for the `provider`/`domain`/`name` subset used to derive form values.
- **`connectionToFormValues(connection)`** — Maps a stored connection to `TenantFormData`, defaulting an unknown provider to `MICROSOFT_365` via `knownValue`.
- **`TenantFormRecord`** — Normalized shape a form consumes: `id`, `provider`, `consentUrl`, `connected` (derived from `connectedAt != null`), `values`, and `attribution`.
- **`readTenantFormRecord(ref)`** — Reads the inline fragment data and builds a `TenantFormRecord`, including per-customer attribution rules read field-by-field.
- **`EditableField`** — `'name' | 'domain'` — the fields an edit form may change.
- **`changedFields(values, stored, fields)`** — Diffs current form values against stored values for the given fields, returning only the ones that changed (used to build minimal update mutations).
- **`withBoundOrganization(organizations, bound)`** — Ensures a previously-bound organization appears in a picker's option list even if pagination hasn't loaded it yet.

## Usage Example

```typescript
import {
  readTenantFormRecord,
  changedFields,
  withBoundOrganization,
} from './tenant-form-helpers';

// In a form component, after reading the connection via useFragment/readInlineData key:
const record = readTenantFormRecord(connectionRef);

const updates = changedFields(formValues, record.values, ['name', 'domain']);
if (Object.keys(updates).length > 0) {
  commitUpdateMutation({ variables: { id: record.id, ...updates } });
}

// Customer picker options, ensuring the already-bound org is visible:
const options = withBoundOrganization(pagedOrganizations, record.attribution.boundOrganization);
```
