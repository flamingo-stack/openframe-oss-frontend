# rule-values-field.tsx

A React/Relay component implementing the "Values" picker for a directory attribution rule, letting users search and select domains, groups, or org units from a connected directory provider by name.

## Key Components

- **`RuleValuesField`** — Main exported component. Resolves the picker's state based on `kind`: renders a disabled `LockedValues` field when there's no kind selected, `kind` is `ALL`, or the field is `locked`; otherwise renders a live, searchable `RuleValuesList` wrapped in a `ContentErrorBoundary` scoped to the current `kind`.
- **`LockedValues`** — A disabled `Autocomplete` showing the currently selected values with no ability to search (used when there's nothing to query yet, or on load error).
- **`RuleValuesOptions`** — The live picker: debounces user input, queries `ruleValuesFieldQuery` via `useLazyLoadQuery`, merges selected values with fresh server results (so picked chips keep their names across searches), and excludes values already claimed by other rules.
- **`RuleValuesList`** / **`RuleValuesBody`** — Suspense/loading-scope wrappers; `RuleValuesBody` renders a locked skeleton while inside a loading scope (e.g., parent Suspense fallback) to avoid firing redundant queries.
- **`ruleValuesFieldQuery`** — GraphQL query fetching `directoryRuleOptions` (id/name) filtered by `connectionId`, `kind`, `search`, and page size (`OPTIONS_LIMIT = 50`).
- **`toOption`** — Maps a `RuleValue` to an `AutocompleteOption<string>` using `ruleValueLabel` for display.

## Usage Example

```typescript
import { RuleValuesField } from './rule-values-field';
import { DirectoryRuleKind } from '@/generated/schema-enums';
import type { RuleValue } from './attribution.types';

function RuleRow() {
  const [kind, setKind] = useState<DirectoryRuleKind | ''>(DirectoryRuleKind.GROUP);
  const [values, setValues] = useState<RuleValue[]>([]);

  return (
    <RuleValuesField
      connectionId="conn-123"
      kind={kind}
      value={values}
      onChange={setValues}
      label="Values"
      exclude={new Set(['group-42'])}
      locked={false}
      disabled={false}
    />
  );
}
```

The field automatically locks when `kind` is empty or `DirectoryRuleKind.ALL`, and isolates query failures to itself via `ContentErrorBoundary`, allowing retry without affecting the rest of the form.
