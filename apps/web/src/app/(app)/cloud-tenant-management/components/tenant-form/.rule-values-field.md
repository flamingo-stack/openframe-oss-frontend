# rule-values-field.tsx

A React component that renders the "Values" picker for a directory attribution rule, letting users search and select domains, groups, or org units from a directory provider (Figma 3562-27507). It handles multiple field states: locked (no kind selected, `ALL` kind, or explicitly locked), loading, error, and the live search-enabled picker.

## Key Components

- **`RuleValuesField`** — Main exported component. Chooses between a locked, static display (`LockedValues`) and a live, searchable list (`RuleValuesList`) based on `kind` and `locked` props. Wraps the live list in a `ContentErrorBoundary` so a failed directory read only affects this field.
- **`LockedValues`** — Renders a disabled `Autocomplete` showing current values without fetching. Used when there's nothing to search (no kind, `ALL` kind, locked, loading scope, or error fallback).
- **`RuleValuesOptions`** — The real search-enabled `Autocomplete`, backed by a debounced + deferred GraphQL query (`ruleValuesFieldQuery`) that fetches options from `directoryRuleOptions`. Merges previously selected values with fresh results so labels persist across searches, and excludes values already claimed by other rules.
- **`RuleValuesList`** / **`RuleValuesBody`** — Suspense/loading-scope wrappers that render a locked skeleton while inside a loading boundary, otherwise render the live `RuleValuesOptions`.
- **`ruleValuesFieldQuery`** — GraphQL query fetching directory rule options by `connectionId`, `kind`, `search`, and `first` (page limit `OPTIONS_LIMIT = 50`).
- **`toOption`** — Converts a `RuleValue` into an `AutocompleteOption`.

## Usage Example

```typescript
import { RuleValuesField } from './rule-values-field';
import { DirectoryRuleKind } from '@/generated/schema-enums';
import type { RuleValue } from './attribution.types';

function RuleRow() {
  const [values, setValues] = useState<RuleValue[]>([]);

  return (
    <RuleValuesField
      connectionId="conn-123"
      kind={DirectoryRuleKind.GROUP}
      value={values}
      onChange={setValues}
      label="Values"
      exclude={new Set(['group-already-used'])}
      locked={false}
    />
  );
}
```

When `kind` is `''` (no selection yet) or `DirectoryRuleKind.ALL`, the field automatically renders a locked, non-interactive `Autocomplete` instead of issuing a network request.
