# tenant-record-loader.tsx

A Relay-powered data loader component for the Tenant Edit page that fetches a tenant record by ID, renders its identity card, and hands the resolved record up to a parent-owned form via a callback.

## Key Components

- **`TenantRecordState`** — Discriminated union type representing the loader's lifecycle: `{ status: 'loading' }`, `{ status: 'missing' }`, or `{ status: 'ready' } & TenantFormRecord`.
- **`TenantRecordLoader`** — Public entry component. Wraps the query logic in a `LoadingSuspense` boundary labeled "Loading tenant" and renders `TenantRecordLoaderReader`.
- **`TenantRecordLoaderReader`** (internal) — Checks `useLoadingScope()` to detect Suspense fallback/loading windows; renders a bare `TenantIdentityCard` with no data during loading, otherwise delegates to `TenantRecordQuery`.
- **`TenantRecordQuery`** (internal) — Executes `tenantRecordLoaderQuery` via `useLazyLoadQuery` with a `store-and-network` fetch policy and a `retryKey` for refetching. Memoizes the resolved `TenantRecordState` by connection identity and pushes it to the parent via `onResolved` inside a `useLayoutEffect` (ensuring the form seeds before paint when data is cached).

This component intentionally does **not** own form state — it only loads data and reports it upward; the caller is responsible for seeding the form (e.g., via `useSeedForm`).

## Usage Example

```typescript
import { useState } from 'react';
import { TenantRecordLoader, type TenantRecordState } from './tenant-record-loader';

function TenantEditPage({ tenantId }: { tenantId: string }) {
  const [record, setRecord] = useState<TenantRecordState>({ status: 'loading' });

  return (
    <>
      <TenantRecordLoader id={tenantId} onResolved={setRecord} />
      {record.status === 'ready' && (
        <TenantEditForm record={record} />
      )}
      {record.status === 'missing' && <NotFoundMessage />}
    </>
  );
}
```
