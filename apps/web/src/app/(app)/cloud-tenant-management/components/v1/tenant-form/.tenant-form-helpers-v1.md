# tenant-form-helpers-v1.ts

Shared helper functions for the New and Edit tenant forms under the `cloud-tenant-management` feature, active while the `tenant-management-v2` flag is off (file is removed when the flag is dropped). Centralizes the GraphQL fragment used to read a directory connection, the record-to-form-values mapping, a changed-fields diff for partial updates, customer-picker option handling, and invalid-submission feedback.

## Key Components

- **`tenantFormHelpersFragment`** — `@inline` GraphQL fragment on `DirectoryConnection` selecting the fields both forms need (`id`, `provider`, `domain`, `name`, `organizationId`, `consentUrl`, `connectedAt`, `organization`). Being inline lets the create mutation select it directly so the "connect" step can read from the store instead of refetching.
- **`StoredConnectionFieldsV1`** — Pick of the stored fields (`provider`, `domain`, `name`, `organizationId`) used to compare against current form values.
- **`connectionToFormValuesV1(connection)`** — Maps a stored connection into `TenantFormDataV1`, defaulting `provider` to `MICROSOFT_365` when unknown.
- **`TenantFormRecordV1`** — Normalized shape a form consumes: `id`, `provider`, `consentUrl`, `connected` (derived from `connectedAt`), `values`, and `organization` (as a `CustomerOption`).
- **`readTenantFormRecordV1(ref)`** — Reads the inline fragment data from a `tenantFormHelpersV1_connection$key` and returns a `TenantFormRecordV1`.
- **`EditableFieldV1`** — Union of fields an update mutation may send: `'name' | 'organizationId' | 'domain'`.
- **`changedFieldsV1(values, stored, fields)`** — Diffs current form values against stored values, returning only the fields that changed.
- **`withBoundOrganizationV1(organizations, bound)`** — Ensures the connection's currently bound organization appears in the picker options even though the API only returns unbound customers.
- **`invalidSubmitHandlerV1(toast, title)`** — Returns a `react-hook-form` error handler that shows a destructive toast with aggregated error messages and scrolls to the first invalid field.

## Usage Example

```typescript
import {
  readTenantFormRecordV1,
  changedFieldsV1,
  withBoundOrganizationV1,
  invalidSubmitHandlerV1,
} from './tenant-form-helpers-v1';

// Read a connection into form-ready shape
const record = readTenantFormRecordV1(connectionRef);

// Compute only what changed before sending an update
const changes = changedFieldsV1(formValues, record.values, ['name', 'organizationId', 'domain']);

// Ensure the bound organization appears in the customer select options
const options = withBoundOrganizationV1(unboundCustomers, record.organization);

// Wire up invalid-submit feedback
const onInvalid = invalidSubmitHandlerV1(toast, 'Could not save tenant');
handleSubmit(onSubmit, onInvalid)();
```
