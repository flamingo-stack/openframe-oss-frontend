# tenant-form-helpers-v1.ts

Shared helper functions for the Cloud Tenant Management "New" and "Edit" forms, used while the `tenant-management-v2` feature flag is off (this file is deleted once the flag is removed). It centralizes the record-to-form mapping, the inline GraphQL fragment both forms select, the changed-fields diff for updates, customer picker option handling, and invalid-submit feedback.

## Key Components

- **`tenantFormHelpersFragment`** — `@inline` GraphQL fragment selecting the connection fields a form needs (including `consentUrl` and `connectedAt`, which together determine whether the domain is editable and whether a consent link is outstanding).
- **`StoredConnectionFieldsV1`** — Type alias for the subset of connection fields (`provider`, `domain`, `name`, `organizationId`) used to build form values.
- **`connectionToFormValuesV1(connection)`** — Maps a stored connection to `TenantFormDataV1`, defaulting provider to `MICROSOFT_365` if unrecognized.
- **`TenantFormRecordV1`** — Interface describing everything a form needs: id, provider, consent state, connected flag, form values, and bound customer.
- **`readTenantFormRecordV1(ref)`** — Reads the inline fragment data from a Relay fragment key into a plain `TenantFormRecordV1` object (no fragment ownership required by the form).
- **`EditableFieldV1`** — Union of editable field names (`'name' | 'organizationId' | 'domain'`).
- **`changedFieldsV1(values, stored, fields)`** — Diffs current form values against stored values, returning only fields that changed (used to build minimal update mutations).
- **`withBoundOrganizationV1(organizations, bound)`** — Ensures the currently bound customer appears in the picker's options, since the API only returns unbound customers.
- **`invalidSubmitHandlerV1(toast, title)`** — Returns a `react-hook-form` error handler that shows a destructive toast and scrolls to the first invalid field.

## Usage Example

```typescript
import {
  readTenantFormRecordV1,
  changedFieldsV1,
  invalidSubmitHandlerV1,
  withBoundOrganizationV1,
} from './tenant-form-helpers-v1';

// Reading a connection record into form-ready data
const record = readTenantFormRecordV1(connectionFragmentRef);
const { values, connected, consentUrl, organization } = record;

// Computing only the changed fields before submitting an update
const updates = changedFieldsV1(
  currentFormValues,
  { name: record.values.name, organizationId: record.values.organizationId, domain: record.values.domain },
  ['name', 'organizationId'],
);

// Ensuring the bound customer appears in the select options
const options = withBoundOrganizationV1(availableCustomers, organization);

// Wiring invalid submit handling with react-hook-form
const onInvalid = invalidSubmitHandlerV1(toast, 'Could not save tenant');
handleSubmit(onValid, onInvalid)();
```
