# tenant-detail-view-v1.tsx

Legacy (v1) implementation of the cloud tenant detail view, rendered when the `tenant-management-v2` feature flag is disabled. This is the predecessor to `tenant-detail-view.tsx` and will be deleted once the flag is removed. It assembles page action buttons (Reconnect, Edit Integration) and delegates data loading to `TenantDetailContentV1`, which owns its own loading state instead of blocking the whole page.

## Key Components

- **`manageActions(id: string)`** — Builds the array of `PageActionButton` entries (Reconnect, Edit Integration) with icons and routes scoped to a specific tenant `id`.
- **`TenantDetailViewProps`** — Props interface: `id` (tenant identifier) and optional `loading` flag indicating the feature flag hasn't resolved yet.
- **`TenantDetailViewV1`** — Exported component that renders the tenant detail layout. Intentionally avoids `PageLayout` since the page title depends on fetched tenant data; only `TenantDetailContentV1` suspends on that data, following the `software-detail-view` pattern.

## Usage Example

```typescript
import { TenantDetailViewV1 } from '@/app/(app)/cloud-tenant-management/components/tenant-detail/tenant-detail-view-v1';

export default function TenantPage({ params }: { params: { id: string } }) {
  return <TenantDetailViewV1 id={params.id} />;
}
```

```typescript
// While a feature flag resolver is pending
<TenantDetailViewV1 id={tenantId} loading={isFlagLoading} />
```

Note: This component is tied to the `tenant-management-v2` flag lifecycle. Once the flag is fully rolled out, this file (along with `TenantDetailContentV1`) should be removed in favor of the v2 implementation at `tenant-detail-view.tsx`.
