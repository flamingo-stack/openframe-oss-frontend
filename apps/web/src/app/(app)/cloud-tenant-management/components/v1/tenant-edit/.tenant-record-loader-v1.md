# tenant-record-loader-v1.tsx

Legacy (v1) data-loading component for the Cloud Tenant Management Edit page, active only while the `tenant-management-v2` feature flag is off. It fetches a tenant's directory connection via GraphQL, renders the identity card, and hands the resolved record state up to its parent (which owns the form state via `useForm`). Slated for deletion once the flag is removed.

## Key Components

- **`TenantRecordLoaderV1`** — Public entry component. Wraps the query logic in a `LoadingSuspense` boundary with a "Loading tenant" label.
- **`TenantRecordLoaderReader`** — Internal wrapper that checks `useLoadingScope()` to short-circuit rendering (shows a loading-state identity card) while inside a Suspense fallback or flag transition window.
- **`TenantRecordQuery`** — Executes the `tenantRecordLoaderV1Query` GraphQL query via `useLazyLoadQuery`, derives `TenantRecordStateV1` from the response, and reports it to the parent via `onResolved` inside a `useLayoutEffect` (ensuring form seeding happens pre-paint).
- **`TenantRecordStateV1`** (type) — Discriminated union representing loader status: `'loading'`, `'missing'`, or `'ready'` (with `values` and `organization`).
- **`tenantRecordLoaderV1Query`** — GraphQL query fragment spreading `tenantFormHelpersV1_connection` and `tenantSummaryCardV1_identity`.

## Usage Example

```typescript
import { TenantRecordLoaderV1, type TenantRecordStateV1 } from './tenant-record-loader-v1';
import { useState, useCallback } from 'react';

function TenantEditPage({ tenantId }: { tenantId: string }) {
  const [recordState, setRecordState] = useState<TenantRecordStateV1>({ status: 'loading' });

  const handleResolved = useCallback((state: TenantRecordStateV1) => {
    setRecordState(state);
    // Parent owns useForm; seeds the form here via useSeedForm when state.status === 'ready'
  }, []);

  return (
    <TenantRecordLoaderV1 id={tenantId} onResolved={handleResolved} />
  );
}
```

Note: this component does not own form state—it only resolves and surfaces the tenant record. The consuming page must handle seeding the form (`useSeedForm`) based on the `onResolved` callback.
