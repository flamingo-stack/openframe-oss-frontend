Renders the tenants data table on the cloud tenant management list page using a paginated Relay GraphQL query. This is the legacy (v1) implementation used while the `tenant-management-v2` feature flag is off; it is intended to be deleted once the flag is removed.

## Key Components

- **`TenantsTableV1`** — Public entry component. Wraps `TenantsTableReader` in a `LoadingSuspense` boundary with a "Loading tenants" label, giving the table its own suspense scope.
- **`TenantsTableReader`** — Internal dispatcher. If `useLoadingScope()` reports the app is in a loading/flag window, renders `TenantsTableView` with empty rows (skeleton state); otherwise delegates to `TenantsTableQuery`.
- **`TenantsTableQuery`** — Fetches tenant data via `useLazyLoadQuery` (`tenantsTableV1Query`) and paginates with `usePaginationFragment` over `tenantsTableV1_query`. Maps GraphQL edges into `TenantRow` objects, handles the empty state (no search + no results), and wires up infinite scroll via `loadNext`.
- **`tenantsTableV1Query` / `tenantsTableFragment`** — GraphQL query and `@refetchable` connection fragment (`tenantsTableV1_directoryConnections`) fetching tenant `name`, `provider`, `domain`, `userCount`, `lastSyncAt`, `access.state`, and organization details.
- **`tenantRowHref`** — Builds the detail page link for a tenant row via `routes.cloudTenantManagement.details(row.id)`.
- **`TENANTS_PAGE_SIZE`** — Page size constant (20) used for both initial fetch and `loadNext`.

## Usage Example

```typescript
import { TenantsTableV1 } from './tenants-table-v1';

function TenantListPage() {
  const [search, setSearch] = useState('');
  const [isPending, setIsPending] = useState(false);
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <TenantsTableV1
      search={search}
      isPending={isPending}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
    />
  );
}
```

Note: this component is rendered conditionally based on the `tenant-management-v2` feature flag and is slated for removal alongside the flag.
