Renders the paginated tenants table for the Cloud Tenant Management section when the `tenant-management-v2` feature flag is off. It fetches tenant directory connections via a Relay paginated GraphQL fragment, maps them into `TenantRow` objects, and delegates rendering to the shared `TenantsTableView` component, handling loading, empty, and infinite-scroll states.

## Key Components

- **`TenantsTableV1`** — Public entry component. Wraps `TenantsTableReader` in a `LoadingSuspense` boundary with a "Loading tenants" label.
- **`TenantsTableReader`** — Internal gate that renders an empty/skeleton `TenantsTableView` while inside a loading scope (Suspense fallback or feature-flag transition window), otherwise delegates to `TenantsTableQuery`.
- **`TenantsTableQuery`** — Core data-fetching component. Runs `tenantsTableV1Query` via `useLazyLoadQuery`, then paginates through `tenantsTableV1_query` fragment with `usePaginationFragment`. Maps GraphQL edges to `TenantRow[]`, manages empty-state detection, and wires up `onLoadMore` for infinite scroll.
- **`tenantsTableV1Query`** / **`tenantsTableFragment`** — GraphQL query and `@refetchable` fragment definitions for fetching `directoryConnections` (tenant name, provider, domain, user count, last sync, access state, organization info).
- **`tenantRowHref`** — Maps a `TenantRow` to its details route via `routes.cloudTenantManagement.details(row.id)`.
- **`TENANTS_PAGE_SIZE`** — Pagination page size constant (20).

## Usage Example

```typescript
import { TenantsTableV1 } from './tenants-table-v1';

function TenantListSection() {
  const [search, setSearch] = useState('');
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <TenantsTableV1
      search={search}
      isPending={false}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
    />
  );
}
```
