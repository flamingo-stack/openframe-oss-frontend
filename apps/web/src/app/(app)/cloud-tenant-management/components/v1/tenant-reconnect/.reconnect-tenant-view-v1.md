# reconnect-tenant-view-v1.tsx

Renders the legacy (v1) "Reconnect Tenant Integration" page, shown when the `tenant-management-v2` feature flag is off. It fetches a directory connection's consent state, auto-mints a new OAuth consent link when none is outstanding, and lets the user verify the connection before returning to the tenant details page. This file is slated for deletion once the v2 flag is fully rolled out.

## Key Components

- **`reconnectTenantViewV1Query`** — GraphQL query fetching `directoryConnection` (id, provider, consentUrl) plus the `tenantSummaryCardV1_identity` fragment.
- **`ReconnectTenantContent`** — Loading-scope-aware wrapper; renders skeleton UI (`TenantIdentityCardV1` + `ConsentBlock` in loading state) while inside a loading scope, otherwise delegates to the data-fetching component.
- **`ReconnectTenantContentQuery`** — Core component that executes the Relay query with `store-or-network` fetch policy, auto-mints consent via `useStartConsent`, checks connection status via `useCheckConnection`, and renders the identity card, error states, and consent block.
- **`ReconnectTenantViewV1`** — Exported top-level page component (route: `/cloud-tenant-management/reconnect`, Figma 2108-81037), wraps content in `LoadingSuspense`.

## Usage Example

```typescript
import { ReconnectTenantViewV1 } from './reconnect-tenant-view-v1';

export default function ReconnectPage({ params }: { params: { id: string } }) {
  return <ReconnectTenantViewV1 id={params.id} />;
}
```

**Behavior notes:**
- Uses `store-or-network` fetch policy deliberately: a background refetch of `consentUrl` could otherwise overwrite the freshly minted link with a stale empty value.
- Consent minting only auto-fires when a `connectionId` exists and no `consentUrl` is already outstanding, preventing accidental invalidation of a link already shared with a customer admin.
- The "Save" action button navigates back to `routes.cloudTenantManagement.details(id)` rather than persisting new data, since the connection check already updates server state.
- Renders `NotFoundError` if the connection cannot be resolved.
