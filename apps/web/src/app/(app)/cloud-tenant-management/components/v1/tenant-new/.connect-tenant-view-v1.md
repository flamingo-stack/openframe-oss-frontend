Renders the legacy (v1) tenant connection view for a newly created tenant record, shown only while the `tenant-management-v2` feature flag is disabled.

## Key Components

- **`ConnectTenantViewV1`** — Client component that accepts a tenant `id` prop and delegates rendering to `ConnectTenantContentV1`, which handles the consent/connection hand-off flow for the newly generated tenant record.

## Usage Example

```typescript
import { ConnectTenantViewV1 } from './connect-tenant-view-v1';

// Typically rendered on the route:
// /cloud-tenant-management/new?id=<tenantId>
export default function Page({ searchParams }: { searchParams: { id: string } }) {
  return <ConnectTenantViewV1 id={searchParams.id} />;
}
```

## Notes

This component is part of the legacy tenant-management flow (v1). It is a thin wrapper that forwards the `id` prop to `ConnectTenantContentV1`, which contains the actual UI and logic for completing the tenant connection/consent process after a tenant record has been generated.

This file is marked for removal once the `tenant-management-v2` feature flag is fully rolled out and the legacy code path is no longer needed — see the companion v1 content component for the removal scope.
