# tenant-detail-title-v1.tsx

Renders the title block for a tenant's detail page under the legacy (v1) `tenant-management-v2` feature flag path. It displays the tenant's name as the page title, a back button to the tenant list, and optional per-route actions (e.g., Reconnect, Edit), all with loading-state placeholders. This component is slated for removal once the `tenant-management-v2` flag is permanently enabled.

## Key Components

- **`TENANT_DETAIL_TITLE_V1`** — Constant string label (`'Tenant'`), likely used for test IDs or static reference.
- **`TENANT_TITLE_SKELETON_LINES`** — Responsive skeleton line-count config (`phone: 2, md: 1, lg: 1`) that accounts for long tenant names wrapping on narrow viewports while loading.
- **`TenantDetailTitleV1`** — Main component. Renders a `TitleBlock` with:
  - `title` — the tenant's display name
  - `loading` — shows skeleton bar(s) in place of the title
  - `actions` — icon-button actions scoped to the route (not the record)
  - `loadingActions` — shows placeholder action buttons while the record is unconfirmed
  - A back button wired via `useSafeBack` to `routes.cloudTenantManagement.list`

## Usage Example

```typescript
import { TenantDetailTitleV1 } from './tenant-detail-title-v1';
import type { PageActionButton } from '@flamingo-stack/openframe-frontend-core/components/ui';

function TenantDetailPage({ tenant, isLoading }: { tenant?: { name: string }; isLoading: boolean }) {
  const actions: PageActionButton[] = [
    { label: 'Reconnect', icon: 'refresh-cw', onClick: () => {} },
    { label: 'Edit', icon: 'pencil', onClick: () => {} },
  ];

  return (
    <TenantDetailTitleV1
      title={tenant?.name ?? ''}
      loading={isLoading}
      actions={actions}
      loadingActions={!tenant}
    />
  );
}
```

**Note:** This is the v1 fallback rendered only while `tenant-management-v2` is disabled. New development should target the canonical `DetailTitle` component referenced in the v2 path at `apps/web/src/app/(app)/cloud-tenant-management/components/tenant-detail/tenant-detail-title.tsx`.
