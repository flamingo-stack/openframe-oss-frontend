# tenant-detail-title-v1.tsx

Renders the title block for the tenant detail page under the legacy (v1) `cloud-tenant-management` flow — active only while the `tenant-management-v2` feature flag is off. This component will be deleted once the flag is removed.

## Key Components

- **`TENANT_DETAIL_TITLE_V1`** — Constant string label (`'Tenant'`) used as an identifier for this title variant.
- **`TENANT_TITLE_SKELETON_LINES`** — Responsive skeleton line configuration (`phone: 2`, `md: 1`, `lg: 1`) accounting for long tenant names wrapping on narrow viewports.
- **`TenantDetailTitleProps`** — Props interface:
  - `title: string` — the tenant's name, used as the page title.
  - `loading?: boolean` — shows a skeleton bar while the title is loading.
  - `actions?: PageActionButton[]` — route-level actions (e.g., Reconnect, Edit).
  - `loadingActions?: boolean` — renders placeholder actions while they're not yet available.
- **`TenantDetailTitleV1`** — Function component that composes `TitleBlock` from `@flamingo-stack/openframe-frontend-core`, wiring in a safe "Back" navigation handler, title skeleton config, and icon-button-styled actions.

## Usage Example

```typescript
import { TenantDetailTitleV1 } from './tenant-detail-title-v1';

function TenantDetailPage({ tenant, isLoading, actions, actionsLoading }) {
  return (
    <TenantDetailTitleV1
      title={tenant?.name ?? ''}
      loading={isLoading}
      actions={actions}
      loadingActions={actionsLoading}
    />
  );
}
```

This component relies on `useSafeBack` to navigate back to `routes.cloudTenantManagement.list`, ensuring consistent back-button behavior across the tenant management flow. It is a stable, soon-to-be-removed counterpart to the canonical `DetailTitle` pattern used once `tenant-management-v2` is fully rolled out.
