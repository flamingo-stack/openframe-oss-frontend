# tenant-integration-section-v1.tsx

Renders the "Integration" info section for a connected tenant's detail page (legacy v1, active while the `tenant-management-v2` feature flag is off). It displays directory connection details — primary domain, directory ID, granted-by, scopes, authorized-by, and domains — fetched via its own GraphQL query so the slow `domains` field doesn't block the rest of the page from rendering.

## Key Components

- **`TenantIntegrationSectionV1`** — Public entry component; wraps the reader in a `LoadingSuspense` boundary with its own skeleton loading state.
- **`TenantIntegrationSectionReader`** — Internal component that detects loading scope (via `useLoadingScope`) and renders either a skeleton-filled `InfoSection` or delegates to the query component.
- **`TenantIntegrationSectionQuery`** — Executes the `tenantIntegrationSectionV1Query` GraphQL query (`store-and-network` fetch policy, with retry support) and renders the populated `InfoSection`.
- **`integrationRows(data, provider)`** — Builds the row definitions (label/value pairs) for `InfoSection`, handling both loaded and not-yet-loaded states.
- **`MultiLineValue`** — Helper component for rendering multiple domain names as stacked, right-aligned lines.
- **`tenantIntegrationSectionV1Query`** — GraphQL query fetching `directoryConnection` fields: `provider`, `domain`, `directoryId`, `grantedBy`, `domains`, and `access.capabilities`.

## Usage Example

```typescript
import { TenantIntegrationSectionV1 } from './tenant-integration-section-v1';

function TenantDetailPage({ tenantId, provider }: { tenantId: string; provider: string | null }) {
  return (
    <div>
      {/* ...other sections... */}
      <TenantIntegrationSectionV1 id={tenantId} provider={provider} />
    </div>
  );
}
```

The `provider` prop lets the component show provider-specific labels (e.g., directory ID label) immediately via `providerPresentation`, even before the section's own query resolves — since the parent page's record typically loads the provider value first.
