# tenant-integration-section-v1.tsx

Renders the **Integration** section (Figma 2097-140910) of a connected tenant's detail page in the legacy (v1) tenant management UI, active while `tenant-management-v2` is off. It fetches live directory-provider data (domains, scopes, directory ID) via its own GraphQL query, isolated from the page's main record so the slower `domains` field doesn't block initial page paint.

## Key Components

- **`TenantIntegrationSectionV1`** — Public component. Wraps the data-fetching reader in a `LoadingSuspense` boundary with label `"Loading integration"`.
- **`TenantIntegrationSectionReader`** — Detects whether it's inside a loading scope (`useLoadingScope`); if so, renders skeleton rows with real labels but empty values; otherwise delegates to the query component.
- **`TenantIntegrationSectionQuery`** — Executes `tenantIntegrationSectionV1Query` via `useLazyLoadQuery` (policy `store-and-network`, keyed by `useRetryKey`) and renders the populated `InfoSection`.
- **`integrationRows(data, provider)`** — Builds the `InfoSectionRow[]` array (primary domain, directory ID, granted by, scopes, authorised by, domains), handling both populated and not-yet-read states.
- **`MultiLineValue`** — Renders a right-aligned, multi-line value (used when a tenant has multiple domains).
- **`tenantIntegrationSectionV1Query`** — GraphQL query fetching `directoryConnection` fields: `provider`, `domain`, `directoryId`, `grantedBy`, `domains`, `access.capabilities`.

## Usage Example

```typescript
import { TenantIntegrationSectionV1 } from './tenant-integration-section-v1';

function TenantDetailPage({ tenantId, provider }: { tenantId: string; provider: string | null }) {
  return (
    <div>
      {/* Other tenant sections render first and paint immediately */}
      <TenantIntegrationSectionV1 id={tenantId} provider={provider} />
    </div>
  );
}
```

The component self-manages loading via `LoadingSuspense`, so callers only need to supply the tenant `id` and the (possibly `null`) `provider` string known from the parent page's own record.
