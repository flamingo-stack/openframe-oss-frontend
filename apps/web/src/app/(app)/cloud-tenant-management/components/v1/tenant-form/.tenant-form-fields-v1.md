# tenant-form-fields-v1.tsx

Renders the shared field set for the New and Edit tenant connection forms (v1), keeping both pages in sync from a single implementation. This is the legacy component rendered while the `tenant-management-v2` flag is off; it will be removed alongside the flag.

The layout places an optional provider slot above a responsive grid containing Domain Name, Connection Name, and Customer fields. Field validation errors render below each control out of normal flow via the core `FieldWrapper`, so vertical spacing stays fixed regardless of error state.

## Key Components

- **`TenantFormFieldsV1`** — The main exported component. Wires `react-hook-form`'s `Control` to three `Controller`-wrapped fields: `domain`, `name`, and `organizationId`.
- **`TenantFormFieldsProps`** — Props interface controlling disabled state, domain lock, domain visibility, injected provider field, preselected customer, and whether the customer list is queryable yet.
- **`FIELD_GRID`** — Responsive grid class constant: 1 column on mobile, 2 at `md`, 4 at `lg`.
- Domain field auto-normalizes (trim + lowercase) on blur to preview what the submit-time schema transform will send.
- Delegates customer selection to `CustomerSelectV1`, passing through `enabled` to defer loading the customer list until a record exists (Edit flow).

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { TenantFormFieldsV1 } from './tenant-form-fields-v1';
import type { TenantFormDataV1 } from './tenant-form-v1.types';

function NewTenantForm() {
  const { control } = useForm<TenantFormDataV1>();

  return (
    <TenantFormFieldsV1
      control={control}
      providerField={<ProviderPicker />}
      customersEnabled={true}
    />
  );
}

function EditTenantForm({ organization, isDomainLocked }: EditProps) {
  const { control } = useForm<TenantFormDataV1>();

  return (
    <TenantFormFieldsV1
      control={control}
      hideDomain
      domainLocked={isDomainLocked}
      includeOrganization={organization}
      disabled={isSaving}
    />
  );
}
```
