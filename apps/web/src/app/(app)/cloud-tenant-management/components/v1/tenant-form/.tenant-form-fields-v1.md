# tenant-form-fields-v1.tsx

Renders the shared form fields (Domain, Connection Name, Customer) used by both the New and Edit Cloud Tenant Management pages in the legacy (`tenant-management-v2` flag off) implementation. This component exists to keep the two pages' field layout and validation behavior in sync, since it is the single source rendered by both. It is slated for deletion once the `tenant-management-v2` flag is removed.

## Key Components

- **`TenantFormFieldsV1`** — Main exported component rendering a responsive grid (1 column on mobile, 2 at `md`, 4 at `lg`) containing:
  - An optional `providerField` slot (rendered above the grid, used by the New page's provider picker).
  - A `domain` field (`Controller`-bound `Input`), normalizing value to trimmed/lowercased on blur; can be hidden (`hideDomain`) or locked (`domainLocked`).
  - A `name` field for Connection Name.
  - An `organizationId` field rendered via `CustomerSelectV1`.
- **`TenantFormFieldsProps`** — Prop interface controlling disabled state, domain visibility/lock, provider slot content, pre-selected customer (`includeOrganization`), and whether the customer list is enabled yet (`customersEnabled`).
- **`FIELD_GRID`** — Shared Tailwind grid class constant defining the responsive column layout.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { TenantFormFieldsV1 } from './tenant-form-fields-v1';
import type { TenantFormDataV1 } from './tenant-form-v1.types';

function EditTenantForm() {
  const { control } = useForm<TenantFormDataV1>();

  return (
    <TenantFormFieldsV1
      control={control}
      hideDomain
      customersEnabled={true}
      includeOrganization={{ id: 'org_123', name: 'Acme Corp' }}
    />
  );
}
```

Pass `providerField` on the New page to render the provider picker above the field grid, and set `domainLocked` once a consent link has been generated for that domain.
