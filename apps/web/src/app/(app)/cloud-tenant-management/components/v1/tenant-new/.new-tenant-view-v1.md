# new-tenant-view-v1.tsx

Legacy (v1) view for the `/cloud-tenant-management/new` route, rendered before a tenant record exists. It presents the directory provider picker, the three tenant form fields, and a "Generate Connection Link" action. On success, the flow navigates to the `?id=` state handled by `ConnectTenantViewV1`. This component is only active while the `tenant-management-v2` flag is off and is slated for deletion once that flag is removed.

## Key Components

- **`NewTenantViewV1`** — Main exported component rendering the new-tenant creation form inside `TenantFormFrame`.
- **`useNewTenantFormV1`** — Hook supplying the form instance, creation state (`isCreating`), and the `generateLink` action.
- **`ProviderFieldV1`** — Renders the directory provider picker and reports which providers (`DirectoryProvider[]`) the deployment offers via `onOffered`.
- **`TenantFormFieldsV1`** — Renders the remaining tenant form fields alongside the provider field.
- **Offered-provider auto-select effect** — When the deployment offers exactly one provider (or a restricted set) that doesn't include the currently selected value, the form automatically selects the first offered provider and re-validates.

## Usage Example

This component is route-driven and typically not instantiated manually, but conceptually it's used as:

```typescript
import { NewTenantViewV1 } from './new-tenant-view-v1';

export default function NewTenantPage() {
  return <NewTenantViewV1 />;
}
```

Internally, the "Generate Connection Link" button is disabled until:
- The form passes validation (`isValid` from `useFormState`)
- The deployment's offered providers are known and non-empty (`offered`)
- No creation request is already in flight (`isCreating`)

```typescript
const { isValid } = useFormState({ control: form.control });
const [offered, setOffered] = useState<readonly DirectoryProvider[] | null>(null);

const canGenerate = isValid && offered !== null && offered.length > 0;
```

This file lives at `apps/web/src/app/(app)/cloud-tenant-management/components/tenant-new/new-tenant-view-v1.tsx` and mirrors the behavior of the current (non-v1) `new-tenant-view.tsx`, which supersedes it once `tenant-management-v2` is fully rolled out.
