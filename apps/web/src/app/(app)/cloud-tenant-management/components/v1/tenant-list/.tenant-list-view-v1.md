# tenant-list-view-v1.tsx

Legacy (v1) implementation of the Cloud Tenant Management list page, rendered while the `tenant-management-v2` feature flag is disabled. This component will be deleted once the flag is fully rolled out and removed. It composes a sticky search toolbar, an optional consent banner, and the tenant data table, while supporting a deferred loading state for when the parent flag resolution is still in flight.

## Key Components

- **`TenantListViewV1`** — Main exported component rendering the tenant list page via `PageLayout`, including:
  - A "Connect Tenant" split action button (`CONNECT_TENANT_ACTION`) that opens the connect flow in place or in a new tab.
  - A debounced search input synced to the URL query param via `useSearchParam` and `useApiParams`.
  - A deferred search value (`useDeferredQuery`) to avoid blocking renders while typing.
  - A sticky toolbar (`useStickyToolbar`) that collapses when the table reports it is empty.
  - `ConsentAnnouncementBanner` shown conditionally once loading completes.
  - `TenantsTableV1` wrapped in `LoadingWhen` to handle the flag's pending state.
- **`CONNECT_TENANT_ACTION`** — Static `PageActionButton` config for the connect-tenant CTA.
- **`NO_FILTERS`** — Stable `null` constant preventing unnecessary re-deferrals in `useDeferredQuery`.
- **`TenantListViewProps`** — Props interface with an optional `loading` flag indicating the parent flag/module hasn't resolved yet.

## Usage Example

```typescript
import { TenantListViewV1 } from './tenant-list-view-v1';

function CloudTenantManagementPage({ flagLoading }: { flagLoading: boolean }) {
  return <TenantListViewV1 loading={flagLoading} />;
}
```

This component is typically rendered conditionally by a parent shell based on the `tenant-management-v2` flag state, alongside its v2 counterpart. See [tenant-list/tenant-list-view.tsx](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/apps/web/src/app/(app)/cloud-tenant-management/components/tenant-list/tenant-list-view.tsx) for the active v2 implementation.
