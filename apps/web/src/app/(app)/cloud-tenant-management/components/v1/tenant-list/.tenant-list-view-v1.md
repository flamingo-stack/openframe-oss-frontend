# tenant-list-view-v1.tsx

Legacy (v1) implementation of the Cloud Tenant Management list page, active only while the `tenant-management-v2` feature flag is off. It renders a searchable, sticky-toolbar table of cloud tenants with a "Connect Tenant" action, and is slated for deletion once the flag is removed.

## Key Components

- **`TenantListViewV1`** — Main exported component. Renders the page layout, search input, consent banner, and tenant table, wiring search state to the URL via `useApiParams`/`useSearchParam` and deferring query updates with `useDeferredQuery`.
- **`TenantListViewProps`** — Props interface; accepts an optional `loading` flag used while the governing feature flag is resolving (prevents row fetches until the flag is known).
- **`CONNECT_TENANT_ACTION`** — A `PageActionButton` config for the split "Connect Tenant" button: label navigates in-place, arrow icon opens the connect route in a new tab.
- **`NO_FILTERS`** — A stable `null` constant passed to `useDeferredQuery` so the hook doesn't treat every render as a new filter set (this list has no filter funnels).

## Usage Example

```typescript
import { TenantListViewV1 } from './tenant-list-view-v1';

// Rendered conditionally based on a feature flag check upstream
function TenantPageShell({ isV2Enabled, flagLoading }: { isV2Enabled: boolean; flagLoading: boolean }) {
  if (isV2Enabled) {
    return <TenantListViewV2 />;
  }

  return <TenantListViewV1 loading={flagLoading} />;
}
```

Internally, the component manages search state and sticky toolbar positioning:

```typescript
// Search flows: local input -> debounced -> URL param -> deferred query
const { search: localSearch, setSearch: setLocalSearch, debouncedSearch } =
  useSearchParam(params.search, value => setParam('search', value));
const { deferredSearch, isPending } = useDeferredQuery(NO_FILTERS, debouncedSearch);
```
