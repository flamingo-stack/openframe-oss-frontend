# tenant-form-v1.types.ts

Zod schema and type definitions for the New/Edit Tenant Integration form, rendered under the legacy `tenant-management-v2` flag-off path. This file is slated for deletion once the `tenant-management-v2` flag fully replaces it, at which point the customer-binding fragment (`tenantCustomerFieldSchemaV1`) is isolated for easy removal in phase 2 without disturbing the rest of the schema.

## Key Components

- **`tenantCustomerFieldSchemaV1`** — Isolated schema fragment for the `organizationId` field (customer selection). Kept separate so phase 2 can delete the customer ↔ connection binding without touching other fields.
- **`tenantFormSchemaV1`** — Main form schema combining `provider`, `domain`, `name`, and the extended customer fragment. Used for the "New Tenant" flow.
- **`editTenantFormSchemaV1`** — Variant of the main schema where `domain` is relaxed to a plain string, since edit mode never submits a new domain (the stored value may be a GUID or empty).
- **`TenantFormDataV1`** — TypeScript type inferred from `tenantFormSchemaV1`.
- **`TENANT_FORM_DEFAULT_VALUES_V1`** — Default form values, pre-selecting `DirectoryProvider.MICROSOFT_365` as the first radio option per design.
- **Domain validation** — `domainSchema` enforces a registrable, dot-joined domain (no protocol/path/spaces), matching the tenant segment expected in the Microsoft 365 admin consent URL.

## Usage Example

```typescript
import {
  tenantFormSchemaV1,
  editTenantFormSchemaV1,
  TENANT_FORM_DEFAULT_VALUES_V1,
  type TenantFormDataV1,
} from './tenant-form.types';

// New tenant form
const result = tenantFormSchemaV1.safeParse({
  provider: 'MICROSOFT_365',
  domain: 'contoso.com',
  name: 'Contoso Connection',
  organizationId: 'org_123',
});

// Edit tenant form (domain not required to be a valid FQDN)
const editResult = editTenantFormSchemaV1.safeParse({
  provider: 'MICROSOFT_365',
  domain: '', // or stored GUID
  name: 'Contoso Connection',
  organizationId: 'org_123',
});

// Initialize a form with defaults
const defaults: TenantFormDataV1 = TENANT_FORM_DEFAULT_VALUES_V1;
```
