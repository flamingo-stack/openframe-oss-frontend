Renders the tenant details page's summary card (v1, legacy behind `tenant-management-v2` flag), displaying a GraphQL-backed tenant's provider, domain, customer, user count, access status, and sync timestamps, with built-in loading-state skeletons.

## Key Components

- **`TenantIdentityCardV1`** — Compact single-row card (provider + domain name) used on the Edit / Reconnect flows. Accepts a `tenantSummaryCardV1_identity$key` Relay fragment reference.
- **`TenantSummaryCardV1`** — Full two-row card for the tenant details page, showing provider, domain, customer (with avatar), user count, access status tag, connected date, and last read timestamp. Accepts a `tenantSummaryCardV1_connection$key` Relay fragment reference.
- **`ProviderCell`** (internal) — Renders the provider logo and label, falling back to skeleton when provider is `null`.
- **`ConnectedCell`** (internal) — Formats and renders the `connectedAt` timestamp as separate date/time parts.
- **`LABELS`** — Static label constants used for both loaded and skeleton states.
- GraphQL fragments: `tenantSummaryCardV1_identity` (provider, domain) and `tenantSummaryCardV1_connection` (full tenant connection data including organization, access state, sync times).

Both components use `useLoadingScope` and `LoadingWhen` to automatically render skeleton placeholders while data is unresolved, ensuring the card's structure (row/cell count) stays identical between loading and loaded states to avoid layout shift.

## Usage Example

```typescript
import { TenantSummaryCardV1, TenantIdentityCardV1 } from './tenant-summary-card-v1';

// Full summary card on the tenant details page
function TenantDetailsPage({ connectionRef }) {
  return <TenantSummaryCardV1 connection={connectionRef} />;
}

// Compact identity card on Edit / Reconnect flows
function TenantReconnectPage({ identityRef }) {
  return <TenantIdentityCardV1 connection={identityRef} />;
}

// Both support a loading scope with no data yet
function TenantSkeletonPreview() {
  return <TenantSummaryCardV1 connection={null} />;
}
```
