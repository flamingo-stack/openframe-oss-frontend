## provider-field-v1.tsx

Renders the directory provider radio group for the legacy (v1) tenant creation form, fetching enabled providers via a Relay query and reporting the available set back to the parent via a callback. It is a deprecated counterpart to the current implementation and is removed once the `tenant-management-v2` feature flag is fully rolled out.

## Key Components

- **`providerFieldV1Query`** — GraphQL query fetching `directoryConnectionOptions.providers` for the workspace.
- **`toProviderOption(provider)`** — Maps a `DirectoryProvider` enum value to a radio option (`value`, `label`, `description`) using `providerPresentation`.
- **`ProviderOptions`** — Internal component that loads providers via `useLazyLoadQuery`, filters/orders them by `PROVIDER_ORDER`, notifies `onOffered`, and renders a `Controller`-bound `RadioGroupBlock`. Shows a warning `Alert` if no providers are enabled.
- **`ProviderFieldV1`** — Public export; wraps `ProviderFieldBody` in `LoadingSuspense` to handle the async data fetch.
- **`ProviderFieldBody`** — Switches between a disabled placeholder radio group (`LOADING_OPTIONS`, covering all known providers) when inside a loading scope, and the real `ProviderOptions` otherwise.
- **`LOADING_OPTIONS`** — Precomputed static option list for all providers in `PROVIDER_ORDER`, used as the loading-state skeleton.
- **`ProviderFieldProps`** — Props interface: `control` (react-hook-form `Control<TenantFormDataV1>`), `disabled`, `locked` (true once a connection already fixes the provider), and `onOffered` callback.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ProviderFieldV1 } from './provider-field-v1';
import type { TenantFormDataV1 } from './tenant-form-v1.types';

function TenantForm() {
  const { control } = useForm<TenantFormDataV1>();

  return (
    <ProviderFieldV1
      control={control}
      locked={false}
      onOffered={(providers) => {
        console.log('Providers offered to this workspace:', providers);
      }}
    />
  );
}
```

Note: this component must be rendered within a Relay environment provider, since it uses `useLazyLoadQuery` to fetch data on mount.
