# provider-field-v1.tsx

Renders the directory provider selection radio group for the tenant creation form (v1), fetching the set of enabled providers via a GraphQL query and presenting a loading placeholder while data resolves. This is a legacy component tied to Main's `apps/web/src/app/(app)/cloud-tenant-management/components/tenant-form/provider-field.tsx`, active only while the `tenant-management-v2` flag is off; it is slated for deletion once the flag is removed.

## Key Components

- **`providerFieldV1Query`** — GraphQL query fetching `directoryConnectionOptions.providers` (the providers enabled for the current workspace).
- **`toProviderOption(provider)`** — Maps a `DirectoryProvider` enum value to a radio option (`value`, `label`, `description`) using `providerPresentation`.
- **`ProviderOptions`** — Internal component that loads provider data, filters/orders it via `PROVIDER_ORDER`, reports the offered providers via `onOffered`, and renders a `Controller`-bound `RadioGroupBlock`. Shows a warning `Alert` if no providers are enabled.
- **`ProviderFieldV1`** — Public export; wraps `ProviderFieldBody` in `LoadingSuspense` with a "Loading providers" label.
- **`ProviderFieldBody`** — Switches between a disabled placeholder radio group (`LOADING_OPTIONS`, built from all known providers) when inside a loading scope, and the live `ProviderOptions` otherwise.
- **`ProviderFieldProps`** — Props interface: `control` (react-hook-form `Control`), `disabled`, `locked` (true once a provider is already set on an existing connection), `onOffered` callback.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ProviderFieldV1 } from './provider-field-v1';
import type { TenantFormDataV1 } from './tenant-form-v1.types';

function TenantForm() {
  const { control } = useForm<TenantFormDataV1>();

  return (
    <ProviderFieldV1
      control={control}
      disabled={false}
      locked={false}
      onOffered={(providers) => console.log('Enabled providers:', providers)}
    />
  );
}
```

Within a Suspense/loading boundary, `ProviderFieldV1` automatically renders a disabled radio group listing all known providers instead of fetching data, avoiding redundant network calls during page-level loading states.
