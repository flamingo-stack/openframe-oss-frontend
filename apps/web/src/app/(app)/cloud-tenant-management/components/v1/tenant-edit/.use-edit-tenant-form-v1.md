## Overview

React hook that powers the Edit Tenant form (v1/legacy path, active only while the `tenant-management-v2` feature flag is off). It seeds a `react-hook-form` instance from previously loaded tenant data, submits only the changed fields via a Relay mutation, and handles success/error toasts plus navigation back to the tenant details page. This file is slated for deletion once the v2 flag fully replaces it.

## Key Components

- **`useEditTenantFormV1(id, stored)`** — Main hook. Accepts the tenant `id` and the currently `stored` tenant data (or `null`), returning `{ form, isSubmitting, handleSave }`.
- **`updateMutation`** — GraphQL mutation (`useEditTenantFormV1UpdateMutation`) that updates a `DirectoryConnection` and refetches the shared `tenantFormHelpersV1_connection` fragment so the page, list row, and details card stay in sync.
- **`handleSave`** — Guards against double-submits using `inFlightRef`, then triggers `form.handleSubmit`, routing to either the valid or invalid submit handler.
- **`onValid`** — Computes the diff via `changedFieldsV1` (only `name` and `organizationId` are mutable), skips the network call if nothing changed, and commits the mutation otherwise.
- Relies on shared helpers: `useSeedForm`, `invalidSubmitHandlerV1`, `changedFieldsV1`, `getRelayErrorMessage`, `safeBackOrReplace`, and `editTenantFormSchemaV1` / `TENANT_FORM_DEFAULT_VALUES_V1`.

## Usage Example

```typescript
import { useEditTenantFormV1 } from './use-edit-tenant-form-v1';

function EditTenantPage({ tenantId, storedTenant }: { tenantId: string; storedTenant: TenantFormDataV1 | null }) {
  const { form, isSubmitting, handleSave } = useEditTenantFormV1(tenantId, storedTenant);

  return (
    <form onSubmit={e => e.preventDefault()}>
      <input {...form.register('name')} />
      <button type="button" disabled={isSubmitting} onClick={handleSave}>
        Save
      </button>
    </form>
  );
}
```

**Note:** This hook is deprecated and tied to the legacy `tenant-management-v2` flag being disabled. New development should target the v2 equivalent at `apps/web/src/app/(app)/cloud-tenant-management/components/tenant-edit/use-edit-tenant-form.ts`.
