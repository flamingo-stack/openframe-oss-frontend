# use-edit-tenant-form-v1.ts

React hook powering the legacy (v1) Edit Tenant form, used while the `tenant-management-v2` feature flag is off. It seeds a validated `react-hook-form` instance from pre-fetched tenant data and submits only the changed fields via a Relay mutation, updating the shared connection record across the page, list row, and details card. This file is slated for deletion once the v2 flag is fully rolled out.

## Key Components

- **`useEditTenantFormV1(id, stored)`** — Main hook accepting the tenant's `id` and its currently `stored` form data (or `null`). Returns `{ form, isSubmitting, handleSave }`.
- **`updateMutation`** — GraphQL mutation (`useEditTenantFormV1UpdateMutation`) that calls `updateDirectoryConnection`, requesting the updated connection fragment and any `userErrors`.
- **`onValid`** — Internal submit handler that diffs changed fields (`name`, `organizationId`), skips the network call if nothing changed, and shows success/error toasts.
- **`handleSave`** — Guarded submit trigger using a ref (`inFlightRef`) to prevent duplicate submissions before Relay's `isInFlight` state updates.
- **`SAVE_FAILED`** — Shared toast title constant for failure cases.

## Usage Example

```typescript
import { useEditTenantFormV1 } from './use-edit-tenant-form-v1';

function EditTenantPageV1({ tenantId, initialData }: { tenantId: string; initialData: TenantFormDataV1 | null }) {
  const { form, isSubmitting, handleSave } = useEditTenantFormV1(tenantId, initialData);

  return (
    <form onSubmit={e => e.preventDefault()}>
      <input {...form.register('name')} disabled={isSubmitting} />
      <button type="button" onClick={handleSave} disabled={isSubmitting}>
        Save
      </button>
    </form>
  );
}
```

**Notes:**
- Only `name` and `organizationId` fields are diffed and sent on update; provider/domain fields are retained in form state but not submitted.
- On successful save (or a no-op when nothing changed), the user is routed back via `safeBackOrReplace` to the tenant details page.
- Validation errors trigger `invalidSubmitHandlerV1`, surfacing a "Cannot save yet" toast.
