# use-connect-tenant-form-v1.ts

React hook powering the "Connect Tenant" form step (v1, legacy path behind the `tenant-management-v2` flag) for an existing tenant directory connection record. It handles saving edited fields (name/organization), regenerating the consent link after a domain change, and tracking live connection verification state.

## Key Components

- **`useConnectTenantFormV1(record)`** — Main hook accepting a `TenantFormRecordV1`. Wires up:
  - `useForm` with `zodResolver(tenantFormSchemaV1)` for validated form state
  - `updateMutation` (GraphQL) to persist changed fields via `updateDirectoryConnection`
  - `useStartConsent` to mint a fresh consent URL when generating a link
  - `useCheckConnection` to poll/verify whether the tenant is actually connected
- **`SAVE_FIELDS` / `GENERATE_FIELDS`** — Constants defining which fields are diffed and sent for the "Save" vs. "Generate Link" actions (the latter also includes `domain`).
- **Returned API**:
  - `form` — react-hook-form instance
  - `editingDomain` / `editDomain` — toggles domain-edit mode (`undefined` once connected, since domain becomes immutable)
  - `generateLink()` — validates, saves changed fields, mints a new consent link
  - `handleSave()` — validates, saves changed fields, navigates to the tenant details page
  - `isGenerating` / `isSaving` / `isMinting` / `mintFailed` / `retryMint` — loading/error states
  - `check` — live connection verification result

## Usage Example

```typescript
import { useConnectTenantFormV1 } from './use-connect-tenant-form-v1';

function ConnectTenantStep({ record }: { record: TenantFormRecordV1 }) {
  const {
    form,
    editingDomain,
    editDomain,
    generateLink,
    handleSave,
    isSaving,
    isGenerating,
  } = useConnectTenantFormV1(record);

  return (
    <form onSubmit={e => e.preventDefault()}>
      {/* form fields bound via `form.register` / `form.control` */}
      {editingDomain ? (
        <button onClick={generateLink} disabled={isGenerating}>
          Generate Link
        </button>
      ) : (
        <>
          <button onClick={handleSave} disabled={isSaving}>
            Save
          </button>
          {editDomain && <button onClick={editDomain}>Edit Domain</button>}
        </>
      )}
    </form>
  );
}
```

Note: a duplicate submission while the mutation is in flight is prevented via an internal `inFlightRef`, guarding against double-clicks before loading state updates.
