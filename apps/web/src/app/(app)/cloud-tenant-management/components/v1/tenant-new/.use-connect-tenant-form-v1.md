# use-connect-tenant-form-v1.ts

React hook powering the "Connect" step of the tenant-new flow (legacy v1, active while `tenant-management-v2` is off). It manages a `react-hook-form` instance over an existing directory connection record, lets the user save changed fields (name/organization) or edit the domain and regenerate a consent link, and tracks connection status via a readability check.

## Key Components

- **`useConnectTenantFormV1(record: TenantFormRecordV1)`** — Main hook; returns form state and action handlers for the connect step.
- **`updateMutation`** — GraphQL mutation (`useConnectTenantFormV1UpdateMutation`) that updates a `DirectoryConnection` and refreshes the shared `tenantFormHelpersV1_connection` fragment used by list, detail, and form views.
- **`SAVE_FIELDS` / `GENERATE_FIELDS`** — Field sets (`name`, `organizationId`, optionally `domain`) that define what each action is allowed to persist.
- **Returned API**:
  - `form` — the `react-hook-form` instance (Zod-validated via `tenantFormSchemaV1`).
  - `editingDomain` / `editDomain` — toggles domain editing; `undefined` once the connection is already `connected` (domain becomes immutable).
  - `generateLink()` — submits changed fields (including domain) and mints a fresh consent URL via `useStartConsent`.
  - `handleSave()` — submits changed name/organization fields, shows a toast, and navigates to the connection's details page.
  - `isGenerating`, `isSaving`, `isMinting`, `mintFailed`, `retryMint` — loading/error state for consent minting and mutation.
  - `check` — live connection-readability check from `useCheckConnection`.

## Usage Example

```typescript
import { useConnectTenantFormV1 } from './use-connect-tenant-form-v1';
import type { TenantFormRecordV1 } from '../tenant-form/tenant-form-helpers-v1';

function ConnectTenantStep({ record }: { record: TenantFormRecordV1 }) {
  const {
    form,
    editingDomain,
    editDomain,
    generateLink,
    handleSave,
    isSaving,
    isGenerating,
    check,
  } = useConnectTenantFormV1(record);

  return (
    <form onSubmit={e => e.preventDefault()}>
      {/* bind form.register fields: name, organizationId, domain */}

      {editingDomain ? (
        <button type="button" onClick={generateLink} disabled={isGenerating}>
          Generate link
        </button>
      ) : (
        <>
          <button type="button" onClick={handleSave} disabled={isSaving}>
            Save
          </button>
          {editDomain && (
            <button type="button" onClick={editDomain}>
              Edit Domain
            </button>
          )}
        </>
      )}
    </form>
  );
}
```
