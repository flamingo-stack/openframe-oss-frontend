# customer-select-v1.tsx

Renders the "Select Customer" dropdown field used in the New/Edit tenant connection forms. It shows customer organizations not yet bound to a connection, loaded via a paginated Relay fragment with infinite scroll, and gracefully handles loading, error, and locked (disabled) states. This is the legacy implementation used while `tenant-management-v2` is off; it is removed when the flag is deleted.

## Key Components

- **`CustomerSelectV1`** — Public entry component. Switches between a locked placeholder (when `enabled` is `false`), an error boundary fallback, and the live paginated list.
- **`CustomerSelectShell`** — Presentational wrapper around the core `Select` UI, rendering options plus an optional `footer` (used for the infinite-scroll sentinel).
- **`CustomerOptionLabel`** — Renders a customer's avatar and truncated name inside each select item.
- **`CustomerSelectOptions`** — Fetches and paginates customer organizations via `useLazyLoadQuery`/`usePaginationFragment`, merges in an already-bound `includeOrganization`, and triggers `loadNext` via an `IntersectionObserver` sentinel.
- **`CustomerSelectList`** / **`CustomerSelectBody`** — Suspense and loading-scope wrappers that show the locked field while data is still resolving.
- **`CustomerSelectLocked`** — Disabled, option-less fallback shell shown pre-load or on error.
- **GraphQL**: `customerSelectV1Query` and `customerSelectFragment` (refetchable as `customerSelectV1PaginationQuery`) fetch `directoryConnectionOrganizations` in pages of 20 (`CUSTOMER_PAGE_SIZE`).

## Usage Example

```typescript
import { CustomerSelectV1 } from './customer-select-v1';

function TenantForm() {
  const [organizationId, setOrganizationId] = useState('');

  return (
    <CustomerSelectV1
      value={organizationId}
      onChange={setOrganizationId}
      invalid={!organizationId}
      error={!organizationId ? 'Customer is required' : undefined}
      // Edit mode: pre-existing bound customer, list loads only once known
      includeOrganization={existingCustomer}
      enabled={isEditDataReady}
    />
  );
}
```

Use `enabled={false}` (or omit `includeOrganization` in create flows) to show the locked field until prerequisite data resolves, preventing premature queries.
