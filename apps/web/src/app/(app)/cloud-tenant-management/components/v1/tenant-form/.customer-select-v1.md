# customer-select-v1.tsx

Renders the "Select Customer" field used by the New/Edit Tenant forms, implemented as a paginated Relay-backed `Select` (no search box) that lists customers not yet bound to a connection, loading more as the user scrolls. This is the legacy (v1) implementation, active while the `tenant-management-v2` feature flag is off; it is removed along with the flag.

## Key Components

- **`CustomerSelectV1`** — Public entry point. Gates rendering on the `enabled` prop (locked field until the bound customer is known), wraps data loading in a `ContentErrorBoundary` with a disabled "Couldn't load customers" fallback, and delegates to `CustomerSelectList`.
- **`CustomerSelectList` / `CustomerSelectBody`** — Internal wrappers that suspend on data loading (`LoadingSuspense`) and respect `useLoadingScope()` to render a locked placeholder while an ancestor scope is still loading.
- **`CustomerSelectOptions`** — Fetches paginated organization data via `useLazyLoadQuery` + `usePaginationFragment`, merges in the already-bound organization via `withBoundOrganizationV1`, and attaches an `IntersectionObserver` sentinel to trigger `loadNext` for infinite scroll.
- **`CustomerSelectShell`** — Presentational `Select`/`SelectTrigger`/`SelectContent` wrapper, accepting pre-resolved `options` and an optional `footer` (scroll sentinel).
- **`CustomerSelectLocked`** — Disabled fallback shell shown before data is available.
- **`CustomerOptionLabel`** — Renders a `SquareAvatar` + truncated name for each customer option.
- **GraphQL artifacts** — `customerSelectV1Query` and `customerSelectFragment` (Relay `@refetchable` pagination fragment, page size `CUSTOMER_PAGE_SIZE = 20`).

## Usage Example

```typescript
import { CustomerSelectV1 } from './customer-select-v1';

function TenantForm({ organizationId, boundCustomer, listReady }) {
  return (
    <CustomerSelectV1
      value={organizationId}
      onChange={setOrganizationId}
      enabled={listReady}
      includeOrganization={boundCustomer}
      invalid={!!errors.organizationId}
      error={errors.organizationId}
    />
  );
}
```

**Notes:**
- Pass `includeOrganization` in edit flows so the currently bound customer still appears even though the API only returns unbound organizations.
- Set `enabled={false}` to keep the field locked until the bound customer resolves (e.g., during an edit form's initial load).
- When there are no selectable customers and no more pages, the field auto-disables with placeholder `"No customers available"`.
