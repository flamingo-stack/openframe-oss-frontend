# use-new-tenant-form-v1.ts

React hook powering the legacy (v1) "New Tenant Connection" form in cloud tenant management. It validates and submits the provider/domain/name/customer fields via a GraphQL mutation that both creates the directory connection and mints its connection link, then navigates to the connect step using the newly created ID. This file is rendered only while the `tenant-management-v2` feature flag is off and is slated for deletion alongside it.

## Key Components

- **`createMutation`** — GraphQL mutation (`useNewTenantFormV1CreateMutation`) that calls `createDirectoryConnection`, returning the new connection's `id` and spreading the `tenantFormHelpersV1_connection` fragment; its Relay `updater` links the created record into the store under `directoryConnection` so the next page reads from cache instead of refetching.
- **`useNewTenantFormV1()`** — Main hook export. Sets up:
  - A `react-hook-form` instance (`form`) using `zodResolver(tenantFormSchemaV1)` with `mode: 'onChange'` for live validation feedback.
  - `commitCreate` / `isCreating` from `useMutation` to run the create mutation.
  - An `inFlightRef` guard to prevent duplicate submissions from rapid double-clicks before `isCreating` updates.
  - `onValid` — submit handler that commits the mutation, shows a destructive toast on `userErrors` or network error, and otherwise calls `router.replace` to `routes.cloudTenantManagement.new({ id })`.
  - `generateLink` — the exposed submit trigger, guarded by `inFlightRef`, using `invalidSubmitHandlerV1` to toast validation errors.
- Returns `{ form, isCreating, generateLink }` for the form component to bind inputs, disable the submit button, and trigger submission.

## Usage Example

```typescript
import { useNewTenantFormV1 } from './use-new-tenant-form-v1';

function NewTenantFormV1() {
  const { form, isCreating, generateLink } = useNewTenantFormV1();

  return (
    <form onSubmit={e => { e.preventDefault(); generateLink(); }}>
      <input {...form.register('domain')} placeholder="Domain" />
      <input {...form.register('name')} placeholder="Connection name" />
      {/* additional provider/customer fields */}
      <button type="submit" disabled={isCreating}>
        Generate Connection Link
      </button>
    </form>
  );
}
```
