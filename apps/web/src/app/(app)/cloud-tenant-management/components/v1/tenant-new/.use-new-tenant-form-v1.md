## Purpose

React hook powering the legacy (v1) "New Tenant" form at `apps/web/src/app/(app)/cloud-tenant-management/components/tenant-new/`. It wraps a GraphQL mutation that creates a directory connection and navigates to the connect step on success. This file is only rendered while the `tenant-management-v2` feature flag is off and is slated for deletion once that flag is removed.

## Key Components

- **`useNewTenantFormV1()`** — Main hook exported for the New Tenant form. Returns:
  - `form` — `react-hook-form` instance validated via `tenantFormSchemaV1` (Zod), using `onChange` mode so field errors clear live and `isValid` stays accurate for the submit button.
  - `isCreating` — Relay mutation in-flight boolean.
  - `generateLink()` — Guarded submit trigger (click handler) for the "Generate Connection Link" button.
- **`createMutation`** — GraphQL mutation (`useNewTenantFormV1CreateMutation`) that creates a `DirectoryConnection` and returns its id plus fragment data for the connect step.
- **`inFlightRef`** — A `useRef` guard preventing duplicate submissions between click and `isCreating` becoming `true`.
- **`CREATE_FAILED`** — Shared toast title for mutation failures (user errors or network errors).

## Behavior Notes

- On successful creation, the Relay store `updater` links the new connection under `directoryConnection` keyed by `connectionId`, so the next page can read it from the store instead of re-fetching.
- On success, `router.replace` navigates to `routes.cloudTenantManagement.new({ id })`, making the created record resumable via reload or browser Back.
- On user errors or mutation errors, a destructive toast is shown using `getRelayErrorMessage` for friendly error text.
- Invalid form submissions trigger `invalidSubmitHandlerV1` to surface a toast instead of calling the mutation.

## Usage Example

```typescript
import { useNewTenantFormV1 } from './use-new-tenant-form-v1';

function NewTenantFormV1() {
  const { form, isCreating, generateLink } = useNewTenantFormV1();

  return (
    <form>
      {/* form fields bound via form.register / form.control */}
      <button type="button" disabled={isCreating || !form.formState.isValid} onClick={generateLink}>
        Generate Connection Link
      </button>
    </form>
  );
}
```
