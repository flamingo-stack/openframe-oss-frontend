# tenant-page-shell.tsx

A client-side layout wrapper for tenant detail pages that applies consistent page padding and wraps content in an error boundary, ensuring a page title remains visible even if the content inside throws an error.

## Key Components

- **`TenantPageShellProps`** — Interface defining the component's props:
  - `title`: string shown in the error fallback state
  - `errorMessage`: message displayed when an error is caught
  - `resetKey`: optional key (e.g., a record ID) that resets the error boundary when it changes, allowing navigation between records to clear a previously tripped error
  - `children`: the page content to render inside the shell

- **`TenantPageShell`** — The main exported component. It renders a padded container (`px-[var(--spacing-system-l)] pb-[var(--spacing-system-l)]`) and wraps `children` in a `ContentErrorBoundary`, using `tenantPageErrorFallback` to produce a titled error state if rendering fails.

## Usage Example

```typescript
import { TenantPageShell } from './tenant-page-shell';

export default function DeviceDetailPage({ params }: { params: { id: string } }) {
  return (
    <TenantPageShell
      title="Device Details"
      errorMessage="Unable to load device information."
      resetKey={params.id}
    >
      <DeviceDetailContent deviceId={params.id} />
    </TenantPageShell>
  );
}
```

When navigating between different device IDs, passing `params.id` as `resetKey` ensures that if one device's content throws an error, switching to another device automatically resets the error boundary instead of persisting the failure state.
