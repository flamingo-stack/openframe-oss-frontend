# use-tenant-management-gate.ts

React hooks that gate access to the Cloud Tenant Management module using feature flags, returning a tri-state value (`'on'`, `'off'`, `'loading'`) to control UI rendering without flashing 404s during flag resolution.

## Key Components

- **`useTenantManagementGate()`** — Primary gate for all routes under `/cloud-tenant-management`. Wraps `useFeatureFlagGate('tenant-management')`. The sidebar's "Integrations" nav item reads the same flag via `NavigationFlags` in `app-layout.tsx`, keeping nav visibility and route access in sync.
- **`useTenantManagementV2Gate()`** — Gate for Tenant Management Phase 2. Resolves to `'on'` only when **both** `tenant-management` and `tenant-management-v2` flags are `'on'`. If either flag is still resolving, returns `'loading'`; otherwise returns `'off'` (falling back to the v1 screens/operations). Both flags are driven by a single backend answer, so they never diverge.

## Usage Example

```typescript
import { useTenantManagementGate, useTenantManagementV2Gate } from '@/hooks/use-tenant-management-gate';

function CloudTenantManagementPage() {
  const gate = useTenantManagementGate();

  if (gate === 'loading') return <PageSkeleton />;
  if (gate === 'off') return <NotFoundPage />;

  return <TenantManagementDashboard />;
}

function TenantDetailsView() {
  const v2Gate = useTenantManagementV2Gate();

  if (v2Gate === 'loading') return <SectionSkeleton />;

  return v2Gate === 'on' ? <TenantDetailsV2 /> : <TenantDetailsV1 />;
}
```

**Note:** Always handle the `'loading'` state explicitly—never treat it as `'off'`—to avoid rendering a 404 while the flag is still resolving.
