# tenant-form-frame.tsx

A shared layout wrapper component that provides a consistent frame (title bar, back navigation, and action buttons) for all tenant integration forms — New, Connect, Edit, and Reconnect.

## Key Components

- **`GENERATE_LINK_LABEL`** — Exported constant string used as the label for the button that generates a connection's consent link, shared between the New form and the Connect form's domain edit view.
- **`SAVE_PLACEHOLDER`** — A disabled `PageActionButton` placeholder (`"Save Integration"`, accent variant) shown in the title bar before a form has loaded its own live save handler/state.
- **`TenantFormFrame`** — The main component that renders `PageLayout` with:
  - A `title` prop for the page heading.
  - A `backButton` wired to `useSafeBack`, defaulting to `routes.cloudTenantManagement.list`.
  - An `actions` array (defaults to `[SAVE_PLACEHOLDER]`) rendered in `"primary-buttons"` style.
  - `children` rendered as the form body.

## Usage Example

```typescript
import { TenantFormFrame, SAVE_PLACEHOLDER } from './tenant-form-frame';
import { useState } from 'react';

function NewTenantIntegrationForm() {
  const [isSaving, setIsSaving] = useState(false);

  const saveAction = {
    label: 'Save Integration',
    variant: 'accent' as const,
    disabled: isSaving,
    onClick: async () => {
      setIsSaving(true);
      // perform save
      setIsSaving(false);
    },
  };

  return (
    <TenantFormFrame title="New Integration" actions={[saveAction]}>
      <form>{/* form fields */}</form>
    </TenantFormFrame>
  );
}

// Before the live save handler is ready, fall back to the placeholder:
function LoadingState() {
  return (
    <TenantFormFrame title="Edit Integration" actions={[SAVE_PLACEHOLDER]}>
      <p>Loading record…</p>
    </TenantFormFrame>
  );
}
```

This component centralizes layout logic so individual form pages only need to supply the title, children, and (once ready) a live action button, avoiding duplicated back-navigation and title-bar logic across the integration form flows.
