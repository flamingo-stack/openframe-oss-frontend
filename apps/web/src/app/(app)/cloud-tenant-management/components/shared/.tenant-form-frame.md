# tenant-form-frame.tsx

Provides a shared page layout wrapper for all tenant integration forms (New, Connect, Edit, Reconnect), ensuring consistent title bar, back navigation, and save action placement across these views.

## Key Components

- **`GENERATE_LINK_LABEL`** — Exported constant string label used by forms that mint a connection's consent link (used in New form and Connect form's domain edit button).
- **`SAVE_PLACEHOLDER`** — Exported default `PageActionButton` config: a disabled "Save Integration" button shown before a form can actually save (e.g., no record yet, or a pre-connect step). Live forms override this with their own handler and state.
- **`TenantFormFrame`** — The main component. Wraps form content in a `PageLayout` with:
  - A `title` prop for the page heading.
  - A live "Back" button (via `useSafeBack`) that navigates to the tenant management list, functional even while the record is loading.
  - An `actions` array (defaults to `[SAVE_PLACEHOLDER]`) rendered as primary buttons in the title bar.
  - `children` rendered as the form body.

## Usage Example

```typescript
import { TenantFormFrame, SAVE_PLACEHOLDER } from './tenant-form-frame';
import type { PageActionButton } from '@flamingo-stack/openframe-frontend-core/components/ui';

function NewTenantIntegrationForm() {
  // Before the record exists, use the disabled placeholder
  return (
    <TenantFormFrame title="New Integration">
      <IntegrationFields />
    </TenantFormFrame>
  );
}

function EditTenantIntegrationForm() {
  const liveSaveAction: PageActionButton = {
    label: 'Save Integration',
    variant: 'accent',
    disabled: false,
    onClick: handleSave,
  };

  return (
    <TenantFormFrame title="Edit Integration" actions={[liveSaveAction]}>
      <IntegrationFields />
    </TenantFormFrame>
  );
}
```

## Notes

- Requires `'use client'` directive — this is a client-side React component.
- Depends on `useSafeBack` hook and `routes.cloudTenantManagement.list` for back navigation.
- Designed to be composed by specific form components, which supply their own `title`, `actions`, and field content via `children`.
