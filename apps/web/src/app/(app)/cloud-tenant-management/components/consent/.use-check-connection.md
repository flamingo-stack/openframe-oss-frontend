Hook that drives the "Check Connection" action on directory connection pages (New, details, Reconnect), issuing a GraphQL mutation to probe connectivity and tracking the verdict of the most recent attempt.

## Key Components

- **`checkMutation`** — GraphQL mutation (`checkDirectoryConnection`) that re-probes a tenant's directory connection and returns updated `access` state along with consent-related fragment data.
- **`CheckedAccess`** — Type alias for the `access` object returned by the mutation (state + capabilities).
- **`CheckVerdict`** — Discriminated union representing the outcome of the last check: either `{ kind: 'answered', access }` or `{ kind: 'failed', message }`.
- **`useCheckConnection(connectionId)`** — Hook returning:
  - `check()` — triggers the mutation for the given `connectionId`, guards against concurrent calls, and shows a toast on failure or unreadable access state.
  - `isChecking` — boolean mutation-in-flight flag.
  - `verdict` — the latest `CheckVerdict` or `null` if no check has run.
  - `reset()` — clears the verdict and invalidates any in-flight probe (used when the underlying connection link changes, e.g. after editing the domain).

The hook uses an internal attempt counter (`attemptRef`) to ensure stale responses from superseded probes (e.g., after `reset()` is called mid-flight) are discarded rather than overwriting the current verdict.

## Usage Example

```typescript
import { useCheckConnection } from './use-check-connection';

function ConnectionCard({ connectionId }: { connectionId: string | null }) {
  const { check, isChecking, verdict, reset } = useCheckConnection(connectionId);

  return (
    <div>
      <button onClick={check} disabled={isChecking}>
        {isChecking ? 'Checking...' : 'Check Connection'}
      </button>

      {verdict?.kind === 'answered' && (
        <p>State: {verdict.access.state}</p>
      )}
      {verdict?.kind === 'failed' && (
        <p>Error: {verdict.message}</p>
      )}

      {/* Call reset() when the connection link changes, e.g. after editing the domain */}
      <button onClick={reset}>Reset Check</button>
    </div>
  );
}
```
