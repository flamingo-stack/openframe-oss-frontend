# consent-link-panel.tsx

Renders the admin consent hand-off UI card used during tenant connect/reconnect flows — displaying the consent instruction, a read-only consent link field with copy/open actions, and a "Check Connection" control that surfaces live probe verdicts. Supports a locked loading-scope presentation while the underlying record is still resolving.

## Key Components

- **`ConsentMode`** — Type union (`'new' | 'reconnect' | 'details'`) controlling which copy and controls (e.g., "Edit Domain") are shown.
- **`ConsentPanelProps`** — Props interface: `provider`, `consentUrl`, `mode`, `checking`, `verdict`, `onCheck`, `onEditDomain`, `disabled`.
- **`ConsentLinkPanel`** — Main exported component. Renders:
  - Section header with optional "Edit Domain" link (new mode only).
  - Instruction text (skeleton-aware via `LoadingParagraph`), switching between connect vs. reapprove copy.
  - Read-only `Input` showing the consent URL, with copy and external-open icon buttons (respecting `useSameWindowLinks` for app-shell webviews).
  - "Check Connection" `Button` plus a live typing indicator while probing, and a result `Tag` (connected/not) once a verdict resolves.
  - Contextual hint or error message based on the last check's outcome.

Relies on `useLoadingScope`, `useCopyToClipboard`, `useSameWindowLinks`, and presentation helpers (`providerPresentation`, `checkResultTag`, `isReadable`, `accessStateHint`) from the tenant presentation utils.

## Usage Example

```typescript
import { ConsentLinkPanel } from './consent-link-panel';
import { useCheckConnection } from './use-check-connection';

function TenantConnectStep({ provider, consentUrl }: { provider: string; consentUrl: string | null }) {
  const { checking, verdict, check } = useCheckConnection();

  return (
    <ConsentLinkPanel
      provider={provider}
      consentUrl={consentUrl}
      mode="new"
      checking={checking}
      verdict={verdict}
      onCheck={check}
      onEditDomain={() => console.log('unlock domain field')}
    />
  );
}
```

In `details` mode (e.g., viewing a revoked tenant), omit `onEditDomain` — the panel renders without the header row and shows a tailored placeholder when `consentUrl` is `null`.
