# consent-link-panel.tsx

A React component rendering the consent hand-off card for OAuth-style tenant integrations — displaying the admin consent instructions, a read-only copyable/openable link field, and a "Check Connection" action with live probe feedback. Implements the Figma frames for the connect/reconnect/details flows of directory provider onboarding.

## Key Components

- **`ConsentMode`** — Type union (`'new' | 'reconnect' | 'details'`) controlling which instruction copy and UI affordances (e.g., Edit Domain) are shown.
- **`ConsentPanelProps`** — Props interface: `provider`, `consentUrl`, `mode`, `checking`, `verdict`, `onCheck`, `onEditDomain`, `disabled`.
- **`ConsentLinkPanel`** — The main exported component. Renders:
  - A loading-aware instruction paragraph (`LoadingParagraph`) based on `mode`.
  - A read-only `Input` showing the consent URL with copy and open-in-new-tab actions (respects same-window web view constraints via `useSameWindowLinks`).
  - A "Check Connection" `Button` with a typing indicator while `checking`, and a result `Tag` once a `verdict` resolves.
  - Conditional hint/error text depending on connection state (`accessStateHint`, `verdict.kind === 'failed'`).

## Usage Example

```typescript
import { ConsentLinkPanel } from './consent-link-panel';
import { useCheckConnection } from './use-check-connection';

function ReconnectStep({ provider, consentUrl }: { provider: string; consentUrl: string | null }) {
  const { checking, verdict, check } = useCheckConnection(provider);

  return (
    <ConsentLinkPanel
      provider={provider}
      consentUrl={consentUrl}
      mode="reconnect"
      checking={checking}
      verdict={verdict}
      onCheck={check}
    />
  );
}
```

For the "new" flow, pass `onEditDomain` to let users unlock the domain field before a link is minted:

```typescript
<ConsentLinkPanel
  provider="google"
  consentUrl={consentUrl}
  mode="new"
  checking={checking}
  verdict={verdict}
  onCheck={check}
  onEditDomain={() => setDomainLocked(false)}
/>
```

Rendering is loading-scope aware via `useLoadingScope()` — wrap the component in a loading boundary to automatically show skeleton instruction text and disable all interactive controls until the underlying record resolves.
