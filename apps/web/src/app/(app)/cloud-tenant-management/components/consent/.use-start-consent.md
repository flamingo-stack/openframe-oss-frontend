# use-start-consent.ts

A React hook that mints a directory consent link via GraphQL mutation, used to initiate or refresh a connection's consent flow (e.g., for OAuth-style directory authorization).

## Key Components

- **`useStartConsent(connectionId, options)`** — Main hook that wraps a Relay mutation to request a consent link for a given connection.
  - `connectionId: string | null` — the target connection to mint consent for.
  - `options.autoMintWhen?: boolean` — when `true`, automatically mints a link once on mount (gated on subscription state and guarded against double-firing in React StrictMode via `startedRef`).
  - Returns `{ mint, isMinting, mintFailed }`:
    - `mint(onMinted?)` — triggers the mutation; invokes `onMinted` callback on success.
    - `isMinting` — boolean loading state from the underlying mutation.
    - `mintFailed` — boolean indicating the last mint attempt failed.
- **`startConsentMutation`** — GraphQL mutation (`startDirectoryConsent`) that returns the updated `connection` (with `id`, `consentUrl`) and `userErrors`.
- **`MINT_FAILED`** — Exported constant string used as the toast title on failure.

## Usage Example

```typescript
import { useStartConsent } from './use-start-consent';

function ConsentCard({ connectionId }: { connectionId: string }) {
  const { mint, isMinting, mintFailed } = useStartConsent(connectionId);

  return (
    <div>
      <button onClick={() => mint()} disabled={isMinting}>
        {isMinting ? 'Generating link...' : 'Generate consent link'}
      </button>
      {mintFailed && <p>Failed to create link. Please retry.</p>}
    </div>
  );
}

// Auto-mint on a dedicated consent request page
function ConsentRequestPage({ connectionId }: { connectionId: string }) {
  const { isMinting, mintFailed } = useStartConsent(connectionId, { autoMintWhen: true });

  if (isMinting) return <p>Preparing your consent link...</p>;
  if (mintFailed) return <p>Something went wrong.</p>;
  return <p>Check your consent link.</p>;
}
```

Errors (either GraphQL `userErrors` or network errors) surface via a destructive toast and set `mintFailed` to `true`. A new successful mint resets `mintFailed` and replaces any existing consent URL in place.
