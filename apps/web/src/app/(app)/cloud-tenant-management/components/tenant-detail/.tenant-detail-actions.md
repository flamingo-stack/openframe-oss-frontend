# tenant-detail-actions.tsx

Defines action buttons and dropdown menu configurations for the cloud tenant management detail page, supporting both page-level action buttons (Reconnect, Edit) and a contextual "…" overflow menu with state-dependent options (Pause/Resume, Reconnect, Disconnect, Delete).

## Key Components

- **`reconnectAction(id)`** — Builds a `PageActionButton` linking to the tenant reconnect route, used when a tenant's connection needs re-authorization.
- **`editAction(id)`** — Builds a `PageActionButton` linking to the tenant edit route.
- **`tenantMenuGroups(options)`** — Main export that generates the `ActionsMenuGroup[]` array for the overflow menu. Behavior differs based on the `readable` flag:
  - **Unreadable tenant** (partial/failed consent): shows only Reconnect and Delete.
  - **Readable tenant**: shows Pause/Resume Sync (toggled via `paused`), Reconnect, Disconnect, and Delete.
- **`TenantMenuOptions`** (interface) — Props for `tenantMenuGroups`, including `id`, `readable`, `paused`, `busy`, and the `onPause`/`onResume` callbacks.
- Internal helpers `deleteGroup(id)` and `reconnectItem(id)` build reusable menu entries shared across both menu states.

## Usage Example

```typescript
import { reconnectAction, editAction, tenantMenuGroups } from './tenant-detail-actions';

const pageButtons = [editAction(tenant.id), reconnectAction(tenant.id)];

const menuGroups = tenantMenuGroups({
  id: tenant.id,
  readable: tenant.readable,
  paused: tenant.syncPaused,
  busy: isMutating,
  onPause: () => pauseSync(tenant.id),
  onResume: () => resumeSync(tenant.id),
});

// Pass `pageButtons` to a page header component and `menuGroups`
// to an overflow/actions-menu component on the tenant detail page.
```

Routes are resolved via `routes.cloudTenantManagement` from `@/lib/routes`, and icons come from `@flamingo-stack/openframe-frontend-core/components/icons-v2`.
