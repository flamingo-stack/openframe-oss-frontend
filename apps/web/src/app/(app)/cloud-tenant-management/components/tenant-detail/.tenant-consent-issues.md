# tenant-consent-issues.tsx

Renders the list of consent issues from a tenant directory's last consent attempt, surfacing provider errors (with code and correlation ID) or tier-settling states. Mirrors the structure of native provider error pages (Entra/Google): a lead message with an expandable "Troubleshooting details" section for secondary diagnostic data.

## Key Components

- **`TenantConsentIssues`** — Main exported component. Reads a `tenantConsentIssues_connection$key` Relay fragment and renders a list of consent issues, one per card-like list item, each with tier/kind tags and a human-readable message. Returns `null` when there are no issues (component is optional and hidden during loading via `data-loading-optional`).
- **`TroubleshootingDetails`** — Internal collapsible accordion showing error code (with link to provider's error lookup page), correlation ID (copyable), and timestamp. Includes a "Copy Details" button that copies a full plain-text report to the clipboard for support tickets.
- **`tenantConsentIssuesFragment`** — GraphQL fragment (`tenantConsentIssues_connection`) declaring the fields needed: `provider`, `domain`, and `lastConsentInfo` (with `occurredAt` and `issues`).

## Usage Example

```typescript
import { TenantConsentIssues } from './tenant-consent-issues';

function TenantSummaryCard({ connectionRef }: { connectionRef: tenantConsentIssues_connection$key }) {
  return (
    <div className="flex flex-col gap-4">
      {/* Other tenant summary fields */}
      <TenantConsentIssues connection={connectionRef} />
    </div>
  );
}
```

This component relies on `useFragment` to resolve data from a parent Relay query that spreads the `tenantConsentIssues_connection` fragment on a `DirectoryConnection` type. It depends on helper utilities (`consentIssueCode`, `consentIssueTag`, `consentIssueReport`, `formatConnectedAt`, `providerErrorLookupUrl`) from `tenant-presentation` for formatting and link generation, and on `useCopyToClipboard`, `useIsDesktopShell`, and `useSameWindowLinks` hooks for clipboard and navigation behavior that differs between web and desktop shell contexts.
