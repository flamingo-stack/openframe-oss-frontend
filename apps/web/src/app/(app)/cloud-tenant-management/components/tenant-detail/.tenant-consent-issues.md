## tenant-consent-issues.tsx

Renders the list of consent/authorization problems recorded in a tenant directory connection's last consent attempt (e.g., provider errors, partial permission grants), displayed below the tenant summary card. Each issue shows its tag, message, and an expandable "Troubleshooting details" section with error code, correlation ID, timestamp, and a one-click copy-to-clipboard report for support tickets.

## Key Components

- **`TenantConsentIssues`** — Main exported component. Reads a `tenantConsentIssues_connection$key` Relay fragment reference, returns `null` when there's no last consent info or no issues, and otherwise renders a labeled section listing each issue (tier tag, kind tag, message, optional troubleshooting details).
- **`TroubleshootingDetails`** (internal) — Collapsible `Accordion` showing error code (with optional external lookup link to the provider's error reference), correlation ID (with copy button), and formatted timestamp. Includes a "Copy Details" button that copies a full plain-text report.
- **`tenantConsentIssuesFragment`** — GraphQL fragment (`tenantConsentIssues_connection`) declaring the `provider`, `domain`, and `lastConsentInfo` (with `occurredAt` and `issues`) fields consumed by this component.

Relies on helper utilities from `tenant-presentation` (`consentIssueCode`, `consentIssueReport`, `consentIssueTag`, `formatConnectedAt`, `providerErrorLookupUrl`) and hooks (`useCopyToClipboard`, `useIsDesktopShell`, `useSameWindowLinks`) to format data and adapt link behavior between desktop shell and browser contexts.

## Usage Example

```typescript
import { graphql, useLazyLoadQuery } from 'react-relay';
import { TenantConsentIssues } from './tenant-consent-issues';

function TenantSummaryCard() {
  const data = useLazyLoadQuery(
    graphql`
      query TenantSummaryCardQuery($id: ID!) {
        directoryConnection(id: $id) {
          ...tenantConsentIssues_connection
        }
      }
    `,
    { id: 'connection-id' }
  );

  return (
    <div>
      {/* ...other summary card content... */}
      <TenantConsentIssues connection={data.directoryConnection} />
    </div>
  );
}
```

The component is self-contained: pass the Relay fragment reference and it handles rendering (or hiding itself entirely) based on whether consent issues exist.
