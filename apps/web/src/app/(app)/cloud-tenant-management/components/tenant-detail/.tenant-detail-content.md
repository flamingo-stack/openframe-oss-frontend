## tenant-detail-content.tsx

Renders the main content of a tenant's detail page: title, actions, summary card, and connected sections (integration, attribution rules, licences), or a consent hand-off flow for tenants not yet connected. Handles loading states via a dedicated loading scope and isolates section failures with per-section error boundaries.

## Key Components

- **`TenantDetailContent`** — Top-level export. Wraps the content in `LoadingSuspense`, gated by the `loading` prop (module flag not yet resolved) and by Relay suspense while the query is in flight.
- **`TenantDetailContentReader`** — Branches on `useLoadingScope()`: renders skeleton title/card/sections when loading, otherwise delegates to `TenantDetailContentQuery`.
- **`TenantDetailContentQuery`** — Fetches `tenantDetailContentQuery` via `useLazyLoadQuery`, resolves connection state (`isReadable`, `isSyncPaused`), wires up `useCheckConnection` and `useTenantSync`, and renders:
  - `NotFoundError` if the connection is null (unknown id)
  - `TenantDetailTitle` with contextual actions/menu (`editAction`, `reconnectAction`, `tenantMenuGroups`)
  - `TenantSyncPausedNotice`, `TenantSummaryCard`, `TenantConsentAlert`, `TenantConsentIssues`
  - For readable (connected) tenants: `TenantIntegrationSection`, `TenantAttributionRules`, `TenantLicensesSection`, each wrapped in its own `ContentErrorBoundary`
  - For unreadable (not-yet-connected) tenants: `ConsentBlock` in `"details"` mode
- **`tenantDetailContentQuery`** — GraphQL query fetching `directoryConnection` by `id`, with fragment spreads for child components.
- **`loadingMenu`** — Builds an inert, busy menu for the loading title state.

## Usage Example

```typescript
import { TenantDetailContent } from './tenant-detail-content';

function TenantDetailPage({ params }: { params: { id: string } }) {
  const moduleFlagLoading = useFeatureFlagLoading(); // example upstream loading signal

  return (
    <TenantDetailContent id={params.id} loading={moduleFlagLoading} />
  );
}
```

The component requires no manual Relay setup from callers—it self-contains fetching, loading skeletons, not-found handling, and per-section error recovery. Pass only the tenant `id` and an optional `loading` flag when an upstream feature flag hasn't resolved yet.
