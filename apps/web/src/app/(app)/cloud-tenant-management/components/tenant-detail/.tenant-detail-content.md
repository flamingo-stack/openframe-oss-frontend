Client component that renders the main content of a tenant's detail page: title, actions, summary, and (depending on connection state) either the integration/attribution/licensing sections or a consent hand-off block for tenants that still need to connect.

## Key Components

- **`TenantDetailContent`** — Public entry point. Wraps the reader in `LoadingSuspense` so, while the module's "loading" flag is unresolved, it renders a loading scope instead of fetching.
- **`TenantDetailContentReader`** — Branches on `useLoadingScope()`. In a loading scope it renders skeleton title/card/sections with inert actions; otherwise it delegates to `TenantDetailContentQuery`.
- **`TenantDetailContentQuery`** — Fires `tenantDetailContentQuery` via `useLazyLoadQuery`, handles the `NotFoundError` case (null `directoryConnection`), and renders the full page: title with contextual actions/menu, sync-paused notice, summary card, consent alert/issues, and either the connected sections (integration, attribution rules, licenses — each wrapped in its own `ContentErrorBoundary`) or a `ConsentBlock` when the tenant isn't yet readable.
- **`tenantDetailContentQuery`** — GraphQL query fetching the tenant's `directoryConnection` by id, including fragment spreads consumed by child components.
- **`loadingMenu(id)`** — Builds an inert, busy menu for the loading state.

## Usage Example

```typescript
import { TenantDetailContent } from './tenant-detail-content';

function TenantDetailPage({ params }: { params: { id: string } }) {
  const moduleFlagLoading = useSomeFeatureFlagLoading();

  return <TenantDetailContent id={params.id} loading={moduleFlagLoading} />;
}
```

Each content section (`TenantIntegrationSection`, `TenantAttributionRules`, `TenantLicensesSection`) is isolated in its own `ContentErrorBoundary`, so a failure fetching one section (e.g., licenses) shows a `SectionLoadError` with retry, without taking down the rest of the page.
