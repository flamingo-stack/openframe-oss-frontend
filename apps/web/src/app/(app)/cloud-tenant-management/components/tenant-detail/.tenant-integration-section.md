## tenant-integration-section.tsx

Renders the "Integration" section of a connected tenant's detail page (Figma 2097-140910), displaying provider-specific directory metadata (primary domain, directory ID, grantor, scopes, authorizer, and domains). This component manages its own GraphQL fetch and loading boundary independently from the host page, since the `domains` field is a live provider read and typically the slowest field on the page.

## Key Components

- **`TenantIntegrationSection`** — Public entry point; wraps the data-fetching component in a `LoadingSuspense` boundary with its own fallback skeleton.
- **`TenantIntegrationSectionReader`** — Detects whether it's rendering inside a loading scope (e.g. the page's own skeleton state) and short-circuits to a placeholder `InfoSection` if so.
- **`TenantIntegrationSectionQuery`** — Executes the `tenantIntegrationSectionQuery` GraphQL query via `useLazyLoadQuery` and renders the populated `InfoSection`.
- **`integrationRows(data, provider)`** — Builds the ordered list of `InfoSectionRow` entries (primary domain, directory ID, granted by, scopes, authorised by, domains), falling back to empty/skeleton values when no data is available yet.
- **`wrapping(...lines)`** — Helper producing a right-aligned, word-wrapping custom `InfoSectionRow` value from one or more lines of text.
- **`WrappingValue`** — Internal component rendering multi-line, break-friendly text (breaks after `.` and `@` characters so domains/emails wrap cleanly).
- **`breakAtParts(text)`** — Inserts `<wbr>` break opportunities after dots and at-signs in a string.
- **`SCOPES_NOT_READ`** / **`NOT_READ`** — Skeleton/empty placeholder values shown before the query resolves.

## Usage Example

```typescript
import { TenantIntegrationSection } from './tenant-integration-section';

function TenantDetailPage({ tenantId, providerName }: { tenantId: string; providerName: string | null }) {
  return (
    <div className="flex flex-col gap-6">
      {/* Other tenant sections render first and independently */}
      <TenantIntegrationSection id={tenantId} provider={providerName} />
    </div>
  );
}
```

The `provider` prop should come from the host page's already-loaded record (if available), so that loading-state labels (e.g. "Directory ID" vs. a provider-specific label) are accurate even before this component's own query resolves.
