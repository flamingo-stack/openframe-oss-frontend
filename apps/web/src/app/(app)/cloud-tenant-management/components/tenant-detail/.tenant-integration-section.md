## tenant-integration-section.tsx

Renders the "Integration" info section on a connected tenant's detail page, showing directory connection metadata (primary domain, directory ID, grantor, granted scopes, authorizer, and associated domains). It fetches its own GraphQL data independently of the host page so the slowest field (`domains`, a live provider read) doesn't block the rest of the page from painting, and shows its own skeleton while loading.

## Key Components

- **`tenantIntegrationSectionQuery`** — GraphQL query fetching `directoryConnection` fields (provider, domain, directoryId, grantedBy, domains, access.capabilities) by connection ID.
- **`TenantIntegrationSection`** — Public component; wraps the query-driven reader in a `LoadingSuspense` boundary so loading is scoped locally.
- **`TenantIntegrationSectionReader`** — Detects whether it's inside a loading scope (skeleton render) or should fetch live data, and dispatches accordingly.
- **`TenantIntegrationSectionQuery`** — Executes the Relay query via `useLazyLoadQuery` and renders the populated `InfoSection`.
- **`integrationRows(data, provider)`** — Builds the ordered list of `InfoSectionRow` entries (primary domain, directory ID, granted by, scopes, authorised by, domains), using empty/skeleton placeholders when data isn't yet available.
- **`wrapping(...lines)`** — Helper producing a right-aligned, word-wrapping custom `InfoSectionRow` value; exported for reuse.
- **`WrappingValue`** / **`breakAtParts`** — Internal rendering helpers that insert `<wbr>` break opportunities after dots/at-signs so long domains/emails wrap gracefully instead of truncating.
- **`SCOPES_NOT_READ`** / **`NOT_READ`** — Placeholder values shown while data hasn't loaded, including a responsive skeleton for the scopes row.

## Usage Example

```typescript
import { TenantIntegrationSection } from './tenant-integration-section';

function TenantDetailPage({ tenantId, directoryProvider }: { tenantId: string; directoryProvider: string | null }) {
  return (
    <div>
      {/* other sections render first and don't wait on this one */}
      <TenantIntegrationSection id={tenantId} provider={directoryProvider} />
    </div>
  );
}
```

The component manages its own Suspense boundary, so no additional wrapping is required by the parent page. Pass `provider` from the page's already-loaded record (or `null` before it resolves) so loading-state labels remain accurate.
