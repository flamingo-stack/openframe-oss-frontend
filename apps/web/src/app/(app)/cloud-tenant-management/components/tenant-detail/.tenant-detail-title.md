# tenant-detail-title.tsx

Client-side React component that renders the title block for a tenant detail page, including a back button, loading skeleton states, and configurable action buttons/menus. It wraps the shared `TitleBlock` component from `@flamingo-stack/openframe-frontend-core` with tenant-specific defaults.

## Key Components

- **`TENANT_DETAIL_TITLE`** — Constant string (`'Tenant'`) used as a default/reference title elsewhere in the app.
- **`TENANT_TITLE_SKELETON_LINES`** — Responsive skeleton line configuration (`phone`, `md`, `lg`) used while the tenant name is loading, accounting for longer tenant names wrapping on smaller screens.
- **`TenantDetailTitleProps`** — Props interface:
  - `title: string` — the tenant's display name.
  - `loading?: boolean` — shows a skeleton bar instead of the title.
  - `actions?: PageActionButton[]` — primary action buttons (e.g., Edit, Reconnect).
  - `menuActions?: ActionsMenuGroup[]` — overflow "…" menu, used to collapse actions on phone viewports.
  - `loadingActions?: boolean` — renders action placeholders while the record is unconfirmed.
- **`TenantDetailTitle`** — Main exported component. Uses `useSafeBack` to navigate back to `routes.cloudTenantManagement.list`, then renders `TitleBlock` with tenant-specific skeleton sizing and a `menu-primary` actions variant.

## Usage Example

```typescript
import { TenantDetailTitle } from '@/components/tenant-detail-title';

function TenantDetailPage({ tenant, isLoading, actionsReady }) {
  return (
    <TenantDetailTitle
      title={tenant?.name ?? ''}
      loading={isLoading}
      loadingActions={!actionsReady}
      actions={[
        { label: 'Edit', onClick: () => console.log('edit') },
        { label: 'Reconnect', onClick: () => console.log('reconnect') },
      ]}
      menuActions={[
        { label: 'More', items: [{ label: 'Delete', onClick: () => console.log('delete') }] },
      ]}
    />
  );
}
```

This component is intended for use within the tenant management section of the app, specifically on the tenant detail route defined in `routes.cloudTenantManagement`.
