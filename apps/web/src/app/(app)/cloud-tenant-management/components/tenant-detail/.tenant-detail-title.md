# tenant-detail-title.tsx

A client component rendering the title block for a tenant detail page, combining the tenant's name, a back-navigation button, and configurable page actions into the shared `TitleBlock` layout.

## Key Components

- **`TENANT_DETAIL_TITLE`** — Exported constant string (`'Tenant'`) used as a default/fallback title label elsewhere in the app.
- **`TENANT_TITLE_SKELETON_LINES`** — Internal constant defining how many skeleton loading lines to render per breakpoint (`phone: 2`, `md: 1`, `lg: 1`), accounting for longer tenant names wrapping on small screens.
- **`TenantDetailTitleProps`** — Props interface:
  - `title: string` — the tenant's display name.
  - `loading?: boolean` — shows a skeleton bar instead of the title while the record loads.
  - `actions?: PageActionButton[]` — primary action buttons (e.g., Edit, Reconnect).
  - `menuActions?: ActionsMenuGroup[]` — overflow "…" menu grouping, collapsed on phone.
  - `loadingActions?: boolean` — renders action placeholders while actions are not yet available.
- **`TenantDetailTitle(props)`** — The exported component. Uses `useSafeBack` to navigate back to `routes.cloudTenantManagement.list`, and renders `TitleBlock` from `@flamingo-stack/openframe-frontend-core` with the `menu-primary` actions variant.

## Usage Example

```typescript
import { TenantDetailTitle, TENANT_DETAIL_TITLE } from './tenant-detail-title';

function TenantDetailPage({ tenant, isLoading }: { tenant?: { name: string }; isLoading: boolean }) {
  return (
    <TenantDetailTitle
      title={tenant?.name ?? TENANT_DETAIL_TITLE}
      loading={isLoading}
      actions={[{ label: 'Edit', onClick: () => console.log('edit') }]}
      menuActions={[
        {
          items: [{ label: 'Reconnect', onClick: () => console.log('reconnect') }],
        },
      ]}
      loadingActions={isLoading}
    />
  );
}
```

This component is intended for use within a tenant detail page layout where the back button always routes to the cloud tenant management list, defined in [`lib/routes`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/lib/routes.ts).
