# tenant-licenses-section.tsx

Renders the "Licences" section of a tenant/directory detail page, displaying per-SKU license allocations (assigned/purchased/unused seats) with search and sort capabilities. It issues its own GraphQL query so that live search and sort interactions refetch independently of the parent page's record, following a Relay deferred-query pattern to keep the UI responsive while the server responds.

## Key Components

- **`TenantLicensesSection`** — Main exported component. Renders the section header, an optional notice (for providers like Google Workspace that don't report purchased totals), a search input with debounce, a mobile sort button/modal, and the licenses table.
- **`LicensesTable` / `LicensesTableReader` / `LicensesTableQuery`** — Layered components implementing the Suspense/loading-scope pattern: skeleton rows while loading, then a Relay `useLazyLoadQuery` fetch for actual data.
- **`LicensesRows`** — Builds the `useDataTable` instance and renders `LiveTable` with sort, pending state, and empty-state messaging.
- **`licenseColumns(showUnused)`** — Produces column definitions (`License`, `Assigned`, optional `Unused`), conditionally hiding the Unused column for providers without purchase totals.
- **`LicenseCell` / `AssignedCell`** — Cell renderers showing license name/"Free" tag and assigned count (with responsive label on mobile).
- **`toOrderBy(sort)`** — Converts local UI sort state into the GraphQL `DirectoryLicenseOrderInput`.
- **`tenantLicensesSectionQuery`** — GraphQL query fetching `licenseSummary` and `licenses` (filtered/sorted) for a given directory connection ID.

## Usage Example

```typescript
import { TenantLicensesSection } from './tenant-licenses-section';

function TenantDetailPage({ directoryId, provider }: { directoryId: string; provider: string | null }) {
  return (
    <div className="flex flex-col gap-8">
      {/* other sections */}
      <TenantLicensesSection id={directoryId} provider={provider} />
    </div>
  );
}
```

The component expects `id` (the directory connection ID) and `provider` (used to detect Google Workspace and hide the Unused/purchased-total column). Internally, search input is debounced 300ms and sort state toggles ascending → descending → cleared on repeated column clicks, with a dedicated `FilterModal`-based sort picker for narrower viewports.
