# tenant-licenses-section.tsx

Renders the "Licences" section of a tenant directory detail page, displaying per-SKU license data (assigned/purchased/unused seats) in a searchable, sortable table. Search and sort are server-driven via a dedicated GraphQL query, decoupled from the parent page's data so the table can refetch independently without blocking the rest of the page.

## Key Components

- **`TenantLicensesSection`** — Top-level exported component. Renders the heading, an optional `TenantNotice` (shown when the provider is Google Workspace, since it doesn't report purchased totals), a search input, a mobile sort trigger (`FilterModal`), and the `LicensesTable`.
- **`LicensesTable` / `LicensesTableReader` / `LicensesTableQuery`** — Layered components handling Suspense boundaries, the outer page's loading scope, and the actual Relay query execution (`useLazyLoadQuery`).
- **`LicensesRows`** — Builds the TanStack-based data table via `useDataTable`, with skeleton placeholder rows while loading.
- **`LicenseCell` / `AssignedCell`** — Cell renderers for license name (with optional "Free" tag) and assigned-seat count (with responsive mobile label).
- **`tenantLicensesSectionQuery`** — GraphQL query fetching `licenseSummary` and filtered/sorted `licenses` for a directory connection.
- **`toOrderBy`** — Converts local sort state into a `DirectoryLicenseOrderInput` for the GraphQL query.
- **`licenseColumns`** — Builds column definitions, conditionally including the "Unused" column based on provider capabilities.

## Usage Example

```typescript
import { TenantLicensesSection } from '@/app/components/tenant/tenant-licenses-section';

function TenantDetailPage({ connectionId, provider }: { connectionId: string; provider: string | null }) {
  return (
    <div>
      {/* other sections */}
      <TenantLicensesSection id={connectionId} provider={provider} />
    </div>
  );
}
```

The component expects `id` to be a valid directory connection ID and `provider` to match a `DirectoryProvider` enum value (e.g., `GOOGLE_WORKSPACE`), which controls whether the "Unused" column and purchased-total notice are shown. Search input is debounced (300ms) and sorting is deferred via `useDeferredQuery` so the UI reflects clicks instantly while the underlying query updates in the background.
