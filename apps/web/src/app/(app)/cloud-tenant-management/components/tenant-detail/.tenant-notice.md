A presentational React component that displays a neutral, informational notice card for tenant-related facts—used to surface read-only status information without implying an action is required.

## Key Components

- **`TenantNoticeProps`** — Interface extending `HTMLAttributes<HTMLDivElement>` with:
  - `icon: ReactNode` — leading icon displayed alongside the notice
  - `title: string` — primary, bold text (required)
  - `description?: string | null` — optional secondary descriptive text
- **`TenantNotice`** — Functional component rendering an accessible (`role="status"`) card with icon, title, and optional description, styled using design-system tokens (ODS spacing, border, card, and text colors).

## Usage Example

```typescript
import { TenantNotice } from './tenant-notice';
import { InfoIcon } from 'some-icon-library';

function TenantOverview() {
  return (
    <TenantNotice
      icon={<InfoIcon />}
      title="Single sign-on enabled"
      description="This tenant uses SSO for all user authentication."
    />
  );
}

// Without a description
function MinimalNotice() {
  return (
    <TenantNotice
      icon={<InfoIcon />}
      title="Trial account"
    />
  );
}
```

## Notes

- Uses `role="status"` for assistive technology to announce the notice as a live region update.
- Spreads any additional `HTMLAttributes<HTMLDivElement>` props (e.g., `className`, `onClick`) onto the root `div`.
- Styling relies on ODS (OpenFrame Design System) CSS custom properties and utility classes (`--spacing-system-m`, `ods-border`, `ods-card`, `ods-text-primary`, `ods-text-secondary`), so it must be used within a context where these tokens are defined.
