A presentational React component that displays a neutral, informational notice card on tenant-related surfaces, intended for facts that require no user action—purely informational, not an alert or error state.

## Key Components

- **`TenantNoticeProps`** — Props interface extending `HTMLAttributes<HTMLDivElement>` with:
  - `icon: ReactNode` — leading icon element
  - `title: string` — primary notice text
  - `description?: string | null` — optional secondary descriptive text
- **`TenantNotice`** — Functional component rendering an icon alongside a title and optional description inside a bordered card container. Uses `role="status"` for accessibility, signaling a passive status update to assistive technologies.

## Usage Example

```typescript
import { TenantNotice } from './tenant-notice';
import { InfoIcon } from 'lucide-react';

function TenantDetailsPanel() {
  return (
    <TenantNotice
      icon={<InfoIcon size={20} />}
      title="Managed by parent organization"
      description="This tenant inherits billing and policy settings from its parent."
    />
  );
}

// Without description
function MinimalNotice() {
  return (
    <TenantNotice
      icon={<InfoIcon size={20} />}
      title="No active integrations"
    />
  );
}
```

The component accepts all standard `div` attributes via props spreading, allowing consumers to pass `className`, `onClick`, `data-*` attributes, etc. Styling relies on design tokens (`--spacing-system-m`, `ods-border`, `ods-card`, `ods-text-primary`, `ods-text-secondary`) to maintain consistency with the Open Design System (ODS).
