Defines the static row label constants for the "INTEGRATION" section of the tenant details view, ensuring consistent labeling between the live data display and its loading skeleton.

## Key Components

- **`INTEGRATION_LABELS`** — A `const`-asserted object mapping internal field keys (`primaryDomain`, `grantedBy`, `scopes`, `authorisedBy`, `domains`) to their human-readable display labels, matching the order defined in Figma spec (frame 2097-140910).

Note: the directory id row is intentionally excluded since its label comes from `providerPresentation` elsewhere.

## Usage Example

```typescript
import { INTEGRATION_LABELS } from './tenant-integration-labels';

// Rendering a label/value row
function IntegrationRow({ field, value }: { field: keyof typeof INTEGRATION_LABELS; value: string }) {
  return `${INTEGRATION_LABELS[field]}: ${value}`;
}

// Example skeleton loader reusing the same labels to avoid drift
function IntegrationSkeletonRow({ field }: { field: keyof typeof INTEGRATION_LABELS }) {
  return `${INTEGRATION_LABELS[field]}: Loading...`;
}

console.log(INTEGRATION_LABELS.primaryDomain); // "Primary domain"
```

This pattern keeps the live section and skeleton in sync by sourcing both from a single data-only source of truth, preventing label mismatches during UI updates.
