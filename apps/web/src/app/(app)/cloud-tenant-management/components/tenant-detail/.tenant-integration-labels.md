Defines the static row labels for the "INTEGRATION" section of the tenant detail view (per Figma spec 2097-140910), serving as a single source of truth shared between the live data section and its loading skeleton.

## Key Components

- **`INTEGRATION_LABELS`** — A `const` object (readonly via `as const`) mapping field keys to their display labels:
  - `primaryDomain` → `'Primary domain'`
  - `grantedBy` → `'Granted by'`
  - `scopes` → `'Scopes held'`
  - `authorisedBy` → `'Authorised by'`
  - `domains` → `'Additional domains'`

Note: the directory id row is intentionally excluded since its label comes from `providerPresentation` elsewhere.

## Usage Example

```typescript
import { INTEGRATION_LABELS } from './tenant-integration-labels';

// In the live section component
const rows = [
  { label: INTEGRATION_LABELS.primaryDomain, value: tenant.primaryDomain },
  { label: INTEGRATION_LABELS.grantedBy, value: tenant.grantedBy },
  { label: INTEGRATION_LABELS.scopes, value: tenant.scopes.join(', ') },
];

// In the matching skeleton loader, reuse the same labels
// so placeholders render identically to the loaded state
const skeletonRows = Object.values(INTEGRATION_LABELS).map((label) => ({
  label,
  value: null, // placeholder while loading
}));
```

Because `INTEGRATION_LABELS` is defined with `as const`, both its keys and string values are strongly typed as literals, enabling safe, autocompletable access across consuming components.
