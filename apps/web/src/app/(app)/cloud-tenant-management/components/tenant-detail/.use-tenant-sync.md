A React hook that pauses and resumes a directory connection's tenant sync via GraphQL mutations, surfacing success or failure feedback through toast notifications.

## Key Components

- **`useTenantSync(connectionId)`** — Hook that accepts a directory connection ID (or `null`) and returns controls for pausing/resuming sync.
- **`pauseMutation` / `resumeMutation`** — GraphQL mutations (`pauseDirectoryConnection`, `resumeDirectoryConnection`) that update the connection's `enabled` state and refresh the `tenantSyncPausedNotice_connection` fragment in place, so related UI (title actions, status card, notice, list row) stays in sync.
- **Return value**:
  - `pause()` — Triggers the pause mutation; shows a success toast on completion or a destructive toast on `userErrors`/network error.
  - `resume()` — Triggers the resume mutation with the same success/error toast pattern.
  - `isBusy` — `boolean` combining both mutations' in-flight states (`isPausing || isResuming`), useful for disabling buttons during the request.

Both actions no-op silently if `connectionId` is `null`, making the hook safe to call before a connection is loaded.

## Usage Example

```typescript
import { useTenantSync } from '@/hooks/use-tenant-sync';

function SyncControls({ connectionId }: { connectionId: string | null }) {
  const { pause, resume, isBusy } = useTenantSync(connectionId);

  return (
    <>
      <button onClick={pause} disabled={isBusy || !connectionId}>
        Pause Sync
      </button>
      <button onClick={resume} disabled={isBusy || !connectionId}>
        Resume Sync
      </button>
    </>
  );
}
```

Errors returned in `userErrors` (e.g., validation issues) and network/Relay errors are both handled, ensuring the user always receives feedback regardless of failure type.
