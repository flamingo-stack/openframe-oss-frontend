# use-tenant-sync.ts

A React hook that provides pause/resume controls for a tenant directory sync connection, using Relay mutations with optimistic in-place updates across the UI (title actions, status notice, card status, and list rows).

## Key Components

- **`useTenantSync(connectionId)`** — Hook that exposes directory sync controls for a given connection ID.
  - `pause()` — Commits the `pauseDirectoryConnection` mutation; shows a success or error toast based on the result.
  - `resume()` — Commits the `resumeDirectoryConnection` mutation; shows a success or error toast based on the result.
  - `isBusy` — Boolean flag, `true` while either mutation is in flight.
- **`pauseMutation`** / **`resumeMutation`** — GraphQL mutation documents (via `graphql` tag) that request `connection.id`, `connection.enabled`, and the `tenantSyncPausedNotice_connection` fragment, plus `userErrors` for form-level error handling.

## Usage Example

```typescript
import { useTenantSync } from '@/hooks/use-tenant-sync';

function SyncControls({ connectionId }: { connectionId: string | null }) {
  const { pause, resume, isBusy } = useTenantSync(connectionId);

  return (
    <div>
      <button onClick={pause} disabled={isBusy}>
        Pause Sync
      </button>
      <button onClick={resume} disabled={isBusy}>
        Resume Sync
      </button>
    </div>
  );
}
```

## Notes

- Returns early (no-op) if `connectionId` is `null`, making it safe to call before data has loaded.
- Errors are surfaced via `useToast` with a `destructive` variant, using `userErrorsDescription` for field-level GraphQL errors and `getRelayErrorMessage` for network/transport errors.
- Because mutations select the `tenantSyncPausedNotice_connection` fragment, any component consuming that fragment updates automatically without a refetch.
