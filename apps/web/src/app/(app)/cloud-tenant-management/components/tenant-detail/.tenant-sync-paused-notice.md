## tenant-sync-paused-notice.tsx

A React client component that displays a warning notice when a tenant's directory connection has had its synchronization paused, showing who paused it and when (per Figma design 3051-7925).

## Key Components

- **`TenantSyncPausedNotice`** — Functional component that renders a `TenantNotice` warning banner when sync is paused for a given directory connection, or `null` when sync is active.
- **`tenantSyncPausedNoticeFragment`** — GraphQL fragment (via `graphql` tag) defined on `DirectoryConnection`, fetching `enabled`, `syncPausedAt`, `syncPausedBy` (with nested `userSummaryFields_user` fragment), and `access.state`.

The component relies on utility functions `isSyncPaused` and `syncPausedDescription` from `../../utils/tenant-presentation` to determine pause state and format the description text, and `toUserSummary` to resolve the display name of the user who paused the sync.

## Usage Example

```typescript
import { TenantSyncPausedNotice } from './tenant-sync-paused-notice';
import { graphql, useFragment } from 'react-relay';

function DirectoryConnectionPanel({ connectionRef }: { connectionRef: any }) {
  return (
    <div className="connection-panel">
      {/* Renders nothing if sync is not paused */}
      <TenantSyncPausedNotice connection={connectionRef} />
    </div>
  );
}
```

The parent component must spread the `tenantSyncPausedNotice_connection` fragment into its own GraphQL query on `DirectoryConnection` to supply the `connection` prop:

```graphql
query ParentQuery {
  directoryConnection(id: $id) {
    ...tenantSyncPausedNotice_connection
  }
}
```

This component is typically used within tenant/directory settings pages where connection health status needs surfacing to administrators.
