Renders a warning notice banner indicating that a tenant's directory sync has been paused, including who paused it and when.

## Key Components

- **`tenantSyncPausedNoticeFragment`** — GraphQL fragment on `DirectoryConnection` that fetches `enabled`, `syncPausedAt`, `syncPausedBy` (via `userSummaryFields_user`), and `access.state` needed to determine and describe the paused state.
- **`TenantSyncPausedNotice`** — React client component that reads the fragment data, checks `isSyncPaused`, and conditionally renders a `TenantNotice` with a warning icon, title, and a formatted description of who paused sync and when. Returns `null` if sync is not paused.

## Usage Example

```typescript
import { TenantSyncPausedNotice } from './tenant-sync-paused-notice';
import { graphql, useFragment } from 'react-relay';

function TenantDetailsPanel({ connectionRef }: { connectionRef: any }) {
  return (
    <div className="tenant-details">
      {/* Shown only when the connection's sync is paused */}
      <TenantSyncPausedNotice connection={connectionRef} />
      {/* ... other tenant detail sections ... */}
    </div>
  );
}
```

This component relies on a parent query spreading the `tenantSyncPausedNotice_connection` fragment on a `DirectoryConnection` object, and depends on helper utilities (`isSyncPaused`, `syncPausedDescription`) from `tenant-presentation` to determine visibility and compose the notice text. It uses the shared `TenantNotice` presentational component for consistent styling, matching the Figma design reference (3051-7925).
