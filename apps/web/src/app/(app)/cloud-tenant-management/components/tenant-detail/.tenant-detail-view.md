# tenant-detail-view.tsx

A client-side React component that renders the top-level container for a single tenant's detail page, delegating data-dependent rendering to a child content component.

This component intentionally avoids wrapping its content in the shared `PageLayout` component, since the page title itself is derived from the tenant record being fetched. Instead of blocking the entire layout on data loading, only the inner content island (`TenantDetailContent`) awaits the fetch, allowing the outer frame to render immediately. This pattern mirrors the canonical `software-detail-view` implementation.

## Key Components

- **`TenantDetailViewProps`** — Interface defining the component's props:
  - `id: string` — The tenant identifier used to fetch tenant details.
  - `loading?: boolean` — Optional flag indicating whether the tenant data is still being fetched (defaults to `false`).
- **`TenantDetailView`** — The exported functional component that renders a flex column wrapper around `TenantDetailContent`, passing through `id` and `loading`.

## Usage Example

```typescript
import { TenantDetailView } from './tenant-detail-view';

export default function TenantPage({ params }: { params: { id: string } }) {
  return <TenantDetailView id={params.id} loading={false} />;
}
```

```typescript
// Rendering while the tenant record is still being resolved
<TenantDetailView id="tenant-123" loading={true} />
```
