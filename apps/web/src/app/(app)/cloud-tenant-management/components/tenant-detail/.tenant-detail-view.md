# tenant-detail-view.tsx

A thin client-side wrapper component that renders the detail view for a single tenant record. It intentionally avoids the standard `PageLayout` wrapper since the page title derives from the fetched tenant data itself, deferring loading behavior to the inner content component (following the same pattern as `software-detail-view`).

## Key Components

- **`TenantDetailViewProps`** — Interface defining the component's props:
  - `id: string` — the tenant identifier used to fetch record data
  - `loading?: boolean` — optional flag indicating fetch state has not yet resolved; defaults to `false`
- **`TenantDetailView`** — Exported functional component that wraps `TenantDetailContent` in a full-width flex column container, passing through `id` and `loading` props unchanged.

## Usage Example

```typescript
import { TenantDetailView } from './tenant-detail-view';

export default function TenantPage({ params }: { params: { id: string } }) {
  return <TenantDetailView id={params.id} loading={false} />;
}
```

```typescript
// While the parent route is resolving initial data
<TenantDetailView id={tenantId} loading={isFetching} />
```

## Notes

- Marked `'use client'` since it is rendered within a client component tree.
- Does not perform any data fetching itself — all loading/fetching logic is delegated to `TenantDetailContent`, keeping this component a pure layout shell.
- The container uses `flex w-full flex-col` to ensure the detail content spans the full available width in a vertical stack.
