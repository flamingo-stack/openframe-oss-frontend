# tenant-summary-card.tsx

Renders the tenant identity/summary cards shown on the directory connection details page (and its reduced Edit/Reconnect variant), using Relay fragments to display provider, domain, customer attribution, and sync status with built-in loading skeletons.

## Key Components

- **`TenantIdentityCard`** — Exported component rendering the single-row Edit/Reconnect card variant, showing only provider and domain name. Uses the `tenantSummaryCard_identity` Relay fragment.
- **`TenantSummaryCard`** — Exported component rendering the full two-row details-page card, showing provider, customers, attribution, user count, sync status, and last read time. Uses the `tenantSummaryCard_connection` Relay fragment.
- **`ProviderCell`** — Internal cell displaying the provider's logo and label, with skeleton fallback while loading.
- **`CustomersCell`** — Internal cell displaying the lead bound customer (avatar, name, optional badge) plus an `AllCustomersMenu` dropdown for additional customers.
- **`AllCustomersMenu`** — Internal dropdown listing all bound customers when more than one is attached.
- **`AttributionCell`** — Internal cell summarizing unattributed vs. total user counts, highlighting warnings via `attributionSummary`.
- **`LABELS`** — Static label constants used across cells (also rendered during loading states).

Both exported components rely on `useLoadingScope()` to detect an in-flight loading context and `LoadingWhen` to coordinate skeleton rendering, so cards render consistent placeholder states before data resolves—preventing layout shift once real data (including a loaded `connection` key with `null` data) lands.

## Usage Example

```typescript
import { TenantSummaryCard, TenantIdentityCard } from './tenant-summary-card';

// Full details page card
function TenantDetailsPage({ connectionRef }: { connectionRef: tenantSummaryCard_connection$key | null }) {
  return <TenantSummaryCard connection={connectionRef} />;
}

// Reduced Edit/Reconnect card
function EditTenantModal({ connectionRef }: { connectionRef: tenantSummaryCard_identity$key | null }) {
  return <TenantIdentityCard connection={connectionRef} />;
}
```

Both components accept `null` for the connection ref to render their loading/empty state, and automatically resolve Relay fragment data when wrapped in a loading scope boundary.
