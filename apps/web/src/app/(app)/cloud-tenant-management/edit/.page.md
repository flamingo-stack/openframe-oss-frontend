This Next.js client page component renders the tenant integration edit screen, routing between two implementation versions based on a feature gate while handling loading and not-found states.

## Key Components

- **`EditTenantPage`** - Default export; the page component for editing a tenant integration, resolved via a required `id` route/query parameter.
- **`useTenantManagementGate`** - Hook returning `'off' | 'loading' | 'on'`; controls whether the tenant management feature is enabled at all.
- **`useTenantManagementV2Gate`** - Hook returning `'off' | 'loading' | 'on'`; determines whether to render the v2 (`EditTenantView`) or v1 (`EditTenantViewV1`) edit experience.
- **`useRequiredIdParam`** - Hook that extracts the tenant `id` from the route, redirecting to the list or "new tenant" route if missing.
- **`TenantPageShell`** - Shared layout wrapper providing title, error boundary (`errorMessage`), and a `resetKey` to reset state when the tenant `id` changes.
- **`LoadingWhen`** - Utility component from `@flamingo-stack/openframe-frontend-core` that renders a loading state and disables interaction while `loading` is `true`.

## Usage Example

This file is a Next.js App Router page and is rendered automatically for its route; it isn't imported directly elsewhere. The key pattern is the dual feature-gate check before rendering:

```typescript
const gate = useTenantManagementGate();
const v2 = useTenantManagementV2Gate();
const id = useRequiredIdParam(routes.cloudTenantManagement.list, routes.cloudTenantManagement.new());

if (gate === 'off') {
  notFound();
}
if (!id) {
  return null;
}

return (
  <LoadingWhen loading={gate === 'loading' || v2 === 'loading'}>
    {v2 === 'on' ? <EditTenantView key={id} id={id} /> : <EditTenantViewV1 key={id} id={id} />}
  </LoadingWhen>
);
```

Both gates must resolve to a definitive state before the loading lock releases, preventing a flash of the wrong view. The `key={id}` prop ensures navigating between different tenant IDs fully remounts the edit view instead of reusing stale form state.
