# page.tsx (Reconnect Tenant Page)

Client-rendered Next.js page component that allows users to reconnect an existing tenant's integration. It resolves the tenant ID from the route, gates access based on feature flags, and renders either the v1 or v2 reconnect view accordingly.

## Key Components

- **`ReconnectTenantPage`** (default export) — Page component for the tenant reconnect flow
- **`useTenantManagementGate`** — Determines if tenant management functionality is enabled (`'off'`, `'loading'`, or `'on'`)
- **`useTenantManagementV2Gate`** — Determines whether to use the v2 implementation of the reconnect view
- **`useRequiredIdParam`** — Extracts and validates the required `id` route param, redirecting to a fallback route if missing
- **`TenantPageShell`** — Shared layout wrapper providing title, error boundary, and reset-key-based remounting
- **`LoadingWhen`** — Conditionally renders a loading state while feature flags resolve
- **`ReconnectTenantView`** / **`ReconnectTenantViewV1`** — The v2 and v1 reconnect UI implementations, respectively

## Behavior

1. If the tenant management feature gate is `'off'`, the page triggers a `notFound()` response.
2. If no valid `id` param is present, the component returns `null` (navigation/redirect is handled by `useRequiredIdParam`).
3. While the `gate` or `v2` flag values are still `'loading'`, the content is wrapped in a loading state and doesn't read tenant data yet.
4. Once flags resolve, it renders `ReconnectTenantView` (v2) or `ReconnectTenantViewV1` (v1), keyed by `id` to ensure a clean remount per tenant.

## Usage Example

This page is automatically routed by Next.js based on its file location (e.g., under a dynamic `[id]` segment) and requires no manual invocation:

```typescript
// Navigating to this page programmatically
import { routes } from '@/lib/routes';
import { useRouter } from 'next/navigation';

function NavigateToReconnect({ tenantId }: { tenantId: string }) {
  const router = useRouter();
  return (
    <button onClick={() => router.push(routes.cloudTenantManagement.reconnect(tenantId))}>
      Reconnect Tenant
    </button>
  );
}
```
