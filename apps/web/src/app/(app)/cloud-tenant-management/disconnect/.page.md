Next.js client page component for disconnecting a cloud tenant connection, gated behind a feature flag and requiring a valid tenant ID route parameter.

## Key Components

- **`DisconnectTenantPage`** — Default-exported page component rendered at the disconnect-tenant route. Handles feature-gating, ID validation, loading state, and delegates actual disconnect logic to `EndConnectionView`.
- **`useTenantManagementV2Gate`** — Hook returning the feature gate state (`'off'`, `'loading'`, or enabled), used to conditionally render a 404 or a loading indicator.
- **`useRequiredIdParam`** — Hook that extracts and validates the required `id` route parameter, redirecting to `routes.cloudTenantManagement.list` if missing/invalid.
- **`TenantPageShell`** — Shared layout wrapper providing page title, error boundary messaging, and reset-on-key-change behavior.
- **`EndConnectionView`** — Shared component (used for both disconnect and delete flows) rendered in `"disconnect"` mode to handle the tenant disconnection workflow.

## Usage Example

```typescript
// This page is automatically routed by Next.js based on its file path,
// e.g. app/(dashboard)/cloud-tenant-management/[id]/disconnect/page.tsx

// Conceptual flow performed internally:
function DisconnectTenantPage() {
  const gate = useTenantManagementV2Gate();
  const id = useRequiredIdParam(routes.cloudTenantManagement.list);

  if (gate === 'off') return notFound();
  if (!id) return null;

  return (
    <TenantPageShell title="Disconnect Tenant" errorMessage="Couldn't load this tenant." resetKey={id}>
      <LoadingWhen loading={gate === 'loading'}>
        <EndConnectionView key={id} id={id} mode="disconnect" />
      </LoadingWhen>
    </TenantPageShell>
  );
}
```

**Notes:**
- Returns `notFound()` (404) when the `useTenantManagementV2Gate` feature flag is `'off'`.
- Returns `null` while the required `id` param is being resolved or is invalid.
- The `resetKey={id}` prop on `TenantPageShell` ensures the shell resets state when switching between tenants.
