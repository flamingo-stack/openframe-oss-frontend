Client-rendered Next.js page component that renders the "Disconnect Tenant" flow, allowing an authorized user to disconnect a cloud tenant from the platform while enforcing feature-gating and required-parameter validation.

## Key Components

- **`DisconnectTenantPage`** (default export) — Page component that:
  - Resolves feature availability via `useTenantManagementV2Gate()`, returning `'on'`, `'off'`, or `'loading'`.
  - Extracts and validates the required `id` route param via `useRequiredIdParam`, redirecting to `routes.cloudTenantManagement.list` if missing.
  - Calls `notFound()` when the tenant management v2 feature gate is `'off'`.
  - Renders `TenantPageShell` as a layout wrapper with title/error handling and a `resetKey` tied to the tenant `id`.
  - Uses `LoadingWhen` to show a loading state while the gate status resolves.
  - Renders `EndConnectionView` in `"disconnect"` mode to perform the actual disconnect UI/logic.

## Usage Example

```typescript
// This file is a Next.js App Router page, typically located at:
// app/(somewhere)/tenants/[id]/disconnect/page.tsx
//
// It is rendered automatically by Next.js routing when navigating to
// a URL matching the dynamic [id] segment, e.g.:
//   /cloud-tenant-management/123/disconnect

// Example of navigating to this page programmatically:
import { useRouter } from 'next/navigation';

function DisconnectButton({ tenantId }: { tenantId: string }) {
  const router = useRouter();
  return (
    <button onClick={() => router.push(`/cloud-tenant-management/${tenantId}/disconnect`)}>
      Disconnect Tenant
    </button>
  );
}
```

## Notes

- Depends on `useTenantManagementV2Gate` for feature flag gating and `useRequiredIdParam` for safe param extraction with fallback navigation.
- The `key={id}` on `EndConnectionView` ensures the component fully remounts when the tenant `id` changes, resetting internal state.
