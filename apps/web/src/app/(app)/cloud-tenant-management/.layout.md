Defines page metadata and layout for the Cloud Tenant Management route, leveraging a shared layout component and a dynamic title generator.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the document title for this route using the `routeTitle` helper with `'Cloud Tenant Management'` as the page name.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` to render the standard layout wrapper (e.g., title header, breadcrumbs, or consistent page chrome) for this route segment.

## Usage Example

This file follows the Next.js App Router convention, automatically applying to all pages nested under the same route segment:

```typescript
// app/(app)/cloud-tenant-management/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Cloud Tenant Management') };
```

Any `page.tsx` file within the same directory automatically inherits this layout and metadata, ensuring the browser tab displays a consistent, formatted title (e.g., `"Cloud Tenant Management | OpenFrame"`) without needing to redefine it per page. This pattern is reused across the app for consistent route-level title management—see other `layout.tsx` files in `app/(app)/` for similar usage.
