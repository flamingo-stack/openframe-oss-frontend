Defines the Next.js page metadata and layout wrapper for the Cloud Tenant Management route, re-exporting a shared layout component while setting a route-specific document title.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the browser tab title for this route using `routeTitle('Cloud Tenant Management')`.
- **Default export** — Re-exports the `default` export from `@/app/(app)/route-title-layout`, delegating the actual layout rendering (e.g., wrapping children with a titled header/shell) to a shared, centralized layout component.
- **`routeTitle`** — Imported helper (from `@/lib/route-title`) responsible for formatting the page title consistently across the app (e.g., appending a suffix like "| OpenFrame").

## Usage Example

This file follows Next.js App Router conventions and is not imported directly elsewhere in the codebase. Next.js automatically picks it up as the `layout.tsx` for its route segment:

```typescript
// Next.js automatically applies this layout and metadata
// to all pages under the Cloud Tenant Management route segment.

// Example of the routeTitle helper this file relies on:
// lib/route-title.ts
export function routeTitle(title: string): string {
  return `${title} | OpenFrame`;
}
```

Because the component logic is re-exported from a shared `route-title-layout`, adding a new route with a titled layout typically only requires creating a similar `layout.tsx` file with an updated `metadata.title` value, keeping layout behavior consistent across routes.
