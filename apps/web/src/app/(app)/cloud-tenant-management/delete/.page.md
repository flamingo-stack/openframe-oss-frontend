Client-rendered Next.js page component for deleting a tenant connection within the cloud tenant management feature, gated behind a feature flag.

## Key Components

- **`DeleteConnectionPage`** — Default export; a client component (`'use client'`) that renders the delete-connection UI for a specific tenant identified by a route parameter.
- **`useTenantManagementV2Gate`** — Hook controlling feature flag state (`'off' | 'loading' | <enabled>`), used to block access via `notFound()` when disabled.
- **`useRequiredIdParam`** — Hook that extracts a required `id` param from the route, redirecting to `routes.cloudTenantManagement.list` if missing.
- **`TenantPageShell`** — Shared layout wrapper providing page title, error boundary messaging, and reset-on-key-change behavior.
- **`LoadingWhen`** — Conditional rendering helper from `@flamingo-stack/openframe-frontend-core` that shows a loading state while the gate resolves.
- **`EndConnectionView`** — Shared view component (also used for disconnect flows) rendered in `"delete"` mode to perform the tenant connection deletion.

## Usage Example

This file is a Next.js App Router page and is not invoked directly; it's rendered automatically when a user navigates to the delete-connection route for a given tenant `id`, e.g.:

```typescript
// Navigated to via routing, for example:
router.push(`/cloud-tenant-management/${tenantId}/delete`);
```

Internally, the page composes shared primitives:

```typescript
import { EndConnectionView } from '../components/tenant-end/end-connection-view';

<EndConnectionView key={id} id={id} mode="delete" />
```

The `mode="delete"` prop differentiates this page from a similar "disconnect" page that likely reuses `EndConnectionView` with a different mode value.
