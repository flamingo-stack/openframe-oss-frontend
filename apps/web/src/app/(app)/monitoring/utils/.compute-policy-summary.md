Computes policy compliance summary statistics and determines per-policy status from a list of Fleet/MSP policies, used to power compliance dashboards in the OpenFrame frontend.

## Key Components

- **`PolicyStatus`** — Union type: `'compliant' | 'failing' | 'pending' | 'partial'`
- **`POLICY_STATUS_CONFIG`** — Display configuration map (label + badge variant) for each `PolicyStatus`
- **`getPolicyStatus(policy)`** — Derives a single `PolicyStatus` from a policy's host counts
- **`computePolicySummary(policies)`** — Aggregates a policy array into a `PolicySummaryStats` object; `pending` and `partial` policies are excluded from percentage calculations

## Status Logic

| Status | Condition |
|---|---|
| `pending` | No hosts responded and some are missing |
| `partial` | Some hosts responded, some are still missing |
| `failing` | All hosts responded but at least one failed |
| `compliant` | All hosts responded and none failed |

## Usage Example

```typescript
import { computePolicySummary, getPolicyStatus, POLICY_STATUS_CONFIG } from './compute-policy-summary';

// Per-policy badge
const status = getPolicyStatus(policy);
const { label, variant } = POLICY_STATUS_CONFIG[status];
// label → 'Failing', variant → 'error'

// Dashboard summary
const summary = computePolicySummary(policies);
console.log(summary.failingPoliciesPercentage); // e.g. 25
console.log(summary.lastUpdatedAt);             // ISO timestamp or null
```

> **Note:** Percentage fields are calculated only over resolved policies (`compliant + failing`). A policy list consisting entirely of `pending`/`partial` policies returns `0%` for both percentages.
