# test-query-section.tsx

A React client component that renders the "Test Query" panel shown beneath the osquery editor, allowing a user to run an ad-hoc osquery SQL query against a single Fleet-connected device and view live results (status, timing, and result rows) before saving or assigning the query.

## Key Components

- **`TestQuerySectionProps`** — Props interface: `getQuery` (returns current SQL), `hasQuery`, `devices`, `isLoadingDevices`, and optional `className`.
- **`TestQuerySection`** — Main exported component. Responsibilities:
  - Maps Fleet host IDs to registry device names via `indexDevicesByFleetHostId` and `getDeviceName`.
  - Uses `useQueryTestRun` (from `./query-test-run`) to manage test execution state (`run`, `stop`, `reset`, `isActive`, `hasRun`, `status`, `startedLabel`, `durationLabel`, `displayRows`, `firstError`, `showResults`).
  - Builds a searchable device dropdown (`SearchableSelect`) restricted to Fleet-connected devices, sorted alphabetically, with an ONLINE/OFFLINE `Tag` rendered per option via `renderDeviceOption`.
  - Toggles an expandable panel (`isOpen`) with a "Test Query" / "Cancel Test" button and an Osquery Documentation link.
  - Renders timing stats (`TimingStat`), run status (`TestRunStatusStat`), a context-sensitive action button (Run Test / Stop Test / Test Again), and results (`TestRunResults`).

## Usage Example

```typescript
import { TestQuerySection } from './test-query-section';

function QueryEditorPage({ devices, isLoadingDevices, query }: {
  devices: Device[];
  isLoadingDevices: boolean;
  query: string;
}) {
  return (
    <div>
      {/* ...query editor... */}
      <TestQuerySection
        getQuery={() => query}
        hasQuery={query.trim().length > 0}
        devices={devices}
        isLoadingDevices={isLoadingDevices}
        className="mt-4"
      />
    </div>
  );
}
```

Only devices with a resolvable Fleet host ID (`getFleetHostId`) appear as selectable test targets; the "Run Test"/"Test Again" button is disabled unless a query exists, a device is selected, and no test is currently active.
