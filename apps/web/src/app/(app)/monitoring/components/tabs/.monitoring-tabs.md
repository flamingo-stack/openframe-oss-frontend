## monitoring-tabs.tsx

Client component that renders the tab navigation bar for the Monitoring section, switching between "Policies" and "Queries" views. It integrates with the Manhattan shell's dock system to hide its own tab bar when navigation is already handled externally (e.g., in the Manhattan v2 shell where navigation lists both tabs).

## Key Components

- **`MONITORING_TABS`** — Exported array of `TabItem` configs defining the `policies` and `queries` tabs, each paired with an icon (`FolderShieldIcon`, `BracketCurlyEllipsisVrIcon`) and its corresponding component (`Policies`, `Queries`).
- **`MonitoringTabNavigation`** — React component that renders the `TabNavigation` UI. Accepts optional `activeTab` and `onTabChange` props; falls back to syncing tab selection with the URL query string (`?tab=`) via `useRouter`/`usePathname` when no handler is provided. Returns `null` when rendered inside the Manhattan dock navigation context (detected via `useManhattanDock`), since that context provides its own tab list.

## Usage Example

```typescript
import { MonitoringTabNavigation, MONITORING_TABS } from './monitoring-tabs';

// Default usage - syncs active tab with the URL (?tab=policies)
function MonitoringPage() {
  return (
    <div>
      <MonitoringTabNavigation />
      {/* render active tab's component based on URL */}
    </div>
  );
}

// Controlled usage with custom state management
function ControlledMonitoringPage() {
  const [activeTab, setActiveTab] = useState('queries');

  return (
    <MonitoringTabNavigation
      activeTab={activeTab}
      onTabChange={setActiveTab}
    />
  );
}

// Accessing tab definitions directly (e.g., for external navigation)
MONITORING_TABS.forEach((tab) => console.log(tab.id, tab.label));
```

**Notes:**
- When used outside the Manhattan dock context, clicking a tab updates the URL via `router.replace`, preserving the current `pathname` and setting the `tab` query parameter.
- Inside the Manhattan v2 shell (`useManhattanDock()` returns `true`), the component renders nothing, deferring tab navigation to the shell's own dock UI.
