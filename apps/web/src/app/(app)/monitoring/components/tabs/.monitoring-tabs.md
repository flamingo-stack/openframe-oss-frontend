Tab navigation component for the monitoring section, rendering **Policies** and **Queries** tabs with optional URL synchronization via query parameters.

## Key Components

- **`MONITORING_TABS`** — Static array of `TabItem` configurations defining the two monitoring tabs: `policies` (with `FolderShieldIcon`) and `queries` (with `BracketCurlyEllipsisVrIcon`).
- **`MonitoringTabNavigation`** — Client component that wraps `TabNavigation` with routing logic. Defaults to updating the URL query string (`?tab=<id>`) on tab change, or delegates to a custom `onTabChange` handler if provided.

## Props

| Prop | Type | Description |
|---|---|---|
| `activeTab` | `string` (optional) | Currently active tab ID; defaults to `'policies'` |
| `onTabChange` | `(tab: string) => void` (optional) | Override for tab change behavior; falls back to URL query param update |

## Usage Example

```typescript
// Basic usage — URL-driven tab state
<MonitoringTabNavigation activeTab={searchParams.get('tab') ?? 'policies'} />

// Controlled usage — custom tab handler
<MonitoringTabNavigation
  activeTab={currentTab}
  onTabChange={(tab) => setCurrentTab(tab)}
/>
```

## Notes

- `urlSync` is explicitly set to `false` on `TabNavigation`, with URL sync handled manually via `router.replace`.
- The default handler uses `useCallback` memoized on `router` and `pathname` to avoid unnecessary re-renders.
