# query-test-run.tsx

A Fleet-specific React hook that wires the shared `useTestRunState` state machine (from `@flamingo-stack/openframe-frontend-core`) to this app's live-campaign transport layer, providing a complete run/stop/reset flow for executing osquery test queries against a set of hosts.

## Key Components

- **`useQueryTestRun(options?)`** — Main hook export. Combines `useLiveCampaign` (Fleet's campaign transport) with `useTestRunState` (the core lib's generic test-run state machine) to produce a ready-to-use test query runner.
  - **Parameters:** `options?: UseLiveCampaignOptions` — optional configuration forwarded to `useLiveCampaign`.
  - **Returns:** All properties/methods from `useTestRunState` (duration ticking, display flags, stop/reset handlers, etc.), plus an overridden `run` function.
  - **`run(query: string, hostIds: number[])`** — Starts a new test run by invoking `campaign.startCampaign(query, hostIds)`, wrapped through the state machine's `runStart` lifecycle handler.

## Usage Example

```typescript
import { useQueryTestRun } from './query-test-run';

function TestQueryPanel({ hostIds }: { hostIds: number[] }) {
  const { run, stop, reset, isRunning, duration } = useQueryTestRun();

  const handleRun = () => {
    run('SELECT * FROM system_info;', hostIds);
  };

  return (
    <div>
      <button onClick={handleRun} disabled={isRunning}>
        Run Query
      </button>
      <button onClick={stop} disabled={!isRunning}>
        Stop
      </button>
      <button onClick={reset}>Reset</button>
      {isRunning && <span>Elapsed: {duration}s</span>}
    </div>
  );
}
```

Pair this hook's return value with the shared UI building blocks (`TimingStat`, `TestRunResults`, `TestResultsTable`) exported from `@flamingo-stack/openframe-frontend-core` to render a complete test-run experience.
