# policies-empty-state.tsx

A React client component that renders the default empty state for the Policies feature, displayed when no device policies have been created yet.

## Key Components

- **`PoliciesEmptyState`** — Functional component rendering the shared `EmptyState` UI with:
  - A `FolderShieldIcon` and "No policies yet" title/description
  - Three feature highlight tiles (icon + label) explaining policy capabilities: applying settings in bulk, targeting devices by customer/OS/tag, and compliance alerting
  - An onboarding-guide footer button generated via `onboardingGuideButton('policies')`, linking to the relevant Help Center guide

This component is shared verbatim between two locations: the Monitoring page's **Policies** tab and the device-details **Policies** tab, ensuring consistent empty-state messaging across the app.

## Usage Example

```typescript
import { PoliciesEmptyState } from '@/app/components/policies/policies-empty-state';

export function PoliciesTab({ policies }: { policies: Policy[] }) {
  if (policies.length === 0) {
    return <PoliciesEmptyState />;
  }

  return (
    <PoliciesList policies={policies} />
  );
}
```

The component takes no props — all content (icon, title, description, action tiles, guide link) is statically configured internally, making it a drop-in replacement wherever the empty Policies state needs to be shown.
