Renders the default empty state UI for the Policies feature, shared across the Monitoring page's Policies tab and the device-details Policies tab.

## Key Components

- **`PoliciesEmptyState`** — Client component that composes `EmptyState` with a `FolderShieldIcon`, descriptive title/description, three feature-highlight action tiles, and an onboarding guide footer button.

## Usage Example

```typescript
import { PoliciesEmptyState } from './policies-empty-state';

// Drop-in replacement when the policies list is empty
function PoliciesTab({ policies }) {
  if (!policies.length) return <PoliciesEmptyState />;
  return <PoliciesList policies={policies} />;
}
```

## Notes

- Uses `onboardingGuideButton('policies', 'Learn more about Policies')` to inject a Help-Center link via spread props — the `'policies'` key must match a valid onboarding guide route.
- Icons are sourced from `@flamingo-stack/openframe-frontend-core/components/icons-v2`: `FolderShieldIcon` (hero), `Hierarchy02Icon`, `RadarIcon`, `BellCheckIcon` (tiles).
- Marked `'use client'` — safe to render inside any Server Component tree via a client boundary.
