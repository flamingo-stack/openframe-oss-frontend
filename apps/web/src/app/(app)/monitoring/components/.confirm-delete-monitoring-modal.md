A reusable confirmation modal for deleting monitoring items (policies or queries), built on top of the shared `ConfirmDialog` component.

## Key Components

### `ConfirmDeleteMonitoringModal`
A wrapper around `ConfirmDialog` that renders a deletion confirmation prompt tailored for monitoring-related items.

**Props (`ConfirmDeleteMonitoringModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback when open state changes |
| `itemName` | `string` | Name of the item being deleted (displayed in error color) |
| `itemType` | `'policy' \| 'query'` | Type of item being deleted |
| `onConfirm` | `() => void` | Callback executed on deletion confirmation |

## Usage Example

```typescript
import { ConfirmDeleteMonitoringModal } from './confirm-delete-monitoring-modal';

function MonitoringList() {
  const [open, setOpen] = useState(false);

  const handleDelete = () => {
    // perform delete logic
  };

  return (
    <ConfirmDeleteMonitoringModal
      open={open}
      onOpenChange={setOpen}
      itemName="CPU Usage Alert"
      itemType="policy"
      onConfirm={handleDelete}
    />
  );
}
```

The confirm button label is dynamically capitalized (e.g., `"Delete Policy"` or `"Delete Query"`), and the `itemName` is highlighted in `text-ods-error` styling to visually emphasize the destructive action.
