React Query hook for managing Fleet osquery queries — provides list, create, update, and delete operations with integrated toast notifications and cache invalidation.

## Key Components

### `queriesQueryKeys`
Structured query key factory for TanStack Query cache management:
- `all` — base key for all queries
- `list(params?)` — scoped to filtered/paginated lists
- `detail(id)` — scoped to a single query by ID

### `useQueries(params?)`
Primary hook exposing full CRUD operations for Fleet queries.

**Returns:**

| Property | Type | Description |
|---|---|---|
| `queries` | `Query[]` | Fetched query list (defaults to `[]`) |
| `isLoading` | `boolean` | Fetch in progress |
| `error` | `string \| null` | Fetch error message |
| `refetch` | `function` | Manual refetch trigger |
| `createQuery` | `function` | Create with success/error callbacks |
| `isCreating` | `boolean` | Create mutation pending |
| `updateQuery` | `function` | Update by ID with callbacks |
| `isUpdating` | `boolean` | Update mutation pending |
| `deleteQuery` | `function` | Delete by ID with callbacks |
| `isDeleting` | `boolean` | Delete mutation pending |
| `queriesQuery` | `UseQueryResult` | Raw query object for advanced use |

## Usage Example

```typescript
import { useQueries } from './use-queries';

function QueriesPanel({ teamId }: { teamId: number }) {
  const {
    queries,
    isLoading,
    createQuery,
    isCreating,
    deleteQuery,
  } = useQueries({ team_id: teamId });

  const handleCreate = () => {
    createQuery(
      { name: 'OS Version', query: 'SELECT * FROM os_version;', team_id: teamId },
      {
        onSuccess: (query) => console.log('Created:', query.id),
        onError: (err) => console.error(err),
      }
    );
  };

  if (isLoading) return <Spinner />;

  return (
    <>
      {queries.map(q => (
        <QueryRow key={q.id} query={q} onDelete={() => deleteQuery(q.id)} />
      ))}
      <button onClick={handleCreate} disabled={isCreating}>
        Add Query
      </button>
    </>
  );
}
```
