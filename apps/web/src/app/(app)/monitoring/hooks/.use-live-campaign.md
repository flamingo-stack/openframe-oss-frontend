## Overview

React hook that runs an ad-hoc osquery "live query" campaign against Fleet, streaming results over a SockJS/WebSocket connection. It handles campaign creation, host-targeting, real-time result/error/status message parsing, and lifecycle management (timeouts, cancellation, cleanup).

## Key Components

- **`useLiveCampaign(options?)`** — Main hook that returns campaign state and control functions (`startCampaign`, `stopCampaign`).
- **`UseLiveCampaignReturn`** — Return shape including `results`, `errors`, `emptyResults`, `totals`, `isRunning`, `stopReason`, `connectionState`, and `campaignStatus`.
- **`UseLiveCampaignOptions`** — Accepts an optional `hostName` resolver to map Fleet host data to display-friendly names (e.g., nickname lookups).
- **`CampaignError` / `CampaignEmptyResult` / `CampaignTotals`** — Typed shapes for per-host error, empty-result, and aggregate count data.
- **`fetchFleetApiToken()`** — Internal GraphQL call to retrieve the Fleet MDM API key used to authenticate the live-query session.
- **`getAllHostsLabelId()`** — Cached lookup for Fleet's dynamic "All Hosts" label, used when targeting campaigns broadly.
- **SockJS frame helpers** (`buildWsUrl`, `encodeSockJsMessage`, `parseSockJsFrame`) — Low-level utilities for building the WebSocket URL and encoding/decoding SockJS protocol frames (`open`, `data`, `heartbeat`, `close`).
- **`FLEET_API_TOKEN_QUERY_KEY`** — TanStack Query key for the cached Fleet API token.

## Usage Example

```typescript
import { useLiveCampaign } from '@/hooks/use-live-campaign';

function LiveQueryRunner() {
  const {
    startCampaign,
    stopCampaign,
    isRunning,
    results,
    errors,
    totals,
    stopReason,
    campaignStatus,
  } = useLiveCampaign({
    hostName: ({ fleetName }) => fleetName, // or resolve from a device registry
  });

  const handleRun = async () => {
    const started = await startCampaign('SELECT * FROM system_info;', [1, 2, 3]);
    if (!started) {
      console.warn('Campaign failed to start');
    }
  };

  return (
    <div>
      <button onClick={handleRun} disabled={isRunning}>
        Run Query
      </button>
      <button onClick={stopCampaign} disabled={!isRunning}>
        Cancel Test
      </button>
      <p>Status: {campaignStatus} ({stopReason ?? 'running'})</p>
      <p>Hosts online: {totals?.online ?? 0}</p>
      <p>Results: {results.length}, Errors: {errors.length}</p>
    </div>
  );
}
```

Notes:
- `startCampaign` resolves `false` if the query is empty or the Fleet API token isn't yet loaded.
- `stopReason` is only `'completed'` when the server reports `status: finished`; cancellations and timeouts use `'canceled'`/other reasons so the UI never shows a false success state.
- The hook automatically cleans up WebSocket connections and timers on unmount.
