React hook for managing Fleet policies (list, create, update, delete) using TanStack Query, with built-in toast notifications and cache invalidation.

## Key Components

- **`policiesQueryKeys`** - Centralized query key factory for policies (`all`, `lists`, `list`, `detail`) to ensure consistent cache keys and support targeted invalidation.
- **`fetchPolicies` / `createPolicyApi` / `updatePolicyApi` / `deletePolicyApi`** - Internal API functions wrapping `fleetApiClient` calls, normalizing errors into thrown `Error` instances.
- **`usePolicies(params?)`** - Main hook exposing:
  - `policies` - array of policies (defaults to empty array via `EMPTY_POLICIES` to avoid unnecessary re-renders)
  - Loading/error state spread from `queryState(policiesQuery)`
  - `refetch` - manual refetch trigger
  - `createPolicy(data, options?)`, `updatePolicy(id, data, options?)`, `deletePolicy(id, options?)` - mutation triggers with success/error toast notifications and optional callbacks
  - `isCreating`, `isUpdating`, `isDeleting` - mutation pending flags
  - `policiesQuery` - raw TanStack Query object for advanced consumers

## Usage Example

```typescript
import { usePolicies } from './use-policies';

function PoliciesPanel({ teamId }: { teamId: number }) {
  const {
    policies,
    isLoading,
    error,
    createPolicy,
    isCreating,
    deletePolicy,
  } = usePolicies({ team_id: teamId });

  if (isLoading) return <p>Loading policies...</p>;
  if (error) return <p>Error: {error.message}</p>;

  const handleCreate = () => {
    createPolicy(
      { name: 'Disk Encryption', query: 'SELECT 1;', description: 'Check encryption status' },
      { onSuccess: () => console.log('Created!') },
    );
  };

  return (
    <div>
      <button onClick={handleCreate} disabled={isCreating}>
        Add Policy
      </button>
      <ul>
        {policies.map(policy => (
          <li key={policy.id}>
            {policy.name}
            <button onClick={() => deletePolicy(policy.id)}>Delete</button>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

Note: Requires `'use client'` directive context (Next.js App Router) and expects `fleetApiClient`, `handleApiError`, and `queryState` utilities to be available in the project.
