Defines the TypeScript interface for aggregated policy compliance statistics used in dashboard summary displays.

## Key Components

### `PolicySummaryStats`
Interface representing a snapshot of policy health metrics:

| Field | Type | Description |
|---|---|---|
| `totalPolicies` | `number` | Total number of policies tracked |
| `failingPolicies` | `number` | Count of non-compliant policies |
| `failingPoliciesPercentage` | `number` | Percentage of failing policies |
| `compliantPolicies` | `number` | Count of passing policies |
| `compliantPoliciesPercentage` | `number` | Percentage of compliant policies |
| `lastUpdatedAt` | `string \| null` | ISO timestamp of last data refresh, or `null` if never updated |

## Usage Example

```typescript
import { PolicySummaryStats } from './policy-summary.types';

const stats: PolicySummaryStats = {
  totalPolicies: 120,
  failingPolicies: 18,
  failingPoliciesPercentage: 15,
  compliantPolicies: 102,
  compliantPoliciesPercentage: 85,
  lastUpdatedAt: '2024-11-01T12:00:00Z',
};

function isHealthy(stats: PolicySummaryStats): boolean {
  return stats.failingPoliciesPercentage < 10;
}
```

## Notes

- `failingPoliciesPercentage` and `compliantPoliciesPercentage` should sum to `100` under normal conditions.
- `lastUpdatedAt` being `null` typically indicates no compliance scan has completed yet.
