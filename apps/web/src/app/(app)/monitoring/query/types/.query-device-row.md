Defines the data model for rows displayed in the Query Details "Assigned Devices" table, representing a merged view of Fleet host data and device registry information.

## Key Components

- **`QueryDeviceTag`** — Simple key/value pair interface representing a device tag.
- **`QueryDeviceRow`** — Row shape for the assigned devices table, combining:
  - Identity fields: `id`, `hostname`, `name`, `machineId`, `fleetHostId`
  - Classification fields: `deviceType`, `osType`
  - Organization display fields: `organization`, `organizationImageUrl`, `organizationImageHash`
  - Status fields: `status` (e.g. `ONLINE` / `OFFLINE`), `lastSeen`
  - `tags`: array of `QueryDeviceTag` associated with the device

This row is built by joining the query's assigned Fleet hosts (via `getQueryHosts`) with the device registry, so `name` falls back to the Fleet host name when no matching device record exists.

## Usage Example

```typescript
import type { QueryDeviceRow, QueryDeviceTag } from './query-device-row';

function buildDeviceRow(host: any, device: any): QueryDeviceRow {
  const tags: QueryDeviceTag[] = device?.tags ?? [];

  return {
    id: device?.id ?? String(host.id),
    hostname: host.hostname,
    name: device ? getDeviceName(device) : host.hostname,
    deviceType: device?.type,
    organization: device?.organization?.name,
    organizationImageUrl: device?.organization?.imageUrl,
    organizationImageHash: device?.organization?.imageHash,
    osType: device?.osType,
    status: device?.status ?? 'OFFLINE',
    lastSeen: device?.lastSeen,
    machineId: device?.machineId,
    fleetHostId: host.id,
    tags,
  };
}

// Rendering in a table component
rows.map((row: QueryDeviceRow) => (
  renderRow(row.name, row.organization, row.status, row.tags)
));
```
