# query-details-view.tsx

Client-side React component that renders the detail page for a single osquery-based monitoring query, displaying its metadata, SQL source with an inline test runner, and tabbed views of query results and assigned devices.

## Key Components

- **`QueryDetailsView`** — Main exported component; accepts a `queryId` prop and orchestrates data fetching, tab/URL sync, and rendering of the full query detail page.
- **`formatInterval(seconds)`** — Formats a numeric interval (seconds) into a human-readable schedule string (e.g., `"Every 5m"`, `"Manual"`).
- **`isQueryDetailTab(value)`** — Type guard validating a URL tab parameter against the allowed `QueryDetailTab` values.
- **`QUERY_TABS`** — Tab configuration array (`Query Results`, `Assigned Devices`) used by `TabNavigation`.
- **`QUERY_DESCRIPTION_SKELETON_LINES`** — Responsive skeleton line-count config for the description loading state.

## Behavior Highlights

- Fetches query details (`useQueryDetails`), report rows (`useQueryReport`), devices (`usePolicyDevices`), and exposes `deleteQuery` via `useQueries`.
- Syncs the active tab (`results` / `devices`) with the `?tab=` URL search param, making the URL the source of truth.
- Registers the open query as Mingo's passive "open view" context via `useTrackOpenView`.
- Shows `LoadError` on fetch failure and `NotFoundError` when the query doesn't exist.
- Renders a read-only `ScriptEditor` (SQL shell) alongside `TestQuerySection` for ad hoc query testing.
- Supports editing (navigates to edit route), and deleting (via `ConfirmDeleteMonitoringModal`) with safe back-navigation to the monitoring queries list.

## Usage Example

```typescript
import { QueryDetailsView } from './query-details-view';

// Typically rendered from a Next.js dynamic route, e.g. app/monitoring/queries/[queryId]/page.tsx
export default function QueryDetailPage({ params }: { params: { queryId: string } }) {
  return <QueryDetailsView queryId={params.queryId} />;
}
```

The component expects no additional props beyond `queryId` (a string, parsed internally to a number) and manages all data fetching, loading states, and navigation internally.
