# use-query-details.ts

A React hook that fetches detailed information for a single saved query from the Fleet API using React Query, with support for conditional fetching.

## Key Components

- **`fetchQuery(id: number): Promise<Query>`** — Internal async function that calls `fleetApiClient.getQuery(id)`, validates the response, and unwraps the nested `{ query: {...} }` payload returned by the Fleet API into a flat `Query` object.
- **`useQueryDetails(queryId: number | null)`** — Public hook that wraps `fetchQuery` in a `useQuery` call. When `queryId` is `null`, it uses TanStack Query's `skipToken` to disable the fetch entirely (useful when a query ID hasn't been selected yet).

### Return Value

The hook returns an object with:
- `queryDetails` — The fetched `Query` object, or `null` if not yet loaded/disabled.
- `isLoading` — Boolean loading state.
- `error` — Error message string, or `null` if no error occurred.
- `refetch` — Function to manually trigger a refetch.

## Usage Example

```typescript
import { useQueryDetails } from './use-query-details';

function QueryDetailPanel({ queryId }: { queryId: number | null }) {
  const { queryDetails, isLoading, error, refetch } = useQueryDetails(queryId);

  if (isLoading) return <p>Loading query details...</p>;
  if (error) return <p>Error: {error}</p>;
  if (!queryDetails) return <p>No query selected.</p>;

  return (
    <div>
      <h2>{queryDetails.name}</h2>
      <pre>{queryDetails.query}</pre>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}
```

This hook is typically used in query detail views or edit forms where fetching should only occur once a valid `queryId` is available, avoiding unnecessary API calls when no selection has been made.
