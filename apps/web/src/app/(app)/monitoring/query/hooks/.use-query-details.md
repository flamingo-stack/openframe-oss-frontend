Fetches and returns the details of a single Fleet query by ID using React Query, wrapping the Fleet API client response into a normalized shape.

## Key Components

- **`fetchQuery(id)`** — Async function that calls `fleetApiClient.getQuery(id)`, unwraps the Fleet API's `{ query: {...} }` envelope, and throws on error.
- **`useQueryDetails(queryId)`** — Custom React Query hook that conditionally fetches a query's details. Skips the request when `queryId` is `null`.

## Usage Example

```typescript
import { useQueryDetails } from './use-query-details';

function QueryDetailPanel({ queryId }: { queryId: number | null }) {
  const { queryDetails, isLoading, error, refetch } = useQueryDetails(queryId);

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;
  if (!queryDetails) return null;

  return (
    <div>
      <h2>{queryDetails.name}</h2>
      <pre>{queryDetails.query}</pre>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}
```

## Notes

- The hook is **disabled** when `queryId` is `null`, preventing unnecessary API calls.
- Cache keys are managed via `queriesQueryKeys.detail()` for consistency with the broader queries query key factory.
- The Fleet API response envelope `{ query: Query }` is explicitly cast to avoid a naming conflict with the `Query.query` field on the `Query` type.
