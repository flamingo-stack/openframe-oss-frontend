# use-query-hosts.ts

React Query hooks for fetching and managing the hosts (devices) assigned to a Fleet osquery query, handling paginated fetching and host assignment replacement via the Fleet API.

## Key Components

- **`queryHostsQueryKeys`** - Query key factory for cache management, scoped by `queryId` to enable targeted invalidation.
- **`fetchAllQueryHosts(queryId)`** - Internal async function that paginates through the Fleet API (`per_page: 100`) until `has_next_results` is false, aggregating all hosts into a single array.
- **`replaceQueryHostsApi(params)`** - Internal async function that replaces the full set of host IDs assigned to a query via `fleetApiClient.replaceQueryHosts`.
- **`useQueryHosts(queryId)`** - Query hook that fetches all hosts assigned to a query. Uses `skipToken` to disable the query when `queryId` is `null`. Returns `hosts` (defaults to a stable empty array), `isLoading`, `error` (string or `null`), and `refetch`.
- **`useReplaceQueryHosts()`** - Mutation hook for bulk-replacing a query's assigned hosts. On success, invalidates both the query-hosts list and the related query detail cache (from `use-queries`). On error, surfaces a toast via `handleApiError`.

## Usage Example

```typescript
import { useQueryHosts, useReplaceQueryHosts } from './use-query-hosts';

function QueryHostsPanel({ queryId }: { queryId: number | null }) {
  const { hosts, isLoading, error, refetch } = useQueryHosts(queryId);
  const replaceHosts = useReplaceQueryHosts();

  const handleAssign = (hostIds: number[]) => {
    if (queryId === null) return;
    replaceHosts.mutate({ queryId, hostIds });
  };

  if (isLoading) return <p>Loading hosts...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <div>
      <p>{hosts.length} hosts assigned</p>
      <button onClick={() => handleAssign([1, 2, 3])}>
        Update Assignments
      </button>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}
```

## Notes

- Fully paginates results client-side, so `hosts` always contains the complete list rather than a single page.
- `EMPTY_QUERY_HOSTS` is a module-level constant to avoid returning a new empty array reference on every render.
- Depends on `queriesQueryKeys` from `../../hooks/use-queries` to keep query detail data in sync after host reassignment.
