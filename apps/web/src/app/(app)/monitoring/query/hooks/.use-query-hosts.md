Provides React Query hooks for fetching and replacing hosts associated with a Fleet query, with automatic pagination and cache invalidation.

## Key Components

- **`queryHostsQueryKeys`** — Structured query key factory for `query-hosts` cache entries, scoped by `queryId`
- **`fetchAllQueryHosts(queryId)`** — Internal async function that paginates through all host pages (100 per page) until `has_next_results` is false
- **`replaceQueryHostsApi(params)`** — Internal async function that calls `fleetApiClient.replaceQueryHosts` with a new set of host IDs
- **`useQueryHosts(queryId)`** — Query hook that loads all hosts for a given query; returns `hosts`, `isLoading`, `error`, and `refetch`; skips fetching when `queryId` is `null`
- **`useReplaceQueryHosts()`** — Mutation hook that replaces the host list for a query, then invalidates both the hosts list and the parent query detail cache; surfaces errors via toast

## Usage Example

```typescript
// Fetch all hosts assigned to a query
const { hosts, isLoading, error } = useQueryHosts(queryId);

// Replace assigned hosts
const { mutate: replaceHosts, isPending } = useReplaceQueryHosts();

replaceHosts(
  { queryId: 42, hostIds: [1, 2, 3] },
  { onSuccess: () => console.log('Hosts updated') }
);
```

## Notes

- `queryId` accepts `null` to support conditional rendering patterns; the query is disabled until a valid ID is provided
- On successful replacement, both `queryHostsQueryKeys.list(queryId)` and `queriesQueryKeys.detail(queryId)` are invalidated to keep related query detail data in sync
