# use-query-devices-table.ts

A React hook that builds the row data for a Query's "Assigned Devices" table by fetching the Fleet hosts assigned to a given query and enriching each one with data from the device registry.

## Key Components

- **`fetchQueryHosts(queryId)`** — Internal async helper that paginates through Fleet's `getQueryHosts` API (page-based pagination, 100 hosts per page) and returns the full flat list of `{ id, hostname }` entries assigned to the query. Guards against infinite loops if the API misreports `has_next_results`.
- **`useQueryDevicesTable(queryId)`** — Main exported hook. Combines:
  - A `useQuery` call that fetches assigned hosts via `fetchQueryHosts` (skipped via `skipToken` when `queryId` is `null`).
  - `useAllDevices` to load the enriched device registry (filtered by `DEVICE_ENRICHMENT_FILTER`).
  - A memoized merge step that indexes devices by Fleet host id (`indexDevicesByFleetHostId`), joins each assigned host to its device record (falling back to host-only fields when no match exists), flattens tags, and sorts rows alphabetically by display name.

Returns `{ rows: QueryDeviceRow[], isLoading: boolean, error: string | undefined }`.

## Usage Example

```typescript
import { useQueryDevicesTable } from './use-query-devices-table';

function QueryAssignedDevicesTable({ queryId }: { queryId: number | null }) {
  const { rows, isLoading, error } = useQueryDevicesTable(queryId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <DataTable
      rows={rows}
      columns={[
        { key: 'name', label: 'Device' },
        { key: 'organization', label: 'Organization' },
        { key: 'status', label: 'Status' },
        { key: 'lastSeen', label: 'Last Seen' },
      ]}
    />
  );
}
```

**Notes:**
- Passing `queryId: null` disables both the hosts fetch (via `skipToken`) and device enrichment (`enabled: queryId !== null`), returning an empty `rows` array.
- Rows always resolve a display name and hostname even when no matching device record exists, falling back to `Host {id}`.
