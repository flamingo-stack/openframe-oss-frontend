# use-query-report.ts

A React hook that fetches a saved Fleet query's report results and enriches each row with human-friendly device names and formatted timestamps, ready for display in a data table.

## Key Components

- **`fetchQueryReport(queryId)`** — Internal async function that calls `fleetApiClient.getQueryReport` and throws if the response is unsuccessful or missing data.
- **`flattenResults(results, deviceByFleetId)`** — Internal helper that transforms raw report results into `QueryResultRow` objects, resolving each row's device name (preferring the registry device's nickname, falling back to Fleet's `host_name`) and formatting the `last_fetched` timestamp.
- **`useQueryReport(queryId)`** — Main hook export. Fetches the query report via `useQuery` (skipped when `queryId` is `null`), cross-references results with the full device list (via `useAllDevices`, deduplicated by react-query), and returns enriched, display-ready rows.

## Usage Example

```typescript
import { useQueryReport } from './use-query-report';

function QueryReportTable({ queryId }: { queryId: number | null }) {
  const { rows, reportClipped, isLoading, error, refetch } = useQueryReport(queryId);

  if (isLoading) return <p>Loading report...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <div>
      {reportClipped && <p>Report was truncated; some results may be missing.</p>}
      <DataTable rows={rows} onRefresh={refetch} />
    </div>
  );
}
```

## Notes

- Returns an empty `rows` array until both the query report and device list have loaded.
- `reportClipped` indicates whether Fleet truncated the report results.
- Device enrichment reuses the same `useAllDevices` call made elsewhere on the page (e.g., the Devices tab), so react-query deduplicates the network request.
