Defines TypeScript types representing a device's compliance status within a policy, used to render device rows in policy-related tables or lists across the UI.

## Key Components

- **`ComplianceStatus`** - Union type representing the three possible compliance states of a device: `'non-compliant'`, `'passing'`, or `'pending'`.
- **`PolicyDeviceRow`** - Interface describing the shape of a single device row, including identifiers (`id`, `hostname`, `machineId`, `fleetHostId`), display metadata (`name`, `deviceType`, `osType`), organization context (`organization`, `organizationImageUrl`, `organizationImageHash`), and the device's `complianceStatus`.

## Usage Example

```typescript
import type { PolicyDeviceRow, ComplianceStatus } from './policy-device-row';

function renderStatusBadge(status: ComplianceStatus): string {
  switch (status) {
    case 'passing':
      return '✅ Passing';
    case 'non-compliant':
      return '❌ Non-compliant';
    case 'pending':
      return '⏳ Pending';
  }
}

const row: PolicyDeviceRow = {
  id: 'dev-123',
  hostname: 'host-01.local',
  name: 'Marketing Laptop',
  deviceType: 'laptop',
  organization: 'Acme Corp',
  organizationImageUrl: 'https://cdn.example.com/acme.png',
  organizationImageHash: 'abc123',
  osType: 'macOS',
  complianceStatus: 'passing',
  machineId: 'm-456',
  fleetHostId: 789,
};

console.log(renderStatusBadge(row.complianceStatus));
```

This type is typically consumed by table components that list devices affected by a given compliance policy, mapping backend data (from Fleet and device inventory services) into a normalized row shape for display.
