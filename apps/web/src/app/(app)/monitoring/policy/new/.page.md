A Next.js client-side page component that renders the policy creation flow by wrapping the shared `EditPolicyPage` component with a `null` policy ID, indicating a new (unsaved) policy.

## Key Components

- **`NewPolicyPageWrapper`** — Default export; a thin wrapper that mounts `EditPolicyPage` in "create new" mode by passing `policyId={null}`.

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to the /policies/new route.
// No manual instantiation needed; the page is driven by the router.

// The underlying component handles both create and edit modes:
<EditPolicyPage policyId={null} />   // create mode (this file)
<EditPolicyPage policyId="abc-123" /> // edit mode (used elsewhere)
```

## Notes

- The `'use client'` directive marks this as a Client Component, enabling interactivity and hooks within `EditPolicyPage`.
- The shared `EditPolicyPage` component (in `../components/edit-policy-page`) handles all form state and submission logic for both creating and editing policies — `policyId={null}` signals a new record.
