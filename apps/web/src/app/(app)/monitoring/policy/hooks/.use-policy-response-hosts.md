A React hook that fetches hosts filtered by their compliance status (passing or failing) for a given Fleet policy, using TanStack Query for caching and state management.

## Key Components

- **`policyResponseHostsQueryKeys`** — Query key factory for scoping and invalidating cached queries related to policy response hosts, keyed by `policyId` and response status.
- **`fetchPolicyResponseHosts(policyId, policyResponse)`** — Internal async function that calls `fleetApiClient.getHosts` with policy filters (`policy_id`, `policy_response`, `per_page: 100`, `disable_failing_policies: true`) and returns the list of hosts, throwing on error.
- **`usePolicyResponseHosts(policyId, policyResponse)`** — Main exported hook that wraps the fetch logic in `useQuery`. Automatically skips the query when `policyId` is `null` (via `skipToken`), and returns a simplified result shape.

## Usage Example

```typescript
import { usePolicyResponseHosts } from '@/hooks/use-policy-response-hosts';

function PassingHostsList({ policyId }: { policyId: number | null }) {
  const { hosts, isLoading, error } = usePolicyResponseHosts(policyId, 'passing');

  if (isLoading) return <p>Loading hosts...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {hosts.map((host) => (
        <li key={host.id}>{host.hostname}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Returns a stable `EMPTY_HOSTS` array reference when no data is available, avoiding unnecessary re-renders.
- Query is automatically disabled (`enabled: policyId !== null`) until a valid `policyId` is provided.
- Use `policyResponseHostsQueryKeys.list(policyId, response)` with `queryClient.invalidateQueries` to manually refresh host data after policy changes.
