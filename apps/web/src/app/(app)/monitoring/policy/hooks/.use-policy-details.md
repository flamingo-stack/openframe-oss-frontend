A client-side React hook for fetching a single policy's details by ID using TanStack Query, with built-in support for conditional fetching when no policy is selected.

## Key Components

- **`fetchPolicy(id)`** — Async helper that calls `fleetApiClient.getPolicy(id)` and throws an error if the response is unsuccessful or missing data; otherwise returns the `Policy` payload.
- **`usePolicyDetails(policyId)`** — Hook that wraps `useQuery` to fetch policy details, keyed by `policiesQueryKeys.detail(policyId)`. Uses `skipToken` instead of the `enabled` option when `policyId` is `null`, which both disables the query and type-narrows `policyId` to `number` inside the `queryFn`, avoiding a non-null assertion.

## Usage Example

```typescript
import { usePolicyDetails } from './use-policy-details';

function PolicyDetailsPanel({ policyId }: { policyId: number | null }) {
  const { policyDetails, isLoading, error, refetch } = usePolicyDetails(policyId);

  if (isLoading) return <p>Loading policy...</p>;
  if (error) return <p>Error: {error}</p>;
  if (!policyDetails) return <p>No policy selected</p>;

  return (
    <div>
      <h2>{policyDetails.name}</h2>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}
```

The hook returns `policyDetails` as `null` until data loads or when `policyId` is `null`, along with `isLoading`, a stringified `error` message (or `null`), and a `refetch` function to manually re-trigger the query.
