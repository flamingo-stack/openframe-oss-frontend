Provides a React Query hook for fetching and deduplicating all online/offline devices for use in policy device selectors, handling paginated GraphQL requests internally.

## Key Components

- **`usePolicyDevices`** — The only export. Reads the ONLINE/OFFLINE fleet through `useAllDevices` (the app's single device query layer, which owns the pagination loop), then collapses Fleet-connected devices to one row per Fleet host via `indexDevicesByFleetHostId` and appends the devices that have no Fleet connection.

## Usage Example

```typescript
import { usePolicyDevices } from './use-policy-devices';

function PolicyDeviceSelector() {
  const { devices, isLoading } = usePolicyDevices();

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {devices.map(device => (
        <li key={device.id}>{device.hostname}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Pagination is handled by `useAllDevices` — all pages are fetched before the query resolves, and it stops when the cursor can't advance even if the server still reports a next page.
- Fleet devices are deduplicated by host ID (most recent `lastSeen` wins) before being merged with non-Fleet devices; non-Fleet devices are appended as-is.
- The cache lives under `deviceQueryKeys.full(filter)`, so `invalidateDeviceQueries` refreshes this selector along with every other device surface, and the policy and query selectors share one fetch.
