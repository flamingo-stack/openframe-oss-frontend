# use-policy-devices.ts

A React hook that supplies the deduplicated device list used by policy and query device selectors, collapsing Fleet-connected devices to a single row per Fleet host.

## Key Components

- **`usePolicyDevices()`** — Hook that fetches online/offline devices and returns a deduplicated device list along with a loading state.
- **`POLICY_DEVICE_FILTER`** — Constant `DeviceFilterInput` restricting fetched devices to `DEVICE_STATUS.ONLINE` and `DEVICE_STATUS.OFFLINE`.

### Behavior

1. Fetches all devices matching `POLICY_DEVICE_FILTER` via `useAllDevices`.
2. Splits devices into:
   - **Non-Fleet devices** — devices without a Fleet host ID (`getFleetHostId` returns `undefined`), kept as-is.
   - **Fleet devices** — devices with a Fleet host ID, deduplicated via `indexDevicesByFleetHostId` so re-enrolled machines (which can leave multiple device records behind the same Fleet host) appear only once.
3. Combines both groups into a single memoized `devices` array, recomputed only when `allDevices` changes.

## Usage Example

```typescript
import { usePolicyDevices } from './use-policy-devices';

function PolicyDeviceSelector() {
  const { devices, isLoading } = usePolicyDevices();

  if (isLoading) {
    return <Spinner />;
  }

  return (
    <ul>
      {devices.map(device => (
        <li key={device.id}>{device.name}</li>
      ))}
    </ul>
  );
}
```

This hook is intended for use in UI components where a user selects target devices for a policy or query, ensuring Fleet-managed hosts are represented only once regardless of how many underlying device records exist.
