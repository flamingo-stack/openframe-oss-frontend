Provides React Query hooks for fetching and replacing the list of hosts assigned to a Fleet policy, with paginated fetching and cache invalidation on mutation.

## Key Components

### Query Keys

- **`policyHostsQueryKeys`** — Structured query key factory with `all` and `list(policyId)` for scoped cache management.

### API Functions

- **`fetchAllPolicyHosts(policyId)`** — Paginates through all pages (`per_page: 100`) of the Fleet API to return a complete `PolicyHost[]` list.
- **`replacePolicyHostsApi(params)`** — Calls the Fleet API to atomically replace all host assignments for a given policy.

### Hooks

- **`usePolicyHosts(policyId)`** — Query hook that fetches all hosts for a policy. Returns `hosts`, `isLoading`, `error`, and `refetch`. Skips fetching when `policyId` is `null`.
- **`useReplacePolicyHosts()`** — Mutation hook that replaces policy host assignments. On success, invalidates the policy hosts list, all policies, and policy response hosts caches, then shows a success toast. On error, delegates to `handleApiError`.

## Usage Example

```typescript
// Fetch hosts assigned to a policy
const { hosts, isLoading } = usePolicyHosts(42);

// Replace host assignments
const { mutate: replaceHosts } = useReplacePolicyHosts();

replaceHosts(
  { policyId: 42, hostIds: [1, 2, 3] },
);
```

## Cache Invalidation

On a successful replacement, three query caches are invalidated to ensure UI consistency:

| Cache | Reason |
|---|---|
| `policyHostsQueryKeys.list(policyId)` | Reflect the updated host list |
| `policiesQueryKeys.all` | Refresh policy-level pass/fail counts |
| `policyResponseHostsQueryKeys.all` | Clear stale pre-assignment device status snapshots |
