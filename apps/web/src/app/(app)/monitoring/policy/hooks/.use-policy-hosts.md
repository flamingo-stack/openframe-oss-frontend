# use-policy-hosts.ts

Client-side React Query hooks for fetching and managing the set of devices (hosts) assigned to a Fleet policy. Handles paginated host retrieval and bulk replacement of policy-host assignments, with appropriate cache invalidation across related query domains.

## Key Components

- **`policyHostsQueryKeys`** — Query key factory for policy hosts, scoped by `policyId` to support targeted cache invalidation.
- **`fetchAllPolicyHosts(policyId)`** — Internal function that paginates through Fleet's `getPolicyHosts` API (100 per page) until all hosts are retrieved, aggregating results into a single array.
- **`replacePolicyHostsApi(params)`** — Internal function that calls `fleetApiClient.replacePolicyHosts` to overwrite the full set of host IDs assigned to a policy.
- **`usePolicyHosts(policyId)`** — Query hook returning `hosts`, `isLoading`, `error`, and `refetch`. Uses `skipToken` to avoid fetching when `policyId` is `null`, and defaults to a stable empty array to prevent unnecessary re-renders.
- **`useReplacePolicyHosts()`** — Mutation hook that replaces a policy's host assignments. On success, invalidates:
  - the specific policy's host list,
  - all policies queries (`policiesQueryKeys.all`),
  - policy response hosts (`policyResponseHostsQueryKeys.all`), since Fleet's passing/failing membership data becomes stale after reassignment.
  
  Shows success/error toasts via `useToast` and `handleApiError`.

## Usage Example

```typescript
import { usePolicyHosts, useReplacePolicyHosts } from './use-policy-hosts';

function PolicyDeviceAssignment({ policyId }: { policyId: number | null }) {
  const { hosts, isLoading, error } = usePolicyHosts(policyId);
  const replaceHosts = useReplacePolicyHosts();

  const handleSave = (selectedHostIds: number[]) => {
    if (policyId === null) return;
    replaceHosts.mutate({ policyId, hostIds: selectedHostIds });
  };

  if (isLoading) return <p>Loading devices...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <div>
      <p>{hosts.length} devices assigned</p>
      <button onClick={() => handleSave([1, 2, 3])} disabled={replaceHosts.isPending}>
        Save Assignment
      </button>
    </div>
  );
}
```
