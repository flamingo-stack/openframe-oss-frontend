This hook builds the device compliance table for a Fleet policy by merging policy-assigned hosts with their live failing/passing status and enriched device metadata.

## Key Components

- **`usePolicyDevicesTable(policyId, assignedHostIds?)`** - Main hook that assembles `PolicyDeviceRow[]` data for rendering a policy's device compliance table.
- **`rows`** - Memoized, sorted array of `PolicyDeviceRow` objects (non-compliant first, then pending, then passing; alphabetical within each group).
- **`isLoading`** - Combined loading state from failing hosts, passing hosts, and device enrichment queries.
- **`error`** - Propagated error from the device enrichment fetch.

### Internal logic
- Uses `assignedHostIds` as the source of truth for which devices appear in the table, since Fleet retains stale failing/passing responses for hosts until their next check-in.
- Computes a `statusMap` (`'non-compliant' | 'passing' | 'pending'`) per host ID by cross-referencing assigned hosts against `usePolicyResponseHosts` results for both `failing` and `passing` statuses.
- Enriches each row with device metadata (hostname, display name, type, organization, OS, machine ID) via `indexDevicesByFleetHostId`, falling back to Fleet host info when a matching device isn't found.

## Usage Example

```typescript
import { usePolicyDevicesTable } from './use-policy-devices-table';

function PolicyDevicesTable({ policyId, assignedHosts }: {
  policyId: number | null;
  assignedHosts: Array<{ id: number; hostname: string }>;
}) {
  const { rows, isLoading, error } = usePolicyDevicesTable(policyId, assignedHosts);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  return (
    <Table>
      {rows.map(row => (
        <TableRow key={row.id} status={row.complianceStatus}>
          {row.name} - {row.organization}
        </TableRow>
      ))}
    </Table>
  );
}
```
