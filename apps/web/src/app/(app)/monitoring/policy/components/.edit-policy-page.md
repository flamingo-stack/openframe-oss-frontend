## edit-policy-page.tsx

A page-level React component that renders a create/edit form for monitoring policies, handling policy metadata, an osquery SQL query editor with inline testing, and device assignment selection.

## Key Components

- **`EditPolicyPage`** — Main exported component. Accepts a `policyId` prop (string or `null`); when `null` it operates in "create" mode, otherwise it fetches and edits the existing policy.
- **`policyFormSchema`** / **`PolicyFormData`** — Zod schema and inferred type validating `name` (required), `description`, and `query` fields.
- **`getDeviceKey`** — Helper that derives a stable string key for a `Device` using its Fleet host ID.
- **Data hooks used**: `usePolicyDetails`, `usePolicies` (create/update), `usePolicyHosts`/`useReplacePolicyHosts` (device assignment), `usePolicyDevices` (available devices list).
- **UI building blocks**: `PageLayout`, `Input`, `Textarea`, `Label`, `ScriptEditor` (SQL editor), `TestQuerySection`, `DeviceSelector`, `LoadingWhen`, `LoadError`, `NotFoundError` from `@flamingo-stack/openframe-frontend-core`.

## Behavior Notes

- Form state is managed with `react-hook-form` + `zodResolver`, seeded from fetched `policyDetails` during render (not in an effect) to avoid a blank-form flash.
- Selected device host IDs are tracked as a `Set<number>`, initialized once from existing policy host assignments via a render-time guard (`hostsInitialized`).
- On submit, the policy is created/updated first, then host assignments are replaced via a separate mutation; host-assignment failures surface via toast without blocking navigation.
- Navigation uses `useSafeBack`/`safeBackOrReplace` to return to the policy detail page or the policies tab.

## Usage Example

```typescript
// Rendered by a Next.js route segment, e.g. app/monitoring/policies/[policyId]/edit/page.tsx
import { EditPolicyPage } from './edit-policy-page';

export default function Page({ params }: { params: { policyId: string } }) {
  return <EditPolicyPage policyId={params.policyId} />;
}

// Create-mode usage:
<EditPolicyPage policyId={null} />
```
