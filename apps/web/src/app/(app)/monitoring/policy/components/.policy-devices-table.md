Renders the devices table for a security policy view, displaying assigned hosts with their compliance status and supporting per-device live query execution via an expandable sub-row.

## Key Components

### `PolicyDevicesTable` (default export)

The main component that combines device listing with live campaign-based query execution.

**Props:**

| Prop | Type | Description |
|---|---|---|
| `policyId` | `number` | ID of the policy to fetch device assignments for |
| `assignedHostIds` | `Array<{ id: number; hostname: string }>` | Optional pre-filtered list of hosts |
| `policyQuery` | `string` | osquery SQL string; enables the "Run on This Device" button |

### Internal Types

- **`DeviceRunOutcome`** — `'pass' | 'fail' | 'error' | 'no-response'`
- **`DeviceRunSnapshot`** — holds the frozen result of a single-device campaign run (outcome, rows, optional error message)

### Key Hooks Used

- `usePolicyDevicesTable` — fetches and shapes `PolicyDeviceRow[]` for the given policy
- `useLiveCampaign` — manages the osquery live campaign lifecycle (start, status, results)
- `useDataTable` — wires columns and data into a sortable/pageable table instance

## Usage Example

```typescript
<PolicyDevicesTable
  policyId={42}
  assignedHostIds={[{ id: 1, hostname: 'host-a' }, { id: 2, hostname: 'host-b' }]}
  policyQuery="SELECT 1 FROM users WHERE uid = 0 AND password_last_set > 0;"
/>
```

## Behaviour Notes

- Expanding a row reveals a **"Run on This Device"** button that fires the policy SQL against that host via `useLiveCampaign`.
- Each device's last run outcome is frozen into `runsByHost` (a `Map<hostId, DeviceRunSnapshot>`) so switching between expanded rows preserves individual results.
- When a run finishes, the outcome maps to one of four states rendered as a `Tag` + plain-text detail string (`RUN_OUTCOME_TAG` / `runOutcomeDetail`).
- If `policyQuery` is absent or blank, `canRun` is `false` and the run button is disabled.
- The table header is hidden when there are no rows and loading is complete, matching the empty-state design spec.
