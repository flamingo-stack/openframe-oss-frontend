Policy details page component that handles routing for viewing a specific monitoring policy, including a legacy redirect for the deprecated `?id=new` URL pattern.

## Key Components

- **`PolicyPage`** — Default export page component that reads the `id` query parameter and renders the appropriate view or redirects
- **Legacy redirect** — Intercepts `?id=new` requests (from pre-alignment policy creation links) and redirects to the dedicated `routes.monitoring.policyNew` route
- **`PolicyDetailsView`** — Delegated component that receives the resolved `policyId` and renders the full policy detail UI

## Usage Example

```typescript
// Accessed via URL: /monitoring/policy?id=abc123
// Renders: <PolicyDetailsView policyId="abc123" />

// Accessed via legacy URL: /monitoring/policy?id=new
// Redirects to: routes.monitoring.policyNew
```

## Notes

- Returns `null` during the redirect cycle when `paramId === 'new'` to prevent a flash of the details view
- Falls back to an empty string (`''`) if no `id` param is present, delegating any empty-state handling to `PolicyDetailsView`
