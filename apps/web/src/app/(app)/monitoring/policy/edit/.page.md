Wrapper page component that extracts and validates the required `id` route parameter before rendering the policy editor.

## Key Components

- **`EditPolicyPageWrapper`** — Default export; a client-side page component that guards against missing `id` params by redirecting to the policies list or new policy route if the param is absent.
- **`useRequiredIdParam`** — Hook that reads the `id` from the URL, redirecting to a fallback route if it's not present.
- **`EditPolicyPage`** — The underlying editor component rendered once a valid `policyId` is confirmed.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to:
// /monitoring/policies/[id]/edit

// If `id` is missing, redirects to:
//   routes.monitoring.root({ tab: 'policies' })
// or:
//   routes.monitoring.policyNew

// If `id` is present, renders:
<EditPolicyPage policyId={id} />
```

## Notes

- Marked `'use client'` — runs only in the browser.
- Returns `null` during the redirect cycle to avoid rendering with an invalid state.
- Follows the project pattern of separating param-extraction logic (wrapper) from UI logic ([`EditPolicyPage`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/monitoring/policies/components/edit-policy-page.tsx)).
