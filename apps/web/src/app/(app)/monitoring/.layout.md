Defines route metadata and layout delegation for the Monitoring section, setting the page title via Next.js's `Metadata` API while reusing a shared layout component.

## Key Components

- **`metadata`** — A `Metadata` object exported for Next.js to apply the page `<title>`, generated using the `routeTitle` helper with `'Monitoring'` as the section label.
- **`default` export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as this route segment's layout, avoiding duplication of layout logic across sections.

## Usage Example

This file follows the Next.js App Router convention for a `layout.tsx` file within a route segment (e.g., `app/(app)/monitoring/layout.tsx`). It doesn't need to be imported manually—Next.js automatically applies it to all pages under the `Monitoring` route segment.

```typescript
// app/(app)/monitoring/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Monitoring') };
```

To add a similarly titled layout for another section, replicate this pattern with a different label:

```typescript
export const metadata: Metadata = { title: routeTitle('Devices') };
```

This keeps page titles consistent across the app while centralizing layout structure in `route-title-layout`.
