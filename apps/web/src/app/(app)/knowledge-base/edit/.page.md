Renders the edit article page for an existing knowledge base article, retrieving a required `id` route parameter before delegating rendering to the shared article form component.

## Key Components

- **`EditArticlePage`** — Default page export that validates the presence of an article ID from the URL and renders the edit form, or redirects/returns null if the ID is missing.
- **`useRequiredIdParam`** — Hook that extracts and validates the `id` route parameter, redirecting to `/knowledge-base` or `/knowledge-base/new` if absent.
- **`ArticleFormPage`** — Shared form component used for both creating and editing articles, driven by the `articleId` prop.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to:
// /knowledge-base/[id]/edit

// If `id` is missing or invalid, the user is redirected to
// /knowledge-base or /knowledge-base/new.
// Otherwise, the ArticleFormPage is rendered in edit mode:
<ArticleFormPage articleId="abc-123" />
```

## Notes

- Marked as a Client Component via `'use client'` — required for hook usage.
- Acts as a thin routing wrapper; all form logic lives in [`ArticleFormPage`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/knowledge-base/components/article-form-page.tsx).
