Renders the Knowledge Base archive page, displaying a list of archived articles within a shared page shell layout that handles loading and error states.

## Key Components

- **`ArchivePage`** (default export): A Next.js client component that serves as the route entry point for the archive page. It composes `KnowledgeBasePageShell` and `ArchivedArticlesView` to render archived knowledge base articles with built-in error handling.

## Usage Example

This file is a Next.js App Router page component and is automatically rendered when navigating to the archive route (e.g., `/archive`). It is not typically imported directly elsewhere in the codebase.

```typescript
// File location (by Next.js convention):
// app/archive/page.tsx  (or similar route segment)

// Automatically invoked by Next.js routing when the
// corresponding URL path is visited. No manual import needed.

// Example of the resulting rendered structure:
export default function ArchivePage() {
  return (
    <KnowledgeBasePageShell errorMessage="Couldn't load the archive.">
      <ArchivedArticlesView />
    </KnowledgeBasePageShell>
  );
}
```

The `KnowledgeBasePageShell` wraps content with consistent layout, loading indicators, and error boundary behavior—displaying `"Couldn't load the archive."` if data fetching fails. The actual archived article listing logic is encapsulated within `ArchivedArticlesView`, keeping this page component minimal and declarative.
