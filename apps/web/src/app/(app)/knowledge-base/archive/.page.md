Renders the Knowledge Base Archive page, displaying articles that have been archived within a shared page layout that handles loading and error states.

## Key Components

- **`ArchivePage`** - Default exported Next.js page component (client component) for the `/archive` route in the Knowledge Base module.
- **`KnowledgeBasePageShell`** - Shared layout wrapper providing consistent page structure and error handling via the `errorMessage` prop.
- **`ArchivedArticlesView`** - Renders the list/grid of archived knowledge base articles.

## Usage Example

```typescript
// This file is automatically routed by Next.js App Router
// based on its location, e.g.:
// app/knowledge-base/archive/page.tsx

export default function ArchivePage() {
  return (
    <KnowledgeBasePageShell errorMessage="Couldn't load the archive.">
      <ArchivedArticlesView />
    </KnowledgeBasePageShell>
  );
}
```

This component requires no props since it's a Next.js page entry point. It composes the `KnowledgeBasePageShell` for consistent error/loading UX across Knowledge Base pages, delegating the actual archived content rendering to `ArchivedArticlesView`. The `'use client'` directive indicates this page relies on client-side interactivity (likely state or data fetching hooks used within child components).
