Provides Relay connection ID helpers, GraphQL query, and folder tree utilities for knowledge base item navigation in the OpenFrame frontend.

## Key Components

### Connection Key Constants
- `KNOWLEDGE_BASE_FOLDERS_CONNECTION_KEY` — Relay connection key for folder listings
- `KNOWLEDGE_BASE_ARTICLES_CONNECTION_KEY` — Relay connection key for flat article listings
- `KNOWLEDGE_BASE_ARTICLES_SUBTREE_CONNECTION_KEY` — Relay connection key for full subtree article listings

### Connection ID Helpers
- `getKnowledgeBaseFoldersConnectionId(filter)` — Generates a Relay `ConnectionHandler` ID for folders, scoped by `parentId`, `search`, and `tagIds`
- `getKnowledgeBaseArticlesConnectionId(filter)` — Same as above but for articles (`type: 'ARTICLE'`)
- `getKnowledgeBaseArticlesSubtreeConnectionId(filter)` — Generates a connection ID for all items regardless of type (subtree traversal)

### Hook
- `useKnowledgeBaseFolders()` — Relay `useLazyLoadQuery` hook returning a flat `FolderOption[]` list using `store-and-network` fetch policy

### Utilities
- `buildFolderTree(folders)` — Converts a flat `FolderOption[]` array into a nested `FolderTreeNode[]` tree, sorted alphabetically at each level
- `normalizeTagIds(tagIds)` — Internal helper that converts an empty/undefined tag array to `null` for consistent GraphQL filtering

### Types
- `KnowledgeBaseItemsConnectionFilter` — Filter shape used by all connection ID helpers
- `FolderOption` — Flat folder data: `{ id, name, parentId }`
- `FolderTreeNode` — Extends `FolderOption` with a recursive `children` array

} from './use-knowledge-base-items';

  const folders = useKnowledgeBaseFolders();
  const tree = buildFolderTree(folders);

// Generate a Relay connection ID for cache invalidation or store reads
const connectionId = getKnowledgeBaseArticlesConnectionId({
  parentId: 'folder-123',
  search: 'setup guide',
  tagIds: ['tag-abc'],
