A React hook that links temporary file attachments to a knowledge base article via a GraphQL mutation.

## Key Components

- **`linkArticleAttachmentsMutation`** — GraphQL mutation (`linkKnowledgeBaseTempAttachmentsToArticle`) that persists temp attachments to an article, returning attachment metadata (`id`, `fileName`, `fileSize`, `contentType`, `createdAt`)
- **`LinkInput`** — Interface defining `articleId: string` and `tempIds: string[]` as mutation inputs
- **`useLinkArticleAttachments()`** — Custom hook exposing:
  - `linkAttachments(input)` — Promise-based function that commits the mutation and rejects on GraphQL or network errors
  - `isPending` — Boolean reflecting in-flight mutation state

## Usage Example

```typescript
import { useLinkArticleAttachments } from '@/hooks/use-link-article-attachments';

function ArticleEditor({ articleId }: { articleId: string }) {
  const { linkAttachments, isPending } = useLinkArticleAttachments();

  const handleUploadComplete = async (tempIds: string[]) => {
    try {
      await linkAttachments({ articleId, tempIds });
      console.log('Attachments linked successfully');
    } catch (error) {
      console.error('Failed to link attachments:', error);
    }
  };

  return (
    <button disabled={isPending} onClick={() => handleUploadComplete(['temp-123'])}>
      {isPending ? 'Linking...' : 'Save Attachments'}
    </button>
  );
}
```

## Notes

- Designed for a two-step upload flow: files are uploaded to temporary storage first, then linked to the article via this mutation
- Errors from both `onCompleted` (GraphQL errors) and `onError` (network errors) are surfaced through Promise rejection
