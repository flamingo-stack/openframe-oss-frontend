React hook that executes a GraphQL mutation to create a new folder in the Knowledge Base, with optimistic Relay store updates and error toast notifications.

## Key Components

- **`createFolderMutation`** — Relay `graphql` tagged mutation using `@appendNode` to automatically append the created folder into the relevant Relay connection.
- **`useCreateFolder`** — Main exported hook that wraps the mutation in a `Promise`-based callback, manually syncing the new folder into the `KNOWLEDGE_BASE_FOLDER_TREE_FIELD` linked records to avoid duplicates.
- **`CreateFolderArgs`** — Interface defining the mutation inputs: `name`, `parentId` (nullable for root-level folders), and `connections` (Relay connection IDs for edge appending).

## Usage Example

```typescript
import { useCreateFolder } from './use-create-folder';

function NewFolderButton({ connectionId }: { connectionId: string }) {
  const { createFolder, isPending } = useCreateFolder();

  const handleCreate = async () => {
    const { id } = await createFolder({
      name: 'My New Folder',
      parentId: null,         // null = root-level folder
      connections: [connectionId],
    });
    console.log('Created folder with ID:', id);
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      {isPending ? 'Creating...' : 'New Folder'}
    </button>
  );
}
```

## Return Value

| Property | Type | Description |
|---|---|---|
| `createFolder` | `(args: CreateFolderArgs) => Promise<{ id: string }>` | Executes the mutation and resolves with the new folder's ID |
| `isPending` | `boolean` | `true` while the mutation is in-flight |

> **Note:** On error, the hook automatically shows a destructive toast via `useToast` before rejecting the promise, so callers do not need to handle user-facing error display.
