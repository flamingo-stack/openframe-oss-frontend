Utility for managing Relay connection IDs for archived knowledge base articles, enabling client-side cache lookups and store updates.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ARCHIVED_ARTICLES_CONNECTION_KEY` | `const string` | Relay connection key tied to the `knowledgeBaseTable_archivedArticles` fragment |
| `ArchivedArticlesConnectionFilter` | `interface` | Filter shape accepted by the connection ID generator (`search`, `tagIds`) |
| `getArchivedArticlesConnectionId` | `function` | Returns a stable Relay `ConnectionID` for a given filter combination |

## Usage Example

```typescript
import {
  getArchivedArticlesConnectionId,
  ARCHIVED_ARTICLES_CONNECTION_KEY,
} from './use-archived-articles';

// Build a connection ID for the current filter state
const connectionId = getArchivedArticlesConnectionId({
  search: 'VPN setup',
  tagIds: ['tag-1', 'tag-2'],
});

// Use the ID in a Relay store updater to append a new edge
updater(store) {
  const connection = store.get(connectionId);
  if (connection) {
    const newEdge = store.getRootField('archiveArticle')?.getLinkedRecord('articleEdge');
    if (newEdge) {
      ConnectionHandler.insertEdgeAfter(connection, newEdge);
    }
  }
}
```

> Pass `null` for either filter field when no filtering is active — `getArchivedArticlesConnectionId` normalises both to `null` automatically, ensuring a consistent cache key.

## Notes

- Marked `'use client'` — safe for use inside React Server Component trees only on the client boundary.
- The connection key `knowledgeBaseTable_archivedArticles` must match the `@connection(key: "...")` directive in the corresponding Relay fragment.
