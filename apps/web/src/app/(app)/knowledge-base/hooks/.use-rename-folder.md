A React hook that executes a GraphQL mutation to rename a folder, with built-in error handling via toast notifications.

## Key Components

- **`renameFolderMutation`** — Relay GraphQL mutation that accepts `id` and `name` variables, returning the updated folder's `id`, `name`, and `updatedAt`
- **`RenameFolderArgs`** — Interface defining the hook's parameters: `id`, `name`, and an optional `onCompleted` callback
- **`useRenameFolder()`** — Primary exported hook returning `renameFolder` and `isPending`

## Usage Example

```typescript
import { useRenameFolder } from './use-rename-folder';

function FolderItem({ folderId }: { folderId: string }) {
  const { renameFolder, isPending } = useRenameFolder();

  const handleRename = (newName: string) => {
    renameFolder({
      id: folderId,
      name: newName,
      onCompleted: () => console.log('Folder renamed successfully'),
    });
  };

  return (
    <button onClick={() => handleRename('New Folder Name')} disabled={isPending}>
      Rename
    </button>
  );
}
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `renameFolder` | `(args: RenameFolderArgs) => void` | Triggers the rename mutation |
| `isPending` | `boolean` | `true` while the mutation is in flight |

## Notes

- On error, displays a destructive toast with the error message (or a fallback string if the error is not an `Error` instance)
- `onCompleted` is optional and only invoked on success
- Built with [React Relay](https://relay.dev/) for GraphQL and memoized via `useCallback`
