A React hook that wraps a Relay GraphQL mutation for creating knowledge base articles, with built-in toast error notifications.

## Key Components

- **`createArticleMutation`** — GraphQL mutation that creates an article and appends it to a connection using `@appendNode` with `KnowledgeBaseItemEdge`
- **`useCreateArticle()`** — Main exported hook returning:
  - `createArticle({ input, connections })` — Async function returning a `Promise<{ id: string }>`
  - `isPending` — Boolean reflecting the in-flight mutation state

## Usage Example

```typescript
import { useCreateArticle } from './use-create-article';

function CreateArticleButton({ connectionId }: { connectionId: string }) {
  const { createArticle, isPending } = useCreateArticle();

  const handleCreate = async () => {
    const { id } = await createArticle({
      input: {
        name: 'New Article',
        content: 'Article content...',
        status: 'DRAFT',
      },
      connections: [connectionId],
    });

    console.log('Created article with id:', id);
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      {isPending ? 'Creating...' : 'Create Article'}
    </button>
  );
}
```

## Notes

- On error, automatically displays a destructive toast notification before rejecting the promise — callers do not need to handle toast display manually
- The `connections` array is passed to Relay's `@appendNode` directive to keep the store cache up to date without a refetch
- Requires a Relay environment provider and `ToastProvider` from `@flamingo-stack/openframe-frontend-core` in the component tree
