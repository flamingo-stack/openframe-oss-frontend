# page.tsx

Next.js client page component for creating a new knowledge base article. It reads an optional `folderId` query parameter to pre-select the folder the article should be created in, then renders the article form within a shared error-handling shell.

## Key Components

- **`NewArticlePage`** (default export) — Page component that:
  - Extracts `folderId` from the URL search params via `useSearchParams`
  - Wraps content in `KnowledgeBasePageShell` for consistent error handling/layout
  - Renders `ArticleFormView` in "create" mode (`articleId={null}`), passing the pre-selected folder as `initialFolderId`

## Usage Example

This page is automatically routed by Next.js based on its file location (e.g., `app/knowledge-base/new/page.tsx`). Navigating to it with a folder context pre-fills the form's target folder:

```typescript
// Navigating from a folder view, e.g.:
router.push(`/knowledge-base/new?folderId=${folder.id}`);

// Resulting page renders:
// <KnowledgeBasePageShell errorMessage="Couldn't load the article form.">
//   <ArticleFormView articleId={null} initialFolderId={folder.id} />
// </KnowledgeBasePageShell>
```

If no `folderId` is present in the URL, the form opens without a pre-selected folder, allowing the user to choose one manually.

## Notes

- Marked `'use client'` since it relies on the `useSearchParams` hook, which requires client-side rendering.
- Delegates all form logic and validation to `ArticleFormView`; this page is purely a routing/composition layer.
