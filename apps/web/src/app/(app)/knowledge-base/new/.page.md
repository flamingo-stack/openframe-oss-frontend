Next.js page component for creating a new knowledge base article. It reads an optional `folderId` from the URL search parameters so new articles can be pre-assigned to the folder they were created from, then renders the shared article form within a consistent page shell.

## Key Components

- **`NewArticlePage`** - Default export; the page component rendered for the "new article" route.
- **`useSearchParams`** - Next.js navigation hook used to extract the `folderId` query parameter.
- **`KnowledgeBasePageShell`** - Shared wrapper providing consistent layout and error handling for knowledge base pages.
- **`ArticleFormView`** - Reusable form component for creating/editing articles, invoked here with `articleId={null}` to indicate creation mode.

## Usage Example

```typescript
// Navigating to this page with a pre-selected folder:
// /knowledge-base/articles/new?folderId=abc123

// The page automatically reads the folderId and passes it
// to ArticleFormView so the new article is created inside
// the correct folder by default.
```

This page is typically reached by clicking an "Add Article" action from within a specific folder view, ensuring the `folderId` context is preserved. If no `folderId` is present in the URL, the article form falls back to its default (unassigned/root) behavior.
