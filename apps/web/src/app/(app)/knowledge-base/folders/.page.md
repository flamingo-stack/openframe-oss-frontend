A Next.js client-side page component that renders a knowledge base folder view based on a query parameter.

## Key Components

- **`FolderPage`** — Default export page component that reads the `id` query param and passes it to `KnowledgeBaseView`. Calls `notFound()` if no `id` is present.
- **`KnowledgeBaseView`** — Imported child component responsible for rendering the folder contents.

## Usage Example

```typescript
// Accessed via URL: /knowledge-base/folder?id=abc123
// Renders: <KnowledgeBaseView folderId="abc123" />
```

```typescript
// Missing id param triggers Next.js 404
// URL: /knowledge-base/folder
// → notFound() called → 404 page
```

## Notes

- Marked `'use client'` — runs in the browser; `useSearchParams()` requires client context.
- No fallback UI for the loading state; consider wrapping with a `<Suspense>` boundary if needed per Next.js requirements for `useSearchParams` in static builds.
