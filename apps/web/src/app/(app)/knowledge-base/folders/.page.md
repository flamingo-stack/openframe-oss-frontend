# Folder Page (Knowledge Base)

A Next.js client page component that renders a specific knowledge base folder, identified via a required `id` query parameter.

## Key Components

- **`FolderPage`** (default export) — Page-level React component that:
  - Reads the `id` query parameter using `useSearchParams`
  - Triggers a 404 (`notFound()`) if no `id` is present
  - Wraps the folder content in `KnowledgeBasePageShell` for consistent error handling
  - Renders `KnowledgeBaseView`, keyed by `id` to force a clean remount when navigating between folders

## Usage Example

This page is typically reached via a route like:

```text
/knowledge-base/folder?id=abc123
```

Navigating between folders by changing only the `id` query param:

```typescript
import { useRouter } from 'next/navigation';

function FolderLink({ folderId }: { folderId: string }) {
  const router = useRouter();

  const goToFolder = () => {
    router.push(`/knowledge-base/folder?id=${folderId}`);
  };

  return <button onClick={goToFolder}>Open Folder</button>;
}
```

## Notes

- The `key={id}` prop on `KnowledgeBaseView` ensures React fully remounts the component when the folder `id` changes, since Next.js reuses the same route segment when only the search params differ.
- `KnowledgeBasePageShell` receives a `resetKey={id}` prop, allowing it to reset any internal error boundary state when the folder changes.
- If the `id` parameter is missing, the component immediately calls `notFound()`, rendering the Next.js 404 page.
