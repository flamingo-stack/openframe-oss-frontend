Defines the Next.js page metadata and layout wrapper for the Knowledge Base route, enabling dynamic browser tab titles consistent with the app's routing structure.

## Key Components

- **`metadata`**: `Metadata` object exported for Next.js App Router, setting the page title via `routeTitle('Knowledge Base')`.
- **Default export**: Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, used to render the layout shell for this route segment.
- **`routeTitle`**: Utility function imported from `@/lib/route-title` that formats route-specific titles (likely appending a suffix like the app name).

## Usage Example

This file is automatically picked up by Next.js as the layout for the `Knowledge Base` route segment. No manual invocation is needed; Next.js uses the exported `metadata` and default layout component to render the page shell.

```typescript
// Next.js automatically applies this layout and metadata
// to any page within the same route segment, e.g.:
// app/(app)/knowledge-base/page.tsx

export default function KnowledgeBasePage() {
  return <div>Knowledge Base content</div>;
}
```

The resulting browser tab title will be generated by `routeTitle('Knowledge Base')`, ensuring consistent title formatting across the application. To reuse this pattern for other routes, create a similar `layout.tsx` file with a different title string passed to `routeTitle`.
