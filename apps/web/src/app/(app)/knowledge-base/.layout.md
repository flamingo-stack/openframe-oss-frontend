Defines route-level metadata and layout wiring for the Knowledge Base section of the application, using Next.js's App Router metadata API.

## Key Components

- **`metadata`** — A `Metadata` object (Next.js convention) that sets the page title to `"Knowledge Base"` using the `routeTitle` helper, ensuring consistent title formatting across the app.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as this route segment's layout, avoiding duplication of layout logic across sections.

## Usage Example

This file is automatically picked up by Next.js as the layout for the `Knowledge Base` route segment. No manual invocation is required—Next.js resolves it based on file-system routing conventions.

```typescript
// Equivalent conceptual usage (handled internally by Next.js):
import KnowledgeBaseLayout, { metadata } from './layout';

// metadata.title => "Knowledge Base" (formatted via routeTitle)
// KnowledgeBaseLayout renders the shared route-title-layout wrapper
// around all pages within the Knowledge Base route segment.
```

To reuse this pattern for another section, create a sibling `layout.tsx` with:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Your Section Name') };
```
