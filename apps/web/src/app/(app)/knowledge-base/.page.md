Next.js client page component that renders the root Knowledge Base view, wrapped in a shared page shell for consistent layout and error handling.

## Key Components

- **`KnowledgeBasePage`** - Default export; the root page component for the Knowledge Base route. Renders `KnowledgeBasePageShell` with a custom error message and passes `folderId={null}` to `KnowledgeBaseView`, indicating the top-level (root) folder context.
- **`KnowledgeBasePageShell`** - Shared wrapper component providing consistent page structure (e.g., layout, error boundaries) across knowledge base pages.
- **`KnowledgeBaseView`** - Renders the list/grid of knowledge base items for a given `folderId`.

## Usage Example

This file acts as the entry point for the Knowledge Base route in the Next.js app router (e.g., `app/knowledge-base/page.tsx`). It requires no manual invocation—Next.js automatically renders it when the route is visited.

```typescript
// Example of how a nested folder page might reuse the same pattern
'use client';

import { KnowledgeBaseView } from '../components/item-list/knowledge-base-view';
import { KnowledgeBasePageShell } from '../components/shared/knowledge-base-page-shell';

export default function KnowledgeBaseFolderPage({ params }: { params: { folderId: string } }) {
  return (
    <KnowledgeBasePageShell errorMessage="Couldn't load this folder.">
      <KnowledgeBaseView folderId={params.folderId} />
    </KnowledgeBasePageShell>
  );
}
```

**Notes:**
- Marked `'use client'` since it relies on client-side rendering for interactive views.
- `folderId={null}` signals the root-level knowledge base contents should be displayed.
