# Knowledge Base Page

Next.js page component that renders the root-level Knowledge Base view, displaying top-level items (folders and articles) when no specific folder is selected.

## Key Components

- **`KnowledgeBasePage`** — Default exported page component (client component) that serves as the entry route for the Knowledge Base feature.
- **`KnowledgeBasePageShell`** — Shared wrapper component providing consistent layout and error handling (via `errorMessage` prop) across knowledge base pages.
- **`KnowledgeBaseView`** — Renders the list of knowledge base items for a given `folderId`; receives `null` here to indicate the root level.

## Usage Example

```typescript
// This page is automatically routed by Next.js based on its file path,
// typically rendering at a route such as `/knowledge-base`.

export default function KnowledgeBasePage() {
  return (
    <KnowledgeBasePageShell errorMessage="Couldn't load the knowledge base.">
      <KnowledgeBaseView folderId={null} />
    </KnowledgeBasePageShell>
  );
}
```

To navigate into a subfolder, a related dynamic route (e.g. `[folderId]/page.tsx`) would pass a non-null `folderId` to `KnowledgeBaseView`, reusing the same `KnowledgeBasePageShell` wrapper for consistent error and loading states.

## Notes

- Marked `'use client'` since it composes client-side interactive components.
- Keeps the page component minimal by delegating data fetching, loading, and error UI to `KnowledgeBasePageShell` and `KnowledgeBaseView`.
