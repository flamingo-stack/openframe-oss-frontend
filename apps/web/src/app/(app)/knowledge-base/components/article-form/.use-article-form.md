# use-article-form.ts

React hook powering the knowledge base article form, shared by both the create and edit pages. It wires up form validation, attachment management, and save/navigation logic, and seeds itself with stored article data when editing.

## Key Components

- **`useArticleForm(options)`** — Main hook accepting `articleId` (null for create), `initialFolderId` (folder context for new articles), and `stored` (loaded article data, null while loading or when creating).
- **`UseArticleFormOptions`** — Interface describing the hook's input parameters.
- **Returned API**:
  - `form` — The `react-hook-form` instance (zod-validated via `articleFormSchema`).
  - `attachments` — Attachment state/handlers from `useArticleAttachments`.
  - `isSubmitting` — Boolean save-in-progress flag (from `useSaveArticle`).
  - `handleSave(status: SaveStatus)` — Triggers validation and save for a given status (e.g., draft vs. published).

## Behavior Notes

- Uses `useSeedForm` to populate the form once `stored` data arrives, since this hook owns the `useForm` instance.
- Guards against double-submission with an `inFlightRef`, since `handleSubmit`'s async resolver can allow a second click before `isSaving` disables the UI.
- On successful save:
  - **Create**: shows a success toast and replaces the route to the new article's detail page.
  - **Edit**: shows a success toast and navigates back safely (or replaces) to the article's detail page.
- On validation failure: aggregates field error messages into a single destructive toast.

## Usage Example

```typescript
import { useArticleForm } from './use-article-form';

function ArticleFormPage({ articleId, initialFolderId, stored }) {
  const { form, attachments, isSubmitting, handleSave } = useArticleForm({
    articleId,
    initialFolderId,
    stored,
  });

  return (
    <form>
      {/* form fields bound via `form.register` / `form.control` */}
      <AttachmentList attachments={attachments} />
      <button
        type="button"
        disabled={isSubmitting}
        onClick={() => handleSave('draft')}
      >
        Save Draft
      </button>
      <button
        type="button"
        disabled={isSubmitting}
        onClick={() => handleSave('published')}
      >
        Publish
      </button>
    </form>
  );
}
```
