# article-form-view.tsx

Page-level component powering the `/knowledge-base/new` and `/knowledge-base/edit` routes. It renders the knowledge base article form shell (title, Back button, Save actions) immediately, while coordinating the asynchronous loading of the article record and its assignments before unlocking the form fields for editing.

## Key Components

- **`ArticleFormView`** — Main exported component. Accepts `articleId` (or `null` for creating a new article) and an optional `initialFolderId` used to seed a new article's folder.
- **`ArticleFormViewProps`** — Props interface: `articleId: string | null` and `initialFolderId?: string | null`.
- **Internal coordination logic**:
  - Uses `ArticleRecordLoader` to fetch the article record over Relay (edit mode only).
  - Uses `useAssignedItems` to fetch the article's assignments independently.
  - Combines both into a single `stored: StoredArticle | null` value via `useMemo`, only considering the article "loaded" once **both** the record and its assignments are ready — preventing a partial save that would wipe out assignments.
  - Delegates form state and submission to `useArticleForm`.
  - Builds `PageActionButton[]` for "Save as Draft" and "Save and Publish", both disabled while loading, submitting, or while an attachment upload is in progress.

## Usage Example

```typescript
// app/knowledge-base/edit/[id]/page.tsx
import { ArticleFormView } from './article-form-view';

export default function EditArticlePage({ params }: { params: { id: string } }) {
  return <ArticleFormView articleId={params.id} />;
}
```

```typescript
// app/knowledge-base/new/page.tsx
import { ArticleFormView } from './article-form-view';

export default function NewArticlePage({ searchParams }: { searchParams: { folderId?: string } }) {
  return <ArticleFormView articleId={null} initialFolderId={searchParams.folderId ?? null} />;
}
```

Note: this component is compiled for performance — it only passes `form` down to children and never reads form state directly during render, keeping re-renders scoped to the fields that actually depend on it.
