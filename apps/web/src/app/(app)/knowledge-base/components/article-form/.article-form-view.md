## Purpose

Renders the Knowledge Base article form used by both the `/knowledge-base/new` and `/knowledge-base/edit` routes. It composes a page layout (title, back button, Save actions) that mounts immediately, while gating the actual form fields until both the article record and its assignments have loaded — preventing a premature save from wiping out existing assignments.

## Key Components

- **`ArticleFormView`** — The default export, a page-level component that:
  - Accepts `articleId` (or `null` for create mode) and an optional `initialFolderId` for new articles.
  - Uses `useSafeBack` to navigate back to the article's details page (edit mode) or the list (create mode).
  - Loads the article record via `ArticleRecordLoader` (invisible, Relay-backed) and its assignments via `useAssignedItems`.
  - Merges record + assignments into a single `stored: StoredArticle | null` via `useMemo`, only once both halves are ready.
  - Delegates form state/submission to `useArticleForm`, passing the merged `stored` object.
  - Renders two `PageActionButton`s ("Save as Draft", "Save and Publish") that are disabled while loading, submitting, or while an attachment upload is in progress.
  - Wraps `ArticleFormFields` in `LoadingWhen` to show loading state until the form is fully seeded.

## Usage Example

```typescript
import { ArticleFormView } from './article-form-view';

// Edit an existing article
export default function EditArticlePage({ params }: { params: { id: string } }) {
  return <ArticleFormView articleId={params.id} />;
}

// Create a new article inside a specific folder
export default function NewArticlePage({ searchParams }: { searchParams: { folderId?: string } }) {
  return <ArticleFormView articleId={null} initialFolderId={searchParams.folderId ?? null} />;
}
```

**Note:** This component is designed to be driven by route params; it should not be used as a generic reusable form outside the knowledge base new/edit pages, since it couples directly to `routes.knowledgeBase` and `useArticleForm`.
