# article-record-loader.tsx

A headless "data island" component that fetches a knowledge base article via GraphQL and delivers the resolved form record to a parent component, without rendering any visible UI.

## Key Components

- **`ArticleRecordLoader`** — Public entry component. Wraps the data-fetching logic in a `LoadingSuspense` boundary (with `contents` layout so it occupies no visual space) and displays a "Loading article" fallback while the query resolves.
- **`ArticleRecordReader`** — Internal gate that checks `useLoadingScope()` to avoid reading/rendering while still inside a Suspense fallback pass.
- **`ArticleRecordQuery`** — Executes the `articleRecordLoaderQuery` GraphQL query via `useLazyLoadQuery`, validates the item is of type `ARTICLE`, converts it to an `ArticleFormRecord` via `readArticleFormRecord`, and calls `onResolved` in a `useLayoutEffect` (pre-paint) once the record is available. Calls `notFound()` if the id doesn't resolve to an article.
- **`articleRecordLoaderQuery`** — The GraphQL query fetching `knowledgeBaseItem` by `id`, including its `type` and spreading the `articleFormRecord_article` fragment.

## Usage Example

```typescript
import { useState } from 'react';
import { ArticleRecordLoader } from './article-record-loader';
import type { ArticleFormRecord } from './article-form-record';

function EditArticlePage({ articleId }: { articleId: string }) {
  const [record, setRecord] = useState<ArticleFormRecord | null>(null);

  return (
    <>
      <ArticleRecordLoader
        articleId={articleId}
        onResolved={(resolved) => setRecord(resolved)}
      />
      {record && <ArticleForm initialRecord={record} />}
    </>
  );
}
```

This component is designed to be used alongside a form owner (e.g., `useForm`/`useSeedForm`) that seeds its state only once per resolved record, relying on the `useMemo` identity stability to avoid redundant re-seeding on re-renders.
