# use-save-article.ts

A React hook that saves a knowledge base article (create or update) via GraphQL Relay mutations, handling folder placement, tags, assignments, attachments, and cache invalidation in a single atomic operation.

## Key Components

- **`SaveStatus`** — Type alias restricting the status a save can set an article to (`DRAFT` or `PUBLISHED`); archiving happens elsewhere.
- **`SaveArticleRequest`** — Interface describing the save payload: `articleId` (null for create), form `values`, target `status`, attachment changes, and the `stored` snapshot of the article as originally loaded (used to detect changes and update listings correctly).
- **`useSaveArticle()`** — Main hook exporting:
  - `save(request, onSaved)` — Commits a create or update mutation depending on whether `articleId` is set.
  - `isSaving` — Boolean combining the in-flight state of both mutations.
- **`createMutation` / `updateMutation`** — GraphQL mutation documents (via `graphql` tag) for creating and updating articles, with the update mutation returning the full article shape needed to refresh its page/list row without a refetch.
- **`summaryOf(body)`** — Derives a 160-character summary from the article body.
- **`savedTagIds(values)`** — Filters out tags still pending creation (optimistic IDs) so only server-known tag IDs are submitted.
- **`MAX_ASSIGNED_PER_KIND`** — Client-side cap (50) on assignment targets per kind, validated before submission.

## Usage Example

```typescript
import { useSaveArticle } from './use-save-article';

function ArticleEditor({ articleId, stored, values }: EditorProps) {
  const { save, isSaving } = useSaveArticle();

  const handleSave = (status: SaveStatus) => {
    save(
      {
        articleId,
        values,
        status,
        attachmentTempIds: ['temp-123'],
        deleteAttachmentIds: [],
        stored,
      },
      (savedArticleId) => {
        // Navigate or update UI after successful save
        router.push(`/knowledge-base/${savedArticleId}`);
      }
    );
  };

  return (
    <button disabled={isSaving} onClick={() => handleSave(KnowledgeBaseArticleStatus.PUBLISHED)}>
      {isSaving ? 'Saving…' : 'Publish'}
    </button>
  );
}
```

Errors surface via `useToast`, and assignment/folder caches are invalidated automatically through Relay store updaters and React Query.
