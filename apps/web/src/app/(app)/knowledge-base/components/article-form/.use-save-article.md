# use-save-article.ts

A React hook that persists a Knowledge Base article form via GraphQL mutations, handling both creation and updates in a single call that covers content, status, folder placement, tags, assignments, and attachments.

## Key Components

- **`SaveStatus`** — Type alias restricting the status a save can set an article to (`DRAFT` or `PUBLISHED`; archiving happens elsewhere).
- **`SaveArticleRequest`** — Interface describing the save payload: target article ID (or `null` to create), form values, desired status, attachment changes, and the previously stored article snapshot (used to detect changes).
- **`useSaveArticle()`** — Hook returning:
  - `save(request, onSaved)` — Commits a create or update mutation depending on whether `articleId` is present.
  - `isSaving` — Boolean combining the in-flight state of both the create and update mutations.
- **`createMutation` / `updateMutation`** — Relay GraphQL mutation definitions. The update mutation returns the full article shape so dependent UI (article page, list rows) stays fresh without refetching.
- **`summaryOf`** — Derives a 160-character summary from the article body.
- **`savedTagIds`** — Filters out tag IDs still pending server-side creation (optimistic tags).
- **`MAX_ASSIGNED_PER_KIND`** — Caps assignment list size (50) per target kind; exceeding it fails client-side with a toast before any network call.

## Usage Example

```typescript
import { useSaveArticle } from './use-save-article';

function ArticleEditor({ articleId, stored }: { articleId: string | null; stored: StoredArticle | null }) {
  const { save, isSaving } = useSaveArticle();

  const handleSave = (values: ArticleFormData, status: SaveStatus) => {
    save(
      {
        articleId,
        values,
        status,
        attachmentTempIds: ['temp-upload-1'],
        deleteAttachmentIds: [],
        stored,
      },
      savedId => {
        console.log('Article saved with id:', savedId);
      }
    );
  };

  return (
    <button disabled={isSaving} onClick={() => handleSave(formValues, KnowledgeBaseArticleStatus.DRAFT)}>
      {isSaving ? 'Saving…' : 'Save Draft'}
    </button>
  );
}
```

On success, the hook invalidates the `ASSIGNED_ITEMS_QUERY_KEY` react-query cache and updates the Relay store (folder/archive listings) so UI reflects the change without a manual refetch. On failure, a destructive toast is shown with a human-readable error message.
