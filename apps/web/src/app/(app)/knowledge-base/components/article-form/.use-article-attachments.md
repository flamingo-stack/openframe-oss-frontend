# use-article-attachments.ts

A React hook that manages file attachment uploads for a knowledge base article form, handling temporary file uploads via presigned URLs, upload status tracking, and removal of both newly-added and pre-existing attachments. Uploads happen immediately (before the article is saved) against temporary storage; the article save step is later handed the resulting `tempIds` to attach and `removedIds` to delete.

## Key Components

- **`useArticleAttachments(stored)`** — Main hook that accepts the article's currently stored attachments and returns the combined list of files (stored + newly uploaded, minus removed), along with upload/remove actions and save-ready metadata.
- **`AttachmentFile`** — Public interface representing a single row in the attachments list (`id`, `fileName`, `fileSize`, `status`, optional `error`).
- **`Upload`** — Internal interface tracking an in-progress upload's lifecycle (`key`, `tempId`, file metadata, `status`).
- **`UploadStatus`** — Union type: `'uploading' | 'uploaded' | 'error'`.
- **`createUploadMutation`** / **`discardUploadMutation`** — GraphQL mutations for requesting a presigned upload URL and discarding a temp attachment, respectively.
- **`ArticleAttachments`** — Exported type alias for the hook's return value, used for typing props/context elsewhere.

### Returned API
- `files` — Combined, display-ready list of stored and uploaded attachments.
- `upload(source)` — Starts uploading a new file (`UploadSource`).
- `remove(id)` — Removes a stored attachment (marks for deletion) or cancels/discards an in-progress upload.
- `isUploading` — `true` if any upload is still in progress.
- `tempIds` — IDs of successfully uploaded temp attachments, to attach on save.
- `removedIds` — IDs of stored attachments marked for removal on save.

## Usage Example

```typescript
import { useArticleAttachments } from './use-article-attachments';

function ArticleAttachmentsPanel({ article }: { article: { attachments: StoredAttachment[] } }) {
  const { files, upload, remove, isUploading, tempIds, removedIds } = useArticleAttachments(
    article.attachments,
  );

  const handleFileSelect = (file: File) => {
    upload(file);
  };

  const handleSave = () => {
    saveArticle({ attachTempIds: tempIds, removeIds: removedIds });
  };

  return (
    <div>
      {files.map(file => (
        <div key={file.id}>
          {file.fileName} - {file.status}
          <button onClick={() => remove(file.id)}>Remove</button>
        </div>
      ))}
      <button disabled={isUploading} onClick={handleSave}>
        Save Article
      </button>
    </div>
  );
}
```
