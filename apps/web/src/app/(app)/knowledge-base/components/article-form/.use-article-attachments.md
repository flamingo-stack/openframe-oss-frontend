# use-article-attachments.ts

A React hook that manages file attachments for the knowledge base article form, handling presigned-URL uploads, pending removals, and upload state tracking before the article is actually saved.

Files are uploaded immediately as "temporary attachments" via a presigned URL, while removals of already-stored attachments are only staged (not executed) until the article save completes. This decouples attachment I/O from the article's own save lifecycle.

## Key Components

- **`useArticleAttachments(stored)`** — Main hook accepting the article's existing stored attachments; returns the combined file list and mutation handlers.
- **`upload(source: UploadSource)`** — Requests a presigned upload URL via GraphQL, uploads the file, and tracks its status (`uploading` → `uploaded`/`error`).
- **`remove(id: string)`** — Removes a pending upload (discarding its temp attachment server-side) or stages a stored attachment for deletion on save.
- **`AttachmentFile`** — Public shape for rendering a row in the attachments UI (`id`, `fileName`, `fileSize`, `status`, optional `error`).
- **`ArticleAttachments`** — Exported type alias for the hook's return value, for use in parent components/props.
- Returned fields: `files`, `upload`, `remove`, `isUploading`, `tempIds` (uploaded files to attach on save), `removedIds` (stored files to delete on save).

## Usage Example

```typescript
import { useArticleAttachments } from './use-article-attachments';

function ArticleAttachmentsPanel({ storedAttachments }: { storedAttachments: StoredAttachment[] }) {
  const { files, upload, remove, isUploading, tempIds, removedIds } =
    useArticleAttachments(storedAttachments);

  const handleFileSelect = (file: File) => {
    upload(file); // begins presigned upload immediately
  };

  const handleSave = () => {
    // pass tempIds and removedIds to the article save mutation
    saveArticle({ variables: { tempIds, removedIds } });
  };

  return (
    <div>
      {files.map(file => (
        <FileUpload key={file.id} file={file} onRemove={() => remove(file.id)} />
      ))}
      <button onClick={handleSave} disabled={isUploading}>
        Save Article
      </button>
    </div>
  );
}
```

**Note:** Attachments already belonging to the article are only marked for removal in `removedIds`; the actual deletion happens server-side when the article save mutation processes them.
