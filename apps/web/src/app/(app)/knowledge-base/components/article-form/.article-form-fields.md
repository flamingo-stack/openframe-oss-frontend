Renders the complete set of form fields used to create and edit knowledge base articles, wiring a `react-hook-form` instance to title, folder, tags, markdown body, attachments, and assignment controls.

## Key Components

- **`ArticleFormFields`** — Main exported component. Accepts the form instance, a `disabled` flag, `initialTags`, and an `attachments` controller, rendering all article fields in a single fragment.
- **`ArticleFormFieldsProps`** — Prop types for the component, including `form: UseFormReturn<ArticleFormData>` and `attachments: ArticleAttachments`.
- **`MarkdownEditor`** — Code-split markdown editor created via `lazyMarkdownEditor`, sized by `ARTICLE_BODY_EDITOR_HEIGHT`.
- **`renderPreview`** — Module-scoped render function passed to the markdown editor to display a live preview using `SimpleMarkdownRenderer`.
- **Field bindings** — Uses `Controller` from `react-hook-form` to connect:
  - `title` → `Input`
  - `folderId` → `FolderPicker`
  - `tags` → `EntityTagPicker` (scoped to `TagEntityType.KNOWLEDGE_ARTICLE`)
  - `body` → `MarkdownEditor` (with image upload via `useArticleImageUpload`)
  - `assignments` → `AssignmentsField`
- **`FileUpload`** — Handles attachment uploads using `nativeFilePicker` and the `attachments` prop's `upload`/`remove`/`files` API.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ArticleFormFields } from './article-form-fields';
import type { ArticleFormData } from './article-form.types';
import { useArticleAttachments } from './use-article-attachments';

function ArticleEditor({ articleId, initialTags }: { articleId: string; initialTags: { id: string; key: string }[] }) {
  const form = useForm<ArticleFormData>({
    defaultValues: { title: '', folderId: null, tags: [], body: '', assignments: {} },
  });
  const attachments = useArticleAttachments(articleId);

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <ArticleFormFields
        form={form}
        disabled={form.formState.isSubmitting}
        initialTags={initialTags}
        attachments={attachments}
      />
      <button type="submit">Save</button>
    </form>
  );
}
```
