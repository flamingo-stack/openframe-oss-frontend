Renders the complete set of form fields for creating and editing knowledge base articles, wiring a `react-hook-form` instance to title, folder, tags, markdown body, attachments, and assignment controls.

## Key Components

- **`ArticleFormFields`** — Main exported component. Accepts a `form` (`UseFormReturn<ArticleFormData>`), a `disabled` flag, `initialTags` for pre-populating the tag picker, and an `attachments` object for managing file uploads.
- **`ArticleFormFieldsProps`** — Prop type definition for the component.
- **`renderPreview`** — Module-scoped render function passed to the markdown editor to display a live preview using `SimpleMarkdownRenderer`.
- **`MarkdownEditor`** — Lazily-loaded markdown editor instance created via `lazyMarkdownEditor`, fixed at `ARTICLE_BODY_EDITOR_HEIGHT` (400px).
- **`ARTICLE_BODY_EDITOR_HEIGHT`** — Shared height constant used by both the live field and its code-split loading skeleton.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ArticleFormFields } from './article-form-fields';
import type { ArticleFormData } from './article-form.types';
import { useArticleAttachments } from './use-article-attachments';

function ArticleEditor() {
  const form = useForm<ArticleFormData>({
    defaultValues: { title: '', folderId: '', tags: [], body: '', assignments: {} },
  });
  const attachments = useArticleAttachments();

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <ArticleFormFields
        form={form}
        disabled={false}
        initialTags={[{ id: 'tag-1', key: 'onboarding' }]}
        attachments={attachments}
      />
    </form>
  );
}
```

The component is designed to be embedded within a parent form element; it does not render its own `<form>` tag, submit controls, or handle submission itself — that responsibility belongs to the consuming page (e.g., article create/edit pages), which also supplies the shared `disabled` loading state.
