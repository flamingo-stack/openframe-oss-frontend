Reads a `KnowledgeBaseItem` Relay fragment and normalizes it into a plain-object shape suitable for seeding the article edit form, decoupling the form's data model from the GraphQL fragment structure.

## Key Components

- **`articleFormRecordFragment`** — Inline GraphQL fragment (`@inline`) on `KnowledgeBaseItem`, fetching `name`, `parentId`, `content`, `status`, `tags`, and `attachments`.
- **`StoredAttachment`** — Interface describing an attachment already persisted on the article (`id`, `fileName`, `fileSize`, `contentType`).
- **`ArticleFormRecord`** — Shape returned by `readArticleFormRecord`, containing form `values` (minus `assignments`, which is fetched separately), the article's `status`, its `tags`, and its `attachments`.
- **`StoredArticle`** — Represents the full baseline state (including `assignments` via `ArticleFormData`) used as the "before" snapshot when diffing for a save operation.
- **`readArticleFormRecord(article)`** — Reads the inline fragment data via `readInlineData` and maps it into an `ArticleFormRecord`, applying defaults (`content ?? ''`, `fileSize ?? 0`, `contentType ?? 'application/octet-stream'`) and converting `status` via `toArticleStatus`.

## Usage Example

```typescript
import { readArticleFormRecord } from './article-form-record';
import type { articleFormRecord_article$key } from '@/__generated__/articleFormRecord_article.graphql';

function useArticleFormSeed(articleRef: articleFormRecord_article$key) {
  const record = readArticleFormRecord(articleRef);

  // Seed the form
  const initialValues = record.values;

  // Render tag chips immediately, before the tag picker's full list loads
  const tagChips = record.tags.map(tag => tag.key);

  // Show existing attachments
  const existingFiles = record.attachments.map(a => a.fileName);

  return { initialValues, tagChips, existingFiles, status: record.status };
}
```

This is typically used when initializing an edit form for an existing knowledge base article, providing a stable, defaulted data shape independent of Relay's generated types.
