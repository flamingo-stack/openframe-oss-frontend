Reads a Knowledge Base article's Relay inline fragment data and normalizes it into a plain record shape consumed by the article edit form, decoupling the form's data model from raw GraphQL fields.

## Key Components

- **`articleFormRecordFragment`** — Relay `@inline` GraphQL fragment declaring the `KnowledgeBaseItem` fields needed by the form (`name`, `parentId`, `content`, `status`, `tags`, `attachments`).
- **`StoredAttachment`** — Interface describing an attachment already saved on the article (`id`, `fileName`, `fileSize`, `contentType`).
- **`ArticleFormRecord`** — Interface representing the article as consumed by the edit form: form `values` (excluding `assignments`, which is fetched separately), `status`, `tags`, and `attachments`.
- **`StoredArticle`** — Interface representing the baseline article state a save operation diffs against, including full `ArticleFormData` values, `status`, and `attachments`.
- **`readArticleFormRecord(article)`** — Reads the inline fragment data via `readInlineData` and maps it into an `ArticleFormRecord`, applying defaults (e.g., empty string for missing `content`, `'application/octet-stream'` for missing `contentType`) and converting raw `status` via `toArticleStatus`.

## Usage Example

```typescript
import { readArticleFormRecord } from './article-form-record';
import type { articleFormRecord_article$key } from '@/__generated__/articleFormRecord_article.graphql';

function useArticleFormInitialState(articleRef: articleFormRecord_article$key) {
  const record = readArticleFormRecord(articleRef);

  // Seed the edit form
  const initialValues = record.values;

  // Render existing tag chips before the tag picker's own data loads
  const tagChips = record.tags.map(tag => tag.key);

  // List attachments already uploaded
  const existingFiles = record.attachments.map(a => a.fileName);

  return { initialValues, tagChips, existingFiles, status: record.status };
}
```

This is typically used when initializing an article edit form, allowing the UI to render known tags and attachments immediately while assignments load asynchronously via `useAssignedItems`.
