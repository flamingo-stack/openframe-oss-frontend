A thin client-side view component that wraps `KnowledgeBaseBody` and bridges the folder navigation context to the knowledge base content area.

## Key Components

- **`KnowledgeBaseView`** — Default exported React component that accepts a nullable `folderId` and passes it as `parentId` to `KnowledgeBaseBody`.
- **`KnowledgeBaseViewProps`** — Interface defining the single `folderId: string | null` prop used for folder-scoped content display.

## Usage Example

```typescript
import { KnowledgeBaseView } from './knowledge-base-view';

// Render the knowledge base rooted at a specific folder
<KnowledgeBaseView folderId="folder-abc-123" />

// Render the knowledge base from the root level
<KnowledgeBaseView folderId={null} />
```
