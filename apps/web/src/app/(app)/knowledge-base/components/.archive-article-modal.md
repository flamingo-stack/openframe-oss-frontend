A confirmation modal component for archiving knowledge base articles, using a shared `ConfirmDialog` with destructive styling and toast feedback on success.

## Key Components

### Exports

- **`ArchiveArticleModal`** — Main modal component that wraps `ConfirmDialog` to confirm article archiving
- **`ArchiveArticleTarget`** — Interface describing the minimal article shape (`id`, `name`) needed to trigger archiving
- **`ARCHIVED_ARTICLES_CONNECTION_KEY`** — Re-exported connection key constant for use by consumers

### Props (`ArchiveArticleModalProps`)

| Prop | Type | Description |
|---|---|---|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback fired when the dialog is dismissed or action completes |
| `article` | `ArchiveArticleTarget \| null` | The article to archive; null-safe throughout |
| `sourceConnectionId` | `string` | The relay/cache connection to remove the article from after archiving |

### Internal Logic

- Resolves the **archived articles connection ID** (no search/tag filters) via `getArchivedArticlesConnectionId`
- Calls `archiveArticle` with `removeFromConnections` and `appendToConnections` to move the article between cache connections atomically
- Shows a **success toast** on completion, or silently swallows errors (empty `catch` block)

## Usage Example

```typescript
import { ArchiveArticleModal, ArchiveArticleTarget } from './archive-article-modal';

const article: ArchiveArticleTarget = { id: 'art_123', name: 'How to Reset a Password' };

<ArchiveArticleModal
  isOpen={showArchiveModal}
  onClose={() => setShowArchiveModal(false)}
  article={article}
  sourceConnectionId="active-articles-connection"
/>
```
