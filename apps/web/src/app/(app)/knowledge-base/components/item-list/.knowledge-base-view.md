# knowledge-base-view.tsx

Client component that renders a single level (root or a specific folder) of the knowledge base. It owns URL-driven state for search/tag filters, a sticky toolbar, and the "New Folder" dialog, delegating the folder title and row rendering to child components that suspend independently.

## Key Components

- **`pageActions(folderId, onNewFolder, emphasizeAddArticle, generateWithAi)`** — Builds the header `PageActionButton[]` array (New Folder, Add Article, and Archive when at root). "Add Article" is visually emphasized (accent variant) when the current level is empty, nudging the user toward the one available action.
- **`KnowledgeBaseView`** — The exported component. Props: `{ folderId: string | null }` (`null` = root level).
  - Uses `useTagSearchState` for search/tag filter state and `useDeferredQuery` to defer both together (single `isPending` flag).
  - Uses `useStickyToolbar` for sticky toolbar positioning and offset.
  - Uses `useGenerateWithAiAction` (with `DIALOG_INTENT.CREATE_KB_ARTICLE`) to wire an AI-assisted article creation action into the "Add Article" button.
  - Renders `KnowledgeBaseListTitle` (root) or `KnowledgeBaseFolderTitle` (nested folder) for the header, `KnowledgeBaseSearchToolbar` (hidden when the level is empty), `KnowledgeBaseItemsTable` for rows, and `NewFolderModal` for folder creation.

## Usage Example

```typescript
import { KnowledgeBaseView } from './knowledge-base-view';

// Root level of the knowledge base
export default function KnowledgeBasePage() {
  return <KnowledgeBaseView folderId={null} />;
}

// A specific folder
export default function FolderPage({ params }: { params: { folderId: string } }) {
  return <KnowledgeBaseView folderId={params.folderId} />;
}
```

## Notes

- Deliberately avoids a shared `PageLayout` wrapper: since a folder's title requires fetching the folder record, only the title component (`KnowledgeBaseFolderTitle`) suspends on that data, while the rest of the page (actions, toolbar) renders immediately. This mirrors the pattern used in `software-detail-view`.
- The "Archive" action only appears at the root level, since archived items span the whole knowledge base rather than being per-folder.
