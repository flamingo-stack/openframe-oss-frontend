# folder-title.tsx

Renders the title row for a knowledge base folder page, combining the folder's name, a "Back" navigation control, and a contextual menu for folder actions (rename, move, delete). It coordinates the opening/closing of folder-related modals and ensures that deleting the current folder navigates away safely.

## Key Components

- **`FolderTitle`** — Main component that displays the folder title, back navigation, and action menu. Accepts a Relay fragment reference (`folder`) and a list of `actions` (page action buttons).
- **`folderTitleFragment`** — GraphQL fragment defining the data needed (`name`, `parentId`) plus nested fragment references for the rename, move, and delete modals.
- **`FolderTitleProps`** — Prop types: `folder` (Relay fragment key) and `actions` (`PageActionButton[]`).

Internally, it manages which dialog (`rename`, `move`, `delete`) is currently open via local state, and uses `useSafeBack` to determine where to navigate after a folder is deleted.

## Usage Example

```typescript
import { FolderTitle } from './folder-title';
import type { PageActionButton } from '@flamingo-stack/openframe-frontend-core/components/ui';

function FolderPage({ folderRef }: { folderRef: folderTitle_folder$key }) {
  const actions: PageActionButton[] = [
    { label: 'Add Document', onClick: () => console.log('add') },
  ];

  return <FolderTitle folder={folderRef} actions={actions} />;
}
```

The component expects to be rendered within a Relay environment where the parent query has spread the `folderTitle_folder` fragment onto a `KnowledgeBaseItem` node. Navigation after deletion falls back to the parent folder's route, or the knowledge base list if there is no parent (`data.parentId` is null).
