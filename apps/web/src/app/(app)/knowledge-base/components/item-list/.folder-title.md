# folder-title.tsx

Renders the title row for a knowledge base folder page, including the folder name, a back-navigation link to the parent level, and a contextual menu for folder operations (rename, move, delete).

## Key Components

- **`FolderTitle`** — Main component that displays the folder's title bar with back navigation and action menu. Accepts a Relay fragment reference to the folder and a list of page action buttons.
- **`folderTitleFragment`** — GraphQL fragment (`folderTitle_folder`) that fetches the folder's `name`, `parentId`, and spreads fragments required by the rename, move, and delete modals.
- **`FolderTitleProps`** — Props interface requiring a `folder` fragment key and `actions` (`PageActionButton[]`).

## Behavior

- Computes `parentUrl` from `data.parentId`, falling back to the knowledge base list route if the folder has no parent.
- Uses `useSafeBack` to produce a `leave` handler that navigates back safely, reused as the `onDeleted` callback so deleting a folder returns the user to the same place as pressing Back.
- Manages a single `dialog` state (`FolderDialogKind | null`) to control which modal (rename, move, or delete) is currently open, driven by menu actions from `folderMenuGroups`.

## Usage Example

```typescript
import { FolderTitle } from './folder-title';
import type { PageActionButton } from '@flamingo-stack/openframe-frontend-core/components/ui';

function FolderPage({ folderRef }: { folderRef: folderTitle_folder$key }) {
  const actions: PageActionButton[] = [
    { label: 'Add Document', onClick: () => console.log('add') },
  ];

  return <FolderTitle folder={folderRef} actions={actions} />;
}
```

The component is intended to be used within a folder detail page, where `folderRef` is obtained via a parent Relay query that spreads the `folderTitle_folder` fragment on a `KnowledgeBaseItem`.
