# knowledge-base-list-title.tsx

A client component that renders the title row for a knowledge base listing page, supporting both the root view and individual folder views with contextual back navigation and action controls.

## Key Components

- **`KnowledgeBaseListTitleProps`** — Interface defining the component's props:
  - `title`: Display name (empty string `''` triggers a loading skeleton bar)
  - `backTo`: Optional route to navigate back to; omitted for the root view (no Back button shown)
  - `actions`: Array of `PageActionButton` items (e.g., Archive, New Folder, Add Article) tied to the route
  - `menuActions`: Optional `ActionsMenuGroup[]` for folder-specific contextual actions

- **`KnowledgeBaseListTitle`** — The exported component. Wraps `TitleBlock` from `@flamingo-stack/openframe-frontend-core`, wiring up:
  - Conditional back button via `useSafeBack` hook (falls back to `routes.knowledgeBase.list` if `backTo` is not provided)
  - `actionsVariant="menu-primary"` styling for the actions menu

## Usage Example

```typescript
import { KnowledgeBaseListTitle } from './knowledge-base-list-title';
import { routes } from '@/lib/routes';

// Root listing — no Back button
<KnowledgeBaseListTitle
  title="Knowledge Base"
  actions={[{ label: 'New Folder', onClick: handleNewFolder }]}
/>

// Folder view — includes Back button and folder-specific menu actions
<KnowledgeBaseListTitle
  title={folder.name}
  backTo={routes.knowledgeBase.list}
  actions={[{ label: 'Add Article', onClick: handleAddArticle }]}
  menuActions={[
    {
      label: 'Folder Actions',
      items: [{ label: 'Archive', onClick: handleArchive }],
    },
  ]}
/>

// Loading state — title is '' and renders as a skeleton bar
<KnowledgeBaseListTitle title="" actions={[]} />
```

## Notes

- Relies on `useSafeBack` (from `@/app/hooks/use-safe-back`) to safely navigate back, falling back to the configured `backTo` or the default knowledge base list route when there's no browser history to pop.
- The Back button only renders when `backTo` is explicitly provided, since the root listing has no logical "back" destination.
