This component renders the title row for a Knowledge Base listing page, supporting both the root view and individual folder views, with optional back navigation and contextual action buttons/menus.

## Key Components

- **`KnowledgeBaseListTitleProps`** — Props interface defining:
  - `title`: display name (empty string renders a loading bar placeholder)
  - `backTo`: optional route for back navigation (root has none)
  - `actions`: array of `PageActionButton` items (e.g., Archive, New Folder, Add Article)
  - `menuActions`: optional `ActionsMenuGroup[]` for folder-specific operations

- **`KnowledgeBaseListTitle`** — Client component that wraps `TitleBlock` from `@flamingo-stack/openframe-frontend-core`, wiring up:
  - Safe back navigation via `useSafeBack`, falling back to `routes.knowledgeBase.list`
  - Conditional back button rendering (only shown when `backTo` is provided)
  - `menu-primary` actions variant styling

## Usage Example

```typescript
import { KnowledgeBaseListTitle } from './knowledge-base-list-title';
import { routes } from '@/lib/routes';

// Root listing (no back button)
<KnowledgeBaseListTitle
  title="Knowledge Base"
  actions={[
    { label: 'New Folder', onClick: handleNewFolder },
    { label: 'Add Article', onClick: handleAddArticle },
  ]}
/>

// Folder view (with back navigation and folder-specific menu)
<KnowledgeBaseListTitle
  title={folderName}
  backTo={routes.knowledgeBase.folder(parentId)}
  actions={[{ label: 'Add Article', onClick: handleAddArticle }]}
  menuActions={[
    { label: 'Archive', onClick: handleArchive },
    { label: 'Rename', onClick: handleRename },
  ]}
/>
```

Use an empty string for `title` to display the loading placeholder while folder data is being fetched.
