# knowledge-base-item-actions-cell.tsx

Renders the row-level "⋯" actions menu for a Knowledge Base table row (folder or article), rendering a different set of menu actions depending on the item's type. Uses Relay fragments to read item data and supports a loading state via `useLoadingScope`.

## Key Components

- **`ItemDialogKind`** — Union type of dialog kinds a row can open: folder dialog kinds (from `FolderDialogKind`) or `'archive'`.
- **`articleMenuGroups(articleId, onOpen)`** — Builds the `ActionsMenuGroup[]` for an article row: "Edit" (navigates via `routes.knowledgeBase.edit`), "Move to folder", and "Archive" (both trigger `onOpen` with the respective dialog kind).
- **`KnowledgeBaseItemActionsCell`** — The main exported component. Reads the item via the `knowledgeBaseItemActionsCell_item` Relay fragment, determines whether the item is a `FOLDER` or an article, and renders the corresponding menu groups (`folderMenuGroups` or `articleMenuGroups`) inside an `ActionsMenuDropdown`.

During a loading scope (row data not yet resolved), the fragment read is skipped and an empty, inert menu trigger is rendered instead.

## Usage Example

```typescript
import { KnowledgeBaseItemActionsCell, type ItemDialogKind } from './knowledge-base-item-actions-cell';

function KnowledgeBaseRow({ itemRef }: { itemRef: knowledgeBaseItemActionsCell_item$key }) {
  const handleOpenDialog = (dialog: ItemDialogKind) => {
    // e.g. setActiveDialog(dialog)
  };

  return (
    <tr>
      {/* ...other cells... */}
      <td>
        <KnowledgeBaseItemActionsCell item={itemRef} onOpen={handleOpenDialog} />
      </td>
    </tr>
  );
}
```

**Note:** The dialog itself is owned and rendered by the parent table (via `onOpen`), not by this cell — see `useRowDialog` for the rationale. The `data-no-row-click` attribute prevents the row's own click/link handler from firing when interacting with the menu.
