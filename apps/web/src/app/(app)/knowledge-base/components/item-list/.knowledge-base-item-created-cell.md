Renders the "Created" column cell in the knowledge base table, displaying the creation timestamp for article rows while leaving folder rows blank.

## Key Components

- **`KnowledgeBaseItemCreatedCell`** - React component that reads a `KnowledgeBaseItem` GraphQL fragment and conditionally renders a formatted timestamp.
- **`knowledgeBaseItemCreatedCellFragment`** - Relay GraphQL fragment declaring the `type` and `createdAt` fields required from `KnowledgeBaseItem`.

## Usage Example

```typescript
import { KnowledgeBaseItemCreatedCell } from './knowledge-base-item-created-cell';
import type { knowledgeBaseItemCreatedCell_item$key } from '@/__generated__/knowledgeBaseItemCreatedCell_item.graphql';

function KnowledgeBaseRow({ itemRef }: { itemRef: knowledgeBaseItemCreatedCell_item$key }) {
  return (
    <tr>
      {/* other cells */}
      <td>
        <KnowledgeBaseItemCreatedCell item={itemRef} />
      </td>
    </tr>
  );
}
```

### Behavior Notes

- While the row is within a loading scope (e.g., skeleton/placeholder state), the fragment read is skipped and `ItemTimestamp` renders its loading bars via a `null` value.
- If the item's `type` is not `ARTICLE` (e.g., it's a folder) or `createdAt` is missing, the component renders nothing (`null`).
- Only `ARTICLE` type items with a valid `createdAt` display a formatted timestamp, delegated to the shared `ItemTimestamp` component.
