Renders the "Created" column cell for a knowledge base table row, displaying the article's creation timestamp while leaving folder rows empty.

## Key Components

- **`knowledgeBaseItemCreatedCellFragment`** — GraphQL fragment declaring the `type` and `createdAt` fields needed from a `KnowledgeBaseItem`.
- **`KnowledgeBaseItemCreatedCell`** — React component that reads the fragment data and renders an `ItemTimestamp`:
  - Returns a loading-state `ItemTimestamp` (`value={null}`) when inside a loading scope or when fragment data isn't available yet.
  - Returns `null` for non-`ARTICLE` items (e.g., folders) or when `createdAt` is missing.
  - Otherwise renders `ItemTimestamp` with the article's `createdAt` value.

## Usage Example

```typescript
import { KnowledgeBaseItemCreatedCell } from './knowledge-base-item-created-cell';
import { graphql, useFragment } from 'react-relay';

// Typically used as a table cell within a row renderer that holds
// a fragment reference to a KnowledgeBaseItem
function KnowledgeBaseRow({ item }: { item: KnowledgeBaseRow_item$key }) {
  const data = useFragment(
    graphql`
      fragment KnowledgeBaseRow_item on KnowledgeBaseItem {
        ...knowledgeBaseItemCreatedCell_item
      }
    `,
    item
  );

  return (
    <tr>
      <td>
        <KnowledgeBaseItemCreatedCell item={data} />
      </td>
    </tr>
  );
}
```

Within a `LoadingScope` provider, the component automatically renders a skeleton/loading timestamp instead of attempting to read fragment data, enabling seamless placeholder rows during data fetches.
