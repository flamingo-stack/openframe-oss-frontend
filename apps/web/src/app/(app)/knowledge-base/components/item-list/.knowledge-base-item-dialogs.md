# knowledge-base-item-dialogs.tsx

A client-side component that renders the appropriate modal dialog for a Knowledge Base item (folder or article) based on the action kind selected from the item's row menu, such as rename, move, delete, or archive.

## Key Components

- **`KnowledgeBaseItemDialogs`** — Main exported component. Resolves a single Relay fragment on a `KnowledgeBaseItem` and switches on the `kind` prop to render one of the four modal dialogs (`RenameFolderModal`, `MoveToFolderModal`, `DeleteFolderModal`, `ArchiveArticleModal`), passing through shared `isOpen`/`onClose` handlers and, where applicable, `listingIds` so affected listings can be updated or removed after the action completes.
- **`knowledgeBaseItemDialogsFragment`** — GraphQL fragment on `KnowledgeBaseItem` that spreads the fragments required by each child modal (`renameFolderModal_folder`, `moveToFolderModal_item`, `deleteFolderModal_folder`, `archiveArticleModal_article`), ensuring a single fetch satisfies all possible dialog variants.
- **`KnowledgeBaseItemDialogsProps`** — Props interface: `item` (Relay fragment key), `kind` (`ItemDialogKind`), `isOpen`, `onClose`, and `listingIds` (read-only array of listing IDs the row belongs to, used to keep on-screen listings in sync after archive/delete/move operations).

## Usage Example

```typescript
import { KnowledgeBaseItemDialogs } from './knowledge-base-item-dialogs';
import type { ItemDialogKind } from './knowledge-base-item-actions-cell';

function KnowledgeBaseRow({ item, listingIds }) {
  const [openDialog, setOpenDialog] = useState<ItemDialogKind | null>(null);

  return (
    <>
      {/* row menu triggers setOpenDialog('rename' | 'move' | 'delete' | 'archive') */}
      {openDialog && (
        <KnowledgeBaseItemDialogs
          item={item}
          kind={openDialog}
          isOpen={!!openDialog}
          onClose={() => setOpenDialog(null)}
          listingIds={listingIds}
        />
      )}
    </>
  );
}
```

Only one dialog is rendered at a time, driven by the `kind` value, making this component a single mount point for all item-level actions in a Knowledge Base listing.
