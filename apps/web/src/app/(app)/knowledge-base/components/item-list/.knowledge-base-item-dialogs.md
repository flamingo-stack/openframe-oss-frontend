## Knowledge Base Item Dialogs

A dispatcher component that renders the appropriate modal dialog (rename, move, delete, or archive) for a Knowledge Base item, based on which action was triggered from a row's context menu.

## Key Components

- **`KnowledgeBaseItemDialogs`** — The main exported component. Resolves a GraphQL fragment on a `KnowledgeBaseItem` and conditionally renders one of four modals (`RenameFolderModal`, `MoveToFolderModal`, `DeleteFolderModal`, `ArchiveArticleModal`) depending on the `kind` prop.
- **`knowledgeBaseItemDialogsFragment`** — Relay fragment that composes the fragments required by each child modal (`renameFolderModal_folder`, `moveToFolderModal_item`, `deleteFolderModal_folder`, `archiveArticleModal_article`), ensuring a single data fetch covers all dialog variants.
- **`KnowledgeBaseItemDialogsProps`** — Props interface: `item` (Relay fragment ref), `kind` (`ItemDialogKind` discriminant), `isOpen`, `onClose`, and `listingIds` (IDs of the listings the row currently appears in, used to update cache after move/delete/archive).

## Usage Example

```typescript
import { KnowledgeBaseItemDialogs } from './knowledge-base-item-dialogs';

function KnowledgeBaseRow({ item, listingIds }) {
  const [openDialog, setOpenDialog] = useState<ItemDialogKind | null>(null);

  return (
    <>
      {/* row content, menu triggers setOpenDialog('rename' | 'move' | 'delete' | 'archive') */}
      {openDialog && (
        <KnowledgeBaseItemDialogs
          item={item}
          kind={openDialog}
          isOpen={openDialog !== null}
          onClose={() => setOpenDialog(null)}
          listingIds={listingIds}
        />
      )}
    </>
  );
}
```

This component is typically rendered alongside `knowledge-base-item-actions-cell.tsx`, which supplies the `kind` value (`ItemDialogKind`) when a user selects a menu action for a given row.
