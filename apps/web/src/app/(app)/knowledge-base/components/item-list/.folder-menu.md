Defines the shared actions menu configuration for folder entities, used both in folder listing rows and on a folder's own page header.

## Key Components

- **`FolderDialogKind`** — Union type (`'rename' | 'move' | 'delete'`) representing the dialogs that can be triggered from the folder menu.
- **`folderMenuGroups(onOpen)`** — Factory function that builds an `ActionsMenuGroup[]` structure for the actions menu. Accepts a callback `onOpen` invoked with the appropriate `FolderDialogKind` when a menu item is clicked. Returns a single group containing three items: **Rename**, **Move folder**, and **Delete**, each with an icon and click handler.
- **`ICON_CLASS`** — Shared Tailwind class string applied to all menu item icons for consistent sizing and color.

## Usage Example

```typescript
import { folderMenuGroups, type FolderDialogKind } from './folder-menu';
import { ActionsMenu } from '@flamingo-stack/openframe-frontend-core/components/ui';
import { useState } from 'react';

function FolderRow() {
  const [openDialog, setOpenDialog] = useState<FolderDialogKind | null>(null);

  const groups = folderMenuGroups((dialog) => setOpenDialog(dialog));

  return (
    <>
      <ActionsMenu groups={groups} />
      {openDialog === 'rename' && <RenameFolderDialog onClose={() => setOpenDialog(null)} />}
      {openDialog === 'move' && <MoveFolderDialog onClose={() => setOpenDialog(null)} />}
      {openDialog === 'delete' && <DeleteFolderDialog onClose={() => setOpenDialog(null)} />}
    </>
  );
}
```

This pattern lets the same menu configuration be reused in both the folder listing table and the folder detail page header, keeping dialog-opening logic centralized in the consuming component.
