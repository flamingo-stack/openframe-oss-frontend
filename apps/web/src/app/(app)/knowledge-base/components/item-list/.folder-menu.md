Defines the actions menu configuration for folder management, used both in folder listing rows and folder page headers to trigger rename, move, and delete dialogs.

## Key Components

- **`FolderDialogKind`** - A type union representing the dialog types a folder's menu can open: `'rename'`, `'move'`, or `'delete'`.
- **`folderMenuGroups(onOpen)`** - A factory function that builds an `ActionsMenuGroup[]` configuration for the shared actions menu component. Accepts a callback invoked with the relevant `FolderDialogKind` when a menu item is clicked, and returns a single group containing three items (Rename, Move folder, Delete) each with an icon and click handler.

## Usage Example

```typescript
import { useState } from 'react';
import { ActionsMenu } from '@flamingo-stack/openframe-frontend-core/components/ui';
import { folderMenuGroups, type FolderDialogKind } from './folder-menu';

function FolderRow() {
  const [openDialog, setOpenDialog] = useState<FolderDialogKind | null>(null);

  const groups = folderMenuGroups((dialog) => setOpenDialog(dialog));

  return (
    <>
      <ActionsMenu groups={groups} />
      {openDialog === 'rename' && <RenameFolderDialog onClose={() => setOpenDialog(null)} />}
      {openDialog === 'move' && <MoveFolderDialog onClose={() => setOpenDialog(null)} />}
      {openDialog === 'delete' && <DeleteFolderDialog onClose={() => setOpenDialog(null)} />}
    </>
  );
}
```

This pattern lets a single `folderMenuGroups` factory drive the menu for both a folder's row in a listing and the header of its dedicated page, keeping dialog-opening logic centralized in the consuming component.
