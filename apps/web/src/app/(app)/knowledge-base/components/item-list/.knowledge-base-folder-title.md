## Knowledge Base Folder Title

Renders the title bar for a knowledge base folder page, fetching the folder's data by ID and handling loading/not-found states independently from the folder's content rows.

## Key Components

- **`KnowledgeBaseFolderTitle`** — Public component that wraps the title-loading logic in a `LoadingSuspense` boundary, isolating this part of the page so it doesn't block the content rows (which fetch by id in parallel).
- **`KnowledgeBaseFolderTitleReader`** — Internal component that renders a placeholder title while inside a loading scope (e.g., during a parent suspense fallback), otherwise delegates to the live version.
- **`KnowledgeBaseFolderTitleLive`** — Fetches the folder via `knowledgeBaseFolderTitleQuery`, calls `notFound()` if the item isn't a `FOLDER` type, and renders `FolderTitle` with the resolved data.
- **`knowledgeBaseFolderTitleQuery`** — GraphQL query fetching `type` and the `folderTitle_folder` fragment for a given item ID.

## Usage Example

```typescript
import { KnowledgeBaseFolderTitle } from './knowledge-base-folder-title';

export default function FolderPage({ params }: { params: { folderId: string } }) {
  return (
    <KnowledgeBaseFolderTitle
      folderId={params.folderId}
      actions={[
        { label: 'Edit', onClick: () => console.log('edit') },
        { label: 'Delete', onClick: () => console.log('delete') },
      ]}
    />
  );
}
```

The component uses `fetchPolicy: 'store-and-network'` combined with a `retryKey` (via `useRetryKey`) to support retrying failed fetches. If the fetched item isn't a folder (e.g., it's an article or doesn't exist), Next.js's `notFound()` is triggered to render the 404 page.
