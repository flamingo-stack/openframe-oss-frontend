# knowledge-base-folder-title.tsx

Renders the title bar for a Knowledge Base folder page, fetching the folder's data via a GraphQL query with its own Suspense boundary so the title loads independently from the folder's content rows below it.

## Key Components

- **`KnowledgeBaseFolderTitle`** — Public component wrapping the title in a `LoadingSuspense` boundary with a loading label, isolating its fetch from sibling content.
- **`KnowledgeBaseFolderTitleReader`** — Suspense-aware inner component; renders a placeholder title bar (empty title, back link to the Knowledge Base list) while inside a loading scope, otherwise defers to the live variant.
- **`KnowledgeBaseFolderTitleLive`** — Executes the `knowledgeBaseFolderTitleQuery` via `useLazyLoadQuery`, validates the item is a `FOLDER` type (calling `notFound()` otherwise), and renders `FolderTitle` with the fetched fragment data.
- **`knowledgeBaseFolderTitleQuery`** — GraphQL query fetching a `knowledgeBaseItem` by `id`, including its `type` and the `folderTitle_folder` fragment.

## Usage Example

```typescript
import { KnowledgeBaseFolderTitle } from './knowledge-base-folder-title';

function FolderPage({ params }: { params: { folderId: string } }) {
  const actions = [
    { label: 'Add Article', onClick: () => {/* ... */} },
  ];

  return (
    <KnowledgeBaseFolderTitle
      folderId={params.folderId}
      actions={actions}
    />
  );
}
```

The component handles its own loading and not-found states internally—callers only need to supply the `folderId` and `actions` props. The `useRetryKey` hook ensures the query can be re-fetched when a retry is triggered elsewhere in the app.
