# knowledge-base-items-table.tsx

Renders one level of the knowledge base (root or a folder) as a paginated, live-updating table of folders and articles. It handles data fetching via Relay (query, pagination fragment, and invalidation subscriptions), a loading-scope placeholder mode for Suspense fallbacks, infinite scroll, empty states, and row-action dialogs (rename, move, delete, etc.).

## Key Components

- **`KnowledgeBaseItemsTable`** — Public entry component. Wraps everything in a `LoadingSuspense` boundary and delegates to `KnowledgeBaseItemsTableReader`.
- **`KnowledgeBaseItemsTableReader`** — Checks `useLoadingScope()`; if in a loading scope, renders placeholder rows with no data fetch, otherwise defers to `KnowledgeBaseItemsTableQuery`.
- **`KnowledgeBaseItemsTableQuery`** — Runs the Relay query (`useLazyLoadQuery`), sets up pagination (`usePaginationFragment`), and subscribes to invalidation state so stale listings (from mutations like move/create) refetch automatically.
- **`KnowledgeBaseItemsRows`** — Pure presentational component that builds the `useDataTable` instance, decides whether to show the empty state or the `LiveTable`, and manages the row-action dialog (`useRowDialog`).
- **`buildColumns`** — Constructs column definitions: name (with folder label for subtree listings), created date, actions, and open-in-new-tab.
- **GraphQL definitions** — `knowledgeBaseItemsTableQuery` and `knowledgeBaseItemsTable_query` fragment (refetchable as `knowledgeBaseItemsTablePaginationQuery`), driving a `@connection` for pagination.
- **`ItemRow`** — Type alias for a single node in the `knowledgeBaseItems` connection.

## Usage Example

```typescript
import { KnowledgeBaseItemsTable } from './knowledge-base-items-table';

function KnowledgeBaseView() {
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <KnowledgeBaseItemsTable
      listing={{ folderId: null, search: '', tags: [] }}
      isPending={false}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
    />
  );
}
```

The component expects a `KnowledgeBaseListing` describing the current folder/search/tag context, an `isPending` flag for in-flight refetches (e.g., while typing a search), and `onEmptyChange` to let the parent view hide its toolbar when the level has no items at all (distinct from a search/filter yielding zero matches).
