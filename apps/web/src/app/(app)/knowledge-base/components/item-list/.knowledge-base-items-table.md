# knowledge-base-items-table.tsx

Renders a paginated table of knowledge base items (folders and articles) for a single level — either the root folder or a specific subfolder. Supports two modes: a flat browse of the current level (folders first, then articles) or a flattened search/tag-filtered view across the whole subtree. Integrates with Relay for data fetching/pagination, supports infinite scroll, loading placeholders, and row-level action dialogs.

## Key Components

- **`KnowledgeBaseItemsTable`** — Public entry component. Wraps the reader in a `LoadingSuspense` boundary with a "Loading articles" label.
- **`KnowledgeBaseItemsTableReader`** — Detects loading scope (e.g., Suspense fallback) and either renders placeholder rows with no query, or delegates to the live query component.
- **`KnowledgeBaseItemsTableQuery`** — Runs the GraphQL query (`useLazyLoadQuery` + `usePaginationFragment`), subscribes to invalidation state (refetches when a mutation marks the listing stale), and wires up `useKnowledgeBaseLoadMore` for infinite scroll.
- **`KnowledgeBaseItemsRows`** — Pure presentational table builder using `useDataTable`; decides between the page's `EmptyState` (nothing on this level) and `LiveTable`'s own "no match" row (search/filter miss); manages row dialogs via `useRowDialog`.
- **`buildColumns`** — Builds column definitions (name, created, actions, open-in-new-tab) based on whether the listing is a flattened subtree (shows parent folder name) or a flat level listing.
- **GraphQL artifacts** — `knowledgeBaseItemsTableQuery` and `knowledgeBaseItemsTable_query` fragment (refetchable as `knowledgeBaseItemsTablePaginationQuery`), paginating via a `@connection`.

## Usage Example

```typescript
import { KnowledgeBaseItemsTable } from './knowledge-base-items-table';

function KnowledgeBaseFolderView({ listing, isPending }: Props) {
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <div>
      {!isEmpty && <KnowledgeBaseToolbar />}
      <KnowledgeBaseItemsTable
        listing={listing}
        isPending={isPending}
        onEmptyChange={setIsEmpty}
        stickyHeaderOffset="64px"
      />
    </div>
  );
}
```

The component expects a `KnowledgeBaseListing` (built via `knowledgeBaseListingArgs`) describing the current folder, search term, and tag filters, and notifies the parent view via `onEmptyChange` when the level has no items at all (distinct from a search/filter yielding zero matches).
