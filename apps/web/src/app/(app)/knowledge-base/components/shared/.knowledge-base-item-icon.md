# knowledge-base-item-icon.ts

Defines a shared icon mapping for Knowledge Base item types, ensuring visual consistency between the Knowledge Base table UI and Mingo's `@kb`/`@kbFolder` mention chips in chat.

## Key Components

- **`KB_ITEM_ICON`** — A constant record mapping each `KnowledgeBaseItemType` enum value (`ARTICLE`, `FOLDER`) to its corresponding icon component (`BookTextIcon`, `FolderIcon`). Uses the `satisfies` operator to enforce exhaustive type coverage of `KnowledgeBaseItemType` while preserving precise literal icon types.

## Usage Example

```typescript
import { KB_ITEM_ICON } from './knowledge-base-item-icon';
import { KnowledgeBaseItemType } from '@/generated/schema-enums';

function KnowledgeBaseRowIcon({ type }: { type: KnowledgeBaseItemType }) {
  const Icon = KB_ITEM_ICON[type];
  return <Icon className="h-4 w-4" />;
}

// Example: rendering an icon for a mention chip
const articleIcon = KB_ITEM_ICON[KnowledgeBaseItemType.ARTICLE]; // BookTextIcon
const folderIcon = KB_ITEM_ICON[KnowledgeBaseItemType.FOLDER];   // FolderIcon
```

This mapping should be used anywhere a Knowledge Base item type's icon is displayed, so that adding a new `KnowledgeBaseItemType` value requires updating only this single file (TypeScript will enforce completeness via `satisfies`).
