# use-tag-search-state.ts

A React hook that manages combined search-text and tag-filter state for the Knowledge Base, persisting both in the URL so filters survive page refresh and back/forward navigation.

## Key Components

- **`TagSearchState`** — Interface describing the hook's return value: current/debounced search text, selected tags, tag IDs, tag search options, and mutator functions (`setSearch`, `addTag`, `removeTag`, `setTags`, `clearAll`).
- **`encodeTag(tag)`** — Serializes a `SelectableTag` into a single URL-safe string (`id:key`), used to store each tag as a repeated `tags=` query parameter.
- **`decodeTag(entry)`** — Parses an encoded tag string back into a `SelectableTag`, splitting on the first colon (tag IDs never contain `:`, but keys may).
- **`useTagSearchState()`** — Main hook. Combines `useApiParams` (URL param sync) and `useSearchParam` (debounced, lag-free text input) to expose a unified search + tag filter API.

## Usage Example

```typescript
import { useTagSearchState } from '@/app/hooks/use-tag-search-state';

function KnowledgeBaseFilters() {
  const {
    search,
    setSearch,
    debouncedSearch,
    selectedTags,
    tagIds,
    tagSearchOptions,
    addTag,
    removeTag,
    clearAll,
  } = useTagSearchState();

  // Use `debouncedSearch` and `tagIds` as query inputs for data fetching
  // e.g. useArticlesQuery({ search: debouncedSearch, tagIds })

  return (
    <div>
      <input value={search} onChange={e => setSearch(e.target.value)} />
      <TagPicker options={tagSearchOptions} onAdd={addTag} onRemove={removeTag} />
      <button onClick={clearAll}>Clear filters</button>
    </div>
  );
}
```

## Notes

- Each selected tag is stored as its own `tags=<id>:<key>` entry in the URL (repeated query params) rather than a single comma-joined value, avoiding escaping issues with special characters in tag keys.
- Search input updates immediately in local state while the URL write is debounced (300ms), keeping typing responsive without losing keystrokes to router navigation.
- `clearAll` resets both search text and tag selection in a single URL update.
