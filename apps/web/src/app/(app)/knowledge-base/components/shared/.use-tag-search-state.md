# use-tag-search-state.ts

A React hook that manages combined search text and tag filter state for the Knowledge Base, persisting both in the URL so filters survive page refresh and browser back/forward navigation.

## Key Components

- **`TagSearchState`** — Interface describing the hook's return value: search text (raw + debounced), selected tags, derived tag IDs/options, and mutator functions.
- **`useTagSearchState()`** — Main hook that wires together `useApiParams` (URL param state) and `useSearchParam` (debounced search input) into a unified search/filter API.
- **`encodeTag` / `decodeTag`** — Internal helpers that serialize a `SelectableTag` to/from the `id:key` string format used in the `tags` URL param. Splitting occurs on the first colon only, so tag keys may safely contain colons.
- **`addTag(tag)`** — Adds a tag to the selection if not already present.
- **`removeTag(id)`** — Removes a tag by ID.
- **`setTags(tags)`** — Replaces the entire selected-tag set while preserving search text.
- **`clearAll()`** — Resets both search and tags to empty.

## Usage Example

```typescript
import { useTagSearchState } from '@/app/hooks/use-tag-search-state';

function KnowledgeBaseFilters() {
  const {
    search,
    setSearch,
    debouncedSearch,
    selectedTags,
    tagIds,
    tagSearchOptions,
    addTag,
    removeTag,
    clearAll,
  } = useTagSearchState();

  return (
    <div>
      <input value={search} onChange={e => setSearch(e.target.value)} />

      {/* Use debouncedSearch to trigger data fetching */}
      {/* fetchArticles({ query: debouncedSearch, tagIds }) */}

      {selectedTags.map(tag => (
        <button key={tag.id} onClick={() => removeTag(tag.id)}>
          {tag.key} ✕
        </button>
      ))}

      <button onClick={clearAll}>Clear all filters</button>
    </div>
  );
}
```

Tags persist as repeated `tags=<id>:<key>` URL entries, ensuring special characters in keys (commas, colons) don't break parsing. Search input remains responsive to typing via local state, with writes to the URL debounced by 300ms.
