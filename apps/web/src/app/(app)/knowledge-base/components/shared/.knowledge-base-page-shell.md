# knowledge-base-page-shell.tsx

A client-side layout wrapper component that provides consistent page padding and error boundary handling for all Knowledge Base routes.

This shell ensures that when a query or rendering error occurs within a knowledge base page, the error boundary's fallback UI remains properly padded and indented, rather than collapsing the layout spacing declared by the parent.

## Key Components

- **`KnowledgeBasePageShellProps`** — Interface defining the component's props:
  - `errorMessage: string` — Message displayed when the error boundary is triggered.
  - `resetKey?: string` — Optional key (typically a record `?id=`) used to reset a previously tripped error boundary when navigating to a new record.
  - `children: ReactNode` — The page content to render inside the shell.

- **`KnowledgeBasePageShell`** — The main exported component. Wraps `children` in a padded container and a `ContentErrorBoundary`, providing a consistent "Knowledge Base" error title across all routes that use it.

## Usage Example

```typescript
import { KnowledgeBasePageShell } from '@/app/components/knowledge-base/knowledge-base-page-shell';

export default function ArticlePage({ searchParams }: { searchParams: { id?: string } }) {
  return (
    <KnowledgeBasePageShell
      errorMessage="Failed to load this knowledge base article."
      resetKey={searchParams.id}
    >
      <ArticleContent id={searchParams.id} />
    </KnowledgeBasePageShell>
  );
}
```

Use this shell at the top level of any knowledge base page component to ensure consistent spacing and error recovery behavior. Pass a unique `resetKey` (such as the current record's ID) so that navigating between records automatically clears any previously triggered error state.
