## KnowledgeBaseItemNameCell

A React Relay component that renders the NAME column cell for knowledge base list rows, handling both loaded data and loading-skeleton states via GraphQL fragment composition.

This component acts as a data-fetching wrapper around `KnowledgeBaseItemName`, resolving a Relay fragment reference into the fields needed for display (type, name, status, summary). It integrates with `useLoadingScope` to detect when a row is a placeholder being rendered during pagination/loading, in which case it skips fragment reading and renders a default loading shape instead.

## Key Components

- **`knowledgeBaseItemNameCellFragment`** — GraphQL fragment declaration spread on `KnowledgeBaseItem`, selecting `type`, `name`, `status`, and `summary`.
- **`KnowledgeBaseItemNameCellProps`** — Props interface requiring an `item` fragment key and an optional `folder` string (used when rows span multiple folders in a combined list).
- **`KnowledgeBaseItemNameCell`** — The exported component function that resolves the fragment and delegates rendering to `KnowledgeBaseItemName`.

## Usage Example

```typescript
import { KnowledgeBaseItemNameCell } from './knowledge-base-item-name-cell';

function KnowledgeBaseRow({ itemRef }: { itemRef: knowledgeBaseItemNameCell_item$key }) {
  return (
    <td>
      <KnowledgeBaseItemNameCell item={itemRef} folder="Onboarding" />
    </td>
  );
}
```

In a list context, each row passes its own Relay fragment reference (`itemRef`). When the row is within a loading scope (e.g., during infinite scroll or initial fetch), the component bypasses `useFragment` and renders an empty `ARTICLE`-type placeholder, ensuring the UI remains stable while data streams in.
