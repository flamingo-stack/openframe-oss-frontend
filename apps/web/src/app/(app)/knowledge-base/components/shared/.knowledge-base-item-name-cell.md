Renders the **NAME** column cell for rows in knowledge base list tables, resolving a GraphQL fragment to display item name, type, status, and summary — with built-in support for loading placeholder states.

## Key Components

- **`KnowledgeBaseItemNameCell`** — React component that reads a `KnowledgeBaseItem` fragment via Relay and renders a `KnowledgeBaseItemName` presentational component.
- **`knowledgeBaseItemNameCellFragment`** — GraphQL fragment defined on `KnowledgeBaseItem`, selecting `type`, `name`, `status`, and `summary`.
- **`KnowledgeBaseItemNameCellProps`** — Prop interface requiring an `item` fragment reference and an optional `folder` string (used when a table mixes rows from multiple folders).

## Usage Example

```typescript
import { KnowledgeBaseItemNameCell } from './knowledge-base-item-name-cell';

function KnowledgeBaseRow({ item }: { item: knowledgeBaseItemNameCell_item$key }) {
  return (
    <td>
      <KnowledgeBaseItemNameCell item={item} folder="Onboarding" />
    </td>
  );
}
```

## Behavior Notes

- Uses `useLoadingScope()` to detect whether the row is still loading. If so, `useFragment` is called with `null` instead of the real fragment reference, and the component renders a placeholder `KnowledgeBaseItemName` with an empty name, `null` status, and `null` summary, defaulting the type to `KnowledgeBaseItemType.ARTICLE`.
- Once data resolves, the actual `type`, `name`, `status`, and `summary` are passed through to `KnowledgeBaseItemName`, along with the optional `folder` prop for disambiguating rows across folders.
- Marked `'use client'`, indicating this is a client-rendered component (relies on Relay hooks and client-side state).
