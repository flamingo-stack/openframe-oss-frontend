Defines display and normalization logic for knowledge base article statuses, ensuring consistent status-to-color mapping and safe status resolution across the UI.

## Key Components

- **`ARTICLE_STATUS_VARIANT`** — A readonly record mapping each `KnowledgeBaseArticleStatus` enum value to a tag/badge color variant (`'success'`, `'warning'`, `'grey'`). Used by both list rows and article detail pages to render consistent status badges.
- **`toArticleStatus(status)`** — A normalization function that takes a raw, possibly `null`/`undefined` status string and resolves it to a valid `KnowledgeBaseArticleStatus`. Any value that isn't explicitly `PUBLISHED` or `ARCHIVED` falls back to `DRAFT`, treating missing status as the safe default.

## Usage Example

```typescript
import { ARTICLE_STATUS_VARIANT, toArticleStatus } from './article-status';
import { KnowledgeBaseArticleStatus } from '@/generated/schema-enums';

// Normalize a possibly-missing status from an API response
const rawStatus = article.status; // could be null
const status = toArticleStatus(rawStatus);

// Use the normalized status to pick a badge color
const variant = ARTICLE_STATUS_VARIANT[status];

// Render in a Vue component
```

```vue
<template>
  <Tag :variant="variant">{{ status }}</Tag>
</template>
```

This pattern ensures that articles without an explicit status are always treated as drafts, and the same color scheme is applied wherever article status is displayed.
