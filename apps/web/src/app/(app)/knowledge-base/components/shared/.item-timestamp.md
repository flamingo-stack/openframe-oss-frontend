A compact timestamp display component that renders a date and time stacked vertically, used as a reusable column element in knowledge base list views.

## Key Components

- **`ItemTimestamp`** — A functional component that accepts a `value` prop (`Instant | null`) and renders:
  - The formatted date on the first line (via `formatDate`)
  - The formatted time on the second line (via `formatTime`), styled with a smaller, secondary-toned variant
  - Both lines use `TruncateText` to handle overflow gracefully and prevent layout shifts in constrained-width columns
  - When `value` is `null` (e.g., during loading), both lines render empty, allowing parent skeleton/loading states to display placeholder bars

## Usage Example

```typescript
import { ItemTimestamp } from '@/components/item-timestamp';
import type { Instant } from '@/lib/graphql-scalars';

function KnowledgeBaseRow({ createdAt }: { createdAt: Instant | null }) {
  return (
    <div className="grid grid-cols-[1fr_auto] gap-4">
      <span>Article Title</span>
      <ItemTimestamp value={createdAt} />
    </div>
  );
}

// Loading state example
function LoadingRow() {
  return <ItemTimestamp value={null} />;
}
```

## Notes

- Relies on `formatDate` and `formatTime` utilities from `@/lib/format-date` for locale-aware formatting.
- The `TruncateText` component comes from the shared `@flamingo-stack/openframe-frontend-core` UI package, ensuring consistent text truncation behavior across the app.
- Designed for use within flex/grid layouts where `min-w-0` ensures proper truncation inside constrained columns.
