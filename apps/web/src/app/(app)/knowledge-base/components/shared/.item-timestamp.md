Renders a compact two-line timestamp cell for knowledge base list items, displaying the formatted date on top and the formatted time below it in secondary, truncated text.

## Key Components

- **`ItemTimestamp`** - A client component that accepts a single `value` prop of type `Instant | null` and renders a vertically stacked date/time display. When `value` is `null` (e.g., during a loading state), it renders empty strings, allowing skeleton/loading placeholders to occupy the space gracefully.
- Uses `TruncateText` from `@flamingo-stack/openframe-frontend-core/components/ui` to prevent overflow in constrained table/list layouts.
- Uses `formatDate` and `formatTime` helpers from `@/lib/format-date` to format the `Instant` value consistently across the app.

## Usage Example

```typescript
import { ItemTimestamp } from '@/components/item-timestamp';
import type { Instant } from '@/lib/graphql-scalars';

function KnowledgeBaseRow({ updatedAt }: { updatedAt: Instant | null }) {
  return (
    <div className="grid grid-cols-[1fr_auto] gap-4">
      <span>Article Title</span>
      <ItemTimestamp value={updatedAt} />
    </div>
  );
}
```

```typescript
// Loading state example - value is null until data resolves
function LoadingRow() {
  return <ItemTimestamp value={null} />;
}
```

Typically used inside table rows or list items where a compact, two-line timestamp display (date above, time below) is needed, such as in knowledge base article listings or audit log entries.
