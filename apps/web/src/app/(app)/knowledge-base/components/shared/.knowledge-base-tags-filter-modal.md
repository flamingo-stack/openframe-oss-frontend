# knowledge-base-tags-filter-modal.tsx

A mobile/compact-view modal for filtering knowledge base articles by tags, presenting all available tags as a single checkbox group. Designed as a touch-friendly alternative to the inline tag filter row used on wider viewports, and also reused for filtering the Assigned Articles tab.

## Key Components

- **`KnowledgeBaseTagsFilterModal`** — Public entry component. Wraps the reader in a `LoadingSuspense` boundary with a "Loading tags" fallback.
- **`KnowledgeBaseTagsFilterModalReader`** — Detects if it's already inside a loading scope (e.g., an outer Suspense boundary) via `useLoadingScope()`. If so, renders a loading placeholder without triggering a data read; otherwise delegates to the query component.
- **`KnowledgeBaseTagsFilterModalQuery`** — Fetches tags via `useKnowledgeBaseTags`, scoped by `parentId`, `archived` status, optional `assignedTo` target, and a `refreshKey` to force re-fetch after assign/unassign actions.
- **`TagsFilterModalView`** — Presentational component rendering `FilterModal` with a single filter group (`tags`), mapping selected tag IDs back to full `SelectableTag` objects on apply.
- **`noTagsDescription`** — Helper producing context-aware empty-state copy depending on whether the view is scoped to assigned articles, archived articles, a folder, or the whole knowledge base.

## Usage Example

```typescript
import { KnowledgeBaseTagsFilterModal } from './knowledge-base-tags-filter-modal';

function ArticlesListMobile() {
  const [isOpen, setIsOpen] = useState(false);
  const [selectedTagIds, setSelectedTagIds] = useState<string[]>([]);

  return (
    <KnowledgeBaseTagsFilterModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      parentId={null}
      archived={false}
      selectedIds={selectedTagIds}
      onApply={(tags) => setSelectedTagIds(tags.map(t => t.id))}
    />
  );
}
```

**Note:** `onApply` receives the complete new selection as `SelectableTag[]`, not a delta — treat it as a full replacement of the current filter state.
