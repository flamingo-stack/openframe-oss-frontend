The knowledge base tag filter as a modal (a phone's, where the tag row has no room, and the Assigned Articles tab's at
every width): every tag as a checkbox in the lib's `FilterModal`. Suspends on the tags; in a loading scope (its
Suspense fallback) the modal draws its own loading state and reads nothing.

## Key Components

- **`KnowledgeBaseTagsFilterModal`** — Exported. Switches on `useLoadingScope()`: in a scope it draws the view with
  `NO_ITEMS` and `isLoading`, otherwise it runs the tags query.
- **`KnowledgeBaseTagsFilterModalQuery`** — Internal. Reads the tags with `useKnowledgeBaseTags(parentId, archived,
  assignedTo, refreshKey)` (the assigned articles' tags when `assignedTo` is given).
- **`TagsFilterModalView`** — Internal. One `FilterModal` group (`TAGS_GROUP_ID`, the tags are flat) and the
  apply handler.

## Usage Example

```typescript
import type { SelectableTag } from '@/app/components/shared';
import { KnowledgeBaseTagsFilterModal } from './knowledge-base-tags-filter-modal';

<KnowledgeBaseTagsFilterModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  parentId="folder-123"
  archived={false}
  selectedIds={selected.map(tag => tag.id)}
  onApply={(tags: SelectableTag[]) => setSelected(tags)} // replaces the selection
/>;
```

## Behavior Notes

- `FilterModal` re-seeds its checkboxes from `selectedIds` each time it opens.
- `onApply` receives the whole new selection (replace, not merge).
- `refreshKey` is bumped after an assign or unassign, which can change the tags on offer.
