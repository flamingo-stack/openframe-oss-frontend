## KnowledgeBaseTagsFilterModal

A modal dialog component for filtering knowledge base articles by tags, designed as the mobile/narrow-width alternative to an inline tag filter row. It suspends while tag data loads and renders tags as a single checkbox group.

## Key Components

- **`KnowledgeBaseTagsFilterModal`** — Public entry point. Wraps the reader in a `LoadingSuspense` boundary so the modal can render its own loading state while tags are being fetched.
- **`KnowledgeBaseTagsFilterModalReader`** — Detects whether it's inside an active loading scope (via `useLoadingScope`) and either renders a loading placeholder or delegates to the data-fetching query component.
- **`KnowledgeBaseTagsFilterModalQuery`** — Calls `useKnowledgeBaseTags` to fetch tags scoped by `parentId`, `archived` state, `assignedTo` target, and `refreshKey`.
- **`TagsFilterModalView`** — Pure presentational component that renders `FilterModal` with a single filter group (`tags`), handles selection changes, and supplies a contextual empty-state message via `noTagsDescription`.
- **`noTagsDescription`** — Helper producing a context-aware empty-state message (assigned articles, archived folder, specific folder, or whole knowledge base).

## Usage Example

```typescript
import { KnowledgeBaseTagsFilterModal } from './knowledge-base-tags-filter-modal';

function ArticleListToolbar() {
  const [isOpen, setIsOpen] = useState(false);
  const [selectedTagIds, setSelectedTagIds] = useState<string[]>([]);

  return (
    <KnowledgeBaseTagsFilterModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      parentId={null}
      archived={false}
      assignedTo={null}
      refreshKey={0}
      selectedIds={selectedTagIds}
      onApply={(tags) => {
        setSelectedTagIds(tags.map(tag => tag.id));
        setIsOpen(false);
      }}
    />
  );
}
```

Pass `assignedTo` to scope tags to a customer's or device's assigned articles instead of the general knowledge base, and bump `refreshKey` after assign/unassign operations to refetch the available tag set.
