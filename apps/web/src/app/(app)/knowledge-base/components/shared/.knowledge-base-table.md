A React hook that wraps Relay's pagination (`loadNext`/`hasNext`/`isLoadingNext`) into an `InfiniteScroll`-compatible object for knowledge base listings, triggering a destructive toast notification on load errors.

## Key Components

- **`useKnowledgeBaseLoadMore(pagination, errorTitle)`** — Hook that accepts Relay pagination props and an error toast title, returning an `InfiniteScroll` object (`hasNextPage`, `isFetchingNextPage`, `onLoadMore`).
- **`onLoadMore`** — Internal callback that guards against redundant fetches (no next page or already loading) and loads the next `KNOWLEDGE_BASE_PAGE_SIZE` items, surfacing a toast on failure.

## Usage Example

```typescript
import { useKnowledgeBaseLoadMore } from './knowledge-base-table';
import { useInfiniteScroll } from '@/app/components/shared';

function KnowledgeBaseList({ relayPagination }: { relayPagination: RelayPaginationProp }) {
  const { loadNext, hasNext, isLoadingNext } = relayPagination;

  const infiniteScroll = useKnowledgeBaseLoadMore(
    { loadNext, hasNext, isLoadingNext },
    'Failed to load more articles',
  );

  // Pass infiniteScroll into a shared infinite-scroll-enabled table/list component
  return <KnowledgeBaseTable infiniteScroll={infiniteScroll} />;
}
```

This hook centralizes the pagination-to-UI binding logic so any knowledge base listing component can consistently handle "load more" behavior and error reporting without duplicating toast logic.
