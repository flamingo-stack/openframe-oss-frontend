A client-side hook that wraps Relay's pagination primitives (`loadNext`, `hasNext`, `isLoadingNext`) into an `InfiniteScroll`-compatible interface for the knowledge base listing, surfacing load errors via a toast notification.

## Key Components

- **`useKnowledgeBaseLoadMore(args, errorTitle)`** - Hook that accepts Relay pagination props and an error toast title, returning an `InfiniteScroll` object (`hasNextPage`, `isFetchingNextPage`, `onLoadMore`) consumable by a shared infinite-scroll UI component.
- Internally guards against redundant fetches (no-op if `hasNext` is `false` or a fetch `isLoadingNext`).
- Fetches pages sized by `KNOWLEDGE_BASE_PAGE_SIZE` (imported from `./knowledge-base-item-columns`).
- On fetch error, shows a destructive-variant toast with the supplied `errorTitle` and the error message.

## Usage Example

```typescript
import { useKnowledgeBaseLoadMore } from './knowledge-base-table';
import { InfiniteScrollList } from '@/app/components/shared';

function KnowledgeBaseTable({ connection }: { connection: KnowledgeBaseConnection }) {
  const { data, loadNext, hasNext, isLoadingNext } = usePaginationFragment(
    knowledgeBaseFragment,
    connection,
  );

  const infiniteScroll = useKnowledgeBaseLoadMore(
    { loadNext, hasNext, isLoadingNext },
    'Failed to load more articles',
  );

  return (
    <InfiniteScrollList {...infiniteScroll}>
      {data.items.map(item => (
        <KnowledgeBaseRow key={item.id} item={item} />
      ))}
    </InfiniteScrollList>
  );
}
```

This hook decouples the Relay pagination API from the generic `InfiniteScroll` UI contract, keeping toast-based error handling consistent across knowledge base views.
