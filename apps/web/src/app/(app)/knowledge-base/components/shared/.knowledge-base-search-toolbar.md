## Purpose

A sticky search toolbar for knowledge base list views, combining a tag-aware search input with responsive tag filtering: a row of tag chips on wider viewports, or a filter button opening a modal on narrower ones. The responsive switch is handled via CSS breakpoints rather than a media-query hook to avoid first-render flicker.

## Key Components

- **`KnowledgeBaseSearchToolbar`** — The main component. Renders:
  - A sticky container (positioned via `toolbarRef` from `useStickyToolbar`)
  - A `TagSearchInput` bound to the provided `filters` state (search text, selected tags)
  - A filter `Button` (visible below the `content-md` breakpoint) that opens `KnowledgeBaseTagsFilterModal`
  - `KnowledgeBaseTagsRow` (visible at `content-md` and above) showing available tag chips
  - `KnowledgeBaseTagsFilterModal` rendered as a sibling (not nested) to escape the toolbar's sticky stacking context

- **`KnowledgeBaseSearchToolbarProps`**
  - `toolbarRef`: ref callback from `useStickyToolbar` so the table header can pin beneath this bar
  - `placeholder`: search input placeholder text
  - `parentId`: folder scope for tag offers (`null` = whole knowledge base)
  - `archived`: optional flag to scope tags to archived articles
  - `filters`: a `TagSearchState` object driving search/tag state

## Usage Example

```typescript
import { KnowledgeBaseSearchToolbar } from './knowledge-base-search-toolbar';
import { useTagSearchState } from './use-tag-search-state';
import { useStickyToolbar } from '@flamingo-stack/openframe-frontend-core/hooks';

function KnowledgeBaseList({ folderId }: { folderId: string | null }) {
  const filters = useTagSearchState();
  const { toolbarRef } = useStickyToolbar();

  return (
    <KnowledgeBaseSearchToolbar
      toolbarRef={toolbarRef}
      placeholder="Search articles..."
      parentId={folderId}
      archived={false}
      filters={filters}
    />
  );
}
```

**Notes:**
- Both `KnowledgeBaseTagsRow` and `KnowledgeBaseTagsFilterModal` independently suspend while loading their tag lists, each with its own loading boundary.
- The modal is rendered outside the sticky toolbar `div` so it isn't clipped by the toolbar's `z-20` stacking context.
