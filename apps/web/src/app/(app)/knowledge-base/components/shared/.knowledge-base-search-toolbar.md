Sticky search toolbar for knowledge base list views, combining a tag-aware search input with responsive tag filtering (inline chips on wider screens, modal on narrower ones).

## Key Components

- **`KnowledgeBaseSearchToolbar`** — Main component rendering the sticky toolbar. Composes:
  - `TagSearchInput` — search box showing selected tags as removable chips
  - `KnowledgeBaseTagsRow` — inline row of available tags (shown at `content-md` breakpoint and up)
  - `KnowledgeBaseTagsFilterModal` — modal for tag filtering (shown below `content-md`, triggered by filter button)
- **`KnowledgeBaseSearchToolbarProps`** — Props interface:
  - `toolbarRef` — callback ref from `useStickyToolbar` so the table header can pin beneath the bar
  - `placeholder` — search input placeholder text
  - `parentId` — folder scope for tag offerings (`null` = entire knowledge base)
  - `archived` — optional flag to pull tags from archived articles instead
  - `filters` — a `TagSearchState` object driving search text, selected tags, and tag mutation callbacks

The responsive behavior (chips row vs. filter modal trigger) is handled purely via CSS (`content-md:hidden` / `content-md:contents`) rather than a media-query hook, avoiding a flash on first render.

## Usage Example

```typescript
import { KnowledgeBaseSearchToolbar } from './knowledge-base-search-toolbar';
import { useTagSearchState } from './use-tag-search-state';
import { useStickyToolbar } from './use-sticky-toolbar';

function KnowledgeBaseList({ folderId }: { folderId: string | null }) {
  const filters = useTagSearchState();
  const { toolbarRef } = useStickyToolbar();

  return (
    <div>
      <KnowledgeBaseSearchToolbar
        toolbarRef={toolbarRef}
        placeholder="Search articles..."
        parentId={folderId}
        archived={false}
        filters={filters}
      />
      {/* Article list / table follows, header pinned under the toolbar */}
    </div>
  );
}
```

## Notes

- The tag filter modal is rendered as a sibling of the sticky bar (not nested inside), since the bar is its own stacking context (`sticky` + `z-20`) and would otherwise clip the modal below the app header.
- Tag data fetching is delegated to `KnowledgeBaseTagsRow` and `KnowledgeBaseTagsFilterModal`, each suspending independently with their own loading states.
