# use-knowledge-base-tags.ts

A React hook that fetches the set of knowledge base tags available for filtering articles, scoped to either a folder, the archived list, or articles assigned to a customer/device. It powers both the tag filter row and the phone modal's filter UI from a single shared GraphQL query.

## Key Components

- **`useKnowledgeBaseTagsQuery`** — GraphQL query definition fetching `knowledgeBaseTags` by `folderId`, `archived`, and/or `assignedTo`.
- **`useKnowledgeBaseTags(folderId, archived, assignedTo?, refreshKey?)`** — Hook that executes the query via `useLazyLoadQuery` and returns a normalized array of `SelectableTag` objects (`{ id, key }`).

### Parameters

| Param | Type | Description |
|---|---|---|
| `folderId` | `string \| null` | Restrict tags to articles in this folder. |
| `archived` | `boolean` | When `true`, restrict tags to archived articles. |
| `assignedTo` | `AssignedArticlesTarget \| null` | When provided, restricts tags to articles assigned to this target; takes precedence over `folderId`/`archived` on the server. |
| `refreshKey` | `number` | Incrementing this forces a refetch (e.g., after an assign/unassign operation changes the tag set). |

Returns `SelectableTag[]`.

## Usage Example

```typescript
import { useKnowledgeBaseTags } from '@/app/components/.../use-knowledge-base-tags';

function TagFilterRow({ folderId }: { folderId: string | null }) {
  const tags = useKnowledgeBaseTags(folderId, false);

  return (
    <div>
      {tags.map(tag => (
        <span key={tag.id}>{tag.key}</span>
      ))}
    </div>
  );
}

// Filtering by assignment target, with manual refresh after an unassign action
function AssignedTagsFilter({ target }: { target: AssignedArticlesTarget }) {
  const [refreshKey, setRefreshKey] = useState(0);
  const tags = useKnowledgeBaseTags(null, false, target, refreshKey);

  const handleUnassign = async () => {
    await unassignArticle();
    setRefreshKey(k => k + 1); // triggers refetch
  };

  return <TagList tags={tags} onUnassign={handleUnassign} />;
}
```

**Note:** This hook uses `useLazyLoadQuery` with `fetchPolicy: 'store-and-network'`, so it must be rendered inside a Relay `Suspense` boundary.
