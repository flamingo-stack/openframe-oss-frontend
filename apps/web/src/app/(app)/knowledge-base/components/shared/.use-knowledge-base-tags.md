Fetches and returns tags assigned to knowledge-base articles, scoped by folder and archived state. Used to back the list filter row and filter modal in the knowledge-base UI.

## Key Components

- **`knowledgeBaseTagsQuery`** — GraphQL query (`useKnowledgeBaseTagsQuery`) that fetches tags via `knowledgeBaseTags(folderId, archived)`, returning `id`, `key`, `color`, and `description` per tag.
- **`KnowledgeBaseTag`** — TypeScript type alias for a single tag item derived from the generated query response type.
- **`useKnowledgeBaseTags(options?)`** — React hook that executes the query with `store-and-network` fetch policy and returns a memoized, filtered array of tags.

## Usage Example

```typescript
import { useKnowledgeBaseTags } from '@/hooks/use-knowledge-base-tags';

function KnowledgeBaseFilterBar({ folderId }: { folderId: string }) {
  const tags = useKnowledgeBaseTags({ folderId, archived: false });

  return (
    <div>
      {tags.map(tag => (
        <span key={tag.id} style={{ color: tag.color }}>
          {tag.key}
        </span>
      ))}
    </div>
  );
}
```

> **Note:** This hook returns only tags *already assigned* to articles within the given scope. The article editor's tag picker uses `tagsByEntityType(entityType: KNOWLEDGE_ARTICLE)` via `EntityTagPicker` instead, which exposes the full tenant tag vocabulary including unlinked tags.

## Notes

- `folderId` and `archived` both default to `null` when omitted, returning tags across all folders/states.
- Relies on Relay's `useLazyLoadQuery` — the nearest Suspense boundary will handle the loading state.
