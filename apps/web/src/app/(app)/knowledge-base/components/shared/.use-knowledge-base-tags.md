## use-knowledge-base-tags.ts

A React hook that fetches the set of tags available for filtering knowledge base articles, scoped to a folder, the archived list, or articles assigned to a specific customer/device. It backs both the tag filter row and the mobile filter modal via a single shared GraphQL query.

## Key Components

- **`useKnowledgeBaseTagsQuery`** — The GraphQL query (defined via `graphql` tag) that requests `knowledgeBaseTags` filtered by `folderId`, `archived`, and/or `assignedTo`.
- **`useKnowledgeBaseTags(folderId, archived, assignedTo?, refreshKey?)`** — Hook that executes the query with `useLazyLoadQuery` and returns an array of `SelectableTag` objects (`{ id, key }`).
  - `folderId`: scope tags to a specific folder, or `null` for no folder scoping.
  - `archived`: when `true`, scopes to archived articles; otherwise passed as `null` to the server.
  - `assignedTo`: an `AssignedArticlesTarget` (customer/device); takes precedence over `folderId`/`archived` on the server side.
  - `refreshKey`: bump this value to force a refetch (e.g., after a tag assign/unassign action).

## Usage Example

```typescript
import { useKnowledgeBaseTags } from './use-knowledge-base-tags';

function TagFilterRow({ folderId }: { folderId: string | null }) {
  const [refreshKey, setRefreshKey] = useState(0);

  const tags = useKnowledgeBaseTags(folderId, false, null, refreshKey);

  const handleTagAssigned = () => {
    // Force a refetch since the available tag set may have changed
    setRefreshKey(prev => prev + 1);
  };

  return (
    <div>
      {tags.map(tag => (
        <span key={tag.id}>{tag.key}</span>
      ))}
    </div>
  );
}

// Filtering by assignment target instead of folder
function DeviceTagFilter({ deviceId }: { deviceId: string }) {
  const tags = useKnowledgeBaseTags(null, false, {
    targetType: 'DEVICE',
    targetId: deviceId,
  });

  return <TagList tags={tags} />;
}
```

**Note:** This hook uses `useLazyLoadQuery` with `fetchPolicy: 'store-and-network'`, so it must be rendered inside a Relay `Suspense` boundary. The internal `useRetryKey` combined with `refreshKey` forms the Relay `fetchKey`, ensuring a fresh network request whenever either value changes.
