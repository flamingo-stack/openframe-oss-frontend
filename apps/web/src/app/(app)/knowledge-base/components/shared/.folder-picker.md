# folder-picker.tsx

A dropdown picker component for selecting a folder from the knowledge base's folder tree, including the root folder and any custom leading options. It fetches the full, unpaged folder tree via GraphQL (needed since a picker must expose all depths at once) and renders it as a nested `ActionsMenuDropdown`, with a loading-aware trigger shown while data is in flight.

## Key Components

- **`FolderPicker`** — Public entry point. Wraps `FolderPickerBody` in a `LoadingSuspense` boundary so the component manages its own loading state independently of parent suspense.
- **`FolderPickerBody`** — Checks `useLoadingScope()` to decide whether to render a disabled `FolderPickerTrigger` (while loading) or the fully interactive `FolderPickerMenu`.
- **`FolderPickerTrigger`** — The visual field/button used as the Radix `asChild` trigger. Must forward all received props (open handlers, `aria-*`, ref) to the underlying button for the menu to function.
- **`FolderPickerMenu`** — Loads the folder tree via `useLazyLoadQuery`, resolves the currently picked folder's display name, and renders an `ActionsMenuDropdown` with a root item plus nested folder menu items.
- **`folderPickerQuery`** — GraphQL query fetching the entire `knowledgeBaseFolderTree`, fragment-delegated via `folderTree_folder`.
- **`FolderPickerProps`** — Props interface: `value` (picked folder id, `null` for root, `undefined` for none), `onSelect`, `placeholder`, `label`, `leadingItems`, `excludeFolderId`, `disabled`.

## Usage Example

```typescript
import { FolderPicker } from './folder-picker';
import type { FolderTarget } from './folder-tree';

function MoveFileDialog() {
  const [folderId, setFolderId] = useState<string | null | undefined>(undefined);

  const handleSelect = (target: FolderTarget) => {
    setFolderId(target.id);
  };

  return (
    <FolderPicker
      value={folderId}
      onSelect={handleSelect}
      placeholder="Choose a destination folder"
      excludeFolderId="current-folder-id"
      leadingItems={[
        { id: 'new-folder', label: 'Create New Folder', onClick: () => openCreateFolderDialog() },
      ]}
    />
  );
}
```

Pass `disabled` to lock the control, or `label` to override the trigger text for non-folder selections (e.g., when the pick represents a special target rather than an actual folder).
