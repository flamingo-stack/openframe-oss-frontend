# folder-picker.tsx

A dropdown picker component for selecting a folder from the knowledge base's folder tree. It fetches the entire unpaged folder hierarchy via GraphQL and renders it as a nested `ActionsMenuDropdown`, supporting root selection, exclusion of specific folders, and custom leading menu items.

## Key Components

- **`FolderPicker`** — Public entry point. Wraps `FolderPickerBody` in a `LoadingSuspense` boundary with a "Loading folders" label.
- **`FolderPickerBody`** — Internal component that checks `useLoadingScope()` to render a locked trigger during loading, or the interactive `FolderPickerMenu` once data is ready.
- **`FolderPickerTrigger`** — Shared trigger button (built on `InputTrigger`) used both for the loading state and the active menu trigger, with a chevron-down icon.
- **`FolderPickerMenu`** — Fetches the folder tree via `useLazyLoadQuery`, resolves the currently picked folder's display name, and builds the dropdown menu items (root + nested folders).
- **`folderPickerQuery`** — GraphQL query fetching the full `knowledgeBaseFolderTree` (unpaged, all depths) via the `folderTree_folder` fragment.
- **`FolderPickerProps`** — Props interface: `value` (picked folder id, `null` for root, `undefined` for none), `onSelect`, `placeholder`, `label`, `leadingItems`, `excludeFolderId`, `disabled`.

## Usage Example

```typescript
import { FolderPicker } from './folder-picker';
import type { FolderTarget } from './folder-tree';

function DocumentFolderField() {
  const [folder, setFolder] = useState<string | null | undefined>(undefined);

  const handleSelect = (target: FolderTarget) => {
    setFolder(target.id);
  };

  return (
    <FolderPicker
      value={folder}
      onSelect={handleSelect}
      placeholder="Select Folder"
      excludeFolderId="current-doc-folder-id"
      leadingItems={[
        { id: 'create-new', label: 'Create New Folder', onClick: () => openCreateFolderDialog() },
      ]}
    />
  );
}
```

Pass `value={null}` to represent the root folder as selected, or `value={undefined}` when nothing has been picked yet. Use `excludeFolderId` to prevent selecting a folder (and its descendants) that would create an invalid move, such as moving a folder into itself.
