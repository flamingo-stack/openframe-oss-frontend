Generates the navigation URL for a knowledge base item based on its type, routing folders to a listing view and articles to a detail view.

## Key Components

- **`knowledgeBaseItemHref(type, id)`** - Pure function that takes a knowledge base item's `type` and `id`, returning the appropriate route string. Uses `KnowledgeBaseItemType.FOLDER` to determine whether to generate a folder listing URL (`routes.knowledgeBase.folder(id)`) or an article detail URL (`routes.knowledgeBase.details(id)`).

## Usage Example

```typescript
import { knowledgeBaseItemHref } from '@/lib/knowledge-base-item-href';
import { KnowledgeBaseItemType } from '@/generated/schema-enums';

// Folder item -> links to folder listing
const folderUrl = knowledgeBaseItemHref(KnowledgeBaseItemType.FOLDER, 'folder-123');
// e.g. "/knowledge-base/folders/folder-123"

// Article item -> links to article details
const articleUrl = knowledgeBaseItemHref('ARTICLE', 'article-456');
// e.g. "/knowledge-base/articles/article-456"

// Typical usage in a list/table row component
items.map((item) => (
  <Link href={knowledgeBaseItemHref(item.type, item.id)}>
    {item.title}
  </Link>
));
```

This utility centralizes routing logic for knowledge base rows, ensuring consistent navigation behavior across list views, search results, and tables that render mixed folder/article items.
