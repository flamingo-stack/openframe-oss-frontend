Utility function that computes the navigation target (URL) for a knowledge base item based on its type, distinguishing between folder listings and article detail pages.

## Key Components

- **`knowledgeBaseItemHref(type, id)`** — Returns the appropriate route string for a given knowledge base item. If the item's `type` matches `KnowledgeBaseItemType.FOLDER`, it returns the folder listing route; otherwise, it returns the article details route.

## Usage Example

```typescript
import { knowledgeBaseItemHref } from '@/lib/knowledge-base-item-href';
import { KnowledgeBaseItemType } from '@/generated/schema-enums';

// Folder item -> navigates to the folder listing page
const folderHref = knowledgeBaseItemHref(KnowledgeBaseItemType.FOLDER, 'folder-123');
// => '/knowledge-base/folders/folder-123' (based on routes.knowledgeBase.folder)

// Article item -> navigates to the article details page
const articleHref = knowledgeBaseItemHref(KnowledgeBaseItemType.ARTICLE, 'article-456');
// => '/knowledge-base/articles/article-456' (based on routes.knowledgeBase.details)

// Typical usage in a component rendering a row link
function KnowledgeBaseRow({ item }: { item: { type: string; id: string } }) {
  const href = knowledgeBaseItemHref(item.type, item.id);
  return `<a href="${href}">View</a>`;
}
```

This function is typically used when rendering lists of knowledge base items (e.g., in tables or navigation menus) where each row needs to link to the correct destination depending on whether it represents a folder or an individual article.
