The tags a knowledge base list can still be filtered by, as one row of chips (`SelectableTagsRow`). Suspends on the
tags; in a loading scope (its toolbar's Suspense fallback) it draws the row's own loading state and reads nothing.

## Key Components

- **`KnowledgeBaseTagsRow`** — Exported. Switches on `useLoadingScope()`: in a scope it draws `SelectableTagsRow` with
  `NO_ITEMS` (the one empty item list, `app/components/shared/no-next-page.ts`), otherwise it runs the tags query.
  Props: `parentId` (`null` outside a folder), `archived`, `selectedIds`, `onAdd(tag: SelectableTag)`.
- **`KnowledgeBaseTagsRowQuery`** — Internal. Reads the tags with `useKnowledgeBaseTags(parentId, archived)` and draws
  them.

## Usage Example

```typescript
import type { SelectableTag } from '@/app/components/shared';
import { KnowledgeBaseTagsRow } from './knowledge-base-tags-row';

const [selected, setSelected] = useState<SelectableTag[]>([]);

<KnowledgeBaseTagsRow
  parentId="folder-123"
  archived={false}
  selectedIds={selected.map(tag => tag.id)}
  onAdd={tag => setSelected(prev => [...prev, tag])}
/>;
```
