A client-side component that renders a row of selectable knowledge base tags, suspending on the tags; in a loading scope (its toolbar's Suspense fallback) it draws `SelectableTagsRow`'s own loading state and reads nothing.

## Key Components

- **`SelectedKnowledgeBaseTag`** — Interface describing a selected tag with `id` and `key` string fields
- **`KnowledgeBaseTagsRowProps`** — Props interface accepting a `parentId` (folder context), `selectedIds`, an `onAdd` callback, and optional `archived` flag
- **`KnowledgeBaseTagsRowContent`** — Internal component that fetches tags via `useKnowledgeBaseTags` and renders them using `SelectableTagsRow`
- **`KnowledgeBaseTagsRow`** — Public-facing component: switches on `useLoadingScope()`, otherwise runs the tags query

## Usage Example

```typescript
import { KnowledgeBaseTagsRow, SelectedKnowledgeBaseTag } from './knowledge-base-tags-row';

function MyForm() {
  const [selectedIds, setSelectedIds] = useState<string[]>([]);

  const handleAdd = (tag: SelectedKnowledgeBaseTag) => {
    setSelectedIds(prev => [...prev, tag.id]);
  };

  return (
    <KnowledgeBaseTagsRow
      parentId="folder-123"
      selectedIds={selectedIds}
      onAdd={handleAdd}
      archived={false}
    />
  );
}
```

## Notes

- The toolbar's Suspense fallback renders this same component in a `LoadingFallback`, so the row draws its own loading state while the tags are fetched
- Pass `parentId` as `null` to fetch tags outside of any folder context
- The `archived` prop filters the tag list to include archived knowledge base items when set to `true`
