Renders a row of filterable tag chips for the knowledge base, allowing users to filter articles by tag within a given parent folder. It manages Suspense-based loading states so the row can render a placeholder while tag data is fetched, without blocking the rest of the toolbar.

## Key Components

- **`KnowledgeBaseTagsRow`** — Public component that wraps the reader in a `LoadingSuspense` boundary with the label `"Loading tags"`.
- **`KnowledgeBaseTagsRowReader`** — Checks `useLoadingScope()`; if inside a loading scope, renders `SelectableTagsRow` with `NO_ITEMS` (no data fetch triggered). Otherwise delegates to the query component.
- **`KnowledgeBaseTagsRowQuery`** — Calls `useKnowledgeBaseTags(parentId, archived)` to fetch tags and renders them via `SelectableTagsRow`.
- **`KnowledgeBaseTagsRowProps`** — Props interface: `parentId`, `archived`, `selectedIds`, and `onAdd` callback.

## Usage Example

```typescript
import { KnowledgeBaseTagsRow } from './knowledge-base-tags-row';
import type { SelectableTag } from '@/app/components/shared';

function KnowledgeBaseToolbar() {
  const [selectedTagIds, setSelectedTagIds] = useState<string[]>([]);

  const handleAddTag = (tag: SelectableTag) => {
    setSelectedTagIds((prev) => [...prev, tag.id]);
  };

  return (
    <KnowledgeBaseTagsRow
      parentId="folder-123"
      archived={false}
      selectedIds={selectedTagIds}
      onAdd={handleAddTag}
    />
  );
}
```

This component is designed to be used within a toolbar that already provides a `Suspense` boundary context, allowing it to gracefully degrade to a non-fetching placeholder when rendered inside a loading scope (e.g., during route transitions).
