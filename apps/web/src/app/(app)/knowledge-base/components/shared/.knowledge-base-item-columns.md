Defines the static column layout configuration for knowledge base list tables, used to keep skeleton loaders and live table rendering visually consistent.

## Key Components

- **`KNOWLEDGE_BASE_ITEM_COLUMNS`** — A typed constant object describing each column in the knowledge base table:
  - `name` — Flexible-width primary column displaying the item's name.
  - `created` — Fixed-width (140px) column for creation date, hidden at `lg` breakpoint and below.
  - `actions` — Fixed-width (48px) column for row actions, right-aligned.
  - `open` — Fixed-width (48px) column for an "open" action, hidden at `md` breakpoint and below, right-aligned.
  
  Typed via `satisfies Record<string, TableSkeletonColumn>` to ensure compatibility with the shared `table-column-layout` definitions while preserving literal types.

- **`KNOWLEDGE_BASE_PAGE_SIZE`** — Constant defining the number of items fetched/displayed per page (`20`).

This file is intentionally data-only (no components or logic), so both the real table and its loading skeleton can import the same column definitions and stay in sync.

## Usage Example

```typescript
import {
  KNOWLEDGE_BASE_ITEM_COLUMNS,
  KNOWLEDGE_BASE_PAGE_SIZE,
} from '@/app/components/knowledge-base/knowledge-base-item-columns';

// Rendering table headers
Object.values(KNOWLEDGE_BASE_ITEM_COLUMNS).map((col) => (
  <th key={col.id} className={col.width}>
    {col.header}
  </th>
));

// Fetching paginated data
const { data } = useKnowledgeBaseItems({ pageSize: KNOWLEDGE_BASE_PAGE_SIZE });
```

This configuration is typically consumed by both the live knowledge base table component and its corresponding skeleton loader, ensuring consistent column widths and visibility across loading and loaded states.
