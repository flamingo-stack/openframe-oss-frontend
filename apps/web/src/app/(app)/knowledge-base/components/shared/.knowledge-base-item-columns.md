Defines the static column layout configuration and pagination size for knowledge base item lists, consumed by both the live data table and its loading skeleton to ensure consistent column structure.

## Key Components

- **`KNOWLEDGE_BASE_ITEM_COLUMNS`** — A `Record<string, TableSkeletonColumn>` defining the table's columns:
  - `name` — Flexible-width column for the item name, always visible.
  - `created` — Fixed 140px column for creation date, hidden at `lg` breakpoint and below.
  - `actions` — Fixed 48px column for row actions, right-aligned, never shrinks.
  - `open` — Fixed 48px column (e.g., an "open" link/icon), hidden at `md` breakpoint and below, right-aligned.
- **`KNOWLEDGE_BASE_PAGE_SIZE`** — Constant (`20`) defining the number of items fetched/displayed per page.

This file is data-only (no components or logic) so that both the real table and its skeleton loader can import the same column definitions without circular dependencies or duplicated layout logic.

## Usage Example

```typescript
import {
  KNOWLEDGE_BASE_ITEM_COLUMNS,
  KNOWLEDGE_BASE_PAGE_SIZE,
} from './knowledge-base-item-columns';
import { TableSkeleton } from '@/app/components/shared/table-column-layout';

// Render a loading skeleton matching the real table's columns
<TableSkeleton
  columns={Object.values(KNOWLEDGE_BASE_ITEM_COLUMNS)}
  rowCount={KNOWLEDGE_BASE_PAGE_SIZE}
/>

// Fetch a page of knowledge base items using the shared page size
const items = await fetchKnowledgeBaseItems({ pageSize: KNOWLEDGE_BASE_PAGE_SIZE });
```
