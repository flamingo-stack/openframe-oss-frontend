# knowledge-base-item-name.tsx

Renders the NAME column cell for a knowledge base list row, displaying an icon, truncated name, optional status tag, and a secondary caption combining folder path and article summary. Supports a skeleton-like loading state driven by a Relay loading scope.

## Key Components

- **`KnowledgeBaseItemNameProps`** — Type derived from the `knowledgeBaseItemNameCell_item` GraphQL fragment (minus Relay's internal `$fragmentType`), extended with an optional `folder` string for rows aggregated across multiple folders.
- **`KnowledgeBaseItemName`** — Functional component that renders:
  - A fixed-size icon tile, chosen via `KB_ITEM_ICON` based on whether the item is a `FOLDER` or `ARTICLE`.
  - The item's `name`, truncated with `TruncateText`.
  - A status `Tag` (using `ARTICLE_STATUS_VARIANT`) only when `status` is `DRAFT` or `ARCHIVED`.
  - A secondary caption line joining `folder` and `summary` (summary omitted for folders).
  - A loading state (detected via `useLoadingScope()` combined with an empty `name`) that renders placeholder chrome instead of content.

## Usage Example

```typescript
import { KnowledgeBaseItemName } from './knowledge-base-item-name';
import { KnowledgeBaseItemType, KnowledgeBaseArticleStatus } from '@/generated/schema-enums';

function ExampleRow() {
  return (
    <KnowledgeBaseItemName
      type={KnowledgeBaseItemType.ARTICLE}
      name="Resetting a user's password"
      status={KnowledgeBaseArticleStatus.DRAFT}
      summary="Step-by-step guide for support agents."
      folder="Account Management"
    />
  );
}
```

Typically used as a cell renderer within a knowledge base table or list component, where `item` data is spread in from a Relay fragment and `folder` is supplied when rows originate from multiple source folders.
