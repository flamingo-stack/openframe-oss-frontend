# knowledge-base-item-name.tsx

Renders the "Name" column cell for knowledge base list/table rows, displaying an item's type icon, name, draft/archived status tag, and a secondary caption combining folder path and article summary. Supports a skeleton-like loading state via Relay's loading scope.

## Key Components

- **`KnowledgeBaseItemNameProps`** — Type derived from the `knowledgeBaseItemNameCell_item` GraphQL fragment data (minus `$fragmentType`), extended with an optional `folder` field for cross-folder lists.
- **`KnowledgeBaseItemName`** — Functional component that renders:
  - A fixed icon tile (folder or article icon, from `KB_ITEM_ICON`) based on `type`.
  - A truncated name with an optional status `Tag` (shown only for `DRAFT` or `ARCHIVED` statuses, styled via `ARTICLE_STATUS_VARIANT`).
  - A secondary truncated caption joining `folder` and `summary` (summary omitted for folders).
  - A loading state detected through `useLoadingScope()` when `name` is not yet resolved.

## Usage Example

```typescript
import { KnowledgeBaseItemName } from './knowledge-base-item-name';
import { KnowledgeBaseItemType, KnowledgeBaseArticleStatus } from '@/generated/schema-enums';

function Example() {
  return (
    <KnowledgeBaseItemName
      type={KnowledgeBaseItemType.ARTICLE}
      name="Resetting your password"
      status={KnowledgeBaseArticleStatus.DRAFT}
      summary="Step-by-step guide for password resets."
      folder="Account / Security"
    />
  );
}
```

Typically used as a cell renderer within a table/list component bound to a GraphQL fragment (`knowledgeBaseItemNameCell_item`), where row data is spread directly into the component's props.
