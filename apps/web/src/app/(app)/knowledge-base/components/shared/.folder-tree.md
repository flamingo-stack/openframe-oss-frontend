# folder-tree.ts

Builds and operates on a hierarchical folder tree from a flat list of Knowledge Base folders, used for folder pickers and move/delete destination menus.

## Key Components

- **`ROOT_FOLDER`** — Constant `FolderTarget` representing the Knowledge Base root (`id: null`).
- **`FolderTarget`** — Interface describing a selectable destination (folder or root).
- **`FolderTreeNode`** — Interface for a nested tree node (`id`, `name`, `children`).
- **`buildFolderTree(folders)`** — Converts a flat list of `{ id, name, parentId }` into a nested, alphabetically sorted (natural/numeric collation) `FolderTreeNode[]`. Orphaned folders (parent not in list) are dropped.
- **`readFolderTree(folders)`** — Reads an array of Relay `folderTree_folder$key` fragment refs via `readInlineData`, then delegates to `buildFolderTree`.
- **`findFolderName(tree, id)`** — Recursively looks up a folder's display name by id; returns `null` if not found.
- **`folderMenuItems(tree, onSelect, excludeFolderId?)`** — Converts a tree into `ActionsMenuItem[]` for an actions menu. Leaf folders are directly clickable; folders with children become submenus offering the folder itself plus its subfolders. `excludeFolderId` prunes a folder (and its descendants) to prevent self-targeting during move/delete.

## Usage Example

```typescript
import {
  buildFolderTree,
  readFolderTree,
  findFolderName,
  folderMenuItems,
  ROOT_FOLDER,
  type FolderTarget,
} from './folder-tree';

// From a flat list (e.g. REST response)
const tree = buildFolderTree([
  { id: '1', name: 'Guides', parentId: null },
  { id: '2', name: 'Guides / Setup', parentId: '1' },
]);

// From Relay query results
const relayTree = readFolderTree(folderFragmentRefs);

// Resolve a name for display
const name = findFolderName(tree, '2') ?? ROOT_FOLDER.name;

// Build a destination picker menu, excluding the folder being moved
const onPick = (target: FolderTarget) => console.log('Moved to', target.name);
const menuItems = folderMenuItems(tree, onPick, 'currentFolderId');
```
