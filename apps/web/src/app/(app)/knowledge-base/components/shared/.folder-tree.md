# folder-tree.ts

Utilities for building and consuming a hierarchical folder tree from a flat list of Knowledge Base folders, plus helpers for rendering that tree as navigable actions-menu items (e.g., for "move to folder" or "save in folder" pickers).

## Key Components

- **`ROOT_FOLDER`** — Constant `FolderTarget` representing the root ("Knowledge Base", `id: null`).
- **`FolderTarget`** — Interface describing a selectable destination: a folder or the root.
- **`FolderTreeNode`** — Interface for a nested tree node (`id`, `name`, `children`).
- **`buildFolderTree(folders)`** — Converts a flat array of `{ id, name, parentId }` into a nested, alphabetically-sorted (natural/numeric collation) tree. Orphaned folders (parent not present) are dropped.
- **`readFolderTree(folders)`** — Reads an array of `folderTree_folder$key` Relay fragment references and builds the tree via `buildFolderTree`.
- **`findFolderName(tree, id)`** — Recursively looks up a folder's display name by `id`; returns `null` if not found.
- **`folderMenuItems(tree, onSelect, excludeFolderId?)`** — Converts a tree into `ActionsMenuItem[]` for an actions menu. Folders with children become submenus (offering the folder itself plus a separator before nested items); leaf folders are directly clickable. `excludeFolderId` prunes a folder and its descendants (useful to prevent moving/deleting a folder into itself).

## Usage Example

```typescript
import {
  buildFolderTree,
  readFolderTree,
  findFolderName,
  folderMenuItems,
  ROOT_FOLDER,
  type FolderTarget,
} from './folder-tree';

// From a flat list (e.g., non-GraphQL source)
const tree = buildFolderTree([
  { id: '1', name: 'Guides', parentId: null },
  { id: '2', name: 'Setup', parentId: '1' },
]);

// From Relay fragment references
const treeFromRelay = readFolderTree(knowledgeBaseItems);

// Lookup a folder's name
const name = findFolderName(tree, '2'); // 'Setup'

// Build menu items for a folder picker, excluding the folder being moved
function handleSelect(target: FolderTarget) {
  console.log('Selected destination:', target.id ?? ROOT_FOLDER.id, target.name);
}

const items = folderMenuItems(tree, handleSelect, '2');
```

Typically used in UI components that present a "move to" or "save to" folder picker backed by Relay's `KnowledgeBaseItem` data.
