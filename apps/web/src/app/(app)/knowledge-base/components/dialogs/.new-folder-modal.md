## new-folder-modal.tsx

A React modal component that lets users create a new folder within the knowledge base, using a GraphQL mutation via Relay to persist the folder and update the local Relay store cache.

## Key Components

- **`NewFolderModal`** — The main exported component rendering a `SimpleModal` with a folder name input, Cancel/Create Folder buttons, and submission handling.
- **`newFolderModalMutation`** — GraphQL mutation (`createFolder`) that creates a folder given a `name` and optional `parentId`.
- **`NewFolderModalProps`** — Props interface: `isOpen` (modal visibility), `onClose` (close callback), and `parentId` (target parent folder, `null` for root).

## Behavior Notes

- Input state resets to empty when the modal transitions from open to closed, computed during render (not in an effect) to avoid showing stale text during the closing animation.
- Submission is gated by `canSubmit`, requiring a non-empty trimmed name and no in-flight mutation.
- Pressing `Enter` in the input triggers submission if valid.
- On success, the Relay store is updated via `addToFolderTree` and `invalidateFolderListing` (from `knowledge-base-listings`), a success toast is shown, and the modal closes.
- On error, `getRelayErrorMessage` extracts a user-friendly message shown in a destructive toast.

## Usage Example

```typescript
import { useState } from 'react';
import { NewFolderModal } from '@/app/components/new-folder-modal';

function FolderToolbar({ currentFolderId }: { currentFolderId: string | null }) {
  const [isModalOpen, setIsModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>New Folder</button>
      <NewFolderModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        parentId={currentFolderId}
      />
    </>
  );
}
```
