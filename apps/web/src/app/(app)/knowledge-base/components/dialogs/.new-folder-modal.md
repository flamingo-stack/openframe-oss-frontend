# new-folder-modal.tsx

A modal component that lets users create a new folder within the knowledge base by submitting a GraphQL mutation via Relay, with optimistic store updates and toast notifications for success/error states.

## Key Components

- **`NewFolderModal`** — The main exported React component. Renders a `SimpleModal` containing a text input for the folder name, with Cancel/Create Folder actions in the footer.
- **`newFolderModalMutation`** — GraphQL mutation definition (`createFolder`) that accepts a `name` and optional `parentId`, returning the new folder's `id`, `name`, and `parentId`.
- **`NewFolderModalProps`** — Props interface: `isOpen` (visibility), `onClose` (close callback), and `parentId` (destination folder, `null` for root).

## Behavior Notes

- Input state resets to empty when the modal transitions from open to closed, handled synchronously during render (not in an effect) to avoid showing stale text during the closing animation.
- Submission is gated by `canSubmit`: requires a non-empty trimmed name and no in-flight mutation.
- Pressing `Enter` in the input triggers submission if valid.
- On success, the Relay store is updated via `addToFolderTree` and `invalidateFolderListing` (from `../shared/knowledge-base-listings`) to keep the folder tree and listings in sync without a refetch.
- Errors are surfaced via `getRelayErrorMessage` and displayed in a destructive toast.

## Usage Example

```typescript
import { useState } from 'react';
import { NewFolderModal } from '@/app/components/knowledge-base/new-folder-modal';

function FolderToolbar({ currentFolderId }: { currentFolderId: string | null }) {
  const [isModalOpen, setIsModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>New Folder</button>
      <NewFolderModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        parentId={currentFolderId}
      />
    </>
  );
}
```
