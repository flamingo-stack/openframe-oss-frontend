# move-to-folder-modal.tsx

A modal component that lets users move a knowledge base item (article or folder) to a different folder via a folder picker, using a GraphQL mutation to persist the change and update any affected on-screen listings.

## Key Components

- **`MoveToFolderModal`** — The main exported component. Renders a `SimpleModal` containing a `FolderPicker` and Cancel/Move action buttons.
- **`moveToFolderModalFragment`** — Relay GraphQL fragment fetching `id`, `type`, `name`, and `parentId` for the item being moved.
- **`moveToFolderModalMutation`** — Relay GraphQL mutation (`moveToFolder`) that updates the item's `parentId` and returns updated parent info for list display.
- **`MoveToFolderModalProps`** — Prop interface: `item` (Relay fragment key), `isOpen`, `onClose`, and optional `listingIds` (on-screen listings to update via the Relay store updater).

## Behavior Notes

- Resets the selected `target` folder when the modal closes, computed synchronously during render (avoiding a stale-value flash during the close animation) rather than via `useEffect`.
- Prevents moving a folder into itself or its own descendants by passing `excludeFolderId` to `FolderPicker` when the item type is `KnowledgeBaseItemType.FOLDER`.
- Uses `moveBetweenFolders` (from `shared/knowledge-base-listings`) as the Relay store updater to keep any currently rendered folder listings in sync after the move.
- Shows success/error feedback via the `useToast` hook, parsing mutation errors with `getRelayErrorMessage`.

## Usage Example

```typescript
import { MoveToFolderModal } from '@/app/components/knowledge-base/move-to-folder-modal';

function ArticleRow({ itemRef, listingIds }: { itemRef: any; listingIds: string[] }) {
  const [isModalOpen, setModalOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setModalOpen(true)}>Move</Button>
      <MoveToFolderModal
        item={itemRef}
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
        listingIds={listingIds}
      />
    </>
  );
}
```
