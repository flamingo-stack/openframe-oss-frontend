# move-to-folder-modal.tsx

A modal dialog component that lets users move a knowledge base item (folder or article) to a different folder via a `FolderPicker`, executing the move through a GraphQL mutation with optimistic Relay store updates.

## Key Components

- **`MoveToFolderModal`** — Main exported component rendering a `SimpleModal` with a `FolderPicker` for selecting a destination folder, plus Cancel/Move action buttons.
- **`moveToFolderModalFragment`** — Relay fragment fetching `id`, `type`, `name`, and `parentId` from a `KnowledgeBaseItem`.
- **`moveToFolderModalMutation`** — Relay mutation `moveToFolder` that updates the item's `parentId` and returns the new parent info.
- **`MoveToFolderModalProps`** — Props interface: `item` (fragment ref), `isOpen`, `onClose`, and optional `listingIds` (the on-screen listings the item was dragged/selected from, used for store reconciliation).

## Behavior Notes

- Resets the selected `target` folder when the modal transitions from open to closed, computed synchronously during render (avoids a stale-value flash during the close animation).
- Prevents moving a folder into itself or its own descendants via `excludeFolderId` passed to `FolderPicker`.
- Uses `moveBetweenFolders` store updater to keep any on-screen listings in sync after the mutation.
- Shows success/error toasts using `useToast`, with error messages extracted via `getRelayErrorMessage`.

## Usage Example

```typescript
import { useState } from 'react';
import { MoveToFolderModal } from '@/app/components/knowledge-base/move-to-folder-modal';

function KnowledgeBaseRow({ itemRef, listingIds }) {
  const [isMoveModalOpen, setIsMoveModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsMoveModalOpen(true)}>Move</button>

      <MoveToFolderModal
        item={itemRef}
        isOpen={isMoveModalOpen}
        onClose={() => setIsMoveModalOpen(false)}
        listingIds={listingIds}
      />
    </>
  );
}
```

The `item` prop must be a Relay fragment reference (`moveToFolderModal_item$key`) spread from a parent query that includes the `moveToFolderModal_item` fragment on a `KnowledgeBaseItem`.
