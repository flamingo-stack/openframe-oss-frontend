## UnarchiveArticleModal

A modal dialog component that allows users to restore an archived knowledge base article to a selected destination folder, using a Relay mutation to perform the unarchive operation.

## Key Components

- **`UnarchiveArticleModal`** — Main exported component rendering a `SimpleModal` with a `FolderPicker` to select the destination folder and Cancel/Unarchive actions.
- **`unarchiveArticleModalFragment`** — GraphQL fragment fetching `id` and `name` from the `KnowledgeBaseItem` passed in as `article`.
- **`unarchiveArticleModalMutation`** — GraphQL mutation calling `unarchiveArticle(id, parentId)`, returning updated status, parent info, and timestamp.
- **`UnarchiveArticleModalProps`** — Props interface: `article` (Relay fragment key), `isOpen`, `onClose`, and optional `listingIds` (archive listings currently displaying the article, used for cache cleanup).

## Behavior Notes

- Resets the selected `target` folder when the modal transitions from open to closed, computed during render (not in an effect) to avoid a stale value flashing during the closing animation.
- On confirm, the Relay `updater` removes the article from the given `listingIds`, invalidates the archive listing, and invalidates the destination folder's listing so UI stays in sync without a refetch.
- Displays success/error toasts via `useToast`, using `getRelayErrorMessage` to extract a user-friendly error message.
- The "Unarchive" button is disabled until a destination folder is selected or while the mutation is in flight.

## Usage Example

```typescript
import { UnarchiveArticleModal } from '@/app/components/knowledge-base/unarchive-article-modal';

function ArchivedArticleRow({ articleRef, listingIds }) {
  const [isModalOpen, setModalOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setModalOpen(true)}>Unarchive</Button>
      <UnarchiveArticleModal
        article={articleRef}
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
        listingIds={listingIds}
      />
    </>
  );
}
```
