# unarchive-article-modal.tsx

A modal component that lets users restore an archived knowledge base article to a chosen folder, using a Relay mutation with optimistic cache updates for archive and folder listings.

## Key Components

- **`UnarchiveArticleModal`** — React component rendering a `SimpleModal` with a `FolderPicker` to select a destination folder and a confirm/cancel footer.
- **`UnarchiveArticleModalProps`** — Props interface requiring an `article` Relay fragment key, `isOpen`, `onClose`, and optional `listingIds` (archive listings currently displaying the article, used for cache cleanup).
- **`unarchiveArticleModalFragment`** — GraphQL fragment fetching `id` and `name` from `KnowledgeBaseItem`.
- **`unarchiveArticleModalMutation`** — GraphQL mutation `unarchiveArticle(id, parentId)` returning updated status and parent info.

## Behavior Notes

- Resets the selected `target` folder when the modal transitions from open to closed, computed synchronously during render (avoids a stale frame during the closing animation instead of using an effect).
- On confirm, the mutation's `updater` removes the article from the given `listingIds`, invalidates the archive listing, and invalidates the destination folder's listing to keep the Relay store consistent.
- Shows success/error toasts via `useToast`, using `getRelayErrorMessage` to extract a user-friendly error message.
- The "Unarchive" button is disabled until a target folder is selected or while the mutation `isInFlight`.

## Usage Example

```typescript
import { UnarchiveArticleModal } from '@/app/components/knowledge-base/unarchive-article-modal';

function ArchivedArticleRow({ articleRef, listingId }: { articleRef: any; listingId: string }) {
  const [isModalOpen, setModalOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setModalOpen(true)}>Unarchive</Button>
      <UnarchiveArticleModal
        article={articleRef}
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
        listingIds={[listingId]}
      />
    </>
  );
}
```
