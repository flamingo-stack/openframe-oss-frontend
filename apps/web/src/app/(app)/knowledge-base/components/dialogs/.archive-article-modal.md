# archive-article-modal.tsx

A confirmation modal component that archives a knowledge base article via GraphQL mutation, updating the Relay store to remove the article from active listings and invalidate the archive view.

## Key Components

- **`ArchiveArticleModal`** — Main exported component that renders a `ConfirmDialog` prompting the user to confirm archiving an article.
- **`archiveArticleModalFragment`** — Relay fragment fetching `id`, `name`, and `parentId` from a `KnowledgeBaseItem`.
- **`archiveArticleModalMutation`** — Relay mutation calling `archiveArticle(id)`, returning updated `id`, `status`, and `updatedAt`.
- **`ArchiveArticleModalProps`** — Props interface requiring an `article` fragment reference, `isOpen`/`onClose` dialog controls, and optional `listingIds` for listings currently displaying the article.

## Usage Example

```typescript
import { ArchiveArticleModal } from './archive-article-modal';

function KnowledgeBaseArticleActions({ articleRef, listingIds }) {
  const [isModalOpen, setModalOpen] = useState(false);

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Archive</button>
      <ArchiveArticleModal
        article={articleRef}
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
        listingIds={listingIds}
      />
    </>
  );
}
```

On confirmation, the component:
1. Commits the `archiveArticle` mutation.
2. Updates the Relay store by removing the article from the provided `listingIds`, removing it from its parent folder's listing, and invalidating the archive listing cache.
3. Shows a success toast and closes the modal on completion, or a destructive-variant error toast via `getRelayErrorMessage` on failure.
