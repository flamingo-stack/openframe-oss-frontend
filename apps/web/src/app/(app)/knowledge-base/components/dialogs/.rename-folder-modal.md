Modal component for renaming an existing folder, providing a pre-filled input field and save/cancel actions with loading state management.

## Key Components

### `RenameFolderTarget`
Interface representing the folder to be renamed:
- `id: string` — unique folder identifier
- `name: string` — current folder name

### `RenameFolderModalProps`
- `isOpen: boolean` — controls modal visibility
- `onClose: () => void` — callback when modal is dismissed
- `folder: RenameFolderTarget | null` — target folder data

### `RenameFolderModal`
Main exported component that:
- Pre-populates the input with the current folder name when opened
- Validates input (non-empty, changed from original, not pending)
- Submits via `useRenameFolder` hook and shows a success toast on completion
- Supports `Enter` key submission

## Usage Example

```typescript
import { RenameFolderModal } from './rename-folder-modal';

function FolderList() {
  const [renameTarget, setRenameTarget] = useState<RenameFolderTarget | null>(null);

  return (
    <>
      <button onClick={() => setRenameTarget({ id: 'folder-1', name: 'My Documents' })}>
        Rename
      </button>
      <RenameFolderModal
        isOpen={!!renameTarget}
        onClose={() => setRenameTarget(null)}
        folder={renameTarget}
      />
    </>
  );
}
```

## Behavior Notes

- Input auto-focuses on open via `autoFocus`
- Submit is disabled if the name is unchanged or whitespace-only
- Both buttons are disabled during the pending/saving state
- On success, a toast notification confirms the rename and the modal closes
