# rename-folder-modal.tsx

A React modal component that allows users to rename a knowledge base folder, built on Relay for GraphQL data fetching and mutation handling.

## Key Components

- **`RenameFolderModal`** — The main exported component rendering a modal dialog with a text input for editing a folder's name, plus Cancel/Save actions.
- **`renameFolderModalFragment`** — GraphQL fragment retrieving the folder's `id` and `name` from a `KnowledgeBaseItem`.
- **`renameFolderModalMutation`** — GraphQL mutation (`renameFolder`) that persists the new name and returns updated `id`, `name`, and `updatedAt`.
- **`RenameFolderModalProps`** — Props interface requiring a Relay fragment key (`folder`), an `isOpen` flag, and an `onClose` callback.

## Behavior Notes

- The input's local `name` state is re-seeded from the fragment data each time the modal transitions from closed to open, computed directly during render (not in a `useEffect`) to avoid a visible flash of stale data.
- `canSubmit` guards against empty/unchanged names and prevents double-submits while the mutation is in flight.
- Pressing `Enter` in the input triggers submission if the form is valid.
- On success, a success toast is shown and the modal closes; on failure, an error toast displays a message derived via `getRelayErrorMessage`.

## Usage Example

```typescript
import { RenameFolderModal } from '@/app/components/knowledge-base/rename-folder-modal';
import { useFragment } from 'react-relay';

function FolderActions({ folderRef }: { folderRef: renameFolderModal_folder$key }) {
  const [isRenameOpen, setIsRenameOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsRenameOpen(true)}>Rename</button>
      <RenameFolderModal
        folder={folderRef}
        isOpen={isRenameOpen}
        onClose={() => setIsRenameOpen(false)}
      />
    </>
  );
}
```

The parent component must pass a valid Relay fragment reference (`renameFolderModal_folder$key`) obtained from a parent query or fragment that spreads `renameFolderModal_folder`.
