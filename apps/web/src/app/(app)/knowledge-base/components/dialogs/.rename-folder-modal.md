# rename-folder-modal.tsx

A React modal component that lets users rename a knowledge base folder, using Relay fragments and mutations to fetch the current folder name and persist the update via GraphQL.

## Key Components

- **`RenameFolderModal`** — The main exported component. Renders a `SimpleModal` with a text input for the folder name, a "Cancel" button, and a "Save" button that submits the rename mutation.
- **`renameFolderModalFragment`** — GraphQL fragment that reads `id` and `name` from a `KnowledgeBaseItem`, used to populate the input's initial value via `useFragment`.
- **`renameFolderModalMutation`** — GraphQL mutation `renameFolder(id, name)` that updates the folder and returns `id`, `name`, and `updatedAt`.
- **`RenameFolderModalProps`** — Props interface requiring a Relay fragment key (`folder`), `isOpen` state, and an `onClose` callback.

## Behavior Notes

- The input value is re-seeded from the fragment data only on the `isOpen` transition (computed during render, not in an effect), preventing a flash of stale text and avoiding overwrites from background data refreshes while the user is typing.
- Submission is gated by `canSubmit`: the trimmed name must be non-empty, different from the current name, and no mutation can already be in flight.
- Pressing `Enter` in the input triggers submission if `canSubmit` is true.
- On success, a success toast is shown and the modal closes; on failure, an error toast displays a message derived via `getRelayErrorMessage`.

## Usage Example

```typescript
import { useState } from 'react';
import { useFragment } from 'react-relay';
import { RenameFolderModal } from '@/app/components/knowledge-base/rename-folder-modal';

function FolderActions({ folderRef }) {
  const [isRenameOpen, setIsRenameOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsRenameOpen(true)}>Rename</button>
      <RenameFolderModal
        folder={folderRef}
        isOpen={isRenameOpen}
        onClose={() => setIsRenameOpen(false)}
      />
    </>
  );
}
```

The parent component must spread a fragment reference compatible with `renameFolderModal_folder` into the `folder` prop (typically obtained from a parent query or list item that includes this fragment).
