# delete-folder-modal.tsx

A client-side React component that renders a confirmation modal for deleting a knowledge base folder, with an option to either move its contents to another folder or archive them.

## Key Components

- **`DeleteFolderModal`** — Main exported component rendering a `ConfirmDialog` with folder-deletion confirmation and a destination picker.
- **`deleteFolderModalFragment`** — GraphQL fragment retrieving `id`, `name`, and `parentId` from a `KnowledgeBaseItem`.
- **`deleteFolderModalMutation`** — GraphQL mutation (`deleteFolder`) that performs the actual delete operation, supporting `MOVE` or `ARCHIVE` behavior via `FolderChildrenAction`.
- **`DeleteFolderModalProps`** — Props interface: `folder` (Relay fragment key), `isOpen`, `onClose`, optional `listingIds` (listings displaying the folder that need updating), and optional `onDeleted` callback.
- **`ARCHIVE_LABEL`** — Constant label `"Don't Move and Archive"` used in the `FolderPicker`.

## Behavior Notes

- Uses Relay's `useMutation` to commit the delete, with a Relay store `updater` that removes the folder from all relevant listings/trees and invalidates either the target folder listing or the archive listing.
- Destination state (`destination`) resets when the modal transitions from open to closed, handled synchronously during render (not in an `useEffect`) to avoid a stale-value flash during the closing animation.
- On success, shows a success toast and calls `onDeleted` and `onClose`. On failure, shows a destructive toast using `getRelayErrorMessage`.

## Usage Example

```typescript
import { DeleteFolderModal } from '@/app/components/knowledge-base/delete-folder-modal';

function FolderActions({ folderRef, listingIds }) {
  const [isDeleteOpen, setDeleteOpen] = useState(false);

  return (
    <>
      <button onClick={() => setDeleteOpen(true)}>Delete Folder</button>
      <DeleteFolderModal
        folder={folderRef}
        isOpen={isDeleteOpen}
        onClose={() => setDeleteOpen(false)}
        listingIds={listingIds}
        onDeleted={() => router.push('/knowledge-base')}
      />
    </>
  );
}
```
