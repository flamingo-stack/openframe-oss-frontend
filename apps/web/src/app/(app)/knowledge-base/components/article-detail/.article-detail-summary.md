# article-detail-summary.tsx

A client-side React component that renders a summary card for a knowledge base article's detail view, displaying the author, last-updated date, and publication status. It integrates with Relay via GraphQL fragments and gracefully handles loading states and deleted author accounts.

## Key Components

- **`ArticleDetailSummary`** — The main exported component. Accepts an `article` Relay fragment reference (or `null`) and renders a summary card with author info, update timestamp, and status tag. Uses `LoadingWhen` to render skeleton placeholders when data is unavailable.
- **`SummaryCard`** — Internal layout component that arranges the three info cells in a responsive grid (2 columns below `lg`, 3 columns at `content-lg` and above), with a divider shown only in the narrower layout.
- **`AuthorCell`** — Internal component pairing an avatar with an `InfoCell` for the author's name.
- **`articleDetailSummaryFragment`** — GraphQL fragment (`articleDetailSummary_article`) declaring the fields required from `KnowledgeBaseItem`: `status`, `createdAt`, `updatedAt`, and nested `author` data (name, email, status, image).
- **`LABELS`** / **`CELL_CLASSES`** — Static copy and shared styling constants used across cells, including during loading states.

## Usage Example

```typescript
import { ArticleDetailSummary } from '@/app/components/articles/article-detail-summary';
import { useFragment } from 'react-relay';

function ArticlePage({ articleRef }: { articleRef: articleDetailSummary_article$key | null }) {
  return (
    <div>
      <ArticleDetailSummary article={articleRef} />
    </div>
  );
}
```

Pass `null` as `article` while the parent query is still resolving — the component will automatically render a loading skeleton (labels shown, values replaced with shimmering bars) until data resolves. Deleted authors are rendered with a distinct `DeletedUserAvatar` and error-styled name text.
