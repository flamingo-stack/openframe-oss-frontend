## article-detail-summary.tsx

A React client component that renders a summary card for a knowledge base article's detail view, displaying the author, last-updated timestamp, and publication status. It uses Relay fragments to fetch data and gracefully handles loading states and deleted author accounts.

## Key Components

- **`ArticleDetailSummary`** — Main exported component. Accepts an `article` prop (a Relay fragment reference or `null`) and renders a `SummaryCard` with author, updated date, and status cells. Wraps content in `LoadingWhen` so the card shows skeleton placeholders while data is unavailable.
- **`SummaryCard`** (internal) — Lays out three cells in a responsive grid (2 columns below `lg`, 3 columns at `content-lg` breakpoint) inside a bordered `Card`.
- **`AuthorCell`** (internal) — Combines an avatar and an `InfoCell` to display the author's name.
- **`articleDetailSummaryFragment`** — GraphQL fragment (`articleDetailSummary_article`) declared on `KnowledgeBaseItem`, fetching `status`, `createdAt`, `updatedAt`, and nested `author` fields (name, email, status, image).
- **`LABELS`** — Static label strings (`Author`, `Updated`, `Status`) reused for real labels and loading placeholders.

## Usage Example

```typescript
import { ArticleDetailSummary } from '@/app/components/article-detail/article-detail-summary';
import type { articleDetailSummary_article$key } from '@/__generated__/articleDetailSummary_article.graphql';

function ArticlePage({ articleRef }: { articleRef: articleDetailSummary_article$key | null }) {
  return (
    <div className="space-y-4">
      <ArticleDetailSummary article={articleRef} />
    </div>
  );
}
```

Pass `null` while the parent query is still resolving — the component automatically renders a skeleton-loading state via `LoadingWhen` until the fragment data is available. It also detects deleted author accounts via `isDeletedUserStatus` and renders a special `DeletedUserAvatar` with error-styled text instead of the normal avatar/name.
