# article-detail-body.tsx

Renders the body content of a knowledge base article as Markdown, using a GraphQL fragment to fetch and expose the raw content for rendering.

## Key Components

- **`ArticleDetailBody`** — React client component that accepts a Relay fragment reference (`article`) and renders the article's markdown content via `SimpleMarkdownRenderer`. Handles the loading state gracefully by passing an empty string when data hasn't resolved yet.
- **`articleDetailBodyFragment`** — GraphQL fragment (`articleDetailBody_article`) defined on `KnowledgeBaseItem`, fetching the `content` field.
- **`BODY_TEXT_SIZE`** — Constant controlling the rendered text size (`'compact'`).
- **`ARTICLE_BODY_SKELETON_LINES`** — Constant defining the number of skeleton loading lines to display per breakpoint (`phone`, `md`, `lg`) while content is unavailable.

## Usage Example

```typescript
import { ArticleDetailBody } from '@/app/components/articles/article-detail-body';
import { useLazyLoadQuery, graphql } from 'react-relay';

function ArticlePage() {
  const data = useLazyLoadQuery(
    graphql`
      query ArticlePageQuery($id: ID!) {
        knowledgeBaseItem(id: $id) {
          ...articleDetailBody_article
        }
      }
    `,
    { id: 'article-123' }
  );

  return <ArticleDetailBody article={data.knowledgeBaseItem} />;
}
```

The component is designed to be used within a Relay-powered tree where the parent query spreads the `articleDetailBody_article` fragment onto a `KnowledgeBaseItem` node. Passing `null` for `article` (e.g., during Suspense fallback) triggers the skeleton loading state automatically via `SimpleMarkdownRenderer`.
