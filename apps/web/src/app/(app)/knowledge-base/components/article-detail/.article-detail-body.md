Renders the body content of a knowledge base article as markdown, using a GraphQL fragment to fetch the content and displaying a skeleton loading state while data is unavailable.

## Key Components

- **`ArticleDetailBody`** — React component that accepts an `article` Relay fragment reference and renders its `content` field as markdown via `SimpleMarkdownRenderer`.
- **`articleDetailBodyFragment`** — GraphQL fragment (`articleDetailBody_article`) defined on `KnowledgeBaseItem`, selecting the `content` field.
- **`BODY_TEXT_SIZE`** — Constant controlling the rendered text size (`'compact'`).
- **`ARTICLE_BODY_SKELETON_LINES`** — Constant defining the number of skeleton loading lines to show at each responsive breakpoint (`phone`, `md`, `lg`) before content arrives.

## Usage Example

```typescript
import { ArticleDetailBody } from '@/app/components/articles/article-detail-body';
import type { articleDetailBody_article$key } from '@/__generated__/articleDetailBody_article.graphql';

function ArticlePage({ articleRef }: { articleRef: articleDetailBody_article$key | null }) {
  return (
    <div className="article-container">
      <ArticleDetailBody article={articleRef} />
    </div>
  );
}
```

The component is designed to be used within a parent component that queries a `KnowledgeBaseItem` via Relay and spreads the fragment reference into `ArticleDetailBody`. When `article` is `null` (e.g., during initial load or a Suspense boundary), `useFragment` returns `null`, and the renderer falls back to an empty string while still showing its configured skeleton placeholder, ensuring a consistent loading experience across screen sizes.
