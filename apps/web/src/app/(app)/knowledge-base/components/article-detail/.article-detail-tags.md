# article-detail-tags.tsx

A client-side React component that renders the tag list for a knowledge base article, displaying a skeleton loading state while data is unavailable and gracefully rendering nothing for untagged articles.

## Key Components

- **`articleDetailTagsFragment`** — GraphQL fragment (via `react-relay`) declared on `KnowledgeBaseItem`, fetching each tag's `id` and `key`.
- **`ARTICLE_TAGS_SKELETON_COUNT`** — Constant (`3`) defining how many skeleton chips render during loading, approximating a typical article's tag count.
- **`ROW_CLASS`** — Shared Tailwind class string for the flex-wrapping tag row layout.
- **`ArticleDetailTags`** — The exported component. Accepts an `article` prop (a Relay fragment reference or `null`) and:
  - Resolves fragment data via `useFragment`.
  - Renders `ARTICLE_TAGS_SKELETON_COUNT` loading `Tag` placeholders when in a loading scope (`useLoadingScope()`) or when data isn't yet available.
  - Returns `null` if the resolved article has zero tags.
  - Otherwise renders each tag as an outlined `Tag` chip.

## Usage Example

```typescript
import { ArticleDetailTags } from '@/components/article-detail-tags';
import { useFragment } from 'react-relay';

function ArticleDetailHeader({ article }: { article: articleDetail_article$key }) {
  return (
    <div>
      <h1>Article Title</h1>
      <ArticleDetailTags article={article} />
    </div>
  );
}
```

The parent component must spread/pass down the Relay fragment reference (`articleDetailTags_article$key`) obtained from its own GraphQL query or fragment, typically via fragment composition:

```typescript
graphql`
  fragment articleDetail_article on KnowledgeBaseItem {
    title
    ...articleDetailTags_article
  }
`;
```
