# article-detail-tags.tsx

A React client component that renders a knowledge base article's tags as a row of chips beneath its title, handling loading and empty states gracefully via GraphQL fragments.

## Key Components

- **`ArticleDetailTags`** — Main exported component that accepts an `article` fragment reference and renders either a skeleton loading row, nothing (if untagged), or a row of `Tag` chips.
- **`articleDetailTagsFragment`** — Relay GraphQL fragment (`articleDetailTags_article`) defined on `KnowledgeBaseItem`, fetching `tags { id, key }`.
- **`ARTICLE_TAGS_SKELETON_COUNT`** — Constant (`3`) controlling how many skeleton chips render while loading, approximating a typical article's tag count.
- **`ROW_CLASS`** — Shared Tailwind class string (`flex flex-wrap gap-...`) applied to the tag row container in both loading and loaded states.

## Usage Example

```typescript
import { ArticleDetailTags } from './article-detail-tags';
import { useFragment } from 'react-relay';

function ArticleDetailPage({ articleRef }: { articleRef: articleDetailTags_article$key | null }) {
  return (
    <div>
      <h1>Article Title</h1>
      <ArticleDetailTags article={articleRef} />
    </div>
  );
}
```

The component relies on `useLoadingScope()` (from `@flamingo-stack/openframe-frontend-core/components/ui`) to detect ambient loading state. When loading or when `article` is `null`, it renders `ARTICLE_TAGS_SKELETON_COUNT` skeleton `Tag` placeholders via `LoadingItems`. Once data resolves, it either renders nothing (empty `tags` array) or an `outline`-variant `Tag` per tag, keyed by `tag.id` and labeled with `tag.key`.
