Renders the full detail page for a single knowledge base article, handling both the Suspense loading state and the fully-loaded state with title, tags, summary, body, attachments, and assigned items.

## Key Components

- **`ArticleDetail`** — Top-level component that accepts a `articleDetail_article$key | null` Relay fragment reference. If inside a `useLoadingScope()` or the reference is `null`, it renders skeleton/loading placeholders for the title, tags, summary, body, and assigned-items view (without attachments, since those depend on data that hasn't loaded).
- **`LoadedArticleDetail`** — Internal component that resolves the Relay fragment via `useFragment` and renders the fully populated article page: title with actions/menu actions, tags, summary, body, attachments, and the assigned items view, plus any action dialogs.
- **`articleDetailFragment`** — GraphQL fragment on `KnowledgeBaseItem` composing child fragments from the tags, summary, body, and attachments sub-components, plus `useArticleDetailActions_article`.
- **`LOADING_ACTIONS`** — Static array containing a disabled/inert `editArticleAction()` shown while loading.
- **`BODY_CLASS`** — Shared Tailwind class string for the article body layout container.

## Usage Example

```typescript
import { ArticleDetail } from './article-detail';
import type { articleDetail_article$key } from '@/__generated__/articleDetail_article.graphql';

function ArticlePage({ article }: { article: articleDetail_article$key | null }) {
  return (
    <div className="flex flex-col gap-4">
      <ArticleDetail article={article} />
    </div>
  );
}
```

This component is typically rendered inside a `Suspense` boundary paired with a `LoadingScope` provider, allowing `ArticleDetail` to automatically detect the loading phase via `useLoadingScope()` and render placeholder UI before the Relay query resolves.
