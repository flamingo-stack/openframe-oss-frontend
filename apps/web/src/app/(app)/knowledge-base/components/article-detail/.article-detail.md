# article-detail.tsx

Renders a knowledge base article's detail page, composing its title, tags, summary, body, attachments, and assigned items, while handling both loading (Suspense) and loaded states via a Relay GraphQL fragment.

## Key Components

- **`ArticleDetail`** — Top-level exported component. Accepts an `article` Relay fragment reference (or `null`). If inside a loading scope or the reference is missing, it renders a skeleton layout with placeholder sub-components (title, tags, summary, body, and an empty `AssignedItemsView`). Otherwise it delegates to `LoadedArticleDetail`.
- **`LoadedArticleDetail`** — Internal component that resolves the Relay fragment via `useFragment`, derives page actions/menu actions/dialogs from `useArticleDetailActions`, and renders the fully populated article layout, including `ArticleDetailAttachments` and the real `AssignedItemsView` tied to the article's `id`.
- **`articleDetailFragment`** — GraphQL fragment on `KnowledgeBaseItem` spreading child fragments used by title actions, tags, summary, body, and attachments sub-components.
- **`LOADING_ACTIONS`** — Static array providing an inert "edit" page action shown while the article is loading.
- **`BODY_CLASS`** — Shared Tailwind class string for the article body's flex layout.

## Usage Example

```typescript
import { ArticleDetail } from './article-detail';
import type { articleDetail_article$key } from '@/__generated__/articleDetail_article.graphql';

function ArticlePage({ article }: { article: articleDetail_article$key | null }) {
  return <ArticleDetail article={article} />;
}
```

This component is typically rendered as a React Suspense boundary's resolved child, where `article` is `null` during the initial fetch (triggering the loading skeleton) and becomes a valid Relay fragment key once the GraphQL query resolves.
