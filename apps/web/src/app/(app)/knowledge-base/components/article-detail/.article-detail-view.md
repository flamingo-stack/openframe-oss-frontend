Client-side view component that renders a single knowledge base article detail page, delegating data fetching and rendering to an inner content component.

## Key Components

- **`ArticleDetailView`** — A client component (`'use client'`) that accepts an `articleId` prop and renders the `ArticleDetailContent` component inside a full-width flex column wrapper.

## Design Notes

This component intentionally avoids wrapping content in `PageLayout`. Since the page title is derived from the article record itself (not known ahead of time), only the inner `ArticleDetailContent` island suspends/waits on data loading, following the same pattern used by the canonical `software-detail-view` component. This allows the outer shell to render immediately while the article content loads independently.

## Usage Example

```typescript
import { ArticleDetailView } from './article-detail-view';

export default function Page({ params }: { params: { articleId: string } }) {
  return <ArticleDetailView articleId={params.articleId} />;
}
```
