# article-detail-view.tsx

Top-level client view component for the `/knowledge-base/details` route, rendering a single knowledge base article by ID.

This component intentionally skips the shared `PageLayout` wrapper. Since the article's title is itself part of the fetched record (not static page chrome), only the inner content island (`ArticleDetailContent`) suspends while loading data — mirroring the pattern established by `software-detail-view`.

## Key Components

- **`ArticleDetailView`** — Client component (`'use client'`) that accepts an `articleId` prop and renders a full-width flex column container wrapping `ArticleDetailContent`. Acts as the route-level entry point for article detail pages, deferring all data-fetching and rendering logic to the child component.

## Usage Example

```typescript
import { ArticleDetailView } from './article-detail-view';

// Typical usage in a Next.js dynamic route, e.g. app/knowledge-base/details/[articleId]/page.tsx
export default function Page({ params }: { params: { articleId: string } }) {
  return <ArticleDetailView articleId={params.articleId} />;
}
```

## Notes

- No `PageLayout` is used here by design — avoids blocking the whole page shell while the article title/content streams in.
- All data-fetching, loading, and error states are delegated to `ArticleDetailContent`.
