# article-detail-attachments.tsx

Renders the list of downloadable file attachments for a knowledge base article, using a GraphQL fragment to fetch attachment metadata and a shared `TicketAttachmentsList` UI component for display.

## Key Components

- **`articleDetailAttachmentsFragment`** — GraphQL fragment declared on the `KnowledgeBaseItem` type, fetching `attachments` (`id`, `fileName`, `fileSize`) for the article.
- **`ArticleDetailAttachments`** — Client component (`'use client'`) that:
  - Resolves the fragment via `useFragment` using the passed `article` fragment reference.
  - Returns `null` when the article has no attachments (no section is rendered).
  - Wraps the list in a `TicketDetailSection` labeled "Attachments".
  - Uses `useDownloadArticleAttachment` to provide a `download` handler per attachment.
  - Formats file sizes with `formatFileSize` before display.
  - Marks its root `div` with `data-loading-optional`, signaling that this section is optional content for the page's loading/height gate.

## Usage Example

```typescript
import { ArticleDetailAttachments } from './article-detail-attachments';
import { graphql, useLazyLoadQuery } from 'react-relay';

function ArticlePage({ articleId }: { articleId: string }) {
  const data = useLazyLoadQuery(
    graphql`
      query ArticlePageQuery($id: ID!) {
        knowledgeBaseItem(id: $id) {
          ...articleDetailAttachments_article
        }
      }
    `,
    { id: articleId }
  );

  return (
    <div>
      {/* other article detail sections */}
      <ArticleDetailAttachments article={data.knowledgeBaseItem} />
    </div>
  );
}
```

The parent query must spread `...articleDetailAttachments_article` on a `KnowledgeBaseItem` to supply the required fragment data.
