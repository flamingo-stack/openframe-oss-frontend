Renders the list of downloadable attachments for a knowledge base article, using a GraphQL fragment to fetch attachment metadata and rendering nothing if the article has no attachments.

## Key Components

- **`articleDetailAttachmentsFragment`** — GraphQL fragment on `KnowledgeBaseItem` that selects `attachments` (`id`, `fileName`, `fileSize`).
- **`ArticleDetailAttachments`** — Client component that:
  - Resolves the fragment data via `useFragment`.
  - Returns `null` early if there are no attachments (so the section doesn't render at all).
  - Wraps output in a `data-loading-optional` div, signaling to the page's loading/height gate that this section is optional content.
  - Renders a `TicketDetailSection` labeled "Attachments" containing a `TicketAttachmentsList`.
  - Formats file sizes via `formatFileSize` and wires up per-attachment downloads via `useDownloadArticleAttachment`.

## Usage Example

```typescript
import { ArticleDetailAttachments } from './article-detail-attachments';
import { useFragment } from 'react-relay';

function ArticleDetailPage({ articleRef }: { articleRef: any }) {
  return (
    <div>
      {/* other article detail sections */}
      <ArticleDetailAttachments article={articleRef} />
    </div>
  );
}
```

The `article` prop must be a Relay fragment reference (`articleDetailAttachments_article$key`) obtained from a parent query that spreads the `articleDetailAttachments_article` fragment on a `KnowledgeBaseItem`. The component handles its own data fetching via `useFragment` and automatically hides itself when the article has no attachments.
