This file defines a React hook that builds the status-dependent action buttons, overflow menu items, and dialogs for a knowledge base article's detail page, driven by a Relay GraphQL fragment.

## Key Components

- **`editArticleAction(href?)`** — Helper that returns a standardized "Edit Article" `PageActionButton`, reused by loading states and the hook itself.
- **`useArticleDetailActions(article)`** — Main hook that:
  - Reads article data via the `useArticleDetailActions_article` Relay fragment.
  - Exposes `commitPublish`/`commitUnpublish` mutations (`publishArticle`, `unpublishArticle`) with toast notifications on success/error.
  - Manages local dialog state (`archive`, `move`, `unarchive`) for rendering modals.
  - Returns `{ actions, menuActions, dialogs }` tailored to the article's status:
    - **Archived**: only an "Unarchive" action.
    - **Draft**: "Edit Article" + "Publish Article" primary actions, plus "Archive"/"Move to Folder" menu items.
    - **Published**: "Edit Article" primary action, plus "Archive"/"Move to Folder"/"Move to Draft" menu items.
- **`ArticleDetailActions`** — Return type interface (`actions`, `menuActions`, `dialogs`).
- **`ArticleDialog`** — Union type for which modal is currently open.

## Usage Example

```typescript
import { useArticleDetailActions } from './use-article-detail-actions';

function ArticleDetailHeader({ articleRef }: { articleRef: useArticleDetailActions_article$key }) {
  const { actions, menuActions, dialogs } = useArticleDetailActions(articleRef);

  return (
    <>
      <PageHeader actions={actions} menuActions={menuActions} />
      {dialogs}
    </>
  );
}
```

The hook must be used within a Relay environment where the parent query spreads the `useArticleDetailActions_article` fragment on a `KnowledgeBaseItem`.
