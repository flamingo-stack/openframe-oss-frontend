# useArticleDetailActions

A React hook that computes the status-driven action buttons, overflow menu items, and modal dialogs for the knowledge base article detail page. It uses Relay fragments and mutations to drive publish/unpublish operations and coordinates the archive, move, and unarchive dialogs.

## Key Components

- **`editArticleAction(href?)`** — Builds a reusable "Edit Article" `PageActionButton`, also used by loading/inert states of the page header.
- **`useArticleDetailActions(article)`** — Main hook that:
  - Reads article fields (`id`, `name`, `status`) via the `useArticleDetailActions_article` Relay fragment.
  - Commits `publishArticle` / `unpublishArticle` mutations, surfacing success/error via `useToast`.
  - Manages which modal dialog (`archive`, `move`, `unarchive`) is currently open.
  - Returns status-specific `actions` (primary buttons), `menuActions` (overflow menu groups), and `dialogs` (rendered modal components).
- **`ArticleDetailActions`** — Return type interface: `{ actions, menuActions, dialogs }`.
- **`ArticleDialog`** — Union type `'archive' | 'move' | 'unarchive'` tracking open dialog state.

## Behavior by Status

- **Archived**: only an "Unarchive" action is available; no menu items.
- **Draft**: Edit + Publish actions; menu offers Archive and Move to Folder.
- **Published**: Edit action; menu offers Archive, Move to Folder, and Move to Draft (unpublish).
- **Live (non-draft/published)**: Edit action plus Archive/Move to Folder menu items.

## Usage Example

```typescript
import { useArticleDetailActions } from './use-article-detail-actions';

function ArticleDetailPage({ articleRef }: { articleRef: useArticleDetailActions_article$key }) {
  const { actions, menuActions, dialogs } = useArticleDetailActions(articleRef);

  return (
    <>
      <PageHeader actions={actions} menuActions={menuActions} />
      {dialogs}
    </>
  );
}
```

Pass the article's Relay fragment reference directly; the hook internally resolves the fragment data, derives the normalized status via `toArticleStatus`, and wires up mutation handlers and dialog state without further configuration.
