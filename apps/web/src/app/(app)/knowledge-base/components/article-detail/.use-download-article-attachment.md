A React hook that fetches a signed download URL for a knowledge base article attachment via GraphQL and triggers a browser file download.

## Key Components

- **`downloadArticleAttachmentQuery`** — Relay GraphQL query that resolves `knowledgeBaseAttachmentDownloadUrl` for a given `attachmentId`.
- **`useDownloadArticleAttachment`** — Hook returning a `download` callback that:
  1. Fetches the signed URL using `fetchQuery` with `network-only` policy.
  2. Retrieves the file as a `Blob` via `fetch`.
  3. Creates an object URL and programmatically clicks a temporary `<a>` element to trigger the browser download.
  4. Revokes the object URL after download.
  5. Shows a destructive toast notification on any failure.

## Usage Example

```typescript
import { useDownloadArticleAttachment } from './use-download-article-attachment';

function AttachmentItem({ id, name }: { id: string; name: string }) {
  const { download } = useDownloadArticleAttachment();

  return (
    <button onClick={() => download(id, name)}>
      Download {name}
    </button>
  );
}
```

## Error Handling

Errors are surfaced via toast rather than thrown, covering two failure modes:
- GraphQL query returns no URL (`'No download URL returned'`)
- File fetch responds with a non-OK status (`'Failed to fetch file'`)

## Notes

- Uses `fetchPolicy: 'network-only'` to ensure a fresh signed URL on every call, avoiding stale cached URLs.
- Cleans up the temporary DOM element and object URL immediately after the download is initiated.
