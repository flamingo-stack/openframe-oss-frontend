# use-download-article-attachment.ts

A React hook that provides functionality to download knowledge base article attachments by fetching a download URL via a Relay GraphQL query and triggering the file download.

## Key Components

- **`downloadArticleAttachmentQuery`** — GraphQL query that retrieves a downloadable URL (`knowledgeBaseAttachmentDownloadUrl`) for a given attachment ID.
- **`useDownloadArticleAttachment()`** — Custom hook that exposes a `download` function for fetching and downloading an attachment by ID.
  - Uses `useRelayEnvironment` to access the current Relay environment.
  - Uses `useFileDownload` (from `@/lib/use-file-download`) to handle the actual browser download logic.
  - Executes the GraphQL query with `network-only` fetch policy to always retrieve a fresh download URL (avoiding stale cached links).

## Usage Example

```typescript
import { useDownloadArticleAttachment } from '@/hooks/use-download-article-attachment';

function AttachmentLink({ attachmentId, fileName }: { attachmentId: string; fileName: string }) {
  const { download } = useDownloadArticleAttachment();

  return (
    <button onClick={() => download(attachmentId, fileName)}>
      Download {fileName}
    </button>
  );
}
```

The `download` function is memoized via `useCallback` and depends on the Relay `environment` and the `downloadFile` utility, ensuring a stable reference across re-renders. It returns a promise chain that resolves the download URL from the GraphQL response and delegates the file-saving behavior to `useFileDownload`.
