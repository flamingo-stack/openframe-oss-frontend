A React hook that fetches a signed download URL for a knowledge base article attachment via GraphQL and triggers the file download in the browser.

## Key Components

- **`downloadArticleAttachmentQuery`** — GraphQL query that resolves `knowledgeBaseAttachmentDownloadUrl` for a given `attachmentId`.
- **`useDownloadArticleAttachment()`** — Hook that returns a `download` function for initiating attachment downloads.
  - Uses `useRelayEnvironment` to access the current Relay environment.
  - Uses `useFileDownload` (from `@/lib/use-file-download`) to handle the actual browser download flow.
  - Executes the query with `fetchPolicy: 'network-only'` to always fetch a fresh download URL (avoiding stale/expired cached URLs).

## Usage Example

```typescript
'use client';

import { useDownloadArticleAttachment } from '@/hooks/use-download-article-attachment';

function AttachmentButton({ attachmentId, fileName }: { attachmentId: string; fileName: string }) {
  const { download } = useDownloadArticleAttachment();

  return (
    <button onClick={() => download(attachmentId, fileName)}>
      Download {fileName}
    </button>
  );
}
```

The `download` function accepts the attachment's `attachmentId` and the desired `fileName`, fetches a fresh download URL from the server, and delegates the actual file-saving behavior to `useFileDownload`. If the query returns no URL, the download silently resolves without a file being saved (handled internally by `useFileDownload`).
