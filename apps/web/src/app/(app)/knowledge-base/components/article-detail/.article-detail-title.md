A client-side React component that renders the title block for an individual article/knowledge base detail page, including a back button, loading states, and configurable action buttons/menus.

## Key Components

- **`ArticleDetailTitle`** — The main exported component. Renders a `TitleBlock` with the article's title, a "Back" navigation button (routed to the knowledge base list), and optional action buttons or menu actions.
- **`ArticleDetailTitleProps`** — Props interface defining:
  - `title: string` — the article's name, displayed as the page title.
  - `loading?: boolean` — shows a skeleton bar in place of the title while the article data loads.
  - `actions?: PageActionButton[]` — primary action buttons shown alongside the title.
  - `loadingActions?: boolean` — shows placeholder skeletons for actions while they are being resolved (e.g., actions depend on article status not yet loaded).
  - `menuActions?: ActionsMenuGroup[]` — grouped actions rendered in a dropdown menu.

## Usage Example

```typescript
import { ArticleDetailTitle } from '@/components/article-detail-title';

function ArticlePage() {
  const { data: article, isLoading } = useArticle();

  return (
    <ArticleDetailTitle
      title={article?.name ?? ''}
      loading={isLoading}
      loadingActions={!article}
      actions={[
        { label: 'Edit', onClick: () => console.log('edit') },
      ]}
      menuActions={[
        {
          label: 'More',
          items: [
            { label: 'Delete', onClick: () => console.log('delete') },
          ],
        },
      ]}
    />
  );
}
```

Internally, the component uses `useSafeBack` to navigate back to `routes.knowledgeBase.list`, ensuring consistent back-navigation behavior across the knowledge base article detail pages.
