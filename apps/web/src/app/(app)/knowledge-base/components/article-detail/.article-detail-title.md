# article-detail-title.tsx

A client-side React component that renders the title block for an article detail page in the Knowledge Base, including a back navigation button, loading states, and configurable action buttons/menus.

## Key Components

- **`ArticleDetailTitle`** — Functional component that wraps `TitleBlock` from `@flamingo-stack/openframe-frontend-core`, providing a standardized header for article detail views.
- **`ArticleDetailTitleProps`** — Props interface defining:
  - `title` (`string`) — the article's display name.
  - `loading` (`boolean`, optional) — shows a placeholder bar while the title is loading.
  - `actions` (`PageActionButton[]`, optional) — primary action buttons shown via a menu.
  - `loadingActions` (`boolean`, optional) — shows placeholder actions while they're being determined.
  - `menuActions` (`ActionsMenuGroup[]`, optional) — grouped secondary actions rendered in a dropdown menu.

The component uses `useSafeBack` (from `@/app/hooks/use-safe-back`) to navigate back to the Knowledge Base list route (`routes.knowledgeBase.list`), falling back safely if no browser history is available.

## Usage Example

```typescript
import { ArticleDetailTitle } from './article-detail-title';

function ArticlePage({ article, isLoading }: { article?: Article; isLoading: boolean }) {
  return (
    <ArticleDetailTitle
      title={article?.name ?? ''}
      loading={isLoading}
      loadingActions={!article}
      actions={[
        { label: 'Edit', onClick: () => console.log('edit') },
      ]}
      menuActions={[
        {
          items: [
            { label: 'Duplicate', onClick: () => console.log('duplicate') },
            { label: 'Delete', onClick: () => console.log('delete'), destructive: true },
          ],
        },
      ]}
    />
  );
}
```

This component is typically used at the top of an article detail page to provide consistent navigation and action controls across the Knowledge Base feature.
