# assign-article-modal.tsx

A modal component that assigns one or more knowledge base articles to a customer or device target. It provides a searchable multi-select autocomplete and submits individual GraphQL mutations per selected article, aggregating success/failure feedback via toast notifications.

## Key Components

- **`AssignArticleModal`** — Main exported React component. Renders a `SimpleModal` containing an article search/select `Autocomplete` field and Cancel/Assign footer actions.
- **`assignArticleModalMutation`** — GraphQL mutation (`assignItem`) used to assign a single article to a target. Called once per selected article since no batch mutation exists.
- **`ArticleOption`** — Local interface describing an autocomplete option (`value`, `label`).
- **`AssignArticleModalProps`** — Props interface: `target` (customer/device assignment target), `isOpen`, `onClose`, and `onAssigned` (callback fired when at least one article is successfully assigned, prompting the parent to refetch assigned list/tags).

### Behavior Notes

- Uses `useAssignmentSearch` to fetch article options filtered by `searchInput`, scoped to `AssignmentTargetType.KNOWLEDGE_ARTICLE`.
- Merges live search `options` with already-`selected` items so picked chips retain labels even after being filtered out of the search results.
- Resets `selected` and `searchInput` state during render (not in a `useEffect`) when the modal transitions from open to closed, avoiding a stale-selection flash during the close animation.
- Submits all selected articles concurrently via `Promise.allSettled`, then reports partial or full success/failure through `useToast`.

## Usage Example

```typescript
import { AssignArticleModal } from './assign-article-modal';
import { useState } from 'react';
import { AssignmentTargetType } from '@/generated/schema-enums';

function CustomerArticlesTab({ customerId }: { customerId: string }) {
  const [isModalOpen, setIsModalOpen] = useState(false);

  const target = {
    targetType: AssignmentTargetType.CUSTOMER,
    targetId: customerId,
  };

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>Assign Article</button>
      <AssignArticleModal
        target={target}
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        onAssigned={() => {
          // Refetch assigned articles list/tags for this customer
        }}
      />
    </>
  );
}
```
