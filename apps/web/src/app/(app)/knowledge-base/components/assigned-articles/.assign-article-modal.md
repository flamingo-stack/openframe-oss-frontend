# AssignArticleModal

A modal component that assigns one or more knowledge base articles to a customer or device target, using multi-select search and per-article GraphQL mutations submitted in parallel.

## Key Components

- **`AssignArticleModal`** — Default-exported React component rendering a `SimpleModal` with an `Autocomplete` field for selecting knowledge base articles, plus Cancel/Assign actions.
- **`assignArticleModalMutation`** — Relay GraphQL mutation that calls `assignItem` with `itemId`, `itemType`, `targetType`, and `targetId`.
- **`ArticleOption`** — Local type describing an autocomplete option (`value`/`label` pair).
- **`AssignArticleModalProps`** — Props interface: `target` (an `AssignedArticlesTarget`), `isOpen`, `onClose`, and `onAssigned` (callback fired after at least one successful assignment).

## Behavior Notes

- Uses `useAssignmentSearch` to query `KNOWLEDGE_ARTICLE` targets as the user types, merging previously selected options back in so chips retain labels even after a new search filters them out.
- Resets selection and search input synchronously during render (not via `useEffect`) when the modal transitions from open to closed, avoiding a stale-selection flash during the closing animation.
- Since there's no batch assignment mutation, it fires one `assignItem` mutation per selected article via `Promise.allSettled`, then reports success/partial-failure/failure via `useToast`.
- Calls `onAssigned()` whenever at least one article succeeds, even amid partial failures.

## Usage Example

import { useState } from 'react';
import { AssignArticleModal } from './assign-article-modal';
import type { AssignedArticlesTarget } from './assigned-articles-target';

function CustomerArticlesPanel({ target }: { target: AssignedArticlesTarget }) {
  const [isModalOpen, setIsModalOpen] = useState(false);

  const refreshArticleList = () => {
    // refetch assigned articles/tags for the tab
  };

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>Assign Article</button>
      <AssignArticleModal
        target={target}
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        onAssigned={refreshArticleList}
      />
    </>
  );
}
