# assigned-articles-tab.tsx

A React component that renders the "Assigned Articles" tab for a customer or device, displaying knowledge base articles assigned to that target with search, tag filtering, and assign/unassign capabilities.

## Key Components

- **`AssignedArticlesTab`** — Main exported component rendering the tab UI: a header with an "Assign Article" action, a sticky search/filter toolbar, the articles table, and the supporting modals (assign article, tag filter).
- **`AssignedArticlesTabProps`** — Props interface; accepts `target: AssignedArticlesTarget | null`, where `null` indicates the page hasn't resolved the target yet (renders in a loading scope).

### Internal Behavior
- **Tab-local state**: `search` and `selectedTags`/`tagIds` are kept local to the tab (not synced to URL), since the page's query string is shared across sibling tabs.
- **Debounced + deferred search**: Uses `useDebounce` (300ms) and `useDeferredQuery` to avoid thrashing the table query while typing or toggling tags.
- **Refresh coordination**: `refreshKey` is bumped on assign/unassign (`handleChanged`), re-triggering the table and tags filter modal, and invalidates the `ASSIGNED_ITEMS_QUERY_KEY` react-query cache so other parts of the app (e.g., the article page's assignee list) stay in sync.
- **Empty state handling**: When the list is empty (`isEmpty`), the search/filter toolbar is hidden entirely.
- **Sticky toolbar**: Uses `useStickyToolbar` to compute `containerStyle` and `stickyHeaderOffset` for the sticky search bar positioning.
- **Modal placement**: Modals (`AssignArticleModal`, `KnowledgeBaseTagsFilterModal`) are rendered outside the sticky toolbar's stacking context to avoid z-index conflicts, and only mounted once `target` is resolved.

## Usage Example

```typescript
import { AssignedArticlesTab } from './assigned-articles-tab';
import type { AssignedArticlesTarget } from './assigned-articles-target';

function CustomerDetailPage({ customerId }: { customerId: string }) {
  const target: AssignedArticlesTarget | null = {
    type: 'customer',
    id: customerId,
  };

  return (
    <div>
      {/* Other tabs... */}
      <AssignedArticlesTab target={target} />
    </div>
  );
}

// While the target is still being resolved:
<AssignedArticlesTab target={null} />
```
