## assigned-articles-table.tsx

Renders the "Assigned Articles" tab for a knowledge base target (a customer or device), showing paginated knowledge base articles assigned to that target with infinite scroll, unassign action, and empty/loading states driven by Relay.

## Key Components

- **`AssignedArticlesTable`** — Public entry point; wraps the reader in a `LoadingSuspense` boundary so the table can suspend while fetching.
- **`AssignedArticlesTableReader`** — Decides whether to render a loading placeholder (when in a loading scope or `target` is `null`) or to run the live query via `AssignedArticlesTableQuery`.
- **`AssignedArticlesTableQuery`** — Executes `assignedArticlesTableQuery`/fragment via `useLazyLoadQuery` and `usePaginationFragment`, wires up the `unassignItem` mutation with optimistic connection updates, and feeds rows to `AssignedArticlesRows`.
- **`AssignedArticlesRows`** — Presentational layer building the `useDataTable` instance, columns (name, created date, actions menu, open-in-new-tab), and empty-state logic.
- **`AssignedArticlesListing`** (interface) — Shape of search/tag filter state passed in from the parent tab.
- **`buildColumns`** — Constructs `ColumnDef` array including an `ActionsMenuDropdown` with an "Unassign" action.
- GraphQL definitions: `assignedArticlesTableQuery`, `assignedArticlesTableFragment` (paginated, `@connection`-based), `assignedArticlesTableUnassignMutation`.

## Usage Example

```typescript
import { AssignedArticlesTable } from './assigned-articles-table';

function CustomerArticlesTab({ customerId }: { customerId: string }) {
  const [refreshKey, setRefreshKey] = useState(0);
  const [isPending, setIsPending] = useState(false);

  return (
    <AssignedArticlesTable
      target={{ targetType: 'CUSTOMER', targetId: customerId }}
      listing={{ search: '', tagIds: [] }}
      isPending={isPending}
      refreshKey={refreshKey}
      onChanged={() => setRefreshKey(k => k + 1)}
      onEmptyChange={(isEmpty) => console.log('tab empty:', isEmpty)}
      stickyHeaderOffset="4rem"
    />
  );
}
```

Unassigning a row removes it optimistically from the Relay connection (updating `filteredCount`), shows a success/error toast, and triggers `onChanged` to refresh dependent tab state (e.g., tag counts).
