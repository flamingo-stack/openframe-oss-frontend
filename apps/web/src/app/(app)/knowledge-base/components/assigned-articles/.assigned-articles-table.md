## assigned-articles-table.tsx

Renders the "Assigned Articles" tab content for a knowledge base target (customer or device): a paginated, searchable/filterable Relay-backed data table of assigned articles with inline unassign support and infinite scroll.

## Key Components

- **`assignedArticlesTableQuery` / `assignedArticlesTableFragment` / `assignedArticlesTableUnassignMutation`** — GraphQL operations: root query, refetchable pagination fragment on `knowledgeBaseItems` (filtered by `assignedTo` target and tags/search), and the mutation to unassign an item from a target.
- **`AssignedArticlesTable`** — Public entry point; wraps the reader in `LoadingSuspense` so the tab can suspend while loading.
- **`AssignedArticlesTableReader`** — Decides whether to render a loading placeholder (when `target` is `null` or inside a loading scope) or to run the live query via `AssignedArticlesTableQuery`.
- **`AssignedArticlesTableQuery`** — Executes `useLazyLoadQuery` + `usePaginationFragment`, wires up the unassign mutation (with optimistic connection update via `ConnectionHandler.deleteNode`), and sets up infinite scroll via `useKnowledgeBaseLoadMore`.
- **`AssignedArticlesRows`** — Builds the actual `useDataTable` instance from rows/placeholder rows, handles empty-state detection, and notifies the parent tab via `onEmptyChange`.
- **`buildColumns`** — Constructs column definitions: name, created date, actions (unassign dropdown), and open-in-new-tab.
- **`AssignedArticlesListing`** / **`AssignedArticlesTableProps`** — Exported prop/type contracts for search, tag filtering, pending state, refresh key, and callbacks.

## Usage Example

```typescript
import { AssignedArticlesTable } from './assigned-articles-table';
import type { AssignedArticlesTarget } from './assigned-articles-target';

function AssignedArticlesTab({ target }: { target: AssignedArticlesTarget | null }) {
  const [refreshKey, setRefreshKey] = useState(0);
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <AssignedArticlesTable
      target={target}
      listing={{ search: '', tagIds: [] }}
      isPending={false}
      refreshKey={refreshKey}
      onChanged={() => setRefreshKey(k => k + 1)}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="var(--header-height)"
    />
  );
}
```

Rows are unassigned via an `ActionsMenuDropdown` action that optimistically removes the row from the Relay connection and triggers `onChanged` to refresh dependent tag/list state, with toast feedback on success or failure.
