Defines the `AssignedArticlesTarget` type and helper functions for representing the customer or device that knowledge base articles are assigned to, used across GraphQL filtering and assignment operations.

## Key Components

- **`AssignedArticlesTarget`** — Interface representing an assignment target, with a `targetType` (`ORGANIZATION` or `DEVICE` from `AssignmentTargetType`) and a `targetId` (a Relay global id).
- **`customerArticlesTarget(organizationId)`** — Builds an `AssignedArticlesTarget` for a customer/organization, encoding the given `organizationId` as a global id for the `Organization` type.
- **`deviceArticlesTarget(machineId)`** — Builds an `AssignedArticlesTarget` for a device, encoding the given `machineId` as a global id for the `Machine` type.
- **`targetNoun(target)`** — Returns a human-readable noun (`"customer"` or `"device"`) for use in UI copy, such as empty states.

## Usage Example

```typescript
import { customerArticlesTarget, deviceArticlesTarget, targetNoun } from '@/lib/assigned-articles-target';

// Build a target for filtering articles assigned to an organization
const orgTarget = customerArticlesTarget('org_123');
// orgTarget.targetType === AssignmentTargetType.ORGANIZATION
// orgTarget.targetId === toGlobalId('Organization', 'org_123')

// Build a target for filtering articles assigned to a device
const deviceTarget = deviceArticlesTarget('machine_456');

// Use in a GraphQL query filter
const filter = { assignedTo: orgTarget };

// Display a human-friendly label in an empty state
const emptyStateMessage = `No articles assigned to this ${targetNoun(deviceTarget)}.`;
```

This type is typically consumed by components or hooks that query `knowledgeBaseItems` or `knowledgeBaseTags` filtered by assignment, or that call `assignItem` / `unassignItem` mutations.
