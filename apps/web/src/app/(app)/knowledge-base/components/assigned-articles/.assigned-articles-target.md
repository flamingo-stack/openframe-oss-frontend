Defines the `AssignedArticlesTarget` type and helper constructors used to identify the customer (organization) or device whose assigned knowledge base articles are being listed, filtered, or (un)assigned.

## Key Components

- **`AssignedArticlesTarget`** — Interface representing an assignment target, with a `targetType` (`ORGANIZATION` or `DEVICE` from `AssignmentTargetType`) and a `targetId` (a relay global id).
- **`customerArticlesTarget(organizationId: string)`** — Builds an `AssignedArticlesTarget` for an organization, converting the raw `organizationId` into a global id via `toGlobalId('Organization', ...)`.
- **`deviceArticlesTarget(machineId: string)`** — Builds an `AssignedArticlesTarget` for a device, converting the raw `machineId` into a global id via `toGlobalId('Machine', ...)`.
- **`targetNoun(target: AssignedArticlesTarget)`** — Returns a human-readable noun (`'customer'` or `'device'`) describing the target, used for empty-state messaging in the UI.

## Usage Example

```typescript
import {
  customerArticlesTarget,
  deviceArticlesTarget,
  targetNoun,
} from '@/lib/assigned-articles-target';

// Build a target for an organization's assigned articles
const orgTarget = customerArticlesTarget('org-123');

// Build a target for a device's assigned articles
const deviceTarget = deviceArticlesTarget('machine-456');

// Use in a GraphQL query filter
const filter = { assignedTo: orgTarget };

// Display friendly empty-state text
const emptyMessage = `No articles assigned to this ${targetNoun(orgTarget)}.`;
```

This type is typically consumed by knowledge base pages that query `knowledgeBaseItems` or `knowledgeBaseTags` filtered by assignment, and by mutations like `assignItem` / `unassignItem` that require a target.
