# archived-articles-view.tsx

Client-side view component rendering the `/knowledge-base/archive` page, displaying archived knowledge base articles with search and tag filtering. It coordinates URL-driven filter state, a sticky search toolbar, and a deferred-query pattern to keep the UI responsive while the article table loads.

## Key Components

- **`ArchivedArticlesView`** — Default page component that:
  - Resolves a safe "back" navigation target via `useSafeBack`, falling back to `routes.knowledgeBase.list`.
  - Manages tag/search filter state through `useTagSearchState`.
  - Uses `useStickyToolbar` to pin the search toolbar and compute an offset for the table's sticky header.
  - Defers search and tag changes together via `useDeferredQuery`, exposing a single `isPending` flag so loading states stay in sync.
  - Renders `KnowledgeBaseSearchToolbar` (configured with `archived` and `parentId={null}`) and `ArchivedArticlesTable`, passing deferred values down.

## Usage Example

```typescript
// app/knowledge-base/archive/page.tsx
import { ArchivedArticlesView } from '@/app/knowledge-base/archived-articles-view';

export default function ArchivePage() {
  return <ArchivedArticlesView />;
}
```

This component is intended to be used directly as a route-level page entry; it owns all URL-related state (search query and selected tags) internally via `useTagSearchState`, so no props are required. The `ArchivedArticlesTable` child is responsible for data fetching, suspense boundaries, and rendering its own loading state while the deferred query resolves.
