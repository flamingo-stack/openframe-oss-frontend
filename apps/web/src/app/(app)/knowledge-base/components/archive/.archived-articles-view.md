# archived-articles-view.tsx

Page-level component for the `/knowledge-base/archive` route that displays archived knowledge base articles. It owns the URL-driven search and tag filter state, renders a sticky search toolbar, and defers query updates to keep the UI responsive while the article table suspends and loads results below it.

## Key Components

- **`ArchivedArticlesView`** — Default page component composing the archive view:
  - Uses `useSafeBack` to navigate back to the knowledge base list (`routes.knowledgeBase.list`).
  - Uses `useTagSearchState` to manage search text and selected tag filters synced with the URL.
  - Uses `useStickyToolbar` to pin the search toolbar and compute a sticky header offset for the table.
  - Uses `useDeferredQuery` to defer both search and tag filters together, exposing a single `isPending` flag covering both inputs.
  - Renders `KnowledgeBaseSearchToolbar` (configured with `archived` and `parentId={null}`) and `ArchivedArticlesTable`, wrapped in `PageLayout`.

## Usage Example

```typescript
// Rendered automatically by the Next.js router for the archive route
import { ArchivedArticlesView } from './archived-articles-view';

export default function ArchivePage() {
  return <ArchivedArticlesView />;
}
```

This component is route-bound and not typically imported elsewhere; it demonstrates the pattern of combining `useTagSearchState`, `useDeferredQuery`, and `useStickyToolbar` to build a responsive, filterable list view where the child table (`ArchivedArticlesTable`) manages its own suspense boundary and loading state based on the `isPending` and deferred filter props passed down.
