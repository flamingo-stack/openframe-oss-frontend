## archived-articles-columns.ts

Defines the column configuration for the archived knowledge base articles table, reusing shared column definitions while customizing the date column to reflect archival context.

## Key Components

- **`ARCHIVED_COLUMN`** — A `TableSkeletonColumn` configuration derived from the shared `KNOWLEDGE_BASE_ITEM_COLUMNS.created` column. It repurposes the "created" column slot to instead display the archival date, overriding the `id` to `'archived'` and the `header` label to `'Archived'`.

## Usage Example

```typescript
import { ARCHIVED_COLUMN } from './archived-articles-columns';
import { KNOWLEDGE_BASE_ITEM_COLUMNS } from '../shared/knowledge-base-item-columns';

const archivedTableColumns = [
  KNOWLEDGE_BASE_ITEM_COLUMNS.title,
  ARCHIVED_COLUMN,
  // ...other shared columns
];

// Pass to a table component that expects TableSkeletonColumn[]
<DataTable columns={archivedTableColumns} data={archivedArticles} />
```

This pattern allows the archived articles view to share most column logic with the main knowledge base listing while swapping out the semantic meaning of the date column (created vs. archived) without duplicating column definitions.
