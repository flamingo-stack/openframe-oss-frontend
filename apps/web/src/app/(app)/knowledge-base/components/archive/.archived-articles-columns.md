Defines the column configuration for the "Archived" date column used in archived knowledge base article table views, reusing the shared `created` column layout but relabeling it to reflect archival context.

## Key Components

- **`ARCHIVED_COLUMN`**: A `TableSkeletonColumn` object that extends `KNOWLEDGE_BASE_ITEM_COLUMNS.created`, overriding the `id` to `'archived'` and the `header` label to `'Archived'`. It preserves the original column's formatting/rendering logic while repurposing it to display the article's archival date instead of its creation date.

## Usage Example

```typescript
import { ARCHIVED_COLUMN } from './archived-articles-columns';
import type { TableSkeletonColumn } from '@/app/components/shared/table-column-layout';

const archivedArticlesTableColumns: TableSkeletonColumn[] = [
  // ... other columns like title, author, category
  ARCHIVED_COLUMN,
];

// Render in a table component
<TableSkeleton columns={archivedArticlesTableColumns} data={archivedArticles} />
```

This column is typically composed alongside other shared knowledge base item columns (e.g., title, author) to build the full table schema for the archived articles view, ensuring consistent styling and behavior with the rest of the knowledge base UI while clearly labeling the date as "Archived" rather than "Created".
