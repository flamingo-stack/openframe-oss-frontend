# archived-articles-table.tsx

A React/Relay component that renders a paginated, infinitely-scrollable table of archived knowledge base articles. It supports loading-state placeholders, search/tag filtering, and an unarchive action triggered from each row.

## Key Components

- **`ArchivedArticlesTable`** — Public entry point. Wraps the reader in a `LoadingSuspense` boundary with a loading label.
- **`ArchivedArticlesTableReader`** — Detects whether it's rendering inside a loading scope; if so, renders placeholder rows with no data fetch, otherwise delegates to the query component.
- **`ArchivedArticlesTableQuery`** — Executes `archivedArticlesTableQuery` via `useLazyLoadQuery`, then uses `usePaginationFragment` to manage the `archivedArticles` connection and infinite scrolling.
- **`ArchivedArticlesRows`** — Presentational component that builds the `useDataTable` instance, renders `LiveTable`, and manages the `UnarchiveArticleModal` row dialog.
- **`buildColumns(onUnarchive)`** — Builds column definitions: article name, archived date, row actions (unarchive), and "open in new tab".
- **`archivedArticlesTableQuery` / `archivedArticlesTableFragment`** — GraphQL query and refetchable fragment defining the `archivedArticles` connection (search, tagIds, pagination args).
- **`ArchivedRow`** — Type alias for a single archived article node extracted from the GraphQL fragment data.

## Usage Example

```typescript
import { ArchivedArticlesTable } from './archived-articles-table';

function ArchivedArticlesView() {
  const [search, setSearch] = useState('');
  const [tagIds, setTagIds] = useState<string[]>([]);
  const [isPending, startTransition] = useTransition();

  return (
    <ArchivedArticlesTable
      search={search}
      tagIds={tagIds}
      isPending={isPending}
      stickyHeaderOffset="64px"
    />
  );
}
```

The component is designed to be rendered within a parent `<Suspense>` boundary (or loading scope) since it suspends while fetching data via `useLazyLoadQuery`. The `search` and `tagIds` props should be deferred values to avoid UI flicker during refetches, paired with `isPending` from `useTransition` to indicate stale data is shown.
