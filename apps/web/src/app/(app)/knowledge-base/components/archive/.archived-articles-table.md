# archived-articles-table.tsx

A React client component that renders a paginated, searchable table of archived knowledge base articles, supporting infinite scroll, loading placeholders, and an unarchive action dialog.

This component is layered to support three distinct rendering states: a Suspense-wrapped query reader, a loading-scope placeholder view (used inside a parent loading boundary), and the live GraphQL-backed data view. It uses Relay pagination fragments to fetch archived articles with search/tag filtering and cursor-based infinite scroll.

## Key Components

- **`ArchivedArticlesTable`** — Top-level export; wraps the table in a `LoadingSuspense` boundary with a custom loading label.
- **`ArchivedArticlesTableReader`** — Detects whether it's in a loading scope; renders placeholder rows with no query, or delegates to the live query component.
- **`ArchivedArticlesTableQuery`** — Executes the Relay `archivedArticlesTableQuery`, manages pagination via `usePaginationFragment`, and derives infinite scroll state.
- **`ArchivedArticlesRows`** — Presentational table renderer; builds the `useDataTable` instance, handles the unarchive dialog via `useRowDialog`, and renders `LiveTable` with empty-state/footer logic.
- **`buildColumns(onUnarchive)`** — Constructs column definitions: name, archived date, actions (unarchive), and "open in new tab".
- **GraphQL definitions** — `archivedArticlesTableQuery` and `archivedArticlesTableFragment` (refetchable, connection-based pagination keyed by `search`/`tagIds`).

## Usage Example

```typescript
import { ArchivedArticlesTable } from './archived-articles-table';

function KnowledgeBaseArchiveView() {
  const [search, setSearch] = useState('');
  const [tagIds, setTagIds] = useState<string[]>([]);
  const [isPending, startTransition] = useTransition();
  const deferredSearch = useDeferredValue(search);
  const deferredTagIds = useDeferredValue(tagIds);

  return (
    <ArchivedArticlesTable
      search={deferredSearch}
      tagIds={deferredTagIds}
      isPending={isPending}
      stickyHeaderOffset="64px"
    />
  );
}
```

The component expects `search` and `tagIds` to be deferred values so the displayed rows can lag behind rapid input changes while a refetch is in flight, indicated by `isPending`.
