Renders the "ARCHIVED" column cell in a knowledge base article table, displaying the timestamp of when an article was archived (derived from its last update time).

## Key Components

- **`archivedArticleDateCellFragment`** — GraphQL fragment declaration fetching `updatedAt` and `createdAt` from a `KnowledgeBaseItem`. Since archiving counts as the article's most recent modification, `updatedAt` reflects the archival moment.
- **`ArchivedArticleDateCell`** — React component that reads the fragment data (respecting table loading-scope state) and renders an `ItemTimestamp` using `updatedAt`, falling back to `createdAt` if unavailable.

## Usage Example

```typescript
import { ArchivedArticleDateCell } from './archived-article-date-cell';
import type { archivedArticleDateCell_article$key } from '@/__generated__/archivedArticleDateCell_article.graphql';

function ArchivedArticlesTableRow({ article }: { article: archivedArticleDateCell_article$key }) {
  return (
    <td>
      <ArchivedArticleDateCell article={article} />
    </td>
  );
}
```

The component is designed to be used within a table body wrapped in a loading-scope context (via `useLoadingScope`). When a row is still loading, the component skips reading the fragment and renders a skeleton-style timestamp placeholder instead, preventing errors from reading incomplete Relay data. Once resolved, it displays the archival date using the shared `ItemTimestamp` component, ensuring consistent date formatting across the knowledge base UI.
