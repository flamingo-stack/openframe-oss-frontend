# archived-article-date-cell.tsx

A React component that renders the "archived" timestamp column for a knowledge base article row, using the article's `updatedAt` field as a proxy for its archival date since archiving is treated as the last change to the item.

## Key Components

- **`archivedArticleDateCellFragment`** — GraphQL fragment on `KnowledgeBaseItem` that fetches `updatedAt` and `createdAt` fields needed to determine the archive timestamp.
- **`ArchivedArticleDateCell`** — Functional component that displays the archive date (or a loading skeleton) for a given article row. Accepts a `article` prop typed as `archivedArticleDateCell_article$key` (a Relay fragment reference).

## Usage Example

```typescript
import { ArchivedArticleDateCell } from './archived-article-date-cell';

function ArchivedArticlesTable({ articles }: { articles: archivedArticleDateCell_article$key[] }) {
  return (
    <table>
      <tbody>
        {articles.map((article, index) => (
          <tr key={index}>
            <td>
              <ArchivedArticleDateCell article={article} />
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

## Behavior Notes

- When rendered within a **loading scope** (via `useLoadingScope()`), the component skips reading the Relay fragment and renders `<ItemTimestamp value={null} />`, which displays a loading placeholder instead of real data.
- Once data resolves, it prefers `updatedAt` over `createdAt`, falling back only if `updatedAt` is absent.
- If no archive timestamp can be determined, the component renders nothing (`null`).
