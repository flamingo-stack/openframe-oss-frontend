# archived-article-actions-cell.tsx

A table cell component that renders a context menu (⋯) for archived articles, exposing a single "Unarchive" action. Designed for use within row-based data tables where clicking an action must not trigger the row's own click handler.

## Key Components

- **`ArchivedArticleActionsCellProps`** — Interface defining the component's props:
  - `onUnarchive: () => void` — callback invoked when the user selects "Unarchive" from the dropdown menu.

- **`ArchivedArticleActionsCell`** — The main exported component. Renders an `ActionsMenuDropdown` with a single menu group containing the "Unarchive" action. Uses `data-no-row-click` on the wrapping `div` to prevent the row's click handler (e.g., navigation) from firing when the menu is interacted with.

## Usage Example

```typescript
import { ArchivedArticleActionsCell } from './archived-article-actions-cell';

function ArchivedArticlesTableRow({ article, onUnarchive }) {
  return (
    <tr>
      <td>{article.title}</td>
      <td>
        <ArchivedArticleActionsCell
          onUnarchive={() => onUnarchive(article.id)}
        />
      </td>
    </tr>
  );
}
```

### Typical Integration with `useRowDialog`

Since the table (not the row) owns the dialog state, `onUnarchive` is typically wired to open a confirmation dialog at the table level:

```typescript
const { openDialog } = useRowDialog();

<ArchivedArticleActionsCell
  onUnarchive={() => openDialog({ type: 'unarchive', rowId: article.id })}
/>
```

This keeps dialog state centralized while allowing each row to trigger it independently without interfering with row-level click navigation.
