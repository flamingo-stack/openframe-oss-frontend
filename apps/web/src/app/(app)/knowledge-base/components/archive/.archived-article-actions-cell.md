# ArchivedArticleActionsCell

Renders the row-level actions dropdown (⋯ menu) for an archived article in a table, exposing a single "Unarchive" action.

## Key Components

- **`ArchivedArticleActionsCell`** — React component rendering an `ActionsMenuDropdown` with one menu group containing an "Unarchive" action item.
- **`ArchivedArticleActionsCellProps`** — Props interface requiring an `onUnarchive` callback.

The component wraps its content in a `div` with `data-no-row-click`, which prevents the click from bubbling up and triggering the containing table row's own click/link behavior (useful when rows are clickable but the actions menu should remain independently interactive).

## Usage Example

```typescript
import { ArchivedArticleActionsCell } from './archived-article-actions-cell';
import { useRowDialog } from './use-row-dialog';

function ArchivedArticlesTableRow({ article }: { article: Article }) {
  const { openUnarchiveDialog } = useRowDialog(article);

  return (
    <tr>
      <td>{article.title}</td>
      <td>
        <ArchivedArticleActionsCell
          onUnarchive={() => openUnarchiveDialog(article.id)}
        />
      </td>
    </tr>
  );
}
```

## Notes

- The `onUnarchive` callback is expected to trigger a confirmation dialog managed at the table level (not the row level) — see the `useRowDialog` hook for the rationale behind this pattern.
- Icon sizing uses the `--icon-size-icon-size` CSS variable and `text-ods-text-secondary` for consistent theming with the design system.
