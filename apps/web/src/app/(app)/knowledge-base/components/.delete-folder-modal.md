A modal dialog component for deleting knowledge base folders, with an option to either archive or move child articles to another folder before deletion.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DeleteFolderModal` | Component | Main modal component wrapping `ConfirmDialog` with folder deletion logic |
| `DeleteFolderTarget` | Interface | Shape of the folder to delete (`id`, `name`) |
| `DeleteFolderModalProps` | Interface | Props for the modal (`isOpen`, `onClose`, `folder`, `sourceConnectionId`, `onDeleted`) |
| `FolderPicker` | Component (internal) | Dropdown to select archive or move destination |
| `FolderPickerSkeleton` | Component (internal) | Loading placeholder for `FolderPicker` while folders are fetching |

## Behavior

- **Archive** — default selection; child articles are archived in place
- **Move** — user picks a destination folder from the knowledge base tree (current folder is excluded)
- Resets selection to `archive` whenever the modal closes
- Shows a success toast on completion and calls `onDeleted` + `onClose`

## Usage Example

```typescript
import { DeleteFolderModal, type DeleteFolderTarget } from './delete-folder-modal';

const folder: DeleteFolderTarget = { id: 'folder-123', name: 'My Folder' };

<DeleteFolderModal
  isOpen={isDeleteOpen}
  onClose={() => setIsDeleteOpen(false)}
  folder={folder}
  sourceConnectionId="conn-abc"
  onDeleted={() => refetchFolders()}
/>
```
