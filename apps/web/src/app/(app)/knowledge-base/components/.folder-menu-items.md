Builds `ActionsMenuItem` arrays from a `FolderTreeNode` hierarchy for use in knowledge base folder selection menus, supporting recursive submenus and an optional root entry.

## Key Components

| Export | Type | Description |
|---|---|---|
| `FolderMenuTarget` | Interface | Payload passed to `onSelect` — folder `id` (null for root) and display `name` |
| `FOLDER_ROOT_MENU_ID` | Constant | Sentinel ID (`__kb_root__`) for the root menu item |
| `FOLDER_ROOT_TARGET` | Constant | Pre-built `FolderMenuTarget` representing the knowledge base root |
| `buildFolderMenuItems` | Function | Recursively maps folder nodes to `ActionsMenuItem[]`, promoting nodes with children to submenus |
| `buildFolderMenuItemsWithRoot` | Function | Wraps `buildFolderMenuItems` with a prepended root item |

### Submenu Structure

When a node has children, it renders as a `submenu` containing:
1. A self-select item (`nodeId__self`) to select the folder itself
2. A separator (`nodeId__sep`)
3. Recursive child items

## Usage Example

```typescript
import {
  buildFolderMenuItemsWithRoot,
  type FolderMenuTarget,
} from './folder-menu-items';

const menuItems = buildFolderMenuItemsWithRoot(
  folderTree,
  (target: FolderMenuTarget) => {
    console.log('Selected folder:', target.id ?? 'root', target.name);
  },
  { excludeFolderId: currentFolderId }, // omit the folder being moved
);
```

> **`excludeFolderId`** — Pass the ID of the folder currently being moved/renamed to prevent selecting it as its own parent.
