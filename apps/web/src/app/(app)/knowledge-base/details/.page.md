Next.js client page component that renders a single Knowledge Base article detail view, resolving the article ID from URL search parameters.

## Key Components

- **`ArticleDetailsPage`** (default export) — Page component that:
  - Reads the `id` query parameter via `useSearchParams()`
  - Triggers `notFound()` if no `id` is present, rendering the Next.js 404 page
  - Wraps content in `KnowledgeBasePageShell` for consistent error handling/layout
  - Renders `ArticleDetailView`, keyed by `id` to force remount when the article ID changes (since Next.js otherwise reuses the route segment when only the query string changes)

## Usage Example

This page is automatically invoked by Next.js routing when navigating to the article details route with an `id` query parameter:

```typescript
// Navigating to this page from elsewhere in the app
import { useRouter } from 'next/navigation';

function ArticleLink({ articleId }: { articleId: string }) {
  const router = useRouter();

  return (
    <button onClick={() => router.push(`/knowledge-base/article?id=${articleId}`)}>
      View Article
    </button>
  );
}
```

**Note:** The `key={id}` prop on `ArticleDetailView` is essential—without it, navigating between two articles via `?id=` changes alone would not remount the component, potentially leaving stale state or data from the previous article.
