## Overview

This is a Next.js route group layout component (`AppGroupLayout`) that wraps the main application shell. It sets up the chat runtime context, registers a shell-level navigation bridge, and handles legacy dialog-opening deep links before rendering the core `AppLayout` with page content.

## Key Components

- **`AppGroupLayout`** — Default export; a client-side layout component that composes the app's chat runtime, navigation registrar, and legacy URL-param bridge around the main `AppLayout`.
- **`OpenframeChatRuntimeProvider`** — Supplies the `ChatRuntime` context consumed by the embeddable chat (Guide and Mingo modes), used by the composer dock inside `AppLayout`.
- **`ShellNavigatorRegistrar`** — Registers a navigation seam so dialogs/components outside the React tree can trigger navigation.
- **`MingoDialogParamBridge`** — Wrapped in a `Suspense` boundary (fallback `null`) since it reads `useSearchParams()`; redirects legacy `?mingoDialog=` links to the chat page without blocking shell rendering.
- **`getMainClassNameOverride`** — Computes a route-specific override for the main content area's class name based on the current `pathname`.

## Usage Example

This layout is automatically applied by Next.js to all routes within its route group—it is not imported manually. Its structure illustrates the composition pattern:

```typescript
// app/(app-group)/layout.tsx (conceptual usage)
export default function AppGroupLayout({ children }: { children: React.ReactNode }) {
  const pathname = usePathname();
  const mainClassNameOverride = getMainClassNameOverride(pathname);

  return (
    <OpenframeChatRuntimeProvider>
      <ShellNavigatorRegistrar />
      <Suspense fallback={null}>
        <MingoDialogParamBridge />
      </Suspense>
      <AppLayout mainClassName={mainClassNameOverride || APP_MAIN_CLASS_NAME}>
        {children}
      </AppLayout>
    </OpenframeChatRuntimeProvider>
  );
}
```

Any page placed inside this route group automatically receives chat runtime context, shell navigation support, and legacy link handling without additional setup.
