# layout.tsx

Route group layout component that wraps all authenticated app pages with the shared chat runtime, shell navigation registrar, and legacy dialog-link bridge, before rendering the main `AppLayout` shell.

## Key Components

- **`AppGroupLayout`** — Default export; a client-side layout component (Next.js App Router route group layout) that composes the application shell for all nested routes.
- **`OpenframeChatRuntimeProvider`** — Supplies the `ChatRuntime` context consumed by the `EmbeddableChat` component docked inside `AppLayout`, supporting both Guide mode (SSE → MPH via `/guide` proxy) and Mingo mode (NATS → openframe backend).
- **`ShellNavigatorRegistrar`** — Registers a navigation seam allowing dialog-open logic outside React to trigger navigation.
- **`MingoDialogParamBridge`** — Wrapped in `Suspense`; redirects legacy `?mingoDialog=` query-param links (on any route) to the chat page. Isolated in its own suspense boundary since it relies on `useSearchParams()`.
- **`getMainClassNameOverride`** / **`APP_MAIN_CLASS_NAME`** — Resolve the `<main>` element's class name based on the current pathname, with a fallback to the default app class name.

## Usage Example

This file is a Next.js route group layout and is not imported manually—Next.js automatically applies it to all routes nested within the corresponding `(app)` route group:

```typescript
// app/(app)/dashboard/page.tsx
export default function DashboardPage() {
  // Automatically wrapped by AppGroupLayout:
  // - OpenframeChatRuntimeProvider context available
  // - ShellNavigatorRegistrar active
  // - Legacy ?mingoDialog= links auto-redirected
  return <div>Dashboard content</div>;
}
```

Pathname-based `<main>` class overrides are resolved automatically:

```typescript
import { getMainClassNameOverride, APP_MAIN_CLASS_NAME } from '../components/app-shell-chrome';

const mainClassName = getMainClassNameOverride('/some/path') || APP_MAIN_CLASS_NAME;
```

**Note:** The AI agent avatars rendered alongside notification popups come from `AppAgentIdentityProvider`, defined in the root layout above this one—not within this file.
