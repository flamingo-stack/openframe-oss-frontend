Determines the time-of-day greeting shown to a user (for example, in Mingo's home screen), mapping a local hour to a `DayPart` and formatting a personalized or generic greeting string.

## Key Components

- **`DayPart`** - Union type representing the segment of the day: `'Morning'`, `'Afternoon'`, or `'Evening'`.
- **`dayPartOf(hour: number): DayPart`** - Maps a 24-hour clock value (0-23) to a `DayPart`: before 12 is `'Morning'`, before 18 is `'Afternoon'`, otherwise `'Evening'`.
- **`greetingFor(hour: number, firstName: string | null | undefined): string`** - Builds a greeting string for the given hour. If `firstName` is present (after trimming whitespace), returns `"<Part>, <Name>"` (e.g., `"Morning, Ann"`). Otherwise, returns a generic greeting like `"Good morning"`, deliberately avoiding name-like fallbacks (e.g., an email's local part or the word "there").

## Usage Example

```typescript
import { dayPartOf, greetingFor } from './greeting';

// Determine the day part from an hour
dayPartOf(9);   // 'Morning'
dayPartOf(14);  // 'Afternoon'
dayPartOf(20);  // 'Evening'

// Personalized greeting
greetingFor(9, 'Ann');       // 'Morning, Ann'
greetingFor(14, '  Bob  ');  // 'Afternoon, Bob'

// No name available - falls back to a generic greeting
greetingFor(20, null);       // 'Good evening'
greetingFor(9, undefined);   // 'Good morning'
greetingFor(9, '   ');       // 'Good morning' (whitespace-only treated as absent)
```
