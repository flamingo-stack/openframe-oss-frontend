Provides time-of-day greeting utilities used in Mingo's home UI, generating a personalized or generic salutation based on the local hour and an optional first name.

## Key Components

- **`DayPart`** — Type alias representing the segment of the day: `'Morning'`, `'Afternoon'`, or `'Evening'`.
- **`dayPartOf(hour: number): DayPart`** — Maps a local hour (0-23) to its corresponding `DayPart`:
  - `0–11` → `Morning`
  - `12–17` → `Afternoon`
  - `18–23` → `Evening`
- **`greetingFor(hour: number, firstName: string | null | undefined): string`** — Builds a greeting string. If a non-empty `firstName` is provided, returns `"<Part>, <Name>"` (e.g., `"Morning, Ann"`). Otherwise returns a generic greeting like `"Good morning"` rather than falling back to a placeholder name.

## Usage Example

```typescript
import { dayPartOf, greetingFor } from './greeting';

// Determine the day part from an hour
dayPartOf(9);   // 'Morning'
dayPartOf(14);  // 'Afternoon'
dayPartOf(20);  // 'Evening'

// Build a personalized greeting
greetingFor(9, 'Ann');       // 'Morning, Ann'
greetingFor(14, '  Bob  ');  // 'Afternoon, Bob'

// Build a generic greeting when no name is available
greetingFor(20, null);       // 'Good evening'
greetingFor(9, undefined);   // 'Good morning'
greetingFor(9, '   ');       // 'Good morning' (whitespace-only treated as absent)
```
