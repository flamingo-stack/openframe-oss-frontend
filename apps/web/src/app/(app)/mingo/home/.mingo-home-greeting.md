# mingo-home-greeting.tsx

A client-side React hook that generates a time-aware, personalized greeting message (e.g., "Good morning, John") for the Mingo home screen, automatically updating as the time of day changes.

## Key Components

- **`CLOCK_TICK_MS`** — Constant (60,000 ms) defining how often the clock re-reads, ensuring the greeting updates when crossing time-of-day boundaries (e.g., noon, 6 PM) during a long-lived session.
- **`useGreeting()`** — A custom React hook that:
  - Retrieves the authenticated user's first name from `useAuthStore`.
  - Subscribes to a periodically-updating timestamp via `useNow`, ticking every `CLOCK_TICK_MS`.
  - Computes and returns a greeting string using `greetingFor`, based on the current hour and the user's first name.

## Usage Example

```typescript
'use client';

import { useGreeting } from './mingo-home-greeting';

export function HomeHeader() {
  const greeting = useGreeting();

  return (
    <h1 className="text-2xl font-semibold">
      {greeting}
    </h1>
  );
}
```

This hook is designed for use in client components within the Mingo home experience. Because it relies on `useNow` to re-trigger renders on an interval, any component consuming `useGreeting` will automatically reflect the correct greeting (morning, afternoon, evening) without requiring a page refresh, even if left open across time-of-day transitions.

**Dependencies:**
- `useAuthStore` — Zustand-based auth store exposing the current user's profile data.
- `useNow` — Hook providing a periodically refreshed timestamp.
- `greetingFor` — Pure function (from `./greeting`) mapping an hour and optional name to a greeting string.
