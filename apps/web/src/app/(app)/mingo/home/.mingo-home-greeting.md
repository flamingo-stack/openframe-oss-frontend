# mingo-home-greeting.tsx

A client-side React hook that generates a time-aware greeting message (e.g., "Good morning, John") for display on the Mingo home screen, automatically updating as the time of day changes.

## Key Components

- **`CLOCK_TICK_MS`** - Constant defining the clock refresh interval (60,000ms / 1 minute), ensuring the greeting updates when crossing time-of-day boundaries (e.g., noon, 6 PM) during a long-lived session.
- **`useGreeting()`** - A custom React hook that:
  - Retrieves the current user's first name from the global auth store (`useAuthStore`)
  - Tracks the current time via the `useNow` hook, polling every minute
  - Delegates to `greetingFor` (imported from `./greeting`) to produce the final greeting string based on the hour of day and the user's name

## Usage Example

```typescript
import { useGreeting } from './mingo-home-greeting';

function HomeHeader() {
  const greeting = useGreeting();

  return <h1>{greeting}</h1>;
}
```

This hook is intended for use in client components (note the `'use client'` directive) within the Mingo home experience, where a personalized, time-sensitive greeting enhances the user interface without requiring manual refresh logic.
