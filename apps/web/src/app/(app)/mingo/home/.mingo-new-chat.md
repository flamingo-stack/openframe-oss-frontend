This component renders Mingo's "New chat" screen at `/mingo`: a centered greeting with Mingo's identity mark, a prompt inviting fleet-wide requests, and a link into the full "What to ask Mingo?" suggestions chat. On mobile, when reached from the chat list, it shows a back button that restores the list view instead of behaving like a standard page navigation.

## Key Components

- **`MingoNewChat`** — Default-exported function component with no props. Composes:
  - `useGreeting()` — supplies the personalized greeting text.
  - `useMdUp()` — detects phone vs. desktop breakpoint.
  - `useMingoSheetStore` — reads `newChatPage` (the page the chat list was opened from) and `showListAfterNavigation` (action to re-show the list).
  - `useSafeBack(newChatPage ?? routes.dashboard)` — resolves a safe back-navigation target, falling back to the dashboard route.
  - `AgentMark` — renders Mingo's consistent identity icon (used twice: next to the greeting and inside the CTA button).
  - `BackButton` — conditionally rendered only on phone layouts when a `newChatPage` context exists.
  - `Button` (outline variant) — links to `routes.mingo.whatToAsk`, Mingo's full suggestion chat.

## Usage Example

```typescript
import { MingoNewChat } from './mingo-new-chat';

// Rendered as the default view at the /mingo route
export default function MingoPage() {
  return <MingoNewChat />;
}
```

The component is self-contained and reads all required state (greeting, breakpoint, sheet navigation context) internally via hooks, so it requires no props. It is intended to be mounted directly as the `/mingo` page/route content, and relies on `MingoSheetStore` being available in context for the mobile back-navigation behavior.
