# mingo-new-chat.tsx

Renders Mingo's "New chat" screen at `/mingo`: a centered greeting with Mingo's agent mark, a prompt line, and a button linking to the "What to ask Mingo?" suggestions page. On phone, when reached from the chat list, it shows a back button that returns to the previous screen with the list reopened.

## Key Components

- **`MingoNewChat`** — Default export (function component). Composes:
  - `useGreeting()` — time/context-aware greeting text
  - `useMdUp()` — responsive check to detect phone layout
  - `useMingoSheetStore` — reads `newChatPage` (origin page for back navigation) and `showListAfterNavigation` action
  - `useSafeBack(newChatPage ?? routes.dashboard)` — resolves a safe back-navigation handler
  - `AgentMark` — renders Mingo's identity icon consistently (greeting + button)
  - `BackButton` — conditionally shown only on phone when navigated from the chat list
  - `Button` with `href={routes.mingo.whatToAsk}` — links to the full chat suggestions view

## Usage Example

```typescript
import { MingoNewChat } from '@/app/components/mingo-new-chat';

export default function MingoPage() {
  return <MingoNewChat />;
}
```

This component is typically rendered as the default view for the `/mingo` route, representing the "start of a new chat" state before the user selects a quick action or types a request. The back-navigation logic only activates on phone viewports when the sheet store indicates the user arrived via the chat list (`newChatPage` is set), ensuring the chat list panel reopens on return.
