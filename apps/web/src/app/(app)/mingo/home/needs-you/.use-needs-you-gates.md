## use-needs-you-gates.ts

A React hook that computes visibility gates for each source type shown in the "Needs you" dashboard card, mirroring the same feature-flag/mode logic used to decide sidebar module visibility.

## Key Components

- **`useNeedsYouGates()`** — Hook returning a `NeedsYouGates` object with one tri-state value (`'on' | 'off' | 'loading'`) per source:
  - `approvals` — always `'on'` (notifications backing it exist in every mode, so no gate is needed).
  - `incidents` — delegates to `useIncidentsGate()` (SaaS + `insights` flag).
  - `disk` — reuses the same value as `incidents` (disk detector shares its gate).
  - `tickets` — `'on'` only in SaaS tenant mode (`isSaasTenantMode()`), otherwise `'off'`.
  - `tenants` — delegates to `useFeatureFlagGate('tenant-management')`.
  - `software` — delegates to `useFeatureFlagGate('software-management')`.

The tri-state design is intentional: `'loading'` represents an unresolved flag check (rendered as a loading state by the consuming card), distinct from `'off'` (row intentionally hidden) and `'on'` (row shown, possibly prematurely if the flag turns out false).

## Usage Example

```typescript
'use client';

import { useNeedsYouGates } from './use-needs-you-gates';

function NeedsYouCard() {
  const gates = useNeedsYouGates();

  if (gates.incidents === 'loading') {
    return <CardSkeleton />;
  }

  return (
    <div>
      {gates.incidents === 'on' && <IncidentsRow />}
      {gates.tickets === 'on' && <TicketsRow />}
      {gates.tenants === 'on' && <TenantsRow />}
      {gates.software === 'on' && <SoftwareRow />}
      {gates.approvals === 'on' && <ApprovalsRow />}
    </div>
  );
}
```

This hook should be used by the "Needs you" card component to conditionally render each row based on tenant mode and feature flags, keeping gate logic consistent with the app's sidebar navigation (`navigation-config.tsx`).
