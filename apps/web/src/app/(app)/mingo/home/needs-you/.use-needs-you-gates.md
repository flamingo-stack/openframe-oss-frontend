## use-needs-you-gates.ts

A React hook that computes visibility gates for each "Needs you" dashboard card source, mirroring the same feature-flag and tenant-mode logic used to build the sidebar navigation.

## Key Components

- **`useNeedsYouGates()`** — Hook returning a `NeedsYouGates` object with a tri-state gate (`'on' | 'off' | 'loading'`) per source:
  - `approvals` — always `'on'` (backed by notifications present in every mode)
  - `incidents` / `disk` — gated by `useIncidentsGate()` (SaaS + `insights` flag)
  - `tickets` — `'on'` only in SaaS tenant mode (via `isSaasTenantMode()`)
  - `tenants` — gated by the `tenant-management` feature flag
  - `software` — gated by the `software-management` feature flag

The tri-state design is intentional: `'loading'` represents an unanswered flag check (rendered as a loading state on the card), distinct from `'off'` (row hidden) and `'on'` (row shown). This prevents flashing a row for a module the tenant doesn't actually have access to.

## Usage Example

```typescript
'use client';

import { useNeedsYouGates } from './use-needs-you-gates';
import { buildNeedsYouRows } from './needs-you-rows';

function NeedsYouCard() {
  const gates = useNeedsYouGates();

  if (Object.values(gates).some((g) => g === 'loading')) {
    return <CardSkeleton />;
  }

  const rows = buildNeedsYouRows(gates);

  return (
    <ul>
      {rows.map((row) => (
        <li key={row.id}>{row.label}</li>
      ))}
    </ul>
  );
}
```

This hook is typically consumed by a dashboard "Needs you" card component that filters its rows based on the returned gates before rendering, ensuring only relevant, tenant-appropriate sources appear.
