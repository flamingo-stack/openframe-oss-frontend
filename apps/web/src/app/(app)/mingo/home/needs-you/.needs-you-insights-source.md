# needs-you-insights-source.tsx

A headless data-fetching component that loads "Needs You" dashboard insights (critical incidents and disk space warnings) via a single GraphQL round-trip and reports the results to a parent card component through a callback.

## Key Components

- **`needsYouInsightsSourceQuery`** — GraphQL query fetching three related fields in one request: `critical` (NEW, CRITICAL-severity incidents), `disk` (unresolved `DISK_SPACE_LOW` insights), and `newIncidents` (count of NEW incidents for footer display).
- **`DISK_CANDIDATES`** — Constant (5) controlling how many disk warning candidates are fetched, allowing for dropped duplicates beyond the card's display cap.
- **`NeedsYouInsightsSource`** — Renders nothing (`null`); fetches data via `useLazyLoadQuery` and reports transformed rows to the parent via the `onReport` callback using `useLayoutEffect` for pre-paint reporting.

## Usage Example

```typescript
import { NeedsYouInsightsSource } from './needs-you-insights-source';
import type { ReportSource } from './needs-you-rows';

function NeedsYouCard() {
  const [sources, setSources] = useState<Record<string, SourceState>>({});

  const handleReport: ReportSource = (key, state) => {
    setSources(prev => ({ ...prev, [key]: state }));
  };

  return (
    <>
      <Suspense fallback={<NeedsYouCardSkeleton />}>
        <NeedsYouInsightsSource onReport={handleReport} />
      </Suspense>
      <NeedsYouCardView sources={sources} />
    </>
  );
}
```

**Key behaviors:**
- Uses `store-and-network` fetch policy combined with a `retryKey` (from `useRetryKey`) to support error-boundary retries while still serving cached data instantly.
- `useLayoutEffect` (rather than `useEffect`) ensures that when navigating back to a page with cached store data, rows render in the same paint rather than flashing a loading state.
- Row transformation (`criticalIncidentRow`, `diskWarningRow`, `toIncidentRow`) is memoized so reporting effects only fire when the actual row data changes, not on every render.
