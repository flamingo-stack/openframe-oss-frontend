# needs-you-insights-source.tsx

A headless data-fetching component that queries critical incidents and disk space warnings from saas-api in a single GraphQL round-trip, then reports the transformed results to a parent component via a callback. Used to power the "Needs You" summary card without rendering any UI itself.

## Key Components

- **`needsYouInsightsSourceQuery`** — GraphQL query fetching three fields in one request: `critical` (NEW, CRITICAL-severity incidents), `disk` (unresolved `DISK_SPACE_LOW` insights, NEW or ACKNOWLEDGED), and `newIncidents` (count of all NEW incidents for footer display).
- **`DISK_CANDIDATES`** — Constant (`5`) controlling how many disk warnings are fetched, oversized relative to the display cap to allow for de-duplication.
- **`NeedsYouInsightsSource`** — Headless component (returns `null`) that executes the query, transforms results into row data, and reports them to the parent via the `onReport` callback prop.

## Usage Example

```typescript
import { NeedsYouInsightsSource } from './needs-you-insights-source';
import type { ReportSource } from './needs-you-rows';

function NeedsYouCard() {
  const handleReport: ReportSource = (key, payload) => {
    // key is 'incidents' or 'disk'
    // payload contains status, rows, and optional count
    updateCardState(key, payload);
  };

  return (
    <>
      <NeedsYouInsightsSource onReport={handleReport} />
      {/* Render card UI based on reported state */}
    </>
  );
}
```

**Notes:**
- Uses `useLazyLoadQuery` with `fetchPolicy: 'store-and-network'` and a `retryKey` (via `useRetryKey`) to support error-boundary retries.
- Reports happen in `useLayoutEffect` (not `useEffect`) so cached store data renders in the same commit when revisiting the page, avoiding a loading-state flash.
- Relies on `toIncidentRow`, `criticalIncidentRow`, and `diskWarningRow` transform utilities to convert raw GraphQL nodes into display-ready row shapes.
- Designed to fail as a single unit — since all three fields share one query, a backend failure affects all data together, simplifying error handling via the parent's error boundary.
