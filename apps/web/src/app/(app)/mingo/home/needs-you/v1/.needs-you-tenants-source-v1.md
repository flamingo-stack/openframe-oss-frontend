# needs-you-tenants-source-v1.tsx

Legacy (v1) data source component that fetches cloud tenants with failed sync status for the "Needs You" card on the Mingo home dashboard. This component is rendered only while the `tenant-management-v2` feature flag is off, and is slated for deletion once that flag is removed.

## Key Components

- **`needsYouTenantsSourceV1Query`** — GraphQL query fetching `directoryConnections` filtered server-side by `lastSyncStatuses: [ERROR]`, ensuring failed tenants are found even beyond the first page of results.
- **`NeedsYouTenantsSourceV1`** — Headless component (renders `null`) that:
  - Fetches up to `TENANT_CANDIDATES` (5) failed tenant connections via `useLazyLoadQuery`.
  - Maps each result into a row using `failedSyncTenantRow` from `../needs-you-rows`.
  - Reports the computed `tenants` rows to the parent via the `onReport` callback, using `useLayoutEffect` so store-cached data paints synchronously without a loading flash.
- **`TENANT_CANDIDATES`** — Constant capping query results to the card's display limit plus buffer for deduplication.

## Usage Example

```typescript
import { NeedsYouTenantsSourceV1 } from './needs-you-tenants-source-v1';
import type { ReportSource } from '../needs-you-rows';

function NeedsYouCard() {
  const handleReport: ReportSource = (source, result) => {
    // source === 'tenants'
    // result.status === 'ready', result.rows contains mapped tenant rows
    console.log(`Source ${source} reported:`, result);
  };

  return (
    <>
      <NeedsYouTenantsSourceV1 onReport={handleReport} />
      {/* other sources and the card UI consuming aggregated reports */}
    </>
  );
}
```

This component is intended to be used alongside sibling "source" components (each reporting a different data category) that feed a shared aggregator card. It does not render any visible UI itself—only side effects via `onReport`.
