## NeedsYouTenantsSourceV1

A data-source component for the "Needs You" home card that fetches cloud tenants with failed sync status via a Relay GraphQL query. This is the legacy implementation used when the `tenant-management-v2` feature flag is off, and is slated for deletion once the flag is removed.

## Key Components

- **`needsYouTenantsSourceV1Query`** — GraphQL query fetching `directoryConnections` filtered server-side by `lastSyncStatuses: [ERROR]`, ensuring failed tenants beyond the first page are still captured. Deliberately omits `access` to avoid per-row provider probes.
- **`TENANT_CANDIDATES`** — Constant (`5`) capping fetched rows, sized to cover the card's display limit plus potential duplicate-row drops.
- **`NeedsYouTenantsSourceV1`** — Headless component (renders `null`) that loads tenant data and reports it upstream via the `onReport` callback under the `'tenants'` key.

## Usage Example

```typescript
import { NeedsYouTenantsSourceV1 } from './needs-you-tenants-source-v1';
import type { ReportSource } from '../needs-you-rows';

function NeedsYouCard() {
  const handleReport: ReportSource = (sourceKey, result) => {
    if (sourceKey === 'tenants' && result.status === 'ready') {
      console.log('Failed-sync tenant rows:', result.rows);
    }
  };

  return (
    <>
      <NeedsYouTenantsSourceV1 onReport={handleReport} />
      {/* other report sources render alongside this one */}
    </>
  );
}
```

### Implementation Notes

- Uses `useLazyLoadQuery` with `fetchPolicy: 'store-and-network'` and a `fetchKey` tied to `useRetryKey()`, allowing the [`ContentErrorBoundary`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/apps/web/src/app/components/shared/content-error-boundary.tsx) to force a refetch on retry.
- Rows are memoized and reported inside `useLayoutEffect` (not `useEffect`) so that store-cached data renders its rows synchronously on return navigation, avoiding a flash of the loading state.
- Row shaping is delegated to `failedSyncTenantRow` from `../needs-you-rows`, keeping row-format logic shared across source variants.
