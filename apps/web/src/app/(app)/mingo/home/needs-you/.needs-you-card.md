# needs-you-card.tsx

Implements the "Needs you" dashboard card: an aggregated, prioritized list of items requiring user attention (pending approvals, critical incidents, escalated tickets, tenant sync failures, failed software actions, and low-disk devices). The card orchestrates multiple independent data sources, each gated by sidebar visibility settings, and renders a fixed-size panel that looks identical whether loading or loaded.

## Key Components

- **`useNeedsYou(enabled?)`** — Core hook that gates each data source (`useNeedsYouGates`), collects reports via a stable `report` callback, resolves them into a `NeedsYouView` (via `resolveNeedsYou`), and returns the `ReactNode` tree of source-fetching components that must be mounted for data to flow.
- **`useNeedsYouCount(enabled?)`** — Derives the row count (0 while loading or on failure) plus the `sources` node, used for sidebar badges.
- **`NeedsYouCard`** — Top-level component for the Start Work page; mounts `sources`, tracks page-level loading/reveal state (`useLoadingScope`, `useRevealHeld`, `useRevealPart`), and renders `NeedsYouPanel`.
- **`NeedsYouPanel`** — Presentational panel rendering loading skeleton rows, an "all clear" row, failure rows (with retry), or real data rows — always at a consistent size via `StackedRowsPanel`.
- **`EntityIcon`** / **`ENTITY_ICON`** — Maps each `NeedsYouEntity` type to its icon (devices use `renderDeviceTypeIcon`).
- **`toPanelRow`**, **`failureRow`**, **`ALL_CLEAR_ROW`**, **`LOADING_ROWS`** — Row builders converting domain data into `PanelRow` shapes consumed by `StackedRowsPanel`.

## Usage Example

```typescript
import { NeedsYouCard, useNeedsYouCount } from './needs-you-card';

// Render the full card on the dashboard
function StartWorkPage() {
  return (
    <div className="dashboard-grid">
      <NeedsYouCard />
    </div>
  );
}

// Use just the count for a sidebar badge
function SidebarBadge() {
  const { count, sources } = useNeedsYouCount();
  return (
    <>
      {sources}
      {count > 0 && <span className="badge">{count}</span>}
    </>
  );
}
```

Each boundary-wrapped source (`NeedsYouApprovalsSource`, `NeedsYouInsightsSource`, `NeedsYouTenantsSource`, `NeedsYouSoftwareSource`) fetches and reports independently, so a single backend failure only affects its own rows rather than the whole card.
