## Purpose

Implements the "Needs you" dashboard card: a unified panel aggregating pending approvals, critical incidents, escalated tickets, failed tenant syncs, and software failures into a single prioritized row list, with consistent loading/empty/error states.

## Key Components

- **`useNeedsYou(enabled?)`** — Core hook that gates each data source (approvals, incidents, tenants, software, tickets), collects their reports, resolves them into a unified `NeedsYouView`, computes the footer summary text, and returns the `ReactNode` tree of source boundaries that must be rendered to populate the data.
- **`useNeedsYouCount(enabled?)`** — Lightweight wrapper exposing just the row count (e.g., for sidebar badges) plus the required `sources` node.
- **`NeedsYouCard()`** — Top-level component for the dashboard; wires `useNeedsYou` into `NeedsYouPanel`, coordinating with page-level loading/reveal state (`useLoadingScope`, `useRevealHeld`, `useRevealPart`).
- **`NeedsYouPanel(props)`** — Presentational panel rendering rows, failures, an "all clear" state, or skeleton loading rows — always at a fixed size via `StackedRowsPanel`.
- **`toPanelRow`, `failureRow`, `EntityIcon`** — Internal helpers mapping domain rows/failures to `PanelRow` structures with icons, links, and tags.

## Usage Example

```typescript
import { NeedsYouCard, useNeedsYouCount } from './needs-you-card';

// Render the full card on the dashboard
function DashboardStartWork() {
  return (
    <div className="dashboard-grid">
      <NeedsYouCard />
    </div>
  );
}

// Use just the count for a sidebar badge
function SidebarBadge() {
  const { count, sources } = useNeedsYouCount();
  return (
    <>
      {sources}
      <span className="badge">{count}</span>
    </>
  );
}
```

Each data source (approvals, insights, tenants, software) must be rendered via the `sources` node returned from the hook—these are headless components that fetch data and report results via `onReport`, without rendering visible UI themselves.
