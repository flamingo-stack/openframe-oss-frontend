## Purpose

This module implements the data layer and business logic for the "Needs You" card on Mingo's home dashboard, aggregating actionable items (approvals, incidents, tickets, tenant syncs, software failures, disk warnings) from six independent sources into a single composed view with deduplication, capping, and loading/error state resolution.

## Key Components

- **`NEEDS_YOU_SOURCES`** / **`NeedsYouSource`** — ordered tuple of the six data sources and its derived type.
- **`NEEDS_YOU_CAPS`** — max rows each source may contribute to the card.
- **`NEEDS_YOU_PREVIEW_ROWS`** — fixed preview row count for consistent card height.
- **`NeedsYouRow`** — a single row's shape (entity, name, detail, reason, tone, href, subjects).
- **`SourceReport`** — a source's status: `loading`, `ready` (with rows/count), or `error` (with retry).
- **`resolveNeedsYou(gates, reports, pending?)`** — merges gated source reports into a `NeedsYouView` (`loading` / `hidden` / `ready`), applying per-source caps and subject-based deduplication across sources.
- **`sameReport(previous, next)`** — structural equality check to avoid unnecessary re-renders on unchanged reports.
- **`needsYouFooter(counts)`** — formats the footer summary string (e.g., "3 tickets handled by AI · 2 need a technician").
- **Row builders** — `approvalRow`, `criticalIncidentRow`, `diskWarningRow`, `escalatedTicketRow`, `failedSyncTenantRow`, `failedSoftwareActionRow`: each maps a domain entity into a `NeedsYouRow`.

## Usage Example

```typescript
import {
  resolveNeedsYou,
  criticalIncidentRow,
  escalatedTicketRow,
  needsYouFooter,
  type NeedsYouGates,
  type NeedsYouReports,
} from './needs-you-rows';

const gates: NeedsYouGates = {
  approvals: 'on',
  incidents: 'on',
  tickets: 'on',
  tenants: 'off',
  software: 'off',
  disk: 'off',
};

const reports: NeedsYouReports = {
  incidents: { status: 'ready', rows: [criticalIncidentRow(incident)], count: 4 },
  tickets: { status: 'ready', rows: [escalatedTicketRow(ticket)] },
};

const view = resolveNeedsYou(gates, reports);
if (view.status === 'ready') {
  console.log(view.rows); // deduplicated, capped rows in source order
  console.log(view.failures); // sources that errored
}

const footer = needsYouFooter({ aiHandled: 3, needTechnician: 2, newIncidents: 4 });
// "3 tickets handled by AI · 2 need a technician · 4 new incidents"
```
