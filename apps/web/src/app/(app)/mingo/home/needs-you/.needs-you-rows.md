# needs-you-rows.ts

Defines the data model and reconciliation logic behind Mingo home's "Needs You" card — a single card that surfaces actionable items (pending approvals, critical incidents, escalated tickets, failed syncs, etc.) aggregated client-side from six independent data sources. It does not fetch data itself; it combines per-source reports into a stable, capped, deduplicated row set for rendering.

## Key Components

- **`NEEDS_YOU_SOURCES` / `NeedsYouSource`** — ordered tuple of the six sources (`approvals`, `incidents`, `tickets`, `tenants`, `software`, `disk`) and its derived type.
- **`NEEDS_YOU_CAPS`** — max rows each source may contribute.
- **`NEEDS_YOU_PREVIEW_ROWS`** — fixed number of rows shown before "Show N more".
- **`NeedsYouRow`** — a single row's shape: entity type, name/detail/reason text, tone, link, and `subjects` used for cross-source deduplication.
- **`SourceReport` / `NeedsYouReports` / `NeedsYouGates`** — per-source loading/ready/error state, keyed by source, gated by feature flags.
- **`resolveNeedsYou(gates, reports, pending?)`** — core reducer: merges reports into a `NeedsYouView` (`loading` | `hidden` | `ready`), applying caps and subject-based deduplication across sources.
- **`sameReport(previous, next)`** — shallow-equality check to avoid unnecessary re-renders when a refetch returns identical data.
- **`needsYouFooter(counts)`** — builds the footer summary string (e.g. "3 tickets handled by AI · 2 need a technician").
- **Row builders** — `approvalRow`, `criticalIncidentRow`, `diskWarningRow`, `escalatedTicketRow`, `failedSyncTenantRow`, `failedSoftwareActionRow`: convert raw domain objects into `NeedsYouRow`s.

## Usage Example

```typescript
import { resolveNeedsYou, criticalIncidentRow, type NeedsYouGates, type NeedsYouReports } from './needs-you-rows';

const gates: NeedsYouGates = {
  approvals: 'on', incidents: 'on', tickets: 'off',
  tenants: 'off', software: 'off', disk: 'off',
};

const reports: NeedsYouReports = {
  incidents: {
    status: 'ready',
    rows: [criticalIncidentRow(incident)],
    count: 4,
  },
};

const view = resolveNeedsYou(gates, reports);
if (view.status === 'ready') {
  // render view.rows, show view.failures for sources that errored
}
```
