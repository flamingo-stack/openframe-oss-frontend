# needs-you-tenants-source.tsx

A headless data-source component that fetches cloud tenants with failed sync status and reports them to a parent "Needs You" card via callback, with gated v1/v2 implementation switching.

## Key Components

- **`NeedsYouTenantsSource`** — Gate-switching entry component. Renders `NeedsYouTenantsSourceV2` when the `useTenantManagementV2Gate` flag is `'on'`, `NeedsYouTenantsSourceV1` when `'off'`, or nothing while the flag is loading.
- **`NeedsYouTenantsSourceV2`** — Internal component that queries `directoryConnections` filtered to `ERROR` sync status, maps results into row data via `failedSyncTenantRow`, and reports them through the `onReport` callback. Renders nothing (headless).
- **`needsYouTenantsSourceQuery`** — GraphQL query fetching tenant directory connections with `lastSyncStatuses: [ERROR]`, including `id`, `name`, `provider`, and bound `customers` fragment data.
- **`TENANT_CANDIDATES`** — Constant (`5`) controlling how many failed connections are fetched, sized to account for duplicate-row filtering downstream.

## Usage Example

```typescript
import { NeedsYouTenantsSource } from './needs-you-tenants-source';
import type { ReportSource } from './needs-you-rows';

function NeedsYouCard() {
  const handleReport: ReportSource = (key, result) => {
    if (result.status === 'ready') {
      console.log(`${key} rows:`, result.rows);
    }
  };

  return (
    <>
      <NeedsYouTenantsSource onReport={handleReport} />
      {/* other sources report into the same card */}
    </>
  );
}
```

The component is designed to be used alongside sibling "source" components (e.g., for customers, devices) that each report their own `ReportSource` key into a shared aggregating card. Since it fetches via Relay's `useLazyLoadQuery` with `store-and-network` policy and reports in a `useLayoutEffect`, cached data renders synchronously on revisit, avoiding a loading-state flash.
