# needs-you-tenants-source.tsx

A headless data-source component that fetches cloud tenants with failed sync status for the "Needs You" attention card. It gates between a v2 (GraphQL/Relay) and v1 implementation based on a feature flag, and reports results via callback rather than rendering UI.

## Key Components

- **`needsYouTenantsSourceQuery`** — GraphQL query fetching `directoryConnections` filtered server-side by `lastSyncStatuses: [ERROR]`, including tenant `id`, `name`, `provider`, and bound `customers`.
- **`TENANT_CANDIDATES`** — Constant (5) capping the number of failed tenants fetched, sized to allow for duplicate-row filtering downstream.
- **`NeedsYouTenantsSource`** — Exported gate component. Renders `NeedsYouTenantsSourceV2` or `NeedsYouTenantsSourceV1` depending on `useTenantManagementV2Gate()`, or nothing while the flag is resolving.
- **`NeedsYouTenantsSourceV2`** — Internal component that runs the Relay query, maps results into row objects via `failedSyncTenantRow`, and reports them through `onReport('tenants', { status: 'ready', rows })` inside a `useLayoutEffect` (ensures synchronous reporting before paint when data is already cached).

## Usage Example

```typescript
import { NeedsYouTenantsSource } from './needs-you-tenants-source';
import type { ReportSource } from './needs-you-rows';

function NeedsYouCard() {
  const handleReport: ReportSource = (sourceName, result) => {
    console.log(`${sourceName} reported:`, result);
    // Aggregate rows across multiple sources for the card
  };

  return (
    <>
      <NeedsYouTenantsSource onReport={handleReport} />
      {/* Other source components (e.g., needs-you-alerts-source) */}
    </>
  );
}
```

This component renders nothing itself; it's designed to be composed alongside other `NeedsYou*Source` components that each report rows for a unified attention/alerts card. The parent card manages loading state until all sources have reported.
