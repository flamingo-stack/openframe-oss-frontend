# needs-you-software-source.tsx

A headless data-source component that fetches failed software install/update actions via GraphQL and reports them to a parent aggregator for display in a "Needs You" attention panel. Renders no UI itself.

## Key Components

- **`needsYouSoftwareSourceQuery`** — GraphQL query fetching the most recent `FAILED` software actions, capped by a configurable `first` limit.
- **`NeedsYouSoftwareSource`** — React component that:
  - Uses `useLazyLoadQuery` with `store-and-network` fetch policy to retrieve failed software action data.
  - Transforms each edge node into a normalized row via `failedSoftwareActionRow`.
  - Reports the computed rows to the parent through the `onReport` callback using `useLayoutEffect`, ensuring synchronous updates before paint (avoiding a flash of loading state when store data is already available).
  - Integrates with `useRetryKey` to support retry-on-error via a shared content error boundary.
  - Returns `null` — purely a data-fetching/reporting component.

## Usage Example

```typescript
import { NeedsYouSoftwareSource } from './needs-you-software-source';
import type { ReportSource } from './needs-you-rows';

function NeedsYouPanel() {
  const handleReport: ReportSource = (sourceKey, result) => {
    // e.g., store result.rows in a Map keyed by sourceKey ('software')
    // to aggregate alongside other "Needs You" sources (patches, alerts, etc.)
    console.log(sourceKey, result.status, result.rows);
  };

  return (
    <>
      <NeedsYouSoftwareSource onReport={handleReport} />
      {/* other sibling sources + aggregated rows rendered elsewhere */}
    </>
  );
}
```

This component is typically composed alongside sibling `*Source` components (e.g., patches, alerts) inside a wrapping panel that collects reports into a single "Needs You" list using a shared `ReportSource` callback contract.
