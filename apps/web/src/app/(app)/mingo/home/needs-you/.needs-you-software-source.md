Renderless data-source component that fetches failed software install/update actions via a Relay GraphQL query and reports the resulting rows to a parent "Needs You" aggregator component.

## Key Components

- **`needsYouSoftwareSourceQuery`** — GraphQL query fetching `softwareActions` filtered to `FAILED` status, newest first, capped at a configurable count.
- **`NeedsYouSoftwareSource({ onReport })`** — Functional component that:
  - Uses `useLazyLoadQuery` with `store-and-network` fetch policy and a retry key (from `useRetryKey`) to support manual refetching on error recovery.
  - Maps query edges into standardized row objects via `failedSoftwareActionRow`.
  - Memoizes the mapped rows so the reporting effect only fires when data actually changes.
  - Calls `onReport('software', { status: 'ready', rows })` inside `useLayoutEffect` (pre-paint) so cached store data renders immediately without a loading flash.
  - Renders `null` — it's a pure data-fetching/reporting component with no visual output.


This component is designed to be used alongside sibling `NeedsYou*Source` components, each reporting a distinct data slice (e.g., devices, alerts) to a shared parent that merges them into a unified "Needs You" summary card.
