This file defines `NeedsYouSourceBoundary`, a React error boundary wrapper that isolates one or more Relay-backed "Needs you" data sources so each can fetch independently and fail without affecting sibling sources on the same card.

## Key Components

- **`NeedsYouSourceBoundary`** — Wraps `children` (a Relay-backed source) in a `ContentErrorBoundary`. On retry, resets the given `sources` to a `loading` state via `onReport` before the remount, avoiding a stale failure message during an in-flight retry. Uses `Suspense` with a `null` fallback, since the loading UI is owned by the parent card, not the source itself.
- **`ReportFailure`** — Internal helper component rendered as the error boundary's fallback. On mount, reports an `error` status (including `isOffline` and `retry`) for every source in the list, then renders nothing.
- **`NeedsYouSourceBoundaryProps`** / **`ReportFailureProps`** — Prop interfaces describing the `sources` list, the `onReport` callback (`ReportSource`), and children/retry/offline state.

## Usage Example

```typescript
import { NeedsYouSourceBoundary } from './needs-you-source-boundary';
import type { NeedsYouSource, ReportSource } from './needs-you-rows';

function NeedsYouCard({ onReport }: { onReport: ReportSource }) {
  const sources: NeedsYouSource[] = ['openTickets', 'pendingApprovals'];

  return (
    <NeedsYouSourceBoundary sources={sources} onReport={onReport}>
      <RelayBackedSourceRows sources={sources} />
    </NeedsYouSourceBoundary>
  );
}
```

Each distinct source (or group of related sources) should be wrapped in its own `NeedsYouSourceBoundary` so that a backend failure for one source reports an error only for its own rows, while other sources continue fetching and rendering independently.
