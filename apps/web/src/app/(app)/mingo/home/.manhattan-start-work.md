# manhattan-start-work.tsx

Renders the "Start Work" view for the Manhattan v2 shell (`/mingo`), displaying a Mingo greeting, a "What to ask Mingo?" entry point, and the "Needs You" panel (approvals, critical incidents, escalated tickets). It supports both a standalone full-page layout and an embedded column layout alongside an open page.

## Key Components

- **`ManhattanStartWork`** — Main exported component that renders the greeting, call-to-action button, and "Needs You" content.
  - `live?: boolean` (default `true`) — When `false`, renders `NeedsYouPanel` in a loading state and skips data fetching, used while the shell awaits the onboarding answer.
  - `variant?: 'page' | 'column'` (default `'page'`) — `'page'` renders a full `<h1>` greeting with navigation to `routes.mingo.whatToAsk`; `'column'` renders an `<h2>` section heading and triggers `onWhatToAsk` in-place instead of navigating.
  - `onWhatToAsk?: () => void` — Callback invoked in `'column'` variant to show the "What to ask Mingo?" content inline rather than navigating away.
- Relies on `useGreeting` for the dynamic greeting text, `AgentMark` for the Mingo avatar, `RevealTogether` for animated reveal of live content, and `NeedsYouCard` / `NeedsYouPanel` for the "Needs You" section.

## Usage Example

```typescript
// Full-page usage (e.g. /mingo route)
<ManhattanStartWork live={true} variant="page" />

// Column usage beside an open page, with inline "What to ask Mingo?" handling
<ManhattanStartWork
  variant="column"
  onWhatToAsk={() => setShowWhatToAsk(true)}
/>

// While awaiting onboarding state, render without live data
<ManhattanStartWork live={false} />
```
