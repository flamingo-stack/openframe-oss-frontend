# manhattan-start-work.tsx

The `ManhattanStartWork` component renders the "Start Work" view (`/mingo` route in the Manhattan v2 shell), combining a personalized greeting, a "What to ask Mingo?" prompt, and a "Needs You" section highlighting items requiring human attention (approvals, critical incidents, escalated tickets). It supports both a standalone page layout and an embedded column layout alongside an open chat.

## Key Components

- **`ManhattanStartWork`** — Main exported component.
  - `live?: boolean` (default `true`) — When `false`, skips data fetching and shows `NeedsYouPanel` in a loading state (used while the shell awaits onboarding status).
  - `variant?: 'page' | 'column'` (default `'page'`) — `'page'` renders a full-page layout with an `h1` greeting; `'column'` renders a compact layout with an `h2` greeting intended to sit beside an open chat panel.
  - `onWhatToAsk?: () => void` — Callback used only in `'column'` variant to trigger the "What to ask Mingo?" action inline instead of navigating to `routes.mingo.whatToAsk`.
- Relies on `useGreeting` for the personalized heading text, `AgentMark` for the Mingo agent avatar, `RevealTogether`/`NeedsYouCard`/`NeedsYouPanel` for the "Needs You" section, and `Button` for the call-to-action.

## Usage Example

```typescript
import { ManhattanStartWork } from './manhattan-start-work';

// Full-page usage (default)
export function MingoPage() {
  return <ManhattanStartWork />;
}

// Column usage beside an open chat, with inline "What to ask Mingo?" handling
export function ChatSidebar({ openWhatToAsk }: { openWhatToAsk: () => void }) {
  return (
    <ManhattanStartWork
      variant="column"
      live={true}
      onWhatToAsk={openWhatToAsk}
    />
  );
}

// Loading state while onboarding status is pending
export function PendingShell() {
  return <ManhattanStartWork live={false} />;
}
```
