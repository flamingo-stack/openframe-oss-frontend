## Overview

`use-mingo-tour.tsx` implements the `useMingoTour` hook, which drives the Mingo-first "Getting Started" onboarding tour. It manages the lifecycle of a dedicated tour conversation (creation, server recording, greeting injection, archiving/skipping), wires tour step chips to send prompts and navigate, and renders the `GettingStartedBlock` above the chat composer while the tour is active.

## Key Components

- **`useMingoTour(input: MingoTourInput): MingoTour`** — Main hook. Takes the host chat state plus callbacks for creating a named dialog, tracking dialog errors/timestamps, and screen/close behavior. Returns a decorated chat `state` (with the tour greeting prepended and an `archiveDialog` override that skips onboarding) and an `aboveComposer` node to render the tour UI.
- **`MingoTourInput`** — Props interface: `state`, `createNamedDialog`, `dialogError`, `dialogCreatedAt`, `onStepOpened`, `onScreen`, `onClose`.
- **`MingoTour`** — Return type: `state` (decorated `UnifiedChatState`) and `aboveComposer` (`ReactNode`).
- **`handleAction`** — Handles a tour chip click: guards against busy chat, navigates to the step's `href`, fetches the first enrolled device for prompt personalization, sends the tour prompt, and marks the step complete on the server.
- **`handleFinish`** / **`confirmSkip`** — Complete or skip onboarding, via `useOnboardingMutations`.
- **`handleClose`** — Sets the Getting Started block aside (closes it from the current screen) without ending the tour.
- Internal state tracks dialog creation (`createdDialogId`), greeting injection timing, and whether the block is currently `showing`.

## Usage Example

```typescript
import { useMingoTour } from './use-mingo-tour';

function MingoDock({ chatState, createNamedDialog, dialogError }: DockProps) {
  const { state, aboveComposer } = useMingoTour({
    state: chatState,
    createNamedDialog,
    dialogError,
    onStepOpened: (href) => console.log('Opened section:', href),
    onScreen: true,
    onClose: () => console.log('Tour block closed'),
  });

  return (
    <div>
      {aboveComposer}
      <ChatComposer state={state} />
    </div>
  );
}
```

This hook is intended for use inside the Mingo-first shell's composer dock, where it must be composed with the host's `UnifiedChatState` and onboarding store (`@/stores/onboarding-store`) to correctly reflect tour progress across devices.
