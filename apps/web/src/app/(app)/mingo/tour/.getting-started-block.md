## Getting Started Block

A React/Next.js client component that renders the interactive "Getting Started" onboarding tour panel, pinned above the Mingo chat composer. It supports two adaptive layouts—an expandable list of step rows and a compact two-column grid of step chips—and tracks user progress through a set of tour steps.

## Key Components

- **`GettingStartedBlock`** — Main exported component. Renders the tour UI with a title row (progress count, "Skip Onboarding", fold/collapse chevron, close button) and a body that toggles between list and grid layouts via animated `Fold` transitions.
- **`GettingStartedBlockProps`** — Props interface defining `steps`, `doneStepIds`, and callbacks (`onAction`, `onFinish`, `onSkip`, `onClose`, `onOpenFae`, `busy`).
- **`Fold`** (internal) — Animated collapsible wrapper using CSS grid row transitions (`0fr` ↔ `1fr`) with `inert`/`invisible` state management for accessibility when collapsed.
- **`FoldChevron`** (internal) — Chevron icon that rotates 180° based on open/closed state, synced with `Fold` motion timing.
- **Shared style constants** — `DISABLED_CHIP`, `EASE`, `MOTION`, `TITLE_ROW_GLYPH` define consistent timing curves and disabled-state styling reused across the component.

The component relies on `useGettingStartedView` (from `getting-started-view`) to persist the collapsed/expanded shape across pages and tabs, and on types from `tour-steps` (`TourAction`, `TourStep`, `TourStepId`).

## Usage Example

```typescript
import { GettingStartedBlock } from './getting-started-block';
import type { TourStep, TourAction, TourStepId } from './tour-steps';

function OnboardingPanel({ steps, completedIds }: {
  steps: readonly TourStep[];
  completedIds: ReadonlySet<TourStepId>;
}) {
  return (
    <GettingStartedBlock
      steps={steps}
      doneStepIds={completedIds}
      busy={false}
      onAction={(step, action) => {
        // Send the "try asking" prompt; return false to keep the step open
        return sendPromptToChat(action.prompt);
      }}
      onFinish={() => console.log('Tour finished')}
      onSkip={() => console.log('Tour skipped')}
      onClose={() => console.log('Panel closed')}
      onOpenFae={() => openFaeAssistant()}
    />
  );
}
```

**Notes:**
- Must be rendered in a client component context (`'use client'` directive).
- The layout shape (list vs. grid) is automatically determined by progress unless the user has explicitly toggled it, in which case the preference persists via `useGettingStartedView`.
- `onAction` returning `false` (e.g., when the chat is busy) keeps the current step expanded instead of collapsing the panel.
