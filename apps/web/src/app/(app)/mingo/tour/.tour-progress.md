Utility module for mapping server-tracked onboarding progress to the frontend's internal tour step identifiers, used to determine which guided tour steps a user has already completed.

## Key Components

- **`doneTourStepIds(serverSteps)`** — Converts a list of `UserOnboardingStep` values (as reported by the backend) into a `ReadonlySet<TourStepId>` by matching each entry in `TOUR_STEPS` against the server-provided steps. Returns an empty set if `serverSteps` is `undefined`.

## Usage Example

```typescript
import { doneTourStepIds } from './tour-progress';
import type { UserOnboardingStep } from '@/generated/schema-enums';

// Example server response indicating completed onboarding steps
const serverSteps: UserOnboardingStep[] = ['WELCOME', 'CREATE_ORG'];

const completedSteps = doneTourStepIds(serverSteps);

if (completedSteps.has('welcome-step')) {
  console.log('User has already completed the welcome tour step');
}

// Handles undefined gracefully
const noProgress = doneTourStepIds(undefined);
console.log(noProgress.size); // 0
```

This function is typically used in onboarding/tour components to decide which steps to skip or highlight as completed, by cross-referencing the canonical `TOUR_STEPS` definition with the user's persisted progress from the backend.
