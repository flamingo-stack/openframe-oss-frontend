# getting-started-view.ts

Manages the display state of the "Getting Started" onboarding block, persisting per-user preferences (expanded/collapsed view and dismissed state) to `localStorage` with cross-tab synchronization via the `storage` event.

## Key Components

- **`GettingStartedView`** — Type alias: `'default'` (step list) or `'collapsed'` (folded grid).
- **`ensureGettingStartedView(userId)`** — Initializes the view to `'default'` if unset (used when starting the tour).
- **`resetGettingStartedView(userId)`** — Resets view to `'default'` and un-dismisses the block (used by "Reset Onboarding").
- **`clearGettingStartedView(userId)`** — Clears all state when the tour ends (finished or skipped).
- **`setGettingStartedView(userId, view)`** — Sets the view explicitly (user folds/unfolds the block).
- **`setGettingStartedAside(userId)`** — Marks the block as dismissed/closed.
- **`useGettingStartedView()`** — React hook returning `[view, setView]` for the current signed-in user, reactive across tabs via `useSyncExternalStore`.
- **`useGettingStartedAside()`** — React hook returning `[isAside, setAside]` for dismissed state.

State falls back to an in-memory value (`memoryView`/`memoryAside`) when no `userId` is available (e.g., session still loading), rather than persisting to storage.

## Usage Example

```typescript
import {
  useGettingStartedView,
  useGettingStartedAside,
  ensureGettingStartedView,
  resetGettingStartedView,
} from './getting-started-view';

function GettingStartedBlock() {
  const [view, setView] = useGettingStartedView();
  const [isAside, dismiss] = useGettingStartedAside();

  if (isAside) return null;

  return (
    <div>
      <button onClick={() => setView(view === 'default' ? 'collapsed' : 'default')}>
        Toggle View
      </button>
      <button onClick={dismiss}>Close</button>
    </div>
  );
}

// Starting the tour from elsewhere:
function startTour(userId: string | undefined) {
  ensureGettingStartedView(userId);
}

// "Reset Onboarding" action:
function resetTour(userId: string | undefined) {
  resetGettingStartedView(userId);
}
```
