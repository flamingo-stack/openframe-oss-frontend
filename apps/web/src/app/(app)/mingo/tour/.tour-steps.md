# tour-steps.ts

Defines the content and configuration for OpenFrame's "Getting Started" product tour, driven by Mingo (the AI assistant). It describes each onboarding step (Devices, Tickets, Scripting, Monitoring, Logs, Incidents, Knowledge Management), the suggested action chips shown per step, and the prompts those chips send to Mingo, with device mentions resolved dynamically.

## Key Components

- **`TOUR_DIALOG_TITLE`** — Fixed title for the tour's chat conversation.
- **`tourGreeting(firstName)`** — Builds Mingo's personalized opening message for the tour.
- **`TourStepId`** — Union type of the seven tour step identifiers.
- **`TourAction`** — Interface for a chip: `label`, `prompt` (string or a function of the device mention), `href`, and `Icon`.
- **`TourStep`** — Interface for a tour step: metadata (`title`, `subtitle`, `description`, `Icon`), its `userStep` (backend-tracked onboarding step enum), `actions` (chips), and optional `opensFae` flag.
- **`TourStepOptions`** — Config for `tourSteps`, currently just `softwareManagement` (feature flag toggling the second Devices chip).
- **`tourSteps(options)`** — Factory function returning the full ordered list of `TourStep` objects, with conditional chip variants based on enabled modules.
- **`TOUR_STEPS`** — Precomputed tour steps with all modules enabled (used by tests and fully-licensed workspaces).
- **`TOUR_DEVICE_FALLBACK`** — Fallback label (`"my device"`) used when no device mention is available.
- **`tourPrompt(action, device)`** — Resolves an action's final prompt string, substituting an `@device:<id>` mention when a device is known, or the fallback text otherwise.

## Usage Example

```typescript
import { tourSteps, tourPrompt, tourGreeting, TOUR_STEPS } from './tour-steps';

// Build steps based on enabled features
const steps = tourSteps({ softwareManagement: true });

// Render a greeting
const greeting = tourGreeting('Alex');

// Resolve a chip's prompt for a known device
const devicesStep = TOUR_STEPS.find(s => s.id === 'devices')!;
const action = devicesStep.actions[0];
const promptText = tourPrompt(action, { mentionId: 'abc123' });
// => "Check @device:abc123: OS, uptime, CPU, memory and free disk..."

// Resolve for an unknown device
const fallbackPrompt = tourPrompt(action, null);
// => "Check my device: OS, uptime, CPU, memory and free disk..."
```
