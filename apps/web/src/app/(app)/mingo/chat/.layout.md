This file defines the Next.js metadata and layout export for the Mingo Chat route, ensuring the page title is consistently generated and applying the shared route-title layout wrapper.

## Key Components

- **`metadata`** — A statically exported `Metadata` object (from `next`) that sets the page title using the `routeTitle` helper with `'Mingo Chat'` as the label.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as the layout for this route segment, avoiding duplicated layout logic across routes.

## Usage Example

This file follows Next.js App Router conventions, where a `layout.tsx` file automatically applies to all pages within its route segment. You typically don't import it directly; Next.js picks it up based on file location.

```typescript
// Example of how routeTitle is used elsewhere to generate consistent titles
import { routeTitle } from '@/lib/route-title';

export const metadata = {
  title: routeTitle('Mingo Chat'), // e.g., "Mingo Chat | OpenFrame"
};
```

To customize the layout for a different route, create a sibling `layout.tsx` file following the same pattern:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Your Page Name') };
```

This pattern keeps title generation centralized via `routeTitle`, while reusing a shared layout component for consistent UI structure across route segments.
