Defines Next.js route metadata and layout delegation for the Mingo Chat page, setting the browser tab title while reusing a shared layout component across the application.

## Key Components

- **`metadata`** — Exports a Next.js `Metadata` object that sets the page title to `routeTitle('Mingo Chat')`, ensuring consistent title formatting across routes.
- **`default` export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as the default layout for this route segment, avoiding duplication of layout logic.

## Usage Example

This file follows the Next.js App Router convention where `layout.tsx` applies to all pages within its route segment. It doesn't need to be imported manually—Next.js automatically picks it up based on file location.

```typescript
// Example of the shared layout being reused (route-title-layout.tsx)
export default function RouteTitleLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return <div className="route-title-wrapper">{children}</div>;
}
```

```typescript
// Example of the routeTitle helper used for consistent title formatting
export function routeTitle(pageName: string): string {
  return `${pageName} | OpenFrame`;
}
```

This pattern lets multiple route segments share identical layout behavior while only customizing the page-specific metadata (like the title), keeping layout code DRY across the Next.js app directory structure.
