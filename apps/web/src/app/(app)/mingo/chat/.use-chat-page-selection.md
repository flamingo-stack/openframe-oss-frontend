## use-chat-page-selection.ts

A React hook that synchronizes the Mingo chat page's `?id` URL parameter with the active chat session's dialog selection, managing bidirectional state flow between the URL and the chat provider.

This hook acts as the glue between a page-level `dialogId` (from the URL) and the shared `MingoChatState` selection. It ensures the page writes the selection to the session exactly once per id, then defers to whatever the session's selection does afterward — following it to a new URL if the selection moves to a different dialog, or redirecting home if the selection is cleared (e.g., the dialog was archived).

## Key Components

- **`ChatPageStatus`** — Union type representing the page's rendering state: `'starting'`, `'ready'`, `'not-found'`, or `'failed'`.
- **`useChatPageSelection(dialogId, chat)`** — The main hook. Takes the current `?id` value (or `null`) and the `MingoChatState` (or `null` if no session is running), and returns a `ChatPageStatus`.
  - Writes `dialogId` to the session via `selectDialog` once per id change (guarded by `appliedIdRef`).
  - Tracks when the dialog "lands" (`activeDialogId === dialogId`) via `landedIdRef`, and after landing, follows further selection changes by redirecting with `router.replace` to either `routes.mingo.chat(activeDialogId)` or `routes.mingo.home`.
  - Latches a `not-found` state via `notFoundId` when `MINGO_DIALOG_NOT_FOUND` is reported for the active id, so the error renders for exactly one state before the session clears the selection.

## Usage Example

```typescript
'use client';

import { useChatPageSelection } from './use-chat-page-selection';
import { useMingoChat } from '../providers/mingo-chat-provider';

function MingoChatPage({ dialogId }: { dialogId: string | null }) {
  const chat = useMingoChat();
  const status = useChatPageSelection(dialogId, chat);

  switch (status) {
    case 'starting':
      return <ChatSkeleton />;
    case 'not-found':
      return <ChatNotFoundToast />;
    case 'failed':
      return <ChatErrorState />;
    case 'ready':
      return <ChatDock dialogId={dialogId} />;
  }
}
```
