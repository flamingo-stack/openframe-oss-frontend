## chat-fixtures.ts

Test fixture helpers for simulating Mingo (AI agent) chat turns published over a fake JetStream subject and persisted as Mongo-style rows, used by the chat replay regression test suite. It provides both "happy path" streaming turns and more complex approval-gated turns (where a tool execution requires admin approval before running).

## Key Components

- **`DIALOG` / `SUBJECT` / `USER_ID`** — Shared constants identifying the test dialog, its NATS subject (`chat.<dialogId>.admin-message`), and the admin user.
- **`thread()`** — Reads the current message thread for `DIALOG` from `useMingoMessagesStore`.
- **`processMingoHistory(rows)`** — Converts persisted Mongo-style rows into store `Message[]` using `processHistoricalMessagesWithErrors`, mirroring the options `use-mingo-dialog-selection` passes.
- **`PublishedTurn` / `publishTurn(js, i, noise?)`** — Publishes a full streamed Mingo turn (request echo, start, text, tool execution, tool result, answer, end, token usage) onto the fake JetStream, interleaving noise from other dialogs; returns the turn's text/script/output and the sequence number of each chunk.
- **`persistedRows(turn, i, stamp, at)`** — Builds the Mongo-style persisted rows (user message + assistant segments) corresponding to a `PublishedTurn`, optionally stripping `lastChunkStreamSeq` when `stamp` is `false`.
- **`renderedText(message)` / `countOccurrences(messages, needle)`** — Flattens a rendered message's content (text, tool execution, approval batch) into a comparable string, and counts how many messages contain a given substring.
- **`historyPage(rows)`** — Wraps persisted rows into a `MessagePage` shaped like the newest-first history query response.
- **`ApprovalRound` / `ApprovalSession`** — Models a multi-round approval-gated Mingo turn: user request → intro → approval request → (admin approves → tool runs → resumed answer, repeated per round), maintaining a session clock (`at`) and recording both published stream chunks and persisted rows.

## Usage Example

```typescript
import { FakeJetStream } from './fake-jetstream';
import {
  publishTurn,
  persistedRows,
  historyPage,
  processMingoHistory,
  thread,
  ApprovalSession,
} from './chat-fixtures';

const js = new FakeJetStream();

// Simple streamed turn
const turn = publishTurn(js, 1);
const rows = persistedRows(turn, 1, /* stamp */ true, Date.now());
const messages = processMingoHistory(historyPage(rows).messages as never);

// Approval-gated turn
const session = new ApprovalSession(js, 2, Date.now()).start();
// session.approve(...) drives subsequent approval rounds

const currentThread = thread();
```
