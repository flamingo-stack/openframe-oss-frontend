## chat-fixtures.ts

Test fixture utilities for simulating Mingo AI agent chat turns, including JetStream-published message chunks, persisted MongoDB rows, and rendered-message helpers used by the chat replay regression suite.

## Key Components

- **`DIALOG`, `SUBJECT`, `USER_ID`** — Shared constants identifying the test dialog, NATS subject, and acting user.
- **`thread()`** — Reads the current message thread for `DIALOG` from the Mingo messages store.
- **`processMingoHistory(rows)`** — Converts raw persisted rows into `Message[]` using the same options `use-mingo-dialog-selection` applies.
- **`publishTurn(js, i, noise?)`** — Publishes a full Mingo turn (request, start, text, tool execution, answer, end, usage) onto the fake JetStream, interleaved with noise from other dialogs; returns a `PublishedTurn` with text/script/output and the sequence number of each chunk.
- **`persistedRows(turn, i, stamp, at)`** — Builds the MongoDB-style persisted rows corresponding to a `PublishedTurn`, optionally stripping `lastChunkStreamSeq` when `stamp` is `false`.
- **`renderedText(message)` / `countOccurrences(messages, needle)`** — Flattens a message's segments (text, tool execution, approval batch) into a comparable string and counts matches across messages.
- **`historyPage(rows)`** — Wraps persisted rows into a newest-first `MessagePage` as returned by the history query.
- **`ApprovalSession`** — Models a multi-round approval flow (request → approve → resumed run), tracking published rows (`rows`), round metadata (`rounds`), and the session clock (`at`). Exposes `start()` to kick off the user message/intro/first approval request, and `approve(...)` (truncated) to simulate approving a pending request.

## Usage Example

```typescript
import { FakeJetStream } from './fake-jetstream';
import { publishTurn, persistedRows, processMingoHistory, thread, ApprovalSession } from './chat-fixtures';

const js = new FakeJetStream();

// Simulate a simple tool-call turn
const turn = publishTurn(js, 1);
const rows = persistedRows(turn, 1, /* stamp */ true, Date.now());
const messages = processMingoHistory(rows);

// Assert the live store mirrors the persisted history
expect(thread()).toEqual(messages);

// Simulate an approval-gated turn
const session = new ApprovalSession(js, 2, Date.now()).start();
```
