## fake-jetstream.ts

An in-memory simulation of a NATS JetStream server, used as a drop-in replacement for `nats.ws`'s `connect()` function to drive real `DialogSubscription` logic in tests without a live NATS server. It simulates only the server-side behavior needed by the consumer-creation options the client library passes (`by_start_sequence` vs `new` delivery policies, retention limits with max-age, and `pending` message counts).

## Key Components

- **`FakeJetStream`** — The main test double. Exposes:
  - `publish(subject, payload)` — stores a message and delivers it to matching live consumers.
  - `publishNoise(count)` — burns sequence numbers on an unrelated subject, simulating shared-stream traffic.
  - `disconnectAll()` — simulates server-side connection drops, ending all active consumers.
  - `reset()` — clears stream state while preserving the instance (mirrors the lib's one-connection-per-URL reuse).
  - `connect` — the `nats.ws`-compatible `connect()` replacement, returning a fake connection with `jetstream().consumers.get(...)`.
  - `consumeDelayMs` — configurable latency before backlog delivery, for testing timing-sensitive consumption paths.
  - `createdConsumers` — records every `ServerConsumerConfig` created, for assertions on consumer setup.
- **`serverConfig(name, opts)`** — Translates client-provided consumer options into a `ServerConsumerConfig`, choosing `new` or `by_start_sequence` delivery policy.
- **`ServerConsumerConfig`** — Shape of a simulated JetStream consumer configuration.
- **`Queue<T>`** — Internal async pull-queue used to model both message delivery and status events, supporting `close()` to terminate iteration.

## Usage Example

```typescript
import { FakeJetStream } from './fake-jetstream';

const fakeJs = new FakeJetStream();

// Swap this in wherever the lib would call nats.ws's connect()
const nc = await fakeJs.connect();
const js = nc.jetstream();

const consumer = await js.consumers.get('CHAT_CHUNKS', {
  filterSubjects: 'chat.my-dialog.admin-message',
  deliver_policy: 'by_start_sequence',
  opt_start_seq: 1,
});

const sub = await consumer.consume();

// Publish a message that the live consumer will receive
fakeJs.publish('chat.my-dialog.admin-message', { type: 'TEXT', text: 'hello' });

for await (const msg of sub) {
  console.log(JSON.parse(new TextDecoder().decode(msg.data)));
  break;
}

// Simulate connection loss
fakeJs.disconnectAll();

// Reset state between test cases
fakeJs.reset();
```
