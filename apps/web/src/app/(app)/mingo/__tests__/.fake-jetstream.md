# fake-jetstream.ts

An in-memory simulation of NATS JetStream that replaces `nats.ws`'s `connect` function, used to drive the real `DialogSubscription` (and underlying lib client) in tests without a running NATS server.

Only the server-side behavior is simulated: `by_start_sequence` delivers all retained messages from `opt_start_seq` onward, `new` delivers nothing retained, retention follows `Limits` + `maxAge` (10 minutes for CHAT_CHUNKS), and each delivered message carries the `pending` count the real server would include in its reply subject. The exact translation of client options into a `CONSUMER.CREATE` call is pinned by running the actual `nats.ws` library code against this fake.

## Key Components

- **`FakeJetStream`** — Main class simulating the JetStream server. Holds published messages, tracks created consumers, and exposes a `connect` method compatible with `nats.ws`'s connection interface.
  - `publish(subject, payload)` — stores a message and delivers it to any live matching consumers.
  - `publishNoise(count)` — burns stream sequence numbers on an unrelated subject to simulate shared-stream traffic.
  - `disconnectAll()` — simulates a server-side connection drop, ending all live consumers.
  - `reset()` — clears state while preserving the instance (useful since the lib shares one connection per URL across tests).
  - `consumeDelayMs` — configurable latency between consumer creation and first delivered message.
  - `createdConsumers` — records every `ServerConsumerConfig` created, for assertions on consumer setup.
- **`ServerConsumerConfig`** — Shape of a server-side consumer configuration (`deliver_policy`, `opt_start_seq`, `filter_subject`).
- **`Queue<T>`** — Internal async pull-queue used to model NATS message/status iterators.

## Usage Example

```typescript
import { FakeJetStream } from './fake-jetstream';

const fakeNats = new FakeJetStream();

// Swap this in wherever the app calls nats.ws's `connect`
const connectFn = fakeNats.connect;

// Seed retained messages before a consumer starts from a given sequence
fakeNats.publish('chat.dialog-1.admin-message', { type: 'TEXT', text: 'hello' });

// Simulate unrelated stream traffic affecting sequence numbers
fakeNats.publishNoise(5);

// Simulate a server-side disconnect mid-test
fakeNats.disconnectAll();

// Reset state between test cases while reusing the same instance
fakeNats.reset();

// Inspect what consumer configs the client actually created
expect(fakeNats.createdConsumers[0].deliver_policy).toBe('by_start_sequence');
```
