## context-types.ts

Defines the shared type system for Mingo's entity-context feature — the mechanism that lets chat messages reference entities (devices, tickets, scripts, etc.) via `@mention` tokens or an explicit context picker. This file is the single source of truth tying together the backend's `ContextItemType` enum, its mention markers, and Relay typename mappings needed for client-side re-fetching.

## Key Components

- **`CONTEXT_ENTITY_KIND`** — Const object enumerating all supported context kinds (`DEVICE`, `SCRIPT`, `TICKET`, `ORGANIZATION`, `USER`, `KB_ARTICLE`, `KB_FOLDER`, `POLICY`, `QUERY`, `SCHEDULED_SCRIPT`, `INSIGHT`, `SOFTWARE`, `VULNERABILITY`), mirroring the backend's `ContextItemType` enum.
- **`ContextEntityKind`** — Union type derived from `CONTEXT_ENTITY_KIND` values.
- **`CONTEXT_ENTITY_KINDS`** — Runtime array of all kinds, in declaration order.
- **`CONTEXT_ENTITY_MARKER`** — Maps each kind to its backend inline `@marker:id` token (e.g. `KB_ARTICLE` → `kb`, `SCHEDULED_SCRIPT` → `scheduledScript`).
- **`CONTEXT_RELAY_TYPENAME`** — Partial map from kind to Relay `__typename`, used to re-encode raw DB ids into Relay global ids for `node(id:)` fetches.
- **`ContextRef`** — Minimal wire shape (`{ type, id }`) sent in the `sendMessage` mutation payload.
- **`ContextRefWithLabel`** — `ContextRef` extended with `label` and optional `description`, used in UI (picker, chips, recent views).
- **`CONTEXT_ITEMS_MAX`** / **`RECENT_VIEWS_MAX`** — Numeric limits (10 and 5 respectively) enforced by the spec.

## Usage Example

```typescript
import {
  CONTEXT_ENTITY_KIND,
  CONTEXT_ENTITY_MARKER,
  type ContextEntityKind,
  type ContextRef,
  type ContextRefWithLabel,
  CONTEXT_ITEMS_MAX,
} from './context-types';

function buildMentionToken(kind: ContextEntityKind, id: string): string {
  return `@${CONTEXT_ENTITY_MARKER[kind]}:${id}`;
}

// e.g. "@device:abc123"
const token = buildMentionToken(CONTEXT_ENTITY_KIND.DEVICE, 'abc123');

// Enforcing picker limits
function addContext(items: ContextRefWithLabel[], newItem: ContextRefWithLabel) {
  if (items.length >= CONTEXT_ITEMS_MAX) {
    throw new Error('Context limit reached');
  }
  return [...items, newItem];
}

// Building the wire payload (label stripped)
function toWirePayload(items: ContextRefWithLabel[]): ContextRef[] {
  return items.map(({ type, id }) => ({ type, id }));
}
```

To add a new context kind, add an entry to `CONTEXT_ENTITY_KIND` and `CONTEXT_ENTITY_MARKER`, then wire its label/icon and fetcher in `context-sources.tsx`.
