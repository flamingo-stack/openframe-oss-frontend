## context-types.ts

Defines the shared type system for Mingo's entity-context feature — the set of entity "kinds" (devices, scripts, tickets, etc.) that can be attached to a chat message as context, along with their backend mention markers and Relay typename mappings.

This file is the **single source of truth** for context entity kinds: adding a new kind requires only one entry here (plus wiring its label/icon/fetcher in `context-sources.tsx`), and TypeScript's `Record<ContextEntityKind, …>` constraints will surface a compile error if an entry is missing elsewhere.

## Key Components

- **`CONTEXT_ENTITY_KIND`** — const object enumerating all supported context kinds (`DEVICE`, `SCRIPT`, `TICKET`, `ORGANIZATION`, `USER`, `KB_ARTICLE`, `KB_FOLDER`, `POLICY`, `QUERY`, `SCHEDULED_SCRIPT`, `INSIGHT`, `SOFTWARE`, `VULNERABILITY`), mirroring the backend's `ContextItemType` enum.
- **`ContextEntityKind`** — union type derived from `CONTEXT_ENTITY_KIND` values.
- **`CONTEXT_ENTITY_KINDS`** — runtime array of all kinds, in declaration order.
- **`CONTEXT_ENTITY_MARKER`** — maps each kind to its backend `@marker:id` inline-mention token (e.g., `KB_ARTICLE` → `kb`, `SCHEDULED_SCRIPT` → `scheduledScript`).
- **`CONTEXT_RELAY_TYPENAME`** — partial map from kind to Relay `__typename`, used to re-encode raw database ids into Relay global ids for `node(id:)` fetches (a temporary bridge until the backend speaks global ids end-to-end).
- **`ContextRef`** — minimal wire shape (`{ type, id }`) sent in the `sendMessage` mutation payload.
- **`ContextRefWithLabel`** — `ContextRef` extended with `label` and optional `description`, used for UI display (chips, dev window, recent-views store).
- **`CONTEXT_ITEMS_MAX`** / **`RECENT_VIEWS_MAX`** — numeric limits (10 and 5 respectively) per the context spec.

## Usage Example

```typescript
import {
  CONTEXT_ENTITY_KIND,
  CONTEXT_ENTITY_MARKER,
  CONTEXT_RELAY_TYPENAME,
  type ContextRef,
  type ContextRefWithLabel,
  CONTEXT_ITEMS_MAX,
} from './context-types';

// Build a wire-format context item for sendMessage
const contextItem: ContextRef = {
  type: CONTEXT_ENTITY_KIND.DEVICE,
  id: 'raw-device-id-123',
};

// Build an inline @-mention marker for message text
const marker = CONTEXT_ENTITY_MARKER[CONTEXT_ENTITY_KIND.KB_ARTICLE]; // 'kb'
const mentionToken = `@${marker}:${contextItem.id}`;

// Enforce the max context items before adding a new one
if (currentContextItems.length < CONTEXT_ITEMS_MAX) {
  currentContextItems.push(contextItem);
}

// Re-encode a raw id to a Relay global id before a node(id:) fetch
const typename = CONTEXT_RELAY_TYPENAME[CONTEXT_ENTITY_KIND.DEVICE]; // 'Machine'
```
