## Purpose

Renders a self-fetching "mention chip" for REST/GraphQL-backed entity types (`policy`, `query`, `script`, `ticket`). Each marker type has a dedicated async resolver that fetches a display name and route, degrading gracefully to the raw id (or a caller-provided `fallbackLabel`) if the lookup fails, so the chip never throws and always renders.

## Key Components

- **`RestMentionChip`** — Public entry point. Wraps the resolution flow in a `MentionErrorBoundary`, falling back to a static `MentionTag` (label = `fallbackLabel` or `id`) on hard failure.
- **`RestLoader` / `RestReader` / `RestInner`** — Internal Suspense pipeline. `RestLoader` wraps the chip in a `LoadingSuspense` scope so loading renders as an empty-label chip (not a text status) inline within prose. `RestInner` runs the actual `useSuspenseQuery` fetch and swaps in `fallbackLabel` when the resolver degrades to the bare id.
- **`RESOLVERS`** — Map of marker → async resolver function:
  - `resolvePolicy` — Fleet `getPolicy`, routes to `routes.monitoring.policy(id)`.
  - `resolveQuery` — Fleet `getQuery`, unwraps nested `{ query: { name } }`, routes to `routes.monitoring.query(id)`.
  - `resolveScript` — Legacy Tactical RMM script path; endpoint removed, so it always degrades to id + link (`routes.scripts.details(id)`). New scripts resolve via the separate Relay `GraphqlMentionChip`.
  - `resolveTicket` — GraphQL `ticket(id:)` query via `apiClient`, formats label with `formatTicketRef`, routes to `routes.tickets.dialog(id)`.
- **`Resolved`** — Shared resolver return shape: `{ label, href? }`.

## Usage Example

```typescript
import { RestMentionChip } from './rest-mention-chips';

// Inline inside rendered chat/message markup
<RestMentionChip
  marker="ticket"
  id="64f1c2a9b8e3..."
  fallbackLabel="Ticket #123"
/>

<RestMentionChip
  marker="policy"
  id="42"
/>
```

Dispatch by marker type typically happens in `render-mention.tsx`, which decides whether to render `RestMentionChip` (REST/legacy ids) or the Relay `GraphqlMentionChip` (new ObjectId-based entities) based on id shape.
