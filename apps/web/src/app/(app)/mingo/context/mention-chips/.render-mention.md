Renders inline mention tokens and attached context-item chips for the `<EmbeddableChat>` component, routing each `@marker:id` to a self-fetching entity chip (GraphQL or REST) based on entity type.

## Key Components

### `renderMingoMention({ marker, id, label? })`
Main dispatch function that maps a parsed mention token to the appropriate chip component. Routes GraphQL-resolved types (`device`, `organization`, `kb_article`, `script` via ObjectId) to `GraphqlMentionChip` and REST-resolved types (`policy`, `query`, `user`, `ticket`, legacy scripts) to `RestMentionChip`. Returns `null` for unknown markers, letting the lib render the raw token.

### `renderMingoContextItem(item: ChatContextItem)`
Adapter that bridges the structured context-item shape `{ type, id, label }` to `renderMingoMention`. Used as the `renderContextItem` prop on `<EmbeddableChat>`. Passes the picked display label as a fallback so chips never flash a bare ID on reload.

### `ICON_BY_MARKER`
Module-level `Map<string, ReactNode>` built from `MINGO_CONTEXT_ENTITY_TYPES` config, providing the lead icon for each marker without per-render recomputation.

### `OBJECT_ID_RE`
Regex `/^[0-9a-f]{24}$/i` used to distinguish new OpenFrame scripts (24-char Mongo ObjectId → Relay) from legacy Tactical scripts (numeric ID → REST).

## Usage Example

```typescript
// Wire both functions into <EmbeddableChat>
<EmbeddableChat
  renderMention={renderMingoMention}
  renderContextItem={renderMingoContextItem}
/>

// renderMingoMention is called by the lib for each parsed @marker:id token:
// @device:abc123   → <GraphqlMentionChip kind="DEVICE" .../>
// @ticket:42       → <RestMentionChip marker="ticket" .../>
// @script:507f...  → <GraphqlMentionChip kind="SCRIPT" .../>  (ObjectId)
// @script:1234     → <RestMentionChip .../>                   (legacy numeric)
```

> Both functions are module-level (not hooks) to guarantee stable reference equality across streaming re-renders — the lib's per-message memo depends on this.
