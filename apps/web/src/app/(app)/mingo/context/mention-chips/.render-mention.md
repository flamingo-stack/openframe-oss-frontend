## render-mention.tsx

Dispatch logic that renders inline `@marker:id` mention tokens and attached context chips inside `<EmbeddableChat>`. It routes each of the thirteen supported entity markers (plus the special `@chat:` conversation reference) to the appropriate self-fetching chip component, mirroring how `card://` markers route to entity cards.

## Key Components

- **`renderMingoMention({ marker, id, label })`** — Core dispatcher. Given a mention marker and id, returns the matching chip:
  - `@chat:` → `ChatReferenceChip` (opens a drawer, not a page — it's a memory reference, not an entity)
  - GraphQL-backed entities (device, organization, KB article/folder, scheduled script, insight, software, user) → `GraphqlMentionChip` via Relay
  - `vulnerability` → plain `MentionTag` linking to the vulnerability page (no fetch needed; CVE id is the name)
  - `script` → dual-sourced: 24-char ObjectId resolves via Relay (native script), otherwise via `RestMentionChip` (legacy Tactical script)
  - `policy` / `query` / `ticket` → `RestMentionChip` (REST/ai-agent backed)
  - Unknown marker → returns `null`, letting the chat lib fall back to the bare token
- **`renderMingoContextItem(item: ChatContextItem)`** — Bridges an attached context item (`{ type, id, label }`) to the same mention-rendering path by mapping its `type` to a marker and delegating to `renderMingoMention`, ensuring attached chips and inline mentions render identically.
- **`ICON_BY_MARKER`** — Map of marker → lead icon, sourced from `MINGO_CONTEXT_ENTITY_TYPES` plus mention-only additions (e.g. KB folder icon).
- **`OBJECT_ID_RE`** — Regex distinguishing native MongoDB ObjectIds (24-char hex) from legacy numeric Tactical ids, used for script id dispatch.

Both exported functions are defined at module scope (not hooks) to preserve stable reference identity, which the chat library's per-message memoization relies on across streaming updates.

## Usage Example

```typescript
import { renderMingoMention, renderMingoContextItem } from './render-mention';

// Rendering an inline mention parsed from message text, e.g. "@device:abc123"
const chip = renderMingoMention({ marker: '@device:', id: 'abc123' });

// Rendering a user-attached context chip
const contextChip = renderMingoContextItem({
  type: 'DEVICE',
  id: 'abc123',
  label: 'Workstation-07',
});

// Typically wired into <EmbeddableChat> configuration:
<EmbeddableChat
  renderMention={renderMingoMention}
  renderContextItem={renderMingoContextItem}
  // ...other props
/>
```
