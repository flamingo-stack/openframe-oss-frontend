## render-mention.tsx

Renders inline `@marker:id` mention tokens and attached context chips inside `<EmbeddableChat>`, dispatching each of the thirteen supported entity markers (plus `@chat:`) to the appropriate self-fetching chip component. It mirrors the `card://` → `renderEntityCard` pattern but for inline mentions.

## Key Components

- **`renderMingoMention({ marker, id, label })`** — Core dispatcher. Given a marker string and id, returns the correct `ReactNode`:
  - `CHAT_REFERENCE_MARKER` → `ChatReferenceChip` (opens an earlier conversation in the drawer, not a page)
  - GraphQL-backed entities (device, organization, kb article/folder, scheduled script, insight, software, user) → `GraphqlMentionChip` via Relay
  - `VULNERABILITY` → a plain linked `MentionTag` (CVE id is its own name, no fetch needed)
  - `SCRIPT` → dual-sourced: 24-char ObjectId resolves via `GraphqlMentionChip` (native), numeric id via `RestMentionChip` (legacy Tactical)
  - `POLICY`, `QUERY`, `TICKET` → `RestMentionChip`
  - Unknown marker → `null`, letting the lib fall back to the bare token
- **`renderMingoContextItem(item: ChatContextItem)`** — Bridges a structured `{ type, id, label }` context item to the marker-keyed mention path by mapping `item.type` to its marker and delegating to `renderMingoMention`, ensuring attached chips render identically to inline mentions.
- **`ICON_BY_MARKER`** — Map from marker to lead icon, built from the picker's entity-type config plus mention-only additions (e.g. KB folder).
- **`OBJECT_ID_RE`** — Regex distinguishing native Mongo ObjectIds (24-char hex) from legacy numeric Tactical script ids.

Both exports are plain module-level functions (not hooks) so they retain stable reference identity across renders, which the chat lib's per-message memoization depends on.

## Usage Example

```typescript
import { renderMingoMention, renderMingoContextItem } from './render-mention';

// Used as a renderer prop passed into the chat lib's inline mention parser:
<EmbeddableChat
  renderMention={({ marker, id, label }) => renderMingoMention({ marker, id, label })}
  renderContextItem={renderMingoContextItem}
/>

// Direct invocation example:
const chip = renderMingoMention({ marker: '@device:', id: 'abc123', label: 'Laptop-01' });
```
