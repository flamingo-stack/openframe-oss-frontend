## mention-tag.tsx

Renders the shared visual chip ("mention tag") used for inline entity references in chat messages, handling link navigation, new-tab affordance, and graceful fallback when per-type chip data fails to load.

## Key Components

- **`MentionTag`** — Renders an entity mention as an `InlineChip`. Behavior varies by props:
  - No `href`: renders a plain, non-clickable chip.
  - `href` present, same-window navigation only: wraps the chip in `NavLinkAnchorViaRuntime` so the chip behaves like any other chat link (keeps sidebar/composer, supports Back navigation).
  - `href` present and new-tab opening is supported (`useSameWindowLinks` returns `false`): renders a two-segment control — a main link segment (navigates in place) plus a trailing segment with `ExternalLinkIcon` (opens the same `href` in a new tab via `openIn="new-tab"`), each with independent hover styling.
- **`MentionErrorBoundary`** — Class component error boundary that catches fetch/render errors in a per-type mention chip and renders a `fallback` (typically a plain id chip) instead of crashing the whole chat message.
- **`CHIP_CLASS` / `SEGMENT_HOVER_CLASS` / `MAIN_SEGMENT_CLASS` / `NEW_TAB_SEGMENT_CLASS`** — Internal style constants controlling chip max-width and the visual seam between the two clickable segments.

## Usage Example

```typescript
import { MentionTag, MentionErrorBoundary } from './mention-tag';
import { routes } from '@/app/routes';

// Basic resolved mention chip linking to an entity detail page
<MentionTag
  icon={<UserIcon />}
  label="Jane Doe"
  href={routes.users.detail('123')}
/>

// Wrapping a per-type chip (e.g. a user mention) so a fetch failure
// degrades to a plain id chip instead of breaking the message
<MentionErrorBoundary fallback={<MentionTag label="user:123" />}>
  <UserMentionChip userId="123" />
</MentionErrorBoundary>
```

This component is typically consumed by per-type mention chip implementations (e.g. user, ticket, or asset mentions) rather than used directly for raw text—callers provide the resolved `icon`/`label`/`href`, while `MentionTag` handles consistent styling and navigation semantics.
