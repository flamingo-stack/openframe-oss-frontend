## relay-mention-chips.tsx

Self-fetching React/Relay components that render `@marker:id` mention chips (device, organization, user, KB article/folder, script, script schedule, insight, software) by resolving each entity's display name from the GraphQL store, falling back to the raw id on error.

## Key Components

- **`GraphqlMentionChip`** — Public entry point. Converts the raw db id to a Relay global id (where required per entity type), wraps the fetch in `MentionErrorBoundary`, and renders a loading chip while data streams in.
- **`GraphqlMentionLoader` / `GraphqlMentionReader`** — Internal suspense/read boundary: draws an inline skeleton chip (no visible "loading" text) while the query resolves, then reads the resolved entity.
- **`NodeInner`, `KbInner`, `ScriptInner`, `ScheduleInner`, `InsightInner`, `SoftwareInner`** — Per-entity-type renderers, each backed by its own `useLazyLoadQuery` call (`NODE_QUERY`, `KB_QUERY`, `SCRIPT_QUERY`, `SCHEDULE_QUERY`, `INSIGHT_QUERY`, `SOFTWARE_QUERY`) using `fetchPolicy: 'store-or-network'` to avoid flashing on Relay store remounts.
- **`innerFor(kind)`** — Dispatches to the correct `*Inner` renderer based on `ContextEntityKind`.
- **`hrefFor(kind, rawId, globalId)`** — Builds the detail-page URL per entity type; device/organization/software/user routes use the raw id, while KB/script/schedule/insight routes use the Relay global id.

## Usage Example

```typescript
import { GraphqlMentionChip } from './relay-mention-chips';
import { CONTEXT_ENTITY_KIND } from '../context-types';

function MessageBody() {
  return (
    <p>
      See device{' '}
      <GraphqlMentionChip
        kind={CONTEXT_ENTITY_KIND.DEVICE}
        id="machine-123"
        fallbackLabel="Unknown device"
      />{' '}
      for details, referenced in{' '}
      <GraphqlMentionChip kind={CONTEXT_ENTITY_KIND.KB_ARTICLE} id="kb-456" />.
    </p>
  );
}
```

Each chip suspends independently on first fetch, showing an inline skeleton, then resolves to a named, linked tag (or a plain id/fallback-label chip if the entity can't be found).
