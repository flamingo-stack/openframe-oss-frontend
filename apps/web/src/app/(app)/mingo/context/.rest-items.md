# rest-items.tsx

Client-side React components that fetch Mingo AI chat "context item" lists (tickets, policies, queries) for the context picker, using TanStack Query suspense hooks. Each component suspends while loading its initial page and throws on error so the parent picker can render a skeleton or error boundary respectively.

## Key Components

- **`TicketItems`** — Fetches tickets via GraphQL (`/chat/graphql`), using cursor-based pagination with `useSuspenseInfiniteQuery`. Supports search and "load more" via `hasNextPage`/`fetchNextPage`.
- **`PolicyItems`** — Fetches policies from the Fleet REST API with server-side search. Loads the full result set via `useSuspenseQuery`, then applies client-side pagination through `useClientPaging`.
- **`QueryItems`** — Fetches saved queries from the Fleet REST API with server-side search and `page`/`per_page` pagination, using `useSuspenseInfiniteQuery`.
- **`fetchTicketsPage`**, **`fetchPolicies`**, **`fetchQueriesPage`** — Internal async fetchers that call the respective API clients and normalize responses into `ChatContextItem[]`.

All three components share the same props shape (`ContextItemsProps`: `query`, `selectedKeys`, `onToggle`, `atLimit`) and render results via the shared `ContextItemsList` UI component.

## Usage Example

```typescript
import { Suspense } from 'react';
import { TicketItems, PolicyItems, QueryItems } from './rest-items';

function ContextPickerPanel({ entityKind, query, selectedKeys, onToggle, atLimit }) {
  return (
    <Suspense fallback={<ContextItemsSkeleton />}>
      {entityKind === 'ticket' && (
        <TicketItems
          query={query}
          selectedKeys={selectedKeys}
          onToggle={onToggle}
          atLimit={atLimit}
        />
      )}
      {entityKind === 'policy' && (
        <PolicyItems
          query={query}
          selectedKeys={selectedKeys}
          onToggle={onToggle}
          atLimit={atLimit}
        />
      )}
      {entityKind === 'query' && (
        <QueryItems
          query={query}
          selectedKeys={selectedKeys}
          onToggle={onToggle}
          atLimit={atLimit}
        />
      )}
    </Suspense>
  );
}
```

Note the `TicketItems` component preserves the raw `ticketId` (not a global ID) as the item's `id`, since the chat backend matches `@ticket:<id>` mentions literally against that raw identifier.
