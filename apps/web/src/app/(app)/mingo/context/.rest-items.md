Provides React suspense-based data fetching components for Mingo's chat context picker, surfacing selectable Tickets, Policies, and Queries from a mix of GraphQL and Fleet REST APIs. Each component renders a `ContextItemsList` and integrates with TanStack Query's suspense hooks so loading and error states are handled by the parent picker (skeleton / error boundary) rather than locally.

## Key Components

- **`TicketItems`** — Fetches tickets via GraphQL (`/chat/graphql`) using `useSuspenseInfiniteQuery` with cursor-based pagination (`pageInfo.endCursor`/`hasNextPage`). Maps ticket nodes to `ChatContextItem`, using the raw `ticketId` (required for `@ticket:<id>` mention matching) and a formatted label via `formatTicketRef`.
- **`PolicyItems`** — Fetches the full policy list from Fleet REST (`fleetApiClient.getPolicies`) via `useSuspenseQuery`, with server-side search but client-side pagination through the shared `useClientPaging` hook.
- **`QueryItems`** — Fetches queries from Fleet REST (`fleetApiClient.getQueries`) via `useSuspenseInfiniteQuery`, using server-side `page`/`per_page` pagination driven by response length compared to `MINGO_CONTEXT_PAGE_SIZE`.
- **`fetchTicketsPage`, `fetchPolicies`, `fetchQueriesPage`** — Internal async fetchers that call the respective APIs, throw on error, and normalize results into `ChatContextItem[]`.

All three components share the `ContextItemsProps` interface (`query`, `selectedKeys`, `onToggle`, `atLimit`) and render through the shared `ContextItemsList` UI component.

## Usage Example

```typescript
import { Suspense } from 'react';
import { TicketItems, PolicyItems, QueryItems } from './rest-items';

function ContextPickerPanel({ kind, query, selectedKeys, onToggle, atLimit }: PanelProps) {
  return (
    <Suspense fallback={<PickerSkeleton />}>
      {kind === 'ticket' && (
        <TicketItems query={query} selectedKeys={selectedKeys} onToggle={onToggle} atLimit={atLimit} />
      )}
      {kind === 'policy' && (
        <PolicyItems query={query} selectedKeys={selectedKeys} onToggle={onToggle} atLimit={atLimit} />
      )}
      {kind === 'query' && (
        <QueryItems query={query} selectedKeys={selectedKeys} onToggle={onToggle} atLimit={atLimit} />
      )}
    </Suspense>
  );
}
```

Each component should be wrapped in a `Suspense` boundary (for loading) and an error boundary (for fetch failures) by the consuming picker component.
