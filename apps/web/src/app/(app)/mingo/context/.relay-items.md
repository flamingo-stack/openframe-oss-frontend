## relay-items.tsx

Relay-powered React components that supply paginated, searchable lists of context entities (Devices, Organizations, Users, Knowledge Articles, Knowledge Folders, Scripts, Script Schedules, Incidents, Software, Vulnerabilities) for the Mingo AI chat context picker. Each entity type is backed by a GraphQL connection on the app's own `/api/graphql` endpoint and uses idiomatic Relay cursor pagination (`@refetchable` + `@connection` + `useLazyLoadQuery`/`usePaginationFragment`) instead of manual cursor/`hasMore` tracking.

## Key Components

- **`DeviceItems`** — Lists ONLINE/OFFLINE devices only (via `DEFAULT_DEVICES_LIST_STATUSES`), using `getDeviceName` for display labels and decoding the Relay global ID to the raw device ID expected by the backend context resolver.
- **`OrganizationItems`** — Lists organizations with name/category, decoding the raw `organizationId`.
- **`UserItems`** — Lists users via the shared `userSummaryFields_user` fragment and `toUserSummary` helper, showing name/email.
- Additional fragments/queries (`relayItemsKb_query`, `relayItemsKbFolders_query`, `relayItemsScripts_query`, `relayItemsSchedules_query`, `relayItemsIncidents_query`, `relayItemsSoftware_query`, `relayItemsVulnerabilities_query`) back equivalent list components for the other entity kinds (truncated in this excerpt).
- Each component follows the same pattern: a `@refetchable` GraphQL fragment with `@connection`, a root list query via `useLazyLoadQuery` (suspends on first load), `usePaginationFragment` for `loadNext`/`hasNext`/`isLoadingNext`, and rendering through the shared `ContextItemsList` UI.

## Usage Example

```typescript
import { Suspense } from 'react';
import { DeviceItems, OrganizationItems, UserItems } from './relay-items';

function ContextPicker({ query, selectedKeys, onToggle, atLimit }: ContextItemsProps) {
  return (
    <Suspense fallback={<PickerSkeleton />}>
      <DeviceItems
        query={query}
        selectedKeys={selectedKeys}
        onToggle={onToggle}
        atLimit={atLimit}
      />
      <OrganizationItems
        query={query}
        selectedKeys={selectedKeys}
        onToggle={onToggle}
        atLimit={atLimit}
      />
      <UserItems
        query={query}
        selectedKeys={selectedKeys}
        onToggle={onToggle}
        atLimit={atLimit}
      />
    </Suspense>
  );
}
```

Each component expects a `ContextItemsProps` object (`query`, `selectedKeys`, `onToggle`, `atLimit`) and must be rendered inside a `Suspense` boundary since the initial query uses `useLazyLoadQuery`.
