# render-context-items.tsx

Renders the item list for the active context entity type inside the chat's context picker. Acts as a dispatcher that maps an entity type (e.g., device, ticket, policy) to its dedicated items component, each of which fetches its own data via hooks.

## Key Components

- **`COMPONENTS`** — Internal lookup table mapping each `CONTEXT_ENTITY_KIND` value to its corresponding items component (`DeviceItems`, `OrganizationItems`, `KnowledgeBaseItems`, `KnowledgeBaseFolderItems`, `TicketItems`, `PolicyItems`, `QueryItems`, `UserItems`, `ScriptItems`, `ScheduleItems`, `IncidentItems`, `SoftwareItems`, `VulnerabilityItems`).
- **`renderMingoContextItems(args: ContextItemsRenderArgs): ReactNode`** — The exported render function wired into `ChatContextPickerConfig.renderItems`. Looks up the component for the given `type` and returns it as a JSX element, or `null` if the type is unrecognized.

## Usage Example

```typescript
import { renderMingoContextItems } from './render-context-items';
import type { ChatContextPickerConfig } from '@flamingo-stack/openframe-frontend-core/components/chat';

const contextPickerConfig: ChatContextPickerConfig = {
  renderItems: renderMingoContextItems,
  // ...other config options
};
```

The function is invoked internally by the chat library, inside a `<Suspense>` boundary with error handling, so the matched component may suspend while loading data:

```typescript
// Called internally with render args for the active entity type
renderMingoContextItems({
  type: CONTEXT_ENTITY_KIND.TICKET,
  query: '',
  selectedKeys: new Set(),
  onToggle: (key) => { /* toggle selection */ },
  atLimit: false,
});
```

**Important notes:**
- The returned JSX must be a rendered element (`<Component ... />`), not a direct function call, so React hooks inside the component behave correctly.
- `key={type}` ensures the component remounts when the entity type changes, isolating each type's internal hook state.
