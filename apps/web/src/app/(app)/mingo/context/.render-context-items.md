Dispatcher function for the chat context picker that maps entity types to their corresponding item list components.

## Key Components

- **`renderMingoContextItems`** — Main exported function implementing `ChatContextPickerConfig.renderItems`. Accepts `ContextItemsRenderArgs` and returns the appropriate items component as a JSX element for correct hook execution.
- **`COMPONENTS`** — Static lookup map from `CONTEXT_ENTITY_KIND` keys to their item renderer components (`DeviceItems`, `OrganizationItems`, `KnowledgeBaseItems`, `TicketItems`, `PolicyItems`, `QueryItems`, `UserItems`).
- **Script context** — `CONTEXT_ENTITY_KIND.SCRIPT` routes to `ScriptItems` (Relay-based, active scripts only), same as every other source in the map.

## Usage Example

```typescript
// Passed as the renderItems callback in ChatContextPickerConfig
const pickerConfig: ChatContextPickerConfig = {
  renderItems: renderMingoContextItems,
};

// Called internally by the lib inside its <Suspense> + error boundary:
// renderMingoContextItems({ type: 'device', query: 'laptop', selectedKeys: new Set(), onToggle, atLimit: false })
// → <DeviceItems key="device" query="laptop" selectedKeys={...} onToggle={...} atLimit={false} />
```

## Notes

- Returns the component as a **JSX element** (not a direct function call) so each component's hooks execute in the correct React context.
- `key={type}` ensures full remount and isolated hook state when the user switches entity types.
- Designed to suspend on initial load — safe to use inside `<Suspense>` boundaries.
