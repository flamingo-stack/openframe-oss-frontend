## page-context.ts

Resolves a URL (pathname + query) into the page context sent with a Mingo chat message, describing which page the user is on (`currentPage`) and, if it's a list page, which list and filters are active (`currentList`). Context is derived entirely from the URL at send time rather than reported by individual pages, since list filters already live in query params via `useApiParams`.

## Key Components

- **`PAGE_CONTEXT_LIMITS`** — Size limits (title, section, search, filters, field, value counts/lengths) enforced before sending context to the ai-agent.
- **`PageContext`** — Shape of the resolved context: `currentPage` (always present) and optional `currentList`.
- **`LIST_PAGES`** — Maps known list page pathnames to their module, nav id, optional section (e.g. archive), and default tab filter.
- **`ENTITY_PAGES`** — Maps detail page pathnames to the `ContextEntityKind` they represent (device, ticket, script, etc.).
- **`NAMED_PAGES`** — Maps special routes (dashboard, Mingo home/archive, approvals, notifications) to fixed `MessagePageRef` objects.
- **`resolvePageContext(href, openView)`** — Main resolver: inspects pathname/query against the lookup tables above (list, entity, settings, monitoring, or fallback "OTHER") and returns a `PageContext`. Uses `openView` to title entity pages like `"Device: MacBook"`.
- **`pageContextHref(location, lastPage, phone?)`** — Determines which URL to treat as "the page" when the user is on the Mingo chat page itself (chat is about the page it was opened from, or Mingo's home).
- **`isMingoHomeHref(href)`** — Checks whether a given href is Mingo's home route (no page context to report).

## Usage Example

```typescript
import { resolvePageContext, pageContextHref, isMingoHomeHref } from './page-context';

// Resolve context for the current location when sending a chat message
const href = pageContextHref(
  { pathname: location.pathname, search: location.search },
  lastPage,
);

if (!isMingoHomeHref(href)) {
  const { currentPage, currentList } = resolvePageContext(href, openView);
  // currentPage: { kind: 'LIST', title: 'Devices' }
  // currentList: { module: 'DEVICES', filters: [...], search: '...' }
  sendMessage({ currentPage, currentList });
}
```
