# page-context.ts

Resolves a URL (pathname + query string) into structured page context that Mingo (the AI agent) uses to understand what page a user's chat message is about — including the page kind/title and, for list pages, the active module and filters read directly from the URL.

## Key Components

- **`PAGE_CONTEXT_LIMITS`** — Hard caps on title, section, search, filter field/value counts sent to the AI agent; messages exceeding these are rejected.
- **`PageContext`** — Shape combining `currentPage` (always present) and `currentList` (only for list pages).
- **`LIST_PAGES`** — Maps exact pathnames (e.g. `/devices`, `/tickets/archive`) to their list module, nav entry, optional section/variant, and default tab filter.
- **`ENTITY_PAGES`** — Maps detail-page pathnames to the `ContextEntityKind` they represent (e.g. `/devices/details` → `DEVICE`).
- **`NAMED_PAGES`** — Fixed routes (dashboard, Mingo home/archive, approvals, notifications) mapped directly to a `MessagePageRef`.
- **`resolvePageContext(href, openView)`** — Main resolver: given a URL and the currently tracked "open view" entity, returns the full `PageContext`, handling lists, entities, settings sub-pages, and fallback/unlisted pages (`OTHER`).
- **`pageContextHref(location, lastPage, phone?)`** — Determines which URL a chat message should be evaluated against, since the chat page itself has no inherent context and must borrow it from the page it was opened over (or Mingo's home as default).
- **`isMingoHomeHref(href)`** — Checks whether a given href is Mingo's home (i.e., no page-specific context applies).

## Usage Example

```typescript
import { resolvePageContext, pageContextHref, isMingoHomeHref } from './page-context';

// Resolve context for a devices list page with filters
const context = resolvePageContext('/devices?status=online&search=mac', null);
// => { currentPage: { kind: 'LIST', title: 'Devices' },
//      currentList: { module: 'DEVICES', filters: [...], search: 'mac' } }

// Resolve context for an entity detail page with an open view
const entityContext = resolvePageContext('/devices/details?id=123', {
  type: 'DEVICE',
  label: 'MacBook Pro',
});
// => { currentPage: { kind: 'ENTITY', title: 'Device: MacBook Pro' } }

// Determine the href a chat message should be scoped to
const href = pageContextHref(
  { pathname: '/mingo/chat', search: '' },
  '/tickets?tab=open',
);
// => '/tickets?tab=open'

isMingoHomeHref('/mingo/chat'); // => false, since it resolves to the opener page
```
