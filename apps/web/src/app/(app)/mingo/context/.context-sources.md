Defines the catalog of entity types ("context sources") selectable in Mingo's context picker, mapping each backend entity kind to its display label, mention marker, and icon, with a feature-flag-aware hook to filter the list.

## Key Components

- **`MINGO_CONTEXT_ENTITY_TYPES`** — Static, ordered array of `ChatContextEntityType` entries (Device, Script, Scheduled Script, Ticket, Organization, User, KB Article, KB Folder, Policy, Query, Insight, Software, Vulnerability). Each entry has `type` (backend discriminator), `label` (display name), `marker` (mention short form used for `@marker:id` tokens), and `icon` (24px glyph).
- **`ModuleFlag`** — Type alias narrowing `FeatureFlagName` to the subset (`'insights'`, `'software-management'`) that gate optional entity kinds.
- **`KIND_FLAG`** — Partial map from `ContextEntityKind` to the `ModuleFlag` required to show it; kinds absent from this map are always enabled.
- **`useMingoContextEntityTypes()`** — Hook that reads the relevant feature flags via `useFeatureFlag` and returns the filtered list of entity types available to the current user/tenant.

## Usage Example

```typescript
import { useMingoContextEntityTypes } from './context-sources';

function MingoContextPicker() {
  const entityTypes = useMingoContextEntityTypes();

  return (
    <ul>
      {entityTypes.map(entity => (
        <li key={entity.type}>
          {entity.icon}
          <span>{entity.label}</span>
        </li>
      ))}
    </ul>
  );
}
```

Each selected entity type's `marker` is used elsewhere to construct `@marker:id` mention tokens, which the backend's `MentionParser` resolves, and per-type components (e.g. `relay-items`, `rest-items`) fetch the actual data dispatched via `renderMingoContextItems`.
