# context-sources.tsx

Defines the Mingo AI chat context picker's entity-type list — the first-level selection menu for `@mentions` (devices, scripts, tickets, customers, etc.). Each entry pairs a backend discriminator type, a mention marker, and a display icon, with optional feature-flag gating.

## Key Components

- **`MINGO_CONTEXT_ENTITY_TYPES`** — Ordered array of `ChatContextEntityType` entries defining every context source offered in the picker (Device, Script, Script Schedule, Ticket, Customer, User, Knowledge Article, Knowledge Folder, Policy, Query, Incident, Software, Vulnerability). Each entry has `type` (backend discriminator), `label` (display text), `marker` (mention short form, e.g. `@device:id`), and `icon`.
- **`ModuleFlag`** — Type alias restricting module-gating flags to `'insights' | 'software-management'`.
- **`KIND_FLAG`** — Maps specific `ContextEntityKind` values to the feature flag that must be enabled for them to appear (Incident → `insights`; Software/Vulnerability → `software-management`).
- **`useMingoContextEntityTypes()`** — Hook that filters `MINGO_CONTEXT_ENTITY_TYPES` based on current feature-flag state, returning only entity types whose gating flag (if any) is enabled.

## Usage Example

```typescript
import { useMingoContextEntityTypes } from './context-sources';

function MentionPicker() {
  const entityTypes = useMingoContextEntityTypes();

  return (
    <ul>
      {entityTypes.map(entity => (
        <li key={entity.type}>
          {entity.icon}
          <span>{entity.label}</span>
        </li>
      ))}
    </ul>
  );
}
```

Each entity type's `marker` is used downstream to commit `@marker:id` mention tokens (e.g. `@device:123`), matching the backend's `MentionParser`. Actual data for each type is fetched by per-type components (`relay-items` / `rest-items`) and dispatched via `renderMingoContextItems`, while rendered mentions in chat are dispatched by `renderMingoMention` based on marker — independent of this list, so existing mentions still render even if their module flag is later disabled.
