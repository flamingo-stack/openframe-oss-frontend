Defines centralized, strongly-typed query key factories for the Mingo chat dialog list and single-dialog caches, used by React Query (or a similar caching layer) to ensure consistent key generation across hooks, mutations, and cache invalidation logic.

## Key Components

- **`mingoDialogQueryKeys`** — A frozen object exposing key-builder functions/constants:
  - **`lists`**: `['mingo-dialogs', 'list']` — static prefix matching all list queries (used for broad invalidation).
  - **`list(params)`**: Builds a scoped key `['mingo-dialogs', 'list', params]` from `{ search?, limit, scope }`, used for the actual paginated/filtered list query.
  - **`detail(dialogId)`**: Builds `['mingo-dialog', dialogId]` for a single dialog's metadata.
  - **`messages(dialogId)`**: Builds `['mingo-dialog-messages', dialogId]` for a dialog's message thread.

All keys use `as const` to preserve literal tuple types, enabling precise type inference when used with query clients.

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { mingoDialogQueryKeys } from './query-keys';

// Fetching the dialog list
function useDialogList(params: { search?: string; limit: number; scope: string }) {
  return useQuery({
    queryKey: mingoDialogQueryKeys.list(params),
    queryFn: () => fetchDialogs(params),
  });
}

// Fetching a single dialog's messages
function useDialogMessages(dialogId: string | null) {
  return useQuery({
    queryKey: mingoDialogQueryKeys.messages(dialogId),
    queryFn: () => fetchMessages(dialogId),
  });
}

// Invalidating all list queries after creating a new dialog
function useInvalidateDialogLists() {
  const queryClient = useQueryClient();
  return () =>
    queryClient.invalidateQueries({ queryKey: mingoDialogQueryKeys.lists });
}
```

**Note:** Invalidation should target `mingoDialogQueryKeys.lists` rather than a raw `['mingo-dialogs']` prefix, since the incident dialogs feature shares that top-level namespace.
