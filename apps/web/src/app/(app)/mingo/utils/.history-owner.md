## history-owner.ts

Adapts a GraphQL message owner's user avatar into the format expected by the shared history processor, resolving the image URL to an absolute gateway URL that includes the image hash for cache-busting.

## Key Components

- **`toHistoryOwner(owner)`** — Transforms a `GraphQlMessage['owner']` object into a `HistoricalMessage['owner']` object. It specifically rewrites the nested `user.image.imageUrl` field by resolving it (along with its `hash`) into a full, absolute URL via `getFullImageUrl`. If the owner has no `user` or no `image`, the owner is returned unchanged.

## Usage Example

```typescript
import { toHistoryOwner } from './history-owner';
import type { GraphQlMessage } from '../types';

function mapMessageToHistoryItem(message: GraphQlMessage) {
  return {
    ...message,
    owner: toHistoryOwner(message.owner),
  };
}

// Example input/output
const owner: GraphQlMessage['owner'] = {
  user: {
    image: { imageUrl: '/images/avatar.png', hash: 'abc123' },
  },
};

const historyOwner = toHistoryOwner(owner);
// historyOwner.user.image.imageUrl is now an absolute gateway URL,
// e.g. "https://gateway.example.com/images/avatar.png?hash=abc123"
```

This utility is typically used when converting raw GraphQL message data into the `HistoricalMessage` shape consumed by the shared `@flamingo-stack/openframe-frontend-core` history processor, ensuring avatars render correctly without requiring the processor itself to know about image hashing.
