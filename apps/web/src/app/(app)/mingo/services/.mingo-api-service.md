React Query mutation hooks for Mingo AI chat operations, providing a typed interface to the chat service REST API for dialog management, message sending, and approval workflows.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `CreateDialogResponse` | Response shape for a newly created chat dialog |
| `SendMessageRequest` | Request payload including optional entity context refs (`contextItems`, `currentView`, `recentViews`) |
| `MessageContextRef` | Minimal entity reference (`type` + `id`) attached to messages |
| `ApprovalResponse` | Response for approve/reject actions with status and timestamp |

### Mutation Hooks

| Hook | Endpoint | Description |
|---|---|---|
| `useCreateDialogMutation` | `POST /chat/api/v1/dialogs` | Creates a new `ADMIN_AI_CHAT` dialog session |
| `useSendMessageMutation` | `POST /chat/api/v1/messages` | Sends a message with optional entity context (max 10 context items, 5 recent views) |
| `useApproveRequestMutation` | `POST /chat/api/v1/approval-requests/:id/approve` | Approves a pending AI action request; shows destructive toast on error |
| `useRejectRequestMutation` | `POST /chat/api/v1/approval-requests/:id/approve` | Rejects a pending AI action request; shows destructive toast on error |
| `useStopGenerationMutation` | `POST /chat/api/v1/dialogs/:id/stop` | Cancels active AI response generation for a dialog |

## Usage Example

```typescript
import {
  useCreateDialogMutation,
  useSendMessageMutation,
  useApproveRequestMutation,
} from './mingo-api-service';

function MingoChat() {
  const createDialog = useCreateDialogMutation();
  const sendMessage = useSendMessageMutation();
  const approveRequest = useApproveRequestMutation();

  const handleStartChat = async () => {
    const dialog = await createDialog.mutateAsync();

    await sendMessage.mutateAsync({
      dialogId: dialog.id,
      content: 'Show me all open tickets',
      currentView: { type: 'ticket', id: 'ticket-123' },
      contextItems: [{ type: 'client', id: 'client-456' }],
    });
  };

  const handleApprove = (requestId: string) => {
    approveRequest.mutate(requestId);
  };
}
```

> **Context fields** (`contextItems`, `currentView`, `recentViews`) are omitted from the request payload when empty, preserving backward compatibility with legacy message shapes.
