Provides a set of React Query mutation hooks that wrap the `ticketService` for interacting with Mingo's AI chat agent, covering dialog creation, message sending, generation control, and approval workflows (admin chat context).

## Key Components

- **`useCreateDialogMutation()`** — Creates a new admin chat dialog, optionally scoped to an `insightId` (incident context) or a `DialogIntent` (entity-creation greeting). Resolves to the new dialog id.
- **`CreateMingoDialogOptions`** — Interface for optional dialog creation parameters (`insightId`, `intent`).
- **`useSendMessageMutation()`** — Sends a text message to an existing dialog, including additional `SendMessageContext` fields, using `CHAT_TYPE.ADMIN`.
- **`useStopGenerationMutation()`** — Stops an in-progress AI response generation for a given dialog.
- **`useApproveRequestMutation()`** — Approves an approval request; shows a destructive toast on failure.
- **`useRejectRequestMutation()`** — Rejects an approval request; shows a destructive toast on failure.

## Usage Example

```typescript
import {
  useCreateDialogMutation,
  useSendMessageMutation,
  useApproveRequestMutation,
} from './mingo-api-service';

function MingoChatPanel() {
  const createDialog = useCreateDialogMutation();
  const sendMessage = useSendMessageMutation();
  const approveRequest = useApproveRequestMutation();

  const startChat = async (insightId?: string) => {
    const dialogId = await createDialog.mutateAsync({ insightId });
    await sendMessage.mutateAsync({
      dialogId,
      content: 'What is the status of this incident?',
    });
  };

  const handleApprove = (requestId: string) => {
    approveRequest.mutate(requestId);
  };

  return null; // render chat UI using mutation state (isPending, data, error)
}
```

Each hook returns a standard `@tanstack/react-query` mutation object (`mutate`, `mutateAsync`, `isPending`, `data`, `error`), enabling consumers to compose loading and error states directly in their components.
