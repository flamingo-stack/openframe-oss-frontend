TypeScript interfaces for a Mingo chat message as the GraphQL API answers it. In memory a message is the lib's `ChatMessage` (`{ id, role, metadata?, parts }`, from `chat-protocol`), read through its one decoder; nothing here is the UI model.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GraphQlMessage` | Interface | Raw message from the GraphQL API, including `dialogId`, `chatType`, `owner`, `lastChunkStreamSeq` and `messageData`, typed as the lib's `MessageData` union |
| `MessageConnection` | Interface | Relay-style paginated edge/node wrapper around `GraphQlMessage` |
| `MessagesResponse` | Interface | Top-level GraphQL response envelope containing a `MessageConnection` |
| `MessagePage` | Interface | Flattened page result used after unwrapping the connection: a flat `messages` array plus `pageInfo` |
