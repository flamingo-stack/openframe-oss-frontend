# message.types.ts

Type definitions and type guards for chat messages, bridging the GraphQL API shape (`GraphQlMessage`) with the shared library's message model (`CoreMessage`/`Message`) used throughout the mingo chat feature.

## Key Components

- **`GraphQlMessage`** — Raw message shape as returned by the chat GraphQL API, including `owner` (with user/image metadata) and `messageData` (typed as the library's `MessageData` union for single or batched payloads).
- **`CoreMessage`** — Type alias directly referencing the library's `Message` type (not a re-declaration), ensuring mirrored reducer state stays assignable without casts.
- **`Message`** — Public alias of `CoreMessage` for mingo-facing code.
- **`MessageConnection`** — Relay-style paginated connection (`edges`/`pageInfo`) wrapping `GraphQlMessage` nodes.
- **`MessagesResponse`** — Top-level GraphQL response envelope containing `data.messages` and optional `errors`.
- **`MessagePage`** — Flattened page shape (`messages` array + `pageInfo`) used internally after unwrapping the GraphQL edges.
- **`isGraphQlMessage(message)`** — Type guard checking for the `messageData` field to narrow to `GraphQlMessage`.
- **`isCoreMessage(message)`** — Type guard checking for the `content` field to narrow to `CoreMessage`.

## Usage Example

```typescript
import { isGraphQlMessage, isCoreMessage, type Message, type GraphQlMessage } from './message.types';

function renderMessage(message: Message | GraphQlMessage) {
  if (isGraphQlMessage(message)) {
    // message.messageData is MessageData | MessageData[]
    console.log('GraphQL message from dialog:', message.dialogId);
  } else if (isCoreMessage(message)) {
    // message.content available from lib Message type
    console.log('Core message content:', message.content);
  }
}
```

Use `GraphQlMessage` when working directly with API responses (e.g., `MessagesResponse`, `MessageConnection`), and `CoreMessage`/`Message` when interacting with shared reducer state or UI components that expect the library's canonical `Message` shape.
