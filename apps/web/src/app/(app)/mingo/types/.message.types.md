Defines TypeScript interfaces and type guards for the chat message domain, bridging GraphQL API responses with the core UI message model.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GraphQlMessage` | Interface | Raw message shape returned from the GraphQL API, including `dialogId`, `chatType`, `owner`, and untyped `messageData` |
| `CoreMessage` | Interface | Normalized UI message with typed `content`, `role`, optional `streamSeq` for realtime deduplication, and `contextItems` for composer context chips |
| `Message` | Type alias | Alias for `CoreMessage`; use this as the canonical message type in UI components |
| `MessageConnection` | Interface | Relay-style paginated edge/node wrapper around `GraphQlMessage` |
| `MessagesResponse` | Interface | Top-level GraphQL response envelope containing a `MessageConnection` |
| `MessagePage` | Interface | Flattened page result used after unwrapping the connection — flat `messages` array plus `pageInfo` |
| `isGraphQlMessage` | Type guard | Returns `true` if the value has a `messageData` property (GraphQL origin) |
| `isCoreMessage` | Type guard | Returns `true` if the value has a `content` property (UI model origin) |

## Usage Example

```typescript
import {
  isGraphQlMessage,
  isCoreMessage,
  type Message,
  type GraphQlMessage,
} from './message.types';

function processMessage(raw: GraphQlMessage): Message {
  if (isGraphQlMessage(raw)) {
    return {
      id: raw.id,
      role: 'assistant',
      content: raw.messageData.content,
      streamSeq: raw.lastChunkStreamSeq ?? undefined,
    };
  }
  throw new Error('Unexpected message shape');
}

// Type guard usage
function handleUnknown(msg: unknown) {
  if (isCoreMessage(msg)) {
    console.log(msg.content); // typed as MessageContent
  }
}
```
