# dialog.types.ts

TypeScript type definitions for Mingo AI dialog (chat) entities, modeling GraphQL responses for dialog/conversation data, including ownership (client machine vs. admin user), streaming state, pending approvals, and token usage metrics.

## Key Components

- **`DialogTokenUsage`** — Per-chat-type token consumption metrics (input/output/total/context sizes).
- **`DialogStreamState`** — Union type for whether a dialog is `'IDLE'` or actively `'STREAMING'`.
- **`DialogNode`** — Core dialog entity: relay `id` vs. raw `dialogId`, title, status, owner (client machine or admin user via union), timestamps (`createdAt`, `lastActivityAt`, `resolvedAt`, `aiResolutionSuggestedAt`), pending approval, rating, and token usage.
- **`DialogEdge`** / **`DialogConnection`** — Relay-style cursor pagination wrappers around `DialogNode`.
- **`DialogsResponse`** — GraphQL response type for the dialog list query (`dialogs` connection).
- **`DialogResponse`** — GraphQL response type for a single `dialog(id:)` query; `dialog` is `null` when inaccessible or nonexistent.
- **`UseMingoDialogsOptions`** — Options for the dialogs-list hook: `enabled`, `search`, `limit`, and `scope` (`'my'` vs `'all'`, mapped to the server's `ChatScope` enum).

## Usage Example

```typescript
import type {
  DialogNode,
  DialogsResponse,
  DialogResponse,
  UseMingoDialogsOptions,
} from './dialog.types';

function renderDialogTitle(node: DialogNode): string {
  const ownerLabel =
    node.owner?.type === 'CLIENT'
      ? node.owner.machine?.hostname
      : node.owner?.user?.firstName;
  return `${node.title} (${ownerLabel ?? 'unknown'})`;
}

function fetchDialogs(options: UseMingoDialogsOptions) {
  // options.scope maps to DialogFilterInput.scope on the server
  return queryDialogs({ scope: options.scope ?? 'my', limit: options.limit ?? 20 });
}

function handleSingleDialog(response: DialogResponse) {
  if (!response.data?.dialog) {
    // id resolved to nothing accessible — not an error
    return;
  }
  console.log(response.data.dialog.streamState);
}
```

## Notes

- Use `dialogId` (not the relay `id`) when referencing dialogs in NATS subjects, notifications, REST calls, or the `?mingoDialog=` query param.
- `owner` is a GraphQL union — inspect `owner.type` to discriminate between `CLIENT` (machine fields) and `ADMIN` (user fields) before accessing nested properties.
- `lastActivityAt` falls back to `createdAt` when no messages exist and determines chat list ordering.
