# use-mingo-quick-actions.ts

A React hook that supplies the quick-action chips shown in Mingo's chat empty state, dynamically switching between Product Hub defaults and org-customized actions based on admin configuration.

## Key Components

- **`useMingoQuickActions()`** — Main hook returning `{ actions: AiQuickAction[]; loading: boolean }`.
  - Reads the admin AI config via `useAdminAiConfig()` to determine `quickActionsIsDefault` (defaults to `true` if unset).
  - When defaults are enabled: fetches OpenFrame's default quick actions for the `mingo` agent from the Product Hub via `useHubDefaultQuickActions('mingo', { enabled: isDefault })`.
  - When defaults are disabled: returns the org's customized actions directly from `config.quickActions` (the same data edited in the AI Settings "Mingo AI Chat" tab).
  - `loading` reflects both the admin config load state and, when applicable, the Hub defaults fetch state.

## Usage Example

```typescript
import { useMingoQuickActions } from './use-mingo-quick-actions';

function MingoChatEmptyState() {
  const { actions, loading } = useMingoQuickActions();

  if (loading) {
    return <ChipRowSkeleton />;
  }

  return (
    <div className="quick-actions-row">
      {actions.map((action) => (
        <QuickActionChip key={action.id} action={action} />
      ))}
    </div>
  );
}
```

## Notes

- This hook is client-side only (`'use client'` directive required for Next.js App Router).
- The data source toggle (`quickActionsIsDefault`) is controlled entirely by the tenant admin configuration — no local state is needed.
- When org customization is active, `loading` is always `false` since the data comes directly from the already-fetched admin config.
