# use-mingo-quick-actions.ts

A React hook that resolves the set of quick-action chips shown in Mingo's chat empty state, choosing between OpenFrame's default actions and an organization's customized actions based on admin configuration.

## Key Components

- **`useMingoQuickActions()`** — Hook returning `{ actions: AiQuickAction[]; loading: boolean }`. It:
  - Reads the admin AI config via `useAdminAiConfig()` to determine `quickActionsIsDefault` (defaults to `true` when unset).
  - When defaults are enabled, fetches OpenFrame's built-in quick actions for the `mingo` agent via `useHubDefaultQuickActions('mingo', { enabled: isDefault })`, sourced from the Product Hub's `agent-mingo` public config through the gateway's `/chat/content/**` proxy.
  - When defaults are disabled, returns the organization's customized `quickActions` from the tenant backend config — the same data edited in the AI Settings "Mingo AI Chat" tab.
  - Combines loading states appropriately: loading is `true` while either the admin config or the hub defaults (when applicable) are still being fetched.

## Usage Example

```typescript
import { useMingoQuickActions } from './use-mingo-quick-actions';

function MingoChatEmptyState() {
  const { actions, loading } = useMingoQuickActions();

  if (loading) {
    return <ChipRowSkeleton />;
  }

  return (
    <div className="quick-actions-row">
      {actions.map((action) => (
        <QuickActionChip key={action.id} action={action} />
      ))}
    </div>
  );
}
```

This hook is intended for use within Mingo's chat UI to render a dynamic, admin-configurable row of suggested actions without the consuming component needing to know whether defaults or custom actions are in effect.
