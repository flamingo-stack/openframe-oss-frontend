## use-mingo-what-to-ask.ts

A React hook that generates contextual "What to ask Mingo?" prompt suggestions by fetching a fresh snapshot of the workspace's online devices on demand, enriching the AI chat panel's suggested questions with real device names.

## Key Components

- **`useMingoWhatToAsk()`** — Hook returning a memoized async callback. Each invocation performs a `network-only` Relay query to fetch up to 20 online devices, then passes them to `buildMingoWhatToAsk` to construct the `WhatToAskContent` payload.
- **`DEVICES_LOOKED_AT`** — Constant (`20`) defining how many devices to sample, chosen to be likely enough to surface a workstation, a server, and a Windows device in the results.

## Behavior Notes

- Uses `fetchQuery` with `fetchPolicy: 'network-only'` to always get live online-status data instead of relying on the Relay cache, since device online state changes frequently.
- **Never throws/rejects**: if the GraphQL fetch fails, the error is logged via `console.error` and the function falls back to `buildMingoWhatToAsk([])`, which still returns generic (nameless) prompt suggestions.
- Depends on `useRelayEnvironment()` from `react-relay` to access the active Relay environment for the query.

## Usage Example

```typescript
import { useMingoWhatToAsk } from './use-mingo-what-to-ask';

function MingoChatPanel() {
  const getWhatToAsk = useMingoWhatToAsk();

  const handleOpenHelp = async () => {
    const whatToAskContent = await getWhatToAsk();
    // whatToAskContent is always defined, even on fetch failure
    showSuggestedPrompts(whatToAskContent);
  };

  return <button onClick={handleOpenHelp}>What can I ask Mingo?</button>;
}
```
