## Purpose

This file provides a React hook that supplies dynamic, example-driven "What to ask Mingo?" suggestions for the chat panel, using live data from the workspace's online devices so suggested prompts reference real device names.

## Key Components

- **`useMingoWhatToAsk`** — Hook that returns a memoized async function producing `WhatToAskContent` for the Mingo chat panel's prompt suggestions.
- **`DEVICES_LOOKED_AT`** — Constant (20) defining how many devices to fetch, chosen to be enough to likely find a workstation, a server, and a Windows device.
- Relies on **`buildMingoWhatToAsk`** (from `../what-to-ask`) to transform raw device nodes into prompt content, and **`whatToAskDevicesRelayQuery`** to fetch device data via Relay.

## Behavior

- Fetches devices fresh on every invocation using `fetchPolicy: 'network-only'`, ensuring prompts reflect devices that are online right now.
- Gracefully degrades: if the GraphQL fetch fails, it logs the error and falls back to `buildMingoWhatToAsk([])`, returning generic prompts without device names instead of rejecting.
- Designed to be called on-demand (e.g., when a user opens the "what to ask" panel), not on mount.

## Usage Example

```typescript
import { useMingoWhatToAsk } from './use-mingo-what-to-ask';

function MingoPanel() {
  const getWhatToAsk = useMingoWhatToAsk();

  const handleOpenSuggestions = async () => {
    const content = await getWhatToAsk();
    // content: WhatToAskContent ready to render in the chat panel
    setSuggestions(content);
  };

  return <button onClick={handleOpenSuggestions}>What should I ask?</button>;
}
```
