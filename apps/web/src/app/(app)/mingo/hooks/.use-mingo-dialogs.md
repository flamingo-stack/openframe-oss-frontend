# use-mingo-dialogs.ts

Client-side hook powering the Mingo chat list: fetches a paginated, searchable, and auto-refreshing list of AI assistant dialogs via GraphQL, and normalizes raw dialog nodes into UI-ready `DialogItem` rows.

## Key Components

- **`ACTIVE_DIALOG_STATUSES`** — Statuses shown in the active chat list (`ACTIVE`, `ACTION_REQUIRED`, `ON_HOLD`, `RESOLVED`); archived dialogs are excluded and live on a separate page.
- **`DIALOGS_BY_LAST_ACTIVITY`** — Default sort (`lastActivityAt DESC`) used for both the query and cursor pagination.
- **`MINGO_DIALOGS_PAGE_SIZE`** — Page size constant (20) shared with the chat history component for consistent initial render.
- **`transformToDialogItem(dialog, unreadCount?)`** — Maps a raw `DialogNode` to a `DialogItem`: derives owner display name/avatar, falls back to `'New Chat'` while the backend generates a title asynchronously, and marks `archived` based on status.
- **`useMingoDialogs(options?)`** — The main hook. Wraps `useInfiniteQuery` to:
  - Fetch dialogs filtered by `agentTypes: ['ADMIN']`, status, search term, and ownership `scope` (`'my' | 'all'`).
  - Keep newly created dialogs pinned to the top of an unsearched first page via `keepCreatedDialogs`.
  - Adaptively poll (10s while any dialog awaits a generated title, 60s otherwise), respecting `sessionPollsAllowed()`.
  - Preserve the visible list during search refetches via `placeholderData: keepPreviousData`.
  - Optionally compute per-dialog unread counts from notifications (currently disabled via `HIGHLIGHT_UNREAD_FROM_NOTIFICATIONS` pending backend support).

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs';

function MingoChatList() {
  const {
    dialogs,
    isLoading,
    isError,
    error,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage,
  } = useMingoDialogs({ scope: 'my', search: '', limit: 20 });

  if (isLoading) return <div>Loading dialogs...</div>;
  if (isError) return <div>Error: {error}</div>;

  return (
    <ul>
      {dialogs.map(dialog => (
        <li key={dialog.id}>{dialog.title}</li>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </ul>
  );
}
```
