# use-mingo-dialogs.ts

React hook that fetches and manages the paginated list of Mingo AI dialogs (conversations) for the admin chat interface, using infinite scroll, polling, and GraphQL.

## Key Components

- **`ACTIVE_DIALOG_STATUSES`** — Explicit list of non-archived dialog statuses (`ACTIVE`, `ACTION_REQUIRED`, `ON_HOLD`, `RESOLVED`) sent to the backend, since archived dialogs are queried separately.
- **`DIALOGS_BY_LAST_ACTIVITY`** — Default sort order (most recently active first), matching the cursor's traversal order.
- **`MINGO_DIALOGS_PAGE_SIZE`** — Default page size (20) for a single fetch, matching the chat UI's initial render.
- **`transformToDialogItem(dialog, unreadCount)`** — Maps a raw `DialogNode` (GraphQL) into a `DialogItem` consumed by the chat list UI, handling title fallback ("New Chat"), archived status, owner avatar resolution, and timestamp normalization.
- **`useMingoDialogs(options)`** — Main hook built on `useInfiniteQuery`. Fetches dialogs via GraphQL (`/chat/graphql`), supports search, ownership scope (`my`/`all`), optimistic retention of newly created dialogs, adaptive polling (faster while a title is pending), and placeholder data during search refetches.

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs';

function DialogList() {
  const {
    dialogs,
    isLoading,
    isError,
    error,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage,
  } = useMingoDialogs({ search: '', scope: 'all', limit: 20 });

  if (isLoading) return <p>Loading…</p>;
  if (isError) return <p>Error: {error}</p>;

  return (
    <ul>
      {dialogs.map(dialog => (
        <li key={dialog.id}>
          {dialog.title} — {dialog.unreadMessagesCount} unread
        </li>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </ul>
  );
}
```

Scoped to the signed-in admin's own dialogs:

```typescript
const { dialogs } = useMingoDialogs({ scope: 'my' });
```
