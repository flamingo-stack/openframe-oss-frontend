Fetches and transforms paginated Mingo chat dialogs for the admin panel, mapping raw GraphQL dialog nodes into `DialogItem` objects with optional unread badge counts.

## Key Components

### `useMingoDialogs(options?: UseMingoDialogsOptions)`

The primary exported hook. Accepts an options object and returns a normalized list of dialogs with pagination controls.

**Options (`UseMingoDialogsOptions`):**

| Option | Default | Description |
|--------|---------|-------------|
| `enabled` | `true` | Enables/disables the query |
| `search` | — | Full-text search string |
| `limit` | `20` | Page size |
| `scope` | `'all'` | `'all'` or `'my'` (filters to signed-in admin's dialogs) |

**Returns:**

| Field | Type | Description |
|-------|------|-------------|
| `dialogs` | `DialogItem[]` | Flattened, transformed dialog list across all loaded pages |
| `isLoading` | `boolean` | True on initial load |
| `isError` | `boolean` | True if the query failed |
| `error` | `string \| undefined` | Error message if present |
| `hasNextPage` | `boolean` | Whether more pages exist |
| `fetchNextPage` | `function` | Loads the next cursor page |
| `isFetchingNextPage` | `boolean` | True while loading additional pages |
| `refetch` | `function` | Manually triggers a refetch |

### `transformToDialogItem(dialog, unreadCount)` *(internal)*

Converts a raw `DialogNode` from the GraphQL response into a `DialogItem`, resolving the owner's display name and avatar URL.

### `HIGHLIGHT_UNREAD_FROM_NOTIFICATIONS` *(feature flag)*

Boolean flag (currently `false`) controlling whether unread badge counts are derived from notification metadata. Disabled pending backend support for per-dialog unread counts on the dialog entity.

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs';

function MingoDrawer() {
  const {
    dialogs,
    isLoading,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage,
  } = useMingoDialogs({ scope: 'my', search: 'billing', limit: 15 });

  if (isLoading) return <Skeleton />;

  return (
    <>
      {dialogs.map(dialog => (
        <DialogRow key={dialog.id} dialog={dialog} />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```

## Caching Strategy

The query uses an aggressive caching configuration tuned for the Mingo drawer's mount/unmount lifecycle:

- **`staleTime`**: 5 minutes — prevents refetch on reopen within the same session
- **`gcTime`**: 30 minutes — retains cached pages across closed drawer periods, avoiding skeleton re-flashes
- **`refetchInterval`**: 60 seconds — polls for fresh data while the drawer is open
- **`placeholderData: keepPreviousData`** — prevents list flicker while a new search query is in-flight
