## Overview

A React hook that builds the "Generate with AI" split-button action, the Mingo-powered segment of create buttons throughout the app. Clicking it opens the Mingo chat dock on a new conversation scoped to a given `intent`, where Mingo proactively guides the user through creating that entity.

## Key Components

- **`useGenerateWithAiAction(intent)`** — Hook that returns a `SplitButtonIconAction` object configured for the "Generate with AI" button segment.
  - **Parameters:** `intent: DialogIntent` — identifies what kind of entity Mingo should help create (e.g., a ticket).
  - **Returns:** `SplitButtonIconAction` containing:
    - `icon` — an `AgentMark` for the `mingo` agent, sized `h-6 w-6`, colored via `currentColor` to inherit the button's text color.
    - `'aria-label'` — `"Generate with AI"` for accessibility.
    - `onClick` — calls `startIntentChat(intent)` from the Mingo launcher store, opening a new intent-scoped chat.
    - `disabled` — `true` when no Mingo chat dock is mounted (`dockMounted` is `false`), preventing the action in a locked/unmounted workspace.

The hook reads state from `useMingoLauncherStore` (Zustand-style store): `dockMounted` to gate availability, and `startIntentChat` to trigger the chat flow.

## Usage Example

```typescript
import { useGenerateWithAiAction } from './use-generate-with-ai-action';
import { DialogIntent } from '../../tickets/constants';

function CreateTicketButton() {
  const aiAction = useGenerateWithAiAction(DialogIntent.CreateTicket);

  return (
    <SplitButton
      primaryAction={{ label: 'New Ticket', onClick: handleManualCreate }}
      secondaryAction={aiAction}
    />
  );
}
```

The resulting action integrates directly into a `SplitButtonIconAction`-compatible component, automatically disabling itself when the Mingo chat dock isn't available.
