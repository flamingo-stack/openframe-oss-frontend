## use-generate-with-ai-action.tsx

A React hook that builds a `SplitButtonIconAction` for the "Generate with AI" button segment, letting users launch Mingo (the AI assistant) to create an entity through a guided chat flow instead of manual form-filling.

## Key Components

- **`useGenerateWithAiAction(intent: DialogIntent)`** — Hook that returns a `SplitButtonIconAction` configured to open Mingo for a given `intent`. Internally reads the `dockMounted` and `startIntentChat` state/actions from `useMingoLauncherStore` to:
  - Render the Mingo `AgentMark` icon (sized `h-6 w-6`, inheriting the button's current color).
  - Set an accessible `aria-label` of `"Generate with AI"`.
  - Trigger `startIntentChat(intent)` on click, which opens Mingo in a new dialog scoped to that intent.
  - Disable the action when no chat dock is mounted (e.g., in a locked workspace), keeping it inert.

## Usage Example

```typescript
import { useGenerateWithAiAction } from './use-generate-with-ai-action';
import type { DialogIntent } from '../../tickets/constants';

function CreateTicketButton() {
  const aiAction = useGenerateWithAiAction('create-ticket' as DialogIntent);

  return (
    <SplitButton
      primaryLabel="Create Ticket"
      onPrimaryClick={() => openManualForm()}
      secondaryAction={aiAction}
    />
  );
}
```

This is typically paired with a manual "create" action as the primary button segment, while the AI-generated action serves as the secondary split-button option, letting Mingo greet the user and walk them through entity creation conversationally.
