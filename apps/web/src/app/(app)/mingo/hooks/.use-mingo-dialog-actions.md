Provides CRUD-style dialog management actions (rename, archive, unarchive, fetch archived) for the Mingo AI chat interface, wired to the `/chat/graphql` endpoint with React Query cache invalidation and toast notifications.

## Key Components

### `useMingoDialogActions` (default export)

Returns four memoized async callbacks:

| Function | Description |
|---|---|
| `renameDialog(id, title)` | Renames a dialog and invalidates its individual cache entry |
| `archiveDialog(id)` | Moves a dialog to the archived state; re-throws on error for caller handling |
| `unarchiveDialog(id)` | Restores an archived dialog; re-throws on error for caller handling |
| `fetchArchivedDialogs(params)` | Fetches paginated archived dialogs; first page is cached in React Query (`staleTime` 5 min) |

### `runDialogMutation` (internal helper)

Generic GraphQL mutation runner that posts to `/chat/graphql`, checks `response.ok`, and surfaces `userErrors` from the payload as thrown errors.

### Cache Strategy

- All mutations invalidate both `mingo-dialogs` and `mingo-archived-dialogs` query keys
- Rename additionally invalidates the specific `mingo-dialog/{id}` entry
- First page of archived dialogs is cached (`gcTime` 30 min) via `queryClient.fetchQuery`; paginated pages (with cursor) bypass the cache

## Usage Example

```typescript
import { useMingoDialogActions } from '@/features/mingo/hooks/use-mingo-dialog-actions';

function DialogRowMenu({ dialog }: { dialog: { id: string } }) {
  const { renameDialog, archiveDialog, unarchiveDialog } = useMingoDialogActions();

  return (
    <>
      <button onClick={() => renameDialog(dialog.id, 'New Title')}>Rename</button>
      <button onClick={() => archiveDialog(dialog.id)}>Archive</button>
      <button onClick={() => unarchiveDialog(dialog.id)}>Unarchive</button>
    </>
  );
}
```
