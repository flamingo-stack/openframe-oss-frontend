## use-mingo-dialog-actions.ts

A React hook providing Mingo chat dialog management actions (rename, archive, unarchive, fetch archived list) backed by the saas-ai-agent `/chat/graphql` endpoint, with integrated toast notifications and React Query cache invalidation/caching.

## Key Components

- **`useMingoDialogActions()`** — Main hook exposing dialog mutation/query actions:
  - `renameDialog(id, title, options?)` — Renames a dialog; supports a `silent` option to suppress the success toast (used for app-initiated renames like onboarding tours).
  - `archiveDialog(id)` — Archives a dialog, invalidates dialog lists and the dialog's detail cache, shows success/error toast, and rethrows on failure.
  - `unarchiveDialog(id)` — Unarchives a dialog; awaits the detail cache invalidation (not just fire-and-forget) so dependent UI (e.g. "Unarchive chat" banner) updates synchronously once the promise resolves.
  - `fetchArchivedDialogs(params)` — Fetches a paginated list of archived dialogs (`ADMIN` agent type, `ARCHIVED` status). The first page (no cursor) is cached via `queryClient.fetchQuery` for instant reopen of the archive view; subsequent pages are fetched transiently.
- **`runDialogMutation(query, variables, key)`** — Internal helper that posts a GraphQL mutation and throws if `userErrors` are present in the response payload.
- **`invalidateDialogs()`** — Internal helper invalidating both the active (`mingo-dialogs`) and archived (`mingo-archived-dialogs`) dialog list caches together, since archive/unarchive moves dialogs between the two.

## Usage Example

```typescript
import { useMingoDialogActions } from './use-mingo-dialog-actions';

function DialogRowMenu({ dialogId }: { dialogId: string }) {
  const { renameDialog, archiveDialog, unarchiveDialog } = useMingoDialogActions();

  const handleRename = async (newTitle: string) => {
    await renameDialog(dialogId, newTitle);
  };

  const handleArchive = async () => {
    try {
      await archiveDialog(dialogId);
    } catch {
      // error toast already shown by the hook
    }
  };

  return (
    <div>
      <button onClick={() => handleRename('New Title')}>Rename</button>
      <button onClick={handleArchive}>Archive</button>
      <button onClick={() => unarchiveDialog(dialogId)}>Unarchive</button>
    </div>
  );
}
```

```typescript
import { useMingoDialogActions } from './use-mingo-dialog-actions';

async function loadArchivedPage() {
  const { fetchArchivedDialogs } = useMingoDialogActions();
  const { dialogs, nextCursor } = await fetchArchivedDialogs({ limit: 20, search: 'invoice' });
  return { dialogs, nextCursor };
}
```
