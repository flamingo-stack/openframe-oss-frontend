# use-mingo-dialog-actions.ts

React hook providing dialog management actions (rename, archive, unarchive, fetch archived) for Mingo AI chat conversations, backed by GraphQL mutations against the saas-ai-agent `/chat/graphql` endpoint. It coordinates React Query cache invalidation so UI surfaces (embeddable chat, archive page) stay in sync.

## Key Components

- **`runDialogMutation(query, variables, key)`** — Internal helper that POSTs a GraphQL mutation, extracts the response payload, and throws if `userErrors` are present.
- **`useMingoDialogActions()`** — Main hook exposing:
  - `renameDialog(id, title, options?)` — Renames a dialog; supports a `silent` option to skip the success toast (used when the app auto-titles a chat, e.g. during onboarding).
  - `archiveDialog(id)` — Archives a dialog and invalidates both active and archived dialog list caches plus the dialog's detail cache.
  - `unarchiveDialog(id)` — Unarchives a dialog, **awaiting** the detail cache invalidation so the chat UI exits read-only mode only once the status is confirmed `ACTIVE`.
  - `fetchArchivedDialogs(params)` — Fetches a paginated list of archived dialogs; the first page (no cursor) is cached via `queryClient.fetchQuery` for instant reopening of the archive view, while subsequent pages are fetched transiently.
- **`invalidateDialogs()`** — Internal callback invalidating both `mingo-dialogs` and `mingo-archived-dialogs` query keys, since archive/unarchive move dialogs between these two lists.

## Usage Example

```typescript
import { useMingoDialogActions } from './hooks/use-mingo-dialog-actions';

function DialogRowMenu({ dialogId }: { dialogId: string }) {
  const { renameDialog, archiveDialog, unarchiveDialog, fetchArchivedDialogs } =
    useMingoDialogActions();

  const handleRename = () => renameDialog(dialogId, 'New Title');

  const handleArchive = async () => {
    try {
      await archiveDialog(dialogId);
    } catch {
      // Error toast already shown by the hook
    }
  };

  const loadArchived = () =>
    fetchArchivedDialogs({ limit: 20, search: 'support' });

  return (
    <div>
      <button onClick={handleRename}>Rename</button>
      <button onClick={handleArchive}>Archive</button>
      <button onClick={() => unarchiveDialog(dialogId)}>Unarchive</button>
      <button onClick={loadArchived}>Load Archived</button>
    </div>
  );
}
```

Errors are caught internally and surfaced via toast notifications; `archiveDialog`/`unarchiveDialog` also re-throw so callers can handle failure flows (e.g., preventing optimistic UI updates).
