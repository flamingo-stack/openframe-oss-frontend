## Purpose

A React hook that computes the status glyph (working, awaiting approval, or none) shown at the end of each row in the Mingo chat dialog list. It merges live streaming state for the currently open chat with server-polled state for all other chats, and syncs the open chat's live state back into the cached list query so it survives re-renders.

## Key Components

- **`useMingoDialogRowStatus(options)`** — Main hook. Accepts the active dialog ID, the server-provided dialog nodes, and whether the active thread's history has loaded. Returns a function `(dialog: DialogItem) => MingoDialogStatus | undefined` that resolves the status for any given dialog row.
- **`UseMingoDialogRowStatusOptions`** — Input interface: `activeDialogId`, `nodes` (server-sent chat list rows), `activeThreadLoaded`.
- Internally uses `useMingoMessagesStore` to read live phase/messages for the active dialog, and `liveRowState`, `dialogRowStatus`, `serverRowState`, `withLiveRowState` from `dialog-row-status` utils to derive and propagate status.
- Writes the active dialog's live streaming/approval state into the React Query cache (`mingoDialogQueryKeys.lists`) via a `useEffect`, so the status glyph persists even if the user navigates away mid-stream.

## Usage Example

```typescript
import { useMingoDialogRowStatus } from './use-mingo-dialog-row-status';

function DialogList({ dialogs, activeDialogId, activeThreadLoaded, nodes }) {
  const getStatus = useMingoDialogRowStatus({
    activeDialogId,
    nodes,
    activeThreadLoaded,
  });

  return (
    <ul>
      {dialogs.map(dialog => {
        const status = getStatus(dialog);
        return (
          <li key={dialog.id}>
            {dialog.title} {status && <StatusGlyph status={status} />}
          </li>
        );
      })}
    </ul>
  );
}
```

**Note:** The returned function is stable in identity per render but closes over the current status values as plain strings (not the live object), minimizing unnecessary re-renders across list rows (e.g., in sidebar and phone drawer views).
