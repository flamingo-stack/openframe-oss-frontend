# use-mingo-dialog-row-status.ts

React hook that computes the status glyph (working / awaiting approval / none) shown at the end of each row in the Mingo chat list, blending live streaming state for the currently open dialog with polled server state for every other row.

## Key Components

- **`useMingoDialogRowStatus(options)`** — Main hook. Accepts `activeDialogId`, the server-provided `nodes` (dialog list rows), and `activeThreadLoaded` (whether the open chat's history has finished loading). Returns a stable lookup function `(dialog: DialogItem) => MingoDialogStatus | undefined`.
- **`UseMingoDialogRowStatusOptions`** — Input options interface for the hook.
- Internally relies on:
  - `useMingoMessagesStore` to read the active dialog's phase and messages.
  - `liveRowState` / `dialogRowStatus` / `serverRowState` / `withLiveRowState` from `utils/dialog-row-status` to derive status from either live or server state.
  - `mingoDialogQueryKeys` and React Query's `useQueryClient` to sync the live status back into the cached dialogs list, so the glyph persists across list re-fetches.

## Behavior Notes

- Only the **currently open dialog** derives its status from live streaming state (`phase` + `messages` from the Zustand store). All other rows use the server-provided `streamState`/`pendingApproval` fields from `nodes`, which are refreshed via polling.
- A `useEffect` writes the active dialog's live `streaming`/`awaitingApproval`/`approvalRequestId` state into the React Query cache for all `mingoDialogQueryKeys.lists` queries, ensuring the status glyph doesn't flicker away if the user navigates away mid-stream before the next poll.
- The returned lookup function intentionally closes over a **string status**, not the raw `live` object, to avoid re-rendering every row (in both sidebar and phone drawer) on every streamed chunk. Only the open row depends on live state; the rest are computed once per `nodes` list via a `Map`.

## Usage Example

```typescript
import { useMingoDialogRowStatus } from './use-mingo-dialog-row-status';

function DialogList({ dialogs, activeDialogId, nodes, activeThreadLoaded }: {
  dialogs: DialogItem[];
  activeDialogId: string | null;
  nodes: DialogNode[];
  activeThreadLoaded: boolean;
}) {
  const getStatus = useMingoDialogRowStatus({ activeDialogId, nodes, activeThreadLoaded });

  return (
    <ul>
      {dialogs.map(dialog => (
        <li key={dialog.id}>
          {dialog.title}
          <StatusIcon status={getStatus(dialog)} />
        </li>
      ))}
    </ul>
  );
}
```
