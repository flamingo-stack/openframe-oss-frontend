Manages the Mingo AI chat session lifecycle, including dialog creation, message sending, generation stopping, and real-time message state processing with optimistic UI updates.

## Key Components

### Interfaces

- **`MingoSendContext`** — Outgoing message context payload containing optional `contextItems`, `openView`, and `recentViews` for navigation-aware AI responses
- **`ProcessedMessage`** — Normalized message shape consumed by the UI layer, with resolved avatar URLs, role, content segments, and context chips
- **`UseMingoChat`** — Return type contract for the hook, exposing messages, actions, approvals, and loading states

### Internal Utilities

- **`isContentEqual(a, b)`** — Structural equality check for message content; uses reference equality first, then falls back to `JSON.stringify` for segment arrays
- **`isSameProcessedMessage(a, b)`** — Drives reference reuse for the lib's memo: only replaces a processed message object when its rendered output has actually changed

### Hook: `useMingoChat(dialogId)`

| Return | Description |
|---|---|
| `messages` | Filtered, deduplicated, and reference-reconciled `ProcessedMessage[]` |
| `approvals` | Pending `approval_request` segments deduplicated by `requestId` |
| `createDialog()` | Creates a new Mingo dialog via mutation, invalidates query cache |
| `sendMessage(content, targetDialogId?, context?)` | Sends a message with optimistic approval interrupt handling |
| `stopGeneration()` | Aborts the current streaming generation |
| `isTyping` / `isCompacting` / `isCreatingDialog` | Granular loading states |

## Usage Example

```typescript
import { useMingoChat } from './use-mingo-chat';

function MingoPanel({ dialogId }: { dialogId: string | null }) {
  const { messages, sendMessage, approvals, isTyping, createDialog } = useMingoChat(dialogId);

  const handleSend = async (text: string) => {
    let targetId = dialogId;
    if (!targetId) {
      targetId = await createDialog();
      if (!targetId) return;
    }
    await sendMessage(text, targetId, {
      openView: { type: 'ticket', id: '123' },
    });
  };

  return (
    <ChatWindow
      messages={messages}
      approvals={approvals}
      isTyping={isTyping}
      onSend={handleSend}
    />
  );
}
```

> **Note:** Approval deduplication across message bubbles and reference reconciliation (`stableMessagesRef`) are handled internally — callers receive a stable, render-optimized `messages` array on every update.
