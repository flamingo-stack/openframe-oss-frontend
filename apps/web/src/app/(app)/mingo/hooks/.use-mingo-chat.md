## use-mingo-chat.ts

A React hook that manages a single Mingo AI chat dialog: it derives render-ready messages from the shared message store, handles dialog creation, message sending, generation stopping, and pending-approval tracking, while optimizing re-renders through reference-stable message reconciliation.

## Key Components

- **`MingoSendContext`** — Interface describing the navigation/context payload attached to an outgoing message (context items, current view, current page/list).
- **`ProcessedMessage`** — Type intersecting the library's `CoreMessage` with a resolved `name` and `timestamp`, deliberately built via spread to avoid dropping lib-owned fields (e.g., `hidden`, streaming metadata).
- **`useMingoDialogChat(dialogId)`** — Main hook returning:
  - `messages` — reconciled, render-ready `ProcessedMessage[]`
  - `isLoading`, `isTyping`, `isCompacting`, `isCreatingDialog` — state flags
  - `createDialog(options)` — creates a new dialog, optimistically inserts it into the dialog list, and surfaces errors via toast
  - `sendMessage(content, targetDialogId?, context?)` — sends a message to a dialog
  - `stopGeneration()` — cancels in-flight generation
  - `approvals` — pending approval segments extracted from messages
  - `assistantType` — fixed as `'mingo'`
- **`isContentEqual` / `isSameProcessedMessage` / `shallowEqualExcept`** — Internal helpers that detect structurally identical messages so previous object references can be reused, preserving the library's reference-equality render memo and avoiding unnecessary re-renders.

## Usage Example

```typescript
import { useMingoDialogChat } from './use-mingo-chat';

function MingoChatPanel({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    isTyping,
    isCompacting,
    approvals,
    sendMessage,
    createDialog,
    stopGeneration,
  } = useMingoDialogChat(dialogId);

  const handleSend = async (text: string) => {
    let targetId = dialogId;
    if (!targetId) {
      targetId = await createDialog({ title: 'New conversation' });
      if (!targetId) return;
    }
    await sendMessage(text, targetId);
  };

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.name}: {String(msg.content)}</div>
      ))}
      {isTyping && <span>Mingo is typing…</span>}
      {isCompacting && <span>Compacting context…</span>}
      {approvals.length > 0 && <ApprovalBar approvals={approvals} />}
      <button onClick={stopGeneration}>Stop</button>
    </div>
  );
}
```

This hook is designed for use inside chat UI components that render a single dialog thread backed by the `mingo-messages-store` and `mingo-api-service`.
