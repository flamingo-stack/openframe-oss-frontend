Manages the Mingo AI chat session lifecycle, including dialog creation, message sending, generation stopping and the thread's messages (`ChatMessage[]`) with optimistic UI updates.

## Key Components

### Interfaces

- **`MingoSendContext`** — Outgoing message context payload containing optional `contextItems`, `openView`, `recentViews`, and the page the message was sent from (`currentPage`, plus `currentList` on a list page) for navigation-aware AI responses

### Internal Utilities

- **`isSameJson(a, b)`** — Reference equality first, then `JSON.stringify`
- **`isSameMessage(a, b)`** — Drives reference reuse for the lib's memo: only replaces a message object when its rendered output has actually changed
- **`withFullAvatar(message)`** — A row with its author's avatar as a full URL, resolved once so every surface gets an absolute src

### Hook: `useMingoDialogChat(dialogId)`

| Return | Description |
|---|---|
| `messages` | Filtered, deduplicated and reference-reconciled `ChatMessage[]` |
| `createDialog()` | Creates a new Mingo dialog via mutation, invalidates query cache |
| `sendMessage(content, targetDialogId?, context?)` | Sends a message with optimistic approval interrupt handling |
| `stopGeneration()` | Aborts the current streaming generation |
| `isTyping` / `isCompacting` / `isCreatingDialog` | Granular loading states |

## Usage Example

```typescript
import { useMingoDialogChat } from './use-mingo-chat';

function MingoPanel({ dialogId }: { dialogId: string | null }) {
  const { messages, sendMessage, approvals, isTyping, createDialog } = useMingoDialogChat(dialogId);

  const handleSend = async (text: string) => {
    let targetId = dialogId;
    if (!targetId) {
      targetId = await createDialog();
      if (!targetId) return;
    }
    await sendMessage(text, targetId, {
      openView: { type: 'ticket', id: '123' },
    });
  };

  return (
    <ChatWindow
      messages={messages}
      approvals={approvals}
      isTyping={isTyping}
      onSend={handleSend}
    />
  );
}
```

> **Note:** Approval deduplication across message bubbles and reference reconciliation are handled internally. Callers receive a stable, render-optimized `messages` array on every update.
