## use-mingo-chat.ts

A React hook that manages the state and actions for a Mingo AI chat dialog, including message processing, dialog creation, message sending, and pending-approval tracking. It bridges the raw message store (`useMingoMessagesStore`) with a render-ready, memoized message list consumed by the chat UI.

## Key Components

- **`MingoSendContext`** – Interface describing the context (picker selections, current page/view) attached to an outgoing message.
- **`ProcessedMessage`** – Type intersecting the library's `CoreMessage` with a resolved `name`, optional `assistantType`, and a guaranteed `timestamp`. Deliberately an intersection (not a re-declared shape) so lib-owned fields like `hidden` or streaming metadata are never silently dropped.
- **`isContentEqual` / `isSameProcessedMessage` / `shallowEqualExcept`** – Structural equality helpers used to reuse previous message object references across renders, preserving the library's reference-equality memoization and avoiding unnecessary re-renders.
- **`useMingoDialogChat(dialogId)`** – Main hook returning:
  - `messages`: reconciled, render-ready `ProcessedMessage[]`
  - `approvals`: pending `MessageSegment[]` extracted for a sticky approval footer
  - `createDialog(options)`: creates a new Mingo dialog, optimistically inserts it into the query cache, and surfaces errors via toast
  - `sendMessage(content, targetDialogId?, context?)`: sends a message with optional navigation/context payload
  - `stopGeneration()`: cancels an in-flight assistant response
  - `isLoading`, `isTyping`, `isCompacting`, `isCreatingDialog`, `assistantType`: derived UI state flags

## Usage Example

```typescript
import { useMingoDialogChat } from './use-mingo-chat';

function MingoChatPanel({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    approvals,
    isTyping,
    isCompacting,
    sendMessage,
    stopGeneration,
    createDialog,
  } = useMingoDialogChat(dialogId);

  const handleSend = async (text: string) => {
    const ok = await sendMessage(text, dialogId ?? undefined, {
      currentPage: { type: 'ticket', id: 'TCK-123' },
    });
    if (!ok) console.warn('Message failed to send');
  };

  const handleNewChat = async () => {
    const newId = await createDialog({ title: 'Support request' });
    if (newId) console.log('Created dialog', newId);
  };

  return null; // render messages, approvals, isTyping, etc.
}
```

## Notes

- Message reconciliation reuses prior object references when a message's rendered output is structurally unchanged, which prevents cascading re-renders in the message list.
- Pending approvals are extracted via `extractPendingApprovals`/`stripPendingApprovals` from `@/lib/chat-history`, ensuring the main flow and the approval footer never diverge on which cards they show.
- Dialog creation cancels in-flight list queries before optimistically inserting the new dialog to avoid a stale refetch overwriting it.
