Barrel file that re-exports composables related to the Mingo AI chat dialog feature, providing a single entry point for importing Mingo dialog functionality throughout the application.

## Key Components

- **`useMingoDialogChat`** - Composable handling chat message state and interactions within a Mingo dialog session.
- **`useMingoDialogSelection`** - Composable managing selection state (e.g., selected items, context) for Mingo dialogs.
- **`useMingoDialogs`** - Composable for managing the lifecycle and state of multiple Mingo dialog instances.
- **`useMingoRealtimeSubscription`** - Composable establishing and managing real-time subscriptions for live Mingo updates.

## Usage Example

```typescript
import {
  useMingoDialogChat,
  useMingoDialogSelection,
  useMingoDialogs,
  useMingoRealtimeSubscription
} from '@/composables/mingo';

export default {
  setup() {
    const { messages, sendMessage } = useMingoDialogChat();
    const { selectedItem, selectItem } = useMingoDialogSelection();
    const { dialogs, openDialog, closeDialog } = useMingoDialogs();
    useMingoRealtimeSubscription();

    return {
      messages,
      sendMessage,
      selectedItem,
      selectItem,
      dialogs,
      openDialog,
      closeDialog
    };
  }
};
```

This barrel export pattern simplifies imports by consolidating all Mingo dialog-related composables under a single module path, improving maintainability and reducing import clutter across consuming components.
