## Key Components

| Export | Source File |
|--------|-------------|
| `useMingoChat` | `./use-mingo-chat` |
| `useMingoDialog` | `./use-mingo-dialog` |
| `useMingoDialogSelection` | `./use-mingo-dialog-selection` |
| `useMingoDialogs` | `./use-mingo-dialogs` |
| `useMingoRealtimeSubscription` | `./use-mingo-realtime-subscription` |

## Usage Example

```typescript
import {
  useMingoChat,
  useMingoDialog,
  useMingoDialogSelection,
  useMingoDialogs,
  useMingoRealtimeSubscription,
} from '@/composables/mingo-chat';
```

Consumers import directly from this index rather than referencing individual files, keeping import paths stable if internal file structure changes.
