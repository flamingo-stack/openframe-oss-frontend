Barrel file that re-exports composable hooks related to the Mingo AI dialog/chat feature, providing a single entry point for consumers to import Mingo-related functionality.

## Key Components

- **`useMingoDialogChat`** - Composable for managing chat interactions within a Mingo dialog session.
- **`useMingoDialogSelection`** - Composable for handling selection state within Mingo dialogs.
- **`useMingoDialogs`** - Composable for managing the lifecycle and state of Mingo dialogs.
- **`useMingoRealtimeSubscription`** - Composable for subscribing to real-time updates related to Mingo interactions.

## Usage Example

```typescript
import {
  useMingoDialogChat,
  useMingoDialogSelection,
  useMingoDialogs,
  useMingoRealtimeSubscription
} from '@/composables/mingo';

export default {
  setup() {
    const { messages, sendMessage } = useMingoDialogChat();
    const { selectedItem, selectItem } = useMingoDialogSelection();
    const { dialogs, openDialog, closeDialog } = useMingoDialogs();

    useMingoRealtimeSubscription();

    return {
      messages,
      sendMessage,
      selectedItem,
      selectItem,
      dialogs,
      openDialog,
      closeDialog
    };
  }
};
```

This index file simplifies imports across the codebase by consolidating all Mingo dialog-related composables into a single module, avoiding the need to reference individual file paths throughout the application.
