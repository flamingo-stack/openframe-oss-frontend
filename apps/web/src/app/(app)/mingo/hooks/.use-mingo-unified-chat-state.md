Adapts the existing Mingo data stack (react-query, Zustand, NATS/JetStream) into the `UnifiedChatState` interface for injection into `<EmbeddableChat>`, enabling persistent chat state that survives component unmounts without the `keepMounted` workaround.

## Key Components

### `useMingoUnifiedChatState(): MingoUnifiedChat`
Primary hook that composes multiple sub-hooks and maps their output to the unified chat contract.

### `MingoUnifiedChat`
Return type containing:
- `state: UnifiedChatState` — unified chat state for `<EmbeddableChat>`
- `subscription: MingoSubscriptionBindings` — props for rendering `<DialogSubscription>`
- `sendInNewDialog(text)` — creates a fresh dialog and sends immediately (used by "Ask Mingo about X" launchers)
- `searchQuery` / `setSearchQuery` — server-side dialog filtering
- `fetchArchivedDialogs` — paginated archive retrieval
- `unarchiveDialog` — restores archived dialogs

### `MingoSubscriptionBindings`
Props bundle for the host to render `<DialogSubscription>`, including connection state, approval handlers, and JetStream sequence tracking.

## Usage Example

```typescript
// In your panel/drawer component
import { useMingoUnifiedChatState } from './use-mingo-unified-chat-state';
import { EmbeddableChat } from '@flamingo-stack/openframe-frontend-core/components/chat';
import { DialogSubscription } from '../components/dialog-subscription';

function MingoPanel() {
  const { state, subscription, sendInNewDialog } = useMingoUnifiedChatState();

  return (
    <>
      {/* Realtime subscription rendered alongside the chat */}
      {subscription.activeDialogId && subscription.isSubscribed && (
        <DialogSubscription
          dialogId={subscription.activeDialogId}
          onConnectionChange={subscription.onConnectionChange}
          onMetadata={subscription.onMetadata}
          onApprove={subscription.onApprove}
          onReject={subscription.onReject}
          initialOptStartSeq={subscription.initialOptStartSeq}
        />
      )}
      <EmbeddableChat mingoState={state} />
    </>
  );
}
```

## Architecture Notes

- Composes `useMingoDialogs`, `useMingoDialogSelection`, `useMingoChat`, `useMingoRealtimeSubscription`, and `useMingoMessagesStore` independently
- Uses a `WeakMap` cache to produce referentially-stable `UnifiedChatMessage` objects, preventing full list re-renders on each streaming chunk
- `useDeferredValue` on dialog scope prevents scope-switch from blocking the UI while a new query loads
- Token usage prefers the live Zustand store over the GraphQL query fallback
