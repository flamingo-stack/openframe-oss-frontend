## Overview

`useMingoUnifiedChatState` is a React hook that adapts the `/mingo` page's data stack (React Query + the `mingo-messages-store` Zustand store + NATS/JetStream realtime subscription) into the `UnifiedChatState` shape consumed by `<EmbeddableChat>`. It exists so chat state lives outside component lifecycle (query cache + global store), letting the chat panel unmount and remount without losing data, replacing the previous `keepMounted` workaround.

It composes existing building blocks (`useMingoDialogs`, `useMingoDialogSelection`, `useMingoDialogChat`, `useMingoRealtimeSubscription`, `useMingoMessagesStore`) rather than reimplementing them, and must be called exactly once (inside `MingoChatProvider`), with other surfaces consuming the result via `useMingoChatSurface()`.

## Key Components

- **`mapMingoMessageToUnified(message)`** — Converts a `ProcessedMessage` into a `UnifiedChatMessage` via destructure-and-spread, preserving unknown metadata fields (`streamSeq`, `scrollAnchor`, Guide Mode V3 metadata, etc.) while normalizing role and user identity.
- **`needsAllChatsScope(ownerUserId, currentUserId)`** — Determines whether the "All Chats" scope is required to locate a dialog not owned by the current user.
- **`rawDialogIdToAdopt(activeDialogId, dialog)`** — Resolves a Relay global dialog id to the raw dialog id needed by NATS subjects and list registries.
- **`openNamedDialog(title, steps)`** — Creates, opens, and renames a dialog in sequence so it never appears as an unnamed draft row.
- **`MingoSubscriptionBindings`** — Props contract for rendering `<DialogSubscription>` (approval handling, connection state, metadata callback, replay cursor).
- **`MingoUnifiedChat`** — Return shape bundling `state` (UnifiedChatState), `subscription` bindings, pending approvals, dialog status helpers, search/archive operations, and dialog-level error/timestamp info not covered by `UnifiedChatState`.

## Usage Example

```typescript
// Inside MingoChatProvider (called exactly once per session)
function MingoChatProvider({ children }: { children: React.ReactNode }) {
  const { state, subscription } = useMingoUnifiedChatState();

  return (
    <MingoChatContext.Provider value={{ state, subscription }}>
      {children}
      <DialogSubscription
        dialogId={subscription.activeDialogId}
        onApprove={subscription.onApprove}
        onReject={subscription.onReject}
        onMetadata={subscription.onMetadata}
      />
    </MingoChatContext.Provider>
  );
}

// Consumed elsewhere via the surface hook
function MingoPanel() {
  const { state } = useMingoChatSurface();
  return <EmbeddableChat mingoState={state} />;
}
```
