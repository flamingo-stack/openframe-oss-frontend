## Overview

`useMingoUnifiedChatState` adapts the existing `/mingo` data stack (react-query, the `mingo-messages-store` Zustand store, and the NATS/JetStream realtime subscription) into the lib's `UnifiedChatState` shape, so it can be injected directly into `<EmbeddableChat mingoState={…}>`. It solves the problem of chat state being lost on panel unmount by reusing `/mingo`'s persistence model — data lives outside the component in react-query cache and a global Zustand store — eliminating the need for the `keepMounted` workaround.

This hook should be called in exactly **one place** (`MingoChatProvider`); other surfaces consume its output via `useMingoChatSurface()` to avoid duplicate dialog polling and duplicate live-tail processing.

## Key Components

- **`useMingoUnifiedChatState`** (implied default export) — composes `useMingoDialogs`, `useMingoDialogSelection`, `useMingoDialogChat`, `useMingoRealtimeSubscription`, and `useMingoMessagesStore` into a `MingoUnifiedChat` result.
- **`MingoUnifiedChat`** — return type containing `state` (the `UnifiedChatState`), `subscription` (bindings for rendering `<DialogSubscription>`), `pendingApprovals`, dialog CRUD helpers (`sendInNewDialog`, `createNamedDialog`, `createIntentDialog`, `unarchiveDialog`, `fetchArchivedDialogs`), and dialog metadata (`dialogError`, `dialogCreatedAt`, `dialogStatusOf`, `dialogsLoadFailed`).
- **`MingoSubscriptionBindings`** — props the host uses to render the realtime `<DialogSubscription>` component (connection state, approvals, metadata callbacks, replay cursor).
- **`needsAllChatsScope(ownerUserId, currentUserId)`** — determines whether the rail must switch to "All Chats" to display a given dialog.
- **`rawDialogIdToAdopt(activeDialogId, dialog)`** — resolves a Relay global dialog id back to its raw id for NATS subject/list matching.
- **`openNamedDialog(title, steps)`** — creates, opens, and renames a dialog in the correct order to avoid duplicate "New Chat" rows.
- **`mapMingoMessageToUnified(message)`** — converts a `ProcessedMessage` into a `UnifiedChatMessage` via spread, preserving unknown metadata fields.

## Usage Example

```typescript
// Inside MingoChatProvider — call once per session
const { state, subscription, pendingApprovals } = useMingoUnifiedChatState();

return (
  <>
    {subscription.isSubscribed && (
      <DialogSubscription
        dialogId={subscription.activeDialogId}
        onApprove={subscription.onApprove}
        onReject={subscription.onReject}
        onMetadata={subscription.onMetadata}
        onConnectionChange={subscription.onConnectionChange}
      />
    )}
    <EmbeddableChat mingoState={state} pendingApprovals={pendingApprovals} />
  </>
);
```

Other surfaces access the shared result without re-invoking the hook:

```typescript
const { state, sendInNewDialog } = useMingoChatSurface();
```
