# use-mingo-realtime-subscription.ts

Manages real-time subscriptions to Mingo (AI assistant) dialog streams over NATS JetStream, handling subscription lifecycle, connection state tracking, and chunk processing for streaming chat responses.

## Key Components

- **`useMingoRealtimeSubscription(activeDialogId, options)`** — Hook that manages the set of dialogs currently subscribed to real-time updates. Tracks per-dialog subscription/connection/catch-up state, auto-subscribes the active dialog, and exposes `subscribeToDialog`, `unsubscribeFromDialog`, and `getSubscriptionState`.

- **`useDialogChunkProcessor(dialogId, options)`** — Internal hook wiring a dialog's approve/reject/metadata handlers into the shared message store and delegating chunk accumulation logic to `useChatChunkProcessor` (shared with the tickets processor).

- **`DialogSubscription`** — Headless component (`returns null`) that mounts the actual JetStream subscription (`useJetStreamDialogSubscription`) for a single dialog. Handles:
  - Registering the dialog as an "active view" (suppresses notification popups while on screen).
  - Deduplicating redelivered chunks via `streamSeq` gating.
  - Resolving the effective replay start sequence (`optStartSeq`) from persisted state and stored highest sequence.
  - Dispatching chunks to the processor and noting tool executions (`noteMingoToolExecuted`).
  - Invalidating React Query caches (`mingoDialogQueryKeys`) after catch-up completes.

- **`MINGO_JETSTREAM_TOPIC`** / **`CHAT_CHUNKS_STREAM`** — Constants identifying the NATS topic (`'admin-message'`) and JetStream stream name (`'CHAT_CHUNKS'`) used for Mingo chat streaming.

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription';

function MingoChatPanel({ dialogId }: { dialogId: string }) {
  const { subscribeToDialog, getSubscriptionState, onConnectionChange } =
    useMingoRealtimeSubscription(dialogId);

  const state = getSubscriptionState(dialogId);

  return (
    <>
      <DialogSubscription
        dialogId={dialogId}
        isActive
        onApprove={(requestId) => console.log('approved', requestId)}
        onReject={(requestId) => console.log('rejected', requestId)}
        onConnectionChange={onConnectionChange}
        initialOptStartSeq={null}
        isInitialOptStartSeqReady
      />
      <div>Connected: {state.isConnected ? 'yes' : 'no'}</div>
    </>
  );
}
```

Note: `DialogSubscription` renders nothing visually — it's a side-effect-only component meant to be mounted alongside the dialog UI to drive live updates into the shared `mingo-messages-store`.
