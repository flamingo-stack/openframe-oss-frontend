## Purpose

Provides real-time chat streaming infrastructure for Mingo dialogs via NATS JetStream. It manages dialog subscription lifecycle (`useMingoRealtimeSubscription`) and renders a headless component (`DialogSubscription`) that wires JetStream chunk events into the Mingo message store, deduplicates redelivered chunks, and triggers cache invalidation after catch-up replay.

## Key Components

- **`useMingoRealtimeSubscription(activeDialogId, options)`** — Hook that tracks which dialogs are subscribed, their connection/catch-up state, and auto-subscribes to the active dialog. Returns subscribe/unsubscribe actions and per-dialog state getters.
- **`useDialogChunkProcessor(dialogId, options)`** — Internal hook binding approval/reject/metadata handlers and routing chunks through `useChatChunkProcessor` into the mingo message store.
- **`DialogSubscription`** — Headless React component (returns `null`) that opens a `useJetStreamDialogSubscription` tail for a single dialog, deduplicates chunks by `streamSeq`, records the highest seen sequence, registers the dialog as "on screen" for notification suppression, and invalidates React Query caches after catch-up.
- **`MINGO_JETSTREAM_TOPIC`** / **`CHAT_CHUNKS_STREAM`** — Constants identifying the NATS topic (`admin-message`) and JetStream stream name (`CHAT_CHUNKS`) used for Mingo chat.
- **`UseMingoRealtimeSubscriptionOptions`**, **`DialogSubscriptionState`**, **`UseMingoRealtimeSubscription`**, **`DialogSubscriptionProps`** — Supporting TypeScript interfaces.

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription';

function MingoChatPanel({ activeDialogId }: { activeDialogId: string | null }) {
  const { subscribedDialogs, getSubscriptionState, onConnectionChange } =
    useMingoRealtimeSubscription(activeDialogId);

  return (
    <>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          onConnectionChange={onConnectionChange}
          initialOptStartSeq={null}
          isInitialOptStartSeqReady={true}
          onApprove={requestId => console.log('approved', requestId)}
          onReject={requestId => console.log('rejected', requestId)}
        />
      ))}
    </>
  );
}
```

Each subscribed dialog's live tail runs via its own `DialogSubscription` instance, keeping chunk processing, redelivery gating, and cache invalidation isolated per dialog.
