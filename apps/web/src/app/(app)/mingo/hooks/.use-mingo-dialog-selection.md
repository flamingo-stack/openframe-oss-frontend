## Overview

React hook that manages the selection, loading, and real-time synchronization of a Mingo AI chat dialog, including historical message pagination, streaming state, and approval/rejection workflows for agent-initiated commands.

## Key Components

- **`MINGO_DIALOG_NOT_FOUND`** — Sentinel error message used as a discriminator when a dialog ID resolves to nothing the user can access (deleted, unauthorized, or invalid).
- **`isAwaitingGeneratedTitle(dialog)`** — Determines whether a dialog is still waiting on its asynchronously-generated title, bounded by a max age window, to drive conditional polling.
- **`useMingoDialogSelection()`** — Primary hook returning dialog state, message history, and approval/rejection handlers:
  - `dialogQuery` — `useQuery` fetching dialog metadata via GraphQL, with conditional polling for streaming state and title generation.
  - `messagesQuery` — `useInfiniteQuery` for paginated historical messages, normalized and merged with real-time store data.
  - `handleApprove` / `handleReject` — Optimistic-update handlers for approving/rejecting agent command requests, with composer-lock management and toast error feedback.
  - Integrates with `useMingoMessagesStore` (Zustand) for active dialog ID, message state, typing/streaming indicators, and pagination.

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection';

function MingoDialogPanel() {
  const {
    dialogQuery,
    messagesQuery,
    handleApprove,
    handleReject,
  } = useMingoDialogSelection();

  if (dialogQuery.isLoading) return <LoadingSpinner />;

  if (dialogQuery.error?.message === MINGO_DIALOG_NOT_FOUND) {
    return <EmptyDialogState />;
  }

  return (
    <div>
      <DialogHeader title={dialogQuery.data?.title} />
      <MessageList pages={messagesQuery.data?.pages} />
      <ApprovalActions onApprove={handleApprove} onReject={handleReject} />
    </div>
  );
}
```

Consumers should rely on `activeDialogId` managed internally via the shared `useMingoMessagesStore` to drive which dialog this hook loads and keeps synchronized with real-time streaming updates.
