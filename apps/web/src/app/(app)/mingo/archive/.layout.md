Defines the Next.js metadata configuration and layout export for the Chat Archive route, enabling dynamic page titling while delegating the actual layout rendering to a shared layout component.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title to `"Chat Archive"` using the `routeTitle` utility, ensuring consistent title formatting across the app.
- **`default` export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as the layout for this route segment.

## Usage Example

This file follows the Next.js App Router convention where `layout.tsx` in a route segment provides both metadata and layout structure:

```typescript
// app/(app)/chat-archive/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Chat Archive') };
```

The `routeTitle` helper standardizes how page titles are generated (e.g., appending a suffix like `" | OpenFrame"`), so individual route layouts only need to supply the page-specific label. Since the layout component itself is re-exported rather than redefined, this file's primary responsibility is wiring up metadata for the route while reusing shared layout logic—reducing duplication across similar route segments.

This pattern is common across the `app/(app)/` directory, where each route defines its own `layout.tsx` with unique metadata but shares a common layout structure via re-export.
