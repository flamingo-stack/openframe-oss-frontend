Defines route metadata and layout configuration for the Chat Archive page, setting the browser tab title and delegating rendering to a shared layout component.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title to `"Chat Archive"` using the `routeTitle` utility, ensuring consistent title formatting across the app.
- **Default export** — Re-exports `route-title-layout` as the default layout component for this route segment, avoiding duplicate layout logic.

## Usage Example

This file follows the Next.js App Router convention where a `layout.tsx` file defines shared UI and metadata for a route segment:

```typescript
// app/(app)/chat-archive/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Chat Archive') };
```

Next.js automatically picks up this `layout.tsx` to:
1. Set the document title via the exported `metadata` object.
2. Wrap child pages/components using the shared `route-title-layout` component.

No manual invocation is required—Next.js handles rendering and metadata injection based on file-system routing conventions.
