# mingo-archive-view.tsx

Renders the Mingo archived-chats page, displaying a paginated, infinite-scrolling list of archived dialogs backed by `react-query`'s `useInfiniteQuery`, delegating rendering to the shared `ChatArchivePage` component from `openframe-frontend-core`.

## Key Components

- **`ARCHIVE_PAGE_QUERY_KEY`** — Query key (`['mingo-archived-dialogs', 'archive-page']`) namespaced under `mingo-archived-dialogs` so that archive/unarchive actions elsewhere can invalidate the whole prefix, keeping this list fresh.
- **`ARCHIVE_PAGE_SIZE`** — Page size constant (`20`) used for each fetch.
- **`MingoArchiveView()`** — Default page component that:
  - Fetches archived dialogs page-by-page via `useMingoDialogActions().fetchArchivedDialogs`, using cursor-based pagination (`nextCursor`).
  - Flattens all fetched pages into a single `dialogs` array.
  - Wraps content in `PageLayout` with a title/subtitle.
  - Renders `ChatArchivePage` (embedded mode) with loading, fetching, pagination, and error-retry state wired to the query state.
  - Navigates to a chat on row selection via `routes.mingo.chat(id)`.

## Usage Example

```typescript
import { MingoArchiveView } from './mingo-archive-view';

// Used as a Next.js page/route component
export default function ArchivePage() {
  return <MingoArchiveView />;
}
```

**Notable behavior:**
- `isLoading` is `true` during initial load, next-page fetches, or a retry after an error—ensuring the skeleton UI takes priority over the error state during retries.
- `loadError` only surfaces when **no dialogs are currently displayed**, so a failed subsequent page doesn't clear already-rendered chats.
- Selecting a row navigates to the chat detail view, where archived chats are read-only and expose an "Unarchive" action.
