# mingo-archive-view.tsx

Renders the Mingo archived-chats page: a paged, infinite-scrolling list of archived chat dialogs that lets the reader reopen a chat to read it or unarchive it.

## Key Components

- **`ARCHIVE_PAGE_QUERY_KEY`** — React Query key (`['mingo-archived-dialogs', 'archive-page']`) namespaced under the `mingo-archived-dialogs` prefix so that archiving/unarchiving actions elsewhere can invalidate the whole prefix and keep this list fresh.
- **`ARCHIVE_PAGE_SIZE`** — Page size (20) used for each fetch of archived dialogs.
- **`MingoArchiveView`** — The exported page component. It:
  - Uses `useInfiniteQuery` with `fetchArchivedDialogs` (from `useMingoDialogActions`) to load cursor-paged archived dialogs.
  - Flattens all fetched pages into a single `dialogs` array.
  - Renders `PageLayout` with a title/subtitle wrapping the library's `ChatArchivePage` (embedded mode).
  - Navigates to `routes.mingo.chat(id)` when a dialog row is selected.
  - Computes loading/error/retry state so that a failed first page shows a "Try again" error (only when no dialogs are yet listed), while failures on later pages leave existing rows in place and a retry shows the loading skeleton.

## Usage Example

```typescript
// app/mingo/archive/page.tsx
import { MingoArchiveView } from '@/features/mingo/views/mingo-archive-view';

export default function MingoArchivePage() {
  return <MingoArchiveView />;
}
```

This component is self-contained (no props) and is intended to be rendered directly as a route's page content. It relies on `useMingoDialogActions` for data fetching and `routes.mingo.chat` for navigation, so both must be available in the app's routing and hook context.
