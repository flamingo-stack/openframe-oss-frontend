This file defines a reusable GraphQL fragment string representing the `PolicyReview` guardrail data returned for tool calls in the `/chat/graphql` API, used when selecting fields on `PendingToolCall` and `ExecutingToolData` types.

## Key Components

- **`POLICY_REVIEW_SELECTION`** — A `const` string export containing the GraphQL selection block for the `policyReview` field, including:
  - `decision` — the guardrail's approval/rejection decision
  - `approvalLevel` — required approval tier
  - `policyLevel` — policy strictness tier
  - `operationCodes` — codes identifying the operations evaluated
  - `matchedRules` — list of matched policy rules (`code`, `label`)
  - `reason` — explanation for the decision

**Important note:** `PolicyReviewRule.type` is intentionally excluded from the selection. The ai-agent backend is in the process of removing this field, and including it would cause the entire GraphQL query to fail once the schema no longer supports it.

## Usage Example

```typescript
import { POLICY_REVIEW_SELECTION } from './policy-review-selection';

const PENDING_TOOL_CALL_QUERY = `
  query GetPendingToolCall($id: ID!) {
    pendingToolCall(id: $id) {
      id
      toolName
      ${POLICY_REVIEW_SELECTION}
    }
  }
`;

const EXECUTING_TOOL_DATA_QUERY = `
  query GetExecutingToolData($id: ID!) {
    executingToolData(id: $id) {
      id
      status
      ${POLICY_REVIEW_SELECTION}
    }
  }
`;
```

Compose this constant into any GraphQL query string that needs to fetch guardrail review data, ensuring consistent field selection and avoiding schema-mismatch failures across call sites.
