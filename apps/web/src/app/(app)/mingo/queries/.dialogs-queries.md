# dialogs-queries.ts

GraphQL query and mutation definitions for Mingo chat dialogs, along with helper logic to normalize persisted ASK message data back into the shape used by live NATS stream chunks.

This module centralizes all dialog-related GraphQL operations (listing, renaming, archiving, fetching messages) and solves a subtle GraphQL schema conflict: `AskData.text` is nullable while sibling types' `text` fields are non-nullable, which violates GraphQL's SameResponseShape rule if selected under the same name. The alias/normalize pair works around this so downstream consumers (the core lib's history decoder) always see a consistent `{ type, text, ... }` shape regardless of whether data came from a live stream or a reloaded history query.

## Key Components

- **`ASK_INTRO_ALIAS`** - Constant `'askIntro'`, the alias used to fetch `AskData.text` without triggering GraphQL field-merging conflicts.
- **`normalizeAskMessageData<T>(messageData)`** - Rewrites `askIntro` back to `text` on ASK rows (single object or array), preserving reference identity when unchanged to avoid unnecessary copies.
- **`GET_MINGO_DIALOGS_QUERY`** / **`GET_MINGO_DIALOGS_WITH_PENDING_APPROVAL_QUERY`** - Paginated dialog list queries; the latter adds `pendingApproval` for the live chat list's row status.
- **`GET_MINGO_DIALOG_QUERY`** - Fetches a single dialog with owner, rating, and token usage details.
- **`RENAME_MINGO_DIALOG_MUTATION`**, **`ARCHIVE_MINGO_DIALOG_MUTATION`**, **`UNARCHIVE_MINGO_DIALOG_MUTATION`**, **`COMPACT_MINGO_DIALOG_MUTATION`** - Dialog mutation operations.
- **`getMingoDialogMessagesQuery({ legacyGuide })`** - Builds the full message-history query, selecting `ATTACHMENTS_FRAGMENT` (current backend) or `LEGACY_GUIDE_FRAGMENT` (pre-migration backend) based on the flag.

## Usage Example

```typescript
import {
  GET_MINGO_DIALOGS_WITH_PENDING_APPROVAL_QUERY,
  getMingoDialogMessagesQuery,
  normalizeAskMessageData,
} from './dialogs-queries';

// Fetch chat list with pending approval status
const { data } = await graphqlClient.query({
  query: GET_MINGO_DIALOGS_WITH_PENDING_APPROVAL_QUERY,
  variables: { first: 20 },
});

// Fetch messages, selecting legacy fragment for older backends
const query = getMingoDialogMessagesQuery({ legacyGuide: isLegacyBackend });
const { data: msgData } = await graphqlClient.query({
  query,
  variables: { dialogId, limit: 50 },
});

// Normalize each persisted message row before handing to the core lib decoder
const normalizedEdges = msgData.messages.edges.map(edge => ({
  ...edge,
  node: { ...edge.node, messageData: normalizeAskMessageData(edge.node.messageData) },
}));
```

**Note:** `ASK_INTRO_ALIAS` is pinned to `normalizeAskRow`'s behavior and covered by `dialogs-queries.test.ts` — changing one requires updating the other.
