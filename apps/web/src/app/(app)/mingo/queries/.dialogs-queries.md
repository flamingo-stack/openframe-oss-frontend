GraphQL query and mutation definitions for the Mingo AI dialog system, covering dialog listing, detail retrieval, renaming and archiving. A dialog's messages are read with the core lib's one chat history document (`MINGO_MESSAGES_QUERY`) through `fetchDialogMessagesPage` in `@/lib/dialog-messages-page`.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GET_MINGO_DIALOGS_QUERY` | Query | Paginated list of dialogs with owner info and cursor-based pagination |
| `GET_MINGO_DIALOG_QUERY` | Query | Single dialog detail including stream state, token usage, and rating |
| `RENAME_MINGO_DIALOG_MUTATION` | Mutation | Renames a dialog by ID |
| `ARCHIVE_MINGO_DIALOG_MUTATION` | Mutation | Archives a dialog by ID |
| `UNARCHIVE_MINGO_DIALOG_MUTATION` | Mutation | Restores an archived dialog |

## Usage Example

```typescript
import {
  GET_MINGO_DIALOGS_QUERY,
  GET_MINGO_DIALOG_QUERY,
  RENAME_MINGO_DIALOG_MUTATION,
} from './dialogs-queries';

// Fetch paginated dialogs
const { data } = await gqlClient.query(GET_MINGO_DIALOGS_QUERY, {
  filter: { status: 'ACTIVE' },
  first: 20,
  search: 'network issue',
});

// Fetch a single dialog
const { data: dialog } = await gqlClient.query(GET_MINGO_DIALOG_QUERY, {
  id: 'dialog_abc123',
});

// Rename a dialog
await gqlClient.mutate(RENAME_MINGO_DIALOG_MUTATION, {
  input: { id: 'dialog_abc123', title: 'VPN Troubleshooting' },
});

```

## Notes

- All mutations return a `userErrors` array for field-level validation feedback.
