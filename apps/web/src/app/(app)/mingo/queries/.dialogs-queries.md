GraphQL query and mutation definitions for the Mingo AI dialog system, covering dialog listing, detail retrieval, renaming, archiving, and message fetching.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GET_MINGO_DIALOGS_QUERY` | Query | Paginated list of dialogs with owner info and cursor-based pagination |
| `GET_MINGO_DIALOG_QUERY` | Query | Single dialog detail including stream state, token usage, and rating |
| `RENAME_MINGO_DIALOG_MUTATION` | Mutation | Renames a dialog by ID |
| `ARCHIVE_MINGO_DIALOG_MUTATION` | Mutation | Archives a dialog by ID |
| `UNARCHIVE_MINGO_DIALOG_MUTATION` | Mutation | Restores an archived dialog |
| `getMingoDialogMessagesQuery()` | Function → Query | Full message thread with polymorphic `messageData` fragments (text, tool execution, approval flows, context compaction, errors) |

## Usage Example

```typescript
import {
  GET_MINGO_DIALOGS_QUERY,
  GET_MINGO_DIALOG_QUERY,
  RENAME_MINGO_DIALOG_MUTATION,
  getMingoDialogMessagesQuery,
} from './dialogs-queries';

// Fetch paginated dialogs
const { data } = await gqlClient.query(GET_MINGO_DIALOGS_QUERY, {
  filter: { status: 'ACTIVE' },
  pagination: { limit: 20 },
  search: 'network issue',
});

// Fetch a single dialog
const { data: dialog } = await gqlClient.query(GET_MINGO_DIALOG_QUERY, {
  id: 'dialog_abc123',
});

// Rename a dialog
await gqlClient.mutate(RENAME_MINGO_DIALOG_MUTATION, {
  input: { id: 'dialog_abc123', title: 'VPN Troubleshooting' },
});

// Fetch messages for a dialog
const messagesQuery = getMingoDialogMessagesQuery();
const { data: messages } = await gqlClient.query(messagesQuery, {
  dialogId: 'dialog_abc123',
  limit: 50,
  sortDirection: 'ASC',
});
```

## Notes

- `getMingoDialogMessagesQuery` is a **function** rather than a constant, allowing for potential future dynamic query construction.
- Message `messageData` uses GraphQL inline fragments to handle all Mingo AI message types: `TextData`, `ThinkingData`, `ExecutingToolData`, `ExecutedToolData`, `ApprovalRequestData`, `ApprovalResultData`, `ContextCompactionStartData`, `ContextCompactionEndData`, and `ErrorData`.
- All mutations return a `userErrors` array for field-level validation feedback.
