# dialogs-queries.ts

GraphQL query/mutation definitions and normalization helpers for Mingo dialogs (chat conversations), covering dialog listing, CRUD operations, and paginated message history retrieval with polymorphic `messageData` fragments.

## Key Components

- **`ASK_INTRO_ALIAS`** — Alias (`askIntro`) used to fetch `AskData.text` separately from other `text` fields, working around GraphQL's `SameResponseShape` rule that would otherwise reject the whole query due to nullability mismatches between `AskData.text` (nullable) and other data types' `text` (non-nullable).
- **`normalizeAskMessageData<T>(messageData)`** — Rewrites a persisted `ASK`-type message row (or array of rows) so its aliased `askIntro` field becomes `text`, matching the shape of live NATS stream chunks. Preserves reference identity when unchanged, to avoid unnecessary copies.
- **`GET_MINGO_DIALOGS_QUERY`** — Paginated dialog list query (no pending-approval data).
- **`GET_MINGO_DIALOGS_WITH_PENDING_APPROVAL_QUERY`** — Same as above, plus `pendingApproval` info for row status display in the chat list.
- **`RENAME_MINGO_DIALOG_MUTATION`**, **`ARCHIVE_MINGO_DIALOG_MUTATION`**, **`UNARCHIVE_MINGO_DIALOG_MUTATION`**, **`COMPACT_MINGO_DIALOG_MUTATION`** — Dialog mutation operations.
- **`GET_MINGO_DIALOG_QUERY`** — Fetches a single dialog's full details, including owner (admin/client), rating, and token usage.
- **`getMingoDialogMessagesQuery({ legacyGuide })`** — Factory returning the paginated message-history query, with polymorphic fragments for `TextData`, `ThinkingData`, `AskData`, `ExecutingToolData`, `ApprovalRequestData`, `ErrorData`, etc. The `legacyGuide` flag swaps in `LEGACY_GUIDE_FRAGMENT` for backends predating `AttachmentsData` support.

## Usage Example

```typescript
import {
  GET_MINGO_DIALOGS_WITH_PENDING_APPROVAL_QUERY,
  getMingoDialogMessagesQuery,
  normalizeAskMessageData,
} from './dialogs-queries';

// Fetch dialog list with pending approval badges
const { data } = await graphqlClient.query({
  query: GET_MINGO_DIALOGS_WITH_PENDING_APPROVAL_QUERY,
  variables: { first: 20 },
});

// Build messages query, falling back to legacy guide fragment if needed
const messagesQuery = getMingoDialogMessagesQuery({ legacyGuide: isLegacyBackend });
const { data: messagesData } = await graphqlClient.query({
  query: messagesQuery,
  variables: { dialogId, limit: 50 },
});

// Normalize ASK rows before handing off to the core lib's history decoder
const normalized = messagesData.messages.edges.map(edge => ({
  ...edge.node,
  messageData: normalizeAskMessageData(edge.node.messageData),
}));
```

**Note:** `ASK_INTRO_ALIAS` and `normalizeAskRow` are tightly coupled — changing the alias string requires updating the normalization logic; this pairing is locked by `dialogs-queries.test.ts`.
