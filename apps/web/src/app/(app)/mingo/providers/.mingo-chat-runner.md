## Purpose

This file implements the single "runner" that drives Mingo chat state for an entire session, publishing it into a shared store that multiple UI surfaces can read from, while isolating failures so a crash in the chat state doesn't take down the rest of the app.

## Key Components

- **`useDialogErrorToast(chat)`** — Internal hook that toasts a dialog-level error exactly once per `(dialog, error)` pair per session. Distinguishes a "not found" dialog (clears the active selection) from a transient failure (keeps selection, since a reload could recover it).
- **`MingoChatRunner({ store, onScreen })`** — The component mounted once by `MingoChatProvider` while at least one surface is registered. It calls `useMingoUnifiedChatState()`, publishes the resulting state into `store` via a layout effect (so subscribers render before paint), resets the store on unmount, wires up `useDialogErrorToast`, and conditionally renders `DialogSubscription` to stream realtime message chunks for the active dialog.
- **`MingoChatRunnerBoundary`** — A class-based error boundary wrapping the runner. Catches any crash in chat state, reports it to `store.fail(error)` so surfaces can show a degraded "Mingo is unavailable" UI, and resets the store on unmount so a retry starts clean.

## Usage Example

```typescript
import { MingoChatRunner, MingoChatRunnerBoundary } from './mingo-chat-runner';
import { createMingoChatStore } from './mingo-chat-store';

const store = createMingoChatStore();

function MingoChatProvider({ children, onScreen }: { children: React.ReactNode; onScreen: boolean }) {
  return (
    <MingoChatRunnerBoundary store={store}>
      <MingoChatRunner store={store} onScreen={onScreen} />
      {children}
    </MingoChatRunnerBoundary>
  );
}
```

Surfaces elsewhere in the app read from `store` (e.g., via `useSyncExternalStore`) to render chat messages, errors, or the unavailable state—without each surface independently invoking `useMingoUnifiedChatState()`.
