## mingo-chat-runner.tsx

Hosts the single, session-wide instance of Mingo's unified chat state, publishing it to a shared store consumed by all registered chat surfaces, while isolating state crashes and realtime subscription management from the UI layer.

## Key Components

- **`useDialogErrorToast(state)`** — Internal hook that toasts a user-facing error when the active dialog fails to load. Deduplicates by `(dialogId, error)` key so retries don't stack toasts, and clears the dialog selection when the error is a settled "not found" (vs. a transient network failure, which preserves selection for recovery on reload).

- **`MingoChatRunner({ store, onScreen })`** — The core runner component, mounted once per session by `MingoChatProvider` only while at least one surface is registered. Calls `useMingoUnifiedChatState()` and publishes results to `store` via `useLayoutEffect` (ensuring synchronous pre-paint delivery through `useSyncExternalStore`), resets the store on unmount, wires up the error toast, and conditionally renders `DialogSubscription` to stream realtime message chunks for the active dialog.

- **`MingoChatRunnerBoundary`** — A class-based error boundary wrapping `MingoChatRunner`. Catches any crash in the chat state, forwards the error to `store.fail(...)` so surfaces can observe it via `MingoChatSnapshot.error`, renders `null` while failed, and resets the store on unmount so a subsequent retry starts clean.

## Usage Example

```typescript
import { MingoChatRunner, MingoChatRunnerBoundary } from './mingo-chat-runner';
import { createMingoChatStore } from './mingo-chat-store';

const store = createMingoChatStore();

function MingoChatProvider({ children }: { children: React.ReactNode }) {
  const hasSurface = /* true once a surface registers */ true;

  return (
    <>
      {hasSurface && (
        <MingoChatRunnerBoundary store={store}>
          <MingoChatRunner store={store} onScreen={true} />
        </MingoChatRunnerBoundary>
      )}
      {children}
    </>
  );
}
```

Consumers never render `MingoChatRunner` directly from a surface—it is owned and lifecycle-managed exclusively by `MingoChatProvider`, which mounts it once per session and tears it down when the last surface unregisters.
