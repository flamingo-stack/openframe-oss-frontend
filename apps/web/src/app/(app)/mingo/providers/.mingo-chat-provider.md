# mingo-chat-provider.tsx

Provides the single, session-wide Mingo chat state via React context, ensuring only one copy of chat state exists regardless of how many surfaces (composer dock, chat page, etc.) display it. The state runs only while enabled and at least one surface is registered, mounting with the first surface and unmounting with the last.

## Key Components

- **`MingoChatProvider`** — Root provider mounted once (in AppShell) around the entire layout. Runs the chat state (`MingoChatRunner`) only when `enabled` and at least one surface is registered. Also mounts `MingoCompactionWatchers` whenever enabled, independent of surface registration, so a compaction started from a panel can still report its result after the panel closes.
- **`useMingoChat()`** — Reads the current chat snapshot without registering as a surface (doesn't trigger the state to start). Throws if called outside `MingoChatProvider`.
- **`useMingoChatSurface()`** — Like `useMingoChat()`, but registers the caller as an active surface in a layout effect, causing the chat state to start/keep running while mounted.
- **`useMingoChatThreadOnScreen()`** — Marks the open dialog's thread as "on screen" (used only by the chat page) so its notifications skip the popup and are marked read on arrival.
- **`MingoChat`** interface — Shape returned to consumers: `chat`, `error`, `enabled`, `identityEnabled`, `compactDialog`, `copyDialogLink`, `retry`.

## Usage Example

```typescript
// AppShell: mount once around the whole layout
import { MingoChatProvider } from '@/app/components/mingo-chat-provider';

function AppLayout({ children }: { children: React.ReactNode }) {
  return (
    <MingoChatProvider enabled={isSignedIn && isUnlocked} identityEnabled={isSignedIn}>
      {children}
    </MingoChatProvider>
  );
}

// A component that actually displays the chat (composer dock, chat page, etc.)
import { useMingoChatSurface } from '@/app/components/mingo-chat-provider';

function ComposerDock() {
  const { chat, error, compactDialog, copyDialogLink, retry } = useMingoChatSurface();

  if (error) return <RetryBanner onRetry={retry} />;
  if (!chat) return null;

  return <ChatDock state={chat} onCompact={compactDialog} onCopyLink={copyDialogLink} />;
}

// The chat page additionally marks the thread as on-screen
import { useMingoChatThreadOnScreen } from '@/app/components/mingo-chat-provider';

function ChatPage() {
  useMingoChatThreadOnScreen();
  return <ChatThreadView />;
}
```
