# mingo-chat-provider.tsx

React context provider that owns a single, shared instance of the Mingo chat state for an entire session, allowing multiple UI surfaces (composer dock, chat page, etc.) to read the same state without duplicating list polling or live-tail processing.

## Key Components

- **`MingoChatProvider`** — Mounts once around the whole app layout. Owns the chat store, tracks how many surfaces are registered, and only runs the live chat state (`MingoChatRunner`) when `enabled` is true and at least one surface is registered. Also renders `MingoCompactionWatchers` (outlives individual surfaces to report compaction results).
- **`useMingoChat()`** — Reads the current chat snapshot without causing the state to run. Throws if called outside `MingoChatProvider`.
- **`useMingoChatSurface()`** — Like `useMingoChat()`, but also registers the calling component as an active surface (in a layout effect), causing the chat state to start/continue running while mounted.
- **`useMingoChatThreadOnScreen()`** — Marks the open dialog's thread as "on screen" (used only by the chat page), so its notifications are read on arrival instead of showing a popup.
- **`MingoChat`** (interface) — Shape returned to surfaces: `chat`, `error`, `enabled`, `identityEnabled`, `compactDialog`, `copyDialogLink`, `retry`.

## Usage Example

```typescript
// Mounting the provider once, around the app shell
import { MingoChatProvider } from '@/app/chat/mingo-chat-provider';

function AppShell({ children }: { children: React.ReactNode }) {
  const { isSignedIn, isUnlocked } = useWorkspaceSession();
  const identityEnabled = isSignedIn;

  return (
    <MingoChatProvider enabled={isSignedIn && isUnlocked} identityEnabled={identityEnabled}>
      {children}
    </MingoChatProvider>
  );
}
```

```typescript
// A surface that displays the chat (e.g., the composer dock)
import { useMingoChatSurface } from '@/app/chat/mingo-chat-provider';

function ChatDock() {
  const { chat, error, compactDialog, copyDialogLink, retry } = useMingoChatSurface();

  if (error) return <RetryPanel onRetry={retry} />;
  if (!chat) return null;

  return <ChatDockView chat={chat} onCopyLink={copyDialogLink} onCompact={compactDialog} />;
}
```

```typescript
// Marking the chat page as "on screen" so notifications are read inline
import { useMingoChatThreadOnScreen } from '@/app/chat/mingo-chat-provider';

function MingoChatPage() {
  useMingoChatThreadOnScreen();
  return <ChatThreadView />;
}
```
