Test double module providing fake implementations of `MingoChatProvider`'s dependencies — the unified chat-state hook and the live dialog-tail component — instrumented with counters so tests can assert mount/unmount behavior without a real backend.

## Key Components

- **`fakeChatProbe`** — Shared mutable probe object tracking hook instance counts (`created`, `mounted`), active live tails (`liveTails`, `onScreenTails`), the configured hook `result`, and an optional `crash` error to simulate thrown errors.
- **`resetFakeChatProbe(result)`** — Resets the probe's counters and tails, and sets the value the fake hook should return. Call this before each test.
- **`makeFakeChat(options)`** — Builds a `MingoUnifiedChat` result object with sensible defaults (no active dialog, empty messages/dialogs, no-op callbacks), overridable via `FakeChatOptions`.
- **`useFakeMingoUnifiedChatState()`** — Drop-in replacement for the real chat-state hook. Increments `created`/`mounted` counters on mount, decrements `mounted` on unmount, throws `fakeChatProbe.crash` if set, and returns `fakeChatProbe.result`.
- **`FakeDialogSubscription({ dialogId, onScreen })`** — Drop-in replacement for the live-tail component. Registers `dialogId` in `liveTails` while mounted, and in `onScreenTails` while `onScreen` is true, cleaning up both on unmount.

## Usage Example

```typescript
import { vi } from 'vitest';
import {
  fakeChatProbe,
  resetFakeChatProbe,
  makeFakeChat,
  useFakeMingoUnifiedChatState,
  FakeDialogSubscription,
} from './fake-mingo-chat';

vi.mock('../../hooks/use-mingo-unified-chat-state', () => ({
  useMingoUnifiedChatState: useFakeMingoUnifiedChatState,
}));
vi.mock('../dialog-subscription', () => ({
  DialogSubscription: FakeDialogSubscription,
}));

beforeEach(() => {
  resetFakeChatProbe(makeFakeChat({ activeDialogId: 'dialog-1' }));
});

it('mounts exactly one chat state for the session', () => {
  render(<MingoChatProvider />);
  expect(fakeChatProbe.mounted).toBe(1);
});

it('runs the live tail only while the surface is registered', () => {
  const { unmount } = render(<SomeSurface dialogId="dialog-1" />);
  expect(fakeChatProbe.liveTails).toContain('dialog-1');
  unmount();
  expect(fakeChatProbe.liveTails).not.toContain('dialog-1');
});
```
