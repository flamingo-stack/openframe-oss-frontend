Test double module that replaces `MingoChatProvider`'s two runtime dependencies — the chat-state hook and the live-tail dialog subscription component — with instrumented fakes. It exposes a shared probe object so tests can assert on mount/unmount counts and crash behavior without wiring up a real backend.

## Key Components

- **`fakeChatProbe`** — Mutable singleton tracking hook creation/mount counts, mounted live-tail dialog ids (`liveTails`), on-screen tail ids (`onScreenTails`), the fake result to return, and an optional error to throw.
- **`resetFakeChatProbe(result)`** — Resets all probe counters/arrays and sets the `MingoUnifiedChat` result to be returned by the fake hook. Call this before each test.
- **`makeFakeChat(options?)`** — Builds a complete `MingoUnifiedChat` object with sensible defaults (empty dialogs/messages, no-op handlers), overridable via `FakeChatOptions` (`activeDialogId`, `dialogError`, `isMessagesLoading`, `selectDialog`, `sendInNewDialog`).
- **`useFakeMingoUnifiedChatState()`** — Drop-in replacement for the real hook; increments `created`/`mounted` counters on mount, decrements on unmount, throws `fakeChatProbe.crash` if set, and returns `fakeChatProbe.result` (throws if not initialized via `resetFakeChatProbe`).
- **`FakeDialogSubscription`** — Drop-in replacement for the live-tail component; tracks its `dialogId` in `liveTails` while mounted, and additionally in `onScreenTails` when the `onScreen` prop is `true`. Renders nothing.

## Usage Example

```typescript
import { vi, beforeEach, test, expect } from 'vitest';
import {
  fakeChatProbe,
  resetFakeChatProbe,
  makeFakeChat,
  useFakeMingoUnifiedChatState,
  FakeDialogSubscription,
} from './fake-mingo-chat';

vi.mock('../../hooks/use-mingo-unified-chat-state', () => ({
  useMingoUnifiedChatState: useFakeMingoUnifiedChatState,
}));
vi.mock('./dialog-subscription', () => ({
  DialogSubscription: FakeDialogSubscription,
}));

beforeEach(() => {
  resetFakeChatProbe(makeFakeChat({ activeDialogId: 'dialog-1' }));
});

test('mounts a single chat state for the session', () => {
  render(<MingoChatProvider />);
  expect(fakeChatProbe.mounted).toBe(1);
});

test('live tail only runs while registered', () => {
  render(<MingoChatProvider />);
  expect(fakeChatProbe.liveTails).toContain('dialog-1');
});
```
