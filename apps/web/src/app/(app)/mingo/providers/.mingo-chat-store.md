# mingo-chat-store.ts

An external store that distributes the single running Mingo chat state to multiple consuming surfaces (e.g., dock, panel) without requiring them to share a React component tree. It exists because the chat state is computed by a component mounted beside the app layout rather than above it, so the value must be published rather than passed down as props.

## Key Components

- **`MingoChatState`** — Type alias for `MingoUnifiedChat` minus `subscription`, since the live-tail subscription (`<DialogSubscription>`) must be rendered exactly once by the provider to avoid double-applying chat chunks.
- **`MingoChatSnapshot`** — Shape of the published state: `{ chat, error }`. `chat` is `null` when idle, disabled, or failed. `error` persists until all surfaces unmount, ensuring a remounted surface starts fresh.
- **`IDLE_MINGO_CHAT`** — Frozen constant representing the initial/idle snapshot.
- **`MingoChatStore`** — Interface exposing `getSnapshot`, `subscribe`, `publish`, `fail`, and `reset`, designed for use with React's `useSyncExternalStore`.
- **`createMingoChatStore()`** — Factory that creates a store instance with internal listener management and change detection (`isSameChat` does field-by-field `Object.is` comparison to avoid unnecessary re-renders from freshly rebuilt objects).

## Usage Example

```typescript
import { createMingoChatStore } from './mingo-chat-store';
import { useSyncExternalStore } from 'react';

// Created once, shared via context or module scope
const mingoChatStore = createMingoChatStore();

// Producer: the component that owns the live chat state
function MingoChatProvider() {
  const chat = useMingoUnifiedChatState();
  useEffect(() => {
    mingoChatStore.publish(chat);
    return () => mingoChatStore.reset();
  }, [chat]);
  // ... renders <DialogSubscription> once
}

// Consumer: any surface that needs to read the chat state
function MingoDock() {
  const { chat, error } = useSyncExternalStore(
    mingoChatStore.subscribe,
    mingoChatStore.getSnapshot
  );

  if (error) return <RetryButton />;
  if (!chat) return null;
  return <ChatPanel chat={chat} />;
}
```
