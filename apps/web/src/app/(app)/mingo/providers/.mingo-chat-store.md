# mingo-chat-store.ts

An external store that broadcasts the single running Mingo chat state to every UI surface (dock, panels, etc.) that needs to read it, without requiring those surfaces to share a common React tree ancestor with the component that computes the state.

This pattern is necessary because the chat state is computed by a component rendered alongside the layout — it must mount/unmount independently without remounting the layout shell — so the state can't be passed via props. Instead it's published to a store, and consumers subscribe via `useSyncExternalStore` so only the components reading the chat state re-render, not the surrounding shell.

## Key Components

- **`MingoChatState`** — The chat state shape exposed to surfaces: everything from `MingoUnifiedChat` except `subscription`, since only the provider should own the live-tail subscription (`<DialogSubscription>`) to avoid double-applying chunks.
- **`MingoChatSnapshot`** — Immutable snapshot shape with `chat` (null when idle/disabled/failed) and `error` (persisted until all surfaces unmount, so a remount starts fresh).
- **`IDLE_MINGO_CHAT`** — Frozen default snapshot representing no active chat.
- **`MingoChatStore`** — Interface with `getSnapshot`, `subscribe`, `publish`, `fail`, and `reset` for store consumers (typically via `useSyncExternalStore`).
- **`createMingoChatStore()`** — Factory that creates a store instance with listener management and change detection (field-by-field equality via `isSameChat` to avoid redundant notifications when a new object with identical values is published).

## Usage Example

```typescript
import { createMingoChatStore } from './mingo-chat-store';
import { useSyncExternalStore } from 'react';

const mingoChatStore = createMingoChatStore();

// Producer: the component computing chat state
function ChatStateProducer() {
  const chat = useMingoUnifiedChatState();
  useEffect(() => {
    mingoChatStore.publish(chat);
    return () => mingoChatStore.reset();
  }, [chat]);
  return null;
}

// Consumer: any surface needing the chat state
function MingoDock() {
  const { chat, error } = useSyncExternalStore(
    mingoChatStore.subscribe,
    mingoChatStore.getSnapshot
  );

  if (error) return <RetryButton />;
  if (!chat) return <IdleState />;
  return <ChatPanel chat={chat} />;
}
```
