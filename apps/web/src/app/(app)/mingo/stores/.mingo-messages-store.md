## mingo-messages-store.ts

Zustand store managing Mingo AI assistant chat state. This is "Phase 4" of chat unification: actual message accumulation lives in shared reducers from `createChatDialogStore` (one per dialog), while this store provides persistence/cache, identity bookkeeping, and a read mirror of each reducer's snapshot (messages, streaming phase, streaming bubble id, token usage) so existing selectors continue to work unchanged.

## Key Components

- **`mingoChatDialogStore`** — the underlying lib dialog store backing all per-dialog reducers, built via `createReducerMirror`.
- **`setMingoChatHandlers(dialogId, handlers)`** — merges NATS handlers (approve/reject, metadata) registered by separate effects for a dialog.
- **`bindMingoDialog(dialogId)`** — returns a memoized `BoundMirror` (`apply`/`mutate`/`mergeApprovalStatuses`) curried for one dialog.
- **`mutateMingoDialog(dialogId, fn)`** — runs non-wire reducer commands (e.g., optimistic sends, pagination) against a dialog and syncs the mirror.
- **`useMingoMessagesStore`** — the main zustand hook (with `devtools`) exposing:
  - Read-mirror maps: `messagesByDialog`, `phaseByDialog`, `streamingIdByDialog`, `tokenUsageByDialog`
  - Dialog/session state: `activeDialogId`, `unreadCounts`, `highestStreamSeqByDialog`
  - Loading/error/pagination flags
  - Thread command actions: `setMessages`, `prependMessages`, `pushOptimisticSend`, `updateMessage`, `updateApprovalStatusInMessages`, etc.
  - `setActiveDialogId` — pins the active dialog against reducer eviction and manages an LRU window (`MAX_CACHED_DIALOGS`) of recently opened dialogs, dropping caches for stale ones.

## Usage Example

```typescript
import { useMingoMessagesStore, bindMingoDialog, setMingoChatHandlers } from '@/stores/mingo-messages-store';

// Register NATS handlers for approve/reject on a dialog
setMingoChatHandlers('dialog-123', {
  onApprove: requestId => console.log('approved', requestId),
});

// Read mirrored state in a component
const messages = useMingoMessagesStore(state => state.messagesByDialog.get('dialog-123') ?? []);
const phase = useMingoMessagesStore(state => state.phaseByDialog.get('dialog-123'));

// Activate a dialog (pins it against eviction, updates recency window)
useMingoMessagesStore.getState().setActiveDialogId('dialog-123');

// Bind reducer commands for direct mutation
const bound = bindMingoDialog('dialog-123');
bound.apply(/* incoming event */);
```
