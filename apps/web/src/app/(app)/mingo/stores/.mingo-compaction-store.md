Zustand store tracking which Mingo dialogs currently have a manual context compaction in progress, used to coordinate `MingoCompactionWatchers` so only one compaction runs per dialog at a time.

## Key Components

- **`useMingoCompactionStore`** — Zustand hook (with `devtools` middleware) exposing the compaction state and actions.
- **`compactingDialogIds: string[]`** — List of dialog IDs currently undergoing compaction.
- **`startCompaction(dialogId): boolean`** — Attempts to mark a dialog as compacting; returns `false` if it's already in progress, otherwise adds the id and returns `true`.
- **`finishCompaction(dialogId): void`** — Removes the dialog id from the in-progress list once the compaction turn completes.
- **`resetCompactions(): void`** — Clears all tracked ids, used when no watcher remains to resolve them (e.g., on cleanup/unmount).

## Usage Example

```typescript
import { useMingoCompactionStore } from './mingo-compaction-store';

function startDialogCompaction(dialogId: string) {
  const { startCompaction, finishCompaction } = useMingoCompactionStore.getState();

  const canStart = startCompaction(dialogId);
  if (!canStart) {
    console.warn('Compaction already in progress for', dialogId);
    return;
  }

  // Open the dialog's chunk stream, send the compaction request...
  runCompactionStream(dialogId).finally(() => {
    finishCompaction(dialogId);
  });
}

// React component usage
function CompactionIndicator({ dialogId }: { dialogId: string }) {
  const isCompacting = useMingoCompactionStore(state =>
    state.compactingDialogIds.includes(dialogId)
  );

  return isCompacting ? <span>Compacting…</span> : null;
}

// Reset on app-level cleanup
useMingoCompactionStore.getState().resetCompactions();
```
