## mingo-context-store.ts

A Zustand store that tracks Mingo's navigation context — the entity detail page currently being viewed (`openView`) and up to 5 recently viewed entities (`recentViews`) — so this working context can be attached to every Mingo chat message.

## Key Components

- **`useMingoContextStore`** — Zustand store (with `devtools` + `persist` middleware) holding:
  - `openView: ContextRefWithLabel | null` — the entity currently open on screen.
  - `recentViews: ContextRefWithLabel[]` — deduped, most-recent-first history, capped at `RECENT_VIEWS_MAX`.
  - `openViewPending: boolean` — transient flag while a detail page is loading its entity (not persisted).
  - `setOpenView(ref)` — sets the open view, rolling the previous one into `recentViews`.
  - `clearOpenView(ref?)` — clears the open view (rolling it into recents), guarded against stale unmount races via an optional expected `ref`.
  - `removeView(ref)` — fully forgets one entity (open view and/or recents entry) without demoting it to recents.
  - `clearRecentViews()` — wipes recent views (debug action).
- **`clearMingoContext()`** — resets in-memory state and clears persisted storage; intended for logout to prevent context leaking across sessions on shared browsers.
- **`rollIntoRecents(recents, ref)`** — internal helper that prepends a ref, dedupes by `type:id`, and caps the list length.
- Only `recentViews` is persisted to localStorage; `openView` is intentionally excluded since it represents "currently mounted" state that has no meaning after a reload.

## Usage Example

```typescript
import { useMingoContextStore, clearMingoContext } from './mingo-context-store';

// In a detail page component (via useTrackOpenView hook)
const setOpenView = useMingoContextStore(state => state.setOpenView);
setOpenView({ type: 'device', id: 'dev-123', label: 'MacBook Pro' });

// On unmount
const clearOpenView = useMingoContextStore(state => state.clearOpenView);
clearOpenView({ type: 'device', id: 'dev-123' });

// In the composer's context dropdown ("x" button)
const removeView = useMingoContextStore(state => state.removeView);
removeView({ type: 'ticket', id: 'tkt-456' });

// On logout
clearMingoContext();
```
