## mingo-launcher-store.ts

A Zustand store that lets any page in the app hand off a request to Mingo (the AI assistant) via the composer dock mounted under every page. It decouples "something wants Mingo to do X" from the dock's lifecycle, queuing a single one-shot request that is drained once the dock is mounted and ready.

## Key Components

- **`MingoDraft`** — Type alias for `ChatPrefillDraft`, representing composer content (text + context chips) relayed verbatim when prefilling a chat.
- **`MingoDockRequest`** — Discriminated union of all possible launcher requests: `prompt`, `draft`, `newChat`, `intent`, `open`, and `whatToAsk`.
- **`useMingoLauncherStore`** — The Zustand store (with devtools middleware) exposing:
  - `dockMounted` / `setDockMounted` — tracks whether the dock is ready to accept requests.
  - `dockRequest` / `consumeDockRequest` — the pending one-shot request and a safe read-and-clear accessor.
  - `sendToMingo(prompt)` — sends a prompt immediately in a new chat.
  - `draftToMingo(draft)` — prefills a new chat's composer without sending.
  - `startNewChat()` — opens Mingo's home with a fresh, empty chat.
  - `startIntentChat(intent)` — starts a chat scoped to creating one entity via a `DialogIntent`.
  - `openDialog(dialogId)` — reopens an existing chat/dialog over the current page.
  - `showWhatToAsk()` — opens the "What to ask Mingo?" suggestions page.

## Usage Example

```typescript
import { useMingoLauncherStore } from './mingo-launcher-store';

// From any page: send a prompt to Mingo in a new chat
function AskMingoButton() {
  const sendToMingo = useMingoLauncherStore(state => state.sendToMingo);
  return <button onClick={() => sendToMingo('Summarize this incident')}>Ask Mingo</button>;
}

// From the composer dock: drain pending requests once mounted
function ComposerDock() {
  const { setDockMounted, consumeDockRequest } = useMingoLauncherStore();

  useEffect(() => {
    setDockMounted(true);
    const request = consumeDockRequest();
    if (request) {
      // handle request.kind: 'prompt' | 'draft' | 'newChat' | 'intent' | 'open' | 'whatToAsk'
    }
    return () => setDockMounted(false);
  }, []);

  return null;
}
```
