# what-to-ask.ts

Builds the "What can I ask Mingo?" suggestion content shown in the chat UI, generating contextual example prompts that reference real online devices from the workspace when a suitable match exists.

## Key Components

- **`WhatToAskDevice`** — Type alias for a device node from `whatToAskDevicesRelayQuery$data`, representing an online device eligible to be named in a prompt.
- **`isWorkstation`, `isServer`, `isWindows`** — Predicate helpers that classify a device by type (`LAPTOP`/`DESKTOP`, `SERVER`) or OS (`WINDOWS`).
- **`mingoIcon(name)`** — Builds a `SuggestionPrompt['icon']` styled with Mingo's accent color, matching the look of Mingo's quick-action chips.
- **`aboutDevice(device, named, unnamed, icon)`** — Produces a `SuggestionPrompt` for a device-specific question. If a device is provided, the chip label and prompt text reference it by name, and the actual message embeds an `@device:<id>` mention (using `CONTEXT_ENTITY_MARKER.DEVICE` and `decodeGlobalId`) so Mingo resolves the exact device even when hostnames collide. Falls back to a generic, unnamed phrasing when no device is available.
- **`buildMingoWhatToAsk(devices)`** — Main export. Given the list of online devices, selects distinct devices per category (Windows device for spooler fix, server for logs, workstation for "slow" diagnosis, any device for DNS) using a `pick` helper that avoids reusing the same device twice and prioritizes more specific matches first. Returns a `WhatToAskContent` object with a question, reply, and three prompt groups: **Diagnose**, **Check**, and **Fix**.

## Usage Example

```typescript
import { buildMingoWhatToAsk, type WhatToAskDevice } from './what-to-ask';

const devices: WhatToAskDevice[] = fetchedDevicesFromQuery;

const content = buildMingoWhatToAsk(devices);

// content.groups[0].label === 'Diagnose'
// Each prompt has a `label` for the chip, an `icon`, and optionally
// a `prompt` string carrying an `@device:<id>` mention to send to Mingo.
content.groups.forEach(group => {
  group.prompts.forEach(suggestion => {
    renderChip(suggestion.label, suggestion.icon, suggestion.prompt);
  });
});
```
