Defines the Next.js metadata configuration and layout export for the Mingo route, generating a standardized page title.

## Key Components

- **`metadata`**: `Metadata` object that sets the page title using `routeTitle('Mingo')`, ensuring consistent title formatting across the app.
- **Default export**: Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as the layout for this route segment.

## Usage Example

This file follows Next.js App Router conventions, where a `layout.tsx` file automatically applies to all pages within the same route segment:

```typescript
// Next.js automatically picks up this layout.tsx for the Mingo route
// and applies the exported metadata to generate the <title> tag.

import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Mingo') };
```

No manual usage is required—Next.js resolves this layout and metadata automatically based on file location within the `app` directory structure. The `routeTitle` helper ensures the "Mingo" page title matches the formatting convention used throughout the rest of the application (e.g., appending a suffix like " | OpenFrame").
