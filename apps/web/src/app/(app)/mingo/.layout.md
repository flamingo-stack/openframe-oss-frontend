Defines page metadata and layout wrapping for a route segment in the Next.js App Router, specifically setting the browser tab title for the "Mingo" section while reusing a shared layout component.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title using the `routeTitle` helper, producing a formatted title string (e.g., `"Mingo"` combined with a base app title).
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as this segment's layout, avoiding duplication of layout logic across routes.

## Usage Example

This file follows the Next.js convention for a `layout.tsx` file co-located within a route segment folder (e.g., `app/(app)/mingo/layout.tsx`). Next.js automatically applies it to all pages under that segment:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Mingo') };
```

To create an analogous layout for a different section, duplicate this pattern and change the label passed to `routeTitle`:

```typescript
export const metadata: Metadata = { title: routeTitle('Devices') };
```

This pattern keeps per-route metadata minimal while centralizing the actual layout markup (navigation, wrappers, providers) in the shared `route-title-layout` component.
