# DetailsSection

A React component that renders the payload/details portion of the Log Details page, dynamically displaying either a single "Details" card or separate "Input"/"Output" cards depending on the log entry type.

## Key Components

- **`DetailsSection`** — Main component that renders one or two `JsonPanel` cards based on the log entry's content.
- **`DetailsSectionProps`** — Props interface accepting an optional `logDetails` (a `LogEntry` or `null`), which is absent while the log is still loading.

The component delegates the logic of splitting raw log details into `input`/`output`/`outputTitle` to the `splitLogDetails` utility, and renders results using the `JsonPanel` component. It also integrates with `useLoadingScope` to show a skeleton state while data loads.

## Usage Example

```typescript
import { DetailsSection } from './details-section';
import type { LogEntry } from '../../logs-page/types/log.types';

function LogDetailsPage({ log }: { log: LogEntry | null }) {
  return (
    <div className="log-details-page">
      {/* Renders a loading skeleton if `log` is null/undefined,
          a single "Details" card for regular logs, or
          "Input"/"Output" cards for script-run logs */}
      <DetailsSection logDetails={log} />
    </div>
  );
}
```

**Behavior notes:**
- When `logDetails` is `undefined`/`null` or `useLoadingScope()` is active, a single loading `JsonPanel` titled "Details" is shown.
- When `logDetails` represents a script run, two panels are rendered: one for `input` (if defined) and one for `output` (with a dynamic `outputTitle`).
- For all other log types, only the output/details panel is rendered.

See [`split-log-details.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/utils/split-log-details.ts) for the data-shaping logic.
