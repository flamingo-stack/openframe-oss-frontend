# json-panel.tsx

A titled, syntax-highlighted JSON display card used on the Log Details page, featuring a "Copy" action and a skeleton loading state for in-flight payloads.

## Key Components

- **`JsonPanel`** — React component that renders a labeled section containing:
  - A header with a title and a "Copy `<title>`" button that copies the pretty-printed JSON to the clipboard, swapping its icon to a checkmark on success.
  - A bordered card body that shows either a code skeleton (while loading) or the pretty-printed, syntax-highlighted JSON (keys, strings/scalars, and punctuation colored distinctly).
- **`JsonPanelProps`** — Props interface:
  - `title: string` — section label, also used in the copy button text and toast messages.
  - `value: unknown` — the raw value to be JSON-formatted and displayed.
  - `loading?: boolean` — optional explicit loading flag (also derived from `useLoadingScope()`).
- **`JSON_PANEL_SKELETON_LINES`** — constant controlling skeleton line count (17) to approximate a typical payload's length while loading.
- **`TOKEN_CLASS`** — maps `JsonToken['type']` (`key`, `string`, `scalar`, `punct`) to Tailwind color classes for syntax highlighting.

Relies on `formatJson` and `tokenizeJson` from `../utils/json-highlight` for formatting/tokenization, and `useCopyToClipboard` for clipboard operations with toast feedback.

## Usage Example

```typescript
import { JsonPanel } from './json-panel';

function LogDetails({ request, response, isLoading }: {
  request: unknown;
  response: unknown;
  isLoading: boolean;
}) {
  return (
    <div className="flex flex-col gap-6">
      <JsonPanel title="Input" value={request} loading={isLoading} />
      <JsonPanel title="Output" value={response} loading={isLoading} />
    </div>
  );
}
```

The component automatically wraps long lines instead of scrolling, preserves string escape sequences (for example, `\n` is shown literally rather than rendered), and integrates with any ancestor `useLoadingScope()` context to infer loading state.
