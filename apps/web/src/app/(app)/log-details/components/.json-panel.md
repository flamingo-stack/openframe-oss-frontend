# JsonPanel

Renders a titled, syntax-highlighted JSON card with a "Copy" action, used on the Log Details page to display pretty-printed input/output payloads. Handles loading states with a skeleton placeholder and preserves string escapes exactly as formatted by the backend.

## Key Components

- **`JsonPanel`** — React component that renders a labeled section containing:
  - A header with the section `title` and a "Copy {title}" button (toggles a check icon on successful copy).
  - A bordered card body showing either a `TextLineSkeleton` (while loading) or syntax-highlighted JSON via `tokenizeJson`.
- **`JsonPanelProps`** — Props interface: `title` (string, used for heading and copy/toast labels), `value` (the raw payload, any type), and optional `loading` flag.
- **`JSON_PANEL_SKELETON_LINES`** — Constant (17) controlling skeleton line count while loading.
- **`TOKEN_CLASS`** — Maps `JsonToken` types (`key`, `string`, `scalar`, `punct`) to Tailwind color classes; punctuation is left unstyled so structural characters read as plain text.

The component relies on `formatJson` and `tokenizeJson` from `../utils/json-highlight` to pretty-print and tokenize the JSON for colored rendering, and on `useCopyToClipboard` for clipboard interaction with success/error toasts.

## Usage Example

```typescript
import { JsonPanel } from './json-panel';

function LogDetails({ log, isLoading }: { log: { request: unknown; response: unknown }; isLoading: boolean }) {
  return (
    <div className="flex flex-col gap-6">
      <JsonPanel title="Input" value={log.request} loading={isLoading} />
      <JsonPanel title="Output" value={log.response} loading={isLoading} />
    </div>
  );
}
```

Loading state can also be driven implicitly via `useLoadingScope()` context (e.g., Suspense boundary), without passing the `loading` prop explicitly.
