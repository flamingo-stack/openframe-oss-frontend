# log-details-view.tsx

Client-side React component that renders the full log details page, including log metadata, device info, and structured sections, with loading, error, and copy-to-clipboard support.

## Key Components

- **`LogDetailsView`** — Main exported component. Accepts `logId`, `ingestDay`, `toolType`, `eventType`, and `timestamp` props to fetch and display a single log entry's details.
- **`EventTypeText`** — Internal helper component rendering the event type caption, with a skeleton placeholder while loading or before the event type resolves.
- **`getSeverityVariant`** — Maps a log severity string (`ERROR`, `WARNING`, `INFO`, `CRITICAL`, `DEBUG`) to a `Tag` variant (`error`, `warning`, `grey`, `critical`).
- **`LOG_MESSAGE_SKELETON_LINES`** — Constant controlling how many skeleton lines render for the log message while loading.

## Behavior Notes

- Uses `useLogDetails` hook to fetch log data based on the identifying props; redirects to the logs list page (`routes.logs.page`) if required props are missing.
- Distinguishes "still loading" from "answered but not found" via `hasAnswered`, showing a "Log Not Found" state only after the fetch completes with no result.
- Renders a `PageLayout` with a back button (via `useSafeBack`) and a "Copy Log Details" action that uses `useCopyToClipboard` and `formatLogDetailsForCopy`.
- Conditionally renders `DeviceInfoSection` only when loading or when the log references a `deviceId`.
- Delegates structured content to `FullInformationSection` and `DetailsSection`.

## Usage Example

```typescript
import { LogDetailsView } from './log-details-view';

export default function LogDetailsPage({
  searchParams,
}: {
  searchParams: {
    logId: string;
    ingestDay: string;
    toolType: string;
    eventType: string;
    timestamp: string;
  };
}) {
  return (
    <LogDetailsView
      logId={searchParams.logId}
      ingestDay={searchParams.ingestDay}
      toolType={searchParams.toolType}
      eventType={searchParams.eventType}
      timestamp={searchParams.timestamp}
    />
  );
}
```
