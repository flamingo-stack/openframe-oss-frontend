# full-information-section.tsx

A React client component that renders a detailed log entry's metadata as a labeled info card, including loading skeleton and empty state handling.

## Key Components

- **`FullInformationSection`** — Main component that displays a log's full metadata (tool event ID, ingest day, tool type, event type, severity, user ID, device ID, timestamp) inside an `InfoCard`.
- **`ROW`** — Constant object defining the canonical set of row labels used both by the loaded card and its loading skeleton, ensuring consistency.
- **`LOADING_SKELETON`** — Defines the skeleton shape (row labels, no title) shown while data is loading via `useLoadingScope`.
- **`FullInformationSectionProps`** — Props interface accepting an optional `logDetails: LogEntry | null`.

## Usage Example

```typescript
import { FullInformationSection } from '@/app/components/full-information-section';

function LogDetailPage({ log }: { log: LogEntry | null }) {
  return (
    <div className="flex flex-col gap-4">
      <FullInformationSection logDetails={log} />
    </div>
  );
}
```

**Behavior notes:**
- While inside a loading scope (`useLoadingScope()` returns `true`), the component renders `InfoCard` with the `LOADING_SKELETON` shape, letting `InfoCard` draw its own skeleton rows.
- If not loading and `logDetails` is `null`/`undefined`, it renders a "No log details available" empty state instead of the card.
- `userId` and `deviceId` rows are conditionally included only when present on `logDetails`.
- The `toolType` row includes a `ToolIcon`, normalized via `normalizeToolTypeWithFallback` and labeled via `toToolLabel`.
- `timestamp` is shown as the raw wire value; the human-formatted date appears elsewhere (the page header).
