Defines page metadata and re-exports the shared layout component for the "Log" route segment, ensuring the browser tab title reflects the current page context.

## Key Components

- **`metadata`** - Next.js `Metadata` object that sets the page title using the `routeTitle` helper, producing a consistent, branded title for the "Log" section.
- **`default` (re-export)** - Re-exports `route-title-layout` as the default layout component for this route segment, avoiding duplication of layout logic across routes.

## Usage Example

This file follows the Next.js App Router convention where a `layout.tsx` file defines metadata and wraps child routes. It's automatically picked up by Next.js for any route under this segment:

```typescript
// app/(app)/log/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Log') };
```

To create a similar layout for another section, replace the string passed to `routeTitle`:

```typescript
export const metadata: Metadata = { title: routeTitle('Settings') };
```

The shared `route-title-layout` component handles rendering the `children` prop and any title-related UI, so individual route segments only need to supply their own `metadata`.
