Defines the Next.js metadata and layout export for the "Log" route segment, setting the browser tab title and delegating layout rendering to a shared layout component.

## Key Components

- **`metadata`** — A `Metadata` object (Next.js App Router convention) that sets the page title via `routeTitle('Log')`, ensuring consistent title formatting across the app.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as this segment's layout, avoiding duplicate layout logic.

## Usage Example

This file follows the Next.js App Router convention where `layout.tsx` automatically applies to all routes within its directory segment. You typically don't import it directly; Next.js picks it up based on file location:

```typescript
// File location: app/(app)/log/layout.tsx
// Next.js automatically wraps all pages under /log with this layout
// and sets the document title using the shared routeTitle helper.

import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Log') };
```

To reuse this pattern for a new route, create a similar `layout.tsx` in the target segment, passing the appropriate section name to `routeTitle`:

```typescript
export const metadata: Metadata = { title: routeTitle('Settings') };
export { default } from '@/app/(app)/route-title-layout';
```
