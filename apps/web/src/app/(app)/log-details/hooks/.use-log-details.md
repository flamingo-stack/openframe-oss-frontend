A React hook for fetching a single log entry's full details via GraphQL, used to resolve deep-linked or drilled-down log views (e.g. from a notification or shared URL) by its composite identifying fields.

## Key Components

- **`useLogDetails()`** — Hook returning state and actions for fetching/clearing log details.
- **`fetchLogDetailsById(logId, ingestDay, toolType, eventType, timestamp)`** — Async callback that queries `GET_LOG_DETAILS_QUERY` via `apiClient.post('/api/graphql', ...)`, updates state, and shows a destructive toast on failure. Returns the resolved `LogEntry | null` and re-throws on error.
- **`clearLogDetails()`** — Resets `logDetails`, `error`, and `hasAnswered` to their initial state.
- **Return values**:
  - `logDetails: LogEntry | null` — the fetched log, or `null` if no match was found (stale/deleted link).
  - `isLoading: boolean` — true while a request is in flight.
  - `hasAnswered: boolean` — true once a request has completed (success, empty, or error), useful for distinguishing "loading" from "not found" in the UI.
  - `error: string | null` — last error message, if any.
- **`LogDetailsResponse`** / **`GraphQlResponse<T>`** — Internal types describing the GraphQL response shape.

## Usage Example

```typescript
'use client';

import { useEffect } from 'react';
import { useLogDetails } from './use-log-details';

function LogDetailPanel({ logId, ingestDay, toolType, eventType, timestamp }: {
  logId: string;
  ingestDay: string;
  toolType: string;
  eventType: string;
  timestamp: string;
}) {
  const { logDetails, isLoading, hasAnswered, error, fetchLogDetailsById, clearLogDetails } =
    useLogDetails();

  useEffect(() => {
    fetchLogDetailsById(logId, ingestDay, toolType, eventType, timestamp).catch(() => {
      // Error already surfaced via toast
    });

    return () => clearLogDetails();
  }, [logId, ingestDay, toolType, eventType, timestamp]);

  if (isLoading) return <p>Loading log details…</p>;
  if (hasAnswered && !logDetails) return <p>Log not found (it may have been deleted).</p>;
  if (error) return <p>Error: {error}</p>;

  return <pre>{JSON.stringify(logDetails, null, 2)}</pre>;
}
```
