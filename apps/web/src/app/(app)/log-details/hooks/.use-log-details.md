# use-log-details.ts

A React hook for fetching a single log entry's full details via GraphQL, used for deep-linking to a specific log (e.g., from a notification or shared URL). Handles loading, error, and "answered" state so consuming pages can distinguish between "still loading" and "loaded but not found".

## Key Components

- **`useLogDetails()`** - Hook that returns log detail state and fetch/clear actions.
- **`fetchLogDetailsById(logId, ingestDay, toolType, eventType, timestamp)`** - Async function that queries `GET_LOG_DETAILS_QUERY` via `apiClient.post('/api/graphql', ...)`, updates state, and shows a destructive toast on failure. Resolves with the fetched `LogEntry` (or `null` if not found) and re-throws errors for caller handling.
- **`clearLogDetails()`** - Resets `logDetails`, `error`, and `hasAnswered` to their initial state.
- **State returned:**
  - `logDetails: LogEntry | null` - the fetched log, or `null` if no match (stale/deleted link).
  - `isLoading: boolean` - true while a request is in flight.
  - `hasAnswered: boolean` - true once a request has completed (success, not-found, or error), used to differentiate initial loading from a confirmed "no log found" state.
  - `error: string | null` - last error message, if any.
- **`LogDetailsResponse`** / **`GraphQlResponse<T>`** - internal types describing the expected GraphQL response shape.

## Usage Example

```typescript
import { useLogDetails } from './use-log-details';

function LogDetailPage({ logId, ingestDay, toolType, eventType, timestamp }: LogDetailParams) {
  const { logDetails, isLoading, hasAnswered, error, fetchLogDetailsById, clearLogDetails } = useLogDetails();

  useEffect(() => {
    fetchLogDetailsById(logId, ingestDay, toolType, eventType, timestamp).catch(() => {
      // Error already surfaced via toast; handle additional UI state here if needed.
    });

    return () => clearLogDetails();
  }, [logId, ingestDay, toolType, eventType, timestamp]);

  if (isLoading || !hasAnswered) return <LoadingSpinner />;
  if (error) return <ErrorBanner message={error} />;
  if (!logDetails) return <NotFoundState message="This log could not be found." />;

  return <LogDetailView log={logDetails} />;
}
```
