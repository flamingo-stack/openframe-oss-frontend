# json-highlight.ts

Provides utilities for pretty-printing JSON values and tokenizing the resulting text into color-coded segments for syntax highlighting in UI components (e.g., JSON viewer panels).

## Key Components

- **`JsonToken`** — Interface representing a single classified slice of pretty-printed JSON text, with a `type` (`'key' | 'string' | 'scalar' | 'punct'`) and raw `text`.
- **`formatJson(value: unknown): string`** — Pretty-prints any value using `JSON.stringify` with 2-space indentation, matching the canonical format used across JSON display/copy features.
- **`tokenizeJson(json: string): JsonToken[]`** — Splits pretty-printed JSON (as produced by `formatJson`) into an array of `JsonToken`s suitable for rendering with per-type styling. It never throws—unrecognized text is simply treated as `punct`.

Internally, a single regex (`JSON_TOKEN`) matches quoted strings (optionally followed by a key-indicating colon) and bare scalars (numbers, `true`, `false`, `null`). Quote characters themselves are always emitted as `punct` tokens, since only the key name or string value between the quotes is colored.

## Usage Example

```typescript
import { formatJson, tokenizeJson } from './json-highlight';

const payload = { name: 'Agent-1', active: true, retries: 3, notes: null };

const pretty = formatJson(payload);
// {
//   "name": "Agent-1",
//   "active": true,
//   ...
// }

const tokens = tokenizeJson(pretty);

for (const token of tokens) {
  switch (token.type) {
    case 'key':
      console.log(`Key: ${token.text}`);
      break;
    case 'string':
      console.log(`String value: ${token.text}`);
      break;
    case 'scalar':
      console.log(`Scalar: ${token.text}`);
      break;
    case 'punct':
      // Render as plain structural text (braces, commas, quotes, whitespace)
      break;
  }
}
```

This pairing is typically used in a Vue component to render each token with a CSS class matching `token.type`, giving JSON panels consistent syntax highlighting.
