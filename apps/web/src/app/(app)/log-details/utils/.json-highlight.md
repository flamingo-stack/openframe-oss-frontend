# json-highlight.ts

Provides utilities for pretty-printing JSON and tokenizing it into typed segments for syntax-highlighted rendering in the UI.

## Key Components

- **`JsonToken`** — Interface representing a single colored token from a JSON document, with `type` (`'key' | 'string' | 'scalar' | 'punct'`) and `text` fields.
- **`formatJson(value: unknown): string`** — Pretty-prints any value using `JSON.stringify` with 2-space indentation, matching the canonical JSON display/copy format used throughout the app.
- **`tokenizeJson(json: string): JsonToken[]`** — Parses pretty-printed JSON text (expected to be output from `formatJson`) into an array of `JsonToken` objects suitable for syntax-colored rendering. Keys and string values are extracted without quotes; quotes themselves, braces, colons, commas, indentation, and line breaks are all classified as `punct`. The tokenizer is resilient and never throws—it simply colors what it recognizes.

## Usage Example

```typescript
import { formatJson, tokenizeJson } from './json-highlight';

const data = { name: 'OpenFrame', active: true, count: 42, meta: null };

const pretty = formatJson(data);
// {
//   "name": "OpenFrame",
//   "active": true,
//   "count": 42,
//   "meta": null
// }

const tokens = tokenizeJson(pretty);

// Render tokens with per-type CSS classes
tokens.forEach(({ type, text }) => {
  console.log(`[${type}] ${text}`);
});
// [punct] { \n  "
// [key] name
// [punct] "
// [punct] :
// [punct]  "
// [string] OpenFrame
// [punct] "
// ...
```

This is typically consumed by a Vue component that renders each token with a class based on `type` to produce colorized JSON output in panels, previews, or API response viewers.
