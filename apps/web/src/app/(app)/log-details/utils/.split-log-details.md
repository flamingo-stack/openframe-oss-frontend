## split-log-details.ts

Utility for parsing and splitting a log entry's `details` JSON payload into separate Input and Output sections for display on the Log Details page. It specifically handles script-run logs where the backend nests the script's input inside `result.input`, lifting that input out so it can be shown side-by-side with the remaining output data.

## Key Components

- **`LogOutputTitle`** — Type alias (`'Output' | 'Details'`) indicating whether the output section has a matching input to pair with.
- **`LogPayloadSections`** — Interface describing the split result: optional `input`, required `output`, and `outputTitle`.
- **`fallbackDetails(log, rawDetails?)`** — Builds a structured placeholder object from a log's identifying fields when `details` is missing or unparseable, ensuring the panel is never empty.
- **`splitLogDetails(log: LogEntry): LogPayloadSections`** — Main export. Parses `log.details` as JSON and:
  - Returns fallback details with title `'Details'` if `details` is absent or invalid JSON.
  - Returns the raw parsed object with title `'Details'` if there's no `result.input` to split out.
  - Otherwise extracts `input` from `result`, removes it from the remaining `result` object (dropping `result` entirely if it becomes empty), and returns `{ input, output, outputTitle: 'Output' }`.

## Usage Example

```typescript
import { splitLogDetails } from './split-log-details';
import type { LogEntry } from '../../logs-page/types/log.types';

function renderLogPanels(log: LogEntry) {
  const { input, output, outputTitle } = splitLogDetails(log);

  if (input !== undefined) {
    renderPanel('Input', input);
  }
  renderPanel(outputTitle, output);
}
```

For a script-run log with `details: '{"result":{"input":{"cmd":"ls"},"exitCode":0}}'`, this produces:

```json
{
  "input": { "cmd": "ls" },
  "output": { "result": { "exitCode": 0 } },
  "outputTitle": "Output"
}
```

For a Fleet audit log with no `result.input`, the full parsed `details` is returned as `output` with `outputTitle: "Details"`.
