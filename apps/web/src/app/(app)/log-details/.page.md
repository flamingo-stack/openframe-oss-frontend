Client-side page component for viewing individual log entry details, extracting required query parameters from the URL and redirecting to the logs list if any are missing.

## Key Components

- **`LogDetailsPage`** — Default export; Next.js page component that reads `id`, `ingestDay`, `toolType`, `eventType`, and `timestamp` from search params, guards against incomplete URLs, and renders `LogDetailsView`.

## Usage Example

```typescript
// Accessed via URL with required query params:
// /logs/details?id=abc123&ingestDay=2024-01-15&toolType=psa&eventType=ticket&timestamp=1705276800

// Missing any param redirects to routes.logs.page
// All params present renders:
<LogDetailsView
  logId="abc123"
  ingestDay="2024-01-15"
  toolType="psa"
  eventType="ticket"
  timestamp="1705276800"
/>
```

## Behavior

| Condition | Result |
|---|---|
| All params present | Renders `LogDetailsView` |
| Any param missing | Redirects to `routes.logs.page` |
| During redirect | Returns `null` (no flash) |
