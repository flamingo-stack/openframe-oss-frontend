Defines the Next.js metadata and layout wrapper for the Users route, ensuring the browser tab title is set consistently using the shared route title utility.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page `title` to `"Users"` via the `routeTitle` helper, ensuring consistent title formatting (e.g., appending app name or suffix) across routes.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as the layout for this route segment, avoiding duplicate layout logic across pages.

## Usage Example

This file follows the Next.js App Router convention for route-level layouts and metadata. It doesn't need to be imported directly—Next.js automatically picks it up based on file location within the `app` directory structure.

```typescript
// Example of the shared utility this file relies on:
// lib/route-title.ts
export function routeTitle(pageName: string): string {
  return `${pageName} | OpenFrame`;
}
```

```typescript
// Example of the shared layout being re-exported:
// app/(app)/route-title-layout.tsx
export default function RouteTitleLayout({ children }: { children: React.ReactNode }) {
  return <>{children}</>;
}
```

Any new route requiring a titled layout can follow this same minimal pattern—import `routeTitle`, re-export the shared layout, and define `metadata` with the desired page name.
