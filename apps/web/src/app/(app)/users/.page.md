Client-rendered Next.js page component that renders the tenant Users management view, gated behind a feature flag that controls access to the tenant management v2 experience.

## Key Components

- **`UsersPage`** — Default export; the page-level React component for the Users route.
- **`useTenantManagementV2Gate`** — Hook that returns the current gate state: `'on'`, `'off'`, or `'loading'`.
- **`TenantPageShell`** — Shared layout wrapper providing consistent page title and error handling for tenant pages.
- **`UsersView`** — Renders the actual users list/content, accepting a `loading` prop to reflect gate resolution state.

## Behavior

The gate determines access to this page:
- `'off'` — The tenant does not have this feature; triggers `notFound()` to render a 404.
- `'loading'` — The gate state is not yet resolved; the page renders normally but passes `loading={true}` down to `UsersView` so it can show an appropriate loading state. This state must never trigger a 404, since it's not a definitive answer.
- Any other value (e.g. `'on'`) — Renders `UsersView` with `loading={false}`.
