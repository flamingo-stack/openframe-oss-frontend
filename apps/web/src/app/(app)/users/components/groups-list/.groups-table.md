# groups-table.tsx

A Relay-powered, paginated data table that lists a customer's directory groups, supporting live search, sortable member counts, infinite scroll, and dedicated loading/empty states.

## Key Components

- **`GroupsTable`** — Public entry point; wraps the query-driven reader in `LoadingSuspense` so a skeleton table renders while data loads.
- **`GroupsTableReader`** — Checks `useLoadingScope()` to decide between rendering placeholder rows (no fetch) or the live query component.
- **`GroupsTableQuery`** — Executes `groupsTableQuery` via `useLazyLoadQuery`, then paginates results with `usePaginationFragment` over `groupsTable_query` fragment (connection: `groupsTable_directoryGroups`).
- **`GroupsRows`** — Builds the `useDataTable` instance, decides between the empty state (no groups at all) vs. the live table (search with no matches keeps the table visible), and renders `LiveTable`.
- **`membersOrderBy(sort)`** — Converts a UI sort direction (`'asc' | 'desc' | null`) into a `DirectoryGroupOrderInput` GraphQL variable, sorting by `DirectoryGroupSortField.MEMBERS`.
- **`GROUPS_PAGE_SIZE`** — Page size constant (20) used for both initial fetch and `loadNext` pagination.

## Usage Example

```typescript
import { GroupsTable, membersOrderBy } from './groups-table';
import { useState } from 'react';

function CustomerGroupsSection({ organizationId }: { organizationId: string }) {
  const [membersSort, setMembersSort] = useState<'asc' | 'desc' | null>(null);
  const [debouncedSearch, setDebouncedSearch] = useState('');
  const [isPending, setIsPending] = useState(false);
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <GroupsTable
      organizationId={organizationId}
      orderBy={membersOrderBy(membersSort)}
      debouncedSearch={debouncedSearch}
      membersSort={membersSort}
      onToggleMembersSort={() =>
        setMembersSort(prev => (prev === 'asc' ? 'desc' : 'asc'))
      }
      isPending={isPending}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
    />
  );
}
```

Note the `orderBy` prop drives the GraphQL query (deferred), while `membersSort` drives what the table header displays immediately on click, keeping the UI responsive before the refetch resolves.
