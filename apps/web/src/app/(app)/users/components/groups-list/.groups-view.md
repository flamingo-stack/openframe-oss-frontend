# groups-view.tsx

Top-level view component for the Customer → Groups page (Figma 733:99271), rendering the groups associated with a customer organization. It owns URL-synced state for search and Members sorting, manages a sticky search toolbar, and delegates row rendering to `GroupsTable`.

## Key Components

- **`GroupsView`** — Default export; client component accepting `organizationId: string`. Responsibilities:
  - Syncs `search` and `membersSort` query params via `useApiParams`.
  - Debounces search input (300ms) using `useSearchParam`.
  - Normalizes `membersSort` to `'asc' | 'desc' | null` and derives a memoized `orderBy` via `membersOrderBy` (used for reference-stable deferred query comparison).
  - Uses `useDeferredQuery` to defer filters/search until data is ready, exposing an `isPending` flag for loading states.
  - Uses `useStickyToolbar` for sticky positioning of the search bar, passing `stickyHeaderOffset` down to the table.
  - Tracks `isEmpty` state (via `onEmptyChange`) to conditionally hide the page title and search toolbar when there are no groups.
  - Renders `PageLayout`, `SearchToolbar`, and `GroupsTable` with the composed state.

## Usage Example

```typescript
import { GroupsView } from '@/app/(customer)/groups/groups-view';

export default function GroupsPage({ params }: { params: { organizationId: string } }) {
  return <GroupsView organizationId={params.organizationId} />;
}
```

This component is intended to be rendered within a route segment where `organizationId` is resolved from the URL or a parent layout, and expects `GroupsTable` to handle actual data fetching/suspense for the group rows.
