# group-row.tsx

Defines the table row model, column configuration, and cell renderers for displaying groups (e.g., customer tenant groups) in a data table, including GraphQL fragment mapping to a row-friendly shape.

## Key Components

- **`GroupRow`** — Interface representing a group table row; all fields except `id` are optional to support loading/skeleton states.
- **`toGroupRow(ref, customerId?)`** — Reads an inline Relay fragment (`groupRowFields_group$key`) and maps it into a `GroupRow`, building the row's `href` via `routes.customers.group`.
- **`groupColumns({ groupHeader, sortable })`** — Returns `ColumnDef<GroupRow>[]` for the table: Group (name/provider/tenant), Members (count, optionally sortable), Feed (tag), and Open (open-in-new-tab button).
- **`MEMBERS_COLUMN_ID`** — Exported column id constant for the Members column, useful for sort state wiring.
- **`GroupCell`** / **`FeedCell`** — Internal cell components rendering provider logo + group name/tenant, and the group's feed tag respectively; both respect `useLoadingScope` for skeleton placeholders.
- **`getGroupRowId(row)`** — Row id accessor for table virtualization/identity.
- **`groupRowHref(row)`** — Returns the row's navigation href or `null`.

## Usage Example

```typescript
import { groupColumns, toGroupRow, getGroupRowId, groupRowHref } from './group-row';

// Map Relay fragment refs to row data
const rows = groupRefs.map(ref => toGroupRow(ref, customerId));

// Build table columns
const columns = groupColumns({ groupHeader: 'Group', sortable: true });

// Use with a data table component
<DataTable
  columns={columns}
  data={rows}
  getRowId={getGroupRowId}
  getRowHref={groupRowHref}
/>
```

This module is typically consumed by a parent table component that fetches group list data via GraphQL, converts each node with `toGroupRow`, and renders it using the `groupColumns` configuration.
