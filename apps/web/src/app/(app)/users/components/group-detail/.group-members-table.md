## Overview

Client component implementing the **Members** section of a directory group detail page (Figma 733:99325). It renders a paginated, live-refreshing table of a group's members (users, nested groups, and devices), supports switching between "Direct" and "Nested" membership scopes via a deferred query, and includes a responsive filter modal for mobile viewports.

## Key Components

- **`GroupMembersSection`** — Top-level exported component. Manages scope state (`Direct`/`Nested`) via `useApiParams`, defers scope changes with `useDeferredQuery` to avoid blocking the UI, and renders the heading, table island, and `FilterModal`.
- **`GroupMembersIsland`** (internal) — Wraps the data-fetching reader in `LoadingSuspense` for loading/gated states.
- **`GroupMembersReader`** (internal) — Branches on `useLoadingScope()` to render an empty skeleton state or delegate to the live query component.
- **`groupMembersTableQuery` / `groupMembersTableFragment`** — Relay GraphQL query and paginated, refetchable fragment (`@connection`) fetching group members scoped by `DirectoryMembershipScope`.
- **`toMemberRow`** — Normalizes a GraphQL `MemberNode` (union of `DirectoryAccount`, `DirectoryGroup`, `OrgDevice`) into a unified `MemberRow` for table rendering, generating navigable hrefs via `routes`.
- **`COLUMNS`** / **`MEMBER_COLUMNS`** — Column definitions for the data table (Member, Type, Customer, Licences, Open-in-new-tab action), including responsive hide breakpoints.
- **`SCOPE_OPTIONS`** — Filter options for Direct vs. Nested membership scope.

## Usage Example

```typescript
import { GroupMembersSection } from '@/app/components/group-detail/members/group-members-table';

function GroupDetailPage({ groupId, customerId }: { groupId: string; customerId?: string }) {
  return (
    <GroupMembersSection
      id={groupId}
      customerId={customerId}
      loading={false}
    />
  );
}
```

**Notes:**
- `members` resolution requires scoping through `Query.directoryGroup` rather than the `DirectoryGroup` node directly, since `DirectoryGroup` is not a `Node` type—pagination is handled via a `@refetchable` fragment on `Query`.
- Scope changes (Direct/Nested) are deferred using `useDeferredQuery` so the filter UI updates instantly while the underlying query transitions without blocking.
- Member rows are polymorphic: user accounts, nested groups, and devices each render distinct cells (`MemberCell`, `MemberTypeCell`, `MemberCustomerCell`) based on `__typename`.
