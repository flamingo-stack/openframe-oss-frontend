# group-member-row.tsx

Renders table cells for members of a group — which may be users, nested subgroups, or devices — reusing the Users list cell components where applicable while providing group/device-specific presentation.

## Key Components

- **`MemberKind`** — Type union of `'user' | 'group' | 'device'` identifying what a member row represents.
- **`MemberRow`** — Interface extending `UserRow` with optional `kind`, `detail` (secondary line text), and `via` (the nested group a member is inherited through).
- **`RecordCell`** — Internal component rendering group/device rows without an avatar or email, keeping name alignment consistent with user rows via an empty avatar-sized placeholder. Shows a monitor icon for devices or provider marks for groups.
- **`MemberCell`** — Public cell renderer that dispatches to `RecordCell` for `'group'`/`'device'` kinds, or `UserCell` for `'user'` kind.
- **`MemberTypeCell`** — Displays the member's type label (`User`/`Group`/`Device`) and, if present, a "via `{group}`" secondary line indicating inheritance through a nested group. Supports loading state via `useLoadingScope`.
- **`MemberCustomerCell`** — Shows customer association: groups display "Counted through its members" (since subgroups have no direct customer assignment), while users/devices delegate to `CustomerCell`.

## Usage Example

```typescript
import { MemberCell, MemberTypeCell, MemberCustomerCell, type MemberRow } from './group-member-row';

const row: MemberRow = {
  id: 'dev-123',
  kind: 'device',
  name: 'DESKTOP-ABC123',
  detail: 'Entra device',
  providers: [],
};

function GroupMemberTableRow({ row }: { row: MemberRow }) {
  return (
    <tr>
      <td><MemberCell row={row} /></td>
      <td><MemberTypeCell row={row} /></td>
      <td><MemberCustomerCell row={row} /></td>
    </tr>
  );
}
```

For a nested group member inherited via another group:

```typescript
const nestedRow: MemberRow = {
  id: 'user-456',
  kind: 'user',
  name: 'Jane Doe',
  via: 'Engineering Team',
};
```
