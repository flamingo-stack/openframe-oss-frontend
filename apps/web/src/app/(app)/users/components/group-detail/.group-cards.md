# group-cards.tsx

Renders the two detail cards shown on a directory group's page (identity/membership info and settings/metadata), consuming a GraphQL fragment and adapting their layout and row dividers to a responsive grid.

## Key Components

- **`GroupCards`** — Main exported component. Accepts a `groupCards_group$key` relay fragment reference (or `null`), resolves it via `useFragment`, and renders two stacked `CardCells` sections. Supports a loading scope where labels render but values show skeletons.
- **`CardCells`** — Internal layout component that renders a list of `CardCell` items inside `DETAIL_CARD_CLASSES`, inserting `RowDivider`s computed by `rowEnds`.
- **`rowEnds`** — Pure function that determines where row dividers should appear based on a responsive 2-column/4-column grid, accounting for `wide` cells that span two columns.
- **`FeedValue`** — Renders the group's feed as a `Tag`, mapping the raw feed string to a label/variant via `groupFeedTag`.
- **`TypeCell`** — Renders the "Type" `InfoCell`, including the provider's logo mark (via `providerMark`) and the human-readable group kind label.
- **`settingsCells`** — Builds the dynamic list of settings-related `CardCell`s (Membership, Membership rule, Source, Created by), filtering out fields that are `null`/absent for a given provider.
- **`CardCell`** (type) — Shape describing a single cell: `key`, `node` (ReactNode), and optional `wide` flag for two-column spanning cells.

## Usage Example

```typescript
import { GroupCards } from '@/app/components/groups/group-detail/group-cards';
import type { groupCards_group$key } from '@/__generated__/groupCards_group.graphql';

function GroupDetailPage({ group }: { group: groupCards_group$key | null }) {
  return (
    <div>
      <GroupCards group={group} />
    </div>
  );
}
```

The component is typically rendered inside a page that provides a Relay fragment reference to a `DirectoryGroup` and wraps loading states using `useLoadingScope`. When `group` is `null` and not in a loading scope, the component renders nothing, deferring the "not found" message to the parent page/title.
