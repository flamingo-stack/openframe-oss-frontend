# group-detail-title.tsx

Renders the title section for the Group Details page, including a back-navigation button and a "Read only" tag indicating that groups cannot be edited from OpenFrame.

## Key Components

- **`GROUP_DETAIL_TITLE`** — Constant string (`"Group Details"`) used as the page title.
- **`groupPageBackRoute(customerId?)`** — Resolves the back-navigation route: the customer's Groups tab if `customerId` is provided, otherwise the Users list.
- **`GroupTitle({ customerId, adornment })`** — Renders a `TitleBlock` with the group title, a back button (via `useSafeBack`), and an optional adornment (e.g., a tag).
- **`GroupDetailTitle({ group, customerId })`** — Wraps `GroupTitle`, reading `readOnlyReasons` from a GraphQL fragment (`groupDetailTitle_group`) and displaying a "Read only" `Tag` with a `FloatingTooltip` explaining why the group is read-only.

## Usage Example

```typescript
import { GroupDetailTitle } from './group-detail-title';
import { useFragment } from 'react-relay';

function GroupDetailsPage({ groupRef, customerId }: { groupRef: any; customerId?: string }) {
  return (
    <div>
      <GroupDetailTitle group={groupRef} customerId={customerId} />
      {/* rest of group details content */}
    </div>
  );
}
```

If only the title and back button are needed (without the read-only tag), use `GroupTitle` directly:

```typescript
import { GroupTitle } from './group-detail-title';

function SimpleGroupHeader({ customerId }: { customerId?: string }) {
  return <GroupTitle customerId={customerId} />;
}
```

The component relies on a Relay fragment (`groupDetailTitle_group`) to fetch `readOnlyReasons`, which is passed to `readOnlyTooltip` to generate the tooltip content explaining why editing is disabled.
