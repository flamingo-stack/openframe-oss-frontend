# edit-user-fields.tsx

Renders the editable field grid for the "Edit User" form in the cloud tenant management module, binding each field to a `react-hook-form` controller and applying per-field lock/disable rules based on the source identity provider (Figma reference 1040:37391).

## Key Components

- **`EditUserFields`** — Main exported component. Renders the responsive field grid (First/Last Name, Customer, Department, Job Title, Manager, Email, Phone, optional Office/Usage Location, Leaving Date), plus an optional `TenantNotice` banner derived from `editUserNotice(record)`. Fields are individually locked via `fieldLocked(record, field)` when the record's provider doesn't support editing them, or disabled entirely while `disabled` (a write in flight) or the record hasn't loaded yet.
- **`TextField`** — Internal helper wrapping a `Controller` around the core `Input` component for simple string fields (`firstName`, `lastName`, `department`, `jobTitle`, `phone`, `officeLocation`, `usageLocation`). Disabling is applied to the rendered `Input`, not the `Controller`, so disabled fields are still submitted.
- **`CustomerField`** — Read-only customer display; renders a comma-joined `Input` when a user has multiple customers, or a disabled `Autocomplete` with an avatar option for a single customer.
- **`customerOption`** — Maps an `EditUserCustomer` to an `AutocompleteOption` with a `SquareAvatar` icon.
- **`FIELD_GRID`** — Shared CSS class string defining the responsive grid layout (1/2/3 columns across breakpoints).
- **`LEAVING_DATE_ID`** — DOM id linking the `FieldWrapper` label to the `DatePicker` input.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { EditUserFields } from './edit-user-fields';
import type { EditUserFormData, EditUserRecord } from './edit-user-form';

function EditUserDialog({ record }: { record: EditUserRecord | null }) {
  const form = useForm<EditUserFormData>({
    defaultValues: {
      firstName: '',
      lastName: '',
      department: '',
      jobTitle: '',
      phone: '',
      manager: null,
      officeLocation: '',
      usageLocation: '',
      leavingDate: null,
    },
  });

  const isSaving = form.formState.isSubmitting;

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <EditUserFields form={form} record={record} disabled={isSaving} />
    </form>
  );
}
```

Note: `record` is `null` until the user record loads; fields render in a locked/disabled state until then. Location fields (`officeLocation`, `usageLocation`) only appear when `showsLocationFields(record)` returns true, and `leavingDate` saves locally without reaching the identity provider.
