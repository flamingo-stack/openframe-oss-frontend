A React client component that renders an autocomplete field for selecting an account's manager, backed by a GraphQL query over directory users scoped to a specific connection and customer.

## Key Components

- **`ManagerField`** — Main exported component. Falls back to a locked (read-only) field when `locked`, or `connectionId`/`customerId` are missing. Otherwise wraps the live query in a `ContentErrorBoundary` so a failed fetch only affects this field, not the whole form.
- **`LockedManager`** — Renders a disabled `Autocomplete` showing only the previously `selected` option, without issuing any network read.
- **`ManagerOptions`** — Fetches directory users via `useLazyLoadQuery`, debounces and defers search input, filters out the account being edited (it cannot be its own manager), and maps accounts to `ManagerOption` items.
- **`ManagerBody`** — Detects whether it's rendering inside a loading scope (e.g., Suspense fallback) via `useLoadingScope`, and skips the network read in that case by delegating to `LockedManager`.
- **`ManagerList`** — Wraps `ManagerBody` in `LoadingSuspense` to show a skeleton while the query resolves.
- **`managerFieldQuery`** — GraphQL query fetching `directoryUsers` filtered by `connectionId`, with optional `search` and a page size capped by `OPTIONS_LIMIT` (50).

## Usage Example

```typescript
import { ManagerField } from '@/app/components/.../manager-field';

function AccountEditForm() {
  const [managerId, setManagerId] = useState<string | null>(null);

  return (
    <ManagerField
      accountId="acct_123"
      connectionId="conn_456"
      customerId="cust_789"
      value={managerId}
      onChange={setManagerId}
      selected={managerId ? { value: managerId, label: 'Jane Doe' } : null}
      locked={false}
      disabled={isSaving}
    />
  );
}
```

Pass `locked` when the field shouldn't be editable (no query executed), and `selected` to display the currently stored manager before the options list resolves or when it falls outside the first page.
