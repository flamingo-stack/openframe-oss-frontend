## Edit User Form

Form model and business logic for editing a directory user's profile, encapsulating field-level validation, provider-based read-only rules (Microsoft/Google/OpenFrame), and diff-based submission payload construction.

## Key Components

- **`editUserFormFragment`** — Relay inline fragment pulling account, directory details, manager, phone, and customer claim data.
- **`editUserSchema(storedUsageLocation)`** — Zod schema factory enforcing field length limits and the two-letter `usageLocation` country code rule.
- **`EditUserFormData` / `EDIT_USER_DEFAULT_VALUES`** — Inferred form type and its blank defaults.
- **`EditUserRecord`** — Normalized view of the selected account used to seed and gate the form.
- **`toEditUserRecord(person)`** / **`readEditUserRecord(ref)`** — Convert raw Relay/GraphQL data into an `EditUserRecord`, or `null` if no account exists.
- **`providerFieldLocked(record, field)`** / **`fieldLocked(record, field)`** — Determine whether a given field is editable based on customer claims, live read status, and provider-supported fields.
- **`showsLocationFields(record)`** — Hides office/usage location for Google Workspace and OpenFrame sources.
- **`editUserNotice(record)`** — Produces a title/description explaining why (part of) the form is locked.
- **`isDeprovisioned(readOnlyReasons)`** — Checks for the deprovisioned read-only reason.
- **`toUpdateInput(record, ...)`** — Builds the mutation input containing only changed, writable fields (truncated in source, but drives the diffing logic).
- **Constants** — `EDIT_USER_TITLE`, `NO_CUSTOMER_REASON`, `DEPROVISIONED_REASON`, `MANAGER_NOT_SYNCED`.

## Usage Example

```typescript
import {
  readEditUserRecord,
  editUserSchema,
  editUserNotice,
  fieldLocked,
  EDIT_USER_DEFAULT_VALUES,
} from './edit-user-form';

function EditUserPanel({ personRef }: { personRef: editUserForm_person$key }) {
  const record = readEditUserRecord(personRef);
  if (!record) return <NotEditable />;

  const schema = editUserSchema(record.values.usageLocation);
  const notice = editUserNotice(record);
  const firstNameLocked = fieldLocked(record, 'firstName');

  const form = useForm({
    defaultValues: record.values ?? EDIT_USER_DEFAULT_VALUES,
    resolver: zodResolver(schema),
  });

  return (
    <Form form={form}>
      {notice && <Alert title={notice.title}>{notice.description}</Alert>}
      <TextField name="firstName" disabled={firstNameLocked} />
    </Form>
  );
}
```
