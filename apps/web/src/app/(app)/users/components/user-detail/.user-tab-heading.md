# user-tab-heading.tsx

A presentational React component that renders a standardized heading block for user-page tabs, aligning the tab title with optional action controls (e.g., buttons) using responsive spacing tokens defined in the design system.

## Key Components

- **`UserTabHeading`** — Functional component accepting:
  - `title: string` — The heading text displayed as an `<h2>`, truncated if it overflows.
  - `actions?: ReactNode` — Optional slot for trailing content (buttons, menus, etc.) aligned to the right of the title.

The component uses responsive utility classes (`content-md:` breakpoint) to adjust the block's minimum height and top padding between mobile (68px block, 36px top offset) and desktop (72px block, 32px top offset) layouts, matching the Figma spec referenced in the source comment (node `1014:1222`, phone variant `1019:35005`).

## Usage Example

```typescript
import { UserTabHeading } from './user-tab-heading';
import { Button } from '@/components/ui/button';

function UserProfileTab() {
  return (
    <>
      <UserTabHeading
        title="Profile Settings"
        actions={<Button variant="primary">Save Changes</Button>}
      />
      {/* Tab content below */}
    </>
  );
}
```

Without actions:

```typescript
import { UserTabHeading } from './user-tab-heading';

function UserOverviewTab() {
  return <UserTabHeading title="Overview" />;
}
```

## Notes

- The `title` is truncated via `truncate` and `min-w-0` to prevent overflow in constrained layouts.
- Styling relies on CSS custom properties (`--spacing-system-m`, `--spacing-system-xl`, `--spacing-system-l`) and the `content-md` responsive variant, so this component should be used within a project configured with the corresponding Tailwind/design-token setup.
