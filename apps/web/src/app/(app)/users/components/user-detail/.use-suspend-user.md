# use-suspend-user.ts

A React hook that suspends or unsuspends a directory user (e.g., Microsoft/Google account) via a Relay mutation, surfacing success, warning, or error feedback through toast notifications.

## Key Components

- **`suspendUserMutation`** — GraphQL mutation (`SetDirectoryUserSuspendedInput`) that toggles a user's suspended state. Fetches fragments (`userDetailHeader_person`, `userDetailsTab_person`) so account-level UI (header button, status tag) updates immediately, while person-level fields refresh on the next page read.
- **`SYNC_PENDING`** — Error code indicating the identity provider accepted the write but hasn't yet reflected it on re-read; treated as a warning rather than a hard failure.
- **`SESSIONS_STILL_OPEN`** — User-facing message clarifying that Microsoft only blocks new sign-ins (existing sessions stay open), unlike Google which revokes sessions on suspend.
- **`SuspendTarget`** — Interface describing the mutation target: `accountId`, `organizationId` (required since unclaimed accounts can't be suspended), and `name` (for toast messages).
- **`useSuspendUser()`** — Hook returning:
  - `setSuspended(target, suspended, onSettled?)` — Commits the mutation. Shows a success toast on completion, a warning toast if only `SYNC_PENDING` errors occurred (with person data still returned), or a destructive toast on hard errors/failures. Calls `onSettled` once the write settles, regardless of outcome.
  - `isSaving` — Boolean mutation-in-flight indicator.

## Usage Example

```typescript
import { useSuspendUser } from '@/hooks/use-suspend-user';

function UserActionButton({ account, organizationId, userName }: Props) {
  const { setSuspended, isSaving } = useSuspendUser();
  const [confirmOpen, setConfirmOpen] = useState(true);

  const handleSuspend = () => {
    setSuspended(
      { accountId: account.id, organizationId, name: userName },
      true,
      () => setConfirmOpen(false), // close confirmation dialog once settled
    );
  };

  return (
    <Button onClick={handleSuspend} disabled={isSaving}>
      {isSaving ? 'Suspending...' : 'Suspend User'}
    </Button>
  );
}
```

Pass `suspended: false` to reverse the action and reinstate sign-in access for the user.
