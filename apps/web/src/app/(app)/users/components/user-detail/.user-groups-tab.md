# user-groups-tab.tsx

Renders the "Groups" tab on a user detail page, displaying the paginated list of directory groups a user belongs to, with infinite-scroll loading and loading/empty states handled via Relay and the shared data table components.

## Key Components

- **`UserGroupsTab`** — Memoized top-level export. Wraps the tab content in `LoadingSuspense` (gated by the `loading` prop) and renders `UserGroupsReader` for the actual data-driven content.
- **`UserGroupsReader`** — Internal component that short-circuits to a placeholder `GroupsTable` when within a loading scope, otherwise delegates to `UserGroupsQuery`.
- **`UserGroupsQuery`** — Fetches group data via `useLazyLoadQuery` and paginates with `usePaginationFragment`, converting GraphQL edges into `GroupRow` objects.
- **`GroupsTable`** — Presentational component rendering `UserTabHeading` and `LiveTable` with columns, loading placeholders, empty state, and infinite scroll footer.
- **`userGroupsTabQuery`** / **`userGroupsTabFragment`** — GraphQL query and `@refetchable` fragment that fetch a user's groups through `directoryAccount(id).groups`, chosen specifically because Relay connections can't be paginated within a plural field (per contract v0.3 §1).
- **`COLUMNS`** — Table column definitions built via `groupColumns`, labeling the header "Group" per Figma spec 1014:2086.

## Usage Example

```typescript
import { UserGroupsTab } from '@/app/components/user-detail/user-groups-tab';

function UserDetailPage({ userId, isPageLoading }: { userId: string; isPageLoading: boolean }) {
  return (
    <UserGroupsTab id={userId} loading={isPageLoading} />
  );
}
```

The component internally manages data fetching, pagination (20 rows per page via `GROUPS_PAGE_SIZE`), and retry behavior (`useRetryKey`), so consumers only need to supply the directory account `id` and an optional external `loading` gate to defer rendering until a parent tab becomes active.
