# detail-card.tsx

A layout primitive module providing a responsive grid card system for displaying detail records (e.g., directory entries). It defines a two-to-four column grid layout with responsive breakpoint behavior and row divider lines between cells.

## Key Components

- **`DETAIL_CARD_CLASSES`** — Exported Tailwind class string for the outer card container. Implements a 2-column grid below the `content-lg` breakpoint and a 4-column grid at/above it, with responsive gap and padding adjustments at `content-md`.
- **`DetailCell`** — Component rendering a single grid cell with consistent padding/alignment (`min-h-20` height at `content-md`+). Accepts `children` and an optional `className` for overrides.
- **`RowDivider`** — Component rendering a horizontal divider line that spans the full grid width, bleeding into the card's padding via negative margins. Its visibility is controlled by the `at` prop (`'narrow'`, `'wide'`, or `'all'`) to match where rows actually break at different column counts.

## Usage Example

```typescript
import { DETAIL_CARD_CLASSES, DetailCell, RowDivider } from './detail-card';

function RecordDetails() {
  return (
    <div className={DETAIL_CARD_CLASSES}>
      <DetailCell>Field A</DetailCell>
      <DetailCell>Field B</DetailCell>
      <RowDivider at="narrow" />
      <DetailCell>Field C</DetailCell>
      <DetailCell>Field D</DetailCell>
      <RowDivider at="wide" />
      <DetailCell>Field E</DetailCell>
      <DetailCell>Field F</DetailCell>
      <DetailCell>Field G</DetailCell>
      <DetailCell>Field H</DetailCell>
    </div>
  );
}
```

Use `at="narrow"` for dividers that should only appear when the grid shows 2 columns, `at="wide"` for dividers only relevant at 4 columns, and `at="all"` when a divider should appear at both breakpoints.
