# user-detail-header.tsx

Renders the title block for a user detail page, showing the person's name, job title, and provider-aware actions (Suspend/Unsuspend, Edit User), including loading and not-found states.

## Key Components

- **`UserTitle`** — Presentational title component wrapping `TitleBlock`. Shows a back button, skeleton loading state, and placeholder actions (`Suspend`, `Edit User`) while data loads.
- **`UserDetailHeader`** — Data-driven header that reads a `userDetailHeader_person$key` GraphQL fragment via `useFragment`, and derives:
  - A "User not found" state (`NotFoundError`) when `person` is `null`.
  - A read-only `Tag` adornment when the account has `readOnlyReasons`.
  - A Suspend/Unsuspend action (or an unavailable, tooltip-explained button) based on account source (Microsoft 365, Google Workspace, OpenFrame), organization ownership, read-only status, and archived status.
  - An Edit User action (or unavailable button) based on whether the account belongs to a customer organization.
  - A `ConfirmDialog` confirmation step before suspending a user.
- **`UnavailableAction`** — Renders a disabled `Button` wrapped in a `FloatingTooltip` explaining why an action can't be performed.
- **`suspendConfirmation` / `suspendTooltip`** — Provider-specific copy generators for suspend confirmation dialogs and tooltips.
- **`USER_DETAIL_TITLE`** — Exported constant used as the fallback page title ("User").

## Usage Example

```typescript
import { UserDetailHeader } from './user-detail-header';
import { useFragment } from 'react-relay';

function UserDetailPage({ queryRef }: { queryRef: PersonQuery$key }) {
  const data = useFragment(userQuery, queryRef);

  return (
    <div>
      <UserDetailHeader person={data.person} />
      {/* rest of the user detail page */}
    </div>
  );
}
```

Standalone loading/title usage:

```typescript
import { UserTitle, USER_DETAIL_TITLE } from './user-detail-header';

function LoadingHeader() {
  return <UserTitle title={USER_DETAIL_TITLE} loading />;
}
```

This component depends on `useSuspendUser` for mutation logic and `useSafeBack` for back-navigation behavior, and expects routing via `routes.users.list` / `routes.users.edit`.
