# link-device-modal.tsx

Modal component for linking a directory record (e.g., an Entra ID entry) to an OpenFrame device/machine. It presents a searchable, radio-selectable list of candidate machines — prioritizing pre-computed suggestions — and commits the link via a GraphQL mutation.

## Key Components

- **`LinkRecord`** — Interface describing the directory record being linked (`id`, `name`, `origin`, and ranked `suggestions`).
- **`LinkDeviceModal`** — Main exported component. Manages search input (debounced + deferred), the picked machine, and the link mutation; renders a `SimpleModal` with Cancel/Link Device actions.
- **`MachineRow`** — Renders a single selectable machine row (type tile, name, "Suggested" tag, status, last-seen time).
- **`MachineList`** — Wraps rows in a `RadioGroup`, or shows an empty-state message.
- **`MachineOptions`** — Fetches devices via `useLazyLoadQuery` (search + filter by `MACHINE_FILTER` statuses), merges suggestions with search results, and auto-clears the pick if it becomes hidden by a new search.
- **`MachineOptionsBody`** / **`MachineOptionsIsland`** — Suspense/loading-scope wrapper: shows only suggestions while loading, then switches to the live query results via `LoadingSuspense`.
- **`linkDeviceModalQuery`** / **`linkDeviceModalMutation`** — GraphQL query (devices search) and mutation (`linkDirectoryDevice`) definitions.
- **`MACHINES_LIMIT`**, **`MACHINE_FILTER`**, **`LINK_FAILED`** — Constants controlling page size, allowed device statuses, and the shared error toast title.

## Usage Example

```typescript
import { LinkDeviceModal, type LinkRecord } from '@/app/components/.../link-device-modal';

function DirectoryRecordActions({ record }: { record: LinkRecord }) {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Link Device</Button>
      {isOpen && (
        <LinkDeviceModal
          record={record}
          onClose={() => setIsOpen(false)}
          onLinked={() => {
            setIsOpen(false);
            refetchAccountDevices();
          }}
        />
      )}
    </>
  );
}
```

**Notes:**
- There is no "unlink" action in this modal; linking is one-directional.
- Devices in `PENDING_DELETION`, `DELETED`, `ARCHIVED`, or `DECOMMISSIONED` states are excluded from results.
- The component should be mounted fresh per `record` so search and selection state reset correctly.
