# user-details-tab.tsx

Renders the "Details" tab of a user profile page, displaying identity, access, and account source information for a directory person using Relay GraphQL fragments. The component handles loading states with skeleton placeholders and merges data from multiple linked accounts (e.g., Microsoft 365, Google) belonging to the same person.

## Key Components

- **`UserDetailsTab`** — Top-level exported component; resolves the GraphQL fragment from `userDetailsTab_person$key` and renders `UserDetailsCards`, returning `null` if the person doesn't exist and isn't loading.
- **`UserDetailsCards`** — Builds the three main sections (Identity, Access, Sources) from the resolved person data.
- **`Section`** — Layout wrapper rendering a titled card section.
- **`StatusValue`** — Displays the account status as a `Tag` with a tooltip, respecting loading scope.
- **`CustomerValue`** — Resolves and renders the customer(s) linked to an account, as a logo cell (single) or linked list (multiple).
- **`SourceCell`** / **`SourcesSection`** — Render each linked account's origin (provider + connection, or "Added in OpenFrame"), linking to other accounts belonging to the same person.
- **`accountOrigin`** — Helper resolving a human-readable label for where an account originates.
- **`liveValue`** — Helper distinguishing "Not available" (provider data unread) from "Not set" (empty field).

## Usage Example

```typescript
import { UserDetailsTab } from './user-details-tab';
import { graphql, useLazyLoadQuery } from 'react-relay';

function UserPage({ personId }: { personId: string }) {
  const data = useLazyLoadQuery(
    graphql`
      query UserPageQuery($id: ID!) {
        directoryUser(id: $id) {
          ...userDetailsTab_person
        }
      }
    `,
    { id: personId },
  );

  return <UserDetailsTab person={data.directoryUser} />;
}
```

This component is typically rendered inside a tabbed user-details view, where `person` is passed as a Relay fragment reference (`userDetailsTab_person$key`) resolved higher up the query tree. Pass `null` while awaiting the query or when the user is not found.
