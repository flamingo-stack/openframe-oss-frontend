# user-licences-tab.tsx

Renders the "Licences" tab on the user detail page, displaying the SKUs assigned to a directory account (either directly or inherited via group membership) using a GraphQL Relay query with filtering and loading states.

## Key Components

- **`UserLicencesTab`** — Main exported component (memoized). Accepts `id` (directory account ID) and `loading` (gates the fetch until the tab is active) props, wrapping everything in `LoadingSuspense`.
- **`UserLicencesReader`** — Decides whether to show skeleton rows (while the parent scope is still loading) or fetch real data via `UserLicencesQuery`.
- **`UserLicencesQuery`** — Executes the `userLicencesTabQuery` GraphQL query with `useLazyLoadQuery`, maps results to row data, and renders `LicencesTable`.
- **`LicencesTable`** — Presentational table component combining `UserTabHeading`, `LiveTable`, and a mobile `FilterModal` for the "Assignment" filter (Direct / Via group).
- **`LicenceCell`** — Renders the licence name alongside the directory provider's logo mark.
- **`AssignmentCell`** — Renders `Direct` and/or `Via group` tags; the "Via group" tag shows a tooltip listing the inheriting group names.
- **`toLicenceRow`** — Maps a raw GraphQL `Licence` record into the row shape (`LicenceRow`) consumed by the table.
- **`userLicencesTabQuery`** — GraphQL query fetching `directoryAccount.licenses` (SKU id, name, direct assignment flag, and groups granting the licence).
- **`COLUMNS` / `LICENCE_COLUMNS`** — Column definitions and layout metadata for the licence name and assignment columns.
- **`assignmentFilterFn`** — Client-side filter predicate matching rows against selected assignment types.

## Usage Example

```typescript
import { UserLicencesTab } from './user-licences-tab';

function UserDetailPage({ accountId, tabLoading }: { accountId: string; tabLoading: boolean }) {
  return (
    <UserLicencesTab id={accountId} loading={tabLoading} />
  );
}
```

The component is designed to be rendered within a tabbed layout (e.g., `TabNavigation`) where `loading` reflects whether this tab is currently visible/active, deferring the GraphQL fetch until then. Filtering by assignment type (Direct/Via group) happens entirely client-side since the full licence list for an account is small and fetched in one request.
