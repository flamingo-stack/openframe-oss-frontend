Defines the column layout configuration for the Users list table and the customer-scoped Users tab, along with the pagination page size, used by the shared table skeleton component to render responsive columns.

## Key Components

- **`USER_COLUMNS`** — Column definitions for the global Users list (Figma 733:99047): `user`, `customer`, `devices`, `status`, and `open`, with responsive `hideAt` breakpoints for `customer` (`md`) and `devices` (`lg`).
- **`CUSTOMER_USER_COLUMNS`** — Column definitions for a customer's Users tab (Figma 733:98943): reuses `USER_COLUMNS` ids/headers but with fixed widths for `devices`, `status`, and an additional `license` column, dropping `customer`. Hides `devices` at `md` and `license` at `lg` to preserve the responsive behavior described in Figma frame 889:52494.
- **`STATUS_PHONE_WIDTH`** (internal) — Shared width constant (`flex-none`) ensuring the Status tag stays compact on phone-sized viewports so the user name column retains space.
- **`USERS_PAGE_SIZE`** — Exported constant (`20`) defining the default pagination size for the Users list.

This module is intentionally data-only — it holds no rendering logic. The actual table rendering is handled by `table-column-layout.ts`, which consumes these `TableSkeletonColumn` definitions.

## Usage Example

```typescript
import { USER_COLUMNS, CUSTOMER_USER_COLUMNS, USERS_PAGE_SIZE } from './users-columns';
import { TableSkeleton } from '@/app/components/shared/table-column-layout';

// Render the global Users list
<TableSkeleton columns={Object.values(USER_COLUMNS)} pageSize={USERS_PAGE_SIZE} />

// Render the Users tab within a customer detail page
<TableSkeleton columns={Object.values(CUSTOMER_USER_COLUMNS)} pageSize={USERS_PAGE_SIZE} />
```
