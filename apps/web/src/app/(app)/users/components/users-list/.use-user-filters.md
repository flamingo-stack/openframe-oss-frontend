# use-user-filters.ts

A React hook that fetches and shapes filter facet options (Customer, Status, Licenses) for the Users list, including live counts that narrow as other filters are applied.

This hook queries `directoryUserFilters` via Relay, which computes each facet's counts relative to the *other* active filters (not itself), allowing a filter dropdown to retain its previously selected options even after a selection reduces the result set to zero for that option.

## Key Components

- **`userFiltersQuery`** — GraphQL query (via `graphql` tag) that fetches `customers`, `statuses`, and `licenses` facets, each scored with `value`, `label`, and `count`, scoped by `organizationId`, `search`, and `filter`.
- **`UserFilterOptions`** — Interface describing the shaped output: `customers`, `statuses`, and `licenses`, each an array of `DataTableFilterOption`.
- **`toOptions`** — Internal helper that maps raw facet rows into `DataTableFilterOption[]`, ensuring any already-selected value is preserved (with a zero count) even if the current facet response omits it, using `withSelected`.
- **`useUserFilters`** — The main exported hook. Suspends while loading (via `useLazyLoadQuery`), and returns a `UserFilterOptions` object with labeled, count-aware filter options for customers, statuses, and licenses.

## Usage Example

```typescript
import { useUserFilters } from './use-user-filters';
import { Suspense } from 'react';

function UsersFilterPanel({ organizationId, search, filter, selections }) {
  const { customers, statuses, licenses } = useUserFilters(
    organizationId,
    search,
    filter,
    selections,
  );

  return (
    <>
      <FilterDropdown label="Customer" options={customers} />
      <FilterDropdown label="Status" options={statuses} />
      <FilterDropdown label="License" options={licenses} />
    </>
  );
}

function UsersFiltersWithSuspense(props) {
  return (
    <Suspense fallback={<FiltersSkeleton />}>
      <UsersFilterPanel {...props} />
    </Suspense>
  );
}
```

**Important:** Because this hook uses `useLazyLoadQuery`, it must be rendered within a `Suspense` boundary—ideally the same boundary wrapping the Users list it filters, so loading states stay coordinated.
