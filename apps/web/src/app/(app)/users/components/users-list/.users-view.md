# users-view.tsx

Client component rendering the Users directory view, used both as the standalone `/users` page (all users across all connected tenants) and as an embedded "Users" tab within a customer's organization page. It owns URL-synced search/filter state and coordinates the sticky toolbar with the deferred-loading table beneath it.

## Key Components

- **`UsersViewProps`** — Props interface:
  - `organizationId?: string` — scopes the view to a single customer's users when rendered as a tab.
  - `embedded?: boolean` — when `true`, cancels the page title's top spacing (`EMBEDDED_PAGE_OFFSET`) for tab-in-page rendering.
  - `loading?: boolean` — gates row fetching while an upstream feature flag or guard is still resolving.
- **`UsersView`** — Main exported component. Responsibilities:
  - Reads/writes `search`, `customer`, `status`, and `license` as URL query params via `useApiParams`.
  - Debounces search input (`useSearchParam`, 300ms) and defers filter/search changes (`useDeferredQuery`) to avoid redundant refetches during rapid user input.
  - Manages local UI state for empty-results detection (`isEmpty`) and mobile filter panel visibility (`filtersOpen`).
  - Uses `useStickyToolbar` to pin the search toolbar and compute a sticky header offset passed down to the table.
  - Renders `SearchToolbar` (hidden when results are empty) and `DirectoryUsersTable` wrapped in `LoadingWhen`.

## Usage Example

```typescript
// Standalone /users page — all users across all tenants
import { UsersView } from './users-view';

export default function UsersPage() {
  return <UsersView />;
}
```

```typescript
// Embedded as a tab inside a customer's organization page
import { UsersView } from './users-view';

function CustomerUsersTab({ customerId, flagLoading }: { customerId: string; flagLoading: boolean }) {
  return (
    <UsersView
      organizationId={customerId}
      embedded
      loading={flagLoading}
    />
  );
}
```

Related modules: `DirectoryUsersTable` (renders the paginated rows), `users-filter` (converts `UserSelections` into backend filter objects), and `SearchToolbar` (shared search UI).
