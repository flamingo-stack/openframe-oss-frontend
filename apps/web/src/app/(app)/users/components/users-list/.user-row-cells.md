# user-row-cells.tsx

Defines reusable cell components for rendering user rows in a data table (users list, customer tables, device "Users" tabs). Supports skeleton/loading states via `useLoadingScope`, so the same cells render both populated rows and placeholder rows (`{ id }` only).

## Key Components

- **`UserRow`** — Interface describing a user row's data shape. Only `id` is required; all other fields are optional to support loading placeholders.
- **`ProviderMarks`** — Renders a row of provider logo icons (e.g., which identity console an account belongs to) in front of a user's name.
- **`UserCell`** — Renders the primary "user" cell: avatar, provider marks, truncated name, optional role tag, and email (or an empty-value placeholder).
- **`FirstPlusCountCell`** — Generic "first item + N more" cell (e.g., `"Microsoft 365 E3 +3"`) used for customers, devices, licenses, or groups lists.
- **`CustomerCell`** — Renders a customer's logo plus name(s) via `FirstPlusCountCell`, with a tooltip listing all customer claims, and optionally the tenant name beneath.
- **`StatusCell`** — Renders a status `Tag` with an optional tooltip, plus a "Last sign-in" subtext (hidden on phone breakpoints).

## Usage Example

```typescript
import { UserCell, CustomerCell, StatusCell, type UserRow } from './user-row-cells';

const row: UserRow = {
  id: 'user-1',
  name: 'Jane Doe',
  email: 'jane@example.com',
  providers: ['google'],
  roleTag: 'Global admin',
  customers: [{ name: 'Acme Corp', imageUrl: '/acme.png', claim: 'Admin' }],
  tenant: { name: 'Acme Tenant', provider: 'google' },
  status: { label: 'Active', variant: 'green' },
  lastSignIn: '2024-01-15',
};

function UserTableRow({ row }: { row: UserRow }) {
  return (
    <tr>
      <td><UserCell row={row} /></td>
      <td><CustomerCell row={row} /></td>
      <td><StatusCell row={row} /></td>
    </tr>
  );
}

// Loading placeholder: only `id` provided, components self-render skeleton state
const placeholderRow: UserRow = { id: 'loading-1' };
```

Each cell reads `useLoadingScope()` internally to detect whether it's inside a placeholder row and applies skeleton widths/states automatically—no extra props needed from the caller.
