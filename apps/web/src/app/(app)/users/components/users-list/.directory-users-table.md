## directory-users-table.tsx

Client-side React component that renders a paginated, filterable table of directory users via GraphQL/Relay. Supports two display modes: a global view (all users across tenants, filterable by customer) and a customer-scoped view (users claimed by one customer, filterable by license), reusing shared table infrastructure (`LiveTable`, filter modal, infinite scroll).

## Key Components

- **`DirectoryUsersTable`** — Public entry point; wraps the reader in `LoadingSuspense` so suspense boundaries are scoped to this table only.
- **`DirectoryUsersTableReader`** — Chooses between a loading-placeholder render (via `useLoadingScope`) and the live query-backed component.
- **`DirectoryUsersTableQuery`** — Fetches data with `useLazyLoadQuery` + `usePaginationFragment`, manages retry keys and fetch policy.
- **`toUserRow(node)`** — Maps a GraphQL `PersonNode` into a `UserRow`, merging per-account data (status, admin role, sign-in readability) into a single display row.
- **`buildColumns(options, customerScoped)`** — Builds `ColumnDef<UserRow>[]`, switching between `USER_COLUMNS` (global) and `CUSTOMER_USER_COLUMNS` (customer-scoped) layouts.
- **`filterGroups(options, customerScoped)`** — Produces `FilterGroup[]` for the mobile/phone `FilterModal`, mirroring the column filter definitions.
- **`directoryUsersTableQuery` / `directoryUsersTable_query` fragment** — GraphQL query and refetchable Relay fragment powering pagination (`directoryUsersTablePaginationQuery`).
- **`DirectoryUsersTableProps`** — Props contract including `organizationId`, `backendFilters`, `debouncedSearch`, `selections`, `isPending`, and filter-modal open/close handlers.

## Usage Example

```typescript
import { DirectoryUsersTable } from './directory-users-table';

function UsersPage() {
  const [selections, setSelections] = useState<UserSelections>({});
  const [filtersOpen, setFiltersOpen] = useState(false);

  return (
    <DirectoryUsersTable
      organizationId={undefined} // omit for global users page; pass a customer id for its Users tab
      backendFilters={null}
      debouncedSearch=""
      selections={selections}
      onSelectionsChange={setSelections}
      isPending={false}
      onEmptyChange={(isEmpty) => console.log('empty:', isEmpty)}
      stickyHeaderOffset="64px"
      filtersOpen={filtersOpen}
      onFiltersClose={() => setFiltersOpen(false)}
    />
  );
}
```

Row data flows from `toUserRow`, so each displayed user merges data from all their linked accounts (tenant connections) into one row, with device and license lists flattened for display via `FirstPlusCountCell`.
