## group-presentation.ts

Presentation/formatting utilities that map directory group schema enums (kind, visibility, membership scope, read-only reasons) to human-readable labels for group detail pages, following Figma designs for the group presentation UI.

## Key Components

- **`groupTypeLabel(kind)`** — Returns the display label for a group's type (e.g., "Microsoft 365", "Security").
- **`nestedGroupLabel(kind)`** — Formats a nested subgroup's row label, e.g. `"Security group, nested"`.
- **`groupVisibilityLabel(visibility)`** — Maps visibility enum to label ("Public", "Private", "Hidden membership").
- **`groupMembershipLabel(settings)`** — Builds the membership mode string (e.g. `"Dynamic · processing On"`); returns `null` when the provider has no dynamic membership concept (e.g. Google).
- **`readOnlyTooltip(reasons)`** — Resolves the tooltip explaining why a record is read-only, using the first reason in the list or a fallback message.
- **`pickMembershipScope(current, ticked)`** — Resolves the single effective membership scope from a checkbox-style UI state, defaulting to `DirectoryMembershipScope.DIRECT`.
- **`externalMembersHint(provider)`** — Returns explanatory text for members external to the provider's directory.
- **`membersEmptyMessage(options)`** — Chooses the correct empty-state message for a group's members table based on live-fetch failure, hidden count, and external count.

## Usage Example

```typescript
import {
  groupTypeLabel,
  groupVisibilityLabel,
  groupMembershipLabel,
  readOnlyTooltip,
  membersEmptyMessage,
} from '@/lib/group-presentation';

const typeLabel = groupTypeLabel(group.kind); // "Security"
const visibility = groupVisibilityLabel(group.visibility); // "Private"

const membership = groupMembershipLabel({
  dynamic: group.dynamic,
  membershipPaused: group.membershipPaused,
}); // "Dynamic · processing On" or null

const tooltip = readOnlyTooltip(group.readOnlyReasons);
// "The sync is paused" or default managed-in-directory message

const emptyMsg = membersEmptyMessage({
  liveFailed: false,
  hiddenCount: 0,
  externalCount: 3,
}); // "No members to list here."
```

Each function relies on `presentationFor` from `@/lib/exhaustive-map` to perform exhaustive, type-safe enum-to-label lookups, ensuring all schema enum values are covered at compile time.
