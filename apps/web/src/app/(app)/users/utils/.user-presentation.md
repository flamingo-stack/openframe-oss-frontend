## user-presentation.ts

Presentation-layer utilities that map directory-synced organization user (org user) data—status, sign-in activity, admin roles, MFA state, and group membership—into UI-ready labels, tags, and tooltips. Centralizes formatting logic for user rows and user detail pages across identity provider sources (Microsoft 365, Google Workspace, OpenFrame).

## Key Components

- **`userStatusTag(status)`** – Maps `OrgUserStatus` to a `{ label, variant }` tag, falling back to the raw status in grey for unknown values.
- **`userStatusTooltip(reason, detail)`** – Builds a tooltip combining the human-readable status reason with provider-specific detail text.
- **`lastSignInLabel(lastSignInAt, signInData, form, now?)`** – Formats last sign-in time as relative ("5 min"/"3 h"), calendar date, "Today", or explains why it's unreadable ("Needs Entra ID P1", "Not permitted", "Never").
- **`topAdminRole(topAdmin, source)`** / **`topAdminValue(topAdmin, source)`** – Resolves provider-specific top admin role names (e.g., "Global admin" for Microsoft 365, "Super admin" for Google Workspace).
- **`secondFactorValue(state)`** – Maps `SecondFactorState` to readable MFA status text.
- **`accountAddress(account)`** – Returns the user's email or fallback sign-in name.
- **`providerMarks(source)`** – Returns provider badge list (empty for native OpenFrame users).
- **`groupRefName(group)`** – Resolves a group's display name, falling back to a "deleted" label with id.
- **`firstAndCount(names)`** – Splits a name list into first item + remaining count for "Name +2" style display.
- **`groupFeedTag(feed)`** – Maps `DirectoryFeed` sync mode to a status tag ("Live", "No push", "Polling").
