## device-presentation.ts

Presentation/formatting utilities for device directory records, deriving human-readable labels for a device's originating provider, last-seen status, matched identity keys, and machine linking summaries. This module centralizes string formatting logic referenced from Figma design specs so UI components stay declarative.

## Key Components

- **`DeviceOrigin`** — interface describing how a directory record's source is labeled in a row (`name`) versus in a group member list (`member`).
- **`deviceOrigin(source, sourceId)`** — determines a record's origin (Intune, ChromeOS, Google Workspace mobile, Entra ID, or Google Workspace) by inspecting the `sourceId` prefix or falling back to the `source` provider.
- **`recordDetail(origin, lastSeenAt)`** — builds the subtitle line for a record, e.g. `"Entra ID, last seen 20 minutes ago"`, omitting the time suffix when `lastSeenAt` is invalid/missing.
- **`matchedKeysLabel(keys)`** — converts an array of `DirectoryMatchKey` values into a comma-separated display string (e.g. `"Hostname, OS"`).
- **`machineSummary(type, osVersion)`** — formats a machine's type and OS version into a display string, e.g. `"Laptop, Windows 11 23H2"`.
- **`machineLinkFacts(serialNumber, directorySources)`** — formats serial number and directory-record status for the Link modal, e.g. `"Serial number CND9921, no directory record"`.

## Usage Example

```typescript
import { deviceOrigin, recordDetail, matchedKeysLabel, machineSummary, machineLinkFacts } from './device-presentation';
import { DirectoryMatchKey } from '@/generated/schema-enums';

const origin = deviceOrigin('MICROSOFT_365', 'intune:abc123');
// origin.name === 'Intune'

const detail = recordDetail(origin, '2024-01-15T10:00:00Z');
// "Intune, last seen 3 months ago"

const keysLabel = matchedKeysLabel([DirectoryMatchKey.HOSTNAME, DirectoryMatchKey.OS]);
// "Hostname, OS"

const summary = machineSummary('LAPTOP', 'Windows 11 23H2');
// "Laptop, Windows 11 23H2"

const linkFacts = machineLinkFacts('CND9921', []);
// "Serial number CND9921, no directory record"
```
