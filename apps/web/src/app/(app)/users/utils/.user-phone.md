Reads and normalizes a user's phone number from a Relay GraphQL fragment, reconciling the three possible wire sources (local `phone`, provider `mobilePhone`, provider `businessPhones`) into a single display value with a target indicating where edits should be written back.

## Key Components

- **`userPhoneFragment`** — Inline Relay GraphQL fragment on `DirectoryAccount` selecting `phone` and `details.mobilePhone`/`details.businessPhones`.
- **`PhoneTarget`** — Union type (`'mobile' | 'business' | 'local'`) indicating which of the three wire fields an edit should be written back to.
- **`UserPhone`** — Interface describing the resolved phone state: `phone` (display string, `''` if none), `target` (write-back destination), and `otherBusinessPhones` (remaining business numbers beyond the first, preserved for round-tripping writes).
- **`readUserPhone(ref)`** — Resolves a `userPhone_account$key` into a `UserPhone`, applying priority: mobile phone → first business phone → local phone → fallback to business (for provider accounts with no numbers at all).

## Usage Example

```typescript
import { readUserPhone } from './user-phone';
import type { userPhone_account$key } from '@/__generated__/userPhone_account.graphql';

function UserPhoneField({ accountRef }: { accountRef: userPhone_account$key }) {
  const { phone, target, otherBusinessPhones } = readUserPhone(accountRef);

  return (
    <input
      value={phone}
      placeholder={phone ? undefined : 'No phone number'}
      data-target={target}
      aria-label={`Phone (${target})`}
    />
  );
  // On save, write `phone` back to the field matching `target`,
  // reassembling `businessPhones` as [newValue, ...otherBusinessPhones] when target === 'business'.
}
```

**Resolution priority:**
1. `details.mobilePhone` if present → `target: 'mobile'`
2. First entry of `details.businessPhones` → `target: 'business'`, remainder kept in `otherBusinessPhones`
3. Local `phone` field → `target: 'local'` (also used when `details` is absent entirely, e.g. a failed live read)
4. Otherwise → empty phone, `target: 'business'` (provider account with no numbers at all)
