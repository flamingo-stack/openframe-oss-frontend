## Overview

Defines route-level metadata and layout wiring for the Incidents page in the Next.js App Router. This file sets the browser tab title and delegates layout rendering to a shared layout component.

## Key Components

- **`metadata`** — A Next.js `Metadata` export that sets the document title to `"Incidents"` (formatted via the `routeTitle` helper), enabling consistent, app-wide title formatting.
- **`default export`** — Re-exports `route-title-layout` from `@/app/(app)/route-title-layout` as the layout component for this route segment, avoiding duplication of layout logic across pages.

## Usage Example

This file is automatically picked up by Next.js as the `layout.tsx` for the `incidents` route segment—no manual import is needed. It follows a pattern reusable across other route segments:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Incidents') };
```

To create an analogous layout for another section (e.g., "Assets"), replicate this structure with the updated title string:

```typescript
export const metadata: Metadata = { title: routeTitle('Assets') };
```

This pattern keeps metadata declaration co-located with each route while centralizing shared layout behavior (e.g., navigation chrome, page shell) in `route-title-layout`.
