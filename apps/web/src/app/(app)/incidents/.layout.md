Defines Next.js metadata and layout re-export for the Incidents route segment, setting the browser tab title using a shared route-title utility.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title by calling `routeTitle('Incidents')`, ensuring consistent title formatting across the app.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, delegating actual layout rendering to a common implementation.

## Usage Example

This file follows the Next.js App Router convention and is not imported directly. Placing a `layout.tsx` file in a route segment automatically applies it (and its metadata) to that segment and its children:

```text
app/
  (app)/
    incidents/
      layout.tsx   <- this file
      page.tsx
```

The pattern can be reused for other route segments by adjusting the title string:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Devices') };
```

This keeps layout logic centralized in `route-title-layout` while allowing each route to declare only its page-specific title.
