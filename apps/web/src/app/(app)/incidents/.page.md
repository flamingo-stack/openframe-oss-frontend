# IncidentsPage

Next.js App Router page component that renders the Incidents feature, gated behind a feature flag and organized into tabs (e.g., Current, Snoozed) with per-tab filter state and error isolation.

## Key Components

- **`IncidentsPage`** (default export) — The page component. Responsibilities:
  - Resolves feature-flag gate state via `useIncidentsGate` (`'off' | 'loading' | 'on'`).
  - Calls `notFound()` when the gate is definitively `'off'` (never while merely unresolved).
  - Shows a loading skeleton (`LoadingWhen`) while the gate is unresolved.
  - Syncs the active tab and incident filters via `useApiParams`, defaulting `tab` to `'current'`.
  - Renders `TabNavigation` for switching between `INCIDENTS_TABS`.
  - Clears all filter params (`NO_INCIDENT_FILTERS`) on every tab change, since filters are tab-scoped.
  - Wraps the table in `ContentErrorBoundary`, keyed by `tab` so a tab switch resets any prior error.
  - Renders `IncidentsTable`, keyed by `tab` to force remount (fresh search box, dialogs, refetch counters) per tab.

## Usage Example

This is a route-level page file; Next.js renders it automatically for the matching route. No direct import is typically needed, but the pattern can be reused for similar gated, tabbed pages:

```typescript
'use client';

import { TabNavigation } from '@flamingo-stack/openframe-frontend-core';
import { LoadingWhen } from '@flamingo-stack/openframe-frontend-core/components/ui';
import { useApiParams } from '@flamingo-stack/openframe-frontend-core/hooks';
import { notFound } from 'next/navigation';

export default function ExampleGatedPage() {
  const gate = useFeatureGate(); // 'off' | 'loading' | 'on'
  const { params, setParams } = useApiParams({ tab: { type: 'string', default: 'tab1' } });

  if (gate === 'off') notFound();

  return (
    <LoadingWhen loading={gate === 'loading'}>
      <TabNavigation
        urlSync={false}
        activeTab={params.tab}
        tabs={MY_TABS}
        onTabChange={next => setParams({ tab: next })}
      />
    </LoadingWhen>
  );
}
```
