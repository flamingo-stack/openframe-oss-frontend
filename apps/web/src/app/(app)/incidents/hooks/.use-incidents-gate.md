A client-side hook that determines whether the Incidents module should be enabled, combining feature flag state with application mode restrictions.

## Key Components

- **`useIncidentsGate()`** — Hook returning a `FeatureFlagGate` value indicating whether the Incidents feature is active. It checks the `insights` feature flag via `useFeatureFlagGate`, but forces the gate to `'off'` unless the app is running in SaaS tenant mode (since the underlying insights API is only available in that mode).

## Usage Example

```typescript
import { useIncidentsGate } from '@/app/hooks/use-incidents-gate';

function IncidentsNavLink() {
  const incidentsGate = useIncidentsGate();

  if (incidentsGate === 'off') {
    return null;
  }

  return <NavLink href="/incidents">Incidents</NavLink>;
}
```

## Notes

- This hook enforces a hard dependency: regardless of how the `insights` feature flag is configured, the Incidents module is unavailable outside SaaS tenant mode because its backing API (`insights`) only exists in that deployment mode.
- Relies on [`useFeatureFlagGate`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/hooks/use-feature-flag.ts) and [`isSaasTenantMode`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/lib/app-mode.ts) for its underlying logic.
- Must be used within client components (`'use client'` directive) since it depends on React hooks.
