# use-incident-transitions.ts

A React hook that centralizes the five incident (Insight) status transitions—acknowledge, resolve, archive, reopen, and snooze—behind a single `transition(target, status)` API, shared between the incident list's row menu and the detail view header.

Each transition fires a Relay GraphQL mutation with an optimistic response so the UI updates immediately, then shows a success or error toast based on the result. Snooze is a two-step flow: calling `transition` with `InsightStatus.SNOOZED` stages the target for a confirmation modal, and `confirmSnooze(until)` actually commits the mutation with the chosen date.

## Key Components

- **`TransitionTarget`** — Interface describing the minimal data (`id`, `title`) a transition needs.
- **`useIncidentTransitions(onTransitioned?)`** — Main hook, returns:
  - `transition(target, status)` — Triggers acknowledge/resolve/archive/reopen directly, or stages snooze.
  - `snoozeTarget` — The incident currently pending snooze confirmation (or `null`).
  - `cancelSnooze()` — Clears the pending snooze target.
  - `confirmSnooze(until: Date)` — Commits the snooze mutation with the chosen date.
  - `isMutating` — `true` if any of the five mutations is in flight.
  - `isSnoozing` — `true` specifically while the snooze mutation is in flight.

## Usage Example

```typescript
import { useIncidentTransitions } from './use-incident-transitions';
import { InsightStatus } from '@/generated/schema-enums';

function IncidentRowMenu({ incident, onListRefresh }: { incident: { id: string; title: string }; onListRefresh: () => void }) {
  const { transition, snoozeTarget, cancelSnooze, confirmSnooze, isMutating } =
    useIncidentTransitions(onListRefresh);

  return (
    <>
      <button disabled={isMutating} onClick={() => transition(incident, InsightStatus.ACKNOWLEDGED)}>
        Acknowledge
      </button>
      <button disabled={isMutating} onClick={() => transition(incident, InsightStatus.RESOLVED)}>
        Resolve
      </button>
      <button disabled={isMutating} onClick={() => transition(incident, InsightStatus.SNOOZED)}>
        Snooze
      </button>

      {snoozeTarget && (
        <SnoozeModal
          target={snoozeTarget}
          onCancel={cancelSnooze}
          onConfirm={(date) => confirmSnooze(date)}
        />
      )}
    </>
  );
}
```

Both the incident list and detail header reuse this hook so transition behavior, toasts, and optimistic updates stay consistent across the app.
