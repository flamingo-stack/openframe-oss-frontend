A React hook that centralizes the five incident (insight) status transitions—acknowledge, resolve, archive, reopen, and snooze—used by both the incident list's row menu and the detail view header.

## Key Components

- **`TransitionTarget`** — Interface describing the minimal incident data (`id`, `title`) needed to perform a transition.
- **`useIncidentTransitions(onTransitioned?)`** — Main hook that wires up five Relay mutations (acknowledge, snooze, resolve, archive, reopen) behind a single unified API.
- **`transition(target, status)`** — Dispatches the appropriate mutation based on the target `InsightStatus`. For `SNOOZED`, it defers execution and stores the target for confirmation via a modal.
- **`confirmSnooze(until)`** — Completes the two-step snooze flow by submitting the chosen date/time.
- **`cancelSnooze()`** — Clears the pending snooze target without mutating.
- **Returned state** — `snoozeTarget` (pending snooze incident or `null`), `isMutating` (any mutation in flight), `isSnoozing` (snooze-specific loading state).

Each mutation uses an optimistic response to update the Relay store immediately, and shared `feedback` handlers show success/error toasts (via `getRelayErrorMessage` for backend error messages) and invoke `onTransitioned` so callers can refresh derived data like facet counts.

## Usage Example

```typescript
import { useIncidentTransitions } from './use-incident-transitions';
import { InsightStatus } from '@/generated/schema-enums';

function IncidentRowMenu({ incident, refetchFacets }: { incident: { id: string; title: string }; refetchFacets: () => void }) {
  const { transition, snoozeTarget, cancelSnooze, confirmSnooze, isMutating } =
    useIncidentTransitions(refetchFacets);

  return (
    <>
      <button disabled={isMutating} onClick={() => transition(incident, InsightStatus.ACKNOWLEDGED)}>
        Acknowledge
      </button>
      <button disabled={isMutating} onClick={() => transition(incident, InsightStatus.SNOOZED)}>
        Snooze
      </button>

      {snoozeTarget && (
        <SnoozeModal
          target={snoozeTarget}
          onCancel={cancelSnooze}
          onConfirm={(date) => confirmSnooze(date)}
        />
      )}
    </>
  );
}
```
