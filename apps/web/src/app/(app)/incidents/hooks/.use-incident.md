# use-incident.ts

A React hook module that fetches and provides incident detail data via Relay, acting as the single shared data-fetching point for all UI islands on an incident detail page.

## Key Components

- **`useIncident(incidentId: string): Incident`** — Convenience hook that returns only the incident record, built on top of `useIncidentDetail`.
- **`useIncidentDetail(incidentId: string): { incident: Incident; transitions: IncidentTransitionTable }`** — Core hook that executes `incidentDetailRelayQuery` via `useLazyLoadQuery`, using a `store-and-network` fetch policy and a shared `useRetryKey` as the `fetchKey`. Returns both the transformed incident and its status-transition table.

Because both hooks use identical query variables and fetch policy, Relay deduplicates concurrent calls from multiple components (e.g., header and body) into a single network request, as long as they request the same shape of data.

## Usage Example

```typescript
import { useIncident, useIncidentDetail } from './use-incident';

// Component that only needs the incident record
function IncidentBody({ incidentId }: { incidentId: string }) {
  const incident = useIncident(incidentId);
  return <p>{incident.title}</p>;
}

// Component that also needs transition history
function IncidentHeader({ incidentId }: { incidentId: string }) {
  const { incident, transitions } = useIncidentDetail(incidentId);
  return (
    <header>
      <h1>{incident.title}</h1>
      <StatusTimeline transitions={transitions} />
    </header>
  );
}
```

**Note:** Ensure a shared `useRetryKey` provider wraps sibling components so that a manual "Retry" action correctly invalidates cached rejections for all consumers instead of leaving an unkeyed sibling replaying a stale failed response.
