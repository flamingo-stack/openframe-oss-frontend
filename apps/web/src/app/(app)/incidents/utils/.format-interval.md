Utility for formatting a numeric interval (in seconds) into a human-readable duration string, such as "15 minutes" or "1 hour 30 minutes". It is primarily used to display `Insight.interval` values representing how often a detecting query runs.

## Key Components

- **`UNITS`** — A read-only ordered array of `[label, seconds]` tuples (week, day, hour, minute, second), used to break down a total duration into its largest applicable units.
- **`formatInterval(seconds: number): string`** — Converts a duration in seconds into a readable string composed of the largest non-zero units (e.g., `"1 hour 30 minutes"`). Returns `'Manual'` for zero or negative input.

The function intentionally uses fixed-unit arithmetic (constant seconds per week/day/hour) rather than calendar-based math (like `date-fns`), since the value represents a fixed duration, not a calendar span affected by months or DST.

## Usage Example

```typescript
import { formatInterval } from './format-interval';

formatInterval(0);        // "Manual"
formatInterval(1);        // "1 second"
formatInterval(90);       // "1 minute 30 seconds"
formatInterval(3600);     // "1 hour"
formatInterval(5400);     // "1 hour 30 minutes"
formatInterval(93784);    // "1 day 2 hours 3 minutes 4 seconds"
```

This is typically used in UI components to render the polling/check interval of an `Insight` in a user-friendly format, instead of showing raw seconds.
