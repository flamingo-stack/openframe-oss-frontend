Utility for converting a raw seconds value into a human-readable duration string (e.g., "1 hour 30 minutes"), used to display `Insight.interval` values representing the time between detecting-query runs.

## Key Components

- **`UNITS`** — Ordered, fixed list of `[label, seconds]` tuples (week, day, hour, minute, second), used to greedily decompose the total seconds into the largest applicable units.
- **`formatInterval(seconds: number): string`** — Converts a duration in seconds into a readable string composed of the largest non-zero units (e.g., `"2 days 3 hours"`). Returns `'Manual'` for zero or negative input, indicating no automatic interval is set.

## Usage Example

```typescript
import { formatInterval } from './format-interval';

formatInterval(0);        // "Manual"
formatInterval(-10);      // "Manual"
formatInterval(1);        // "1 second"
formatInterval(90);       // "1 minute 30 seconds"
formatInterval(5400);     // "1 hour 30 minutes"
formatInterval(694800);   // "1 week 1 day 1 hour"
```

**Design notes:**
- Uses fixed-unit arithmetic (constant seconds per week/day/hour/etc.) rather than calendar-aware date math (e.g., `date-fns`), since the value represents a pure duration and should not vary with month length or daylight saving time transitions.
- Units with a zero count are omitted entirely from the output.
- Singular/plural labels are handled automatically (`1 hour` vs `2 hours`).
