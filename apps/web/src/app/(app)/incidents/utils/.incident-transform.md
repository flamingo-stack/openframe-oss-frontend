## incident-transform.ts

Provides transformation functions that convert GraphQL Relay fragment data into plain, UI-ready objects for the Incidents feature — covering table rows, detail views, user attribution, and allowed status transitions.

## Key Components

- **`IncidentRow`** — Shape of a row in the Incidents table, including device, organization, and assignee data.
- **`toIncidentRow(ref)`** — Reads an `insightRowFields_insight$key` fragment and maps it into an `IncidentRow`, resolving device presence/name and assignee.
- **`IncidentUser`** — Shape of a user reference (assignee/author) shown on incidents, with deleted-account handling.
- **`toIncidentUser(rawId, ref)`** — Builds an `IncidentUser` from a raw id and an optional user fragment, falling back to a deleted-user label when the reference is missing.
- **`Incident`** — Extends `IncidentRow` with detail-page-only fields: description, detection interval, query evidence, and organization image.
- **`toIncident(ref)`** — Reads an `insightFields_insight$key` fragment and produces a full `Incident`, including normalized `queryResult` rows.
- **`IncidentTransitionTable`** — Lookup of allowed next statuses keyed by current status.
- **`toTransitionTable(ref)`** — Reads an `insightTransitions_query$key` fragment and builds an `IncidentTransitionTable`, filtering out statuses unknown to this build.
- **`transitionsFrom(table, status)`** — Returns the allowed target statuses for a given current status.

## Usage Example

```typescript
import { toIncidentRow, toIncident, toTransitionTable, transitionsFrom } from './incident-transform';

// In a table component
const rows = incidents.map((incidentRef) => toIncidentRow(incidentRef));

// In a detail page
const incident = toIncident(incidentFragmentRef);
console.log(incident.description, incident.queryResult);

// Determining valid status actions
const transitionTable = toTransitionTable(queryFragmentRef);
const nextStatuses = transitionsFrom(transitionTable, incident.status);
```

Each function expects a Relay fragment key (`readInlineData`-compatible) rather than raw GraphQL responses, keeping fragment colocation intact while exposing simple, serializable types to presentation components.
