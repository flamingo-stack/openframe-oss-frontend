## incident-transform.ts

Transforms GraphQL (Relay) fragment data into plain, view-friendly objects for the Incidents feature — covering table rows, detail pages, assignee/user info, and allowed status transitions.

## Key Components

- **`IncidentRow`** — Interface for a row in the Incidents table, including device, organization, and assignee info, with fields kept intact even for unknown enum values (Relay's `"%future added value"`).
- **`toIncidentRow(ref)`** — Converts an `insightRowFields_insight$key` fragment reference into an `IncidentRow`, resolving device presence/name and assignee.
- **`IncidentUser`** — Interface representing a user reference (assignee), including a `deleted` flag for unresolved/deleted accounts.
- **`toIncidentUser(rawId, ref)`** — Builds an `IncidentUser` from a raw id and optional user fragment, falling back to a deleted-employee placeholder when the reference is missing.
- **`Incident`** — Extends `IncidentRow` with detail-page-only fields: `description`, `interval`, `queryResult` (osquery evidence), and `organizationImageUrl`.
- **`toIncident(ref)`** — Converts an `insightFields_insight$key` fragment into a full `Incident`, normalizing query result rows into safe table cell values.
- **`IncidentTransitionTable`** — Type mapping a status string to its allowed next statuses.
- **`toTransitionTable(ref)`** — Builds a transition lookup table from `insightTransitions_query$key`, filtering out unknown `InsightStatus` values via `knownValues`.
- **`transitionsFrom(table, status)`** — Returns the allowed transitions for a given status, or an empty array if none exist.

## Usage Example

```typescript
import { toIncidentRow, toIncident, toTransitionTable, transitionsFrom } from './incident-transform';

// Transform a Relay fragment into a table row
const row = toIncidentRow(insightRowRef);
console.log(row.deviceName, row.status, row.assignee?.name);

// Transform into a full incident detail object
const incident = toIncident(insightFieldsRef);
console.log(incident.description, incident.queryResult);

// Determine valid next statuses for an incident
const table = toTransitionTable(transitionsQueryRef);
const nextStatuses = transitionsFrom(table, incident.status);
```

Used primarily by Incidents list/detail pages and status-change UI to safely bridge Relay-generated GraphQL types with the app's display and business logic layers.
