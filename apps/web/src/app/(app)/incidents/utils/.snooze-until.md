# snooze-until.ts

Utility module for computing "snooze until" timestamps, used to temporarily defer incidents or alerts by a given amount of time (hours, days, or weeks).

## Key Components

- **`SnoozeUnit`** — Type representing the valid time units for snoozing: `'hour'`, `'day'`, or `'week'`.
- **`SNOOZE_UNITS`** — Array of all valid `SnoozeUnit` values, useful for populating UI selectors (e.g., dropdowns).
- **`SNOOZE_MAX_AMOUNT`** — Constant (`999`) defining the maximum acceptable amount a user can input, guarding against typos and overflow in `Date` calculations.
- **`snoozeUnitLabel(unit)`** — Returns the human-readable label (e.g., `"Hour"`, `"Day"`, `"Week"`) for a given `SnoozeUnit`.
- **`snoozeUntil(amount, unit, from?)`** — Computes the resulting `Date` after snoozing `amount` × `unit` from a given starting point (defaults to `new Date()`).

## Usage Example

```typescript
import { snoozeUntil, snoozeUnitLabel, SNOOZE_UNITS, SNOOZE_MAX_AMOUNT } from './snooze-until';

// Populate a unit selector
SNOOZE_UNITS.forEach((unit) => {
  console.log(snoozeUnitLabel(unit)); // "Hour", "Day", "Week"
});

// Snooze an incident for 3 days from now
const resumeAt = snoozeUntil(3, 'day');
console.log(resumeAt.toISOString());

// Snooze relative to a specific timestamp
const customFrom = new Date('2024-01-01T00:00:00Z');
const resumeAtCustom = snoozeUntil(2, 'week', customFrom);

// Validate user input against the max bound
function isValidAmount(amount: number): boolean {
  return amount > 0 && amount <= SNOOZE_MAX_AMOUNT;
}
```

## Notes

- `SNOOZE_MAX_AMOUNT` exists to prevent `amount × ms` from exceeding what JavaScript's `Date` object can safely represent, which would cause `toISOString()` to throw.
- The `from` parameter in `snoozeUntil` defaults to the current time but accepts any `Date`, making the function easy to unit test deterministically.
