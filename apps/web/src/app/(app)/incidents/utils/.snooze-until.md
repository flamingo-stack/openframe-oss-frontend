Utility module for computing "snooze until" timestamps, used to temporarily defer incidents (e.g., alerts) by a selectable amount of time and unit (hour, day, week).

## Key Components

- **`SnoozeUnit`** — Type alias representing the allowed snooze units: `'hour'`, `'day'`, or `'week'`.
- **`SNOOZE_UNITS`** — Array of all valid `SnoozeUnit` values, useful for populating a unit picker UI.
- **`SNOOZE_MAX_AMOUNT`** — Constant (`999`) capping the acceptable snooze amount, guarding against typos or values that would overflow `Date`'s representable range.
- **`snoozeUnitLabel(unit)`** — Returns a human-readable label (e.g., `"Hour"`, `"Day"`, `"Week"`) for a given `SnoozeUnit`.
- **`snoozeUntil(amount, unit, from?)`** — Computes the `Date` that is `amount × unit` after `from` (defaults to now), representing when a snoozed incident should return to the working set.

## Usage Example

```typescript
import { snoozeUntil, snoozeUnitLabel, SNOOZE_UNITS, SNOOZE_MAX_AMOUNT } from './snooze-until';

// Populate a unit selector
SNOOZE_UNITS.forEach((unit) => {
  console.log(snoozeUnitLabel(unit)); // "Hour", "Day", "Week"
});

// Validate user input against the max bound
const amount = 5;
if (amount > SNOOZE_MAX_AMOUNT) {
  throw new Error('Snooze amount too large');
}

// Compute when a snoozed incident resurfaces
const resumeAt = snoozeUntil(amount, 'day');
console.log(resumeAt.toISOString());

// Compute relative to a specific reference time
const customFrom = new Date('2024-01-01T00:00:00Z');
const until = snoozeUntil(2, 'week', customFrom);
```

## Notes

`SNOOZE_MAX_AMOUNT` exists both as a UX safeguard (preventing accidental extreme values) and a technical safeguard (keeping `amount × ms` well within `Date`'s valid range, avoiding exceptions from methods like `toISOString()`).
