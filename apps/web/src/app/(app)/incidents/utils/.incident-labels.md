Defines display labels, status transition metadata, and status groupings for incidents (insights), providing a single source of truth for rendering incident type, severity, and status text across the UI.

## Key Components

- **`INCIDENT_TYPE_LABELS`** — Maps `InsightType` enum values (`SECURITY`, `IT`) to display labels.
- **`INCIDENT_SEVERITY_LABELS`** — Maps `InsightSeverity` values (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`, `INFO`) to display labels.
- **`INCIDENT_STATUS_LABELS`** — Maps `InsightStatus` values (`NEW`, `ACKNOWLEDGED`, `SNOOZED`, `RESOLVED`, `ARCHIVED`) to display labels.
- **`labelOf(labels, value)`** — Safely looks up a label for a given string value, falling back to the raw value itself. Useful for Relay-widened enums that may include unknown future values (`"%future added value"`).
- **`INCIDENT_TRANSITION_ACTIONS`** — Maps each `InsightStatus` to its transition action metadata: the menu `label` (e.g. "Acknowledge") and the past-tense `done` text used in toasts (e.g. "acknowledged").
- **`WORKING_SET_STATUSES`** — Statuses considered "still in play" (excludes `ARCHIVED`).
- **`CURRENT_INCIDENT_STATUSES`** — Statuses shown in the "Current Incidents" tab (`NEW`, `ACKNOWLEDGED`, `RESOLVED`).
- **`SNOOZED_INCIDENT_STATUSES`** / **`ARCHIVED_INCIDENT_STATUSES`** — Single-status groupings for their respective tabs.
- **`ALL_INCIDENT_STATUSES`** — Every defined `InsightStatus`, for unrestricted filters.

## Usage Example

```typescript
import {
  INCIDENT_SEVERITY_LABELS,
  INCIDENT_TRANSITION_ACTIONS,
  labelOf,
  CURRENT_INCIDENT_STATUSES,
} from '@/constants/incident-labels';

// Render a severity label safely, even for unknown future enum values
const severityText = labelOf(INCIDENT_SEVERITY_LABELS, incident.severity);

// Build a status transition menu item
const action = INCIDENT_TRANSITION_ACTIONS[InsightStatus.ACKNOWLEDGED];
console.log(action.label); // "Acknowledge"
console.log(action.done);  // "acknowledged"

// Filter incidents for the "Current Incidents" tab
const currentIncidents = incidents.filter((i) =>
  CURRENT_INCIDENT_STATUSES.includes(i.status)
);
```
