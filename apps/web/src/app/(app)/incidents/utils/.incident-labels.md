Defines label mappings and status groupings for incident (Insight) display, translating GraphQL enum values into human-readable UI text and organizing statuses into tab-based working sets.

## Key Components

- **`INCIDENT_TYPE_LABELS`** — Maps `InsightType` values (`SECURITY`, `IT`) to display labels.
- **`INCIDENT_SEVERITY_LABELS`** — Maps `InsightSeverity` values (`CRITICAL`–`INFO`) to display labels.
- **`INCIDENT_STATUS_LABELS`** — Maps `InsightStatus` values (`NEW`, `ACKNOWLEDGED`, `SNOOZED`, `RESOLVED`, `ARCHIVED`) to display labels.
- **`labelOf(labels, value)`** — Safe lookup helper that falls back to the raw value when a Relay-widened enum (`"%future added value"`) isn't in the label map.
- **`INCIDENT_TRANSITION_ACTIONS`** — Per-status action metadata: the menu `label` (e.g. "Acknowledge") and the past-tense `done` text used in confirmation toasts (e.g. "acknowledged").
- **`WORKING_SET_STATUSES`** — Statuses considered "still active" (excludes `ARCHIVED`), used as the default scope for incident lists.
- **`CURRENT_INCIDENT_STATUSES`** — Statuses shown in the "Current Incidents" tab (`NEW`, `ACKNOWLEDGED`, `RESOLVED`).
- **`SNOOZED_INCIDENT_STATUSES`** / **`ARCHIVED_INCIDENT_STATUSES`** — Single-status arrays for their respective dedicated tabs.
- **`ALL_INCIDENT_STATUSES`** — Every `InsightStatus` value, for unfiltered contexts like the device page.

## Usage Example

```typescript
import {
  INCIDENT_STATUS_LABELS,
  INCIDENT_TRANSITION_ACTIONS,
  CURRENT_INCIDENT_STATUSES,
  labelOf,
} from '@/lib/incident-labels';

// Render a status badge, tolerant of unknown future enum values
const badgeText = labelOf(INCIDENT_STATUS_LABELS, incident.status);

// Build a "transition to" menu
const action = INCIDENT_TRANSITION_ACTIONS.ACKNOWLEDGED;
console.log(action.label); // "Acknowledge"
console.log(`Incident ${action.done}`); // "Incident acknowledged"

// Filter the Current Incidents tab
const currentIncidents = incidents.filter((i) =>
  CURRENT_INCIDENT_STATUSES.includes(i.status)
);
```
