## fix-with-mingo-draft.ts

Builds a Mingo composer draft from an incident's "Fix with Mingo" server prompt, converting leading `@marker:id` context tokens into structured mention chips while preserving the remaining free-text ask.

## Key Components

- **`incidentMingoDraft(prompt, incident)`** — Parses a server-generated `insightChatPrompt` string, stripping leading `@marker:id` tokens (e.g. `@insight:...`, `@device:...`) and converting recognized ones into `MingoDraft['mentions']` entries. Unknown marker kinds are preserved as plain text rather than discarded, and parsing continues past them. Returns a `MingoDraft` with `text` (unknown tokens + remaining prompt) and `mentions`.
- **`labelFor(kind, id, incident)`** — Resolves a human-readable label for a mention chip using data already available on the `IncidentRow` (insight title, device name), falling back to the raw id if it doesn't match the incident's known entities.
- **`LEADING_MARKER`** — Regex matching one leading `@marker:id` token at the start of the remaining prompt text.
- **`KIND_BY_MARKER`** — Reverse lookup map from marker string to `ContextEntityKind`, derived from `CONTEXT_ENTITY_MARKER`.

## Usage Example

```typescript
import { incidentMingoDraft } from './fix-with-mingo-draft';

const draft = incidentMingoDraft(
  '@insight:ins_123 @device:dev_456 Why is this device offline?',
  incident,
);

// draft.mentions:
// [
//   { type: 'insight', id: 'ins_123', label: incident.title },
//   { type: 'device', id: 'dev_456', label: incident.deviceName },
// ]
// draft.text: "Why is this device offline?"
```

This draft is typically passed directly into the Mingo launcher store to pre-populate the composer with attached context mentions when a user triggers "Fix with Mingo" from an incident row.
