## Overview

Parses the "Fix with Mingo" composer draft generated from the server's `insightChatPrompt` for an incident. It extracts leading `@marker:id` context tokens (e.g., `@insight:<id>`, `@device:<machineId>`) from the prompt text and converts them into attached Mingo mentions with human-readable labels, leaving the remaining text as the user's ask.

## Key Components

- **`incidentMingoDraft(prompt, incident)`** — Main export. Parses leading context markers from the prompt string, converts recognized markers into `MingoDraft['mentions']` entries with resolved labels, and returns the remaining text (including any unrecognized markers, preserved inline) joined with the trimmed prompt body.
- **`labelFor(kind, id, incident)`** — Resolves a display label for a mention: uses `incident.title` for a matching insight ID, `incident.deviceName` for a matching device/machine ID, and falls back to the raw `id` otherwise.
- **`KIND_BY_MARKER`** — Reverse lookup map built from `CONTEXT_ENTITY_MARKER`, mapping marker strings (e.g., `"insight"`, `"device"`) back to `ContextEntityKind` values.
- **`LEADING_MARKER`** — Regex matching a single leading `@marker:id` token plus trailing whitespace.

## Usage Example

```typescript
import { incidentMingoDraft } from './fix-with-mingo-draft';

const draft = incidentMingoDraft(
  '@insight:ins_123 @device:machine_456 Investigate high CPU usage',
  {
    insightId: 'ins_123',
    title: 'High CPU Alert',
    machineId: 'machine_456',
    deviceName: 'WIN-SERVER-01',
    // ...other IncidentRow fields
  },
);

// draft.mentions => [
//   { type: 'insight', id: 'ins_123', label: 'High CPU Alert' },
//   { type: 'device', id: 'machine_456', label: 'WIN-SERVER-01' },
// ]
// draft.text => 'Investigate high CPU usage'
```

Unknown markers (not present in `CONTEXT_ENTITY_MARKER`) are left in the resulting `text` rather than discarded, and parsing continues past them to read any subsequent recognized markers.
