# incidents-tabs.tsx

Defines the tab configuration for the Incidents page, mapping each tab (`current`, `snoozed`, `archived`) to its display metadata, associated incident statuses, and empty-state content.

## Key Components

- **`IncidentTabView`** — Interface describing per-tab view data: title, icon, status filters, whether to show the "Archive Resolved" action, and empty-state copy.
- **`INCIDENT_TAB_VIEWS`** — Record mapping each `IncidentsTab` (`current`, `snoozed`, `archived`) to its `IncidentTabView` configuration, including status lists imported from `incident-labels` utils.
- **`INCIDENTS_TABS`** — Array of `TabItem` objects (derived from `TAB_IDS.incidents`) used to render the tab navigation UI.
- **`isIncidentsTab(value)`** — Type guard that narrows a string to `IncidentsTab` if it matches a valid tab ID.
- **`archiveResolvedAction(onClick)`** — Factory function that builds a `PageActionButton` config for the "Archive Resolved" header button, including icon and click handler.

## Usage Example

```typescript
import {
  INCIDENT_TAB_VIEWS,
  INCIDENTS_TABS,
  isIncidentsTab,
  archiveResolvedAction,
} from './incidents-tabs';

// Render tab navigation
<TabBar tabs={INCIDENTS_TABS} activeTab={currentTab} onChange={setTab} />

// Validate route param before rendering a tab's content
if (isIncidentsTab(tabParam)) {
  const view = INCIDENT_TAB_VIEWS[tabParam];
  renderIncidentsList(view.statuses, view.empty);
}

// Conditionally show the "Archive Resolved" action in the page header
const actions = INCIDENT_TAB_VIEWS.current.archiveResolved
  ? [archiveResolvedAction(() => handleArchiveResolved())]
  : [];
```

This module centralizes tab-specific configuration so the Incidents page components can stay declarative, pulling titles, icons, status filters, and empty states from a single source of truth.
