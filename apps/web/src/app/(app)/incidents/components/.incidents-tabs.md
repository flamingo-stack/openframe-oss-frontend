## incidents-tabs.tsx

Defines the tab configuration for the Incidents page, mapping each tab (`current`, `snoozed`, `archived`) to its display metadata, associated incident statuses, and empty-state content.

## Key Components

- **`IncidentTabView`** — Interface describing per-tab view data: title, icon, status filters, whether the "Archive Resolved" action is available, and empty-state copy.
- **`INCIDENT_TAB_VIEWS`** — Record mapping each `IncidentsTab` (`current`, `snoozed`, `archived`) to its `IncidentTabView` configuration, including which `InsightStatus` values belong to each tab.
- **`INCIDENTS_TABS`** — Array of `TabItem` objects (derived from `INCIDENT_TAB_VIEWS`) used to render the tab navigation UI.
- **`isIncidentsTab(value)`** — Type guard that checks whether a string is a valid `IncidentsTab` identifier.
- **`archiveResolvedAction(onClick)`** — Factory function that builds a `PageActionButton` for the "Archive Resolved" header action, rendering a `BoxArchiveIcon`.

## Usage Example

```typescript
import {
  INCIDENTS_TABS,
  INCIDENT_TAB_VIEWS,
  isIncidentsTab,
  archiveResolvedAction,
} from './incidents-tabs';

// Render tab navigation
<Tabs items={INCIDENTS_TABS} activeTab={currentTab} />

// Get view config for the active tab
const view = INCIDENT_TAB_VIEWS[currentTab];
console.log(view.title, view.statuses);

// Validate a route param before using it as a tab
if (isIncidentsTab(routeParam)) {
  setActiveTab(routeParam);
}

// Build the header action button for resolved incidents
const action = view.archiveResolved
  ? archiveResolvedAction(() => handleArchiveResolved())
  : undefined;
```
