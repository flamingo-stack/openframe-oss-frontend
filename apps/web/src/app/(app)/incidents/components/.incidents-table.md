## Incidents Table

Renders the main incidents table with filtering, pagination, row actions (transitions, snoozing, archiving), and AI-assisted ("Mingo") remediation shortcuts. Built on Relay pagination fragments and a shared `LiveTable`/`useDataTable` abstraction, it supports device-scoped views, status locking, and facet-driven column filters derived from the server response.

## Key Components

- **`incidentColumns()`** — Builds the `ColumnDef[]` for the incidents table (incident title/type, device, severity, status, assignee, actions, Mingo, open-link), wiring facet-based filters and conditional device-column visibility.
- **`IncidentTableRow`** — Row shape extending `IncidentRow` with `mingoAction` and `unreadNotificationCount`, kept in row data (not column closures) so memoized cells stay stable across column/filter changes.
- **`enumFacetOptions()`** — Maps raw facet entries to labeled dropdown options using this app's label maps (e.g., `INCIDENT_STATUS_LABELS`).
- **`statusTime()`** — Computes the secondary status line text: relative age for `NEW`, snooze resume time for `SNOOZED`, otherwise detection timestamp.
- **`IncidentUnreadIndicator`** — Shows unread-notification badge/link for an incident row, hidden when count is 0.
- **`IncidentColumnOptions` / `IncidentColumnsInput`** — Typed inputs describing available facet options, device-scoping, status-lock state, and row-action renderer passed into `incidentColumns`.

## Usage Example

```typescript
import { incidentsTableRelayFragment, incidentsTableRelayQuery } from '@/graphql/insights/incidents-table-relay';
import { usePaginationFragment, useLazyLoadQuery } from 'react-relay';

function IncidentsTable({ deviceScoped = false }: { deviceScoped?: boolean }) {
  const queryData = useLazyLoadQuery<IncidentsTableQueryType>(incidentsTableRelayQuery, {});
  const { data, loadNext } = usePaginationFragment<IncidentsPaginationQueryType, IncidentsFragmentKey>(
    incidentsTableRelayFragment,
    queryData.insights
  );

  const columns = incidentColumns({
    options: null, // facets loaded via a deferred query
    deviceScoped,
    statusLocked: false,
    renderRowActions: row => <ActionsMenuDropdown items={transitionMenuItems(row)} />,
  });

  return <LiveTable columns={columns} data={data.edges.map(e => e.node)} />;
}
```

This component is typically rendered inside the incidents page layout alongside filter modals, toasts for mutation errors, and Mingo-assisted remediation dialogs.
