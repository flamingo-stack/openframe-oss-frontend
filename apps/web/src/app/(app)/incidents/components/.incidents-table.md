## incidents-table.tsx

Client-rendered incidents data table that lists, filters, paginates, and acts on infrastructure insights/incidents. It combines a Relay GraphQL pagination fragment with a shared `LiveTable`/`useDataTable` setup, rendering per-row status, severity, assignee, Mingo AI remediation actions, and unread notification badges.

## Key Components

- **`incidentColumns`** – Builds the `ColumnDef<IncidentTableRow>[]` array for the table (incident title/type, device/customer, severity, status, assignee, row actions, Mingo action, open link), wiring each filterable column to server-provided facets via `facetFilter`/`liveColumnMeta`.
- **`IncidentTableRow`** – Row shape extending `IncidentRow` with a precomputed `mingoAction` and `unreadNotificationCount`, kept in the row data (not column closures) so memoized cells stay stable across column updates.
- **`IncidentColumnOptions` / `IncidentColumnsInput`** – Typed inputs describing available facet options (type, customer, severity, status, assignee) and table-scoping flags (`deviceScoped`, `statusLocked`).
- **`enumFacetOptions`** – Maps raw facet entries to labeled dropdown options using this app's label maps.
- **`statusTime`** – Computes the secondary status line (relative time for `NEW`, snooze date for `SNOOZED`, otherwise detection timestamp).
- **`IncidentUnreadIndicator`** – Renders the per-row unread notification badge linking to the notifications view.
- Integrates with `archiveResolvedInsightsMutation`, `useFixWithMingo`, `useIncidentTransitions`, `useLatestIncidentDialogs`, and `SnoozeIncidentModal` for row-level actions (resolve, snooze, transition status, archive).

## Usage Example

```typescript
import IncidentsTable from '@/app/components/incidents-table';

function IncidentsPage() {
  return (
    <PageLayout>
      <IncidentsTable tab="open" deviceScoped={false} />
    </PageLayout>
  );
}
```

Internally, the table consumes a Relay pagination fragment (`incidentsTableRelayFragment`) seeded by `incidentsTableRelayQuery`, transforms results via `toIncidentRow`, and builds columns with `incidentColumns({ options, deviceScoped, statusLocked, renderRowActions })` before handing them to `useDataTable`/`LiveTable` for rendering, sorting, and filtering.
