# incident-assignee.tsx

Client component rendering the assignee cell for incidents (used in both the summary card and the Incidents table). It pairs a compact assignee picker with the current holder's name, and supports assigning/unassigning independently of incident status.

## Key Components

- **`IncidentAssignee`** — Main component accepting an optional `incident: IncidentRow`. Renders an `AssigneeDropdown` (compact variant) alongside an `InfoCell` showing the assignee's name, or "Unassigned" if none.
- **`UNREAD_ASSIGNEE`** — Placeholder assignee object (`{ id: '', name: '' }`) used to render the picker's trigger as an inert skeleton state while loading.
- **`handleAssign`** — Internal handler that commits either `assignInsightMutation` (when a `userId` is provided) or `unassignInsightMutation` (when `userId` is `null`), showing success/error toasts via `useToast`.

## Behavior Notes

- Loading state is derived from `useLoadingScope()` or the absence of an `incident` prop; in this state the dropdown trigger is inert (`onTriggerClick` is a no-op) and both the avatar and name render as skeletons.
- Assignee options are fetched via the shared `useAssigneeOptions` hook (same source used by the ticket board), supporting search-driven filtering.
- Deleted assignees are shown with `text-ods-error` styling on their name.
- The picker is wrapped with `data-no-row-click` so clicking it doesn't trigger the parent table row's click handler.
- GraphQL errors are surfaced via `getRelayErrorMessage` and displayed as a destructive toast.

## Usage Example

```typescript
import { IncidentAssignee } from '@/app/components/incidents/incident-assignee';
import type { IncidentRow } from '@/app/components/incidents/utils/incident-transform';

function IncidentTableRow({ incident }: { incident: IncidentRow }) {
  return (
    <div className="flex items-center">
      <IncidentAssignee incident={incident} />
    </div>
  );
}

// Loading/skeleton state (no incident yet)
function IncidentTableRowSkeleton() {
  return <IncidentAssignee />;
}
```
