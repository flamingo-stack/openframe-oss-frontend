# incident-assignee.tsx

Renders the "Assigned" cell used in both the incident summary card and the Incidents table. It combines a compact assignee picker (shared with the ticket board) with the current assignee's name, and lets a technician assign or unassign an incident independently of its status (e.g., while snoozed).

## Key Components

- **`IncidentAssignee`** — Main component. Accepts an optional `incident: IncidentRow` prop and renders:
  - An `AssigneeDropdown` (compact variant) showing the current assignee's avatar, or a skeleton while loading.
  - An `InfoCell` showing the assignee's name (styled red if deleted) or "Unassigned".
- **`UNREAD_ASSIGNEE`** — Placeholder `{ id: '', name: '' }` used as the dropdown's current assignee while data hasn't loaded yet, so the trigger renders inert with a skeleton avatar.
- **`handleAssign`** — Internal handler that commits either `assignInsightMutation` (when a `userId` is picked) or `unassignInsightMutation` (when `userId` is `null`), and shows success/error toasts accordingly.

## Usage Example

```typescript
import { IncidentAssignee } from '@/app/incidents/components/incident-assignee';
import type { IncidentRow } from '@/app/incidents/utils/incident-transform';

function IncidentTableRow({ incident }: { incident: IncidentRow }) {
  return (
    <div className="flex items-center">
      <IncidentAssignee incident={incident} />
    </div>
  );
}

// While data is loading, render without the `incident` prop to show skeleton state:
function IncidentRowSkeleton() {
  return <IncidentAssignee />;
}
```

The component relies on `useLoadingScope()` to detect ambient loading state and `useAssigneeOptions()` to fetch selectable technicians, so it must be rendered within a Relay environment and the appropriate loading-scope provider.
