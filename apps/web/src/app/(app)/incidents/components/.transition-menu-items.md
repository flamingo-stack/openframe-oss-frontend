## transition-menu-items.tsx

Builds the list of status-transition menu items for an incident, deriving the available actions from the server-defined transition table so the UI never exposes an invalid status change.

## Key Components

- **`TRANSITION_ICON`** — Maps each `InsightStatus` value (`NEW`, `ACKNOWLEDGED`, `SNOOZED`, `RESOLVED`, `ARCHIVED`) to its corresponding icon component.
- **`transitionMenuItems(incident, transitions, transition, disabled)`** — Factory function that returns an array of `ActionsMenuItem` objects, one per valid transition target for the given incident's current status. Uses `transitionsFrom` (from `incident-transform`) to compute allowed next statuses and `INCIDENT_TRANSITION_ACTIONS` (from `incident-labels`) for display labels. Each item's `onClick` invokes the provided `transition` callback with the incident and target status.

## Usage Example

```typescript
import { transitionMenuItems } from './transition-menu-items';
import { useIncidentTransitions } from '../hooks/use-incident-transitions';

function IncidentRowMenu({ incident }: { incident: TransitionTarget & { status: string } }) {
  const { transitions, transition, isPending } = useIncidentTransitions();

  const items = transitionMenuItems(incident, transitions, transition, isPending);

  return <ActionsMenu items={items} />;
}
```

This is typically consumed by both the incident list's row-level actions menu and the incident detail header, ensuring consistent transition options are derived from a single source of truth — the `transitions` table — rather than being hardcoded per view.
