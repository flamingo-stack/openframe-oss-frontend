## transition-menu-items.tsx

Builds a dynamic, server-driven list of status-transition menu items for an incident, ensuring only valid transitions (as defined by the backend's transition table) are presented to the user.

## Key Components

- **`TRANSITION_ICON`** — A record mapping each `InsightStatus` value (`NEW`, `ACKNOWLEDGED`, `SNOOZED`, `RESOLVED`, `ARCHIVED`) to its corresponding icon component.
- **`transitionMenuItems(incident, transitions, transition, disabled)`** — Main exported function that computes the list of `ActionsMenuItem` entries available for a given incident. It uses `transitionsFrom` to determine which statuses are reachable from the incident's current status, then builds a menu item per valid transition with the appropriate icon, label, and click handler.

## Usage Example

```typescript
import { transitionMenuItems } from './transition-menu-items';

const menuItems = transitionMenuItems(
  { id: incident.id, status: incident.status },
  incidentTransitionTable,
  (target, status) => updateIncidentStatus(target, status),
  isUpdating,
);

// Render items in an actions menu
<ActionsMenu items={menuItems} />;
```

This function is shared between the incident list's row-level action menu and the incident detail header, guaranteeing consistent transition behavior across the UI. Because the menu items are derived from `transitionsFrom(transitions, incident.status)`, invalid transitions (those that would be rejected server-side) are never shown, preventing avoidable errors.
