# incident-tags.tsx

Defines presentational `Tag` wrapper components that map incident **severity** and **status** enum values to the appropriate visual variant, based on the Figma design spec. Handles loading states and unknown/future enum values gracefully.

## Key Components

- **`SEVERITY_VARIANT`** — Maps `InsightSeverity` values (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`, `INFO`) to `TagVariant` styles (`critical`, `error`, `warning`, `grey`).
- **`STATUS_VARIANT`** — Maps `InsightStatus` values (`NEW`, `ACKNOWLEDGED`, `SNOOZED`, `RESOLVED`, `ARCHIVED`) to `TagVariant` styles (`primary`, `outline`, `grey`, `success`).
- **`variantOf(map, value)`** — Internal helper that safely resolves a variant from a lookup map, defaulting to `'grey'` for unrecognized values (e.g., Relay's `"%future added value"` placeholder for forward-compatible enums).
- **`IncidentSeverityTag({ severity })`** — Renders a `Tag` for an incident's severity level; shows a skeleton loading `Tag` when `severity` is undefined.
- **`IncidentStatusTag({ status })`** — Renders a `Tag` for an incident's status; shows a skeleton loading `Tag` when `status` is undefined.

## Usage Example

```typescript
import { IncidentSeverityTag, IncidentStatusTag } from '@/components/incident-tags';

function IncidentRow({ incident }: { incident?: { severity?: string; status?: string } }) {
  return (
    <div className="flex gap-2">
      <IncidentSeverityTag severity={incident?.severity} />
      <IncidentStatusTag status={incident?.status} />
    </div>
  );
}
```

Both components accept an optional `string` value (typically a GraphQL enum from Relay) rather than a strict enum type, so they remain resilient to loading states and to new enum members added by the backend before the frontend schema is regenerated.
