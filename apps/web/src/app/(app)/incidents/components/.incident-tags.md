## incident-tags.tsx

Provides two presentational React components that render color-coded `Tag` badges for incident **severity** and **status** values, mapping each enum member to a specific visual variant matching the Figma design spec.

## Key Components

- **`SEVERITY_VARIANT`** — Maps `InsightSeverity` values (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`, `INFO`) to tag variants (`critical`, `error`, `warning`, `grey`).
- **`STATUS_VARIANT`** — Maps `InsightStatus` values (`NEW`, `ACKNOWLEDGED`, `SNOOZED`, `RESOLVED`, `ARCHIVED`) to tag variants (`primary`, `outline`, `grey`, `success`).
- **`variantOf(map, value)`** — Looks up a variant for a given raw string value, falling back to `'grey'` for unrecognized/future enum members (handles Relay's `"%future added value"` case).
- **`IncidentSeverityTag({ severity })`** — Renders a `Tag` for an incident's severity; shows a loading skeleton when `severity` is undefined.
- **`IncidentStatusTag({ status })`** — Renders a `Tag` for an incident's status; shows a loading skeleton when `status` is undefined.

## Usage Example

```typescript
import { IncidentSeverityTag, IncidentStatusTag } from '@/components/incident-tags';

function IncidentRow({ incident }: { incident?: { severity?: string; status?: string } }) {
  return (
    <div>
      <IncidentSeverityTag severity={incident?.severity} />
      <IncidentStatusTag status={incident?.status} />
    </div>
  );
}

// While data is loading, omit the value to show a skeleton placeholder:
<IncidentSeverityTag />
```

Both components are designed to be used directly against GraphQL/Relay fields, gracefully handling `undefined` values during loading states and unknown enum members introduced by schema evolution.
