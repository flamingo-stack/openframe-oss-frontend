A React modal component that lets a user "snooze" an incident by specifying an amount and time unit (e.g., minutes, hours, days), then confirms a computed resume timestamp.

## Key Components

- **`SnoozeIncidentModal`** — Default export component rendering a `SimpleModal` with:
  - A numeric `Input` for the snooze amount (validated as an integer between 1 and `SNOOZE_MAX_AMOUNT`).
  - A `Select` dropdown for choosing the `SnoozeUnit` (e.g., hour, day), populated from `SNOOZE_UNITS` and labeled via `snoozeUnitLabel`.
  - A footer `Button` ("Confirm") that is disabled when input is invalid and shows a loading state via `isPending`.
- **`SnoozeIncidentModalProps`** — Props interface:
  - `open: boolean` — controls modal visibility.
  - `onOpenChange: (open: boolean) => void` — callback to close/toggle the modal.
  - `onConfirm: (until: Date) => void` — invoked with the computed resume `Date`, calculated via `snoozeUntil(amount, unit)`.
  - `isPending?: boolean` — optional loading flag for the confirm button.

## Usage Example

```typescript
import { useState } from 'react';
import { SnoozeIncidentModal } from './snooze-incident-modal';

function IncidentActions() {
  const [isSnoozeOpen, setSnoozeOpen] = useState(false);

  const handleConfirm = (until: Date) => {
    console.log('Snoozing incident until', until);
    setSnoozeOpen(false);
  };

  return (
    <SnoozeIncidentModal
      open={isSnoozeOpen}
      onOpenChange={setSnoozeOpen}
      onConfirm={handleConfirm}
      isPending={false}
    />
  );
}
```

Note the component uses `Number()` rather than `parseInt()` for amount validation, ensuring inputs like `"1.5"` are rejected as invalid instead of silently truncated.
