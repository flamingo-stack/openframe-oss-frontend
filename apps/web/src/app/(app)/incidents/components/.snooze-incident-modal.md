# snooze-incident-modal.tsx

A React modal component that lets users snooze an incident's notifications for a configurable duration (amount + time unit, e.g. "1 Hour"). It validates the input amount and delegates the resulting resume timestamp to a caller-supplied callback.

## Key Components

- **`SnoozeIncidentModalProps`** — Interface defining the component's props:
  - `open` / `onOpenChange` — controls modal visibility (controlled pattern).
  - `onConfirm(until: Date)` — invoked with the computed "resume at" timestamp when the user confirms.
  - `isPending` — optional flag to show a loading state on the confirm button.
- **`SnoozeIncidentModal`** — The main exported component. Renders a `SimpleModal` containing a numeric amount input and a unit `Select` (sourced from `SNOOZE_UNITS`), with validation ensuring the amount is an integer between 1 and `SNOOZE_MAX_AMOUNT`.

Relies on helpers from `../utils/snooze-until`: `SNOOZE_UNITS`, `SnoozeUnit`, `snoozeUnitLabel`, `SNOOZE_MAX_AMOUNT`, and `snoozeUntil` (which computes the target `Date` from amount + unit).

## Usage Example

```typescript
import { useState } from 'react';
import { SnoozeIncidentModal } from './snooze-incident-modal';

function IncidentRow({ incidentId }: { incidentId: string }) {
  const [snoozeOpen, setSnoozeOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleConfirm = async (until: Date) => {
    setIsPending(true);
    await snoozeIncident(incidentId, until);
    setIsPending(false);
    setSnoozeOpen(false);
  };

  return (
    <>
      <button onClick={() => setSnoozeOpen(true)}>Snooze</button>
      <SnoozeIncidentModal
        open={snoozeOpen}
        onOpenChange={setSnoozeOpen}
        onConfirm={handleConfirm}
        isPending={isPending}
      />
    </>
  );
}
```

Note: the component is keyed per-incident by the caller (e.g. via a `key` prop on `SnoozeIncidentModal`) so the amount/unit selection resets when targeting a different incident.
