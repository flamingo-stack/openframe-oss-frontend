## session-recordings-service.ts

Defines the contract and error types for the session-recordings backend surface, abstracting how session recording metadata, live sessions, and recording files are fetched, deleted, kept, and measured for storage usage. The actual implementation lives in the openframe-saas-api client (`session-recordings-api-service.ts`).

## Key Components

- **`RecordingUnavailableError`** - Thrown by `downloadSegment` when a recording's file bytes can't be fetched (no download URL yet, or storage failure). Triggers the "Session recording unavailable" UI state.
- **`RecordingNotFoundError`** - Thrown by `get` when a recording doesn't exist (unknown id, deleted session, or expired/deleted file). Triggers a 404 on the recording page.
- **`SessionNotFoundError`** - Thrown by `live` when a live session doesn't exist or isn't visible to the caller. Triggers a 404 on the live session page.
- **`ISessionRecordingsService`** - Interface defining the full session-recordings API surface:
  - `canDelete` - read-only flag indicating whether deletion is permitted at all.
  - `list(deviceId)` - lists a device's recorded sessions, newest first.
  - `get(recordingId)` - fetches recording details, throws `RecordingNotFoundError`.
  - `live(sessionId)` - fetches a live session's details, throws `SessionNotFoundError`.
  - `downloadSegment(segment)` - downloads raw `.mcrec` bytes, throws `RecordingUnavailableError`.
  - `delete(sessionId)` - permanently deletes an ended session and its files.
  - `keep(sessionId, selection)` - protects selected files from automatic expiry.
  - `release(sessionId)` - releases a Keep, allowing files to expire again.
  - `storage()` - returns tenant recording storage usage.

## Usage Example

```typescript
import type { ISessionRecordingsService } from './session-recordings-service';
import { RecordingNotFoundError, RecordingUnavailableError } from './session-recordings-service';

async function loadRecording(service: ISessionRecordingsService, recordingId: string) {
  try {
    const recording = await service.get(recordingId);
    return recording;
  } catch (error) {
    if (error instanceof RecordingNotFoundError) {
      // render 404 state
      return null;
    }
    throw error;
  }
}

async function downloadFile(service: ISessionRecordingsService, segment: RecordingSegment) {
  try {
    return await service.downloadSegment(segment);
  } catch (error) {
    if (error instanceof RecordingUnavailableError) {
      // render "Session recording unavailable" state
      return null;
    }
    throw error;
  }
}
```
