# session-recordings-service.ts

Defines the contract and error types for the session-recordings backend surface, used to list, retrieve, download, delete, and manage retention ("keep") of remote session recordings. The actual HTTP implementation lives in `session-recordings-api-service.ts`, which conforms to the `ISessionRecordingsService` interface declared here.

## Key Components

- **`RecordingUnavailableError`** — Thrown by `downloadSegment` when segment bytes can't be fetched (missing URL or storage failure). Triggers the "Session recording unavailable" UI state.
- **`RecordingNotFoundError`** — Thrown by `get` when a recording doesn't exist (unknown id, deleted session, expired/deleted file). Triggers the recording page's 404.
- **`SessionNotFoundError`** — Thrown by `live` when a live session doesn't exist or isn't visible to the caller. Triggers the live session page's 404.
- **`ISessionRecordingsService`** — Interface describing the backend surface:
  - `canDelete` — whether deletion is permitted at all.
  - `list(deviceId)` — returns a device's sessions, newest first.
  - `get(recordingId)` — fetches recording detail; throws `RecordingNotFoundError`.
  - `live(sessionId)` — fetches live session detail; throws `SessionNotFoundError`.
  - `downloadSegment(segment)` — fetches raw `.mcrec` bytes; throws `RecordingUnavailableError`.
  - `delete(sessionId)` — deletes an ended session and its files (irreversible); throws server refusal errors.
  - `keep(sessionId, selection)` — prevents automatic deletion of files; throws on quota/refusal.
  - `release(sessionId)` — re-enables expiration after a grace period; throws server refusal.
  - `storage()` — returns tenant recording storage usage/limits.

## Usage Example

```typescript
import type { ISessionRecordingsService } from './session-recordings-service';
import { RecordingNotFoundError, RecordingUnavailableError } from './session-recordings-service';

async function loadRecording(service: ISessionRecordingsService, recordingId: string) {
  try {
    const recording = await service.get(recordingId);
    return recording;
  } catch (err) {
    if (err instanceof RecordingNotFoundError) {
      // render 404 state
      return null;
    }
    throw err;
  }
}

async function fetchSegmentBytes(service: ISessionRecordingsService, segment: RecordingSegment) {
  try {
    return await service.downloadSegment(segment);
  } catch (err) {
    if (err instanceof RecordingUnavailableError) {
      // render "Session recording unavailable" state
      return null;
    }
    throw err;
  }
}
```
