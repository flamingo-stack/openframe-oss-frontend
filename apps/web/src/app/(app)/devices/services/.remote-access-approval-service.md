# remote-access-approval-service.ts

Defines the service contract for managing remote-access approval requests, along with a helper for identifying terminal request states. This file establishes the abstraction that concrete API implementations (e.g., `RemoteAccessApprovalApiService`) must fulfill, decoupling request/response handling from the real-time decision delivery mechanism (NATS push notifications).

## Key Components

- **`IRemoteAccessApprovalService`** — Interface describing the backend surface for remote-access approval requests:
  - `create(input)` — Creates an approval request; the server enforces at most one open request per device, returning the existing request if one is already pending.
  - `get(requestId)` — Fetches a request by ID; used as a polling fallback when a push notification is missed.
  - `revoke(requestId)` — Cancels an open request, transitioning it to `REVOKED` and closing the client prompt.
- **`SETTLED`** — A `ReadonlySet` of `RemoteAccessRequestStatus` values considered terminal: `APPROVED`, `DENIED`, `TIMED_OUT`, `REVOKED`, `CANCELLED`, `EXPIRED`.
- **`isSettledRequestStatus(status)`** — Type guard-style helper returning `true` if the given status is terminal (no further transitions expected).

## Usage Example

```typescript
import type { IRemoteAccessApprovalService } from './remote-access-approval-service';
import { isSettledRequestStatus } from './remote-access-approval-service';

async function requestAccess(
  service: IRemoteAccessApprovalService,
  deviceId: string
) {
  const request = await service.create({ deviceId });

  // Poll as a fallback if no NATS push arrives
  let current = request;
  while (!isSettledRequestStatus(current.status)) {
    await new Promise((resolve) => setTimeout(resolve, 2000));
    current = await service.get(request.id);
  }

  console.log(`Request settled with status: ${current.status}`);
}
```

Note that the actual approval/denial decision is **not** fetched via this interface alone—it is primarily delivered through a NATS notification subject consumed by `useRemoteAccessApproval`, with `get` serving only as a fallback for missed pushes.
