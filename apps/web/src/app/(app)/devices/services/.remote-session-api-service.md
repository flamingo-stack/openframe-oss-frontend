# remote-session-api-service.ts

GraphQL service handling the technician side of the remote desktop session lifecycle against `openframe-saas-api`. It queries active/specific sessions, ends sessions, and parses/folds real-time lifecycle events (`REMOTE_SESSION_STARTED`/`ENDED`) pushed over the technician's notification subject.

## Key Components

- **`sessionFragment`** — Inline GraphQL fragment (`@inline`) defining the full `RemoteSession` shape read by every query/mutation in this service.
- **`fromWireRemoteSession(data)`** — Converts the raw GraphQL wire payload into the app's `RemoteSession` read model; throws if required fields (`sessionId`, `status`) are missing or malformed.
- **`parseRemoteSessionEvent(payload)`** — Parses an unknown notification payload into a typed `RemoteSessionEvent`, returning `null` if it's not a recognized session lifecycle event.
- **`applyRemoteSessionEvent(session, event)`** — Folds a lifecycle event into an existing (or `null`) session, building a minimal record on `STARTED` or marking `ENDED` with reason/timestamp.
- **`RemoteSessionApiService`** — Class exposing:
  - `active(deviceId)` — fetches the caller's own active session on a device (network-only), or `null`.
  - `get(sessionId)` — fetches a specific session by ID, throwing if not found.
  - `end(sessionId)` — ends the technician's own session; treats "already ended" as success.
  - `endOnUnload(sessionId)` — fire-and-forget keepalive end call sent as the page unloads.
- **`remoteSessionApiService`** — Singleton instance of `RemoteSessionApiService`.

## Usage Example

```typescript
import { remoteSessionApiService, parseRemoteSessionEvent, applyRemoteSessionEvent } from './remote-session-api-service';

// Check for an active session on a device
const session = await remoteSessionApiService.active(deviceId);

// Fetch a known session
const details = await remoteSessionApiService.get(sessionId);

// End the session (treats already-ended as success)
await remoteSessionApiService.end(sessionId);

// End on tab close
window.addEventListener('beforeunload', () => {
  remoteSessionApiService.endOnUnload(sessionId);
});

// Handle a lifecycle event from a notification subscription
const event = parseRemoteSessionEvent(incomingPayload);
if (event) {
  const updated = applyRemoteSessionEvent(currentSession, event);
}
```

Used primarily by `useRemoteSession` for session polling, lifecycle subscriptions, and cleanup during technician-initiated remote access flows.
