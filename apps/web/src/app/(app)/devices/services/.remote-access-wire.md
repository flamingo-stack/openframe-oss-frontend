## remote-access-wire.ts

Defines type-safe parsing utilities for untyped wire-format data coming from the remote-access backend: GraphQL `Instant` scalars and flat NATS event payloads. These helpers normalize loosely-typed, cross-service data (Relay GraphQL responses and NATS notification messages) into consistent TypeScript values, guarding against schema drift between backend hosts (e.g., differing Jackson serialization settings for timestamps).

## Key Components

- **`RawWire`** — Type alias for an untyped `Record<string, unknown>`, representing a raw wire payload before validation.
- **`text(raw, key)`** — Extracts a non-empty string field from a raw payload; returns `undefined` if missing, empty, or not a string.
- **`timestamp(value)`** — Normalizes an `Instant` scalar into an ISO-8601 string. Accepts ISO strings directly, or numeric epoch values (seconds or milliseconds, auto-detected via a `1e12` threshold), converting them to ISO format.
- **`nullableTimestamp(value)`** — Like `timestamp`, but passes through explicit `null` values (distinguishing "no value" from "missing field").
- **`oneOf(value, allowed)`** — Validates that a string value belongs to an allowed set, narrowing it to a literal union type `T`; returns `undefined` otherwise.

## Usage Example

```typescript
import { text, timestamp, nullableTimestamp, oneOf, RawWire } from './remote-access-wire';

type SessionStatus = 'PENDING' | 'ACTIVE' | 'CLOSED';
const ALLOWED_STATUSES = new Set(['PENDING', 'ACTIVE', 'CLOSED']);

function parseSessionEvent(raw: RawWire) {
  return {
    deviceId: text(raw, 'deviceId'),
    requestedAt: timestamp(raw.requestedAt),
    closedAt: nullableTimestamp(raw.closedAt),
    status: oneOf<SessionStatus>(raw.status, ALLOWED_STATUSES),
  };
}

// Handles both ISO strings and epoch numbers transparently
parseSessionEvent({
  deviceId: 'abc-123',
  requestedAt: 1716400000, // seconds epoch
  closedAt: null,
  status: 'ACTIVE',
});
```

Used by the approval and session services to safely decode GraphQL `Instant` fields and NATS notification events without trusting upstream type consistency.
