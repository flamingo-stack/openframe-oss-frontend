# remote-access-wire.ts

Provides small, defensive parsing utilities for reading untyped "wire" data—GraphQL payloads using the untyped `Instant` scalar and flat NATS event payloads from the technician's notification subject. These helpers normalize loosely-typed, cross-service data into safe TypeScript values, shared by the approval and session services.

## Key Components

- **`RawWire`** — Type alias for `Record<string, unknown>`, representing an untyped wire payload (GraphQL response or NATS message).
- **`text(raw, key)`** — Extracts a non-empty string field from a `RawWire` object; returns `undefined` if missing, empty, or not a string.
- **`timestamp(value)`** — Normalizes an `Instant` scalar value into an ISO-8601 string. Accepts strings as-is (Spring's default serialization) or numeric epoch values (seconds or milliseconds, auto-detected by magnitude) and converts them to ISO-8601. Returns `undefined` if the value can't be parsed.
- **`nullableTimestamp(value)`** — Like `timestamp`, but passes through explicit `null` values instead of treating them as unparseable.
- **`oneOf<T>(value, allowed)`** — Validates that a string value belongs to an allowed set, narrowing it to a literal union type `T`; returns `undefined` otherwise.

## Usage Example

```typescript
import { text, timestamp, nullableTimestamp, oneOf, RawWire } from './remote-access-wire';

function parseSessionEvent(raw: RawWire) {
  const sessionId = text(raw, 'sessionId');
  const startedAt = timestamp(raw.startedAt);
  const endedAt = nullableTimestamp(raw.endedAt);

  const status = oneOf<'PENDING' | 'ACTIVE' | 'CLOSED'>(
    raw.status,
    new Set(['PENDING', 'ACTIVE', 'CLOSED'])
  );

  return { sessionId, startedAt, endedAt, status };
}

// Handles both string and numeric epoch timestamps transparently
timestamp('2024-01-15T10:30:00Z'); // '2024-01-15T10:30:00Z'
timestamp(1705315800);             // epoch seconds -> ISO string
timestamp(1705315800000);          // epoch millis -> ISO string
```
