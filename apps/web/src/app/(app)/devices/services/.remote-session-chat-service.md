Defines the TypeScript contract for retrieving and sending remote session chat messages, decoupling callers from the concrete implementation provided by `remote-session-chat-api-service.ts`.

## Key Components

- **`RemoteSessionChatHistory`** — Interface describing a page of chat history: an oldest-first `messages` array and `lastSeq`, the highest JetStream sequence number seen on that page (used to resume the live feed right after it; `0` means no sequence has been stamped yet).
- **`IRemoteSessionChatService`** — Service interface exposing:
  - `history(dialogId: string): Promise<RemoteSessionChatHistory>` — fetches existing messages for a given remote session dialog.
  - `send(dialogId: string, body: string): Promise<void>` — sends a technician message, which is then delivered back asynchronously through the dialog's live feed rather than returned directly.

## Usage Example

```typescript
import type { IRemoteSessionChatService } from './remote-session-chat-service';

async function loadAndReply(chatService: IRemoteSessionChatService, dialogId: string) {
  const { messages, lastSeq } = await chatService.history(dialogId);

  console.log(`Loaded ${messages.length} messages, resuming after seq ${lastSeq}`);

  await chatService.send(dialogId, 'Reboot completed, please verify connectivity.');
  // The sent message will arrive via the live feed, not as a return value here.
}
```

This interface is typically implemented by `remote-session-chat-api-service.ts`, which wires it to the actual HTTP/JetStream-backed dialog API.
