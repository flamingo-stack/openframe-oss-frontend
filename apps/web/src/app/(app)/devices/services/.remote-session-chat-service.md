# remote-session-chat-service.ts

Defines the service contract for managing chat messages within a remote session dialog, establishing the interface implemented by `remote-session-chat-api-service.ts`.

## Key Components

- **`RemoteSessionChatHistory`** — Interface representing a page of chat history, containing:
  - `messages`: Array of `RemoteSessionChatMessage` objects, ordered oldest first.
  - `lastSeq`: The highest JetStream sequence number on the page, used to resume a live feed immediately after it (`0` indicates no stamped sequence yet).

- **`IRemoteSessionChatService`** — Interface defining the chat service contract:
  - `history(dialogId: string)`: Retrieves the existing messages for a given dialog.
  - `send(dialogId: string, body: string)`: Sends a technician's message to the dialog; the message is expected to be delivered back through the dialog's live feed rather than returned directly.

## Usage Example

```typescript
import type { IRemoteSessionChatService, RemoteSessionChatHistory } from './remote-session-chat-service';

async function loadAndSendMessage(
  chatService: IRemoteSessionChatService,
  dialogId: string
) {
  // Fetch existing chat history
  const history: RemoteSessionChatHistory = await chatService.history(dialogId);
  console.log(`Loaded ${history.messages.length} messages, lastSeq=${history.lastSeq}`);

  // Send a new message; it will arrive via the dialog's live feed
  await chatService.send(dialogId, 'Session reconnected, please confirm status.');
}
```

This interface is typically consumed by UI components (e.g., a remote session chat panel) and backed by a concrete implementation such as `remote-session-chat-api-service.ts`, which handles the actual API/transport logic.
