# remote-session-events-api-service.ts

Relay-based API service for fetching the timeline events of a remote session recording and reporting playback activity. It powers the Session Events list and timeline markers on the recording playback page.

## Key Components

- **`eventsQuery`** - GraphQL query fetching a paginated connection of `RemoteSession.events` for a given recording, filtered by event type.
- **`playedMutation`** - GraphQL mutation (`recordRecordingPlayed`) that reports a recording playback event to the server.
- **`LISTED_TYPES`** - The fixed set of `RemoteSessionEventType` values shown in the UI (e.g. `STARTED`, `ENDED`, `MONITOR_SWITCHED`, `RECORDING_KEPT`), excluding request/chat/playback-only events.
- **`PAGE_SIZE`** - Constant (`500`) matching the server's pagination ceiling.
- **`SessionEventsPage`** - Interface describing a page result: `events` (list of `SessionTimelineEvent`) and `nextCursor` (string or `null`).
- **`fetchSessionEventsPage(recordingId, after)`** - Fetches one page of timeline events (oldest first) for a recording, using a network-only fetch policy, and maps raw nodes via `toSessionTimelineEvent`.
- **`recordRecordingPlayed(sessionId)`** - Commits the "played" mutation and returns whether the server accepted the report.

## Usage Example

```typescript
import { fetchSessionEventsPage, recordRecordingPlayed } from './remote-session-events-api-service';

// Fetch the first page of events for a recording
const page = await fetchSessionEventsPage('recording-123', null);
console.log(page.events, page.nextCursor);

// Fetch subsequent pages using the returned cursor
if (page.nextCursor) {
  const nextPage = await fetchSessionEventsPage('recording-123', page.nextCursor);
}

// Report that the recording was played
const accepted = await recordRecordingPlayed('session-abc');
if (!accepted) {
  console.warn('Playback report was not accepted');
}
```
