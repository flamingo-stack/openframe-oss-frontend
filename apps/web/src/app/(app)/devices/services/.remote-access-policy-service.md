# remote-access-policy-service.ts

Defines the `IRemoteAccessPolicyService` interface, a contract for reading and managing remote access policies at three hierarchical scopes: tenant, organization, and device. The effective access mode is resolved by the server following a device → organization → tenant inheritance chain, with each lower scope optionally overriding the one above it.

## Key Components

- **`IRemoteAccessPolicyService`** — Interface defining the remote access policy contract:
  - `getTenantPolicy()` — Fetches the tenant-wide default policy.
  - `updateTenantPolicy(policy)` — Updates the tenant-wide default policy.
  - `getOrganizationPolicy(organizationId)` — Fetches an organization's policy, including its effective mode.
  - `setOrganizationMode(organizationId, mode)` — Sets or clears (via `null`) an organization-level override.
  - `getDevicePolicy(deviceId)` — Fetches a single device's override and effective mode.
  - `getDevicePolicies(deviceIds)` — Batch-fetches policies for multiple devices in one request, returned as a `Map` keyed by device id; unknown devices are omitted.
  - `setDeviceMode(deviceId, mode)` — Sets or clears (via `null`) a device-level override.

This interface is implemented by `RemoteAccessPolicyApiService` in `remote-access-policy-api-service.ts`, which communicates with the `openframe-saas-api` backend.

## Usage Example

```typescript
import type { IRemoteAccessPolicyService } from './remote-access-policy-service';
import type { RemoteAccessMode } from '../types/remote-access';

async function clearDeviceOverride(
  service: IRemoteAccessPolicyService,
  deviceId: string
) {
  // Passing `null` clears the override, reverting to inherited policy
  const updatedPolicy = await service.setDeviceMode(deviceId, null);
  console.log('Effective mode:', updatedPolicy.effectiveMode);
}

async function loadRowPolicies(
  service: IRemoteAccessPolicyService,
  deviceIds: string[]
) {
  const policiesByDevice = await service.getDevicePolicies(deviceIds);
  for (const [deviceId, policy] of policiesByDevice) {
    console.log(deviceId, policy.effectiveMode);
  }
}
```
