# recording-tickets-api-service.ts

API service for reading and mutating the tickets linked to a remote session, accessed through a recording's session. It wraps Relay queries/mutations for fetching, assigning, and unassigning tickets, normalizing each GraphQL response into `RecordingTicket[]` via `toRecordingTicket`.

## Key Components

- **`MAX_ASSIGNED_TICKETS`** — Constant (`50`) representing the server-enforced max number of ticket ids per assign call.
- **`fetchRecordingTickets(recordingId: string): Promise<RecordingTicket[]>`** — Fetches the tickets linked to a recording's session using a network-only Relay query.
- **`assignRecordingTickets(sessionId: string, ticketIds: string[]): Promise<RecordingTicket[]>`** — Links one or more tickets to a session via mutation; throws on `userErrors`, and returns the updated ticket list from the mutation payload (no refetch).
- **`unassignRecordingTicket(sessionId: string, ticketId: string): Promise<RecordingTicket[]>`** — Unlinks a single ticket from a session; throws on `userErrors`, and returns the updated ticket list from the mutation payload.

Internally defined (not exported): `ticketsQuery`, `assignMutation`, `unassignMutation` — the GraphQL documents backing the above functions.

## Usage Example

```typescript
import {
  fetchRecordingTickets,
  assignRecordingTickets,
  unassignRecordingTicket,
  MAX_ASSIGNED_TICKETS,
} from './recording-tickets-api-service';

// Load tickets linked to a recording's session
const tickets = await fetchRecordingTickets('recording-123');

// Assign tickets (respect the max batch size)
const ticketIds = ['ticket-1', 'ticket-2'].slice(0, MAX_ASSIGNED_TICKETS);
const updatedTickets = await assignRecordingTickets('session-456', ticketIds);

// Unassign a single ticket
const remainingTickets = await unassignRecordingTicket('session-456', 'ticket-1');
```

Both mutation functions throw an `Error` with the server-provided message (or a fallback) when `userErrors` is non-empty, so callers should wrap calls in `try/catch` to surface failures to the UI.
