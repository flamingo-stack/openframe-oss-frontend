Service module that fetches and mutates the tickets linked to a remote session recording via Relay GraphQL queries/mutations, exposing a clean async API for ticket assignment workflows.

## Key Components

- **`MAX_ASSIGNED_TICKETS`** - Constant (50) representing the server-enforced limit on ticket IDs per assign call.
- **`fetchRecordingTickets(recordingId)`** - Fetches the list of tickets linked to a recording's session, using a network-only fetch policy. Returns an array of `RecordingTicket` objects (session's own tickets first, then by link time).
- **`assignRecordingTickets(sessionId, ticketIds)`** - Commits the `assignRecordingTickets` mutation to link one or more tickets to a session. Returns the updated ticket list from the mutation payload; throws on `userErrors`.
- **`unassignRecordingTicket(sessionId, ticketId)`** - Commits the `unassignRecordingTicket` mutation to unlink a single ticket. Returns the updated ticket list; throws on `userErrors`.

All functions rely on `toRecordingTicket` to normalize GraphQL fragment data into the `RecordingTicket` shape, and the mutations return the full session's tickets so the UI table can be replaced directly from the mutation response instead of re-querying.

## Usage Example

```typescript
import {
  fetchRecordingTickets,
  assignRecordingTickets,
  unassignRecordingTicket,
  MAX_ASSIGNED_TICKETS,
} from './recording-tickets-api-service';

// Load tickets for a recording's session
const tickets = await fetchRecordingTickets('recording-123');

// Assign new tickets (respecting the server-side limit)
if (ticketIds.length <= MAX_ASSIGNED_TICKETS) {
  const updatedTickets = await assignRecordingTickets('session-456', ticketIds);
}

// Unassign a single ticket
try {
  const remainingTickets = await unassignRecordingTicket('session-456', 'ticket-789');
} catch (err) {
  console.error('Unassign failed:', err.message);
}
```
