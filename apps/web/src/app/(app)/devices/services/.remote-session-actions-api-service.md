# remote-session-actions-api-service.ts

Reports technician actions performed in the remote desktop console to a session's timeline via the `recordRemoteSessionAction` GraphQL mutation. Only the controlling technician's console reports actions, and the server timestamps each report so late arrivals are harmless.

## Key Components

- **`RemoteSessionAction`** - Discriminated union type representing the console actions that can be reported: `INPUT_ENABLED`, `INPUT_DISABLED`, `CTRL_ALT_DEL`, `SHORTCUT_SENT` (with label/source), and `MONITOR_SWITCHED` (with monitor ids/label).
- **`toActionInput(sessionId, action, clientEventId, clientTime)`** - Converts a `RemoteSessionAction` into a `RecordRemoteSessionActionInput` for the mutation. Returns `null` if the action's fields (label pattern or monitor id) would be rejected by the server, in which case it should not be sent.
- **`isRetryableReportError(error)`** - Determines whether a failed report is worth retrying. Returns `true` for connectivity/offline issues (no response received); returns `false` for GraphQL validation errors or server-side `userErrors` refusals, which are final.
- **`recordRemoteSessionAction(input)`** - Executes the mutation and resolves to whether the server accepted/stored the action.

## Usage Example

```typescript
import {
  toActionInput,
  recordRemoteSessionAction,
  isRetryableReportError,
} from '@/services/remote-session-actions-api-service';

async function reportShortcut(sessionId: string) {
  const input = toActionInput(
    sessionId,
    { action: 'SHORTCUT_SENT', label: 'Ctrl+Shift+Esc', source: 'KEYBOARD' },
    crypto.randomUUID(),
    new Date().toISOString(),
  );

  if (!input) {
    // Label failed server validation pattern; action is dropped silently.
    return;
  }

  try {
    const accepted = await recordRemoteSessionAction(input);
    if (!accepted) {
      // Server stored the request but refused the action (userErrors).
    }
  } catch (error) {
    if (isRetryableReportError(error)) {
      // Safe to retry: network/offline/5xx failure.
    } else {
      // Final failure: validation error, do not retry.
    }
  }
}
```
