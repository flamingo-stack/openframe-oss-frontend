# remote-session-actions-api-service.ts

Service for reporting technician actions taken in a remote desktop session (e.g., enabling/disabling input, sending Ctrl+Alt+Del, keyboard shortcuts, monitor switches) to the server's session timeline via a GraphQL mutation. It validates and shapes inputs client-side so invalid reports are dropped rather than sent, and classifies errors to distinguish retryable network failures from final server refusals.

## Key Components

- **`RemoteSessionAction`** - Discriminated union of the console actions that can be reported (`INPUT_ENABLED`, `INPUT_DISABLED`, `CTRL_ALT_DEL`, `SHORTCUT_SENT`, `MONITOR_SWITCHED`), each with its required fields.
- **`toActionInput(sessionId, action, clientEventId, clientTime)`** - Converts a `RemoteSessionAction` into a `RecordRemoteSessionActionInput`, validating labels against `LABEL_PATTERN` and monitor ids against `isMonitorId`. Returns `null` if the action would be rejected by the server, so callers should skip sending it.
- **`isRetryableReportError(error)`** - Determines if a failed report is worth retrying: `true` for offline/network/timeout/5xx errors, `false` for GraphQL validation errors or server-side `userErrors`.
- **`recordRemoteSessionAction(input)`** - Executes the `recordRemoteSessionActionMutation`, returning whether the server accepted and stored the action.
- **`LABEL_PATTERN`** - Regex enforcing the server's label rule (letters, digits, spaces, "+", 1–40 chars).
- **`isMonitorId(id)`** - Type guard ensuring a monitor id is an integer between 0 and 15 (excludes the agent's "all displays" sentinel `0xFFFF`).

## Usage Example

```typescript
import { toActionInput, recordRemoteSessionAction, isRetryableReportError } from '@/services/remote-session-actions-api-service';

const input = toActionInput(
  sessionId,
  { action: 'SHORTCUT_SENT', label: 'Ctrl+Shift+Esc', source: 'KEYBOARD' },
  crypto.randomUUID(),
  new Date().toISOString(),
);

if (input) {
  try {
    const accepted = await recordRemoteSessionAction(input);
    if (!accepted) console.warn('Server refused the action');
  } catch (error) {
    if (isRetryableReportError(error)) {
      // queue for retry
    } else {
      // log and discard
    }
  }
}
```
