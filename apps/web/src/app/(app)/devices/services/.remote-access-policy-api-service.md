# remote-access-policy-api-service.ts

GraphQL-backed implementation of the remote access policy service for the openframe-saas-api backend. It fetches and mutates remote access policies at the tenant, organization, and device scopes via Relay, converting GraphQL wire shapes into application-level read models.

## Key Components

- **`RemoteAccessPolicyApiService`** — Class implementing `IRemoteAccessPolicyService`, providing:
  - `getTenantPolicy()` / `updateTenantPolicy(policy)` — read/write the tenant-wide remote access mode.
  - `getOrganizationPolicy(organizationId)` / `setOrganizationMode(organizationId, mode)` — read/write an organization's mode (or clear it, falling back to tenant default).
  - `getDevicePolicy(deviceId)` / `getDevicePolicies(deviceIds)` — read a single device's policy, or batch-fetch many via a `nodes(ids:)` query (used for paginated table rows).
  - `setDeviceMode(deviceId, mode)` — set or clear a device's override mode.
- **`remoteAccessPolicyApiService`** — Singleton instance of the service, intended for app-wide use.
- **Wire-to-model converters** — `fromWireTenantPolicy`, `fromWireOrganizationPolicy`, `fromWireDevicePolicy` validate and transform raw GraphQL fragment data (`mode`, `effectiveMode`, `effectiveScope`) into typed domain objects, throwing on malformed server data.
- **GraphQL artifacts** — Inline fragments (`remoteAccessPolicyApiService_tenant/_organization/_device`), queries, and mutations defined via `graphql` tagged templates, consumed through Relay's `fetchQuery` and a shared `commitMutationPromise` helper.

## Usage Example

```typescript
import { remoteAccessPolicyApiService } from './remote-access-policy-api-service';

// Read the tenant's current policy
const tenantPolicy = await remoteAccessPolicyApiService.getTenantPolicy();

// Update an organization's mode (pass null to clear override)
const orgPolicy = await remoteAccessPolicyApiService.setOrganizationMode('org-123', 'DISABLED');

// Batch-fetch device policies for a table page
const devicePolicies = await remoteAccessPolicyApiService.getDevicePolicies(['dev-1', 'dev-2']);
const devicePolicy = devicePolicies.get('dev-1');
```

Note: device policies are read through dedicated queries (not the shared device query bundle) because this same codebase also targets an OSS backend schema lacking `Machine.remoteAccess`, and GraphQL validation fails if a query references a nonexistent field.
