## RemoteAccessPolicyApiService

GraphQL-backed implementation of `IRemoteAccessPolicyService` that reads and writes remote access policies at the tenant, organization, and device scopes against the `openframe-saas-api` backend. Tenant and organization scopes use dedicated queries/mutations, while the device scope is resolved server-side (device → organization → tenant → defaults) and read through its own small queries rather than the app's shared device queries, since the OSS backend schema lacks the `Machine.remoteAccess` field and would fail validation if it were included.

## Key Components

- **`RemoteAccessPolicyApiService`** - Class implementing `IRemoteAccessPolicyService` with methods:
  - `getTenantPolicy()` / `updateTenantPolicy(policy)` - tenant-level mode
  - `getOrganizationPolicy(organizationId)` / `setOrganizationMode(organizationId, mode)` - org-level mode with effective resolution
  - `getDevicePolicy(deviceId)` / `getDevicePolicies(deviceIds)` - single and batched device policy reads (via `nodes` connection)
  - `setDeviceMode(deviceId, mode)` - updates a device's override mode
- **`remoteAccessPolicyApiService`** - Singleton instance for app-wide use.
- **`fromWireTenantPolicy`, `fromWireOrganizationPolicy`, `fromWireDevicePolicy`** - Pure mappers converting GraphQL fragment data into app-level `TenantRemoteAccessPolicy`, `OrganizationRemoteAccessPolicy`, and `DeviceRemoteAccessPolicy` types, throwing on malformed/unknown mode or scope values.
- Internal GraphQL fragments/queries/mutations (`tenantFragment`, `organizationFragment`, `deviceFragment`, `tenantQuery`, `organizationQuery`, `deviceQuery`, `devicesQuery`, `setTenantMutation`, `setOrganizationMutation`, `setDeviceMutation`) define the wire contract.

## Usage Example

```typescript
import { remoteAccessPolicyApiService } from './remote-access-policy-api-service';

// Read the tenant-wide policy
const tenantPolicy = await remoteAccessPolicyApiService.getTenantPolicy();

// Update an organization's mode (null clears the override, falling back to tenant default)
const orgPolicy = await remoteAccessPolicyApiService.setOrganizationMode('org-123', 'DISABLED');

// Batch-fetch device policies for a page of table rows
const devicePolicies = await remoteAccessPolicyApiService.getDevicePolicies(['device-1', 'device-2']);
const policy = devicePolicies.get('device-1');
console.log(policy?.effectiveMode, policy?.effectiveScope);
```

Mutation calls that fail validation surface as thrown `Error`s using the server's `userErrors[0].message` (falling back to a generic message); device-scope failures (unknown device, feature disabled) instead reject via standard GraphQL errors.
