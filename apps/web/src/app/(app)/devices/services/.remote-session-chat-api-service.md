# remote-session-chat-api-service.ts

Implements the chat service for remote support sessions, bridging the backend's session dialog (a `CLIENT_CHAT`-type dialog provisioned alongside a remote session) with the chat UI. It fetches message history via the ticket service and decodes live chat events streamed from JetStream, filtering out system notices and non-participant chunks.

## Key Components

- **`decodeRemoteSessionChatChunk(payload, technician?)`** — Decodes a raw NATS/JetStream chunk into a `RemoteSessionChatMessage`, or `null` if it's not a participant's chat line (e.g., assistant deltas, system notices). Maps `OWNER_TYPE.CLIENT` to the end user and `OWNER_TYPE.ADMIN` to the technician, falling back to a provided technician name or `"Technician"`.
- **`rowsOf(message)`** — Converts a persisted `Message` (from history) into zero or more `RemoteSessionChatMessage` rows, keeping only `TEXT`-type entries and tagging them by owner type.
- **`technicianName(owner)`** — Resolves a display name from an `AdminOwner`'s first/last name, falling back to `"Technician"`.
- **`RemoteSessionChatApiService`** — Implements `IRemoteSessionChatService`:
  - `history(dialogId)`: Fetches the latest page of messages (newest-first, reversed to chronological), flattens them into chat rows, and computes the highest sequence number seen.
  - `send(dialogId, body)`: Sends a message through the ticket service using `CHAT_TYPE.CLIENT`.
- **`remoteSessionChatApiService`** — Singleton instance of `RemoteSessionChatApiService`.

## Usage Example

```typescript
import { remoteSessionChatApiService, decodeRemoteSessionChatChunk } from './remote-session-chat-api-service';

// Load initial history for a session's dialog
const { messages, lastSeq } = await remoteSessionChatApiService.history(dialogId);

// Send a technician message
await remoteSessionChatApiService.send(dialogId, 'How can I help?');

// Decode a live JetStream chunk subscribed by a hook
const row = decodeRemoteSessionChatChunk(rawPayload, { name: 'Jane Doe' });
if (row) {
  // append row to the live chat feed
}
```

Note: a technician's own sent message only appears in the UI once it echoes back through the dialog as an ADMIN-owned chunk—`send()` does not optimistically render the message.
