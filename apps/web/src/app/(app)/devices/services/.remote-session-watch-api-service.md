# remote-session-watch-api-service.ts

Provides the GraphQL-backed service for joining (or renewing admission to) a live remote session as a view-only watcher, plus helpers for parsing viewer presence events from the real-time notification channel.

## Key Components

- **`watchMutation`** - GraphQL mutation (`watchRemoteSession`) that admits the caller to a session's remote screen and returns the socket dial info (`requestId`, `nodeId`) and current viewer list.
- **`WatchViewer`** - Type alias for a viewer entry (user watching a session).
- **`WatchGrant`** - Interface describing a successful watch admission: `requestId`, `nodeId`, and `viewers`.
- **`WatchEndedError`** - Thrown when the session has already ended.
- **`WatchDisabledError`** - Thrown when watching is disabled (tenant setting, live reads, or remote access itself), carries an error `code`.
- **`WATCH_EVENT_TYPES`** - Constant map of notification event type strings (`joined`, `left`, `ended`).
- **`WatchEvent`** - Union type representing either an updated viewers list or a session-ended signal.
- **`currentViewers(list)`** - Deduplicates a raw viewer list into active viewers (drops entries with `leftAt` set).
- **`parseWatchEvent(payload, sessionId)`** - Parses a notification-subject payload into a `WatchEvent` for the given session, or `null` if irrelevant.
- **`RemoteSessionWatchApiService`** - Service class exposing `watch(sessionId)` to request/renew watch admission.
- **`remoteSessionWatchApiService`** - Singleton instance of the service.

## Usage Example

```typescript
import {
  remoteSessionWatchApiService,
  parseWatchEvent,
  WatchEndedError,
  WatchDisabledError,
} from './remote-session-watch-api-service';
import { SessionNotFoundError } from './session-recordings-service';

async function joinWatch(sessionId: string) {
  try {
    const grant = await remoteSessionWatchApiService.watch(sessionId);
    console.log('Dial socket with', grant.requestId, grant.nodeId);
    console.log('Current viewers:', grant.viewers);
  } catch (err) {
    if (err instanceof WatchEndedError) {
      console.log('Session has ended');
    } else if (err instanceof WatchDisabledError) {
      console.log(`Watching disabled: ${err.code}`);
    } else if (err instanceof SessionNotFoundError) {
      console.log('Session not found');
    } else {
      throw err;
    }
  }
}

// Handling a notification-subject event
function onNotification(payload: unknown, sessionId: string) {
  const event = parseWatchEvent(payload, sessionId);
  if (event?.kind === 'ended') {
    console.log('Watch session ended');
  } else if (event?.kind === 'viewers') {
    console.log('Updated viewers:', event.viewers);
  }
}
```

Call `watch()` again every ~10s (and right before dialing) to renew admission, since grants expire after a short time.
