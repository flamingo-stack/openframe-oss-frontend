# remote-session-watch-api-service.ts

Provides a view-only "watch" capability for live remote sessions, admitting the caller to a session's remote screen via GraphQL and parsing viewer presence events delivered over the notification subject.

## Key Components

- **`RemoteSessionWatchApiService`** — Service class exposing `watch(sessionId)`, which calls the `watchRemoteSession` mutation to admit/renew the caller's watch access and returns connection details plus current viewers.
- **`remoteSessionWatchApiService`** — Singleton instance of the service for app-wide use.
- **`WatchGrant`** — Result of a successful watch call: `requestId`, `nodeId` (used to dial the watch socket), and `viewers`.
- **`WatchViewer`** — Alias for `RemoteSessionViewerEntry`, representing a user currently watching.
- **`WatchEndedError`** — Thrown when the session has already ended.
- **`WatchDisabledError`** — Thrown when watching is disabled for the tenant (carries an error `code`).
- **`WATCH_EVENT_TYPES`** — Constants for viewer-joined/left/session-ended notification event types.
- **`WatchEvent`** — Discriminated union representing either an updated viewers list or a session-ended signal.
- **`currentViewers(list)`** — Reduces a raw viewer list to unique, still-present viewers (drops duplicates and those with `leftAt` set).
- **`parseWatchEvent(payload, sessionId)`** — Parses a notification payload into a `WatchEvent` for the given session, or `null` if irrelevant.

## Usage Example

```typescript
import {
  remoteSessionWatchApiService,
  parseWatchEvent,
  WatchEndedError,
  WatchDisabledError,
} from './remote-session-watch-api-service';
import { SessionNotFoundError } from './session-recordings-service';

async function joinWatch(sessionId: string) {
  try {
    const grant = await remoteSessionWatchApiService.watch(sessionId);
    console.log('Dial socket with', grant.requestId, grant.nodeId);
    console.log('Current viewers:', grant.viewers);
  } catch (err) {
    if (err instanceof WatchEndedError) {
      console.log('Session already ended');
    } else if (err instanceof WatchDisabledError) {
      console.log('Watching disabled:', err.code);
    } else if (err instanceof SessionNotFoundError) {
      console.log('Unknown session');
    }
  }
}

// Handling live notification events
function handleNotification(payload: unknown, sessionId: string) {
  const event = parseWatchEvent(payload, sessionId);
  if (!event) return;
  if (event.kind === 'ended') {
    console.log('Session ended');
  } else {
    console.log('Viewers updated:', event.viewers);
  }
}
```

Callers should re-invoke `watch()` before dialing the socket and periodically (every 10s) while watching, per the renewal requirement described in the mutation's documentation.
