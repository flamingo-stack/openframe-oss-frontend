# remote-access-approval-api-service.ts

GraphQL-backed implementation of the remote access approval service, handling technician-initiated requests for remote device access via `openframe-saas-api`. It creates, polls, and revokes `RemoteAccessRequest` records using Relay, and provides helpers to parse/merge real-time decision events pushed over the technician's notification subject.

## Key Components

- **`RemoteAccessApprovalApiService`** — class implementing `IRemoteAccessApprovalService`:
  - `create(input)` — runs `createRemoteAccessRequest` mutation; throws `RemoteAccessCreateError` on domain-level `userErrors` (e.g. device has a live request, remote access disabled).
  - `get(requestId)` — network-only fetch of `remoteAccessRequest(requestId)`, used for 2s poll loops.
  - `revoke(requestId)` — runs `revokeRemoteAccessRequest`; tolerates the "already settled" error code as a no-op.
- **`remoteAccessApprovalApiService`** — singleton instance exported for app-wide use.
- **`fromWireRemoteAccessRequest(data)`** — converts the GraphQL wire shape into the app's `RemoteAccessRequest` read model; throws on malformed data (missing `requestId`/`status`).
- **`parseRemoteAccessDecisionEvent(payload)`** — type-guards and parses a raw notification payload into a `RemoteAccessDecisionEvent`, or returns `null` if it's not a matching event.
- **`applyRemoteAccessDecisionEvent(request, event)`** — merges a decision event into an existing request object (used after a push notification updates status/decision fields).

## Usage Example

```typescript
import {
  remoteAccessApprovalApiService,
  parseRemoteAccessDecisionEvent,
  applyRemoteAccessDecisionEvent,
} from './remote-access-approval-api-service';

// Create a request
const request = await remoteAccessApprovalApiService.create({
  deviceId: 'device-123',
  reason: 'Troubleshooting network issue',
  ticketId: 'TICKET-456',
});

// Poll for status updates
const latest = await remoteAccessApprovalApiService.get(request.requestId);

// Handle a pushed decision event (e.g. from a notification subscription)
const event = parseRemoteAccessDecisionEvent(incomingPayload);
if (event) {
  const updated = applyRemoteAccessDecisionEvent(latest, event);
}

// Revoke a pending request
await remoteAccessApprovalApiService.revoke(request.requestId);
```

Used primarily by `useRemoteAccessApproval`, which subscribes to decision events and drives the UI's polling/approval flow.
