# remote-access-approval-api-service.ts

GraphQL-backed implementation of the remote access approval service, communicating with `openframe-saas-api` to create, poll, and revoke technician remote access requests. It converts GraphQL wire payloads into the app's `RemoteAccessRequest` domain model and parses decision-push events delivered via the technician's notification subject.

## Key Components

- **`RemoteAccessApprovalApiService`** - class implementing `IRemoteAccessApprovalService` with three operations, all run imperatively against the app's Relay environment:
  - `create(input)` - runs `createRemoteAccessRequest` mutation; throws `RemoteAccessCreateError` on domain refusals (live request/session conflict, unreachable device, feature disabled)
  - `get(requestId)` - runs `remoteAccessRequest(requestId)` query (network-only), used for 2s polling
  - `revoke(requestId)` - runs `revokeRemoteAccessRequest` mutation; silently tolerates a "request already settled" error
- **`remoteAccessApprovalApiService`** - singleton instance exported for app-wide use
- **`fromWireRemoteAccessRequest(data)`** - converts the GraphQL fragment shape into `RemoteAccessRequest`, validating required fields and enum values (status, mode, decision source)
- **`parseRemoteAccessDecisionEvent(payload)`** - parses an untyped notification payload into a `RemoteAccessDecisionEvent`, or returns `null` if it isn't a `REMOTE_ACCESS_DECISION` event
- **`applyRemoteAccessDecisionEvent(request, event)`** - merges a decision event into an existing request to produce the updated state

## Usage Example

```typescript
import { remoteAccessApprovalApiService, parseRemoteAccessDecisionEvent, applyRemoteAccessDecisionEvent } from './remote-access-approval-api-service';

// Create a request
const request = await remoteAccessApprovalApiService.create({
  deviceId: 'device-123',
  reason: 'Investigating slow performance',
});

// Poll for status updates
const latest = await remoteAccessApprovalApiService.get(request.requestId);

// Handle a push event from the notification subject
const event = parseRemoteAccessDecisionEvent(incomingPayload);
if (event) {
  const updated = applyRemoteAccessDecisionEvent(latest, event);
}

// Revoke when no longer needed
await remoteAccessApprovalApiService.revoke(request.requestId);
```

Used by `useRemoteAccessApproval` and related hooks to drive the technician-facing remote access approval workflow.
