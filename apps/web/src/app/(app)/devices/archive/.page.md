# ArchivedDevices Page

Next.js page component that displays a read-only archive of deleted (and legacy archived) devices, with optional scoping to a single customer organization.

## Key Components

- **`ArchivedDevices`** (default export) — Page component rendering the `DevicesPanel` configured for archive viewing.
- **`ARCHIVE_STATUSES`** — Constant array of `DEVICE_STATUS.DELETED` and `DEVICE_STATUS.ARCHIVED`, used to lock the status filter to archived records only. `ARCHIVED` is retained only for legacy records predating the removal of the archive action; neither status is restorable.
- **`ORGANIZATION`** — Constant array (`['organization']`) used to conditionally hide the organization column/filter when the view is scoped to a single customer.

## Behavior

- Reads an `organizationId` query parameter via `useSearchParams`, but only honors it when `useTenantManagementV2Gate()` returns `'on'`. Otherwise the parameter is ignored, matching behavior on the main devices view.
- When scoped to an organization, the back button returns to that customer's details page (devices tab); otherwise it returns to the main devices list, using `useSafeBack` for safe navigation history handling.
- `lockedFilters` is memoized and combines the archive statuses with an optional `organizationIds` filter.
- The panel hides the status filter (and organization column/filter when scoped), disables directory lookups, hides the "Add Device" action, and renders all rows as read-only.
- Displays a custom `EmptyState` with a box-archive icon when no archived devices exist.

## Usage Example

This file is a Next.js route page and is rendered automatically by the framework when navigating to its route. It is not typically imported directly, but conceptually behaves as:

```typescript
// Navigated to via app routing, e.g.:
// /devices/archive
// /devices/archive?organizationId=org-123  (only effective when tenant-management-v2 is enabled)

import ArchivedDevices from './page';

function Example() {
  return <ArchivedDevices />;
}
```

Linking to this page from a customer's Devices tab (when the v2 gate is enabled):

```typescript
import { routes } from '@/lib/routes';

const archiveLink = `${routes.devices.archive}?organizationId=${organizationId}`;
```
