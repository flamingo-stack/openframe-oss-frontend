# page.tsx

Next.js page component that displays a read-only archive of deleted devices, reusing the shared `DevicesPanel` with locked filters for archived/deleted statuses. Optionally scopes the archive to a single organization when opened from a customer's Devices tab (gated behind the `tenant-management-v2` feature flag).

## Key Components

- **`ArchivedDevices`** (default export) — Page component rendering the devices archive view.
- **`ARCHIVE_STATUSES`** — Constant array containing `DEVICE_STATUS.DELETED` and `DEVICE_STATUS.ARCHIVED`, used to lock the status filter to only show archived/deleted devices.
- **`ORGANIZATION`** — Constant array (`['organization']`) used to conditionally hide the organization column/filter when scoped to a single customer.

## Behavior Notes

- Reads `organizationId` from the URL query string via `useSearchParams`.
- The organization scope is only honored when `useTenantManagementV2Gate()` returns `'on'`; otherwise the query param is ignored and the full archive is shown.
- `useSafeBack` determines the back-navigation target: back to the customer's devices tab (if scoped) or the main devices list.
- When scoped to an organization, the organization column and filter are hidden, and the status filter is also hidden (statuses are locked, not user-selectable).
- Renders a custom `EmptyState` with an archive icon when no archived devices exist.

## Usage Example

```typescript
// Accessed via routing, e.g.:
// /devices/archive                      -> full archive
// /devices/archive?organizationId=123   -> scoped to org (if tenant-management-v2 is on)

import ArchivedDevices from './page';

export default ArchivedDevices;
```

This component is typically reached through:
- A direct navigation link labeled "Devices Archive" from the main devices list.
- A link from a customer's Devices tab (`routes.customers.details(organizationId, { tab: 'devices' })`), which passes `organizationId` as a query param.
