This file defines the Next.js metadata configuration and layout export for the Remote Sessions route, setting a dynamic page title based on the application's route-title utility.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the document title to `"Remote Sessions"` (formatted via the `routeTitle` helper), enabling Next.js's built-in `<head>` title injection for this route segment.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, reusing a common layout wrapper across routes instead of defining a new one.

## Usage Example

This file is a Next.js App Router convention file (`layout.tsx`) and is not imported manually. Placing it within a route segment automatically applies the layout and metadata to that segment and its children:

```typescript
// app/(app)/remote-sessions/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Remote Sessions') };
```

Next.js automatically picks up this file to:
1. Render the shared layout component around the route's page content.
2. Set the browser tab title to the value produced by `routeTitle('Remote Sessions')`.

To reuse this pattern for another route, copy this file into the target route folder and change the string passed to `routeTitle`.
