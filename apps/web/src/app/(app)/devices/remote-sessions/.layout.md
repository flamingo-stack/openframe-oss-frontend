This Next.js layout file configures page metadata for the Remote Sessions route, re-exporting a shared layout component while defining a route-specific page title.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the document title for this route using the `routeTitle` utility, producing a consistent, branded page title (e.g., `"Remote Sessions"` formatted per app conventions).
- **Default export** — Re-exports `route-title-layout` from `@/app/(app)/route-title-layout` as this route's layout component, avoiding duplication of layout logic across routes.

## Usage Example

This file follows the Next.js App Router convention where a `layout.tsx` file automatically applies to all pages within its route segment:

```typescript
// app/(app)/remote-sessions/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Remote Sessions') };
```

Next.js automatically picks up this file to:
1. Apply the shared `route-title-layout` component to wrap child pages/routes.
2. Set the browser tab title to the result of `routeTitle('Remote Sessions')`.

To add a new route with the same pattern, create a sibling `layout.tsx` and simply change the string passed to `routeTitle(...)`, keeping title formatting consistent across the application without rewriting layout markup.
