# use-remote-session-watch-gate.ts

React hooks that gate access to the live session-watching feature (LIVE rows in Remote Sessions lists, the live session page, and header viewer counts) by combining the session recordings feature gate with the `remote-session-watch` flag.

## Key Components

- **`useRemoteSessionWatchGate()`** — Resolves the combined feature flag state for live session watching. Returns `'off'` if either the session recordings gate or the `remote-session-watch` flag is off, `'loading'` if either is still resolving, and `'on'` only when both are enabled.
- **`useLiveRows()`** — Returns the data needed by Remote Sessions lists to render LIVE rows (currently just `{ userId }`), or `null` when the watch gate is not `'on'`. When `null`, callers should fall back to reading a running session via its recording instead.

## Usage Example

```typescript
import { useLiveRows } from './use-remote-session-watch-gate';

function RemoteSessionsList() {
  const liveRows = useLiveRows();

  if (liveRows) {
    // Gate is on: subscribe to live session data for liveRows.userId
    return <LiveSessionRow userId={liveRows.userId} />;
  }

  // Gate is off or still loading: fall back to recording-based rendering
  return <RecordingBasedRow />;
}
```

```typescript
import { useRemoteSessionWatchGate } from './use-remote-session-watch-gate';

function RemoteControlHeader() {
  const gate = useRemoteSessionWatchGate();

  if (gate === 'loading') return <Spinner />;
  if (gate === 'off') return null;

  return <LiveViewerCount />;
}
```

## Notes

- `useRemoteSessionWatchGate` depends on `useSessionRecordingsGate` as a prerequisite — live watching is unavailable unless the broader session recordings surface is also enabled.
- Client-only hooks (`'use client'` directive), intended for Next.js app directory components.
