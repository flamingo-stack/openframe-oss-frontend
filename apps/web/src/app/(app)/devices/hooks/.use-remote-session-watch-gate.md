This file provides React hooks for gating the "live session watch" feature, controlling visibility of real-time session viewing capabilities (LIVE rows in Remote Sessions lists, the live session page, and active viewer indicators in the Remote Control header).

## Key Components

- **`useRemoteSessionWatchGate()`** — Combines the `session-recordings` gate with the `remote-session-watch` feature flag gate. Returns `'off'` if either gate is off, `'loading'` if either is still resolving, or `'on'` when both are enabled. This ensures watch functionality only activates when its prerequisite (session recordings) is also available.
- **`useLiveRows()`** — Derives the data needed by Remote Sessions lists to render LIVE rows. Returns `null` when the watch gate isn't `'on'` (falling back to recording-based display), or an object containing the current authenticated `userId` when live watching is enabled.

## Usage Example

```typescript
import { useRemoteSessionWatchGate, useLiveRows } from './use-remote-session-watch-gate';

function RemoteSessionsList() {
  const liveRows = useLiveRows();

  if (liveRows) {
    // Render LIVE row using liveRows.userId to identify the current viewer
    return <SessionTableWithLiveSupport userId={liveRows.userId} />;
  }

  // Fall back to standard recording-based rows
  return <SessionTableRecordingsOnly />;
}

function RemoteControlHeader() {
  const gate = useRemoteSessionWatchGate();

  if (gate === 'loading') return <HeaderSkeleton />;
  if (gate === 'off') return null;

  return <ActiveViewersIndicator />;
}
```

## Notes

- Depends on `useSessionRecordingsGate` (from `./use-session-recordings-gate`) and `useFeatureFlagGate` (from `@/app/hooks/use-feature-flag`) to resolve combined gate state.
- Reads the authenticated user via `useAuthStore` from `@/app/(auth)/auth/stores/auth-store`.
- Use `useLiveRows()` directly in list-rendering components to avoid duplicating gate-combination logic; use `useRemoteSessionWatchGate()` when only the on/off/loading state is needed (e.g., conditional UI chrome).
