Provides a React hook that determines whether QA-only mock tooling for the Remote Access recording player (local `.mcrec` file loader) should be rendered in the UI.

## Key Components

- **`useRemoteAccessMockTools()`** — Hook returning a `boolean` indicating if the mock recording loader should be shown. Resolves to `true` when:
  - The app is running in local development (`process.env.NODE_ENV === 'development'`), **or**
  - The server-side feature flag `remote-access-mock-tools` is enabled (typically on for `dev`/`qa` environments).

This dual condition ensures the tool is always available locally for development/testing—even if pointed at an environment (like staging) that doesn't have the flag enabled—while remaining gated behind a feature flag in deployed builds.

## Usage Example

```typescript
import { useRemoteAccessMockTools } from '@/app/hooks/use-remote-access-mock-tools';

function RecordingPlayer() {
  const showMockTools = useRemoteAccessMockTools();

  return (
    <div>
      {showMockTools && (
        <McrecFileLoader onFileSelected={handleLocalRecording} />
      )}
      <RemoteAccessRecordingViewer />
    </div>
  );
}
```

**Note:** This is temporary tooling intended to be removed once recordings storage is fully supported across all environments. Avoid relying on it for production feature gating.
