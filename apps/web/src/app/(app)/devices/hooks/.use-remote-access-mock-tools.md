# use-remote-access-mock-tools.ts

A React hook that determines whether the recording player's local `.mcrec` file loader (QA tooling for playing sample recordings) should render. This is a temporary utility intended to be removed once recordings storage is fully available across all environments.

## Key Components

- **`useRemoteAccessMockTools()`** — Hook returning a `boolean`. Resolves to `true` when:
  - The app is running in development mode (`NODE_ENV === 'development'`), **or**
  - The server-side feature flag `remote-access-mock-tools` is enabled (typically on for dev/qa environments).

This mirrors the "dev bypass" pattern used elsewhere (e.g., the approval gate), ensuring that a local dev server pointed at an environment lacking the flag (such as stage) still has access to the mock tooling for testing.

## Usage Example

```typescript
import { useRemoteAccessMockTools } from '@/app/hooks/use-remote-access-mock-tools';

function RecordingPlayer() {
  const showMockLoader = useRemoteAccessMockTools();

  return (
    <div>
      {showMockLoader && <McrecFileLoader />}
      <RemoteAccessPlayer />
    </div>
  );
}
```

## Notes

- Depends on `useFeatureFlag` from `@/app/hooks/use-feature-flag`.
- Marked `'use client'`, so it must be used within client components.
- This is explicitly flagged as **temporary** — once recordings storage is available on every environment, this hook and its associated mock loader UI should be removed.
