# use-device-list.ts

A React hook that fetches a single bounded page of devices via Relay, intended for "picker" surfaces (device selection in run/test-script dialogs and schedule assignment views) rather than paginated browsing.

## Key Components

- **`DEVICE_LIST_LIMIT`** — Exported constant (`100`) capping the number of devices returned; pickers render what fits without pagination.
- **`UseDeviceListOptions`** — Input options interface: `filter` (device filter), `search` (query string), `first` (page size override), and `retryKey` (cache-breaker for forcing a refetch after a thrown error).
- **`DeviceListResult`** — Return shape: `devices` (array of `Device`) and `filteredCount` (total matching count).
- **`useDeviceList(options)`** — The main hook. Builds a Relay `fetchKey` from a global device epoch plus `retryKey`, runs `devicesPageRelayQuery` via `useLazyLoadQuery` with a `store-and-network` fetch policy, and returns normalized devices and filtered count.

**Important behavior notes:**
- This hook **suspends** — it has no `enabled` flag. Callers must conditionally mount the consuming component inside a `Suspense` boundary (e.g., `{isOpen && <Suspense fallback={...}>...</Suspense>}`) rather than toggling an `enabled` option.
- Devices are read from the shared Relay store by `id`, so pickers always stay consistent with the Devices list and schedule tables.
- Retrying after an error requires bumping `retryKey` — simply remounting the error boundary will not force a refetch, since Relay caches thrown errors under a `forceUpdateKey-fetchKey` composite key.

## Usage Example

```typescript
import { Suspense } from 'react';
import { useDeviceList, DEVICE_LIST_LIMIT } from './use-device-list';

function DevicePickerContent({ search }: { search: string }) {
  const { devices, filteredCount } = useDeviceList({
    search,
    first: DEVICE_LIST_LIMIT,
  });

  return (
    <ul>
      {devices.map((device) => (
        <li key={device.id}>{device.hostname}</li>
      ))}
      <li>Total matches: {filteredCount}</li>
    </ul>
  );
}

function DevicePickerModal({ isOpen }: { isOpen: boolean }) {
  return (
    <>
      {isOpen && (
        <Suspense fallback={<p>Loading devices...</p>}>
          <DevicePickerContent search="" />
        </Suspense>
      )}
    </>
  );
}
```
