# use-device-logs-live-tail.ts

A React hook that polls for new device log entries at a fixed interval, implementing a "live tail" pattern that pauses when the view is not visible, not scrolled to the top, or blocked by a subscription lock.

## Key Components

- **`DEVICE_LOGS_POLL_INTERVAL_MS`** - Constant (5,000 ms) controlling the normal polling interval.
- **`DEVICE_LOGS_RETRY_INTERVAL_MS`** - Constant (30,000 ms) controlling the retry interval after a failed reload.
- **`UseDeviceLogsLiveTailOptions`** - Input interface requiring `reload` (a stable callback returning an `Observable`), `enabled`, and `atTop`.
- **`useDeviceLogsLiveTail(options)`** - The hook itself. Returns `{ failed: boolean }` indicating whether the current `reload` function is in a failed/retrying state.

The hook polls by calling `reload()` every 5 seconds, but only while all of these are true:
- `enabled` is `true`
- `atTop` is `true` (paused when scrolled away, since reloading the head would displace older pages the user is viewing)
- the subscription is unlocked (via `useSubscriptionOpen`)
- the document is visible (`document.visibilityState === 'visible'`)

On success, it reschedules at the normal interval and clears any failure state. On error, it tracks the failing `reload` reference and retries after 30 seconds. It also listens for `visibilitychange` to immediately resume polling when the tab becomes visible again, and ensures only one in-flight request exists at a time.

## Usage Example

```typescript
import { useCallback, useState } from 'react';
import { useDeviceLogsLiveTail } from './use-device-logs-live-tail';

function DeviceLogsViewer({ deviceId }: { deviceId: string }) {
  const [atTop, setAtTop] = useState(true);

  const reload = useCallback(() => {
    return fetchLatestLogsObservable(deviceId);
  }, [deviceId]);

  const { failed } = useDeviceLogsLiveTail({
    reload,
    enabled: true,
    atTop,
  });

  return (
    <div onScroll={e => setAtTop(e.currentTarget.scrollTop === 0)}>
      {failed && <div className="warning">Live updates paused — retrying…</div>}
      {/* render log list */}
    </div>
  );
}
```

**Notes:**
- `reload` must be memoized (e.g., with `useCallback`); a new reference restarts the polling timer.
- When `reload` changes (e.g., switching to a different device's log list), any prior failure state is discarded so the new list doesn't inherit a stale error banner.
- Cleanup unsubscribes any in-flight request and clears timers/listeners on unmount or when `active` becomes `false`.
