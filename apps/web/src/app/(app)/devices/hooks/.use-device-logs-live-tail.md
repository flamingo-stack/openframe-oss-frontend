# use-device-logs-live-tail.ts

A React hook that implements "live tail" polling for device logs, periodically reloading the head of a log list while the view is visible, scrolled to the top, and not blocked by a subscription lock.

## Key Components

- **`DEVICE_LOGS_POLL_INTERVAL_MS`** — Constant (5,000 ms) controlling the interval between successful polls.
- **`DEVICE_LOGS_RETRY_INTERVAL_MS`** — Constant (30,000 ms) controlling the backoff delay after a failed poll.
- **`UseDeviceLogsLiveTailOptions`** — Input options interface:
  - `reload`: a stable callback returning an `Observable` that re-fetches the head of the list.
  - `enabled`: whether live tail should be active.
  - `atTop`: whether the user is scrolled to the top of the list (polling pauses otherwise to avoid disrupting pagination).
- **`useDeviceLogsLiveTail(options)`** — The main hook. Returns `{ failed: boolean }` indicating whether the current `reload` function is in a failed/retry state.

## Behavior Notes

- Polling only runs when `enabled && atTop && subscriptionOpen` (subscription lock state comes from `useSubscriptionOpen`).
- Only one in-flight request is allowed at a time; a new tick is skipped if a request is already pending.
- Polling pauses when the document is hidden (`visibilitychange`) and resumes immediately when it becomes visible again.
- On success, the poll reschedules after `DEVICE_LOGS_POLL_INTERVAL_MS`; on error, it reschedules after `DEVICE_LOGS_RETRY_INTERVAL_MS` and marks `failed` as `true` for that specific `reload` reference.
- Changing the `reload` reference (e.g., switching lists) restarts the timer and clears any prior failure state.

## Usage Example

```typescript
import { useDeviceLogsLiveTail } from './use-device-logs-live-tail';
import { useCallback } from 'react';

function DeviceLogsPanel({ deviceId, atTop }: { deviceId: string; atTop: boolean }) {
  const reload = useCallback(() => fetchLatestLogsObservable(deviceId), [deviceId]);

  const { failed } = useDeviceLogsLiveTail({
    reload,
    enabled: true,
    atTop,
  });

  return (
    <div>
      {failed && <span>Live tail paused — retrying…</span>}
      {/* render log list */}
    </div>
  );
}
```
