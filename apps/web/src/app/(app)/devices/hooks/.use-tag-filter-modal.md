Custom hook that manages the state and logic for a tag-based device filter modal, coordinating column filters and tag filters into a single batched `setParams` call.

## Key Components

### `isCompleteTag(tag: string): boolean`
Internal helper that validates a tag string contains a key-value separator (`:`) at a non-boundary position.

### `useTagFilterModal(params)`
Primary hook export. Accepts:
- `tags` — currently selected tag strings
- `deviceFilters` — available filter metadata including tag keys
- `columns` — column definitions with optional `filterable` and `filterOptions`
- `setParams` — callback to apply the final combined filter state

**Returns:**

| Property | Type | Description |
|---|---|---|
| `isOpen` / `open` / `close` | `boolean` / `() => void` | Modal visibility controls |
| `isMdUp` | `boolean` | Breakpoint flag; hides column filter groups on desktop |
| `filterGroups` | `array` | Filterable column groups for the modal (mobile only) |
| `tagFilterKeys` | `array` | Grouped tag key/value options derived from `deviceFilters` |
| `handleFilterChange` | `function` | Buffers column filter changes before flush |
| `handleTagsChange` | `function` | Flushes buffered column filters + tags in one `setParams` call |
| `selectedTags` | `string[]` | Passthrough of current `tags` |

## Usage Example

```typescript
const {
  isOpen,
  open,
  close,
  filterGroups,
  tagFilterKeys,
  handleFilterChange,
  handleTagsChange,
  selectedTags,
} = useTagFilterModal({
  tags: activeTagFilters,
  deviceFilters,
  columns: tableColumns,
  setParams: updateQueryParams,
});

return (
  <FilterModal
    open={isOpen}
    onClose={close}
    filterGroups={filterGroups}
    tagGroups={tagFilterKeys}
    selectedTags={selectedTags}
    onFilterChange={handleFilterChange}
    onTagsChange={handleTagsChange}
  />
);
```

> **Note:** `handleFilterChange` and `handleTagsChange` are designed to be called in sequence by `FilterModal`. Column filters are buffered via a `useRef` to avoid a double `setParams` call, then flushed atomically when tags are committed.
