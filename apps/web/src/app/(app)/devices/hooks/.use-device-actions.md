# use-device-actions.ts

A React hook that encapsulates device mutation actions—remote uninstall (delete) and display name updates—combining REST API calls, GraphQL/Relay mutations, and cache invalidation with built-in toast notifications and loading state.

## Key Components

- **`useDeviceActions(options?)`** — Main hook accepting an optional `onSuccess` callback invoked after successful mutations.
- **`deleteDevice(deviceId, deviceName?)`** — Triggers a remote device uninstall via REST (`POST /api/force/client/uninstall`). Marks the device `PENDING_DELETION`; the agent uninstalls on next check-in, after which the device moves to a read-only archived `DELETED` record. This is irreversible—restoring the machine requires reinstalling the agent.
- **`updateNickname(deviceId, nickname)`** — Updates a device's display name via the `updateDeviceNicknameMutation` GraphQL mutation (Relay). Trims input and sends `null` when empty to clear the nickname.
- **`isDeleting`** / **`isSavingNickname`** / **`isProcessing`** — Loading state flags for UI feedback; `isProcessing` is `true` if either action is in flight.
- **`invalidateDevices`** — Internal callback wrapping `invalidateDeviceQueries` to refresh all react-query device caches (lists, pickers, detail views, counters) after a mutation.

## Usage Example

```typescript
import { useDeviceActions } from '@/hooks/use-device-actions';

function DeviceActionsMenu({ deviceId, deviceName }: { deviceId: string; deviceName: string }) {
  const { deleteDevice, updateNickname, isProcessing } = useDeviceActions({
    onSuccess: () => console.log('Action completed'),
  });

  const handleDelete = async () => {
    const success = await deleteDevice(deviceId, deviceName);
    if (success) {
      // navigate away or close dialog
    }
  };

  const handleRename = async (newName: string) => {
    await updateNickname(deviceId, newName);
  };

  return (
    <button disabled={isProcessing} onClick={handleDelete}>
      Delete Device
    </button>
  );
}
```

**Notes:**
- Relay mutations update the normalized store directly (since `Machine` is a GraphQL `Node`), so Relay-fed UI re-renders automatically; `invalidateDevices` additionally refreshes react-query–backed surfaces.
- Both actions return a `Promise<boolean>` indicating success, making them easy to chain with UI state (e.g., closing modals only on success).
