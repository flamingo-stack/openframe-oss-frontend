# use-device-actions.ts

A client-side React hook that encapsulates mutation actions for devices — scheduling remote uninstalls and updating device display names (nicknames) — with toast notifications and cache invalidation across both react-query and Relay-backed surfaces.

## Key Components

- **`useDeviceActions(options?)`** — Main hook factory accepting an optional `onSuccess` callback invoked after successful mutations.
- **`deleteDevice(deviceId, deviceName?)`** — Async function that calls the `/api/force/client/uninstall` REST endpoint to schedule a remote agent uninstall. The device transitions to `PENDING_DELETION` and later becomes a read-only `DELETED` archive record once the agent processes it. Returns `boolean` success status and shows success/error toasts.
- **`updateNickname(deviceId, nickname)`** — Async function wrapping a GraphQL Relay mutation (`updateDeviceNicknameMutation`) to rename a device. Trims whitespace and clears the nickname if empty. Returns a `Promise<boolean>`.
- **`isDeleting`** — Boolean state flag for in-flight delete operations.
- **`isSavingNickname`** — Boolean flag (from `useMutation`) for in-flight nickname updates.
- **`isProcessing`** — Combined flag (`isDeleting || isSavingNickname`) useful for disabling UI controls during any pending action.

## Usage Example

```typescript
import { useDeviceActions } from './use-device-actions';

function DeviceRow({ device }: { device: { id: string; name: string } }) {
  const { deleteDevice, updateNickname, isProcessing } = useDeviceActions({
    onSuccess: () => console.log('Device action completed'),
  });

  const handleDelete = async () => {
    const success = await deleteDevice(device.id, device.name);
    if (success) {
      // Device list/UI auto-refreshes via query invalidation
    }
  };

  const handleRename = async (newName: string) => {
    await updateNickname(device.id, newName);
  };

  return (
    <div>
      <button disabled={isProcessing} onClick={handleDelete}>
        Delete Device
      </button>
      <button disabled={isProcessing} onClick={() => handleRename('Office PC')}>
        Rename
      </button>
    </div>
  );
}
```

**Notes:**
- `deleteDevice` triggers a graceful remote uninstall, not an immediate hard delete — the device remains visible until the agent completes uninstallation.
- `updateNickname` updates the Relay store directly (since `Machine` is a Node), so Relay-driven views refresh automatically; `invalidateDeviceQueries` additionally refreshes react-query-backed views (detail pages, fleet lists, counters).
