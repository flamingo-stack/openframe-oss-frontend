## Overview

`useMeshFileManager` is a React hook that provides a stateful, high-level interface for browsing, uploading, downloading, and manipulating files on a remote MeshCentral agent via a WebSocket-based file manager connection. It manages connection lifecycle, directory navigation, file transfer progress, search, and clipboard (copy/cut/paste) operations.

## Key Components

- **`useMeshFileManager(options)`** — Main hook accepting `meshcentralAgentId`, `isRemote`, and `onError`, returning file manager state and action handlers.
- **State exposed**: `files`, `currentPath`, `selectedFiles`, `connectionState`, `loading`, `isSearching`, `uploadProgress`, `downloadProgress`, `clipboard`.
- **Navigation actions**: `navigateToPath`, `navigateUp`, `navigateInto`.
- **File operations**: `createFolder`, `deleteItems`, `renameItem`, `uploadFile`, `downloadFile`, `cancelDownload`, `cancelUpload`, `copyFiles`, `moveFiles`.
- **Search**: `searchFiles`, `cancelSearch`, `isSearchActive`.
- **Clipboard**: `copyToClipboard`, `cutFiles`, `pasteFiles`, `clearClipboard`.
- **Selection**: `selectFile`, `selectAll`.
- **Generic dispatcher**: `handleFileAction` for `FileAction`-based UI event handling.
- **Connection management**: `retryConnection` to re-establish a failed connection; guards against duplicate connections via a module-level `activeFileManagers` map (React Strict Mode safe) and a `CONNECT_TIMEOUT_MS` (15s) connection timeout.
- **Helpers**: `getDirectoryFromFileIds` (internal), uses `convertFileEntriesToItems` and `sanitizePath` from `file-manager-utils`.

## Usage Example

```typescript
import { useMeshFileManager } from './use-mesh-file-manager';

function RemoteFileBrowser({ agentId }: { agentId: string }) {
  const {
    files,
    currentPath,
    connectionState,
    loading,
    navigateInto,
    navigateUp,
    deleteItems,
    uploadFile,
    retryConnection,
  } = useMeshFileManager({
    meshcentralAgentId: agentId,
    isRemote: true,
    onError: (err) => console.error('File manager error:', err),
  });

  if (connectionState === 'failed') {
    return <button onClick={retryConnection}>Retry Connection</button>;
  }

  return (
    <div>
      <p>Path: {currentPath}</p>
      {loading ? (
        <span>Connecting...</span>
      ) : (
        <ul>
          {files.map(file => (
            <li key={file.id} onDoubleClick={() => navigateInto(file.name)}>
              {file.name}
            </li>
          ))}
        </ul>
      )}
      <button onClick={navigateUp}>Up</button>
    </div>
  );
}
```

Underlying connection lifecycle is tied to `meshcentralAgentId`/`isRemote` changes; the hook automatically cleans up `MeshCentralFileManager` and `MeshControlClient` instances on unmount or dependency change.
