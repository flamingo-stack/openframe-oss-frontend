## use-mesh-file-manager.ts

A React hook that manages a MeshCentral-backed remote file manager connection, wrapping `MeshCentralFileManager` and `MeshControlClient` to expose file browsing, transfer, clipboard, and search operations against a remote device's file system.

## Key Components

- **`useMeshFileManager(options)`** — Main hook accepting `meshcentralAgentId`, `isRemote`, and an `onError` callback; returns file listing state, connection status, transfer progress, and a full set of file operation actions.
- **`UseMeshFileManagerOptions` / `UseMeshFileManagerReturn`** — TypeScript interfaces defining the hook's input configuration and output API surface (state + actions).
- **Connection lifecycle management** — Establishes a `MeshControlClient` and `MeshCentralFileManager` inside a `useEffect`, with a `CONNECT_TIMEOUT_MS` (15s) race against `fileManager.connect()`, cancellation tokens (`initTokenRef`) to guard against stale/React Strict Mode double-invocations, and an `activeFileManagers` map keyed by device ID to prevent duplicate connections.
- **State exposed**: `files`, `currentPath`, `selectedFiles`, `connectionState`, `loading`, `isSearching`, `uploadProgress`, `downloadProgress`, `clipboard`.
- **Actions exposed**: navigation (`navigateToPath`, `navigateUp`, `navigateInto`), CRUD (`createFolder`, `deleteItems`, `renameItem`), transfers (`uploadFile`, `downloadFile`, `cancelUpload`, `cancelDownload`), bulk operations (`copyFiles`, `moveFiles`), search (`searchFiles`, `cancelSearch`), clipboard (`copyToClipboard`, `cutFiles`, `pasteFiles`, `clearClipboard`), selection (`selectFile`, `selectAll`), a generic `handleFileAction` dispatcher, and `retryConnection` for re-establishing a failed connection.
- **`retryConnection`** — Increments an internal `connectAttempt` counter to force the connection effect to re-run with a fresh client.
- **`refreshCurrentDirectory`** — Internal helper that reloads the current directory listing from the connected file manager.

## Usage Example

```typescript
import { useMeshFileManager } from './use-mesh-file-manager';

function RemoteFileExplorer({ agentId }: { agentId: string }) {
  const {
    files,
    currentPath,
    connectionState,
    loading,
    navigateInto,
    navigateUp,
    uploadFile,
    downloadFile,
    deleteItems,
    retryConnection,
  } = useMeshFileManager({
    meshcentralAgentId: agentId,
    isRemote: true,
    onError: err => console.error('File manager error:', err),
  });

  if (connectionState === 'failed') {
    return <button onClick={retryConnection}>Retry Connection</button>;
  }

  return (
    <div>
      <p>Path: {currentPath}</p>
      {loading ? (
        <span>Loading...</span>
      ) : (
        files.map(file => (
          <div key={file.id} onDoubleClick={() => navigateInto(file.name)}>
            {file.name}
          </div>
        ))
      )}
    </div>
  );
}
```
