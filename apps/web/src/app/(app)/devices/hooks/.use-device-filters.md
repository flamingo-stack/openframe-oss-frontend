# use-device-filters.ts

A React hook that fetches filter facets (status, device type, OS, customer, tags) with counts for the device list toolbar, using Relay for data fetching with automatic refresh on mutations and retries.

## Key Components

- **`useDeviceFilters(filters?: DeviceFilterInput): DeviceFilters`** — Main hook that loads and returns filter facet data for the devices view.
- **Suspense behavior** — This hook suspends during data fetching. It must be rendered inside the same Suspense boundary as the device list it filters, since mismatched facet counts and rows produce a confusing UI. It should have its own error boundary (independent from the device table) so a failed filter fetch doesn't take down the whole table.
- **Fetch key composition** — Combines `useDeviceEpoch()` (bumped on device mutations) and `useRetryKey()` (bumped on error boundary retry) into a single `fetchKey`, forcing Relay to refetch an already-mounted query when either changes.
- **Memoization** — Converts Relay's readonly arrays into mutable arrays (required by the `DeviceFilters` consumer contract) and memoizes the result on `data.deviceFilters` to avoid needless re-renders of filter UI and table column definitions.

## Usage Example

```typescript
'use client';

import { Suspense } from 'react';
import { useDeviceFilters } from '@/app/hooks/use-device-filters';

function DeviceFilterToolbar({ filters }: { filters?: DeviceFilterInput }) {
  const deviceFilters = useDeviceFilters(filters);

  return (
    <div>
      <span>Matching devices: {deviceFilters.filteredCount}</span>
      {/* Render status/type/OS/tag filter controls from deviceFilters */}
    </div>
  );
}

export function DevicesPanel({ filters }: { filters?: DeviceFilterInput }) {
  return (
    // Filters and the device table share one Suspense boundary so loading
    // states stay in sync; the filter toolbar has its own error boundary
    // so a failed facet query doesn't break the table.
    <Suspense fallback={<ToolbarSkeleton />}>
      <DeviceFilterToolbar filters={filters} />
    </Suspense>
  );
}
```

Note: this hook depends on `useDeviceEpoch` and `useRetryKey`, and must be used within a component tree wrapped by the relevant Relay and Suspense providers.
