Filter facets — the status / device-type / OS / customer / tag options the device filter UI offers, each with a count, narrowed by the filter already applied.

## `useDeviceFilters(filters?)`

A Relay `useLazyLoadQuery` over `deviceFiltersRelayQuery` (`store-and-network`). Returns `DeviceFilters` directly — no `data` wrapper, no query key, no `staleTime`.

**Suspends.** Render it inside the same boundary as the device list it narrows: the toolbar and the table are one unit, and facet counts that don't match the rows below them are worse than neither. It also re-suspends when `filters` changes, so callers that must keep the current view on screen pass a DEFERRED filter (see `DevicesPanel` and `schedule-picker-lists.tsx`, both via `useDeferredQuery`).

Relay hands back readonly arrays; the hook copies them into the mutable `DeviceFilters` the table and filter-modal helpers consume.

## Usage Example

```typescript
const deviceFilters = useDeviceFilters(deferredFilters);
const columns = getDeviceFilterColumns(deviceFilters);
```
