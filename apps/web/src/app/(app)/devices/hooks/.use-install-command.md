## use-install-command.ts

A React hook that builds the shell commands (and native-shell install request) used to enroll a new agent device, handling server-URL resolution across web and app-shell contexts, SSR/hydration safety, and per-visit machine identification for download tracking.

## Key Components

- **`useInstallCommand(options)`** — Main hook returning `{ command, registerCommand, initialKey, installRequest, rotateMachineId }` for a given organization, platform, tags, and remote access mode.
- **`buildTagArgs(tags, platform)`** — Converts tag entries into `--tag` CLI arguments, quoting style adapted per OS.
- **`withLocalMode(host)`** — Appends `--localMode` when the resolved host is the developer's own machine (`localhost`/`127.0.0.1`).
- **`tenantGatewayHost()`** — Resolves the tenant gateway host from runtime config, used when running inside a native app shell.
- **`currentServerUrl()`** — Determines the correct server host the agent should call home to, differing between browser tabs and native shells (Capacitor/Tauri).
- **SSR-safe snapshot functions** (`getServerSnapshot`, `getServerDownloadBaseSnapshot`, `getClientHydratedSnapshot`, `getServerHydratedSnapshot`) — Used with `useSyncExternalStore` to avoid hydration mismatches since `window` is unavailable during prerendering.

## Usage Example

```typescript
import { useInstallCommand } from './use-install-command';

function InstallInstructions({ orgId, platform, tags, remoteAccessMode }) {
  const { command, registerCommand, installRequest, rotateMachineId } = useInstallCommand({
    organizationId: orgId,
    platform,
    tags,
    remoteAccessMode,
  });

  const handleCopy = async () => {
    await navigator.clipboard.writeText(command);
    rotateMachineId(); // ensure next copy gets a fresh download machine id
  };

  return (
    <div>
      <pre>{command}</pre>
      <button onClick={handleCopy}>Copy Install Command</button>
      {/* registerCommand used for package-manager step 2 */}
      {/* installRequest passed to native shell for local installs */}
    </div>
  );
}
```

Notes:
- The hook depends on `useRegistrationSecret`, `useAgentLogKey`, and `useAuthStore` for credentials and user context.
- `machineId` starts empty until hydration completes, ensuring server and client render the same initial command.
- Call `rotateMachineId()` after each copy to prevent download collisions between multiple enrolled devices from the same tab.
