## Purpose

React hook that builds the shell command (and related metadata) a user copies to install the OpenFrame agent on a device, computing the correct server URL, download base, registration secret, and tag/remote-access flags across web and native shell (Capacitor/Tauri) contexts while remaining SSR-hydration safe.

## Key Components

- **`useInstallCommand(options)`** — Main hook; accepts `organizationId`, `platform`, optional `tags`, and `remoteAccessMode`. Returns `{ command, registerCommand, initialKey, installRequest, rotateMachineId }`.
- **`currentServerUrl()`** — Resolves the host the agent should call home to, branching on native app shell vs. browser `window.location`.
- **`withLocalMode(host)`** — Appends `--localMode` when the resolved host is `localhost`/`127.0.0.1`.
- **`tenantGatewayHost()`** — Extracts the host from the configured tenant gateway URL.
- **`buildTagArgs(tags, platform)`** — Converts `TagEntry[]` into platform-appropriate `--tag` CLI arguments (quoting differs for Windows).
- **`subscribe`, `getServerSnapshot`, `getServerDownloadBaseSnapshot`, `getClientHydratedSnapshot`, `getServerHydratedSnapshot`** — Support functions for `useSyncExternalStore`, ensuring SSR/client hydration consistency for `window`-dependent values.

## Usage Example

```typescript
import { useInstallCommand } from './use-install-command';

function InstallCommandPanel({ organizationId, platform, tags, remoteAccessMode }) {
  const { command, registerCommand, installRequest, rotateMachineId } = useInstallCommand({
    organizationId,
    platform,
    tags,
    remoteAccessMode,
  });

  const handleCopy = async () => {
    await navigator.clipboard.writeText(command);
    rotateMachineId(); // ensure next copy gets a fresh download machine id
  };

  return (
    <div>
      <pre>{command}</pre>
      <button onClick={handleCopy}>Copy Install Command</button>
      <pre>{registerCommand}</pre>
    </div>
  );
}
```

The `installRequest` value is passed to the native desktop shell (via `AgentInstallRequest`) when installation happens locally instead of through a copied shell command.
