A React hook that implements infinite scroll behavior for grid layouts using the Intersection Observer API, triggering data fetches when a sentinel element scrolls into view.

## Key Components

- **`useGridInfiniteScroll`** - Custom hook that accepts pagination state and a fetch callback, returning a ref to attach to a sentinel DOM element.
- **`UseGridInfiniteScrollParams`** - Interface defining the hook's input parameters:
  - `enabled`: toggles whether the observer is active
  - `hasNextPage`: indicates if more data is available to load
  - `isFetchingNextPage`: prevents duplicate fetch calls while a request is in flight
  - `fetchNextPage`: callback invoked to load the next page of data
- **`sentinelRef`** - Returned ref object to be attached to an invisible element at the end of the grid, used to detect when the user has scrolled near the bottom.

The hook uses a 200px `rootMargin` so the fetch triggers slightly before the sentinel is fully visible, providing a smoother loading experience.

## Usage Example

```typescript
import { useGridInfiniteScroll } from './use-grid-infinite-scroll';

function DeviceGrid() {
  const { data, hasNextPage, isFetchingNextPage, fetchNextPage } = useInfiniteDevicesQuery();

  const sentinelRef = useGridInfiniteScroll({
    enabled: true,
    hasNextPage: hasNextPage ?? false,
    isFetchingNextPage,
    fetchNextPage,
  });

  return (
    <div className="grid grid-cols-3 gap-4">
      {data?.pages.flatMap(page => page.items).map(device => (
        <DeviceCard key={device.id} device={device} />
      ))}
      <div ref={sentinelRef} className="h-1" />
      {isFetchingNextPage && <Spinner />}
    </div>
  );
}
```
