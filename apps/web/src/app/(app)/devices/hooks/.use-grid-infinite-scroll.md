A React hook that implements infinite scroll for grid layouts using the `IntersectionObserver` API, triggering pagination fetches when a sentinel element becomes visible in the viewport.

## Key Components

- **`useGridInfiniteScroll(params)`** — Custom hook that returns a ref to attach to a sentinel DOM element. It observes the sentinel's visibility and calls `fetchNextPage` when it scrolls into view (with a 200px root margin for early triggering).
- **`UseGridInfiniteScrollParams`** — Interface defining the hook's input:
  - `enabled: boolean` — Toggles whether the observer should be active.
  - `hasNextPage: boolean` — Indicates if more pages are available to fetch.
  - `isFetchingNextPage: boolean` — Prevents duplicate fetches while a request is in flight.
  - `fetchNextPage: () => void` — Callback to load the next page of data.

## Usage Example

```typescript
import { useGridInfiniteScroll } from './use-grid-infinite-scroll';

function DeviceGrid() {
  const {
    data,
    fetchNextPage,
    hasNextPage,
    isFetchingNextPage,
  } = useInfiniteQuery(/* ... */);

  const sentinelRef = useGridInfiniteScroll({
    enabled: true,
    hasNextPage: hasNextPage ?? false,
    isFetchingNextPage,
    fetchNextPage,
  });

  return (
    <div className="grid">
      {data?.pages.map(page =>
        page.items.map(item => <GridItem key={item.id} item={item} />),
      )}
      <div ref={sentinelRef} />
      {isFetchingNextPage && <Spinner />}
    </div>
  );
}
```

The hook cleans up the observer automatically when dependencies change or the component unmounts, preventing memory leaks and redundant fetch calls.
