Fetches and manages the active agent registration secret from the API, providing loading and error state with toast notifications on failure.

## Key Components

- **`useRegistrationSecret`** — Custom React hook that auto-fetches the active registration secret on mount via `GET /api/agent/registration-secret/active`

### Returned Values

| Property | Type | Description |
|---|---|---|
| `initialKey` | `string` | The active registration secret key |
| `isLoading` | `boolean` | Fetch in-progress indicator |
| `error` | `string \| null` | Error message if the fetch failed |
| `refetch` | `() => Promise<void>` | Manually re-trigger the secret fetch |

## Usage Example

```typescript
import { useRegistrationSecret } from './use-registration-secret';

function AgentRegistrationPanel() {
  const { initialKey, isLoading, error, refetch } = useRegistrationSecret();

  if (isLoading) return <Spinner />;
  if (error) return <button onClick={refetch}>Retry</button>;

  return <SecretDisplay value={initialKey} />;
}
```

## Notes

- Automatically fetches on mount via `useEffect`
- Displays a destructive toast notification on fetch failure using `useToast`
- `fetchActiveSecret` is memoized with `useCallback` to prevent unnecessary re-renders
- Requires the `apiClient` instance from `@/lib/api-client` and a configured `/api/agent/registration-secret/active` endpoint
