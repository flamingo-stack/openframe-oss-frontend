A React hook that fetches and manages the active agent registration secret key, auto-loading it on mount and exposing loading/error state along with a manual refetch capability.

## Key Components

- **`useRegistrationSecret()`** - Custom hook that retrieves the active registration secret from the `/api/agent/registration-secret/active` endpoint.
- **`initialKey`** - The fetched registration secret string (empty string until loaded).
- **`isLoading`** - Boolean flag indicating an in-flight fetch request.
- **`error`** - String message describing the last fetch failure, or `null` if none.
- **`refetch`** - Callback to manually re-trigger fetching the active secret.

## Usage Example

```typescript
import { useRegistrationSecret } from '@/hooks/use-registration-secret';

function RegistrationSecretPanel() {
  const { initialKey, isLoading, error, refetch } = useRegistrationSecret();

  if (isLoading) {
    return <p>Loading registration secret...</p>;
  }

  if (error) {
    return (
      <div>
        <p>Error: {error}</p>
        <button onClick={refetch}>Retry</button>
      </div>
    );
  }

  return (
    <div>
      <code>{initialKey}</code>
      <button onClick={refetch}>Refresh</button>
    </div>
  );
}
```

The hook automatically fetches the secret when the component mounts. On failure, it surfaces a toast notification via `useToast` from `@flamingo-stack/openframe-frontend-core/hooks` and sets the `error` state, allowing consumers to handle retries through the `refetch` function.
