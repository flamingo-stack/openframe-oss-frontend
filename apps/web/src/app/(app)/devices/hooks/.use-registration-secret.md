A React hook that fetches and manages the active agent registration secret key, auto-loading it on mount and exposing loading/error state along with a manual refetch function.

## Key Components

- **`useRegistrationSecret()`** — Custom hook that:
  - `initialKey: string` — the fetched registration secret key (empty string until loaded)
  - `isLoading: boolean` — indicates whether a fetch is in progress
  - `error: string | null` — holds an error message if the fetch fails
  - `refetch: () => Promise<void>` — manually re-triggers the fetch (same function used on mount)
- **`fetchActiveSecret`** — Internal `useCallback` that calls `GET /api/agent/registration-secret/active` via `apiClient`, validates the response, and updates state. On failure, it sets an error message and displays a destructive toast notification via `useToast`.

## Usage Example

```typescript
'use client';

import { useRegistrationSecret } from '@/hooks/use-registration-secret';

export function RegistrationSecretPanel() {
  const { initialKey, isLoading, error, refetch } = useRegistrationSecret();

  if (isLoading) return <p>Loading registration secret...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <div>
      <p>Current secret: {initialKey}</p>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}
```

**Notes:**
- Requires the component to be a client component (`'use client'`) since it uses React hooks and the `useToast` hook from `@flamingo-stack/openframe-frontend-core/hooks`.
- Depends on `apiClient` (from `@/lib/api-client`) for authenticated/configured API requests.
- Automatically fetches the secret on mount; call `refetch()` to reload after an update (e.g., regenerating the secret).
