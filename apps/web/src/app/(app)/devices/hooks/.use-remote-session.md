# use-remote-session.ts

React hook that manages the full lifecycle of a remote access session tied to an approved request: locating the backend session record, tracking live viewer presence and status via NATS push events, polling as a fallback, and ending the session when the technician leaves the page.

## Key Components

- **`useRemoteSession(deviceId, requestId)`** - Main hook. Returns `{ session, ended, endSession }`.
- **`UseRemoteSessionResult`** - Return type interface:
  - `session`: the current `RemoteSession | null`
  - `ended`: `RemoteSessionEnd | null`, set once by push, poll, or local end
  - `endSession()`: ends the session locally and notifies the backend (idempotent)
- **Lookup loop**: retries `remoteSessionApiService.active(deviceId)` up to `LOOKUP_ATTEMPTS` (5) times at `LOOKUP_RETRY_MS` (1s) intervals until the session record appears (covers the race right after approval).
- **NATS subscription**: listens on `user.{userId}.notification` for viewer-presence updates and `REMOTE_SESSION_ENDED`/other session events via `parseWatchEvent` and `parseRemoteSessionEvent`.
- **Poll fallback**: every `POLL_MS` (5s) while the session is active, re-fetches the session via `remoteSessionApiService.get` to catch any missed push.
- **Page-leave handling**: `pagehide` listener (tab close/reload) calls `remoteSessionApiService.endOnUnload`; component unmount (in-app navigation) defers to `endSession()` via a zero-delay timeout, guarding against React StrictMode's double-invoke in development.

## Usage Example

```typescript
import { useRemoteSession } from '../hooks/use-remote-session';

function RemoteSessionView({ deviceId, requestId }: { deviceId: string; requestId: string | null }) {
  const { session, ended, endSession } = useRemoteSession(deviceId, requestId);

  if (ended) {
    return <div>Session ended: {ended.endReason}</div>;
  }

  if (!session) {
    return <div>Locating session...</div>;
  }

  return (
    <div>
      <p>Status: {session.status}</p>
      <p>Viewers: {session.viewers.map(v => v.name).join(', ')}</p>
      <button onClick={endSession}>End Session</button>
    </div>
  );
}
```

Pass `requestId` as `null` to disable the hook (e.g., before a request is approved); it becomes active once a non-null `requestId` is supplied.
