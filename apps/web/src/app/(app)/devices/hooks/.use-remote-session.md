# use-remote-session.ts

A React hook that manages the full lifecycle of a remote access session: locating the backend session created after request approval, tracking live viewer/status updates via NATS push and polling fallback, and ensuring the session is properly ended when the technician leaves the page.

## Key Components

- **`UseRemoteSessionResult`** — Return type exposing `session` (current `RemoteSession | null`), `ended` (`RemoteSessionEnd | null`), and `endSession()` to manually terminate.
- **`useRemoteSession(deviceId, requestId)`** — Main hook. Returns `null` session state until found, and resolves lifecycle via:
  - **Lookup retry loop**: polls `remoteSessionApiService.active(deviceId)` up to `LOOKUP_ATTEMPTS` (5) times, `LOOKUP_RETRY_MS` (1s) apart, to find the session created right after approval.
  - **NATS push subscription**: listens on `user.{userId}.notification` subject via `useNatsJsonSubscription`, handling both viewer-list updates (`parseWatchEvent`) and session events (`parseRemoteSessionEvent`, e.g. `REMOTE_SESSION_ENDED`).
  - **Polling fallback**: every `POLL_MS` (5s) while the session is active, re-fetches session state via `remoteSessionApiService.get()` to catch missed pushes.
  - **`endSession()`**: locally marks the session ended (`endReason: 'admin'`) and notifies the backend via `remoteSessionApiService.end()`, guarded by `endedRef` to fire at most once.
  - **Unload/unmount handling**: uses `pagehide` for tab close/reload (via `endOnUnload`, a fire-and-forget beacon-style call) and a deferred unmount effect that tolerates React StrictMode's double-invoke in development.

Internal helpers `endOf`, `sameViewers`, and `sameSession` prevent redundant state updates by comparing only the fields the UI reacts to.

## Usage Example

```typescript
import { useRemoteSession } from '../hooks/use-remote-session';

function RemoteSessionPanel({ deviceId, requestId }: { deviceId: string; requestId: string | null }) {
  const { session, ended, endSession } = useRemoteSession(deviceId, requestId);

  if (ended) {
    return <div>Session ended: {ended.endReason}</div>;
  }

  if (!session) {
    return <div>Connecting to remote session…</div>;
  }

  return (
    <div>
      <p>Status: {session.status}</p>
      <p>Viewers: {session.viewers.map(v => v.name).join(', ')}</p>
      <button onClick={endSession}>End Session</button>
    </div>
  );
}
```

Pass `requestId = null` to disable the hook (e.g., before an approval exists); it becomes active once a real request ID is available.
