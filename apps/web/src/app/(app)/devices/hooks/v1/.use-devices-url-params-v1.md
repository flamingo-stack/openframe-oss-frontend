# use-devices-url-params-v1.ts

A legacy (v1) React hook that synchronizes the Devices list page's search, filter, and view-mode state with URL query parameters. It is the `tenant-management-v2`-off counterpart to the current `use-devices-url-params.ts` hook and will be removed once that feature flag is fully rolled out.

## Key Components

- **`useDevicesUrlParamsV1(options)`** — Main hook that manages URL-backed state for the devices list:
  - `options.defaultStatuses` — Optional override for the default status filter set (defaults to `DEFAULT_DEVICES_LIST_STATUSES`); pass `[]` for pages like `/devices/archive` that need all statuses with no implicit default.
  - Returns:
    - `params` — Normalized URL params (`search`, `statuses`, `osTypes`, `organizationIds`, `tags`, `viewMode`).
    - `setParam` / `setParams` — Setters for individual or multiple params (status-normalizing).
    - `localSearch`, `setLocalSearch`, `debouncedSearch` — Responsive local search state debounced into the URL.
    - `filters` — `DeviceFilterInput` shaped for the GraphQL/API query layer.
    - `tableFilters` — Filter shape consumed by the devices table's column filter UI.
    - `tagOptions` — Tag values formatted as `TagSearchOption[]` for the tag search component.
    - `handleFilterChange`, `handleTagRemove`, `handleClearAll` — Event handlers for filter UI interactions.

## Usage Example

```typescript
import { useDevicesUrlParamsV1 } from './hooks/use-devices-url-params-v1';

function DevicesPage() {
  const {
    filters,
    tableFilters,
    localSearch,
    setLocalSearch,
    handleFilterChange,
    handleClearAll,
  } = useDevicesUrlParamsV1();

  const { data } = useDevicesQuery({ filters });

  return (
    <DevicesTable
      search={localSearch}
      onSearchChange={setLocalSearch}
      columnFilters={tableFilters}
      onFilterChange={handleFilterChange}
      onClearAll={handleClearAll}
      rows={data?.devices}
    />
  );
}
```
