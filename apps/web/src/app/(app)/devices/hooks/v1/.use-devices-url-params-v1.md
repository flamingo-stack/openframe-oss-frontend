## Purpose

A legacy (v1) hook for managing devices-list URL params—search, status/OS/organization/tag filters, and view mode—synchronized with the URL query string. It is the version rendered while the `tenant-management-v2` feature flag is off, and will be deleted once the flag is removed. It normalizes "default" status selections to keep URLs clean and provides derived filter objects for both GraphQL queries and table UI filtering.

## Key Components

- **`useDevicesUrlParamsV1(options)`** — Main hook, accepts optional `defaultStatuses` (defaults to `DEFAULT_DEVICES_LIST_STATUSES`; pass `[]` to disable default-status fallback, e.g. for an archive view).
- **`normalizeStatuses`** — Collapses a status selection matching the default set exactly to `[]`, so the URL omits `statuses` when it's effectively "no filter."
- **`effectiveStatuses`** — Status list actually sent to the API: explicit selection, or falls back to `defaultStatuses` when empty.
- **`filters`** (`DeviceFilterInput`) — GraphQL-ready filter object (statuses, osTypes, organizationIds, tagValues).
- **`tableFilters`** — UI-facing filter shape used to drive table column filter components.
- **`tagOptions`** — Tag chips derived from URL `tags` param, for display/removal.
- **`handleFilterChange`, `handleTagRemove`, `handleClearAll`** — Callbacks to update filters, remove a tag, or reset search/tags.
- **`localSearch` / `debouncedSearch`** — Responsive local search input decoupled from debounced URL sync.

## Usage Example

```typescript
import { useDevicesUrlParamsV1 } from './use-devices-url-params-v1';

function DevicesPage() {
  const {
    localSearch,
    setLocalSearch,
    filters,
    tableFilters,
    tagOptions,
    handleFilterChange,
    handleTagRemove,
    handleClearAll,
  } = useDevicesUrlParamsV1();

  // Use `filters` to query devices via GraphQL
  const { data } = useDevicesQuery({ variables: { filters } });

  return (
    <DevicesTable
      searchValue={localSearch}
      onSearchChange={setLocalSearch}
      columnFilters={tableFilters}
      onFilterChange={handleFilterChange}
      tags={tagOptions}
      onTagRemove={handleTagRemove}
      onClearAll={handleClearAll}
      data={data}
    />
  );
}

// Archive page: disable default status fallback, show all statuses
function ArchivePage() {
  const { filters } = useDevicesUrlParamsV1({ defaultStatuses: [] });
}
```
