# use-devices-v1.ts

A Relay-powered hook that fetches and paginates the device list used by the Devices page, customer devices tab, and archive page. This is the legacy (v1) implementation rendered only when the `tenant-management-v2` feature flag is off, and will be removed once that flag is retired.

## Key Components

- **`useDevicesV1(filters?, search?)`** — Main hook that loads a paginated, filterable list of devices via Relay, returning normalized `Machine`-based `Device` records.
- **`UseDevicesResultV1`** — Return type interface exposing `devices`, `filteredCount`, `hasNextPage`, `isFetchingNextPage`, and `fetchNextPage`.

### Behavior notes

- **Suspends** on initial load and whenever `filters`/`search` change. Consumers must wrap usage in `<Suspense>`. To avoid flashing the fallback on filter changes, defer the `filters`/`search` values before passing them in (see `DevicesPanel`).
- Uses `useLazyLoadQuery` combined with `usePaginationFragment` so Relay manages cursors and page merging instead of manual infinite-query logic.
- Subscribes to `useDeviceEpoch()` as a `fetchKey` so mutations elsewhere in the app (which bump the epoch) trigger a refetch of this already-mounted query.
- **Known limitation:** refetching after a mutation restarts pagination from the head (`after: null`), so a scrolled user is reset to the first page. A proper fix requires a `ConnectionHandler` updater tied to a Relay mutation, but the device delete call currently uses REST (`apiClient.post`), so this needs the delete mutation to move to Relay first.

## Usage Example

```typescript
import { Suspense, useDeferredValue, useState } from 'react';
import { useDevicesV1 } from './use-devices-v1';

function DevicesPanel() {
  const [filters, setFilters] = useState<DeviceFilterInput>();
  const [search, setSearch] = useState('');

  // Defer so filter/search changes become transitions, keeping the
  // previous list visible instead of dropping to the Suspense fallback.
  const deferredFilters = useDeferredValue(filters);
  const deferredSearch = useDeferredValue(search);

  return (
    <Suspense fallback={<DevicesListSkeleton />}>
      <DevicesList filters={deferredFilters} search={deferredSearch} />
    </Suspense>
  );
}

function DevicesList({ filters, search }: { filters?: DeviceFilterInput; search: string }) {
  const { devices, filteredCount, hasNextPage, isFetchingNextPage, fetchNextPage } =
    useDevicesV1(filters, search);

  return (
    <div>
      <p>{filteredCount} devices found</p>
      {devices.map((device) => (
        <DeviceRow key={device.id} device={device} />
      ))}
      {hasNextPage && (
        <button onClick={fetchNextPage} disabled={isFetchingNextPage}>
          {isFetchingNextPage ? 'Loading…' : 'Load more'}
        </button>
      )}
    </div>
  );
}
```
