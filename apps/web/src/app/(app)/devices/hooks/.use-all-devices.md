A React hook that fetches the *entire* set of devices matching a filter (exhausting pagination), intended for lookup-style consumption such as monitoring tables keyed by Fleet host id, rather than paged UI lists.

## Key Components

- **`UseAllDevicesOptions`** — Input options interface: optional `filter` (`DeviceFilterInput`) and `enabled` flag to control query execution.
- **`useAllDevices(options)`** — React Query-backed hook that walks all pages of `fetchAllDevices` and returns the full device collection as a flat array, along with loading/error state and a `refetch` function.
- **`EMPTY_DEVICES`** — Stable empty array constant used as a fallback to avoid unnecessary re-renders when no data is loaded yet.

Internally, it uses `useQuery` from `@tanstack/react-query` with a cache key generated by `deviceQueryKeys.full(filter)` and a 30-second `staleTime`. Note that although the underlying `fetchAllDevices` call executes a Relay GraphQL document (populating the Relay normalized store with `Machine` records), the exhaustive pagination loop and caching here are managed by React Query, not Relay's `usePaginationFragment`.

## Usage Example

```typescript
import { useAllDevices } from './use-all-devices';

function DeviceLookupTable() {
  const { devices, isLoading, error, refetch } = useAllDevices({
    filter: { status: 'online' },
  });

  if (isLoading) return <p>Loading devices...</p>;
  if (error) return <p>Error: {error}</p>;

  const devicesByFleetId = new Map(devices.map((d) => [d.fleetHostId, d]));

  return (
    <div>
      <button onClick={() => refetch()}>Refresh</button>
      <p>{devicesByFleetId.size} devices loaded</p>
    </div>
  );
}
```

Pass `enabled: false` to defer fetching until a required condition (e.g., an available filter) is met.
