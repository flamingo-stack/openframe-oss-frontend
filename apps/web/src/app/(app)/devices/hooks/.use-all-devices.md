## use-all-devices.ts

A React hook that fetches the complete set of devices matching a given filter by exhaustively walking all pages, intended for lookup-table use cases rather than paginated UI lists.

This hook bridges Relay-backed GraphQL data fetching with React Query's caching layer. While the underlying `fetchAllDevices` query executes the Relay document (so results are normalized into the Relay store as `Machine` records), the pagination loop and caching logic are managed entirely by React Query here. This is a deliberate choice: Relay's `usePaginationFragment` doesn't provide a "fetch all pages" primitive, and since consumers need the full device set as a keyed lookup (not an incrementally-scrolled list), react-query's simpler cursor-walk-to-exhaustion model fits better than driving `loadNext` from an effect.

## Key Components

- **`useAllDevices(options)`** — Main hook; fetches and caches the full device list for a given filter.
- **`UseAllDevicesOptions`** — Input interface: `filter` (optional `DeviceFilterInput`) and `enabled` (optional boolean, defaults to `true`).
- **Return value**: `{ devices, isLoading, error, refetch }`
  - `devices`: `Device[]`, defaults to a stable empty array (`EMPTY_DEVICES`) to avoid unnecessary re-renders.
  - `isLoading`: boolean from the underlying query state.
  - `error`: string message or `null`.
  - `refetch`: function to manually re-trigger the fetch.

## Usage Example

```typescript
import { useAllDevices } from './use-all-devices';

function DeviceLookupTable() {
  const { devices, isLoading, error } = useAllDevices({
    filter: { status: 'online' },
    enabled: true,
  });

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner message={error} />;

  // Build a lookup keyed by Fleet host id
  const deviceById = new Map(devices.map((d) => [d.hostId, d]));

  return <MonitoringTable deviceLookup={deviceById} />;
}
```

Use this hook only when you need the entire filtered fleet (e.g., for cross-referencing monitoring data by host ID). For paginated, user-scrollable device lists, use a Relay-based pagination hook instead.
