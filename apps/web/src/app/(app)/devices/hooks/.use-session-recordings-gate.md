# use-session-recordings-gate.ts

A client-side React hook that gates visibility of the session recordings UI (device Remote Sessions tab and recording playback page) by combining the `session-recordings` feature flag with the remote access approval gate.

## Key Components

- **`useSessionRecordingsGate()`** - Hook returning a `FeatureFlagGate` (`'on'`, `'off'`, or `'loading'`) that determines whether session recordings surfaces should be shown.

### Gating Logic

- Depends on `useRemoteAccessApprovalGate()` — recordings require remote access to be enabled.
- Depends on `useFeatureFlagGate('session-recordings')` — the dedicated recordings flag.
- Returns `'off'` if either gate is `'off'`.
- Returns `'loading'` if either gate is `'loading'` (and neither is `'off'`).
- Returns `'on'` only when both gates resolve to `'on'`.

This ensures recordings can be disabled independently even when remote access is enabled, but never shown without remote access being on.

## Usage Example

```typescript
import { useSessionRecordingsGate } from '@/app/hooks/use-session-recordings-gate';

function RemoteSessionsTab() {
  const gate = useSessionRecordingsGate();

  if (gate === 'loading') {
    return <SpinnerPlaceholder />;
  }

  if (gate === 'off') {
    return null;
  }

  return <SessionRecordingsList />;
}
```

## Notes

- Must be used within a Client Component (`'use client'` directive required).
- Relies on `useRemoteAccessApprovalGate` from the sibling module for the underlying remote access check.
- Returned `FeatureFlagGate` type is shared with other feature flag hooks for consistent UI handling across loading/off/on states.
