This client-side hook composes two feature flag gates to determine whether session recording surfaces (the device's Remote Sessions tab and the recording playback page) should be shown.

## Key Components

- **`useSessionRecordingsGate()`** — A React hook that returns a `FeatureFlagGate` (`'on'`, `'off'`, or `'loading'`) by combining:
  - `useRemoteAccessApprovalGate()` — the gate for the remote access feature itself.
  - `useFeatureFlagGate('session-recordings')` — the dedicated `session-recordings` feature flag.

  The combined gate resolves as:
  - `'off'` if either the remote access gate or the recordings flag is off.
  - `'loading'` if either is still loading (and neither is off).
  - `'on'` otherwise.

This ensures session recordings are only enabled when remote access is also enabled, allowing recordings to be independently disabled even when remote access is on.

## Usage Example

```typescript
import { useSessionRecordingsGate } from '@/app/hooks/use-session-recordings-gate';

function RemoteSessionsTab() {
  const gate = useSessionRecordingsGate();

  if (gate === 'loading') {
    return <Spinner />;
  }

  if (gate === 'off') {
    return null; // Hide the tab entirely
  }

  return <RemoteSessionsContent />;
}
```

This hook is intended for use in components that render device remote session recording UI, ensuring consistent gating logic across the Remote Sessions tab and recording detail pages.
