# use-device-actions-menu.tsx

React hook that assembles the full set of actions-menu items for a device (device details, remote shell, remote control, file manager, run script, edit display name, reboot, logs, delete), wiring in availability rules, remote access policy gating, mobile-shell restrictions, and the associated confirmation/edit dialogs.

## Key Components

- **`useDeviceActionsMenu(device, options)`** — Main hook. Builds a `DeviceActionsMenuItems` object plus the dialogs needed to back destructive/edit actions (delete, reboot, edit display name confirmations).
- **`UseDeviceActionsMenuOptions`** — Input options: `onRunScript`, `onActionComplete`, `deviceId` (fallback id for loading states), `iconSize`, `navigateOnDestructive` (navigate to devices list after delete), and `policyContext` (`'page'` vs `'row'`, controlling how remote access policy is resolved).
- **`DeviceActionsMenuItems`** — Shape of the returned menu items. Notable nullable entries:
  - `remoteControl` is `null` in the mobile shell (MeshCentral canvas isn't usable without pointer/keyboard).
  - `editDisplayName`, `reboot`, `delete` are `null` when disabled by `DeviceActionAvailability`.
- **`UseDeviceActionsMenuResult`** — Return type: `{ items, dialogs, actionAvailability }`.

Internally composes `buildDeviceMenuItems`, `getDeviceActionAvailability`, `useDeviceConfirmationDialogs`, `useRemoteAccessApprovalGate`, and `useEffectiveDeviceRemoteAccessMode` to determine enabled/disabled state and labels (e.g. "Edit Device" vs "Edit Display Name" depending on the remote access gate flag).

## Usage Example

```typescript
import { useDeviceActionsMenu } from './hooks/use-device-actions-menu';

function DeviceRowActions({ device }: { device: Device }) {
  const { items, dialogs } = useDeviceActionsMenu(device, {
    policyContext: 'row',
    onActionComplete: () => refetchDevices(),
    navigateOnDestructive: false,
  });

  return (
    <>
      <ActionsMenu
        items={[
          items.deviceDetails,
          items.remoteShell,
          items.remoteControl,
          items.manageFiles,
          items.runScript,
          items.editDisplayName,
          items.reboot,
          items.deviceLogs,
          items.delete,
        ].filter(Boolean)}
      />
      {dialogs}
    </>
  );
}
```

Pass `deviceId` when rendering actions before the full `Device` object has loaded, so hrefs (e.g. run-script navigation) still resolve correctly.
