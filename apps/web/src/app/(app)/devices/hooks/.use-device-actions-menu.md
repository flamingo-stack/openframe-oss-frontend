# use-device-actions-menu.tsx

A React hook that builds the complete set of action-menu items (details, remote shell/control, file manager, run script, edit display name, reboot, logs, delete) for a device, applying availability rules, remote-access policy gating, and mobile-shell restrictions. It centralizes the logic shared across the devices table dropdown, device-details header, and ticket-details menu.

## Key Components

- **`useDeviceActionsMenu(device, options)`** — Main hook. Accepts a `Device` (or `null`/`undefined` while loading) and configuration options, returning menu items, associated dialogs, and computed action availability.
- **`UseDeviceActionsMenuOptions`** — Configuration interface: `onRunScript`, `onActionComplete`, `deviceId` (fallback for hrefs), `iconSize`, `navigateOnDestructive` (navigate to device list after delete), and `policyContext` (`'page'` vs `'row'`, controls how remote-access policy is resolved).
- **`DeviceActionsMenuItems`** — Shape of the returned menu items. Notably `remoteControl` is `null` in the mobile shell (no pointer/keyboard support for MeshCentral), and `editDisplayName`/`reboot`/`delete` are `null` when disabled by `DeviceActionAvailability` or archive status.
- **`UseDeviceActionsMenuResult`** — Return type: `items`, `dialogs` (ReactNode containing confirmation dialogs and the edit-display-name modal), and `actionAvailability`.

## Usage Example

```typescript
import { useDeviceActionsMenu } from '../hooks/use-device-actions-menu';

function DeviceRowActions({ device, refetch }: { device: Device; refetch: () => void }) {
  const { items, dialogs } = useDeviceActionsMenu(device, {
    onActionComplete: refetch,
    navigateOnDestructive: true,
    policyContext: 'row',
  });

  return (
    <>
      <ActionsMenu
        items={[
          items.deviceDetails,
          items.remoteShell,
          items.remoteControl,
          items.manageFiles,
          items.runScript,
          items.editDisplayName,
          items.reboot,
          items.deviceLogs,
          items.delete,
        ].filter(Boolean)}
      />
      {dialogs}
    </>
  );
}
```

Pass `deviceId` instead of a full `device` object when the row/header is still loading, so hrefs (e.g., Run Script) can be computed early. Use `policyContext: 'page'` for table views that batch-fetch remote access policy via `useRowRemoteAccessPolicies`, and `'row'` for per-row resolution.
