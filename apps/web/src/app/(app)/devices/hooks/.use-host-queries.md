A React Query hook for fetching Fleet osquery query reports scoped to a specific host, used in the monitoring section of the app.

## Key Components

- **`hostQueriesKeys`** — Query key factory exposing `detail(hostId)` for cache targeting/invalidation of a host's queries.
- **`fetchHostQueries(hostId)`** — Async fetcher calling `fleetApiClient.getHostQueries(hostId)` (`GET /fleet/hosts/{id}/queries`), throwing on non-ok responses and returning the `reports` array (or an empty array fallback).
- **`useHostQueries(hostId)`** — React Query hook wrapping the fetcher. Automatically disables fetching (via `skipToken`) when `hostId` is `undefined`, and guarantees a referentially stable empty array (`EMPTY_REPORTS`) as `data` while loading or disabled, to avoid retriggering memoized consumers like `useDataTable`.

**Important note:** The returned reports include `report_id` (the query id), `last_fetched`, and `n_host_results`, but **not** the query's scheduling `interval`. To get frequency, join these results with the global `/fleet/queries` list by id.

## Usage Example

```typescript
import { useHostQueries } from '@/hooks/use-host-queries';

function HostQueriesPanel({ fleetHostId }: { fleetHostId: number | undefined }) {
  const { data: reports, isLoading, error } = useHostQueries(fleetHostId);

  if (isLoading) return <p>Loading queries...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <ul>
      {reports.map((report) => (
        <li key={report.report_id}>
          Query #{report.report_id} — last fetched: {report.last_fetched ?? 'never'}
        </li>
      ))}
    </ul>
  );
}
```

If `fleetHostId` is `undefined` (e.g., the device has no linked Fleet host), the query is automatically skipped and `reports` resolves to an empty array.
