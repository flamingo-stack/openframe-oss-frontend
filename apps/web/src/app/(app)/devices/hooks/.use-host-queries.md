# use-host-queries.ts

React Query hook for fetching Fleet query reports scoped to a specific host, enabling per-device monitoring data to be joined with global query metadata (like interval frequency).

## Key Components

- **`hostQueriesKeys`** — Query key factory object; `detail(hostId)` produces the cache key `['fleet', 'hosts', hostId, 'queries']` for a given host.
- **`fetchHostQueries(hostId)`** — Async fetcher that calls `fleetApiClient.getHostQueries(hostId)` (the Fleet `GET /fleet/hosts/{id}/queries` endpoint), throws on error responses, and returns the `reports` array (or an empty array fallback).
- **`useHostQueries(hostId)`** — Primary hook wrapping `useQuery`. Disables the fetch (via `skipToken`) when `hostId` is `undefined`, and always returns a referentially stable `data` array (`EMPTY_REPORTS`) instead of `undefined` while loading or disabled, to prevent infinite re-renders in dependent memoized consumers (e.g. `useDataTable`).

Note: the returned report rows include `report_id` (the query id), `last_fetched`, and `n_host_results`, but **not** query frequency/interval — that must be joined from the global `/fleet/queries` list by id.

## Usage Example

```typescript
import { useHostQueries } from '@/hooks/use-host-queries';

function HostQueriesPanel({ hostId }: { hostId: number | undefined }) {
  const { data: reports, isLoading, error } = useHostQueries(hostId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  return (
    <ul>
      {reports.map((report) => (
        <li key={report.report_id}>
          Query {report.report_id}: {report.n_host_results} results
          (last fetched {report.last_fetched})
        </li>
      ))}
    </ul>
  );
}
```

To join with global query metadata for interval/frequency:

```typescript
const { data: hostReports } = useHostQueries(hostId);
const { data: allQueries } = useFleetQueries();

const enriched = hostReports.map((r) => ({
  ...r,
  interval: allQueries?.find((q) => q.id === r.report_id)?.interval,
}));
```
