Manages confirmation dialog state and logic for device archive and delete operations, rendering pre-built `ConfirmDialog` nodes (including an uninstall command box for deletions) that callers inject directly into their JSX.

## Key Components

### `useDeviceConfirmationDialogs(device, options)`

Main hook accepting a `Device` object and optional callbacks.

**Parameters:**
- `device` — Target device (`Device | null | undefined`)
- `options.onArchived` — Called after a successful archive
- `options.onDeleted` — Called after a successful delete

**Returns (`UseDeviceConfirmationDialogsResult`):**

| Property | Type | Description |
|---|---|---|
| `openArchive` | `() => void` | Opens the archive confirmation dialog |
| `openDelete` | `() => void` | Opens the delete confirmation dialog |
| `dialogs` | `ReactNode` | Pre-rendered `<ConfirmDialog>` pair to place in JSX |
| `isArchiving` | `boolean` | Pending state for the archive action |
| `isDeleting` | `boolean` | Pending state for the delete action |
| `unarchiveDevice` | `(id, name?) => Promise<boolean>` | Re-exported from `useDeviceActions` to avoid double instantiation |
| `isUnarchiving` | `boolean` | Pending state for the unarchive action |

**Internal dependencies:**
- `useDeviceActions` — Executes archive/unarchive/delete API calls
- `useReleaseVersion` — Fetches the current agent version (lazy, only when delete dialog is open)
- `buildUninstallCommand` / `normalizeDevicePlatform` — Derives a platform-specific uninstall command shown in the delete dialog

## Usage Example

```typescript
export function DeviceDetailPage({ device }: { device: Device }) {
  const { openArchive, openDelete, dialogs, isArchiving, isDeleting } =
    useDeviceConfirmationDialogs(device, {
      onArchived: () => router.push('/devices'),
      onDeleted:  () => router.push('/devices'),
    });

  return (
    <>
      <button onClick={openArchive} disabled={isArchiving}>Archive</button>
      <button onClick={openDelete}  disabled={isDeleting}>Delete</button>

      {/* Renders both ConfirmDialogs; mount once near the root of the subtree */}
      {dialogs}
    </>
  );
}
```
