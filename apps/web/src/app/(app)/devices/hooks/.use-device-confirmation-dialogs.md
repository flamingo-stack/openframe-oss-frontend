A custom React hook that encapsulates confirmation dialog state and handlers for destructive device actions (delete and reboot), rendering ready-to-use dialog UI alongside trigger functions.

## Key Components

- **`useDeviceConfirmationDialogs(device, options)`** — Main hook accepting a `Device` object and optional `onDeleted`/`onRebooted` callbacks.
- **`openDelete` / `openReboot`** — Functions to trigger the respective confirmation dialogs.
- **`dialogs`** — A `ReactNode` containing both the reboot and delete `ConfirmDialog` components, ready to render in JSX.
- **`isDeleting` / `isRebooting`** — Boolean loading states forwarded from `useDeviceActions` and `useRebootDevice`.
- Internally relies on `useDeviceActions`, `useRebootDevice`, and `getDeviceActionAvailability` to perform the actual delete/reboot operations and check device eligibility (e.g., presence of a MeshCentral agent ID for reboot).

## Usage Example

```typescript
import { useDeviceConfirmationDialogs } from './hooks/use-device-confirmation-dialogs';

function DeviceActionsMenu({ device, refreshList }: { device: Device; refreshList: () => void }) {
  const { openDelete, openReboot, dialogs, isDeleting, isRebooting } = useDeviceConfirmationDialogs(device, {
    onDeleted: refreshList,
    onRebooted: () => console.log('Device rebooted'),
  });

  return (
    <>
      <button onClick={openReboot} disabled={isRebooting}>
        Reboot
      </button>
      <button onClick={openDelete} disabled={isDeleting}>
        Delete
      </button>

      {dialogs}
    </>
  );
}
```

The hook handles opening/closing dialogs, calling the underlying mutation hooks, and invoking success callbacks once the operation completes successfully. Consumers only need to render `{dialogs}` and wire up the `open*` triggers to buttons or menu items.
