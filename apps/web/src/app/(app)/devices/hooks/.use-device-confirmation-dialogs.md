# use-device-confirmation-dialogs.tsx

A custom React hook that encapsulates confirmation dialog state and logic for destructive/impactful device actions (delete and reboot), rendering ready-to-use dialog UI alongside trigger functions.

## Key Components

- **`useDeviceConfirmationDialogs(device, options)`** — Main hook that manages confirmation dialogs for a given device.
  - **Parameters:**
    - `device: Device | null | undefined` — The target device for the actions.
    - `options.onDeleted?: () => void` — Callback invoked after successful deletion.
    - `options.onRebooted?: () => void` — Callback invoked after successful reboot.
  - **Returns:** `UseDeviceConfirmationDialogsResult`
    - `openDelete: () => void` — Opens the delete confirmation dialog.
    - `openReboot: () => void` — Opens the reboot confirmation dialog.
    - `dialogs: ReactNode` — Pre-built JSX containing both `ConfirmDialog` instances.
    - `isDeleting: boolean` — Loading state during delete operation.
    - `isRebooting: boolean` — Loading state during reboot operation.

The hook internally relies on `useDeviceActions` (for deletion), `useRebootDevice` (for reboot), and `getDeviceActionAvailability` to resolve the MeshCentral agent ID required for reboot.

## Usage Example

```typescript
import { useDeviceConfirmationDialogs } from './hooks/use-device-confirmation-dialogs';

function DeviceActionsPanel({ device }: { device: Device }) {
  const { openDelete, openReboot, dialogs, isDeleting, isRebooting } =
    useDeviceConfirmationDialogs(device, {
      onDeleted: () => console.log('Device deleted, refresh list'),
      onRebooted: () => console.log('Device rebooted'),
    });

  return (
    <>
      <button onClick={openReboot} disabled={isRebooting}>
        Reboot
      </button>
      <button onClick={openDelete} disabled={isDeleting}>
        Delete
      </button>
      {dialogs}
    </>
  );
}
```

Render `{dialogs}` once in your component tree so the confirmation modals are available when `openDelete` or `openReboot` are triggered.
