# use-remote-control-viewers.ts

A React hook that computes the list of viewers to display in the Remote Control header's "Watch live" indicator, combining the hosting technician with any additional session watchers.

## Key Components

- **`useRemoteControlViewers()`** - Returns a `RemoteSessionViewer[]` representing who should be shown as watching the current remote control session. Returns an empty array when:
  - Watch-live gating is off (`useRemoteSessionWatchGate` !== `'on'`)
  - No active session exists
  - The session has ended (locally or via `session.status === 'ENDED'`)
  - No authenticated user ID is available
  - No one besides the host is currently viewing (the host alone doesn't count)

- Relies on these composed hooks/utilities:
  - `useRemoteSessionWatchGate` - determines if viewer display is enabled
  - `useRemoteAccessSession` - provides the current `session` and `ended` state
  - `useRemoteSessionChatTechnician` - supplies the technician's display name/avatar
  - `useAuthStore` - retrieves the logged-in user's ID
  - `sessionViewers` - builds the final viewer list, merging host info with session viewer records

## Usage Example

```typescript
import { useRemoteControlViewers } from './use-remote-control-viewers';

function RemoteControlHeader() {
  const viewers = useRemoteControlViewers();

  if (viewers.length === 0) {
    return null; // Nothing to show - gate off, no session, or solo host
  }

  return (
    <div className="watch-live-indicator">
      <span>Watching live:</span>
      {viewers.map(viewer => (
        <Avatar key={viewer.userId} name={viewer.name} src={viewer.avatarUrl} />
      ))}
    </div>
  );
}
```

## Notes

The viewer list stays in sync with the live session record, which is updated by viewer join/leave events and background polling (see `useRemoteSession`). The hook correctly identifies the host even when they're viewing from a second browser tab, ensuring the host is never duplicated or mistakenly counted as a separate "watcher."
