# use-remote-control-viewers.ts

A React hook that computes the list of viewers (host technician plus watchers) to display in the Remote Control header's "Watch live" indicator, derived from the active remote access session state.

## Key Components

- **`useRemoteControlViewers()`** — Hook returning a `RemoteSessionViewer[]` array representing who should be shown as currently watching the remote session.

### Behavior

- Returns an empty array when any of the following is true:
  - The watch gate (`useRemoteSessionWatchGate`) is not `'on'`.
  - There is no active session, or the session has ended (`ended` flag or `session.status === 'ENDED'`).
  - There's no authenticated user (`userId` is null).
  - Only the host is present (no other distinct viewer exists besides `hostId`).
- Determines `hostId` from `session.technicianId`, falling back to the current `userId` (covers the case where the signed-in technician is running their own session).
- Delegates final list construction to `sessionViewers()`, combining the host's identity (name/avatar from `useRemoteSessionChatTechnician`) with the raw `session.viewers` array, excluding duplicates.

### Dependencies

- `useRemoteSessionWatchGate` — determines whether "Watch live" is enabled.
- `useRemoteAccessSession` — provides the current session record and `ended` state.
- `useRemoteSessionChatTechnician` — supplies technician display info (name, avatar).
- `useAuthStore` — supplies the signed-in user's ID.
- `sessionViewers` — pure helper that merges host + viewers into the final list.

## Usage Example

```typescript
import { useRemoteControlViewers } from './use-remote-control-viewers';

function RemoteControlHeader() {
  const viewers = useRemoteControlViewers();

  if (viewers.length === 0) {
    return null; // Nothing to show: gate off, no session, or host-only
  }

  return (
    <div className="watch-live-indicator">
      <span>Watch live:</span>
      {viewers.map(viewer => (
        <Avatar key={viewer.id} src={viewer.avatarUrl} name={viewer.name} />
      ))}
    </div>
  );
}
```

This hook is typically consumed by UI components that render the "who's watching" indicator during an active remote support session, reacting automatically to session updates, viewer join/leave events, and gate toggles.
