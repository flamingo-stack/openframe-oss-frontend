# use-agent-log-key.ts

A React hook that fetches and caches the tenant's agent log key, used to authenticate a device's log streaming from first connection rather than relying on the install key.

## Key Components

- **`useAgentLogKey()`** — Hook that returns the tenant's log key (`string | undefined`) by querying the `/api/agent/log-key` endpoint. Returns `undefined` while loading or if no key exists yet.

### Behavior Details

- Uses `@tanstack/react-query` with query key `['agent', 'log-key']`.
- **4xx responses** (e.g., `AGENT_LOG_KEY_NOT_FOUND`) are treated as a valid "no key yet" answer — resolves to `null` without throwing or retrying, since a tenant may not have generated a key yet.
- **Network errors or 5xx responses** throw and are retried (`retry: 2`), guarding against transient failures at mount time.
- `staleTime: Infinity` since the log key is a stable, tenant-scoped value that is never rotated — no need to refetch once fetched.
- Silent failure by design: there is no user-facing error/toast because there's nothing actionable for the user, and the install flow doesn't block waiting for this value.

## Usage Example

```typescript
import { useAgentLogKey } from '@/hooks/use-agent-log-key';

function InstallCommandPanel() {
  const logKey = useAgentLogKey();

  const installCommand = logKey
    ? `install-agent --logKey=${logKey}`
    : 'install-agent';

  return (
    <pre>
      <code>{installCommand}</code>
    </pre>
  );
}
```

```typescript
// Conditionally render based on key availability
function AgentRegisterButton() {
  const logKey = useAgentLogKey();

  return (
    <button disabled={logKey === undefined}>
      Register Device
    </button>
  );
}
```
