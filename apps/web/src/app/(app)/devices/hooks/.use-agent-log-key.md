# use-agent-log-key.ts

A React hook that fetches the tenant's agent log key, used to authenticate a device's log stream before it registers with its own key.

## Key Components

- **`useAgentLogKey()`** — Hook that returns the tenant's agent log key as a `string`, or `undefined` if unavailable (not yet fetched, request still pending, or no key exists for the tenant).

## Behavior Notes

- Fetches from `/api/agent/log-key` via `apiClient.get`.
- A successful response (`response.ok`) yields the `key` field (or `null` if absent).
- A 4xx status (e.g., the `AGENT_LOG_KEY_NOT_FOUND` case for a tenant without a key yet) is treated as a valid "no key" answer — it resolves to `null` without throwing, since there's nothing actionable for the user.
- Any other failure (no response, or 5xx) throws, triggering React Query's retry logic, since it may be a transient blip rather than a real "no key" state.
- `staleTime: Infinity` — the key is fetched once per tenant and never considered stale, since it's never rotated.
- `retry: 2` — retries transient failures twice before giving up.
- Failures surface silently (no toast); the flag is optional and the device falls back to authenticating with the install key until registration completes.

## Usage Example

```typescript
import { useAgentLogKey } from '@/hooks/use-agent-log-key';

function InstallCommandPreview() {
  const logKey = useAgentLogKey();

  const installCommand = logKey
    ? `install-agent --logKey=${logKey}`
    : `install-agent`;

  return <code>{installCommand}</code>;
}
```
