## Overview

A React hook that merges paginated tenant session rows with live-polled session data, keeping a tenant-wide remote session list current while it's open. It handles detecting sessions that started after the current page load, refreshing stale pages, and recovering from invalid pagination cursors.

## Key Components

- **`useTenantSessionRows(input: TenantSessionRowsInput)`** — Main hook that combines paged rows with live polling data and returns an up-to-date row set, adjusted total count, and a load-more completion handler.
- **`TenantSessionRowsInput`** — Input shape: `pageRows`, `totalCount`, `filter`, and `onRefresh` callback.
- **`TenantSessionRows`** — Return shape: `rows`, `totalCount`, and `onLoadMoreComplete`.
- **`INVALID_CURSOR`** — Constant matching the server's error code for a rejected/expired pagination cursor.

### Behavior Notes
- Live polling (`useTenantLiveSessions`) only runs when Watch is enabled and no `recordingState` filter is set, since running sessions never match a state filter like KEPT/EXPIRING/EXPIRED.
- Sessions that appear in polling but aren't on the loaded page yet are counted in `totalCount` via `startedSincePage`.
- When a previously "live" row disappears from the poll (meaning it ended), the hook triggers `onRefresh` once per session ID (tracked via `refreshedFor`) to avoid repeated refetching.
- `onLoadMoreComplete` triggers a full refresh if the server rejects the pagination cursor with `INVALID_CURSOR`, handling cases where a table stays open across a deployment that changed cursor encoding.

## Usage Example

```typescript
import { useTenantSessionRows } from './use-tenant-session-rows';

function TenantSessionsTable({ pageRows, totalCount, filter, refetchFirstPage, loadMore }) {
  const { rows, totalCount: liveTotalCount, onLoadMoreComplete } = useTenantSessionRows({
    pageRows,
    totalCount,
    filter,
    onRefresh: refetchFirstPage,
  });

  const handleLoadMore = () => {
    loadMore((error) => onLoadMoreComplete(error));
  };

  return (
    <SessionTable
      rows={rows}
      totalCount={liveTotalCount}
      onLoadMore={handleLoadMore}
    />
  );
}
```
