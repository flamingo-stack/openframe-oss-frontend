# use-tenant-session-rows.ts

A React hook that merges paginated tenant remote-session rows with live-polled session data, keeping the tenant-wide session list current while it is open, and gracefully recovering from stale pagination cursors.

## Key Components

- **`useTenantSessionRows(input: TenantSessionRowsInput): TenantSessionRows`** — Main hook that combines server-paged rows with optionally polled live sessions, computes an adjusted total count, and exposes a load-more-complete handler for cursor invalidation recovery.
- **`TenantSessionRowsInput`** — Input shape: `pageRows`, `totalCount`, `filter`, and `onRefresh` callback.
- **`TenantSessionRows`** — Output shape: merged `rows`, adjusted `totalCount`, and `onLoadMoreComplete` callback.
- **`INVALID_CURSOR`** — Constant matching the server error code signaling a stale/unrecognized pagination cursor.

### Behavior Notes
- Live polling (`useTenantLiveSessions`) only runs when Watch mode is active (`useLiveRows`) and no `recordingState` filter is set (state filters like KEPT/EXPIRING/EXPIRED never match running sessions).
- Rows found polling but absent from the current page count toward `totalCount` (`startedSincePage`).
- When a previously "live" row disappears from the poll results (session ended), the hook triggers `onRefresh()` once per session ID (tracked via `refreshedFor`) to avoid refetch loops on inconsistent server responses.
- `onLoadMoreComplete` calls `onRefresh()` if the server rejects the pagination cursor with `INVALID_CURSOR`, restarting the list instead of failing the scroll.

## Usage Example

```typescript
import { useTenantSessionRows } from './use-tenant-session-rows';

function TenantSessionsTable({ data, filter, refetchFirstPage }) {
  const { rows, totalCount, onLoadMoreComplete } = useTenantSessionRows({
    pageRows: data.pageRows,
    totalCount: data.totalCount,
    filter,
    onRefresh: refetchFirstPage,
  });

  const loadMore = (error: Error | null) => {
    onLoadMoreComplete(error);
    // proceed with additional pagination logic
  };

  return (
    <SessionTable
      rows={rows}
      totalCount={totalCount}
      onLoadMore={loadMore}
    />
  );
}
```
