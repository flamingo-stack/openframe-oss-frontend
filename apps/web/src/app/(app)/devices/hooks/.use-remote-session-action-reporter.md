A React hook that provides a stable function for reporting remote session actions (e.g., console interactions) to a session's timeline, lazily creating and caching a `RemoteSessionActionReporter` instance tied to the active session.

## Key Components

- **`useRemoteSessionActionReporter(sessionId: string | null)`** - Hook that returns a report function `(action: RemoteSessionAction) => void`.
  - Returns a no-op reporter when `sessionId` is `null` (e.g., remote access approval disabled or session not yet opened).
  - Lazily instantiates a new `RemoteSessionActionReporter` whenever the `sessionId` changes, caching it via `useRef` to avoid unnecessary re-creation across re-renders.
  - Delegates actual reporting to `RemoteSessionActionReporter.report()`.

## Usage Example

```typescript
import { useRemoteSessionActionReporter } from './use-remote-session-action-reporter';

function RemoteConsole({ sessionId }: { sessionId: string | null }) {
  const reportAction = useRemoteSessionActionReporter(sessionId);

  const handleCommandSent = (command: string) => {
    // Send command to agent first...
    sendCommandToAgent(command);

    // Then report it to the session timeline
    reportAction({
      type: 'command',
      payload: command,
      timestamp: Date.now(),
    });
  };

  return <button onClick={() => handleCommandSent('ls -la')}>Run Command</button>;
}
```

**Important:** Always call the returned function from event handlers, and only *after* the action has been sent to the agent. If `sessionId` is `null`, calls are silently ignored, making this hook safe to use unconditionally regardless of session state.
