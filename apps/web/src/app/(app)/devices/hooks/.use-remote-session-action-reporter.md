A React hook that reports remote console actions to a session's timeline, lazily instantiating a `RemoteSessionActionReporter` per session and becoming a no-op when no session ID is available.

## Key Components

- **`useRemoteSessionActionReporter(sessionId)`** - Hook that returns a stable `report` function for sending `RemoteSessionAction` events tied to a given session.
- Internally uses `useRef` to cache a `RemoteSessionActionReporter` instance, recreating it only when the `sessionId` changes, avoiding unnecessary reporter re-instantiation across re-renders.
- Returns a no-op-safe function: if `sessionId` is `null` (e.g., remote access approval is disabled or the session hasn't opened yet), calling the returned function does nothing.

## Usage Example

```typescript
import { useRemoteSessionActionReporter } from './use-remote-session-action-reporter';

function RemoteConsole({ sessionId }: { sessionId: string | null }) {
  const reportAction = useRemoteSessionActionReporter(sessionId);

  const handleCommandSent = (command: string) => {
    // Perform the actual action first (e.g., send to agent)
    sendCommandToAgent(command);

    // Then report it to the session timeline
    reportAction({
      type: 'command',
      payload: { command },
      timestamp: Date.now(),
    });
  };

  return (
    <button onClick={() => handleCommandSent('ls -la')}>
      Run Command
    </button>
  );
}
```

**Important:** Always call the returned `report` function from event handlers, and only after the action has already been dispatched to the remote agent—this hook is for telemetry/history reporting, not for triggering actions itself.
