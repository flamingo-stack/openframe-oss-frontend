# use-remote-access-approval.ts

A React hook that manages the technician-side state machine for requesting remote screen-access approval to a device, combining a NATS push channel with a polling fallback to detect the end user's decision.

## Key Components

- **`RemoteAccessApprovalState`** — union type describing the approval lifecycle: `idle` → `requesting` → `awaiting` → one of `approved` / `denied` / `timed_out`, plus create-call refusals `busy` / `unreachable` / `error`.
- **`UseRemoteAccessApprovalResult`** — hook return shape: `state`, `request`, `error`, `errorCode`, and the actions `requestAccess`, `cancel`, `reset`.
- **`useRemoteAccessApproval(deviceId)`** — main hook. Creates a remote access request via `remoteAccessApprovalApiService`, then waits for a decision through:
  - A NATS subscription (`useNatsJsonSubscription`) on the technician's `user.{userId}.notification` subject (fast path).
  - A 2-second polling fallback via `remoteAccessApprovalApiService.get` (`POLL_MS`).
- **`stateForSettled`** — maps a settled `RemoteAccessRequest` status to its corresponding UI state (treats `REVOKED`/`CANCELLED` as a return to `idle`).
- **`stateForCreateError`** — maps `RemoteAccessCreateErrorCode` (e.g. `DEVICE_HAS_LIVE_REQUEST`, `DEVICE_UNREACHABLE`) to `busy`/`unreachable`/`error`.

Internally, an `attemptRef` generation counter coalesces async results so stale callbacks from a cancelled or superseded attempt are ignored.

## Usage Example

```typescript
import { useRemoteAccessApproval } from './hooks/use-remote-access-approval';

function RemoteAccessButton({ deviceId }: { deviceId: string }) {
  const { state, request, error, requestAccess, cancel, reset } = useRemoteAccessApproval(deviceId);

  if (state === 'idle') {
    return <button onClick={() => requestAccess('Troubleshooting ticket #123')}>Request Access</button>;
  }
  if (state === 'awaiting') {
    return <button onClick={cancel}>Awaiting approval... Cancel</button>;
  }
  if (state === 'approved') {
    return <span>Access approved for request {request?.requestId}</span>;
  }
  if (state === 'denied' || state === 'timed_out' || state === 'busy' || state === 'error') {
    return (
      <div>
        <span>{error ?? state}</span>
        <button onClick={reset}>Retry</button>
      </div>
    );
  }
  return null;
}
```
