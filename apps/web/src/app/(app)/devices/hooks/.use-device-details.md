## use-device-details.ts

This module fetches and composes a unified `Device` object by merging data from the primary GraphQL device node, Fleet MDM host data, and MeshCentral status/connectivity info, exposing a React Query hook for device detail retrieval.

## Key Components

- **`collectEndUserEmails(fleetData)`** — Extracts a deduplicated list of end-user emails (primary + alternate) from Fleet host data.
- **`createDevice(node, fleetData, meshCentralStatus, meshCentralLastSeen, sources)`** — Pure mapping function that merges a `DeviceGraphQlNode`, Fleet host payload, and MeshCentral status into a single `Device` object. Handles software/battery/policy/user transformation, private IP filtering, tool connection enrichment (Fleet/MeshCentral status overlays), and legacy field fallbacks.
- **`fetchDeviceDetails(machineId)`** — Async orchestrator that fetches the base device node, conditionally fetches Fleet host details (skipping when the Fleet connection is `pending` or `disconnected`), fetches MeshCentral status/last-seen, and passes everything to `createDevice`.
- Relies on `fleetApiClient`, `getMeshCentralDeviceInfo`/`parseMeshCentralDeviceStatus`/`parseMeshCentralLastSeen`, `getToolConnectionState`/`isDeviceStillConnecting`, `toDeviceTags`, and `deviceQueryKeys` for data sourcing and caching keys.
- Designed for use with `@tanstack/react-query`'s `useQuery`/`skipToken` pattern, with `useToast` for error surfacing.

## Usage Example

```typescript
import { useQuery } from '@tanstack/react-query';
import { deviceQueryKeys } from '../utils/query-keys';

function DeviceDetailsPanel({ machineId }: { machineId: string }) {
  const { data: device, isLoading } = useQuery({
    queryKey: deviceQueryKeys.detail(machineId),
    queryFn: () => fetchDeviceDetails(machineId),
  });

  if (isLoading || !device) return <div>Loading...</div>;

  return (
    <div>
      <h2>{device.displayName}</h2>
      <p>Status: {device.status}</p>
      <p>OS: {device.operating_system} {device.osVersion}</p>
      <p>IP: {device.ip}</p>
    </div>
  );
}
```

**Note:** `createDevice` can also be used directly in tests or custom data pipelines when Fleet and MeshCentral data are already available, bypassing network fetches.
