## use-device-details.ts

React Query-based hook module for fetching and composing unified `Device` objects by merging data from multiple sources: the GraphQL device node, Fleet MDM host details, and MeshCentral remote-control status. Centralizes device normalization so UI components consume a single consistent `Device` shape regardless of which tools are connected.

## Key Components

- **`collectEndUserEmails(fleetData)`** — Extracts and deduplicates end-user email addresses (primary + alternates) from a Fleet host record.
- **`createDevice(node, fleetData, meshCentralStatus, meshCentralLastSeen, sources)`** — Pure function that maps raw API responses (GraphQL `DeviceGraphQlNode`, Fleet `FleetHost`, MeshCentral status) directly into the unified `Device` type, without an intermediate normalization layer. Handles hardware specs, network IPs (with private/public IP filtering), OS metadata, software/vulnerabilities, battery/policy/user arrays, tool connection enrichment, and legacy field aliases.
- **`fetchDeviceDetails(machineId)`** — Async orchestrator that fetches the device node, then conditionally fetches Fleet MDM host data based on the tool connection state (`pending`, `disconnected`, or live), avoiding unnecessary or stale lookups.
- Relies on `deviceQueryKeys`, `fleetApiClient`, `getMeshCentralDeviceInfo`/`parseMeshCentralDeviceStatus`/`parseMeshCentralLastSeen`, and `getToolConnectionState`/`isDeviceStillConnecting` helpers to coordinate multi-source data fetching.

## Usage Example

```typescript
import { useQuery } from '@tanstack/react-query';
import { deviceQueryKeys } from '../utils/query-keys';

function useDeviceDetails(machineId: string) {
  return useQuery({
    queryKey: deviceQueryKeys.detail(machineId),
    queryFn: machineId ? () => fetchDeviceDetails(machineId) : skipToken,
  });
}

function DeviceDetailPanel({ machineId }: { machineId: string }) {
  const { data: device, isLoading } = useDeviceDetails(machineId);

  if (isLoading || !device) return <p>Loading device...</p>;

  return (
    <div>
      <h2>{device.displayName}</h2>
      <p>Status: {device.status}</p>
      <p>OS: {device.osType} {device.osVersion}</p>
      <p>Software items: {device.software.length}</p>
    </div>
  );
}
```

This hook is typically consumed by device detail pages that need a merged view of enrollment, hardware, and remote-access status across Fleet MDM and MeshCentral integrations.
