Checks whether the current tenant has at least one organization (customer) by querying the GraphQL API, driving the Devices page "no customer" guard state.

## Key Components

- **`useHasOrganizations()`** — Custom React Query hook that returns:
  - `hasOrganizations: boolean | undefined` — `undefined` while loading, `true`/`false` once resolved
  - `isLoading: boolean` — query loading state

## Usage Example

```typescript
import { useHasOrganizations } from './use-has-organizations';

function AddDeviceButton() {
  const { hasOrganizations, isLoading } = useHasOrganizations();

  // Avoid flashing empty-customer UI before the answer is known
  if (isLoading || hasOrganizations === undefined) return null;

  if (!hasOrganizations) {
    return <p>Add a customer before adding a device.</p>;
  }

  return <button>Add Device</button>;
}
```

## Behaviour Notes

- Returns `hasOrganizations: undefined` during loading to prevent premature rendering of the empty-customer prompt
- Results are cached with a `staleTime` of 60 seconds to avoid redundant requests
- Throws on non-OK HTTP responses or GraphQL-level errors
