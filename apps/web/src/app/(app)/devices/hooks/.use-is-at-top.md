## Overview

A React hook that detects whether a user has scrolled away from the top of a scrollable list by observing a sentinel element with `IntersectionObserver`. It's commonly used to conditionally show "scroll to top" buttons or sticky headers based on scroll position.

## Key Components

- **`useIsAtTop<T>(rootMargin?)`** - Hook that returns `{ ref, atTop }`:
  - `ref` - A callback ref to attach to a sentinel element (e.g., placed above a list). Being a callback ref ensures the observer re-attaches if the node is re-rendered or swapped.
  - `atTop` - Boolean indicating whether the sentinel is visible within `rootMargin` of the scroll container's top, **or** the content hasn't been scrolled yet (still "below the fold" under a tall header).
  - `rootMargin` (default `'120px'`) - Controls how far from the top the sentinel is considered "at top".

The hook observes relative to the nearest `<main>` ancestor (via `node.closest('main')`) rather than the viewport, since the app's scroll container is `<main>`, not `window`.

## Usage Example

```typescript
import { useIsAtTop } from './use-is-at-top';

function ListWithScrollIndicator() {
  const { ref, atTop } = useIsAtTop<HTMLDivElement>('100px');

  return (
    <div>
      <div ref={ref} />
      {!atTop && (
        <button className="scroll-to-top" onClick={() => window.scrollTo(0, 0)}>
          Back to top
        </button>
      )}
      <ul>
        {/* list items */}
      </ul>
    </div>
  );
}
```

## Notes

- Requires the `'use client'` directive since it relies on browser APIs (`IntersectionObserver`, `window`).
- The sentinel `ref` should be placed at the very top of the scrollable content, above the list items.
- Designed to work within a layout where `<main>` is the scrolling ancestor; see the related `shared/empty-state` component for context on this constraint.
