A React hook that tracks whether a sentinel element is near the top of its scrollable container, used to toggle "scroll to top" affordances or sticky header states in lists.

## Key Components

- **`useIsAtTop<T>(rootMargin?)`** - Generic hook accepting an optional `rootMargin` (default `'120px'`) that returns:
  - `ref`: a callback ref to attach to a sentinel element (typically placed above a scrollable list).
  - `atTop`: a boolean indicating whether the sentinel is within `rootMargin` of the scroller's top, or whether the list hasn't been scrolled into view yet (still below the fold).

Internally, the hook uses a callback ref (via `useState`) rather than a plain `useRef` so that if the sentinel node changes across re-renders, the `IntersectionObserver` is properly torn down and re-attached to the new node. It scopes observation to the nearest `<main>` ancestor (`node.closest('main')`) rather than the viewport, since the app's scroll container is `<main>`, not the window.

## Usage Example

```typescript
'use client';

import { useIsAtTop } from './use-is-at-top';

function DeviceList() {
  const { ref, atTop } = useIsAtTop<HTMLDivElement>('150px');

  return (
    <div>
      <div ref={ref} />
      {!atTop && (
        <button onClick={() => window.scrollTo({ top: 0, behavior: 'smooth' })}>
          Back to top
        </button>
      )}
      {/* list content */}
    </div>
  );
}
```

**Notes:**
- Place the sentinel element (with `ref` attached) at the very top of the scrollable content.
- `atTop` starts as `true` by default, assuming the top is visible until the observer reports otherwise.
- Because the observer roots against the closest `<main>` element, this hook assumes the app's primary scroll container is a `<main>` tag.
