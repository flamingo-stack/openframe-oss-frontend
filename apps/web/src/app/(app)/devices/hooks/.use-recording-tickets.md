React Query hooks for fetching and mutating tickets linked to a remote session recording, keeping the recording page's ticket list in sync with changes made elsewhere in the app.

## Key Components

- **`useRecordingTickets(recordingId)`** — Query hook that fetches tickets linked to a given recording. Uses `staleTime: 0` to always refetch on mount, since ticket assignee/status can change on other pages that don't share this cache. Returns `skipToken` (disabling the query) when `recordingId` is `null`.
- **`useApplyRecordingTickets(recordingId)`** — Internal helper returning a function that writes mutation results directly into the `recordingTickets` query cache and invalidates `sessionEvents` so the session timeline reflects the new `TICKET_ASSIGNED`/`TICKET_UNASSIGNED` entry.
- **`useAssignRecordingTickets(recordingId)`** — Mutation hook to assign one or more tickets to a session. On success, updates the cache via `useApplyRecordingTickets` and shows a success toast (singular/plural aware). On error, surfaces a toast via `handleApiError`.
- **`useUnassignRecordingTicket(recordingId)`** — Mutation hook to unassign a single ticket from a session, with the same cache update and toast behavior as assignment.

## Usage Example

```typescript
import {
  useRecordingTickets,
  useAssignRecordingTickets,
  useUnassignRecordingTicket,
} from './use-recording-tickets';

function RecordingTicketsPanel({ recordingId, sessionId }: { recordingId: string; sessionId: string }) {
  const { data: tickets, isLoading } = useRecordingTickets(recordingId);
  const assignTickets = useAssignRecordingTickets(recordingId);
  const unassignTicket = useUnassignRecordingTicket(recordingId);

  const handleAssign = (ticketIds: string[]) => {
    assignTickets.mutate({ sessionId, ticketIds });
  };

  const handleUnassign = (ticketId: string) => {
    unassignTicket.mutate({ sessionId, ticketId });
  };

  if (isLoading) return <p>Loading tickets...</p>;

  return (
    <ul>
      {tickets?.map(ticket => (
        <li key={ticket.id}>
          {ticket.title}
          <button onClick={() => handleUnassign(ticket.id)}>Unassign</button>
        </li>
      ))}
    </ul>
  );
}
```
