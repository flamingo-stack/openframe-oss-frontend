React hooks for fetching and managing tickets linked to a remote session recording, including assignment and unassignment of tickets with cache synchronization and toast notifications.

## Key Components

- **`useRecordingTickets(recordingId)`** — Query hook that fetches tickets linked to a recording session. Uses `skipToken` to disable the query when `recordingId` is `null`, and sets `staleTime: 0` to always refetch on mount, since ticket assignee/status changes happen on separate Tickets pages that don't share this cache.
- **`useApplyRecordingTickets(recordingId)`** — Internal helper that writes mutation results directly into the `recordingTickets` query cache and invalidates `sessionEvents` so the session timeline reflects the new assignment event.
- **`useAssignRecordingTickets(recordingId)`** — Mutation hook to assign one or more tickets to a session. On success, updates the cache and shows a success toast (singular/plural message); on failure, surfaces an error toast via `handleApiError`.
- **`useUnassignRecordingTicket(recordingId)`** — Mutation hook to unassign a single ticket from a session, with matching cache update and toast feedback.

## Usage Example

```typescript
import {
  useRecordingTickets,
  useAssignRecordingTickets,
  useUnassignRecordingTicket,
} from './use-recording-tickets';

function RecordingTicketsPanel({ recordingId, sessionId }: { recordingId: string; sessionId: string }) {
  const { data: tickets, isLoading } = useRecordingTickets(recordingId);
  const assignTickets = useAssignRecordingTickets(recordingId);
  const unassignTicket = useUnassignRecordingTicket(recordingId);

  const handleAssign = (ticketIds: string[]) => {
    assignTickets.mutate({ sessionId, ticketIds });
  };

  const handleUnassign = (ticketId: string) => {
    unassignTicket.mutate({ sessionId, ticketId });
  };

  if (isLoading) return <p>Loading tickets...</p>;

  return (
    <ul>
      {tickets?.map(ticket => (
        <li key={ticket.id}>
          {ticket.title}
          <button onClick={() => handleUnassign(ticket.id)}>Unassign</button>
        </li>
      ))}
    </ul>
  );
}
```
