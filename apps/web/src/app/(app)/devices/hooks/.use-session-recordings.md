# use-session-recordings.ts

React Query hooks for managing session recordings: listing a device's remote sessions, viewing recording/live session detail, tracking tenant storage usage, and performing delete/keep/release mutations with cache synchronization.

## Key Components

- **`LIVE_POLL_MS`** - Constant (10,000ms) defining the polling interval for live session data.
- **`useSessionRecordings(deviceId, options)`** - Fetches the list of session recordings for a device. Supports optional live polling (`poll: true`) that refetches every 10s, pausing when the tab is hidden or unhealthy.
- **`useSessionRecording(recordingId)`** - Fetches a single recording's detail for the player page. Treats "recording not found" as a terminal state (no retry).
- **`useLiveSession(sessionId)`** - Polls a single live session until it settles (ended and recording resolved or unavailable). Stops retrying on "session not found".
- **`useRecordingStorage()`** - Fetches tenant-wide recording storage usage, only enabled when the session recordings feature gate is `'on'`.
- **`DeleteRemoteSessionTarget`** - Interface describing the data needed to delete a session (`sessionId`, `recordingId`, optional `deviceId`).
- **`useDeleteRemoteSession(deviceId)`** - Mutation to delete a session/recording; optimistically removes it from the cached list, invalidates related queries, and shows a toast.
- **`KeepSessionRecordingTarget`** - Extends `DeleteRemoteSessionTarget` with a `selection` (`KeepRecordingSelection`).
- **`useKeepSessionRecording(deviceId)`** - Mutation to mark a recording as "kept" (exempt from auto-deletion); refreshes related caches and storage.
- **`useReleaseSessionRecording(deviceId)`** - Mutation to release a previously kept recording, reversing the keep state.

## Usage Example

```typescript
import {
  useSessionRecordings,
  useLiveSession,
  useDeleteRemoteSession,
  useKeepSessionRecording,
} from './use-session-recordings';

function RemoteSessionsTab({ deviceId }: { deviceId: string }) {
  const { data: recordings, isLoading } = useSessionRecordings(deviceId, { poll: true });
  const deleteSession = useDeleteRemoteSession(deviceId);
  const keepRecording = useKeepSessionRecording(deviceId);

  const handleDelete = (sessionId: string, recordingId: string | null) => {
    deleteSession.mutate({ sessionId, recordingId });
  };

  const handleKeep = (sessionId: string, recordingId: string | null) => {
    keepRecording.mutate({ sessionId, recordingId, selection: 'full' });
  };

  if (isLoading) return <p>Loading…</p>;
  return (
    <ul>
      {recordings?.map(r => (
        <li key={r.id}>{r.id}</li>
      ))}
    </ul>
  );
}

function LiveSessionPage({ sessionId }: { sessionId: string }) {
  const { data: session } = useLiveSession(sessionId);
  return <div>{session?.live ? 'Live now' : 'Session ended'}</div>;
}
```
