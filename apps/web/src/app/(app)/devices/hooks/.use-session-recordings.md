# use-session-recordings.ts

React Query hooks for managing remote session recordings: listing recordings per device, polling live sessions, viewing recording details, and mutating (delete/keep/release) recordings with correct cache invalidation.

## Key Components

- **`LIVE_POLL_MS`** — Poll interval constant (10 seconds) used for live session/list refetching.
- **`useSessionRecordings(deviceId, { poll })`** — Fetches a device's recording list; optionally polls every `LIVE_POLL_MS` (paused when the tab is hidden or unhealthy) to reflect sessions starting/ending elsewhere.
- **`useSessionRecording(recordingId)`** — Fetches a single recording's detail for the player page; treats `RecordingNotFoundError` as a final answer (no retry).
- **`useLiveSession(sessionId)`** — Polls a live session until it settles (ended and not awaiting recording); treats `SessionNotFoundError` as final.
- **`useRecordingStorage()`** — Fetches tenant recording storage usage, only enabled when the session recordings feature gate is `'on'`.
- **`DeleteRemoteSessionTarget`** — Interface describing a session/recording/device target for delete operations.
- **`useDeleteRemoteSession(deviceId)`** — Mutation to delete a session's recording and data, optimistically removing it from the cached list and invalidating related queries (list, storage, detail).
- **`KeepSessionRecordingTarget`** — Extends `DeleteRemoteSessionTarget` with a `selection` (`KeepRecordingSelection`).
- **`useKeepSessionRecording(deviceId)`** — Mutation to mark a recording as "kept" (excluded from auto-deletion), refreshing related caches.
- **`useReleaseSessionRecording(deviceId)`** — Mutation to release a previously kept recording, refreshing related caches.

## Usage Example

```typescript
import {
  useSessionRecordings,
  useLiveSession,
  useDeleteRemoteSession,
  useKeepSessionRecording,
} from './use-session-recordings';

function RemoteSessionsTab({ deviceId }: { deviceId: string }) {
  const { data: recordings } = useSessionRecordings(deviceId, { poll: true });
  const deleteSession = useDeleteRemoteSession(deviceId);
  const keepRecording = useKeepSessionRecording(deviceId);

  const handleDelete = (sessionId: string, recordingId: string | null) => {
    deleteSession.mutate({ sessionId, recordingId });
  };

  const handleKeep = (sessionId: string, recordingId: string | null) => {
    keepRecording.mutate({ sessionId, recordingId, selection: 'full' });
  };

  return (
    <ul>
      {recordings?.map(r => (
        <li key={r.id}>{r.id}</li>
      ))}
    </ul>
  );
}

function LiveSessionPage({ sessionId }: { sessionId: string }) {
  const { data: session } = useLiveSession(sessionId);
  return <div>{session?.live ? 'Live' : 'Ended'}</div>;
}
```
