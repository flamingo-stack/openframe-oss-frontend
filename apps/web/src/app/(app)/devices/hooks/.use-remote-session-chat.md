# use-remote-session-chat.ts

React hooks that power the in-app chat panel for a remote access session, merging a persisted message history with a live JetStream subject feed into a single deduplicated, ordered message list.

## Key Components

- **`useRemoteSessionDialogId()`** - Returns the active remote session's chat `dialogId` (or `null` if none provisioned), sourced from `useRemoteAccessSession`.
- **`useRemoteSessionChatTechnician()`** - Derives the signed-in technician's display name and avatar URL from the auth store, memoized on user changes.
- **`useRemoteSessionChat(dialogId, panelOpen?)`** - Main hook combining:
  - History fetch via `remoteSessionChatApiService.history()`, re-triggered after feed gaps/reconnects.
  - Live tail via `useJetStreamDialogSubscription` on the `CHAT_CHUNKS` stream starting at the last known sequence.
  - Deduplication by message `id` and `seq` against the loaded page.
  - Unread tracking (`hasUnread`) flagged only for end-user messages arriving while the panel is closed.
  - `send(body)` to post a message, returning `false` on blank text, missing dialog, or failure.
  - `markRead()` to clear the unread flag.
- **`RemoteSessionChatState`** - Return shape: `messages`, `isLoading`, `sending`, `technician`, `send`, `hasUnread`, `markRead`.
- **`ChatStore`** (internal) - Per-dialog state: `history`, `live`, `historyLoaded`, `lastSeq`, `unread`.

## Usage Example

```typescript
import { useRemoteSessionDialogId, useRemoteSessionChat } from './use-remote-session-chat';

function RemoteSessionChatPanel({ panelOpen }: { panelOpen: boolean }) {
  const dialogId = useRemoteSessionDialogId();
  const { messages, isLoading, sending, technician, send, hasUnread, markRead } =
    useRemoteSessionChat(dialogId, panelOpen);

  useEffect(() => {
    if (panelOpen) markRead();
  }, [panelOpen, markRead]);

  const handleSend = async (text: string) => {
    const ok = await send(text);
    if (!ok) {
      // show send failure feedback
    }
  };

  if (isLoading) return <div>Loading chat…</div>;

  return (
    <div>
      {hasUnread && <span>New message</span>}
      {messages.map(m => (
        <div key={m.id}>{m.author === 'technician' ? technician.name : 'User'}: {m.body}</div>
      ))}
      <ChatInput disabled={sending} onSubmit={handleSend} />
    </div>
  );
}
```

Dialog state automatically resets when `dialogId` changes, and the live feed resumes delivering messages the moment history finishes loading, keeping technician and end-user messages in a single ordered timeline.
