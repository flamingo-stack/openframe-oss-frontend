# use-tenant-live-sessions.ts

Provides live polling of a tenant's currently running remote sessions, used to keep a tenant-wide session list in sync with devices that start or stop sessions in near real time.

## Key Components

- **`TenantLiveSessionsFilter`** - Type alias for `RemoteSessionFilter` excluding `recordingState`, since the live poll always forces the state to `LIVE`.
- **`readLiveSessions(filter)`** - Async function that performs a single network-only Relay query for live sessions matching `filter`, returning an array of `TenantSessionRow` (mapped via `toTenantSessionRow`). Used both by the polling hook and for one-off lookups (e.g., checking if a device is busy).
- **`useTenantLiveSessions(filter)`** - React hook built on `useQuery` that polls `readLiveSessions` every `LIVE_POLL_MS` (10s) while the tab is visible. Returns:
  - `null` if `filter` is `null` (e.g., "Watch live" toggle is off) or before the first successful response.
  - An array of `TenantSessionRow` once data has loaded.
  - On query failure, the hook keeps returning stale/previous data rather than clearing the list, so the UI falls back to the server-paged results.

Polling behavior is controlled by shared helpers `sessionInterval`, `sessionRetry`, and `sessionPollMeta` from `@/lib/session-poll`, ensuring consistent retry/backoff and visibility-aware polling across session-related hooks.

## Usage Example

```typescript
import { useTenantLiveSessions, type TenantLiveSessionsFilter } from './use-tenant-live-sessions';

function TenantSessionsList({ scopeFilter, watchLive }: {
  scopeFilter: TenantLiveSessionsFilter;
  watchLive: boolean;
}) {
  const liveSessions = useTenantLiveSessions(watchLive ? scopeFilter : null);

  if (liveSessions === null) {
    return <StaticSessionTable />; // fall back to server-paged data
  }

  return <SessionTable rows={liveSessions} />;
}
```

For a one-time check (e.g., determining if a specific device currently has a live session):

```typescript
import { readLiveSessions } from './use-tenant-live-sessions';

const liveRows = await readLiveSessions({ deviceId: 'device-123' });
const isBusy = liveRows.length > 0;
```
