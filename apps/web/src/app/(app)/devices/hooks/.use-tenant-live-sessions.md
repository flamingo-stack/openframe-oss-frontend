# use-tenant-live-sessions.ts

Provides a React Query hook that polls for a tenant's currently running (LIVE) remote sessions via Relay, used to keep a tenant-wide session list in sync without waiting for a full page refresh.

## Key Components

- **`TenantLiveSessionsFilter`** - Type alias for `RemoteSessionFilter` with `recordingState` omitted, since the live poll always forces the state to `LIVE`.
- **`readLiveSessions(filter)`** - Async function that performs a single network-only Relay fetch of `tenantRemoteSessionsRelayLiveQuery`, forcing `recordingState: RemoteSessionListState.LIVE`, and maps the returned edges into `TenantSessionRow[]` via `toTenantSessionRow`.
- **`useTenantLiveSessions(filter)`** - React hook wrapping `readLiveSessions` in `useQuery`, polling every 10 seconds (`LIVE_POLL_MS`) while the tab is visible (via `sessionInterval`), with retry logic from `sessionRetry(3)`. Returns `null` when `filter` is `null` or before the first successful response; on query failure, the previously fetched data is retained (list stays as last paged by the server).

## Usage Example

```typescript
import { useTenantLiveSessions, type TenantLiveSessionsFilter } from './use-tenant-live-sessions';

function TenantSessionList({ tenantId }: { tenantId: string }) {
  const filter: TenantLiveSessionsFilter = { tenantId };

  const liveSessions = useTenantLiveSessions(filter);

  if (liveSessions === null) {
    return <p>Loading live sessions…</p>;
  }

  return (
    <ul>
      {liveSessions.map(session => (
        <li key={session.id}>{session.deviceName} — started {session.startedAt}</li>
      ))}
    </ul>
  );
}

// Disable polling entirely by passing null
function Paused() {
  const sessions = useTenantLiveSessions(null); // always null, no network calls
  return null;
}
```

Note: this hook depends on an active Relay environment (`getRelayEnvironment`) and the `deviceQueryKeys.tenantLiveSessions` query key factory for cache scoping.
