React hook that fetches organization options for device-related selection dropdowns using TanStack Query and a GraphQL endpoint.

## Key Components

- **`DeviceOrganizationOption`** — Interface describing a single organization option (id, name, default flag, optional image metadata).
- **`deviceOrganizationsQueryKeys`** — Query key factory for TanStack Query cache management; prefixed with `organizations` to share invalidation with other org-related caches.
- **`useDeviceOrganizations(first?)`** — Suspense-enabled hook that POSTs a `GetOrganizationsOptions` GraphQL query via `apiClient`, maps the edge/node response to a flat `DeviceOrganizationOption[]`, and throws on HTTP or GraphQL errors.

## Usage Example

```typescript
import { LoadingSuspense } from '@flamingo-stack/openframe-frontend-core/components';
import { NO_ITEMS } from '@/app/components/shared';
import { useDeviceOrganizations } from '@/hooks/use-device-organizations';

// The picker over the organizations it is handed: in a loading scope it draws its own skeleton.
function OrganizationSelectView({ organizations }) {
  return <SearchableSelect options={organizations.map(org => ({ value: org.organizationId, label: org.name }))} />;
}

function OrganizationSelect() {
  return <OrganizationSelectView organizations={useDeviceOrganizations(50)} />;
}

// The hook suspends while fetching: the boundary's fallback is the same picker with no options.
export default function Page() {
  return (
    <LoadingSuspense label="Loading organizations" fallback={<OrganizationSelectView organizations={NO_ITEMS} />}>
      <OrganizationSelect />
    </LoadingSuspense>
  );
}
```

> **Cache invalidation:** Because the query key starts with `organizations`, calling `queryClient.invalidateQueries({ queryKey: ['organizations'] })` after a create/update operation will automatically refetch this hook alongside other org caches.
