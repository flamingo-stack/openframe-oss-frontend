## use-directory-facets.ts

A React hook that fetches facet counts for device "directory source" and "user link" filters, used to populate filter pickers in a device list UI. It is intentionally decoupled from the main `useDeviceFilters` hook since it queries separate Pinot columns that can fail independently.

## Key Components

- **`directoryFacetsQuery`** - GraphQL query (via `react-relay`) that fetches `directorySources` and `userLinks` facet values/counts from `deviceFilters`, gated by the `@include(if: $list)` directive.
- **`useDirectoryFacets(filters, enabled)`** - Main hook export. Takes the current `DeviceFilterInput` and an `enabled` flag, returns a memoized object with `directorySources` and `userLinks` facet lists (each entry has `value` and `count`).

### Behavior Notes

- Uses `useNonSuspendingQuery` so a failed or pending facet fetch never blocks rendering of the device list or other filter funnels.
- Selected filter values are always included in the returned facets (via `withSelected`) even if the server doesn't return them, so users can always deselect an active filter.
- Results are memoized based on a stringified key of currently selected values, preventing unnecessary re-renders of dependent table column definitions.
- Facet counts do not auto-refresh on device mutations; they update on re-narrowing or store expiry.

## Usage Example

```typescript
import { useDirectoryFacets } from '@/app/hooks/use-directory-facets';

function DeviceFilterPanel({ filters, isPanelOpen }: Props) {
  const { directorySources, userLinks } = useDirectoryFacets(filters, isPanelOpen);

  return (
    <div>
      <FacetPicker label="Directory Source" options={directorySources} />
      <FacetPicker label="User Link" options={userLinks} />
    </div>
  );
}
```
