# use-directory-facets.ts

A React hook that fetches facet counts (options with occurrence counts) for the "Directory Sources" and "User Links" filter funnels in the device directory, using a non-suspending GraphQL query so facet loading never blocks the device list or other filter pickers.

## Key Components

- **`directoryFacetsQuery`** — Relay GraphQL query requesting `directorySources` and `userLinks` facet values/counts from `deviceFilters`, conditionally included via the `$list` variable.
- **`useDirectoryFacets(filters, enabled)`** — Hook returning `Pick<DeviceFilters, 'directorySources' | 'userLinks'>`:
  - Converts incoming `DeviceFilterInput` to a Relay-compatible filter via `toRelayDeviceFilter`.
  - Uses `useNonSuspendingQuery` so the query never throws or suspends the UI; while pending or on failure, it degrades gracefully to only showing currently selected values.
  - Preserves currently selected (URL-derived) facet values even if they are absent from the raw query response or dropped by `toRelayDeviceFilter`, using `withSelected` to merge selected values at `count: 0` when missing.
  - Memoizes the result on a stable JSON string key (`selectedKey`) rather than raw arrays, preventing unnecessary re-renders/table column rebuilds.

## Usage Example

```typescript
import { useDirectoryFacets } from '@/app/hooks/use-directory-facets';

function DirectoryFilters({ filters, isListView }: { filters: DeviceFilterInput; isListView: boolean }) {
  const { directorySources, userLinks } = useDirectoryFacets(filters, isListView);

  return (
    <div>
      <FacetPicker label="Directory Source" options={directorySources} />
      <FacetPicker label="User Link" options={userLinks} />
    </div>
  );
}
```

**Notes:**
- `enabled` should reflect whether the facet picker UI is currently visible (e.g., list view toggle); when `false`, the hook returns empty facet sets without querying.
- Unlike `useDeviceFilters`, facet counts here do not auto-refresh on device mutations—only on re-narrowing or Relay store expiry.
