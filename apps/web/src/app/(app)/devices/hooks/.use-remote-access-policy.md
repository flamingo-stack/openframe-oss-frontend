## use-remote-access-policy.ts

React Query hooks for managing remote access policies across a three-tier hierarchy (tenant → organization → device), where each level can inherit from or override the level above it.

## Key Components

- **`remoteAccessPolicyKeys`** - Query key factory for tenant, organization, device, and row-batch cache entries.
- **`useTenantRemoteAccessPolicy(options)`** - Fetches the tenant-wide default policy.
- **`useUpdateTenantRemoteAccessPolicy()`** - Mutation to update the tenant policy; invalidates all dependent caches on success.
- **`useOrganizationRemoteAccessPolicy(organizationId, options)`** - Fetches an organization's policy override plus its effective mode.
- **`useSetOrganizationRemoteAccessMode()`** - Mutation to set or clear (`null`) an organization-level override.
- **`useDeviceRemoteAccessPolicy(deviceId, options)`** - Fetches a device's policy override plus its effective mode.
- **`useSetDeviceRemoteAccessMode()`** - Mutation to set or clear (`null`) a device-level override.
- **`useRowRemoteAccessPolicies(devices)`** - Batches policy reads for a device table, paginated to match `DEVICES_PAGE_SIZE`, writing results into per-device cache entries.
- **`useEffectiveDeviceRemoteAccessMode(device, options)`** - Resolves the effective mode for a single device, gated by the `remote-access-approval` feature flag. Returns `undefined` when the gate is off or still loading, preserving legacy unrestricted behavior. Supports a `context: 'row'` mode that relies on `useRowRemoteAccessPolicies` having already populated the cache instead of issuing its own request.

All mutations are silent (no built-in toast feedback) - callers are responsible for surfacing success/error state to the user.

## Usage Example

```typescript
import {
  useTenantRemoteAccessPolicy,
  useSetDeviceRemoteAccessMode,
  useEffectiveDeviceRemoteAccessMode,
  useRowRemoteAccessPolicies,
} from './use-remote-access-policy';

// Resolve effective mode for a single device (e.g., connect button)
function ConnectButton({ device }: { device: Pick<Device, 'machineId' | 'id'> }) {
  const mode = useEffectiveDeviceRemoteAccessMode(device, { context: 'page' });
  if (mode === 'DENY_ACCESS') return <DisabledButton />;
  return <ConnectAction device={device} />;
}

// Batch-load policies for a device table, then read per-row effective mode
function DeviceTable({ devices }: { devices: Device[] }) {
  useRowRemoteAccessPolicies(devices);
  return devices.map(device => (
    <Row key={device.id} mode={useEffectiveDeviceRemoteAccessMode(device, { context: 'row' })} />
  ));
}

// Update a device-level override
function DeviceModeSelect({ deviceId }: { deviceId: string }) {
  const { mutate } = useSetDeviceRemoteAccessMode();
  return <Select onChange={mode => mutate({ deviceId, mode })} />;
}
```
