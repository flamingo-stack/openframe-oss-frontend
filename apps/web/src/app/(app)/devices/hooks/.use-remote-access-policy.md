# use-remote-access-policy.ts

React Query hooks for reading and mutating remote access policy at the tenant, organization, and device levels, including batched per-row policy prefetching for device tables and resolution of a device's effective (inherited) remote access mode.

## Key Components

- **`remoteAccessPolicyKeys`** - Query key factory for tenant, organization, device, and row-batch cache entries.
- **`useTenantRemoteAccessPolicy(options?)`** - Fetches the tenant-wide default policy.
- **`useUpdateTenantRemoteAccessPolicy()`** - Mutation to update the tenant policy; invalidates all dependent caches (silent, caller handles toasts).
- **`useOrganizationRemoteAccessPolicy(organizationId, options?)`** - Fetches an organization's policy override (or inherited tenant default).
- **`useSetOrganizationRemoteAccessMode()`** - Mutation to set/clear an organization's mode override; invalidates all policy queries.
- **`useDeviceRemoteAccessPolicy(deviceId, options?)`** - Fetches a device's policy override and effective mode.
- **`useSetDeviceRemoteAccessMode()`** - Mutation to set/clear a device's mode override; invalidates that device's query.
- **`useRowRemoteAccessPolicies(devices)`** - Batches device table rows into pages (`DEVICES_PAGE_SIZE`), fetches policies per page, and seeds individual device cache entries. Gated behind the `remote-access-approval` feature flag.
- **`useEffectiveDeviceRemoteAccessMode(device, options?)`** - Resolves the effective mode for a single device (device → organization → tenant inheritance), respecting the feature gate. Supports `context: 'row'` to avoid redundant fetches when a table already batches policies via `useRowRemoteAccessPolicies`.

## Usage Example

```typescript
import {
  useTenantRemoteAccessPolicy,
  useSetDeviceRemoteAccessMode,
  useRowRemoteAccessPolicies,
  useEffectiveDeviceRemoteAccessMode,
} from './use-remote-access-policy';

// Tenant-level read
const { data: tenantPolicy } = useTenantRemoteAccessPolicy();

// Device table: prefetch policies for visible rows
useRowRemoteAccessPolicies(devices);

// Resolve effective mode for a row (reuses the batched cache entry)
const mode = useEffectiveDeviceRemoteAccessMode(device, { context: 'row' });

// Override a single device's mode
const { mutate: setDeviceMode } = useSetDeviceRemoteAccessMode();
setDeviceMode({ deviceId: device.machineId, mode: 'manual-approval' });
```

Consumers typically combine `useEffectiveDeviceRemoteAccessMode` with the connect flow to decide whether a connection attempt should proceed or require approval, and use the silent mutations alongside their own toast notifications.
