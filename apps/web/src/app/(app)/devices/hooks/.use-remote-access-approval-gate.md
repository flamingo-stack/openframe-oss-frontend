This file defines a React hook that gates the approval-aware remote access connect flow behind a feature flag, allowing the legacy auto-start tunnel behavior to remain active until the flag is enabled.

## Key Components

- **`useRemoteAccessApprovalGate()`** — A client-side hook that wraps `useFeatureFlagGate` with the hardcoded flag key `'remote-access-approval'`. Returns a `FeatureFlagGate` object indicating whether the approval-based consent flow should be shown, or whether the legacy auto-start tunnel behavior applies.

## Usage Example

```typescript
'use client';

import { useRemoteAccessApprovalGate } from '@/app/hooks/use-remote-access-approval-gate';

function RemoteAccessConnectButton() {
  const { enabled, loading } = useRemoteAccessApprovalGate();

  if (loading) {
    return <span>Checking access policy...</span>;
  }

  if (enabled) {
    // New flow: requires explicit approval before the tunnel starts
    return <ApprovalAwareConnectFlow />;
  }

  // Legacy flow: tunnel auto-starts with no consent step
  return <LegacyAutoConnectFlow />;
}
```

## Notes

- The flag is evaluated consistently across all environments, including the dev server, since it mirrors the server-side flag state rather than being hardcoded per build.
- When the flag is `off`, the UI should route users to the legacy auto-start behavior without hitting the approval API.
- When `on`, the connect flow and associated policy UI should call the approval API, which is only active where this flag is enabled.
- This hook centralizes the flag key (`'remote-access-approval'`) so consumers don't need to reference the raw string directly.
