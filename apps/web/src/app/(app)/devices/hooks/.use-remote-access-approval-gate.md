This client-side React hook exposes the feature flag gate controlling the approval-aware remote access connect flow, determining whether users see a consent/approval step before a remote tunnel starts.

## Key Components

- **`useRemoteAccessApprovalGate()`** - A React hook that returns a `FeatureFlagGate` object for the `remote-access-approval` feature flag. It wraps `useFeatureFlagGate` to provide a single, named entry point for this specific gate.
- When the flag is **off**, legacy behavior applies: the remote tunnel auto-starts with no consent step.
- When the flag is **on**, the UI engages the approval-aware flow, calling the approval API before starting the tunnel.

This hook always reflects the live server-side flag state, including in development builds, ensuring consistent behavior across environments.

## Usage Example

```typescript
'use client';

import { useRemoteAccessApprovalGate } from '@/app/hooks/use-remote-access-approval-gate';

function RemoteAccessButton() {
  const approvalGate = useRemoteAccessApprovalGate();

  const handleConnect = async () => {
    if (approvalGate.enabled) {
      // Show consent/approval UI before starting the tunnel
      await requestApproval();
    } else {
      // Legacy behavior: auto-start tunnel
      await startTunnel();
    }
  };

  return <button onClick={handleConnect}>Connect</button>;
}
```

Use this hook anywhere the remote access connect flow or its associated policy UI needs to check whether approval-gated behavior is active, keeping the feature flag check centralized and consistent across components.
