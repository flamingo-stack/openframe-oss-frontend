# use-remote-session-watch.ts

A React hook that implements read-only ("watch") viewing of a live remote desktop session via MeshCentral, rendering the host's screen onto a canvas without establishing control access. It manages watch admission renewal, socket lifecycle, reconnection limits, and real-time viewer/session-end notifications over NATS.

## Key Components

- **`useRemoteSessionWatch(sessionId, live)`** — Main hook; dials a watch session, streams frames to a canvas, and exposes connection state, viewers, display/resolution info, and retry control.
- **`UseRemoteSessionWatchResult`** — Return type containing `state`, `viewers`, `display`, `resolution`, `attachCanvas`, and `retry`.
- **`WatchState`** — Union type: `'connecting' | 'streaming' | 'unavailable' | 'ended'`.
- **`WATCH_RENEW_MS`** — Interval (10s) for renewing watch admission while streaming.
- **`MAX_FAILED_DIALS`** — Max consecutive reconnect attempts (3) before giving up and requiring manual retry.
- **`isSessionEndedClose`** — Helper to detect the gateway's "session ended" WebSocket close code/reason.

## Usage Example

```typescript
function LiveWatchView({ sessionId }: { sessionId: string }) {
  const { state, viewers, resolution, attachCanvas, retry } =
    useRemoteSessionWatch(sessionId, true);

  return (
    <div>
      <canvas ref={attachCanvas} width={resolution?.width} height={resolution?.height} />
      {state === 'unavailable' && <button onClick={retry}>Retry</button>}
      {state === 'ended' && <p>Session has ended.</p>}
      <ul>
        {viewers.map(v => (
          <li key={v.userId}>{v.name}</li>
        ))}
      </ul>
    </div>
  );
}
```

## Behavior Notes

- The hook only becomes `active` when a `sessionId` is present, `live` is `true`, the subscription gate (`useSubscriptionOpen`) is open, and the state isn't already `ended`.
- Each dial attempt creates a fresh `MeshDesktop` (render-only) and `MeshTunnel`, tearing both down on cleanup or retry.
- Watch admission is renewed every `WATCH_RENEW_MS` and again immediately before each reconnect, so a backgrounded tab can resume after its admission lapses.
- A `WatchEndedError` transitions to `'ended'` and invalidates the `deviceQueryKeys.liveSession` query; `WatchDisabledError`/`SessionNotFoundError` transition to `'unavailable'`.
- Viewer list and session-end events also arrive via a NATS subscription on the user's notification subject (`user.<userId>.notification`).
- Call `retry()` to reset state to `'connecting'` and trigger a fresh dial attempt.
