# use-remote-session-watch.ts

A React hook that implements view-only ("Watch live") monitoring of an active remote session. It establishes a MeshCentral desktop relay in receive-only mode, renders the remote screen to a canvas, and tracks session lifecycle and viewer presence via NATS notifications, without opening a control socket or performing a mesh login.

## Key Components

- **`useRemoteSessionWatch(sessionId, live)`** — Main hook; dials a watch session and returns live stream state.
- **`UseRemoteSessionWatchResult`** — Return shape: `state`, `viewers`, `display`, `resolution`, `attachCanvas`, `retry`.
- **`WatchState`** — Union type: `'connecting' | 'streaming' | 'unavailable' | 'ended'`.
- **`WATCH_RENEW_MS`** — Interval (10s) at which the watch admission grant is renewed while active.
- **`MAX_FAILED_DIALS`** — Max consecutive failed reconnect attempts (3) before giving up and requiring manual retry.
- **`DESKTOP_PROTOCOL`** — MeshCentral relay protocol constant for KVM/desktop streams.

### Behavior Highlights

- Opens a `MeshTunnel` scoped to the session's screen relay only (no control channel).
- Renews the watch grant every 10 seconds and again immediately before each reconnect attempt, so tabs backgrounded longer than the grant's TTL still recover.
- Detects session termination via the gateway's socket close code (`1008`), an `ended` NATS event, or a failed watch renewal, transitioning to the `ended` state and invalidating the related React Query cache entry.
- Distinguishes `WatchDisabledError`/`SessionNotFoundError` (→ `unavailable`) from `WatchEndedError` (→ `ended`).
- Subscribes to the authenticated user's NATS notification subject to receive viewer-list updates and end-of-session events without per-session subscriptions.

## Usage Example

```typescript
import { useRemoteSessionWatch } from './hooks/use-remote-session-watch';

function WatchLivePanel({ sessionId }: { sessionId: string }) {
  const { state, viewers, display, resolution, attachCanvas, retry } =
    useRemoteSessionWatch(sessionId, true);

  return (
    <div>
      <canvas ref={attachCanvas} width={resolution?.width} height={resolution?.height} />
      <p>Status: {state}</p>
      <p>Display: {display ?? 'n/a'}</p>
      <ul>
        {viewers.map(v => (
          <li key={v.id}>{v.name}</li>
        ))}
      </ul>
      {state === 'unavailable' && <button onClick={retry}>Retry</button>}
    </div>
  );
}
```
