## useDirectoryGate

A client-side React hook that determines whether the tenant's directory integration UI (directory users/sources on device screens) should be shown, combining SaaS-only deployment checks, a Tenant Management Phase 2 feature flag, and the existence of at least one successfully-synced (or previously synced) directory connection.

## Key Components

- **`directoryGateQuery`** — GraphQL query (via `react-relay`) that conditionally fetches the count of directory connections whose last sync status was `SUCCESS` or `ERROR`, only executed when the `list` variable is true.
- **`useDirectoryGate()`** — The exported hook. Returns a `FeatureFlagGate` value (`'on' | 'off' | 'loading'`) by layering these checks in order:
  1. Not SaaS mode → `'off'`.
  2. Tenant Management v2 flag (`useTenantManagementV2Gate`) not `'on'` → passes through its value (`'off'` or `'loading'`).
  3. Query still loading → `'loading'`.
  4. At least one matching directory connection exists → `'on'`, otherwise `'off'`.

## Usage Example

```typescript
import { useDirectoryGate } from '@/hooks/use-directory-gate';

function DeviceDirectoryPanel() {
  const gate = useDirectoryGate();

  if (gate === 'loading') return <Spinner />;
  if (gate === 'off') return null;

  return <DirectoryUsersSection />;
}
```

Call this hook once per screen (e.g., at a top-level page or layout component) and pass the resulting gate value down to child components, since each invocation independently queries and caches its own result—concurrent callers may briefly disagree after a failed sync count until re-fetched.
