# use-directory-gate.ts

A React hook that determines whether directory-related UI (users, sources) should be shown on device screens, gating visibility behind SaaS mode, Tenant Management Phase 2 rollout, and the existence of at least one successfully-synced directory connection.

## Key Components

- **`directoryGateQuery`** — A GraphQL query (via `react-relay`) that conditionally fetches the total count of directory connections whose last sync status is `SUCCESS` or `ERROR`. The query is skipped entirely (`@include(if: $list)`) when preconditions aren't met.
- **`useDirectoryGate()`** — The exported hook returning a `FeatureFlagGate` (`'on' | 'off' | 'loading'`). It layers four checks:
  1. Must be running in `'saas-tenant'` app mode (via `runtimeEnv.appMode()`), otherwise `'off'`.
  2. Delegates to `useTenantManagementV2Gate()` — if not `'on'`, returns that gate's value as-is (`'off'` or `'loading'`).
  3. While the connection query is in flight, returns `'loading'`.
  4. Otherwise returns `'on'` only if at least one directory connection has synced (`totalCount > 0`), else `'off'`.

## Usage Example

```typescript
'use client';

import { useDirectoryGate } from '@/app/(app)/cloud-tenant-management/components/shared/use-directory-gate';

function DeviceDirectoryPanel() {
  const directoryGate = useDirectoryGate();

  if (directoryGate === 'loading') {
    return <Spinner />;
  }

  if (directoryGate === 'off') {
    // Fall back to local device accounts view
    return <LocalAccountsPanel />;
  }

  return <DirectoryUsersPanel />;
}
```

**Notes:**
- Read the gate once per screen and pass the resolved value down to children rather than calling the hook multiple times, since separate calls can momentarily disagree (e.g., one reads `'off'` after a failed count while a subsequent call re-fetches and reads `'on'`).
- A query error is treated the same as "no synced directory" (`'off'`), ensuring the fallback UI (local accounts) is never blocked by transient failures.
