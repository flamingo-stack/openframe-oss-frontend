# use-devices-url-params.ts

A React hook that synchronizes the Devices list UI state (search, filters, tags, view mode) with URL query parameters, providing a single source of truth for filtering, table column filters, and GraphQL filter inputs.

## Key Components

- **`UseDevicesUrlParamsOptions`** — Configuration interface:
  - `defaultStatuses` — Default device statuses applied when the user hasn't explicitly filtered (defaults to `DEFAULT_DEVICES_LIST_STATUSES`; pass `[]` for pages like the archive view that need every status).
  - `directoryColumns` — Enables the USER/SOURCES columns (`userLinks`, `directorySources`) for pages that render them.
- **`useDevicesUrlParams(options)`** — Main hook that returns:
  - `params` — Normalized URL params (statuses collapsed to `[]` when they match the defaults).
  - `setParam` / `setParams` — Setters that auto-normalize the `statuses` array.
  - `localSearch`, `setLocalSearch`, `debouncedSearch` — Responsive local search state debounced into the URL.
  - `filters` — `DeviceFilterInput` object ready to pass to a GraphQL query (only includes non-empty fields).
  - `tableFilters` — Flattened shape consumed by the data-table's column filter UI.
  - `tagOptions` — Tag values formatted as `TagSearchOption[]`.
  - `handleFilterChange` — Applies table column filter changes back to the URL and scrolls to top.
  - `handleTagRemove` — Removes a single tag.
  - `handleClearAll` — Resets search and tags.

## Usage Example

```typescript
import { useDevicesUrlParams } from '@/app/hooks/use-devices-url-params';

function DevicesPage() {
  const {
    params,
    filters,
    tableFilters,
    localSearch,
    setLocalSearch,
    handleFilterChange,
    handleTagRemove,
    handleClearAll,
  } = useDevicesUrlParams();

  // `filters` is ready for the devices GraphQL query
  const { data } = useDevicesQuery({ filters, search: params.search });

  return (
    <DevicesTable
      filters={tableFilters}
      onFilterChange={handleFilterChange}
      searchValue={localSearch}
      onSearchChange={setLocalSearch}
      onTagRemove={handleTagRemove}
      onClearAll={handleClearAll}
    />
  );
}

// Archive page: no default status filtering, scoped via lockedFilters elsewhere
function ArchivePage() {
  const { filters } = useDevicesUrlParams({ defaultStatuses: [] });

}
```
