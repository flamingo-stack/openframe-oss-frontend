# use-devices-url-params.ts

A React hook that synchronizes the Devices list UI state (search, filters, tags, view mode) with URL query parameters, providing a single source of truth for shareable/bookmarkable device list views across the main Devices page, Customer devices tab, and archive page.

## Key Components

- **`useDevicesUrlParams(options)`** — Main hook that manages URL-backed state for the devices list.
- **`UseDevicesUrlParamsOptions`** — Configuration interface:
  - `defaultStatuses` — Default status filter (defaults to `DEFAULT_DEVICES_LIST_STATUSES`); pass `[]` for archive-style pages with no default filtering.
  - `directoryColumns` — Enables `userLinks`/`directorySources` params when the consuming list renders USER/SOURCES columns.
- **Status normalization** — `normalizeStatuses`/`effectiveStatuses` collapse a fully-selected default status set to `[]` in the URL, while still applying defaults to the actual API query.
- **Returned API**:
  - `params` — Normalized, read-ready URL params.
  - `filters` — `DeviceFilterInput` object ready for GraphQL/API calls.
  - `tableFilters` — Flattened shape for table column filter UI.
  - `tagOptions` — Tag values mapped to `TagSearchOption` for search components.
  - `handleFilterChange`, `handleTagRemove`, `handleClearAll` — Event handlers for filter UI interactions.
  - `localSearch`, `setLocalSearch`, `debouncedSearch` — Responsive search input state, debounced into the URL.

## Usage Example

```typescript
import { useDevicesUrlParams } from '@/app/hooks/use-devices-url-params';

function DevicesPage() {
  const {
    params,
    filters,
    tableFilters,
    localSearch,
    setLocalSearch,
    handleFilterChange,
    handleTagRemove,
    handleClearAll,
  } = useDevicesUrlParams({ directoryColumns: true });

  const { data } = useDevicesQuery({ variables: { filters, search: params.search } });

  return (
    <DevicesTable
      data={data}
      searchValue={localSearch}
      onSearchChange={setLocalSearch}
      activeFilters={tableFilters}
      onFilterChange={handleFilterChange}
      onTagRemove={handleTagRemove}
      onClearAll={handleClearAll}
    />
  );
}

// Archive page: no default status filtering
function ArchivedDevicesPage() {
  const { filters } = useDevicesUrlParams({ defaultStatuses: [] });
  // filters.statuses is omitted entirely unless user explicitly selects some
}
```
