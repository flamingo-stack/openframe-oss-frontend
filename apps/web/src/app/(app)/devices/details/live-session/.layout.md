This file defines Next.js metadata and re-exports a shared layout component for the "Live Session" route, ensuring the browser tab title is set consistently with other app routes.

## Key Components

- **`metadata`** — A statically exported `Metadata` object (Next.js convention) that sets the page title using the `routeTitle` helper, producing a formatted title string for the "Live Session" page.
- **Default export** — Re-exports the default export from `@/app/(app)/route-title-layout`, reusing a shared layout component rather than defining a new one.

## Usage Example

This file is automatically picked up by the Next.js App Router as the `layout.tsx` for its route segment. Developers typically don't import it directly; instead, Next.js uses it to wrap pages within this route and apply the exported `metadata`.

```typescript
// Example of the shared helper used here
// lib/route-title.ts
export function routeTitle(title: string): string {
  return `${title} | OpenFrame`;
}
```

```typescript
// Resulting behavior: any page under this route segment
// will render with document title "Live Session | OpenFrame"
// and inherit the layout defined in route-title-layout.tsx
```

For more context on the shared layout pattern, see [`route-title-layout`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/route-title-layout.tsx) in the repository.
