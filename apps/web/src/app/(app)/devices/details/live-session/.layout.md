Defines page metadata for the Live Session route and re-exports the shared route-title layout component to apply consistent page title formatting.

## Key Components

- **`metadata`**: A Next.js `Metadata` object that sets the document title using the `routeTitle` helper with `'Live Session'` as the page label.
- **Default export**: Re-exported from `@/app/(app)/route-title-layout`, providing the layout shell used to render the "Live Session" route along with its dynamic title.

## Usage Example

This file is a Next.js route segment layout and is used automatically by the framework's file-based routing system—it's not imported directly in application code.

```typescript
// Next.js automatically applies this layout to the
// "Live Session" route segment, setting the <title> tag
// via the exported `metadata` object.

// app/(app)/live-session/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Live Session') };
```

The `routeTitle` helper ensures the "Live Session" label is formatted consistently with the rest of the application's page titles (for example, appending a suffix like the app name), while the imported default layout component handles rendering the shared structure (headers, title display, etc.) for pages that need this pattern.
