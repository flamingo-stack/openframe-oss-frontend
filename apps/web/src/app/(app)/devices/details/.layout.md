Defines route-level metadata and layout export for the Device page within the application's route group, setting the browser tab title using a shared title formatting utility.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title to `routeTitle('Device')`, ensuring consistent title formatting across the app.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout` as this route segment's layout, avoiding duplicate layout logic.

## Usage Example

This file follows the Next.js App Router convention, where a `layout.tsx` file automatically applies to all pages within its route segment:

```typescript
// app/(app)/device/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Device') };
```

Next.js automatically picks up the `metadata` export to set the `<title>` tag, and the re-exported layout component wraps all child pages/components under the `device` route segment. To create a similar layout for another route, duplicate this pattern with a different title string, e.g. `routeTitle('Settings')`.

For the shared layout implementation, see [`route-title-layout.tsx`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/app/(app)/route-title-layout.tsx).
