Defines page metadata for the Device route and re-exports a shared layout component, following the Next.js App Router convention for route-level metadata configuration.

## Key Components

- **`metadata`** — A `Metadata` object (Next.js type) that sets the browser tab title for this route segment using the `routeTitle` helper, producing a consistent title format (e.g., `"Device | OpenFrame"`).
- **Default export** — Re-exported from `@/app/(app)/route-title-layout`, reusing a shared layout component rather than defining a new one. This keeps layout logic centralized while allowing each route to supply its own `metadata`.

## Usage Example

This file is a Next.js layout module and is not imported directly in application code. Next.js automatically applies it to all pages under the corresponding route segment:

```typescript
// Resulting behavior: any page rendered under this route segment
// will use the shared layout and display the title generated by:
import { routeTitle } from '@/lib/route-title';

export const metadata = { title: routeTitle('Device') };
// e.g., routeTitle('Device') -> "Device | OpenFrame"
```

To replicate this pattern for a new route, create a `layout.tsx` in the route's folder that re-exports the shared layout and sets a route-specific `metadata.title` via `routeTitle`.
