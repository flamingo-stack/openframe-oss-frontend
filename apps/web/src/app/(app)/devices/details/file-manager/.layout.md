Defines route-level metadata and layout for the File Manager page within the app's route group, using Next.js's metadata API to set the browser tab title.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title to `routeTitle('File Manager')`, ensuring consistent title formatting (e.g., with app name suffix/prefix) across the application.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, allowing this route segment to inherit common layout behavior (such as rendering the page title in the UI) without duplicating logic.

## Usage Example

This file is a Next.js layout file and is not imported directly; it's automatically picked up by the Next.js App Router for the File Manager route segment.

```typescript
// Equivalent conceptual usage - Next.js applies this automatically
// for any page under the File Manager route segment.

import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export const metadata: Metadata = { title: routeTitle('File Manager') };

// Layout component (re-exported from shared location)
export { default } from '@/app/(app)/route-title-layout';
```

**Note:** To add a similarly titled layout for another route, create a new `layout.tsx` following this pattern, passing the appropriate page name string to `routeTitle()`.
