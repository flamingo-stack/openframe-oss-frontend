# new-folder-modal.tsx

A controlled modal component for creating a new folder, built on top of the shared `SimpleModal` component. It provides a text input for the folder name and handles submission via button click or the Enter key.

## Key Components

- **`NewFolderModalProps`** — Interface defining the component's props:
  - `isOpen`: controls modal visibility
  - `folderName`: current value of the folder name input
  - `submitting`: disables inputs/buttons while a create request is in flight
  - `onChange`: callback fired when the input value changes
  - `onSubmit`: callback fired when the user confirms folder creation
  - `onClose`: callback fired when the modal is dismissed

- **`NewFolderModal`** — The main exported component. Renders a `SimpleModal` with:
  - A title ("Create New Folder")
  - An `Input` field bound to `folderName`
  - A footer with "Cancel" and "Create" buttons
  - A `keydown` listener (active only while open) that triggers submission on `Enter`, provided the form isn't currently submitting and `folderName` is non-empty

## Usage Example

```typescript
import { useState } from 'react';
import { NewFolderModal } from '@/app/components/shared/new-folder-modal';

function FolderToolbar() {
  const [isOpen, setIsOpen] = useState(false);
  const [folderName, setFolderName] = useState('');
  const [submitting, setSubmitting] = useState(false);

  const handleSubmit = async () => {
    setSubmitting(true);
    try {
      await createFolder(folderName);
      setIsOpen(false);
      setFolderName('');
    } finally {
      setSubmitting(false);
    }
  };

  return (
    <NewFolderModal
      isOpen={isOpen}
      folderName={folderName}
      submitting={submitting}
      onChange={setFolderName}
      onSubmit={handleSubmit}
      onClose={() => setIsOpen(false)}
    />
  );
}
```

**Notes:**
- The component is purely presentational/controlled — all state management (open/close, name value, submission status) must be handled by the parent.
- The Enter-key handler is scoped to the window and automatically cleaned up when the modal closes or unmounts, preventing duplicate listeners.
