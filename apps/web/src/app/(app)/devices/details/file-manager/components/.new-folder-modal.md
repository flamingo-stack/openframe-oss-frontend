A React modal component for creating a new folder, built on top of the shared `SimpleModal` component. It provides a text input for the folder name and supports submitting via the Enter key or a "Create" button.

## Key Components

- **`NewFolderModalProps`** — Interface defining the component's props:
  - `isOpen`: controls modal visibility
  - `folderName`: current value of the input field
  - `submitting`: disables inputs/buttons while a create request is in progress
  - `onChange`: callback fired when the input value changes
  - `onSubmit`: callback fired to trigger folder creation
  - `onClose`: callback fired to dismiss the modal

- **`NewFolderModal`** — The main component. Renders a `SimpleModal` with:
  - A title ("Create New Folder")
  - An auto-focused `Input` field bound to `folderName`
  - A footer with "Cancel" and "Create" buttons
  - A keyboard listener that submits the form when Enter is pressed (only while open, not submitting, and the name is non-empty)

## Usage Example

```typescript
'use client';

import { useState } from 'react';
import { NewFolderModal } from '@/app/components/shared/new-folder-modal';

export function FolderToolbar() {
  const [isOpen, setIsOpen] = useState(false);
  const [folderName, setFolderName] = useState('');
  const [submitting, setSubmitting] = useState(false);

  const handleSubmit = async () => {
    setSubmitting(true);
    try {
      await createFolder(folderName);
      setIsOpen(false);
      setFolderName('');
    } finally {
      setSubmitting(false);
    }
  };

  return (
    <>
      <button onClick={() => setIsOpen(true)}>New Folder</button>
      <NewFolderModal
        isOpen={isOpen}
        folderName={folderName}
        submitting={submitting}
        onChange={setFolderName}
        onSubmit={handleSubmit}
        onClose={() => setIsOpen(false)}
      />
    </>
  );
}
```

This component is intended for use within client-rendered sections of the app (`'use client'`) and expects the caller to manage all state (open/close, input value, submission lifecycle) externally.
