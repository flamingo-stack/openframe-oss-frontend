A React container component that manages a remote file manager interface for a MeshCentral-connected device, handling file navigation, upload/download progress, search, clipboard operations, and CRUD modals.

## Key Components

### `FileManagerContainer`

The primary exported component that wraps the `FileManager` UI with full state management and side effects.

**Props (`FileManagerContainerProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `deviceId` | `string` | Identifier for the target device |
| `meshcentralAgentId` | `string` | MeshCentral agent identifier for remote connection |
| `hostname` | `string?` | Display name for the device |
| `organizationName` | `string?` | Organization context (unused in render) |
| `className` | `string?` | Additional CSS classes |

**Key behaviours:**
- Delegates file system operations to `useMeshFileManager` hook
- Renders `FileManagerSkeleton` while disconnected or connecting
- Displays fixed-position upload/download progress bars with cancel buttons
- Registers global keyboard shortcuts: `Ctrl/Cmd+C` (copy), `Ctrl/Cmd+X` (cut), `Ctrl/Cmd+V` (paste), `Delete` (delete), `Escape` (deselect/clear clipboard)
- Manages three modal dialogs: `NewFolderModal`, `RenameItemModal`, `DeleteConfirmationModal`

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container';

export default function DeviceFilesPage({ params }) {
  return (
    <FileManagerContainer
      deviceId={params.deviceId}
      meshcentralAgentId="agent-abc123"
      hostname="DESKTOP-WORKSTATION"
      organizationName="Acme Corp"
    />
  );
}
```
