## File Manager Container

A client-side React component that renders a remote device's file browser (via MeshCentral), handling navigation, search, file operations (upload/download/rename/delete/copy/cut/paste), and modal dialogs, while managing connection and loading states.

## Key Components

- **`FileManagerContainer`** — Main component accepting `deviceId`, `meshcentralAgentId`, `deviceName`, `organizationName`, and `className` props. Orchestrates the file manager UI, connection lifecycle, and all user interactions.
- **`useMeshFileManager`** hook — Supplies file system state (files, currentPath, selectedFiles, connectionState), clipboard operations, and async actions (upload, download, rename, delete, search).
- **Keyboard shortcuts** — Handles `Ctrl/Cmd+C` (copy), `Ctrl/Cmd+X` (cut), `Ctrl/Cmd+V` (paste), `Delete`, and `Escape` for clipboard/selection management.
- **Modal dialogs** — `NewFolderModal`, `RenameItemModal`, and `DeleteConfirmationModal` manage create/rename/delete workflows with submission state tracking.
- **`held` loading state** — Computed flag that shows an empty, loading-state file manager while the remote connection is establishing or disconnected, avoiding flashes of stale content.
- **Upload/download progress indicators** — Fixed-position UI panels showing transfer progress with cancel controls.

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container';

export default function DeviceFileManagerPage() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-abc-456"
      deviceName="Workstation-01"
      organizationName="Acme Corp"
      className="h-screen"
    />
  );
}
```

The component is designed to be rendered within a page route for a specific device, requiring valid `deviceId` and `meshcentralAgentId` to establish the remote file system connection. It internally manages all file manager state via the `useMeshFileManager` hook and does not require additional prop-driven state management from the parent.
