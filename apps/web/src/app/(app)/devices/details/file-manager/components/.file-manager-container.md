# file-manager-container.tsx

Container component that renders a remote device's file manager UI, wiring together file browsing, search, upload/download, clipboard operations, and CRUD modals (new folder, rename, delete) backed by a MeshCentral-based remote file system connection.

## Key Components

- **`FileManagerContainer`** — Main exported component. Accepts `deviceId`, `meshcentralAgentId`, `deviceName`, `organizationName`, and `className` props. Renders a `PageLayout` wrapping the `FileManager` UI component, handling connection states (`disconnected`, `connecting`, `connected_to_server`, `connected_end_to_end`, `failed`) and surfacing a `LoadError` with retry on failed connections.
- **`PAGE_MIN_HEIGHT`** — Constant enforcing a minimum page height so the file list doesn't collapse to nothing on short viewports.
- **Data hook** — Uses `useMeshFileManager({ meshcentralAgentId, isRemote: true })` for all file system state and operations (navigation, upload/download, clipboard, search, rename/delete).
- **Modals** — Integrates `NewFolderModal`, `RenameItemModal`, and `DeleteConfirmationModal` (imported, invocation truncated in shown source) driven by local state (`isNewFolderModalOpen`, `renameContext`, `deleteContext`).
- **Keyboard shortcuts** — Global `keydown` listener supporting Ctrl/Cmd+C (copy), Ctrl/Cmd+X (cut), Ctrl/Cmd+V (paste), Delete, and Escape (deselect/clear clipboard).
- **Upload/download progress** — Displays a fixed-position progress panel with cancel action while an upload is in flight.

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container';

export default function DeviceFilesPage({ params }: { params: { deviceId: string } }) {
  return (
    <FileManagerContainer
      deviceId={params.deviceId}
      meshcentralAgentId="agent-123"
      deviceName="WORKSTATION-01"
      organizationName="Acme Corp"
      className="h-screen"
    />
  );
}
```

The component is intended for use within device detail routes (see `routes.devices.details`) where a MeshCentral agent ID is known, providing a full-featured remote file browser with loading, error, and interactive states handled internally.
