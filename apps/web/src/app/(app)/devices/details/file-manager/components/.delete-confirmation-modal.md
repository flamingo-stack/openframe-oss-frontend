A React client component that renders a confirmation modal for deleting one or more items, with dynamic messaging based on item count and keyboard shortcut support for quick confirmation.

## Key Components

- **`DeleteConfirmationModalProps`** — Interface defining the component's props: `isOpen`, `itemCount`, `submitting`, `onConfirm`, and `onClose`.
- **`DeleteConfirmationModal`** — The main exported component that wraps the shared `ConfirmDialog` component, providing delete-specific title/description text and an `Enter` keypress handler to trigger confirmation.

## Usage Example

```typescript
'use client';

import { useState } from 'react';
import { DeleteConfirmationModal } from '@/app/components/shared/delete-confirmation-modal';

export function ItemList() {
  const [isModalOpen, setModalOpen] = useState(false);
  const [isSubmitting, setSubmitting] = useState(false);
  const selectedCount = 3;

  const handleDelete = async () => {
    setSubmitting(true);
    await deleteSelectedItems();
    setSubmitting(false);
    setModalOpen(false);
  };

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Delete Selected</button>
      <DeleteConfirmationModal
        isOpen={isModalOpen}
        itemCount={selectedCount}
        submitting={isSubmitting}
        onConfirm={handleDelete}
        onClose={() => setModalOpen(false)}
      />
    </>
  );
}
```

## Notes

- Automatically pluralizes the title and description depending on whether `itemCount` is 1 or more.
- Listens for the `Enter` key while open to confirm deletion, unless `submitting` is `true`, preventing duplicate submissions.
- Delegates actual dialog rendering/styling to the shared `ConfirmDialog` component located at `app/components/shared/confirm-dialog`.
