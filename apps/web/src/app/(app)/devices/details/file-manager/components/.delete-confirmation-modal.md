A reusable modal component for confirming deletion of one or more items, built on top of `ConfirmDialog` with keyboard shortcut support (`Enter` to confirm).

## Key Components

- **`DeleteConfirmationModal`** — Client component that renders a destructive confirmation dialog with dynamic title and description based on the number of items being deleted.
- **`DeleteConfirmationModalProps`** — Interface defining:
  - `isOpen` — controls dialog visibility
  - `itemCount` — drives singular/plural copy
  - `submitting` — disables `Enter` key confirm and shows a pending label
  - `onConfirm` / `onClose` — action callbacks
- **`useEffect` keyboard handler** — Attaches a `keydown` listener when the modal is open, triggering `onConfirm` on `Enter` unless a submission is already in progress. Cleans up automatically on close.

## Usage Example

```typescript
import { DeleteConfirmationModal } from './delete-confirmation-modal';

function MyList() {
  const [isOpen, setIsOpen] = useState(false);
  const [submitting, setSubmitting] = useState(false);

  const handleConfirm = async () => {
    setSubmitting(true);
    await deleteSelectedItems();
    setSubmitting(false);
    setIsOpen(false);
  };

  return (
    <DeleteConfirmationModal
      isOpen={isOpen}
      itemCount={3}
      submitting={submitting}
      onConfirm={handleConfirm}
      onClose={() => setIsOpen(false)}
    />
  );
}
```

> **Note:** The `Enter` key shortcut is automatically disabled while `submitting` is `true` to prevent duplicate submissions.
