A React client component that renders a confirmation modal for deleting one or more items, wrapping a shared `ConfirmDialog` with delete-specific messaging and keyboard support.

## Key Components

- **`DeleteConfirmationModalProps`** — Interface defining the component's props: `isOpen`, `itemCount`, `submitting`, `onConfirm`, `onClose`.
- **`DeleteConfirmationModal`** — Functional component that:
  - Dynamically generates a singular/plural title and description based on `itemCount`.
  - Listens for the `Enter` key while the modal is open (and not submitting) to trigger `onConfirm`.
  - Delegates rendering and open/close behavior to `ConfirmDialog`, passing destructive styling and pending-state labels.

## Usage Example

```typescript
import { useState } from 'react';
import { DeleteConfirmationModal } from '@/app/components/.../delete-confirmation-modal';

export function ItemsList() {
  const [isModalOpen, setModalOpen] = useState(false);
  const [isDeleting, setIsDeleting] = useState(false);
  const selectedItems = [/* ...selected items... */];

  const handleDelete = async () => {
    setIsDeleting(true);
    try {
      await deleteItems(selectedItems);
      setModalOpen(false);
    } finally {
      setIsDeleting(false);
    }
  };

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Delete Selected</button>

      <DeleteConfirmationModal
        isOpen={isModalOpen}
        itemCount={selectedItems.length}
        submitting={isDeleting}
        onConfirm={handleDelete}
        onClose={() => setModalOpen(false)}
      />
    </>
  );
}
```

**Notes:**
- Requires a `'use client'` boundary since it uses hooks (`useEffect`) and browser event listeners.
- Depends on the shared `ConfirmDialog` component at `@/app/components/shared/confirm-dialog`.
- Pressing `Enter` while the dialog is open triggers confirmation unless `submitting` is `true`, preventing duplicate submissions.
