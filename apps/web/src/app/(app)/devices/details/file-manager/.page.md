# File Manager Page

Next.js page component that renders the remote file manager interface for a specific device, handling MeshCentral connection validation, loading states, and error recovery before delegating to the `FileManagerContainer`.

## Key Components

- **`FileManagerPage`** (default export) — Client component rendering the file manager view for a device identified by the `id` query parameter.
- **`PAGE_PADDING`** — Shared horizontal padding constant applied to the page layout and content container.

### Behavior

- Reads `deviceId` from URL search params and fetches device details via `useDeviceDetails` (polling disabled).
- Resolves the MeshCentral tool connection state and derives an `agentToolId` only when the connection is `'live'`.
- Registers the device as the active Mingo "open view" via `useTrackOpenView`, since the parent detail page unmounts on navigation.
- Renders an **error state** (with a "Return to Device Details" action) if device data fails to load.
- Renders a **blocked state** when MeshCentral is unavailable, using `getMeshCentralBlockedCopy` for contextual title/description text.
- Otherwise wraps `FileManagerContainer` in `LoadingWhen` to show a loading scope while device data resolves, without blocking the file manager from rendering its own internal loading state.

## Usage Example

This page is routed via Next.js file-based routing and expects a `id` query parameter:

```typescript
// Navigated to via:
// /devices/details/file-manager?id=<deviceId>

// Internally relies on:
const deviceId = useSearchParams().get('id') ?? '';
const { deviceDetails, isLoading, error } = useDeviceDetails(deviceId, { polling: false });
```

Back navigation uses `useSafeBack` to fall back to the device details route:

```typescript
const handleBack = useSafeBack(routes.devices.details(deviceId));
```

## Notes

- No approval gate is applied here (unlike remote screen sessions) — file manager access auto-starts once a live MeshCentral `agentToolId` is available.
- Hook calls (`useTrackOpenView`) are placed above all early returns to preserve stable hook ordering across render branches.
