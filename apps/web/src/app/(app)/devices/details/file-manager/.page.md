Next.js page component that renders the remote File Manager surface for a device, resolving the device's MeshCentral agent connection and handling loading, error, and blocked-connection states before mounting the file browser UI.

## Key Components

- **`FileManagerPage`** (default export) — Client component (`'use client'`) rendered for the file manager route. Reads the `id` query param via `useSearchParams` to identify the device.
- **Device resolution** — Uses `useDeviceDetails(deviceId, { polling: false })` to fetch device details without polling, then extracts the MeshCentral tool connection via `getToolConnection` and `getToolConnectionState`.
- **Mingo context tracking** — Calls `useTrackOpenView` to register the device as the active "open view" entity (`CONTEXT_ENTITY_KIND.DEVICE`) so Mingo retains context when the parent detail page unmounts.
- **State handling**:
  - Error state: shows an error message with a "Return to Device Details" button if `useDeviceDetails` fails.
  - Blocked connection state: if no live MeshCentral agent is available, shows contextual copy from `getMeshCentralBlockedCopy`.
  - Loading state: wraps the main content in `LoadingWhen` while device details load.
- **`FileManagerContainer`** — The actual file manager UI, rendered once a valid `meshcentralAgentId` is available, receiving `deviceId`, `meshcentralAgentId`, and `deviceName`.
- **`PAGE_PADDING`** — Shared horizontal padding constant applied consistently across all render branches.

## Usage Example

```typescript
// Accessed via route, e.g.:
// /devices/details/file-manager?id=<deviceId>

// The page automatically:
// 1. Resolves deviceId from the `id` search param
// 2. Fetches device details and MeshCentral connection state
// 3. Renders error / blocked / loading / ready states accordingly

export default function FileManagerPage() {
  // ...resolves deviceId, deviceDetails, meshcentralAgentId
  return (
    <LoadingWhen loading={isLoading}>
      <FileManagerContainer
        deviceId={deviceId}
        meshcentralAgentId={meshcentralAgentId ?? ''}
        deviceName={deviceName}
        className={PAGE_PADDING}
      />
    </LoadingWhen>
  );
}
```

Navigation back to device details is handled via `useSafeBack(routes.devices.details(deviceId))`, ensuring a consistent back-button experience across all render states.
