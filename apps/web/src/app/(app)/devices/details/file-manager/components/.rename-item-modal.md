# RenameItemModal

A controlled modal component for renaming an item, built on top of `SimpleModal`. It provides a text input with autofocus, Enter-key submission, and loading state handling while a rename operation is in progress.

## Key Components

- **`RenameItemModal`** — Functional component that renders a modal dialog with a title, descriptive text, an input field for the new name, and Cancel/Rename action buttons.
- **`RenameItemModalProps`** — Props interface controlling visibility (`isOpen`), the current input `value`, submission state (`submitting`), and callback handlers (`onChange`, `onSubmit`, `onClose`).
- **Enter-key handling** — A `useEffect` hook attaches a global `keydown` listener while the modal is open, triggering `onSubmit` when Enter is pressed (unless the value is empty or a submission is already in progress).

## Usage Example

```typescript
import { useState } from 'react';
import { RenameItemModal } from '@/app/components/shared/rename-item-modal';

function ItemList() {
  const [isModalOpen, setIsModalOpen] = useState(false);
  const [newName, setNewName] = useState('');
  const [isSubmitting, setIsSubmitting] = useState(false);

  const handleRename = async () => {
    setIsSubmitting(true);
    try {
      await renameItemOnServer(newName);
      setIsModalOpen(false);
    } finally {
      setIsSubmitting(false);
    }
  };

  return (
    <RenameItemModal
      isOpen={isModalOpen}
      value={newName}
      submitting={isSubmitting}
      onChange={setNewName}
      onSubmit={handleRename}
      onClose={() => setIsModalOpen(false)}
    />
  );
}
```

## Notes

- The Rename button is disabled when the trimmed value is empty or while `submitting` is `true`.
- The modal relies on the shared `SimpleModal` component for layout, overlay, and close behavior.
- Button text toggles to `"Renaming..."` during submission to provide user feedback.
