A modal dialog component for renaming items, built on `SimpleModal` with keyboard (Enter key) and button submission support.

## Key Components

### `RenameItemModal`

A controlled modal component that manages the rename workflow:

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `value` | `string` | Current input value |
| `submitting` | `boolean` | Disables controls and shows loading state during submission |
| `onChange` | `(value: string) => void` | Fires on input change |
| `onSubmit` | `() => void` | Fires on confirmation (button click or Enter key) |
| `onClose` | `() => void` | Fires on cancel or modal dismiss |

**Behaviors:**
- Listens for `Enter` keydown globally when open; submits only if `value` is non-empty and not already submitting
- Auto-focuses the input on open via `autoFocus`
- Submit button is disabled when `value` is blank or `submitting` is `true`
- Cleans up the keydown listener on close or unmount

## Usage Example

```typescript
import { RenameItemModal } from '@/app/components/shared/rename-item-modal';

function MyComponent() {
  const [isOpen, setIsOpen] = useState(false);
  const [name, setName] = useState('');
  const [submitting, setSubmitting] = useState(false);

  const handleSubmit = async () => {
    setSubmitting(true);
    await renameItem(name);
    setSubmitting(false);
    setIsOpen(false);
  };

  return (
    <RenameItemModal
      isOpen={isOpen}
      value={name}
      submitting={submitting}
      onChange={setName}
      onSubmit={handleSubmit}
      onClose={() => setIsOpen(false)}
    />
  );
}
```
