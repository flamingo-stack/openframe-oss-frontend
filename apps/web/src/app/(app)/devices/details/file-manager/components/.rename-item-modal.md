A controlled modal component for renaming an item, providing a text input with keyboard (Enter-to-submit) support and a footer with Cancel/Rename actions.

## Key Components

- **`RenameItemModal`** — React functional component that renders a `SimpleModal` containing an `Input` for the new name and a footer with `Cancel` and `Rename` buttons.
- **`RenameItemModalProps`** — Props interface controlling modal visibility (`isOpen`), the current input `value`, loading state (`submitting`), and callback handlers (`onChange`, `onSubmit`, `onClose`).
- **Enter-key handler** — A `useEffect` hook that listens for the `Enter` keydown event while the modal is open, triggering `onSubmit` when the trimmed value is non-empty and the form isn't already submitting.

## Usage Example

```typescript
import { useState } from 'react';
import { RenameItemModal } from '@/app/components/shared/rename-item-modal';

function ItemList() {
  const [isOpen, setIsOpen] = useState(false);
  const [name, setName] = useState('');
  const [submitting, setSubmitting] = useState(false);

  const handleRename = async () => {
    setSubmitting(true);
    try {
      await renameItemOnServer(name);
      setIsOpen(false);
    } finally {
      setSubmitting(false);
    }
  };

  return (
    <RenameItemModal
      isOpen={isOpen}
      value={name}
      submitting={submitting}
      onChange={setName}
      onSubmit={handleRename}
      onClose={() => setIsOpen(false)}
    />
  );
}
```

The component is intentionally stateless regarding the input value—parent components own `value` and `submitting` state, making it easy to reuse across different "rename" flows (e.g., renaming devices, tags, or folders) while keeping submission logic (API calls, validation) outside the modal itself.
