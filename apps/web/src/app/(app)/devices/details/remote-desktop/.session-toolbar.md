Renders the floating, auto-hiding overlay toolbar displayed on top of a remote-desktop session stream, providing device info, display switching, viewer presence, and quick actions (chat, fullscreen, settings).

## Key Components

- **`SessionToolbar`** — React component that renders the session toolbar overlay. Shows the device name, an optional display switcher dropdown, a list of current remote-session viewers, an actions menu, and icon buttons for chat toggle, fullscreen toggle, and settings.
- **`SessionToolbarProps`** — Props interface controlling toolbar content and behavior:
  - `deviceName`, `displayMenuGroups`, `currentDisplayLabel`, `actionsMenuGroups` — core content/menu configuration.
  - `fullscreen`, `onToggleFullscreen` — fullscreen state and toggle handler (shows dimmed `OpenframeLogoIcon` in the corner when fullscreen).
  - `chatOpen`, `chatUnread`, `onToggleChat` — optional chat toggle button with unread indicator (`UnreadDot`); omitted entirely when `onToggleChat` is not provided.
  - `viewers` — list of `RemoteSessionViewer`s rendered via `RemoteSessionViewers`.
  - `visible`, `hold` — support for auto-hide behavior; the bar stays mounted but slides out of view when `visible` is `false`, and `hold(key, held)` is called on hover/focus/menu-open events to keep it visible while interacted with.

## Usage Example

```typescript
import { SessionToolbar } from './session-toolbar';

function RemoteSessionView() {
  return (
    <SessionToolbar
      deviceName="DESKTOP-ABC123"
      displayMenuGroups={displayGroups}
      currentDisplayLabel="Display 1"
      actionsMenuGroups={actionGroups}
      onOpenSettings={() => setSettingsOpen(true)}
      fullscreen={isFullscreen}
      onToggleFullscreen={() => setIsFullscreen(v => !v)}
      chatOpen={chatOpen}
      chatUnread={hasUnreadChat}
      onToggleChat={() => setChatOpen(v => !v)}
      viewers={remoteViewers}
      visible={toolbarVisible}
      hold={holdToolbarVisible}
    />
  );
}
```

The `hold` callback is typically supplied by a `useAutoHideToolbar`-style hook that tracks hover, focus, and open submenus to decide when the bar should remain visible versus auto-hide.
