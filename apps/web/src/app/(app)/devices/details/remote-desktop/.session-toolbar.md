A floating overlay toolbar rendered on top of a remote-desktop session stream, providing device info, display switching, viewer presence, and quick-action controls (actions menu, chat, fullscreen, settings).

## Key Components

- **`SessionToolbar`** — The main exported component. Renders a semi-transparent bar centered at the top of the session container, plus a dimmed OpenFrame logo in the top-left corner when in fullscreen mode.
- **`SessionToolbarProps`** — Props interface controlling the device name, display/actions menus, fullscreen and chat state, connected viewers, and visibility/auto-hide behavior.
- **Auto-hide hold logic** — Internal `useEffect` and `onViewersOpenChange` handler that release the toolbar's "held" state (via the `hold` callback) when the viewers menu closes because the viewers list became empty, ensuring the bar doesn't get stuck visible without an explicit close.

## Usage Example

```typescript
import { SessionToolbar } from './session-toolbar';

function RemoteSessionOverlay() {
  const [fullscreen, setFullscreen] = useState(false);
  const [chatOpen, setChatOpen] = useState(false);

  return (
    <SessionToolbar
      deviceName="DESKTOP-ACME01"
      displayMenuGroups={displayGroups}
      currentDisplayLabel="Display 1"
      actionsMenuGroups={actionGroups}
      onOpenSettings={() => setSettingsOpen(true)}
      fullscreen={fullscreen}
      onToggleFullscreen={() => setFullscreen(f => !f)}
      chatOpen={chatOpen}
      chatUnread={hasUnreadMessages}
      onToggleChat={() => setChatOpen(o => !o)}
      viewers={activeViewers}
      visible={toolbarVisible}
      hold={holdToolbarVisible}
    />
  );
}
```

Typically used alongside a `useAutoHideToolbar`-style hook that supplies `visible` and `hold`, so pointer hover, keyboard focus, or an open dropdown menu keep the bar on screen, while otherwise it auto-hides over the stream.
