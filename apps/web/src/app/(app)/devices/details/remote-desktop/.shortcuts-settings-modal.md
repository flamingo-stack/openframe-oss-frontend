# shortcuts-settings-modal.tsx

A modal component for managing a customizable list of keyboard shortcuts used during remote sessions, allowing users to reorder, delete, and add new key combinations with modifier keys (Shift, Alt, Ctrl, Win).

## Key Components

- **`ShortcutRow`** — Internal row component rendering a single shortcut with drag handle (or move buttons fallback), label, and delete button. Uses `useSortableItem` for drag-and-drop state.
- **`ShortcutsSettingsModal`** — Main exported modal component. Props:
  - `open: boolean` — controls modal visibility
  - `onOpenChange: (open: boolean) => void` — visibility change callback
  - `shortcuts: RemoteShortcut[]` — initial shortcut list
  - `onSave: (shortcuts: RemoteShortcut[]) => void` — called with the updated list on save
- **`MODIFIER_LABELS`** — Display labels mapping for `ShortcutModifier` values.

The component maintains a local `draft` copy of shortcuts (seeded from props) that supports reordering via `SortableList`, adding new combos via modifier checkboxes + key input, and removing entries. Validation uses `normalizeKeyToken` and duplicate-combo checks, surfacing errors via `useToast`. Changes are only committed to the parent via `onSave` when the user clicks "Save Shortcuts".

## Usage Example

```typescript
import { useState } from 'react';
import { ShortcutsSettingsModal } from './shortcuts-settings-modal';
import type { RemoteShortcut } from './remote-shortcuts';

function RemoteSessionToolbar() {
  const [open, setOpen] = useState(false);
  const [shortcuts, setShortcuts] = useState<RemoteShortcut[]>([
    { id: 'ctrl-alt-del', combo: 'ctrl+alt+Delete' },
  ]);

  return (
    <>
      <button onClick={() => setOpen(true)}>Edit Shortcuts</button>
      <ShortcutsSettingsModal
        open={open}
        onOpenChange={setOpen}
        shortcuts={shortcuts}
        onSave={setShortcuts}
      />
    </>
  );
}
```

**Note:** The modal should be mounted only while `open` is true, since the internal `draft` state seeds from the `shortcuts` prop solely on initial mount.
