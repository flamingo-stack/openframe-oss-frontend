# shortcuts-settings-modal.tsx

A React modal component that lets users manage a reorderable list of remote keyboard shortcuts, supporting drag-and-drop reordering, modifier key selection, and shortcut creation/deletion before persisting changes.

## Key Components

- **`ShortcutRow`** — Internal row component rendering a single shortcut entry with a drag handle (or move buttons when drag-and-drop is disabled), the shortcut's display label, and a delete button.
- **`ShortcutsSettingsModal`** — Main exported modal component. Manages a local draft copy of shortcuts (seeded from props), modifier checkbox state, and key input, exposing Save/Close actions.
- **`ShortcutsSettingsModalProps`** — Props interface: `open`, `onOpenChange`, `shortcuts: RemoteShortcut[]`, `onSave: (shortcuts: RemoteShortcut[]) => void`.
- **`MODIFIER_LABELS`** — Maps `ShortcutModifier` values (`shift`, `alt`, `ctrl`, `win`) to display labels.

The component depends on helpers from `./remote-shortcuts` (`buildCombo`, `comboLabel`, `normalizeKeyToken`, `SHORTCUT_MODIFIERS`) and shared UI primitives (`SortableList`, `SimpleModal`, `Checkbox`, `Input`, etc.) from `@flamingo-stack/openframe-frontend-core`.

## Usage Example

```typescript
import { useState } from 'react';
import { ShortcutsSettingsModal } from './shortcuts-settings-modal';
import type { RemoteShortcut } from './remote-shortcuts';

function RemoteSessionToolbar() {
  const [modalOpen, setModalOpen] = useState(false);
  const [shortcuts, setShortcuts] = useState<RemoteShortcut[]>([
    { id: 'custom-ctrl+alt+del', combo: 'ctrl+alt+del' },
  ]);

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Edit Shortcuts</button>
      <ShortcutsSettingsModal
        open={modalOpen}
        onOpenChange={setModalOpen}
        shortcuts={shortcuts}
        onSave={setShortcuts}
      />
    </>
  );
}
```

Notes:
- The modal should only be mounted while `open` is `true`, since the draft list seeds from `shortcuts` on mount and local edits are discarded if the modal is closed without saving.
- Invalid keys or duplicate combos trigger a toast notification instead of being added to the draft list.
