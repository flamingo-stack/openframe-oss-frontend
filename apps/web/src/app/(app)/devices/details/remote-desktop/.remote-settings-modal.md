A modal component for configuring MeshCentral remote desktop session settings, including quality, scaling, frame rate, and input behavior preferences (mouse, scroll, keyboard, toolbar auto-hide).

## Key Components

- **`RemoteSettingsModal`** - React component rendering a settings dialog for an active remote desktop session, built on `SimpleModal`.
- **`RemoteSettingsModalProps`** - Props interface requiring the modal's open state, current `RemoteSettingsConfig`, refs to the active `MeshDesktop`/`MeshTunnel` instances, connection state, and callbacks for settings and toolbar auto-hide changes.
- **`handleSaveSettings`** - Validates the tunnel connection is active (`connectionState === 3`), applies settings via `RemoteDesktopSettings`, pushes mouse/keyboard/scroll overrides to the live `MeshDesktop` instance, and shows a toast with the estimated bandwidth impact.
- **`handleClose`** - Reverts local state to `currentSettings` and closes the modal without saving.

## Usage Example

```typescript
import { useRef, useState } from 'react';
import { RemoteSettingsModal } from '@/app/components/remote-settings-modal';
import type { RemoteSettingsConfig } from '@/lib/meshcentral/remote-settings';
import type { MeshDesktop } from '@/lib/meshcentral/meshcentral-desktop';
import type { MeshTunnel } from '@/lib/meshcentral/meshcentral-tunnel';

function RemoteSessionControls() {
  const [open, setOpen] = useState(false);
  const [autoHideToolbar, setAutoHideToolbar] = useState(false);
  const [settings, setSettings] = useState<RemoteSettingsConfig>(defaultSettings);
  const desktopRef = useRef<MeshDesktop | null>(null);
  const tunnelRef = useRef<MeshTunnel | null>(null);

  return (
    <RemoteSettingsModal
      open={open}
      onOpenChange={setOpen}
      currentSettings={settings}
      desktopRef={desktopRef}
      tunnelRef={tunnelRef}
      connectionState={3}
      onSettingsChange={setSettings}
      autoHideToolbar={autoHideToolbar}
      onAutoHideToolbarChange={setAutoHideToolbar}
    />
  );
}
```

Note: Settings are only applied while connected (`connectionState === 3`); the toolbar auto-hide toggle is a viewer-only preference that applies instantly and is independent of the Save/Close actions.
