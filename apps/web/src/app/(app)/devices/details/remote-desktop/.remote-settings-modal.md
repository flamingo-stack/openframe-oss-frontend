# remote-settings-modal.tsx

A modal dialog component that lets users configure remote desktop session settings (quality, scaling, frame rate, mouse/keyboard behavior) for an active MeshCentral remote control session.

## Key Components

- **`RemoteSettingsModal`** - The main exported React component rendering the settings modal.
- **`RemoteSettingsModalProps`** - Props interface requiring modal visibility state, current settings, refs to the active `MeshDesktop` and `MeshTunnel` instances, connection state, and callbacks for settings/toolbar changes.
- **`handleSaveSettings`** - Validates that the remote connection is established (`connectionState === 3`), applies settings via `RemoteDesktopSettings`, pushes mouse/keyboard overrides directly to `desktopRef`, and shows toast feedback (including estimated bandwidth).
- **`handleClose`** - Reverts local state to `currentSettings` and closes the modal without persisting changes.
- Live sync logic (render-time state adoption) keeps the local `settings` state in sync whenever `currentSettings` changes from the parent, avoiding a stale first render that an effect-based approach would cause.

The UI is organized into:
- Quality / Scaling dropdowns (grid row)
- Frame Rate dropdown
- Checkboxes for Invert Scroll Direction, Swap Mouse Buttons, Use Remote Keyboard Map
- A separate **Auto-hide Toolbar** checkbox - a viewer-only preference applied immediately (not part of Save/Close), toggled via `onAutoHideToolbarChange`.

## Usage Example

```typescript
import { RemoteSettingsModal } from './remote-settings-modal';
import { useState, useRef } from 'react';

function RemoteSessionControls() {
  const [open, setOpen] = useState(false);
  const [autoHide, setAutoHide] = useState(false);
  const desktopRef = useRef<MeshDesktop | null>(null);
  const tunnelRef = useRef<MeshTunnel | null>(null);
  const [settings, setSettings] = useState<RemoteSettingsConfig>(defaultSettings);

  return (
    <RemoteSettingsModal
      open={open}
      onOpenChange={setOpen}
      currentSettings={settings}
      desktopRef={desktopRef}
      tunnelRef={tunnelRef}
      connectionState={3}
      onSettingsChange={setSettings}
      autoHideToolbar={autoHide}
      onAutoHideToolbarChange={setAutoHide}
    />
  );
}
```
