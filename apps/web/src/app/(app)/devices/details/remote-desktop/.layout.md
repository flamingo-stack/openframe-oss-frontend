Defines the route metadata and layout wrapper for the Remote Desktop page in the Next.js App Router, setting the browser tab title and delegating rendering to a shared layout component.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title using `routeTitle('Remote Desktop')`, ensuring consistent title formatting across the app.
- **`default export`** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, which handles the common layout structure (e.g., title display, wrapping) for routes using this pattern.

## Usage Example

This file is a Next.js layout file and is automatically picked up by the framework based on its location in the route segment (e.g., `app/(app)/remote-desktop/layout.tsx`). It is not imported directly elsewhere.

```typescript
// Next.js automatically applies this layout to all pages
// within the same route segment, e.g.:
// app/(app)/remote-desktop/page.tsx

// The exported metadata sets the document title:
// <title>Remote Desktop | Your App Name</title>

// The default export wraps child pages with the shared layout:
export { default } from '@/app/(app)/route-title-layout';
```

## Notes

- Relies on `routeTitle` from `@/lib/route-title` to generate a standardized page title string, likely appending a common suffix (e.g., app name) to `'Remote Desktop'`.
- Keeps the layout logic centralized in `route-title-layout`, promoting reuse across multiple route segments that only need to customize the page title.
