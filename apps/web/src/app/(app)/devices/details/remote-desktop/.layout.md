This file defines the Next.js metadata configuration and layout export for the Remote Desktop route, ensuring the browser tab title is dynamically generated using the shared route title utility.

## Key Components

- **`metadata`** — A statically exported `Metadata` object conforming to Next.js's App Router convention, used to set the document title for this route segment. The title is generated via `routeTitle('Remote Desktop')`.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, which likely renders a consistent layout shell (e.g., header with the page title) across routes.

## Usage Example

This file is automatically picked up by Next.js as a route segment layout (`layout.tsx`). You don't import it directly; instead, place it alongside a `page.tsx` within the corresponding route folder:

```typescript
// app/(app)/remote-desktop/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Remote Desktop') };
```

Next.js will automatically apply this layout and metadata to all pages nested under the `remote-desktop` route segment, setting the browser tab title accordingly (e.g., `"Remote Desktop | OpenFrame"` depending on the `routeTitle` implementation).

For more context on the shared layout, see [`route-title-layout.tsx`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/route-title-layout.tsx).
