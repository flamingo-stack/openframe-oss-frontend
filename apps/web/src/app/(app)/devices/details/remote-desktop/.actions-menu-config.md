Defines the configuration builder for the remote session actions menu, producing grouped menu items for applying keyboard shortcuts, sending power actions, and toggling input/clipboard settings during a remote device session.

## Key Components

- **`ActionHandlers`** — Interface describing the callback functions the menu depends on: sending shortcuts, opening the shortcuts manager, sending power commands, toggling input/clipboard state, and showing toast notifications.
- **`createActionsMenuGroups`** — Factory function that builds an array of `ActionsMenuGroup` objects (from `@flamingo-stack/openframe-frontend-core`) based on current state (`enableInput`, `clipboardEnabled`, `shortcuts`) and the provided `ActionHandlers`. Returns three groups:
  - **Shortcuts group** — A submenu with a "Manage Shortcuts" entry plus one entry per `RemoteShortcut`, each triggering `sendShortcut`.
  - **Power group** — Wake, Sleep, Reboot, and Shut Down actions, each mapped to `sendPower` with the corresponding action string.
  - **Settings group** — Checkbox items for toggling `enableInput` and `clipboardEnabled`.

## Usage Example

```typescript
import { createActionsMenuGroups, type ActionHandlers } from './actions-menu-config';

const handlers: ActionHandlers = {
  sendShortcut: (combo) => console.log('Sending shortcut', combo),
  openShortcutsManager: () => setShortcutsManagerOpen(true),
  sendPower: (action) => console.log('Power action', action),
  setEnableInput: (enabled) => setEnableInput(enabled),
  setClipboardEnabled: (enabled) => setClipboardEnabled(enabled),
  toast: ({ title, description, variant }) => showToast(title, description, variant),
};

const menuGroups = createActionsMenuGroups(
  handlers,
  enableInput,
  clipboardEnabled,
  remoteShortcuts,
);

// Pass `menuGroups` to the ActionsMenu UI component for rendering
<ActionsMenu groups={menuGroups} />
```

This configuration is typically consumed by a remote desktop/session toolbar component to render a dropdown or context menu with grouped, separated sections.
