Builds the configuration for a remote-session actions menu, grouping keyboard shortcuts, power controls, and input/clipboard toggles into a structured menu definition consumed by the `ActionsMenuGroup` UI component.

## Key Components

- **`ActionHandlers`** — Interface defining the callback contract required to drive the menu: sending keyboard shortcuts, opening the shortcuts manager, issuing power actions (`wake`/`sleep`/`reset`/`poweroff`), toggling input/clipboard sharing, and showing toast notifications.
- **`createActionsMenuGroups`** — Factory function that assembles an array of `ActionsMenuGroup` objects based on current state (`enableInput`, `clipboardEnabled`, `shortcuts`) and the provided `ActionHandlers`. Returns three groups:
  - **Shortcuts group**: A submenu containing "Manage Shortcuts" plus one entry per `RemoteShortcut`, each labeled via `comboLabel`.
  - **Power group**: Wake up, Sleep, Reboot, and Shut Down actions, each mapped to `handlers.sendPower`.
  - **Toggles group**: Checkbox items for "Enable Input" and "Clipboard Sharing" reflecting current boolean state.

## Usage Example

```typescript
import { createActionsMenuGroups, type ActionHandlers } from './actions-menu-config';

const handlers: ActionHandlers = {
  sendShortcut: (combo) => session.sendKeys(combo),
  openShortcutsManager: () => setShortcutsManagerOpen(true),
  sendPower: (action) => session.power(action),
  setEnableInput: (enabled) => setInputEnabled(enabled),
  setClipboardEnabled: (enabled) => setClipboardEnabled(enabled),
  toast: ({ title, description, variant }) => showToast(title, description, variant),
};

const menuGroups = createActionsMenuGroups(
  handlers,
  inputEnabled,
  clipboardEnabled,
  savedShortcuts,
);

// Pass `menuGroups` into the ActionsMenu component for rendering
<ActionsMenu groups={menuGroups} />
```
