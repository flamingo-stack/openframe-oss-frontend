Defines the configuration and structure for the remote desktop actions menu, including keyboard shortcuts, power management controls, and input/clipboard toggles.

## Key Components

- **`VK`** — Constant map of Windows Virtual-Key codes used when constructing key combination payloads.
- **`ActionHandlers`** — Interface defining the callback contract required by the menu (key combos, power actions, input/clipboard toggling, and toast notifications).
- **`createActionsMenuGroups`** — Factory function that accepts handler callbacks and current toggle states, returning a structured `ActionsMenuGroup[]` array for rendering the actions menu.

The returned menu is organized into three separator-delimited groups:
1. **Shortcuts** — A submenu with common Windows key combos (e.g. `Ctrl+Alt+Del`, `Win+L`, `Win+R`).
2. **Power** — Wake, Sleep, Reboot, and Shut Down actions.
3. **Toggles** — Checkbox items for enabling/disabling input and clipboard sharing.

## Usage Example

```typescript
import { createActionsMenuGroups, ActionHandlers } from './actions-menu-config';

const handlers: ActionHandlers = {
  sendCtrlAltDel: () => sendKeyEvent('ctrl-alt-del'),
  sendKeyCombo: (keys) => sendKeyEvent(keys),
  sendPower: (action) => invokeAgentPower(action),
  setEnableInput: (enabled) => dispatch(setInput(enabled)),
  setClipboardEnabled: (enabled) => dispatch(setClipboard(enabled)),
  toast: ({ title, description, variant }) => showToast({ title, description, variant }),
};

const groups = createActionsMenuGroups(handlers, enableInput, clipboardEnabled);
// Pass `groups` to your <ActionsMenu> component
```
