React hook implementing auto-hide behavior for the remote-session overlay toolbar, showing it on mount, hiding it after an idle delay, and revealing it again via a hot-zone dwell on the top edge of the stream or through declarative "hold" states.

## Key Components

- **`REMOTE_TOOLBAR_AUTO_HIDE_STORAGE_KEY`** - `useLocalStorage` key for persisting the user's auto-hide preference.
- **`TOOLBAR_HOT_ZONE_PX`** - pixel height of the top-edge zone that triggers toolbar reveal.
- **`TOOLBAR_REVEAL_DWELL_MS`** - dwell time the pointer must stay in the hot zone before revealing (prevents accidental reveal from a pass-through click on a remote window's title bar).
- **`TOOLBAR_HIDE_DELAY_MS`** - idle delay before the toolbar hides after the pointer leaves it.
- **`AutoHideToolbar`** - interface returned by the hook: `visible`, `reveal()`, `hold(key, held)`, `onPointerMove`, `onPointerLeave`.
- **`useAutoHideToolbar(enabled, pinned?)`** - the hook itself. When `enabled` is `false`, the toolbar is always visible. `pinned` acts as a declarative hold tied to external state (e.g., an open settings modal or unread chat message).

## Usage Example

```typescript
import { useAutoHideToolbar } from './use-auto-hide-toolbar';

function RemoteSessionOverlay({ autoHideEnabled, isSettingsOpen }: {
  autoHideEnabled: boolean;
  isSettingsOpen: boolean;
}) {
  const toolbar = useAutoHideToolbar(autoHideEnabled, isSettingsOpen);

  return (
    <div
      className="remote-stream"
      onPointerMove={toolbar.onPointerMove}
      onPointerLeave={toolbar.onPointerLeave}
    >
      {toolbar.visible && (
        <div
          className="toolbar"
          onPointerEnter={() => toolbar.hold('hover', true)}
          onPointerLeave={() => toolbar.hold('hover', false)}
          onFocus={() => toolbar.hold('focus', true)}
          onBlur={() => toolbar.hold('focus', false)}
        >
          {/* toolbar buttons */}
        </div>
      )}
    </div>
  );
}
```

Each independent reason to keep the toolbar visible (hover, keyboard focus, open menu) should call `hold(key, true/false)` with a unique key; the hide countdown only starts once all holds are released.
