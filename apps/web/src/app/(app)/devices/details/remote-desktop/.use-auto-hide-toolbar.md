## useAutoHideToolbar

A React hook implementing auto-hide behavior for the remote-session overlay toolbar. Unlike typical "show on mouse move" patterns, it shows the toolbar on mount, hides it after a delay, and only reveals it again when the pointer dwells in a hot zone near the top edge of the stream (or via explicit `hold()` calls) — avoiding false reveals caused by constant mouse movement during a remote session.

## Key Components

- **`useAutoHideToolbar(enabled, pinned?)`** — Main hook returning an `AutoHideToolbar` object.
- **`AutoHideToolbar`** interface:
  - `visible` — whether the toolbar should currently render.
  - `reveal()` — show the toolbar and restart the idle countdown.
  - `hold(key, held)` — keep the toolbar visible while any key is held (e.g. pointer over it, menu open, unread chat).
  - `onPointerMove` / `onPointerLeave` — pointer handlers to attach to the stream element for hot-zone detection.
- **Constants**:
  - `REMOTE_TOOLBAR_AUTO_HIDE_STORAGE_KEY` — `localStorage` key for the auto-hide preference.
  - `TOOLBAR_HOT_ZONE_PX` — pixel height of the top-edge reveal zone.
  - `TOOLBAR_REVEAL_DWELL_MS` — dwell time before hot-zone hover reveals the toolbar.
  - `TOOLBAR_HIDE_DELAY_MS` — idle delay before the toolbar hides.

## Usage Example

```typescript
import { useAutoHideToolbar } from './use-auto-hide-toolbar';

function RemoteSessionView({ settingsOpen, hasUnreadChat }: Props) {
  const toolbar = useAutoHideToolbar(
    /* enabled */ true,
    /* pinned */ settingsOpen || hasUnreadChat
  );

  return (
    <div
      onPointerMove={toolbar.onPointerMove}
      onPointerLeave={toolbar.onPointerLeave}
    >
      {toolbar.visible && (
        <div
          className="toolbar"
          onPointerEnter={() => toolbar.hold('pointer', true)}
          onPointerLeave={() => toolbar.hold('pointer', false)}
        >
          {/* toolbar buttons */}
        </div>
      )}
      {/* remote stream content */}
    </div>
  );
}
```

Use `hold('focus', true/false)` on keyboard focus/blur events to keep the toolbar visible for keyboard navigation, and toggle `enabled` based on the user's stored preference (`REMOTE_TOOLBAR_AUTO_HIDE_STORAGE_KEY`).
