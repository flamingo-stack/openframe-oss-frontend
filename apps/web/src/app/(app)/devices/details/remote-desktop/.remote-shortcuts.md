## remote-shortcuts.ts

Defines the data model, defaults, and helper utilities for user-managed keyboard shortcuts shown in the remote desktop "Apply Shortcut" menu. Shortcuts are stored as `comboToSequence`-compatible combo strings (e.g. `'shift+win+m'`), which serve as the wire contract consumed by `MeshDesktop.sendKeyCombo`; display labels are always derived from this stored value.

## Key Components

- **`RemoteShortcut`** — interface representing a stored shortcut (`id`, `combo`).
- **`REMOTE_SHORTCUTS_STORAGE_KEY`** — localStorage key for persisting user shortcuts.
- **`DEFAULT_REMOTE_SHORTCUTS`** — built-in list of common shortcuts (e.g. `alt+ctrl+del`, `win+m`, `ctrl+w`).
- **`SHORTCUT_DESCRIPTIONS`** — toast message lookup for well-known combos.
- **`SHORTCUT_MODIFIERS`** / **`ShortcutModifier`** — allowed modifier keys (`shift`, `alt`, `ctrl`, `win`).
- **`normalizeKeyToken(input)`** — normalizes free-text key input into a valid combo token, or `null` if unsupported.
- **`buildCombo(modifiers, keyToken)`** — composes an ordered combo string from modifiers and a key token.
- **`comboLabel(combo)`** — converts a combo string into a human-readable label (e.g. `'Shift + Win + M'`).
- **`shortcutAction(combo)`** — maps a combo to a `RemoteSessionAction` for session timeline logging, distinguishing the secure attention sequence (`CTRL_ALT_DEL`) from other shortcuts (`SHORTCUT_SENT`).

## Usage Example

```typescript
import {
  DEFAULT_REMOTE_SHORTCUTS,
  buildCombo,
  normalizeKeyToken,
  comboLabel,
  shortcutAction,
} from './remote-shortcuts';

// Build a new shortcut from user input
const keyToken = normalizeKeyToken('Delete'); // 'del'
if (keyToken) {
  const combo = buildCombo(['ctrl', 'alt'], keyToken); // 'ctrl+alt+del'
  const label = comboLabel(combo); // 'Ctrl + Alt + Del'
  const action = shortcutAction(combo); // { action: 'CTRL_ALT_DEL' }
}

// Render default shortcuts in a menu
DEFAULT_REMOTE_SHORTCUTS.forEach(({ combo }) => {
  console.log(comboLabel(combo));
});
```
