## remote-shortcuts.ts

Defines the data model, defaults, and helper utilities for user-managed keyboard shortcuts shown in the remote desktop "Apply Shortcut" menu. Shortcuts are stored as `comboToSequence`-compatible combo strings (e.g. `'shift+win+m'`), matching the wire format consumed by `MeshDesktop.sendKeyCombo`, with human-readable labels always derived from that combo string.

## Key Components

- **`RemoteShortcut`** — interface representing a stored shortcut (`id` + `combo`).
- **`REMOTE_SHORTCUTS_STORAGE_KEY`** — localStorage key used to persist user shortcuts.
- **`DEFAULT_REMOTE_SHORTCUTS`** — built-in list of default shortcuts (e.g. Ctrl+Alt+Del, Win+M, Win+L).
- **`SHORTCUT_DESCRIPTIONS`** — maps well-known combos to toast description text.
- **`SHORTCUT_MODIFIERS`** / **`ShortcutModifier`** — allowed modifier keys (`shift`, `alt`, `ctrl`, `win`).
- **`normalizeKeyToken(input)`** — normalizes free-text key input (e.g. `'Delete'`, `'F5'`) into a valid combo token, or `null` if unsupported.
- **`buildCombo(modifiers, keyToken)`** — composes a combo string from selected modifiers and a key token, in canonical modifier order.
- **`comboLabel(combo)`** — converts a combo string into a display label (e.g. `'shift+win+m'` → `'Shift + Win + M'`).
- **`shortcutAction(combo)`** — maps a combo to a `RemoteSessionAction` for the session timeline, special-casing the secure attention sequence (`CTRL_ALT_DEL`).

## Usage Example

```typescript
import {
  DEFAULT_REMOTE_SHORTCUTS,
  buildCombo,
  normalizeKeyToken,
  comboLabel,
  shortcutAction,
} from './remote-shortcuts';

// Build a custom shortcut from user input
const keyToken = normalizeKeyToken('Delete'); // 'del'
if (keyToken) {
  const combo = buildCombo(['ctrl', 'alt'], keyToken); // 'ctrl+alt+del'
  console.log(comboLabel(combo)); // 'Ctrl + Alt + Del'
}

// Send a shortcut and record it on the session timeline
const action = shortcutAction('win+l');
// { action: 'SHORTCUT_SENT', label: 'Win + L', source: 'MENU' }

// List default shortcuts in the menu
DEFAULT_REMOTE_SHORTCUTS.forEach(s => console.log(s.id, comboLabel(s.combo)));
```
