This Next.js client page renders an interactive remote shell (CMD or PowerShell) session to a device via a MeshCentral tunnel, using an `xterm.js` terminal UI embedded in the app's device management flow.

## Key Components

- **`RemoteShellPage`** — Default export; thin wrapper rendering `RemoteShellSession` (no approval gate, unlike remote screen sessions).
- **`RemoteShellSession`** — Core component that:
  - Resolves `deviceId` and `shellType` (`cmd`/`powershell`) from URL search params.
  - Fetches device details via `useDeviceDetails` and derives the MeshCentral tool connection/agent ID via `getToolConnectionState`.
  - Lazily loads `xterm` and `@xterm/addon-fit`, initializes a `Terminal`, and wires it to a `ResizeObserver` for responsive resizing.
  - Establishes a `MeshControlClient` session and a `MeshTunnel` to stream terminal I/O (binary data) between the browser and the remote device.
  - Auto-injects a PowerShell bootstrap command (`WINDOWS_POWERSHELL_CMD`) once the shell connects and the session type is `powershell`.
  - Tracks connection state (`TunnelState`) and surfaces status text/color (`Idle`, `Connecting`, `Open`, `Connected`).
  - Registers the device as the active Mingo "open view" via `useTrackOpenView`.
  - Handles error/blocked states (device load failure, MeshCentral agent unavailable) with dedicated UI and "Back" navigation via `useSafeBack`.
- **`WINDOWS_POWERSHELL_CMD`** — Constant shell command with fallback chain to locate and launch PowerShell across Windows configurations.

## Usage Example

This page is rendered automatically by Next.js routing for a remote shell route, invoked with query params:

```typescript
// Navigate to a remote shell session for a device
router.push(`/devices/remote-shell?id=${deviceId}&shellType=powershell`);

// Or for a standard command prompt session
router.push(`/devices/remote-shell?id=${deviceId}&shellType=cmd`);
```

The component itself requires no props—state is derived entirely from `useSearchParams()` and device/tool connection hooks, making it a self-contained route page within the `(app)/devices` route group.
