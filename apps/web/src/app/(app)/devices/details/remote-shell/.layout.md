Defines page-level metadata for the Remote Shell route and re-exports a shared layout component to maintain consistent structure across the application.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the document title for this route, generated via the `routeTitle` helper with `"Remote Shell"` as the page name.
- **Default export** — Re-exports `default` from `@/app/(app)/route-title-layout`, reusing the shared layout implementation instead of defining a new one.

## Usage Example

This file is automatically picked up by Next.js as the layout for its route segment. No manual import is needed elsewhere, but the pattern it follows can be replicated for other routes:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Another Page') };
```

Next.js uses the exported `metadata` to render the `<title>` tag for the "Remote Shell" page, while the re-exported layout component wraps the page content with shared UI (e.g., headers, navigation) defined centrally in `route-title-layout`. This approach keeps layout logic DRY while allowing each route to customize its title independently.
