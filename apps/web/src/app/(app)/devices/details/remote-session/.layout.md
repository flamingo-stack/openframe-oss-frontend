Next.js layout re-export file that wires up page metadata for the Remote Session Recording route while delegating actual layout rendering to a shared layout component.

## Key Components

- **`metadata`** – A `Metadata` object (from Next.js) that sets the page title using the `routeTitle` helper, producing a formatted title string for the "Remote Session Recording" route.
- **Default export** – Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, avoiding duplication of layout logic across routes.

## Usage Example

This file is automatically picked up by Next.js as the `layout.tsx` for its route segment. You typically don't import it directly, but the pattern it follows looks like:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = {
  title: routeTitle('Remote Session Recording'),
};
```

To replicate this pattern for a new route, create a similar `layout.tsx` in the route's directory, re-export the shared layout, and customize the `routeTitle` argument to match the new page's name:

```typescript
export const metadata: Metadata = { title: routeTitle('Device Inventory') };
```

This keeps layout behavior consistent across the app while allowing each route to define its own browser tab title via `next/metadata`.
