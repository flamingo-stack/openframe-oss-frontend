Defines the page metadata and layout wrapper for the Remote Session Recording route, re-exporting a shared layout component while customizing the browser tab title.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title to `"Remote Session Recording"` via the `routeTitle` helper, ensuring consistent title formatting across the app.
- **Default export** — Re-exports `default` from `@/app/(app)/route-title-layout`, reusing the shared layout that renders route titles consistently without duplicating layout logic.

## Usage Example

This file is automatically picked up by Next.js's file-based routing system as the `layout.tsx` for its route segment. No manual invocation is needed:

```typescript
// Next.js automatically applies this layout and metadata
// to all pages under the "Remote Session Recording" route segment.

// Example of the routeTitle helper used internally:
import { routeTitle } from '@/lib/route-title';

const title = routeTitle('Remote Session Recording');
// => formatted title string, e.g. "Remote Session Recording | OpenFrame"
```

## Notes

- This pattern (re-exporting a shared layout and overriding only `metadata`) is a common convention in this repository for keeping route titles consistent while avoiding duplicated layout markup.
- See `@/app/(app)/route-title-layout` for the actual layout implementation shared across multiple routes.
