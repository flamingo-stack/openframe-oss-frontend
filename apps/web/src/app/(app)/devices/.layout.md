This file defines the Next.js metadata and layout export for the Devices route, setting the browser tab title dynamically using a shared route title utility.

## Key Components

- **`metadata`**: A `Metadata` object (from Next.js) that sets the page title to `"Devices"` via the `routeTitle` helper, ensuring consistent title formatting across the app (e.g., appending a suffix like app name).
- **Default export**: Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, reusing a common layout implementation instead of duplicating layout logic per route.

## Usage Example

This file follows the Next.js App Router convention where a `layout.tsx` file automatically applies to all pages within the same route segment (in this case, the `Devices` section):

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Devices') };
```

Next.js automatically picks up this `layout.tsx` for any route under the `Devices` segment, applying the shared layout component and setting the page's `<title>` tag to the result of `routeTitle('Devices')` (e.g., `"Devices | OpenFrame"`). No manual import or rendering is required elsewhere—Next.js handles wiring based on file location within the `app` directory structure.

To reuse this pattern for another route, create a similar `layout.tsx` file in that route's folder, importing the same shared layout and passing the appropriate page name to `routeTitle`.
