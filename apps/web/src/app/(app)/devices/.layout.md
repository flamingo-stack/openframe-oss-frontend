Defines route-level metadata and layout configuration for the Devices page in the Next.js App Router, setting the browser tab title and delegating rendering to a shared layout component.

## Key Components

- **`metadata`** — Exported `Metadata` object that sets the page title to `"Devices"` using the `routeTitle` helper for consistent title formatting across the app.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, avoiding duplication of layout logic across route segments.

## Usage Example

This file follows the Next.js App Router convention where a `layout.tsx` file automatically wraps its corresponding route segment (in this case, the `Devices` page):

```typescript
// app/(app)/devices/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Devices') };
```

Next.js automatically applies this metadata to the `<head>` of the page and renders the shared layout around any nested `page.tsx` for the Devices route. No manual invocation is required—placing this file in the route directory is sufficient for Next.js to pick it up.

To create a similar layout for another route, copy this pattern and replace `'Devices'` with the appropriate route name:

```typescript
export const metadata: Metadata = { title: routeTitle('Settings') };
```
