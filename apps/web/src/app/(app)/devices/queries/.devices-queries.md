## devices-queries.ts

Defines the raw GraphQL query strings for device-related reads that have **not** been migrated to Relay. This module is intentionally narrow in scope — it holds only the device detail-page query, per-facet counter queries, and an organization existence probe. The device list and filter-facet UI queries live as Relay documents under `src/graphql/devices/` and must not be duplicated here.

## Key Components

- **`HAS_ORGANIZATIONS_QUERY`** — Lightweight probe that checks whether the tenant has at least one organization. Used to gate the "Add Device" action on the Devices page (a device must belong to an organization).
- **`GET_DEVICE_STATUS_COUNTS_QUERY`** — Fetches only `statuses` and `filteredCount` from the `deviceFilters` resolver, scoped to what the status counter needs.
- **`GET_DEVICE_ORGANIZATION_COUNTS_QUERY`** — Fetches only `organizationIds` facet counts, used by the customers table and dashboard overview.
- **`GET_DEVICE_QUERY`** — Full device detail-page query, returning hostname, hardware/OS metadata, organization, tag assignments, tool connections, and installed agents for a single device by `machineId`.

## Usage Example

```typescript
import { GET_DEVICE_QUERY, HAS_ORGANIZATIONS_QUERY, GET_DEVICE_STATUS_COUNTS_QUERY } from './devices-queries';

// Fetch a single device's details
const deviceResult = await graphqlClient.request(GET_DEVICE_QUERY, {
  machineId: 'abc-123',
});

// Gate "Add Device" action on org existence
const hasOrgsResult = await graphqlClient.request(HAS_ORGANIZATIONS_QUERY);
const canAddDevice = hasOrgsResult.organizations.edges.length > 0;

// Render status counter badges
const statusCounts = await graphqlClient.request(GET_DEVICE_STATUS_COUNTS_QUERY, {
  filter: { organizationId: 'org-1' },
});
```

**Important:** When a new counter needs a facet already returned by one of these queries, widen the existing document instead of adding a new one — `deviceFilters` runs all six backend facet queries regardless of the GraphQL selection set, so extra documents add resolution cost without backend savings.
