# devices-api.ts

Imperative (non-hook) device data access layer that complements the Relay hooks used for lists, pickers, and filter facets. It provides plain-promise functions for the cases where a React hook isn't appropriate: react-query `queryFn`s, singleton services, cursor-based full-fleet traversal, and detail-node fetching. Every function fully owns its query, variable mapping, response unwrapping, and transform to `Device`, so callers never deal with raw GraphQL envelopes.

## Key Components

- **`DEVICES_PAGE_SIZE`** / **`DEVICES_BULK_PAGE_SIZE`** — shared page-size constants for scrolled lists vs. bulk/full-fleet fetches.
- **`DevicesPage`**, **`DevicesQueryVariables`**, **`DevicesPageInfo`** — pagination result/input shapes.
- **`DeviceStatusCounts`**, **`DeviceOrganizationCounts`** — aggregate count types for dashboard stats.
- **`postDeviceQuery<T>`** — internal helper that POSTs a GraphQL query via `apiClient` and normalizes transport/GraphQL errors into a single thrown `Error`.
- **`fetchDevicesPage`** — fetches one page of devices via `fetchQuery` (Relay, imperative), returning transformed `Device[]` plus page info and filtered count.
- **`fetchAllDevices`** — walks `fetchDevicesPage` cursors to exhaustion, returning the entire matching fleet as a flat array. Includes defensive stop conditions to avoid infinite loops.
- **`fetchDeviceStatusCounts`** — fetches per-status device counts plus total filtered count (dashboard stat cards).
- **`fetchDeviceOrganizationCounts`** — fetches per-organization device counts; note the backend excludes `organizationIds` from its own facet filter (self-exclusion faceting).
- **`fetchDeviceNode`** — fetches the raw GraphQL node for a single device by `machineId`, including detail-only fields like `installedAgents`.

## Usage Example

```typescript
import {
  fetchDevicesPage,
  fetchAllDevices,
  fetchDeviceStatusCounts,
  fetchDeviceOrganizationCounts,
  fetchDeviceNode,
} from '@/features/devices/api/devices-api';

// One page, e.g. for a react-query queryFn
const page = await fetchDevicesPage({ search: 'laptop', first: 20 });

// Entire fleet for a monitoring lookup table
const allDevices = await fetchAllDevices({ filter: { statuses: ['online'] } });

// Dashboard stat cards
const statusCounts = await fetchDeviceStatusCounts();
const orgCounts = await fetchDeviceOrganizationCounts();

// Single device detail (merged elsewhere with Fleet/MeshCentral data)
const node = await fetchDeviceNode('machine-123');
```
