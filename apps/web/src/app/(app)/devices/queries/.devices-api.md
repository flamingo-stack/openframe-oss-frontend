## devices-api.ts

Imperative device data-fetching functions that complement the Relay-hook-based device data layer. This module provides the non-hook reads: a react-query-compatible `queryFn`, dashboard count aggregations, a full-fleet cursor walk, and single-device detail retrieval — each returning plain `Device` objects or counts rather than raw GraphQL envelopes.

## Key Components

- **`DEVICES_PAGE_SIZE`** / **`DEVICES_BULK_PAGE_SIZE`** — Page size constants for scrolled lists (20) and bulk fetches (100).
- **`fetchDevicesPage(variables)`** — Fetches one page of devices via `fetchQuery` (Relay), using the same document as the suspending pickers so results normalize into the shared Relay store. Throws if no data is returned, to avoid silently caching an empty fleet.
- **`fetchAllDevices(variables)`** — Walks `fetchDevicesPage` to exhaustion, collecting the entire matching fleet. Guards against infinite loops via four stop conditions (no next page, null/unmoved cursor, or empty page).
- **`fetchDeviceStatusCounts(filter)`** — Returns per-status device counts plus a filtered total, for dashboard stat cards.
- **`fetchDeviceOrganizationCounts(filter)`** — Returns per-organization device counts. Note: the backend excludes `organizationIds` from its own facet filter (self-exclusion faceting), so the result always covers every organization in the tenant regardless of the filter passed.
- **`fetchDeviceNode(machineId)`** — Fetches the raw GraphQL node for a single device, including detail-only fields like `installedAgents`, used by `useDeviceDetails` to merge with Fleet/MeshCentral data.
- **`postDeviceQuery<T>(query, variables)`** (internal) — Shared POST-to-GraphQL helper that normalizes transport errors, GraphQL `errors`, and empty bodies into a single thrown `Error`.
- **Types** — `DevicesPage`, `DevicesPageInfo`, `DevicesQueryVariables`, `DeviceStatusCounts`, `DeviceOrganizationCounts`.

## Usage Example

```typescript
import {
  fetchDevicesPage,
  fetchAllDevices,
  fetchDeviceStatusCounts,
  fetchDeviceNode,
} from '@/lib/devices/devices-api';

// react-query queryFn for ticket-form autocomplete
const page = await fetchDevicesPage({ search: 'laptop', first: 20 });

// Whole-fleet lookup for monitoring tables
const allDevices = await fetchAllDevices({ filter: { organizationIds: ['org-1'] } });

// Dashboard stat cards
const counts = await fetchDeviceStatusCounts({ organizationIds: ['org-1'] });
console.log(counts.filteredCount, counts.byStatus.get('online'));

// Device detail node (merged with Fleet/MeshCentral elsewhere)
const node = await fetchDeviceNode('machine-123');
```
