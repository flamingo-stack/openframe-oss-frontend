# page.tsx — Devices List Page

Next.js client page component that renders the main Devices list view, displaying a tabbed navigation between the devices list and remote sessions, along with a panel of connected devices or an empty state when none exist.

## Key Components

- **`Devices`** (default export) — Page component that composes the devices list view
- **`DevicesTabNavigation`** — Tab switcher between "list" and remote session views (active tab set to `"list"`)
- **`DevicesPanel`** — Shared panel component displaying the devices grid/list, with archive link, organization-awareness, and empty state support
- **`EmptyState`** — Shared empty-state UI shown when no devices are connected, listing key capabilities (monitoring, scripting, remote sessions)
- **`useHasOrganizations`** — Hook that determines whether the tenant has any organizations, used to conditionally show an "Add a customer" prompt without flashing during load
- **`onboardingGuideButton`** — Helper that generates the contextual onboarding guide button/action for the `"devices"` section

## Usage Example

```typescript
// Rendered automatically by Next.js App Router for the /devices route
export default function Devices() {
  const { hasOrganizations, isLoading } = useHasOrganizations();
  const guideButton = onboardingGuideButton('devices');

  return (
    <div className="flex w-full flex-col">
      <DevicesTabNavigation activeTab="list" />
      <DevicesPanel
        archiveHref={routes.devices.archive()}
        noOrganizations={hasOrganizations === false}
        isCheckingOrganizations={isLoading}
        emptyState={<EmptyState title="No devices connected" {...guideButton} />}
      />
    </div>
  );
}
```

**Key behavior:** The `noOrganizations` flag is only set to `true` once `hasOrganizations` resolves to `false` (not during loading), preventing a flash of the "Add a customer" banner. Loading state is instead communicated separately via `isCheckingOrganizations`, which keeps the "Add Device" action disabled until the organization check completes.
