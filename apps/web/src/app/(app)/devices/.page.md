# page.tsx (Devices)

Next.js client page component that renders the main Devices list view, displaying all monitored devices (laptops, servers, workstations, mobile) within the current tenant/organization context.

## Key Components

- **`Devices`** (default export) — The page component rendering the devices list tab, combining tab navigation, a loading gate, and a devices data panel with contextual empty state.
- **`DevicesTabNavigation`** — Renders tab switcher between "Devices List" and "Remote Sessions" views, with `list` set as the active tab.
- **`useHasOrganizations`** — Hook returning `hasOrganizations` and `isLoading` to determine whether the tenant has any customers configured, used to conditionally show an "Add a customer" prompt without flashing during load.
- **`useTableGridGate`** — Hook resolving the table layout mode (`loading`, grid-enabled, or card-row fallback) based on a feature flag.
- **`EmptyState`** — Displays onboarding guidance (icons, title, description, feature highlights, and a guide button) when no devices are connected yet.

## Usage Example

This page is automatically routed by Next.js App Router and requires no manual instantiation. It composes shared components to assemble the devices view:

```typescript
// app/devices/page.tsx
export default function Devices() {
  const { hasOrganizations, isLoading } = useHasOrganizations();
  const tableGate = useTableGridGate();

  return (
    <div className="flex w-full flex-col">
      <DevicesTabNavigation activeTab="list" />
      <LoadingWhen loading={tableGate === 'loading'}>
        <DevicesPanel
          tableLayout={tableLayoutFor(tableGate)}
          noOrganizations={hasOrganizations === false}
          isCheckingOrganizations={isLoading}
          emptyState={<EmptyState icon={<MonitorIcon />} title="No devices connected" />}
        />
      </LoadingWhen>
    </div>
  );
}
```

**Notes:**
- `noOrganizations` only flips to `true` after the organizations check resolves, preventing UI flash during loading.
- Table layout switches between grid and card-row rendering based on a feature flag gate (`useTableGridGate`), with a loading state handled by `LoadingWhen`.
- The empty state surfaces an onboarding guide button scoped to the `devices` context via `onboardingGuideButton('devices')`.
