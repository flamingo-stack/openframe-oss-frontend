# device-info-rows.ts

Defines the shape and helper functions for rendering labelled rows in device detail cards (Hardware, OS, and Network tabs), normalizing missing values to a consistent empty-value placeholder.

## Key Components

- **`DeviceInfoRow`** - Type representing one labelled row with an optional value (`string | number | null`) and an optional `copyable` flag.
- **`deviceInfoItems(rows)`** - Maps an array of `DeviceInfoRow` into display-ready items, converting present values to strings and substituting `EMPTY_VALUE` for missing/blank values. Used both for the loaded card and its loading-state placeholder (`labelsOf(rows)`).
- **`hasDeviceInfo(rows)`** - Returns `true` if at least one row in the array has a real value, used to decide whether a whole section should be rendered.

## Usage Example

```typescript
import { deviceInfoItems, hasDeviceInfo, type DeviceInfoRow } from '@/lib/device-info-rows';

const hardwareRows: DeviceInfoRow[] = [
  { label: 'CPU', value: 'Intel i7-12700K', copyable: true },
  { label: 'RAM', value: 16384 },
  { label: 'GPU', value: null }, // not reported by this device
];

if (hasDeviceInfo(hardwareRows)) {
  const items = deviceInfoItems(hardwareRows);
  // [
  //   { label: 'CPU', value: 'Intel i7-12700K', copyable: true },
  //   { label: 'RAM', value: '16384', copyable: undefined },
  //   { label: 'GPU', value: EMPTY_VALUE },
  // ]
  items.forEach(item => console.log(item.label, item.value));
}
```

## Notes

- Fields reported by **most** devices should always be included in `rows` (showing the empty-value mark when absent), keeping card layout consistent across devices.
- Fields only **some** devices report should be omitted from the `rows` array entirely rather than shown as empty, per the design intent documented in the source comments.
