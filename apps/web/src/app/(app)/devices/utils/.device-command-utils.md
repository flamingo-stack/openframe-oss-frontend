# device-command-utils.ts

Platform-aware utility functions for building shell/PowerShell commands that install, register, and uninstall the OpenFrame client agent on a device, plus helpers for resolving the download URL and normalizing OS identifiers.

## Key Components

- **`MACHINE_ID_HEADER`** — HTTP header name sent with every download request to identify the command instance.
- **`newDownloadMachineId()`** — Generates a fresh v4 UUID (with `crypto.randomUUID` fallback) for a single download command.
- **`assetsDownloadBase()`** — Resolves the origin serving the assets download endpoint, from tenant host config or browser origin.
- **`buildAssetsDownloadUrl(baseUrl, platform)`** — Builds the asset bundle download URL (maps non-Windows platforms to `macos`).
- **`buildInstallCommand(options: InstallCommandOptions)`** — Builds the full download-and-install command for Windows (PowerShell) or macOS/Linux (bash).
- **`buildRegisterCommand(options: RegisterCommandOptions)`** — Builds the "step 2" enrollment command for agents already installed via a package manager.
- **`buildUninstallCommand(options: UninstallCommandOptions)`** — Builds the download-and-uninstall command.
- **`buildRemoteAccessModeArgs(mode)`** — Converts a `RemoteAccessMode` into the `--remote-access-mode` CLI flag.
- **`PACKAGE_MANAGER_METHODS`** — Install commands (`winget`, `chocolatey`, `brew`) keyed by `InstallMethod`.
- **`installMethodLabel(method)`**, **`isInstallMethodEnabled(method)`**, **`installMethodsForPlatform(platform)`** — Helpers for rendering the Install Method dropdown.
- **`normalizeDevicePlatform(platform?, osType?, operatingSystem?)`** — Normalizes free-form OS strings into an `OSPlatformId` (`windows` | `darwin` | `linux`).

## Usage Example

```typescript
import {
  newDownloadMachineId,
  assetsDownloadBase,
  buildInstallCommand,
  buildUninstallCommand,
  normalizeDevicePlatform,
} from './device-command-utils';

const platform = normalizeDevicePlatform(undefined, device.osType);
const machineId = newDownloadMachineId();

const installCmd = buildInstallCommand({
  platform,
  serverUrl: 'https://gateway.example.com',
  initialKey: 'init-key-123',
  orgId: 'org-456',
  downloadBaseUrl: assetsDownloadBase(),
  machineId,
});

const uninstallCmd = buildUninstallCommand({
  platform,
  downloadBaseUrl: assetsDownloadBase(),
  machineId: newDownloadMachineId(),
});
```

Each generated command is a single shell/PowerShell string ready to be copied or executed, handling bundle download, extraction, and invocation of `openframe-client` with the appropriate flags for the target platform.
