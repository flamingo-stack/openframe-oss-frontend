Utilities for building platform-specific device installation and uninstallation commands for the OpenFrame client, with support for macOS (darwin), Windows, and Linux platforms.

## Key Components

### Interfaces

- **`InstallCommandOptions`** — Options for `buildInstallCommand`: `platform`, `serverUrl`, `initialKey`, `orgId`, `releaseVersion`, and optional `additionalArgs`
- **`UninstallCommandOptions`** — Options for `buildUninstallCommand`: `platform` and `releaseVersion`

### Functions

| Function | Description |
|---|---|
| `buildBinaryUrl(version, assetName)` | Constructs a release download URL; falls back to `/latest/download/` when version is empty |
| `getMacBinaryUrl(version)` | Returns the macOS `.tar.gz` binary URL for a given version |
| `getWindowsBinaryUrl(version)` | Returns the Windows `.zip` binary URL for a given version |
| `buildInstallCommand(options)` | Generates a full shell/PowerShell install command string for the target platform |
| `buildUninstallCommand(options)` | Generates a full shell/PowerShell uninstall command string for the target platform |
| `normalizeDevicePlatform(platform?, osType?, operatingSystem?)` | Normalizes raw OS strings (e.g. `"win32"`, `"ubuntu"`, `"darwin"`) into a typed `OSPlatformId`; defaults to `"darwin"` |

## Usage Example

```typescript
import {
  buildInstallCommand,
  buildUninstallCommand,
  normalizeDevicePlatform,
} from './device-command-utils';

// Normalize an incoming OS string from a device record
const platform = normalizeDevicePlatform(undefined, 'win32'); // → 'windows'

// Build an install command
const installCmd = buildInstallCommand({
  platform,
  serverUrl: 'https://myorg.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org_xyz',
  releaseVersion: 'v1.2.0',
  additionalArgs: ['--silent'],
});

// Build an uninstall command
const uninstallCmd = buildUninstallCommand({
  platform,
  releaseVersion: 'v1.2.0',
});
```

> **Note:** When `releaseVersion` is an empty string, `buildBinaryUrl` automatically targets the latest release at `https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/`.
