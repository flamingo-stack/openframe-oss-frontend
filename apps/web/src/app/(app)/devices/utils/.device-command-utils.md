# device-command-utils.ts

Provides unified logic for constructing shell/PowerShell commands used to install, register, and uninstall the OpenFrame device agent across Windows, macOS, and Linux platforms, plus helpers for OS platform detection.

## Key Components

- **`MACHINE_ID_HEADER`** - HTTP header name used to tag each agent download with a unique machine id.
- **`newDownloadMachineId()`** - Generates a fresh v4 UUID (via `crypto.randomUUID` or a manual fallback) for a single download command.
- **`assetsDownloadBase()`** - Resolves the base origin for the assets download endpoint (tenant host or current browser origin).
- **`buildAssetsDownloadUrl(baseUrl, platform)`** - Builds the URL for downloading the agent bundle, mapping non-Windows platforms to `macos`.
- **`buildInstallCommand(options: InstallCommandOptions)`** - Builds the full download + install shell command for a target platform.
- **`buildRegisterCommand(options: RegisterCommandOptions)`** - Builds the "step 2" enrollment command for agents installed via a package manager.
- **`buildUninstallCommand(options: UninstallCommandOptions)`** - Builds the full download + uninstall shell command.
- **`buildRemoteAccessModeArgs(mode)`** - Converts a `RemoteAccessMode` into the matching `--remote-access-mode` CLI flag.
- **`PACKAGE_MANAGER_METHODS`** - Config for `winget`, `chocolatey`, and `brew` install methods (labels, titles, install commands).
- **`installMethodLabel(method)`** / **`isInstallMethodEnabled(method)`** / **`installMethodsForPlatform(platform)`** - Helpers for driving the Install Method UI dropdown.
- **`normalizeDevicePlatform(platform?, osType?, operatingSystem?)`** - Normalizes assorted OS string fields into an `OSPlatformId` (`'windows' | 'darwin' | 'linux'`).

## Usage Example

```typescript
import {
  buildInstallCommand,
  buildUninstallCommand,
  newDownloadMachineId,
  assetsDownloadBase,
  normalizeDevicePlatform,
} from './device-command-utils';

const platform = normalizeDevicePlatform(device.platform, device.osType);
const machineId = newDownloadMachineId();

const installCmd = buildInstallCommand({
  platform,
  serverUrl: 'https://tenant.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org-456',
  downloadBaseUrl: assetsDownloadBase(),
  machineId,
});

const uninstallCmd = buildUninstallCommand({
  platform,
  downloadBaseUrl: assetsDownloadBase(),
  machineId: newDownloadMachineId(),
});
```

These command strings are typically displayed in the UI for the user to copy and run on the target device (e.g., via `useInstallCommand`), rather than executed directly by the frontend.
