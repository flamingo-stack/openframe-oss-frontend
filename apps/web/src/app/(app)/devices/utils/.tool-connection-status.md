# tool-connection-status.ts

Utility module encapsulating business logic around the lifecycle and display status of device tool connections (FLEET_MDM, MESHCENTRAL). It translates raw backend connection state into UI-friendly states, determines which agents a device should have, and detects devices still in the initial connection/install phase.

## Key Components

- **`ToolConnectionDisplayStatus`** — Type alias: `'online' | 'offline' | 'pending'`, used for rendering status badges.
- **`ToolConnectionState`** — Type alias: `'pending' | 'disconnected' | 'live'`, the internal lifecycle state of a tool connection.
- **`getToolConnectionState(connection)`** — Derives the lifecycle state from a `ToolConnection`: no `agentToolId` means `pending`; `DISCONNECTED`/`ERROR` status means `disconnected`; otherwise `live`.
- **`getToolConnectionDisplayStatus(connection)`** — Maps a connection to the UI display status (`pending`, `online`, `offline`) for the Agents tab.
- **`getExpectedAgentTypes(device, saasTenant)`** — Returns the list of agent types expected on a device (core agents, plus `openframe-chat` for SaaS tenants); returns an empty list for archived/deleted/decommissioned devices.
- **`isDeviceStillConnecting(device)`** — Returns `true` if the device is awaiting its first Fleet or MeshCentral registration, driving a "still connecting" banner.
- **`getMeshCentralBlockedCopy(state, feature)`** — Produces title/description copy explaining why a remote feature (shell, desktop, file manager) is blocked based on connection state.

## Usage Example

```typescript
import {
  getToolConnectionDisplayStatus,
  isDeviceStillConnecting,
  getExpectedAgentTypes,
  getMeshCentralBlockedCopy,
  getToolConnectionState,
} from './tool-connection-status';

// Render a status badge for a tool connection
const status = getToolConnectionDisplayStatus(device.toolConnections?.[0]);
// 'pending' | 'online' | 'offline'

// Show a connecting banner while waiting for first registration
if (isDeviceStillConnecting(device)) {
  showBanner('Device is still connecting');
}

// Determine expected agents for a SaaS tenant device
const expectedAgents = getExpectedAgentTypes(device, true);
// ['fleetmdm-agent', 'meshcentral-agent', 'openframe-chat']

// Block remote shell access with contextual copy
const meshState = getToolConnectionState(
  device.toolConnections?.find(tc => tc.toolType === 'MESHCENTRAL'),
);
if (meshState !== 'live') {
  const { title, description } = getMeshCentralBlockedCopy(meshState, 'Remote shell');
  showBlockedDialog(title, description);
}
```
