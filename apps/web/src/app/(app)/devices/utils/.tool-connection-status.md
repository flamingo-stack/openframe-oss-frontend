## tool-connection-status.ts

Provides helper functions and types for interpreting the lifecycle and display status of device tool connections (FLEET_MDM, MESHCENTRAL) on the Agents tab, including logic for distinguishing "still installing", "disconnected", and "live" states, and determining which agent types a device is expected to report.

## Key Components

- **`ToolConnectionDisplayStatus`** — Union type: `'online' | 'offline' | 'pending'`, used for UI display.
- **`ToolConnectionState`** — Union type: `'pending' | 'disconnected' | 'live'`, representing the backend lifecycle of a tool connection.
- **`getToolConnectionState(connection)`** — Derives the lifecycle state from a `ToolConnection`; returns `'pending'` if no `agentToolId`, `'disconnected'` for `DISCONNECTED`/`ERROR` status, otherwise `'live'`.
- **`getToolConnectionDisplayStatus(connection)`** — Maps lifecycle state to a UI-friendly display status (`'pending'`, `'online'`, `'offline'`).
- **`getExpectedAgentTypes(device, saasTenant)`** — Returns the list of agent types (`fleetmdm-agent`, `meshcentral-agent`, and `openframe-chat` for SaaS tenants) expected on a device, or an empty list for archive-lifecycle devices.
- **`isDeviceStillConnecting(device)`** — Returns `true` if the device is awaiting its first Fleet or MeshCentral registration (drives the "still connecting" banner).
- **`getMeshCentralBlockedCopy(state, feature)`** — Returns `{ title, description }` copy explaining why a remote feature (shell, desktop, file manager) is blocked based on connection state.

## Usage Example

```typescript
import {
  getToolConnectionDisplayStatus,
  isDeviceStillConnecting,
  getExpectedAgentTypes,
  getMeshCentralBlockedCopy,
  getToolConnectionState,
} from './tool-connection-status';

const meshConnection = device.toolConnections?.find(tc => tc.toolType === 'MESHCENTRAL');

const status = getToolConnectionDisplayStatus(meshConnection); // 'online' | 'offline' | 'pending'

if (isDeviceStillConnecting(device)) {
  showBanner('Device is still connecting');
}

const expectedAgents = getExpectedAgentTypes(device, isSaasTenant);

const state = getToolConnectionState(meshConnection);
if (state !== 'live') {
  const { title, description } = getMeshCentralBlockedCopy(state, 'Remote Desktop');
  showBlockedState(title, description);
}
```
