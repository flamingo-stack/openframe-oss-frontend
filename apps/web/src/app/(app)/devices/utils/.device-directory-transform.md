Transforms Relay GraphQL fragment data into directory-related fields (USER and SOURCES cells) for device rows displayed in the Devices list UI.

## Key Components

- **`machineDirectoryToDevice(ref)`** — Reads the `deviceDirectoryFields_machine` inline fragment from a Relay fragment key and maps it to a `DeviceDirectoryCells` object containing `directorySources`, `directoryUserLink`, `directoryUserName`, and a derived `directoryUserCount` (computed from the length of `directoryUserIds`).
- **`readDirectoryListedMachineEdges(edges)`** — Combines base device fields (via `readListedMachineEdges`) with directory-specific fields (via `machineDirectoryToDevice`) for each edge/node pair, producing a fully merged `Device[]` array ready for rendering in the device list. Gracefully handles `null`/`undefined` edges and nodes by filtering them out.
- **`DeviceDirectoryCells`** — Type alias picking the directory-related subset of fields from the `Device` type.
- **`DirectoryListedNode`** — Internal type combining both required Relay fragment keys plus the `unreadNotificationCount` field needed by the base device transform.

## Usage Example

```typescript
import { readDirectoryListedMachineEdges } from './device-directory-transform';

function DeviceList({ connection }: { connection: DeviceConnection }) {
  const devices = readDirectoryListedMachineEdges(connection.edges);

  return (
    <ul>
      {devices.map(device => (
        <li key={device.id}>
          {device.name} - {device.directoryUserName} ({device.directoryUserCount} users)
        </li>
      ))}
    </ul>
  );
}
```

This function is typically used alongside `readListedMachineEdges` to build the complete row data for a paginated/scrolled device directory table, ensuring both base device fields and directory-specific fields (user identity, source systems) are populated in a single pass.
