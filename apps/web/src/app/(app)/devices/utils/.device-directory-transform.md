# device-directory-transform.ts

Transforms GraphQL machine fragment data into the "USER" and "SOURCES" cell values displayed in the Devices-list directory columns. It bridges Relay inline fragments with the broader device row data produced by `readListedMachineEdges`.

## Key Components

- **`machineDirectoryToDevice(ref)`** — Reads the `deviceDirectoryFields_machine` inline fragment from a Relay fragment reference and maps it to a `DeviceDirectoryCells` object, which includes `directorySources`, `directoryUserLink`, `directoryUserName`, and a computed `directoryUserCount` (derived from the length of `directoryUserIds`).
- **`readDirectoryListedMachineEdges(edges)`** — Takes a list of GraphQL connection edges (each wrapping a machine node), and for each non-null node, merges the standard device-list row (via `readListedMachineEdges`) with the directory-specific cells (via `machineDirectoryToDevice`). Returns a flat array of fully-populated `Device` objects.
- **`DeviceDirectoryCells`** (type) — A `Pick` of `Device` fields limited to directory-related properties.
- **`DirectoryListedNode`** (type) — An intersection type combining both required Relay fragment keys plus `unreadNotificationCount`, representing the shape expected for each machine node.

## Usage Example

```typescript
import { readDirectoryListedMachineEdges } from './device-directory-transform';

function DeviceDirectoryList({ connection }: { connection: DeviceConnectionQuery$data['machines'] }) {
  const devices = readDirectoryListedMachineEdges(connection?.edges);

  return (
    <table>
      <tbody>
        {devices.map(device => (
          <tr key={device.id}>
            <td>{device.directoryUserName}</td>
            <td>{device.directoryUserCount} users</td>
            <td>{device.directorySources}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

This utility is typically consumed by list/table components that render the Devices directory view, ensuring each row combines both general device metadata and directory-sourced user/source information in a single pass.
