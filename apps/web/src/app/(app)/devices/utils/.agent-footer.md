Provides footer metadata for agent info cards, linking supported agent tool types to their external source repositories and a "Signed by Flamingo" trust badge.

## Key Components

- **`AGENT_REPO_LINKS`** — A `Record<ToolType, string>` mapping known tool types (`FLEET_MDM`, `MESHCENTRAL`) to their corresponding GitHub repository URLs. Tool types not present in this map have no associated footer.
- **`isLinkedToolType(toolType: string)`** — Type guard that checks whether a given string key exists in `AGENT_REPO_LINKS`, narrowing it to `ToolType`.
- **`getAgentFooter(toolType: string): InfoCardFooterData | undefined`** — Main exported function. Accepts a raw string (since callers like the agents tab may synthesize values outside the `ToolType` union, e.g. `OSQUERYD`), and returns footer data (icon, text, logo, and link) only if the tool type has a registered repository link; otherwise returns `undefined`.

## Usage Example

```typescript
import { getAgentFooter } from './agent-footer';

function AgentInfoCard({ toolType }: { toolType: string }) {
  const footer = getAgentFooter(toolType);

  if (!footer) {
    return null; // No footer for unlinked tool types (e.g. OSQUERYD)
  }

  return (
    <div className="info-card-footer">
      {footer.icon}
      <span>{footer.text}</span>
      {footer.logo}
      <a href={footer.link.href} target="_blank" rel="noopener noreferrer">
        View source
      </a>
    </div>
  );
}
```

For supported tool types like `FLEET_MDM`, this renders a "Signed by Flamingo" badge linking to [github.com/flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm). For unlisted tool types, no footer is rendered.
