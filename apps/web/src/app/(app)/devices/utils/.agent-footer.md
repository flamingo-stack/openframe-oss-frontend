Provides footer metadata for agent info cards, linking supported agent tool types to their external Flamingo repository sources and rendering a "Signed by Flamingo" trust badge.

## Key Components

- **`AGENT_REPO_LINKS`** — Internal record mapping `ToolType` values (`FLEET_MDM`, `MESHCENTRAL`) to their GitHub repository URLs. Tool types without an entry are not considered "linked" agents.
- **`isLinkedToolType(toolType)`** — Type guard that narrows a plain `string` to `ToolType` by checking it exists as a key in `AGENT_REPO_LINKS`.
- **`getAgentFooter(toolType)`** — Main exported function. Given a tool type string, returns an `InfoCardFooterData` object (icon, label, Flamingo logo, and repo link) if the tool type is recognized, or `undefined` otherwise.

## Usage Example

```typescript
import { getAgentFooter } from './agent-footer';

function AgentInfoCard({ toolType }: { toolType: string }) {
  const footer = getAgentFooter(toolType);

  if (!footer) {
    return null; // No footer for unrecognized/unlinked agent types
  }

  return (
    <div className="info-card-footer">
      {footer.icon}
      <span>{footer.text}</span>
      {footer.logo}
      <a href={footer.link.href} target="_blank" rel="noreferrer">
        View source
      </a>
    </div>
  );
}
```

Since `toolType` is accepted as a plain `string` (not strictly `ToolType`), this function safely handles dynamically synthesized values, such as `OSQUERYD` from the agents tab, by returning `undefined` for any unmapped type.
