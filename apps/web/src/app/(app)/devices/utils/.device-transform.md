# device-transform.ts

Transforms Relay `Machine` GraphQL fragment data into the flat `Device` shape consumed by shared device tables, cards, and selectors throughout the app. Implements a three-step "field ladder" where each transform function builds on the previous, mirroring the fragment composition defined in `src/graphql/devices/`.

## Key Components

- **`DeviceRowFields`** — Type alias for row-level machine data with Relay's `$fragmentType` marker stripped; the entry point for non-Relay data sources (e.g., the assignments list's raw-POST union query).
- **`rowFieldsToDevice(machine)`** — Step 1 base transform. Converts raw row fields (identifiers, network placeholder, status, OS, organization, tags) into a `Device`. Exposed separately so non-Relay callers can reach it without a fragment reference.
- **`machineRowToDevice(ref)`** — Step 1 wrapper. Reads `deviceRowFields_machine` fragment via `readInlineData` and delegates to `rowFieldsToDevice`.
- **`machineSelectorToDevice(ref)`** — Step 2. Reads `deviceSelectorFields_machine` fragment, extends Step 1 with hardware identifiers (serial, manufacturer, model) and resolves the organization's primary contact email via `customerContactEmail`.
- **`machineToDevice(ref)`** — Step 3, full transform. Reads `deviceFields_machine` fragment, extends Step 2 with network details (IP, MAC), enrollment/OS version data, agent version, and tool connections.
- **`toToolConnections(connections)`** — Internal helper that maps raw tool connection edges into `ToolConnection[]`, filtering out null entries.

Each function's input type (`$key`) enforces at compile time which fragment a caller must have selected in their GraphQL query, preventing access to fields not actually fetched.

## Usage Example

```typescript
import { machineToDevice, machineSelectorToDevice, machineRowToDevice } from './device-transform';

// In a component that spread deviceFields_machine fragment
function DeviceDetailRow({ machineRef }: { machineRef: deviceFields_machine$key }) {
  const device = machineToDevice(machineRef);
  return <div>{device.hostname} — {device.os_version}</div>;
}

// In a component with only selector-level fragment access
function DeviceOption({ machineRef }: { machineRef: deviceSelectorFields_machine$key }) {
  const device = machineSelectorToDevice(machineRef);
  return <span>{device.hardware_model} ({device.organizationEmail})</span>;
}

// Non-Relay path: data already shaped as DeviceRowFields
import { rowFieldsToDevice, type DeviceRowFields } from './device-transform';

function fromRawMachine(rawFields: DeviceRowFields) {
  return rowFieldsToDevice(rawFields);
}
```
