## device-refresh.ts

Provides a module-level, Relay-compatible mechanism for forcing mounted device queries to refetch after a mutation (e.g., archiving a device), without remounting components or dropping the UI to a loading skeleton.

This exists because Relay's `store.invalidateStore()` does not force a refetch of queries that are already mounted — `QueryResource.prepareWithIdentifier` returns the retained cache entry before checking staleness. Instead, this module bumps a shared counter that components feed into Relay's `fetchKey`, which changes the cache identifier and triggers a genuine refetch.

## Key Components

- **`bumpDeviceEpoch()`** — Increments the module-level `deviceEpoch` counter and notifies all subscribed listeners. Call this from mutation callbacks (e.g., after archiving/updating a device) to invalidate all mounted device queries.
- **`useDeviceEpoch()`** — React hook that subscribes to the epoch counter via `useSyncExternalStore` and wraps it in `useDeferredValue`. Returns the current epoch value for use as a Relay `fetchKey`. Deferring the value ensures the refetch happens as a background transition, keeping previously committed rows visible instead of suspending the whole view.

## Usage Example

```typescript
import { useDeviceEpoch, bumpDeviceEpoch } from './device-refresh';

// In a component rendering a device list query:
function DevicesPanel() {
  const fetchKey = useDeviceEpoch();

  const data = useLazyLoadQuery(DevicesQuery, { /* variables */ }, { fetchKey });

  // ... render devices
}

// In a mutation's onCompleted callback (e.g., archive device):
function archiveDevice(deviceId: string) {
  commitMutation(environment, {
    mutation: ArchiveDeviceMutation,
    variables: { deviceId },
    onCompleted: () => {
      bumpDeviceEpoch(); // forces all mounted device queries to refetch
    },
  });
}
```

Use `useDeviceEpoch()` wherever a Relay query needs to react to device mutations performed elsewhere in the app, and call `bumpDeviceEpoch()` from any mutation handler that changes device state.
