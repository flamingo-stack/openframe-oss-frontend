Utility module providing a unified, single-source-of-truth layer for evaluating device action availability and tool connection lookups across the OpenFrame frontend.

## Key Components

### Status Check Functions

| Function | Description |
|---|---|
| `isDeviceOnline(status)` | Returns `true` if device status equals `"ONLINE"` (case-insensitive) |
| `canArchiveDevice(status)` | Returns `true` if status is neither `"ARCHIVED"` nor `"DELETED"` |
| `canUnarchiveDevice(status)` | Returns `true` only when status is `"ARCHIVED"` |
| `canDeleteDevice(status)` | Returns `true` if status is not `"DELETED"` |

### Tool Connection Helpers

| Function | Description |
|---|---|
| `getToolConnection(connections, toolType)` | Finds a `ToolConnection` by `"MESHCENTRAL"` or `"FLEET_MDM"` type |
| `getMeshCentralAgentId(device)` | Extracts the MeshCentral `agentToolId` string from device connections |
| `getFleetHostId(device)` | Extracts and coerces the Fleet MDM `agentToolId` to a numeric host ID |

### `DeviceActionAvailability` Interface

Typed result shape returned by `getDeviceActionAvailability`, exposing boolean flags for each action and resolved tool IDs.

### `getDeviceActionAvailability(device)`

Primary entry point — computes the full availability map for a single device. MeshCentral-dependent actions (`remoteShellEnabled`, `remoteControlEnabled`, `manageFilesEnabled`) require a connected, online agent. `runScriptEnabled` requires only device online status.

## Usage Example

```typescript
import { getDeviceActionAvailability } from './device-action-utils';

const availability = getDeviceActionAvailability(device);

if (availability.remoteShellEnabled) {
  openRemoteShell(availability.meshcentralAgentId);
}

if (availability.archiveEnabled) {
  showArchiveButton();
}

if (availability.runScriptEnabled) {
  enableScriptRunner();
}
```
