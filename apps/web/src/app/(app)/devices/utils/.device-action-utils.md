# device-action-utils.ts

Centralizes the logic for determining which device actions (remote shell, remote control, file management, reboot, script execution, rename, delete) are available for a given device, based on its status and tool connection health. Acts as the single source of truth so UI components don't duplicate availability checks.

## Key Components

- **`isDeviceOnline(status)`** — Case-insensitive check for `ONLINE` status.
- **`canDeleteDevice(status)`** — Blocks deletion for `DELETED` and `PENDING_DELETION` devices (already final/archived).
- **`canEditDisplayName(status)`** — Blocks renaming for `DELETED`, `ARCHIVED`, and `PENDING_DELETION` devices.
- **`getToolConnection(toolConnections, toolType)`** — Finds a tool connection entry by type (`MESHCENTRAL` or `FLEET_MDM`).
- **`getMeshCentralAgentId(device)`** — Retrieves the MeshCentral agent ID for a device.
- **`getFleetHostId(device)`** — Returns the numeric Fleet MDM host ID, but only when the connection state is `live` (avoids stale IDs from disconnected devices).
- **`indexDevicesByFleetHostId(devices)`** — Builds a `Map<number, Device>` keyed by Fleet host ID, resolving duplicates by picking the most recently seen device.
- **`DeviceActionAvailability`** — Interface describing enabled/disabled states for each device action plus relevant tool IDs.
- **`getDeviceActionAvailability(device)`** — Computes the full `DeviceActionAvailability` result for a device, combining online status and MeshCentral connection readiness.

## Usage Example

```typescript
import { getDeviceActionAvailability, canDeleteDevice } from './device-action-utils';

const availability = getDeviceActionAvailability(device);

if (availability.remoteShellEnabled) {
  openRemoteShell(availability.meshcentralAgentId);
}

if (!canDeleteDevice(device.status)) {
  console.log('Device cannot be deleted - already archived or pending deletion');
}
```

Use `indexDevicesByFleetHostId` when a screen starts from a Fleet host context (e.g., monitoring queries, policies) and needs to resolve back to the corresponding OpenFrame `Device`:

```typescript
import { indexDevicesByFleetHostId } from './device-action-utils';

const deviceByFleetId = indexDevicesByFleetHostId(allDevices);
const device = deviceByFleetId.get(fleetHostId);
```
