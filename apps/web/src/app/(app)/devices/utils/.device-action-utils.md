# device-action-utils.ts

Centralized utility functions for determining device state and action availability (e.g., remote shell, reboot, delete, edit) based on device status and tool connection health. Serves as the single source of truth for enabling/disabling device actions across the UI.

## Key Components

- **`isDeviceOnline(status)`** - Case-insensitive check for `ONLINE` device status.
- **`canDeleteDevice(status)`** - Returns `false` for `DELETED` or `PENDING_DELETION` devices.
- **`canEditDisplayName(status)`** - Returns `false` for `DELETED`, `ARCHIVED`, or `PENDING_DELETION` devices.
- **`getToolConnection(toolConnections, toolType)`** - Finds a tool connection by type (`MESHCENTRAL` or `FLEET_MDM`).
- **`getMeshCentralAgentId(device)`** - Extracts the MeshCentral agent ID from a device's tool connections.
- **`getFleetHostId(device)`** - Returns the numeric Fleet MDM host ID, only when the connection state is `live` (guards against stale IDs on disconnected rows).
- **`indexDevicesByFleetHostId(devices)`** - Builds a `Map<number, Device>` keyed by Fleet host ID, resolving duplicates by most recent `lastSeen` timestamp.
- **`DeviceActionAvailability`** - Interface describing enabled/disabled states for all device actions plus tool IDs and online state.
- **`getDeviceActionAvailability(device)`** - Computes the full `DeviceActionAvailability` result for a given device, combining online status and MeshCentral connection health.

## Usage Example

```typescript
import {
  getDeviceActionAvailability,
  indexDevicesByFleetHostId,
  canDeleteDevice,
} from './device-action-utils';

// Determine which actions are available for a device
const availability = getDeviceActionAvailability(device);

if (availability.remoteShellEnabled) {
  openRemoteShell(availability.meshcentralAgentId);
}

if (availability.deleteEnabled) {
  showDeleteButton();
}

// Build a lookup for Fleet-originated screens (policies, live queries)
const devicesByFleetId = indexDevicesByFleetHostId(allDevices);
const device = devicesByFleetId.get(fleetHostId);

// Standalone status check
if (canDeleteDevice(device?.status)) {
  confirmDeletion(device);
}
```
