## device-log-time.ts

Provides time-range and grouping utilities for the device log viewer: defining selectable time ranges (preset and custom), converting them into API-ready instant bounds while enforcing a 30-day maximum range, and grouping log lines by local calendar day for display.

## Key Components

- **`DEVICE_LOG_RANGES` / `DeviceLogRange` / `DeviceLogPreset`** - Supported range options (`1h`, `24h`, `7d`, `custom`) and their types.
- **`DEVICE_LOG_RANGE_LABELS`** - Human-readable labels for each range option.
- **`DEFAULT_DEVICE_LOG_RANGE`** - Default preset (`24h`) used as fallback.
- **`isDeviceLogRange(value)`** - Type guard validating a string is a known `DeviceLogRange`.
- **`deviceLogRangeBounds(range, custom, anchorMs, fallback?)`** - Computes `{ from, to }` instant bounds for a given range, clamping custom ranges to the 30-day API limit.
- **`deviceLogPickerBounds(anchorMs)`** - Returns the selectable `fromDate`/`toDate` window (30 days ending on the anchor date) for a custom date picker.
- **`DeviceLogDayGroup<T>`** - Interface representing a group of log rows belonging to one local day.
- **`groupByLocalDay(items, instantOf, cursorOf)`** - Groups consecutive log items into per-local-day buckets, assigning unique React keys even when cursors repeat.

## Usage Example

```typescript
import {
  deviceLogRangeBounds,
  deviceLogPickerBounds,
  groupByLocalDay,
  DEFAULT_DEVICE_LOG_RANGE,
} from '@/lib/device-log-time';

// Compute instant bounds for a preset range
const bounds = deviceLogRangeBounds('7d', undefined, Date.now());
// => { from: '2024-01-01T00:00:00Z' }

// Get selectable date-picker bounds for custom ranges
const { fromDate, toDate } = deviceLogPickerBounds(Date.now());

// Group fetched log lines by local day for rendering
const groups = groupByLocalDay(
  logLines,
  line => line.timestamp,
  line => line.cursor,
);

groups.forEach(group => {
  console.log(group.date, group.rows.length);
});
```
