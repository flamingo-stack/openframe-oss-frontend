# device-log-time.ts

Utility module for managing time range selection and local-day grouping of device log entries. It defines the supported log time range presets, computes GraphQL `Instant` bounds for those ranges (clamped to the API's 30-day maximum), and groups log lines by local calendar day for display.

## Key Components

- **`DEVICE_LOG_RANGES` / `DeviceLogRange` / `DeviceLogPreset`** — Supported range options (`'1h'`, `'24h'`, `'7d'`, `'custom'`) and their type definitions.
- **`DEVICE_LOG_RANGE_LABELS`** — Human-readable labels for each range, for use in UI controls.
- **`DEFAULT_DEVICE_LOG_RANGE`** — Default preset (`'24h'`).
- **`isDeviceLogRange(value)`** — Type guard validating a string is a known `DeviceLogRange`.
- **`deviceLogRangeBounds(range, custom, anchorMs, fallback?)`** — Computes `{ from, to }` `Instant` bounds for a preset or custom `DateRange`, clamping custom ranges to the 30-day API maximum.
- **`deviceLogPickerBounds(anchorMs)`** — Returns the min/max selectable `Date`s (30-day window ending on the anchor day) for a custom date picker.
- **`groupByLocalDay(items, instantOf, cursorOf)`** — Groups a list of log items into consecutive `DeviceLogDayGroup<T>` buckets by local day, assigning unique React row keys even when cursors collide.
- **`DeviceLogDayGroup<T>`** — Interface describing a day group: `key`, `date`, and `rows` (each with a unique `key` and the original `item`).

## Usage Example

```typescript
import {
  DEVICE_LOG_RANGE_LABELS,
  DEFAULT_DEVICE_LOG_RANGE,
  deviceLogRangeBounds,
  deviceLogPickerBounds,
  groupByLocalDay,
  type DeviceLogRange,
} from '@/lib/device-log-time';

const anchorMs = Date.now();
const range: DeviceLogRange = '24h';

// Resolve filter bounds for an API query
const bounds = deviceLogRangeBounds(range, undefined, anchorMs);
// => { from: Instant }

// Picker constraints for a custom date range control
const { fromDate, toDate } = deviceLogPickerBounds(anchorMs);

// Group fetched log lines by local day for rendering
const groups = groupByLocalDay(
  logLines,
  (line) => line.timestamp,
  (line) => line.cursor,
);

groups.forEach(group => {
  console.log(DEVICE_LOG_RANGE_LABELS[range], group.key, group.rows.length);
});
```
