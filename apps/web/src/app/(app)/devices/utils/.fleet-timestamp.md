Converts Fleet API timestamp strings into millisecond epoch values, normalizing Fleet's "never-set" sentinel date (`0001-01-01T00:00:00Z`) and other invalid values to `null`.

## Key Components

- **`fleetTimestampMs(iso)`** — Parses an ISO timestamp string from Fleet and returns a millisecond timestamp (`number`), or `null` if the value is missing, unparsable, or equal to Fleet's "never-set" sentinel (which parses to a non-positive epoch value).

## Usage Example

```typescript
import { fleetTimestampMs } from './fleet-timestamp';

// Valid timestamp
fleetTimestampMs('2024-05-01T12:00:00Z'); // => 1714564800000

// Fleet's "never-set" sentinel
fleetTimestampMs('0001-01-01T00:00:00Z'); // => null

// Missing value
fleetTimestampMs(null); // => null
fleetTimestampMs(undefined); // => null

// Unparsable value
fleetTimestampMs('not-a-date'); // => null

// Use in a display helper
function formatLastSeen(iso: string | null | undefined): string {
  const ms = fleetTimestampMs(iso);
  return ms ? new Date(ms).toLocaleString() : 'Never';
}
```

This helper is useful when rendering Fleet-sourced fields such as "last seen" or "enrolled at" timestamps, ensuring the UI consistently displays a fallback (e.g., "Never") instead of an incorrect date like the year 0001.
