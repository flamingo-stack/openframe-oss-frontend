Utility for normalizing Fleet API timestamps, which use a special sentinel value (`0001-01-01T00:00:00Z`) to represent "never set" instead of `null`. This function converts that sentinel, missing values, and unparsable strings into a consistent `null` result.

## Key Components

- **`fleetTimestampMs(iso)`** — Parses an ISO timestamp string into epoch milliseconds, returning `null` if the input is missing, unparsable, or represents Fleet's "never-set" sentinel (any timestamp resolving to a non-positive epoch value).

## Usage Example

```typescript
import { fleetTimestampMs } from './fleet-timestamp';

// Valid timestamp
fleetTimestampMs('2024-03-15T10:30:00Z'); // 1710498600000

// Fleet's "never-set" sentinel
fleetTimestampMs('0001-01-01T00:00:00Z'); // null

// Missing value
fleetTimestampMs(null); // null
fleetTimestampMs(undefined); // null

// Unparsable string
fleetTimestampMs('not-a-date'); // null

// Example: display "Never" for unset last-seen timestamps
function formatLastSeen(iso: string | null): string {
  const ms = fleetTimestampMs(iso);
  return ms === null ? 'Never' : new Date(ms).toLocaleString();
}
```

This is typically used when displaying host/device metadata returned from Fleet's API (e.g., `last_enrolled_at`, `detail_updated_at`), ensuring the UI treats all "unset" representations uniformly rather than rendering a misleading epoch-zero date.
