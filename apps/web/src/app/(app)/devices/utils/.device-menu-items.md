# device-menu-items.tsx

Defines the shared configuration for device-action menu items (Remote Shell, Remote Control, Manage Files, Device Details, Device Logs) used across multiple views such as the Devices table dropdown and the Tickets panel. Centralizes label, icon, href, and disabled-state logic so each view only needs to supply a lightweight context.

## Key Components

- **`DeviceMenuItemContext`** — Input shape describing the calling view's needs: `deviceId`, `availability` (from `getDeviceActionAvailability`), optional `iconSize`, `isWindows` (controls Remote Shell rendering), and `withNewTabAction` (adds an "open in new tab" icon action).
- **`DeviceMenuItems`** — Output shape containing the built `ActionsMenuItem` entries: `deviceDetails`, `remoteShell`, `remoteControl`, `manageFiles`, `deviceLogs`. Note: "Run Script" is intentionally excluded since it requires React state (modal) owned by the parent.
- **`buildDeviceMenuItems(ctx)`** — Main factory function that builds all five menu items from a given context, deriving hrefs via `routes.devices.*` and disabled states from `ctx.availability`.
- **`buildRemoteShellItem(ctx)`** (internal) — Builds the Remote Shell item specially: renders a Windows submenu (CMD/PowerShell) when `isWindows === true`, a plain link with `&shellType=bash` when `isWindows === false`, or a plain link with no shell param when `isWindows` is `undefined`.
- **`iconClass` / `newTabIconAction` / `maybeNewTabAction`** (internal helpers) — Compute icon styling (muted vs. inherited color based on disabled state) and optionally attach an "open in new tab" icon action.

## Usage Example

```typescript
import { buildDeviceMenuItems } from './device-menu-items';
import { getDeviceActionAvailability } from './device-action-utils';

const availability = getDeviceActionAvailability(device);

const items = buildDeviceMenuItems({
  deviceId: device.id,
  availability,
  iconSize: 'w-6 h-6',
  isWindows: device.osType === 'windows',
  withNewTabAction: true,
});

// Use in a dropdown/menu component
<ActionsMenu
  items={[
    items.deviceDetails,
    items.remoteShell,
    items.remoteControl,
    items.manageFiles,
    items.deviceLogs,
  ]}
/>;
```

For a lighter-weight context (e.g. Tickets panel), omit `iconSize`, `isWindows`, and `withNewTabAction`:

```typescript
const items = buildDeviceMenuItems({
  deviceId: ticket.machineId,
  availability: getDeviceActionAvailability(device),
});
```
