Builds the shared set of device-action menu items (Device Details, Remote Shell, Remote Control, Manage Files, Device Logs) used across different views (Devices table dropdown, Tickets). Centralizes each action's label, icon, href, and disabled state so views only differ by the context they pass in.

## Key Components

- **`DeviceMenuItemContext`** — Input shape describing the calling view's needs: `deviceId`, `availability` (from `getDeviceActionAvailability`), optional `iconSize`, `isWindows` (controls Remote Shell rendering), and `withNewTabAction` (adds an "open in new tab" icon-action).
- **`DeviceMenuItems`** — Output shape with `deviceDetails`, `remoteShell`, `remoteControl`, `manageFiles`, `deviceLogs` entries (each an `ActionsMenuItem`). Note: `Run Script` is deliberately excluded since it requires React-stateful modal logic owned by the parent component.
- **`buildDeviceMenuItems(ctx)`** — Main factory function that returns a fully-populated `DeviceMenuItems` object based on the given context.
- **`buildRemoteShellItem(ctx)`** (internal) — Handles the three Remote Shell variants: Windows submenu (CMD/PowerShell), plain Bash link, or a generic link without a `shellType` param.
- Internal helpers `newTabIconAction`, `maybeNewTabAction`, and `iconClass` manage the optional "open in new tab" affordance and consistent icon styling/disabled-state coloring.

## Usage Example

```typescript
import { buildDeviceMenuItems } from './device-menu-items';
import { getDeviceActionAvailability } from './device-action-utils';

const availability = getDeviceActionAvailability(device);

const menuItems = buildDeviceMenuItems({
  deviceId: device.id,
  availability,
  iconSize: 'w-6 h-6',
  isWindows: device.os === 'windows',
  withNewTabAction: true,
});

// Use in a dropdown/actions menu component
<ActionsMenu
  items={[
    menuItems.deviceDetails,
    menuItems.remoteShell,
    menuItems.remoteControl,
    menuItems.manageFiles,
    menuItems.deviceLogs,
  ]}
/>;
```

For a Tickets view, pass a minimal context (no `iconSize`/`isWindows`) to get the smaller, plain-link style without the Windows shell submenu.
