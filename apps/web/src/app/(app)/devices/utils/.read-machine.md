# read-machine.ts

Utility functions for transforming GraphQL connection edges containing device "machine" fragments into application-level `Device` objects, safely handling null/undefined values at each step.

## Key Components

- **`readMachineEdges(edges)`** — Converts a standard GraphQL connection's edge array into an array of `Device` objects. Filters out null/undefined edges and nodes, delegating the actual field mapping to `machineToDevice`.

- **`readListedMachineEdges(edges)`** — Variant used specifically for the scrolled/listed view, where each edge's node includes an additional `unreadNotificationCount` field (from the viewer's unread notifications for that device). Produces `Device` objects enriched with this count.

Both functions use `flatMap` with single-element or empty arrays as a null-safe filtering pattern, avoiding explicit null checks with `filter`/`map` chains.

## Usage Example

```typescript
import { readMachineEdges, readListedMachineEdges } from './read-machine';
import { useFragment } from 'react-relay';

// Standard device list
const connection = useFragment(deviceListFragment, queryRef);
const devices = readMachineEdges(connection?.edges);

// Listed view with unread notification counts
const listedConnection = useFragment(deviceScrolledListFragment, queryRef);
const listedDevices = readListedMachineEdges(listedConnection?.edges);

listedDevices.forEach(device => {
  console.log(device.id, device.unreadNotificationCount);
});
```

Both functions gracefully handle `null` or `undefined` input for the `edges` array itself, as well as null entries within the array, returning an empty array (`[]`) when no valid data is present.
