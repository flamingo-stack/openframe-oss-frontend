This module provides helper functions for safely transforming GraphQL connection edges into `Device` objects, handling null/undefined edges and nodes gracefully.

## Key Components

- **`readMachineEdges`** — Maps an array of GraphQL edge objects (each wrapping a `deviceFields_machine$key` node) into an array of `Device` rows. Null or undefined edges/nodes are filtered out automatically.
- **`readListedMachineEdges`** — Similar to `readMachineEdges`, but for edges whose nodes also include an `unreadNotificationCount` field (used by the scrolled device list view). The resulting `Device` objects include this count alongside the standard transformed fields.

Both functions rely on `machineToDevice` from `./device-transform` to perform the actual field mapping from the Relay fragment reference to the `Device` type, and use `flatMap` to concisely skip null entries without manual filtering.

## Usage Example

```typescript
import { readMachineEdges, readListedMachineEdges } from './read-machine';

// Basic device list from a GraphQL connection
const devices = readMachineEdges(data.machines?.edges);

// Device list with unread notification counts (e.g., for a scrollable list view)
const listedDevices = readListedMachineEdges(data.machineList?.edges);

listedDevices.forEach(device => {
  console.log(device.id, device.unreadNotificationCount);
});
```

These functions are typically used inside Relay fragment/query components to convert raw GraphQL connection data into the `Device` shape consumed by UI components, ensuring consistent null-safety across the app.
