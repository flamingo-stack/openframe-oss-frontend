# directory-presentation.ts

Maps directory-service enum values (Entra ID join type, Intune compliance, ownership, management agent, and unavailability reasons) to human-readable labels and UI tag variants for display in the frontend.

## Key Components

- **`entraJoinTypeLabel(joinType)`** — Converts an `EntraJoinType` value into a readable label (e.g., "Entra joined", "Hybrid joined (on-premises AD)").
- **`intuneComplianceTag(state)`** — Converts an `IntuneComplianceState` value into a `{ label, variant }` object for rendering a status tag (e.g., success/error/warning variants).
- **`intuneOwnerLabel(owner)`** — Converts an `IntuneOwnerType` value into a readable label (e.g., "Company", "Personal").
- **`intuneManagementLabel(agent)`** — Converts an `IntuneManagementAgent` value into a readable label describing the management method (e.g., "Intune", "ConfigMgr", "Jamf").
- **`intuneUnavailableCopy(reason)`** — Converts an `IntuneUnavailableReason` into a `{ title, description }` explanation card, or `null` when no card should be shown (e.g., device simply not enrolled).

All functions use `presentationFor` from `@/lib/exhaustive-map` to perform exhaustive, type-safe lookups against `satisfies Record<Enum, ...>` maps, falling back to the raw input value (or `null`) when no match is found.

## Usage Example

```typescript
import {
  entraJoinTypeLabel,
  intuneComplianceTag,
  intuneOwnerLabel,
  intuneManagementLabel,
  intuneUnavailableCopy,
} from '@/lib/directory-presentation';

// Render a join type label
const joinLabel = entraJoinTypeLabel(device.entraJoinType);

// Render a compliance tag
const { label, variant } = intuneComplianceTag(device.complianceState);
<Tag variant={variant}>{label}</Tag>;

// Show why no Intune card is available
const unavailable = intuneUnavailableCopy(device.intuneUnavailableReason);
if (unavailable) {
  renderCard(unavailable.title, unavailable.description);
}
```
