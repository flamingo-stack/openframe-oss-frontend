# directory-presentation.ts

Presentation/label-mapping utilities that translate raw Entra ID and Intune enum values (from the generated GraphQL schema) into human-readable labels, UI tag variants, and explanatory copy for the device directory views.

## Key Components

- **`entraJoinTypeLabel(joinType)`** — Maps an `EntraJoinType` value to a display label (e.g., "Entra joined", "Hybrid joined (on-premises AD)").
- **`intuneComplianceTag(state)`** — Maps an `IntuneComplianceState` value to a `{ label, variant }` object for rendering a status `Tag` component (e.g., success/error/warning/grey variants).
- **`intuneOwnerLabel(owner)`** — Maps an `IntuneOwnerType` value to a display label (Company/Personal/Unknown).
- **`intuneManagementLabel(agent)`** — Maps an `IntuneManagementAgent` value to a display label describing the management channel (Intune, ConfigMgr, Jamf, co-management combos, etc.).
- **`intuneUnavailableCopy(reason)`** — Maps an `IntuneUnavailableReason` to a `{ title, description }` explanation card, or `null` when no card should be shown (e.g., `NOT_ENROLLED` has no design per contract §2).

All functions rely on `presentationFor` (from `@/lib/exhaustive-map`) to perform safe, exhaustive-checked lookups and fall back gracefully (returning the raw value or `null`) for unmapped input.

## Usage Example

```typescript
import {
  entraJoinTypeLabel,
  intuneComplianceTag,
  intuneOwnerLabel,
  intuneManagementLabel,
  intuneUnavailableCopy,
} from './directory-presentation';

// Display join type
const joinLabel = entraJoinTypeLabel(device.entraJoinType); // "Entra joined"

// Render a compliance Tag component
const { label, variant } = intuneComplianceTag(device.complianceState);
// <Tag variant={variant}>{label}</Tag>

// Show management agent
const managedBy = intuneManagementLabel(device.managementAgent); // "Intune PC client"

// Owner info
const owner = intuneOwnerLabel(device.ownerType); // "Company"

// Explain missing Intune data
const copy = intuneUnavailableCopy(device.unavailableReason);
if (copy) {
  renderInfoCard(copy.title, copy.description);
}
```

Each function accepts a loosely-typed `string` (not the strict enum) to accommodate runtime data from the backend, gracefully handling unknown or unmapped values.
