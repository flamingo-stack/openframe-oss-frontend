# device-log-level.ts

Provides utilities for normalizing and styling device log level values, mapping raw log level strings to the `DeviceLogLevel` enum and corresponding UI `Tag` variants for consistent display.

## Key Components

- **`DEVICE_LOG_LEVELS`** — Ordered readonly array of `DeviceLogLevel` values (`DEBUG`, `INFO`, `WARN`, `ERROR`), ordered from lowest to highest severity, useful for rendering filter chips in a consistent order.
- **`LEVEL_VARIANT`** (internal) — Maps each `DeviceLogLevel` to a `Tag` component variant (`outline`, `grey`, `warning`, `error`) for visual severity indication.
- **`isDeviceLogLevel(value)`** — Type guard that checks whether a string is a valid `DeviceLogLevel` key.
- **`normalizeDeviceLogLevel(level)`** — Normalizes a free-form, possibly mixed-case log level string into a valid `DeviceLogLevel`, defaulting to `INFO` for unrecognized values.
- **`deviceLogLevelVariant(level)`** — Resolves a raw log level string directly to its corresponding `Tag` variant, combining normalization and lookup in one call.

## Usage Example

```typescript
import {
  DEVICE_LOG_LEVELS,
  normalizeDeviceLogLevel,
  deviceLogLevelVariant,
} from '@/utils/device-log-level';

// Render filter chips in severity order
DEVICE_LOG_LEVELS.forEach((level) => {
  console.log(level, deviceLogLevelVariant(level));
});

// Normalize an arbitrary log entry's level field
const rawLevel = 'warn'; // from DeviceLogEntry.level
const level = normalizeDeviceLogLevel(rawLevel); // DeviceLogLevel.WARN

// Get the Tag variant for display
const variant = deviceLogLevelVariant('unknown-level'); // falls back to INFO variant: 'grey'
```

This is typically used in device log viewers to render a `<Tag variant={deviceLogLevelVariant(entry.level)}>` badge next to each log entry, ensuring unrecognized or malformed level strings degrade gracefully to `INFO`.
