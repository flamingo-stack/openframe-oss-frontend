## device-log-level.ts

Utility module for normalizing and styling device log level values. It maps the `DeviceLogLevel` enum to UI tag variants and safely coerces arbitrary, free-form log level strings (as stored on `DeviceLogEntry.level`) into a known enum value, defaulting to `INFO` for unrecognized input.

## Key Components

- **`DEVICE_LOG_LEVELS`** - Ordered array of `DeviceLogLevel` values (`DEBUG`, `INFO`, `WARN`, `ERROR`), lowest severity first, useful for rendering filter chips in a consistent order.
- **`isDeviceLogLevel(value)`** - Type guard that checks whether a string is a valid `DeviceLogLevel` member.
- **`normalizeDeviceLogLevel(level)`** - Trims and uppercases an arbitrary string, returning the matching `DeviceLogLevel`, or `DeviceLogLevel.INFO` if no match is found.
- **`deviceLogLevelVariant(level)`** - Resolves a log level string to its corresponding `TagProps['variant']` (`'outline'`, `'grey'`, `'warning'`, or `'error'`) for display in UI tag/chip components.

## Usage Example

```typescript
import {
  DEVICE_LOG_LEVELS,
  normalizeDeviceLogLevel,
  deviceLogLevelVariant,
} from './device-log-level';

// Render ordered filter chips
DEVICE_LOG_LEVELS.forEach((level) => {
  console.log(level, deviceLogLevelVariant(level));
});

// Normalize an unpredictable raw log entry value
const rawLevel = 'warn'; // could be any casing, or garbage
const level = normalizeDeviceLogLevel(rawLevel); // DeviceLogLevel.WARN

// Get the tag variant for rendering, with graceful fallback
const variant = deviceLogLevelVariant('unknown'); // 'grey' (treated as INFO)
```

This module is typically used in components that display device logs, ensuring consistent severity-based styling even when backend data contains unexpected casing or invalid values.
