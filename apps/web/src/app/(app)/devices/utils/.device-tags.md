## device-tags.ts

Maps GraphQL `MachineTag` assignment nodes returned by Relay into the UI-facing `DeviceTag` shape used by device list/detail components. It isolates this transformation from `device-transform.ts` so it can be unit-tested without the Relay babel plugin (which vitest cannot load).

## Key Components

- **`MachineTagFields`** — Type alias extracted from the `deviceRowFields_machine` GraphQL fragment, representing a single tag assignment element.
- **`MachineTagFieldsLike`** — A looser, partial version of `MachineTagFields` that requires only `id` on the assignment and `id`/`key` on the nested `tag`. Used so callers (like the device detail page, which reads data via raw POST rather than Relay) don't need a full fragment match.
- **`toDeviceTags(assignments)`** — Converts an array (or nullable array) of `MachineTagFieldsLike` into a `DeviceTag[]`:
  - `tagId`, `key`, `description`, `color` are sourced from the tag definition.
  - `values` and `createdAt` come from the assignment itself (`taggedAt` becomes `createdAt`).
  - Null/undefined entries are filtered out via `flatMap`.
  - `values` is spread into a new array since Relay returns readonly arrays.

## Usage Example

```typescript
import { toDeviceTags } from './device-tags';

const assignments = [
  {
    id: 'assignment-1',
    values: ['production', 'critical'],
    taggedAt: '2024-01-15T10:00:00Z',
    tag: {
      id: 'tag-1',
      key: 'environment',
      description: 'Deployment environment',
      color: '#ff0000',
    },
  },
  null,
];

const deviceTags = toDeviceTags(assignments);
// [
//   {
//     tagId: 'tag-1',
//     key: 'environment',
//     description: 'Deployment environment',
//     color: '#ff0000',
//     values: ['production', 'critical'],
//     createdAt: '2024-01-15T10:00:00Z',
//   },
// ]
```

This function is typically called when transforming Relay fragment data (`deviceRowFields_machine$data`) into props for components rendering device tag chips/filters.
