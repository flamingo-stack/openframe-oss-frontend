Utility functions for converting MeshCentral file system entries into UI-Kit compatible file items, plus helpers for formatting, path manipulation, and sanitization used by the file manager feature.

## Key Components

- **`convertFileEntryToItem(entry, currentPath)`** — Converts a single MeshCentral `FileEntry` into a `FileItem`, normalizing path separators and computing the full item path (file/folder detection based on `entry.t`).
- **`convertFileEntriesToItems(entries, currentPath)`** — Batch-converts an array of `FileEntry` objects to `FileItem[]`.
- **`formatFileSize(bytes)`** — Converts byte counts into human-readable strings (B, KB, MB, GB, TB).
- **`formatDate(timestamp)`** — Converts a Unix timestamp to a formatted date string via `formatDateTime`.
- **`getFileExtension(filename)`** — Extracts the lowercase file extension from a filename.
- **`isDownloadable(fileType)`** — Returns `true` if the file type code represents a regular (downloadable) file (type `3`).
- **`sanitizePath(path)`** — Strips path traversal segments (`.`, `..`) and normalizes Windows drive-letter paths or POSIX-style paths to prevent directory traversal attacks.
- **`getParentPath(path)`** — Computes the parent directory of a given path.
- **`joinPath(...segments)`** — Joins path segments into a normalized, slash-prefixed path string.

## Usage Example

```typescript
import {
  convertFileEntriesToItems,
  formatFileSize,
  sanitizePath,
  getParentPath,
  joinPath,
} from '@/lib/meshcentral/file-manager-utils';
import type { FileEntry } from '@/lib/meshcentral/file-manager-types';

const entries: FileEntry[] = [
  { n: 'report.pdf', t: 3, s: 204800, d: 1700000000000 },
  { n: 'projects', t: 1 },
];

const items = convertFileEntriesToItems(entries, '/home/user');
// items[0].size === '200.00 KB'

const safePath = sanitizePath('../../etc/passwd'); // '/etc/passwd'
const parent = getParentPath('/home/user/projects'); // '/home/user'
const fullPath = joinPath('home', 'user', 'projects'); // '/home/user/projects'
```

This module is primarily used by file manager UI components that render MeshCentral remote file browsing results in a `FileItem`-based list view.
