Utility functions for the MeshCentral file manager feature, handling conversion between MeshCentral's `FileEntry` wire format and the UI-Kit's `FileItem` model, plus common filesystem helpers (size formatting, date formatting, path sanitization, and path manipulation).

## Key Components

- **`convertFileEntryToItem(entry, currentPath)`** - Converts a single MeshCentral `FileEntry` into a UI-Kit `FileItem`, resolving the full item path, folder/file type (based on `entry.t`), formatted size, and formatted modified date.
- **`convertFileEntriesToItems(entries, currentPath)`** - Batch version of `convertFileEntryToItem` for arrays of entries.
- **`formatFileSize(bytes)`** - Converts raw byte counts into human-readable strings (e.g., `"1.50 MB"`).
- **`formatDate(timestamp)`** - Converts a Unix timestamp (ms) into a formatted date string via `formatDateTime`, returning `''` for invalid dates.
- **`getFileExtension(filename)`** - Extracts the lowercase file extension from a filename.
- **`isDownloadable(fileType)`** - Returns `true` only for regular files (type `3`), excluding folders/drives.
- **`sanitizePath(path)`** - Strips path traversal segments (`.`, `..`) and normalizes slashes, preserving Windows drive letters (e.g., `C:\`) when present.
- **`getParentPath(path)`** - Returns the parent directory of a given path, defaulting to `/`.
- **`joinPath(...segments)`** - Joins path segments into a single normalized, leading-slash path.

## Usage Example

```typescript
import {
  convertFileEntriesToItems,
  sanitizePath,
  getParentPath,
  joinPath,
} from '@/lib/meshcentral/file-manager-utils';

// Convert MeshCentral entries to UI-Kit FileItems
const items = convertFileEntriesToItems(meshFileEntries, '/home/user');

// Sanitize a user-supplied path before sending to the agent
const safePath = sanitizePath('../../etc/passwd'); // -> '/etc/passwd'

// Navigate up a directory
const parent = getParentPath('/home/user/docs'); // -> '/home/user'

// Build a new path
const newPath = joinPath('home', 'user', 'file.txt'); // -> '/home/user/file.txt'
```
