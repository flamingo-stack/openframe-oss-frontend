## vulnerabilities-empty-state.ts

Determines why a device's vulnerabilities list is empty by evaluating the state of the Fleet MDM data pipeline (fan-out, connection, inventory scan, and vulnerability matching), and separately determines whether a vulnerability-matching scan is still pending relative to the device's software inventory.

This logic encodes a decision table agreed with the backend team (see ClickUp 86ak6hzfx, `vulnerability-tab-states-FE-spec.md`), ensuring the UI never incorrectly reports "clean" for software that hasn't actually been matched against the vulnerability catalogue.

## Key Components

- **`VulnerabilitiesEmptyReason`** — Union type representing why the vulnerabilities list is empty: `'error'`, `'disconnected'`, `'collecting'`, `'scan-pending'`, or `'clean'`.
- **`getVulnerabilitiesEmptyReason(device)`** — Evaluates a `Device` top-down through the pipeline stages (fleet fan-out error, disconnected, collecting/pending inventory, scan-pending, or clean) and returns the applicable `VulnerabilitiesEmptyReason`.
- **`isVulnerabilityScanPending(device)`** — Returns `true` when the last completed vulnerability-matching run does not yet cover the device's current software inventory (matching incomplete or software changed since). Used independently of emptiness to drive a "Data sync in progress" banner even when results are already displayed.

## Usage Example

```typescript
import { getVulnerabilitiesEmptyReason, isVulnerabilityScanPending } from './vulnerabilities-empty-state';
import type { Device } from '../types/device.types';

function renderVulnerabilitiesTab(device: Device) {
  if (isVulnerabilityScanPending(device)) {
    showSyncBanner('Data sync in progress');
  }

  if (device.vulnerabilities?.length) {
    renderVulnerabilitiesList(device.vulnerabilities);
    return;
  }

  const reason = getVulnerabilitiesEmptyReason(device);
  switch (reason) {
    case 'error':
      showEmptyState('Unable to fetch vulnerability data.');
      break;
    case 'disconnected':
      showEmptyState('Device is disconnected from Fleet.');
      break;
    case 'collecting':
      showEmptyState('Inventory scan in progress...');
      break;
    case 'scan-pending':
      showEmptyState('Waiting for vulnerability matching to complete.');
      break;
    case 'clean':
      showEmptyState('No vulnerabilities found.');
      break;
  }
}
```
