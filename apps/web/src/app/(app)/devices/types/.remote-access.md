## remote-access.ts

Type definitions and helper functions for the remote-access approval feature set, modeling the backend approval contract for MeshCentral remote desktop sessions (request lifecycle, access policy, and session lifecycle). Consumed by `remote-access-approval-api-service.ts` and related UI components.

## Key Components

- **`RemoteSessionKind`** - literal type for the MeshCentral surface (`'desktop'` only).
- **`RemoteAccessRequestStatus`** - request state machine values (`PENDING`, `DELIVERED`, `APPROVED`, `DENIED`, `TIMED_OUT`, `REVOKED`, plus legacy aliases).
- **`RemoteAccessRequest`** - full request read model (device, status, timestamps, mode, decision source).
- **`CreateRemoteAccessRequestInput`** - payload shape for creating a request.
- **`RemoteAccessCreateError`** - typed error class thrown on create failures, with `code` and optional HTTP `status`.
- **`RemoteAccessDecisionEvent`** - shape of the `REMOTE_ACCESS_DECISION` NATS notification event.
- **`buildRemoteAccessRelayIdPrefix(requestId, protocol)`** - builds the MeshCentral relay id prefix for gateway matching.
- **`REMOTE_ACCESS_MODES` / `RemoteAccessMode`** - policy modes (`APPROVAL_REQUIRED`, `NOTIFY_ONLY`, `SILENT_ACCESS`, `DENY_ACCESS`).
- **`REMOTE_ACCESS_MODE_META`** - display label/description per mode.
- **`CUSTOMER_DEFAULT`, `RemoteAccessChoice`, `REMOTE_ACCESS_CHOICES`** - device-level select options including "inherit" choice.
- **`remoteAccessChoiceLabel` / `remoteAccessChoiceDescription`** - UI copy helpers for policy selects.
- **`TenantRemoteAccessPolicy`, `OrganizationRemoteAccessPolicy`, `DeviceRemoteAccessPolicy`** - policy shapes at each scope, with effective-mode resolution.
- **`RemoteSession`, `RemoteSessionStatus`, `RemoteSessionEndReason`** - active/ended session records and end-reason enum.
- **`RemoteSessionViewerEntry`, `RemoteSessionEnd`, `RemoteSessionEvent`** - live viewer info and session lifecycle notification shapes.

## Usage Example

```typescript
import {
  RemoteAccessMode,
  REMOTE_ACCESS_MODE_META,
  remoteAccessChoiceLabel,
  CUSTOMER_DEFAULT,
  buildRemoteAccessRelayIdPrefix,
} from './remote-access';

// Display a mode's label/description
const mode: RemoteAccessMode = 'APPROVAL_REQUIRED';
console.log(REMOTE_ACCESS_MODE_META[mode].label); // "Approval Required"

// Render a device policy select option
const label = remoteAccessChoiceLabel(CUSTOMER_DEFAULT, 'NOTIFY_ONLY');
// "Customer Default (Notify Only)"

// Build a relay id prefix for a desktop session (protocol 2)
const relayPrefix = buildRemoteAccessRelayIdPrefix('01HZX3K9...', 2);
```
