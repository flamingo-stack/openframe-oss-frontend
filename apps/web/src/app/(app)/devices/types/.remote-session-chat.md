# remote-session-chat.ts

Defines the shared message model for chat exchanged between a technician and end user during a remote screen session, plus adapters that convert this shared format into the shapes expected by the desktop chat panel component and the read-only session recording transcript viewer.

This chat flows over the same DIRECT-mode dialog the backend provisions alongside the remote session; the mock approval backend substitutes an in-memory stand-in since it has no real dialog.

## Key Components

- **`RemoteSessionChatAuthor`** - Union type identifying the message sender: `'technician'` or `'user'`.
- **`RemoteSessionChatMessage`** - Core message interface with `id`, `author`, `authorName`, `sentAt` (ISO timestamp), `body`, and optional `seq` (JetStream sequence number, absent on mock messages).
- **`toDesktopChatMessage(message)`** - Converts a `RemoteSessionChatMessage` into the `DesktopChatMessage` shape consumed by the library's `RemoteDesktopChatPanel` component (used on the technician's remote-desktop page).
- **`toRecordingChatMessage(message)`** - Converts a `RemoteSessionChatMessage` into a `RecordingChatMessage` for display in the read-only transcript shown on the recording page and live session page.
- **`RemoteSessionChatTechnician`** - Interface describing the technician's displayed identity (`name`, optional `avatarUrl`) shown alongside their chat rows.
- **`REMOTE_SESSION_END_USER_NAME`** - Constant string `'User'` used as the display name for the end user, who has no profile on the wire.

## Usage Example

```typescript
import {
  toDesktopChatMessage,
  toRecordingChatMessage,
  REMOTE_SESSION_END_USER_NAME,
  type RemoteSessionChatMessage,
} from './remote-session-chat';

const message: RemoteSessionChatMessage = {
  id: 'msg-1',
  author: 'user',
  authorName: REMOTE_SESSION_END_USER_NAME,
  sentAt: new Date().toISOString(),
  body: 'My screen is frozen.',
};

// Render in the technician's RemoteDesktopChatPanel
const desktopMessage = toDesktopChatMessage(message);

// Render in the read-only session transcript (recording or live view)
const transcriptMessage = toRecordingChatMessage(message);
```
