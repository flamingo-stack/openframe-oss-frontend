# remote-session-chat.ts

Type definitions and helpers for the chat feature used during a remote screen session, enabling communication between a technician and an end user. This module bridges the application's chat message shape with the `RemoteDesktopChatPanel` component's expected format from `@flamingo-stack/openframe-frontend-core`.

Both the technician (on the remote-desktop page) and the end user (on the openframe-chat session block) exchange messages through a shared DIRECT-mode dialog provisioned by the backend. A mock approval backend substitutes an in-memory stand-in when no real dialog exists.

## Key Components

- **`RemoteSessionChatAuthor`** - Union type identifying the message sender: `'technician'` or `'user'`.
- **`RemoteSessionChatMessage`** - Core interface describing a chat message, including `id`, `author`, `authorName`, `sentAt` (ISO timestamp), `body`, and an optional `seq` (JetStream sequence number for live/history rows).
- **`toDesktopChatMessage(message)`** - Converts a `RemoteSessionChatMessage` into the `DesktopChatMessage` shape expected by the library's `RemoteDesktopChatPanel` component.
- **`RemoteSessionChatTechnician`** - Interface describing the technician's identity shown in the chat (`name`, optional `avatarUrl`).
- **`REMOTE_SESSION_END_USER_NAME`** - Constant (`'User'`) used as the display name for the end user, who has no profile on the wire.

## Usage Example

```typescript
import {
  toDesktopChatMessage,
  REMOTE_SESSION_END_USER_NAME,
  type RemoteSessionChatMessage,
} from './remote-session-chat';

const incoming: RemoteSessionChatMessage = {
  id: 'msg-1',
  author: 'user',
  authorName: REMOTE_SESSION_END_USER_NAME,
  sentAt: new Date().toISOString(),
  body: 'My screen is frozen, can you help?',
  seq: 42,
};

// Convert to the shape required by RemoteDesktopChatPanel
const panelMessage = toDesktopChatMessage(incoming);

console.log(panelMessage);
// { id: 'msg-1', author: 'user', name: 'User', text: '...', at: Date }
```
