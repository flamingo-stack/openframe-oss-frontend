Type definitions for Fleet MDM API responses, modeling the structure of host data returned by Fleet's REST API, including hardware, software, policies, MDM status, and user identity information.

## Key Components

- **`FleetHost`** — The primary interface representing a complete host record, covering identification, platform/OS, CPU/hardware specs, network, storage, uptime/status, software inventory, team assignment, MDM enrollment, policies, labels, geolocation, and end-user identity.
- **`FleetHostResponse`** — Wrapper type for the `GET /hosts/:id` API response (`{ host: FleetHost }`).
- **`FleetSoftware`** — Installed software entry with source type, vulnerabilities, install paths, and code-signing info.
- **`FleetVulnerability`** — CVE details, including optional Fleet Premium severity fields (CVSS score, EPSS probability, CISA known-exploit flag).
- **`FleetHostPolicy`** — Per-host policy compliance result (`pass` | `fail` | `''`).
- **`FleetMdmInfo`** — MDM enrollment status, server URL, and device management state.
- **`FleetGeolocation`** — Built-in GeoIP data derived from the host's public IP.
- **`FleetEndUser`** — End-user identity (email, IdP groups) associated with the host.
- **`FleetUser`**, **`FleetBattery`**, **`FleetLabel`**, **`FleetSignatureInfo`**, **`FleetIssues`** — Supporting types for local OS users, battery health, label membership, software signatures, and policy issue counts.

## Usage Example

```typescript
import type { FleetHostResponse, FleetHost, FleetSoftware } from './fleet.types';

async function getHost(hostId: number): Promise<FleetHost> {
  const response = await fetch(`/api/v1/fleet/hosts/${hostId}`);
  const data: FleetHostResponse = await response.json();
  return data.host;
}

function hasCriticalVulnerabilities(software: FleetSoftware): boolean {
  return (software.vulnerabilities ?? []).some(
    (vuln) => vuln.cisa_known_exploit === true
  );
}

function isCompliant(host: FleetHost): boolean {
  return host.policies.every((policy) => policy.response !== 'fail');
}
```

This module is intended purely for type-checking; it contains no runtime logic and should be imported wherever Fleet API responses are parsed or consumed (e.g., services, composables, or UI components displaying device details).
