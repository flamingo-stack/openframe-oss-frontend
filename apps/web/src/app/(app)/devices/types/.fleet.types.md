## fleet.types.ts

TypeScript type definitions modeling the response shape of Fleet MDM's host API (`GET /hosts/:id`), covering host hardware, software inventory, policies, vulnerabilities, MDM enrollment, and user/geolocation metadata.

## Key Components

- **`FleetVulnerability`** — CVE details for detected software vulnerabilities, including optional Fleet Premium severity fields (CVSS score, EPSS probability, CISA exploit flag).
- **`FleetGeolocation`** — GeoIP data derived from the host's public IP.
- **`FleetEndUser`** — End-user identity info (email, IdP groups) associated with a host.
- **`FleetHostPolicy`** — A policy check result scoped to a single host (`pass`/`fail`/`''`).
- **`FleetSoftware`** — Installed software entry with source, vendor, CPE, and associated vulnerabilities.
- **`FleetUser`**, **`FleetBattery`**, **`FleetLabel`** — Host-level OS user accounts, battery health, and Fleet label metadata.
- **`FleetMdmInfo`** — MDM enrollment status and profile sync state.
- **`FleetIssues`** — Aggregate counts of failing policies/issues for a host.
- **`FleetHost`** — The comprehensive host entity combining hardware, network, storage, software, MDM, policy, and organizational data.
- **`FleetHostResponse`** — Top-level API response wrapper (`{ host: FleetHost }`).

## Usage Example

```typescript
import type { FleetHostResponse, FleetHost } from './fleet.types';

async function getHost(id: number): Promise<FleetHost> {
  const res = await fetch(`/api/fleet/hosts/${id}`);
  const data: FleetHostResponse = await res.json();
  return data.host;
}

const host = await getHost(42);

if (host.status === 'online' && host.mdm.connected_to_fleet) {
  console.log(`${host.display_name} has ${host.issues.failing_policies_count} failing policies`);
}

const vulnerableSoftware = host.software?.filter(
  (sw) => sw.vulnerabilities && sw.vulnerabilities.length > 0
);
```

Use these types when consuming Fleet MDM host data in API clients, UI components, or data transformation layers to ensure type-safe access to host fields.
