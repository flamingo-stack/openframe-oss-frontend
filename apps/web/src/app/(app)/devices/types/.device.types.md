# device.types.ts

Central type definitions for the unified Device domain model used across the OpenFrame device management UI. It establishes a flat, non-nested `Device` interface as the single source of truth, along with supporting types for software inventory, vulnerabilities, policies, tool connections, and GraphQL response shapes.

## Key Components

- **`Software`** — A software title from Fleet's inventory, including source type, vendor, code-signing info, and associated vulnerabilities.
- **`Vulnerability`** — A CVE entry on a `Software` item, with optional Fleet Premium severity fields (CVSS score, EPSS probability, CISA known-exploit flag).
- **`DevicePolicy`** — A compliance policy result evaluated against a device (from Fleet MDM).
- **`Battery`**, **`User`**, **`DeviceGeolocation`** — Hardware/user/location detail types.
- **`ToolType`** / **`ToolConnection`** — Represents a device's connection to `MESHCENTRAL` or `FLEET_MDM`, including status and vulnerability-matching timestamps.
- **`DeviceDataSources`** — Fan-out outcome of Fleet detail fetches (`skipped-pending`, `skipped-disconnected`, `ok`, `error`) used to distinguish loading/empty/error states in the UI.
- **`InstalledAgent`** — Agent installation metadata for a machine.
- **`Device`** — The unified, flat device model combining identifiers, hardware, network, OS, software arrays, organization, tags, tool connections, and Fleet-derived metadata.
- **`GraphQlResponse<T>`** — Generic wrapper for GraphQL query results with optional errors.
- **`PartialNamedDevice`** — A `Partial<Device>` that still requires `nickname`, preventing silent hostname fallback in partial device contexts.
- **`DeviceGraphQlNode`** — Raw GraphQL node shape returned by device queries, including `tagAssignments` which get transformed into `DeviceTag[]`.

## Usage Example

```typescript
import type { Device, Software, ToolConnection, PartialNamedDevice } from './device.types';

function getActiveSoftware(device: Device): Software[] {
  return device.software?.filter(s => s.vulnerabilities.length === 0) ?? [];
}

function isFleetConnected(connections: ToolConnection[] = []): boolean {
  return connections.some(c => c.toolType === 'FLEET_MDM' && c.status === 'connected');
}

function renderDeviceName(device: PartialNamedDevice): string {
  // nickname is guaranteed, so no silent fallback to hostname
  return device.nickname ?? device.displayName ?? device.hostname ?? 'Unknown Device';
}
```
