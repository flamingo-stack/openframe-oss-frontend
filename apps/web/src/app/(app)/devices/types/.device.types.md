## device.types.ts

Centralized TypeScript type definitions for the unified Device domain model, consolidating device data from multiple sources (Fleet MDM, MeshCentral, directory services) into a single flat structure with no nested objects.

## Key Components

- **`Software`** / **`Vulnerability`** — Fleet-sourced software inventory and CVE data for the Software/Vulnerabilities tabs.
- **`DevicePolicy`** — Compliance policy evaluation results from Fleet MDM.
- **`Battery`**, **`User`**, **`DeviceGeolocation`** — Hardware/user/location metadata.
- **`ToolType`** / **`ToolConnection`** — Represents connections to backing tools (`MESHCENTRAL`, `FLEET_MDM`), including sync timestamps and vulnerability-matching status.
- **`DeviceDataSources`** — Per-source fetch outcome (`skipped-pending` | `skipped-disconnected` | `ok` | `error`) used to distinguish loading states from genuine empty data.
- **`InstalledAgent`** — Agent installation records tied to a device.
- **`Device`** — The unified device model: core identifiers, hardware (CPU/memory/storage), network, OS info, organization data, tags, tool connections, and legacy aliases for backward compatibility.
- **`GraphQlResponse<T>`** — Generic GraphQL response wrapper with `data`/`errors`.
- **`PartialNamedDevice`** — A `Partial<Device>` that still requires `nickname`, preventing accidental loss of the name-resolution contract (see `DeviceNameSource`).
- **`DeviceGraphQlNode`** — Raw GraphQL query shape (pre-transform), including `tagAssignments` which get mapped into `DeviceTag[]` before reaching `Device`.

## Usage Example

```typescript
import type { Device, DeviceGraphQlNode, PartialNamedDevice } from '@/types/device.types';

// Rendering a device name safely requires nickname to be present (even if undefined)
function resolveDeviceName(device: PartialNamedDevice): string {
  return device.nickname ?? device.displayName ?? device.hostname ?? 'Unknown device';
}

// Transforming a raw GraphQL node into the unified Device shape
function transformDevice(node: DeviceGraphQlNode): Device {
  return {
    id: node.id,
    machineId: node.machineId,
    hostname: node.hostname,
    displayName: node.displayName ?? node.hostname,
    nickname: node.nickname ?? undefined,
    status: node.status,
    local_ips: [],
    organizationId: node.organization?.id,
    organization: node.organization?.name,
    organizationEmail: node.organization?.contactInformation?.contacts?.[0]?.email,
    tags: node.tagAssignments?.map((a) => ({
      id: a.tag.id,
      key: a.tag.key,
      values: a.values,
    })),
  };
}
```
