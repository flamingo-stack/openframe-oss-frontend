## session-recording.ts

Defines the TypeScript read-model types for remote session recordings, used by the Remote Sessions tab and the recording playback page. These types describe data shapes returned by the openframe-saas-api client, covering session summaries, recording state transitions, retention/keep policies, and detailed recording playback data (segments, chat, storage).

## Key Components

- **`RecordingEmployee`** - Technician display info (name, role, avatar).
- **`RecordingState`** - Union type tracking recording lifecycle: `none`, `processing`, `ready`, `failed`, `expired`, `deleted`.
- **`RecordingKeep`** - Represents a retention override ("Keep") on a recording, including who placed it, reason, and expiration behavior on release.
- **`RecordingSummary`** - A single row in the Remote Sessions tab, combining session metadata (duration, size, protocol) with recording/keep state.
- **`RecordingChatMessage`** - A chat message exchanged during a session, tagged by technician vs. end user.
- **`RecordingSegment`** - One `.mcrec` file belonging to a session (sessions that re-pair produce multiple segments).
- **`RecordingDetail`** - Extends `RecordingSummary` with full playback data: organization, resolution, segments, and chat.
- **`LiveSessionDetail`** - Extends `RecordingSummary` for the live session page, including `notRecorded` flag and live chat `dialogId`.
- **`RecordingStorage`** - Tenant-level recording storage quota/usage, distinguishing kept vs. general pool capacity.

## Usage Example

```typescript
import type {
  RecordingSummary,
  RecordingDetail,
  RecordingState,
} from './session-recording';

function isPlayable(state: RecordingState): boolean {
  return state === 'ready';
}

function renderRow(session: RecordingSummary) {
  const canPlay = session.recordingId !== null && isPlayable(session.recordingState);
  return {
    label: `${session.employee.name} — ${session.protocol === 1 ? 'Terminal' : 'Desktop'}`,
    playable: canPlay,
    expiresAt: session.keep?.expiresAtOnRelease ?? session.expiresAt,
  };
}

async function loadDetail(id: string): Promise<RecordingDetail> {
  const response = await fetch(`/api/recordings/${id}`);
  return response.json();
}
```

These types are consumed by components in the Remote Sessions tab and recording player to render state badges, retention controls, and playback timelines built from ordered `segments`.
