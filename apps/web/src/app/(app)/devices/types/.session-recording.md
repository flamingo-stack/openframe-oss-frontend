This file defines TypeScript read-model interfaces for the Remote Sessions tab and session recording/playback pages, as produced by the `openframe-saas-api` client. It models session metadata, recording lifecycle state, retention ("Keep") semantics, and live/recorded session details.

## Key Components

- **`RecordingEmployee`** — Minimal technician identity (name, role, avatar) shown on a session row.
- **`RecordingState`** — Union type tracking a recording's lifecycle: `none`, `processing`, `ready`, `failed`, `expired`, `deleted`.
- **`RecordingKeep`** — Describes a retention hold on a session's files: who placed it, why, and when it would expire if released.
- **`RecordingSummary`** — Core row model for the Remote Sessions tab: session id, device, timing, size, protocol, recording state, live/kept flags, and the technician who ran it.
- **`RecordingChatMessage`** — A single chat entry exchanged during a session.
- **`RecordingSegment`** — One `.mcrec` file belonging to a session (sessions can produce multiple segments across reconnects).
- **`RecordingDetail`** — Extends `RecordingSummary` with organization info, resolution, all file segments, and chat — used by the recording playback page.
- **`LiveSessionDetail`** — Extends `RecordingSummary` for an in-progress session being followed live, including `notRecorded` (recording skipped due to full storage) and live chat.
- **`RecordingStorage`** — Tenant-level storage usage/limits for recordings, including kept-file quotas and a `full` flag.

## Usage Example

```typescript
import type { RecordingSummary, RecordingDetail } from './session-recording';

function renderSessionRow(row: RecordingSummary) {
  const status = row.recordingState === 'ready' ? 'Play' : row.recordingState;
  return `${row.employee.name} — ${status}${row.kept ? ' (kept)' : ''}`;
}

async function loadRecording(id: string): Promise<RecordingDetail> {
  const res = await fetch(`/api/recordings/${id}`);
  return res.json();
}
```

These types are intended purely as data contracts for API responses consumed by UI components; they contain no runtime logic.
