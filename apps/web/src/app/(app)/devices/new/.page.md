This file defines the Next.js page component for the "New Device" route, serving as a thin client-side wrapper around the main content component.

## Key Components

- **`NewDevicePage`** (default export) — A client component (`'use client'`) that renders the `NewDeviceContent` component. Acts as the route entry point for the new device creation page, delegating all logic and UI to `NewDeviceContent`.

## Usage Example

This file is automatically used by Next.js routing based on its file path (e.g., `app/devices/new/page.tsx`) and is not typically imported directly. Navigating to the corresponding route renders this page:

```typescript
// Accessing the route automatically renders NewDevicePage
// e.g., visiting /devices/new in the browser

// The actual implementation and UI logic lives in:
// ./new-device-content.tsx
export function NewDeviceContent() {
  // form fields, validation, submission logic, etc.
  return (
    // ...
  );
}
```

This pattern keeps the page file minimal, separating Next.js routing concerns from the actual component logic implemented in `new-device-content.tsx`, which can be found at [`new-device-content.tsx`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/devices/new/new-device-content.tsx) (path may vary based on actual route structure).
