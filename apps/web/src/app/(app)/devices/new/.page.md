Next.js page component that renders the "New Device" view, serving as the route entry point for creating a new device within the application.

## Key Components

- **`NewDevicePage`** - Default-exported React client component that acts as the route handler for the new device page. It delegates all rendering logic to the `NewDeviceContent` component.

## Usage Example

This file is automatically used by the Next.js App Router based on its file path (e.g., `app/devices/new/page.tsx`). It requires no manual invocation—navigating to the corresponding route renders this page.

```typescript
// Accessing the route triggers this page component
// e.g., navigating to /devices/new

export default function NewDevicePage() {
  return <NewDeviceContent />;
}
```

The actual UI and logic (forms, state management, submission handling) are implemented in the `NewDeviceContent` component, keeping this page component minimal and focused solely on route-level composition. The `'use client'` directive ensures this component and its children are rendered on the client side, enabling interactive features such as form handling and state updates.

For implementation details on device creation, see the `new-device-content` component in the same directory:
[`new-device-content.tsx`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/new-device-content.tsx)
