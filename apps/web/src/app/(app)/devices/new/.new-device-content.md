## new-device-content.tsx

Renders the "New Device" page, a multi-step form for registering a new device under a customer organization. It handles organization selection, OS platform/install method selection, tag management, remote access mode configuration, and generates copyable install/registration commands, all wrapped in a loading-suspense boundary.

## Key Components

- **`NewDeviceContent`** – Top-level exported component; wraps the form in a `LoadingSuspense` boundary with a loading label.
- **`NewDeviceContentReader`** – Determines whether the app is in a loading scope and renders either a skeleton form (no orgs) or the live data-driven form.
- **`NewDeviceContentLive`** – Fetches organizations via `useDeviceOrganizations` and reads the `organizationId` query param for pre-selection, then renders `NewDeviceForm`.
- **`NewDeviceForm`** – The core form component:
  - Uses `react-hook-form` + `zod` (`newDeviceSchema`) for validation of `organizationId`, `platform`, `installMethod`, and `remoteAccessMode`.
  - Manages tags state (`TagEntryWithId[]`) with validation via `isValidTag`.
  - Integrates `useInstallCommand` to generate install/register commands based on form state.
  - Integrates `useRemoteAccessApprovalGate` and `useOrganizationRemoteAccessPolicy` to conditionally show remote access options (feature-flagged via `useFeatureFlag('remote-access-v2')`).
  - Provides clipboard copy handlers (`copyCommand`, `copyInstallScript`, `copyRegisterCommand`) via `useCopyToClipboard`, each validated through `validateBeforeAction`.
  - Renders customer `Autocomplete`, OS platform selector (`OsPlatformSelector`), install method `Select`, tags editor (`TagsEditor`), and command display (`CommandBox`).
- **`newDeviceSchema` / `NewDeviceFormValues`** – Zod schema and inferred type for form validation.

## Usage Example

```typescript
import { NewDeviceContent } from './new-device-content';

export default function NewDevicePage() {
  return <NewDeviceContent />;
}
```

This component is typically rendered at a route like `/devices/new`, optionally with a query parameter to pre-select a customer:

```text
/devices/new?organizationId=<customer-id>
```
