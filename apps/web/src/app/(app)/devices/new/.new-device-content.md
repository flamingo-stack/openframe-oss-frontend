## new-device-content.tsx

Renders the "New Device" page, providing a form to select a customer organization, OS platform, and installation method, and generating a copyable install/registration command for enrolling a new device.

## Key Components

- **`NewDeviceContent`** — Top-level exported component; wraps the form in a `LoadingSuspense` boundary with a loading label.
- **`NewDeviceContentReader`** — Detects whether it's rendering inside the Suspense fallback (`useLoadingScope`) and renders the form with no organizations in that case, otherwise delegates to the live data loader.
- **`NewDeviceContentLive`** — Reads the `organizationId` query param (for pre-selecting a customer) and fetches organizations via `useDeviceOrganizations`.
- **`NewDeviceForm`** — Main form component built with `react-hook-form` + `zod` (`newDeviceSchema`). Manages:
  - Customer (`organizationId`), platform, install method, and remote access mode fields
  - Tag editing (`TagsEditor`) with validation (`isValidTag`, deduplication)
  - Install/registration command generation via `useInstallCommand`
  - Remote access policy resolution via `useOrganizationRemoteAccessPolicy` (gated by feature flags `remote-access-v2` and `useRemoteAccessApprovalGate`)
  - Clipboard copy actions (`useCopyToClipboard`) for the full command, install-only script, or register-only command
  - Validation (`validateBeforeAction`) ensuring a customer is selected, tags are valid/unique, and the registration secret is loaded
- **`newDeviceSchema` / `NewDeviceFormValues`** — Zod schema and inferred type for form validation.

## Usage Example

```typescript
import { NewDeviceContent } from '@/app/devices/new/new-device-content';

export default function NewDevicePage() {
  return <NewDeviceContent />;
}
```

The component is self-contained—mount it as a route's page body (e.g. `/devices/new`). It optionally reads an `organizationId` search param to pre-select a customer:

```text
/devices/new?organizationId=<id>
```

No props are required; all data fetching (organizations, install command, remote access policy) is handled internally via hooks.
