Loading state placeholder component that renders a skeleton UI for the "New Device" page while content is being fetched.

## Key Components

**`NewDeviceSkeleton`** — A functional React component that mirrors the layout structure of the New Device page using animated skeleton placeholders. It replicates the following sections:

- **Breadcrumb/title bar** — Narrow skeleton for page heading
- **Page header** — Action button placeholder
- **Organization + Platform fields** — Two-column responsive grid of form field skeletons
- **Add Device Tag row** — Icon and label placeholders
- **Command box card** — Title, command textarea, and two action button skeletons
- **Antivirus warning card** — Banner, description, five list-item rows, and a full-width footnote skeleton

## Usage Example

```typescript
import { NewDeviceSkeleton } from './new-device-skeleton';

// Render while the New Device page data is loading
function NewDevicePage() {
  const { data, isLoading } = useNewDeviceData();

  if (isLoading) {
    return <NewDeviceSkeleton />;
  }

  return <NewDeviceContent data={data} />;
}
```
