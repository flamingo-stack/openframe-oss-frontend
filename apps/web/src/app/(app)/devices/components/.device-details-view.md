# device-details-view.tsx

Renders the full device detail page: a loading-aware header (title, status tag, action buttons/menu), tab navigation for device sub-views, and modals/dialogs for device actions (run script, delete, reboot, etc.). It is the primary client component backing the device detail route.

## Key Components

- **`DeviceDetailsView`** — Main exported component. Accepts a `deviceId` prop, fetches device details via `useDeviceDetails`, manages the active tab (synced to the URL's `tab` query param via `history.replaceState`), builds header actions/menu from `useDeviceActionsMenu`, and renders `PageLayout` with `TabNavigation`/`TabContent` and the `RunScriptModal`.
- **`DeviceStatusTag`** — Internal helper that renders the device status `Tag` next to the title, showing a loading skeleton while status is unresolved.
- **`DETAIL_ICON_SIZE`** — Shared icon sizing token applied only to dropdown menu item icons (header button icons are sized by the button variant itself).
- **`DEFAULT_DEVICE_TAB`** — Fallback tab id (`'overview'`) used when no valid `tab` query param is present.
- **`DeviceDetailsViewProps`** — Props interface requiring `deviceId: string`.

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view';

// Typical usage in a Next.js route page
export default function DevicePage({ params }: { params: { deviceId: string } }) {
  return <DeviceDetailsView deviceId={params.deviceId} />;
}
```

Behavioral highlights:
- **Tab state** is derived from `?tab=` in the URL, validated against the tenant/flag-gated `useDeviceTabs` list, falling back to `overview` if invalid or missing.
- **Deep-link action**: `?action=runScript` on load automatically opens the `RunScriptModal` and strips the param from the URL.
- **Loading states** are handled declaratively via `LoadingWhen`/`useLoadingScope`, so header, tabs, and tag render skeletons instead of conditionally hiding the whole page.
- **Error/not-found states** short-circuit rendering with `LoadError` or `NotFoundError`.
- Relative "Updated X ago" subtitle refreshes every second via a forced re-render interval.
