# device-actions-dropdown.tsx

A React component that renders a context-aware dropdown menu of device actions (remote shell, remote control, file management, script execution, rename, reboot, delete) for a given device, adapting its contents based on whether it's used in a table row or a device detail page.

## Key Components

- **`DeviceActionsDropdown`** — Main exported component that builds and renders the actions dropdown menu along with any associated confirmation/action dialogs.
- **`DeviceActionsDropdownProps`** — Props interface:
  - `device: Device` — the target device for the actions.
  - `context: 'table' | 'detail'` — controls which actions appear (table rows expose Remote Shell/Control/Files inline in the menu, while detail pages expose them as separate buttons elsewhere, so the menu omits them).
  - `onActionComplete?: () => void` — callback fired after an action completes.
  - `onRunScript?: () => void` — callback fired when the "Run Script" action is triggered.

The component delegates action/state logic to the `useDeviceActionsMenu` hook, which returns `items` (available menu actions) and `dialogs` (any modal/dialog elements needed by those actions). Menu groups are memoized via `useMemo` and grouped into a primary action group (with separator) and a destructive action group (e.g., delete).

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown';

function DeviceTableRow({ device }: { device: Device }) {
  return (
    <DeviceActionsDropdown
      device={device}
      context="table"
      onActionComplete={() => refetchDevices()}
      onRunScript={() => openScriptRunner(device)}
    />
  );
}

function DeviceDetailPage({ device }: { device: Device }) {
  return (
    <DeviceActionsDropdown
      device={device}
      context="detail"
      onActionComplete={() => router.push('/devices')}
    />
  );
}
```

**Note:** The component returns `null` when no menu groups are applicable (e.g., no actions available for the device), avoiding rendering an empty dropdown. The wrapping `<div>` includes `data-no-row-click` to prevent click-through to row/detail navigation handlers when embedded in clickable table rows.
