A context-aware dropdown menu component that renders available actions for a device, grouping them into action and destructive sections based on the display context.

## Key Components

### `DeviceActionsDropdownProps`
| Prop | Type | Description |
|------|------|-------------|
| `device` | `Device` | The target device object |
| `context` | `'table' \| 'detail'` | Controls which actions are shown (Remote Shell/Control/Files are omitted in `detail` context as they appear elsewhere) |
| `onActionComplete` | `() => void` | Optional callback fired after an action completes |
| `onRunScript` | `() => void` | Optional callback for the run script action |

### Internal Structure
- **Action group** — Conditionally includes `remoteShell`, `remoteControl`, `manageFiles` (table only), and `runScript`; rendered with a separator
- **Destructive group** — Conditionally includes `archive`, `unarchive`, and `delete` actions
- Delegates action logic and dialog rendering to `useDeviceActionsMenu`
- Returns `null` when no groups are available to avoid rendering an empty dropdown

## Usage Example

```typescript
// In a table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
  onRunScript={() => openScriptPanel()}
/>

// In a device detail page
<DeviceActionsDropdown
  device={device}
  context="detail"
  onActionComplete={() => router.push('/devices')}
/>
```

> **Note:** The wrapping `<div data-no-row-click>` prevents click events from bubbling to parent table row handlers when rendered in a table.
