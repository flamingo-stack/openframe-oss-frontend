# device-actions-dropdown.tsx

A React client component that renders a dropdown menu of device-level actions (e.g., remote shell, remote control, file management, run script, rename, reboot, delete), with action sets adapted based on display context.

## Key Components

- **`DeviceActionsDropdown`** — The main exported component that builds and renders an `ActionsMenuDropdown` populated with contextual device actions.
- **`DeviceActionsDropdownProps`** — Props interface:
  - `device: Device` — the target device for the actions.
  - `context: 'table' | 'detail'` — determines which actions appear (table view shows remote shell/control/files inline; detail view omits them since they're exposed as separate buttons elsewhere).
  - `onActionComplete?: () => void` — optional callback fired when an action finishes.
  - `onRunScript?: () => void` — optional callback for the "run script" action.
- Uses `useDeviceActionsMenu` hook to derive `items` (available action definitions) and `dialogs` (any confirmation/input dialogs triggered by actions).
- Groups actions into an `ActionsMenuGroup[]` array — a primary group of non-destructive actions (with a separator) and a secondary group for destructive actions like delete.

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown';

function DeviceTableRow({ device }: { device: Device }) {
  return (
    <DeviceActionsDropdown
      device={device}
      context="table"
      onActionComplete={() => refetchDevices()}
      onRunScript={() => openScriptRunner(device)}
    />
  );
}

function DeviceDetailPage({ device }: { device: Device }) {
  return (
    <DeviceActionsDropdown
      device={device}
      context="detail"
      onActionComplete={() => router.push('/devices')}
    />
  );
}
```

The component returns `null` when no applicable actions exist for the device, and wraps its output with a `data-no-row-click` attribute to prevent click-through conflicts in table rows.
