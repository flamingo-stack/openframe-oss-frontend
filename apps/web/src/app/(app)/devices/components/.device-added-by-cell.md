# device-added-by-cell.tsx

A React component that renders a device table/detail cell showing which user enrolled a device, resolving the user's name and avatar via a Relay GraphQL query while gracefully handling missing, deleted, or unresolvable users.

## Key Components

- **`DeviceAddedByCell`** — Public entry point. Wraps content in a `ContentErrorBoundary` so a failed user lookup silently falls back to the empty state instead of surfacing an error toast.
- **`DeviceAddedByContent`** — Wraps the reader in a `LoadingSuspense` boundary with an accessible loading label.
- **`DeviceAddedByReader`** — Checks for an active loading scope (skeleton state) and short-circuits to a placeholder avatar/name when no `userId` is provided.
- **`DeviceAddedByQuery`** — Executes the `deviceAddedByCellQuery` GraphQL query via `useLazyLoadQuery`, resolving the user node and mapping it through `toUserSummary`. Renders the deleted-employee placeholder if the node is no longer a `User`, or a deleted-user avatar if the account was removed.
- **`AddedBy`** — Presentational layout combining an optional avatar with an `InfoCell` labeled "Added by".
- **`deviceAddedByCellQueryNode`** — The GraphQL query definition fetching a `User` node by global id, spreading `userSummaryFields_user`.

## Usage Example

```typescript
import { DeviceAddedByCell } from '@/app/components/devices/device-added-by-cell';

function DeviceRow({ device }: { device: { addedByUserId?: string | null } }) {
  return (
    <div className="flex items-center gap-4">
      <DeviceAddedByCell userId={device.addedByUserId} />
    </div>
  );
}
```

The component expects `userId` to be a raw (non-global) user id; it internally converts it using `ensureGlobalIdForType('User', userId)` before querying. Pass `null`/`undefined` for devices enrolled before user tracking existed—the cell renders an empty-state label automatically.
