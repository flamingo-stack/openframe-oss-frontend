A client-side React component that renders a platform-aware warning instructing users to run the OpenFrame agent installer with elevated (administrator/sudo) privileges.

## Key Components

- **`AdminPrivilegesWarningProps`** — Interface accepting a single `platform` prop of type `OSPlatformId` (`'windows' | 'darwin' | 'linux'`).
- **`PLATFORM_INSTRUCTION`** — Record mapping each platform to a short, human-readable instruction (e.g., "Run PowerShell as Local Administrator").
- **`PLATFORM_NOTE`** — Record mapping each platform to a detailed warning note explaining the consequences of skipping elevated privileges and how to resolve it.
- **`AdminPrivilegesWarning`** — The exported functional component. Renders a `WarningBlock` containing:
  - A heading prompting the user to run the install command with proper permissions.
  - A `PathsDisplay` showing the platform-specific instruction alongside an `OSTypeIcon`.
  - A closing paragraph with the platform-specific elevation note.

## Usage Example

```typescript
import { AdminPrivilegesWarning } from './admin-privileges-warning';

export function InstallInstructions() {
  const platform = 'darwin'; // typically derived from OS detection logic

  return (
    <div className="install-steps">
      <AdminPrivilegesWarning platform={platform} />
    </div>
  );
}
```

This component is typically rendered within an agent installation wizard or onboarding flow, where the detected or selected target OS platform (`windows`, `darwin`, or `linux`) is passed in to display the correct privilege-escalation guidance.
