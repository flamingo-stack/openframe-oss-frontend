# admin-privileges-warning.tsx

A client-side React component that displays a platform-aware warning instructing users to run OpenFrame agent installation commands with administrator/sudo privileges.

## Key Components

- **`AdminPrivilegesWarningProps`** — Interface defining the component's single prop: `platform` of type `OSPlatformId`.
- **`PLATFORM_INSTRUCTION`** — Record mapping each supported OS platform (`windows`, `darwin`, `linux`) to the elevation instruction text shown next to the platform icon.
- **`PLATFORM_NOTE`** — Record mapping each platform to a detailed cautionary note explaining consequences of missing elevated privileges and how to resolve them.
- **`AdminPrivilegesWarning`** — The exported component that renders a `WarningBlock` containing the platform icon, elevation instruction, and detailed note, using `PathsDisplay` to format the instruction visually.

## Usage Example

```typescript
import { AdminPrivilegesWarning } from './admin-privileges-warning';

function InstallInstructions() {
  const detectedPlatform = 'darwin'; // or 'windows' | 'linux'

  return (
    <div>
      <AdminPrivilegesWarning platform={detectedPlatform} />
    </div>
  );
}
```

This component is typically rendered as part of an agent installation wizard or onboarding flow, where the user's operating system has already been detected or selected, and the appropriate elevation guidance (PowerShell as Administrator for Windows, `sudo` for macOS/Linux) needs to be surfaced prominently to prevent silent installation failures.
