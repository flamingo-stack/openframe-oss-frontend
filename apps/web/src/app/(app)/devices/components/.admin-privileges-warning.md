Renders a platform-aware warning block informing users that administrator privileges are required before installing the OpenFrame agent, displaying the appropriate elevation instruction and note for Windows, macOS, or Linux.

## Key Components

- **`AdminPrivilegesWarningProps`** — Interface accepting a single `platform: OSPlatformId` prop
- **`PLATFORM_INSTRUCTION`** — Record mapping each OS to a short elevation instruction (e.g., `"Run PowerShell as Local Administrator"`)
- **`PLATFORM_NOTE`** — Record mapping each OS to a detailed fallback/escalation message explaining silent failure risks
- **`AdminPrivilegesWarning`** — Named export; composes `WarningBlock`, `PathsDisplay`, and `OSTypeIcon` from `openframe-frontend-core` to render the full warning UI

## Usage Example

```typescript
import { AdminPrivilegesWarning } from './admin-privileges-warning';

// Inside an agent installation flow
<AdminPrivilegesWarning platform="windows" />
// → Renders a WarningBlock with PowerShell elevation instructions

<AdminPrivilegesWarning platform="darwin" />
// → Renders a WarningBlock with sudo instructions for macOS
```

## Supported Platforms

| `OSPlatformId` | Instruction |
|---|---|
| `windows` | Run PowerShell as Local Administrator |
| `darwin` | Run Terminal with sudo privileges |
| `linux` | Run Terminal with sudo privileges |

## Notes

- This is a **Client Component** (`'use client'`); ensure it is used within a React client boundary
- `showCopyButtons={false}` is intentionally set — the instruction is informational, not a copyable command
