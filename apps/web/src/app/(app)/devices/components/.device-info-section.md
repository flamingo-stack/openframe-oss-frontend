# device-info-section.tsx

Renders a responsive device details card displaying hostname, device model, type, serial number, customer, added-by, registration/update timestamps, and UUID (with copy-to-clipboard support). Adapts its layout across mobile, tablet, and desktop breakpoints, and integrates with a shared loading scope so each cell can render its own skeleton state while data loads.

## Key Components

- **`DeviceInfoSection`** — Main exported component. Accepts a `device` prop and renders a card with responsive row layouts (mobile single-column, tablet paired, desktop 4-column grid).
- **`formatDateWithTime`** — Internal helper that formats an ISO date string into a date + secondary-styled time string, returning `null` for invalid/missing dates.
- **Layout class constants** (`ROW_CLASS`, `CLOSING_ROW_CLASS`, `MOBILE_SINGLE_ROW_CLASS`, `TABLET_PAIR_ROW_CLASS`, `CARD_CLASS`, `ICON_SIZE`, `OS_ICON_SIZE`) — Shared Tailwind class strings ensuring consistent spacing, dividers, and icon sizing across breakpoints.
- Uses `InfoCell` and `CustomerInfoCell` (shared components) plus `DeviceAddedByCell` to render individual labeled values, and `useCopyToClipboard` for the UUID copy action.

## Usage Example

```typescript
import { DeviceInfoSection } from '@/app/components/device-info-section';
import type { Device } from '../types/device.types';

function DeviceDetailsPage({ device }: { device: Device | null }) {
  return (
    <div className="space-y-4">
      <DeviceInfoSection device={device} />
    </div>
  );
}
```

When `device` is `null` and not within a loading scope, the component renders a "No device data available" placeholder. While wrapped in a loading scope (e.g., via a parent `Suspense`/loading provider), each `InfoCell` renders its own skeleton placeholder instead of blocking the entire section.
