# device-info-section.tsx

Renders a responsive card displaying detailed device metadata (hostname, type, OS, serial number, customer, registration dates, UUID) with distinct layouts for mobile, tablet, and desktop viewports.

## Key Components

- **`DeviceInfoSection`** — Main exported component that accepts a `device` object (or `null`) and renders a structured info card. Handles loading states via `useLoadingScope` and displays an empty state when no device data is available.
- **`formatDateWithTime`** — Internal helper that formats an ISO date string into a React node showing date and time (with seconds), or `null` if invalid.
- **Layout constants** (`ROW_CLASS`, `CLOSING_ROW_CLASS`, `MOBILE_SINGLE_ROW_CLASS`, `TABLET_PAIR_ROW_CLASS`, `CARD_CLASS`, `ICON_SIZE`, `OS_ICON_SIZE`) — Shared Tailwind class strings defining consistent spacing, borders, and icon sizing across responsive breakpoints.

The component composes reusable info cells (`InfoCell`, `CustomerInfoCell`, `DeviceAddedByCell`) built once and reused across the mobile/tablet stacked layout and the desktop 4-column grid, ensuring visual consistency and avoiding duplicated logic.

## Usage Example

```typescript
import { DeviceInfoSection } from './device-info-section';
import type { Device } from '../types/device.types';

function DeviceDetailsPage({ device }: { device: Device | null }) {
  return (
    <div className="space-y-4">
      <DeviceInfoSection device={device} />
    </div>
  );
}
```

When `device` is `null` and no loading scope is active, the component renders a "No device data available" placeholder. Within a loading scope (e.g., while data is being fetched), each `InfoCell` automatically displays its own skeleton loading state instead of requiring external loading props.

Key fields rendered include hostname, manufacturer/model, device type icon, OS type icon, serial number, customer/organization info (with logo), the user who added the device, registration/update timestamps, and a copyable UUID field (via `useCopyToClipboard`).
