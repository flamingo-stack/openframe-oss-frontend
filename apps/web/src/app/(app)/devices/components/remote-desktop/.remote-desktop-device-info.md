Renders the device identity header for the Remote Desktop view, displaying a monitor icon alongside the device's title (name) and subtitle (typically "Desktop • <customer>") using the shared `DeviceIdentity` layout component.

## Key Components

- **`RemoteDesktopDeviceInfo`** — Client component that accepts `title` and `subtitle` string props and renders them inside a `DeviceIdentity` wrapper, prefixed with a styled monitor icon tile.
- **`ICON_TILE_CLASS`** — Shared Tailwind class string defining the bordered, padded icon container styling (card background, rounded border, system spacing).

## Usage Example

```typescript
import { RemoteDesktopDeviceInfo } from './remote-desktop-device-info';

export function RemoteDesktopHeader({ device, customer }: { device: string; customer: string }) {
  return (
    <RemoteDesktopDeviceInfo
      title={device}
      subtitle={`Desktop • ${customer}`}
    />
  );
}
```

This component is typically placed at the top of a remote desktop session panel to give users quick visual confirmation of which device and customer they're currently connected to.
