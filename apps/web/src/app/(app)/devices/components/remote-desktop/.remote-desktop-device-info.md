Renders the device identity header shown in the remote desktop view, displaying a monitor icon alongside the device name and its "Desktop • customer" subtitle.

## Key Components

- **`RemoteDesktopDeviceInfo`** — Functional component accepting `title` and `subtitle` string props. Wraps the shared `DeviceIdentity` component, supplying a styled monitor icon tile as the leading visual element.
- **`ICON_TILE_CLASS`** — Shared Tailwind class string defining the bordered, padded icon container (`ods-border`/`ods-card` design tokens) used to frame the `MonitorIcon`.

## Usage Example

```tsx
import { RemoteDesktopDeviceInfo } from './remote-desktop-device-info';

export function RemoteDesktopHeader() {
  return (
    <RemoteDesktopDeviceInfo
      title="WIN-DESKTOP-01"
      subtitle="Desktop • Acme Corp"
    />
  );
}
```

This component is intended for use at the top of the remote desktop session view, giving users quick confirmation of which device and customer they are currently connected to. It relies on `DeviceIdentity` for consistent layout/spacing with other device info headers across the app, and on the `MonitorIcon` from `@flamingo-stack/openframe-frontend-core` for the icon treatment.
