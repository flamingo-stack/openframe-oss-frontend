# edit-display-name-modal.tsx

A modal component for editing a device's display name (nickname) and, when the remote-access-approval feature flag is enabled, its per-device Remote Access Permission override. Clearing the name field reverts the device's title to the agent-reported `displayName`/`hostname`.

## Key Components

- **`EditDisplayNameModal`** — Main exported component rendering a `SimpleModal` with:
  - A `Display Name` text input, seeded from `device.nickname` on open.
  - A conditional `Remote Access Permission` `Select` (shown only if `useRemoteAccessApprovalGate()` returns `'on'`), offering `Customer Default` plus the other `REMOTE_ACCESS_CHOICES`.
  - Save/Cancel footer buttons, disabled while mutations are pending.
- **`EditDisplayNameModalProps`** — Props interface: `isOpen`, `onClose`, `device: Device | null`, optional `onSaved` callback.

Internally it composes several hooks:
- `useDeviceActions` for saving the nickname (`updateNickname`).
- `useDeviceRemoteAccessPolicy`, `useOrganizationRemoteAccessPolicy`, `useTenantRemoteAccessPolicy` to resolve the device's current override and the customer's effective mode (used to label "Customer Default").
- `useSetDeviceRemoteAccessMode` to persist a chosen mode (`null` clears the override, inheriting the customer/tenant default).

State is re-seeded on each open transition (via render-time comparison of `isOpen`/`wasOpen`) rather than via `useEffect`, avoiding a flash of stale data.

## Usage Example

```typescript
import { useState } from 'react';
import { EditDisplayNameModal } from './edit-display-name-modal';
import type { Device } from '../types/device.types';

function DeviceRow({ device }: { device: Device }) {
  const [isEditOpen, setIsEditOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsEditOpen(true)}>Edit</button>
      <EditDisplayNameModal
        isOpen={isEditOpen}
        onClose={() => setIsEditOpen(false)}
        device={device}
        onSaved={() => console.log('Device updated')}
      />
    </>
  );
}
```
