# edit-display-name-modal.tsx

A modal component for editing a device's display name (nickname) and, when the remote-access-approval feature gate is enabled, its per-device Remote Access Permission override.

## Key Components

- **`EditDisplayNameModal`** — The main exported React component. Renders a `SimpleModal` with:
  - A text input for the device's display name (clearing it reverts the title to the agent-reported `displayName`/`hostname`).
  - A conditional `Select` dropdown for Remote Access Permission, shown only when `useRemoteAccessApprovalGate()` returns `'on'`.
- **`EditDisplayNameModalProps`** — Props interface: `isOpen`, `onClose`, `device` (nullable `Device`), and optional `onSaved` callback.

### Behavior Notes
- Form state (`name`, `pickedChoice`) is seeded during render on the `isOpen` transition (not via `useEffect`) to avoid flicker from stale previous values.
- The permission select defaults to `CUSTOMER_DEFAULT` when no device-level override exists, resolving its displayed label against the effective customer (organization) or tenant mode.
- Saving `CUSTOMER_DEFAULT` clears the override (sends `mode: null`), causing the device to inherit the parent customer's or tenant's policy.
- Submission is blocked (`canSubmit`) unless the name or mode actually changed and a save isn't already in progress.
- Name updates and mode updates are independent save operations; `updateNickname` manages its own success/error toasts, while mode-only saves and errors are toasted locally.

## Usage Example

```typescript
import { EditDisplayNameModal } from './edit-display-name-modal';
import { useState } from 'react';

function DeviceRow({ device }: { device: Device }) {
  const [isEditOpen, setIsEditOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsEditOpen(true)}>Edit</Button>
      <EditDisplayNameModal
        isOpen={isEditOpen}
        onClose={() => setIsEditOpen(false)}
        device={device}
        onSaved={() => {
          // refetch device list or update local cache
        }}
      />
    </>
  );
}
```
