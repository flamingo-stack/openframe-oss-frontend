## live-session-view.tsx

Renders the live-session viewing page for a remote-control session in progress: a meta card, an optional "not being recorded" storage warning, a WebSocket-driven live screen stream with viewer presence and fullscreen support, and a read-only chat transcript mirrored from the technician's session dialog. Polls the session every 10 seconds and automatically hands off to the recording playback page once the session ends and its recording file is ready.

## Key Components

- **`LiveSessionView`** — Main exported component; takes a `sessionId` (nullable while resolving) and orchestrates data loading (`useLiveSession`), live WebSocket streaming (`useRemoteSessionWatch`), and chat (`useRemoteSessionChat`), handling loading, not-found, error, and handoff states.
- **`LiveStreamFrame`** — Renders the canvas video stream with host name, active display badge, viewer list, elapsed-time counter, and fullscreen toggle.
- **`SessionEndedScreen`** — Placeholder shown after the session ends, indicating recording is processing.
- **`ConnectingOverlay`** / **`UnavailableOverlay`** — Overlay states for the stream canvas while the watch socket connects or fails.
- **`titleTag`** — Derives the page's status tag (`'live' | 'processing' | 'failed' | null`) from session state.
- **`displayLabel`**, **`SectionLabel`** — Small formatting/label helpers.
- **`useIsFullscreen`** — Hook tracking whether a given element is the current fullscreen target.
- **`LiveSessionViewProps`** — Props interface (`sessionId: string | null`).

## Usage Example

```typescript
import { LiveSessionView } from './live-session-view';

export default function LiveSessionPage({ params }: { params: { sessionId: string } }) {
  return <LiveSessionView sessionId={params.sessionId ?? null} />;
}
```

The component is self-contained: pass a `sessionId` (or `null` while it's being resolved from route params) and it handles fetching, live streaming, chat, loading/error/not-found states, and automatic navigation to the recording page via `routes.devices.remoteSessionRecording` once the session's recording is ready.
