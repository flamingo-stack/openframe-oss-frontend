Defines the column configuration for the Remote Sessions data table (Figma 1644-6911), rendering session date/status, employee, duration, expiry, and row actions (Open/Delete) with full loading-skeleton and live-session awareness.

## Key Components

- **`remoteSessionColumns()`** – Generic factory function returning a `ColumnDef<T>[]` array for use with the table component. Accepts options for the date filter, employee filter options, a ticking clock (`now`), live-session tracking (`liveRows`), and `onOpen`/`onDelete` callbacks.
- **`SessionCell`** – Renders the session start date/time with a `LIVE` / `PROCESSING` / `FAILED` status tag; shows skeleton bars while loading.
- **`EmployeeCell`** – Renders the employee avatar, name, and role.
- **`ExpiresCell`** – Renders "Kept" (with reason), expiry date (with a soon-to-expire countdown), "Expired", "Deleted", or nothing for live rows.
- **`DurationCell`** – Renders session duration and file size.
- **`SessionActions`** – Renders Delete and Open buttons, each independently enabled based on row state (`canDeleteSession`, `sessionHref`).
- **`liveSessionRowClass()`** – Returns a border class to visually highlight rows currently live.
- **`employeeInitials()`** – Helper producing up-to-two-letter initials from a name for avatar fallback.
- **`RemoteSessionColumnsOptions<T>`** – Options interface for `remoteSessionColumns`.

## Usage Example

```typescript
import { remoteSessionColumns, liveSessionRowClass } from './remote-session-columns';
import type { RecordingSummary } from '../../types/session-recording';

const columns = remoteSessionColumns<RecordingSummary>({
  dateFilter,
  employeeOptions,
  now: Date.now(),
  liveRows,
  onOpen: row => router.push(sessionHref(row, liveRows)!),
  onDelete: row => deleteSession(row.id),
});

// Pass `columns` to the data table component, and use `liveSessionRowClass`
// to style currently-live rows:
<DataTable
  columns={columns}
  data={recordings}
  rowClassName={row => liveSessionRowClass(row, liveRows)}
/>
```

This module is shared by both the per-device and tenant-wide Remote Sessions pages; the latter extends these columns with additional device/customer columns.
