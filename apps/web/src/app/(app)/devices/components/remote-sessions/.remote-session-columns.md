Defines the column configuration for the Remote Sessions data table, rendering session date/status, employee, duration, expiration, and row actions (Open/Delete) according to the Figma spec (1644-6911), with support for live-session highlighting and loading skeleton states.

## Key Components

- **`remoteSessionColumns<T>(options)`** — Factory function returning a `ColumnDef<T>[]` array for use with the table component. Accepts `dateFilter`, `employeeOptions`, `now`, `liveRows`, `onOpen`, and `onDelete` to wire up filtering, live-session detection, and row actions.
- **`liveSessionRowClass(row, liveRows)`** — Returns a border CSS class (`border-ods-error`) for rows representing a currently live session.
- **`SessionCell`** — Renders the session start date/time with a LIVE/PROCESSING/FAILED status tag.
- **`EmployeeCell`** — Renders the employee's avatar, name, and role.
- **`DurationCell`** — Renders recording duration and file size.
- **`ExpiresCell`** — Renders expiration state: kept (with reason), expiry date with countdown, expired, or deleted.
- **`SessionActions`** — Renders Delete and Open/Watch-live buttons, each conditionally enabled based on row state.
- **`RemoteSessionColumnsOptions<T>`** — Interface describing the configuration options required by `remoteSessionColumns`.

## Usage Example

```typescript
import { remoteSessionColumns } from './remote-session-columns';

const columns = remoteSessionColumns({
  dateFilter: { sortDirection: 'desc', range: null, onRangeChange: setRange },
  employeeOptions: [{ id: '1', value: 'jane', label: 'Jane Doe' }],
  now: Date.now(),
  liveRows: liveSessionsMap,
  onOpen: (row) => router.push(sessionHref(row, liveSessionsMap) ?? '#'),
  onDelete: (row) => deleteRecording(row.id),
});

<DataTable columns={columns} data={recordings} getRowClassName={(row) => liveSessionRowClass(row, liveSessionsMap)} />
```

This is typically consumed by both the per-device Remote Sessions table and the tenant-wide sessions page, which extends these columns with additional device/customer fields.
