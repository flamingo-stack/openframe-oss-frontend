This file defines the data shape and transformation logic for the "Assigned Tickets" table on the recording page, converting a GraphQL inline fragment into a plain object usable by UI components, plus a search-matching helper.

## Key Components

- **`recordingTicketFragment`** — GraphQL inline fragment (`recordingTickets_ticket` on `RemoteSessionTicketLink`) declaring the ticket fields read by the table (id, number, title, status, assignee, timestamps).
- **`RecordingTicket`** — Interface representing one row of the Assigned Tickets table, with normalized/nullable fields ready for rendering.
- **`toRecordingTicket(ref)`** — Reads the inline fragment data from a Relay fragment reference and maps it into a `RecordingTicket`, applying defaults (e.g. `'Untitled Ticket'`), normalizing nullish values, and resolving the assignee's avatar via `getFullImageUrl`.
- **`matchesTicketSearch(ticket, search)`** — Predicate used by the "Search for Tickets" box; matches against the ticket title or ticket number (ignoring a leading `#`), case-insensitively.

## Usage Example

```typescript
import { toRecordingTicket, matchesTicketSearch } from './recording-tickets';
import type { recordingTickets_ticket$key } from '@/__generated__/recordingTickets_ticket.graphql';

function buildRows(ticketRefs: recordingTickets_ticket$key[], search: string) {
  return ticketRefs
    .map(toRecordingTicket)
    .filter((ticket) => matchesTicketSearch(ticket, search));
}

// Example row usage in a component
function TicketRow({ ticket }: { ticket: ReturnType<typeof toRecordingTicket> }) {
  return (
    <div>
      <span>#{ticket.ticketNumber ?? '—'}</span>
      <span>{ticket.title}</span>
      <span style={{ color: ticket.statusColor ?? undefined }}>{ticket.statusName}</span>
      <span>{ticket.assignedName ?? 'Unassigned'}</span>
    </div>
  );
}
```

This pattern keeps the Relay fragment reading isolated in `toRecordingTicket`, so table components only deal with the plain `RecordingTicket` shape, and search filtering is centralized in `matchesTicketSearch` for consistent behavior across the UI.
