Renders metadata summary cards for session recordings and live sessions, displaying details like date, resolution, duration, hostname, customer, and employee info in a responsive grid layout with built-in loading states.

## Key Components

- **`MetaFrame`** — Internal layout wrapper providing consistent cell framing (padding, borders, responsive height) for grid cells.
- **`CARD_CLASS`** — Shared Tailwind class string defining the responsive grid layout (2 columns on mobile/tablet, 4 on desktop) used by both card components.
- **`RecordingMetaCard`** — Displays full metadata for a completed recording: Date, Resolution, Duration, File size, Hostname, Customer, Employee, and either an "Expires on" date or "Kept by" info (with lock icon) if the recording has been preserved.
- **`LiveSessionMetaCard`** — Displays a reduced metadata set for an in-progress live session: Date, Resolution, Hostname, Customer, and Employee, omitting fields not yet available (duration, file size, expiry).

Both components use `useLoadingScope()` to detect ambient loading state and render skeleton/placeholder values via `LoadingWhen` and `InfoCell` when data is unavailable.

## Usage Example

```typescript
import { RecordingMetaCard, LiveSessionMetaCard } from './recording-meta-card';

// Completed recording detail page
function RecordingDetailPage({ recording }: { recording: RecordingDetail | null }) {
  return <RecordingMetaCard recording={recording} />;
}

// Active live session view
function LiveSessionPage({ session }: { session: LiveSessionDetail | null }) {
  return <LiveSessionMetaCard session={session} resolution="1920x1080" />;
}
```

Both components handle `null` data gracefully, automatically switching to loading placeholders until the underlying data resolves.
