# session-chat.tsx

A read-only client component that renders the chat transcript for a session recording, displayed alongside the recording player. It reuses the same message row component as the live remote-desktop chat panel, but renders a static history scoped to the recording's technician.

## Key Components

- **`SessionChat`** — Main component that renders a labeled, scrollable chat transcript panel. Returns `null` when there are no messages.
- **`SessionChatProps`** — Props interface:
  - `messages: RecordingChatMessage[]` — ordered list of chat messages to display
  - `employee: RecordingEmployee` — the recording's technician, used to resolve the avatar for technician messages
  - `className?: string` — optional styling override for the root container

## Behavior

- Auto-scrolls to the bottom (latest message) whenever `messages` changes, using a `useEffect` tied to the `scrollRef`. This ensures the transcript opens on the newest message without disrupting manual scroll position on unrelated re-renders.
- On larger viewports (`content-lg` breakpoint), the transcript is absolutely positioned to fill its container height and scrolls internally, matching the player's height. Below that breakpoint, it stacks naturally under the player.
- Each message is rendered via `RemoteDesktopChatMessageRow`, passing `authorName`, `isTechnician`, `avatarUrl`, `sentAt`, and `body`.

## Usage Example

```typescript
import { SessionChat } from './session-chat';
import type { RecordingChatMessage, RecordingEmployee } from '../../types/session-recording';

const employee: RecordingEmployee = {
  id: 'emp-1',
  name: 'Jane Doe',
  avatarUrl: 'https://example.com/avatar.png',
};

const messages: RecordingChatMessage[] = [
  {
    id: 'msg-1',
    author: 'Jane Doe',
    fromTechnician: true,
    sentAt: '2024-01-01T10:00:00Z',
    body: 'Starting the remote session now.',
  },
  {
    id: 'msg-2',
    author: 'Client User',
    fromTechnician: false,
    sentAt: '2024-01-01T10:01:00Z',
    body: 'Thanks, go ahead.',
  },
];

export function RecordingSidebar() {
  return (
    <SessionChat
      messages={messages}
      employee={employee}
      className="w-full max-w-sm"
    />
  );
}
```
