A confirmation dialog component that prompts the user before permanently deleting a remote session, warning that the session's recording and data cannot be restored.

## Key Components

- **`DeleteSessionDialog`** — React component that wraps the shared `ConfirmDialog` with session-deletion-specific copy, styling, and behavior.
- **`DeleteSessionDialogProps`** — Props interface defining:
  - `startedAt`: ISO timestamp string (or `null`) of the session being deleted, shown formatted in the confirmation message.
  - `open` / `onOpenChange`: controls dialog visibility (controlled component pattern).
  - `isPending`: disables/shows loading state on the confirm action while the delete request is in flight.
  - `onConfirm`: callback invoked when the user confirms deletion.

## Usage Example

```typescript
import { useState } from 'react';
import { DeleteSessionDialog } from '@/app/components/sessions/delete-session-dialog';

function SessionRow({ session }: { session: { startedAt: string; id: string } }) {
  const [open, setOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleConfirm = async () => {
    setIsPending(true);
    await deleteSession(session.id);
    setIsPending(false);
    setOpen(false);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Delete</button>
      <DeleteSessionDialog
        startedAt={session.startedAt}
        open={open}
        onOpenChange={setOpen}
        isPending={isPending}
        onConfirm={handleConfirm}
      />
    </>
  );
}
```

This component is intended for use in session list rows and on the session recording playback page, anywhere a destructive delete action needs explicit user confirmation.
