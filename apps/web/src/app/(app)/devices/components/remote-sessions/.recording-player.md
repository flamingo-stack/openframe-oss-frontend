# recording-player.tsx

A presentational React component that renders the playback surface for session recordings, hosting either a KVM canvas (protocol 2) or an xterm terminal (protocol 1) inside a black letterboxed container, with overlays for loading, play prompt, and empty states.

## Key Components

- **`RecordingPlayer`** — Main component rendering the recording playback surface. Accepts a `player` object (from `useRecordingPlayer`), an `unavailableNote` explaining why no recording is available, and an optional `className`.
- **`RecordingPlayerProps`** — Props interface: `player: UseRecordingPlayerResult`, `unavailableNote: string | null`, `className?: string`.

### Rendering States
- **Canvas/Terminal hosts**: Both always mounted; visibility toggled via `protocol` (2 = canvas, 1 = terminal) to avoid detaching the decoder on remount.
- **`seeking` / `waiting`**: Dimming overlay with a pulsing loading icon.
- **`ready`**: Centered Play button overlay shown before first playback starts.
- **`empty` + `unavailableNote`**: "Session recording unavailable" empty state with a clapperboard icon and the reason text.

## Usage Example

```typescript
import { RecordingPlayer } from './recording-player';
import { useRecordingPlayer } from './use-recording-player';

function SessionRecordingView({ recordingUrl }: { recordingUrl: string }) {
  const player = useRecordingPlayer(recordingUrl);
  const unavailableNote = player.state === 'empty' ? 'No frames captured for this session.' : null;

  return (
    <RecordingPlayer
      player={player}
      unavailableNote={unavailableNote}
      className="aspect-video rounded-lg"
    />
  );
}
```

## Notes

- Requires a paired `UseRecordingPlayerResult` object from the `use-recording-player` hook, which supplies refs (`canvasRef`, `terminalHostRef`), the active `protocol`, playback `state`, and the `togglePlay` handler.
- Styling follows the `ods-*` design tokens and Figma specs 758-46350 (player surface) and 775-50606 (empty state).
- Client-only component (`'use client'`) due to DOM refs and interactive playback controls.
