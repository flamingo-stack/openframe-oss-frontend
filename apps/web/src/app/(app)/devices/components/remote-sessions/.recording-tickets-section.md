# recording-tickets-section.tsx

Renders the "Assigned Tickets" table within a recording session view (per Figma 1755-93683), displaying tickets linked to the recording with search, sort, and filter capabilities, plus quick actions to open or unassign a ticket.

## Key Components

- **`RecordingTicketsSection`** — Main exported component. Accepts `tickets` (list of `RecordingTicket`) and `onUnassign` callback. Manages local search, sorting, and column filter state, and renders a `DataTable` with a search bar, header, and body (including an empty state).
- **`recordingTicketColumns`** — Builds the `ColumnDef<RecordingTicket>[]` array for four columns: `TICKET` (title + metadata, sortable), `ASSIGNED` (avatar + name, filterable), `STATUS` (status tag, filterable), and `actions` (unassign/open icon buttons).
- **`RECORDING_TICKET_COLUMNS`** — Static column layout config (widths, headers, responsive hide breakpoints) matching the Figma spec.
- **`initials`** — Derives up to two uppercase initials from a person's name, used as avatar fallback.
- **`filterOptions`** — Converts a list of string values into deduplicated, sorted filter-dropdown options.
- **`UNASSIGNED`** — Constant label used when a ticket has no assignee.

## Usage Example

```typescript
import { RecordingTicketsSection } from './recording-tickets-section';
import type { RecordingTicket } from './recording-tickets';

function RecordingDetailPanel({ tickets }: { tickets: RecordingTicket[] }) {
  const handleUnassign = (ticket: RecordingTicket) => {
    // call API/mutation to unassign the ticket from the recording
    console.log('Unassigning ticket', ticket.id);
  };

  if (tickets.length === 0) {
    return null; // caller omits the section when there are no linked tickets
  }

  return <RecordingTicketsSection tickets={tickets} onUnassign={handleUnassign} />;
}
```

Clicking a row or the chevron button navigates to `routes.tickets.dialog(ticket.id)` via Next.js router; clicking the trash icon invokes `onUnassign` without triggering row navigation (`data-no-row-click`).
