# use-recording-player.ts

A React hook that manages a MeshCentral session recording player (`McrecPlayer`), handling segment loading, playback control, and rendering to either a canvas (desktop recordings) or an xterm terminal (text recordings).

## Key Components

- **`useRecordingPlayer()`** — Main hook that creates and owns a single `McrecPlayer` instance for the lifetime of the component, exposing reactive state and imperative controls.
- **`UseRecordingPlayerResult`** — Interface describing the hook's return value:
  - `state`, `currentMs`, `durationMs`, `speed`, `protocol`, `timeline` — reactive playback state.
  - `canvasRef`, `terminalHostRef` — refs to attach to DOM elements for rendering.
  - `loadSegments(sources)` — loads session files (oldest first) into one continuous timeline, streaming them in as they're fetched; skips failed files and reports the count.
  - `togglePlay()`, `seek(ms)`, `seekToTime(atMs)`, `stepBack()`, `stepForward()`, `setSpeed(speed)`, `cycleSpeed()` — playback controls.
- Internally selects a renderer based on the recording's protocol: `DesktopRecordingRenderer` (protocol 2, draws to canvas) or `TerminalRecordingRenderer` (protocol 1, lazily boots a read-only xterm instance via dynamic import).
- Uses a `SEEK_BUSY_DELAY_MS` (150ms) debounce so fast seeks don't flash a "seeking" state in the UI.
- Tracks a `loadGenerationRef` counter to ensure stale, in-flight segment loads stop feeding the player once a newer load starts.

## Usage Example

```typescript
'use client';

import { useRecordingPlayer } from '@/hooks/use-recording-player';

export function RecordingViewer({ fetchSegments }: { fetchSegments: () => Promise<ArrayBuffer>[] }) {
  const {
    state,
    currentMs,
    durationMs,
    canvasRef,
    terminalHostRef,
    loadSegments,
    togglePlay,
    seek,
    cycleSpeed,
  } = useRecordingPlayer();

  useEffect(() => {
    loadSegments(fetchSegments()).then(({ failed }) => {
      if (failed > 0) console.warn(`${failed} segment(s) failed to load`);
    });
  }, []);

  return (
    <div>
      <canvas ref={canvasRef} />
      <div ref={terminalHostRef} />
      <button onClick={togglePlay}>{state === 'playing' ? 'Pause' : 'Play'}</button>
      <input
        type="range"
        min={0}
        max={durationMs}
        value={currentMs}
        onChange={(e) => seek(Number(e.target.value))}
      />
      <button onClick={cycleSpeed}>Cycle Speed</button>
    </div>
  );
}
```
