# use-recording-player.ts

A React hook that manages a MeshCentral recording player (`McrecPlayer`) for playback of desktop or terminal session recordings. It handles renderer selection (canvas for desktop, xterm.js for terminal), incremental loading of multi-file session segments, and exposes playback controls to consuming components.

## Key Components

- **`useRecordingPlayer()`** - Main hook that creates and owns a `McrecPlayer` instance, syncing its internal state (play/pause, seek, duration, time) into React state while keeping the player itself in a ref to avoid unnecessary re-renders.
- **`UseRecordingPlayerResult`** - Return type exposing player state, refs (`canvasRef`, `terminalHostRef`), and control functions (`togglePlay`, `seek`, `seekToTime`, `stepBack`, `stepForward`, `setSpeed`, `cycleSpeed`).
- **`loadSegments`** - Loads an ordered list of session file sources into a single timeline, starting playback as soon as the first segment is parsed, appending subsequent segments as they arrive, and tracking load "generations" to discard stale in-flight loads.
- **`attachRenderer`** - Internal helper that lazily instantiates either `DesktopRecordingRenderer` (canvas-based) or `TerminalRecordingRenderer` (xterm.js, read-only) based on the recording's protocol.
- **Seek debounce (`SEEK_BUSY_DELAY_MS`)** - Delays showing the `'seeking'` state by 150ms so fast seeks don't flash disabled/dimmed UI.

## Usage Example

```typescript
import { useRecordingPlayer } from '@/hooks/use-recording-player';

function RecordingViewer({ fileUrls }: { fileUrls: string[] }) {
  const {
    state,
    currentMs,
    durationMs,
    protocol,
    canvasRef,
    terminalHostRef,
    loadSegments,
    togglePlay,
    seek,
    cycleSpeed,
  } = useRecordingPlayer();

  useEffect(() => {
    const sources = fileUrls.map((url) => () => fetch(url).then((r) => r.arrayBuffer()));
    loadSegments(sources).then(({ failed }) => {
      if (failed) console.warn(`${failed} segment(s) failed to load`);
    });
  }, [fileUrls]);

  return (
    <div>
      {protocol === 2 ? <canvas ref={canvasRef} /> : <div ref={terminalHostRef} />}
      <button onClick={togglePlay}>{state === 'playing' ? 'Pause' : 'Play'}</button>
      <input
        type="range"
        max={durationMs}
        value={currentMs}
        onChange={(e) => seek(Number(e.target.value))}
      />
      <button onClick={cycleSpeed}>Speed</button>
    </div>
  );
}
```
