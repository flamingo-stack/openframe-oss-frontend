Utility module for reconciling Remote Session rows across paginated lists and live polling updates. Since `RemoteSession` entries lack a global identifier, Relay (the data layer) may retain duplicate copies of the same session fetched at different times; this module deduplicates rows and merges freshly polled "live" session data with existing list state.

## Key Components

- **`SessionRow`** — Minimal type constraint requiring a readonly `id: string`, used as the generic base for all functions.
- **`uniqueSessions<T>(rows)`** — Deduplicates rows by `id`, keeping the first occurrence encountered. Handles cases where the same session appears twice across pages loaded at different times (e.g., once while running, once after it ended).
- **`withPolledLiveRows<T>(rows, polled)`** — Merges freshly polled live sessions to the front of the list (in poll order), followed by remaining non-polled rows, then deduplicates. Returns the original list (deduplicated) unchanged if `polled` is `null` (poll hasn't resolved yet).
- **`endedLiveRows<T>(rows, polled)`** — Identifies session IDs that the UI still marks as `live: true` but that no longer appear in the latest poll result, indicating they have since ended.

## Usage Example

```typescript
import { uniqueSessions, withPolledLiveRows, endedLiveRows } from "./live-session-rows";

type RemoteSessionRow = { id: string; live: boolean; name: string };

// Deduplicate rows loaded across paginated requests
const dedupedRows = uniqueSessions(allLoadedRows);

// Merge the latest poll results into the displayed list
const displayedRows = withPolledLiveRows(currentRows, latestPolledRows);

// Determine which previously "live" rows have ended, to update their status
const endedIds = endedLiveRows(currentRows, latestPolledRows);
endedIds.forEach(id => {
  const row = currentRows.find(r => r.id === id);
  if (row) row.live = false;
});
```

This pattern is typically used in a polling loop where `latestPolledRows` is refreshed periodically, `withPolledLiveRows` recomputes the displayed list, and `endedLiveRows` triggers UI updates (e.g., badges, status icons) for sessions that have stopped running.
