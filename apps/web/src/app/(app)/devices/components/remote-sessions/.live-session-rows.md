This file provides utility functions for deduplicating and merging Remote Session rows in list views, since `RemoteSession` entities lack a global ID and Relay may retain multiple copies of the same session across paginated reads.

## Key Components

- **`SessionRow`** - Internal type requiring a readonly `id` string, the minimal shape needed for deduplication.
- **`uniqueSessions<T>(rows)`** - Filters an array of session rows, keeping only the first occurrence of each unique `id`. Used to collapse duplicate copies that may appear across pages loaded at different times.
- **`withPolledLiveRows<T>(rows, polled)`** - Merges freshly polled live session data with the existing list. If `polled` is `null` (poll hasn't answered yet), returns the deduplicated original rows unchanged. Otherwise, places polled rows first (preserving poll order), followed by remaining non-polled rows, then deduplicates the combined result.
- **`endedLiveRows<T>(rows, polled)`** - Identifies session IDs that were previously marked `live: true` in `rows` but are no longer present in the latest `polled` results, indicating those sessions have ended.

## Usage Example

```typescript
import { uniqueSessions, withPolledLiveRows, endedLiveRows } from './live-session-rows';

type Session = { id: string; live: boolean; name: string };

const existingRows: Session[] = [
  { id: 's1', live: true, name: 'Session 1' },
  { id: 's2', live: true, name: 'Session 2' },
];

const polledRows: Session[] | null = [
  { id: 's1', live: true, name: 'Session 1' },
];

// Merge polled live sessions with existing list
const merged = withPolledLiveRows(existingRows, polledRows);

// Detect sessions that ended since last poll
const ended = endedLiveRows(existingRows, polledRows ?? []);
// ended => ['s2']

// Deduplicate any list of rows by id
const deduped = uniqueSessions([...existingRows, ...existingRows]);
```

These helpers are typically used within Remote Session list components to keep polling-driven UI updates consistent and free of duplicate entries.
