## format.ts

Utility functions for formatting milliseconds and byte counts into human-readable strings, matching display conventions used in UI mockups (e.g., media player timestamps and file sizes).

## Key Components

- **`formatTimecodeMs(ms: number): string`** — Converts milliseconds into a fixed `HH:MM:SS` timecode, always zero-padded regardless of duration (used for player position display).
- **`formatDurationMs(ms: number): string`** — Converts milliseconds into a compact duration string, omitting the hours segment when the duration is under an hour (e.g., `"01:30"` vs `"1:05:12"`).
- **`formatBytes(bytes: number): string`** — Converts a byte count into a human-readable size string with the appropriate unit (`B`, `KB`, `MB`, `GB`), rounding to one decimal place and dropping trailing `.0` for whole numbers.

## Usage Example

```typescript
import { formatTimecodeMs, formatDurationMs, formatBytes } from './format';

// Player timecode (always HH:MM:SS)
formatTimecodeMs(318_000); // "00:05:18"

// Compact duration (hours omitted when zero)
formatDurationMs(90_500);     // "01:30"
formatDurationMs(3_912_000);  // "1:05:12"

// Human-readable file size
formatBytes(500);        // "500 B"
formatBytes(2_454_931);  // "2.3 MB"
formatBytes(53_687_091_200); // "50 GB"
```

## Notes

- `formatBytes` uses a `99.95` threshold (instead of `100`) before rounding to a whole number, avoiding inconsistent display where `99.96` would otherwise round to `"100.0"` next to an actual `"100"` value.
- Both timecode functions truncate (not round) to whole seconds via `Math.floor`.
