Utility functions for formatting time and byte values into human-readable strings, used for displaying media player timecodes, durations, and file sizes consistently across the UI.

## Key Components

- **`formatTimecodeMs(ms: number): string`** — Converts milliseconds into a fixed `HH:MM:SS` timecode string, zero-padded regardless of magnitude (e.g., a player's current playback position).
- **`formatDurationMs(ms: number): string`** — Converts milliseconds into a compact duration string, omitting the hours segment when not needed (`MM:SS` vs `H:MM:SS`).
- **`formatBytes(bytes: number): string`** — Converts a byte count into a human-readable size string (`B`, `KB`, `MB`, `GB`), rounding to one decimal place and dropping trailing `.0` for whole numbers, with special handling near the 100 threshold to avoid ambiguous rounding (e.g., `99.96` displaying as `100.0` next to an actual `100`).

## Usage Example

```typescript
import { formatTimecodeMs, formatDurationMs, formatBytes } from './format';

// Player timecode display
formatTimecodeMs(318_000); // "00:05:18"

// Recording duration display
formatDurationMs(90_500);     // "01:30"
formatDurationMs(3_912_000);  // "1:05:12"

// File size display
formatBytes(500);        // "500 B"
formatBytes(2_454_931);  // "2.3 MB"
formatBytes(107_374_182); // "102 MB"
```

These functions are pure and side-effect free, making them safe to use directly in Vue component templates or computed properties for rendering UI text.
