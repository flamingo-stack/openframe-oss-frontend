This file builds the ordered list of participants shown in a remote session's "viewers stack" UI, merging the session host and connected watchers into a unified display model.

## Key Components

- **`UNNAMED_VIEWER`** — Fallback display name (`"Technician"`) used when a viewer entry has no name.
- **`SessionHost`** — Interface describing the host of a session (`id`, `name`, `avatarUrl`).
- **`sessionViewers(host, viewers, userId)`** — Builds a `RemoteSessionViewer[]` array with the host listed first (flagged `isHost: true`), followed by all other viewers (excluding any duplicate entry for the host watching their own session). Each entry is flagged `isYou` when it matches the currently signed-in `userId`.

## Usage Example

```typescript
import { sessionViewers, type SessionHost } from './session-viewers';
import type { RemoteSessionViewerEntry } from '../../types/remote-access';

const host: SessionHost = {
  id: 'tech-1',
  name: 'Alice',
  avatarUrl: 'https://cdn.example.com/avatars/alice.png',
};

const viewers: RemoteSessionViewerEntry[] = [
  { userId: 'tech-1', name: 'Alice', avatarUrl: null }, // host watching own session, deduped
  { userId: 'tech-2', name: null, avatarUrl: null },
  { userId: 'tech-3', name: 'Bob', avatarUrl: 'https://cdn.example.com/avatars/bob.png' },
];

const currentUserId = 'tech-3';

const stack = sessionViewers(host, viewers, currentUserId);
// [
//   { id: 'tech-1', name: 'Alice', avatarUrl: '...', isHost: true, isYou: false },
//   { id: 'tech-2', name: 'Technician', avatarUrl: null, isYou: false },
//   { id: 'tech-3', name: 'Bob', avatarUrl: '...', isYou: true },
// ]
```

Use this function when rendering live session participant stacks, ensuring the host never appears twice and the current user is correctly highlighted.
