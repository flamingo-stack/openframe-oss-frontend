## session-viewers.ts

Builds the ordered list of participants shown in a remote session's "viewers stack" UI, combining the session host and any additional watchers into a unified, deduplicated list.

## Key Components

- **`SessionHost`** — Interface describing the technician whose session is being viewed (`id`, `name`, `avatarUrl`).
- **`sessionViewers(host, viewers, userId)`** — Merges the host and viewer entries into a single `RemoteSessionViewer[]` array:
  - Places the host first, flagged with `isHost: true`.
  - Filters out any viewer entry matching the host's `userId` (avoids listing the host twice if they're watching their own session from another tab).
  - Falls back to `"Technician"` (`UNNAMED_VIEWER`) for viewers without a name.
  - Marks the current signed-in user (`userId`) with `isYou: true`, wherever they appear in the list.

## Usage Example

```typescript
import { sessionViewers, type SessionHost } from './session-viewers';
import type { RemoteSessionViewerEntry } from '../../types/remote-access';

const host: SessionHost = {
  id: 'tech-1',
  name: 'Jane Doe',
  avatarUrl: 'https://cdn.example.com/avatars/jane.png',
};

const viewers: RemoteSessionViewerEntry[] = [
  { userId: 'tech-2', name: 'John Smith', avatarUrl: null },
  { userId: 'tech-3', name: null, avatarUrl: null },
];

const currentUserId = 'tech-2';

const stack = sessionViewers(host, viewers, currentUserId);
// [
//   { id: 'tech-1', name: 'Jane Doe', avatarUrl: '...', isHost: true, isYou: false },
//   { id: 'tech-2', name: 'John Smith', avatarUrl: null, isYou: true },
//   { id: 'tech-3', name: 'Technician', avatarUrl: null, isYou: false },
// ]
```
