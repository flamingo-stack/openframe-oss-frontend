Defines the column configuration for the tenant-wide Remote Sessions table (the Devices page's session tab), extending the shared remote-session columns with server-filtered DEVICE and CUSTOMER columns, plus row-mapping and query-variable helpers for the Relay-backed, server-paged session list.

## Key Components

- **`TenantSessionRow`** — Row shape combining `RecordingSummary` with nullable `device` and `customer` info.
- **`toTenantSessionRow(ref)`** — Converts a Relay fragment reference (`tenantRemoteSessionsRelay_row$key`) into a `TenantSessionRow`, reading session, device, and organization/customer data.
- **`TENANT_SESSION_COLUMNS`** — Static column layout metadata (SESSION, DEVICE, CUSTOMER, EXPIRES, ACTIONS) with responsive `hideAt` breakpoints.
- **`TenantSessionsParams`** — URL-state shape for device/customer/expires filters, date range, and sort direction.
- **`tenantSessionsVariables(params, dateRange)`** — Builds the GraphQL `filter`/`sort` query variables from URL params, converting the date range to instant bounds and always including sort direction.
- **`keepLastPick(previous, next)`** — Utility enforcing single-value semantics on a multi-select filter UI control.
- **`TenantSessionColumnsOptions`** — Options interface for building the column definitions (filter options, loading state, live rows, row action callbacks).
- **`tenantSessionColumns(options)`** — Builds the full `ColumnDef<TenantSessionRow>[]` array by reusing shared session columns (SESSION, EXPIRES, actions) and inserting DEVICE/CUSTOMER columns with server-side multi-select filtering.
- **`DeviceCell` / `CustomerCell`** — Internal row-cell components rendering device icon/name/hostname and customer logo/name, with loading-skeleton support via `useLoadingScope`.

## Usage Example

```typescript
import { tenantSessionColumns, tenantSessionsVariables, toTenantSessionRow } from './tenant-session-columns';

// Build GraphQL variables from URL state
const variables = tenantSessionsVariables(
  { device: [], customer: ['org-1'], expires: ['expiring'], dateFrom: '', dateTo: '', sortDir: 'desc' },
  dateRange,
);

// Build table columns
const columns = tenantSessionColumns({
  dateFilter,
  deviceOptions,
  customerOptions,
  optionsPending: false,
  now: Date.now(),
  liveRows,
  onOpen: row => openSession(row),
  onDelete: row => deleteSession(row),
});

// Map Relay fragment refs to rows
const rows = edges.map(edge => toTenantSessionRow(edge.node));
```
