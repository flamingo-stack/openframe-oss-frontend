# tenant-session-columns.tsx

Defines the column configuration for the tenant-wide Remote Sessions table (the Devices page's session tab), adding DEVICE and CUSTOMER columns to the shared remote session columns (SESSION, EXPIRES, Actions). Handles server-side filtering/sorting state derivation from URL params and GraphQL fragment-to-row mapping.

## Key Components

- **`TenantSessionRow`** — Row interface extending `RecordingSummary` with `device` and `customer` info.
- **`toTenantSessionRow(ref)`** — Converts a Relay fragment reference into a `TenantSessionRow` by reading the inline fragment and deriving device/customer fields (including logo URL resolution).
- **`TENANT_SESSION_COLUMNS`** — Static column layout metadata (SESSION/DEVICE/CUSTOMER/EXPIRES/Actions) with responsive `hideAt` breakpoints.
- **`TenantSessionsParams`** — Shape of the page's URL-driven filter/sort state.
- **`tenantSessionsVariables(params, dateRange)`** — Builds the GraphQL query `filter`/`sort` variables from URL params and a date range, converting calendar days to instant bounds.
- **`keepLastPick(previous, next)`** — Utility enforcing single-value semantics on a multi-select filter UI (keeps only the most recently added or last remaining value).
- **`tenantSessionColumns(options)`** — Builds the full `ColumnDef[]` array for the table, reusing shared session columns and inserting custom `DeviceCell`/`CustomerCell` renderers for DEVICE and CUSTOMER.
- **`DeviceCell`, `CustomerCell`** — Internal row-cell components rendering device icon/name/hostname and customer logo/name, with loading-skeleton awareness via `useLoadingScope`.

## Usage Example

```typescript
import {
  tenantSessionColumns,
  tenantSessionsVariables,
  toTenantSessionRow,
  keepLastPick,
} from './tenant-session-columns';

// Build GraphQL variables from URL state
const variables = tenantSessionsVariables(
  { device: [], customer: ['org-1'], expires: ['expiring'], dateFrom: '', dateTo: '', sortDir: 'desc' },
  dateRange,
);

// Map Relay fragment refs to rows
const rows = edges.map(edge => toTenantSessionRow(edge.node));

// Configure table columns
const columns = tenantSessionColumns({
  dateFilter,
  deviceOptions,
  customerOptions,
  optionsPending: false,
  now: Date.now(),
  liveRows: null,
  onOpen: row => openSession(row),
  onDelete: row => deleteSession(row),
});
```
