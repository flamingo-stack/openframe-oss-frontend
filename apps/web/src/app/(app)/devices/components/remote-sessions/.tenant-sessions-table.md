## Overview

Client-side component that renders a paginated, filterable table of tenant remote sessions. It combines Relay-based GraphQL pagination with live session polling, URL-synced filters/date range, and a delete confirmation flow, while supporting skeleton loading states via a loading scope.

## Key Components

- **`TenantSessionsTable`** – Presentational table component rendering columns (device, customer, expiry), handling mobile filter modal, row navigation, loading placeholders, and the delete session dialog.
- **`MobileFiltersButton`** – Small button shown below `md` breakpoint that opens the mobile `FilterModal`.
- **`TenantSessionsContent`** – Wraps the data-fetching reader in a `LoadingSuspense` boundary with a custom loading label.
- **`TenantSessionsContentReader`** – Chooses between a skeleton render (inside a loading scope) and the live Relay query.
- **`TenantSessionsContentQuery`** – Executes `tenantRemoteSessionsRelayQuery` via `useLazyLoadQuery`, paginates with `usePaginationFragment`, merges live polling rows via `useTenantSessionRows`, and exposes `loadMore` for infinite scroll.
- **Constants**: `PAGE_SIZE` (20), `FILTER_KEYS`, `SINGLE_VALUE_FILTERS`, `NO_SESSIONS` (empty state config).

## Usage Example

```typescript
import { tenantSessionsVariables } from './tenant-session-columns';

function RemoteSessionsPanel() {
  const variables = tenantSessionsVariables({ /* filter params */ });

  return (
    <TenantSessionsContent
      variables={variables}
      refreshKey={0}
      onRefresh={() => {/* refetch first page */}}
      tableFilters={{ device: [], customer: [], expires: [] }}
      onFilterChange={filters => {/* sync to URL */}}
      dateFilter={{
        range: undefined,
        sortDirection: 'desc',
        onApply: range => {/* update date filter */},
      }}
      onDeleted={() => {/* refresh after delete */}}
    />
  );
}
```

This component is typically consumed from a parent tab (e.g., the remote sessions tab) that owns URL param state via `useQueuedParamsWrite`/`useApiParams` and passes filter/date state down as props.
