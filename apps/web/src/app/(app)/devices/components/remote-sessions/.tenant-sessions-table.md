# tenant-sessions-table.tsx

Renders the tenant's remote sessions table with server-driven filtering, sorting, pagination, and live row merging via Relay. Combines a Suspense-backed GraphQL query layer with a presentational table component that handles loading states, mobile filters, and session deletion.

## Key Components

- **`TenantSessionsTable`** – Presentational table component rendering columns, filters (device, customer, expires), date range filtering, mobile `FilterModal`, and `DeleteSessionDialog`. Draws placeholder rows while in a loading scope.
- **`MobileFiltersButton`** – Small button shown below `md` breakpoint to open the mobile filter modal.
- **`TenantSessionsContent`** – Wraps the data-fetching reader in a `LoadingSuspense` boundary with its own fallback label.
- **`TenantSessionsContentReader`** – Renders an empty/loading table when inside a loading scope (e.g., the recordings gate), otherwise delegates to `TenantSessionsContentQuery`.
- **`TenantSessionsContentQuery`** – Executes the Relay query (`tenantRemoteSessionsRelayQuery`) and paginates via `usePaginationFragment`, merges live/polled session rows with `useTenantSessionRows`, and exposes `loadMore` for infinite scroll.
- **`FilterKey` / `FILTER_KEYS` / `SINGLE_VALUE_FILTERS`** – Defines the supported filter dimensions (`device`, `customer`, `expires`) and which are single-select vs. multi-select.
- **`NO_SESSIONS`** – Default empty-state content (icon, title, description) when no filters are applied.

## Usage Example

```typescript
import { tenantSessionsVariables } from './tenant-session-columns';

function RemoteSessionsSection() {
  const variables = tenantSessionsVariables({ /* filter params */ });
  const [refreshKey, setRefreshKey] = useState(0);

  return (
    <TenantSessionsContent
      variables={variables}
      refreshKey={refreshKey}
      onRefresh={() => setRefreshKey(k => k + 1)}
      tableFilters={{ device: [], customer: [], expires: [] }}
      onFilterChange={(filters) => { /* persist to URL params */ }}
      dateFilter={{
        range: undefined,
        sortDirection: 'desc',
        onApply: (result) => { /* update date range */ },
      }}
      onDeleted={() => setRefreshKey(k => k + 1)}
    />
  );
}
```

This component is intended for use within the tenant remote sessions tab (see `remote-sessions-tab`), relying on surrounding hooks (`useApiParams`, `useQueuedParamsWrite`) to synchronize filters with URL state.
