# recording-keep.ts

Formatting helpers that render a recording's **Keep** state (the hold placed on a session recording to prevent expiry) across the recording page, the Remote Sessions list, and the Release Keeping dialog.

## Key Components

- **`keepReasonText(keep)`** — Resolves the human-readable reason text for a Keep. Returns the keep's custom `note` when the reason is `'OTHER'`, otherwise looks up the label from `REMOTE_SESSION_KEEP_REASON_LABELS`.
- **`releaseDueOn(keep)`** — Computes the original expiry date to display in the Release dialog's "It was due to expire on" copy. Returns `null` unless releasing the Keep applies a grace period that pushes the expiry later than the original due date; otherwise returns a formatted date string via `formatDate`.
- **`keptUsageText(storage)`** — Produces the storage usage summary (e.g. `"612 MB of 50 GB"`) shown in the Keep dialog. Falls back to `'their own allowance'` when storage data isn't yet available.

## Usage Example

```typescript
import { keepReasonText, releaseDueOn, keptUsageText } from './recording-keep';

// Display the reason for a Keep
const reasonLabel = keepReasonText({ reason: 'OTHER', note: 'Pending compliance review' });
// => "Pending compliance review"

const standardLabel = keepReasonText({ reason: 'LEGAL_HOLD', note: null });
// => resolves from REMOTE_SESSION_KEEP_REASON_LABELS

// Show original expiry in the Release dialog, if grace period applies
const dueOn = releaseDueOn({
  dueAt: '2024-05-01T00:00:00Z',
  expiresAtOnRelease: '2024-05-10T00:00:00Z',
});
// => "May 1, 2024" (formatted) when grace period extends expiry

// Render storage usage in the Keep dialog
const usage = keptUsageText({ keptBytes: 642_252_800, keptLimitBytes: 53_687_091_200 });
// => "612 MB of 50 GB"

const unknownUsage = keptUsageText(undefined);
// => "their own allowance"
```
