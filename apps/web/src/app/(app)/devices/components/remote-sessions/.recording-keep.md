# recording-keep.ts

Formatting helpers that render human-readable text for recording "Keep" state across the recording page, the Remote Sessions list, and the Release Keeping dialog.

## Key Components

- **`keepReasonText(keep)`** - Returns the display text for a Keep's reason. Uses the keep's custom `note` when the reason is `'OTHER'`; otherwise looks up the label from `REMOTE_SESSION_KEEP_REASON_LABELS`.
- **`releaseDueOn(keep)`** - Computes the original expiry date to show in the Release dialog's "It was due to expire on" message. Returns a formatted date only when releasing applies a grace period that pushes the expiry later than the original due date; returns `null` otherwise.
- **`keptUsageText(storage)`** - Formats the Keep dialog's storage usage summary (e.g. `"612 MB of 50 GB"`). Falls back to `"their own allowance"` when storage data isn't yet available.

## Usage Example

```typescript
import { keepReasonText, releaseDueOn, keptUsageText } from './recording-keep';

// Reason text
keepReasonText({ reason: 'OTHER', note: 'Pending compliance review' });
// => "Pending compliance review"

keepReasonText({ reason: 'LEGAL_HOLD', note: null });
// => "Legal hold" (from REMOTE_SESSION_KEEP_REASON_LABELS)

// Original expiry shown only if grace period extended it
releaseDueOn({ dueAt: '2024-01-10T00:00:00Z', expiresAtOnRelease: '2024-01-15T00:00:00Z' });
// => "Jan 10, 2024"

releaseDueOn({ dueAt: null, expiresAtOnRelease: null });
// => null

// Storage usage summary
keptUsageText({ keptBytes: 641728512, keptLimitBytes: 53687091200 });
// => "612 MB of 50 GB"

keptUsageText(undefined);
// => "their own allowance"
```
