# player-controls.tsx

A purely presentational React component that renders the playback control strip for a MeshCentral session recording player, including a custom progress bar with event markers, transport buttons, a timecode display, a playback speed toggle group, and a fullscreen control.

## Key Components

- **`PlayerControls`** — The main exported component. Renders:
  - A custom progress/scrubber track (bordered track, played-fill overlay, draggable thumb) layered over an invisible native `<input type="range">` for accessible pointer and keyboard seeking.
  - Transport buttons: play/pause, step back 10s, step forward 10s.
  - A "current / total" timecode display (via `formatTimecodeMs`), rendered as a skeleton while in a loading scope.
  - A speed toggle group (`0.5x`, `1x`, `2x`, `4x`) driven by the `SPEED_OPTIONS` constant.
  - A fullscreen toggle button.
- **`PlayerControlsProps`** — Props interface accepting player state (`state`, `currentMs`, `durationMs`, `speed`, `isFullscreen`), optional `markers` (ReactNode drawn above the track), and callback handlers (`onTogglePlay`, `onSeek`, `onStepBack`, `onStepForward`, `onSetSpeed`, `onToggleFullscreen`).
- **`SPEED_OPTIONS`** — Fixed array of supported playback speeds: `[0.5, 1, 2, 4]`.

The component holds local `dragMs` state so that scrubbing the range input updates the displayed position immediately, while the actual `onSeek` callback only fires on pointer release or relevant key-up events (`ArrowLeft`/`ArrowRight`/`Home`/`End`). This prevents the animation-frame-driven `currentMs` prop from fighting the thumb mid-drag. All controls are disabled when inside a loading scope (`useLoadingScope`) or when `state` is `'empty'`/`'seeking'`.

## Usage Example

```typescript
import { PlayerControls } from './player-controls';
import type { RecordingPlaybackSpeed, RecordingPlayerState } from '@/lib/meshcentral/recording';

function RecordingPlayerShell() {
  const [state, setState] = useState<RecordingPlayerState>('paused');
  const [currentMs, setCurrentMs] = useState(0);
  const [speed, setSpeed] = useState<RecordingPlaybackSpeed>(1);
  const [isFullscreen, setIsFullscreen] = useState(false);
  const durationMs = 120_000;

  return (
    <PlayerControls
      state={state}
      currentMs={currentMs}
      durationMs={durationMs}
      speed={speed}
      isFullscreen={isFullscreen}
      markers={<EventMarkers />}
      onTogglePlay={() => setState(s => (s === 'playing' ? 'paused' : 'playing'))}
      onSeek={ms => setCurrentMs(ms)}
      onStepBack={() => setCurrentMs(ms => Math.max(0, ms - 10_000))}
      onStepForward={() => setCurrentMs(ms => Math.min(durationMs, ms + 10_000))}
      onSetSpeed={setSpeed}
      onToggleFullscreen={() => setIsFullscreen(f => !f)}
    />
  );
}
```

This component is designed to be used inside `useRecordingPlayer`-driven pages where all playback state and fullscreen logic are managed externally; it contains no business logic of its own.
