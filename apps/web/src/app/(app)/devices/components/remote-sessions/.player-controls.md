Presentational React component that renders the playback transport UI for a MeshCentral recording session: a draggable progress bar with event markers, play/pause and step buttons, an elapsed/total time clock, a playback-speed toggle group, and a fullscreen toggle. It holds no playback logic itself—state is driven entirely by `useRecordingPlayer` and passed in via props.

## Key Components

- **`PlayerControls`** — Main exported component. Renders:
  - A custom progress track (bordered track, filled portion, draggable thumb) layered with an invisible native `<input type="range">` for accessible pointer/keyboard seeking. Uses local `dragMs` state to track in-progress drags and only calls `onSeek` on pointer release or arrow/home/end key release, avoiding conflicts with `currentMs` updates during playback.
  - Transport buttons (play/pause, step back/forward) using `Button` from the UI kit.
  - A timecode display (`formatTimecodeMs`) showing `current / duration`, replaced by a `TextLineSkeleton` while in a loading scope (via `useLoadingScope`).
  - A speed selector button group (`0.5x`, `1x`, `2x`, `4x`).
  - A fullscreen toggle button.
- **`PlayerControlsProps`** — Prop interface: playback `state`, `currentMs`, `durationMs`, `speed`, `isFullscreen`, optional `markers` (ReactNode rendered above the track), and callback handlers (`onTogglePlay`, `onSeek`, `onStepBack`, `onStepForward`, `onSetSpeed`, `onToggleFullscreen`).
- **`SPEED_OPTIONS`** — Constant array of available `RecordingPlaybackSpeed` values: `[0.5, 1, 2, 4]`.

All controls are disabled when `loading`, or when playback `state` is `'empty'` or `'seeking'`.

## Usage Example

```typescript
import { PlayerControls } from './player-controls';
import { useRecordingPlayer } from '@/lib/meshcentral/recording';

function RecordingViewer() {
  const player = useRecordingPlayer(/* ... */);
  const [isFullscreen, setIsFullscreen] = useState(false);

  return (
    <PlayerControls
      state={player.state}
      currentMs={player.currentMs}
      durationMs={player.durationMs}
      speed={player.speed}
      isFullscreen={isFullscreen}
      markers={<EventMarkers events={player.events} />}
      onTogglePlay={player.togglePlay}
      onSeek={player.seek}
      onStepBack={() => player.seek(player.currentMs - 10000)}
      onStepForward={() => player.seek(player.currentMs + 10000)}
      onSetSpeed={player.setSpeed}
      onToggleFullscreen={() => setIsFullscreen(v => !v)}
    />
  );
}
```
