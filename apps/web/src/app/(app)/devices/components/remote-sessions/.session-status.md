# session-status.ts

Shared logic for Remote Sessions rows that determines how a session recording's state maps to UI behavior—what a row links to, which actions (keep/delete) are available, and how expiry is filtered and displayed. Used by both the per-device sessions tab and the tenant-wide sessions page so they stay consistent.

## Key Components

- **`LiveRows`** — Interface holding the signed-in technician's `userId`, used to gate "live" row detection.
- **`isLiveRow(row, liveRows)`** — Type guard: true when Watch live is enabled and the session is still running.
- **`sessionHref(row, liveRows)`** — Returns the URL a row should navigate to: the live session page for running sessions, the recording playback page for finished/playable sessions, or `null` if nothing is openable.
- **`ExpiresFilterValue`** / **`EXPIRES_FILTER_OPTIONS`** — Filter options for the EXPIRES column (`kept`, `expiring`, `expired`).
- **`EXPIRING_WINDOW_MS`** — 7-day threshold matching the server's "expiring soon" window.
- **`expiresFilterValue(row, now)`** — Classifies a row into an `ExpiresFilterValue`, or `null` if no filter applies.
- **`isAwaitingRecording(session)`** — True for an ended session whose recording file isn't available yet.
- **`canOpenSession(row)`** — True if the recording is `ready` and has a `recordingId`.
- **`canKeepSession(row)`** — True if the recording can be marked "kept" (ready, not already kept).
- **`canDeleteSession(row)`** — True if the session is deletable (not live, not kept, not processing).
- **`isRecordingGone(row)`** — True if the recording has `expired` or `deleted` state (render greyed out).
- **`expiresSoonLabel(expiresAt, now)`** — Produces an "Expires in N hours" string once under 24 hours remain, floored at 1 hour.

## Usage Example

```typescript
import {
  sessionHref,
  canDeleteSession,
  expiresFilterValue,
  expiresSoonLabel,
} from './session-status';

const liveRows = { userId: currentUser.id };

const href = sessionHref(session, liveRows);
if (href) navigate(href);

if (canDeleteSession(session)) {
  showDeleteButton();
}

const filter = expiresFilterValue(session, Date.now());
// filter === 'expiring' | 'expired' | 'kept' | null

const label = expiresSoonLabel(session.expiresAt, Date.now());
// e.g. "Expires in 3 hours"
```
