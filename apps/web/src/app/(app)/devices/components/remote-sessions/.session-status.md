## Overview

Shared status logic for Remote Sessions rows, determining how a session row behaves and renders based on its recording's lifecycle state. Used by both the device tab and the tenant-wide sessions page to ensure consistent behavior for opening, keeping, deleting, and filtering sessions.

## Key Components

- **`LiveRows`** — Interface marking that "Watch live" is enabled, carrying the signed-in technician's `userId`.
- **`isLiveRow(row, liveRows)`** — Type-guards whether a row should be treated as live (running + live mode enabled).
- **`sessionHref(row, liveRows)`** — Resolves the navigation target for a row: live session page, recording playback page, or `null` if nothing is openable.
- **`ExpiresFilterValue`** / **`EXPIRES_FILTER_OPTIONS`** — Filter values (`kept`, `expiring`, `expired`) and their UI options for the EXPIRES column.
- **`EXPIRING_WINDOW_MS`** — 7-day threshold matching the server's "expiring soon" definition.
- **`expiresFilterValue(row, now)`** — Classifies a row into an `ExpiresFilterValue`, or `null` if no filter applies.
- **`isAwaitingRecording(session)`** — True when a session ended but its recording file isn't available yet.
- **`canOpenSession(row)`** — True if the row has a playable recording.
- **`canKeepSession(row)`** — True if the recording is eligible to be marked "kept."
- **`canDeleteSession(row)`** — True if the session can be deleted (not live, not kept, not processing).
- **`isRecordingGone(row)`** — True if the recording has expired or been deleted (renders greyed out).
- **`expiresSoonLabel(expiresAt, now)`** — Produces a human-readable "Expires in N hours" label when under 24 hours remain.

## Usage Example

```typescript
import {
  isLiveRow,
  sessionHref,
  expiresFilterValue,
  canDeleteSession,
  expiresSoonLabel,
} from './session-status';

const now = Date.now();
const liveRows = { userId: 'tech-123' };

const row = {
  id: 'session-1',
  recordingId: 'rec-1',
  recordingState: 'ready' as const,
  live: false,
  kept: false,
  expiresAt: new Date(now + 3 * 60 * 60 * 1000).toISOString(),
};

const href = sessionHref(row, liveRows);
// -> "/devices/.../remote-sessions/rec-1"

const filter = expiresFilterValue(row, now);
// -> "expiring"

const label = expiresSoonLabel(row.expiresAt, now);
// -> "Expires in 3 hours"

const deletable = canDeleteSession(row);
// -> true
```
