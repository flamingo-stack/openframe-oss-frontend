React component module providing a warning alert UI for displaying session recording storage status, specifically alerting users when the tenant's recording storage pool is full.

## Key Components

- **`RecordingWarningAlert`** - A reusable presentational component that renders a styled warning alert (triangle icon + bold message) matching the design spec (Figma 2328-20598 / 2328-20570). Accepts standard `HTMLAttributes<HTMLDivElement>` and forwards `children` as the alert message.
- **`RecordingStorageBanner`** - A data-driven banner that fetches recording storage status via the `useRecordingStorage` hook and conditionally renders a `RecordingWarningAlert` only when storage is full. Renders `null` while loading, when data is unavailable, or when storage has room — the data is treated as optional (`data-loading-optional`), so it never blocks page render.

## Usage Example

```typescript
import { RecordingStorageBanner } from './recording-storage-banner';

function DevicePage() {
  return (
    <div>
      {/* Shows nothing unless the tenant's recording storage is full */}
      <RecordingStorageBanner className="mb-4" />
      {/* ...rest of device page content... */}
    </div>
  );
}
```

```typescript
import { RecordingWarningAlert } from './recording-storage-banner';

function CustomWarning() {
  return (
    <RecordingWarningAlert>
      Custom warning message rendered with the same styling.
    </RecordingWarningAlert>
  );
}
```

## Notes

- The storage limit shown is always sourced from the server response (`storage.limitBytes`), never hardcoded, and formatted via the shared `formatBytes` utility.
- `RecordingStorageBanner` is safe to render unconditionally in parent components since it self-manages visibility based on fetched data state.
