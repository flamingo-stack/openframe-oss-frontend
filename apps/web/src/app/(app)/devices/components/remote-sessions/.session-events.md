# session-events.ts

Transforms raw GraphQL `RemoteSessionEvent` data into human-readable timeline rows for display in the Session Events list and on the recording player's track markers. Handles event-type-specific labeling, timestamp mapping to the playback timeline, and playhead-based active event detection.

## Key Components

- **`sessionEventFragment`** — Inline Relay GraphQL fragment defining the fields read from each `RemoteSessionEvent` node.
- **`SessionTimelineEvent`** — Interface for a single rendered row (`id`, `atMs`, `offsetMs`, `title`, `detail`).
- **`describeSessionEvent(event)`** — Maps a raw event to a `{ title, detail }` pair based on its `RemoteSessionEventType` (e.g., session start/end, input toggling, clipboard activity, shortcuts, monitor switches, recording hold/release). Returns `null` for unsupported event types.
- **`toSessionTimelineEvent(ref)`** — Reads an inline Relay fragment reference and converts it into a `SessionTimelineEvent`, or `null` if the event type isn't displayable.
- **`placeSessionEvents(events, timeline)`** — Maps server-time events onto the player's actual playback timeline (accounting for reconnect gaps), falling back to the raw session-relative offset when no `RecordingTimeline` is available yet.
- **`activeSessionEventId(events, currentMs)`** — Determines which event row is "active" for a given playhead position (the latest event at or before `currentMs`).

## Usage Example

```typescript
import {
  toSessionTimelineEvent,
  placeSessionEvents,
  activeSessionEventId,
} from './session-events';

// Convert Relay fragment refs into display-ready rows
const rawRows = eventRefs
  .map(toSessionTimelineEvent)
  .filter((row): row is NonNullable<typeof row> => row !== null);

// Map rows onto the loaded recording's playback timeline
const placedEvents = placeSessionEvents(rawRows, recordingTimeline);

// Determine which row the player's current position corresponds to
const activeId = activeSessionEventId(placedEvents, currentPlaybackMs);
```

Typically used together in a recording playback page: `toSessionTimelineEvent` processes the GraphQL query results, `placeSessionEvents` aligns them to the video timeline once loaded, and `activeSessionEventId` highlights the corresponding row as the user scrubs through playback.
