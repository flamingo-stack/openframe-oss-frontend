# session-events.ts

Transforms raw `RemoteSessionEvent` GraphQL data into human-readable timeline rows for the Session Events list and the recording player's track markers. Handles formatting of titles/details per event type and places events correctly along the playback timeline.

## Key Components

- **`sessionEventFragment`** — Inline GraphQL fragment (`sessionEvents_event`) defining the fields read from each `RemoteSessionEvent` node.
- **`SessionTimelineEvent`** — Interface representing one row in the Session Events list (`id`, `atMs`, `offsetMs`, `title`, `detail`).
- **`describeSessionEvent(event)`** — Maps a `RemoteSessionEventType` to a design-worded `{ title, detail }` pair (e.g., "Input enabled" / "technician took keyboard and mouse"); returns `null` for unsupported types.
- **`toSessionTimelineEvent(ref)`** — Reads the inline fragment from a `SessionEventRef` and builds a `SessionTimelineEvent`, parsing the server timestamp and computing descriptive text.
- **`placeSessionEvents(events, timeline)`** — Maps raw timeline events onto the player's timeline, converting server wall-clock time into playback milliseconds via `toPlaybackMs` when a `RecordingTimeline` is available.
- **`activeSessionEventId(events, currentMs)`** — Determines which event row corresponds to the current playhead position (the last event at or before `currentMs`).

## Usage Example

```typescript
import {
  toSessionTimelineEvent,
  placeSessionEvents,
  activeSessionEventId,
} from './session-events';

// Convert GraphQL fragment refs into timeline rows
const timelineEvents = eventRefs
  .map(toSessionTimelineEvent)
  .filter((event): event is SessionTimelineEvent => event !== null);

// Position events along the player's timeline (or raw offsets if no recording loaded)
const placedEvents = placeSessionEvents(timelineEvents, recordingTimeline);

// Determine which event marker is currently active based on playhead position
const activeId = activeSessionEventId(placedEvents, currentPlaybackMs);
```

This module is used by the recording/session playback UI to render the events list and synchronize track markers with the video player's current position.
