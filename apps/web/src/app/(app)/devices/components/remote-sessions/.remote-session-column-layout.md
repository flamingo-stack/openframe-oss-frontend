Defines the shared column layout configuration for the Remote Sessions tables, used by both the device's Remote Sessions tab and the tenant-wide sessions list.

## Key Components

- **`REMOTE_SESSION_COLUMNS`** — A `const` object (typed via `satisfies Record<string, TableSkeletonColumn>`) describing five columns:
  - `session` — flexible-width column, supports date filtering, visible on all breakpoints
  - `employee` — flexible-width column, hidden at `md` breakpoint and below
  - `duration` — flexible-width column, sortable, hidden at `md` breakpoint and below
  - `expires` — flexible-width column (recording expiration), hidden at `md` breakpoint and below
  - `actions` — fixed-width (`w-[112px]`) column, right-aligned, combines delete and open actions into a single cell

This file is **data-only**: it contains no rendering logic. The live table component consumes this layout both for rendering loaded data and for drawing its own skeleton/loading state, ensuring the header stays consistent between loading and loaded states.

## Usage Example

```typescript
import { REMOTE_SESSION_COLUMNS } from '@/app/components/.../remote-session-column-layout';

function RemoteSessionsTable() {
  const columns = Object.values(REMOTE_SESSION_COLUMNS);

  return (
    <TableSkeleton columns={columns}>
      {/* render rows once session data loads */}
    </TableSkeleton>
  );
}
```

On mobile viewports, only the `session` and `actions` columns remain visible since `employee`, `duration`, and `expires` are hidden via `hideAt: 'md'`, matching the Figma mobile spec (758-46869).
