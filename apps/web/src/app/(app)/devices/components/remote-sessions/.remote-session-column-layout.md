# remote-session-column-layout.ts

Defines the shared column layout configuration for remote sessions tables, used by both the device's Remote Sessions tab and the tenant-wide sessions list. This file is intentionally data-only, decoupling column structure from rendering logic so the live table can own both loaded and loading states under a single header definition.

## Key Components

- **`REMOTE_SESSION_COLUMNS`** — A `satisfies Record<string, TableSkeletonColumn>` constant describing five columns:
  - `session` — flexible width, date-filterable
  - `employee` — flexible width, hidden below `md` breakpoint
  - `duration` — flexible width, hidden below `md`, sortable
  - `expires` — flexible width ("RECORDING EXPIRES"), hidden below `md`
  - `actions` — fixed width (`112px`), right-aligned, combines delete and open actions into a single cell (carries the results count in its header per the Figma spec)

On mobile viewports, only the `session` (date) and `actions` columns remain visible.

## Usage Example

```typescript
import { REMOTE_SESSION_COLUMNS } from '@/app/components/shared/remote-session-column-layout';
import { TableSkeleton } from '@/app/components/shared/table-column-layout';

function RemoteSessionsTable({ sessions, isLoading }: RemoteSessionsTableProps) {
  if (isLoading) {
    return <TableSkeleton columns={REMOTE_SESSION_COLUMNS} />;
  }

  return (
    <table>
      <thead>
        {Object.values(REMOTE_SESSION_COLUMNS).map((col) => (
          <th key={col.id} className={col.width}>
            {col.header}
          </th>
        ))}
      </thead>
      <tbody>
        {sessions.map((session) => (
          <RemoteSessionRow key={session.id} session={session} columns={REMOTE_SESSION_COLUMNS} />
        ))}
      </tbody>
    </table>
  );
}
```

Both consumer tables (device tab and tenant-wide list) import this single configuration to guarantee consistent column widths, headers, and responsive behavior.
