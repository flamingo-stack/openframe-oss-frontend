A reusable navigation button component that links to a device's detail page, accepting either a `deviceId` or `machineId` as identifier.

## Key Components

- **`DeviceDetailsButton`** — Named export. Renders a `Button` from `@flamingo-stack/openframe-frontend-core` that navigates to the device details route. Without an ID (the device is still being read) it draws the same button, disabled, so the card keeps its box.
- **`DeviceDetailsButtonProps`** — Interface defining optional props for identifier, label, styling, and tab behavior.

| Prop | Type | Default | Description |
|---|---|---|---|
| `deviceId` | `string` | — | Primary device identifier |
| `machineId` | `string` | — | Alternative machine identifier (takes precedence over `deviceId`) |
| `label` | `string` | `'Details'` | Button display text |
| `variant` | `'accent' \| 'outline'` | `'outline'` | Visual style variant |
| `className` | `string` | — | Additional CSS classes |
| `openInNewTab` | `boolean` | `false` | Open the details page in a new browser tab |

## Usage Example

```typescript
// Basic usage with a device ID
<DeviceDetailsButton deviceId="dev-abc123" />

// Using machineId with accent variant, opens in new tab
<DeviceDetailsButton
  machineId="machine-xyz789"
  label="View Device"
  variant="accent"
  openInNewTab={true}
  className="mt-2"
/>
```

> **Note:** `machineId` takes precedence over `deviceId` when both are provided. When neither is supplied it renders the same button disabled (never nothing), so a card being read keeps its shape.
