Renders a responsive grid of device cards with loading skeletons, empty states, and infinite scroll support.

## Key Components

### `DevicesGrid`
Main exported component that displays a collection of devices in a responsive grid layout.

**Props (`DevicesGridProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `devices` | `Device[]` | Array of device objects to display |
| `isLoading` | `boolean` | Shows full skeleton grid when true and no devices loaded |
| `hasNextPage` | `boolean` | Controls visibility of the scroll sentinel element |
| `isFetchingNextPage` | `boolean` | Appends 4 skeleton cards during pagination fetch |
| `sentinelRef` | `RefObject<HTMLDivElement>` | Ref attached to the intersection observer sentinel |
| `emptyMessage` | `string` | Custom empty state message (has default) |

**Internal behavior:**
- Resolves device identity via `device.machineId || device.id` for navigation
- Maps device status to label/variant using `getDeviceStatusConfig`
- Derives display name and OS type from utility helpers
- Navigates to `routes.devices.details(id)` on card click

## Usage Example

```typescript
import { DevicesGrid } from './devices-grid';

function DevicesPage() {
  const { data, isLoading, hasNextPage, isFetchingNextPage, ref } = useInfiniteDevices();

  return (
    <DevicesGrid
      devices={data}
      isLoading={isLoading}
      hasNextPage={hasNextPage}
      isFetchingNextPage={isFetchingNextPage}
      sentinelRef={ref}
      emptyMessage="No devices match your current filters."
    />
  );
}
```

## States

| Condition | Rendered Output |
|-----------|----------------|
| `isLoading && devices.length === 0` | 12-card skeleton grid |
| `devices.length === 0` (loaded) | Centered empty state message |
| Devices present | Responsive 1→2→3 column grid of `DeviceCard` components |
| `isFetchingNextPage` | 4 skeleton cards appended to grid |
