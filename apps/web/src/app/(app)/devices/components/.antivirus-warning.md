# antivirus-warning.tsx

A React client component that displays a platform-specific warning about antivirus false positives when installing OpenFrame, providing users with copyable folder paths to exclude from antivirus scanning.

## Key Components

- **`AntivirusWarning`** — The main exported component. Accepts an `OSPlatformId` platform prop (`'windows'`, `'darwin'`, etc.) and renders a warning block with platform-specific installation paths.
- **`AntivirusWarningProps`** — Interface defining the required `platform` prop.
- **Internal logic**:
  - Resolves the relevant `OPENFRAME_PATHS` entry based on the given `platform` (supports `windows` and `darwin`; returns an empty array—and renders nothing—for unsupported platforms).
  - Uses `useCopyToClipboard` to copy a path and show success/error toast-style feedback.
  - Renders `WarningBlock` (outer warning container) and `PathsDisplay` (list of copyable exclusion paths) from `@flamingo-stack/openframe-frontend-core/components/features`.

## Usage Example

```typescript
import { AntivirusWarning } from '@/app/components/antivirus-warning';

export function InstallInstructions() {
  return (
    <div>
      <h2>Install OpenFrame</h2>
      <AntivirusWarning platform="windows" />
    </div>
  );
}
```

The component automatically hides itself (returns `null`) if no exclusion paths are defined for the given platform, so it's safe to render unconditionally based on detected or selected OS.
