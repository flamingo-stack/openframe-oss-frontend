# antivirus-warning.tsx

A client-side React component that displays a platform-specific warning about antivirus false positives when installing OpenFrame, along with the relevant filesystem paths users should exclude from scanning.

## Key Components

- **`AntivirusWarningProps`** — Interface defining the component's props, requiring a `platform` of type `OSPlatformId`.
- **`AntivirusWarning`** — Default exported functional component that renders a warning block containing:
  - A title explaining the false-positive nature of antivirus blocks.
  - A `PathsDisplay` listing OS-specific OpenFrame installation paths with copy-to-clipboard support.
  - Explanatory text suggesting users temporarily disable protection if needed.

The component resolves paths from `OPENFRAME_PATHS` based on the `platform` prop (`windows` or `darwin`), returning `null` if no paths are defined for the given platform. It uses the `useCopyToClipboard` hook to provide clipboard functionality with toast-style success/error messaging.

## Usage Example

```typescript
import { AntivirusWarning } from '@/components/antivirus-warning';

export function InstallationGuide() {
  const detectedPlatform = 'windows'; // or 'darwin', typically from OS detection logic

  return (
    <div>
      <h2>Install OpenFrame</h2>
      <AntivirusWarning platform={detectedPlatform} />
    </div>
  );
}
```

If `platform` is not `windows` or `darwin` (e.g., `linux`), the component renders nothing, since no exclusion paths are defined for that case.

## Notes

- Requires the `'use client'` directive since it uses React hooks (`useMemo`, `useCallback`) and clipboard interaction.
- Depends on shared UI primitives (`WarningBlock`, `PathsDisplay`) and path constants (`OPENFRAME_PATHS`) from `@flamingo-stack/openframe-frontend-core`.
- The copy-to-clipboard behavior is abstracted via the local `useCopyToClipboard` hook at `@/app/hooks/use-copy-to-clipboard`.
