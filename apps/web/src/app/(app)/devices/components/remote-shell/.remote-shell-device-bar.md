# remote-shell-device-bar.tsx

A header bar component for the remote shell view that displays device identity information, tunnel connection status, and a disconnect action button. It integrates with the loading scope context to render skeleton placeholders while data is loading.

## Key Components

- **`RemoteShellDeviceBar`** — The main exported component rendering a flex bar with:
  - A `DeviceIdentity` block showing a terminal icon, device title, and subtitle
  - A status indicator (passed in as a pre-colored `ReactNode`) or a skeleton placeholder during loading
  - A "Disconnect" `Button` that is disabled while loading or when explicitly disabled via props

- **`RemoteShellDeviceBarProps`** — Props interface:
  - `title: string` — primary device/shell label
  - `subtitle: string` — secondary descriptive text
  - `status: ReactNode` — tunnel state element, already styled/colored by the parent page
  - `onDisconnect: () => void` — callback invoked when the Disconnect button is clicked
  - `disconnectDisabled: boolean` — disables the Disconnect button independent of loading state

- **`BAR_CLASS`** / **`DISCONNECT_CLASS`** — Shared Tailwind class constants for consistent styling of the bar container and disconnect button.

## Usage Example

```typescript
import { RemoteShellDeviceBar } from './remote-shell-device-bar';

function RemoteShellPage() {
  const handleDisconnect = () => {
    // close tunnel / navigate away
  };

  return (
    <RemoteShellDeviceBar
      title="prod-web-01"
      subtitle="Remote Shell Session"
      status={<span className="text-green-500">Connected</span>}
      onDisconnect={handleDisconnect}
      disconnectDisabled={false}
    />
  );
}
```

The component relies on `useLoadingScope()` from `@flamingo-stack/openframe-frontend-core` being available via a surrounding loading scope provider; when active, the status is replaced by a `TextLineSkeleton` and the Disconnect button is disabled automatically.
