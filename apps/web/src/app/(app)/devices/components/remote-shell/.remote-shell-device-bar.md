# remote-shell-device-bar.tsx

A header bar component for the remote shell view, displaying the connected device's identity, the tunnel's connection status, and a Disconnect action. It integrates with the page's loading scope to show skeleton placeholders while data is loading.

## Key Components

- **`RemoteShellDeviceBar`** - Main exported component that renders a horizontal bar with:
  - A `DeviceIdentity` block showing a terminal icon, device title, and subtitle (shell name)
  - A status indicator (passed in as pre-styled `ReactNode`, already colored by the parent page)
  - A `Disconnect` button that is disabled while loading or when explicitly disabled via props

- **`RemoteShellDeviceBarProps`** - Props interface:
  - `title: string` - Primary device label
  - `subtitle: string` - Secondary label (e.g., shell type)
  - `status: ReactNode` - Pre-rendered, colored status indicator
  - `onDisconnect: () => void` - Callback invoked when Disconnect is clicked
  - `disconnectDisabled: boolean` - Externally controlled disabled state for the Disconnect button

- Uses `useLoadingScope()` to detect ancestor loading state, rendering `TextLineSkeleton` in place of the status when loading, and disabling the Disconnect button.

## Usage Example

```typescript
import { RemoteShellDeviceBar } from './remote-shell-device-bar';

function RemoteShellPage() {
  const [connected, setConnected] = useState(true);

  const handleDisconnect = () => {
    setConnected(false);
  };

  return (
    <RemoteShellDeviceBar
      title="WIN-DEVICE-01"
      subtitle="PowerShell"
      status={
        <span className="text-ods-success">Connected</span>
      }
      onDisconnect={handleDisconnect}
      disconnectDisabled={!connected}
    />
  );
}
```

This component is typically placed inside a loading-aware page layout (e.g., wrapped by a `LoadingScope` provider) so that the status skeleton automatically appears during data fetches.
