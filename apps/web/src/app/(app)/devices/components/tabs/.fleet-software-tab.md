## FleetSoftwareTab

React component that renders a device's installed software inventory sourced from the Fleet host payload, used when the `software-management` module is disabled. It provides client-side search and sorting over the device's already-fetched software list, with loading, error, and empty states tailored to Fleet agent connectivity status.

## Key Components

- **`FleetSoftwareTab`** — Main exported component; accepts a `device: Device | null` prop and renders a searchable, sortable `DataTable` of software entries, or an appropriate empty/error state.
- **`SoftwareNameCell`** — Renders software name and version, with skeleton support via `useLoadingScope`.
- **`SourceCell`** — Renders the software source (e.g., App, Chrome Extension, Homebrew) with icon and label, mapped via `SOURCE_ICON`/`getSourceIcon`.
- **`VulnerabilityCountCell`** — Renders a `Tag` showing vulnerability count (success/error variant).
- **`LastUsedCell`** — Renders relative "last used" time via `formatLastUsed`, handling Fleet's epoch "never used" sentinel.
- **`FLEET_SOFTWARE_COLUMNS`** — Column configuration (header, width, responsive hide breakpoints) for the table.
- **`FLEET_SOFTWARE_SKELETON_ROWS`** — Constant (10) controlling placeholder row count during loading.

## Usage Example

```typescript
import { FleetSoftwareTab } from './fleet-software-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailsPanel({ device }: { device: Device | null }) {
  return (
    <div className="device-tabs">
      <FleetSoftwareTab device={device} />
    </div>
  );
}
```

The component is self-contained: it reads `device.software` directly (no extra network request), filters by name/vendor via a debounced search input, and automatically switches between loading skeletons, empty states (no device, Fleet error, agent disconnected, agent deploying, or inventory not yet collected), and the populated data table depending on `device` state and `device.sources.fleet` status.
