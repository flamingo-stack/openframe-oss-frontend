Renders a structured hardware information tab for a device detail view, displaying system identity, boot/uptime, CPU, memory, storage, and battery health in a responsive grid layout.

## Key Components

| Export / Symbol | Description |
|---|---|
| `HardwareTab` | Main exported component; accepts a `Device` (or `null`) and renders grouped hardware info cards |
| `HardwareTabProps` | Props interface — single `device: Device \| null` prop |
| `toItems` | Filters and normalizes `InfoRow[]` into display-ready label/value pairs, stripping nulls and empty strings |
| `formatUptime` | Converts raw uptime seconds into a human-readable string (e.g., `2d 4h 30m`) |
| `Row` | Layout primitive — 3-column responsive grid (`1 col → 3 col at lg`) for grouping `Block` components |
| `Block` | Wraps an `InfoCard` with a section heading; renders an invisible placeholder heading to maintain grid alignment when heading is omitted |
| `HardwareEmptyState` | Fallback UI shown when `device` is `null` or no hardware data is present |

## Usage Example

```typescript
import { HardwareTab } from './hardware-tab';
import type { Device } from '../../types/device.types';

// Inside a device detail page or tab panel:
function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <section>
      <HardwareTab device={device} />
    </section>
  );
}
```

**Sections rendered (when data is available):**

```text
Row 1: [System]  [Boot]    [CPU]
Row 2: [Memory]
Row 3: [Storage]
Row 4: [Battery Health] [Battery 2?] ...
```

Each section is conditionally rendered — only cards with at least one non-empty field appear. Storage includes a usage progress bar; battery cards include an inverted health progress bar with warning/critical thresholds.
