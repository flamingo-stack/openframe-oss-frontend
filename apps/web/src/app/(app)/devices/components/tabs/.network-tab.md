# network-tab.tsx

Renders the "Network" tab within a device detail view, displaying interface identity, geolocation, and categorized IPv4/IPv6 address lists for a device. Handles loading skeletons, empty states, and pending-deployment states via shared tab components.

## Key Components

- **`NetworkTab`** — Main exported component. Accepts a `device` (or `null`) and renders grouped `InfoCard` sections for network interface info, location, and IP addresses. Uses `useLoadingScope()` to coordinate skeleton rendering while device data loads.
- **`sortIpv4(addresses)`** — Utility that numerically sorts dotted IPv4/CIDR address strings (octet-by-octet comparison instead of lexicographic).
- **`Labeled`** — Small internal wrapper that renders an uppercase section title above its children.
- **`TYPICAL_IP_ROWS`** — Constant (`2`) controlling the number of skeleton rows shown for IP address cards while loading.

## Usage Example

```typescript
import { NetworkTab } from './network-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPanel({ device }: { device: Device | null }) {
  return (
    <div className="tab-panel">
      <NetworkTab device={device} />
    </div>
  );
}
```

## Behavior Notes

- **Empty states**: If no device is provided (and not loading), shows a generic "No network data found" empty state. If a device exists but has no network data at all, it checks `device.sources.fleet === 'skipped-pending'` to show a deploying-specific empty state instead.
- **IP sorting**: IPv4 addresses are numerically sorted via `sortIpv4`, with the Fleet-reported `primary_ip` pinned to the top of the list. IPv6 addresses use default string sorting.
- **Section visibility**: Each section (interface, location, IPv4, IPv6) is independently shown if it has data or if the component is in a loading state (so skeletons render per-card).
- **Dependencies**: Relies on `InfoCard` and `useLoadingScope` from `@flamingo-stack/openframe-frontend-core`, plus shared helpers `deviceInfoItems`, `hasDeviceInfo`, and `labelsOf` for building row data and skeleton placeholders.
