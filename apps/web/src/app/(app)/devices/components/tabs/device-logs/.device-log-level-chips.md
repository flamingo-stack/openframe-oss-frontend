# device-log-level-chips.tsx

Renders a row of toggleable chip controls for filtering device logs by severity level (DEBUG, INFO, WARN, ERROR). Shared between the device detail tab and the Troubleshooting page to provide a consistent log-level filter UI.

## Key Components

- **`DeviceLogLevelChips`** — React component rendering a `role="group"` container of `Tag` chips, one per entry in `DEVICE_LOG_LEVELS`, in severity order.
- **`DeviceLogLevelChipsProps`** — Props interface:
  - `selectedLevels: ReadonlyArray<DeviceLogLevel>` — currently active levels; an empty array means "all levels selected" (every chip renders as "on").
  - `onToggleLevel: (level: DeviceLogLevel) => void` — callback fired when a chip is activated via click or keyboard.
  - `disabled?: boolean` — disables interaction and keyboard focus on all chips.

Each chip is keyboard-accessible (`Enter`/`Space` triggers toggle via `chipKeyDown`), uses `aria-pressed` to reflect selection state, and applies visual styling through `deviceLogLevelVariant` (active) or `'outline'` (inactive), with reduced opacity when off.

## Usage Example

```typescript
import { useState } from 'react';
import { DeviceLogLevelChips } from './device-log-level-chips';
import type { DeviceLogLevel } from '@/generated/schema-enums';

function LogFilterPanel() {
  const [selectedLevels, setSelectedLevels] = useState<DeviceLogLevel[]>([]);

  const handleToggle = (level: DeviceLogLevel) => {
    setSelectedLevels(prev =>
      prev.includes(level)
        ? prev.filter(l => l !== level)
        : [...prev, level]
    );
  };

  return (
    <DeviceLogLevelChips
      selectedLevels={selectedLevels}
      onToggleLevel={handleToggle}
      disabled={false}
    />
  );
}
```

An empty `selectedLevels` array treats all levels as active, which is useful as a default "show everything" state before the user applies any filters.
