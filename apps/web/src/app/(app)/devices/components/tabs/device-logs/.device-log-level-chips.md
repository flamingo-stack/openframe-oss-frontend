# device-log-level-chips.tsx

Renders a row of toggleable chips for filtering logs by severity level (DEBUG, INFO, WARN, ERROR). Shared component used across the device detail tab and the Troubleshooting page to let users select which log levels to display.

## Key Components

- **`DeviceLogLevelChips`** — React component that renders one `Tag` chip per entry in `DEVICE_LOG_LEVELS`, each acting as an accessible toggle button.
- **`DeviceLogLevelChipsProps`** — Props interface:
  - `selectedLevels: ReadonlyArray<DeviceLogLevel>` — currently active levels; an empty array is treated as "all levels selected."
  - `onToggleLevel: (level: DeviceLogLevel) => void` — callback invoked when a chip is clicked or activated via keyboard.
  - `disabled?: boolean` — disables interaction and keyboard focus for all chips.

### Behavior notes
- Chips support keyboard activation (`Enter` / `Space`) via a `role="button"` wrapper with `tabIndex` and `aria-pressed`.
- Visual variant is computed with `deviceLogLevelVariant(level)` when active, falling back to `'outline'` when inactive.
- Inactive chips get reduced opacity (`opacity-50`); disabled chips lose pointer cursor and interaction handlers.
- The group is wrapped in a `role="group"` container with `aria-label="Log levels"` for accessibility.

## Usage Example

```typescript
import { useState } from 'react';
import { DeviceLogLevelChips } from './device-log-level-chips';
import type { DeviceLogLevel } from '@/generated/schema-enums';

function LogFilterBar() {
  const [selectedLevels, setSelectedLevels] = useState<DeviceLogLevel[]>([]);

  const toggleLevel = (level: DeviceLogLevel) => {
    setSelectedLevels(prev =>
      prev.includes(level) ? prev.filter(l => l !== level) : [...prev, level]
    );
  };

  return (
    <DeviceLogLevelChips
      selectedLevels={selectedLevels}
      onToggleLevel={toggleLevel}
    />
  );
}
```
