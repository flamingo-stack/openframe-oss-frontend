# device-vulnerabilities-table.tsx

Renders the "Vulnerabilities" tab of a device detail page, listing CVEs found on a single machine using the shared `VulnerabilityTable` component. It fetches data via a paginated Relay GraphQL query scoped to `machineId`, supporting search and infinite scroll (no sorting or filter funnels, matching the fleet-wide vulnerability list's underlying node type).

## Key Components

- **`DeviceVulnerabilitiesTable`** — Public component. Wraps the reader in a `LoadingSuspense` boundary with the label "Loading vulnerabilities".
- **`DeviceVulnerabilitiesTableReader`** — Checks `useLoadingScope()`; if the device/module context hasn't resolved yet, renders a skeleton `VulnerabilityTable` with no data. Otherwise delegates to the query component.
- **`DeviceVulnerabilitiesTableQuery`** — Executes `useLazyLoadQuery` for the device's vulnerabilities, then uses `usePaginationFragment` to drive infinite scroll via `loadNext`. Maps connection edges to rows and passes them to `VulnerabilityTable`.
- **`deviceVulnerabilitiesTableQuery`** / **`deviceVulnerabilitiesTableFragment`** — GraphQL query and refetchable fragment definitions, parameterized by `machineId`, `search`, `first`, and `after`.

## Usage Example

```typescript
import { DeviceVulnerabilitiesTable } from '@/app/(app)/devices/components/device-vulnerabilities-table';

function DeviceVulnerabilitiesTab({ machineId }: { machineId: string }) {
  const [search, setSearch] = useState('');
  const [isEmpty, setIsEmpty] = useState(false);
  const debouncedSearch = useDebouncedValue(search);

  return (
    <DeviceVulnerabilitiesTable
      machineId={machineId}
      debouncedSearch={debouncedSearch}
      isPending={false}
      emptyState={<NoVulnerabilitiesFound />}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
    />
  );
}
```

Pagination size is controlled by `VULNERABILITY_LIST_PAGE_SIZE`, shared with the fleet-wide vulnerability list to keep page-size behavior consistent across both views.
