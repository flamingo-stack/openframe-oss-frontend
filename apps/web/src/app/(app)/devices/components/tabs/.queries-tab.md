Renders the "Queries" tab within a device detail page, listing the scheduled osquery reports assigned to a specific host, with search filtering and links to query details.

## Key Components

- **`QueriesTab`** — Client component (`'use client'`) that accepts a `device` prop and displays a searchable, sortable table of the device's scheduled queries.
- **`QUERIES_TAB_SKELETON_ROWS`** — Constant defining the number of skeleton rows (5) shown during loading, since devices typically have only a handful of scheduled queries.
- **Data fetching** — Combines two hooks:
  - `useHostQueries(device?.fleetId)` — fetches host-specific query reports from `/fleet/hosts/{id}/queries` (lacks interval/frequency data).
  - `useQueries({ team_id })` — fetches the team-scoped global query list from `/fleet/queries` to recover each query's `interval`, joined by query ID.
- **Row mapping** — Builds `QueryTableRow[]` by filtering host reports against the search term (name/description) and enriching each with a formatted frequency label (`formatQueryInterval`) and a link to `routes.monitoring.query(id)`.
- **Empty states** — Three distinct states handled via `TabEmptyState`: no device loaded, no queries assigned at all, and no search results (handled inline in `QueriesTable`'s `emptyState` prop).
- **Sticky search toolbar** — Uses `useStickyToolbar` to keep the search `Input` pinned while scrolling, conditionally hidden when the table is truly empty.

## Usage Example

```typescript
import { QueriesTab } from '@/app/(app)/monitoring/devices/[id]/components/queries-tab';

function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <div>
      {/* other tabs */}
      <QueriesTab device={device} />
    </div>
  );
}
```

The component requires no additional configuration beyond the `device` object; it internally resolves `fleetId` and `fleetTeamId` to fetch and join the relevant query data, and navigates to the query details route via Next.js's `useRouter` when a row is clicked or its "Query Details" action is invoked.
