# security-tab.tsx

Renders the Security tab for a device detail view, showing disk encryption status, installed security agent versions (OpenFrame Agent, osquery, Orbit, Fleet Desktop), and Fleet policy/posture compliance (failing policies, total issues). Supports loading skeletons and empty/deploying states when no device or no security data is available.

## Key Components

- **`SecurityTab`** — Main exported component. Takes a `Device | null` prop and renders either a loading skeleton, an empty state, a "deploying" state (when Fleet is pending), or the built security sections.
- **`buildSections(device)`** — Derives `SecuritySection[]` (Encryption, Security Agents, Posture) from the normalized `Device` object. Sections/cards are omitted entirely when the underlying data isn't available (no "Unknown" filler).
- **`LOADING_SECTIONS`** — Static mirror of `buildSections`' typical output, used to render skeleton bars while the device is loading, sourced from the same `SECTION`/`ROW`/`CARD_TITLE`/`AGENT_CARD` copy tables to avoid drift.
- **`SecurityStatusCard` / `SecuritySectionBlock` / `StatusRow`** — Presentational building blocks: a card with a title and rows, a titled section containing a grid of cards, and a single labeled row with a value tone (`success`/`error`/`warning`/`neutral`) and matching trailing icon.
- **`normalizeVersion(version)`** — Cleans agent version strings, treating `"unknown"` or empty values as absent.

## Usage Example

```typescript
import { SecurityTab } from './security-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPanel({ device }: { device: Device | null }) {
  return (
    <div>
      {/* Renders loading skeletons, empty state, or security sections automatically */}
      <SecurityTab device={device} />
    </div>
  );
}
```

The component relies on a `useLoadingScope()` context to determine whether to render skeleton placeholders (`LOADING_SECTIONS`) or real data from `buildSections(device)`. When `device` is `null` and not loading, it shows a `TabEmptyState`; when Fleet reporting is `skipped-pending`, it shows `TabDeployingEmptyState` instead.
