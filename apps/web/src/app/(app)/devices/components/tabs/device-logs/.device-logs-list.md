# device-logs-list.tsx

Renders a paginated, auto-updating list of device logs grouped by local day, with infinite scroll for older entries and a live-tail mechanism that re-fetches the head of the list when new logs arrive. Built with Relay fragments/pagination and designed to coexist with React Suspense/transition loading states.

## Key Components

- **`DeviceLogsList`** — Public component. Wraps the reader in a `LoadingSuspense` boundary and remounts via `listKey` when the active filter changes (preserving the outer boundary across filter swaps).
- **`DeviceLogsListReader`** — Detects an active loading scope (parent Suspense fallback) and renders a lightweight loading page instead of issuing a query; otherwise delegates to `DeviceLogsListQuery`.
- **`DeviceLogsListQuery`** — Core data-fetching component. Runs the paginated GraphQL query via `useLazyLoadQuery` + `usePaginationFragment`, wires up:
  - Infinite scroll (`useGridInfiniteScroll`) for loading older pages.
  - Live tail (`useDeviceLogsLiveTail`) for auto-refreshing the newest logs when scrolled to top.
  - Day grouping (`groupByLocalDay`) for rendering `DeviceLogDayGroup` sections.
  - Error/retry handling for both live-tail failures and "load more" failures.
  - Empty state (`TabEmptyState`) when no logs match the filter.
- **`DeviceLogsLoadingPage`** — Skeleton loader rendering `PAGE_SIZE` placeholder rows, optionally with a day header.
- **`DeviceLogsFilter`** — Exported type alias for the GraphQL filter input shape.
- **`PAGE_SIZE`** — Page size constant (100) used for both initial query and pagination.

## Usage Example

```typescript
import { DeviceLogsList, type DeviceLogsFilter } from './device-logs-list';

function DeviceLogsPanel({ hostname }: { hostname: string }) {
  const [filter, setFilter] = useState<DeviceLogsFilter>({});
  const [selectedKey, setSelectedKey] = useState<string | null>(null);

  return (
    <DeviceLogsList
      listKey={JSON.stringify(filter)}
      machineIds={[hostname]}
      filter={filter}
      deviceHostname={hostname}
      isPending={false}
      autoUpdate
      hasFilters={Object.keys(filter).length > 0}
      onResetFilters={() => setFilter({})}
      selectedKey={selectedKey}
      onSelect={(key, entry) => {
        setSelectedKey(key);
        // open log details drawer with `entry`
      }}
    />
  );
}
```

Pass `listKey` as a stable identity derived from the active filter/device scope so filter changes remount the list within its Suspense boundary, keeping prior rows visible during the transition.
