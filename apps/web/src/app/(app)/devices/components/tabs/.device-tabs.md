# device-tabs.tsx

Defines the full set of tabs rendered on the device detail page, including feature-gated tabs for Incidents, Remote Sessions, Users/Directory, and wires up the visibility filtering logic via `useDeviceTabs`.

## Key Components

- **`ALL_DEVICE_TABS`** — Exported array of `TabItem` definitions (id, label, icon, component) for every possible device tab, including gated ones. Serves as the master registry; `useDeviceTabs` filters it down to the visible subset.
- **`useDeviceTabs(directoryGate)`** — Hook that returns the filtered list of tabs to render, hiding tabs whose feature gate resolves to `'off'` (Remote Sessions, Incidents, Directory). Tabs in a `'loading'` state remain visible with their panel showing a loading form.
- **`DeviceDirectoryGateContext`** — React context carrying the directory feature gate value so the tab bar and the active tab panel read the same gate result and never disagree.
- **`GatedIncidentsTab` / `GatedRemoteSessionsTab` / `GatedUsersTab` / `GatedDirectoryTab`** — Module-level wrapper components that read their respective gates and render a loading state (via `LoadingWhen`) or the real tab content (`IncidentsTab`, `RemoteSessionsTab`, `UsersTab`/`DirectoryUsersTab`, `DirectoryTab`). Being module-level keeps component identity stable so tabs don't remount on re-render.
- **`ArticlesTab`** — Wrapper rendering `AssignedArticlesTab` scoped to the current device via `deviceArticlesTarget`, showing a loading state until `device.machineId` is available.
- **`REMOTE_SESSIONS_TAB_ID`, `INCIDENTS_TAB_ID`, `DEVICE_LOGS_TAB_ID`, `DIRECTORY_TAB_ID`** — Tab id constants typed with `satisfies DeviceDetailTab` to keep this file in sync with the route registry.

## Usage Example

```typescript
import { useDeviceTabs, DeviceDirectoryGateContext } from './device-tabs';

function DeviceDetailPage({ device, directoryGate }) {
  const tabs = useDeviceTabs(directoryGate);

  return (
    <DeviceDirectoryGateContext.Provider value={directoryGate}>
      <TabsView tabs={tabs} context={{ device }} />
    </DeviceDirectoryGateContext.Provider>
  );
}
```

Each `TabItem`'s `component` receives `{ device }` as props and is rendered inside the tab panel container managed by the page.
