## device-log-layout.ts

Shared Tailwind CSS class constants defining the layout geometry for device log rows, ensuring visual consistency between skeleton loading states and real content (preventing layout shift during the swap). Also centralizes the list container and scroll-sentinel styling used for infinite scroll and live-tail features.

## Key Components

- **`DEVICE_LOG_LINE`** - Flex row layout shared by both live log lines and their skeleton placeholders.
- **`DEVICE_LOG_TIME_COLUMN`** - Fixed-width column sized to fit timestamps like `13:23:05.486`.
- **`DEVICE_LOG_LEVEL_COLUMN`** - Fixed-width slot for log level labels (e.g. `INFO`, `ERROR`), sized so the message column stays aligned regardless of label length.
- **`DEVICE_LOG_DAY_HEADER`** - Layout for the date heading displayed above each day's group of log lines.
- **`DEVICE_LOG_LIST_CLASS`** - Single-column grid (not flex-column) for stacking days/lines, chosen for performance with large, frequently-updated lists.
- **`DEVICE_LOG_SENTINEL_CLASS`** - Minimal-height marker element used as a scroll trigger for infinite scroll and live-tail "at top" detection.

## Usage Example

```typescript
import {
  DEVICE_LOG_LINE,
  DEVICE_LOG_TIME_COLUMN,
  DEVICE_LOG_LEVEL_COLUMN,
  DEVICE_LOG_DAY_HEADER,
  DEVICE_LOG_LIST_CLASS,
  DEVICE_LOG_SENTINEL_CLASS,
} from './device-log-layout';

function DeviceLogList({ days }: { days: LogDay[] }) {
  return (
    <div class={DEVICE_LOG_LIST_CLASS}>
      <div class={DEVICE_LOG_SENTINEL_CLASS} data-role="top-sentinel" />
      {days.map((day) => (
        <section key={day.date}>
          <div class={DEVICE_LOG_DAY_HEADER}>{day.date}</div>
          {day.lines.map((line) => (
            <div key={line.id} class={DEVICE_LOG_LINE}>
              <span class={DEVICE_LOG_TIME_COLUMN}>{line.time}</span>
              <span class={DEVICE_LOG_LEVEL_COLUMN}>{line.level}</span>
              <span>{line.message}</span>
            </div>
          ))}
        </section>
      ))}
      <div class={DEVICE_LOG_SENTINEL_CLASS} data-role="bottom-sentinel" />
    </div>
  );
}
```
