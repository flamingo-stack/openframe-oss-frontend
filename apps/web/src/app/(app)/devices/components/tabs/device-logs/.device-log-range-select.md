# device-log-range-select.tsx

A React component that renders a time-range preset selector for device logs, revealing a date-range picker inline when the user selects the "custom" option. It is a layout-agnostic fragment, allowing the caller to control how the select and picker are arranged within a row.

## Key Components

- **`DeviceLogRangeSelect`** — Main component combining a `Select` dropdown (populated from `DEVICE_LOG_RANGES`/`DEVICE_LOG_RANGE_LABELS`) with a conditionally rendered `DatePicker` for custom ranges.
- **`DeviceLogRangeSelectProps`** — Props interface:
  - `range: DeviceLogRange` — currently selected preset.
  - `onRangeChange: (range: DeviceLogRange) => void` — callback when the preset changes.
  - `customRange: DateRange | undefined` — current custom date range value.
  - `onCustomRangeChange: (range: DateRange | undefined) => void` — callback for custom range updates.
  - `pickerBounds: { fromDate: Date; toDate: Date }` — min/max selectable dates for the picker.
  - `disabled?: boolean` — disables both controls.
  - `triggerClassName?: string` / `pickerClassName?: string` — styling hooks for the select trigger and picker, since placement varies by surface.

## Usage Example

```vue
<!-- Example usage within a parent component -->
<script setup lang="ts">
import { useState } from 'react'
</script>
```

```typescript
import { useState } from 'react';
import { DeviceLogRangeSelect } from './device-log-range-select';
import type { DateRange } from '@flamingo-stack/openframe-frontend-core/components/ui';
import type { DeviceLogRange } from '../../../utils/device-log-time';

function DeviceLogFilters() {
  const [range, setRange] = useState<DeviceLogRange>('24h');
  const [customRange, setCustomRange] = useState<DateRange | undefined>();

  return (
    <div className="flex items-center gap-2">
      <DeviceLogRangeSelect
        range={range}
        onRangeChange={setRange}
        customRange={customRange}
        onCustomRangeChange={setCustomRange}
        pickerBounds={{ fromDate: new Date(2023, 0, 1), toDate: new Date() }}
        triggerClassName="w-40"
        pickerClassName="ml-2"
      />
    </div>
  );
}
```

Relies on shared utilities from `../../../utils/device-log-time` (`DEVICE_LOG_RANGE_LABELS`, `DEVICE_LOG_RANGES`, `DeviceLogRange`) and UI primitives from `@flamingo-stack/openframe-frontend-core`.
