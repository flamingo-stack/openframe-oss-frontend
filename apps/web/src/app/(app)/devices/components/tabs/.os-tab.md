# os-tab.tsx

Renders the "OS" tab for a device detail view, displaying operating system identity, boot/time information, and Fleet management metadata in a set of `InfoCard` sections, with built-in loading, deploying, and empty states.

## Key Components

- **`OsTab`** — Main exported component. Accepts a `device` prop and renders three grouped sections: Operating System, Boot & Time, and Management (Fleet). Handles three UI states:
  - **Loading**: shows skeleton placeholders via `useLoadingScope()`.
  - **Deploying**: shows `TabDeployingEmptyState` when `device.sources.fleet === 'skipped-pending'`.
  - **Empty**: shows `OsEmptyState` when no device data or no section data is available.
- **`formatUptime(seconds)`** — Converts a seconds count into a human-readable duration string (e.g., `"3d 4h"`), omitting minutes when days are present.
- **`Section`** — Small layout wrapper rendering an uppercase section title with its children.
- **`OsEmptyState`** — Empty-state illustration/message shown when no OS data exists for the device.

## Usage Example

```typescript
import { OsTab } from './os-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPanel({ device }: { device: Device | null }) {
  return (
    <div className="tab-panel">
      <OsTab device={device} />
    </div>
  );
}
```

**Notes:**
- `nowSeconds` is sampled once via `useState` on mount (not computed inline during render) to keep the component pure across renders and avoid breaking memoization.
- Boot and enrollment timestamps are formatted using the device's own timezone (`formatDateTimeOnDevice`) when available, falling back to the viewer's timezone otherwise.
- Section visibility (`showOs`, `showBoot`, `showManagement`) is computed independently so each `InfoCard` can render its own skeleton or populated state based on data availability, even while other sections are still loading.
- Row definitions (`osRows`, `bootRows`, `managementRows`) use the shared `DeviceInfoRow` shape and are converted to display items via `deviceInfoItems()` / `labelsOf()` from `device-info-rows` utilities.
