A React tab component that displays user accounts associated with a device, featuring searchable/filterable rows with columns for username, UID, type, group, shell, and active session status.

## Key Components

- **`UsersTab`** — Main exported component rendering the users data table for a given device
- **`UserRow`** — Internal interface mapping raw device user data into table-friendly rows
- **`roleLabel`** — Helper that derives a human-readable role description (e.g., `"Active session"`, `"User account"`, `"System user"`) from a `UserRow`
- **Column definitions** — Six columns: `USER` (username + role label), `UID`, `TYPE`, `GROUP`, `SHELL`, and `STATUS` (active session tag); responsive hiding applied at `md`/`lg` breakpoints
- **`useStickyToolbar`** — Hook providing sticky toolbar positioning for the search input
- **`useDebounce`** — Debounces the search query (300 ms) before filtering rows
- **`TabEmptyState`** — Shared empty state component shown when the device is null or has no users

## Usage Example

```typescript
import { UsersTab } from './users-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  users: [
    { username: 'jdoe', uid: 1001, type: 'person', groupname: 'staff', shell: '/bin/zsh', isLoggedIn: true },
    { username: 'daemon', uid: 1, type: 'system', groupname: 'daemon', shell: '/usr/sbin/nologin' },
  ],
  endUserEmails: ['jdoe@example.com'],
  // ...other device fields
};

<UsersTab device={device} />
```

## Notes

- End-user emails from `device.endUserEmails` are rendered as `Tag` chips above the table when present
- The search toolbar is hidden when the table is empty and no active query exists, preventing a misleading UI
- Rows are filtered client-side against `username`, `groupname`, and `type` fields
