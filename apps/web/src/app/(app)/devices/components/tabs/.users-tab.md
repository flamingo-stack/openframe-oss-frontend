# users-tab.tsx

Renders the "Users" tab of a device detail view, displaying local user accounts for a device in a searchable, sortable-disabled data table with full loading-skeleton support and empty-state handling.

## Key Components

- **`UsersTab`** — Main exported component. Accepts a `device: Device | null` prop and renders a searchable table of the device's user accounts, with loading skeletons, deploying/empty states, and an optional end-user emails strip.
- **`UserRow`** — Internal row shape (`id`, `username`, `uid`, `type`, `groupname`, `shell`, `isLoggedIn`) derived from `device.users`.
- **`USER_COLUMNS`** — Column layout configuration (header, width, responsive hide breakpoints) for USER, UID, TYPE, GROUP, SHELL, and STATUS columns.
- **`UserNameCell`** — Cell renderer showing username plus a role label (e.g., "Active session", "User account"), skeleton-aware via `useLoadingScope`.
- **`UserTypeCell`** — Cell renderer for the account type, with a skeleton fallback.
- **`roleLabel`** — Helper deriving a human-readable role description from a `UserRow`.
- **`USERS_TAB_SKELETON_ROWS`** — Constant (10) defining the number of placeholder rows shown while loading.

## Usage Example

```typescript
import { UsersTab } from './users-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPanel({ device }: { device: Device | null }) {
  return (
    <div>
      {/* Renders loading skeleton, empty states, or the users table automatically */}
      <UsersTab device={device} />
    </div>
  );
}
```

The component自动ically handles three states:
- **Loading** — when wrapped in a loading scope (`useLoadingScope`), shows skeleton rows and bars.
- **No device / no users** — shows `TabEmptyState` with a descriptive message, or `TabDeployingEmptyState` if Fleet data collection is pending (`device.sources?.fleet === 'skipped-pending'`).
- **Populated** — shows a debounced-search-filterable `DataTable` with sticky header/toolbar, plus an optional end-user emails `Tag` strip when available.
