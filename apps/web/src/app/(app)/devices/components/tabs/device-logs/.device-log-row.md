Renders a single device log line (time, level, message, optional hostname/count chips) as a clickable row that opens the Log Details drawer, plus helper components for grouping log rows by day with date headings.

## Key Components

- **`DeviceLogEntry`** — Interface representing a fully-loaded log line, used as the shape passed to the Log Details drawer.
- **`DeviceLogRow`** — Main component rendering one log line. Uses a GraphQL fragment (`deviceLogRow_entry`) via `useFragment` to read entry data, supports a loading state (skeleton bars) via `useLoadingScope`, and shows a hostname chip either always (multi-device lists) or only when it differs from the list's device (single-device lists). Clicking invokes `onSelect` with the full entry.
- **`DeviceLogDayGroup`** — Wraps a day's rows in a `<section>`/`<ul>`, optionally rendering a `DeviceLogDayHeader` when a `date` is provided.
- **`DeviceLogDayHeader`** — Internal component rendering the uppercase formatted date heading with a loading-aware skeleton fallback.

## Usage Example

```typescript
import { DeviceLogRow, DeviceLogDayGroup } from './device-log-row';

function DeviceLogList({ entries, deviceHostname, selectedId, onSelectEntry }) {
  return (
    <DeviceLogDayGroup date={new Date()}>
      {entries.map((entry) => (
        <DeviceLogRow
          key={entry.id}
          entry={entry}
          deviceHostname={deviceHostname}
          selected={entry.id === selectedId}
          onSelect={onSelectEntry}
        />
      ))}
    </DeviceLogDayGroup>
  );
}

// Loading state: pass `entry={null}` inside a loading scope to render skeleton bars
<DeviceLogRow entry={null} selected={false} onSelect={() => {}} />
```

Omit `deviceHostname` for lists spanning multiple devices (always shows the hostname chip); provide it for single-device lists (hostname chip shown only when a line's host differs, visible from `content-md` breakpoint up).
