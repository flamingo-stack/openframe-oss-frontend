Renders the "Directory" tab on the device detail page, showing Microsoft Entra ID and Intune directory records (compliance, management, ownership, sign-in activity) for a given device via a GraphQL query against `deviceDirectory`.

## Key Components

- **`DirectoryTab`** – Public entry point. Takes a `device` prop, resolves its `machineId`, and wraps the content in `LoadingSuspense` for async loading/gating.
- **`DirectoryReader`** – Decides whether to render a placeholder (`DirectoryCards` with `null`) or fire the live query (`DirectoryQuery`), based on loading scope and `machineId` availability.
- **`DirectoryQuery`** – Executes `directoryTabQuery` via `useLazyLoadQuery` (store-and-network policy, retry-aware) and passes results to `DirectoryCards`.
- **`DirectoryCards`** – Renders the grid of directory cards or an empty state (`TabEmptyState`) when no records exist; shows skeleton rows while loading.
- **`EntraCard`** – Displays Entra ID fields: join type, compliance, MDM management, last sign-in, owners, and group membership.
- **`IntuneCard`** – Displays Intune fields: primary user, ownership, compliance tag, encryption, management mode, enrollment date, last check-in.
- **`IntuneUnavailable`** – Shows a fallback message (e.g., "No Intune licence/access") when Intune data isn't available.
- **`YesNo`**, **`CardSection`**, **`StaleHint`** – Small presentational helpers for boolean tags, titled sections, and stale-data notices.
- **`directoryTabQuery`** – GraphQL query fetching `deviceDirectory` cards (Entra + Intune) for a `machineId`.

## Usage Example

```typescript
import { DirectoryTab } from '@/app/(app)/users/components/user-detail/directory-tab';

function DeviceDetailPanel({ device }: { device: Device | null }) {
  return (
    <div>
      {/* Other tabs... */}
      <DirectoryTab device={device} />
    </div>
  );
}
```

The component expects `device.machineId`; if `null`, `LoadingSuspense` gates rendering until a valid device is available. Data staleness (`liveDataUnavailable`) is surfaced per-card via `StaleHint`.
