# directory-tab.tsx

Renders the "Directory" tab on the device detail page, showing Microsoft Entra ID and Intune enrollment/compliance information for a device via a GraphQL Relay query, with loading, empty, and stale-data states.

## Key Components

- **`DirectoryTab`** — Exported entry component. Accepts a `device` object, extracts its `machineId`, and wraps the reader in a `LoadingSuspense` boundary that gates rendering until the machine ID is available.
- **`DirectoryReader`** — Decides whether to show a placeholder (`DirectoryCards` with no data) while loading/no `machineId`, or fire the live query via `DirectoryQuery`.
- **`DirectoryQuery`** — Executes `directoryTabQuery` with `useLazyLoadQuery`, using `store-and-network` fetch policy and a retry key (`useRetryKey`) to support manual refresh.
- **`DirectoryCards`** — Renders the grid of Entra/Intune cards, the "no records" empty state (`TabEmptyState`), or loading skeleton rows.
- **`EntraCard`** / **`IntuneCard`** — Present join type, compliance, management, sign-in, enrollment, and ownership details as `LeaderRow` entries, with a `StaleHint` shown when live data was unavailable.
- **`IntuneUnavailable`** — Displays a friendly message (e.g., "No Intune licence") in place of the Intune card when access/licensing prevents data retrieval.
- **`YesNo`** — Renders a boolean as a `Tag` (`Yes`/`No`) or an empty-value marker when unknown.
- **`directoryTabQuery`** — GraphQL query fetching `deviceDirectory` cards (Entra and Intune fields) for a given `machineId`.

## Usage Example

```typescript
import { DirectoryTab } from '@/app/(app)/users/components/user-detail/directory-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <div>
      <DirectoryTab device={device} />
    </div>
  );
}
```

The component requires no additional setup beyond a valid `device` object with a `machineId`; it internally manages Relay data fetching, loading states, and fallback UI for missing or stale directory data.
