# directory-users-tab.tsx

Renders the "Users" tab on a device detail page, listing directory-linked user accounts (and their group memberships) for a given device, with search, filtering, and loading/empty states. It fetches data via a Relay GraphQL query scoped to the device's `machineId` and composes shared table/filter UI components.

## Key Components

- **`DirectoryUsersTab`** — Public entry point; takes a `Device | null` and wraps the reader in `LoadingSuspense`, gating the query until `machineId` is available.
- **`DirectoryUsersReader`** — Decides whether to show placeholder rows (while loading or no `machineId`) or trigger the Relay query.
- **`DirectoryUsersQuery`** — Executes `directoryUsersTabQuery` via `useLazyLoadQuery` and passes resulting users to the rows renderer.
- **`DirectoryUsersRows`** — Core presentational component: manages search, debounced filtering, column filters (status, customer, group), sticky toolbar, and renders `LiveTable` with `FilterModal` support.
- **`toRow`** — Maps a `DirectoryUser` GraphQL record into a `UserRow` for table rendering.
- **`buildColumns`** — Constructs `ColumnDef<UserRow>[]` for user, status, customer, group, and open-row columns.
- **`FACETS` / `matches` / `facetOptions`** — Client-side faceted filtering logic that counts/filters rows by status, customer, and group selections.
- **`directoryUsersTabQuery`** — GraphQL query fetching `deviceDirectory.users` (account info, groups, connection) for a device.

## Usage Example

```typescript
import { DirectoryUsersTab } from '@/app/(app)/devices/[id]/components/directory-users-tab';

function DeviceUsersPanel({ device }: { device: Device | null }) {
  return <DirectoryUsersTab device={device} />;
}
```

The component handles its own data fetching, loading skeletons, empty states, and filter UI internally—consumers only need to pass the current `device` object (or `null` while it loads).
