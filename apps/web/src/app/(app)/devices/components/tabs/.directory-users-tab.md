# directory-users-tab.tsx

Renders the "Users" tab on a device detail page, listing directory users associated with a specific device via a GraphQL query, with client-side search, filtering, and a sticky toolbar.

## Key Components

- **`DirectoryUsersTab`** — Public entry component; accepts a `device` prop, extracts `machineId`, and wraps the reader in `LoadingSuspense` for loading/gating behavior.
- **`DirectoryUsersReader`** — Internal component deciding whether to show a placeholder (no `machineId` or still loading) or trigger the live GraphQL query.
- **`DirectoryUsersQuery`** — Fetches `deviceDirectory.users` via `useLazyLoadQuery` with `directoryUsersTabQuery`, using a retry key for refetch support.
- **`DirectoryUsersRows`** — Core presentational component: handles search (debounced), column filters, facet option computation, and renders the table using `LiveTable`.
- **`directoryUsersTabQuery`** — GraphQL query fetching user accounts, groups, status, and connection/provider info for a device's directory.
- **`toRow`** — Maps a `DirectoryUser` GraphQL record to a `UserRow` for table display.
- **`buildColumns`** — Constructs `ColumnDef<UserRow>[]` for user, status, customer, group, and open-row columns.
- **`matches` / `matchesSearch` / `facetOptions`** — Client-side filtering utilities that replicate server-facet counting logic locally since the field has no server-side filter support.
- **`COLUMNS_LAYOUT`** — Static layout/width/visibility config for table columns.

## Usage Example

```typescript
import { DirectoryUsersTab } from '@/app/(app)/devices/components/directory-users-tab';
import type { Device } from '../../types/device.types';

function DeviceUsersPanel({ device }: { device: Device | null }) {
  return <DirectoryUsersTab device={device} />;
}
```

This component is typically rendered inside a device detail page's tab layout, where `device` (containing `machineId`) is passed down from a parent query. Internally, it manages its own search/filter state and loading skeletons, requiring no additional props or wiring beyond the `device` object.
