# device-software-table.tsx

Renders the Software tab's paginated, searchable list of software installed on a single device, reusing the shared `SoftwareTable` presentation component but scoped to a specific `machineId` via a Relay connection.

## Key Components

- **`DeviceSoftwareTable`** — Public entry point. Wraps the query-driven reader in a `LoadingSuspense` boundary with the label "Loading software", giving this tab its own independent loading fallback.
- **`DeviceSoftwareTableReader`** — Checks `useLoadingScope()`; if the surrounding scope hasn't resolved (device/feature flag pending), renders `SoftwareTable` in its empty/loading form without issuing a query. Otherwise delegates to `DeviceSoftwareTableQuery`.
- **`DeviceSoftwareTableQuery`** — Issues `deviceSoftwareTableQuery` via `useLazyLoadQuery`, then drives infinite scroll with `usePaginationFragment` over `deviceSoftwareTable_query` (refetchable as `deviceSoftwareTablePaginationQuery`). Maps connection edges to rows and passes pagination state (`hasNext`, `isLoadingNext`, `loadNext`) into `SoftwareTable`.
- **`deviceSoftwareTableQuery` / `deviceSoftwareTableFragment`** — GraphQL definitions: the query takes `machineId`, `search`, `first`, `after`; the fragment exposes a `@connection`-keyed `deviceSoftware` field with `filteredCount`, edges spreading `softwareTable_software`, and `pageInfo`.
- **`DeviceSoftwareTableProps`** — Props contract: `machineId`, `debouncedSearch`, `isPending` (guards stale empty states), `emptyState` (tab-specific empty copy), `onEmptyChange` callback, and `stickyHeaderOffset`.

## Usage Example

```typescript
import { DeviceSoftwareTable } from '@/app/(app)/devices/components/device-software-table';

function SoftwareTab({ machineId, stickyHeaderOffset }: { machineId: string; stickyHeaderOffset: string }) {
  const [search, setSearch] = useState('');
  const debouncedSearch = useDebouncedValue(search, 300);
  const [isEmpty, setIsEmpty] = useState(false);

  return (
    <DeviceSoftwareTable
      machineId={machineId}
      debouncedSearch={debouncedSearch}
      isPending={false}
      emptyState={<p>No software installed on this device.</p>}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset={stickyHeaderOffset}
    />
  );
}
```

Search queries are server-side (passed as a GraphQL variable), and scrolling further triggers `loadNext` through the pagination fragment's connection, appending additional pages of `SOFTWARE_LIST_PAGE_SIZE` rows.
