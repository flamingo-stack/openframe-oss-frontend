# device-software-table.tsx

Renders the Software tab on a device detail page: a paginated, searchable list of software installed on a specific machine, reusing the shared `SoftwareTable` component in a device-scoped context. Data is fetched via a Relay GraphQL query/fragment with cursor-based infinite scroll.

## Key Components

- **`DeviceSoftwareTable`** — Public entry point. Wraps the reader in a `LoadingSuspense` boundary so loading state is scoped to this tab.
- **`DeviceSoftwareTableReader`** — Checks `useLoadingScope()`; if the surrounding scope (device or feature flag) hasn't resolved, renders `SoftwareTable` in a skeleton/empty state without issuing a query. Otherwise delegates to `DeviceSoftwareTableQuery`.
- **`DeviceSoftwareTableQuery`** — Executes `deviceSoftwareTableQuery` via `useLazyLoadQuery`, then drives pagination with `usePaginationFragment` over `deviceSoftwareTable_query` (refetchable as `deviceSoftwareTablePaginationQuery`). Maps edges to rows and wires up `loadNext`/`hasNext`/`isLoadingNext` into `SoftwareTable`'s `infiniteScroll` prop.
- **`DeviceSoftwareTableProps`** — Props contract: `machineId`, `debouncedSearch`, `isPending`, `emptyState`, `onEmptyChange`, `stickyHeaderOffset`.

## Usage Example

```typescript
import { DeviceSoftwareTable } from '@/app/(app)/devices/components/device-software-table';

function DeviceSoftwareTab({ machineId }: { machineId: string }) {
  const [search, setSearch] = useState('');
  const [isEmpty, setIsEmpty] = useState(false);
  const debouncedSearch = useDebouncedValue(search, 300);

  return (
    <DeviceSoftwareTable
      machineId={machineId}
      debouncedSearch={debouncedSearch}
      isPending={false}
      emptyState={<p>No software installed on this device.</p>}
      onEmptyChange={setIsEmpty}
      stickyHeaderOffset="64px"
    />
  );
}
```

**Notes:**
- Search filtering is server-side; pass a debounced value to avoid refetch churn.
- `onEmptyChange` lets the parent tab hide its toolbar when the device truly has no software (distinct from a search yielding zero results).
- Pagination uses `SOFTWARE_LIST_PAGE_SIZE` (shared with the fleet-wide software list) for consistent page sizing.
