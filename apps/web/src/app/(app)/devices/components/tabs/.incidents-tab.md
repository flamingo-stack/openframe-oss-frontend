# incidents-tab.tsx

Renders the "Incidents" tab within a device detail view, displaying device-scoped incidents by filtering the Incidents page's data to the current machine's ID.

## Key Components

- **`IncidentsTab`** — React component that accepts a `device` prop and renders either an empty state or a filtered incidents table, depending on loading state and device data availability.
- **`IncidentsTabProps`** — Interface defining the `device: Device | null` prop.
- **`NO_INCIDENTS`** — A pre-built `TabEmptyState` element shown when there's no `machineId` to query incidents by.

## Behavior

- Uses `useLoadingScope()` to detect whether the parent device data is still loading. While loading, the component defers rendering the empty state (since the table itself handles its own loading UI).
- If loading has finished and the device has no `machineId`, it shows the `NO_INCIDENTS` empty state immediately — there's nothing to query incidents for.
- Otherwise, it renders `DeviceIncidentsTable` wrapped in a `ContentErrorBoundary`, keyed by `device?.machineId` so the table remounts with the correct filters once the real device ID resolves (avoiding a stale fetch with an empty ID).

## Usage Example

```typescript
import { IncidentsTab } from './incidents-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPanel({ device }: { device: Device | null }) {
  return (
    <div className="tab-panel">
      <IncidentsTab device={device} />
    </div>
  );
}
```

This component is typically rendered as one of several tabs managed by `useDeviceTabs`, which determines tab visibility based on device capabilities and state.
