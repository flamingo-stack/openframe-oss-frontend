# device-logs-tab.tsx

Renders the "Device Logs" tab within the device details page. It coordinates URL-driven log filters, a deferred/debounced log list (to avoid re-fetching on every keystroke), a toolbar for search/level/range controls, and a drawer for inspecting a selected log entry.

## Key Components

- **`DeviceLogsTab`** — Main component accepting a `device` prop (nullable while the parent page is still loading). Composes:
  - `DeviceLogsToolbar` — search, log-level filters, time range picker, auto-update toggle, and refresh control.
  - `DeviceLogsList` — rendered inside a `LoadingWhen` guard and a `ContentErrorBoundary`, keyed by the deferred list state so failed requests don't get silently remounted and retried.
  - `DeviceLogDrawer` — shows details for the currently selected log entry; only rendered once `device` is available.
- Uses `useDeviceLogFilters` (with `DEVICE_LOG_PARAM_SCHEMA`) to sync filter state to the URL, and `useDeferredLogList` to debounce list requests against live filter/anchor changes.
- Local state: `autoUpdate` (toggle for live refresh) and `selected` (currently open log entry in the drawer), both kept outside the list so they survive filter-driven remounts.

## Usage Example

```typescript
import { DeviceLogsTab } from './device-logs-tab';

function DeviceDetailsPage() {
  const device = useDevice(); // returns Device | null while loading

  return (
    <div>
      {/* Other tabs... */}
      <DeviceLogsTab device={device} />
    </div>
  );
}
```

**Notes:**
- `device` may be `null` while the parent page is in its own loading scope; the tab degrades gracefully, drawing the toolbar in a locked state and the list in a loading skeleton via `useLoadingScope`.
- The list's cache key (`list.key`) combines `machineId`, `anchor`, and the serialized `filter` object, ensuring a fresh list is fetched when any of these change, including explicit refresh calls.
- The drawer is intentionally kept above the list in the component tree so selecting an entry doesn't get reset when the list remounts due to filter changes.
