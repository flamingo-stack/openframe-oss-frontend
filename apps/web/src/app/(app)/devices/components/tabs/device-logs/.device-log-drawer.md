# device-log-drawer.tsx

A React client component that renders a slide-out drawer displaying the full details of a single device log entry, including timestamp, hostname, occurrence count, and a copy-to-clipboard action for the log message.

## Key Components

- **`DeviceLogDrawer`** — The main exported component. Renders a `LogDrawer` populated with the selected log entry's details (status tag, timestamp, info fields, device card) and a "Copy" button for the raw message. Passing `null` as `entry` closes the drawer.
- **`DeviceLogDrawerProps`** — Props interface:
  - `entry: DeviceLogEntry | null` — the log line to display; `null` closes the drawer.
  - `onClose: () => void` — callback invoked to close the drawer.
  - `deviceId?: string` — fallback device context for the drawer's device card when the log entry itself has no associated device.
- **`infoFields`** — Internal helper that builds the `LogDrawerInfoField[]` array (Received time, Agent Timestamp, Hostname, Occurrences) from a `DeviceLogEntry`, omitting fields that are absent.

## Usage Example

```typescript
import { useState } from 'react';
import { DeviceLogDrawer } from './device-log-drawer';
import type { DeviceLogEntry } from './device-log-row';

function LogsPage({ deviceId }: { deviceId?: string }) {
  const [selectedEntry, setSelectedEntry] = useState<DeviceLogEntry | null>(null);

  return (
    <>
      {/* ...log list that sets selectedEntry on row click... */}
      <DeviceLogDrawer
        entry={selectedEntry}
        onClose={() => setSelectedEntry(null)}
        deviceId={deviceId}
      />
    </>
  );
}
```

The drawer automatically closes when `entry` becomes `null`. The device card shown inside the drawer prefers the device referenced by `entry.machineId`, falling back to the `deviceId` prop when the entry itself doesn't specify one.
