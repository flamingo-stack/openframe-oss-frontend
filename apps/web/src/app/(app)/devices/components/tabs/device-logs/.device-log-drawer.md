# device-log-drawer.tsx

A client-side React component that renders a slide-out drawer showing the full details of a single device log entry, including its message, metadata, and associated device context. It is used on the Device Logs page to let users inspect and copy a log line.

## Key Components

- **`DeviceLogDrawer`** — The main exported component. Renders a `LogDrawer` populated with the selected log entry's description, status tag, timestamp, info fields, device card, and a copy-to-clipboard button.
- **`DeviceLogDrawerProps`** — Props interface: `entry` (the `DeviceLogEntry` to display, or `null` to keep the drawer closed), `onClose` (close handler), and optional `deviceId` (fallback device for the drawer's device card when the log entry itself has no associated device).
- **`infoFields(entry)`** — Internal helper that builds the list of `LogDrawerInfoField` items (Received timestamp, optional Agent Timestamp, Hostname, and Occurrences count) shown in the drawer.

## Usage Example

```typescript
import { useState } from 'react';
import { DeviceLogDrawer } from './device-log-drawer';
import type { DeviceLogEntry } from './device-log-row';

function DeviceLogsPage({ deviceId }: { deviceId: string }) {
  const [selectedEntry, setSelectedEntry] = useState<DeviceLogEntry | null>(null);

  return (
    <>
      {/* ... log list that sets selectedEntry on row click ... */}

      <DeviceLogDrawer
        entry={selectedEntry}
        onClose={() => setSelectedEntry(null)}
        deviceId={deviceId}
      />
    </>
  );
}
```

## Notes

- The drawer's device card follows precedence rules: a log entry naming its own `machineId` takes priority over the `deviceId` prop, which is useful for tenant-wide log lists versus device-scoped ones.
- The log message is rendered with `whitespace-pre-wrap` to preserve original line breaks.
- Copy functionality uses the shared `useCopyToClipboard` hook, swapping the button icon between `Copy02Icon` and `CheckIcon` to indicate success.
