## Purpose

Renders the Vulnerabilities tab on a device detail page, showing CVEs detected on that device. It feature-flag switches between a legacy Fleet-sourced view and the Software module's own `deviceVulnerabilities`-backed table, with pipeline-stage-aware empty states and sync status messaging.

## Key Components

- **`VulnerabilitiesTab`** — Public entry point. Checks the `software-management` feature flag via `useFeatureFlagGate`: when `off`, renders `FleetVulnerabilitiesTab`; otherwise renders `ModuleVulnerabilitiesTab` (passing a `loading` flag while the gate resolves).
- **`ModuleVulnerabilitiesTab`** — Internal component rendering the module's `SoftwareListFrame` with a `DeviceVulnerabilitiesTable`, wrapped in a `ContentErrorBoundary`. Shows a `DataSyncBanner` when a vulnerability scan is pending relative to the latest inventory.
- **`vulnerabilitiesEmptyState(device)`** — Maps the device's pipeline stage (`disconnected`, `collecting`, `scan-pending`, or none) to the appropriate empty-state UI, using `getVulnerabilitiesEmptyReason`.
- **`NO_VULNERABILITIES`** — Default empty state shown when no vulnerabilities exist and the pipeline has fully run.
- **`SEARCH_PLACEHOLDER`** — Placeholder text for the vulnerability search input.

## Usage Example

```typescript
import { VulnerabilitiesTab } from './vulnerabilities-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <div>
      {/* ...other tabs... */}
      <VulnerabilitiesTab device={device} />
    </div>
  );
}
```

The component requires no additional props beyond `device`; it internally resolves the `software-management` feature flag and the device's pipeline/sync state to decide what to render.
