A client-side React tab component that displays security vulnerabilities detected across a device's installed software, with search, sorting, and severity classification.

## Key Components

### Interfaces
- **`VulnerabilitiesTabProps`** — Accepts a nullable `Device` object
- **`VulnerabilityWithSoftware`** — Extends `Vulnerability` with flattened software context (`software_name`, `software_version`, `software_vendor`, `software_source`, `unique_key`)

### Utility Functions
- **`severityFromScore(score)`** — Maps a CVSS v3 numeric score to a `Severity` band (`critical` ≥ 9, `high` ≥ 7, `medium` ≥ 4, `low` otherwise)
- **`getSeverity(vuln)`** — Derives severity from `cvss_score` when present; falls back to a CVE publication year heuristic

### Constants
- **`SEVERITY_RANK`** — Numeric rank per severity level (used for sortable column values)
- **`SEVERITY_VARIANT`** — Maps severity to `Tag` component variant

### Component: `VulnerabilitiesTab`
- Flattens `device.software[].vulnerabilities` into a single array with software context
- Filters rows by CVE ID or software name via a search input
- Renders a `DataTable` with columns: CVE ID, Severity (with CVSS score), Software (name + version), Discovered (date + days ago), and an external link button
- Uses `useStickyToolbar` to keep the search bar visible on scroll
- Shows a `TabEmptyState` when device is null or no results exist

## Usage Example

```typescript
import { VulnerabilitiesTab } from './vulnerabilities-tab';
import type { Device } from '../../types/device.types';

function DeviceDetail({ device }: { device: Device | null }) {
  return <VulnerabilitiesTab device={device} />;
}
```
