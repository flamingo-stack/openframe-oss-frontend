A lightweight wrapper around the shared `EmptyState` component used to render consistent empty-state UI within device detail tabs, plus a specialized variant for devices whose agent is still deploying.

## Key Components

- **`TabEmptyState`** — Generic empty-state component for tab content. Wraps the app-wide `EmptyState` so messaging is vertically centered like list pages. Accepts `icon`, `title`, `description`, and optional `buttonLabel`/`onButtonClick` for an action button (e.g., a Retry button for fleet-error states).
- **`TabDeployingEmptyState`** — Convenience wrapper around `TabEmptyState` for tabs showing no data because the agent hasn't finished deploying yet. Takes `icon` and `section` (the tab's name), and auto-generates consistent title/description copy.

## Usage Example

```typescript
import { TabEmptyState, TabDeployingEmptyState } from '@/app/components/.../tab-empty-state';
import { AlertIcon, NetworkIcon } from '@/app/components/icons';

// Generic empty state with retry action
function FleetErrorTab() {
  return (
    <TabEmptyState
      icon={<AlertIcon />}
      title="Unable to load fleet data"
      description="There was an error fetching data from the fleet service."
      buttonLabel="Retry"
      onButtonClick={() => refetchFleetData()}
    />
  );
}

// Deploying state shared across tabs
function NetworkTab({ isDeploying }: { isDeploying: boolean }) {
  if (isDeploying) {
    return <TabDeployingEmptyState icon={<NetworkIcon />} section="Network" />;
  }
  return <NetworkContent />;
}
```

## Notes

- Icons should match the corresponding tab icon defined in `device-tabs.tsx` for visual consistency.
- `TabDeployingEmptyState` enforces identical copy across all tabs, only varying the `section` label and `icon`.
