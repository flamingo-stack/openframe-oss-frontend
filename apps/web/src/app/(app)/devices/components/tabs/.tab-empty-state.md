Renders a consistent empty state for device detail tabs, wrapping the shared `NoData` component with standardized padding so content tabs (hardware, network, OS, etc.) are visually identical to empty data tables.

## Key Components

- **`TabEmptyState`** — Functional component that accepts an icon, title, and description, and renders a full-width `NoData` block with uniform vertical padding via CSS spacing tokens.

## Usage Example

```typescript
import { TabEmptyState } from './tab-empty-state';
import { HardwareIcon } from './device-tabs';

function HardwareTab() {
  return (
    <TabEmptyState
      icon={<HardwareIcon />}
      title="No hardware data"
      description="Hardware information has not been collected for this device."
    />
  );
}
```

## Notes

- The icon should come from the corresponding tab definition in `device-tabs.tsx` to ensure the empty state visually matches its tab.
- Spacing is driven by CSS custom properties (`--spacing-system-xsf`, `--spacing-system-xxl`) for design-system consistency.
- Depends on `NoData` from `@flamingo-stack/openframe-frontend-core`.
