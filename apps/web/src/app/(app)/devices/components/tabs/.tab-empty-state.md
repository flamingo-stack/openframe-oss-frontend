A React component module providing standardized empty-state UI for device detail tabs, ensuring consistent vertical centering and styling with other list pages (devices, customers, etc.).

## Key Components

- **`TabEmptyState`** — Generic wrapper around the shared `EmptyState` component. Accepts an icon, title, description, and optional button label/click handler (useful for actions like "Retry" on error states).
- **`TabDeployingEmptyState`** — Specialized variant of `TabEmptyState` for tabs whose data is unavailable because the device agent is still deploying (not because data is genuinely absent). Takes an `icon` and a `section` name, and auto-generates consistent title/description copy.

## Usage Example

```typescript
import { TabEmptyState, TabDeployingEmptyState } from './tab-empty-state';
import { AlertIcon, ClockIcon } from '@/app/components/icons';

// Generic empty state with retry action
function FleetErrorTab() {
  return (
    <TabEmptyState
      icon={<AlertIcon />}
      title="Unable to load fleet data"
      description="Something went wrong while fetching this information."
      buttonLabel="Retry"
      onButtonClick={() => refetchFleetData()}
    />
  );
}

// Deploying state shared across data tabs
function SoftwareTab() {
  const isDeploying = useAgentDeployingStatus();

  if (isDeploying) {
    return <TabDeployingEmptyState icon={<ClockIcon />} section="Software" />;
  }

  return <SoftwareList />;
}
```

## Notes

- Both components rely on the shared `EmptyState` component (`@/app/components/shared/empty-state`) to keep empty-state layout consistent across the app.
- Use `TabDeployingEmptyState` specifically when the absence of data is due to an agent still connecting/deploying, rather than a true empty or error state — this keeps messaging accurate and consistent across all device detail tabs.
