# agents-tab.tsx

React client component that renders the "Agent Versions" tab on a device detail page, displaying one `InfoCard` per installed agent, active tool connection, or expected-but-not-yet-reporting agent, with loading skeletons and an empty state.

## Key Components

- **`AgentsTab`** — Main exported component. Accepts a `device` prop, shows skeleton loading cards via `useLoadingScope`, renders a `TabEmptyState` when no agents exist, or renders the combined agent cards grid.
- **`combineAgents(device)`** — Merges `installedAgents`, `toolConnections`, and platform-expected agent types (via `getExpectedAgentTypes`) into a single deduplicated, alphabetically sorted list of `CombinedAgent` objects, including placeholder entries for agents not yet reporting.
- **`agentCardData(agent)`** — Builds the `InfoCardData` (rows + footer) for a single agent, showing Agent/Status/Last Seen/ID/Version/Updated rows conditionally based on agent type and available data.
- **`AgentCards`** — Layout wrapper rendering the section heading and responsive grid shared by both loading and loaded states.
- **`agentTypeToToolType`** — Maps internal agent type strings (for example `fleetmdm-agent`) to tool type enums (for example `FLEET_MDM`).
- **`AGENT_CARD_SKELETONS`** — Precomputed skeleton row/footer configs per known agent type, used while loading.
- **`getAgentDisplayStatus`** / **`formatTimestamp`** / **`formatRelative`** — Helpers for deriving status and formatting dates per agent type.

## Usage Example

```typescript
import { AgentsTab } from './agents-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPage({ device }: { device: Device }) {
  return (
    <div>
      {/* Renders installed agents, active tool connections, and pending agent slots */}
      <AgentsTab device={device} />
    </div>
  );
}
```

The component requires no additional configuration—pass a `Device` object containing `installedAgents` and `toolConnections` arrays, and it handles merging, sorting, status resolution, and loading/empty states internally.
