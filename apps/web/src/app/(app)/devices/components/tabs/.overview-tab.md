Renders the Overview tab for a device detail page, combining the device summary, tags, and a device-scoped logs table with automatic refresh support via URL search params.

## Key Components

### `OverviewTab`
Main exported component that composes three sections:
- **`DeviceInfoSection`** — displays the device summary/info grid
- **`DeviceTagsSection`** — displays tags associated with the device
- **`LogsTable`** — renders filtered logs for the device (header suppressed via `showHeader={false}`)

### Refresh Behavior
Watches the `refresh` URL search parameter (e.g. set after a script runs) and calls `logsTableRef.current?.refresh()` with a 100ms debounce to re-fetch logs without a full page reload.

### `OverviewTabProps`
```typescript
interface OverviewTabProps {
  device: Device;
}
```

## Usage Example

```typescript
import { OverviewTab } from './overview-tab';

// Inside a device detail page or tab switcher:
<OverviewTab device={device} />

// To trigger a log refresh after a script runs, navigate to:
// /devices/[id]?refresh=<timestamp>
// The tab detects the param change and calls logsTable.refresh() automatically.
```

## Notes

- Uses `device.machineId` as the primary log filter key, falling back to `device.id`
- The `LogsTable` is only rendered when a valid `deviceId` is resolved
- The component is a `'use client'` boundary; it relies on `useSearchParams` from Next.js App Router
