# overview-tab.tsx

Client-side React component rendering the "Overview" tab for a device detail page. It displays device summary information, associated tags, and a device-scoped logs table, with automatic log refreshing triggered via a URL query parameter.

## Key Components

- **`OverviewTabProps`** — Interface defining the component's props; accepts a `device` of type `Device | null` (null while loading).
- **`OverviewTab`** — Main exported component that composes `DeviceInfoSection`, `DeviceTagsSection`, and a device-scoped `LogsTable`.

### Behavior Details
- Uses `useSearchParams` to detect a `refresh` query parameter and triggers `logsTableRef.current.refresh()` after a short delay when it changes (e.g., after a script execution elsewhere in the app).
- Derives `deviceId` preferring `device.machineId`, falling back to `device.id`, used to scope the logs table to the current device.
- Passes `showHeader={false}` to `LogsTable` since the page itself already provides header/page context.

## Usage Example

```typescript
import { OverviewTab } from './overview-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <div>
      {/* Rendered within a tabbed device detail layout */}
      <OverviewTab device={device} />
    </div>
  );
}
```

When navigating to a URL like `/devices/123?tab=overview&refresh=1`, the component automatically detects the `refresh` param change and reloads the logs table without requiring a full device refetch.

## Dependencies

- `next/navigation` — for reading URL search params.
- `react` — `useEffect`, `useRef` for lifecycle and imperative table refresh.
- `LogsTable` from `@/app/(app)/logs-page/components/logs-table` — displays device-scoped log entries.
- `DeviceInfoSection` and `DeviceTagsSection` — sibling components rendering device metadata and tags.
