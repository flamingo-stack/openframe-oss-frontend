# overview-tab.tsx

A client-side React component that renders the **Overview** tab for a device detail page, displaying the device's summary info, tags, and a scoped logs table with auto-refresh support.

## Key Components

- **`OverviewTabProps`** — Interface defining the `device: Device | null` prop (nullable while the parent page is loading).
- **`OverviewTab`** — Main component that:
  - Resolves the device identifier (`machineId` preferred, falling back to `id`) for filtering logs.
  - Watches the `refresh` URL search param via `useSearchParams` and triggers a debounced (`100ms`) logs table refresh when it changes — useful after actions like running a script against the device.
  - Renders `DeviceInfoSection`, `DeviceTagsSection`, and a device-scoped `LogsTable` (with `showHeader={false}` since the page already supplies context).
  - Uses a `logsTableRef` (`LogsTableRef`) to imperatively call `refresh()` on the logs table.

## Usage Example

```typescript
import { OverviewTab } from './overview-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <div>
      {/* Other tab navigation UI */}
      <OverviewTab device={device} />
    </div>
  );
}
```

To trigger a refresh of the logs table from elsewhere (e.g., after a script run), navigate with an updated `refresh` query parameter:

```typescript
router.push(`/devices/${deviceId}?refresh=${Date.now()}`);
```

This component expects to be rendered within a route that supplies `useSearchParams` context (i.e., inside the Next.js App Router) and relies on sibling components `DeviceInfoSection`, `DeviceTagsSection`, and `LogsTable` for actual content rendering.
