# software-tab.tsx

Renders the Software tab on a device's detail page, switching between a built-in Fleet-sourced software table and the full Software module's table based on the `software-management` feature flag, with pipeline-stage-aware empty states.

## Key Components

- **`SoftwareTab(props)`** — Exported entry point. Reads the `software-management` feature flag gate via `useFeatureFlagGate`. When the flag is `off`, renders `FleetSoftwareTab` (data already on the device payload). Otherwise renders `ModuleSoftwareTab`, passing a `loading` flag while the gate is resolving to avoid flashing the wrong UI.
- **`ModuleSoftwareTab({ device, loading })`** — Internal component wrapping `SoftwareListFrame` (shared search/filter/pagination frame) and `DeviceSoftwareTable`, scoped to the device's `machineId`. Wraps the table in `ContentErrorBoundary` so a failed `deviceSoftware` query doesn't crash the page. Shows `NO_SOFTWARE` immediately if there's no `machineId` and nothing is loading.
- **`softwareEmptyState(device)`** — Derives the correct empty-state message by reusing `getVulnerabilitiesEmptyReason` (same decision table as the Vulnerabilities tab): `'disconnected'` → Fleet-not-connected message; `'collecting'` → either a deploying state (`sources.fleet === 'skipped-pending'`) or a "collecting inventory" state; otherwise falls back to `NO_SOFTWARE`.
- **`NO_SOFTWARE`** — Shared `TabEmptyState` constant for the generic "no software found" case.
- **`SEARCH_PLACEHOLDER`** — Search input placeholder text ("Search for Software").

## Usage Example

```typescript
import { SoftwareTab } from './software-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPanel({ device }: { device: Device | null }) {
  return (
    <div className="device-tabs">
      {/* other tabs... */}
      <SoftwareTab device={device} />
    </div>
  );
}
```

The component requires no additional configuration — it self-selects its rendering path based on the `software-management` feature flag and the device's connection/inventory state, falling back gracefully when `device` is `null` or software data hasn't arrived yet.
