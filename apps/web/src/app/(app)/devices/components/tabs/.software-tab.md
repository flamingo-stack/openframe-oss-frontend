Renders an interactive, searchable data table of all software installed on a device, including version, source type, vulnerability count, file path, and last-used time.

## Key Components

### `SoftwareTab`
Main exported component. Accepts a `device` prop and renders a filterable `DataTable` with five columns:

| Column | Description |
|---|---|
| **SOFTWARE** | Name + version |
| **SOURCE** | Icon + label mapped from source key (e.g., `apps`, `homebrew_packages`) |
| **VULNERABILITIES** | Success/error `Tag` badge based on count |
| **FILE PATH** | First installed path via `TruncateText` |
| **LAST USED** | Relative timestamp via `formatRelativeTime` |

### `SOURCE_ICON`
Static lookup map translating raw source strings (`apps`, `chrome_extensions`, `vscode_extensions`, `homebrew_packages`, `python_packages`) to icon components and human-readable labels. Falls back to `PackageIcon` + raw source string for unknown types.

### `getSourceIcon(source)`
Helper resolving a source string to its `{ Icon, label }` pair from `SOURCE_ICON`.

### `formatLastUsed(dateString?)`
Formats an ISO date string to a relative time label (e.g., "3 days ago") or `—` when absent or invalid.

### `useStickyToolbar`
Custom hook providing `toolbarRef`, `containerStyle`, and `stickyHeaderOffset` for coordinating sticky search bar and sticky table header offsets.

## Usage Example

```typescript
import { SoftwareTab } from './software-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPage({ device }: { device: Device }) {
  return (
    <SoftwareTab device={device} />
  );
}
```

**Empty / null states:**
- `device` is `null` → renders a centered `TabEmptyState`.
- `device.software` is empty → same empty state.
- Active search with no matches → inline empty state inside the table with the search query echoed back.
