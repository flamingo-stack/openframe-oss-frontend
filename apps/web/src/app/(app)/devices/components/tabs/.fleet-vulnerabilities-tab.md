# fleet-vulnerabilities-tab.tsx

Renders the Vulnerabilities tab for a device using Fleet's native host payload (used when the `software-management` module is disabled). It flattens CVEs from `device.software[].vulnerabilities` into a searchable, sortable client-side table.

## Key Components

- **`FleetVulnerabilitiesTab`** — Main exported component. Accepts a `device` prop, flattens all vulnerabilities across software entries, supports search/sort, and renders either a loading skeleton, an empty state, or the populated `DataTable`.
- **`FLEET_VULNERABILITY_COLUMNS`** — Column layout config (CVE, SEVERITY, SOFTWARE, DISCOVERED, open-details) with responsive width/visibility rules; SOFTWARE and DISCOVERED hide below `md`, with SOFTWARE folded into the CVE cell on mobile.
- **`VulnerabilityWithSoftware`** — Type extending `Vulnerability` with flattened software context (`software_name`, `software_version`, `software_vendor`, `software_source`, `unique_key`).
- **`SeverityCell`**, **`SoftwareCell`**, **`DiscoveredCell`**, **`OpenDetailsButton`** — Cell renderers, each aware of `useLoadingScope()` to draw skeleton placeholders when loading.
- **`severityOf`** — Resolves CVE severity band purely from `cvss_score` (returns `null` when unrated, no guessing).
- **`softwareLabel`** — Formats the package name/version string folded into the CVE cell on mobile viewports.
- **`vulnerabilityRowId`** — Row-id accessor using `unique_key`, falling back to `id` for placeholder rows.

## Usage Example

```typescript
import { FleetVulnerabilitiesTab } from './fleet-vulnerabilities-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailsPage({ device }: { device: Device | null }) {
  return (
    <section>
      <h2>Vulnerabilities</h2>
      <FleetVulnerabilitiesTab device={device} />
    </section>
  );
}
```

This component is typically rendered conditionally alongside the module-based `VulnerabilitiesTab`, depending on whether the `software-management` feature module is enabled for the tenant/device.
