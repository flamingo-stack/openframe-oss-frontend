## FleetVulnerabilitiesTab

Client component that renders the Vulnerabilities tab for a device using Fleet's native host payload, used when the `software-management` module is disabled. It flattens CVEs from `device.software[].vulnerabilities` into a searchable, sortable client-side table, with a responsive layout that folds the software/package name into the CVE cell on mobile viewports (below `md`).

## Key Components

- **`FleetVulnerabilitiesTab`** — main exported component; accepts a `device` prop, flattens vulnerabilities, manages search/sort state, and renders a `DataTable` with loading, empty, and deploying states.
- **`FLEET_VULNERABILITY_COLUMNS`** — column layout config (CVE, SEVERITY, SOFTWARE, DISCOVERED, open-details) with responsive width/visibility rules.
- **`VulnerabilityWithSoftware`** — type combining a `Vulnerability` with its owning software's name/version/vendor/source and a `unique_key` for React keys.
- **`SeverityCell`**, **`SoftwareCell`**, **`DiscoveredCell`**, **`OpenDetailsButton`** — per-cell renderers, each aware of the shared loading scope (`useLoadingScope`) to show skeletons vs. real content.
- **`severityOf`** — resolves CVE severity band from `cvss_score` (null if unrated, never guessed).
- **`softwareLabel`** — formats the "name · version" string folded into the CVE cell on mobile.

## Usage Example

```typescript
import { FleetVulnerabilitiesTab } from './fleet-vulnerabilities-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPanel({ device }: { device: Device | null }) {
  return (
    <div>
      <FleetVulnerabilitiesTab device={device} />
    </div>
  );
}
```

This component is typically rendered conditionally alongside `VulnerabilitiesTab` based on whether the `software-management` module is enabled, as both share the same tab slot in the device details view.
