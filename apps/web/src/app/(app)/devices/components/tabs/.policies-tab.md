# policies-tab.tsx

A React client component that renders a searchable table of compliance policies applied to a specific device, mapping each policy's pass/fail status to a styled badge and linking to detailed policy views.

## Key Components

- **`PoliciesTab`** — Main component accepting a `device` prop; renders search input and `PoliciesTable`, handling loading and empty states.
- **`toStatus()`** — Maps a `DevicePolicy['response']` value (`'pass'` / `'fail'` / other) to a `PolicyTableRow['status']` object with a label and visual variant (`success`, `error`, `warning`).
- **`parsePlatforms()`** — Converts a comma-separated platform string into a trimmed, filtered array of platform names.
- **`PoliciesTabProps`** — Props interface: `{ device: Device | null }`.

## Behavior Notes

- Uses `useLoadingScope` to coordinate loading state across the search input and table.
- Uses `useStickyToolbar` to keep the search bar sticky while scrolling, aligned with the table's sticky header.
- Filters policies client-side by name/description against the search query (case-insensitive).
- Three distinct empty states:
  - No `device` loaded → generic empty state.
  - Device loaded but zero policies → plain empty state (rich onboarding lives on the Monitoring page).
  - Search yields zero matches → table chrome stays visible with a contextual empty message.
- The search bar is hidden entirely when the table has no rows and no active search, so only the centered empty state is shown.
- Each row links to `routes.monitoring.policy(policy.id)` and includes a "Policy Details" row action.

## Usage Example

```typescript
import { PoliciesTab } from './policies-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPanel({ device }: { device: Device | null }) {
  return (
    <section>
      <h2>Compliance</h2>
      <PoliciesTab device={device} />
    </section>
  );
}
```

Typically rendered as one tab within a device detail view, alongside other tabs (e.g., monitoring, software) that share the same `Device` data shape.
