# PoliciesTab

Client-side React component that renders a searchable, sticky-header table of compliance policies applied to a device, mapping each policy's pass/fail state to a status badge and linking rows to the policy details page.

## Key Components

- **`PoliciesTab`** — Main component accepting a `device` prop (or `null`). Handles three states: device not loaded, no policies at all, and populated/filtered policy list.
- **`toStatus(response)`** — Maps a `DevicePolicy['response']` value (`'pass'` / `'fail'` / other) to a `PolicyTableRow['status']` badge (`Compliant`/success, `Failing`/error, `Pending`/warning).
- **`parsePlatforms(platform)`** — Splits a comma-separated platform string into a trimmed, non-empty array of platform names.
- **`PoliciesTabProps`** — Props interface: `{ device: Device | null }`.

## Behavior

- Uses `useLoadingScope` to detect in-flight data loading and defer empty-state rendering until the device payload resolves.
- Uses `useStickyToolbar` to keep the search input pinned while scrolling, matching the table's sticky header offset.
- Filters policies client-side by name or description against the search query (case-insensitive).
- Builds `PolicyTableRow[]` with an `actions` entry that navigates to `routes.monitoring.policy(policy.id)` and sets `rowAsLink` so the whole row is clickable.
- Shows distinct `TabEmptyState` messaging for "device missing" vs. "no policies configured", while a zero-match search keeps the table chrome with a compact inline empty state.
- Hides the search input entirely when there are no rows and no active search term, to avoid showing search UI over an empty centered state.

## Usage Example

```typescript
import { PoliciesTab } from './policies-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPolicies({ device }: { device: Device | null }) {
  return (
    <section>
      <PoliciesTab device={device} />
    </section>
  );
}
```

Typically rendered as a tab panel within a device details view, alongside other device-related tabs (e.g., overview, software, scripts).
