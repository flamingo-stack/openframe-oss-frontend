# device-logs-toolbar.tsx

A presentational toolbar component for the device logs view that combines search, auto-update toggle, log level filtering, time range selection, and manual refresh controls into a single responsive layout.

## Key Components

- **`DeviceLogsToolbarProps`** — Interface defining all controlled props for search text, log level selection, time range (including custom ranges), auto-update state, refresh handling, and an optional `disabled` state for loading scenarios.
- **`DeviceLogsToolbar`** — The main exported component. Renders:
  - An `Input` for search with inline error messaging via `searchError`.
  - A `CheckboxBlock` toggle for enabling/disabling auto-update.
  - `DeviceLogLevelChips` for multi-select log level filtering.
  - `DeviceLogRangeSelect` for choosing predefined or custom date ranges, bounded by `pickerBounds`.
  - A refresh `Button` with a loading-aware disabled state.

This component is intentionally kept outside any `Suspense` boundary wrapping the log list, ensuring the search input retains focus while log data streams in or reloads.

## Usage Example

```typescript
<DeviceLogsToolbar
  search={search}
  onSearchChange={setSearch}
  searchError={searchError}
  selectedLevels={selectedLevels}
  onToggleLevel={toggleLevel}
  range={range}
  onRangeChange={setRange}
  customRange={customRange}
  onCustomRangeChange={setCustomRange}
  pickerBounds={{ fromDate: minDate, toDate: maxDate }}
  autoUpdate={autoUpdate}
  onAutoUpdateChange={setAutoUpdate}
  onRefresh={handleRefresh}
  isRefreshing={isFetching}
  disabled={isDeviceLoading}
/>
```

Typically used at the top of a device logs page, with the component itself remaining mounted while the underlying log list (wrapped in `Suspense`) re-renders based on filter changes.
