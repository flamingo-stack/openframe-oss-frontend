# tickets-tab.tsx

Renders the device detail page's "Tickets" tab, showing a searchable, paginated, and sortable table of tickets associated with a specific device, scoped server-side by `machineId`.

## Key Components

- **`TicketsTab`** — React component that accepts a `device` prop and renders a live-updating table of the device's tickets, with search, pagination, and empty/error states.
- **`TicketsTabProps`** — Interface defining the component's props (`device: Device | null`).
- **Column configuration** — Reuses shared ticket table columns (`getTicketTableColumns`) but strips the redundant `source` column and pins `ASSIGNEE`/`STATUS` to fixed widths from `DEVICE_TICKET_COLUMNS`, appending a trailing open-in-new-tab action column (`getTicketOpenColumn`).
- **Loading/empty-state logic** — Distinguishes between "still loading" (device or first page pending), "genuinely empty" (no tickets at all, no search), and "empty search results" (search active, zero matches), rendering the appropriate UI for each case.

## Usage Example

```typescript
import { TicketsTab } from './tickets-tab';
import type { Device } from '../../types/device.types';

function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <div className="device-tabs">
      <TicketsTab device={device} />
    </div>
  );
}
```

### Behavior Notes

- Tickets are filtered server-side using `TicketFilterInput.deviceIds`, keyed on `device.machineId` — the same id stored on `Ticket.deviceId`. If a device is unlinked from a ticket, it no longer appears in this list (no client-side fallback matching).
- Search input is debounced (300ms) via `useDebounce` before triggering a new query.
- A sticky toolbar (via `useStickyToolbar`) keeps the search bar pinned while scrolling.
- While loading, placeholder rows (`loadingPlaceholderRows`) populate the table so cells can render their own skeleton/loading state.
- Three distinct empty states are supported: initial loading, no tickets at all (plain icon/title/description), and zero search matches (compact empty state within table chrome).
