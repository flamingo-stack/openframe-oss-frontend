Renders the Tickets tab on a device detail page, displaying the support tickets of a specific device, filtered on the server by its machine id.

## Key Components

- **`TicketsTab`** — Main exported component; accepts a `Device` prop and renders a searchable, infinitely-scrollable ticket table scoped to that device

## Usage Example

```typescript
import { TicketsTab } from './tickets-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  id: 'abc123',
  machineId: 'machine-xyz',
  // ...other fields
};

<TicketsTab device={device} />
```

## Notes

- **Server-side device scope**: the tickets query is filtered by `deviceIds: [machineId]`; a ticket whose device was unlinked is no longer the device's.
- The `source` column is stripped from the shared ticket table columns since it's redundant in a device-scoped context.
- Column widths for `assignee` (`w-[280px]`) and `status` (`w-[160px]`) are pinned so the table keeps one layout; while the device (or the first page) is read the same table holds one full page (`TICKETS_PAGE_SIZE`) of placeholder rows (`loadingPlaceholderRows`) drawn with its real cells (`loadingCells`), each cell in its own loading form; the infinite footer draws the same page.
- Shows `TicketsEmptyState` when no tickets exist; shows the inline empty state when a search yields no results.
