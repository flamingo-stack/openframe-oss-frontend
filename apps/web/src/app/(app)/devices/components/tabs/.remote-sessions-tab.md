## Remote Sessions Tab

Renders the "Remote Sessions" tab on a device's detail page, showing a searchable, filterable, sortable table of recorded remote sessions with live-update support and delete functionality.

## Key Components

- **`RemoteSessionsTab`** — Main component; renders a `DataTable` of `RecordingSummary` rows for a given `Device`, backed by `useSessionRecordings` (polled when live rows are active) and `useLoadingScope` to gate requests until the device resolves.
- **`emptyDescription`** — Pure helper that returns the appropriate empty-state message based on active search, date range, or column filters.
- **`MODAL_FILTER_IDS`** — Column IDs (`employee`, `expires`) mirrored by the mobile `FilterModal`.
- **`DEFAULT_SORTING`** / **`REMOTE_SESSIONS_SKELETON_ROWS`** — Default sort (newest session first) and skeleton row count used while loading.

Internally it wires together:
- Debounced client-side search/filtering over `startedAt`, employee name/role.
- Date range filtering via `dateRangeToInstantBounds`, synced with the SESSION column's calendar sort popover.
- Column filter bridging between TanStack's `ColumnFiltersState` and the mobile `FilterModal`'s `Record<string, string[]>` shape.
- Row navigation to a session's recording via `sessionHref`, and row deletion via `DeleteSessionDialog` / `useDeleteRemoteSession`.
- Live-row highlighting/polling via `useLiveRows` and `liveSessionRowClass`.

## Usage Example

```typescript
import { RemoteSessionsTab } from '@/app/components/device/remote-sessions-tab';

function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <div className="device-tabs">
      <RemoteSessionsTab device={device} />
    </div>
  );
}
```

The component requires no additional props beyond `device`; it internally resolves `device.machineId` to fetch session recordings, and gracefully renders a `TabEmptyState` when there is no device or no recorded sessions.
