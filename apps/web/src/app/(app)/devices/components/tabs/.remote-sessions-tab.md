## Remote Sessions Tab

Renders the "Remote Sessions" tab on a device detail page: a filterable, sortable, live-updating table of recorded remote sessions (`RecordingSummary`) for a given device, with search, date-range filtering, column filters (Employee/Expires), row navigation to session playback, and session deletion.

## Key Components

- **`RemoteSessionsTab`** — Main component. Accepts a `device: Device | null` prop, resolves the device's `machineId`, fetches session recordings (with polling when "live rows" are active), and renders a `DataTable` with toolbar (search, date filter, mobile `FilterModal`), empty states, and a `DeleteSessionDialog`.
- **`emptyDescription`** — Pure helper that picks the empty-state message based on active search/date-range/column-filter narrowing.
- **`RemoteSessionsTabProps`** — Props interface (`{ device: Device | null }`).
- **Constants**: `REMOTE_SESSIONS_SKELETON_ROWS` (loading placeholder row count), `DEFAULT_SORTING` (newest session first), `MODAL_FILTER_IDS` (columns mirrored in the mobile filter modal).

Internally it composes several hooks/utilities: `useSessionRecordings`, `useDeleteRemoteSession`, `useLiveRows`, `useNow`, `useStickyToolbar`, `useDataTable`, `useDebounce`, and `useLoadingScope`, plus column definitions from `remoteSessionColumns`/`REMOTE_SESSION_COLUMNS`.

## Usage Example

```typescript
import { RemoteSessionsTab } from '@/app/components/device/remote-sessions-tab';

function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <section>
      <RemoteSessionsTab device={device} />
    </section>
  );
}
```

Typical behavior:
- Pass `device={null}` while the parent device query loads — the tab defers fetching recordings (`useLoadingScope`) and shows placeholder rows.
- Once `device` resolves, sessions load; rows for in-progress ("live") sessions are visually distinguished and the list polls automatically.
- Clicking a row navigates via `sessionHref(row, liveRows)`; clicking delete opens `DeleteSessionDialog` with the selected `RecordingSummary` as `deleteTarget`.
