# data-sync-banner.tsx

A React component that renders a neutral, non-alarming banner indicating background data synchronization is in progress on device-detail tabs.

## Key Components

- **`DataSyncBanner`** — Functional component that displays a grey informational strip with a pulsing loading icon and a message about in-progress data sync. It accepts standard `HTMLAttributes<HTMLDivElement>` props (including `className`) for flexible composition and styling overrides.

### Design Notes
- Uses the same layout geometry as the `WarningBlock` banner for visual consistency, but intentionally styled neutral/grey (via `bg-ods-bg-hover` / `text-ods-text-secondary`) rather than a warning color — the displayed data is real, just potentially stale during sync.
- The `Loading01Icon` is animated with `LIVE_PULSE_CLASS` to represent an active, live sync process rather than a generic loading spinner.
- Intended to be optional and conditionally rendered by callers (e.g., tagged with `data-loading-optional`) since only some devices are mid-sync at any time.
- Should be placed before the list of rows/data it qualifies, since it establishes context for the content that follows.

## Usage Example

```typescript
import { DataSyncBanner } from './data-sync-banner';

function DeviceDetailTab({ isSyncing, devices }: { isSyncing: boolean; devices: Device[] }) {
  return (
    <div className="flex flex-col gap-4">
      {isSyncing && (
        <DataSyncBanner data-loading-optional className="mb-2" />
      )}
      <DeviceTable devices={devices} />
    </div>
  );
}
```

Pass additional `div` attributes (e.g., `id`, `data-*` attributes, event handlers) as needed since the component spreads all received props onto its root element.
