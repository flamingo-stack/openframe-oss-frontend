# data-sync-banner.tsx

A neutral informational banner component that signals an in-progress background data sync on device-detail tabs. Unlike a warning banner, it uses grey/neutral styling because the displayed data is valid — it may just be temporarily stale while a sync completes in the background.

## Key Components

- **`DataSyncBanner`** — React functional component that renders a horizontal strip with a pulsing loading icon and explanatory text. Accepts standard `HTMLAttributes<HTMLDivElement>` props (including `className`) which are spread onto the root `div`, allowing callers to extend or override styling.
- Uses `Loading01Icon` combined with `LIVE_PULSE_CLASS` to convey an active, live sync state (not a generic loading spinner).
- Shares the same visual geometry/spacing as the related `WarningBlock` component for layout consistency, but intentionally differs in color semantics (grey vs. warning colors).

## Usage Example

```typescript
import { DataSyncBanner } from './data-sync-banner';

function DeviceDetailTab({ isSyncing, devices }: { isSyncing: boolean; devices: Device[] }) {
  return (
    <div>
      {isSyncing && (
        <DataSyncBanner
          data-loading-optional
          className="mb-4"
        />
      )}
      <DeviceList devices={devices} />
    </div>
  );
}
```

**Notes:**
- The component is optional and should only render when the caller determines a sync is actually in flight, typically marked with a `data-loading-optional` attribute for consumers/tests to identify it as conditional.
- Place it at the top of the list or section it describes, since it should be read before the (potentially stale) rows it qualifies.
