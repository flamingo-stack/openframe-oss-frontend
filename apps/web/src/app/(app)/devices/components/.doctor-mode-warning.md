# doctor-mode-warning.tsx

Client-side React component that displays a warning message with a copyable diagnostic command to help users troubleshoot devices stuck in pending state or agents that failed to install correctly.

## Key Components

- **`DoctorModeWarningProps`** — Interface defining the component's props, requiring a `platform` of type `OSPlatformId`.
- **`DoctorModeWarning`** — Default-exported functional component that renders a `WarningBlock` containing instructional text and a platform-specific "doctor" command (sourced from `OPENFRAME_DOCTOR_COMMANDS`) that users can copy to their clipboard via `PathsDisplay`.

## Usage Example

```typescript
import { DoctorModeWarning } from '@/components/doctor-mode-warning';

function DeviceTroubleshootingPanel({ platform }: { platform: 'macos' | 'windows' | 'linux' }) {
  return (
    <div className="troubleshooting-section">
      <DoctorModeWarning platform={platform} />
    </div>
  );
}
```

### Behavior

- Looks up the correct diagnostic command for the given `platform` from `OPENFRAME_DOCTOR_COMMANDS`.
- Renders the command inside a `PathsDisplay` component, which provides a copy-to-clipboard affordance.
- Uses the `useCopyToClipboard` hook (from `@/app/hooks/use-copy-to-clipboard`) to handle copy actions and surface success/error toast notifications.
- The `copyCommand` callback is memoized with `useCallback` to avoid unnecessary re-renders of child components.

## Notes

- Requires the `'use client'` directive since it relies on client-side hooks (`useCallback`, clipboard interaction).
- Depends on shared UI primitives (`WarningBlock`, `PathsDisplay`) and constants (`OPENFRAME_DOCTOR_COMMANDS`) from `@flamingo-stack/openframe-frontend-core`.
