# doctor-mode-warning.tsx

A React client component that displays a platform-specific warning block instructing users to run a "doctor" diagnostic command when an agent device fails to appear or gets stuck in a pending state.

## Key Components

- **`DoctorModeWarning`** — Default-exported functional component that renders a `WarningBlock` containing troubleshooting guidance and a copyable diagnostic command.
- **`DoctorModeWarningProps`** — Props interface requiring a `platform` of type `OSPlatformId` to select the correct doctor command.
- Relies on shared UI primitives `WarningBlock` and `PathsDisplay`, and the `OPENFRAME_DOCTOR_COMMANDS` lookup map from `@flamingo-stack/openframe-frontend-core`.
- Uses the local `useCopyToClipboard` hook to copy the resolved command to the clipboard with success/error toast messaging.

## Usage Example

```typescript
import { DoctorModeWarning } from '@/app/components/doctor-mode-warning';

export function AgentInstallTroubleshooting() {
  return (
    <div>
      <h2>Installation Troubleshooting</h2>
      <DoctorModeWarning platform="macos" />
    </div>
  );
}
```

The component looks up the correct doctor command string for the given `platform` (e.g., `macos`, `windows`, `linux`) from `OPENFRAME_DOCTOR_COMMANDS`, displays it via `PathsDisplay`, and wires up a copy-to-clipboard action so users can quickly paste the command into their terminal to diagnose and repair a malfunctioning agent installation.
