# remote-access-session-context.tsx

React context for propagating remote access session state down to mounted session surfaces (e.g., remote-desktop viewers). It links an approved access request to its live session, exposes the session's ended state, and provides controls for ending or re-requesting access.

## Key Components

- **`RemoteAccessSessionContextValue`** — Interface describing the context shape:
  - `requestId`: the approval behind the session; used by remote-desktop sessions to build MeshCentral relay ids as `<requestId>.<p>.<nonce>`, letting the gateway match tunnels to grants.
  - `session`: the `RemoteSession` record (`null` until resolved).
  - `ended`: a `RemoteSessionEnd` once the session terminates, otherwise `null`.
  - `endSession`: callback for the technician to end their own session.
  - `requestAgain`: callback to issue a new request in place of an ended one, or `null` if not applicable.
- **`NO_SESSION`** — Default context value representing "no approval in play" (feature flag off or legacy auto-start flow), where the tunnel keeps a random id and no re-request is possible.
- **`RemoteAccessSessionProvider`** — Provider component wrapping children with a given context value.
- **`useRemoteAccessSession()`** — Hook returning the full context value.
- **`useApprovedRemoteAccessRequestId()`** — Convenience hook returning just the `requestId`.

## Usage Example

```typescript
import {
  RemoteAccessSessionProvider,
  useRemoteAccessSession,
  useApprovedRemoteAccessRequestId,
} from './remote-access-session-context';

function RemoteDesktopViewer() {
  const { session, ended, endSession, requestAgain } = useRemoteAccessSession();
  const requestId = useApprovedRemoteAccessRequestId();

  if (ended) {
    return (
      <div>
        Session ended: {ended.reason}
        {requestAgain && <button onClick={requestAgain}>Request Again</button>}
      </div>
    );
  }

  return (
    <div>
      <p>Request: {requestId}</p>
      <p>Session: {session?.id ?? 'Connecting...'}</p>
      <button onClick={endSession}>End Session</button>
    </div>
  );
}

function App() {
  return (
    <RemoteAccessSessionProvider
      value={{
        requestId: 'req-123',
        session: null,
        ended: null,
        endSession: () => console.log('ending'),
        requestAgain: null,
      }}
    >
      <RemoteDesktopViewer />
    </RemoteAccessSessionProvider>
  );
}
```
