React context for propagating remote-access session approval state (request id, session record, end state) down to mounted remote-desktop session surfaces, so the MeshCentral relay tunnel can be correlated with its approval grant.

## Key Components

- **`RemoteAccessSessionContextValue`** - Interface describing the context shape: `requestId` (the approval id used to build the MeshCentral relay id as `<requestId>.<p>.<nonce>`), `session` (the `RemoteSession` record, or `null` until resolved), `ended` (`RemoteSessionEnd` once the session terminates), `endSession` (callback to end the session from the technician's side), and `requestAgain` (callback to re-request access in place of an ended session, or `null` if not applicable).
- **`NO_SESSION`** - Default context value representing "no approval in play" (feature flag off or legacy auto-start flow); all fields are empty/no-op.
- **`RemoteAccessSessionContext`** - The underlying React context, initialized with `NO_SESSION`.
- **`RemoteAccessSessionProvider`** - Provider component that wraps children with a supplied context value.
- **`useRemoteAccessSession()`** - Hook to read the full context value.
- **`useApprovedRemoteAccessRequestId()`** - Convenience hook returning just the approved `requestId`, or `null`.

## Usage Example

```typescript
import {
  RemoteAccessSessionProvider,
  useRemoteAccessSession,
  useApprovedRemoteAccessRequestId,
} from './remote-access-session-context';

function RemoteDesktopSurface() {
  const { session, ended, endSession, requestAgain } = useRemoteAccessSession();
  const requestId = useApprovedRemoteAccessRequestId();

  if (ended) {
    return requestAgain ? <button onClick={requestAgain}>Request again</button> : <p>Session ended</p>;
  }

  return (
    <div>
      <p>Relay id prefix: {requestId ?? 'legacy'}</p>
      <button onClick={endSession}>End session</button>
    </div>
  );
}

function App() {
  return (
    <RemoteAccessSessionProvider
      value={{
        requestId: 'req-123',
        session: null,
        ended: null,
        endSession: () => console.log('ended'),
        requestAgain: null,
      }}
    >
      <RemoteDesktopSurface />
    </RemoteAccessSessionProvider>
  );
}
```
