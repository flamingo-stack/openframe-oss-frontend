This file implements the `RunScriptModal` React component, a multi-step modal flow for running a script on a specific device from the Scripts feature.

## Key Components

- **`RunScriptModalProps`** — interface defining the component's props: `isOpen`, `onClose`, `machineId` (target device), and `onViewDeviceLogs` (callback to navigate to device logs).
- **`RunScriptModal`** — the main exported component that orchestrates a three-step workflow:
  1. **Select** — renders `RunScriptSelectStep` to search/filter and pick an active script.
  2. **Config** — renders `RunScriptConfigStep` to review/override per-run settings (timeout, privilege, args, env) and trigger `batchRunScript` against `machineId`.
  3. **Running** — renders `ScriptRunningModal` as a post-run confirmation with a CTA to view device logs.
- Internal state management:
  - `step` — tracks whether the user is on `'select'` or `'config'`.
  - `scriptId` — the currently selected script.
  - `ran` — whether the script run has been triggered, switching to the confirmation modal.
  - `wasOpen` — used to detect modal open transitions during render (avoids a flash of stale state that an effect-based reset would cause) and resets `step`, `scriptId`, and `ran`.

## Usage Example

```typescript
import { useState } from 'react';
import { RunScriptModal } from './run-script-modal';
import { useRouter } from 'next/navigation';

function DeviceActions({ machineId }: { machineId: string }) {
  const [isModalOpen, setModalOpen] = useState(false);
  const router = useRouter();

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Run Script</button>

      <RunScriptModal
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
        machineId={machineId}
        onViewDeviceLogs={() => router.push(`/devices/${machineId}?tab=overview`)}
      />
    </>
  );
}
```
