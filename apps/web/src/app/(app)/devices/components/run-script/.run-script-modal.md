# run-script-modal.tsx

A multi-step modal component for running a script on a specific device from the Scripts feature. It orchestrates script selection, run configuration, and a post-run confirmation view.

## Key Components

- **`RunScriptModal`** — Main exported component that manages the step-based flow:
  1. **Select Script** — renders `RunScriptSelectStep` to pick an active script via search/tag filters.
  2. **Run Script (config)** — renders `RunScriptConfigStep` to review/override per-run variables (timeout, privilege, args, env) and trigger `batchRunScript` against the target device.
  3. **Scripts Running** — renders `ScriptRunningModal` as a post-run confirmation, offering a CTA to view device logs.

- **`RunScriptModalProps`** — Props interface:
  - `isOpen: boolean` — controls modal visibility.
  - `onClose: () => void` — close handler.
  - `machineId: string` — target device id for `batchRunScript`.
  - `onViewDeviceLogs: () => void` — navigation callback to the device's Overview/logs tab.

Internally, the component tracks `step` (`'select' | 'config'`), `scriptId`, and `ran` state. A render-time check (`wasOpen` vs `isOpen`) resets state when the modal reopens, avoiding a flash of stale UI that an effect-based reset would cause.

## Usage Example

```typescript
import { useState } from 'react';
import { RunScriptModal } from './run-script-modal';

function DeviceActions({ machineId, goToDeviceLogsTab }: { machineId: string; goToDeviceLogsTab: () => void }) {
  const [isRunScriptOpen, setIsRunScriptOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsRunScriptOpen(true)}>Run Script</button>

      <RunScriptModal
        isOpen={isRunScriptOpen}
        onClose={() => setIsRunScriptOpen(false)}
        machineId={machineId}
        onViewDeviceLogs={goToDeviceLogsTab}
      />
    </>
  );
}
```
