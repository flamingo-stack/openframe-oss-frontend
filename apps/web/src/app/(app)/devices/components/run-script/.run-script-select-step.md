## Overview

React component implementing the first step of the "run script" modal workflow: a searchable, tag-filterable, infinite-scrolling list of active scripts for selection. Built with Relay for GraphQL pagination and a shared loading-scope system that renders skeleton rows during data fetches.

## Key Components

- **`RunScriptSelectStep`** — Top-level exported component combining `ScriptsTagFilter` (search + tag filters) and `PickerList`. Debounces search input (300ms) before triggering queries.
- **`PickerList`** — Wraps the picker in a `LoadingSuspense` boundary with a "Loading scripts" label.
- **`PickerListReader`** — Detects if inside a loading scope (Suspense fallback) and renders skeleton rows (`PickerLoadingPage`) instead of running the live query.
- **`PickerListQuery`** — Core data-fetching component using `useLazyLoadQuery` + `usePaginationFragment` to load scripts, with `IntersectionObserver`-based infinite scroll.
- **`PickerRow`** — Renders a single script row (name, description, OS badges) or its skeleton equivalent when `script` is `null` or within a loading scope.
- **`PickerLoadingPage`** — Renders a full page of skeleton `PickerRow`s during pagination fetches.

## Usage Example

```typescript
import { RunScriptSelectStep } from './run-script-select-step';

function RunScriptModal() {
  const handleScriptSelect = (scriptId: string) => {
    console.log('Selected script:', scriptId);
    // Advance to next modal step (e.g., target selection)
  };

  return (
    <div className="flex h-[600px] flex-col">
      <RunScriptSelectStep onSelect={handleScriptSelect} />
    </div>
  );
}
```

**Notes:**
- Requires a Relay environment provider ancestor since it uses `useLazyLoadQuery` and `usePaginationFragment`.
- The list auto-paginates via an `IntersectionObserver` sentinel when the user scrolls near the bottom (200px pre-fetch margin).
- Loading states are coordinated via `useLoadingScope`/`LoadingSuspense` so skeletons render consistently whether on initial load or pagination.
- Search and tag filters are passed down from `ScriptsTagFilter`, which owns its own Suspense boundary independently.
