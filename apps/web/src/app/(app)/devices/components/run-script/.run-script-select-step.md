# run-script-select-step.tsx

The first step of the "Run Script" modal flow, rendering a searchable, tag-filterable, paginated list of active scripts for the user to select from before proceeding to parameter/target configuration.

## Key Components

- **`RunScriptSelectStep`** — Exported step component. Manages search input (debounced) and tag filter state, renders `ScriptsTagFilter` and the scrollable `PickerList`.
- **`PickerList`** — Wraps `PickerListReader` in a `LoadingSuspense` boundary with a "Loading scripts" label.
- **`PickerListReader`** — Detects an active loading scope (e.g. parent Suspense fallback) and renders skeleton rows instead of firing a query.
- **`PickerListQuery`** — Runs the Relay query (`scriptsRunPickerRelayQuery`) and paginated fragment (`scriptsRunPickerRelayFragment`) via `useLazyLoadQuery`/`usePaginationFragment`. Implements infinite scroll using an `IntersectionObserver` sentinel element.
- **`PickerRow`** — Renders a single script row (name, description, OS badges) or its skeleton loading form when `script` is `null` or inside a loading scope.
- **`PickerLoadingPage`** — Renders a full page of skeleton `PickerRow`s (count = `PICKER_PAGE_SIZE`).
- **`PICKER_PAGE_SIZE`** — Pagination page size constant (20).

## Usage Example

```typescript
import { RunScriptSelectStep } from './run-script-select-step';

function RunScriptModal() {
  const [scriptId, setScriptId] = useState<string | null>(null);

  if (!scriptId) {
    return (
      <RunScriptSelectStep
        onSelect={(selectedId) => setScriptId(selectedId)}
      />
    );
  }

  return <RunScriptConfigureStep scriptId={scriptId} />;
}
```

This component is designed to be the first panel in a multi-step modal; `onSelect` is the callback used to advance to the next step once a script is chosen. Search input is debounced 300ms before triggering the GraphQL query, and tag filtering is delegated to the `ScriptsTagFilter` component, which owns its own Suspense boundary for tag loading.
