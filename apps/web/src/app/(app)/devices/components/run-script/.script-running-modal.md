A React modal component that displays a confirmation message after a script has been dispatched to run on a device, offering the user a direct path to view the device's logs.

## Key Components

- **`ScriptRunningModalProps`** — Interface defining the component's props: `isOpen` (visibility flag), `onClose` (dismiss handler), and `onViewDeviceLogs` (navigation handler to the device's Overview tab logs).
- **`ScriptRunningModal`** — Functional component rendering a `SimpleModal` with the title "Scripts Running", an informational message, and two footer actions: **Close** and **Device Logs**.

This component is a thin, presentational wrapper around `SimpleModal`, built to match the Figma design spec (`1:65393`) for post-script-execution feedback.

## Usage Example

```typescript
import { useState } from 'react';
import { ScriptRunningModal } from '@/app/components/scripts/script-running-modal';
import { useRouter } from 'next/navigation';

function ScriptRunner({ deviceId }: { deviceId: string }) {
  const [isModalOpen, setModalOpen] = useState(false);
  const router = useRouter();

  const handleRunScript = async () => {
    // dispatch script execution to the device...
    setModalOpen(true);
  };

  const handleViewDeviceLogs = () => {
    router.push(`/devices/${deviceId}?tab=overview`);
    setModalOpen(false);
  };

  return (
    <>
      <button onClick={handleRunScript}>Run Script</button>
      <ScriptRunningModal
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
        onViewDeviceLogs={handleViewDeviceLogs}
      />
    </>
  );
}
```

## Notes

- Relies on `@flamingo-stack/openframe-frontend-core` for the `Button` component and the shared `SimpleModal` from `@/app/components/shared/simple-modal`.
- Caller is responsible for implementing the actual navigation logic in `onViewDeviceLogs`.
