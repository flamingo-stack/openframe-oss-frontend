A React client component that displays a post-run confirmation modal after a script has been dispatched to a device, prompting the user to either close the dialog or navigate to the device's logs.

## Key Components

- **`ScriptRunningModalProps`** — Interface defining the component's props: `isOpen` (modal visibility), `onClose` (close handler), and `onViewDeviceLogs` (navigation handler to the device's Overview/logs tab).
- **`ScriptRunningModal`** — Functional component rendering a `SimpleModal` with a "Scripts Running" title, informational message, and two footer actions: **Close** (outline button) and **Device Logs** (accent button).

## Usage Example

```typescript
import { useState } from 'react';
import { ScriptRunningModal } from './script-running-modal';
import { useRouter } from 'next/navigation';

function ScriptExecutionFlow({ deviceId }: { deviceId: string }) {
  const [isModalOpen, setIsModalOpen] = useState(false);
  const router = useRouter();

  const handleRunScript = async () => {
    // Dispatch script to device
    await runScriptOnDevice(deviceId);
    setIsModalOpen(true);
  };

  const handleViewDeviceLogs = () => {
    router.push(`/devices/${deviceId}?tab=overview`);
    setIsModalOpen(false);
  };

  return (
    <>
      <button onClick={handleRunScript}>Run Script</button>
      <ScriptRunningModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        onViewDeviceLogs={handleViewDeviceLogs}
      />
    </>
  );
}
```

This component is typically used as the final step in a script-execution flow, giving users immediate feedback that the script was dispatched and a direct path to monitor results via device logs.
