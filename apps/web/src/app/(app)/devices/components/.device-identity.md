# device-identity.tsx

A presentational React component that renders a device's identity by combining an icon tile with a two-line text label (title and subtitle). It's used within remote tool views to display which device is being referenced, supporting a loading state where text renders as skeleton bars while the icon remains fixed.

## Key Components

- **`DeviceIdentity`** — Functional component that lays out an icon alongside stacked title/subtitle text using a flex container.
- **`DeviceIdentityProps`** — Props interface:
  - `icon: ReactNode` — The tool's icon tile, rendered as-is (not part of loading skeleton).
  - `title: string` — Primary device name.
  - `subtitle: string` — Secondary descriptive line.
  - `className?: string` — Optional class override, primarily used to control spacing between icon and text.

Internally, it delegates text rendering to the shared `TitleLines` component, passing a fixed skeleton width (`w-36`) for the subline during loading states.

## Usage Example

```typescript
import { DeviceIdentity } from '@/app/components/device-identity';
import { Laptop } from 'lucide-react';

function DeviceRow() {
  return (
    <DeviceIdentity
      icon={<Laptop className="h-8 w-8" />}
      title="MacBook Pro M2"
      subtitle="Last seen 2 minutes ago"
      className="gap-3"
    />
  );
}
```

During data loading, omit or placeholder the `title`/`subtitle` values while keeping the `icon` stable, since `TitleLines` handles rendering skeleton bars for the text portion automatically.
