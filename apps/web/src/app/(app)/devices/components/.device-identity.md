# device-identity.tsx

A presentational component that displays a device's identity—its tool icon alongside a title and subtitle—typically used to represent which device a remote tool is currently showing.

## Key Components

- **`DeviceIdentity`** — Functional component rendering an icon tile next to stacked title/subtitle text.
- **`DeviceIdentityProps`** — Props interface:
  - `icon: ReactNode` — the tool's icon tile, rendered as-is (not loading-aware)
  - `title: string` — primary device name
  - `subtitle: string` — secondary descriptive line
  - `className?: string` — optional class to control spacing/gap between icon and text

This component relies on `TitleLines` (from `@/app/components/shared`) to render the title and subtitle, including skeleton/loading states for the text (the icon tile itself does not show a loading skeleton).

## Usage Example

```vue
<script setup lang="ts">
// Example usage within a parent component (React/Next.js context)
</script>
```

```typescript
import { DeviceIdentity } from '@/app/components/device-identity';
import { ToolIcon } from '@/app/components/shared';

export function DeviceRow({ device }: { device: Device }) {
  return (
    <DeviceIdentity
      icon={<ToolIcon tool={device.tool} />}
      title={device.name}
      subtitle={device.serialNumber}
      className="gap-3"
    />
  );
}
```

During loading states, pass placeholder values for `title` and `subtitle`—`TitleLines` will render skeleton bars for the text while the `icon` remains static and fully rendered.
