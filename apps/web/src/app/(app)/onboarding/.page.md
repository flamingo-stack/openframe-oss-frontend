Client-side Next.js page component that renders the "Get Started" onboarding tour, with automatic redirection for SaaS tenant mode users who bypass onboarding entirely.

## Key Components

- **`OnboardingPage`** (default export) — The page component for the onboarding route. Determines whether the current context is a SaaS tenant via `isSaasTenantMode()`, and if so, redirects to Mingo's home page instead of rendering onboarding content.
- Uses **`useAppModeRedirect`** hook to perform the conditional redirect based on app mode.
- Renders **`OnboardingContent`** (from `./components/onboarding-content`) when onboarding should actually be shown, delegating loading-state management to that component.

## Usage Example

```typescript
// This is a Next.js page component, automatically routed
// based on its file location (e.g., app/onboarding/page.tsx)

// Behavior summary:
// 1. If app is in SaaS tenant mode -> redirect to routes.mingo.home, render nothing
// 2. Otherwise -> render <OnboardingContent /> which manages its own loading state

import { isSaasTenantMode } from '@/lib/app-mode';
import { useAppModeRedirect } from '@/app/hooks/use-app-mode-redirect';
import { routes } from '@/lib/routes';

function ExampleUsagePattern() {
  const mingoHome = isSaasTenantMode();
  useAppModeRedirect(mingoHome ? routes.mingo.home : null);

  if (mingoHome) return null;
  // Render onboarding-specific UI here
  return null;
}
```

**Notes:**
- Marked `'use client'` since it relies on client-side hooks for redirection logic.
- No props are accepted; behavior is fully derived from app mode configuration.
- Returning `null` while `mingoHome` is true prevents a flash of onboarding content before the redirect completes.
