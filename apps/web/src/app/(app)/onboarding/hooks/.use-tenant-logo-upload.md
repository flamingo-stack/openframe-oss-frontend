A React hook that manages tenant logo upload/removal, providing state and handlers suitable for an `ImageUploader` component. It writes directly to `TENANT_IMAGE_ENDPOINT` and optimistically patches the cached tenant info query so all consumers of `useTenantInfo` reflect the new logo immediately.

## Key Components

- **`useTenantLogoUpload()`** - Main hook returning:
  - `imageUrl` - current logo URL (or `undefined` if none)
  - `imageHash` - cache-busting hash/timestamp tied to the current image
  - `isBusy` - `true` while an upload or delete request is in flight
  - `seed(image)` - initializes local state from a `TenantImage` record (call when tenant data first loads)
  - `upload(file)` - uploads a `File`, updates local state and the React Query cache, shows a success/error toast
  - `remove()` - deletes the current logo, clears local state and cache, shows a success/error toast

## Usage Example

```typescript
import { useTenantLogoUpload } from './use-tenant-logo-upload';
import { useTenantInfo } from '../../settings/hooks/use-tenant-info';

function OrganizationLogoField() {
  const { data: tenantInfo } = useTenantInfo();
  const { imageUrl, imageHash, isBusy, seed, upload, remove } = useTenantLogoUpload();

  useEffect(() => {
    seed(tenantInfo?.image);
  }, [tenantInfo?.image, seed]);

  return (
    <ImageUploader
      imageUrl={imageUrl}
      imageHash={imageHash}
      isBusy={isBusy}
      onUpload={upload}
      onRemove={remove}
    />
  );
}
```

This hook is shared between the Initial Setup card and the onboarding setup wizard, ensuring a single, consistent upload pipeline for the organization logo across both surfaces.
