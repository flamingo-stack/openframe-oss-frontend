# use-pending-logo.ts

A React hook that manages a logo file selected before its owning record exists, holding it in memory with a local preview URL until the caller is ready to upload it (typically once the record receives a server-assigned id). It safely manages the lifecycle of `object-URL` previews, revoking them on replacement or unmount to avoid memory leaks.

This hook is shared between the two onboarding flows that create the first customer: the Initial Setup card step and the setup wizard's customer screen.

## Key Components

- **`usePendingLogo()`** — Hook returning:
  - `pendingFile: File | null` — the currently selected logo file awaiting upload.
  - `previewUrl: string | undefined` — an object URL for rendering a live preview of `pendingFile`.
  - `replace(file: File | null): void` — sets a new pending file (revoking any prior preview URL first), or clears the selection when passed `null`.

## Usage Example

```typescript
import { usePendingLogo } from './use-pending-logo';

function CustomerLogoStep() {
  const { pendingFile, previewUrl, replace } = usePendingLogo();

  const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0] ?? null;
    replace(file);
  };

  const handleSubmit = async (customerId: string) => {
    if (!pendingFile) return;
    const formData = new FormData();
    formData.append('logo', pendingFile);
    await fetch(`/api/customers/${customerId}/logo`, {
      method: 'POST',
      body: formData,
    });
  };

  return (
    <div>
      <input type="file" accept="image/*" onChange={handleFileChange} />
      {previewUrl && <img src={previewUrl} alt="Logo preview" />}
    </div>
  );
}
```

**Notes:**
- Call `replace(null)` to clear the selection and release the preview URL.
- The hook automatically revokes the active object URL on unmount, so no manual cleanup is required by consumers.
- Upload logic (e.g., calling a mutation with `pendingFile`) is the caller's responsibility once the parent record's id is available.
