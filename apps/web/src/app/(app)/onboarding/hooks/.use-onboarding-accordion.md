# use-onboarding-accordion.ts

A React hook implementing a single-open accordion pattern for onboarding surfaces, with URL hash synchronization and scroll-anchoring behavior. Only one step can be expanded at a time, and expanding/collapsing is always paired with a smooth scroll to keep the interacted row in view.

## Key Components

- **`ANCHOR_TOP_OFFSET_PX`** — Exported constant (80px) defining the scroll offset from the top of the container to the anchored row, used both internally and by consuming pages (e.g., `navigateSamePageHash`) to keep tween targets consistent.
- **`useOnboardingAccordion<T extends string>(options)`** — The main hook. Accepts:
  - `urlStep?: T | null` — externally controlled open step, synced with a URL hash.
  - `onOpenStepChange?: (step: T | null) => void` — callback fired on every open/close transition.
  
  Returns:
  - `expandedOf(step)` — boolean accessor for whether a given step is open.
  - `onExpandedChangeOf(step)` — returns a change handler to pass to a collapsible component.
  - `refOf(step)` — returns a stable ref callback to attach to each step's DOM node (used for scroll anchoring).

## Behavior Notes

- Expanding one step always collapses any previously open step (single-open accordion).
- Clicking a row immediately triggers a scroll anchor, compensating for the height of a still-collapsing sibling row above it, so the final scroll position is accurate even mid-animation.
- On mount, if `urlStep` is set, that step opens and the page scrolls to it.
- External changes to `urlStep` (e.g., browser back/forward) are "adopted" — the hook opens the corresponding step and scrolls to it.
- Scrolling is delegated to `scrollElementIntoView` from `@flamingo-stack/openframe-frontend-core/utils`, which resolves the actual scrollable container rather than relying on the window.

## Usage Example

```typescript
import { useOnboardingAccordion } from './use-onboarding-accordion';

type OnboardingStep = 'connect' | 'configure' | 'invite';

function OnboardingPage({ urlStep, setUrlStep }: {
  urlStep: OnboardingStep | null;
  setUrlStep: (step: OnboardingStep | null) => void;
}) {
  const { expandedOf, onExpandedChangeOf, refOf } = useOnboardingAccordion<OnboardingStep>({
    urlStep,
    onOpenStepChange: setUrlStep,
  });

  return (
    <div>
      {(['connect', 'configure', 'invite'] as OnboardingStep[]).map(step => (
        <OnboardingAccordionItem
          key={step}
          ref={refOf(step)}
          expanded={expandedOf(step)}
          onExpandedChange={onExpandedChangeOf(step)}
          title={step}
        />
      ))}
    </div>
  );
}
```
