Single-open accordion state for an onboarding surface (the Onboarding page and the dashboard's Initial Setup card). Every step starts collapsed and only the user opens one (a chevron click, or a deep link); progress never moves the open step.

## Key Components

### Constants

- **`ANCHOR_TOP_OFFSET_PX`** (`80`) — Top offset used when anchoring a row into view; exported so page-level `navigateSamePageHash` calls use the same landing position

### `useOnboardingAccordion<T extends string>({ urlStep?, onOpenStepChange? })`

| Option | Description |
|---|---|
| `urlStep` | The URL-synced open step (`#step-…`); adopted on mount and on external hash changes, and anchored into view |
| `onOpenStepChange` | Reports every open/close (`null` = all collapsed) so the URL mirrors the open block |

| Return | Description |
|---|---|
| `expandedOf(step)` | Whether the given step is open |
| `onExpandedChangeOf(step)` | A change handler that opens/closes the step and anchors the clicked row |
| `refOf(step)` | A stable ref callback attaching a step row's DOM node |

Anchoring goes through the lib's `scrollElementIntoView`, which resolves the app's scroll container and honours `prefers-reduced-motion`.

## Usage Example

```typescript
const { expandedOf, onExpandedChangeOf, refOf } = useOnboardingAccordion<TenantOnboardingStep>();

<OnboardingAccordionItem
  ref={refOf(step)}
  expanded={expandedOf(step)}
  onExpandedChange={onExpandedChangeOf(step)}
  {...rest}
/>
```
