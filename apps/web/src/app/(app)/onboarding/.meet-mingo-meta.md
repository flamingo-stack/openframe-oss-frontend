Defines shared metadata (icon and copy) for the "Meet Mingo" step, ensuring consistent presentation across the Initial Setup card and the "Get Started" tour.

## Key Components

- **`MEET_MINGO_META`** — A typed constant object exporting:
  - `icon: ReactNode` — An `AgentMark` component configured for the `mingo` agent, styled with secondary text color to match sibling step icons.
  - `title: string` — The step's display title, `"Meet Mingo"`.
  - `description: string` — Short copy explaining Mingo's role as an AI co-pilot for the OpenFrame workspace.

This constant acts as a single source of truth, preventing icon/copy drift between the two UI surfaces that render this step. The step's body content is similarly shared via `./components/mingo-step`.

## Usage Example

```typescript
import { MEET_MINGO_META } from './meet-mingo-meta';

function SetupStepRow() {
  return (
    <div className="flex items-center gap-3">
      {MEET_MINGO_META.icon}
      <div>
        <h3 className="text-sm font-medium">{MEET_MINGO_META.title}</h3>
        <p className="text-sm text-ods-text-secondary">
          {MEET_MINGO_META.description}
        </p>
      </div>
    </div>
  );
}
```

Both the Initial Setup card and the "Get Started" tour import `MEET_MINGO_META` to render identical icon and copy, avoiding duplicated or diverging text/icon definitions across components.
