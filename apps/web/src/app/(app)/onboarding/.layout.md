Defines Next.js metadata and layout configuration for the Onboarding route, setting the page title and delegating layout rendering to a shared layout component.

## Key Components

- **`metadata`** — A `Metadata` object exported for Next.js to use for the page's `<head>` tag, generated via the `routeTitle` helper with `'Onboarding'` as the page name.
- **Default export** — Re-exports the default layout component from `@/app/(app)/route-title-layout`, allowing this route segment to reuse the shared layout implementation without duplicating logic.

## Usage Example

This file follows the Next.js App Router convention where a `layout.tsx` file automatically applies to all routes within its directory segment:

```typescript
// app/(app)/onboarding/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Onboarding') };
```

Next.js automatically picks up the `metadata` export to set the browser tab title (e.g., "Onboarding | OpenFrame") and uses the re-exported default component to wrap all pages within the `onboarding` route segment, ensuring consistent layout and title behavior across the app without rewriting layout logic per route.
