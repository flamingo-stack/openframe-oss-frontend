# scripting-step.tsx

Renders the "Scripting" onboarding step, a simplified version of the full add-script form that lets users create their first automation script directly from the onboarding flow. On submission it creates the script via GraphQL mutation and redirects to its details page.

## Key Components

- **`onboardingScriptSchema`** — Zod schema validating a trimmed subset of script fields (`name`, `shell`, `default_timeout`, `run_as_user`, `supported_platforms`, `script_body`). Missing fields are filled from `EDIT_SCRIPT_DEFAULT_VALUES` before being mapped to the GraphQL write input.
- **`OnboardingScriptForm`** — Type inferred from `onboardingScriptSchema`, used for `react-hook-form` typing.
- **`ScriptingStep`** — Main exported component. Props:
  - `onComplete?: () => void` — callback invoked when the step is marked complete or a script is successfully created.
  - `completed?: boolean` — whether the step has already been completed (hides the "Mark as Complete" button).
  - `completing?: boolean` — external loading state passed to `useStepActionState`.

## Internal Behavior

- Uses `react-hook-form` with `zodResolver` for validation, defaulting to Windows platform and a 90-second timeout.
- `useMutation(createScriptMutation)` creates the script; on success it shows a toast, calls `onComplete`, and navigates to `routes.scripts.details(newId)` with an onboarding coach-mark hint via `onboardingHintUrl`.
- On validation failure, aggregates field error messages into a single toast.
- Reuses shared UI primitives: `SelectButton` (platform picker), shell `Select`, and `ScriptEditor` (syntax editor).
- Footer provides a `FullFormLink` to the complete script creation page (`routes.scripts.new`), plus "Mark as Complete" and "Add Script" action buttons managed via `useStepActionState`.

## Usage Example

```typescript
import { ScriptingStep } from './scripting-step';

function OnboardingFlow() {
  const [completed, setCompleted] = useState(false);

  return (
    <ScriptingStep
      completed={completed}
      completing={false}
      onComplete={() => setCompleted(true)}
    />
  );
}
```

This component is intended to be used within an onboarding wizard/stepper that controls step completion state and navigation context.
