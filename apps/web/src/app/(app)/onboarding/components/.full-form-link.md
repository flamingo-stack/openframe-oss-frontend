Renders a styled link used as a "full form" escape hatch at the bottom of a trimmed onboarding step, letting users navigate to the complete entity page instead of the condensed in-flow form.

## Key Components

- **`FullFormLink`** — Client component (`'use client'`) that renders a `next/link` styled with an external-link icon and underlined label.
  - **Props:**
    - `href: string` — destination URL for the full entity page.
    - `label: string` — visible link text.
  - **Behavior:** Uses `useIsMobileShell()` to detect whether the app is running inside the mobile (Capacitor) shell. On the web, the link opens in a new tab (`target="_blank"`, with `rel="noopener noreferrer"`) so the partially filled onboarding step remains behind it. Inside the mobile shell, `target` and `rel` are omitted entirely, because:
    - The mobile shell has no tabs, and the WebView would discard the navigation.
    - Capacitor's iOS `createWebViewWith` forwards new-window requests to `UIApplication.open(url)`, but no handler is registered for `capacitor://localhost`, so the tap would silently fail.

## Usage Example

```typescript
import { FullFormLink } from '@/components/full-form-link';

export function OnboardingStepFooter() {
  return (
    <footer className="flex items-center justify-between p-4">
      <FullFormLink
        href="/customers/123/edit"
        label="Open full customer form"
      />
    </footer>
  );
}
```

Place this component in the footer of any trimmed onboarding/step form where users may need to escape to the complete, non-condensed entity editing page.
