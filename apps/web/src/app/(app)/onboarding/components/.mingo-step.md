Renders the "Meet Mingo" onboarding step UI — an interactive introduction to the Mingo AI co-pilot that combines a demo video, MPH-sourced quick action chips, and completion controls.

## Key Components

- **`MingoStep`** — Primary exported component. Displays the onboarding step body with a description, quick action chips, a YouTube demo video, and footer action buttons ("Mark as Complete" / "Start New Chat").
- **`MINGO_AGENT_SLUG`** — Constant (`'mingo'`) used to resolve the agent's config URL and accent color via `aiAgentConfigUrl`.
- **`DEMO_VIDEO_ID`** — YouTube video ID placeholder for the onboarding demo clip.
- **`GUARDRAILS_HREF`** — Internal link to the AI Guardrail Settings page.

### Key Behaviors

| Behavior | Details |
|---|---|
| Quick action chips | Fetched from the `agent-mingo` config via `useEmptyStateConfig`; first 4 actions rendered with turquoise (`cyan`) accent matching the chat empty state |
| "Start New Chat" | Clears the active Mingo dialog and opens the Mingo drawer via `useMingoLauncherStore` |
| Quick action selection | Calls `sendToMingo(prompt)` directly, opening the drawer and sending the prompt |
| Step completion | "Mark as Complete" triggers `onComplete` with a spinner; opening a chat silently triggers `onCompleteBackground` |

## Usage Example

```typescript
import { MingoStep } from '@/app/(app)/mingo/components/mingo-step';

function OnboardingFlow() {
  const [completed, setCompleted] = useState(false);
  const [completing, setCompleting] = useState(false);

  const handleComplete = async () => {
    setCompleting(true);
    await markStepComplete('mingo');
    setCompleted(true);
    setCompleting(false);
  };

  return (
    <MingoStep
      completed={completed}
      completing={completing}
      onComplete={handleComplete}
      onCompleteBackground={() => markStepComplete('mingo')}
    />
  );
}
```

## Props

| Prop | Type | Description |
|---|---|---|
| `onComplete` | `() => void` | Called when "Mark as Complete" is clicked; shows loading spinner |
| `onCompleteBackground` | `() => void` | Called silently when "Start New Chat" is clicked on an incomplete step |
| `completed` | `boolean` | Hides the "Mark as Complete" button when `true` |
| `completing` | `boolean` | Puts the "Mark as Complete" button into a loading/disabled state |
