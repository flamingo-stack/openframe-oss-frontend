## Overview

`MingoStep` is a React client component that renders the "Meet Mingo" onboarding step, combining an introductory message, AI-agent-sourced quick-action chips, and a demo video, alongside completion controls for the onboarding flow.

## Key Components

- **`MingoStep`** — Main exported component. Props:
  - `onComplete?`, `onCompleteBackground?`: callbacks invoked on step completion (foreground vs. background completion)
  - `completed?`, `completing?`: completion state flags controlling button rendering
  - `expanded?`: controls whether the demo video is active/suspended
- **`MINGO_AGENT_SLUG`** — Public slug (`'mingo'`) used to fetch the Mingo agent's published config via `useChatRuntime`'s `aiAgentConfigUrl` seam.
- **`MAX_WALL_ROWS` / `MIN_UNIQUE_CHIPS_PER_ROW`** — Constants governing how many rows the `QuickActionWall` renders, computed from the number of available chips rather than hardcoded, to avoid repeated single-chip rows.
- **`startNewChat`** — Callback that clears any open dialog and routes the launcher panel directly to the composer (via `useMingoLauncherStore`), rather than just opening the drawer.
- **`chips`** — Memoized `QuickActionChip[]` derived from the agent's quick-action config, resolving accent color admin-first (per-action → agent identity icon → fallback), each wired to `sendToMingo`.

## Usage Example

```typescript
import { MingoStep } from './mingo-step';

function OnboardingFlow() {
  const [completed, setCompleted] = useState(false);
  const [completing, setCompleting] = useState(false);

  return (
    <MingoStep
      expanded
      completed={completed}
      completing={completing}
      onComplete={() => {
        setCompleting(true);
        // mark step complete...
        setCompleted(true);
      }}
      onCompleteBackground={() => setCompleted(true)}
    />
  );
}
```

This component depends on `useChatRuntime` and `useMingoLauncherStore` context/state providers being available in the component tree, and is intended for use within the OpenFrame onboarding step sequence.
