# OnboardingCompleteBanner

A shared completion banner component displayed when all onboarding steps are finished, used across both the dashboard's Initial Setup card and the Get Started page.

Shows a leading emoji in a bordered icon box, a title/description pair, and an accent call-to-action button. The responsive layout keeps the emoji and text together on a single row on mobile (with the CTA dropping below), while on desktop the content grows to push the CTA to the right, matching the Figma spec.

## Key Components

- **`OnboardingCompleteBanner`** — The main exported component function.
- **`OnboardingCompleteBannerProps`** — Props interface:
  - `emoji` — Leading emoji rendered in a bordered icon box (e.g. `"🎉"`).
  - `title` — Banner heading text.
  - `description` — Supporting description text.
  - `actionLabel` — Label for the accent CTA button.
  - `onAction` — Callback fired when the CTA is clicked.
  - `actionIcon` *(optional)* — Icon rendered before the CTA label.
  - `className` *(optional)* — Overrides the outer background; defaults to `bg-ods-card`. Pass `bg-ods-bg` when the banner sits on a `bg-ods-bg` surface (e.g. the Initial Setup card) so it reads as a bordered box instead of a raised card.

## Usage Example

```typescript
import { OnboardingCompleteBanner } from './onboarding-complete-banner';
import { CheckCircleIcon } from 'lucide-react';

function GetStartedPage() {
  return (
    <OnboardingCompleteBanner
      emoji="🎉"
      title="All Steps Done!"
      description="You've completed every onboarding step."
      actionLabel="Go to Dashboard"
      actionIcon={<CheckCircleIcon className="size-4" />}
      onAction={() => router.push('/dashboard')}
    />
  );
}

function InitialSetupCardFooter() {
  return (
    <OnboardingCompleteBanner
      emoji="🎉"
      title="Setup Complete"
      description="All onboarding steps are finished."
      actionLabel="Take the Product Tour"
      onAction={() => startProductTour()}
      className="bg-ods-bg"
    />
  );
}
```

## Notes

- Requires `'use client'` — intended for use in client-rendered React trees.
- Relies on `@flamingo-stack/openframe-frontend-core` for the `Button` component and `cn` utility, and on ODS (OpenFrame Design System) CSS variables/tokens for spacing and theming.
