Renders the "Company & Team" onboarding step, providing a dynamic multi-row form for inviting technicians to OpenFrame via email, with role selection and invite dispatch.

## Key Components

- **`CompanyTeamStep`** — Primary exported component. Renders an invite form with dynamically addable/removable email+role rows, sends invitations via the `useInvitations` hook, and reports step completion via `onComplete`.
- **`InviteRow`** — Internal type representing a single invite entry (`{ email: string; role: string }`).
- **`useInvitations`** — Hook (from settings) providing the `inviteUsers` mutation.
- **`useStepActionState`** — Hook managing loading/disabled state for the "Mark as Complete" and "Send Invites" buttons.
- **`canSubmit`** — Memoized boolean; `true` when at least one row contains a valid email address.

## Props

| Prop | Type | Description |
|---|---|---|
| `onComplete` | `() => void` (optional) | Fired on first successful invite send, or when "Mark as Complete" is clicked |
| `completed` | `boolean` (optional) | Suppresses re-firing `onComplete` on subsequent invite sends |
| `completing` | `boolean` (optional) | Passed to `useStepActionState` to disable actions during parent transitions |

## Usage Example

```typescript
import { CompanyTeamStep } from './company-team-step';

function OnboardingFlow() {
  const [stepDone, setStepDone] = useState(false);

  return (
    <CompanyTeamStep
      onComplete={() => setStepDone(true)}
      completed={stepDone}
      completing={false}
    />
  );
}
```

## Behaviour Notes

- Rows default to the `ADMIN` role; currently the only available option via `ROLE_OPTIONS`.
- Invalid email inputs are visually flagged once the user has typed at least one character.
- "Send Invites" only dispatches rows with valid emails; empty/invalid rows are silently skipped.
- A "Manage Roles" link navigates to `routes.settings.employees`.
