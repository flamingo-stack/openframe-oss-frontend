Renders the "Logging" onboarding step — a read-only preview table of the three most recent log entries, with actions to mark the step complete and navigate to the full logs page.

## Key Components

- **`LoggingStep`** — Main exported React component. Accepts `onComplete`, `onCompleteBackground`, `completed`, and `completing` props to manage onboarding step state.
- **`LogRow`** — Internal interface mapping a raw `LogEntry` into a flattened, display-ready table row shape.
- **`severityVariant`** — Maps log severity strings (`ERROR`, `WARNING`, `INFO`, `CRITICAL`) to `Tag` variant tokens.
- **`logDetailsUrl`** — Builds the deep-link URL to the log details page from a `LogEntry`.
- **`columns`** — Memoized `ColumnDef<LogRow>[]` defining six columns: Log ID/timestamp, Status tag, Tool badge, Source device/org, Log Details summary, and an open-in-new-tab action button.

## Usage Example

```typescript
import { LoggingStep } from './logging-step';

function OnboardingFlow() {
  const [completed, setCompleted] = useState(false);
  const [completing, setCompleting] = useState(false);

  const handleComplete = async () => {
    setCompleting(true);
    await markStepComplete('logging');
    setCompleted(true);
    setCompleting(false);
  };

  return (
    <LoggingStep
      completed={completed}
      completing={completing}
      onComplete={handleComplete}
      onCompleteBackground={() => markStepComplete('logging')}
    />
  );
}
```

## Behavior Notes

- Fetches logs via `useLogs()` and slices to the first three entries.
- "View Logs" navigates to `/logs-page` with a coach-mark hint URL via `onboardingHintUrl`, and silently calls `onCompleteBackground` if the step is not yet marked done.
- "Mark as Complete" is hidden once `completed` is `true`; a spacer `div` preserves the two-column footer layout.
- Row clicks and the external-link button open the full log details page. The button uses `data-no-row-click` to prevent event bubbling to the row handler.
