Renders an accordion-style UI for onboarding step lists, supporting active, completed, and disabled step states with expandable bodies, status pills, and loading-skeleton states. Designed to be driven by an external auto-advance hook (`useOnboardingAccordion`) for scroll anchoring and controlled expansion.

## Key Components

- **`OnboardingStepStatus`** — Type union: `'active' | 'completed' | 'disabled'`, controlling row styling and interactivity.
- **`OnboardingAccordionItemProps`** — Props interface for a single row: icon, title, description, status, `next` flag, `requirementHint`, expansion state (controlled or uncontrolled), `loading`, `ref`, `id`, and `children` (step body).
- **`OnboardingAccordionItem`** — Main component rendering a single accordion row. Handles:
  - Icon swap to `CheckCircleIcon` when completed
  - Status pill ("Complete"/"Next") via internal `StepStatusPill`
  - Chevron toggle button (disabled/hidden for locked steps)
  - Requirement hint text for disabled steps
  - Animated expand/collapse via CSS grid-rows transition
  - Loading-skeleton rendering through `useLoadingScope` or the `loading` prop
- **`OnboardingAccordionGroupProps`** / **`OnboardingAccordionGroup`** — Wraps multiple items in a bordered container with an optional uppercase section `label`.
- **`ONBOARDING_STEP_LIST_CLASS`** — Exported class string for the bordered/rounded step-list frame, reusable by consumers (e.g., dashboard cards).

## Usage Example

```typescript
import {
  OnboardingAccordionGroup,
  OnboardingAccordionItem,
} from './onboarding-accordion';
import { IdCardIcon } from '@flamingo-stack/openframe-frontend-core/components/icons-v2';

function GetStartedSection() {
  const [expandedStep, setExpandedStep] = React.useState<string | null>('profile');

  return (
    <OnboardingAccordionGroup label="Get Started">
      <OnboardingAccordionItem
        id="step-profile"
        icon={<IdCardIcon size={24} />}
        title="Complete your profile"
        description="Add your company details and logo."
        status="completed"
      />
      <OnboardingAccordionItem
        id="step-customer"
        icon={<IdCardIcon size={24} />}
        title="Add your first customer"
        description="Create a customer record to get started."
        status="active"
        next
        expanded={expandedStep === 'customer'}
        onExpandedChange={(v) => setExpandedStep(v ? 'customer' : null)}
      >
        <p>Step body content goes here.</p>
      </OnboardingAccordionItem>
      <OnboardingAccordionItem
        icon={<IdCardIcon size={24} />}
        title="Invite teammates"
        description="Collaborate with your team."
        status="disabled"
        requirementHint="Added Customer required"
      />
    </OnboardingAccordionGroup>
  );
}
```
