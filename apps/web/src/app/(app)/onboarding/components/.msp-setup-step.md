# msp-setup-step.tsx

React client component rendering the "Complete MSP Setup" onboarding step, allowing users to configure their organization's name, website, and logo during onboarding. It shares the same tenant-info data layer as the settings "Edit Organization" modal to keep both forms in sync.

## Key Components

- **`MspSetupStep`** — Main exported component accepting `onComplete`, `completed`, and `completing` props to integrate with the onboarding step flow.
- **Tenant data seeding logic** — Seeds local `name`/`website` state and the logo uploader from `tenantInfo` during render (not in an effect) using a `seededFrom` sentinel tracker, ensuring fields populate correctly even when react-query serves cached data on remount.
- **`handleSave`** — Persists organization changes via `useUpdateTenantInfo`, firing `onComplete` only on the first successful save when the step isn't already marked complete.
- **Layout** — Two-column responsive form (name/website inputs on the left, `ImageUploader` for the logo on the right), with "Mark as Complete" and "Save Organization" actions aligned per the design grid.

## Usage Example

```typescript
import { MspSetupStep } from './msp-setup-step';

function OnboardingWizard() {
  const [completed, setCompleted] = useState(false);

  return (
    <MspSetupStep
      completed={completed}
      completing={false}
      onComplete={() => setCompleted(true)}
    />
  );
}
```

## Dependencies

- `useTenantInfo` / `useUpdateTenantInfo` — shared tenant data hooks (`../../settings/hooks/use-tenant-info`)
- `useTenantLogoUpload` — manages logo upload, seeding, and removal state (`../hooks/use-tenant-logo-upload`)
- `useStepActionState` — tracks loading/disabled state for the "Mark as Complete" and "Save" buttons across async actions (`../use-step-action-state`)
- `getFullImageUrl` — resolves the displayable logo URL from uploader state (`@/lib/image-url`)
- UI primitives (`Button`, `Input`, `ImageUploader`, `CheckCircleIcon`) from `@flamingo-stack/openframe-frontend-core`
