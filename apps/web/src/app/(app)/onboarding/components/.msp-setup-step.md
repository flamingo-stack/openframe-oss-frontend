Renders the "Complete MSP Setup" onboarding step, allowing users to configure their organization's name, website, and logo. Shares the same tenant-info data layer as the settings "Edit Organization" form to keep both views in sync.

## Key Components

- **`MspSetupStep`** — Primary exported React component accepting:
  - `onComplete?: () => void` — callback fired on first successful save or explicit "Mark as Complete" click
  - `completed?: boolean` — hides the "Mark as Complete" button once the step is done
  - `completing?: boolean` — passed to `useStepActionState` to manage button busy/disabled states

- **`handleImageChange`** — Uploads a new logo via `uploadWithAuth`, updates local state and React Query cache, and shows a success/error toast

- **`handleImageRemove`** — Deletes the current logo via `deleteWithAuth`, clears local image state, and patches the query cache

- **`handleSave`** — Calls `useUpdateTenantInfo.mutate` with current name/website; triggers `onComplete` only on the first successful save (guards against re-firing on already-completed steps)

## Usage Example

```typescript
import { MspSetupStep } from './msp-setup-step';

function OnboardingFlow() {
  const [completed, setCompleted] = useState(false);

  return (
    <MspSetupStep
      completed={completed}
      onComplete={() => setCompleted(true)}
    />
  );
}
```

## Notes

- Image uploads are capped at **5 MB** (`maxSize={5 * 1024 * 1024}`)
- The logo dropzone is fixed to `148px` height on `md+` screens to align with the two-input column; it reverts to natural height on mobile
- Button layout reserves two invisible flex spacers on desktop to right-align the action buttons, matching the design grid
