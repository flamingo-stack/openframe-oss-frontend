# customer-setup-step.tsx

Renders the "Customers Setup" step within the onboarding flow, providing a simplified form to create the first client profile. Reuses building blocks from the full customer creation page (`Input`, `ImageUploader`, `useCreateCustomer`) while deferring full address/contact details, and links to the complete form at `routes.customers.new` for advanced setup.

## Key Components

- **`CustomerSetupStep`** — Default export React component accepting `onComplete`, `completed`, and `completing` props to integrate with the onboarding step lifecycle.
- **`handleSave`** — Async callback that builds a `CreateCustomerRequest` payload, calls `createOrganization`, uploads a pending logo (if any) via `uploadWithAuth`, invalidates relevant React Query caches (`organizations`, `dashboardQueryKeys.all`), shows success/failure toasts, and navigates to `/customers` with an onboarding coach-mark hint.
- **`usePendingLogo`** — Hook holding the uploaded logo file in memory until the customer record exists (since image upload requires an organization ID).
- **`useStepActionState`** — Hook managing loading/disabled state for the "Mark as Complete" and "Save Customer" buttons.
- **`emptyAddress`** — Default empty address object used for both physical and mailing addresses in the simplified payload.

## Usage Example

```typescript
import { CustomerSetupStep } from './customer-setup-step';

function OnboardingWizard() {
  const [completed, setCompleted] = useState(false);

  return (
    <CustomerSetupStep
      completed={completed}
      completing={false}
      onComplete={() => setCompleted(true)}
    />
  );
}
```

The component is self-contained: it manages its own form state (`name`, `website`, pending logo file) and only requires the parent to supply completion callbacks/state. On successful save, it triggers `onComplete` (once, if not already `completed`) and redirects the user to the Customers page with a contextual coach-mark hint.
