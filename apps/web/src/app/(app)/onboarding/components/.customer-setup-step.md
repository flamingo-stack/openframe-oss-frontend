A client-side React component that renders the "Customers Setup" step of the onboarding flow, allowing users to create their first client profile with a name, website URL, and optional logo upload.

## Key Components

- **`CustomerSetupStep`** — Main exported component accepting:
  - `onComplete` — callback fired once after successful customer creation
  - `completed` — whether the step is already marked done
  - `completing` — whether a completion transition is in progress
- **`replacePreview`** — Manages in-memory object URLs for logo preview, revoking stale URLs to prevent memory leaks
- **`handleSave`** — Async handler that creates the customer, optionally uploads the pending logo, invalidates relevant React Query caches, and navigates to `/customers` with an onboarding coach-mark hint

## Usage Example

```typescript
import { CustomerSetupStep } from './customer-setup-step';

function OnboardingFlow() {
  const [stepComplete, setStepComplete] = useState(false);

  return (
    <CustomerSetupStep
      completed={stepComplete}
      onComplete={() => setStepComplete(true)}
      completing={false}
    />
  );
}
```

## Behavior Notes

- Logo is held in memory as a `File` until the customer is successfully created, then uploaded via `uploadWithAuth` to `/api/organizations/{id}/image`
- On save, invalidates both `['organizations']` and `dashboardQueryKeys.all` query caches
- `onComplete` fires only on first successful save (`!completed` guard prevents re-firing)
- Provides a link to the full organization form at `routes.customers.new` that opens in a new tab
- "Mark as Complete" button is hidden once the step is already completed; a spacer `div` preserves layout alignment
