Renders a static loading skeleton for the onboarding page, using real metadata (groups, steps, icons, titles) while displaying placeholder controls for per-step completion status.

## Key Components

- **`OnboardingSkeleton`** — Client component that maps over `USER_ONBOARDING_GROUPS` and `USER_ONBOARDING_STEPS` to render the full onboarding layout with `OnboardingAccordionItem` in `loading` state, suppressing body mounts and preventing `useSuspenseQuery` from triggering.

## Usage Example

```typescript
// As a Suspense fallback in the onboarding page route
import { Suspense } from 'react';
import { OnboardingSkeleton } from './components/onboarding-skeleton';
import { OnboardingContent } from './components/onboarding-content';

export default function OnboardingPage() {
  return (
    <Suspense fallback={<OnboardingSkeleton />}>
      <OnboardingContent />
    </Suspense>
  );
}
```

## Notes

- Uses `USER_ONBOARDING_GROUPS` and `USER_ONBOARDING_STEPS` as the single source of truth, so the skeleton never drifts out of sync with real content.
- The `loading` prop on `OnboardingAccordionItem` prevents accordion bodies from mounting, ensuring `DeviceSetupStep` (which contains a `useSuspenseQuery`) never suspends during the skeleton phase.
- The "Skip Onboarding" action is rendered but `disabled` to preserve layout without interactive functionality.
