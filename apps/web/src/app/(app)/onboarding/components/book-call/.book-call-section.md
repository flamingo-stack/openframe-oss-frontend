## BookCallSection

A React component that toggles between a promotional CTA and an embedded scheduler for booking an onboarding call, used in both the dashboard's Initial Setup card and the `/onboarding` tour flow.

### Purpose

This component manages the visual state transition between `BookCallPromo` (the marketing/CTA view) and `BookCallScheduler` (the actual booking widget). Rather than conditionally mounting/unmounting the promo, it is hidden via CSS (`hidden` class) while the scheduler is active, preserving the promo's embedded video element so it doesn't get reset or "pop" into an app-shell floating card mid-booking.

## Key Components

- **`BookCallSection`** — Main exported component. Accepts an optional `className` prop for styling.
- **`useOnboardingMeetingLink`** — Hook providing `link` (the scheduling URL) and `isLoading` state.
- **`BookCallPromo`** — Promotional view with a "Book a call" CTA button; stays mounted (hidden, not unmounted) during scheduling.
- **`BookCallScheduler`** — The actual scheduler widget, rendered only when `booking` is true and `link` is available.

### State Behavior

- If loading has settled and there's no `link`, the component renders `null` (nothing to book).
- While loading, the promo renders with its CTA disabled, avoiding layout shift once the link resolves.
- Once `booking` is triggered and `link` exists, the scheduler renders alongside the hidden promo.

## Usage Example

```typescript
import { BookCallSection } from './book-call-section';

export function OnboardingTour() {
  return (
    <div className="onboarding-card">
      <h2>Next Step</h2>
      <BookCallSection className="mt-4" />
    </div>
  );
}
```

The component requires no props beyond an optional `className`; all data fetching and state transitions are handled internally via `useOnboardingMeetingLink` and local `useState`.
