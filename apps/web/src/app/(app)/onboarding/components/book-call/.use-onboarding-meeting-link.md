# use-onboarding-meeting-link.ts

Client-side React hook that resolves which HubSpot meeting link the onboarding "Book a call" promo should use, by fetching the hub's meeting directory and selecting the "OpenFrame Users" audience link (with a graceful fallback).

Rather than rendering the full meeting directory UI (grouped by audience), this hook picks a single link for the onboarding flow, degrading gracefully if the content-managed audience label is renamed.

## Key Components

- **`useSchedulingLinks()`** — React Query hook that fetches the meeting directory (`GET /content/api/meetings`) via `embedAuthedFetch` (required since the gateway role-gates `/content/**` routes). Treats `404`/`410` as "no links available" (returns `null`), and throws on other errors so React Query can retry rather than silently hiding the promo.
- **`useOnboardingMeetingLink()`** — Wraps `useSchedulingLinks` and returns the resolved onboarding link plus a loading flag.
- **`pickOnboardingLink(payload)`** — Internal selector that prefers the `openframe-users` purpose group's first link, falling back to the first link in any group if that audience has none.
- **`OnboardingMeetingLinkResult`** — Return shape: `{ link: SchedulingLink | null; isLoading: boolean }`.
- **`ONBOARDING_PURPOSE`** — Constant slug (`'openframe-users'`) identifying the target audience group.

## Usage Example

```typescript
import { useOnboardingMeetingLink } from '@/hooks/use-onboarding-meeting-link';

function BookACallPromo() {
  const { link, isLoading } = useOnboardingMeetingLink();

  if (isLoading) return <Spinner />;
  if (!link) return null; // hub has no scheduling links configured

  return (
    <a href={link.url} target="_blank" rel="noopener noreferrer">
      Book a call: {link.title}
    </a>
  );
}
```

**Note:** `useSchedulingLinks()` can also be used directly when full directory data (all audience groups) is needed, such as in the Contact Support flow's billing call-back feature.
