Renders the HubSpot meeting scheduler widget bound to a specific scheduling link, wiring up the host app's proxy base, booking confirmation toast, and back navigation. Serves as the booking counterpart to `book-call-section`, delegating all picker UI to the shared `@flamingo-stack/openframe-frontend-core` library.

## Key Components

- **`BookCallSchedulerProps`** — Props interface: `link` (the `SchedulingLink` to book), `onBack` (callback to return to the promo view), and optional `className`.
- **`BookCallScheduler`** — Client component (`'use client'`) that wraps `HubSpotMeetingScheduler` from the core library, supplying:
  - `meetingId` / `hosts` / `fallbackUrl` derived from the `link` prop
  - `apiBaseUrl` set to `CONTENT_BASE` (the `/content` proxy base)
  - `detailsForm` set to `SignedInBookingForm` for collecting booker details
  - `onBooked` handler that fires a success toast with the booking title and formatted start time
  - `onBack` passthrough so the host decides navigation behavior

## Usage Example

```typescript
import { BookCallScheduler } from '@/app/components/book-call-scheduler';
import type { SchedulingLink } from '@flamingo-stack/openframe-frontend-core/schemas/meeting-booking-schema';

function BookCallFlow({ link }: { link: SchedulingLink }) {
  const [showScheduler, setShowScheduler] = useState(false);

  if (!showScheduler) {
    return <button onClick={() => setShowScheduler(true)}>Schedule a call</button>;
  }

  return (
    <BookCallScheduler
      link={link}
      onBack={() => setShowScheduler(false)}
      className="mt-4"
    />
  );
}
```

Note: this component intentionally omits a title/description override since the host page's own promo card already provides the heading context.
