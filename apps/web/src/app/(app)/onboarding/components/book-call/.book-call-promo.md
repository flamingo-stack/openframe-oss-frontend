# book-call-promo.tsx

A presentational component rendering the "offer" half of the book-call section — marketing copy, a CTA button, and a walkthrough video. It's the counterpart to the scheduler component, sharing the same layout slot and height so the UI doesn't shift when one swaps for the other.

The component implements three responsive layouts (phone, tablet, desktop) that mirror the scheduler's own breakpoints, ensuring both halves of the swap change shape in sync. It deliberately matches `MEETING_SCHEDULER_H` as a fixed height (not a minimum) so shorter copy doesn't cause layout shift, letting any leftover vertical space flow to the video, which maintains a 16:9 aspect ratio.

## Key Components

- **`BookCallPromo`** — Default-exported function component rendering the promo card (icon + heading, description, CTA button, walkthrough video).
- **`BookCallPromoProps`** — Props interface:
  - `onBookCall: () => void` — handler invoked when the CTA is clicked.
  - `disabled?: boolean` — disables the CTA (e.g., when no bookable link is available yet).
  - `className?: string` — additional classes merged onto the root `<section>`.

## Usage Example

```typescript
import { BookCallPromo } from './book-call-promo';

function BookCallSection() {
  const handleBookCall = () => {
    window.open('https://calendly.com/example', '_blank');
  };

  return (
    <BookCallPromo
      onBookCall={handleBookCall}
      disabled={false}
      className="my-custom-class"
    />
  );
}
```

**Note:** This component is `'use client'` and relies on shared design-system primitives (`Button`, `CalendarBookmarkIcon`, `MEETING_SCHEDULER_H`) from `@flamingo-stack/openframe-frontend-core`, as well as a sibling `BookCallWalkthroughVideo` component. It's intended to be rendered alongside a scheduler component within a parent section that controls the actual swap/transition logic between the two states.
