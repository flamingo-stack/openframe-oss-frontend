Renders the "Knowledge Base" onboarding step body, introducing users to the AI Assistant documentation library and providing actions to mark the step complete or navigate directly to the article editor.

## Key Components

### `KnowledgeBaseStep`

The sole export — a client component that displays a brief description of the Knowledge Base feature alongside two footer actions.

| Prop | Type | Description |
|---|---|---|
| `onComplete` | `() => void` | Called when the user clicks "Mark as Complete" |
| `onCompleteBackground` | `() => void` | Called silently when the user navigates to the article editor without having completed the step yet |
| `completed` | `boolean` | Hides "Mark as Complete" and replaces it with a layout spacer when `true` |
| `completing` | `boolean` | Puts the "Mark as Complete" button into a loading/disabled state during async completion |

**Navigation behaviour:** "Create Article" pushes the user to `/knowledge-base/new`, decorated with an onboarding hint via [`onboardingHintUrl`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/src/features/onboarding/onboarding-coach-marks.ts), and simultaneously fires `onCompleteBackground` if the step has not already been marked done.

## Usage Example

```typescript
<KnowledgeBaseStep
  completed={step.completed}
  completing={isSubmitting}
  onComplete={() => markStepComplete('knowledge-base')}
  onCompleteBackground={() => markStepComplete('knowledge-base', { silent: true })}
/>
```
