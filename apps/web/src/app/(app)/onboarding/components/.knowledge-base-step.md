# knowledge-base-step.tsx

Renders the body content for the "Knowledge Base" step in the onboarding flow, introducing users to building a documentation library and providing navigation to the knowledge base article editor.

## Key Components

- **`KnowledgeBaseStep`** — React client component that displays an introductory description of the Knowledge Base feature along with action buttons:
  - **"Mark as Complete"** button (outline variant) — visible only when the step is not yet completed; triggers `onComplete` and shows a loading state via `completing`.
  - **"Create Article"** button (accent variant) — always visible; navigates to the knowledge base editor (`routes.knowledgeBase.new()`) via `onboardingHintUrl`, and silently completes the step in the background (`onCompleteBackground`) if not already completed.

### Props

| Prop | Type | Description |
|---|---|---|
| `onComplete` | `() => void` | Called when the user explicitly marks the step complete |
| `onCompleteBackground` | `() => void` | Called to complete the step silently when navigating away |
| `completed` | `boolean` | Whether the step has already been completed |
| `completing` | `boolean` | Whether completion is in progress (shows loading spinner) |

## Usage Example

```typescript
import { KnowledgeBaseStep } from './knowledge-base-step';

<KnowledgeBaseStep
  completed={false}
  completing={false}
  onComplete={() => markStepComplete('knowledge')}
  onCompleteBackground={() => markStepCompleteSilently('knowledge')}
/>
```

This component is intended to be rendered inside a larger onboarding step container (e.g., a coach-mark or wizard card) that supplies the completion handlers and tracks step state across the onboarding flow.
