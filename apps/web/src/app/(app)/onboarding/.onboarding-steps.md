# onboarding-steps.ts

Canonical source of truth for onboarding step ordering, counting, and progress calculations across the "Initial Setup" (tenant) and "Get Started" (user) onboarding surfaces. Rather than hardcoding step counts throughout the app, all surfaces derive their counts and completion state from these shared arrays and helper functions.

## Key Components

- **`TENANT_ONBOARDING_STEPS`** — Ordered array of `TenantOnboardingStep` values rendered in the tenant "Initial Setup" flow.
- **`USER_ONBOARDING_STEPS`** — A deliberate, `const`-narrowed subset of `UserOnboardingStep` rendered in the "Get Started" tour (excludes customer/device steps already satisfied by tenant onboarding).
- **`UserOnboardingStepId`** — Type alias derived from `USER_ONBOARDING_STEPS`, used to make step→content maps exhaustive over just the rendered steps.
- **`onboardingStepAnchorId(step)`** — Converts a step name into a DOM id / URL hash (e.g., `TICKETS` → `step-tickets`).
- **`onboardingStepFromAnchorId(steps, anchorId)`** — Reverse lookup; resolves an anchor id back to a step, validated against a given step list.
- **`countCompleted(steps, completedSteps)`** — Counts how many of `steps` are present in the `completedSteps` membership set.
- **`isStepDone(step, completedSteps)`** — Checks whether a single step is completed.
- **`OnboardingProgress<T>`** — Interface describing `total`, `done`, `nextStep`, and `allDone` for a surface.
- **`onboardingProgress(steps, completedSteps, loading)`** — Computes full progress state for a surface's step list.
- **`OnboardingStepWiring`** — Interface describing how a rendered step row is wired (ref, anchor id, expansion state, body).
- **`stepsToCompleteLabel(total)`** / **`progressLine(progress)`** — Human-readable progress text helpers.

## Usage Example

```typescript
import {
  USER_ONBOARDING_STEPS,
  onboardingProgress,
  onboardingStepAnchorId,
  progressLine,
} from '@/lib/onboarding-steps';

const completedSteps = ['MEET_MINGO', 'TICKETS'];

const progress = onboardingProgress(USER_ONBOARDING_STEPS, completedSteps);
// { total: 6, done: 2, nextStep: 'SCRIPTING', allDone: false }

console.log(progressLine(progress));
// "6 steps to complete · 2/6 done"

const anchor = onboardingStepAnchorId('SCRIPTING');
// "step-scripting"
```
