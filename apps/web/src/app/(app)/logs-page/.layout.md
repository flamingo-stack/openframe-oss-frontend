Defines the page metadata and layout export for the Logs route in the Next.js App Router, setting a dynamic browser tab title and delegating rendering to a shared layout component.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title to `"Logs"` using the `routeTitle` helper, ensuring consistent title formatting across the app.
- **`default export`** — Re-exports `route-title-layout` from `@/app/(app)/route-title-layout` as this route segment's layout component, avoiding duplicate layout logic.

## Usage Example

This file is automatically picked up by Next.js as the layout for the `logs` route segment—no manual import is needed. It works alongside a `page.tsx` in the same directory:

```typescript
// app/logs/page.tsx
export default function LogsPage() {
  return <div>Logs content goes here</div>;
}
```

The `routeTitle` helper centralizes title formatting, e.g.:

```typescript
// lib/route-title.ts
export function routeTitle(section: string): string {
  return `${section} | OpenFrame`;
}
```

This pattern keeps metadata declarations lightweight per route while reusing a shared layout shell (navigation, breadcrumbs, etc.) defined once in `route-title-layout`.
