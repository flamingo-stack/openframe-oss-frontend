This file defines the Next.js metadata and layout re-export for the Logs page route, setting a dynamic page title using the shared `routeTitle` utility.

## Key Components

- **`metadata`** — A Next.js `Metadata` object exporting the page title, generated via `routeTitle('Logs')` so the browser tab/title reflects the "Logs" section consistently with the app's naming convention.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, avoiding duplication of layout logic across route segments.

## Usage Example

This file is automatically picked up by Next.js as the layout for the `logs` route segment. No manual invocation is needed; Next.js uses the exported `metadata` and default layout component to render the page shell.

```typescript
// Example of how routeTitle is used elsewhere to maintain consistency
import { routeTitle } from '@/lib/route-title';

export const metadata: Metadata = { title: routeTitle('Devices') };
```

The shared layout component (`route-title-layout`) typically handles consistent page chrome (headers, breadcrumbs, etc.) for routes that only need a custom title, reducing boilerplate across the `app/(app)` route group.

See the implementation at [`route-title-layout`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/route-title-layout.tsx) for layout details.
