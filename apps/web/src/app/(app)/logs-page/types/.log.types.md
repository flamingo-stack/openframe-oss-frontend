## log.types.ts

Defines TypeScript interfaces for log entries, filters, and related data structures used by legacy raw-POST log endpoints (`use-logs.ts`, `use-log-details.ts`). These types bridge hand-maintained fields with a generated copy-payload shape, pending migration to Relay.

## Key Components

- **`LogEntry`** — Core log record interface extending `CopyableLogDetails`. Includes ingestion metadata (`ingestDay`, `userId`, `deviceId`), a human-readable `summary`, arbitrary `metadata`, device-related fields (`hostname`, `nickname`, `organizationName`, `organizationId`), and a transformed `device` object following the `PartialNamedDevice` shape.
- **`LogEdge`** — Minimal GraphQL-style edge wrapper around a `LogEntry` node, used for list/pagination shapes.
- **`LogFilters`** — Describes available filter options surfaced in the UI (tool types, event types, severities, organizations).
- **`LogFilterInput`** — Input shape for querying/filtering logs, including severity, tool type, organization, device/user scoping, and an inclusive `timestampFrom`/`timestampTo` range using the `Instant` scalar.

## Usage Example

```typescript
import type { LogEntry, LogFilterInput, LogFilters } from './log.types';

function buildFilterInput(orgId: string): LogFilterInput {
  return {
    organizationIds: [orgId],
    severities: ['ERROR', 'WARN'],
    timestampFrom: '2024-01-01T00:00:00Z',
    timestampTo: '2024-01-31T23:59:59Z',
  };
}

function summarizeLog(log: LogEntry): string {
  const name = log.nickname ?? log.hostname ?? 'Unknown device';
  return `[${log.ingestDay}] ${name}: ${log.summary}`;
}

function populateFilterOptions(filters: LogFilters) {
  console.log(filters.toolTypes, filters.severities, filters.organizations);
}
```
