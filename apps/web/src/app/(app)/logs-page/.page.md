The root page component for the Logs section, responsible for rendering the logs interface within a standardized layout container.

## Key Components

- **`Logs`** — Default export. Client-side page component that wraps the `LogsTable` component with consistent horizontal and bottom padding using system spacing tokens.

## Usage Example

```typescript
// Rendered automatically by Next.js App Router at the /logs route
// No props required — layout and data fetching handled internally by LogsTable

import Logs from './page';

// Used within a Next.js layout
export default function Layout() {
  return <Logs />;
}
```

## Notes

- Marked as `'use client'` to enable client-side rendering for the logs page.
- Spacing is applied via CSS custom properties (`--spacing-system-l`) for consistency with the design system.
- All data fetching and display logic is delegated to [`LogsTable`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/logs/components/logs-table.tsx).
