# format-log-details.ts

Centralizes the logic for formatting log details into a canonical plain-text representation, used by every "Copy Log Details" affordance in the app (log-details page, logs table row button, and "Log Details" drawer). This ensures all three copy payloads stay in sync without duplicating the field list.

## Key Components

- **`formatLogDetailsFragment`** — An `@inline` Relay GraphQL fragment on `LogDetails` selecting the fields needed for the copy payload (`toolEventId`, `severity`, `timestamp`, `toolType`, `eventType`, `message`, `details`).
- **`CopyableLogDetails`** — Plain data type derived from the fragment's data shape with Relay's `$fragmentType` marker omitted, for callers that have raw log data instead of a fragment reference.
- **`LOG_DETAILS_COPY_LINE_COUNT`** — The number of lines in the formatted payload, useful for UI that needs to pre-render drawer/skeleton layouts.
- **`formatLogDetailsForCopy(log)`** — Formats a `CopyableLogDetails` object into the canonical multi-line string for clipboard copy.
- **`formatLogDetailsRefForCopy(ref)`** — Convenience wrapper that reads an inline Relay fragment reference and formats it in one call.

## Usage Example

```typescript
import { formatLogDetailsForCopy, formatLogDetailsRefForCopy } from './format-log-details';

// When you already have plain log data (e.g. from a raw POST response)
const text = formatLogDetailsForCopy({
  toolEventId: 'evt-123',
  severity: 'ERROR',
  timestamp: '2024-01-01T00:00:00Z',
  toolType: 'RMM',
  eventType: 'DEVICE_OFFLINE',
  message: 'Device disconnected',
  details: 'Connection timeout after 30s',
});
navigator.clipboard.writeText(text);

// When you have a Relay fragment reference spread with ...formatLogDetails_log
function CopyButton({ logRef }: { logRef: formatLogDetails_log$key }) {
  const handleCopy = () => {
    navigator.clipboard.writeText(formatLogDetailsRefForCopy(logRef));
  };
  return <button onClick={handleCopy}>Copy Log Details</button>;
}
```
