Formats log entry details into a canonical plain-text string for clipboard copying, ensuring consistent output across the log-details page, logs table row action, and the "Log Details" drawer.

## Key Components

- **`formatLogDetailsFragment`** — An `@inline` Relay GraphQL fragment on `LogDetails` that selects the fields needed for the copy payload (`toolEventId`, `severity`, `timestamp`, `toolType`, `eventType`, `message`, `details`). Centralizing the field list here prevents callers from restating it and risking drift.
- **`CopyableLogDetails`** — Type alias for the fragment's data shape with the Relay `$fragmentType` marker omitted, used by callers that have plain log data (not a Relay fragment reference), such as the log-details page that fetches via raw POST.
- **`LOG_DETAILS_COPY_LINE_COUNT`** — Constant exposing the number of lines in the copy payload, useful for UI that needs to render a matching number of skeleton/placeholder lines while loading.
- **`formatLogDetailsForCopy(log)`** — Builds the canonical multi-line plain-text string from a `CopyableLogDetails` object, one line per field, with fallback text for missing `message`/`details`.
- **`formatLogDetailsRefForCopy(ref)`** — Convenience wrapper that reads an inline Relay fragment reference via `readInlineData` and passes the result to `formatLogDetailsForCopy`.

## Usage Example

```typescript
import { formatLogDetailsRefForCopy, formatLogDetailsForCopy } from './format-log-details';

// From a Relay fragment reference (e.g., in a component that spread
// ...formatLogDetails_log on its query/fragment)
function handleCopyFromRelay(logRef: formatLogDetails_log$key) {
  const text = formatLogDetailsRefForCopy(logRef);
  navigator.clipboard.writeText(text);
}

// From plain fetched data (e.g., log-details page using raw POST)
function handleCopyFromRawData(log: CopyableLogDetails) {
  const text = formatLogDetailsForCopy(log);
  navigator.clipboard.writeText(text);
}
```
