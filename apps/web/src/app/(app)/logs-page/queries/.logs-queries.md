This file defines GraphQL query strings used for fetching log-related data, including filter options, paginated log lists, and detailed log entries.

## Key Components

- **`GET_LOG_FILTERS_QUERY`** — Retrieves available filter options for logs (tool types, event types, severities, and organizations) based on an optional `LogFilterInput` filter.
- **`GET_LOGS_QUERY`** — Fetches a paginated, searchable list of logs using cursor-based pagination (`first`/`after`), returning log summary fields and `pageInfo` for navigation.
- **`GET_LOG_DETAILS_QUERY`** — Retrieves full details for a single log entry, identified by `toolEventId`, `ingestDay`, `toolType`, `eventType`, and `timestamp`.

## Usage Example

```typescript
import { GET_LOGS_QUERY, GET_LOG_DETAILS_QUERY, GET_LOG_FILTERS_QUERY } from './logs-queries';

// Fetch log filter options
const filtersResult = await apolloClient.query({
  query: GET_LOG_FILTERS_QUERY,
  variables: { filter: { organizationId: 'org-123' } },
});

// Fetch paginated logs with search
const logsResult = await apolloClient.query({
  query: GET_LOGS_QUERY,
  variables: { filter: { severity: 'ERROR' }, first: 20, search: 'timeout' },
});

// Fetch detailed info for a specific log entry
const logDetails = await apolloClient.query({
  query: GET_LOG_DETAILS_QUERY,
  variables: {
    logId: 'evt-456',
    ingestDay: '2024-01-15',
    toolType: 'RMM',
    eventType: 'ALERT',
    timestamp: '2024-01-15T10:30:00Z',
  },
});
```

These query strings are intended to be used with a GraphQL client (such as Apollo Client) to interact with the logs API schema.
