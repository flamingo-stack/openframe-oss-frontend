# logs-queries.ts

Defines GraphQL query strings for fetching log-related data, including available filter options, paginated log lists, and detailed information for a single log entry.

## Key Components

- **`GET_LOG_FILTERS_QUERY`** — Fetches available filter options for logs: tool types, event types, severities, and a list of organizations (`id`, `name`). Accepts an optional `LogFilterInput` to scope results.
- **`GET_LOGS_QUERY`** — Fetches a paginated, searchable, filterable list of logs using cursor-based pagination (`first`/`after`). Returns `edges` with log node fields (e.g., `toolEventId`, `eventType`, `severity`, `hostname`, `organizationName`, `timestamp`) plus `pageInfo` (`hasNextPage`, `hasPreviousPage`, `startCursor`, `endCursor`).
- **`GET_LOG_DETAILS_QUERY`** — Fetches full details for a single log entry, requiring `logId`, `ingestDay`, `toolType`, `eventType`, and `timestamp` as identifying parameters. Returns extended fields including `message` and `details`.

## Usage Example

```typescript
import { GET_LOGS_QUERY, GET_LOG_FILTERS_QUERY, GET_LOG_DETAILS_QUERY } from './logs-queries';

// Fetch filter options
const filtersResult = await graphqlClient.request(GET_LOG_FILTERS_QUERY, {
  filter: { organizationId: 'org-123' },
});

// Fetch paginated logs
const logsResult = await graphqlClient.request(GET_LOGS_QUERY, {
  filter: { severities: ['ERROR'], toolTypes: ['RMM'] },
  first: 25,
  after: null,
  search: 'disk space',
});

// Fetch details for a specific log entry
const detailsResult = await graphqlClient.request(GET_LOG_DETAILS_QUERY, {
  logId: 'evt-456',
  ingestDay: '2024-05-01',
  toolType: 'RMM',
  eventType: 'ALERT',
  timestamp: '2024-05-01T12:00:00Z',
});
```

These query strings are intended to be used with a GraphQL client (e.g., Apollo Client or a custom fetch wrapper) within the logs feature of the application.
