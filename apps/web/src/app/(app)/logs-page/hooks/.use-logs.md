Provides React hooks for fetching paginated log entries and log filter options via GraphQL, with built-in error toasting and infinite scroll support.

## Key Components

### `logsQueryKeys`
Cache key factory for TanStack Query, scoping cache entries by filter and search state.

### `transformLogEntry(logEntry)`
Internal utility that maps flat backend fields (`hostname`, `organizationName`, `organizationId`) into a nested `device` object on each `LogEntry`.

### `useLogs(filters, search)`
Infinite-scroll hook that fetches paginated log entries. Accepts `LogFilterInput` and an optional search string. Automatically surfaces errors as toast notifications.

**Returns:**

| Property | Type | Description |
|---|---|---|
| `logs` | `LogEntry[]` | Flattened array across all fetched pages |
| `isLoading` | `boolean` | Initial load state |
| `isFetchingNextPage` | `boolean` | Next-page fetch in progress |
| `hasNextPage` | `boolean` | More pages available |
| `fetchNextPage` | `function` | Trigger next page load |
| `error` | `string \| null` | Latest error message |
| `resetToFirstPage` | `function` | Resets query cache to page 1 |

### `useLogFilters(filter)`
Fetches available filter options (severity levels, tool types, organizations). Uses a 60-second stale time.

**Returns:** `{ logFilters, isLoading, error }`

## Usage Example

```typescript
import { useLogs, useLogFilters } from './use-logs';

function LogsPanel() {
  const { logs, isLoading, hasNextPage, fetchNextPage } = useLogs(
    { severity: 'ERROR', organizationId: 'org_123' },
    'connection timeout'
  );

  const { logFilters } = useLogFilters({ organizationId: 'org_123' });

  return (
    <>
      {logs.map(log => (
        <div key={log.id}>{log.message}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>Load More</button>
      )}
    </>
  );
}
```

> Page size is fixed at `20` entries per request (`LOGS_PAGE_SIZE`). Logs data has a 30-second stale time; filter options have a 60-second stale time.
