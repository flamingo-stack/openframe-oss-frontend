React hooks for fetching paginated system logs and their associated filter options via GraphQL, with built-in error toasting, caching, and data transformation for device association.

## Key Components

- **`LOGS_PAGE_SIZE`** - Constant defining the number of log entries fetched per page (20).
- **`logsQueryKeys`** - Query key factory object for consistent React Query cache keys (`all`, `list`, `filters`).
- **`transformLogEntry(logEntry)`** - Internal helper that maps flat log fields (`deviceId`, `hostname`, `organizationName`) into a nested `device` object for consistent UI consumption.
- **`useLogs(filters, search)`** - Infinite query hook that fetches paginated logs via GraphQL, exposing:
  - `logs` - flattened array of all loaded log entries
  - `isFetchingNextPage`, `hasNextPage`, `fetchNextPage` - pagination controls
  - `resetToFirstPage` - resets the query cache to reload from the first page
  - Standard query state (loading, error, etc.) via `queryState`
- **`useLogFilters(filter)`** - Query hook that fetches available filter options (severity, tool type, organization), returning `logFilters` and standard query state.

Both hooks automatically display an error toast via `useToast` when the underlying query fails.

## Usage Example

```typescript
import { useLogs, useLogFilters, LOGS_PAGE_SIZE } from './use-logs';

function LogsTable() {
  const { logFilters } = useLogFilters({ toolType: 'AGENT' });

  const {
    logs,
    isLoading,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
    resetToFirstPage,
  } = useLogs({ severity: 'ERROR' }, 'connection timeout');

  if (isLoading) return <div>Loading logs…</div>;

  return (
    <div>
      {logs.map(log => (
        <div key={log.id}>{log.device?.hostname}: {log.message}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
      <button onClick={resetToFirstPage}>Refresh</button>
    </div>
  );
}
```
