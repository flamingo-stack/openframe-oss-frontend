This file provides React Query hooks for fetching and paginating system logs via GraphQL, including log filter options for filtering the logs table.

## Key Components

- **`LOGS_PAGE_SIZE`** - Constant (20) defining the page size used for infinite log pagination.
- **`logsQueryKeys`** - Query key factory for cache management (`all`, `list`, `filters`).
- **`transformLogEntry(logEntry)`** - Internal helper that normalizes flat backend fields (hostname, organizationId, organizationName) into a nested `device` object on each log entry.
- **`useLogs(filters, search)`** - Infinite query hook that fetches paginated logs from the GraphQL API, flattens pages into a single `logs` array, handles error toasts, and exposes pagination controls.
- **`useLogFilters(filter)`** - Query hook that fetches available filter options (severity, tool type, organization lists) for building log filter UIs.

## Usage Example

```typescript
import { useLogs, useLogFilters, LOGS_PAGE_SIZE } from './use-logs';

function LogsTable() {
  const { logFilters } = useLogFilters({});

  const {
    logs,
    isLoading,
    isFetchingNextPage,
    hasNextPage,
    fetchNextPage,
    resetToFirstPage,
  } = useLogs({ severity: 'ERROR' }, 'connection timeout');

  if (isLoading) {
    return <p>Loading logs…</p>;
  }

  return (
    <div>
      <ul>
        {logs.map(log => (
          <li key={log.id}>
            {log.device?.hostname} — {log.message}
          </li>
        ))}
      </ul>

      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}

      <button onClick={resetToFirstPage}>Reset</button>
    </div>
  );
}
```

Each page fetches `LOGS_PAGE_SIZE` entries at a time; `resetToFirstPage` clears the cached query so the next fetch starts from the first page (useful after changing filters or triggering a refresh).
