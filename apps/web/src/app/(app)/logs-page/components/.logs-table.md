## logs-table.tsx

Client-rendered Relay-backed logs table component with pagination, filtering (tool type, severity, organization, date range), search, and a detail drawer. Wraps the shared `LogsTableView` presentation component with GraphQL data fetching, loading-scope awareness, and parent-triggered refresh via an imperative ref.

## Key Components

- **`LogsTableContent`** — Outer wrapper establishing a `LoadingSuspense` boundary so the table draws its own loading rows while scoped.
- **`LogsTableContentReader`** — Detects loading scope (`useLoadingScope`) and renders a skeleton `LogsTableView` or delegates to the live reader.
- **`LogsTableContentLive`** — Core data-fetching component using `useLazyLoadQuery` and `usePaginationFragment` to load logs, derive filter facets, transform rows, handle pagination (`fetchNextPage`), and expose `resetToFirstPage` via `onRefreshRef`.
- **`logsTableRelayQuery` / `logsTableRelayFragment`** — GraphQL query and `@refetchable` fragment definitions for paginated log connections and `logFilters` facets.
- **`LogsTableProps` / `LogsTableRef`** — Public props (device/organization scoping, embedding, header visibility) and the imperative `refresh()` handle.
- **`LogRow`** — Table row type extending `UiLogEntry` with the original fragment-bearing `originalLogEntry` for the copy button and drawer.
- **`renderCopyAction` / `renderEmptyState`** — Render-prop helpers passed to `LogsTableView` for row actions and onboarding empty states.

## Usage Example

```typescript
import { forwardRef, useRef } from 'react';
import { LogsTable, type LogsTableRef } from './logs-table';

function DeviceLogsTab({ deviceId }: { deviceId: string }) {
  const tableRef = useRef<LogsTableRef>(null);

  return (
    <div>
      <button onClick={() => tableRef.current?.refresh()}>Refresh Logs</button>
      <LogsTable
        ref={tableRef}
        deviceId={deviceId}
        deviceScoped
        embedded
        showHeader={false}
      />
    </div>
  );
}
```

Scoped to an organization (hides the organization filter column):

```typescript
<LogsTable organizationId="org-123" />
```
