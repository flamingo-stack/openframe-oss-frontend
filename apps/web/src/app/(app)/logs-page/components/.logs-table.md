## logs-table.tsx

Renders the paginated, filterable logs table using Relay GraphQL for data fetching, with support for device-scoped views, organization locking, and embedded display modes. It wraps the shared `LogsTableView` from the `openframe-frontend-core` package with app-specific pagination, search, sorting, and drawer-based log detail viewing.

## Key Components

- **`LogsTable`** (forwarded ref component) — Top-level entry point; manages search params, date filters, sort state, and mobile filter modal, exposing a `refresh()` method via `LogsTableRef`.
- **`LogsTableContent`** — Wraps the live content in a `LoadingSuspense` boundary, deferring to loading-scope rendering when the table is embedded in a still-loading parent.
- **`LogsTableContentReader`** — Detects loading scope (`useLoadingScope`) and renders either a skeleton `LogsTableView` or the live, data-connected component.
- **`LogsTableContentLive`** — Core Relay-powered component: issues `logsTableRelayQuery`, paginates via `usePaginationFragment`, maps GraphQL nodes to `LogRow`s, handles `fetchNextPage`/`resetToFirstPage`, and syncs a refresh callback to the parent via ref.
- **`LogRow`** — Interface extending `UiLogEntry` with `originalLogEntry` (raw GraphQL node) for copy-button and drawer fragments.
- **`LogsTableProps` / `LogsTableRef`** — Public prop and ref contracts (`deviceId`, `deviceScoped`, `organizationId`, `embedded`, `showHeader`, `refresh`).
- **GraphQL definitions** — `logsTableRelayQuery` (root query with `logFilters` facets) and `logsTableRelayFragment` (`@refetchable` connection fragment for paginated logs).

## Usage Example

```typescript
import { useRef } from 'react';
import { LogsTable, type LogsTableRef } from '@/app/components/logs-table';

function DeviceLogsTab({ deviceId }: { deviceId: string }) {
  const tableRef = useRef<LogsTableRef>(null);

  return (
    <div>
      <button onClick={() => tableRef.current?.refresh()}>
        Refresh Logs
      </button>
      <LogsTable
        ref={tableRef}
        deviceId={deviceId}
        deviceScoped
        embedded
        showHeader={false}
      />
    </div>
  );
}
```
