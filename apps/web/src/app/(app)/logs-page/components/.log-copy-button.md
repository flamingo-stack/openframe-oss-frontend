# log-copy-button.tsx

Client component rendering a "Copy Log Details" icon button for a table row, which fetches the full log details on-demand and copies a formatted representation to the clipboard.

## Key Components

- **`logCopyButtonFragment`** — GraphQL fragment on `LogEvent` that extracts the composite key fields (`toolEventId`, `ingestDay`, `toolType`, `eventType`, `timestamp`) needed to identify a log row, without requiring the full log payload to be loaded upfront.
- **`logCopyButtonQuery`** — GraphQL query that fetches `logDetails` (message + raw details) for a given log, using the composite key. Shares the same `logDetails` field used by the log drawer and log-details page, enabling Relay store reuse.
- **`LogCopyButton`** — React component that:
  - Resolves the composite key via `useFragment`.
  - On click, runs `fetchQuery` with `fetchPolicy: 'store-or-network'` so already-fetched logs copy instantly from the Relay store.
  - Formats the result via `formatLogDetailsRefForCopy` and copies it using `useCopyToClipboard`.
  - Shows an error toast on failure and manages a loading/copied state passed to `LogCopyIconButton`.

## Usage Example

```typescript
import { LogCopyButton } from '@/app/components/log-copy-button';
import type { logCopyButton_log$key } from '@/__generated__/logCopyButton_log.graphql';

function LogTableRow({ log }: { log: logCopyButton_log$key }) {
  return (
    <tr>
      <td>{/* other log columns */}</td>
      <td>
        <LogCopyButton log={log} />
      </td>
    </tr>
  );
}
```

The parent query must spread `...logCopyButton_log` on the `LogEvent` type to supply the fragment reference.
