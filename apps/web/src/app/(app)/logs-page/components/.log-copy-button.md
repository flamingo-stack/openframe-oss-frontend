A "Copy Log Details" button component for log table rows that lazily fetches full log details on click before copying them to the clipboard.

## Key Components

### `LogCopyTarget` (interface)
Identifies a log entry with the minimum fields required to fetch its full details:
- `toolEventId` — unique event identifier
- `ingestDay` — partition/date key for the log
- `toolType` — source tool type
- `eventType` — category of the event
- `timestamp` — event timestamp

### `LogCopyButton` (component)
A table-row action button that:
1. Fetches full log details on demand via `useLogDetails().fetchLogDetailsById`
2. Formats the result using `formatLogDetailsForCopy`
3. Writes the formatted string to the clipboard via `useCopyToClipboard`
4. Toggles between `Copy02Icon` and `CheckIcon` to confirm the copy action
5. Disables itself while the fetch is in flight (`isLoading`)

## Usage Example

```typescript
import { LogCopyButton, type LogCopyTarget } from './log-copy-button';

const logEntry: LogCopyTarget = {
  toolEventId: 'evt_abc123',
  ingestDay: '2024-01-15',
  toolType: 'connectwise',
  eventType: 'ticket.created',
  timestamp: '2024-01-15T10:30:00Z',
};

// Render inside a table row actions cell
<LogCopyButton log={logEntry} />
```

## Notes
- Marked `'use client'` — renders only on the client side.
- Copy errors are surfaced as toasts inside `fetchLogDetailsById`; the `catch` block is intentionally silent to avoid duplicate error messaging.
