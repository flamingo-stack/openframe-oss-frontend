# log-copy-button.tsx

A table-row "Copy Log Details" button component that lazily fetches full log details on click and copies them to the clipboard, reusing Relay's store when possible.

## Key Components

- **`logCopyButtonFragment`** — GraphQL fragment on `LogEvent` that extracts the composite key fields (`toolEventId`, `ingestDay`, `toolType`, `eventType`, `timestamp`) needed to look up full log details. Note: the fragment only carries the key, not the full log payload.
- **`logCopyButtonQuery`** — GraphQL query that resolves `logDetails` using the composite key, spreading the `formatLogDetails_log` fragment for consistent formatting with the drawer and log-details page.
- **`LogCopyButton`** — React component that renders a `LogCopyIconButton`. On click, it:
  1. Fetches `logDetails` via `fetchQuery` with `store-or-network` policy (reuses cached data if the drawer already loaded it).
  2. Formats the result using `formatLogDetailsRefForCopy`.
  3. Copies formatted text to the clipboard via `useCopyToClipboard`.
  4. Shows a destructive toast on failure via `useToast` and `getRelayErrorMessage`.

## Usage Example

```typescript
import { LogCopyButton } from './log-copy-button';
import { useFragment } from 'react-relay';

function LogRow({ logRef }: { logRef: logCopyButton_log$key }) {
  return (
    <tr>
      <td>{/* other log columns */}</td>
      <td>
        <LogCopyButton log={logRef} />
      </td>
    </tr>
  );
}
```

The `log` prop must be a Relay fragment reference (`logCopyButton_log$key`) spread from a parent query or fragment that includes the `logCopyButton_log` fragment on the `LogEvent` type. The component handles its own loading and copied states internally, requiring no additional wiring from the parent.
