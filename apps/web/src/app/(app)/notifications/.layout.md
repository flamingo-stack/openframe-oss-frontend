Defines metadata and layout re-export for the Notifications route segment in a Next.js App Router application.

## Key Components

- **`metadata`** — A `Metadata` object (Next.js convention) that sets the page's document title using the `routeTitle` helper, producing a consistent "Notifications" title for this route segment.
- **Default export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, allowing this route to use a common layout without duplicating implementation.

## Usage Example

This file follows the Next.js App Router convention where `layout.tsx` co-located within a route folder automatically applies to that segment and its children. You typically don't import it directly; Next.js picks it up based on file location:

```typescript
// File location: app/(app)/notifications/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Notifications') };
```

The `routeTitle` helper standardizes title formatting (e.g., appending a brand suffix), ensuring every route in the app has a consistent `<title>` tag without repeating boilerplate logic. Reusing `route-title-layout` as the default export avoids duplicating layout markup across similar routes, keeping navigation shells, headers, or wrappers centralized in one place.
