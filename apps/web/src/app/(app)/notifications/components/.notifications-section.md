## notifications-section.tsx

This file implements the notifications list section used across the notifications feature, rendering a searchable, paginated, infinite-scroll table of notifications (unread or read variants) backed by a Relay pagination fragment, with sticky search/toolbar UI and Suspense-based loading states.

## Key Components

- **`NotificationsSection`** — Top-level component rendering the page layout, sticky search toolbar (plain `Input` or `TagSearchInput` when scoped to an entity), and the notifications table. Hides the search bar only for the genuine empty state (no search, no scope).
- **`NotificationsScope`** — Interface describing a single-entity scope chip (label + clear handler) used to narrow the list to one entity.
- **`SectionTable`** — Wraps the data-fetching reader in a `LoadingSuspense` boundary with a context-aware loading label.
- **`SectionTableReader`** — Decides between loading placeholder table, fallback-wrapped loading table, or the live Relay-backed table, based on `useLoadingScope()` and `queryRef` availability.
- **`SectionTableLive`** — Reads the preloaded Relay query (`usePreloadedQuery`) and paginates via `usePaginationFragment`, maps GraphQL nodes to `NotificationRow`, handles `loadNext` with toast error reporting, and reports empty state upward.
- **`SectionTableLoading`** — Renders the table shell with no rows for pre-query loading states.
- **`SectionTableView`** — Pure, prop-driven table renderer using `useDataTable`, building columns via `buildNotificationColumns`, rendering approval sub-rows (`NotificationApprovalSubRow`) for approval-type notifications, and generating placeholder rows while loading.
- **`NOTIFICATIONS_SECTION_PAGE_SIZE`** — Constant page size (50) for pagination and placeholder row count.

## Usage Example

```typescript
<NotificationsSection
  title="Notifications"
  queryRef={preloadedQueryRef}
  searchValue={searchValue}
  onSearchChange={setSearchValue}
  rowVariant="unread"
  onMarkRead={id => markAsRead(id)}
  onDelete={id => deleteNotification(id)}
  scope={{ label: 'Device: server-01', onClear: () => setEntityFilter(null) }}
  actions={[{ label: 'Mark all read', onClick: handleMarkAllRead }]}
/>
```

The component expects a Relay `PreloadedQuery` from `notificationsSectionRelayQuery` and integrates with `useStickyToolbar` for scroll-aware header positioning and `LoadingSuspense`/`useLoadingScope` for consistent skeleton states across the app.
