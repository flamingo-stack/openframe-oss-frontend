Renders a paginated, searchable notifications list section with support for unread/read variants, infinite scroll loading, approval sub-rows, and contextual empty states.

## Key Components

- **`NotificationsSection`** — Top-level exported component. Accepts a Relay `PreloadedQuery`, search state, and action buttons. Manages empty state visibility and conditionally renders the search input.
- **`SectionTable`** — Internal component that resolves the Relay query/fragment, maps edges to `NotificationRow` objects and hands them, with the next page's `InfiniteScroll`, to `SectionTableView`.
- **`SectionTableView`** — Exported, props-only table: the shared `LiveTable` (sticky header with the row count, body with approval sub-rows, infinite footer). In a loading scope it draws one full page of skeleton rows.
- **`SectionTableLoading`** — The section before its query answers: `SectionTableView` with no rows and no next page, the Suspense fallback (inside `LoadingSuspense`) and the body while no `queryRef` exists yet (inside `LoadingFallback`).
- **`NOTIFICATIONS_SECTION_PAGE_SIZE`** — Exported constant: the Relay page size, and the full page of rows the loading table draws.

## Usage Example

```typescript
import { NotificationsSection, NOTIFICATIONS_SECTION_PAGE_SIZE } from './notifications-section';
import { useQueryLoader } from 'react-relay';
import { notificationsSectionRelayQuery } from '@/graphql/notifications/notifications-section-relay';

function UnreadTab() {
  const [queryRef, loadQuery] = useQueryLoader(notificationsSectionRelayQuery);
  const [search, setSearch] = useState('');

  useEffect(() => {
    loadQuery({ first: NOTIFICATIONS_SECTION_PAGE_SIZE, search });
  }, [search]);

  return (
    <NotificationsSection
      title="Notifications"
      queryRef={queryRef}
      searchValue={search}
      onSearchChange={setSearch}
      rowVariant="unread"
      onMarkRead={(id) => markAsRead(id)}
      onDelete={(id) => deleteNotification(id)}
    />
  );
}
```

## Notes

- The search input is hidden when the list is genuinely empty (no active search query), following the empty-state UX convention.
- Approval notifications automatically expand a `NotificationApprovalSubRow` beneath their row.
- Read-variant sections display a 30-day history retention notice at the bottom.
