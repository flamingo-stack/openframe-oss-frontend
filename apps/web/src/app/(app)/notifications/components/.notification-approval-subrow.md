Renders the expandable approval sub-row shown beneath an approval-request notification, displaying the proposed commands/explanation and letting the user approve or reject it inline with optimistic UI feedback.

## Key Components

- **`NotificationApprovalSubRowProps`** — Props interface: `notification` (nullable, triggers a loading state when `null`) and optional `onResolved` callback fired after a successful decision.
- **`NotificationApprovalSubRow`** — Main component that:
  - Extracts approval metadata from the notification via `getApprovalMeta`.
  - Converts resolution data to a `ChatApprovalStatus` via `resolutionToStatus`, falling back to local optimistic state (`localStatus`) when the backend hasn't resolved yet.
  - Builds display data with `approvalMetaToBatchData`, memoized on `approval`.
  - Exposes a `decide` callback that optimistically updates status, calls `useApproveRequest`, and rolls back on failure.
  - Renders `ApprovalBatchMessage` with the derived status, approve/reject handlers, and a loading variant when `notification` is `null`.

## Usage Example

```typescript
import { NotificationApprovalSubRow } from '@/app/components/notifications/notification-approval-subrow';

function NotificationRow({ notification, markAsRead }: { notification: Notification; markAsRead: (id: string) => void }) {
  return (
    <div>
      {/* ...row header/summary... */}
      <NotificationApprovalSubRow
        notification={notification}
        onResolved={(id) => markAsRead(id)}
      />
    </div>
  );
}

// While data is loading, pass null to show the sub-row's own loading state:
<NotificationApprovalSubRow notification={null} />
```

This component is designed to be used inside an expandable notification list row where the notification type is an approval request, handling both the pending and loading states internally.
