Defines the column configuration for the notifications data table, providing cell renderers for notification content, details, action buttons, and row-level controls (mark-as-read / delete).

## Key Components

### `NotificationRow`
Data shape consumed by the table. Flattens the core `Notification` object alongside display-ready fields (`title`, `description`, `createdAt`, `read`).

### `buildNotificationColumns(args)`
Factory function that returns a `ColumnDef<NotificationRow>[]` array. Accepts:

| Argument | Type | Purpose |
|---|---|---|
| `rowVariant` | `'unread' \| 'read'` | Switches the row icon between a mark-done button and a delete button |
| `onMarkRead` | `(id: string) => void` | Called when marking a notification read |
| `onDelete` | `(id: string) => void` | Called when deleting a read notification |

**Columns produced:**

| ID | Description |
|---|---|
| `notification` | Category icon, severity-tinted title, relative timestamp; collapses with description on mobile |
| `details` | Full title (when a `type` label is present) and description text; hidden below `md` breakpoint |
| `action` | `SplitButton` (desktop) / icon `Button` (mobile) that opens a route link or Mingo drawer dialog |
| `rowIcon` | `CheckCircleIcon` for unread rows, `TrashIcon` for read rows |

## Usage Example

```typescript
import { buildNotificationColumns } from '@/app/components/notifications/notifications-columns';

const columns = buildNotificationColumns({
  rowVariant: 'unread',
  onMarkRead: (id) => markNotificationRead(id),
  onDelete: (id) => deleteNotification(id),
});

// Pass to your data table component
<DataTable columns={columns} data={notificationRows} />
```
