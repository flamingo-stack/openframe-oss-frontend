Provides a helper for generating human-readable scope labels used in notification filtering UI, mapping entity types to display names and optionally combining them with an entity's name.

## Key Components

- **`ENTITY_KIND`**: An internal record mapping each `NotificationEntityType` (`DEVICE`, `INSIGHT`, `TICKET`, `DIALOG`) to its display label (`Device`, `Incident`, `Ticket`, `Chat`).
- **`entityScopeLabel(type, name)`**: Exported function that returns a formatted label for a notification entity scope. If a `name` is provided, it returns `"Kind: Name"`; otherwise it returns just the `Kind`.

## Usage Example

```typescript
import { entityScopeLabel } from './entity-scope-label';

// With a specific entity name
entityScopeLabel('DEVICE', 'MacBook Pro-01');
// => "Device: MacBook Pro-01"

entityScopeLabel('TICKET', 'Printer not working');
// => "Ticket: Printer not working"

// Without a name - falls back to just the kind label
entityScopeLabel('INSIGHT', '');
// => "Incident"

entityScopeLabel('DIALOG', '');
// => "Chat"
```

This is typically used to render a chip or badge in a notifications panel, indicating which entity (device, incident, ticket, or chat) the current notification list is scoped to, including the specific entity's name when the navigation link to the list included one.
