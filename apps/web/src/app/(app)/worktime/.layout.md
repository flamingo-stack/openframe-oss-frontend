Defines the page metadata and layout wrapper for the Worktime route, setting the document title and re-exporting the shared route title layout component.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title to `"Worktime"` using the `routeTitle` helper, ensuring consistent title formatting across the app.
- **`default` export** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, used as the layout for this route segment.

## Usage Example

This file is automatically picked up by Next.js as the layout for the `Worktime` route segment. No manual import is needed; Next.js uses it based on file conventions.

```typescript
// Next.js automatically applies this layout and metadata
// to all pages within the Worktime route segment.

// Example of the routeTitle helper used internally:
import { routeTitle } from '@/lib/route-title';

const title = routeTitle('Worktime');
// => "Worktime | <App Name>" (format depends on routeTitle implementation)
```

Place this file within the appropriate route folder (e.g., `app/(app)/worktime/layout.tsx`) to automatically apply the title metadata and shared layout to that route and its children.
