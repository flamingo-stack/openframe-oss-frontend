A client-side React view component that renders the Worktime management page, providing a layout with an "Add Work Time" action and a work time table with employee and customer columns visible.

## Key Components

- **`WorktimeView`** — Main page view component that composes `PageLayout` and `WorkTimeTable` with controlled modal state for adding work time entries.

## Usage Example

```typescript
import { WorktimeView } from '@/app/components/worktime-view';

// Used as a page-level component in the app router
export default function WorktimePage() {
  return <WorktimeView />;
}
```

## Behavior

- Manages `addWorkTimeOpen` boolean state to control the add work time modal visibility.
- Passes an `actions` array to `PageLayout` rendering a `PlusCircleIcon` button that triggers the modal.
- Renders `WorkTimeTable` with `showEmployee` and `showCustomer` flags enabled, surfacing both columns in the table view.
- Uses CSS custom properties (`--spacing-system-l`) for consistent system-level padding.
