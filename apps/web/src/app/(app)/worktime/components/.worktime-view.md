# worktime-view.tsx

A page-level component that renders the Worktime management screen, combining a page header with an "Add Work Time" action and a table listing work time entries.

## Key Components

- **`WorktimeView`** — Default exported React component (client component) that composes `PageLayout` and `WorkTimeTable` to display the worktime page.
- **`addWorkTimeOpen` state** — Local boolean state controlling visibility of the "add work time" dialog/panel, shared with `WorkTimeTable` via props.
- **`actions`** — Array defining the page-level action button ("Add Work Time") rendered by `PageLayout`, using `PlusCircleIcon` from `icons-v2` (chosen specifically because it supports `currentColor` fill, unlike the legacy `icons` package).

## Usage Example

```typescript
import { WorktimeView } from '@/app/components/worktime-view';

export default function WorktimePage() {
  return <WorktimeView />;
}
```

The component requires no props. It internally manages the "Add Work Time" dialog open state and passes `showEmployee` and `showCustomer` flags to `WorkTimeTable` so that both employee and customer columns/filters are displayed in the table.

**Notes:**
- Uses `PageLayout` from `@flamingo-stack/openframe-frontend-core/components/ui` with `actionsVariant="primary-buttons"` to style the action button prominently.
- Custom padding is applied via CSS variables (`--spacing-system-l`) for consistent spacing with the design system.
- The icon's fill color (`text-ods-text-secondary`) can be muted because `icons-v2` icons use `currentColor` instead of hardcoded fills.
