Resolves the display email for a customer by selecting the first non-empty value from a list of contact email addresses.

## Key Components

- **`customerContactEmail(emails)`** - Pure function that accepts an array of nullable/undefined email strings and returns the first truthy one found, or `undefined` if none exist (or the input itself is `null`/`undefined`).

## Usage Example

```typescript
import { customerContactEmail } from './customer-contact-email';

// Typical case: first contact has no email, second does
const email = customerContactEmail([null, 'jane@example.com', 'john@example.com']);
// => 'jane@example.com'

// No valid emails present
const noEmail = customerContactEmail([null, undefined, '']);
// => undefined

// Input itself is missing
const missing = customerContactEmail(undefined);
// => undefined
```

**Intended usage pattern:** callers should query the `email` field from each of a customer's contacts and pass the resulting array of addresses (not the full contact objects) into this function. This keeps the data dependency explicit at each call site, making it clear that `email` is the field being read from the underlying query/schema.
