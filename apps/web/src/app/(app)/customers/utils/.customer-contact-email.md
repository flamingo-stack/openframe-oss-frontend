Utility function that resolves the display email for a customer by selecting the first non-empty email address from a list of contact emails.

## Key Components

- **`customerContactEmail(emails)`** — Accepts an array of email strings (which may individually be `null`/`undefined`) or a `null`/`undefined` array itself, and returns the first truthy email found, or `undefined` if none exist.

## Usage Example

```typescript
import { customerContactEmail } from './customer-contact-email';

// Standard case: pick the first valid email
const email = customerContactEmail(['', null, 'contact@example.com', 'other@example.com']);
// => 'contact@example.com'

// No valid emails present
const noEmail = customerContactEmail([null, undefined, '']);
// => undefined

// Entire array is missing
const missing = customerContactEmail(undefined);
// => undefined
```

This function is designed to work with a list of **addresses** (the `email` field values) rather than full contact objects. This ensures that any code calling it must explicitly query/select the `email` field from each contact, making the data dependency clear at the call site rather than hidden inside this utility.
