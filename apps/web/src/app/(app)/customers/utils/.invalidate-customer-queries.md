Utility function that invalidates all React Query caches related to a customer record, ensuring that customer lists, dashboard counters, and individual customer detail views are refreshed after a create, update, or delete operation.

## Key Components

- **`invalidateCustomerQueries(queryClient, organizationId)`** - Async function that invalidates:
  - The full customers list cache (`customersQueryKeys.all`)
  - The dashboard counters cache (`dashboardQueryKeys.all`)
  - The specific customer's detail cache (`customerDetailsQueryKeys.detail(organizationId)`), only when `organizationId` is provided (non-null)

All invalidations run concurrently via `Promise.all` and the function returns a promise that resolves once every cache has been invalidated.

## Usage Example

```typescript
import { useQueryClient } from '@tanstack/react-query';
import { invalidateCustomerQueries } from './invalidate-customer-queries';

async function saveCustomer(organizationId: string | null) {
  const queryClient = useQueryClient();

  // ... perform create/update/delete mutation ...

  // Ensure caches are fresh before navigating away
  await invalidateCustomerQueries(queryClient, organizationId);

  navigateToCustomerList();
}
```

**Note:** Pass `null` for `organizationId` when creating a new customer (no existing detail cache to invalidate), or the customer's ID when editing an existing record to also refresh its detail view.
