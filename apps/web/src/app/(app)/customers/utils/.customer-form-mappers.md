# customer-form-mappers.ts

Mapping utilities that translate between the API-shaped `CustomerDetails` record, the form's internal `CustomerFormData` state, and the `CreateCustomerRequest` write payload. These functions handle the impedance mismatch between what the form edits and what the backend expects, including fields that are preserved but not user-editable.

## Key Components

- **`PreservedCustomerFields`** — Interface for fields the form doesn't expose (category, employee count, revenue, contract dates) but which must be echoed back on every write request.
- **`DEFAULT_PRESERVED_FIELDS`** — Default/empty values for `PreservedCustomerFields`, used when creating a new customer with no existing record.
- **`toPreservedFields(organization)`** — Extracts preserved fields from a live `CustomerDetails` record, normalizing dates to `YYYY-MM-DD` and empty strings to `undefined`.
- **`isBlankContact(contact)`** — Predicate that checks whether a `ContactPersonDto` has no populated fields (used to filter placeholder/empty rows).
- **`recordToForm(organization)`** — Converts a `CustomerDetails` record into `CustomerFormData`. Infers the "mailing same as physical" checkbox by comparing addresses, and seeds one empty contact row if the record has no real contacts.
- **`formToWriteInput(data, preserved)`** — Builds the `CreateCustomerRequest` payload from form data plus preserved fields. Trims name/website, omits blank optional fields, and resolves the mailing address based on the "same as physical" flag.

## Usage Example

```typescript
import {
  recordToForm,
  toPreservedFields,
  formToWriteInput,
  DEFAULT_PRESERVED_FIELDS,
} from './customer-form-mappers';

// Loading an existing customer into the edit form
const formData = recordToForm(customerDetails);
const preserved = toPreservedFields(customerDetails);

// On submit, rebuild the write payload
const request = formToWriteInput(formData, preserved);
await createCustomer(request);

// Creating a brand-new customer (no preserved record yet)
const newRequest = formToWriteInput(blankFormData, DEFAULT_PRESERVED_FIELDS);
```
