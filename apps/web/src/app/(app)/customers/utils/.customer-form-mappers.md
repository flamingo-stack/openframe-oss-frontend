# customer-form-mappers.ts

Mapping utilities that translate between the live `CustomerDetails` record, the editable `CustomerFormData` used by the customer form, and the `CreateCustomerRequest` write payload sent to the API. These mappers isolate the form from API shape details, including fields the form doesn't edit directly but must still round-trip on submit.

## Key Components

- **`PreservedCustomerFields`** - Interface for fields the form never edits (category, employee count, revenue, contract dates) but the write endpoint requires on every call.
- **`DEFAULT_PRESERVED_FIELDS`** - Default/empty preserved field values for new or not-yet-loaded records.
- **`toPreservedFields(organization)`** - Extracts preserved fields from a `CustomerDetails` record, normalizing dates to `YYYY-MM-DD` via the internal `toDateOnly` helper.
- **`isBlankContact(contact)`** - Predicate that returns `true` when a contact row has no name, title, phone, or email.
- **`recordToForm(organization)`** - Converts a `CustomerDetails` record into `CustomerFormData`. Infers the "mailing same as physical" checkbox by comparing addresses, filters out blank contacts, and seeds a single empty contact row (`EMPTY_CONTACT_ROW`) when no contacts remain.
- **`formToWriteInput(data, preserved)`** - Builds a `CreateCustomerRequest` from form data plus preserved fields. Trims `name`/`website`, omits blank optional fields, filters blank contacts, and builds address DTOs via the internal `buildAddressDto` helper.

## Usage Example

```typescript
import {
  recordToForm,
  formToWriteInput,
  toPreservedFields,
  DEFAULT_PRESERVED_FIELDS,
} from './customer-form-mappers';

// Loading an existing customer into the form
const formData = recordToForm(customerDetails);
const preserved = toPreservedFields(customerDetails);

// On submit, rebuild the API payload
const payload = formToWriteInput(formData, preserved);
await createCustomer(payload);

// For a brand-new customer, fall back to defaults
const newPreserved = DEFAULT_PRESERVED_FIELDS;
```
