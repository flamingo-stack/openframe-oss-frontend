## Purpose

Maps the raw `OrganizationNode` GraphQL response (from the legacy `/api/graphql` raw-POST route) into a normalized `CustomerDetails` view-model used by the customer details/edit pages.

## Key Components

- **`CustomerDetails`** — View-model interface consumed by UI pages, including formatted addresses, contact list, and financial fields.
- **`OrganizationAddressNode`** — Raw address shape returned by the API (street, city, state, etc.).
- **`OrganizationContactNode`** — Raw contact shape returned by the API.
- **`OrganizationNode`** — Raw organization node shape as returned by the legacy GraphQL query; only includes fields the mapper actually reads.
- **`formatAddress(addr)`** — Joins non-empty address parts into a single comma-separated string.
- **`toContactDto(contact)`** — Converts a raw `OrganizationContactNode` into a `ContactPersonDto`, defaulting missing fields to empty strings.
- **`mapOrganization(org)`** — Pure function that transforms an `OrganizationNode` into a `CustomerDetails` object, normalizing nullable fields, formatting addresses, and mapping contacts.

## Usage Example

```typescript
import { mapOrganization, type OrganizationNode } from './map-organization';

const rawOrg: OrganizationNode = {
  id: '1',
  organizationId: 'org-123',
  name: 'Acme Corp',
  category: 'Retail',
  numberOfEmployees: 50,
  contactInformation: {
    physicalAddress: { street1: '123 Main St', city: 'Springfield', state: 'IL' },
    contacts: [{ contactName: 'Jane Doe', email: 'jane@acme.com' }],
  },
};

const customer = mapOrganization(rawOrg);
// customer.physicalAddress === '123 Main St, Springfield, IL'
// customer.contacts === [{ contactName: 'Jane Doe', title: '', phone: '', email: 'jane@acme.com' }]
```

**Important:** The `contacts` array is round-tripped wholesale by the edit form — any contact omitted from this list when saving (`PUT /api/organizations/{id}`) will be deleted on the backend.
