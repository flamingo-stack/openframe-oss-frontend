# customer-form-fields.tsx

Renders the shared field set for creating/editing a customer record (name, website, notes, physical/mailing address, and contacts), wired to a `react-hook-form` instance. Used by both the create and edit customer pages so form behavior stays consistent across them.

## Key Components

- **`CustomerFormFields`** — Main exported component that renders all customer form fields using `Controller` bindings into the passed `form` instance.
- **`CustomerFormFieldsProps`** — Props interface:
  - `form: UseFormReturn<CustomerFormData>` — the react-hook-form instance to bind to.
  - `disabled: boolean` — disables all input controls (used as a loading state on the edit page).
  - `showErrors: boolean` — gates whether inline validation errors are displayed (toggled after first Save attempt).
  - `logoSlot?: ReactNode` — optional slot for a logo uploader, rendered beside name/website on wide screens.
- **`ADDRESS_PLACEHOLDER`** — Shared placeholder string for address inputs.

Notable behavior:
- The "Mailing Address Same as Physical" checkbox mirrors the physical address into the mailing address field synchronously on each keystroke (no `useEffect`), avoiding lag between the two fields.
- `disabled` is applied to the underlying input components rather than the `Controller`, since a disabled `Controller` field is stripped from submitted form data and ignores `setValue`.
- Delegates contact fields to `CustomerContactsFields`.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { CustomerFormFields } from './customer-form-fields';
import type { CustomerFormData } from '../types/customer-form.types';

function CustomerFormPage() {
  const form = useForm<CustomerFormData>({
    defaultValues: {
      name: '',
      website: '',
      notes: '',
      physicalAddress: '',
      mailingAddress: '',
      mailingSameAsPhysical: false,
    },
  });

  const [showErrors, setShowErrors] = useState(false);
  const isLoading = false;

  const onSubmit = form.handleSubmit(
    data => console.log(data),
    () => setShowErrors(true)
  );

  return (
    <form onSubmit={onSubmit}>
      <CustomerFormFields
        form={form}
        disabled={isLoading}
        showErrors={showErrors}
        logoSlot={<LogoUploader />}
      />
      <button type="submit">Save</button>
    </form>
  );
}
```
