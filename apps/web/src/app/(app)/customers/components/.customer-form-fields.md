Renders the shared form body for creating/editing a customer record, binding `react-hook-form` controllers to the core UI inputs (name, website, notes, addresses, contacts) and an optional logo slot.

## Key Components

- **`CustomerFormFields`** — Main component rendering the full customer form layout (name/website/logo row, notes, address fields, mailing-same-as-physical checkbox, and contacts section via `CustomerContactsFields`).
- **`CustomerFormFieldsProps`** — Props interface:
  - `form`: `UseFormReturn<CustomerFormData>` instance from the parent.
  - `disabled`: disables all controls (used while loading, e.g. on the edit page).
  - `showErrors`: toggles inline validation error display (only after first Save attempt).
  - `logoSlot`: optional `ReactNode` for a logo uploader (SaaS-only), shown beside name/website on wide screens.
- **`ADDRESS_PLACEHOLDER`** — Shared placeholder text for physical/mailing address inputs.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { CustomerFormFields } from './customer-form-fields';
import type { CustomerFormData } from '../types/customer-form.types';

function CustomerEditPage() {
  const form = useForm<CustomerFormData>({
    defaultValues: {
      name: '',
      website: '',
      notes: '',
      physicalAddress: '',
      mailingAddress: '',
      mailingSameAsPhysical: false,
    },
  });

  const [showErrors, setShowErrors] = useState(false);
  const isLoading = false;

  return (
    <form onSubmit={form.handleSubmit(() => setShowErrors(true))}>
      <CustomerFormFields
        form={form}
        disabled={isLoading}
        showErrors={showErrors}
        logoSlot={<LogoUploader />}
      />
    </form>
  );
}
```

**Notes:**
- The `disabled` prop is applied only to the rendered input controls, never to the `Controller` itself, to avoid react-hook-form stripping disabled fields from submission or ignoring `setValue` calls.
- Mailing address mirrors physical address synchronously (within the same `onChange`/`onCheckedChange` event) to avoid a one-keystroke lag between fields.
