Provides a full-page loading skeleton for the `CustomerDetailsView`, composing responsive placeholder components that mirror the real page's header, tab navigation, and per-tab content layouts.

## Key Components

| Export | Description |
|---|---|
| `CustomerDetailsSkeleton` | Root skeleton component; composes header, tab nav, and active-tab content |
| `CustomerHeaderSkeleton` | Mirrors `TitleBlock` with logo, title, subtitle, and responsive action buttons |
| `CustomerTabNavigationSkeleton` | Four-tab navigation bar with icon + label placeholders |
| `CustomerDetailsTabSkeleton` | Info card skeleton with website row and dual address cells |
| `CustomerDevicesTabSkeleton` | Table skeleton pre-configured with Devices column layout |
| `CustomerTicketsTabSkeleton` | Table skeleton pre-configured with Tickets column layout |
| `CustomerLogsTabSkeleton` | Table skeleton pre-configured with Logs column layout |
| `getCustomerTabSkeleton` | Utility that returns the correct tab skeleton by `activeTab` string |

**Internal helpers:**
- `TabTitleSkeleton` — inline section title with optional action button placeholder
- `makeTableTabSkeleton` — factory that produces a `DataTable`-backed skeleton matching a given column schema 1:1

## Usage Example

```typescript
// Full-page skeleton — render while customer data is loading
import { CustomerDetailsSkeleton } from './customer-details-skeleton';

// Default to devices tab
<CustomerDetailsSkeleton />

// Match the currently active tab
<CustomerDetailsSkeleton activeTab="tickets" />

// Render individual skeletons independently
import {
  CustomerHeaderSkeleton,
  CustomerTabNavigationSkeleton,
  getCustomerTabSkeleton,
} from './customer-details-skeleton';

<CustomerHeaderSkeleton />
<CustomerTabNavigationSkeleton />
{getCustomerTabSkeleton('logs')}
```

Accepted `activeTab` values: `"devices"` (default), `"tickets"`, `"logs"`, `"details"`.
