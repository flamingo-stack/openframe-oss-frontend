Renders a tabbed navigation interface for switching between Active and Archived customer views, with optional URL-synced tab state via query parameters.

## Key Components

- **`CUSTOMERS_TABS`** — Static array of `TabItem` configs defining the "Active Customers" and "Archived Customers" tabs, each with an icon and a bound `CustomersTable` component.
- **`ActiveCustomers`** / **`ArchivedCustomers`** — Internal wrapper components that render `CustomersTable` with the appropriate `status` prop (`"ACTIVE"` or `"ARCHIVED"`).
- **`CustomersTabNavigation`** — Primary exported component that renders the `TabNavigation` UI. Accepts an optional controlled `activeTab` and `onTabChange` handler; falls back to URL-based tab switching via `router.replace` when no handler is provided.

## Usage Example

```typescript
// Uncontrolled — tab state synced to URL query param (?tab=active)
<CustomersTabNavigation />

// Controlled — manage tab state externally
const [tab, setTab] = useState('active');

<CustomersTabNavigation
  activeTab={tab}
  onTabChange={(newTab) => setTab(newTab)}
/>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `activeTab` | `string` | `'active'` | Currently selected tab ID |
| `onTabChange` | `(tab: string) => void` | URL replace | Callback fired on tab switch |

## Notes

- `urlSync` on `TabNavigation` is set to `false`; URL state is managed manually via `router.replace` to keep the `?tab=` query param in sync.
- Tab IDs are `"active"` and `"archived"` — these must match any routing logic that reads the `?tab=` param.
