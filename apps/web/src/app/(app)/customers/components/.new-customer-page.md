Client-side page component for creating and editing customer (organization) records, supporting multi-tab editing with AI configuration, guardrails, and image upload capabilities.

## Key Components

### `NewCustomerPage`
Main page component accepting `organizationId` (null for new customers). Handles both create and edit flows with URL-controlled tab navigation.

### Interfaces
- **`FormState`** — Core customer fields: name, website, notes, addresses, image
- **`PreservedFields`** — Additional org fields preserved across edits (contacts, revenue, contract dates)
- **`NewCustomerPageProps`** — Component props with optional `organizationId`

### Helper Utilities
- **`buildAddressDto`** — Converts raw address string to address DTO structure
- **`stripPlaceholder`** — Sanitizes placeholder values (`'-'`) to empty strings
- **`contactToDto`** — Maps contact object to API DTO shape

### Tab System
Three tabs driven by `TAB_IDS.customerEdit`: `Details`, `AI Configuration` (or legacy "AI-Assistant Appearance"), and `Customer AI Guardrails`. Tab state is URL-controlled via `?tab=` search param.

### Refs for AI Sub-Panels
- `aiConfigurationRef` — Full AI configuration handle
- `appearanceRef` — Legacy appearance-only handle
- `guardrailsRef` — Guardrails settings handle

All sub-panels expose `{ validate, commit }` imperative handles, invoked on save.

## Usage Example

```typescript
// Render in edit mode (existing customer)
<NewCustomerPage organizationId="org_abc123" />

// Render in create mode (new customer)
<NewCustomerPage organizationId={null} />
```

## Feature Flag Gates

| Flag | Effect |
|---|---|
| `customerAiConfiguration` | Full AI config tab vs. legacy appearance tab |
| `customerAiAssistantSettings` | Shows legacy appearance tab |
| `customerGuardrails` | Shows Guardrails tab |

All AI/guardrail tabs are **SaaS-only** (`appMode === 'saas-tenant'`) and **edit-mode only** (require an existing `organizationId`).

## Image Handling

- **Existing org**: Uploads/deletes immediately via `uploadWithAuth`/`deleteWithAuth`, independent of Save
- **New org**: Image held in memory (`pendingFile`) and uploaded after creation
- Blob preview URLs are revoked on unmount to prevent memory leaks
