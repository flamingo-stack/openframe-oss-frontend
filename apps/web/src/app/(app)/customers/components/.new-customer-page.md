# new-customer-page.tsx

Client component that renders the create/edit customer page, combining a details form with optional SaaS-only tabs (AI Configuration, AI Guardrails, Device Guardrails). It composes `useCustomerForm`, `useCustomerLogo`, and tab-aware URL state to support both creation and editing flows within a single `PageLayout`.

## Key Components

- **`NewCustomerPage`** — Main exported component. Accepts `organizationId` (string or `null`); `null` indicates creation mode, a string value indicates edit mode.
- **Tab visibility logic** — `showAiConfig` and `showGuardrails` are gated by SaaS tenant mode (`runtimeEnv.appMode()`) and edit mode; `showDeviceGuardrails` is gated by `useRemoteAccessApprovalGate()` (tri-state, OSS-compatible).
- **URL-controlled tabs** — Active tab is read from and written to the `?tab=` query param via `useSearchParams`/`router.replace`, keeping tab state shareable and refresh-safe.
- **Invalid-submit handling** — `handleInvalid` switches back to the Details tab and scrolls to the first invalid field using `scrollToFirstInvalidField`, coordinated via `pendingScrollRef` and `useLayoutEffect` since the switch happens across a render.
- **Persistent panel mounting** — All tab panels remain mounted (toggled via CSS `hidden` class) so form state and imperative refs (`refs.aiConfigurationRef`, `refs.guardrailsRef`, `refs.deviceGuardrailsRef`) survive tab switches, enabling a single "Save Customer" action to persist all panels.
- **`logo`** — Result of `useCustomerLogo`, providing `displayedImage`, `handleImageChange`, `handleImageRemove`, and `flushPendingUpload` for the optional `ImageUploader` (SaaS tenants only).

## Usage Example

```typescript
import { NewCustomerPage } from './new-customer-page';

// Creation mode
<NewCustomerPage organizationId={null} key="new" />

// Edit mode — key by organizationId to reset form seed on customer switch
<NewCustomerPage organizationId={customerId} key={customerId} />
```

**Important:** Always mount with `key={organizationId}`. Since the initial form seed is captured per mount, swapping the `organizationId` prop without remounting will retain the previous customer's unsaved edits instead of loading the new record.
