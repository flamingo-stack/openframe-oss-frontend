# customers-table-columns.tsx

Defines the column schema, cell renderers, and table body component for the customers data table, including loading-skeleton support, device/user count display, and row navigation to customer detail pages.

## Key Components

- **`UiCustomerEntry`** — View-model interface representing a customer row (id, name, email, device count, employees, last activity, image).
- **`transformCustomerToEntry(org, deviceCount)`** — Maps a raw `Customer` API object into a `UiCustomerEntry`.
- **`CustomerNameCell`** — Renders avatar, name, and email with skeleton fallback while loading.
- **`buildCustomersColumns(dateFilter?)`** — Builds the `ColumnDef[]` array (Name, Devices, Last Activity, Open) for `useDataTable`; wires an optional date filter popover into the "Last Activity" header.
- **`CustomerCountsCell`** — Displays device/user counts, with a loading skeleton state.
- **`OpenCustomerButton`** — Icon button that opens the customer's detail page in a new tab.
- **`customerRowHref(row)`** — Resolves the route for a table row click.
- **`CustomersSearchInput`** — Controlled search input with icon adornment.
- **`CustomersTableBody`** — Full table body component: fetches device counts, transforms rows, handles loading/empty/infinite-scroll states via `LiveTable`.
- **`CustomersDateFilter`** — Type alias for `TableDateFilter` used by the date column header.

## Usage Example

```typescript
import { CustomersTableBody, CustomersSearchInput } from './customers-table-columns';
import { useState } from 'react';

function CustomersPage({ customers, isLoading }: { customers: Customer[]; isLoading: boolean }) {
  const [search, setSearch] = useState('');

  return (
    <div>
      <CustomersSearchInput value={search} onChange={setSearch} />
      <CustomersTableBody
        customers={customers}
        isLoading={isLoading}
        pageSize={20}
        footer={{ hasMore: true, onLoadMore: () => {} }}
      />
    </div>
  );
}
```

Use `pageSize` for paginated lists or `skeletonRows` for fixed, non-paged lists — these are mutually exclusive props on `CustomersTableBody`.
