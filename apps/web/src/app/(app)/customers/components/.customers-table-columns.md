# customers-table-columns.tsx

Defines the column configuration, cell renderers, and table body component for the Customers data table. It transforms raw `Customer` API data into display-ready `UiCustomerEntry` rows, wires up device/user counts, loading skeletons, and row navigation into a reusable `CustomersTableBody` component.

## Key Components

- **`UiCustomerEntry`** – View model for a customer row (name, email, device count, activity dates, image).
- **`transformCustomerToEntry(org, deviceCount)`** – Maps a `Customer` domain object into a `UiCustomerEntry`.
- **`buildCustomersColumns(dateFilter?)`** – Builds the `ColumnDef[]` array (Name, Devices, Last Activity, Open button), optionally wiring a sortable/filterable date header.
- **`CustomerNameCell`** – Renders avatar + name + email with loading-skeleton awareness via `useLoadingScope`.
- **`CustomerCountsCell`** – Renders device/user counts with skeleton fallback while loading.
- **`OpenCustomerButton`** – Icon button that opens the customer's detail page in a new tab.
- **`customerRowHref(row)`** – Resolves the row's navigation URL (`routes.customers.details`).
- **`CustomersSearchInput`** – Controlled search input with icon adornment.
- **`CustomersTableBody`** – Full table body component: computes rows (merging device counts), builds columns, handles loading placeholder rows, and renders a `LiveTable` with pagination/infinite-scroll support.

## Usage Example

```typescript
import { CustomersTableBody, CustomersSearchInput } from './customers-table-columns';

function CustomersPage() {
  const [search, setSearch] = useState('');
  const { customers, isLoading } = useCustomers({ search });

  return (
    <div>
      <CustomersSearchInput value={search} onChange={setSearch} />
      <CustomersTableBody
        customers={customers}
        isLoading={isLoading}
        pageSize={20}
        footer={{ hasNextPage: true, loadMore: () => fetchNextPage() }}
        dateFilter={{ sort: sortState, onSortChange, range, onRangeChange }}
      />
    </div>
  );
}
```

Use `buildCustomersColumns` directly when embedding the column set into a custom table instance instead of `CustomersTableBody`.
