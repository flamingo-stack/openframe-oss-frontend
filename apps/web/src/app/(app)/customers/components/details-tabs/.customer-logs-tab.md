Renders the **Logs** tab within a customer detail view by delegating to the shared `LogsTable` component, scoped to a specific organization.

## Key Components

### `CustomerLogsTab`
A thin wrapper component that renders `LogsTable` in embedded mode, pre-filtered to the given organization's logs.

**Props:**
| Prop | Type | Description |
|---|---|---|
| `organizationId` | `string` | Locks the `SOURCE` filter in `LogsTable` to this organization |

## Usage Example

```typescript
import { CustomerLogsTab } from './customer-logs-tab';

// Inside a customer detail page or tabbed layout
<CustomerLogsTab organizationId="org_abc123" />
```

## Notes

- Passes `embedded={true}` to `LogsTable`, which suppresses standalone page chrome and adapts the layout for use inside a parent container.
- All rendering logic (title, Refresh button, search) is owned by [`LogsTable`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/logs-page/components/logs-table.tsx) — this component has no local state or side effects.
