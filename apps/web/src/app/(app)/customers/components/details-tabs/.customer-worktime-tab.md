Renders the "Worktime" tab on a customer detail page, displaying a `WorkTimeTable` scoped to that customer and letting users log new work time pre-filled with the customer context.

## Key Components

- **`CustomerWorktimeTabProps`** — Props interface; takes `organization: CustomerDetails | null` (null while the customer is still loading).
- **`CustomerWorktimeTab`** — Main component that:
  - Shows a `CustomerTabHeader` with title "Worktime" and an "Add Work Time" action button.
  - Manages local `addOpen` state controlling the add-work-time dialog/drawer.
  - Computes `addDefaultCustomer` (memoized) to prefill and lock the customer field when adding work time, using `organization.organizationId`, `name`, and a resolved image URL via `getFullImageUrl`.
  - Wraps the `WorkTimeTable` in `LoadingWhen` so the table displays a loading state until the customer's global id (`organization.id`) is available, since the table uses it to scope its data query.
  - Passes `organizationGlobalId`, `showEmployee`, and add-dialog state/handlers down to `WorkTimeTable` (Customer column is omitted since context is implicit).

## Usage Example

```typescript
import { CustomerWorktimeTab } from './customer-worktime-tab';
import { useCustomerDetails } from '../../hooks/use-customer-details';

function CustomerDetailPage({ customerId }: { customerId: string }) {
  const { data: organization } = useCustomerDetails(customerId);

  return (
    <div>
      {/* Renders loading state internally until organization is resolved */}
      <CustomerWorktimeTab organization={organization ?? null} />
    </div>
  );
}
```

This component is typically rendered as one tab within a customer detail view, alongside other tabs (e.g., overview, tickets), and relies on the parent to supply the loaded `CustomerDetails` object once available.
