# customer-worktime-tab.tsx

Renders the "Worktime" tab within a customer detail view, displaying a filtered worktime log table scoped to a single customer/organization, with the ability to add new work time entries pre-filled and locked to that customer.

## Key Components

- **`CustomerWorktimeTab`** — Main component rendering the worktime tab. Accepts the customer `organization` (or `null` while loading) and renders a header with an "Add Work Time" action plus a `WorkTimeTable` scoped to that customer's global ID.
- **`CustomerWorktimeTabProps`** — Props interface; `organization: CustomerDetails | null`.

### Behavior Notes
- While `organization` is `null`, the "Add Work Time" button is disabled and the table renders in a loading state via `LoadingWhen`.
- The `addDefaultCustomer` object (id, label, image URL) is memoized and passed to `WorkTimeTable` to prefill and lock the customer field in the "Add Work Time" flow.
- The `WorkTimeTable` is rendered with `showEmployee` enabled and the `Customer` column implicitly omitted since the view is already scoped to one customer.

## Usage Example

```typescript
import { CustomerWorktimeTab } from './customer-worktime-tab';
import { useCustomerDetails } from '../../hooks/use-customer-details';

function CustomerDetailPage({ customerId }: { customerId: string }) {
  const { data: organization } = useCustomerDetails(customerId);

  return (
    <div>
      {/* Renders loading state until organization resolves */}
      <CustomerWorktimeTab organization={organization ?? null} />
    </div>
  );
}
```

This component is typically rendered as one tab panel within a tabbed customer detail layout, alongside other tabs (e.g., Overview, Tickets, Assets).
