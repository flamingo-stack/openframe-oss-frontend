## Customer Device Guardrails Tab

Renders the "Customer Device Guardrails" tab on the customer details page, displaying the organization's effective remote access permission mode. Shows a read-only view of either the tenant-level default (when the organization inherits settings) or the organization's own explicitly configured mode.

## Key Components

- **`CustomerDeviceGuardrailsTab`** - Default exported component that accepts an `organizationId` and renders the guardrails tab content.
- **`CustomerDeviceGuardrailsTabProps`** - Props interface requiring `organizationId: string`.
- Uses `useOrganizationRemoteAccessPolicy` hook to fetch the organization's remote access policy data, including `mode` (explicit override, or `null` if inheriting) and `effectiveMode` (resolved mode label key).
- Uses `useLoadingScope` combined with `organization.isPending` to determine loading state, since the query depends on feature flags resolving first.
- Renders a "Using Default Settings" banner (with an edit link to `routes.settings.aiSettings`) when the organization inherits the tenant default, plus a `PolicyValueCard` showing the effective permission label.
- On error or missing data (post-loading), renders `LoadError` with a retry action wired to `organization.refetch()`.

This component is currently read-only. Per-customer override editing is expected to build on `setOrganizationMode` once backend support is available; today, the only edit action routes to the tenant-wide default guardrails settings.

## Usage Example

```typescript
import { CustomerDeviceGuardrailsTab } from '@/app/(app)/customers/[id]/components/customer-device-guardrails-tab';

function CustomerDetailsTabs({ customerId }: { customerId: string }) {
  return (
    <TabsContent value="device-guardrails">
      <CustomerDeviceGuardrailsTab organizationId={customerId} />
    </TabsContent>
  );
}
```

The component handles its own loading, error, and empty states internally, so it can be dropped directly into a tab panel without additional wrapper logic beyond providing the `organizationId`.
