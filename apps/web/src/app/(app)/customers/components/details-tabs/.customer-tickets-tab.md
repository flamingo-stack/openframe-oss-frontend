Renders a filterable, paginated ticket list scoped to a specific customer organization within the customer detail view.

## Key Components

- **`CustomerTicketsTab`** — Main exported component; accepts an `organizationId` prop and displays all tickets belonging to that organization
- **`useTicketsQuery`** — Hook that fetches paginated ticket dialogs with optional search filtering
- **`useStickyToolbar`** — Hook managing sticky positioning offsets for the search toolbar and table header
- **`getTicketTableColumns`** / **`getTicketOpenColumn`** — The shared ticket columns and the trailing open-in-new-tab action

## Usage Example

```typescript
import { CustomerTicketsTab } from './customer-tickets-tab';

// Inside a customer detail page or tab panel
export default function CustomerPage({ params }: { params: { orgId: string } }) {
  return (
    <CustomerTicketsTab organizationId={params.orgId} />
  );
}
```

## Notes

- Tickets are scoped on the server (`organizationIds`: a ticket's own `organizationId`); the search is debounced (300 ms) before it reaches `useTicketsQuery`
- The search toolbar is sticky (`top-0, z-20`) with negative vertical margins to extend its background without affecting layout flow; the table header docks below it via `stickyHeaderOffset`
- Clicking a row navigates to the ticket dialog route; the trailing action button opens the same route in a new tab
- The table is the shared `LiveTable` (the ticket columns plus `getTicketOpenColumn`), inside `LoadingWhen` while the customer or the first page is read, over one page of placeholder rows (`loadingPlaceholderRows`) drawn with the real ticket cells (`loadingCells`); a new search keeps the rows on screen dimmed (`isPending`) until it answers; the footer is the next page's infinite scroll (`fetchNextPage`)
