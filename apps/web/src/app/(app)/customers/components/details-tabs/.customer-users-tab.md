# customer-users-tab.tsx

Renders the "Users" tab within the Customer (tenant) management page, displaying the directory of users claimed by this customer's rules. Each tab is isolated with its own error boundary so a failed data load affects only this tab, not the parent customer page or its sibling tabs.

## Key Components

- **`CustomerUsersTab`** — React component that accepts an `organizationId` prop and renders the embedded `UsersView` for that organization, wrapped in a scoped `ContentErrorBoundary`.
- **`usersTabError`** — Pre-built fallback UI (via `tenantPageErrorFallback`) shown when the tab fails to load users, using `EMBEDDED_PAGE_OFFSET` for correct layout spacing within the embedded context.

## Usage Example

```typescript
import { CustomerUsersTab } from '@/app/(app)/cloud-tenant-management/components/customer-users-tab';

function CustomerDetailPage({ organizationId }: { organizationId: string }) {
  return (
    <div>
      {/* other tabs */}
      <CustomerUsersTab organizationId={organizationId} />
    </div>
  );
}
```

The component relies on:
- `UsersView` (from `app/(app)/users/components/users-list/users-view`) rendered in `embedded` mode to fit within the tenant management layout.
- `ContentErrorBoundary` to isolate failures per-tab, using `organizationId` as the `resetKey` so switching customers resets the error state.
- `tenantPageErrorFallback` to generate a consistent, tenant-page-styled error message ("Couldn't load the users.") when data fetching fails.

This pattern (isolated boundary + embedded view + tenant-styled fallback) is consistent across other customer tabs (e.g., devices, tickets) to ensure resilient, independent tab rendering.
