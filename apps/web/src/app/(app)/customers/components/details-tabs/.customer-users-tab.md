Renders the "Users" tab within the customer detail page, displaying the directory users associated with a given organization, wrapped in its own isolated error boundary.

## Key Components

- **`CustomerUsersTab`** — Component accepting an `organizationId` prop; renders `UsersView` in `embedded` mode scoped to that organization.
- **`usersTabError`** — A tab-specific error fallback built via `tenantPageErrorFallback`, displayed only when this tab's data fails to load.
- **`ContentErrorBoundary`** — Wraps the tab content, isolating failures so a users-fetch error doesn't crash the rest of the customer page or its other tabs. Uses `resetKey={organizationId}` to reset the boundary when switching customers.

## Usage Example

```typescript
import { CustomerUsersTab } from '@/app/(app)/cloud-tenant-management/components/customer/customer-users-tab';

export function CustomerDetailTabs({ organizationId }: { organizationId: string }) {
  return (
    <TabsContent value="users">
      <CustomerUsersTab organizationId={organizationId} />
    </TabsContent>
  );
}
```

## Notes

- Part of the Customer detail view (Figma reference `733:98943`), displaying users scoped by this customer's organizational rules.
- Error isolation: if the users list fails to fetch, only this tab shows an error fallback (`"Couldn't load the users."`)—the rest of the customer page (other tabs) remains functional.
- Relies on `EMBEDDED_PAGE_OFFSET` to adjust the fallback UI layout for its embedded context within the larger customer page.
- The underlying `UsersView` component is shared with the standalone `/users` page but runs in `embedded` mode here to fit the tab layout.
