Defines the tab configuration for the customer detail page, wiring together devices, users, groups, tickets, logs, worktime, details, AI assistant, guardrails, and assigned articles tabs into a feature-gated, navigable tab list.

## Key Components

- **`CustomerTabProps`** — Props shared by every tab component: `organizationId` (available immediately from the URL) and `organization` (`null` until loaded).
- **Module-level tab wrappers** (`DevicesTab`, `UsersTab`, `GroupsTab`, `TicketsTab`, `LogsTab`, `WorktimeTab`, `DetailsTab`, `CustomAiAssistantTab`, `GuardrailsTab`, `DeviceGuardrailsTab`, `ArticlesTab`) — Stable-identity wrappers around the underlying tab components, preventing unnecessary unmount/remount during re-renders.
- **Tab ID constants** (`CUSTOM_AI_ASSISTANT_TAB_ID`, `CUSTOMER_GUARDRAILS_TAB_ID`, `CUSTOMER_DEVICE_GUARDRAILS_TAB_ID`) — Typed via `satisfies CustomerDetailTab` to keep the route registry in sync at compile time.
- **`getCustomerTabs(visibility)`** — Builds the ordered, feature-gated array of `TabItem`s to render, based on a `CustomerTabsVisibility` flag object (`showDirectory`, `showCustomAiAssistant`, `showGuardrails`, `showDeviceGuardrails`).
- **`getCustomerTab(tabId)`** — Looks up a `TabItem` by id from the full superset of tabs (`ALL_CUSTOMER_TABS`), regardless of visibility gating.
- **`getCustomerTabComponent(tabId)`** — Resolves the React component for a given tab id, for direct rendering outside the tab list.

## Usage Example

```typescript
import { getCustomerTabs, getCustomerTabComponent } from './customer-tabs';

const tabs = getCustomerTabs({
  showDirectory: true,
  showCustomAiAssistant: false,
  showGuardrails: true,
  showDeviceGuardrails: false,
});

// Render with a TabNavigation component
<TabNavigation
  tabs={tabs}
  tabProps={{ organizationId, organization }}
/>;

// Or resolve a specific tab's component directly
const DetailsComponent = getCustomerTabComponent('details');
if (DetailsComponent) {
  <DetailsComponent organizationId={organizationId} organization={organization} />;
}
```
