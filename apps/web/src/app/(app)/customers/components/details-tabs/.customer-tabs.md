Defines the tab configuration and wrapper components for the customer detail view, including feature-gated visibility logic for directory management, AI configuration, and guardrails tabs.

## Key Components

- **`CustomerTabProps`** - Shared props interface (`organizationId`, `organization`) passed to every tab component.
- **Module-level tab wrappers** (`DevicesTab`, `UsersTab`, `GroupsTab`, `TicketsTab`, `LogsTab`, `WorktimeTab`, `DetailsTab`, `CustomAiAssistantTab`, `GuardrailsTab`, `DeviceGuardrailsTab`, `ArticlesTab`) - Stable-identity wrappers around the actual tab implementations, needed so React preserves component identity across re-renders (avoiding unwanted unmount/remount during tab navigation).
- **Tab ID constants** (`CUSTOM_AI_ASSISTANT_TAB_ID`, `CUSTOMER_GUARDRAILS_TAB_ID`, `CUSTOMER_DEVICE_GUARDRAILS_TAB_ID`) - Tab identifiers typed against the `CustomerDetailTab` route union via `satisfies`, ensuring renames fail at compile time.
- **`BASE_CUSTOMER_TABS`** - Always-visible tabs: Tickets, Logs, Worktime, Details.
- **`ALL_CUSTOMER_TABS`** - Superset of every possible tab, used to resolve a tab's component regardless of current visibility.
- **`getCustomerTabs(visibility)`** - Builds the ordered, visibility-filtered `TabItem[]` list for rendering, based on feature gates (directory, custom AI assistant, guardrails, device guardrails).
- **`getCustomerTab(tabId)`** - Looks up a `TabItem` by id from `ALL_CUSTOMER_TABS`.
- **`getCustomerTabComponent(tabId)`** - Resolves the React component for a given tab id.

## Usage Example

```typescript
const tabs = getCustomerTabs({
  showDirectory: true,
  showCustomAiAssistant: false,
  showGuardrails: true,
  showDeviceGuardrails: false,
});

// Render active tab based on URL tab id
const ActiveTabComponent = getCustomerTabComponent(activeTabId);

{ActiveTabComponent && (
  <ActiveTabComponent organizationId={organizationId} organization={organization} />
)}
```
