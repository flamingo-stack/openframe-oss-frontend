# customer-custom-ai-assistant-tab.tsx

A read-only React component rendering the "Customer AI Configuration" tab on the customer details page, displaying the effective AI assistant settings (org-level overrides merged with tenant defaults) for a given customer organization.

## Key Components

- **`CustomerCustomAiAssistantTab`** — Main exported component that accepts `organizationId` and renders:
  - A loading state via `LoadingWhen` while view, config, and quick-action hub defaults resolve.
  - An error state via `LoadError` with retry support if the organization AI config fails to load.
  - An inheritance banner (shown when the customer fully inherits the tenant's default config) linking to `/settings/ai-settings` in edit mode.
  - The shared `AiSettingsOverview` component, fed with the customer's **effective** values (org overrides where present, otherwise tenant defaults).

- **Effective value resolution logic:**
  - `inheritsDefault` — true when there's no appearance override and the AI logic config inherits defaults.
  - `effectiveView` — resolved from org view, falling back to tenant default view, then a generated default.
  - `quickActions` / `isOpenFrameSet` / `usesGlobalDefault` — determine whether quick actions are the customer's custom set, the tenant's default set, or OpenFrame's built-in curated set, driving the banner copy shown to the user.
  - `aiConfig` — an `AgentAiConfig` object projected from organization config onto the shape expected by `AiSettingsOverview`.

- **Hooks used:** `useClientView`, `useOrganizationClientAiConfig`, `useSupportedModels`, `useHubDefaultQuickActions`.

## Usage Example

```typescript
import { CustomerCustomAiAssistantTab } from '@/app/(app)/customers/components/customer-custom-ai-assistant-tab';

export function CustomerDetailsPage({ organizationId }: { organizationId: string }) {
  return (
    <div>
      {/* Renders within a tabbed customer details layout */}
      <CustomerCustomAiAssistantTab organizationId={organizationId} />
    </div>
  );
}
```

Editing is not performed on this tab; users are redirected to `/customers/edit` (or the global AI settings page for defaults) to modify configuration.
