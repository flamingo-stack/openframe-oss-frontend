Read-only React component rendering the "Customer AI Configuration" tab on the customer details page, displaying the effective AI assistant settings (organization overrides merged with tenant defaults) for a specific customer.

## Key Components

- **`CustomerCustomAiAssistantTab`** — Main component accepting an `organizationId` prop. Fetches and merges the customer's AI config view with tenant defaults, computes effective values (LLM provider, model, answer style, custom prompt, quick actions), and renders a read-only `AiSettingsOverview`.
- **Inheritance banner** — Displayed when the customer fully inherits the tenant's default configuration (no view override and `inheritDefault` is true), with a link to edit the global/default configuration via `routes.settings.aiSettings`.
- **Quick actions resolution** — Determines whether quick actions are the built-in OpenFrame set, inherited from tenant defaults, or customized per-customer, and builds an appropriate banner message (`quickActionsBanner`) for each case.
- **Loading/error handling** — Uses `LoadingWhen` to wrap the whole tab in a skeleton state while `useClientView`, `useOrganizationClientAiConfig`, and `useHubDefaultQuickActions` resolve, and `LoadError` with a retry action if the config fetch fails.

## Usage Example

```typescript
import { CustomerCustomAiAssistantTab } from '@/app/(app)/customers/components/customer-custom-ai-assistant-tab';

export function CustomerDetailsAiTab({ customerId }: { customerId: string }) {
  return (
    <CustomerCustomAiAssistantTab organizationId={customerId} />
  );
}
```

Editing is not handled in this component—users are redirected to `/customers/edit` (or the global AI settings page when inheriting defaults) to make changes.
