# customer-devices-tab.tsx

Renders the Devices tab within a customer/tenant detail view, displaying a scoped device list locked to a single organization.

## Key Components

- **`CustomerDevicesTab`** — React component that renders an embedded `DevicesPanel` pre-filtered to a specific organization's devices.
- **`CustomerDevicesTabProps`** — Props interface requiring `organizationId: string`.

The component:
- Locks the device list filters to the given `organizationId` via `lockedFilters`, memoized to avoid unnecessary re-renders.
- Hides the `organization` column and filter since the context already scopes to a single customer.
- Conditionally exposes an "archive" (deleted devices) link via `routes.devices.archive`, gated behind the `useTenantManagementV2Gate` feature flag—this is necessary because the standard device Status filter doesn't surface `DELETED` devices.
- Provides an "add device" link scoped to the current organization via `routes.devices.new`.

## Usage Example

```typescript
import { CustomerDevicesTab } from '@/app/(app)/cloud-tenant-management/components/customer-devices-tab';

function CustomerDetailPage({ organizationId }: { organizationId: string }) {
  return (
    <div>
      {/* Other customer detail tabs/sections */}
      <CustomerDevicesTab organizationId={organizationId} />
    </div>
  );
}
```

This component is intended to be used as a tab panel within a larger customer/tenant management view, such as a tabbed detail page at `/cloud-tenant-management/[organizationId]`.
