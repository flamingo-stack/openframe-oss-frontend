# customer-devices-tab.tsx

Renders the Devices tab within a customer's detail view, embedding the shared `DevicesPanel` scoped to a single organization with organization-specific filters hidden and locked.

## Key Components

- **`CustomerDevicesTab`** — React component that displays a filtered, embedded devices panel for a specific customer/organization.
- **`CustomerDevicesTabProps`** — Props interface requiring `organizationId: string`.

### Behavior

- Locks the device list filters to the given `organizationId` via `lockedFilters`, so only that customer's devices are shown.
- Hides the `organization` column and filter since the context is already scoped to a single customer.
- Provides an "Add Device" link pre-populated with the customer's `organizationId`.
- Conditionally exposes an "Archive" link (to view deleted devices) only when the Tenant Management Phase 2 feature flag (`useTenantManagementV2Gate`) is `'on'`. This is necessary because the standard Status filter never surfaces `DELETED` devices, so the archive link is the only route to a customer's deleted device history.

## Usage Example

```typescript
import { CustomerDevicesTab } from '@/app/(app)/cloud-tenant-management/components/customer-devices-tab';

export function CustomerDetailPage({ params }: { params: { organizationId: string } }) {
  return (
    <div>
      <h2>Devices</h2>
      <CustomerDevicesTab organizationId={params.organizationId} />
    </div>
  );
}
```

This component is typically rendered as one tab within a larger customer detail/tabs layout, alongside other customer-scoped panels (e.g., users, billing).
