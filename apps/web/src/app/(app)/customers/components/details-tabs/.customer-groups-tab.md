# customer-groups-tab.tsx

Renders the "Groups" tab within the Customer detail view, displaying directory groups associated with a specific customer organization. Wraps the shared `GroupsView` component in its own error boundary so a failed load is isolated to this tab without affecting sibling tabs or the parent customer page.

## Key Components

- **`CustomerGroupsTab`** — Client component that renders the customer's groups tab. Accepts an `organizationId` prop and passes it through to `GroupsView`, scoped within a `ContentErrorBoundary`.
- **`groupsTabError`** — Pre-configured error fallback UI built via `tenantPageErrorFallback`, displayed if the groups data fails to load.

## Usage Example

```typescript
import { CustomerGroupsTab } from '@/app/(app)/cloud-tenant-management/components/customer-groups-tab';

export function CustomerDetailTabs({ organizationId }: { organizationId: string }) {
  return (
    <div>
      {/* Other tabs... */}
      <CustomerGroupsTab organizationId={organizationId} />
    </div>
  );
}
```

## Notes

- Uses `ContentErrorBoundary` with a `resetKey` tied to `organizationId`, so the boundary resets automatically when switching between customers.
- The `fallback` UI is generated via `tenantPageErrorFallback`, offset by `EMBEDDED_PAGE_OFFSET` to account for the tab's embedded layout position.
- Corresponds to Figma design reference `733:99271`.
