# customer-groups-tab.tsx

Renders the "Groups" tab within the Customer detail view, displaying directory groups associated with a given customer/tenant. Wraps the content in its own isolated error boundary so a failed data fetch only affects this tab, not the rest of the customer page.

## Key Components

- **`CustomerGroupsTab`** — Client component that accepts an `organizationId` prop and renders the groups list for that organization, scoped within a dedicated error boundary.
- **`groupsTabError`** — A pre-built error fallback (via `tenantPageErrorFallback`) shown if the groups data fails to load, using the shared `EMBEDDED_PAGE_OFFSET` layout offset for embedded tab contexts.

## Usage Example

```typescript
import { CustomerGroupsTab } from '@/app/(app)/cloud-tenant-management/components/customer-groups-tab';

function CustomerDetailTabs({ organizationId }: { organizationId: string }) {
  return (
    <Tabs>
      <TabPanel label="Groups">
        <CustomerGroupsTab organizationId={organizationId} />
      </TabPanel>
      {/* other tabs render independently and are unaffected if this one errors */}
    </Tabs>
  );
}
```

## Notes

- Relies on `ContentErrorBoundary` from `@/app/components/shared` to isolate failures per-tab, using `organizationId` as the `resetKey` so switching customers resets the error state.
- Delegates actual data fetching and rendering to the shared `GroupsView` component, keeping this file as a thin, error-isolated wrapper.
- Corresponds to the Figma design reference `733:99271` for the Customer → Groups tab layout.
