Renders a consistent subtitle row for organization/customer detail tabs, displaying a title alongside optional right-aligned action elements (buttons, filters, etc.).

## Key Components

- **`CustomerTabHeader`** — Client component that renders a flex row with a title heading (`h2`) on the left and optional action content on the right.
- **`CustomerTabHeaderProps`** — Props interface:
  - `title: string` — Required heading text displayed using the `text-h2` style.
  - `rightActions?: ReactNode` — Optional content (e.g., buttons, dropdowns) rendered on the right side, only shown when provided.

## Usage Example

```typescript
import { CustomerTabHeader } from './customer-tab-header';
import { Button } from '@/components/ui/button';

export function DevicesTab() {
  return (
    <div>
      <CustomerTabHeader
        title="Devices"
        rightActions={
          <>
            <Button variant="outline">Filter</Button>
            <Button>Add Device</Button>
          </>
        }
      />
      {/* tab content */}
    </div>
  );
}

// Without actions
<CustomerTabHeader title="Overview" />
```

The component uses a responsive flex layout (`flex-wrap`) so right actions wrap gracefully on smaller screens, and applies design-system tokens (`text-ods-text-primary`, `text-h2`) for consistent typography across organization detail views.
