A client-side React component that renders a standardized subtitle/header row used within organization (customer) detail tabs, displaying a title alongside optional right-aligned action elements.

## Key Components

- **`CustomerTabHeaderProps`** — Interface defining the component's props:
  - `title: string` — the heading text to display
  - `rightActions?: ReactNode` — optional content (e.g., buttons) rendered on the right side
- **`CustomerTabHeader`** — Functional component that renders a flex container with the title as an `h2` and optional right-side actions, wrapping gracefully on smaller screens.

## Usage Example

```typescript
import { CustomerTabHeader } from './customer-tab-header';
import { Button } from '@/components/ui/button';

export function DevicesTab() {
  return (
    <div>
      <CustomerTabHeader
        title="Devices"
        rightActions={
          <>
            <Button variant="outline">Export</Button>
            <Button>Add Device</Button>
          </>
        }
      />
      {/* tab content */}
    </div>
  );
}
```

```typescript
// Without right-side actions
```
