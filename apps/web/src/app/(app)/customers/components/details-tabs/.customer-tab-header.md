A presentational header component for organization detail tabs, rendering a title and an optional row of right-aligned action elements.

## Key Components

### `CustomerTabHeader`

A layout component that displays a section title alongside optional action controls in a responsive flex row.

**Props (`CustomerTabHeaderProps`):**

| Prop | Type | Required | Description |
|---|---|---|---|
| `title` | `string` | ✅ | The section heading text |
| `rightActions` | `ReactNode` | ❌ | Buttons, badges, or other controls rendered on the right |

## Usage Example

```typescript
import { CustomerTabHeader } from './customer-tab-header';
import { Button } from '@/components/ui/button';

// Title only
<CustomerTabHeader title="Contacts" />

// Title with action buttons
<CustomerTabHeader
  title="Devices"
  rightActions={
    <Button variant="outline" size="sm">
      Add Device
    </Button>
  }
/>
```

## Notes

- Wraps with `flex-wrap` so content stacks gracefully on narrow viewports
- Uses `text-h2` and `text-ods-text-primary` design tokens — ensure the ODS theme is loaded
