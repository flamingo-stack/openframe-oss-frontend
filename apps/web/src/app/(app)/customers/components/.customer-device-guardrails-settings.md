# customer-device-guardrails-settings.tsx

A React client component that renders the "Customer Device Guardrails" section on the customer edit page, allowing admins to override the tenant-wide remote access permission policy for a specific organization. It mirrors the AI guardrails UI pattern: a "use default" checkbox paired with a mode selector, with no independent save action—persistence is driven externally via an imperative handle.

## Key Components

- **`CustomerDeviceGuardrailsSettings`** — `forwardRef` component accepting `organizationId`. Fetches the tenant's default remote access policy and the organization's override via `useTenantRemoteAccessPolicy` / `useOrganizationRemoteAccessPolicy`, and exposes a `commit()` method (via `useImperativeHandle`) for the parent "Save Customer" action to invoke.
- **`CustomerDeviceGuardrailsHandle`** — Interface exposing `commit(): Promise<void>`, used by the parent component to persist pending changes.
- **`CustomerDeviceGuardrailsSettingsProps`** — Props interface requiring `organizationId: string`.
- Internal state `choice` tracks unsaved user interaction (`useDefault` + `mode`), kept `null` until touched so background refetches don't clobber in-progress edits.

## Usage Example

```typescript
import { useRef } from 'react';
import {
  CustomerDeviceGuardrailsSettings,
  type CustomerDeviceGuardrailsHandle,
} from './customer-device-guardrails-settings';

function CustomerEditPage({ organizationId }: { organizationId: string }) {
  const guardrailsRef = useRef<CustomerDeviceGuardrailsHandle>(null);

  const handleSaveCustomer = async () => {
    // other save logic...
    await guardrailsRef.current?.commit();
  };

  return (
    <div>
      <CustomerDeviceGuardrailsSettings ref={guardrailsRef} organizationId={organizationId} />
      <button onClick={handleSaveCustomer}>Save Customer</button>
    </div>
  );
}
```

The component renders a loading skeleton while policies load, an error state with retry on fetch failure, and otherwise either a muted "default" policy card or an editable `Select` for choosing among `REMOTE_ACCESS_MODES`.
