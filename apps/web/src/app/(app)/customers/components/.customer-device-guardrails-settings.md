# customer-device-guardrails-settings.tsx

A React client component that renders the "Customer Device Guardrails" block on the customer edit page, allowing per-organization override of the remote access permission policy. It follows the "use default" pattern seen in AI guardrails blocks: a checkbox to inherit tenant-level settings, or a select to choose a specific `RemoteAccessMode` for the organization.

## Key Components

- **`CustomerDeviceGuardrailsSettings`** - `forwardRef` component accepting `organizationId` as a prop. Fetches both the tenant-level default policy (`useTenantRemoteAccessPolicy`) and the organization-specific override (`useOrganizationRemoteAccessPolicy`), displaying a loading/error state while data resolves.
- **`CustomerDeviceGuardrailsHandle`** - Exposed ref interface with a single `commit()` method, allowing a parent component (e.g., a "Save Customer" button) to trigger persistence of the pending selection.
- **Local state (`choice`)** - Tracks unsaved user interaction (`useDefault` + `mode`) separately from server state, preventing background refetches from clobbering in-progress edits.
- **`setOrganizationMode`** mutation - Persists `null` (use default) or a specific `RemoteAccessMode` via `useSetOrganizationRemoteAccessMode`.

## Usage Example

```typescript
import { useRef } from 'react';
import {
  CustomerDeviceGuardrailsSettings,
  type CustomerDeviceGuardrailsHandle,
} from './customer-device-guardrails-settings';

function CustomerEditPage({ organizationId }: { organizationId: string }) {
  const guardrailsRef = useRef<CustomerDeviceGuardrailsHandle>(null);

  const handleSaveCustomer = async () => {
    // Other save logic...
    await guardrailsRef.current?.commit();
  };

  return (
    <>
      <CustomerDeviceGuardrailsSettings
        ref={guardrailsRef}
        organizationId={organizationId}
      />
      <button onClick={handleSaveCustomer}>Save Customer</button>
    </>
  );
}
```

The component has no internal save button; it relies entirely on the parent invoking `commit()` via the ref, making it composable within a larger multi-section settings form.
