# customer-contacts-fields.tsx

Renders the "Contact Information" section of the customer form, allowing users to manage a dynamic list of contact rows (name, title, email, phone) with add/remove functionality backed by `react-hook-form`'s field array API.

## Key Components

- **`CustomerContactsFields`** — Main exported component. Renders a header, a hint about the first contact being the "primary" one shown in customer lists, a list of contact rows (each with four inputs and a remove button), and an "Add Contact" button. Rows can be removed down to zero; empty seed rows are dropped on submit.
- **`ContactInput`** (internal) — Renders a single controlled `Input` field wired to `react-hook-form` via `Controller`, handling validation error display, placeholder text, and input type based on the field name (`text`, `email`, `tel`).
- **`CONTACT_FIELDS`**, **`PLACEHOLDERS`**, **`FIELD_TYPES`** — Local constants mapping each contact field to its placeholder text and HTML input type.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { CustomerContactsFields } from './customer-contacts-fields';
import type { CustomerFormData } from '../types/customer-form.types';

function CustomerFormSection() {
  const { control } = useForm<CustomerFormData>({
    defaultValues: { contacts: [] },
  });

  return (
    <CustomerContactsFields
      control={control}
      disabled={false}
      showErrors={true}
    />
  );
}
```

## Notes

- Uses responsive layout: below the `md` breakpoint, the name field and trash button share a row while other fields stack; at `md` and above, all four inputs and the trash button align in a single row.
- Relies on `EMPTY_CONTACT_ROW` and `CONTACT_FIELD_LABELS` from `../types/customer-form.types` for default values and field labels.
- Validation errors are only shown when `showErrors` is `true`, letting the parent form control when to surface errors (e.g., after a submit attempt).
