Renders the "Contact Information" section of the customer form as a dynamic, repeatable list of contact rows (name, title, email, phone), each with its own remove button, plus an "Add Contact" action to append new rows.

## Key Components

- **`CustomerContactsFields`** — Main component that wires `react-hook-form`'s `useFieldArray` to the `contacts` field of `CustomerFormData`. Renders a header with a hint (the first contact is shown in customer lists), a bordered container with one row per contact, and an "Add Contact" button. Rows can be removed down to zero; the array can start empty and blank rows are expected to be dropped on submit.
- **`ContactInput`** (internal) — Wraps a single `Controller`-bound `Input` for one contact field (`contactName`, `title`, `email`, or `phone`), applying the correct input `type`, label, placeholder, and validation error display based on `showErrors`.
- **`CONTACT_FIELDS`** — Ordered tuple of field keys (`contactName`, `title`, `email`, `phone`) driving row layout and iteration.
- **`PLACEHOLDERS` / `FIELD_TYPES`** — Static lookup maps for per-field placeholder text and HTML input type.

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { CustomerContactsFields } from './customer-contacts-fields';
import type { CustomerFormData } from '../types/customer-form.types';

function CustomerFormSection() {
  const { control } = useForm<CustomerFormData>({
    defaultValues: { contacts: [] },
  });

  return (
    <CustomerContactsFields
      control={control}
      disabled={false}
      showErrors={true}
    />
  );
}
```

The component expects to be rendered inside a `react-hook-form` `useForm` context whose schema defines a `contacts` array matching `CustomerFormData`. Use `disabled` to lock the fields (e.g., during submission) and `showErrors` to toggle validation message visibility (typically tied to a submit attempt).
