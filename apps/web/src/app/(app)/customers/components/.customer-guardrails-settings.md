## customer-guardrails-settings.tsx

Implements the "Customer AI Guardrails" tab on the customer edit page, allowing per-organization AI guardrail policies to either inherit tenant defaults or be customized from a stock preset with per-operation approval-level overrides. Exposes an imperative `commit()` handle so the parent page's "Save Customer" action can persist changes, mirroring the pattern used by the AI-Assistant appearance block (no standalone save button).

## Key Components

- **`CustomerGuardrailsSettings`** — Forward-ref component (`React.forwardRef`) rendering the guardrails tab UI: a toggle for inheriting defaults, a template picker (stock presets + synthetic "Custom" option), and an editable policy-group list.
- **`CustomerGuardrailsHandle`** — Imperative interface with a single `commit()` method that persists the current selection (no-op when inheriting or unchanged).
- **`OrgGuardrailsSelection`** — Internal union type tracking either a chosen `template` or a `custom` template with a `Map` of approval-level `edits`.
- **`ORG_CUSTOM_OPTION_ID`** — Sentinel radio value representing the synthetic "Custom" picker option.
- Internal hooks consumed: `useOrganizationGuardrails`, `useUpdateOrganizationGuardrails`, `useResetOrganizationGuardrails`, `useGuardrailsTemplates`, `useGuardrailsTemplate`, `usePrefetchGuardrailsTemplates`.

## Usage Example

```typescript
import { useRef } from 'react';
import {
  CustomerGuardrailsSettings,
  type CustomerGuardrailsHandle,
} from '@/app/(app)/settings/ai-settings/components/guardrails/customer-guardrails-settings';

function CustomerEditPage({ organizationId }: { organizationId: string }) {
  const guardrailsRef = useRef<CustomerGuardrailsHandle>(null);

  const handleSaveCustomer = async () => {
    // Persist other customer fields first, then commit guardrails.
    await guardrailsRef.current?.commit();
  };

  return (
    <>
      <CustomerGuardrailsSettings ref={guardrailsRef} organizationId={organizationId} />
      <button onClick={handleSaveCustomer}>Save Customer</button>
    </>
  );
}
```

Toggling "Use the default AI-Assistant guardrails" OFF switches the org to its own policy (a stock preset or a custom set of overrides); toggling it back ON prompts a confirmation dialog and resets any existing org-specific policy immediately upon confirmation.
