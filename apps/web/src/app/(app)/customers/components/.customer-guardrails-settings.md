## customer-guardrails-settings.tsx

This client component renders the "Customer AI Guardrails" tab on the customer edit page, letting an admin either inherit tenant-wide default guardrails or configure org-specific guardrails (a stock preset or a fully custom set of per-operation approval overrides). It exposes an imperative `commit()` handle so the parent page's "Save Customer" action can persist changes without this component owning its own save button.

## Key Components

- **`CustomerGuardrailsSettings`** — Forward-ref component accepting `organizationId`; the main exported component.
- **`CustomerGuardrailsHandle`** — Imperative ref interface with a single `commit()` method that persists the selection (no-op when inheriting defaults or unchanged).
- **`OrgGuardrailsSelection`** — Internal union type tracking either a chosen stock `template` or a `custom` template with a `Map` of approval-level edits keyed by `naturalKey`.
- **`ORG_CUSTOM_OPTION_ID`** — Synthetic radio value representing the "Custom" picker option.
- Data hooks: `useOrganizationGuardrails`, `useGuardrailsTemplates`, `useGuardrailsTemplate`, `usePrefetchGuardrailsTemplates`, `useUpdateOrganizationGuardrails`, `useResetOrganizationGuardrails`.
- Helpers: `buildPolicyGroups`, `buildBaseLevels`, `applyEditsToRules`, `withPolicyEdit`, `withCategoryEdits`.
- UI children: `GuardrailsTemplatePicker`, `GuardrailsPresetCard`, `GuardrailsPolicyGroups`, `ConfirmDialog`, `CheckboxBlock`, `LoadError`.

## Usage Example

```typescript
import { useRef } from 'react';
import {
  CustomerGuardrailsSettings,
  type CustomerGuardrailsHandle,
} from '@/app/(app)/settings/ai-settings/components/guardrails/customer-guardrails-settings';

function CustomerEditPage({ organizationId }: { organizationId: string }) {
  const guardrailsRef = useRef<CustomerGuardrailsHandle>(null);

  const handleSaveCustomer = async () => {
    // ...save other customer fields...
    await guardrailsRef.current?.commit();
  };

  return (
    <>
      <CustomerGuardrailsSettings ref={guardrailsRef} organizationId={organizationId} />
      <button onClick={handleSaveCustomer}>Save Customer</button>
    </>
  );
}
```

Toggling "Use the default guardrails settings" OFF reveals a preset picker and editable policy groups; toggling it back ON prompts a confirmation dialog (via `ConfirmDialog`) before resetting any existing org-level policy back to tenant defaults.
