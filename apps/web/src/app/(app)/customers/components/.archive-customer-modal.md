A modal dialog component for archiving customers, with conditional rendering based on whether the customer is eligible for archiving.

## Key Components

### `ArchiveCustomerModal`
Main exported component that renders one of two dialogs depending on the `canArchive` flag:

- **`canArchive: false`** — Renders a blocking `AlertDialog` informing the user that active devices must be removed before archiving.
- **`canArchive: true`** — Renders a `ConfirmDialog` with a destructive confirmation flow, supporting a pending/loading state.

### `ArchiveCustomerModalProps`

| Prop | Type | Description |
|---|---|---|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open state changes |
| `canArchive` | `boolean` | Whether the customer is eligible to archive |
| `onConfirm` | `() => void` | Called when the user confirms archiving |
| `isPending` | `boolean?` | Shows loading state during the archive operation |

## Usage Example
