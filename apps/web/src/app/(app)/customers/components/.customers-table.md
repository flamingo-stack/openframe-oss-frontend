# customers-table.tsx

Client-side React component that renders the Customers list page, including a sticky search/filter toolbar, paginated table body, date-range filtering, and empty/error/offline states.

## Key Components

- **`CustomersTable`** — Main exported component. Accepts an optional `status` prop to filter customers by status.
- **`CustomersTableProps`** — Props interface (`status?: string`).
- **`LOAD_ERROR_MESSAGE`** — Shared error copy used both in the page-level error strip and the table's empty slot, ensuring message consistency.

### Internal behavior
- Uses `useApiParams` to sync `search`, `dateFrom`, `dateTo`, and `sortDirection` with URL query params.
- Uses `useSearchParam` for debounced, responsive local search input that syncs to the URL without clobbering in-progress typing.
- Uses `useStickyToolbar` to keep the search/filter bar pinned while scrolling.
- Uses `useCustomers` to fetch paginated customer data, exposing loading, offline, error, and pagination state.
- Derives `showEmptyState` only when the query successfully resolved with zero results (via `canClaimEmpty`), preventing offline/error states from being misreported as "no customers."
- Renders a mobile-only `FilterModal` for date filtering on small screens.

## Usage Example

```typescript
import { CustomersTable } from '@/app/customers/components/customers-table';

export default function CustomersPage() {
  return <CustomersTable status="active" />;
}
```

Typical integration is inside a Next.js route segment where `status` may come from a search param or tab selection:

```typescript
export default function Page({ searchParams }: { searchParams: { status?: string } }) {
  return <CustomersTable status={searchParams.status} />;
}
```
