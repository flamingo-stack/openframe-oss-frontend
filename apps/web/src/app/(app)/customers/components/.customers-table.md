Client-side React component that renders the Customers list page, including a searchable, date-filterable, infinite-scroll table with empty, loading, and error states.

## Key Components

- **`CustomersTable`** — Default page component accepting an optional `status` prop (filters customers by status). Composes:
  - URL-synced query params (`search`, `dateFrom`, `dateTo`, `sortDirection`) via `useApiParams`
  - Debounced local search state via `useSearchParam`
  - Sticky toolbar behavior via `useStickyToolbar`
  - Data fetching via `useCustomers`
  - Last-activity date filtering (desktop `FilterModal`'s date filter and inline `CustomersTableBody` filter)
  - "Add Customer" action button that navigates to `routes.customers.new`
  - Conditional rendering of `EmptyState` (true empty), inline empty/error message (filtered-out or failed load), and `SectionLoadError` banner (error/offline)
- **`LOAD_ERROR_MESSAGE`** — Shared error copy used both in the top banner and the table's inline empty state, kept as a single source of truth.

## Usage Example

```typescript
import { CustomersTable } from './customers-table';

// Inside a Next.js route page (e.g. app/customers/page.tsx)
export default function CustomersPage() {
  return <CustomersTable />;
}

// Filtered by status (e.g. app/customers/active/page.tsx)
export default function ActiveCustomersPage() {
  return <CustomersTable status="active" />;
}
```

Key implementation detail: `showEmptyState` is derived from `canClaimEmpty` (a positive confirmation the query succeeded with data) rather than `!isLoading`, ensuring offline or failed states never render as "no customers exist." This same guard is applied one level down in `CustomersTableBody`'s empty-state message.
