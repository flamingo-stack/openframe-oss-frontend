A client-side React component that renders the paginated, filterable customers list page with search, date range filtering, sort controls, and an empty onboarding state.

## Key Components

- **`CustomersTable`** — Main exported component accepting an optional `status` prop to pre-filter customers by status
- **`useApiParams`** — Manages URL-synced query parameters (`search`, `dateFrom`, `dateTo`, `sortDirection`)
- **`useSearchParam`** — Debounces local search input (500ms) while keeping typing responsive and guarding URL sync
- **`useStickyToolbar`** — Computes sticky toolbar offset for the table's sticky header
- **`useCustomers`** — Fetches paginated customer data with infinite scroll support
- **`CustomersTableBody`** — Renders the data table rows with skeleton loading and a date filter column header
- **`FilterModal`** — Mobile-only bottom sheet for date/sort filtering (desktop uses inline controls)
- **`EmptyState`** — Shown when no customers exist yet; includes onboarding guide actions and an accent-variant "Add Customer" button

## Usage Example

```typescript
// Render all customers (no status filter)
<CustomersTable />

// Render only active customers
<CustomersTable status="active" />
```

## Behavior Notes

- URL params drive all filter state; browser back/forward navigation restores filters automatically
- Scrolls `<main>` to top on filter apply and on initial mount detection
- "Add Customer" button variant switches to `accent` when the empty state is shown, and `outline` otherwise
- Mobile users access date/sort filters via a `FilterModal`; desktop users interact inline via the table header
- Infinite scroll is handled by `DataTable.InfiniteFooter` when `hasNextPage` is truthy
