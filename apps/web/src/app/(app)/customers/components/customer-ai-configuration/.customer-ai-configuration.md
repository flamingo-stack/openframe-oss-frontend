## Customer AI Configuration Component

React component (forwarded ref) that renders the "Customer AI Configuration" tab on the customer edit page, allowing per-organization AI assistant overrides (branding, provider/model, answer style, quick actions) that either inherit from or override the tenant-wide default configuration.

## Key Components

- **`CustomerAiConfigurationHandle`** — Imperative handle interface exposing `validate()` and `commit()`, driven by the parent page's "Save Customer" action.
- **`CustomerAiConfigurationProps`** — Props interface requiring `organizationId` to scope the configuration.
- **`CustomerAiConfiguration`** — The main `forwardRef` component implementation:
  - Loads org-scoped overrides (`ClientView`, `OrganizationClientAiConfig`) and tenant-wide defaults.
  - Manages a "use default" toggle that, when enabled, resets both overrides (with confirmation) and shows inherited values/previews.
  - When disabled, renders editable fields (assistant name, accent color, avatar, provider/model, answer style, quick actions) backed by `useCustomerAiConfigurationForm`.
  - Exposes `validate`/`commit` via `useImperativeHandle` so the parent "Save Customer" button can persist both overrides atomically, including avatar upload and quick-actions reset logic.
  - Handles loading and error states via `LoadingWhen` and `LoadError`.

## Usage Example

```typescript
import { useRef } from 'react';
import { CustomerAiConfiguration, CustomerAiConfigurationHandle } from './customer-ai-configuration';

function CustomerEditPage({ organizationId }: { organizationId: string }) {
  const aiConfigRef = useRef<CustomerAiConfigurationHandle>(null);

  const handleSaveCustomer = async () => {
    const isValid = await aiConfigRef.current?.validate();
    if (!isValid) return;

    await aiConfigRef.current?.commit();
    // continue saving other customer tabs/fields...
  };

  return (
    <>
      <CustomerAiConfiguration ref={aiConfigRef} organizationId={organizationId} />
      <button onClick={handleSaveCustomer}>Save Customer</button>
    </>
  );
}
```

**Note:** This component depends on several custom hooks (`useClientView`, `useOrganizationClientAiConfig`, `useSupportedModels`, etc.) and shared field/preview components from the `ai-settings` module. It should only be rendered within the customer edit flow where `organizationId` is available.
