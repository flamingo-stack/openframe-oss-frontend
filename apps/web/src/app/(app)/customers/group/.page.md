# page.tsx

Next.js client page component that renders the detail view for a specific user group within the cloud tenant management context, gated behind a feature flag.

## Key Components

- **`CustomerGroupPage`** — Default export; the route component for viewing a single group's details, scoped to an optional `customerId` query parameter.
- Uses **`useTenantManagementV2Gate`** to determine feature availability (`'off'`, `'loading'`, or enabled).
- Uses **`useRequiredIdParam`** to extract and validate the required `id` query param, redirecting to `groupPageBackRoute(customerId)` if missing.
- Renders **`TenantPageShell`** as a layout wrapper (title, error state, reset behavior) and **`GroupDetailView`** for the actual group content.

## Behavior

1. If the tenant management v2 feature gate is `'off'`, triggers `notFound()`.
2. If the required `id` param is absent, `useRequiredIdParam` handles redirect and the component returns `null` during that transition.
3. Otherwise renders `GroupDetailView`, keyed by `id` so React reuses the component instance when navigating between subgroups (only `?id=` changes), preserving internal state appropriately while still re-fetching per-group data.
4. Passes `loading={gate === 'loading'}` to `GroupDetailView` so it can render a loading state while the gate resolves.

## Usage Example

This component is automatically wired into the Next.js App Router based on its file path (e.g. `app/(app)/users/.../page.tsx`). It's accessed via a URL such as:

```text
/users/group-detail?id=group-123&customerId=cust-456
```

No manual invocation is required—Next.js renders it when the matching route is visited. To navigate to it programmatically elsewhere in the app:

```typescript
import { useRouter } from 'next/navigation';

function NavigateToGroup() {
  const router = useRouter();

  const openGroup = (groupId: string, customerId?: string) => {
    const params = new URLSearchParams({ id: groupId });
    if (customerId) params.set('customerId', customerId);
    router.push(`/users/group-detail?${params.toString()}`);
  };

  return null;
}
```
