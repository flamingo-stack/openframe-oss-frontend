# page.tsx

Next.js client page component that renders a single customer group's detail view within the cloud tenant management section, gated behind a feature flag.

## Key Components

- **`CustomerGroupPage`** (default export) — Page component for viewing a specific user group's details, scoped to an optional customer context via `customerId` query param.

### Behavior
- Reads the gate status via `useTenantManagementV2Gate()`; calls `notFound()` if the feature is disabled (`'off'`).
- Extracts `customerId` from the URL search params.
- Resolves the required `id` param via `useRequiredIdParam`, redirecting to the group list (`groupPageBackRoute(customerId)`) if `id` is missing. Returns `null` while that redirect is in-flight.
- Wraps content in `TenantPageShell` for consistent title/error handling, with `resetKey={id}` ensuring the shell resets state when navigating between groups.
- Renders `GroupDetailView`, keyed by `id` so React remounts the view when navigating to a different group (e.g., opening a subgroup), while the router still reuses the route segment.

## Usage Example

This page is automatically invoked by Next.js routing based on its file location (e.g., a route like `/users/groups?id=<groupId>&customerId=<customerId>`). It isn't typically imported directly, but conceptually works like:

```typescript
// Navigating to this page via Next.js Link or router
import { useRouter } from 'next/navigation';

function GroupListItem({ groupId, customerId }: { groupId: string; customerId?: string }) {
  const router = useRouter();

  const openGroup = () => {
    const query = customerId ? `?id=${groupId}&customerId=${customerId}` : `?id=${groupId}`;
    router.push(`/users/groups${query}`);
  };

  return <button onClick={openGroup}>View Group</button>;
}
```

## Notes

- Depends on the `tenant-management-v2` feature gate; while loading, `GroupDetailView` receives `loading={true}` to show appropriate loading UI.
- The `id` query param is required — its absence triggers a redirect back to the group list rather than a 404.
