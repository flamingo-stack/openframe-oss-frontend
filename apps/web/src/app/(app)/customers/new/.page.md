A Next.js page component that renders the new customer creation form at the root level, without a pre-associated organization.

## Key Components

- **`NewOrganizationPage`** — Default page export that renders `NewCustomerPage` with `organizationId` set to `null`, indicating no parent organization context.

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to the /customers/new route.
// No props required — organizationId is explicitly passed as null.
<NewOrganizationPage />
```

> For creating a customer scoped to a specific organization, see [`NewCustomerPage`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/customers/components/new-customer-page.tsx) directly.
