GraphQL query definitions for fetching customer organization data, supporting paginated lists, minimal lookups, and full detail retrieval by ID or organization ID.

## Key Components

| Export | Description |
|--------|-------------|
| `GET_ORGANIZATIONS_QUERY` | Paginated, filterable, sortable list of organizations with full metadata |
| `GET_ORGANIZATIONS_MIN_QUERY` | Lightweight organization list returning only `id`, `organizationId`, `name`, `isDefault`, and `image` |
| `GET_ORGANIZATION_BY_ORGANIZATION_ID_QUERY` | Full organization detail lookup by business-level `organizationId` (string) |
| `GET_ORGANIZATION_BY_ID_QUERY` | Full organization detail lookup by internal GraphQL `id` (ID scalar) |

## Usage Example

```typescript
import {
  GET_ORGANIZATIONS_QUERY,
  GET_ORGANIZATIONS_MIN_QUERY,
  GET_ORGANIZATION_BY_ORGANIZATION_ID_QUERY,
  GET_ORGANIZATION_BY_ID_QUERY,
} from './customers-queries';

// Paginated list with search and filter
const { data } = await client.query({
  query: GET_ORGANIZATIONS_QUERY,
  variables: { search: 'Acme', first: 20, after: null, filter: { status: 'ACTIVE' } },
});

// Minimal list for dropdowns/selects
const { data: minData } = await client.query({
  query: GET_ORGANIZATIONS_MIN_QUERY,
  variables: { first: 50 },
});

// Detail by business org ID
const { data: orgData } = await client.query({
  query: GET_ORGANIZATION_BY_ORGANIZATION_ID_QUERY,
  variables: { organizationId: 'ORG-001' },
});

// Detail by internal GraphQL ID
const { data: orgById } = await client.query({
  query: GET_ORGANIZATION_BY_ID_QUERY,
  variables: { id: 'abc123' },
});
```

## Notes

- `GET_ORGANIZATIONS_QUERY` returns `pageInfo` and `filteredCount` for cursor-based pagination UI.
- Full detail queries include complete `contactInformation` (contacts, physical/mailing addresses) and `notes`, which are omitted from list queries.
- Use `GET_ORGANIZATIONS_MIN_QUERY` for performance-sensitive contexts such as search dropdowns or autocomplete fields.
