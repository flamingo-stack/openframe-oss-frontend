# customer-form.types.ts

Defines the Zod validation schemas, types, and default values used by the customer creation/editing form, including validation rules for customer details and contact rows.

## Key Components

- **`contactRowSchema`** — Zod schema for a single contact entry (name, title, email, phone). All fields are optional; email is format-checked only when non-empty; phone remains free-form to support international formats.
- **`customerFormSchema`** — Zod schema for the full customer form: requires a non-empty `name`, allows free-form `notes`/address fields, a `mailingSameAsPhysical` toggle, and an array of `contacts`.
- **`ContactRow`** / **`CustomerFormData`** — Inferred TypeScript types from the above schemas, used throughout the form components.
- **`CONTACT_FIELD_LABELS`** — Single source of truth for contact field display labels, shared between the form and the read-only "Details" card.
- **Validation constants** — `CONTACT_NAME_MAX`, `CONTACT_TITLE_MAX`, `CONTACT_EMAIL_MAX`, `CONTACT_PHONE_MAX`, `CUSTOMER_NAME_REQUIRED`, `CONTACT_EMAIL_ERROR`: UI-level sanity caps and error messages (the backend does not enforce these).
- **`EMPTY_CONTACT_ROW`** — A blank contact row object, also used to detect and drop empty rows on submit.
- **`CUSTOMER_FORM_DEFAULT_VALUES`** — Default values for an empty customer form (no contacts).
- **`CUSTOMER_FORM_CREATE_DEFAULTS`** — Default values for the "create new customer" flow, pre-seeded with one empty contact row for visible inputs.

## Usage Example

```typescript
import {
  customerFormSchema,
  CUSTOMER_FORM_CREATE_DEFAULTS,
  CONTACT_FIELD_LABELS,
  type CustomerFormData,
} from './customer-form.types';

// Initialize a form (e.g., with react-hook-form + zodResolver)
const form = useForm<CustomerFormData>({
  resolver: zodResolver(customerFormSchema),
  defaultValues: CUSTOMER_FORM_CREATE_DEFAULTS,
});

// Render a contact field label
<label>{CONTACT_FIELD_LABELS.contactName}</label>

// Validate data before submission
const result = customerFormSchema.safeParse(formValues);
if (!result.success) {
  console.error(result.error.flatten());
}
```
