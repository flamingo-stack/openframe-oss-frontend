# customer-form.types.ts

Defines Zod validation schemas and TypeScript types for the customer form, including per-contact field constraints, default values, and reusable error messages/labels shared between the form and its read-only display (Details card).

## Key Components

- **`contactRowSchema`** — Zod schema for a single contact row. All fields are optional (no required contact fields); email is only format-validated when non-empty; phone remains free-form to support international formats and extensions.
- **`customerFormSchema`** — Top-level Zod schema for the full customer form: requires `name`, keeps `notes`/address fields as typed (whitespace preserved), and includes an array of `contactRowSchema` entries.
- **`ContactRow` / `CustomerFormData`** — Inferred TypeScript types from the schemas above, used throughout the form components.
- **`CONTACT_FIELD_LABELS`** — Single source of truth for contact field display labels, shared by the form inputs and the Details card.
- **Constants** — `CONTACT_NAME_MAX`, `CONTACT_TITLE_MAX`, `CONTACT_EMAIL_MAX`, `CONTACT_PHONE_MAX` (UI-only length caps), `CUSTOMER_NAME_REQUIRED`, `CONTACT_EMAIL_ERROR` (error messages).
- **`EMPTY_CONTACT_ROW`** — A blank contact row object, dropped automatically on submit if left untouched.
- **`CUSTOMER_FORM_DEFAULT_VALUES`** — Baseline default values for the form (no contacts).
- **`CUSTOMER_FORM_CREATE_DEFAULTS`** — Defaults for the "create customer" flow, pre-seeded with one empty contact row for visible inputs.

## Usage Example

```typescript
import {
  customerFormSchema,
  CUSTOMER_FORM_CREATE_DEFAULTS,
  CONTACT_FIELD_LABELS,
  type CustomerFormData,
} from './customer-form.types';

// Initialize a form (e.g., with react-hook-form or vee-validate)
const defaultValues: CustomerFormData = CUSTOMER_FORM_CREATE_DEFAULTS;

// Validate submitted data
const result = customerFormSchema.safeParse(formValues);
if (!result.success) {
  console.error(result.error.issues);
}

// Render a label consistently in form and details view
console.log(CONTACT_FIELD_LABELS.email); // "Email Address"
```
