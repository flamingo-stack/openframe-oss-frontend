## Purpose

This file defines the Next.js layout and page metadata configuration for the "Customers" route. It sets the browser tab title using a shared title-generation utility and delegates the actual layout rendering to a shared layout component.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title to the result of `routeTitle('Customers')`, ensuring consistent title formatting (e.g., appending an app/brand suffix) across routes.
- **Default export** — Re-exports the default export from `@/app/(app)/route-title-layout`, reusing a shared layout component rather than defining a new one.

## Usage Example

This file is automatically picked up by the Next.js App Router as the layout for the `customers` route segment. You typically don't import it directly; instead, Next.js applies it based on file location.

```typescript
// Example of the shared utility this file relies on:
// lib/route-title.ts
export function routeTitle(section: string): string {
  return `${section} | OpenFrame`;
}
```

To replicate this pattern for a new route, create a sibling `layout.tsx`:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Devices') };
```

This keeps layout logic centralized in `route-title-layout` while allowing each route to declare only its page-specific title.
