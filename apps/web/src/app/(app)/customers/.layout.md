This layout module configures page metadata for the Customers route segment and re-exports a shared layout component responsible for rendering route-specific titles.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page `title` to `"Customers"` (formatted via `routeTitle`), used by Next.js App Router for `<head>` generation.
- **Default export** — Re-exported from `@/app/(app)/route-title-layout`, providing the actual layout rendering logic shared across routes.
- **`routeTitle`** — Utility imported from `@/lib/route-title` that formats the raw page name into the application's standard title format (e.g., appending a suffix like the app name).

## Usage Example

This file follows the Next.js App Router convention where `layout.tsx` applies to all nested routes under the `customers` segment:

```typescript
// app/(app)/customers/layout.tsx
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Customers') };
```

Next.js automatically applies this metadata and layout to every page rendered within the `customers` route segment, ensuring a consistent browser tab title and shared layout chrome without requiring each page to redefine them.

For more context on the shared layout implementation, see [route-title-layout.tsx](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/route-title-layout.tsx).
