# use-customers.ts

A React hook for fetching a paginated, searchable, and filterable list of customer organizations via GraphQL, built on TanStack Query's infinite query pattern. It normalizes raw GraphQL organization nodes into a flat `Customer` shape for UI consumption.

## Key Components

- **`ORGANIZATIONS_PAGE_SIZE`** - Constant defining the page size (20) used for pagination and loading-state skeletons.
- **`Customer`** - Flattened, UI-friendly shape of an organization record.
- **`OrganizationNode`** - Raw GraphQL node shape returned by the API before normalization.
- **`mapOrganizationNode(node)`** - Maps an `OrganizationNode` into a `Customer`, applying fallbacks for nullable fields.
- **`CustomersDateQuery`** - Shape for server-side last-activity date range filtering plus sort direction.
- **`customersQueryKeys`** - Query key factory (`all`, `list`) used for cache management with TanStack Query.
- **`useCustomers(search, status, dateQuery)`** - Main hook that fetches customers using `useInfiniteQuery`, handles errors via toast notifications, and exposes derived state.

## Usage Example

```typescript
import { useCustomers } from './use-customers';

function CustomersTable() {
  const {
    customers,
    isLoading,
    isFetchingNextPage,
    hasNextPage,
    fetchNextPage,
    filteredCount,
    refetch,
  } = useCustomers('acme', 'active', {
    lastActivityFrom: '2024-01-01T00:00:00Z',
    lastActivityTo: '2024-12-31T23:59:59Z',
    sortDirection: 'desc',
  });

  if (isLoading) return <p>Loading customers...</p>;

  return (
    <div>
      <p>{filteredCount} customers found</p>
      <ul>
        {customers.map(customer => (
          <li key={customer.id}>{customer.name}</li>
        ))}
      </ul>
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </div>
  );
}
```

The hook automatically refetches when `search`, `status`, or `dateQuery` change (via query key composition), surfaces fetch errors through a toast, and flattens all loaded pages into a single `customers` array via `useMemo`.
