# use-customers.ts

Client-side hook for fetching a paginated, filterable list of customer organizations via GraphQL, backed by `@tanstack/react-query`'s infinite query. Handles server-side search, status filtering, last-activity date range filtering/sorting, and maps raw GraphQL organization nodes into a flattened `Customer` shape for UI consumption.

## Key Components

- **`ORGANIZATIONS_PAGE_SIZE`** — Constant (20) defining the page size used for pagination and skeleton loading rows.
- **`Customer`** — Flattened, UI-friendly shape of a customer organization.
- **`OrganizationNode`** — Raw GraphQL node shape returned by the `organizations` query.
- **`mapOrganizationNode(node)`** — Maps an `OrganizationNode` into a `Customer`, applying sensible defaults for nullable fields and falling back through `lastActivityAt` → `updatedAt` → `createdAt` → current time.
- **`CustomersDateQuery`** — Server-side filter/sort params: `lastActivityFrom`, `lastActivityTo`, and `sortDirection`.
- **`customersQueryKeys`** — React Query key factory (`all`, `list(search, status, dateQuery)`) for cache management.
- **`useCustomers(search?, status?, dateQuery?)`** — Main hook. Returns:
  - `customers`: flattened array across all fetched pages
  - `isFetchingNextPage`, `hasNextPage`, `fetchNextPage`: pagination controls
  - `filteredCount`: total matching records reported by the server
  - `refetch` plus standard loading/error state spread from `queryState(query)`
  - Automatically surfaces fetch errors via `useToast`

## Usage Example

```typescript
import { useCustomers } from '@/features/customers/hooks/use-customers';

function CustomersTable() {
  const {
    customers,
    isLoading,
    isFetchingNextPage,
    hasNextPage,
    fetchNextPage,
    filteredCount,
  } = useCustomers('acme', 'active', {
    lastActivityFrom: '2024-01-01T00:00:00Z',
    lastActivityTo: '2024-12-31T23:59:59Z',
    sortDirection: 'desc',
  });

  if (isLoading) return <p>Loading…</p>;

  return (
    <>
      <p>{filteredCount} customers found</p>
      <ul>
        {customers.map(customer => (
          <li key={customer.id}>{customer.name}</li>
        ))}
      </ul>
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```
