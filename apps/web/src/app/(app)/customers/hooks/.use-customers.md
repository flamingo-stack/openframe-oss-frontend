Infinite-scroll data hook for fetching and paginating customer (organization) records via GraphQL, with built-in error toasting and result flattening.

## Key Components

- **`Customer`** — Normalized interface representing a customer record with contact, financial, and activity fields
- **`OrganizationNode`** — Raw GraphQL response shape for an organization node
- **`mapOrganizationNode(node)`** — Maps a raw `OrganizationNode` to the normalized `Customer` interface, applying safe fallbacks for nullable fields
- **`CustomersDateQuery`** — Filter interface for server-side last-activity date range and sort direction
- **`customersQueryKeys`** — TanStack Query key factory for cache scoping and invalidation
- **`useCustomers(search, status, dateQuery)`** — Primary hook; returns paginated customers, loading/error state, and pagination controls

## Usage Example

```typescript
import { useCustomers } from '@/features/customers/hooks/use-customers';

function CustomerList() {
  const {
    customers,
    isLoading,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage,
    filteredCount,
  } = useCustomers('Acme', 'active', {
    lastActivityFrom: '2024-01-01T00:00:00Z',
    lastActivityTo: '2024-12-31T23:59:59Z',
    sortDirection: 'desc',
  });

  if (isLoading) return <Spinner />;

  return (
    <>
      <p>{filteredCount} customers found</p>
      {customers.map(c => <CustomerRow key={c.id} customer={c} />)}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```

Errors are surfaced automatically via a destructive toast — no additional error handling is needed in the consuming component. Pages are fetched in batches of 20, keyed by `endCursor`, and cached for 30 seconds.
