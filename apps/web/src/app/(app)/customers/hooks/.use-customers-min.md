A React hook that fetches a lightweight list of organizations (customers) via GraphQL, optimized for use in search/autocomplete components where only minimal fields (id, name, logo) are needed.

## Key Components

- **`OrganizationMin`** — Flattened interface representing a minimal organization record (`id`, `organizationId`, `name`, `isDefault`, `imageUrl`).
- **`OrganizationMinNode`** — Internal interface matching the raw GraphQL node shape before flattening (nested `image.imageUrl`).
- **`useCustomersMin(limit)`** — Hook that returns:
  - `items: OrganizationMin[]` — the fetched list of organizations.
  - `isLoading: boolean` — loading state.
  - `error: string | null` — error message, if any.
  - `fetch(search?: string)` — async function to trigger the query, optionally filtered by `search` text; returns the mapped list or throws on failure.

## Usage Example

```typescript
'use client';

import { useEffect } from 'react';
import { useCustomersMin } from './use-customers-min';

export function CustomerPicker() {
  const { items, isLoading, error, fetch } = useCustomersMin(20);

  useEffect(() => {
    fetch();
  }, [fetch]);

  const handleSearch = (value: string) => {
    fetch(value);
  };

  if (error) return <p>Error: {error}</p>;

  return (
    <div>
      <input
        placeholder="Search customers..."
        onChange={(e) => handleSearch(e.target.value)}
      />
      {isLoading ? (
        <p>Loading...</p>
      ) : (
        <ul>
          {items.map((org) => (
            <li key={org.id}>
              {org.imageUrl && <img src={org.imageUrl} alt={org.name} width={20} />}
              {org.name}
              {org.isDefault ? ' (default)' : ''}
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}
```

Internally, the hook posts a GraphQL query (`GET_ORGANIZATIONS_MIN_QUERY`) to `/api/graphql` via `apiClient`, handles errors from non-ok responses, and maps the nested `edges`/`node` GraphQL response shape into a flat `OrganizationMin[]` array stored in state.
