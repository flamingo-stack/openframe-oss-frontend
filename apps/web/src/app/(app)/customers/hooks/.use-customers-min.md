Lightweight React hook for fetching a minimal, searchable list of organizations (customers) via GraphQL, intended for use in dropdowns, autocomplete fields, or other UI components that need a compact organization dataset.

## Key Components

- **`OrganizationMin`** — Public interface representing a flattened organization record (`id`, `organizationId`, `name`, `isDefault`, optional `imageUrl`).
- **`OrganizationMinNode`** — Internal interface matching the raw GraphQL node shape (before flattening the nested `image` object into `imageUrl`).
- **`useCustomersMin(limit?: number)`** — Hook that manages fetch state and exposes:
  - `items: OrganizationMin[]` — the current list of fetched organizations.
  - `isLoading: boolean` — loading state flag.
  - `error: string | null` — error message, if any.
  - `fetch(search?: string): Promise<OrganizationMin[]>` — async callback to query organizations by search term, returning (and setting) the mapped results.

## Usage Example

```typescript
'use client';

import { useEffect, useState } from 'react';
import { useCustomersMin } from '@/hooks/use-customers-min';

function CustomerPicker() {
  const { items, isLoading, error, fetch } = useCustomersMin(20);
  const [query, setQuery] = useState('');

  useEffect(() => {
    fetch(query).catch(() => {
      // error state already captured in hook
    });
  }, [query, fetch]);

  return (
    <div>
      <input
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        placeholder="Search customers..."
      />
      {isLoading && <p>Loading...</p>}
      {error && <p>Error: {error}</p>}
      <ul>
        {items.map((org) => (
          <li key={org.id}>
            {org.name} {org.isDefault && '(default)'}
          </li>
        ))}
      </ul>
    </div>
  );
}
```

The hook relies on `apiClient` to POST to `/api/graphql` using the `GET_ORGANIZATIONS_MIN_QUERY` document, and normalizes the nested `image.imageUrl` field into a flat `imageUrl` property for easier consumption.
