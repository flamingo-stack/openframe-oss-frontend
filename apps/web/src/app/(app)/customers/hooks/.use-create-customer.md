# use-create-customer.ts

A client-side React hook that encapsulates the logic for creating a new customer organization via the OpenFrame API, including the TypeScript interfaces for the request and response payloads.

## Key Components

- **`ContactPersonDto`** - Represents a single contact person with name, title, phone, and email.
- **`AddressDto`** - Represents a physical or mailing address, with most fields optional except `street1`.
- **`ContactInformationDto`** - Aggregates contact persons, physical/mailing addresses, and a flag indicating whether the mailing address matches the physical one.
- **`CreateCustomerRequest`** - The full payload shape required to create a customer, including name, category, revenue, contract dates, and contact information.
- **`CreatedOrganization`** - Response shape from the create endpoint; declares both `organizationId` and `id` since callers should check both (see fallback logic in `new-customer-page`).
- **`useCreateCustomer()`** - Hook that returns a `createOrganization` callback for submitting a `CreateCustomerRequest` to the API.

## Usage Example

```typescript
'use client';

import { useCreateCustomer, CreateCustomerRequest } from '@/hooks/use-create-customer';

function NewCustomerForm() {
  const { createOrganization } = useCreateCustomer();

  const handleSubmit = async () => {
    const request: CreateCustomerRequest = {
      name: 'Acme Corp',
      category: 'Technology',
      numberOfEmployees: 50,
      websiteUrl: 'https://acme.example.com',
      contactInformation: {
        contacts: [
          { contactName: 'Jane Doe', title: 'CTO', phone: '555-1234', email: 'jane@acme.example.com' },
        ],
        physicalAddress: { street1: '123 Main St', city: 'Springfield' },
        mailingAddress: { street1: '123 Main St', city: 'Springfield' },
        mailingAddressSameAsPhysical: true,
      },
    };

    try {
      const org = await createOrganization(request);
      const newId = org?.organizationId ?? org?.id;
      console.log('Created organization:', newId);
    } catch (err) {
      console.error('Failed to create customer:', err);
    }
  };

  return <button onClick={handleSubmit}>Create Customer</button>;
}
```

## Notes

- Throws an `Error` when the API response indicates failure, using the server-provided error message or a status-based fallback.
- Relies on `apiClient` from `@/lib/api-client` for making the underlying HTTP request.
- The `createOrganization` callback is memoized with `useCallback` and has no dependencies, so it remains stable across re-renders.
