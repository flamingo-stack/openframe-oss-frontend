A React hook for creating new customer organizations via the API, exposing a typed `createOrganization` function along with the request/response TypeScript interfaces used throughout the customer creation flow.

## Key Components

- **`ContactPersonDto`** — Shape of an individual contact's details (name, title, phone, email).
- **`AddressDto`** — Shape of a physical or mailing address, with optional fields beyond `street1`.
- **`ContactInformationDto`** — Groups contacts, physical/mailing addresses, and a flag indicating whether the mailing address matches the physical one.
- **`CreateCustomerRequest`** — Full payload shape for the create-organization API call, including optional business metadata (revenue, employee count, contract dates).
- **`CreatedOrganization`** (internal) — Response shape, tolerant of either `organizationId` or `id` depending on backend response variance.
- **`useCreateCustomer()`** — Hook returning `{ createOrganization }`, a memoized async function that posts to `/api/organizations` and returns the created organization data, throwing on failure.

## Usage Example

```typescript
import { useCreateCustomer, type CreateCustomerRequest } from '@/hooks/use-create-customer';

function NewCustomerPage() {
  const { createOrganization } = useCreateCustomer();

  const handleSubmit = async (formData: CreateCustomerRequest) => {
    try {
      const created = await createOrganization(formData);
      const newId = created.organizationId ?? created.id;
      console.log('Created organization with id:', newId);
    } catch (err) {
      console.error('Failed to create customer:', err);
    }
  };

  return null; // render form that calls handleSubmit
}
```

## Notes

- Relies on the shared `apiClient` from `@/lib/api-client` for HTTP requests and error handling.
- Marked `'use client'`, so it's intended for use in client components within a Next.js app.
- `createOrganization` is wrapped in `useCallback` with an empty dependency array, making it safe to include in effect dependency arrays without causing re-renders.
- Callers should check for both `organizationId` and `id` on the response, since the backend may return either shape (see the fallback pattern noted in the source comment).
