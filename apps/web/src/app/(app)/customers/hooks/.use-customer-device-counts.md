Fetches and caches device counts per organization using a GraphQL query, returning a stable `Map<string, number>` keyed by organization ID.

## Key Components

- Cache key is the constant `deviceQueryKeys.countsBy({})`, so a device mutation refreshes these counts along with every other device surface, and every page of the table shares one cache entry.
- **`useCustomerDeviceCounts(organizationIds)`** — Primary hook that fires a `GetDeviceOrganizationCounts` GraphQL request and returns a map of device counts alongside a loading state.
- **`EMPTY_DEVICE_COUNTS`** — Shared readonly empty `Map` used as a stable fallback before data loads, preventing unnecessary re-renders.

## Behavior Notes

- `organizationIds` gates the request but is **not sent**: the backend's organization facet self-excludes that filter (see `fetchDeviceOrganizationCounts`), so the response is the same tenant-wide map on every page. Passing it only fragmented the cache.
- The query is **disabled** when `organizationIds` is empty, avoiding unnecessary network requests.
- Results are cached for **30 seconds** (`staleTime: 30_000`).
- GraphQL-level errors are surfaced as thrown `Error` instances, consistent with HTTP-level failures.

## Usage Example

```typescript
import { useCustomerDeviceCounts } from '@/hooks/use-customer-device-counts';

function CustomerTable({ orgIds }: { orgIds: string[] }) {
  const { deviceCounts, isLoading } = useCustomerDeviceCounts(orgIds);

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {orgIds.map((id) => (
        <li key={id}>
          Org {id}: {deviceCounts.get(id) ?? 0} devices
        </li>
      ))}
    </ul>
  );
}
```
