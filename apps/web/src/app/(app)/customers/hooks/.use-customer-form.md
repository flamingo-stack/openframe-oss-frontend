# use-customer-form.ts

Custom hook that owns the entire customer create/edit form lifecycle: form state (react-hook-form + zod), seeding from fetched data, orchestrating saves across multiple sub-panels (AI configuration, guardrails, device guardrails), and navigation/toast feedback.

## Key Components

- **`useCustomerForm(options)`** — Main hook accepting `organizationId` (null for create mode), `flushPendingLogo` callback, and optional `onInvalid` callback.
- **`UseCustomerFormOptions`** — Input interface describing the hook's dependencies.
- **Returned API**:
  - `form` — the react-hook-form instance (bound to `customerFormSchema` via `zodResolver`).
  - `organization` / `isEditMode` / `customerLoaded` — data and mode flags.
  - `isSubmitting` / `showErrors` — UI state flags.
  - `handleSave` — stable callback to trigger validated submission.
  - `refs` — imperative handles (`aiConfigurationRef`, `guardrailsRef`, `deviceGuardrailsRef`) for sub-panels that must commit alongside the main save.

## Behavior Notes

- Uses `'use no memo'` — this module opts out of React Compiler auto-memoization, so values like `seed` are memoized manually and dependency arrays must stay correct.
- Form is seeded once the customer record loads via `useSeedForm`, dirty-guarded so in-progress edits aren't clobbered.
- Save is gated by an `inFlightRef` to prevent double-submits (more reliable than `formState.isSubmitting`, which lags a render).
- Sub-panel commits (AI config, guardrails, device guardrails) are **non-fatal**: if the main customer save succeeds but a sub-panel commit fails, the user gets a warning toast instead of a full failure.
- On invalid submit, errors are collected via `collectFormErrorMessages`, surfaced in a toast, and the first invalid field is scrolled into view with `scrollToFirstInvalidField`.
- On success, related customer queries are invalidated and the router navigates back to the details page (edit) or customer list (create).

## Usage Example

```typescript
function CustomerFormPage({ organizationId }: { organizationId: string | null }) {
  const {
    form,
    organization,
    isEditMode,
    customerLoaded,
    isSubmitting,
    showErrors,
    handleSave,
    refs,
  } = useCustomerForm({
    organizationId,
    flushPendingLogo: async (newOrgId) => {
      await uploadPendingLogo(newOrgId);
    },
    onInvalid: () => setActiveTab('details'),
  });

  return (
    <FormProvider {...form}>
      <CustomerDetailsPanel showErrors={showErrors} />
      {isEditMode && (
        <CustomerAiConfiguration ref={refs.aiConfigurationRef} />
      )}
      <Button onClick={handleSave} disabled={isSubmitting}>
        Save Customer
      </Button>
    </FormProvider>
  );
}
```
