# use-customer-form.ts

Custom React hook that encapsulates all customer create/edit form logic, including react-hook-form + zod validation, record seeding, imperative sub-panel commits (AI configuration, guardrails, device guardrails), and the full save/navigation chain.

## Key Components

- **`useCustomerForm(options)`** — Main hook accepting `organizationId` (null for create mode), `flushPendingLogo` callback, and optional `onInvalid` handler. Returns the RHF `form` instance, loaded `organization`, mode flags, submission state, `handleSave` trigger, and refs for sub-panel imperative handles.
- **`UseCustomerFormOptions`** — Input interface for the hook (organization ID, logo flush callback, invalid-submit callback).
- **Internal `runSave`** — Async save chain: validates AI configuration, maps form data to the write payload (preserving untouched fields), creates or updates the organization, flushes a pending logo on create, commits AI/guardrails/device-guardrails sub-panels (non-fatal on failure), invalidates relevant queries, shows a toast, and navigates.
- **Internal `onValid`** — Wraps `runSave` with a ref-based re-entrancy guard to prevent double-submission from rapid clicks.
- **`handleSave`** — Public submit handler combining valid/invalid RHF callbacks, surfacing validation toasts and scrolling to the first invalid field.

## Usage Example

```typescript
import { useCustomerForm } from './use-customer-form';

function CustomerFormPage({ organizationId }: { organizationId: string | null }) {
  const { form, organization, isEditMode, customerLoaded, isSubmitting, showErrors, handleSave, refs } =
    useCustomerForm({
      organizationId,
      flushPendingLogo: async (createdOrgId) => {
        await uploadLogo(createdOrgId, pendingLogoFile);
      },
      onInvalid: () => setActiveTab('details'),
    });

  if (isEditMode && !customerLoaded) return <LoadingSpinner />;

  return (
    <form>
      {/* fields bound via form.register / form.control */}
      <CustomerAiConfiguration ref={refs.aiConfigurationRef} />
      <CustomerGuardrailsSettings ref={refs.guardrailsRef} />
      <CustomerDeviceGuardrailsSettings ref={refs.deviceGuardrailsRef} />
      <button type="button" disabled={isSubmitting} onClick={handleSave}>
        Save Customer
      </button>
    </form>
  );
}
```

**Note:** This hook is marked `'use no memo'` and designed for React Compiler compatibility — consuming components must read returned primitives/stable functions rather than reaching into `form.formState` or calling `form.watch()` directly, since `form` retains a single stable identity across renders.
