## use-customer-logo.ts

React hook that manages a customer organization's logo, handling both immediate persistence (edit mode) and deferred upload (create mode) with optimistic UI updates.

This hook decouples the logo from the main customer form: in edit mode, uploads and deletes are persisted to the server immediately, while in create mode the file is held in memory until the organization record exists. A local `override` state ensures freshly uploaded or deleted images display instantly, winning over the cached record until a background refetch catches up.

## Key Components

- **`useCustomerLogo(options)`** — Main hook accepting `{ organizationId: string | null }`.
- **`displayedImage`** — Resolved image URL to render, preferring a pending local preview, then the session override, then the stored record.
- **`handleImageChange(file)`** — Uploads the file immediately if `organizationId` exists; otherwise stores it as a pending preview (blob URL).
- **`handleImageRemove()`** — Deletes the logo immediately if present server-side; otherwise clears the pending preview.
- **`flushPendingUpload(createdOrganizationId)`** — Uploads a previously staged file once the organization record is created; failures surface as a non-blocking warning toast.

Internally it layers `useCustomerDetails` (source of truth for the stored logo), `uploadWithAuth`/`deleteWithAuth` (authenticated HTTP), `getFullImageUrl` (URL/hash resolution for cache-busting), and `invalidateCustomerQueries` (keeps other cached views in sync).

## Usage Example

```typescript
function CustomerLogoEditor({ organizationId }: { organizationId: string | null }) {
  const { displayedImage, handleImageChange, handleImageRemove, flushPendingUpload } =
    useCustomerLogo({ organizationId });

  const onFileSelected = (file: File) => handleImageChange(file);

  // After creating a new organization record on form submit:
  const onCustomerCreated = async (newOrgId: string) => {
    await flushPendingUpload(newOrgId);
  };

  return (
    <div>
      {displayedImage && <img src={displayedImage} alt="Customer logo" />}
      <input
        type="file"
        accept="image/*"
        onChange={(e) => e.target.files?.[0] && onFileSelected(e.target.files[0])}
      />
      <button onClick={handleImageRemove}>Remove Logo</button>
    </div>
  );
}
```
