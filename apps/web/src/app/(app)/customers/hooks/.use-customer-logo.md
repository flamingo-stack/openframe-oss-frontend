## Purpose

A React hook that manages customer (organization) logo upload, preview, and deletion, handling both edit mode (immediate persistence to the server) and create mode (deferred upload via `flushPendingUpload` until the record exists).

## Key Components

- **`useCustomerLogo(options)`** — Main hook accepting `{ organizationId }` and returning:
  - `displayedImage` — resolved image URL to render (pending blob preview, session override, or stored record image)
  - `handleImageChange(file)` — uploads immediately if `organizationId` exists, otherwise stages the file as a local preview
  - `handleImageRemove()` — deletes immediately if a stored logo exists, otherwise clears the pending preview
  - `flushPendingUpload(createdOrganizationId)` — uploads a previously staged file once the organization record is created; failures surface as a non-blocking warning toast
- **`StoredCustomerLogo`** — internal shape `{ imageUrl, imageHash }` representing the persisted logo state
- Internal state: `override` (session-local upload/delete result that takes precedence over cached data until refetch), `pendingFile`/`pendingPreviewUrl` (unsaved file and its object URL for create mode)

## Usage Example

```typescript
import { useCustomerLogo } from './use-customer-logo';

function CustomerLogoEditor({ organizationId }: { organizationId: string | null }) {
  const { displayedImage, handleImageChange, handleImageRemove, flushPendingUpload } =
    useCustomerLogo({ organizationId });

  const onFileSelected = (file: File) => {
    handleImageChange(file);
  };

  // After creating a new organization, flush any staged logo upload
  const onOrganizationCreated = async (newOrgId: string) => {
    await flushPendingUpload(newOrgId);
  };

  return (
    <div>
      {displayedImage && <img src={displayedImage} alt="Customer logo" />}
      <input
        type="file"
        onChange={(e) => e.target.files?.[0] && onFileSelected(e.target.files[0])}
      />
      <button onClick={handleImageRemove}>Remove logo</button>
    </div>
  );
}
```

**Notes:**
- Object URLs created for previews are automatically revoked on unmount and when replaced.
- In edit mode, uploads/deletes trigger `invalidateCustomerQueries` to refresh cached customer lists elsewhere in the app.
- The `imageHash` is cache-busted with a timestamp after upload to avoid stale image display.
