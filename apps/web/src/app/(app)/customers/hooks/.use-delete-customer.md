A React hook that provides a memoized function for deleting a customer organization via the API.

## Key Components

- **`useDeleteCustomer`** — Custom hook that exposes `deleteOrganization`, a `useCallback`-memoized async function for sending a `DELETE` request to `/api/organizations/:id`. Throws an error if the request fails.

## Usage Example

```typescript
import { useDeleteCustomer } from '@/hooks/use-delete-customer';

function CustomerActions({ customerId }: { customerId: string }) {
  const { deleteOrganization } = useDeleteCustomer();

  const handleDelete = async () => {
    try {
      await deleteOrganization(customerId);
      console.log('Customer deleted successfully');
    } catch (error) {
      console.error('Failed to delete customer:', error);
    }
  };

  return <button onClick={handleDelete}>Delete Customer</button>;
}
```

## Notes

- Marked with `'use client'` — intended for client-side rendering only.
- `deleteOrganization` is stable across renders (memoized with no dependencies), safe to use in `useEffect` dependency arrays or pass as a prop.
- Error handling surfaces either the API error message or a fallback HTTP status message.
