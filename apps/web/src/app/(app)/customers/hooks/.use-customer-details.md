# use-customer-details.ts

A React Query hook that fetches and caches detailed customer (organization) data via GraphQL, exposing a normalized loading/error/data state for use in customer detail and edit views.

## Key Components

- **`customerDetailsQueryKeys`** - Query key factory with `all` (base key) and `detail(id)` (per-customer key) for cache management and invalidation.
- **`fetchCustomer(id)`** - Internal async function that posts a GraphQL query to `/api/graphql`, validates the HTTP response, checks for GraphQL-level errors, and maps the raw `OrganizationNode` into a `CustomerDetails` object via `mapOrganization`. Throws on any failure rather than returning a partial record, since a nulled field paired with a GraphQL error must never be mistaken for valid data.
- **`useCustomerDetails(id?)`** - Public hook that wraps `useQuery`, conditionally skipping the fetch (via `skipToken`) when no `id` is provided. Returns `organization`, derived query state (via `queryState`), and `refetch`.
- **`CustomerDetails`** (re-exported type) - Shape of the mapped customer details object.

## Usage Example

```typescript
import { useCustomerDetails } from './use-customer-details';

function CustomerDetailPanel({ customerId }: { customerId?: string }) {
  const { organization, isLoading, isError, error, refetch } = useCustomerDetails(customerId);

  if (!customerId) return <p>No customer selected</p>;
  if (isLoading) return <p>Loading customer...</p>;
  if (isError) return <p>Error: {error?.message}</p>;

  return (
    <div>
      <h2>{organization?.name}</h2>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}
```

**Notes:**
- Passing `undefined` or `null` as `id` puts the hook in a `closed` gate state, preventing the query from running and avoiding an indefinite loading state.
- The hook relies on `queryState` to produce a consistent `isLoading`/`isError`/`error` shape across the codebase.
- GraphQL errors are surfaced as thrown errors, ensuring consumers never receive a partially-null `CustomerDetails` object.
