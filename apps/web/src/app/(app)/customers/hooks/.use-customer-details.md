# use-customer-details.ts

React Query hook for fetching a single customer (organization) record by ID via GraphQL, exposing a normalized loading/error/data state.

## Key Components

- **`customerDetailsQueryKeys`** - Query key factory with `all` (base key) and `detail(id)` (per-customer key) for cache management and invalidation.
- **`fetchCustomer(id)`** - Internal async function that POSTs a GraphQL query to `/api/graphql`, validates the HTTP response, checks for GraphQL-level errors, and maps the result via `mapOrganization`. Treats GraphQL errors as load failures (never returns a partial record) to prevent accidentally overwriting a real customer with blank data.
- **`useCustomerDetails(id?)`** - Public hook that wraps `useQuery` with a conditional `skipToken` so the query only runs when an `id` is provided. Returns `organization`, standard query state (via `queryState`, gated `'open'`/`'closed'` based on `id` presence), and `refetch`.
- **`CustomerDetails`** (re-exported type) - Shape of the mapped customer/organization data.

## Usage Example

```typescript
import { useCustomerDetails } from './use-customer-details';

function CustomerProfile({ customerId }: { customerId?: string }) {
  const { organization, isLoading, isError, error, refetch } = useCustomerDetails(customerId);

  if (!customerId) return <p>No customer selected</p>;
  if (isLoading) return <p>Loading...</p>;
  if (isError) return <p>Error: {error?.message}</p>;

  return (
    <div>
      <h2>{organization?.name}</h2>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}
```

When `customerId` is `undefined` or `null`, the query is skipped entirely (via `skipToken`) and the hook reports an idle/closed gate state instead of an indefinite loading state.
