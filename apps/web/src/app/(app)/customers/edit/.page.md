Renders the edit organization page by extracting a required `id` route parameter and delegating to the `NewCustomerPage` component in edit mode.

## Key Components

- **`EditOrganizationPage`** — Default export; a client-side page component that retrieves the organization ID from the URL and conditionally renders the customer edit form.
- **`useRequiredIdParam`** — Hook that validates and returns the `id` route parameter, redirecting to `/customers` or `routes.customers.new` if absent.
- **`NewCustomerPage`** — Shared form component used for both creating and editing customers, driven by the presence of `organizationId`.

## Usage Example

```typescript
// Mounted automatically by Next.js at a route such as:
// /customers/[id]/edit

// When a valid ID is present in the URL:
// → Renders <NewCustomerPage organizationId="abc-123" />

// When the ID is missing or invalid:
// → Redirects to /customers or routes.customers.new
// → Returns null to prevent render
```

## Notes

- The `'use client'` directive marks this as a Client Component, enabling hooks.
- Guard pattern (`if (!id) return null`) prevents rendering before a redirect completes.
- Reuses `NewCustomerPage` for both create and edit flows, keeping UI logic consolidated.
