# scripts-tabs.tsx

A client-side navigation component that renders tab controls for switching between the Scripts and Script Schedules pages, which are implemented as separate routes rather than tab-state views of a single page.

## Key Components

- **`ScriptsTabNavigation`** — React component that renders a `TabNavigation` UI element, translating tab clicks into route pushes via Next.js's `useRouter`.
- **`ScriptsTabNavigationProps`** — Props interface requiring `activeTab: ScriptsTabId` to indicate which tab is currently active.
- **`handleTabChange`** — Memoized callback that navigates to `routes.scripts.schedules.list` or `routes.scripts.list` depending on the selected tab, short-circuiting if the tab is already active.

The component also checks `useManhattanDock()` — when the app is rendered inside the Manhattan v2 shell's navigation dock (`inNavigation` is `true`), it returns `null` since the shell's own navigation already lists both destinations, avoiding duplicate tab UI.

## Usage Example

```typescript
import { ScriptsTabNavigation } from './scripts-tabs';

export default function ScriptsPage() {
  return (
    <div>
      <ScriptsTabNavigation activeTab="scripts" />
      {/* page content */}
    </div>
  );
}

export default function ScriptSchedulesPage() {
  return (
    <div>
      <ScriptsTabNavigation activeTab="schedules" />
      {/* page content */}
    </div>
  );
}
```

**Notes:**
- `activeTab` must match one of the IDs defined in `SCRIPTS_TABS` (e.g., `'scripts'` or `'schedules'`).
- This component holds no internal tab state — it is a pure navigation trigger (`urlSync={false}`), relying entirely on route changes to reflect the active page.
- Rendering is suppressed automatically when inside the Manhattan dock shell to prevent duplicate navigation controls.
