# script-param-rows.tsx

Renders script argument/environment-variable pairs as aligned `key ——— value` leader rows, handling empty values, secrets, and loading states consistently across the app.

## Key Components

- **`ScriptParamRow`** — Interface describing a single row: `id`, `label`, `value`, plus optional `muted`, `hint`, and `secret` flags.
- **`argsToParamRows(args)`** — Converts `"key value"` string arguments (parsed via `parseKeyValues`) into `ScriptParamRow[]`; a bare key renders as a "flag" value.
- **`envPairsToParamRows(pairs)`** — Converts `ScriptArgument` env-var pairs (from GraphQL `envVars`) into `ScriptParamRow[]`; a key with no value renders as "empty".
- **`ScriptParamRows`** — React component that renders the rows list, showing:
  - A skeleton loader (via `useLoadingScope` or the `loading` prop) using `LoadingItems` + `LeaderRow`.
  - `emptyText` when there are no rows.
  - Each row with a lock icon for secrets, truncated labels/values, and a tooltip (`FloatingTooltip`) explaining muted/secret values.

Secret values are always masked client-side (`**********`) regardless of whether a value was returned by the server, ensuring consistent masking with the editor UI.

## Usage Example

```vue
<script setup lang="ts">
import {
  ScriptParamRows,
  argsToParamRows,
  envPairsToParamRows,
} from './script-param-rows';

const argRows = argsToParamRows(['--verbose true', '--dry-run']);
const envRows = envPairsToParamRows([
  { id: '1', key: 'API_KEY', value: '', secret: true },
  { id: '2', key: 'REGION', value: 'us-east-1' },
]);
</script>

<template>
  <ScriptParamRows :rows="argRows" empty-text="No arguments" />
  <ScriptParamRows :rows="envRows" empty-text="No environment variables" />
</template>
```

```typescript
// Direct function usage
const rows = argsToParamRows(['--force', '--level 3']);
// rows[0]: { label: '--force', value: 'flag', muted: true, hint: 'Passed as a flag — no value' }
// rows[1]: { label: '--level', value: '3' }
```
