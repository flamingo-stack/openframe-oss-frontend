## executions-table.tsx

Shared client component implementing the Execution History table used by both the per-script and per-schedule execution tabs. It defines the row shape, column layout, URL-synced filter/search state, and the sticky toolbar/infinite-scroll behavior, leaving only the Relay query wiring to the callers.

## Key Components

- **`EXECUTIONS_PAGE_SIZE`** – Default page size constant for paginated execution queries.
- **`UiExecution`** – Flattened row shape rendered by the table (status, timestamp, machine, initiator, result, etc.).
- **`toUiExecution(ref, scriptName?)`** – Converts a Relay `executionFields_execution` fragment reference into a `UiExecution` row.
- **`narrowExecutions(executions, term)`** – Client-side text filter across execution fields, used when server-side search is unavailable.
- **`ExecutionFacetOptions`** / **`useExecutionFacetOptions(ref)`** – Derives filter dropdown options (status, machine, initiator) from server-provided facets.
- **`ExecutionsTableProps`** – Props contract for `ExecutionsTable`, covering rows, facets, filters, pagination, date filtering, empty states, and sticky header offset.
- **`OpenExecutionButton`** – Button that opens an execution's detail page in a new tab, disabled while a loading scope is active.
- **`executionColumns(...)`** – Builds the shared `ColumnDef<UiExecution>[]` array (timestamp/calendar header, status, etc.) used identically by loaded and loading table states.

## Usage Example

```typescript
import { ExecutionsTable, toUiExecution, useExecutionFacetOptions } from './executions-table';

function ScriptExecutionsTab({ queryData }: { queryData: any }) {
  const executions = queryData.edges.map(edge => toUiExecution(edge.node.fragmentRef));
  const facetOptions = useExecutionFacetOptions(queryData.filters);

  return (
    <ExecutionsTable
      executions={executions}
      facetOptions={facetOptions}
      tableFilters={{}}
      onFilterChange={() => {}}
      isPending={false}
      hasNext={queryData.pageInfo.hasNextPage}
      isLoadingNext={false}
      onLoadMore={() => {}}
      search=""
      dateFilter={{ range: null, sort: 'DESC' }}
      emptyState={{ title: 'No executions', description: 'Nothing to show yet' }}
      stickyHeaderOffset="56px"
      mobileFilterOpen={false}
      onMobileFilterClose={() => {}}
    />
  );
}
```
