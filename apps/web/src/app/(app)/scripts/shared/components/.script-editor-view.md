## ScriptEditorView

CodeMirror 6-based code editor component for editing shell/automation scripts with syntax highlighting for Bash, PowerShell, Python, SQL, and JavaScript/TypeScript (Deno). Split from `script-editor.tsx` to keep the CodeMirror library in its own lazy-loaded chunk, swapping in for `ScriptEditorPlaceholder` once the real editor is ready.

## Key Components

- **`ScriptEditorView`** — Default export; the React component that mounts and manages the CodeMirror `EditorView` instance.
- **`odsTheme`** — CodeMirror theme (`EditorView.theme`) implementing the dark `ods-dark` palette, with pixel geometry intentionally matching `ScriptEditorPlaceholder`.
- **`odsHighlight`** — `HighlightStyle` mapping Lezer syntax tags to the theme's token colors.
- **`languageFor(shellId)`** — Resolves a shell/language identifier (`powershell`, `python`, `sql`, `deno`, `cmd`, or default shell/bash) to a CodeMirror language `Extension`.
- **`editableFor(readOnly)`** — Returns read-only or active-line-highlighting extensions depending on edit mode.
- **`externalSync`** — `Annotation` used to mark programmatic document updates so the `updateListener` doesn't echo them back as user edits.
- **`toDocText` / `fromDocText` / `eolOf`** — Helpers that normalize and restore `\r\n` vs `\n` line endings, since CodeMirror documents only store LF internally.
- **`ScriptEditorViewProps`** — Props interface: `value`, `onChange`, `shell`, `readOnly`, `onReady`.

## Usage Example

```typescript
import ScriptEditorView from './script-editor-view';

function MyScriptEditor() {
  const [code, setCode] = useState('#!/bin/bash\necho "hello"');

  return (
    <ScriptEditorView
      value={code}
      onChange={setCode}
      shell="bash"
      readOnly={false}
      onReady={() => console.log('Editor mounted')}
    />
  );
}
```

This component is typically lazy-loaded via `prewarmScriptEditor` and rendered inside a wrapper (`script-editor.tsx`) that displays `ScriptEditorPlaceholder` until `onReady` fires, ensuring a seamless visual transition with matching geometry (line height, gutter width, padding).
