# script-editor.tsx

A code-splitting wrapper around a CodeMirror-based script editor that renders a pixel-matched skeleton placeholder until the real editor is built and ready, avoiding layout shift and loading flashes.

## Key Components

- **`ScriptEditor`** — The main exported component. Renders a fixed-height framing `<div>` containing the lazily-loaded `Editor` and an overlaid `ScriptEditorPlaceholder`. Props:
  - `value: string` — current script content
  - `onChange?: (value: string) => void` — change handler
  - `shell?: string` — shell/language mode (default `"bash"`)
  - `readOnly?: boolean`
  - `height?: string` — fixed height applied to the wrapper (default `"400px"`)
  - `invalid?: boolean` — draws an error border
  - `loading?: boolean` — keeps the placeholder visible while content is still arriving
  - `className?: string` — merged into the framing wrapper for embedding in custom containers

- **`prewarmScriptEditor()`** — Idempotent, idle-scheduled function that pre-fetches the editor's JS chunk before it's actually needed (e.g., call it when a collapsed card that might reveal an editor is rendered). Uses `requestIdleCallback` when available, falling back to a `setTimeout` delay.

- **`ScriptEditorPlaceholder`** (internal) — Renders skeleton rows matching the real editor's exact line geometry (gutter width, line height, code column inset) so the swap from placeholder to live editor doesn't shift layout.

- **`Editor`** (internal) — `next/dynamic` import of `./script-editor-view` with `ssr: false` and no built-in loading state, since the placeholder above handles that role persistently.

## Usage Example

```typescript
import { ScriptEditor, prewarmScriptEditor } from './script-editor';

function ScriptCard({ script, onScriptChange, isExpanded }: ScriptCardProps) {
  // Pre-fetch the editor chunk as soon as this card might be expanded
  if (isExpanded) {
    prewarmScriptEditor();
  }

  return (
    <ScriptEditor
      value={script.content}
      onChange={onScriptChange}
      shell="bash"
      height="300px"
      invalid={!script.content.trim()}
      loading={script.isFetching}
      className="rounded-none border-0"
    />
  );
}
```

Call `prewarmScriptEditor()` from any surface that *might* reveal an editor (e.g., on hover or when a parent card mounts) to warm the code-split chunk ahead of the user's click.
