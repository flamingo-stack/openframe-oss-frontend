Defines Zod schemas and TypeScript types for validating the script editing form, including script arguments, environment variables, and metadata like category and supported platforms.

## Key Components

- **`scriptArgumentSchema`** - Zod schema for a single key/value argument row (used for both script arguments and environment variables). Supports optional `secret` flag (masks sensitive env vars) and `hasStoredValue` flag (indicates the server holds a secret value that isn't echoed back; an empty submission preserves the stored value).
- **`editScriptSchema`** - Main Zod schema for the edit script form, validating name, shell type, timeout bounds (1–86400 seconds), arguments, script body, run-as-user flag, environment variables, description, supported platforms, category, and `tag_ids`.
- **`EditScriptFormData`** - TypeScript type inferred from `editScriptSchema`, used for form state typing.
- **`CATEGORIES`** - Static array of allowed script category labels for UI selection.
- **`EDIT_SCRIPT_DEFAULT_VALUES`** - Default form values used to initialize the edit script form (e.g., with React Hook Form).

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import {
  editScriptSchema,
  EditScriptFormData,
  EDIT_SCRIPT_DEFAULT_VALUES,
  CATEGORIES,
} from './edit-script.types';

const form = useForm<EditScriptFormData>({
  resolver: zodResolver(editScriptSchema),
  defaultValues: EDIT_SCRIPT_DEFAULT_VALUES,
});

// Render category options
CATEGORIES.map((category) => (
  <option key={category} value={category}>{category}</option>
));

// Handling a secret env var row that keeps its stored value on submit
const envVar = { id: '1', key: 'API_KEY', value: '', secret: true, hasStoredValue: true };
```

Validation errors surface via the schema's custom messages, e.g. timeout bounds or required fields like `name`, `shell`, `supported_platforms`, and `category`.
