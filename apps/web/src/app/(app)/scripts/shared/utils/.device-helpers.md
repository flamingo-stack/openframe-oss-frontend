Utility functions for resolving device identifiers, normalizing OS/platform values, and determining shell execution context across single or multiple selected devices.

## Key Components

- **`getDevicePrimaryId(device)`** — Returns the best available unique identifier for a device, checking `machineId`, then `agent_id`, then `id` in order of preference.
- **`normalizeOsOrNull(os)`** — Normalizes a raw OS string into a platform ID (`'windows' | 'linux' | 'darwin'`), returning `null` when the string doesn't match any recognized OS keyword (unlike `normalizeDevicePlatform`, which defaults to `'darwin'`).
- **`resolveOsTypeFromDevices(devices)`** — Inspects a list of devices and returns the common platform if all devices share the same OS, or `'all'` if the selection is mixed or unrecognized.
- **`resolveShellForExecution(resolvedOsType, scriptShell)`** — Picks the appropriate shell command (`'powershell'`, `'cmd'`, or `'/bin/bash'`) based on OS type and an optional shell preference for Windows.

## Usage Example

```typescript
import {
  getDevicePrimaryId,
  resolveOsTypeFromDevices,
  resolveShellForExecution,
} from './device-helpers';

const selectedDevices = [
  { id: '1', machineId: 'm-1', osType: 'Windows 11' },
  { id: '2', machineId: 'm-2', osType: 'Windows Server 2019' },
];

// Get unique IDs for the selected devices
const ids = selectedDevices.map(getDevicePrimaryId);

// Determine shared OS type across selection
const osType = resolveOsTypeFromDevices(selectedDevices); // 'windows'

// Resolve shell to execute a script with
const shell = resolveShellForExecution(osType, 'powershell'); // 'powershell'
```

This is typically used in bulk device action flows (e.g., script execution dialogs) where the UI must adapt shell options and command syntax based on the OS of the currently selected devices.
