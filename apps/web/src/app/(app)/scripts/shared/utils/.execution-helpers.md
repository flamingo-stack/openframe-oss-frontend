# execution-helpers.ts

Presentation helpers for script execution data, shared between the Execution History table and single-execution details page to keep status labels, tag colors, and initiator displays consistent across views.

## Key Components

- **`TagVariant`** — Type alias for `ScriptExecutionStatusVariant`, used for tag coloring.
- **`executionStatusLabel(status)`** — Returns a human-readable label for an execution status (e.g., `SUCCESS` → "Completed"); falls back to the raw string or `EMPTY_VALUE`.
- **`executionStatusVariant(status)`** — Returns the tag color variant for a status, defaulting to `'grey'`.
- **`isExecutionInFlight(status)`** — Returns `true` if the execution is still queued or running (not yet in a final state).
- **`privilegeLevelLabel(level)`** — Maps `PrivilegeLevel` enum values (`ADMIN`, `USER`, `ELEVATED_USER`) to display labels ("System", "User", "Elevated User").
- **`initiatorName(user)`** — Builds a full name from `firstName`/`lastName`, falling back to email, then `"Unknown"`.
- **`initiatorInitials(user)`** — Produces up to two uppercase initials for avatar fallbacks.
- **`executionOutput({ stdout, stderr, error })`** — Concatenates stdout, stderr, and error (in that order) with blank-line separators, since failures can print to multiple streams.

The module uses an exhaustive `Record<ScriptExecutionStatus, …>` table (`EXECUTION_STATUS_PRESENTATION`) so that when the backend schema adds a new status, type-checking fails until the presentation table is updated — preventing silent rendering of unstyled raw status strings.

## Usage Example

```typescript
import {
  executionStatusLabel,
  executionStatusVariant,
  isExecutionInFlight,
  privilegeLevelLabel,
  initiatorName,
  initiatorInitials,
  executionOutput,
} from '@/lib/execution-helpers';

const status = execution.status;

const label = executionStatusLabel(status); // "Completed"
const variant = executionStatusVariant(status); // "green"
const pending = isExecutionInFlight(status); // false

const privilege = privilegeLevelLabel(execution.privilegeLevel); // "Elevated User"

const name = initiatorName(execution.initiator); // "Jane Doe"
const initials = initiatorInitials(execution.initiator); // "JD"

const output = executionOutput({
  stdout: execution.stdout,
  stderr: execution.stderr,
  error: execution.error,
}); // combined log text for display
```
