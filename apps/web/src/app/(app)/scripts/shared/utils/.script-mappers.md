# script-mappers.ts

Translation layer that converts between the UI's form-shaped script model and the native OpenFrame GraphQL Script model. This keeps the v2 views able to reuse existing presentational components while isolating all schema/model differences in one place.

## Key Components

- **`shellToEnum(shell)` / `shellToId(shell)`** — Converts between the lowercase UI shell id and the `ScriptShell` enum, with a safe default (`ScriptShell.SHELL`).
- **`platformsToEnums(ids)` / `platformsToIds(enums)`** — Converts between UI platform ids (`windows`, `darwin`, `linux`) and the `OsType` enum. Mapping tables are keyed on strings (not enum members) so renamed/removed enum members fail gracefully rather than breaking the build.
- **`ScriptEnvVarInput`** — Input shape for env vars sent to the GraphQL API, with special `null`-value semantics for untouched stored secrets ("keep what you hold").
- **`StoredEnvVar`** — Shape of env vars as returned by the schema (secrets arrive with `value: null`).
- **`envVarsToInput(pairs)`** — Converts form key/value pairs to `ScriptEnvVarInput[]`, preserving the mask-vs-value distinction for secrets.
- **`envVarsToPairs(envVars)`** — Converts GraphQL env vars back to form pairs, flagging untouched secrets with `hasStoredValue`.
- **`ScriptWriteInput`** — Full payload shape for create/update GraphQL mutations.
- **`formToWriteInput(data)`** — Converts `EditScriptFormData` into a `ScriptWriteInput` ready for the API (handles shell, privilege level, args serialization, tags, etc.).
- **`ScriptDetailNode`** — Shape of a script node as returned by the Relay/GraphQL query.
- **`relayScriptToForm(node)`** — Converts a `ScriptDetailNode` into `EditScriptFormData` for populating the edit form.

## Usage Example

```typescript
import { formToWriteInput, relayScriptToForm } from './script-mappers';

// Loading a script into the edit form
const formData = relayScriptToForm(scriptQueryResult.script);

// Saving the form back to the API
const input = formToWriteInput(formData);
await updateScriptMutation({ variables: { id: scriptId, input } });
```

Secrets round-trip correctly: an untouched stored secret is shown masked (empty field + `hasStoredValue: true`) and sent back as `value: null`, so the server keeps the existing secret unless the user types a new value.
