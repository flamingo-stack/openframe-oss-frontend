Provides bidirectional mapping between the UI's form model (`EditScriptFormData`) and the OpenFrame GraphQL `Script` model, translating enums, platform IDs, environment variables, and form payloads for create/update operations.

## Key Components

### Shell Mapping
- **`shellToEnum(shell: string): ScriptShell`** — Converts a lowercase shell string (e.g. `"powershell"`) to its `ScriptShell` enum value; falls back to `ScriptShell.SHELL`.
- **`shellToId(shell): string`** — Converts a `ScriptShell` enum to its lowercase UI string identifier.

### Platform Mapping
- **`platformsToEnums(ids: string[]): ScriptPlatform[]`** — Maps UI platform IDs (`windows`, `darwin`, `linux`) to `ScriptPlatform` enums; handles the `darwin` → `MACOS` alias.
- **`platformsToIds(enums): string[]`** — Reverse mapping from `ScriptPlatform` enums back to UI IDs.

### Environment Variable Mapping
- **`envVarsToInput(pairs): ScriptEnvVarInput[]`** — Converts form key/value pairs to GraphQL `ScriptEnvVarInput[]` objects; filters empty keys, defaults `secret` to `false`.
- **`envVarsToStrings(envVars): string[]`** — Serializes GraphQL env vars to `"name=value"` strings for display components.
- **`envVarsToPairs(envVars): ScriptArgument[]`** — Converts GraphQL env vars to form key/value pairs.

### Form ↔ GraphQL Conversion
- **`formToWriteInput(data: EditScriptFormData): ScriptWriteInput`** — Maps a complete form payload to a GraphQL create/update input; handles `run_as_user` → `PrivilegeLevel`, args serialization, and tag replacement (PUT semantics).
- **`relayScriptToForm(node: ScriptDetailNode): EditScriptFormData`** — Hydrates an edit form from a fetched GraphQL `Script` node; applies defaults for nullable/missing fields.

## Usage Example

```typescript
import { formToWriteInput, relayScriptToForm } from './script-mappers';

// Hydrate form from a fetched GraphQL script node
const formValues = relayScriptToForm(scriptNode);

// On form submit, convert back to GraphQL input
const input = formToWriteInput(formValues);
await createScript({ variables: { input } });
```
