Client-rendered page component that displays the Scripts listing view, combining tab-based navigation with an error-bounded table of scripts.

## Key Components

- **`ScriptsPage`** - Default export; a Next.js page component that renders the Scripts list screen.
- **`ScriptsTabNavigation`** - Navigation tabs for switching between script-related views, with `"list"` set as the active tab.
- **`ContentErrorBoundary`** - Shared wrapper component that catches rendering errors within its children and displays a fallback title/message.
- **`ScriptsTable`** - Renders the actual table of scripts, wrapped in the error boundary for resilience.

## Usage Example

```typescript
// This file is a Next.js route page (app/scripts/page.tsx)
// It is automatically rendered when navigating to the /scripts route.

export default function ScriptsPage() {
  return (
    <div className="flex w-full flex-col">
      <ScriptsTabNavigation activeTab="list" />
      <ContentErrorBoundary title="Scripts" message="Couldn't load scripts.">
        <ScriptsTable />
      </ContentErrorBoundary>
    </div>
  );
}
```

**Notes:**
- Marked with `'use client'` since it relies on client-side interactivity (tab navigation and table rendering).
- The `ContentErrorBoundary` ensures that failures in fetching or rendering script data don't crash the entire page, showing a friendly error message instead.
- Part of a larger Scripts feature module, alongside sibling components like `ScriptsTabNavigation` (shared across script-related tabs) and `ScriptsTable` (script-specific listing).
