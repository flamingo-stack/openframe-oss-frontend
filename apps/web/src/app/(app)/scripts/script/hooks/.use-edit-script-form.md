React Hook Form integration for the script editor that handles both create and edit modes, managing form state, validation, and GraphQL mutations via Relay.

## Key Components

### Schema Extension

`editScriptFormSchema` extends the shared `editScriptSchema` with two overrides:
- `script_body` — made required (min 1 character) to surface syntax errors in the editor
- `category` — relaxed to a plain string (field is hidden; not a validation gate)

### `CREATE_SCRIPT_DEFAULT_VALUES`

Extends `EDIT_SCRIPT_DEFAULT_VALUES` with one pre-populated empty row for `args` and `env_vars` so the input fields are visible on the create page. Empty rows are stripped before submission.

### `useEditScriptForm(options)`

The primary export. Accepts:

| Option | Type | Description |
|---|---|---|
| `scriptId` | `string \| null` | ID of the script when editing |
| `initialValues` | `EditScriptFormData \| null` | Seeded from the Relay store |
| `isEditMode` | `boolean` | Toggles create vs. update flow |

Returns:

| Return | Type | Description |
|---|---|---|
| `form` | `UseFormReturn` | Full RHF form instance |
| `isSubmitting` | `boolean` | `true` while either mutation is in-flight |
| `handleSave` | `() => void` | Validates and submits; toasts on error |

**Key behaviors:**
- `mode: 'onChange'` — programmatically set errors (e.g., pre-test checks) auto-clear when the field becomes valid
- `useEffect` re-seeds the form from a background Relay refresh **only while `!isDirty`**, preserving in-progress edits
- On successful create, redirects to the new script's detail page; on update, navigates back or to the detail page

## Usage Example

```typescript
const { form, isSubmitting, handleSave } = useEditScriptForm({
  scriptId: '123',
  initialValues: scriptData,
  isEditMode: true,
});

// Trigger save (validates first, toasts on error)
<Button onClick={handleSave} disabled={isSubmitting}>
  Save Script
</Button>

// Access form state directly
const { watch, formState: { errors } } = form;
```
