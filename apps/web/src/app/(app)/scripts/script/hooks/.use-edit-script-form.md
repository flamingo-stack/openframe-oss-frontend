# use-edit-script-form.ts

Custom React hook that manages the form state, validation, and submission logic for creating and editing scripts, integrating React Hook Form with Zod validation and Relay GraphQL mutations.

## Key Components

- **`editScriptFormSchema`** — Extends the shared `editScriptSchema` with form-specific rules: `script_body` becomes required (to drive syntax error states), and `category` is relaxed since the native API has no such field.
- **`CREATE_SCRIPT_DEFAULT_VALUES`** — Default form values for the create flow, pre-seeding one empty argument row and one empty environment variable row so inputs are visible immediately.
- **`useEditScriptForm(options)`** — Main hook accepting `{ scriptId, isEditMode }` and returning:
  - `form` — the React Hook Form instance (Zod-resolved, `onChange` validation mode).
  - `isSubmitting` — boolean combining create/update mutation in-flight states.
  - `handleSave` — callback that validates and submits the form, showing toast errors and scrolling to the first invalid field on failure.

## Usage Example

```typescript
import { useEditScriptForm } from './use-edit-script-form';

function ScriptEditorPage({ scriptId }: { scriptId: string | null }) {
  const { form, isSubmitting, handleSave } = useEditScriptForm({
    scriptId,
    isEditMode: Boolean(scriptId),
  });

  return (
    <form>
      {/* Pass `form` down to field components (FormProvider or props) */}
      <button type="button" disabled={isSubmitting} onClick={handleSave}>
        {isSubmitting ? 'Saving...' : 'Save'}
      </button>
    </form>
  );
}
```

On submit, the hook converts form data via `formToWriteInput`, then dispatches either `createScriptMutation` or `updateScriptMutation` depending on `isEditMode`. On success, it shows a success toast and navigates to the script's detail page (via `safeBackOrReplace` for updates, or `router.replace` for new scripts). On failure, it surfaces a GraphQL error message via a destructive toast.
