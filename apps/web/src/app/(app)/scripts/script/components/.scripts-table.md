## scripts-table.tsx

Client-rendered table component for browsing and managing automation scripts. Built on Relay pagination fragments, it renders a filterable/sortable data grid with shell type, supported platform, and author columns, plus row-level actions (run, edit, archive/restore) and AI-assisted script creation.

## Key Components

- **`ScriptShellCell`** – Renders the shell badge (bash/powershell/etc.) with a skeleton fallback while the row is loading.
- **`ScriptAuthorCell`** – Renders the "Added by" cell; links to the employee detail page in a new tab, handles deleted-user state, and shows a loading skeleton.
- **`ScriptColumnOptions`** – Interface describing the facet filter options (`shell`, `platform`, `author`) derived from server-provided filter data.
- **`scriptColumns()`** – Builds the `ColumnDef<UiScriptEntry>[]` array shared by both the loaded table and its loading-state placeholder, wiring up filters, sorting, and row-action rendering.
- **`UiScriptEntry`** – Normalized shape of a script row used by all cell renderers (name, shell type, platforms, author info, timeout, etc.).
- **`ScriptsTableContentProps`** – Props contract for the inner Relay-powered content component (backend filters, debounced search, table filters, tag filter state, and deferred-query staleness flag).
- Uses `usePaginationFragment`, `useLazyLoadQuery`, and `useMutation` (for `archiveScriptMutation` / `unarchiveScriptMutation`) to drive paginated, filterable data fetching.

## Usage Example

```typescript
import { ScriptsTable } from './scripts-table';

export default function ScriptsPage() {
  return (
    <PageLayout title="Scripts">
      <ScriptsTable />
    </PageLayout>
  );
}
```

Internally, the table composes `scriptColumns` with live filter options and row-action renderers:

```typescript
const columns = scriptColumns({
  options: { shell: shellFacets, platform: platformFacets, author: authorFacets },
  renderRowActions: (script) => (
    <ActionsMenuDropdown
      groups={[
        { items: [{ label: 'Run', icon: PlayIcon, onClick: () => runScript(script.id) }] },
        { items: [{ label: 'Archive', icon: BoxArchiveIcon, onClick: () => archive(script.id) }] },
      ]}
    />
  ),
});
```

This component relies on GraphQL fragments (`scriptsTableRelay_query`) and generated types from `@/__generated__`, and must be rendered within a Relay environment/Suspense boundary provided by its parent page.
