## script-execution-details-view.tsx

Renders the detail page for a single script execution, showing the script, device, initiator, status, timing (in both device and viewer timezones), and output result, with live polling while the execution is still in flight.

## Key Components

- **`ScriptExecutionDetailsView`** (default export, implied by truncated content) — top-level client component accepting `executionId`, wraps content in `LoadingSuspense`/error boundary handling (e.g. `NotFoundError`).
- **`ScriptExecutionDetailsContent`** — fetches execution data via `useLazyLoadQuery` with `scriptExecutionDetailRelayQuery`, sets up polling (`IN_FLIGHT_POLL_INTERVAL_MS` = 5000ms) for in-flight executions, builds the "Copy Execution Details" page action, and computes the back navigation target.
- **`ExecutionDetailsPage`** — `PageLayout` wrapper with title, subtitle (execution ID), back button, and actions.
- **`ExecutionDetailsCard`** — the main card UI: script name/privilege, device/organization/initiator/status/execution time rows, device & viewer timezone rows (`TimingRow`), and the `ScriptExecutionResult` output block.
- **`DetailCell`** — label/value cell wrapper around the shared `InfoCell`, loading-aware.
- **`ExecutedByValue`** — renders the initiator identity plus an `ExecutionSourceBadge` (scheduled/assistant chip).
- **`TimingRow`** — reusable row showing timezone label plus start/finish times.

## Usage Example

```typescript
import { ScriptExecutionDetailsView } from './script-execution-details-view';

export default function Page({ params }: { params: { executionId: string } }) {
  return <ScriptExecutionDetailsView executionId={params.executionId} />;
}
```

Key behaviors:
- Uses Relay's `fetchQuery` in a `setInterval` to refresh data every 5 seconds while `isExecutionInFlight(execution?.status)` is true, stopping automatically once the status becomes final.
- Back navigation resolves to the parent script's execution tab via `useSafeBack`, converting the raw `scriptId` into a Relay global ID with `ensureGlobalIdForType`.
- The "Copy Execution Details" action serializes key execution fields (script name, machine, initiator, status, timestamps, result) into clipboard text, surfacing success/error via `useToast`.
- Loading states are driven by `useLoadingScope`, allowing child cells (`InfoCell`, `ExecutionStatusCell`, `InitiatorIdentity`) to render skeleton placeholders automatically when `execution` is `null`.
