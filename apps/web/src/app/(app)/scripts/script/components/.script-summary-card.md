# script-summary-card.tsx

A React client component that renders a summary card for displaying script metadata (name, description, shell type, supported platforms, timeout, and author) on script details and run pages. It supports a skeleton loading state via a shared loading-scope context.

## Key Components

- **`ScriptSummaryCard`** — Main exported component. Renders a header (name + optional description via `TitleLines`) followed by a metadata strip laid out on a 4-column flex grid using `InfoCell` for each stat.
- **`ScriptSummaryCardProps`** — Props interface: `name`, `description`, `shellId`, `platforms`, `timeoutSeconds`, `showTimeout` (default `true`), `author`.
- **`MetaSpacer`** — Internal helper that renders a trailing flex spacer to keep stat cells aligned to the `META_COLUMNS` grid when fewer than 4 stats are present.
- **`shellLabel`** — Internal helper wrapping `scriptShellLabel` to resolve a human-readable shell name from a shell id.
- **`STAT_LABELS`** — Constant map of static labels (`Shell Type`, `Supported Platforms`, `Timeout (seconds)`, `Added by`) always rendered even while loading.
- **`META_COLUMNS`** — Constant (`4`) defining the grid column count for the metadata strip.

## Usage Example

```typescript
import { ScriptSummaryCard } from '@/app/components/scripts/script-summary-card';

export function ScriptDetailsPage() {
  return (
    <ScriptSummaryCard
      name="Install Agent"
      description="Installs the monitoring agent on target devices"
      shellId="bash"
      platforms={['linux', 'darwin']}
      timeoutSeconds={120}
      author="Jane Doe"
    />
  );
}

// On a run page, hide the timeout stat (edited elsewhere) and omit author
export function ScriptRunPage() {
  return (
    <ScriptSummaryCard
      name="Cleanup Temp Files"
      shellId="powershell"
      platforms={['windows']}
      showTimeout={false}
    />
  );
}
```

Notes:
- `author` set to `undefined` omits the "Added by" stat entirely; pass `null` to show it with an empty-value placeholder.
- Wrap the component in a loading-scope provider to trigger its built-in skeleton rendering for name, description, and stat values while labels remain static.
