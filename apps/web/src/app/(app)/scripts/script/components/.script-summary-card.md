Displays a script's name, description, and metadata strip (shell type, platforms, timeout, author) in a card layout used on script details and run pages.

## Key Components

- **`ScriptSummaryCard`** — Main card component rendering the name/description header and a 4-column metadata strip. Conditionally shows timeout and author stats via `showTimeout` and `author` props.
- **Loading** — in a loading scope the same card draws itself: the labels real, the name, description and values bars.
- **`MetaStat`** / **`MetaSpacer`** — Internal layout primitives: a stat is the shared `InfoCell`; `MetaSpacer` fills remaining columns when fewer than 4 stats are present.
- **`STAT_LABELS`** — Single source of truth for metadata label strings.

## Usage Example

```typescript
// Details page (all 4 stats)
<ScriptSummaryCard
  name="Disk Cleanup"
  description="Removes temp files older than 30 days."
  shellId="bash"
  platforms={['linux', 'darwin']}
  timeoutSeconds={120}
  author="Jane Smith"
/>

// Run page (timeout hidden)
<ScriptSummaryCard
  name="Disk Cleanup"
  shellId="bash"
  platforms={['linux']}
  showTimeout={false}
  author="Jane Smith"
/>
```
