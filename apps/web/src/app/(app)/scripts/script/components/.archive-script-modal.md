Confirmation modal for archiving a script, setting its status to `ARCHIVED`. The action is reversible via a Restore flow.

## Key Components

- **`ArchiveScriptModal`** — Thin wrapper around `ConfirmDialog` pre-configured with archive-specific copy and a destructive variant style.

### Props (`ArchiveScriptModalProps`)

| Prop | Type | Description |
|---|---|---|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle visibility |
| `onConfirm` | `() => void` | Called when the user confirms the archive action |
| `isPending` | `boolean?` | Shows `"Archiving..."` label during async operation |

## Usage Example

```typescript
const [open, setOpen] = useState(false);
const { mutate: archiveScript, isPending } = useArchiveScript();

<ArchiveScriptModal
  open={open}
  onOpenChange={setOpen}
  onConfirm={() => archiveScript({ scriptId })}
  isPending={isPending}
/>
```

## Notes

- Uses `variant="destructive"` on `ConfirmDialog` for visual emphasis.
- The archive action is **non-destructive** — scripts can be restored at any time from the Archived Scripts view.
