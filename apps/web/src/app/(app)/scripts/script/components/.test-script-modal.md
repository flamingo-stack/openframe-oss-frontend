# test-script-modal.tsx

A modal component that lets users select a single device to run a test script against, filtering devices by platform compatibility and validating that the chosen device has an active agent connection before confirming selection.

## Key Components

- **`TestScriptModal`** — Main component rendering a modal dialog with a device picker, confirm/cancel actions, and platform-aware filtering.
- **`SelectedTestDevice`** — Interface describing the data returned on confirmation (`machineId` and `deviceName`).
- **`TestScriptModalProps`** — Props interface: `isOpen`, `onClose`, `onDeviceSelected`, and `supportedPlatforms`.

## Behavior

- Renders `DeviceListPicker` only when `isOpen` is `true`, ensuring its underlying data query (Relay) only runs while the modal is mounted/open.
- If `supportedPlatforms` is empty, shows a placeholder message instead of the device list.
- Devices without a `machineId` (no connected agent) are disabled in the picker with a tooltip-style message.
- On confirm, validates that a device is selected and has a `machineId`, showing a destructive toast otherwise.
- Resets selection state on both confirm and cancel to avoid stale state on reopen.

## Usage Example

```typescript
import { useState } from 'react';
import { TestScriptModal, type SelectedTestDevice } from './test-script-modal';

function RunScriptButton() {
  const [isModalOpen, setModalOpen] = useState(false);

  const handleDeviceSelected = (device: SelectedTestDevice) => {
    console.log('Running script on', device.deviceName, device.machineId);
    // trigger script execution against device.machineId
  };

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Test Script</button>
      <TestScriptModal
        isOpen={isModalOpen}
        onClose={() => setModalOpen(false)}
        onDeviceSelected={handleDeviceSelected}
        supportedPlatforms={['windows', 'linux']}
      />
    </>
  );
}
```
