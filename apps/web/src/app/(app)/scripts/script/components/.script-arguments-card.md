# script-arguments-card.tsx

A client-side React component that renders a titled card displaying key-value pairs (script arguments or environment variables) in a styled container, with explicit handling for empty/valueless entries.

## Key Components

- **`ScriptArgumentsCardProps`** — Interface defining the component's props: `title` (string) and `rows` (array of `ScriptParamRow`).
- **`ScriptArgumentsCard`** — Main component function. Renders a titled card containing a list of key-value rows via the shared `ScriptParamRows` component. Returns `null` if `rows` is empty, avoiding an empty card frame.

This component is built on top of the shared `ScriptParamRows` component rather than a generic `InfoCard`, specifically because it needs to support rows with no value (e.g., flags or secrets) without rendering a dangling leader line.

## Usage Example

```typescript
import { ScriptArgumentsCard } from './script-arguments-card';
import { argsToParamRows, envPairsToParamRows } from '../../shared/components/script-param-rows';

// Displaying script arguments
const argRows = argsToParamRows(['--verbose', '--output=/tmp/log.txt']);

<ScriptArgumentsCard title="Arguments" rows={argRows} />

// Displaying environment variables
const envRows = envPairsToParamRows([
  { key: 'API_KEY', value: 'secret-value' },
  { key: 'DEBUG_MODE', value: '' },
]);

<ScriptArgumentsCard title="Environment Variables" rows={envRows} />
```

## Notes

- The component is a `'use client'` component, intended for use in Next.js client-rendered contexts.
- Row data should be constructed using the `argsToParamRows` or `envPairsToParamRows` helpers (from `script-param-rows`), which determine how valueless or secret entries are displayed.
- Styling relies on design tokens (`ods-text-secondary`, `ods-border`, `ods-card`, `--spacing-system-m`) consistent with the OpenFrame design system (see design reference 1:49182).
