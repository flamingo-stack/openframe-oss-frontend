Renders a labeled card displaying a list of script arguments parsed into key-value pairs using a configurable separator character.

## Key Components

- **`ScriptArgumentsCard`** — Client component that parses an array of argument strings and displays them in an `InfoCard` with label/value columns. Returns `null` if no arguments are provided.
- **`ScriptArgumentsCardProps`** — Interface defining the component's props:
  - `title` — Label displayed above the card
  - `args` — Array of argument strings to parse and display
  - `separator` — Delimiter used to split each argument into key/value (defaults to `=`)

## Usage Example

```typescript
// Basic usage with default '=' separator
<ScriptArgumentsCard
  title="Script Arguments"
  args={['timeout=30', 'retries=3', 'verbose=true']}
/>

// Custom separator
<ScriptArgumentsCard
  title="Environment Variables"
  args={['HOST:localhost', 'PORT:8080']}
  separator=":"
/>

// Returns null — renders nothing
<ScriptArgumentsCard title="No Args" args={[]} />
```

**Parsing behavior:** Each string in `args` is split on the first occurrence of `separator`. If the separator is not found, the full string becomes the label with an empty value.

| Input | Label | Value |
|---|---|---|
| `timeout=30` | `timeout` | `30` |
| `verbose` | `verbose` | `` |
| `HOST:localhost` (`:` sep) | `HOST` | `localhost` |
