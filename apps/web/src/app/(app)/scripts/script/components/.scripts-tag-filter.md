# scripts-tag-filter.tsx

Client component that renders the tag-filtering UI for the Scripts list, combining a free-text search input with selectable tag chips sourced from a GraphQL query. It wraps data fetching in a Suspense boundary so the search input remains interactive while tags load asynchronously, and supports scoping the tag set to either active or archived scripts.

## Key Components

- **`ScriptsTagFilter`** — Public entry point. Wraps `ScriptsTagFilterReader` in a `LoadingSuspense` boundary with a loading label, ensuring consistent fallback UI.
- **`ScriptsTagFilterReader`** — Detects whether it's rendering inside a loading scope (via `useLoadingScope`) and short-circuits to an empty-tag state instead of issuing a query, avoiding redundant fetches during suspense.
- **`ScriptsTagFilterContent`** — Executes `scriptTagsRelayFilterQuery` via `useLazyLoadQuery`, scoping results by the `archived` flag, and maps the response into `SelectableTag` objects.
- **`ScriptsTagFilterBar`** — Shared presentational component that renders `TagFilterBar` for both loading and loaded states, guaranteeing visual consistency regardless of data availability.
- **`ScriptsTagFilterProps`** — Interface defining `search`, `onSearchChange`, `tagIds`, `onTagIdsChange`, optional `filterButton`, and optional `archived` flag.

## Usage Example

```typescript
import { useState } from 'react';
import { ScriptsTagFilter } from '@/app/components/scripts/scripts-tag-filter';

function ScriptsListToolbar() {
  const [search, setSearch] = useState('');
  const [tagIds, setTagIds] = useState<string[]>([]);

  return (
    <ScriptsTagFilter
      search={search}
      onSearchChange={setSearch}
      tagIds={tagIds}
      onTagIdsChange={setTagIds}
      archived={false}
    />
  );
}
```

Pass `archived={true}` when rendering the toolbar on an Archived Scripts page to scope the tag chips to tags actually assigned to archived scripts rather than active ones.
