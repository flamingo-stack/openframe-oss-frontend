Renders the tag-based filter bar for the Scripts list by fetching tags assigned to scripts via a Relay lazy query, scoping results to either active or archived scripts.

## Key Components

- **`ScriptsTagFilter`** — Main filter component that queries `scriptsTags` via `useLazyLoadQuery` and renders a `TagFilterBar`. Owns its Suspense boundary: while the tags load the same bar draws itself in a loading scope.
- **`ScriptsTagFilterProps`** — Accepts `search`/`onSearchChange` for free-text input, `tagIds`/`onTagIdsChange` for selected tag state, an optional `filterButton` node, and `archived` to scope the tag query.

## Usage Example

```typescript
import { ScriptsTagFilter } from './scripts-tag-filter';

function ScriptsToolbar({ search, setSearch, tagIds, setTagIds, archived }) {
  return (
    <ScriptsTagFilter
      search={search}
      onSearchChange={setSearch}
      tagIds={tagIds}
      onTagIdsChange={setTagIds}
      archived={archived}
    />
  );
}
```

The `archived` prop toggles the GraphQL variable between `true` (Archived Scripts page) and `null` (active scripts), ensuring the tag chips shown are always relevant to the current list view.
