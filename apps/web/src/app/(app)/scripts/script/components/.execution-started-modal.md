# Execution Started Modal

A confirmation modal component that notifies users a script has been successfully submitted for execution, with a call-to-action to navigate to results tracking.

## Key Components

- **`ExecutionStartedModalProps`** — Interface defining component props:
  - `isOpen` / `onClose` — modal visibility control
  - `scriptName` — name of the submitted script, highlighted in the body text
  - `onViewResults` — callback triggered by the primary CTA button
  - `viewLabel` (optional) — customizes the CTA button text (defaults to `'View Execution History'`)
  - `resultsLocation` (optional) — customizes the body text's reference to where results live (defaults to `'execution history'`)
- **`ExecutionStartedModal`** — Functional component rendering a `SimpleModal` with a confirmation message and a two-button footer (`Close` and a results-navigation CTA).

## Usage Example

```typescript
import { ExecutionStartedModal } from '@/app/components/shared/execution-started-modal';
import { useState } from 'react';
import { useRouter } from 'next/navigation';

function ScriptRunner() {
  const [showModal, setShowModal] = useState(false);
  const router = useRouter();

  const handleRunScript = async () => {
    await submitScript();
    setShowModal(true);
  };

  return (
    <>
      <button onClick={handleRunScript}>Run Script</button>
      <ExecutionStartedModal
        isOpen={showModal}
        onClose={() => setShowModal(false)}
        scriptName="cleanup-temp-files.sh"
        onViewResults={() => router.push('/executions')}
      />
    </>
  );
}
```

Customizing labels for a different context (e.g., device-specific tracking):

```typescript
<ExecutionStartedModal
  isOpen={showModal}
  onClose={() => setShowModal(false)}
  scriptName="restart-service.sh"
  onViewResults={() => router.push(`/devices/${deviceId}/history`)}
  viewLabel="View Device History"
  resultsLocation="device's execution history"
/>
```
