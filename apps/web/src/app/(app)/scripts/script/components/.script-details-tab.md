# script-details-tab.tsx

Renders the "Script Details" tab of a script view, combining a read-only syntax-highlighted script editor with optional cards for default arguments and environment variables. Manages its own Suspense boundary so switching to this tab doesn't affect the surrounding page (header, summary, tab strip).

## Key Components

- **`ScriptDetailsTab`** — Main exported component (memoized). Accepts `scriptId` and orchestrates the param cards and script editor, keeping the editor mounted throughout loading via local state (`SourceState`).
- **`ScriptParamCards`** — Wraps the data-reading component in a `LoadingSuspense` boundary, isolating suspension to just the optional cards.
- **`ScriptParamCardsReader`** — Detects an active loading scope (`useLoadingScope`) and renders a skeleton view instead of triggering a data read.
- **`ScriptParamCardsLive`** — Executes the `scriptDetailRelayQuery` via `useLazyLoadQuery` (with `store-or-network` fetch policy to reuse data already loaded by the page), derives the `ScriptSource`, and reports it to the parent via `onResolved` inside a `useLayoutEffect` (ensures sync reveal with the editor).
- **`ScriptParamCardsView`** — Pure presentational component rendering the arguments/env-vars cards grid, or `null` when the script has no defaults.
- **`ScriptSource` / `SourceState`** — Internal types tracking the script body/shell and the loading/ready lifecycle.

## Usage Example

```typescript
import { ScriptDetailsTab } from './script-details-tab';

function ScriptPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      {/* Other tab content, header, summary... */}
      <ScriptDetailsTab scriptId={scriptId} />
    </div>
  );
}
```

The component internally fetches script data via Relay, so no props beyond `scriptId` are required. The editor stays mounted and shows its own loading placeholder (`loading={isLoading}`) while the query resolves, avoiding duplicate editor instantiation. If the resolved script has no `scriptBody`, the editor section is omitted entirely.
