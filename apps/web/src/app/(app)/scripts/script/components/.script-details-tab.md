Renders the "Script Details" tab content, composing default argument cards and a read-only script source editor into a single layout panel.

## Key Components

### `ScriptDetailsTab`
Main exported component that conditionally renders:
- **`ScriptArgumentsCard`** (×2) — Displays default script arguments and default environment variables in a two-column grid, each card shown only when the respective data is non-empty.
- **`ScriptEditor`** — Read-only syntax-highlighted editor (400px height) showing the script body, rendered only when `scriptBody` is truthy.

### `ScriptDetailsTabProps`

| Prop | Type | Description |
|---|---|---|
| `args` | `string[]` | Default arguments as `"key value"` strings |
| `envVarStrings` | `string[]` | Default env vars as `"name=value"` strings |
| `scriptBody` | `string` | Raw script source content |
| `shellId` | `string` | Lowercase shell identifier (e.g. `'bash'`) for syntax highlighting |

## Usage Example

```typescript
<ScriptDetailsTab
  args={['timeout 30', 'retries 3']}
  envVarStrings={['NODE_ENV=production', 'LOG_LEVEL=info']}
  scriptBody="#!/bin/bash\necho 'Hello, World!'"
  shellId="bash"
/>
```

## Notes

- Both argument cards are hidden entirely when `args` and `envVarStrings` are both empty — no empty grid is rendered.
- When only one card has data, an empty `<div />` fills the opposing grid column to preserve the two-column layout.
- Extracted from the parent script details view to enable tab-swapping between script details and execution history without re-rendering the full view.
