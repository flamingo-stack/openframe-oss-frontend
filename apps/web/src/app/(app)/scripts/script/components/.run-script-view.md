## run-script-view.tsx

Client-side view component that renders the "Run Script" page, letting a user configure timeout, privilege level, script arguments, environment variables, and a device selection before dispatching a batch script execution via GraphQL/Relay.

## Key Components

- **`RunScriptView`** (implied default export, driven by `scriptId` prop): wraps the form with a `LoadingSuspense`/Relay query boundary, fetching script details via `scriptDetailRelayQuery` and handling the not-found case.
- **`RunScriptForm`**: the main form component. Responsibilities:
  - Seeds form defaults (timeout, privilege level, args, env vars) from the loaded script once, guarded by `isDirty` to avoid clobbering user edits.
  - Tracks the script as the active Mingo "open view" context via `useTrackOpenView`.
  - Manages device selection state (`Device[]`) decoupled from the Suspense-bound device list.
  - Dispatches a single `batchRunScriptMutation` across all selected machine IDs under one execution.
  - Shows validation toasts, scrolls to the first invalid field on error, and opens `ExecutionStartedModal` on success.
- **`runFormSchema`** (zod schema) / **`RunFormData`**: validates `timeout` (1–86400s), `runAsUser`, `scriptArgs`, and `envVars`.
- **`getMachineId`**: extracts a device's `machineId`, filtering out incompatible devices.
- Helper utilities consumed: `parseKeyValues`/`serializeKeyValues`, `envVarsToInput`/`envVarsToPairs`, `platformsToIds`, `shellToId`, `runDeviceFilter`.

## Usage Example

```typescript
import { RunScriptView } from './run-script-view';

// Typically rendered from a Next.js route page
export default function Page({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />;
}
```

Internally, the form is driven by `react-hook-form` with a Zod resolver:

```typescript
const { control, handleSubmit, reset } = useForm<RunFormData>({
  resolver: zodResolver(runFormSchema),
  defaultValues: { timeout: 90, runAsUser: false, scriptArgs: [], envVars: [] },
});
```

Submission dispatches a batch run to all selected devices' machine IDs in one mutation call, then opens `ExecutionStartedModal`, offering navigation to the script's execution history via `routes.scripts.details(scriptId, { tab: 'executions' })`.
