# script-form-fields.tsx

Shared form-fields component rendering the editable fields of a script record (platform selection, name, shell type, category, timeout, description, arguments/env vars, and script body editor) bound to a React Hook Form instance. Designed to be reused by both the legacy scripts editor and scripts v2, with configurable field visibility and error display.

## Key Components

- **`ScriptFormFields`** — Main exported component. Renders:
  - A platform picker grid (`SelectButton` per `AVAILABLE_PLATFORMS`, with disabled/"Coming Soon" states) plus an optional "Run as User" checkbox.
  - Core fields via `Controller`: `name`, `shell` (shell type select), `category` (optional), `default_timeout`.
  - `description` textarea, optional injected `tagsField`.
  - `args` and `env_vars` editors via the shared `ScriptArguments` component.
  - `script_body` field rendered through `ScriptEditor`.
- **`ScriptFormFieldsProps`** — Prop interface controlling:
  - `form`: the `UseFormReturn<EditScriptFormData>` instance driving all fields.
  - `allowedShellIds` / `shellTypes`: restrict or fully override the Shell Type options.
  - `hideCategory` / `hideRunAsUser`: toggle fields not applicable to the native API.
  - `tagsField`: optional `ReactNode` injected after description (owned by caller for tag-fetching logic).
  - `disabled`: disables all controls (used as a loading-state substitute).
  - `showErrors`: controls whether inline validation messages are shown (defaults to `true`).

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ScriptFormFields } from './script-form-fields';
import type { EditScriptFormData } from '../../shared/types/edit-script.types';

function EditScriptPage() {
  const form = useForm<EditScriptFormData>({
    defaultValues: {
      name: '',
      shell: 'bash',
      category: 'General',
      default_timeout: 90,
      supported_platforms: [],
      description: '',
      args: [],
      env_vars: [],
      script_body: '',
      run_as_user: false,
    },
  });

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <ScriptFormFields
        form={form}
        hideCategory={false}
        hideRunAsUser={false}
        showErrors={form.formState.isSubmitted}
      />
    </form>
  );
}
```
