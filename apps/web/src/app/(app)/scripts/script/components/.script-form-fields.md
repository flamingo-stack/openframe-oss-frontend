Reusable form field group for creating and editing automation scripts, rendering all script metadata controls (platform, name, shell type, category, timeout, description, arguments, environment variables, and script body) as a single controlled component wired to a `react-hook-form` instance.

## Key Components

### `ScriptFormFields`

The sole export — a client-side React component that composes all script form inputs.

**Props (`ScriptFormFieldsProps`):**

| Prop | Type | Description |
|---|---|---|
| `form` | `UseFormReturn<EditScriptFormData>` | The `react-hook-form` instance from the parent page |
| `allowedShellIds` | `string[]` | Restrict visible shell type options by ID |
| `shellTypes` | `ShellTypeDefinition[]` | Override the shell type list entirely (Scripts v2) |
| `hideCategory` | `boolean` | Hides the Category select (native API has no category concept) |
| `hideRunAsUser` | `boolean` | Hides the "Run as User" checkbox (native API) |
| `tagsField` | `ReactNode` | Injected tags picker rendered after description |
| `disabled` | `boolean` | Disables all controls; used as a loading state |
| `showErrors` | `boolean` | Controls inline error visibility; defaults to `true` |

**Rendered sections (in order):**
1. **Supported Platform** — `SelectButton` cards per platform with an optional "Run as User" checkbox
2. **Form Fields grid** — Name, Shell Type, Category (optional), Timeout
3. **Description** — `Textarea`
4. **Tags** — injected `tagsField` slot
5. **Script Arguments / Environment Variables** — two `ScriptArguments` panels side-by-side
6. **Script Body** — `ScriptEditor` (CodeMirror 6) with shell-aware syntax highlighting

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ScriptFormFields } from './components/script-form-fields';
import type { EditScriptFormData } from './types/edit-script.types';

function EditScriptPage() {
  const form = useForm<EditScriptFormData>({
    defaultValues: {
      name: '',
      shell: 'powershell',
      supported_platforms: ['windows'],
      default_timeout: 90,
      description: '',
      args: [],
      env_vars: [],
      script_body: '',
    },
  });

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <ScriptFormFields
        form={form}
        hideCategory={false}
        showErrors={hasAttemptedSubmit}
        disabled={isLoading}
      />
    </form>
  );
}
```

## Notes

- Shell type list resolves in priority order: `shellTypes` prop → `allowedShellIds` filter → full `SHELL_TYPES`
- Platform selection allows deselecting all items; the "at least one" constraint is enforced at submit-time validation via `form.trigger`
- `disabled` doubles as a loading skeleton replacement — the parent mounts the form once and flips this flag rather than swapping between a skeleton and the real form
