Full-page view component for displaying script details, combining page chrome, header metadata, and tab-based content (script details + execution history) with Relay-powered data fetching; each data island is a `LoadingSuspense` boundary whose fallback is the same view drawing itself in a loading scope.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ScriptDetailsView` | Component | Root page component (memoized): the header island, the summary island, then the tab strip |

**Internal:** `ScriptHeader` (the suspending header island: reads the script, `store-and-network`) over `ScriptHeaderView` (the props-only header: the static title, Back and the actions; without a script it draws itself, the action slots placeholders); `ScriptSummary` over `ScriptSummaryView` (tag chips and the `ScriptSummaryCard`). Each island is a `LoadingSuspense` whose fallback is its view with no script, drawn in a loading scope. The tab bodies come from `script-detail-tabs.ts` and own their own boundaries.

## Architecture Notes

- **Not found:** a missing script renders `NotFoundError` in the summary island.
- **Mingo context tracking:** `useTrackOpenView` receives the raw DB ID (decoded from the Relay global ID) to register the script in the AI assistant's open-view context.

## Usage Example

```typescript
// Used as the page-level component in the [id] route segment
<ScriptDetailsView scriptId="U2NyaXB0OjEyMw==" />
```
