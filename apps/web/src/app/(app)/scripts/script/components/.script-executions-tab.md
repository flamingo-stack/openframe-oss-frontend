# script-executions-tab.tsx

Renders the execution history tab for a single script, displaying a paginated, filterable, and searchable table of past script runs using Relay for data fetching.

## Key Components

- **`ScriptExecutionsTab`** — Memoized default export component. Accepts a `scriptId` prop and wraps the Relay-powered content inside `ExecutionsTabShell`, which provides the toolbar (filters/search) and Suspense boundary.
- **`ScriptExecutionsContent`** — Internal component that performs the actual Relay data fetching. Must render inside the shell's Suspense boundary since it uses `useLazyLoadQuery`.
- **`EMPTY_STATE`** — Placeholder config (icon, title, description) shown when a script has no execution history.
- **`ScriptExecutionsTabProps`** — Interface requiring `scriptId: string`.

## Behavior Notes

- Uses `useLazyLoadQuery` with `scriptExecutionsRelayQuery` to fetch the first page of executions along with filter facets (`scriptExecutionFilters`) in a single round-trip.
- Uses `usePaginationFragment` with `scriptExecutionsRelayFragment` to support cursor-based pagination (`loadNext`/`hasNext`).
- Server-side search means `narrowSearch` is always empty client-side; `narrowExecutions` is called for contract consistency with other tabs.
- Defensively filters out dangling edges (nodes that may have been evicted from the Relay store).
- `fetchNextPage` guards against duplicate fetches via `hasNext && !isLoadingNext`.
- The Suspense boundary sits below the toolbar inside `ExecutionsTabShell`, so changing filters only reloads the table rows, not the search input.

## Usage Example

```typescript
import { ScriptExecutionsTab } from './script-executions-tab';

function ScriptDetailPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      {/* Other script detail tabs */}
      <ScriptExecutionsTab scriptId={scriptId} />
    </div>
  );
}
```

This component is typically rendered as one tab within a script detail view's tab set, alongside other tabs like schedule or configuration, following the pattern described in `script-detail-tabs.ts`.
