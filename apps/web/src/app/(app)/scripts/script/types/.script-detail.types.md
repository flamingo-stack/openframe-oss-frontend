Defines a shared TypeScript type representing the resolved `script` payload from the script detail GraphQL query, used across script detail, edit, and run pages.

## Key Components

- **`ScriptDetailData`** — A type alias derived from the generated `scriptDetailRelayQuery` response type, representing the non-null `script` field returned once the query resolves. By deriving this type directly from the Relay-generated query artifact (rather than manually declaring an interface), it automatically stays in sync with the GraphQL schema — any schema change will produce a compile-time error at usage sites instead of a silent runtime mismatch.

## Usage Example

```typescript
import type { ScriptDetailData } from './script-detail.types';

function renderScriptName(script: ScriptDetailData): string {
  return script.name;
}

// Typical usage after a Relay query resolves
function ScriptDetailPage({ script }: { script: ScriptDetailData }) {
  return (
    <div>
      <h1>{script.name}</h1>
      <p>{script.description}</p>
    </div>
  );
}
```

This type is typically imported wherever a component or utility function needs to consume the fully-loaded script data (e.g., script details view, script editor, or script execution panel), ensuring type safety is derived straight from the GraphQL schema contract defined in [`scriptDetailRelayQuery.graphql.ts`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/__generated__/scriptDetailRelayQuery.graphql.ts).
