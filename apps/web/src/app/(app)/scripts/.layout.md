Defines the route-level metadata and layout wrapper for the Scripts page, setting the browser tab title and re-exporting the shared layout component used across the app's authenticated routes.

## Key Components

- **`metadata`** — A Next.js `Metadata` object that sets the page title to `"Scripts"` (formatted via `routeTitle`) for use in the `<head>` of the rendered page.
- **`default export`** — Re-exports the shared `route-title-layout` component from `@/app/(app)/route-title-layout`, which likely renders a consistent header/layout structure displaying the route title across pages.

## Usage Example

This file is a Next.js route segment layout and is not imported directly; it is automatically picked up by the Next.js App Router for the `Scripts` route segment.

```typescript
// Next.js automatically applies this layout and metadata
// to any page within the same route segment, e.g.:
// app/(app)/scripts/page.tsx

// The resulting <title> tag will render as the output of:
routeTitle('Scripts'); // e.g., "Scripts | OpenFrame"
```

To customize the title for another route, create a similar `layout.tsx` file in that route's folder:

```typescript
import type { Metadata } from 'next';
import { routeTitle } from '@/lib/route-title';

export { default } from '@/app/(app)/route-title-layout';

export const metadata: Metadata = { title: routeTitle('Devices') };
```

See the layout implementation at [`route-title-layout`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/app/(app)/route-title-layout.tsx).
