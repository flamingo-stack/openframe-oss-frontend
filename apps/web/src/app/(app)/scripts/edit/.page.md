# EditScriptPageWrapper

A Next.js page component that wraps the script editing interface, handling required `id` query parameter validation before rendering the actual edit form.

## Key Components

- **`EditScriptPageWrapper`** (default export) — Page-level component that extracts the required `id` param from the URL and conditionally renders `EditScriptPage`, redirecting if the param is missing or invalid.

## Usage Example

This component is automatically rendered by Next.js routing when the corresponding route is visited (e.g., `/scripts/edit?id=123`):

```typescript
// Rendered automatically by Next.js App Router
// when navigating to the edit-script route with an id query param

export default function EditScriptPageWrapper() {
  const id = useRequiredIdParam('/scripts', routes.scripts.new);
  if (!id) return null;

  return <EditScriptPage scriptId={id} />;
}
```

The `useRequiredIdParam` hook validates the presence of an `id` query parameter:
- If valid, returns the `id` string.
- If missing/invalid, redirects to `/scripts` (fallback route) or `routes.scripts.new` (new-script route), and the component returns `null` to avoid rendering stale content.

## Notes

- This wrapper intentionally omits a `Suspense` boundary. The inner `EditScriptPage` component manages its own loading UI on first render and only suspends around the specific fields that fetch script data, enabling a smoother perceived loading experience.
- Marked `'use client'` since it relies on client-side routing hooks (e.g., reading query params).
