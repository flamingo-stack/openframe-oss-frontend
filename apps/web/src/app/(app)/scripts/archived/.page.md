Renders the "Archived Scripts" page, displaying a read-only table of scripts that have been archived, wrapped in an error boundary for graceful failure handling.

## Key Components

- **`ArchivedScriptsPage`** (default export) – Next.js page component (client component) that composes `ContentErrorBoundary` and `ScriptsTable` to display archived scripts.
- **`ContentErrorBoundary`** – Shared error boundary component that catches rendering/data errors and displays a fallback title/message.
- **`ScriptsTable`** – Reusable table component (imported from the sibling `script` feature) that lists scripts; the `archived` prop filters it to show only archived entries.

## Usage Example

This file is a Next.js route page and is rendered automatically by the framework based on its file path—no manual invocation is needed. The pattern it demonstrates can be reused for other archived-content pages:

```typescript
'use client';

import { ContentErrorBoundary } from '@/app/components/shared';
import { ScriptsTable } from '../script/components/scripts-table';

export default function ArchivedScriptsPage() {
  return (
    <ContentErrorBoundary
      title="Archived Scripts"
      message="Couldn't load archived scripts."
    >
      <ScriptsTable archived />
    </ContentErrorBoundary>
  );
}
```

**Notes:**
- Marked `'use client'` since it relies on client-side rendering (likely due to `ScriptsTable`'s interactivity, e.g., data fetching/state).
- The `archived` boolean prop toggles `ScriptsTable` between active and archived script views, avoiding duplication of table logic across pages.
