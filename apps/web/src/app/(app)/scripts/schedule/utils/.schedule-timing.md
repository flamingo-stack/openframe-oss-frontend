## schedule-timing.ts

Timing model helpers for Script Schedules v2, bridging the backend's UTC-based `startAt`/`repeat` representation with the local wall-clock values users interact with in the UI. Covers trigger/timing-reference labeling, duration ↔ seconds conversions, offline-behavior labeling, and instant/local-time conversion for scheduling forms and read-only displays.

## Key Components

- **`triggerToLabel(trigger)`** — Human label for a schedule trigger (`"Device Online"` vs `"Date & Time"`).
- **`resolveTimeReference(timeReference)`** — Narrows a stored/raw `timeReference` to `DEVICE_LOCAL` or `SERVER` (defaulting to `SERVER`).
- **`durationToSeconds(interval, unit)`** / **`secondsToDuration(seconds)`** — Convert between a form's `{ interval, unit }` pair and stored seconds, picking the coarsest exact unit.
- **`resolveDurationSeconds(interval, unit, storedSeconds)`** — Decides whether to keep a stored seconds value or recompute from form input, avoiding lossy round-trips on untouched fields.
- **`offlineBehaviorToLabel(behavior, reconnectWindowSeconds)`** — Read-only label like `"Retry for 1 Week"` or `"Skip this Run"`.
- **`resolveOfflineBehavior(behavior)`** — Narrows a stored/raw offline behavior to `RETRY_ON_RECONNECT` or `SKIP` (defaulting to `SKIP`).
- **`repeatToLabel(repeat)`** — Label for a schedule's recurrence (`"Once"`, `"1 Week"`, etc.).
- **`DEVICE_LOCAL_TIME_NOTE`** — Constant string (`"Device local"`) used to annotate device-local times in UI.
- **`toScheduleInstant(date, timeReference)`** — Converts a picked local `Date` into the UTC `Instant` to persist, handling `SERVER` (true UTC conversion) vs `DEVICE_LOCAL` (wall-clock digits stamped with `Z`) semantics differently.
- **`formatScheduleStartAt(iso, timeReference)`** — Converts a stored `startAt` into `{ date, time }` strings for display, respecting the timezone semantics of the schedule's `timeReference`.

## Usage Example

```typescript
import {
  toScheduleInstant,
  formatScheduleStartAt,
  resolveDurationSeconds,
  repeatToLabel,
  offlineBehaviorToLabel,
} from './schedule-timing';
import { ScheduleTimeReference } from '@/generated/schema-enums';

// Convert a picked local date/time into the instant to save
const startAt = toScheduleInstant(pickedDate, ScheduleTimeReference.SERVER);

// Display the stored start time in the viewer's local timezone
const { date, time } = formatScheduleStartAt(startAt, ScheduleTimeReference.SERVER);

// Compute seconds to persist from a duration form, preserving untouched values
const repeatSeconds = resolveDurationSeconds(1, 'week', existingSchedule.repeat);

// Human-readable summaries
const repeatLabel = repeatToLabel(repeatSeconds); // "1 Week"
const offlineLabel = offlineBehaviorToLabel(
  existingSchedule.offlineBehavior,
  existingSchedule.reconnectWindowSeconds,
); // "Retry for 1 Week"
```
