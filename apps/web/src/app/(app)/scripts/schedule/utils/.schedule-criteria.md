Defines the `ScheduleCriteria` model used by the "Select Devices by Criteria" rule editor for script schedules, along with conversion helpers to move between the editor's in-memory shape, the GraphQL-stored shape, and the device filter used for live device-matching previews.

## Key Components

- **`ScheduleCriteria`** — editor-facing shape with three whitelist arrays (`organizationIds`, `deviceTypes`, `osTypes`). Empty arrays mean "no constraint," not "nothing matches"; dimensions are AND'd together, values within a dimension are OR'd.
- **`EMPTY_SCHEDULE_CRITERIA`** — constant representing an unconstrained rule (targets all devices).
- **`StoredScheduleCriteria`** — readonly, nullable-array shape matching the persisted `ScriptSchedule.deviceCriteria` GraphQL type.
- **`criteriaFromStored(stored)`** — converts stored (possibly null/undefined) criteria into the editor's `ScheduleCriteria` shape, normalizing nulls to empty arrays.
- **`criteriaToFilter(criteria)`** — converts criteria into a `DeviceFilterInput` for querying `availableDevicesForSchedule`, omitting empty dimensions so the server's own matching logic powers the live preview.
- **`criteriaToInput(criteria)`** — converts criteria into the mutation input shape, always including empty arrays (rather than omitting fields) so clearing a dimension is explicit.
- **`isCriteriaUnconstrained(criteria)`** — returns `true` if the rule has no constraints in any dimension.
- **`criteriaEqual(a, b)`** — order-insensitive equality check between two criteria objects, useful for dirty-state checks in the editor.

## Usage Example

```typescript
import {
  criteriaFromStored,
  criteriaToFilter,
  criteriaToInput,
  isCriteriaUnconstrained,
  criteriaEqual,
  EMPTY_SCHEDULE_CRITERIA,
} from './schedule-criteria';

// Hydrate editor state from a saved schedule
const criteria = criteriaFromStored(schedule.deviceCriteria);

// Preview matching devices via the device filter query
const filter = criteriaToFilter(criteria);
const { devices } = await availableDevicesForSchedule(filter);

// Check if the rule targets all devices
if (isCriteriaUnconstrained(criteria)) {
  console.log('This schedule applies to all supported devices');
}

// Save changes only if the rule actually changed
if (!criteriaEqual(criteria, EMPTY_SCHEDULE_CRITERIA)) {
  await updateSchedule({ deviceCriteria: criteriaToInput(criteria) });
}
```
