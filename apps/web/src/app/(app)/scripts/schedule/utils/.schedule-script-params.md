# schedule-script-params.ts

Handles per-script argument and environment variable overrides ("custom scripts") for schedules — managing the sparse, field-level inheritance model where a schedule either overrides a script's defaults or inherits them, tracked independently for args and env vars.

## Key Components

- **`StoredScriptCustomParams`** — shape of a stored override as returned by queries/mutations (`scriptId`, optional `args`, optional `envVars`).
- **`toEnvVarInputs(envVars)`** — converts stored env vars (with nullable/masked secret values) into the write-shape `ScriptEnvVarInput[]`, preserving the masked-secret null so untouched secrets don't generate spurious overrides.
- **`ScriptCustomParamsInput`** — the write shape expected by `ScheduledScriptCustomParamsInput`; `args`/`envVars` are `null` to mean "inherit", or a full array to mean "replace".
- **`ScriptParamsEntry`** — a form-level record of one script's run parameters plus its underlying defaults, used to diff against defaults.
- **`customParamsByScriptId(params)`** — indexes stored overrides by `scriptId` for quick lookup when seeding the form.
- **`effectiveScriptParams(script, custom)`** — resolves what a script actually runs with: override values if present, otherwise the script's own defaults (field by field, using `??` to respect empty-array overrides).
- **`collectScriptCustomParams(entries)`** — converts form rows back into the sparse override list to submit, emitting an override only for fields that differ from defaults, and de-duplicating repeated script entries.

## Usage Example

```typescript
import {
  customParamsByScriptId,
  effectiveScriptParams,
  collectScriptCustomParams,
  type ScriptParamsEntry,
} from './schedule-script-params';

// Seeding the form from stored data
const overridesById = customParamsByScriptId(schedule.scriptCustomParams);
const { args, envVars } = effectiveScriptParams(script, overridesById.get(script.id));

// Building the form entry
const entry: ScriptParamsEntry = {
  scriptId: script.id,
  args: /* ScriptArgument[] from args */ [],
  envVars: /* ScriptArgument[] from envVars */ [],
  defaultArgs: script.defaultArgs ?? [],
  defaultEnvVars: toEnvVarInputs(script.envVars),
};

// Submitting the form
const scriptCustomParams = collectScriptCustomParams([entry]);
// => only includes overrides for fields that diverge from script defaults
```
