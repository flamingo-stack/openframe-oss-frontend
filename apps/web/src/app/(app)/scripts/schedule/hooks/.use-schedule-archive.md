# use-schedule-archive.ts

A React hook that provides archive/unarchive functionality for a script schedule, including mutation execution, status detection, and toast notifications for success and failure states.

## Key Components

- **`useScheduleArchive(schedule)`** — Hook accepting a `ScheduleDetailData | null | undefined` record and returning:
  - `isArchived` — boolean derived from `schedule.status === ScriptStatus.ARCHIVED`.
  - `isArchiving` — pending state of the archive mutation.
  - `isPending` — combined pending state of either the archive or unarchive mutation.
  - `toggleArchive(onSettled?)` — callback that commits the appropriate mutation (archive or unarchive) based on the schedule's current status, shows a success or error toast, and invokes `onSettled` on completion or failure (e.g., to close a confirmation dialog).

The hook relies on two generated Relay mutations (`archiveScriptScheduleMutation` and `unarchiveScriptScheduleMutation`) and does not pass any Relay `connections` for pruning, since list views own and refetch their own connections.

## Usage Example

```typescript
import { useScheduleArchive } from './use-schedule-archive';

function ScheduleActionButton({ schedule }: { schedule: ScheduleDetailData }) {
  const { isArchived, isPending, toggleArchive } = useScheduleArchive(schedule);
  const [confirmOpen, setConfirmOpen] = useState(false);

  const handleConfirm = () => {
    toggleArchive(() => setConfirmOpen(false));
  };

  return (
    <>
      <button disabled={isPending} onClick={() => setConfirmOpen(true)}>
        {isArchived ? 'Unarchive' : 'Archive'}
      </button>
      {confirmOpen && (
        <ConfirmDialog
          onConfirm={handleConfirm}
          onCancel={() => setConfirmOpen(false)}
        />
      )}
    </>
  );
}
```

**Notes:**
- Pass `null`/`undefined` safely; `toggleArchive` becomes a no-op until a valid `schedule` is provided.
- The toast variant and message automatically adapt to the current archive direction.
- `onSettled` runs on both success and error, making it ideal for closing modals regardless of outcome.
