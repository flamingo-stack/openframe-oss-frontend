# use-edit-schedule-form.ts

React hook that manages form state, validation, and the GraphQL create/update mutation for script schedules, used by both the schedule creation and edit pages.

## Key Components

- **`useEditScheduleForm(options)`** — Main hook accepting `{ scheduleId: string | null }`. A `null` scheduleId selects create mode; a non-null value selects update mode.
- **Returned API:**
  - `methods` — `react-hook-form` instance (typed with `EditScheduleFormData`, validated via `editScheduleFormSchema` through `zodResolver`).
  - `showErrors` — boolean flag that stays `false` until the first Save attempt, then tracks live validation.
  - `handleSave()` — triggers validation display and submits the form.
  - `isSaving` — `true` while either the create or update mutation is in flight.
  - `isEditMode` — whether the hook is operating in update mode.
  - `backFallback` — route to navigate back to if there's no safe history entry.

## Behavior Notes

- Builds the mutation `input` payload with PUT semantics: fields like `description`, `startAt`, `repeat`, and `scriptCustomParams` are explicitly nulled/cleared when not applicable, rather than omitted.
- Event-driven triggers (`DEVICE_ONLINE`) strip all timing data (`startAt`, `repeat`) and force `offlineBehavior` to `SKIP`.
- `reconnectWindowSeconds` is only populated when `offlineBehavior` is `RETRY_ON_RECONNECT`.
- On success: update mode shows a toast and navigates back to schedule details; create mode shows a toast and redirects to the device-assignment step via `router.replace`.
- On failure: shows a destructive toast with a Relay-derived error message.
- Validation failures trigger a toast and scroll the viewport to the first invalid field via `scrollToFirstInvalidField`.

## Usage Example

```typescript
import { useEditScheduleForm } from './use-edit-schedule-form';

function EditScheduleForm({ scheduleId }: { scheduleId: string | null }) {
  const { methods, showErrors, handleSave, isSaving, isEditMode, backFallback } =
    useEditScheduleForm({ scheduleId });

  return (
    <form onSubmit={e => { e.preventDefault(); handleSave(); }}>
      {/* form fields bound via methods.register / Controller */}
      <button type="submit" disabled={isSaving}>
        {isEditMode ? 'Update Schedule' : 'Create Schedule'}
      </button>
    </form>
  );
}
```
