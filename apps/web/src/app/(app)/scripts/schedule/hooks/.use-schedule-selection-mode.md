# use-schedule-selection-mode.ts

React hook that handles switching a script schedule's device-targeting mode from CRITERIA (rule-based) back to SPECIFIC (explicit device list), committing the change immediately via a full schedule update mutation.

## Key Components

- **`useScheduleSelectionMode(schedule)`** — Hook accepting a `ScheduleDevicesSettingsData | null | undefined` and returning `{ saveSpecificMode, isSavingMode }`.
- **`saveSpecificMode(callbacks)`** — Callback that commits the schedule update with `selectionMode: ScheduleDeviceSelectionMode.SPECIFIC`, preserving all other schedule fields (name, description, platforms, scripts, trigger, timing, offline behavior). Accepts optional `onSaved` and `onFailed` callbacks.
- **`isSavingMode`** — Boolean mutation-in-flight flag from `useMutation`.
- **`SaveSpecificModeCallbacks`** — Interface for the optional success/failure handlers passed to `saveSpecificMode`.

The hook is deliberately "commit-on-click" rather than behind a Save button, because the server interprets each row's `assigned` flag differently depending on the active mode — switching modes first avoids misreading add/remove actions in the device picker. Since the update mutation is a full PUT on `UpdateScriptScheduleInput`, every writable field must be re-sent (via the current `schedule` snapshot) to avoid clearing it; notably `offlineBehavior` and `timeReference` are resolved through helper functions since `null` has special server-side meaning (SKIP / SERVER respectively) rather than "unset."

On success, it invalidates the schedule's Relay record (device connections are stale once targeting flips) and shows a success toast; on failure, it shows an error toast and lets the caller revert any optimistic UI state via `onFailed`.

## Usage Example

```typescript
import { useScheduleSelectionMode } from './use-schedule-selection-mode';

function DeviceTargetingToggle({ schedule }: { schedule: ScheduleDevicesSettingsData }) {
  const { saveSpecificMode, isSavingMode } = useScheduleSelectionMode(schedule);

  const handleSwitchToSpecific = () => {
    // Optimistically select the radio, then commit the switch
    saveSpecificMode({
      onSaved: () => console.log('Switched to specific device targeting'),
      onFailed: () => {
        // Revert the optimistic radio selection back to CRITERIA
      },
    });
  };

  return (
    <button disabled={isSavingMode} onClick={handleSwitchToSpecific}>
      Use Specific Devices
    </button>
  );
}
```
