# edit-schedule-page.tsx

Page component implementing the combined create/edit view for script schedules using Relay for data fetching. It separates concerns into a non-rendering data loader, a suspense-bounded field reader, and a static page shell so the page title, back button, and action bar paint immediately while only the schedule-dependent fields suspend.

## Key Components

- **`EditSchedulePage`** — Public entry point. Accepts `scheduleId` (`null` for create mode) and remounts the inner page via `key` whenever the id changes, preventing stale form state when navigating between schedules.
- **`ScheduleFormPage`** — Owns the form instance (`useEditScheduleForm`), the `ScheduleRecordState`, and the `PageLayout` chrome (title, Back, Save/Update/Cancel actions). Seeds the form once the record resolves via `useSeedForm`.
- **`ScheduleRecordFields`** — Wraps the reader in a `LoadingSuspense` boundary labeled "Loading schedule".
- **`ScheduleRecordFieldsReader`** — Renders disabled skeleton fields while in a loading scope; otherwise renders either a `NotFoundError` or the live `ScheduleFormFields`.
- **`ScheduleRecordLoader`** — Pure data-fetching island (returns `null`). Runs the `scriptScheduleDetailRelayQuery`, converts the schedule via `scheduleToFormValues`, and reports the result upward via `onResolved` in a `useLayoutEffect` (pre-paint).
- **`ScheduleRecordState`** — Union type (`loading` | `missing` | `ready`) tracking the lifecycle of the edited record.

## Usage Example

```typescript
import { EditSchedulePage } from './edit-schedule-page';

// Create mode (no existing schedule)
<EditSchedulePage scheduleId={null} />

// Edit mode (loads and seeds the existing schedule)
<EditSchedulePage scheduleId="schedule-123" />
```

The component is designed to be rendered directly by a route/page file, with `scheduleId` typically derived from a search param (e.g., `?id=schedule-123`). It requires feature-flag gating context (`useFeatureFlagGate`) and Relay environment setup to resolve `scriptScheduleDetailRelayQuery`.
