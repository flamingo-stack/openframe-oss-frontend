## schedule-info-bar.tsx

Renders the card-style info bar summarizing a schedule's key details (name, timing, platforms, offline behavior, and author), supporting both loaded and skeleton-loading states via `useLoadingScope`.

## Key Components

- **`ScheduleInfoBarFromData`** — Main component that renders the schedule info bar. Conditionally shows a name/note row, a timing row (Date/Time/Repeat/Platform, or a collapsed "Trigger/Platform" row for event-driven triggers like `DEVICE_ONLINE`), and a trailing row for offline behavior and/or "Added by".
- **`ScheduleInfoBarFromDataProps`** — Props interface controlling which rows render and what values they display, including `trigger` (schedule trigger type) and `timeReference` (clock reference, e.g. device-local time).
- **`infoBarCell(className?)`** — Helper returning the shared cell class string (fixed height, padding) used by both the schedule bar and matching run bar.
- **`INFO_BAR_FRAME_CLASS`** — Exported card frame class for the bar's outer container.
- **`DIVIDED_CELL_CLASS`** — Exported class adding a bottom border between stacked cells on mobile layouts.

## Usage Example

```typescript
import { ScheduleInfoBarFromData } from './schedule-info-bar';
import { ScriptScheduleTrigger } from '@/generated/schema-enums';

function ScheduleDetailsHeader() {
  return (
    <ScheduleInfoBarFromData
      name="Weekly Disk Cleanup"
      note="Runs after business hours"
      addedBy="Jane Doe"
      date="Mar 12, 2025"
      time="6:00 PM"
      repeat="Weekly"
      platforms={['windows', 'macos']}
      trigger={ScriptScheduleTrigger.DATE_TIME}
      timeReference="DEVICE_LOCAL"
    />
  );
}

// Event-driven trigger collapses the timing row:
<ScheduleInfoBarFromData
  date=""
  time=""
  repeat=""
  platforms={['linux']}
  trigger={ScriptScheduleTrigger.DEVICE_ONLINE}
/>
```

Rows are included only when their corresponding props are provided (or, while loading, when passed as empty strings `''` to reserve skeleton space).
