# schedule-criteria-picker.tsx

Renders the "Select Devices by Criteria" editor for a script schedule — a rule-based device picker that pairs a criteria editor with a live preview of the devices that rule currently matches.

## Key Components

- **`ScheduleCriteriaPicker`** — Main component that combines `ScheduleCriteriaFields` (the rule editor) with `DeviceSelector` (the preview list), driven by a GraphQL/Relay pagination query against the schedule's `availableDevices` connection.
- **`ScheduleCriteriaPickerProps`** — Props interface: `scheduleId`, `criteria` (current `ScheduleCriteria`), `onCriteriaChange` callback, and `busy` flag to disable interaction during saves.

## Behavior Notes

- The preview is powered by the **same server-side matching** the Available list uses: the criteria are converted via `criteriaToFilter` into a `ScheduleDeviceCriteriaInput`/`DeviceFilterInput`, so matched devices are already scoped to the schedule's supported platforms — no client-side re-implementation of matching logic.
- Query variables are passed through `useDeferredQuery` so edits to the criteria update the preview inside a React transition, keeping the previous results visible instead of falling back to a Suspense skeleton on every keystroke.
- Nothing commits as the user edits — the rule is held in local state (`criteria`) and only persisted when the parent page's Save action is triggered.
- OS/platform facet options come from `DeviceFacets`, wrapped in a `ContentErrorBoundary` so a facet-fetch failure only degrades the OS filter options, not the whole picker.

## Usage Example

```typescript
import { ScheduleCriteriaPicker } from './schedule-criteria-picker';
import { useState } from 'react';
import type { ScheduleCriteria } from '../utils/schedule-criteria';

function ScheduleEditor({ scheduleId }: { scheduleId: string }) {
  const [criteria, setCriteria] = useState<ScheduleCriteria>(/* initial */);
  const [busy, setBusy] = useState(false);

  return (
    <ScheduleCriteriaPicker
      scheduleId={scheduleId}
      criteria={criteria}
      onCriteriaChange={setCriteria}
      busy={busy}
    />
  );
}
```
