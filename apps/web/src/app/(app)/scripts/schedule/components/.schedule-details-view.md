Renders the full schedule details page view for a script schedule, composing a tabbed layout with Relay-powered data islands for schedule metadata, assigned scripts, and assigned devices.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ScheduleDetailsView` | Page View | Root component (memoized): the header island, the info bar island, then the tab strip island |

**Internal:** `ScheduleHeader` over `ScheduleHeaderView` (the props-only header; without a schedule it draws itself with `LOADING_ACTIONS` placeholders), `ScheduleInfoBar` (reads the schedule and renders `ScheduleInfoBarFromData`), `ScheduleTabsIsland` (reads the trigger, which decides whether Schedule Runs exists) over `ScheduleTabs`. The header and info bar are `LoadingSuspense` boundaries whose fallback is the same view with no data, drawn in a loading scope; the tab island's fallback is the working strip on the certain tabs.

## Usage Example

```typescript
// Rendered via the schedule detail gate/route:
import { ScheduleDetailsView } from './schedule-details-view';

// Each data island is a LoadingSuspense whose fallback is the same view, drawn in a loading scope,
// so the header and tabs load independently.
<LoadingSuspense
  label="Loading schedule details"
  fallback={<ScheduleInfoBarFromData date="" time="" repeat="" platforms={[]} addedBy="" ifDeviceOffline="" />}
>
  <ScheduleInfoBar scheduleId="sch_abc123" />
</LoadingSuspense>

```

> **Note:** An event-driven (Device Online) schedule has no Schedule Runs tab and its info bar shows a Trigger cell in place of Date/Time/Repeat.
