# schedule-devices-tab.tsx

Implements the "Assigned Devices" tab for a script schedule's detail page, displaying the paginated list of devices a schedule runs on, with search, facet filtering, and infinite scroll — reusing the shared fleet-page `DevicesList` component.

## Key Components

- **`ScheduleDevicesTab`** — Public, memoized entry point. Wraps its content in `LoadingSuspense` so the tab suspends independently of the page header/tab strip.
- **`ScheduleDevicesTabReader`** — Detects whether it's rendering inside a loading scope (e.g. a fallback) and short-circuits to the loading placeholder without issuing data reads.
- **`ScheduleDevicesTabContent`** — The data-fetching core. Loads schedule detail (`scriptScheduleDetailRelayQuery`), paginates assigned devices (`scriptScheduleDevicesRelayQuery` + `usePaginationFragment`), and renders `DevicesList` with server-side search/filter narrowing.
- **`ScheduleDevicesTabLoading`** — Skeleton state matching the final list's shape.
- **`toDeviceFilter`** — Converts the UI's `DevicesListNarrowing` shape into the `AssignedDevicesFilter` GraphQL input (`statuses`, `osTypes`, `organizationIds`, `tagValues`).
- **`AssignedDevicesFilter`** — Local type mirroring the subset of `DeviceFilterInput` fields relevant to assigned devices.
- **`EMPTY_STATE`** / **`PAGE_SIZE`** — Shared empty-state content and pagination page size (20).

## Usage Example

```typescript
import { ScheduleDevicesTab } from './schedule-devices-tab';

function ScheduleDetailPage({ scheduleId }: { scheduleId: string }) {
  return (
    <div>
      {/* ...header, timing bar, tab strip... */}
      <ScheduleDevicesTab scheduleId={scheduleId} />
    </div>
  );
}
```

Key behaviors:
- Search input is debounced 500ms; filter/search changes use `useDeferredQuery` to keep the current list visible (dimmed, not replaced) while refetching.
- Facets (status, OS, org, tag filters) are scoped to the schedule's own assigned devices via `ScheduleDeviceFacets`, wrapped in `ContentErrorBoundary` so a facet-loading failure still renders the list without funnels.
- When `schedule.selectionMode` is `CRITERIA`, a `ScheduleCriteriaSummary` is shown above the list describing the assignment rule.
