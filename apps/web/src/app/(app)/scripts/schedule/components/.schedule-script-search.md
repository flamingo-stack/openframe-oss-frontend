## schedule-script-search.tsx

This client component implements the "Select Script" slot of a schedule form, wiring the core library's search field UI to a Relay-backed autocomplete hook that filters scripts by the schedule's target platforms.

## Key Components

- **`DEFAULT_TIMEOUT_SECONDS`** — Fallback timeout (90s) used when a picked script has no timeout defined.
- **`scriptToFormRow(script)`** — Converts a `PickerScript` into a `ScheduleFormScriptRow`, seeding form fields (args, env vars, timeout, platforms) from the script's own defaults so the form starts "uncustomised" but never blank.
- **`ScheduleScriptSearch`** — The exported component. Wraps `ScheduleScriptSearchField` (from `@flamingo-stack/openframe-frontend-core`) with:
  - `useScheduleScriptsAutocomplete` for search state (scripts, loading, input value, open/close handlers), scoped by `supportedPlatforms`.
  - A memoized `results` list mapping raw scripts into `{ id, name, supportedPlatforms }` for the picker.
  - `handleChange` to resolve a picked script ID back to a full script object and emit a `ScheduleFormScriptRow` via `onPick`.

## Usage Example

```typescript
import { ScheduleScriptSearch } from './schedule-script-search';

function ScheduleFormScriptSlot(props: ScheduleScriptSearchSlotProps) {
  return (
    <ScheduleScriptSearch
      scriptId={props.scriptId}
      name={props.name}
      supportedPlatforms={props.supportedPlatforms}
      onPick={props.onPick}
      disabled={props.disabled}
      error={props.error}
      invalid={props.invalid}
    />
  );
}
```

When a user selects a script, `onPick` receives a fully populated `ScheduleFormScriptRow` — including default args, env vars, and timeout — ready to be merged into the schedule form state without additional lookups.
