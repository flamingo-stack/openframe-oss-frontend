Renders a paginated, filterable data table for script schedules, supporting archive/unarchive actions, search, OS platform filtering, and mobile-responsive filter modals via Relay-backed GraphQL queries.

## Key Components

- **`ScriptSchedulesTable`** — The exported page: toolbar, filters, and the `LoadingSuspense` around the rows, whose fallback is the shared `LiveTable` over the same columns (`LOADING_COLUMNS`): it holds one page of placeholder rows and draws them with their real cells in the boundary's loading scope, every cell in its own loading form (the Date & Time, Repeat and Devices cells switch themselves).
- **`SchedulesTableContent`** — Inner Relay-dependent component (lives inside that boundary) that fetches schedule data via `useLazyLoadQuery` and `usePaginationFragment`, renders the shared `LiveTable` (sticky header, body, infinite footer, the pending dim while a deferred refetch runs), and handles archive/unarchive mutations with confirmation modals.
- **`UiScheduleEntry`** — Local interface representing a flattened schedule row (`id`, `name`, `description`, `supportedPlatforms`, `deviceCount`).
- **`renderRowActions`** — Per-row actions menu with Edit Schedule, Edit Devices, and Archive/Unarchive options.
- **`handleConfirmArchive`** — Commits the archive or unarchive mutation, invalidates the Relay record, shows a toast, and refreshes filter facets.
- **`refreshFilterMeta`** — Imperatively re-fetches platform filter facets after membership changes without re-fetching the full list.
- **`ArchiveScheduleModal` / `RestoreScheduleModal`** — Confirmation dialogs triggered before committing mutations.
- **`PAGE_SIZE`** — The list's page size: one Relay page, and the full page of rows its loading table draws.

## Usage Example

```typescript
// Rendered inside the page's boundary with deferred query state wired from the parent; the fallback is the same table
// with no rows:
<LoadingSuspense
  label="Loading schedules"
  fallback={<LiveTable columns={LOADING_COLUMNS} pageSize={PAGE_SIZE} stickyHeaderOffset="64px" />}
>
  <SchedulesTableContent
    backendFilters={{ archived: false }}
    debouncedSearch="backup"
    tableFilters={{ supportedPlatforms: ['windows'] }}
    isPending={false}
    onFilterChange={(filters) => setTableFilters(filters)}
    onEmptyChange={(isEmpty) => setIsEmpty(isEmpty)}
    mobileFilterOpen={false}
    onMobileFilterClose={() => setMobileFilterOpen(false)}
    stickyHeaderOffset="64px"
    archived={false}
  />
</LoadingSuspense>
```
