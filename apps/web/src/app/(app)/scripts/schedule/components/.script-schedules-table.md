Renders a paginated, filterable data table for script schedules, supporting archive/unarchive actions, search, OS platform filtering, and mobile-responsive filter modals via Relay-backed GraphQL queries.

## Key Components

- **`SchedulesTableContent`** — Inner Relay-dependent component (must live inside `<Suspense>`) that fetches schedule data via `useLazyLoadQuery` and `usePaginationFragment`, renders the `DataTable`, and handles archive/unarchive mutations with confirmation modals.
- **`UiScheduleEntry`** — Local interface representing a flattened schedule row (`id`, `name`, `description`, `supportedPlatforms`, `deviceCount`).
- **`renderRowActions`** — Per-row actions menu with Edit Schedule, Edit Devices, and Archive/Unarchive options.
- **`handleConfirmArchive`** — Commits the archive or unarchive mutation, invalidates the Relay record, shows a toast, and refreshes filter facets.
- **`refreshFilterMeta`** — Imperatively re-fetches platform filter facets after membership changes without re-fetching the full list.
- **`ArchiveScheduleModal` / `RestoreScheduleModal`** — Confirmation dialogs triggered before committing mutations.
- **`PAGE_SIZE`** — Constant (`20`) controlling pagination chunk size.

## Usage Example

```typescript
// Rendered inside a Suspense boundary with deferred query state wired from the parent:
<Suspense fallback={<Spinner />}>
  <SchedulesTableContent
    backendFilters={{ archived: false }}
    debouncedSearch="backup"
    tableFilters={{ supportedPlatforms: ['windows'] }}
    isPending={false}
    onFilterChange={(filters) => setTableFilters(filters)}
    onEmptyChange={(isEmpty) => setIsEmpty(isEmpty)}
    mobileFilterOpen={false}
    onMobileFilterClose={() => setMobileFilterOpen(false)}
    stickyHeaderOffset="64px"
    archived={false}
  />
</Suspense>
```
