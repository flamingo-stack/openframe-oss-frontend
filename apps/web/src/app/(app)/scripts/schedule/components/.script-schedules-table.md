## script-schedules-table.tsx

Renders the Script Schedules data table — a paginated, filterable, sortable Relay-backed list of scheduled script runs, supporting search, OS platform filtering, date/time filtering, archive/unarchive actions, and row-level navigation to schedule details.

## Key Components

- **`scheduleColumns()`** — Builds the `ColumnDef<UiScheduleEntry>[]` for the table: name/description, supported platforms (OS badges), date/time (with calendar filter popover), repeat cadence, device count, row actions, and an "open in new tab" link.
- **`ScheduleStartCell`** — Renders a schedule's start date/time, handling event-triggered schedules (no date), device-local time annotation, and loading skeleton via `useLoadingScope`.
- **`ScheduleRepeatCell`** — Displays the repeat cadence label, skeleton-aware.
- **`ScheduleDeviceCountCell`** — Displays targeted device count, skeleton-aware.
- **`SchedulesTableContent`** — Inner component consuming Relay pagination fragment data; must render inside Suspense. Accepts live vs. deferred sort/filter state to avoid UI flicker during refetches.
- **`UiScheduleEntry`** — Shape of a normalized schedule row used by cells and columns.
- **`SORTABLE_COLUMN_IDS`**, **`START_AT_SORT_FIELD`** — Constrain which URL-driven sort fields are honored by the backend query.
- Uses `archiveScriptScheduleMutation` / `unarchiveScriptScheduleMutation` for row actions, and `ArchiveScheduleModal` / `RestoreScheduleModal` for confirmation dialogs.

## Usage Example

```typescript
import { SchedulesTableContent } from './script-schedules-table';

// Typically rendered by a parent page component that owns filter/sort state
// and wraps this content in a Suspense boundary (per Relay requirements):
<Suspense fallback={<LoadingSuspense />}>
  <SchedulesTableContent
    backendFilters={{ status: [ScriptStatus.Active] }}
    debouncedSearch={search}
    sort={sort}
    tableFilters={tableFilters}
    sortState={sortState}
    onSortChange={handleSortChange}
    isPending={isPending}
    onFilterChange={setTableFilters}
    dateFilter={dateFilter}
    onEmptyChange={setIsEmpty}
    mobileFilterOpen={mobileFilterOpen}
    onMobileFilterClose={() => setMobileFilterOpen(false)}
    stickyHeaderOffset="64px"
    archived={false}
  />
</Suspense>
```

Row actions dispatch Relay mutations (archive/unarchive) and update the Relay store via `RecordSourceSelectorProxy`, keeping the table in sync without a full refetch.
