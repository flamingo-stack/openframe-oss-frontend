Defines the tab configuration for the Schedule Details page, mapping each tab's id, label, and icon to its corresponding lazy-loaded body component, and provides helpers to resolve the active tab set and body component based on a schedule's trigger type.

## Key Components

- **`ScheduleTabProps`** — Shared prop shape (`scheduleId`) passed to every tab body component.
- **`SCHEDULE_DETAIL_TABS`** — Full `TabItem[]` array: `scripts`, `devices`, `runs`, `executions`, each paired with an icon and its tab body component.
- **`SCHEDULE_TABS_WITHOUT_RUNS`** — `SCHEDULE_DETAIL_TABS` filtered to exclude `runs`, used for event-triggered schedules (e.g., `DEVICE_ONLINE`) where there's no meaningful "fire" aggregate.
- **`scheduleDetailTabs(trigger)`** — Returns the correct tab set depending on whether the trigger is an event trigger (via `isEventTrigger`) or a time-based one.
- **`SCHEDULE_DEFAULT_TAB`** — The id of the first tab (`'scripts'`), used as the fallback when `?tab=` is absent or invalid.
- **`scheduleTabBody(tabId)`** — Resolves a tab id to its registered body component, falling back to the default tab if not found.

## Usage Example

```typescript
import { scheduleDetailTabs, scheduleTabBody, SCHEDULE_DEFAULT_TAB } from './schedule-detail-tabs';

// Determine visible tabs based on schedule trigger
const tabs = scheduleDetailTabs(schedule.trigger);

// Resolve active tab from query param, falling back to default
const activeTabId = searchParams.get('tab') ?? SCHEDULE_DEFAULT_TAB;
const TabBody = scheduleTabBody(activeTabId);

// Render
<TabNavigation tabs={tabs} activeId={activeTabId} />
<TabBody scheduleId={schedule.id} />
```

Each tab body is individually `memo`'d and owns its own `Suspense` boundary, preventing unrelated re-renders and ensuring only the active tab's content loads during navigation.
