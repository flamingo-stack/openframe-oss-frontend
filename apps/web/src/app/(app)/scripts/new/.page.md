This file defines the Next.js page component for creating a new script, rendering the shared `EditScriptPage` component in "create" mode.

## Key Components

- **`NewScriptPageWrapper`** (default export): A client-side page component that wraps `EditScriptPage`, passing `scriptId={null}` to signal that a new script is being created rather than an existing one being edited.

## Usage Example

This file is a Next.js route entry point and is rendered automatically by the framework when navigating to the corresponding route (e.g., `/scripts/new`). It is not typically imported manually elsewhere in the codebase.

```typescript
// Next.js automatically routes to this page based on file location,
// e.g., app/scripts/new/page.tsx

// Internally, it reuses the shared edit/create UI:
import { EditScriptPage } from '../script/components/edit-script-page';

export default function NewScriptPageWrapper() {
  return <EditScriptPage scriptId={null} />;
}
```

By passing `null` as the `scriptId`, the `EditScriptPage` component knows to initialize an empty form state for creating a new script, as opposed to fetching and populating data for an existing script when a valid `scriptId` is provided.
