Next.js client page component that renders the Script Schedules tab, displaying scheduled script executions within a tabbed scripts interface with error boundary protection.

## Key Components

- **`ScriptSchedulesPage`** (default export) — Page-level component rendering the schedules view
- **`ScriptsTabNavigation`** — Shared tab navigation bar for the Scripts section, with `activeTab="schedules"` highlighting the current tab
- **`ContentErrorBoundary`** — Wraps the table content to gracefully handle rendering/data errors, showing a fallback title and message
- **`ScriptSchedulesTable`** — Renders the actual list/table of script schedules

## Usage Example

This file is a route-level page (e.g., under `app/.../schedule/page.tsx` in the Next.js App Router) and is rendered automatically by the framework when the corresponding route is visited:

```typescript
// Navigating to the schedules route renders this page automatically
// e.g., /scripts/schedule

// Structure consumed by the router:
export default function ScriptSchedulesPage() {
  return (
    <div className="flex w-full flex-col">
      <ScriptsTabNavigation activeTab="schedules" />
      <ContentErrorBoundary title="Schedules" message="Couldn't load schedules.">
        <ScriptSchedulesTable />
      </ContentErrorBoundary>
    </div>
  );
}
```
