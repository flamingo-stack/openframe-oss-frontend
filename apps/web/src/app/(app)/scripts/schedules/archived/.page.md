This client-side Next.js page component renders a read-only view of archived script schedules, wrapped in an error boundary for resilient failure handling.

## Key Components

- **`ArchivedScriptSchedulesPage`** - Default-exported page component that renders the archived schedules view
- **`ContentErrorBoundary`** - Wraps the content to catch and gracefully display errors with a custom title and message
- **`ScriptSchedulesTable`** - Shared table component (reused from the active schedules feature) rendered with the `archived` prop set to `true` to filter for archived entries

## Usage Example

This file is a Next.js route page and is rendered automatically by the framework based on its file path (e.g., `app/.../archived/page.tsx`). It requires no manual invocation:

```typescript
// Automatically rendered by Next.js routing when navigating to
// the corresponding archived schedules route.

export default function ArchivedScriptSchedulesPage() {
  return (
    <ContentErrorBoundary title="Archived Schedules" message="Couldn't load archived schedules.">
      <ScriptSchedulesTable archived />
    </ContentErrorBoundary>
  );
}
```

The `archived` prop passed to `ScriptSchedulesTable` differentiates this page from the active schedules listing, allowing the same table component to be reused across both views with different data filtering logic.
