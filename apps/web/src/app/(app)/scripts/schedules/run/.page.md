Renders the Schedule Run Details page, extracting the run ID from the URL query parameters and passing it to the view component responsible for displaying schedule run details.

## Key Components

- **`ScheduleRunDetailsPage`** (default export): A Next.js client page component that reads the `id` query parameter from the current URL and renders the `ScheduleRunDetailsView` component with that ID.
- Uses the `useSearchParams` hook from `next/navigation` to access URL query parameters on the client side.
- Delegates rendering logic to `ScheduleRunDetailsView` from `../../schedule/components/schedule-run-details-view`.

## Usage Example

This page is automatically rendered by Next.js routing when navigating to its corresponding route with an `id` query parameter, e.g.:

```text
/schedule/run-details?id=12345
```

```typescript
// Example: Linking to this page elsewhere in the app
import Link from 'next/link';

export function ScheduleRunLink({ runId }: { runId: string }) {
  return (
    <Link href={`/schedule/run-details?id=${runId}`}>
      View Run Details
    </Link>
  );
}
```

The page itself requires no props since it derives its state entirely from the URL search parameters, making it suitable as a standalone route entry point within the Next.js app router structure.
