Provides deployment environment detection for React components, combining a Zustand global store with a React hook to detect and cache whether the app is running in cloud, self-hosted, or development mode.

## Key Components

### `useDeployment()` *(hook)*
Primary React hook that initializes deployment detection on first use and returns cached results thereafter. Handles browser environment safety with a deferred `setTimeout`.

**Returns:**

| Property | Type | Description |
|---|---|---|
| `deployment` | `DeploymentInfo \| null` | Full deployment info object |
| `isLoading` | `boolean` | True while detection is pending |
| `isInitialized` | `boolean` | True once detection has run |
| `isCloud` | `boolean` | Cloud deployment flag |
| `isSelfHosted` | `boolean` | Self-hosted deployment flag |
| `isDevelopment` | `boolean` | Development environment flag |
| `deploymentType` | `DeploymentType` | Enumerated type string |
| `hostname` | `string` | Current hostname |
| `reset` | `() => void` | Clears and re-arms detection |

### Static Helpers *(non-component contexts)*

| Function | Returns | Description |
|---|---|---|
| `getDeployment()` | `DeploymentInfo \| null` | Full deployment object |
| `isCloudDeployment()` | `boolean` | Cloud check |
| `isSelfHostedDeployment()` | `boolean` | Self-hosted check |
| `isDevelopmentDeployment()` | `boolean` | Dev environment check |
| `getDeploymentType()` | `DeploymentType` | Deployment type string |

### `useDeploymentStore` *(internal)*
Private Zustand store with Redux DevTools integration (`"deployment-store"`). Detection runs at most once — guarded by `isInitialized`.

## Usage Example

```typescript
// In a React component
import { useDeployment } from '@/hooks/use-deployment';

function FeatureFlag() {
  const { isCloud, isSelfHosted, isLoading, deploymentType } = useDeployment();

  if (isLoading) return <Spinner />;

  return isCloud
    ? <CloudOnlyFeature />
    : <SelfHostedFeature />;
}

// Outside React (e.g., API utility, middleware)
import { isCloudDeployment, getDeploymentType } from '@/hooks/use-deployment';

function buildApiUrl(path: string) {
  return isCloudDeployment()
    ? `https://api.flamingo.run${path}`
    : `/api${path}`;
}
```

> **Note:** Static helpers may return `null` / fallback defaults if called before the hook has initialized. Prefer `useDeployment()` inside components and reserve static helpers for server utilities or non-React code paths where hook initialization is guaranteed to have already occurred.
