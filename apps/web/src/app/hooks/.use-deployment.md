A React hook and Zustand store for detecting and caching the application's deployment context (cloud, self-hosted, or development) across the client-side app.

## Key Components

- **`useDeploymentStore`** — Internal Zustand store (with devtools middleware) holding the `DeploymentInfo`, an `isInitialized` flag, and `initialize`/`reset` actions. Detection runs only once per session via `detectDeployment()` from `@/lib/deployment-detector`.
- **`useDeployment()`** — Primary hook for components. Lazily initializes detection on first mount, tracks a local `isLoading` state, and returns convenience flags (`isCloud`, `isSelfHosted`, `isDevelopment`), deployment details (`deploymentType`, `hostname`), the full `deployment` object, and a `reset` action.
- **`getDeployment()`** — Static getter for `DeploymentInfo` outside of React components (e.g., utility functions, API clients).
- **`isCloudDeployment()` / `isSelfHostedDeployment()` / `isDevelopmentDeployment()`** — Static boolean helpers for non-component contexts.
- **`getDeploymentType()`** — Static getter returning the raw `DeploymentType`.
- **Re-exported types** — `DeploymentInfo`, `DeploymentType` from `@/lib/deployment-detector`.

## Usage Example

```typescript
'use client';

import { useDeployment } from '@/hooks/use-deployment';

function DeploymentBadge() {
  const { isLoading, isCloud, isSelfHosted, deploymentType, hostname } = useDeployment();

  if (isLoading) return <span>Detecting deployment…</span>;

  return (
    <span>
      Running as {deploymentType} ({hostname})
      {isCloud && ' — Cloud'}
      {isSelfHosted && ' — Self-hosted'}
    </span>
  );
}
```

Outside components:

```typescript
import { isCloudDeployment, getDeploymentType } from '@/hooks/use-deployment';

if (isCloudDeployment()) {
  console.log('Running in cloud mode:', getDeploymentType());
}
```

**Note:** Static helpers return default/fallback values (`false`/`'development'`) until `useDeployment()` has initialized detection at least once in the component tree.
