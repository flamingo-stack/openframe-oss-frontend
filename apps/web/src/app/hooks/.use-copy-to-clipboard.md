A React hook that copies text to the clipboard using the Clipboard API, displays success/error toast notifications, and tracks a transient "copied" state that auto-resets after a configurable delay. It guards against state updates after the component unmounts.

## Key Components

- **`useCopyToClipboard(options?)`** — Main hook accepting optional configuration:
  - `successTitle` / `successDescription` — toast text shown on successful copy (defaults: "Copied" / "Copied to clipboard")
  - `errorTitle` / `errorDescription` — toast text shown on failed copy (defaults: "Copy failed" / "Could not copy to clipboard")
  - `resetDelay` — milliseconds before `copied` resets to `false` (default: `2000`)
- **Returns** `{ copy, copied }`:
  - `copy(text: string)` — async function that writes `text` to the clipboard, triggers a toast, and sets `copied` to `true` temporarily
  - `copied` — boolean state indicating a recent successful copy, useful for showing a "Copied!" icon/label

Internally it uses `useToast` from `@flamingo-stack/openframe-frontend-core/hooks` for notifications, and refs to track unmount status and the pending reset timer, preventing memory leaks or state updates on unmounted components.

## Usage Example

```typescript
import { useCopyToClipboard } from './use-copy-to-clipboard';

function ApiKeyField({ apiKey }: { apiKey: string }) {
  const { copy, copied } = useCopyToClipboard({
    successDescription: 'API key copied to clipboard',
  });

  return (
    <button onClick={() => copy(apiKey)}>
      {copied ? 'Copied!' : 'Copy API Key'}
    </button>
  );
}
```

Custom options example:

```typescript
const { copy, copied } = useCopyToClipboard({
  successTitle: 'Link copied',
  resetDelay: 3000,
});

await copy(window.location.href);
```
