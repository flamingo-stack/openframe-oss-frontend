A React hook that wraps the browser Clipboard API with toast notifications and a temporary `copied` state indicator.

## Key Components

- **`useCopyToClipboard(options?)`** — Main hook export. Accepts optional configuration and returns `{ copy, copied }`.
- **`UseCopyToClipboardOptions`** — Interface for customizing toast messages and reset timing.
- **`copy(text: string)`** — Async callback that writes to the clipboard, shows a success/error toast, and resets `copied` after `resetDelay` ms.
- **`copied`** — Boolean state that is `true` briefly after a successful copy, useful for driving UI feedback (e.g., icon swap).

## Usage Example

```typescript
import { useCopyToClipboard } from './use-copy-to-clipboard';

function CopyButton({ value }: { value: string }) {
  const { copy, copied } = useCopyToClipboard({
    successTitle: 'Done!',
    successDescription: 'Token copied to clipboard',
    resetDelay: 3000,
  });

  return (
    <button onClick={() => copy(value)}>
      {copied ? 'Copied!' : 'Copy'}
    </button>
  );
}
```

### Options Reference

| Option | Type | Default |
|---|---|---|
| `successTitle` | `string` | `'Copied'` |
| `successDescription` | `string` | `'Copied to clipboard'` |
| `errorTitle` | `string` | `'Copy failed'` |
| `errorDescription` | `string` | `'Could not copy to clipboard'` |
| `resetDelay` | `number` | `2000` |

> **Note:** Requires a browser environment (`'use client'`). The hook depends on `useToast` from `@flamingo-stack/openframe-frontend-core/hooks`.
