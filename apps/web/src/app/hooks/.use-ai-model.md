Provides React hooks for accessing the tenant-wide admin AI model configuration, resolving the active LLM provider and model display name from GraphQL-backed settings.

## Key Components

### Interfaces
- **`AiModel`** — Shape describing the active AI model: `provider` (string) and `displayName` (human-readable label).

### Functions
- **`useAiModelStatus()`** — Returns `{ aiModel: AiModel | null, isLoading: boolean }`. Combines loading states from both the admin AI config and the supported models list.
- **`useAiModel()`** — Convenience wrapper returning just the `AiModel | null` value without the loading state.

## Usage Example

```typescript
import { useAiModel, useAiModelStatus } from '@/hooks/use-ai-model';

// With loading state
function ModelBadge() {
  const { aiModel, isLoading } = useAiModelStatus();

  if (isLoading) return <Spinner />;
  if (!aiModel) return <span>No model configured</span>;

  return <span>{aiModel.displayName}</span>;
}

// Without loading state
function ModelLabel() {
  const aiModel = useAiModel();
  return <span>{aiModel?.displayName ?? '—'}</span>;
}
```

## Notes

- This hook targets the **admin (Mingo) assistant** only. It reads from the `adminAiConfig` GraphQL query, which has no per-organization override.
- For **client-facing chats**, use the per-message `AssistantOwner` provenance or `organizationClientAiConfig` — the effective model is resolved per customer.
