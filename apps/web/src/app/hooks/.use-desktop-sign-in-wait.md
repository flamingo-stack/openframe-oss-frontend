# use-desktop-sign-in-wait.ts

A React hook that exposes the current desktop sign-in wait state to client components, enabling the UI to react when a desktop application is waiting for the browser to complete an authentication flow.

## Key Components

- **`useDesktopSignInWait()`** — Hook that subscribes to the external desktop sign-in wait store and returns the current `DesktopSignInWait` state, or `null` if no desktop sign-in is pending.
- **`getServerSnapshot()`** — Internal helper that returns `null` during server-side rendering, since prerendered HTML can never be mid-sign-in.

This hook relies on `useSyncExternalStore` to safely read external, mutable state (managed in `@/lib/desktop-sign-in-wait`) that may change outside of React's render cycle, such as from a browser extension, polling mechanism, or cross-tab communication.

## Usage Example

```typescript
'use client';

import { useDesktopSignInWait } from '@/hooks/use-desktop-sign-in-wait';

export function DesktopSignInBanner() {
  const desktopSignInWait = useDesktopSignInWait();

  if (!desktopSignInWait) {
    return null;
  }

  return (
    <div role="status">
      Waiting to complete sign-in for desktop app: {desktopSignInWait.appName}
    </div>
  );
}
```

The hook returns `null` on the server and during initial hydration until the external store resolves an active desktop sign-in wait, ensuring consistent behavior between server and client renders.
