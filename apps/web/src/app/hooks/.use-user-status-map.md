# use-user-status-map.ts

A React hook that provides a stable lookup function for determining whether users have been deleted, based on their IDs. Designed for UI surfaces (like boards) that need to mark deleted users decoratively without triggering unnecessary re-renders.

## Key Components

- **`useUserStatusMap(userIds)`** — Hook that accepts an array of user IDs (raw or Relay global IDs, nullable) and returns an `isUserDeleted` function.
- **`isUserDeleted(id?)`** — Returned callback that checks whether a given user ID corresponds to a deleted user. Accepts both raw and Relay global IDs via `rawIdOf` normalization.

### Behavior Notes

- **Fail-open semantics**: Until user data resolves, or if the fetch fails, `isUserDeleted` returns `false`. This is intentional since the "deleted" mark is purely decorative.
- **Stable memoization**: The returned `isUserDeleted` function is memoized against a derived, sorted, comma-joined string of deleted user IDs (`deletedKey`) — not against the raw `users` map. This avoids creating a new function identity on every data update, which matters because consumers (e.g., card caches) key off this function's identity.
- Relies on `useUsersById` internally to fetch user records for the given IDs.

## Usage Example

```typescript
import { useUserStatusMap } from '@/hooks/use-user-status-map';

function BoardCard({ cardUserId }: { cardUserId: string }) {
  const { isUserDeleted } = useUserStatusMap([cardUserId]);

  return (
    <div>
      {isUserDeleted(cardUserId) && (
        <span className="badge-deleted">Deleted User</span>
      )}
    </div>
  );
}
```

```typescript
// Checking multiple users on a board
function Board({ assigneeIds }: { assigneeIds: string[] }) {
  const { isUserDeleted } = useUserStatusMap(assigneeIds);

  return assigneeIds.map(id => (
    <Avatar key={id} userId={id} deleted={isUserDeleted(id)} />
  ));
}
```
