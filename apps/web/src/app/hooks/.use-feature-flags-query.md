# use-feature-flags-query.ts

A React Query hook that fetches feature flags from the GraphQL backend on app bootstrap and syncs them into the global feature flags store, with graceful degradation for errors and offline states.

## Key Components

- **`featureFlagsQueryKey`** — Exported query key (`['featureFlags']`) usable for cache invalidation/prefetching elsewhere in the app.
- **`useFeatureFlagsQuery({ enabled })`** — Main hook. Fetches all known feature flags via a GraphQL query, writes results into `useFeatureFlagsStore`, and returns the underlying `useQuery` result.
  - Uses `skipSessionGate: true` since this is a bootstrap call that must run as soon as the session resolves, without waiting on the session latch that blocks other app data requests.
  - Calls `detectTrialExpiredFromGraphqlErrors` to surface subscription-lock signals embedded in GraphQL errors.
  - On success, calls `setFlags(query.data)` to populate the store.
  - On error, logs the failure and calls `setLoaded()` so dependent UI (via `useFeatureFlagGate`) doesn't hang waiting for flags that will never arrive.
  - Subscribes to connectivity changes (`subscribeConnectivity`) and calls `setLoaded()` when offline, since a disabled/session-gated query never reaches `isPaused` state and would otherwise skeleton forever on routes like `/notifications`, `/settings/billing-usage`, and `/mingo`.
  - Configured with `retry: 1`, `staleTime: 30 minutes`, and `refetchOnWindowFocus: false`.

## Usage Example

```typescript
import { useFeatureFlagsQuery } from '@/hooks/use-feature-flags-query';
import { useSession } from '@/hooks/use-session';

function AppBootstrap() {
  const { isResolved } = useSession();

  const { data, isLoading, isError } = useFeatureFlagsQuery({
    enabled: isResolved,
  });

  if (isLoading) {
    return <SkeletonLoader />;
  }

  return <AppShell />;
}
```

Downstream components typically consume flag state via the `useFeatureFlagsStore` (e.g., through a `useFeatureFlagGate` hook) rather than reading `data` directly from this hook, since the store is the source of truth once flags are loaded or defaulted.
