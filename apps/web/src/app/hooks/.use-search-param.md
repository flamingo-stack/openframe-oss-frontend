A React hook that synchronizes a free-typing search input with a URL/query parameter, debouncing writes to avoid excessive updates while preventing race conditions that could erase in-progress typing.

## Key Components

- **`useSearchParam(paramValue, onDebouncedChange, delay?)`** — Main hook function that bridges a controlled search input to an external param source (e.g. URL query string).
- **`UseSearchParamResult`** — Return type containing:
  - `search`: the instant, controlled input value
  - `setSearch`: setter to update `search` immediately
  - `debouncedSearch`: the debounced value, pushed upward via `onDebouncedChange`

## Usage Example

```typescript
import { useSearchParam } from './use-search-param';
import { useApiParams } from './use-api-params';

function SearchBar() {
  const { params, setParam } = useApiParams();

  const { search, setSearch } = useSearchParam(
    params.search ?? '',
    (value) => setParam('search', value),
    300,
  );

  return (
    <input
      value={search}
      onChange={(e) => setSearch(e.target.value)}
      placeholder="Search..."
    />
  );
}
```

### How it works

- **Up sync**: typing updates `search` instantly; after the debounce delay, `debouncedSearch` changes and `onDebouncedChange` is called to persist it (e.g. writing to the URL).
- **Down sync**: when the external param changes independently (like browser back/forward navigation), the input is updated to match — but only if it's a genuine external change, not an echo of the hook's own write. This is tracked via `lastSyncedRef`.
- This design avoids a common bug where an in-flight debounce write gets echoed back and overwrites characters the user is still typing.
