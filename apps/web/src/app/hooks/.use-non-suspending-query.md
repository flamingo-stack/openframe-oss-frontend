# use-non-suspending-query.ts

A custom React hook that fetches Relay GraphQL queries without triggering React Suspense, enabling non-blocking data reads for components that can't be wrapped in a Suspense boundary (e.g., deeply nested props in table cells, board cards, or modals).

## Key Components

- **`useNonSuspendingQuery<TQuery>(query, variables, enabled)`** — Main hook that performs a Suspense-free Relay query read. Returns `{ data, isLoading }`.
  - `query`: A `GraphQLTaggedNode` whose root fields must be guarded with `@include(if: $list)` and accept a `$list: Boolean!` variable.
  - `variables`: Query variables (passed with implicit `list: true`).
  - `enabled`: Optional flag to skip fetching (defaults to `true`).

### How it works
1. Serializes `variables` into a `requestKey` string for comparison across renders.
2. Checks the Relay store synchronously on mount to avoid an unnecessary render flash if data is already cached.
3. Uses `fetchQuery` with `fetchPolicy: 'store-or-network'` inside a `useEffect` to fetch data imperatively, retaining the operation to prevent garbage collection while in flight.
4. Reads the result via `useLazyLoadQuery` with `fetchPolicy: 'store-only'`, so it never suspends — before the first successful fetch, it reads with `list: false`, which resolves to empty data with no network request.
5. On fetch failure, keeps showing the last known good data and simply stops `isLoading`.

## Usage Example

```typescript
import { graphql } from 'react-relay';
import { useNonSuspendingQuery } from './use-non-suspending-query';

const DeviceStatusQuery = graphql`
  query useNonSuspendingQueryExampleQuery($deviceId: ID!, $list: Boolean!) {
    device(id: $deviceId) @include(if: $list) {
      status
      lastSeen
    }
  }
`;

function DeviceStatusCell({ deviceId }: { deviceId: string }) {
  const { data, isLoading } = useNonSuspendingQuery(DeviceStatusQuery, { deviceId }, true);

  return (
    <span>
      {data.device?.status ?? 'Unknown'}
      {isLoading && ' (refreshing...)'}
    </span>
  );
}
```

Pass `enabled={false}` to skip fetching entirely (e.g., while a parent condition isn't met), which clears `requestKey` and keeps the hook idle.
