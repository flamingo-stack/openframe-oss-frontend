Client-side React hook that determines whether the signed-in user may view or manage workspace billing, based on their admin status.

## Key Components

- **`BillingAccessGate`** — Type alias representing the three possible states: `'loading'`, `'allowed'`, or `'denied'`. The three-state model avoids prematurely denying access while the real admin status is still being resolved.
- **`useBillingAccessGate()`** — Hook that wraps `useAdminGate` from `use-admin-gate.ts` and maps its result to a billing-specific access decision. Owners and admins are granted access (`'allowed'`); all other roles (e.g. members) receive `'denied'`.

## Usage Example

```typescript
'use client';

import { useBillingAccessGate } from '@/app/hooks/use-billing-access-gate';

export function BillingPage() {
  const gate = useBillingAccessGate();

  if (gate === 'loading') {
    return <LoadingSpinner />;
  }

  if (gate === 'denied') {
    return <AccessDeniedMessage />;
  }

  return <BillingDashboard />;
}
```

## Notes

- This hook only addresses billing access. For ownership-specific actions (e.g. account/workspace deletion), use `use-owner-gate.ts` instead.
- Because the gate can be `'loading'`, consumers should avoid redirecting or calling `notFound()` until the state resolves to `'allowed'` or `'denied'`, preventing a flash of incorrect access state for legitimate users.
