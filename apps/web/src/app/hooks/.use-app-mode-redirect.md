A client-side React hook that redirects users away from routes that don't exist for the current app mode (SaaS vs. OSS tenants), using Next.js navigation.

## Key Components

- **`useAppModeRedirect(target, options)`** — Hook that conditionally redirects the current route to a `target` path when the route is invalid for the active app mode. Passing `null` as `target` means "stay on this page, no redirect needed."
  - `target: string | null` — The destination path to redirect to, or `null` to skip redirecting.
  - `options.carryLocation?: boolean` — When `true`, appends the current `window.location.search` (query string) and `window.location.hash` (fragment) to the `target` before navigating. Useful for preserving things like `?mingoDialog=` params across the redirect.

## Usage Example

```typescript
'use client';

import { useAppModeRedirect } from '@/hooks/use-app-mode-redirect';
import { useAppMode } from '@/hooks/use-app-mode';

export default function HomePage() {
  const { isSaaS } = useAppMode();

  // SaaS tenants land on Mingo's dashboard; OSS tenants have no such route.
  useAppModeRedirect(isSaaS ? null : '/dashboard');

  return null;
}
```

```typescript
// Preserve query/fragment across the redirect, e.g. ?mingoDialog=open
useAppModeRedirect(shouldRedirect ? '/mingo' : null, { carryLocation: true });
```

## Notes

- Because app mode is resolved before first paint, the hook performs the redirect synchronously via `router.replace`, avoiding a flash of invalid content.
- `target` must be a bare path (no existing query/fragment) when `carryLocation` is `true`, since the current location's search and hash are appended automatically.
- The redirect runs inside a `useEffect`, re-triggering if `target`, `carryLocation`, or `router` change.
