## use-users-by-id.ts

A React hook that resolves a list of user ids (raw or Relay global IDs) into a map of `UserSummary` objects, using a non-suspending GraphQL query so the UI can render progressively while user data loads.

This is intended for domains (like tickets) where only a user id is available and the full user object must be fetched separately. It gracefully handles unknown or purged users by simply omitting them from the result map rather than throwing.

## Key Components

- **`usersByIdQuery`** — GraphQL query fetching `User` nodes by a list of global IDs, spreading the `userSummaryFields_user` fragment.
- **`useUsersById(userIds)`** — Hook that:
  - Deduplicates and normalizes input ids to raw ids (via `rawIdOf`), sorting them for stable query variables.
  - Converts raw ids back to Relay global IDs (via `toGlobalId('User', id)`) for the query.
  - Uses `useNonSuspendingQuery` so the hook never suspends or throws; missing ids simply aren't present in the result yet.
  - Returns `{ users, isLoading }`, where `users` is a `Map<string, UserSummary>` keyed by raw user id.

## Usage Example

```typescript
import { useUsersById } from '@/hooks/use-users-by-id';

function TicketAssignee({ assigneeId }: { assigneeId: string | null }) {
  const { users, isLoading } = useUsersById([assigneeId]);

  if (isLoading) return <Spinner />;

  const user = assigneeId ? users.get(assigneeId) : undefined;

  if (!user) return <span>Unassigned or deleted user</span>;

  return <span>{user.displayName}</span>;
}
```

```typescript
// Resolving multiple assignees at once
function TicketList({ tickets }: { tickets: { assigneeId: string }[] }) {
  const ids = tickets.map(t => t.assigneeId);
  const { users } = useUsersById(ids);

  return (
    <ul>
      {tickets.map(ticket => (
        <li key={ticket.assigneeId}>
          {users.get(ticket.assigneeId)?.displayName ?? 'Unknown user'}
        </li>
      ))}
    </ul>
  );
}
```
