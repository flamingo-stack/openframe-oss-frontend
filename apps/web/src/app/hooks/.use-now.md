A tiny React hook that returns the current timestamp (`Date.now()`), re-sampled on a fixed interval, so relative-time UI keeps ticking between data refetches.

## Key Components

- **`useNow(intervalMs: number): number`** — Sole export. Initializes state to `Date.now()`, then updates it via `setInterval` every `intervalMs`; the interval is cleared on unmount and recreated when `intervalMs` changes.

## Usage Example

```typescript
import { useNow } from '@/app/hooks/use-now';

function StalenessLabel({ lastActivityAt }: { lastActivityAt: number }) {
  const now = useNow(60_000); // tick every minute
  return <span>No activity for {formatDistance(lastActivityAt, now)}</span>;
}
```

## Notes

- Built for the ticket board activity indicators (`lastActivityAt` / `activityState`): staleness labels like "No activity for N hours" must keep advancing even though the board's 15s poll would otherwise freeze them at the last fetch.
- Client-only (`'use client'`); every subscriber re-renders on each tick, so pick the coarsest `intervalMs` the label needs.
