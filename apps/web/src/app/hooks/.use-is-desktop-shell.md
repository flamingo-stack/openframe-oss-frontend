# use-is-desktop-shell.ts

A React hook that safely exposes `isDesktopShell()` for use during render, preventing hydration mismatches between server-rendered HTML and client-side Tauri desktop detection.

## Key Components

- **`useIsDesktopShell()`** — Exported hook that returns `true` when running inside the Tauri desktop shell, `false` when running in a standard web browser. Built on `useSyncExternalStore` to guarantee consistent values across server and client renders.
- **`subscribe()`** — Internal no-op subscription function; the shell type never changes mid-session, so there's nothing to listen for.
- **`getServerSnapshot()`** — Internal function returning `false` (web) as the assumed server-rendered value, corrected automatically during hydration if running in the desktop shell.

## Usage Example

```typescript
import { useIsDesktopShell } from '@/hooks/use-is-desktop-shell';

function ExternalLink({ href, children }: { href: string; children: React.ReactNode }) {
  const isDesktop = useIsDesktopShell();

  return (
    <a href={href} target={isDesktop ? '_blank' : undefined}>
      {children}
    </a>
  );
}
```

**When to use this hook vs. the raw predicate:**

- Use `useIsDesktopShell()` when the result affects rendered output or DOM attributes (e.g., link `target`, conditional UI elements) — this avoids hydration mismatches since React reconciles the value safely.
- Call `isDesktopShell()` directly (without the hook) inside `useEffect` callbacks or for one-off logic like gating a network request, where render-time consistency isn't a concern.

This hook is the desktop-detection counterpart to `useIsMobileShell`, following the same pattern to handle the fact that server builds have no `window` object and always resolve to "web," while the Tauri runtime resolves to "desktop" after hydration.
