Custom React hook that determines whether the current device/browser is an Apple platform, used to conditionally render the "Continue with Apple" sign-in option.

## Key Components

- **`useIsApplePlatform()`** — Returns a `boolean` indicating whether the Apple sign-in button should be displayed.

> ⚠️ **Temporary override (2026-08-11):** The real platform detection logic has been disabled and the hook now unconditionally returns `true`, so the "Continue with Apple" button renders for **every** user and device. The original hydration-safe `isApplePlatform()` detection (using `useState`/`useEffect`) is preserved in git history and should be restored by reverting this commit. Note that only button **visibility** is affected — the native iOS sheet trigger is gated separately in `native-login.ts`, and non-Apple devices still authenticate via the standard web OAuth flow (same as Google/Microsoft).

## Usage Example

```typescript
'use client';

import { useIsApplePlatform } from './use-apple-platform';

function LoginButtons() {
  const isApplePlatform = useIsApplePlatform();

  return (
    <div>
      <button>Continue with Google</button>
      <button>Continue with Microsoft</button>
      {isApplePlatform && <button>Continue with Apple</button>}
    </div>
  );
}
```

## Notes

- This is a client-only hook (`'use client'` directive required).
- To restore real platform detection, check git history for the previous `isApplePlatform()` implementation and revert the change referenced in the inline comment.
