# use-sticky-toolbar.ts

Re-exports the `useStickyToolbar` composable from the shared `openframe-frontend-core` package, preserving a stable import path for this app's list/table views. This is a thin wrapper file so consuming code doesn't need to know the internal location of the shared library implementation.

## Key Components

- **`useStickyToolbar`** — A Vue composable (re-exported, not redefined) that coordinates sticky positioning between a filter toolbar and a table header, ensuring the toolbar remains pinned above the header as the user scrolls through device/data tables.

## Usage Example

```typescript
import { useStickyToolbar } from '@/composables/use-sticky-toolbar';

export default defineComponent({
  setup() {
    const { toolbarRef, headerRef, isSticky } = useStickyToolbar();

    return {
      toolbarRef,
      headerRef,
      isSticky,
    };
  },
});
```

```vue
<template>
  <div>
    <div ref="toolbarRef" :class="{ sticky: isSticky }">
      <!-- Filter controls -->
    </div>
    <table>
      <thead ref="headerRef">
        <!-- Sticky header row -->
      </thead>
      <tbody>
        <!-- Device rows -->
      </tbody>
    </table>
  </div>
</template>
```

## Notes

- This file exists purely for import path stability—actual logic lives in `@flamingo-stack/openframe-frontend-core/components/features`.
- Used by the library's own device tables, so any app-level list/table component expecting sticky toolbar behavior should import from this local path rather than the core package directly.
- No additional logic, state, or transformation is added here; it's a pure re-export.
