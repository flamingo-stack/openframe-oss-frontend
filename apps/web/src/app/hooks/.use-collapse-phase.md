# use-collapse-phase.ts

A React hook that manages the mount/animation lifecycle of collapsible content using CSS grid-rows transitions, handling reduced-motion preferences and proper unmounting after collapse animations complete.

## Key Components

- **`CollapsePhase`** — Type representing the lifecycle state of a collapsible body: `'opening'` (just mounted, still visually collapsed), `'open'` (fully expanded, transition running), or `'closing'` (collapsing, still mounted until transition ends). `null` means unmounted.
- **`toggledPhase(phase)`** — Pure function computing the next phase when a toggle occurs. Returns `null` instead of `'closing'` if currently `'opening'` (no animation has started yet), and returns `null` instead of `'closing'` when the user prefers reduced motion (since no transition end event would fire).
- **`afterPaint(callback)`** — Schedules a callback after two animation frames, ensuring the browser commits the collapsed state before switching to `'open'`, so the transition animates rather than snapping instantly.
- **`useCollapsePhase()`** — The main hook. Returns `{ phase, toggle, collapsed }`:
  - `phase`: current `CollapsePhase | null`
  - `toggle()`: opens a closed body or begins closing an open one
  - `collapsed()`: called on transition end to unmount a closed body (sets `phase` to `null`)

## Usage Example

```typescript
import { useCollapsePhase } from './use-collapse-phase';

function OnboardingAccordionItem({ children }: { children: React.ReactNode }) {
  const { phase, toggle, collapsed } = useCollapsePhase();

  return (
    <div>
      <button onClick={toggle}>Toggle</button>
      {phase !== null && (
        <div
          style={{
            display: 'grid',
            gridTemplateRows: phase === 'open' ? '1fr' : '0fr',
            transition: 'grid-template-rows 0.2s ease',
          }}
          onTransitionEnd={collapsed}
        >
          <div style={{ overflow: 'hidden' }}>{children}</div>
        </div>
      )}
    </div>
  );
}
```

This pattern ensures the body mounts in a collapsed state (`opening`), animates open on the next paint (`open`), and cleanly unmounts after closing (`closing` → `null`) once the CSS transition finishes—avoiding the cost of rendering closed content and respecting `prefers-reduced-motion`.
