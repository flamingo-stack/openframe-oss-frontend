This script is a thin CLI entry point that triggers the loading-gate validation to ensure page components implement proper loading/skeleton states.

## Key Components

- **Shebang (`#!/usr/bin/env node`)** — allows the script to be executed directly as a Node.js CLI tool.
- **`runLoadingGate` import** — pulls in the core validation logic from the shared library module `scripts/lib/loading-gate.mjs`, which encapsulates the actual rule-checking engine for skeleton/loading state enforcement.
- **`runLoadingGate('check-page-skeletons')` call** — invokes the gate check, passing an identifier string used for logging/reporting context so output can be traced back to this specific check.

## Usage Example

Run directly via Node:

```bash
node check-page-skeletons.mjs
```

Or invoke it as part of an npm script:

```json
{
  "scripts": {
    "check:skeletons": "node scripts/check-page-skeletons.mjs"
  }
}
```

```bash
npm run check:skeletons
```

This is typically wired into CI or a pre-commit/pre-push hook to enforce that page-level components provide loading skeletons before merging, preventing regressions where pages render blank or jarring states during data fetches. For the actual validation rules and logic, see [`scripts/lib/loading-gate.mjs`](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/scripts/lib/loading-gate.mjs).
