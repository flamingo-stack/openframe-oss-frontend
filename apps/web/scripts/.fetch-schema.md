# fetch-schema.mjs

A Node.js CLI script that fetches a GraphQL schema from a running DGS backend via introspection and writes it as SDL (`schema.graphql`) for use by the Relay compiler.

The script loads environment variables from `.env.local`/`.env`, determines the GraphQL endpoint (defaulting to `NEXT_PUBLIC_TENANT_HOST_URL` or `http://localhost:8080`), performs an introspection query, converts the result into SDL using `graphql-js`, and writes it to `schema.graphql` at the project root.

## Key Components

- **`getArg(name)`** — Parses CLI flags (e.g., `--endpoint`, `--token`) from `process.argv`.
- **`loadDotEnv()`** — Reads `.env.local` and `.env` files and populates `process.env` without overwriting existing variables.
- **`INTROSPECTION_QUERY`** — Standard GraphQL introspection query string used to retrieve the full schema (types, fields, directives).
- **`fetchSchema()`** — Main async function that:
  - Sends the introspection query via `fetch` (with optional `Authorization: Bearer` header).
  - Builds a client schema with `buildClientSchema` and converts it to SDL with `printSchema` (from the `graphql` package).
  - Writes the generated SDL, prefixed with an auto-generated header comment, to `schema.graphql`.

## Usage Example

```bash
# Uses NEXT_PUBLIC_TENANT_HOST_URL from .env
npm run fetch-schema

# With an auth token via CLI flag
npm run fetch-schema -- --token <JWT>

# With an auth token via environment variable
GRAPHQL_TOKEN=<JWT> npm run fetch-schema

# Custom endpoint
npm run fetch-schema -- --endpoint http://localhost:4000/api/graphql

# Custom endpoint with token
npm run fetch-schema -- --endpoint http://localhost:4000/api/graphql --token <JWT>
```

**Notes:**
- Requires the `graphql` package (dynamically imported) as a project dependency.
- The output file `schema.graphql` includes a header noting it is auto-generated — do not edit it manually; re-run the script instead.
- On failure (non-2xx response or GraphQL errors), the script logs the error and exits with code `1`.
