Code generation script that parses `schema.graphql` and emits a TypeScript module containing Prisma-style enum definitions (combined const object + type for each GraphQL enum), written to `src/generated/schema-enums.ts`.

## Key Components

- **`SCHEMA_PATH`** - Resolved path to `schema.graphql` at the repository root, used as the source of truth for enum definitions.
- **`OUT_PATH`** - Resolved output path `src/generated/schema-enums.ts`, intentionally kept outside `src/__generated__/` so relay-compiler doesn't prune it.
- **Enum extraction logic** - Parses the GraphQL SDL using `graphql`'s `parse`, filters `EnumTypeDefinition` nodes, and sorts them alphabetically by name.
- **Code generation loop** - For each enum, generates a `const` object mapping each value to itself (`as const`) plus a derived TypeScript type sharing the same name, enabling dual use as both runtime value and type.

## Usage Example

Run via the npm script (chained into the build process):

```bash
npm run generate-enums
```

Given a schema like:

```graphql
enum SubscriptionStatus {
  ACTIVE
  CANCELED
}
```

The script generates:

```typescript
export const SubscriptionStatus = {
  ACTIVE: 'ACTIVE',
  CANCELED: 'CANCELED',
} as const;
export type SubscriptionStatus = (typeof SubscriptionStatus)[keyof typeof SubscriptionStatus];
```

Consumers can then import and use it as both a value and a type:

```typescript
import { SubscriptionStatus } from '@/generated/schema-enums';

function isActive(status: SubscriptionStatus): boolean {
  return status === SubscriptionStatus.ACTIVE;
}
```

The generated file is gitignored and should never be edited manually — re-run the script whenever `schema.graphql` changes.
