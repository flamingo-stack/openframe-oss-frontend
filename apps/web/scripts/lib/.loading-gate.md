## Purpose

Implements the app's "loading gate" — a CI/local check (`npm run check:loading`) that enforces the loading-standard rule engine from the installed `@flamingo-stack/openframe-frontend-core` library against this app's `src/` directory. It dynamically imports the engine straight from `node_modules` so rules always match the pinned lib version, rather than a bundled copy.

## Key Components

- **`RULE_EXAMPLES`** — Re-exported passing/failing examples per rule, sourced from the engine's `rule-examples.mjs`.
- **`loadingReport(srcRoot)`** — Builds an `engine.Project` indexing both the app's `src/` (reported) and the installed lib's `src/` (not reported, needed so lib-reading rules have something to read), runs `engine.analyzeProject` under `engine.CONFIGS.frontend`, and returns formatted finding strings (`file:line: message [RULE]`).
- **`runLoadingGate(name)`** — Runs `loadingReport`, prints findings to stderr and exits with code `1` if any exist, otherwise logs success.
- **Startup guard** — Checks `ENGINE_PATH` exists in the installed lib before import; exits `1` with an actionable error if the lib release lacks the loading-standard engine.

This module is the canonical entry point; `check-page-skeletons.mjs` runs it under its current name, and `check-skeleton-full-page.mjs` is a backward-compatible alias (never run both together).

## Usage Example

```javascript
import { runLoadingGate, loadingReport, RULE_EXAMPLES } from './loading-gate.mjs';

// Run as a CI gate (exits 1 on violations)
runLoadingGate('check-page-skeletons');

// Or inspect findings programmatically
const findings = loadingReport();
if (findings.length > 0) {
  console.log(`${findings.length} violations found`);
}

// Inspect rule documentation examples
console.log(RULE_EXAMPLES);
```

```bash
npm run check:loading
```
