## loading-gate.mjs

Core implementation of the app's loading-standard gate — a single run of the rule engine shipped by the installed `@flamingo-stack/openframe-frontend-core` library (loaded by file path from `node_modules`, never copied), checking this app's `src/` against the library's own `src/` indexed alongside it. It powers `npm run check:loading` and the "Loading gates" CI job defined in `.github/workflows/test.yml`.

The rules themselves (what they check, which components/skeletons/forms they recognize, and the opt-out form) are documented once in the engine's header at `src/loading-standard/engine.mjs` inside the library — this module only wires up the app-specific run and does not restate them.

Both `check-page-skeletons.mjs` and `check-skeleton-full-page.mjs` invoke this module; the latter is a legacy alias kept for backward compatibility and must never be run alongside the former.

## Key Components

- **`RULE_EXAMPLES`** — Re-exported from the engine's `rule-examples.mjs`; contains a failing/passing example per rule, useful for error messages or documentation.
- **`loadingReport(srcRoot)`** — Runs the engine's `Project`/`analyzeProject` over `srcRoot` (default: app's `src/`) with the installed library's `src/` indexed (not reported on). Returns an array of formatted finding strings (`file:line: message [RULE]`). Returns a `[GATE]` error if the library's `src/` is missing.
- **`runLoadingGate(name)`** — Runs `loadingReport()`, prints any findings to `stderr`, and exits with code `1` if findings exist; otherwise logs success and exits `0`.

## Usage Example

```javascript
// check-page-skeletons.mjs
import { runLoadingGate } from './loading-gate.mjs';

runLoadingGate('check-page-skeletons');
```

```bash
# Run via npm script
npm run check:loading
```

```text
check-page-skeletons: 2 place(s) that break the loading standard (see the header of the lib's
src/loading-standard/engine.mjs for each rule):
  src/pages/DevicesPage.vue:42: missing skeleton for async list [NO_SKELETON]
  src/components/UserCard.vue:10: deprecated skeleton still in use [DEPRECATED_SKELETON]
```

**Note:** `loadingReport()` requires the library's `src/` to be present under `node_modules/@flamingo-stack/openframe-frontend-core/src` — without it, lib-reading rules would silently pass by reading nothing, so the function fails loudly with a `[GATE]` finding instead.
