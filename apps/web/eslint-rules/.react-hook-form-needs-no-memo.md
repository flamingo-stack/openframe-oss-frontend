# react-hook-form-needs-no-memo.mjs

Custom ESLint rule that enforces a module-level `'use no memo'` directive in any file that uses `react-hook-form` at runtime, preventing the React Compiler from applying unsafe memoization to form state it cannot observe mutating.

## Key Components

- **`FORM_STATE_CARRIER_TYPES`** — A `Set` of react-hook-form TypeScript types (e.g. `Control`, `UseFormReturn`, `UseFormRegister`, `UseFormReset`) that represent a handle on the live form object. Importing any of these as a *type-only* import still counts as using react-hook-form, since the imported type names a live, mutable handle.
- **`reactHookFormNeedsNoMemo`** — The exported ESLint rule object (`import('eslint').Rule.RuleModule`). It:
  - Detects `import` declarations from `'react-hook-form'` with runtime specifiers (not type-only), or type-only imports naming a type in `FORM_STATE_CARRIER_TYPES`.
  - On `Program:exit`, checks whether a `'use no memo'` directive already exists in the directive prologue.
  - Reports a `missingDirective` error with an autofix that inserts `'use no memo';` — placed after `'use client'` if present, to keep Next.js's client directive first.

## Usage Example

Enable the rule in an ESLint flat config:

```javascript
import { reactHookFormNeedsNoMemo } from './react-hook-form-needs-no-memo.mjs';

export default [
  {
    plugins: {
      custom: {
        rules: {
          'react-hook-form-needs-no-memo': reactHookFormNeedsNoMemo,
        },
      },
    },
    rules: {
      'custom/react-hook-form-needs-no-memo': 'error',
    },
  },
];
```

A file that triggers the rule:

```typescript
// Missing directive — rule will autofix by inserting 'use no memo' at the top
import { useForm } from 'react-hook-form';

export function useSeedForm() {
  const form = useForm();
  return form;
}
```

After autofix:

```typescript
'use no memo';

import { useForm } from 'react-hook-form';

export function useSeedForm() {
  const form = useForm();
  return form;
}
```

**Note:** This rule should be removed once the project upgrades to react-hook-form 7.75+ and React 19.2.5, per the linked [react-hook-form discussion](https://github.com/orgs/react-hook-form/discussions/12524).
