This file defines and exports the custom ESLint plugin object for the `openframe` namespace, aggregating project-specific lint rules into a single plugin that can be registered in an ESLint flat config.

## Key Components

- **`openframePlugin`** — the default-exported plugin object containing a `rules` map keyed by rule name:
  - `form-label-scale` — imported from `./form-label-scale.mjs`, enforces correct usage of form label scaling.
  - `react-hook-form-needs-no-memo` — imported from `./react-hook-form-needs-no-memo.mjs`, flags unnecessary memoization around React Hook Form usage.

## Usage Example

Register the plugin under the `openframe/` prefix in your ESLint flat config (`eslint.config.mjs`):

```javascript
import openframePlugin from './index.mjs';

export default [
  {
    plugins: {
      openframe: openframePlugin,
    },
    rules: {
      'openframe/form-label-scale': 'warn',
      'openframe/react-hook-form-needs-no-memo': 'error',
    },
  },
];
```

Once registered, ESLint will apply both custom rules across the codebase, surfacing violations related to form label scaling conventions and redundant memoization patterns in React Hook Form components.
