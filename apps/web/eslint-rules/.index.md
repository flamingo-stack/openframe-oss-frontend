Entry point for the custom `openframe` ESLint plugin, aggregating individual lint rules into a single exportable plugin object for use in `eslint.config.mjs`.

## Key Components

- **`openframePlugin`** (default export) - A plugin object with a `rules` map exposing two custom ESLint rules under the `openframe/` namespace:
  - `form-label-scale` - Sourced from `form-label-scale.mjs`
  - `react-hook-form-needs-no-memo` - Sourced from `react-hook-form-needs-no-memo.mjs`

## Usage Example

Register the plugin in your ESLint flat config:

```javascript
// eslint.config.mjs
import openframePlugin from './index.mjs';

export default [
  {
    plugins: {
      openframe: openframePlugin,
    },
    rules: {
      'openframe/form-label-scale': 'warn',
      'openframe/react-hook-form-needs-no-memo': 'error',
    },
  },
];
```

Once registered, both rules run automatically during linting (`npm run lint`), flagging violations related to form label scaling conventions and unnecessary `useMemo`/`useCallback` wrapping in React Hook Form usage.

See the full source in [index.mjs](https://github.com/flamingo-stack/openframe-oss-frontend/blob/main/index.mjs) within the repository.
