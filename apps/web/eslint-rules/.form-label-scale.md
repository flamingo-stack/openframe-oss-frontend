# form-label-scale.mjs

A custom ESLint rule that enforces a consistent font scale (`text-h4`/large) for all form field labels across the dashboard, preventing new forms from defaulting to the library's smaller `text-h6` label size.

This rule exists because the shared component library (`@flamingo-stack/openframe-frontend-core`) defaults field labels to a small scale (`text-h6`) for other Flamingo apps, but the dashboard standardizes on the `large` scale. Without enforcement, new forms silently regress to the small default, causing visual inconsistency (as happened with policy and ticket forms).

## Key Components

- **`formLabelScale`** — the exported ESLint rule object (`meta` + `create`), auto-fixable.
- **`LIB_FIELD_CONTROLS`** — map of library components (`Input`, `Textarea`, `Autocomplete`, `FileUpload`, `ImageUploader`, `ScriptArguments`, `SearchableSelect`, `SelectTrigger`, `FieldWrapper`) to the prop name that carries their label text.
- **Detection logic**:
  - Tracks local import bindings from `@flamingo-stack/openframe-frontend-core` for field controls and `Label`.
  - For field controls with a label prop set, requires `labelVariant="large"`.
  - For `<Label>` elements, requires `variant="large"` unless it's a `surface` variant or `className` already contains `text-h4`.
  - Flags (without auto-fixing) a `className` that sets a conflicting `text-h*` scale, since it would silently override the variant.
- **Auto-fix**: inserts `labelVariant="large"` or `variant="large"` where safely possible.

## Usage Example

Add to an ESLint flat config:

```javascript
import { formLabelScale } from './rules/form-label-scale.mjs';

export default [
  {
    plugins: { dashboard: { rules: { 'form-label-scale': formLabelScale } } },
    rules: {
      'dashboard/form-label-scale': 'error',
    },
  },
];
```

Triggers on code like:

```vue
<script setup lang="ts">
import { Input, Label } from '@flamingo-stack/openframe-frontend-core';
</script>

<template>
  <!-- Flagged: missing labelVariant="large" -->
  <Input label="Email" />

  <!-- Flagged: Label defaults to small scale -->
  <Label>Status</Label>

  <!-- OK -->
  <Input label="Email" labelVariant="large" />
  <Label variant="large">Status</Label>
</template>
```
