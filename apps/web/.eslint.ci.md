# eslint.ci.mjs

ESLint configuration used specifically by CI, extending the shared base config while disabling the `relay/unused-fields` rule due to a large pre-existing backlog (543 findings) that predates proper `files:` glob patterns in the base config.

## Key Components

- **Default export**: A `defineConfig([...])` array that spreads the base ESLint config (`eslint.config.mjs`) and appends an override.
- **Override block** (`openframe-frontend/ci-relay-unused-fields-backlog`): Disables `relay/unused-fields` for all `.js`, `.jsx`, `.ts`, `.tsx` files, scoped only to this CI config.

## Usage Example

This config is intended to be referenced explicitly by the CI pipeline's lint step, not used locally:

```bash
# CI lint command (uses eslint.ci.mjs)
eslint --config eslint.ci.mjs .

# Local/editor/pre-commit lint command (uses eslint.config.mjs, rule stays ON)
npm run lint
```

```javascript
// eslint.ci.mjs
import { defineConfig } from 'eslint/config';
import base from './eslint.config.mjs';

export default defineConfig([
  ...base,
  {
    name: 'openframe-frontend/ci-relay-unused-fields-backlog',
    files: ['**/*.{js,jsx,ts,tsx}'],
    rules: { 'relay/unused-fields': 'off' },
  },
]);
```

## Important Notes

- The `relay/unused-fields` rule remains **enabled** in `eslint.config.mjs`, so editors and the pre-commit hook still surface over-fetching issues in files developers actively touch.
- This file exists purely to prevent CI from blocking PRs on a large, pre-existing backlog unrelated to the current change.
- **Deletion plan**: Once the `relay/unused-fields` backlog is fully resolved, delete `eslint.ci.mjs` and have CI run `npm run lint` directly against the base config.
