This file defines the ESLint configuration used by CI, which extends the base configuration but disables one rule (`relay/unused-fields`) that has a large pre-existing backlog of findings.

## Key Components

- **Default export**: An ESLint flat config array built with `defineConfig`, composed of:
  - `base` — the full shared configuration imported from `eslint.config.mjs`
  - An override object named `openframe-frontend/ci-relay-unused-fields-backlog` that targets all `.js`, `.jsx`, `.ts`, `.tsx` files and turns off the `relay/unused-fields` rule

## Purpose

CI uses this config instead of the base one so that pull requests aren't blocked by the pre-existing backlog of 543 `relay/unused-fields` findings (a legacy artifact from when `eslint.config.mjs` previously lacked `files:` patterns and thus linted nothing). All other rules remain enforced at zero violations. The rule stays active in the base config so developers still see it in their editor and in the pre-commit hook — it's only suppressed for CI so new code isn't blocked by unrelated, pre-existing debt.

This file should be deleted once the `relay/unused-fields` backlog is cleared, at which point CI can run `npm run lint` directly against the base config.

## Usage Example

```bash
# Run the CI-specific lint config (used in pipelines)
npx eslint --config eslint.ci.mjs .

# Contrast with the full/base config used locally and in pre-commit hooks
npx eslint --config eslint.config.mjs .
```

```javascript
// eslint.ci.mjs
import { defineConfig } from 'eslint/config';
import base from './eslint.config.mjs';

export default defineConfig([
  ...base,
  {
    name: 'openframe-frontend/ci-relay-unused-fields-backlog',
    files: ['**/*.{js,jsx,ts,tsx}'],
    rules: { 'relay/unused-fields': 'off' },
  },
]);
```
