# next.config.mjs

Next.js configuration that drives multi-target builds (web SSR, static export for Capacitor mobile/Tauri desktop) from a single codebase, with bundle versioning, route-scoped CSS inlining, and a dev-time chat proxy.

## Key Components

- **`isStaticExport`** — Boolean flag derived from `OPENFRAME_BUILD_TARGET === 'export'`. Switches output mode between `export` (static SPA for native shells) and `standalone` (SSR server for web).
- **`resolveBundleVersion()`** — Resolves the version string reported in the `X-OpenFrame-Client` header. Prefers `OPENFRAME_BUNDLE_VERSION` env var; falls back to `git describe --tags --match '[0-9]*' --always --dirty --abbrev=7`; returns `''` if both fail.
- **`nextConfig`** — The core `NextConfig` object:
  - `output`: `export` or `standalone` based on `isStaticExport`.
  - `outputFileTracingRoot` / `skipTrailingSlashRedirect`: standalone-only settings (irrelevant/harmful under `export`).
  - `trailingSlash: true` for consistent static-host-compatible routing.
  - `env`: injects `OPENFRAME_BUNDLE_VERSION` and `NEXT_PUBLIC_SUPABASE_HOST` (defaults to the shared hub host).
  - `images.unoptimized: true` for static export compatibility.
  - `reactCompiler: true` for automatic memoization via `babel-plugin-react-compiler`.
  - `compiler.relay`: Relay compiler config pointing at `./src` with generated artifacts in `./src/__generated__`.
  - `rewrites()`: standalone-only proxy that forwards `/content/*` to `NEXT_PUBLIC_TENANT_HOST_URL` for the embedded chat library's same-origin requirement during local dev/build.
- **`configForPhase(phase)`** — Per-phase config factory. Caps Turbopack memory to 8GB only during `phase-development-server`; wraps the final config with `withBundleAnalyzer` (enabled via `ANALYZE=true`).
- **Default export** — `withRouteStyles(configForPhase)`, which inlines per-route stylesheets into page HTML (from `@flamingo-stack/openframe-frontend-core/next-styles`).

## Usage Example

```bash
# Standard web build (SSR, standalone server)
npm run build

# Static export build for Capacitor/Tauri shells
OPENFRAME_BUILD_TARGET=export npm run build

# Local dev with chat proxy to a tenant gateway
NEXT_PUBLIC_TENANT_HOST_URL=https://tenant.example.com npm run dev

# Analyze bundle size
ANALYZE=true npm run build

# Override bundle version reported in X-OpenFrame-Client header
OPENFRAME_BUNDLE_VERSION=1.2.3 npm run build
```

Related: see `apps/mobile/scripts/build-web.sh` for the mirrored `git describe` logic used in mobile builds, and `src/lib/client-identity.ts` for how `OPENFRAME_BUNDLE_VERSION` is consumed.
