## Next.js Configuration

Central build configuration for the OpenFrame OSS frontend, supporting multiple deployment targets (SSR web server, static export for Capacitor mobile/Tauri desktop) from a single codebase.

## Key Components

- **`resolveBundleVersion()`** — Determines the version string reported in the `X-OpenFrame-Client` header. Prefers the `OPENFRAME_BUNDLE_VERSION` env var; falls back to `git describe` output; returns an empty string if neither is available.
- **`isStaticExport`** — Build-time flag (`OPENFRAME_BUILD_TARGET === 'export'`) that switches output mode between `export` (static SPA for native shells) and `standalone` (SSR server for web).
- **`nextConfig`** — The core `NextConfig` object: sets `output`, `distDir`, image handling, React Compiler, Relay compiler settings, and conditionally applies `outputFileTracingRoot`, `skipTrailingSlashRedirect`, and `rewrites()` depending on build target.
- **`rewrites()`** — Proxies `/content/*` requests to the tenant gateway (`NEXT_PUBLIC_TENANT_HOST_URL`) at build time; only active in standalone/local-dev builds, omitted entirely under static export.
- **`configForPhase(phase)`** — Applies dev-only Turbopack memory caps (8GB) and wraps the config with `withBundleAnalyzer`.
- **Default export** — `withRouteStyles(configForPhase)`, which inlines per-page stylesheets so each page paints without an extra request.

## Usage Example

```bash
# Standard SSR build (web deployment)
next build

# Static export build for Capacitor/Tauri native shells
OPENFRAME_BUILD_TARGET=export next build

# Local dev with tenant gateway proxy for embedded chat
NEXT_PUBLIC_TENANT_HOST_URL=https://tenant.example.com next dev

# Analyze bundle size
ANALYZE=true next build
```

```javascript
// Example: explicit bundle version override (overrides git describe)
process.env.OPENFRAME_BUNDLE_VERSION = '1.2.3-release';
```

Note: environment variables controlling build target (`OPENFRAME_BUILD_TARGET`, `OPENFRAME_BUNDLE_VERSION`) are build-time only and are never exposed to the client bundle, unlike `NEXT_PUBLIC_*` variables such as `NEXT_PUBLIC_SUPABASE_HOST`.
